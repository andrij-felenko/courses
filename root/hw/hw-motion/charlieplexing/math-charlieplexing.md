# 🧮 Математичний апарат Чарліплексингу: комбінаторика повних графів, аналіз паразитних вузлів та інтегральна яскравість

Чарліплексинг спирається на точний математичний фундамент: теорію орієнтованих графів, вузловий аналіз нелінійних електричних кіл та інтегральне числення імпульсного струму. Цей математичний апарат дає строгі аналітичні відповіді на чотири фундаментальні питання схемотехніка:
1. Скільки саме світлодіодів можна однозначно адресатувати за допомогою `N` ліній введення-виведення?
2. Яка точна топологічна перевага Чарліплексингу над класичною прямокутною матрицею рядків і стовпчиків?
3. Чому електричний струм не тече обхідними паразитними шляхами крізь вимкнені світлодіоди за наявності ізольованих вузлів?
4. Як розрахувати амплітуду імпульсного струму, шпаруватість і тепловий баланс для збереження заданої інтегральної яскравості світіння?

---

### 1. Комбінаторний розрахунок ємності шини та теорія графів

Розглянемо множину з `N` цифрових виводів мікроконтролера: `P = {p[0], p[1], ..., p[N-1]}`. Світлодіод є полярним напівпровідниковим приладом із двома виводами — анодом і катодом. Щоб запалити світлодіод, його анод необхідно з'єднати з виводом, на якому встановлено потенціал `HIGH` (активне джерело струму), а катод — із виводом, де встановлено `LOW` (активний стік струму).

Оскільки світлодіод не може мати анод і катод на одній і тій самій фізичній ніжці мікроконтролера (це відповідало б короткому замиканню виводу самого на себе), кожен світлодіод однозначно задається **впорядкованою парою** різних виводів `(p[i], p[j])`, де `i ≠ j`.

Порядок елементів у парі є критичним: пара `(p[i], p[j])` відповідає світлодіоду з анодом на `p[i]` та катодом на `p[j]`, тоді як пара `(p[j], p[i])` відповідає зустрічно увімкненому світлодіоду з анодом на `p[j]` та катодом на `p[i]`. Кількість таких пар визначається кількістю розміщень без повторень із `N` елементів по 2:

```
L(N) = P(N, 2)
     = N! / (N − 2)!           [означення кількості розміщень без повторень]
     = (N · (N − 1) · (N − 2)!) / (N − 2)!   [розклад факторіала на множники]
     = N · (N − 1)             [підсумок для матриці Чарліплексингу]
```

У термінах теорії графів система еквівалентна **повному орієнтованому графу** `K[N]` без петель. Кожна вершина графа відповідає окремому виводу мікроконтролера, а кожне напрямлене ребро від вершини `i` до вершини `j` відповідає фізичному світлодіоду з анодом на виводі `i` та катодом на виводі `j`. Матриця суміжності такого графа має нулі на головній діагоналі (відсутність петель) та одиниці на всіх інших позиціях, що підтверджує наявність `N² − N = N(N − 1)` робочих зв'язків.

### 2. Порівняльний аналіз із класичною прямокутною матрицею

Порівняємо Чарліплексинг із традиційною матричною розгорткою `R × C`, де `R` виводів виділено під рядки (джерела струму), а `C` — під стовпчики (стоки струму). При фіксованій загальній кількості виводів `N = R + C` максимальна кількість світлодіодів у класичній матриці досягається при симетричному поділі `R = C = N / 2`:

```
M(N) = R · C
     = (N / 2) · (N / 2)       [умова максимізації добутку при сталій сумі]
     = N² / 4                  [максимум для класичної прямокутної матриці]
```

Знайдемо коефіцієнт відносної ефективності Чарліплексингу у порівнянні з класичною матрицею:

```
η(N) = L(N) / M(N)
     = (N · (N − 1)) / (N² / 4)  [підстановка виведених формул ємності]
     = (4 · N · (N − 1)) / N²    [множення чисельника й знаменника на 4]
     = (4 · N² − 4 · N) / N²     [розкриття дужок у чисельнику]
     = 4 · (1 − 1 / N)           [почленне ділення на N²]
```

Дослідимо поведінку цієї функції при зростанні кількості виводів `N`:

```
lim[N→∞] η(N) = lim[N→∞] 4 · (1 − 1 / N)
              = 4 · (1 − 0)      [граничний перехід при 1/N → 0]
              = 4                [асимптотична перевага у 4 рази]
```

Аналіз показує швидке наближення до теоретичної межі:
- При `N = 3`: `η(3) = 4 · (1 − 1/3) = 2.67` (6 світлодіодів Чарліплексингу проти 2 світлодіодів у матриці 1×2).
- При `N = 4`: `η(4) = 4 · (1 − 1/4) = 3.00` (12 світлодіодів проти 4 у матриці 2×2).
- При `N = 8`: `η(8) = 4 · (1 − 1/8) = 3.50` (56 світлодіодів проти 16 у матриці 4×4).
- При `N = 16`: `η(16) = 4 · (1 − 1/16) = 3.75` (240 світлодіодів проти 64 у матриці 8×8).

### 3. Вузловий аналіз паразитних шляхів (Sneak Paths)

Критичною умовою бездоганної роботи Чарліплексингу є повна відсутність небажаного протікання струму через незадіяні діоди. Нехай вивід `p[0]` налаштовано як `HIGH` (потенціал `V[CC]`), вивід `p[1]` — як `LOW` (потенціал `0 В`), а всі інші `N − 2` виводів перебувають у стані високого імпедансу (`Hi-Z`).

Розглянемо довільний третій вивід `p[k]` (де `k ≥ 2`), який висить у повітрі (`Hi-Z`). До цього плаваючого вузла під'єднані два світлодіоди:
1. `D[0, k]` з анодом на активній лінії `p[0]` (`V[CC]`) та катодом на ізольованому вузлі `p[k]`.
2. `D[k, 1]` з анодом на ізольованому вузлі `p[k]` та катодом на активній лінії `p[1]` (`0 В`).

Ці два світлодіоди утворюють послідовний паразитний міст `p[0] → D[0, k] → p[k] → D[k, 1] → p[1]`, увімкнений паралельно до основного робочого діода `D[0, 1]`.

Оскільки внутрішній опір цифрового виводу у стані `Hi-Z` перевищує сотні мегаом, струм відгалуження у мікроконтролер відсутній (`I[pin] ≈ 0`). За першим законом Кірхгофа струми через обидва паразитні світлодіоди є строго рівними:

```
I[D0k] = I[Dk1] = I[sneak]     [перший закон Кірхгофа для вузла p[k]]
```

Вольт-амперна характеристика реального світлодіода описується рівнянням Шоклі для `pn`-переходу: `I = I[s] · (exp(q · U / (n · k · T)) − 1)`. Для однакових світлодіодів однаковий струм `I[sneak]` викликає абсолютно однакові падіння напруги на обох переходах:

```
U[D0k] = U[Dk1] = U[D]         [симетрія ідентичних напівпровідникових структур]
```

Складемо рівняння контурних напруг за другим законом Кірхгофа від шини живлення до землі:

```
V[CC] = U[D0k] + U[Dk1] + 2 · I[sneak] · R
      = 2 · U[D] + 2 · I[sneak] · R  [де R — струмообмежувальний опір у колі]
```

У докритичному стані, коли діоди закриті, паразитний струм `I[sneak] ≈ 0`. Спад напруги на струмообмежувальних резисторах дорівнює нулю. Тоді напруга розподіляється порівну між двома діодами:

```
V[k] = V[CC] / 2               [потенціал плаваючого вузла p[k]]
U[D] = V[CC] / 2               [напруга на кожному з двох паразитних діодів]
```

Щоб діод почав помітно випромінювати світло, прикладена до нього пряма напруга `U[D]` має перевищити його порогову пряму напругу відкриття `V[F]`:

```
U[D] > V[F]                    [умова відкриття напівпровідникового діода]
V[CC] / 2 > V[F]               [підстановка U[D] = V[CC] / 2]
V[CC] > 2 · V[F]               [критерій виникнення паразитного світіння]
```

Звідси випливає строга **нерівність стійкості Чарліплексингу до примарного світіння**:

```
V[CC] < 2 · V[F]               [гарантія відсутності паразитних струмів]
```

Якщо ланцюг паразитного обходу містить `m` проміжних ізольованих вузлів (`m ≥ 2`), сумарний поріг відкриття зростає до `m · V[F]`. Отже, двохдіодний міст через один проміжний вивід є найгіршим, найбільш небезпечним крайовим випадком, і виконання умови `V[CC] < 2 · V[F]` гарантує повну відсутність привидів у всій матриці довільної розмірності.

### 4. Інтегральна яскравість і розрахунок імпульсного режиму

Людське око сприймає періодичні світлові спалахи високої частоти (понад 60–100 Гц) як безперервне стабільне світло. Згідно з психофізичним законом Блоха, видима яскравість спалаху тривалістю, меншою за час зорової інтеграції (~100 мс), пропорційна повній енергії випромінювання, тобто середньому значенню струму за період розгортки кадру `T[frame]`:

```
I[avg] = (1 / T[frame]) · ∫[0..T[frame]] i(t) dt
       = (1 / T[frame]) · (I[peak] · t[on])   [для прямокутного імпульсу струму]
       = I[peak] · (t[on] / T[frame])         [виділення коефіцієнта заповнення]
       = I[peak] · D                          [де D — шпаруватість увімкнення]
```

При поодинокому скануванні `L = N · (N − 1)` світлодіодів кожен діод отримує рівну часову частку `D = 1 / L`:

```
D = 1 / (N · (N − 1))          [шпаруватість поодинокої розгортки]
I[peak] = I[avg] · N · (N − 1) [необхідний піковий імпульсний струм]
```

Для типових світлодіодів комфортна видима яскравість відповідає середньому струму `I[avg] ≈ 2 мА`. Звідси:
- Для `N = 3` (`L = 6` діодів): `I[peak] = 2 мА · 6 = 12 мА` (повністю безпечно для будь-якого МК).
- Для `N = 4` (`L = 12` діодів): `I[peak] = 2 мА · 12 = 24 мА` (граничний робочий струм стандартного виводу AVR чи STM32).
- Для `N = 5` (`L = 20` діодів): `I[peak] = 2 мА · 20 = 40 мА` (перевищує номінальний струм багатьох мікроконтролерів).

Це встановлює фундаментальну інженерну нерівність масштабування поодинокого Чарліплексингу без використання зовнішніх підсилювальних транзисторних ключів:

```
N · (N − 1) ≤ I[max,GPIO] / I[avg,target]
```

Для подолання цього обмеження у великих масивах застосовують групове (рядкове) сканування, де один вивід-анод `HIGH` одночасно живить кілька виводів-катодів `LOW` через індивідуальні резистори. У такому режимі коефіцієнт заповнення зростає до `D = 1 / N`, що дозволяє нарощувати кількість світлодіодів при збереженні високої яскравості.
