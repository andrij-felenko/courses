# 🧮 Розрахунок інтервалів векторів та доведення ліміту напруги у просторово-векторній ШІМ

Коли трифазний інвертор напруги синтезує обертове магнітне поле статора, силові напівпровідникові ключі можуть перебувати лише у восьми дискретних станах. Будь-яка неперервна трифазна напруга формується як інтегральне середнє значення цих базових векторів за період високочастотної комутації. Тут розгорнуто строгий математичний апарат розрахунку тривалостей активних і нульових векторів за законом вольт-секундного балансу в косокутних базисах усіх шести секторів гексагона, виведено прямий безтригонометричний метод синтезу через компоненти нерухомої системи координат, проаналізовано гармонійний склад напруги при інжекції нульової послідовності та доведено геометричну межу використання напруги шини постійного струму `1/√3 ≈ 57.74 %` проти `50.0 %` у класичній синусоїдальній ШІМ.

## 1. Проекція трифазної системи на ортогональну площину (перетворення Кларк)

Трифазна система напруг у просторі статора електричної машини задається трьома скалярними величинами `V_an(t)`, `V_bn(t)`, `V_cn(t)`, чиї просторові осі обмоток зміщені на кут `120°` (`2π/3` радіан). Узагальнений просторовий вектор напруги `V_s` визначається як геометрична сума миттєвих фазних напруг уздовж відповідних одиничних просторових векторів:

```
V_s = (2/3) · (V_an + V_bn · e^(j·2π/3) + V_cn · e^(j·4π/3))
```

Масштабний числовий множник `2/3` обрано з фундаментальної вимоги амплітудної інваріантності. Це означає, що за умови дії симетричної трифазної системи напруг із піковою фазною амплітудою `V_m` довжина синтезованого вектора `|V_s|` на двовимірній комплексній площині буде тотожно дорівнювати амплітуді фазної синусоїди `V_m`. Якби було обрано коефіцієнт `√(2/3)` (потужнісно-інваріантна форма Кларк), зберігалася б миттєва електрична потужність без числового коефіцієнта, але вектор напруги масштабувався б у `√(3/2)` раза, що ускладнило б пряме фізичне зіставлення амплітуд із напругою шини живлення.

Розкладаючи комплексні поворотні множники за формулою Ейлера `e^(j·φ) = cos(φ) + j·sin(φ)`, записуємо точні значення тригонометричних функцій для просторових зсувів:

```
cos(2π/3) = -1/2
sin(2π/3) = √3/2
cos(4π/3) = -1/2
sin(4π/3) = -√3/2
```

Підставляючи ці значення у вихідний вираз просторового вектора, відокремлюємо дійсну складову вздовж осі `α` (яка збігається з віссю фази A) та уявну складову вздовж перпендикулярної осі `β`:

```
V_α
= (2/3) · (V_an + V_bn · cos(2π/3) + V_cn · cos(4π/3))       [підстановка тригонометричних косинусів]
= (2/3) · (V_an - 0.5 · V_bn - 0.5 · V_cn)                  [групування коефіцієнтів проекцій]

V_β
= (2/3) · (0 + V_bn · sin(2π/3) + V_cn · sin(4π/3))         [підстановка тригонометричних синусів]
= (2/3) · ( (√3/2) · V_bn - (√3/2) · V_cn )                 [винесення спільного кореня]
= (1/√3) · (V_bn - V_cn)                                     [спрощення коефіцієнта (2/3)·(√3/2) = 1/√3]
```

Для трипровідної системи обмоток двигуна, з'єднаних у зірку з ізольованою центральною нейтраллю, перший закон Кірхгофа вимагає рівності нулю суми миттєвих струмів, а за симетричного магнітного опору — і суми фазно-нейтральних напруг: `V_an + V_bn + V_cn = 0`. Звідси напруга третьої фази однозначно визначається через дві інші: `V_cn = -V_an - V_bn`. Підставляючи цей вираз у формулу для `V_α`, отримуємо спрощену форму проекції:

```
V_α
= (2/3) · (V_an - 0.5 · V_bn - 0.5 · (-V_an - V_bn))         [підстановка виразу ізольованої нейтралі]
= (2/3) · (V_an - 0.5 · V_bn + 0.5 · V_an + 0.5 · V_bn)      [розкриття дужок]
= (2/3) · (1.5 · V_an)                                       [взаємне скорочення доданків фази B]
= V_an                                                       [прямий збіг проекції alpha з напругою фази A]
```

Цей результат наочно демонструє перевагу амплітудно-інваріантної системи координат: координата `V_α` у будь-яку мить часу безпосередньо відображає миттєву фазну напругу першої фази навантаження.

## 2. Координати восьми дискретних векторів інвертора

Потенціал кожної фази на виході трифазного моста відносно мінусової шини постійного струму `GND` набуває бінарних значень `V_a, V_b, V_c ∈ {0, V_dc}` залежно від логічного стану верхніх силових ключів `S_a, S_b, S_c ∈ {0, 1}`. Оскільки нейтраль двигуна `N` електрично не з'єднана з жодною з шин живлення, її потенціал відносно землі плаває разом із комутацією і дорівнює середньому арифметичному потенціалів усіх трьох стійок інвертора:

```
V_N = (V_a + V_b + V_c) / 3
```

Фазні напруги, прикладені безпосередньо до обмоток статора, визначаються різницею потенціалів між виводом відповідної фази та нейтральною точкою:

```
V_an = V_a - V_N
V_bn = V_b - V_N
V_cn = V_c - V_N
```

Розглянемо детальний розрахунок для активного стану `(1, 0, 0)`, якому відповідає базовий просторовий вектор `V₁`:

```
V_a = V_dc,  V_b = 0,  V_c = 0                               [стан ключів S_a=1, S_b=0, S_c=0]
V_N = (V_dc + 0 + 0) / 3 = (1/3) · V_dc                      [потенціал плаваючої нейтралі]
V_an = V_dc - (1/3) · V_dc = +(2/3) · V_dc                   [напруга на фазі A]
V_bn = 0 - (1/3) · V_dc = -(1/3) · V_dc                      [напруга на фазі B]
V_cn = 0 - (1/3) · V_dc = -(1/3) · V_dc                      [напруга на фазі C]
```

Підставляючи отримані фазні напруги у матрицю перетворення Кларк, знаходимо положення вектора `V₁` на двовимірній площині:

```
V_1α
= (2/3) · ((2/3)·V_dc - 0.5·(-1/3)·V_dc - 0.5·(-1/3)·V_dc)   [підстановка у формулу осі alpha]
= (2/3) · ((2/3)·V_dc + (1/6)·V_dc + (1/6)·V_dc)            [зведення дробів до спільного знаменника]
= (2/3) · (1.0 · V_dc)                                       [сума часток у дужках]
= (2/3) · V_dc                                               [кінцева координата вздовж дійсної осі]

V_1β
= (1/√3) · ((-1/3)·V_dc - (-1/3)·V_dc)                       [підстановка у формулу осі beta]
= 0                                                          [повна взаємна компенсація проекцій]
```

Модуль вектора `V₁` дорівнює `|V₁| = √(((2/3)·V_dc)² + 0²) = (2/3) · V_dc`, а його фазовий кут у полярних координатах становить `0°`.

Виконуючи аналогічні обчислення для всіх комбінацій перемикання силових транзисторів, формуємо вичерпну таблицю станів інвертора:

| Вектор | Код стану `(S_a, S_b, S_c)` | `V_an / V_dc` | `V_bn / V_dc` | `V_cn / V_dc` | `V_α / V_dc` | `V_β / V_dc` | Модуль вектора | Кут `θ` |
|:---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| `V₀` | `(0, 0, 0)` | `0` | `0` | `0` | `0` | `0` | `0` | — |
| `V₁` | `(1, 0, 0)` | `+2/3` | `-1/3` | `-1/3` | `+2/3` | `0` | `(2/3)·V_dc` | `0°` |
| `V₂` | `(1, 1, 0)` | `+1/3` | `+1/3` | `-2/3` | `+1/3` | `+1/√3` | `(2/3)·V_dc` | `60°` |
| `V₃` | `(0, 1, 0)` | `-1/3` | `+2/3` | `-1/3` | `-1/3` | `+1/√3` | `(2/3)·V_dc` | `120°` |
| `V₄` | `(0, 1, 1)` | `-2/3` | `+1/3` | `+1/3` | `-2/3` | `0` | `(2/3)·V_dc` | `180°` |
| `V₅` | `(0, 0, 1)` | `-1/3` | `-1/3` | `+2/3` | `-1/3` | `-1/√3` | `(2/3)·V_dc` | `240°` |
| `V₆` | `(1, 0, 1)` | `+1/3` | `-2/3` | `+1/3` | `+1/3` | `-1/√3` | `(2/3)·V_dc` | `300°` |
| `V₇` | `(1, 1, 1)` | `0` | `0` | `0` | `0` | `0` | `0` | — |

Шість активних векторів `V₁..V₆` мають строго однакову довжину `(2/3) · V_dc` і розвернуті один відносно одного на `60°`. Вони утворюють правильний шестикутник на площині `(α, β)`. Два вектори `V₀` та `V₇` мають нульову довжину і представляють стан короткого замикання всіх обмоток двигуна на землю або на шину живлення відповідно.

## 3. Математичний апарат вольт-секундного балансу в Секторі 1

Нехай вектор завдання `V_ref = |V_ref| · e^(j·θ)` знаходиться всередині першого сектора гексагона, тобто його кут задовольняє умову `0 ≤ θ ≤ π/3`. Завдання модулятора — підібрати такі тривалості увімкнення граничних активних векторів `V₁` і `V₂`, щоб інтеграл напруги за період ШІМ `T_s` точно дорівнював інтегралу від бажаного безперервного вектора `V_ref`.

Оскільки за період ШІМ вектори вважаються сталими шматково-постійними функціями, інтегральне рівняння перетворюється на алгебраїчне рівняння вольт-секундного балансу:

```
V_ref · T_s = V₁ · T₁ + V₂ · T₂ + V₀ · T₀
```

де `T₁` — час активності вектора `V₁`, `T₂` — час активності вектора `V₂`, а `T₀ = T_s - T₁ - T₂` — залишковий час, протягом якого інвертор генерує нульову напругу.

Для аналітичного розв'язання цього векторного рівняння спроектуємо його на прямокутні осі `α` та `β`:

```
|V_ref| · cos(θ) · T_s = |V₁| · T₁ + |V₂| · cos(π/3) · T₂     [проекція на вісь alpha]
|V_ref| · sin(θ) · T_s = 0 · T₁ + |V₂| · sin(π/3) · T₂         [проекція на вісь beta]
```

Підставимо у систему відомі довжини базових векторів `|V₁| = |V₂| = (2/3) · V_dc` і табличні значення кутів `cos(π/3) = 1/2`, `sin(π/3) = √3/2`:

```
|V_ref| · cos(θ) · T_s = (2/3) · V_dc · T₁ + (1/3) · V_dc · T₂   (Рівняння 1)
|V_ref| · sin(θ) · T_s = (1/√3) · V_dc · T₂                      (Рівняння 2)
```

З другого рівняння одразу знаходимо точний вираз для тривалості другого активного вектора `T₂`:

```
T₂
= √3 · (T_s · |V_ref| / V_dc) · sin(θ)                        [множення обох частин на √3 / V_dc]
```

Тепер підставимо отримане значення `T₂` у перше рівняння для виведення формули тривалості `T₁`:

```
(2/3) · V_dc · T₁
= |V_ref| · cos(θ) · T_s - (1/3) · V_dc · T₂                  [перенесення доданка з T2 праворуч]
= |V_ref| · cos(θ) · T_s - (1/3) · V_dc · (√3 · T_s · |V_ref| / V_dc · sin(θ))  [підстановка виразу для T2]
= |V_ref| · T_s · (cos(θ) - (1/√3) · sin(θ))                 [винесення спільних множників]
```

Помножимо обидві частини рівності на дріб `3 / (2 · V_dc)` та перетворимо тригонометричний вираз у дужках:

```
T₁
= (3/2) · (T_s · |V_ref| / V_dc) · (cos(θ) - (1/√3) · sin(θ)) [множення на 3/(2·V_dc)]
= √3 · (T_s · |V_ref| / V_dc) · ((√3/2) · cos(θ) - (1/2) · sin(θ))  [внесення коефіцієнта √3/2]
= √3 · (T_s · |V_ref| / V_dc) · (sin(π/3) · cos(θ) - cos(π/3) · sin(θ))  [заміна на табличні синуси/косинуси]
= √3 · (T_s · |V_ref| / V_dc) · sin(π/3 - θ)                 [застосування формули синуса різниці аргументів]
```

Таким чином, для першого сектора отримано остаточні робочі формули тривалостей:

```
T₁ = √3 · (T_s · |V_ref| / V_dc) · sin(60° - θ)
T₂ = √3 · (T_s · |V_ref| / V_dc) · sin(θ)
T₀ = T_s - T₁ - T₂
```

Якщо визначити коефіцієнт глибини модуляції як відношення амплітуди вектора завдання до максимально можливої лінійної напруги `m = |V_ref| / (V_dc / √3)`, формули зводяться до елегантного безрозмірного вигляду:

```
T₁ = m · T_s · sin(60° - θ)
T₂ = m · T_s · sin(θ)
T₀ = T_s · (1 - m · (sin(60° - θ) + sin(θ)))
```

Ці вирази мають прозорий фізичний зміст закону важеля: коли кут `θ` наближається до `0°`, тривалість `T₁` прямує до максимуму `m · T_s · sin(60°)`, а `T₂` спадає до нуля. Коли кут доходить до середини сектора (`θ = 30°`), тривалості зрівнюються: `T₁ = T₂ = m · T_s · 0.5`. При наближенні до `60°` домінує вектор `V₂`, а час `T₁` прямує до нуля.

## 4. Прямий алгебраїчний розрахунок часів без обчислення кута

У високошвидкісних цифрових системах керування реального часу пряме обчислення тригонометричних функцій `sin()`, `cos()` та арктангенса `atan2()` створює значне обчислювальне навантаження на процесорне ядро. Тому на практиці застосовують прямий алгебраїчний метод, що оперує безпосередньо прямокутними компонентами `V_α` та `V_β`, які надходять зі зворотного перетворення Парка.

Виразимо тригонометричні складові часів у Секторі 1 через декартові координати `V_α = |V_ref| · cos(θ)` та `V_β = |V_ref| · sin(θ)`:

```
T₁
= √3 · (T_s / V_dc) · |V_ref| · (sin(60°) · cos(θ) - cos(60°) · sin(θ))  [розкриття синуса різниці]
= √3 · (T_s / V_dc) · ((√3/2) · V_α - (1/2) · V_β)                      [підстановка координат alpha і beta]
= (T_s / V_dc) · (1.5 · V_α - (√3/2) · V_β)                              [внесення множника √3 у дужки]

T₂
= √3 · (T_s / V_dc) · |V_ref| · sin(θ)                                   [базовий вираз для T2]
= √3 · (T_s / V_dc) · V_β                                                [пряма підстановка V_beta]
```

Для уніфікації розрахунків у всіх шести секторах введемо три проміжні базисні змінні:

```
X = √3 · (T_s / V_dc) · V_β
Y = (T_s / V_dc) · (1.5 · V_α + (√3/2) · V_β)
Z = (T_s / V_dc) · (-1.5 · V_α + (√3/2) · V_β)
```

Завдяки симетрії гексагона тривалості активних векторів для будь-якого сектора виражаються виключно через перестановку та зміну знаків цих трьох змінних:

| Номер сектора | Перший активний вектор `T_a` | Другий активний вектор `T_b` | Залишковий нульовий час `T_0` |
|:---:|:---:|:---:|:---:|
| **Сектор I** | `-Z` | `X` | `T_s - T_a - T_b` |
| **Сектор II** | `Z` | `Y` | `T_s - T_a - T_b` |
| **Сектор III** | `X` | `-Y` | `T_s - T_a - T_b` |
| **Сектор IV** | `-X` | `Z` | `T_s - T_a - T_b` |
| **Сектор V** | `-Y` | `-Z` | `T_s - T_a - T_b` |
| **Сектор VI** | `Y` | `-X` | `T_s - T_a - T_b` |

Цей алгебраїчний підхід потребує лише декількох операцій множення та додавання з фіксованими коефіцієнтами, повністю виключаючи тригонометричні виклики з переривання ШІМ.

## 5. Доведення ліміту використання напруги шини постійного струму

Критерієм перебування модулятора в зоні лінійного формування напруги є фізична умова неперевищення сумою активних інтервалів тривалості повного періоду ШІМ:

```
T₁ + T₂ ≤ T_s
```

Підставимо у цю нерівність тригонометричні вирази для `T₁` та `T₂`:

```
T₁ + T₂
= √3 · (T_s · |V_ref| / V_dc) · (sin(60° - θ) + sin(θ))        [підстановка формул часів]
= √3 · (T_s · |V_ref| / V_dc) · (2 · sin(30°) · cos(θ - 30°)) [застосування формули суми синусів]
= √3 · (T_s · |V_ref| / V_dc) · (2 · 0.5 · cos(θ - 30°))      [підстановка sin(30°) = 0.5]
= √3 · (T_s · |V_ref| / V_dc) · cos(θ - 30°)                  [спрощений тригонометричний вираз]
```

Функція `cos(θ - 30°)` набуває свого абсолютного максимуму, коли її аргумент дорівнює нулю, тобто точно посередині сектора при куті `θ = 30°` (`π/6` рад). У цій точці косинус дорівнює одиниці, і сума тривалостей стає максимальною:

```
(T₁ + T₂)_max = √3 · (T_s · |V_ref| / V_dc)
```

Прирівнюючи це максимальне значення до гранично допустимого часу періоду `T_s`, знаходимо абсолютну теоретичну межу амплітуди вектора напруги в лінійному режимі:

```
√3 · (T_s · |V_ref_max| / V_dc) = T_s                         [гранична рівність суми часів періоду]
|V_ref_max| = V_dc / √3                                       [ділення обох частин на √3·T_s / V_dc]
|V_ref_max| ≈ 0.57735 · V_dc                                  [числовий розрахунок коефіцієнта]
```

Геометрично величина `V_dc / √3` — це радіус кола, вписаного у шестикутник базових векторів (апофема правильного гексагона зі стороною `(2/3)·V_dc`):

```
R_inscribed = ((2/3) · V_dc) · cos(30°) = ((2/3) · V_dc) · (√3 / 2) = V_dc / √3
```

Порівняємо це значення з граничною напругою синусоїдальної ШІМ (SPWM):

1. **SPWM:** амплітуда кожної фазної напруги модулюється окремо відносно фіксованої віртуальної середньої точки шини DC (`V_dc / 2`). Щоб уникнути обмеження сигналу (кліпінгу), пікова фазна амплітуда не може перевищувати `V_max_SPWM = V_dc / 2 = 0.5000 · V_dc`.
2. **SVPWM:** траєкторія вектора рухається по вписаному колу гексагона з радіусом `V_max_SVPWM = V_dc / √3 ≈ 0.57735 · V_dc`.

Співвідношення між граничними амплітудами:

```
V_max_SVPWM / V_max_SPWM
= (V_dc / √3) / (V_dc / 2)                                    [відношення граничних амплітуд]
= 2 / √3                                                      [скорочення напруги живлення V_dc]
≈ 1.1547005                                                   [числовий коефіцієнт зростання]
```

Це математично доводить, що просторово-векторна модуляція забезпечує приріст доступної вихідної напруги на **+15.47 %** порівняно з класичною синусоїдальною ШІМ за абсолютно однакової напруги джерела живлення `V_dc`.

Перевіримо максимальну лінійну (міжфазну) напругу:

```
V_line_max_SPWM  = √3 · (V_dc / 2)  ≈ 0.8660 · V_dc
V_line_max_SVPWM = √3 · (V_dc / √3) = 1.0000 · V_dc
```

У режимі SVPWM інвертор здатний видати між фазами чисту синусоїду, чий розмах від піку до піку точно дорівнює повній напрузі шини живлення `V_dc`.

## 6. Аналітичний зв'язок SVPWM з підмішуванням 3-ї гармоніки

Фізичний механізм, що дозволяє отримати 15.5 % додаткової напруги без викривлення міжфазного струму, полягає в автоматичній інжекції синфазної напруги нульової послідовності.

У симетричному 7-сегментному циклі нульовий стан розбивається на дві рівні половини між векторами `V₀ (000)` та `V₇ (111)`: `T_00 = T_0 / 2`, `T_77 = T_0 / 2`. Це математично еквівалентно зміщенню миттєвих фазних сигналів на синфазну добавку `V_zero(t)`:

```
V_zero(t) = 0.5 · (V_dc - max(V_a, V_b, V_c) - min(V_a, V_b, V_c))
```

Розглянемо симетричний трифазний набір синусоїд з амплітудою `V_m`:

```
V_a(t) = V_m · sin(ωt)
V_b(t) = V_m · sin(ωt - 2π/3)
V_c(t) = V_m · sin(ωt - 4π/3)
```

На інтервалі `[-π/6, π/6]` (що відповідає кутам від `-30°` до `+30°`), фаза A має найбільше додатне значення, а фази B і C формують симетричний мінімум:

```
max(V_a, V_b, V_c) = V_m · cos(ωt)
min(V_a, V_b, V_c) = -V_m · cos(ωt) · cos(π/3) - V_m · |sin(ωt)| · sin(π/3)
```

Функція `V_zero(t)` є строго періодичною з частотою `3ω` (втричі вищою за основну електричну частоту). Розкладемо модифікований фазний сигнал `V_mod(t) = V_a(t) + V_zero(t)` у ряд Фур'є:

```
V_mod(t) = (2/√3) · V_m · (sin(ωt) + (1/6) · sin(3ωt) - (1/216) · sin(9ωt) + ...)
```

Амплітуда третьої гармоніки становить рівно `1/6` (16.67 %) від амплітуди першої гармоніки. Дослідимо функцію `f(φ) = sin(φ) + (1/6)·sin(3φ)` на екстремуми:

```
df/dφ
= cos(φ) + (3/6) · cos(3φ)                                    [взяття першої похідної]
= cos(φ) + 0.5 · (4·cos³(φ) - 3·cos(φ))                       [формула косинуса потрійного кута]
= cos(φ) + 2·cos³(φ) - 1.5·cos(φ)                             [розкриття дужок]
= 2·cos³(φ) - 0.5·cos(φ)                                      [зведення подібних доданків]
= 0.5 · cos(φ) · (4·cos²(φ) - 1)                             [винесення спільного множника]
```

Прирівнюючи похідну до нуля, отримуємо стаціонарні точки:
1. `cos(φ) = 0` → `φ = 90°` (локальний мінімум — прогин сідла);
2. `4·cos²(φ) - 1 = 0` → `cos(φ) = 1/2` → `φ = 60°` та `φ = 120°` (два симетричні максимуми сідла).

Обчислимо значення функції у точках максимумів при `φ = 60°`:

```
f(60°)
= sin(60°) + (1/6) · sin(180°)                                [підстановка аргументу 60 градусів]
= √3/2 + 0                                                    [синус 180 градусів тотожно дорівнює нулю]
= √3/2 ≈ 0.866025                                             [висота сплющеного піку]
```

Завдяки додаванню третьої гармоніки максимальна висота кривої зменшилася з `1.0` до `√3/2 ≈ 0.866`. Це дає змогу масштабувати весь сигнал на коефіцієнт `2/√3 ≈ 1.1547` до моменту, коли два піки торкнуться одиничного рівня шини живлення.

Оскільки обмотки статора з'єднані в зірку з ізольованою нейтраллю, третя гармоніка, будучи синфазною для всіх трьох фаз, прикладається до нейтральної точки `N` і повністю взаємознищується у фазно-нейтральних напругах обмоток:

```
V_an(t) = (V_a(t) + V_zero(t)) - V_N(t) = V_a(t)
V_ab(t) = (V_a(t) + V_zero(t)) - (V_b(t) + V_zero(t)) = V_a(t) - V_b(t)
```

Таким чином, інжекція третьої гармоніки змінює лише форму напруги на виході ключів відносно землі, тоді як струми й магнітний потік статора залишаються ідеально синусоїдними.

## 7. Зона перемодуляції та межа шестикрокового режиму

Коли амплітуда вектора завдання перевищує радіус вписаного кола `|V_ref| > V_dc / √3`, траєкторія кінця вектора виходить за межі лінійного гексагона біля вершин секторів. Виникає зона перемодуляції (*Overmodulation*), що поділяється на два діапазони:

1. **Режим перемодуляції I (`V_dc / √3 < |V_ref| ≤ 0.606 · V_dc`):**
   Кругова траєкторія частково перетинає ребра шестикутника. Для точок, що опинилися за межами гексагона, тривалість нульового вектора падає до нуля (`T₀ = 0`), а вектор примусово обмежується контуром гексагона шляхом пропорційного масштабування:
   `T₁_mod = T₁ · T_s / (T₁ + T₂)`, `T₂_mod = T₂ · T_s / (T₁ + T₂)`.
   Вихідна напруга зростає, але у спектрі з'являються слабкі низькочастотні гармоніки 5-го та 7-го порядків.

2. **Режим перемодуляції II (`0.606 · V_dc < |V_ref| ≤ 2/π · V_dc ≈ 0.6366 · V_dc`):**
   При подальшому зростанні завдання вектор на певний кутовий час «залипає» у вершинах гексагона (стан чистого активного вектора). На максимальній межі кут утримання розширюється на всі 60°, і модулятор переходить у класичний шестикроковий режим комутації (*Six-Step mode*).

Гранична амплітуда першої гармоніки у шестикроковому режимі розраховується через розклад прямокутного меандру:

```
V_fundamental_six_step = (2 / π) · V_dc ≈ 0.63662 · V_dc
```

Максимальний теоретичний коефіцієнт використання напруги становить:

```
(2 / π) / (1 / 2) = 4 / π ≈ 1.2732  (+27.32 % відносно SPWM)
```

## 8. Комутаційні втрати: 7-сегментний патерн проти дисконтинуальної модуляції (DPWM)

Енергетичні втрати в силовому інверторі поділяються на дві основні складові: статичні втрати провідності у відкритому каналі транзистора `P_cond = I_rms² · R_ds(on)` та динамічні комутаційні втрати при кожному перемиканні `P_sw = f_sw · (E_on + E_off)`.

У класичному симетричному 7-сегментному патерні (`V₀ → V_a → V_b → V₇ → V_b → V_a → V₀`) за один період ШІМ `T_s` кожна з трьох стійок інвертора виконує рівно одне увімкнення та одне вимкнення. Загальна кількість комутацій за період:

```
N_sw_7seg = 6 перемикань за період T_s (по 2 на кожну фазу)
```

Частота комутації кожного окремого ключа точно дорівнює частоті носійної ШІМ: `f_switch = f_sw`.

Для зниження комутаційних втрат у потужних тягових приводах застосовують дисконтинуальні просторово-векторні модуляції (*Discontinuous Space Vector PWM*, DPWM). Їхня математична суть полягає у відмові від симетричного ділення нульового інтервалу між `V₀` та `V₇`. У кожному секторі весь нульовий час віддається лише одному з нульових векторів (наприклад, тільки `V₀` або тільки `V₇`), що утворює 5-сегментний патерн:

```
Патерн DPWM0: V₀ → V_a → V_b → V_a → V₀  (стан V₇ не використовується взагалі)
```

Оскільки одна з фаз протягом усього 60-градусного сектора залишається нерухомо притиснутою до шини живлення або землі, її ключі не перемикаються взагалі. Загальна кількість комутацій за період скорочується на одну третину:

```
N_sw_5seg = 4 перемикання за період T_s
```

Середня частота перемикання транзисторів падає до `f_switch_eff = (2/3) · f_sw`, що безпосередньо знижує динамічні комутаційні втрати на **33.3 %**:

```
P_sw_DPWM = (2/3) · P_sw_7seg
```

Ціною такого зниження є зростання низькочастотних пульсацій струму на малих глибинах модуляції (`m < 0.5`). Тому в сучасних контролерах застосовують гібридний алгоритм: на малих швидкостях та струмах працює плавний 7-сегментний SVPWM, а при високій потужності та швидкості контролер автоматично перемикається на 5-сегментний DPWM.

## 9. Фактор гармонійних втрат у міді обмоток (THD струму)

Високочастотні пульсації напруги ШІМ створюють у фазних обмотках статора пульсації струму `Δi(t)`, які протікають крізь активний опір міді `R_s` і спричиняють додатковий паразитичний нагрів двигуна. Фактор гармонійних втрат у міді (*Harmonic Copper Loss Factor*, `K_h`) визначається інтегралом квадрата відхилення напруги ШІМ від її середнього значення:

```
K_h = (1 / T_s) · ∫ [ (v_an(t) - v_an_fund(t)) / (ω_sw · L_s) ]² dt
```

де `L_s` — еквівалентна індуктивність розсіювання статора, а `ω_sw = 2π · f_sw`.

Завдяки симетричному розташуванню імпульсів відносно центру періоду у 7-сегментному патерні, спектральні компоненти пульсацій групуються біля подвоєної частоти комутації `2 · f_sw`, а гармоніки на основній частоті носійної `f_sw` взаємно компенсуються у міжфазній напрузі. Порівняння фактора гармонійних втрат між класичною SPWM та просторово-векторною ШІМ при глибині модуляції `m = 0.8` дає такі аналітичні значення:

```
K_h_SPWM  ≈ 0.048 · (V_dc / (f_sw · L_s))²
K_h_SVPWM ≈ 0.031 · (V_dc / (f_sw · L_s))²
```

Відношення гармонійних втрат:

```
K_h_SVPWM / K_h_SPWM ≈ 0.031 / 0.048 ≈ 0.645  (-35.5 % паразитного нагріву обмоток)
```

Таким чином, просторово-векторна модуляція одночасно забезпечує три ключові фізичні переваги: збільшення амплітуди напруги на 15.5 %, зниження комутаційних втрат інвертора та зменшення високочастотного нагріву міді двигуна на 35.5 %.
