## Аналітичний вивід згинальних напружень у ніжці зуба за методом балки Льюїса

У класичній моделі Льюїса зуб розглядається як пружний консольний стрижень, жорстко закріплений в основі обода колеса. Припустимо, що повне нормальне навантаження `F_n` передається через вершину зуба під кутом зачеплення `alpha`. Розкладаючи нормальну силу на радіальну складову `F_r = F_n * sin(alpha)` (яка стискає тіло зуба) та колову тангенціальну силу `F_t = F_n * cos(alpha)` (яка створює згинальний момент), та нехтуючи стиском на користь згину, записуємо згинальний момент у небезпечному перерізі: `M = F_t * h`, де `h` — висота прикладання навантаження від основи.

Момент опору прямокутного небезпечного перерізу шириною `b` та товщиною основи `s` дорівнює `W = (b * s^2) / 6`. Відповідно, номінальне напруження згину становить:
```
sigma_b = M / W
        = (6 * F_t * h) / (b * s^2)
        = F_t / (b * m * Y_F)
```
де `m` — нормальний модуль зачеплення, а `Y_F = s^2 / (6 * h * m)` — геометричний коефіцієнт форми зуба, який залежить виключно від числа зубів колеса `z` та коефіцієнта зміщення вихідного контуру `x`. Для врахування високої концентрації напружень у перехідній галтелі западини зуба вводиться поправочний коефіцієнт концентрації `Y_S` (коефіцієнт Келлі), який емпірично залежить від радіуса скруглення фрези `rho_f` та відношення `s / rho_f`.

У практичному конструюванні високонавантажених зубчастих передач особлива увага приділяється технологічному забезпеченню чистоти робочих поверхонь. Фінішне зубошліфування або хонінгування дозволяє досягти шорсткості Ra ≤ 0,4...0,8 мкм, що в поєднанні з оптимізованими мастильними матеріалами з протизадирними присадками EP (Extreme Pressure) істотно знижує коефіцієнт тертя в контакті до f = 0,03...0,05. Це мінімізує теплове напруження зачеплення, усуває мікрозварювання нерівностей та підвищує сумарний ресурс передачі за критерієм контактної витривалості щонайменше вдвічі.

## Розрахунок контактних напружень Герца в полюсі евольвентного зачеплення

Контакт зубів циліндричної прямозубої передачі моделюється як пружний дотик двох паралельних циліндрів із миттєвими радіусами кривизни `rho_1` та `rho_2` в точці контакту. У полюсі зачеплення ці радіуси визначаються геометричними параметрами ділильних коліс: `rho_1 = (d_1 * sin(alpha)) / 2` та `rho_2 = (d_2 * sin(alpha)) / 2`. Приведений радіус кривизни становить `1 / rho_red = 1 / rho_1 + 1 / rho_2`. За класичною формулою Герца максимальне контактне напруження в центрі площадки контакту шириною `2 * a` дорівнює:
```
sigma_H = sqrt((F_n * E_red) / (pi * b * rho_red))
```
де `E_red` — приведений модуль поздовжньої пружності контактуючих тіл, що обчислюється через модулі Юнга `E_1, E_2` та коефіцієнти Пуассона `nu_1, nu_2`:
```
1 / E_red = (1 - nu_1^2) / (2 * E_1) + (1 - nu_2^2) / (2 * E_2)
```
Виражаючи нормальну силу через колову силу `F_t` як `F_n = F_t / cos(alpha)`, стандартна формула Герца набуває вигляду:
```
sigma_H = Z_H * Z_E * sqrt((F_t * (u + 1)) / (d_1 * b * u))
```
де `Z_H` — коефіцієнт зони контакту, `Z_E` — коефіцієнт пружності матеріалів пари, `u = d_2 / d_1` — передавальне число, а `d_1` — ділильний діаметр шестерні.

## Динамічні фактори навантаження та критерії запасу втомної витривалості

У реальних зубчастих передачах роботизованих приводів фактичні діючі напруження істотно перевищують теоретичні номінальні значення через похибки кроку профілю, пружні деформації валів та ударні явища при вході зуба в зачеплення. Для врахування цих ефектів стандартні формули розрахунку згину `sigma_F` та контакту `sigma_H` доповнюються системою безрозмірних коефіцієнтів навантаження:
```
sigma_F = (F_t / (b * m)) * Y_F * Y_S * Y_beta * K_A * K_v * K_Fbeta * K_Falpha
sigma_H = Z_H * Z_E * Z_epsilon * Z_beta * sqrt((F_t / (d_1 * b)) * ((u + 1) / u) * K_A * K_v * K_Hbeta * K_Halpha)
```
де `K_A` — коефіцієнт зовнішнього динамічного навантаження, `K_v` — внутрішній динамічний коефіцієнт зачеплення, `K_Hbeta, K_Fbeta` — коефіцієнти нерівномірності розподілу навантаження по ширині вінця через перекіс осей підшипників, а `K_Halpha, K_Falpha` — фактори розподілу навантаження між одночасно зачепленими парами зубів.

Розрахункові коефіцієнти безпеки за втомною міцністю зубів визначаються як відношення граничних допустимих напружень матеріалу до розрахункових еквівалентних напружень:
```
S_F = sigma_FP / sigma_F >= S_F_min [типово 1.4...1.6]
S_H = sigma_HP / sigma_H >= S_H_min [типово 1.1...1.3]
```
де `sigma_FP` — границя згинальної витривалості зуба, а `sigma_HP` — границя контактної витривалості поверхні при базовому числі циклів навантаження `N_L0` (для сталей `N_L0 ≈ 5 * 10^7` циклів). Якщо умова запасу не виконується, конструктор зобов'язаний скоригувати геометрію вінця: збільшити ширину вінця `b`, модуль `m` або ввести висотну й кутову корекцію зачеплення.
