## Архітектура параметричного калькулятора та визначення геометрії зубчастої пари і спектра навантажень

Розрахунок тривалої міцності та втомної довговічності зубчастих передач є ключовим етапом проєктування високонавантажених роботизованих приводів. Стандарт ISO 6336 регламентує інженерну методику розрахунку тривалої витривалості сталевих зубчастих коліс із зовнішнім і внутрішнім зачепленням, враховуючи як контактну міцність робочих поверхонь (пітинг), так і згинальну витривалість ніжки зуба (втомний злам).

Архітектура розробленого модуля калькулятора мовою Python базується на розділенні геометричного, кінематичного та міцнісного аналізу. На першому етапі датаклас `GearPairParams` агрегує фундаментальні параметри зубчастої пари: нормальний модуль `m_n`, кількість зубів шестерні `z1` та колеса `z2`, ширину вінця `b`, кут нахилу зубів `beta` та кут профілю `alpha_n`.

Модуль автоматично розраховує основні геометричні характеристики зачеплення:
- Ділильні діаметри: `d_1 = (m_n · z_1) / cos(beta)`, `d_2 = (m_n · z_2) / cos(beta)`.
- Міжосьову відстань: `a_w = (d_1 + d_2) / 2`.
- Тангенціальну колову силу на ділильному колі: `F_t = 2000 · T_1 / d_1`.

Ці параметри слугують базисом для визначення питомого колового навантаження `w_t = F_t / b` та подальшого розрахунку напруженого стану контактних поверхонь.

У практичному конструюванні високонавантажених зубчастих передач особлива увага приділяється технологічному забезпеченню чистоти робочих поверхонь. Фінішне зубошліфування або хонінгування дозволяє досягти шорсткості Ra <= 0,4...0,8 мкм, що в поєднанні з оптимізованими мастильними матеріалами з протизадирними присадками EP (Extreme Pressure) істотно знижує коефіцієнт тертя в контакті до f = 0,03...0,05. Це мінімізує теплове напруження зачеплення, усуває мікрозварювання нерівностей та підвищує сумарний ресурс передачі за критерієм контактної витривалості щонайменше вдвічі.

## Алгоритм розрахунку контактних і згинальних напружень та коефіцієнтів безпеки S_H і S_F за стандартом ISO 6336

Другий етап алгоритму реалізує математичний апарат стандарту ISO 6336 (Method B). Розрахунок контактних напружень Герца базується на визначенні номінального напруження `sigma_H0` у зоні полюса зачеплення:

```
sigma_H0 = Z_H · Z_E · Z_eps · Z_beta · sqrt((F_t / (b · d_1)) · ((u + 1) / u))
```

де `Z_H` — коефіцієнт форми зуба, `Z_E = 189,8 МПа^0,5` — коефіцієнт пружності матеріалу спряжених сталевих коліс, а `Z_eps` — коефіцієнт торцевого перекриття. Розрахункове контактне напруження коригується динамічними коефіцієнтами навантаження `K_A`, `K_v` та коефіцієнтами концентрації `K_Hbeta`, `K_Halpha`:

```
sigma_H = sigma_H0 · sqrt(K_A · K_v · K_Hbeta · K_Halpha)
```

Згинальне напруження в небезпечному перерізі ніжки зуба розраховується за уточненою формулою балочної моделі Льюїса:

```
sigma_F = (F_t / (b · m_n)) · Y_F · Y_S · Y_beta · K_A · K_v · K_Fbeta
```

де `Y_F` — теоретичний коефіцієнт форми зуба, `Y_S` — фактор концентрації напружень біля перехідної галтелі ніжки.

На завершення калькулятор обчислює коефіцієнти запасу безпеки `S_H = sigma_Hlim / sigma_H` та `S_F = sigma_FE / sigma_F`. Якщо `S_H >= 1,2` та `S_F >= 1,4`, передача гарантовано витримує базовий ресурс у 10^7 циклів навантаження без появи втомного викришування та тріщин зламу.

## Моделювання накопичення втомних пошкоджень за правилом Пальмгрена-Майнера та оцінка залишкового ресурсу шестерень

В реальних умовах експлуатації промислових роботів-маніпуляторів зубчасті редуктори працюють при змінному спектрі крутних моментів: від тривалого холостого переміщення з малим моментом до короткочасних пікових ударних навантажень під час екстреного гальмування з вантажем. Для адекватного прогнозування ресурсу калькулятор реалізує лінійну гіпотезу накопичення втомних пошкоджень Пальмгрена-Майнера (Palmgren-Miner Rule).

Спектр навантаження дискретизується на `k` режимів із моментами `T_i` та кількістю циклів `n_i`. Відповідно до кривої втомної витривалості Веллера (S-N curve) для кожного режиму розраховується критична кількість циклів до руйнування `N_i`:

```
N_i = N_base · (sigma_Hlim / sigma_H,i)^m
```

де `m = 6` для контактних напружень Герца та `m = 9` для напружень згину в ніжці зуба. Сумарне накопичене пошкодження `D` визначається сумою відносних часток:

```
D = sum(n_i / N_i)
```

Критерієм завершення ресурсу та виникнення втомного пітингу є досягнення умови `D >= 1,0`. Якщо сумарне пошкодження `D = 0,42` за 5000 годин роботи за типовим циклом зварювання, то розрахунковий залишковий ресурс передачі становить `(1 - D) / (D / 5000) = 6900` мотогодин. Калькулятор генерує гістограму внеску кожного технологічного режиму у загальне зношування, що дозволяє інженерам оптимізувати траєкторії руху робота для продовження терміну служби редуктора.

У практичному конструюванні високонавантажених зубчастих передач особлива увага приділяється технологічному забезпеченню чистоти робочих поверхонь.
