# ⚙️ Модуль розрахунку RC-снубера та вхідного EMI-фільтра імпульсного перетворювача

Цей програмний модуль призначений для точного аналітичного розрахунку параметрів демпфування комутаційного вузла (RC-снуберів) та оптимізації багатоланкових вхідних фільтрів електромагнітних завад (EMI-фільтрів) імпульсних DC-DC перетворювачів напруги. На відміну від емпіричного підбору компонентів наосліп, модуль базується на двочастотному методі вимірювання паразитного резонансу плати, формулах характеристичного хвильового імпедансу контуру та строгому математичному задоволенні критерію стійкості Міддлбрука для запобігання автоколиванням перетворювача.

У реальній інженерній практиці проектування друкованих плат аналітичний розрахунок за даташитом рідко дає точний результат через невідому заздалегідь паразитну індуктивність монтажу `L_par`, яка складається з індуктивності внутрішніх дротяних розварок мікросхеми, виводів корпусу (QFN, SOIC, DPAK), перехідних отворів та мідних полігонів. Даний модуль реалізує повний інженерний цикл: від обробки первинних даних лабораторного осцилографа до підбору найближчих стандартних номіналів компонентів з рядів E24/E96 з розрахунком теплового розсіювання резисторів та запасу фазової стійкості.

---

### Фізична природа паразитного дзвону та обмеження аналітичних моделей

При проектуванні імпульсних перетворювачів напруги початковий розрахунок часто зводять до вибору силової котушки індуктивності та вхідних і вихідних конденсаторів за формулами збереження заряду та допустимого коефіцієнта пульсацій струму. Проте реальний комутаційний вузол друкованої плати являє собою розподілену електродинамічну систему, де будь-який провідник має паразитну індуктивність, а будь-яка пара провідників на різних потенціалах — паразитну ємність.

Коли силовий транзистор перемикається, напівпровідниковий канал змінює свій опір від сотень кілоомів до одиниць міліомів за час від 0.5 до 5 наносекунд. У цей момент струм у контурі миттєво перенаправляється, що викликає появу екстремально високих значень похідної напруги `dV/dt` (до 10–50 В/нс) та струму `dI/dt` (до 2–10 А/нс).

Спроба розрахувати частоту виникаючого резонансу виключно за паспортними даними компонентів (Datasheet) зазвичай призводить до помилки у 2–4 рази з трьох фізичних причин:
1. **Нелінійність вихідної ємності напівпровідникового ключа `C_oss`:** Виробники вказують значення вихідної ємності польового транзистора при фіксованій постійній напрузі сток-витік (наприклад, при `V_DS = 25 В` або `V_DS = 0.5 · V_max`). Проте під час перехідного процесу напруга на стоці змінюється від 0 В до повної напруги живлення, при цьому реальна ємність p-n переходів кристала змінюється на порядок (від 1000 пФ поблизу нуля до 80 пФ при максимальній напрузі);
2. **Розподілена паразитна індуктивність плати `L_par`:** Паразитна індуктивність формується не тільки внутрішніми провідниками мікросхеми, але й геометрією струмової петлі на платі. Кожен міліметр доріжки шириною 0.5 мм додає приблизно 0.8–1.0 нГн індуктивності, а пара перехідних отворів між шарами — ще 1.0–2.0 нГн. Точна конфігурація зворотного струму в шарах землі залежить від товщини діелектрика та наявності розривів у мідних полігонах;
3. **Частотна дисперсія пасивних компонентів:** Керамічні конденсатори вхідного контуру на частотах понад 50 МГц уже проходять власну резонансну частоту (SRF) і починають вести себе як індуктивності, що збільшує ефективну індуктивність гарячої петлі.

Саме тому єдиним достовірним методом визначення параметрів паразитного контуру є пряме вимірювання на працюючому фізичному прототипі за допомогою двочастотного резонансного методу.

### Математична модель двочастотного методу вимірювання резонансу

Коливальний процес на комутаційному вузлі SW описується еквівалентним послідовним коливальним контуром, складеним із паразитної індуктивності `L_par` та паразитної ємності `C_par`.

Початкова частота спостережуваного високочастотного дзвону `f_1` описується класичною формулою Томсона:

```
f_1 = 1 / (2 · π · √(L_par · C_par))  [початкова резонансна частота дзвону]
```

Оскільки ні паразитну індуктивність `L_par`, ні паразитну ємність `C_par` неможливо виміряти окремо безпосередньо на платі за допомогою стандартних вимірювальних приладів, розробник застосовує метод доданої каліброваної ємності:

1. За допомогою високочастотного цифрового осцилографа з коаксіальним адаптером (або пружинним контактом типу Spring Tip) вимірюють точний період осциляцій `T_1` і визначають початкову частоту `f_1 = 1 / T_1`;
2. Безпосередньо паралельно виводам сток-витік нижнього транзистора (або між вузлом SW та опорною силовою землею GND) припаюють високочастотний керамічний конденсатор `C_test` класу C0G/NP0 з мінімальною довжиною виводів. Номінал `C_test` обирають приблизно рівним очікуваній ємності контуру (зазвичай від 100 до 500 пФ);
3. Повторно вмикають перетворювач та вимірюють нову, зменшену частоту дзвону `f_2`.

Оскільки додана ємність підключена паралельно до власної ємності схеми `C_par`, нова резонансна частота визначається виразом:

```
f_2 = 1 / (2 · π · √(L_par · (C_par + C_test)))  [зміщена резонансна частота]
```

Поділивши початкову частоту `f_1` на зміщену частоту `f_2`, отримуємо співвідношення:

```
f_1 / f_2 = √((C_par + C_test) / C_par) = √(1 + C_test / C_par)
```

Піднісши обидві частини рівності до квадрата:

```
(f_1 / f_2)² = 1 + (C_test / C_par)
```

Звідси отримуємо точну аналітичну формулу для розрахунку власної паразитної ємності комутаційного вузла:

```
C_par = C_test / ((f_1 / f_2)² - 1)  [власна паразитна ємність монтажу]
```

Знаючи точну величину паразитної ємності `C_par`, власну паразитну індуктивність гарячої петлі комутації вираховують із вихідного рівняння частоти резонансу `f_1`:

```
L_par = 1 / ((2 · π · f_1)² · C_par)  [власна паразитна індуктивність контуру]
```

Характеристичний (хвильовий) імпеданс паразитного контуру `Z_0` визначає масштаб активного опору, необхідного для розсіювання накопиченої в індуктивності електромагнітної енергії:

```
Z_0 = √(L_par / C_par)  [характеристичний опір паразитного контуру]
```

### Теорія перехідних процесів та аналіз демпфування контуру (RLC Transient Analysis)

Підключення RC-демпфера перетворює недемпфований коливальний контур на керовану дисипативну динамічну систему. Розглянемо диференціальне рівняння другого порядку, що описує зміну напруги на комутаційному вузлі після перемикання транзистора:

```
L_par · (d²v / dt²) + R_total · (dv / dt) + (1 / C_total) · v = 0
```

де `R_total` — сумарний активний опір демпфування, а `C_total` — еквівалентна ємність вузла.

Характеристичне рівняння системи має вигляд:

```
s² + 2 · α · s + ω_0² = 0
```

де коефіцієнт затухання `α` та власна кутова частота `ω_0` визначаються виразами:

```
α = R_total / (2 · L_par)
ω_0 = 1 / √(L_par · C_total)
```

Безрозмірний коефіцієнт демпфування системи `ζ` (Damping Ratio) дорівнює:

```
ζ = α / ω_0 = (R_total / 2) · √(C_total / L_par)
```

Залежно від величини `ζ` перехідний процес комутації розвивається за одним із трьох сценаріїв:

1. **Недодемпфований режим (Underdamped, `ζ < 1.0`):** Корені характеристичного рівняння є комплексно-спряженими `s_{1,2} = -α ± j·ω_d`, де `ω_d = ω_0 · √(1 - ζ²)`. Напруга на комутаційному вузлі здійснює високочастотні коливання, а максимальний сплеск перенапруги (Overshoot) описується виразом:
   ```
   V_peak = V_in · (1 + exp(- π · ζ / √(1 - ζ²)))
   ```
   При типовому недемпфованому контурі друкованої плати коефіцієнт демпфування становить всього `ζ ≈ 0.05–0.1`, через що пікова перенапруга сягає `1.8–1.95 · V_in`, створюючи пряму загрозу електричного пробою транзистора та генеруючи потужне радіовипромінювання;
2. **Критично демпфований режим (Critically Damped, `ζ = 1.0`):** Характеристичне рівняння має один дійсний кратний корінь `s_1 = s_2 = -α`. У цьому режимі напруга максимально швидко виходить на усталене значення без виникнення жодного періоду коливань та без перерегулювання;
3. **Передемпфований режим (Overdamped, `ζ > 1.0`):** Корені дійсні та різні. Система не коливається, проте швидкість наростання напруги суттєво сповільнюється, що призводить до збільшення тривалості перехідного процесу та невиправданого зростання динамічних теплових втрат на силових транзисторах.

У реальній схемі RC-снубера конденсатор `C_snub` підключений послідовно з резистором `R_snub`, що утворює динамічну систему третього порядку. Вибір опору резистора `R_snub = Z_0` забезпечує коефіцієнт демпфування `ζ ≈ 0.707–1.0` на основній частоті резонансу, що гарантує зниження амплітуди дзвону на 20–30 дБ без затягування робочих фронтів перемикання.

### Порівняльний аналіз топологій демпфування комутаційних вузлів

Залежно від топології перетворювача та рівня робочої напруги застосовують різні схемотехнічні конфігурації демпферів:

#### 1. Простий послідовний RC-снубер (Simple RC Snubber)

Встановлюється паралельно нижньому транзистору або між вузлом SW та опорною землею GND.

- **Переваги:** Мінімальна кількість компонентів (всього один резистор та один конденсатор), ефективне двонаправлене демпфування як у момент відкривання, так і в момент закривання транзистора, повна симетрія;
- **Недоліки:** Постійне розсіювання енергії щоперіоду `P = C_snub · V_in² · f_sw`. При напругах живлення понад 48 В та частотах комутації вище 1 МГц потужність втрат може сягати 0.5–2 Вт, що погіршує ККД перетворювача на 1–3%;
- **Сфера застосування:** Неізольовані Buck, Boost, Buck-Boost стабілізатори з напругою живлення до 48 В.

#### 2. RCD-клампер фіксації напруги (RCD Clamp Snubber)

Застосовується у перетворювачах з індуктивною розв'язкою (Flyback, Forward) для обмеження високовольтного викиду від індуктивності розсіювання трансформатора `L_leak`.

Схема складається з надшвидкого діода `D_clamp`, накопичувального конденсатора відносно великої ємності `C_clamp` (у 10–50 разів більшої за `C_oss`) та паралельного розрядного резистора `R_clamp`.

- **Фізика роботи:** У момент вимкнення первинного транзистора струм індуктивності розсіювання відкриває діод `D_clamp` і заряджає конденсатор `C_clamp`. Після закривання діода накопичена енергія повільно розсіюється на резисторі `R_clamp` протягом усього періоду комутації;
- **Розрахунок напруги фіксації:**
  ```
  V_clamp = V_in + N · V_out + ΔV_margin
  ```
- **Розрахунок резистора клампера:**
  ```
  R_clamp = (2 · V_clamp · (V_clamp - N · V_out)) / (L_leak · I_pk² · f_sw)
  ```
- **Сфера застосування:** Мережеві AC-DC блоки живлення, ізольовані DC-DC конвертери потужністю від 10 до 200 Вт.

#### 3. Активний клампер (Active Clamp)

Замість пасивного резистора використовується додатковий малопотужний польовий транзистор з керуванням від основного ШІМ-контролера. Енергія індуктивності розсіювання не перетворюється на тепло, а повертається назад у первинне джерело живлення або передається у навантаження через режим м'якої комутації (Zero Voltage Switching, ZVS). Активні клампери забезпечують максимальний ККД (до 96–98%), проте вимагають складних спеціалізованих контролерів керування затворами.

### Фізика діелектричних та магнітних втрат на високих частотах

При роботі снуберних ланцюгів та вхідних фільтрів на високих частотах (від 100 кГц до 500 МГц) тепловий баланс визначається не тільки активним опором за постійним струмом, але й специфічними механізмами високочастотних втрат у діелектриках та феромагнітних осердях.

#### 1. Діелектричні втрати в керамічних конденсаторах снубера

Коли керамічний конденсатор снубера багаторазово перезаряджається струмами високої крутості, змінне електричне поле викликає циклічну поляризацію та деполяризацію діелектрика. Втрати енергії на одне переполяризування описуються тангенсом кута діелектричних втрат `tan δ`:

```
tan δ = ESR · 2 · π · f · C  [тангенс кута діелектричних втрат]
```

Потужність діелектричних втрат, яка безпосередньо розсіюється всередині тіла конденсатора, становить:

```
P_diel = 2 · π · f · C · V_rms² · tan δ
```

Для керамічних конденсаторів класу II (X7R, X5R, Y5V) величина `tan δ` становить від 0.015 до 0.050 (1.5–5.0%). При напрузі 24 В та частоті дзвону 150 МГц це призводить до виділення у крихітному корпусі 0603 понад 0.5–1.0 Вт теплової енергії, що викликає локальне нагрівання кераміки понад +150°C, розтріскування кристала від внутрішніх механічних напружень та катастрофічний короткозамкнений пробій.

Натомість конденсатори класу I (C0G/NP0) на основі діоксиду титану та титанатів рідкісноземельних металів мають тангенс втрат `tan δ < 0.0005` (менше 0.05%), що знижує внутрішнє діелектричне самонагрівання у 100 разів, забезпечуючи стабільну багаторічну роботу приладу.

#### 2. Магнітні втрати в осердях дроселів вхідного фільтра (Core Losses)

Втрати у феритовому осерді дроселя вхідного фільтра складаються з двох компонентів: втрат на динамічний гістерезис при перемагнічуванні та втрат на вихрові струми Фуко всередині об'єму матеріалу.

Згідно з узагальненою емпіричною формулою Штейнмеца (Steinmetz Equation), об'ємна щільність магнітних втрат `P_core` (Вт/м³) описується виразом:

```
P_core = k · f^α · B_max^β  [формула втрат Штейнмеца]
```

де `k`, `α` (типово 1.2–1.8), `β` (типово 2.0–2.6) — матеріальні константи феромагнетика, а `B_max` — пікова магнітна індукція змінної складової.

Вибір матеріалу магнітопроводу визначає смугу ефективної роботи фільтра:
- **Марганець-цинкові ферити (MnZn, `μ_r = 2000–10000`):** Мають високу початкову проникність та високу індукцію насичення, проте їхній питомий електричний опір відносно низький (`ρ ≈ 0.1–10 Ом·м`). На частотах понад 2–5 МГц у масиві MnZn-фериту виникають потужні вихрові струми, що різко збільшує втрати та зменшує проникність. MnZn-матеріали застосовують виключно для синфазних дроселів у низькочастотній області (до 3–5 МГц);
- **Нікель-цинкові ферити (NiZn, `μ_r = 100–1500`):** Володіють колосальним питомим електричним опором (`ρ ≈ 10⁵–10⁷ Ом·м`), завдяки чому вихрові струми не виникають навіть на частотах до 100–300 МГц. NiZn-ферити є безальтернативною основою для високочастотних диференційних дроселів та феритових фільтрувальних намистин;
- **Порошкові композитні метали (Sendust / Kool Mμ, Iron Powder, MPP):** Виготовляються пресуванням мікроскопічних частинок залізо-кремній-алюмінієвого сплаву, ізольованих діелектричним лаком. Мають розподілений повітряний зазор (Distributed Air Gap) та високу індукцію насичення (`B_sat = 1.0–1.6 Тл`), що виключає різке насичення дроселя при пікових пускових струмах DC-DC перетворювача.

### Взаємна індуктивність та магнітна розв'язка індуктивних компонентів

Поширеною помилкою інженерів є розміщення вхідного фільтрувального дроселя `L_f` поруч із силовою котушкою перетворювача `L_main` на верхньому шарі плати без дотримання правил просторової орієнтації.

Дві котушки індуктивності, розташовані на відстані `d`, утворюють систему зі взаємною індуктивністю `M`:

```
M = k_mag · √(L_f · L_main)  [коефіцієнт взаємної індуктивності]
```

Змінне магнітне поле силової котушки, викликане перемиканням струмів перетворювача, пронизує витки вхідного дроселя фільтра і наводить у ньому паразитну ЕРС згідно із законом електромагнітної індукції Фарадея:

```
V_crosstalk = - M · (dI_main / dt)
```

Ця паразитна наведена напруга потрапляє безпосередньо у вхідні лінії живлення в обхід усіх вхідних конденсаторів `C_1` та `C_2` (явище магнітного шунтування фільтра, Magnetic Crosstalk). У результаті навіть ідеально розрахований фільтр з теоретичним затуханням 40 дБ на практиці забезпечує придушення завад всього на 10–15 дБ.

Правила запобігання магнітному зв'язку:
1. **Ортогональна просторова орієнтація:** Осі намотки дроселя фільтра та силової котушки повинні бути розташовані під кутом строго 90° одна до одної. При ортогональному розміщенні магнітний потік першої котушки проходить паралельно площині витків другої котушки, що зводить коефіцієнт магнітного зв'язку `k_mag` практично до нуля;
2. **Правило трикратної відстані:** Фізична відстань між корпусами двох неекранованих або напівекранованих індуктивностей повинна бути не меншою за потрійну висоту найбільшого корпусу (`d ≥ 3 · h_max`);
3. **Екрануючий земляний бар'єр:** Між котушками на всіх внутрішніх шарах плати формують суцільний земляний полігон із ланцюжком перехідних отворів, у якому вихрові струми створюють протиполе, що екранує магнітний потік.

### Трасування кіл живлення за принципом Кельвіна (Kelvin Through-Pad Routing)

Ефективність будь-якого розрахунку фільтрації може бути зведена до нуля некоректним підведенням друкованих провідників до контактних майданчиків конденсаторів.

Якщо провідник живлення прокладено повз конденсатор, а сам конденсатор під'єднано за допомогою короткого відгалуження (відростка / Stub trace) довжиною всього 2–3 мм:

```
 Помилкове трасування (Stub):           Правильне трасування (Through-Pad / Kelvin):
   V_IN ──────────────────────► До DC-DC      V_IN ──────┐      ┌──────► До DC-DC
             │ (L_stub = 2..3 нГн!)                      │      │
            === C_in                                    === C_in
             │                                           │
            GND                                         GND
```

Паразитна індуктивність відростка `L_stub ≈ 2–3 нГн` включається строго послідовно з конденсатором `C_in`. На частоті 100 МГц опір цієї індуктивності становить `X_L = 2π · 100 · 10⁶ · 2.5 · 10⁻⁹ ≈ 1.57 Ом`, що на два порядки перевищує опір самого конденсатора, повністю блокуючи його здатність фільтрувати високочастотні завади.

При правильному **наскрізному трасуванні (Through-Pad Routing)** провідник живлення входить безпосередньо в один край контактного майданчика SMD-конденсатора, а виходить з протилежного краю того самого майданчика. У такому разі весь високочастотний струм перетворювача фізично змушений пройти крізь виводи конденсатора, що забезпечує максимальну ефективність шунтування без виникнення паразитних послідовних індуктивностей відгалужень.

### Механічна стійкість та захист від розтріскування керамічних конденсаторів

Керамічні конденсатори снуберних ланцюгів та вхідних фільтрів зазнають значних механічних і теплових навантажень. При паянні оплавленням припою та під час термічних циклів експлуатації через різницю коефіцієнтів теплового розширення (CTE) міді, склотекстоліту FR-4 та кераміки в тілі компонента виникають механічні напруження зсуву.

Для запобігання мікротріщинам та короткозамкненому виходу з ладу рекомендується:
1. **Контроль швидкості охолодження плати:** Швидкість охолодження після паяння не повинна перевищувати `2°C/с`, щоб уникнути температурного шоку кераміки;
2. **Застосування конденсаторів із гнучкими термінаціями (Soft Termination / FlexiCap):** У таких конденсаторах між мідним електродом та шаром нікелю додається шар струмопровідного еластичного полімеру, який поглинає механічні вигини друкованої плати величиною до 3–5 мм без пошкодження крихкого внутрішнього керамічного моноліту;
3. **Орієнтація на платі:** Конденсатори типорозмірів 0805, 1206 та 1210 розміщують паралельно лініям можливого вигину друкованої плати (подалі від кріпильних гвинтів та роз'ємів підключення важких кабелів).

### Комплексна теорія вхідної фільтрації та стійкість Міддлбрука

Імпульсний перетворювач напруги генерує потужні диференційні пульсації струму на вході. Для виконання вимог міжнародних стандартів електромагнітної сумісності (CISPR 25 Class 5 для автомобільної електроніки, CISPR 32 Class B для мультимедійного обладнання) застосовують диференційний π-подібний фільтр нижніх частот другого порядку.

Фільтр складається з вхідного керамічного конденсатора `C_1`, силового фільтрувального дроселя `L_f` та вихідного конденсатора фільтра `C_2` (який є безпосереднім вхідним блокувальним конденсатором DC-DC перетворювача).

Необхідне затухання фільтра `A_req` (в децибелах) на частоті комутації `f_sw` розраховується на основі різниці між амплітудою вхідних пульсацій напруги без фільтрації `V_ripple` та нормативною межею стандарту `V_limit` з додаванням інженерного запасу надійності `Margin` (зазвичай 6–10 дБ):

```
A_req = 20 · log10(V_ripple / V_limit) + Margin  [необхідне затухання, дБ]
```

Оскільки LC-фільтр другого порядку забезпечує асимптотичний спад передавальної характеристики зі швидкістю **-40 дБ на декаду** (-12 дБ на октаву) на частотах вище частоти зрізу, необхідна частота зрізу фільтра `f_c` розраховується за формулою:

```
f_c = f_sw · 10^(- A_req / 40)  [частота зрізу вхідного фільтра]
```

Добуток необхідної індуктивності та вихідної ємності фільтра становить:

```
L_f · C_2 = 1 / (2 · π · f_c)²
```

#### Критерій стійкості Міддлбрука (Middlebrook Stability Criterion)

Будь-який імпульсний перетворювач із замкненим контуром зворотного зв'язку за напругою на низьких частотах (у межах смуги пропускання контуру регулювання) підтримує стабільну вихідну потужність навантаження `P_out = V_out · I_out = const`.

Якщо вхідна напруга живлення `V_in` зростає, для збереження постійної вихідної потужності перетворювач автоматично зменшує коефіцієнт заповнення `D` і споживає менший вхідний струм `I_in`. Навпаки, при просіданні вхідної напруги споживаний струм зростає:

```
P_in = V_in · I_in = P_out / η = const  ==>  I_in = P_out / (η · V_in)
```

Диференціюючи вираз струму за вхідною напругою, отримуємо диференційну провідність:

```
dI_in / dV_in = - P_out / (η · V_in²) < 0
```

Це означає, що імпульсний стабілізатор володіє **негативним динамічним вхідним опором**:

```
R_in_conv = - (V_in_min² · η) / P_out  [негативний вхідний опір DC-DC]
```

де `V_in_min` — мінімальна робоча напруга джерела живлення, `η` — коефіцієнт корисної дії регулятора, `P_out` — максимальна вихідна потужність.

Недемпфований вхідний LC-фільтр на своїй резонансній частоті `f_c` має добротний пік вихідного імпедансу `Z_out_filter`:

```
Z_out_peak = Q · √(L_f / C_2) = (1 / R_esr) · (L_f / C_2)
```

де `R_esr` — паразитичний активний опір втрат конденсатора та дроселя.

Якщо вихідний опір вхідного фільтра `Z_out_peak` наближається до модуля динамічного вхідного опору перетворювача `|R_in_conv|`, система втрачає фазовий запас стійкості. Виникає позитивний зворотний зв'язок за напругою, що перетворює стабілізатор на генератор низькочастотних автоколивань. Напруга на вході мікросхеми починає хаотично коливатися з великою амплітудою, що призводить до спрацьовування захисту за напругою, зриву стабілізації та можливого теплового руйнування компонентів.

Згідно з критерієм Міддлбрука, система «вхідний фільтр — DC-DC перетворювач» залишається безумовно стійкою за будь-яких перехідних процесів, якщо вихідний комплексний імпеданс фільтра значно менший за модуль динамічного вхідного опору перетворювача в усьому діапазоні частот:

```
|Z_out_filter(f)| << |R_in_conv|  [умова стійкості Міддлбрука]
```

Для гарантованої стійкості розробники застосовують інженерне правило запасу: максимальний вихідний імпеданс демпфованого фільтра `Z_out_max` повинен бути принаймні утричі меншим за `|R_in_conv|`:

```
Z_out_max ≤ 0.33 · |R_in_conv|  (Stability Margin ≥ 3.0)
```

#### Розрахунок паралельного RC-демпфування за методом Еріксона

Для придушення добротного резонансного піку паралельно керамічному конденсатору `C_2` підключають демпфувальну гілку, що складається з послідовно з'єднаних конденсатора `C_d` та резистора `R_d`.

Конденсатор `C_d` блокує протікання постійного струму через резистор `R_d`, усуваючи статичні втрати потужності, а резистор `R_d` вносить активне згасання в контур на частоті резонансу.

Оптимальний розрахунок параметрів демпфування:

1. **Коефіцієнт співвідношення ємностей `n`:**
   ```
   n = C_d / C_2
   ```
   Оптимальним компромісом між габаритами конденсатора та ступенем демпфування є значення `n = 4.0` (допустимий діапазон від 3.0 до 5.0). Ємність демпфувального конденсатора обирають рівною:
   ```
   C_d = n · C_2 = 4 · C_2
   ```
2. **Оптимальний демпфувальний опір `R_d`:**
   Для мінімізації максимального значення вихідного імпедансу фільтра опір `R_d` розраховують за аналітичною формулою:
   ```
   R_d = √(L_f / C_2) · √((2 + n) · (4 + 3·n) / (2 · n² · (4 + n)))
   ```
   Для значення `n = 4.0` підкореневий множник дорівнює `√((6 · 16) / (2 · 16 · 8)) = √(96 / 256) ≈ 0.6124`. Таким чином:
   ```
   R_d ≈ 0.6124 · √(L_f / C_2)
   ```
3. **Максимальний вихідний імпеданс демпфованого фільтра `Z_out_max`:**
   При встановленні розрахованих номіналів `C_d` та `R_d` піковий вихідний опір фільтра фіксується на рівні:
   ```
   Z_out_max = √(L_f / C_2) · (√(2 · (2 + n)) / n)
   ```
   Для `n = 4.0` множник дорівнює `√(2 · 6) / 4 = √12 / 4 ≈ 0.866`. Тобто:
   ```
   Z_out_max ≈ 0.866 · √(L_f / C_2)
   ```

Якщо розраховане значення `Z_out_max` задовольняє умову `Z_out_max ≤ 0.33 · |R_in_conv|`, фільтр забезпечує максимальну ефективність фільтрації завад без найменшого ризику втрати стійкості перетворювача.

### Моделювання багатоланкових фільтрів у просторі матриць передачі (ABCD-Parameters)

При проектуванні складних комбінованих систем фільтрації, що включають синфазний дросель, кілька послідовних π-ланок та кабельні лінії зв'язку, класичні методи розрахунку окремих LC-контурів втрачають точність через взаємний вплив каскадів.

У таких випадках застосовують матричний апарат **ABCD-параметрів (ланцюгових матриць передачі)** для лінійних чотириполюсників:

```
[ V_in ]   [ A  B ]   [ V_out ]
[      ] = [      ] · [       ]
[ I_in ]   [ C  D ]   [ I_out ]
```

Кожен елемент фільтра описується елементарною матрицею другого порядку в операторній формі Лапласа `s = j·ω`:
- **Послідовна індуктивність або опір `Z(s)`:**
  ```
  M_series = [ 1   Z(s) ]
             [ 0    1   ]
  ```
- **Паралельна ємність або демпфувальна гілка `Y(s)`:**
  ```
  M_shunt  = [ 1    0   ]
             [ Y(s) 1   ]
  ```
  де провідність паралельної RC-гілки демпфування Міддлбрука описується виразом `Y_d(s) = (s · C_d) / (1 + s · R_d · C_d)`.

Результуюча матриця передачі всього фільтра розраховується прямим послідовним перемноженням матриць усіх його ланок:

```
M_total = M_C1 · M_L · M_CdRd · M_C2 = [ A_tot  B_tot ]
                                       [ C_tot  D_tot ]
```

Знаючи елементи сумарної матриці, коефіцієнт передачі напруги під навантаженням `Z_L` з урахуванням внутрішнього імпедансу джерела `Z_S` вираховується аналітично:

```
T(s) = V_out(s) / V_source(s) = Z_L / (A_tot · Z_L + B_tot + C_tot · Z_S · Z_L + D_tot · Z_S)
```

Матричний підхід дозволяє за лічені мікросекунди розрахувати точну амплітудно-частотну (АЧХ) та фазо-частотну (ФЧХ) характеристики фільтра з урахуванням індуктивності довгих дротів живлення та температурної деградації компонентів.

### Температурний дрейф, старіння та вибір технології конденсаторів

Надійність роботи вхідного фільтра та збереження фазового запасу стійкості Міддлбрука суттєво залежать від стабільності параметрів конденсаторів у діапазоні робочих температур від -40°C до +105°C:

1. **Алюмінієві електролітичні конденсатори з рідким електролітом:**
   - *Низькотемпературна поведінка:* При температурі -40°C в'язкість рідкого електроліту зростає, а його іонна провідність падає, через що еквівалентний послідовний опір `ESR` зростає у **10–40 разів**. Це призводить до того, що демпфувальний опір `R_d` виявляється занадто великим, демпфування втрачає ефективність, і на морозі перетворювач раптово починає генерувати автоколивання;
   - *Високотемпературна деградація:* При постійній роботі за температури +85–105°C рідкий електроліт поступово випаровується крізь гумове ущільнення. Термін служби скорочується вдвічі на кожні 10°C підвищення температури (закон Арреніуса);
2. **Полімерні алюмінієві та танталові конденсатори (Conductive Polymer):**
   - Замість рідкого електроліту використовується твердий струмопровідний полімер (PEDOT:PSS). Вони мають стабільний опір `ESR` у всьому діапазоні від -55°C до +125°C без температурних стрибків та вкрай високий допустимий змінний струм пульсацій (Ripple Current);
3. **Гібридні алюмінієві конденсатори (Polymer Hybrid):**
   - Поєднують твердий полімер та рідкий електроліт. Володіють самовідновленням діелектрика, стабільним `ESR` на холоді та гарантованим терміном служби понад 4000–10000 годин при +125°C, що робить їх ідеальним вибором для демпфування фільтрів в автомобільній електроніці.

### Синфазний дросель як елемент диференційної фільтрації

У багатьох сучасних високоефективних джерелах живлення розробники використовують конструктивну неідеальність синфазного дроселя (Common-Mode Choke, CMC) на користь диференційній фільтрації.

Через неповне магнітне зчеплення між двома силовими обмотками на тороїдальному або броньовому осерді (коефіцієнт зв'язку `k ≈ 0.97–0.99`) будь-який синфазний дросель має **індуктивність розсіювання (Stray / Leakage Inductance)**:

```
L_leak_CMC = (1 - k²) · L_CM ≈ (0.01 ... 0.03) · L_CM
```

Ця індуктивність розсіювання веде себе в схемі як послідовний диференційний дросель. Наприклад, якщо синфазний дросель має номінал `L_CM = 1.5 мГн`, його індуктивність розсіювання становить:

```
L_leak = 0.02 · 1.5 мГн = 30 мкГн
```

Ці 30 мкГн індуктивності розсіювання разом із керамічними конденсаторами `C_1` та `C_2` формують повноцінний високоефективний диференційний π-фільтр без необхідності встановлення окремого дискретного дроселя `L_f`, що дозволяє зменшити габарити силового модуля живлення на 30–40% та знизити собівартість друкованої плати.

### Алгоритм апроксимації до промислових рядів номіналів (E12, E24, E96)

Розраховані теоретичні значення ємностей та опорів є довільними дійсними числами (наприклад, `R_snub = 14.37 Ом`, `C_snub = 412.8 пФ`). У серійному виробництві використовуються компоненти стандартних номінальних рядів Ренара (Renard Series), побудованих за геометричною прогресією:

```
X_k = 10^(k / N),  де N — кількість номіналів у декаді (12, 24 або 96)
```

- **Ряд E12 (`N = 12`, допуск ±10%):** Застосовується для вибору великих демпфувальних та фільтрувальних конденсаторів (електролітичних, танталових, полімерних);
- **Ряд E24 (`N = 24`, допуск ±5%):** Основний ряд для снуберних керамічних конденсаторів класу C0G/NP0 та силових резисторів;
- **Ряд E96 (`N = 96`, допуск ±1%):** Прецизійний ряд для точного підбору демпфувальних резисторів Міддлбрука.

Алгоритм апроксимації виконує такі кроки:
1. Відокремлення десяткового порядку `exponent = floor(log10(val))` та нормалізованої мантиси `mantissa = val / 10^exponent`;
2. Логарифмічний або табличний пошук найближчого значення мантиси зі стандартного масиву з мінімізацією абсолютної відносної похибки `|mantissa - standard|`;
3. Контроль переходу через межу декади (якщо знайдена мантиса дорівнює 10.0, базове значення встановлюється в 1.0, а експонента збільшується на 1);
4. Формування кінцевого номіналу `val_std = mantissa_std · 10^exponent`;
5. Контрольний перерахунок усіх результуючих характеристик схеми (частоти зрізу, теплового розсіювання, пікового імпедансу) за фактично обраними стандартними номіналами для виявлення можливого погіршення запасу стійкості.

### Детальні інженерні сценарії розрахунку (Case Studies)

#### Сценарій 1: Автомобільний синхронний перетворювач 12 В -> 3.3 В (Частота 2.2 МГц)

В автомобільній електроніці (ECU, панелі приладів, радари ADAS) імпульсні стабілізатори напруги спеціально проектують на високу частоту комутації `f_sw = 2.1–2.3 МГц`. Це дозволяє уникнути інтерференції з радіомовним діапазоном амплітудної модуляції (AM Broadcast Band 530–1700 кГц), де вимоги стандарту CISPR 25 Class 5 є надзвичайно суворими (допустимий рівень завад становить не більше 18–24 дБмкВ).

- **Первинні вимірювання:** На платі без снубера зафіксовано високочастотний дзвін з амплітудою сплеску 24.5 В (при напрузі живлення 13.5 В) та частотою `f_1 = 185 МГц`. Після встановлення тестового конденсатора `C_test = 330 пФ` (C0G, 0603) частота осциляцій впала до `f_2 = 118 МГц`;
- **Обчислення контуру:**
  ```
  (f_1 / f_2)² = (185 / 118)² = (1.5678)² ≈ 2.458
  C_par = 330 пФ / (2.458 - 1) = 330 пФ / 1.458 ≈ 226.3 пФ
  L_par = 1 / ((2 · π · 185 · 10⁶)² · 226.3 · 10⁻¹²) ≈ 3.26 нГн
  Z_0 = √(3.26 · 10⁻⁹ / 226.3 · 10⁻¹²) ≈ 3.80 Ом
  ```
- **Вибір компонентів демпфування:**
  - Резистор снубера: обираємо стандартний номінал з ряду E24 `R_snub = 3.9 Ом` (корпус 0805 або 1206 з імпульсною потужністю);
  - Конденсатор снубера: `C_snub = 3 · 226.3 пФ ≈ 678.9 пФ`. Обираємо найближчий стандартний номінал `C_snub = 680 пФ` (діелектрик C0G/NP0, робоча напруга 50 В);
- **Тепловий розрахунок снубера:**
  ```
  P_snub = 680 · 10⁻¹² Ф · (13.5 В)² · 2.2 · 10⁶ Гц = 0.272 Вт (272 мВт)
  ```
  Потужність 272 мВт перевищує ліміт стандартного резистора типорозміру 0805 (125 мВт). Тому необхідно встановити резистор типорозміру **1206** (номінальна потужність 0.25–0.5 Вт) або скласти снубер із двох паралельних резисторів по `7.5 Ом` типорозміру 0805;
- **Результат:** Після встановлення розрахованого снубера викид напруги на вузлі SW зменшився з 24.5 В до 14.8 В, а високочастотний спектральний пік на частоті 185 МГц впав на 24 дБ, що дозволило приладу успішно пройти кваліфікацію за нормами CISPR 25 Class 5.

#### Сценарій 2: Промисловий DC-DC перетворювач 48 В -> 12 В / 10 А (Частота 350 кГц)

У телекомунікаційному та промисловому обладнанні шина живлення 48 В (діапазон 36–72 В) живить потужні стабілізатори з великим вихідним струмом.

- **Вихідні дані:** Мінімальна вхідна напруга `V_in_min = 36 В`, вихідна потужність `P_out = 12 В · 10 А = 120 Вт`, ККД `η = 0.94`, частота перемикання `f_sw = 350 кГц`. Цільове затухання вхідного фільтра становить 38 дБ для відповідності нормам EN 55032 Class B;
- **Розрахунок динамічного вхідного опору DC-DC:**
  ```
  R_in_conv = (36² · 0.94) / 120 = (1296 · 0.94) / 120 ≈ 10.15 Ом
  ```
- **Розрахунок вхідного π-фільтра:**
  - Обираємо силовой фільтрувальний екранований дросель `L_f = 6.8 мкГн` зі струмом насичення `I_sat = 6.5 А` та активним опором `DCR = 18 мОм`;
  - Необхідна частота зрізу фільтра для затухання 38 дБ:
    ```
    f_c = 350 кГц · 10^(-38 / 40) = 350 кГц · 10^(-0.95) ≈ 39.2 кГц
    ```
  - Розрахунок вихідної ємності фільтра `C_2`:
    ```
    C_2 = 1 / ((2 · π · 39.2 · 10³)² · 6.8 · 10⁻⁶) ≈ 2.42 мкФ
    ```
    Обираємо два паралельні керамічні конденсатори по 2.2 мкФ / 100 В (X7R, 1210). З урахуванням ефекту постійної напруги зміщення (DC Bias Effect), при напрузі 48 В ємність конденсаторів 2.2 мкФ падає на 45%, забезпечуючи фактичну результуючу ємність `C_2_eff ≈ 2.4 мкФ`;
- **Параметри демпфування Міддлбрука:**
  - Ємність демпфувального конденсатора:
    ```
    C_d = 4 · C_2_eff = 4 · 2.4 мкФ = 9.6 мкФ
    ```
    Обираємо алюмінієвий електролітичний конденсатор або полімерний танталовий конденсатор ємністю `10 мкФ` (ряд E12) з робочою напругою 100 В;
  - Характеристичний опір фільтра:
    ```
    Z_char = √(6.8 · 10⁻⁶ / 2.4 · 10⁻⁶) = √2.833 ≈ 1.68 Ом
    ```
  - Оптимальний резистор демпфування:
    ```
    R_d = 0.6124 · Z_char = 0.6124 · 1.68 Ом ≈ 1.03 Ом (обираємо 1.0 Ом ряду E24)
    ```
  - Максимальний демпфований вихідний імпеданс фільтра:
    ```
    Z_out_max = 0.866 · Z_char = 0.866 · 1.68 Ом ≈ 1.45 Ом
    ```
  - Запас стійкості Міддлбрука:
    ```
    Stability Margin = |R_in_conv| / Z_out_max = 10.15 Ом / 1.45 Ом ≈ 7.00
    ```
- **Висновок:** Запас стійкості 7.00 значно перевищує мінімальний інженерний поріг 3.0, що гарантує абсолютну стійкість перетворювача при будь-яких динамічних накидах і скиданнях струму навантаження від 0 до 10 А.

#### Сценарій 3: Демпфування індуктивності розсіювання у зворотноходовому перетворювачі (Flyback 24 В -> 5 В / 4 А)

В ізольованих джерелах живлення типу Flyback індуктивність розсіювання первинної обмотки трансформатора `L_leak` не передає накопичену енергію у вторинне коло в момент вимикання силового ключа, що призводить до появи високовольтного індуктивного піку на стоці.

- **Вихідні дані:** Первинна індуктивність `L_pri = 100 мкГн`, індуктивність розсіювання `L_leak = 2.5 мкГн` (2.5% від `L_pri`), піковий струм первинної обмотки `I_pk = 2.8 А`, частота комутації `f_sw = 150 кГц`, максимальна вхідна напруга `V_in_max = 32 В`, відбита напруга вторинної обмотки `V_reflected = N · (V_out + V_diode) = 4 · (5.0 + 0.5) = 22 В`;
- **Цільова напруга клампування:** Встановлюємо безпечну напругу клампування `V_clamp = 75 В` (запас до максимальної напруги транзистора 100 В становить 25 В);
- **Розрахунок резистора клампера `R_clamp`:**
  ```
  P_leak = 0.5 · L_leak · I_pk² · f_sw = 0.5 · 2.5 · 10⁻⁶ Гн · (2.8 А)² · 150 · 10³ Гц = 1.47 Вт
  R_clamp = (2 · V_clamp · (V_clamp - V_reflected)) / (L_leak · I_pk² · f_sw)
  R_clamp = (2 · 75 · (75 - 22)) / (2.5 · 10⁻⁶ · 7.84 · 150 · 10³) = (150 · 53) / 2.94 ≈ 2704 Ом
  ```
  Обираємо резистор `R_clamp = 2.7 кОм` номінальною потужністю не менше **3 Вт** (або три паралельні резистори по 8.2 кОм потужністю 1 Вт кожен);
- **Розрахунок ємності конденсатора клампера `C_clamp`:**
  Пульсація напруги на конденсаторі клампера `ΔV_clamp` не повинна перевищувати 5–10% від `V_clamp` (тобто `ΔV ≤ 5 В`):
  ```
  C_clamp = V_clamp / (R_clamp · ΔV_clamp · f_sw) = 75 / (2700 · 5 · 150 · 10³) ≈ 37 нФ
  ```
  Обираємо стандартний керамічний або плівковий конденсатор ємністю `47 нФ` з робочою напругою **250 В** (клас X7R або поліпропілен MKP);
- **Вибір діода клампера `D_clamp`:** Діод повинен бути ультрашвидким (Ultra-fast Recovery Diode) з часом зворотного відновлення `t_rr < 35 нс`, піковим зворотним напругою не менше 200 В та імпульсним струмом понад 5 А (наприклад, US1M, ES1J або діод Шотткі на карбіді кремнію SiC).

### Чеклист практичного впровадження демпферів та діагностики помилок

Під час проектування, налагодження та сертифікації імпульсних вузлів живлення рекомендується використовувати наступний перелік обов'язкових перевірок:

1. **Правило геометрії контуру снубера:** Снуберний резистор `R_snub` та конденсатор `C_snub` розташовані строго в одній лінії безпосередньо біля виводів силового ключа. Площа струмової петлі між вузлом SW, снубером та витоком транзистора становить менше `10 мм²`;
2. **Перевірка діелектрика конденсатора снубера:** Застосовано виключно кераміку класу 1 (C0G/NP0). Якщо на платі помилково встановлено конденсатор X7R або X5R, його ємність під імпульсною напругою падає на 60–80%, а високий діелектричний тангенс втрат спричиняє перегрів конденсатора та його тепловий пробій;
3. **Запас за імпульсною потужністю резистора снубера:** Номінальна потужність резистора розрахована з двократним запасом щодо теоретичних втрат `P_rated ≥ 2 · P_snub`. Для зменшення локального теплового опору резистор запаяно на розширені мідні теплопровідні майданчики, з'єднані з внутрішніми шарами землі через масив перехідних отворів;
4. **Вибір робочого струму дроселя вхідного фільтра `L_f`:** Струм насичення дроселя `I_sat` щонайменше на 30–50% перевищує максимальний піковий вхідний струм перетворювача з урахуванням температурного спадання проникності фериту при максимальній температурі експлуатації корпусу (+105°C);
5. **Орієнтація силової котушки індуктивності:** Початок обмотки котушки (позначений крапкою або скошеним краєм корпусу) з'єднаний із шумним комутаційним вузлом SW, а кінець обмотки — зі стабільною вихідною шиною живлення `V_out`;
6. **Захист кіл зворотного зв'язку:** Високоомний подільник напруги лінії FB (Feedback) та струмовий шунт з'єднані з контролером за допомогою екранованої диференційної пари доріжок, що проходять на внутрішньому сигнальному шарі між двома суцільними земляними площинами (Stripline), далеко від силових котушок та вузла SW;
7. **Перевірка критерію Міддлбрука:** Для демпфованого фільтра підтверджено виконання умови `Stability Margin = |R_in_conv| / Z_out_max ≥ 3.0` у всьому діапазоні температур і робочих напруг.
