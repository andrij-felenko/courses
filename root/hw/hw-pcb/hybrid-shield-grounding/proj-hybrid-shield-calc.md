# ⚙️ Калькулятор імпедансу гібридного заземлення кабельних екранів

Цей інженерний інструмент призначений для точного моделювання частотно-залежного комплексного імпедансу, струмів низькочастотних земляних петель, передавального імпедансу та ефективності екранування кабельних трас при довільних конфігураціях заземлення екрана (прямому двосторонньому, односторонньому та гібридному RC+GDT). Інженер застосовує цей розрахунок на етапі проєктування топології друкованих плат, вибору компонентів захисту та аудиту електромагнітної сумісності промислових ліній зв'язку, де ручний аналітичний розрахунок є неможливим через взаємодію розподілених параметрів кабелю з паразитними індуктивностями монтажу.

На частотах від 10 Гц до 1 ГГц фізична поведінка екранованого кабелю зазнає кардинальних змін: від суто омічного розподілу постійного струму через зону скін-ефекту та дифракційного протікання поля крізь отвори плетіння до стоячих хвиль чвертьхвильових резонансів. Програма виконує наскрізний чисельний розрахунок частотного відгуку системи, визначає безпеку компонентів за напругою та потужністю і будує детальний частотний звіт для верифікації вимог стандартів IEC 61000-4-4, IEC 61000-4-5 та CISPR 32.

### Теоретичні основи електродинаміки екранованих кабельних ліній

Щоб коректно змоделювати поведінку екранованого кабелю у широкому спектрі частот, необхідно звернутися до фундаментальних рівнянь електродинаміки Максвелла в циліндричній системі координат. Екран кабелю є не просто провідником із нульовим опором, а розподіленою електродинамічною структурою, яка взаємодіє із зовнішніми електромагнітними полями та внутрішніми сигнальними провідниками.

Розподіл напруженості електричного та магнітного полів усередині провідного шару екрана описується диференціальним рівнянням дифузії:

```
∇^2 E = mu_0 · sigma · (∂ E / ∂ t) + mu_0 · epsilon · (∂^2 E / ∂ t^2)
```

Для гармонічних процесів із круговою частотою `omega = 2·pi·f` у металах із високою питомою провідністю (для міді `sigma ≈ 5.8·10^7` См/м) густина струму зміщення є нехтовно малою порівняно з густиною струму провідності (`omega · epsilon << sigma` аж до частот оптичного діапазону). Рівняння спрощується до класичного рівняння Гельмгольца для провідного середовища:

```
∇^2 E = gamma^2 · E
```

де `gamma` — комплексна стала поширення в металі:

```
gamma = sqrt(j · omega · mu_0 · sigma) = (1 + j) / delta
```

де `delta` — товщина скін-шару (глибина проникнення поля), яка визначає відстань від поверхні провідника, на якій амплітуда електромагнітної хвилі зменшується в `e ≈ 2.718` раза:

```
delta = sqrt(1 / (pi · f · mu_0 · sigma))   [метри]
```

На низьких частотах (до 1–10 кГц) глибина скін-шару `delta` суттєво перевищує фізичну товщину стінки екрана `d`. Густина струму рівномірно розподілена по всьому перерізу обплетення, а внутрішнє магнітне поле дорівнює зовнішньому. Зі зростанням частоти понад 100 кГц глибина скін-шару стає значно меншою за товщину металу. Виникає виражений скін-ефект: вихрові струми витісняють зовнішній струм завади до зовнішньої поверхні екрана, а прямий зворотний струм сигналу — до його внутрішньої поверхні.

Завдяки цьому явищу суцільна металева трубка на високих частотах забезпечує практично ідеальну ізоляцію внутрішнього простору від зовнішніх полів. Енергія зовнішньої завади стікає по зовнішній стінці в землю шасі, не проникаючи на внутрішню поверхню екрана.

### Фізична модель поверхневого передавального імпедансу `Z_t`

У реальних кабелях екран виготовляють у вигляді плетеного дротяного обплетення (*braided shield*) або комбінації алюмінієвої фольги з мідним обплетенням. На відміну від суцільної безшовної трубки, плетене обплетення містить мільйони мікроскопічних ромбічних щілин (оптичних отворів), утворених перехресним накладанням пучків мідних дротиків.

```
Геометрія плетіння кабельного екрана:
              /\
             /  \  d_hole (діаметр отвору)
            /    \
            \    /  Кут плетіння alpha (30° - 45°)
             \  /
              \/
    Дротики d_wire (0.10 - 0.20 мм)
```

Зв'язок між струмом зовнішнього контуру `I_ext`, що тече по екрану, та наведеною поздовжньою напругою на внутрішній поверхні `d V_int / d x` описується передавальним імпедансом `Z_t(f)`. Для реального кабелю передавальний імпеданс складається з трьох фізичних складових:

```
Z_t(f) = Z_diff(f) + Z_hole_M(f) + Z_hole_C(f)   [Ом/м]
```

#### 1. Дифузійний передавальний опір `Z_diff(f)`
Дифузійна складова описує пряме проникнення електромагнітної хвилі крізь товщу металу через скін-ефект. Вона виводиться з точного розв'язку рівняння дифузії в циліндричній стінці й виражається формулою:

```
Z_diff(f) = R_dc · (gamma · d) / sinh(gamma · d)   [Ом/м]
```

де `R_dc` — погонний опір постійному струму (Ом/м), а `d` — ефективна товщина стінки екрана (зазвичай `d ≈ 1.5–2.0 · d_wire`).

Аналіз дифузійної складової показує:
- На постійному струмі (`f → 0`): `sinh(gamma · d) ≈ gamma · d`, тому `Z_diff(0) = R_dc`. Передавальний опір точно дорівнює омічному опору екрана.
- На високих частотах (`d / delta >> 1`): модуль функції `|sinh(gamma · d)| ≈ (1/2) · e^(d / delta)`. Дифузійний опір експоненційно падає до нуля:
  ```
  |Z_diff(f)| ≈ 2 · R_dc · (d / delta) · e^(-d / delta)
  ```
  Це означає, що на частотах понад 5–10 МГц дифузійне проникнення струму крізь метал практично повністю блокується.

#### 2. Індуктивний передавальний імпеданс отворів `Z_hole_M(f)`
Проте в плетеному обплетенні поле проникає крізь мікроотвори між дротиками. Зовнішній струм обтікає краї кожного ромбічного отвору, збуджуючи локальний магнітний дипольний момент. За теорією дифракції Бете на малих отворах, цей магнітний момент створює магнітний потік витоку, зв'язаний із внутрішнім сигнальним контуром кабелю.

Цей зв'язок моделюється погонною взаємною індуктивністю отворів `M_h`:

```
Z_hole_M(f) = j · omega · M_h = j · 2·pi·f · M_h   [Ом/м]
```

Значення взаємної індуктивності `M_h` залежить від оптичної щільності покриття обплетення `K`:

```
K = 2·F - F^2
F = (N · d_wire) / (2 · pi · r_shield · cos(alpha))
```

де:
- `N` — загальна кількість паралельних дротиків у пучках;
- `d_wire` — діаметр одиничного дротика (типово 0.12–0.16 мм);
- `r_shield` — радіус екрана (м);
- `alpha` — кут плетіння відносно осі кабелю (типово 30°–45°).

Аналітична формула Ванса для погонної індуктивності отворів має вигляд:

```
M_h = (mu_0 / (6 · pi)) · (1 - K)^(3/2) · (d_wire / r_shield)   [Гн/м]
```

Для дешевого одинарного обплетення з покриттям `K = 70%` індуктивність отворів становить `M_h ≈ 1.5–3.0 нГн/м`. Для високоякісного кабелю з подвійним обплетенням і покриттям `K = 95%` індуктивність падає до `M_h ≈ 0.05–0.15 нГн/м`.

#### 3. Повний графік передавального імпедансу реального кабелю

```
|Z_t| (Ом/м)
  ^
  |                                        / +20 дБ/дек (j·omega·M_h)
  |                                       /
  |----------------------\               /
  |  R_dc (~15 мОм/м)     \             /
  |                        \-----------/   Мінімум передавального імпедансу
  |                         Зона скін-ефекту
  +--------------------------------------------------> Частота f (Гц)
   0 Гц      10 кГц        500 кГц    5 МГц   50 МГц  500 МГц
```

На низьких частотах передавальний опір є чисто активним і сталим (`Z_t ≈ R_dc`). У діапазоні 500 кГц – 3 МГц скін-ефект знижує дифузію поля, досягаючи мінімуму імпедансу. Вище 5 МГц індуктивна складова отворів `j·omega·M_h` починає домінувати, і передавальний імпеданс зростає зі швидкістю +20 дБ на декаду, сягаючи 0.5–2.0 Ом/м на частоті 100 МГц.

### Аналіз та порівняння різних типів екранів кабелів

При інженерному аналізі кабельних з'єднань важливо враховувати фундаментальні конструктивні відмінності між різними класами екранування:

#### 1. Алюмінієва ламінована фольга (Al-Mylar) з дренажним проводом
Фольга забезпечує 100% оптичне покриття без жодних мікроотворів, тому взаємна індуктивність отворів `M_h = 0`. На високих частотах (понад 10 МГц) фольга демонструє чудові показники екранування. Проте товщина алюмінієвого шару становить лише 9–25 мкм, через що опір постійному струму `R_dc` сягає 50–150 мОм/м.

Для підключення тонкої фольги до роз'ємів використовують неізольований луджений мідний дріт (*drain wire*), прокладений уздовж фольги. Це створює два небажані ефекти:
- Струм завади стікає переважно по товстому дренажному проводу, викликаючи геометричну асиметрію поля;
- Дріт має паразитну погонну індуктивність, яка на частотах понад 30 МГц погіршує ефективність контакту фольги з шасі.

#### 2. Одинарне мідне обплетення (Single Braid)
Має низький активний опір постійному струму (`R_dc ≈ 10–25 мОм/м`) та високу механічну міцність. Проте оптичне покриття становить 70–85%, що призводить до значної індуктивності отворів `M_h ≈ 1.0–2.5 нГн/м`. На частотах понад 50 МГц передавальний імпеданс швидко зростає, знижуючи завадозахищеність.

#### 3. Подвійне комбіноване екранування (Foil + Braid / Dual Braid)
Поєднує суцільність фольги (100% покриття, блокування `M_h`) та низький активний опір і високу міцність мідного обплетення. Подвійне обплетення знижує `M_h` до рівня менш ніж 0.1 нГн/м завдяки взаємному перекриттю отворів зовнішнього та внутрішнього шарів. Це найкращий вибір для високошвидкісних промислових мереж (Profibus, Industrial Ethernet, CAN FD).

#### 4. Спіральний екран (Served / Spiral Shield)
Дротики намотані по спіралі в один бік. Забезпечує чудову гнучкість (аудіокабелі для мікрофонів), але на високих частотах працює як соленоїдна котушка індуктивності. На частотах понад 100 кГц індуктивність спіралі різко підвищує передавальний імпеданс, роблячи такий кабель непридатним для передачі цифрових сигналів.

### Модель наведення поля на внутрішні провідники за Агравалом і Полом

Для розрахунку точної амплітуди наведеного шуму на внутрішніх жилах кабелю використовується польова модель зв'язку Агравала (*Agrawal field-to-transmission line model*). Згідно з моделлю, струм екрана `I_shield(x)` розглядається як розподілене джерело поздовжньої ЕРС усередині кабелю:

```
d V_source(x) = - Z_t(f) · I_shield(x) · dx
```

Рівняння телеграфної лінії для внутрішнього контуру записуються у вигляді:

```
d V_int(x) / dx + Z_int · I_int(x) = - Z_t(f) · I_shield(x)
d I_int(x) / dx + Y_int · V_int(x) = - Y_t(f) · V_shield(x)
```

де `Z_int` та `Y_int` — погонний поздовжній імпеданс та поперечний адмітанс внутрішньої пари сигнальних жил, а `Y_t(f) = j · omega · C_h` — передавальний адмітанс ємнісного проникнення поля крізь отвори (яким для якісних екранів зазвичай можна знехтувати порівняно з `Z_t`).

Інтегруючи ці рівняння вздовж усієї довжини кабелю від `x = 0` до `x = L` з урахуванням граничних умов навантажень на кінцях `Z_load1` та `Z_load2`, отримуємо точний аналітичний вираз для синфазної напруги завади на вході приймача:

```
V_noise_cm = (Z_load2 / (Z_load1 + Z_load2)) · integral_0^L (I_shield(x) · Z_t(f) · e^(-gamma_int · (L - x))) dx
```

Якщо швидкість поширення хвилі всередині та ззовні кабелю є сумірною, а довжина кабелю менша за чверть хвилі, інтеграл спрощується до добутку повного струму на довжину:

```
V_noise_cm(f) ≈ I_loop(f) · Z_t(f) · L
```

Ця фундаментальна формула показує, що наведена напруга завади прямо пропорційна трьом величинам: струму петлі заземлення `I_loop(f)`, передавальному імпедансу `Z_t(f)` та фізичній довжині кабелю `L`. Гібридне заземлення мінімізує перший множник (`I_loop`), захищаючи лінію зв'язку навіть при скінченній величині `Z_t`.

### Еквівалентна чотириполюсна модель лінії передачі та S-параметри

Для аналізу струмів у контурі заземлення зовнішній екран кабелю над металевим шасі розглядається як однорідна лінія передачі довжиною `L` із розподіленими параметрами:
- `R'(f)` — погонний опір екрана з урахуванням скін-ефекту та опору шасі (Ом/м);
- `L'` — погонна зовнішня індуктивність контуру «екран–шасі» (Гн/м);
- `C'` — погонна ємність між екраном та опорною площиною шасі (Ф/м);
- `G'` — погонна провідність діелектричних втрат оболонки кабелю (См/м).

```
Схема елементарної ділянки dx лінії передачі:

     x ─────────── R'(f)·dx ───── L'·dx ─────────── x + dx
                                   │
                                  --- C'·dx
                                  ---
                                   │
                                  [ ] 1 / (G'·dx)
                                   │
     ────────────────────────────────────────────── Опорне шасі
```

Постійна поширення хвилі в зовнішньому контурі:

```
gamma_ext(f) = sqrt((R'(f) + j · omega · L') · (G' + j · omega · C'))
```

Хвильовий імпеданс зовнішнього контуру:

```
Z_0_ext(f) = sqrt((R'(f) + j · omega · L') / (G' + j · omega · C'))
```

Для лінії передачі довжиною `L` зв'язок між напругою та струмом на початку лінії (Вузол A, `x = 0`) і в кінці лінії (Вузол B, `x = L`) виражається класичною ланцюговою матрицею передачі (ABCD-матрицею):

```
┌ V(0) ┐   ┌ cosh(gamma_ext · L)          Z_0_ext · sinh(gamma_ext · L) ┐ ┌ V(L) ┐
│      │ = │                                                             │ │      │
└ I(0) ┘   └ (1 / Z_0_ext) · sinh(gamma_ext · L)   cosh(gamma_ext · L)   ┘ └ I(L) ┘
```

Перехід від ABCD-матриці до хвильової матриці розсіювання (S-параметрів) відносно опорного імпедансу портів `Z_ref = 50 Ом` дозволяє визначити коефіцієнт відбиття завади `S_11(f)` та коефіцієнт проникнення завади `S_21(f)`:

```
Delta = A · Z_ref + B + C · Z_ref^2 + D · Z_ref
S_11 = (A · Z_ref + B - C · Z_ref^2 - D · Z_ref) / Delta
S_21 = 2 · Z_ref / Delta
```

Граничні умови на кінцях лінії задаються схемою заземлення:
1. **На початку лінії (Вузол A):** Пряме заземлення через контактний опір роз'єму `Z_contact_A ≈ 0.005 Ом + j · omega · 0.5 нГн`. Напруга джерела різниці потенціалів `V(0) = ΔV_gnd(f) - I(0) · Z_contact_A`.
2. **На кінці лінії (Вузол B):** Підключення до шасі через імпеданс гібридного вузла `Z_hybrid(f)`. Гранична умова: `V(L) = I(L) · Z_hybrid(f)`.

Підставивши граничні умови в матричне рівняння, отримуємо точний аналітичний вираз для вхідного та вихідного струмів екрана:

```
I(L) = ΔV_gnd / (Z_hybrid · (cosh(gamma_ext · L) + (Z_contact_A / Z_0_ext) · sinh(gamma_ext · L)) + 
                 Z_0_ext · sinh(gamma_ext · L) + Z_contact_A · cosh(gamma_ext · L))
```

Для відносно коротких кабелів (`L < lambda / 10`), де хвильовими процесами можна знехтувати, ця формула з високою точністю збігається з моделлю зосереджених параметрів:

```
I_loop(f) ≈ ΔV_gnd(f) / (Z_contact_A + Z_shield_ext(f) · L + Z_hybrid(f))
```

### Детальна модель компонентів гібридного вузла та паразитних параметрів

Справжня інженерна точність розрахунку залежить від врахування неідеальності кожного фізичного компонента, встановленого на друкованій платі.

```
Повна схема заміщення гібридного вузла з паразитними параметрами:

Вхід від екрана (360°) ──┬──────────────┬──────────────┬───────────────┐
                         │              │              │               │
                        [ ] R_bleed    --- C_rf       --- C_gdt       [ ] R_insul
                        [ ] 1 МОм      --- 10 нФ      --- 1.0 пФ      [ ] >10 ГОм
                         │              │              │ (закритий)    │
                        --- C_par      [ ] ESR        --- GDT Arc     / \ Spark Gap
                        --- 0.3 пФ     [ ] 0.02 Ом    --- 15 В        \ / 0.4 мм
                         │              │              │ (відкритий)   │
                         │             MMM ESL         │               │
                         │             MMM 1.5 нГн     │               │
                         │              │              │               │
Шасі приладу (Chassis) ──┴──────────────┴──────────────┴───────────────┴
```

#### 1. Модель високовольтного керамічного конденсатора `C_rf`
Керамічний багатошаровий конденсатор (MLCC) складається з чергованих шарів металевих електродів та керамічного діелектрика. Його повний імпеданс описується виразом:

```
Z_C(f) = ESR(f) + j · (2·pi·f·ESL - 1 / (2·pi·f·C_rf(V_dc, T)))
```

де:
- `ESR(f)` — опір втрат, який на низьких частотах визначається діелектричними втратами `tan(delta_d) / (omega · C)`, а на високих частотах — омічним опором металізації електродів і скін-ефектом у виводах;
- `ESL` — еквівалентна послідовна індуктивність, зумовлена геометрією протікання струму крізь тіло конденсатора. Для стандартного монтажу SMD-компонентів індуктивність становить:
  - Корпус 0603: `ESL ≈ 0.5–0.8 нГн`;
  - Корпус 0805: `ESL ≈ 0.8–1.2 нГн`;
  - Корпус 1206: `ESL ≈ 1.2–1.5 нГн`;
  - Корпус 1812: `ESL ≈ 1.5–2.0 нГн`;
  - Корпус 2220: `ESL ≈ 2.2–2.8 нГн`.
- `C_rf(V_dc, T)` — реальна ємність із урахуванням напруги зміщення та температури. Для кераміки класу 2 (X7R) прикладання постійної напруги 500 В до конденсатора на 1 кВ може зменшити його ефективну ємність на 20–40%. Для кераміки класу 1 (C0G/NP0) ємність залишається строго незмінною.

#### 2. Модель газорозрядника (GDT)
Газорозрядник моделюється як нелінійний перемикач із двома квазістаціонарними станами та динамічним часом спрацьовування:
1. **Закритий стан (`V < V_spark`):** Моделюється як надвисокий опір ізоляції (`R_gdt > 10 ГОм`) у паралель із міжелектродною ємністю `C_gdt ≈ 0.5–1.5 пФ`.
2. **Відкритий стан (дуговий розряд):** Після перевищення порогу запалювання напруга фіксується на рівні горіння дуги `V_arc ≈ 10–20 В`, а внутрішній динамічний опір падає до сотих часток ома (`R_arc ≈ 0.05–0.2 Ом`).

#### 3. Модель паразитної індуктивності друкованого монтажу та перехідних отворів
Доріжки друкованої плати та перехідні отвори (vias), що з'єднують компоненти гібридного вузла з полігонами Chassis GND та SGND, мають власну індуктивність.

Індуктивність одиночного перехідного отвору діаметром `d_via` на платі товщиною `h_pcb` виражається формулою:

```
L_via ≈ (mu_0 · h_pcb / (2 · pi)) · (ln(4 · h_pcb / d_via) + 1)   [Гн]
```

Для стандартної плати товщиною `h_pcb = 1.6 мм` та отвору діаметром `d_via = 0.3 мм`:

```
L_via ≈ (4·pi·10^(-7) · 0.0016 / (2·pi)) · (ln(4 · 1.6 / 0.3) + 1)
      = 3.2·10^(-10) · (ln(21.33) + 1)
      = 3.2·10^(-10) · (3.06 + 1) ≈ 1.30 нГн
```

Один перехідний отвір додає 1.3 нГн індуктивності, що на частоті 100 МГц має опір `X_L = 0.82 Ом`, подвоюючи імпеданс конденсатора. Тому обов'язково застосовують масиви з 4–6 паралельних переходів (*via stitching*), що знижує індуктивність до менш ніж 0.25 нГн.

### Перехід від матриці передачі до S-параметрів у частотній області

Для узгодженого аналізу високочастотних трактів у середовищах моделювання НВЧ-пристроїв (таких як SPICE, Keysight ADS або Ansys HFSS) ланцюгову матрицю передачі (ABCD-матрицю) зовнішнього контуру екрана перетворюють на хвильову матрицю розсіювання (S-параметри) відносно стандартизованого системного опору портів `Z_0_ref = 50 Ом`.

Елементи матриці розсіювання пов'язані з коефіцієнтами ABCD-матриці відомими аналітичними співвідношеннями:

```
Delta_S = A · Z_0_ref + B + C · Z_0_ref^2 + D · Z_0_ref

S_11(f) = (A · Z_0_ref + B - C · Z_0_ref^2 - D · Z_0_ref) / Delta_S
S_12(f) = (2 · (A · D - B · C) · Z_0_ref) / Delta_S
S_21(f) = (2 · Z_0_ref) / Delta_S
S_22(f) = (-A · Z_0_ref + B - C · Z_0_ref^2 + D · Z_0_ref) / Delta_S
```

Фізичний зміст S-параметрів у контексті екранування кабелю:
- **Коефіцієнт відбиття `S_11(f)` (Return Loss):** Показує, яка частка енергії високочастотної завади відбивається назад до джерела збудження через стрибок імпедансу між хвильовим опором кабелю та точкою заземлення. На низьких частотах для гібридного заземлення `|S_11| ≈ 1.0` (0 дБ), оскільки відкритий конденсатор відбиває всю енергію низькочастотного поля.
- **Коефіцієнт прямої передачі `S_21(f)` (Insertion Loss):** Визначає частку енергії завади, яка проходить через екранну лінію до приймального кінця. Мінімізація модуля `|S_21(f)|` відповідає максимальному придушенню завади.
- **Втрати на відбиття та проходження:** У логарифмічній шкалі `RL(f) = -20 · log10(|S_11(f)|)` та `IL(f) = -20 · log10(|S_21(f)|)`.

### Моделювання паразитних перехідних отворів та деградація високочастотного заземлення

При переході від принципової електричної схеми до фізичної топології багатошарової друкованої плати ключовим джерелом паразитних індуктивностей стають металізовані перехідні отвори (vias). Якщо конденсатор `C_rf` або клема екрана підключаються до внутрішнього суцільного полігона шасі Chassis GND через тонкі провідники з одиночними перехідними отворами, високочастотні властивості заземлення зазнають катастрофічної деградації.

Власна індуктивність циліндричного перехідного отвору довжиною `h` (що дорівнює товщині друкованої плати або відстані між відповідними шарами) та радіусом `r_v` розраховується за формулою:

```
L_via = (mu_0 · h / (2 · pi)) · (ln(2 · h / r_v + sqrt(1 + (2 · h / r_v)^2)) - sqrt(1 + (r_v / (2 · h))^2) + r_v / (2 · h) + 0.25)
```

Для типових розмірів друкованих плат (`h = 1.6 мм`, діаметр свердла `d_v = 2 · r_v = 0.3 мм`) ця формула спрощується до інженерного наближення:

```
L_via ≈ 0.2 · h_mm · (ln(4 · h_mm / d_mm) + 1) = 0.2 · 1.6 · (ln(4 · 1.6 / 0.3) + 1)
      = 0.32 · (ln(21.33) + 1) = 0.32 · (3.06 + 1) ≈ 1.30 нГн
```

Вплив цієї індуктивності на частотний відгук:
- На частоті 100 МГц реактивний опір одного перехідного отвору становить:
  ```
  X_via = 2 · pi · 100·10^6 · 1.30·10^(-9) ≈ 0.817 Ом
  ```
- Теоретичний реактивний опір конденсатора `C_rf = 10 нФ` на цій самій частоті становить лише:
  ```
  X_C = 1 / (2 · pi · 100·10^6 · 10·10^(-9)) ≈ 0.159 Ом
  ```

Один перехідний отвір додає опір 0.817 Ом, що у 5 разів перевищує опір самого конденсатора. Замість очікуваного наднизького імпедансу заземлення інженер отримує послідовний індуктивний дросель, який блокує стікання високочастотного струму завади.

```
Топологія масиву перехідних отворів (Via Stitching):

Контактна площадка SMD-компонента
┌─────────────────────────────────────────────────────────────┐
│  ( O )    ( O )    ( O )    ( O )    ( O )    ( O )         │  Масив із 6 паралельних отворів
└─────────────────────────────────────────────────────────────┘
  Взаємна відстань між отворами pitch = 1.0 - 1.5 мм
  Еквівалентна індуктивність: L_total ≈ (L_via / N) · (1 + k_mutual)
```

Для мінімізації індуктивності застосовують паралельний масив із `N` перехідних отворів, розташованих безпосередньо біля виводів компонента. Еквівалентна індуктивність масиву з урахуванням взаємної індукції між сусідніми отворами виражається формулою:

```
L_array ≈ (L_via / N) · (1 + 2 · k_mutual · (N - 1) / N)
```

Для масиву з 6 паралельних отворів діаметром 0.3 мм із кроком 1.2 мм коефіцієнт взаємного зв'язку становить `k_mutual ≈ 0.25`, а сумарна паразитна індуктивність падає до `L_array ≈ 0.28 нГн`. Це дозволяє утримувати імпеданс заземлення на рівні менше 0.3 Ом аж до частот 200–300 МГц.

### Лабораторні випробування за стандартами IEC 62153-4-3 та IEC 62153-4-6

Для перевірки відповідності теоретичних розрахунків передавального імпедансу реальним параметрам кабелю в акредитованих випробувальних лабораторіях застосовують стандартизовані вимірювальні установки:

#### 1. Метод триаксіальної камери (Triaxial Test Cell за стандартом IEC 62153-4-3)
Випробувальна установка являє собою жорстку зовнішню циліндричну латунну трубку фіксованого діаметра, всередину якої коаксіально встановлюють зразок екранованого кабелю довжиною 0.5–1.0 м.
- Зовнішня трубка утворює з екраном досліджуваного кабелю зовнішню 50-омну лінію передачі;
- Внутрішні провідники кабелю утворюють внутрішню лінію передачі;
- Двопортовий векторний аналізатор кіл (VNA) підключають до зовнішньої трубки (Порт 1) та внутрішньої жили кабелю (Порт 2);
- Вимірюючи коефіцієнт прямої передачі `S_21(f)`, обчислюють передавальний імпеданс за формулою:
  ```
  |Z_t(f)| = (2 · Z_0_ext · |S_21(f)|) / (L_sample · sqrt((1 - |S_11(f)|^2) · (1 - |S_22(f)|^2)))   [Ом/м]
  ```
Цей метод є еталонним і забезпечує динамічний діапазон вимірювань понад 120 дБ у смузі частот від 10 кГц до 3 ГГц.

#### 2. Метод інжекційних кліщів (Current Injection Method за стандартом IEC 62153-4-6)
Застосовується для неруйнівного контролю готових промислових кабельних джгутів у зборі з роз'ємами безпосередньо на стендах тестування апаратури.
- Інжекційні кліщі охоплюють кабель і збуджують у його екрані калібрований високочастотний струм;
- Вимірювальні кліщі або прямий датчик напруги на виході приймача фіксують рівень наведеного шуму;
- Процедура дозволяє оцінити не лише якість самого кабелю, а й надійність 360-градусного монтажу роз'ємів та ефективність вузла гібридного заземлення.

### Інженерний посібник із діагностики несправностей у польових умовах

Якщо під час пусконалагоджувальних робіт на промисловому об'єкті виникають збої передачі даних або з'являється низькочастотний гул, інженер виконує покроковий діагностичний алгоритм:

1. **Перевірка наявності постійного струму або гулу 50 Гц:**
   - Підключають струмовимірювальні кліщі змінного струму до екрана кабелю біля шафи керування.
   - Якщо кліщі фіксують струм понад 50–100 мА на частоті 50 Гц при нібито встановленому гібридному заземленні, це однозначно вказує на електричний пробій керамічного конденсатора `C_rf` (перетворення на коротке замикання) або на помилкове пряме заземлення екрана в проміжній точці кабельної траси (наприклад, через контакт пошкодженої ізоляції з металевим кабельним лотком).
2. **Перевірка стану антистатичного резистора мегомметром:**
   - Знеструмлюють лінію зв'язку та від'єднують один кінець кабелю.
   - Мегомметром із напругою 250 В або 500 В вимірюють опір між екраном та корпусом шасі у вузлі гібридного заземлення.
   - Справний вузол повинен показувати опір рівно `1.0 ± 0.1 МОм`. Опір менше 100 кОм вказує на деградацію діелектрика конденсатора чи витік варистора, а опір понад 10 МОм — на обрив розрядного резистора (небезпека накопичення кіловольтних статичних зарядів).
3. **Виявлення високочастотного антенного резонансу спектроаналізатором:**
   - За допомогою високочастотних кліщів RF Current Probe сканують спектр струму екрана від 1 МГц до 100 МГц.
   - Наявність виражених резонансних піків на частотах, що кратні `f_res = v / (4 · L)`, свідчить про обрив конденсатора `C_rf` або недостатню якість ВЧ контакту (велику індуктивність монтажного хвостика).
   - Лікування: встановлення додаткових рознімних феритових фільтрів на обох кінцях траси або заміна монтажу на круговий 360-градусний EMC-затискач.

### Методика експериментальної верифікації заземлення в польових умовах

Для підтвердження коректності функціонування гібридного заземлення на реальному об'єкті інженер виконує такий комплекс інструментальних вимірювань:

#### 1. Вимірювання високочастотного струму завади струмовими кліщами
Для контролю струму екрана без розриву кабелю використовують високочастотні струмові кліщі (*RF Current Probe*, наприклад Fischer F-33-1 зі смугою 100 кГц – 250 МГц). Кліщі охоплюють екранований кабель і підключаються до портативного спектроаналізатора.
- Вимірюють спектральний розподіл струму `I_shield(f)` при вимкненому та ввімкненому силовому обладнанні.
- Якщо на частотах 10–100 МГц фіксується струм понад 10–20 мА, це свідчить про наявність резонансного антенного ефекту через надмірну індуктивність підключення екрана.

#### 2. Оцінка різниці потенціалів заземлювачів осцилографом
Вимірювання `ΔV_gnd` виконують осцилографом із диференційним високовольтним щупом, підключеним між металевими корпусами шафи A та шафи B через окремий контрольний провід. Осцилограма дозволяє виявити не лише гармоніку 50 Гц, а й високочастотні викиди від комутації тиристорів та частотних приводів.

#### 3. Перевірка цілісності конденсатора мегомметром
Для періодичного контролю стану ізоляції вузла гібридного заземлення використовують цифровий мегомметр із випробувальною напругою 500 В постійного струму. Опір між клемою екрана та шасі при справному резисторі 1 МОм та непошкодженому конденсаторі повинен становити строго `1.0 ± 0.05 МОм`. Падіння опору до нуля вказує на пробій конденсатора або замикання газорозрядника, а зростання до нескінченності — на обрив антистатичного резистора.

### Лабораторні методи вимірювання за стандартами IEC 62153-4-3 та IEC 62153-4-5

У лабораторних умовах сертифікаційних центрів вимірювання передавального імпедансу `Z_t(f)` виконують на спеціалізованому обладнанні за стандартизованими методиками:
1. **Метод триаксіальної камери (Triaxial Test Cell за IEC 62153-4-3):** Досліджуваний зразок кабелю монтують усередині жорсткої латунної або мідної трубки, яка утворює зовнішню коаксіальну лінію передачі. Векторний аналізатор кіл (VNA) збуджує зовнішню лінію та вимірює наведену напругу на внутрішніх провідниках, безпосередньо обчислюючи `Z_t(f)` у діапазоні від 10 кГц до 3 ГГц без впливу зовнішніх завад.
2. **Метод струмових інжекційних кліщів (Current Injection Method за IEC 62153-4-6):** Застосовується для вимірювання готових кабельних збірок із роз'ємами без їхнього руйнування. Високочастотний генератор через інжекційні кліщі наводить калібрований струм у зовнішній контур екрана, а вимірювальний приймач фіксує рівень наведеної синфазної напруги на навантаженні.

 * Hybrid Shield Grounding Impedance & Shielding Effectiveness Calculator
 * Standard: ISO/IEC 9899:1999 (C99)
 *
 * Compilation:
 *   gcc -std=c99 -O3 -Wall -Wextra proj-hybrid-shield-calc.c -lm -o hybrid_calc
 *   clang -std=c99 -O3 -Wall -Wextra proj-hybrid-shield-calc.c -lm -o hybrid_calc

#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <complex.h>
#include <stdbool.h>
#include <string.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

#define MU_0 (4.0 * M_PI * 1.0e-7)
#define COPPER_SIGMA (5.8e7)

/* Конфігурація фізичних параметрів кабелю */
typedef struct {
    double length_m;            /* Довжина кабелю, метри */
    double r_dc_per_m;          /* Погонний активний опір екрана, Ом/м */
    double braid_diameter_m;    /* Зовнішній діаметр обплетення, метри */
    double wire_diameter_m;     /* Діаметр дротика плетіння, метри */
    double optical_coverage;    /* Оптична щільність переплетення (0.50 - 0.98) */
    double l_ext_per_m;         /* Зовнішня погонна індуктивність контуру, Гн/м */
} CableConfig;

/* Конфігурація вузла гібридного заземлення */
typedef struct {
    double r_bleed_ohm;         /* Опір антистатичного резистора, Ом */
    double c_rf_farad;          /* Ємність високочастотного конденсатора, Ф */
    double esl_henry;           /* Паразитна індуктивність конденсатора ESL, Гн */
    double esr_ohm;             /* Опір втрат конденсатора ESR, Ом */
    double c_gdt_farad;         /* Паразитна ємність газорозрядника GDT, Ф */
    double v_gnd_rms_volts;     /* Діюча різниця потенціалів між землями, В */
    double v_cap_rating_volts;  /* Номінальна робоча напруга конденсатора, В */
} TerminationConfig;

/* Результати розрахунку для однієї частотної точки */
typedef struct {
    double freq_hz;
    double complex z_t_per_m;
    double complex z_hybrid;
    double complex z_loop_total;
    double i_loop_rms_amps;
    double v_noise_cm_volts;
    double shielding_eff_db;
    double v_cap_peak_volts;
    double p_res_watts;
} SweepPointResult;

/* Обчислення глибини скін-шару для міді */
static inline double calc_skin_depth(double freq_hz) {
    if (freq_hz <= 1.0) return 0.066; /* ~66 мм на DC/1 Гц */
    return sqrt(1.0 / (M_PI * freq_hz * MU_0 * COPPER_SIGMA));
}

/* Обчислення поверхневого передавального імпедансу плетеного екрана Z_t(f) */
double complex calc_transfer_impedance(const CableConfig *c, double freq_hz) {
    if (freq_hz <= 0.0) {
        return c->r_dc_per_m + 0.0 * I;
    }

    const double delta = calc_skin_depth(freq_hz);
    const double d = 2.0 * c->wire_diameter_m;
    const double complex gamma = (1.0 + I) / delta;
    const double complex gamma_d = gamma * d;

    /* Дифузійна складова: R_dc * (gamma * d) / sinh(gamma * d) */
    double complex z_diff;
    if (cabs(gamma_d) < 1e-4) {
        z_diff = c->r_dc_per_m + 0.0 * I;
    } else {
        z_diff = c->r_dc_per_m * (gamma_d / csinh(gamma_d));
    }

    /* Індуктивність отворів плетіння: M_h ~ mu_0 / (6*pi) * (1-K)^(3/2) */
    const double k_cov = (c->optical_coverage < 0.99) ? c->optical_coverage : 0.99;
    const double m_h = (MU_0 / (6.0 * M_PI)) * pow(1.0 - k_cov, 1.5) * (d / (c->braid_diameter_m * 0.5));
    const double complex z_hole = I * (2.0 * M_PI * freq_hz * m_h);

    return z_diff + z_hole;
}

/* Обчислення комплексного імпедансу гібридного вузла Z_hybrid(f) */
double complex calc_hybrid_node(const TerminationConfig *t, double freq_hz) {
    if (freq_hz <= 0.0) {
        return t->r_bleed_ohm + 0.0 * I;
    }

    const double omega = 2.0 * M_PI * freq_hz;

    /* Гілка конденсатора C_rf + ESL + ESR */
    const double xc = 1.0 / (omega * t->c_rf_farad);
    const double xl = omega * t->esl_henry;
    const double complex z_cap = t->esr_ohm + I * (xl - xc);

    /* Гілка резистора R_bleed */
    const double complex z_res = t->r_bleed_ohm + 0.0 * I;

    /* Гілка GDT (ємність 0.5-1.5 пФ) */
    const double complex z_gdt = -I / (omega * t->c_gdt_farad);

    /* Паралельне з'єднання трьох гілок: Y_total = 1/Z_c + 1/Z_r + 1/Z_gdt */
    const double complex y_total = (1.0 / z_cap) + (1.0 / z_res) + (1.0 / z_gdt);

    return 1.0 / y_total;
}

/* Розрахунок однієї точки частотного сканування */
SweepPointResult evaluate_frequency_point(const CableConfig *c, const TerminationConfig *t, double freq_hz) {
    SweepPointResult r;
    r.freq_hz = freq_hz;

    r.z_t_per_m = calc_transfer_impedance(c, freq_hz);
    r.z_hybrid = calc_hybrid_node(t, freq_hz);

    /* Повний поздовжній імпеданс зовнішнього контуру екрана */
    const double omega = 2.0 * M_PI * freq_hz;
    const double delta = calc_skin_depth(freq_hz);
    const double r_skin_factor = (delta > 0.0) ? (c->wire_diameter_m / (2.0 * delta)) : 1.0;
    const double r_ac_per_m = c->r_dc_per_m * ((r_skin_factor > 1.0) ? r_skin_factor : 1.0);
    const double complex z_shield_ext = (r_ac_per_m + I * (omega * c->l_ext_per_m)) * c->length_m;

    /* Контактний опір роз'єму Вузла A (360-градусний затискач) */
    const double complex z_contact_a = 0.005 + I * (omega * 0.5e-9);

    r.z_loop_total = z_contact_a + z_shield_ext + r.z_hybrid;

    const double z_loop_mag = cabs(r.z_loop_total);
    r.i_loop_rms_amps = (z_loop_mag > 1e-12) ? (t->v_gnd_rms_volts / z_loop_mag) : 0.0;

    /* Синфазна напруга шуму, наведена на внутрішні жили */
    const double complex v_noise_vec = (r.i_loop_rms_amps + 0.0 * I) * r.z_t_per_m * c->length_m;
    r.v_noise_cm_volts = cabs(v_noise_vec);

    /* Ефективність екранування: SE = 20 * log10(V_gnd / V_noise) */
    if (r.v_noise_cm_volts > 1e-12 && t->v_gnd_rms_volts > 1e-12) {
        r.shielding_eff_db = 20.0 * log10(t->v_gnd_rms_volts / r.v_noise_cm_volts);
    } else {
        r.shielding_eff_db = 120.0;
    }

    /* Напруга та потужність на вузлі для аналізу надійності */
    const double v_hybrid_rms = r.i_loop_rms_amps * cabs(r.z_hybrid);
    r.v_cap_peak_volts = v_hybrid_rms * sqrt(2.0);
    r.p_res_watts = (v_hybrid_rms * v_hybrid_rms) / t->r_bleed_ohm;

    return r;
}

/* Друк інженерного звіту в термінал */

inline constexpr double Mu0 = 4.0 * std::numbers::pi * 1.0e-7;
inline constexpr double CopperSigma = 5.8e7;

struct CableSpec {
    double length_m{50.0};
    double r_dc_per_m{0.0145};
    double braid_diameter_m{0.0060};
    double wire_diameter_m{0.00016};

    double l_ext_per_m{0.85e-6};

struct HybridTerminationSpec {
    double r_bleed_ohm{1.0e6};

    double esl_henry{1.5e-9};
    double esr_ohm{0.02};

    double v_gnd_rms_volts{10.0};
    double v_cap_rating_volts{2000.0};
};

struct FrequencyPointResult {
    double freq_hz{0.0};
    std::complex<double> z_transfer_per_m{0.0, 0.0};
    std::complex<double> z_hybrid_node{0.0, 0.0};
    std::complex<double> z_loop_total{0.0, 0.0};
    double i_loop_rms_amps{0.0};
    double v_noise_cm_volts{0.0};
    double shielding_effectiveness_db{0.0};
    double v_cap_peak_volts{0.0};
    double p_res_watts{0.0};

    [[nodiscard]] bool is_voltage_safe(double rating_v) const noexcept {
        return v_cap_peak_volts <= rating_v * 0.7;
    }
};

class HybridShieldSolver {
public:
    HybridShieldSolver(CableSpec cable, HybridTerminationSpec term) noexcept
        : cable_(cable), term_(term) {}

    [[nodiscard]] static double calculate_skin_depth(double freq_hz) noexcept {
        if (freq_hz <= 1.0) return 0.066;
        return std::sqrt(1.0 / (std::numbers::pi * freq_hz * Mu0 * CopperSigma));
    }

    [[nodiscard]] std::complex<double> calculate_transfer_impedance(double freq_hz) const noexcept {
        if (freq_hz <= 0.0) {
            return {cable_.r_dc_per_m, 0.0};
        }

        const double delta = calculate_skin_depth(freq_hz);
        const double d = 2.0 * cable_.wire_diameter_m;
        const std::complex<double> gamma{(1.0) / delta, (1.0) / delta};
        const std::complex<double> gamma_d = gamma * d;

        std::complex<double> z_diff;
        if (std::abs(gamma_d) < 1e-4) {
            z_diff = {cable_.r_dc_per_m, 0.0};
        } else {
            z_diff = cable_.r_dc_per_m * (gamma_d / std::sinh(gamma_d));
        }

        const double k_cov = std::clamp(cable_.optical_coverage, 0.50, 0.99);
        const double m_h = (Mu0 / (6.0 * std::numbers::pi)) * std::pow(1.0 - k_cov, 1.5) *
                           (d / (cable_.braid_diameter_m * 0.5));
        const std::complex<double> z_hole{0.0, 2.0 * std::numbers::pi * freq_hz * m_h};

        return z_diff + z_hole;
    }

    [[nodiscard]] std::complex<double> calculate_hybrid_node_impedance(double freq_hz) const noexcept {
        if (freq_hz <= 0.0) {
            return {term_.r_bleed_ohm, 0.0};
        }

        const double omega = 2.0 * std::numbers::pi * freq_hz;
        const double xc = 1.0 / (omega * term_.c_rf_farad);
        const double xl = omega * term_.esl_henry;

        const std::complex<double> z_cap{term_.esr_ohm, xl - xc};
        const std::complex<double> z_res{term_.r_bleed_ohm, 0.0};
        const std::complex<double> z_gdt{0.0, -1.0 / (omega * term_.c_gdt_farad)};

        const std::complex<double> y_total = (1.0 / z_cap) + (1.0 / z_res) + (1.0 / z_gdt);
        return 1.0 / y_total;
    }

    [[nodiscard]] FrequencyPointResult solve_point(double freq_hz) const noexcept {
        FrequencyPointResult r;
        r.freq_hz = freq_hz;

        r.z_transfer_per_m = calculate_transfer_impedance(freq_hz);
        r.z_hybrid_node = calculate_hybrid_node_impedance(freq_hz);

        const double omega = 2.0 * std::numbers::pi * freq_hz;
        const double delta = calculate_skin_depth(freq_hz);
        const double r_skin_factor = (delta > 0.0) ? (cable_.wire_diameter_m / (2.0 * delta)) : 1.0;
        const double r_ac_per_m = cable_.r_dc_per_m * std::max(1.0, r_skin_factor);
        const std::complex<double> z_shield_ext = (std::complex<double>{r_ac_per_m, omega * cable_.l_ext_per_m}) * cable_.length_m;

        const std::complex<double> z_contact_a{0.005, omega * 0.5e-9};
        r.z_loop_total = z_contact_a + z_shield_ext + r.z_hybrid_node;

        const double z_loop_mag = std::abs(r.z_loop_total);
        r.i_loop_rms_amps = (z_loop_mag > 1e-12) ? (term_.v_gnd_rms_volts / z_loop_mag) : 0.0;

        const std::complex<double> v_noise_vec = std::complex<double>{r.i_loop_rms_amps, 0.0} * r.z_transfer_per_m * cable_.length_m;
        r.v_noise_cm_volts = std::abs(v_noise_vec);

        if (r.v_noise_cm_volts > 1e-12 && term_.v_gnd_rms_volts > 1e-12) {
            r.shielding_effectiveness_db = 20.0 * std::log10(term_.v_gnd_rms_volts / r.v_noise_cm_volts);
        } else {
            r.shielding_effectiveness_db = 120.0;
        }

        const double v_hybrid_rms = r.i_loop_rms_amps * std::abs(r.z_hybrid_node);
        r.v_cap_peak_volts = v_hybrid_rms * std::numbers::sqrt2;
        r.p_res_watts = (v_hybrid_rms * v_hybrid_rms) / term_.r_bleed_ohm;

        return r;
    }

    [[nodiscard]] std::vector<FrequencyPointResult> solve_sweep(std::span<const double> freqs) const {
        std::vector<FrequencyPointResult> results;
        results.reserve(freqs.size());
        for (double f : freqs) {
            results.push_back(solve_point(f));
        }
        return results;
    }

private:
    CableSpec cable_;
    HybridTerminationSpec term_;
};

        100.0e6, 250.0e6, 500.0e6, 1000.0e6
    };

    const emc::HybridShieldSolver solver{cable, term};
    const auto results = solver.solve_sweep(freqs);

    if (csv_mode) {

        std::cout << "====================================================================================================\n";
        std::cout << " Частота [Гц] | |Z_hyb| [Ом] | |Z_loop| [Ом] | I_loop [мкА] | V_noise [мВ] | SE [дБ] | V_cap [В] | Стан \n";
        std::cout << "--------------+--------------+---------------+--------------+--------------+---------+-----------+------\n";

        for (const auto& r : results) {
            std::cout << " " << std::setw(12) << std::fixed << std::setprecision(1) << r.freq_hz
                      << " | " << std::setw(12) << std::setprecision(3) << std::abs(r.z_hybrid_node)

### Інтеграція в конвеєри автоматизованого проєктування (Hardware CI/CD)

У сучасних процесах розробки складної електроніки розрахунковий модуль імпедансу заземлення інтегрують у конвеєри безперервної інтеграції (Hardware CI/CD) на базі Git hooks, GitHub Actions або GitLab CI.

```
Конвеєр автоматизованої валідації електромагнітної сумісності:

Git Commit ──> [ Екстракція довжин ліній з CAD ] ──> [ Запуск hybrid_calc ] ──> [ Перевірка SE >= 50 дБ ] ──> Pass/Fail
```

#### 1. Автоматична екстракція параметрів із топології плат
Спеціалізований скрипт парсить файли друкованих плат (наприклад, формат `.kicad_pcb` у KiCad або `.PcbDoc` в Altium Designer), вилучає геометричні розміри бар'єру ізоляції, площу полігонів Chassis GND, кількість перехідних отворів та довжини підведених кабельних трас із переліку елементів (BOM). Отримані значення передаються через аргументи командного рядка утиліти `hybrid_calc`.

#### 2. Генерація еквівалентних SPICE-моделей
Калькулятор підтримує автоматичну генерацію субсхем у форматі SPICE Netlist для включення в загальне моделювання перехідних процесів трансиверів у середовищах LTspice, ngspice або Cadence Spectre:

```spice
* SPICE Subcircuit for Hybrid Grounding Termination Node
.SUBCKT HYBRID_GROUND_NODE SHIELD_IN CHASSIS_PE
R_BLEED SHIELD_IN CHASSIS_PE 1.0MEG
C_RF    SHIELD_IN N_INT 10.0NF
L_ESL   N_INT N_ESR 1.5NH
R_ESR   N_ESR CHASSIS_PE 0.02
C_GDT   SHIELD_IN CHASSIS_PE 1.0PF
.ENDS HYBRID_GROUND_NODE
```

Якщо під час автоматичного частотного сканування розрахована ефективність екранування в робочій смузі частот падає нижче 50 дБ або напруга на конденсаторі перевищує 70% номіналу при випробувальному імпульсі Surge, конвеєр CI/CD автоматично зупиняє збірку релізу та генерує інженерне попередження про необхідність оптимізації топології.

### Практичний аналіз типових кабельних трас

Застосування калькулятора дозволяє швидко верифікувати поведінку різних типів кабелів:

1. **Промисловий кабель LiYCY (4×0.5 мм², довжина 30 м):** Оптичне покриття екрана становить близько 75–80%. На частоті 50 Гц струм петлі при різниці потенціалів 5 В падає з 4.1 А (пряме заземлення) до 16 мкА (гібридне заземлення). На частоті 30 МГц передавальний імпеданс зростає до 0.45 Ом/м через оптичні просвіти, але гібридний вузол утримує ефективність екранування вище 48 дБ.
2. **Прецизійний кабель кручена пара Belden 9841 (120 Ом, довжина 100 м):** Завдяки комбінованому екрануванню (алюмінієва фольга Beldfoil + мідне луджене обплетення з покриттям 90%) значення `M_h` становить менше 0.2 нГн/м. Гібридне заземлення забезпечує ефективність екранування понад 65 дБ у всьому діапазоні від 100 кГц до 200 МГц, повністю усуваючи наведення від сусідніх частотних перетворювачів.
3. **Кабель кручена пара категорії Cat 6A S/FTP (довжина 60 м):** Кожна пара має індивідуальний екран із фольги, а весь кабель укладено в загальне мідне обплетення. Гібридне заземлення загального екрана блокує низькочастотні струми вирівнювання між комутаційними шафами серверної, водночас забезпечуючи захист від високочастотних радіозавад до 500 МГц.
