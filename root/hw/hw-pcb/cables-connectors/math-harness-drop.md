# 🧮 Розрахунок падіння напруги, зсуву землі та нагріву джгута

Аналітичний розрахунок електричних та теплових параметрів кабельного джгута дозволяє запобігти неочікуваним перезавантаженням мікроконтролерів, збоям цифрових інтерфейсів через деградацію логічних рівнів і деструктивному тепловому розплавленню ізоляції під час пікових навантажень.

---

## 1. Температурна залежність опору мідного провідника

Електричний опір постійному струму для монолітного або багатодротового провідника довжиною `L` з ефективною площею поперечного перерізу `S` визначається за питомим опором матеріалу `ρ`:

```
R_20 = ρ_20 · L / S
```

де для електротехнічної відпаленої міді (стандарт IACS) питомий опір при температурі `T_0 = 20°C` становить `ρ_20 = 0.0175 Ом·мм²/м` (або `1.75 · 10⁻⁸ Ом·м`).

Зі зростанням температури провідника внаслідок зовнішнього нагріву або виділення тепла струмом його опір лінійно зростає з температурним коефіцієнтом `α = 0.00393 1/°C`:

```
R(T) = R_20 · (1 + α · (T - 20°C))
```

Для багатодротового гнучкого проводу (Stranded Wire) дійсний опір збільшується на коефіцієнт скрутки `k_twist ≈ 1.02 – 1.05` через те, що окремі жилки йдуть по спіралі й мають більшу фізичну довжину, ніж загальна довжина кабелю:

```
R_stranded(T) = R_20 · (1 + α · (T - 20°C)) · k_twist
```

## 2. Фізична модель опору контактного з'єднання за Холмом

Опір перехідного контакту з'єднувача `R_contact` не є суто омічним опором металу штиря. Згідно з класичною контактною теорією Рагнара Холма (Ragnar Holm), дійсний електричний контакт між двома провідниками виникає лише на мікронерівностях поверхні (плямах дотику, або a-spots).

Сумарний опір контакту складається з трьох компонентів:

```
R_contact = R_bulk + R_constriction + R_film
```

де:
* `R_bulk` — об'ємний опір металевих деталей контакту (штиря, гнізда, пелюсток обтиску);
* `R_constriction` — опір стягування ліній струму;
* `R_film` — опір оксидних та адсорбованих поверхневих плівок.

### Опір стягування (Constriction Resistance)

Якщо на контакт діє нормальна сила притискання `F_N`, мікронерівності зазнають пластичної деформації доти, доки тиск не зрівняється з твердістю пластичності матеріалу контакту за Майєром `H` (для відпаленої міді `H ≈ 300–500 МПа`, для латуні та бронзи `H ≈ 700–1200 МПа`).

Сумарна дійсна площа контакту `A_real` та ефективний радіус контактної плями `a` визначаються силою притискання:

```
A_real = F_N / H
a = √(A_real / π) = √(F_N / (π · H))
```

Для однієї кругової контактної плями радіуса `a` опір стягування дорівнює:

```
R_constriction = ρ / (2 · a) = ρ / (2 · √(F_N / (π · H)))
```

Для контакту з `n` паралельними мікроплямами:

```
R_constriction ≈ ρ / (2 · n · a_i) + ρ / (2 · α_cluster)
```

де `α_cluster` — радіус усього кластера контактних плям.

### Висновок рівняння Холма

З формули видно ключову інженерну залежність: опір стягування обернено пропорційний квадратному кореню сили притискання `R_constriction ∝ 1 / √F_N`. Послаблення контактної пружини або релаксація напружень у металі при нагріванні зменшує `F_N`, що призводить до нелінійного лавиноподібного зростання перехідного опору.

## 3. Модель теплового балансу та самонагріву джгута

При протіканні постійного або середньоквадратичного змінного струму `I_RMS` у провіднику виділяється джоулева теплова потужність:

```
P_gen = I_RMS² · R(T)
```

У стаціонарному режимі вся генерована теплова потужність розсіюється в навколишнє середовище через конвекцію та теплове випромінювання:

```
P_diss = h_eff · S_surface · (T_ss - T_amb)
```

де:
* `h_eff` — ефективний коефіцієнт тепловіддачі з поверхні ізоляції (`h_eff ≈ 10 – 20 Вт/(м²·°C)` для природної повітряної конвекції);
* `S_surface = π · D_outer · L` — площа зовнішньої поверхні кабелю діаметром `D_outer`;
* `T_ss` — стала температура жили провідника;
* `T_amb` — температура навколишнього середовища.

Прирівнюючи тепловиділення до тепловіддачі, отримуємо нелінійне рівняння стаціонарної температури:

```
I² · R_20 · (1 + α · (T_ss - 20°C)) = h_eff · (π · D_outer · L) · (T_ss - T_amb)
```

Виражаємо усталений перегрів провідника `ΔT = T_ss - T_amb`:

```
ΔT = (I² · R_20 · (1 + α · (T_amb - 20°C))) / (h_eff · π · D_outer · L - I² · R_20 · α)
```

Якщо струм перевищує критичне значення `I_crit = √(h_eff · π · D_outer · L / (R_20 · α))`, знаменник наближається до нуля — настає явище теплового розгону (thermal runaway), коли приріст опору від нагріву генерує більше тепла, ніж ізоляція здатна розсіяти, що призводить до миттєвого згоряння джгута.

## 4. Зсув опорної землі (Ground Shift) та запас завадостійкості цифрових шин

Розглянемо двопровідне підключення віддаленого модуля, який живиться від джерела постійної напруги `V_DD` і одночасно передає логічний цифровий сигнал (UART / SPI / I2C) на головний мікроконтролер.

### Схема розподілу потенціалів

Опір прямого проводу живлення `R_pwr` та зворотного проводу землі `R_gnd` включає як опір кабелю, так і опір контактів роз'ємів на обох кінцях джгута:

```
R_pwr = R_wire_pwr + 2 · R_contact
R_gnd = R_wire_gnd + 2 · R_contact
```

Струм навантаження віддаленого модуля `I_load(t)` протікає по шині `R_gnd`, зміщуючи локальний потенціал землі віддаленого модуля `GND_remote` відносно системної землі `GND_master`:

```
ΔU_GND(t) = I_load(t) · R_gnd
```

### Вплив на вхідні логічні рівні

Для однопровідних цифрових інтерфейсів передавач формує напругу відносно своєї локальної землі:

1. **Передача від віддаленого модуля до майстра:**
   Напруга логічного нуля на вході приймача майстра зміщується вгору:
   ```
   V_in_master = V_OL_remote + ΔU_GND
   ```
   Умова коректного розпізнавання нуля:
   ```
   V_OL_remote + ΔU_GND ≤ V_IL_max_master
   ```
   Запас завадостійкості по низькому рівню:
   ```
   Margin_LOW = V_IL_max_master - (V_OL_remote + ΔU_GND)
   ```

2. **Передача від майстра до віддаленого модуля:**
   Напруга на вході приймача віддаленого модуля вимірюється відносно зміщеної землі `GND_remote`:
   ```
   V_in_remote = V_sig_master - ΔU_GND
   ```
   Для логічного нуля при `V_sig_master ≈ 0 В`:
   ```
   V_in_remote = 0 В - ΔU_GND = -ΔU_GND
   ```
   Якщо `ΔU_GND > 0.4 – 0.5 В`, від'ємний потенціал на вході мікросхеми відкриває внутрішні захисні ESD-діоди на підкладку (Clamp Diodes), що спричиняє паразитне замикання сигнального струму, перегрів кристала і можливий ефект замикання (Latch-up).

## 5. Наскрізний числовий розрахунок реального інженерного джгута

Розрахуємо кабельне з'єднання між головною платою керування (Master MCU, живлення 3.3 В CMOS) та віддаленим сенсорно-актуаторним вузлом (Slave Node: мікроконтролер + давач тиску + кроковий сервопривід).

### Вихідні дані

* Довжина кабельного джгута: `L = 1.5 м` (повна довжина петлі струму `2 · L = 3.0 м`).
* Кабель: 4-жильний гнучкий провід калібру **AWG 26** (переріз жили `S = 0.141 мм²`).
* З'єднувачі: два роз'єми **JST PH 2.0 мм** (по 4 контакти: VBUS, GND, TX, RX).
* Опір одного перехідного контакту роз'єму (новий, з лудінням): `R_contact = 15 мОм = 0.015 Ом`.
* Напруга живлення джерела: `V_source = 5.00 В`.
* Струм спокою модуля (сенсор + MCU): `I_idle = 0.05 А`.
* Піковий струм при русі сервоприводу: `I_peak = 2.00 А`.
* Логічні рівні 3.3 В CMOS-інтерфейсу UART:
  `V_IL_max = 0.80 В`, `V_IH_min = 2.00 В`, `V_OL_max = 0.15 В`, `V_OH_min = 2.90 В`.
* Температура всередині кабельного каналу: `T_amb = 40°C`.

### Крок 1. Розрахунок активного опору провідників з урахуванням температури

Обчислимо опір 1.5 м мідної жили перерізом 0.141 мм² при температурі 40°C з коефіцієнтом скрутки 1.03:

```
R_20 = 0.0175 · 1.5 / 0.141
= 0.1862 Ом      [опір мідної жили при 20°C: ρ · L / S]

R_wire_40 = 0.1862 · (1 + 0.00393 · (40 - 20)) · 1.03
= 0.1862 · (1 + 0.0786) · 1.03      [температурна поправка: 1 + α·ΔT]
= 0.1862 · 1.0786 · 1.03            [обчислення коефіцієнта нагріву]
= 0.2069 Ом                         [опір одного проводу при 40°C]
```

### Крок 2. Повний опір силових ланцюгів живлення та землі

Опір прямої лінії живлення `R_pwr` та зворотного проводу `R_gnd` включає опір жили та по два контакти роз'ємів (на вході й виході джгута):

```
R_pwr = R_wire_40 + 2 · R_contact
= 0.2069 + 2 · 0.0150      [підстановка значень опору проводу та контактів]
= 0.2069 + 0.0300          [додавання перехідних опорів контактів]
= 0.2369 Ом                [сумарний опір шини живлення VBUS]

R_gnd = R_wire_40 + 2 · R_contact
= 0.2369 Ом                [сумарний опір шини повернення GND]
```

Сумарний опір петлі живлення:

```
R_loop = R_pwr + R_gnd
= 0.2369 + 0.2369      [додавання опорів прямої та зворотної шин]
= 0.4738 Ом            [повний петльовий опір живлення]
```

### Крок 3. Падіння напруги на навантаженні

1. **У режимі спокою (`I = 0.05 А`):**
```
ΔU_loop_idle = 0.05 · 0.4738
= 0.0237 В      [падіння напруги за законом Ома: I_idle · R_loop]

V_slave_idle = 5.00 - 0.0237
= 4.9763 В      [напруга живлення на віддаленому модулі в спокої]
```

2. **У піковому режимі роботи сервоприводу (`I = 2.00 А`):**
```
ΔU_loop_peak = 2.00 · 0.4738
= 0.9476 В      [падіння напруги за законом Ома: I_peak · R_loop]

V_slave_peak = 5.00 - 0.9476
= 4.0524 В      [напруга живлення на віддаленому модулі під навантаженням]
```
*Висновок:* Напруга живлення просідає з 5.00 В до 4.05 В (просідання на 19.0%). Якщо на віддаленому модулі встановлено лінійний LDO на 3.3 В з падінням `V_drop = 0.5 В`, він збереже працездатність (`4.05 В > 3.80 В`). Однак сам сервопривід втратить крутний момент через зменшення напруги.

### Крок 4. Розрахунок зсуву землі та перевірка логічних рівнів UART

Обчислимо зсув потенціалу землі віддаленого модуля `GND_remote` відносно `GND_master` під час пікового навантаження 2.00 А:

```
ΔU_GND = I_peak · R_gnd
= 2.00 · 0.2369      [струм помножено на опір проводу й контактів землі]
= 0.4738 В          [зсув потенціалу локальної землі Slave-модуля]
```

Тепер перевіримо сигнал логічного нуля від віддаленого сенсора до головного контролера:

```
V_OL_actual = V_OL_max + ΔU_GND
= 0.15 + 0.4738      [додавання вихідного нуля передавача та зсуву землі]
= 0.6238 В          [фактична напруга на вході приймача Master MCU]

Margin_LOW = V_IL_max - V_OL_actual
= 0.80 - 0.6238      [порівняння з граничним порогом логічного нуля]
= 0.1762 В          [залишковий запас завадостійкості]
```

*Аналіз критичності:* Початковий статичний запас завадостійкості становив `0.80 В - 0.15 В = 0.65 В`. Під дією струму двигуна запас скоротився до `0.176 В` (падіння запасу на 73%). Будь-яка додаткова електромагнітна завада амплітудою більше 180 мВ викличе помилкове сприйняття нуля як одиниці та зірве пакет UART.

Крім того, сигнал від Master до Slave у стані нуля матиме відносний рівень:
```
V_in_slave_LOW = 0.00 В - ΔU_GND
= -0.4738 В      [від'ємний потенціал на піні RX відносно зміщеної землі Slave]
```
Напруга `-0.474 В` відкриває внутрішній захисний кремнієвий діод мікроконтролера Slave (поріг відмикання `~0.4 – 0.5 В`), що спричиняє витік струму з підкладки кристала.

### Крок 5. Розрахунок тепловиділення

Потужність тепла, що виділяється на джгуті під час струму 2.0 А:

```
P_heat = I_peak² · R_loop
= 2.00² · 0.4738      [струм у квадраті помножено на повний опір джгута]
= 4.00 · 0.4738       [обчислення квадрата струму]
= 1.895 Вт            [сумарна потужність теплових втрат на джгуті]
```

Для джгута довжиною 1.5 м лінійне теплове навантаження становить `1.26 Вт/м`. У закритій гофрованій трубці без вентиляції такий рівень потужності спричинить локальний перегрів на `+25...35°C` вище температури навколишнього середовища.

### Інженерні рекомендації за результатами розрахунку

1. Збільшити калібр силових жил живлення VBUS і GND до **AWG 20** (`S = 0.518 мм²`, опір `R_wire_40 = 0.056 Ом`).
2. Опір шини землі зменшиться до `R_gnd = 0.056 + 0.030 = 0.086 Ом`.
3. Зсув землі при піку 2.0 А становитиме `ΔU_GND = 2.0 · 0.086 = 0.172 В` (замість 0.474 В).
4. Запас завадостійкості UART складе `0.80 - (0.15 + 0.172) = 0.478 В` (зростання надійності в 2.7 раза), а від'ємний потенціал `-0.17 В` не відкриватиме захисні діоди.
5. Для гарантованої відсутності збоїв при більших струмах — застосувати диференційну передачу даних (**RS-485 / CAN**) або розділити джгут на два окремі кабелі: силовий (Power) та сигнальний (Signal) з ізольованою цифровою землею.
