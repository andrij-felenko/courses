# ⚙️ Інженерний розрахунок контуру кварцу та аналогового тракту АЦП

У прецизійній схемотехніці та розробці топології друкованих плат надійність роботи тактових генераторів та аналогових вимірювальних трактів визначається точним числовим розрахунком фізичних параметрів контурів. Спроба обрати ємності навантаження кварцу «за аналогією з типовою схемою» або встановити антиаліасинговий фільтр АЦП з довільними номіналами призводить до прихованих дефектів: зриву генерації тактового сигналу при низьких температурах (-40 °C), відходу тактової частоти за межі протокольних допусків USB/CAN, втрати 4–6 розрядів реальної точності АЦП через незавершений перехідний процес фази вибірки або виникнення паразитних коливань на шині аналогового живлення VDDA через резонанс феритової намистини.

Цей інженерний проект містить повну математичну модель, бібліотеку та утиліту діагностики мовами C99 та C++20 для обчислення й перевірки ключових параметрів чутливих вузлів плати:
1. Номіналів зовнішніх навантажувальних конденсаторів `C_1` та `C_2` з урахуванням паразитної ємності монтажу `C_stray`;
2. Критичної крутизни `g_m_crit` та коефіцієнта запасу підсилення (Gain Margin) інвертора Пірса;
3. Потужності збудження кристала (Drive Level) та номіналу послідовного демпфуючого резистора `R_d`;
4. Часового бюджету встановлення напруги на конденсаторі вибірки АЦП під час фази вибірки `t_acq` та розрахунку зовнішнього антиаліасингового RC-фільтра;
5. Коефіцієнта добротності `Q` та демпфування резонансного сплеску LC-фільтра аналогового живлення на базі феритової намистини (Ferrite Bead);
6. Динаміки перемикання каналів аналогового мультиплексора та перезаряду ємності вибірки при комутації;
7. Обмеження теплового шуму `kT/C` та впливу апертурного джиттера тактового генератора на ефективну розрядність перетворювача (ENOB).

### Фізична природа та математичні моделі

#### 1. П'єзоелектричний резонатор та модель Баттерворта — Ван Дайка

Кварцовий кристал є високодобротною електромеханічною коливальною системою. П'єзоелектричний ефект забезпечує двостороннє перетворення між механічною деформацією кристалічної решітки діоксиду кремнію `SiO₂` та електричним полем на металевих електродах напилення.

Електрична еквівалентна схема кристала поблизу основного резонансу описується чотириелементною моделлю Баттерворта — Ван Дайка (англ. *Butterworth–Van Dyke model*, BVD):
* **Динамічна індуктивність `L_m`:** Еквівалент інерційної маси коливної кварцової пластини (становить від одиниць мілігенрі для ВЧ-кристалів до сотень генрі для годинникових резонаторів 32.768 кГц);
* **Динамічна ємність `C_m`:** Еквівалент пружності кристалічної структури кварцу (знаходиться в межах `1...40 фФ`, де `1 фФ = 10⁻¹⁵ Ф`);
* **Опір втрат `R_m` (ESR):** Еквівалентний послідовний опір, що описує втрати на внутрішнє тертя в кварці та дисипацію енергії в точках кріплення пластини до тримача;
* **Статична паралельна ємність `C_0`:** Електростатична ємність між нанесеними металевими електродами через діелектрик кварцу разом із паразитною ємністю корпусу (типово `1...7 пФ`).

Комплексний імпеданс моделі BVD як функція кутової частоти `ω = 2πf` визначається рівнянням:

```
Z_xtal(jω) = 1 / (jω C_0 + 1 / (R_m + jω L_m + 1 / (jω C_m)))
```

Кристал має дві характерні резонансні частоти:
1. **Частота послідовного резонансу `f_s`:** Частота, на якій реактивні опори `L_m` та `C_m` взаємно компенсуються:
   ```
   f_s = 1 / (2 · π · √(L_m · C_m))
   ```
   На частоті `f_s` імпеданс гілки кристала є чисто активним і мінімальним: `Z(f_s) ≈ R_m = ESR`.
2. **Частота паралельного резонансу (антирезонансу) `f_p`:** Частота, на якій динамічна гілка взаємодіє зі статичною ємністю `C_0`:
   ```
   f_p = f_s · √(1 + C_m / C_0) ≈ f_s · (1 + C_m / (2 · C_0))
   ```

У схемах генераторів Пірса кристал завжди працює в індуктивній смузі між `f_s` та `f_p`, де його реактивний опір має індуктивний характер. Разом із зовнішніми конденсаторами `C_1`, `C_2` кристал формує паралельний резонансний контур на робочій частоті `f_osc`.

#### 2. Температурний дрейф частоти та криві зрізу кварцу

Залежність резонансної частоти кварцового резонатора від температури визначається кутом кристалографічного зрізу кварцового бруска відносно оптичних та електричних осей монокристала.

##### Резонатори зрізу AT (AT-Cut Crystal, діапазон 4–64 МГц)
Для високочастотних резонаторів застосовують пластини зрізу AT (кутова орієнтація біля `35°15'` відносно оптичної осі Z). Температурний відхід частоти описується кубічною поліноміальною кривою (кубічною параболою):

```
Δf / f_0 = a_1 · (T - T_0) + a_2 · (T - T_0)² + a_3 · (T - T_0)³
```

де `T_0 ≈ 25 °C` — точка перегину. Завдяки кубічній формі кривої резонатори AT-зрізу зберігають високу стабільність у широкому промисловому діапазоні температур від -40 °C до +105 °C із сумарним відхиленням частоти не більше `±15...±30 ppm`.

##### Годинникові камертонні резонатори (Tuning Fork 32.768 кГц)
Низькочастотні часові кварци виготовляються у формі крихітного камертона зрізу XY або NT. Їхня температурна характеристика має форму спадної квадратичної параболи:

```
Δf / f_0 = -B · (T - T_0)²
```

де `B ≈ 0.035...0.040 ppm/°C²` — параболічний коефіцієнт, `T_0 ≈ 25 °C` — вершина параболи.

При екстремальних температурах відхід частоти годинникового кварцу є істотним:
* При `T = +85 °C` (`ΔT = +60 °C`): `Δf / f_0 = -0.035 · (60)² = -126 ppm` (годинник відстає приблизно на 11 секунд на добу);
* При `T = -40 °C` (`ΔT = -65 °C`): `Δf / f_0 = -0.035 · (-65)² = -148 ppm` (годинник відстає на 13 секунд на добу).

#### 3. Математика від'ємного опору інвертора Пірса (Negative Resistance)

Для підтримки незгасаючих коливань активний підсилювальний елемент (CMOS-інвертор) повинен вносити в коливальний контур еквівалентний **від'ємний динамічний опір** `R_neg`, який повністю компенсує омічні втрати в резонаторі `ESR`.

Спрощена еквівалентна схема генератора Пірса розглядає інвертор як джерело струму, кероване вхідною напругою, з крутизною `g_m = dI_out / dV_in`.

Комплексний вхідний імпеданс, який бачить резонатор з боку своїх виводів, дорівнює:

```
Z_in(jω) = -g_m / (ω² · C_1 · C_2) + 1 / (jω · (C_1 · C_2 / (C_1 + C_2)))
```

Дійсна частина цього імпедансу є від'ємним активним опором:

```
R_neg = -g_m / (ω² · C_1 · C_2)
```

##### Умова виникнення та стійкості коливань:
1. **Умова наростання амплітуди коливань при запуску:**
   ```
   |R_neg| > ESR
   ```
2. **Критична крутизна `g_m_crit`:** Значення крутизни транзисторів інвертора, за якого абсолютна величина від'ємного опору точно дорівнює втратам у кристалі (`|R_neg| = ESR`):
   ```
   g_m_crit = ESR · ω² · C_1 · C_2
   ```
   З урахуванням повної ємності навантаження контуру `C_L = (C_1 C_2) / (C_1 + C_2) + C_stray` та статичної ємності `C_0` формулу критичної крутизни зводять до канонічного вигляду:
   ```
   g_m_crit = 4 · ESR · (2 · π · f)² · (C_0 + C_L)²
   ```
3. **Коефіцієнт запасу підсилення (Gain Margin):**
   ```
   Gain Margin = g_m / g_m_crit
   ```

##### Експериментальна перевірка від'ємного опору на платі
Для фізичного вимірювання запасу стійкості реальної друкованої плати в лабораторії застосовують метод послідовного резистора:
* Послідовно з кварцовим резонатором розривають доріжку і запаюють змінний безіндукційний SMD-потенціометр (або набір постійних резисторів) номіналом `R_test = 0...500 Ом` (для HSE) чи `0...500 кОм` (для LSE);
* Плату охолоджують у кліматичній камері до -40 °C і поступово збільшують номінал `R_test` доти, доки генератор не перестане запускатися при вмиканні живлення (точка зриву `R_break`);
* Фактичний від'ємний опір інвертора за таких умов становить:
  ```
  |R_neg| = ESR + R_break
  Gain Margin = (ESR + R_break) / ESR
  ```
  Якщо виміряне значення `R_break` перевищує `4 · ESR`, контур має достатній 5-кратний запас надійності.

#### 4. Динаміка перезаряду входу вибірки АЦП

Вхідний каскад перетворювача послідовного наближення (SAR ADC) під час фази вибірки `t_acq` описується системою диференціальних рівнянь балансу зарядів.

Нехай до початку вибірки зовнішній конденсатор фільтра `C_ext` заряджений до напруги джерела `V_in`, а внутрішній конденсатор вибірки `C_sample` має залишковий заряд від попереднього такту перетворення `V_prev`.

У момент часу `t = 0` замикається ключ S&H з опором `R_on`.

1. **Миттєвий перерозподіл заряду:**
   За перші частки наносекунди (доки опір зовнішнього резистора `R_ext` обмежує приплив струму від джерела) відбувається швидкий перерозподіл заряду між `C_ext` та `C_sample`. Напруга у вузлі піна АЦП миттєво стрибає до проміжного значення `V_dip`:
   ```
   V_dip = (C_ext · V_in + C_sample · V_prev) / (C_ext + C_sample)
   ```
   Максимальний стрибок напруги становить:
   ```
   ΔV_step = |V_in - V_prev| · (C_sample / (C_ext + C_sample))
   ```
   Якщо `C_ext ≥ 50 · C_sample`, початковий стрибок не перевищує `2%` від повної шкали напруги.
2. **Експоненційне дозаряджання контуру:**
   Після початкового стрибка конденсатор `C_sample` експоненційно дозаряджається до точного значення `V_in` через сумарний послідовний опір `R_total = R_ext + R_on`:
   ```
   V_sample(t) = V_in - (V_in - V_dip) · exp(-t / τ)
   ```
   де еквівалентна стала часу контуру:
   ```
   τ = (R_ext + R_on) · C_sample
   ```
3. **Залишковий шум та похибка встановлення:**
   Через час фази вибірки `t_acq` абсолютна похибка напруги становить:
   ```
   V_error(t_acq) = ΔV_step · exp(-t_acq / τ)
   ```
   Щоб ця похибка не перевищувала `0.5 LSB` (`V_ref / 2^(N+1)`), час вибірки повинен строго задовольняти нерівність:
   ```
   t_acq ≥ τ · ln((ΔV_step · 2^(N + 1)) / V_ref)
   ```
   У найгіршому випадку повного перепаду шкали (`|V_in - V_prev| = V_ref`) нерівність спрощується до класичної інженерної форми:
   ```
   t_acq_min = (N + 1) · ln(2) · (R_ext + R_on) · C_sample
   ```

#### 5. Багатоканальне мультиплексування та міжканальне перехресне проникнення (MUX Scanning Dynamics)

У системах збору даних один АЦП зазвичай опитує від 4 до 16 аналогових каналів за допомогою внутрішнього аналогового мультиплексора (ADC MUX).

Коли АЦП завершує оцифрування каналу CH0 (наприклад, з напругою `3.3 В`) і мультиплексор перемикається на канал CH1 (де напруга сенсора дорівнює `0.05 В`), на внутрішній паразитній ємності шини мультиплексора `C_mux` (типово `5...15 пФ`) та внутрішньому конденсаторі `C_sample` зберігається заряд високого потенціалу `3.3 В`.

У момент підключення каналу CH1 цей заряд інжектується назад у зовнішній конденсатор `C_ext1` каналу CH1. Виникає імпульс перехресної завади (англ. *Cross-Talk Glitch*).

Якщо зовнішній опір джерела каналу CH1 є високим (`R_source = 10 кОм`), а час між перемиканнями каналів малий, залишковий заряд не встигає стекти. У результаті виміряне значення на каналі CH1 виявляється завищеним на кілька мілівольт (або десятки LSB).

##### Методи боротьби з перехресним проникненням при мультиплексуванні:
1. **Зниження вихідного опору каналів:** Встановлення буферних операційних підсилювачів перед кожним аналоговим входом мультиплексора;
2. **Збільшення тривалості фази вибірки:** Програмне налаштування збільшеного часу вибірки `SMPR` для каналів з високим внутрішнім опором джерела;
3. **Фіктивне скидання заряду (Dummy Sampling / GND Sampling):** Програмне вставлення між вимірюванням корисних каналів одного швидкого такту вибірки спеціального каналу заземлення (GND channel), що повністю скидає накопичений заряд на шині мультиплексора.

#### 6. Тепловий шум kT/C та апертурний джиттер тактового генератора

Точність високорозрядних систем (16–24 біти) обмежується не лише завадами друкованої плати, але й фундаментальними фізичними шумовими бар'єрами.

##### Тепловий шум комутованого конденсатора (kT/C Noise)
У будь-якому RC-контурі тепловий рух носіїв заряду в резисторі генерує білий шум Джонсона — Найквіста з густиною `e_n² = 4 k T R`. При проходженні крізь фільтр низьких частот смуга шуму обмежується значенням `BW = 1 / (4 R C)`.

Середньоквадратична напруга теплового шуму, інтегрована на конденсаторі вибірки `C_sample`, не залежить від опору резистора і визначається виключно температурою `T` та ємністю `C`:

```
V_noise_rms = √(k · T / C_sample)
```

де `k = 1.380649×10⁻²³ Дж/К` — стала Больцмана, `T = 300 К` (кімнатна температура).

При `C_sample = 10 пФ`:

```
V_noise_rms = √(1.38×10⁻²³ · 300 / 10×10⁻¹²)
= √(4.14×10⁻²¹ / 10⁻¹¹)
= √4.14×10⁻¹⁰ ≈ 2.03×10⁻⁵ В = 20.3 мкВ RMS
```

Для 16-розрядного АЦП із діапазоном 3.3 В (1 LSB = 50.35 мкВ) тепловий шум `kT/C` становить `0.4 LSB`, що призводить до природного тремтіння молодшого розряду в межах ±1 біта. Для 24-розрядних систем ємність конденсатора вибірки штучно збільшують до `100...500 пФ`, щоб знизити шум `kT/C` до часток мікровольта.

##### Вплив апертурного джиттера генератора на SNR
Нестабільність часових фронтів тактового генератора (апертурний джиттер `t_jitter`) призводить до випадкової похибки моменту фіксації аналогового сигналу `ΔV = (dV_in / dt) · t_jitter`.

Максимальне теоретичне відношення сигнал/шум (SNR), зумовлене виключно джиттером тактування при вимірюванні синусоїдального сигналу частоти `f_in`, становить:

```
SNR_jitter = -20 · log10(2 · π · f_in · t_jitter)
```

Якщо для тактування АЦП використано низькоякісний RC-генератор із джиттером `t_jitter = 100 пс`, то при оцифруванні сигналу частотою `f_in = 100 кГц`:

```
SNR_jitter = -20 · log10(2 · 3.14159 · 100000 · 100×10⁻¹²)
= -20 · log10(6.283×10⁻⁵)
≈ -20 · (-4.20) ≈ 84.0 дБ
```

Максимальна ефективна розрядність за формулою `ENOB = (SNR - 1.76) / 6.02` становить `(84.0 - 1.76) / 6.02 ≈ 13.66 біт`. Тобто 16-розрядний АЦП через джиттер втратить понад 2.3 розряди точності. Застосування стабільного кварцового резонатора з джиттером менше `1...2 пс` повертає SNR вище 110 дБ.

#### 7. Комплексний аналіз та демпфування LC-фільтра на феритовій намистині

Фільтр живлення `VDDA` складається з феритової намистини та шунтувального керамічного конденсатора. Передатна функція такого фільтра по напрузі `H(s) = V_out(s) / V_in(s)` має вигляд:

```
H(s) = (1 + s · ESR · C) / (s² · L · C + s · (R_dc + ESR) · C + 1)
```

Знаменник передатної функції описує класичну коливальну ланку другого порядку зі стандартною формою `s² / ω_0² + 2ζ s / ω_0 + 1`, де:
* **Власна резонансна частота:**
  ```
  ω_0 = 1 / √(L · C)
  f_res = 1 / (2 · π · √(L · C))
  ```
* **Коефіцієнт демпфування `ζ` та добротність `Q`:**
  ```
  ζ = (R_dc + ESR) / 2 · √(C / L)
  Q = 1 / (2 · ζ) = (1 / (R_dc + ESR)) · √(L / C)
  ```

##### Фізичні наслідки високої добротності `Q > 1`:
1. **Підсилення завад (Resonant Peaking):** На частоті `f_res` амплітудно-частотна характеристика фільтра має пік підсилення `|H(jω_0)| ≈ Q`. Якщо імпульсний стабілізатор живлення (DC-DC) працює на частоті, близькій до `f_res`, або містить у спектрі струму навантаження гармоніки цієї частоти, фільтр посилить пульсації на шині `VDDA` у `Q` разів замість їхнього послаблення!
2. **Імпульсний дзвін при перехідних процесах:** Будь-який стрибок споживання струму ядром чи АЦП викликає затухаючі коливання напруги з періодом `T_res = 1 / f_res` та тривалістю затухання `t_settle ≈ 3 · Q / (π · f_res)`.

##### Критерій критичного демпфування Баттерворта (`Q ≤ 0.707`):
Для повного усунення резонансного піка необхідно забезпечити коефіцієнт демпфування `ζ ≥ 1 / √2 ≈ 0.7071`. Звідси випливає умова на мінімальний опір контуру:

```
R_total_min = √(2 · L / C)
```

Якщо власний опір постійному струму намистини `R_dc` недостатній, додатковий опір демпфування `R_damp = R_total_min - R_dc` реалізують одним із двох способів:
* **Спосіб А (Паралельний RC-демпфер Снабера):** Паралельно керамічному конденсатору `10 мкФ` підключають танталовий конденсатор `10...22 мкФ` з власним `ESR ≈ 0.5...1.5 Ом`. Тантал забезпечує необхідне розсіювання енергії на низьких частотах, тоді як кераміка шунтує високочастотні завади.
* **Спосіб Б (Послідовний резистор):** Послідовно з феритом встановлюють резистор `0.5...1.0 Ом`. Цей спосіб простий, але створює постійне падіння напруги `ΔV = I_analog · R_damp`, тому він підходить лише для малоспоживаючих аналогових трактів (`I_analog < 10 мА`).

#### 8. Диференційні драйвери АЦП (FDA) та розрахунок синфазного і диференційного фільтра

Для високошвидкісних 16–18 розрядних перетворювачів застосовують підсилювачі з повністю диференційним виходом (англ. *Fully Differential Amplifier*, FDA, наприклад Texas Instruments THS4551, Analog Devices ADA4940).

FDA перетворює однополярний вхідний сигнал датчика на симетричну диференційну пару, зміщену відносно опорного рівня синфазної напруги `VOCM = VREF / 2`.

```
                    ┌───[ R_f ]───┐
                    │             │
Вхід (+) ───[ R_g ]─┴───[\        │
                        │ FDA ]───┴───[ R_ext ]───┬────────> AIN+ (до АЦП)
Джерело                 │     ]                   │
VOCM ───────────────────[ VOCM]                [ C_diff ]
                        │     ]                   │
Вхід (-) ───[ R_g ]─┬───[/    ]───┬───[ R_ext ]───┴────────> AIN- (до АЦП)
                    │             │               │
                    └───[ R_f ]───┘            [ C_cm ]
                                                  │
                                                 GND
```

##### Розрахунок симетричного триконденсаторного фільтра:
На вході диференційного АЦП встановлюють три конденсатори: один міжканальний диференційний `C_diff` та два однакових синфазних `C_cm`, підключених до землі.
1. **Співвідношення номіналів:**
   Диференційний конденсатор обирають щонайменше у 10 разів більшим за синфазні:
   ```
   C_diff ≥ 10 · C_cm
   ```
   *Чому це правило критичне:* Будь-які два реальні конденсатори `C_cm1` та `C_cm2` мають технологічний допуск (наприклад, ±5%). Якщо `C_diff` відсутній, а синфазний шум наводиться на обидві лінії, різниця номіналів `C_cm1` та `C_cm2` перетворить синфазний шум на диференційну напругу завади, яка буде оцифрована АЦП. Великий міжканальний конденсатор `C_diff` домінує в диференційній фільтрації, нівелюючи вплив несиметрії синфазних ємностей.
2. **Диференційна смуга зрізу:**
   ```
   f_cutoff_diff = 1 / (2 · π · (2 · R_ext) · (C_diff + C_cm / 2))
   ```

#### 9. Регістровий розрахунок тактів вибірки мікроконтролерів (STM32 ADC Sizing)

У прошивці мікроконтролера інженер повинен перевести розрахований мінімальний час вибірки `t_acq_min` у конкретне числове значення бітів регістру конфігурації каналу (наприклад, `ADC_SMPR1 / ADC_SMPR2` у STM32 або `ADCCLK` у TI C2000).

1. **Визначення частоти тактування АЦП:**
   Тактовий сигнал АЦП `f_adc` формується від системної шини через передподільник (Prescaler `PRESC`):
   ```
   f_adc = f_source / PRESC
   T_adc_cycle = 1 / f_adc
   ```
2. **Розрахунок необхідної кількості тактів:**
   ```
   N_cycles_required = t_acq_min / T_adc_cycle = t_acq_min · f_adc
   ```
3. **Вибір найближчого більшого значення з таблиці квантів:**
   У мікроконтролерах STM32G4/H7 регістр вибірки дозволяє встановити дискретний ряд значень:
   * `SMP = 000`: 2.5 такти АЦП;
   * `SMP = 001`: 6.5 тактів;
   * `SMP = 010`: 12.5 тактів;
   * `SMP = 011`: 24.5 тактів;
   * `SMP = 100`: 47.5 тактів;
   * `SMP = 101`: 92.5 тактів;
   * `SMP = 110`: 247.5 тактів;
   * `SMP = 111`: 640.5 тактів.

##### Розрахунковий приклад:
Нехай `f_adc = 40 МГц` (`T_adc = 25 нс`). Для 16-розрядного перетворювача розрахований час вибірки становить `t_acq_min = 96.8 нс`.

```
N_cycles = 96.8 нс / 25 нс = 3.872 такти
```

Значення `2.5 такти` (62.5 нс) призведе до незавершеного встановлення сигналу. Тому обираємо наступне більше значення ряду: **6.5 тактів** (`t_acq_real = 6.5 · 25 нс = 162.5 нс`), що гарантує 100% точність оцифрування.

#### 10. Вплив діелектрика плати та вологості на паразитну ємність

Діелектрична проникність стандартного склотекстоліту FR-4 `ε_r` не є константою: вона становить `4.2...4.4` на частоті 1 МГц за сухого повітря, але зростає до `4.8...5.1` при високій вологості (понад 85% RH) через гігроскопічне вбирання води смолою (діелектрична проникність води `ε_water ≈ 80`).

Зростання `ε_r` на 15% призводить до пропорційного збільшення паразитної ємності монтажу `C_stray`:
```
C_stray(волого) = C_stray(сухо) · (ε_r_wet / ε_r_dry)
```

При початковому `C_stray = 3.5 пФ` ємність зростає до `4.0 пФ`. Це відхилення зсуває частоту кварцового генератора на додаткові 10–25 ppm. Для високопрецизійних вимірювальних систем плату покривають гідрофобним захисним конформним лаком (силіконовим або акриловим згідно з IPC-CC-830), або використовують базові матеріали з низьким водопоглинанням (Rogers RO4350B або Isola 370HR).

#### 11. Прецизійне трасування джерела опорної напруги VREF та 4-провідне підключення Кельвіна

Джерело опорної напруги (VREF) є еталоном, з яким АЦП порівнює вхідні сигнали. Будь-який шум або падіння напруги на провідниках лінії VREF безпосередньо транслюється у похибку кожного відліку перетворювача.

У прецизійних 16–24 розрядних системах під час фази перетворення SAR АЦП споживає від виводу VREF імпульсний струм з частотою перемикання внутрішніх зважених конденсаторів CDAC. Пікові струми можуть досягати `10...50 мА` протягом кількох наносекунд.

Якщо доріжка між виходом мікросхеми VREF та піном АЦП має паразитний опір `R_trace = 0.1 Ом` та індуктивність `L_trace = 5 нГн`, імпульсний струм викличе динамічне просідання опорної напруги:
```
ΔV_vref = I_peak · R_trace + L_trace · (dI / dt)
```

При швидкості наростання `dI / dt = 50 мА / 2 нс = 2.5×10⁷ А/с`:
```
ΔV_vref = 0.05 А · 0.1 Ом + 5×10⁻⁹ Гн · 2.5×10⁷ А/с
= 5 мВ + 125 мВ = 130 мВ!
```
Такий колосальний стрибок миттєво спотворює старші розряди перетворення SAR АЦП.

##### Правила трасування та фільтрації шини VREF:
1. **Локальний буферний конденсатор безпосередньо біля виводу MCU:** Керамічний конденсатор `10...47 мкФ` класу X7R/X5R розміщують на відстані не більше 1.5–2 мм від виводу `VREF+` мікроконтролера. Зворотний вивід цього конденсатора підключають безпосередньо до виводу `VREF-` (або `VSSA`), мінімізуючи площу паразитної петлі.
2. **Чотирипровідне підключення Кельвіна (Kelvin Sense Connection):** Якщо джерело опорної напруги має виводи зворотного зв'язку (Force/Sense, наприклад REF5025 або ADR4525), вивід `Sense` трасують окремим тонким провідником і підключають строго до площадки конденсатора безпосередньо біля піна АЦП. Це дозволяє внутрішній схемі компенсації VREF повністю усунути статичне падіння напруги на силовій трасі `Force`.
3. **Широкі полігони живлення:** Трасу лінії VREF виконують провідником шириною не менше 0.5–1.0 мм (або полігоном) на шарі L1 з нерозривною опорною площиною GND на L2.

#### 12. Методологія заводського тестування та калібрування на виробництві (DFM & Testing)

Для забезпечення 100% виходу придатних виробів на автоматизованих лініях поверхневого монтажу (SMT) застосовують стандартизовані процедури перевірки чутливих вузлів:

1. **Тестування запасу запуску методом зниження напруги живлення (VDD Margin Test):**
   * Під час функціонального тестування (FCT) напругу живлення мікроконтролера короткочасно знижують на 15–20% нижче номінального мінімуму (наприклад, з 3.0 В до 2.4 В);
   * За низької напруги живлення крутизна інвертора `g_m` падає приблизно пропорційно напрузі;
   * Якщо кварцовий контур має дефект (підвищений ESR кристала через мікротріщину або надлишковий флюс із витоком), генератор не зможе запуститися за зниженої напруги. Плати, які не пройшли тест, автоматично відбраковуються.
2. **Калібрування внутрішніх ємнісних матриць (Internal Capacitance Trimming):**
   * Сучасні мікроконтролери та RTC-мікросхеми містять внутрішні програмовані банки конденсаторів (Capacitance Trimming Registers);
   * На етапі фінального калібрування вимірюється точна частота на виводі MCO/CLKOUT за допомогою прецизійного частотоміра, синхронізованого з рубідієвим або GPS-еталоном;
   * Розраховується похибка `Δf` і в енергонезалежну пам'ять EEPROM/Flash записується калібрувальний байт підстроювання ємності, що компенсує технологічний розкид монтажу до рівня `< ±1 ppm`.

#### 13. Термоелектричні ЕРС Зеєбека на контактних площадках SMD та ізотермічна топологія

У прецизійних трактах з роздільною здатністю 18–24 біти (де вага молодшого розряду 1 LSB становить менше `1...5 мкВ`) небезпечним джерелом похибки є термоелектричний ефект Зеєбека.

Будь-який контакт між різнорідними металами на друкованій платі (мідна доріжка `Cu`, свинцево-олов'яний або безсвинцевий припій `Sn-Ag-Cu` (SAC305), металізований нікель-золотий торець SMD-компонента `Ni-Au`) утворює мініатюрну термопару. Коефіцієнт Зеєбека для переходу мідь-припій становить приблизно `S ≈ 1...3 мкВ/°C`, а для переходів з оксидом міді `Cu-CuO` може досягати `1000 мкВ/°C`.

Якщо вздовж корпусу резистора чи діодної збірки виникає температурний градієнт (наприклад, один кінець резистора розташований ближче до гарячого лінійного стабілізатора LDO або мікроконтролера, ніж інший), різниця температур між двома спаями `ΔT = T_pad1 - T_pad2` генерує паразитну термо-ЕРС:

```
V_thermo = S_cu_solder · ΔT
```

При різниці температур всього `ΔT = 0.5 °C` на вході АЦП з'являється паразитне зміщення `V_thermo = 1.5 мкВ`, що для 24-розрядного перетворювача (1 LSB = 0.2 мкВ) створює постійну похибку зміщення нуля величиною у `7.5 LSB`!

##### Правила ізотермічної топології друкованої плати:
1. **Орієнтація компонентів за ізотермічними лініями:** Обидва контактні пади чутливих пасивних компонентів (резисторів фільтра, конденсаторів, діодів) розташовують на однаковій відстані від основних джерел тепла на платі (перпендикулярно вектору теплового потоку).
2. **Симетрія мідного тепловідведення (Thermal Symmetry):** До обох контактних площадок SMD-резистора мають підходити доріжки строго однакової ширини та довжини, щоб забезпечити однаковий тепловий відтік і зрівняти температури обох пайових з'єднань (`ΔT = 0`).
3. **Захист від повітряних конвекційних потоків:** Чутливий аналоговий вузол закривають локальним пластиковим чи металевим екраном, який запобігає прямому обдуванню компонентів нерівномірними потоками повітря від вентиляторів охолодження.

#### 14. Механічні напруження плати та балансування міді (Copper Balancing)

Мініатюрні керамічні корпуси SMD кварцових резонаторів (типорозміри 3225, 2016, 1612) містять всередині тонку п'єзоелектричну пластину, закріплену на консольних струмопровідних клейових опорах.

Будь-яка механічна деформація або короблення плати (англ. *PCB Warpage / Bow and Twist*), що виникає при пайці оплавленням (Reflow Solder) або механічному закручуванні гвинтів кріплення плати в корпус, передається через контактні площадки на керамічний корпус і кварцову пластину.

Внаслідок п'єзооптичного та п'єзоелектричного ефектів механічне стискання чи розтягнення кварцової пластини викликає зміщення власної резонансної частоти генератора на `20...80 ppm`, а в гірших випадках — мікротріщини в точках кріплення кристала, що призводить до зростання ESR у 5–10 разів і раптового зриву генерації через місяці експлуатації.

##### Заходи запобігання механічним напруженням:
1. **Зона віддалення від механічних фіксаторів:** Кварцовий резонатор заборонено розміщувати ближче ніж на `10...15 мм` від кріпильних отворів під гвинти, затискачів, напрямних пазів корпусу, важких електролітичних конденсаторів, реле та важких силових роз'ємів живлення.
2. **Балансування міді на шарах (Copper Thieving / Balancing):** Нерівномірний розподіл міді між шарами (наприклад, суцільний екран на L2 та розріджене трасування на L1) призводить до різного коефіцієнта теплового розширення (CTE) шарів під час нагрівання в печі оплавлення до 250 °C. Це викликає залишковий вигин плати після охолодження. На вільних ділянках шарів L1 та L4 додають нейтральні мідні полігони вирівнювання щільності міді (балансувальні площадки), з'єднані з землею.
3. **Орієнтація корпусу відносно лінії вигину:** Якщо відомо, що плата зазнає циклічного пружного вигину вздовж певної осі (наприклад, при натисканні кнопок або підключенні кабелю), корпус кварцового резонатора орієнтують поздовжньою віссю паралельно лінії вигину (а не перпендикулярно їй), що мінімізує механічний згинальний момент на електродах кристала.

### Детальний числовий аналіз прикладних інженерних задач

#### Задача 1: Автомобільний резонатор HSE 16.0 МГц
* Параметри: `f = 16 МГц`, `C_L = 12.0 пФ`, `ESR = 35.0 Ом`, `C_0 = 3.0 пФ`, `P_max = 100 мкВт`.
* Драйвер мікроконтролера: `g_m = 2500 мкА/В`, `VDD = 3.3 В`, `C_stray = 3.5 пФ`.

```
C_ext = 2 · (12.0 - 3.5) = 17.0 пФ     [найближчий номінал E24: 18 пФ C0G]
C_tot = 3.0 + 12.0 = 15.0 пФ
ω = 2 · π · 16×10⁶ = 1.0053×10⁸ рад/с

g_m_crit = 4 · 35 · (1.0053×10⁸)² · (15×10⁻¹²)²
= 140 · 1.0106×10¹⁶ · 2.25×10⁻²²
≈ 318 мкА/В

Gain Margin = 2500 / 318 = 7.86        [Критерій >= 5.0 виконано]

I_drive = π · 16×10⁶ · 15×10⁻¹² · 3.3 = 2.488 мА
P_drive_undamped = 2 · 35 · (2.488×10⁻³)² ≈ 433 мкВт

R_d_opt = 1 / (2 · π · 16×10⁶ · 18×10⁻¹²) ≈ 552 Ом
```
**Інженерний висновок:** Оскільки потужність розгойдування без демпфування (433 мкВт) перевищує гранично допустиму (100 мкВт), обов'язково встановлюємо послідовний резистор `R_d = 470 Ом`. Номінал навантажувальних конденсаторів `C_1 = C_2 = 18 пФ`.

#### Задача 2: Годинниковий резонатор LSE 32.768 кГц
* Параметри: `f = 32768 Гц`, `C_L = 6.0 пФ`, `ESR = 65 000 Ом`, `C_0 = 1.1 пФ`, `P_max = 0.5 мкВт`.
* Драйвер RTC: `g_m = 10.0 мкА/В`, `VDD = 3.0 В`, `C_stray = 2.2 пФ`.

```
C_ext = 2 · (6.0 - 2.2) = 7.6 пФ      [найближчий номінал E24: 8.2 пФ або 6.8 пФ C0G]
C_tot = 1.1 + 6.0 = 7.1 пФ
ω = 2 · π · 32768 = 205887 рад/с

g_m_crit = 4 · 65000 · (205887)² · (7.1×10⁻¹²)²
= 260000 · 4.2389×10¹⁰ · 5.041×10⁻²³
≈ 0.555 мкА/В

Gain Margin = 10.0 / 0.555 = 18.0     [Критерій >= 5.0 виконано]
```
**Інженерний висновок:** Контур має відмінний запас стійкості `Gain Margin = 18.0`. Для конденсаторів обираємо номінал `8.2 пФ` C0G. Додатковий демпфуючий резистор не потрібен через високий власний ESR кристала.

#### Задача 3: 16-розрядний SAR АЦП AD7685 (250 kSPS)
* Параметри: `N = 16 біт`, `C_sample = 15 пФ`, `R_on = 400 Ом`, `t_acq = 150 нс`.
* Зовнішній фільтр: `R_ext = 47 Ом`, `C_ext = 1000 пФ`.

```
Ratio = C_ext / C_sample = 1000 / 15 = 66.7   [Критерій >= 50 виконано]
τ = (47 + 400) · 15×10⁻¹² = 6.705 нс

k = (16 + 1) · ln(2) ≈ 11.78
t_acq_min = 11.78 · 6.705 нс = 79.0 нс

ε(150 нс) = exp(-150 / 6.705) = exp(-22.37) ≈ 1.92×10⁻¹⁰
Error_LSB = 65536 · 1.92×10⁻¹⁰ ≈ 0.000012 LSB
```
**Інженерний висновок:** Сконфігурований час вибірки `150 нс` майже вдвічі перевищує мінімальний поріг `79.0 нс`. Похибка встановлення становить частки мікро-LSB, що гарантує відсутність динамічних нелінійних спотворень.

#### Задача 4: Демпфування фільтра VDDA на феритовій намистині Murata BLM18PG600
* Параметри: `L = 2.2 мкГн`, `R_dc = 0.08 Ом`, `C = 10.0 мкФ`, `ESR_cap = 0.005 Ом` (кераміка X7R).

```
f_res = 1 / (2 · π · √(2.2×10⁻⁶ · 10×10⁻⁶)) = 1 / (6.283 · 4.69×10⁻⁶) ≈ 33.9 кГц

R_tot = 0.08 + 0.005 = 0.085 Ом
Q = (1 / 0.085) · √(2.2×10⁻⁶ / 10×10⁻⁶) = 11.76 · 0.469 ≈ 5.51   [Небезпека: Q >> 0.707]

Пік підсилення завад: |H(f_res)| ≈ 5.51 (+14.8 дБ)

R_total_min = √(2 · 2.2×10⁻⁶ / 10×10⁻⁶) = √0.44 ≈ 0.663 Ом
R_damp_needed = 0.663 - 0.085 = 0.578 Ом
```
**Інженерний висновок:** Недемпфований керамічний фільтр має резонансний сплеск добротності `Q = 5.51` на частоті 33.9 кГц, підсилюючи низькочастотний шум живлення на +14.8 дБ. Для усунення сплеску паралельно кераміці необхідно встановити танталовий конденсатор `10 мкФ` з `ESR = 0.8 Ом`.

### Практичні інженерні пастки при вимірюванні та налагодженні

1. **Пастка 1: Вимірювання генератора стандартним щупом осцилографа.**
   Стандартний пасивний щуп осцилографа з дільником 1:10 має власний вхідний імпеданс `10 МОм` та вхідну ємність `C_probe = 10...15 пФ`. Підключення такого щупа до виводу `OSC_IN` чи `OSC_OUT` паралельно навантажувальному конденсатору 18 пФ миттєво збільшує сумарну ємність контуру майже вдвічі. У результаті:
   * Високочастотний генератор HSE зміщує частоту вниз на сотні ppm;
   * Годинниковий генератор LSE 32.768 кГц миттєво зриває генерацію через падіння коефіцієнта запасу підсилення нижче критичного порогу.
   * **Правильне рішення:** Для контролю частоти та форми сигналу програмно налаштовують вихід внутрішнього тактового буфера мікроконтролера (MCO — Microcontroller Clock Output або CLKOUT) на виділений пін GPIO. Якщо ж необхідно дослідити сам контур безпосередньо, застосовують активний диференціальний або польовий FET-пробник із власною ємністю `< 0.5 пФ` та опором `> 100 МОм`.

2. **Пастка 2: Діелектрична абсорбція конденсаторів антиаліасингового фільтра.**
   У мультиплексованих вимірювальних трактах (де один АЦП опитує кілька каналів по черзі) застосування керамічних конденсаторів з діелектриком X7R або X5R у ролі `C_ext` викликає ефект діелектричної абсорбції (англ. *Dielectric Absorption / Soakage*). Сегнетоелектричний матеріал діелектрика поляризується під дією напруги попереднього каналу (наприклад, 3.3 В) і повільно релаксує, інжектуючи залишковий заряд при перемиканні на наступний низьковольтний канал (наприклад, 0.05 В). Виникає міжканальне перехресне проникнення сигналу (англ. *crosstalk*), яке неможливо відфільтрувати програмно. Для всіх прецизійних кіл АЦП обов'язковим є використання конденсаторів з діелектриком класу I (C0G/NP0) або плівкових поліпропіленових конденсаторів.

3. **Пастка 3: Струмове насичення феритової намистини.**
   У багатьох паспортах на феритові намистини графік імпедансу `Z(f)` наводиться за відсутності постійного струму (`I_dc = 0`). Проте при протіканні постійного струму живлення аналогового домену (`I_dc = 50...200 мА`) магнітний сердечник фериту зазнає часткового підмагнічування. Внаслідок цього його ефективна індуктивність та імпеданс на частотах завад падають на 40–80%. При виборі компонента слід обирати намистини з номінальним робочим струмом (Rated Current), що щонайменше у 2–3 рази перевищує максимальне споживання аналогового домену.

### Діагностичний довідник інженерних несправностей (Troubleshooting Guide)

| Симптом несправності на платі | Фізична першопричина дефекту | Інженерний метод локалізації та усунення |
|---|---|---|
| **Генератор HSE працює при +25 °C, але зривається при -40 °C** | Недостатній коефіцієнт запасу підсилення (`Gain Margin < 5.0`) через зростання `ESR` або зниження `g_m` | Зменшити номінали `C_1, C_2` або переключити в регістрах MCU режим драйвера на максимальну крутизну (High Drive Mode) |
| **Кварц генерує на третій гармоніці (48 МГц замість 16 МГц)** | Відсутність або занижений номінал демпфуючого резистора `R_d`, що призводить до перезбудження | Збільшити номінал послідовного резистора `R_d` до розрахункового значення `1 / (2π f C_2)` (470 Ом) |
| **Зміщення частоти HSE на +150 ppm (збій USB/CAN)** | Фактична ємність навантаження менша за паспортну через невраховану малу ємність `C_1, C_2` | Збільшити ємність зовнішніх конденсаторів `C_1, C_2` на `3...5 пФ` |
| **Годинник RTC відстає або зупиняється у вологій камері** | Поверхневий витік струму крізь іонні залишки флюсу на високоомному вході `OSC32_IN` | Додати охоронне кільце Guard Ring, ретельно відмити плату в ультразвуковій ванні та покрити вологозахисним лаком |
| **Шум та дрейф молодших розрядів АЦП при роботі DC-DC** | Резонансний сплеск добротності `Q > 2` на феритовому фільтрі `VDDA` біля частоти ШІМ | Задемпфувати контур фериту шляхом додавання паралельного танталового конденсатора з `ESR = 0.5...1.0 Ом` |
| **Втрата ефективної розрядності АЦП (ENOB) при високих SPS** | Час фази вибірки `t_acq` менший за постійну часу `(N+1)·ln(2)·τ` через високий опір джерела | Збільшити час вибірки `SMPR` у конфігурації АЦП або встановити перед входом швидкий буферний ОП із резистором `R_iso` |
| **Стрибок коду АЦП при комутації сусіднього каналу** | Недостатня зовнішня ємність `C_ext < 20·C_sample` або діелектрична абсорбція X7R кераміки | Збільшити ємність `C_ext` до 1–2.2 нФ і замінити тип діелектрика на ультрастабільний C0G/NP0 |
| **Паразитне фазове тремтіння (Jitter) тактового сигналу** | Цифрові траси (SPI, PWM, Flash) проходять на внутрішніх шарах під кварцовим резонатором | Ввести суцільну зону заборони Keep-Out під кварцом на всіх шарах і забезпечити нерозривну землю на L2 |
