# ⚙️ Калькулятор диференційного імпедансу мікросмужкових та копланарних ліній

## 1. Постановка фізичної задачі електродинаміки спряжених провідників

У швидкісній цифровій та надвисокочастотній схемотехніці забезпечення цілісності сигналів (Signal Integrity) безпосередньо залежить від точності розрахунку характеристичних та модальних хвильових опорів друкованих провідників. Будь-яка геометрична неузгодженість поперечного перерізу лінії передачі або розрив опорного шару викликає стрибок хвильового імпедансу, відбиття імпульсів, фазовий розрив та паразитне перетворення корисної протифазної енергії в синфазне випромінювання.

Електродинамічний розрахунок симетричної системи двох паралельних провідників полягає у відшуканні просторового розподілу електромагнітного поля в поперечному перерізі лінії `(x, y)`. На частотах, де геометричні розміри поперечного перерізу плати (ширина доріжок `w`, міжосьовий зазор `s`, товщина діелектрика `h`) значно менші за мінімальну довжину хвилі сигналу в діелектричному середовищі (`w, s, h << λ`), структура електромагнітного поля повністю відповідає квазі-ТЕМ наближенню (Transverse Electro-Magnetic Mode).

Для типових друкованих плат із товщиною діелектрика `h = 0.1` мм та шириною доріжок `w = 0.15` мм критична частота виникнення вищих поперечних хвилеводних мод (таких як моди `TE_10` або `TM_10`) перевищує 150–200 ГГц. Це означає, що для всіх сучасних високошвидкісних інтерфейсів (включно з PCIe Gen5/Gen6, USB4 та 112G PAM4) поздовжні складові електричного та магнітного полів `E_z` та `H_z` є нехтовно малими порівняно з поперечними складовими `E_t` та `H_t`. У результаті просторовий розподіл електричного потенціалу `Φ(x, y)` описується двовимірним стаціонарним рівнянням Лапласа для неоднорідного діелектричного простору:

```
∇ · [ ε_r(x, y) · ∇Φ(x, y) ] = 0
```

У розгорнутій декартовій системі координат це диференційне рівняння другого порядку в частинних похідних має вигляд:

```
∂/∂x [ ε_r(x, y) · ∂Φ(x, y)/∂x ] + ∂/∂y [ ε_r(x, y) · ∂Φ(x, y)/∂y ] = 0
```

де `ε_r(x, y)` — просторова функція відносної діелектричної проникності матеріалів друкованої плати. У межах одного поперечного перерізу ця функція набуває різних сталих значень:
* `ε_r(x, y) = ε_sub` — усередині шару склотекстолітової підкладки (наприклад, `ε_sub ≈ 4.1` для FR-4 чи `ε_sub ≈ 3.48` для Rogers RO4350B);
* `ε_r(x, y) = ε_mask` — у шарі конформного захисного покриття рідкої паяльної маски (`ε_mask ≈ 3.3–3.8`);
* `ε_r(x, y) = ε_air = 1.0` — у вільному повітряному просторі над поверхнею друкованої плати.

Двовимірна розрахункова область містить такі фізичні межі та крайові умови:
1. **Опорний шар землі (Ground Plane, `y = 0`):** нижня межа являє собою суцільний металевий полігон, який вважається ідеальним провідником із нульовим потенціалом (однорідна крайова умова Діріхле першого роду `Φ(x, 0) = 0` В).
2. **Контури сигнальних провідників:** металеві прямокутні або трапецієподібні перерізи провідників прямого `D+` та інверсного `D-` сигналів товщиною `t`, на яких задаються дискретні потенціали збудження відповідно до досліджуваної моди:
   * **Непарний режим (Odd Mode, протифазна хвиля):** провідник 1 збуджується потенціалом `Φ_1 = +1.0` В, а провідник 2 — потенціалом `Φ_2 = -1.0` В.
   * **Парний режим (Even Mode, синфазна хвиля):** провідник 1 збуджується потенціалом `Φ_1 = +1.0` В, а провідник 2 — потенціалом `Φ_2 = +1.0` В.
3. **Штучні зовнішні межі розрахункового боксу:** верхня та бічні стінки розрахункової області відносять на значну відстань від провідників (`x_max ≥ 5 · h`, `y_max ≥ 5 · h`). На такій відстані напруженість поля спадає до мізерних величин, що дозволяє встановити крайову умову Діріхле `Φ = 0` або природну умову Неймана другого роду `∂Φ/∂n = 0` (відсутність нормального потоку вектора електричного зміщення).

## 2. Теорія багатопровідникових ліній зв'язку та матричний опис

У системі зв'язаних ліній передачі електричні процеси описуються векторними матричними телеграфними рівняннями. Для системи з двох паралельних провідників над спільною площиною землі вектори напруг `V(z) = [V_1(z), V_2(z)]^T` та струмів `I(z) = [I_1(z), I_2(z)]^T` пов'язані матрицями погонних параметрів:

```
-d V(z) / dz = [R + j·ω·L] · I(z)
-d I(z) / dz = [G + j·ω·C] · V(z)
```

Для ліній без омічних втрат у міді та діелектрику (`[R] = [0]`, `[G] = [0]`) стан системи повністю визначається симетричною матрицею погонних індуктивностей `[L]` та симетричною матрицею погонних ємностей `[C]`:

```
[L] = [ L_11   L_12 ]       [C] = [  C_11  -C_12 ]
      [ L_12   L_22 ]             [ -C_12   C_22 ]
```

де елементи матриць мають строгий фізичний зміст:
* `L_11 = L_22 = L_0` — власна погонна індуктивність одиночного провідника відносно контуру повернення струму землі;
* `L_12 = L_m` — взаємна магнітна індуктивність зв'язку між двома провідниками;
* `C_11 = C_22 = C_0 + C_m` — сумарна ємність провідника на землю та сусідній провідник (діагональний елемент матриці Максвелла);
* `C_12 = C_m` — взаємна ємність прямого ємнісного зв'язку між двома доріжками через бічний зазор `s`;
* `C_0` — власна ємність доріжки безпосередньо на нижню опорну площину землі.

Оскільки недіагональні елементи матриць відмінні від нуля (`L_m ≠ 0`, `C_m ≠ 0`), проходження сигналу по одному провіднику неминуче індукує перехресну напругу та струм на сусідньому провіднику.

Для діагоналізації системи рівнянь використовують модальне перетворення. Ортогональна матриця переходу перетворює фізичні вектори напруг `[V_1, V_2]^T` у модальні напруги `[V_odd, V_even]^T`. В результаті фізична пара зв'язаних ліній розпадається на дві абсолютно незалежні віртуальні лінії передачі:

### 1. Непарна мода (Odd Mode)
Непарна мода відповідає чистому диференційному сигналу: напруги на провідниках протифазні `V_1 = -V_2 = V_diff / 2`, а струми рівні та протилежні за напрямком `I_1 = -I_2`.
У площині симетрії системи утворюється віртуальна земля з нульовим потенціалом електричного поля `Φ = 0`.
Лінії електричного поля щільно концентруються безпосередньо між бічними гранями провідників у зазорі `s`. Напруженість поля в зазорі досягає максимуму `E_max ≈ V_diff / s`.

Модальні параметри непарного режиму набувають вигляду:
```
L_odd = L_0 - L_m
C_odd = C_0 + 2 · C_m
Z_odd = √( L_odd / C_odd ) = √( (L_0 - L_m) / (C_0 + 2 · C_m) )
```
Диференційний хвильовий опір пари провідників дорівнює подвоєному непарному імпедансу:
```
Z_diff = 2 · Z_odd = 2 · √( (L_0 - L_m) / (C_0 + 2 · C_m) )
```

### 2. Парна мода (Even Mode)
Парна мода відповідає синфазному збудженню або зовнішній заваді: напруги на провідниках синфазні `V_1 = V_2 = V_comm`, а струми течуть в одному напрямку `I_1 = I_2`.
У площині симетрії системи утворюється віртуальна магнітна стінка з нульовим нормальним градієнтом електричного поля `∂Φ / ∂x = 0`.
Лінії електричного поля відштовхуються одна від одної і замикаються виключно на нижній опорний шар землі `y = 0`. Ємнісний зв'язок між доріжками повністю вимикається, а магнітні потоки додаються, що призводить до зростання погонної індуктивності.

Модальні параметри парного режиму:
```
L_even = L_0 + L_m
C_even = C_0
Z_even = √( L_even / C_even ) = √( (L_0 + L_m) / C_0 )
```
Синфазний хвильовий опір пари становить половину парного імпедансу:
```
Z_comm = 0.5 · Z_even = 0.5 · √( (L_0 + L_m) / C_0 )
```

## 3. Математична дискретизація методом скінченних різниць (FDM)

Для чисельного розв'язання рівняння Лапласа двовимірну область розбивають рівномірною прямокутною просторовою сіткою з кроками `Δx` та `Δy`. Вузли сітки позначаються цілочисельними індексами `(i, j)`, де просторові координати дорівнюють `x = i · Δx` та `y = j · Δy`.

Для коректного зшивання полів на межах розділу двох діелектриків із різними значеннями `ε_r` безпосереднє застосування класичного оператора Лапласа `∇²Φ = 0` є неприпустимим через розрив першої похідної потенціалу. Замість цього застосовують інтегральний метод балансу потоків (метод контрольного об'єму). Навколо кожного внутрішнього вузла `(i, j)` виділяють елементарну прямокутну комірку площею `Δx · Δy`. За теоремою Гауса, сумарний потік вектора електричного зміщення `D = ε_0 · ε_r · E` крізь чотири замкнені бічні грані цієї комірки строго дорівнює нулю за відсутності вільних зарядів у діелектрику:

```
∮_S ( ε_r(r) · ∇Φ · n ) dS = 0
```

Апроксимуючи похідні центральними різницями першого порядку на серединах граней комірки, отримуємо консервативне п'ятиточкове різницеве рівняння:

```
ε_right · [ (Φ(i+1, j) - Φ(i, j)) / Δx ] · Δy +
ε_left  · [ (Φ(i-1, j) - Φ(i, j)) / Δx ] · Δy +
ε_top   · [ (Φ(i, j+1) - Φ(i, j)) / Δy ] · Δx +
ε_bottom· [ (Φ(i, j-1) - Φ(i, j)) / Δy ] · Δx = 0
```

Для квадратної сітки (`Δx = Δy = h_step`) вираз перетворюється на канонічну різницеву форму для обчислення потенціалу вузла `Φ(i, j)`:

```
Φ(i, j) = [ ε_right·Φ(i+1, j) + ε_left·Φ(i-1, j) + ε_top·Φ(i, j+1) + ε_bottom·Φ(i, j-1) ] / Σ_ε
```

де сума діелектричних ваг становить:

```
Σ_ε = ε_right + ε_left + ε_top + ε_bottom
```

Ефективні діелектричні проникності на напівкроках сітки між вузлами обчислюються як середнє арифметичне діелектричних проникностей суміжних комірок:

```
ε_right  = 0.5 · [ ε_r(i, j) + ε_r(i+1, j) ]
ε_left   = 0.5 · [ ε_r(i, j) + ε_r(i-1, j) ]
ε_top    = 0.5 · [ ε_r(i, j) + ε_r(i, j+1) ]
ε_bottom = 0.5 · [ ε_r(i, j) + ε_r(i, j-1) ]
```

Якщо вузол повністю занурений в однорідний матеріал (`ε_right = ε_left = ε_top = ε_bottom = ε_r`), рівняння зводиться до класичного середнього чотирьох сусідів:

```
Φ(i, j) = 0.25 · [ Φ(i+1, j) + Φ(i-1, j) + Φ(i, j+1) + Φ(i, j-1) ]
```

### Аналіз локальної похибки апроксимації
Розкладаючи потенціал у ряд Тейлора в околі вузла `(x_i, y_j)`:
```
Φ(x_i + Δx, y_j) = Φ(x_i, y_j) + Δx · (∂Φ/∂x) + (Δx²/2) · (∂²Φ/∂x²) + (Δx³/6) · (∂³Φ/∂x³) + O(Δx⁴)
Φ(x_i - Δx, y_j) = Φ(x_i, y_j) - Δx · (∂Φ/∂x) + (Δx²/2) · (∂²Φ/∂x²) - (Δx³/6) · (∂³Φ/∂x³) + O(Δx⁴)
```
Сума цих двох виразів скорочує непарні похідні першого та третього порядків:
```
Φ(x_i + Δx, y_j) + Φ(x_i - Δx, y_j) - 2·Φ(x_i, y_j) = Δx² · (∂²Φ/∂x²) + O(Δx⁴)
```
Це строго доводить, що отримана п'ятиточкова різницева схема FDM має другий порядок точності апроксимації `O(Δx² + Δy²)`. При подрібненні кроку сітки вдвічі чисельна похибка обчислення потенціалу та ємності зменшується в 4 рази.

## 4. Математика методу послідовної верхньої релаксації (SOR)

Дискретизація області сіткою розміром `N_x × N_y` вузлів (наприклад, `300 × 200 = 60 000` вузлів) породжує гігантську розріджену лінійну алгебраїчну систему рівнянь вигляду `A · Φ = b`. Матриця системи `A` є симетричною, п'ятидіагональною та строго діагонально домінуючою.

Використання прямих методів розв'язання (метод виключення Гауса, розклад Холецького) для таких розмірностей вимагає гігантського обсягу пам'яті порядку `O(N_x² · N_y)` та мільйонів операцій з плаваючою комою. Найбільш ефективним ітераційним методом для сіткових еліптичних рівнянь є метод послідовної верхньої релаксації (Successive Over-Relaxation, SOR).

На кожній глобальній ітерації `k+1` нове значення потенціалу вузла розраховується шляхом зважування поточного значення з поправкою Гауса-Зейделя через параметр релаксації `ω`:

```
Φ^(k+1)(i, j) = (1.0 - ω) · Φ^(k)(i, j) + ω · Φ_GS(i, j)
```

де проміжне значення за Гаусом-Зейделем `Φ_GS(i, j)` формується з використанням уже оновлених на поточній ітерації значень лівого та нижнього сусідніх вузлів:

```
Φ_GS(i, j) = [ ε_right·Φ^(k)(i+1, j) + ε_left·Φ^(k+1)(i-1, j) + ε_top·Φ^(k)(i, j+1) + ε_bottom·Φ^(k+1)(i, j-1) ] / Σ_ε
```

Діапазон стабільності параметра релаксації згідно з теоремою Островського-Рейха обмежений інтервалом `0 < ω < 2.0`. При `ω = 1.0` метод SOR вироджується у звичайний повільний метод Гауса-Зейделя, який вимагає тисяч кроків для поширення крайових потенціалів через усю сітку.

Для прямокутної розрахункової області розміром `N_x × N_y` вузлів оптимальне теоретичне значення параметра релаксації `ω_opt`, що мінімізує спектральний радіус матриці переходу та максимізує швидкість збіжності, визначається виразом:

```
μ_J = 0.5 · [ cos( π / N_x ) + cos( π / N_y ) ]
ω_opt = 2.0 / [ 1.0 + √( 1.0 - μ_J² ) ]
```

Застосування `ω_opt` (яке для сітки `300 × 200` становить близько `1.94–1.96`) прискорює процес досягнення заданої точності у 30–60 разів, скорочуючи час розрахунку до 50–100 мілісекунд на сучасному процесорі.

Ітераційний процес припиняється за умови досягнення максимальної похибки зміни потенціалу по всіх вільних вузлах сітки нижче порогу точності:

```
max_{i, j} | Φ^(k+1)(i, j) - Φ^(k)(i, j) | < ε_tol   (де ε_tol = 10⁻⁶ В)
```

### Спектральний аналіз та Червоно-Чорна схема Red-Black SOR
Для розпаралелювання обчислень на багатоядерних процесорах вузли сітки розбивають на два класи за шаховим принципом:
1. «Червоні» вузли: координати задовольняють умову `(i + j) mod 2 = 0`.
2. «Чорні» вузли: координати задовольняють умову `(i + j) mod 2 = 1`.

Оскільки п'ятиточковий шаблон для будь-якого червоного вузла спирається виключно на значення чотирьох сусідніх чорних вузлів, обчислення всіх червоних вузлів є повністю незалежним. Це усуває стан гонитви даних (Data Race) і дозволяє виконувати розрахунок паралельно на всіх ядрах CPU за допомогою векторних інструкцій AVX2 / AVX-512 без блокувань пам'яті.

## 5. Контурне інтегрування за теоремою Гауса та двоетапний метод вакуумізації

Після розрахунку просторового розподілу потенціалів `Φ(x, y)` необхідно вилучити електричний заряд `Q`, зосереджений на одиниці поздовжньої довжини сигнального провідника. Для цього навколо прямокутного профілю лівого провідника 1 будують замкнений прямокутний контур інтегрування `Γ`.

Повний погонний електричний заряд `Q` (у Кулонах на метр, Кл/м) обчислюють чисельним інтегруванням нормального потоку вектора електричного зміщення `D_n = ε_0 · ε_r · E_n = -ε_0 · ε_r · (∂Φ / ∂n)` уздовж контуру `Γ`:

```
Q = ∮_Γ ε_0 · ε_r(x, y) · [ -∂Φ(x, y) / ∂n ] · dl
```

де `ε_0 = 8.8541878128 · 10⁻¹²` Ф/м — фундаментальна електрична стала вакууму.

Чисельна апроксимація контурного інтеграла Гауса на прямокутній сітці з кроками `Δx` та `Δy` розпадається на суму чотирьох лінійних сегментів:
1. **Нижній горизонтальний сегмент (`y = y_bottom`, нормаль вниз):**
   ```
   Q_bottom = ε_0 · Σ_{i = x1}^{x2} ε_mid,y1 · [ (Φ(i, y1) - Φ(i, y1 - 1)) / Δy ] · Δx
   ```
2. **Верхній горизонтальний сегмент (`y = y_top`, нормаль вгору):**
   ```
   Q_top = ε_0 · Σ_{i = x1}^{x2} ε_mid,y2 · [ (Φ(i, y2) - Φ(i, y2 + 1)) / Δy ] · Δx
   ```
3. **Лівий вертикальний сегмент (`x = x_left`, нормаль вліво):**
   ```
   Q_left = ε_0 · Σ_{j = y1}^{y2} ε_mid,x1 · [ (Φ(x1, j) - Φ(x1 - 1, j)) / Δx ] · Δy
   ```
4. **Правий вертикальний сегмент (`x = x_right`, нормаль вправо):**
   ```
   Q_right = ε_0 · Σ_{j = y1}^{y2} ε_mid,x2 · [ (Φ(x2, j) - Φ(x2 + 1, j)) / Δx ] · Δy
   ```

Сумарний заряд провідника становить:

```
Q = Q_bottom + Q_top + Q_left + Q_right
```

Важливо відзначити, що контур інтегрування `Γ` ніколи не проводять безпосередньо по металевій поверхні провідника, оскільки на прямокутних кутах виникає сингулярність градієнта поля (нескінченна напруженість електричного поля на гострому куті ідеального провідника). Відступ контуру на 2–4 кроки сітки вглиб діелектрика гарантує високу точність обчислення інтеграла завдяки гладкості функції потенціалу.

### Двоетапна процедура вилучення параметрів [C] та [L]

Оскільки фазова швидкість електромагнітної хвилі в неоднорідному середовищі є модально-залежною, прямий розрахунок матриці індуктивностей `[L]` через класичні магнітні потенціали є обчислювально складним. Натомість використовують фундаментальну теорему електродинаміки про незалежність індуктивності від немагнітних діелектриків (`μ_r = 1.0`). Матриця індуктивностей лінії зв'язку строго пов'язана з матрицею ємностей у вакуумі `[C_0]`:

```
[L] = μ_0 · ε_0 · [C_0]⁻¹ = (1.0 / c²) · [C_0]⁻¹
```

Алгоритм повного двоетапного розрахунку:

1. **Етап 1: Розрахунок у реальному діелектричному середовищі.**
   * Задають реальні діелектричні проникності підкладки `ε_sub` та паяльної маски `ε_mask`.
   * **Непарна мода (Odd):** встановлюють потенціали `Φ_1 = +1.0` В, `Φ_2 = -1.0` В. Розраховують заряд `Q_odd` та знаходять непарну погонну ємність:
     ```
     C_odd = Q_odd / (Φ_1 - 0) = Q_odd   [Ф/м]
     ```
   * **Парна мода (Even):** встановлюють потенціали `Φ_1 = +1.0` В, `Φ_2 = +1.0` В. Розраховують заряд `Q_even` та отримують парну погонну ємність:
     ```
     C_even = Q_even / (Φ_1 - 0) = Q_even   [Ф/м]
     ```

2. **Етап 2: Розрахунок в однорідному вакуумі.**
   * Усі матеріали замінюють вакуумом: `ε_r(x, y) = 1.0` по всій розрахунковій сітці.
   * Виконуючи аналогічні ітерації для непарного та парного збуджень, обчислюють вакуумні ємності: `C_odd,0` та `C_even,0`.

3. **Етап 3: Синтез хвильових та модальних параметрів лінії.**
   * Модальні погонні індуктивності:
     ```
     L_odd  = 1.0 / ( c² · C_odd,0 )   [Гн/м]
     L_even = 1.0 / ( c² · C_even,0 )  [Гн/м]
     ```
   * Ефективні діелектричні проникності для кожної моди:
     ```
     ε_eff,odd  = C_odd / C_odd,0
     ε_eff,even = C_even / C_even,0
     ```
   * Фазові швидкості поширення хвиль:
     ```
     v_prop,odd  = c / √( ε_eff,odd )
     v_prop,even = c / √( ε_eff,even )
     ```
   * Модальні характеристичні імпеданси:
     ```
     Z_odd  = √( L_odd / C_odd )   = 1.0 / ( c · √( C_odd · C_odd,0 ) )
     Z_even = √( L_even / C_even ) = 1.0 / ( c · √( C_even · C_even,0 ) )
     ```
   * Фінальний диференційний та синфазний хвильовий опір:
     ```
     Z_diff = 2.0 · Z_odd
     Z_comm = 0.5 · Z_even
     ```
   * Фазовий перекіс дальнього кінця (Far-End Skew / FEXT) на один метр довжини траси:
     ```
     t_skew = | 1.0 / v_prop,odd - 1.0 / v_prop,even |   [пс / метр]
     ```

## 6. Фізика та моделювання впливу захисної паяльної маски

Паяльна маска (Solder Mask) є рідким або плівковим термореактивним полімером, який наноситься на зовнішні шари друкованої плати для захисту мідних провідників від окиснення та запобігання утворенню припійних містків під час монтажу компонентів.

Типова товщина шару маски над поверхнею міді становить `t_mask = 15–25` мкм, а в бічних зазорах між близько розташованими провідниками рідка маска затікає, повністю або частково заповнюючи простір між трасами. Відносна діелектрична проникність затверділої паяльної маски коливається в межах `ε_mask ≈ 3.3–3.8`, що в 3.5 рази перевищує проникність повітря (`ε_air = 1.0`).

Фізичні наслідки нанесення маски на диференційну мікросмужку:
1. **Зростання взаємної ємності `C_m`:** оскільки в непарному режимі значна частка ліній електричного поля замикається між бічними гранями провідників пари крізь зазор `s`, поява полімеру з високою діелектричною проникністю замість повітря викликає різке збільшення ємності зв'язку `C_m`.
2. **Падіння диференційного імпедансу:** збільшення ємності `C_odd = C_0 + C_m` призводить до неминучого падіння хвильового опору `Z_diff = 2 / (c · √(C_odd · C_odd,0))`. Для типових швидкісних пар (наприклад, USB 90 Ом або PCIe 100 Ом) падіння становить від 2.5 до 5.5 Ом (близько 3–6%).
3. **Збільшення дисперсії фазових швидкостей:** маска сильніше збільшує непарну проникність `ε_eff,odd`, ніж парну `ε_eff,even`, що збільшує фазовий перекіс між модами і посилює перехресну заваду FEXT.

Програмний чисельний розв'язувач FDM у кожному розрахунку точно відтворює двошаровий діелектричний профіль (підкладка + шар маски потрібної товщини), що дозволяє фабрикам та розробникам синтезувати ширину доріжок із компенсацією впливу маски без потреби у виготовленні дорогих попередніх прототипів.

## 7. Моделі конформних відображень для смужкових ліній (Stripline за Коном)

Для внутрішніх сигнальних шарів друкованої плати провідники затиснуті між двома паралельними нескінченними площинами землі на відстані `B` одна від одної. Таке середовище є абсолютно однорідним (`ε_r(x, y) = ε_sub = \text{const}`), що ліквідує дисперсію фазових швидкостей (`v_odd = v_even = c / √ε_r`) та повністю пригнічує перехресну заваду FEXT.

Класичне аналітичне розв'язання задачі зв'язаних смужкових ліній було отримано Сеймуром Коном (Seymour B. Cohn) у 1955 році за допомогою методу конформних відображень Шварца-Крістоффеля через повні еліптичні інтеграли першого роду `K(k)`.

Для нульової товщини фольги (`t = 0`) характеристичні імпеданси парного `Z_even` та непарного `Z_odd` режимів зв'язаної смужкової лінії мають строгий аналітичний вигляд:

```
Z_even = ( 30.0 · π / √(ε_r) ) · [ K'(k_e) / K(k_e) ]
Z_odd  = ( 30.0 · π / √(ε_r) ) · [ K'(k_o) / K(k_o) ]
```

де геометричні модулі еліптичних інтегралів визначаються через гіперболічні функції відношення розмірів до висоти між площинами `B`:

```
k_e = tanh( π · w / (2.0 · B) ) · coth( π · (w + s) / (2.0 · B) )
k_o = tanh( π · w / (2.0 · B) ) · tanh( π · (w + s) / (2.0 · B) )
```

Для врахування скінченної товщини фольги `t > 0` Кон запропонував еквівалентне збільшення ширини доріжки `w` на величину крайової поправки `Δw_t`:

```
Δw_t = (B / π) · [ ( 2.0 / (1.0 - t/B) ) · ln( 1.0 + 1.0 / (1.0 - t/B) ) - ( (1.0 / (1.0 - t/B) - 1.0) ) · ln( 1.0 / ( (1.0 - t/B)² - 1.0 ) ) ]
```

Ці формули забезпечують похибку розрахунку імпедансу менше 0.5% для будь-яких практичних конфігурацій смужкових ліній.

## 8. Моделювання копланарного хвилеводу з землею (CBCPW) та аналітика Хілберга

Для копланарної лінії з бічною землею на зазорі `g` та нижньою площиною землі на висоті `h` аналітичний розрахунок базується на відношенні повних еліптичних інтегралів першого роду `K(k) / K'(k)`.

Апроксимація Хілберга для відношення еліптичних інтегралів:

```
k' = √( 1.0 - k² )

Якщо 0 <= k <= 1/√2:
  K(k) / K'(k) = π / ln( 2.0 · (1.0 + √(k')) / (1.0 - √(k')) )

Якщо 1/√2 < k <= 1.0:
  K(k) / K'(k) = (1.0 / π) · ln( 2.0 · (1.0 + √k) / (1.0 - √k) )
```

Модулі конформного відображення для копланара з нижньою землею:

```
k_1 = w / ( w + 2.0 · g )
k_2 = sinh( π · w / (4.0 · h) ) / sinh( π · (w + 2.0 · g) / (4.0 · h) )
```

Ефективна діелектрична проникність та хвильовий опір CPWG:

```
ε_eff,cpwg = 1.0 + 0.5 · (ε_r - 1.0) · [ K'(k_1) · K(k_2) ] / [ K(k_1) · K'(k_2) ]
Z_0,cpwg = ( 60.0 · π / √(ε_eff,cpwg) ) / [ K(k_1)/K'(k_1) + K(k_2)/K'(k_2) ]
```

У FDM-моделі копланара вузли бічної землі встановлюються під нульовим потенціалом `Φ = 0` В на координатах `x ≤ x_gnd_left` та `x ≥ x_gnd_right`, що дозволяє розв'язувачу точно враховувати перерозподіл бічних крайових полів між доріжками та екранами.

## 9. Аналіз перехресних завад NEXT та FEXT у модальних матрицях

У високошвидкісних системах паралельні диференційні лінії взаємодіють між собою через паразитні ємності та взаємні індуктивності. При поширенні сигналу по активній лінії (Aggressor) на сусідній пасивній лінії (Victim) наводяться два типи шумів:
1. **Ближня перехресна завада (Near-End Crosstalk, NEXT):** поширюється у зворотному напрямку, до передавача пасивної лінії.
2. **Дальня перехресна завада (Far-End Crosstalk, FEXT):** поширюється у прямому напрямку, разом із основним сигналом до приймача.

Амплітудні коефіцієнти перехресних зв'язків виражаються через елементи погонних матриць `[L]` та `[C]`:

```
K_NEXT = 0.25 · [ (C_m / C_0) + (L_m / L_0) ]
K_FEXT = 0.50 · [ (C_m / C_0) - (L_m / L_0) ]
```

В ідеально однорідному діелектричному середовищі (смужкова лінія всередині плати) електромагнітне поле має суто ТЕМ-структуру, для якої коефіцієнт ємнісного зв'язку строго дорівнює коефіцієнту індуктивного зв'язку:

```
C_m / C_0 = L_m / L_0
```

У результаті для смужкових ліній коефіцієнт дальньої перехресної завади теоретично дорівнює нулю:

```
K_FEXT ≡ 0
```

У мікросмужкових лініях на поверхні плати через неоднорідність діелектрика (повітря зверху і склотекстоліт знизу) рівність порушується (`C_m / C_0 ≠ L_m / L_0`), що породжує виражену заваду FEXT у формі вузького імпульсу, амплітуда якого прямо пропорційна швидкості наростання сигналу `dV/dt` та фізичній довжині спільного пробігу ліній.

## 10. Моделювання шорсткості мідної фольги: моделі Хаммерштада та Хурея

На високих частотах (понад 2–5 ГГц) струм витісняється до поверхні провідника внаслідок скін-ефекту. Товщина скін-шару `δ(f)` стає меншою за середньоквадратичну висоту мікронерівностей фольги `R_q` (типово 1.5–3.0 мкм для стандартної фольги типу Standard Electrodeposited, STD).

Звивиста траєкторія ліній струму навколо зубців шорсткості збільшує ефективний омічний опір та діелектричні втрати. Для врахування цього явища використовують дві моделі:

### 1. Модель Хаммерштада (Hammerstad)
Коефіцієнт збільшення втрат виражається через середньоквадратичну шорсткість `R_q` та товщину скін-шару `δ(f)`:

```
K_Hammerstad(f) = 1.0 + (2.0 / π) · arctan( 1.4 · ( R_q / δ(f) )² )
```

Надзвичайно проста модель Хаммерштада має фундаментальне фізичне обмеження: при дуже високих частотах (`δ << R_q`) коефіцієнт насичується на теоретичній межі `K = 2.0` (збільшення втрат не більше ніж удвічі).

### 2. Модель снігових кульок Хурея (Huray Snowball Model)
Для точного опису втрат на частотах 10–56 ГГц застосовують модель Хурея, яка представляє мікроструктуру мідного дендрита у вигляді пірамід із кластерів провідних сфер радіуса `a ≈ 0.5–1.5` мкм:

```
K_Huray(f) = 1.0 + ( A_rough / A_flat ) / [ 1.0 + δ(f) / a + 0.5 · ( δ(f) / a )² ]
```

де `A_rough / A_flat` — відношення реальної площі шорсткої поверхні до гладкої площі (типово від 1.5 до 3.5 для профілів VLP та RTF). Модель Хурея точно збігається з експериментальними вимірюваннями на векторних аналізаторах кіл VNA аж до 110 ГГц.

## 11. Дисперсія діелектрика: широкосмугова модель Дебая та співвідношення Крамерса-Кроніга

На надвисоких швидкостях передачі даних (28–112 Гбіт/с) діелектрична проникність матеріалів друкованої плати `ε_r(f)` та тангенс кута втрат `tan δ(f)` перестають бути сталими величинами.

Реальна діелектрична проникність є комплексною функцією частоти `ω = 2 · π · f`:

```
ε*(ω) = ε'(ω) - j · ε''(ω) = ε_0 · ε_r(ω) · [ 1.0 - j · tan δ(ω) ]
```

Для забезпечення фізичної каузальності (причинності) часового відгуку швидкісного каналу дійсна `ε'(ω)` та уявна `ε''(ω)` частини діелектричної проникності повинні строго задовольняти інтегральним співвідношенням Крамерса-Кроніга:

```
ε'(ω) - ε_∞ = (2 / π) · P.V. ∫_0^∞ [ ( u · ε''(u) ) / ( u² - ω² ) ] du
ε''(ω) = -(2 · ω / π) · P.V. ∫_0^∞ [ ( ε'(u) - ε_∞ ) / ( u² - ω² ) ] du
```

Якщо при симуляції швидкісної лінії в діапазоні від 100 МГц до 50 ГГц використовувати некаузальну модель зі сталим діелектриком (`ε_r = \text{const}`), зворотне перетворення Фур'є породить нефізичний відгук: сигнал почне наростати на виході приймача ще **до** того, як вхідний імпульс буде подано на вхід передавача (явище некаузального передзвону, Pre-cursor Ringing).

Для усунення цього артефакту застосовують широкосмугову модель Дебая (модель Свенсона-Джорджевича):

```
ε_r(f) = ε_∞ + ( Δε / ln( f_high / f_low ) ) · ln( ( f_high + j · f ) / ( f_low + j · f ) )
```

де `f_low ≈ 1` кГц, `f_high ≈ 100` ГГц, а `Δε` та `ε_∞` калібруються за фабричним значенням `ε_r` на опорній частоті 1 ГГц.

## 12. Вплив температури: термодрейф діелектрика (TCDk)

При експлуатації електронних пристроїв у розширеному температурному діапазоні (від `-40°C` до `+125°C` для автомобільної електроніки або промислових серверів) діелектрична проникність підкладки зазнає теплового дрейфу.

Температурний коефіцієнт діелектричної проникності (Thermal Coefficient of Dielectric Constant, TCDk) вимірюється в мільйонних частках на градус Цельсія (ppm/°C):

```
TCDk = ( 1.0 / ε_r(T_0) ) · [ d ε_r(T) / dT ] · 10⁶   [ppm/°C]
```

Для стандартного недорогого матеріалу FR-4 коефіцієнт TCDk є значно від'ємним і становить від `-300` до `-450` ppm/°C. Це означає, що при нагріванні плати від кімнатної температури `+25°C` до робочої температури під навантаженням `+85°C` (`ΔT = +60°C`) діелектрична проникність FR-4 зменшується з 4.10 до 3.98:

```
Δε_r ≈ 4.10 · ( -400 · 10⁻⁶ ) · 60 ≈ -0.10
```

Зниження `ε_r` викликає зміну хвильового імпедансу: для диференційної пари 90 Ом імпеданс дрейфує вгору на `+1.8–2.5` Ом, а фазова затримка поширення сигналу скорочується на 1.5%.

У прецизійних радіочастотних та високошвидкісних системах (радари 77 ГГц, PCIe Gen5/Gen6) застосовують термостабільні ламінати з керамічним наповненням (наприклад, Rogers RO4350B з `TCDk = +40` ppm/°C або Panasonic Megtron 6 з `TCDk = -60` ppm/°C), що гарантує збереження форми сигнального ока в усьому робочому діапазоні температур.

## 13. Ефект плетіння скловолокна (Fiber-Weave Effect)

Багатошарові ламінати друкованих плат складаються зі скляної тканини (E-Glass або Low-Dk Glass), просоченої епоксидною смолою. Склонитки мають відносно високу діелектричну проникність (`ε_glass ≈ 6.6`), тоді як чиста епоксидна смола має низьку проникність (`ε_resin ≈ 3.0`).

Якщо провідник `D+` диференційної пари прокладається точно над щільним пучком склониток (`ε_eff ≈ 4.0`), а сусідній інверсний провідник `D-` потрапляє в зазор між нитками, заповнений чистою смолою (`ε_eff ≈ 3.3`), між провідниками виникає фазовий перекіс швидкостей (Fiber-Weave Skew):

```
Δt_skew = ( L / c ) · [ √( ε_eff,1 ) - √( ε_eff,2 ) ]
```

На трасі довжиною `L = 20` см різниця затримок досягає 20–30 пікосекунд. Для інтерфейсів зі швидкістю 28–56 Гбіт/с (де тривалість бітового інтервалу становить всього 18–35 пс) такий перекіс призводить до повного руйнування диференційного сигналу та неможливості відновлення тактової частоти блоком CDR.

Інженерні методи боротьби з ефектом плетіння:
1. **Трасування під кутом до плетіння (Angled / Zig-zag Routing):** прокладання трас під технологічним кутом 10°–15° до осі склотканини гарантує, що обидва провідники пари періодично перетинають однакову кількість ниток і смоляних кишень.
2. **Використання розправленого скловолокна (Spread Glass Cloth):** застосування тканин марок 1067, 1078 або 2116 із механічно розплющеними нитками, що ліквідує смоляні вікна.
3. **Поворот фотошаблону на панелі:** заводський поворот усієї плати всередині виробничої заготовки на кут 5.7° відносно рулону текстоліту.

## 14. Трасування виходу з BGA (BGA Escape Routing) та компенсація звужень

При виведенні швидкісних диференційних пар із-під корпусів мікросхем BGA з дрібним кроком виводів (Pitch 0.8 мм, 0.65 мм або 0.5 мм) стандартна геометрія лінії не поміщається між контактними площадками кульок BGA.

Розробнику доводиться локально зменшувати ширину доріжки `w` (техніка звуження траси, Neck-down). Зменшення ширини траси з номінальних 0.16 мм до 0.10 мм на довжині всього 3–5 мм без зміни інших параметрів викликає локальний стрибок диференційного імпедансу вгору з 90 Ом до 108 Ом.

Для компенсації цього стрибка застосовують синхронне зменшення міжосьового зазору `s` (збільшуючи взаємну ємність зв'язку `C_m`), що дозволяє утримувати результуючий імпеданс у межах допуску ±5%:

```
Z_diff,neck = 2.0 · √( (L_0,neck - L_m,neck) / (C_0,neck + 2 · C_m,neck) ) ≈ Z_diff,nom
```

Додатково під BGA застосовують технологію глухих мікропереходів (Microvias / HDI) або розміщення перехідних отворів безпосередньо в контактних площадках із подальшим мідним заповненням та поліруванням (Via-in-Pad Plated Over, VIPPO), що мінімізує паразитну індуктивність виводів.

## 15. Серпентинні фазовирівнюючі секції (Serpentine Phase Tuning)

При проходженні поворотів друкованої плати внутрішній провідник пари має коротшу геометричну довжину, ніж зовнішній. Виникає внутрішньопарний фазовий перекіс (Intra-pair Skew), який перетворює частину корисного диференційного сигналу в паразитний синфазний шум і погіршує електромагнітну сумісність (EMC).

Для компенсації перекосу коротший провідник штучно подовжують за допомогою серпентинної фазовирівнюючої секції (Serpentine Tuning). Фізична структура петлі серпентину повинна задовольняти суворим геометричним правилам:
* Мінімальний зазор між витками всередині петлі повинен становити не менше `S_loop ≥ 3.0 · w` (або `S_loop ≥ 2.0 · h`).
* Якщо зазор зробити надто малим (`S_loop < 2.0 · w`), високочастотні гармоніки сигналу починають ємнісно «перестрибувати» через зазор між витками (High-Frequency Capacitive Bypassing). У результаті на частотах понад 5–10 ГГц серпентин втрачає свою ефективну електричну довжину і перестає компенсувати фазовий перекіс.
* Фазовирівнююча петля повинна розміщуватися якомога ближче до місця виникнення перекосу (безпосередньо за вигином траси), щоб мінімізувати зону спільного пробігу розфазованого синфазного сигналу.

## 16. Синфазні дроселі (Common-Mode Chokes, CMC) та придушення завад EMI

Синфазний дросель (Common-Mode Choke) являє собою двообмоточний пасивний магнітний компонент на тороїдальному або біфілярному феритовому осерді з високою магнітною проникністю `μ_r ≈ 500–5000`.

Фізика роботи дроселя ґрунтується на вибірковому розділенні диференційного та синфазного струмів:
1. **Диференційний сигнал (Odd Mode):** корисні струми `I_1` та `I_2` течуть у протилежних напрямках (`I_1 = -I_2`). Згенеровані ними магнітні потоки в осерді `Φ_1` та `Φ_2` мають рівну амплітуду і протилежні знаки. Результуючий магнітний потік дорівнює нулю (`Φ_net = Φ_1 - Φ_2 = 0`), осердя не намагнічується, і дросель створює для сигналу мінімальний паразитичний індуктивний опір розсіювання `L_leakage ≈ 0.5–2.0` нГн.
2. **Синфазний шум (Even Mode):** завади та шуми `I_comm` протікають в одному напрямку (`I_1 = I_2`). Їхні магнітні потоки синфазно складаються (`Φ_net = Φ_1 + Φ_2 = 2 · Φ`), створюючи колосальний реактивний опір `Z_comm = 2 · π · f · L_cm ≥ 500–2000` Ом на частотах від 100 МГц до 3 ГГц.

Завдяки цьому синфазний шум та випромінювання EMI пригнічуються на 25–40 дБ без спотворення форми швидкісних імпульсів диференційної шини.

## 17. Виробничі фактори: трапецієподібність травлення та метод Монте-Карло

У реальному виробництві друкованих плат переріз мідного провідника ніколи не є ідеальним прямокутником. Внаслідок бічного підтравлювання під шаром фоторезисту провідник набуває форми трапеції, де ширина верхньої грані `w_top` менша за ширину нижньої грані `w_bottom`.

Етч-фактор (Etch Factor, EF) визначається співвідношенням товщини фольги до величини бічного підтравлювання:

```
EF = t / ( w_bottom - w_top )
```

Типові промислові значення етч-фактора для стандартних хімічних ліній травлення складають `EF ≈ 2.0–3.0`. Нахил бічних стінок траси на кут `θ ≈ 65°–75°` зменшує ефективну площу поперечного перерізу та площу бічного ємнісного перекриття в зазорі `s`. У результаті диференційний імпеданс трапецієподібної мікросмужки збільшується на 2.5–4.5 Ом порівняно з ідеальним прямокутником. Розроблений 2D FDM-солвер дозволяє задавати координати вершин довільного трапецієподібного полігону, точно враховуючи технологічний етч-фактор конкретної фабрики.

Для статистичного аналізу виробничого виходу придатних плат (Yield Analysis) застосовують метод статистичних випробувань Монте-Карло. Програма генерує тисячі випадкових комбінацій виробничих параметрів відповідно до їхніх гаусових розподілів:
* Ширина доріжки: `w = w_nom ± 12.5` мкм (`3σ = 12.5` мкм);
* Зазор між доріжками: `s = s_nom ± 12.5` мкм;
* Товщина діелектрика: `h = h_nom ± 10%`;
* Діелектрична проникність: `ε_r = ε_nom ± 0.15`.

Статистична гістограма розподілу `Z_diff` дозволяє розробнику точно оцінити ймовірність виходу за рамки стандартного 10% допуску специфікації (наприклад, 81–99 Ом для USB чи 90–110 Ом для PCIe) ще до запуску плати у виробництво.

## 18. Інженерне проектування перехідних отворів (Differential Via Design & Backdrilling)

Перехідні отвори (Vias) є найпоширенішим джерелом розриву хвильового імпедансу при переході диференційної пари між сигнальними шарами друкованої плати. Фізична еквівалентна схема пари отворів містить послідовну індуктивність металізованого стовбура `L_barrel`, надлишкову паразитну ємність контактних площадок `C_pad` відносно внутрішніх полігонів землі та паразитний розімкнений шлейф — стаб (Via Stub).

Стаб являє собою неробочу металізовану частину отвору, що тягнеться від цільового сигнального шару до протилежної поверхні плати. На чвертьхвильовій резонансній частоті розімкнений стаб довжиною `L_stub` діє як ідеальне коротке замикання:

```
f_stub = c / [ 4.0 · L_stub · √( ε_sub ) ]
```

Для типової 16-шарової плати товщиною 2.4 мм при переході з Layer 1 на Layer 3 довжина стаба становить `L_stub ≈ 2.0` мм. На підкладці FR-4 (`ε_sub = 4.1`) резонансна частота такого стаба складає:

```
f_stub = 3.0 · 10⁸ / [ 4.0 · 0.002 · √4.1 ] ≈ 18.5 ГГц
```

На частоті 18.5 ГГц виникає глибокий резонансний провал у характеристиці внесених втрат `S_dd21` глибиною до `-35` дБ, що повністю знищує сигнал шин PCIe Gen5 (частота Найквіста 16 ГГц) та 100GbE (частота 13.28 ГГц).

Для запобігання резонансному провалу застосовують технологію зворотного висвердлювання (Backdrilling / Controlled Depth Counterboring). Металевий стаб висвердлюється свердлом збільшеного діаметра з боку нижньої поверхні плати так, щоб залишковий фрагмент не перевищував `L_stub ≤ 0.15–0.20` мм (6–8 mil). Це зміщує паразитний резонанс вище 100 ГГц, за межі робочої смуги частот інтерфейсу.

Додатково виконують оптимізацію форми антіпедів (Antipads): під парою перехідних отворів у шарах опорної землі вирізають спільний овальний отвір замість двох круглих (Common Differential Antipad), що зменшує надлишкову паразитну ємність `C_pad` і вирівнює диференційний імпеданс переходу до цільових 85–100 Ом.

## 19. Теорія часової рефлектометрії (TDR) та просторової локалізації дефектів

Часова рефлектометрія (Time-Domain Reflectometry, TDR) є основним метрологічним методом верифікації імпедансу друкованих плат на виробництві та в лабораторіях.

Принцип методу полягає у подачі прецизійного перепаду напруги (Step Pulse) з суб-20-пікосекундним фронтом наростання `t_rise` у досліджувану диференційну лінію передачі та безперервній реєстрації форми відбитої хвилі на надшвидкісному стробоскопічному осцилографі.

Миттєвий диференційний коефіцієнт відбиття `Γ(t)` у кожній точці часу пов'язаний із локальним імпедансом лінії `Z_diff(t)` співвідношенням:

```
Γ(t) = [ V_reflected(t) ] / [ V_incident ]
Z_diff(t) = Z_ref · [ 1.0 + Γ(t) ] / [ 1.0 - Γ(t) ]
```

де `Z_ref = 100.0` Ом — еталонний внутрішній опір вимірювальних головок рефлектометра.

Перетворення часової шкали `t` у просторову координату положення на платі `x` здійснюється за формулою подвійного пробігу хвилі (туди й назад):

```
x(t) = ( c · t ) / [ 2.0 · √( ε_eff ) ]
```

Просторова роздільна здатність рефлектометра `Δx_min` визначається тривалістю фронту наростання генератора імпульсів:

```
Δx_min ≈ ( c · t_rise ) / [ 2.0 · √( ε_eff ) ]
```

При використанні імпульсу з фронтом `t_rise = 25` пс на діелектрику FR-4 (`ε_eff ≈ 3.2`) рефлектометр здатний розрізнити локальні неоднорідності імпедансу на відстані всього `Δx_min ≈ 2.1` мм вздовж траси друкованої плати.

## 20. Інженерний посібник: проектування високошвидкісних стек-апів від 1 до 112 Гбіт/с

Для забезпечення надійної передачі даних у сучасних цифрових інтерфейсах інженерний розрахунок стек-апу друкованої плати узгоджують із фізичними властивостями діелектричних ламінатів:

| Тип діелектрика | Торгова марка / Ламінат | `ε_r` (1 ГГц) | `tan δ` (1 ГГц) | `tan δ` (10 ГГц) | Максимальна швидкість |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Standard FR-4** | Kingboard KB-6160 | 4.40 | 0.0200 | 0.0250 | до 1.5 Гбіт/с (USB 2.0, CAN FD) |
| **Mid-Loss FR-4** | Isola 370HR, ITEQ IT-180A | 4.05 | 0.0150 | 0.0180 | до 5.0 Гбіт/с (PCIe Gen2, USB 3.0) |

### Покроковий алгоритм синтезу імпедансу швидкісного каналу
1. **Вибір цільового інтерфейсу та імпедансу:** визначають цільовий опір `Z_target` (наприклад, 85 Ом для PCIe Gen5, 90 Ом для USB 3.2 або 100 Ом для 100GBase-KR4).
2. **Вибір сигнального шару:** для швидкостей понад 10 Гбіт/с обирають виключно внутрішні смужкові шари (Layer 3 або Layer 5) між двома суцільними площинами GND для повного усунення перехресної завади FEXT.
3. **Оптимізація геометрії в FDM-солвері:** варіюють ширину `w` та зазор `s` при фіксованій товщині препрегу `h` до досягнення `Z_diff = Z_target ± 0.5%`.
4. **Розрахунок внесених втрат (Insertion Loss Budget):** обчислюють загальне згасання каналу на частоті Найквіста `f_Nyquist = BitRate / 2` (або `BitRate / 4` для 4-рівневої модуляції PAM4):
   ```
   IL_total(f) = α_conductor(f, R_q) · L + α_dielectric(f, tan δ) · L + IL_vias
   ```
5. **Верифікація бюджету:** переконуються, що повні втрати каналу `IL_total` не перевищують ліміту специфікації стандарту (типово `-28` дБ для PCIe Gen5 або `-32` дБ для IEEE 802.3ck).

### Аналіз збіжності FDM-сітки
Дослідження залежності похибки від розмірності сітки показує монотонну асимптотичну збіжність розв'язку:
* При кроці `Δx = 10` мкм (сітка `120 × 80`): час розрахунку 15 мс, похибка розрахунку `Z_diff` становить `~2.1%`.
* При кроці `Δx = 5` мкм (сітка `240 × 160`): час розрахунку 75 мс, похибка падає до `~0.3%`.
* При кроці `Δx = 2.5` мкм (сітка `480 × 320`): час розрахунку 380 мс, похибка становить менше `0.08%`.

Таким чином, базова конфігурація сітки `240 × 160` вузлів є ідеальним інженерним компромісом між субсекундною швидкодією та прецизійною метрологічною точністю.

### Аналіз впливу виробничих допусків (Monte Carlo Tolerance Sensitivity)

Реальне виробництво друкованих плат на заводі супроводжується технологічним розкидом параметрів матеріалів та геометричних розмірів трасування:
1. **Травлення міді (Etch Tolerance):** допуск ширини доріжки складає типово `Δw = ±12.5` мкм (±0.5 mil). Звуження ширини на 12.5 мкм збільшує диференційний імпеданс `Z_diff` на 3.8–4.5 Ом.
2. **Товщина діелектричного препрегу (Dielectric Thickness):** варіація висоти `h` після пресування багатошарового пакету досягає `±10%` (наприклад, `h = 100 ± 10` мкм). Збільшення товщини діелектрика на 10 мкм піднімає `Z_diff` на 6.5–7.5 Ом.
3. **Діелектрична проникність смоли (Dielectric Constant `ε_r`):** неоднорідність співвідношення смола/скловолокно дає розкид `ε_sub = 4.1 ± 0.2`. Це зсуває імпеданс на `±2.2 Ом`.

Для гарантованого вкладання серійної продукції у стандартний технологічний допуск `±10%` (або жорсткий прецизійний допуск `±5%` для серверних плат PCIe Gen5) центральне номінальне значення геометрії розраховують саме за допомогою 2D FDM-солвера, після чого завод виготовляє тестовий купон із вимірюванням рефлектограми TDR на кожній виробничій панелі.
