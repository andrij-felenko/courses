# Оживлення нової плати: рейки → скидання → такт → відлагоджувач

Коли свіжозмонтована друкована плата вперше вмикається на робочому столі, мікроконтролер на ній не подає жодних ознак життя. Спроба одразу підключити програматор і прошити мікросхему часто закінчується повідомленням про помилку зв'язку. Щоб знайти несправність і не пошкодити новий пристрій, використовують покроковий порядок перевірки: спершу перевіряють шини живлення, далі стан лінії скидання, потім роботу тактового генератора і лише після цього — налагоджувальний інтерфейс.

Цей порядок називають канонічною послідовністю оживлення плати (англ. *Bringup*). Кожен наступний крок спирається на попередній: якщо напруга нестабільна, лінія скидання не відпуститься; якщо процесор утримується в стані скидання, тактові генератори не запустяться; без тактування та живлення відлагоджувач не зможе виявити ядро.

```
Порядок перевірки вузлів плати:
[ 1. Шини живлення ] ──► Стабільна напруга VDD, плавний пуск, поріг Power-On-Reset
         │
         ▼
[ 2. Лінія скидання ] ──► Підтяжка nRST до 3.3 В, затримка RC-фільтра, відсутність замикань
         │
         ▼
[ 3. Тактове дерево ] ──► Старт внутрішнього генератора HSI, збудження кварцу HSE
         │
         ▼
[ 4. Відлагоджувач  ] ──► Зв'язок SWD/JTAG, читання IDCODE, керування ядром через OpenOCD
```

---

## 1. Крок перший: шини живлення та схема первинного скидання

Перше увімкнення плати виконують від лабораторного блоку живлення з обмеженням струму. Це захищає доріжки та компоненти від вигоряння у разі випадкового короткого замикання під мікросхемами.

Після подачі напруги перевіряють форму її наростання цифровим осцилографом. Напруга на головній цифровій шині `VDD` (зазвичай 3.3 В) повинна підійматися плавно й монотонно — без провалів, сходинок чи високочастотних коливань. Плавний підйом забезпечує схема софт-старту стабілізатора, обмежуючи пусковий струм заряду розв'язувальних конденсаторів.

Коли напруга перетинає поріг близько 1.7–1.9 В, внутрішня схема мікроконтролера — Power-On Reset (POR) — виходить зі стану скидання. Якщо напруга підіймається надто повільно або просідає через увімкнення іншого споживача, схема скидання потрапляє в зону невизначеності, і процесор зависає ще до початку роботи.

## 2. Крок другий: стан лінії скидання nRST

Вивід скидання мікроконтролера `nRST` має активний низький рівень: поки на ньому присутній нуль вольтів, процесорне ядро заморожене і не виконує жодних операцій. Для переходу в робочий стан лінія повинна піднятися до напруги живлення (3.3 В).

Схемотехніка цього вузла складається із зовнішнього підтягувального резистора (10–47 кОм до `VDD`) та фільтрувального конденсатора (100 нФ на землю). Конденсатор створює невелику затримку (близько 1 мс), утримуючи низький рівень на піні `nRST` навіть після того, як живлення `VDD` вже досягло норми. Це дає внутрішнім регуляторам ядра час на стабілізацію.

Осцилографом перевіряють два параметри:
1. **Постійний рівень:** після завершення перехідного процесу на лінії `nRST` має бути стабільна напруга 3.3 В.
2. **Форма імпульсу:** при натисканні на кнопку скидання або за командою відлагоджувача напруга має спадати до 0 В і плавно повертатися назад після відпускання.

Якщо напруга на виводі `nRST` залишається на рівні нуля або плаває близько 1 В, причиною зазвичай є замикання під кнопкою, пробитий конденсатор або відсутність резистора підтяжки.

## 3. Крок третій: тактовий генератор і кварцовий резонатор

Після звільнення лінії скидання мікроконтролер автоматично запускається від внутрішнього RC-генератора (HSI, зазвичай 8 або 16 МГц). Цей генератор не потребує зовнішніх компонентів і дозволяє ядру виконувати базові команди навіть на платі без кварцу.

Для роботи точних інтерфейсів (USB, Ethernet, CAN) програмне забезпечення активує зовнішній кварцовий резонатор (HSE). Резонатор підключається до виводів `OSC_IN` та `OSC_OUT` разом із двома навантажувальними конденсаторами ємністю 10–22 пФ.

Перевірку кварцу виконують осцилографом із малоємнісним щупом на виводі `OSC_OUT`. На екрані має з'явитися чиста синусоїда з розмахом не менше 0.8–1.5 В на номінальній частоті резонатора (наприклад, 8 МГц або 25 МГц). Якщо генерація відсутня, перевіряють номінали конденсаторів, відсутність флюсу між ніжками та цілісність пайки корпусу кварцу.

## 4. Крок четвертий: підключення відлагоджувача через SWD

Коли живлення, лінія скидання і тактування перевірені, підключають апаратний відлагоджувач (ST-Link, J-Link, CMSIS-DAP) до інтерфейсу SWD (Serial Wire Debug).

Інтерфейс використовує дві лінії:
- **`SWCLK`** — лінія тактування, якою керує відлагоджувач (потребує підтяжки 10–100 кОм до землі);
- **`SWDIO`** — двоспрямована лінія даних (потребує підтяжки 10–100 кОм до 3.3 В).

Під час запуску відлагоджувач надсилає на лінію `SWDIO` серію з понад 50 одиниць (Line Reset), спеціальну 16-бітну послідовність перемикання `0x79E7` та виконує читання 32-бітного ідентифікатора Debug Port (DP-IDCODE). Якщо чіп справний, відлагоджувач отримує відповідь `ACK OK` та числовий код ядра (наприклад, `0x0BC11477` для Cortex-M0+ або `0x2BA01477` для Cortex-M4).

```
Типові проблеми зв'язку та методи їх усунення:
┌──────────────────────────────┬───────────────────────────────┬────────────────────────────────────────┐
│ Симптом помилки              │ Ймовірна причина              │ Спосіб виправлення                     │
├──────────────────────────────┼───────────────────────────────┼────────────────────────────────────────┤
│ No target detected           │ Немає живлення на VDD чи nRST │ Перевірити 3.3 В на роз'ємі відладки   │
├──────────────────────────────┼───────────────────────────────┼────────────────────────────────────────┤
│ Target not halted            │ Код у Flash вимкнув SWD піни  │ Застосувати режим Connect-Under-Reset  │
│                              │ або перевів ядро в глибокий сон│ через утримання піна nRST низьким      │
├──────────────────────────────┼───────────────────────────────┼────────────────────────────────────────┤
│ Помилки передачі даних       │ Довгий шлейф, паразитна       │ Знизити тактову частоту адаптера       │
│ (Parity Error / Read Fail)   │ ємність доріжок понад 30 пФ   │ в OpenOCD до 100–500 кГц               │
└──────────────────────────────┴───────────────────────────────┴────────────────────────────────────────┘
```
