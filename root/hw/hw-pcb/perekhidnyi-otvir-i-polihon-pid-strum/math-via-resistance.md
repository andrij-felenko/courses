# 🧮 Виведення електричного та теплового опору перехідного отвору

Перехідний отвір (англ. *via*, лат. *via* — «шлях», «дорога») на друкованій платі являє собою порожнистий мідний циліндр, утворений свердлінням отвору в діелектрику та наступним хіміко-гальванічним осадженням шару міді на його внутрішніх стінках. Розрахунок електричного опору, падіння напруги, індуктивності та теплової спроможності такого елемента ґрунтується на геометрії тонкостінної трубки, хвильовому скін-ефекті та температурній залежності провідності металу.

## 1. Геометрія циліндричної гільзи та площа поперечного перерізу

Нехай отвір просвердлено свердлом діаметром `d_drill`. Після хімічного осадження первинного шару та гальванічного нарощування товщина мідної стінки становить `t_wall`.

Позначимо радіуси гільзи:
- Зовнішній радіус гільзи: `r_out = d_drill / 2`
- Внутрішній радіус гільзи (фінішний просвіт): `r_in = r_out - t_wall = (d_drill / 2) - t_wall`
- Фінішний внутрішній діаметр отвору: `d_hole = 2 · r_in = d_drill - 2 · t_wall`

Площа поперечного перерізу мідного кільця `A_via`, крізь яку тече вертикальний струм, дорівнює різниці площ зовнішнього та внутрішнього кругів:

```
A_via = π · r_out² - π · r_in²               [площа кільцевого перерізу]
= π · (r_out² - (r_out - t_wall)²)           [підстановка r_in = r_out - t_wall]
= π · (r_out² - (r_out² - 2·r_out·t_wall + t_wall²)) [розкриття квадрата]
= π · (2·r_out·t_wall - t_wall²)             [спрощення: скорочення r_out²]
= π · t_wall · (2·r_out - t_wall)            [винесення t_wall за дужки]
= π · t_wall · (d_drill - t_wall)            [підстановка 2·r_out = d_drill]
```

Оскільки товщина металізації `t_wall` (типово 18–25 мкм = 0.018–0.025 мм) на порядок менша за діаметр свердла `d_drill` (типово 0.3–0.6 мм), величиною `t_wall²` у наближених інженерних розрахунках часто нехтують. Тоді формула набуває простого вигляду довжини середнього кола, помноженої на товщину стінки:

```
A_via ≈ π · d_mid · t_wall                   [апроксимація тонкостінної трубки]
де d_mid = (d_drill + d_hole) / 2 = d_drill - t_wall
```

**Числовий приклад розрахунку перерізу.** Для типового перехідного отвору з діаметром свердла `d_drill = 0.3 мм` та номінальною товщиною стінки металізації `t_wall = 25 мкм = 0.025 мм`:

```
A_via = π · 0.025 мм · (0.3 мм - 0.025 мм)   [підстановка d_drill=0.3 мм, t_wall=0.025 мм]
= 3.14159 · 0.025 · 0.275                    [обчислення різниці радіусів]
≈ 0.02160 мм² = 21600 мкм²                   [площа перерізу стінки]
```

Порівняймо цей переріз зі звичайною плоскою доріжкою на стандартній фользі 1 oz (`t_foil = 35 мкм = 0.035 мм`). Еквівалентна ширина доріжки `w_equiv`, що має таку ж площу перерізу:

```
w_equiv = A_via / t_foil                     [визначення еквівалентної ширини]
= 0.02160 мм² / 0.035 мм                     [підстановка перерізу та товщини фольги]
≈ 0.617 мм (близько 24.3 mil)                [еквівалентна ширина доріжки]
```

Один компактний отвір діаметром 0.3 мм за площею міді еквівалентний доріжці завширшки понад 0.6 мм.

## 2. Електричний опір постійному струму та температурна корекція

Опір циліндричної гільзи висотою `h` (що відповідає повній товщині друкованої плати, типово `h = 1.6 мм`) розраховується за класичним законом питомого опору:

```
R_via = ρ_Cu(T) · h / A_via                  [електричний опір провідника]
```

Питомий опір електролітично осадженої міді залежить від температури:

```
ρ_Cu(T) = ρ₀ · (1 + α · (T - T₀))            [температурна залежність питомого опору]
```

де:
- `ρ₀ ≈ 1.72 · 10⁻⁸ Ом·м = 1.72 · 10⁻⁵ Ом·мм` — питомий опір чистої міді при `T₀ = 20 °C`;
- `α ≈ 0.00393 1/°C` (або `0.393 %/°C`) — температурний коефіцієнт електричного опору міді.

Для гальванічної міді в отворі внаслідок можливих мікродомішок та дрібнозернистої структури питомий опір дещо вищий і в інженерних нормах IPC приймається рівним `ρ_Cu(20°C) ≈ 1.90 · 10⁻⁵ Ом·мм`.

**Розрахунок опору одиничного via при 20 °C та 70 °C.** Для гільзи довжиною `h = 1.6 мм` і перерізом `A_via = 0.02160 мм²`:

При `T = 20 °C`:
```
R_via(20°C) = 1.90·10⁻⁵ Ом·мм · 1.6 мм / 0.02160 мм² [закон Ома для провідника]
= 3.04·10⁻⁵ / 0.02160                                 [добуток у чисельнику]
≈ 1.407 · 10⁻³ Ом = 1.41 мОм                          [опір при 20 °C]
```

При нагріванні до `T = 70 °C` (`ΔT = 50 °C`):
```
ρ_Cu(70°C) = 1.90·10⁻⁵ · (1 + 0.00393 · 50)  [температурна поправка для ΔT=50 °C]
= 1.90·10⁻⁵ · (1 + 0.1965)                   [добуток коефіцієнта на перегрів]
= 2.273 · 10⁻⁵ Ом·мм                         [зростання питомого опору на 19.65%]

R_via(70°C) = 2.273·10⁻⁵ · 1.6 / 0.02160     [опір гільзи при 70 °C]
≈ 1.684 мОм                                  [гарячий опір перехідного отвору]
```

## 3. Падіння напруги та втрати потужності

Коли крізь перехідний отвір протікає постійний струм `I = 2 А`:

1. **Падіння напруги на одному отворі:**
```
ΔU_via = I · R_via(70°C)                     [закон Ома]
= 2 А · 1.684·10⁻³ Ом                        [підстановка струму та гарячого опору]
≈ 3.37 мВ                                    [падіння напруги на 1 via]
```

2. **Джоулева потужність втрат, що розсіюється в гільзі:**
```
P_loss = I² · R_via(70°C)                    [закон Джоуля–Ленца]
= (2 А)² · 1.684·10⁻³ Ом                     [підстановка струму 2 А]
= 4 · 1.684·10⁻³                             [піднесення до квадрата]
≈ 6.74 мВт                                   [виділювана теплова потужність]
```

Незважаючи на те, що абсолютна потужність 6.74 мВт здається невеликою, вона зосереджена в крихітному об'ємі міді:

```
V_Cu = A_via · h = 0.02160 мм² · 1.6 мм ≈ 0.03456 мм³ = 3.456 · 10⁻¹¹ м³
```

Об'ємна густина виділення тепла `q_v`:
```
q_v = P_loss / V_Cu                          [об'ємна густина тепловиділення]
= 6.74·10⁻³ Вт / (3.456·10⁻¹¹ м³)            [підстановка потужності та об'єму міді]
≈ 1.95 · 10⁸ Вт/м³ = 195 Вт/см³              [питома об'ємна потужність]
```

Саме висока об'ємна густина тепловиділення вимагає ефективного відведення тепла у масивні прилеглі площини міді.

## 4. Паралельне з'єднання: силова матриця (Stitching Vias)

Якщо струм силової шини становить `I_total = 20 А`, пропускання його через один отвір призвело б до розсіювання потужності:

```
P_single = (20 А)² · 1.684·10⁻³ Ом           [закон Джоуля–Ленца для 20 А]
= 400 · 1.684·10⁻³                           [піднесення до квадрата]
≈ 0.674 Вт                                   [небезпечна локальна потужність]
```

Така потужність усередині локальної точки плати перегріє діелектрик вище температури склування `Tg` (130–150 °C) за лічені секунди, спричинивши розшарування (delamination).

Для розподілу навантаження застосовують паралельну матрицю з `N` отворів. Еквівалентний електричний опір групи:

```
R_eq = R_via / N                             [паралельне з'єднання однакових провідників]
```

Для `N = 10` отворів:
```
R_eq = 1.684 мОм / 10 = 0.1684 мОм
```

Загальне падіння напруги при струмі 20 А:
```
ΔU_total = I_total · R_eq                    [закон Ома для матриці]
= 20 А · 0.1684·10⁻³ Ом                      [підстановка загального струму та R_eq]
≈ 3.37 мВ                                    [загальне падіння напруги]
```

Сумарна потужність втрат на всій матриці:
```
P_total = I_total² · R_eq                    [сумарні джоулеві втрати]
= (20 А)² · 0.1684·10⁻³ Ом                   [підстановка струму 20 А]
= 400 · 0.1684·10⁻³                          [піднесення струму до квадрата]
≈ 0.0674 Вт = 67.4 мВт                       [кінцевий результат для матриці]
```

Потужність, що припадає на один отвір у матриці:
```
P_per_via = P_total / N                      [потужність на один отвір]
= 67.4 мВт / 10                              [ділення на кількість via]
≈ 6.74 мВт                                   [безпечний нагрів одного via]
```

Збільшення кількості отворів у 10 разів знизило загальні теплові втрати рівно в 10 разів (з 674 мВт до 67.4 мВт), а теплове навантаження на одиницю об'єму міді — у 100 разів.

## 5. Тепловий опір циліндричної гільзи

Перехідний отвір передає тепло між шарами друкованої плати завдяки високій теплопровідності міді `k_Cu ≈ 385 Вт/(м·К) = 0.385 Вт/(мм·К)`.

Тепловий опір мідної гільзи у вертикальному напрямку вздовж осі отвору:

```
θ_via = h / (k_Cu · A_via)                   [тепловий опір циліндра]
```

Для розглянутого via (`h = 1.6 мм`, `A_via = 0.02160 мм²`):

```
θ_via = 1.6 мм / (0.385 Вт/(мм·К) · 0.02160 мм²) [підстановка параметрів]
= 1.6 / 0.008316                                  [обчислення знаменника]
≈ 192.4 °C/Вт                                     [вертикальний тепловий опір 1 via]
```

Для масиву з `N = 10` теплових перехідних отворів сумарний вертикальний тепловий опір зменшується паралельно:

```
θ_array = θ_via / N                          [паралельне з'єднання теплових опорів]
= 192.4 °C/Вт / 10                           [ділення на кількість отворів]
≈ 19.2 °C/Вт                                 [сумарний тепловий опір матриці]
```

Матриця з 10–20 отворів під силовим транзистором дозволяє відводити кілька ватів тепла від верхнього кристала безпосередньо у внутрішній або нижній шар заземлення з перепадом температури лише в десятки градусів.

## 6. Паразитна індуктивність та високочастотні ефекти

Окрім активного опору, перехідний отвір володіє власною паразитною індуктивністю `L_via`. У наближенні одиночного круглого провідника за формулою Джонсона–Грехема:

```
L_via ≈ 5.08 · h · (ln(4·h / d_drill) + 1)   [індуктивність у нГн при h і d у дюймах]
```

Для стандартного отвору `h = 1.6 мм ≈ 0.063 дюйма` та `d_drill = 0.3 мм ≈ 0.0118 дюйма`:
```
L_via ≈ 5.08 · 0.063 · (ln(4 · 0.063 / 0.0118) + 1)
≈ 0.32 · (ln(21.35) + 1)
≈ 0.32 · (3.06 + 1)
≈ 1.30 нГн
```

Коли через перехідний отвір протікає імпульсний струм із високою швидкістю наростання фронту `dI/dt` (наприклад, у перемикачі синхронного перетворювача з `dI/dt = 10 А / 5 нс = 2 · 10⁹ А/с`), на індуктивності отвору виникає індуктивний сплеск напруги:

```
ΔU_L = L_via · (dI/dt)                       [закон електромагнітної індукції]
= 1.30 · 10⁻⁹ Гн · 2 · 10⁹ А/с               [підстановка індуктивності та швидкості струму]
≈ 2.60 В                                     [амплітуда паразитного викиду напруги]
```

Об'єднання перехідних отворів у паралельну матрицю з `N` елементів зменшує еквівалентну індуктивність за формулою паралельних гілок `L_eq ≈ L_via / N` (з поправкою на взаємну індуктивність між сусідніми отворами). Матриця з 8 отворів знижує паразитний викид напруги з 2.6 В до безпечних 0.35 В.

## 7. Термомеханічні напруження та втомне руйнування гільзи (Barrel Cracking)

Під час циклічного нагрівання та охолодження плати виникає механічне напруження через суттєву різницю коефіцієнтів теплового розширення (англ. *coefficient of thermal expansion*, CTE) міді та склотекстоліту FR-4:
- Коефіцієнт розширення міді: `CTE_Cu ≈ 17 ppm/°C` (частин на мільйон на градус Цельсія).
- Коефіцієнт розширення FR-4 у площині плати (осі X і Y, де склотканина стримує розширення): `CTE_XY ≈ 14–16 ppm/°C` (майже ідеально узгоджений із міддю).
- Коефіцієнт розширення FR-4 за товщиною (вісь Z, перпендикулярно шарам тканини): `CTE_Z ≈ 50–70 ppm/°C` за температур нижче `Tg`, та стрімко зростає до `250–350 ppm/°C` вище температури склування.

Оскільки діелектрик за товщиною розширюється в 3–15 разів сильніше за мідну гільзу, при кожному нагріванні плата намагається «розірвати» циліндр via вздовж вертикальної осі. Механічне відносне видовження `ε_z`:

```
ε_z = (CTE_Z - CTE_Cu) · ΔT                  [різницева термічна деформація]
```

Якщо товщина стінки металізації занижена (наприклад, менше 15–18 мкм через технологічний брак фабрики) або робочий перегрів `ΔT` регулярно перевищує 50–60 °C, у середині висоти гільзи виникають мікротріщини (англ. *barrel cracking*). Забезпечення нормативної товщини стінки `t_wall ≥ 20–25 мкм` та обмеження локального джоулевого перегріву є необхідною умовою довготривалої надійності друкованого вузла.
