# 🧮 Виведення теплового опору циліндричного перехідного отвору та моделі розтікання

Цей математичний аналіз виводить точні аналітичні рівняння для теплового опору металізованого циліндричного перехідного отвору (via barrel), аналізує внесок заповнювача та кількісно описує тривимірний опір розтікання тепла в тонких мідних шарах плати. Без цього математичного апарату неможливо оптимізувати кількість та крок отворів у матриці охолодження, оскільки просте паралельне ділення опору на кількість via ігнорує просторове насичення теплового потоку.

## 1. Одновимірне теплове проведення вздовж порожнистого мідного циліндра

Стаціонарний процес передачі тепла теплопровідністю у твердому тілі описується диференціальним законом Фур'є:

```text
q = −k · ∇T
```

де `q` — густина теплового потоку [Вт/м²], `k` — коефіцієнт теплопровідності матеріалу [Вт/(м·К)], `∇T` — градієнт температури [К/м].

Розглянемо одиничний перехідний отвір у друкованій платі загальною товщиною `h`. Отвір утворено свердлінням циліндричного каналу зовнішнього діаметра `d` (номінальний діаметр свердла або finished hole diameter) та подальшим гальванічним осадженням шару міді товщиною `t` на його стінки.

Тепловий потік спрямований переважно вздовж осі циліндра (вісь `z`), від верхнього контактного майданчика до нижнього. За умови рівномірного розподілу температури по периметру отвору та відсутності значних радіальних теплових втрат крізь стінки в діелектрик FR-4 (внаслідок низької провідності FR-4), інтеграл закону Фур'є вздовж довжини `h` набуває одновимірного вигляду:

```text
P = k_Cu · A_Cu · (ΔT / h)
```

де `P` — повний тепловий потік (потужність тепловтрат) [Вт], `ΔT` — перепад температури між торцями отвору [К], `A_Cu` — площа поперечного перерізу мідної гільзи [м²].

За визначенням теплового опору:

```text
R_θ,via = ΔT / P = h / (k_Cu · A_Cu)
```

### Геометрія поперечного перерізу гільзи

Поперечний переріз являє собою кругле кільце із зовнішнім радіусом `r_out = d / 2` та внутрішнім радіусом `r_in = (d / 2) − t`. Площа цього кільця обчислюється через різницю площ двох кіл:

```text
A_Cu = π · r_out² − π · r_in²
A_Cu = π · ( (d / 2)² − ((d − 2t) / 2)² )
A_Cu = (π / 4) · ( d² − (d² − 4·d·t + 4·t²) )
A_Cu = (π / 4) · ( 4·d·t − 4·t² )
A_Cu = π · ( d·t − t² )
```

Підставляючи отриману площу у вираз для теплового опору, маємо базову розрахункову формулу:

```text
R_θ,via = h / ( k_Cu · π · (d·t − t²) )
```

### Числовий приклад розрахунку

Нехай плата має стандартні параметри:
- Товщина діелектрика разом із фольгою: `h = 1.6 мм = 1.6·10⁻³ м`
- Діаметр отвору: `d = 0.3 мм = 3.0·10⁻⁴ м`
- Товщина металізації стінки: `t = 25 мкм = 2.5·10⁻⁵ м`
- Теплопровідність електролітичної міді: `k_Cu = 385 Вт/(м·К)`

1. Обчислення площі перерізу міді:

```text
A_Cu = π · ( 0.3 · 0.025 − 0.025² ) мм²
A_Cu = π · ( 0.0075 − 0.000625 ) мм²
A_Cu = π · 0.006875 мм² ≈ 0.021598 мм² = 2.1598·10⁻⁸ м²
```

2. Обчислення теплового опору:

```text
R_θ,via = 1.6·10⁻³ / ( 385 · 2.1598·10⁻⁸ )
R_θ,via = 1.6·10⁻³ / 8.3154·10⁻⁶ ≈ 192.42 К/Вт
```

Якщо товщина плати зменшується до `h = 1.0 мм` (типово для 4-шарових компактних модулів), опір пропорційно знижується:

```text
R_θ,via(1.0 мм) = 1.0·10⁻³ / 8.3154·10⁻⁶ ≈ 120.26 К/Вт
```

Якщо ж плата виготовлена за технологією потовщеного міднення з `t = 35 мкм` (1 oz на стінках):

```text
A_Cu(35 мкм) = π · ( 0.3 · 0.035 − 0.035² ) = π · ( 0.0105 − 0.001225 ) = π · 0.009275 ≈ 0.029138 мм²
R_θ,via(1.6 мм, 35 мкм) = 1.6·10⁻³ / ( 385 · 2.9138·10⁻⁸ ) ≈ 142.62 К/Вт
```

## 2. Вплив матеріалу заповнення осердя отвору

У реальних конструкціях внутрішній циліндричний об'єм отвору радіуса `r_in = (d / 2) − t` може бути заповнений повітрям, епоксидним компаундом без домішок, теплопровідною пастою або міддю. Повна теплова провідність отвору є сумою провідностей мідної гільзи та центрального осердя:

```text
G_total = 1 / R_θ,total = G_Cu + G_core
G_total = (k_Cu · A_Cu / h) + (k_core · A_core / h)
```

де `A_core = π · ( (d − 2t) / 2 )² = (π / 4) · (d − 2t)²`.

Порівняємо відносний внесок різних заповнювачів для отвору `d = 0.3 мм`, `t = 25 мкм`, `d_in = 0.25 мм`:

```text
A_Cu = 2.1598·10⁻⁸ м²
A_core = (π / 4) · (0.25·10⁻³)² ≈ 4.9087·10⁻⁸ м²
```

| Матеріал осердя | Теплопровідність k_core [Вт/(м·К)] | Провідність осердя G_core [Вт/К] | Провідність міді G_Cu [Вт/К] | Частка осердя у відведенні тепла |
|---|---|---|---|---|
| Повітря (незаповнений отвір) | 0.026 | 0.798·10⁻⁶ | 5.197·10⁻³ | 0.015% |
| Стандартна епоксидна смола | 0.25 | 7.670·10⁻⁶ | 5.197·10⁻³ | 0.147% |
| Спеціальний термокомпаунд | 2.50 | 7.670·10⁻⁵ | 5.197·10⁻³ | 1.454% |
| Суцільна гальванічна мідь (Solid Copper Via) | 385.0 | 1.181·10⁻² | 5.197·10⁻³ | 69.44% |

**Висновок:** Заповнення отвору неелектропровідною епоксидною смолою (навіть із теплопровідними керамічними мікросферами до 2.5 Вт/(м·К)) покращує пряме вертикальне тепловідведення менш ніж на 1.5%. Головна функція заповнення в технології VIPPO — механічна герметизація паду для запобігання дефектам пайки, а не підвищення теплопровідності. Єдиний спосіб кардинально знизити тепловий опір одиничного via — це суцільне гальванічне заповнення міддю (solid copper via-fill), яке збільшує провідність отвору у 3.27 раза (`R_θ` падає зі 192 К/Вт до 59 К/Вт).

## 3. Модель тривимірного розтікання тепла (Spreading Resistance)

Коли тепло передається від невеликого джерела (кристала чи термопада площею `A_source = a × b`) у тонкий мідний полігон більшої площі (`A_plane = L × W`), лінії теплового потоку розширюються радіально. Це створює додатковий перепад температур, відомий як **опір розтікання** (англ. *thermal spreading resistance*).

За моделлю Сонга-Лі-Йовановича (Song-Lee-Yovanovich analytical spreading model) для прямокутного джерела на тонкому шарі товщиною `t_Cu` з тепловідведенням на нижній межі, опір розтікання у тонкій фользі описується співвідношенням:

```text
R_spread = ψ / ( k_Cu · √A_source )
```

де `ψ` — безрозмірний коефіцієнт розтікання, що залежить від відношення характерного розміру джерела `r_s = √(A_source / π)` до ефективного радіуса пластини `r_p = √(A_plane / π)` та біотеплового числа `Bi = h_eff · r_s / k_Cu`:

```text
ψ ≈ (1 / (2 · √π)) · (1 − ε)^1.5 · tanh( λ · t_Cu / r_s ) / ( λ · t_Cu / r_s )
```

де `ε = r_s / r_p`, `λ = π + 1 / (√π · ε)`.

Для двовимірного наближення тонкого мідного шару товщиною `t_Cu` опір радіального розтікання тепла від центрального круглого джерела радіуса `r₁` до зовнішнього радіуса `r₂` виводиться безпосередньо інтегруванням закону Фур'є в циліндричних координатах:

```text
q_r = −k_Cu · (2·π·r · t_Cu) · (dT / dr)
P = −2·π·k_Cu · t_Cu · r · (dT / dr) = const
```

Розділяючи змінні та інтегруючи від `r₁` до `r₂`:

```text
∫[T₁ to T₂] dT = −( P / (2·π·k_Cu · t_Cu) ) · ∫[r₁ to r₂] (dr / r)
T₁ − T₂ = ( P / (2·π·k_Cu · t_Cu) ) · ln(r₂ / r₁)
```

Звідки опір радіального розтікання у площині міді:

```text
R_spread,radial = (T₁ − T₂) / P = ln(r₂ / r₁) / ( 2·π · k_Cu · t_Cu )
```

### Числовий приклад опору розтікання

Нехай тепло розтікається від термопада радіусом `r₁ = 2.0 мм` по мідному полігону плати товщиною 1 oz (`t_Cu = 35 мкм = 3.5·10⁻⁵ м`) до зони охолодження радіусом `r₂ = 20.0 мм`:

```text
ln(20 / 2) = ln(10) ≈ 2.3026
Знаменник: 2 · π · 385 Вт/(м·К) · 3.5·10⁻⁵ м ≈ 0.08466 Вт/К
R_spread,radial = 2.3026 / 0.08466 ≈ 27.20 К/Вт
```

Якщо шар міді збільшити до 2 oz (`t_Cu = 70 мкм`), опір розтікання зменшиться вдвічі:

```text
R_spread,radial(2 oz) = 27.20 / 2 = 13.60 К/Вт
```

Цей розрахунок доводить фундаментальний інженерний факт: **опір розтікання у тонкій мідній фользі (13–27 К/Вт) є співмірним або навіть більшим за опір масиву перехідних отворів**. Тому без збільшення товщини зовнішніх мідних шарів або збільшення площі підведення тепла додавання нескінченної кількості via не знижує сумарну температуру вузла.

## 4. Оптимізація кількості отворів: закон спадної віддачі

Повний тепловий опір вузла «кристал → верхній майданчик → масив via → нижній полігон» моделюється комбінованим виразом:

```text
R_θ,total(N) = R_spread,top(N) + ( R_θ,via / N ) + R_spread,bot(N)
```

Коли кількість отворів `N` зростає, еквівалентний паралельний опір `R_θ,via / N` асимптотично прямує до нуля. Проте опір підведення тепла у верхньому шарі `R_spread,top` та відведення у нижньому `R_spread,bot` прагнуть до ненульової межі стиснення ліній потоку (constriction resistance):

```text
lim[N → ∞] R_θ,total(N) = R_constriction,top + R_constriction,bot > 0
```

Розрахуємо теоретичний сумарний опір для паду 5×5 мм при `R_θ,via = 192 К/Вт` та середньому опорі розтікання контактної площадки `R_constriction ≈ 3.5 К/Вт`:

| Кількість via (N) | Чистий опір масиву R_θ,via / N [К/Вт] | Додатковий опір розтікання [К/Вт] | Сумарний опір R_θ,total [К/Вт] | Відносне покращення від попереднього кроку |
|---|---|---|---|---|
| 1 | 192.4 | 1.0 | 193.4 К/Вт | — |
| 4 (матриця 2×2) | 48.1 | 1.5 | 49.6 К/Вт | −74.4% |
| 9 (матриця 3×3) | 21.4 | 2.2 | 23.6 К/Вт | −52.4% |
| 16 (матриця 4×4) | 12.0 | 2.8 | 14.8 К/Вт | −37.3% |
| 25 (матриця 5×5) | 7.7 | 3.3 | 11.0 К/Вт | −25.7% |
| 36 (матриця 6×6) | 5.3 | 3.7 | 9.0 К/Вт | −18.2% |
| 64 (матриця 8×8) | 3.0 | 4.2 | 7.2 К/Вт | −20.0% |

Похідна сумарного опору за кількістю отворів:

```text
d(R_θ,total) / dN = −( R_θ,via / N² ) + d(R_spread) / dN
```

При `N ≥ 16` абсолютна величина швидкості зниження опору стає меншою за `0.5 К/Вт` на кожен додатковий отвір. Це означає, що для паду типового розміру (до 5×5 мм) встановлення понад 16–25 отворів є економічно та технологічно недоцільним: механічна міцність плати падає, ризик пошкодження внутрішніх шарів свердлом зростає, а виграш у температурі кристала становить менше 1–2 °C.
