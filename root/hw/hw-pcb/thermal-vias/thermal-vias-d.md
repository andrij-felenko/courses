# Теплові перехідні отвори (thermal vias)

<preknowlist>
- [Теплове проведення](root:ph-thermodynamics/thermal-conductivity) — як тепло рухається крізь тверде тіло за диференціальним законом Фур'є і чому питома теплопровідність k визначає густину теплового потоку.
- [Тепловий опір](root:ph-thermodynamics/thermal-resistance) — еквівалент закону Ома для теплових процесів: перепад температури ΔT = P · R_θ на шляху теплового струму від джерела до охолоджувача.
- [Шарування плати](root:hw-pcb/pcb-stackup) — чергування тонкої мідної фольги та діелектричних склоепоксидних шарів FR-4 у структурі багатошарової друкованої плати.
- [Посадкові місця](root:hw-pcb/footprint-design) — геометрія контактних площадок, відкритого теплового майданчика (Exposed Pad) та теплових бар'єрів SMD-компонентів.
</preknowlist>

Потужний силовий транзистор, інтегральний DC-DC перетворювач або драйвер світлодіодів у компактному корпусі QFN 5×5 мм під час роботи розсіює 3 Вт теплової потужності на кремнієвому кристалі площею всього 4 мм². Безпосередньо під кристалом виробник розміщує відкритий металевий майданчик — термопад (англ. *Exposed Pad* або *PowerPAD*). Якщо запаяти такий компонент на стандартну двошарову плату без спеціальних заходів тепловідведення, тепло спробує пройти крізь товщу склотекстоліту FR-4 до нижнього мідного шару. Теплопровідність склотекстоліту у поперечному напрямку (вісь Z) становить жалюгідні 0.25–0.30 Вт/(м·К). Для плати товщиною 1.6 мм тепловий опір ділянки діелектрика під мікросхемою перевищує 60 К/Вт: кристал миттєво нагрівається на величину ΔT = 3 Вт × 60 К/Вт = 180 °C, вбудована схема захисту вимикає чип через перегрів, або напівпровідниковий перехід незворотно деградує за лічені секунди.

Причина цієї теплової катастрофи криється у колосальній фізичній невідповідності матеріалів, з яких зібрана плата. Електролітична мідь має питому теплопровідність близько 380–390 Вт/(м·К) — у понад 1300 разів вищу, ніж склотекстоліт. Тонкий шар мідної фольги товщиною 35 мкм (1 унція) на верхньому боці плати чудово розносить тепло в горизонтальній площині, але не здатний проштовхнути його крізь монолітну товщу діелектрика до внутрішніх шарів заземлення чи масивного нижнього радіатора. Діелектрик плати працює як високоефективний тепловий ізолятор, замикаючи всю теплову енергію всередині крихітної зони монтажу компонента.

Щоб пробити цей ізоляційний бар'єр і створити вертикальний канал із низьким тепловим опором, товщу друкованої плати безпосередньо під тепловим майданчиком прошивають **тепловими перехідними отворами (thermal vias)**. Тонка мідна циліндрична гільза товщиною 20–35 мкм, нанесена на стінки просвердленого отвору під час гальванічного міднення, утворює паралельні металеві містки крізь діелектрик. Проте спроба розставити ці отвори навмання створює новий комплекс технологічних проблем: від капілярного витікання рідкого припою під час пайки з утворенням критичних порожнин до ефекту теплового насичення, коли додавання зайвих отворів уже не знижує температуру кристала.

## 1. Фізика теплопередачі в платі: анізотропія FR-4 проти міді

Склотекстоліт ґатунку FR-4 не є однорідним ізотропним матеріалом. Він складається з кількох шарів тканого скловолокна (ниток алюмоборосилікатного скла E-glass), просочених епоксидною смолою. Скловолокно та застигла смола мають кардинально різні теплофізичні характеристики. Нитки скла проводять тепло значно краще, ніж епоксидна матриця, і орієнтовані виключно вздовж поверхні плати (у площині X-Y).

![Фізика теплопередачі: монолітний діелектрик FR-4 блокує тепловий потік, тоді як масив перехідних отворів створює вертикальну магістраль до протилежних мідних шарів.](/root/hw/hw-pcb/thermal-vias/img/pcb-thermal-conduction-contrast.svg)
*Фізика теплового бар'єра в друкованій платі: зліва — перегрів кристала в монолітному діелектрику FR-4 через низьку теплопровідність у напрямку осі Z; справа — ефективне вертикальне відведення тепла за допомогою паралельного масиву мідних перехідних отворів.*

Через шарувату структуру склотекстоліт демонструє виражену **теплову анізотропію** — його властивості залежать від просторового напрямку:

- **У площині плати (осі X та Y):** тепло передається вздовж неперервних скляних волокон, забезпечуючи коефіцієнт теплопровідності `k_xy ≈ 0.8–1.05 Вт/(м·К)`.
- **Поперек плати (вісь Z):** тепло змушене послідовно долати шари чистої епоксидної смоли між шарами склотканини. Теплопровідність у цьому напрямку падає до `k_z ≈ 0.25–0.30 Вт/(м·К)`.

Для порівняння зіставимо теплофізичні параметри основних конструкційних матеріалів друкованого вузла:

| Матеріал | Теплопровідність k [Вт/(м·К)] | Питомий електричний опір ρ [Ом·м] | Роль у тепловому балансі плати |
|---|---|---|---|
| **Гальванічна мідь (Electrodeposited Cu)** | 380–395 | 1.72·10⁻⁸ | Головний тепловий та електричний провідник |
| **Припій SAC305 (Sn96.5 Ag3.0 Cu0.5)** | 58 | 1.32·10⁻⁷ | Тепловий контакт «корпус чипа — контактний майданчик» |
| **Алюміній (сплав 6061)** | 160–180 | 3.99·10⁻⁸ | Матеріал зовнішніх радіаторів та теплорозподільних пластин |
| **FR-4 (у площині X-Y)** | 0.80–1.05 | > 10¹² | Помірне горизонтальне розсіювання тепла |
| **FR-4 (поперек шарів, вісь Z)** | 0.25–0.30 | > 10¹² | **Тепловий бар'єр (термоізолятор)** |
| **Повітря (за нормальних умов)** | 0.026 | Ізолятор | Порожнечі та voids блокують тепловідвід |

Коли кристал площею `A` виділяє теплову потужність `P`, одновимірний тепловий опір монолітного шару FR-4 товщиною `h` без перехідних отворів розраховується за формулою:

```text
R_θ,FR4 = h / (k_z · A)
```

Для квадратного майданчика розміром 3.0 × 3.0 мм (`A = 9·10⁻⁶ м²`) на платі товщиною `h = 1.6 мм` (`1.6·10⁻³ м`):

```text
R_θ,FR4 = 1.6·10⁻³ м / (0.28 Вт/(м·К) · 9.0·10⁻⁶ м²) ≈ 635 К/Вт
```

Навіть якщо врахувати тривимірне пірамідальне розтікання тепла під кутом 45° у товщу текстоліту, еквівалентний опір ділянки FR-4 під чіпом не опускається нижче 60–80 К/Вт. Це означає, що передати навіть 1 Вт тепла на зворотний бік плати безпосередньо крізь склотекстоліт неможливо. Єдиним фізичним порятунком є створення металевих паралельних шунтів — теплових перехідних отворів.

## 2. Тепловий опір одного перехідного отвору

Перехідний отвір формується механічним або лазерним свердлінням каналу діаметром `d` з подальшим хімічним та гальванічним нарощуванням шару чистої міді товщиною `t` на стінки.

![Геометрія та розріз одиничного теплового перехідного отвору: мідна циліндрична гільза товщиною t у платі товщиною h.](/root/hw/hw-pcb/thermal-vias/img/thermal-via-anatomy-formula.svg)
*Анатомія одиничного теплового перехідного отвору (thermal via) та геометричний розрахунок площі поперечного перерізу мідної гільзи для визначення власного теплового опору.*

З точки зору геометрії провідна частина отвору — це порожниста тонкостінна циліндрична трубка (гільза, або *barrel*) довжиною `h`, зовнішнім діаметром `d` і товщиною стінки `t`.

Площа поперечного перерізу мідного кільця:

```text
A_Cu = π · ( (d / 2)² − ((d − 2·t) / 2)² ) = π · (d·t − t²)
```

Застосовуючи диференціальний закон Фур'є для стаціонарного теплового потоку вздовж циліндричної стінки довжиною `h`, отримуємо точну аналітичну формулу теплового опору одиничного отвору:

```text
R_θ,via = h / ( k_Cu · π · (d·t − t²) )
```

Детальні математичні перетворення, розрахунок теплової провідності осердя та моделювання тривимірного розтікання наведено у [виведенні формул теплопровідності та опору розтікання](root:hw-pcb/thermal-vias/math-thermal-resistance.md).

### Вплив конструктивних параметрів на опір одиничного via

Розрахуємо значення власного теплового опору одиничного перехідного отвору для різних діаметрів свердла `d`, товщини металізації `t` та товщини плати `h` (при `k_Cu = 385 Вт/(м·К)`):

| Діаметр свердла d [мм] | Товщина металізації t [мкм] | Товщина плати h [мм] | Площа перерізу міді A_Cu [мм²] | Тепловий опір R_θ,via [К/Вт] |
|---|---|---|---|---|
| 0.20 (8 mil) | 20 (IPC Class 2) | 1.6 | 0.0113 | **367.4 К/Вт** |
| 0.30 (12 mil) | 20 (IPC Class 2) | 1.6 | 0.0176 | **236.0 К/Вт** |
| **0.30 (12 mil)** | **25 (IPC Class 3)** | **1.6** | **0.0216** | **192.4 К/Вт** |
| 0.30 (12 mil) | 35 (1 oz Heavy) | 1.6 | 0.0291 | **142.6 К/Вт** |
| 0.30 (12 mil) | 25 (IPC Class 3) | **1.0** | **0.0216** | **120.3 К/Вт** |
| 0.50 (20 mil) | 25 (IPC Class 3) | 1.6 | 0.0373 | **111.4 К/Вт** |
| 0.30 (суцільна Cu) | 150 (Solid Copper) | 1.6 | 0.0707 | **58.8 К/Вт** |

З аналізу таблиці випливає фундаментальний висновок: **один окремий перехідний отвір має високий тепловий опір — близько 190–240 К/Вт** для стандартної плати 1.6 мм. Сам по собі один отвір не здатний вирішити проблему охолодження силового чипа. Щоб знизити опір до прийнятних одиниць градусів на ват, під корпус встановлюють паралельний масив із десятків таких отворів.

## 3. Геометрія теплової матриці під Exposed Pad

Коли під нагрітим майданчиком компонента паралельно розташовано `N` однакових перехідних отворів, їхній сумарний опір у першому наближенні ділиться на кількість vias:

```text
R_θ,array = R_θ,via / N
```

Для масиву з 16 отворів (`d = 0.3 мм`, `t = 25 мкм`, `h = 1.6 мм`) еквівалентний опір гільз становить `192.4 К/Вт / 16 ≈ 12.0 К/Вт`.

*Матриця теплових отворів під термопадом компонента: правила розміщення з кроком 1.0–1.2 мм, віконне розбиття паяльного трафарету та запобігання капілярному засмоктуванню припою за рахунок вибору діаметра отвору d = 0.3 мм.*

### Крок отворів (Via Pitch) та ефект теплового насичення

При проєктуванні виникає спокуса просвердлити якомога більше отворів із мінімальним зазором між ними. Проте реальна поведінка тепла підкоряється **закону спадної віддачі (diminishing returns)**:

1. **Опір розтікання у тонкій мідній фользі:** Тепло надходить від невеликої площі кристала (die) у верхній контактний шар міді завтовшки всього 35 мкм. Перш ніж потрапити до віддалених via, тепловий потік долає горизонтальний опір міді. Отвори, які лежать далі від центру кристала, отримують усе меншу частку тепла.
2. **Перекриття зон теплового збору:** Кожен перехідний отвір відбирає тепло з навколишньої площі фольги радіусом приблизно 0.5–0.7 мм. Якщо зблизити отвори на відстань менше ніж 0.8 мм (pitch < 0.8 мм), їхні зони збору перекриваються: два сусідні via починають «красти» тепло один в одного, і сумарна тепловіддача зростає незначно.
3. **Механічна деградація та вартість:** Занадто щільна перфорація послаблює склотекстоліт під мікросхемою, провокуючи розшарування (delamination) при циклічному нагріванні та охолодженні.

**Практичні правила розміщення матриці:**
- Оптимальний крок між центрами via (Pitch): **1.0–1.2 мм** (типово 1.0 мм / 40 mil або 1.27 мм / 50 mil).
- Оптимальний діаметр отвору: **0.30 мм** (12 mil).
- Згущення матриці понад 16–25 отворів під стандартним корпусом 5×5 мм чи 7×7 мм зменшує температуру кристала менш ніж на 1–2 °C, але різко збільшує виробничі ризики.

## 4. Паяння, витікання припою (Solder Wicking) та IPC-4761

Найнебезпечніша помилка конструктора — використання отворів великого діаметра (`d ≥ 0.5 мм`) всередині відкритого контактного майданчика SMD-компонента без попереднього заповнення.

### Механізм капілярного витікання (Solder Wicking)

Під час пайки оплавленням у конвекційній печі паяльна паста плавиться при температурі 217–225 °C (для безсвинцевого сплаву SAC305). Рідкий припій має низьку динамічну в'язкість та високе змочування мідних стінок. Якщо діаметр отвору перевищує 0.35 мм, **капілярні сили засмоктують рідкий припій всередину вертикального каналу via**.

Це призводить до трьох важких дефектів монтажу:

1. **Голодування паяного шва (Solder Starvation) та порожнини (Voids):** Більша частина припою стікає крізь отвір на зворотний бік плати. Під термопадом утворюються гігантські повітряні кишені (порожнечі площею понад 40–70%). Повітря з теплопровідністю 0.026 Вт/(м·К) блокує контакт, і кристал згорає від локального перегріву.
2. **Краплі та кульки припою на зворотному боці (Solder Balls / Bumps):** Витіклий припій застигає у вигляді кулястих наростів на нижньому боці плати. Якщо під платою монтується плаский радіатор або металевий корпус, ці кульки деформують плату, пробивають ізоляційну термопрокладку або замикають сусідні доріжки.
3. **Перекіс та зміщення мікросхеми:** Неоднакове втягування припою під різними кутами корпуса спричиняє перекіс компонента й обрив пайки сигнальних ніжок (tombstoning / open pins).

### Чому діаметр 0.3 мм є критичним стандартом

При діаметрі свердла `d = 0.30 мм` (або `d = 0.25 мм`) та товщині металізації 25 мкм кінцевий внутрішній просвіт отвору становить лише 0.25 мм. При таких розмірах сила **поверхневого натягу** розплавленого припою утворює стійкий меніск на вході в отвір, який перешкоджає вільному стіканню пасти вниз. Припій залишається у шві між корпусом і платою.

### Трафаретний друк: віконна матриця (Windowed Stencil)

Нанесення суцільного шару паяльної пасти (100% апертура) на великий термопад суворо заборонено. При нагріванні рідкий флюс закипає. Під суцільною кришкою корпусу пари розчинників і флюсу не можуть вийти назовні й утворюють великі газові порожнини (gas voids).

Правильне рішення — **віконний трафарет (Windowed Stencil Aperture)**:
- Суцільний майданчик розбивають на матрицю з 4, 9 або 16 окремих квадратних віконець.
- Коефіцієнт покриття пастою (Solder Coverage) встановлюють на рівні **50–70%** від площі майданчика.
- Між віконцями залишають чисті смуги без пасти шириною 0.15–0.25 мм, які слугують дренажними каналами для безперешкодного виходу летких газів флюсу під час оплавлення.

### Технології обробки отворів за стандартом IPC-4761

Коли крок виводів компонента стає меншим за 0.8 мм (дрібні BGA, мікросхеми CSP, ультракомпактні QFN), розмістити отвори діаметром 0.3 мм між виводами неможливо. Виникає необхідність свердлити отвори безпосередньо всередині мініатюрних паяльних площадок (Via-in-Pad). Для цього застосовують технології захисту та заповнення за стандартом **IPC-4761**.

![Класифікація конструкцій перехідних отворів за стандартом IPC-4761 та будова планарного переходу VIPPO (Type VII).](/root/hw/hw-pcb/thermal-vias/img/ipc4761-via-types-vippo.svg)
*Конструкції перехідних отворів за стандартом IPC-4761: тентовані (Type I), заповнені смолою (Type III) та планарні з гальванічним покриттям міддю VIPPO (Type VII) для дрібнокрокових корпусів BGA та QFN.*

- **IPC-4761 Type I (Tented):** Отвір закривається плівкою паяльної маски з одного або двох боків. Найдешевше рішення, але **непридатне для Via-in-Pad**: під паяним майданчиком плівка маски лопається від температури, або припій стікає в порожнину.
- **IPC-4761 Type III (Plugged):** Отвір заповнюється епоксидною маскою або пастою без металізації поверхні. На вході залишається поглиблення (димпл), яке може утримувати бульбашки повітря.
- **IPC-4761 Type VII (VIPPO — Via-in-Pad Plated Over / POFV — Plated Over Filled Via):**
  1. Свердлиться отвір малого діаметра (0.20–0.25 мм) і металізується міддю на стінках.
  2. Канал повністю під вакуумом заповнюється неелектропровідною епоксидною смолою з низьким коефіцієнтом термічного розширення (CTE).
  3. Поверхня плати механічно шліфується та полірується заподлице з мідною фольгою (планаризація).
  4. Поверх заповненого отвору гальванічним методом осаджується суцільний шар вторинної міді (мідна кришка — *cap plating*) товщиною не менше 12 мкм.

Технологія **VIPPO (Type VII)** створює абсолютно плаский, гладкий, суцільний мідний контактний майданчик. Вона гарантує 100% площу контакту під кулькою BGA чи термопадом QFN, повністю ліквідує ризик втягування припою та запобігає утворенню пустот.

Повний звід нормативів, класи товщини міднення за IPC-6012 та правила трафарету наведено у [довіднику типів переходів IPC-4761 та правил трафарету](root:hw-pcb/thermal-vias/api-vippo-specs.md).

## 5. Підключення до внутрішніх шарів та термомеханічна втома

У багатошарових друкованих платах (4, 6 і більше шарів) теплові перехідні отвори виконують подвійну функцію: вони не лише передають тепло на протилежний бік плати, але й скидають тепловий потік у внутрішні суцільні мідні площини заземлення та живлення (`GND Plane`, `PWR Plane`).

### Заборона термобар'єрів (Thermal Relief)

При проєктуванні сигнальних отворів для полегшення ручної пайки полігони підключають через так звані термохрести або термобар'єри (англ. *thermal relief* — 4 тонкі мідні перемички шириною 0.2–0.3 мм). Для сигнальних кіл це запобігає надмірному відведенню тепла від жала паяльника.

Проте на силових теплових майданчиках та у перехідних отворах охолодження **використання термобар'єрів категорично заборонено**:
- Тонкі перемички термохреста створюють колосальний локальний опір розтікання (звуження ліній теплового потоку).
- Термобар'єр збільшує тепловий опір контакту отвору з внутрішньою площиною у 4–8 разів, повністю знецінюючи наявність внутрішніх мідних шарів.
- **Правило проєктування:** Усі теплові отвори повинні мати **пряме суцільне з'єднання (Direct Connect / Solid Fill)** з усіма доступними площинами міді на внутрішніх і зовнішніх шарах.

### Термомеханічна втома та циклічність (Thermal Fatigue)

Під час роботи силової електроніки температура плати постійно коливається від кімнатної (20 °C) до робочої (80–110 °C). Усі матеріали плати розширюються, але з кардинально різною швидкістю. Коефіцієнт термічного розширення (CTE) вздовж осі Z для склотекстоліту FR-4 становить `CTE_z ≈ 50–70 ppm/°C` (до температури склування `T_g`) і підскакує до `250–350 ppm/°C` при нагріванні вище `T_g`. Водночас електролітична мідь розширюється зі швидкістю лише `CTE_Cu ≈ 17 ppm/°C`.

Ця різниця коефіцієнтів у 3–15 разів створює колосальні циклічні механічні напруження розтягу вздовж осі циліндра. Якщо товщина металізації стінки становить менше 18–20 мкм (дефект травлення чи неякісна гальваніка Class 1), через кілька сотень циклів вмикання-вимикання відбувається втомний поперечний зсув або круговий розрив мідної гільзи (barrel cracking). Після розриву гільзи тепловий контакт миттєво зникає, опір зростає у сотні разів, і мікросхема зазнає аварійного перегріву. Забезпечення гарантованої товщини міді `t ≥ 25 мкм` (IPC Class 3) є головним конструктивним бар'єром проти втомного руйнування теплових переходів.

## 6. Повний тепловий ланцюг: Кристал → Плата → Радіатор

Тепловий розрахунок надійного електронного пристрою будується як послідовний аналіз теплового еквівалентного кола. Згідно з аналогією закону Ома:
- Різниця температур `ΔT` [°C або К] відповідає різниці потенціалів (напрузі `U`).
- Тепловий потік `P` [Вт] відповідає електричному струму `I`.
- Тепловий опір `R_θ` [К/Вт] відповідає електричному опору `R`.

Температура переходу напівпровідникового кристала `T_J` визначається рівнянням:

```text
T_J = T_A + P · R_θ,JA
```

де `T_A` — температура навколишнього середовища, `R_θ,JA` — сумарний тепловий опір «кристал-середовище» (Junction-to-Ambient).

![Еквівалентна теплова схема ланцюга охолодження та графік покрокового спаду температури від кремнієвого кристала до навколишнього повітря.](/root/hw/hw-pcb/thermal-vias/img/thermal-equivalent-circuit.svg)
*Повний еквівалентний тепловий ланцюг «Кристал — Припій — Масив Via — Нижня мідь — Термоінтерфейс — Радіатор — Середовище» та відповідний температурний профіль перепадів ΔT.*

Повний тепловий опір є сумою послідовних ділянок теплового тракту:

```text
R_θ,JA = R_θ,JC + R_θ,solder + R_θ,vias + R_θ,spread,bot + R_θ,TIM + R_θ,SA
```

Розберемо кожну ланку цього ланцюга:

1. **Опір кристала до підкладки корпуса (`R_θ,JC` — Junction-to-Case):** Внутрішній опір мікросхеми, визначений виробником у даташиті. Для корпусів із відкритим майданчиком (QFN, DFN, D2PAK, TO-263) становить **1.0–3.0 К/Вт**.
2. **Опір паяного з'єднання (`R_θ,solder`):** Шар припою SAC305 товщиною 50 мкм (`k = 58 Вт/(м·К)`) під падом 5×5 мм за відсутності порожнин додає менше **0.05 К/Вт**. За наявності 50% порожнин (через wicking) цей опір зростає до 0.3–0.8 К/Вт і створює небезпечні локальні гарячі точки.
3. **Опір масиву перехідних отворів (`R_θ,vias`):** Матриця 16 отворів `d = 0.3 мм`, `t = 25 мкм` на платі 1.6 мм забезпечує опір **7.0–12.0 К/Вт**.
4. **Опір розтікання у нижній мідній площині (`R_θ,spread,bot`):** Розтікання тепла від матриці отворів до країв нижнього мідного полігону становить **2.0–5.0 К/Вт** (залежно від площі та товщини фольги 1 oz чи 2 oz).
5. **Опір теплоінтерфейсу (`R_θ,TIM` — Thermal Interface Material):** Еластична термопрокладка або шар термопасти (`k = 2.0–6.0 Вт/(м·К)`), яка згладжує мікронерівності між нижнім боком плати та радіатором, вносить **2.0–4.0 К/Вт**.
6. **Опір «радіатор-середовище» (`R_θ,SA` — Sink-to-Ambient):** Відведення тепла від ребер радіатора у навколишнє повітря за рахунок природної конвекції та випромінювання (**5.0–15.0 К/Вт**) або примусового обдуву вентилятором (**1.0–3.0 К/Вт**).

## 7. Програмний розрахунок теплового бюджету в EDA

Для автоматизації розрахунку та інтеграції в скрипти перевірки правил проєктування (DRC) наведемо інженерний розрахунковий модуль мовами C та C++.

@tab C
```c
#include <stdio.h>
#include <stdbool.h>
#include <math.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

// Розрахунок теплового балансу вузла друкованої плати
typedef struct {
    double pcb_thickness_m;      // Товщина плати (h), м
    double via_drill_m;          // Діаметр отвору via (d), м
    double via_copper_thk_m;     // Товщина металізації via (t), м
    int    via_count;            // Кількість отворів у матриці (N)
    double r_jc_k_w;             // Опір кристал-корпус (R_theta_JC), К/Вт
    double r_tim_k_w;            // Опір термопрокладки (R_theta_TIM), К/Вт
    double r_heatsink_k_w;       // Опір радіатора (R_theta_SA), К/Вт
    double ambient_temp_c;       // Температура середовища (T_A), °C
    double power_dissipation_w;  // Потужність, що розсіюється (P), Вт
} ThermalCircuitConfig;

typedef struct {
    double r_single_via_k_w;
    double r_via_array_k_w;
    double r_total_ja_k_w;
    double junction_temp_c;
    bool   is_safe;
} ThermalCircuitResult;

ThermalCircuitResult solve_pcb_thermal(const ThermalCircuitConfig *cfg) {
    const double k_copper = 385.0; // Вт/(м·К)
    ThermalCircuitResult res;

    // Площа поперечного перерізу мідної гільзи: A = pi * (d*t - t^2)
    double d = cfg->via_drill_m;
    double t = cfg->via_copper_thk_m;
    double a_copper = M_PI * (d * t - t * t);

    // Опір одного via та масиву
    res.r_single_via_k_w = cfg->pcb_thickness_m / (k_copper * a_copper);
    res.r_via_array_k_w  = res.r_single_via_k_w / (double)cfg->via_count;

    // Сумарний тепловий опір (додаємо типовий опір розтікання у міді 3.0 К/Вт і припій 0.1 К/Вт)
    double r_pcb_extras = 3.1;
    res.r_total_ja_k_w = cfg->r_jc_k_w + res.r_via_array_k_w + r_pcb_extras + 
                         cfg->r_tim_k_w + cfg->r_heatsink_k_w;

    // Температура напівпровідникового переходу T_J
    res.junction_temp_c = cfg->ambient_temp_c + cfg->power_dissipation_w * res.r_total_ja_k_w;
    res.is_safe = (res.junction_temp_c <= 125.0);

    return res;
}

int main(void) {
    ThermalCircuitConfig cfg = {
        .pcb_thickness_m     = 0.0016, // 1.6 мм
        .via_drill_m         = 0.0003, // 0.3 мм
        .via_copper_thk_m    = 0.000025, // 25 мкм
        .via_count           = 16,     // Матриця 4x4
        .r_jc_k_w            = 2.0,    // 2.0 К/Вт
        .r_tim_k_w           = 3.0,    // 3.0 К/Вт
        .r_heatsink_k_w      = 6.0,    // 6.0 К/Вт
        .ambient_temp_c      = 25.0,   // 25 °C
        .power_dissipation_w = 4.6     // 4.6 Вт
    };

    ThermalCircuitResult r = solve_pcb_thermal(&cfg);

    printf("Одиничний via: R_th = %.1f K/W\n", r.r_single_via_k_w);
    printf("Матриця 16 via: R_th = %.2f K/W\n", r.r_via_array_k_w);
    printf("Повний опір R_th(JA): %.2f K/W\n", r.r_total_ja_k_w);
    printf("Температура кристала T_J: %.1f C (%s)\n", 
           r.junction_temp_c, r.is_safe ? "НОРМА" : "ПЕРЕГРІВ!");

    return 0;
}
```

## 8. Практичний підсумок: чек-лист проєктування thermal vias

1. **Діаметр свердла:** Використовуйте стандартний діаметр **0.30 мм** (12 mil) для відкритих отворів. Це виключає витікання припою (solder wicking) за рахунок сил поверхневого натягу.
2. **Крок розміщення:** Дотримуйтесь кроку сітки **1.0–1.2 мм**. Згущення менше ніж 0.8 мм неефективне через насичення площі теплового збору.
3. **Пряме підключення до міді:** Забороніть термобар'єри (thermal relief) на термопадах. З'єднання з полігонами землі та внутрішніми шарами має бути суцільним і прямим (Solid / Direct Connect).
4. **Трафаретний друк:** Розбийте апертуру паяльної пасти під термопадом на сітку віконець із сумарним покриттям **50–70%**, щоб запобігти утворенню газових порожнин.
5. **Вибір VIPPO:** Для BGA з кроком ≤ 0.8 мм та мікросхем CSP обов'язково замовляйте технологію **IPC-4761 Type VII (VIPPO)** з епоксидним заповненням та мідненням площадки заподлице.
