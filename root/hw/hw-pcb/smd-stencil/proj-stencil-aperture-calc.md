# Розрахунок апертур трафарету та оптимізація перенесення пасти (Stencil Aperture Calculator)

Виробничий процес поверхневого монтажу (SMT) вимагає суворого математичного контролю геометрії кожної апертури трафарету. У сучасному змішаному монтажі на одній друкованій платі співіснують мініатюрні пасивні чіпи типорозмірів 0201 та 0402, мікроконтролери у безвивідних корпусах QFN/DFN із кроком виводів 0.4 мм та великими тепловими майданчиками площею 20–50 мм², BGA-мікросхеми з кульковими виводами діаметром 0.25–0.30 мм, а також масивні силові роз'єми наскрізного монтажу, що монтуються за технологією оплавлення припою в отворах (Pin-in-Paste / Through-Hole Reflow, THR).

Якщо для всіх цих компонентів використати просте пряме копіювання контурів мідних площадок у шар трафарету (масштаб 1:1) на сталевій фользі фіксованої товщини (наприклад, 120 мкм), виробнича лінія зіткнеться з нерозв'язним конфліктом дефектів:
- Сигнальні виводи QFN 0.4 мм матимуть коефіцієнт площі `AR = 0.52 < 0.66`, що призведе до застрягання пасти в апертурах та утворення дефектів непропаю (англ. *insufficient solder / starvation*).
- Центральний тепловий майданчик QFN площею 25 мм² отримає 100% суцільний відбиток пасти, що викличе спливання деталі на рідкому меніску, перекіс корпусу та утворення велетенських газових каверн (англ. *voids > 40%*) від закипання летких компонентів флюсу.
- Чіп-компоненти 0402 та 0603 отримають надлишок пасти на внутрішніх гранях площадок, який при встановленні витиснеться під корпус і утворить паразитні металеві кульки (англ. *solder beads*).
- Металізовані отвори силових роз'ємів Pin-in-Paste недоотримають 50% необхідного металу через дворазову усадку об'єму пасти під час оплавлення флюсу, порушуючи вимоги стандарту IPC-A-610 Class 3 щодо 100% вертикального заповнення отвору.

Для усунення цих проблем розробляється спеціалізований інженерний розрахунковий інструмент — **Калькулятор та оптимізатор апертур трафарету (Stencil Aperture & Transfer Efficiency Calculator)**, що реалізує строгі алгоритми проектування трафаретів за стандартами IPC-7525, IPC-7351 та IPC-A-610.

### Фізико-математична модель трафаретного перенесення

#### 1. Гідродинамічне нагнітання та напруження зсуву в клині ракеля

Під час руху ракеля паяльна паста захоплюється похилим металевим лезом, нахиленим під кутом атаки `α = 60°` до горизонтальної площини трафарету. У звужувальному клині формується поле гідродинамічного тиску, яке описується розв'язком рівняння Нав'є-Стокса для неньютонівської псевдопластичної рідини Гершеля-Балклі:

```
τ = τ₀ + K · γ̇ⁿ      [реологічне рівняння напруження зсуву]
```

де `τ₀` — початкова границя плинності пасти (`50–150 Па`), `K` — коефіцієнт консистенції, `γ̇` — швидкість зсуву (`с⁻¹`), `n` — індекс течії (`n ≈ 0.35–0.50`).

Швидкість деформації зсуву під лезом ракеля досягає `γ̇ ≈ v / h_gap ≈ 1000–5000 с⁻¹` (де `v` — швидкість руху ракеля `40–80 мм/с`, `h_gap` — мікрозазор під кромкою леза). При такій високій швидкості зсуву внутрішня просторова сітка тиксотропного загусника руйнується, і динамічна в'язкість пасти падає з `1000 Па·с` (у стані спокою) до `50–80 Па·с` (під лезом).

Гідродинамічний тиск нагнітання пасти `P_h` у зоні входу в апертуру становить:

```
P_h = (6 · η · v · sin²(α)) / [ h_eff · (α - sin(α) · cos(α)) ]
```

Для повного заповнення мікроапертури час перебування порожнини під зоною нагнітання валика пасти `t_fill = L_roll / v` повинен перевищувати час релаксації в'язкості рідини `t_relax ≈ 0.05–0.10 с`. При швидкостях друку `v > 120 мм/с` для апертур глибиною `120–150 мкм` виникає ефект неповного заповнення, коли повітря не встигає витіснитися з дна апертури, формуючи первинні порожнечі у відбитку пасти.

### Геометричні моделі апертур за стандартом IPC-7525

Стандарт IPC-7525 встановлює два фундаментальні геометричні критерії, що визначають баланс сил між адгезією пасти до мідної площадки друкованої плати та силами тертя об внутрішні стінки фольги трафарету під час вертикального розділення:

1. **Коефіцієнт площі (Area Ratio, AR)**:
   ```
   AR = A_pad / A_walls
   ```
   де `A_pad` — площа основи апертури, що контактує з мідною площадкою плати, `A_walls` — сумарна площа всіх внутрішніх бічних стінок апертури.
2. **Коефіцієнт пропорції (Aspect Ratio, AS)**:
   ```
   AS = W / T
   ```
   де `W` — найменший лінійний розмір отвору в площині, `T` — товщина фольги трафарету.

Нормативні обмеження:
- `AR ≥ 0.66` (для стандартної нержавіючої сталі без покриття);
- `AR ≥ 0.50–0.55` (для електрополірованої сталі з гідрофобним нанопокриттям Nano-coating);
- `AS ≥ 1.50` (для гарантованого проштовхування пасти на дно апертури під тиском ракеля).

Нижче наведено строгі геометричні формули розрахунку площ для всіх типів сучасних апертур:

#### 1. Прямокутна апертура (Rectangular Aperture)
```
A_pad = W · L
A_walls = 2 · (W + L) · T
AR = (W · L) / [ 2 · (W + L) · T ]
AS = min(W, L) / T
```

#### 2. Кругла апертура (Circular Aperture для кульок BGA та CSP)
```
A_pad = π · (D / 2)² = (π · D²) / 4
A_walls = π · D · T
AR = [ (π · D²) / 4 ] / (π · D · T) = D / (4 · T)
AS = D / T
```

#### 3. Прямокутна апертура із заокругленими кутами (Rounded Rectangle)
Лазерне різання формує природні радіуси заокруглення `R` у кутах апертури. Видалення прямих кутів 90° зменшує адгезійні пастки:
```
A_pad = W · L - (4 - π) · R²
P_perimeter = 2 · (W + L) - (8 - 2 · π) · R
A_walls = P_perimeter · T
AR = A_pad / A_walls
```

#### 4. Овальна апертура (Obround / Stadium)
Прямокутне тіло з двома напівкруглими торцями радіусом `R = W / 2` при довжині `L ≥ W`:
```
A_pad = (L - W) · W + π · (W / 2)² = W · L - W² · (1 - π / 4)
P_perimeter = 2 · (L - W) + π · W
A_walls = P_perimeter · T
AR = A_pad / A_walls
```

#### 5. Апертура форми Home-Plate (П'ятикутник проти Solder Beads)
Для дискретних чіпів 0402/0603/0805 внутрішній торець апертури підрізається у вигляді трикутного вістря зі скосом під кутом `45°` або `60°` на довжину скосу `c`:
```
A_pad = W · L - 0.5 · W · c
P_perimeter = 2 · (L - c) + W + 2 · sqrt( c² + (W / 2)² )
A_walls = P_perimeter · T
AR = A_pad / A_walls
```

Ця геометрія прибирає 15–25% об'єму пасти саме з внутрішнього краю площадки, усуваючи паразитне витискання припою під керамічний корпус конденсатора під час встановлення Pick-and-Place.

### Моделювання коефіцієнта передачі пасти (Transfer Efficiency)

Коефіцієнт передачі пасти (англ. *Transfer Efficiency, TE*) — це відношення фактичного об'єму вивільненого стовпчика пасти `V_actual` на платі до теоретичного внутрішнього об'єму вікна трафарету `V_theoretical = A_pad · T`:

```
TE = V_actual / V_theoretical
```

На основі масивів вимірювань оптичних 3D SPI систем поведінка Transfer Efficiency як функція Area Ratio апроксимується логістичною сигмоїдною кривою:

```
TE(AR) = TE_max / [ 1 + exp( -k · (AR - AR₀) ) ]
```

Параметри моделі залежать від типу пасти (розміру кульок) та наявності нанопокриття:
- Для стандартної лазерної фольги без покриття (паста Type 4): `TE_max = 0.95`, `k = 11.0`, `AR₀ = 0.55`.
- Для фольги з полімерним гідрофобним нанопокриттям: `TE_max = 0.98`, `k = 14.0`, `AR₀ = 0.45`.
- Для дрібнодисперсної пасти Type 5 на нанопокритті: `TE_max = 0.99`, `k = 16.0`, `AR₀ = 0.40`.

Таблиця емпіричних калібрувальних параметрів для різних класів SMT-процесів:

| Тип пасти | Технологія трафарету | `TE_max` | `k` (крутизна) | `AR₀` (точка перегину) | Очікуваний `TE` при `AR = 0.66` |
|---|---|---|---|---|---|
| **Type 3 (25–45 мкм)** | Лазерна сталь (Laser-cut) | 0.92 | 9.5 | 0.58 | 78.5% |
| **Type 3 (25–45 мкм)** | Електрополірування (EP) | 0.94 | 10.5 | 0.54 | 85.2% |
| **Type 4 (20–38 мкм)** | Лазерна сталь (Laser-cut) | 0.95 | 11.0 | 0.55 | 87.1% |
| **Type 4 (20–38 мкм)** | Нанопокриття (Nano-coated) | 0.98 | 14.0 | 0.45 | 94.5% |
| **Type 5 (15–25 мкм)** | Електроформування (Ni E-form) | 0.99 | 15.5 | 0.42 | 96.8% |
| **Type 5 (15–25 мкм)** | Нанопокриття (Nano-coated) | 0.99 | 16.0 | 0.40 | 97.4% |

При `AR < 0.45` функція швидко прямує до значень менше 0.30 (критичний зрив друку); при `AR = 0.66` значення `TE` становить `82–88%`, а при `AR ≥ 0.80` виходить на стабільне плато `92–95%`.

#### Статистична модель дефектності та інтеграл Гауса

Фактичний об'єм вивільненої пасти `V` на серійній лінії підпорядковується нормальному розподілу Гауса `N(μ, σ²)` для стабільних процесів (`AR ≥ 0.66`) або логнормальному розподілу з важким лівим хвостом при нестабільних процесах (`AR < 0.60`).

Середнє значення об'єму визначається математичним сподіванням `μ = V_theoretical · TE(AR)`, а середньоквадратичне відхилення `σ` залежить від стабільності процесу. Коефіцієнт варіації `CV = σ / μ` становить:
- При `AR ≥ 0.66`: `CV ≈ 0.04–0.06` (4–6% розкиду);
- При `0.50 ≤ AR < 0.66`: `CV ≈ 0.10–0.15` (10–15% розкиду);
- При `AR < 0.50`: `CV > 0.25` (катастрофічна нестабільність).

Ймовірність виникнення дефекту недостатності припою (starved solder joint), коли фактичний об'єм падає нижче нижньої межі специфікації `LSL = 0.60 · V_theoretical`, обчислюється через функцію помилок Гауса `erf()`:

```
Z_LSL = (LSL - μ) / σ
P(Defect) = 0.5 · [ 1 + erf( Z_LSL / sqrt(2) ) ]
```

При зниженні `AR` з 0.66 до 0.52 рівень дефектності `P(Defect)` зростає експоненційно — з менше ніж `10 ppm` (parts per million) до понад `15 000 ppm` (1.5% браку на кожен контакт мікросхеми).

### Статистичний контроль процесів (SPC) та індекси Cp / Cpk у 3D SPI

Для серійного контролю якості нанесення пасти оптична система 3D SPI вимірює об'єм кожного відбитка та розраховує ключові показники відтворюваності процесу за стандартом IPC-9850:

```
Cp = (USL - LSL) / (6 · σ)
Cpk = min( (USL - μ) / (3 · σ), (μ - LSL) / (3 · σ) )
```

де `USL = 1.40 · V_theor` (верхня межа специфікації), `LSL = 0.60 · V_theor` (нижня межа), `μ` — середнє виміряне значення об'єму, `σ` — середньоквадратичне відхилення по вибірці з 100 послідовно надрукованих плат.

Нормативні критерії стабільності:
- `Cpk ≥ 1.33` (відповідність концепції 4 Sigma, рівень дефектності `< 64 ppm`);
- `Cpk ≥ 1.67` (відповідність концепції 5 Sigma, дефектність `< 1 ppm`, обов'язкова вимога для автомобільної електроніки ISO/TS 16949 та аерокосмічного обладнання IPC Class 3);
- При `Cpk < 1.00` процес визнається неконтрольованим, і лінія автоматично зупиняється до корекції параметрів друку.

#### Замкнений зворотний зв'язок (Closed-Loop SPI to Printer Feedback)

Сучасні автоматичні лінії SMT об'єднують принтер трафаретного друку та установку 3D SPI у замкнену цифрову систему зворотного зв'язку (англ. *Closed-Loop Feedback*):
1. **Динамічне вирівнювання зсуву координат**: Якщо SPI виявляє систематичний дрейф положення пасти (зсув `ΔX`, `ΔY` або кут розвороту `ΔΘ`), значення похибки автоматично передаються на серводвигуни столу принтера для компенсації зміщення на наступній платі без участі оператора.
2. **Автоматичний запуск очищення трафарету (Auto-Wipe Trigger)**: Якщо SPI фіксує наростання висоти пасти в зоні мікросхем QFP або виявляє зменшення вільного зазору між сусідніми відбитками нижче `50 мкм` (перевищення індексу ризику утворення перемичок `Bridge_Risk > 15%`), системі принтера подається команда на позачерговий цикл вологого вакуумного очищення трафарету (Wet-Vac Wipe).

### Геометрія та розрахунок ступінчастих трафаретів (Step Stencil)

Коли на одній платі поєднуються ультратонкі мікросхеми WLCSP (крок кульок 0.35 мм, що вимагають товщини фольги `80–100 мкм`) та потужні силові роз'єми або котушки індуктивності (що потребують `150–180 мкм`), виникає необхідність проектування ступінчастого трафарету (Step-Up / Step-Down Stencil).

Ступінчастий рельєф створюється на поверхні фольги за допомогою прецизійного хімічного травлення або мікрофрезерування на глибину `ΔT = T_base - T_step`.

Для забезпечення стабільного проходження гнучкого металевого ракеля через перепад висот обов'язковим є дотримання інженерного правила безпечного відступу (Keepout Distance):

```
D_keepout ≥ 30 · ΔT
```

Якщо глибина локального потоншення Step-Down становить `ΔT = 120 мкм - 80 мкм = 40 мкм (0.040 мм)`, мінімальна відстань від краю потоншеної кишені до найближчої зовнішньої апертури повинна бути:

```
D_keepout ≥ 30 · 0.040 мм = 1.20 мм
```

Якщо цієї відстані не дотриматися, лезо ракеля зазнає пружного підскоку на сходинці, що викличе нерівномірне вичерпування пасти або затікання флюсу під фольгу в зоні перепаду висот.

### Термодинаміка оплавлення та сили поверхневого натягу (Tombstoning)

Нерівномірний розподіл об'єму пасти між двома контактними площадками двополюсних чіпів 0201/0402 є головною рушійною силою виникнення дефекту «могильного каменя» (Tombstoning).

Під час проходження піку термопрофілю печі розплавлений припій створює силу капілярного стягування на торці виводу:

```
F_cap = 2 · γ_LV · W_chip · cos(θ)
```

де `γ_LV` — поверхневий натяг рідкого сплаву (для SAC305 `γ_LV ≈ 0.55 Н/м`), `W_chip` — ширина деталі, `θ` — динамічний кут змочування.

Вертикальний перекидальний момент, що намагається підняти чіп на дибки навколо протилежного ребра:

```
M_overturn = F_cap · H_chip · sin(φ)
```

Цьому моменту протидіє сила гравітації та капілярне зчеплення рідкої пасти на протилежній площадці:

```
M_restore = m_chip · g · (L_chip / 2) + F_cap_opp · H_chip · cos(φ)
```

Якщо об'єм пасти на одній із площадок на `20–30%` перевищує протилежний (або площадки мають різну швидкість нагрівання через підключення до суцільного мідного полігону без термобар'єрів), різниця моментів `ΔM = M_overturn - M_restore` стає додатною. Обертальний момент миттєво підіймає конденсатор вертикально вгору протягом `0.05–0.15 секунди`. Редукція апертур форми Home Plate та точне вирівнювання розрахункових об'ємів пасти алгоритмом калькулятора зводять дисбаланс сил `ΔF` до нуля.

### Кінетика утворення газових каверн (Voiding) під великими площадками

Під час нагрівання в печі оплавлення органічні кислотні активатори (адипінова, бурштинова кислоти) та гліколеві розчинники флюсу починають інтенсивно кипіти в діапазоні температур `150–220°C`. Об'єм виділених летких газів у сотні разів перевищує початковий об'єм рідкої фракції флюсу.

Швидкість спливання та евакуації газової бульбашки радіусом `r_bubble` у товщі розплавленого припою описується законом Стокса:

```
v_bubble = [ 2 · r_bubble² · (ρ_solder - ρ_gas) · g ] / (9 · η_solder)
```

Оскільки густина розплавленого припою висока (`ρ ≈ 7.4 г/см³`), а в'язкість становить `η ≈ 0.002 Па·с`, підйомна сила Архімеда прагне виштовхнути бульбашку вгору. Проте над великим тепловим майданчиком QFN/DFN площею `20–50 мм²` розташоване суцільне плоске металізоване дно компонента, яке повністю блокує вертикальний вихід газів. Бульбашка змушена рухатися горизонтально від центру майданчика до периферійного краю.

Час горизонтальної евакуації газу з центру суцільної квадратної площадки зі стороною `L_pad` оцінюється за формулою:

```
t_evac = (L_pad / 2) / v_horiz
```

Якщо `L_pad = 5.0 мм`, довжина шляху евакуації становить `2.5 мм`, і газ просто не встигає дістатися краю за час перебування припою в розплавленому стані над точкою ліквідусу (Time Above Liquidus, `TAL = 45–60 с`). Велетенські бульбашки газу застигають всередині шва, утворюючи каверни площею понад `40–50%` від загальної площі контакту.

Віконна решітка (Window Pane) кардинально змінює фізику дегазації: розбиття майданчика на матрицю `3 × 3` вікна з сухими сталевими перемичками шириною `0.30–0.35 мм` створює мережу відкритих вентиляційних каналів безпосередньо над площею майданчика. Шлях евакуації газу з кожного окремого віконця скорочується з `2.5 мм` до всього `0.60 мм`, а сухі перемички слугують відкритими димовими трубами, якими гази вільно виходять назовні до моменту злиття розплавлених острівців металу. У результаті відсоток каверн (Void Area) знижується з критичних `45%` до нормативних `< 10%`, забезпечуючи максимальну теплопровідність `R_th` кристала та захищаючи його від локального перегріву.

### Механіка натягу трафарету та пружний прогин фольги

Фольга трафарету натягується на жорстку раму з нормованим натягом `T_tension = 35–45 Н/см` (`3500–4500 Н/м`). Під час руху ракеля металеве лезо створює розподілений вертикальний тиск `F_down ≈ 2.0 Па (2.0 Н/м²)`.

Максимальний пружний прогин фольги `δ_max` посередині робочого поля довжиною `L_span` описується формулою теорії пружності мембран:

```
δ_max = (F_down · L_span²) / (8 · T_tension)
```

Для трафарету з прольотом `L_span = 400 мм = 0.4 м` при нормативному натягу `T_tension = 40 Н/см = 4000 Н/м`:

```
δ_max = (2.0 · 0.4²) / (8 · 4000) = 0.32 / 32000 = 0.00001 м
```

Цей прогин у `0.00001 м` (`10 мкм`) є цілком допустимим і компенсується пружним підйомом столу принтера.

Проте якщо в процесі тривалої експлуатації натяг сітки трафарету деградує до `T_tension < 20 Н/см`, прогин зростає до `δ_max > 25–35 мкм`. При русі ракеля фольга починає хвилеподібно коливатися (ефект батута). Під час вертикального відриву плати трафарет зазнає раптового пружного горизонтального ривка (англ. *snap-off jitter*), амплітуда якого досягає `30–50 мкм`. Цей мікроривок змазує кути свіжонанесених стовпчиків пасти компонентів BGA та QFN 0.4 мм, призводячи до масових мікроперемичок. Саме тому регламент виробництва вимагає щодобового контролю натягу тензометром у 5 контрольних точках рамки (по кутах та в центрі) з вибракуванням при падінні натягу нижче `25 Н/см`.

### Алгоритм декомпозиції теплових майданчиків (Window-Pane Algorithm)

Для великих майданчиків QFN/DFN, силових DPAK та PowerSOIC суцільна апертура неприпустима. Алгоритм виконує автоматичне розбиття суцільного прямокутника розміром `W_pad × L_pad` на регулярну сітку вікон `N_x × N_y`:

1. **Цільові технологічні обмеження**:
   - Цільовий коефіцієнт покриття пастою: `Coverage_target = 50% – 70%` (типово `60%`);
   - Мінімальна технологічна ширина сталевої перемички між вікнами: `Web_min = 0.25–0.35 мм` (для збереження механічної жорсткості фольги під ракелем);
   - Максимальний лінійний розмір окремого вікна: `Window_max ≤ 1.5–2.0 мм` (для ефективної дегазації летких фракцій флюсу).
2. **Вибір розмірності сітки `N_x` та `N_y`**:
   ```
   N_x = max(1, round( W_pad / 1.5 ))
   N_y = max(1, round( L_pad / 1.5 ))
   ```
3. **Розрахунок розмірів одиничного вікна `w_win` та `l_win`**:
   Якщо майданчик розбивається перемичками шириною `w_web`, сумарна доступна ширина для вікон становить `W_pad - (N_x - 1) · w_web`.
   Для досягнення точного відсотка покриття `C`:
   ```
   w_win = sqrt( C · W_pad · L_pad / (N_x · N_y) ) · (W_pad / (W_pad + L_pad)) · 2
   l_win = (C · W_pad · L_pad) / (N_x · N_y · w_win)
   ```
   Кожне вікно додатково перевіряється на відповідність критерію `AR_win ≥ 0.66`.

4. **Орієнтація перемичок відносно руху ракеля**:
   Для мінімізації вичерпування пасти ракелем (англ. *squeegee scooping*) перемички віконної решітки повинні бути орієнтовані паралельно та перпендикулярно до напрямку руху ракеля. При діагональному друку перемички підтримують металеве лезо, унеможливлюючи його прогинання всередину порожнини апертури.

5. **Зони виключення термальних отворів (Via Exclusion)**:
   Якщо на тепловому майданчику розташована матриця відкритих перехідних отворів (Thermal Vias), віконна сітка повинна автоматично розраховуватися так, щоб лінії сталевих перемичок проходили точно над отворами, а вікна пасти лягали на суцільну мідь між отворами. Це повністю виключає затікання пасти в отвори при друку.

### Алгоритм розрахунку технології Pin-in-Paste (Through-Hole Reflow)

Для вивідного компонента, встановленого в металізований отвір (PTH), необхідний об'єм пасти розраховується з урахуванням 50% усадки:

```
V_hole = π · (D_hole / 2)² · H_pcb                  [об'єм отвору в діелектрику плати]
V_pin = S_pin · H_pcb                               [об'єм тіла виводу всередині отвору]
V_barrel_gap = V_hole - V_pin                       [об'єм зазору між штирем та металізацією]

V_fillet_top = 0.25 · V_barrel_gap                  [об'єм верхнього конічного меніска]
V_fillet_bot = 0.25 · V_barrel_gap                  [об'єм нижнього конічного меніска]

V_solder_net = V_barrel_gap + V_fillet_top + V_fillet_bot
V_paste_req = 2.0 · V_solder_net                    [з урахуванням 50% флюсу в пасті]
```

Формула розрахунку площі перерізу виводу `S_pin` залежить від його форми:
- Для круглого штиря діаметром `d`: `S_pin = (π · d²) / 4`.
- Для квадратного штиря зі стороною `a`: `S_pin = a²`.
- Для прямокутного виводу силового роз'єму шириною `w_p` та товщиною `t_p`: `S_pin = w_p · t_p`.

Якщо необхідний об'єм пасти `V_paste_req` перевищує об'єм, що вміщується в стандартну апертуру над мідним кільцем площадки (`V_stencil = A_pad · T`), алгоритм обчислює розміри прямокутного або хрестоподібного оверпринту (Overprint) на паяльну маску:

```
A_aperture_req = V_paste_req / T
Overprint_Side = sqrt( A_aperture_req )
```

#### Термодинаміка капілярного стягування з маски (Laplace Wicking)

Чому паста, надрукована на діелектричну паяльну маску навколо отвору, не утворює кульок бруду, а повністю втягується в отвір?
Розплавлений припій має високий поверхневий натяг (`γ_LV ≈ 0.55 Н/м`) та не змочує полімерну паяльну маску (крайовий кут `θ_mask > 120°`). Натомість рідкий флюс змочує чисту мідну металізацію всередині циліндра отвору (кут `θ_copper < 20°`).

Виникає потужний градієнт капілярного тиску Лапласа:

```
ΔP_Laplace = (2 · γ_LV · cos(θ_copper)) / r_hole
```

Для отвору радіусом `r_hole = 0.55 мм` тиск капілярного всмоктування становить `ΔP ≈ 1.8–2.2 кПа`. Цей тиск миттєво засмоктує розплавлену лінзу припою з гладкої паяльної маски всередину металізованого циліндра, формуючи ідеальну галтель меніска за стандартом IPC-A-610 Class 3.

### Покроковий математичний розрахунок для тестового набору компонентів

Розглянемо детальні ручні інженерні розрахунки для восьми характерних вузлів сучасної друкованої плати при базовій товщині фольги трафарету `T = 0.120 мм (120 мкм)`:

#### Кейс 1: Чіп-конденсатор C101 типорозміру 0201
- Розміри мідної контактної площадки: `W = 0.30 мм`, `L = 0.30 мм`.
- Площа площадки: `A_pad = 0.30 · 0.30 = 0.090 мм²`.
- Площа чотирьох бічних стінок апертури: `A_walls = 2 · (0.30 + 0.30) · 0.120 = 4 · 0.30 · 0.120 = 0.144 мм²`.
- Коефіцієнт площі: `AR = 0.090 / 0.144 = 0.625`.
- Коефіцієнт пропорції: `AS = 0.30 / 0.120 = 2.50 > 1.50` (`PASS`).
- **Аналіз IPC-7525**: Для звичайної лазерної сталі норматив становить `AR ≥ 0.66`. Значення `0.625` не проходить допуск (`FAIL`). За сигмоїдною моделлю очікуваний коефіцієнт передачі пасти становить лише `TE = 72.3%`, що створює високий ризик непропаю. При застосуванні фольги з гідрофобним нанопокриттям нормативний поріг знижується до `0.55`, переводячи апертуру в статус `PASS` із прогнозованим `TE = 89.4%` та об'ємом пасти `V = 0.00965 мм³ (9.65 нл)`.

#### Кейс 2: Чіп-резистор R105 типорозміру 0402 із радіусними кутами
- Розміри площадки: `W = 0.50 мм`, `L = 0.55 мм`, радіус заокруглення кутів `R = 0.10 мм`.
- Площа площадки: `A_pad = (0.50 · 0.55) - (4 - π) · (0.10)² = 0.275 - 0.8584 · 0.010 = 0.2664 мм²`.
- Периметр контуру: `P = 2 · (0.50 + 0.55) - (8 - 2π) · 0.10 = 2.10 - 1.7168 · 0.10 = 1.9283 мм`.
- Площа бічних стінок: `A_walls = 1.9283 · 0.120 = 0.2314 мм²`.
- Коефіцієнт площі: `AR = 0.2664 / 0.2314 = 1.151 >> 0.66` (`PASS`).
- Коефіцієнт пропорції: `AS = 0.50 / 0.120 = 4.17 > 1.50` (`PASS`).
- **Аналіз**: Апертура має великий запас стабільності, прогнозований `TE = 96.0%`. Заокруглення кутів усунуло залипання пасти, забезпечуючи перенесення об'єму `30.7 нл`.

#### Кейс 3: Чіп-конденсатор C106 типорозміру 0603 форми Home-Plate
- Номінальні розміри площадки: `W = 0.80 мм`, `L = 0.90 мм`.
- Довжина скосу Home-Plate: `c = 0.30 мм`.
- Площа площадки з виїмкою: `A_pad = (0.80 · 0.90) - (0.5 · 0.80 · 0.30) = 0.720 - 0.120 = 0.600 мм²`.
- Довжина скошеної гіпотенузи: `hyp = sqrt( 0.30² + 0.40² ) = sqrt( 0.09 + 0.16 ) = 0.50 мм`.
- Периметр контуру: `P = 2 · (0.90 - 0.30) + 0.80 + 2 · 0.50 = 1.20 + 0.80 + 1.00 = 3.00 мм`.
- Площа бічних стінок: `A_walls = 3.00 · 0.120 = 0.360 мм²`.
- Коефіцієнт площі: `AR = 0.600 / 0.360 = 1.667 >> 0.66` (`PASS`).
- **Аналіз**: Апертура зменшує об'єм пасти на `16.7%` виключно з внутрішнього боку деталі, гарантуючи повну відсутність дефекту Solder Beads при формуванні надійної зовнішньої галтелі.

#### Кейс 4: Мікросхема U2 у корпусі QFP-48 із кроком виводів 0.5 мм
- Розміри площадки: `W = 0.25 мм`, `L = 1.20 мм`.
- Площа площадки: `A_pad = 0.25 · 1.20 = 0.300 мм²`.
- Площа бічних стінок: `A_walls = 2 · (0.25 + 1.20) · 0.120 = 2.90 · 0.120 = 0.348 мм²`.
- Коефіцієнт площі: `AR = 0.300 / 0.348 = 0.862 > 0.66` (`PASS`).
- **Оптимізація редукції**: Для усунення ризику місткового замикання між ніжками з кроком 0.5 мм алгоритм виконує 10% редукцію по ширині та довжині (`W_opt = 0.225 мм`, `L_opt = 1.08 мм`).
- Нова площа апертури: `A_opt = 0.225 · 1.08 = 0.243 мм²` (редукція об'єму на 19.0%).
- Новий Area Ratio: `AR_opt = 0.243 / [ 2 · (0.225 + 1.08) · 0.120 ] = 0.243 / 0.3132 = 0.776 > 0.66` (`PASS`).
- **Аналіз**: Редукція успішно знизила надлишок припою, зберігши коефіцієнт площі значно вище критичного порогу.

#### Кейс 5: Сигнальні виводи U1 у корпусі QFN-32 із кроком 0.4 мм
- Розміри площадки: `W = 0.20 мм`, `L = 0.80 мм`.
- Площа площадки: `A_pad = 0.20 · 0.80 = 0.160 мм²`.
- Площа бічних стінок: `A_walls = 2 · (0.20 + 0.80) · 0.120 = 2.00 · 0.120 = 0.240 мм²`.
- Коефіцієнт площі: `AR = 0.160 / 0.240 = 0.667`.
- Коефіцієнт пропорції: `AS = 0.20 / 0.120 = 1.67 > 1.50` (`PASS`).
- **Аналіз**: Значення `AR = 0.667` знаходиться на граничній межі стандарту `0.66`. При найменшому коливанні тиску або в'язкості пасти виникає брак. Будь-яка спроба редукції ширини на фользі 120 мкм опустить AR нижче 0.60. Висновок інженерного аналізу: для даної плати обов'язковим є або замовлення нанопокриття, або вибір загальної товщини фольги `100 мкм` (при якій `AR = 0.800`).

#### Кейс 6: Центральний тепловий майданчик U1_Thermal (QFN-32 EP)
- Розміри площадки: `W = 4.50 мм`, `L = 4.50 мм` (суцільна площа `20.25 мм²`).
- **Параметри декомпозиції**: Цільове покриття `60%`, мінімальна перемичка `0.30 мм`.
- Розмірність матриці: `N_x = round(4.50 / 1.5) = 3`, `N_y = 3` (разом 9 вікон).
- Розрахунок розміру одного вікна: `w_win = 1.20 мм`, `l_win = 1.20 мм`.
- Фактична площа пасти: `9 · (1.20 · 1.20) = 9 · 1.44 = 12.96 мм²`.
- Фактичний відсоток покриття: `(12.96 / 20.25) · 100% = 64.0%`.
- Коефіцієнт площі одного вікна: `AR_win = (1.20 · 1.20) / [ 4 · 1.20 · 0.120 ] = 1.44 / 0.576 = 2.50 >> 0.66` (`PASS`).
- **Аналіз**: Суцільний майданчик розбито на 9 квадратних вікон із сухими перемичками `0.45 мм`. Це повністю усуває спливання чіпа та забезпечує гарантований вихід газів флюсу, знижуючи відсоток каверн до `< 10%`.

#### Кейс 7: Кулькові контакти BGA-256 із кроком 0.5 мм (U3_BGA)
- Діаметр круглої контактної площадки: `D = 0.28 мм`.
- Площа круга: `A_pad = (π · 0.28²) / 4 = 0.061575 мм²`.
- Площа бічної циліндричної стінки: `A_walls = π · 0.28 · 0.120 = 0.10556 мм²`.
- Коефіцієнт площі: `AR = D / (4 · T) = 0.28 / (4 · 0.120) = 0.28 / 0.480 = 0.583`.
- **Аналіз**: Для фольги `120 мкм` без покриття поріг `0.66` не виконується (`FAIL`). Передача пасти впаде до `68%`. Використання нанопокриття (поріг `0.55`) переводить апертуру в статус `PASS` (`TE = 85.5%`), або вимагає локального потоншення трафарету Step-down до `100 мкм` (при якому `AR = 0.700`).

#### Кейс 8: Силовий роз'єм Through-Hole Reflow (J1_Power)
- Товщина друкованої плати: `H_pcb = 1.60 мм`.
- Діаметр металізованого отвору: `D_hole = 1.10 мм`.
- Діаметр круглого штиря виводу: `D_pin = 0.64 мм`.
- Об'єм циліндра отвору: `V_hole = π · (0.55)² · 1.60 = 0.9503 · 1.60 = 1.5205 мм³`.
- Об'єм виводу в отворі: `V_pin = π · (0.32)² · 1.60 = 0.3217 · 1.60 = 0.5147 мм³`.
- Об'єм зазору в металізації: `V_gap = 1.5205 - 0.5147 = 1.0058 мм³`.
- Об'єм менісків зверху і знизу: `V_fillets = 2 · (0.25 · 1.0058) = 0.5029 мм³`.
- Сумарний необхідний об'єм чистого припою: `V_solder = 1.0058 + 0.5029 = 1.5087 мм³`.
- Необхідний об'єм паяльної пасти (50% усадка): `V_paste_req = 2.0 · 1.5087 = 3.0174 мм³ (3017 нл)`.
- Розрахунок площі апертури при фользі `T = 0.120 мм`: `A_req = 3.0174 / 0.120 = 25.145 мм²`.
- Сторона квадратного оверпринту на маску: `Side = sqrt( 25.145 ) = 5.014 мм`.
- **Аналіз**: Навколо отвору формується квадратна апертура `5.01 × 5.01 мм`, яка перекриває паяльну маску. Під час оплавлення розплавлений метал під дією капілярного тиску Лапласа повністю втягується з маски всередину отвору, забезпечуючи 100% заповнення за стандартом IPC-A-610 Class 3.

    double area_ratio;
    double aspect_ratio;

/* Розрахунок критеріїв IPC-7525 для прямокутної апертури */
static void evaluate_rectangular(const ComponentPad* pad, const StencilConfig* cfg, ApertureEvaluation* eval) {
    double w = pad->width_mm;
    double l = pad->length_mm;
    double t = cfg->foil_thickness_mm;

    eval->area_pad_mm2 = w * l;
    eval->area_walls_mm2 = 2.0 * (w + l) * t;
    eval->theoretical_volume_mm3 = eval->area_pad_mm2 * t;

    eval->area_ratio = eval->area_pad_mm2 / eval->area_walls_mm2;
    eval->aspect_ratio = (w < l ? w : l) / t;

    double ar_threshold = cfg->has_nano_coating ? 0.55 : 0.66;
    eval->pass_area_ratio = (eval->area_ratio >= ar_threshold);
    eval->pass_aspect_ratio = (eval->aspect_ratio >= 1.50);

    /* Модель Transfer Efficiency */
    double k = cfg->has_nano_coating ? 14.0 : 11.0;
    double ar0 = cfg->has_nano_coating ? 0.45 : 0.55;
    eval->transfer_efficiency = 0.96 / (1.0 + exp(-k * (eval->area_ratio - ar0)));
    eval->expected_volume_mm3 = eval->theoretical_volume_mm3 * eval->transfer_efficiency;

    /* Оптимізація редукції розмірів: зменшення на 10-15% за умови збереження AR >= threshold */
    double opt_w = w * 0.90;
    double opt_l = l * 0.90;
    double opt_ar = (opt_w * opt_l) / (2.0 * (opt_w + opt_l) * t);

    if (opt_ar >= ar_threshold) {
        eval->opt_width_mm = opt_w;
        eval->opt_length_mm = opt_l;
        eval->reduction_percent = 19.0; /* 1.0 - (0.9 * 0.9) */
    } else {
        eval->opt_width_mm = w;
        eval->opt_length_mm = l;
        eval->reduction_percent = 0.0;
    }
}

/* Розрахунок для круглої апертури BGA / CSP */
static void evaluate_circular(const ComponentPad* pad, const StencilConfig* cfg, ApertureEvaluation* eval) {
    double d = pad->width_mm;
    double t = cfg->foil_thickness_mm;

    eval->area_pad_mm2 = (M_PI_CONST * d * d) / 4.0;
    eval->area_walls_mm2 = M_PI_CONST * d * t;
    eval->theoretical_volume_mm3 = eval->area_pad_mm2 * t;

    eval->area_ratio = d / (4.0 * t);
    eval->aspect_ratio = d / t;

    double ar_threshold = cfg->has_nano_coating ? 0.55 : 0.66;
    eval->pass_area_ratio = (eval->area_ratio >= ar_threshold);
    eval->pass_aspect_ratio = (eval->aspect_ratio >= 1.50);

    double k = cfg->has_nano_coating ? 14.0 : 11.0;
    double ar0 = cfg->has_nano_coating ? 0.45 : 0.55;
    eval->transfer_efficiency = 0.96 / (1.0 + exp(-k * (eval->area_ratio - ar0)));
    eval->expected_volume_mm3 = eval->theoretical_volume_mm3 * eval->transfer_efficiency;

    eval->opt_width_mm = d;
    eval->opt_length_mm = d;
    eval->reduction_percent = 0.0;
}

/* Розрахунок для прямокутника із скругленими кутами */
static void evaluate_rounded_rect(const ComponentPad* pad, const StencilConfig* cfg, ApertureEvaluation* eval) {
    double w = pad->width_mm;
    double l = pad->length_mm;
    double r = pad->corner_radius_mm;
    double t = cfg->foil_thickness_mm;

    if (r > w / 2.0) r = w / 2.0;
    if (r > l / 2.0) r = l / 2.0;

    eval->area_pad_mm2 = (w * l) - (4.0 - M_PI_CONST) * (r * r);
    double perimeter = 2.0 * (w + l) - (8.0 - 2.0 * M_PI_CONST) * r;
    eval->area_walls_mm2 = perimeter * t;
    eval->theoretical_volume_mm3 = eval->area_pad_mm2 * t;

    eval->area_ratio = eval->area_pad_mm2 / eval->area_walls_mm2;
    eval->aspect_ratio = (w < l ? w : l) / t;

    double ar_threshold = cfg->has_nano_coating ? 0.55 : 0.66;
    eval->pass_area_ratio = (eval->area_ratio >= ar_threshold);
    eval->pass_aspect_ratio = (eval->aspect_ratio >= 1.50);

    double k = cfg->has_nano_coating ? 14.0 : 11.0;
    double ar0 = cfg->has_nano_coating ? 0.45 : 0.55;
    eval->transfer_efficiency = 0.97 / (1.0 + exp(-k * (eval->area_ratio - ar0)));
    eval->expected_volume_mm3 = eval->theoretical_volume_mm3 * eval->transfer_efficiency;

    eval->opt_width_mm = w;
    eval->opt_length_mm = l;
    eval->reduction_percent = 0.0;
}

/* Розрахунок для форми Home-Plate */
static void evaluate_home_plate(const ComponentPad* pad, const StencilConfig* cfg, ApertureEvaluation* eval) {
    double w = pad->width_mm;
    double l = pad->length_mm;
    double c = pad->home_plate_cut_mm > 0.0 ? pad->home_plate_cut_mm : w * 0.35;
    double t = cfg->foil_thickness_mm;

    if (c >= l) c = l * 0.5;

    eval->area_pad_mm2 = (w * l) - (0.5 * w * c);
    double hypotenuse = sqrt(c * c + (w / 2.0) * (w / 2.0));
    double perimeter = 2.0 * (l - c) + w + 2.0 * hypotenuse;
    eval->area_walls_mm2 = perimeter * t;
    eval->theoretical_volume_mm3 = eval->area_pad_mm2 * t;

    eval->area_ratio = eval->area_pad_mm2 / eval->area_walls_mm2;
    eval->aspect_ratio = (w < l ? w : l) / t;

    double ar_threshold = cfg->has_nano_coating ? 0.55 : 0.66;
    eval->pass_area_ratio = (eval->area_ratio >= ar_threshold);
    eval->pass_aspect_ratio = (eval->aspect_ratio >= 1.50);

    double k = cfg->has_nano_coating ? 14.0 : 11.0;
    double ar0 = cfg->has_nano_coating ? 0.45 : 0.55;
    eval->transfer_efficiency = 0.96 / (1.0 + exp(-k * (eval->area_ratio - ar0)));
    eval->expected_volume_mm3 = eval->theoretical_volume_mm3 * eval->transfer_efficiency;

    eval->opt_width_mm = w;
    eval->opt_length_mm = l;
    eval->reduction_percent = (0.5 * w * c) / (w * l) * 100.0;
}

/* Розрахунок віконної решітки для великих теплових майданчиків QFN/DFN/PowerPAK */
static void evaluate_thermal_pad(const ComponentPad* pad, const StencilConfig* cfg, ApertureEvaluation* eval) {
    double w = pad->width_mm;
    double l = pad->length_mm;
    double t = cfg->foil_thickness_mm;
    double cov = cfg->target_thermal_coverage;
    double web = cfg->min_web_width_mm;

    eval->area_pad_mm2 = w * l;
    eval->theoretical_volume_mm3 = eval->area_pad_mm2 * t;

    /* Вибір розмірності сітки: крок вікон не більше 1.5 мм */
    int nx = (int)floor(w / 1.5);
    int ny = (int)floor(l / 1.5);
    if (nx < 2) nx = 2;
    if (ny < 2) ny = 2;
    if (nx > 5) nx = 5;
    if (ny > 5) ny = 5;

    eval->grid_nx = nx;
    eval->grid_ny = ny;

    /* Розрахунок розмірів кожного окремого вікна для забезпечення цільового покриття cov */
    double target_window_area_sum = eval->area_pad_mm2 * cov;
    double single_win_area = target_window_area_sum / (double)(nx * ny);

    /* Пропорційне масштабування ширини та довжини вікна */
    double aspect = w / l;
    double win_l = sqrt(single_win_area / aspect);
    double win_w = win_l * aspect;

    /* Перевірка обмеження перемичок */
    double max_allowed_w = (w - (nx - 1) * web) / (double)nx;
    double max_allowed_l = (l - (ny - 1) * web) / (double)ny;

    if (win_w > max_allowed_w) win_w = max_allowed_w;
    if (win_l > max_allowed_l) win_l = max_allowed_l;

    eval->window_width_mm = win_w;
    eval->window_length_mm = win_l;

    double actual_paste_area = (double)(nx * ny) * (win_w * win_l);
    eval->actual_coverage_percent = (actual_paste_area / eval->area_pad_mm2) * 100.0;

    /* Розрахунок AR для одного окремого вікна */
    double a_win_pad = win_w * win_l;
    double a_win_walls = 2.0 * (win_w + win_l) * t;
    eval->area_ratio = a_win_pad / a_win_walls;
    eval->aspect_ratio = (win_w < win_l ? win_w : win_l) / t;

    double ar_threshold = cfg->has_nano_coating ? 0.55 : 0.66;
    eval->pass_area_ratio = (eval->area_ratio >= ar_threshold);
    eval->pass_aspect_ratio = (eval->aspect_ratio >= 1.50);

    eval->transfer_efficiency = 0.95;
    eval->expected_volume_mm3 = actual_paste_area * t * eval->transfer_efficiency;
}

/* Розрахунок об'єму пасти для технології Through-Hole Reflow (Pin-in-Paste) */
static void evaluate_thr_pin(const ComponentPad* pad, const StencilConfig* cfg, ApertureEvaluation* eval) {
    double d_hole = pad->hole_diameter_mm;
    double d_pin = pad->pin_diameter_mm;
    double h_pcb = pad->pcb_thickness_mm;
    double t_foil = cfg->foil_thickness_mm;

    double v_hole = M_PI_CONST * pow(d_hole / 2.0, 2.0) * h_pcb;
    double v_pin = M_PI_CONST * pow(d_pin / 2.0, 2.0) * h_pcb;
    double v_gap = v_hole - v_pin;

    /* Галтелі зверху та знизу за IPC-A-610 Class 3 */
    double v_fillet_top = 0.25 * v_gap;
    double v_fillet_bot = 0.25 * v_gap;
    double v_solder_target = v_gap + v_fillet_top + v_fillet_bot;

    /* Враховуємо 50% вміст металу в пасті за об'ємом */
    eval->thr_paste_required_mm3 = 2.0 * v_solder_target;

    /* Розрахунок розміру прямокутного оверпринту */
    double required_aperture_area = eval->thr_paste_required_mm3 / t_foil;
    eval->thr_overprint_size_mm = sqrt(required_aperture_area);

    eval->area_pad_mm2 = required_aperture_area;
    eval->area_walls_mm2 = 4.0 * eval->thr_overprint_size_mm * t_foil;
    eval->area_ratio = eval->area_pad_mm2 / eval->area_walls_mm2;
    eval->aspect_ratio = eval->thr_overprint_size_mm / t_foil;
    eval->pass_area_ratio = true;
    eval->pass_aspect_ratio = true;
    eval->transfer_efficiency = 0.95;
    eval->expected_volume_mm3 = eval->thr_paste_required_mm3 * 0.95;
}

void evaluate_component_pad(const ComponentPad* pad, const StencilConfig* cfg, ApertureEvaluation* eval) {
    memset(eval, 0, sizeof(ApertureEvaluation));
    switch (pad->pad_type) {
        case PAD_RECTANGULAR:
            evaluate_rectangular(pad, cfg, eval);
            break;
        case PAD_CIRCULAR:
            evaluate_circular(pad, cfg, eval);
            break;
        case PAD_ROUNDED_RECT:
        case PAD_OBROUND:
            evaluate_rounded_rect(pad, cfg, eval);
            break;
        case PAD_HOME_PLATE:
            evaluate_home_plate(pad, cfg, eval);
            break;
        case PAD_THERMAL_EXPOSED:
            evaluate_thermal_pad(pad, cfg, eval);
            break;
        case PAD_THROUGH_HOLE_THR:
            evaluate_thr_pin(pad, cfg, eval);
            break;
    }
}

    double opt_length_mm{0.0};
    double reduction_percent{0.0};

    /* Віконна решітка */
    int grid_nx{1};
    int grid_ny{1};
    double window_width_mm{0.0};
    double window_length_mm{0.0};
    double actual_coverage_percent{0.0};

    /* Through-Hole Reflow */
    double thr_paste_required_mm3{0.0};
    double thr_overprint_size_mm{0.0};
};

class StencilOptimizer {
public:
    [[nodiscard]] static ApertureEvaluation evaluate(const ComponentPad& pad, const StencilConfig& cfg) noexcept {
        ApertureEvaluation eval{};
        switch (pad.pad_type) {
            case PadType::Rectangular:
                evaluate_rectangular(pad, cfg, eval);
                break;
            case PadType::Circular:
                evaluate_circular(pad, cfg, eval);
                break;
            case PadType::RoundedRect:
            case PadType::Obround:
                evaluate_rounded_rect(pad, cfg, eval);
                break;
            case PadType::HomePlate:
                evaluate_home_plate(pad, cfg, eval);
                break;
            case PadType::ThermalExposed:
                evaluate_thermal_pad(pad, cfg, eval);
                break;
            case PadType::ThroughHoleTHR:
                evaluate_thr_pin(pad, cfg, eval);
                break;
        }
        return eval;
    }

private:
    static void evaluate_rectangular(const ComponentPad& pad, const StencilConfig& cfg, ApertureEvaluation& eval) noexcept {
        const double w = pad.width_mm;
        const double l = pad.length_mm;
        const double t = cfg.foil_thickness_mm;

        eval.area_pad_mm2 = w * l;
        eval.area_walls_mm2 = 2.0 * (w + l) * t;
        eval.theoretical_volume_mm3 = eval.area_pad_mm2 * t;

        eval.area_ratio = eval.area_pad_mm2 / eval.area_walls_mm2;
        eval.aspect_ratio = std::min(w, l) / t;

        const double ar_thresh = cfg.area_ratio_threshold();
        eval.pass_area_ratio = (eval.area_ratio >= ar_thresh);
        eval.pass_aspect_ratio = (eval.aspect_ratio >= 1.50);

        const double k = cfg.has_nano_coating ? 14.0 : 11.0;
        const double ar0 = cfg.has_nano_coating ? 0.45 : 0.55;
        eval.transfer_efficiency = 0.96 / (1.0 + std::exp(-k * (eval.area_ratio - ar0)));
        eval.expected_volume_mm3 = eval.theoretical_volume_mm3 * eval.transfer_efficiency;

        const double opt_w = w * 0.90;
        const double opt_l = l * 0.90;
        const double opt_ar = (opt_w * opt_l) / (2.0 * (opt_w + opt_l) * t);

        if (opt_ar >= ar_thresh) {
            eval.opt_width_mm = opt_w;
            eval.opt_length_mm = opt_l;
            eval.reduction_percent = 19.0;
        } else {
            eval.opt_width_mm = w;
            eval.opt_length_mm = l;
            eval.reduction_percent = 0.0;
        }
    }

    static void evaluate_circular(const ComponentPad& pad, const StencilConfig& cfg, ApertureEvaluation& eval) noexcept {
        const double d = pad.width_mm;
        const double t = cfg.foil_thickness_mm;

        eval.area_pad_mm2 = (std::numbers::pi * d * d) / 4.0;
        eval.area_walls_mm2 = std::numbers::pi * d * t;
        eval.theoretical_volume_mm3 = eval.area_pad_mm2 * t;

        eval.area_ratio = d / (4.0 * t);
        eval.aspect_ratio = d / t;

        const double ar_thresh = cfg.area_ratio_threshold();
        eval.pass_area_ratio = (eval.area_ratio >= ar_thresh);
        eval.pass_aspect_ratio = (eval.aspect_ratio >= 1.50);

        const double k = cfg.has_nano_coating ? 14.0 : 11.0;
        const double ar0 = cfg.has_nano_coating ? 0.45 : 0.55;
        eval.transfer_efficiency = 0.96 / (1.0 + std::exp(-k * (eval.area_ratio - ar0)));
        eval.expected_volume_mm3 = eval.theoretical_volume_mm3 * eval.transfer_efficiency;

        eval.opt_width_mm = d;
        eval.opt_length_mm = d;
        eval.reduction_percent = 0.0;
    }

    static void evaluate_rounded_rect(const ComponentPad& pad, const StencilConfig& cfg, ApertureEvaluation& eval) noexcept {
        const double w = pad.width_mm;
        const double l = pad.length_mm;
        double r = pad.corner_radius_mm;
        const double t = cfg.foil_thickness_mm;

        r = std::min({r, w / 2.0, l / 2.0});

        eval.area_pad_mm2 = (w * l) - (4.0 - std::numbers::pi) * (r * r);
        const double perimeter = 2.0 * (w + l) - (8.0 - 2.0 * std::numbers::pi) * r;
        eval.area_walls_mm2 = perimeter * t;
        eval.theoretical_volume_mm3 = eval.area_pad_mm2 * t;

        eval.area_ratio = eval.area_pad_mm2 / eval.area_walls_mm2;
        eval.aspect_ratio = std::min(w, l) / t;

        const double ar_thresh = cfg.area_ratio_threshold();
        eval.pass_area_ratio = (eval.area_ratio >= ar_thresh);
        eval.pass_aspect_ratio = (eval.aspect_ratio >= 1.50);

        const double k = cfg.has_nano_coating ? 14.0 : 11.0;
        const double ar0 = cfg.has_nano_coating ? 0.45 : 0.55;
        eval.transfer_efficiency = 0.97 / (1.0 + std::exp(-k * (eval.area_ratio - ar0)));
        eval.expected_volume_mm3 = eval.theoretical_volume_mm3 * eval.transfer_efficiency;

        eval.opt_width_mm = w;
        eval.opt_length_mm = l;
        eval.reduction_percent = 0.0;
    }

    static void evaluate_home_plate(const ComponentPad& pad, const StencilConfig& cfg, ApertureEvaluation& eval) noexcept {
        const double w = pad.width_mm;
        const double l = pad.length_mm;
        double c = pad.home_plate_cut_mm > 0.0 ? pad.home_plate_cut_mm : w * 0.35;
        const double t = cfg->foil_thickness_mm;

        if (c >= l) c = l * 0.5;

        eval.area_pad_mm2 = (w * l) - (0.5 * w * c);
        const double hypotenuse = std::sqrt(c * c + (w / 2.0) * (w / 2.0));
        const double perimeter = 2.0 * (l - c) + w + 2.0 * hypotenuse;
        eval.area_walls_mm2 = perimeter * t;
        eval.theoretical_volume_mm3 = eval.area_pad_mm2 * t;

        eval.area_ratio = eval.area_pad_mm2 / eval.area_walls_mm2;
        eval.aspect_ratio = std::min(w, l) / t;

        const double ar_thresh = cfg.area_ratio_threshold();
        eval.pass_area_ratio = (eval.area_ratio >= ar_thresh);
        eval.pass_aspect_ratio = (eval.aspect_ratio >= 1.50);

        const double k = cfg.has_nano_coating ? 14.0 : 11.0;
        const double ar0 = cfg.has_nano_coating ? 0.45 : 0.55;
        eval.transfer_efficiency = 0.96 / (1.0 + std::exp(-k * (eval.area_ratio - ar0)));
        eval.expected_volume_mm3 = eval.theoretical_volume_mm3 * eval.transfer_efficiency;

        eval.opt_width_mm = w;
        eval.opt_length_mm = l;
        eval.reduction_percent = (0.5 * w * c) / (w * l) * 100.0;
    }

    static void evaluate_thermal_pad(const ComponentPad& pad, const StencilConfig& cfg, ApertureEvaluation& eval) noexcept {
        const double w = pad.width_mm;
        const double l = pad.length_mm;
        const double t = cfg.foil_thickness_mm;
        const double cov = cfg.target_thermal_coverage;
        const double web = cfg.min_web_width_mm;

        eval.area_pad_mm2 = w * l;
        eval.theoretical_volume_mm3 = eval.area_pad_mm2 * t;

        int nx = std::clamp(static_cast<int>(std::floor(w / 1.5)), 2, 5);
        int ny = std::clamp(static_cast<int>(std::floor(l / 1.5)), 2, 5);

        eval.grid_nx = nx;
        eval.grid_ny = ny;

        const double target_win_sum = eval.area_pad_mm2 * cov;
        const double single_win_area = target_win_sum / static_cast<double>(nx * ny);

        const double aspect = w / l;
        double win_l = std::sqrt(single_win_area / aspect);
        double win_w = win_l * aspect;

        const double max_w = (w - (nx - 1) * web) / static_cast<double>(nx);
        const double max_l = (l - (ny - 1) * web) / static_cast<double>(ny);

        win_w = std::min(win_w, max_w);
        win_l = std::min(win_l, max_l);

        eval.window_width_mm = win_w;
        eval.window_length_mm = win_l;

        const double actual_paste_area = static_cast<double>(nx * ny) * (win_w * win_l);
        eval.actual_coverage_percent = (actual_paste_area / eval.area_pad_mm2) * 100.0;

        const double a_win_pad = win_w * win_l;
        const double a_win_walls = 2.0 * (win_w + win_l) * t;
        eval.area_ratio = a_win_pad / a_win_walls;
        eval.aspect_ratio = std::min(win_w, win_l) / t;

        const double ar_thresh = cfg.area_ratio_threshold();
        eval.pass_area_ratio = (eval.area_ratio >= ar_thresh);
        eval.pass_aspect_ratio = (eval.aspect_ratio >= 1.50);

        eval.transfer_efficiency = 0.95;
        eval.expected_volume_mm3 = actual_paste_area * t * eval.transfer_efficiency;
    }

    static void evaluate_thr_pin(const ComponentPad& pad, const StencilConfig& cfg, ApertureEvaluation& eval) noexcept {
        const double d_hole = pad.hole_diameter_mm;
        const double d_pin = pad.pin_diameter_mm;
        const double h_pcb = pad.pcb_thickness_mm;
        const double t_foil = cfg.foil_thickness_mm;

        const double v_hole = std::numbers::pi * std::pow(d_hole / 2.0, 2.0) * h_pcb;
        const double v_pin = std::numbers::pi * std::pow(d_pin / 2.0, 2.0) * h_pcb;
        const double v_gap = v_hole - v_pin;

        const double v_fillet_top = 0.25 * v_gap;
        const double v_fillet_bot = 0.25 * v_gap;
        const double v_solder_target = v_gap + v_fillet_top + v_fillet_bot;

        eval.thr_paste_required_mm3 = 2.0 * v_solder_target;
        const double required_area = eval.thr_paste_required_mm3 / t_foil;
        eval.thr_overprint_size_mm = std::sqrt(required_area);

        eval.area_pad_mm2 = required_area;
        eval.area_walls_mm2 = 4.0 * eval.thr_overprint_size_mm * t_foil;
        eval.area_ratio = eval.area_pad_mm2 / eval.area_walls_mm2;
        eval.aspect_ratio = eval.thr_overprint_size_mm / t_foil;
        eval.pass_area_ratio = true;
        eval.pass_aspect_ratio = true;
        eval.transfer_efficiency = 0.95;
        eval.expected_volume_mm3 = eval.thr_paste_required_mm3 * 0.95;
    }
};

void print_cpp_report(const std::vector<ComponentPad>& pads, const StencilConfig& cfg) {
    std::cout << "========================================================================================================\n";
    std::cout << "                  ЗВІТ ВАЛІДАЦІЇ ТРАФАРЕТНИХ АПЕРТУР ЗА СТАНДАРТОМ IPC-7525 (C++20)\n";

        } else if (pad.pad_type == PadType::ThroughHoleTHR) {

### Інтеграція в САПР (EDA/CAD) та автоматизація DFM

Для промислового використання розрахунковий алгоритм інтегрується в постпроцесор підготовки Gerber-файлів шарів паяльної пасти (`F.Paste` / `B.Paste` у KiCad, `GTP` / `GBP` в Altium Designer).

Типовий виробничий процес автоматизованої підготовки виглядає наступним чином:

1. **Експорт Gerber-шару пасти**: Тополог експортує шар пасти у форматі Gerber X2 або RS-274X з номінальним масштабом `1:1`.
2. **Скриптова постобробка**:
   - Скрипт парсить D-коди (апертури) та зіставляє координати площадок із базою даних компонентів (BOM / Netlist).
   - Для мікросхем із малим кроком (QFN/QFP `≤ 0.5 мм`) розміри D-кодів автоматично зменшуються на `10–15%` по ширині.
   - Для чіпів 0402/0603 прямокутні D-коди замінюються на макроси апертур Home-Plate (`AM` — *Aperture Macro*).
   - Великі суцільні полігони теплових площадок площею `> 4 мм²` автоматично конвертуються у масив вікон `N_x × N_y` із технологічними перемичками `0.30 мм`.
   - Для роз'ємів THR круглі апертури розширюються до розрахункового прямокутного оверпринту.
3. **Експорт інженерних даних у форматі CSV для систем MES та 3D SPI**:
   Розраховані теоретичні об'єми та допуски експортуються у файл конфігурації інспекційної системи 3D SPI. Це дозволяє оптичній машині автоматично встановити індивідуальні пороги тривоги USL/LSL для кожного відбитка на основі розрахованого Transfer Efficiency, виключаючи хибні спрацьовування на мініатюрних чіпах 0201. Інтеграція з MES-системою заводу дозволяє зберігати повний цифровий паспорт трафарету та відстежувати кількість відбитків для вчасного оновлення фольги.
4. **Генерація виробничої специфікації для виробника трафаретів (Stencil Fab Note)**:
   Разом із модифікованим Gerber-файлом фабриці передається текстовий супровідний файл із чіткими вимогами:
   - Матеріал фольги: нержавіюча сталь марки AISI 304 з напругою натягу `≥ 35 Н/см`;
   - Товщина фольги: `120 ± 4 мкм`;
   - Спосіб обробки стінок: волоконна лазерна різка з подальшим обов'язковим електрополіруванням (шорсткість стінок `Ra ≤ 0.20 мкм`);
   - Покриття: полімерне гідрофобне та олеофобне нанопокриття на контактному боці трафарету (крайовий кут змочування `θ ≥ 110°`);
   - Оптичні репери: 4 напівпротравлені кутові репери з чорним матовим оптичним наповнювачем для камер системи технічного зору принтера.

### Підводні камені, калібрування та крайові випадки

1. **Деформація фольги під тиском ракеля (Stencil Deflection)**:
   При проектуванні віконної решітки великих теплових майданчиків ширина сталевих перемичок не повинна бути меншою за `0.25 мм`. Якщо зробити перемички занадто тонкими (`0.10–0.15 мм`), під тиском сталевого ракеля `0.25 кг/см` вони зазнають необоротної пластичної деформації розтягування (хвилястість фольги), що призводить до втрати герметичності прилягання (Gasketing) та витікання пасти.
2. **Вплив товщини та нерівномірності паяльної маски плати**:
   Товщина паяльної маски на поверхні мідних провідників становить `15–25 мкм`. Якщо навколо контактної площадки є високий валик маски (наприклад, при типі площадок SMD — *Solder Mask Defined*), між міддю та фольгою трафарету утворюється повітряний зазор. Це еквівалентно збільшенню ефективної товщини фольги `T_eff = T + h_mask`, що знижує фактичний Area Ratio на 15–20%. Для fine-pitch компонентів завжди слід проектувати площадки типу NSMD (*Non-Solder Mask Defined*) із нульовим напливом маски на мідь.
3. **Калібрування сигмоїди Transfer Efficiency за даними SPI фабрики**:
   Коефіцієнти `k` та `AR₀` у формулі Transfer Efficiency залежать від типу застосовуваної паяльної пасти, типу флюсу та швидкості розділення столу принтера `v_sep`. Для високоточного калібрування рекомендується завантажити масив вимірювань `V_actual` з бази даних 3D SPI системи за останні 5000 відбитків та виконати нелінійну регресію методом найменших квадратів, уточнивши константи `k` та `AR₀` під конкретну SMT-лінію виробництва.
4. **Вплив зносу та деформації леза ракеля (Squeegee Wear)**:
   При багаторазових тисячах циклів гостра кромка сталевого ракеля зазнає механічного стирання: радіус притуплення вістря зростає від початкових `R < 0.02 мм` до `R > 0.15 мм`. Це призводить до зміни кута атаки в контактній зоні, локального підвищення гідродинамічного тиску та ефекту залишку тонкої плівки флюсу на фользі трафарету, що вимагає регулярної заміни або переточування лез ракеля.
5. **Вплив короблення плати (PCB Warpage / Bow and Twist)**:
   Згідно зі стандартом IPC-TM-650, максимальне допустиме короблення групової заготовки друкованої плати для поверхневого монтажу не повинно перевищувати `0.75%` від діагоналі (для BGA кроку 0.5 мм — не більше `0.50%`). При перевищенні цієї величини вакуумний стіл принтера не може ідеально притиснути деформовану плату до трафарету. У зонах прогину утворюються зазори `10–40 мкм`, що призводить до масового затікання пасти між трафаретом і платою.
6. **Аудит якості нанопокриття на виробництві**:
   Гідрофобне нанопокриття поступово зношується під дією абразивних мікрочасток порошку припою та агресивних миючих розчинників. Для контролю стану покриття застосовують калібровані маркери поверхневої енергії (Dyne Pens) або крапельні гоніометри: якщо крайовий кут змочування водою падає нижче `90°`, трафарет підлягає повторній хімічній обробці рідким нанопокриттям (наприклад, розчинами типу *NanoSlic* або *Aculon*) або заміні.
7. **Лазерна фізика різання та конусність апертур**:
   Під час різання фольги імпульсним волоконним лазером пучок випромінювання фокусується у вузьку перетяжку діаметром `20–25 мкм`. Через природну розбіжність променя стінка отвору отримує невеликий технологічний нахил під кутом `1°–2°`. Трафарет завжди повинен прорізатися з верхнього (ракельного) боку: тоді вхідний отвір зверху виходить на `5–10 мкм` вужчим за вихідний отвір на контактному боці з платою. Цей розтруб донизу кардинально полегшує вихід пасти при вертикальному розділенні. Якщо ж помилково прорізати трафарет зі зворотного боку, виникне зворотний конус («ластівчин хвіст»), який механічно заклинить пасту всередині сталі.
8. **Термічний баланс маси припою під час оплавлення**:
   Масивні відкладення припою під силовими компонентами потребують більшої кількості теплової енергії `Q = m · c_p · ΔT` для переходу в рідку фазу. Незбалансовані апертури викликають різночасне розплавлення виводів одного компонента, що посилює динамічний дисбаланс сил поверхневого натягу та збільшує ймовірність розвороту чіпів на платі.
