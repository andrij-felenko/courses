# 🧮 Виведення випромінюваного поля: диференційний контур проти синфазного кабелю

<preknowlist>
- [Індуктивність](root:ph-electromagnetism/inductance) — струмовий контур як магнітний диполь, площа якого визначає випромінювання.
- [Джерело, шлях, жертва: чотири шляхи завади](root:hw-pcb/electromagnetic-compatibility) — фізичні механізми випромінювання в дальньому полі.
</preknowlist>

Коли друкована плата не проходить сертифікацію на електромагнітне випромінювання в безвідлунній камері, інженери часто шукають причину в цифрових мікросхемах або швидких шинах даних. Проте спектроаналізатор фіксує перебільшення ліміту на 15–20 дБ там, де струми сигналів становлять усього десятки міліампер. Причина криється у фундаментальній відмінності між двома механізмами випромінювання: випромінюванням замкненого контуру (диференційний режим, Differential Mode) та випромінюванням приєднаного кабелю чи металевого корпусу (синфазний режим, Common Mode).

Нижче наведено строге аналітичне виведення напруженості електричного поля для обох випадків та кількісне порівняння, яке демонструє, чому крихітний синфазний струм у мікроампери випромінює набагато потужніше за сотні міліампер робочого струму на платі.

### 1. Випромінювання диференційного контуру (магнітний диполь)

Розглянемо замкнений контур на друкованій платі площею A, по якому протікає високочастотний струм I_DM із частотою f. Якщо максимальний лінійний розмір контуру набагато менший за довжину хвилі (умова малого диполя d << λ), такий контур еквівалентний елементарному магнітному диполю з магнітним моментом m:

```
m = I_DM · A  [магнітний момент контуру, А·м²]
```

У дальній зоні (r >> λ / (2·π)) напруженість електричного поля E_DM у вільному просторі визначається через розв'язок рівнянь Максвелла для випромінювання малого магнітного диполя:

```
E_DM_free(r, θ) = (μ₀ · m · ω² · sin(θ)) / (4 · π · c · r)  [напруженість поля у вільному просторі]
```

Де:
- μ₀ = 4·π·10⁻⁷ Гн/м — магнітна стала;
- c = 3·10⁸ м/с — швидкість світла у вакуумі;
- ω = 2·π·f — кутова частота сигналу (рад/с);
- r — відстань від контуру до вимірювальної антени (м);
- θ — кут від осі диполя (максимум при θ = 90°, sin(θ) = 1).

Підставимо кутову частоту та виразимо константи через частоту f:

```
E_DM_max = (μ₀ · I_DM · A · (2 · π · f)²) / (4 · π · c · r)
         = (4 · π · 10⁻⁷ · 4 · π² · f² · I_DM · A) / (4 · π · 3 · 10⁸ · r)
         = (4 · π² · 10⁻¹⁵ · f² · I_DM · A) / (3 · r)
         = (1.316 · 10⁻¹⁴ · f² · I_DM · A) / r  [В/м]
```

Під час вимірювань за стандартами CISPR 32 та FCC Part 15 над металевою площиною заземлення (Ground Plane) випробувального майданчика виникає відбиття хвилі, яке у найгіршому випадку подвоює напруженість поля (коефіцієнт відбиття k_refl = 2):

```
E_DM = 2 · E_DM_max
     = (2.632 · 10⁻¹⁴ · f² · I_DM · A) / r  [В/м, з урахуванням відбиття від землі]
```

Головна характеристика диференційного випромінювання — **квадратична залежність від частоти** (f²). Подвоєння тактової частоти або гармоніки збільшує напруженість поля у 4 рази (+12 дБ).

### 2. Випромінювання синфазного струму (електричний диполь)

Синфазний струм I_CM виникає через асиметрію імпедансів і стікає з плати у підключений кабель завдовжки L (або між двома частинами розірваного шару землі). Провідник зі струмом I_CM поводиться як симетричний електричний диполь або монополь над землею.

Для короткого електричного диполя довжиною L (де L << λ) напруженість електричного поля E_CM у дальній зоні описується класичною формулою Герца:

```
E_CM_free(r, θ) = (μ₀ · I_CM · L · ω · sin(θ)) / (4 · π · r)  [напруженість поля електричного диполя]
```

Підставимо кутову частоту ω = 2·π·f:

```
E_CM_max = (μ₀ · I_CM · L · 2 · π · f) / (4 · π · r)
         = (μ₀ · f · I_CM · L) / (2 · r)
         = (4 · π · 10⁻⁷ · f · I_CM · L) / (2 · r)
         = (2 · π · 10⁻⁷ · f · I_CM · L) / r
         = (6.283 · 10⁻⁷ · f · I_CM · L) / r  [В/м]
```

З урахуванням відбиття від провідної підлоги випробувального майданчика (k_refl = 2):

```
E_CM = 2 · E_CM_max
     = (1.257 · 10⁻⁶ · f · I_CM · L) / r  [В/м, з урахуванням відбиття від землі]
```

На відміну від контуру, синфазне поле залежить від частоти **лінійно** (пропорційно f), проте константа зв'язку тут на 8 порядків вища, ніж у магнітного диполя (10⁻⁶ проти 10⁻¹⁴).

### 3. Числове порівняння: контур проти кабелю

Зіставимо випромінювання типового сигнального контуру на друкованій платі та кабелю живлення, підключеного до цієї ж плати.

Параметри системи:
- Частота гармоніки: f = 100 МГц = 10⁸ Гц;
- Відстань до антени: r = 3 м (стандартна дистанція вимірювання за FCC Part 15 / CISPR 32 Class B);
- Дозволений нормативний ліміт за CISPR 32 Class B на частоті 100 МГц: 40 дБмкВ/м (що відповідає 100 мкВ/м).

**Розрахунок диференційного контуру:**
- Струм сигналу: I_DM = 20 мА = 0.02 А;
- Площа петлі трасування (погана траса без суцільної землі поруч): A = 2 см² = 2·10⁻⁴ м².

```
E_DM = (2.632 · 10⁻¹⁴ · (10⁸)² · 0.02 · 2 · 10⁻⁴) / 3
     = (2.632 · 10⁻¹⁴ · 10¹⁶ · 4 · 10⁻⁶) / 3
     = (2.632 · 10² · 4 · 10⁻⁶) / 3
     = (1.053 · 10⁻³) / 3
     = 3.51 · 10⁻⁴ В/м
     = 351 мкВ/м  [напруженість поля]

E_DM_dB = 20 · lg(351)
        = 20 · 2.545
        = 50.9 дБмкВ/м  [перевищення ліміту на 10.9 дБ]
```

Якщо ж плата має **суцільну площину землі**, відстань між шаром сигналу та землею становить h = 0.2 мм, а довжина траси 50 мм, тоді площа контуру зменшується до:

```
A_gnd = 50 мм · 0.2 мм = 10 мм² = 10⁻⁵ м²  [площа з суцільною землею]

E_DM_gnd = (2.632 · 10⁻¹⁴ · 10¹⁶ · 0.02 · 10⁻⁵) / 3
         = (5.264 · 10⁻⁵) / 3
         = 1.75 · 10⁻⁵ В/м
         = 17.5 мкВ/м  [24.9 дБмкВ/м — запас 15.1 дБ відносно ліміту 40 дБмкВ/м]
```

**Розрахунок синфазного кабелю:**
Припустимо, що в кабель довжиною L = 1 м витікає мікроскопічний синфазний струм I_CM = 5 мкА = 5·10⁻⁶ А:

```
E_CM = (1.257 · 10⁻⁶ · 10⁸ · 5 · 10⁻⁶ · 1.0) / 3
     = (1.257 · 10² · 5 · 10⁻⁶) / 3
     = (6.285 · 10⁻⁴) / 3
     = 2.095 · 10⁻⁴ В/м
     = 209.5 мкВ/м  [напруженість поля]

E_CM_dB = 20 · lg(209.5)
        = 20 · 2.321
        = 46.4 дБмкВ/м  [перевищення ліміту 40 дБмкВ/м на 6.4 дБ!]
```

### 4. Висновок співвідношення струмів

Знайдемо співвідношення синфазного та диференційного струмів, які створюють однакове випромінюване поле (E_CM = E_DM):

```
(1.257 · 10⁻⁶ · f · I_CM · L) / r = (2.632 · 10⁻¹⁴ · f² · I_DM · A) / r
I_CM / I_DM = (2.632 · 10⁻¹⁴ · f · A) / (1.257 · 10⁻⁶ · L)
            = 2.094 · 10⁻⁸ · (f · A) / L  [коефіцієнт еквівалентності струмів]
```

Для частоти f = 100 МГц, площі контуру A = 10⁻⁵ м² (з площиною землі) та кабелю L = 1 м:

```
I_CM / I_DM = 2.094 · 10⁻⁸ · (10⁸ · 10⁻⁵) / 1.0
            = 2.094 · 10⁻⁵  [співвідношення струмів]
```

Це означає, що **синфазний струм величиною лише 21 мкА створює таке саме потужне випромінювання, як 1 А диференційного струму в сигнальній лінії**. Саме тому головна битва за проходження сертифікації ЕМС розгортається не навколо сигнальних трас, а навколо блокування синфазних струмів, що намагаються вийти на зовнішні кабелі пристрою.
