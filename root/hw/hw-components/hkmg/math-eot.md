# 🧮 Математика EOT, квантового тунелювання та зонного вирівнювання HKMG

Підзатворний стек транзистора на основі діелектрика з високою проникністю (High-k) та металевого затвора (Metal Gate) підпорядковується фундаментальним законам електростатики багатошарових діелектриків, квантовомеханічного переносу носіїв крізь потенціальний бар'єр, квантових розмірних ефектів у кремнієвому каналі, фононного розсіювання, електростатики короткого каналу, захоплення заряду дефектами, дипольної інженерії межі розділу та фізики контактної різниці потенціалів. Щоб зрозуміти, як фізичне потовщення діелектричного шару може одночасно зменшувати струм витоку на порядки і зберігати сильну ємнісну дію на кремнієвий канал, необхідно кількісно розрахувати ємність багатошарового ізолятора, прозорість потенціального бар'єру у квазікласичному наближенні, квантовий зсув центроїду заряду інверсії, ефект збіднення затвора, розсіювання на м'яких оптичних фононах, придушення короткоканальних ефектів, динамічний зсув заряду пасток, дипольний зсув зон та зміщення порогової напруги.

## 1. Еквівалентна товщина оксиду (EOT) і ємнісна еквівалентна товщина (CET)

Фундаментальною характеристикою підзатворного діелектрика є його питома ємність на одиницю площі `C_diel` (вимірюється у `Ф/см²` або `фФ/мкм²`). Для плоского конденсатора з відносною діелектричною проникністю `k` та фізичною товщиною `t_phys` питома ємність визначається формулою:

```
C_diel
= ε_0 · k / t_phys                     [питома ємність плоского діелектрика]
```

де `ε_0 ≈ 8.854 · 10⁻¹⁴ Ф/см` — електрична стала вакууму.

Протягом десятиліть стандартом мікроелектроніки був діоксид кремнію `SiO₂` з проникністю `k_SiO2 = 3.9`. Щоб зіставляти діелектрики різного хімічного складу, введено поняття **еквівалентної товщини оксиду** (англ. *Equivalent Oxide Thickness*, скорочено **EOT**). За визначенням, EOT — це товщина гіпотетичного шару ідеального `SiO₂`, який мав би точно таку саму питому ємність, як і досліджуваний шар High-k товщиною `t_highk` із проникністю `k_highk`:

```
C_highk = ε_0 · k_highk / t_highk
C_SiO2  = ε_0 · k_SiO2 / EOT
```

Прирівнюючи питомі ємності `C_highk = C_SiO2`, отримуємо формулу перерахунку:

```
ε_0 · k_SiO2 / EOT
= ε_0 · k_highk / t_highk             [рівність питомих ємностей]
= (ε_0 · k_SiO2) / (t_highk · (k_SiO2 / k_highk)) [перегрупування множників]
```

Скорочуючи обидві частини на `ε_0 · k_SiO2`, маємо формулу EOT для однорідного шару:

```
EOT
= t_highk · (k_SiO2 / k_highk)         [еквівалентна товщина однорідного High-k]
```

### Двошарова модель з інтерфейсним оксидом (Interfacial Layer)

У реальному технологічному процесі неможливо нанести шар `HfO₂` безпосередньо на кремнієвий кристал без утворення тонкого перехідного шару кремнієвого оксинітриду або діоксиду кремнію `SiO₂` (Interfacial Layer, `IL`) товщиною `t_IL ≈ 0.4…0.6 нм` з діелектричною проникністю `k_IL ≈ 3.9…4.5`. Цей шар необхідний для мінімізації густини поверхневих дефектів на межі з кремнієм.

Підзатворний ізолятор стає послідовним з'єднанням двох плоских конденсаторів: перехідного шару `C_IL` та основного High-k шару `C_highk`.

```
1 / C_total
= 1 / C_IL + 1 / C_highk              [послідовне додавання ємностей]
= t_IL / (ε_0 · k_IL) + t_highk / (ε_0 · k_highk) [підстановка питомих ємностей]
= (1 / (ε_0 · k_SiO2)) · (t_IL · (k_SiO2 / k_IL) + t_highk · (k_SiO2 / k_highk)) [винесення масштабу SiO2]
```

Оскільки повна питома ємність виражається через результуючий EOT як `C_total = ε_0 · k_SiO2 / EOT_total`, отримуємо загальну формулу еквівалентної товщини підзатворного діелектрика:

```
EOT_total
= t_IL · (k_SiO2 / k_IL) + t_highk · (k_SiO2 / k_highk) [загальна двошарова формула EOT]
```

Якщо перехідний шар є чистим `SiO₂` (`k_IL = k_SiO2 = 3.9`), формула спрощується:

```
EOT_total
= t_IL + t_highk · (3.9 / k_highk)     [EOT двошарового стека з інтерфейсним SiO2]
```

**Числовий приклад.** Нехай діелектрик складається з перехідного шару `SiO₂` товщиною `t_IL = 0.5 нм` (`k_IL = 3.9`) та шару `HfO₂` товщиною `t_highk = 2.8 нм` із діелектричною проникністю `k_highk = 22`.

```
EOT_total
= 0.5 нм + 2.8 нм · (3.9 / 22)
= 0.5 нм + 2.8 нм · 0.1773
= 0.5 нм + 0.496 нм
= 0.996 нм                            [підсумковий EOT менше 1 нанометра]
```

Фізична товщина ізолятора становить `t_phys = 0.5 + 2.8 = 3.3 нм`, тоді як його електрична ємність відповідає шару `SiO₂` товщиною всього `1.0 нм`.

## 2. Квантовомеханічне пряме тунелювання крізь діелектричний бар'єр

Струм витоку крізь ультратонкий діелектрик за робочих напруг `V_ox < 1.5 В` визначається **прямим квантовим тунелюванням** (англ. *Direct Tunneling*), коли електрони проникають крізь трапецеподібний енергетичний бар'єр між затвором і каналом без переходу в зону провідності ізолятора.

### Наближення Вентцеля–Крамерса–Бріллюена (ВКБ)

Ймовірність проникнення (коефіцієнт прозорості) `T(E)` електрона з енергією `E` крізь одновимірний потенціальний бар'єр `V(x)` шириною `t_phys` у квазікласичному наближенні ВКБ визначається інтегралом хвильового числа затухаючої хвилі:

```
T(E)
= exp(-2 · ∫[0..t_phys] κ(x) dx)      [коефіцієнт прозорості бар'єру за ВКБ]
```

де хвильове число згасання хвильової функції електрона під бар'єром дорівнює:

```
κ(x)
= sqrt(2 · m_ox* · (V(x) - E)) / ħ     [хвильове число затухання в діелектрику]
```

де `m_ox*` — ефективна маса електрона в діелектрику (для `SiO₂` `m_ox* ≈ 0.40 · m_0`, для `HfO₂` `m_ox* ≈ 0.22 · m_0`), `ħ ≈ 1.05457 · 10⁻³⁴ Дж·с` — зведена стала Планка, `m_0 ≈ 9.109 · 10⁻³¹ кг` — маса спокою вільного електрона.

Для плоского бар'єру середньої висоти `Φ_B` (енергетичний розрив зон між кремнієм і діелектриком `ΔE_c`) за малого падіння напруги інтеграл спрощується до прямого добутку:

```
T(E)
= exp(-2 · t_phys · sqrt(2 · m_ox* · q · Φ_B) / ħ) [прозорість бар'єру скінченної товщини]
```

Густина струму прямого тунелювання `J_DT` пропорційна концентрації електронів на межі розділу та коефіцієнту прозорості `T`:

```
J_DT
= J_0 · exp(-α · t_phys · sqrt(m_ox* / m_0 · Φ_B)) [густина струму прямого тунелювання]
```

де `α = 2 · sqrt(2 · m_0 · q) / ħ ≈ 10.25 нм⁻¹·еВ⁻⁰˙⁵`, а `Φ_B` виражено в електрон-вольтах (`еВ`), `t_phys` — у нанометрах (`нм`).

### Кількісне порівняння струмів витоку: SiO₂ проти HfO₂

Розглянемо два варіанти підзатворного діелектрика з однаковою ємністю `EOT = 1.2 нм`:

1. **Традиційний шар `SiO₂`:**
   - `t_phys = 1.2 нм`
   - Висота бар'єру для електронів `Φ_B = 3.15 еВ`
   - Ефективна маса `m_ox* = 0.40 · m_0`
   - Показник експоненти:
     ```
     γ_SiO2
     = α · t_phys · sqrt(m_ox* / m_0 · Φ_B)
     = 10.25 · 1.2 · sqrt(0.40 · 3.15)
     = 12.30 · sqrt(1.26)
     = 12.30 · 1.1225
     = 13.81                           [аргумент експоненти для SiO2]
     ```

2. **Діелектрик `HfO₂` (High-k):**
   - Фізична товщина для `EOT = 1.2 нм` при `k = 22`: `t_phys = 1.2 · (22 / 3.9) ≈ 6.77 нм` (або для двошарового стека з `t_IL = 0.5 нм`: `t_HfO2 = (1.2 - 0.5) · (22 / 3.9) ≈ 3.95 нм`, сумарна товщина `t_phys = 4.45 нм`).
   - Для шару `HfO₂` товщиною `3.95 нм` з висотою бар'єру `Φ_B = 1.50 еВ` та `m_ox* = 0.22 · m_0`:
     ```
     γ_HfO2
     = α · t_phys · sqrt(m_ox* / m_0 · Φ_B)
     = 10.25 · 3.95 · sqrt(0.22 · 1.50)
     = 40.49 · sqrt(0.33)
     = 40.49 · 0.5745
     = 23.26                           [аргумент експоненти для шару HfO2]
     ```

Порівняння відносного коефіцієнта тунелювання:

```
J_HfO2 / J_SiO2
≈ exp(-(γ_HfO2 - γ_SiO2))
= exp(-(23.26 - 13.81))
= exp(-9.45)
≈ 7.87 · 10⁻⁵                         [придушення струму витоку на 4 порядки]
```

Незважаючи на те, що висота енергетичного бар'єру `HfO₂` (`1.50 еВ`) вдвічі менша за бар'єр `SiO₂` (`3.15 еВ`), збільшення фізичної товщини бар'єру `t_phys` у понад три рази переважає ефект зниження бар'єру завдяки лінійному входженню `t_phys` у показник експоненти порівняно з кореневою залежністю від `sqrt(Φ_B)`.

### Перехідний режим між прямим тунелюванням та режимом Фаулера–Нордгейма

Якщо падіння напруги на діелектрику `V_ox` збільшується, нахил зон стає крутішим. Перехід від трапецеподібного бар'єру (пряме тунелювання) до трикутного бар'єру (тунелювання Фаулера–Нордгейма) відбувається за критичної напруженості поля:

```
E_crit
= Φ_B / (q · t_phys)                  [критичне поле зміни форми бар'єру]
```

За полів `E_ox > E_crit` електрони виходять безпосередньо в зону провідності діелектрика на відстані `x_t = Φ_B / (q · E_ox) < t_phys`, і густина струму підпорядковується рівнянню Фаулера–Нордгейма:

```
J_FN
= (q³ · E_ox² / (8 · π · h · Φ_B)) · exp(-4 · sqrt(2 · m_ox*) · (q · Φ_B)¹˙⁵ / (3 · q · ħ · E_ox)) [струм Фаулера-Нордгейма]
```

## 3. Модель збіднення полікремнію (Poly-Depletion)

Полікристалічний кремній є сильно легованим напівпровідником із максимально досяжною активною концентрацією домішок `N_poly ≈ (1…3) · 10²⁰ см⁻³`. При прикладанні позитивного потенціалу до затвора n-MOSFET електрони відтягуються від межі розділу полікремній–діелектрик углиб затвора, утворюючи тонкий шар нескомпенсованого позитивного об'ємного заряду іонізованих донорів товщиною `W_dep`.

### Інтегрування рівняння Пуассона в полікремнієвому затворі

Розподіл електричного потенціалу `ψ(x)` у шарі збіднення затвора (`-W_dep ≤ x ≤ 0`) описується одновимірним рівнянням Пуассона:

```
d²ψ / dx²
= -ρ(x) / (ε_0 · ε_Si)                [одновимірне рівняння Пуассона]
= -q · N_poly / (ε_0 · ε_Si)          [заряд іонізованих донорів]
```

Інтегруючи від нейтрального об'єму затвора (`x = -W_dep`, де `dψ/dx = 0` та `ψ = 0`):

```
dψ / dx
= -q · N_poly · (x + W_dep) / (ε_0 · ε_Si) [напруженість електричного поля E(x)]
```

На межі з підзатворним діелектриком (`x = 0`) електричне зміщення повинно бути неперервним: `ε_Si · E_poly(0) = ε_diel · E_diel = Q_inv + Q_dep,sub`, де `E_diel` — напруженість поля в діелектрику.

```
E_poly(0)
= q · N_poly · W_dep / (ε_0 · ε_Si)   [поле на межі розділу полікремнію]
```

Звідси товщина шару збіднення в полікремнії:

```
W_dep
= (ε_0 · ε_diel · E_diel) / (q · N_poly) [товщина шару збіднення полікремнію]
```

Падіння потенціалу всередині шару збіднення полікремнію (інтеграл від `E(x)`):

```
V_poly
= q · N_poly · W_dep² / (2 · ε_0 · ε_Si)
= (ε_0 · ε_diel · E_diel)² / (2 · q · N_poly · ε_0 · ε_Si) [падіння напруги на затворі]
```

### Еквівалентна ємність та збільшення CET

Шар збіднення діє як додатковий конденсатор `C_poly = ε_0 · ε_Si / W_dep`, увімкнений послідовно з ємністю діелектрика `C_diel`:

```
1 / C_gate
= 1 / C_diel + 1 / C_poly             [сумарна ємність затворного вузла]
= EOT / (ε_0 · k_SiO2) + W_dep / (ε_0 · ε_Si) [підстановка питомих ємностей]
= (1 / (ε_0 · k_SiO2)) · (EOT + W_dep · (k_SiO2 / ε_Si)) [вираження через CET]
```

Звідси **ємнісна еквівалентна товщина** (Capacitance Equivalent Thickness, **CET**), яка вимірюється експериментально у режимі сильної інверсії:

```
CET
= EOT + W_dep · (k_SiO2 / ε_Si)        [збільшення електричної товщини через Poly-Depletion]
```

Оскільки відносна проникність кремнію `ε_Si ≈ 11.7`, а `k_SiO2 = 3.9`, відношення `k_SiO2 / ε_Si = 3.9 / 11.7 = 1/3`.

**Розрахунок деградації.** За робочого електричного поля `E_diel = 5 МВ/см` та концентрації легування `N_poly = 1.5 · 10²⁰ см⁻³`:

```
W_dep
= (8.854 · 10⁻¹⁴ · 3.9 · 5 · 10⁶) / (1.602 · 10⁻¹⁹ · 1.5 · 10²⁰)
= (1.726 · 10⁻⁶) / (24.03)
≈ 0.0718 · 10⁻⁶ см = 0.718 нм         [фізична товщина збіднення]
```

Внесок шару збіднення в електричну товщину:

```
ΔEOT_poly
= W_dep · (3.9 / 11.7)
= 0.718 нм / 3
≈ 0.24 нм                             [паразитне потовщення діелектричного проміжку]
```

## 4. Квантовий зсув центроїду заряду інверсійного каналу

У класичній фізиці вважається, що інверсійний шар електронів зосереджений безпосередньо на геометричній межі розділу діелектрик–кремній (`z = 0`). Проте у квантовій механіці хвильова функція електронів `ψ(z)` на нескінченно високому потенціальному бар'єрі повинна спадати до нуля на межі: `ψ(0) = 0`.

Внаслідок квантового розмірного квантування пік густини ймовірності знаходження електронів `|ψ(z)|²` зміщується вглиб кремнієвого каналу на середню відстань (квантовий центроїд `z_inv`):

```
z_inv
= ∫[0..∞] z · |ψ(z)|² dz / ∫[0..∞] |ψ(z)|² dz [середня глибина розташування носіїв]
```

У наближенні трикутної потенціальної ями (за сильного електричного поля інверсії `E_eff`) квантовий центроїд оцінюється формулою Фанга–Говарда:

```
z_inv
≈ (3 / 2) · (ε_0 · ε_Si · ħ² / (q · m_z* · Q_eff))^(1/3) [квантове зміщення центроїду інверсії]
```

Для типових полів інверсії `E_eff ≈ 0.8…1.0 МВ/см` квантовий центроїд становить `z_inv ≈ 0.8…1.2 нм`. Цей зміщений шар інверсії додає власну квантову ємність каналу `C_qm = ε_0 · ε_Si / z_inv`, яка зменшує підсумкову виміряну ємність затвора:

```
1 / C_inv_total
= 1 / C_diel + 1 / C_poly + 1 / C_qm   [повний ємнісний ланцюг затвор-канал]
```

У перерахунку на еквівалентну товщину діоксиду кремнію квантовий ефект каналу додає:

```
ΔEOT_qm
= z_inv · (k_SiO2 / ε_Si)
= 1.0 нм · (3.9 / 11.7)
≈ 0.33 нм                             [квантова добавка до CET з боку кремнію]
```

Таким чином, підсумковий виміряний `CET` транзистора складається з трьох доданків:

```
CET
= EOT_diel + ΔEOT_poly + ΔEOT_qm      [повна ємнісна товщина в режимі інверсії]
```

Для стека з `EOT_diel = 1.0 нм`:
- З полікремнієвим затвором: `CET = 1.0 + 0.24 + 0.33 = 1.57 нм` (втрата понад 36% керуючої ємності).
- З металевим затвором (`ΔEOT_poly = 0`): `CET = 1.0 + 0.00 + 0.33 = 1.33 нм` (повернення ємності та зростання струму насичення `I_on` на `20–25%`).

## 5. Модель дистанційного фононного розсіювання (Remote Phonon Scattering)

High-k діелектрики є високополярними матеріалами з великою часткою іонного хімічного зв'язку (на відміну від переважно ковалентного `SiO₂`). Внаслідок цього в ґратці `HfO₂` існують м'які поздовжні оптичні фонони (Soft Optical Phonons) з низькою енергією квантів `ħω_SO ≈ 15…25 меВ`.

Коливання іонів кристалічної ґратки High-k створюють далекодіючі флуктуації електричного потенціалу (поляризація Фреліха), які проникають крізь тонкий перехідний шар `IL` безпосередньо в кремнієвий канал. Згідно з правилом Маттіссена, загальна рухливість електронів у каналі `μ_total` падає:

```
1 / μ_total
= 1 / μ_bulk + 1 / μ_acoustic + 1 / μ_surface + 1 / μ_SO [правило Маттіссена для рухливості]
```

де частота розсіювання на м'яких оптичних фононах діелектрика `1 / μ_SO` експоненційно залежить від товщини інтерфейсного шару `t_IL` та екранування затвором:

```
1 / μ_SO
∝ (1 / (ε_opt - ε_stat)) · exp(-2 · q_F · t_IL) · (1 - exp(-2 · q_F · t_highk)) [розсіювання Фреліха]
```

де `q_F` — хвильовий вектор Фермі електронів каналу, `ε_opt` та `ε_stat` — оптична та статична діелектричні проникності High-k.

Металевий затвор забезпечує додаткове плазмонне екранування поляризаційних полів Фреліха завдяки високій концентрації вільних електронів:

```
S_metal(q)
≈ 1 + 2 · q_TF / q                    [фактор екранування Томаса-Фермі в металі]
```

Завдяки екрануванню металом та наявності буферного шару `SiO₂` товщиною `t_IL ≈ 0.5 нм` вдається відновити рухливість електронів та дірок до `85…90%` від рівня ідеального оксиду кремнію.

## 6. Вплив EOT на короткоканальні ефекти (Short-Channel Effects)

Зменшення еквівалентної товщини оксиду EOT безпосередньо посилює електростатичний контроль затвора над потенціальним бар'єром каналу, придушуючи небажані паразитичні ефекти короткого каналу.

### Характеристична довжина масштабування (Natural Scaling Length)

Електростатична проникність поля стоку в глибину каналу кількісно описується характеристичною довжиною масштабування `λ_scale`. Для планарного польового транзистора з глибиною збіднення підкладки `W_dep` (або товщиною кремнієвого шару `t_Si` у транзисторах на кремнії-на-ізоляторі SOI):

```
λ_scale
= sqrt((ε_Si / k_SiO2) · t_Si · EOT)   [характеристична довжина масштабування каналу]
```

Щоб гарантувати надійне замикання каналу затвором і запобігти наскрізному пробою підкладки (Punch-Through), довжина затвора `L_g` повинна задовольняти емпіричному критерію масштабування:

```
L_g ≥ (4…6) · λ_scale                  [критерій електростатичної керованості]
```

При зменшенні `EOT` удвічі (наприклад, з `1.8 нм` до `0.9 нм`), характеристична довжина `λ_scale` скорочується у `sqrt(2) ≈ 1.41` раза, що дозволяє зменшити фізичну довжину затвора `L_g` на `30–40%` без деградації замикання транзистора.

### Підпороговий розмах (Subthreshold Swing) та ефект DIBL

Крутизна переходу транзистора із закритого стану у відкритий характеризується **підпороговим розмахом** `SS` (напругою затвора, необхідною для зміни підпорогового струму стоку на один десятковий порядок):

```
SS
= ln(10) · (k_B · T / q) · (1 + C_dep / C_ox) [підпороговий розмах у мВ/декаду]
= ln(10) · (k_B · T / q) · (1 + (ε_Si / W_dep) · (EOT / (ε_0 · k_SiO2))) [залежність від EOT]
```

При кімнатній температурі `T = 300 K` теоретична фундаментальна термодинамічна границя становить `ln(10) · (k_B · T / q) ≈ 59.6 мВ/дек`. Мінімізація `EOT` зменшує дільник ємності `C_dep / C_ox` до нуля, наближаючи підпороговий розмах реального транзистора до `65…70 мВ/дек`.

Зниження потенціального бар'єру каналу полем стоку (**Drain-Induced Barrier Lowering, DIBL**) експоненційно спадає зі збільшенням відношення `L_g / λ_scale`:

```
DIBL
= ΔV_th / ΔV_ds
∝ exp(-L_g / (2 · λ_scale))           [експоненційне придушення DIBL через EOT]
```

Зменшення EOT за допомогою технології High-k дозволило утримати DIBL на рівні менше ніж `80…100 мВ/В` на нанорозмірних вузлах.

## 7. Захоплення заряду пастками та динамічний зсув порогової напруги (BTI)

Об'єм діелектрика `HfO₂` містить власні дефекти кристалічної ґратки — насамперед вакансії кисню `V_O`, які утворюють локалізовані енергетичні рівні пасток у забороненій зоні діелектрика. Під дією електричного поля інверсії електрони або дірки тунелюють із каналу та захоплюються цими пастками.

### Зсув порогової напруги через просторовий розподіл заряду пасток

Зсув порогової напруги `ΔV_th` внаслідок накопичення об'ємного заряду захоплених носіїв `ρ_trap(x)` уздовж товщини діелектрика описується інтегральним співвідношенням:

```
ΔV_th
= -1 / (ε_0 · k_SiO2) · ∫[0..EOT] x_eot · ρ_trap(x_eot) dx_eot [зсув порогу від об'ємного заряду пасток]
```

де `x_eot` — еквівалентна координата від поверхні затвора (`x_eot = 0`) до межі з кремнієм (`x_eot = EOT`).

Якщо заряд пасток `Q_trap = q · N_trap` локалізований безпосередньо на межі розділу `IL / High-k` на відстані `EOT_highk` від затвора:

```
ΔV_th
= (q · N_trap · EOT_highk) / (ε_0 · k_SiO2) [зсув порогової напруги від поверхневих пасток]
```

За густини пасток `N_trap = 10¹² см⁻²` та `EOT_highk = 0.5 нм`:

```
ΔV_th
= (1.602 · 10⁻¹⁹ · 10¹² · 0.5 · 10⁻⁷) / (8.854 · 10⁻¹⁴ · 3.9)
= (8.01 · 10⁻¹⁵) / (3.453 · 10⁻¹³)
≈ 0.0232 В = 23.2 мВ                  [динамічний зсув порогової напруги]
```

Цей ефект визначає нестабільність порогової напруги при температурно-електричному стресі (Bias Temperature Instability, PBTI для nMOS та NBTI для pMOS) і вимагає оптимізації легування High-k шару лантаном або алюмінієм для пасивації кисневих вакансій.

## 8. Розрахунок порогової напруги та дипольної інженерії межі розділу

Порогова напруга польового транзистора `V_th` визначається виразом:

```
V_th
= Φ_ms + 2 · ψ_B + Q_dep / C_ox - Q_eff / C_ox - ΔV_dipole [повне рівняння порогової напруги з диполем]
```

де:
- `Φ_ms = Φ_m - Φ_s` — контактна різниця потенціалів між затвором і напівпровідником (`В`);
- `ψ_B = (k_B · T / q) · ln(N_sub / n_i)` — потенціал Фермі об'єму напівпровідника (`≈ 0.35…0.40 В` при `N_sub = 10¹⁸ см⁻³`);
- `Q_dep = sqrt(4 · q · ε_0 · ε_Si · N_sub · ψ_B)` — заряд іонізованих домішок у збідненій області підкладки;
- `Q_eff` — ефективний фіксований заряд у діелектрику та на межі розділу;
- `ΔV_dipole` — стрибок електростатичного потенціалу на інтерфейсному диполі `High-k / SiO₂`.

### Дипольний зсув зон (Interface Dipole Engineering)

Осадження субмоношарових плівок оксиду лантану (`La₂O₃`) або оксиду алюмінію (`Al₂O₃`) на межу розділу `HfO₂ / SiO₂` генерує спрямований електричний дипольний момент завдяки різниці електронегативності та густини кисню в оксидах:

```
ΔV_dipole
= (q · N_dipole · d_dipole) / (ε_0 · k_dipole) [стрибок потенціалу на інтерфейсному диполі]
```

- Введення лантану (`La`) створює диполь, спрямований до кремнію, що зміщує ефективну роботу виходу на `ΔΦ_eff ≈ -0.3…-0.4 еВ` (ідеально для налаштування nMOS);
- Введення алюмінію (`Al`) створює зворотний диполь, що зміщує роботу виходу на `ΔΦ_eff ≈ +0.3…+0.4 еВ` (ідеально для налаштування pMOS).

Це дозволяє точно модифікувати зонні бар'єри на атомному рівні без необхідності пошуку екзотичних чистих металів з екстремальними роботами виходу.

### Екстракція роботи виходу методом Теради–Мути (C–V Flatband Method)

Для експериментального вимірювання ефективної роботи виходу `Φ_m,eff` виготовляють тестові структури конденсаторів із різною товщиною діелектрика `EOT` та вимірюють напругу плоских зон `V_fb`:

```
V_fb
= Φ_ms - Q_eff · EOT / (ε_0 · k_SiO2)  [лінійна залежність напруги плоских зон від EOT]
```

Будуючи графік залежності `V_fb` від `EOT`, екстраполюють пряму до перетину з віссю ординат (`EOT = 0`):
- Точка перетину з віссю напруги дає безпосереднє значення контактної різниці `Φ_ms = V_fb(EOT=0)`;
- Нахил прямої лінії визначає величину і знак ефективного заряду `Q_eff` на межі розділу.

Це дозволяє точно контролювати стабільність роботи виходу металів під час підбору нанорозмірних ковпачкових шарів `TiN`, `TaN`, `Al` та рідкісноземельних оксидів у виробничих лініях.
