# 🧮 Термодинамічна модель теплового розчіплювача та розрахунок часу спрацьовування біметалу

Для правильного проектування та селективної координації автоматичного вимикача недостатньо емпіричних таблиць: необхідно кількісно розрахувати швидкість деформації біметалевої пластини під дією джоулевого тепла, визначити точний час до розмикання механічного замка, оцінити енергію протікання `I²t` під час гасіння дуги та обчислити тягове зусилля соленоїда при короткому замиканні. Нижче наведено суворе математичне та термодинамічне виведення цих фізичних залежностей разом із числовим розрахунком для типового вимикача C16.

### 1. Механіка біметалевої пластини (формула Тимошенка)

Розглянемо консольно закріплену біметалеву смужку довжиною `L`, шириною `w` та загальною товщиною `d = d₁ + d₂`, що складається з двох жорстко з'єднаних шарів металу:
- Активний шар 1 (латунь або мідно-нікелевий сплав) із коефіцієнтом теплового розширення `α₁` та модулем пружності Юнга `E₁`;
- Пасивний шар 2 (інвар, сплав Fe-Ni 36%) із меншим коефіцієнтом розширення `α₂` (`α₁ > α₂`) та модулем Юнга `E₂`.

При підвищенні температури пластини на `ΔT = T - T₀` активний шар намагається видовжитися сильніше за пасивний. Оскільки шари жорстко зварені по всій площі контакту, вздовж межі розділу виникають зсувні напруження. Вони розтягують пасивний шар і стискають активний, створюючи внутрішній згинальний момент, що згинає смужку по дузі радіуса `ρ`.

За класичною теорією вигину біметалів Степана Тимошенка кривина пластини `1 / ρ` описується рівнянням:

```
1 / ρ = [ 6 · (α₁ - α₂) · ΔT · (1 + m)² ] / [ d · (3·(1 + m)² + (1 + m·n)·(m² + 1/(m·n))) ]
```

де безрозмірні коефіцієнти відношення товщин та модулів пружності шарів:

```
m = d₁ / d₂     [відношення товщин шарів]
n = E₁ / E₂     [відношення модулів пружності Юнга]
```

Для більшості стандартних електротехнічних термобіметалів товщини шарів обирають однаковими (`d₁ = d₂ = d / 2`, тобто `m = 1`), а модулі пружності близькими (`n ≈ 1`). Підставляючи ці значення у вираз Тимошенка:

```
1 / ρ
= [ 6 · (α₁ - α₂) · ΔT · (1 + 1)² ] / [ d · (3·(1 + 1)² + (1 + 1)·(1 + 1)) ]
= [ 6 · (α₁ - α₂) · ΔT · 4 ] / [ d · (3·4 + 2·2) ]
= [ 24 · (α₁ - α₂) · ΔT ] / [ d · 16 ]
= [ 3 · (α₁ - α₂) · ΔT ] / [ 2 · d ]
```

Прогин вільного кінця консольної пластини `y` при пружному вигині (`y << L`) пов'язаний із кривиною співвідношенням `y ≈ L² / (2 · ρ)`. Підставляючи `1 / ρ`, отримуємо рівняння прогину:

```
y(ΔT)
= (L² / 2) · (1 / ρ)
= (L² / 2) · [ 3 · (α₁ - α₂) · ΔT / (2 · d) ]
= [ 3 · (α₁ - α₂) · ΔT · L² ] / [ 4 · d ]
```

Це рівняння показує:
1. Прогин строго лінійно залежить від перепаду температури `ΔT`;
2. Прогин зростає як квадрат довжини пластини `L²`;
3. Прогин обернено пропорційний сумарній товщині пластини `d`.

### 2. Диференціальне рівняння термодинамічного балансу

Тепловий стан біметалу в кожну мить часу `t` визначається балансом потужностей: швидкість виділення тепла струмом `I` дорівнює сумі швидкості розсіювання тепла в довкілля та швидкості зміни внутрішньої енергії:

```
P_gen = P_diss + P_acc
I² · R(T) = k_th · (T(t) - T_amb) + C_th · [ dT(t) / dt ]
```

де:
- `I` — діюче значення струму розчіплювача (А);
- `R` — активний електричний опір біметалевої пластини (Ом);
- `C_th = m_b · c_p` — повна теплоємність пластини (Дж/K), де `m_b` — маса, `c_p` — питома теплоємність сплаву;
- `k_th = h_th · S_surf` — інтегральний коефіцієнт тепловіддачі в довкілля (Вт/K), де `S_surf` — площа охолодження;
- `T_amb` — температура всередині корпусу вимикача (°C).

Розділимо рівняння на повну теплоємність `C_th` і введемо теплову постійну часу розчіплювача `τ = C_th / k_th`:

```
dT(t) / dt + (1 / τ) · T(t) = (I² · R / C_th) + (T_amb / τ)
```

Це лінійне неоднорідне диференціальне рівняння першого порядку. Його аналітичний розв'язок за початкової умови `T(0) = T_amb` (холодний стан автомата) має вигляд:

```
T(t)
= T_amb + [ (I² · R) / k_th ] · [ 1 - e^(-t / τ) ]
```

Стаціонарна температура `T_inf`, якої пластина досягає при нескінченному часі протікання струму (`t → ∞`):

```
T_inf = T_amb + (I² · R) / k_th
```

### 3. Виведення обернено-залежної часової характеристики спрацьовування

Автомат спрацьовує, коли механічний прогин пластини `y(ΔT)` досягає критичного порогу спускової рейки `y_trip`, що відповідає перегріву пластини на `ΔT_trip = T_trip - T_amb`:

```
ΔT_trip = [ 4 · d · y_trip ] / [ 3 · (α₁ - α₂) · L² ]
```

Введемо струм асимптотичного розчеплення `I_inf` — мінімальний струм, який за нескінченний час розігріває пластину рівно до порогу `ΔT_trip`:

```
ΔT_trip = (I_inf² · R) / k_th   ==>   I_inf = √[ (k_th · ΔT_trip) / R ]
```

Підставимо порогову умову `T(t_trip) = T_trip` у розв'язок теплового рівняння:

```
T_trip - T_amb = [ (I² · R) / k_th ] · [ 1 - e^(-t_trip / τ) ]
ΔT_trip = [ (I² · R) / k_th ] · [ 1 - e^(-t_trip / τ) ]
```

Розв'яжемо отримане співвідношення відносно часу розчеплення `t_trip`:

```
(k_th · ΔT_trip) / (I² · R) = 1 - e^(-t_trip / τ)
I_inf² / I² = 1 - e^(-t_trip / τ)            [підставили I_inf² = k_th · ΔT_trip / R]
e^(-t_trip / τ) = 1 - (I_inf² / I²)
e^(-t_trip / τ) = (I² - I_inf²) / I²
-t_trip / τ = ln [ (I² - I_inf²) / I² ]
t_trip = τ · ln [ I² / (I² - I_inf²) ]
```

Аналітичний аналіз залежності часу розчеплення від кратності струму `k = I / I_inf`:
1. При `k ≤ 1.0` (`I ≤ I_inf`): аргумент логарифма від'ємний або дорівнює нескінченності, час `t_trip → ∞` (вимикач не розмикається);
2. При малому перевантаженні `k = 1.2` (`I = 1.2 · I_inf`):
   `t_trip = τ · ln [ 1.44 / (1.44 - 1.0) ] = τ · ln(3.27) ≈ 1.185 · τ`;
3. При високому струмі `k >> 1` (`I >> I_inf`): застосуємо розклад Тейлора `ln[1 / (1 - x)] ≈ x` при `x = I_inf² / I² << 1`:
   `t_trip = τ · ln [ 1 / (1 - I_inf²/I²) ] ≈ τ · (I_inf² / I²)`
   Час спрацьовування стає строго обернено-пропорційним квадрату струму: `t_trip ∝ 1 / I²`.

```
+─────────────────────────────────────────────────────────────────────────────+
|           ЧАС РОЗЧЕПЛЕННЯ ТЕПЛОВОГО РОЗЧІПЛЮВАЧА ВІД КРАТНОСТІ СТРУМУ       |
+───────────────────────────+───────────────────────────+─────────────────────+
| Кратність струму I/I_inf  | Формула ln[I²/(I²-I_inf²)]| Час розчеплення t   |
+───────────────────────────+───────────────────────────+─────────────────────+
| 1.05                      | ln(1.1025 / 0.1025)       | 2.38 · τ            |
| 1.13 (I_nt за IEC 60898)  | ln(1.2769 / 0.2769)       | 1.53 · τ            |
| 1.20                      | ln(1.4400 / 0.4400)       | 1.18 · τ            |
| 1.45 (I_t за IEC 60898)   | ln(2.1025 / 1.1025)       | 0.65 · τ            |
| 2.00                      | ln(4.0000 / 3.0000)       | 0.29 · τ            |
| 3.00                      | ln(9.0000 / 8.0000)       | 0.12 · τ            |
+───────────────────────────+───────────────────────────+─────────────────────+
```

### 4. Розрахунок сили електромагнітного розчіплювача соленоїда

При короткому замиканні швидкість нагріву біметалу недостатня для захисту кабелю. Захист виконує соленоїд миттєвої дії.

Тягова електромагнітна сила `F_mag`, що діє на рухомий феромагнітний плунжер соленоїда з числом витків `N`, площею перерізу осердя `A` та немагнітним зазором `x`, визначається через зміну магнітної енергії системи `W_mag`:

```
W_mag = (1 / 2) · L_sol(x) · I²
F_mag = ∂W_mag / ∂x = (1 / 2) · I² · (dL_sol / dx)
```

Індуктивність котушки з повітряним зазором `x` становить:

```
L_sol(x) = (μ₀ · N² · A) / x
dL_sol / dx = - (μ₀ · N² · A) / x²
```

Звідси величина сили магнітного притягання плунжера:

```
F_mag(I, x) = [ μ₀ · N² · I² · A ] / [ 2 · x² ]
```

Плунжер зрушує спускову собачку замка та вибиває контактний важіль, коли електромагнітна сила перевищує зусилля стиснення поворотної пружини `F_spring`:

```
F_mag(I_trip) ≥ F_spring
[ μ₀ · N² · I_trip² · A ] / [ 2 · x² ] = F_spring
I_trip = (x / N) · √[ (2 · F_spring) / (μ₀ · A) ]
```

Оскільки параметри `x`, `N`, `A` та `F_spring` визначаються суто механічною геометрією деталей, струм спрацьовування соленоїда `I_trip` практично не залежить від температури довкілля, що забезпечує стабільність порогів типів B (3–5 In), C (5–10 In) та D (10–20 In).

### 5. Динаміка енергії протікання I²t та модель напруги дуги

При розмиканні контактів під час короткого замикання повна енергія, що виділяється в колі за час відключення `t_clear`, визначається інтегралом Джоуля:

```
I²t_total = ∫₀^t_clear [ i(t) ]² dt
```

Процес відключення струмообмежувального автомата ділиться на дві стадії:
1. **Стадія розходження контактів (`0 ≤ t ≤ t_open`, типово 1.5–2.5 мс):** струм наростає за законом кола `di/dt = V_grid(t) / L_loop`.
2. **Стадія горіння дуги (`t_open ≤ t ≤ t_clear`, типово 3–5 мс):** дуга влітає в деіонну решітку, де її напруга стрибкоподібно піднімається до `V_arc > V_grid`.

Диференціальне рівняння струму під час горіння дуги:

```
L_loop · [ di(t) / dt ] + R_loop · i(t) = V_grid(t) - V_arc(t)
```

Оскільки напруга деіонної решітки `V_arc ≈ 280 В` перевищує миттєву напругу мережі `V_grid ≈ 230 · √2 · sin(ωt) ≈ 200 В`, похідна струму стає строго від'ємною:

```
di(t) / dt = [ V_grid(t) - V_arc ] / L_loop < 0
```

Струм лінійно спадає до нуля за час:

```
Δt_arc = [ L_loop · I_peak_limited ] / [ V_arc - V_grid_avg ]
```

Підставимо типові значення для короткого замикання з очікуваним струмом 6 кА (`L_loop ≈ 0.8 мГн`, `I_peak_limited ≈ 1.8 кА`, `V_arc = 280 В`, `V_grid_avg = 180 В`):

```
Δt_arc = [ 0.8 · 10⁻³ · 1800 ] / [ 280 - 180 ] = 1.44 / 100 = 0.0144 с = 14.4 мс (без решітки)
Δt_arc = [ 0.8 · 10⁻³ · 1800 ] / [ 350 - 180 ] = 1.44 / 170 ≈ 8.5 мс (з 12-пластинчастою деіонною камерою)
```

Інтеграл енергії `I²t` для трикутного імпульсу обмеженого струму:

```
I²t_limited
= (1 / 3) · (I_peak_limited)² · t_clear       [інтеграл від квадрата лінійного трикутного імпульсу]
= (1 / 3) · (1800)² · (0.006)                 [підстановка піку 1.8 кА та часу гасіння 6 мс]
= (1 / 3) · 3.24 · 10⁶ · 0.006                [обчислення квадрата амплітуди струму]
= 6 480 А²·с                                  [результат інтегрування обмеженої енергії]
```

Для порівняння, без деіонного струмообмеження (гасіння на переході синусоїди через нуль при `t = 10 мс`, очікуваний пік струму 8.5 кА):

```
I²t_prospective
= (1 / 2) · (I_peak)² · t_halfwave            [інтеграл від квадрата синусоїдної півхвилі струму]
= (1 / 2) · (8500)² · (0.010)                 [підстановка піку 8.5 кА та тривалості 10 мс]
= (1 / 2) · 72.25 · 10⁶ · 0.010               [обчислення квадрата амплітуди синусоїди]
= 361 250 А²·с                                [результат для необмеженого струму]
```

Енергія теплового руйнування `I²t` завдяки деіонному розсіченню дуги зменшується у **55 разів**, що повністю запобігає вибуху апарата та займанню прилеглої проводки.
