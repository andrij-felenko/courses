# 🧮 Розрахунок надійності: математичні моделі резервування 1+1 та 2oo3 (TMR)

Цей аналітичний розділ містить строге математичне виведення функцій надійності, інтенсивності відмов та середнього часу безвідмовної роботи (MTTF) для нерезервованих систем, схем дублювання 1+1 (Active/Standby) та мажоритарних систем потрійного модульного резервування 2oo3 (Triple Modular Redundancy — TMR), включно з моделями впливу арбітражного вузла та спільних причин відмови (β-factor model).

### 1. Базові функції теорії надійності нерезервованої системи (Simplex)

Для апаратного компонента з постійною інтенсивністю відмов `λ` (вираженою в кількості відмов на годину або у FIT, де `1 FIT = 10⁻⁹ відмов/год`), розподіл часу до першої відмови описується експоненційним законом.

Ймовірність безвідмовної роботи на інтервалі часу `t` визначається функцією надійності `R(t)`:

```
R_simplex(t) = e^(-λ · t)
```

Ймовірність виникнення відмови (функція ненадійності або функція розподілу відмов) `Q(t)`:

```
Q_simplex(t) = 1 - R_simplex(t)
= 1 - e^(-λ · t)           [підстановка експоненційного закону надійності]
```

Середній час безвідмовної роботи (англ. *Mean Time To Failure*, MTTF) обчислюється як інтеграл від функції надійності на нескінченному проміжку часу:

```
MTTF_simplex = ∫[0..∞] R_simplex(t) dt
= ∫[0..∞] e^(-λ · t) dt                  [підстановка R_simplex(t)]
= [- (1 / λ) · e^(-λ · t)] [0..∞]       [первісна показникової функції]
= 0 - (- 1 / λ)                          [границі інтегрування: e^(-∞)=0, e^0=1]
= 1 / λ                                  [результат інтегрування]
```

### 2. Система активного дублювання 1+1 (Hot Standby / Parallel Redundancy)

В архітектурі 1+1 Hot Standby два ідентичні апаратні модулі працюють паралельно, кожен з інтенсивністю відмов `λ`. Система зазнає повного колапсу тоді й лише тоді, коли одночасно відмовляють обидва канали.

Припускаючи повну статистичну незалежність відмов у каналах 1 та 2:

```
Q_1plus1(t) = Q₁(t) · Q₂(t)                                  [теорема множення ймовірностей незалежних подій]
= (1 - e^(-λ · t)) · (1 - e^(-λ · t))                         [вираз ненадійності через експоненційний закон]
= (1 - e^(-λ · t))²                                           [зведення у квадрат однакових множників]
= 1 - 2 · e^(-λ · t) + e^(-2 · λ · t)                         [розкриття квадрата двочлена (a - b)²]
```

Відповідно, функція надійності дубльованої системи `R_1plus1(t)` набуває вигляду:

```
R_1plus1(t) = 1 - Q_1plus1(t)                                 [визначення надійності через доповнення]
= 1 - (1 - 2 · e^(-λ · t) + e^(-2 · λ · t))                   [підстановка виведеного виразу Q_1plus1]
= 2 · e^(-λ · t) - e^(-2 · λ · t)                             [спрощення та приведення подібних]
```

Розрахуємо середній час безвідмовної роботи `MTTF_1plus1`:

```
MTTF_1plus1 = ∫[0..∞] R_1plus1(t) dt
= ∫[0..∞] (2 · e^(-λ · t) - e^(-2 · λ · t)) dt                [підстановка виведеної функції R_1plus1(t)]
= 2 · ∫[0..∞] e^(-λ · t) dt - ∫[0..∞] e^(-2 · λ · t) dt       [лінійність визначеного інтеграла]
= 2 · (1 / λ) - (1 / (2 · λ))                                 [інтегрування експонент: ∫ e^(-k·t) dt = 1/k]
= (4 / (2 · λ)) - (1 / (2 · λ))                               [зведення дробів до спільного знаменника]
= 3 / (2 · λ)                                                 [віднімання чисельників]
= 1.5 · MTTF_simplex                                          [зв'язок із надійністю одиничного каналу]
```

Дублювання збільшує середній час життя системи в 1.5 раза. Проте на ранніх етапах експлуатації (`λ · t << 1`) приріст надійності значно вищий, оскільки ймовірність відмови зменшується квадратично:

```
e^(-λ · t) ≈ 1 - λ · t + (λ · t)² / 2                         [розклад експоненти в ряд Тейлора до 2-го порядку]

Q_1plus1(t) = (1 - e^(-λ · t))²
≈ (λ · t)²                                                    [підстановка наближення першого порядку]
```

### 3. Потрійне модульне резервування 2oo3 (TMR з мажоритарним вибором)

У системі 2oo3 (англ. *2-out-of-3*) функціонують три паралельні обчислювальні або вимірювальні канали, виходи яких подаються на мажоритарний орган (Voter). Система залишається працездатною, якщо функціонують щонайменше 2 будь-які канали з 3.

Подія безвідмовної роботи системи складається з двох несумісних варіантів:
1. Працюють усі 3 канали: ймовірність `P(3 з 3) = R(t)³`.
2. Працюють будь-які 2 канали з 3 (а один відмовив): число комбінацій `C(3, 2) = 3`, ймовірність `P(2 з 3) = 3 · R(t)² · (1 - R(t))`.

Сумуючи ймовірності:

```
R_2oo3(t) = R(t)³ + 3 · R(t)² · (1 - R(t))                    [сума ймовірностей взаємовиключних станів]
= R(t)³ + 3 · R(t)² - 3 · R(t)³                               [розкриття дужок у другому доданку]
= 3 · R(t)² - 2 · R(t)³                                       [зведення подібних доданків для степеня 3]
```

Підставляючи експоненційний закон надійності `R(t) = e^(-λ · t)`:

```
R_2oo3(t) = 3 · (e^(-λ · t))² - 2 · (e^(-λ · t))³             [підстановка базової функції R(t)]
= 3 · e^(-2 · λ · t) - 2 · e^(-3 · λ · t)                     [властивість степенів (e^a)^b = e^(a·b)]
```

Обчислимо середній час безвідмовної роботи `MTTF_2oo3`:

```
MTTF_2oo3 = ∫[0..∞] (3 · e^(-2 · λ · t) - 2 · e^(-3 · λ · t)) dt   [інтеграл від функції надійності R_2oo3]
= 3 · ∫[0..∞] e^(-2 · λ · t) dt - 2 · ∫[0..∞] e^(-3 · λ · t) dt    [розбиття на суму табличних інтегралів]
= 3 · (1 / (2 · λ)) - 2 · (1 / (3 · λ))                            [обчислення інтегралів експонент]
= (3 / (2 · λ)) - (2 / (3 · λ))                                    [множення коефіцієнтів]
= (9 - 4) / (6 · λ)                                                [зведення до спільного знаменника 6·λ]
= 5 / (6 · λ)                                                      [віднімання чисельників]
≈ 0.833 · MTTF_simplex                                             [вираження через час життя Simplex]
```

#### Парадокс TMR: Чому MTTF зменшився, а надійність на місії зросла

Парадоксальний результат `MTTF_2oo3 = 0.833 · MTTF_simplex < MTTF_simplex` пояснюється тим, що в системі TMR працює втричі більше апаратних компонентів, кожен із яких піддається деградації. Коли відмовляє перший вузол, система 2oo3 автоматично перетворюється на систему без резерву з двох каналів, де відмова будь-якого наступного вузла виводить систему з ладу.

Знайдемо критичний момент часу перетину `t_cross`, до якого система TMR надійніша за Simplex:

```
R_2oo3(t_cross) = R_simplex(t_cross)                          [умова рівності надійності схем]
3 · R² - 2 · R³ = R                                           [підстановка поліномів надійності]

3 · R - 2 · R² = 1                                            [поділ на спільний множник R ≠ 0]
2 · R² - 3 · R + 1 = 0                                        [перенесення членів у форму квадратного рівняння]
(2 · R - 1) · (R - 1) = 0                                     [факторизація квадратного тричлена]
```

Корінь `R = 1` відповідає початковому моменту `t = 0`. Другий корінь визначає точку зламу:

```
R(t_cross) = 0.5                                              [корінь рівняння 2·R - 1 = 0]
e^(-λ · t_cross) = 0.5                                        [підстановка експоненційного закону]
- λ · t_cross = ln(0.5)                                       [лоґарифмування обох частин]
- λ · t_cross = - ln(2)                                       [властивість ln(1/2) = -ln(2)]
t_cross = ln(2) / λ                                           [ділення на -λ]
≈ 0.693 / λ                                                   [чисельне значення ln(2) ≈ 0.69315]
≈ 0.693 · MTTF_simplex                                        [вираження через MTTF одиночного каналу]
```

**Висновки для проєктування TMR:**
- При тривалості роботи `t < 0.693 · MTTF` система TMR має істотно вищу надійність, ніж одиночний канал.
- На ранніх етапах (`λ · t << 1`):
  `Q_2oo3(t) = 1 - (3 · R² - 2 · R³) ≈ 3 · (λ · t)²`.
- Якщо система не підлягає ремонту і тривалість її місії перевищує `0.693 · MTTF`, архітектура 2oo3 стає менш надійною, ніж Simplex, оскільки накопичені невідновлювані відмови 3 модулів неминуче викличуть подвійний збій. Тому системи TMR вимагають або періодичного технічного обслуговування (заміни відмовилих блоків), або обмеження гарантованого часу експлуатації.

### 4. Вплив надійності мажоритарного органу (Voter Reliability)

Мажоритарний елемент (голосуючий арбітр) стоїть на виході каналів і сам є потенційною одиничною точкою відмови (SPOF). Нехай арбітр має власну інтенсивність відмов `λ_v` та надійність `R_v(t) = e^(-λ_v · t)`.

Повна функція надійності системи:

```
R_system(t) = R_v(t) · R_2oo3(t)                                    [послідовне з'єднання арбітра та ядра 2oo3]
= e^(-λ_v · t) · (3 · e^(-2 · λ · t) - 2 · e^(-3 · λ · t))          [підстановка складових функцій надійності]
= 3 · e^(-(2 · λ + λ_v) · t) - 2 · e^(-(3 · λ + λ_v) · t)           [внесення експоненти e^(-λ_v·t) всередину дужок]
```

Середній час безвідмовної роботи з урахуванням арбітра:

```
MTTF_system = ∫[0..∞] R_system(t) dt
= 3 / (2 · λ + λ_v) - 2 / (3 · λ + λ_v)                             [інтегрування суми двох експонент]
```

### 5. Модель залежних відмов зі спільної причини (Common Cause Failure — β-factor)

У реальних вбудованих системах канали резервування не є абсолютно ізольованими: вони зазнають однакового впливу перепадів температури, сплесків напруги живлення, радіації та вібрацій. Для врахування залежних відмов використовують модель бета-фактора (англ. *β-factor model* за стандартом IEC 61508).

Загальна інтенсивність відмов кожного каналу `λ_total` розкладається на дві компоненти:
1. Незалежні індивідуальні відмови: `λ_ind = (1 - β) · λ_total`.
2. Відмови від спільної причини: `λ_cc = β · λ_total`, де `β` — частка відмов спільної причини (типово `β = 0.01 .. 0.10`, тобто 1–10%).

Для системи 1+1 з урахуванням `β`:

```
R_1plus1_ccf(t) = e^(-λ_cc · t) · [ 2 · e^(-λ_ind · t) - e^(-2 · λ_ind · t) ]    [модель спільної та незалежних часток]
= e^(-β · λ · t) · [ 2 · e^(-(1 - β) · λ · t) - e^(-2 · (1 - β) · λ · t) ]       [підстановка часток через параметр β]
```

При малих `t` розклад у ряд дає граничну ненадійність системи:

```
Q_1plus1_ccf(t) ≈ β · λ · t + ((1 - β) · λ · t)²                    [лінійне наближення спільної та квадратичне незалежної частки]
```

**Практичне значення формули:**
Якщо `β = 0.05` (5% відмов спричинені спільними факторами — спільним живленням або спільною шиною), то навіть при нескінченному резервуванні індивідуальних каналів надійність системи ніколи не перевищить стелю, задану коефіцієнтом `β`. Ненадійність визначається лінійним членом `β · λ · t`, а не квадратичним `(λ · t)²`. Це доводить, що усунення апаратних SPOF (розділення живлення, гальванічна ізоляція, незалежне тактування) є обов'язковою передумовою ефективності будь-якого резервування.

### 6. Покроковий розрахунок надійності модуля керування

**Умови інженерного завдання:**
- Модуль промислового контролера має інтенсивність відмов `λ = 200 FIT = 200 · 10⁻⁹ год⁻¹` (`MTTF = 5 000 000 год ≈ 570 років`).
- Тривалість безперервної місії `t = 8760 год` (1 рік).
- Мажоритарний орган 2oo3 реалізовано на дискретній логіці з `λ_v = 10 FIT`.
- Коефіцієнт спільних відмов `β = 0.02` (2%).

Розрахуємо ймовірність відмови за 1 рік експлуатації для трьох варіантів побудови системи.

```
λ · t = (200 · 10⁻⁹ год⁻¹) · 8760 год
= 1.752 · 10⁻³ = 0.001752                                           [безрозмірний показник напрацювання за рік]

1. Нерезервований Simplex канал:
Q_simplex = 1 - e^(-0.001752)                                       [формула ймовірності відмови Simplex]
≈ 0.001750 = 0.175 % (1750 ppm)                                     [обчислення експоненти: 1750 збоїв на мільйон]

2. Ідеальна дубльована система 1+1 (без спільних причин, β = 0):
Q_1plus1_ideal ≈ (λ · t)²                                           [квадратична ненадійність ідеального дублювання]
= (0.001752)²                                                       [підстановка показника напрацювання]
≈ 3.07 · 10⁻⁶ = 0.000307 % (3.07 ppm)                               [зниження збоїв у 570 разів порівняно з Simplex]

3. Дубльована система 1+1 з урахуванням спільних причин (β = 0.02):
Q_cc = 1 - e^(-β · λ · t)                                           [ненадійність від спільних факторів]
≈ 0.02 · 0.001752 = 3.504 · 10⁻⁵ (35.04 ppm)                        [лінійна оцінка частки спільних причин]

Q_ind ≈ ((1 - β) · λ · t)²                                          [ненадійність від незалежних відмов]
= (0.98 · 0.001752)² ≈ 2.95 · 10⁻⁶ (2.95 ppm)                       [квадратична оцінка незалежних каналів]

Q_1plus1_real = 1 - (1 - Q_cc) · (1 - Q_ind)                        [сумарна ймовірність за правилом добутку]
≈ Q_cc + Q_ind                                                      [наближення для малих ймовірностей]
= 35.04 ppm + 2.95 ppm = 37.99 ppm                                  [спільні причини спричинили 92% усіх відмов]

4. Система 2oo3 TMR з урахуванням надійності арбітра (λ_v = 10 FIT):
λ_v · t = (10 · 10⁻⁹) · 8760 = 8.76 · 10⁻⁵ (87.6 ppm)               [напрацювання мажоритарного органу]
Q_voter ≈ 8.76 · 10⁻⁵ = 87.6 ppm                                    [ймовірність відмови арбітра]

Q_tmr_core ≈ 3 · (λ · t)²                                           [ймовірність подвійної відмови каналів 2oo3]
= 3 · (0.001752)² ≈ 9.21 · 10⁻⁶ = 9.21 ppm                          [чисельне значення збоїв каналів 2oo3]

Q_tmr_total ≈ Q_voter + Q_tmr_core                                  [сумарна ненадійність системи TMR]
= 87.6 ppm + 9.21 ppm = 96.81 ppm                                   [арбітр став джерелом 90% ненадійності]
```

**Головний інженерний висновок:**
Надійність резервованої системи на 90–95% лімітується не якістю основних обчислювальних каналів, а надійністю вузлів комутації/арбітражу та залишковими апаратними SPOF (коефіцієнтом `β`).
