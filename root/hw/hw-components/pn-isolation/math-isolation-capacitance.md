# 🧮 Розрахунок бар'єрної ємності p-n ізоляції та струмів зміщення

Електрична ізоляція між функціональними кишенями інтегральної мікросхеми забезпечується зворотно зміщеним p-n переходом. У статичному режимі опір такого переходу наближається до нескінченності, а струм обмежується мізерним струмом витоку неосновних носіїв. Проте в динамічному режимі, коли потенціали на колекторах транзисторів або на виводах резисторів змінюються з високою швидкістю, зворотно зміщений p-n перехід поводиться як нелінійний конденсатор.

Ця паразитна ємність ізоляції сповільнює перемикання логічних вентилів, знижує граничну частоту підсилення інтегрованих транзисторів та слугує містком, крізь який високочастотні завади з цифрової частини схеми проникають у спільну підкладку й спотворюють роботу чутливих аналогових блоків.

## Вбудований потенціал та рівняння Пуассона

На межі розділу між епітаксійним n-шаром (донорна концентрація `N_D`) та p-підкладкою (акцепторна концентрація `N_A`) утворюється подвійний шар просторового нерухомого заряду: позитивно заряджених іонізованих донорів з боку n-області та негативно заряджених іонізованих акцепторів з боку p-області.

Вбудована різниця потенціалів `V_bi` (контактна різниця потенціалів) виникає внаслідок дифузії основних носіїв до моменту встановлення термодинамічної рівноваги:

```
V_bi = V_t · ln((N_A · N_D) / n_i²)      [рівняння Больцмана для контактного бар'єра]
```

Тут `V_t = k · T / q` — термічний потенціал (близько `0.0259 В` при температурі `T = 300 K`), `k` — стала Больцмана, `q = 1.602 · 10⁻¹⁹ Кл` — елементарний електричний заряд, `n_i` — власна концентрація носіїв у кремнії (`≈ 1.5 · 10¹⁰ см⁻³` при кімнатній температурі).

Якщо до переходу прикладено зовнішню зворотну напругу зміщення `V_R = V_n - V_p > 0`, повна різниця потенціалів на переході зростає:

```
V_total = V_bi + V_R                    [сумарне падіння напруги на збідненій області]
```

Для знаходження розподілу електричного поля `E(x)` та ширини збідненої області `W_dep` скористаємося одновимірним рівнянням Пуассона для густини об'ємного заряду `ρ(x)`:

```
d²φ / dx² = -ρ(x) / ε_s                 [диференціальне рівняння Пуассона]
```

де `ε_s = ε_r · ε_0` — абсолютна діелектрична проникність кремнію (`ε_r ≈ 11.7`, `ε_0 = 8.854 · 10⁻¹⁴ Ф/см`, звідки `ε_s ≈ 1.036 · 10⁻¹² Ф/см`).

Розподіл густини заряду в збідненій області:
- У p-області (`-x_p ≤ x ≤ 0`): `ρ(x) = -q · N_A`
- У n-області (`0 ≤ x ≤ x_n`): `ρ(x) = +q · N_D`

Інтегруючи рівняння Пуассона від межі `x = -x_p` (де поле дорівнює нулю), отримуємо розподіл електричного поля `E(x) = -dφ/dx`:

```
E(x) = -(q · N_A / ε_s) · (x + x_p)     [електричне поле в p-області: -x_p ≤ x ≤ 0]
E(x) = -(q · N_D / ε_s) · (x_n - x)     [електричне поле в n-області: 0 ≤ x ≤ x_n]
```

Максимальне електричне поле досягається строго на металургійній межі `x = 0`:

```
E_max = (q · N_A · x_p) / ε_s = (q · N_D · x_n) / ε_s   [максимальне поле на межі поділу]
```

Умова нейтральності повного заряду `N_A · x_p = N_D · x_n` разом із подвійним інтегруванням поля для знаходження потенціалу дає зв'язок між напругою та глибиною збіднення:

```
V_total = (1/2) · E_max · (x_n + x_p)
= (q / (2 · ε_s)) · (N_A · x_p² + N_D · x_n²)           [інтеграл електричного поля]
```

Розв'язуючи цю систему відносно повної ширини збідненого шару `W_dep = x_n + x_p`:

```
W_dep(V_R) = √((2 · ε_s · (V_bi + V_R) / q) · (1/N_A + 1/N_D))   [ширина збідненої області]
```

Оскільки об'ємний шар іонізованих домішок повністю позбавлений рухомих носіїв струму, він виконує роль ідеального діелектрика товщиною `W_dep`, розташованого між двома провідними квазінейтральними областями кремнію.

## Питома бар'єрна ємність ізоляційного переходу

Диференціальна ємність одиниці площі зворотно зміщеного p-n переходу визначається зміною накопиченого просторового заряду `dQ` при нескінченно малій зміні прикладеної напруги `dV`:

```
C_j_area = dQ / dV_R
= ε_s / W_dep(V_R)                      [формула плоскопаралельного шару діелектрика]
= √((q · ε_s · N_A · N_D) / (2 · (N_A + N_D) · (V_bi + V_R)))   [питома ємність різкого переходу]
```

У практичних інженерних розрахунках питому ємність записують через ємність за нульового зовнішнього зміщення `C_j0`:

```
C_j0 = √((q · ε_s · N_A · N_D) / (2 · (N_A + N_D) · V_bi))      [питома ємність при V_R = 0]
```

Тоді залежність бар'єрної ємності від прикладеної зворотної напруги набуває канонічного вигляду:

```
C_j_area(V_R) = C_j0 / (1 + V_R / V_bi)^m                        [вольт-фарадна характеристика]
```

де `m` — коефіцієнт градієнта легування. Для різкого ступінчастого переходу (abrupt junction) `m = 0.5`, а для плавно-лінійного дифузійного переходу (linearly graded junction) `m ≈ 0.33`.

## Порівняння різкого та плавно-градієнтного переходу (Linearly Graded Junction)

У реальних дифузійних процесах, де профіль домішки бору в ізоляційних p⁺ стінках формується високотемпературною дифузією з поверхні, межа розділу не є ідеально ступінчастою. Поблизу металургійного переходу різниця концентрацій домішок змінюється лінійно вздовж координати `x`:

```
N_D(x) - N_A(x) = a · x                 [лінійне наближення профілю легування]
```

де `a = d(N_D - N_A) / dx` — градієнт концентрації домішок (типово `a ~ 10²⁰ – 10²² см⁻⁴`).

Інтегруючи рівняння Пуассона `d²φ/dx² = -(q · a · x) / ε_s` для симетричної збідненої області `[-W_dep/2 .. +W_dep/2]`:

```
E(x) = (q · a / (2 · ε_s)) · ((W_dep / 2)² - x²)   [параболічний профіль електричного поля]
E_max = (q · a · W_dep²) / (8 · ε_s)               [максимальне поле в центрі лінійного переходу]
```

Інтегрування електричного поля для знаходження контактної різниці потенціалів та прикладеної напруги дає:

```
V_total = V_bi + V_R = (q · a · W_dep³) / (12 · ε_s)   [зв'язок напруги та товщини лінійного переходу]
```

Звідки ширина збідненого шару плавно-градієнтного переходу пропорційна кубічному кореню з прикладеної напруги:

```
W_dep_graded(V_R) = ((12 · ε_s · (V_bi + V_R)) / (q · a))^(1/3)   [товщина збіднення лінійного переходу]
```

Відповідно, питома бар'єрна ємність лінійно-градієнтного ізоляційного переходу спадає повільніше за збільшення напруги, ніж для різкого переходу:

```
C_j_graded(V_R) = ε_s / W_dep_graded
= ((q · a · ε_s²) / (12 · (V_bi + V_R)))^(1/3)   [питома ємність лінійно-градієнтного переходу]
```

У практичних біполярних ІС перехід на дні кишені (`n⁺ прихований шар / p-підкладка`) через високу концентрацію домішок у subcollector поводиться майже строго як **різкий перехід** (`m ≈ 0.5`), тоді як перехід на бічній стінці через тривале дифузійне розмиття бору має проміжний показник ступеня (`m ≈ 0.38 – 0.44`).

## Дві складові паразитної ємності ізольованої кишені: дно та бічні стінки

Ізольована кишеня на кристалі оточена p-областями з усіх боків:
1. **Донна ємність (`C_bottom`)**: перехід між дном n-кишені (або високолегованим n⁺ прихованим шаром) та слаболегованою p-підкладкою.
2. **Периметральна / бічна ємність (`C_wall`)**: перехід між вертикальними бічними гранями n-кишені та важколегованими p⁺ ізоляційними стінками.

Оскільки ізоляційні стінки легуються бором із надзвичайно високою поверхневою концентрацією (`N_A_wall ~ 10¹⁸ – 10¹⁹ см⁻³`), перехід на бічній стінці є несиметричним `p⁺-n`. Ширина збідненої області бічної стінки виявляється набагато вужчою, ніж на дні, а питома ємність бічної стінки `C_j_wall` — значно вищою за донну `C_j_bottom`.

Повна ємність ізольованої кишені `C_iso` є сумою паралельних ємностей дна та бічного периметра:

```
C_iso(V_R) = A_bottom · C_j_bottom(V_R) + P_wall · X_epi · C_j_wall(V_R)   [повна ємність кишені]
```

де `A_bottom` — площа дна кишені в плані (довжина `L` × ширина `W`), `P_wall = 2 · (L + W)` — периметр кишені, `X_epi` — глибина епітаксійного шару (глибина залягання ізоляційної ванни).

## Напруга лавинного пробою ізоляційного переходу

Максимальна напруга, яку здатна витримати ізоляційна кишеня без руйнівного пробою, визначається критичним електричним полем ударної іонізації кремнію `E_crit ≈ 3 · 10⁵ В/см`:

```
BV_iso = (ε_s · E_crit²) / (2 · q · N_D_epi) - V_bi              [напруга лавинного пробою]
```

Для типової концентрації донорів епітаксії `N_D_epi = 2 · 10¹⁵ см⁻³`:

```
BV_iso = (1.036 · 10⁻¹² · 9 · 10¹⁰) / (2 · 1.602 · 10⁻¹⁹ · 2 · 10¹⁵) - 0.8
= (9.324 · 10⁻²) / (6.408 · 10⁻⁴) - 0.8
= 145.5 - 0.8 ≈ 144.7 В                                         [пробивна напруга ізоляції]
```

Такий значний запас напруги дозволяє класичній p-n ізоляції надійно працювати в схемах живлення з напругами `12 В`, `24 В` та `48 В`.

## Покроковий числовий приклад розрахунку стандартної кишені

Розглянемо стандартний біполярний техпроцес із такими технологічними параметрами:
- Концентрація акцепторів у p-підкладці: `N_A_sub = 10¹⁵ см⁻³`
- Концентрація донорів в епітаксійному n-шарі: `N_D_epi = 2 · 10¹⁵ см⁻³`
- Концентрація донорів у прихованому шарі n⁺ (дно): `N_D_BL = 10¹⁹ см⁻³`
- Концентрація акцепторів у p⁺ ізоляційній стінці: `N_A_wall = 5 · 10¹⁸ см⁻³`
- Геометричні розміри n-кишені: довжина `L = 80 мкм`, ширина `W = 40 мкм`, глибина епітаксії `X_epi = 8 мкм`
- Напруга живлення: `V_CC = 15 В`, напруга на підкладці: `V_sub = 0 В` (робоча зворотна напруга `V_R = 15 В`)

### Крок 1. Розрахунок контактної різниці потенціалів дна

```
V_bi_bottom = 0.0259 · ln((10¹⁹ · 10¹⁵) / (1.5 · 10¹⁰)²)
= 0.0259 · ln(10³⁴ / 2.25 · 10²⁰)        [підстановка числових значень]
= 0.0259 · ln(4.44 · 10¹³)               [розрахунок аргументу логарифма]
= 0.0259 · 31.42                         [обчислення натурального логарифма]
= 0.814 В                                [вбудований потенціал n⁺-p переходу дна]
```

### Крок 2. Розрахунок питомої ємності дна при V_R = 15 В

Оскільки `N_D_BL >> N_A_sub`, перехід на дні є однобічним різким переходом, де майже вся збіднена область розширюється вглиб слаболегованої p-підкладки:

```
W_dep_bottom = √((2 · 1.036 · 10⁻¹² · (0.814 + 15)) / (1.602 · 10⁻¹⁹ · 10¹⁵))
= √((2 · 1.036 · 10⁻¹² · 15.814) / 1.602 · 10⁻⁴)    [підстановка напруги та констант]
= √(3.276 · 10⁻¹¹ / 1.602 · 10⁻⁴)                    [проміжне ділення]
= √(2.045 · 10⁻⁷)                                    [квадратний корінь]
= 4.52 · 10⁻⁴ см                                     [ширина збіднення: 4.52 мкм]
```

Питома ємність дна:

```
C_j_bottom = ε_s / W_dep_bottom
= (1.036 · 10⁻¹² Ф/см) / (4.52 · 10⁻⁴ см)            [ділення діелектричної проникності на товщину]
= 2.29 · 10⁻⁹ Ф/см²                                  [питома ємність у фарадах на кв. см]
= 2.29 · 10⁻⁵ пФ/мкм²                                [переведення у пФ на кв. мікрометр]
```

### Крок 3. Розрахунок питомої ємності бічної стінки при V_R = 15 В

На бічній стінці перехід `p⁺-n` сформований важколегованою p⁺ стінкою та помірно легованим n-епітаксійним шаром (`N_D_epi = 2 · 10¹⁵ см⁻³`):

```
V_bi_wall = 0.0259 · ln((5 · 10¹⁸ · 2 · 10¹⁵) / (1.5 · 10¹⁰)²)
= 0.0259 · ln(10³⁴ / 2.25 · 10²⁰)
= 0.814 В                                            [вбудований потенціал бічного переходу]
```

Ширина збідненої області бічної стінки (розширюється в n-епітаксію):

```
W_dep_wall = √((2 · 1.036 · 10⁻¹² · 15.814) / (1.602 · 10⁻¹⁹ · 2 · 10¹⁵))
= √((3.276 · 10⁻¹¹) / (3.204 · 10⁻⁴))
= √(1.022 · 10⁻⁷)
= 3.20 · 10⁻⁴ см                                     [ширина збіднення бічної стінки: 3.20 мкм]
```

Питома ємність бічної стінки:

```
C_j_wall = (1.036 · 10⁻¹² Ф/см) / (3.20 · 10⁻⁴ см)
= 3.24 · 10⁻⁹ Ф/см²
= 3.24 · 10⁻⁵ пФ/мкм²                                [питома ємність бічної стінки]
```

### Крок 4. Повна паразитна ємність кишені

Площа дна:
`A_bottom = 80 мкм · 40 мкм = 3200 мкм²`

Площа бічних стінок:
`A_wall = 2 · (80 + 40) мкм · 8 мкм = 1920 мкм²`

Обчислюємо внесок кожної частини:

```
C_bottom = 3200 мкм² · 2.29 · 10⁻⁵ пФ/мкм²
= 0.0733 пФ                                          [ємність дна кишені]

C_wall = 1920 мкм² · 3.24 · 10⁻⁵ пФ/мкм²
= 0.0622 пФ                                          [ємність бічних стінок]

C_iso_total = C_bottom + C_wall
= 0.0733 + 0.0622
= 0.1355 пФ ≈ 136 фФ                                 [повна паразитна ємність ізольованої кишені]
```

Незважаючи на те, що площа бічних стінок менша за площу дна майже в 1.7 раза, через вищу концентрацію легування бічні стінки дають понад 45% сумарної паразитної ємності ізоляції.

## Динамічні струми зміщення та модель ємнісного проникнення завад (Substrate Crosstalk)

Коли потенціал на колекторі транзистора змінюється з крутизною `dV/dt`, крізь бар'єрну ємність ізоляції в спільну підкладку тече струм зміщення:

```
i_sub(t) = C_iso(V) · (dV / dt) + V · (dC_iso / dt)  [повний ємнісний струм зміщення]
```

Для швидкого логічного фронту перемикання з перепадом `ΔV = 5 В` за час `Δt = 1 нс` (`dV/dt = 5 · 10⁹ В/с`):

```
i_sub ≈ 1.36 · 10⁻¹³ Ф · 5 · 10⁹ В/с
= 6.8 · 10⁻⁴ А = 0.68 мА                             [імпульсний струм однієї кишені в підкладку]
```

Розглянемо передачу цього шуму на сусідню високоомну аналогову кишеню через спільний розподілений опір підкладки `R_sub` за допомогою частотної передавальної функції `H(s) = V_noise(s) / V_driver(s)`:

```
H(s) = (s · R_sub · C_iso1) / (1 + s · R_sub · (C_iso1 + C_iso2))   [передавальна функція зв'язку]
```

На високих частотах (`ω >> 1 / (R_sub · (C_iso1 + C_iso2))`) коефіцієнт проникнення шуму визначається ємнісним дільником:

```
V_noise_max = V_driver · (C_iso1 / (C_iso1 + C_iso2))               [асимптотична амплітуда завади]
```

Для двох однакових кишень `C_iso1 = C_iso2 = 0.136 пФ` коефіцієнт передачі на високій частоті сягає `0.5` (50% амплітуди цифрового перепаду наводиться на підкладку). Якщо підкладка заземлена через контактний опір `R_sub = 20 Ом`, амплітуда шуму на частоті `100 МГц` (`ω = 6.28 · 10⁸ рад/с`) становить:

```
|H(jω)| ≈ ω · R_sub · C_iso1
= 6.28 · 10⁸ · 20 · 1.36 · 10⁻¹³
= 1.71 · 10⁻³ = -55.3 дБ                             [коефіцієнт придушення завади підкладки]
```

При амплітуді цифрового перемикання `5 В` наведений шум на аналоговому вузлі становить `5 В · 1.71 · 10⁻³ ≈ 8.55 мВ`. Для 10-бітного АЦП з опорною напругою `2.5 В` вага одного молодшого значущого розряду (LSB) становить `2.44 мВ`. 

Отже, наведений шум `8.55 мВ` еквівалентний спотворенню на `3.5 LSB`, що повністю руйнує точність перетворення. Це строго доводить математичну необхідність топологічного екранування охоронними кільцями та фізичного рознесення цифрових і аналогових кишень на кристалі.

## Температурний коефіцієнт вбудованого потенціалу та ємності

Вбудована різниця потенціалів `V_bi` має виражену температурну залежність, зумовлену експоненційним зростанням власної концентрації носіїв `n_i(T)` зі збільшенням температури:

```
n_i(T) = N_0 · T^(3/2) · exp(-E_g / (2 · k · T))   [температурна залежність власної концентрації]
```

Диференціюючи вираз для `V_bi = (k·T/q) · ln((N_A·N_D)/n_i²)` по температурі `T`, отримуємо температурний коефіцієнт контактного потенціалу:

```
dV_bi / dT = (V_bi - (E_g0 / q)) / T - (3 · k / q)  [температурний градієнт вбудованого потенціалу]
```

Для кремнію при `T = 300 K` та `V_bi ≈ 0.8 В` температурний коефіцієнт становить приблизно `-1.8 – -2.0 мВ/°C`. Зниження контактного потенціалу при нагріванні призводить до того, що за фіксованої зовнішньої напруги сумарний бар'єр `(V_bi + V_R)` зменшується, що спричиняє додаткове зростання паразитної ємності ізоляції:

```
dC_iso / dT = -m · (C_iso / (V_bi + V_R)) · (dV_bi / dT) > 0   [зростання ємності з температурою]
```

При підвищенні температури від `25 °C` до `125 °C` паразитна ємність ізоляційної кишені зростає на `3 – 5%`, що додатково збільшує затримки перемикання та посилює ємнісне наведення завад у гарячих зонах кристала.

## Високочастотна модель втрат у підкладці та добротність переходу

На надвисоких частотах (СВЧ / RF) зворотно зміщений p-n перехід ізоляції не можна розглядати як ідеальний конденсатор. Послідовно з бар'єрною ємністю `C_iso` діє розподілений опір омічного контакту та об'єму слаболегованої підкладки `R_sub`. 

Повна еквівалентна провідність (адмітанс) ізоляційного вузла на кутовій частоті `ω` має вигляд:

```
Y_iso(ω) = G_eq(ω) + j · ω · C_eq(ω)                 [еквівалентний адмітанс ізоляції]
```

де активна провідність еквівалентних діелектричних втрат та еквівалентна ємність визначаються формулами:

```
G_eq(ω) = (ω² · R_sub · C_iso²) / (1 + ω² · R_sub² · C_iso²)   [активна провідність втрат]
C_eq(ω) = C_iso / (1 + ω² · R_sub² · C_iso²)                   [еквівалентна ємність на ВЧ]
```

Добротність паразитної ємності ізоляції `Q_iso` швидко спадає зі зростанням частоти:

```
Q_iso = 1 / (ω · R_sub · C_iso)                      [добротність паразитної ємності]
```

Для опору підкладки `R_sub = 30 Ом` та ємності `C_iso = 0.136 пФ` на частоті `1 ГГц` (`ω = 6.28 · 10⁹ рад/с`):

```
Q_iso = 1 / (6.28 · 10⁹ · 30 · 1.36 · 10⁻¹³)
= 1 / (2.56 · 10⁻²) ≈ 39.0                           [добротність на частоті 1 ГГц]
```

Енергія високочастотного сигналу розсіюється на опорі підкладки у вигляді тепла, що обмежує застосування традиційної p-n ізоляції в радіочастотних інтегральних схемах (RFIC) і робить безальтернативним використання технологій кремнію на ізоляторі (SOI) з високоомною підкладкою.

## Великосигнальна усереднена ємність при цифровому перемиканні

Оскільки бар'єрна ємність `C_j(V)` є нелінійною функцією прикладеної напруги, при перемиканні логічного сигналу від низького рівня `V_1` до високого рівня `V_2` перезаряджання ізоляції визначається не миттєвою, а еквівалентною **великосигнальною усередненою ємністю** (*large-signal average capacitance*):

```
Q_total = ∫[V_1 .. V_2] C_j(V) dV                    [повний накопичений заряд]
C_avg = Q_total / (V_2 - V_1)                        [усереднена великосигнальна ємність]
```

Підставляючи аналітичний вираз вольт-фарадної характеристики для різкого переходу (`m = 1/2`), виконуємо аналітичне інтегрування:

```
C_avg = (1 / (V_2 - V_1)) · ∫[V_1 .. V_2] (C_j0 / √(1 + V / V_bi)) dV
= ((2 · C_j0 · V_bi) / (V_2 - V_1)) · [√(1 + V_2 / V_bi) - √(1 + V_1 / V_bi)]   [точна формула інтегральної ємності]
```

Для імпульсу перемикання від `V_1 = 0.5 В` до `V_2 = 5.0 В` при `V_bi = 0.814 В` та нульовій ємності `C_j0 = 0.5 пФ`:

```
√(1 + V_2 / V_bi) = √(1 + 5.0 / 0.814) = √(7.14) = 2.672   [фактор верхньої напруги]
√(1 + V_1 / V_bi) = √(1 + 0.5 / 0.814) = √(1.61) = 1.270   [фактор нижньої напруги]

C_avg = ((2 · 0.5 · 0.814) / (5.0 - 0.5)) · (2.672 - 1.270)
= (0.814 / 4.5) · 1.402
= 0.1809 · 1.402 = 0.2536 пФ                         [динамічна еквівалентна ємність перезаряджання]
```

Цей розрахунок показує, що ефективна динамічна ємність кишені при цифровому перемиканні приблизно вдвічі менша за статичну ємність `C_j0` за нульової напруги.

## Динамічні втрати потужності та заряд відновлення ізоляції

При роботі в імпульсних та перемикальних схемах паразитна ємність p-n ізоляції є джерелом постійного розсіювання енергії. Повна потужність втрат у вузлі ізоляції складається зі статичної та динамічної компонент:

```
P_total = P_static + P_dynamic                       [повна потужність розсіювання ізоляційного переходу]
= I_leak(T) · V_R + f_sw · C_avg · (ΔV)²             [статичні втрати витоку + динамічні втрати перезаряджання]
```

де `f_sw` — частота перемикання вузла, `ΔV = V_2 - V_1` — розмах амплітуди перемикання, `C_avg` — великосигнальна усереднена ємність.

Для мікросхеми драйвера з 16 вихідними ключами, що комутують напругу `ΔV = 24 В` на частоті `f_sw = 500 кГц` за температури `125 °C` (струм витоку `I_leak ≈ 500 нА`, ємність кишені `C_avg = 0.25 пФ`):

```
P_static = 500 · 10⁻⁹ А · 24 В = 1.2 · 10⁻⁵ Вт = 12 мкВт   [статичні втрати однієї кишені]
P_dynamic = 5 · 10⁵ Гц · 2.5 · 10⁻¹³ Ф · (24 В)²
= 1.25 · 10⁻⁷ · 576
= 7.2 · 10⁻⁵ Вт = 72 мкВт                            [динамічні втрати однієї кишені]

P_16_tubs = 16 · (12 + 72) мкВт
= 16 · 84 мкВт = 1.344 мВт                           [сумарні втрати ізоляції 16 каналів]
```

Хоча для однієї кишені втрати становлять мікровати, у великих багатоканальних драйверах інтегральні ємнісні втрати в підкладку роблять помітний внесок у загальний тепловий бюджет мікросхеми та вимагають розрахунку теплового опору кристала.

## Тепловий шум підкладки та його наведення на вхідні каскади

Окрім динамічних завад перемикання, розподілений опір підкладки `R_sub` є джерелом неперервного білого теплового шуму Джонсона-Найквіста:

```
v_n_sub² = 4 · k · T · R_sub · Δf                    [спектральна густина теплового шуму підкладки]
```

Для опору підкладки `R_sub = 50 Ом` за кімнатної температури `T = 300 K` у смузі частот `Δf = 10 МГц`:

```
v_n_sub = √(4 · 1.38 · 10⁻²³ · 300 · 50 · 10⁷)
= √(8.28 · 10⁻¹² В²)
= 2.88 · 10⁻⁶ В = 2.88 мкВ                           [діюче значення теплового шуму підкладки]
```

Цей шумовий потенціал крізь бар'єрну ємність ізоляції `C_iso` та імпеданс джерела сигналу `Z_src` прикладається до бази вхідного малошумлячого транзистора (LNA), створюючи нижній шумовий поріг підсилювача:

```
v_n_in = v_n_sub · (ω · C_iso · |Z_src|) / √(1 + (ω · C_iso · |Z_src|)²)   [шумова напруга на вході каскаду]
```

Для високоомного джерела сигналу `Z_src = 10 кОм` на частоті `10 МГц` (`ω = 6.28 · 10⁷ рад/с`) при ємності ізоляції `C_iso = 0.136 пФ`:

```
ω · C_iso · |Z_src| = 6.28 · 10⁷ · 1.36 · 10⁻¹³ · 10⁴ = 8.54 · 10⁻²   [фактор ємнісного ділення]
v_n_in ≈ 2.88 мкВ · 0.0854 = 0.246 мкВ               [наведений шум на вході підсилювача]
```

У мікрофонних та інструментальних передпідсилювачах, де корисний сигнал становить одиниці мікровольтів, наведений шум підкладки може погіршити відношення сигнал/шум (SNR) на `3 – 6 дБ`, що вимагає застосування спеціальних глибоких дифузійних екранів та окремих виводів тихої аналогової землі.

## Вплив ємності ізоляції на частотну смугу та ефект Міллера

У підсилювальному каскаді зі спільним емітером паразитна ємність кишені `C_iso` під'єднана між колектором транзистора та заземленою підкладкою, діючи паралельно вихідному навантаженню `R_L`. Вона формує домінантний високочастотний полюс:

```
f_3dB = 1 / (2 · π · R_L · C_iso)                    [верхня гранична частота каскаду за рівнем -3 дБ]
```

Для високоомного колекторного навантаження `R_L = 10 кОм` та ємності кишені `C_iso = 0.136 пФ`:

```
f_3dB = 1 / (2 · 3.1416 · 10⁴ Ом · 1.36 · 10⁻¹³ Ф)
= 1 / (8.545 · 10⁻⁸ с)
= 1.17 · 10⁷ Гц = 11.7 МГц                           [гранична смуга пропускання]
```

Крім того, у багатокаскадних підсилювачах зворотно зміщений перехід ізоляції вносить внесок у динамічну вхідну ємність через ефект Міллера: якщо паразитна ємність підкладки увімкнена на виході інвертуючого підсилювача з коефіцієнтом підсилення `K_v = -g_m · R_L`, її вплив на затримку наростання фронту пропорційний коефіцієнту підсилення каскаду:

```
C_in_miller = C_CB · (1 + |K_v|) + C_iso_load         [сумарне ємнісне навантаження вузла]
```

Також зміна зворотної напруги підкладки викликає ефект модулювального зміщення ширини бази (*Early-like backgate modulation*): розширення збідненого шару колектор-підкладка модулює ефективний опір тіла колектора, що створює нелінійні гармонійні спотворення в аналогових підсилювачах потужності при великих розмахах вихідної напруги.

Саме ця паразитна ємність на рівні десятків і сотень фемтофарадів історично обмежувала швидкодію планарних біполярних ІС і стимулювала перехід до технологій діелектричної ізоляції (STI та SOI).
