# 🔌 Порівняння методів обмеження індуктивних викидів: лавина, діод, снабер і TVS

Комутація індуктивних навантажень (обмоток реле, електромагнітних клапанів, тягових двигунів або первинних обмоток імпульсних трансформаторів) неминуче супроводжується викидом напруги самоіндукції при розмиканні ключа. Якщо не передбачити шлях для розсіювання магнітної енергії `(1/2)·L·I²`, перенапруга перевищить напругу пробою силового транзистора.

Інженер має п'ять основних схемотехнічних стратегій придушення індуктивного викиду. Кожна з них пропонує компроміс між швидкістю знеструмлення котушки, тепловим навантаженням на кристал, рівнем електромагнітних завад (EMI) та кількістю додаткових компонентів на платі.

### 1. Пряма лавинна робота силового ключа (Self-Clamping Avalanche)

У цьому підході в коло не встановлюють жодних додаткових захисних компонентів. При розмиканні ключа індуктивний струм підіймає напругу на стоці до рівня `V_DS = BV_DSS`, змушуючи транзистор перейти в режим керованого лавинного пробою.

- **Фізика розсіювання:** Уся магнітна енергія індуктивності разом з енергією джерела живлення `V_DD` поглинається внутрішнім об'ємом кремнію силового транзистора.
- **Швидкість спаду струму:** Максимально можлива серед усіх пасивних методів. Оскільки проти-ЕРС дорівнює різниці `BV_DSS - V_DD`, швидкість спаду струму `di/dt = -(BV_DSS - V_DD)/L` є гранично високою, а час знеструмлення `t_demag = L · I / (BV_DSS - V_DD)` — мінімальним.
- **Повторюваність та розкид параметрів:** Напруга лавинного пробою `BV_DSS` має технологічний розкид у межах партії до ±10% і позитивний температурний коефіцієнт `+0.08%/°C`. Це призводить до помітної варіації тривалості знеструмлення котушки залежно від поточної температури вузла, що може бути небажаним у високопрецизійних системах дозування.
- **Переваги:** Нуль додаткових деталей, нульова площа на друкованій платі, найшвидше відпускання механічних реле чи клапанів.
- **Недоліки та обмеження:** Кристал MOSFET зазнає сильного теплового удару. Підхід придатний лише для рідкісних одиночних комутацій або низькочастотних циклів, де розсіяна енергія суворо менша за допустиму паспортну `E_AS(T_j)`. Категорично не підходить для високочастотного ШІМ через перевищення ліміту `E_AR` та ризик відмикання паразитного біполярного транзистора.

### 2. Зворотний діод паралельно навантаженню (Freewheeling / Flyback Diode)

Класичне рішення: паралельно індуктивному навантаженню вмикають діод катодом до шини живлення `+V_DD`, а анодом — до стоку транзистора.

- **Фізика розсіювання:** У момент вимкнення індуктивність змінює полярність напруги, діод відкривається у прямому напрямку, і струм замикається у контурі «котушка — діод». Енергія розсіюється на прямому спаді напруги діода `V_F` (~0.4–1.0 В) та активному опорі обмотки котушки `R_coil`.
- **Швидкість спаду струму:** Дуже повільна. Напруга розмагнічування котушки становить лише `V_demag = V_F + I · R_coil ≈ 1–2 В`. Струм спадає експоненційно з постійною часу `τ = L / R_coil`. У реле чи електромагнітах це призводить до затягування механічного відпускання контактів (10–50 мс замість 1–2 мс) та повільного розмикання, що багаторазово прискорює ерозію контактних груп через тривале горіння електричної дуги.
- **Динамічні втрати діода:** У високочастотних імпульсних перетворювачах звичайний кремнієвий діод (наприклад, 1N4007) спричиняє величезні втрати через тривалий час зворотного відновлення `t_rr` (> 2 мкс) та накопичений заряд `Q_rr`. Під час чергового відкривання MOSFET зворотний струм діода створює практично пряме коротке замикання шини живлення на землю. Тому в ШІМ-колах обов'язково застосовують діоди Шотткі (Schottky) або ультрашвидкі діоди (Ultra-Fast Recovery, `t_rr < 25 нс`).
- **Переваги:** Повна відсутність високовольтного перевантаження на транзисторі (`V_DS` ніколи не перевищує `V_DD + V_F`), усе тепло розсіюється поза кристалом транзистора, дешевизна та простота.
- **Недоліки:** Повільне знеструмлення; необхідність ретельного підбору діода за часом відновлення у високочастотних колах.

### 3. RC або RCD-снабер (Resistor-Capacitor-Diode Snubber)

Демпферне коло, що підключається або паралельно транзистору (стік-витік), або паралельно індуктивності.

- **Фізика розсіювання:** Конденсатор `C_s` уповільнює наростання напруги `dV/dt` на стоці в момент вимкнення ключа, приймаючи на себе початковий кидок струму. Резистор `R_s` поглинає коливальну енергію паразитного резонансного контуру `L_parasitic - C_oss`, гасячи високочастотний «дзвін» (Ringing).
- **Розрахунок демпфування:** Для оптимального критичного затухання без перерегулювання опір резистора снабера підбирають близьким до характеристичного хвильового опору паразитного контуру:
  ```
  R_s ≈ √(L_stray / C_oss)
  ```
  Ємність конденсатора `C_s` зазвичай обирають у 2–4 рази більшою за вихідну ємність транзистора `C_oss`.
- **Вимоги до компонентів снабера:** Конденсатор снабера зазнає дуже високих струмових навантажень `I_rms = C_s · (dV/dt)`. Застосування звичайних керамічних конденсаторів класу 2 (X7R, X5R) небажане через втрату до 70–80% ємності під високою постійною напругою (DC-bias effect) та сильне п'єзоелектричне розтріскування. Рекомендується використовувати виключно високостабільну кераміку класу 1 (C0G/NP0) або поліпропіленові плівкові конденсатори (MKP).
- **Переваги:** Ефективне придушення високочастотного електромагнітного випромінювання (EMI), зниження динамічних втрат увімкнення та вимкнення, перенесення тепла з кристала транзистора на потужний зовнішній резистор снабера.
- **Недоліки:** Додаткові втрати потужності на кожному циклі перемикання `P_snubber = (1/2) · C_s · V² · f_sw`, збільшення габаритів плати через встановлення потужного резистора та високовольтного конденсатора.

### 4. TVS-діод (Transient Voltage Suppressor / Супресор)

Напівпровідниковий симетричний або несиметричний обмежувач напруги (супресор), встановлений або паралельно транзистору, або паралельно індуктивності.

- **Фізика розсіювання:** При перевищенні напруги пробою супресора `V_BR(TVS)` діод лавинно відкривається і жорстко обмежує напругу на рівні фіксації `V_clamp`. Уся магнітна енергія скидається в масивний кремнієвий кристал TVS-діода, спеціально оптимізований для поглинання високих пікових потужностей (від 400 Вт до 5 кВт).
- **Швидкість спаду струму:** Висока. Оскільки напруга фіксації супресора `V_clamp` обирається значно вищою за напругу живлення `V_DD` (але нижчою за `BV_DSS` транзистора), розрядка індуктивності відбувається швидко, забезпечуючи чітке та швидке спрацьовування реле чи клапанів.
- **Координація за напругою:** Щоб TVS надійно захищав MOSFET за будь-яких температур, його максимальна напруга фіксації за найвищої робочої температури повинна бути суворо меншою за мінімальну напругу лавини MOSFET за найнижчої температури:
  ```
  V_clamp_max(TVS, +125°C) < BV_DSS_min(MOSFET, -40°C)
  ```
- **Динамічний опір супресора:** На відміну від ідеального стабілітрона, реальний TVS-діод має внутрішній динамічний диференційний опір `R_dyn = ΔV / ΔI` (близько 0.1–1.5 Ом). При великих пікових струмах напруга на супресорі зростає вище номінальної напруги пробою `V_BR`, що слід враховувати при виборі запасу за напругою для MOSFET.
- **Переваги:** Передбачуваний і стабільний рівень обмеження напруги, повний захист транзистора від лавинного нагрівання, швидке знеструмлення котушки, висока надійність.
- **Недоліки:** Вартість супресора, обмеження щодо середньої потужності розсіювання при безперервній високочастотній роботі.

### 5. Активне стабілітронне обмеження (Active Zener Clamping)

Схемотехнічний прийом, за якого між стоком і затвором силового транзистора вмикають високовольтний стабілітрон або TVS-діод з напругою стабілізації `V_Z < BV_DSS`.

- **Фізика розсіювання:** Коли напруга стоку перевищує `V_Z`, стабілітрон пробивається і починає впорскувати струм безпосередньо в затвор транзистора. Напруга на затворі підіймається до порогового рівня `V_th`, змушуючи транзистор відкритися в лінійному (активному) режимі.
- **Розподіл навантаження:** Транзистор утримує напругу на рівні `V_DS ≈ V_Z + V_th`, самостійно проводячи індуктивний струм крізь свій **основний канал**, а не через зворотний p-n перехід body-діода!
- **Стійкість до вторинного пробою:** Оскільки струм тече крізь інверсійний канал під оксидом затвора, дірковий струм крізь підкладковий опір `R_body` повністю відсутній. Це на 100% усуває ризик відкриття паразитного біполярного транзистора (BJT turn-on). Тепло розсіюється рівномірно по всій площі активного каналу транзистора.
- **Особливості проектування:** Потрібно обов'язково встановлювати захисний діод послідовно зі стабілітроном (щоб запобігти витоку струму керування з затвора в стік при нормальному відкриванні ключа) та правильно обирати послідовний резистор затвора `R_G` для уникнення високочастотної автогенерації в активному режимі.
- **Переваги:** Повний захист від руйнівного біполярного пробою, використання одного потужного кристала транзистора для поглинання тепла, висока швидкість знеструмлення.
- **Недоліки:** Необхідність додаткових компонентів зворотного зв'язку затвора, деяке сповільнення фронтів вимикання.

### Топологічні правила трасування та режими відмови

При виборі будь-якої схеми обмеження викидів критичну роль відіграє фізичне розташування компонентів на друкованій платі (PCB Layout):

1. **Мінімізація паразитної індуктивності контуру (Loop Inductance):**
   Контур, утворений стоком транзистора, супресором (або снабером/діодом) та витоком транзистора, повинен мати мінімально можливу геометричну площу. Кожні `10 нГн` паразитної індуктивності монтажу при швидкості спаду струму `di/dt = 100 А/мкс` генерують додатковий неконтрольований перепад напруги `ΔV = L · (di/dt) = 1 В`, який додається до напруги фіксації і може пробити закритий транзистор.
2. **Кельвінове підключення затвора при активному клампі:**
   Коло зворотного зв'язку активного стабілітрона має повертатися безпосередньо на вивід затвора транзистора, оминаючи силові провідники витоку, якими протікає великий струм розряду.
3. **Аналіз режимів відмови компонентів (Failure Modes):**
   - TVS-діоди при критичному перевантаженні за енергією майже завжди переходять у стан стійкого короткого замикання (Short-Circuit Failure), надійно захищаючи транзистор ціною виходу з ладу захисного вузла.
   - Резистори снаберів при перевантаженні перегорають в обрив (Open-Circuit Failure), після чого весь наступний комутаційний сплеск безперешкодно б'є по транзистору.
   - Зворотні діоди при тривалому нагріванні страждають від зростання струму витоку `I_R(T_j)`, що може спричинити тепловий розгін самого діода у високовольтних блоках живлення.

### Програмний розрахунок параметрів гасіння викидів

Для порівняння параметрів розмагнічування індуктивності нижче наведено розрахунковий алгоритм мовами C та C++, який обчислює тривалість спаду струму, пікову потужність та енергетичні втрати для різних методів захисту.

```c
/* calculation_clamping.c — розрахунок параметрів захисту від індуктивного викиду */
#include <stdio.h>
#include <math.h>

typedef struct {
    double v_dd;        /* Напруга живлення, В */
    double l_ind;       /* Індуктивність навантаження, Гн */
    double i_peak;      /* Струм перед вимиканням, А */
    double r_coil;      /* Активний опір котушки, Ом */
    double bv_dss;      /* Напруга лавини MOSFET, В */
    double v_tvs_clamp; /* Напруга обмеження TVS, В */
} CircuitParams;

typedef struct {
    double t_demag_sec; /* Час знеструмлення котушки, с */
    double energy_joules;/* Повна енергія розсіювання, Дж */
    double peak_power_w;/* Пікова розсіювана потужність, Вт */
} DemagResult;

/* Розрахунок режиму прямої лавини MOSFET */
DemagResult calc_avalanche_mode(const CircuitParams *p) {
    DemagResult res;
    double v_diff = p->bv_dss - p->v_dd;
    if (v_diff <= 0.0) {
        res.t_demag_sec = -1.0; /* Помилка: BV_DSS має бути більшим за V_DD */
        return res;
    }
    res.t_demag_sec = (p->l_ind * p->i_peak) / v_diff;
    res.energy_joules = 0.5 * p->l_ind * p->i_peak * p->i_peak * (p->bv_dss / v_diff);
    res.peak_power_w = p->bv_dss * p->i_peak;
    return res;
}

/* Розрахунок режиму захисту зворотним діодом */
DemagResult calc_freewheel_diode(const CircuitParams *p, double v_f) {
    DemagResult res;
    /* Спад струму за законом i(t) = I0 * exp(-t/tau), де tau = L/R. Час до спаду 99% струму ≈ 5*tau */
    double tau = p->l_ind / (p->r_coil > 0.05 ? p->r_coil : 0.05);
    res.t_demag_sec = 5.0 * tau;
    res.energy_joules = 0.5 * p->l_ind * p->i_peak * p->i_peak;
    res.peak_power_w = (p->v_dd + v_f) * p->i_peak;
    return res;
}

/* Розрахунок режиму захисту супресором (TVS) */
DemagResult calc_tvs_mode(const CircuitParams *p) {
    DemagResult res;
    double v_diff = p->v_tvs_clamp - p->v_dd;
    if (v_diff <= 0.0) {
        res.t_demag_sec = -1.0;
        return res;
    }
    res.t_demag_sec = (p->l_ind * p->i_peak) / v_diff;
    res.energy_joules = 0.5 * p->l_ind * p->i_peak * p->i_peak * (p->v_tvs_clamp / v_diff);
    res.peak_power_w = p->v_tvs_clamp * p->i_peak;
    return res;
}
```

    double v_dd{24.0};         // Напруга живлення, В
    double l_ind{0.010};       // Індуктивність, Гн (10 мГн)
    double i_peak{3.0};        // Струм навантаження, А
    double r_coil{8.0};        // Опір обмотки, Ом
    double bv_dss{60.0};       // Напруга лавини MOSFET, В
    double v_tvs_clamp{45.0};  // Напруга фіксації TVS, В
};

struct DemagResult {
    double t_demag_sec{0.0};
    double energy_joules{0.0};
    double peak_power_w{0.0};
};

enum class CalcError {
    InvalidVoltageDifference,
    ZeroInductance
};

class ClampingCalculator {
public:
    static std::expected<DemagResult, CalcError> calc_avalanche(const CircuitParams& p) noexcept {
        if (p.l_ind <= 0.0) return std::unexpected(CalcError::ZeroInductance);
        const double v_diff = p.bv_dss - p.v_dd;
        if (v_diff <= 0.0) return std::unexpected(CalcError::InvalidVoltageDifference);

        const double t_av = (p.l_ind * p.i_peak) / v_diff;
        const double e_as = 0.5 * p.l_ind * p.i_peak * p.i_peak * (p.bv_dss / v_diff);
        const double p_pk = p.bv_dss * p.i_peak;

        return DemagResult{t_av, e_as, p_pk};
    }

    static std::expected<DemagResult, CalcError> calc_freewheel(const CircuitParams& p, double v_f = 0.7) noexcept {
        if (p.l_ind <= 0.0) return std::unexpected(CalcError::ZeroInductance);
        const double effective_r = (p.r_coil > 0.05) ? p.r_coil : 0.05;
        const double tau = p.l_ind / effective_r;
        const double t_demag = 5.0 * tau; // 99% спаду струму
        const double energy = 0.5 * p.l_ind * p.i_peak * p.i_peak;
        const double p_pk = v_f * p.i_peak;

        return DemagResult{t_demag, energy, p_pk};
    }

    static std::expected<DemagResult, CalcError> calc_tvs(const CircuitParams& p) noexcept {
        if (p.l_ind <= 0.0) return std::unexpected(CalcError::ZeroInductance);
        const double v_diff = p.v_tvs_clamp - p.v_dd;
        if (v_diff <= 0.0) return std::unexpected(CalcError::InvalidVoltageDifference);

        const double t_demag = (p.l_ind * p.i_peak) / v_diff;
        const double energy = 0.5 * p.l_ind * p.i_peak * p.i_peak * (p.v_tvs_clamp / v_diff);
        const double p_pk = p.v_tvs_clamp * p.i_peak;

        return DemagResult{t_demag, energy, p_pk};
    }
};
