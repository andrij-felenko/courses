# 🧮 Математика лавинної енергії UIS та інтегрування теплового імпульсу

Коли силовий транзистор розриває коло зі струмом крізь індуктивність без шунтувального діода, енергія магнітного поля не зникає: вона перетворюється на тепло безпосередньо в кремнієвому кристалі за напруги лавинного пробою. Щоб розрахувати, чи витримає напівпровідникова структура такий удар, інженер повинен точно визначити тривалість лавинного процесу, пікову потужність, сумарну розсіяну енергію, точний часовий профіль температури переходу та результуючий стрибок нагрівання кристала з урахуванням нелінійності теплофізичних властивостей кремнію, теплових еквівалентних схем, динамічного опору пробою та теплового накопичення при серіях імпульсів.

### Динаміка струму під час прямого ходу (накопичення енергії)

Схема випробування на нефіксовану індуктивну комутацію (Unclamped Inductive Switching, UIS) містить джерело постійної напруги `V_DD`, послідовно з'єднаний дросель з індуктивністю `L` та випробовуваний транзистор (DUT).

Під час замикання транзистора на час `t_on` напруга джерела живлення прикладається до індуктивності. Якщо знехтувати малим падінням напруги на відкритому каналі `I · R_DS(on)` та активним опором котушки `R_L` (припущення `R_total · t_on / L << 1`), диференціальне рівняння наростання струму має вигляд:

```
V_DD = L · (di / dt)

di / dt = V_DD / L          [розділення змінних]

i(t) = (V_DD / L) · t       [інтегрування за початкової умови i(0) = 0]
```

Наприкінці інтервалу провідності `t = t_on` струм у колі досягає пікового значення `I_AS` (лавинного випробувального струму):

```
I_AS = (V_DD / L) · t_on
```

Енергія магнітного поля `E_L`, накопичена в осерді та просторі котушки до моменту розмикання ключа:

```
E_L = ∫[0..I_AS] L · i di
= (1/2) · L · I_AS²         [інтегрування магнітної енергії]
```

Якщо ж враховувати активний опір дроселя `R_L`, рівняння кола набуває форми класичного перехідного процесу першого порядку:

```
V_DD = L · (di / dt) + i(t) · R_L

di / dt + (R_L / L) · i(t) = V_DD / L

i(t) = (V_DD / R_L) · [ 1 - exp(- (R_L / L) · t) ]   [загальний розв'язок з урахуванням R_L]
```

При малих значеннях `(R_L · t / L)` розклад експоненти в ряд Тейлора `exp(-x) ≈ 1 - x` повертає вихідну лінійну формулу `i(t) ≈ (V_DD / L) · t`.

### Динаміка розряду індуктивності під час лавинного пробою

У момент `t = t_on` напруга на затворі транзистора спадає нижче порогової (`V_GS = 0 В`), і канал перекривається. Струм в індуктивності не може змінитися стрибком (`i(t_on+) = I_AS`). Зменшення струму генерує ЕРС самоіндукції зворотного знака:

```
e_L = -L · (di / dt)
```

Потенціал стоку підіймається вище напруги живлення:

```
v_DS(t) = V_DD - e_L = V_DD + L · (-di / dt)
```

Щойно напруга `v_DS` досягає фактичної напруги лавинного пробою переходу `BV_DSS` (позначається також як `V_BR`), у кристалі розпочинається ударна іонізація. Напруга на стоці жорстко фіксується на рівні `v_DS(t) = BV_DSS`, утворюючи так звану лавинну полицю.

Запишемо другий закон Кірхгофа для замкненого контуру під час лавини для ідеального дроселя (`R_L = 0`):

```
V_DD - L · (di / dt) - BV_DSS = 0

L · (di / dt) = -(BV_DSS - V_DD)

di / dt = -(BV_DSS - V_DD) / L      [швидкість спаду струму]
```

Оскільки напруга живлення `V_DD` та напруга лавинного пробою `BV_DSS` є незмінними в першому наближенні, швидкість спаду струму `di / dt` є строго постійною від'ємною величиною. Струм стоку лінійно спадає від `I_AS` до нуля:

```
i_D(t) = I_AS - ((BV_DSS - V_DD) / L) · t      [для 0 ≤ t ≤ t_av]
```

Тривалість лавинного імпульсу `t_av` — це час, за який струм `i_D(t)` повністю спадає до 0:

```
0 = I_AS - ((BV_DSS - V_DD) / L) · t_av

t_av = (L · I_AS) / (BV_DSS - V_DD)           [тривалість лавинного розряду]
```

#### Врахування власного активного опору котушки R_L

Якщо опір обмотки `R_L` становить помітну величину (наприклад, у високоомних котушках реле чи соленоїдів), рівняння контуру набуває вигляду:

```
V_DD - L · (di / dt) - i(t) · R_L - BV_DSS = 0

L · (di / dt) + i(t) · R_L = -(BV_DSS - V_DD)

di / [ (BV_DSS - V_DD) + i · R_L ] = -(1 / L) dt     [розділення змінних]
```

Інтегруючи від `t = 0` (де `i = I_AS`) до довільного моменту часу `t`, отримуємо точний закон спаду струму:

```
i(t) = [ I_AS + (BV_DSS - V_DD) / R_L ] · exp(- (R_L / L) · t) - (BV_DSS - V_DD) / R_L
```

Час повного знеструмлення `t_av(R_L)` за наявності активного опору:

```
t_av(R_L) = (L / R_L) · ln[ 1 + (I_AS · R_L) / (BV_DSS - V_DD) ]
```

При малих значеннях аргументу `x = (I_AS · R_L) / (BV_DSS - V_DD)` наближення `ln(1 + x) ≈ x - x²/2` дає `t_av(R_L) ≈ (L · I_AS) / (BV_DSS - V_DD)`, що повністю збігається з ідеальною формулою.

### Динамічний опір лавинного пробою R_dyn та нахил лавинної полиці

У реальних напівпровідникових приладах напруга на лавинній полиці не є абсолютно горизонтальною лінією. Вона має помітний позитивний нахил за рахунок двох фізичних факторів:
1. **Динамічного диференційного опору збідненої зони `R_dyn`:**
   При протіканні великого струму заряд вільних носіїв у збідненому шарі частково екранує електричне поле (Space-Charge Resistance), що вимагає вищої напруги для підтримки коефіцієнта ударної іонізації.
2. **Динамічного саморозігріву кристала під час імпульсу:**
   Зі зростанням температури за рахунок позитивного коефіцієнта `α_BV` напруга пробою зростає прямо під час протікання імпульсу.

Миттєва напруга на стоці з урахуванням динамічного опору записується як:

```
v_DS(t) = BV_DSS0 + i_D(t) · R_dyn + BV_DSS0 · α_BV · ΔT_j(t)
```

де `BV_DSS0` — початкова напруга пробою при нульовому струмі та початковій температурі.

Підставивши цей вираз у рівняння спаду струму, отримуємо уточнений інтеграл енергії:

```
E_AS_real = ∫[0..t_av] [ BV_DSS0 + i_D(t) · R_dyn ] · i_D(t) dt

= BV_DSS0 · ∫[0..t_av] i_D(t) dt + R_dyn · ∫[0..t_av] i_D²(t) dt

= (1/2) · BV_DSS0 · I_AS · t_av + (1/3) · R_dyn · I_AS² · t_av
```

Додатковий доданок `(1/3) · R_dyn · I_AS² · t_av` показує внесок внутрішнього динамічного опору кристала у сумарні енергетичні втрати під час важких сильнострумових випробувань.

### Виведення формули розсіяної лавинної енергії E_AS

Миттєва електрична потужність `p(t)`, що виділяється у вигляді тепла всередині напівпровідникового кристала MOSFET під час лавинного пробою:

```
p(t) = v_DS(t) · i_D(t)
= BV_DSS · [ I_AS · (1 - t / t_av) ]
```

Повна енергія одиночного лавинного імпульсу `E_AS` (Single Pulse Avalanche Energy), яка розсіюється в кристалі, дорівнює інтегралу миттєвої потужності за час `t_av`:

```
E_AS = ∫[0..t_av] p(t) dt

= ∫[0..t_av] BV_DSS · I_AS · (1 - t / t_av) dt

= BV_DSS · I_AS · ∫[0..t_av] (1 - t / t_av) dt

= BV_DSS · I_AS · [ t - t² / (2 · t_av) ][0..t_av]

= BV_DSS · I_AS · (t_av - t_av / 2)

= (1/2) · BV_DSS · I_AS · t_av                 [площа трикутника потужності]
```

Підставимо отриманий раніше вираз для тривалості розряду `t_av = (L · I_AS) / (BV_DSS - V_DD)`:

```
E_AS = (1/2) · BV_DSS · I_AS · [ (L · I_AS) / (BV_DSS - V_DD) ]

= (1/2) · L · I_AS² · [ BV_DSS / (BV_DSS - V_DD) ]
```

Це фундаментальна формула лавинної енергії UIS.

### Фізичний зміст множника BV_DSS / (BV_DSS - V_DD) та баланс енергії

Зверніть увагу на множник `BV_DSS / (BV_DSS - V_DD)`. Він завжди строго більший за одиницю, оскільки `BV_DSS > V_DD`.

Це означає, що енергія, розсіяна в транзисторі `E_AS`, **завжди перевищує** чисто магнітну енергію `E_L = (1/2) · L · I_AS²`, накопичену в індуктивності перед вимиканням.

Звідки береться додаткова енергія? Її постачає джерело постійної напруги `V_DD` безпосередньо під час протікання розрядного струму.

Обчислимо енергію `E_source`, віддану джерелом `V_DD` за час `t_av`:

```
E_source = ∫[0..t_av] V_DD · i_D(t) dt

= V_DD · ∫[0..t_av] I_AS · (1 - t / t_av) dt

= (1/2) · V_DD · I_AS · t_av

= (1/2) · V_DD · I_AS · [ (L · I_AS) / (BV_DSS - V_DD) ]

= (1/2) · L · I_AS² · [ V_DD / (BV_DSS - V_DD) ]
```

Перевіримо закон збереження енергії для замкненої системи:

```
E_L + E_source
= (1/2) · L · I_AS² + (1/2) · L · I_AS² · [ V_DD / (BV_DSS - V_DD) ]

= (1/2) · L · I_AS² · [ 1 + V_DD / (BV_DSS - V_DD) ]

= (1/2) · L · I_AS² · [ (BV_DSS - V_DD + V_DD) / (BV_DSS - V_DD) ]

= (1/2) · L · I_AS² · [ BV_DSS / (BV_DSS - V_DD) ]

= E_AS                                       [баланс енергії строго доведено]
```

Таким чином, енергія лавинного удару складається з двох компонентів:
1. Магнітної енергії котушки `E_L`;
2. Додаткової енергії живлення `E_source`, частка якої зростає зі зближенням напруги живлення `V_DD` та напруги пробою `BV_DSS`.

Якщо `V_DD` становить, наприклад, 80% від `BV_DSS` (`V_DD / BV_DSS = 0.8`), коефіцієнт становить `1 / (1 - 0.8) = 5`. У такому разі транзистор розсіє в 5 разів більше енергії, ніж було спочатку запасено в дроселі, оскільки розряд триватиме довго, і джерело струму закачає в лавинний канал величезну додаткову потужність.

### Теплові моделі кристала: еквівалентні схеми Фостера та Кауера

Для моделювання теплової поведінки напівпровідникового кристала використовують дві класичні еквівалентні схеми заміщення, засновані на тепло-електричній аналогії:

1. **Теплова модель Фостера (Foster RC Network):**
   Представляє тепловий імпеданс як послідовне з'єднання паралельних RC-ланок. Кожна ланка має свій тепловий опір `R_i` та теплоємність `C_i` з постійною часу `τ_i = R_i · C_i`.
   Перехідний тепловий опір у часовій області для моделі Фостера записується як сума експоненційних складових:
   ```
   Z_th(t) = ∑[i=1..N] R_i · [ 1 - exp(-t / τ_i) ]
   ```
   Головний недолік моделі Фостера полягає в тому, що вона є чисто математичною апроксимацією (розкладанням передавальної функції на прості дроби). Її проміжні вузли не мають фізичного змісту і не відповідають реальним фізичним шарам структури (кристал, припій, фланець).

2. **Теплова модель Кауера (Cauer Ladder Network):**
   Являє собою фізичну T-подібну або П-подібну драбинчасту RC-мережу. У ній кожен вузол строго відповідає реальному геометричному шару приладу:
   - Перша ланка — теплоємність кремнієвого кристала `C_silicon` та тепловий опір кремнію `R_silicon`;
   - Друга ланка — теплоємність і опір шару припою (Die Attach);
   - Третя ланка — мідний тепловідвідний фланець корпусу (Leadframe / Copper Header).

Трансформація між параметрами моделі Фостера та фізичною моделлю Кауера здійснюється через розкладання вхідного імпедансу `Z_th(s)` у неперервний ланцюговий дріб.

### Тепловий розрахунок перехідного нагрівання кристала

Лавинний розряд триває дуже короткий проміжок часу — типово від 1 мкс до 100 мкс. За такий мізерний інтервал тепло не встигає покинути кремнієву пластину й дійти до металевого фланця чи зовнішнього радіатора: нагрівання має суто адіабатичний характер.

#### Одновимірна дифузія тепла в напівбезмежний кремній

Глибина проникнення теплової хвилі `L_diff` у кремній за час `t` оцінюється за фундаментальним дифузійним співвідношенням:

```
L_diff = 2 · √(α · t)
```

де `α = k / (ρ · c)` — коефіцієнт температуропровідності кремнію (близько `0.85 · 10⁻⁴ м²/с` при 300 К).

Для лавинного імпульсу тривалістю `t_av = 10 мкс`:

```
L_diff = 2 · √(0.85 · 10⁻⁴ · 10 · 10⁻⁶) = 2 · √(8.5 · 10⁻¹⁰) ≈ 2 · 2.91 · 10⁻⁵ м ≈ 58 мкм
```

Оскільки стандартна товщина кремнієвої пластини становить 150–250 мкм, за час лавинного імпульсу теплова хвиля прогріває лише верхню третину кристала. Металева основа корпусу (фланець TO-220 чи D2PAK) залишається абсолютно холодною, і вся лавинна енергія локалізується виключно в мікроскопічному об'ємі кремнію.

Розв'язок одновимірного рівняння теплопровідності Фур'є для плоского джерела тепла потужністю `P` на поверхні напівбезмежного кремнієвого тіла площею `A` визначає стрибок температури поверхні:

```
ΔT_surface(t) = [ (2 · P) / (A · √(π · k · ρ · c)) ] · √t
```

де:
- `k` — теплопровідність кремнію (`≈ 148 Вт/(м·°C)` при 300 К);
- `ρ` — густина кремнію (`≈ 2330 кг/м³`);
- `c` — питома теплоємність (`≈ 700 Дж/(кг·°C)`).

Групуючи теплофізичні константи матеріалу в єдиний коефіцієнт `K_th`, отримуємо фундаментальну залежність короткоімпульсного перехідного теплового імпедансу від кореня з часу:

```
Z_th(t) = K_th · √t          [для адіабатичного інтервалу t < 1 мс]
```

#### Нелінійність теплопровідності кремнію при нагріванні

Важливо враховувати, що теплопровідність кремнію `k` сильно падає зі зростанням температури через посилення фононного розсіювання:

```
k(T) = k_0 · (300 / T)^1.3
```

Якщо при 25 °C (298 К) теплопровідність кремнію становить приблизно `148 Вт/(м·К)`, то при нагріванні до 175 °C (448 К) вона падає майже вдвічі — до `85 Вт/(м·К)`. Через це по мірі протікання лавинного процесу кристал починає гірше відводити тепло у власний об'єм, і реальне пікове нагрівання в гарячій зоні виявляється на 10–20% вищим, ніж дає лінійний розрахунок.

#### Інтеграл Дюамеля для спадної трикутної потужності

Для довільного змінного в часі профілю потужності `p(t)` температура переходу обчислюється через інтеграл Дюамеля з перехідною імпульсною тепловою характеристикою:

```
ΔT_j(t) = ∫[0..t] p(τ) · [ d Z_th(t - τ) / d(t - τ) ] dτ
```

Підставивши лінійно спадну потужність `p(τ) = P_peak · (1 - τ / t_av)` та адіабатичний імпеданс `Z_th(t) = K_th · √t`, отримаємо:

```
d Z_th(t - τ) / d(t - τ) = (K_th / 2) · (t - τ)^(-1/2)

ΔT_j(t) = (P_peak · K_th / 2) · ∫[0..t] (1 - τ / t_av) · (t - τ)^(-1/2) dτ
```

Використовуючи заміну змінної `u = t - τ`, маємо:

```
ΔT_j(t) = (P_peak · K_th / 2) · ∫[0..t] [ 1 - (t - u) / t_av ] · u^(-1/2) du

= (P_peak · K_th / 2) · [ (1 - t / t_av) · 2 · √t + (1 / t_av) · (2/3) · t^(3/2) ]

= P_peak · K_th · √t · [ 1 - (2/3) · (t / t_av) ]
```

Оскільки `Z_th(t) = K_th · √t`, динаміка температури описується функцією:

```
ΔT_j(t) = P_peak · Z_th(t) · [ 1 - (2/3) · (t / t_av) ]
```

Знайдемо момент часу `t_max`, коли температура переходу досягає абсолютного максимуму. Для цього прирівняємо похідну за часом до нуля:

```
d(ΔT_j) / dt = P_peak · K_th · [ (1 / (2·√t)) - (1 / t_av) · √t ] = 0

(1 / (2·√t_max)) = √t_max / t_av

t_max = (1/2) · t_av         [момент пікової температури кристала]
```

Підставивши `t_max = (1/2) · t_av` у вираз для температури, знайдемо точну величину максимального нагріву:

```
ΔT_j_max = P_peak · K_th · √(t_av / 2) · [ 1 - (2/3) · (1/2) ]

= P_peak · K_th · (√t_av / √2) · (2/3)

= (2 / (3 · √2)) · P_peak · Z_th(t_av)

≈ 0.4714 · P_peak · Z_th(t_av)
```

Це доводить, що максимальний стрибок температури при спадному трикутному імпульсі лавини становить приблизно `0.47 · P_peak · Z_th(t_av)`.

У практичній інженерії це значення з невеликим запасом надійності округлюють до стандартного коефіцієнта `1/2`:

```
ΔT_j_max ≈ (1/2) · P_peak · Z_th(t_av) = (1/2) · BV_DSS · I_AS · Z_th(t_av)
```

Кінцева пікова температура переходу в найгарячіший момент лавинного процесу:

```
T_j_peak = T_j_initial + (1/2) · BV_DSS · I_AS · Z_th(t_av)
```

Головна умова надійності: `T_j_peak` не повинна перевищувати абсолютну максимальну робочу температуру переходу `T_j(max)` (зазвичай 150 °C або 175 °C):

```
T_j_initial + (1/2) · BV_DSS · I_AS · Z_th(t_av) ≤ T_j(max)
```

### Теплове накопичення при повторюваних імпульсах (E_AR)

Якщо лавинний процес повторюється з періодом `T_sw = 1 / f_sw`, температура кристала не встигає повністю повернутися до початкового рівня між імпульсами.

У сталому режимі середня температура корпусу та переходу зростає на постійну величину середнього перегріву:

```
ΔT_avg = P_avg · R_thJA = (E_AS · f_sw) · R_thJA
```

де `R_thJA` — повний тепловий опір від переходу до навколишнього середовища.

На цю середню температуру в моменти комутації накладається швидка пікова пилкоподібна пульсація `ΔT_ripple`:

```
ΔT_ripple ≈ (1/2) · BV_DSS · I_AS · Z_thJC(t_av)
```

Максимальна миттєва температура переходу в серії імпульсів становить:

```
T_j_peak_repetitive = T_ambient + (E_AS · f_sw) · R_thJA + (1/2) · BV_DSS · I_AS · Z_thJC(t_av)
```

Звідси випливає фундаментальне обмеження на граничну частоту повторення лавинних комутацій `f_max`:

```
f_max ≤ [ T_j(max) - T_ambient - ΔT_ripple ] / [ E_AS · R_thJA ]
```

Якщо частота перемикань перевищує `f_max`, середній тепловий баланс порушується, температура безперервно зростає, і транзистор гине від теплового розгону за кілька сотень або тисяч циклів.

### Наскрізний числовий розрахунок реального випадку

Розглянемо практичний приклад розрахунку лавинної стійкості ключа для керування промисловим соленоїдом.

**Вихідні дані:**
- Напруга живлення схеми: `V_DD = 24 В`
- Індуктивність навантаження: `L = 20 мГн = 0.020 Гн`
- Струм увімкненого стану (піковий лавинний струм): `I_AS = 5 А`
- Параметри силового транзистора (наприклад, 60-вольтовий Trench MOSFET):
  - Номінальна напруга пробою: `BV_DSS = 60 В`
  - Фактична напруга лавини при струмі 5 А (з урахуванням динамічного опору): `V_BR = 68 В`
  - Початкова температура кристала (нагрітий у робочому режимі ключ): `T_j_initial = 85 °C`
  - Гранична температура: `T_j(max) = 175 °C`
  - Перехідний тепловий опір за графіком даташита для імпульсу відповідної тривалості: `Z_thJC = 0.42 °C/Вт`

**1. Розрахунок магнітної енергії котушки:**

```
E_L = (1/2) · L · I_AS²
= 0.5 · 0.020 · 5²           [підстановка числових значень]
= 0.5 · 0.020 · 25           [обчислення квадрата струму]
= 0.25 Дж = 250 мДж          [результат магнітної енергії]
```

**2. Розрахунок тривалості лавинного імпульсу t_av:**

```
t_av = (L · I_AS) / (V_BR - V_DD)
= (0.020 · 5) / (68 - 24)    [підстановка параметрів схеми]
= 0.100 / 44                 [різниця лавинної напруги та живлення]
≈ 0.002273 с = 2.273 мс      [тривалість лавинного розряду]
```

**3. Розрахунок повної лавинної енергії E_AS:**

```
E_AS = E_L · [ V_BR / (V_BR - V_DD) ]
= 0.250 · [ 68 / (68 - 24) ] [підстановка E_L та напруг]
= 0.250 · (68 / 44)          [обчислення множника живлення]
= 0.250 · 1.5455             [коефіцієнт додаткової енергії]
≈ 0.3864 Дж = 386.4 мДж      [повна розсіяна лавинна енергія]
```

Джерело живлення додало `E_source = 386.4 - 250 = 136.4 мДж` енергії під час розряду.

**4. Розрахунок пікової та еквівалентної потужності:**

```
P_peak = V_BR · I_AS = 68 · 5 = 340 Вт
P_eff = (1/2) · P_peak = 170 Вт
```

**5. Розрахунок стрибка температури кристала:**

```
ΔT_j = P_eff · Z_thJC(t_av)
= 170 · 0.42                 [добуток ефективної потужності на Z_th]
= 71.4 °C                    [стрибок температури переходу]
```

**6. Перевірка максимальної температури переходу:**

```
T_j_peak = T_j_initial + ΔT_j
= 85 + 71.4                  [додавання початкової температури]
= 156.4 °C                   [пікова температура переходу]
```

**Висновок розрахунку:**
Оскільки `T_j_peak = 156.4 °C < 175 °C`, транзистор гарантовано витримає одиночний лавинний імпульс без руйнування з запасом по температурі `175 - 156.4 = 18.6 °C`. Однак повторення таких імпульсів з високою частотою призведе до швидкого накопичення середнього тепла та теплового розгону.

### Порівняльний розрахунок для котушки з кінцевим активним опором R_L = 4 Ом

Розглянемо вплив реального опору мідного дроту обмотки соленоїда `R_L = 4.0 Ом` на той самий випадок комутації. За наявності активного опору частина енергії розсіюється безпосередньо в обмотці у вигляді тепла `i² · R_L`, полегшуючи навантаження на кристал транзистора.

**1. Уточнений розрахунок тривалості спаду струму t_av(R_L):**

```
t_av_R = (L / R_L) · ln[ 1 + (I_AS · R_L) / (V_BR - V_DD) ]
= (0.020 / 4.0) · ln[ 1 + (5.0 · 4.0) / (68 - 24) ] [підстановка параметрів]
= 0.005 · ln[ 1 + 20.0 / 44.0 ]                     [обчислення дробу]
= 0.005 · ln[ 1.4545 ]                              [аргумент логарифма]
= 0.005 · 0.3747                                    [значення натурального логарифма]
≈ 0.001874 с = 1.874 мс                             [уточнений час лавини]
```

Тривалість лавинного процесу скоротилася з `2.273 мс` до `1.874 мс` (на 17.5%), оскільки активний опір котушки створює додаткову проти-ЕРС `i · R_L`.

**2. Уточнена лавинна енергія в кристалі E_AS(R_L):**

```
E_AS_R = V_BR · ∫[0..t_av] i(t) dt
= (68 / 4.0) · [ 0.020 · 5.0 - (68 - 24) · 0.001874 ] [інтегрування за формулою розряду]
= 17.0 · [ 0.100 - 44.0 · 0.001874 ]                  [обчислення різниці]
= 17.0 · [ 0.100 - 0.08246 ]                          [множення на напругу]
= 17.0 · 0.01754                                      [множення на різницю потоків]
≈ 0.2982 Дж = 298.2 мДж                               [фактична енергія в кристалі]
```

Завдяки активному опору обмотки соленоїда розсіяна в транзисторі енергія знизилася з `386.4 мДж` до `298.2 мДж` (економія `88.2 мДж`, які розсіялися на мідному дроті).

**3. Уточнений стрибок температури переходу:**

```
ΔT_j_R = (1/2) · (V_BR · I_AS) · Z_thJC(t_av_R)
= 170 · 0.38                                        [значення Z_th для коротшого імпульсу]
= 64.6 °C                                           [знижений стрибок температури]
```

**4. Підсумкова пікова температура переходу:**

```
T_j_peak_R = 85 + 64.6                              [додавання початкової температури]
= 149.6 °C                                          [підсумкова температура кристала]
```

Врахування реального опору котушки збільшило температурний запас транзистора з `18.6 °C` до `25.4 °C`, що підтверджує важливість точного комплексного розрахунку кола.
