# ⚙️ Практична екстраполяція ресурсу TDDB за даними прискорених випробувань

Прискорені ресурсні випробування (Accelerated Lifetime Testing, ALT) підзатворного діелектрика є обов'язковою фазою кваліфікації кожного напівпровідникового техпроцесу на сучасних напівпровідникових фабриках. Оскільки інтегральна схема має гарантовано функціонувати понад 10 років за номінальної робочої напруги (наприклад, `V_op = 0.85 В`) та підвищеної температури (`105…125 °C`), пряме тестування в робочому режимі в лабораторії неможливе, адже тривало б десятиліттями. Інженери з надійності випробовують спеціальні тестові транзистори на кремнієвій пластині при підвищених напругах (`2.2…3.2 В`) та температурах (`125…200 °C`), вимірюють час до пробою `t_bd` для статистичної вибірки з десятків зразків, після чого екстраполюють ці дані на робочі умови за допомогою фізичних моделей прискорення та закону масштабування площі.

Нижче наведено повну реалізацію інженерного калькулятора екстраполяції ресурсу TDDB мовами Python, C та C++, детальний аналіз вимірювальних процедур на пластині, математичне обґрунтування алгоритмів обробки даних та розбір типових інженерних пасток.

---

## 1. Архітектура випробувань на пластині (Wafer-Level Reliability)

Під час розробки та випуску кремнієвих пластин тестові структури для контролю надійності підзатворного діелектрика розміщують на технологічних доріжках між кристалами (скрип-лініях, англ. *scribe lines*) або на виділених тестових чіпах.

Типова вимірювальна станція WLR (Wafer-Level Reliability) складається з термостолика (thermal chuck) з точністю підтримки температури до `±0.5 °C`, матричного зондового пристрою з голками з вольфраму або сплавів паладію та прецизійного вимірювача параметрів напівпровідників (Source Measure Unit, SMU), здатного вимірювати струми від десятків фемтоампер (`10⁻¹⁵ А`) до сотень міліампер.

```
                  АРХІТЕКТУРА СТРЕС-ТЕСТУВАННЯ WLR
┌────────────────────────────────────────────────────────────────────────┐
│  Кремнієва пластина на термостолику (T = 125…200 °C)                   │
│                                                                        │
│  ┌────────────────────────┐             ┌───────────────────────────┐  │
│  │ Тестовий транзистор A0 │◄──Голки────►│ Source Measure Unit (SMU) │  │
│  │   (A0 = 100 мкм²)      │  зондової   │ • Джерело напруги V_stress│  │
│  │   tox = 1.2…1.4 нм     │   головки   │ • Вимірювач струму pA…mA  │  │
│  └────────────────────────┘             └─────────────┬─────────────┘  │
│                                                       │                │
└───────────────────────────────────────────────────────┼────────────────┘
                                                        ▼
                                          ┌───────────────────────────┐
                                          │ ПК керування та збору     │
                                          │ • Фіксація часу t_bd      │
                                          │ • Побудова масивів даних  │
                                          └───────────────────────────┘
```

Процедура випробування включає такі обов'язкові кроки:
1. **Попередній контроль (Initial Screening):** за низької напруги (`0.1…0.3 В`) вимірюють початковий струм витоку. Зразки з наявними дефектами маски або металічними мікрочастинками (які мають високий витік одразу) вибраковуються з вибірки.
2. **Стрес постійною напругою (Constant Voltage Stress, CVS):** на затвор подається фіксована напруга `V_stress`. Струм затвора записується з високою частотою дискретизації.
3. **Детекція моменту пробою:** алгоритм реєструє час `t_bd`, коли струм затвора стрибкоподібно зростає на задану кількість порядків або перевищує фіксований поріг (наприклад, `10 мкА`).

## 3. Покроковий математичний розбір алгоритму екстраполяції

Процес розрахунку ресурсу діелектрика в коді розбито на кілька послідовних математичних етапів.

### Етап 1. Сортування вибірки та наближення Бернарда

Для побудови кумулятивної функції розподілу експериментальні значення часу пробою `t_bd` сортуються за зростанням. Для кожного `i`-го елемента з вибірки обсягом `N` кумулятивна частка відмов `F_i` обчислюється за модифікованою формулою Бернарда (Bernard's approximation):

```
F_i
= (i - 0.3) / (N + 0.4)                   [незміщена оцінка медіанних рангів]
```

Ця формула запобігає появі крайніх значень `F = 0` та `F = 1`, які призвели б до сингулярностей під час обчислення подвійного логарифма Вейбула `ln(-ln(1 - F))`. Порівняно з наївним наближенням `i / N` формула Бернарда дає незміщену оцінку медіани рангу для будь-якого симетричного або помірно асиметричного розподілу.

### Етап 2. Лінійна регресія за методом найменших квадратів

Кожна експериментальна точка перетворюється у координати лінеаризації Вейбула:
* `X_i = ln(t_i)`;
* `Y_i = ln(-ln(1 - F_i))`.

Пряма лінія `Y = a · X + b` підганяється методом найменших квадратів. Кутовий коефіцієнт `a` безпосередньо дає оцінку нахилу Вейбула `β`, а вільний член `b` визначає характеристичний час `η`:

```
η
= exp(-b / β)                             [визначення характеристичного часу за вільним членом]
```

Параметр `β` відображає дисперсію дефектів: чим він вищий, тим однорідніший діелектрик і тим менший розкид за часом пробою між різними транзисторами на пластині.

### Етап 3. Оцінка коефіцієнта напругового прискорення `n_v`

Для визначення чутливості діелектрика до напруги випробування повторюють за кількох рівнів напруги стресу (наприклад, `2.4 В`, `2.6 В`, `2.8 В`) при фіксованій температурі.

Отримані значення характеристичного часу `η(V)` апроксимуються степеневою моделлю. У подвійних логарифмічних координатах `ln(η)` від `ln(V)` експериментальні точки утворюють пряму лінію з нахилом `-n_v`:

```
ln(η)
= ln(C_0) - n_v · ln(V)                   [логарифмічна форма степеневої моделі напруги]
```

Для якісних сучасних діелектриків показник `n_v` становить `30…45`. Це означає, що зниження напруги всього на 10% збільшує час до пробою в `(1 / 0.9)³⁵ ≈ 40 разів`.

### Етап 4. Температурна деконволюція за законом Арреніуса

Температурна залежність швидкості деградації ізолятора моделюється експоненційним законом Арреніуса:

```
AF_T
= exp([E_a / k_B] · [1 / T_op - 1 / T_stress]) [температурний коефіцієнт прискорення]
```

де `E_a` — ефективна енергія активації процесу руйнування діелектрика (для оксинітридів кремнію `E_a ≈ 0.65…0.75 еВ`, для діелектриків High-k на основі `HfO₂` `E_a ≈ 0.8…0.95 еВ`), `k_B = 8.617 · 10⁻⁵ еВ/К` — постійна Больцмана, а температури подано в Кельвінах.

Добуток напругового та температурного прискорення формує повний коефіцієнт екстраполяції:

```
AF_total
= AF_V · AF_T                             [повний коефіцієнт прискорення стрес-тесту]
```

### Етап 5. Масштабування за площею та розрахунок надійності чіпа

Закон «найслабшої ланки» зміщує характеристичний час цілого кристала вліво пропорційно відношенню площ у степені `1 / β`:

```
η_chip
= η_test · (A_test / A_chip)^(1 / β)      [зсув часу пропорційно площі та нахилу бета]
```

Знаючи характеристичний час кристала `η_chip` при робочій напрузі та температурі, розраховують інтенсивність відмов у одиницях FIT (`1 FIT = 1 відмова на 10⁹ приладо-годин`):

```
FIT(t)
= [dF(t)/dt] · 10⁹                        [миттєва інтенсивність відмов]
= (β / η_chip) · (t / η_chip)^(β - 1) · 10⁹ [аналітична інтенсивність відмов Вейбула]
```

## 4. Інженерні пастки та аналіз крайових випадків

Під час проведення випробувань та програмного аналізу даних TDDB інженери стикаються з низкою підступних ефектів, неправильне врахування яких веде до помилкових висновків щодо надійності продукту.

### 1. Бімодальний розподіл Вейбула (Bimodal Distribution)

Якщо на графіку Вейбула експериментальні точки утворюють не одну пряму лінію, а ламану криву з двома різними нахилами (злам кривої), це свідчить про співіснування двох різних фізичних механізмів відмови:
* **Зовнішні дефекти (Extrinsic Defects / Infant Mortality):** рання популяція відмов із малим нахилом `β_ext ≈ 0.3…0.6`. Їх причиною є сторонні частинки пилу, дефекти фотолітографії або локальні потоншення оксиду.
* **Власна деградація (Intrinsic Breakdown):** пізня популяція з високим нахилом `β_int ≈ 1.2…1.8`, що відповідає рівномірній перколяції в якісному матеріалі.

Змішування цих двох популяцій в один масив призводить до спотворення оцінки нахилу `β` та фатальної помилки при екстраполяції. Програмний алгоритм повинен попередньо розділяти бімодальні вибірки за допомогою алгоритмів кластеризації або EM-алгоритму (Expectation-Maximization).

```
                  БІМОДАЛЬНИЙ ГРАФІК ВЕЙБУЛА
      W = ln(-ln(1-F))
             ▲
             │                       / Intrinsic (власний пробій, β ≈ 1.4)
             │                      /
             │                     /
             │                    /
      ───────┼───────────/───────/──────────────────── W = 0 (63.2%)
             │          /       /
             │         /  ◄────/──── Точка зламу популяцій
             │        /
             │  ────/ Extrinsic (ранні дефекти виробництва, β ≈ 0.4)
             │
             └────────────────────────────────────────► ln(t)
```

### 2. Зсув оцінки нахилу на малих вибірках (Small Sample Bias)

Якщо вибірка містить менше ніж 20 зразків (`N < 20`), лінійна регресія методом найменших квадратів систематично завищує оцінку параметра `β` на `10…25%`. Завищений нахил створює ілюзію високої надійності в області низьких рівнів браку (наприклад, для квантиля `0.01% = 100 ppm`).

Для усунення цього зміщення в інженерній практиці використовують поправочний коефіцієнт незміщеності або переходять до оцінки методом максимальної правдоподібності (MLE) з корекцією Тіку–Сміта.

### 3. Вплив послідовного опору виводів (Series Resistance Masking)

Під час тестування транзисторів великої площі або за дуже високих струмів стресу падіння напруги на паразитному опорі металевих доріжок, контактних вікон та підкладки `R_series` зменшує реальну напругу, прикладену безпосередньо до діелектрика:

```
V_ox_real
= V_applied - I_gate · R_series           [зменшення напруги на оксиді через спад на контактах]
```

Це явище штучно затягує час до пробою, маскуючи справжню швидкість деградації оксиду. Для запобігання цій помилці застосовують чотирипровідну схему підключення Кельвіна (Kelvin 4-wire sensing), що вимірює потенціал безпосередньо біля затвора транзистора.

### 4. Динамічний AC-стрес проти постійного DC-стресу

У реальних цифрових схемах більшість транзисторів перемикається між станами логічного нуля та одиниці з робочою частотою від сотень мегагерц до гігагерц. Час перебування під високою напругою визначається коефіцієнтом активності (duty cycle `α = t_high / t_period`).

Під час фази низької напруги (`V_GS = 0 В`) відбувається часткова релаксація накопиченого заряду та зворотна пасивація нестабільних дефектів воднем. Завдяки цьому динамічний ресурс діелектрика в режимі AC виявляється у `3…10 разів` вищим, ніж при постійному стресі DC. Проведення кваліфікації за даними постійного стресу DC закладає надійний інженерний запас міцності в проект мікросхеми.

## 5. Методологія планування матриці випробувань за стандартом JEDEC JESD92

Для забезпечення високої статистичної достовірності міжнародний стандарт JEDEC JESD92 визначає суворі вимоги до планування матриці прискорених випробувань (Test Matrix Planning):

1. **Сітка напруг і температур:** випробування проводять щонайменше за трьох різних температур (наприклад, `125 °C`, `150 °C`, `175 °C`). Для кожної температури обирають не менше трьох рівнів напруги стресу (наприклад, `2.4 В`, `2.6 В`, `2.8 В`).
2. **Розмір вибірки на точку:** кожна комбінація `(V_stress, T_stress)` тестується на вибірці з щонайменше `25…50` окремих приладів, розташованих на різних ділянках пластини (у центрі, на середньому радіусі та біля краю) для урахування радіальної нерівномірності товщини оксиду.
3. **Критерій достовірності регресії:** коефіцієнт детермінації `R²` для лінійної регресії Вейбула на кожній точці стресу повинен перевищувати `0.95`. Якщо `R² < 0.95`, це вказує на наявність паразитних шумів, бімодальності або дрейфу температури, і такі дані бракуються.

## 6. Розділення об'ємних та крайових відмов за допомогою геометрії затвора

У реальному транзисторі дефекти можуть утворюватися як у площині діелектрика (Area-intensive breakdown), так і на його периметрі — вздовж меж джерела та стоку або країв польової ізоляції STI (Perimeter-intensive breakdown).

Для розділення цих внесків на пластині виготовляють два типи спеціальних тестових конденсаторів:
* **Площинні структури (Area Capacitors):** великі квадратні затвори з мінімальним відношенням периметра до площі `P / A ≈ 0.04 мкм⁻¹`.
* **Периметральні гребінчасті структури (Comb / Finger Capacitors):** затвори з десятками вузьких смуг, що мають однаковий сумарний об'єм діелектрика, але колосальний периметр `P / A ≈ 4.0 мкм⁻¹`.

Аналіз різниці характеристичних часів `η_area` та `η_comb` дозволяє математично розділити площинну та периметральну густину дефектів:

```
1 / η_total
= (A_gate / A_0) · (1 / η_area) + (P_gate / P_0) · (1 / η_perim) [розділення внесків площі та периметра]
```

Це дозволяє точно прогнозувати відмови як для широких силових транзисторів, так і для вузьких вентилів цифрової логіки.

## 7. Алгоритм розділення бімодальних вибірок методом EM

Коли експериментальна вибірка містить як ранні дефекти виробництва (extrinsic), так і власні відмови (intrinsic), кумулятивна функція описується сумішшю двох розподілів Вейбула з ваговим коефіцієнтом `p`:

```
F_mix(t)
= p · [1 - exp(- (t / η_1)^β_1)] + (1 - p) · [1 - exp(- (t / η_2)^β_2)] [суміш двох розподілів Вейбула]
```

Для розділення популяцій застосовують алгоритм очікування–максимізації (Expectation-Maximization, EM):

1. **E-крок (Очікування):** для кожного виміряного часу `t_i` обчислюється апостеріорна ймовірність `γ_i` його належності до першої субпопуляції:

```
γ_i
= [p · f_1(t_i)] / [p · f_1(t_i) + (1 - p) · f_2(t_i)] [апостеріорна ймовірність належності до групи 1]
```

2. **M-крок (Максимізація):** оновлюються параметри розподілів:
* Вага першої групи: `p = (1 / N) · ∑ γ_i`;
* Параметри `(β_1, η_1)` та `(β_2, η_2)` перераховуються зваженим методом максимальної правдоподібності, де кожне спостереження `t_i` має вагу `γ_i` для першої групи та `(1 - γ_i)` для другої групи.

Ітерації повторюють до збіжності з відносною похибкою менше ніж `10⁻⁵`. Отримана популяція з більшим нахилом `β_2 > 1.0` використовується для екстраполяції власного ресурсу технології.

## 8. Фільтрація шумів вимірювального тракту та вибір NPLC

Під час проведення тривалих CVS випробувань аналогово-цифровий перетворювач SMU піддається впливу мерехтливих наведень мережі живлення (`50/60 Гц`) та теплового шуму кабелів.

1. **Параметр NPLC (Number of Power Line Cycles):** інтегратор струму SMU повинен налаштовуватися на значення `NPLC = 1` або `NPLC = 2` (час інтегрування `20…40 мс`). Це забезпечує подавлення мережевої перешкоди понад `60 дБ`. Менші значення (`NPLC = 0.01`) дозволяють фіксувати надшвидкі наносекундні перехідні процеси, але створюють хибні спрацьовування порогу пробою через високочастотний шум.
2. **Фільтр відкидання аномалій (Glitch Filter):** короткочасний сплеск струму тривалістю в один відлік, після якого струм повертається до фонового значення SILC, класифікується як заряджання/розряджання пастки або зовнішня електромагнітна завада. Пробій `t_bd` фіксується лише тоді, коли підвищений рівень струму зберігається щонайменше 3 послідовні відліки.

## 9. Розрахунок ресурсу для автомобільних профілів навантаження (AEC-Q100 Mission Profiles)

Автомобільні мікросхеми (стандарт AEC-Q100 Grade 0 / Grade 1) протягом терміну експлуатації працюють за складного комбінованого температурного профілю, наприклад:
* `1000 годин` при екстремальній температурі під капотом `150 °C`;
* `5000 годин` за температури `125 °C`;
* `20000 годин` за помірної температури `85 °C`;
* `50000 годин` у режимі сну при `40 °C`.

Для розрахунку сумарного пошкодження діелектрика застосовують лінійне правило накопичення пошкоджень Пальмгрена–Майнера (Miner's Rule). Відносне пошкодження на кожному `k`-му температурному інтервалі:

```
D_k
= t_work,k / t_fail,k                     [частка вичерпаного ресурсу на k-му інтервалі]
```

де `t_fail,k` — розрахунковий час до пробою за температури `T_k`.

Сумарне кумулятивне пошкодження:

```
D_total
= ∑ D_k                                   [сума часток вичерпаного ресурсу]
```

Критерієм гарантованої надійності мікросхеми для всього профілю експлуатації є умова `D_total ≤ 0.1` (коефіцієнт надійнісного запасу не менше 10×).

## 10. Оцінка залишкового ресурсу діелектрика в реальному часі

Для систем із підвищеними вимогами до функціональної безпеки (сервери, авіоніка, медичне обладнання) критично знати не лише початковий ресурс, але й залишковий час безпечної експлуатації (Remaining Useful Life, RUL) чіпа після `t_used` годин роботи.

З умовної функції надійності Вейбула ймовірність безвідмовної роботи протягом додаткового часу `Δt` за умови, що прилад уже пропрацював час `t_used`, визначається виразом:

```
R(Δt | t_used)
= R(t_used + Δt) / R(t_used)              [теорема про умовну ймовірність надійності]
= exp(- [ (t_used + Δt)^β - t_used^β ] / η_chip^β) [умовна надійність Вейбула]
```

Оскільки для діелектрика параметр форми `β > 1`, інтенсивність відмов є монотонно зростаючою функцією часу (старіння системи). Залишковий час життя до досягнення допустимого рівня ризику `F_add` стрімко скорочується з віком чіпа:

```
Δt_safe
≈ η_chip · (F_add / β)^(1 / β) · (t_used / η_chip)^(1 - β) [наближення залишкового часу]
```

## 11. Спектральний аналіз низькочастотного шуму 1/f як передвісник пробою

Перед настанням м'якого пробою підзатворний діелектрик зазнає різкої зміни спектральної густини потужності низькочастотного шуму (флікер-шуму, або шуму `1/f`).

Спектральна густина струму витоку `S_I(f)` описується емпіричною моделлю Хоуге:

```
S_I(f)
= (α_H · I_gate²) / (N_carriers · f^γ)     [спектральна густина потужності шуму 1/f]
```

де `α_H` — параметр Хоуге, прямо пропорційний концентрації нейтральних пасток у діелектрику, а показник частоти `γ ≈ 1.0…1.2`.

У міру наближення моменту перколяції спостерігаються дві ключові аномалії:
1. **Зростання амплітуди шуму:** параметр `α_H` зростає на 2–3 порядки за кілька годин або хвилин до замикання перколяційного кластера.
2. **Трансформація спектра у лоренціани:** неперервний спектр `1/f` розпадається на дискретні піки лоренцівської форми `S(f) ∝ 1 / (1 + (2π f τ)²)` через активізацію поодиноких домінуючих пасток (перехід до режиму RTN шуму).

Фіксація цих змін дозволяє предиктивно прогнозувати відмову критичних мікроелектронних компонентів до появи незворотного короткого замикання.

## 12. Корекція на ефект самонагріву (Self-Heating Correction) у FinFET та GAA

У тривимірних транзисторах FinFET та нанолистах GAA кремнієві канали оточені діелектриком з низькою теплопровідністю, що ускладнює відведення джоулевого тепла до масивної підкладки.

Під час випробувань за підвищеної напруги стресу густина струму витоку викликає локальний самонагрів каналу (Self-Heating Effect, SHE), через що реальна температура діелектрика `T_real` перевищує встановлену температуру термостолика `T_chuck`:

```
T_real
= T_chuck + R_th · I_gate · V_stress      [підвищення локальної температури через самонагрів]
```

де `R_th` — локальний тепловий опір структури (`R_th ≈ 10⁴…10⁵ К/Вт` для суб-7-нм нанолистів).

Якщо не врахувати доданок `ΔT = R_th · I_gate · V_stress`, підвищена температура буде помилково приписана дії надлишкової напруги, що спотворить оцінку показника `n_v` на `15…30%`. Програмний калькулятор вводить ітераційну поправку температури за формулою Арреніуса на кожному кроці регресії, гарантуючи ізотермічність екстраполяційних оцінок. Для прецизійного проектування мікросхем топологічні САПР об'єднують термодинамічний 3D-аналіз теплових полів чіпа з картами напруженості електричного поля, виконуючи спільне електротермічне моделювання деградації TDDB у кожному критичному логічному тракті.
