# 🧮 Математика розподілу Вейбула для TDDB та перколяційна статистика

Статистична природа часо-залежного пробою діелектрика (TDDB) вимагає математичного апарату, здатного описати поведінку системи з мільярдів атомних комірок, у якій руйнування хоча б одного мікроскопічного ланцюжка призводить до катастрофічної відмови всього виробу. Цей математичний опис базується на теорії екстремальних значень (Extreme Value Theory), статистиці розподілу Вейбула та геометрії тривимірної перколяції у дискретній ґратці.

Нижче наведено строгий математичний вивід розподілу Вейбула з моделі «найслабшої ланки», виведення зв'язку між параметром форми `β` і товщиною діелектрика, аналітичний закон масштабування за площею, алгоритм оцінки параметрів методом максимальної правдоподібності та покрокові числові приклади розрахунку надійності інтегральних мікросхем.

---

## 1. Теорія екстремальних значень та статистика «найслабшої ланки»

Чому час до пробою діелектрика описується саме розподілом Вейбула, а не класичним нормальним (гаусовим) чи логнормальним розподілом?

Згідно з граничною теоремою Фішера–Тіппетта–Гнєденка для екстремальних значень, якщо випадкова величина визначається як мінімум із великої кількості `N` незалежних однаково розподілених випадкових величин (час виходу з ладу найслабшого мікроелемента серед мільйонів паралельних ділянок діелектрика), то граничний розподіл цієї величини при `N → ∞` може належати лише до одного з трьох типів: Гумбеля, Фреше або Вейбула. Оскільки час до пробою фізично обмежений знизу нулем (`t ≥ 0`), єдиним математично можливим граничним розподілом є мінімальний розподіл Вейбула.

Розглянемо конденсатор затвора площею `A` та товщиною `t_ox`. Розіб'ємо весь об'єм діелектрика `V = A · t_ox` на `M` незалежних елементарних комірок об'ємом `v_0 = a_0³`, де `a_0` — характерний лінійний розмір дефекту (кисневої вакансії), який становить приблизно `0.3…0.5 нм`.

Загальна кількість таких елементарних комірок у діелектрику:

```
M
= V / v_0                                 [загальний об'єм поділений на об'єм комірки]
= (A · t_ox) / a_0³                       [геометричний вираз через площу та товщину]
```

Припустимо, що утворення дефектів у кожній комірці є випадковим пуассонівським процесом, незалежним від інших комірок. Нехай `P_cell(t)` — імовірність того, що в окремому вертикальному стовпчику комірок до моменту часу `t` сформувався неперервний провідний ланцюжок дефектів.

Імовірність того, що даний стовпчик не пробився (його функція надійності `R_cell(t)`):

```
R_cell(t)
= 1 - P_cell(t)                           [імовірність протилежної події]
```

Оскільки затвор транзистора функціонує як єдина система за правилом «найслабшої ланки» (пробій хоча б одного з `M_col = A / a_0²` паралельних стовпчиків означає пробій усього затвора), загальна ймовірність виживання діелектрика `R(t)` дорівнює добутку ймовірностей виживання всіх незалежних стовпчиків:

```
R(t)
= [R_cell(t)]^(M_col)                     [добуток незалежних імовірностей]
= [1 - P_cell(t)]^(A / a_0²)              [підстановка кількості паралельних стовпчиків]
```

Оскільки ймовірність пробою окремого стовпчика `P_cell(t)` для надійного діелектрика є надзвичайно малою величиною (`P_cell << 1`), скористаємося відомим асимптотичним розкладом у степеневий ряд Тейлора `ln(1 - x) = -x - x²/2 - ... ≈ -x`:

```
ln(R(t))
= ln([1 - P_cell(t)]^(A / a_0²))          [логарифмування виразу надійності]
= (A / a_0²) · ln(1 - P_cell(t))          [винесення степеня за знак логарифма]
= - (A / a_0²) · P_cell(t)                [лінійне наближення ln(1 - x) при x << 1]
```

Потенціюючи отриманий вираз, маємо експоненційну форму функції надійності:

```
R(t)
= exp(- (A / a_0²) · P_cell(t))           [потенціювання обох частин]
```

Кумулятивна функція частки відмов `F(t) = 1 - R(t)` набуває вигляду:

```
F(t)
= 1 - exp(- (A / a_0²) · P_cell(t))       [визначення кумулятивної ймовірності відмови]
```

## 2. Степенева кінетика накопичення дефектів та нахил Вейбула

Щоб знайти явну часову залежність `P_cell(t)`, проаналізуємо процес формування провідного шляху у вертикальному стовпчику з `n` послідовно розташованих комірок, де:

```
n
= t_ox / a_0                              [кількість елементарних комірок по товщині]
```

Нехай `p(t)` — імовірність того, що окрема комірка містить дефект (пастку) у момент часу `t`. За пуассонівського розподілу надходження електронів генерація дефектів під дією тунельного струму описується диференціальним рівнянням першого порядку:

```
dp/dt
= g_gen · (1 - p)                         [швидкість генерації дефектів на вільних вузлах]
```

де `g_gen` — питома швидкість генерації пасток, яка експоненційно залежить від напруженості електричного поля `E_ox` та температури `T`. Для малих часів стресу (`p << 1`) розв'язок має лінійний вигляд:

```
p(t)
= 1 - exp(-g_gen · t)                     [точний розв'язок диференціального рівняння]
≈ g_gen · t                               [наближення при малих часах стресу g_gen · t << 1]
```

Для утворення провідного перколяційного містка у стовпчику товщиною `n` комірок необхідно, щоб усі `n` комірок цього стовпчика одночасно містили пастки:

```
P_cell(t)
= [p(t)]^n                                [одночасна поява дефектів у n комірках стовпчика]
= (g_gen · t)^n                           [підстановка лінійної за часом імовірності]
= (g_gen)^n · t^n                         [розкриття дужок]
```

Підставимо отриманий вираз для `P_cell(t)` у формулу кумулятивної ймовірності відмови `F(t)`:

```
F(t)
= 1 - exp(- (A / a_0²) · (g_gen)^n · t^n) [підстановка P_cell у функцію відмов]
= 1 - exp(- (t / η)^n)                    [зведення до канонічної форми Вейбула]
```

де масштабний параметр часу `η` (характеристичний час до пробою, за якого виходить з ладу `63.2%` приладів) визначається виразом:

```
η
= (a_0² / A)^(1 / n) · (1 / g_gen)        [характеристичний час до пробою 63.2% зразків]
```

Порівнюючи отримане рівняння з класичним двопараметричним розподілом Вейбула:

```
F(t)
= 1 - exp(- (t / η)^β)                    [канонічний розподіл Вейбула]
```

отримуємо фундаментальний висновок перколяційної теорії: **параметр форми (нахил Вейбула) `β` прямо пропорційний товщині діелектрика**:

```
β
= n                                       [теоретична рівність нахилу кількості комірок]
= t_ox / a_0                              [зв'язок нахилу з товщиною діелектрика]
```

### Фізичні наслідки зменшення товщини

Параметр `β` визначає дисперсію часу відмови:
* У товстих діелектриках (`t_ox = 10 нм`, `a_0 = 0.5 нм`) параметр `β` сягає `15…20`. Розподіл відмов у часі є надзвичайно гострим: майже всі прилади виходять з ладу одночасно у вузькому часовому вікні біля `t ≈ η`.
* У сучасних надтонких діелектриках (`t_ox = 1.2…1.5 нм`) параметр `β` деградує до значень `β ≈ 1.1…1.4`. При малому `β` статистичний розкид стає колосальним: перші `0.01%` приладів (100 ppm) виходять з ладу на 4–6 порядків раніше, ніж середній час життя вибірки `η`.

## 3. Лінеаризація розподілу на графіку Вейбула

Для практичної обробки експериментальних даних випробувань надійність представляють у спеціальних подвійних логарифмічних координатах (координатах Вейбула), де нелінійна крива перетворюється на пряму лінію.

Візьмемо подвійний натуральний логарифм від виразу `1 / (1 - F(t))`:

```
1 - F(t)
= exp(- (t / η)^β)                        [функція виживання]
```

```
1 / (1 - F(t))
= exp((t / η)^β)                          [обернена величина]
```

```
ln(1 / (1 - F(t)))
= -ln(1 - F(t))                           [властивість логарифма оберненого дробу]
= (t / η)^β                               [перше логарифмування]
```

```
ln(-ln(1 - F(t)))
= ln((t / η)^β)                           [друге логарифмування]
= β · ln(t / η)                           [винесення показника степеня]
= β · ln(t) - β · ln(η)                   [розкриття логарифма частки]
```

Введемо змінну Вейбула `W`:

```
W
= ln(-ln(1 - F))                          [ордината графіка Вейбула]
```

Рівняння `W = β · ln(t) - β · ln(η)` є рівнянням прямої лінії `Y = a · X + b` у координатах `(ln(t), W)`:
* Нахил прямої лінії `a` точно дорівнює параметру форми `β`.
* Точка перетину прямої з нульовим рівнем `W = 0` (що відповідає `F = 1 - e⁻¹ ≈ 63.212%`) визначає характеристичний час `X_0 = ln(η)`, звідки `η = exp(X_0)`.

## 4. Математичний закон масштабування за площею

Розглянемо дві структури з однаковою товщиною та якістю діелектрика, але різними площами:
1. Одиночний тестовий транзистор із малою площею `A_1` (функція відмов `F_1(t)`, характеристичний час `η_1`).
2. Повний кристал мікропроцесора з великою сумарною площею затворів `A_2` (функція відмов `F_2(t)`, характеристичний час `η_2`).

Використовуючи закон добутку функцій надійності для незалежних ділянок:

```
R_2(t)
= [R_1(t)]^(A_2 / A_1)                    [масштабування надійності за відношенням площ]
```

Прологарифмуємо обидві частини рівності двічі:

```
ln(R_2(t))
= (A_2 / A_1) · ln(R_1(t))                [перше логарифмування]
```

```
-ln(R_2(t))
= (A_2 / A_1) · [-ln(R_1(t))]             [множення на мінус одиницю]
```

```
ln(-ln(1 - F_2(t)))
= ln(A_2 / A_1) + ln(-ln(1 - F_1(t)))     [друге логарифмування]
```

Підставимо вираз для лінеаризованої форми Вейбула `ln(-ln(1 - F(t))) = β · ln(t / η)`:

```
β · ln(t / η_2)
= β · ln(t / η_1) + ln(A_2 / A_1)         [підстановка форми Вейбула в рівняння площ]
```

Розділимо обидві частини рівності на `β`:

```
ln(t) - ln(η_2)
= ln(t) - ln(η_1) + (1 / β) · ln(A_2 / A_1) [ділення на коефіцієнт нахилу beta]
```

Скорочуючи `ln(t)` з обох боків, отримуємо аналітичну залежність для зсуву характеристичного часу життя:

```
ln(η_1) - ln(η_2)
= (1 / β) · ln(A_2 / A_1)                 [логарифмічний зсув часу через відношення площ]
```

```
ln(η_2 / η_1)
= - (1 / β) · ln(A_2 / A_1)               [зміна знака логарифма]
= ln([A_1 / A_2]^(1 / β))                 [внесення множника в показник степеня]
```

Потенціюючи, маємо фундаментальний закон масштабування площі TDDB:

```
η_2
= η_1 · (A_1 / A_2)^(1 / β)               [закон масштабування характеристичного часу]
```

Аналогічно, для будь-якого фіксованого кумулятивного рівня дефектності `F` (наприклад, `F = 0.01% = 100 ppm`), час до відмови `t_F` масштабується точно за таким же законом:

```
t_F(A_2)
= t_F(A_1) · (A_1 / A_2)^(1 / β)          [масштабування часу досягнення заданого рівня браку]
```

## 5. Оцінка параметрів методом максимальної правдоподібності (MLE)

Метод найменших квадратів на графіку Вейбула є наочним, але дає статистичне зміщення для малих вибірок (`N < 30`). У промислових системах аналізу надійності параметри `β` та `η` знаходять **методом максимальної правдоподібності** (Maximum Likelihood Estimation, MLE).

Густина ймовірності розподілу Вейбула `f(t)`:

```
f(t)
= dF(t)/dt                                [визначення густини ймовірності]
= (β / η) · (t / η)^(β - 1) · exp(- (t / η)^β) [диференціювання функції Вейбула]
```

Для вибірки з `N` незалежно виміряних часів до пробою `t_1, t_2, ..., t_N` функція правдоподібності `L(β, η)` дорівнює добутку густин:

```
L(β, η)
= ∏ f(t_i; β, η)                          [добуток густин імовірностей усіх вимірів]
```

Логарифмічна функція правдоподібності `ln L`:

```
ln L(β, η)
= N · ln(β) - N · β · ln(η) + (β - 1) · ∑ ln(t_i) - ∑ (t_i / η)^β [логарифмування добутку]
```

Диференціюючи `ln L` за `η` та прирівнюючи похідну до нуля:

```
∂(ln L)/∂η
= - N · β / η + (β / η^(β + 1)) · ∑ t_i^β = 0 [умова екстремуму за ета]
```

Звідси отримуємо аналітичний вираз для оцінки `η` через відоме значення `β`:

```
η
= [ (1 / N) · ∑ t_i^β ]^(1 / β)           [оцінка максимальної правдоподібності для ета]
```

Диференціюючи `ln L` за `β` та підставляючи вираз для `η`, отримуємо нелінійне рівняння для знаходження `β`:

```
1 / β + (1 / N) · ∑ ln(t_i) - (∑ [t_i^β · ln(t_i)]) / (∑ t_i^β)
= 0                                       [одновимірне рівняння для нахилу Вейбула]
```

Це одновимірне рівняння розв'язується чисельно ітераційним методом Ньютона–Рафсона за 4–5 кроків, забезпечуючи точну та незміщену оцінку параметрів надійності.

## 6. Покроковий числовий приклад: одиночний транзистор проти процесора

### Вихідні дані експерименту

Під час прискорених випробувань партії з 50 тестових польових транзисторів за постійної напруги `V_stress = 2.6 В` та температури `T_stress = 125 °C` отримано такі параметри:
* Площа затвора тестового транзистора: `A_0 = 10⁻⁶ см²` (`100 мкм²`).
* Товщина підзатворного діелектрика: `t_ox = 1.4 нм`.
* Оцінений нахил Вейбула: `β = 1.30`.
* Характеристичний час до пробою: `η_0 = 2400 с` (при `F = 63.2%`).

Параметри реального мікроконтролера:
* Загальна площа тонкого підзатворного діелектрика на кристалі: `A_chip = 0.05 см²` (`5 мм²`).
* Робоча напруга ядра: `V_op = 0.85 В`.
* Робоча температура: `T_op = 85 °C`.
* Показник напругового прискорення (Power-Law model): `n_v = 36`.
* Енергія активації (Arrhenius): `E_a = 0.75 еВ`.
* Постійна Больцмана: `k_B = 8.617 · 10⁻⁵ еВ / К`.

---

### Крок 1. Розрахунок коефіцієнта прискорення за напругою `AF_V`

Застосуємо степеневу модель напруги:

```
AF_V
= (V_stress / V_op)^(n_v)                 [степеневий закон прискорення напругою]
= (2.6 / 0.85)^36                         [підстановка значень напруг і показника степеня]
= (3.0588)^36                             [обчислення відношення напруг]
≈ 1.488 · 10¹⁷                            [коефіцієнт прискорення напругою]
```

---

### Крок 2. Розрахунок коефіцієнта температурного прискорення `AF_T`

Переведемо температури в абсолютну шкалу Кельвіна:
* `T_stress = 125 + 273.15 = 398.15 K`.
* `T_op = 85 + 273.15 = 358.15 K`.

Застосуємо закон Арреніуса:

```
1 / T_op - 1 / T_stress
= 1 / 358.15 - 1 / 398.15                 [різниця обернених температур]
= 0.0027921 - 0.0025116                   [обчислення обернених значень]
= 0.0002805 K⁻¹                           [значення різниці]
```

```
(E_a / k_B) · (1 / T_op - 1 / T_stress)
= (0.75 / (8.617 · 10⁻⁵)) · 0.0002805     [підстановка енергії активації та сталої Больцмана]
= 8703.7 · 0.0002805                      [ділення енергії активації на k_B]
= 2.4414                                  [безрозмірний показник експоненти]
```

```
AF_T
= exp(2.4414)                             [обчислення експоненти]
≈ 11.49                                   [температурний коефіцієнт прискорення]
```

Загальний коефіцієнт прискорення стрес-тесту:

```
AF_total
= AF_V · AF_T                             [добуток коефіцієнтів прискорення]
= (1.488 · 10¹⁷) · 11.49                  [перемноження складових]
≈ 1.710 · 10¹⁸                            [сумарне прискорення від випробувань до роботи]
```

---

### Крок 3. Розрахунок характеристичного часу `η_chip` з урахуванням площі

Екстраполюємо характеристичний час тестового транзистора на робочі умови:

```
η_0(op)
= η_0 · AF_total                          [масштабування характеристичного часу за стресом]
= 2400 с · (1.710 · 10¹⁸)                 [підстановка даних]
≈ 4.104 · 10²¹ с                          [характеристичний час тестового транзистора при 0.85 В]
```

Тепер врахуємо масштаб площі кристала `A_chip / A_0`:

```
A_chip / A_0
= 0.05 см² / 10⁻⁶ см²                     [відношення площі кристала до тестової структури]
= 50 000                                  [кристал має у 50 000 разів більшу площу діелектрика]
```

Коефіцієнт зменшення часу через масштабування площі:

```
(A_0 / A_chip)^(1 / β)
= (1 / 50000)^(1 / 1.30)                  [піднесення до степеня 1/beta]
= (2 · 10⁻⁵)^0.7692                       [обчислення степеня]
≈ 2.476 · 10⁻⁴                            [масштабний коефіцієнт площі]
```

Характеристичний час для цілого кристала `η_chip`:

```
η_chip
= η_0(op) · (A_0 / A_chip)^(1 / β)        [застосування закону масштабування площі]
= (4.104 · 10²¹ с) · (2.476 · 10⁻⁴)       [перемноження величин]
≈ 1.016 · 10¹⁸ с                          [характеристичний час чіпа при 63.2% відмов]
```

### Крок 4. Розрахунок часу до накопичення браку 100 ppm (`F = 0.01%`)

Цільовий рівень відмов для автомобільних та серверних мікросхем становить `F = 100 ppm = 0.0001` (`0.01%`).

Знайдемо співвідношення між часом до `100 ppm` і характеристичним часом `η_chip`:

```
ln(-ln(1 - F))
= ln(-ln(1 - 0.0001))                     [підстановка F = 0.0001]
≈ ln(0.000100005)                         [наближення -ln(1 - F) ≈ F]
≈ -9.2103                                 [значення змінної Вейбула для 100 ppm]
```

```
t_100ppm
= η_chip · [-ln(1 - F)]^(1 / β)           [вираз для квантиля часу Вейбула]
= η_chip · (0.000100005)^(1 / 1.30)       [підстановка значень]
= η_chip · (0.000100005)^0.7692           [обчислення показника степеня]
= η_chip · (8.324 · 10⁻⁴)                 [відношення часу 100 ppm до характеристичного часу]
```

Підставимо значення `η_chip`:

```
t_100ppm
= (1.016 · 10¹⁸ с) · (8.324 · 10⁻⁴)       [розрахунок абсолютного часу]
≈ 8.457 · 10¹⁴ с                          [час у секундах]
```

Переведемо отриманий результат у роки (в одному році `31 536 000 с ≈ 3.1536 · 10⁷ с`):

```
t_100ppm (роки)
= (8.457 · 10¹⁴ с) / (3.1536 · 10⁷ с/рік) [переведення секунд у роки]
≈ 2.68 · 10⁷ років                        [фінальний розрахунковий ресурс]
```

## 7. Числовий приклад: гетерогенна надійність багатодоменної системи на кристалі

Сучасна система-на-кристалі (SoC) містить два принципово різні типи транзисторів:
1. **Ядро процесора (Core Domain):** надтонкий оксид `t_ox1 = 1.2 нм`, площа `A_core = 0.08 см²`, робоча напруга `V_core = 0.75 В`, нахил Вейбула `β_core = 1.20`.
2. **Периферія вводу–виводу (I/O Domain):** товстий оксид `t_ox2 = 3.5 нм`, площа `A_io = 0.01 см²`, робоча напруга `V_io = 1.8 В`, нахил Вейбула `β_io = 4.50`.

Загальна функція виживання чіпа `R_SoC(t)` є добутком функцій виживання обох доменів:

```
R_SoC(t)
= R_core(t) · R_io(t)                     [добуток надійностей незалежних доменів]
= exp(- (t / η_core)^β_core) · exp(- (t / η_io)^β_io) [підстановка розподілів Вейбула]
= exp(- [ (t / η_core)^β_core + (t / η_io)^β_io ])   [об'єднання показників експоненти]
```

Кумулятивна частка відмов SoC:

```
F_SoC(t)
= 1 - exp(- [ (t / η_core)^β_core + (t / η_io)^β_io ]) [сумарна ймовірність відмови SoC]
```

Для малих рівнів відмов (`F << 1`):

```
F_SoC(t)
≈ (t / η_core)^β_core + (t / η_io)^β_io   [лінійне наближення сумарного браку]
```

Завдяки високому значенню `β_io = 4.50` у домені вводу–виводу, внесок товстого оксиду в ранні відмови (`F < 0.01%`) є мізерно малим (`(t / η_io)^4.5 << (t / η_core)^1.2`). Таким чином, сумарна надійність складної системи на кристалі на ранніх етапах життєвого циклу практично повністю лімітується доменом процесорного ядра з найтоншим діелектриком.

## 8. Чисельне моделювання перколяції методом Монте-Карло

Для аналізу складних тривимірних геометрій (FinFET, нанолисти GAA), де аналітичні вирази стають занадто спрощеними, застосовують пряме статистичне моделювання методом Монте-Карло.

### Алгоритм Хошена–Копельмана для пошуку зв'язних кластерів

Об'єм діелектрика дискретизується у тривимірний масив комірок розміром `N_x × N_y × N_z`, де `N_z = t_ox / a_0` — кількість шарів по товщині.

1. **Генерація псевдовипадкових пасток:** на кожному часовому кроці `Δt` у ґратці випадковим чином генерується нова порція дефектів відповідно до локальної напруженості електричного поля:

```
ΔN_traps
= g_gen(E(x,y,z), T) · ΔV · Δt            [кількість нових дефектів за часовий крок]
```

2. **Маркування зв'язних кластерів (Hoshen–Kopelman Algorithm):** алгоритм послідовно сканує тривимірний масив і призначає цілочисельні мітки суміжним дефектним коміркам. Якщо нова пастка торкається вже існуючого кластера, вона отримує його мітку; якщо вона сполучає два різні кластери, таблиця еквівалентностей об'єднує їхні мітки.
3. **Критерій зупинки (Percolation Condition):** моделювання зупиняється в момент, коли хоча б один зв'язний кластер одночасно містить комірки з нижнього шару `z = 0` (канал) та верхнього шару `z = N_z` (затвор). Час досягнення цієї умови фіксується як час до пробою `t_bd` для даної статистичної реалізації.

Повторення цього процесу `10 000` разів дозволяє побудувати точну функцію розподілу відмов безпосередньо з перших фізичних принципів, підтверджуючи аналітичну залежність `β(t_ox)` навіть для неоднорідних за товщиною шарів.

## 9. Довірчі інтервали та дисперсія оцінок Вейбула

Під час випробування обмеженої вибірки з `N` зразків точкові оцінки параметрів `β̂` та `η̂` мають статистичну невизначеність. Для гарантування надійності розраховують **довірчі інтервали** (Confidence Bounds).

З теорії асимптотичної нормальності оцінок максимальної правдоподібності коваріаційна матриця параметрів `[ln(η̂), ln(β̂)]` визначається оберненою матрицею інформації Фішера:

```
Var(ln(η̂))
≈ 1.1086 / (N · β²)                       [дисперсія оцінки характеристичного часу]
```

```
Var(ln(β̂))
≈ 0.6079 / N                              [дисперсія оцінки нахилу Вейбула]
```

```
Cov(ln(η̂), ln(β̂))
≈ 0.2570 / (N · β)                        [коваріація параметрів Вейбула]
```

Дисперсія логарифма квантиля часу життя `t_F` для заданого рівня браку `F`:

```
Var(ln(t_F))
= Var(ln(η̂)) + (w_F / β)² · Var(ln(β̂)) - 2 · (w_F / β) · Cov(ln(η̂), ln(β̂)) [дисперсія квантиля]
```

де `w_F = ln(-ln(1 - F))`.

Для довірчої ймовірності `95%` (`Z_0.95 = 1.645` для одностороннього інтервалу) нижня гарантована межа терміну служби обчислюється як:

```
t_F,lower
= t_F · exp(- 1.645 · √[Var(ln(t_F))])    [нижня 95% довірча межа часу життя]
```

Саме ця нижня консервативна оцінка закладається в офіційну специфікацію надійності напівпровідникового виробу.

## 10. Доведення граничної теореми Фішера–Тіппетта–Гнєденка для мінімумів

Розглянемо послідовність із `M` незалежних випадкових величин часу пробою окремих комірок `T_1, T_2, ..., T_M`, що мають спільну неперервну функцію розподілу `F_0(t)` з нижньою межею носія `t = 0`. Час пробою діелектрика визначається статистикою мінімуму `T_(1) = min(T_1, T_2, ..., T_M)`.

Функція розподілу мінімуму вибірки:

```
F_min(t)
= 1 - [1 - F_0(t)]^M                      [точний розподіл мінімального значення з M елементів]
```

Припустимо, що в околі нуля функція розподілу окремої комірки має степеневий вигляд `F_0(t) = c · t^α` при `t → 0⁺` (де `α > 0` визначається кількістю стадій генерації дефектів).

Введемо нормуючі коефіцієнти `a_M = (c · M)^(-1 / α)` та `b_M = 0`. Знайдемо границю нормованого розподілу при `M → ∞`:

```
P((T_(1) - b_M) / a_M ≤ x)
= 1 - [1 - F_0(a_M · x)]^M                [підстановка нормованої змінної]
= 1 - [1 - c · (a_M · x)^α]^M             [підстановка степеневої асимптотики]
= 1 - [1 - c · (c · M)⁻¹ · x^α]^M         [підстановка масштабного коефіцієнта a_M]
= 1 - [1 - x^α / M]^M                     [скорочення сталих]
```

Переходячи до границі за другою чудовою границею `lim_{M → ∞} (1 - z / M)^M = exp(-z)`:

```
lim_{M → ∞} P(T_(1) / a_M ≤ x)
= 1 - exp(-x^α)                           [граничний розподіл Вейбула для мінімумів]
```

Це доводить, що розподіл Вейбула є єдино можливим строго стійким граничним розподілом для пробою систем типу «найслабшої ланки», якщо розподіл окремого дефекту має степеневу поведінку біля нуля.

## 11. Термічна модуляція радіуса взаємодії пасток

У класичній геометрії перколяції дві сусідні пастки вважаються з'єднаними, якщо відстань між їхніми центрами не перевищує характерний радіус перекриття хвильових функцій електрона (радіус квантового тунелювання) `r_trap`.

При підвищенні температури кристала фононні коливання ґратки модулюють положення енергетичних рівнів, що викликає термічно асистоване тунелювання (Variable-Range Hopping) та збільшує ефективний радіус захоплення:

```
r_trap(T)
= r_0 · (1 + α_T · [T - T_0])             [температурна залежність ефективного радіуса пастки]
```

де `α_T ≈ 1.2 · 10⁻³ K⁻¹` — температурний коефіцієнт розширення хвильової функції, `r_0 ≈ 0.4 нм` — вихідний радіус за кімнатної температури.

Збільшення радіуса пастки веде до зростання ефективного об'єму комірки `v_0(T) = (4/3) π [r_trap(T)]³` та зменшення кількості кроків `n(T) = t_ox / (2 r_trap(T))` для подолання бар'єру. Це пояснює експериментально спостережуване повільне зменшення нахилу Вейбула `β` за високих температур (`150…200 °C`).

## 12. Порівняння хвостів розподілу Вейбула та логнормального розподілу

У ранній літературі з надійності напівпровідників дані відмов іноді апроксимували логнормальним розподілом через його математичну простоту в околі медіани `50%`.

Проте логнормальний та вейбулівський розподіли демонструють кардинально різну поведінку в області низьких квантилів (`F < 0.01% = 100 ppm`):
* Логнормальний розподіл має значно важчий лівий хвіст у масштабі площі, оскільки не задовольняє аксіому стійкості мінімумів: масштабування площі в логнормальній статистиці не зводиться до паралельного зсуву кривої.
* Якщо дані, що підпорядковуються перколяційному механізму Вейбула, помилково апроксимувати логнормальним законом за центральними точками (`F = 20…80%`), екстраполяція в область `100 ppm` призведе до заниження гарантованого ресурсу в десятки або сотні разів.

Тому використання розподілу Вейбула є обов'язковою фізично обґрунтованою вимогою індустріальних стандартів для розрахунку надійності підзатворного діелектрика.
