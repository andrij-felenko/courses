# 🧮 Термодинаміка слабкої інверсії та виведення підпорогового розмаху

Ця математична вставка містить строге аналітичне виведення рівняння підпорогового струму дифузії в каналі польового транзистора, розрахунок ємнісного дільника потенціалу між діелектриком затвора, збідненим шаром напівпровідника та пастками на межі поділу, двовимірне розв'язання рівняння Пуассона для моделювання ефекту DIBL, аналіз перехідної області помірної інверсії за моделлю EKV, а також термодинамічне обґрунтування фундаментальної межі підпорогового розмаху 60 мВ/декаду при кімнатній температурі.

---

### 1. Електростатичний ємнісний дільник та поверхневий потенціал

У польовому транзисторі зі структурою метал-діелектрик-напівпровідник (MOSFET) робочий стан приладу визначається величиною поверхневого потенціалу `ψ_s` на межі кремній-діелектрик. Потенціал `ψ_s` відраховується від нейтрального об'єму напівпровідникової підкладки (bulk), де енергетичні зони є плоскими.

Коли прикладена напруга між затвором і витоком `V_GS` менша за порогову напругу `V_th`, поверхня напівпровідника перебуває в режимі слабкої інверсії (weak inversion) або збіднення (depletion). У цьому режимі концентрація вільних електронів під діелектриком залишається набагато меншою за концентрацію іонізованих акцепторних атомів домішки в кремнії.

Повний електричний заряд під затвором на одиницю площі `Q_s` складається з трьох фізичних компонентів: заряду нерухомих іонізованих акцепторів у збідненому шарі `Q_dep`, малого заряду рухомих електронів інверсійного шару `Q_inv`, а також заряду поверхневих пасток і дефектів на межі поділу кремній-оксид `Q_it`:

```
Q_s = Q_dep + Q_inv + Q_it                       [повний заряд у напівпровіднику]
```

Оскільки в підпороговій області концентрація електронів надзвичайно мала, виконується сильна нерівність `|Q_inv| ≪ |Q_dep|`. Якщо припустити високу якість вирощування діелектрика (де густина пасток є знехтовно малою), заряд поверхні визначається практично виключно просторовим зарядом збідненої області:

```
Q_s ≈ Q_dep = -√(2 · q · ε_si · N_A · ψ_s)      [наближення просторового заряду]
```

де `q = 1.602176634 × 10⁻¹⁹ Кл` — елементарний заряд електрона, `ε_si ≈ 1.036 × 10⁻¹⁰ Ф/м` (або `11.7 · ε_0`) — діелектрична проникність кремнію, `N_A` — концентрація акцепторної домішки в p-підкладці (зазвичай від `10¹⁶` до `10¹⁸ см⁻³`), а `ψ_s` — поверхневий потенціал.

Рівняння балансу потенціалів у системі затвор-діелектрик-канал пов'язує прикладену напругу `V_GS` із падінням напруги на підзатворному діелектрику `V_ox` та потенціалом поверхні напівпровідника `ψ_s`:

```
V_GS - V_FB = V_ox + ψ_s                        [електростатичний баланс напруг]
```

де `V_FB` — напруга плоских зон (flat-band voltage), що визначається різницею термодинамічних робіт виходу матеріалу затвора і напівпровідника, а також фіксованим зарядом в оксиді.

За теоремою Гауса спад напруги на шарі підзатворного діелектрика завтовшки `t_ox` пропорційний повному заряду в напівпровіднику:

```
V_ox = -Q_s / C_ox ≈ -Q_dep / C_ox              [напруга на діелектрику]
```

де `C_ox = ε_ox / t_ox` — питома ємність підзатворного діелектрика на одиницю площі, а `ε_ox` — діелектрична проникність матеріалу затвора (`3.9 · ε_0` для діоксиду кремнію `SiO₂` або `20 ... 25 · ε_0` для діелектриків класу High-k на основі оксиду гафнію `HfO₂`).

Підставляючи вираз для заряду `Q_dep` у баланс напруг, отримуємо нелінійний зв'язок між керівною напругою затвора `V_GS` та результуючим потенціалом поверхні `ψ_s`:

```
V_GS - V_FB = ψ_s + √(2 · q · ε_si · N_A · ψ_s) / C_ox   [нелінійне рівняння потенціалу]
```

Диференціюємо обидві частини за поверхневим потенціалом `ψ_s`:

```
d(V_GS) / d(ψ_s) = 1 + (1 / C_ox) · [d(-Q_dep) / d(ψ_s)]   [диференціювання за ψ_s]
```

Величина `d(-Q_dep) / dψ_s` є диференціальною ємністю збідненого шару напівпровідника на одиницю площі `C_dep`:

```
C_dep = d(-Q_dep) / d(ψ_s) = √(q · ε_si · N_A / (2 · ψ_s)) = ε_si / W_dep   [ємність збіднення]
```

де `W_dep = √(2 · ε_si · ψ_s / (q · N_A))` — просторова ширина збідненої області під каналом.

Якщо врахувати наявність пасток на межі розділу кремній-діелектрик із густиною станів `D_it` (вимірюється в `еВ⁻¹ · см⁻²`), вони створюють додаткову паралельну ємність пасток `C_it = q² · D_it`. Тоді повна ємність поверхні дорівнює сумі `C_dep + C_it`.

Швидкість зміни поверхневого потенціалу каналу під дією напруги затвора описується коефіцієнтом ємнісного дільника:

```
d(ψ_s) / d(V_GS) = C_ox / (C_ox + C_dep + C_it) = 1 / m   [коефіцієнт передачі дільника]
```

Тут безрозмірний параметр `m` називають фактором підпорогової неідеальності (subthreshold slope factor або body coefficient):

```
m = 1 + (C_dep + C_it) / C_ox                   [повний фактор неідеальності m]
```

Оскільки фізичні ємності `C_dep` та `C_ox` завжди строго додатні, коефіцієнт `m` завжди більший за одиницю (`m > 1`). Це фундаментально означає, що поверхневий потенціал кремнію `ψ_s` завжди зростає повільніше, ніж прикладена напруга затвора `V_GS`: при зміні `V_GS` на 100 мВ потенціал каналу `ψ_s` змінюється лише на `100 / m` мВ (наприклад, на 75–85 мВ у типових планарних транзисторах).

### 2. Розподіл Больцмана та дифузійний перенос неосновних носіїв

На відміну від режиму сильної інверсії (`V_GS > V_th`), де щільність електронів у каналі висока і головним механізмом струму є дрейф під дією поздовжнього електричного поля стоку, у підпороговому режимі концентрація носіїв є вкрай низькою.

Рівень Фермі `E_F` у слабкій інверсії лежить глибоко всередині забороненої зони (на відстані кількох `k_B · T` нижче дна зони провідності `E_c`). Тому виродження відсутнє, і розподіл Фермі-Дірака точно зводиться до класичної експоненційної статистики Максвелла-Больцмана.

Концентрація електронів на межі поділу з діелектриком у точці з координатою `x` вздовж каналу (де `x = 0` відповідає витоку, а `x = L` — стоку) описується рівнянням:

```
n_s(x) = (n_i² / N_A) · exp(q · (ψ_s(x) - V(x)) / (k_B · T))   [концентрація електронів]
```

де:
- `n_i` — власна концентрація носіїв заряду в кремнії (`n_i ≈ 1.0 × 10¹⁰ см⁻³` при 300 К);
- `n_i² / N_A = n_p0` — рівноважна концентрація неосновних носіїв (електронів) у нейтральній p-підкладці;
- `V(x)` — квазірівень Фермі електронів вздовж каналу, що змінюється від `V(0) = 0` (потенціал витоку) до `V(L) = V_DS` (потенціал стоку);
- `k_B = 1.380649 × 10⁻²³ Дж/К` — стала Больцмана;
- `T` — абсолютна температура в Кельвінах;
- `v_t = k_B · T / q` — термічний потенціал напівпровідника (`v_t ≈ 25.85` мВ при `T = 300` К).

Оскільки градієнт потенціалу `dψ_s / dx` уздовж каналу в довгому транзисторі є незначним, дрейфовий струм практично відсутній. Перенесення заряду відбувається за рахунок градієнта концентрації носіїв (чиста теплова дифузія).

Густина дифузійного струму електронів описується законом Фіка:

```
j_diff(x, y) = q · D_n · (dn(x, y) / dx)         [густина дифузійного струму]
```

де `D_n` — коефіцієнт дифузії електронів, пов'язаний із їхньою рухливістю `μ_n` через фундаментальне термодинамічне співвідношення Ейнштейна:

```
D_n = μ_n · (k_B · T / q) = μ_n · v_t            [співвідношення Ейнштейна]
```

Повний струм стоку `I_sub` отримуємо інтегруванням густини струму по ширині каналу `W` та по глибині `y` від поверхні вглиб підкладки:

```
I_sub = W · ∫ [q · D_n · (dn(x, y) / dx)] dy     [інтегрування по перерізу]
```

Інтегруючи концентрацію електронів по глибині, знаходимо повний інверсійний заряд рухомих носіїв на одиницю площі `Q_inv(x)`:

```
Q_inv(x) = -q · ∫ n(x, y) dy                     [заряд інверсійного шару]
```

Тоді дифузійний струм через будь-який переріз каналу `x` можна переписати через просторову похідну інверсійного заряду:

```
I_sub = -W · D_n · (d Q_inv(x) / dx) = -W · μ_n · v_t · (d Q_inv(x) / dx)   [струм через заряд]
```

Оскільки струм неперервний уздовж каналу (в стаціонарному стані `dI_sub / dx = 0`), інтегруємо обидві частини рівняння вздовж усієї довжини каналу від `x = 0` до `x = L`:

```
∫₀ᴸ I_sub dx = -W · μ_n · v_t · ∫₀ᴸ (d Q_inv / dx) dx   [інтегрування вздовж каналу]
I_sub · L    = W · μ_n · v_t · [Q_inv(0) - Q_inv(L)]   [інтеграл струму]
I_sub        = μ_n · (W / L) · v_t · [Q_inv(0) - Q_inv(L)]   [рівняння дифузійного струму]
```

### 3. Аналітичний зв'язок інверсійного заряду з напругами електродів

Щоб знайти точні значення інверсійного заряду біля витоку `Q_inv(0)` та біля стоку `Q_inv(L)`, розв'яжемо одновимірне рівняння Пуассона біля поверхні напівпровідника:

```
d²ψ / dy² = -(q / ε_si) · [N_A · (exp(-q · ψ / (k_B · T)) - 1) + n_p0 · exp(q · (ψ - V) / (k_B · T))]
```

Перший інтеграл рівняння Пуассона дає напруженість електричного поля біля поверхні кремнію `E_s = -(dψ/dy)|_y=0`:

```
E_s = √(2 · q · N_A · ψ_s / ε_si) + (v_t / ψ_s) · (n_i / N_A)² · exp(q · (ψ_s - V) / (k_B · T))
```

Інтегруючи лише електронну частину заряду в межах тонкого підпорогового шару, отримуємо аналітичний вираз для поверхневої густини інверсійного заряду:

```
Q_inv(V) = -√(q · ε_si · N_A / (2 · ψ_s)) · (v_t / ψ_s) · (n_i / N_A)² · exp(q · (ψ_s - V) / (k_B · T))
```

Враховуючи, що ємність збідненого шару дорівнює `C_dep = √(q · ε_si · N_A / (2 · ψ_s))`, а поверхневий потенціал `ψ_s` пов'язаний із напругою затвора через коефіцієнт передачі дільника `dψ_s / dV_GS = 1/m`, лінеаризуємо вираз для `ψ_s` в околі порогової напруги `V_th`:

```
ψ_s(V_GS) ≈ ψ_s(V_th) + (V_GS - V_th) / m        [лінеаризація потенціалу каналу]
```

Підставивши це значення в заряд `Q_inv`, отримуємо значення інверсійного заряду на межах каналу:

```
Q_inv(0) = Q_0 · exp((V_GS - V_th) / (m · v_t))                [заряд біля витоку]
Q_inv(L) = Q_0 · exp((V_GS - V_th) / (m · v_t)) · exp(-V_DS / v_t)   [заряд біля стоку]
```

де `Q_0 = C_ox · (m - 1) · v_t` — характерний інверсійний заряд при пороговій напрузі.

Підставляючи граничні значення заряду у формулу дифузійного струму, отримуємо фундаментальне рівняння підпорогового струму MOSFET:

```
I_sub = μ_n · C_ox · (W / L) · (m - 1) · v_t² · exp((V_GS - V_th) / (m · v_t)) · [1 - exp(-V_DS / v_t)]
```

Введемо масштабний коефіцієнт струму `I_0 = μ_n · C_ox · (W / L) · (m - 1) · v_t²`. Тоді підпороговий струм записується у канонічній формі:

```
I_sub = I_0 · exp((V_GS - V_th) / (m · v_t)) · [1 - exp(-V_DS / v_t)]   [канонічне рівняння струму]
```

Аналіз залежності від напруги стоку `V_DS`:
1. При малих напругах стоку (`V_DS ≪ v_t ≈ 26 мВ`): розкладаємо експоненту в ряд Тейлора `1 - exp(-V_DS / v_t) ≈ V_DS / v_t`. Струм стоку зростає лінійно з напругою `V_DS`:
```
I_sub ≈ I_0 · exp((V_GS - V_th) / (m · v_t)) · (V_DS / v_t)   [лінійний підпороговий режим]
```
2. При напругах стоку `V_DS > 3 ... 4 · v_t ≈ 0.1 В`: експоненційний член стає знехтовно малим (`exp(-4) ≈ 0.018`), а множник `[1 - exp(-V_DS / v_t)] → 1`. Струм повністю насичується і стає незалежним від `V_DS` (для ідеального довгоканального транзистора):
```
I_sub(sat) = I_0 · exp((V_GS - V_th) / (m · v_t))             [насичений підпороговий струм]
```

### 4. Виведення підпорогового розмаху (Subthreshold Swing)

Підпороговий розмах `S` (Subthreshold Swing або Subthreshold Slope) є головною метрикою якості закривання польового транзистора. Він кількісно визначає зміну напруги затвора `ΔV_GS`, необхідну для зміни підпорогового струму стоку `I_sub` рівно в 10 разів (на один десятковий порядок, або одну декаду):

```
S = [d(log₁₀(I_sub)) / d(V_GS)]⁻¹ = d(V_GS) / d(log₁₀(I_sub))   [визначення розмаху S]
```

Застосовуючи математичне правило переходу між десятковим і натуральним логарифмами `log₁₀(y) = ln(y) / ln(10)`:

```
d(log₁₀(I_sub)) / d(V_GS) = (1 / ln(10)) · [d(ln(I_sub)) / d(V_GS)]   [перехід до натурального логарифма]
S = ln(10) · [d(ln(I_sub)) / d(V_GS)]⁻¹          [розмах через натуральний логарифм]
```

Знайдемо натуральний логарифм насиченого підпорогового струму:

```
ln(I_sub) = ln(I_0) + (V_GS - V_th) / (m · v_t)  [логарифм струму]
```

Диференціюємо за напругою затвора `V_GS`:

```
d(ln(I_sub)) / d(V_GS) = 1 / (m · v_t)           [похідна логарифма струму]
```

Підставляючи цю похідну у вираз для `S`:

```
S = ln(10) · m · v_t                             [базова формула розмаху]
```

Розгортаючи коефіцієнт неідеальності `m` через ємності структури та підставляючи термічний потенціал `v_t = k_B · T / q`, отримуємо повний розгорнутий аналітичний вираз:

```
S = ln(10) · (1 + (C_dep + C_it) / C_ox) · (k_B · T / q)   [повний аналітичний вираз S]
```

### 5. Термодинамічна межа 60 мВ/декаду при 300 К

Розглянемо фізичну границю ідеального польового транзистора:
1. Товщина підзатворного діелектрика прямує до нуля або його діелектрична проникність прямує до нескінченності (`C_ox → ∞`);
2. Густина пасток на межі розділу зведена до абсолютного нуля (`C_it = 0`);
3. Канал транзистора є ультратонким або повністю оточеним затвором (Gate-All-Around), завдяки чому ємність збідненого об'єму напівпровідника зникає (`C_dep → 0`).

У цьому ідеальному випадку коефіцієнт ємнісного дільника дорівнює одиниці:

```
m_ideal = 1 + 0 = 1.000                          [ідеальний ємнісний дільник]
```

Тоді мінімальний фізично досяжний підпороговий розмах для будь-якого класичного польового транзистора з термоемісійним інжектуванням носіїв визначається виключно фундаментальними фізичними сталими та абсолютною температурою:

```
S_ideal = ln(10) · (k_B · T / q)                 [термодинамічна межа Больцмана]
```

Підставимо точні значення фундаментальних фізичних констант SI:
- Стала Больцмана: `k_B = 1.380649 × 10⁻²³ Дж/К` (точне значення за стандартом SI 2019 року);
- Елементарний електричний заряд: `q = 1.602176634 × 10⁻¹⁹ Кл` (точне значення);
- Натуральний логарифм десяти: `ln(10) ≈ 2.302585092994046`.

Розрахуємо термічний потенціал при стандартизованій кімнатній температурі `T = 300.0` К (+26.85 °C):

```
v_t = (1.380649 × 10⁻²³ · 300.0) / (1.602176634 × 10⁻¹⁹)
v_t = 4.141947 × 10⁻²¹ / 1.602176634 × 10⁻¹⁹
v_t ≈ 0.0258520 В = 25.8520 мВ                   [термічний потенціал при 300 К]
```

Обчислюємо граничний підпороговий розмах:

```
S_ideal = 2.302585093 · 25.852014 мВ
S_ideal = 59.5264 мВ/декаду ≈ 59.5 мВ/декаду ≈ 60 мВ/декаду   [фундаментальна межа]
```

Ця величина є нездоланним фізичним бар'єром для будь-якого напівпровідникового ключа, в якому струм формується тепловим перелітанням носіїв заряду через потенціальний бар'єр. Щоб зменшити струм витоку в 10 разів при кімнатній температурі, необхідно знизити напругу на затворі щонайменше на 59.5 мВ навіть у транзисторі з ідеальним діелектриком.

### 6. Температурна залежність підпорогового розмаху

Оскільки підпороговий розмах `S` лінійно залежить від абсолютної температури `T`, термічні коливання всередині мікропроцесора кардинально змінюють статичний струм витоку:

```
S(T) = S_ideal(300 K) · m · (T / 300)            [температурне масштабування розмаху]
```

Проаналізуємо характеристики для чотирьох ключових температурних точок при різних факторах неідеальності `m` (де `m = 1.0` — теоретичний ідеал, `m = 1.08` — сучасний 3 нм GAA Nanosheet, `m = 1.15` — 7 нм FinFET, `m = 1.35` — 65 нм планарний bulk MOSFET):

```
1. Кріогенне охолодження рідким азотом (T = 77 К, -196 °C):
   v_t = 6.635 мВ
   S_ideal (m = 1.00) = 2.303 · 6.635 мВ = 15.28 мВ/декаду
   S_GAA   (m = 1.08) = 1.08 · 15.28 мВ  = 16.50 мВ/декаду
   S_Fin   (m = 1.15) = 1.15 · 15.28 мВ  = 17.57 мВ/декаду
   S_Plan  (m = 1.35) = 1.35 · 15.28 мВ  = 20.63 мВ/декаду

2. Кімнатна температура (T = 300 К, +27 °C):
   v_t = 25.852 мВ
   S_ideal (m = 1.00) = 59.53 мВ/декаду
   S_GAA   (m = 1.08) = 64.29 мВ/декаду
   S_Fin   (m = 1.15) = 68.46 мВ/декаду
   S_Plan  (m = 1.35) = 80.36 мВ/декаду

3. Номінальна температура кремнієвого кристала під навантаженням (T = 358 К, +85 °C):
   v_t = 30.850 мВ
   S_ideal (m = 1.00) = 71.03 мВ/декаду
   S_GAA   (m = 1.08) = 76.71 мВ/декаду
   S_Fin   (m = 1.15) = 81.69 мВ/декаду
   S_Plan  (m = 1.35) = 95.89 мВ/декаду

4. Локальна точка перегріву кристала (T = 398 К, +125 °C):
   v_t = 34.297 мВ
   S_ideal (m = 1.00) = 78.97 мВ/декаду
   S_GAA   (m = 1.08) = 85.29 мВ/декаду
   S_Fin   (m = 1.15) = 90.82 мВ/декаду
   S_Plan  (m = 1.35) = 106.61 мВ/декаду
```

При зростанні температури від 300 К до 398 К (+125 °C) підпороговий розмах зростає на 32.7%. 

Порахуємо, як змінюється струм вимкненого стану `I_off` при фіксованій пороговій напрузі `V_th = 0.35` В для планарного транзистора (`S = 80.4` мВ/дек при 300 К та `S = 106.6` мВ/дек при 398 К):

```
I_off(300 K) ∝ 10^(-V_th / S(300 K)) = 10^(-0.35 / 0.0804) = 10^(-4.353) ≈ 4.43 × 10⁻⁵
I_off(398 K) ∝ 10^(-V_th / S(398 K)) = 10^(-0.35 / 0.1066) = 10^(-3.283) ≈ 5.21 × 10⁻⁴
```

Відношення струмів становить:

```
I_off(398 K) / I_off(300 K) = (5.21 × 10⁻⁴) / (4.43 × 10⁻⁵) ≈ 11.8 разів   [зростання витоку]
```

Лише через деградацію підпорогового нахилу `S` статичний витік транзистора зростає майже у 12 разів. Якщо додати сюди температурне падіння самої порогової напруги `dV_th / dT ≈ -1 ... -2 мВ/К` (що зменшує `V_th` на 100–150 мВ при нагріванні), сумарний статичний струм витоку чіпа при 125 °C зростає у 50–100 разів порівняно зі станом при кімнатній температурі.

### 7. Двовимірний аналіз ефекту DIBL у короткоканальних транзисторах

У транзисторах із довжиною каналу `L < 100` нм одновимірне наближення перестає працювати: електричне поле стоку проникає в глибину каналу, знижуючи електростатичний потенціальний бар'єр між витоком і каналом. Це явище називають індукованим стоком зниженням бар'єра (Drain-Induced Barrier Lowering, DIBL).

Розв'язок двовимірного рівняння Лапласа в збідненій області під затвором методом розділення змінних дає розподіл потенціалу вздовж каналу:

```
ψ(x) = ψ_s0 + A · sinh((L - x) / λ) + B · sinh(x / λ)   [розподіл потенціалу каналу]
```

де `λ` — характерна довжина електростатичного масштабування (characteristic scaling length):

```
λ = √( (ε_si / ε_ox) · t_ox · W_dep )            [масштабна довжина для bulk MOSFET]
```

Для FinFET та ультратонких SOI транзисторів масштабна довжина визначається товщиною кремнієвого тіла `t_si`:

```
λ_FinFET = √( (ε_si / (2 · ε_ox)) · t_ox · t_si )   [масштабна довжина для FinFET]
```

Мінімум потенціалу вздовж каналу відповідає вершині потенціального бар'єра `ψ_min`, через яку дифундують електрони:

```
ψ_min ≈ ψ_s0 + 2 · √(V_bi · (V_bi + V_DS)) · exp(-L / (2 · λ))   [зниження бар'єра стоком]
```

Звідси зміна ефективної порогової напруги під дією високої напруги стоку `V_DS` виражається формулою:

```
ΔV_th = -DIBL · ΔV_DS = -[2 · exp(-L / (2 · λ))] · ΔV_DS   [зсув порогової напруги через DIBL]
```

Коефіцієнт DIBL (вимірюється в мВ/В) визначається як:

```
DIBL = -d(V_th) / d(V_DS) ≈ 2 · exp(-L / (2 · λ)) · (V_bi / v_t)   [коефіцієнт DIBL]
```

Якщо відношення довжини каналу до масштабної довжини `L / λ` падає нижче `4 ... 5`, коефіцієнт DIBL різко зростає від знехтовних значень до `100 ... 150 мВ/В`. При напрузі живлення `V_DD = 1.0` В це призводить до зниження порогу на 100–150 мВ, що через експоненційну залежність `I_sub ∝ 10^(ΔV_th / S)` збільшує струм витоку вимкненого транзистора в `10^(120 / 75) ≈ 40` разів.

### 8. Модель неперервної інтерполяції між слабкою та сильною інверсією (модель EKV)

У реальному аналоговому моделюванні та компактних моделях транзисторів (таких як BSIM або EKV) неможливо використовувати розривний опис, де підпороговий струм різко обривається в точці `V_GS = V_th`, поступаючись місцем квадратичному закону сильної інверсії `I_D ∝ (V_GS - V_th)²`.

Між чистою слабкою інверсією (де домінує дифузія) і сильною інверсією (де домінує дрейф) існує широка перехідна область — режим помірної інверсії (moderate inversion), де обидва механізми перенесення дають порівнянний внесок.

Модель Енза-Крумменахера-Вітоза (EKV) пропонує єдину неперервну аналітичну функцію для прямого нормованого струму інверсії `i_f` через напругу затвора:

```
i_f = [ ln(1 + exp((V_GS - V_th) / (2 · m · v_t))) ]²   [функція зшивання EKV]
```

Повний струм стоку через пряму `i_f` та зворотну `i_r` компоненти виражається як:

```
I_D = I_spec · (i_f - i_r)                       [загальний струм стоку EKV]
```

де характерний масштабний струм (specific current) `I_spec` дорівнює:

```
I_spec = 2 · m · μ_n · C_ox · (W / L) · v_t²     [характерний струм EKV]
```

Перевіримо два граничні випадки цієї моделі:

1. Глибока слабка інверсія (`(V_GS - V_th) ≪ -2 · m · v_t`):
   Оскільки аргумент експоненти малий, застосовуємо розклад `ln(1 + ε) ≈ ε`:
```
i_f ≈ [ exp((V_GS - V_th) / (2 · m · v_t)) ]² = exp((V_GS - V_th) / (m · v_t))
I_D ≈ I_spec · exp((V_GS - V_th) / (m · v_t)) · [1 - exp(-V_DS / v_t)]
```
Це тотожно збігається з виведеним вище рівнянням підпорогового дифузійного струму.

2. Глибока сильна інверсія (`(V_GS - V_th) ≫ +2 · m · v_t`):
   У цьому випадку `1 + exp(u) ≈ exp(u)`, тому `ln(exp(u)) = u`:
```
i_f ≈ [ (V_GS - V_th) / (2 · m · v_t) ]² = (V_GS - V_th)² / (4 · m² · v_t²)
I_D ≈ I_spec · i_f = [2 · m · μ_n · C_ox · (W / L) · v_t²] · [(V_GS - V_th)² / (4 · m² · v_t²)]
I_D = (1 / (2 · m)) · μ_n · C_ox · (W / L) · (V_GS - V_th)²   [класичний закон сильної інверсії]
```
Це точно відповідає класичному квадратичному закону MOSFET у насиченні.

Таким чином, модель EKV забезпечує математичну неперервність не лише самого струму стоку `I_D`, але й усіх його похідних — крутизни `g_m = dI_D / dV_GS` та вихідної провідності `g_ds = dI_D / dV_DS`, що усуває штучні сингулярності під час чисельного моделювання SPICE.
