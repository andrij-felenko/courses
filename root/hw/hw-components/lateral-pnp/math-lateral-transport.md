# 🧮 Фізико-математичний аналіз переносу носіїв у латеральному PNP

У монолітному латеральному p-n-p транзисторі фізика підсилення та частотні обмеження кардинально відрізняються від класичного вертикального n-p-n приладу. Якщо у вертикальному транзисторі рух електронів відбувається перпендикулярно до площини кристала крізь металургійно надтонку базу, то в латеральному PNP дірки дрейфують і дифундують паралельно до поверхні напівпровідника крізь геометрично широку n-епітаксійну кишеню. Нижче наведено повне аналітичне виведення рівнянь перенесення заряду, коефіцієнта інжекції емітера, коефіцієнта переносу бази в декартових та циліндричних координатах, впливу поверхневої рекомбінації, розподіленого опору бази й крайового ефекту штовхання струму (Current Crowding), ефекту високого рівня інжекції (Вебстера), модуляції ширини бази (напруги Ерлі), температурної залежності, граничної частоти та чисельного розрахунку параметрів.

## Рівняння неперервності та одновимірний профіль дірок у базі

Розглянемо стаціонарний стан латерального перенесення неосновних носіїв (дірок) у нейтральній n-базі вздовж координати `x` (від металургійної межі емітерного переходу `x = 0` до колекторного переходу `x = W_B`). За відсутності сильного тягового електричного поля в нейтральній слаболегованій базі струм дірок є суто дифузійним:

```
J_p(x) = −q · D_p · (d(Δp) / dx)
```

де `q = 1.602 · 10⁻¹⁹ Кл` — елементарний заряд, `D_p` — коефіцієнт дифузії дірок у кремнії n-типу, `Δp(x) = p_n(x) − p_n0` — надлишкова концентрація дірок над рівноважним значенням `p_n0 = n_i² / N_D`.

Стаціонарне одновимірне рівняння неперервності для дірок у базі за умови низького рівня інжекції має вигляд:

```
D_p · (d²(Δp) / dx²) − (Δp / τ_p) = 0
```

де `τ_p` — час життя неосновних носіїв (дірок) у n-епітаксії до рекомбінації з електронами. Ввівши дифузійну довжину дірок `L_p = √(D_p · τ_p)`, перепишемо диференціальне рівняння:

```
(d²(Δp) / dx²) − (Δp / L_p²) = 0
```

Загальний розв'язок цього лінійного однорідного диференціального рівняння другого порядку записується через гіперболічні функції:

```
Δp(x) = A · cosh((W_B − x) / L_p) + B · sinh((W_B − x) / L_p)
```

Для знаходження коефіцієнтів `A` та `B` задамо крайові умови на межах збіднених областей:

1. На прямо зміщеному емітерному переході (`x = 0`, напруга емітер–база `V_EB > 0`):
```
Δp(0) = p_n0 · (e^(V_EB / V_T) − 1)
```
де `V_T = k · T / q ≈ 25.85 мВ` за кімнатної температури `T = 300 К`.

2. На зворотно зміщеному колекторному переході (`x = W_B`, напруга колектор–база `V_CB < 0`):
Електричне поле зворотно зміщеного переходу миттєво екстрагує всі дірки, що долетіли до колектора, тому концентрація падає до нуля:
```
Δp(W_B) = 0
```

Підставивши другу крайову умову при `x = W_B`:
```
Δp(W_B) = A · cosh(0) + B · sinh(0) = A · 1 + 0 = A = 0
```

Звідси `A = 0`. Підставивши першу крайову умову при `x = 0`:
```
Δp(0) = B · sinh(W_B / L_p)
```

Звідси константа інтегрування:
```
B = Δp(0) / sinh(W_B / L_p)
```

Остаточний аналітичний розподіл надлишкової концентрації дірок у нейтральній базі латерального транзистора:

```
Δp(x) = Δp(0) · (sinh((W_B − x) / L_p) / sinh(W_B / L_p))
```

Оскільки ширина бази `W_B` у якісному латеральному транзисторі менша за дифузійну довжину `L_p` (`W_B / L_p ≪ 1`), розкладемо гіперболічний синус у степеневий ряд Тейлора `sinh(z) ≈ z + z³ / 6`:

```
Δp(x) ≈ Δp(0) · ((W_B − x) / W_B) · (1 − (2 · W_B · x − x²) / (6 · L_p²))
```

У нульовому наближенні профіль концентрації є строго лінійним спадом від `Δp(0)` біля емітера до `0` біля колектора.

## Двовимірний радіальний розподіл дірок у циліндричній геометрії

Реальний латеральний PNP виготовляється у вигляді центрального круглого емітера радіусом `r_E`, оточеного концентричним кільцевим колектором із внутрішнім радіусом `r_C = r_E + W_B`. 

У полярних координатах `(r, θ)` за радіальної симетрії стаціонарне рівняння дифузії набуває форми рівняння Бесселя:

```
(1 / r) · (d / dr) [r · (d(Δp) / dr)] − (Δp / L_p²) = 0
```

Заміною змінної `u = r / L_p` це рівняння зводиться до модифікованого рівняння Бесселя нульового порядку, загальний розв'язок якого записується через модифіковані функції Бесселя першого `I₀(r/L_p)` та другого `K₀(r/L_p)` роду:

```
Δp(r) = C₁ · I₀(r / L_p) + C₂ · K₀(r / L_p)
```

За типових розмірів емітера `r_E ~ 5–10 мкм` та ширини бази `W_B ~ 2 мкм` відношення `r / L_p ≪ 1` (оскільки `L_p ≈ 15–25 мкм`). Для малих аргументів функції Бесселя апроксимуються як:
```
I₀(z) ≈ 1
K₀(z) ≈ −ln(z / 2) − γ_E
```
де `γ_E ≈ 0.5772` — стала Ейлера — Маскероні.

Підставивши крайові умови `Δp(r_E) = Δp(0)` та `Δp(r_C) = 0`, отримуємо радіальний логарифмічний профіль надлишкової концентрації:

```
Δp(r) = Δp(0) · (ln(r_C / r) / ln(r_C / r_E))
```

Густина струму емітера на радіусі `r_E` в циліндричній геометрії:

```
J_p(r_E) = −q · D_p · [d(Δp) / dr]|_(r=r_E)
         = q · D_p · Δp(0) / (r_E · ln(r_C / r_E))
```

Оскільки `r_C = r_E + W_B`, розкладемо логарифм `ln(1 + W_B / r_E) ≈ (W_B / r_E) · (1 − W_B / (2 · r_E))`:

```
J_p(r_E) ≈ (q · D_p · Δp(0) / W_B) · (1 + W_B / (2 · r_E))
```

Множник `(1 + W_B / (2 · r_E))` показує, що через радіальне розширення ліній струму від центру до периферії ефективна густина струму емітера в кільцевому транзисторі на 10–20% вища, ніж у плоскій одновимірній геометрії тієї самої ширини бази.

## Густина струму та коефіцієнт переносу бази (Base Transport Factor)

Густина діркового струму, що входить у базу через емітерний перехід (`x = 0`), обчислюється через похідну від концентрації:

```
J_p(0) = −q · D_p · [d(Δp) / dx]|_(x=0)
       = q · D_p · (Δp(0) / L_p) · (cosh(W_B / L_p) / sinh(W_B / L_p))
       = q · D_p · (Δp(0) / L_p) · coth(W_B / L_p)
```

Густина діркового струму, що досягає колектора (`x = W_B`), дорівнює:

```
J_p(W_B) = −q · D_p · [d(Δp) / dx]|_(x=W_B)
         = q · D_p · (Δp(0) / L_p) · (1 / sinh(W_B / L_p))
```

Коефіцієнт переносу бази `α_T` визначається як частка інжектованого емітером діркового струму, яка досягає колектора без рекомбінації в об'ємі бази:

```
α_T = J_p(W_B) / J_p(0)
    = (1 / sinh(W_B / L_p)) / (cosh(W_B / L_p) / sinh(W_B / L_p))  [підстановка густин струмів]
    = 1 / cosh(W_B / L_p)                                          [скорочення спільного sinh]
```

Розкладемо гіперболічний косинус у ряд Тейлора для випадку тонкої бази `W_B ≪ L_p` (`cosh(z) ≈ 1 + z² / 2`):

```
α_T = 1 / (1 + W_B² / (2 · L_p²))                                  [розклад косинуса в ряд Тейлора]
    ≈ 1 − (W_B² / (2 · L_p²))                                      [лінійне наближення 1/(1+ε)]
    = 1 − (W_B² / (2 · D_p · τ_p))                                 [підстановка L_p² = D_p · τ_p]
```

Рекомбінаційні втрати струму в базі `1 − α_T` зростають пропорційно квадрату ширини бази `W_B²`. У латеральному PNP, де `W_B` становить 1.5–3 мкм (проти 0.2–0.4 мкм у вертикальному NPN), рекомбінаційні втрати в об'ємі бази виявляються у 25–100 разів вищими.

## Вплив поверхневої рекомбінації на межі Si–SiO₂

Латеральний струм протікає безпосередньо під пасивуючим шаром діоксиду кремнію `SiO₂`. На межі розділу кристалічної ґратки кремнію та аморфного оксиду виникають обірвані зв'язки та поверхневі пастки з високою густиною станів `N_ss ~ 10¹⁰ – 10¹¹ см⁻²·еВ⁻¹`.

Крайова умова для рекомбінації на поверхні (`y = 0`):

```
−D_p · [∂(Δp) / ∂y]|_(y=0) = −S_rec · Δp(y=0)
```

де `S_rec` — швидкість поверхневої рекомбінації (типово `100 – 1000 см/с`).

Поверхнева рекомбінація додає паразитний струм рекомбінації `I_surf`:

```
I_surf = q · S_rec · A_surf · Δp(0)
```

де `A_surf ≈ 2 · π · r_E · W_B` — площа поверхні нейтральної бази між емітером і колектором.

Ефективний час життя дірок у латеральному каналі `τ_eff` зменшується за правилом додавання швидкостей рекомбінації:

```
1 / τ_eff = (1 / τ_bulk) + (S_rec / d_eff)
```

де `d_eff ≈ 1.0 – 1.5 мкм` — глибина залягання латерального струмового каналу. За наявності поверхневих пасток `τ_eff` скорочується з 10–20 мкс до 1–2 мкс, що спричиняє додаткове падіння коефіцієнта `α_T`.

## Ефективність інжекції емітера (Emitter Injection Efficiency)

Повний струм емітерного переходу складається з двох компонентів:
1. Корисного діркового струму `I_pE`, інжектованого з p-емітера в n-базу.
2. Паразитного електронного струму `I_nE`, інжектованого з n-бази назад у p-емітер.

Ефективність інжекції емітера `γ` визначається співвідношенням:

```
γ = I_pE / (I_pE + I_nE) = 1 / (1 + (I_nE / I_pE))
```

Для дифузійних струмів:
```
I_pE = q · A_E · (D_p · p_n0 / W_B) = q · A_E · (D_p · n_i² / (N_D_base · W_B))
I_nE = q · A_E · (D_n · n_p0 / W_E) = q · A_E · (D_n · n_i² / (N_A_emit · W_E))
```

де `N_D_base` — концентрація донорів у n-епітаксійній базі (`~10¹⁵ – 10¹⁶ см⁻³`), `N_A_emit` — концентрація акцепторів у p-емітері (`~10¹⁷ – 10¹⁸ см⁻³`), `W_E` — ефективна глибина емітера, `D_n` — коефіцієнт дифузії електронів у p-емітері.

Підставивши вирази струмів, отримуємо формулу ефективності інжекції:

```
γ = 1 / (1 + (D_n · N_D_base · W_B) / (D_p · N_A_emit · W_E))
```

У латеральному PNP p-емітер формується базовою дифузією NPN-транзистора, тому рівень його легування `N_A_emit` обмежений величиною `~10¹⁸ см⁻³` (на відміну від `n⁺` емітера NPN з легуванням `~10²⁰ см⁻³`). Одночасно ширина бази `W_B` є великою. В результаті відношення `(N_D_base · W_B) / (N_A_emit · W_E)` становить помітну величину `0.01 – 0.04`, що знижує коефіцієнт інжекції `γ` до `0.96 – 0.98` (тоді як у NPN `γ > 0.999`).

## Розподілений опір бази та витіснення струму (Current Crowding)

Струм бази `I_B = (1 − α) · I_E` протікає радіально крізь слаболеговану n-епітаксію до віддаленого зовнішнього `n⁺` контакту. Розподілений опір тіла бази `r_bb'` створює падіння напруги:

```
R_B = R_sheet_epi · (1 / (2 · π)) · ln(r_contact / r_C)
```

де `R_sheet_epi` — шаровий опір епітаксійного шару (`~1000 – 3000 Ом/квадрат`).

Падіння напруги `ΔV_B(r) = I_B · R_B(r)` призводить до того, що внутрішня напруга емітер–база `V_EB(r)` максимальна на зовнішньому периметрі емітера, зверненому до колектора, і різко спадає до центру емітерного круга. В результаті діркова інжекція концентрується виключно на краях емітера (ефект витіснення струму або *emitter crowding*), через що центральна площа емітера стає неефективною для підсилення струму.

## Модуляція ширини бази та напруга Ерлі (Early Effect)

Під час збільшення зворотної напруги колектор–база `|V_CB|` ширина збідненої області колекторного переходу `x_dC` розширюється вглиб нейтральної бази:

```
x_dC = √((2 · ε_s / q) · (1 / N_D_base) · (V_bi + |V_CB|))
```

де `ε_s ≈ 1.036 · 10⁻¹² Ф/см` — діелектрична проникність кремнію, `V_bi ≈ 0.7 В` — вбудований потенціал переходу.

Ефективна ширина нейтральної бази зменшується:

```
W_B(V_CB) = W_B0 − x_dC(V_CB)
```

Оскільки струм колектора пропорційний `1 / W_B(V_CB)`, струм зростає зі збільшенням напруги:

```
I_C(V_CB) = I_C0 · (1 + |V_CB| / V_A)
```

де `V_A` — напруга Ерлі, яка аналітично виражається через швидкість розширення збідненого шару:

```
V_A = W_B0 / (d(x_dC) / d|V_CB|) = W_B0 · √((2 · q · N_D_base · (V_bi + |V_CB|)) / ε_s)
```

У латеральному PNP через помірну концентрацію донорів у базі `N_D_base ~ 2 · 10¹⁵ см⁻³` та початкову ширину `W_B0 ≈ 2 мкм`, напруга Ерлі становить помірну величину `V_A ≈ 30 – 50 В` (проти `100 – 150 В` у NPN). Це зумовлює динамічний вихідний опір колектора:

```
r_o = (V_A + |V_CE|) / I_C
```

За робочого струму `I_C = 100 мкА` та `V_A = 40 В` вихідний опір становить `r_o ≈ 400 кОм`.

## Температурна залежність коефіцієнта підсилення dβ/dT

Коефіцієнт підсилення `β` латерального PNP зростає з підвищенням абсолютної температури `T` з позитивним температурним коефіцієнтом:

```
(1 / β) · (dβ / dT) ≈ +0.5% ... +1.0% / °C
```

Цей ефект визначається фізичним зростанням дифузійної довжини дірок `L_p = √(D_p · τ_p)`: час життя дірок `τ_p` зростає з температурою внаслідок теплової депасивації пасток рекомбінації Шоклі — Ріда — Холла значно швидше, ніж спадає дифузійна рухливість `D_p ∝ T⁻¹.⁵`. В результаті коефіцієнт переносу бази `α_T` наближається до одиниці, підвищуючи підсилення нагрітого транзистора.

## Високий рівень інжекції та ефект Вебстера

За зростання струму емітера концентрація інжектованих дірок `Δp(0)` перевищує рівноважну концентрацію донорів у базі `N_D_base` (`Δp > N_D_base`). Це явище називається високим рівнем інжекції (ефект Вебстера).

Для збереження квазінейтральності плазми в базі накопичуються електрони: `n(x) ≈ N_D_base + Δp(x)`. Це породжує два наслідки:
1. Виникає внутрішнє електричне поле, яке подвоює ефективний коефіцієнт дифузії (амбіполярна дифузія): `D_eff = 2 · D_p`.
2. Концентрація електронів біля емітерного переходу зростає, що різко збільшує зворотну інжекцію електронів `I_nE` з бази в емітер.

За високого рівня інжекції ефективність інжекції емітера падає обернено пропорційно до колекторного струму:

```
γ(I_C) ≈ γ₀ / (1 + I_C / I_knee)
```

де `I_knee` — характерний струм перегину, за якого `Δp(0) = N_D_base`:

```
I_knee = q · A_E · (2 · D_p · N_D_base / W_B)
```

Через малу концентрацію донорів у n-епітаксії (`N_D ~ 10¹⁵ см⁻³`) та малу площу емітера, струм перегину `I_knee` становить усього `0.2 – 1.0 мА`. При струмах `I_C > 1 мА` коефіцієнт підсилення `β` латерального PNP спадає як `1 / I_C`.

## Повний коефіцієнт підсилення струму β

Загальний коефіцієнт передачі струму емітера в колектор `α` враховує ефективність інжекції, перенос через нейтральну базу та геометричний фактор збору колекторного кільця `η_c`:

```
α = γ · α_T · η_c
```

Коефіцієнт підсилення струму в схемі зі спільним емітером `β` дорівнює:

```
β = α / (1 − α)
```

Якщо колектор виконаний у вигляді суцільного кільця, що охоплює емітер на 360°, геометричний коефіцієнт збору `η_c ≈ 0.92 – 0.96` (решта 4–8% дірок інжектуються вертикально вниз або рекомбінують біля поверхні).

Підставимо типові параметри інтегрального латерального PNP:
- `γ = 0.97`
- `α_T = 0.98`
- `η_c = 0.94`

Обчислимо повний коефіцієнт `α`:

```
α = 0.97 · 0.98 · 0.94
  = 0.89357
```

Розрахуємо результуючий коефіцієнт підсилення струму `β`:

```
β = 0.89357 / (1 − 0.89357)
  = 0.89357 / 0.10643
  ≈ 8.4
```

Для оптимізованих технологій із вузькою базою (`W_B ≈ 1.2 мкм`) та мінімальною поверхневою рекомбінацією коефіцієнт `α` зростає до `0.96 – 0.98`, що забезпечує `β ≈ 25 – 50`.

## Час прольоту бази та гранична частота підсилення f_T

Гранична частота передачі струму `f_T` (частота одиничного підсилення за струмом у схемі зі спільним емітером) визначається повним часом затримки сигналу від емітера до колектора `τ_EC`:

```
f_T = 1 / (2 · π · τ_EC)
```

Повний час затримки `τ_EC` складається з чотирьох послідовних компонентів:

```
τ_EC = τ_E + τ_B + τ_C + τ_D
```

де:
1. `τ_E = r_e · C_jE = (V_T / I_E) · C_jE` — час перезаряджання бар'єрної ємності емітерного переходу.
2. `τ_B` — час прольоту неосновних носіїв крізь нейтральну базу.
3. `τ_C = r_e · C_jC + R_C_bulk · C_jC` — час перезаряджання ємності колекторного переходу.
4. `τ_D = x_dC / (2 · v_sat)` — час прольоту дірок крізь збіднену область колектора зі швидкістю насичення `v_sat ≈ 10⁷ см/с`.

У латеральному PNP транзисторі з широкою базою абсолютним домінантним чинником затримок є час дифузійного прольоту бази `τ_B`. Знайдемо його шляхом інтегрування накопиченого в базі заряду дірок `Q_B`:

```
Q_B = q · A_E · ∫[0..W_B] Δp(x) dx
```

Підставивши лінійний профіль `Δp(x) = Δp(0) · (1 − x / W_B)`:

```
Q_B = q · A_E · Δp(0) · ∫[0..W_B] (1 − x / W_B) dx
    = q · A_E · Δp(0) · (W_B / 2)
```

Оскільки струм колектора дорівнює `I_C = q · A_E · D_p · (Δp(0) / W_B)`, виразимо час прольоту бази:

```
τ_B = Q_B / I_C
    = (q · A_E · Δp(0) · W_B / 2) / (q · A_E · D_p · Δp(0) / W_B)  [підстановка виразів заряду та струму]
    = W_B² / (2 · D_p)                                             [скорочення спільних множників]
```

Порівняємо фізичні величини часу прольоту бази для вертикального NPN та латерального PNP транзисторів:

### 1. Вертикальний NPN транзистор:
- Носії заряду: електрони (`D_n ≈ 35 см²/с = 3.5 · 10⁻³ м²/с`).
- Ширина дифузійної бази: `W_B = 0.3 мкм = 0.3 · 10⁻⁶ м`.

```
τ_B_NPN = (0.3 · 10⁻⁶)² / (2 · 3.5 · 10⁻³)  [підстановка параметрів NPN]
        = 0.09 · 10⁻¹² / (7 · 10⁻³)         [піднесення до квадрату]
        ≈ 1.28 · 10⁻¹¹ с = 0.013 нс         [ділення]
```

### 2. Латеральний PNP транзистор:
- Носії заряду: дірки (`D_p ≈ 12 см²/с = 1.2 · 10⁻³ м²/с`).
- Ширина літографічної бази: `W_B = 2.2 мкм = 2.2 · 10⁻⁶ м`.

```
τ_B_PNP = (2.2 · 10⁻⁶)² / (2 · 1.2 · 10⁻³)  [підстановка параметрів латерального PNP]
        = 4.84 · 10⁻¹² / (2.4 · 10⁻³)       [піднесення до квадрату]
        ≈ 2.02 · 10⁻⁹ с = 2.02 нс           [ділення]
```

Час прольоту бази в латеральному PNP виявляється у 150–160 разів довшим.

З урахуванням паразитних бар'єрних ємностей емітерного переходу `C_jE` та колекторного переходу великої площі `C_jC` (охоплююче кільце), реальна величина `τ_EC` зростає до `25 – 50 нс`. Це зменшує практичну граничну частоту латерального PNP до:

```
f_T = 1 / (2 · π · (35 · 10⁻⁹)) ≈ 4.5 МГц
```

## Математична модель розділеного колектора (Split-Collector)

У топології з розділеним колектором дірковий потік ділиться між окремими металізованими секціями колекторного кільця. Якщо емітер є круглим диском радіусом `r_E`, а колекторні сегменти розташовані концентрично на радіусі `r_C` із кутовими розкриттями `θ₁` та `θ₂` (де `θ₁ + θ₂ ≤ 2π` радіанів):

```
I_C1 = I_pE · (θ₁ / (2 · π)) · α_T
I_C2 = I_pE · (θ₂ / (2 · π)) · α_T
```

Відношення струмів двох колекторів визначається виключно геометричним співвідношенням кутів маски:

```
I_C1 / I_C2 = θ₁ / θ₂
```

Оскільки обидва переходи виготовляються в єдиному технологічному вікні на відстані літографічної точності, температурні коефіцієнти насичення та напруги зміщення збігаються до десятих часток відсотка:

```
Δ(I_C1 / I_C2) / (I_C1 / I_C2) < 0.2%
```

## Покроковий чисельний розрахунок параметрів латерального PNP

Зведемо вихідні фізико-технологічні параметри кремнієвого латерального PNP транзистора в єдину розрахункову модель:

| Параметр | Позначення | Значення | Одиниці |
| :--- | :--- | :--- | :--- |
| Концентрація донорів у базі (епітаксія) | `N_D` | `2 · 10¹⁵` | `см⁻³` |
| Концентрація акцепторів в емітері | `N_A` | `5 · 10¹⁷` | `см⁻³` |
| Власна концентрація носіїв у Si (300 K) | `n_i` | `1.5 · 10¹⁰` | `см⁻³` |
| Коефіцієнт дифузії дірок у базі | `D_p` | `12.5` | `см²/с` |
| Коефіцієнт дифузії електронів в емітері | `D_n` | `25.0` | `см²/с` |
| Час життя дірок у нейтральній базі | `τ_p` | `5.0 · 10⁻⁶` | `с` (5 мкс) |
| Металургійна ширина бази | `W_B` | `2.0 · 10⁻⁴` | `см` (2.0 мкм) |
| Ефективна товщина емітера | `W_E` | `1.5 · 10⁻⁴` | `см` (1.5 мкм) |
| Робочий струм колектора | `I_C` | `100` | `мкА` |

### Крок 1. Розрахунок дифузійної довжини дірок:
```
L_p = √(D_p · τ_p)
    = √(12.5 · 5.0 · 10⁻⁶)   [підстановка параметрів]
    = √(6.25 · 10⁻⁵)         [перемноження під коренем]
    = 7.906 · 10⁻³ см ≈ 79.1 мкм  [добування кореня]
```

### Крок 2. Розрахунок коефіцієнта переносу бази:
```
W_B / L_p = 2.0 · 10⁻⁴ / (7.906 · 10⁻³) ≈ 0.0253
α_T = 1 / cosh(0.0253)
    ≈ 1 / (1 + (0.0253)² / 2)  [розклад косинуса в ряд]
    = 1 / (1 + 0.00032)        [піднесення до квадрату]
    ≈ 0.99968                  [обчислення частки]
```

### Крок 3. Розрахунок ефективності інжекції емітера:
```
(D_n · N_D · W_B) / (D_p · N_A · W_E)
  = (25.0 · (2 · 10¹⁵) · (2.0 · 10⁻⁴)) / (12.5 · (5 · 10¹⁷) · (1.5 · 10⁻⁴))  [числові значення параметрів]
  = (1.0 · 10¹³) / (9.375 · 10¹⁴)                                            [добуток у чисельнику та знаменнику]
  ≈ 0.01067                                                                 [ділення]

γ = 1 / (1 + 0.01067) ≈ 0.98944  [ефективність інжекції]
```

### Крок 4. Розрахунок коефіцієнта збору кільцевого колектора:
З урахуванням втрат 4% на паразитний вертикальний витік у підкладку: `η_c = 0.960`.

### Крок 5. Розрахунок підсумкового коефіцієнта підсилення:
```
α = γ · α_T · η_c
  = 0.98944 · 0.99968 · 0.960  [підстановка компонентів]
  ≈ 0.94955                    [перемноження складових]

β = α / (1 − α)
  = 0.94955 / (1 − 0.94955)    [підстановка знайденого α]
  = 0.94955 / 0.05045          [обчислення знаменника]
  ≈ 18.82                      [підсумкове підсилення за струмом]
```

Розрахунок строго підтверджує: навіть за ідеального монокристалічного кремнію та максимального пригнічення поверхневих пасток коефіцієнт підсилення латерального PNP транзистора становить величину порядку `β ≈ 15–35`. Це диктується фундаментальним компромісом планарної топології: неможливістю створити субмікронну базу без виділених масок дифузії та низькою рухливістю дірок у кремнії. 

Практичні інженерні розрахунки біполярних аналогових інтегральних схем завжди закладають найгірший випадок (*worst-case corner*) з розкидом `β = 10` за мінімальної робочої температури −55 °C та `β = 50` за максимальної температури +125 °C, проектуючи схемотехніку струмових дзеркал так, щоб похибка передачі струму не залежала від величини базового струму $I_B$.
