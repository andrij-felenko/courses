# 🔌 Порівняння інтегральних PNP-структур у планарних технологіях

У класичних кремнієвих монолітних інтегральних схемах формування транзисторів p-n-p типу стикається з технологічним обмеженням: базовий планарний процес оптимізовано виключно під високошвидкісні вертикальні n-p-n прилади. Щоб забезпечити схемотехнічні потреби в комплементарних ключах, генераторах струму, вихідних каскадах та зсувачах рівня без значного подорожчання кристала, інженери розробили кілька топологічних і технологічних конфігурацій PNP-структур. Нижче наведено всебічне зіставлення чотирьох основних різновидів інтегральних PNP-транзисторів за їхньою фізичною конструкцією, електричними параметрами, обмеженнями підключення, топологічними правилами проектування (DRC), захистом від замикання на підкладку, стійкістю до засувки (latch-up) та виробничою складністю.

## Порівняльна матриця топологій PNP у біполярних процесах

| Параметр | Латеральний PNP (Lateral PNP) | Субстратний PNP (Substrate PNP) | Розділений латеральний PNP (Split-Collector) | Вертикальний ізольований PNP (Complementary Bipolar) |
| :--- | :--- | :--- | :--- | :--- |
| **Орієнтація струму** | Горизонтальна (латеральна) вздовж поверхні | Вертикальна (від поверхні вглиб підкладки) | Горизонтальна (латеральна) радіальна | Вертикальна (крізь тонкий базовий p-шар) |
| **Додаткові маски процесу** | **0** (нульова вартість) | **0** (нульова вартість) | **0** (нульова вартість) | **3–5 додаткових масок** (+40–60% вартості) |

| **Напруга пробою BV_CEO** | 30 – 50 В | 30 – 50 В | 30 – 50 В | 15 – 40 В |

| **Стійкість до Latch-up** | Середня (потребує охоплюючого n⁺ кільця) | Висока (відсутній паразитний тиристор) | Середня (потребує суворого DRC-контролю) | Абсолютна (за діелектричної ізоляції SOI) |
| **Займана площа на кристалі** | Середня / велика (охоплююче кільце) | Мала (компактний вертикальний стек) | Велика (багатосегментна топологія) | Велика (потрібна ізолююча кишеня та діелектрик) |
| **Головна схемотехнічна роль** | Струмові дзеркала, зсувачі рівня, активні навантаження | Емітерні повторювачі, вихідні каскади (Push-Pull) | Прецизійні дільники струму, фазорозщеплювачі | Високошвидкісні ОП, RF-тракти, АЦП/ЦАП |

## 1. Латеральний PNP-транзистор (Lateral PNP)

### Конструкція
У слаболегованій епітаксійній n-кишені за допомогою єдиної маски базової дифузії NPN одночасно формуються дві p-області. Центральна кругла або восьмикутна область слугує емітером, а зовнішнє замкнене кільце — колектором. Базою є тіло n-епітаксії між ними. Знизу під епітаксією розміщується високолегований прихований шар `n⁺ NBL`, який відбиває дірки назад до поверхні кристала та пригнічує паразитний вертикальний витік у підкладку.

```
+─────────────────────────────────────────────────────────────────────────────+
|                         Поверхневий оксид SiO₂                              |
+───────────────┬──────────────────────┬───────────────┬──────────────────────+
|               |  Контакт B   p (E)   |    p (C)      |                      |
|  p⁺ ізоляція  |    (n⁺)      емітер  |   колектор    |     p⁺ ізоляція      |
|               ├──────────────────────┴───────────────┤                      |
|               |          n-епітаксія (база)          |                      |
|               ├──────────────────────────────────────┤                      |
|               |          n⁺ прихований шар (NBL)     |                      |
+───────────────┴──────────────────────────────────────┴──────────────────────+
|                             p-підкладка (V_EE)                              |
+─────────────────────────────────────────────────────────────────────────────+
```

### Переваги
- **Повна схемотехнічна свобода**: колектор є повністю ізольованим від підкладки та живлення, його можна підключати до будь-якого вузла електричної схеми (наприклад, до бази наступного каскаду чи до вихідної клеми).
- **Висока напруга пробою емітер–база `BV_EBO ≈ 40–60 В`**: оскільки емітер і база леговані помірно (`~10¹⁸ см⁻³` та `~10¹⁶ см⁻³`), тунельний лавинний пробій настає за високих напруг, що захищає вхідні каскади мікросхем від диференціальних перенапруг.
- **Висока напруга пробою колектор–емітер `BV_CEO`**: емпіричний зв'язок Міллера визначає `BV_CEO = BV_CBO / (β)^(1/n)`. Оскільки `β` латерального PNP мале (20–40 проти 200 у NPN), напруга `BV_CEO` виявляється значно ближчою до максимальної напруги пробою переходу `BV_CBO ≈ 50–70 В`.
- **Нульова додаткова вартість**: формується автоматично в стандартному біполярному техпроцесі без внесення змін у технологічний маршрут.

### Недоліки
- Низький коефіцієнт підсилення струму (`β ≈ 10–50`) через рекомбінацію в широкій літографічній базі (`W_B ≈ 1.5–3 мкм`) та на межі розділу `Si-SiO₂`.
- Вкрай низька швидкодія (`f_T < 8 МГц`) через тривалий час дифузійного прольоту дірок через базу.

## 2. Субстратний PNP-транзистор (Substrate PNP)

### Конструкція
Формується за допомогою дифузії p-базового шару NPN у спеціально виділену n-епітаксійну кишеню, під якою **навмисно не формують** прихований шар `n⁺ NBL`. 
- Поверхнева дифузійна p-область слугує **емітером**.
- n-епітаксійна кишеня слугує **базою**.
- Об'ємна монокристалічна **p-підкладка** (Substrate) слугує **колектором**.

Струм інжектованих дірок тече вертикально вниз крізь епітаксійний шар безпосередньо в підкладку.

```
+─────────────────────────────────────────────────────────────+
|                     Поверхневий оксид                       |
+───────────────┬─────────────────────────────┬───────────────+
|               |  Контакт B   Контакт E (p)  |               |
|  p⁺ ізоляція  |    (n⁺)      (дифузія бази) |  p⁺ ізоляція  |
|               ├─────────────────────────────┤               |
|               |      n-епітаксія (база)     |               |
+───────────────┴─────────────────────────────┴───────────────+
|                     p-підкладка (Колектор)                  |
|                    (з'єднана з шиною V_EE)                  |
+─────────────────────────────────────────────────────────────+
```

### Переваги
- **Кращий коефіцієнт підсилення (`β ≈ 40–120`)**: вертикальний струм протікає в глибині кремнію, де відсутня поверхнева рекомбінація на оксидних пастках `Si-SiO₂`.
- **Вища гранична частота (`f_T ≈ 20–60 МГц`)**: вертикальна товщина бази задається товщиною епітаксійного шару під p-дифузією (зазвичай 1–2 мкм), а площа переходу є компактною.
- **Мала площа на кристалі**: не потрібне габаритне охоплююче колекторне кільце.
- **Висока здатність навантаження**: підкладка має велику площу та ефективно розсіює тепло.

### Недоліки
- **Жорстке обмеження топології**: колектор фізично є спільним тілом усього кристала, тому він нерозривно з'єднаний із найнижчим потенціалом живлення (`V_EE` або `GND`). Транзистор може працювати **виключно за схемою емітерного повторювача** (зі спільним колектором). Його неможливо використати як навантажувальне струмове дзеркало біля шини `V⁺`.
- **Впорскування шуму в підкладку**: весь колекторний струм стікає в спільну підкладку ІС, створюючи паразитні падіння напруги та перехресні завади для чутливих вузлів схеми.

## 3. Розділений латеральний PNP (Split-Collector Lateral PNP)

### Конструкція
Латеральна структура, в якій зовнішнє колекторне кільце фізично розрізано фотолітографією на дві, три або більше ізольованих дугових секцій (`C₁`, `C₂`, `C₃`), кожна з яких має власний омічний контакт та металізацію.

```
                  +─────────────+
                  |  Колектор C₁| (50% дуги)
                  +──────┬──────+
                         |
           +─────────────┴─────────────+
           |       Емітер E (p)        |
           +─────────────┬─────────────+
                         |
                  +──────┴──────+
                  |  Колектор C₂| (50% дуги)
                  +─────────────+
```

### Переваги
- **Прецизійний поділ струмів**: пропорція між струмами колекторів `I_C1 / I_C2` строго дорівнює відношенню кутових дуг сегментів маски (наприклад, 1:1, 1:2, 1:4).
- **Ідеальне термічне та технологічне узгодження**: оскільки обидва колектори оточують один спільний емітер на відстані кількох мікронів, будь-які градієнти температури кристала або флуктуації легування впливають на них абсолютно однаково.
- **Економія площі**: заміна двох окремих узгоджених PNP-транзисторів одним багатоколекторним приладом зменшує займану площу ізольованої n-кишені на 40–50%.

### Недоліки
- Підвищена міжелектродна ємність між колекторними сегментами, що може спричиняти паразитний ємнісний зворотний зв'язок на високих частотах.
- Потребує суворого дотримання правил симетрії металізації, щоб падіння напруги на тонких алюмінієвих доріжках не спотворювали точність поділу струмів.

## 4. Вертикальний ізольований PNP (Complementary Bipolar)

### Конструкція
Повноцінний вертикальний PNP-транзистор, виготовлений за спеціалізованим комплементарним біполярним техпроцесом (наприклад, VIP™ від National Semiconductor або технологіями Dielectric Isolation). 
Процес містить окремий глибокий прихований шар `p⁺ PBL`, додатковий ізольований епітаксійний карман або дифузійний n-базовий профіль та сильнолегований поверхневий `p⁺` емітер.

```
+─────────────────────────────────────────────────────────────+
|                     Поверхневий оксид                       |
+───────────────┬─────────────────────────────┬───────────────+
|               |   E (p⁺)   B (n⁺)   C (p⁺)  |               |
|  SiO₂ траншея ├─────────────────────────────┤  SiO₂ траншея |
|               |        p-кишеня (колектор)  |               |
|               ├─────────────────────────────┤               |
|               |       p⁺ прихований шар     |               |
+───────────────┴─────────────────────────────┴───────────────+
|                     Підкладка p-Si                          |
+─────────────────────────────────────────────────────────────+
```

### Переваги
- **Повна симетрія характеристик**: швидкодія (`f_T ≈ 1–10 ГГц`) та коефіцієнт підсилення (`β ≈ 150–300`) повністю відповідають параметрам вертикального NPN-транзистора.
- Відсутність поверхневих витоків та наднизький рівень струмового шуму на низьких частотах.
- Повна електрична ізоляція колектора за допомогою діелектричних канавок (Trench Isolation) або зустрічних p-n переходів.

### Недоліки
- **Висока собівартість пластини**: потребує введення 3–5 додаткових масок фотолітографії, складних циклів високотемпературної дифузії та іонної імплантації, що збільшує вартість кристала на 40–60% і знижує вихід придатних мікросхем.

## Топологічні правила проектування (DRC) та захист від Latch-up

Під час трасування латеральних біполярних транзисторів на кристалі інженер з фізичного проектування повинен суворо дотримуватися специфічних топологічних обмежень:

1. **Мінімальний зазор між емітером та колектором (`W_B`)**:
   - Обмежується правилами роздільної здатності літографії та глибиною бічного підтравлювання/розтікання під маскою.
   - Занадто малий зазор спричиняє ефект змикання збіднених областей (*punch-through*), коли колекторний перехід електрично замикається на емітер за напруги всього кілька вольтів.
2. **Охоплююче базове кільце `n⁺`**:
   - Навколо p-колекторного кільця обов'язково розміщують замкнене високолеговане кільце `n⁺` контакту кишені, підключене до бази або до найвищого потенціалу `V⁺`.
   - Воно знижує розподілений опір тіла кишені `r_bb'` та перехоплює дірки, які вирвалися за межі колектора, запобігаючи їхньому потраплянню в сусідні кишені.
3. **Захисні кільця від тиристорного замикання (Guard Rings)**:
   - Сукупність p-емітера, n-кишені, p-підкладки та сусідньої n-кишені NPN-транзистора утворює чотиришарову паразитну структуру p-n-p-n (тиристор).
   - Якщо латеральний PNP заходить у глибоке насичення, дірки масивно викидаються в підкладку, викликаючи спрацьовування засувки (*latch-up*).
   - Захисні `p⁺` кільця в підкладці навколо латерального транзистора, заземлені на `V_EE`, утворюють дірковий дренаж і повністю блокують позитивний зворотний зв'язок тиристора.

## Латеральний PNP проти pMOS у технологіях BiCMOS

З появою технологій BiCMOS (поєднання біполярних та КМОН приладів на одному кристалі) виникла альтернатива: використовувати p-канальні польові транзистори (pMOS) замість латеральних PNP для активних навантажень та зсуву рівня.

Зіставлення показує чіткий схемотехнічний поділ:
1. **pMOS-транзистор**:
   - Має нульовий постійний струм затвора (`I_G ≈ 0`).
   - Дозволяє розмах вихідної напруги від шини до шини (Rail-to-Rail) з малим залишковим опором каналу `R_on`.
   - Проте має високий рівень низькочастотного флікер-шуму (`1/f`) через поверхневі пастки на межі підзатворного оксиду, низьку крутизну `g_m = √(2 · μ · C_ox · (W/L) · I_D)` при малих мікроамперних струмах та сильний розкид порогової напруги `V_th` (до десятків мілівольтів).
2. **Латеральний PNP-транзистор**:
   - Забезпечує строго експоненційну вольт-амперну характеристику `I_C = I_S · e^(V_EB / V_T)`.
   - Має високу крутизну `g_m = I_C / V_T`, що не залежить від геометрії каналу, і відтворювану різницю напруг емітер–база `ΔV_EB = V_T · ln(N)`.
   - Має значно нижчий рівень низькочастотного шуму `1/f`, ніж pMOS.

Тому навіть у сучасних BiCMOS-мікросхемах латеральні та субстратні PNP-транзистори залишаються безальтернативною основою для прецизійних джерел опорної напруги (Bandgap Reference) та малошумливих аудіотрактів.

## Порівняння SPICE-параметрів типових інтегральних транзисторів

У програмах схемотехнічного моделювання (SPICE) модель Гуммеля — Пуна відображає кардинальні відмінності між структурами:

```
.MODEL Q_LAT_PNP  PNP (IS=1E-16 BF=35  BR=2  VAF=40  TF=25N  CJE=0.6P CJC=1.2P)
.MODEL Q_SUB_PNP  PNP (IS=5E-16 BF=80  BR=1  VAF=60  TF=3.5N CJE=0.8P CJC=3.5P)
.MODEL Q_VERT_PNP PNP (IS=1E-17 BF=200 BR=5  VAF=100 TF=0.1N CJE=0.2P CJC=0.3P)
.MODEL Q_VERT_NPN NPN (IS=1E-16 BF=250 BR=4  VAF=120 TF=0.15N CJE=0.3P CJC=0.2P)
```

Зверніть увагу на параметр `TF` (ідеальний час прямого перенесення вперед): у латерального PNP він становить 25 нс (що дає `f_T ≈ 5 МГц`), тоді як у вертикального ізольованого PNP він дорівнює лише 0.1 нс (`f_T ≈ 1.5 ГГц`).

## Рекомендації щодо вибору структури в схемотехніці

1. **Якщо потрібне струмове дзеркало, зсувач рівня від позитивної шини живлення або вхідний каскад із широким діапазоном напруг у масовій дешевій ІС**:
   - Однозначний вибір — **стандартний латеральний PNP** (охоплююче кільце, нульова додаткова вартість).
2. **Якщо потрібен вихідний буферний каскад або потужний емітерний повторювач, підключений до шини `GND`**:
   - Найкращий вибір — **субстратний PNP** (вищий `β`, більший допустимий струм, вища гранична частота `f_T`).
3. **Якщо потрібно розділити або здублювати опорний струм у стабілізаторі чи перемножувачі**:
   - Застосовують **розділений латеральний PNP** (Split-Collector).
4. **Якщо розробляється прецизійний операційний підсилювач із смугою понад 50–100 МГц або високочастотний тракт зв'язку**:
   - Застосовують **вертикальний ізольований PNP** у комплементарному біполярному (CB) процесі, свідомо сплачуючи за додаткові маски.
