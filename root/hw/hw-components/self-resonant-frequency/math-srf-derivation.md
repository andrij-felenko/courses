# 🧮 Виведення імпедансу, екстремумів та фази для реальних RLC-компонентів

Розрахунок поведінки реальних компонентів на високих частотах спирається на точний аналіз їхніх комплексних передавальних функцій. Коли інженер бачить графік імпедансу з V-подібним дном для конденсатора або гострим піком для котушки, за цими кривими стоїть строгий алгебраїчний апарат: пошук коренів характеристичних рівнянь, екстремумів модуля комплексного числа, аналіз чутливості до допусків, математика частотно-залежних втрат, розрахунок перехідних процесів у часовій області та матричний перерахунок S-параметрів вимірювальних трактів.

Без точного математичного виведення неможливо кількісно передбачити, де саме розташований мінімум чи максимум імпедансу, наскільки глибокою є резонансна яма, який точний фазовий зсув створює компонент у колі зворотного зв'язку і якої амплітуди досягне паразитний антирезонансний викид при паралельному сполученні двох ємностей. Нижче наведено повні аналітичні викладки для послідовної RLC-моделі конденсатора, паралельної моделі котушки індуктивності, двоконденсаторної мережі живлення, аналізу перехідних процесів при стрибку навантаження та двопортової матриці вимірювального стенда.

---

### 1. Послідовна RLC-модель конденсатора

Еквівалентна схема заміщення конденсатора складається з послідовно з'єднаних номінальної ємності `C`, еквівалентної індуктивності виводів та внутрішніх електродів `ESL` (позначимо для стислості як `L`) та активного опору втрат `ESR` (позначимо як `R`).

У просторі комплексної частоти Лапласа `s = σ + j·ω` операторний імпеданс записується як сума імпедансів трьох елементів:

```
Z_C(s) = R + s·L + 1 / (s·C)
       = ( s²·L·C + s·R·C + 1 ) / ( s·C )       [зведення до спільного знаменника]
```

Для аналізу реакції кола на гармонічний сигнал усталеного режиму підставляємо значення `s = j·ω` (де `j = √(-1)` — уявна одиниця):

```
Z_C(j·ω) = R + j·ω·L + 1 / (j·ω·C)
         = R + j·ω·L - j / (ω·C)                [множення чисельника й знаменника на j]
         = R + j·( ω·L - 1 / (ω·C) )            [винесення уявної одиниці j]
```

Дійсна частина імпедансу `Re(Z_C) = R = ESR` відповідає за незворотне розсіювання енергії у вигляді тепла (джоулів нагрів обкладок та діелектричні втрати). Уявна частина `Im(Z_C) = X(ω) = ω·L - 1 / (ω·C)` описує коливальний обмін енергією між електричним полем діелектрика та магнітним полем струму у виводах.

#### Модуль імпедансу та строге виведення точки мінімуму

Модуль комплексного числа `Z = Re + j·Im` визначається як евклідова довжина радіус-вектора на комплексній площині:

```
|Z_C(ω)| = √( (Re(Z_C))² + (Im(Z_C))² )
         = √( R² + ( ω·L - 1 / (ω·C) )² )
```

Щоб знайти екстремум функції `|Z_C(ω)|`, знайдемо точку, де її перша похідна за кутовою частотою `ω` перетворюється на нуль. Оскільки операція взяття квадратного кореня є монотонно зростаючою функцією для будь-яких невід'ємних чисел, точки екстремуму функції `|Z_C(ω)|` строго збігаються з точками екстремуму підкореневого виразу `f(ω)`:

```
f(ω) = R² + ( ω·L - 1 / (ω·C) )²
```

Диференціюємо `f(ω)` за змінною `ω`, застосовуючи правило диференціювання складеної функції:

```
df/dω = d/dω ( R² ) + d/dω ( ( ω·L - 1 / (ω·C) )² )
      = 0 + 2 · ( ω·L - 1 / (ω·C) ) · d/dω ( ω·L - 1 / (ω·C) )   [похідна зовнішньої функції]
      = 2 · ( ω·L - 1 / (ω·C) ) · ( L - (-1) / (ω²·C) )          [похідна внутрішньої функції]
      = 2 · ( ω·L - 1 / (ω·C) ) · ( L + 1 / (ω²·C) )             [розкриття подвійного мінуса]
```

Прирівнюємо отриману похідну до нуля для пошуку стаціонарних точок:

```
2 · ( ω·L - 1 / (ω·C) ) · ( L + 1 / (ω²·C) ) = 0
```

Оскільки параметри `L > 0` та `C > 0` є фізично додатними величинами, для будь-якої частоти `ω > 0` другий множник строго більший за нуль:

```
L + 1 / (ω²·C) > 0
```

Отже, рівність нулю можлива тоді й лише тоді, коли перший множник дорівнює нулю:

```
ω·L - 1 / (ω·C) = 0
ω·L = 1 / (ω·C)                                 [умова резонансу реактивностей]
ω² = 1 / ( L · C )                              [множення обох частин на ω / L]
ω_0 = 1 / √( L · C )                            [кутова резонансна частота]
```

Перехід від кутової частоти `ω` (вимірюваної в радіанах за секунду) до лінійної частоти `f` (у герцах) через співвідношення `ω = 2·π·f` дає класичну формулу власної резонансної частоти:

```
f_SRF = ω_0 / ( 2 · π ) = 1 / ( 2 · π · √( L · C ) )
```

Обчислимо точне значення імпедансу на цій резонансній частоті `ω_0`:

```
|Z_C(ω_0)| = √( R² + ( ω_0·L - 1 / (ω_0·C) )² )   [підстановка кутової частоти резонансу ω_0]
           = √( R² + 0² )                         [умова резонансу: ω_0·L = 1 / (ω_0·C)]
           = R = ESR                              [вилучення кореня: √(R²) = R]
```

Щоб строго довести, що ця точка є саме глобальним мінімумом, а не максимумом чи перегином, знайдемо другу похідну `d²f/dω²` в точці `ω_0`:

```
d²f/dω² = 2 · [ d/dω ( ω·L - 1 / (ω·C) ) · ( L + 1 / (ω²·C) ) + ( ω·L - 1 / (ω·C) ) · d/dω ( L + 1 / (ω²·C) ) ]
        = 2 · [ ( L + 1 / (ω²·C) )² + ( ω·L - 1 / (ω·C) ) · ( -2 / (ω³·C) ) ]
```

Підставивши у другу похідну значення `ω = ω_0`, де `ω_0·L - 1 / (ω_0·C) = 0` та `1 / (ω_0²·C) = L`:

```
d²f/dω² |_(ω=ω_0) = 2 · [ ( L + L )² + 0 ]
                  = 2 · ( 2·L )²
                  = 8 · L² > 0                  [строго більше нуля]
```

Оскільки друга похідна строго додатна, точка `f_SRF` є єдиним строго доведеним глобальним мінімумом функції імпедансу.

#### Фазова характеристика та групова затримка

Фазовий кут `φ(ω) = arg(Z_C)` визначає просторовий зсув між вектором напруги та вектором струму:

```
φ(ω) = arctan( Im(Z_C) / Re(Z_C) )
     = arctan( ( ω·L - 1 / (ω·C) ) / R )
```

Дослідимо поведінку фази на трьох ключових ділянках частотної осі:

```
1) Нижні частоти (ω << ω_0):
   ω·L << 1 / (ω·C)
   φ(ω) ≈ arctan( -1 / (ω·R·C) )
   При ω → 0: φ(ω) → arctan(-∞) = −π/2 (−90°)    [струм випереджає напругу на 90°]

2) Точка власного резонансу (ω = ω_0):
   ω_0·L = 1 / (ω_0·C)
   φ(ω_0) = arctan( 0 / R ) = 0°                [чисто активний опір, напруга й струм у фазі]

3) Високі частоти (ω >> ω_0):
   ω·L >> 1 / (ω·C)
   φ(ω) ≈ arctan( ω·L / R )
   При ω → ∞: φ(ω) → arctan(+∞) = +π/2 (+90°)   [напруга випереджає струм на 90°]
```

Групова затримка фази (*Group Delay* `τ_g`) показує час затримки обвідної широкосмугового сигналу під час проходження крізь компонент і визначається як від'ємна похідна фази за частотою:

```
τ_g(ω) = - dφ/dω = - d/dω [ arctan( ( ω·L - 1 / (ω·C) ) / R ) ]
```

За правилом диференціювання арктангенса `d/dx (arctan(x)) = 1 / (1 + x²)`:

```
τ_g(ω) = - ( 1 / ( 1 + ( ( ω·L - 1 / (ω·C) ) / R )² ) ) · ( 1 / R ) · ( L + 1 / (ω²·C) )
       = - ( R · ( L + 1 / (ω²·C) ) ) / ( R² + ( ω·L - 1 / (ω·C) )² )
```

У точці резонансу `ω = ω_0` значення групової затримки сягає екстремальної величини:

```
τ_g(ω_0) = - ( R · ( L + L ) ) / R² = - ( 2 · L ) / R = - 2 · τ_L
```

де `τ_L = L / R` — постійна часу індуктивності та активного опору. Цей вираз показує, що поблизу власного резонансу фазова крива зазнає найстрімкішого перепаду, викликаючи максимальну дисперсію крутих фронтів швидкісних імпульсних сигналів.

#### Полюси, нулі та комплексна площина Лапласа

Розглянемо розташування нулів операторного імпедансу `Z_C(s) = 0`, що визначають власні коливання системи без зовнішнього збудження:

```
s²·L·C + s·R·C + 1 = 0
s² + s · ( R / L ) + 1 / ( L · C ) = 0           [ділення на L·C]
```

Введемо стандартні позначення теорії коливань: незгасаючу власну частоту `ω_0 = 1 / √(L·C)` та коефіцієнт затухання `α = R / (2·L)`:

```
s² + 2·α·s + ω_0² = 0
```

Корені квадратного рівняння (полюси провідності `Y(s)`):

```
s_1,2 = -α ± √( α² - ω_0² )
```

У практичних конденсаторах втрати малі, тому `α < ω_0` (режим слабкого демпфування). Підкореневий вираз стає від'ємним:

```
s_1,2 = -α ± j · √( ω_0² - α² ) = -α ± j · ω_d
```

де `ω_d = √( ω_0² - α² )` — власна частота затухаючих вільних коливань. Дійсна частина коренів `-α = -R / (2·L)` розташована в лівій півплощині комплексної площини й визначає швидкість експоненційного згасання перехідного процесу. Уявна частина `ω_d` визначає частоту виникаючого високочастотного дзвону при стрибкоподібній зміні струму.

Залежно від величини активного опору втрат `R` можливі три фізичні режими роботи кола:

1. **Коливальний режим слабкого демпфування (`R < 2·√(L/C)` або `Q > 0.5`):** Корені є комплексно-спряженими. Перехідний процес містить затухаючі синусоїдальні осциляції на частоті `ω_d`. На графіку імпедансу спостерігається чітко виражений мінімум, глибина якого обернено пропорційна `Q`.
2. **Критичне демпфування (`R = 2·√(L/C)` або `Q = 0.5`):** Підкореневий вираз обнуляється, і система має два кратні дійсні корені `s_1 = s_2 = -α = -ω_0`. Перехідний процес є найшвидшим із можливих без жодного перерегулювання чи осциляцій.
3. **Аперіодичний режим сильного демпфування (`R > 2·√(L/C)` або `Q < 0.5`):** Підкореневий вираз додатний, корені розпадаються на два окремі від'ємні дійсні числа `s_1 = -α + √(α² - ω_0²)` та `s_2 = -α - √(α² - ω_0²)`. Швидкість реакції сповільнюється, а V-подібний провал імпедансу повністю згладжується.

Добротність контуру `Q` визначається через коефіцієнт затухання `α` та резонансну частоту `ω_0`:

```
Q = ω_0 / ( 2 · α ) = ( 1 / √(L·C) ) / ( R / L ) = ( 1 / R ) · √( L / C )
```

Смуга частот `Δf` на рівні подвоєння потужності втрат (−3 дБ за напругою, де `|Z| = √2 · R`):

```
Δf = f_SRF / Q = ( R / ( 2 · π · L ) )
```

### 2. Паралельна RLC-модель котушки індуктивності

Еквівалентна схема реальної котушки складається з індуктивності `L` з послідовним опором дроту `R_s` (DCR та втрати ACR), що з'єднані паралельно з міжелектродною паразитною ємністю `C_p`.

Комплексна провідність (адмітанс) схеми є сумою провідностей двох паралельних гілок:

```
Y_L(j·ω) = 1 / ( R_s + j·ω·L ) + j·ω·C_p
```

Перетворимо перший дріб, помноживши чисельник і знаменник на комплексно-спряжений вираз `R_s - j·ω·L`:

```
Y_L(j·ω) = ( R_s - j·ω·L ) / ( R_s² + ω²·L² ) + j·ω·C_p
         = R_s / ( R_s² + ω²·L² ) + j·( ω·C_p - ( ω·L ) / ( R_s² + ω²·L² ) )
```

Комплексний імпеданс `Z_L(j·ω) = 1 / Y_L(j·ω)` після спрощення набуває вигляду:

```
Z_L(j·ω) = ( R_s + j·ω·L ) / ( ( 1 - ω²·L·C_p ) + j·ω·R_s·C_p )
```

#### Умова резонансу фази (нульова реактивність)

Частота, на якій вхідний імпеданс стає чисто активним (фазовий кут `φ = 0`), визначається умовою обнулення уявної частини адмітансу `Im(Y_L) = 0`:

```
ω_0 · C_p - ( ω_0 · L ) / ( R_s² + ω_0² · L² ) = 0
```

Оскільки `ω_0 > 0`, ділимо обидві частини на `ω_0`:

```
C_p = L / ( R_s² + ω_0² · L² )
R_s² + ω_0² · L² = L / C_p                       [множення на знаменник та ділення на C_p]
ω_0² · L² = L / C_p - R_s²                       [віднімання R_s²]
ω_0² = 1 / ( L · C_p ) - R_s² / L²               [ділення на L²]
ω_0 = √( 1 / ( L · C_p ) - ( R_s / L )² )        [точна кутова частота антирезонансу]
```

З отриманої точної формули видно, що активний опір проводу `R_s` завжди дещо знижує фактичну частоту власного резонансу порівняно з ідеальною формулою Томсона. Проте для якісних котушок, де `R_s << √(L/C_p)`, членом `(R_s/L)²` можна з високою точністю знехтувати:

```
f_SRF ≈ 1 / ( 2 · π · √( L · C_p ) )
```

#### Розрахунок максимального пікового імпедансу

Знайдемо модуль імпедансу в точці резонансу `ω = ω_0`. Оскільки на цій частоті уявна частина адмітансу дорівнює нулю, повний імпеданс визначається виключно оберненою величиною дійсної частини провідності:

```
|Z_L(ω_0)| = 1 / Re(Y_L(ω_0)) = ( R_s² + ω_0² · L² ) / R_s
```

Підставивши виведене вище значення `R_s² + ω_0² · L² = L / C_p`:

```
|Z_L(ω_0)| = ( L / C_p ) / R_s = L / ( R_s · C_p )
```

Враховуючи, що добротність котушки `Q = ( ω_0 · L ) / R_s ≈ ( 1 / R_s ) · √( L / C_p )`, а характеристичний хвильовий опір контуру `Z_0 = √( L / C_p )`:

```
|Z_max| = ( √(L/C_p) / R_s ) · √(L/C_p) = Q · Z_0 = Q² · R_s
```

Цей результат наочно демонструє, чому котушка з високою добротністю `Q` породжує гігантський пік імпедансу: опір постійному струму `R_s` (наприклад, 0.5 Ом) на резонансній частоті при `Q = 100` множиться на коефіцієнт `Q² = 10 000`, перетворюючись на 5 кОм ізолюючого бар'єра.

#### Частотна залежність добротності та скін-ефект

У реальних дроселях опір `R_s` не є сталою величиною, а зростає з частотою через скін-ефект у провіднику. Глибина проникнення струму в мідь визначається формулою `δ = √( ρ / ( π · f · μ_0 · μ_r ) )`. Коли товщина дроту перевищує `2·δ`, струм витісняється до поверхні, а опір зростає як `R_s(f) = R_DC · ( 1 + k · √f )`.

Добротність котушки як функція частоти описується виразом:

```
Q(f) = ( 2 · π · f · L ) / ( R_DC · ( 1 + k · √f ) ) · ( 1 - ( f / f_SRF )² )
```

Ця формула пояснює характерну куполоподібну форму паспортного графіка `Q(f)`: на низьких частотах чисельник зростає швидше за знаменник, і добротність росте; проте поблизу частоти `f_Qmax ≈ 0.3–0.5 · f_SRF` зростання опору втрат через скін-ефект та шунтуюча дія множника `(1 - (f/f_SRF)²)` пересилюють індуктивність, змушуючи `Q` різко спадати до нуля в точці власного резонансу.

### 3. Математика паралельного антирезонансу двох конденсаторів

Розгляньмо паралельне з'єднання двох реальних керамічних конденсаторів:
- Перший конденсатор (великий номінал): ємність `C_1`, паразитна індуктивність `L_1`, опір `R_1`;
- Другий конденсатор (малий номінал): ємність `C_2`, паразитна індуктивність `L_2`, опір `R_2`, де `C_1 >> C_2` та `L_1 ≥ L_2`.

Власні резонансні частоти кожного з конденсаторів окремо становлять:

```
ω_SRF1 = 1 / √( L_1 · C_1 )
ω_SRF2 = 1 / √( L_2 · C_2 )
```

У проміжному частотному діапазоні між двома власними резонансами (`ω_SRF1 < ω < ω_SRF2`):
- Для першого конденсатора частота `ω > ω_SRF1`, тому його ємнісна складова знехтовно мала, і він поводиться як індуктивність: `Z_1(j·ω) ≈ R_1 + j·ω·L_1`.
- Для другого конденсатора частота `ω < ω_SRF2`, тому його індуктивність ще не проявляється, і він діє як чиста ємність: `Z_2(j·ω) ≈ R_2 + 1 / (j·ω·C_2)`.

Загальний еквівалентний імпеданс паралельного з'єднання:

```
Z_total(j·ω) = ( Z_1(j·ω) · Z_2(j·ω) ) / ( Z_1(j·ω) + Z_2(j·ω) )
```

Дослідимо знаменник `Z_denom(j·ω) = Z_1(j·ω) + Z_2(j·ω)`:

```
Z_denom(j·ω) = ( R_1 + R_2 ) + j·( ω·L_1 - 1 / (ω·C_2) )
```

Знаменник являє собою повний імпеданс еквівалентного послідовного контуру, утвореного індуктивністю першого конденсатора `L_1` та ємністю другого конденсатора `C_2`. Модуль знаменника досягає абсолютного мінімуму на частоті антирезонансу:

```
ω_anti · L_1 - 1 / ( ω_anti · C_2 ) = 0
ω_anti = 1 / √( L_1 · C_2 )
f_anti = 1 / ( 2 · π · √( L_1 · C_2 ) )
```

Оскільки на цій частоті знаменник мінімізується до чисто активного опору `R_sum = R_1 + R_2`, увесь вираз `Z_total` досягає свого екстремального максимуму:

```
|Z_total(ω_anti)| ≈ ( |Z_1(ω_anti)| · |Z_2(ω_anti)| ) / ( R_1 + R_2 )
```

Оскільки на частоті `ω_anti` реактивні модулі збігаються: `|Im(Z_1)| = |Im(Z_2)| = ω_anti·L_1 = 1 / (ω_anti·C_2) = √( L_1 / C_2 ) = Z_0_anti`:

```
|Z_total(ω_anti)| ≈ ( Z_0_anti² ) / ( R_1 + R_2 ) = ( L_1 / C_2 ) / ( R_1 + R_2 )
```

Добротність цього паразитного піку шини живлення:

```
Q_anti = Z_0_anti / ( R_1 + R_2 ) = ( √( L_1 / C_2 ) ) / ( R_1 + R_2 )
```

#### Критерій оптимального демпфування (Optimum Damping Condition)

Щоб паразитний антирезонансний пік повністю зник (тобто добротність контуру знизилася до `Q_anti ≤ 1`, коли амплітудно-частотна характеристика стає монотонною без локальних викидів), сумарний активний опір втрат мусить задовольняти нерівності:

```
R_1 + R_2 ≥ √( L_1 / C_2 )
```

Цей строгий висновок є математичним обґрунтуванням інженерного методу демпфування шин живлення: для ліквідації небезпечного антирезонансу необхідно або штучно обирати конденсатори великої ємності з помірним опором `ESR` (наприклад, полімерний тантал замість наднизькоомної кераміки), або відмовлятися від комбінування різних номіналів на користь масивів однакових ємностей `C_1 = C_2 = ... = C_N`.

### 4. Динаміка перехідного процесу при стрибку навантаження

Коли цифрове навантаження споживає миттєвий сходинковий імпульс струму амплітудою `ΔI` з фронтом наростання, значно коротшим за чверть періоду резонансу `t_rise << 1 / (4·f_SRF)`, напруга на шині живлення зазнає перехідного коливального процесу.

Диференціальне рівняння другого порядку для відхилення напруги `v(t)` на виході RLC-ланцюга описується класичним законом:

```
L · C · d²v/dt² + R · C · dv/dt + v(t) = 0
```

Розв'язок для випадку слабкого демпфування (`R < 2·√(L/C)`) з початковими умовами `v(0) = 0` та `dv/dt|_(t=0) = - ΔI / C`:

```
v(t) = - ( ΔI / ( ω_d · C ) ) · exp( - α · t ) · sin( ω_d · t )
```

де `α = R / (2·L)` — коефіцієнт експоненційного затухання, а `ω_d = √( 1/(L·C) - α² )` — частота власних затухаючих коливань.

Перший екстремум (максимальне просідання напруги `ΔV_max`) досягається в момент часу `t_peak`:

```
dv/dt = 0
d/dt [ exp(-α·t) · sin(ω_d·t) ] = 0
-α · sin(ω_d·t) + ω_d · cos(ω_d·t) = 0
tan(ω_d·t_peak) = ω_d / α = √( (2·L / (R·√(L·C)))² - 1 ) = √( 4·Q² - 1 ) ≈ 2·Q
```

Для високодобротного контуру (`Q >> 1`) значення `t_peak ≈ π / (2·ω_d) ≈ π / (2·ω_0) = 1 / (4·f_SRF)`. Підставивши `t_peak` у вираз для напруги, отримуємо пікове просідання:

```
ΔV_max ≈ ΔI · √( L / C ) · exp( - π / ( 4 · Q ) )
```

Ця формула пов'язує просторово-часову поведінку схеми з її частотними характеристиками: максимальний викид напруги прямо пропорційний характеристичному опору `Z_0 = √(L/C)` і майже не залежить від опору втрат `R`, якщо `Q > 5`. Звідси випливає фундаментальна вимога: для зменшення просідання напруги на надшвидких фронтах перемикання єдиним дієвим засобом є фізичне зменшення паразитної індуктивності `L = ESL` шляхом вдосконалення топології плати.

### 5. Аналіз чутливості SRF до технологічних допусків

Реальні компоненти мають статистичний розкид параметрів: ємність має допуск `ΔC / C` (наприклад, ±10% або ±20%), а паразитна індуктивність друкованої плати варіюється через технологічні допуски травлення доріжок та свердління отворів `ΔL / L` (близько ±15–20%).

Визначимо нормовану логарифмічну чутливість резонансної частоти `f_SRF` до зміни індуктивності `L` та ємності `C`:

```
S_L^(f_SRF) = ( ∂f_SRF / ∂L ) · ( L / f_SRF )
S_C^(f_SRF) = ( ∂f_SRF / ∂C ) · ( C / f_SRF )
```

Обчислимо часткову похідну за індуктивністю:

```
∂f_SRF / ∂L = ∂/∂L [ ( 2·π·√C )⁻¹ · L^(-1/2) ]
             = - ( 1/2 ) · ( 2·π·√C )⁻¹ · L^(-3/2)
             = - ( 1/2 ) · f_SRF / L
```

Звідси нормована чутливість за індуктивністю:

```
S_L^(f_SRF) = ( - ( 1/2 ) · f_SRF / L ) · ( L / f_SRF ) = -1/2 = -0.5
```

Аналогічно для ємності:

```
S_C^(f_SRF) = -1/2 = -0.5
```

Відносне відхилення власної резонансної частоти у лінійному наближенні повного диференціала:

```
df_SRF / f_SRF = S_L^(f_SRF) · ( dL / L ) + S_C^(f_SRF) · ( dC / C )
               = - 0.5 · ( dL / L ) - 0.5 · ( dC / C )
```

Знак мінус показує, що збільшення індуктивності монтажу або ємності призводить до пропорційного зниження резонансної частоти. Якщо ємність збільшилася на +20% (`dC/C = +0.20`), а паразитна індуктивність зросла на +30% (`dL/L = +0.30`), резонансна частота зміститься вниз приблизно на:

```
df_SRF / f_SRF ≈ - 0.5 · 0.30 - 0.5 · 0.20 = - 0.25 = -25%
```

Цей розрахунок доводить, що високочастотний декуплінг не можна розраховувати на єдину вузьку точку резонансу: через технологічний розкид фактична точка мінімуму імпедансу завжди розмивається в діапазоні не менше ±20–30% від номінального значення.

### 6. Матричне виведення 2-портового методу Shunt-Thru на VNA

Під час вимірювання наднизьких імпедансів досліджуваний компонент `Z_x` підключають паралельно до 50-омної лінії передачі між Портом 1 та Портом 2 векторного аналізатора кіл.

Матриця передачі ABCD (ланцюгова матриця) для паралельного двополюсника з комплексним імпедансом `Z_x` має стандартний вигляд:

```
[ A  B ]   [ 1      0 ]
[ C  D ] = [ 1/Z_x  1 ]
```

Співвідношення між матрицею ABCD та матрицею розсіювання S-параметрів для симетричного двопортовика з опорним імпедансом портів `Z_0 = 50 Ом`:

```
S21 = 2 / ( A + B / Z_0 + C · Z_0 + D )
```

Підставимо елементи матриці паралельного шунта `A = 1`, `B = 0`, `C = 1/Z_x`, `D = 1`:

```
S21 = 2 / ( 1 + 0 / Z_0 + ( 1 / Z_x ) · Z_0 + 1 )
    = 2 / ( 2 + Z_0 / Z_x )                     [спрощення знаменника]
    = ( 2 · Z_x ) / ( 2 · Z_x + Z_0 )           [множення чисельника й знаменника на Z_x]
```

Знайдемо аналітичний вираз для невідомого імпедансу `Z_x` через виміряний коефіцієнт прямої передачі `S21`:

```
S21 · ( 2 · Z_x + Z_0 ) = 2 · Z_x               [множення на знаменник]
2 · Z_x · S21 + Z_0 · S21 = 2 · Z_x
2 · Z_x · ( 1 - S21 ) = Z_0 · S21               [групування доданків із Z_x]
Z_x = ( Z_0 / 2 ) · ( S21 / ( 1 - S21 ) )       [точна формула вимірювання імпедансу]
```

Якщо досліджуваний імпеданс набагато менший за опорний опір портів (`|Z_x| << Z_0 / 2 = 25 Ом`), коефіцієнт передачі `|S21| << 1`, і знаменник `1 - S21 ≈ 1`. Тоді формула набуває гранично простого лінійного вигляду:

```
Z_x ≈ ( Z_0 / 2 ) · S21 = 25 · S21
```

Диференціал чутливості методу:

```
dZ_x / dS21 = ( Z_0 / 2 ) / ( 1 - S21 )² ≈ Z_0 / 2 = 25 Ом / одиницю S21
```

Постійна висока чутливість (25 Ом на повну шкалу S-параметра) дозволяє векторному аналізатору кіл упевнено вимірювати міліомні та субміліомні опори втрат ESR у керамічних конденсаторах аж до частот у кілька гігагерців.
