# 🧮 Оптична фізика TCO: модель Друде, плазмове відбиття та оптимізація Хааке

Електромагнітна поведінка прозорих провідних плівок (TCO) підпорядкована зв'язку між густиною вільних носіїв заряду, їхньою рухливістю та комплексною діелектричною проникністю матеріалу. Без кількісного розрахунку моделі Друде неможливо визначити, за якої саме концентрації легування край плазмового відбиття зміститься в інфрачервону область, не поглинаючи видиме світло, і як знайти оптимальну товщину плівки за критерієм якості Хааке.

## Комплексна діелектрична проникність та оптична провідність у моделі Друде

Вільний електронний газ у кристалічній ґратці оксиду зазнає дії змінного електричного поля світлової хвилі `E(t) = E₀ · exp(-i·ω·t)` та гальмування внаслідок розсіювання на фононах, іонізованих домішках і міжзеренних межах. Класичне рівняння руху для квазівільного електрона провідності з ефективною масою `m*` та середнім часом вільного пробігу `τ`:

```
m* · (d²x/dt² + γ · dx/dt) = -e · E(t)
```

де `γ = 1 / τ` — феноменологічна частота релаксації імпульсу носіїв, `e` — елементарний електричний заряд. Для гармонічного поля з циклічною частотою `ω` шукаємо стаціонарний розв'язок у формі зміщення `x(t) = x₀ · exp(-i·ω·t)`:

```
-m* · ω² · x(t) - i · m* · ω · γ · x(t) = -e · E(t)
m* · x(t) · (-ω² - i·ω·γ) = -e · E(t)     [винесення спільного множника]
x(t) = e · E(t) / (m* · (ω² + i·ω·γ))      [поділ на множник при x]
```

Густина електричного струму `J(t)`, створеного рухом ансамблю електронів з об'ємною концентрацією `n`, визначається швидкістю дрейфу `v(t) = dx/dt = -i · ω · x(t)`:

```
J(t)
= -n · e · v(t)                           [означення густини струму]
= i · n · e · ω · x(t)                    [підстановка швидкості v = -i·ω·x]
= i · n · e · ω · (e · E(t) / (m* · (ω² + i·ω·γ))) [підстановка зміщення x]
= (n · e² / (m* · (γ - i·ω))) · E(t)      [спрощення та перегрупування]
= σ(ω) · E(t)                             [закон Ома в диференціальній формі]
```

Звідси випливає комплексна оптична провідність Друде `σ(ω) = σ₁(ω) + i · σ₂(ω)`:

```
σ(ω)
= σ₀ / (1 - i · ω · τ)                    [де σ₀ = (n · e² · τ) / m* — статична провідність]
= σ₀ · (1 + i · ω · τ) / (1 + ω² · τ²)     [множення чисельника й знаменника на спряжене]
= σ₀ / (1 + ω² · τ²) + i · (σ₀ · ω · τ) / (1 + ω² · τ²) [розподіл на Re та Im]
```

Діелектрична індукція середовища `D(ω)` враховує як поляризацію зв'язаних електронів внутрішніх оболонок та іонного кістяка кристалічної ґратки (високочастотну діелектричну проникність `ε_inf`), так і відгук вільних носіїв:

```
D(ω) = ε₀ · ε_inf · E(t) + P_free(t) = ε₀ · ε(ω) · E(t)
```

Оскільки густина поляризації вільних носіїв `P_free(t) = -n · e · x(t) = i · J(t) / ω`, отримуємо зв'язок між комплексною діелектричною проникністю та провідністю:

```
ε(ω)
= ε_inf + i · σ(ω) / (ε₀ · ω)             [зв'язок діелектричної проникності та провідності]
= ε_inf - (n · e²) / (ε₀ · m* · (ω² + i·ω·γ)) [підстановка провідності σ(ω)]
= ε_inf · (1 - ω_p² / (ω² + i·ω·γ))       [винесення ε_inf за дужки]
```

де циклічна плазмова частота нелегованого вакууму або фонового середовища `ω_p` визначається концентрацією носіїв `n` та високочастотною діелектричною сталою `ε_inf`:

```
ω_p² = (n · e²) / (ε₀ · ε_inf · m*)
```

Розділимо комплексну функцію `ε(ω) = ε₁(ω) + i · ε₂(ω)` на дійсну та уявну частини:

```
ε(ω)
= ε_inf - (n · e² / (ε₀ · m*)) · (ω² - i·ω·γ) / (ω⁴ + ω²·γ²)  [множення на спряжене]
= ε_inf · (1 - ω_p² / (ω² + γ²)) + i · ε_inf · (ω_p² · γ) / (ω · (ω² + γ²)) [розподіл на Re та Im]
```

Звідси отримуємо дійсну `ε₁(ω)` та уявну `ε₂(ω)` складові:

```
ε₁(ω) = ε_inf · (1 - ω_p² / (ω² + γ²))
ε₂(ω) = ε_inf · (ω_p² · γ) / (ω · (ω² + γ²))
```

## Критерій Мотта та перехід метал–діелектрик

Перехід напівпровідникового оксиду у вироджений металевий стан описується квантовим критерієм Мотта. Коли хвильові функції сусідніх домішкових центрів перекриваються, дискретний донорний рівень розширюється в донорну зону, яка зливається з дном зони провідності.

Згідно з критерієм Мотта, критична концентрація донорів `n_Mott`, необхідна для виникнення делокалізованої металевої провідності:

```
n_Mott^(1/3) · a_B* ≈ 0.26
```

де `a_B* = a₀ · ε_static · (m₀ / m*)` — ефективний борівський радіус домішкового воднеподібного стану (`a₀ = 0.0529` нм — радіус Бора, `ε_static ≈ 9.0` — статична діелектрична проникність In₂O₃).

Для параметрів ITO (`m* = 0.35 m₀`):

```
a_B* = 0.0529 · 9.0 / 0.35 ≈ 1.36 нм
n_Mott ≈ (0.26 / (1.36 × 10⁻⁷))³ ≈ (1.91 × 10⁶)³ ≈ 7.0 × 10¹⁸ см⁻³
```

Оскільки реальні плівки ITO легуються до рівнів `n = (3–10) × 10²⁰` см⁻³, умова Мотта виконується із запасом у 50–100 разів. Вільні носії утворюють істинно вироджений електронний газ Фермі, в якому довжина хвилі де Бройля на поверхні Фермі `λ_F = 2π / k_F` менша за довжину вільного пробігу (`k_F · l_e > 1`, критерій Іоффе — Регеля). Це зумовлює металевий температурний коефіцієнт опору (ТКО): опір плівки слабо зростає з нагріванням через посилення фононного розсіювання, а не падає експоненційно, як у звичайних нелегованих напівпровідниках.

## Механізми розсіювання носіїв та межа рухливості Брукса — Геррінга

Параметр релаксації `γ = 1 / τ` визначає не лише уявну частину діелектричної проникності (паразитне внутрішньозонне поглинання), а й дрейфову рухливість носіїв заряду `μ`:

```
μ = e · τ / m* = e / (m* · γ)
```

У сильнолегованих вироджених напівпровідникових оксидах за кімнатної температури діють три паралельні механізми розсіювання імпульсу, які підпорядковуються правилу Маттіссена `1/τ = 1/τ_ii + 1/τ_ph + 1/τ_gb`:

1. **Розсіювання на іонізованих домішках (`τ_ii`).** Оскільки для досягнення `n > 10²⁰` см⁻³ у ґратку вводиться відповідна кількість позитивно заряджених донорів (Sn⁴⁺ у In₂O₃ або Al³⁺ у ZnO), кулонівське поле домішкових іонів стає головним джерелом опору. Згідно з теорією Брукса — Геррінга для екранованого кулонівського потенціалу у виродженому електронному газі:

```
μ_ii = (24 · π³ · (ε₀ · ε_inf)² · ħ³) / (e³ · (m*)² · Z² · g(x))
```

де `Z` — заряд іонізованої домішки (`Z = 1` для заміщення Sn⁴⁺ на вузлі In³⁺), а функція екранування `g(x)` дорівнює:

```
g(x) = ln(1 + x) - x / (1 + x)
x = 4 · k_F² · L_D² = (4 · π / e) · (ε₀ · ε_inf · ħ² / m*) · (3 · π² · n)^(1/3)
```

тут `k_F = (3·π²·n)^(1/3)` — радіус сфери Фермі, а `L_D = √( (ε₀ · ε_inf · E_F) / (3 · n · e²) )` — дебаївська довжина екранування у виродженому газі.

Аналіз формули Брукса — Геррінга показує, що рухливість, обмежена іонізованими домішками `μ_ii`, практично не залежить від температури, але слабко спадає зі зростанням концентрації носіїв через збільшення густини розсіювальних центрів. Це встановлює фундаментальну межу рухливості для полікристалічного ITO на рівні `μ_max ≈ 40–60` см²/(В·с) за концентрації `n ≈ 10²¹` см⁻³.

2. **Розсіювання на оптичних і акустичних фононах ґратки (`τ_ph`).** Визначається тепловими коливаннями полярної ґратки (поляронами). Для In₂O₃ внесок фононного розсіювання за 300 К обмежує рухливість рівнем `μ_ph ≈ 140–160` см²/(В·с), що значно перевищує домішковий опір.

3. **Розсіювання на міжзеренних межах (`τ_gb`).** У тонких полікристалічних плівках межі кристалітів містять пастки заряду, які створюють потенціальні бар'єри висотою `E_B`. Якщо середня довжина вільного пробігу електрона `l_e = v_F · τ` (де `v_F = ħ · k_F / m*` — швидкість Фермі) порівнянна з розміром зерна `D_grain` (типово 20–50 нм для магнетронного ITO), межі зерен додатково знижують макроскопічну провідність.

## Оптичні сталі: показник заломлення, коефіцієнт екстинкції та відбиття

Комплексний показник заломлення середовища `ñ = n_r + i · k` пов'язаний із комплексною діелектричною проникністю співвідношенням `ε(ω) = ñ² = (n_r + i·k)² = n_r² - k² + 2·i·n_r·k`:

```
n_r² - k² = ε₁(ω)
2 · n_r · k = ε₂(ω)
```

Розв'язуючи систему квадратних рівнянь відносно дійсного показника заломлення `n_r` та коефіцієнта згасання (екстинкції) `k`:

```
n_r = √( (√(ε₁² + ε₂²) + ε₁) / 2 )
k   = √( (√(ε₁² + ε₂²) - ε₁) / 2 )
```

Коефіцієнт оптичного поглинання `α(ω)` визначає експоненційне згасання інтенсивності світла вглиб плівки за законом Бугера — Ламберта — Бера `I(z) = I₀ · exp(-α · z)`:

```
α(ω)
= (2 · ω / c) · k                         [зв'язок хвильового числа та екстинкції]
= (4 · π · k) / λ                         [перехід до довжини хвилі у вакуумі]
```

Для нормального падіння світла з повітря (`n_air ≈ 1`) коефіцієнт відбиття за формулами Френеля:

```
R(ω)
= |(ñ - 1) / (ñ + 1)|²                     [формула Френеля для нормального падіння]
= ((n_r - 1)² + k²) / ((n_r + 1)² + k²)   [розкриття модуля комплексного числа]
```

## Три оптичні режими плівки TCO

Аналіз дійсної частини `ε₁(ω)` у діапазоні низького затухання (`ω >> γ`) виявляє три принципово різні фізичні режими взаємодії з випромінюванням:

```
Режим 1 (Високі частоти, ω > ω_p):
ε₁(ω) > 0  →  k ≈ 0, n_r ≈ √ε_inf ≈ 1.9–2.0
R ≈ ((n_r - 1) / (n_r + 1))² ≈ ((1.9 - 1) / (1.9 + 1))² ≈ 0.096 (9.6%)
Матеріал поводиться як прозорий діелектрик (видиме вікно).

Режим 2 (Плазмовий резонанс, ω = ω_p):
ε₁(ω_p) = 0  →  n_r = k = √(ε₂ / 2)
Довжина хвилі плазмового краю: λ_p = (2 · π · c) / ω_p.

Режим 3 (Низькі частоти, ω < ω_p):
ε₁(ω) < 0  →  k >> n_r, ñ ≈ i · k
R → 1 (відбиття наближається до 90–98%).
Матеріал поводиться як дзеркальний метал (ІЧ-відбивач).
```

### Розрахунок плазмової довжини хвилі для плівки ITO

Розглянемо типову оксидну плівку індію-олова (ITO) з такими експериментальними параметрами:
* Концентрація електронів: `n = 8.0 × 10²⁰` см⁻³ = `8.0 × 10²⁶` м⁻³;
* Ефективна маса електрона: `m* = 0.35 · m₀ = 0.35 × (9.109 × 10⁻³¹)` кг = `3.188 × 10⁻³¹` кг;
* Високочастотна проникність: `ε_inf = 4.0`;
* Електрична стала: `ε₀ = 8.854 × 10⁻¹²` Ф/м;
* Швидкість світла: `c = 2.998 × 10⁸` м/с;
* Елементарний заряд: `e = 1.602 × 10⁻¹⁹` Кл.

Обчислимо квадрат циклічної плазмової частоти:

```
ω_p²
= (n · e²) / (ε₀ · ε_inf · m*)            [формула плазмової частоти Друде]
= (8.0 × 10²⁶ · (1.602 × 10⁻¹⁹)²) / (8.854 × 10⁻¹² · 4.0 · 3.188 × 10⁻³¹) [підстановка чисел]
= (8.0 × 10²⁶ · 2.566 × 10⁻³⁸) / (1.129 × 10⁻⁴⁰) [обчислення чисельника і знаменника]
= (2.053 × 10⁻¹¹) / (1.129 × 10⁻⁴⁰)       [ділення]
= 1.818 × 10³⁰ рад²/с²
```

Звідси циклічна плазмова частота:

```
ω_p = √(1.818 × 10³⁰) = 1.348 × 10¹⁵ рад/с
```

Плазмова довжина хвилі `λ_p`:

```
λ_p
= (2 · π · c) / ω_p                       [зв'язок довжини хвилі та циклічної частоти]
= (2 · 3.14159 · 2.998 × 10⁸) / (1.348 × 10¹⁵) [підстановка сталих]
= (1.884 × 10⁹) / (1.348 × 10¹⁵)          [обчислення]
= 1.398 × 10⁻⁶ м = 1398 нм (1.40 мкм)
```

Отримане значення `λ_p ≈ 1.4` мкм лежить у ближньому інфрачервоному діапазоні. Усе видиме світло (380–780 нм) має частоту `ω > ω_p`, тому плівка є прозорою. Якби концентрацію електронів підняли до `n = 5 × 10²¹` см⁻³, плазмова довжина змістилася б у зелену область (`λ_p ≈ 550` нм), і матеріал перетворився б на непрозоре дзеркало.

## Кількісний розрахунок зсуву Бурштейна — Мосса

У нелегованому напівпровіднику In₂O₃ пряма оптична заборонена зона складає `E_g^0 ≈ 3.50` еВ. При концентрації електронів `n > 10²⁰` см⁻³ рівень Фермі `E_F` занурюється вглиб зони провідності на величину енергії Фермі `E_F - E_c`.

Оскільки стани нижче рівня Фермі повністю заповнені, за принципом заборони Паулі електрон із валентної зони може поглинути фотон лише для переходу на вільний рівень із хвильовим вектором `k_F`.

Радіус сфери Фермі в k-просторі:

```
k_F = (3 · π² · n)^(1/3)
```

Енергія Фермі в зоні провідності (параболічне наближення):

```
E_F - E_c = (ħ² · k_F²) / (2 · m_c*) = (ħ² / (2 · m_c*)) · (3 · π² · n)^(2/3)
```

Повний оптичний зсув Бурштейна — Мосса `ΔE_g^{BM}` враховує кривизну обох зон (зони провідності з масою `m_c*` та валентної зони з масою `m_v*`):

```
ΔE_g^{BM}
= (ħ² · k_F²) / (2 · m_c*) + (ħ² · k_F²) / (2 · m_v*) [сума енергій збудження в обох зонах]
= (ħ² · k_F²) / (2 · m_vc*)               [введення зведеної оптичної маси]
= (ħ² / (2 · m_vc*)) · (3 · π² · n)^(2/3) [вираз через концентрацію носіїв n]
```

де `1 / m_vc* = 1 / m_c* + 1 / m_v*`.

Для типових значень ITO: `m_c* = 0.35 · m₀`, `m_v* = 1.5 · m₀`:

```
1 / m_vc*
= 1 / (0.35 · m₀) + 1 / (1.5 · m₀)        [сума обернених мас]
= (2.857 + 0.667) / m₀                   [додавання]
= 3.524 / m₀
m_vc* = m₀ / 3.524 ≈ 0.284 · m₀
```

Для концентрації `n = 8.0 × 10²⁶` м⁻³:

```
k_F
= (3 · π² · 8.0 × 10²⁶)^(1/3)             [обчислення радіуса сфери Фермі]
= (2.369 × 10²⁸)^(1/3)                    [піднесення до степеня 1/3]
= 2.872 × 10⁹ м⁻¹
```

Обчислимо зсув Бурштейна — Мосса:

```
ΔE_g^{BM}
= ((1.055 × 10⁻³⁴)² · (2.872 × 10⁹)²) / (2 · 0.284 · 9.109 × 10⁻³¹) [підстановка сталих]
= (1.113 × 10⁻⁶⁸ · 8.248 × 10¹⁸) / (5.174 × 10⁻³¹) [множення в чисельнику]
= (9.180 × 10⁻⁵⁰) / (5.174 × 10⁻³¹)       [ділення]
= 1.774 × 10⁻¹⁹ Дж
= 1.774 × 10⁻¹⁹ / (1.602 × 10⁻¹⁹) еВ      [переведення у джоулі/еВ]
= 1.107 еВ
```

З урахуванням багачастинкового звуження забороненої зони (Bandgap Renormalization, BGN) через електрон-електронну та електрон-іонну взаємодію `ΔE_g^{BGN} ≈ -0.32` еВ, результуюча оптична заборонена зона складає:

```
E_g^{opt} = E_g^0 + ΔE_g^{BM} - ΔE_g^{BGN} = 3.50 + 1.11 - 0.32 = 4.29 еВ
```

Таке сильне розширення оптичної щілини відсуває край фундаментального міжзонного поглинання з довжини хвилі `λ = 1240 / 3.50 = 354` нм до `λ = 1240 / 4.29 = 289` нм, забезпечуючи високу прозорість у всьому ультрафіолетовому діапазоні UV-A та видимому спектрі.

## Інтерференція та багатопроменеве пропускання в системі повітря–плівка–підкладка

Реальний спектр пропускання оптичної структури (наприклад, 150 нм ITO на скляній пластині товщиною 0.7 мм) визначається інтерференцією Фабрі — Перо в тонкому оксидному шарі.

Нехай плоска світлова хвиля падає нормально з повітря (`n₀ = 1`) на плівку TCO з комплексним показником заломлення `ñ₁ = n₁ + i·k₁` і геометричною товщиною `d`, нанесену на товсту скляну підкладку (`n₂ ≈ 1.52`, `k₂ ≈ 0`).

Комплексні коефіцієнти відбиття Френеля на верхній і нижній межах плівки:

```
r₁ = (n₀ - ñ₁) / (n₀ + ñ₁) = (1 - ñ₁) / (1 + ñ₁)
r₂ = (ñ₁ - n₂) / (ñ₁ + n₂)
```

Комплексний набіг фази хвилі за один прохід крізь плівку:

```
δ = (2 · π · ñ₁ · d) / λ = (2 · π · n₁ · d) / λ + i · (2 · π · k₁ · d) / λ
```

Повний амплітудний коефіцієнт пропускання `t_total` крізь тонку плівку за формулою Ейрі (підсумовування нескінченного ряду внутрішніх перевідбиттів):

```
t_total = (t₁ · t₂ · exp(i · δ)) / (1 + r₁ · r₂ · exp(2 · i · δ))
```

де `t₁ = 2·n₀ / (n₀ + ñ₁)`, `t₂ = 2·ñ₁ / (ñ₁ + n₂)`. Енергетичний коефіцієнт пропускання `T(λ)`:

```
T(λ) = (n₂ / n₀) · |t_total|²
```

Умова екстремумів інтерференції:
* **Максимуми пропускання** виникають, коли оптична товщина плівки кратна половині довжини хвилі: `2 · n₁ · d = m · λ` (де `m = 1, 2, ...`). Для `d = 145` нм, `n₁ ≈ 1.9` маємо оптичну товщину `n₁ · d ≈ 275` нм, що дає максимум просвітлення саме на довжині хвилі зеленого світла `λ = 2 · 275 / 1 = 550` нм.
* **Мінімуми пропускання** спостерігаються при `2 · n₁ · d = (m - 1/2) · λ`.

Ось чому підбір товщини TCO в оптоелектроніці є компромісом не лише між електричним опором і поглинанням, а й точним розрахунком чвертьхвильового просвітлення для зменшення відбиття на межі зі склом.

## Квантова електродинаміка графену: оптична провідність моношару

Графен є граничним випадком двовимірного напівметалу з безмасовими діраківськими ферміонами та лінійним законом дисперсії `E(k) = ± ħ · v_F · |k|`, де швидкість Фермі `v_F ≈ 10⁶` м/с.

У діапазоні енергій фотонів міжзонних переходів `ħω > 2·|E_F|` оптична провідність ідеального нелегованого моношару графену є універсальною квантовою сталою:

```
G₀ = e² / (4 · ħ) ≈ 6.084 × 10⁻⁵ См
```

Коефіцієнт оптичного поглинання нелегованого моношару графену у вакуумі виражається безпосередньо через сталу тонкої структури `α_qed = e² / (4 · π · ε₀ · ħ · c) ≈ 1 / 137.036`:

```
A_mono
= π · α_qed                               [фундаментальне квантове поглинання моношару]
= π / 137.036 ≈ 0.02293 (2.293%)
```

Звідси оптичне пропускання ідеального одного шару графену у видимому спектрі:

```
T_mono = 1 - A_mono ≈ 97.71%
```

Для `N`-шарового графенового покриття світлопропускання зменшується адитивно: `T_N ≈ 1 - N · π · α_qed`. Проте питомий поверхневий опір нелегованого графену є високим (`R_sq > 1000` Ом/кв через нульову густину станів у точці Дірака).

При хімічному або електростатичному легуванні рівень Фермі зсувається на величину `E_F`. За умови `E_F >> k_B · T` поверхнева концентрація носіїв `n_2D = (E_F / (ħ · v_F))² / π`, а поверхневий опір:

```
R_sq = 1 / (e · n_2D · μ) = π · ħ² · v_F² / (e · μ · E_F²)
```

Для сильнолегованого графену (`E_F = 0.6` еВ, рухливість `μ = 2000` см²/(В·с)) отримуємо поверхневий опір `R_sq ≈ 30` Ом/кв при збереженні пропускання `T ≈ 97.7%`, що демонструє граничні теоретичні можливості двовимірних нановуглецевих матеріалів.

## Метрологія поверхневого опору: чотиризондовий метод та теорема Ван дер Пау

Вимірювання поверхневого опору тонких провідних плівок `R_sq` здійснюється за допомогою лінійного чотиризондового зонда (Four-Point Probe), де через зовнішні контакти 1 і 4 пропускається струм `I`, а на внутрішніх контактах 2 і 3 вимірюється спад напруги `V`.

Для напівнескінченного зразка товщиною `t`, коли відстань між зондами `s` значно перевищує товщину плівки (`s >> t`):

```
V₂₃
= (I · ρ / (2 · π · t)) · ln( ((s + s) · (s + s)) / (s · s) ) [інтегрування логарифмічного потенціалу 2D струму]
= (I · ρ / (2 · π · t)) · ln(4)            [спрощення аргументу логарифма]
= (I · ρ / (π · t)) · ln(2)                [властивість логарифма ln(2²) = 2·ln(2)]
```

Звідси питомий поверхневий опір `R_sq = ρ / t`:

```
R_sq
= (π / ln(2)) · (V₂₃ / I)                  [вираження R_sq через виміряні величини]
≈ 4.53236 · (V₂₃ / I)                      [обчислення числового коефіцієнта π / ln(2)]
```

Для зразків довільної форми з чотирма точковими контактами A, B, C, D на периметрі застосовується теорема Ван дер Пау. Вимірюються два характеристичні опори `R_AB,CD = V_CD / I_AB` та `R_BC,DA = V_DA / I_BC`. Вони пов'язані трансцендентним рівнянням конформного відображення:

```
exp(-π · R_AB,CD / R_sq) + exp(-π · R_BC,DA / R_sq) = 1
```

Для симетричного зразка (`R_AB,CD = R_BC,DA = R_sym`):

```
2 · exp(-π · R_sym / R_sq) = 1
exp(-π · R_sym / R_sq) = 1/2
-π · R_sym / R_sq = ln(1/2) = -ln(2)       [логарифмування обох частин]
R_sq = (π / ln(2)) · R_sym ≈ 4.53236 · R_sym [точний розв'язок]
```

## Теорія перколяції для нанодротяних сіток (AgNW)

На відміну від суцільних оксидних плівок, срібні нанодроти утворюють випадкову двовимірну сітку скінченних провідних стрижнів довжиною `L_w` та діаметром `d_w`.

Згідно з 2D-теорією геометричної перколяції стрижнів (Stick Percolation), струм починає протікати через сітку лише тоді, коли поверхнева щільність нанодротів `N_w` (кількість стрижнів на одиницю площі) перевищує критичний поріг перколяції `N_c`:

```
N_c ≈ 5.71 / L_w²
```

Поверхневий опір сітки вище порогу підпорядковується степеневому закону:

```
R_sq ∝ (N_w - N_c)^(-t_crit)
```

де `t_crit ≈ 1.33` — критичний індекс двовимірної перколяції. Оптичне пропускання такої сітки лінійно зменшується зі зростанням площі покриття стрижнями (затінення поверхні):

```
T ≈ 1 - a_shadow · N_w · d_w · L_w
```

де `a_shadow ≈ 1.0–1.2` — коефіцієнт з урахуванням оптичної дифракції на субхвильових металевих циліндрах.

Оптичний каламут (Haze factor) сітки нанодротів визначається часткою дифузного розсіювання світла на металевих циліндрах:

```
Haze(λ) = (T_diffuse(λ) / T_total(λ)) · 100%
```

Для дисплеїв високої роздільної здатності Haze не повинен перевищувати 1.0–1.5%, що вимагає використання нанодротів зменшеного діаметра (`d_w < 25` нм), тоді як для сонячних панелей навпаки бажаний високий Haze (понад 10–15%) для збільшення оптичного шляху фотонів у фотоактивному шарі шляхом багаторазового розсіювання.

## Виведення та оптимізація фактора якості Хааке

Поверхневий електричний опір плівки товщиною `t` та питомим опором `ρ = 1 / σ`:

```
R_sq = ρ / t = 1 / (σ · t)
```

Оптичне пропускання плівки за законом Бугера (нехтуючи відбиттям на границях для чистого поглинання):

```
T = exp(-α · t)
```

Фактор якості Хааке (Haacke Figure of Merit, `Φ_TC`) введено для кількісного порівняння прозорих провідників:

```
Φ_TC = T¹⁰ / R_sq
```

Степінь 10 обрано тому, що в оптичних дисплеях падіння прозорості `T` нижче 90% неприпустиме: при `T = 90%` множник `T¹⁰ = 0.90¹⁰ ≈ 0.349`, тоді як при `T = 80%` він падає до `0.80¹⁰ ≈ 0.107` (втрата у 3.3 рази).

Підставимо вирази для `T` та `R_sq` у формулу Хааке як функцію товщини плівки `t`:

```
Φ_TC(t)
= (exp(-α · t))¹⁰ / (1 / (σ · t))         [підстановка T та R_sq]
= σ · t · exp(-10 · α · t)                 [спрощення дробу]
```

Знайдемо оптимальну товщину плівки `t_opt`, яка максимізує фактор Хааке. Для цього візьмемо похідну `dΦ_TC / dt` і прирівняємо її до нуля:

```
dΦ_TC / dt
= d/dt [σ · t · exp(-10 · α · t)]          [похідна добутку]
= σ · exp(-10 · α · t) + σ · t · (-10 · α) · exp(-10 · α · t) [диференціювання]
= σ · exp(-10 · α · t) · (1 - 10 · α · t)  [винесення спільного множника]
```

Прирівнюємо похідну до нуля:

```
σ · exp(-10 · α · t) · (1 - 10 · α · t) = 0
1 - 10 · α · t = 0                        [експонента і σ не дорівнюють нулю]
t_opt = 1 / (10 · α)                      [розв'язок відносно t]
```

### Фізичний зміст екстремуму Хааке

При оптимальній товщині `t_opt = 1 / (10 · α)` пропускання плівки складає строго фіксовану величину:

```
T(t_opt)
= exp(-α · t_opt)                         [підстановка t_opt]
= exp(-α · (1 / (10 · α)))                 [скорочення коефіцієнта α]
= exp(-1/10) = exp(-0.1)                  [числове значення]
≈ 0.9048 (90.48%)
```

Максимальне значення фактора якості Хааке при цьому дорівнює:

```
Φ_TC^{max}
= σ · (1 / (10 · α)) · exp(-1)             [підстановка t_opt у Φ_TC]
= σ / (10 · e · α)                         [де e ≈ 2.71828 — основа натурального логарифма]
≈ 0.03679 · (σ / α)
```

Це фундаментальний результат: максимальна якість прозорого провідника визначається виключно відношенням його питомої електропровідності `σ` до коефіцієнта оптичного поглинання `α`.

## Порівняльний числовий аналіз провідних плівок

Обчислимо поверхневий опір, пропускання на довжині хвилі 550 нм та фактор Хааке для чотирьох провідних систем товщиною `t = 150` нм:

```
1. Оксид індію-олова (ITO):
   σ = 5000 См/см = 5.0 × 10⁵ См/м
   α = 1.2 × 10⁵ м⁻¹ (на 550 нм)
   R_sq = 1 / (5.0 × 10⁵ · 1.5 × 10⁻⁷) = 13.33 Ом/кв
   T = exp(-1.2 × 10⁵ · 1.5 × 10⁻⁷) = exp(-0.018) ≈ 0.982 (98.2% без урахування відбиття, ~90.5% з відбиттям)
   T_real ≈ 90.5%  →  Φ_TC = (0.905)¹⁰ / 13.33 ≈ 0.367 / 13.33 ≈ 2.75 × 10⁻² Ом⁻¹

2. Легований фтором оксид олова (FTO):
   σ = 2500 См/см = 2.5 × 10⁵ См/м
   α = 2.0 × 10⁵ м⁻¹
   R_sq = 1 / (2.5 × 10⁵ · 1.5 × 10⁻⁷) = 26.67 Ом/кв
   T_real ≈ 84.0%  →  Φ_TC = (0.84)¹⁰ / 26.67 ≈ 0.175 / 26.67 ≈ 6.56 × 10⁻³ Ом⁻¹

3. Легований алюмінієм оксид цинку (AZO):
   σ = 2000 См/см = 2.0 × 10⁵ См/м
   α = 1.8 × 10⁵ м⁻¹
   R_sq = 1 / (2.0 × 10⁵ · 1.5 × 10⁻⁷) = 33.33 Ом/кв
   T_real ≈ 86.0%  →  Φ_TC = (0.86)¹⁰ / 33.33 ≈ 0.221 / 33.33 ≈ 6.63 × 10⁻³ Ом⁻¹

4. Срібні нанодроти (AgNW сітка з поверхневою густиною 40 мг/м²):
   R_sq = 15.0 Ом/кв
   T_real = 89.0%
   Φ_TC = (0.89)¹⁰ / 15.0 ≈ 0.312 / 15.0 ≈ 2.08 × 10⁻² Ом⁻¹
```

Математичний аналіз доводить, чому ITO утримує позиції індустріального еталона для дисплеїв високої чіткості: його фактор Хааке (`~2.75 × 10⁻²` Ом⁻¹) у 4 рази перевищує FTO та AZO завдяки поєднанню високої рухливості електронів (`μ > 40` см²/(В·с)) та низького поглинання у видимому діапазоні. Срібні нанодроти (AgNW) досягають порівнянного фактора Хааке (`~2.1 × 10⁻²` Ом⁻¹), пропонуючи гнучкість, недосяжну для крихких оксидних керамік.
