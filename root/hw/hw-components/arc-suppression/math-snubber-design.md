# 🧮 Математичний розрахунок параметрів демпфувальних RC- та RCD-ланок

Розрахунок демпфувальних ланцюгів (снаберів) ґрунтується на математичному моделюванні перехідних процесів у лінійних та нелінійних електричних колах другого порядку, утворених індуктивністю навантаження або паразитною індуктивністю розсіювання, ємністю снабера та еквівалентним демпфувальним опором. Строгий аналіз характеристичного рівняння та енергетичних інтегралів дозволяє не лише ліквідувати резонансний дзвін і перенапруги на ключах, а й точно обчислити розсіювану теплову потужність резистора та вибрати компоненти з мінімальними габаритами.

---

### 1. Диференціальне рівняння контуру другого порядку та коефіцієнт демпфування

Розглянемо замкнений контур, що утворюється в момент розмикання комутаційного ключа. Котушка індуктивністю `L` із початковим струмом `I_0` шунтується демпфувальним ланцюгом із послідовно з'єднаних опору `R` та ємності `C`.

![Перехідні процеси та осцилограми напруги при демпфуванні](img/rc-damping-waveforms.svg)
*Форма перехідної напруги залежно від коефіцієнта демпфування: від коливального дзвону при малому R до монотонного критичного спаду та початкового стрибка I₀·R при надлишковому опорі.*

За другим законом Кірхгофа сума спадів напруг на всіх елементах контуру в будь-який момент часу `t ≥ 0`:

```
V_L(t) + V_R(t) + V_C(t) = 0
```

Виразимо кожну напругу через миттєвий струм у контурі `i(t)`:

```
L · (di(t) / dt) + R · i(t) + (1 / C) · ∫ i(t) dt = 0
```

Диференціюємо обидві частини рівняння за часом `t`:

```
d²i(t) / dt² + (R / L) · (di(t) / dt) + (1 / (L · C)) · i(t) = 0
```

Це лінійне однорідне диференціальне рівняння другого порядку зі сталими коефіцієнтами. Введемо стандартні параметри теорії коливань:

* **Власна резонансна кутова частота незгасаючого контуру**:
  ```
  ω_0 = 1 / √(L · C)
  ```
* **Коефіцієнт згасання (коефіцієнт затухання)**:
  ```
  α = R / (2 · L)
  ```
* **Характеристичний (хвильовий) імпеданс контуру**:
  ```
  Z_0 = √(L / C)
  ```
* **Безрозмірний коефіцієнт демпфування (damping factor)**:
  ```
  ζ = α / ω_0 = (R / (2 · L)) · √(L · C) = (R / 2) · √(C / L) = R / (2 · Z_0)
  ```

Характеристичне рівняння в операторній формі Лапласа:

```
s² + 2 · ζ · ω_0 · s + ω_0² = 0
```

Корені характеристичного рівняння визначають поведінку напруги:

```
s₁,₂ = -ζ · ω_0 ± ω_0 · √(ζ² - 1)
```

### 2. Три режими розв'язку та їхній фізичний зміст

#### Режим 1. Недодемпфований стан (`ζ < 1`, тобто `R < 2 · Z_0`)
Підкореневий вираз є від'ємним, тому корені комплексно-спряжені:

```
s₁,₂ = -α ± j · ω_d
```
де `ω_d = ω_0 · √(1 - ζ²)` — власна затухаюча кругова частота коливань.

Аналітичний розв'язок для струму та напруги на ємності:

```
i(t) = I_0 · exp(-α · t) · (cos(ω_d · t) - (α / ω_d) · sin(ω_d · t))
v_c(t) = V_cc - I_0 · Z_0 · (ω_0 / ω_d) · exp(-α · t) · sin(ω_d · t)
```

Перехідний процес має яскраво виражений коливальний характер (дзвін). Перший пік напруги на ключі виникає при `t_peak = π / ω_d`:

```
V_max = V_cc + I_0 · Z_0 · exp(- (π · ζ) / √(1 - ζ²))
```

Якщо резистор відсутній зовсім (`R = 0`, `ζ = 0`), експонента перетворюється на одиницю, і вся магнітна енергія індуктивності `0.5 · L · I_0²` без втрат переходить в електричну енергію конденсатора `0.5 · C · V_peak²`:

```
0.5 · C · V_peak² = 0.5 · L · I_0²
V_peak = I_0 · √(L / C) = I_0 · Z_0
```

Сумарна напруга на комутаційному ключі досягає `V_total = V_cc + I_0 · Z_0`. Наприклад, при струмі `I_0 = 1 А`, індуктивності `L = 10 мГн` та ємності монтажу `C = 100 пФ` характеристичний опір становить `Z_0 = √(0.01 / 10⁻¹⁰) = 10000 Ом = 10 кОм`. Напруга сплеску сягає `1 А · 10 кОм = 10 000 В`, що гарантовано викликає пробій будь-якого напівпровідника або спалахування дуги на контактах.

#### Режим 2. Критичне демпфування (`ζ = 1`, тобто `R_crit = 2 · Z_0 = 2 · √(L / C)`)
Підкореневий вираз дорівнює нулю. Корені дійсні й кратні: `s₁ = s₂ = -ω_0`.

Аналітичний розв'язок для струму:

```
i(t) = I_0 · (1 - ω_0 · t) · exp(-ω_0 · t)
```

Це найшвидший можливий перехідний процес без виникнення коливань і без перерегулювання напруги. Напруга на ємності плавно прямує до асимптоти без жодного перевищення `V_cc`.

#### Режим 3. Передемпфований стан (`ζ > 1`, тобто `R > 2 · Z_0`)
Корені дійсні й різні:

```
s₁,₂ = -α ± ω_0 · √(ζ² - 1)
```

Струм згасає повільно за двома експонентами. Головна небезпека надмірного опору полягає в тому, що в момент розмикання комутаційного контакту початковий струм `I_0`, протікаючи крізь резистор `R`, створює миттєвий стрибок напруги за законом Ома:

```
ΔV_initial = I_0 · R
```
Якщо опір `R` завеликий, цей початковий стрибок може перевищити напругу пробою ключа ще до того, як конденсатор почне заряджатися.

### 3. Траєкторія перемикання на площині I–V та динамічні втрати в MOSFET

У силових напівпровідникових ключах (MOSFET, IGBT) застосування паралельного ємнісного снабера змінює динамічну траєкторію робочої точки на площині «струм–напруга» (I–V), захищаючи кристал від виходу за межі області безпечної роботи (Safe Operating Area, SOA).

#### Динамічні втрати при вимкненні без снабера
Коли транзистор вимикається без демпфера, струм каналу починає спадати, а напруга на стоку підскакує до напруги живлення `V_ds = V_in`. Протягом часу спаду струму `t_fall` транзистор одночасно проводить великий струм під повною напругою.

Миттєва пікова потужність у кристалі сягає:

```
P_peak = V_in · I_load
```

Енергія динамічних втрат за одне вимкнення становить:

```
E_off = 0.5 · V_in · I_load · t_fall
```
При частоті 100 кГц ці втрати нагрівають кристал потужністю в десятки ватів, обмежуючи граничний струм перетворювача.

#### Модифікація траєкторії за допомогою turn-off снабера
Паралельний конденсатор `C_s` затримує наростання напруги на стоку: поки струм каналу спадає від `I_load` до нуля, напруга на стоку встигає піднятися лише до низького значення `V_ds(t_fall) = (I_load · t_fall) / (2 · C_s)`.

Перемноження струму на напругу показує, що інтеграл потужності втрат усередині кремнієвого кристала зменшується у 5–10 разів:

```
E_off_snubbed = (I_load² · t_fall²) / (24 · C_s)
```

Транзистор вимикається практично за нульової напруги (Zero-Voltage Switching, ZVS-подібний режим), а динамічне тепло виноситься за межі мікросхеми в зовнішній пасивний резистор снабера.

### 4. Баланс енергії та потужність розсіювання на резисторі RC-снабера

Розглянемо повний цикл комутації: розмикання ключа (заряд конденсатора `C_s` до напруги живлення `V_cc`) та наступне замикання ключа (повний розряд конденсатора через резистор `R_s`).

Енергія, що закачується в конденсатор ємністю `C_s` при його заряді до напруги `V_cc`:

```
E_cap = ∫ (0 до V_cc) C_s · v · dv
= 0.5 · C_s · V_cc²       [інтегрування лінійної залежності заряду q = C·v]
```

Під час заряду від джерела постійної напруги `V_cc` джерело віддає повний заряд `Q = C_s · V_cc`, виконуючи роботу:

```
A_source = Q · V_cc
= C_s · V_cc²             [робота джерела при передачі заряду Q]
```

Різниця між роботою джерела та енергією, накопиченою в електричному полі конденсатора, неминуче виділяється у вигляді тепла на активному опорі контуру:

```
E_loss_charge = A_source - E_cap
= C_s · V_cc² - 0.5 · C_s · V_cc² [віднімання енергії поля]
= 0.5 · C_s · V_cc²               [половина енергії перетворюється на тепло]
```

Під час наступного замикання ключа конденсатор `C_s` розряджається на резистор `R_s`, і вся накопичена енергія `0.5 · C_s · V_cc²` також повністю розсіюється у вигляді тепла.

Сумарна енергія, що перетворюється на тепло на резисторі за один повний період комутації:

```
E_total_cycle = E_loss_charge + E_loss_discharge
= 0.5 · C_s · V_cc² + 0.5 · C_s · V_cc² [додавання втрат заряду та розряду]
= C_s · V_cc²                           [повна енергія циклу комутації]
```

Якщо ключ перемикається з робочою частотою `f_sw`, середня теплова потужність, яка виділяється на резисторі снабера, становить:

```
P_snubber_R = E_total_cycle · f_sw
= C_s · V_cc² · f_sw
```

Ця формула показує фундаментальне обмеження простих RC-снаберів: потужність втрат на резисторі прямо пропорційна ємності конденсатора та частоті перемикання і абсолютно не залежить від величини опору `R_s`. Величина `R_s` визначає лише піковий струм розряду `I_peak = V_cc / R_s` та швидкість згасання коливань, але не сумарні вати тепла.

### 5. Частотний аналіз RC-снабера в колах змінного струму (AC)

У колах синусоїдального змінного струму з частотою `f = 50 Гц` або `400 Гц` снабер перебуває під безперервною напругою `v(t) = V_m · sin(ω · t)`.

Комплексний імпеданс послідовного RC-снабера:

```
Z_snubber(jω) = R_s + 1 / (j · ω · C_s) = R_s - j / (ω · C_s)
```

Модуль повного електричного опору:

```
|Z_snubber| = √(R_s² + (1 / (ω · C_s))²)
```

Діюче значення безперервного струму витоку крізь снабер у черговому режимі:

```
I_leak_rms = V_rms / |Z_snubber| ≈ V_rms · ω · C_s  [за умови R_s << 1/(ω·C_s)]
```

Активна потужність, що безперервно виділяється на резисторі снабера під дією струму мережі:

```
P_ac_continuous = I_leak_rms² · R_s
= (V_rms² · ω² · C_s² · R_s) / (1 + ω² · C_s² · R_s²)
≈ V_rms² · ω² · C_s² · R_s
```

Наприклад, для стандартного мережевого снабера `R_s = 100 Ом`, `C_s = 0.1 мкФ` у мережі 230 В, 50 Гц (`ω = 314.16 рад/с`):
```
I_leak = 230 · 314.16 · 10⁻⁷ ≈ 0.0072 А = 7.2 мА
P_ac = (0.0072)² · 100 ≈ 0.0052 Вт = 5.2 мВт
```
Постійні теплові втрати на частоті 50 Гц мізерні (5.2 мВт), проте струм витоку 7.2 мА достатній для збудження чутливих навантажень, що вимагає врахування при проектуванні.

### 6. Математика RCD-снабера у зворотноходових перетворювачах (Flyback)

В імпульсних джерелах живлення первинна обмотка трансформатора має індуктивність намагнічування `L_pri` та паразитну індуктивність розсіювання `L_leak`.

![Схема та осцилограма RCD-снабера первинного кола Flyback](img/rcd-flyback-clamp.svg)
*Принципова схема первинного кола Flyback-перетворювача з RCD-снабером та осцилограма напруги на стоку MOSFET. Снабер фіксує кіловольтний сплеск індуктивності розсіювання L_leak на безпечному рівні V_clamp.*

У мить закриття силового MOSFET-транзистора струм первинної обмотки сягає пікового значення `I_peak`. Енергія, накопичена в індуктивності розсіювання:

```
E_leak = 0.5 · L_leak · I_peak²
```

Ця енергія скидається через діод снабера `D_s` у паралельний RC-ланцюг `R_s || C_s`. Напруга на стоку транзистора фіксується на рівні:

```
V_ds_peak = V_in_max + V_snubber
```
де `V_snubber` — середня напруга на конденсаторі снабера.

Конденсатор снабера перебуває під постійною напругою `V_snubber`, яка повинна бути вищою за відбиту напругу вторинної обмотки `V_or`:

```
V_or = (N_pri / N_sec) · (V_out + V_diode_sec)
```

Струм індуктивності розсіювання під час перехідного процесу спадає не до нуля вольтів, а розряджається проти різниці потенціалів `(V_snubber - V_or)`. Час скидання енергії розсіювання в конденсатор:

```
t_reset = (L_leak · I_peak) / (V_snubber - V_or)
```

За час `t_reset` джерело магнітного поля індуктивності розсіювання передає в коло снабера повну енергію:

```
E_snubber_in = 0.5 · L_leak · I_peak² · (V_snubber / (V_snubber - V_or))
```

Середня потужність, що надходить у снабер за період перемикання `T_sw = 1 / f_sw`:

```
P_snubber_in = E_snubber_in · f_sw
= 0.5 · L_leak · I_peak² · f_sw · (V_snubber / (V_snubber - V_or))
```

У сталому режимі вся ця потужність повинна розсіюватися на розрядному резисторі `R_s` за законом Джоуля — Ленца:

```
P_snubber_R = V_snubber² / R_s
```

Прирівнюючи потужність надходження до потужності розсіювання:

```
V_snubber² / R_s = 0.5 · L_leak · I_peak² · f_sw · (V_snubber / (V_snubber - V_or))
```

Ділимо обидві частини на `V_snubber` і виражаємо шуканий опір `R_s`:

```
V_snubber / R_s = 0.5 · L_leak · I_peak² · f_sw / (V_snubber - V_or)
R_s = (2 · V_snubber · (V_snubber - V_or)) / (L_leak · I_peak² · f_sw)
```

#### Розрахунок ємності `C_s` за критерієм низьких пульсацій
Ємність конденсатора `C_s` обирають із розрахунку, щоб амплітуда змінної складової пульсацій напруги `ΔV_snubber` за період `T_sw` не перевищувала 5–10 % від середнього значення `V_snubber`:

```
ΔV_snubber = V_snubber / (R_s · C_s · f_sw)
C_s ≥ V_snubber / (R_s · ΔV_snubber · f_sw)
```

### 7. Покрокові приклади детального числового розрахунку

#### Приклад 1. Демпфування силового контактора DC
* Напруга постійного живлення: `V_cc = 24 В`.
* Струм утримування котушки: `I_0 = 0.5 А`.
* Індуктивність обмотки: `L = 80 мГн = 0.08 Гн`.
* Гранично допустима напруга на контактах: `V_max = 50 В`.

**Крок 1. Розрахунок мінімальної ємності снабера**:
```
C_s = (L · I_0²) / (V_max² - V_cc²)
= (0.08 · 0.5²) / (50² - 24²)        [підстановка параметрів схеми]
= (0.08 · 0.25) / (2500 - 576)       [обчислення квадратів величин]
= 0.02 / 1924                        [ділення значень]
≈ 1.039 · 10⁻⁵ Ф = 10.4 мкФ          [результат ємності]
```
Обираємо плівковий конденсатор номіналом `C_s = 10 мкФ`.

**Крок 2. Розрахунок характеристичного імпедансу**:
```
Z_0 = √(L / C_s)
= √(0.08 / (10 · 10⁻⁶))              [підстановка L та C_s]
= √8000                              [обчислення підкореневого виразу]
≈ 89.44 Ом                           [хвильовий опір контуру]
```
Обираємо номінал резистора `R_s = 91 Ом` (ряд E24).

**Крок 3. Перевірка початкового стрибка напруги**:
```
V_jump = V_cc + I_0 · R_s
= 24 + 0.5 · 91                      [підстановка струму й опору]
= 24 + 45.5                          [додавання напруги живлення]
= 69.5 В                             [перевірка проти V_max]
```
Оскільки стрибок 69.5 В перевищує ліміт 50 В, збільшуємо ємність до `C_s = 47 мкФ`:
```
Z_0_new = √(0.08 / (47 · 10⁻⁶))      [перерахунок Z_0 для нової ємності]
≈ 41.26 Ом                           [новий хвильовий імпеданс]
R_s_new = 39 Ом                      [вибір резистора з ряду E24]
V_jump_new = 24 + 0.5 · 39           [перерахунок стрибка напруги]
= 24 + 19.5                          [підсумовування]
= 43.5 В                             [результат безпечний: 43.5 В < 50 В]
```

#### Приклад 2. Розрахунок RCD-снабера для Flyback-перетворювача потужністю 60 Вт
* Максимальна напруга живлення DC шини: `V_in_max = 375 В`.
* Відбита напруга вторинної обмотки: `V_or = 100 В`.
* Піковий струм первинної обмотки: `I_peak = 2.5 А`.
* Індуктивність розсіювання трансформатора: `L_leak = 8 мкГн = 8 · 10⁻⁶ Гн`.
* Частота комутації ШІМ: `f_sw = 100 кГц = 10⁵ Гц`.
* Гранична напруга сток-витік MOSFET: `V_ds_max = 650 В`.
* Задаємо напругу фіксації снабера `V_snubber = 160 В` (тоді `V_ds_peak = 375 + 160 = 535 В`, що дає надійний запас 115 В до 650 В).

**Крок 1. Розрахунок розрядного опору `R_s`**:
```
R_s = (2 · V_snubber · (V_snubber - V_or)) / (L_leak · I_peak² · f_sw)
= (2 · 160 · (160 - 100)) / (8 · 10⁻⁶ · 2.5² · 100000) [підстановка значень]
= (320 · 60) / (8 · 10⁻⁶ · 6.25 · 10⁵)                 [обчислення чисельника і знаменника]
= 19200 / 5                                            [спрощення дробу]
= 3840 Ом = 3.84 кОм                                   [точний розрахунковий опір]
```
Обираємо стандартний номінал ряду E24: `R_s = 3.9 кОм`.

**Крок 2. Розрахунок розсіюваної теплової потужності резистора**:
```
P_R = V_snubber² / R_s
= 160² / 3900                        [підстановка напруги фіксації та опору]
= 25600 / 3900                       [ділення]
≈ 6.56 Вт                            [теплова потужність]
```
Для забезпечення теплової надійності та недопущення перегріву плати встановлюємо два паралельно з'єднаних резистори номіналом `7.8 кОм` (або `8.2 кОм`) потужністю по 5 Вт кожен (сумарна паспортна потужність 10 Вт).

**Крок 3. Розрахунок ємності снабера `C_s` для пульсацій `ΔV = 10 % = 16 В`**:
```
C_s ≥ V_snubber / (R_s · ΔV · f_sw)
= 160 / (3900 · 16 · 100000)         [підстановка параметрів]
= 160 / 6240000000                   [обчислення знаменника]
≈ 2.564 · 10⁻⁸ Ф = 25.64 нФ          [розрахункова ємність]
```
Обираємо стандартний високовольтний керамічний або металоплівковий конденсатор ємністю `C_s = 33 нФ` на робочу напругу `630 В`.
