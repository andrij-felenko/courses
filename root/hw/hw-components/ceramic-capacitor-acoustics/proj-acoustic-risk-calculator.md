# ⚙️ Інженерний розрахунок акустичного шуму MLCC та ризику чутності

Розрахунок акустичного ризику дозволяє виявити потенційну проблему «співу» керамічних конденсаторів ще на етапі схемотехнічного проектування та трасування друкованої плати, задовго до виготовлення першого фізичного прототипу. Комп'ютерна модель зв'язує воєдино чотири взаємопов'язані фізичні домени: мікроскопічну електродинаміку сегнетоелектричного кристала, механіку пружної деформації багатошарового пакета, модальну динаміку згинальних коливань текстолітової пластини та аероакустичне випромінювання звукових хвиль у навколишнє повітряне середовище.

Головна мета розрахунку — визначити, чи не потрапляє частота комутаційних пульсацій перетворювача в зону механічного резонансу плати, та обчислити очікуваний рівень звукового тиску в децибелах акустичної шкали `dBA` з урахуванням психоакустичної кривої чутливості людського слуху.

## Архітектура розрахункової моделі

Інженерний аналізатор побудовано за модульним принципом із послідовною передачею фізичних параметрів між чотирма розрахунковими блоками:

```
 ┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
 │   Електрика     │  ──►  │    Механіка     │  ──►  │  Динаміка PCB   │  ──►  │   Акустика      │
 │  V_dc, V_ripple │       │  d_eff, ΔL_pk   │       │  D, f_(m,n), Q  │       │  W_ac, SPL dBA  │
 └─────────────────┘       └─────────────────┘       └─────────────────┘       └─────────────────┘
```

### Модуль 1: Електромеханічне перетворення сегнетоелектричного кристала

У сегнетоелектричній кераміці класу II (діелектрик X7R на основі легованого титанату барію `BaTiO₃`) деформація під дією електричного поля описується сумою лінійного зворотного п'єзоефекту та квадратичної електрострикції:

```
S_z = d₃₃ · E_z + M₃₃ · E_z²
```

Оскільки товщина діелектричного шару `d_layer` у сучасних ультракомпактних конденсаторах становить від 1.0 до 3.0 мкм, робоча постійна напруга `V_dc = 5...24 В` створює надзвичайно сильне статичне електричне поле:

```
E_dc = V_dc / d_layer = 2...12 МВ/м
```

Розкладаючи сумарне змінне поле `E(t) = E_dc + E_ac · sin(ω · t)` у ряд Тейлора навколо робочої точки постійного зміщення `E_dc`, програма визначає лінеаризований ефективний п'єзомодуль першої гармоніки:

```
d_eff = d₃₃ + 2 · M₃₃ · E_dc
```

Поперечна деформація стискання корпусу вздовж головної осі довжини `X` виникає через пружну взаємодію кристалічної ґратки, що описується коефіцієнтом Пуассона кераміки `ν ≈ 0.30`. Амплітуда динамічної зміни довжини компонента `ΔL_pk` обчислюється як:

```
ΔL_pk = ν · d_eff · (V_ripple_pk / d_layer) · L_cap
```

Цей розрахунок показує, наскільки сильно стискається керамічний моноліт у горизонтальній площині під час кожного періоду електричних пульсацій.

### Модуль 2: Модальний аналіз друкованої плати

Друкована плата моделюється як тонка пружна пластина за класичною теорією пластин Кірхгофа — Лява. Циліндрична згинальна жорсткість текстоліту `D` обчислюється через ефективний модуль Юнга склотекстоліту FR4 (`E_pcb ≈ 22 ГПа`), коефіцієнт Пуассона (`ν_pcb ≈ 0.14`) та товщину плати `t_pcb`:

```
D = E_pcb · t_pcb³ / [12 · (1 - ν_pcb²)]
```

Спектр власних резонансних частот згинальних мод `(m, n)` прямокутної плати розміром `L_x × L_y` за шарнірного закріплення країв визначається аналітичним виразом:

```
f_(m,n) = (π / 2) · √[D / m_pcb] · [(m / L_x)² + (n / L_y)²]
```

де `m_pcb = ρ_pcb · t_pcb` — поверхнева густина плати (для FR4 густиною 1850 кг/м³ при товщині 1.6 мм становить 2.96 кг/м²).

Програма виконує дискретний пошук по двовимірній сітці просторових мод `(m = 1...6, n = 1...6)`, знаходячи резонансну моду, найближчу за частотою до електричних пульсацій перетворювача `f_ripple`.

### Модуль 3: Резонансний фактор підсилення

Резонансний динамічний відгук механічної коливальної системи описується передатною амплітудно-частотною характеристикою другого порядку:

```
Q_amp(f) = 1 / √[ (1 - (f / f_mode)²)² + (f / (Q · f_mode))² ]
```

Для стандартного склотекстоліту FR4 типове значення механічної добротності становить `Q ≈ 20...30`. Якщо частота електричних пульсацій точно збігається з однією з власних мод плати (`f_ripple ≈ f_mode`), амплітуда поперечного прогину плати зростає у 20–30 разів порівняно зі статичним зміщенням.

Динамічна амплітуда коливань центру плати `w_pk` та середньоквадратична швидкість вібрації поверхні `v_rms` розраховуються як:

```
static_w0 = ΔL_pk · [t_pcb / (2 · L_cap)]
w_pk = static_w0 · Q_amp
v_rms = (2 · π · f_ripple · w_pk) / √2
```

### Модуль 4: Аероакустичне випромінювання та психоакустичне зважування

Акустична потужність `W_ac`, що випромінюється поверхнею плати в навколишнє повітря, розраховується з урахуванням фактора ефективності акустичного випромінювання `σ_rad(f)` відносно критичної частоти збігу `f_crit = [c₀² / (2π)] · √(m_pcb / D)`:

```
W_ac = σ_rad(f) · ρ₀ · c₀ · A_pcb · <v_rms²>
```

Звуковий тиск `p_rms` у вільному півпросторі на відстані `r` (типово 0.5 м) перераховується у логарифмічний рівень звукового тиску `SPL` (дБ) відносно міжнародного порогу чутності `p_ref = 20 мкПа`:

```
SPL = 20 · log₁₀(p_rms / p_ref)
```

Для коректної оцінки сприйняття звуку людським вухом програма застосовує стандартне A-зважування (IEC 61672-1), яке накладає частотну фільтрацію та обчислює підсумковий рівень шуму у шкалі `dBA`.

## Детальний розбір розрахункового прикладу

Розглянемо покроковий фізичний зміст числових результатів, отриманих у тестовому розрахунку:

1. **Електромеханічна лінеаризація:** Прикладення постійної напруги зміщення 12 В створює в тонкому 2-мікрометровому діелектрику постійне поле напруженістю 6.0 МВ/м. Це збільшує ефективний п'єзоелектричний коефіцієнт `d_eff` з початкових 200 пм/В до 2600 пм/В (у 13 разів). Як наслідок, змінна пульсація викликає значно потужніший динамічний відгук, ніж за відсутності постійного зміщення.
2. **Резонансний збіг:** Пульсація напруги на частоті 3.45 кГц майже точно збігається з власною згинальною модою плати `f_(1,3) ≈ 3730 Гц` або `f_(3,2) ≈ 3159 Гц`. Це спричиняє механічне підсилення амплітуди коливань плати у 15–25 разів відповідно до добротності текстоліту `Q = 25`.
3. **Підсумковий звуковий тиск:** Рівень звукового тиску досягає 74.8 дБА на відстані 50 см. Це критичний рівень, що відповідає гучній розмові і робить пристрій повністю непридатним для використання в житлових приміщеннях або офісах (де граничний допустимий рівень шуму побутової техніки в режимі сну становить не більше 25–30 дБА).

## Аналіз чутливості моделі до проектних параметрів

Чутливість підсумкового рівня акустичного шуму до різних інженерних параметрів неоднакова:

- **Товщина плати `t_pcb` (найвищий вплив):** Оскільки циліндрична згинальна жорсткість плати пропорційна кубу товщини `D ∝ t_pcb³`, перехід із тонкої плати 0.8 мм на стандартну 1.6 мм збільшує жорсткість у 8 разів, що знижує амплітуду вібрацій на 18 дБ. Збільшення товщини до 2.0–2.4 мм забезпечує додаткове зниження шуму на 6–10 дБ.
- **Товщина шару діелектрика `d_layer`:** Застосування конденсатора більшого типорозміру (наприклад, 1210 замість 0603 того самого номіналу) дозволяє виробнику збільшити товщину шару діелектрика `d_layer` у 2–3 рази. Це знижує внутрішню напруженість поля `E_dc` та `E_ac`, зменшуючи ефективний п'єзомодуль `d_eff` у 4–6 разів.
- **Внутрішні суцільні шари міді (GND/PWR planes):** Багатошарові плати (4–8 шарів) із суцільними мідними полігонами живлення та землі мають вищий еквівалентний модуль Юнга (`E_eff ≈ 26...30 ГПа` проти 22 ГПа у двошарового FR4) та підвищений коефіцієнт в'язкого демпфування на межах шарів препрегу, що зменшує добротність резонансу `Q` з 25–30 до 12–15.
- **Аспектне співвідношення сторін плати `L_x / L_y`:** Квадратні плати (`L_x ≈ L_y`) мають вироджені моди коливань (збіг частот мод `(m,n)` та `(n,m)`), що призводить до подвоєння резонансного піку. Прямокутні плати з аспектним співвідношенням 1.5–1.8 розносять моди по частотному спектру, зменшуючи ймовірність сильного резонансного сплеску.

## Крайові випадки та межі застосування моделі

При використанні даного алгоритму для специфічних класів апаратури необхідно враховувати фізичні межі базових припущень:

1. **Ультракомпактні плати носимих пристроїв (Smartwatches, TWS-навушники):** Якщо габарити плати менші за 20 × 20 мм, базова згинальна мода `f_(1,1)` зміщується вище 15–20 кГц (виходить за межі звукового діапазону). У таких пристроях акустичний резонанс плати практично неможливий, а випромінювання звуку визначається виключно вібрацією пластикового корпусу приладу.
2. **Великі материнські плати серверів та телевізорів:** При габаритах понад 300 × 200 мм густина спектра резонансних мод стає дуже високою (моди розташовані з інтервалом 20–50 Гц). У такій системі практично будь-яка частота комутації PFM потрапить на одну з власних мод. Єдиним ефективним рішенням стає збільшення кількості точок кріплення гвинтами до металевого шасі з кроком не більше 50–70 мм.
3. **Паралельне ввімкнення декількох конденсаторів:** Якщо на шині живлення встановлено групу з `N` паралельних MLCC, розташованих поруч на відстані менше 5 мм, їхні динамічні сили додаються синфазно, збільшуючи еквівалентний згинальний момент у `N` разів (+6 дБ для двох конденсаторів, +12 дБ для чотирьох). Навпаки, розміщення конденсаторів у різних кутах плати створює просторову деструктивну інтерференцію хвиль, знижуючи загальний випромінений звуковий тиск.
4. **Вплив гумових демпферів та стійок шасі:** Використання еластичних силіконових втулок (Grommets) під кріпильними гвинтами плати трансформує граничні умови з жорстких у в'язкопружні. Це знижує добротність коливань `Q` у 2–3 рази та зміщує резонансні піки, зменшуючи передачу звукової вібрації на металевий корпус виробу.
5. **Акустичні резонанси корпусу (Кавітаційні та Гельмгольцові ефекти):** Якщо плата встановлена всередині закритого пластикового або металевого боксу, внутрішній об'єм повітря разом із вентиляційними отворами утворює резонатор Гельмгольца. Якщо власна частота акустичної каверни збігається з частотою пульсацій конденсатора, виникає додаткове посилення звукового випромінювання на 10–15 дБ.

## Психоакустична помітність тонального шуму

Згідно зі стандартом ISO 7779 та методикою ECMA-74, оцінка шуму електронного обладнання враховує не лише сумарний рівень у `dBA`, а й **коефіцієнт виразності тону** (*Prominence Ratio*):

- Людина значно гостріше реагує на чистий дискретний тональний свист (наприклад, одиночний тон 3.5 кГц), ніж на широкосмуговий шум вентилятора тієї самої гучності.
- Тональний пік вважається суб'єктивно «дратівливим» і неприйнятним, якщо він перевищує рівень навколишнього широкосмугового шуму в критичній смузі слуху (Bark band) лише на **6–9 дБ**.
- Саме тому свист конденсатора потужністю лише 35 дБА часто викликає більше скарг споживачів, ніж шум кулера системи охолодження з рівнем 45 дБА.

## Практичні рекомендації за категоріями ризику

На основі розрахованого значення `SPL (dBA)` інженерна система формує такі рекомендації щодо модифікації проекту:

- **Категорія «НЕЧУТНО» (`< 25 дБА`):** Заходи не потрібні. Рівень шуму нижчий за природний фоновий шум тихої кімнати.
- **Категорія «ПОМІРНИЙ» (`25...38 дБА`):** Шум може бути помітним у повній тиші поруч із приладом. Рекомендовано змістити конденсатор ближче до кріпильного отвору плати або замінити його на версію із захистом Soft-Termination.
- **Категорія «ВИСОКИЙ» (`38...52 дБА`):** Дратівливий високочастотний писк. Обов'язкове впровадження одного з рішень:
  1. Двосторонній симетричний монтаж двох однакових конденсаторів (Top/Bottom mirroring) для взаємної компенсації згинальних моментів;
  2. Фрезерування акустичних пазів (Isolation Slots) навколо контактних майданчиків;
  3. Перемикання DC-DC перетворювача в примусовий режим безперервної комутації (FCCM).
- **Категорія «КРИТИЧНИЙ» (`> 52 дБА`):** Нестерпний гучний свист, ризик механічного руйнування припою від вібрації. Необхідна повна заміна компонента на безп'єзоелектричний полімерний конденсатор (POSCAP, KO-CAP) або конденсатор із металевими рамками (Metal Cap / KRM).

## Лабораторна верифікація та вимірювальний стенд

Для експериментальної перевірки результатів симуляції застосовують лабораторний комплекс:
1. **Безконтактний лазерний доплерівський віброметр (LDV — Laser Doppler Vibrometer):** Сканує сітку точок на поверхні плати з просторовою роздільною здатністю 0.5 мм, вимірюючи реальну амплітуду швидкості `v_rms` та форму згинальних мод.
2. **Акустичний вимірювальний мікрофон 1/2 дюйма класу 1:** Встановлюється у безлунній камері (або звукоізольованому боксі) на відстані 0.5 м по нормалі до центру плати.
3. **Аудіоаналізатор спектра (FFT Analyzer):** Фіксує спектральну густину звукового тиску в смузі 20 Гц – 20 кГц із застосуванням стандартного A-зважування.

Зіставлення виміряних даних із розрахунковою моделлю підтверджує точність прогнозування резонансних частот у межах ±8% та абсолютного рівня звукового тиску в межах ±3...5 дБА.

## Інтеграція алгоритму в САПР друкованих плат (EDA DRC)

Автоматизація акустичного аналізу в середовищі САПР (наприклад, KiCad PCB Calculator або Altium Designer Extension) реалізується як додаткове правило проектування (Design Rule):

1. **Екстракція даних зі схеми (Netlist Parsing):** Для кожного конденсатора класу II аналізатор зчитує робочу постійну напругу лінії `V_dc`, очікувану частоту комутації перетворювача `f_sw` та амплітуду пульсацій `V_ripple` за результатами SPICE-моделювання.
2. **Геометричний аналіз топології (Board Geometry):** З файлу шарів плати витягуються розміри контуру `L_x`, `L_y`, товщина `t_pcb`, кількість мідних шарів та координати розміщення кріпильних отворів.
3. **Розрахунок модального збігу та акустичного тиску:** Алгоритм викликає обчислювальне ядро для кожної підозрілої пари «конденсатор — плата».
4. **Формування звіту та підсвічування на платі:** Якщо розрахований рівень `SPL` перевищує заданий поріг (наприклад, 35 дБА), компонент підсвічується помаранчевим або червоним кольором у редакторі плат із пропозицією заміни на Metal Cap або додавання розвантажувальних пазів.

## Чек-лист інженера для усунення акустичного шуму

При виявленні акустичного шуму на фізичному макеті рекомендується виконувати таку послідовність практичних діагностичних дій:

- [ ] **Крок 1 (Ідентифікація):** Притиснути дерев'яною або пластиковою діелектричною паличкою почергово підозрілі конденсатори та дроселі. Зміна тону або повне зникнення звуку при легкому механічному притисканні вказує на точне джерело збудження коливань.
- [ ] **Крок 2 (Осцилографічний контроль):** Підключити щуп осцилографа з короткою пружинною заземлювальною насадкою в режимі закритого входу (AC Coupling) безпосередньо до виводів конденсатора та виміряти точну частоту і розмах `V_pk` змінних пульсацій.
- [ ] **Крок 3 (Швидка схемотехнічна перевірка):** Якщо напруга пульсацій викликана PFM/Burst режимом, перевести мікросхему стабілізатора в режим FCCM (примусовий ШІМ) подачею логічного рівня на відповідний вивід (наприклад, MODE або SYNC).
- [ ] **Крок 4 (Компонентна заміна):** Якщо вимкнення PFM неприпустиме через суворі вимоги до енергоспоживання, замінити звичайний MLCC на компонент серії Metal Cap (Murata KRM) або танталовий полімерний конденсатор (Panasonic POSCAP).
- [ ] **Крок 5 (Топологічна модифікація для наступної ревізії):** Якщо плата йде на редизайн, додати симетричний конденсатор на зворотному боці або розвантажувальний паз у шарі фрезерування контуру.
- [ ] **Крок 6 (Демпфування шасі):** За необхідності швидкого серійного доопрацювання нанести на ділянку плати навколо конденсатора шар силіконового компаунду (RTV Potting) або встановити м'які прокладки між платою та стійками корпусу.
- [ ] **Крок 7 (Акустична верифікація):** Провести контрольне вимірювання шумоміром класу 1 у звукоізольованій камері на відстані 0.5 м, переконавшись, що рівень звукового тиску не перевищує 25 дБА в усьому діапазоні навантажень.
