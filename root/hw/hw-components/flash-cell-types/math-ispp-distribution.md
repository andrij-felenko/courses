# 🧮 Математика ISPP: від кроку напруги до дисперсії порогового розподілу

Покрокове імпульсне програмування ISPP (англ. *Incremental Step Pulse Programming*) є базовим аналоговим алгоритмом, який переносить задану кількість електронів у плаваючий затвор чи нітридну пастку заряду Flash-комірки. Алгоритм забезпечує формування компактних статистичних розподілів порогової напруги `V_th` для кожного інформаційного стану.

## Геометрія циліндричного 3D-конденсатора та коефіцієнт зв'язку

У сучасній архітектурі 3D NAND Flash комірка пам'яті являє собою коаксіальний циліндр, де центральний кремнієвий канал радіуса `r_ch` оточений тунельним діоксидом кремнію товщиною `t_tox`, нітридною пасткою заряду товщиною `t_trap` та зовнішнім блокувальним оксидом товщиною `t_box`.

Ємність циліндричного діелектричного шару довжиною `L` з відносною діелектричною проникністю `ε_r` визначається за формулою коаксіального конденсатора:

```
C_cyl = 2 · π · ε_0 · ε_r · L / ln(r_out / r_in)
```

Коефіцієнт ємнісного зв'язку керувального затвора `α_cg` визначає, яка саме частка прикладеної до лінії Wordline напруги `V_cg` передається на внутрішній шар пастки заряду:

```
α_cg
= C_box / (C_box + C_tox + C_ch)         [визначення: ємнісний подільник напруги]
= C_box / C_total                        [де C_total — повна ємність циліндричної комірки]
```

Завдяки повній круговій геометрії Gate-All-Around (GAA) коефіцієнт зв'язку в 3D CTF досягає `α_cg ≈ 0.65–0.75`, що істотно вище за показники планарних плаваючих затворів (`α_cg ≈ 0.50–0.55`).

## Фізика тунелювання та зсув порогової напруги

Інжекція електронів у пастку заряду відбувається за механізмом тунелювання Фаулера — Нордгейма крізь трикутний потенціальний бар'єр тунельного діелектрика. Густина струму тунелювання `J_FN` експоненційно залежить від напруженості електричного поля `E_ox` в тунельному оксиді:

```
J_FN = A · E_ox² · exp(-B / E_ox)
```

де `A` та `B` — константи Фаулера — Нордгейма, що визначаються ефективною масою електрона в діелектрику та висотою потенціального бар'єра на межі кремній-діоксид.

Напруженість поля в оксиді `E_ox` створюється різницею потенціалів між плаваючим затвором (або пасткою) `V_fg` та кремнієвим каналом підкладки `V_ch = 0`:

```
E_ox = V_fg / t_ox
```

Потенціал плаваючого затвора `V_fg` визначається напругою на керувальному затворі `V_cg` через коефіцієнт ємнісного зв'язку `α_cg`:

```
V_fg = α_cg · V_cg + Q_fg / C_total
```

де `Q_fg` — накопичений негативний заряд електронів, а `C_total` — сумарна ємність комірки.

Порогова напруга транзистора `V_th` — це напруга на керувальному затворі `V_cg`, за якої потенціал `V_fg` досягає порогу інверсії каналу `V_th0`. Звідси випливає фундаментальний зв'язок порогової напруги з накопиченим зарядом:

```
V_th - V_th0
= -Q_fg / (α_cg · C_total)      [визначення: заряд екранує зовнішнє поле затвора]
= -Q_fg / C_box                 [спрощення: C_box = α_cg · C_total — міжелектродна ємність]
```

Оскільки заряд електронів негативний (`Q_fg < 0`), накопичення електронів збільшує `V_th`.

## Рівняння динаміки ISPP та ширина розподілу

Алгоритм ISPP подає послідовність імпульсів напруги на керувальний затвор. Напруга кожного наступного імпульсу `k+1` зростає на фіксовану величину кроку `ΔV_ispp`:

```
V_cg[k+1] = V_cg[k] + ΔV_ispp
```

Після кожного імпульсу тривалістю `t_pulse` контролер подає на затвор напругу верифікації `V_pv` і перевіряє, чи відкрився канал транзистора. Якщо струм каналу менший за опорний поріг компаратора, комірка вважається запрограмованою (`V_th ≥ V_pv`), і подальші імпульси на цей стовпчик масиву блокуються подачею напруги інгібування на лінію Bitline.

Розглянемо приріст порогової напруги за один крок `ΔV_th[k] = V_th[k+1] - V_th[k]`. В усталеному режимі програмування кожен крок імпульсу збільшує порогову напругу рівно на величину кроку затвора:

```
ΔV_th[k]
= ΔQ_fg / C_box                          [зміна порогової напруги від доданого заряду]
= (J_FN · Area · t_pulse) / C_box        [заряд як інтеграл струму тунелювання за час імпульсу]
= ΔV_ispp                                [умова динамічної рівноваги тунелювання]
```

Оскільки алгоритм зупиняє подачу імпульсів у момент, коли порогова напруга вперше перетинає рівень верифікації `V_pv`, максимальна похибка перельоту визначається величиною останнього приросту `ΔV_ispp`.

Кінцева теоретична ширина розподілу порогової напруги `W_dist` для даного стану складається з величини кроку `ΔV_ispp` та апаратної невизначеності вимірювання струму:

```
W_dist
= ΔV_ispp + δ_sense + δ_noise            [повна ширина статистичного розподілу]
= ΔV_ispp + (I_sense_tol / g_m) + δ_noise [де g_m — крутизна ВАХ, I_sense_tol — похибка компаратора]
```

## Інтегральне збурення невибраних комірок (Program Disturb)

Під час виконання `N_pulses` кроків алгоритму ISPP на вибраній лінії Wordline всі сусідні невибрані комірки того самого блока відчувають напругу пропуску `V_pass ≈ 7–8 В`.

Хоча напруженість поля при `V_pass` нижча за робоче поле тунелювання, за час тривалості всіх імпульсів `t_total = N_pulses · t_pulse` через тунельний діелектрик невибраних стертих комірок протікає інтегральний паразитний струм:

```
Q_disturb
= ∫ J_FN(V_pass) · Area · dt             [інтегрування за час усіх імпульсів запису сторінки]
= J_FN(V_pass) · Area · N_pulses · t_pulse [для однакових імпульсів тривалістю t_pulse]
```

Паразитний зсув порогової напруги стертих комірок `ΔV_th_disturb` пропорційний загальній кількості імпульсів:

```
ΔV_th_disturb
= Q_disturb / C_box                      [зсув порогової напруги від фонового тунелювання]
= (J_FN(V_pass) · Area · t_pulse / C_box) · N_pulses [пряма залежність від кількості ітерацій ISPP]
```

Це накладає строге обмеження знизу на вибір кроку `ΔV_ispp`: надмірне зменшення кроку заради звуження розподілів збільшує `N_pulses`, що спричиняє деградацію стертого стану через Program Disturb.

## Статистична дисперсія та дробовий шум електронів

У субмікронних комірках 3D NAND кількість електронів у кожному стані є малою, тому порогова напруга зазнає впливу квантового дробового шуму (Shot Noise) інжекції носіїв.

Кількість захоплених електронів `N_e` підпорядковується розподілу Пуассона із середньоквадратичним відхиленням:

```
σ_N = √N_e
```

Внесок пуассонівського шуму в дисперсію порогової напруги `σ_shot` виражається через заряд одного електрона `q` та ефективну міжелектродну ємність `C_box`:

```
σ_shot
= (q / C_box) · σ_N                      [переведення флуктуації кількості електронів у напругу]
= (q / C_box) · √N_e                     [підстановка дисперсії Пуассона]
= √(q · (V_th - V_th0) / C_box)          [вираз через цільовий зсув порогової напруги]
```

Для типової комірки 3D CTF з ємністю `C_box ≈ 1.0·10⁻¹⁷ Ф` та зарядом `N_e ≈ 100` електронів флуктуація становить `σ_N = 10` електронів, що дає незгладжувану похибку `σ_shot ≈ 16 мВ`. Це фундаментальне фізичне обмеження, яке неможливо усунути зменшенням кроку `ΔV_ispp`.

Крім того, дефекти на межі кремній-діоксид створюють телеграфний шум RTN (Random Telegraph Noise), викликаний випадковим захопленням та вивільненням поодиноких електронів. Амплітуда RTN у 3D-комірках сягає 30–50 мВ, розширюючи хвости розподілів напруг.

## Розрахунковий приклад: TLC проти QLC

Обчислимо необхідну кількість імпульсів програмування `N_pulses` та сумарний час запису для комірок TLC та QLC за типових параметрів:
- Діапазон зміни порогової напруги від стертого стану до верхнього: `ΔV_total = 4.8 В`;
- Тривалість одного імпульсу запису разом із тактом верифікації: `t_step = 30 мкс`.

**Для комірки TLC:**
- Допустима ширина одного стану: `W_dist = 0.35 В`;
- Обираємо крок `ΔV_ispp = 0.25 В` (з урахуванням `δ_sense ≈ 0.10 В`).

Кількість імпульсів та час програмування:

```
N_pulses_TLC
= ΔV_total / ΔV_ispp                     [базова формула кількості кроків]
= 4.8 / 0.25                             [підстановка параметрів]
≈ 20                                     [округлення до цілих імпульсів]

t_PROG_TLC
= N_pulses_TLC · t_step                  [сумарний час запису]
= 20 · 30 мкс                            [підстановка значень]
= 600 мкс                                [чистий час формувань рівнів]
```

**Для комірки QLC:**
- Допустима ширина одного стану: `W_dist = 0.15 В`;
- Обираємо крок `ΔV_ispp = 0.08 В` (щоб `W_dist = 0.08 + 0.07 = 0.15 В`).

Кількість імпульсів та час програмування:

```
N_pulses_QLC
= ΔV_total / ΔV_ispp                     [кількість кроків для QLC]
= 4.8 / 0.08                             [підстановка параметрів]
= 60                                     [потрібно втричі більше імпульсів]

t_PROG_QLC
= N_pulses_QLC · t_step                  [сумарний час запису]
= 60 · 30 мкс                            [підстановка значень]
= 1800 мкс                               [утричі більша затримка запису]
```

Зменшення кроку `ΔV_ispp` у 3.1 раза дозволило втиснути в 2 рази більше бітів (з 3 до 4), але збільшило затримку запису сторінки рівно в 3 рази.
