# 🧮 Математика температурного дрейфу та ємнісного підтягування кварцу

Температурний дрейф годинникового кварцу, ємнісне зміщення точки резонансу генератора Пірса та похибка дискретного квантування вікна калібрування RTC підкоряються строгим аналітичним закономірностям п'єзоакустики та цифрової схемотехніки. Точний розрахунок хронометричної похибки вимагає дослідження чотирьох взаємопов'язаних математичних моделей: ряду Тейлора для згинальних коливань камертонного зрізу, визначеного інтеграла добових гармонійних коливань температури, диференціальної чутливості частоти до навантажувальної ємності та дискретної арифметики калібрувального вікна 2²⁰ тактів.

---

### Тейлорівське розкладання та параболічна модель камертонного зрізу

Резонансна частота п'єзоелектричного камертонного резонатора (зріз XY або NT) визначається його геометричними розмірами (довжиною і товщиною зубців), густиною кварцу та ефективним модулем пружності Юнга E(T) уздовж напрямку вигину. При зміні температури T лінійне теплове розширення та температурна залежність пружних констант кварцу спричиняють зміну власної частоти коливань.

Розкладемо відносну зміну частоти в околі опорної точки перегину T₀ (зазвичай T₀ = 25 °C) у ряд Тейлора:

```
f(T) - f(T_0)     1   df            1     d²f
------------- = ---- ---- · (T-T_0) + --- ------- · (T-T_0)² + O((T-T_0)³)
   f(T_0)       f_0   dT |T_0         2f_0 dT² |T_0
```

Для резонаторів згинальних коливань (Tuning Fork) кристал орієнтують під таким кутом до кристалографічних осей, щоб перший температурний коефіцієнт частоти (лінійний член) в обраній робочій точці дорівнював нулю:

```
    1   df
α = --- ---- = 0   [вибір кута зрізу для екстремуму при T_0]
    f_0  dT |T_0
```

Другий температурний коефіцієнт (коефіцієнт кривини параболи) визначає квадратичну залежність:

```
    1     d²f
β = --- ------- ≈ -0.035 ... -0.040 ppm/°C²   [квадратичний коефіцієнт параболи]
    2f_0 dT² |T_0
```

Оскільки вищі члени ряду Тейлора для камертонного зрізу мають знехтовно малий внесок у промисловому діапазоні температур від −40 °C до +85 °C, відносне відхилення частоти Δf / f₀ набуває канонічного вигляду квадратичної параболи:

```
Δf(T)
----- = -k · (T - T_0)²   [де k = -β = 0.035 ... 0.040 ppm/°C²]
 f_0
```

Фундаментальна властивість цього рівняння: коефіцієнт k > 0, тому знак мінус є константою. Камертонний кварц за будь-якого відхилення температури від вершини параболи T₀ (як у бік охолодження, так і в бік нагрівання) **завжди зменшує свою частоту**. Некомпенсований годинник на згинальному кварці завжди відстає, ніколи не поспішає внаслідок температурного фактора.

### Інтегрування накопиченого дрейфу часу за гармонійного добового циклу

У польових умовах (вуличні лічильники, необігрівані шафи телеметрії) температура навколишнього середовища зазнає добових коливань навколо середнього значення. Нехай температура змінюється за гармонійним законом із періодом T_day = 86400 с:

```
T(t) = T_avg + ΔT_m · sin(ω·t)   [де ω = 2π / 86400 рад/с]
```

Підставимо профіль T(t) у квадратичну функцію частотного дрейфу:

```
Δf(t)
----- = -k · [ (T_avg - T_0) + ΔT_m · sin(ω·t) ]²
 f_0

      = -k · [ (T_avg - T_0)² + 2·(T_avg - T_0)·ΔT_m·sin(ω·t) + ΔT_m²·sin²(ω·t) ]
```

Накопичений фазовий зсув часу Δt_drift за повний добовий цикл T_day визначається визначеним інтегралом:

```
               T_day
Δt_{drift} = ∫       (Δf(t) / f_0) dt
               0
```

Обчислимо інтеграли від кожного доданка окремо:

```
1) Інтеграл сталого відхилення:
   T_day
 ∫       -k·(T_avg - T_0)² dt = -k · (T_avg - T_0)² · T_day
   0

2) Інтеграл лінійного гармонійного члена:
   T_day
 ∫       2·(T_avg - T_0)·ΔT_m·sin(ω·t) dt = 0   [інтеграл синуса за повний період дорівнює нулю]
   0

3) Інтеграл квадрата синуса:
   T_day                                  T_day   1 - cos(2ωt)
 ∫       ΔT_m² · sin²(ω·t) dt = ΔT_m² · ∫       -------------- dt = 0.5 · ΔT_m² · T_day
   0                                        0          2
```

Об'єднавши результати, отримуємо точний вираз для середньодобового відхилення частоти:

```
(Δf / f_0)_avg = -k · [ (T_avg - T_0)² + 0.5 · ΔT_m² ]
```

Цей результат розкриває важливий фізичний ефект: **навіть якщо середньодобова температура T_avg точно дорівнює оптимальній точці перегину T₀ = 25 °C, наявність добових коливань амплітудою ΔT_m = 15 °C породжує додатковий від'ємний зсув частоти**:

```
(Δf / f_0)_fluc = -0.035 · 0.5 · 15² = -3.9375 ppm
```

За місяць (30 діб) цей шум коливань створює систематичне відставання:

```
Δt = -3.9375 · 10⁻⁶ · 30 · 86400 с = -10.2 с/місяць
```

Якщо ж середня температура зміщена (наприклад, зимова експлуатація при T_avg = −10 °C, ΔT_m = 10 °C):

```
1) Статична складова: (T_avg - T_0)² = (-10 - 25)² = 35² = 1225 °C²
2) Флуктуаційна складова: 0.5 · 10² = 50 °C²
3) Сумарне відхилення: -0.035 · (1225 + 50) = -0.035 · 1275 = -44.625 ppm
4) Добовий дрейф: -44.625 · 10⁻⁶ · 86400 с ≈ -3.856 с/добу
5) Місячний дрейф: -3.856 · 30 ≈ -115.7 с/місяць (~1.93 хвилини)
```

### Ємнісне підтягування (Frequency Pulling) та диференціальна чутливість

Еквівалентна електрична схема кварцового резонатора (модель Баттерворта — Ван Дайка) складається з послідовного динамічного контуру (динамічна індуктивність L₁, динамічна ємність C₁, динамічний опір втрат R₁) та паралельної статичної ємності електродів і корпусу C₀.

Послідовна резонансна частота механічної гілки:

```
           1
f_s = ------------
      2π · √(L_1·C_1)
```

При підключенні зовнішньої навантажувальної ємності C_L еквівалентна сумарна паралельна ємність контуру становить C_total = C₀ + C_L. Робоча паралельна резонансна частота генератора f_L зміщується вище f_s:

```
                       C_1
f_L = f_s · √[ 1 + ------------ ]
                   C_0 + C_L
```

Оскільки для кварцу C₁ ≪ C₀ + C_L (типово C₁ ≈ 2.5 фФ = 0.0025 пФ, тоді як C₀ ≈ 1.2 пФ, C_L ≈ 12.5 пФ), застосуємо лінійне наближення √(1 + x) ≈ 1 + x/2:

```
                    C_1
f_L ≈ f_s · [ 1 + -------------- ]
                  2·(C_0 + C_L)
```

#### Чутливість частоти до похибки навантажувальної ємності

Візьмемо першу похідну від f_L за змінною C_L:

```
df_L          f_s · C_1
---- = - ------------------   [Гц/пФ]
dC_L     2 · (C_0 + C_L)²
```

Нормована відносна чутливість підтягування S(C_L):

```
           1   df_L           C_1
S(C_L) = ---- ----- = - ------------------   [1/пФ або ppm/пФ]
         f_s  dC_L      2 · (C_0 + C_L)²
```

Обчислимо числове значення S(C_L) для двох поширених специфікацій годинникових кварців:

#### Варіант A: Стандартний кварц на C_{L,nom} = 12.5 пФ (C₁ = 2.5 фФ, C₀ = 1.2 пФ)

```
1) Знаменник: 2 · (1.2 + 12.5)² = 2 · (13.7)² = 2 · 187.69 = 375.38 пФ²
2) Чутливість: S = -0.0025 / 375.38 = -6.66 · 10⁻⁶ пФ⁻¹ = -6.66 ppm/пФ
```

Похибка номіналу дискретних конденсаторів обв'язки або паразитний розлив припою на друкованій платі величиною всього +1.0 пФ спричиняє сталий зсув:

```
Δf / f = -6.66 ppm   →   дрейф ходу: -6.66 · 0.0864 с = -0.575 с/добу (-17.3 с/місяць)
```

#### Варіант B: Мікропотужний кварц на C_{L,nom} = 6.0 пФ (C₁ = 2.0 фФ, C₀ = 1.0 пФ)

```
1) Знаменник: 2 · (1.0 + 6.0)² = 2 · 7.0² = 2 · 49.0 = 98.0 пФ²
2) Чутливість: S = -0.0020 / 98.0 = -20.41 · 10⁻⁶ пФ⁻¹ = -20.41 ppm/пФ
```

Низькоємнісні кварци (6 пФ) споживають значно менший струм збудження, але мають **втричі вищу чутливість до паразитної ємності монтажу** (−20.4 ppm/пФ). Будь-яке забруднення плати, вологість чи неточність трасування миттєво відхиляють частоту на десятки ppm.

### Дискретна арифметика плавного цифрового калібрування (Smooth Calibration)

Апаратний блок цифрового калібрування в RTC мікроконтролерів (наприклад, STM32, NXP LPC, Microchip SAM) базується на періодичному вікні вимірювання T_cal, яке містить рівно N_total = 2²⁰ = 1048576 вхідних тактів базової частоти 32768 Гц (тривалість вікна T_cal = 1048576 / 32768 = 32.000000 с).

Квант калібрувальної роздільності Δ_step дорівнює вазі одного імпульсу, доданого або вилученого за час одного 32-секундного вікна:

```
                  1           1
Δ_{step} = ------------- = ------- ≈ 0.953674316 ppm
           2²⁰ імпульсів   1048576
```

У часовому вимірі один крок калібрування коригує добовий хід на:

```
Δt_{step} = 0.953674316 · 10⁻⁶ · 86400 с/добу ≈ 0.082397 с/добу
```

#### Синтез калібрувальних регістрів CALM та CALP

Нехай виміряне на виході калібрувального піна (512 Гц або 1 Гц) відносне відхилення частоти дорівнює δ = Δf / f₀ (виражене в ppm).

Алгоритм розбивається на дві гілки:

#### 1. Кварц поспішає (δ > 0, генератор працює швидше номіналу)
Для сповільнення лічильника необхідно вилучати (маскувати) імпульси. Встановлюємо біт `CALP = 0`, а значення регістра маскування `CALM[8:0]` (9-бітне поле, від 0 до 511) обчислюємо за формулою округлення до найближчого цілого:

```
CALM = round( δ / Δ_{step} ) = floor( δ / 0.953674316 + 0.5 )
```

Максимальне компенсоване позитивне відхилення при CALM = 511:

```
δ_{max, mask} = 511 · 0.953674316 ppm = +487.3275 ppm
```

#### 2. Кварц відстає (δ < 0, типовий випадок за низьких/високих температур)
Для прискорення лічильника вмикаємо біт додавання імпульсів `CALP = 1`. Апаратний блок `CALP` вставляє рівно 512 імпульсів на кожні 2²⁰ циклів (1 імпульс кожні 2048 тактів), що еквівалентно зміщенню:

```
Δ_{CALP} = +512 · Δ_{step} = +488.28125 ppm
```

Регістр `CALM` використовується для точного зменшення цієї надлишкової доданої частоти до потрібного значення:

```
CALM = round( (Δ_{CALP} - |δ|) / Δ_{step} )
     = floor( (488.28125 - |δ|) / 0.953674316 + 0.5 )
```

Діапазон від'ємної компенсації: від 0 ppm до −488.28 ppm.

#### Залишкова дискретна похибка калібрування

Оскільки CALM є цілим числом, залишкова похибка квантування ε_quant строго обмежена половиною кроку сітки:

```
|ε_{quant}| ≤ 0.5 · Δ_{step} ≈ 0.4768 ppm
```

Це гарантує, що після правильного налаштування регістрів за стабільної температури похибка ходу не перевищуватиме:

```
|Δt_{residual}| ≤ 0.4768 · 10⁻⁶ · 86400 с ≈ 0.0412 с/добу (~1.23 с/місяць)
```
