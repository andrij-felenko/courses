# 🧮 Іонний транспорт у сильних полях і кінетика формування оксиду

Діелектричний оксидний шар на поверхні вентильних металів росте за кімнатної температури лише тому, що зовнішнє електричне поле всередині плівки сягає колосальних значень `10⁷` В/см (`10⁹` В/м). За звичайних умов іони кристалічної решітки або міжвузля надійно замкнені в потенціальних ямах глибиною `1.5–2.0` еВ, і ймовірність їхнього термоактивованого перескоку за температури 300 K практично дорівнює нулю. Щоб зрозуміти, чому напруга формує строго визначену нанометрову товщину діелектрика, як просторовий заряд викривляє поле і як струм затухає в часі, необхідно побудувати мікроскопічну та термодинамічну теорію іонного переносу.

### Потенціал Мотта і спонтанний ріст природного оксиду

Перш ніж підключати зовнішнє джерело живлення, свіжоочищений метал на повітрі або у ванні миттєво вкривається тонким шаром природного (native) оксиду завтовшки `d_native ≈ 1.5–3.0` нм. Механізм цього спонтанного росту за кімнатної температури пояснює теорія Кабрери — Мотта.

Коли молекули кисню або гідроксильні групи адсорбуються на поверхні металу, виникає різниця між рівнем Фермі металу `E_F` і незаповненими електронними рівнями адсорбованого кисню. Оскільки товщина первинного оксиду менша за довжину де Бройля для електрона (менше 2–3 нм), електрони квантовомеханічно тунелюють крізь оксидний бар'єр на зовнішню поверхню, іонізуючи кисень:

```
O_ads + 2 e⁻(tunnel) → O²⁻_ads
```

Перехід електронів заряджає поверхню негативно, а метал під нею — позитивно. Виникає контактна різниця потенціалів — **потенціал Мотта** `V_M`:

```
V_M = (Φ_metal − χ_oxide − ΔE_F) / e ≈ 1.5–2.5 В   [потенціал Мотта]
```

Оскільки цей потенціал падає на надтонкому шарі `d ≈ 2` нм, усередині природного оксиду спонтанно виникає колосальне внутрішнє електричне поле без будь-якої батареї:

```
E_Mott = V_M / d = 2.0 В / (2.0 · 10⁻⁷ см) = 10⁷ В/см = 10⁹ В/м
```

Це поле втягує іони крізь решітку, доки товщина не досягне граничного значення `d_Mott ≈ 2.5–3.5` нм, при якому квантове тунелювання електронів різко обривається, а поле `E_Mott = V_M / d` падає нижче критичного порогу іонного дрейфу. Подальше збільшення товщини вимагає підключення зовнішнього джерела напруги.

### Електрохімічний потенціал і рушійна сила іонного дрейфу

Термодинамічною рушійною силою перенесення зарядженої частинки (іона сорту `k` із зарядом `q_k = z_k · e`) у конденсованому середовищі є градієнт її електрохімічного потенціалу `μ̃_k`. Електрохімічний потенціал об'єднує хімічну спорідненість частинки та її електростатичну потенційну енергію в полі з потенціалом `φ(x)`:

```
μ̃_k = μ_k + z_k · e · φ(x)
    = μ_k⁰ + k_B · T · ln(a_k) + z_k · e · φ(x)   [розклад за хімічною активністю a_k]
```

де `μ_k⁰` — стандартний хімічний потенціал, `k_B` — стала Больцмана, `T` — абсолютна температура, `a_k` — термодинамічна активність іона (в розведеному наближенні — його концентрація `n_k`).

За відсутності сильного електричного поля потік іонів `J_k` описується класичним рівнянням Нернста — Планка, що враховує градієнт концентрації (дифузію з коефіцієнтом `D_k`) та повільний дрейф у слабкому полі `E = −dφ/dx` з рухливістю `u_k = (z_k · e · D_k) / (k_B · T)`:

```
J_k = −D_k · (dn_k / dx) + u_k · n_k · E   [лінійне рівняння Нернста — Планка]
```

У процесі анодного оксидування напруженість поля сягає `E ≈ 10⁷` В/см. За такого поля електростатична енергія, що передається іону на відстані одного міжатомного стрибка `a ≈ 0.3–0.5` нм, становить `q · E · a ≈ (3 · e) · (10⁹ В/м) · (0.35 · 10⁻⁹ м) ≈ 1.05` еВ. Ця величина на два порядки перевищує теплову енергію `k_B · T ≈ 0.026` еВ. Лінійне наближення Нернста — Планка перестає працювати, і кінетика переходить у режим екстремально нелінійного високопольового іонного транспорту.

### Модель Вервея — Кабрери — Мотта: термопольова активація

Розглянемо мікроскопічний механізм руху катіона металу крізь періодичну потенціальну ґратку оксиду. Нехай `W₀` — висота симетричного потенціального бар'єра між сусідніми міжвузлями за відсутності поля, `a` — відстань між сусідніми мінімумами потенціалу, `ν ≈ 10¹²–10¹³` с⁻¹ — власна частота коливань іона в потенціальній ямі (частота Дебая).

За відсутності поля ймовірність перескоку в одиницю часу однакова в усіх напрямках і визначається больцманівським фактором `P₀ = ν · exp(−W₀ / (k_B · T))`.

Коли вздовж осі `x` прикладено електричне поле `E`, потенційна енергія іона вздовж координати зазнає лінійного нахилу `ΔU(x) = −q · E · x`. Вершина бар'єра, розташована на відстані `x = a / 2`, зміщується по енергії. У результаті ефективна висота бар'єра для стрибка за напрямком поля знижується, а проти поля — зростає:

```
W_forward  = W₀ − (q · a · E) / 2      [зниження бар'єра у напрямку поля]
W_backward = W₀ + (q · a · E) / 2      [підвищення бар'єра проти поля]
```

Частота перескоків уперед і назад:

```
Γ_forward  = ν · exp(−(W₀ − q · a · E / 2) / (k_B · T))   [частота перескоків за полем]
Γ_backward = ν · exp(−(W₀ + q · a · E / 2) / (k_B · T))   [частота перескоків проти поля]
```

Густина результуючого іонного струму `j_ion` дорівнює добутку заряду `q = z · e`, об'ємної концентрації рухливих іонів `n`, довжини стрибка `a` та різниці частот перескоків:

```
j_ion = q · n · a · (Γ_forward − Γ_backward)
      = q · n · a · ν · exp(−W₀ / (k_B · T)) · (exp((q · a · E) / (2 · k_B · T)) − exp(−(q · a · E) / (2 · k_B · T)))   [підстановка частот]
      = 2 · q · n · a · ν · exp(−W₀ / (k_B · T)) · sinh((q · a · E) / (2 · k_B · T))                                     [використання означення sinh]
```

Перевіримо величину безрозмірного аргументу `ξ = (q · a · E) / (2 · k_B · T)` для тривалентного алюмінію (`z = 3`, `a = 0.35` нм) при кімнатній температурі (`T = 298` K) та робочому полі анодування `E = 8 · 10⁶` В/см:

```
ξ = (3 · 1.602 · 10⁻¹⁹ · 0.35 · 10⁻⁹ · 8 · 10⁸) / (2 · 1.381 · 10⁻²³ · 298)
  = (1.346 · 10⁻¹⁹) / (8.231 · 10⁻²¹)
  ≈ 16.35                                                                      [безрозмірний аргумент >> 1]
```

Оскільки `ξ ≈ 16.35 >> 1`, зворотний експоненційний член `exp(−ξ) ≈ exp(−16.35) ≈ 7.9 · 10⁻⁸` є нескінченно малим. Використовуючи асимптотику `sinh(ξ) ≈ 0.5 · exp(ξ)`, отримуємо класичне емпіричне рівняння Гюнтершульце — Бетца:

```
j_ion(E) = j₀ · exp(B · E)
```

де мікроскопічні константи процесу виражаються через характеристики кристалічної ґратки:

```
j₀ = q · n · a · ν · exp(−W₀ / (k_B · T))   [передекспоненційний множник, А/см²]
B  = (q · a) / (2 · k_B · T)                [коефіцієнт електропольового підсилення, см/В]
```

### Вплив просторового заряду: рівняння Пуассона всередині оксиду

У найпростішій моделі електричне поле всередині діелектрика вважається строго однорідним: `E = U / d`. Проте за високих густин іонного струму рухливі катіони `Mᶻ⁺` утворюють ненульовий об'ємний просторовий заряд із густиною `ρ_space(x) = z · e · n(x)`.

Розподіл електричного поля `E(x)` вздовж товщини оксиду підпорядковується одновимірному рівнянню Пуассона:

```
dE / dx = ρ_space(x) / (ε₀ · ε_r) = (z · e · n(x)) / (ε₀ · ε_r)
```

За умов стаціонарного іонного струму `j_ion = const` густина струму в кожному перерізі однакова: `j_ion = z · e · n(x) · v_drift(x) = const`. Оскільки дрейфова швидкість `v_drift(x) ∝ exp(B · E(x))`, концентрація іонів зв'язана з полем:

```
n(x) = j_ion / (z · e · v₀ · exp(B · E(x)))
```

Підставляючи це співвідношення в рівняння Пуассона:

```
dE / dx = (j_ion / (ε₀ · ε_r · v₀)) · exp(−B · E(x))
```

Інтегруючи це диференціальне рівняння від внутрішньої межі металу (`x = 0`, `E = E_0`) до зовнішньої межі (`x = d`):

```
∫ exp(B · E) dE = ∫ (j_ion / (ε₀ · ε_r · v₀)) dx
(1 / B) · exp(B · E(x)) = (j_ion / (ε₀ · ε_r · v₀)) · x + C_const
```

Розв'язок показує, що напруженість поля монотонно зростає від межі «метал — оксид» до межі «оксид — електроліт». Для тонких бар'єрних плівок (до 100 нм) градієнт поля не перевищує 5–8%, тому наближення однорідного поля `E ≈ U / d` є високорівнево точним для інженерних розрахунків.

### Диференціальне рівняння росту товщини оксиду

Згідно з законами Фарадея, маса утвореного оксиду `m` пропорційна пропущеному заряду. Для узагальненої реакції окиснення вентильного металу:

```
2 M + z H₂O → M₂O_z + 2z H⁺ + 2z e⁻
```

Швидкість приросту товщини плівки `d` визначається молярною масою утвореного оксиду `M_ox`, його густиною `ρ`, валентністю реакції `z_ox` (числом електронів на формульну одиницю оксиду) і сталою Фарадея `F = 96485` Кл/моль:

```
dd / dt = (M_ox / (z_ox · F · ρ)) · j_ion · η_faraday
```

де `η_faraday` — вихід за струмом (частка іонного струму в загальному струмі ланцюга; для чистого Al та Ta `η_faraday ≈ 0.98–1.00`).

Позначимо питомий електрохімічний еквівалент об'єму оксиду як `Ω_ox = M_ox / (z_ox · F · ρ)`:

Для анодного оксиду алюмінію Al₂O₃ (`M_ox = 101.96` г/моль, `z_ox = 6`, `ρ = 3.1` г/см³):

```
Ω_ox(Al₂O₃)
= 101.96 / (6 · 96485 · 3.1)       [підстановка молярної маси, валентності, сталої Фарадея та густини]
= 101.96 / 1794621                 [обчислення знаменника]
≈ 5.68 · 10⁻⁵ см³ / Кл = 0.568 нм · см² / мкКл   [розрахунок питомого об'єму оксиду]
```

Для оксиду танталу Ta₂O₅ (`M_ox = 441.89` г/моль, `z_ox = 10`, `ρ = 8.2` г/см³):

```
Ω_ox(Ta₂O₅)
= 441.89 / (10 · 96485 · 8.2)      [підстановка молярної маси, валентності, сталої Фарадея та густини]
= 441.89 / 7911770                 [обчислення знаменника]
≈ 5.59 · 10⁻⁵ см³ / Кл = 0.559 нм · см² / мкКл   [розрахунок питомого об'єму оксиду]
```

Для оксиду ніобію Nb₂O₅ (`M_ox = 265.81` г/моль, `z_ox = 10`, `ρ = 4.6` г/см³):

```
Ω_ox(Nb₂O₅)
= 265.81 / (10 · 96485 · 4.6)      [підстановка молярної маси, валентності, сталої Фарадея та густини]
= 265.81 / 4438310                 [обчислення знаменника]
≈ 5.99 · 10⁻⁵ см³ / Кл = 0.599 нм · см² / мкКл   [розрахунок питомого об'єму оксиду]
```

Підставляючи експоненційний закон Гюнтершульце — Бетца в диференціальне рівняння росту, отримуємо фундаментальне нелінійне рівняння кінетики анодування:

```
dd / dt = Ω_ox · j₀ · exp(B · U(t) / d(t))
```

### Динаміка росту в гальваностатичному та потенціостатичному режимах

Промисловий процес формування діелектрика складається з двох послідовних стадій: стадії постійної густини струму (Constant Current, CC) та стадії витримки при постійній напрузі (Constant Voltage, CV).

#### 1. Стадія сталого струму (CC: Constant Current)

При підтриманні постійної густини струму `j_ion = j_const` швидкість росту товщини строго стала:

```
dd / dt = Ω_ox · j_const = const
```

Інтегруючи цей вираз за початкової товщини природного оксиду `d₀`:

```
d(t) = d₀ + (Ω_ox · j_const) · t
```

Оскільки `j_ion` фіксований, напруженість поля всередині оксиду залишається незмінною:

```
E_form = (1 / B) · ln(j_const / j₀) = const
```

Звідси напруга на комірці `U(t) = E_form · d(t)` зростає строго лінійно в часі:

```
dU / dt = E_form · (dd / dt) = E_form · Ω_ox · j_const
```

#### 2. Стадія сталої напруги (CV: Constant Voltage)

Коли напруга досягає заданого значення `U = U_form`, джерело живлення стабілізує напругу. Товщина плівки продовжує повільно збільшуватися, що призводить до неперервного падіння напруженості поля `E(t) = U_form / d(t)`.

Диференціюючи поле по часу при `U = const`:

```
dE / dt = d(U_form / d) / dt                        [диференціювання виразу поля за U = const]
        = −(U_form / d²) · (dd / dt)                [похідна складеної функції]
        = −(E² / U_form) · Ω_ox · j₀ · exp(B · E)   [підстановка E = U_form / d та швидкості росту dd/dt]
```

Розв'язок цього рівняння дає гіперболічний закон спаду густини струму в часі:

```
j_ion(t) = j_start / (1 + t / τ_decay)
```

де характерний час спаду струму `τ_decay = 1 / (B · E_form · Ω_ox · j_start)`.

Струм швидко спадає на 3–5 порядків — від міліамперів до мікроамперів. При цьому товщина оксиду добирає лічені нанометри, стабілізуючи дефекти та фіксуючи кінцеву товщину.

#### 3. Енергетичний баланс та теплове розсіювання при анодуванні

Електрична енергія, що передається від джерела живлення у ванну анодування, розподіляється між двома фундаментальними каналами: термодинамічною ентальпією утворення оксиду `ΔH_form` (корисна хімічна робота) та джоулевим тепловиділенням `Q_joule` внаслідок іонного тертя у надсильному полі:

```
W_total = ∫ U(t) · I(t) dt = ΔH_form · (m_ox / M_ox) + Q_joule
```

Ентальпія утворення оксиду алюмінію становить `ΔH_form(Al₂O₃) = −1675.7` кДж/моль. Термодинамічна рівноважна ЕРС реакції окиснення алюмінію у водному середовищі за рівнянням Нернста становить `E_rev = −ΔG⁰ / (z · F) ≈ 1.23` В.

Оскільки реальна напруга формування `U_form` (десятки або сотні вольтів) на два порядки перевищує термодинамічну ЕРС `E_rev`, енергетичний ККД процесу анодування становить лічені відсотки:

```
η_energy = E_rev / U_form ≈ 1.23 В / 50 В ≈ 2.5%
```

Решта 97.5% підведеної електричної потужності `P(t) ≈ U(t) · I(t)` безпосередньо розсіюється у вигляді тепла в нанометровому шарі оксиду та об'ємі електроліту. Це вимагає обов'язкового безперервного примусового охолодження ванн анодування (теплообмінники з циркуляцією холодоагенту при 15–20 °C), оскільки локальний перегрів оксиду понад 80–90 °C викликає термічну деградацію, розчинення плівки та сцинтиляційний пробій.

### Виведення анодної сталої формування

Оскільки ріст оксиду зупиняється, коли поле спадає до критичної межі `E_crit`, нижче якої дрейф іонів припиняється, кінцева товщина бар'єрного шару `d` лінійно залежить від напруги формування `U_form`:

```
d = α_v · U_form + d_native
```

де `α_v = 1 / E_crit` — анодна стала формування.

Зв'язок анодної сталої з мікроскопічними параметрами:

```
α_v = B / ln(j_crit / j₀) = (q · a) / (2 · k_B · T · ln(j_crit / j₀))
```

З цього рівняння безпосередньо випливає температурна залежність анодної сталої: при підвищенні температури електроліту теплова енергія `k_B · T` допомагає іонам долати бар'єр, тому для досягнення тієї самої швидкості росту потрібне менше електричне поле `E_crit`. Отже, при нагріванні електроліту величина `α_v` зростає (оксид виростає товщим на кожен вольт).

Значення анодних констант за температури 25 °C:

```
α_v(Al₂O₃) = 1 / (7.5 · 10⁶ В/см)  ≈ 1.33 нм/В   [діапазон 1.2–1.4 нм/В]
α_v(Ta₂O₅) = 1 / (5.3 · 10⁶ В/см)  ≈ 1.88 нм/В   [діапазон 1.7–2.0 нм/В]
α_v(Nb₂O₅) = 1 / (4.0 · 10⁶ В/см)  ≈ 2.50 нм/В   [діапазон 2.4–2.8 нм/В]
α_v(TiO₂)  = 1 / (3.0 · 10⁶ В/см)  ≈ 3.30 нм/В   [діапазон 2.8–3.5 нм/В]
```

### Об'ємна енергетична щільність діелектрика

Питома ємність на одиницю площі плоского бар'єрного шару:

```
C / A = (ε₀ · ε_r) / d = (ε₀ · ε_r) / (α_v · U_form)
```

Добуток питомої ємності на напругу формування `(C · U_form) / A` визначає поверхневу густину накопиченого заряду:

```
(C · U_form) / A = (ε₀ · ε_r) / α_v = ε₀ · ε_r · E_crit
```

Об'ємна густина енергії електричного поля `w_e`, накопичена в шарі діелектрика при робочому полі `E_work = U_work / d`:

```
w_e = (ε₀ · ε_r · E_work²) / 2
```

Для танталового оксиду Ta₂O₅ при `E_work = 3.0 · 10⁶` В/см (`300` кВ/мм) та `ε_r = 27`:

```
w_e(Ta₂O₅)
= (8.854 · 10⁻¹² · 27 · (3.0 · 10⁸)²) / 2       [підстановка електричної сталої, проникності та поля]
= (2.391 · 10⁻¹⁰ · 9.0 · 10¹⁶) / 2              [піднесення напруженості поля до квадрата]
≈ 1.076 · 10⁷ Дж/м³ = 10.76 Дж/см³              [розрахунок об'ємної густини енергії]
```

Це надзвичайно висока густина енергії для електростатичного поля, яка досягається виключно завдяки здатності нанометрового анодного оксиду тримати гігантські електричні поля без пробою.

### Частотна дисперсія та тангенс кута діелектричних втрат

Під впливом змінного електричного поля в анодному оксиді виникають діелектричні втрати, обумовлені запізненням поляризації (дипольної та релаксаційної поляризації дефектів решітки). Комплексна діелектрична проникність описується моделлю Дебая або Коул — Коула:

```
ε*(ω) = ε_inf + (ε_static − ε_inf) / (1 + (j · ω · τ_rel)^(1 − α_cc))
```

де `ε_static` — низькочастотна проникність, `ε_inf` — оптична проникність, `τ_rel` — характерний час діелектричної релаксації, `α_cc` — параметр розподілу часів релаксації в аморфній сітці (`0 ≤ α_cc < 1`).

Повні втрати конденсатора на змінному струмі частоти `f = ω / (2 · π)` складаються з власних діелектричних втрат оксиду (паралельний опір витоку `R_p`) та омічного опору електроліту й виводів (послідовний опір `R_s = ESR`):

```
tan δ = 1 / (2 · π · f · C · R_p) + 2 · π · f · C · R_s
```

На низьких частотах (до 100 Гц) домінує перший член (струм витоку через діелектрик). На середніх і високих частотах (1 кГц — 100 кГц) домінує другий член (`2 · π · f · C · ESR`).

### Модель де Леві: імпеданс пористого анода та спад ємності на високих частотах

Для пористого або тунельно-протравленого анода розрахунок імпедансу ускладнюється тим, що струм змінного поля протікає крізь довгі вузькі циліндричні канали електроліту. Згідно з теорією Роберта де Леві (Robert de Levie, 1963), одиночна циліндрична пора радіусом `r` і довжиною `l`, заповнена електролітом із питомим опором `ρ_el`, поводиться як електрична RC-лінія з неперервно розподіленими параметрами.

Погонний опір стовпчика електроліту на одиницю довжини пори:

```
R_line = ρ_el / (π · r²)   [погонний опір каналу, Ом/м]
```

Погонна ємність діелектричного оксидного шару на стінках пори на одиницю довжини:

```
C_line = (2 · π · r · ε₀ · ε_r) / d   [погонна ємність стінок, Ф/м]
```

Диференціальні рівняння напруги `V(x)` і струму `I(x)` вздовж осі пори:

```
dV / dx = −R_line · I(x)
dI / dx = −j · ω · C_line · V(x)
```

Диференціюючи перше рівняння по `x` і підставляючи друге, отримуємо класичне хвильове телеграфне рівняння для пори:

```
d²V / dx² = (j · ω · R_line · C_line) · V(x) = γ_pore² · V(x)
```

де стала поширення `γ_pore = √(j · ω · R_line · C_line) = (1 + j) · √(ω · R_line · C_line / 2)`.

Розв'язок за граничної умови ізольованого дна пори (`I(l) = 0`) дає комплексний вхідний імпеданс одиночної пори:

```
Z_pore(ω) = √(R_line / (j · ω · C_line)) · coth(γ_pore · l)
```

Граничні асимптотики моделі де Леві:

1. **Низькі частоти (`|γ_pore · l| << 1`, тобто `f << 1 / (2 · π · R_line · C_line · l²)`):**
   Використовуючи розклад `coth(u) ≈ 1/u + u/3`:
   ```
   Z_pore(ω) ≈ 1 / (j · ω · C_total) + R_total / 3   [повна ємність усього об'єму пори]
   ```
   Змінний струм проникає на всю глибину каналу `l`. Ефективна ємність дорівнює повній геометричній ємності стінок `C_total = C_line · l`, а еквівалентний послідовний опір дорівнює третині повного омічного опору електроліту `R_total / 3 = (R_line · l) / 3`.

2. **Високі частоти (`|γ_pore · l| >> 1`):**
   Оскільки `coth(u) → 1` при `Re(u) >> 1`:
   ```
   Z_pore(ω) ≈ √(R_line / (2 · ω · C_line)) · (1 − j)
   ```
   У цій області активна та реактивна складові імпедансу однакові, а фазовий кут строго дорівнює −45° (імпеданс Варбурга). Ефективна ємність падає пропорційно `1 / √ω`:
   ```
   C_eff(ω) = 1 / (ω · Im(Z)) = √(C_line / (2 · ω · R_line)) ∝ 1 / √f
   ```

Глибина проникнення змінного струму в глибину пори `λ_pen = 1 / Re(γ_pore) = √(2 / (ω · R_line · C_line))` стає меншою за довжину пори `l`. Змінний струм заряджає лише гирло каналу, залишаючи глибокі внутрішні ділянки анода неактивними. Це строге математичне виведення пояснює, чому високопористі аноди втрачають ємність на високих частотах і чому перехід на провідні полімери з низьким `ρ_el` є критичним для високої швидкодії.

### Розрахунковий приклад: спад струму витоку на стадії CV

**Умова.** Танталовий анод площею `A = 500` см² сформовано до напруги `U_form = 30` В. На стадії CV напруга утримується сталою. Параметри оксиду: `B = 5.0 · 10⁻⁷` см/В, `j₀ = 10⁻¹⁸` А/см², `Ω_ox = 5.6 · 10⁻⁵` см³/Кл. Початковий струм на стадії перемикання становить `I_start = 50` мА. Обчислити товщину оксиду в точці перемикання та час спаду струму до `50` мкА.

```
1. Товщина оксиду при струмі 50 мА (j_start = 50 · 10⁻³ / 500 = 10⁻⁴ А/см²):
   E_start = (1 / B) · ln(j_start / j₀)
           = (1 / (5.0 · 10⁻⁷)) · ln(10⁻⁴ / 10⁻¹⁸)
           = 2.0 · 10⁶ · ln(10¹⁴)
           = 2.0 · 10⁶ · 32.236
           ≈ 6.447 · 10⁶ В/см = 0.6447 В/нм

   d_start = U_form / E_start
           = 30 / 0.6447
           ≈ 46.53 нм

2. Необхідне поле для спаду струму до 50 мкА (j_end = 50 · 10⁻⁶ / 500 = 10⁻⁷ А/см²):
   E_end = (1 / B) · ln(j_end / j₀)
         = 2.0 · 10⁶ · ln(10⁻⁷ / 10⁻¹⁸)
         = 2.0 · 10⁶ · ln(10¹¹)
         = 2.0 · 10⁶ · 25.328
         ≈ 5.066 · 10⁶ В/см = 0.5066 В/нм

   d_end = U_form / E_end
         = 30 / 0.5066
         ≈ 59.22 нм

3. Приріст товщини на стадії витримки:
   Δd = d_end − d_start
      = 59.22 − 46.53
      = 12.69 нм

4. Сумарний іонний заряд на одиницю площі, необхідний для приросту Δd:
   ΔQ / A = Δd / Ω_ox
          = (12.69 · 10⁻⁷ см) / (5.6 · 10⁻⁵ см³/Кл)
          ≈ 0.02266 Кл/см²

5. Характерний час витримки (за середнього логарифмічного струму):
   j_avg ≈ (j_start − j_end) / ln(j_start / j_end)
         = (10⁻⁴ − 10⁻⁷) / ln(1000)
         = 9.99 · 10⁻⁵ / 6.908
         ≈ 1.446 · 10⁻⁵ А/см²

   t_soak ≈ (ΔQ / A) / j_avg
          = 0.02266 / (1.446 · 10⁻⁵)
          ≈ 1567 с ≈ 26 хвилин
```

Цей розрахунок наочно демонструє технологічну необхідність стадії CV: щоб перевести оксид у високонадійний діелектричний стан із мінімальним струмом витоку, товщину оксиду необхідно наростити всього на 12.7 нм при експоненційно спадаючому струмі.
