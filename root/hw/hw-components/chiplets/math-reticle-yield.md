# 🧮 Математична модель виходу чиплетів, ліміту фотошаблона та вартості KGD

Економічна доцільність розбиття монолітної системи-на-кристалі на окремі чиплети спирається на три взаємопов'язані математичні моделі: оптичне обмеження апертури літографічного сканера (ліміт фотошаблона), нелінійну статистику випадкових дефектів на кремнієвій пластині (моделі виходу придатних кристалів) та ймовірнісну модель збірки з урахуванням вичерпного тестування (Known Good Die).

---

### 1. Оптична апертура сканера та межа поля фотошаблона

Сучасні літографічні сканери ультрафіолетового діапазону (DUV з довжиною хвилі `lambda = 193 нм` та EUV з довжиною хвилі `lambda = 13.5 нм`) працюють за принципом проекційного покрокового сканування (Step-and-Scan). Роздільна здатність оптичної системи визначається критерієм Релея:

```
CD = k₁ · (λ / NA)

CD  — критичний розмір елемента (Critical Dimension)
k₁  — технологічний коефіцієнт процесу (для EUV k₁ ≈ 0.40–0.45)
λ   — довжина хвилі випромінювання (13.5 нм для EUV)
NA  — числова апертура об'єктива (Numerical Aperture, для стандартного EUV NA = 0.33)
```

Оптична система сканера переносить зображення з фотошаблона (маски) на поверхню кремнієвої пластини зі стандартним коефіцієнтом оптичного зменшення `M = 4` (`4× Reduction`).

Фізичний розмір кварцової підкладки фотошаблона стандартизований міжнародною асоціацією SEMI і становить 6 дюймів (`152.4 мм × 152.4 мм`). З урахуванням полів фіксації, маркерів юстування та периферійних зон максимальне корисне поле експонування на фотошаблоні дорівнює `104 мм × 132 мм`.

При 4-кратному оптичному зменшенні максимальний розмір єдиного кадру експонування на поверхні кремнію становить:

```
W_max = 104 мм / 4 = 26.0 мм
H_max = 132 мм / 4 = 33.0 мм
A_reticle = W_max × H_max = 26.0 мм × 33.0 мм = 858.0 мм²
```

Це значення є фундаментальною фізичною **межею фотошаблона** (Reticle Limit).

#### Проблема переходу до High-NA EUV (NA = 0.55)
У наступному поколінні літографічних сканерів High-NA EUV зі збільшеною апертурою `NA = 0.55` кут падіння променів на дзеркальну маску стає занадто крутим, що викликає ефект затінення 3D-структур маски. Щоб усунути затінення без втрати світлосили, оптичну систему зробили анаморфотною (Anamorphic Optics): зменшення по осі X лишається 4-кратним (`4×`), а по осі Y збільшується до 8-кратного (`8×`).

Внаслідок цього висота кадру на кремнії зменшується вдвічі:

```
W_high_na = 104 мм / 4 = 26.0 мм
H_high_na = 132 мм / 8 = 16.5 мм
A_high_na = 26.0 мм × 16.5 мм = 429.0 мм²
```

Для сканерів High-NA EUV максимальна площа монолітного кристала скорочується рівно вдвічі — до `429 мм²`. Створення будь-якого процесора більшої площі стає фізично неможливим без зшивання полів або переходу на чиплетну архітектуру.

#### Математика дефектів літографічного зшивання
Якщо монолітний кристал перевищує площу одного кадру, сканер експонує його суміжними кадрами з перекриттям. Похибка суміщення (Overlay Error) накопичується за квадратичним законом від трьох джерел:

```
E_total = √(E_scanner² + E_mask² + E_thermal²)
```

Імовірність виходу придатних виробів на межі шва експоненційно залежить від довжини лінії стику `L_stitch` та щільності критичних помилок суміщення `lambda_align`:

```
P_stitch = e^(−L_stitch · λ_align)
```

Для монолітного чипа площею `1200 мм²`, де довжина шва становить `L_stitch = 33 мм`, за типової щільності дефектів суміщення `lambda_align = 0.008 мм⁻¹` втрати виходу лише через зшивання становлять:

```
P_stitch = e^(−33 × 0.008) = e^(−0.264) ≈ 0.768   (втрата 23.2% кристалів на шві)
```

### 2. Розподіл розміру дефектів та критична площа кристала

Не кожен дефект на кремнієвій пластині є фатальним («дефектом-убивцею», Killer Defect). Якщо розмір частинки пилу значно менший за ширину провідника або відстань між металевими лініями, вона не викликає замикання чи розриву. 

Розподіл розмірів дефектів `x` на пластині описується степеневим законом Стаппера (Stapper Defect Size Distribution):

```
f(x) = (2 · x_0²) / x³,   при x ≥ x_0
```

де `x_0` — мінімальний розмір дефекту, який здатне зафіксувати метрологічне обладнання сканування.

Ймовірність відмови схеми визначається **критичною площею** (Critical Area) `A_crit(x)`, яка залежить від топології розведення провідників на кристалі. Інтегральна густина фатальних дефектів дорівнює:

```
D_killer = D_total · ∫[0..∞] (A_crit(x) / A_total) · f(x) dx
```

Для обчислювальних ядер CPU/GPU з високою щільністю ліній 3 нм відношення `A_crit / A_total` сягає 0.70–0.85, тоді як для пасивного інтерпозера CoWoS із широкими провідниками воно не перевищує 0.15–0.25. Це пояснює, чому кремнієвий інтерпозер навіть великої площі має набагато вищий вихід придатних виробів, ніж активний монолітний процесор.

### 3. Математичне виведення моделей виходу придатних кристалів (Yield)

#### Виведення моделі Пуассона
Розглянемо кремнієвий кристал площею `A`, на якому випадково з'являються точкові дефекти з середньою густиною `D` (кількість дефектів на одиницю площі). Середня очікувана кількість дефектів на кристал дорівнює `mu = D · A`.

Розіб'ємо площу кристала на `N` мікроскопічних ділянок настільки малого розміру, що кожна ділянка може містити максимум один дефект з імовірністю `p = (D · A) / N`. Імовірність того, що кристал містить рівно `k` дефектів, описується біноміальним розподілом:

```
P(k) = (N! / (k! · (N − k)!)) · p^k · (1 − p)^(N − k)
```

Спрямувавши `N -> inf` при фіксованому добутку `N · p = D · A`, перейдемо до границі за теоремою Пуассона:

```
lim [N -> ∞] (1 − (D · A) / N)^N = e^(−D · A)
```

Кристал є повністю працездатним, якщо кількість дефектів на ньому дорівнює нулю (`k = 0`):

```
Y_Poisson = P(0) = e^(−D · A)
```

#### Виведення моделі Мерфі (з урахуванням флуктуацій густини дефектів)
У реальному виробництві густина дефектів не є постійною величиною по всій площі пластини: біля країв пластини густина дефектів вища через неоднорідність газових потоків у реакторах плазмового травлення. Припустимо, що локальна густина дефектів `D` є випадковою величиною з симетричною трикутною функцією густини ймовірності `f(D)` з центром у точці `D_0` та півшириною `D_0`:

```
f(D) = (1 / D_0) · (1 − |D − D_0| / D_0),   при 0 ≤ D ≤ 2·D_0
```

Підсумковий інтегральний вихід дорівнює математичному сподіванню виходу Пуассона за всіма значеннями густини дефектів:

```
Y_Murphy = ∫[0..2·D_0] e^(−D · A) · f(D) dD
```

Розбивши інтеграл на дві ділянки від `0` до `D_0` та від `D_0` до `2·D_0` та взявши інтегрування частинами, отримуємо точну формулу моделі Мерфі:

```
Y_Murphy = ((1 − e^(−D₀ · A)) / (D₀ · A))²
```

#### Виведення моделі Сідса (від'ємний біноміальний розподіл дефектів)
Якщо дефекти на пластині утворюють просторові скупчення (кластери), локальна густина дефектів `D` підпорядковується неперервному гамма-розподілу з параметром форми `alpha` та масштабом `beta = alpha / D_0`:

```
f_gamma(D) = (β^α / Γ(α)) · D^(α − 1) · e^(−β · D)
```

Інтегруючи вихід Пуассона за гамма-розподілом:

```
Y_Seeds = ∫[0..∞] e^(−D · A) · f_gamma(D) dD
        = (β^α / Γ(α)) · ∫[0..∞] D^(α − 1) · e^(−(A + β) · D) dD
        = (β / (A + β))^α
        = (1 + (D₀ · A) / α)^(−α)
```

При сильному кластеруванні (`alpha -> 0`) дефекти концентруються у вузьких зонах, залишаючи решту площі пластини чистою, що підвищує вихід для малих кристалів. При `alpha -> inf` формула Сідса математично переходить у модель Пуассона.

### 4. Геометричний розрахунок брутто-кристалів на пластині (DPW)

Кількість прямокутних кристалів розміром `w × h` (площею `A = w · h`), які можна фізично розмістити на круглій пластині діаметром `d = 300 мм`, обмежується крайовим ефектом.

```
N_gross = (π · (d / 2)²) / A − (π · d) / √(2 · A)

Перший член: ідеальна площа кола пластини, поділена на площу одного кристала
Другий член: поправка на неможливість розміщення цілих прямокутників уздовж периметра
```

Виведемо поправочний коефіцієнт: довжина кола пластини дорівнює `pi · d`. Середня довжина хорди прямокутного кристала, що перетинає межу кола, за теоремою Піфагора дорівнює діагоналі `sqrt(w² + h²) / 2`. Для квадратного кристала діагональ дорівнює `sqrt(2 · A)`. Поділивши периметр на цю діагональ, отримуємо кількість кристалів, що неминуче обрізаються краєм круглої пластини.

### 5. Оптимізація ступеня розбиття на чиплети (Partition Optimization)

Вибір кількості чиплетів `K`, на які розбивається обчислювальна логіка загальною площею `A_total`, є задачею знаходження глобального мінімуму цільової функції вартості:

```
Cost_total(K) = (K · Cost_die(A_total / K) + Cost_iod) / (Y_pkg(K) · Y_kgd(K)) + Cost_interposer(K) + K · Cost_assembly
```

Простежимо характер поведінки складових при зміні `K`:
1. **Вартість кремнію `K · Cost_die(A_total / K)`:** монотонно спадає зі зростанням `K`, оскільки вихід малих кристалів наближається до 95–98%.
2. **Накладні витрати пакування `Cost_interposer + K · Cost_assembly`:** лінійно зростають зі збільшенням кількості кристалів `K` через потребу в більшій площі підкладки та складнішому циклі монтажу.
3. **Ймовірність дефекту збірки `Y_pkg(K)`:** експоненційно падає як `(Y_assembly_step)^K`.

Внаслідок перетину спадної кремнієвої кривої та зростаючої пакувальної кривої функція має чітко виражений мінімум при `K* = 4..8` чиплетів для процесорів серверного класу.

### 6. Термомеханічні напруження TSV та заборонена зона (Keep-Out Zone)

При формуванні крізних кремнієвих отворів TSV мідь та кремній мають істотну різницю коефіцієнтів теплового розширення: `CTE_Cu = 17 × 10⁻⁶ К⁻¹` проти `CTE_Si = 2.6 × 10⁻⁶ К⁻¹`.

Після високотемпературного відпалу охолодження до робочої кімнатної температури викликає потужні залишкові механічні напруження розтягу в кремнії навколо циліндра TSV. Радіальний розподіл напружень описується рівнянням Ламе:

```
σ_rr(r) = −Δα · ΔT · E_si · (r_tsv / r)²
```

Через п'єзорезистивний ефект кремнію ці механічні напруження змінюють рухливість електронів та дірок у каналах сусідніх польових транзисторів на 10–30%, що призводить до нестабільності порогів перемикання вентилів. 

Щоб запобігти збоям логіки, навколо кожного TSV встановлюють **заборонену зону** (Keep-Out Zone, KOZ) радіусом:

```
r_koz = r_tsv · √( (Δα · ΔT · E_si) / σ_crit )
```

У межах радіуса `r_koz` (зазвичай 3–5 мкм від краю TSV) заборонено розміщувати активні транзистори. Це створює кремнієвий штраф площі, який обов'язково враховується при розрахунку загальної ефективності чиплета.

### 7. Механічна модель короблення підкладки (Package Warpage Model)

Під час термокомпресійного монтажу чиплетів на органічний субстрат або кремнієвий інтерпозер нагрівання до 250–300 °C із наступним охолодженням викликає вигин усієї конструкції через різницю коефіцієнтів теплового розширення шарів.

Величина прогину (Warpage `W_max`) пластини довжиною `L` описується біметалевою моделлю Тімошенка:

```
W_max = (3 · L² · Δα · ΔT) / (4 · t_total · (1 + 4·(E₁·t₁ / (E₂·t₂))))

L        — характерний габаритний розмір підкладки модуля (мм)
Δα       — різниця коефіцієнтів теплового розширення субстрату та кремнію
ΔT       — температурний градієнт охолодження (відпал 260°C → кімнатна 25°C = 235 К)
t_total  — сумарна товщина пакувального сендвіча (субстрат + інтерпозер + кристал)
E₁, E₂   — модулі пружності Юнга відповідних матеріалів
```

Якщо величина прогину `W_max` перевищує 30–50 мкм на площі `50 мм × 50 мм`, припойні мікростовпчики по краях збірки розтягуються або відриваються (Open Solder Joint), а в центрі стискаються з утворенням коротких замикань (Bridging Short). Для запобігання коробленню використовують симетричні шари компенсації напружень та компаунди заповнення Underfill із точно підібраними параметрами пружності.

### 8. Розрахунок цільового імпедансу мережі живлення (PDN Target Impedance)

Сучасні чиплети перемикають струми до `1000 А` за час менше 1 наносекунди під час переходу з режиму сну в робочий стан. Допустима амплітуда коливань напруги живлення `Delta_V` не повинна перевищувати 5% від номінальної напруги `V_dd = 0.75 В` (`Delta_V_max = 37.5 мВ`).

Цільовий комплексний імпеданс мережі живлення (Target Impedance) визначається законом Ома:

```
Z_target = ΔV_max / I_transient = 0.0375 В / 500 А = 75 мкОм
```

Мережа живлення повинна підтримувати імпеданс менше `75 мкОм` у діапазоні частот від постійного струму до гігагерців. Це досягається паралельним каскадуванням трьох рівнів конденсаторів: електролітичних на материнській платі (до 100 кГц), керамічних MLCC на субстраті (до 10 МГц) та глибоких траншейних конденсаторів DTC безпосередньо в кремнієвому інтерпозері (від 10 МГц до 1 ГГц).

### 9. Паразитна ємність мікростовпчиків та гранична частота зрізу

Кожен припойний мікростовпчик (Microbump) діаметром `d_bump = 25 мкм` та висотою `h_bump = 20 мкм`, оточений діелектричним компаундом Underfill із відносною діелектричною проникністю `epsilon_r = 3.5`, утворює паразитний конденсатор та індуктивність:

```
C_bump ≈ (ε₀ · ε_r · π · d_bump²) / (4 · h_bump) ≈ 15–30 фФ
L_bump ≈ (μ₀ · h_bump / 2π) · ln(4 · h_bump / d_bump) ≈ 10–25 пГн
```

Ці мікроскопічні параметри утворюють фільтр нижніх частот із граничною частотою зрізу:

```
f_cutoff = 1 / (2π · R_term · C_total)
```

За вихідного опору термінації `R_term = 50 Ом` та сумарної паразитної ємності вузла `C_total = 80 фФ` смуга пропускання контакту перевищує `f_cutoff ≈ 39.8 ГГц`, що забезпечує неспотворене передавання цифрових сигналів зі швидкостями понад 32 Гбіт/с без потреби у важкій аналоговій корекції.

### 10. Порівняльний розрахунок: монолітний кристал проти чиплетного процесора

Розглянемо реальну виробничу задачу: виготовлення серверного процесора з сумарною площею обчислювальної логіки `A_total = 800 мм²` на передовому техпроцесі 3 нм (`D = 0.10 деф./см²` = `0.0010 деф./мм²`).

Порівняємо дві архітектури:
- **Архітектура A (Моноліт):** єдиний кристал площею `A_mono = 800 мм²`.
- **Архітектура B (Чиплетний модуль):** 8 компактних обчислювальних чиплетів (CCD) по `A_ccd = 75 мм²` (сумарно `600 мм²` на 3 нм) + 1 центральний кристал вводу-виводу (cIOD) площею `A_iod = 250 мм²`, виготовлений на зрілому дешевому техпроцесі 14 нм (`D_14 = 0.05 деф./см²`).

```
================================================================================
РОЗРАХУНОК ВАРІАНТА A: МОНОЛІТ 800 мм² (3 нм)
================================================================================
1. Кількість кристалів на 300-мм пластині:
N_gross = (π · 150²) / 800 − (π · 300) / √(2 × 800)
        = 70685.8 / 800 − 942.48 / 40.0
        = 88.36 − 23.56 = 64.8  →  64 брутто-кристали

2. Вихід придатних кристалів за моделлю Мерфі (D·A = 0.0010 × 800 = 0.80):
Y_mono = ((1 − e^(−0.80)) / 0.80)²
       = ((1 − 0.44933) / 0.80)²      [експонента e^(-0.80) = 0.44933]
       = (0.55067 / 0.80)²            [різниця чисельника]
       = (0.68834)²                   [ділення на 0.80]
       = 0.4738                       →  47.38% придатних кристалів

3. Кількість готових монолітів з однієї пластини:
N_good_mono = ⌊64 × 0.4738⌋ = 30 придатних процесорів

4. Собівартість кристала (за ціни пластини 3 нм Cost_wafer = $22 000):
Cost_die_mono = $22 000 / 30 = $733.33
Собівартість пакування в стандартний корпус: $35.00
Підсумкова собівартість монолітного процесора:
Cost_total_mono = $733.33 + $35.00 = $768.33
```

```
================================================================================
РОЗРАХУНОК ВАРІАНТА B: ЧИПЛЕТНА СИСТЕМА (8 × CCD 3 нм + 1 × cIOD 14 нм)
================================================================================
1. Кількість чиплетів CCD (75 мм²) на 300-мм пластині 3 нм:
N_gross_ccd = (π · 150²) / 75 − (π · 300) / √(2 × 75)
            = 70685.8 / 75 − 942.48 / 12.247
            = 942.48 − 76.95 = 865.5  →  865 брутто-кристалів

2. Вихід придатних чиплетів CCD (D·A = 0.0010 × 75 = 0.075):
Y_ccd = ((1 − e^(−0.075)) / 0.075)²
      = ((1 − 0.92774) / 0.075)²      [експонента e^(-0.075) = 0.92774]
      = (0.07226 / 0.075)²            [різниця чисельника]
      = (0.96342)²                    [ділення на 0.075]
      = 0.9282                        →  92.82% придатних чиплетів

3. Кількість придатних CCD з однієї пластини 3 нм:
N_good_ccd = ⌊865 × 0.9282⌋ = 802 придатні чиплети
Собівартість одного CCD: $22 000 / 802 = $27.43
Собівартість 8 чиплетів CCD: 8 × $27.43 = $219.44

4. Розрахунок кристала вводу-виводу cIOD (250 мм² на пластині 14 нм за $3 500):
N_gross_iod = (π · 150²) / 250 − (π · 300) / √(2 × 250)
            = 70685.8 / 250 − 942.48 / 22.36
            = 282.74 − 42.15 = 240.5  →  240 брутто-кристалів
Вихід cIOD (D·A = 0.0005 × 250 = 0.125):
Y_iod = ((1 − e^(−0.125)) / 0.125)² = 0.8841  →  88.41% придатних
N_good_iod = ⌊240 × 0.8841⌋ = 212 придатних cIOD
Собівартість одного cIOD: $3 500 / 212 = $16.51

5. Вартість кремнієвого інтерпозера CoWoS (площа 1100 мм², пластина $1 500):
N_good_interposer ≈ 42 робочі інтерпозери
Cost_interposer = $1 500 / 42 = $35.71

6. Підсумкова собівартість чиплетного модуля з урахуванням збірки (Y_pkg = 0.96):
Cost_silicon_total = Cost_8_ccd + Cost_iod = $219.44 + $16.51 = $235.95
Cost_total_chiplet = (Cost_silicon_total / 0.96) + Cost_interposer + Cost_assembly
                   = ($235.95 / 0.96) + $35.71 + $45.00
                   = $245.78 + $35.71 + $45.00 = $326.49
```

```
================================================================================
ПІДСУМКОВЕ ПОРІВНЯННЯ ЕКОНОМІКИ:
Монолітний процесор 800 мм²:    $768.33
Чиплетний процесор (8+1):       $326.49
Чиста економія собівартості:    $441.84 на кожному процесорі (зниження на 57.5%)
================================================================================
```

### 11. Амортизація вартості фотошаблонів (NRE Mask Costs)

Крім собівартості самої кремнієвої пластини, вирішальний внесок в економіку вносить початкова вартість виготовлення комплекту фотошаблонів (Non-Recurring Engineering, NRE).

Для повного технологічного маршруту 3 нм комплект фотолітографічних масок (понад 75 шарів із EUV-масками високої точності) коштує близько `$35 000 000`. Для зрілого техпроцесу 14 нм комплект масок коштує близько `$3 000 000`.

Якщо компанія випускає серію з `V = 500 000` процесорів, внесок вартості фотошаблонів на одиницю продукції становить:

```
Для моноліту (уся площа на 3 нм):
Cost_NRE_mono = $35 000 000 / 500 000 = $70.00 на кожен процесор

Для чиплетної системи:
Малий чиплет CCD (3 нм) вимагає меншого поля маски, комплект масок коштує $25 000 000.
Кристал cIOD (14 нм) має маски вартістю $3 000 000.
Інтерпозер (пасивний метал) має маски вартістю $500 000.
Сумарний NRE чиплетів = $28 500 000.
Cost_NRE_chiplet = $28 500 000 / 500 000 = $57.00 на кожен процесор.
```

Ба більше, якщо розробник випускає лінійку з трьох продуктів (8-ядерний, 32-ядерний та 64-ядерний процесори), монолітний підхід вимагає розробки трьох окремих комплектів масок 3 нм загальною вартістю `$105 000 000`. У чиплетній системі використовується той самий єдиний чиплет CCD, змінюється лише кількість кристалів на підкладці, що скорочує сумарні капітальні витрати компанії більш ніж утричі.

### 12. Тепловий розрахунок 3D-стекування кристалів

При вертикальному розміщенні кристалів один над одним тепловий потік від нижнього кристала має пройти крізь шар діелектрика та товщу верхнього кристала.

Згідно з одновимірним законом теплопровідності Фур'є, перепад температури `Delta_T` між активною зоною нижнього кристала та радіатором описується рівнянням:

```
ΔT = q · (t_die_top / k_si + t_bond / k_bond)

q        — густина теплового потоку нижнього кристала (Вт/см²)
t_die    — товщина кремнієвого кристала (зазвичай 50–100 мкм)
k_si     — теплопровідність кремнію (≈ 1.5 Вт/(см·К))
t_bond   — товщина проміжного шару діелектрика SiO₂ (≈ 0.5–2 мкм)
k_bond   — теплопровідність діоксиду кремнію (≈ 0.014 Вт/(см·К))
```

Через низьку теплопровідність діелектрика `k_bond` тонкий шар оксиду товщиною всього 2 мкм створює тепловий опір, еквівалентний 200 мкм чистого кремнію. Тому технологія прямого гібридного зрощування Cu-Cu (TSMC SoIC), яка мінімізує товщину діелектрика та забезпечує прямі металеві мідні контакти, має у 3–5 разів нижчий тепловий опір, ніж клейові 3D-збірки з мікростовпчиками.

### 13. Ймовірнісна модель накопичення браку при складанні (Known Good Die)

Якщо в модулі монтується `K` кристалів, а процедура попереднього тестування на нерозрізаній пластині (Wafer Sort / Probe) має тестове покриття дефектів `C_fault < 1.0`, виникає ймовірність пропускання прихованого браку.

Нехай `Y_die` — справжній вихід придатних кристалів. Імовірність того, що дефектний кристал буде помилково визнано справним і передано на монтаж, дорівнює:

```
P_escape = (1 − Y_die) · (1 − C_fault)
```

Ймовірність того, що всі `K` змонтованих чиплетів є бездоганними, визначається формулою:

```
Y_assembly_kgd = (1 − P_escape)^K · Y_physical_assembly
```

Простежимо вплив тестового покриття на вихід модуля з `K = 9` чиплетів (`Y_die = 0.92`, `Y_physical_assembly = 0.99`):

```
Випадок 1: Стандартне тестування (C_fault = 0.980, тобто 98% покриття дефектів):
P_escape = (1 − 0.92) · (1 − 0.980) = 0.08 × 0.02 = 0.00160
Y_assembly_kgd = (1 − 0.00160)⁹ × 0.99
               = (0.99840)⁹ × 0.99
               = 0.9857 × 0.99 = 0.9758  (2.42% браку готових модулів)

Випадок 2: Поверхневе тестування (C_fault = 0.900, тобто 90% покриття дефектів):
P_escape = (1 − 0.92) · (1 − 0.900) = 0.08 × 0.10 = 0.00800
Y_assembly_kgd = (1 − 0.00800)⁹ × 0.99
               = (0.99200)⁹ × 0.99
               = 0.9303 × 0.99 = 0.9210  (7.90% браку готових модулів!)
```

Кожен відсоток недіагностованого браку на етапі кристала знищує дорогий кінцевий продукт. Саме тому чиплетне виробництво обов'язково супроводжується впровадженням повношвидкісного тестування BIST, стандарту сканування IEEE 1838 та систем надлишкового резервування ліній зв'язку.
