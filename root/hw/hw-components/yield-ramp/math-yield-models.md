# 🧮 Математичні моделі виходу придатних кристалів та просторової кластеризації дефектів

Математичне моделювання виходу придатних кристалів (*integrated circuit yield modeling*) пов'язує фізичну геометрію топології інтегральної схеми, просторовий розподіл мікроскопічних дефектів на кремнієвій пластині та результуючу частку працездатних чипів. Розрахунок виходу визначає собівартість кремнію, економічну доцільність запуску нових процесорних архітектур та ліміти допустимої площі монолітного кристала.

---

### 1. Модель Пуассона та її статистичні обмеження

Найпростіший підхід розглядає виникнення дефектів як послідовність незалежних випадкових подій, рівномірно розподілених по поверхні кремнієвої пластини.

Нехай площа напівпровідникового кристала дорівнює `A` (см²), а середня густина дефектів на одиницю площі становить `D` (дефектів/см²). Середня очікувана кількість дефектів, що потрапляють на один кристал, становить:

```
λ = D · A

λ  — середня кількість дефектів на кристал (безрозмірна величина)
D  — середня густина дефектів на пластині (см⁻²)
A  — площа кристала (см²)
```

За розподілом Пуассона ймовірність того, що на кристал площею `A` потрапить рівно `k` дефектів, виражається формулою:

```
P(k) = (λ^k · e^(−λ)) / k!

P(k)  — ймовірність виявлення рівно k дефектів на кристалі
k!    — факторіал числа k
```

Оскільки напівпровідниковий кристал без апаратної надлишковості втрачає працездатність за наявності хоча б одного критичного дефекту, кристал вважається придатним лише за умови `k = 0`. Вихід придатних за моделлю Пуассона `Y_Poisson` дорівнює ймовірності нульової кількості дефектів `P(0)`:

```
Y_Poisson
= P(0)                    [умова придатності кристала: k = 0]
= (λ⁰ · e^(−λ)) / 0!      [підстановка k = 0 у формулу Пуассона]
= (1 · e^(−D·A)) / 1      [спрощення: λ⁰ = 1, 0! = 1, λ = D·A]
= e^(−D·A)                [класична модель Пуассона]
```

#### Чому модель Пуассона дає хибні результати для великих чипів
Модель Пуассона базується на фундаментальному припущенні: дефекти є абсолютно незалежними й розподілені по пластині рівномірно (дисперсія кількості дефектів дорівнює їхньому середньому значенню: `Var(k) = E(k) = λ`).

У реальному виробництві це припущення грубо порушується через просторову **кластеризацію дефектів** (англ. *defect clustering*): дефекти групуються вздовж зон турбулентності газів у реакторах осадження, біля країв пластини через дію центрифуги при знятті фоторезисту (*edge bead removal*), або вздовж механічних мікроподряпин від полірувальних подушок CMP.

Якщо десять дефектів скупчуються в межах одного кристала, вони знищують лише цей один кристал, залишаючи сусідні дев'ять кристалів неушкодженими. Модель Пуассона вважає, що ці десять дефектів розсіюються по всій пластині й знищують десять різних кристалів. У результаті модель Пуассона критично занижує реальний вихід придатних для чипів великої площі (`A > 2–3 см²`).

### 2. Модель Сідса (Seeds Model)

У 1967 році Роберт Сідс (Robert Seeds) запропонував враховувати просторову неоднорідність виробничого процесу, припустивши, що локальна густина дефектів `D` на різних ділянках пластини не є сталою, а підпорядковується експоненційному розподілу густини ймовірностей:

```
f(D) = (1 / D̄) · e^(−D / D̄)

D̄     — середня густина дефектів по всій вибірці пластин
f(D)  — функція густини ймовірності локальної густини дефектів
```

Загальний вихід придатних обчислюється як інтеграл від локального пуассонівського виходу `e^(-D·A)`, зваженого за розподілом густини `f(D)`:

```
Y_Seeds
= ∫₀^∞ e^(−D·A) · f(D) dD
= ∫₀^∞ e^(−D·A) · (1 / D̄) · e^(−D / D̄) dD       [підстановка експоненційного f(D)]
= (1 / D̄) · ∫₀^∞ e^(−D · (A + 1/D̄)) dD          [об'єднання показників експонент]
= (1 / D̄) · [ −1 / (A + 1/D̄) · e^(−D·(A + 1/D̄)) ]₀^∞   [первісна експоненти]
= (1 / D̄) · ( 0 − ( −1 / (A + 1/D̄) · 1 ) )     [обчислення на межах [0, ∞)]
= (1 / D̄) · ( 1 / ((D̄·A + 1) / D̄) )            [зведення до спільного знаменника]
= 1 / (1 + D̄ · A)                              [модель Сідса]
```

Модель Сідса дає значно повільніше падіння виходу зі зростанням площі кристала порівняно з експонентою Пуассона: при великих значеннях аргументу `D̄·A >> 1` вихід спадає як `1 / (D̄·A)` (гіперболічно), а не як `e^(-D̄·A)`.

### 3. Модель Мерфі (Murphy Model)

У 1964 році Браян Мерфі (Brian Murphy) ввів модель усереднення виходу, де варіація густини дефектів описується симетричним трикутним розподілом навколо середнього значення `D̄` в інтервалі від `0` до `2·D̄`:

```
f(D) = D / D̄²,            при 0 ≤ D ≤ D̄
f(D) = (2·D̄ − D) / D̄²,    при D̄ ≤ D ≤ 2·D̄
```

Розрахунок інтеграла виходу розбивається на дві ділянки:

```
Y_Murphy
= ∫₀^D̄ e^(−D·A) · (D / D̄²) dD + ∫_D̄^(2·D̄) e^(−D·A) · ((2·D̄ − D) / D̄²) dD
```

Інтегрування частинами для кожного з двох доданків:

```
∫ D · e^(−D·A) dD = −(D / A) · e^(−D·A) − (1 / A²) · e^(−D·A)   [формула інтегрування частинами]
```

Підставляючи границі інтегрування `[0, D̄]` та `[D̄, 2·D̄]`, після алгебраїчного спрощення отримуємо:

```
Y_Murphy
= ( (1 − e^(−D̄·A)) / (D̄ · A) )²               [модель Мерфі з трикутним розподілом]
```

#### Варіант Мерфі з рівномірним розподілом
Якщо припустити, що густина дефектів розподілена рівномірно в діапазоні `[0, 2·D̄]`, де `f(D) = 1 / (2·D̄)`, інтеграл спрощується до вигляду:

```
Y_Uniform
= ∫₀^(2·D̄) e^(−D·A) · (1 / (2·D̄)) dD
= (1 / (2·D̄)) · [ −(1 / A) · e^(−D·A) ]₀^(2·D̄)
= (1 − e^(−2·D̄·A)) / (2 · D̄ · A)               [модель Мерфі з рівномірним розподілом]
```

### 4. Модель Окі-Мерфі та від'ємного біноміального розподілу (Stapper Model)

Найточнішою та загальновизнаною у сучасній напівпровідниковій індустрії є модель Чарльза Стаппера (Charles Stapper, IBM), що базується на від'ємному біноміальному розподілі (*Negative Binomial Model*).

Вона припускає, що локальна густина дефектів описується неперервним двопараметричним гамма-розподілом (від грец. *gamma* — функція `Γ`):

```
f(D) = (1 / (Γ(α) · β^α)) · D^(α − 1) · e^(−D / β)

α     — безрозмірний параметр просторової кластеризації дефектів (Clustering Parameter)
β     — масштабний параметр розподілу (β = D̄ / α)
Γ(α)  — гамма-функція Ейлера
```

Дисперсія густини дефектів для гамма-розподілу дорівнює:

```
Var(D) = α · β² = α · (D̄ / α)² = D̄² / α
```

Параметр `α` має прямий фізичний зміст:
* При `α → ∞`: дисперсія прямує до нуля (`Var(D) → 0`), дефекти розподілені абсолютно рівномірно без кластеризації.
* При малому `α ≈ 0.5–2.0`: висока дисперсія, дефекти сильно згруповані в локальні кластери.

Покрокове інтегрування пуассонівського виходу за гамма-розподілом густини дефектів:

```
Y_NegBin
= ∫₀^∞ e^(−D·A) · f(D) dD                                                           [означення усередненого виходу]
= ∫₀^∞ e^(−D·A) · (1 / (Γ(α) · (D̄/α)^α)) · D^(α − 1) · e^(−D / (D̄/α)) dD            [підстановка гамма-густини f(D)]
= (1 / (Γ(α) · (D̄/α)^α)) · ∫₀^∞ D^(α − 1) · e^(−D · (A + α/D̄)) dD                 [винесення констант за знак інтеграла]
= (1 / (Γ(α) · (D̄/α)^α)) · ( Γ(α) / (A + α/D̄)^α )                                 [застосування інтеграла гамма-функції]
= 1 / ( (D̄/α)^α · ((D̄·A + α) / D̄)^α )                                            [скорочення Γ(α) та зведення знаменника]
= 1 / ( ((D̄/α) · ((D̄·A + α) / D̄))^α )                                            [об'єднання степенів α]
= 1 / ( (1 + (D̄ · A) / α)^α )                                                      [спрощення добутку дробів]
= ( 1 + (D̄ · A) / α )^(−α)                                                        [модель Стаппера / від'ємного біноміалу]
```

#### Граничні переходи моделі Стаппера
Математична краса моделі від'ємного біноміального розподілу полягає в тому, що вона містить усі попередні моделі як окремі випадки:

1. **Границя відсутності кластеризації (`α → ∞`):**
```
lim_(α→∞) ( 1 + (D̄ · A) / α )^(−α)
= e^(−D̄·A)                                          [чудова границя: перехід до моделі Пуассона]
```

2. **Границя сильної кластеризації (`α = 1`):**
```
( 1 + (D̄ · A) / 1 )^(−1)
= 1 / (1 + D̄ · A)                                   [точний збіг із моделлю Сідса]
```

На сучасних 3-нм та 2-нм техпроцесах параметр кластеризації становить типово `α ≈ 0.8–2.0`. Це пояснює, чому великі процесори площею `A = 6–8 см²` досягають економічно прийнятного виходу `40–60%`, тоді як формула Пуассона прогнозувала б майже повний нуль (`e^(-0.3 × 8) = e^(-2.4) ≈ 9%` проти `(1 + (0.3 × 8)/1.2)^(-1.2) = (1 + 2.0)^(-1.2) = 3^(-1.2) ≈ 27%`).

### 5. Аналіз критичної площі (Critical Area Analysis, CAA)

Фізичний дефект розміром `x` (нм) не завжди викликає електричну відмову кристала. Якщо частинка пилу діаметром `20 нм` потрапляє на порожню ділянку діелектрика між двома провідниками, що розташовані на відстані `80 нм`, замикання не виникає.

Тому у формулах виходу фізична площа кристала `A` замінюється на **критичну площу** `A_crit` — зважену ймовірнісну площу, влучання центру дефекту в яку гарантовано призводить до функціональної відмови (короткого замикання або обриву).

#### Функція критичної площі для бічних замикань (Shorts)
Розглянемо два паралельні провідники довжиною `L`, розташовані на відстані `s` один від одного. Частинка провідного сміття радіусом `r = x / 2` викличе замикання, лише якщо її діаметр `x > s`, а центр частинки знаходиться на відстані не більше `x/2` від обох провідників.

Зона вразливості центрів дефектів має ширину `(x − s)`. Відповідно, критична площа для двох провідників становить:

```
A_c(x) = 0,            при x < s   [дефект менший за проміжок не здатний замкнути лінію]
A_c(x) = L · (x − s),  при x ≥ s   [критична площа зростає лінійно з розміром дефекту]
```

Для складного масиву з багатьох паралельних шин із кроком `p = w + s`:
```
A_c(x) = A_total · (1 − s / x), при x ≥ s
```

```
A_c(x)    — критична площа для дефектів розміру x
A_total  — повна геометрична площа топологічного блоку
s        — мінімальна відстань між провідниками (Spacing)
w        — ширина провідника (Width)
```

#### Інтегральна густина дефектів з урахуванням спектра розмірів
Розподіл дефектів за фізичним розміром `x` підпорядковується зворотно-степеневому закону Стаппера:

```
f(x) = (p − 1) · x_min^(p − 1) / x^p

x_min  — мінімальний детектовний розмір дефекту
p      — степеневий показник розподілу (для напівпровідникових фабрик p ≈ 3)
```

Узагальнена очікувана середня кількість фатальних дефектів на кристал `λ_crit` обчислюється інтегруванням згортки критичної площі та спектрального розподілу дефектів:

```
λ_crit = D_total · ∫₀^∞ A_c(x) · f(x) dx

D_total  — загальна виміряна оптичними сканерами густина часток
```

Для степеневого розподілу з `p = 3` та функції замикання `A_c(x) = A_total · (1 − s/x)` інтеграл набуває вигляду:

```
λ_crit
= D_total · A_total · ∫_s^∞ (1 − s/x) · (2 · s² / x³) dx
= D_total · A_total · 2·s² · [ ∫_s^∞ x^(−3) dx − s · ∫_s^∞ x^(−4) dx ]
= D_total · A_total · 2·s² · [ ( −1/(2·x²) )_s^∞ − s · ( −1/(3·x³) )_s^∞ ]
= D_total · A_total · 2·s² · [ 1/(2·s²) − s / (3·s³) ]
= D_total · A_total · 2·s² · [ 1/(2·s²) − 1/(3·s²) ]
= D_total · A_total · 2·s² · [ 1 / (6·s²) ]
= D_total · A_total / 3                       [критична площа становить лише 1/3 повної площі]
```

Цей результат доводить, що лише третина (`≈33%`) усіх мікрочастинок, які фізично осідають на поверхню пластини, викликають реальне електричне замикання ліній. Решта дві третини потрапляють у безпечні зони, де розмір частки менший за локальний проміжок між металевими шинами.

#### Функція критичної площі для обривів провідників (Opens)
Поряд із бічними замиканнями іншим критичним механізмом є обрив провідника (*interconnect open*) внаслідок потрапляння непровідної частки (наприклад, кремнійдіоксидного пилу чи пустоти у фоторезисті).

Нехай лінія має ширину `w` та довжину `L`. Частинка ізолятора радіусом `r = x / 2` викличе повний електричний розрив провідника, лише якщо її діаметр `x > w`, а центр дефекту перекриває лінію так, що залишковий переріз металу стає нульовим.

Зона вразливості центрів дефектів обриву має ширину `(x − w)`. Відповідно, критична площа для обриву одиночного провідника становить:

```
A_c_open(x) = 0,            при x < w   [дефект, менший за ширину дроту, викликає звуження, але не повний обрив]
A_c_open(x) = L · (x − w),  при x ≥ w   [критична площа повного обриву]
```

Для масиву з `N` провідників критична площа обривів підсумовується по всій довжині металізації:

```
A_c_open_total(x) = ∑ L_i · (x − w_i) · θ(x − w_i)

θ(u)  — східчаста функція Хевісайда (Heaviside step function: θ(u) = 1 при u ≥ 0, θ(u) = 0 при u < 0)
L_i   — довжина i-го сегмента провідника
w_i   — ширина i-го сегмента провідника
```

Для багаторівневої металізації (сучасні процесори мають від 12 до 18 шарів металу M1–M18) повна критична площа схеми є векторною сумою критичних площ замикань та обривів по кожному шару окремо:

```
λ_total = ∑ [ D_short_j · ∫ A_c_short_j(x) · f_j(x) dx + D_open_j · ∫ A_c_open_j(x) · f_j(x) dx ]
```

де сумування ведеться за всіма металевими шарами `j = 1 … M` та діелектричними шарами переходів `via`.

### 6. Радіальний розподіл дефектів на пластині (Wafer Radial Defect Model)

На практиці дефекти не розподілені рівномірно навіть у межах однієї пластини: спостерігається систематичний радіальний градієнт — вихід придатних біля центру пластини помітно вищий, ніж на крайніх периферійних зонах.

Цей ефект зумовлений трьома фізико-хімічними механізмами:
1. **Нерівномірність товщини плівки при центрифугуванні**: під час нанесення рідкого фоторезисту на обертову пластину лінійна швидкість краю `v = ω · R` значно перевищує швидкість у центрі, що викликає витончення або крайовий валик фоторезисту.
2. **Газодинамічна турбулентність у камерах плазмового травлення**: потік реакційних газів біля крайових кілець фіксації зазнає завихрень, змінюючи швидкість травлення.
3. **Хіміко-механічна полірування (CMP)**: тиск полірувальної головки на краю пластини відрізняється від центру через прогин мембрани, що призводить до крайового переполірування (*edge over-polishing*).

Радіальна зміна густини дефектів апроксимується степеневою функцією від нормованого радіуса `r / R`:

```
D(r) = D_center · ( 1 + C_edge · (r / R)^m )

D_center  — густина дефектів у геометричному центрі пластини (r = 0)
R         — повний радіус пластини (R = 150 мм для стандартної пластини 300 мм)
r         — відстань від центру пластини до досліджуваного кристала (0 ≤ r ≤ R)
C_edge    — коефіцієнт крайового зростання дефектності (типово C_edge ≈ 2–5)
m         — показник крутизни крайового градієнта (типово m ≈ 4–8)
```

Локальний вихід кристала в координатах `(x, y)` на відстані `r = √(x² + y²)` за моделлю Стаппера набуває просторово-залежного вигляду:

```
Y(r) = ( 1 + (D(r) · A_crit) / α )^(−α)
= ( 1 + (D_center · (1 + C_edge · (r/R)^m) · A_crit) / α )^(−α)
```

Інтегральний вихід по всій площі пластини радіуса `R_wafer` обчислюється подвійним інтегруванням у полярних координатах:

```
Y_wafer_avg = (1 / (π · R_wafer²)) · ∫₀^(2π) dθ ∫₀^(R_wafer) Y(r) · r dr
= (2 / R_wafer²) · ∫₀^(R_wafer) ( 1 + (D(r) · A_crit) / α )^(−α) · r dr
```

### 7. Математика апаратної надлишковості та відновлення виходу (Redundancy & Repair)

Для великих регулярних масивів — зокрема вбудованої кеш-пам'яті SRAM, eDRAM або пам'яті HBM — застосовують схеми резервування (*redundancy*). До основного масиву додають запасні рядки (*redundant rows*) та запасні стовпчики (*redundant columns*), керовані електричними плавкими перемичками (*eFuses*) або лазерним пропалюванням.

#### Модель виходу відновлюваного масиву
Нехай масив пам'яті містить `N_rows` рядків і `N_cols` стовпчиків, а також `R_spare` резервних рядків і `C_spare` резервних стовпчиків.

Кристал є придатним до відновлення, якщо загальна кількість дефектних рядків не перевищує `R_spare`, а кількість дефектних стовпчиків — не перевищує `C_spare`.

Якщо дефекти комірок пам'яті незалежні й підпорядковуються розподілу Пуассона з середньою кількістю дефектних комірок `λ_sram = D_bit · N_total_bits`, то вихід відновлюваного блоку пам'яті `Y_repaired` розраховується через суму ймовірностей допустимої кількості поломок:

```
Y_repaired
= P(дефектів ≤ R_spare + C_spare і вони ремонтовні)
= e^(−λ_sram) · ∑_(k=0)^(R_spare + C_spare) (λ_sram^k / k!) · P_alloc(k | R_spare, C_spare)

P_alloc  — комбінаторна ймовірність того, що k випадкових дефектів можна покрити наявними R_spare рядками та C_spare стовпчиками
```

Для простого випадку лише рядкової надлишковості (`R_spare` запасних рядків, `C_spare = 0`):
```
Y_row_redundant = e^(−λ_sram) · ∑_(k=0)^(R_spare) ( (λ_sram)^k / k! )
```

**Числовий приклад відновлення кешу:**
Нехай для масиву SRAM об'ємом 32 МБ середня кількість дефектів становить `λ_sram = 1.8`.
* Без надлишковості вихід масиву за Пуассоном:
```
Y_no_red = e^(−1.8) ≈ 0.1653 → 16.5% придатних
```
* За наявності `R_spare = 3` запасних рядків:
```
Y_with_red
= e^(−1.8) · ( 1 + 1.8 + (1.8² / 2!) + (1.8³ / 3!) )   [формула відновленого виходу для R_spare = 3]
= 0.1653 · ( 1 + 1.8 + 1.62 + 0.972 )                 [обчислення доданків ряду Пуассона]
= 0.1653 · 5.392                                      [сумування коефіцієнтів покриття]
= 0.8913                                              [результуючий вихід: 89.1% придатних]
```
Додавання лише трьох резервних рядків (що збільшує площу блоку менш ніж на 0.5%) піднімає вихід пам'яті з катастрофічних `16.5%` до відмінних `89.1%`.

### 8. Числовий порівняльний аналіз моделей виходу

Проілюструємо розбіжність між п'ятьма моделями на прикладі трьох класів чипів за типової густини дефектів `D̄ = 0.35 деф./см²` та параметра кластеризації `α = 1.2`:
1. **Малий мікроконтролер:** площа `A = 0.20 см²` (`20 мм²`).
2. **Середній мобільний чиплет:** площа `A = 1.20 см²` (`120 мм²`).
3. **Великий монолітний AI-прискорювач:** площа `A = 6.50 см²` (`650 мм²`).

#### 1. Розрахунок для малого кристала (A = 0.20 см², D̄·A = 0.07):
* **Пуассон:** `Y = e^(−0.07) ≈ 0.9324` (93.2%)
* **Сідс:** `Y = 1 / (1 + 0.07) ≈ 0.9346` (93.5%)
* **Мерфі (трикутна):** `Y = ((1 − e^(−0.07)) / 0.07)² = (0.0676 / 0.07)² ≈ 0.9331` (93.3%)
* **Стаппер (α = 1.2):** `Y = (1 + 0.07 / 1.2)^(−1.2) = (1.0583)^(−1.2) ≈ 0.9337` (93.4%)
* *Висновок:* для малих кристалів усі моделі дають практично ідентичний результат із похибкою менше 0.3%.

#### 2. Розрахунок для середнього кристала (A = 1.20 см², D̄·A = 0.42):
* **Пуассон:** `Y = e^(−0.42) ≈ 0.6570` (65.7%)
* **Сідс:** `Y = 1 / (1 + 0.42) ≈ 0.7042` (70.4%)
* **Мерфі (трикутна):** `Y = ((1 − e^(−0.42)) / 0.42)² = (0.3430 / 0.42)² ≈ 0.6667` (66.7%)
* **Стаппер (α = 1.2):** `Y = (1 + 0.42 / 1.2)^(−1.2) = (1.35)^(−1.2) ≈ 0.6974` (69.7%)
* *Висновок:* різниця сягає 4–5 абсолютних відсотків.

#### 3. Розрахунок для великого моноліту (A = 6.50 см², D̄·A = 2.275):
* **Пуассон:** `Y = e^(−2.275) ≈ 0.1028` (**10.3%** — песимістичний колапс)
* **Сідс:** `Y = 1 / (1 + 2.275) ≈ 0.3053` (**30.5%** — трикратне перевищення над Пуассоном)
* **Мерфі (трикутна):** `Y = ((1 − e^(−2.275)) / 2.275)² = (0.8972 / 2.275)² ≈ 0.1555` (**15.6%**)
* **Стаппер (α = 1.2):** `Y = (1 + 2.275 / 1.2)^(−1.2) = (2.8958)^(−1.2) ≈ 0.2801` (**28.0%**)
* *Висновок:* для великих площ реальний вихід за рахунок просторової кластеризації дефектів (`28.0%`) майже утричі перевищує значення класичної моделі Пуассона (`10.3%`). Використання моделі Пуассона в бізнес-плануванні призвело б до помилкового закриття проекту як нібито збиткового.

### 9. Масштабування критичного розміру дефектів при зміні технологічних норм

При переході від одного технологічного вузла до наступного (наприклад, від 28 нм до 3 нм) мінімальний крок ліній металізації `pitch = w + s` зменшується за коефіцієнтом масштабування `s_scale ≈ 0.7` на кожне покоління.

Критичний розмір дефекту `x_crit`, здатний спричинити замикання або обрив, пропорційний половині кроку металізації:

```
x_crit = s / 2 ≈ (pitch) / 4
```

Оскільки інтегральна густина дефектів розміром більшим за `x_crit` підпорядковується інтегралу зворотно-степеневого закону:

```
N_defects(> x_crit)
= ∫_(x_crit)^∞ f(x) dx
= ∫_(x_crit)^∞ ( (p − 1) · x_min^(p − 1) / x^p ) dx
= [ −x_min^(p − 1) / x^(p − 1) ]_(x_crit)^∞
= ( x_min / x_crit )^(p − 1)
```

Для типового показника `p = 3`:

```
N_defects(> x_crit) ∝ 1 / x_crit² ∝ 1 / (pitch)²
```

#### Наслідок «подвійного удару» масштабування:
При зменшенні фізичних розмірів елементів у 2 рази (`pitch → pitch / 2`):
1. **Критичний розмір дефекту падає вдвічі**: частинки пилу розміром `15 нм`, які на вузлі 28 нм були безпечними, на вузлі 3 нм стають фатальними вбивцями кристала.
2. **Густина смертоносних часток у навколишньому середовищі зростає у 4 рази** (`1 / 0.5² = 4`), оскільки дрібних часток у повітрі та хімічних реактивах статистично значно більше, ніж великих.

Отже, якщо фабрика не знижує базову концентрацію забруднень у 4 рази при кожному переході на новий вузол, ефективна густина дефектів `D` зростає квадратично, що призводить до повного обвалу виходу придатних на ранніх етапах освоєння процесу.

| Модель | Формула виходу `Y(D̄, A)` | Розподіл густини `f(D)` | Сфера застосування |
| :--- | :--- | :--- | :--- |
| **Пуассона** | `e^(−D̄·A)` | Дельта-функція Дірака `δ(D − D̄)` | Малі чипи (`<50 мм²`), однорідні процеси |
| **Сідса** | `1 / (1 + D̄·A)` | Експоненційний `(1/D̄)·e^(−D/D̄)` | Сильна локальна кластеризація (`α = 1`) |
| **Мерфі (трикутна)** | `((1 − e^(−D̄·A)) / (D̄·A))²` | Трикутний на `[0, 2·D̄]` | Історичні розрахунки біполярних ІС |
| **Мерфі (рівномірна)** | `(1 − e^(−2·D̄·A)) / (2·D̄·A)` | Рівномірний на `[0, 2·D̄]` | Оцінка виходу пам'яті DRAM перших поколінь |
| **Стаппера (Negative Binomial)** | `(1 + (D̄·A) / α)^(−α)` | Гамма-розподіл `Γ(α, β)` | Сучасні мікропроцесори, GPU, SoC (вузли <28 нм) |
