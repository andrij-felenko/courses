# 🧮 Математичне виведення моделі Арреніуса, коефіцієнтів прискорення та меж правила 10 градусів

Фізичні процеси деградації твердотільних структур, полімерних діелектриків та рідких електролітів підпорядковуються законам статистичної термодинаміки та фізичної кінетики. Щоб коректно оцінити ресурс виробу або перерахувати години стресового лабораторного випробування в роки польової експлуатації, інженеру необхідний строгий математичний апарат, що пов'язує мікроскопічний тепловий рух атомів з макроскопічною ймовірністю відмови компонента.

## 1. Термодинамічне виведення: від розподілу Больцмана до рівняння Арреніуса

У будь-якому кристалі, діелектрику чи рідині атоми та молекули перебувають у безперервному тепловому коливальному русі біля своїх положень рівноваги. Енергетичні стани частинок описуються канонічним ансамблем Гіббса.

Імовірність `P_i` того, що частинка перебуває у квантовому стані з енергією `E_i`, задається розподілом Больцмана:

```
P_i = ( 1 / Z ) · exp( −E_i / (k_B · T) )
```

де `Z = ∑ exp( −E_i / (k_B · T) )` — статистична сума за станами системи, `k_B = 8.617333 × 10⁻⁵ еВ/К` — стала Больцмана, а `T` — абсолютна термодинамічна температура в Кельвінах (`T = t[°C] + 273.15`).

У класичному наближенні для неперервного спектра кінетична енергія теплового руху частинок розподілена за законом Максвелла-Больцмана з тривимірною густиною ймовірності `f(E)`:

```
f(E) = ( 2 / (√π · (k_B · T)^(3/2)) ) · √E · exp( −E / (k_B · T) )
```

Щоб відбулася елементарна подія деградації (наприклад, дифузійний стрибок атома металізації у вакантний вузол сусідньої ґратки під дією імпульсу електронів струму або подолання молекулою розчинника міжмолекулярного потенціалу гумової пробки), частинка мусить подолати потенційний енергетичний бар'єр реакції — енергію активації `E_a`.

Частка частинок `P(E ≥ E_a)`, кінетична енергія яких перевищує цей бар'єр, визначається інтегруванням хвоста функції густини:

```
P(E ≥ E_a) = ∫[E_a..∞] f(E) dE

P(E ≥ E_a) = 1 − erf( √(E_a / (k_B · T)) ) + ( 2 / √π ) · √(E_a / (k_B · T)) · exp( −E_a / (k_B · T) )
```

Оскільки для реальних процесів деградації в електроніці енергія активації `E_a` (0.4...1.2 еВ) у десятки разів перевищує середню теплову енергію `k_B · T` (`E_a / (k_B · T) >> 1`), асимптотичний розклад інтеграла дає експоненційну залежність:

```
P(E ≥ E_a) ≈ ( 2 / √π ) · √(E_a / (k_B · T)) · exp( −E_a / (k_B · T) ) ∝ exp( −E_a / (k_B · T) )
```

### Зв'язок із теорією перехідного стану Ейрінга-Поляні

Згідно з теорією активованого комплексу (теорія перехідного стану Ейрінга-Поляні), швидкість хімічної або дифузійної реакції `k` визначається частотою подолання частинками сідлової точки поверхні потенційної енергії:

```
k = ( (k_B · T) / h ) · ( q‡ / (q_A · q_B) ) · exp( −E_0 / (k_B · T) )
```

де `h` — стала Планка, `q‡`, `q_A`, `q_B` — молекулярні статистичні суми за станами активованого комплексу та вихідних реагентів, а `E_0` — різниця нульових енергій.

У термодинамічному формулюванні:

```
k = ( (k_B · T) / h ) · exp( −ΔG‡ / (R · T) )
```

де `ΔG‡ = ΔH‡ − T · ΔS‡` — стандартна вільна енергія Гіббса активації, `ΔH‡` — ентальпія активації, а `ΔS‡` — ентропія активації процесу.

Розкриваючи термодинамічні складові:

```
k = [ ( (k_B · T) / h ) · exp( ΔS‡ / R ) ] · exp( −ΔH‡ / (R · T) )
```

У робочому інженерному діапазоні температур лінійний передмножник `T` змінюється настільки слабко порівняно зі стрімкою експонентою, що його об'єднують в узагальнений передекспоненційний частотний фактор `A`:

```
k(T) = A · exp( −E_a / (k_B · T) )
```

де експериментальна енергія активації Арреніуса визначається як похідна логарифма швидкості:

```
E_a = k_B · T² · ( d(ln k) / dT ) = −k_B · ( d(ln k) / d(1/T) )
```

Оскільки напрацювання до відмови `L` (англ. *lifetime*) обернено пропорційне швидкості деградаційного процесу (`L ∝ 1 / k`), ресурс компонента за температури `T` виражається експонентою:

```
L(T) = L_0 · exp( E_a / (k_B · T) )
```

## 2. Точне виведення коефіцієнта температурного прискорення AF

Нехай компонент у нормальних польових умовах експлуатується за температури `T_use`, де швидкість його старіння становить `k(T_use)`. Під час прискореного випробування в кліматичній камері за підвищеної температури `T_stress` швидкість старіння зростає до `k(T_stress)`.

Коефіцієнт температурного прискорення `AF_T` (англ. *Acceleration Factor*) визначається як відношення швидкостей реакції або відношення тривалостей безвідмовної роботи:

```
AF_T = k(T_stress) / k(T_use) = L(T_use) / L(T_stress)

AF_T = ( A · exp( −E_a / (k_B · T_stress) ) ) / ( A · exp( −E_a / (k_B · T_use) ) )

AF_T = exp[ (E_a / k_B) · ( 1 / T_use − 1 / T_stress ) ]
```

Позначимо температурний перепад як `ΔT = T_stress − T_use`. Звідси різниця обернених температур:

```
1 / T_use − 1 / T_stress = (T_stress − T_use) / (T_use · T_stress) = ΔT / (T_use · (T_use + ΔT))

AF_T = exp[ (E_a / k_B) · ( ΔT / (T_use · (T_use + ΔT)) ) ]
```

Ця формула є точним аналітичним виразом коефіцієнта прискорення Арреніуса для будь-якого температурного діапазону.

### Чутливість швидкості деградації до відносної зміни температури

Визначимо безрозмірний коефіцієнт чутливості (логарифмічну похідну) швидкості зносу до абсолютної температури:

```
S_T = ( dk / k ) / ( dT / T ) = d(ln k) / d(ln T) = T · ( d(ln k) / dT ) = E_a / (k_B · T)
```

Для типових значень в електроніці за температури +55 °C (`T = 328.15 К`, де `k_B · T ≈ 0.02828 еВ`):
- При `E_a = 0.40 еВ` (електроліт): `S_T = 0.40 / 0.02828 ≈ 14.1` — відносна зміна швидкості деградації у 14 разів перевищує відносну зміну абсолютної температури;
- При `E_a = 0.70 еВ` (полімери, кремній): `S_T = 0.70 / 0.02828 ≈ 24.8`;
- При `E_a = 1.10 еВ` (оксиди затвора TDDB): `S_T = 1.10 / 0.02828 ≈ 38.9`.

Цей розрахунок наочно демонструє, чому матеріали з високою енергією активації мають колосальну чутливість навіть до незначного перегріву.

## 3. Математичне виведення інженерного «правила 10 градусів»

Класичне емпіричне правило подвоєння ресурсу формулюється як степенева функція:

```
AF_10 = 2^( ΔT / 10 ) = exp[ (ln(2) / 10) · ΔT ] ≈ exp( 0.069315 · ΔT )
```

Знайдемо точну аналітичну умову, за якої модель Арреніуса для температурного кроку `ΔT = 10 К` дає коефіцієнт прискорення рівно 2.0:

```
exp[ (E_a / k_B) · ( 10 / (T · (T + 10)) ) ] = 2

(E_a / k_B) · ( 10 / (T · (T + 10)) ) = ln(2)

E_a(T) = ( ln(2) · k_B / 10 ) · T · (T + 10)
```

Підставивши значення констант `ln(2) ≈ 0.693147` та `k_B = 8.617333 × 10⁻⁵ еВ/К`:

```
E_a [еВ] = ( 0.693147 × 8.617333 × 10⁻⁵ / 10 ) · T · (T + 10)

E_a [еВ] ≈ 5.9731 × 10⁻⁶ · T · (T + 10)
```

Обчислимо еквівалентну енергію активації для характерних робочих температур:
- При `t = +25 °C` (`T = 298.15 К`): `E_a = 5.9731 × 10⁻⁶ · 298.15 · 308.15 ≈ 0.549 еВ`;
- При `t = +55 °C` (`T = 328.15 К`): `E_a = 5.9731 × 10⁻⁶ · 328.15 · 338.15 ≈ 0.663 еВ`;
- При `t = +85 °C` (`T = 358.15 К`): `E_a = 5.9731 × 10⁻⁶ · 358.15 · 368.15 ≈ 0.787 еВ`;
- При `t = +105 °C` (`T = 378.15 К`): `E_a = 5.9731 × 10⁻⁶ · 378.15 · 388.15 ≈ 0.877 еВ`.

**Теоретичний висновок:** Емпіричне правило 10 градусів є експоненційною апроксимацією моделі Арреніуса, яка має нульову похибку лише за однієї конкретної енергії активації `E_a ≈ 0.66 еВ` біля середньої робочої температури +55 °C.

### Аналітичний розрахунок похибки правила 10 градусів

Визначимо відносну похибку спрощеного правила `ε`:

```
ε(E_a, T_use, ΔT) = ( AF_10 − AF_exact ) / AF_exact
```

Розкриваючи вираз:

```
ε = [ 2^(ΔT/10) − exp( (E_a / k_B) · (ΔT / (T_use · (T_use + ΔT))) ) ] / exp( (E_a / k_B) · (ΔT / (T_use · (T_use + ΔT))) )
```

Зведемо числові значення похибки для діапазону температур від +25 °C до +65 °C (`ΔT = 40 К`) у зведену таблицю:

| :--- | :--- | :--- | :--- | :--- | :--- |

## 4. Мультифакторні фізичні моделі та сумарне нагромадження зносу

В реальних умовах експлуатації компоненти зазнають одночасної дії кількох стресових факторів.

### 1. Рівняння Блека для електроміграції (Black's Equation)
Швидкість дифузійного масопереносу атомів металу під дією сили електронного вітру `F_wind = −Z* · e · ρ · j` визначається рівнянням дрейфу:

```
v_drift = ( D / (k_B · T) ) · F_wind = ( D_0 / (k_B · T) ) · exp( −E_a / (k_B · T) ) · ( Z* · e · ρ · j )
```

Середній час до відмови провідника металізації `MTTF` виражається класичною формулою Блека (1969 р.):

```
MTTF = ( A / j^m ) · exp( E_a / (k_B · T) )
```

де `j` — густина струму (`А/см²`), `m ≈ 1.5 ... 2.0` — емпіричний показник струмового стресу, а `E_a ≈ 0.8...1.1 еВ`.

### 2. Узагальнена модель Прокоповича-Васкаса (MLCC та плівкові конденсатори)
Напруженість електричного поля `E_field = V / d` знижує потенційний бар'єр перескоку іонів (ефект Пула-Френкеля). Модель Прокоповича-Васкаса комбінує температурний та напруговий коефіцієнти прискорення:

```
AF_total = ( V_stress / V_use )^n_volt · exp[ (E_a / k_B) · ( 1 / T_use − 1 / T_stress ) ]
```

де `n_volt = 2.5 ... 4.5` для кераміки X7R/X8R та `n_volt = 5 ... 8` для самовідновних плівкових конденсаторів.

### 3. Розрахунок зносу за мінливих температур (Модель Пальмгрена-Майнера)
Якщо прилад працює в умовах добових або сезонних температурних циклів, де температура `T_i` діє протягом частки часу `w_i = t_i / t_total` (`∑ w_i = 1`), накопичений знос розраховується за правилом лінійного накопичення пошкоджень Пальмгрена-Майнера:

```
Damage = ∑[i=1..M] ( t_i / L(T_i) ) ≤ 1.0
```

Для неперервного профілю температури `T(t)` накопичене пошкодження визначається інтегралом:

```
Damage(t_total) = ∫[0..t_total] ( 1 / L(T(t)) ) dt = ( 1 / L_0 ) · ∫[0..t_total] exp( −E_a / (k_B · T(t)) ) dt
```

Еквівалентна постійна температура експлуатації `T_eff`, що викликає аналогічний сумарний знос за той самий сумарний час, визначається оберненим перетворенням Арреніуса:

```
exp( −E_a / (k_B · T_eff) ) = ∑[i=1..M] w_i · exp( −E_a / (k_B · T_i) )

T_eff = −( E_a / k_B ) / ln[ ∑[i=1..M] w_i · exp( −E_a / (k_B · T_i) ) ]
```

Оскільки експоненційна функція є строго опуклою (нерівність Єнсена: `E[exp(X)] ≥ exp(E[X])`), еквівалентна температура `T_eff` завжди **вище за середнє арифметичне значення температури** `T_mean = ∑ w_i · T_i`. Навіть короткочасні піки літньої спеки роблять домінуючий внесок у річний знос пристрою.

### 4. Трансформація розподілу Вейбулла під дією температурного прискорення
Для описів зносу компонентів зі зростаючою інтенсивністю відмов у часі застосовують двоелементний розподіл Вейбулла:

```
R(t) = exp[ −( t / η )^β ]
```

де `β` — параметр форми (англ. *shape parameter*, `β > 1` для фази зносу), а `η` — характеристичний час життя (масштабний параметр, за якого відмовляє 63.2 % вибірки).

Під дією теплового стресу Арреніуса фізичний механізм зносу залишається незмінним, тому параметр форми зберігається (`β_stress = β_use`), а масштабний параметр масштабується коефіцієнтом прискорення `AF_T`:

```
η_use = η_stress · AF_T = η_stress · exp[ (E_a / k_B) · ( 1 / T_use − 1 / T_stress ) ]
```

Це дозволяє перераховувати повну криву надійності `R(t)` з лабораторних умов у реальні польові умови експлуатації.

## 5. Статистика HTOL та точне виведення довірчих меж за розподілом хі-квадрат

Під час кваліфікації надійності за стандартом JEDEC JESD22-A108 вибірку з `N` компонентів тестують протягом часу `t_test` за температури `T_stress`.

Сумарний еквівалентний польовий час напрацювання вибірки:

```
T_total = N · t_test · AF_total  [приладо-годин]
```

Потік раптових відмов у період нормальної експлуатації моделюється однорідним пуассонівським процесом із постійною інтенсивністю відмов `λ`. Імовірність зафіксувати рівно `r` відмов за сумарний час `T_total`:

```
P(r | λ · T_total) = ( (λ · T_total)^r / r! ) · exp( −λ · T_total )
```

Якщо за час тесту зафіксовано `r` відмов, верхня довірча межа інтенсивності відмов `λ_upper` для заданого рівня статистичної достовірності `1 − α` (Confidence Level `CL`) визначається з умови, що ймовірність отримати `r` або менше відмов не перевищує `α`:

```
∑[k=0..r] ( (λ_upper · T_total)^k / k! ) · exp( −λ_upper · T_total ) = α = 1 − CL
```

З математичних властивостей неповного гамма-розподілу `Γ(r + 1, x)` випливає точний аналітичний зв'язок суми пуассонівського ряду з квантилями розподілу хі-квадрат `χ²`:

```
2 · λ_upper · T_total = χ²( 2·r + 2, 1 − α )

λ_upper = χ²( 2·r + 2, 1 − α ) / ( 2 · T_total )
```

де `χ²(ν, 1 − α)` — квантиль розподілу хі-квадрат із `ν = 2·r + 2` ступенями вільності для рівня значущості `α`.

Для найбільш поширеного випадку нульової кількості відмов (`r = 0`):
- Кількість ступенів вільності: `ν = 2 · 0 + 2 = 2`;
- Інтеграл розподілу хі-квадрат для двох ступенів вільності має простий аналітичний вигляд:
  ```
  P(χ² ≤ X) = 1 − exp( −X / 2 ) = 1 − α = CL
  exp( −X / 2 ) = 1 − CL
  X = 2 · ln( 1 / (1 − CL) )
  ```
- Для рівня довіри 60 % (`CL = 0.60`):
  ```
  χ²(2, 0.40) = 2 · ln( 1 / 0.40 ) = 2 · ln(2.5) = 2 × 0.916291 ≈ 1.8326
  ```
- Для рівня довіри 90 % (`CL = 0.90`):
  ```
  χ²(2, 0.10) = 2 · ln( 1 / 0.10 ) = 2 · ln(10) = 2 × 2.302585 ≈ 4.6052
  ```

Розрахунок інтенсивності відмов у міжнародних одиницях FIT (`1 FIT = 1 відмова на 10⁹ приладо-годин`):

```
λ_60% [FIT] = ( 1.8326 / ( 2 · N · t_test · AF_total ) ) × 10⁹

MTBF_60% [годин] = 1 / λ_60% = ( 2 · N · t_test · AF_total ) / 1.8326
```

Ці формули дають інженеру строгий статистичний інструмент доведення надійності апаратури на рівні десятків мільйонів годин MTBF за результатами стандартних 1000-годинних лабораторних випробувань.
