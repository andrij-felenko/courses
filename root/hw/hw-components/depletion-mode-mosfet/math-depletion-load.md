# 🧮 Розрахунок інвертора зі збідненим навантаженням та фізика вбудованого каналу

Цей математичний аналіз виводить точний розподіл електростатичного потенціалу в імплантованому каналі збідненого MOSFET, визначає порогову напругу відсікання з одновимірного рівняння Пуассона, розраховує малосигнальний коефіцієнт підсилення, запаси завадостійкості каскаду, динаміку перемикання логічного інвертора з ефектом підкладки, перехідні процеси високовольтного старт-апу, втрати комутації в силовому каскоді та критичну частоту енергетичного балансу порівняно з CMOS.

### Електростатика імплантованого каналу: одновимірне рівняння Пуассона

Розгляньмо напівпровідникову структуру n-канального збідненого MOSFET. На відміну від класичного збагаченого приладу, під тонким шаром діоксиду кремнію товщиною `tox` (з питомою ємністю діелектрика `Cox = εox / tox`) за допомогою іонної імплантації створено n-шар глибиною `xj` з постійною концентрацією донорної домішки `ND`. Підкладка являє собою слаболегований p-кремній із концентрацією акцепторів `NA`.

Спрямуймо просторову вісь `x` перпендикулярно до поверхні розділу «діоксид кремнію–кремній» (`x = 0`) углиб монокристала. При прикладанні до металевого або полікремнієвого затвора від'ємної керівної напруги `Vgs < 0` збіднення вбудованого каналу носіями струму розгортається одночасно з двох протилежних боків:
1. **З боку поверхні (під затвором):** поперечне електричне поле затвора виштовхує вільні електрони провідності на глибину `Wg`, оголюючи нерухомі позитивно іонізовані атоми донорів `q·ND`.
2. **З боку металургійного p-n переходу «канал–підкладка»:** контактна різниця потенціалів `φbi` та зовнішня зворотна напруга зміщення витоку щодо тіла підкладки `Vsb` утворюють збіднену область просторового заряду товщиною `Wsub` у нижній частині n-каналу.

Розподіл електростатичного потенціалу `ψ(x)` у межах поверхневої збідненої зони (`0 ≤ x ≤ Wg`) описується одновимірним диференціальним рівнянням Пуассона:

```
d²ψ/dx² = −ρ(x)/εs = −(q·ND)/εs    [рівняння Пуассона для іонізованого донорного шару]
```

де `q = 1.602·10⁻¹⁹ Кл` — елементарний заряд електрона, `εs = 11.7·ε₀ ≈ 1.036·10⁻¹² Ф/см` — абсолютна діелектрична проникність кремнію.

Інтегруючи рівняння Пуассона за координатою `x` з природною граничною умовою зникнення електричного поля на межі нейтрального квазіпровідного каналу (`dψ/dx = 0` при `x = Wg`), отримуємо аналітичний вираз для напруженості електричного поля `E(x)` та просторового профілю потенціалу:

```
dψ/dx = −(q·ND/εs)·(Wg − x)                               [напруженість електричного поля в збідненій зоні]
ψ(x) = ψs − (q·ND/εs)·(Wg·x − x²/2)                       [інтегрування: падіння потенціалу від поверхні ψs]
```

Падіння потенціалу в поверхневому шарі кремнію від поверхні `ψs` до нейтральної серцевини каналу дорівнює:

```
Δψ_канал = ψ(Wg) − ψs = (q·ND·Wg²)/(2·εs)                 [падіння напруги на поверхневому збідненому шарі]
```

Сумарний нескомпенсований позитивний заряд іонізованих донорів у поверхневому шарі на одиницю площі становить:

```
Qd,gate = q·ND·Wg                                         [поверхнева густина заряду збіднення під затвором]
```

Падіння напруги на діелектрику оксиду зв'язане з цим зарядом через питому ємність оксиду `Cox`:

```
Vox = Qd,gate / Cox = (q·ND·Wg) / Cox                     [падіння напруги на підзатворному діелектрику]
```

### Умова відсікання каналу та виведення порогової напруги

Повне відсікання провідного каналу (*pinch-off*) настає в момент, коли верхня збіднена область `Wg` змикається з нижньою збідненою областю підкладкового p-n переходу `Wsub`. Геометрична сума товщин двох збіднених шарів точно покриває всю товщину імплантованого шару:

```
Wg + Wsub = xj                                            [умова геометричного перекриття каналу]
```

Ширина збідненої області різкого несиметричного p-n переходу «n-канал–p-підкладка» визначається класичним виразом:

```
Wsub = √((2·εs·(φbi + Vsb)·NA) / (q·ND·(NA + ND)))        [товщина збіднення переходу з боку n-каналу]
```

де `φbi = (k·T/q)·ln((NA·ND)/ni²)` — контактна різниця потенціалів переходу (`ni ≈ 1.5·10¹⁰ см⁻³` при кімнатній температурі 300 К).

Порогова напруга `Vth` визначається як напруга на затворі відносно витоку `Vgs`, при якій досягається повне змикання збіднених шарів: `Wg = xj − Wsub`. Електростатичний баланс напруг уздовж МДН-структури має вигляд:

```
Vgs = VFB + ψs + Vox                                      [рівняння балансу напруг у комірці]
```

Підставляючи отримані значення для `Vox`, падіння потенціалу `ψs` та вводячи повну поверхневу дозу іонної імплантації `NI = ND·xj` (іонів/см²), отримуємо рівняння порогової напруги збідненого nMOS-транзистора:

```
Vth = VFB + 2·φF − (q·NI)/Cox − (√(2·εs·q·NA·(2·φF + Vsb))) / Cox    [порогова напруга збідненого MOSFET]
```

Фізичний зміст отриманих доданків:
- `VFB + 2·φF` — початкова порогова напруга структури без імплантації (типово `+0.7...+0.9 В`).
- `−(q·NI)/Cox` — негативний зсувний внесок, лінійно пропорційний дозі імплантованих донорів `NI`.
- Останній доданок — внесок об'ємного просторового заряду акцепторів у тілі напівпровідникової підкладки.

Якщо доза імплантації перевищує критичний поріг `NI,crit = (Cox/q)·(VFB + 2·φF)`, порогова напруга змінює свій знак на від'ємний (`Vth < 0`), формуючи нормально відкритий транзистор.

### Вольт-амперна модель збідненого навантаження

У класичному nMOS-інверторі транзистор навантаження `QL` увімкнений у схемі із замкненими затвором і витоком, тобто `Vgs,load = 0 В`. Оскільки поріг навантаження від'ємний (`Vth,load < 0`), напруга перевищення порогу є додатною навіть за відсутності зовнішнього зміщення:

```
Vov = Vgs,load − Vth,load = 0 − (−|Vth,load|) = |Vth,load| > 0    [перевищення порогу при нульовому зсуві]
```

Падіння напруги «стік–витік» на навантажувальному транзисторі виражається через напругу живлення `Vdd` та миттєву вихідну напругу каскаду `Vout`:

```
Vds,load = Vdd − Vout                                     [напруга стік-витік транзистора підтяжки]
```

Залежно від величини вихідної напруги транзистор `QL` послідовно проходить дві фундаментальні робочі області:

**1. Область насичення (`Vds,load ≥ |Vth,load|`, тобто `Vout ≤ Vdd − |Vth,load|`):**
Провідний канал біля витоку перекритий полем стоку. Струм навантаження практично не залежить від вихідної напруги каскаду й дорівнює постійному струму насичення `Idss`:

```
Id,load = (1/2)·μn·Cox·(W/L)load·|Vth,load|² = Idss       [струм насичення генератора підтяжки]
```

де `μn` — рухливість електронів у каналі, `(W/L)load` — співвідношення ширини й довжини каналу навантаження.

**2. Лінійна (триодна) область (`Vds,load < |Vth,load|`, тобто `Vout > Vdd − |Vth,load|`):**
Коли вихідна напруга наближається до шини живлення `Vdd`, канал відкритий по всій довжині:

```
Id,load = μn·Cox·(W/L)load·[|Vth,load|·(Vdd − Vout) − (1/2)·(Vdd − Vout)²]    [лінійний режим підтяжки]
```

При повному заряді виходу (`Vout = Vdd`) струм `Id,load = 0`, а диференційний вихідний опір каналу прагне до скінченного значення:

```
Ron,load = 1 / (μn·Cox·(W/L)load·|Vth,load|)              [диференційний опір при Vout = Vdd]
```

Оскільки опір `Ron,load` скінченний, вихідний вузол гарантовано дозаряджається до повного рівня шини живлення `Voh = Vdd` без порогових втрат напруги.

### Малосигнальний аналіз та коефіцієнт підсилення каскаду

У перехідній зоні перемикання інвертора обидва транзистори — нижній драйверний `QD` та верхній навантажувальний `QL` — одночасно перебувають у режимі насичення. Це дозволяє використовувати каскад як підсилювач напруги з високим коефіцієнтом підсилення.

Еквівалентна малосигнальна схема вихідного вузла містить:
- Крутизну перетворення драйверного транзистора: `gm,D = ∂Id,D / ∂Vin = kn'·(W/L)D·(Vin − Vth,D)`.
- Вихідну диференційну провідність каналу драйвера: `gds,D = 1 / ro,D = λD·Id`.
- Вихідну диференційну провідність каналу навантаження: `gds,L = 1 / ro,L = λL·Id`.
- Провідність підкладки транзистора навантаження (backgate transconductance): `gmb,L = ∂Id,L / ∂Vsb`.

Підкладкова крутизна виражається через крутизну затвора `gm,L` та коефіцієнт ефекту підкладки `γ`:

```
gmb,L = gm,L · (γ / (2·√(2·φF + Vsb))) = η · gm,L         [крутизна підкладкового керування]
```

де параметр `η = gmb / gm ≈ 0.15...0.30` відображає паразитне керування провідністю каналу з боку тіла кристала.

Малосигнальний коефіцієнт підсилення напруги інвертора розраховується за формулою:

```
Av = −gm,D / (gds,D + gds,L + gmb,L)                      [коефіцієнт підсилення інвертора]
```

Оскільки диференційні провідності `gds` малі (вихідні опори `ro` становлять сотні кілоом), підсилення каскаду зі збідненим навантаженням досягає значень `|Av| ≈ 30...60`, що вдесятеро перевищує підсилення резистивного каскаду (`Av,res ≈ −gm,D·RL ≈ 3...6`).

### Розрахунок граничних точок передатної характеристики та завадостійкості

Передатна характеристика напруги (*Voltage Transfer Characteristic, VTC*) інвертора зв'язує вхідну напругу `Vin` та вихідну напругу `Vout`. Критичними точками VTC є точки одиничного підсилення, де нахил дотичної дорівнює мінус одиниці: `dVout / dVin = −1`.

**1. Нижня точка перегину Vil (гранична напруга логічного нуля на вході):**
У точці `Vin = Vil` драйверний транзистор перебуває в насиченні, а транзистор навантаження — у лінійній області. Диференціюючи рівняння рівності струмів `Id,driver = Id,load` за `Vin` та підставляючи умову `dVout / dVin = −1`, отримуємо аналітичний вираз для `Vil`:

```
Vil = Vth,D + (2 / √3) · √((W/L)L / (W/L)D) · |Vth,L|     [гранична напруга логічного нуля]
```

**2. Верхня точка перегину Vih (гранична напруга логічної одиниці на вході):**
У точці `Vin = Vih` драйверний транзистор переходить у лінійну область, а транзистор навантаження перебуває в насиченні. Диференціювання дає:

```
Vih = Vth,D + (4/3) · √((W/L)L / (W/L)D) · |Vth,L|       [гранична напруга логічної одиниці]
```

**3. Розрахунок статичних запасів завадостійкості:**
Запаси завадостійкості за низьким рівнем (`NML`) та за високим рівнем (`NMH`) визначаються як різниці між допустимими рівнями входів та виходів:

```
NML = Vil − Vol                                           [запас завадостійкості за нулем]
NMH = Voh − Vih = Vdd − Vih                               [запас завадостійкості за одиницею]
```

Для типових параметрів процесора 8086 (`Vdd = 5.0 В`, `(W/L)D / (W/L)L = 20`):
- `Vil ≈ 0.8 + 1.155 · √(1/20) · 2.5 = 0.8 + 1.155 · 0.2236 · 2.5 ≈ 1.44 В`.
- `Vih ≈ 0.8 + 1.333 · 0.2236 · 2.5 ≈ 1.54 В`.
- `NML ≈ 1.44 − 0.04 = 1.40 В`, `NMH ≈ 5.0 − 1.54 = 3.46 В`.

Каскад володіє широкими запасами завадостійкості, що перевищують чверть напруги живлення.

### Динамічний розрахунок часу наростання фронту

Розгляньмо процес заряду паразитної ємності навантаження `CL` вихідного вузла під час переходу з логічного нуля (`Vout = Vol ≈ 0 В`) у логічну одиницю (`Vout = Vdd`) після закриття драйверного транзистора.

Динаміка заряду описується диференційним рівнянням балансу струмів:

```
CL·(dVout/dt) = Id,load(Vout)                             [струм заряду вихідної ємності]
```

Стандартний час фронту наростання `tr` (від `Vout = 0.1·Vdd` до `Vout = 0.9·Vdd`) розбивається на два інтегральні інтервали:

**Інтервал 1: Заряд постійним струмом насичення (`0.1·Vdd ≤ Vout ≤ Vdd − |Vth,load|`):**

```
tr1 = ∫[від 0.1·Vdd до Vdd − |Vth,load|] (CL / Idss) dVout
    = (CL / Idss)·(Vdd − |Vth,load| − 0.1·Vdd)            [тривалість лінійного заряду]
```

На цьому інтервалі вихідна напруга зростає строго лінійно з постійною максимальною швидкістю `dVout/dt = Idss / CL`.

**Інтервал 2: Заряд у лінійній області (`Vdd − |Vth,load| ≤ Vout ≤ 0.9·Vdd`):**
Введемо змінну `u = Vdd − Vout`. Диференційне рівняння набуває вигляду:

```
−CL·(du/dt) = kn'·(W/L)load·[|Vth,load|·u − u²/2]         [динаміка на нелінійній ділянці]
```

де `kn' = μn·Cox`. Інтегруючи методом розділення змінних:

```
tr2 = (CL / (kn'·(W/L)load·|Vth,load|)) · ln((2·|Vth,load| − 0.1·Vdd) / (0.1·Vdd · (2·|Vth,load| / (Vdd − Vout1) − 1)))
```

Повний час наростання фронту становить суму: `tr = tr1 + tr2`.

### Вплив ефекту підкладки на динамічну деградацію швидкодії

У реальних монолітних nMOS-мікросхемах витік транзистора навантаження з'єднаний із вихідним вузлом, а підкладка — із землею (`Vbody = 0 В`). Зростання вихідної напруги збільшує зворотну напругу `Vsb = Vout > 0 В`.

Це зумовлює динамічний зсув порогової напруги підкладкою:

```
Vth,load(Vout) = Vth0 + γ·(√(2·φF + Vout) − √(2·φF))      [динамічний поріг навантаження]
```

де `γ = √(2·εs·q·NA) / Cox` — коефіцієнт підкладкового ефекту (`0.3...0.5 В^(1/2)`), `2·φF ≈ 0.6 В`.

Оскільки `Vth0 < 0`, а зсувний доданок додатний, абсолютна величина перенапруги `|Vth,load(Vout)|` спадає в міру наростання вихідного сигналу:

```
|Vth,load(Vout)| = |Vth0| − γ·(√(2·φF + Vout) − √(2·φF))   [зменшення ефективного перекриття]
```

Це викликає два суттєві фізичні ефекти:
1. **Деградація зарядного струму:** струм насичення спадає пропорційно `|Vth,load(Vout)|²`, знижуючись наприкінці циклу заряду на 40–50%.
2. **Зростання часу наростання:** реальний час наростання фронту `tr` зростає на 50–70% порівняно з ідеальною моделлю без урахування підкладки.

### Динаміка заряду конденсатора у високовольтному старт-апі

Розгляньмо перехідний процес заряду конденсатора живлення `Cvcc` у схемі холодного пуску імпульсного джерела живлення зі збідненим MOSFET (`Vg = 0 В`).

У процесі заряду потенціал витоку дорівнює напрузі на конденсаторі: `Vs(t) = V(t)`. Напруга «затвор–витік» змінюється за законом `Vgs(t) = 0 − V(t) = −V(t)`.

Поки `V(t) < |Vth|`, транзистор перебуває в режимі насичення з перенапругою `Vov(t) = |Vth| − V(t)`:

```
Id(t) = (1/2)·kn'·(W/L)·(|Vth| − V(t))²                   [струм заряду конденсатора старт-апу]
```

Диференційне рівняння заряду конденсатора `Cvcc`:

```
Cvcc · (dV/dt) = (1/2)·kn'·(W/L)·(|Vth| − V)²             [нелінійне диференційне рівняння пуску]
```

Розділяючи змінні та інтегруючи від `V = 0` при `t = 0` до миттєвої напруги `V(t)`:

```
∫[0 до V] dV / (|Vth| − V)² = ((kn'·(W/L)) / (2·Cvcc)) · ∫[0 до t] dt
1 / (|Vth| − V) − 1 / |Vth| = t / (2·τ₀)                  [аналітичний інтеграл пускового струму]
```

де часова стала процесу визначається як:

```
τ₀ = Cvcc / (kn'·(W/L)·|Vth|) = Cvcc·|Vth| / (2·Idss)     [характеристичний час пуску]
```

Розв'язуючи відносно `V(t)`, знаходимо точний гіперболічний закон наростання напруги на шині `Vcc`:

```
V(t) = |Vth| · (t / (2·τ₀ + t))                           [динаміка напруги Vcc під час старту]
```

Цей результат показує, що напруга на шині `Vcc` плавно асимптотично наближається до напруги запирання `|Vth|`, після чого транзистор автоматично самозапирається без додаткових зовнішніх компараторів або ключів.

### Комутаційні втрати в силовому каскоді GaN/Si

У силовому каскоді (високовольтний GaN HEMT + низьковольтний Si MOSFET) проміжний вузол `Vmid` між витоком GaN та стоком Si має власну паразитну ємність `Cmid`:

```
Cmid = Coss,Si + Cgs,GaN + Csub,GaN                       [сумарна ємність проміжного вузла]
```

При закритті каскоду проміжний вузол заряджається до напруги `Vmid,max ≈ 8...12 В`. Енергія, що накопичується в цьому вузлі за один такт комутації:

```
Emid = (1/2)·Cmid·Vmid,max² + Qoss,GaN·Vmid,max           [комутаційна енергія проміжного вузла]
```

Оскільки напруга `Vmid,max` невелика (близько 10 В), а ємність сучасного Si MOSFET становить десятки пікофарад, додаткові втрати енергії на такт комутації становлять лічені наноджоулі:

```
P_комутації = Emid · f_sw ≈ (1/2 · 50·10⁻¹² · 10²) · 10⁶ = 2.5·10⁻⁹ · 10⁶ = 2.5 мВт [втрати на 1 МГц]
```

Це доводить, що каскодна структура практично не погіршує високої енергетичної ефективності широкозонного нітриду галію на мегагерцових частотах.

### Енергетичний баланс: розсіювання потужності nMOS проти CMOS

Порівняймо розсіювану потужність логічного інвертора на збідненому nMOS та комплементарного CMOS-інвертора:

**1. Статичні втрати nMOS:**
Коли вихід інвертора перебуває в стані логічного нуля (імовірність стану `P₀ = 0.5`), крізь відкритий драйвер та збіднене навантаження безперервно протікає струм `Idss`:

```
P_stat,nMOS = P₀ · Vdd · Idss = (1/2) · Vdd · Idss        [статична потужність розсіювання nMOS]
```

**2. Динамічні втрати CMOS:**
У CMOS статичний струм відсутній (`P_stat ≈ 0`), а потужність витрачається виключно на перезаряджання вихідної ємності `CL` із тактовою частотою `f`:

```
P_dyn,CMOS = CL · Vdd² · f                                [динамічна потужність перемикання CMOS]
```

**3. Критична частота енергетичного паритету:**
Прирівнюючи втрати `P_stat,nMOS = P_dyn,CMOS`, знаходимо граничну робочу частоту `f_cross`:

```
f_cross = Idss / (2 · CL · Vdd)                           [критична частота балансу енергії]
```

Для типових параметрів (`Vdd = 5 В`, `CL = 0.2 пФ`, `Idss = 80 мкА`):

```
f_cross = 80·10⁻⁶ / (2 · 0.2·10⁻¹² · 5) = 80·10⁻⁶ / 2·10⁻¹² = 40 МГц [частота паритету nMOS і CMOS]
```

На низьких тактових частотах (до 5–10 МГц), характерних для 1970-х років, CMOS переважав за енергоефективністю в сотні разів. Проте при наближенні до частоти `f_cross` динамічні втрати CMOS наздоганяють статичні втрати nMOS, підтверджуючи, що перехід на CMOS був викликаний насамперед необхідністю зменшити сумарну теплову щільність багатотисячних масивів логіки в режимі спокою.

### Температурна стабільність: точка нульового ТКЕ (Zero-TC Point)

Струм стоку збідненого MOSFET залежить від температури через два взаємно конкуруючі фізичні фактори:
1. **Зниження рухливості електронів:** зі зростанням температури посилюється розсіювання на фононах кристалічної ґратки, тому рухливість спадає за ступеневим законом: `μn(T) = μn(T₀)·(T / T₀)^(−kμ)`, де `kμ ≈ 1.5...2.0`. Це прагне зменшити струм стоку.
2. **Зменшення абсолютної величини порогової напруги:** контактна різниця потенціалів і потенціал Фермі падають із ростом температури зі швидкістю `∂|Vth| / ∂T ≈ −1.5...−2.5 мВ/°C`. Для збідненого nMOS це призводить до розширення каналу та зростання струму.

Повна температурна похідна струму стоку в режимі насичення записується як:

```
dId/dT = (Id / μn)·(dμn/dT) + (2·Id / (Vgs − Vth))·(−dVth/dT)    [температурний баланс струму]
```

Прирівнюючи повну похідну до нуля (`dId/dT = 0`), знаходимо умову існування **точки нульового температурного коефіцієнта струму** (*Zero Temperature Coefficient, ZTC*):

```
Vgs,ZTC = Vth(T) + 2·(kμ / T)·(1 / α_vth)                 [напруга затвора нульового ТКЕ]
```

де `α_vth = |d|Vth| / dT|`.

При роботі в точці `Vgs = Vgs,ZTC` струм стоку збідненого транзистора залишається термостабільним із відносним дрейфом менше `50 ppm/°C` у діапазоні температур від −40 до +125 °C. Це дозволяє використовувати збіднений MOSFET як високопрецизійне джерело опорного струму без застосування складних термокомпенсованих аналогових кіл.

### Практичний інженерний розрахунок параметрів інвертора

Розрахуймо параметри логічного інвертора nMOS для мікропроцесора класу 8086:
- Напруга живлення: `Vdd = 5.0 В`.
- Питомий параметр провідності процесу: `kn' = μn·Cox = 50 мкА/В²`.
- Драйверний транзистор `QD`: `(W/L)D = 10 / 1`, порогова напруга `Vth,D = +0.8 В`.
- Збіднене навантаження `QL`: `(W/L)L = 1 / 2 = 0.5`, початковий поріг `Vth0,L = −2.5 В`.
- Параметри підкладки: `γ = 0.4 В^(1/2)`, `2·φF = 0.6 В`.
- Ємність навантаження вихідного вузла: `CL = 0.2 пФ = 200 фФ`.

**Крок 1. Розрахунок струму насичення навантаження при Vout = 0 В:**

```
Idss = (1/2)·kn'·(W/L)L·|Vth0,L|²
     = 0.5 · 50·10⁻⁶ · 0.5 · (2.5)²
     = 12.5·10⁻⁶ · 6.25 = 78.125 мкА                       [струм короткого замикання навантаження]
```

**Крок 2. Розрахунок вихідної напруги логічного нуля Vol:**
При низькому рівні на виході драйверний транзистор перебуває в лінійній області з напругою на затворі `Vin = Vdd = 5.0 В`:

```
Id,driver ≈ kn'·(W/L)D·[(Vin − Vth,D)·Vol − Vol²/2]
78.125·10⁻⁶ = 50·10⁻⁶ · 10 · [(5.0 − 0.8)·Vol − Vol²/2]
78.125·10⁻⁶ = 500·10⁻⁶ · [4.2·Vol − Vol²/2]
0.15625 = 4.2·Vol − 0.5·Vol²
```

Розв'язуючи квадратне алгебраїчне рівняння:

```
Vol ≈ 0.15625 / 4.2 ≈ 0.037 В                             [напруга логічного нуля на виході]
```

Запас завадостійкості за низьким рівнем: `NML = VIL − VOL ≈ 0.8 − 0.04 = 0.76 В`.

**Крок 3. Розрахунок зсуву порогу ефектом підкладки при Vout = 3.0 В:**

```
ΔVth = γ·(√(2·φF + Vout) − √(2·φF))
     = 0.4 · (√(0.6 + 3.0) − √0.6)
     = 0.4 · (1.897 − 0.775) = 0.4 · 1.122 ≈ 0.449 В       [динамічний зсув порогової напруги]

|Vth,load(3.0 В)| = 2.5 − 0.449 = 2.051 В                  [зменшений ефективний поріг навантаження]
```

Струм підтяжки при `Vout = 3.0 В` деградує з `78.1 мкА` до:

```
Id,load(3.0 В) = 0.5 · 50·10⁻⁶ · 0.5 · (2.051)² ≈ 52.6 мкА [деградація струму підтяжки на 32.7%]
```

**Крок 4. Розрахунок тривалості фронту наростання tr:**
Без урахування ефекту підкладки час заряду становить:

```
tr1 = (0.2·10⁻¹² Ф / 78.125·10⁻⁶ А) · (5.0 − 2.5 − 0.5) = 2.56·10⁻⁹ · 2.0 = 5.12 нс
tr2 ≈ 3.20 нс
tr_ідеал = tr1 + tr2 ≈ 8.32 нс
```

З урахуванням деградації струму через ефект підкладки повний розрахунковий час наростання становить `tr_реальн ≈ 12.8 нс`, що забезпечує граничну тактову частоту перемикання логічного вузла близько `f_max ≈ 1 / (2·tr) ≈ 39 МГц`.
