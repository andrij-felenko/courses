# 📋 Специфікація структури BOM та таксономія сповіщень PCN/PDN

Виробнича специфікація виробу (англ. *Bill of Materials*, BOM) — це головний юридичний та технологічний контракт між інженерною командою та контрактним виробником (англ. *Electronics Manufacturing Services*, EMS). Відсутність хоча б одного обов'язкового атрибута, неоднозначний опис номіналу або використання загальних назв замість точного номера виробника (англ. *Manufacturer Part Number*, MPN) призводить до зупинки автоматичної лінії SMT-монтажу, закупівлі несумісних компонентів або зриву термінів серійного випуску.

## Обов'язкова структура колонок виробничого BOM

Контрактні виробники вимагають подання BOM у форматі таблиць (CSV, TSV, XLSX) з чітко розмежованими полями. Кожен рядок специфікації відповідає або унікальній групі позиційних позначень з ідентичним MPN, або окремому посадковому місцю.

| Назва поля | Тип даних | Обов'язковість | Приклад значення | Інженерне призначення та правила заповнення |
| :--- | :--- | :--- | :--- | :--- |
| `Designator` | Рядок | Так | `C12, C15, C18` | Список позиційних позначень на схемі та друкованій платі (PCB). Роздільник — кома з пробілом. Діапазони на зразок `R1-R5` неприпустимі для автоматизованого імпорту. |
| `Quantity` | Ціле число | Так | `3` | Загальна кількість компонентів даного типу на одній зібраній платі (англ. *Printed Circuit Board Assembly*, PCBA). Повинна строго дорівнювати кількості елементів у полі `Designator`. |
| `MPN` | Рядок | Так | `GRM188R71E104KA01D` | Повний, точний номер деталі виробника (Primary MPN). Включає всі суфікси пакування (Tape & Reel, Bulk), температурного діапазону та допуску. |
| `Manufacturer` | Рядок | Так | `Murata Electronics` | Офіційна назва компанії-виробника первинного компонента. |
| `Value` | Рядок | Так | `100nF` | Номінальне значення електричного параметра (опір, ємність, індуктивність, напруга стабілізації, частота). |
| `Description` | Рядок | Так | `Cap MLCC 0.1uF 25V X7R 10% 0603` | Повний інженерний опис: тип компонента, номінал, робоча напруга, тип діелектрика/ТКЕ, допуск, типорозмір. Дозволяє оператору EMS швидко виявити друкарську помилку в MPN. |
| `Package / Footprint`| Рядок | Так | `0603 (1608 Metric)` | Назва посадкового місця на платі за класифікацією IPC-7351 або JEDEC (наприклад, `SOT-23-5`, `QFN-32-5x5mm-0.5p`, `0402`). |
| `Tolerance` | Рядок | Так | `±10%` | Допустиме відхилення номіналу (наприклад, `±1%`, `±5%`, `±10%`, `±0.1%`). |
| `Voltage / Power` | Рядок | Так | `25V` / `0.1W` | Гранично допустима робоча напруга (для конденсаторів, діодів) або номінальна розсіювана потужність (для резисторів). |
| `Alt_MPN_1` | Рядок | Рекомендовано | `CL10B104KB8NNNC` | Номер деталі схваленого альтернативного виробника (Secondary Source MPN / AML-1). |
| `Alt_Mfr_1` | Рядок | Рекомендовано | `Samsung Electro-Mechanics` | Назва виробника першої альтернативи. |
| `Alt_MPN_2` | Рядок | Опціонально | `C0603X7R1E104K030BA` | Номер деталі другої альтернативи (AML-2). |
| `Alt_Mfr_2` | Рядок | Опціонально | `TDK Corporation` | Назва виробника другої альтернативи. |
| `Mounting_Type` | Перелік | Так | `SMT` | Технологія монтажу: `SMT` (поверхневий), `THT` (наскрізний в отвори), `Press-Fit`, `Mechanical`. |
| `Fit_Status` | Перелік | Так | `Fitted` | Статус встановлення на плату: `Fitted` (монтувати) або `DNP` / `NF` (англ. *Do Not Populate / Not Fitted* — посадкове місце лишається порожнім). |
| `Packaging` | Перелік | Так | `Tape & Reel 7"` | Вимоги до пакування для автоматичного живильника (англ. *feeder*): котушка (Tape & Reel), піддон (Tray), пенал (Tube). Заборонено вказувати насипні пакети (Bulk) для серійного SMT. |

## Внутрішній артикул (IPN) проти артикулу виробника (MPN)

На зрілих підприємствах у BOM вводиться додаткова колонка внутрішнього коду компанії — IPN (англ. *Internal Part Number* або *Company Part Number*, CPN). 

Принципова різниця між MPN та IPN полягає в абстракції:
- **MPN (Manufacturer Part Number):** жорстко прив'язаний до одного конкретного заводу, наприклад `RC0603FR-0710KL` від Yageo. Якщо завод зупиниться, закупівля не має права автоматично купити резистор Vishay `CRCW060310K0FKEA` без зміни схемної документації.
- **IPN (Internal Part Number):** внутрішній інженерний код компанії, наприклад `RES-0603-10K-1%-0.1W`. До цього внутрішнього коду в корпоративній ERP/PLM системі прив'язується цілий перелік схвалених виробників (AML). Інженер на схемі вказує саме IPN, що дозволяє відділу закупівель обирати найдешевшого постачальника серед затверджених альтернатив без необхідності випуску нової ревізії креслень.

## Правила структуризації затвердженого списку виробників (AML)

Затверджений перелік виробників (англ. *Approved Manufacturer List*, AML) регламентує, які саме альтернативні компоненти відділ закупівель або EMS мають право купувати без додаткового узгодження з розробником плати.

```
                    ┌────────────────────────────────────────┐
                    │        ПЕРВИННИЙ КОМПОНЕНТ (Primary)   │
                    │ MPN: GRM188R71E104KA01D (Murata)       │
                    └───────────────────┬────────────────────┘
                                        │
                         Схвалені заміни у BOM (AML)
                                        │
           ┌────────────────────────────┴────────────────────────────┐
           ▼                                                         ▼
┌───────────────────────────────────────┐ ┌───────────────────────────────────────┐
│     АЛЬТЕРНАТИВА 1 (Second Source)    │ │     АЛЬТЕРНАТИВА 2 (Third Source)     │
│ MPN: CL10B104KB8NNNC (Samsung)        │ │ MPN: C0603X7R1E104K030BA (TDK)        │
│ Статус: Повна перевірка у лабораторії │ │ Статус: Повна перевірка у лабораторії │
└───────────────────────────────────────┘ └───────────────────────────────────────┘
```

Для пасивних компонентів стандартизація за AML вимагає повного збігу таких параметрів:
1. **Геометричний типорозмір:** однаковий IPC-футпринт із допустимими допусками на висоту деталі (Z-axis height), що критично для низькопрофільних корпусів.
2. **Температурний коефіцієнт і діелектрик:** заборонено замінювати діелектрик `X7R` на `X5R` (знижується верхня температура з +125°C до +85°C) або на `Y5V` (неприпустимий температурний дрейф).
3. **Робоча напруга:** номінал альтернативи повинен бути рівним або вищим за первинний (наприклад, заміна 25 В на 50 В у тому ж корпусі дозволена, зворотна заміна — суворо заборонена).

## Вимоги до вологочутливості (IPC/JEDEC J-STD-020 MSL) та пакування (EIA-481)

Сучасний контрактний монтаж вимагає фіксації технологічних атрибутів пакування в структурі BOM або прикріплених вимогах закупівлі:

1. **Рівень чутливості до вологи (Moisture Sensitivity Level, MSL):**
   Пластмасові корпуси мікросхем вбирають вологу з повітря. Під час безсвинцевого паяння при температурі +260°C закипаюча вода всередині чипа розриває пластик (ефект «попкорну», англ. *popcorning*).
   - **MSL 1:** необмежений час життя на повітрі (англ. *Floor Life*) при ≤ +30°C / 85% RH.
   - **MSL 2 / 2a:** час життя 1 рік / 4 тижні.
   - **MSL 3:** час життя 168 годин (7 діб) після розкриття вакуумного пакета (англ. *Moisture Barrier Bag*, MBB).
   - **MSL 4 / 5:** час життя 72 години / 48 годин. Компоненти, час зберігання яких перевищено, вимагають тривалого технологічного сушіння в термопечі перед паянням.

2. **Стандарт стрічкового пакування (EIA-481):**
   Для автоматичних живильників SMT-автомата критичний крок кишень у стрічці (англ. *Tape Pitch*, 2 мм для 0402, 4 мм для 0603/0805) та глибина рельєфної стрічки. Помилка у виборі суфікса пакування призводить до отримання сипучих компонентів у пластикових мішках (Bulk), які Pick-and-Place автомат не здатний завантажити у фідер.

## Екологічні стандарти та матеріальна декларація (IPC-1752, RoHS, REACH)

Для легального продажу електронного пристрою на ринках Європейського Союзу, США та Азії кожен рядок BOM повинен мати підтверджений статус відповідності екологічним директивам:

- **Директива RoHS (Restriction of Hazardous Substances):** заборона використання свинцю (Pb), ртуті (Hg), кадмію (Cd), шестивалентного хрому та бромованих вогнетривких добавок (PBB/PBDE). У BOM фіксується статус `RoHS Compliant (Lead-Free)`.
- **Регламент REACH (SVHC):** облік вмісту особливо небезпечних речовин (англ. *Substances of Very High Concern*).
- **Стандарт IPC-1752:** уніфікований XML-формат обміну матеріальними деклараціями між постачальниками напівпровідників та складальними заводами.

## Стандарти та класифікація сповіщень JEDEC (PCN / PDN)

Зміна параметрів компонентів у процесі їхнього промислового виробництва регулюється стандартами асоціації JEDEC (англ. *Joint Electron Device Engineering Council*).

### JEDEC JESD46: Повідомлення про зміну продукту (PCN)

Стандарт JESD46 зобов'язує виробника напівпровідників надіслати клієнтам офіційне сповіщення (англ. *Product Change Notification*, PCN) щонайменше за **90 календарних днів** до першої відгрузки зміненого компонента, якщо зміна стосується форми, посадки або функції (англ. *Form, Fit, Function*):

- **Зміна кристала (Silicon Die):** перехід на новий техпроцес (наприклад, з 90 нм на 55 нм), зменшення площі кристала (die shrink), перенесення виробництва на іншу фабрику (fab transfer).
- **Зміна матеріалів корпусування:** перехід з золотого зварювального дроту на мідний (Au to Cu wire bonding), заміна компаунду або складу покриття виводів (Lead-Free / RoHS перехід).
- **Зміна місця тестування або пакування:** перенесення фінальної збірки (Assembly & Test site).

### JEDEC JESD48: Повідомлення про припинення виробництва (PDN / PTN)

Стандарт JESD48 визначає процедуру зняття компонента з виробництва (англ. *Product Discontinuance Notification*, PDN або *Product Termination Notification*, PTN):

- **Мінімальний термін прийому замовлень (Last Time Buy, LTB):** не менше **6 місяців** від дати публікації PDN. У цей період замовник зобов'язаний розрахувати потребу в чипах на весь залишковий термін випуску пристрою та розмістити безвідкличне замовлення (англ. *Non-Cancelable, Non-Returnable*, NCNR).
- **Мінімальний термін відвантаження (Last Time Ship, LTS):** не менше **12 місяців** від дати публікації PDN. Після цієї дати постачання компонента офіційними каналами повністю припиняється.

## Матриця статусів життєвого циклу

| Статус у базах даних | Ознака у дистриб'юторів | Ризик для нового проєкту | Рекомендована інженерна дія |
| :--- | :--- | :--- | :--- |
| `Preview / Advance` | `Sampling / Pre-release` | Високий | Дозволено для прототипування; заборонено замовляти серійні плати до фіксації кремнієвої ревізії. |
| `Active / Production` | `In Stock / Factory Lead Time` | Нульовий | Базовий компонент для нових серійних виробів. |
| `NRND` | `Not Recommended for New Designs` | Критичний | Не закладати у нові плати. Для поточних виробів — негайно шукати та верифікувати аналоги. |
| `Last Time Buy (LTB)` | `Discontinued / Cut-off Date` | Фатальний | Замовити буферний запас NCNR або виконати терміновий редизайн друкованої плати. |
| `Obsolete / Discontinued`| `No Longer Manufactured` | Повна недоступність | Компонент відсутній у виробника; купівля можлива лише через незалежних брокерів із ризиком підробки. |
