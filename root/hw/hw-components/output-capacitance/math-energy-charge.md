# 🧮 Математика нелінійної вихідної ємності: виведення E_oss, C_o(er) та C_o(tr)

Вихідна ємність польового транзистора змінюється в сотні разів при зміні напруги на стоці, тому класична формула енергії конденсатора `½·C·V²` дає помилку в кілька разів, а розрахунок часу перезаряду за тією самою ємністю призводить до хибного мертвого часу. Щоб точно розрахувати теплові втрати та динаміку перемикання, нелінійну залежність `C_oss(v)` інтегрують окремо для накопиченого заряду та накопиченої енергії, отримуючи два принципово різні еквівалентні значення ємності.

## Фізичний вивід ємності збідненого шару з рівняння Пуассона

Щоб зрозуміти, чому бар'єрна ємність напівпровідникового p-n переходу залежить від прикладеної напруги, звернемося до електростатики збідненої зони *(Space Charge Region, SCR)*. Розгляньмо одновимірний різкий ступінчастий p-n перехід, де p-область базового шару легована акцепторами з концентрацією `N_a`, а n-область дрейфового шару стоку легована донорами з концентрацією `N_d`.

Розподіл електростатичного потенціалу `ψ(x)` у збідненій зоні описується одновимірним рівнянням Пуассона:

```
d²ψ / dx² = - ρ(x) / ε_s
```

де `ρ(x)` — об'ємна густина просторового заряду іонізованих домішок, а `ε_s = ε_r · ε_0` — абсолютна діелектрична проникність напівпровідника (для кремнію `ε_r ≈ 11.7`, для карбіду кремнію `ε_r ≈ 9.7`).

У наближенні повного збіднення вільні носії заряду відсутні, тому в n-області (`0 < x < x_n`) заряд визначається позитивними іонами донорів `ρ = + q · N_d`, а в p-області (`-x_p < x < 0`) — негативними іонами акцепторів `ρ = - q · N_a`, де `q = 1.602 · 10⁻¹⁹ Кл` — елементарний заряд.

Умова нейтральності вимагає рівності повного заряду по обидва боки переходу:

```
q · N_a · x_p = q · N_d · x_n
```

Інтегруючи рівняння Пуассона двічі та накладаючи граничні умови для повної напруги на переході `V_total = V_bi + V_r` (де `V_bi` — контактна різниця потенціалів, а `V_r = V_ds` — прикладена зворотна напруга зміщення), отримуємо вираз для повної ширини збідненої зони `W = x_n + x_p`:

```
W(V_ds) = √( (2 · ε_s / q) · ( (N_a + N_d) / (N_a · N_d) ) · (V_bi + V_ds) )
```

Оскільки у високовольтних силових транзисторах дрейфова область легована значно слабше за базову (`N_d << N_a`), вираз спрощується до однобічного переходу:

```
W(V_ds) ≈ √( (2 · ε_s · (V_bi + V_ds)) / (q · N_d) )
```

Диференціальна ємність переходу площею `A` визначається як ємність плоского шару діелектрика товщиною `W(V_ds)`:

```
C_j(V_ds) = (ε_s · A) / W(V_ds) = A · √( (q · ε_s · N_d) / (2 · (V_bi + V_ds)) )
```

Ввівши початкову ємність при нульовій зовнішній напрузі `C_0 = A · √( (q · ε_s · N_d) / (2 · V_bi) )`, отримуємо класичний закон нелінійної ємності різкого p-n переходу:

```
C_oss(v) = C_0 / √(1 + v / V_bi) = C_0 · (1 + v / V_bi)⁻⁰˙⁵
```

Для кремнію внутрішній контактний потенціал становить:

```
V_bi = (k · T / q) · ln( (N_a · N_d) / n_i² ) ≈ 0.7–0.8 В
```

де `k` — стала Больцмана, `T` — абсолютна температура, `n_i` — власна концентрація носіїв у кремнії (`n_i ≈ 1.5 · 10¹⁰ см⁻³` при 300 К).

## Загальні інтегральні рівняння заряду та енергії

Зв'язок між миттєвим диференціальним зарядом `dq`, напругою `v` та диференціальною ємністю є фундаментальним означенням ємності:

```
dq = C_oss(v) · dv
```

Щоб знайти повний електричний заряд `Q_oss(V_ds)`, накопичений у вихідній ємності при заряді транзистора від `0` до напруги шини `V_ds`, інтегруємо диференціал заряду по напрузі:

```
Q_oss(V_ds) = ∫[0 → V_ds] C_oss(v) dv
```

Енергія `E_oss(V_ds)`, що запасається в електричному полі збідненої зони напівпровідника, дорівнює роботі із перенесення заряду проти сил поля:

```
dE = v · dq = v · C_oss(v) · dv
```

Інтегруючи від нульової напруги до кінцевої напруги `V_ds`, отримуємо точний вираз для накопиченої енергії:

```
E_oss(V_ds) = ∫[0 → V_ds] v · C_oss(v) dv
```

Якщо проінтегрувати цей вираз частинами, поклавши `u = v` та `dw = C_oss(v) dv` (звідки `w = Q_oss(v)`), енергія набуває альтернативного геометричного змісту через заряд:

```
∫[0 → V_ds] v · C_oss(v) dv
= v · Q_oss(v) |[0 → V_ds] - ∫[0 → V_ds] Q_oss(v) dv   [інтегрування частинами: u=v, dw=C(v)dv]
= V_ds · Q_oss(V_ds) - ∫[0 → V_ds] Q_oss(v) dv         [підстановка меж інтегрування]
= ∫[0 → Q_oss] v(q) dq                                 [перехід до інтеграла по змінній заряду q]
```

Це рівняння доводить: енергія `E_oss` є площею під кривою `v(q)` на площині «заряд–напруга», тоді як добуток `V_ds · Q_oss` — це повна енергія, яку джерело живлення віддає при заряді ємності струмом.

## Визначення еквівалентних ємностей C_o(er) та C_o(tr)

Промисловий стандарт JEDEC JESD24-11 визначає дві еквівалентні константи для спрощення інженерних розрахунків:

1. **Енергетично-еквівалентна ємність `C_o(er)`** *(energy-related effective output capacitance)* — це гіпотетична лінійна ємність постійної величини, яка при заряді до напруги `V_ds` накопичує ту саму енергію `E_oss`, що й реальний транзистор:

```
E_oss = ½ · C_o(er) · V_ds²
```

Звідси формульне визначення `C_o(er)`:

```
C_o(er) = (2 · E_oss) / V_ds² = (2 / V_ds²) · ∫[0 → V_ds] v · C_oss(v) dv
```

2. **Часово-еквівалентна (зарядово-еквівалентна) ємність `C_o(tr)`** *(time-related effective output capacitance)* — це гіпотетична лінійна ємність постійної величини, яка при заряді постійним струмом `I_ch` досягає напруги `V_ds` за той самий час `t_ch`, що й реальний прилад, тобто накопичує той самий заряд `Q_oss`:

```
Q_oss = I_ch · t_ch = C_o(tr) · V_ds
```

Звідси формульне визначення `C_o(tr)`:

```
C_o(tr) = Q_oss / V_ds = (1 / V_ds) · ∫[0 → V_ds] C_oss(v) dv
```

## Аналітичне виведення для узагальненого профілю легування

У загальному випадку степеневий закон описує ємність через показник профілю `m`:

```
C_oss(v) = C_0 / (1 + v / V_bi)ᵐ
```

Розгляньмо аналітичні розв'язки для трьох найважливіших фізичних випадків:
1. `m = 0.5` — різкий ступінчастий перехід (abrupt junction, типовий для планарних кремнієвих та SiC приладів);
2. `m = 0.333` — лінійно-градієнтний перехід (linearly graded junction, дифузійні шари);
3. `m = 1.0` — гіперрізкий перехід (hyper-abrupt junction / граничний випадок бічного збіднення).

### 1. Повний розрахунок для різкого переходу (m = 0.5)

#### Заряд Q_oss:

```
Q_oss = ∫[0 → V_ds] C_0 · (1 + v / V_bi)⁻⁰˙⁵ dv

Заміна: u = 1 + v / V_bi  ⇒  du = dv / V_bi  ⇒  dv = V_bi · du
Межі: v = 0 → u = 1;  v = V_ds → u = 1 + V_ds / V_bi

Q_oss
= C_0 · V_bi · ∫[1 → 1 + V_ds/V_bi] u⁻⁰˙⁵ du             [винесення сталих за знак інтеграла]
= C_0 · V_bi · [ 2 · u⁰˙⁵ ] |[1 → 1 + V_ds/V_bi]         [первісна від u⁻⁰˙⁵ дорівнює 2·u⁰˙⁵]
= 2 · C_0 · V_bi · ( √(1 + V_ds / V_bi) - 1 )            [підстановка меж інтегрування]
```

Оскільки у високовольтних силових колах `V_ds >> V_bi` (наприклад, при `V_ds = 400 В` та `V_bi = 0.8 В` відношення `V_ds / V_bi = 500`):

```
Q_oss ≈ 2 · C_0 · √(V_bi · V_ds) = 2 · (C_0 / √(V_ds / V_bi)) · V_ds = 2 · C_oss(V_ds) · V_ds
```

Звідси випливає значення часової еквівалентної ємності:

```
C_o(tr) = Q_oss / V_ds ≈ 2 · C_oss(V_ds)
```

#### Енергія E_oss:

```
E_oss = ∫[0 → V_ds] v · C_0 · (1 + v / V_bi)⁻⁰˙⁵ dv

Заміна: u = 1 + v / V_bi  ⇒  v = V_bi · (u - 1),  dv = V_bi · du
Межі: u_min = 1,  u_max = 1 + V_ds / V_bi

E_oss
= C_0 · V_bi² · ∫[1 → u_max] (u - 1) · u⁻⁰˙⁵ du          [підстановка v через u]
= C_0 · V_bi² · ∫[1 → u_max] (u⁰˙⁵ - u⁻⁰˙⁵) du          [розкриття дужок у підінтегральному виразі]
= C_0 · V_bi² · [ ⅔ · u¹˙⁵ - 2 · u⁰˙⁵ ] |[1 → u_max]     [інтегрування степеневих функцій]
= C_0 · V_bi² · ( ⅔ · (u_max¹˙⁵ - 1) - 2 · (u_max⁰˙⁵ - 1) )
```

При `u_max = V_ds / V_bi >> 1` домінуючим є перший доданок `⅔ · u_max¹˙⁵`:

```
E_oss ≈ ⅔ · C_0 · V_bi² · (V_ds / V_bi)¹˙⁵ = ⅔ · C_0 · √V_bi · V_ds¹˙⁵
```

Підставивши диференціальну ємність `C_oss(V_ds) = C_0 · √(V_bi / V_ds)`:

```
E_oss ≈ ⅔ · C_oss(V_ds) · V_ds²
```

Порівняємо це з визначенням `E_oss = ½ · C_o(er) · V_ds²`:

```
½ · C_o(er) · V_ds² = ⅔ · C_oss(V_ds) · V_ds²
⇒ C_o(er) = ⁴/₃ · C_oss(V_ds) ≈ 1.333 · C_oss(V_ds)
```

#### Співвідношення C_o(tr) та C_o(er) для m = 0.5:

```
C_o(tr) / C_o(er)
= (2 · C_oss(V_ds)) / (⁴/₃ · C_oss(V_ds))    [підстановка виведених формул C_o(tr) та C_o(er)]
= 2 / (⁴/₃)                                 [скорочення на спільний множник C_oss(V_ds)]
= 2 · (¾)                                   [ділення на дріб: множення на обернений]
= 1.50                                      [результат: відношення дорівнює 3/2 = 1.5]
```

Для класичного різкого p-n переходу часова ємність `C_o(tr)` рівно на **50% перевищує** енергетичну ємність `C_o(er)`.

### 2. Повний розрахунок для градієнтного переходу (m = 0.333)

Для лінійно-градієнтного переходу інтегрування дає:

```
Q_oss = C_0 · V_bi · ∫ u⁻⁰˙³³³ du = 1.5 · C_0 · V_bi · (u_max⁰˙⁶⁶⁷ - 1) ≈ 1.5 · C_oss(V_ds) · V_ds
⇒ C_o(tr) = 1.5 · C_oss(V_ds)

E_oss = C_0 · V_bi² · ∫ (u⁰˙⁶⁶⁷ - u⁻⁰˙³³³) du ≈ 0.6 · C_oss(V_ds) · V_ds²
⇒ ½ · C_o(er) · V_ds² = 0.6 · C_oss(V_ds) · V_ds²
⇒ C_o(er) = 1.2 · C_oss(V_ds)

Співвідношення:
C_o(tr) / C_o(er) = (1.5 · C_oss) / (1.2 · C_oss) = 1.25
```

### 3. Узагальнена формула для довільного показника m (де m < 1)

У загальному вигляді для будь-якого показника степеня `m` (при `V_ds >> V_bi`) виконуються точні співвідношення:

```
C_o(tr) = (1 / (1 - m)) · C_oss(V_ds)

C_o(er) = (2 / (2 - m)) · C_oss(V_ds)

Точне співвідношення:
C_o(tr) / C_o(er)
= (1 / (1 - m)) / (2 / (2 - m))               [підстановка формул C_o(tr) та C_o(er)]
= (2 - m) / (2 · (1 - m))                     [ділення дробів: множення на обернений дріб]

Перевіримо:
Для m = 0.5:   (2 - 0.5) / (2 · (1 - 0.5)) = 1.5 / 1.0 = 1.50
Для m = 0.333: (2 - 1/3) / (2 · (1 - 1/3)) = (5/3) / (4/3) = 1.25
```

## Фізична модель Superjunction: двовимірне збіднення стовпчиків

У суперперехідних структурах дрейфовий шар складається з паралельних стовпчиків шириною `w_p` та `w_n` з концентраціями `N_a` та `N_d`. При ідеальному балансі зарядів `N_a · w_p = N_d · w_n`.

Напруга повного бічного змикання стовпчиків розраховується з інтегрування поля вздовж горизонтальної осі:

```
V_pinch = (q · N_d · w_n²) / (8 · ε_s)
```

Для типових параметрів суперпереходу (`w_n = 3 мкм = 3 · 10⁻⁴ см`, `N_d = 2 · 10¹⁵ см⁻³`):

```
V_pinch = (1.6·10⁻¹⁹ · 2·10¹⁵ · 9·10⁻⁸) / (8 · 11.7 · 8.85·10⁻¹⁴) ≈ 28.8 · 10⁻¹² / 8.28·10⁻¹² ≈ 3.47 В  (внутрішнє)
З урахуванням контактів реальна напруга змикання на виводах становить V_pinch ≈ 20–40 В.
```

### Кусково-аналітичний розрахунок Superjunction

Змоделюємо характеристику `C_oss(v)` двома областями:
* `C_oss(v) = C_low` при `0 ≤ v ≤ V_pinch` (велика планарна ємність до змикання);
* `C_oss(v) = C_high` при `V_pinch < v ≤ V_ds` (мінімальна ємність після повного збіднення стовпчиків).

```
Q_oss = C_low · V_pinch + C_high · (V_ds - V_pinch)

E_oss = ½ · C_low · V_pinch² + ½ · C_high · (V_ds² - V_pinch²)
```

Підставимо реальні параметри сучасного 600 В транзистора (наприклад, IPW60R045):
* `V_ds = 400 В`, `V_pinch = 25 В`
* `C_low = 5000 пФ`, `C_high = 45 пФ`

#### Розрахунок заряду:

```
Q_1 = 5000 пФ · 25 В = 125 000 пКл = 125 нКл       [заряд у низьковольтній зоні 0..25 В]
Q_2 = 45 пФ · (400 В - 25 В) = 45 · 375 = 16.875 нКл [заряд у високовольтній зоні 25..400 В]
Q_oss = 125 + 16.875 = 141.875 нКл                [повний заряд вихідної ємності]
```

Часова еквівалентна ємність:

```
C_o(tr) = Q_oss / V_ds = 141.875 нКл / 400 В = 354.7 пФ
```

#### Розрахунок енергії:

```
E_1 = ½ · 5000 пФ · (25 В)² = 0.5 · 5·10⁻⁹ · 625 = 1.5625 мкДж    [енергія в зоні 0..25 В]
E_2 = ½ · 45 пФ · (400² - 25²) = 0.5 · 45·10⁻¹² · 159375 = 3.586 мкДж [енергія в зоні 25..400 В]
E_oss = 1.5625 мкДж + 3.586 мкДж = 5.1485 мкДж                    [повна накопичена енергія]
```

Енергетична еквівалентна ємність:

```
C_o(er) = (2 · E_oss) / V_ds² = (2 · 5.1485 · 10⁻⁶) / 160 000 = 64.36 пФ
```

#### Співвідношення:

```
C_o(tr) / C_o(er) = 354.7 пФ / 64.36 пФ ≈ 5.51
```

У високовольтному Superjunction MOSFET часова ємність перевищує енергетичну ємність у **5.5 раза**. Це наочно доводить математичну природу урвища ємності: заряд зосереджений у початкових 25 вольтах, тоді як енергія накопичується переважно у високовольтній області.

## Чисельне інтегрування за табличними точками з даташита

На практиці залежність `C_oss(v)` задається таблицею виміряних значень або масивом точок із даташита. Оскільки функція має високу кривизну біля нуля, застосовують логарифмічну дискретизацію по напрузі та метод трапецій.

Нижче наведено зразкову реалізацію чисельного інтегратора мовами C та C++:

:::tabs
```c
#include <stdio.h>
#include <math.h>

typedef struct {
    double v;    // напруга сток-витік, В
    double coss; // вихідна ємність, Фарад
} CossPoint;

typedef struct {
    double q_oss;   // повний заряд, Кулони
    double e_oss;   // накопичена енергія, Джоулі
    double c_o_tr;  // часова еквівалентна ємність, Фаради
    double c_o_er;  // енергетична еквівалентна ємність, Фаради
} CossResult;

CossResult integrate_coss(const CossPoint* pts, size_t count) {
    CossResult res = {0.0, 0.0, 0.0, 0.0};
    if (count < 2) return res;

    for (size_t i = 0; i < count - 1; ++i) {
        double v1 = pts[i].v;
        double v2 = pts[i+1].v;
        double c1 = pts[i].coss;
        double c2 = pts[i+1].coss;
        double dv = v2 - v1;

        if (dv <= 0.0) continue;

        // Метод трапецій для заряду: dq = 0.5 * (C1 + C2) * dv
        double dq = 0.5 * (c1 + c2) * dv;
        res.q_oss += dq;

        // Метод трапецій для енергії: dE = 0.5 * (v1*C1 + v2*C2) * dv
        double de = 0.5 * (v1 * c1 + v2 * c2) * dv;
        res.e_oss += de;
    }

    double v_max = pts[count - 1].v;
    if (v_max > 0.0) {
        res.c_o_tr = res.q_oss / v_max;
        res.c_o_er = (2.0 * res.e_oss) / (v_max * v_max);
    }
    return res;
}
```

```cpp
#include <iostream>
#include <vector>
#include <span>
#include <numeric>

struct CossPoint {
    double v;    // напруга сток-витік, В
    double coss; // вихідна ємність, Фарад
};

struct CossResult {
    double q_oss{0.0};   // повний заряд, Кулони
    double e_oss{0.0};   // накопичена енергія, Джоулі
    double c_o_tr{0.0};  // часова еквівалентна ємність, Фаради
    double c_o_er{0.0};  // енергетична еквівалентна ємність, Фаради
};

constexpr CossResult integrate_coss(std::span<const CossPoint> pts) noexcept {
    if (pts.size() < 2) return {};

    double q_total = 0.0;
    double e_total = 0.0;

    for (size_t i = 0; i < pts.size() - 1; ++i) {
        const double v1 = pts[i].v;
        const double v2 = pts[i+1].v;
        const double c1 = pts[i].coss;
        const double c2 = pts[i+1].coss;
        const double dv = v2 - v1;

        if (dv <= 0.0) continue;

        q_total += 0.5 * (c1 + c2) * dv;
        e_total += 0.5 * (v1 * c1 + v2 * c2) * dv;
    }

    const double v_max = pts.back().v;
    if (v_max <= 0.0) return {};

    return CossResult{
        .q_oss = q_total,
        .e_oss = e_total,
        .c_o_tr = q_total / v_max,
        .c_o_er = (2.0 * e_total) / (v_max * v_max)
    };
}
```
