# 🧮 Кінетика термічного окиснення: модель Діла-Гроува

Термічне вирощування діоксиду кремнію (SiO₂) на поверхні монокристалічної пластини є базовою операцією планарного процесу, що забезпечує захист p-n переходів та формування маски для локального легування. Щоб точно контролювати товщину діелектричного шару за заданої температури та складу газового середовища, необхідно знати математичну залежність швидкості росту плівки від часу. Цю закономірність описує модель Діла-Гроува (*Deal-Grove model*), сформульована Брюсом Ділом та Ендрю Гроувом у 1965 році для високотемпературного окиснення кремнію в сухому кисні (O₂) та водяній парі (H₂O).

Модель встановлює фізичний зв'язок між двома процесами: дифузійним транспортом молекул окисника крізь уже вирощений твердий шар оксиду та хімічною реакцією окиснення на внутрішній межі поділу кремній–діоксид кремнію (Si–SiO₂).

---

## Фізична постановка та стаціонарні потоки окисника

Розглянемо кремнієву пластину, вкриту шаром діоксиду кремнію товщиною `x_ox`. Окиснення відбувається в печі за температури 900–1200 °C при атмосферному тиску газу-окисника. Щоб атом кремнію вступив у реакцію, молекула окисника має пройти три послідовні етапи:

1. Перенесення з основного об'єму газової фази до зовнішньої поверхні оксиду.
2. Дифузія крізь товщу вже сформованого твердого шару SiO₂ до фронту реакції.
3. Хімічна реакція взаємодії окисника з кремнієм на межі поділу Si–SiO₂.

За стаціонарного режиму (*steady-state condition*) густини потоків часток на кожному з цих трьох етапів мають бути суворо однаковими, інакше в приповерхневих шарах накопичувалася б або спадала маса окисника.

```
       Газова фаза          │     Шар оксиду SiO₂     │  Підкладка Si
                            │                         │
      Концентрація: C_g     │    C_0             C_i  │
     ───────────────────────┼─────────────────────────┼───────────────
      Потік F₁ (газ → оксид)│   Потік F₂ (дифузія)    │  Потік F₃ (реакція)
                            │   крізь товщину x_ox    │  на межі Si-SiO₂
                            │                         │
     x = -∞                 x = 0                     x = x_ox
```

### 1. Потік із газової фази до поверхні (F₁)

Перенесення молекул окисника з об'єму газу до зовнішньої межі оксиду лімітується газодинамічним прикордонним шаром:

```
F₁ = h_g · (C_g - C_s)
```

де `C_g` — об'ємна концентрація окисника в газовій фазі (см⁻³), `C_s` — концентрація окисника безпосередньо біля зовнішньої поверхні оксиду в газі, а `h_g` — коефіцієнт масоперенесення в газовій фазі (см/с).

Згідно із законом Генрі, рівноважна концентрація розчиненого газу в приповерхневому шарі твердого тіла `C*` пропорційна його парціальному тиску в газовій фазі. Позначимо через `C_0` фактичну концентрацію окисника у твердому SiO₂ на зовнішній поверхні `x = 0`. Тоді потік переписується через константу розчинності за Генрі `H`:

```
F₁ = h · (C* - C_0)
```

де `h` — приведення коефіцієнта газового масоперенесення до концентрацій у твердому тілі (`h = h_g / (H · k_B · T)`).

### 2. Дифузійний потік крізь шар оксиду (F₂)

Рух молекул розчиненого кисню або води крізь аморфну сітку діоксиду кремнію підпорядковується першому закону Фіка:

```
F = -D_eff · (dC / dx)
```

Оскільки в тонкій плівці за стаціонарного стану градієнт концентрації лінійний, потік від зовнішньої межі (`x = 0`, концентрація `C_0`) до внутрішньої межі (`x = x_ox`, концентрація `C_i`) дорівнює:

```
F₂ = D_eff · (C_0 - C_i) / x_ox
```

де `D_eff` — ефективний коефіцієнт дифузії молекул окисника в діоксиді кремнію (см²/с), а `C_i` — концентрація незв'язаного окисника на фронті реакції `x = x_ox`.

### 3. Потік хімічної реакції на межі Si–SiO₂ (F₃)

Швидкість хімічної реакції окиснення кремнію пропорційна концентрації окисника, що дійшов до кристалічної ґратки кремнію:

```
F₃ = k_s · C_i
```

де `k_s` — константа швидкості хімічної реакції на поверхні кремнію (см/с).

## Виведення квазістаціонарного розподілу концентрацій

Прирівнюючи всі три стаціонарні потоки `F₁ = F₂ = F₃ = F`, отримуємо систему рівнянь:

```
h · (C* - C_0) = D_eff · (C_0 - C_i) / x_ox = k_s · C_i
```

Розв'яжемо цю систему відносно невідомих граничних концентрацій `C_0` та `C_i`. З першої та третьої рівностей виразимо `C_0`:

```
h · C* - h · C_0 = k_s · C_i
h · C_0 = h · C* - k_s · C_i
C_0 = C* - (k_s / h) · C_i
```

Підставимо отриманий вираз для `C_0` у рівність для дифузійного потоку `F₂ = F₃`:

```
D_eff · (C* - (k_s / h) · C_i - C_i) / x_ox = k_s · C_i
D_eff · [C* - C_i · (1 + k_s / h)] = k_s · x_ox · C_i
D_eff · C* = C_i · [k_s · x_ox + D_eff · (1 + k_s / h)]
C_i = (D_eff · C*) / [D_eff · (1 + k_s / h) + k_s · x_ox]
```

Поділивши чисельник і знаменник на `D_eff`, дістаємо остаточний вираз для концентрації окисника на фронті реакції:

```
C_i = C* / (1 + k_s / h + k_s · x_ox / D_eff)
```

Звідси повний стаціонарний потік окисника до кремнієвої підкладки становить:

```
F = k_s · C_i
  = (k_s · C*) / (1 + k_s / h + k_s · x_ox / D_eff)   [підстановка C_i у вираз F₃]
```

## Диференціальне рівняння та лінійно-параболічний закон

Нехай `N_1` — кількість молекул окисника, необхідна для утворення одиниці об'єму діоксиду кремнію. Для сухого окиснення (`Si + O₂ → SiO₂`) кожна молекула кисню O₂ дає одну молекулу SiO₂, тому:

```
N_1(сухий O₂) = 2.2 · 10²² см⁻³
```

Для вологого окиснення (`Si + 2H₂O → SiO₂ + 2H₂`) на одну молекулу SiO₂ витрачається дві молекули води, отже:

```
N_1(пара H₂O) = 4.4 · 10²² см⁻³
```

Швидкість приросту товщини оксидної плівки `dx_ox / dt` пов'язана з потоком окисника простим балансом речовини:

```
N_1 · (dx_ox / dt) = F
dx_ox / dt = F / N_1
```

Підставивши виведений раніше потік `F`, маємо диференціальне рівняння росту:

```
dx_ox / dt = (k_s · C* / N_1) / (1 + k_s / h + k_s · x_ox / D_eff)
```

Розділимо змінні для інтегрування:

```
[1 + k_s / h + (k_s / D_eff) · x_ox] · dx_ox = (k_s · C* / N_1) · dt
```

Помножимо обидві частини рівняння на `2 · D_eff / k_s`:

```
[2 · D_eff · (1/k_s + 1/h) + 2 · x_ox] · dx_ox = (2 · D_eff · C* / N_1) · dt
```

Введемо стандартні позначення моделі Діла-Гроува:

```
A = 2 · D_eff · (1 / k_s + 1 / h)        [характеристична довжина, мкм]
B = 2 · D_eff · C* / N_1                 [параболічна константа швидкості, мкм²/год]
B / A = (C* / N_1) / (1 / k_s + 1 / h)   [лінійна константа швидкості, мкм/год]
```

Тоді диференціальне рівняння набуває компактного вигляду:

```
(A + 2 · x_ox) · dx_ox = B · dt
```

Проінтегруємо це рівняння з початковою умовою: у момент часу `t = 0` на поверхні кремнію вже може існувати початковий шар оксиду товщиною `x_ox(0) = x_i` (наприклад, нативний оксид товщиною 1.5–2 нм або оксид від попередніх технологічних кроків):

```
∫[x_i → x_ox] (A + 2 · x) dx = ∫[0 → t] B dt
(A · x_ox + x_ox²) - (A · x_i + x_i²) = B · t
x_ox² + A · x_ox = B · t + (x_i² + A · x_i)
```

Введемо часовий зсув `τ`, що відповідає уявному часу, необхідному для вирощування початкового шару `x_i`:

```
τ = (x_i² + A · x_i) / B
```

У результаті одержуємо класичний **лінійно-параболічний закон Діла-Гроува**:

```
x_ox² + A · x_ox = B · (t + τ)
```

Розв'яжемо це квадратне рівняння відносно товщини оксиду `x_ox`:

```
x_ox² + A · x_ox - B · (t + τ) = 0
x_ox(t) = (-A + √(A² + 4 · B · (t + τ))) / 2
        = (A / 2) · [√(1 + 4 · B · (t + τ) / A²) - 1]
```

## Граничні асимптотичні режими

Поведінка розв'язку визначається співвідношенням між поточною товщиною плівки `x_ox` та характеристичною константою `A / 2`.

```
                    Товщина оксиду x_ox (мкм)
                         ▲
                         │                                Параболічний режим:
                         │                                x_ox ≈ √(B · t)
                         │                                (лімітує дифузія)
                         │                           . ─ ─
                         │                     . ─ ╯
                         │               . ─ ╯
                         │         . ─ ╯
                         │   . ─ ╯  Лінійний режим: x_ox ≈ (B/A) · (t + τ)
                         │ ╯        (лімітує поверхнева реакція)
                         └────────────────────────────────────────► Час t (год)
```

### 1. Лінійний режим (тонкі плівки, малий час)

Коли шар оксиду ще дуже тонкий (`x_ox ≪ A / 2`, або `t + τ ≪ A² / (4 · B)`), дифузійний опір плівки знехтовно малий. Молекули окисника миттєво пролітають крізь тонкий оксид, і швидкість процесу лімітується виключно швидкістю хімічного розриву зв'язків Si–Si на межі кристала.

Розкладаючи квадратний корінь у ряд Тейлора `√(1 + u) ≈ 1 + u/2` для малого `u = 4 · B · (t + τ) / A²`:

```
x_ox(t) ≈ (A / 2) · [1 + 2 · B · (t + τ) / A² - 1]
        = (B / A) · (t + τ)                      [лінійна залежність товщини від часу]
```

У лінійному режимі товщина росте прямо пропорційно часу з константою швидкості `B/A`. Цей режим домінує при вирощуванні тонких підзатворних оксидів або на початкових хвилинах процесу.

### 2. Параболічний режим (товсті плівки, тривалий час)

Коли шар оксиду стає товстим (`x_ox ≫ A / 2`, або `t ≫ A² / (4 · B)`), дифузійний опір товщі SiO₂ починає на порядки перевищувати швидкість поверхневої реакції. Окисник витрачає майже весь час на продирання крізь аморфну сітку скла.

Знехтувавши лінійним членом `A · x_ox` у рівнянні Діла-Гроува:

```
x_ox² ≈ B · t
x_ox(t) ≈ √(B · t)                               [параболічна залежність товщини від часу]
```

У параболічному режимі кожне наступне подвоєння товщини оксиду вимагає вчетверо більшого часу. Швидкість росту контролюється коефіцієнтом дифузії `D_eff` і параболічною константою `B`.

## Порівняння сухого та вологого окиснення

Головна відмінність між окисненням у сухому кисні (`O₂`) та водяній парі (`H₂O`) полягає в розчинності та швидкості дифузії цих молекул у кварцовому склі SiO₂:

```
Властивість окисника             │ Сухий кисень (O₂)      │ Водяна пара (H₂O)
─────────────────────────────────┼────────────────────────┼───────────────────────────
Рівноважна розчинність C*        │ ~5.6 · 10¹⁶ см⁻³       │ ~3.0 · 10¹⁹ см⁻³  (в 500× вища!)
Ефективна дифузія D_eff (1000°C) │ ~3.4 · 10⁻⁹ см²/с      │ ~1.6 · 10⁻⁹ см²/с (у 2× нижча)
Добуток D_eff · C*               │ 1.9 · 10⁸ см⁻¹·с⁻¹     │ 4.8 · 10¹⁰ см⁻¹·с⁻¹ (в ~250× більший!)
Параболічна константа B (1000°C) │ 0.0117 мкм²/год        │ 0.287 мкм²/год    (в 25× швидша)
Лінійна константа B/A (1000°C)   │ 0.071 мкм/год          │ 1.27 мкм/год      (в 18× швидша)
Електрична якість діелектрика    │ Висока (мало дефектів) │ Помірна (вміст груп Si-OH)
Типове призначення               │ Тонкі оксиди, затвори  │ Товсті маски, польовий оксид
```

Величезна розчинність молекул води в сітці кварцу пояснюється хімічною взаємодією: вода утворює з оксидом силанольні групи `Si-OH`, що багаторазово підвищує концентрацію рухливого кисню у плівці. Через це вологе окиснення протікає в десятки разів швидше за сухе, що робить його незамінним для вирощування товстих маскувальних шарів (300–800 нм) без надмірного виснаження термобюджету пластини.

## Кристалографічна орієнтація: залежність констант від площини (111) проти (100)

Швидкість окиснення помітно різниться для пластин із різною кристалографічною орієнтацією поверхні монокристала кремнію. Оскільки параболічна константа `B` визначається дифузією кисню крізь аморфний ізотропний шар діоксиду кремнію, вона майже не залежить від орієнтації підкладки. Натомість лінійна константа швидкості `B/A` прямо пропорційна швидкості хімічної реакції `k_s` на фронті розриву кристалічної ґратки.

Швидкість реакції на межі залежить від поверхневої густини вільних валентних зв'язків атомів кремнію:

* **Площина (111):** поверхнева густина атомів кремнію становить `1.18 · 10¹⁵ см⁻²`, кожен атом має один доступний валентний зв'язок, спрямований перпендикулярно до поверхні.
* **Площина (100):** поверхнева густина атомів становить `6.78 · 10¹⁴ см⁻²`, кожен атом має два валентні зв'язки під кутом до поверхні (ефективна густина зв'язків `1.36 · 10¹⁵ см⁻²`).

Через більшу доступність зв'язків на площині (111) лінійна константа швидкості `B/A` для неї в `1.68` раза вища, ніж для площини (100) за однакової температури. Наприклад, у сухому кисні при 1000 °C:
* `(B/A)[111] ≈ 0.119 мкм/год`
* `(B/A)[100] ≈ 0.071 мкм/год`

Тому в ранній біполярній технології, де першочерговим завданням було швидке вирощування товстих ізоляційних шарів, широко використовували пластини орієнтації (111). Сучасна ж КМОН-мікроелектроніка стандартизована на орієнтації (100), оскільки на ній утворюється в 3–5 разів нижча густина поверхневих електричних пасток і фіксованого заряду на межі поділу з оксидом.

## Аномалія тонких оксидів у сухому кисні (режим менше 30 нм)

Класична модель Діла-Гроува демонструє високу точність для вологого окиснення в усьому діапазоні товщин та для сухого окиснення за товщин `x_ox > 30 нм`. Проте для ультратонких плівок у сухому кисні експериментальна швидкість росту в перші 20–30 нм виявляється в кілька разів вищою, ніж передбачає лінійно-параболічна формула.

Цей ефект, відкритий самими Ділом і Гроувом, зумовлений трьома супутніми фізичними механізмами:

1. **Ефект внутрішнього електричного поля (модель Кабрери-Мотта):** молекули кисню на поверхні оксиду захоплюють електрони, що тунелюють із кремнієвої підкладки крізь тонкий шар SiO₂ (< 5 нм). Виникає колосальне поперечне електричне поле (~10⁶ В/см), яке прискорює дрейф негативно заряджених іонів кисню (O₂⁻, O⁻) крізь діелектрик до кремнію.
2. **Підвищена розчинність кисню в напруженому приповерхневому шарі:** перші атомні шари SiO₂ стиснуті через невідповідність параметрів ґратки кремнію та аморфного скла, що локально змінює коефіцієнт дифузії.
3. **Генерація точкових дефектів:** на початковому етапі реакції в об'єм кремнію інжектується велика кількість власних міжвузлових атомів Si, що тимчасово знижує бар'єр активації хімічної взаємодії.

Щоб математично врахувати це прискорення для надтонких підзатворних оксидів, до рівняння швидкості додають додатковий експоненційний член:

```
dx_ox / dt = (B / (2 · x_ox + A)) + C_fast · exp(-x_ox / L_fast)
```

де `C_fast` — початкова надлишкова швидкість росту, а `L_fast ≈ 7 нм` — характеристична довжина затухання швидкого початкового режиму.

## Вплив концентрації домішок (ефект легування підкладки)

Швидкість росту оксиду суттєво зростає, коли кремній сильно легований донорними або акцепторними домішками (концентрація `N_d, N_a > 10¹⁹ см⁻³`):

* **Сильне легування фосфором чи миш'яком (n⁺-області емітера):** лінійна константа `B/A` зростає в 2–5 разів. При високих концентраціях донорів рівень Фермі зміщується до зони провідності, що збільшує рівноважну концентрацію заряджених вакансій кремнію (V⁻, V²⁻) у приповерхневому шарі. Вакансії полегшують розрив кристалічної ґратки, прискорюючи хімічну реакцію `k_s`.
* **Перерозподіл домішки (сегрегація):** під час окиснення фосфор виштовхується фронтом росту назад у кремній (коефіцієнт сегрегації `m > 1`), утворюючи високолегований пік на самій межі Si–SiO₂ (*pile-up effect*), що додатково стимулює реакцію.
* **Бор (p⁺-області):** на відміну від фосфору, бор охоче розчиняється в оксиді (`m < 1`) і вбудовується в сітку SiO₂, розпушуючи структуру скла. Це підвищує ефективний коефіцієнт дифузії `D_eff` і збільшує параболічну константу `B`.

Через це під час виготовлення транзистора оксид над сильно легованими емітерними та базовими областями росте швидше, ніж над слаболегованим колектором, утворюючи характерні сходинки на поверхні кристала.

## Окиснення під високим тиском (HIPOX)

Рівноважна концентрація розчиненого окисника `C*` за законом Генрі прямо пропорційна тиску газу в реакторі `P`:

```
C* = H · P
```

Оскільки параболічна константа `B` прямо пропорційна `C*`, а лінійна константа `B/A` також пропорційна `C*`, підвищення робочого тиску газу від 1 до 10–25 атмосфер збільшує швидкість росту оксиду в 10–25 разів.

Ця технологія дістала назву **HIPOX** (*High Pressure Oxidation*). Вона дозволяє вирощувати товсті ізоляційні шари за температур 700–800 °C замість 1000–1100 °C за той самий час. Зниження температури на 200–300 °C майже повністю заморожує небажану паразитну дифузію домішок у раніше сформованих p-n переходах, що критично важливо для збереження мікронних і субмікронних профілів легування.

Константи швидкості `B` та `B/A` експоненційно залежать від абсолютної температури `T` (у Кельвінах) за законом Арреніуса:

```
B = B_0 · exp(-E_B / (k_B · T))
B / A = (B/A)_0 · exp(-E_lin / (k_B · T))
```

де `k_B ≈ 8.617 · 10⁻⁵ еВ/К` — стала Больцмана, а `E_B` та `E_lin` — енергії активації відповідних процесів.

* **Енергія активації дифузії `E_B`:** становить приблизно `1.24 еВ` як для сухого кисню, так і для водяної пари. Вона відповідає енергії протискування молекули окисника крізь міжатомні порожнини аморфної сітки тетраедрів SiO₄.
* **Енергія активації реакції `E_lin`:** становить близько `2.00 еВ` (для площини кремнію (111)) та `2.05 еВ` (для площини (100)). Ця величина близька до енергії розриву ковалентного зв'язку Si–Si у кристалічній ґратці кремнію (`1.83 еВ`), що підтверджує: на лінійному етапі швидкість лімітується розривом зв'язків кремнію для приєднання кисню.

## Розрахунковий приклад: маскувальний шар під дифузію бази

Потрібно виростити маскувальний шар діоксиду кремнію товщиною `x_ox = 0.5 мкм` (500 нм) на чистій кремнієвій пластині з орієнтацією (100) за температури 1000 °C. Початкова товщина нативного оксиду `x_i = 2 нм = 0.002 мкм`.

Розрахуємо необхідний час окиснення для двох варіантів: сухого кисню та вологої пари.

### 1. Варіант А: Сухе окиснення в O₂ при 1000 °C

Параметри моделі для сухого O₂ (100):
* `B = 0.0117 мкм²/год`
* `B/A = 0.071 мкм/год`
* `A = B / (B/A) = 0.0117 / 0.071 ≈ 0.1648 мкм`

Обчислимо початковий зсув у часі `τ`:

```
τ = (x_i² + A · x_i) / B
  = (0.002² + 0.1648 · 0.002) / 0.0117   [підстановка початкової товщини x_i = 2 нм]
  = (0.000004 + 0.0003296) / 0.0117      [обчислення чисельника]
  ≈ 0.0285 год                            [ділення на параболічну константу B (1.7 хвилини)]
```

Обчислимо повний час окиснення `t`:

```
t = (x_ox² + A · x_ox) / B - τ
  = (0.5² + 0.1648 · 0.5) / 0.0117 - 0.0285   [підстановка цільової товщини x_ox = 0.5 мкм]
  = (0.25 + 0.0824) / 0.0117 - 0.0285         [піднесення до квадрата та множення]
  = 0.3324 / 0.0117 - 0.0285                  [додавання членів у чисельнику]
  = 28.410 - 0.0285                           [ділення на константу росту B]
  ≈ 28.38 год                                 [віднімання початкового зсуву τ (28 год 23 хв)]
```

### 2. Варіант Б: Вологе окиснення в H₂O при 1000 °C

Параметри моделі для водяної пари H₂O (100):
* `B = 0.287 мкм²/год`
* `B/A = 1.27 мкм/год`
* `A = B / (B/A) = 0.287 / 1.27 ≈ 0.2260 мкм`

Обчислимо початковий зсув у часі `τ`:

```
τ = (x_i² + A · x_i) / B
  = (0.002² + 0.2260 · 0.002) / 0.287   [підстановка початкової товщини x_i = 2 нм]
  = (0.000004 + 0.000452) / 0.287       [обчислення чисельника]
  ≈ 0.0016 год                          [ділення на B для вологого середовища (< 6 с)]
```

Обчислимо повний час окиснення `t`:

```
t = (x_ox² + A · x_ox) / B - τ
  = (0.5² + 0.2260 · 0.5) / 0.287 - 0.0016   [підстановка цільової товщини x_ox = 0.5 мкм]
  = (0.25 + 0.1130) / 0.287 - 0.0016         [обчислення доданків чисельника]
  = 0.3630 / 0.287 - 0.0016                  [додавання в чисельнику]
  = 1.2648 - 0.0016                          [ділення на константу вологого росту B]
  ≈ 1.263 год                                [віднімання зсуву τ (1 година 16 хвилин)]
```

### Висновок із розрахунку

Вирощування маски 500 нм у сухому кисні потребує понад 28 годин безперервного прожарювання за 1000 °C. За такий час усі раніше сформовані p-n переходи розпливлися б унаслідок небажаної термічної дифузії, зруйнувавши геометрію приладу. Вологе окиснення вирішує ту саму задачу всього за 76 хвилин, зменшуючи теплове навантаження на пластину більш ніж у 22 рази.

Саме тому в планарній технології застосовують комбінований тристадійний цикл окиснення «сухий–вологий–сухий» (*dry–wet–dry cycle*):
1. **Короткий сухий етап (10–15 хв):** утворює тонкий, ідеально щільний та бездефектний початковий шар SiO₂ безпосередньо на поверхні кремнію.
2. **Основний вологий етап (45–80 хв):** швидко нарощує основну товщину діелектрика з високою продуктивністю.
3. **Фінальний сухий етап (15–20 хв):** «заліковує» водневі та гідроксильні пастки в оксиді, витісняючи залишки вологи та забезпечуючи високу міцність на пробій і низьку густину поверхневих станів.
