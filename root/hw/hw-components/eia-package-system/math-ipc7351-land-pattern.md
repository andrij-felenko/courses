# 🧮 Розрахунок контактних площадок за стандартом IPC-7351B

Стандарт IPC-7351B *(Generic Requirements for Surface Mount Design and Land Pattern Standard)* визначає математичний апарат розрахунку геометрії контактних площадок друкованих плат для SMD-компонентів. Метод замінює інтуїтивне креслення футпринтів строгим аналізом розмірних ланцюгів із використанням теорії ймовірностей та статистичного розкиду виробничих похибок. Розрахунок гарантує формування правильного меніска припою, стійкість до механічних вібрацій і мінімізацію дефектів автоматизованого паяння.

## Базові змінні та геометрія паяного шва

Для двовивідного чіп-компонента (резистор, конденсатор) контактний рисунок складається з двох однакових прямокутних мідних площадок. Їхнє взаємне положення та розміри визначаються трьома головними вимірами:

```
Z_max — максимальний габарит між зовнішніми краями двох площадок
G_min — мінімальний внутрішній зазор між площадками
X_max — максимальна ширина кожної площадки
```

З цих трьох базових величин виводяться монтажні розміри однієї площадки:

```
Y = (Z_max − G_min) / 2    [довжина контактної площадки]
C = (Z_max + G_min) / 2    [міжцентрова відстань між площадками]
```

Геометрія площадки формує три типи меніска (галтелі) рідкого припою навколо металізованого торця деталі:
1. **Зовнішній виступ (Toe, JT):** Додатковий запас міді зовні компонента, що формує передній меніск припою. Забезпечує візуальний контроль якості паяння та автоматичну оптичну інспекцію (AOI).
2. **Внутрішній виступ (Heel, JH):** Запас міді під компонентом і в бік внутрішнього зазору. Формує внутрішню галтель, яка сприймає зсувні напруження під час теплового розширення плати.
3. **Бічний виступ (Side, JS):** Запас міді з боків торця. Центрує чіп завдяки силам поверхневого натягу розплаву припою.

## Статистичне обґрунтування: чому RMS перемагає арифметичне додавання

У ранніх редакціях стандартів проектування розміри площадок розраховували за методом абсолютного найгіршого випадку *(Worst-Case Arithmetic Summation)*: усі допуски просто додавалися лінійно. Якщо деталь мала допуск довжини `±0.2` мм, плата виготовлялася з похибкою `±0.1` мм, а автомат зміщував деталь на `±0.075` мм, сумарний запас приймався рівним `0.2 + 0.1 + 0.075 = 0.375` мм у кожен бік.

Такий підхід призводив до штучного роздування площі контактних площадок на 35–40%. Надлишок рідкого припою створював надмірні сили поверхневого натягу, які зривали легкі чіпи з посадкового місця й викликали дефект підйому на торець — ефект «надгробка» *(tombstoning)*.

Стандарт IPC-7351B спирається на центральну граничну теорему теорії ймовірностей. Похибки виготовлення компонента, травлення міді на платі та механічного позиціонування сопла pick-and-place є незалежними випадковими величинами з нормальним розподілом Гауса (розподіл `3σ`).

Ймовірність того, що екстремально довгий компонент потрапить на екстремально витравлену плату за максимального відхилення маніпулятора, прямує до нуля. Тому сумарна похибка розраховується за методом середньоквадратичного додавання *(Root-Mean-Square, RMS)*:

```
C_tol = √(S_comp² + F_pcb² + P_place²)
```

де:
- `S_comp` — статистичний розкид геометричного розміру компонента за даташитом;
- `F_pcb` — технологічний допуск виготовлення провідників на друкованій платі (стандартно `F = 0.10` мм для класу точності 4–5 або `F = 0.05` мм для прецизійного виробництва класу 6–7);
- `P_place` — похибка позиціонування автоматичного укладача компонентів (приймається `P = 0.075` мм для стандартного автомата або `P = 0.05` мм для високоточного монтажу).

Використання формули RMS дозволяє зменшити розмір площадки без жодного ризику виходу галтелі за межі нормативних вимог стандарту.

## Повна система розрахункових рівнянь IPC-7351B

Математична модель IPC-7351B визначає три ключові координати посадкового місця:

```
Z_max = L_min + 2 · J_T + √(S_L² + F² + P²)
G_min = S_min − 2 · J_H − √(S_S² + F² + P²)
X_max = W_min + 2 · J_S + √(S_W² + F² + P²)
```

де змінні визначаються з геометричних характеристик чіпа за даташитом:

- `L_min`, `L_max` — мінімальна та максимальна загальна довжина чіпа (`L_min = L_nom − L_tol`, `L_max = L_nom + L_tol`);
- `W_min`, `W_max` — мінімальна та максимальна ширина чіпа (`W_min = W_nom − W_tol`, `W_max = W_nom + W_tol`);
- `T_min`, `T_max` — мінімальна та максимальна ширина металізованого торця чіпа;
- `S_min` — мінімальна відстань між внутрішніми краями металізованих торців деталі:
  ```
  S_min = L_min − 2 · T_max
  ```
- `S_L` — діапазон допуску на довжину деталі:
  ```
  S_L = L_max − L_min = 2 · L_tol
  ```
- `S_W` — діапазон допуску на ширину деталі:
  ```
  S_W = W_max − W_min = 2 · W_tol
  ```
- `S_S` — сумарний діапазон допуску на внутрішній зазор між металізаціями:
  ```
  S_S = √(S_L² + 4 · S_T²)
  ```
  де `S_T = T_max − T_min = 2 · T_tol`.

## Нормативні припуски для трьох рівнів щільності монтажу

Стандарт IPC-7351B визначає три набори цільових значень припусків галтелей залежно від умов експлуатації кінцевого виробу:

| Рівень щільності монтажу | Носок JT (мм) | П'ята JH (мм) | Бічний JS (мм) | Зона Courtyard CE (мм) |
| :--- | :--- | :--- | :--- | :--- |
| **Density Level A (Most)** — максимальна надійність, вібрації, ручне паяння | **+0.55** | **+0.10** | **+0.05** | **0.50** |
| **Density Level B (Nominal)** — промисловий стандарт масового SMT | **+0.35** | **+0.00** | **−0.05** | **0.25** |
| **Density Level C (Least)** — ультращільний монтаж у смартфонах | **+0.15** | **−0.05** | **−0.10** | **0.12** |

Фізичний зміст від'ємних значень `JH` та `JS` у класі Level C полягає в тому, що мідна площадка може закінчуватися дещо раніше, ніж фізичний габарит компонента. Капілярний ефект затягує припій під торець чіпа, забезпечуючи надійний контакт за суттєвої економії площі плати.

## Покроковий розрахунковий приклад для чіпа 0805 (2012M)

Розглянемо стандартний чіп-резистор типорозміру 0805 (Metric 2012M) із такими параметрами з даташита:

```
L_nom = 2.00 мм,  допуск L_tol = ±0.20 мм  → L_min = 1.80 мм, L_max = 2.20 мм
W_nom = 1.25 мм,  допуск W_tol = ±0.20 мм  → W_min = 1.05 мм, W_max = 1.45 мм
T_nom = 0.40 мм,  допуск T_tol = ±0.20 мм  → T_min = 0.20 мм, T_max = 0.60 мм
```

Параметри технологічного процесу монтажу:
```
F = 0.10 мм   (допуск фотолітографії та травлення PCB)
P = 0.075 мм  (допуск позиціонування автомата pick-and-place)
```

### Крок 1. Обчислення геометричних допусків деталі

Обчислюємо діапазони допусків:

```
S_L = L_max − L_min = 2.20 − 1.80 = 0.40 мм
S_W = W_max − W_min = 1.45 − 1.05 = 0.40 мм
S_T = T_max − T_min = 0.60 − 0.20 = 0.40 мм
```

Обчислюємо мінімальний зазор між металізаціями деталі:

```
S_min = L_min − 2 · T_max
= 1.80 − 2 · 0.60   [підстановка L_min та T_max]
= 1.80 − 1.20       [множення]
= 0.60 мм           [мінімальний просвіт між торцями чіпа]
```

Обчислюємо комбінований допуск на просвіт між торцями `S_S`:

```
S_S = √(S_L² + 4 · S_T²)
= √((0.40)² + 4 · (0.40)²)   [підстановка значень S_L та S_T]
= √(0.16 + 4 · 0.16)         [піднесення до квадрата]
= √(0.16 + 0.64)             [множення на 4]
= √(0.80)                    [додавання]
= 0.8944 мм                  [допуск на просвіт між торцями]
```

### Крок 2. Розрахунок середньоквадратичних похибок (RMS)

Розраховуємо сумарну похибку для довжини `C_L`, ширини `C_W` та просвіту `C_S`:

```
C_L = √(S_L² + F² + P²)
= √((0.40)² + (0.10)² + (0.075)²)   [підстановка S_L, F та P]
= √(0.1600 + 0.0100 + 0.0056)       [обчислення квадратів]
= √(0.1756)                         [сума квадратів]
= 0.4190 мм                         [RMS похибка по осі довжини]

C_W = √(S_W² + F² + P²)
= √((0.40)² + (0.10)² + (0.075)²)   [підстановка S_W, F та P]
= √(0.1756)                         [ідентичні допуски]
= 0.4190 мм                         [RMS похибка по осі ширини]

C_S = √(S_S² + F² + P²)
= √((0.8944)² + (0.10)² + (0.075)²) [підстановка S_S, F та P]
= √(0.8000 + 0.0100 + 0.0056)       [обчислення квадратів]
= √(0.8156)                         [сума квадратів]
= 0.9031 мм                         [RMS похибка внутрішнього просвіту]
```

### Крок 3. Розрахунок розмірів для трьох рівнів щільності

Виконаємо розрахунок розмірів площадок для кожного з трьох класів:

**1. Density Level B (Nominal SMT):**
Припуски: `J_T = +0.35` мм, `J_H = 0.00` мм, `J_S = −0.05` мм.

- Зовнішній габарит `Z_max`:
```
Z_max = L_min + 2 · J_T + C_L
= 1.80 + 2 · 0.35 + 0.4190   [підстановка L_min, J_T та C_L]
= 1.80 + 0.70 + 0.4190       [множення припуску Toe на 2]
= 2.9190 мм ≈ 2.92 мм        [максимальний зовнішній габарит]
```

- Внутрішній зазор `G_min`:
```
G_min = S_min − 2 · J_H − C_S
= 0.60 − 2 · 0.00 − 0.9031   [підстановка S_min, J_H та C_S]
= 0.60 − 0.9031              [віднімання похибки]
= −0.3031 мм                 [від'ємне математичне значення]
```
Оскільки математичний розрахунок дав від'ємне значення, стандарт встановлює обмеження за мінімальним технологічним зазором трафарету. Для запобігання перемичкам припою між виводами 0805 приймається `G_min = 0.90` мм.

- Ширина площадки `X_max`:
```
X_max = W_min + 2 · J_S + C_W
= 1.05 + 2 · (−0.05) + 0.4190   [підстановка W_min, J_S та C_W]
= 1.05 − 0.10 + 0.4190          [віднімання бічного припуску]
= 1.3690 мм ≈ 1.37 мм           [ширина контактної площадки]
```

- Розміри площадки `Y` та міжцентрова відстань `C`:
```
Y = (Z_max − G_min) / 2
= (2.92 − 0.90) / 2   [підстановка Z_max та скоригованого G_min]
= 2.02 / 2            [віднімання]
= 1.01 мм ≈ 1.00 мм   [довжина площадки]

C = (Z_max + G_min) / 2
= (2.92 + 0.90) / 2   [підстановка Z_max та G_min]
= 3.82 / 2            [додавання]
= 1.91 мм             [міжцентровий крок]
```

**2. Density Level A (Most — підвищена надійність):**
Припуски: `J_T = +0.55` мм, `J_H = +0.10` мм, `J_S = +0.05` мм.

```
Z_max = 1.80 + 2 · 0.55 + 0.4190 = 3.3190 мм ≈ 3.32 мм
G_min = max(0.60 − 2 · 0.10 − 0.9031, 0.80) = 0.80 мм
X_max = 1.05 + 2 · 0.05 + 0.4190 = 1.5690 мм ≈ 1.57 мм
Y = (3.32 − 0.80) / 2 = 1.26 мм ≈ 1.25 мм
C = (3.32 + 0.80) / 2 = 2.06 мм ≈ 2.05 мм
```

**3. Density Level C (Least — ультращільний монтаж):**
Припуски: `J_T = +0.15` мм, `J_H = −0.05` мм, `J_S = −0.10` мм.

```
Z_max = 1.80 + 2 · 0.15 + 0.4190 = 2.5190 мм ≈ 2.52 мм
G_min = max(0.60 − 2 · (−0.05) − 0.9031, 1.00) = 1.00 мм
X_max = 1.05 + 2 · (−0.10) + 0.4190 = 1.2690 мм ≈ 1.27 мм
Y = (2.52 − 1.00) / 2 = 0.76 мм ≈ 0.75 мм
C = (2.52 + 1.00) / 2 = 1.76 мм ≈ 1.75 мм
```

## Специфіка розрахунку ультрамініатюрних корпусів 0402 та 0201

Для ультрамініатюрних чіпів розмірні похибки стандартного виробництва `F = 0.10` мм і `P = 0.075` мм стають порівнянними з габаритами самого компонента. Для чіпа 0201 (0.6 × 0.3 мм) довжина становить лише 0.60 мм, а торець — 0.15 мм.

Якщо застосувати стандартні коефіцієнти `F = 0.10` та `P = 0.075`, RMS-похибка `C_L ≈ 0.25` мм складатиме понад 40% довжини всього чіпа. Це призводить до катастрофічного розмивання форми площадки.

Тому для корпусів 0402, 0201 та 01005 стандарт IPC-7351B вимагає переходу на прецизійні параметри технологічного процесу:
- Виробничий допуск плати `F` зменшується до `0.05` мм (клас 6–7 точності з прямим лазерним експонуванням LDI);
- Похибка встановлення `P` зменшується до `0.035` мм (автомати з оптичним центруванням по контуру деталі);
- Припуски `J_T` масштабуються: для 0402 `J_T(Nominal) = +0.20` мм, для 0201 `J_T(Nominal) = +0.10` мм.

Для корпусу 0201 (Metric 0603M: `L = 0.6 ± 0.03` мм, `W = 0.3 ± 0.03` мм, `T = 0.15 ± 0.05` мм) розрахунок у класі Level B дає:

```
S_L = 0.06 мм,  F = 0.05 мм,  P = 0.035 мм
C_L = √((0.06)² + (0.05)² + (0.035)²) = √(0.0036 + 0.0025 + 0.0012) = √(0.0073) ≈ 0.085 мм

Z_max = 0.57 + 2 · 0.10 + 0.085 = 0.855 мм ≈ 0.86 мм
G_min = 0.40 − 2 · 0.00 − 0.12 = 0.28 мм
X_max = 0.27 + 2 · (−0.02) + 0.085 = 0.315 мм ≈ 0.32 мм
Y = (0.86 − 0.28) / 2 = 0.29 мм
C = (0.86 + 0.28) / 2 = 0.57 мм
```

Контактні майданчики мікрочіпа 0201 мають мініатюрний розмір `0.32 × 0.29` мм при внутрішньому зазорі `0.28` мм, що вимагає нанесення паяльної пасти з ультрадрібним зерном Type 5 (10–25 мкм) крізь трафарет товщиною не більше 80 мкм.

## Високовольтні обмеження: зазори пробою та шляхи витоку (Clearance & Creepage)

У високовольтних схемах (імпульсні джерела живлення, лічильники електроенергії, сонячні інвертори) внутрішній зазор між площадками `G_min` розраховується не лише за геометрією чіпа, але й за вимогами стандарту електричної ізоляції IEC 60664-1.

Мінімальний повітряний проміжний зазор *(Clearance)* та довжина шляху поверхневого витоку *(Creepage)* залежать від максимальної пікової напруги `U_peak`, ступеня забруднення поверхні *(Pollution Degree 2)* та порівняльного індексу трекінгостійкості діелектрика плати CTI:

```
U_peak = √2 · U_rms
```

Для мережевої напруги 230 В змінного струму `U_peak = 1.4142 · 230 ≈ 325` В. За стандартом IEC 60664-1 мінімальний шлях витоку по поверхні FR-4 (група матеріалу IIIa, CTI 175–400) становить `d_creepage ≥ 1.6` мм для базової ізоляції.

Якщо спробувати встановити резистор 0805 із зазором `G_min = 0.90` мм у високовольтний дільник мережі 230 В, зазор `0.90` мм виявиться вдвічі меншим за нормативні 1.6 мм. З часом осідання пилу та вологість створять мікродуговий поверхневий пробій, який спалить резистор.

Тому для високовольтних кіл обирають корпуси 1206 (`G_min ≈ 1.80` мм), 2010 (`G_min ≈ 3.40` мм) або 2512 (`G_min ≈ 4.80` мм). Якщо через брак місця доводиться використовувати корпус 1206 на граничних напругах, між контактними площадками виконують фрезерування ізоляційного паза *(isolation slot)* шириною 0.8–1.0 мм, що розриває поверхню діелектрика й перетворює шлях витоку на повітряний бар'єр.

## Маска під паяння: геометрія NSMD проти SMD площадок

Геометрія контактного майданчика на реальній платі залежить від способу обмеження площі змочування паяльною маскою *(Solder Mask)*. Стандарт розрізняє два типи формування падів:

1. **NSMD (Non-Solder Mask Defined):** Мідна площадка повністю відкрита, а вікно маски перевищує розмір міді на величину зазору маски `M_clearance` (типово 0.05–0.075 мм з кожного боку). Рідкий припій змочує не лише пласку поверхню міді, але й її вертикальні бічні стінки товщиною 35 мкм (1 oz фольга). Це створює додаткову силу капілярного утримання й збільшує міцність з'єднання на зсув на 20–30%. Для дискретних пасивних компонентів NSMD є обов'язковим промисловим стандартом.

2. **SMD (Solder Mask Defined):** Мідний полігон перевищує розмір вікна, а реальна площа паяння обмежується отвором у шарі паяльної маски. SMD-пади застосовують для ультрадрібних BGA-кульок з кроком менше 0.4 мм, але для двовивідних чіпів вони небажані: наплив маски створює сходинку висоти, яка під час оплавлення припою діє як важіль і сприяє перекиданню легких чіпів 0402 і 0201.

Для забезпечення надійної технологічної перемички паяльної маски *(Solder Mask Dam)* між двома площадками чіпа має виконуватися геометрична умова:

```
Dam_mask = G_min − 2 · M_clearance ≥ 0.075 мм
```

Для нашого розрахунку 0805 (`G_min = 0.90` мм, `M_clearance = 0.05` мм):

```
Dam_mask = 0.90 − 2 · 0.05 = 0.80 мм > 0.075 мм
```

Широка масочна перемичка 0.80 мм надійно ізолює протилежні контактні площадки одна від одної, повністю виключаючи утворення олов'яних перемичок *(solder bridging)* під корпусом.

## Фізика поверхневого натягу та модель моменту перекидання (Tombstoning)

Несиметричний розрахунок контактних площадок або нерівномірне нанесення пасти створює механічний обертальний момент, що призводить до підйому чіпа на торець *(tombstoning / Manhattan effect)*.

Рідкий припій створює силу поверхневого натягу вздовж змочуваного периметра контакту:

```
F_surface = γ · p · cos(θ)
```

де:
- `γ` — коефіцієнт поверхневого натягу рідкого припою (для безсвинцевого сплаву SAC305 `γ ≈ 0.45` Н/м);
- `p` — периметр змочування (`p = 2 · (W + h_term)`);
- `θ` — кут змочування меніска (у добре флюсованому розплаві `θ ≈ 15°–25°`).

Під час оплавлення припою в печі один торець чіпа (підключений до вузької доріжки) розплавляється на 0.5–1.0 секунди раніше, ніж інший (підключений до масивного полігона землі). На першому торці виникає результуючий обертальний момент відносно нижньої точки опори чіпа:

```
M_overturn = F_toe · h_term − F_heel · d_heel − m_chip · g · (L / 2)
```

де:
- `F_toe` — сила натягу зовнішнього меніска (Toe), що тягне верхній край чіпа вниз і провертає корпус вертикально;
- `F_heel` — сила натягу внутрішнього меніска (Heel), що протидіє перекиданню;
- `m_chip · g · (L / 2)` — відновлювальний гравітаційний момент ваги деталі.

Для мініатюрного чіпа 0402 маса становить лише `m ≈ 0.8` мг, а сила тяжіння `m · g ≈ 7.8 · 10⁻⁶` Н. Сила поверхневого натягу на торці завширшки 0.5 мм досягає `F_toe ≈ 0.45 · (0.5 · 10⁻³) ≈ 2.25 · 10⁻⁴` Н, що майже на два порядки перевищує гравітаційне утримання.

Якщо внутрішній зазор `G_min` розрахований занадто малим, або площадка занадто висунута назовні (надмірний `J_T`), плече сили `F_toe` перевищує плече `F_heel`. Результуючий момент стає додатним (`M_overturn > 0`), і чіп стає вертикально за кілька мілісекунд. Правильний розрахунок за IPC-7351B підтримує баланс сил `F_toe` та `F_heel`, блокуючи обертання.

## Теплове балансування доріжок (Thermal Relief)

Щоб уникнути часового зсуву розплавлення припою на двох площадках чіпа, швидкість теплового відтоку від обох контактів повинна бути строго збалансованою.

Тепловий опір мідного провідника, що з'єднує площадку з внутрішнім шаром або полігоном, описується законом:

```
R_th_trace = l_trace / (k_cu · w_trace · t_cu)
```

де:
- `l_trace` — довжина термобар'єрної шийки;
- `k_cu` — коефіцієнт теплопровідності міді (`385` Вт/(м·К));
- `w_trace` — ширина підвідної доріжки;
- `t_cu` — товщина шару фольги (`35` мкм для 1 oz).

Якщо один вивід резистора підключається до сигнальної доріжки шириною 0.2 мм, а другий вивід заливається суцільним мідним полігоном завширшки 5.0 мм, їхні теплові опори різнитимуться у 25 разів:

```
R_th_signal = 1.0 · 10⁻³ / (385 · (0.2 · 10⁻³) · (35 · 10⁻⁶)) ≈ 371 °C/Вт
R_th_plane = 1.0 · 10⁻³ / (385 · (5.0 · 10⁻³) · (35 · 10⁻⁶)) ≈ 14.8 °C/Вт
```

Площадка над полігоном прогріватиметься повільніше через величезний відтік тепла, що гарантує дефект tombstoning на першій площадці. Для усунення дисбалансу підключення до полігона виконують через хрестоподібні термобар'єри *(Thermal Relief Spokes)* із сумарною шириною спиць, рівною ширині сигнальної доріжки.

## Розрахунок вікна трафарету (Stencil Aperture)

Отримані розміри площадок `X_max` та `Y` визначають геометрію апертур у лазерному трафареті для нанесення паяльної пасти. Для якісного відокремлення пасти від стінок трафарету перевіряють два геометричні критерії (IPC-7525):

1. **Співвідношення сторін (Aspect Ratio):** Відношення ширини апертури `W_ap` до товщини трафарету `T_st` має перевищувати 1.5:
   ```
   Aspect_Ratio = W_ap / T_st ≥ 1.5
   ```
2. **Площинне співвідношення (Area Ratio):** Відношення площі основи апертури до площі її бічних стінок має перевищувати 0.66:
   ```
   Area_Ratio = (W_ap · L_ap) / (2 · (W_ap + L_ap) · T_st) ≥ 0.66
   ```

Для чіпа 0805 на стандартному трафареті товщиною `T_st = 0.12` мм (120 мкм) з апертурою `1.30 × 0.90` мм:

```
Area_Ratio = (1.30 · 0.90) / (2 · (1.30 + 0.90) · 0.12)
= 1.170 / (2 · 2.20 · 0.12)   [обчислення площі основи та периметра]
= 1.170 / 0.528               [множення знаменника]
= 2.216 > 0.66                [умова стандарту виконується з 3-кратним запасом]
```

## Розрахунок зони безпеки Courtyard Boundary

Зона безпеки *(Courtyard)* формує заборонений периметр навколо компонента та його контактних площадок. Вона враховує можливий зсув деталі під час оплавлення та забезпечує доступ монтажного сопла.

Формула розрахунку прямокутника Courtyard:

```
Courtyard_X = max(Z_max, L_max) + 2 · C_E
Courtyard_Y = max(X_max, W_max) + 2 · C_E
```

Для чіпа 0805 у трьох класах щільності:
- **Level A (`C_E = 0.50` мм):**
  `Courtyard_X = 3.32 + 2 · 0.50 = 4.32` мм; `Courtyard_Y = 1.57 + 2 · 0.50 = 2.57` мм;
- **Level B (`C_E = 0.25` мм):**
  `Courtyard_X = 2.92 + 2 · 0.25 = 3.42` мм; `Courtyard_Y = 1.45 + 2 · 0.25 = 1.95` мм;
- **Level C (`C_E = 0.12` мм):**
  `Courtyard_X = 2.52 + 2 · 0.12 = 2.76` мм; `Courtyard_Y = 1.45 + 2 · 0.12 = 1.69` мм.

Підсумкові розміри Courtyard вносяться до бібліотеки CAD як системні межі перевірки правил проектування (DRC).
