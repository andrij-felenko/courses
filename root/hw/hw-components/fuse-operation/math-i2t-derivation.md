# 🧮 Розрахунок теплового інтеграла плавлення I²t та інтегрування імпульсних струмів

Чому запобіжник спрацьовує від енергії короткого замикання швидше, ніж тепло встигає розійтися в навколишній простір: строго розбираємо диференціальне рівняння теплового балансу, виведення інтеграла Джоуля `I²t` з фізичних констант металу, математичну модель енергії електричної дуги, геометрію перфорованих перешийків, динаміку комутаційних перенапруг, імпульсну циклічну втому та точні формули інтегрування струмів різної форми.

Коли в електричному колі виникає аварійне коротке замикання, струм зростає на кілька порядків за лічені мікросекунди або мілісекунди. Захисна апаратура повинна розірвати коло до того, як розплавляться доріжки друкованої плати, займеться ізоляція з'єднувальних проводів або відбудеться незворотний тепловий пробій p-n переходів силових напівпровідників. Щоб математично описати цю швидкоплинну динаміку, інженери використовують апарат інтеграла Джоуля — теплового інтеграла `I²t`, який безпосередньо пов'язує протікаючий струм, геометрію провідника та його термодинамічні характеристики.

### Диференціальне рівняння нестаціонарного теплового балансу

Розглянемо калібрований металевий провідник (плавку ланку запобіжника) довжиною `L` з постійною площею поперечного перерізу `S`, густиною матеріалу `γ` (кг/м³) та питомим електричним опором `ρ` (Ом·м).

При протіканні змінного або імпульсного струму `i(t)` за нескінченно малий інтервал часу `dt` в об'ємі провідника виділяється елементарна кількість джоулевого тепла `dQ_gen`:

```
dQ_gen = i²(t) · R(T) · dt
```

де `R(T)` — активний електричний опір ланки за поточної температури `T`. Опір визначається геометричними розмірами та питомим опором металу:

```
R(T) = ρ(T) · L / S
```

Згенерована теплова енергія частково накопичується в тілі провідника, викликаючи підвищення його температури на величину `dT`, а частково відводиться в навколишнє середовище за рахунок теплопровідності через масивні металеві виводи, конвекції навколишнього газу та теплового випромінювання:

```
dQ_gen = dQ_stored + dQ_loss
```

Розпишемо фізичні складові теплового балансу:

```
dQ_stored = m · c_p(T) · dT = (γ · L · S) · c_p(T) · dT
```

де `m = γ · L · S` — маса плавкого елемента, а `c_p(T)` — питома масова ізобарна теплоємність матеріалу (Дж/(кг·K)).

Теплові втрати описуються узагальненим коефіцієнтом тепловіддачі `h_th` через площу бічної поверхні `A_surf` провідника:

```
dQ_loss = h_th · A_surf · (T - T_amb) · dt
```

де `T_amb` — температура навколишнього середовища. Об'єднавши вирази, отримуємо повне диференціальне рівняння нестаціонарного теплового балансу плавкої ланки:

```
i²(t) · (ρ(T) · L / S) · dt = γ · L · S · c_p(T) · dT + h_th · A_surf · (T - T_amb) · dt
```

### Стаціонарний режим проти адіабатичного нагрівання

Поведінка цього диференціального рівняння залежить від співвідношення між швидкістю генерації тепла та швидкістю його розсіювання.

У стаціонарному або тривалому квазістаціонарному режимі, коли крізь запобіжник протікає струм, близький до номінального (`I ≤ I_nom`), температура провідника стабілізується на постійному рівні (`dT/dt = 0`). Тоді вся генерована потужність безперервно скидається в навколишнє середовище:

```
I² · (ρ(T_стала) · L / S) = h_th · A_surf · (T_стала - T_amb)
```

Звідси визначається усталена температура ланки:

```
T_стала = T_amb + I² · [ρ(T_стала) · L] / [S · h_th · A_surf]
```

Для правильно спроєктованого запобіжника за номінального струму `T_стала` лежить значно нижче точки розм'якшення або початку окислення металу (зазвичай у межах 80–140 °C).

При аварійному короткому замиканні ситуація докорінно змінюється: струм `i(t)` підскакує в десятки або сотні разів. Час нагрівання провідника до точки плавлення `t_m` становить від кількох мілісекунд до десятків мікросекунд. Через скінченну швидкість поширення тепла в твердому тілі (обмежену теплопровідністю та температурною дифузією) тепловідвід `dQ_loss` за цей надкороткий проміжок часу виявляється мізерно малим порівняно з велетенською енергією тепловиділення `dQ_gen`:

```
dQ_loss / dQ_gen << 0.001   (для t < 10 мс)
```

Нехтуючи тепловідводом, ми переходимо до строго адіабатичної моделі нагрівання:

```
i²(t) · (ρ(T) · L / S) · dt = γ · L · S · c_p(T) · dT
```

Скоротивши довжину провідника `L` в обох частинах рівняння, перегрупуємо змінні так, щоб усі величини, що залежать від струму і часу, опинилися ліворуч, а всі матеріальні та геометричні константи й температурні змінні — праворуч:

```
i²(t) · dt = S² · [γ · c_p(T) / ρ(T)] · dT
```

Це фундаментальне рівняння адіабатичного нагріву. Проінтегруємо ліву частину за часом від моменту виникнення аварії `t = 0` до моменту початку фазового переходу плавлення `t = t_m`, а праву частину — за температурою від початкової температури провідника `T₀` до температури плавлення металу `T_m`:

```
∫₀^{t_m} i²(t) dt = S² · ∫_{T₀}^{T_m} [γ · c_p(T) / ρ(T)] dT
```

Ліва частина цієї рівності залежить виключно від профілю струму в електричному колі і називається **тепловим інтегралом плавлення** (Melting Integral, `I²t_melt`):

```
I²t_melt = ∫₀^{t_m} i²(t) dt
```

Права частина рівняння залежить виключно від площі перерізу провідника `S` та фізико-хімічних властивостей обраного металу. Цю матеріальну функцію температури позначають як інтеграл Мейєра (Meyer's Constant):

```
K_metal = ∫_{T₀}^{T_m} [γ · c_p(T) / ρ(T)] dT
```

Звідси отримуємо базове інженерне співвідношення для енергії розплавлення ланки:

```
I²t_melt = S² · K_metal
```

Ця формула формулює ключовий фізичний закон: струмова енергія, необхідна для розплавлення запобіжника в адіабатичному режимі, пропорційна **квадрату площі перерізу** плавкої вставки. Збільшення діаметра дроту вдвічі збільшує його площу перерізу в 4 рази, а енергію спрацьовування `I²t` — у 16 разів.

### Врахування лінійної температурної залежності питомого опору

У більшості чистих металів питомий опір у діапазоні від кімнатної температури до точки плавлення з високою точністю описується лінійною функцією:

```
ρ(T) = ρ₀ · [1 + α₀ · (T - T₀)]
```

де `ρ₀` — питомий опір за базової температури `T₀` (зазвичай 20 °C або 293.15 K), а `α₀` — температурний коефіцієнт опору (1/K).

Якщо вважати питому теплоємність `c_p` та густину `γ` усередненими сталими величинами в діапазоні твердої фази, інтеграл Мейєра набуває аналітичного вигляду:

```
K_metal = (γ · c_p / ρ₀) · ∫_{T₀}^{T_m} dT / [1 + α₀ · (T - T₀)]
```

Виконуємо заміну змінної `u = 1 + α₀ · (T - T₀)`, звідки `du = α₀ · dT`:

```
K_metal
= (γ · c_p / (ρ₀ · α₀)) · ∫₁^{1 + α₀·(T_m - T₀)} (1 / u) du   [заміна змінної]
= (γ · c_p / (ρ₀ · α₀)) · ln[1 + α₀ · (T_m - T₀)]            [табличний інтеграл логарифма]
```

Таким чином, повне значення інтеграла нагрівання до точки початку плавлення становить:

```
I²t_heat = S² · [γ · c_p / (ρ₀ · α₀)] · ln[1 + α₀ · (T_m - T₀)]
```

### Внесок прихованої теплоти фазового переходу

Коли метал досягає температури плавлення `T_m`, його температура залишається сталою доти, доки вся кристалічна ґратка не зруйнується, поглинувши приховану питому теплоту плавлення `λ_m` (Дж/кг).

Енергія, необхідна для повного переведення провідника з твердого стану в рідкий при сталій температурі `T_m`, описується рівнянням:

```
i²(t) · (ρ_liq · L / S) · dt = γ · L · S · λ_m
```

де `ρ_liq` — питомий опір металу в рідкому стані безпосередньо при температурі плавлення (як правило, стрибкоподібно зростає у 1.5–2.2 рази порівняно з опором твердого металу перед плавленням через втрату трансляційного порядку решітки).

Інтегруючи за часом фазового переходу від моменту початку плавлення `t_m` до моменту повного розплавлення всього об'єму `t_liq`:

```
I²t_phase = ∫_{t_m}^{t_liq} i²(t) dt = S² · [γ · λ_m / ρ_liq]
```

Повний інтеграл розплавлення твердої ланки `I²t_melt` є сумою енергії нагріву твердої фази та енергії фазового переходу:

```
I²t_melt = I²t_heat + I²t_phase
```

Підставивши виведені вирази:

```
I²t_melt = S² · { [γ · c_p / (ρ₀ · α₀)] · ln[1 + α₀ · (T_m - T₀)] + [γ · λ_m / ρ_liq] }
```

### Фізичні константи металів плавких елементів

Розрахуємо матеріальні параметри для найпоширеніших металів, що застосовуються у виробництві запобіжників:

```
Параметр               Срібло (Ag)    Мідь (Cu)    Алюміній (Al)    Цинк (Zn)    Олово (Sn)
───────────────────────────────────────────────────────────────────────────────────────────

c_p (Дж/(кг·K))         235            385          900              390          230
```

Срібло та мідь є беззаперечними лідерами за показником `K_metal` та електропровідністю: вони забезпечують мінімальне падіння напруги в штатному режимі та високу термічну стабільність контактів. Олово і цинк, навпаки, завдяки низькій температурі плавлення дозволяють створювати компактні низькотемпературні вставки та реалізовувати металургійний М-ефект (дифузійне руйнування срібної або мідної смужки при температурах близько 200 °C).

### Геометрія перфорованих перешийків силових стрічок

У силових швидкодіючих запобіжниках плавка ланка виготовляється не у вигляді суцільного круглого дроту, а у вигляді тонкої стрічки з штампованою перфорацією. Перфорація утворює кілька послідовних звужених ділянок — перешийків (notches) з мінімальною локальною площею перерізу `S_notch` та довжиною `L_notch`.

Густина струму в перешийку `J_notch = I / S_notch` у рази перевищує густину струму в ширших ділянках стрічки. Оскільки питоме тепловиділення пропорційне квадрату густини струму (`q = ρ · J²`), температура перешийка зростає в десятки разів швидше за решту стрічки.

Розплавлення відбувається локалізовано саме в перешийках. Якщо на стрічці виконано `N` однакових послідовних перешийків, у момент розплавлення одночасно запалюється `N` послідовних електричних дуг.

Кожна одинична дуга має спад напруги на катодному та анодному шарах плюс градієнт напруги в стовпі плазми:

```
v_arc_single(t) = V_electrode + E_arc · l_arc
```

де `V_electrode ≈ 20...30 В` — сумарне приелектродне падіння напруги, а `E_arc` — градієнт електричного поля в стисненому піском дуговому каналі (близько 50–150 В/см).

Завдяки послідовному з'єднанню `N` дуг сумарна напруга дуги запобіжника множиться на кількість перешийків:

```
v_arc_total(t) = N · v_arc_single(t)
```

Це дозволяє миттєво сформувати проти-ЕРС дуги, яка перевищує напругу живильної мережі навіть у високовольтних колах (1000–1500 В DC), змушуючи струм короткого замикання стрімко спадати до нуля за частки мілісекунди.

### Енергія горіння електричної дуги та повний інтеграл відключення

Після того як ланка поглинула `I²t_melt` і розплавилася, коло не розмикається миттєво. У місці розриву спалахує електрична дуга, температура якої досягає 5000–15000 K. Дуга є іонізованим стовпом плазми, що володіє динамічним нелінійним опором `R_arc(t)`.

Повний інтеграл відключення струму `I²t_total` (Total Clearing Integral) визначається як інтеграл за всіма двома інтервалами часу:

```
I²t_total = ∫₀^{t_clearing} i²(t) dt = ∫₀^{t_melt} i²(t) dt + ∫_{t_melt}^{t_clearing} i²(t) dt
I²t_total = I²t_melt + I²t_arc
```

Дуговий інтеграл `I²t_arc` безпосередньо залежить від робочої напруги кола `V_sys`, індуктивності контуру `L_loop` та швидкості тепловідведення в дугогасному середовищі (кварцовому піску).

Динаміка дугового розряду в піску описується рівнянням балансу напруг у контурі:

```
V_sys = L_loop · (di / dt) + R_loop · i(t) + v_arc(t)
```

Щоб струм почав спадати до нуля (`di/dt < 0`), напруга дуги `v_arc(t)` повинна перевищити напругу джерела живлення:

```
v_arc(t) > V_sys - R_loop · i(t)
```

Кварцовий пісок інтенсивно відбирає тепло з дугового стовпа за рахунок велетенської сумарної площі поверхні зерен. Охолодження плазми зменшує концентрацію вільних електронів, динамічний опір дуги стрімко зростає, напруга дуги `v_arc(t)` підскакує до сотень і тисяч вольтів, примусово заганяючи струм `i(t)` до нуля.

При цьому виникає комутаційна перенапруга, амплітуда якої визначається швидкістю спаду струму:

```
V_peak = V_sys + L_loop · |di / dt|_max
```

Це накладає строге інженерне обмеження: дугогасна здатність запобіжника не повинна бути надмірно агресивною, інакше комутаційний пік `V_peak` проб'є ізоляцію трансформатора або діелектрик сусідніх компонентів.

### Аналітичний розрахунок I²t для різних форм струмових імпульсів

У реальних електронних та силових колах форма струму під час перехідних процесів рідко є постійною величиною. Щоб перевірити, чи витримає запобіжник пусковий імпульс або як швидко він розімкне аварійне коло, обчислюють визначений інтеграл `∫ i²(t) dt` для конкретної форми хвилі.

#### 1. Прямокутний імпульс струму

Імпульс амплітудою `I_pk` та тривалістю `t_p`:

```
i(t) = I_pk   при   0 ≤ t ≤ t_p
```

Обчислення інтеграла:

```
I²t
= ∫₀^{t_p} (I_pk)² dt
= I_pk² · [t]₀^{t_p}
= I_pk² · t_p
```

#### 2. Трикутний симетричний або пилкоподібний імпульс

Імпульс з піковим значенням `I_pk` та повною тривалістю `t_p` (типова форма струму намагнічування дроселя імпульсного перетворювача при насиченні магнітопроводу):

Для лінійного наростання `i(t) = I_pk · (t / t_p)`:

```
I²t
= ∫₀^{t_p} [I_pk · (t / t_p)]² dt
= (I_pk² / t_p²) · ∫₀^{t_p} t² dt
= (I_pk² / t_p²) · [t³ / 3]₀^{t_p}
= (1/3) · I_pk² · t_p
```

Теплова дія трикутного імпульсу становить рівно 1/3 від дії прямокутного імпульсу тієї ж амплітуди і тривалості.

#### 3. Півсинусоїдний імпульс змінного струму

Половина періоду синусоїди мережевої напруги (50 або 60 Гц) з амплітудою `I_pk` та тривалістю `t_p = π / ω` (для 50 Гц `t_p = 10 мс`):

```
i(t) = I_pk · sin(ω · t)   при   0 ≤ t ≤ t_p
```

Обчислення через тригонометричну тотожність подвійного кута `sin²(x) = (1 - cos(2x)) / 2`:

```
I²t
= ∫₀^{t_p} I_pk² · sin²(ω · t) dt
= I_pk² · ∫₀^{t_p} [(1 - cos(2ω · t)) / 2] dt
= (I_pk² / 2) · [ t - sin(2ω · t) / (2ω) ]₀^{t_p}
= (1/2) · I_pk² · t_p   [оскільки sin(2ω · π/ω) = sin(2π) = 0]
```

Еквівалентний тепловий інтеграл півсинусоїди становить рівно половину добутку квадрата амплітуди на тривалість півперіоду.

#### 4. Експоненційний імпульс розряду або заряду конденсатора (RC-коло)

При заряджанні великої вхідної ємності фільтра `C` через сумарний опір лінії `R` струм падає за експоненційним законом зі сталою часу `τ = R · C`:

```
i(t) = I_pk · e^(-t / τ)
```

де `I_pk = V_in / R`. Обчислення інтеграла на інтервалі від 0 до нескінченності:

```
I²t
= ∫₀^∞ [I_pk · e^(-t / τ)]² dt
= I_pk² · ∫₀^∞ e^(-2t / τ) dt
= I_pk² · [ - (τ / 2) · e^(-2t / τ) ]₀^∞
= I_pk² · [ 0 - ( - τ / 2 · 1 ) ]
= (1/2) · I_pk² · τ
```

Підставивши вирази для пікового струму `I_pk = V_in / R` та сталої часу `τ = R · C`:

```
I²t = (1/2) · (V_in / R)² · (R · C) = (1/2) · V_in² · C / R
```

Цей результат надзвичайно важливий для схемотехніка: імпульс заряду конденсатора ємністю `C` під напругою `V_in` виділяє в запобіжнику теплову енергію, прямо пропорційну квадрату напруги та ємності й обернено пропорційну активному опору контуру.

### Циклічна імпульсна втома та коефіцієнт запасу (Pulse Derating)

Запобіжник не повинен перегорати від штатних пускових струмів під час кожного ввімкнення пристрою. Проте якщо енергія поодинокого пускового імпульсу наближається до `I²t_melt`, плавка ланка зазнає циклічних термомеханічних деформацій.

При кожному пуску метал розширюється, а під час охолодження стискається. У металі виникають мікроскопічні пластичні деформації, з'являються міжкристалітні мікротріщини, посилюється локальне поверхневе окислення. З часом переріз провідника в найтоншому місці деградує, опір зростає, і через кілька сотень або тисяч циклів ввімкнення запобіжник перегорає на штатному робочому струмі без жодної аварії в навантаженні.

Щоб запобігти цьому явищу, в інженерній практиці використовують емпіричний коефіцієнт циклічного дератингу імпульсного `I²t` (Pulse Factor, `k_pulse`):

```
I²t_pulse_allowed = k_pulse · I²t_melt
```

Значення коефіцієнта `k_pulse` залежить від запланованої кількості циклів ввімкнення за весь життєвий цикл виробу:

```
Кількість пускових циклів       Допустима частка I²t_pulse / I²t_melt (k_pulse)
────────────────────────────────────────────────────────────────────────────────
1 цикл (одноразове спрацювання) 1.00 (100 %)
10 циклів                       0.70 (70 %)
100 циклів                      0.50 (50 %)
1 000 циклів                    0.40 (40 %)
10 000 циклів                   0.29 (29 %)
100 000 циклів                  0.20 (20 %)
```

Таким чином, для побутової чи промислової електроніки з ресурсом понад 100 000 циклів комутації розрахунковий пусковий інтеграл `I²t_inrush` не повинен перевищувати 20% від номінального теплового інтеграла плавлення обраного запобіжника (`I²t_fuse ≥ 5 · I²t_inrush`).

### Покроковий приклад: розрахунок координації захисту трифазного випрямляча

**Умова задачі.**
Трифазний промисловий випрямляч живиться від мережі лінійною напругою `V_line = 400 В` (50 Гц). Робочий середньоквадратичний струм плеча тиристорного моста становить `I_RMS = 100 А`. Максимальний розрахунковий струм короткого замикання підстанції в точці підключення становить `I_sc = 10 кА`. Силові тиристори моста мають паспортну граничну стійкість до струму перевантаження `I²t_SCR = 24000 А²·с` (при `t = 10 мс`). Необхідно перевірити придатність надшвидкого запобіжника (тип aR) з паспортними даними:
- Номінальний струм: `I_nom = 125 А`
- Номінальна напруга: `690 В AC`
- Інтеграл плавлення: `I²t_melt = 3200 А²·с`
- Повний інтеграл відключення при 400 В: `I²t_total = 14500 А²·с`
- Гранична відключна здатність: `100 кА`

**Розрахунок та перевірка критеріїв.**

```
Крок 1. Перевірка тривалого робочого струму:
  I_nom = 125 А > I_RMS = 100 А
  Запас за струмом: 125 / 100 = 1.25 (25 % запасу)   ✓

Крок 2. Перевірка номінальної напруги:
  V_fuse = 690 В ≥ V_line = 400 В   ✓

Крок 3. Перевірка відключної здатності:
  I_break = 100 кА >> I_sc = 10 кА
  Запобіжник гарантовано розірве струм к.з. без вибуху корпусу   ✓

Крок 4. Перевірка селективності та координації з напівпровідником:
  Критерій захисту тиристора:
  I²t_total(fuse) < k_safety · I²t_SCR

  Приймаємо нормативний коефіцієнт безпеки k_safety = 0.8:
  I²t_limit = 0.8 · 24000 = 19200 А²·с

  Порівнюємо з повним інтегралом запобіжника:
  I²t_total(fuse) = 14500 А²·с < 19200 А²·с   ✓
```

**Висновок.** Обраний надшвидкий запобіжник надійно захищає тиристорний кристал: при короткому замиканні повна енергія, що виділиться в колі за час розплавлення ланки та горіння дуги (`14500 А²·с`), є на 40% меншою за критичну руйнівну енергію тиристора (`24000 А²·с`). Тиристор залишиться повністю працездатним після заміни перегорілого запобіжника.
