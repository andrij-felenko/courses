# 🔌 Конструктивні тонкощі та схемотехнічні пастки суперперехідних MOSFET

Суперперехідний польовий транзистор (Superjunction MOSFET, широко відомий за торговими марками CoolMOS, MDmesh, SuperFET) радикально перевершує класичний планарний MOSFET за статичним опором відкритого каналу `R_DS(on)`. Проте в інженерній практиці заміна планарного транзистора на суперперехідний в існуючій схемі часто призводить до несподіваних автоколивань, потужних електромагнітних завад, хибних спрацьовувань захисту або навіть миттєвого теплового пробою кристала.

Ці проблеми зумовлені специфічною внутрішньою будовою суперпереходу: гігантською внутрішньою площею p-n переходів, екстремальною нелінійністю міжелектродних ємностей та надвисокими швидкостями комутації струму й напруги.

## 1. Технологічна реалізація: Multi-Epi проти DRIE Trench-Fill

Щоб зрозуміти поведінку приладу в електричному колі, необхідно розглянути два основні способи формування вертикальних компенсованих стовпчиків у товщі кристала:

```
Multi-Epi процес (пошаровий):        DRIE Trench-Fill (траншейний):
┌───┐ ┌───┐ ┌───┐ ┌───┐              ┌───┬───┬───┬───┬───┬───┐
│ p │ │ n │ │ p │ │ n │  Шар 5       │ p │ n │ p │ n │ p │ n │
├───┤ ├───┤ ├───┤ ├───┤              │   │   │   │   │   │   │
│ p │ │ n │ │ p │ │ n │  Шар 4       │   │   │   │   │   │   │  Глибоке
├───┤ ├───┤ ├───┤ ├───┤              │   │   │   │   │   │   │  плазмове
│ p │ │ n │ │ p │ │ n │  Шар 3       │   │   │   │   │   │   │  травлення
├───┤ ├───┤ ├───┤ ├───┤              │   │   │   │   │   │   │  та заповнення
│ p │ │ n │ │ p │ │ n │  Шар 2       │   │   │   │   │   │   │  епітаксією
├───┤ ├───┤ ├───┤ ├───┤              │   │   │   │   │   │   │
│ p │ │ n │ │ p │ │ n │  Шар 1       │   │   │   │   │   │   │
└───┴───┴───┴───┴───┴───┘              └───┴───┴───┴───┴───┴───┘
```

1. **Багатокрокова епітаксія з імплантацією (Multi-Epi):**
   Кристал вирощують у 5–7 послідовних епітаксійних циклів. На кожному кроці через фотомаску імплантують іони бору, формуючи ланцюжок p-острівців, які після фінального високотемпературного дифузійного відпалу зливаються в стовпчики. Через бічну дифузію бору межі стовпчиків виходять хвилястими, що обмежує мінімальний крок комірки величиною 10–12 мкм.

2. **Глибоке реактивне іонне травлення (DRIE Trench-Fill):**
   У суцільному однорідному епітаксійному n-шарі плазмовим методом витравлюють вузькі вертикальні канавки глибиною 40–50 мкм із строго вертикальними стінками, які потім заповнюють p-легованим кремнієм методом газофазного осадження. Цей процес дозволяє стиснути крок комірки до 3–4 мкм, забезпечуючи рекордну провідність, але підвищує механічні напруження в кристалі.

## 2. Гіпернелінійність вихідної ємності Coss та накопичена енергія Eoss

Найбільш помітною схемотехнічною відмінністю суперперехідного MOSFET є поведінка його вихідної ємності `C_oss = C_ds + C_gd` як функції напруги стік-витік `V_DS`.

У класичному планарному MOSFET ємність p-n переходу плавно спадає за законом `C ∝ 1 / √(V_DS)`. Натомість у суперперехідному приладі характеристика `C_oss(V_DS)` має яскраво виражений двоступеневий характер:

- **При низьких напругах (`V_DS < 30...50 В`):** стовпчики ще не збіднені. Завдяки наявності десятків тисяч паралельних вертикальних p-n стовпчиків ефективна площа переходу в об'ємі кристала виявляється в 10–20 разів більшою за геометричну площу чипа. Вихідна ємність досягає гігантських значень — від 5 000 до 15 000 пФ для транзистора середньої потужності.
- **При напрузі бічного збіднення (`V_DS ≈ 40...50 В`):** сусідні p- та n-стовпчики повністю збіднюються в поперечному напрямку. Провідні канали зникають, і діелектриком конденсатора раптово стає вся товща збідненого кремнієвого шару.
- **При високих напругах (`V_DS > 50 В`):** вихідна ємність стрибкоподібно обвалюється у 1000 разів — до величини лише 10–30 пФ.

### Схемотехнічні наслідки нелінійності Coss

Така гіпернелінійність має двоякий наслідок:

1. **Енергія вихідної ємності `E_oss`:**
   Енергія, накопичена у вихідній ємності, обчислюється інтегралом `E_oss = ∫₀^(V_bus) v · C_oss(v) dv`. Оскільки левова частка ємності зосереджена в області низьких напруг (де напруга `v` у підінтегральному виразі мала), повна енергія `E_oss` у суперперехідного MOSFET виявляється у 2–3 рази меншою, ніж у планарного приладу з аналогічним опором `R_DS(on)`. У резонансних перетворювачах (LLC, ZVS) це дозволяє скоротити час паузи (dead-time) та суттєво підвищити ККД.

2. **Екстремальне наростання напруги `dv/dt`:**
   Коли під час вимикання напруга `V_DS` перетинає поріг 40–50 В, струм розриву індуктивності миттєво перезаряджає крихітну залишкову ємність (кілька пікофарадів). Швидкість наростання напруги `dv/dt` різко підскакує від помірних 5–10 В/нс до екстремальних **50–120 В/нс**. Це породжує високі синфазні завади (EMI) та створює небезпеку пробою ізоляції сусідніх компонентів.

## 3. Проблема зворотного відновлення боді-діода (Qrr, trr)

Кожен силовий MOSFET містить паразитний вбудований діод *(body diode)*, утворений p-body областю та n-дрейфовим шаром. У суперперехідній структурі анодом цього діода слугують усі численні p-стовпчики, а катодом — n-стовпчики.

Коли через внутрішній діод протікає прямий струм (наприклад, у фазі вільного ходу індуктивного струму в мостових схемах або інверторах), у всьому об'ємі дрейфової зони накопичується величезний заряд неосновних носіїв (дірок).

Коли протилежний транзистор стійки моста вмикається, до закритого діода прикладається зворотна напруга, викликаючи процес **жорсткого зворотного відновлення** *(Hard Reverse Recovery)*:

```
Струм діода I_D
   ▲
   │        Прямий струм
───┼─────────────────────────────────────────────► Час t
   │                 \
   │                  \       t_rr
   │                   \   ┌─────────┐
   │                    \  │         │
   │                     ──┴─────────┼───
   │                    /  Заряд Q_rr│
   │                   /             │
   │                  ▼              ▼
   │              Піковий струм    Хвиля dv/dt
   │              відновлення I_RRM
```

1. **Великий заряд відновлення `Q_rr`:** час розсмоктування дірок `t_rr` становить 200–500 нс, а зворотний піковий струм `I_RRM` може перевищувати номінальний робочий струм транзистора у 2–4 рази. Це створює величезні динамічні втрати ввімкнення `P_sw` у спареному ключі.
2. **Небезпека лавинного самовмикання (Latch-up паразитного BJT):**
   Всередині кожної комірки MOSFET існує паразитна біполярна n-p-n структура (витік n⁺ — тіло p-body — дрейф n). Під час швидкого розсмоктування заряду дірки стікають до виводу витоку через тонкий підканальний p-body шар. Якщо спад напруги на опорі цього шару `R_p-body · I_hole` перевищить поріг відмикання кремнієвого переходу `0.7 В`, паразитний біполярний транзистор лавиноподібно відкриється. Транзистор втрачає керованість затвором і миттєво згорає від локального перегріву.

### Модифікації Fast Body Diode (серії CFD / FRD)

Для роботи в мостових топологіях (Phase-Shift Full Bridge, інвертори моторів) розробники випускають спеціалізовані серії суперперехідних MOSFET із швидким внутрішнім діодом (наприклад, CoolMOS серій CFD, CFD2, CFD7, MDmesh DM2, DM6):
- Кристал піддають легуванню важкими металами (платиною) або опроміненню швидкими електронами чи іонами гелію.
- Це створює в забороненій зоні глибокі рекомбінаційні пастки, які скорочують час життя неосновних носіїв.
- Заряд відновлення `Q_rr` зменшується у 5–10 разів, а стійкість приладу до швидкості відновлення `di/dt` та `dv/dt` зростає до безпечних меж (понад 50 А/нс та 50 В/нс).

## 4. Ефекти ємнісного зворотного зв'язку Міллера та осциляції затвора

Надвисока швидкість наростання напруги на стоці `dv/dt` замикається крізь паразитну ємність зворотного зв'язку стік-затвор `C_gd` (ємність Міллера), інжектуючи в коло затвора паразитний струм зміщення:

```
I_gate,disp = C_gd · (dv_DS / dt)
```

Цей струм стікає крізь вихідний опір драйвера затвора `R_driver` та зовнішній резистор `R_g`, створюючи динамічний стрибок напруги на затворі:

```
ΔV_GS = I_gate,disp · (R_g + R_driver) = C_gd · (dv_DS / dt) · (R_g + R_driver)
```

Якщо цей сплеск напруги перевищить порогову напругу відкривання каналу `V_GS(th)` (яка для сучасних кремнієвих транзисторів становить лише 2.5–3.5 В), виникає явище **паразитного відмикання ключа** *(False Turn-on / C_gd induced turn-on)*.

У стійці напівмоста це призводить до миттєвого наскрізного короткого замикання шини живлення *(shoot-through cross-conduction)*, що генерує потужні радіозавади або руйнує силові ключі.

```
Схема виникнення наскрізного струму через ємність Міллера:

    +V_bus ───────────────┬────────────────────────
                          │
                       ┌──┴──┐
                       │ Q1  │  Верхній ключ ВИМИКАЄТЬСЯ
                       └──┬──┘  (напруга стік-витік різко зростає)
                          │
  Середня точка  ─────────┼───────► Напруга злітає з dv/dt > 50 В/нс
                          │
                          │   ─── C_gd
                          ├──┤   ├───┐  Паразитний струм інжекції
                          │   ───    │  I_disp = C_gd · dv/dt
                       ┌──┴──┐       ▼
                       │ Q2  ├───────┴─────► Затвор підстрибує: V_GS > V_th
                       └──┬──┘  Нижній ключ  Нижній ключ ХИБНО ВІДКРИВАЄТЬСЯ!
                          │     МАВ БУТИ      (Наскрізне коротке замикання)
                          │     ЗАКРИТИЙ
    GND    ───────────────┴────────────────────────
```

## 5. Автоколивання в колі затвора (Gate Ringing)

Паразитна індуктивність виводів корпусу та друкованих доріжок затвора `L_gate` разом із вхідною ємністю транзистора `C_iss = C_gs + C_gd` утворює послідовний LC-контур із власною резонансною частотою:

```
f_res = 1 / (2 · π · √(L_gate · C_iss))    [типово 50...150 МГц]
```

Добротність цього коливального контуру визначається затворним демпфуючим опором `R_gate = R_g + R_driver + R_int`:

```
Q = (1 / R_gate) · √(L_gate / C_iss)
```

Якщо розробник намагається максимально прискорити вмикання транзистора й встановлює занадто малий резистор `R_g` (менше 2–5 Ом), добротність `Q` перевищує критичну межу `Q > 0.5`. Контур переходить у режим слабозатухаючих автоколивань.

Напруга на затворі коливається з розмахом, що перевищує напругу живлення драйвера, і може перевищити абсолютний паспортний максимум затвора (зазвичай `±20...30 В`), пробиваючи тонкий підзатворний підкисел кремнію `SiO₂`.

Для демпфування ВЧ-дзвону без надмірного сповільнення фронту перемикання рекомендується встановлювати безпосередньо біля виводу затвора спеціальні **феритові намистини** *(Ferrite Beads)*, які мають нульовий опір на постійному струмі, але додають 20–50 Ом активних втрат на частотах понад 50 МГц.

## 6. Інженерні методи приборкання суперперехідних MOSFET

Для надійної безаварійної роботи Superjunction MOSFET у сучасних високоефективних перетворювачах застосовують комплекс схемотехнічних та конструктивних рішень:

### 1. Використання 4-вивідних корпусів з виводом Кельвіна (Kelvin Source)
У класичному 3-вивідному корпусі (TO-220, TO-247) падіння напруги на паразитній індуктивності виводу витоку `L_source · (di/dt)` віднімається від напруги затвора, сповільнюючи комутацію та викликаючи резонансний дзвін. 4-вивідні корпуси (TO-247-4, ThinPAK 8x8) мають окремий вивід джерела керування *(Driver Source)*, який виключає силову індуктивність із контуру затвора.

### 2. Роздільне регулювання швидкості вмикання та вимикання
Для запобігання паразитній інжекції Міллера затворний опір вимикання `R_g,off` вибирають істотно меншим за опір вмикання `R_g,on` (за допомогою паралельного діода Шотткі послідовно з додатковим резистором) або застосовують драйвери з функцією активного закорочування затвора на землю *(Active Miller Clamp)*.

### 3. Негативна напруга замикання затвора
Подача негативного потенціалу `-3 В...-5 В` у закритому стані створює надійний запас завадостійкості, гарантуючи, що жоден динамічний викид `ΔV_GS` не досягне порогу `V_GS(th)`.

### 4. Мінімізація паразитної індуктивності друкованої плати (PCB Layout)
Площа контуру затвора (від виходів мікросхеми драйвера до затвора й витоку MOSFET) має бути мінімальною і прокладатися виключно над суцільним земляним шаром. Силовий контур стоку та шунтувальні керамічні блокувальні конденсатори мають розміщуватися впритул до виводів транзистора, щоб обмежити амплітуду перенапруг `V_peak = L_loop · (di/dt)`.

## 7. Зведена таблиця симптомів та рішень

| Проблема | Фізична першопричина | Схемотехнічне рішення |
|:---|:---|:---|
| **Дзвін напруги на затворі (f > 80 МГц)** | Висока добротність контуру `L_gate-C_iss` при малому `R_g` | Збільшити `R_g`, додати феритову намистину на затвор |
| **Хибне відмикання та наскрізний струм** | Інжекція струму через `C_gd` при крутому `dv/dt > 50 В/нс` | Знизити `R_g,off`, використати Active Miller Clamp або `-3 В` зміщення |
| **Вибух ключа при реверсі струму** | Latch-up паразитного BJT під час жорсткого відновлення діода | Застосувати серію з Fast Body Diode (CFD/FRD) або діод Шотткі |
| **Перенапруга на стоці при вимиканні** | Стрибок напруги `L_loop · (di/dt)` на паразитній індуктивності шини | Оптимізувати розведення плати, застосувати RC-снабер або корпус із Kelvin Source |
