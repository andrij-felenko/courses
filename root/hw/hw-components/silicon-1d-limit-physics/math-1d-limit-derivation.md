# 🧮 Виведення 1D кремнієвої межі та показника степеня 2.5

Розрахунок теоретичної межі питомого опору напівпровідникового ключа починається з розв'язання одновимірного рівняння Пуассона для різкого несиметричного p⁺-n переходу під зворотною напругою зміщення. Мета цього виведення — встановити точну аналітичну залежність між граничною напругою лавинного пробою `V_BR` та мінімально можливим питомим опором дрейфової області `R_sp,drift = R_DS(on) · A`, а також з'ясувати фізичну причину відхилення реального показника степеня від ідеального квадратичного значення до величини 2.5.

## 1. Електростатика збідненої області та одновимірне поле

Розглянемо вертикальну структуру силового напівпровідникового приладу, де високолегований p⁺-шар (область витоку в MOSFET або анода в діоді) утворює плоский перехід із слаболегованим n-епітаксійним шаром (дрейфовою областю) з концентрацією донорної домішки `N_D`. За зворотної напруги зміщення вільні електрони виштовхуються в глиб напівпровідника в напрямку позитивного потенціалу стоку, залишаючи після себе нерухомі позитивно заряджені іони донорів. Утворюється область просторового заряду (збіднена зона) з густиною заряду `ρ(x) = +q · N_D`.

Розподіл напруженості електричного поля `E(x)` уздовж вертикальної координати `x` (де координата `x = 0` відповідає металургійній межі p⁺-n переходу, а `x = W` — краю збідненої області) описується одновимірним рівнянням Пуассона:

```
dE / dx = ρ(x) / ε_s = q · N_D / ε_s     [диференціальне рівняння Пуассона]
```

де прийнято такі фізичні константи:
- `q = 1.602 × 10⁻¹⁹ Кл` — елементарний електричний заряд електрона;
- `ε_0 = 8.854 × 10⁻¹⁴ Ф/см` — електрична стала вакууму;
- `ε_r = 11.7` — відносна діелектрична проникність кремнію;
- `ε_s = ε_r · ε_0 ≈ 1.036 × 10⁻¹² Ф/см` — абсолютна діелектрична проникність кремнієвого кристала.

Гранична умова на правому краю збідненого шару визначається тим, що електричне поле повністю замикається всередині збідненої зони й не проникає в квазінейтральний об'єм напівпровідника: `E(W) = 0`. Інтегруючи рівняння Пуассона від довільної точки `x` до краю `W`, отримуємо лінійний розподіл напруженості поля:

```
E(x) = ∫_x^W (q · N_D / ε_s) dx'
E(x) = (q · N_D / ε_s) · (W - x)          [лінійна епюра поля]
```

Максимальна напруженість електричного поля `E_max` зосереджена безпосередньо на металургійній межі переходу при `x = 0`:

```
E_max = E(0) = q · N_D · W / ε_s          [максимальне пікове поле]
```

Звідси товщина збідненого шару `W` однозначно виражається через пікову напруженість поля та рівень легування:

```
W = ε_s · E_max / (q · N_D)               [ширина збідненої зони]
```

Падіння напруги `V` на збідненому шарі є інтегралом від напруженості електричного поля:

```
V = ∫₀^W E(x) dx
V = ∫₀^W (q · N_D / ε_s) · (W - x) dx
V = 1/2 · E_max · W                      [площа трикутної епюри]
```

Підставивши вираз для `W`, отримуємо зв'язок між прикладеною напругою блокування, піковим полем і концентрацією домішки:

```
V = ε_s · E_max² / (2 · q · N_D)         [зв'язок напруги з піковим полем]
```

## 2. Ідеальна 1D-межа Баліги при постійному критичному полі

Припустимо спочатку спрощену фізичну модель: лавинний пробій настає тоді, коли пікове електричне поле `E_max` сягає деякого фіксованого значення `E_crit`, яке вважається універсальною константою матеріалу кристала (для кремнію порядку `3.0 × 10⁵ В/см`), незалежно від легування.

У цьому разі максимальна напруга блокування (напруга лавинного пробою `V_BR`) дорівнює:

```
V_BR = 1/2 · E_crit · W = ε_s · E_crit² / (2 · q · N_D)
```

З цього виразу випливають дві фундаментальні залежності:

1. Необхідна товщина дрейфової області зростає строго лінійно з ростом напруги пробою:

```
W = 2 · V_BR / E_crit                    [товщина W ∝ V_BR]
```

2. Гранично допустима концентрація донорів падає обернено пропорційно напрузі:

```
N_D = ε_s · E_crit² / (2 · q · V_BR)     [концентрація N_D ∝ 1/V_BR]
```

Коли силовий транзистор відкривається, струм тече крізь цю саму дрейфову область товщиною `W`. Питомий опір дрейфового шару, нормований на площу кристала `A = 1 см²`, визначається концентрацією вільних електронів і їхньою дрейфовою рухливістю `μ_n`:

```
R_sp,drift = W / σ = W / (q · μ_n · N_D)  [Ом·см²]
```

Підставимо у формулу опору знайдені вирази для товщини `W` та концентрації `N_D`:

```
R_sp,drift = (2 · V_BR / E_crit) / [ q · μ_n · (ε_s · E_crit² / (2 · q · V_BR)) ]
           = 4 · V_BR² / (ε_s · μ_n · E_crit³)
```

Це рівняння становить класичну **фігуру якості Баліги** *(Baliga's Figure of Merit, BFOM)* для низькочастотних втрат провідності:

```
BFOM = ε_s · μ_n · E_crit³
R_sp,drift(ідеальна) = 4 · V_BR² / BFOM
```

Кубічна залежність від критичного поля `E_crit³` демонструє, що здатність матеріалу витримувати сильне електричне поле має незрівнянно більший вплив на питомий опір, ніж діелектрична проникність чи навіть рухливість носіїв.

## 3. Фізика ударної іонізації та апроксимація Фуллопа

У реальних напівпровідниках критичне поле пробою `E_crit` не є константою. Лавинний пробій виникає внаслідок ударної іонізації: вільні носії заряду прискорюються електричним полем на довжині вільного пробігу й, зіштовхуючись із вузлами кристалічної ґратки, вибивають валентні електрони в зону провідності, генеруючи нові електронно-діркові пари.

Інтенсивність цього процесу характеризується коефіцієнтами ударної іонізації електронів `α_n(E)` та дірок `α_p(E)` — кількістю іонізаційних актів, які здійснює носій на одиниці шляху (вимірюється в `см⁻¹`).

Класична модель Чіноветса *(Chynoweth's law)* описує коефіцієнт іонізації експоненційною залежністю:

```
α(E) = A · exp(-B / E)
```

де для кремнію емпіричні параметри становлять `A_n ≈ 7.03 × 10⁵ см⁻¹`, `B_n ≈ 1.23 × 10⁶ В/см`. Для аналітичного інтегрування по нелінійному профілю поля зручніше використовувати степеневу апроксимацію Фуллопа *(Fulop's formula)*, яка дає високу точність для кремнію в діапазоні полів `(1.5...5.0) × 10⁵ В/см`:

```
α_eff(E) = 1.8 × 10⁻³⁵ · E⁷              [см⁻¹, де E виражено у В/см]
```

Критерій лавинного пробою (умова виникнення самопідтримуваного лавинного струму, коли коефіцієнт множення носіїв прямує до нескінченності) формулюється як рівність одиниці інтеграла іонізації вздовж усієї збідненої області:

```
∫₀^W α_eff(E(x)) dx = 1                  [інтеграл пробою Таунсенда]
```

Підставимо лінійний розподіл поля `E(x) = E_max · (1 - x/W)` в інтеграл іонізації:

```
∫₀^W 1.8 × 10⁻³⁵ · [E_max · (1 - x/W)]⁷ dx = 1
```

Винесемо сталий множник `E_max⁷` за знак інтеграла:

```
1.8 × 10⁻³⁵ · E_max⁷ · ∫₀^W (1 - x/W)⁷ dx = 1
```

Обчислимо визначений інтеграл заміною змінної `u = 1 - x/W`, `du = - dx / W`:

```
∫₀^W (1 - x/W)⁷ dx = - W · ∫₁⁰ u⁷ du
                   = W · ∫₀¹ u⁷ du
                   = W · [ u⁸ / 8 ]₀¹
                   = W / 8
```

Підставивши значення інтеграла в критерій пробою, маємо:

```
1.8 × 10⁻³⁵ · E_max⁷ · (W / 8) = 1
E_max⁷ · W = 8 / (1.8 × 10⁻³⁵)
E_max⁷ · W = 4.444 × 10³⁵                 [В⁷/см⁶]
```

## 4. Виведення залежності критичного поля від легування

Зв'яжемо товщину шару `W` з піковим полем `E_max` через рівняння Пуассона: `W = ε_s · E_max / (q · N_D)`. Підставимо це співвідношення в отримане рівняння іонізації:

```
E_max⁷ · [ ε_s · E_max / (q · N_D) ] = 4.444 × 10³⁵
E_max⁸ · (ε_s / (q · N_D)) = 4.444 × 10³⁵
```

Підставимо числові значення діелектричної проникності кремнію та заряду електрона:

```
ε_s / q = 1.036 × 10⁻¹² / 1.602 × 10⁻¹⁹ = 6.467 × 10⁶  [В⁻¹·см⁻²]

E_max⁸ = (4.444 × 10³⁵ / 6.467 × 10⁶) · N_D
E_max⁸ = 6.872 × 10²⁸ · N_D               [В⁸/см⁸]
```

Добудемо корінь восьмого степеня з обох частин рівняння:

```
E_crit(N_D) = (6.872 × 10²⁸)^(1/8) · N_D^(1/8)
E_crit(N_D) = 4010 · N_D^(1/8)            [В/см, де N_D у см⁻³]
```

Фізичний зміст цього результату надзвичайно важливий: **критичне поле лавинного пробою повільно спадає як `N_D^(1/8)` зі зменшенням рівня легування**. Оскільки для підвищення напруги пробою шар доводиться легувати рідше, критична напруженість поля для високовольтних приладів виявляється нижчою, ніж для низьковольтних.

## 5. Напруга пробою та товщина шару через концентрацію домішки

Підставимо знайдену функцію `E_crit(N_D)` у вираз для напруги пробою:

```
V_BR = ε_s · E_crit² / (2 · q · N_D)
     = 1/2 · (ε_s / q) · (4010 · N_D^(1/8))² / N_D
     = 1/2 · (6.467 × 10⁶) · (1.608 × 10⁷ · N_D^(1/4)) / N_D
     = 5.20 × 10¹³ · N_D^(-3/4)          [В]
```

Уточнений аналіз із врахуванням різниці коефіцієнтів іонізації електронів і дірок дає точніший емпіричний коефіцієнт:

```
V_BR = 5.34 × 10¹³ · N_D^(-3/4)          [В]
```

Обернемо цю формулу, щоб знайти необхідну концентрацію легування дрейфової зони `N_D` для забезпечення заданої напруги пробою `V_BR`:

```
N_D^(3/4) = 5.34 × 10¹³ / V_BR
N_D = (5.34 × 10¹³ / V_BR)^(4/3)
N_D = 2.01 × 10¹⁸ · V_BR^(-4/3)          [см⁻³]
```

Тепер знайдемо мінімальну товщину дрейфового шару `W`, необхідну для утримання напруги `V_BR` без виникнення пробою:

```
W = 2 · V_BR / E_crit
  = 2 · V_BR / (4010 · N_D^(1/8))
```

Підставимо `N_D = 2.01 × 10¹⁸ · V_BR^(-4/3)`:

```
N_D^(1/8) = (2.01 × 10¹⁸)^(1/8) · (V_BR^(-4/3))^(1/8)
          = 190.5 · V_BR^(-1/6)

W = 2 · V_BR / (4010 · 190.5 · V_BR^(-1/6))
  = 2 · V_BR / (7.639 × 10⁵ · V_BR^(-1/6))
  = 2.62 × 10⁻⁵ · V_BR^(7/6)
  = 2.62 × 10⁻⁵ · V_BR^(1.167)           [см]
```

## 6. Виведення залежності питомого опору R_sp ∝ V_BR^2.5

Зведемо докупи товщину `W` та концентрацію домішки `N_D` у формулу питомого опору відкритого дрейфового шару:

```
R_sp,drift = W / (q · μ_n · N_D)
```

Підставимо залежності `W(V_BR)` та `N_D(V_BR)`:

```
R_sp,drift = (2.62 × 10⁻⁵ · V_BR^(7/6)) / [ q · μ_n · (2.01 × 10¹⁸ · V_BR^(-4/3)) ]
```

Простежимо за сумарним показником степеня змінної `V_BR`:

```
Показник степеня = 7/6 - (-4/3) = 7/6 + 8/6 = 15/6 = 2.5
```

Обчислимо числовий коефіцієнт. Для слаболегованого кремнію рухливість електронів становить `μ_n ≈ 1250...1350 см²/(В·с)`:

```
Знаменник = q · μ_n · 2.01 × 10¹⁸
          = 1.602 × 10⁻¹⁹ · 1250 · 2.01 × 10¹⁸
          = 402.5  [Ом⁻¹·см⁻¹]

Коефіцієнт = 2.62 × 10⁻⁵ / 402.5 = 6.51 × 10⁻⁸
```

З урахуванням залежності рухливості електронів від температури кристала та нелінійностей розсіювання на домішках у реальних приладах кремнієву межу для 1D-структур записують у стандартному інженерному вигляді:

```
R_sp,drift(кремній, межа) ≈ 8.3 × 10⁻⁹ · V_BR^2.5   [Ом·см²,  V_BR у вольтах]
```

## 7. Вплив температури кристала на кремнієву межу

У реальній силовій апаратурі температура напівпровідникового кристала зростає під навантаженням від кімнатної `T₀ = 25 °C (298 К)` до робочої `T = 125...150 °C (398...423 К)`. Це суттєво зміщує обидва ключові параметри кремнієвої межі — напругу пробою та питомий опір.

### Зростання напруги лавинного пробою

Із підвищенням температури збільшується амплітуда теплових коливань кристалічної ґратки, що призводить до зростання ймовірності розсіювання вільних електронів на оптичних фононах. Середня довжина вільного пробігу носія між зіткненнями скорочується:

```
λ_ph(T) ∝ 1 / T
```

Щоб набрати на скороченій довжині вільного пробігу кінетичну енергію, достатню для ударної іонізації (`E_kin ≥ 3/2 · E_g`), електрон потребує сильнішого електричного поля. Тому критичне поле `E_crit` та напруга лавинного пробою `V_BR` зростають із температурою:

```
V_BR(T) = V_BR(T₀) · [ 1 + α_T · (T - T₀) ]
```

де для кремнієвих p-n переходів температурний коефіцієнт напруги пробою становить `α_T ≈ (0.8...1.2) × 10⁻³ К⁻¹`. Для приладу з номіналом 600 В при 25 °C реальна напруга пробою при 125 °C досягає приблизно 660–670 В.

### Падіння рухливості та катастрофічне зростання опору

Одночасно фононне розсіювання різко знижує рухливість вільних носіїв у зоні провідності. У діапазоні робочих температур рухливість електронів у кремнії падає за степеневим законом:

```
μ_n(T) = μ_n(T₀) · (T / T₀)^(-2.3...-2.5)
```

Оскільки питомий опір дрейфової області обернено пропорційний рухливості (`R_sp,drift ∝ 1 / μ_n`), він демонструє сильний позитивний температурний коефіцієнт:

```
R_sp,drift(T) = R_sp,drift(T₀) · (T / T₀)^(2.3...2.5)
```

При нагріванні кристала від 25 °C (298 К) до 125 °C (398 К):

```
(398 / 298)^2.4 = (1.335)^2.4 ≈ 2.00
```

Питомий опір дрейфової зони кремнієвого транзистора при 125 °C **подвоюється**, а при 150 °C зростає у 2.4 раза порівняно з кімнатним значенням. Це фундаментальне обмеження змушує розробників закладати суттєвий запас за площею кристала та охолодженням.

## 8. Двовимірне рівняння Пуассона та лінійна межа суперпереходу

Щоб зламати показник степеня 2.5, необхідно змінити геометрію розподілу заряду з одновимірної (1D) на двовимірну (2D). Саме це реалізує технологія суперпереходу *(Superjunction)*.

Розподіл потенціалу `φ(x, y)` у періодичній системі тонких чергованих p- і n-стовпчиків описується двовимірним рівнянням Пуассона:

```
∂²φ / ∂x² + ∂²φ / ∂y² = - ρ(x, y) / ε_s
```

де `x` — вертикальна координата вздовж напрямку струму, а `y` — горизонтальна координата впоперек стовпчиків шириною `w_n` та `w_p`.

Якщо виконується умова строгого зарядового балансу на одиницю площі:

```
q · N_D · w_n = q · N_A · w_p            [умова балансу зарядів]
```

то при прикладанні зворотної напруги сусідні p- і n-стовпчики повністю збіднюють один одного в горизонтальному напрямку `y` за низької напруги `V_DS < 30...50 В`:

```
V_lat ≈ q · N_D · w_n² / (8 · ε_s)       [напруга бічного збіднення]
```

Оскільки ширина стовпчиків мала (`w_n ≈ 2...5 мкм`), напруга `V_lat` становить менше 5% від повної напруги пробою. Після повного бічного збіднення сумарний нескомпенсований просторовий заряд усереднюється до нуля: `⟨ρ⟩_y = 0`.

Внаслідок цього похідна вертикального поля вздовж стовпця зникає:

```
dE_x / dx = ⟨ρ⟩_y / ε_s ≈ 0
```

Електричне поле вздовж вертикалі стає однорідним (прямокутний профіль `E(x) ≈ E_crit` по всій товщині `W_SJ`). Напруга пробою стає рівною:

```
V_BR,SJ = E_crit · W_SJ                  [прямокутне поле]
```

Звідси товщина дрейфового шару суперпереходу:

```
W_SJ = V_BR / E_crit                     [вдвічі менше, ніж у 1D]
```

Оскільки максимальне горизонтальне поле визначається шириною стовпчика `w_n`, концентрація легування більше не прив'язана до напруги `V_BR`, а задається суто шириною стовпця:

```
N_D,SJ ≈ 2 · ε_s · E_crit / (q · w_n)    [висока концентрація!]
```

Підставимо `W_SJ` та `N_D,SJ` у формулу питомого опору відкритого стану:

```
R_sp,SJ = (w_n + w_p) / w_n · [ W_SJ / (q · μ_n · N_D,SJ) ]
        = 2 · [ (V_BR / E_crit) / (q · μ_n · (2 · ε_s · E_crit / (q · w_n))) ]
        = (w_n · V_BR) / (ε_s · μ_n · E_crit²)
```

Це рівняння виражає фундаментальну **лінійну межу суперпереходу**:

```
R_sp,SJ ∝ V_BR · w_n                     [лінійне масштабування]
```

Питомий опір зростає пропорційно першому степеню напруги `V_BR` (замість `V_BR^2.5`), а його абсолютне значення можна зменшувати шляхом зменшення ширини стовпчиків `w_n` завдяки прецизійним літографічним процесам.

## 9. Математичний аналіз зарядового дисбалансу

Висока ефективність суперпереходу досягається лише за умови прецизійного зарядового балансу між p- і n-стовпчиками. Оцінимо аналітично, як відхилення від ідеального балансу руйнує прямокутний розподіл поля.

Введемо відносний зарядовий дисбаланс `δ`:

```
δ = (Q_n - Q_p) / Q_nom = (N_D · w_n - N_A · w_p) / (N_0 · w)
```

При ненульовому дисбалансі `δ ≠ 0` після бічного збіднення стовпчиків залишається нескомпенсований середній просторовий заряд `⟨ρ⟩ = q · δ · N_0`. Вертикальне електричне поле перестає бути однорідним:

```
dE_x / dx = q · δ · N_0 / ε_s
E_x(x) = E_max - (q · δ · N_0 / ε_s) · x
```

Епюра поля нахиляється, перетворюючись із прямокутника на трапецію або трикутник:
- Якщо `δ > 0` (надлишок донорів), пік поля зміщується до верхнього p⁺-body переходу (`x = 0`), де напруженість сягає `E_crit` раніше, ніж збідниться вся товща шару.
- Якщо `δ < 0` (надлишок акцепторів), пік поля зміщується до нижньої межі з n⁺-підкладкою (`x = W_SJ`).

Інтегруючи нахилене поле, отримуємо напругу пробою при дисбалансі:

```
V_BR(δ) = V_BR,max · [ 1 - (W_SJ · q · |δ| · N_0) / (2 · ε_s · E_crit) ]
```

Підставивши вираз для оптимального легування `N_0 ≈ 2 · ε_s · E_crit / (q · w)`, маємо:

```
V_BR(δ) = V_BR,max · [ 1 - |δ| · (W_SJ / w) ]
```

Оскільки для високовольтних приладів відношення глибини стовпця до його ширини (аспектне відношення) становить `W_SJ / w ≈ 10...20`, навіть крихітний дисбаланс легування `|δ| = 2% (0.02)` призводить до:

```
V_BR(0.02) = V_BR,max · [ 1 - 0.02 · 15 ] = 0.70 · V_BR,max
```

Втрата **30% блокувальної напруги** при похибці дозування домішки лише у 2% наочно пояснює суворі технологічні вимоги до виробництва суперперехідних MOSFET.

## 10. Порівняльний аналітичний розрахунок для Si, SiC та GaN

Застосуємо виведені формули для порівняння параметрів дрейфового шару на робочу напругу `V_BR = 600 В` для чотирьох типів напівпровідникових технологій:

1. **Класичний кремній (1D Si Limit):**
   - Концентрація: `N_D = 2.01 × 10¹⁸ · (600)^(-4/3) ≈ 4.00 × 10¹⁴ см⁻³`
   - Товщина шару: `W = 2.62 × 10⁻⁵ · (600)^(7/6) ≈ 46.5 мкм`
   - Питомий опір: `R_sp,drift = 8.3 × 10⁻⁹ · (600)^2.5 ≈ 73.2 мОм·см²`

2. **Кремнієвий суперперехід (CoolMOS, w_n = 3 мкм):**
   - Концентрація: `N_D,SJ ≈ 2 · (1.036 × 10⁻¹²) · (3.0 × 10⁵) / (1.602 × 10⁻¹⁹ · 3.0 × 10⁻⁴) ≈ 1.30 × 10¹⁶ см⁻³`
   - Товщина шару: `W_SJ = 600 / (3.0 × 10⁵) = 20 мкм`
   - Питомий опір: `R_sp,SJ ≈ (3.0 × 10⁻⁴ · 600) / (1.036 × 10⁻¹² · 1250 · (3.0 × 10⁵)²) ≈ 1.54 мОм·см²` (у 47 разів нижче 1D межі Si!)

3. **Карбід кремнію (4H-SiC, 1D Limit, E_crit = 2.8 × 10⁶ В/см, μ_n = 800 см²/(В·с)):**
   - Концентрація: `N_D,SiC ≈ (0.86 × 10⁻¹² · (2.8 × 10⁶)²) / (2 · 1.602 × 10⁻¹⁹ · 600) ≈ 3.51 × 10¹⁶ см⁻³` (майже у 100 разів густіше за Si!)
   - Товщина шару: `W_SiC = 2 · 600 / (2.8 × 10⁶) ≈ 4.3 мкм` (у 11 разів тонше за Si!)
   - Питомий опір: `R_sp,SiC = 4 · 600² / (0.86 × 10⁻¹² · 800 · (2.8 × 10⁶)³) ≈ 0.095 мОм·см²` (у 770 разів нижче за класичний Si!)

4. **Нітрид галію (GaN 2DEG, E_crit = 3.3 × 10⁶ В/см, μ_n = 1800 см²/(В·с)):**
   - Питомий опір дрейфової області: `R_sp,GaN ≈ 0.035 мОм·см²` (у 2000 разів нижче за класичний Si!)

## 11. Високочастотна фігура якості Баліги (BHFFOM)

У схемах високочастотного перетворення енергії (імпульсні джерела живлення, резонансні перетворювачі) сумарні втрати визначаються не лише статичним опором `R_DS(on)`, а й динамічними втратами на перезаряджання вихідної ємності `C_oss` та ємності затвора `C_iss`.

Питома вихідна ємність збідненого дрейфового шару на одиницю площі оцінюється як:

```
C_sp,oss = ε_s / W = ε_s · E_crit / (2 · V_BR)
```

Добуток питомого опору провідності на питому ємність формує часову сталу перезаряджання кристала:

```
R_sp · C_sp,oss = [ 4 · V_BR² / (ε_s · μ_n · E_crit³) ] · [ ε_s · E_crit / (2 · V_BR) ]
                = 2 · V_BR / (μ_n · E_crit²)
```

Обернена величина цього добутку визначає **високочастотну фігуру якості Баліги** *(Baliga's High Frequency Figure of Merit, BHFFOM)*:

```
BHFFOM = μ_n · E_crit²
```

Порівняння значень BHFFOM для матеріалів силової електроніки показує:
- Кремній (Si): `μ_n · E_crit² ≈ 1250 · (0.3 × 10⁶)² ≈ 1.12 × 10¹⁴ В²/(В·с)` (еталон = 1.0)
- Карбід кремнію (4H-SiC): `800 · (2.8 × 10⁶)² ≈ 6.27 × 10¹⁵ В²/(В·с)` (перевага у 56 разів)
- Нітрид галію (GaN): `1800 · (3.3 × 10⁶)² ≈ 1.96 × 10¹⁶ В²/(В·с)` (перевага у 175 разів)

Високочастотна фігура якості пояснює, чому широкозонні прилади дозволяють підняти робочу частоту комутації з типових для кремнію 50–100 кГц до 500 кГц — 2 МГц зі збереженням коефіцієнта корисної дії перетворювача понад 96–98%.
