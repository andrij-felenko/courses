# 📋 Довідник параметрів, розпіновки та схемотехніки енкодерів

Цей довідник містить інженерні специфікації, цоколівку типових корпусів (Bourns PEC11R, Alps EC11, магнітних датчиків AS5600 та оптичних модулів AMT102), часові параметри квадратурних сигналів, норми брязкоту та розрахункову відомість компонентів (BOM) для апаратного підключення до мікроконтролерів.

### Розпіновка та цоколівка типових корпусів

Механічні панельні енкодери для інтерфейсу користувача (HMI) переважно випускаються у стандартизованих форм-факторах EC11 (діаметр корпусу 11 мм), EC12 (12 мм) та EC16 (16 мм). Їхня контактна група розділена на дві незалежні частини: квадратурний вузол обертання (виводи A, C, B) та контакти вбудованої тактової кнопки натискання на вал (SW1, SW2).

```text
Механічний енкодер EC11 / Bourns PEC11R (вигляд знизу/збоку):

        [   Вал (Shaft)   ]
        +-----------------+
        |   Корпус EC11   |
        +-----------------+
         |   |   |   |   |
         A   C   B  SW1 SW2
         |   |   |   |   |
         |   |   |   +---+---> Тактова кнопка (Push Switch, замикання на GND)
         |   |   +-----------> Канал B (Phase B, квадратурний вихід)
         |   +---------------> Спільний вивід (Common / GND)
         +-------------------> Канал A (Phase A, квадратурний вихід)
```

| Вивід | Назва | Призначення | Електричні рівні |
| :--- | :--- | :--- | :--- |
| **A** | Phase A | Квадратурний імпульсний вихід каналу A | Відкритий контакт на вивід C (потрібен Pull-Up до VCC) |
| **C** | Common | Спільний ковзний контакт ротора | Підключається до сигнальної землі (GND) схеми |
| **B** | Phase B | Квадратурний імпульсний вихід каналу B | Відкритий контакт на вивід C (потрібен Pull-Up до VCC) |
| **SW1** | Switch 1 | Перший контакт вбудованої тактової кнопки | Сигнальний вхід GPIO МК (потрібен Pull-Up до VCC) |
| **SW2** | Switch 2 | Другий контакт вбудованої тактової кнопки | Підключається до сигнальної землі (GND) |

Контакт C є механічною базою ротора. При обертанні вала контакти A і B почергово ковзають по провідних секторах і з'єднуються з виводом C. Оскільки вхідні порти мікроконтролера у вимкненому стані мають високий вхідний опір (Z-стан), за відсутності з'єднання з C на лініях A і B напруга висіла б у невизначеному стані. Тому на кожну сигнальну лінію обов'язково встановлюється резистор підтяжки до шини живлення.

У безконтактних магнітних енкодерах (наприклад, AS5600 у корпусі SOIC-8) призначення виводів інше, оскільки всередині міститься активна мікросхема з інтегрованими елементами Холла, підсилювачами та цифровим сигнальним процесором:

```text
Магнітний кутовий енкодер AS5600 (SOIC-8):

            +---U---+
     VDD5V -| 1   8 |- PGO (Програмування / вихід)
     VDD3V -| 2   7 |- SDA (Шина I²C Data)
       OUT -| 3   6 |- SCL (Шина I²C Clock)
       GND -| 4   5 |- DIR (Напрямок: GND=CW, VDD=CCW)
            +-------+
```

| Вивід AS5600 | Назва | Тип | Функціональне призначення |
| :--- | :--- | :--- | :--- |
| **1** | VDD5V | Живлення | Вхід живлення 5.0 В (при живленні 3.3 В з'єднується з VDD3V) |
| **2** | VDD3V | Живлення / Вихід | Вихід внутрішнього LDO 3.3 В (або прямий вхід 3.3 В) |
| **3** | OUT | Аналог / ШІМ | Аналоговий ратіометричний вихід 0…VDD або вихід ШІМ 1 кГц |
| **4** | GND | Земля | Спільна опорна земля системи |
| **5** | DIR | Цифровий вхід | Завдання напрямку обертання (0 = за годинниковою, 1 = проти) |
| **6** | SCL | Цифровий вхід | Лінія тактування шини I²C (відкритий стік, потрібен Pull-Up) |
| **7** | SDA | Цифровий I/O | Лінія даних шини I²C (відкритий стік, потрібен Pull-Up) |
| **8** | PGO | Цифровий I/O | Вивід одноразового програмування нульової точки та опцій |

### Електричні параметри та вимоги до струму змочування

Механічні контакти з фосфористої бронзи з нікелевим або срібним напиленням чутливі до струму комутації. Якщо струм через контакти занадто малий (менше 0.1 мА, що типово при використанні слабких внутрішніх підтяжок мікроконтролера на 40–100 кОм), енергії електричного розряду при замиканні недостатньо для руйнування тонких діелектричних оксидних і сульфідних плівок, які утворюються на металі під дією повітря та вологи. Це явище призводить до раптового «зникнення» контакту навіть за нового енкодера.

Для стабільної роботи механічних енкодерів необхідний так званий струм змочування контактів (wetting current) величиною не менше 0.5–1.0 мА. При напрузі живлення 3.3 В резистор підтяжки 10 кОм забезпечує струм замикання:

```text
I_contact = V_CC / R_pullup
          = 3.3 В / 10000 Ом
          = 0.33 мА
```

Для промислових пультів із підвищеною вологістю номінал підтяжки знижують до 3.3–4.7 кОм, що підвищує струм до 0.7–1.0 мА і надійно очищує контактні площадки при кожному замиканні.

| Параметр | Позначення | Механічний EC11 | Магнітний AS5600 | Оптичний AMT102 | Одиниця |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Напруга комутації (номінальна) | `V_max` | 5.0 (DC) | 3.0…5.5 | 3.6…5.5 | В |
| Струм комутації контактів | `I_max` | 10 | 4 (вихідний) | 8 (вихідний) | мА |

### Фізичні критерії вибору пасивних компонентів та захисту від ESD

Вибір типів діелектриків для конденсаторів C1–C3 має критичне значення для стабільності часової сталої фільтра:
1. Заборонено застосовувати конденсатори з діелектриками класу 2 і 3 з високою діелектричною проникністю типу Y5V або Z5U. Ємність таких конденсаторів падає на 60–80% при нагріванні до +60 °C або під дією прикладеної постійної напруги зміщення (DC bias effect). У результаті часова стала фільтра падає втричі, і пристрій починає пропускати контактний брязкіт при підвищенні температури.
2. Оптимальним вибором є керамічні конденсатори класу X7R або прецизійні термостабільні конденсатори C0G (NP0). Кераміка X7R зберігає ємність у межах ±15% у всьому діапазоні від -55 °C до +125 °C, не створює пьезоелектричного шуму та забезпечує стабільну фільтрацію протягом усього терміну служби виробу.
3. Захист від електростатики (ESD) є обов'язковим, оскільки металевий шток і гайка енкодера виносяться на передню панель корпусу приладу і піддаються прямому контакту з пальцями людини. Згідно з промисловим стандартом IEC 61000-4-2, вхідні ланцюги повинні витримувати контактний розряд напругою до ±8 кВ та повітряний розряд до ±15 кВ. Застосування швидкодіючих супресорних діодних збірок (наприклад, USBLC6-2SC6) із низькою ємністю переходу та малим часом реакції (менше 1 нс) надійно фіксує електростатичний імпульс на рівнях шин живлення і землі, захищаючи вхідні каскади мікроконтролера від пробою ізоляції затворів CMOS.

### Розрахунок параметрів фільтра низьких частот

Для комбінації `R = 10 кОм` та `C = 100 нФ` часова стала ланцюжка становить:

```text
τ = R · C                      [визначення часової сталої інтегратора]
  = 10000 Ом · 0.0000001 Ф     [підстановка опору 10 кОм і ємності 100 нФ]
  = 0.001 с                    [отримуємо τ = 1.0 мілісекунда]
```

Час наростання напруги від 10% до 90% від `V_CC` при заряді через RC-ланцюг:

```text
t_rise = ln(9) · τ             [час заряду ємності від 0.1 до 0.9 V_CC]
       ≈ 2.197 · 1.0 мс        [підстановка обчисленого значення τ]
       ≈ 2.2 мс                [достатньо для повного поглинання 5 мс брязкоту]
```

Гранична частота зрізу фільтра низьких частот за рівнем -3 дБ:

```text
f_c = 1 / (2 · π · R · C)              [формула частоти зрізу RC-ланцюга]
    = 1 / (2 · 3.14159 · 10000 · 10⁻⁷) [підстановка значень параметрів]
    ≈ 159.15 Гц                        [частота зрізу фільтра низьких частот]
```

При швидкості ручного обертання 2 оберти на секунду (120 RPM) енкодер на 24 PPR генерує сигнал частотою:

```text
f_signal = 2 об/с · 24 імп/об          [частота корисного сигналу обертання]
         = 48 Гц                       [робоча частота значно нижча за частоту зрізу]
```

Оскільки `f_signal = 48 Гц` значно менше за `f_c = 159 Гц`, корисний сигнал обертання проходить крізь фільтр практично без затухання амплітуди (спад амплітуди менше 0.4 дБ), тоді як високі частоти контактного брязкоту (1 кГц — 100 кГц) придушуються на 16—60 дБ.

### Налаштування апаратного квадратурного декодера STM32

Для апаратного підрахунку імпульсів без навантаження процесорного ядра використовується таймер мікроконтролера у режимі квадратурного декодера (Encoder Mode X4). Нижче наведено побітову структуру конфігурації регістрів таймера TIM3:

```text
Регістр TIM3_SMCR (Slave Mode Control Register):
  SMS[2:0] = 011b (Encoder mode 3 — підрахунок за фронтами і спадами каналів TI1 та TI2)

Регістр TIM3_CCMR1 (Capture/Compare Mode Register 1):
  CC1S[1:0] = 01b (Вхід IC1 прив'язано до виводу TI1)
  CC2S[1:0] = 01b (Вхід IC2 прив'язано до виводу TI2)
  IC1F[3:0] = 0100b (Цифровий фільтр входу: частота дискретизації F_DTS/2, N=6 вибірок)
  IC2F[3:0] = 0100b (Цифровий фільтр входу: частота дискретизації F_DTS/2, N=6 вибірок)

Регістр TIM3_CCER (Capture/Compare Enable Register):
  CC1P = 0, CC1NP = 0 (Пряма полярність каналу 1, детектування наростаючого фронту)
  CC2P = 0, CC2NP = 0 (Пряма полярність каналу 2, детектування наростаючого фронту)

Регістр TIM3_CR1 (Control Register 1):
  CEN = 1 (Дозвіл лічби таймера)
```

Режим Encoder Mode 3 відслідковує зміни стану на обох каналах TI1 і TI2, збільшуючи роздільну здатність у 4 рази (кожен клік енкодера на 24 PPR дає зміну лічильника `TIM3->CNT` на 4 або на 1 залежно від конструкції фіксатора detents). Апаратний цифровий фільтр `IC1F`/`IC2F` забезпечує додатковий цифровий захист від завад, відкидаючи будь-які імпульси, тривалість яких менша за 6 тактів внутрішньої дискретизації таймера.

### Рекомендації щодо трасування друкованої плати (PCB Layout)

Для мінімізації наведених електромагнітних завад і паразитних зв'язків при проектуванні друкованої плати слід дотримуватися таких правил:
- Захисні TVS-діоди повинні розташовуватися максимально близько до вхідного роз'єму енкодера. Доріжка від виводу роз'єму має спочатку заходити безпосередньо на площадку TVS-діода, а вже з неї йти до резисторів фільтра.
- Конденсатори фільтра C1–C3 повинні мати пряме коротке з'єднання з суцільним полігоном заземлення (GND plane). Не допускається підключення конденсаторів через довгі тонкі провідники, індуктивність яких погіршує високочастотну фільтрацію.
- Сигнальні провідники каналів A та B повинні проходити паралельно над спільним земляним шаром. Заборонено трасувати лінії енкодера поблизу імпульсних силових ліній (наприклад, виходів драйверів крокових двигунів, ліній ШІМ нагрівачів або котушок реле).
- Якщо енкодер винесено на окрему передню панель і з'єднано з основною платою гнучким шлейфом, земляний провід повинен чергуватися з сигнальними (конфігурація A — GND — B — GND — SW), що запобігає взаємній ємнісній наводці між фазами.
