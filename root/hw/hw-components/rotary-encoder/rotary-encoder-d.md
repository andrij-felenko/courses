# Енкодер поворотний: від механічного контакту до магнітного CORDIC

<preknowlist>
- [Потенціометр і тример](root:hw-components/potentiometer) — поділ напруги, ковзний контакт, шум доріжки та фізика механічного зносу.
- [Резистор](root:hw-components/resistor) — опір, закон Ома, струми змочування та підтягуючі ланцюги.
- [Конденсатор](root:hw-components/capacitor) — накопичення електричного заряду, часова стала RC та фільтрація низьких частот.
- [Тригер Шмітта](root:hw-analog/schmitt-trigger) — гістерезис, пороги перемикання V_T+ і V_T-, усунення метастабільності цифрових входів.
- [Датчик Холла](root:hw-sensing/hall-sensor) — виникнення поперечної різниці потенціалів у напівпровіднику під дією магнітного поля.
</preknowlist>

Коли в цифровому вимірювальному приладі чи аудіомікшері потрібно налаштувати параметр у діапазоні від нуля до сотень тисяч одиниць або гортати безкінечний список меню, класичний резистивний регулятор створює непереборний глухий кут. Звичайний аналоговий регулятор має кутовий хід, обмежений механічними стопорами на позначці 270–300 градусів, його провідна доріжка стирається вже після десяти тисяч обертів, а напруга з рухомого повзунка неминуче шумить через мікронерівності графітового шару й тремтить разом із пульсаціями джерела живлення аналогово-цифрового перетворювача. Спроба обійти обмеження кута за допомогою багатообертових прецизійних резисторів лише відтерміновує проблему: після десяти чи двадцяти обертів вал неминуче впирається в крайній упор, унеможливлюючи безперервне цифрове керування.

Вихід із цього глухого кута полягає у відмові від вимірювання абсолютної напруги на користь генерації послідовності дискретних імпульсів, які несуть інформацію не про абсолютний кут повороту ручки в просторі, а про відносний приріст кута та вектор його зміни. Пристрій, що здійснює таке перетворення механічного кутового переміщення в цифровий код, називається **поворотним енкодером** (англ. *rotary encoder*, від грец. *en-* — усередині + франц. *code* — шифр, звід правил або сигналів).

### Внутрішня будова механічного енкодера та природа квадратурного сигналу

Типовий механічний інкрементний енкодер для панелей керування (найчастіше серії EC11 діаметром 11 мм) містить усередині механічний ротор із пружною металевою контактною крильчаткою (павуком) та нерухомий діелектричний статор, на якому витравлено кругову гребінку провідних контактних майданчиків, з'єднаних зі спільним виводом C (Common).

```text
Спрощена розгортка контактної пари квадратурного енкодера:

Статор:  [ Провідний сектор GND ] [ Ізолятор ] [ Провідний сектор GND ]
                  |                                  |
Щітка A:    -----[o]--------------------------------[o]-----> Фаза A
Щітка B:          |       -----[o]--------------------------------[o]-----> Фаза B
                  |             |
           (Зсув на 90° електричних / 1/4 періоду сітки)
```

З ротором взаємодіють три пружні ковзні контакти (щітки), виготовлені з пружної фосфористої бронзи з нікелевим, срібним або золотим гальванічним покриттям:
1. **Спільний вивід C (Common):** постійно притиснутий до центрального кільця ротора й підключається до сигнальної землі схеми (GND).
2. **Канал A (Phase A):** періодично замикається на вивід C під час проходження над провідними секторами гребінки.
3. **Канал B (Phase B):** також замикається на вивід C, але його контактна щітка фізично зміщена відносно щітки A вздовж кола обертання на чверть просторового кроку контактної сітки.

Чверть просторового кроку відповідає зсуву фази на 90 електричних градусів (або `π/2` радіан). Завдяки цьому зсуву вихідні сигнали обох каналів ніколи не перемикаються одночасно: один канал завжди випереджає інший рівно на чверть періоду коливань. Цей специфічний фазовий зсув на 90 градусів називається **квадратурою** (лат. *quadratura* — надання квадратної форми, розбиття на чотири рівні частини), а самі сформовані імпульси — **квадратурним сигналом** (quadrature output).

![Будова контактної групи, квадратурні сигнали та код Грея](/root/hw/hw-components/rotary-encoder/img/encoder-quadrature.svg)
*Зліва: геометрія кодового диска та розташування щіток A, B і C. Справа: часові діаграми каналів для обертання за годинниковою (CW) та проти годинникової стрілки (CCW) з відповідними станами 2-бітного коду Грея.*

Напрямок обертання вала однозначно визначається тим, який саме з двох каналів першим здійснює логічний перехід:
- **Обертання за годинниковою стрілкою (Clockwise, CW):** щітка каналу A першою наїжджає на провідний сектор і притягує лінію A до землі (логічний 0). Через чверть періоду те саме робить щітка B. При виході з сектора канал A першим повертається до високого рівня напруги (логічна 1 завдяки резистору підтяжки), а за ним — канал B. Канал A випереджає канал B на 90 градусів.
- **Обертання проти годинникової стрілки (Counter-Clockwise, CCW):** щітка каналу B наїжджає на сектор першою, тому канал B випереджає канал A на 90 градусів (або канал A відстає від B на 90 градусів).

Якщо позначити рівні напруги на лініях парою бітів `(A, B)`, де логічна 1 відповідає високому рівню завдяки резисторам підтяжки до шини живлення `V_CC`, а логічний 0 — замкненому контакту на землю, то при повному циклі обертання система послідовно проходить чотири стани:

```text
Послідовність станів при русі CW:
  Стан 0: A = 1, B = 1  (обидва контакти розімкнені)
  Стан 1: A = 0, B = 1  (контакт A замкнувся на GND)
  Стан 2: A = 0, B = 0  (контакт B також замкнувся на GND)
  Стан 3: A = 1, B = 0  (контакт A розімкнувся)
  Стан 0: A = 1, B = 1  (контакт B розімкнувся, повернення у вихідний стан)

Послідовність станів при русі CCW:
  Стан 0: A = 1, B = 1
  Стан 3: A = 1, B = 0
  Стан 2: A = 0, B = 0
  Стан 1: A = 0, B = 1
  Стан 0: A = 1, B = 1
```

Ця послідовність є класичним **кодом Грея** (Gray code, названим на честь фізика Френка Грея). Головна фізична та алгоритмічна перевага коду Грея над звичайним двійковим підрахунком полягає в тому, що при переході між будь-якими двома сусідніми кроками змінюється значення **рівно одного біта**.

> 🔧 **Навіщо це.** Якби лінії перемикалися одночасно (наприклад, перехід від двійкового стану `01b` до `10b`), через мікроскопічні механічні нерівності контактів один із них неминуче замкнувся б на кілька мікросекунд раніше за інший. Це породило б короткочасний паразитичний проміжний стан `00b` або `11b` (явище гонитви сигналів, *race condition*), що призвело б до хаотичних стрибків лічильника координат і помилкового визначення напрямку. У коді Грея гонитва сигналів неможлива в принципі: навіть якщо вал зупиниться точно на межі перемикання або завібрує, змінюватиметься лише один біт, що сприймається алгоритмом як мікрокрок уперед із негайним поверненням назад, без накопичення похибки.

Для забезпечення тактильного відгуку при ручному введенні механічні енкодери оснащуються внутрішнім храповим або кульково-пружинним фіксатором положень — **детентом** (англ. *detent*, від лат. *detinere* — утримувати, зупиняти). Детент складається з підпружиненої металевої кульки чи пластини, яка западає у западини внутрішнього зубчастого вінця. Залежно від співвідношення кількості тактильних кліків (detents) та періодів квадратурної сітки (pulses per revolution, PPR) механічні енкодери діляться на два типи:
1. **Один клік на повний цикл (1 detent per 1 cycle / 4 states per click):** у стані спокою, коли кулька зафіксована у западині детента, обидва контакти A і B гарантовано розімкнені (стан `11b`). Під час повороту вала до наступного кліка енкодер послідовно проходить усі 4 стани (`11 -> 01 -> 00 -> 10 -> 11`) і знову зупиняється в стані `11b`. Це найбільш ергономічний тип для меню приладів: один тактильний клацання пальцем точно відповідає зміні параметра на одиницю, а струм через контакти у стані спокою взагалі не споживається.
2. **Два кліки на цикл (2 detents per cycle / 2 states per click):** фіксація відбувається двічі за період коливань — у стані `11b` (обидва розімкнені) та у стані `00b` (обидва замкнені на землю). У такому виконанні програма повинна детектувати крок за зміною двох станів замість чотирьох.

Механічний ресурс таких енкодерів суворо обмежений фізикою сухого тертя ковзних контактів. При кожному оберті бронзова щітка товщиною в десяті частки міліметра стирає мікронний шар гальванічного золота чи нікелю на статорі. За високої швидкості обертання або в умовах вібрацій демпферне силіконове мастило всередині корпусу змішується з металевим пилом зносу, утворюючи струмопровідну пасту, яка викликає паразитні струми витоку між секторами. Типовий паспортний ресурс панельних механічних енкодерів (Alps EC11, Bourns PEC11R) становить від 15 000 до 30 000 повних обертів, а в найбільш захищених серіях преміум-класу рідко перевищує 100 000 обертів.

### Фізика контактного брязкоту (Switch Bounce)

Коли пружна металева щітка наїжджає на контактний майданчик статора на швидкості, вона не замикає коло миттєво. Через пружність бронзової пластини, неідеальну площинність деталей та мікроскопічну шорсткість поверхні контакт під час першого зіткнення зазнає серії пружних мікровідскоків (ефект «м'ячика, що стрибає по підлозі»).

Цей процес багаторазового механічного розмикання та замикання кола триває від 1 до 5 мілісекунд (у зношених енкодерах — до 10 мс) і називається **контактним брязкотом** (англ. *switch bounce* або *contact chatter*).

```text
Фізичний механізм контактного брязкоту на часовій осі:

Напруга
3.3 В +--------\       /---\       /------------------- (Стан спокою: підтяжка VCC)
       |        \     /     \     /
       |         \   /       \   /
 0.0 В +          \-/         \-/---------------------- (Замкнено: контакт на GND)
       |<- t_b ->|
       (1–5 мс хаотичних імпульсів)
```

Для аналогового кола ці мікророзриви практично непомітні, але для швидкодіючого цифрового мікроконтролера, тактова частота якого становить десятки або сотні мегагерц, кожен такий відскок є повноцінним логічним перепадом. Якщо вхідний контакт енкодера заведений на апаратне переривання мікроконтролера (`EXTI`), один фізичний поворот вала на одну поділку викличе не один логічний перепад, а лавину з 20–80 переривань протягом кількох мілісекунд. Процесор миттєво зависне в нескінченній обробці переривань, а лічильник позиції хаотично проскочить уперед або назад на десятки позицій.

Спроба розв'язати проблему виключно програмною паузою (блокуючим очікуванням `delay(5)`) є грубою інженерною помилкою: вона блокує центральний процесор, знижує частоту реакції системи й призводить до повної втрати кроків, якщо оператор швидко крутне ручку рукою зі швидкістю понад 2–3 оберти на секунду.

### Апаратна дворівнева фільтрація: RC-ланцюг та тригер Шмітта

Єдиним надійним апаратним способом придушення брязкоту є використання двоступеневого фільтраційного каскаду: аналогового інтегруючого RC-фільтра низьких частот і відновлювального буфера з тригером Шмітта.

![Контактний брязкіт, згладжування RC-фільтром та формування прямокутника тригером Шмітта](/root/hw/hw-components/rotary-encoder/img/switch-bounce-filter.svg)
*Зверху вниз: 1) сирий сигнал із пачкою імпульсів брязкоту; 2) аналогова напруга на конденсаторі з порогами V_T+ і V_T-; 3) відновлений прямокутний сигнал на виході тригера Шмітта. Справа: петля гістерезису інвертора 74LVC14.*

Перший ступінь фільтрації реалізується паралельним підключенням конденсатора `C` до сигнальної лінії та виділеним резистором фільтра `R_filt` послідовно з лінією. У парі з резистором підтяжки `R_pullup` формується класичний фільтр низьких частот першого порядку.

Розрахуємо поведінку фільтра для стандартних інженерних номіналів: резистор підтяжки `R_pullup = 10 кОм`, резистор фільтра `R_filt = 10 кОм`, шунтуючий конденсатор `C = 100 нФ` (діелектрик X7R):

```text
Часова стала заряду конденсатора:
τ = R · C                      [визначення часової сталої RC-ланцюжка]
  = 10000 Ом · 100 · 10⁻⁹ Ф    [підстановка R = 10 кОм та C = 100 нФ]
  = 0.001 с                    [отримуємо τ = 1.0 мілісекунда]

Час розряду/заряду до 90% амплітуди:
t_settle = 2.2 · τ             [час перехідного процесу 10%...90%]
         = 2.2 · 1.0 мс        [підстановка знайденого значення τ]
         = 2.2 мс              [перекриває типовий інтервал брязкоту 1.5–2.0 мс]

Частота зрізу фільтра низьких частот:
f_c = 1 / (2 · π · R · C)                   [формула частоти зрізу RC-фільтра першого порядку]
    = 1 / (2 · 3.14159 · 10000 · 10⁻⁷)      [підстановка номіналів]
    ≈ 159.15 Гц                             [гранична частота за рівнем -3 дБ]
```

При швидкості ручного обертання людини 2 оберти на секунду (120 RPM) для енкодера на 24 PPR частота корисного сигналу становить `f_signal = 2 · 24 = 48 Гц`. Оскільки частота 48 Гц значно менша за частоту зрізу 159 Гц, корисні імпульси проходять крізь фільтр практично без ослаблення амплітуди, тоді як високочастотні гармоніки брязкоту (частотою від 2 кГц до 50 кГц) придушуються на 20–50 дБ і перетворюються на гладку експоненційну криву.

Однак інтегруючий RC-ланцюжок породжує іншу критичну небезпеку — **повільний час наростання фронту** (slow input transition time). 

Будь-який стандартний логічний цифровий вхід CMOS або TTL розрахований на круті перепади напруги (зазвичай час наростання повинен бути меншим за 10–20 наносекунд). Якщо напруга змінюється повільно й плавно протягом 2.2 мілісекунди, сигнал зависає в лінійній зоні невизначеності логічних порогів між `V_IL` (максимальна напруга логічного нуля, `≈ 0.3 · V_CC`) та `V_IH` (мінімальна напруга логічної одиниці, `≈ 0.7 · V_CC`).

У цій проміжній зоні обидва комплементарні польові транзистори вхідного каскаду мікроконтролера (і PMOS верхнього плеча, і NMOS нижнього плеча) одночасно відкриваються. Це викликає три небезпечні наслідки:
1. **Наскрізний струм (Shoot-Through Current):** прямий струм короткого замикання від шини `V_CC` на землю GND через відкриту пару транзисторів, що викликає локальне нагрівання кристала та просідання живлення.
2. **Паразитні автоколивання від шумів:** будь-яка мікроскопічна наводка амплітудою в кілька мілівольт (від роботи сусіднього ядра, радіомодуля Wi-Fi/Bluetooth чи імпульсного перетворювача) підсилюється вхідним каскадом, який у лінійній зоні працює як операційний підсилювач із колосальним коефіцієнтом підсилення. У результаті замість брязкоту контактів вхідний каскад генерує власний високочастотний цифровий брязкіт на частоті 50–100 МГц.
3. **Метастабільність тригерів:** внутрішні тригери мікроконтролера входять у невизначений стан, що призводить до зависання системної шини.

Для остаточного формування ідеального прямокутного сигналу після RC-фільтра ставиться **тригер Шмітта** (англ. *Schmitt trigger*, названий на честь американського винахідника Отто Шмітта).

Тригер Шмітта — це бістабільний компаратор із внутрішнім додатним зворотним зв'язком, який має два розділені пороги перемикання:
- **Верхній поріг увімкнення `V_T+` (Positive-going threshold):** напруга, при перевищенні якої вихід стрибкоподібно перемикається в стан логічної одиниці (для прямого тригера) або логічного нуля (для інвертора Шмітта). При живленні `V_CC = 3.3 В` для мікросхеми 74LVC14 поріг `V_T+ ≈ 2.0 В`.
- **Нижній поріг вимкнення `V_T-` (Negative-going threshold):** напруга, нижче якої вихід повертається у вихідний стан. Для тієї ж мікросхеми `V_T- ≈ 1.1 В`.

Різниця між цими порогами утворює **напругу гістерезису** (грец. *hysteresis* — запізнення, відставання):

```text
ΔV_T = V_T+ - V_T-     [визначення ширини петлі гістерезису]
     = 2.0 В - 1.1 В  [підстановка порогів для 74LVC14 при живленні 3.3 В]
     = 0.9 В          [запас завадостійкості проти повторних перемикань]
```

Поки амплітуда високочастотного шуму та залишків брязкоту на конденсаторі не перевищує величину гістерезису `ΔV_T = 0.9 В`, вихід тригера Шмітта залишається абсолютно стабільним. Коли напруга на конденсаторі впевнено перетинає поріг `V_T+`, тригер за частки наносекунди перемикає свій вихід, відновлюючи крутий прямокутний фронт з часом наростання менше 3–5 наносекунд.

Повні параметри мікросхем тригерів Шмітта (74LVC14, 74HC14), граничні електричні режими та рекомендації щодо вибору номіналів зібрано в [довіднику з розпіновки, електричних параметрів та BOM](root:hw-components/rotary-encoder/api-rotary-encoder.md).

### Безконтактні енкодери: магнітні та оптичні технології

У прецизійних сервоприводах, робототехніці, безщіткових двигунах (BLDC) та промислових маніпуляторах механічні енкодери непридатні через швидкий абразивний знос контактів та обмеження швидкості обертання (не більше 100 RPM). Для таких систем застосовують **безконтактні енкодери**, що працюють на магнітних або оптичних фізичних принципах.

![Порівняння магнітного CORDIC-енкодера та оптичного енкодера](/root/hw/hw-components/rotary-encoder/img/magnetic-vs-optical.svg)
*Зліва: магнітний кутовий енкодер із діаметральним магнітом на валу, інтегральною мікросхемою Hall-сенсорів та CORDIC-процесором. Справа: оптичний енкодер зі світлодіодом, диском із мікропрорізами та фотоприймальною матрицею.*

#### Магнітні датчики кута (Magnetic Rotary Encoders)

Сучасний магнітний енкодер (наприклад, AMS AS5600, AS5048, Monolithic Power Systems MagAlpha, MPS MP6500) складається з двох компонентів:
1. Маленького постійного дискового неодимового магніту (NdFeB) з **діаметральним намагнічуванням** (одна половина диска — північний полюс N, інша — південний S), закріпленого на торці обертового вала.
2. Інтегральної мікросхеми датчика, розташованої на друкованій платі точно під магнітом уздовж осі обертання з повітряним зазором 0.5–2.0 мм.

Усередині мікросхеми розташована матриця з чотирьох або більше диференціальних [датчиків Холла](root:hw-sensing/hall-sensor) або магніторезистивних елементів (AMR — анізотропний магнітоопір, TMR — тунельний магнітоопір). При обертанні магніту вектор магнітної індукції `B` обертається в площині кристала. Сенсори вимірюють дві ортогональні проекції поля:

```text
B_x = B_0 · cos(θ)
B_y = B_0 · sin(θ)
```

де `θ` — поточний кут повороту вала, а `B_0` — амплітуда магнітної індукції на поверхні датчика (зазвичай 30–80 мТл).

Отримані ортогональні аналогові сигнали оцифровуються прецизійним диференціальним АЦП і передаються у вбудований цифровий сигнальний процесор. Процесор реалізує алгоритм **CORDIC** (англ. *Coordinate Rotation Digital Computer*, апаратний алгоритм повороту координат), який обчислює функцію арктангенса двох аргументів без використання важких операцій ділення та тригонометрії:

```text
θ = atan2(B_y, B_x)
```

Магнітний енкодер вимірює не прирости, а **абсолютний кут** повороту вала в діапазоні від 0 до 360 градусів із роздільною здатністю 12–14 біт (від 4096 до 16384 дискретних значень на один повний оберт). Абсолютне значення кута доступне мікроконтролеру негайно після подачі живлення без необхідності попереднього калібрування чи пошуку нульової мітки.

Інтегральні магнітні датчики підтримують широкий спектр інтерфейсів зв'язку:
- **Цифрові послідовні шини:** шина SPI або SSI (Synchronous Serial Interface) для передачі повного 14-бітного слова кута за кілька мікросекунд, шина I²C для конфігурації регістрів і калібрування діапазону.
- **ШІМ-вихід (PWM):** шпаруватість імпульсів із частотою 1 кГц лінійно пропорційна куту від 0% (0 градусів) до 100% (360 градусів).
- **Аналоговий ратіометричний вихід:** напруга від 0 до `V_CC`, що дозволяє замінити традиційний зношуваний потенціометр без зміни схеми приладу.
- **Емульований інкрементний квадратурний вихід (ABZ):** мікросхема самостійно синтезує прямокутні сигнали фаз A та B з програмно налаштовуваною кількістю імпульсів (від 64 до 2048 PPR) та індексним імпульсом Z (Zero), що позначає проходження через нульовий кут.

#### Оптичні енкодери (Optical Encoders)

Оптичні енкодери працюють за принципом просторової модуляції світлового потоку:
1. Джерело випромінювання (інфрачервоний або видимий світлодіод із лінзою коліматора) формує паралельний світловий промінь.
2. На валу закріплено прецизійний тонкий диск зі скла або фототравленого металу, на якому фотолітографічним методом нанесено концентричні непрозорі та прозорі оптичні риски шириною в кілька мікрон.
3. Нерухома маска-коліматор пропускає світло на фотоприймальну матрицю фотодіодів.

При обертанні диска фотодіоди генерують дві пари аналогових диференціальних синусоїдальних сигналів зі зсувом 90 градусів. Внутрішній інтерполятор підсилює сигнали, компенсує температурний дрейф світлодіода й за допомогою компараторів перетворює їх на квадратурні цифрові імпульси A та B з надвисокою роздільною здатністю (до 50 000 і більше імпульсів на оберт).

| Критерій порівняння | Механічний контактний | Магнітний (Hall / AMR CORDIC) | Оптичний (Code Wheel) |
| :--- | :--- | :--- | :--- |
| **Принцип вимірювання** | Замикання металевих контактів | Вимірювання вектора магнітного поля | Перекриття оптичного променя диском |
| **Тип вихідних даних** | Інкрементний квадратурний | Абсолютний (SSI/SPI/I2C) + ABZ | Інкрементний (ABZ) або кодовий диск Грея |
| **Кутова роздільність** | 12…30 PPR (імпульсів на оберт) | 1024…16384 CPR (до 14 біт) | 500…50000+ PPR (з інтерполяцією) |
| **Механічний ресурс** | 15 000…100 000 обертів | Необмежений (> 100 000 000) | Обмежений підшипниками (> 50 000 000) |
| **Максимальна швидкість** | 60…100 RPM | До 12 000…30 000 RPM | До 6 000…12 000 RPM |
| **Контактний брязкіт** | Присутній (1–10 мс) | Відсутній | Відсутній |
| **Стійкість до бруду й пилу** | Низька (окиснення, стирання) | Абсолютна (герметичний корпус) | Низька (пил перекриває мікропрорізи) |
| **Стійкість до магнітних полів** | Абсолютна | Вимагає екранування від моторів | Абсолютна |
| **Вартість компонента** | Дуже низька ($0.2–$0.8) | Середня ($1.5–$5.0) | Висока ($15–$150) |

### Інтегрована тактова кнопка (Push Switch)

Більшість механічних енкодерів HMI оснащуються вбудованою тактовою кнопкою осьового натискання на вал. Металевий шток енкодера має вертикальний люфт (хід 0.5–1.5 мм). При натисканні на ручку торець штока тисне на мініатюрний пружний металевий купол (snap dome) у нижній частині корпусу, замикаючи виводи кнопки SW1 та SW2.

```text
Кінематика натискання кнопки у валу енкодера:

    Натискання [ F = 3..6 Н ]
              |
              V
       [ Металевий вал ]
              |
              V  (Осьовий хід 0.5–1.5 мм)
    +-------------------+
    | Пружний купол SW  |  ---> Механічне замикання контакту на GND
    +-------------------+
```

Особливості схемотехнічного використання тактової кнопки:
- **Спільне заземлення:** вивід SW2 найчастіше підключають до спільної шини землі (GND) разом із виводом C енкодера. Це дозволяє обійтися мінімальною кількістю провідників (4 дроти у джгуті: A, B, SW, GND).
- **Струм спрацьовування та брязкіт:** металевий купол кнопки також генерує контактний брязкіт тривалістю 5–15 мс. Для надійного зчитування лінія SW вимагає власного резистора підтяжки (10 кОм), паралельного фільтруючого конденсатора (100 нФ) та тригера Шмітта, або спеціального алгоритму програмного дебаунсу з вимірюванням часу утримання.
- **Механічний ресурс кнопки:** ресурс купола становить від 20 000 до 50 000 натискань при нормованому зусиллі 3–6 Н. Надмірне зусилля натискання може деформувати контактну групу енкодера та вивести з ладу квадратурний диск.

### Повна схемотехніка підключення та вибір компонентів у BOM

Для промислових пристроїв та надійної споживчої електроніки схемотехніка вхідного вузла енкодера повинна забезпечувати надійний захист від електростатичних розрядів (ESD), повне апаратне придушення брязкоту та формування чистих логічних рівнів для мікроконтролера.

![Повна схемотехніка підключення енкодера з RC-фільтрами, захистом від ESD та тригером Шмітта](/root/hw/hw-components/rotary-encoder/img/encoder-wiring-schematic.svg)
*Принципова схема підключення енкодера EC11: підтягуючі резистори R1–R3 (10 кОм), послідовні резистори R_f1–R_f3 (10 кОм), конденсатори C1–C3 (100 нФ), інвертори з тригерами Шмітта 74LVC14 та лінії введення GPIO мікроконтролера.*

#### Функціональні блоки вхідного каскаду:

1. **Захист від електростатики (ESD Protection):** оскільки металева ручка енкодера виходить на передню панель корпусу приладу, вона є первинною мішенню для електростатичного розряду від пальців людини. Згідно зі стандартом IEC 61000-4-2, контактний розряд може досягати напруги `±8 кВ`, а повітряний — `±15 кВ`. Захисна супресорна діодна матриця (наприклад, USBLC6-2SC6) встановлюється безпосередньо біля виводів енкодера і відводить енергію високовольтного імпульсу в шини живлення та заземлення до того, як хвиля дійде до мікросхем.
2. **Підтягуючі резистори `R_pullup` (10 кОм):** забезпечують стабільний струм змочування контактів `I_wet ≈ 0.33 мА` при `V_CC = 3.3 В`, що руйнує оксидні плівки на контактах ротора, та формують чіткий високий логічний рівень при розімкненому стані.
3. **Фільтруючі ланцюги `R_filt` та `C_filt` (10 кОм + 100 нФ):** утворюють симетричний інтегратор із часовою сталою `τ = 1 мс`, який зрізає високочастотний брязкіт і завади від паразитних наводок.
4. **Буферні тригери Шмітта (74LVC14A):** відновлюють ідеальні прямокутні фронти цифрового сигналу та ізолюють чутливі порти мікроконтролера від зовнішніх ліній зв'язку.

Детальні програмні алгоритми обробки квадратурних сигналів за допомогою скінченного автомата станів, фільтрації кнопки та динамічного масштабування кроків розглянуто у [практичному посібнику з алгоритмів декодування енкодерів](root:hw-components/rotary-encoder/proj-rotary-encoder.md).

### Інженерний підсумок

Вибір конкретного типу поворотного енкодера визначається компромісом між ресурсом, швидкістю, кутовою точністю та собівартістю виробу:
- **Механічний інкрементний енкодер (EC11/Bourns PEC11):** безальтернативний лідер для інтерфейсу користувача (HMI) у вимірювальних приладах, лабораторних блоках живлення та автомагнітолах завдяки низькій вартості, наявності приємного тактильного кліка та інтегрованої кнопки. Обов'язково вимагає апаратного RC-фільтра або табличного автомата станів для усунення контактного брязкоту.
- **Магнітний кутовий енкодер (AS5600/MT6701):** оптимальне рішення для безконтактних джойстиків, поворотних платформ, сервоприводів та заміни аналогових потенціометрів. Забезпечує миттєве зчитування 12-бітного абсолютного кута через I²C/SPI та практично необмежений ресурс експлуатації.
- **Оптичний квадратурний енкодер (AMT102/HEDS-9000):** вибір для промислових верстатів ЧПК, прецизійного позиціонування валів двигунів та робототехніки, де критично необхідні гранична частота відліків і повна несприйнятливість до сильних зовнішніх магнітних полів.
