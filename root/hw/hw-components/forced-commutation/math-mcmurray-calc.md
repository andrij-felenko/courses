# 🧮 Аналітичний розрахунок та оптимізація комутатора Мак-Мюррея

Щоб надійно вимкнути головний тиристор у колі постійного струму без необґрунтованого збільшення габаритів реактивних елементів, інженеру необхідно точно розрахувати мінімальну енергію комутуючого конденсатора та параметри резонансної котушки. Без строгих аналітичних залежностей між амплітудою коливального струму, часом зворотного зміщення тиристора та струмом навантаження схема або втрачає працездатність через брак часу на розсмоктування зарядів, або містить надмірно важкі й дорогі високовольтні конденсатори.

### Диференціальне рівняння коливального контуру комутації

У момент відмикання допоміжного тиристора `TA1` утворюється замкнений коливальний контур, що складається з попередньо зарядженого конденсатора `Cc` (з початковою напругою `Vc0`), резонансної котушки індуктивністю `Lc` та власного активного опору контуру `r`. Якщо знехтувати малим активним опором втрат (`r ≈ 0`) для швидкого комутаційного інтервалу, баланс напруг у контурі описується лінійним однорідним диференціальним рівнянням другого порядку:

```
Lc · d²q(t)/dt² + (1 / Cc) · q(t) = 0               [рівняння Кірхгофа для ідеального LC-кола]
```

Початкові умови в момент вмикання `t = 0`:
- заряд на обкладках конденсатора: `q(0) = Cc · Vc0`;
- початковий струм у котушці: `i_c(0) = dq/dt = 0`.

Власна кутова частота коливань контуру визначається класичною формулою Томсона:

```
ω0 = 1 / √(Lc · Cc)                                 [власна резонансна частота]
```

Характеристичний (хвильовий) опір контуру:

```
Z0 = √(Lc / Cc)                                     [характеристичний опір контуру]
```

Диференціюючи розв'язок для заряду `q(t) = Cc · Vc0 · cos(ω0 · t)`, отримуємо аналітичний вираз для миттєвого струму розряду комутуючого конденсатора:

```
i_c(t) = -dq(t)/dt
= Cc · Vc0 · ω0 · sin(ω0 · t)                       [похідна за часом від заряду]
= Cc · Vc0 · (1 / √(Lc · Cc)) · sin(ω0 · t)         [підстановка виразу для ω0]
= Vc0 · √(Cc / Lc) · sin(ω0 · t)                    [спрощення кореня]
= (Vc0 / Z0) · sin(ω0 · t)                          [введення характеристичного опору]
= Ip · sin(ω0 · t)                                  [де Ip = Vc0 / Z0 — піковий струм]
```

Напруга на комутуючому конденсаторі протягом резонансного напівперіоду спадає за косинусоїдним законом:

```
v_c(t) = (1 / Cc) · q(t) = Vc0 · cos(ω0 · t)        [миттєва напруга на конденсаторі]
```

### Врахування реального затухання коливань через активний опір `r`

У реальному комутаторі провідники, внутрішній опір котушки та еквівалентний послідовний опір конденсатора (ESR) вносять активний опір `r > 0`. Повне диференціальне рівняння контуру набуває вигляду:

```
Lc · d²q(t)/dt² + r · dq(t)/dt + (1 / Cc) · q(t) = 0 [рівняння згасаючих коливань]
```

Введемо коефіцієнт затухання `δ = r / (2 · Lc)` та власну частоту згасаючих коливань:

```
ω_d = √(ω0² - δ²) = √((1 / (Lc · Cc)) - (r / (2 · Lc))²) [частота вільних коливань із втратами]
```

Оскільки контур комутації проектується високодобротним (`Q = Z0 / r >> 1`), умова коливального режиму `δ < ω0` виконується з великим запасом. Миттєвий струм у контурі з урахуванням затухання описується аналітичним виразом:

```
i_c(t) = (Vc0 / (ω_d · Lc)) · exp(-δ · t) · sin(ω_d · t) [згасаючий резонансний струм]
```

Затухання знижує амплітуду коливального імпульсу на величину декремента `exp(-δ · t1)`. Для збереження необхідної кратності `m = Ip / I0` розрахункову ємність `Cc` або початкову напругу `Vc0` коригують на коефіцієнт демпфування `k_d = exp(δ · π / (2 · ω0)) ≈ 1 + π / (4 · Q)`.

### Тривалість зворотного зміщення тиристора `tc`

Головний тиристор `T1` проводить струм навантаження `I0`, який протягом короткого імпульсу комутації можна вважати незмінним через велику індуктивність навантаження (`L_load >> Lc`). Резонансний струм `i_c(t)` спрямований назустріч прямому струму тиристора:

```
i_T1(t) = I0 - i_c(t) = I0 - Ip · sin(ω0 · t)       [струм крізь головний тиристор]
```

У момент часу `t1`, коли резонансний струм сягає значення струму навантаження `i_c(t1) = I0`, прямий струм тиристора `i_T1` падає до нуля. Щойно `i_c(t)` перевищує `I0`, надлишковий струм `i_c(t) - I0` перехоплює зустрічно-паралельний діод `D1`. Поки діод `D1` відкритий, напруга на головному тиристорі затиснута на рівні прямого спаду діода `V_AK = -V_D ≈ -1.0 В`. Це від'ємне зміщення забезпечує розсмоктування надлишкових носіїв.

Знайдемо моменти часу `t1` (відмикання діода) та `t2` (закривання діода, коли `i_c(t)` спадає нижче `I0`):

```
Ip · sin(ω0 · t) = I0                               [умова рівності струмів]
sin(ω0 · t) = I0 / Ip = 1 / m                       [введення коефіцієнта кратності m = Ip / I0]
```

Коефіцієнт кратності `m = Ip / I0` мусить бути строго більшим за одиницю (`m > 1`), інакше струм тиристора ніколи не зменшиться до нуля і комутація взагалі не відбудеться.

Моменти часу визначаються через арксинус:

```
t1 = (1 / ω0) · arcsin(1 / m)                       [момент спаду струму тиристора до нуля]
t2 = (1 / ω0) · (π - arcsin(1 / m))                 [момент закривання зворотного діода]
```

Наданий схемою час вимикання `tc` — це тривалість інтервалу провідності діода `D1` між `t1` та `t2`:

```
tc = t2 - t1
= (1 / ω0) · [π - 2 · arcsin(1 / m)]                [різниця моментів часу]
= (2 / ω0) · arccos(1 / m)                          [тригонометрична тотожність: π/2 - arcsin(x) = arccos(x)]
= 2 · √(Lc · Cc) · arccos(1 / m)                    [підстановка власного періоду контуру]
```

### Критерій оптимального співвідношення `m = Ip / I0`

Енергія, що запасається в комутуючому конденсаторі перед кожним актом вимикання, дорівнює:

```
W_C = (1 / 2) · Cc · Vc0²                           [енергія електричного поля конденсатора]
```

Габарити, маса та вартість конденсатора прямо пропорційні його встановленій реактивній потужності та запасу енергії. Виразимо параметри `Cc` та `Lc` через відомий струм навантаження `I0`, початкову напругу `Vc0`, коефіцієнт `m` та необхідний час вимикання `tc`:

```
Ip = Vc0 · √(Cc / Lc) = m · I0                      [амплітуда коливального струму]
√(Lc / Cc) = Vc0 / (m · I0)                         [вираз для хвильового опору через m]
```

Перемноживши вирази для `tc` та `√(Cc / Lc)`:

```
tc · (1 / Z0) = [2 · √(Lc · Cc) · arccos(1 / m)] · [√(Cc / Lc)]
tc / Z0 = 2 · Cc · arccos(1 / m)                    [скорочення індуктивності Lc]
```

Звідси отримуємо точну формулу для мінімальної необхідної ємності комутуючого конденсатора:

```
Cc = (I0 · tc / Vc0) · [m / (2 · arccos(1 / m))]    [аналітичний вираз ємності]
```

Аналогічно, поділивши `tc` на `√(Cc / Lc)`:

```
Lc = (Vc0 · tc / I0) · [1 / (2 · m · arccos(1 / m))] [аналітичний вираз індуктивності]
```

Для мінімізації маси комутатора необхідно знайти значення `m`, за якого функція відносного розміру ємності сягає свого глобального мінімуму:

```
g(m) = m / (2 · arccos(1 / m))                      [безрозмірна функція ємності]
```

Дослідимо функцію `g(m)` на екстремум за аргументом `m`:

```
dg/dm = d/dm [m / (2 · arccos(1 / m))]
= [1 · (2 · arccos(1 / m)) - m · 2 · (-1 / √(1 - (1/m)²)) · (-1 / m²)] / [4 · arccos²(1 / m)] [диференціювання частки]
= [2 · arccos(1 / m) - (2 / (m · √(1 - 1/m²)))] / [4 · arccos²(1 / m)]                         [спрощення похідної]
```

Прирівнюючи чисельник похідної до нуля, отримуємо трансцендентне рівняння для точки оптимуму:

```
arccos(1 / m) = 1 / √(m² - 1)                       [рівняння оптимального параметра m]
```

Розв'язуючи це рівняння чисельними методами (методом послідовних наближень або Ньютона-Рафсона):
- при `m = 1.20` → `arccos(1/1.2) = 0.586 рад`, `1 / √(1.2² - 1) = 1.507` (похідна від'ємна, ємність надто велика через малий кут провідності діода);
- при `m = 1.45` → `arccos(1/1.45) = 0.808 рад`, `1 / √(1.45² - 1) = 0.953`;
- при `m = 1.53` → `arccos(1/1.53) = 0.858 рад`, `1 / √(1.53² - 1) = 0.862` (точка абсолютного мінімуму об'єму конденсатора);
- при `m = 2.00` → `arccos(1/2.0) = 1.047 рад`, `1 / √(2.0² - 1) = 0.577` (похідна додатна, ємність зростає через надмірну амплітуду струму `Ip`).

Мінімум габаритної енергії конденсатора досягається при `m ≈ 1.50 … 1.53`. На практиці обирають діапазон:

```
m_opt = 1.45 … 1.65                                 [інженерний діапазон оптимуму]
```

При цьому значенні безрозмірний коефіцієнт становить:

```
g(1.50) = 1.50 / (2 · arccos(1 / 1.50))
= 1.50 / (2 · 0.841)                                [arccos(0.6667) = 0.84106 рад = 48.19°]
= 1.50 / 1.682
= 0.892                                             [мінімальний множник ємності]
```

### Порівняння ємностей: комутація напругою проти комутації струмом

Проаналізуємо перевагу комутатора Мак-Мюррея над класичною схемою з паралельним конденсатором (комутація напругою). У схемі з паралельним конденсатором вимикання досягається експоненційним перезарядом через резистор навантаження `R_L`:

```
tc_parallel = R_L · C_par · ln(2)                   [час зворотного зміщення паралельної схеми]
C_par = tc / (ln(2) · R_L) = (I0 · tc / Vs) · (1 / ln(2)) [підстановка R_L = Vs / I0]
= (I0 · tc / Vs) · 1.443                            [множник ємності для паралельної схеми]
```

Співвідношення необхідних ємностей для однакових значень напруги джерела `Vs`, струму навантаження `I0` та часу зворотного зміщення `tc`:

```
C_par / Cc_mcmurray = 1.443 / g(m_opt)
= 1.443 / 0.892                                      [відношення розрахункових коефіцієнтів]
= 1.618                                             [паралельна схема вимагає на 62% більшої ємності]
```

Окрім зменшення ємності на 38%, комутатор Мак-Мюррея повністю усуває пряме розсіювання енергії конденсатора на баластному резисторі: якщо в паралельній схемі щотакту в тепло перетворюється енергія `W_loss = C_par · Vs²`, то в схемі Мак-Мюррея реактивна енергія перекачується назад у навантаження та джерело живлення, витрачаючись лише на малий активний опір коливального контуру.

### Динаміка зворотного відновлення тиристора `trr` та заряд `Qrr`

Під час спаду прямого струму тиристора зі швидкістю `di/dt` струм не зупиняється в нулі в момент `t1`, а змінює знак і утворює короткий імпульс зворотного струму `Irr`. Цей зворотний струм виносить вільні дірки та електрони з емітерних переходів `J1` та `J3`.

Кількість винесеного заряду `Qrr` залежить від попереднього прямого струму `I0` та швидкості спаду `di/dt`:

```
Qrr ≈ K_rr · I0^(0.5) · (di/dt)^(0.5)               [емпірична степенева модель розсмоктування]
```

де `K_rr` — конструктивний коефіцієнт кристала тиристора.

Тривалість фази зворотного відновлення `trr`:

```
trr = 2 · Qrr / Irr_peak                            [тривалість винесення носіїв]
Irr_peak = √(2 · Qrr · di/dt)                       [піковий зворотний струм відновлення]
```

Поки триває інтервал `trr`, зворотний струм `Irr` тече крізь тиристор у зворотному напрямку, віднімаючись від струму діода `D1`. Повне відновлення запірної здатності переходів `J1` і `J3` відбувається в кінці фази `trr`, після чого залишковий заряд `Q_base` у середній широкій n-базі рекомбінує за законом експоненційного спаду:

```
Q_base(t) = Q_base(trr) · exp(-(t - trr) / τ_p)    [експоненційне згасання носіїв у базі]
```

де `τ_p` — ефективний час життя неосновних носіїв (дірок) у слабколегованій n-базі (типово `10 … 30 мкс`). Тільки після зниження `Q_base(t)` нижче критичного порогу увімкнення `Q_crit` тиристор стає здатним утримувати пряму напругу.

### Друга фаза комутації: перезаряд конденсатора струмом навантаження

Після закривання зустрічно-паралельного діода `D1` у момент `t2` процес вимикання не завершується. На обкладках конденсатора `Cc` в момент `t2` залишається напруга:

```
v_c(t2) = Vc0 · cos(ω0 · t2)
= Vc0 · cos(π - arcsin(1/m))                        [підстановка моменту t2]
= -Vc0 · cos(arcsin(1/m))                           [формула зведення тригонометрії]
= -Vc0 · √(1 - 1/m²)                                [значення залишкової напруги]
```

При `m = 1.5` залишковий рівень становить `v_c(t2) = -Vc0 · √(1 - 1/2.25) = -0.745 · Vc0`.

Оскільки допоміжний тиристор `TA1` утримується відкритим, а головний `T1` уже закритий і блокує струм, постійний струм навантаження `I0` змушений текти крізь коливальну гілку `TA1 - Lc - Cc`, лінійно дозаряджаючи конденсатор до протилежної полярності:

```
v_c(t) = v_c(t2) + (I0 / Cc) · (t - t2)             [лінійний заряд постійним струмом навантаження]
```

Тривалість лінійної фази перезаряду `t_lin` до моменту, коли напруга сягає напруги шини живлення `Vs` (що викликає відмикання зворотного нульового діода навантаження або завершення такту), визначається виразом:

```
t_lin = Cc · (Vs - v_c(t2)) / I0
= Cc · [Vs + Vc0 · √(1 - 1/m²)] / I0                [тривалість лінійного етапу]
```

Якщо початкова напруга дорівнювала `Vc0 = Vs`, то повний перепад напруги на конденсаторі становить `ΔVc = Vs · (1 + √(1 - 1/m²)) ≈ 1.745 · Vs`.

Цей лінійний етап визначає швидкість наростання прямої напруги `dv/dt` на головному тиристорі після проходження нуля:

```
(dv/dt)|_reapplied = I0 / Cc                        [швидкість відновлення прямої напруги]
```

Якщо струм навантаження зростає, швидкість `dv/dt` збільшується пропорційно. Якщо вона перевищить критичну швидкість тиристора `(dv/dt)_crit`, ємнісний струм зміщення внутрішнього колекторного переходу `J2` (`i_j = C_j · dv/dt`) викличе самовільне відмикання приладу без сигналу керування. Тому паралельно до тиристора обов'язково встановлюється демпфувальне RC-коло (снабер).

### Розрахунок демпфувального RC-снабера

Паразитна індуктивність монтажу `L_stray` разом зі снаберним конденсатором `Cs` утворює високочастотний коливальний контур. Для запобігання резонансному перерегулюванню та обмеження швидкості наростання напруги спад навантажується резистором `Rs`:

```
Rs = 2 · √(L_stray / Cs)                            [умова критичного аперіодичного демпфування]
```

При цьому швидкість наростання напруги на тиристорі обмежується величиною:

```
(dv/dt)_max ≈ Vs / (Rs · Cs)                        [максимальна швидкість наростання зі снабером]
```

Енергія, що розсіюється на снаберному резисторі `Rs` за один комутаційний такт:

```
W_snubber = (1 / 2) · Cs · Vs²                      [втрати енергії в снабері за такт]
```

### Перенапруги від паразитної індуктивності монтажу

У реальній силовій установці провідники шин живлення мають паразитну індуктивність `L_stray` (типово `0.1 … 0.5 мкГн` на метр шини). У момент, коли напруга на конденсаторі досягає `Vs` і струм навантаження починає переходити у зворотний діод вільного ходу, в паразитної індуктивності шини залишається запас магнітної енергії:

```
W_mag = (1 / 2) · L_stray · I0²                     [магнітна енергія розсіювання]
```

Ця енергія спричиняє додатковий резонансний перезаряд ємності `Cc`, що призводить до сплеску перенапруги на ключах понад напругу джерела:

```
(1/2) · Cc · V_peak² = (1/2) · Cc · Vs² + (1/2) · L_stray · I0² [баланс енергії]
V_peak = √(Vs² + (L_stray / Cc) · I0²)              [пікова напруга на елементах схеми]
```

Звідси випливає фундаментальна вимога: клас тиристорів за повторюваною напругою `V_DRM / V_RRM` слід обирати не за напругою живлення `Vs`, а з урахуванням комутаційного викиду:

```
V_DRM ≥ (1.3 … 1.5) · V_peak                        [вибір робочої напруги приладів]
```

### Тепловий розрахунок діелектрика конденсатора комутації

Комутуючий конденсатор працює у важкому імпульсному режимі з високим діючим струмом (RMS). Діюче значення струму крізь конденсатор за період комутації `T_sw = 1 / f_sw`:

```
I_c_rms = √((1 / T_sw) · ∫₀^(π/ω0) (Ip · sin(ω0 · t))² dt + (1 / T_sw) · ∫₀^(t_lin) I0² dt) [інтеграл середньоквадратичного струму]
= √((f_sw · Ip² · π) / (2 · ω0) + f_sw · I0² · t_lin) [аналітичний вираз діючого струму]
```

Теплова потужність, що виділяється у внутрішньому об'ємі конденсатора через діелектричні втрати та опір металізації обкладок:

```
P_cap = I_c_rms² · ESR = I_c_rms² · (tg δ / (ω0 · Cc)) [потужність теплових втрат конденсатора]
```

де `tg δ` — тангенс кута діелектричних втрат (для імпульсного поліпропілену `tg δ ≈ (2 … 5) · 10⁻⁴`).

### Модифікація Мак-Мюррея-Бедфорда: магнітний реверс енергії

Подальшим розвитком резонансного комутатора Мак-Мюррея стала схема Мак-Мюррея-Бедфорда (McMurray-Bedford circuit). У ній резонансна котушка виконується у вигляді імпульсного автотрансформатора із середньою точкою та жорстким магнітним зв'язком між секціями (`k_magn ≈ 1`).

Коли вмикається черговий тиристор стійки `T2`, напруга джерела `Vs` миттєво прикладається до його секції котушки. Завдяки взаємоіндукції на сусідній секції индукується точно така ж проти-ЕРС `e_ind = Vs`, яка сумується з напругою шини й прикладає до закритого головного тиристора `T1` подвоєну зворотну напругу `-2 · Vs`. Це викликає негайне замикання струму `T1` до нуля без потреби в окремому допоміжному тиристорі, скорочуючи загальну кількість напівпровідникових ключів у перетворювачі вдвічі.

При проектуванні імпульсного трансформатора Мак-Мюррея-Бедфорда критично важливим є розрахунок магнітного насичення осердя. Площа перерізу магнітопроводу `S_core` та кількість витків `N` секції розраховуються за вольт-секундним інтегралом комутаційного імпульсу:

```
∫₀^(tc) Vs dt = Vs · tc ≤ N · S_core · ΔB_max       [умова ненасичення магнітопроводу комутатора]
```

де `ΔB_max = B_sat - B_rem` — максимальний робочий розмах магнітної індукції феритового або порошкового матеріалу (типово `0.3 … 0.6 Тл`). Якщо осердя входить у насичення раніше моменту `t2`, динамічна індуктивність `Lc = dΨ/di` різко падає в десятки разів, хвильовий опір `Z0` падає до нуля, і виникає катастрофічний сплеск надструму через ключі.

Для мінімізації високочастотних втрат на скін-ефект в обмотках комутуючої котушки `Lc` товщина провідника обирається з урахуванням глибини проникнення струму `Δ_skin` на резонансній частоті `f0`:

```
Δ_skin = √(ρ_cu / (π · μ0 · f0))                     [глибина проникнення змінного струму в мідь]
```

При частоті комутації `f0 = 8.22 кГц` глибина скін-шару становить `Δ_skin ≈ 0.72 мм`. Тому для виготовлення котушки використовують багатожильний літцендрат або мідну фольгу з товщиною стрічки менше `2 · Δ_skin = 1.44 мм`, що усуває локальний перегрів обмотки імпульсним струмом амплітудою в сотні ампер.

### Чутливість схеми до зміни навантаження: межі стійкості

Аналітичний аналіз показує дві критичні крайові небезпеки для комутатора Мак-Мюррея:

1. **Режим перевантаження за струмом (`I_load > Ip`):**
Якщо струм навантаження внаслідок пуску двигуна або короткого замикання зросте настільки, що `I0 > Ip` (тобто `m < 1`), рівняння `sin(ω0 · t) = 1/m` втрачає дійсні корені. Струм коливального імпульсу не зможе скомпенсувати струм навантаження, струм тиристора `T1` не впаде до нуля, діод `D1` не відімкнеться взагалі, і тиристор залишиться у стані провідності. Це призводить до класичного **зриву комутації** та короткого замикання джерела через силову стійку.

2. **Режим холостого ходу або малого навантаження (`I_load → 0`):**
При `I0 → 0` коефіцієнт `m → ∞`. Час `tc` сягає свого максимуму `tc_max = π / ω0 = π · √(Lc · Cc)`, проте конденсатор не може завершити лінійну фазу перезаряду через відсутність струму розряду в навантаження. Полярність напруги на `Cc` залишається оберненою, і перед наступним комутаційним циклом виникає потреба у спеціальному допоміжному колі реверсу заряду.

### Покроковий розрахунок контуру комутації (числовий приклад)

Розрахуємо параметри комутатора Мак-Мюррея для силового DC-чопера тягового електропривода з такими технічними характеристиками:
- напруга контактної мережі / шини живлення: `Vs = 600 В`;
- номінальний струм навантаження: `I0 = 150 А`;
- паспортний час вимикання силового тиристора: `tq = 20 мкс` при температурі кристала `125 °C`;
- коефіцієнт запасу надійності: `ks = 1.6`;
- обраний коефіцієнт кратності струму: `m = 1.5`;
- паразитний опір коливального контуру: `r = 0.04 Ом`;
- паразитні індуктивності шинного монтажу: `L_stray = 0.8 мкГн`.

#### Крок 1: Розрахунок необхідного часу схеми `tc`

```
tc = ks · tq
= 1.6 · 20 мкс                                      [підстановка коефіцієнта запасу]
= 32.0 мкс                                          [розрахунковий час зворотного зміщення]
```

#### Крок 2: Розрахунок ємності комутуючого конденсатора `Cc`

Вважаємо початкову напругу конденсатора рівною напрузі шини `Vc0 = Vs = 600 В`:

```
Cc = (I0 · tc / Vc0) · g(m)
= (150 · 32.0 · 10⁻⁶ / 600) · 0.892                 [підстановка значень струму й напруги]
= (4.8 · 10⁻³ / 600) · 0.892                        [обчислення добутку]
= 8.0 · 10⁻⁶ · 0.892                                [базова ємність]
= 7.14 · 10⁻⁶ Ф = 7.14 мкФ                          [розрахункова ємність]
```

Обираємо стандартний імпульсний поліпропіленовий конденсатор номіналом `Cc = 7.5 мкФ`.

#### Крок 3: Розрахунок індуктивності комутуючої котушки `Lc`

```
Lc = (Vc0 · tc / I0) · [1 / (2 · m · arccos(1 / m))]
= (600 · 32.0 · 10⁻⁶ / 150) · [1 / (2 · 1.5 · 0.841)] [підстановка параметрів]
= (19.2 · 10⁻³ / 150) · [1 / 2.523]                 [обчислення відношення]
= 0.128 · 10⁻³ · 0.396
= 50.7 · 10⁻⁶ Гн = 50.7 мкГн                        [розрахункова індуктивність]
```

Обираємо високочастотну котушку індуктивністю `Lc = 50 мкГн`.

#### Крок 4: Перевірка динамічних параметрів коливального контуру

Власна частота та хвильовий опір реалізованого контуру:

```
Z0 = √(Lc / Cc)
= √(50 · 10⁻⁶ / 7.5 · 10⁻⁶)                         [підстановка обраних номіналів]
= √6.667 = 2.58 Ом                                  [характеристичний опір]

Ip = Vc0 / Z0
= 600 / 2.58                                        [амплітуда резонансного струму]
= 232.5 А                                           [піковий струм допоміжного тиристора]

m_real = Ip / I0
= 232.5 / 150 = 1.55                                [дійсна кратність струму]

ω0 = 1 / √(Lc · Cc)
= 1 / √(50 · 10⁻⁶ · 7.5 · 10⁻⁶)                     [підстановка величин]
= 1 / √(375 · 10⁻¹²) = 1 / (19.36 · 10⁻⁶)
= 51640 рад/с (f0 ≈ 8.22 кГц)                       [резонансна частота комутації]

tc_real = 2 · √(Lc · Cc) · arccos(1 / m_real)
= 2 · (19.36 · 10⁻⁶) · arccos(1 / 1.55)
= 38.72 · 10⁻⁶ · arccos(0.645)                      [arccos(0.645) = 0.869 рад = 49.8°]
= 38.72 · 10⁻⁶ · 0.869
= 33.6 мкс                                          [фактичний час tc > 32.0 мкс, умова виконана]
```

#### Крок 5: Оцінка швидкості наростання струму `di/dt`

Швидкість наростання струму в допоміжному тиристорі `TA1` у момент відмикання `t = 0`:

```
di/dt|_max = Vc0 / Lc
= 600 / (50 · 10⁻⁶)                                 [напруга поділена на індуктивність]
= 12 · 10⁶ А/с = 12 А/мкс                           [швидкість наростання]
```

Отримане значення `12 А/мкс` знаходиться далеко нижче критичної межі паспортного значення для швидкодіючих тиристорів (типово `(di/dt)_crit = 100 … 500 А/мкс`), що гарантує відсутність локальних теплових пробоїв у кристалі біля керівного електрода.

#### Крок 6: Оцінка пікової напруги та комутаційних втрат

Пікова перенапруга з урахуванням паразитної індуктивності монтажу `L_stray = 0.8 мкГн`:

```
V_peak = √(Vs² + (L_stray / Cc) · I0²)
= √(600² + (0.8 · 10⁻⁶ / 7.5 · 10⁻⁶) · 150²)        [підстановка параметрів монтажу]
= √(360000 + 0.1067 · 22500)
= √(360000 + 2400) = √362400
= 602 В                                             [динамічний викид напруги]
```

Енергія активних втрат у контурі за один комутаційний такт:

```
W_loss ≈ (1 / 2) · r · Ip² · (π / ω0)
= 0.5 · 0.04 · (232.5)² · (3.1416 / 51640)          [інтегрування втрат на активному опорі]
= 0.02 · 54056 · (60.8 · 10⁻⁶)
= 1081 · (60.8 · 10⁻⁶) = 0.0657 Дж                  [теплові втрати за один імпульс]
```

При робочій частоті комутації `f_sw = 500 Гц` середня потужність теплових втрат у коливальному контурі комутатора складе:

```
P_loss = W_loss · f_sw
= 0.0657 · 500 = 32.85 Вт                           [потужність розсіювання в котушці та ESR конденсатора]
```

Ці 33 вати тепла мають бути розсіяні системою охолодження реактивних компонентів комутатора без неприпустимого перегріву діелектрика конденсатора.
