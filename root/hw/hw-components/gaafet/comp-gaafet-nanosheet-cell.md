# 🔌 Анатомія стандартної комірки на наношарах: паразитна ємність внутрішніх спейсерів, NanoFlex та саморозігрів

Перехід від тривимірних ребер FinFET до горизонтальних наношарів GAAFET докорінно змінив принципи проектування [стандартних логічних комірок](root:hw-components/standard-cell) *(standard cells)*. Якщо у FinFET розробник топології був жорстко обмежений дискретним квантуванням струму цілими ребрами, то архітектура наношарів дозволила безперервно варіювати ширину каналу `W_ns`, створивши нову парадигму бібліотек цифрових елементів. Проте ця свобода супроводжується двома важкими фізичними розплатами: паразитною ємністю внутрішніх діелектричних спейсерів та ефектом локального саморозігріву затиснутих у діелектрику кремнієвих пластин.

### Геометрія та висота стандартної комірки (Cell Track Height)

У сучасних технологічних процесах 3 нм та 2 нм висота стандартної комірки вимірюється кількістю паралельних горизонтальних доріжок металізації першого шару *(Metal 1, M1)*, що вміщуються між шинами живлення:

```
H_cell = N_tracks · Track_Pitch
```

де `N_tracks` — висота комірки в треках (позначення `5T`, `4.5T` або `4T`), `Track_Pitch` — крок між металевими доріжками (для вузла 2 нм `Track_Pitch ≈ 22–24 нм`).

У технології FinFET висота комірки визначалася кількістю вертикальних ребер, які можна фізично розмістити між межами комірки з урахуванням кроку ребер *(Fin Pitch, FP ≈ 24–27 нм)*:
- У комірці `6T` містилося 2 ребра для nMOS та 2 ребра для pMOS (сумарно 4 ребра);
- У комірці `5T` вдавалося розмістити лише 1 ребро для nMOS та 1 ребро для pMOS. Це спричиняло падіння струму на 50% і обмежувало швидкодію критичних шляхів логіки.

У наношарах GAAFET один вертикальний стос із 3 або 4 наношарів займає ту саму площу пластини, що й одне ребро FinFET, але забезпечує довільно регульовану ефективну ширину `W_eff`:
- Ширина наношару `W_ns` може плавно змінюватися від 15 нм (для комірок надвисокої щільності та малого споживання) до 45–50 нм (для потужних буферів дерева тактових сигналів);
- Вертикальний крок між наношарами `T_sus` (товщина металевого затвора між сусідніми шарами) становить 8–10 нм;
- Завдяки відсутності потреби в паралельних ребрах стандартні комірки на наношарах успішно масштабуються до ультракомпактної висоти **4.5T та 4.0T** (висота комірки менш ніж 100 нм).

### Крок затворів (CPP) та проміжний рівень з'єднань MOL

Горизонтальний розмір стандартної комірки по осі `x` визначається кроком контактів затворів *(Contacted Poly Pitch, CPP)*:

```
W_cell = N_gates · CPP
```

Для технологічних вузлів 3GAP та N2 значення `CPP` становить **45–50 нм**. На цій мікроскопічній відстані розміщуються:
1. Фізична довжина металевого затвора: `L_g ≈ 12–14 нм`;
2. Два зовнішні діелектричні спейсери затвора: `2 · L_sp,out ≈ 10–12 нм`;
3. Епітаксійний контакт витоку/стоку з металевим переходом: `L_cont ≈ 18–22 нм`.

Для з'єднання транзисторів всередині комірки використовують проміжний рівень металізації *(Middle-of-Line, MOL)*, що містить вертикальні контакти до затвора (CB / Gate Contact) та до витоку/стоку (CA / S/D Contact). У комірках на наношарах контакт CA повинен забезпечувати пряме торцеве затікання струму в усі три поверхи наношарів одночасно. Будь-яке зміщення контакту CA під час літографії викликає різке зростання опору `R_s` для нижніх шарів стосу.

### Доступність пінів і правила проектування DRC у 4.5T-комірках

Зменшення висоти комірки до 4.5T створює критичну проблему **доступності виводів** *(Pin Access)* для автоматичного трасувальника САПР (Router). Коли верхня та нижня колії M1 зайняті шинами живлення VDD та VSS, для сигнальних входів і виходів (A, B, Y) залишається лише 2.5 вільні доріжки металізації.

Щоб уникнути порушень геометричних правил проектування *(Design Rule Check, DRC)* та стохастичних дефектів EUV-літографії (замикання кінців сусідніх доріжок, *tip-to-tip bridging*), застосовують такі топологічні рішення:
- **Зсув пінів по осі X (Staggered Pin Placement):** вхідні контакти затворів розташовують не на одній лінії, а зсувають на один крок сітки CPP, щоб уникнути конфліктів між паралельними лініями M1;
- **Двоповерхові комірки (Multi-Height Cells):** складні логічні елементи (D-тригери, повні суматори, мультиплексори) проектують як високі комірки подвійної висоти (9T = 2 × 4.5T), де шина живлення проходить посередині, надаючи вдвічі більше внутрішніх каналів для внутрішньокоміркової комутації.

### Внутрішні спейсери (Inner Spacers): геометрія та діелектричні матеріали

Найбільш критичним конструктивним елементом транзистора на наношарах є **внутрішні спейсери** *(inner spacers)* — мініатюрні діелектричні ізолятори, розташовані між сусідніми наношарами кремнію безпосередньо під зовнішніми торцями затвора.

Внутрішній спейсер виконує дві незамінні функції:
1. **Фізична ізоляція затвора від витоку й стоку:** під час селективного витравлювання жертовних шарів SiGe внутрішній спейсер блокує проникнення хімічного травителя в область легованих контактів S/D, а під час подальшого осадження металу затвора (RMG) запобігає прямому електричному замиканню металевого затвора на витік і стік.
2. **Екранування паразитної ємності перекриття:** він мінімізує ємнісний зв'язок `C_gd` та `C_gs` між металом затвора в міжнаношарових щілинах та легованими областями витоку й стоку.

Паразитна ємність одного внутрішнього спейсера для стосу з `N_ns` наношарів описується формулою:

```
C_inner_spacer = 2 · (N_ns - 1) · (ε_sp / L_sp) · W_ns · T_sus
```

де `ε_sp` — діелектрична проникність матеріалу спейсера, `L_sp` — довжина спейсера вздовж каналу (`5–6 нм`), `T_sus` — вертикальна товщина спейсера (`8–10 нм`), `W_ns` — ширина наношару.

Вибір матеріалу для внутрішнього спейсера вимагає складного компромісу між електричною ємністю та хімічною стійкістю:
- **Нітрид кремнію (Si₃N₄):** має відносно високу діелектричну проникність `k ≈ 7.0–7.5`, що призводить до неприпустимого зростання паразитної ємності затвора `C_gg` на 20–25% і падіння швидкодії мікросхеми.
- **Діоксид кремнію (SiO₂):** має низьку проникність `k ≈ 3.9`, але легко розчиняється у плавиковій кислоті (HF), яка використовується під час подальших технологічних промивань, що викликає руйнування ізолятора та короткі замикання.
- **Низькопроникні оксикарбонітриди кремнію та бору (SiBCN, SiOCN):** мають діелектричну проникність `k ≈ 4.0–4.5` та колосальну хімічну стійкість проти ізотропних травителів SiGe. Сьогодні плівки SiBCN, осаджені методом атомарно-шарового осадження (ALD), є світовим стандартом для внутрішніх спейсерів GAAFET.

### Технологія NanoFlex: безперервне масштабування ширини каналу

Однією з головних архітектурних інновацій, що стали можливими виключно на наношарах, є технологія **NanoFlex** (термінологія TSMC, аналогічні підходи застосовують Samsung та Intel).

У межах однієї стандартної бібліотеки логічних вентилів формують три типи комірок:
1. **Високопродуктивні комірки (High Performance, HP):**
   Використовують максимально широкі наношари `W_ns = 40–50 нм`. Забезпечують максимальний струм насичення `I_on > 1.8 мА/мкм` для прискорення критичних шляхів інструкцій процесора, блоків АЛП та драйверів шин пам'яті.
2. **Збалансовані комірки (Standard Density, HD):**
   Використовують середню ширину `W_ns = 25–35 нм`. Оптимальні для типових логічних вентилів комбінаційної логіки.
3. **Комірки наднизького споживання (Ultra-High Density, uHD):**
   Використовують вузькі наношари `W_ns = 15–20 нм`. Завдяки мінімальній площі затвора струм підпорогового витоку `I_off` скорочується у 3–4 рази, що ідеально підходить для контролерів живлення, блоків Always-On та комірок кеш-пам'яті SRAM.

САПР топологічного проектування (EDA) автоматично змішує комірки різної ширини на кристалі, розміщуючи швидкі широкі транзистори лише на критичних лініях затримки сигналу, що дозволяє оптимізувати загальний баланс швидкості та енергоспоживання кристала.

Схемотехніки також використовують асиметрію ширини `W_p / W_n` для вирівнювання затримок фронту (Rise Time) та спаду (Fall Time) логічних вентилів. Оскільки рухливість дірок у кремнії нижча за рухливість електронів (`μ_h ≈ μ_e / 2`), у планарних технологіях доводилося робити pMOS удвічі ширшим за nMOS, що збільшувало площу комірки. У GAAFET розробники або збільшують ширину наношарів pMOS `W_ns,p = 1.6 · W_ns,n`, або замінюють матеріал каналу pMOS на кремній-германій `Si₀.₅Ge₀.₅`, де рухливість дірок зростає втричі завдяки ефекту одновісного стиснення ґратки.

### Ефект саморозігріву (Self-Heating Effect, SHE)

Найбільш небезпечним експлуатаційним викликом для наношарів є **ефект локального саморозігріву** *(Self-Heating Effect, SHE)*.

Під час протікання великого струму відкритого стану `I_on` у кремнієвому каналі розсіюється значна теплова потужність джоулевого нагріву:

```
P_heat = I_d · V_ds
```

У планарному MOSFET тепло вільно відводилося вниз через масивну монокристалічну кремнієву підкладку, теплопровідність якої за кімнатної температури становить високі `κ_bulk ≈ 148 Вт/(м·К)`.

У GAAFET кремнієві наношари виявляються **теплоізольованими пастками**:
1. **Зниження теплопровідності кремнію:** у наношарі товщиною `T_ns = 5 нм` довжина вільного пробігу теплових фононів (`≈ 40–100 нм` у масивному кремнії) різко обмежується постійними зіткненнями з межами наношару (дифузне фононне розсіювання). Теплопровідність надтонкої кремнієвої плівки падає з `148 Вт/(м·К)` до мізерних `κ_ns ≈ 15–25 Вт/(м·К)`.
2. **Діелектричне оточення:** зверху, знизу та з боків кожен наношар оточений шарами HfO₂ (`κ ≈ 1–2 Вт/(м·К)`), внутрішніми спейсерами SiBCN (`κ ≈ 1.5 Вт/(м·К)`) та міжшаровими діелектриками ILD (SiO₂, `κ ≈ 1.3 Вт/(м·К)`).
3. **Середній шар стосу:** найбільше розігрівається середній наношар у 3- або 4-шаровому стосі, оскільки він не має прямого контакту ні з підкладкою, ні з верхніми шарами металізації.

Локальний перегрів каналу `ΔT_channel` може досягати **40–60 °C** вище за загальну температуру кристала. Це спричиняє деградацію рухливості електронів через розсіювання на теплових фононах, прискорює деградацію підзатворного діелектрика через часозалежний пробій (TDDB) та викликає небезпечну електродифузію металевих контактів стоку.

### Програмне моделювання параметрів стандартної комірки

Наведений нижче програмний модуль моделює параметри стандартної логічної комірки GAAFET: розраховує ефективну ширину каналу `W_eff`, компоненти паразитної ємності затвора, квазібалістичний струм насичення, локальний тепловий опір та власну затримку перемикання комірки `t_pd`.

:::tabs
```c
#include <stdio.h>
#include <math.h>

/* Структура геометричних та фізичних параметрів наношару GAAFET */
typedef struct {
    double w_ns_nm;     /* Ширина наношару (нм) */
    double t_ns_nm;     /* Товщина наношару (нм) */
    double l_gate_nm;   /* Довжина затвора L_g (нм) */
    int    n_sheets;    /* Кількість наношарів у стосі */
    double eot_nm;      /* Еквівалентна товщина діелектрика EOT (нм) */
    double l_sp_nm;     /* Товщина внутрішнього спейсера (нм) */
    double k_spacer;    /* Діелектрична проникність спейсера (SiBCN = 4.2) */
    double v_dd;        /* Напруга живлення (В) */
} gaafet_cell_params_t;

/* Структура вихідних розрахункових характеристик комірки */
typedef struct {
    double w_eff_total_nm;   /* Повна ефективна ширина каналу (нм) */
    double c_channel_ff;     /* Ємність каналу (фемтофаради) */
    double c_spacer_ff;      /* Паразитна ємність внутрішніх спейсерів (фФ) */
    double c_total_gate_ff;  /* Сумарна ємність затвора (фФ) */
    double i_on_ma;          /* Струм відкритого стану (мА) */
    double delay_ps;         /* Власна затримка перемикання вентиля (пс) */
    double delta_t_she_c;    /* Локальний саморозігрів каналу (градуси C) */
} gaafet_cell_results_t;

/* Функція чисельного моделювання характеристик комірки */
gaafet_cell_results_t evaluate_gaafet_cell(const gaafet_cell_params_t *p) {
    gaafet_cell_results_t res;
    const double eps0 = 8.854187e-12;   /* Ф/м */
    const double eps_sio2 = 3.9;

    /* 1. Розрахунок повної ефективної ширини каналу */
    double perim_one_sheet = 2.0 * p->w_ns_nm + 2.0 * p->t_ns_nm;
    res.w_eff_total_nm = (double)p->n_sheets * perim_one_sheet;

    /* 2. Ємність інверсійного каналу: C_gc = W_eff * L_g * (eps_ox / EOT) */
    double c_ox_density = (eps_sio2 * eps0) / (p->eot_nm * 1e-9); /* Ф/м^2 */
    double area_channel_m2 = (res.w_eff_total_nm * 1e-9) * (p->l_gate_nm * 1e-9);
    res.c_channel_ff = (area_channel_m2 * c_ox_density) * 1e15;

    /* 3. Паразитна ємність внутрішніх спейсерів (між сусідніми шарами) */
    double eps_sp = p->k_spacer * eps0;
    double t_sus_nm = 9.0; /* Типовий зазор між наношарами */
    double cap_one_spacer = eps_sp * (p->w_ns_nm * 1e-9) * (t_sus_nm * 1e-9) / (p->l_sp_nm * 1e-9);
    /* 2 спейсери (витік і стік) для кожного з (n_sheets - 1) проміжків */
    res.c_spacer_ff = (2.0 * (double)(p->n_sheets - 1) * cap_one_spacer) * 1e15;

    /* Сумарна ємність затвора з урахуванням оверлапу */
    res.c_total_gate_ff = res.c_channel_ff + res.c_spacer_ff + 0.15 * res.c_channel_ff;

    /* 4. Квазібалістичний струм насичення I_on (приймаємо густину ~1.45 мА/мкм W_eff) */
    double current_density_ma_per_um = 1.45;
    res.i_on_ma = (res.w_eff_total_nm / 1000.0) * current_density_ma_per_um * (p->v_dd / 0.7);

    /* 5. Власна затримка вентиля: t_delay = C_total * V_dd / I_on */
    res.delay_ps = (res.c_total_gate_ff * 1e-15 * p->v_dd / (res.i_on_ma * 1e-3)) * 1e12;

    /* 6. Оцінка локального саморозігріву (SHE) */
    /* Тепловий опір наношару R_th ~ 85 К/мВт на 1 наношар */
    double p_diss_mw = res.i_on_ma * p->v_dd * 0.15; /* 15% робочого коефіцієнта активності */
    double r_th_stack = 85.0 / (double)p->n_sheets;
    res.delta_t_she_c = p_diss_mw * r_th_stack;

    return res;
}

int main(void) {
    gaafet_cell_params_t hp_cell = {
        .w_ns_nm = 40.0, .t_ns_nm = 5.0, .l_gate_nm = 12.0,
        .n_sheets = 3, .eot_nm = 0.8, .l_sp_nm = 5.5,
        .k_spacer = 4.2, .v_dd = 0.7
    };

    gaafet_cell_results_t r = evaluate_gaafet_cell(&hp_cell);
    printf("GAAFET 2nm Cell Evaluation:\n");
    printf("  W_eff total : %.1f nm\n", r.w_eff_total_nm);
    printf("  C_gate      : %.3f fF (Channel: %.3f, Spacer: %.3f)\n",
           r.c_total_gate_ff, r.c_channel_ff, r.c_spacer_ff);
    printf("  I_on        : %.3f mA\n", r.i_on_ma);
    printf("  Cell Delay  : %.2f ps\n", r.delay_ps);
    printf("  Self-Heating: +%.1f C\n", r.delta_t_she_c);
    return 0;
```

```cpp
#include <iostream>
#include <cmath>
#include <vector>
#include <span>
#include <string_view>
#include <iomanip>

struct NanosheetGeometry {
    double width_nm{35.0};
    double thickness_nm{5.0};
    double gate_length_nm{12.0};
    std::size_t sheet_count{3};
    double eot_nm{0.8};
    double spacer_length_nm{5.5};
    double spacer_dielectric_k{4.2};
    double supply_voltage_v{0.7};
};

struct StandardCellMetrics {
    double effective_width_nm{0.0};
    double channel_capacitance_ff{0.0};
    double inner_spacer_capacitance_ff{0.0};
    double total_gate_capacitance_ff{0.0};
    double drive_current_ma{0.0};
    double propagation_delay_ps{0.0};
    double self_heating_delta_t_c{0.0};
};

class NanosheetCellAnalyzer {
public:
    static constexpr double VacuumPermittivity = 8.854187e-12; // F/m
    static constexpr double Sio2RelativePermittivity = 3.9;

    [[nodiscard]] static StandardCellMetrics analyze(const NanosheetGeometry& geom) noexcept {
        StandardCellMetrics out;

        // 1. Повна ефективна ширина каналу
        const double perimeter = 2.0 * (geom.width_nm + geom.thickness_nm);
        out.effective_width_nm = static_cast<double>(geom.sheet_count) * perimeter;

        // 2. Ємність каналу інверсії
        const double c_ox_density = (Sio2RelativePermittivity * VacuumPermittivity) /
                                    (geom.eot_nm * 1e-9);
        const double channel_area_m2 = (out.effective_width_nm * 1e-9) *
                                       (geom.gate_length_nm * 1e-9);
        out.channel_capacitance_ff = (channel_area_m2 * c_ox_density) * 1e15;

        // 3. Паразитна ємність внутрішніх спейсерів
        constexpr double VerticalSuspensionGapNm = 9.0;
        const double eps_spacer = geom.spacer_dielectric_k * VacuumPermittivity;
        const double single_spacer_cap = eps_spacer * (geom.width_nm * 1e-9) *
                                         (VerticalSuspensionGapNm * 1e-9) /
                                         (geom.spacer_length_nm * 1e-9);

        const auto spacer_layers = static_cast<double>(geom.sheet_count - 1);
        out.inner_spacer_capacitance_ff = (2.0 * spacer_layers * single_spacer_cap) * 1e15;
        out.total_gate_capacitance_ff = out.channel_capacitance_ff * 1.15 +
                                        out.inner_spacer_capacitance_ff;

        // 4. Струм насичення I_on
        constexpr double BaseDriveDensityMaPerUm = 1.45;
        out.drive_current_ma = (out.effective_width_nm / 1000.0) *
                               BaseDriveDensityMaPerUm *
                               (geom.supply_voltage_v / 0.7);

        // 5. Власна затримка вентиля
        out.propagation_delay_ps = (out.total_gate_capacitance_ff * 1e-15 * geom.supply_voltage_v /
                                   (out.drive_current_ma * 1e-3)) * 1e12;

        // 6. Оцінка локального саморозігріву
        constexpr double BaseThermalResistancePerSheet = 85.0; // K/mW
        const double p_diss_mw = out.drive_current_ma * geom.supply_voltage_v * 0.15;
        const double r_th_stack = BaseThermalResistancePerSheet / static_cast<double>(geom.sheet_count);
        out.self_heating_delta_t_c = p_diss_mw * r_th_stack;

        return out;
    }
};

int main() {
    const std::vector<std::pair<std::string_view, NanosheetGeometry>> library_cells = {
        {"High-Performance (HP)  ", NanosheetGeometry{.width_nm = 45.0, .sheet_count = 3}},
        {"Standard-Density (HD)  ", NanosheetGeometry{.width_nm = 30.0, .sheet_count = 3}},
        {"Ultra-High-Density (uHD)", NanosheetGeometry{.width_nm = 18.0, .sheet_count = 3}}
    };

    std::cout << std::fixed << std::setprecision(2);
    std::cout << "=== GAAFET Nanosheet Standard Cell Library Analysis ===\n";
    for (const auto& [cell_name, config] : library_cells) {
        const auto metrics = NanosheetCellAnalyzer::analyze(config);
        std::cout << "[" << cell_name << "] W_eff: " << std::setw(5) << metrics.effective_width_nm
                  << " nm | I_on: " << metrics.drive_current_ma << " mA | Delay: "
                  << metrics.propagation_delay_ps << " ps | SHE: +"
                  << metrics.self_heating_delta_t_c << " °C\n";
    }
    return 0;
}
```
