# 🧮 Математика дератингу: модель Арреніуса, інтенсивність відмов та коефіцієнти прискорення

Ця математична вставка містить аналітичне виведення законів надійності, що лежать в основі концепції дератингу: фізико-хімічного рівняння Сванте Арреніуса для швидкості деградації матеріалів, коефіцієнтів температурного прискорення старіння (Acceleration Factor), степеневих моделей електричного стресу напруги, моделей електроміграції Блека (Black's Equation), термомеханічної втоми Коффіна-Менсона (Coffin-Manson Model), рівняння Норріса-Ландзберга (Norris-Landzberg Model) та розрахунку інтенсивності відмов `λ(t)` і середнього напрацювання на відмову (MTBF / MTTF) за розподілами Вейбулла та експоненційним законом.

Вона дає інженеру математичний інструмент для строгого кількісного обґрунтування вибору робочих режимів замість сліпого слідування емпіричним нормам.

## 1. Фізико-хімічна основа: рівняння Арреніуса

Більшість незворотних відмов в електронних компонентах — це наслідок повільних термохімічних реакцій або дифузійних процесів: окиснення металізації, взаємна дифузія атомів легувальних домішок у напівпровідниковому кристалі, утворення інтерметалідів у паяних з'єднаннях, випаровування рідкого розчинника крізь ущільнювач конденсатора, розрив полімерних зв'язків ізоляції.

Швидкість будь-якої подібної термічно активованої реакції `k_r` описується рівнянням, яке 1889 року сформулював шведський фізик і хімік Сванте Арреніус (швед. *Svante Arrhenius*):

```
k_r = A · exp( −E_a / (k_B · T) )
```

У цьому виразі:
- `k_r` — швидкість протікання процесу деградації (розмірність `1/с`);
- `A` — предекспоненційний множник (частотний фактор зіткнення частинок);
- `E_a` — енергія активації конкретного механізму відмови (вимірюється в електронвольтах, еВ, або Джоулях, Дж);
- `k_B` — стала Больцмана, яка пов'язує температуру з кінетичною енергією частинок (`k_B = 8.617333262 · 10⁻⁵ еВ/К` або `1.380649 · 10⁻²³ Дж/К`);
- `T` — абсолютна термодинамічна температура в Кельвінах (`T = t[°C] + 273.15`).

Фізичний зміст енергії активації `E_a` — це енергетичний бар'єр, який атом чи молекула повинні подолати за рахунок хаотичного теплового руху, щоб вступити в хімічну реакцію або здійснити дифузійний стрибок у кристалічній ґратці. Чим вища температура `T`, тим більша частка частинок має кінетичну енергію, що перевищує `E_a`, і тим стрімкіше деградує структура компонента.

## 2. Виведення коефіцієнта температурного прискорення (AF_T)

Якщо деталь експлуатується за підвищеної температури кристала `T₁` замість зниженої розрахункової температури `T₂` (де `T₁ > T₂`), швидкість її деградації зростає. Відношення швидкостей деградації при двох різних температурах називають **коефіцієнтом температурного прискорення** (англ. *Temperature Acceleration Factor*, `AF_T`):

```
AF_T = k_r(T₁) / k_r(T₂)                                           [визначення коефіцієнта прискорення]
     = [ A · exp( −E_a / (k_B · T₁) ) ] / [ A · exp( −E_a / (k_B · T₂) ) ]  [підстановка закону Арреніуса]
     = exp( −E_a/(k_B · T₁) − (−E_a/(k_B · T₂)) )                  [властивість експоненти e^a / e^b = e^(a-b)]
     = exp( (E_a / k_B) · (1/T₂ − 1/T₁) )                          [винесення спільного множника E_a / k_B]
```

У логарифмічній формі вираз набуває вигляду:

```
ln(AF_T) = (E_a / k_B) · ( (T₁ − T₂) / (T₁ · T₂) )
```

Ця формула показує: щойно ми знижуємо температуру кристала за допомогою дератингу з `T₁` до `T₂`, строк служби компонента зростає рівно в `AF_T` разів.

### Визначення енергії активації у прискорених випробуваннях (ALT / HALT)

Виробники напівпровідників визначають `E_a` експериментально під час високотемпературних випробувань надійності (High Temperature Operating Life, HTOL). Якщо група зразків тестується при двох підвищених температурах `T_A` та `T_B`, і середній час до відмови становить `t_50(T_A)` та `t_50(T_B)` відповідно, енергія активації розраховується як тангенс кута нахилу прямої на графіку Арреніуса:

```
ln( t_50(T_A) / t_50(T_B) ) = (E_a / k_B) · ( 1/T_A − 1/T_B )
E_a = k_B · ln( t_50(T_A) / t_50(T_B) ) / ( 1/T_A − 1/T_B )
```

### Типові значення енергії активації в електроніці

Енергія активації `E_a` залежить від домінуючого фізичного механізму руйнування в конкретному типі компонента. Нижче наведено експериментально підтверджені значення `E_a`, що використовуються в стандартах надійності JEDEC JESD85, MIL-HDBK-217F та Telcordia SR-332:

| Механізм деградації | Тип компонента | Енергія активації E_a (еВ) | Наслідок деградації |
| :--- | :--- | :--- | :--- |
| **Електроміграція металізації (EM)** | Інтегральні схеми, мікроконтролери | 0.70 ... 0.90 | Обрив тонких внутрішніх алюмінієвих/мідних доріжок |
| **Часозалежний пробій підзатворного оксиду (TDDB)** | MOSFET, CMOS ІМС | 0.60 ... 0.90 | Пробій діелектрика затвора SiO₂ або High-k |
| **Висихання рідкого електроліту** | Алюмінієві електролітичні конденсатори | 0.80 ... 0.94 | Зростання ESR у 5–10 разів, падіння ємності C |
| **Корозія контактних майданчиків від вологи** | Пластикові корпуси мікросхем | 0.80 ... 1.10 | Обрив розварювальних провідників (Bond Wires) |
| **Термомеханічна втома безсвинцевого припою (SAC305)** | BGA, QFN, SMD-компоненти | 0.50 ... 0.65 | Тріщини в кульках і галтелях припою при термоциклах |
| **Повільний дрейф опору плівки** | Прецизійні тонкоплівкові резистори | 0.40 ... 0.60 | Вихід номіналу опору за межі гарантованого допуску |

## 3. Математичне обґрунтування «Правила 10 градусів»

В інженерній практиці часто використовують спрощене емпіричне правило монтажу (правило Монтзінгера / Вант-Гоффа): **кожні 10 °C зниження температури подвоюють ресурс компонента** (`AF_T ≈ 2.0` при `ΔT = 10 °C`).

З'ясуймо, за яких умов це наближення є математично точним. Прирівняємо коефіцієнт прискорення до 2 при зміні температури від `T₂ = 298.15 К` (+25 °C) до `T₁ = 308.15 К` (+35 °C):

```
exp( (E_a / k_B) · (1/T₂ − 1/T₁) ) = 2
```

Прологарифмуємо обидві частини рівняння та виразимо необхідну енергію активації `E_a`:

```
(E_a / k_B) · ( (T₁ − T₂) / (T₁ · T₂) ) = ln(2)
E_a = ln(2) · k_B · (T₁ · T₂) / (T₁ − T₂)
```

Підставимо числові значення:
- `ln(2) ≈ 0.693147`;
- `k_B = 8.617333 · 10⁻⁵ еВ/К`;
- `T₁ = 308.15 К`, `T₂ = 298.15 К`, `T₁ − T₂ = 10 К`;

```
E_a = 0.693147 · (8.617333 · 10⁻⁵) · (308.15 · 298.15) / 10       [підстановка для діапазону 25...35 °C]
    = 5.97305 · 10⁻⁵ · 91874.9 / 10                                [добуток сталих та температур]
    ≈ 0.549 еВ                                                     [значення енергії активації]
```

Якщо ж розрахувати для діапазону температур, типового для силових перетворювачів (`T₂ = 358.15 К` (+85 °C), `T₁ = 368.15 К` (+95 °C)):

```
E_a = 0.693147 · (8.617333 · 10⁻⁵) · (368.15 · 358.15) / 10       [підстановка для діапазону 85...95 °C]
    = 5.97305 · 10⁻⁵ · 131852.9 / 10                               [добуток сталих та температур]
    ≈ 0.788 еВ                                                     [значення енергії активації]
```

Оскільки більшість механізмів відмов у силових напівпровідниках та електролітичних конденсаторах мають енергію активації в діапазоні `0.7 ... 0.9 еВ`, правило подвоєння ресурсу на кожні 10 °C охолодження є чудовим і фізично обґрунтованим лінійним наближенням закону Арреніуса.

## 4. Струмовий дератинг та модель електроміграції Блека

Під час протікання великих струмів крізь тонкі металеві провідники інтегральних схем і силових транзисторів виникає явище **електроміграції** (англ. *Electromigration*, EM) — спрямований перенос атомів металу під дією імпульсу «електронного вітру». Атоми зміщуються в напрямку руху електронів, утворюючи мікропустоти на вході та ниткоподібні вирости (віскери) на виході провідника.

1969 року Джеймс Блек (англ. *J. R. Black*) вивів рівняння для середнього часу до відмови провідника `MTTF_EM`:

```
MTTF_EM = ( A_EM / Jⁿ ) · exp( E_a_EM / (k_B · T) )
```

де:
- `A_EM` — константа, що залежить від геометрії та матеріалу провідника (мідь, алюміній, золото);
- `J` — густина струму в провіднику (`J = I / S_wire`, А/см²);
- `n` — показник ступеня густини струму (для сучасних субмікронних технологій `n ≈ 2.0`);
- `E_a_EM` — енергія активації електроміграції (для міді `0.8 ... 1.0 еВ`, для алюмінію `0.5 ... 0.7 еВ`).

З рівняння Блека випливає коефіцієнт прискорення струмового стресу `AF_I`:

```
AF_I = ( J₁ / J₂ )ⁿ = ( I₁ / I₂ )²
```

Зниження робочого струму напівпровідника вдвічі (`I₂ = 0.5 · I₁`) за рахунок дератингу зменшує швидкість електроміграційного руйнування в чотири рази (`AF_I = 4.0`), а разом зі зниженням джоулевого нагріву збільшує напрацювання на відмову на порядки.

## 5. Термоциклічний дератинг: моделі Коффіна-Менсона та Норріса-Ландзберга

В апаратурі, що працює в режимі частих вмикань/вимикань або циклічної зміни потужності, основним фактором відмови стає термомеханічна втома безсвинцевого припою. Різниця коефіцієнтів теплового розширення (Coefficient of Thermal Expansion, CTE) між кристалом кремнію (`CTE ≈ 2.6 ppm/K`), міддю (`16.5 ppm/K`) та склотекстолітом FR-4 (`14 ... 18 ppm/K`) генерує циклічні зсувні напруження в паяних з'єднаннях.

Кількість температурних циклів до появи втомної тріщини `N_f` описується базовою моделлю Коффіна-Менсона (англ. *Coffin-Manson Model*):

```
N_f = C_CM · ( ΔT )⁻ᵐ · exp( E_a / (k_B · T_max) )
```

де:
- `ΔT` — перепад температури за цикл (`ΔT = T_max − T_min`);
- `m` — коефіцієнт втоми Коффіна-Менсона (для безсвинцевого припою SAC305 `m ≈ 1.9 ... 2.5`);
- `T_max` — максимальна абсолютна температура циклу в Кельвінах.

Для врахування частоти термоциклів `f` (циклів за добу) та явища повзучості припою під час тривалого перебування при високій температурі застосовують розширене рівняння Норріса-Ландзберга (англ. *Norris-Landzberg Model*):

```
AF_NL = ( ΔT₁ / ΔT₂ )¹·⁹ · ( f₁ / f₂ )¹/³ · exp( (E_a / k_B) · (1/T_max2 − 1/T_max1) )
```

Якщо завдяки оптимізації тепловідведення та дератингу потужності інженер зменшує температурний розмах перегріву ключа з `ΔT₁ = 80 °C` до `ΔT₂ = 40 °C`, циклічна довговічність пайки зростає у:

```
AF_cycle = ( 80 / 40 )²·² = 2²·² ≈ 4.59 раза.
```

## 6. Електричний стрес: степенева модель напруги та модель Ейрінга

Зниження робочої напруги `V_actual` відносно паспортного номіналу `V_rated` також експоненційно уповільнює деградацію діелектриків. Для конденсаторів та ізоляційних бар'єрів стандартною є **степенева модель прискорення електричним полем** (англ. *Inverse Power Law*):

```
AF_V = ( V₁ / V₂ )ⁿ
```

У цій формулі:
- `V₁` — підвищена або паспортна напруга тестування;
- `V₂` — фактична робоча напруга з урахуванням дератингу;
- `n` — показник ступеня електричної чутливості діелектрика.

Типові значення показника `n`:
- Танталові конденсатори з катодом `MnO₂`: `n = 3.0`;
- Керамічні багатошарові конденсатори (MLCC, титанат барію `BaTiO₃` класів X7R/X5R): `n = 3.0 ... 4.5`;
- Плівкові конденсатори (поліпропілен, поліестер): `n = 5.0 ... 7.0`;
- Оксидний діелектрик затвора MOSFET: `n = 8.0 ... 12.0`.

Наприклад, якщо керамічний конденсатор з показником `n = 3.5` дератувати за напругою на 50 % (`V₂ / V₁ = 0.5`), коефіцієнт електричного збільшення ресурсу становить:

```
AF_V = ( 1.0 / 0.5 )³·⁵ = 2³·⁵ = 2³ · √2 ≈ 11.31
```

У реальному компоненті тепловий та електричний стреси діють одночасно. Загальний коефіцієнт прискорення відмов обчислюється як добуток температурного та напругового факторів за узагальненою моделлю Генрі Ейрінга (англ. *Modified Eyring Model*):

```
AF_total = AF_T · AF_V
         = exp( (E_a / k_B) · (1/T₂ − 1/T₁) ) · ( V₁ / V₂ )ⁿ
```

## 7. Зв'язок дератингу з функцією надійності Вейбулла та інтенсивністю відмов λ(t)

В інженерії надійності для аналізу часового розподілу відмов широко використовується двохпараметричний розподіл Вейбулла (англ. *Weibull Distribution*):

```
R(t) = exp( −( t / η )ᵝ )
```

де:
- `β` — параметр форми (англ. *shape parameter*): при `β < 1` спостерігається період ранніх припрацьовувальних відмов (дитяча смертність), при `β = 1` інтенсивність відмов постійна `λ = 1/η` (експоненційний закон надійності), а при `β > 1` домінує механізм зносу та старіння;
- `η` — характеристичний строк служби (англ. *characteristic life*, час, за який відмовляє 63.2 % вибірки компонентів).

Вплив температури за моделлю Арреніуса масштабує саме характеристичний параметр `η`:

```
η(T) = η₀ · exp( E_a / (k_B · T) )
```

У стаціонарному періоді нормальної експлуатації (`β = 1`) функція надійності зводиться до класичного експоненційного закону:

```
R(t) = exp( −λ · t )
```

де `λ` — інтенсивність відмов (англ. *failure rate*).

Стандартною одиницею вимірювання інтенсивності відмов у мікроелектроніці є **FIT** (англ. *Failures in Time*):

```
1 FIT = 1 відмова / 10⁹ годин роботи = 10⁻⁹ год⁻¹
```

Середнє напрацювання до відмови (англ. *Mean Time Between Failures*, MTBF для відновлюваних систем або *Mean Time to Failure*, MTTF для невідновлюваних компонентів) є оберненою величиною до інтенсивності відмов:

```
MTBF = 1 / λ
```

Згідно з військовим стандартом розрахунку надійності **MIL-HDBK-217F**, прогнозована інтенсивність відмов компонента `λ_p` розраховується через базову інтенсивність `λ_b` та систему поправочних коефіцієнтів (коефіцієнтів стресу `π`):

```
λ_p = λ_b · π_T · π_V · π_P · π_Q · π_E
```

У цьому виразі:
- `λ_b` — базова інтенсивність відмов деталі при стандартному навантаженні (зазвичай +25 °C, 50 % номіналу напруги);
- `π_T` — температурний фактор дератингу (обчислюється за формулою Арреніуса):
  `π_T = exp( −(E_a / k_B) · (1/T_j − 1/298.15) )`;
- `π_V` — фактор напругового дератингу:
  для конденсаторів за MIL-HDBK-217F: `π_V = (S_V / 0.5)³ + 1`, де `S_V = V_op / V_rated`;
- `π_P` — фактор потужнісного дератингу для резисторів:
  `π_P = S_P¹.⁵`, де `S_P = P_op / P_rated`;
- `π_Q` — коефіцієнт якості виготовлення (Quality Factor);
- `π_E` — коефіцієнт жорсткості зовнішнього середовища (Environment: Ground Benign, Airborne Inhabited, Space тощо).

## 8. Повний розрахунковий приклад

Розглянемо практичну задачу оцінки надійності силового вузла перетворювача.

**Умова:**
У силовому каскаді працює MOSFET-транзистор.
- Паспортні параметри: `V_ds_max = 60 В`, `T_j_max = 150 °C`, базова інтенсивність відмов `λ₀ = 20 FIT` при `T_j = 40 °C`, `V_ds = 30 В`.
- Енергія активації деградації кремнієвого кристала: `E_a = 0.70 еВ`.
- Показник електричного стресу: `n = 4.0`.

**Сценарій А (Без дератингу, важкий режим):**
- Робоча напруга стоку: `V₁ = 54 В` (коефіцієнт напруги `S_V = 54/60 = 0.90`);
- Температура кристала через слабкий тепловідвід: `T₁ = +135 °C = 408.15 К`.

**Сценарій Б (З дератингом за стандартами IPC-9592B):**
- Інженер обрав MOSFET на 100 В замість 60 В, тому при тій самій напрузі 54 В коефіцієнт стресу становить `S_V = 54/100 = 0.54` (робоча відносна напруга `V₂ = 32.4 В` в еквіваленті 60 В шкали);
- Покращено охолодження, завдяки чому температура кристала знижена до `T₂ = +75 °C = 348.15 К`.

**Розрахунок коефіцієнта температурного прискорення:**

```
AF_T = exp( (0.70 / (8.617333 · 10⁻⁵)) · (1/348.15 − 1/408.15) )   [підстановка E_a, k_B, T1, T2]
     = exp( 8123.15 · (0.0028723 − 0.0024501) )                    [обчислення 1/T2 та 1/T1]
     = exp( 8123.15 · 0.0004222 )                                  [різниця обернених температур]
     = exp( 3.4296 )                                               [показник експоненти]
     ≈ 30.86                                                       [коефіцієнт прискорення]
```

Температурний дератинг сам по собі зменшив інтенсивність відмов у 30.86 раза!

**Розрахунок коефіцієнта прискорення за напругою:**

```
AF_V = ( 54.0 / 32.4 )⁴·⁰                                          [відношення робочих напруг у 4-му ступені]
     = ( 1.6667 )⁴·⁰                                               [співвідношення напруг]
     ≈ 7.716                                                       [коефіцієнт прискорення напруги]
```

Напруговий дератинг зменшив інтенсивність відмов ще у 7.72 раза!

**Сумарне покращення надійності:**

```
AF_total = AF_T · AF_V                                             [добуток факторів за моделлю Ейрінга]
         = 30.86 · 7.716                                           [підстановка коефіцієнтів]
         ≈ 238.1                                                   [сумарне збільшення надійності]
```

**Порівняння показників MTBF:**
- У Сценарії А інтенсивність відмов становить `λ_A = 20 FIT · 238.1 ≈ 4762 FIT`, а середнє напрацювання до відмови:
  `MTBF_A = 10⁹ / 4762 ≈ 210 000 годин (близько 24 років роботи одного компонента)`.
- У Сценарії Б з дератингом `λ_B = 20 FIT`, а середнє напрацювання до відмови:
  `MTBF_B = 10⁹ / 20 = 50 000 000 годин (понад 5700 років)`.

Якщо на платі змонтовано 200 подібних компонентів, сумарна інтенсивність відмов системи без дератингу складе `λ_sys = 200 · 4762 FIT = 952 400 FIT`, що дає реальний MTBF виробу лише `10⁹ / 952400 ≈ 1050 годин` (менше 1.5 місяця безперервної роботи до першої гарантійної поломки!).

Завдяки впровадженню дератингу сумарний MTBF того самого виробу зростає до `10⁹ / (200 · 20) = 250 000 годин` (понад 28 років надійної безвідмовної експлуатації).
