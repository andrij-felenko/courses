# 🧮 Електростатичне масштабування FinFET: натуральна довжина, підпороговий схил і квантування

Електростатичний бар'єр у нанометровому каналі польового транзистора визначається просторовим розподілом електричного потенціалу між витоком, стоком і керуючим затвором. У підпороговому режимі роботи, коли концентрація вільних носіїв заряду в каналі мізерно мала порівняно з зарядом збіднення, розрахунок потенціалу зводиться до розв'язання крайової задачі для рівняння Пуассона у відповідній тривимірній або симетричній двовимірній геометрії ребра.

### 1. Двовимірне рівняння Пуассона та розв'язок для симетричного подвійного затвора

Для симетричної тривимірної структури з тонким вертикальним ребром основне електростатичне керування здійснюється парою протилежних бічних стінок затвора. Якщо висота ребра H_fin перевершує його ширину W_fin у три або більше разів (співвідношення сторін H_fin / W_fin ≥ 3), градієнт потенціалу вздовж вертикальної осі z у середній частині ребра стає знехтовно малим порівняно з поперечним градієнтом вздовж осі x. Це дозволяє редукувати загальне тривимірне рівняння Пуассона до аналітично розв'язуваної двовимірної крайової задачі в площині (x, y).

Оберемо прямокутну систему координат, де вісь y спрямована вздовж каналу від витоку (y = 0) до стоку (y = L_g), а вісь x орієнтована перпендикулярно до бічних поверхонь ребра з початком координат у геометричному центрі ребра (-W_fin / 2 ≤ x ≤ +W_fin / 2).

У нелегованому або слабо легованому кремнієвому ребрі густина об'ємного заряду іонізованих домішок практично дорівнює нулю (N_a < 10¹⁵ см⁻³). Рівняння Пуассона для електростатичного потенціалу ψ(x, y) набуває вигляду двовимірного рівняння Лапласа:

```
∂²ψ(x, y)/∂x² + ∂²ψ(x, y)/∂y² = 0      [двовимірне рівняння в нелегованому каналі]
```

Для аналітичного знаходження розподілу потенціалу застосуємо метод параболічної апроксимації поперечного профілю потенціалу в тілі ребра:

```
ψ(x, y) = c₀(y) + c₁(y)·x + c₂(y)·x²      [параболічне наближення вздовж осі x]
```

Коефіцієнти c₀(y), c₁(y) та c₂(y) визначаються з фізичних граничних умов на межах симетрії та діелектрика:

1. Внаслідок просторової симетрії однакових затворів з обох боків ребра напруженість електричного поля в центрі ребра дорівнює нулю:

```
∂ψ(x, y)/∂x|_{x=0} = 0
= c₁(y) + 2·c₂(y)·0
= c₁(y)
= 0                                    [симетрія потенціалу відносно центра x=0]
```

Звідси потенціал у центрі ребра дорівнює центральному значенню:

```
c₀(y) = ψ₀(y)                          [потенціал на центральній осі ребра]
```

2. На границі розділу кремній-діелектрик (x = W_fin / 2) діє умова неперервності нормальної складової вектора електричного зміщення. Відношення діелектричних проникностей ε_si / ε_ox визначає стрибок напруженості електричного поля на гетеропереході через зв'язаний поляризаційний заряд. З урахуванням лінійного спаду потенціалу в тонкому шарі підзатворного оксиду товщиною 	_ox:

```
ε_si · ∂ψ/∂x|_{x = W_fin/2} = ε_ox · (V_gs - V_fb - ψ_s(y)) / t_ox      [рівність потоків зміщення на межі Si/SiO₂]
```

де ε_si — діелектрична проникність кремнію (11.7), ε_ox — діелектрична проникність підзатворного оксиду, V_gs — прикладена напруга затвора, V_fb — напруга плоских зон (визначається різницею робіт виходу металу затвора та кремнію), ψ_s(y) = ψ(W_fin/2, y) — поверхневий потенціал на стінці ребра.

Обчислимо просторову похідну параболічного профілю на поверхні:

```
∂ψ/∂x|_{x = W_fin/2} = 2 · c₂(y) · (W_fin / 2)
= c₂(y) · W_fin                        [похідна параболи на межі]
```

Підставимо отриману похідну в крайову умову:

```
c₂(y) · W_fin · ε_si = (ε_ox / t_ox) · (V_gs - V_fb - ψ_s(y))
c₂(y) = (ε_ox / (ε_si · W_fin · t_ox)) · (V_gs - V_fb - ψ_s(y))      [визначення коефіцієнта c₂]
```

Виразимо різницю між поверхневим потенціалом ψ_s(y) та центральним потенціалом ψ₀(y):

```
ψ_s(y) - ψ₀(y) = c₂(y) · (W_fin / 2)²
= (ε_ox / (ε_si · W_fin · t_ox)) · (V_gs - V_fb - ψ_s(y)) · (W_fin² / 4)
= (ε_ox · W_fin / (4 · ε_si · t_ox)) · (V_gs - V_fb - ψ_s(y))          [зв'язок поверхневого та центрального потенціалів]
```

Введемо безрозмірний коефіцієнт ємнісного зв'язку 
 = (ε_ox · W_fin) / (4 · ε_si · t_ox). Оскільки товщина ребра мала порівняно з еквівалентною товщиною діелектрика, величина 
 << 1, що свідчить про майже повну еквіпотенціальність поперечного перерізу тонкого ребра (ψ_s(y) ≈ ψ₀(y)).

Підставимо другу похідну за координатою x:

```
∂²ψ(x, y)/∂x² = 2 · c₂(y)
= (2 · ε_ox / (ε_si · W_fin · t_ox)) · (V_gs - V_fb - ψ_s(y))          [друга поперечна похідна потенціалу]
```

Підставляючи цей вираз у вихідне рівняння Лапласа вздовж поверхні x = W_fin/2, отримуємо одновимірне диференціальне рівняння другого порядку для поздовжнього розподілу поверхневого потенціалу:

```
d²ψ_s(y)/dy² - (ψ_s(y) - (V_gs - V_fb)) / λ_fin² = 0      [рівняння поздовжнього розподілу потенціалу]
```

де фундаментальний електростатичний масштаб екранування λ_fin визначається геометричними та матеріальними параметрами ребра:

```
λ_fin = √((ε_si / (2 · ε_ox)) · W_fin · t_ox)              [натуральна довжина екранування FinFET]
```

Для повноцінної тривимірної структури Tri-Gate, де металевий затвор одночасно накриває верхню горизонтальну грань шириною W_fin та дві бічні вертикальні стінки висотою H_fin, строгий розв'язок тривимірного рівняння Пуассона методом розділення змінних дає модифіковану формулу натуральної довжини:

```
λ_tri = √((ε_si · W_fin · t_ox / (2 · ε_ox)) · (1 / (1 + W_fin / (2 · H_fin))))      [натуральна довжина Tri-Gate]
```

Коли висота ребра значно перевищує його ширину (H_fin >> W_fin), поправочний множник 1 / (1 + W_fin / (2 · H_fin)) прямує до одиниці, і поведінка тривимірного ребра повністю описується формулою симетричного подвійного затвора.

### 2. Розподіл потенціалу вздовж каналу та мінімальний бар'єр

Розв'яжемо отримане диференціальне рівняння другого порядку з крайовими умовами на межах витокового та стокового металургійних переходів:
- На витоку (y = 0): ψ_s(0) = V_bi, де V_bi — вбудована контактна різниця потенціалів p-n переходу витоку;
- На стоці (y = L_g): ψ_s(L_g) = V_bi + V_ds, де V_ds — прикладена робоча напруга стоку.

Загальний розв'язок лінійного неоднорідного диференціального рівняння записується через суму стаціонарного потенціалу затвора та двох просторових гіперболічних мод:

```
ψ_s(y) = (V_gs - V_fb) + A · sinh((L_g - y) / λ_fin) + B · sinh(y / λ_fin)      [загальний розв'язок для потенціалу]
```

Амплітудні коефіцієнти A та B визначаються підстановкою граничних умов при y = 0 та y = L_g:

```
A = (V_bi - (V_gs - V_fb)) / sinh(L_g / λ_fin)              [коефіцієнт впливу витоку]
B = (V_bi + V_ds - (V_gs - V_fb)) / sinh(L_g / λ_fin)       [коефіцієнт впливу стоку]
```

Струм витоку в підпороговому стані транзистора лімітується найвищою точкою енергетичного бар'єра для вільних носіїв заряду. Ця точка відповідає мінімуму електростатичного потенціалу y_min, де перша похідна за координатою обертається на нуль:

```
dψ_s(y)/dy|_{y = y_min} = 0      [умова екстремуму потенціального бар'єра]
```

Диференціюючи загальний розв'язок для ψ_s(y):

```
- A · cosh((L_g - y_min) / λ_fin) + B · cosh(y_min / λ_fin) = 0
cosh((L_g - y_min) / λ_fin) / cosh(y_min / λ_fin) = B / A      [рівняння для знаходження точки мінімуму]
```

Для довгоканального приладу (L_g >> λ_fin) точка мінімального бар'єра розташована практично посередині каналу (y_min ≈ L_g / 2). У цьому наближенні гіперболічні функції апроксимуються експонентами sinh(L_g / λ_fin) ≈ (1/2) · exp(L_g / λ_fin), а значення мінімального потенціалу в центрі каналу набуває вигляду:

```
ψ_min ≈ (V_gs - V_fb) + 2 · √(A · B) · exp(- L_g / (2 · λ_fin))      [висота мінімального потенціалу каналу]
```

Коли довжина каналу скорочується до величини порядку 2 · λ_fin, експоненційний затухаючий член перестає бути малим. Позитивний потенціал стоку V_ds безпосередньо входить у коефіцієнт B і починає напряму піднімати потенціал ψ_min, знижуючи висоту запірного бар'єра для електронів.

### 3. Зниження бар'єра полем стоку (DIBL)

Явище зниження запірного бар'єра каналу під дією прикладеної напруги стоку призводить до паразитного зсуву порогової напруги. Кількісно ефект DIBL оцінюється як відношення зміни порогової напруги ΔV_th до зміни напруги на стоці ΔV_ds:

```
DIBL = - ∂V_th / ∂V_ds
= - ∂ψ_min / ∂V_ds      [визначення коефіцієнта DIBL]
```

Диференціюючи аналітичний вираз для ψ_min за змінною напруги стоку V_ds:

```
∂ψ_min/∂V_ds = (1 / sinh(L_g / λ_fin)) · sinh(y_min / λ_fin)
≈ exp(- (L_g - y_min) / λ_fin)
≈ exp(- L_g / (2 · λ_fin))      [експоненційна залежність DIBL від геометрії]
```

З урахуванням ємнісного взаємопроникнення крайових полів між стоком і каналом точний аналітичний вираз для DIBL у FinFET записується як:

```
DIBL ≈ 2.5 · (ε_si / ε_ox) · (1 + W_fin² / (4 · L_g²)) · exp(- L_g / (2 · λ_fin))      [аналітичний вираз DIBL]
```

Для забезпечення надійної завадостійкості цифрових логічних вентилів величина DIBL не повинна перевищувати 30–50 мВ/В. Звідси випливає фундаментальний електростатичний критерій стійкості до короткоканальних ефектів:

```
L_g / λ_fin ≥ 2.5 … 3.0      [критерій придушення короткоканальних ефектів]
```

Підставимо у цей критерій вираз для натуральної довжини λ_fin:

```
L_g ≥ 2.8 · √((ε_si / (2 · ε_ox)) · W_fin · t_ox)      [зв'язок геометричних розмірів транзистора]
```

Для сучасного підзатворного діелектрика High-k з еквівалентною товщиною оксиду 	_ox = 1.0 нм та діелектричною проникністю кремнію ε_si = 11.7 і діоксиду кремнію ε_ox = 3.9:

```
ε_si / (2 · ε_ox) = 11.7 / (2 · 3.9) = 1.50      [відношення проникностей]
```

Тоді критерій довжини затвора набуває спрощеного числового вигляду:

```
L_g ≥ 2.8 · √(1.50 · W_fin · 1.0 нм)
L_g ≥ 3.43 · √(W_fin · 1.0 нм)                   [гранична довжина каналу]
```

При довжині затвора L_g = 18 нм (вузол 7 нм) розрахункова максимальна товщина ребра становить:

```
W_fin ≤ L_g² / (3.43² · 1.0 нм)
= 324 / 11.76
≈ 27.5 нм      [теоретична верхня межа без урахування 3D-крайових ефектів]
```

Проте на практиці лінії поля стоку проникають не лише крізь бічні стінки, а й крізь не закриту затвором основу ребра біля діелектричної ізоляції STI. Щоб гарантувати надійне придушення витоку через основу ребра (*sub-fin leakage*), інженерне правило вимагає суворішого геометричного обмеження:

```
W_fin ≤ L_g / 2      [емпіричний закон проектування FinFET]
```

### 4. Виведення підпорогового схилу повністю збідненого каналу

Підпороговий схил показує, на скільки мілівольтів потрібно змінити напругу на затворі, щоб змінити струм стоку закритого транзистора рівно на один порядок (в 10 разів):

```
SS = (∂ log₁₀(I_ds) / ∂V_gs)⁻¹
= ln(10) · (∂ ln(I_ds) / ∂V_gs)⁻¹
= ln(10) · (∂ ln(I_ds) / ∂ψ_s)⁻¹ · (∂V_gs / ∂ψ_s)      [розклад підпорогового схилу на множники]
```

У підпороговому режимі носії заряду долають енергетичний бар'єр витоку за рахунок теплової дифузії, підпорядковуючись статистиці Максвелла-Больцмана:

```
I_ds ∝ exp(q · ψ_s / (k_B · T))                        [больцманівська залежність струму від бар'єра]
```

Диференціюючи струм за величиною поверхневого потенціалу:

```
∂ ln(I_ds) / ∂ψ_s = q / (k_B · T)                      [термодинамічний нахил]
```

Другий множник m = ∂V_gs / ∂ψ_s є фактором неідеальності затвора (фактором тіла транзистора), який описує ємнісний дільник напруги між обкладкою затвора та інверсійним каналом:

```
m = ∂V_gs / ∂ψ_s
= 1 + C_dep / C_ox + C_it / C_ox                       [фактор тіла транзистора]
```

де C_ox = ε_ox / t_ox — питома ємність підзатворного діелектрика, C_dep = ε_si / W_dep — диференціальна ємність шару збіднення напівпровідника, C_it = q² · D_it — ємність поверхневих пасток на межі розділу кремній-діелектрик.

**Порівняльний аналіз планарного транзистора та FinFET:**

1. У класичному планарному транзисторі з важко легованим каналом (N_a > 10¹⁸ см⁻³) шар збіднення модулюється напругою затвора, що створює значну ємність C_dep. Відношення C_dep / C_ox становить від 0.35 до 0.60, через що фактор тіла помітно перевищує одиницю:

```
m_planar ≈ 1.35                                        [фактор неідеальності планарного MOSFET]
SS_planar = ln(10) · (k_B · T / q) · 1.35
= 2.3026 · 25.85 мВ · 1.35
≈ 80.3 мВ/дек                                          [підпороговий схил планарного транзистора]
```

2. У повністю збідненому FinFET товщина ребра W_fin < 10 нм менша за природну ширину збідненої області. Усе тіло ребра повністю позбавлене рухливих носіїв заряду контактною різницею потенціалів затвора. Оскільки під каналом немає нейтрального масиву напівпровідника, зміна напруги затвора не може змінити об'єм збіднення:

```
C_dep = 0                                              [повне збіднення ультратонкого ребра]
```

Завдяки конформному нанесенню діелектрика методом атомно-шарового осадження (ALD) та високотемпературному відпалу у воднево-азотному середовищі густина поверхневих станів знижується нижче D_it < 10¹¹ еВ⁻¹·см⁻², що робить C_it / C_ox ≈ 0. Фактор тіла сягає свого теоретичного мінімуму:

```
m_FinFET = 1 + 0 + 0 = 1.00                            [ідеальний фактор тіла FinFET]
```

Граничний теоретичний підпороговий схил нелегованого FinFET при кімнатній температурі T = 300 K становить:

```
SS_ideal = ln(10) · (k_B · T / q) · 1.00
= 2.302585 · 0.025852 В · 1.00
= 0.05952 В/дек
≈ 59.5 мВ/дек                                          [фундаментальна фізична межа Больцмана]
```

Зниження підпорогового схилу з 90 мВ/дек до 65 мВ/дек дозволяє знизити порогову напругу V_th на 100 мВ за умови збереження фіксованого струму витоку I_off:

```
I_off = I₀ · 10^(- V_th / SS)                          [експоненційний струм вимкненого стану]
```

Зменшення порогової напруги уможливило зниження напруги живлення V_dd з 1.0 В до 0.7 В, що забезпечило зниження динамічної потужності перемикання логічних елементів на 51 відсоток:

```
ΔP_dyn / P_dyn = 1 - (V_dd,new / V_dd,old)²
= 1 - (0.7 / 1.0)²
= 1 - 0.49
= 0.51                                                 [економія динамічної потужності на 51%]
```

### 5. Квантово-розмірний зсув енергії підзон (Quantum Confinement)

При зменшенні товщини ребра W_fin нижче 7–8 нм розмір каналу стає сумірним із деброглівською довжиною хвилі електрона в кремнії (λ_dB = h / p ≈ 3–5 нм). Вільний рух електронів уздовж осі x обмежується двома потенціальними бар'єрами підзатворного діелектрика, утворюючи одновимірну квантову яму.

Зона провідності кремнію має шість еквівалентних еліпсоїдів постійної енергії вздовж кристалографічних напрямків <100>. У тонкому ребрі з орієнтацією бічних стінок (110) та напрямком протікання струму [110] шестикратне виродження долин розщеплюється на дві підгрупи:
- Двократна підзона з високою масою квантового обмеження m_conf* = m_l* ≈ 0.916 · m₀;
- Чотирикратна підзона з малою масою квантового обмеження m_conf* = m_t* ≈ 0.190 · m₀.

Рівняння Шредінгера для поперечної складової хвильової функції електрона ϕ(x) у наближенні прямокутної потенціальної ями з нескінченно високими стінками шириною W_fin має вигляд:

```
- (ħ² / (2 · m_conf*)) · d²ϕ(x)/dx² = E · ϕ(x)         [стаціонарне рівняння Шредінгера]
```

де ħ = h / (2·π) = 1.05457 · 10⁻³⁴ Дж·с — зведена стала Планка, m_conf* — ефективна маса електрона в напрямку квантового обмеження.

Дискретні енергетичні рівні квантових підзон визначаються виразом:

```
E_n = (ħ² · π² · n²) / (2 · m_conf* · W_fin²)          [енергетичний спектр підзон для n=1,2,3...]
```

Для основного стану 
 = 1 енергія нульових коливань зміщує дно зони провідності вгору на величину ΔE_c:

```
ΔE_c = (ħ² · π² ) / (2 · m_conf* · W_fin²)              [зсув дна зони провідності]
```

Аналогічно, квантування дірок зміщує стелю валентної зони вниз на величину ΔE_v. Ефективна ширина забороненої зони кремнію в тонкому ребрі зростає:

```
E_g,eff = E_g,0 + ΔE_c + ΔE_v                          [розширення забороненої зони кремнію]
```

Зсув дна зони провідності безпосередньо збільшує потенціальний бар'єр для інверсії носіїв заряду, викликаючи додаткове зростання порогової напруги:

```
ΔV_th,quant ≈ ΔE_c / q
= (ħ² · π²) / (2 · q · m_conf* · W_fin²)               [квантовий зсув порогової напруги]
```

Чутливість порогової напруги до випадкових флуктуацій ширини ребра δW_fin знаходиться взяттям аналітичної похідної за товщиною ребра:

```
d(ΔV_th)/d(W_fin) = - (ħ² · π²) / (q · m_conf* · W_fin³)      [похідна квантового зсуву за товщиною ребра]
```

Розрахуємо квантовий зсув для двох випадків геометрії за умови квантування для легкої підзони, де поперечна ефективна маса становить m_conf* = 0.190 · m₀ = 1.73 · 10⁻³¹ кг:

1. Для технологічного вузла 7 нм з товщиною ребра W_fin = 6.0 нм:

```
ΔE_c = ((1.05457 · 10⁻³⁴)² · π²) / (2 · 1.73 · 10⁻³¹ · (6.0 · 10⁻⁹)²)
= (1.0976 · 10⁻⁶⁷) / (1.2456 · 10⁻⁴⁷)
= 8.81 · 10⁻²¹ Дж
= (8.81 · 10⁻²¹ / 1.6022 · 10⁻¹⁹) еВ
≈ 0.055 еВ = 55 меВ                                    [зсув дна зони провідності для W=6 нм]
```

Зсув порогової напруги становить помірні ΔV_th = +55 мВ, які компенсуються підбором роботи виходу металу затвора.

2. Для спроби екстремального зменшення товщини ребра до W_fin = 3.0 нм:

```
ΔE_c = ((1.05457 · 10⁻³⁴)² · π²) / (2 · 1.73 · 10⁻³¹ · (3.0 · 10⁻⁹)²)
= (1.0976 · 10⁻⁶⁷) / (3.114 · 10⁻⁴⁸)
= 3.524 · 10⁻²⁰ Дж
= (3.524 · 10⁻²⁰ / 1.6022 · 10⁻¹⁹) еВ
≈ 0.220 еВ = 220 меВ                                   [зсув дна зони провідності для W=3 нм]
```

Зсув порогової напруги сягає критичних ΔV_th = +220 мВ.

Обчислимо варіацію порогової напруги при технологічній нерівності бічних стінок ребра всього на один атомний моношар кремнію (величина технологічної варіації становить δW_fin = 0.27 нм):

```
δV_th ≈ |d(ΔV_th)/d(W_fin)| · δW_fin
= (2 · ΔE_c / (q · W_fin)) · δW_fin
= (2 · 0.220 В / 3.0 нм) · 0.27 нм
= 0.1467 В · 0.27
≈ 0.0396 В = 39.6 мВ                                   [розкид порогової напруги від одного моношару]
```

Кубічна залежність чутливості від товщини ребра 1 / W_fin³ призводить до того, що на масштабах W_fin < 5 нм флуктуації ширини ребра в один атом створюють неконтрольований статистичний розкид порогових напруг σ(V_th) > 40 мВ, що унеможливлює надійну роботу комірок пам'яті SRAM. Це квантово-механічне явище встановило фундаментальну нижню межу товщини кремнієвого ребра на рівні 5–6 нм.
