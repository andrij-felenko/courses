# 🧮 Розрахунок ресурсу кулькових підшипників BLDC за стандартом ISO 281

Цей математичний аналіз встановлює точну інженерну залежність між динамічним навантаженням на ротор, частотою обертання, робочою температурою та часом настання втомного руйнування доріжок кочення мініатюрних кулькових підшипників безколекторних двигунів. Без цього розрахунку неможливо обґрунтувати регламентний міжремонтний інтервал заміни моторів або підшипникових вузлів безпілотного апарата.

## Базова модель ресурсу за стандартом ISO 281

Розрахунок базується на емпірично-статистичній теорії втомного руйнування металів Лундберга–Пальмгрена (Lundberg–Palmgren). Номінальний ресурс `L₁₀` визначає кількість мільйонів обертів, яку витримують 90 % партії однакових підшипників за сталого навантаження до появи перших ознак контактної втоми (лущення металу, або *spalling*).

Для радіальних кулькових підшипників (де показник степеня для точкового контакту кульки з доріжкою `p = 3`) зв'язок між базовою динамічною вантажопідйомністю `C` та еквівалентним динамічним навантаженням `P` описується виразом:

```
L₁₀ = (C / P)³      [номінальний ресурс у мільйонах обертів]
```

Оскільки на практиці ресурс вимірюється в годинах напрацювання за частоти обертання `n` (об/хв), здійснюється перерахунок через швидкість накопичення циклів навантаження:

```
L₁₀ₕ = (10⁶ / (60 · n)) · L₁₀
     = (10⁶ / (60 · n)) · (C / P)³      [перерахунок мільйонів обертів у години]
```

## Визначення еквівалентного динамічного навантаження

На вал безколекторного двигуна одночасно діють радіальні сили `F_r` (відцентровий дисбаланс повітряного гвинта, бічна аеродинамічна сила при маневрах) та осьові сили `F_a` (статична та динамічна тяга пропелера).

Еквівалентне навантаження `P` зводить комбінований силовий вплив до умовного суто радіального навантаження за формулою:

```
P = X · F_r + Y · F_a
```

де `X` — радіальний коефіцієнт, `Y` — осьовий коефіцієнт. Їхні значення визначаються співвідношенням `F_a / C₀` (де `C₀` — статична вантажопідйомність підшипника) відносно граничного коефіцієнта `e`:

```
Якщо F_a / F_r ≤ e:
X = 1
Y = 0
P = F_r            [осьове навантаження поглинається без додаткового зносу]

Якщо F_a / F_r > e:
X = 0.56
Y = 1.0 ... 2.0    [значення Y зростає зі збільшенням осьового натягу]
```

## Контактні напруження Герца та товщина мастильної плівки

У точці контакту сталевої кульки з увігнутою поверхнею доріжки кочення діє максимальний контактний тиск Герца `σ_max`. Для пружного еліптичного контакту кульки діаметра `d_b` з жолобом радіуса `r_groove`:

```
σ_max = (3 · Q) / (2 · π · a_h · b_h)
```

де `Q` — максимальне навантаження на найбільш навантажену кульку підшипника (`Q ≈ 5 · P / Z`, де `Z` — кількість кульок), `a_h` та `b_h` — велика й мала півосі еліпса пружного контакту.

У високоспритних підшипниках безпілотників значення `σ_max` сягає `1.8 ... 2.6 ГПа`. За таких тисків збереження розділового шару масла можливе лише в режимі еластогідродинамічного змащення (EHL). Мінімальна товщина плівки `h₀` оцінюється за модифікованою формулою Доусона–Хіггінсона (Dowson–Higginson):

```
h₀ = 2.65 · R_eq · (α_visc · E_red)^0.54 · ((η₀ · u) / (E_red · R_eq))^0.70 · (Q / (E_red · R_eq²))^-0.13
```

де `R_eq` — еквівалентний радіус кривини, `α_visc` — п'єзокоефіцієнт в'язкості мастила, `η₀` — динамічна в'язкість при робочій температурі, `u` — середня швидкість кочення поверхні, `E_red` — приведений модуль пружності сталі (близько 220 ГПа).

Параметр працездатності контакту визначається співвідношенням товщини плівки до середньоквадратичної шорсткості поверхонь `Λ` (параметр Лямбда):

```
Λ = h₀ / √(R_q_ball² + R_q_race²)
```

- Якщо `Λ > 3`: режим повного рідинного тертя. Кульки повністю розділені маслом, втомний знос мінімальний.
- Якщо `1 ≤ Λ ≤ 3`: змішане тертя. Відбувається епізодичний контакт мікронерівностей, швидкість зносу зростає в рази.
- Якщо `Λ < 1`: граничне тертя. Мастило видавлюється з контакту, виникає безпосереднє зварювання мікронерівностей сталі (схоплення та викришування).

## Модифікований ресурс з урахуванням мастила та температури (ISO 281 a_ISO)

У реальних високоспритних двигунах підшипник нагрівається від обмоток статора до температур 70...100 °C. Під дією температури кінематична в'язкість мастила `ν` різко падає, знижуючи параметр `Λ`.

Модифікований ресурс `L_nm` враховує коефіцієнт надійності `a₁` та комплексний коефіцієнт умов роботи `a_ISO`:

```
L_nm = a₁ · a_ISO · L₁₀ₕ
```

Коефіцієнт `a_ISO` є функцією параметра в'язкості мастила `κ` (відношення фактичної кінематичної в'язкості `ν` до мінімально необхідної `ν₁`) та коефіцієнта забруднення `e_C`:

```
κ = ν / ν₁          [коефіцієнт в'язкості мастильної плівки]
```

Коли температура підшипника зростає з 40 °C до 90 °C, в'язкість базового синтетичного масла падає в 4–6 разів (`κ` знижується з 2.0 до 0.4). Це переводить контакт кульок із гідродинамічного режиму у граничний, зменшуючи `a_ISO` з 1.5 до 0.25–0.30.

## Термічна зміна радіального зазору та блокування

Під час роботи статор мотора нагрівається сильніше за зовнішній дзвін ротора, що обдувається зустрічним потоком повітря від гвинта. Внутрішнє кільце підшипника, напресоване на сталевий вал, розширюється за рахунок коефіцієнта теплового лінійного розширення `α_steel ≈ 11.5 · 10⁻⁶ 1/°C`:

```
Δd_inner = d_shaft · α_steel · (T_shaft - T_ambient)
```

При діаметрі вала `d_shaft = 4 мм` та нагріванні від 25 °C до 95 °C (`ΔT = 70 °C`):

```
Δd_inner = 0.004 м · (11.5 · 10⁻⁶) · 70 °C
         = 3.22 мкм
```

Якщо підшипник спочатку мав стандартний радіальний зазор групи C0 (від 2 до 7 мкм), термічне розширення вала разом із натягом посадки внутрішнього кільця може повністю вибрати зазор до нуля або створити паразитичний внутрішній натяг. Це викликає різке зростання внутрішніх сил `Q` без зовнішнього корисного навантаження, призводячи до швидкого перегріву та заклинювання двигуна. Саме тому в швидкісних безколекторних моторах обов'язково застосовуються підшипники зі збільшеним радіальним зазором класу **C3** (від 8 до 13 мкм).

## Покроковий числовий розрахунок для безпілотного апарата

Розглянемо типовий кульковий підшипник типорозміру 684ZZ (`4 × 9 × 4 мм`), встановлений у двигуні 2806.5 / 1300KV польотного апарата.

**Вихідні параметри даташиту та умов польоту:**
- Базова динамічна вантажопідйомність: `C = 640 Н`
- Статична вантажопідйомність: `C₀ = 270 Н`
- Крейсерська частота обертання: `n = 24 000 об/хв`
- Статична тяга гвинта на мотор: `F_a = 9.81 Н` (еквівалент 1.0 кг тяги)
- Радіальна сила дисбалансу гвинта при вібрації: `F_r = 4.2 Н`
- Робоча температура підшипника: `T = 85 °C` (відповідний `a_ISO ≈ 0.35` через розрідження мастила)
- Коефіцієнт надійності: `a₁ = 1.0` (для 90 % безвідмовності)

**Крок 1: Оцінка відношення навантажень**

```
F_a / F_r
= 9.81 / 4.2       [підстановка вихідних сил]
= 2.336            [перевищує граничний e ≈ 0.28, діє осьовий коефіцієнт]
```

Оскільки `F_a / C₀ = 9.81 / 270 = 0.036`, з таблиці ISO 281 беремо `X = 0.56` та `Y = 1.71`.

**Крок 2: Обчислення еквівалентного навантаження P**

```
P = X · F_r + Y · F_a
= 0.56 · 4.2 + 1.71 · 9.81  [підстановка коефіцієнтів]
= 2.352 + 16.775            [проміжне додавання складових]
= 19.127 Н                  [сумарне еквівалентне навантаження]
```

**Крок 3: Обчислення базового ресурсу L₁₀ у мільйонах обертів**

```
L₁₀ = (C / P)³
= (640 / 19.127)³   [підстановка C та розрахованого P]
= (33.46)³          [відношення вантажопідйомності до навантаження]
= 37 460 млн обертів [номінальний ресурс до втоми]
```

**Крок 4: Перерахунок у номінальні години напрацювання L₁₀ₕ**

```
L₁₀ₕ = (10⁶ / (60 · n)) · L₁₀
= (10⁶ / (60 · 24 000)) · 37 460   [підстановка обертів]
= (10⁶ / 1 440 000) · 37 460       [розрахунок кількості годин на мільйон обертів]
= 0.6944 · 37 460                  [коефіцієнт часу]
= 26 014 годин                     [ідеальний теоретичний ресурс у чистому мастилі]
```

**Крок 5: Корекція на реальні умови (температура й абразивний пил)**

В умовах відкритого польоту потрапляння мікрочастинок пилу через щілинні металеві захисні шайби ZZ знижує `e_C`, а робоча температура 85 °C зменшує товщину мастильної плівки (`a_ISO ≈ 0.35`). При польотах над піщаними ґрунтами фактор забруднення дає додаткове зниження до `a_ISO_real ≈ 0.08...0.12`:

```
L_nm_real = a₁ · a_ISO_real · L₁₀ₕ
= 1.0 · 0.10 · 26 014   [урахування сухого тертя та пилу]
= 2 601 година          [теоретичний ресурс при сталій вібрації]
```

**Крок 6: Вплив динамічного дисбалансу та ударних перевантажень**

Якщо внаслідок сколу кромки пропелера або налипання бруду статичний дисбаланс зростає, радіальна сила `F_r` пропорційна квадрату кутової швидкості:

```
F_r_unbalance = m_imb · r_imb · ω²
```

При зміщенні центру мас гвинта всього на `0.02 г` на радіусі `50 мм` при `24 000 об/хв` (`ω = 2 513 рад/с`):

```
F_r_unbalance = 0.00002 кг · 0.05 м · (2 513 рад/с)²
= 0.000001 · 6 315 169
= 6.315 Н          [додаткова змінна радіальна сила на підшипник]
```

Перераховуючи `P`:

```
P_new = 0.56 · (4.2 + 6.315) + 1.71 · 9.81
= 0.56 · 10.515 + 16.775
= 5.888 + 16.775
= 22.663 Н         [зростання навантаження на 18.5 %]
```

Через кубічну залежність `(C / P)³` ресурс падає:

```
L_ratio = (19.127 / 22.663)³
= (0.844)³
= 0.601            [падіння залишкового ресурсу на 40 %]
```

Звідси випливає фізичне обґрунтування інженерного правила: **незбалансований пропелер або деформований після удару вал двигуна скорочує термін життя підшипника вдвічі при збільшенні вібрацій лише на кілька ньютонів**.

## Спектральні маркери деградації доріжок (BPFI / BPFO)

Коли на доріжці з'являється локальна тріщина або раковина пітингу, кожне проходження кульки генерує мікроудар певної частоти:

```
BPFO = (n / 120) · Z · (1 - (d_b / d_m) · cos(α))   [частота дефекту зовнішнього кільця]
BPFI = (n / 120) · Z · (1 + (d_b / d_m) · cos(α))   [частота дефекту внутрішнього кільця]
BSF  = (n / 120) · (d_m / d_b) · (1 - (d_b / d_m)² · cos²(α)) [частота дефекту кульки]
FTF  = (n / 120) · (1 - (d_b / d_m) · cos(α))       [частота дефекту сепаратора]
```

де `Z` — кількість кульок у підшипнику (зазвичай 6–8), `d_b` — діаметр кульки, `d_m` — середній діаметр підшипника, `α` — кут контакту.

Фіксація сплеску вібрацій на цих характерних частотах у логах польотного контролера (через бортовий FFT-фільтр гіроскопа) дозволяє діагностувати руйнування підшипника задовго до його повного заклинювання.
