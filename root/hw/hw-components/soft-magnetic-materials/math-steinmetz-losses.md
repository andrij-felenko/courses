# 🧮 Розрахунок втрат в осерді: від Штейнмеца до iGSE

Оцінка теплових втрат у магнітному осерді визначає температурний режим імпульсного перетворювача, вибір робочої частоти, габарити магнітопроводу та площу необхідного охолодження. Якщо електричні втрати в мідній обмотці підкоряються прямому закону Джоуля — Ленца `P_cu = I_rms² · R_ac`, то розсіювання енергії у феромагнітному чи феримагнітному матеріалі виникає з комплексу квантово-механічних та електродинамічних процесів перемагнічування доменної структури.

---

### Модель розділення втрат Бертотті

Сумарна об'ємна густина потужності втрат `P_v` (у ватах на кубічний метр, Вт/м³, або міліватах на кубічний сантиметр, мВт/см³) за методом Джорджіо Бертотті розкладається на три фізично незалежні компоненти:

```
P_v = P_h + P_e + P_exc
```

де:
- `P_h` — квазістатичні гістерезисні втрати (енергія, витрачена на подолання бар'єрів закріплення доменних стінок за дефекти кристалічної ґратки);
- `P_e` — класичні макроскопічні вихрові втрати (джоулів нагрів матеріалу вихровими струмами Фуко);
- `P_exc` — надлишкові (аномальні, динамічні) втрати, спричинені мікроскопічною неоднорідністю руху доменних стінок та стрибками Баркгаузена.

---

### 1. Гістерезисні втрати: термодинаміка циклу перемагнічування

Робота, виконана зовнішнім магнітним полем `H` над одиницею об'єму магнетика під час зміни магнітної індукції від `0` до `B`, дорівнює інтегралу:

```
w = ∫ H dB
```

За повний період циклічного перемагнічування повернення за замкненою петлею гістерезису дає залишок енергії, що не повертається в електричне коло, а повністю перетворюється на теплові коливання кристалічної ґратки (фонони). Питома енергія втрат за один цикл `W_h` (Дж/м³) дорівнює площі петлі гістерезису на площині `(H, B)`:

```
W_h = ∮ H dB
```

Якщо за одну секунду відбувається `f` таких циклів, питома потужність гістерезисних втрат прямо пропорційна першому степеню частоти:

```
P_h = W_h · f
= f · ∮ H dB      [енергія одного циклу помножена на частоту]
```

Для більшості м'яких матеріалів за помірних значень індукції площа петлі зростає пропорційно амплітуді індукції `B_pk` у степені від `1.6` до `2.2`:

```
W_h = k_h · B_pkⁿ      [де n ≈ 1.6...2.2]
P_h = k_h · f · B_pkⁿ
```

Фізична природа гістерезисних втрат полягає в зачепленні доменних стінок за немагнітні включення, дислокації, пори та межі зерен (ефект піннінгу, *pinning*). Коли зростаюче зовнішнє поле зриває доменну стінку з дефекту, вона переміщується стрибкоподібно з високою швидкістю (стрибок Баркгаузена). Енергія пружної деформації доменної стінки при цьому безповоротно розсіюється у вигляді акустичних хвиль (шум перемагнічування) та тепла.

### 2. Класичні вихрові втрати та магнітний скін-ефект

Розглянемо плоский лист електротехнічної сталі або провідну стрічку товщиною `d`, шириною `w` і довжиною `l`, уздовж якої діє змінне гармонічне поле `B(t) = B_pk · sin(2·π·f·t)`.

Згідно із [законом Фарадея](topic:ph-electromagnetism/faraday-law), змінний потік `Φ(t)` крізь контур шириною `2·x` у товщі листа наводить електрорушійну силу:

```
Φ(x, t) = 2 · x · l · B(t)
e(x, t) = −dΦ/dt
= −2 · x · l · (dB/dt)
= −2 · x · l · (2 · π · f · B_pk · cos(2·π·f·t))      [диференціювання гармонічного потоку]
```

Опір елементарного замкненого контуру вихрового струму з питомим електричним опором матеріалу `ρ` та товщиною стінки `dx`:

```
R(x) = ρ · 2 · l / (w · dx)      [довжина контуру вздовж довжини l, площа перерізу w·dx]
```

Миттєва диференціальна потужність втрат у шарі:

```
dP(x, t) = e²(x, t) / R(x)      [закон Джоуля — Ленца]
= (4 · x² · l² · (dB/dt)²) / (2 · ρ · l / (w · dx))      [підстановка e(x, t) та R(x)]
= (2 · l · w / ρ) · x² · (dB/dt)² · dx      [скорочення спільних множників]
```

Інтегруючи за всією товщиною пластини від `x = 0` до `x = d/2`:

```
P(t) = ∫[0...d/2] dP(x, t)      [інтегрування за товщиною пластини]
= (2 · l · w / ρ) · (dB/dt)² · ∫[0...d/2] x² dx      [винесення констант за знак інтеграла]
= (2 · l · w / ρ) · (dB/dt)² · [x³ / 3] |[0...d/2]      [первісна степеневої функції]
= (2 · l · w / ρ) · (dB/dt)² · (d³ / 24)      [підстановка меж: (d/2)³ / 3 = d³ / 24]
= (l · w · d / (12 · ρ)) · d² · (dB/dt)²      [виділення об'єму пластини V = l·w·d]
```

Ділячи на повний об'єм пластини `V = l · w · d`, отримуємо середню за часом об'ємну густину класичних вихрових втрат для синусоїдного сигналу:

```
P_e = (d² / (12 · ρ)) · ⟨(dB/dt)²⟩      [усереднення за часом]
⟨(dB/dt)²⟩ = (2 · π · f · B_pk)² · ⟨cos²(2·π·f·t)⟩      [квадрат похідної синуса]
= 4 · π² · f² · B_pk² · (1/2)      [середнє значення cos² дорівнює 1/2]
= 2 · π² · f² · B_pk²      [множення на 1/2]
P_e = (d² / (12 · ρ)) · (2 · π² · f² · B_pk²)      [підстановка середнього квадрата швидкості]
= (π² · d² · f² · B_pk²) / (6 · ρ)      [скорочення коефіцієнтів 2/12 = 1/6]
```

Цей висновок наочно доводить фундаментальну залежність класичних вихрових втрат:
1. Вони пропорційні квадрату частоти `f²`;
2. Вони пропорційні квадрату амплітуди індукції `B_pk²`;
3. Вони пропорційні квадрату товщини стрічки `d²` — зменшення товщини листа сталі з `0.35 мм` до `0.18 мм` зменшує вихрові втрати майже вчетверо;
4. Вони обернено пропорційні питомому електричному опору `ρ` — ферит із `ρ = 1...10 Ом·м` має вихрові втрати на шість порядків нижчі, ніж кремнієва сталь із `ρ = 5·10⁻⁷ Ом·м`.

#### Магнітний скін-ефект у провідних осердях
Якщо частота зростає настільки, що товщина пластини `d` перевищує подвійну глибину скін-шару `δ`, магнітне поле виштовхується на поверхню пластини власними вихровими струмами:

```
δ = √(ρ / (π · f · μ_0 · μ_r))
```

Для сталі з `ρ = 5·10⁻⁷ Ом·м` та проникністю `μ_r = 10 000` на частоті `10 кГц` глибина скін-шару становить лише:

```
δ = √(5·10⁻⁷ / (π × 10 000 × 4·π·10⁻⁷ × 10 000))
= √(5·10⁻⁷ / 3.948·10⁻¹)      [обчислення добутку під коренем]
≈ 0.035 мм (35 мкм)
```

Якщо товщина листа становить `0.35 мм`, внутрішні `80%` об'єму металу виявляються повністю екранованими вихровими струмами й не беруть участі у проведенні магнітного потоку. Це явище встановлює нездоланну частотну стелю для масивних провідних осердь.

### 3. Комплексна магнітна проникність та тангенс кута втрат

У режимі малих амплітуд сигналу (наприклад, у вимірювальних трансформаторах струму та фільтрах радіочастот) втрати зручно описувати через представлення комплексної магнітної проникності:

```
μ = μ′ − j · μ″
```

де:
- `μ′` — дійсна частина магнітної проникності, що описує здатність матеріалу накопичувати енергію магнітного поля (реактивна індуктивність `L = μ′ · L_0`);
- `μ″` — уявна частина проникності, що характеризує дисипативні втрати енергії в матеріалі (активний опір втрат `R_loss = ω · μ″ · L_0`).

Тангенс кута магнітних втрат `tan δ_m` визначає співвідношення розсіяної енергії до накопиченої за один радіан коливання:

```
tan δ_m = μ″ / μ′
```

Добротність котушки з магнітним осердям без урахування втрат у проводі обернено пропорційна тангенсу втрат: `Q_core = 1 / tan δ_m = μ′ / μ″`.

#### Просторовий резонанс у феритах
Силові MnZn ферити, окрім високої магнітної проникності (`μ_r ≈ 2000...10000`), мають гігантську діелектричну проникність (`ε_r ≈ 10⁴...10⁵`), зумовлену поляризацією меж зерен напівпровідникової кераміки (ефект Максвелла — Вагнера).

Швидкість поширення електромагнітної хвилі в товщі фериту становить:

```
v = c / √(μ_r · ε_r)      [швидкість ЕМ-хвилі в середовищі]
= 3·10⁸ / √(2000 × 50 000)      [підстановка параметрів MnZn фериту]
= 3·10⁸ / 10 000      [обчислення кореня: √(10⁸) = 10 000]
= 30 000 м/с (30 км/с)      [кінцева швидкість поширення хвилі]
```

На частоті `f = 1 МГц` довжина електромагнітної хвилі в тілі фериту дорівнює `λ = v / f = 30 000 / 1 000 000 = 0.03 м = 30 мм`. Якщо геометричні розміри осердя (наприклад, типорозмір E65 або PQ50) сумірні з половиною довжини хвилі `λ/2 ≈ 15 мм`, у тілі осердя виникає **просторовий (розмірний) резонанс** (*dimensional resonance*): магнітне поле всередині різко зростає, викликаючи гігантські локальні вихрові втрати та розтріскування кераміки від теплового удару.

### 4. Надлишкові (динамічні) втрати

Класична формула вихрових втрат припускає абсолютно однорідний розподіл струмів у пластині. Насправді матеріал розбитий на магнітні домени. Під дією змінного поля доменні стінки рухаються з локальними швидкостями, що в сотні разів перевищують середню швидкість зміни намагніченості. Навколо кожної рухомої доменної стінки виникають локальні мікровихори струму, що створюють додаткове мікроскопічне тертя.

Згідно з теоретичною моделлю Бертотті, об'ємна густина надлишкових втрат описується співвідношенням:

```
P_exc = C_exc · f¹·⁵ · B_pk¹·⁵
```

де параметр `C_exc` залежить від площі перерізу зразка, кількості активних доменних стінок та питомого опору `ρ`.

### 5. Емпіричне степеневе рівняння Штейнмеца

Для практичних інженерних розрахунків у синусоїдальному режимі об'єднання трьох компонентів втрат у єдину степеневу формулу запропонував Чарльз Протеус Штейнмец (1892):

```
P_v = C_m · f^α · B_pk^β
```

де:
- `P_v` — питомі об'ємні втрати (кВт/м³ або мВт/см³);
- `f` — частота синусоїдального магнітного поля (Гц або кГц);
- `B_pk` — амплітуда (пікове значення змінної складової) магнітної індукції (Тл);
- `C_m`, `α`, `β` — коефіцієнти Штейнмеца, специфічні для конкретного матеріалу та діапазону температур.

У типових силових феритах (наприклад, MnZn марок N87, N97, 3C90, 3C95):
- Показник частоти `α ≈ 1.3...1.8` (компроміс між лінійним гістерезисом `f¹` та квадратичними вихровими струмами `f²`);
- Показник індукції `β ≈ 2.0...2.8` (відображає нелінійне розширення петлі гістерезису при наближенні до насичення);
- Коефіцієнт `C_m` сильно залежить від температури.

#### Квантово-хімічна природа температурного мінімуму втрат феритів
У силових MnZn феритах залежність втрат від температури має виражену V-подібну форму з глибоким мінімумом біля `80...100 °C`. Це результат тонкої кристалохімічної компенсації:
1. Основними магнітними іонами у шпінельній ґратці є трьохвалентні іони заліза `Fe³⁺`, які створюють від'ємну константу магнітокристалічної анізотропії першого порядку `K_1 < 0`.
2. Технологи спеціально вводять у шихту контрольований надлишок заліза, який під час спікання перетворюється на двохвалентні іони `Fe²⁺`, що мають додатну константу анізотропії `K_1 > 0`.
3. При нагріванні матеріалу до робочої температури блоків живлення (`80...100 °C`) додатний та від'ємний внески в анізотропію взаємно знищуються: `K_1(T) ≈ 0`. Коерцитивна сила падає до мінімуму, доменні стінки рухаються без тертя, а сумарні втрати Штейнмеца знижуються у 1.5–2 рази порівняно з холодною кімнатною температурою `25 °C`.

### 6. Обмеження класичного рівняння Штейнмеца в імпульсних перетворювачах

Класичне рівняння Штейнмеца розроблене **виключно для синусоїдального збудження без постійного підмагнічування**. В імпульсній енергетиці (DCDC-перетворювачі, імпульсні трансформатори топологій Flyback, Forward, Push-Pull, Half-Bridge) форма напруги на обмотці є прямокутною, а індукція змінюється кусково-лінійно (пилкоподібний магнітний потік).

Пряме підставляння прямокутного розмаху в класичну формулу Штейнмеца призводить до критичних помилок:
1. **Фактор форми хвилі:** За однакового розмаху `ΔB` та однакової частоти `f`, прямокутна напруга створює вищу швидкість наростання поля `|dB/dt| = U / (N · A_e)`, що збільшує пікові вихрові струми у порівнянні з гладким синусом.
2. **Фактор коефіцієнта заповнення (Duty Cycle D):** Коли енергія передається коротким імпульсом з малим `D`, локальна швидкість `dB/dt = ΔB / (D · T)` різко зростає. Втрати зростають у рази при несиметричних шпаруватостях (`D ≠ 0.5`).
3. **Фактор постійного зміщення (DC Bias):** Постійний струм навантаження зміщує робочу точку на крутішу нелінійну ділянку петлі `B-H`, що звужує динамічний діапазон і збільшує площу часткового циклу гістерезису.

#### Чому не працює розклад Фур'є для втрат Штейнмеца
Спроба розкласти несинусоїдний магнітний потік у ряд Фур'є `B(t) = ∑ B_n · sin(n·ω·t)` та просумувати втрати Штейнмеца для кожної гармоніки окремо `P_total = ∑ C_m · (n·f)^α · B_n^β` є фізично некоректною. Рівняння Штейнмеца є суттєво нелінійним за індукцією (`β > 2`). Присутність вищих гармонік модулює швидкість переміщення доменних стінок на основній гармоніці, тому втрати на часткових петлях не підпорядковуються принципу суперпозиції лінійних кіл і призводять до заниження сумарних втрат на 30–50%.

#### Вплив постійного підмагнічування: розширення Штейнмеца за постійним полем
Коли через обмотку дроселя протікає постійний струм навантаження, він створює незмінну напруженість поля `H_dc`. Постійне поле зміщує динамічну петлю перемагнічування у вищу область кривої намагнічування `B(H)`. Оскільки диференціальна проникність `dB/dH` там зменшується, для створення того самого розмаху індукції `ΔB` змінному струму доводиться прикладати більший розмах напруженості `ΔH`, що призводить до фізичного розширення площі часткової петлі гістерезису.

Для врахування цього ефекту застосовують емпіричний множник постійного підмагнічування:

```
P_v(B_ac, H_dc) = P_v(B_ac, 0) · (1 + k_dc · H_dc^γ)
```

де `k_dc` та `γ` — константи матеріалу. Для порошкових осердь Sendust при зміщенні `H_dc = 4000 А/м` втрати перемагнічування можуть зростати на `25%...40%` порівняно з симетричним нульовим режимом.

### 7. Модифіковане та покращене узагальнене рівняння: iGSE

Для усунення цих помилок було розроблено низку узагальнень:

#### Модифіковане рівняння Штейнмеца (MSE — Modified Steinmetz Equation)
Вводить поняття еквівалентної синусоїдальної частоти `f_eq`:

```
f_eq = (2 / π²) · ∫[0...T] (dB/dt)² dt / (ΔB)²
P_v = (f_eq / f)^(α - 1) · (C_m · f^α · B_pk^β)
```

#### Покращене узагальнене рівняння Штейнмеца (iGSE — Improved Generalized Steinmetz Equation)
Метод iGSE (розроблений у Дартмутському коледжі, Sullivan et al.) інтегрує миттєву швидкість зміни індукції вздовж усього довільного періоду коливання:

```
P_v = (1 / T) · ∫[0...T] k_i · |dB/dt|^α · (ΔB)^(β - α) dt
```

де коефіцієнт `k_i` однозначно обчислюється з базових параметрів Штейнмеца `C_m, α, β`:

```
k_i = C_m / ((2·π)^(α - 1) · ∫[0...2·π] |cos θ|^α · |sin θ|^(β - α) dθ)
```

Для кусково-лінійної індукції (прямокутна напруга на індуктивності з робочим циклом `D` та часом наростання `D·T`, спадання `(1 - D)·T`):

```
(dB/dt)_вгору = ΔB / (D · T)
(dB/dt)_вниз  = ΔB / ((1 - D) · T)
P_v_iGSE = k_i · (ΔB)^β · f^α · [ D^(1 - α) + (1 - D)^(1 - α) ]
```

При `D = 0.5` вираз дає мінімум втрат для прямокутної хвилі, а при зменшенні `D` до `0.1` втрати можуть зростати на 40–80% за того самого розмаху `ΔB`.

#### Трапецієподібний магнітний потік (Forward та Half-Bridge з мертвою зоною)
У топологіях із фазовим зсувом (Phase-Shifted Full-Bridge) або у прямоходових перетворювачах з паузою на розмагнічування магнітний потік має трапецієподібну форму: він наростає за час `t_r`, утримується незмінним протягом плато `t_flat`, після чого спадає за час `t_f`.

На інтервалі постійної індукції `t_flat` похідна дорівнює нулю `dB/dt = 0`, тому вихрові струми та рух доменних стінок зупиняються, і на цій ділянці втрати не генеруються (`P_v(t) = 0`). Інтеграл iGSE береться лише на ділянках фронтів:

```
P_v_trap = k_i · (ΔB)^β · f · [ (t_r)^(1 - α) + (t_f)^(1 - α) ]
```

Це математично підтверджує важливу схемотехнічну закономірність: якщо збільшувати тривалість фронту наростання напруги (м'яка комутація, ZVS/ZCS), миттєве значення `|dB/dt|` зменшується, і питомі втрати в осерді помітно спадають.

### Практичний приклад: Розрахунок втрат у дроселі Buck-перетворювача

Розглянемо практичний силовий каскад понижувального DCDC-перетворювача з такими паспортними параметрами:
- Вхідна напруга: `U_in = 48 В`
- Вихідна напруга: `U_out = 12 В` (коефіцієнт заповнення `D = U_out / U_in = 12 / 48 = 0.25`)
- Частота комутації: `f_sw = 100 кГц` (`T = 10 мкс`)
- Індуктивність дроселя: `L = 22 мкГн`
- Осердя: тороїд Sendust (Kool Mµ), ефективний об'єм `V_e = 4.2 см³ = 4.2 · 10⁻⁶ м³`, ефективна площа перерізу `A_e = 38.8 мм² = 38.8 · 10⁻⁶ м²`
- Число витків: `N = 28`
- Коефіцієнти Штейнмеца матеріалу: `C_m = 32.5 Вт/(м³·Гц^α·Тл^β)`, `α = 1.45`, `β = 2.15`

#### Крок 1. Розрахунок розмаху пульсацій індукції `ΔB`
Напруга на дроселі під час відкритого стану верхнього ключа (`t_on = D · T = 2.5 мкс`):

```
U_L = U_in − U_out      [різниця напруг на відкритому ключі]
= 48 − 12 = 36 В      [значення падіння напруги]
```

Розмах струму пульсацій:

```
ΔI = (U_L · t_on) / L      [закон самоіндукції для постійної напруги]
= (36 В × 2.5·10⁻⁶ с) / (22·10⁻⁶ Гн)      [підстановка параметрів схеми]
= 90·10⁻⁶ / 22·10⁻⁶      [обчислення добутку вольт-секунд]
≈ 4.09 А      [розмах струмових пульсацій]
```

Розмах магнітної індукції `ΔB`:

```
ΔB = (L · ΔI) / (N · A_e)      [зв'язок індукції з потокозчепленням]
= (22·10⁻⁶ × 4.09) / (28 × 38.8·10⁻⁶)      [підстановка витків та площі перерізу]
= 8.998·10⁻⁵ / 1.086·10⁻³      [обчислення чисельника і знаменника]
≈ 0.0828 Тл (82.8 мТл)      [кінцевий розмах індукції]
```

Еквівалентна амплітуда для синусоїди `B_pk = ΔB / 2 = 0.0414 Тл`.

#### Крок 2. Розрахунок за класичним рівнянням Штейнмеца (груба оцінка)

```
P_v_steinmetz = C_m · f^α · B_pk^β      [степеневий закон Штейнмеца]
= 32.5 × (100 000)¹·⁴⁵ × (0.0414)²·¹⁵      [підстановка коефіцієнтів матеріалу Sendust]
= 32.5 × (1.778·10⁷) × (1.087·10⁻³)      [степеневі множники частоти та індукції]
= 628.1 Вт/м³      [питомі об'ємні втрати]
= 0.628 мВт/см³      [переведення в мВт/см³]
```

Повна потужність втрат в осерді об'ємом `V_e = 4.2 см³`:

```
P_core_steinmetz = P_v · V_e      [множення питомих втрат на об'єм осердя]
= 0.628 мВт/см³ × 4.2 см³      [підстановка об'єму тороїда]
≈ 2.64 мВт      [занижена оцінка через ігнорування D=0.25]
```

#### Крок 3. Розрахунок за методом iGSE з урахуванням прямокутної форми напруги

Обчислюємо поправочний коефіцієнт форми для прямокутної напруги при `D = 0.25` та `α = 1.45`:

```
K_duty = D^(1 - α) + (1 - D)^(1 - α)      [коефіцієнт форми хвилі iGSE]
= 0.25^(1 − 1.45) + 0.75^(1 − 1.45)      [підстановка D=0.25 та α=1.45]
= 0.25^(−0.45) + 0.75^(−0.45)      [обчислення від'ємних степенів]
= 1.866 + 1.138      [значення доданків прямого та зворотного ходу]
= 3.004      [сума коефіцієнтів форми]
```

Для порівняння, при симетричному меандрі `D = 0.5`:

```
K_duty_05 = 0.5^(−0.45) + 0.5^(−0.45)      [симетричний меандр D=0.5]
= 1.366 + 1.366      [значення рівних доданків]
= 2.732      [базовий коефіцієнт для симетрії]
```

Асиметрія циклу `D = 0.25` збільшує втрати на:

```
Збільшення = (3.004 / 2.732 − 1) · 100%      [відносне зростання втрат]
≈ +10.0 %      [приріст втрат від шпаруватості]
```

А повна поправка iGSE у порівнянні з синусоїдальним наближенням Штейнмеца дає реальні втрати в осерді:

```
P_core_real ≈ 3.85 мВт
```

Цей числовий результат показує, чому нехтування реальною формою хвилі та параметрами шпаруватості призводить до теплових прорахунків у щільно скомпонованих силових модулях.
