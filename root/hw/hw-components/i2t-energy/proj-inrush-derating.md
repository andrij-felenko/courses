# ⚙️ Розрахунок пускового I²t і вибір запобіжника з урахуванням деградації

Кожен імпульсний блок живлення (SMPS), мережевий інвертор, зарядний пристрій або силовий привод містить на вході ємнісний фільтр великої місткості або масивний силовий трансформатор. У момент першого замикання мережевого вимикача повністю розряджений конденсаторний блок еквівалентний «глухому» короткому замиканню: струм у перші мікросекунди обмежується виключно паразитним імпедансом живильної мережі, монтажними проводами та спеціальним пусковим терморезистором (NTC).

Хоча цей імпульс заряду триває лише лічені мілісекунди і не повинен викликати миттєвого спрацьовування вхідного захисту, регулярні цикли вмикання створюють небезпечний кумулятивний ефект. Металева нитка запобіжника зазнає різкого локального стрибка температури з подальшим охолодженням. Внаслідок постійних циклів теплового розширення та стискання на межах кристалічних зерен металу накопичуються мікроскопічні тріщини, зростає внутрішній опір, і через сотні або тисячі запусків прилад несподівано перегорає під час чергового штатного вмикання без жодної аварії в колі.

Нижче наведено строгу фізико-математичну методику інженерного розрахунку пускового інтеграла наскрізної енергії `I²t_inrush`, алгоритм визначення коефіцієнта циклічної деградації (Pulse Derating Factor), аналіз схемотехніки активного обмеження пускового струму (Active Inrush Limiters), методику лабораторних вимірювань цифровим осцилографом, а також завершені обчислювальні модулі мовами C та C++.

## 1. Фізична модель пускового імпульсу заряджання конденсаторів

Розгляньмо типовий вхідний каскад імпульсного перетворювача: однофазна змінна напруга промислової мережі з діючим значенням `U_rms = 230` В (частота 50 Гц) випрямляється діодним мостом і заряджає батарею електролітичних конденсаторів сумарною ємністю `C`.

Найгірший розрахунковий випадок увімкнення припадає на момент, коли миттєва напруга мережі досягає максимального амплітудного піку синусоїди:

```
U_pk = √2 · U_rms = 1.4142 · 230 В ≈ 325.3 В        [пікова амплітуда мережевої напруги]
```

Повний активний опір пускового контуру `R_total` утворений послідовним з'єднанням кількох елементів: опору холодного обмежувального NTC-терморезистора `R_ntc` (при температурі 25 °C), еквівалентного послідовного опору батареї конденсаторів `ESR`, динамічного опору пари відкритих діодів випрямляча `R_diode`, а також активного опору вхідного фільтра ЕМС і мережевих проводів `R_line`:

```
R_total = R_ntc + ESR + R_diode + R_line        [сумарний опір пускового кола]
```

Початковий піковий струм заряду в момент замикання контактів:

```
I_pk = U_pk / R_total        [початковий піковий струм заряду ємності]
```

Характеристична стала часу експоненційного заряджання RC-контуру:

```
τ = R_total · C        [стала часу перехідного процесу]
```

Миттєве значення струму описується спадною експонентою `i(t) = I_pk · e^(-t/τ)`. Інтеграл Джоуля за час усього перехідного процесу (інтегрування від `t = 0` до `t = ∞` або практично до `t > 3τ`):

```
I²t_inrush = ∫[0..∞] (I_pk · e^(-t/τ))² dt = (1 / 2) · I_pk² · τ        [інтеграл Джоуля експоненційного сплеску]
```

Підставляючи вирази для `I_pk` та `τ`:

```
I²t_inrush = (1 / 2) · (U_pk / R_total)² · (R_total · C) = (1 / 2) · U_pk² · (C / R_total)        [залежність пускової енергії від ємності та опору]
```

Ця формула демонструє важливу закономірність: накопичена в запобіжнику теплова доза `I²t_inrush` прямо пропорційна ємності фільтра `C` і обернено пропорційна активному опору обмежувача `R_total`.

## 2. Пускові струми трансформаторів і двигунів

Крім заряджання ємностей, в інженерній практиці часто зустрічаються інші джерела пускових струмів з іншою формою хвилі та тривалістю:

1. **Намагнічування силового трансформатора:** під час увімкнення трансформатора в момент переходу напруги через нуль магнітний потік у сердечнику намагається подвоїтися. Феромагнітне осердя входить у глибоке магнітне насичення, його магнітна проникність падає практично до проникності повітря, а індуктивний опір первинної обмотки колапсує. Струм набуває форми послідовності однополярних напівсинусоїдальних імпульсів тривалістю по 10 мс кожен із поступовим експоненційним згасанням протягом 100–500 мс. Для таких кіл інтеграл `I²t_inrush` обчислюють як суму інтегралів окремих напівхвиль:
   ```
   I²t_trans = ∑[k=1..M] (0.5 · I_pk,k² · t_half)        [інтеграл серії імпульсів насичення осердя]
   ```
2. **Пуск асинхронного електродвигуна:** поки ротор залишається нерухомим, двигун працює в режимі короткозамкненого трансформатора. Пусковий струм становить `6–8 · I_nom` і утримується протягом часу розгону приводу `t_start = 0.5–5.0` секунд. Для таких застосувань використовують спеціалізовані моторні запобіжники класу `aM` або повільні вставки типу Time-Lag (T).

## 3. Схемотехніка активного обмеження пускового струму

У потужних промислових блоках живлення та інверторах пасивного NTC-терморезистора недостатньо через проблему гарячого перезапуску та втрати ККД. Застосовують три основні активні топології:

1. **NTC з релейним шунтуванням:** після завершення заряду конденсатора (через 100–200 мс) контакти електромеханічного реле замикаються накоротко паралельно NTC. Це виключає нагрів терморезистора робочим струмом, підвищує ККД на 1–2% і дозволяє NTC швидко охолонути для готовності до повторного пуску.
2. **Тиристорний плавний пуск (SCR Pre-charge):** пара діодів вхідного моста замінюється керованими тиристорами. Кут відкривання тиристорів плавно зменшується мікроконтролером від 180° до 0° протягом 50–200 мс, формуючи плавний наростаючий струм без ударного сплеску. Інтеграл `I²t_inrush` при цьому знижується у 10–50 разів.
3. **Активний MOSFET-обмежувач на шині DC-link:** польовий транзистор працює в лінійному режимі як джерело стабільного струму заряду `I_charge = C · (dV/dt)`, після чого повністю відкривається з мінімальним опором каналу `R_ds(on)`.

## 4. Механізм циклічної деградації та коефіцієнт Pulse Derating

Кожен імпульс пускового струму локально розігріває металеву нитку запобіжника. Якщо енергія імпульсу `I²t_inrush` становить значну частку від номінального паспортного інтеграла плавлення `I²t_melt` (наприклад, 60–80%), метал не встигає повністю розплавитися, проте досягає температур 400–700 °C.

При багаторазовому повторенні таких термомеханічних ударів виникають три руйнівні явища:

1. **Термовтомні мікротріщини:** внаслідок циклічного розширення та стискання в зонах звужень стрічки формуються кристалічні дислокації та втомні тріщини вздовж меж зерен.
2. **Високотемпературне окислення:** поверхневий шар міді або сплаву вступає в реакцію з киснем повітря всередині колби, що поступово зменшує робочий поперечний переріз жили.
3. **Міграція евтектичних компонентів:** у повільних запобіжниках із M-ефектом крапля легкоплавкого сплаву зазнає мікродифузії в срібну основу, знижуючи поріг розплавлення.

Щоб запобіжник гарантовано витримав плановий життєвий цикл обладнання (наприклад, 10 000 або 50 000 вмикань приладу користувачем), інженери використовують коефіцієнт зниження імпульсної стійкості `K_pulse` (Pulse Derating Factor).

| Очікуваний життєвий ресурс (N циклів) | Максимально допустиме відношення I²t_inrush / I²t_melt (K_pulse) | Мінімально необхідний коефіцієнт запасу за енергією (1 / K_pulse) |
| :--- | :--- | :--- |
| 1 (одноразовий аварійний імпульс) | `1.00` (100%) | `1.00×` |
| 10 | `0.70` (70%) | `1.43×` |
| 100 | `0.50` (50%) | `2.00×` |
| 1 000 | `0.38` (38%) | `2.63×` |
| 10 000 | `0.29` (29%) | `3.45×` |
| 50 000 | `0.23` (23%) | `4.35×` |
| 100 000 | `0.20` (20%) | `5.00×` |

Для автоматизованого розрахунку в коді дискретну табличну залежність апроксимують емпіричною степеневою функцією:

```
K_pulse(N) ≈ 1.0 · N^(-0.14)        [степенева апроксимація кривої втоми матеріалу]
```

Критерій вибору за імпульсною стійкістю формулюється так:

```
I²t_melt_паспортний ≥ I²t_inrush / K_pulse(N)        [головна умова вибору запобіжника за пусковим струмом]
```

## 5. Температурний дерайтинг номінального струму

Паспортний номінальний струм запобіжника `I_n` калібрується виробниками за стандартизованої температури навколишнього середовища 25 °C на відкритому повітрі.

У реальній апаратурі запобіжник встановлюють у закритий пластиковий або металевий корпус, де температура повітря внаслідок нагріву силових радіаторів, діодів і трансформаторів часто сягає 50–70 °C. Підвищена температура погіршує конвективне та кондуктивне охолодження тримача, через що запобіжник плавиться при значно меншому діючому струмі навантаження.

Для врахування температури застосовують коефіцієнт температурного дерайтингу `K_temp` (типово 0.85–0.90 при 55 °C для керамічних вставок) та нормативний коефіцієнт тривалого безперервного навантаження 0.75 (загальноприйняте правило проєктування за стандартами IEC/UL 60950/62368):

```
I_n_min = I_rms_load / (K_temp · 0.75)        [мінімальний номінальний струм запобіжника]
```

де `I_rms_load` — діючий середньоквадратичний струм споживання пристрою при мінімально допустимій напрузі живильної мережі `U_rms_min` (наприклад, 180 В для мережі 230 В або 85 В для універсальних блоків живлення Wide-Range 85–265 В).

## 6. Лабораторне вимірювання пускового I²t осцилографом

Для підтвердження теоретичних розрахунків виконують пряме фізичне вимірювання форми пускового струму в лабораторії:

1. **Датчик струму:** застосовують широкосмуговий коаксіальний струмовий шунт (Current Shunt) з власною індуктивністю менше 1 нГн або прецизійний струмовий пробник Роговського / датчик Холла з робочою смугою не менше 10–50 МГц.
2. **Фазування вмикання:** увімкнення здійснюють через кероване твердотільне реле з можливістю синхронізації з піком фази напруги 90° (Phase Angle Trigger).
3. **Математична функція осцилографа:** на цифровому запам'ятовуючому осцилографі налаштовують математичний канал `Math = Integral(Ch1 * Ch1, dt)`. Перед інтегруванням виконують калібрування нуля каналу (Auto-Zero), щоб запобігти лінійному дрейфу інтеграла від постійного зміщення АЦП.
4. **Обробка даних:** отримують максимальне плато інтегральної кривої наприкінці перехідного процесу, яке і є реальним значенням `I²t_inrush`.

## 8. Типові інженерні пастки при проєктуванні захисту від пускових струмів

1. **Ігнорування циклічної деградації:** розрахунок запобіжника за спрощеною формулою `I²t_melt > I²t_inrush` без урахування коефіцієнта втоми гарантує, що прилад вийде з ладу вже через кілька десятків вмикань. Для надійної роботи побутової та промислової апаратури необхідний 4–5-кратний запас за енергією розплавлення.
2. **Гарячий перезапуск (Hot Restart Trap):** під час тривалої роботи NTC-терморезистор нагрівається робочим струмом до 100–140 °C, і його опір падає з початкових 10 Ом до часток ома (0.3–0.8 Ом). Якщо користувач вимкне пристрій і негайно ввімкне його знову протягом 1–3 секунд (поки NTC гарячий), опір кола виявиться мінімальним, пусковий струм підскочить до сотень ампер, а енергія імпульсу `I²t` зросте у десятки разів, що призведе до миттєвого перегорання вхідного запобіжника. Для виключення цієї проблеми в якісних джерелах живлення NTC шунтують електромеханічним реле після старту, що забезпечує його постійне охолодження в робочому режимі.
