# 🧮 Термодинамічний вивід адіабатичного нагріву та інтеграли форм хвилі

Коли крізь провідник протікає струм короткого замикання, електрична енергія за частки мілісекунди перетворюється на внутрішню теплову енергію металу. Якщо тривалість аварійного процесу становить менше 5–10 мілісекунд, теплопередача в навколишнє середовище — ізоляційну оболонку кабелю, навколишнє повітря чи діелектричну основу друкованої плати — практично не встигає розвинутися. Увесь тепловий потік залишається повністю замкненим усередині кристалічної решітки провідної жили. Такий режим нагріву в термодинаміці називають строго адіабатичним.

Нижче наведено строгий математичний вивід фундаментального диференціального рівняння нагріву провідника струмом короткого замикання з урахуванням температурного коефіцієнта електричного опору, аналітичний вивід формули Ондердонка, виведення нормативного розрахункового коефіцієнта `k` для кабельних ліній за стандартом IEC 60364-5-54, математичне обґрунтування критерію адіабатичності через дифузію тепла, розрахунок термічної стійкості перехідних отворів друкованих плат, а також точні аналітичні формули інтеграла Джоуля `∫ i² dt` для аперіодичних мережевих аварій та динаміку гасіння дуги в індуктивному колі.

## 1. Критерій адіабатичності та дифузія тепла

Перш ніж записувати тепловий баланс без тепловіддачі, необхідно математично довести межі, у яких припущення про відсутність тепловідтоку є фізично коректним.

Поширення тепла в твердому тілі підпорядковується диференціальному рівнянню теплопровідності Фур'є. Для одновимірного випадку вздовж просторової координати `x` воно має вигляд:

```
∂T / ∂t = a_th · (∂²T / ∂x²) + q_v / (d · c_p)        [рівняння теплопровідності з внутрішнім джерелом тепла]
```

Тут `a_th` — коефіцієнт температуропровідності матеріалу (м²/с), що визначається через теплопровідність `λ_th` (Вт/(м·°C)), густину `d` (кг/м³) та питому теплоємність `c_p` (Дж/(кг·°C)):

```
a_th = λ_th / (d · c_p)        [коефіцієнт температуропровідності]
```

Для чистої електротехнічної міді при кімнатній температурі:
* `λ_th = 390` Вт/(м·°C)
* `d = 8900` кг/м³
* `c_p = 385` Дж/(кг·°C)
* `a_th = 390 / (8900 · 385) ≈ 1.14 · 10⁻⁴` м²/с

Характерна глибина теплового проникнення `δ_th` (товщина шару, у який тепло встигає протекти за час `t` від початку імпульсу) оцінюється як:

```
δ_th ≈ 2 · √(a_th · t)        [глибина дифузії теплового фронту]
```

Обчислимо глибину теплового проникнення для різних інтервалів часу аварії:

1. За час надшвидкого короткого замикання `t = 1` мс:
   `δ_th = 2 · √(1.14 · 10⁻⁴ · 0.001) = 2 · √(1.14 · 10⁻⁷) ≈ 2 · 3.37 · 10⁻⁴ м ≈ 0.67` мм.
2. За час відключення стандартного автоматичного вимикача `t = 10` мс:
   `δ_th = 2 · √(1.14 · 10⁻⁴ · 0.01) ≈ 2.13` мм.
3. За тривалості перевантаження `t = 1` с:
   `δ_th = 2 · √(1.14 · 10⁻⁴ · 1.0) ≈ 21.3` мм.

У типових провідниках кабелів перерізом 1.5–16 мм² (радіус жили 0.7–2.3 мм) або на доріжках друкованих плат (товщина фольги 35–105 мкм) за час `t < 5` мс глибина проникнення в навколишню ізоляцію практично нульова, оскільки теплопровідність ізоляційних матеріалів (PVC, XLPE, FR4) на три порядки нижча за мідь (`λ_pvc ≈ 0.15–0.2` Вт/(м·°C), `a_th,pvc ≈ 8 · 10⁻⁸` м²/с). Отже, втрати тепла в оболонку за інтервал менше 5–10 мс становлять менше 1–2% від усієї виділеної енергії, що строго гарантує адіабатичність процесу.

## 2. Диференціальне рівняння адіабатичного нагріву

Розгляньмо однорідний металевий провідник постійної площі поперечного перерізу `S` (м²) та довжини `l` (м). Маса провідника `m` виражається через його густину `d` (кг/м³) та геометричні розміри:

```
m = d · S · l        [маса як добуток густини на об'єм]
```

Електричний опір провідника `R(T)` є функцією температури через питомий електричний опір `ρ(T)` (Ом·м):

```
R(T) = ρ(T) · l / S        [опір однорідного провідника довжиною l і перерізом S]
```

У широкому інженерному діапазоні температур від кімнатної до точки плавлення залежність питомого електричного опору металів від температури описується лінійним законом відносно базової температури `T_0 = 20` °C:

```
ρ(T) = ρ_0 · [1 + α · (T - T_0)]        [температурна залежність питомого опору]
```

де `ρ_0` — питомий електричний опір при температурі `T_0`, а `α` — температурний коефіцієнт опору (1/°C).

За диференціально малий проміжок часу `dt` миттєвий струм `i(t)` генерує в провіднику теплоту за законом Джоуля:

```
dQ_el = i²(t) · R(T) dt = i²(t) · (ρ(T) · l / S) dt        [виділена електрична енергія]
```

В умовах адіабатичної ізоляції вся згенерована енергія витрачається виключно на зміну внутрішньої енергії провідника, спричиняючи підвищення температури на `dT`:

```
dQ_th = m · c_p · dT = (d · S · l) · c_p · dT        [теплоємнісне поглинання теплоти]
```

Прирівнюючи диференціали `dQ_el = dQ_th`:

```
i²(t) · ρ(T) · (l / S) dt = d · S · l · c_p · dT        [рівняння миттєвого теплового балансу]
```

Довжина провідника `l` присутня як спільний множник в обох частинах рівності і скорочується:

```
i²(t) dt = (c_p · d · S² / ρ(T)) dT        [незалежність нагріву від довжини провідника]
```

Підставляючи температурну залежність питомого опору `ρ(T)`:

```
i²(t) dt = [ (c_p · d · S²) / (ρ_0 · (1 + α · (T - T_0))) ] dT        [рівняння з розділеними змінними]
```

## 3. Інтегрування та вивід формули Ондердонка

Інтегруємо ліву частину за часом від початкового моменту аварії `t = 0` до повного відключення `t = t_clear`, а праву частину — за температурою від вихідного робочого стану `T_i` до кінцевої аварійної температури `T_f`:

```
∫[0..t_clear] i²(t) dt = (c_p · d · S² / ρ_0) · ∫[T_i..T_f] (1 / (1 + α · (T - T_0))) dT        [інтегральна форма балансу]
```

Виконаємо аналітичне інтегрування правої частини за допомогою заміни змінної `u = 1 + α · (T - T_0)`, де диференціал `du = α · dT`:

```
∫ (1 / u) · (du / α) = (1 / α) · ln(u)        [інтеграл логарифмічного типу]
```

Обчислюємо визначений інтеграл на межах від `T_i` до `T_f`:

```
∫[T_i..T_f] (1 / (1 + α · (T - T_0))) dT
= (1 / α) · [ ln(1 + α · (T_f - T_0)) - ln(1 + α · (T_i - T_0)) ]      [підстановка меж інтегрування]
= (1 / α) · ln[ (1 + α · (T_f - T_0)) / (1 + α · (T_i - T_0)) ]        [перехід до логарифма частки]
```

Підставляючи знайдений інтеграл у балансове рівняння, одержуємо точний аналітичний вираз:

```
∫[0..t_clear] i²(t) dt = (c_p · d · S² / (ρ_0 · α)) · ln[ (1 + α · (T_f - T_0)) / (1 + α · (T_i - T_0)) ]        [точний адіабатичний інтеграл Джоуля]
```

Введемо фундаментальну характеристичну константу матеріалу — фіктивну температуру абсолютного нуля опору:

```
T_k = (1 / α) - T_0        [температурна константа екстраполяції нульового опору]
```

Для чистої міді з коефіцієнтом `α = 0.00393` 1/°C при опорній температурі `T_0 = 20` °C:

```
T_k = (1 / 0.00393) - 20 = 254.45 - 20 ≈ 234.5 °C        [константа T_k для міді]
```

Тоді логарифмічний вираз набуває компактної та симетричної форми:

```
(1 + α · (T_f - T_0)) / (1 + α · (T_i - T_0)) = (T_f + 234.5) / (T_i + 234.5)        [логарифмічне відношення температур]
```

Підставляючи це відношення, одержуємо класичну формулу Ондердонка (I. M. Onderdonk):

```
I²t_допустимий = S² · [ (c_p · d) / (ρ_0 · α) ] · ln[ (T_f + 234.5) / (T_i + 234.5) ]        [формула Ондердонка]
```

Якщо струм короткого замикання вважати умовно постійним `I_rms` протягом часу `t`, формулу записують відносно часу до розплавлення або досягнення граничної температури:

```
t = (S / I_rms)² · [ (c_p · d) / (ρ_0 · α) ] · ln[ (T_f + 234.5) / (T_i + 234.5) ]        [час адіабатичного нагріву]
```

Для алюмінієвих провідників константа `T_k ≈ 228` °C, а електротепловий коефіцієнт `(c_p · d) / (ρ_0 · α)` суттєво відрізняється через меншу густину та вищий питомий опір.

## 4. Зв'язок із нормативом IEC 60364-5-54: фактор k

Міжнародний електротехнічний стандарт IEC 60364-5-54 регламентує перевірку провідників на термічну стійкість під час протікання струмів короткого замикання тривалістю до 5 секунд за допомогою уніфікованої формули:

```
k² · S² ≥ I²t        [нормативна умова перевірки термічної стійкості]
```

де:
* `S` — площа поперечного перерізу провідника, мм²;
* `I²t` — повна наскрізна енергія вимикання захисного апарата (Clearing I²t), А²·с;
* `k` — розрахунковий коефіцієнт матеріалу жили та типу ізоляції, А·с^0.5 / мм².

Шляхом прямого зіставлення нормативної нерівності з виведеним термодинамічним інтегралом знаходимо аналітичну формулу для визначення коефіцієнта `k`:

```
k = 10⁻⁶ · √[ [ (c_p · d) / (ρ_0 · α) ] · ln[ (T_f + T_k) / (T_i + T_k) ] ]        [аналітичний вираз коефіцієнта k]
```

Множник `10⁻⁶` виникає внаслідок переводу площі перерізу з метрів квадратних (СІ) у міліметри квадратні: `(1 мм)² = 10⁻⁶ м²`.

### 4.1. Розрахунок коефіцієнта k для мідного кабелю з PVC ізоляцією

Вихідні параметри матеріалів за стандартом:
* Питома теплоємність міді: `c_p = 385` Дж/(кг·°C)
* Густина міді: `d = 8900` кг/м³
* Питомий опір при 20 °C: `ρ_0 = 1.724 · 10⁻⁸` Ом·м
* Температурний коефіцієнт опору: `α = 0.00393` 1/°C
* Тривала допустима робоча температура для полівінілхлориду (PVC): `T_i = 70` °C
* Максимальна гранична температура PVC за короткого замикання: `T_f = 160` °C

Поетапний розрахунок:

```
(c_p · d) / (ρ_0 · α)
= (385 · 8900) / (1.724 · 10⁻⁸ · 0.00393)      [підстановка параметрів міді]
= 3 426 500 / (6.77532 · 10⁻¹¹)                [обчислення чисельника і знаменника]
= 5.05732 · 10¹⁶ А²·с / (м⁴·°C)                [матеріальний електротермічний комплекс]
```

Обчислення температурного логарифма:

```
(T_f + 234.5) / (T_i + 234.5)
= (160 + 234.5) / (70 + 234.5)                 [підстановка робочих температур]
= 394.5 / 304.5
= 1.295566                                     [температурне співвідношення]

ln(1.295566) = 0.258946                        [натуральний логарифм]
```

Знаходження коефіцієнта `k`:

```
k = 10⁻⁶ · √[ 5.05732 · 10¹⁶ · 0.258946 ]
= 10⁻⁶ · √[ 1.30957 · 10¹⁶ ]                   [добуток під коренем]
= 10⁻⁶ · 1.14436 · 10⁸
= 114.44 ≈ 115 А·с^0.5 / мм²                   [значення k за IEC 60364 для PVC]
```

### 4.2. Розрахунок коефіцієнта k для кабелю з ізоляцією зі зшитого поліетилену (XLPE)

Для кабелів зі зшитим поліетиленом або етиленпропіленовою гумою (EPR) допустимі температурні межі значно вищі: тривала температура становить `T_i = 90` °C, а гранична короткочасна температура руйнування ізоляції дорівнює `T_f = 250` °C.

```
(T_f + 234.5) / (T_i + 234.5)
= (250 + 234.5) / (90 + 234.5)
= 484.5 / 324.5 = 1.493066                     [температурне співвідношення XLPE]

ln(1.493066) = 0.400832                        [натуральний логарифм]

k = 10⁻⁶ · √[ 5.05732 · 10¹⁶ · 0.400832 ]
= 10⁻⁶ · √[ 2.02713 · 10¹⁶ ]
= 10⁻⁶ · 1.42377 · 10⁸
= 142.38 ≈ 143 А·с^0.5 / мм²                   [значення k за IEC 60364 для XLPE]
```

Таким чином, стандартні коефіцієнти стандарту IEC 60364-5-54 (`k = 115` для PVC і `k = 143` для XLPE) є прямим наслідком фундаментальної термодинаміки нагріву.

## 5. Термічна стійкість перехідних отворів друкованих плат (PCB Vias)

На багатошарових друкованих платах струми короткого замикання протікають крізь масиви металізованих перехідних отворів (Vias).

Перехідний отвір з діаметром свердла `d_via` (типово 0.3 мм) та товщиною гальванічної міді на стінках `t_cu` (типово 20–25 мкм) має площу мідної циліндричної гільзи:

```
S_via ≈ π · d_via · t_cu        [площа перерізу стінки отвору]
```

Для типового отвору `d_via = 0.3` мм та `t_cu = 0.025` мм:

```
S_via = 3.14159 · 0.3 · 0.025 ≈ 0.02356 мм²        [переріз одного отвору]
```

При допустимому коефіцієнті нагріву міді в склотекстоліті `k ≈ 140` (до 260 °C) термічна стійкість одиничного перехідного отвору становить:

```
I²t_via = k² · S_via² = 140² · 0.02356² = 19 600 · 0.000555 ≈ 10.88 А²·с        [стійкість одного via]
```

Якщо струм аварії створює інтеграл `I²t = 400` А²·с, для його безпечного пропускання без перепалювання стінок отворів необхідно встановити масив із паралельних перехідних отворів кількістю `N_via`:

```
N_via ≥ √(I²t_аварії / I²t_via) = √(400 / 10.88) = √36.76 ≈ 6.06 → не менше 7 отворів
```

## 6. Точні аналітичні інтеграли типових форм хвилі струму

Для розрахунку інтеграла Джоуля `I²t = ∫ i²(t) dt` у практичних схемах перехідні процеси представляють набором базових аналітичних функцій.

### 6.1. Експоненційний імпульс струму

Струм перехідного процесу розряду конденсатора або розмагнічування індуктивності:

```
i(t) = I_0 · e^(-t / τ)        [експоненційне спадання струму зі сталою часу τ]
```

Інтегрування від `0` до нескінченності:

```
∫[0..∞] (I_0 · e^(-t / τ))² dt
= I_0² · ∫[0..∞] e^(-2t / τ) dt                [піднесення до квадрата експоненти]
= I_0² · [ (-τ / 2) · e^(-2t / τ) ][0..∞]      [первісна]
= I_0² · [ 0 - (-τ / 2) ]                      [підстановка граничних значень]
= (1 / 2) · I_0² · τ                           [кінцевий вираз інтеграла]
```

```
I²t_exp = 0.5 · I_0² · τ        [інтеграл Джоуля експоненційного імпульсу]
```

### 6.2. Синусоїдальна півхвиля (мережева аварія 50/60 Гц)

Для півперіоду змінного струму тривалістю `t_half` (для частоти 50 Гц `t_half = 10` мс, кругова частота `ω = π / t_half`):

```
i(t) = I_pk · sin(ωt),  де t ∈ [0, t_half]        [одиночна півхвиля синусоїди]
```

Застосовуючи тригонометричну тотожність `sin²(x) = (1 - cos(2x)) / 2`:

```
∫[0..t_half] (I_pk · sin(ωt))² dt
= (I_pk² / 2) · ∫[0..t_half] (1 - cos(2ωt)) dt            [тригонометричне перетворення]
= (I_pk² / 2) · [ t - (sin(2ωt) / (2ω)) ][0..t_half]      [первісна]
= (I_pk² / 2) · [ t_half - (sin(2π) / (2ω)) - 0 ]         [підстановка верхньої та нижньої межі]
= (1 / 2) · I_pk² · t_half                                [оскільки sin(2π) = 0]
```

```
I²t_sine = 0.5 · I_pk² · t_half        [інтеграл синусоїдальної півхвилі]
```

### 6.3. Аперіодичний ударний струм КЗ в енергомережах

У реальних трифазних мережах момент виникнення замикання рідко збігається з переходом напруги через нуль. Виникає аперіодична складова (DC offset), що експоненційно згасає зі сталою часу мережі `T_a = L / R`:

```
i(t) = √2 · I_k · [ sin(ωt - φ) - sin(-φ) · e^(-t / T_a) ]        [струм асиметричного короткого замикання]
```

Піднесення до квадрата породжує три доданки: суто періодичний `sin²(...)`, аперіодичний `e^(-2t/T_a)` та перехресний добуток.

За перші 1–2 періоди (20–40 мс) наявність аперіодичної складової збільшує накопичений інтеграл `I²t` у **2.0–2.8 раза** порівняно з чистою синусоїдою:

```
I²t_асиметричний ≈ (1 + 2 · e^(-2t_clear / T_a)) · I²t_симетричний        [оцінка енергетичного удару асиметрії]
```

Саме тому в стандартах IEC 60947 та IEC 60269 випробування вимикальної здатності захисних апаратів обов'язково проводять при низькому коефіцієнті потужності `cos φ = 0.1–0.2` (високій індуктивності), де аперіодична складова сягає максимуму.

### 6.4. Трапецеїдальний імпульс струму

Імпульс струму з лінійним наростанням за час `t_r`, постійною вершиною `I_pk` тривалістю `t_top` та лінійним спадом за час `t_f`:

```
I²t_trap = (1 / 3) · I_pk² · t_r + I_pk² · t_top + (1 / 3) · I_pk² · t_f = I_pk² · [ t_top + (t_r + t_f) / 3 ]        [інтеграл трапецеїдального імпульсу]
```

## 7. Енергія дуги в індуктивному колі постійного струму

Під час розриву струму короткого замикання запобіжником або автоматичним вимикачем у колі з постійною індуктивністю `L` та активним опором `R` рівняння електричного стану в стадії горіння дуги має вигляд:

```
U_dc = L · (di / dt) + R · i + u_arc(t)        [диференціальне рівняння кола з дугою]
```

де `u_arc(t)` — спад напруги на електричній дузі.

Щоб струм почав спадати (`di/dt < 0`), напруга дуги обов'язково повинна перевищувати напругу джерела живлення:

```
di / dt = (U_dc - R · i - u_arc(t)) / L < 0        [умова згасання струму дуги]
```

Якщо апроксимувати напругу дуги середнім постійним значенням `U_arc > U_dc`, час горіння дуги `t_arc` від початкового струму розплавлення `I_melt` до повного згасання `i = 0` визначається інтегруванням:

```
t_arc = (L / R) · ln[ 1 + (R · I_melt) / (U_arc - U_dc) ]        [тривалість стадії горіння дуги]
```

Для чисто індуктивного кола (`R → 0`) струм спадає строго лінійно:

```
di / dt = - (U_arc - U_dc) / L        [швидкість спадання струму в індуктивності]
```

```
t_arc = (L · I_melt) / (U_arc - U_dc)        [час горіння дуги без активного опору]
```

Інтеграл Джоуля за час горіння дуги для такого лінійного спаду становить:

```
I²t_arc = ∫[0..t_arc] i²(t) dt = (1 / 3) · I_melt² · t_arc = (1 / 3) · I_melt³ · [ L / (U_arc - U_dc) ]        [інтеграл енергії дугової фази]
```

Цей вираз доводить, що енергія дуги `I²t_arc` прямо пропорційна індуктивності кола `L` і швидко зростає при наближенні напруги дуги `U_arc` до напруги джерела `U_dc`. Чим вищу проти-ЕРС здатний створити дугогасник запобіжника над напругою мережі, тим меншою буде наскрізна енергія, пропущена в аварійне коло.
