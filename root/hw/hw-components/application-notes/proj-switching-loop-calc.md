# ⚙️ Автоматизований розрахунок і верифікація параметрів стабілізатора за методиками Application Notes

Під час проєктування імпульсного стабілізатора за формулами з прикладних нотаток інженер щоразу стикається з рутинною послідовністю дій: розрахувати частоти полюсів і нулів силового фільтра, визначити теоретичні номінали резисторів і конденсаторів компенсатора, округлити їх до найближчих стандартних рядів E24 / E96 і повторно перевірити, чи не впав результуючий запас фази (*Phase Margin*) нижче критичних 45°.

Якщо розрахунок виконувати вручну або в незахищених таблицях, найменша помилка в коефіцієнтах або ігнорування дератингу ємності керамічних конденсаторів (MLCC) під постійною напругою призводить до виготовлення нестійкої друкованої плати. Нижче наведено інженерну утиліту, яка автоматизує розрахунок кіл компенсації Type II та Type III за канонічними методиками Application Notes із повною перевіркою стійкості.

## Фізичні основи та математична модель розрахунку

Головна небезпека спрощених онлайн-калькуляторів полягає в тому, що вони розглядають напівпровідникові компоненти як абстрактні ідеальні блоки. У реальному пристрої поведінка контуру регулювання визначається сукупністю трьох взаємопов'язаних передавальних функцій:

```
                  ┌──────────────────────────────────────────┐
    v_ref(s) ────>│  Підсилювач помилки та компенсатор       ├──── v_c(s)
                  │             H_comp(s)                    │
                  └────────────────────▲─────────────────────┘
                                       │ v_fb(s)
                  ┌────────────────────┴─────────────────────┐
                  │   Силова частина (Power Stage Plant)     │
                  │   G_plant(s) = G_pwm · G_LC(s)           │
                  └────────────────────▲─────────────────────┘
                                       │ d(s)
```

1. **Передавальна функція ШІМ-модулятора (`G_pwm`)**:
   Перетворює напругу керування `v_c(s)` на виході компенсатора у шпаруватість імпульсів комутації `d(s)`. Для класичного модулятора з пилкоподібною напругою розмахом `V_ramp` підсилення становить:
   ```
   G_pwm = V_in / V_ramp
   ```
   Якщо вхідна напруга `V_in` змінюється в широких межах (наприклад, від 9 В до 28 В), підсилення силової частини плаває утричі. Компенсатор зобов'язаний забезпечувати стійкість як при мінімальній, так і при максимальній напрузі живлення.

2. **Передавальна функція вихідного фільтра (`G_LC(s)`)**:
   Описує передачу напруги від комутаційного вузла до навантаження через дросель `L` та конденсатори `C_out` із втратами `ESR`:
   ```
   G_LC(s) = (1 + s · ESR · C_out) / ( 1 + s · (L / R_load + ESR · C_out) + s² · L · C_out )
   ```
   Власний резонанс контуру `f_0` створює фазовий завал на 180°:
   ```
   f_0 = 1 / ( 2 · π · √(L · C_eff) )
   ```
   де `C_eff` — ефективна ємність кераміки з урахуванням напруги зміщення (*DC Bias*).

3. **Фазовий зсув компенсатора Type III (`H_comp(s)`)**:
   Формує додатній фазовий підйом (*Phase Boost*) завдяки двом нулям `f_z1` та `f_z2`, розміщеним біля частоти резонансу `f_0`:
   ```
   Phase_Boost = arctan(f_c / f_z1) + arctan(f_c / f_z2) − arctan(f_c / f_p1) − arctan(f_c / f_p2)
   ```

## Архітектура програми та принципи безпеки коду

Програмна реалізація утиліти спроєктована з дотриманням жорстких вимог до вбудованого системного програмного забезпечення:
- **Повна відсутність динамічного виділення пам'яті (Zero Heap Allocation)**: обчислення не використовують викликів `malloc` або `new`, що дозволяє вбудовувати цей розрахунковий модуль безпосередньо у прошивки мікроконтролерів для адаптивного автопідстроювання цифрових стабілізаторів або у виробничі калібрувальні утиліти;
- **Чисельна стабільність логарифмічного пошуку в рядах E24 / E96**: замість простої лінійної різниці алгоритм обчислює відстань між значеннями у логарифмічному просторі мантис, що забезпечує симетричний вибір номіналів з однаковою відносною похибкою по всьому діапазону декад від пікофарадів до десятків кілоомів;
- **Безпечна обробка помилок без винятків у C++**: використання сучасного типу `std::expected<Type3Result, CalcError>` із C++23 гарантує детермінований контроль некоректних вхідних даних (від'ємна індуктивність, нульова частота комутації) на етапі компіляції та виконання без накладних витрат на розкручування стека.

## Структура алгоритму та вхідні параметри

Програма приймає на вхід фізичні параметри перетворювача:
1. `v_in`, `v_out`, `i_out` — напруги живлення та вихідний робочий струм;
2. `f_sw` — робоча частота комутації ШІМ;
3. `l_ind` — номінальна індуктивність силового дроселя;
4. `c_out_nom` — номінальна ємність вихідного фільтра (паспортне значення);
5. `esr` — еквівалентний послідовний опір конденсаторів;
6. `v_ref`, `v_ramp` — внутрішні параметри мікросхеми (опорна напруга і розмах пилки модулятора);
7. `dc_bias_factor` — коефіцієнт залишкової ємності кераміки під постійною напругою зміщення (типово 0.4…0.7 для типорозмірів 0603/0805 на 16 В).

Алгоритм виконує:
1. Обчислення ефективної ємності `C_eff = C_nom · dc_bias_factor`;
2. Розрахунок власного резонансу фільтра `f_0` та нуля `f_z_esr`;
3. Перевірку коректності цільової частоти зрізу `f_c` (обмеження теоремою дискретизації `f_sw / 5`);
4. Синтез номіналів компенсатора Type III (`R1, R2, R3, C1, C2, C3`);
5. Округлення до стандартного ряду E24/E96;
6. Чисельну оцінку фазового запасу на частоті зрізу із виведенням підсумкового вердикту стабільності.

## Інженерний аналіз крайових випадків та пасток

На практиці розрахунок за формулами є лише першим кроком. Розгляньмо чотири типові аномалії, які виникають під час монтажу та тестування розрахованих кіл.

### 1. Катастрофічний вплив DC-Bias дератингу на кераміку

У паспорті керамічного конденсатора MLCC (наприклад, 22 мкФ, 16 В, діелектрик X7R у корпусі 0805) номінал вказується для тестового змінного сигналу 0.5 В без постійної напруги. Якщо на цей конденсатор подати робочу постійну напругу 12 В, його внутрішній сегнетоелектричний діелектрик (титанат барію) поляризується до насичення доменів, і ефективна ємність падає на 65…70 % — до 6.5…7.5 мкФ.

Якщо утиліті передати номінальну ємність (`c_out_nom = 66 мкФ`) без поправки (`dc_bias_factor = 1.0`):
- Програма розрахує резонанс `f_0 = 13.2 кГц` і розмістить нулі компенсатора на 10 кГц та 13.2 кГц;
- На реальній платі фактична ємність становить лише 23 мкФ, тому реальний резонанс `f_0` зсувається вгору до `22.4 кГц`;
- У результаті фазовий підйом компенсатора відбудеться набагато раніше, ніж почнеться завал від LC-фільтра;
- На частоті зрізу `f_c = 50 кГц` фазовий запас замість розрахункових 55° впаде до критичних 22°. Під час підключення навантаження вихідна напруга почне здійснювати затяжні коливання з перерегулюванням понад 250 мВ.

### 2. Обмеження теореми дискретизації та фазова затримка ШІМ

Імпульсний перетворювач не є безперервною лінійною системою — це дискретна імпульсна система з частотою дискретизації `f_sw`. ШІМ-компаратор здійснює вибірку сигналу помилки лише раз за період.

Цей процес еквівалентний введенню в петлю чистої ланки запізнення (*Transport Delay*) тривалістю в половину періоду комутації `t_d = 1 / (2 · f_sw)`. Фазова затримка від дискретизації зростає лінійно з частотою:

```
ΔPhi_delay(f) = − 360° · f · t_d = − 180° · (f / f_sw)
```

На частоті `f = f_sw / 10` затримка додає додаткові −18° фазового зсуву, а на частоті `f = f_sw / 5` — вже −36° фазового зсуву. Саме тому частоту зрізу петлі `f_c` ніколи не обирають вище `f_sw / 5`: на вищих частотах фазова затримка дискретизації неминуче перекидає петлю в режим самозбудження незалежно від кількості нулів компенсатора.

### 3. Правило правої півплощини (RHPZ) для Boost та Buck-Boost

Якщо розрахунок виконується для підвищувального (*Boost*) або інвертуючого (*Buck-Boost*) перетворювача, в передавальній функції силової частини з'являється небезпечний нуль у правій комплексній півплощині (*Right Half-Plane Zero, RHPZ*):

```
f_rhpz = [ R_load · (1 − D)² ] / ( 2 · π · L )
```

де `D` — шпаруватість комутації. Фізична природа RHPZ полягає в тому, що коли навантаження раптово зростає і ШІМ збільшує шпаруватість `D`, транзистор залишається відкритим довший час, накопичуючи енергію в дроселі. Але протягом цього часу діод закритий, і струм у навантаження не надходить — вихідна напруга спочатку короткочасно падає, перш ніж почати зростати.

Математично RHPZ діє парадоксально: він піднімає коефіцієнт підсилення ЛАЧХ на +20 дБ/дек, але **завалює фазу на −90°**, як додатковий полюс. Скомпенсувати RHPZ пасивними колами неможливо. Єдине інженерне рішення, рекомендоване прикладними нотатками — жорстко обмежити частоту зрізу петлі на рівні:

```
f_c ≤ f_rhpz / 3
```

### 4. Взаємодія з вхідним фільтром та негативний вхідний опір

Коли перед стабілізатором встановлюють додатковий LC-фільтр для придушення кондуктивних завад, виникає небезпека виникнення релаксаційних коливань через негативний вхідний опір імпульсного перетворювача `R_in_dyn = − (V_in)² / P_out`.

Якщо вихідний імпеданс фільтра `Z_out_filter` має високий добротний пік на частоті свого власного резонансу `f_flt = 1 / (2π · √(L_flt · C_flt))`, і цей пік за модулем перевищує `|R_in_dyn|`, виникає додатній зворотний зв'язок між фільтром і регулятором. Вхідна напруга починає коливатися з розмахом у кілька вольтів, викликаючи хибні спрацьовування захисту від зниженої напруги (UVLO). Для усунення проблеми розробник зобов'язаний зашунтувати фільтр демпфуючим резистором `R_damp = √(L_flt / C_flt)` або додати електролітичний конденсатор паралельно до кераміки.

## Методика лабораторної верифікації на стенді

Після виготовлення друкованої плати розраховані параметри перевіряють двома інструментальними методами:

```
                      ┌─────────────────────────────────┐
                      │  Векторний аналізатор кіл (FRA) │
                      │       (Bode 100 / AP300)        │
                      └────┬───────────────────────┬────┘
               Генератор   │                       │ Канал B (Вихід)
               (Впорскування)                      │
                           ▼                       ▼
   V_out ────[ R_top ]───/\/\/\───┬───[ Дільник ]───┴─── FB (IC)
                                  │
                                  ▲
                             Канал A (Вхід)
```

1. **Пряме вимірювання діаграми Боде за методом Міддлбрука**:
   У розрив доріжки зворотного зв'язку встановлюють низькоомний інжекційний резистор опором `10…50 Ом`. Через ізолюючий широкосмуговий трансформатор векторний аналізатор кіл (наприклад, Omicron Bode 100 або Keysight E5061B) впорскує малий синусоїдальний сигнал амплітудою 10…20 мВ, скануючи частоту від 10 Гц до 1 МГц. Аналізатор фіксує точну частоту переходу через 0 дБ та безпосередньо показує запас фази і запас підсилення (*Gain Margin*). Критерій успіху: `Phase Margin ≥ 50°`, `Gain Margin ≥ 10 дБ`.

2. **Тестування динамічним накиданням струму (Load Step Transient)**:
   До виходу перетворювача підключають кероване електронне навантаження, яке формує імпульси струму від 10 % до 90 % від максимуму з крутим фронтом `1…5 А/мкс`. За допомогою осцилографа з закритою розв'язкою за змінним струмом (AC Coupling) фіксують реакцію вихідної напруги:
   - **Оптимальна компенсація (PM = 55°…65°)**: напруга плавно просідає на 30…50 мВ і повертається до номіналу за 15…25 мкс без вторинних коливань;
   - **Недостатній запас фази (PM = 25°…35°)**: напруга коливається з 3–5 затухаючими хвилями дзвіну;
   - **Нестійка система (PM < 15°)**: виникають незатухаючі синусоїдальні автоколивання великої амплітуди.
