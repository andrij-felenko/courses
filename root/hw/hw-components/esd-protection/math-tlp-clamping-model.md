# 🧮 Динамічна напруга фіксації TVS: метод TLP та розрахунок розсіяної енергії

Статичний паспортний параметр `V_BR` (напруга пробою, виміряна на повільному постійному струмі 1 мА) не відображає реального потенціалу на виводах захисного діода під час електростатичного удару, коли струм за частку наносекунди підскакує до 30 А. Щоб обчислити дійсну напругу затискання `V_CL`, яку побачить підзатворний діелектрик вхідного транзистора, та оцінити теплову енергію, що розсіюється в напівпровідниковому кристалі, застосовують математичну модель імпульсів лінії передачі (*Transmission Line Pulse*, TLP) та аналітичний інтеграл потужності розряду за стандартом IEC 61000-4-2.

---

### 1. Метрологія TLP та vf-TLP як основа динамічного моделювання

Стандартні вольтамперні характеристики, зняті на повільних розгортках або мікросекундних імпульсах (8/20 мкс), непридатні для аналізу ESD через спотворення результатів квазістатичним самонагрівом напівпровідника. Для дослідження поведінки діода в наносекундному діапазоні використовують генератори на основі зарядженої коаксіальної лінії transmission line pulse (TLP).

Методологія TLP поділяється на два стандартизовані вимірювальні режими:
1. **Класичний TLP (100 нс)**: прямокутний імпульс тривалістю 100 нс із часом наростання фронту `t_rise = 0.2…10 нс` (типово 1.0 нс). Енергія 100-наносекундного імпульсу TLP струмом 1 А відповідає загальній енергії типового розряду стандарту IEC 61000-4-2 рівнем приблизно 2 кВ (коефіцієнт масштабування `I_TLP ≈ I_ESD / (1.5…2.0)`).
2. **Very-Fast TLP (vf-TLP, 1…5 нс)**: імпульси надкороткої тривалості (1…5 нс) із часом наростання фронту `t_rise = 100…200 пс`. Цей режим дозволяє безпосередньо виміряти динаміку першого наносекундного піка ESD та час спрацьовування внутрішніх тиристорних вузлів (*snapback trigger time*).

Вимірювання напруги й струму виконують в автоматизованому вікні усереднення (*averaging window*), розташованому між 70% та 90% тривалості імпульсу (для 100 нс TLP — це інтервал 70…90 нс). Це вікно навмисно зміщене в кінець імпульсу, щоб повністю відфільтрувати високочастотний паразитно-індуктивний дзвін виводів і зафіксувати чисту квазістатичну вольт-амперну характеристику кремнієвого кристала.

#### Вимірювання струму витоку після кожного імпульсу (Spot-End Leakage):

Сучасний вимірювальний комплекс TLP виконує процедуру моніторингу витоку: після кожного 100-наносекундного сильнострумового удару на виводи зразка автоматично подається робоча напруга спокою `V_RWM`, і чутливий пікоамперметр вимірює струм витоку `I_leak`.

Доки структура залишається неушкодженою, струм витоку не перевищує кількох наноампер. Коли амплітуда TLP досягає критичного струму другого теплового пробою `I_t2` (*Second Breakdown*), кремній локально плавиться, формуючи металізований мікрошнур. Струм витоку спокою стрибкоподібно підскакує на 4…6 порядків (до мікроампер і міліампер), що слугує абсолютно точним апаратним критерієм фізичного руйнування кристала.

#### Алгоритм екстракції параметрів V_BR0 та R_dyn з TLP-кривої:

Після зняття серії з десятків імпульсів TLP із наростаючою амплітудою формується масив точок `(V_i, I_i)`. На квазілінійній ділянці розвиненого пробою параметри обчислюють методом лінійної регресії за двома реперними точками `(V₁, I₁)` при `I₁ = 4 А` та `(V₂, I₂)` при `I₂ = 16 А`:

```
R_dyn = (V₂ − V₁) / (I₂ − I₁)
V_BR0 = V₁ − I₁ · R_dyn
```

Для експериментальних значень `V₁ = 6.4 В` (@ 4 А) та `V₂ = 9.4 В` (@ 16 А):

```
R_dyn = (9.4 В − 6.4 В) / (16 А − 4 А) = 3.0 В / 12 А = 0.25 Ом
V_BR0 = 6.4 В − 4 А · 0.25 Ом = 6.4 В − 1.0 В = 5.4 В
```

### 2. Еквівалентна схема та рівняння динамічного затискання

У режимі швидкого перехідного процесу діод супресора описується схемою заміщення, що містить джерело напруги лавинного відмикання `V_BR0`, динамічний диференційний опір лавинного переходу `R_dyn`, опір об'ємного кремнію підкладки `R_bulk` та власну індуктивність кристалотримача й виводів корпусу `L_pkg`:

```
V_CL(t) = V_BR0 + I_PP(t)·(R_dyn + R_bulk) + L_pkg · (dI_PP(t) / dt)
```

де:
- `V_BR0` — екстрапольована напруга лавинного відмикання при нульовому струмі (В);
- `R_dyn = ΔV / ΔI` — диференційний динамічний нахил ВАХ на ділянці розвиненого лавинного пробою (типово 0.08…0.5 Ом для оптимізованих кремнієвих діодів);
- `R_bulk` — омічний опір низьколегованої монокристалічної підкладки (0.02…0.08 Ом);
- `I_PP(t)` — миттєвий струм імпульсу перенапруги (А);
- `L_pkg` — паразитна індуктивність корпусу та тонких золотих або мідних зварних розварок (типово 0.15…0.3 нГн для безвивідних WLCSP / DFN корпусів і 1.8…3.0 нГн для класичних вивідних SOT-23 / SOD-323);
- `dI_PP / dt` — швидкість наростання фронту струму (для стандарту IEC 61000-4-2 досягає `30 А / 0.8 нс ≈ 3.75·10¹⁰ А/с`).

#### Температурна залежність динамічного опору:

Під час протікання імпульсного струму температура p-n переходу зростає. Оскільки рухливість носіїв заряду `μ(T)` у сильних полях падає через розсіювання на фононах ґратки (`μ ∝ T^(−3/2)`), напруга пробою та динамічний опір зростають із додатним температурним коефіцієнтом:

```
V_BR(T) = V_BR0 · [1 + α_V · (T − T₀)]
R_dyn(T) = R_dyn0 · [1 + α_R · (T − T₀)]
```

де `α_V ≈ (0.5…1.0)·10⁻³ К⁻¹`, `α_R ≈ (1.5…2.5)·10⁻³ К⁻¹`. При тривалих імпульсах це призводить до додаткового підйому напруги фіксації на 1…2 В.

### 3. Асиметрія прямого та зворотного затискання в односпрямованих TVS

Односпрямований TVS-діод (unidirectional) має принципово різну фізику роботи залежно від полярності імпульсу перенапруги:
1. **Додатний імпульс (Reverse Clamping)**: перехід перебуває у зворотному зміщенні, і струм протікає в режимі лавинного пробою з напругою `V_BR ≈ 5…15 В` та динамічним опором `R_dyn_rev ≈ 0.15…0.4 Ом`.
2. **Від'ємний імпульс (Forward Clamping)**: перехід зміщується у прямому напрямку, і струм інжектується основними носіями заряду.

У прямому напрямку напруга фіксації визначається висотою вбудованого контактного потенціалу `V_F0 ≈ 0.7…0.85 В` та малим прямим динамічним опором `R_dyn_fwd`:

```
V_CL_fwd(I) = V_F0 + I_PP · R_dyn_fwd + L_pkg · (dI_PP / dt)
```

де `R_dyn_fwd ≈ 0.03…0.08 Ом` (у 3…5 разів менше за зворотний опір `R_dyn_rev` через значну концентрацію інжектованих електронів та дірок у базі діода).

#### Порівняльний розрахунок для струму 30 А:

```
V_CL_зворотне = 5.5 В + 30 А · 0.25 Ом = 13.0 В    [додатний розряд]
V_CL_пряме    = 0.8 В + 30 А · 0.05 Ом = 2.3 В     [від'ємний розряд]
```

Це доводить: односпрямований супресор забезпечує у **5.6 раза нижчу напругу перевантаження** при від'ємному розряді, що робить його ідеальним вибором для однополярних шин живлення та односпрямованих цифрових сигналів (наприклад, ліній USB VBUS, TX/RX шин із нульовим зміщенням).

### 4. Математична модель Snapback SCR-супресора в режимі TLP

На відміну від чистого лавинного діода, структура Snapback SCR (тиристорний кремнієвий супресор) містить ділянку від'ємного диференційного опору (*Negative Differential Resistance*, NDR), що кардинально змінює баланс енергії та напруги фіксації:

```
ВАХ Snapback-структури описується кусковою функцією трьох областей:
1. Зона закритого стану (0 ≤ V < V_trig):
   I(V) = I_витоку · [ 1 / (1 − (V / V_trig)ⁿ) ]
2. Точка перемикання (V = V_trig, I = I_trig):
   Увімкнення біполярного NPN-PNP стека з коефіцієнтом зворотного зв'язку β₁·β₂ ≥ 1
3. Зона утримання та фіксації (I > I_hold):
   V_SCR(I) = V_hold + (I − I_hold) · R_on_SCR
```

де:
- `V_trig` — тригерна напруга відкривання тиристора (типово 6.5…8.5 В);
- `I_trig` — струм увімкнення (типово 50…150 мА);
- `V_hold` — напруга утримання відкритого тиристора (типово 2.5…4.0 В);
- `R_on_SCR` — внутрішній опір відкритого тиристора (0.10…0.25 Ом).

#### Порівняння розсіяної енергії: Лавина проти Snapback:

Розглянемо прямокутний імпульс TLP струмом `I_P = 16 А` тривалістю `τ = 100 нс`.

Для класичного лавинного діода (`V_BR0 = 5.5 В`, `R_dyn = 0.25 Ом`):
```
V_CL_avalanche = 5.5 В + 16 А · 0.25 Ом = 9.5 В
W_avalanche = V_CL · I_P · τ
= 9.5 В · 16 А · 100 · 10⁻⁹ с = 152 Вт · 10⁻⁷ с = 1.52 · 10⁻⁵ Дж = 15.2 мкДж
```

Для Snapback SCR-супресора (`V_hold = 3.0 В`, `R_on_SCR = 0.15 Ом`):
```
V_CL_SCR = V_hold + (16 А − 0.1 А) · 0.15 Ом = 3.0 В + 2.38 В = 5.38 В
W_SCR = V_CL_SCR · I_P · τ
= 5.38 В · 16 А · 100 · 10⁻⁹ с = 86.1 Вт · 10⁻⁷ с = 8.61 · 10⁻⁵ Дж = 8.61 мкДж
```

Завдяки падінню напруги утримання `V_hold` тиристорна структура розсіює на **43.4% менше теплової енергії** (`8.61 мкДж` проти `15.2 мкДж`) при тому самому струмі 16 А. Це дозволяє вдвічі зменшити площу кристала (і пропорційно знизити ємність до `< 0.15 пФ`) при збереженні ідентичної стійкості до руйнування.

### 5. Розрахунок LC-дзвону та паразитного резонансу корпусу

Паразитна індуктивність виводів `L_pkg` разом із власною бар'єрною ємністю p-n переходу `C_j` та ємністю контактних площадок утворює послідовний RLC-коливальний контур.

Резонансна частота контуру корпусу:
```
f_res = 1 / (2·π · √(L_pkg · C_j))
```

Добротність контуру при дії імпульсу з джерела з хвильовим імпедансом лінії `Z_0`:
```
Q = (1 / (R_dyn + Z_0)) · √(L_pkg / C_j)
```

Для звичайного вивідного TVS у корпусі SOD-323 (`L_pkg = 2.0 нГн`, `C_j = 10 пФ`, `Z_0 = 50 Ом`, `R_dyn = 0.2 Ом`):

```
f_res = 1 / (2·3.14159 · √(2.0 · 10⁻⁹ · 10 · 10⁻¹²))
= 1 / (6.283 · √(2.0 · 10⁻²⁰)) = 1 / (6.283 · 1.414 · 10⁻¹⁰) ≈ 1.12 ГГц
Q = (1 / 50.2 Ом) · √(2.0 · 10⁻⁹ / 10 · 10⁻¹²) = (1 / 50.2) · √200 = 14.14 / 50.2 ≈ 0.28
```

Оскільки добротність `Q < 0.5`, процес має аперіодичний затухаючий характер без небезпечних коливальних перепідскоків напруги. Проте для низькоємнісних діодів (`C_j = 0.2 пФ`) добротність зростає:

```
Q = (1 / 50.2) · √(2.0 · 10⁻⁹ / 0.2 · 10⁻¹²) = (1 / 50.2) · √10000 = 100 / 50.2 ≈ 1.99
```

При `Q > 1` на фронті розряду виникає високочастотний коливальний дзвін (*ringing*) із перепідскоком напруги амплітудою `V_peak = V_CL · [1 + exp(−π / √(4·Q² − 1))] ≈ 1.6 · V_CL`, що вимагає застосування безвивідних корпусів DFN з `L_pkg < 0.2 нГн`.

### 6. Методологія SEED: розрахунок спільної роботи TVS та IC

Методологія системно-ефективного проєктування ESD-захисту (англ. *System-Efficient ESD Design*, SEED / JEDEC JEP161) дозволяє аналітично обчислити струморозподіл між зовнішнім TVS-діодом на платі та внутрішніми колами захисту мікросхеми без фізичного руйнування зразків.

Еквівалентна схема вхідного вузла містить:
1. Джерело імпульсу ESD з внутрішнім опором `R_gen = 330 Ом` та напругою холостого ходу `V_ESD`.
2. Зовнішній TVS: `V_BR_tvs`, `R_dyn_tvs`.
3. Доріжка між TVS та мікросхемою: опір `R_trace`, індуктивність `L_trace`.
4. Внутрішній ESD-діод мікросхеми: `V_BR_ic`, `R_on_ic`.
5. Критичний струм відмови внутрішнього діода: `I_fail_ic`.

Рівняння вузлових потенціалів у квазістатичному режимі:

```
V_вузол = V_BR_tvs + I_tvs · R_dyn_tvs
V_ic = V_BR_ic + I_ic · R_on_ic
V_вузол − V_ic = I_ic · R_trace
```

Звідси струм, що проникає у внутрішній кристал мікросхеми:

```
I_ic = (V_BR_tvs − V_BR_ic + I_tvs · R_dyn_tvs) / (R_on_ic + R_trace)
```

Оскільки повний струм генератора `I_ESD ≈ I_tvs + I_ic`, критична напруга генератора ESD, за якої мікросхема виходить із ладу (`I_ic = I_fail_ic`):

```
V_ESD_max = I_fail_ic · [ R_gen · (1 + (R_on_ic + R_trace) / R_dyn_tvs) + R_on_ic + R_trace ] + V_BR_ic
```

Для числових значень `R_gen = 330 Ом`, `I_fail_ic = 1.2 А`, `R_on_ic = 1.8 Ом`, `R_trace = 0.5 Ом`, `R_dyn_tvs = 0.15 Ом`, `V_BR_ic = 7.0 В`, `V_BR_tvs = 5.5 В`:

```
Співвідношення опорів: (1.8 + 0.5) / 0.15 = 2.3 / 0.15 ≈ 15.33
Множник генератора: 1 + 15.33 = 16.33
Ефективний опір системи: 330 · 16.33 + 2.3 ≈ 5391 Ом
V_ESD_max = 1.2 А · 5391 Ом + 7.0 В = 6469 В + 7 В ≈ 6.48 кВ
```

Цей розрахунок доводить: додавання послідовного резистора `R_trace = 2.0 Ом` збільшує співвідношення опорів до `(1.8 + 2.0) / 0.15 = 25.33`, що піднімає максимальну стійкість системи `V_ESD_max` до **10.4 кВ** без заміни TVS-діода.

### 7. Числовий розрахунок пікової напруги для IEC 61000-4-2 Level 4

Розглянемо найсуворіший рівень випробувань на контактний розряд за стандартом IEC 61000-4-2: напруга генератора `U_ESD = 8 кВ`. Струмова хвиля розряду має перший надшвидкий пік `I_P1 = 30 А` із часом наростання `t_rise = 0.8 нс` (10%…90%) і вторинний плавний горб `I_P2 = 16 А` на позначці 30 нс.

Порівняємо три супресори з ідентичним кремнієвим кристалом (`V_BR0 = 5.5 В`, `R_dyn + R_bulk = 0.25 Ом`), але в різних корпусах:
1. Вивідний корпус SOT-23: `L_pkg = 2.4 нГн`.
2. Компактний безвивідний DFN-1006 (0402): `L_pkg = 0.5 нГн`.
3. Ультракомпактний кристал прямого монтажу WLCSP-0201: `L_pkg = 0.15 нГн`.

#### Крок 1. Розрахунок швидкості наростання струму першого піка

```
dI / dt = ΔI / Δt
= (0.9·30 А − 0.1·30 А) / 0.8·10⁻⁹ с   [інтервал наростання 10%–90%]
= (27 А − 3 А) / 0.8·10⁻⁹ с           [різниця струмів]
= 24 А / 0.8·10⁻⁹ с                    [ділення]
= 3.0 · 10¹⁰ А/с                       [швидкість наростання фронту]
```

#### Крок 2. Розрахунок індуктивного падіння напруги на корпусах

```
V_L(SOT-23) = 2.4 · 10⁻⁹ Гн · 3.0 · 10¹⁰ А/с = 72.0 В   [індуктивний викид SOT-23]
V_L(DFN-1006) = 0.5 · 10⁻⁹ Гн · 3.0 · 10¹⁰ А/с = 15.0 В [індуктивний викид DFN-1006]
V_L(WLCSP) = 0.15 · 10⁻⁹ Гн · 3.0 · 10¹⁰ А/с = 4.5 В    [індуктивний викид WLCSP]
```

#### Крок 3. Повна пікова напруга затискання при t = 0.8 нс

Омічна складова напруги на кристалі однакова для всіх трьох варіантів:

```
V_crystal = V_BR0 + I_P1 · (R_dyn + R_bulk)
= 5.5 В + 30 А · 0.25 Ом               [сума напруги пробою та омічного спаду]
= 5.5 В + 7.5 В                        [додавання]
= 13.0 В                               [напруга безпосередньо на кремнієвому переході]
```

Сумарна напруга на виводах компонентів, яку побачить вхідний транзистор захищуваного чипа:

```
V_CL_peak(SOT-23) = 13.0 В + 72.0 В = 85.0 В   [катастрофічний пробій діелектрика затвора]
V_CL_peak(DFN-1006) = 13.0 В + 15.0 В = 28.0 В [напруга на межі стійкості буферів]
V_CL_peak(WLCSP) = 13.0 В + 4.5 В = 17.5 В     [безпечний рівень для захищеного входу]
```

#### Крок 4. Напруга затискання на вторинному плато (t = 30 нс)

На позначці 30 нс похідна струму прямує до нуля (`dI / dt ≈ 0`), тому індуктивна складова зникає для всіх корпусів, а струм становить `I_P2 = 16 А`:

```
V_CL(30 нс) = V_BR0 + I_P2 · (R_dyn + R_bulk) + 0
= 5.5 В + 16 А · 0.25 Ом               [омічне затискання без індуктивності]
= 5.5 В + 4.0 В                        [додавання]
= 9.5 В                                [квазістатична напруга плато]
```

### 8. Аналітичне інтегрування розсіяної енергії

Повна енергія `W`, яку діод перетворює на тепло за час розряду `t_end ≈ 100 нс`, описується визначеним інтегралом миттєвої потужності:

```
W = ∫₀^{t_end} V_CL(t) · I_PP(t) dt
```

Аналітична апроксимація форми струмового імпульсу стандарту IEC 61000-4-2 задається сумою двох експоненційних функцій із нормувальними коефіцієнтами:

```
I_ESD(t) = I₁ · exp(−t / τ₁) · [1 − exp(−t / τ_r1)] + I₂ · exp(−t / τ₂) · [1 − exp(−t / τ_r2)]
```

де для рівня 8 кВ:
- `I₁ = 28.5 А`, `τ_r1 = 0.6 нс` (наростання 1-го піка), `τ₁ = 2.2 нс` (спад 1-го піка);
- `I₂ = 15.2 А`, `τ_r2 = 5.0 нс` (наростання 2-го горба), `τ₂ = 38.0 нс` (спад основного хвоста).

Розбиваючи інтеграл на дві домінантні часові фази:

#### 1. Енергія надшвидкого першого піка (0…5 нс):

На цьому інтервалі середня напруга на діоді з урахуванням `R_dyn` та індуктивності становить `V_avg1 ≈ 18 В`, а інтеграл струму дає переданий заряд `Q₁ ≈ 65 нКл`:

```
W₁ = V_avg1 · Q₁
= 18 В · 65 · 10⁻⁹ Кл                  [добуток середньої напруги на заряд піка]
= 1.17 · 10⁻³ Дж                       [1.17 мДж]
```

#### 2. Енергія основного хвоста розряду (5…100 нс):

На інтервалі хвоста напруга стабілізується на рівні `V_avg2 ≈ 9.2 В`, а інтеграл струму експоненційного спаду дає заряд `Q₂ ≈ 520 нКл`:

```
W₂ = V_avg2 · Q₂
= 9.2 В · 520 · 10⁻⁹ Кл                [добуток середньої напруги на заряд хвоста]
= 4.78 · 10⁻³ Дж                       [4.78 мДж]
```

#### Повна розсіяна енергія одиночного удару 8 кВ:

```
W_total = W₁ + W₂
= 1.17 мДж + 4.78 мДж                  [сума енергій двох фаз]
= 5.95 мДж                             [близько 6 міліджоулів]
```

### 9. Тепловий баланс та межа руйнування Вунша-Белла

Незважаючи на малу величину сумарної енергії (~6 мДж), швидкість її виділення створює колосальну густину потужності в мікроскопічному об'ємі кремнієвого переходу.

#### Адіабатичний нагрів під час першого піка (t < 5 нс):

За час 5 нс фронт тепла встигає поширитися вглиб кремнію лише на характерну дифузійну довжину `x_diff`:

```
x_diff = √(2 · D_th · t)
= √(2 · 0.85 · 10⁻⁴ м²/с · 5 · 10⁻⁹ с) [де D_th = 0.85 см²/с — температуропровідність Si]
= √(8.5 · 10⁻¹³ м²) ≈ 0.92 мкм         [глибина теплового проникнення менше 1 мікрона]
```

Оскільки товщина активної зони лавинного розмноження становить близько `w ≈ 1.0 мкм`, а площа переходу `A = 80 мкм × 80 мкм = 6.4·10⁻⁵ см² = 6.4·10⁻⁹ м²`:

```
Активний об'єм нагріву V_vol = A · w = 6.4 · 10⁻⁹ м² · 1.0 · 10⁻⁶ м = 6.4 · 10⁻¹⁵ м³
Маса кремнію m = V_vol · ρ_Si = 6.4 · 10⁻¹⁵ м³ · 2330 кг/м³ = 1.49 · 10⁻¹¹ кг
Теплоємність кремнію c_Si = 705 Дж/(кг·К)
```

Адіабатичний стрибок температури переходу від енергії першого піка `W₁ = 1.17 мДж`:

```
ΔT₁ = W₁ / (m · c_Si)
= 1.17 · 10⁻³ Дж / (1.49 · 10⁻¹¹ кг · 705 Дж/(кг·К))
= 1.17 · 10⁻³ / (1.05 · 10⁻⁸)
= 111.4 К                              [локальне миттєве нагрівання на 111 °C]
```

Якщо початкова робоча температура чипа становила 60 °C, температура в зоні переходу за 5 нс підскакує до **171 °C**.

#### Гранична стійкість за законом Вунша-Белла:

Модель Вунша-Белла визначає граничну густину імпульсної потужності `P / A`, яка викликає локальне розплавлення кремнію (`T_melt = 1414 °C`):

```
P_crit / A = √(π · ρ · c · κ) · (T_melt − T₀) · t^(−1/2)
```

де:
- `ρ = 2330 кг/м³` — густина кремнію;
- `c = 705 Дж/(кг·К)` — питома теплоємність;
- `κ = 148 Вт/(м·К)` — коефіцієнт теплопровідності кремнію;
- `T_melt − T₀ = 1414 °C − 25 °C = 1389 °C`.

Тепловий коефіцієнт матеріалу:

```
K_th = √(3.14159 · 2330 · 705 · 148)
= √(7.63 · 10⁸) ≈ 2.76 · 10⁴ Вт·с^(1/2) / (м²·К)
```

Для імпульсу тривалістю `t = 100 нс = 10⁻⁷ с`:

```
P_crit / A = 2.76 · 10⁴ · 1389 · (10⁻⁷)^(−1/2)
= 3.83 · 10⁷ · 3162.3
= 1.21 · 10¹¹ Вт/м² = 1.21 · 10⁷ Вт/см² [12.1 МВт на квадратний сантиметр]
```

Для площі кристала `A = 6.4·10⁻⁵ см²` критична руйнівна потужність становить `P_crit = 1.21·10⁷ Вт/см² · 6.4·10⁻⁵ см² = 774 Вт`.

Оскільки максимальна миттєва потужність під час розряду IEC 61000-4-2 Level 4 становить `P_max = V_crystal · I_P1 = 13.0 В · 30 А = 390 Вт`, кристал площею 80×80 мкм має коефіцієнт запасу близько `774 / 390 ≈ 2.0` за тепловою міцністю, що гарантує його надійну багатократну роботу без деградації.

### 10. Модель кумулятивної деградації кристала при багаторазових ударах

При циклічних випробуваннях (понад 1000 ударів ESD) напівпровідниковий кристал зазнає повторюваних термомеханічних ударних навантажень. Локальний градієнт температури між зоною лавини та холодною підкладкою досягає `∇T ≈ 10⁸ К/м`, що створює внутрішнє термопружне механічне напруження:

```
σ_термічне = (E_Si · α_th · ΔT) / (1 − ν_Si)
```

де `E_Si = 160 ГПа` — модуль Юнга кремнію, `α_th = 2.6·10⁻⁶ К⁻¹` — коефіцієнт теплового розширення, `ν_Si = 0.22` — коефіцієнт Пуассона. При `ΔT = 150 К`:

```
σ_термічне = (160 · 10⁹ Па · 2.6 · 10⁻⁶ · 150) / (1 − 0.22) = 6.24 · 10⁷ / 0.78 ≈ 80 МПа
```

Це напруження генерує мікродислокації в кристалічній ґратці, що викликає повільне степеневе зростання струму витоку спокою:

```
I_витоку(N) = I_витоку0 · [ 1 + (N / N₀)^γ ]
```

де `N` — кількість імпульсів, `N₀ ≈ 500…1000`, `γ ≈ 1.2…1.5`. Згідно з автомобільним стандартом надійності AEC-Q101, компонент вважається працездатним, якщо після 1000 розрядів струм витоку не перевищує 10 мкА, а зміщення напруги пробою `ΔV_BR` не перевищує ±10%.
