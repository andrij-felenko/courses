# ⚙️ Моделювання завалу фронтів та вибір ESD-захисту для швидких ліній

На швидкостях понад 10 Гбіт/с (USB4, PCIe 5.0/6.0, HDMI 2.1, 100G Ethernet) кожен пікофарад і навіть десяті частки пікофарада паразитної ємності ESD-супресора `C_esd` утворюють низькочастотний фільтр із хвильовим опором лінії передачі `Z_0`. Це призводить до затягування крутих фронтів сигналів, падіння амплітуди на високих гармоніках (збільшення внесених втрат, *insertion loss* `S21`), міжсимвольної інтерференції та закриття «вічка» очної діаграми (*eye diagram closure*). Щоб перевірити сумісність супресора зі швидкісним стандартом, розраховують граничну частоту зрізу, деградацію часу наростання фронту `Δt_r`, втрати амплітуди на частоті Найквіста та локальні провали імпедансу лінії.

---

### 1. Проблема цілісності сигналу на гігагерцових швидкостях

Цифровий сигнал передачі даних являє собою псевдовипадкову послідовність прямокутних імпульсів. За теоремою Фур'є ідеальний прямокутний перепад напруги розкладається в нескінченний ряд непарних гармонік:

```
V(t) = V₀ / 2 + (2·V₀ / π) · [ sin(ω₀·t) + (1/3)·sin(3·ω₀·t) + (1/5)·sin(5·ω₀·t) + ... ]
```

де `f₀ = DataRate / 2` — фундаментальна частота Найквіста (наприклад, 10 ГГц для потоку 20 Гбіт/с).

Щоб зберегти форму сигналу та забезпечити крутий фронт наростання (який повинен становити менше 20…30% від тривалості біта `T_UI`), лінія передачі та всі підключені до неї компоненти зобов'язані без спотворень пропускати щонайменше 3-тю, а бажано й 5-ту гармоніку сигналу (тобто частоти до `2.5 · DataRate`, що для USB4 становить до 50 ГГц).

Коли паралельно лінії підключається захисний компонент із власною паразитною ємністю `C_esd`, він утворює шунт на землю для високочастотних складових спектра. Комплексний опір ємності `X_C = 1 / (2·π·f · C_esd)` обернено пропорційний частоті:
- На частоті 100 МГц ємність `C = 1 пФ` має опір `X_C ≈ 1590 Ом` (що набагато більше за 50 Ом лінії й майже не впливає на сигнал).
- На частоті 10 ГГц та сама ємність має опір лише `X_C ≈ 15.9 Ом`, що стає переважним шляхом для високочастотного струму й буквально закорочує верхні гармоніки сигналу на землю.

#### Специфіка багаторівневого кодування PAM4 та PAM3:

У найсучасніших протоколах (PCIe 6.0, USB4 Gen 4 на 80 Гбіт/с, 400G Ethernet) для подвоєння пропускної здатності без подвоєння частоти перейшли від двійкового кодування NRZ (*Non-Return-To-Zero*, 1 біт на такт) до чотирирівневої амплітудної модуляції PAM4 (*Pulse Amplitude Modulation 4-Level*, 2 біти на такт, 4 рівні напруги: 00, 01, 10, 11).

У PAM4 загальний розмах сигналу (наприклад, 800 мВ) ділиться на три окремі «вічка», тому висота кожного вічка становить лише `800 мВ / 3 ≈ 266 мВ`. Запас стійкості до шуму та спотворень зменшується у 3 рази порівняно з NRZ. Якщо паразитна ємність супресора викликає навіть невелике додаткове затухання амплітуди на 1.0 дБ (падіння напруги на 11%), вічка PAM4 стискаються настільки критично, що коефіцієнт бітових помилок (BER — *Bit Error Ratio*) катастрофічно зростає, спричиняючи втрату пакетів або перехід шини на знижену швидкість.

### 2. Математична модель S-параметрів та деградації фронтів

Розглянемо узгоджену лінію передачі з хвильовим імпедансом `Z_0 = 50 Ом` (або диференційну пару з імпедансом `Z_diff = 100 Ом`), навантажену на обох кінцях. Для паралельно підключеної ємності `C_esd` еквівалентний опір Тевеніна, що визначає швидкість перезаряду конденсатора, дорівнює паралельному з'єднанню опору джерела та приймача:

```
R_eff = (Z_0 · Z_0) / (Z_0 + Z_0) = Z_0 / 2 = 25 Ом   (для 50-омного тракту)
R_eff_diff = Z_diff / 2 = 50 Ом                        (для 100-омного диференційного тракту)
```

#### Гранична частота смуги пропускання за рівнем −3 дБ:

```
f_cutoff = 1 / (2·π · R_eff · C_esd) = 1 / (π · Z_0 · C_esd)
```

#### Деградація часу наростання фронту (від 10% до 90% амплітуди):

Перехідний процес заряду ємності описується класичним рівнянням `V(t) = V₀ · [1 − exp(−t / τ)]`, де стала часу `τ = R_eff · C_esd`. Час наростання від 10% до 90%:

```
t_10% = −τ · ln(1 − 0.1) = 0.105 · τ
t_90% = −τ · ln(1 − 0.9) = 2.303 · τ
Δt_r = t_90% − t_10% = 2.197 · τ ≈ 2.2 · R_eff · C_esd = 1.1 · Z_0 · C_esd
```

#### Коефіцієнт прямої передачі (Insertion Loss S21):

Матриця розсіювання паралельної ємності в лінії з хвильовим опором `Z_0` дає комплексний коефіцієнт передачі:

```
S21(f) = 2 / [ 2 + j · 2·π·f · Z_0 · C_esd ]
```

Амплітудне значення внесених втрат у децибелах:

```
|S21(f)| = 2 / √( 4 + (2·π·f · Z_0 · C_esd)² )
S21_дБ(f) = 20 · log₁₀( |S21(f)| )
```

#### Фазовий зсув та групова затримка (Group Delay Dispersion):

Окрім амплітудного затухання, паралельна ємність створює частотно-залежний фазовий зсув `φ(f)`:

```
φ(f) = −arctan( (2·π·f · Z_0 · C_esd) / 2 ) = −arctan( π·f · Z_0 · C_esd )
```

Диференціювання фази за кутовою частотою дає груповий час затримки `τ_g(f)`:

```
τ_g(f) = −(dφ / dω) = ( (Z_0 · C_esd) / 2 ) / [ 1 + (π·f · Z_0 · C_esd)² ]
```

Оскільки низькі та високі гармоніки цифрового сигналу проходять через захисний компонент із різною груповою затримкою, виникає **фазова дисперсія** фронту: прямокутний перепад напруги розмивається в часі, додатково деформуючи очну діаграму.

#### Диференційне згасання S_dd21 та змішані S-параметри:

Для симетричної диференційної пари з хвильовим опором `Z_diff = 100 Ом` прямий диференційний коефіцієнт передачі `S_dd21` розраховується з урахуванням ємності кожного плеча на землю `C_esd`:

```
S_dd21(f) = 2 / [ 2 + j · 2·π·f · (Z_diff / 2) · C_esd ]
```

Якщо між плечима пари виникає технологічна або топологічна асиметрія ємності `ΔC = |C₁ − C₂|`, частина корисної диференційної енергії перетворюється на синфазний шум (*Common Mode Conversion*, параметр `S_cd21`):

```
|S_cd21(f)| ≈ (2·π·f · Z_0 · ΔC) / √( 4 + (2·π·f · Z_0 · (C₁ + C₂))² )
```

Цей синфазний струм вільно випромінюється кабелем в ефір, призводячи до провалу тестів на електромагнітну сумісність за стандартами CISPR 32 Class B.

#### Виникнення міжсимвольної інтерференції та джиттеру від даних (DDJ):

Коли в цифровому потоці довга послідовність однакових логічних одиниць (де лінія встигла повністю зарядитися до `V₀`) раптово змінюється одиночним нулем (одиночний бітовий перехід), навантажена ємністю лінія не встигає розрядитися до нуля за час короткого такту `T_UI`. Наступний біт починає наростати не з нуля, а із залишкового потенціалу, що зміщує точку перетину порогу компаратора приймача в часі.

Це явище породжує **детермінований джиттер, залежний від даних** (*Data-Dependent Jitter*, DDJ), величина якого оцінюється як:

```
Δt_DDJ ≈ 0.7 · R_eff · C_esd = 0.35 · Z_0 · C_esd
```

Для ємності `C = 1.5 пФ` на 50-омній лінії додатковий джиттер становить `Δt_DDJ ≈ 26 пс`, що для лінії 20 Гбіт/с (`T_UI = 50 пс`) з'їдає більше половини фазового вікна передачі даних.

### 3. Очна діаграма (Eye Diagram) та TDR-рефлектометрія

Якість високошвидкісного цифрового каналу оцінюють за формою очної діаграми — накладанням тисяч послідовних бітових переходів на одному екрані осцилографа:
- **Висота вічка (Eye Height, `V_eye`)**: запас за амплітудою для надійного спрацьовування компаратора приймача.
- **Ширина вічка (Eye Width, `T_eye`)**: запас за часом (фазовий інтервал), вільний від джиттеру, у якому сигнал стабільний.

Вплив супресора призводить до звуження вічка:
```
V_eye ≈ V_номінал · |S21(f_Nyquist)| − V_шуму
T_eye ≈ T_UI − Δt_r − Δt_DDJ − Джиттер_джерела
```

#### TDR-рефлектометрія та методи компенсації ємнісного паду на платі:

На графіку рефлектометра часової області (*Time-Domain Reflectometry*, TDR) паразитний контактний майданчик (пад) TVS-діода створює локальний ємнісний провал хвильового імпедансу:

```
Z_TDR_min ≈ Z_0 / √( 1 + C_esd / C_доріжки_на_одиницю_довжини )
```

Щоб нейтралізувати цей провал, інженери застосовують метод **компенсації індуктивністю**:
1. **Звуження доріжки біля паду**: ширина сигнальної доріжки безпосередньо перед і після TVS-компонента зменшується на 20…30% на довжині 1…2 мм, що створює локальну розподілену індуктивність `L_comp`, перетворюючи ділянку на узгоджений П-подібний фільтр низьких частот без стрибка імпедансу:
   ```
   Z_хвильове = √( (L_доріжки + L_comp) / (C_доріжки + C_esd) ) ≈ Z_0 = 50 Ом
   ```
2. **Вирізання опорного полігону землі під падами (Ground Cutout)**: під контактними майданчиками TVS-компонента у внутрішньому шарі суцільної землі (Layer 2) роблять вікно (виріз), зсуваючи опорну площину на наступний шар (Layer 3). Це зменшує власну паразитну ємність мідного паду на друкованій платі на 0.08…0.15 пФ.

#### Розпізнавання дефектів трасування за TDR-профілем:

Сучасні стробоскопічні рефлектометри формують тестовий перепад напруги з фронтом `t_step = 15 пс`. За формою TDR-кривої інженер однозначно визначає характер паразитного елемента:
- **Ємнісна неоднорідність (пад TVS, ємність діода)**: формує гладкий від'ємний провал хвильового опору `ΔZ < 0` тривалістю, пропорційною `τ = Z_0 · C_esd`.
- **Індуктивна неоднорідність (довге відгалуження stub, розварка)**: формує гострий додатний сплеск `ΔZ > 0`, амплітуда якого визначається індуктивністю `L_stub / t_step`.
- **Вимога стандарту PCIe 6.0**: інтегральна площа неоднорідності імпедансу `∫ |Z(t) − Z_0| dt` на ділянці монтажу захисту не повинна перевищувати 150 пс·Ом.

### 5. SPICE-моделювання та поведінкові макромоделі

Для комплексного моделювання всього каналу зв'язку в середовищах LTspice або Cadence Spectre TVS-супресор представляють еквівалентною макромоделлю, що включає:
- Нелінійну ємність `C_j(V)` на базі рівняння Бардіна.
- Послідовну індуктивність розварки кристала `L_pkg` та опір підкладки `R_bulk`.
- Поведінковий генератор струму з ділянкою від'ємного опору для Snapback-структур.

Порівняння аналітичних розрахунків нашої програми з результатами чисельного SPICE-моделювання показує збіг затухання `S21` із похибкою менше 2.5%, що дозволяє використовувати запропонований алгоритм для швидкого автоматизованого скринінгу сотень найменувань компонентів на етапі схемотехнічного вибору.

### 6. Алгоритм та архітектура програми оцінки супресорів

Програмний аналізатор реалізує модульний підхід до оцінки фізичних параметрів компонентів:

1. **Модель компонента (`esd_candidate_t` / `EsdCandidate`)**: інкапсулює паспортні параметри супресора — назву технології, паразитну ємність `c_esd_pf`, власний динамічний опір `r_dyn_ohm`, напругу затискання при імпульсі TLP 16 А `v_cl_tlp_v` та стійкість до пікового струму форми 8/20 мкс `max_surge_a`.
2. **Аналітичний обчислювач (`evaluate_esd` / `SignalIntegrityAnalyzer`)**:
   - Розраховує частоту зрізу лінії за рівнем −3 дБ у гігагерцах.
   - Обчислює деградацію часу наростання фронту `Δt_r` у пікосекундах.
   - Визначає комплексне значення передачі `S21` на частоті Найквіста `f_Nyquist = DataRate / 2` та переводить його в децибели.
3. **Двофакторна матриця вердиктів**:
   - **Критерій цілісності сигналу**: `is_signal_clean = (s21_loss_db >= -0.5 дБ)`.
   - **Критерій надійності захисту**: `is_protection_safe = (v_cl_tlp_v <= v_receiver_max_v)`.

#### Метрологічний вимір та деембеддинг VNA:

В інженерних лабораторіях перед запуском серійного виробництва плати з ESD-захистом проходять вимірювання на 4-портовому векторному аналізаторі кіл (Vector Network Analyzer, VNA). Щоб виключити паразитний вплив калібрувальних кабелів та коаксіальних SMA-роз'ємів тестової плати, застосовують математичний деембеддинг (*De-embedding*) за методом 2X-Thru (IEEE 370). Розраховані за нашою програмою значення `S21` безпосередньо порівнюються з деембеддованою матрицею розсіювання, що дозволяє виявити навіть мінімальні невідповідності номіналів компонентів.

:::tabs
```c
#include <stdio.h>
#include <stdbool.h>
#include <math.h>

#define PI 3.14159265358979323846

typedef struct {
    const char *name;
    const char *tech_type;
    double c_esd_pf;      // Паразитна ємність (пФ)
    double r_dyn_ohm;     // Динамічний опір (Ом)
    double v_cl_tlp_v;    // Напруга фіксації при TLP 16 А (В)
    double max_surge_a;   // Піковий струм 8/20 мкс (А)
} esd_candidate_t;

typedef struct {
    double f_cutoff_ghz;      // Частота зрізу -3 дБ (ГГц)
    double delta_tr_ps;       // Завал фронту (пс)
    double s21_loss_db;       // Внесені втрати S21 на f_Nyquist (дБ)
    bool is_signal_clean;     // Чи вкладається у критерій S21 > -0.5 дБ
    bool is_protection_safe;  // Чи безпечна V_cl для приймача (< V_max)
} esd_evaluation_t;

static esd_evaluation_t evaluate_esd(const esd_candidate_t *cand,
                                    double data_rate_gbps,
                                    double z0_ohm,
                                    double v_receiver_max_v)
{
    esd_evaluation_t res;
    double c_farad = cand->c_esd_pf * 1e-12;
    double r_eff = z0_ohm / 2.0;
    double f_nyquist_hz = (data_rate_gbps * 1e9) / 2.0;

    // 1. Гранична частота зрізу -3 дБ
    double f_c_hz = 1.0 / (2.0 * PI * r_eff * c_farad);
    res.f_cutoff_ghz = f_c_hz / 1e9;

    // 2. Деградація часу наростання фронту
    double tr_sec = 2.2 * r_eff * c_farad;
    res.delta_tr_ps = tr_sec * 1e12;

    // 3. Внесені втрати S21 на частоті Найквіста
    double omega = 2.0 * PI * f_nyquist_hz;
    double denom = sqrt(4.0 + pow(omega * z0_ohm * c_farad, 2.0));
    double s21_mag = 2.0 / denom;
    res.s21_loss_db = 20.0 * log10(s21_mag);

    // 4. Критерії придатності
    res.is_signal_clean = (res.s21_loss_db >= -0.5);
    res.is_protection_safe = (cand->v_cl_tlp_v <= v_receiver_max_v);

    return res;
}
```

```cpp
class SignalIntegrityAnalyzer {
public:

        const double c_farad = cand.c_esd_pf * 1e-12;
        const double r_eff = z0_ohm_ / 2.0;

        const double s21_mag = 2.0 / denom;

    [[nodiscard]] constexpr double nyquist_freq() const noexcept { return data_rate_gbps_ / 2.0; }
    [[nodiscard]] constexpr double impedance() const noexcept { return z0_ohm_; }
    [[nodiscard]] constexpr double max_voltage() const noexcept { return v_max_phy_v_; }

private:
    double data_rate_gbps_;
    double z0_ohm_;
    double v_max_phy_v_;
};
```

### 7. Інженерний аналіз результатів та підводні камені

Результати моделювання наочно демонструють межі застосування кожної технології:

1. **Силовий TVS (450 пФ)**: частота зрізу становить усього 14.1 МГц, а затухання на 10 ГГц сягає катастрофічних `S21 = −55 дБ`. Його сфера — виключно силові шини DC/AC живлення та низькочастотні кнопкові входи.
2. **Стандартний ESD-TVS (3.5 пФ)**: зріз на 1.8 ГГц і втрати `S21 = −15 дБ`. Добре підходить для повношвидкісного USB 2.0 (480 Мбіт/с) та I2C/SPI шин, але повністю руйнує гігабітні інтерфейси.
3. **Низькоємнісний TVS на базі діодного моста (0.35 пФ)**: частота зрізу 18.2 ГГц, внесені втрати на 10 ГГц становлять `−0.41 дБ`. Це золотий стандарт для HDMI 2.0 (6 Гбіт/с) та USB 3.2 Gen 1 (5 Гбіт/с), що забезпечує надійне затискання на рівні 5.8 В при відмінній формі очної діаграми.
4. **Ультранизькоємнісний TVS Snapback SCR (0.12 пФ)**: частота зрізу 53 ГГц, втрати `S21 = −0.05 дБ`, а завал фронту становить лише 6.6 пс (при тривалості біта USB4 `T_UI = 50 пс`). Це єдине кремнієве рішення, придатне для USB4, Thunderbolt 4 та PCIe 5.0/6.0, яке поєднує надмалу ємність із низькою напругою фіксації `V_CL = 4.8 В`.
5. **Полімерний PVVM (0.08 пФ)**: має феноменальну смугу пропускання (частота зрізу 80 ГГц) та нульові втрати `S21 = −0.02 дБ`, що робить його незамінним для радіочастотних антенних трактів 24…60 ГГц. Проте через високу напругу фіксації (`V_CL = 32 В`) та значний динамічний опір `R_dyn = 1.8 Ом` він **не може** захистити 3.3-вольтові цифрові трансивери без потужних внутрішніх захисних діодів на кристалі мікросхеми.

#### Підводні камені практичного застосування:

- **Нелінійність ємності при зміні напруги сигналу**: бар'єрна ємність напівпровідникового TVS змінюється під час коливань амплітуди сигналу від 0 до `V_CC`. Якщо для NRZ це створює помірний джиттер, то в чотирирівневому кодуванні PAM4 це викликає несиметричне стискання верхнього та нижнього вічок очної діаграми (*Eye Symmetry Mask Violation*).
- **Перехресне наведення у багатоканальних збірках (Crosstalk)**: у збірках на 4 або 8 ліній в одному корпусі (наприклад, DFN-2510) паразитний ємнісний та індуктивний зв'язок між сусідніми кристалами та виводами може досягати `−30 дБ` на 10 ГГц. Для критичних диференційних пар USB4/PCIe застосовують окремі 2-канальні збірки для кожної пари або чіпи з внутрішніми екрануючими заземленими виводами (*GND Shield Pins*) між сигнальними каналами.
- **Температурний дрейф струму витоку**: у сучасних мобільних та портативних пристроях температура всередині герметичного корпусу може досягати 85…105 °C. При нагріванні струм витоку кремнієвого TVS подвоюється приблизно кожні 10 °C (`I_leak(T) = I_leak0 · 2^((T − 25)/10)`), зростаючи від 10 нА до десятків мікроампер, що створює постійний паразитний розряд акумулятора в режимі сну (*Deep Sleep*).
- **Імпедансна узгодженість тестових роз'ємів**: при верифікації на стенді довжина незахищеного виводу SMA-конектора не повинна перевищувати 0.5 мм, інакше додаткова індуктивність у 0.8 нГн спотворює вимірювання затухання `S21` на частотах понад 8 ГГц.
- **Вибір конструкції корпусу (Flip-Chip проти Wire-Bond)**: традиційні корпуси з дротяними розварками (Wire-Bonded DFN) мають внутрішню індуктивність розварок 0.8…1.5 нГн, що утворює резонансний провал у смузі пропускання на частоті 8…12 ГГц. Для сигналів понад 10 Гбіт/с застосовують виключно технологію прямого монтажу кристала (*Flip-Chip / CSP* або *Trench DFN*), де виводи формуються безпосередньо мідними стовпчиками (Copper Pillars) з індуктивністю менше 0.05 нГн.
- **Розщеплення земляних полігонів біля TVS-компонента**: неприпустимо розділяти сигнальний полігон GND під диференційною парою біля захисного компонента на окремі «аналогові» чи «захисні» острівці. Будь-який розріз у суцільному опорному шарі змушує високочастотний зворотний струм огинати перешкоду контуром великої площі, додаючи в лінію 5…10 нГн паразитної індуктивності та генеруючи потужне електромагнітне випромінювання.
- **Вплив паяльної маски друкованої плати**: паяльна маска між контактними майданчиками компонентів прямого монтажу (крок виводів 0.35…0.5 мм) має високі діелектричні втрати (`tan δ ≈ 0.02…0.035` на частоті 10 ГГц). На швидкісних лініях рекомендується застосовувати безмасочні контактні площадки (*Non-Solder Mask Defined, NSMD*) з повним видаленням маски між провідниками диференційної пари, що забезпечує зниження паразитної міжелектродної ємності на 0.05 пФ.
