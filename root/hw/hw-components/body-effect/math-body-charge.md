# 🧮 Електростатичне виведення формули ефекту підкладки

У класичній триполюсній моделі MOSFET напруга на затворі вважається єдиним чинником, що керує провідністю каналу. Проте під каналом розташований напівпровідник підкладки, просторовий заряд якого безпосередньо входить у баланс електростатичної рівноваги. Коли між витоком і підкладкою виникає напруга зміщення `V_SB`, енергетичні зони напівпровідника зсуваються, а шар збіднення під каналом розширюється. Щоб кількісно розрахувати зсув порогової напруги `ΔV_th` та визначити коефіцієнт ефекту підкладки `γ`, необхідно розв'язати одновимірне рівняння Пуассона для просторового заряду підкладки та записати умову зарядової нейтральності структури метал–діелектрик–напівпровідник.

---

### 1. Потенціал Фермі та поверхневий потенціал

Розглянемо n-канальний MOSFET на p-тип підкладці з однорідною концентрацією акцепторної домішки `N_A`. Положення рівня Фермі в товщі нейтрального напівпровідника відносно середини забороненої зони (власного рівня Фермі `E_i`) визначається потенціалом Фермі `ϕ_F`:

```
ϕ_F = (k·T / q) · ln(N_A / n_i)
```

де:
- `k` — стала Больцмана (`1.380649 × 10⁻²³ Дж/К`);
- `T` — абсолютна температура в Кельвінах (`300 К`);
- `q` — елементарний заряд електрона (`1.60217663 × 10⁻¹⁹ Кл`);
- `n_i` — власна концентрація носіїв у кремнії при 300 К (`≈ 1.0 × 10¹⁰ см⁻³`);
- `k·T / q` — тепловий потенціал `V_t ≈ 25.86 мВ` при `T = 300 К`.

Для типового легування підкладки `N_A = 2 × 10¹⁷ см⁻³`:

```
ϕ_F = 0.02586 · ln((2 × 10¹⁷) / (1.0 × 10¹⁰))    [підстановка концентрацій N_A та n_i]
    = 0.02586 · ln(2 × 10⁷)                       [ділення концентрацій під логарифмом]
    = 0.02586 · 16.811                            [обчислення натурального логарифма]
    = 0.435 В                                     [множення на тепловий потенціал V_t]
```

Критерій сильної інверсії полягає в тому, що концентрація електронів на межі розділу оксид–кремній має досягти концентрації дірок у глибині нейтральної p-підкладки. Це означає, що енергетичні зони на поверхні мають вигнутися вниз на величину `2·ϕ_F`.

Коли витік транзистора перебуває під потенціалом `V_S`, а підкладка — під потенціалом `V_B` (причому `V_S ≥ V_B`, тобто напруга витік-підкладка `V_SB = V_S − V_B ≥ 0`), квазірівень Фермі електронів у каналі піднімається відносно квазірівня Фермі дірок у підкладці на величину `V_SB`. Тому для досягнення однакової густини інверсійного шару поверхневий потенціал `ϕ_s` відносно глибини підкладки повинен подолати додатковий потенційний бар'єр:

```
ϕ_s(inv) = 2·ϕ_F + V_SB
```

### 2. Рівняння Пуассона та ширина збідненої області

У збідненій області під затвором вільні рухомі дірки відштовхнуті електричним полем углиб напівпровідника. Залишаються лише нерухомі негативно іонізовані атоми акцепторних домішок із густиною об'ємного просторового заряду:

```
ρ(x) = −q·N_A       [для 0 ≤ x ≤ W_dep]
ρ(x) = 0            [для x > W_dep]
```

де `x = 0` відповідає межі розділу діелектрик–кремній, а `x = W_dep` — максимальній глибині проникнення збідненого шару в підкладку.

Одновимірне рівняння Пуассона для розподілу електростатичного потенціалу `ϕ(x)` за глибиною має вигляд:

```
d²ϕ(x) / dx² = −ρ(x) / ε_si = q·N_A / ε_si
```

де `ε_si = ε_r(Si) · ε_0 ≈ 11.7 × 8.854 × 10⁻¹⁴ Ф/см ≈ 1.036 × 10⁻¹² Ф/см` — абсолютна діелектрична проникність монокристалічного кремнію.

Інтегруємо рівняння Пуассона за координатою `x` від довільної точки `x` до краю збідненого шару `W_dep`, де електричне поле спадає до нуля: `E(W_dep) = −dϕ/dx |_(x = W_dep) = 0`:

```
dϕ(x) / dx = −(q·N_A / ε_si) · (W_dep − x)
```

Інтегруємо цей вираз удруге від поверхні `x = 0` до межі збіднення `x = W_dep` з граничними умовами `ϕ(0) = ϕ_s` та `ϕ(W_dep) = 0`:

```
ϕ_s = ∫₀^{W_dep} (q·N_A / ε_si) · (W_dep − x) dx
    = (q·N_A / ε_si) · [W_dep · x − x² / 2]₀^{W_dep}    [взяття первісної від лінійної функції]
    = (q·N_A / (2·ε_si)) · W_dep²                       [підстановка верхньої межі інтегрування]
```

Звідси отримуємо явний зв'язок між глибиною збідненого шару `W_dep` і поверхневим потенціалом `ϕ_s`:

```
W_dep = √( (2·ε_si · ϕ_s) / (q·N_A) )
```

Підставляючи поверхневий потенціал на порозі сильної інверсії `ϕ_s = 2·ϕ_F + V_SB`, знаходимо точну ширину збідненої області як функцію напруги між витоком і підкладкою:

```
W_dep(V_SB) = √( (2·ε_si · (2·ϕ_F + V_SB)) / (q·N_A) )
```

### 3. Заряд підкладки та баланс напруг MOS-структури

Повний нерухомий просторовий заряд іонізованих акцепторів у збідненому шарі, розрахований на одиницю площі затвора, є добутком об'ємної густини заряду на глибину збіднення:

```
Q_B = −q·N_A · W_dep
    = −√( 2·q·ε_si · N_A · (2·ϕ_F + V_SB) )
```

Запишемо фундаментальне рівняння балансу електростатичних потенціалів у MOS-структурі вздовж поперечного перерізу від затвора крізь оксид до нейтральної підкладки:

```
V_GB = V_FB + V_ox + ϕ_s
```

де:
- `V_FB = Φ_MS − Q_ox / C_ox` — напруга плоских зон, що компенсує різницю робіт виходу матеріалу затвора й кремнію `Φ_MS` та фіксований паразитичний заряд в оксиді й на межі розділу `Q_ox`;
- `C_ox = ε_ox / t_ox` — питома ємність підзатворного діелектрика на одиницю площі (`ε_ox ≈ 3.9 · ε_0 ≈ 3.45 × 10⁻¹³ Ф/см`);
- `t_ox` — товщина діелектрика затвора;
- `V_ox` — спад напруги безпосередньо на шарі підзатворного діелектрика.

Згідно з теоремою Гаусса для межі діелектрик–напівпровідник, електричне поле в оксиді визначається повним зарядом у напівпровіднику:

```
V_ox = −Q_semi / C_ox = −(Q_inv + Q_B) / C_ox
```

У точці виникнення інверсійного каналу густина рухомих електронів ще мізерно мала порівняно з зарядом збіднення (`Q_inv ≈ 0`), а поверхневий потенціал досягає значення `ϕ_s = 2·ϕ_F + V_SB`. Тому напруга на діелектрику повністю визначається зарядом нерухомих акцепторів:

```
V_ox(th) = −Q_B / C_ox = √( 2·q·ε_si · N_A · (2·ϕ_F + V_SB) ) / C_ox
```

Підставляючи цей вираз у загальний баланс потенціалів, отримуємо порогову напругу між затвором і підкладкою:

```
V_GB(th) = V_FB + 2·ϕ_F + V_SB + (√( 2·q·ε_si · N_A · (2·ϕ_F + V_SB) ) / C_ox)
```

Оскільки в реальних електричних колах керуюча напруга прикладається між затвором і витоком транзистора (`V_GS = V_GB − V_SB`), порогова напруга відкривання транзистора `V_th` дорівнює:

```
V_th(V_SB) = V_GB(th) − V_SB
           = V_FB + 2·ϕ_F + (√( 2·q·ε_si · N_A · (2·ϕ_F + V_SB) ) / C_ox)
```

### 4. Коефіцієнт підкладки та кінцева аналітична формула

Визначимо номінальну порогову напругу транзистора `V_th0` при нульовому зміщенні між витоком і тілом (`V_SB = 0`):

```
V_th0 = V_FB + 2·ϕ_F + (√( 2·q·ε_si · N_A · 2·ϕ_F ) / C_ox)
```

Введемо коефіцієнт ефекту підкладки `γ` (гамма), який вимірюється у `В¹/²`:

```
γ = √( 2·q·ε_si · N_A ) / C_ox
```

Віднімаючи базовий поріг `V_th0` від порогової напруги зі зміщенням `V_th(V_SB)`, отримуємо аналітичний зв'язок:

```
V_th(V_SB) − V_th0
= (√( 2·q·ε_si · N_A · (2·ϕ_F + V_SB) ) − √( 2·q·ε_si · N_A · 2·ϕ_F )) / C_ox  [підстановка формул заряду збіднення]
= (√( 2·q·ε_si · N_A ) / C_ox) · (√( 2·ϕ_F + V_SB ) − √( 2·ϕ_F ))            [винесення множника заряду за дужки]
= γ · (√( 2·ϕ_F + V_SB ) − √( 2·ϕ_F ))                                        [підстановка коефіцієнта підкладки γ]
```

Отримуємо класичне рівняння порогової напруги MOSFET:

```
V_th(V_SB) = V_th0 + γ · (√( 2·ϕ_F + V_SB ) − √( 2·ϕ_F ))
```

Фізичний зміст коефіцієнта `γ`: він показує, наскільки сильно одинична зміна підкладкового заряду впливає на напругу затвора. Що тонший оксид (більша ємність `C_ox`), то слабший вплив підкладки, і навпаки — чим вища концентрація домішки `N_A`, тим масивніший заряд збідненого шару і тим вищий коефіцієнт `γ`.

### 5. Числовий розрахунок на параметрах планарного процесу

Виконаємо покроковий розрахунок для планарного NMOS-транзистора з такими конструктивними характеристиками:
- Рівень легування p-підкладки: `N_A = 3.0 × 10¹⁷ см⁻³`;
- Товщина підзатворного діелектрика SiO₂: `t_ox = 3.5 нм = 3.5 × 10⁻⁷ см`;
- Початковий поріг при нульовому зміщенні: `V_th0 = 0.350 В`.

**Крок 1. Обчислення питомої ємності діелектрика `C_ox`:**

```
C_ox = ε_ox / t_ox
     = (3.9 · 8.854 × 10⁻¹⁴ Ф/см) / (3.5 × 10⁻⁷ см)    [підстановка проникності та товщини]
     = (3.453 × 10⁻¹³ Ф/см) / (3.5 × 10⁻⁷ см)            [обчислення абсолютної проникності SiO₂]
     = 9.866 × 10⁻⁷ Ф/см² = 9.866 фФ/мкм²                [ділення величин]
```

**Крок 2. Обчислення подвоєного потенціалу Фермі `2·ϕ_F`:**

```
2·ϕ_F = 2 · (0.02586 В) · ln((3.0 × 10¹⁷) / (1.0 × 10¹⁰))    [підстановка концентрацій домішок]
      = 0.05172 · ln(3.0 × 10⁷)                               [ділення під знаком логарифма]
      = 0.05172 · 17.217                                      [взяття натурального логарифма]
      = 0.890 В                                               [перемноження теплового множника]
```

Знаходимо корінь із подвоєного потенціалу:

```
√(2·ϕ_F) = √(0.890) = 0.943 В¹/²
```

**Крок 3. Обчислення коефіцієнта ефекту підкладки `γ`:**

```
√(2·q·ε_si · N_A)
= √( 2 · (1.602 × 10⁻¹⁹ Кл) · (1.036 × 10⁻¹² Ф/см) · (3.0 × 10¹⁷ см⁻³) )    [підстановка фізичних констант]
= √( 3.319 × 10⁻³⁰ · 3.0 × 10¹⁷ )                                            [перемноження q та проникності кремнію]
= √( 9.957 × 10⁻¹³ )                                                         [перемноження на концентрацію домішки]
= 9.978 × 10⁻⁷ Кл / (В¹/² · см²)                                             [видобування квадратного кореня]
```

Ділимо на ємність оксиду `C_ox`:

```
γ = (9.978 × 10⁻⁷) / (9.866 × 10⁻⁷)
  = 1.011 В¹/²
```

**Крок 4. Розрахунок порогової напруги при практичних зміщеннях `V_SB`:**

Для помірного зворотного зміщення `V_SB = 0.6 В`:

```
√(2·ϕ_F + V_SB) = √(0.890 + 0.60) = √(1.490) = 1.221 В¹/²

ΔV_th = 1.011 · (1.221 − 0.943)    [підстановка різниці коренів]
      = 1.011 · 0.278              [обчислення різниці потенціалів]
      = 0.281 В                    [множення на коефіцієнт гамма]

V_th(0.6 В) = 0.350 + 0.281 = 0.631 В
```

Для глибокого зворотного зміщення `V_SB = 1.8 В`:

```
√(2·ϕ_F + V_SB) = √(0.890 + 1.80) = √(2.690) = 1.640 В¹/²

ΔV_th = 1.011 · (1.640 − 0.943)    [підстановка різниці коренів]
      = 1.011 · 0.697              [обчислення різниці потенціалів]
      = 0.705 В                    [множення на коефіцієнт гамма]

V_th(1.8 В) = 0.350 + 0.705 = 1.055 В
```

При зміщенні витоку на `1.8 В` порогова напруга транзистора зростає з `0.35 В` до понад `1.05 В` — тобто збільшується утричі. Якщо напруга живлення логічного блоку становить `1.0 В`, такий транзистор буде повністю заблокований і не зможе пропустити струм відкривання.

### 6. Підкладкова крутість і малосигнальні параметри

У режимі насичення струм стоку MOSFET визначається квадратичною формулою Шіхмана–Ходжеса:

```
I_D = (1/2) · μ_n · C_ox · (W / L) · (V_GS − V_th(V_SB))² · (1 + λ·V_DS)
```

Оскільки поріг `V_th` безпосередньо модулюється напругою на підкладці, будь-яка зміна `V_BS` викликає зміну струму стоку. Цей ефект описується малосигнальною підкладковою крутістю `g_mb`:

```
g_mb = ∂I_D / ∂V_BS = −∂I_D / ∂V_SB
```

Застосовуючи правило ланцюгового диференціювання:

```
g_mb = (∂I_D / ∂V_th) · (∂V_th / ∂V_BS)        [ланцюгове правило похідної складеної функції]
     = (−∂I_D / ∂V_GS) · (−∂V_th / ∂V_SB)      [вираження через крутість затвора g_m]
     = g_m · (∂V_th / ∂V_SB)                   [скорочення знаків мінус]
```

де `g_m = ∂I_D / ∂V_GS = μ_n · C_ox · (W / L) · (V_GS − V_th)` — головна крутість транзистора за затвором.

Диференціюємо формулу порогової напруги за напругою зміщення `V_SB`:

```
∂V_th / ∂V_SB = ∂ [ V_th0 + γ · (√(2·ϕ_F + V_SB) − √(2·ϕ_F)) ] / ∂V_SB    [диференціювання виразу порогової напруги]
              = γ / (2 · √(2·ϕ_F + V_SB))                                  [взяття похідної від квадратного кореня]
```

Звідси безрозмірний коефіцієнт передачі підкладки `η = g_mb / g_m`:

```
η = g_mb / g_m = γ / (2 · √(2·ϕ_F + V_SB))
```

Для розглянутого вище приладу при `V_SB = 0`:

```
η = 1.011 / (2 · 0.943) = 1.011 / 1.886 ≈ 0.536
```

Тобто підкладка працює як другий затвор з ефективністю понад `53%` від основного.

#### Вплив `g_mb` на витоковий повторювач (Source Follower)

Розглянемо каскад зі спільним стоком (витоковий повторювач) із навантажувальним резистором `R_L`. Вихідний сигнал знімається з витоку, тому під час роботи потенціал витоку коливається відносно заземленої підкладки, викликаючи динамічну модуляцію порогу.

Запишемо рівняння струмів у вихідному вузлі за законом Кірхгофа:

```
i_out = g_m · v_gs + g_mb · v_bs − v_out / R_L = 0
```

Оскільки заземлена підкладка має нульовий потенціал змінної напруги (`v_b = 0`), напруга між підкладкою і витоком дорівнює `v_bs = 0 − v_out = −v_out`. Напруга затвор-витік дорівнює `v_gs = v_in − v_out`. Підставляючи ці вирази:

```
g_m · (v_in − v_out) + g_mb · (−v_out) − v_out / R_L = 0    [підстановка напруг затвор-витік та підкладка-витік]
g_m · v_in = v_out · (g_m + g_mb + 1 / R_L)                  [групування членів при вихідній напрузі v_out]
```

Коефіцієнт підсилення напруги витокового повторювача:

```
A_v = v_out / v_in = g_m / (g_m + g_mb + 1 / R_L)
```

Якщо знехтувати ефектом підкладки (`g_mb = 0`) при великому навантаженні `R_L >> 1/g_m`, коефіцієнт передачі наближається до одиниці: `A_v ≈ g_m / g_m = 1`.
Проте з урахуванням ефекту підкладки (`g_mb = η · g_m ≈ 0.536 · g_m`):

```
A_v = g_m / (g_m + 0.536 · g_m) = 1 / 1.536 ≈ 0.651
```

Ефект підкладки зменшує коефіцієнт передачі витокового повторювача з теоретичних `0.98` до `0.65`, спричиняючи втрату понад `30%` амплітуди сигналу та вносячи нелінійні спотворення через нелінійну залежність `g_mb(V_SB)`.

#### Вплив `g_mb` на вихідний опір каскодного джерела струму

У каскодному джерелі струму (транзистор `M1` внизу, транзистор `M2` вгорі) витік `M2` з'єднаний зі стоком `M1`. Малосигнальний аналіз дає точний вираз для вихідного опору каскода:

```
R_out = r_o1 + r_o2 + (g_m2 + g_mb2) · r_o1 · r_o2
```

де `r_o1` та `r_o2` — власні вихідні опори транзисторів через модуляцію довжини каналу.

Тут підкладкова крутість `g_mb2` додається до крутості затвора `g_m2`, збільшуючи вихідний опір каскодного джерела на величину `g_mb2 · r_o1 · r_o2` (приблизно на `20–50%`). Це рідкісний випадок, коли ефект підкладки дає позитивний результат в аналоговій схемотехніці.

### 7. Симетрія для p-канальних транзисторів (PMOS)

Для p-канальних транзисторів, сформованих у n-кишені (n-well) з концентрацією донорної домішки `N_D`, усі полярності напруг і зарядів дзеркально обертаються:
1. Потенціал Фермі n-області є від'ємним відносно середини забороненої зони:
   ```
   ϕ_F(n) = −(k·T / q) · ln(N_D / n_i)
   ```
2. Початковий поріг PMOS є від'ємним: `V_th0(PMOS) < 0` (зазвичай `−0.35...−0.45 В`).
3. Напруга підкладка-витік `V_BS = V_B − V_S ≥ 0` створює зворотне зміщення для p-n переходу витоку.
4. Порогова напруга стає більш від'ємною:
   ```
   V_th(PMOS) = V_th0 − γ_p · ( √(2·|ϕ_F| + V_BS) − √(2·|ϕ_F|) )
   ```
   де `γ_p = √(2·q·ε_si · N_D) / C_ox`.

Оскільки абсолютна величина порогової напруги `|V_th(PMOS)|` зростає зі збільшенням `V_BS`, PMOS-транзистори у послідовних стеках верхнього плеча (наприклад, у логічних вентилях NOR) так само зазнають падіння струму та сповільнення перемикання, як і NMOS-транзистори в NAND. Для досягнення однакового часу наростання і спаду геометричну ширину каналу `W` верхніх PMOS-транзисторів у NOR доводиться масштабувати у 3–4 рази ширше порівняно з симетричними NMOS-ключами.

### 8. Неоднорідне легування та параметри моделей SPICE BSIM

У класичному аналітичному виведенні концентрація домішок `N_A` вважалася строго сталою за глибиною напівпровідника. Проте в сучасних субмікронних технологіях для боротьби з проколом каналу (punchthrough) та короткоканальними ефектами застосовують неоднорідні профілі легування:
- **Ретроградне легування (Retrograde Well):** низька концентрація домішок біля поверхні для збереження високої рухливості електронів `μ_n` та висока концентрація в глибині для придушення підповерхневих струмів витоку.
- **Кишенькове легування (Halo / Pocket Implants):** локальне підвищення концентрації біля країв витоку й стоку.

При неоднорідному легуванні параметр `γ` стає функцією глибини збідненого шару, а отже — функцією напруги `V_SB`. Для точного моделювання в симуляторах SPICE (моделі BSIM3/BSIM4) використовують розширене двопараметричне наближення:

```
V_th(V_SB) = V_th0 + K1 · (√(Φ_s + V_SB) − √(Φ_s)) − K2 · V_SB
```

де:
- `K1 = γ_body` — основний коефіцієнт ефекту підкладки для приповерхневої області;
- `K2` — коригуючий коефіцієнт впливу глибоких шарів підкладки (враховує зменшення відносного внеску збіднення при глибокому проростанні шару);
- `Φ_s = 2·ϕ_F` — поверхневий потенціал інверсії (у SPICE позначається як параметр `PHI`).

Для коротких каналів додається також поправка на просторову взаємодію між збідненими областями стоку й витоку, відома як ефект зворотного короткоканального зсуву порогу (Reverse Short-Channel Effect, RSCE), що призводить до залежності параметрів `K1` та `K2` від геометричної довжини затвора `L`.

### 9. Бар'єрна ємність переходу підкладки та динамічні втрати

Зворотне зміщення переходу підкладка-витік не лише змінює поріг, але й створює змінну бар'єрну ємність збідненого шару `C_sb`. За означенням диференціальної ємності:

```
C_sb = |dQ_B / dV_SB|
     = d [ √( 2·q·ε_si · N_A · (2·ϕ_F + V_SB) ) ] / dV_SB    [диференціювання виразу для заряду збіднення]
     = (1/2) · √( 2·q·ε_si · N_A / (2·ϕ_F + V_SB) )           [взяття похідної від квадратного кореня]
     = ε_si / W_dep(V_SB)                                     [вираження через ширину збідненого шару]
```

Звідси ємність одиниці площі переходу підкладки виражається через початкову ємність `C_sb0` при нульовому зміщенні:

```
C_sb(V_SB) = C_sb0 / √( 1 + V_SB / (2·ϕ_F) )
```

де `C_sb0 = ε_si / W_dep0 = √( q·ε_si · N_A / (4·ϕ_F) )`.

У цифрових схемах при перемиканні логічних рівнів плаваючий вузол перезаряджає цю нелінійну ємність `C_sb`. Енергія, що витрачається на перезаряджання ємності підкладки за один такт перемикання, розраховується через інтеграл заряду:

```
E_dyn = ∫₀^{V_DD} V_SB · C_sb(V_SB) dV_SB
```

Ця ємність додається до загальної вузлової паразитної ємності, збільшуючи динамічні втрати енергії в процесорі та сповільнюючи фронти імпульсів у послідовних транзисторних ланцюгах.

### 10. Температурна залежність ефекту підкладки

Потенціал Фермі `ϕ_F` суттєво залежить від абсолютної температури `T` кристала через дві причини: зміну теплового потенціалу `k·T/q` та експоненційну зміну власної концентрації носіїв `n_i(T)`.

Власна концентрація носіїв кремнію залежить від температури за законом:

```
n_i(T) = A · T^{3/2} · exp( −E_g(T) / (2·k·T) )
```

де `E_g(T) ≈ 1.17 В − 4.73 × 10⁻⁴ · T² / (T + 636)` — ширина забороненої зони кремнію.

З підвищенням температури `n_i` стрімко зростає (від `1.0 × 10¹⁰ см⁻³` при 300 К до понад `1.4 × 10¹² см⁻³` при 400 К), що призводить до зменшення потенціалу Фермі `ϕ_F`:

```
dϕ_F / dT ≈ −(1/T) · (E_g(0) / (2·q) − ϕ_F) ≈ −1.0 ... −1.5 мВ/К
```

Зменшення `ϕ_F` зі зростанням температури викликає:
1. Зниження початкового порогу `V_th0` транзистора зі швидкістю приблизно `−1.5 ... −3.0 мВ/К`;
2. Зменшення абсолютного значення підкладкового зсуву `ΔV_th(V_SB)`, оскільки зменшується вихідний бар'єр `2·ϕ_F`.

При низьких температурах (наприклад, у кріогенних квантових процесорах при 77 К чи 4 К) концентрація `n_i` вимерзає до нуля, потенціал `2·ϕ_F` наближається до повної ширини забороненої зони `E_g / q ≈ 1.16 В`, що робить збіднений шар більш чутливим до напруги підкладки та збільшує коефіцієнт `η`.

### 11. Граничний перехід до структур із повним збідненням (FD-SOI та FinFET)

Ультратонкі структури кремнію на ізоляторі (FD-SOI) та тривимірні плавцеві транзистори (FinFET) демонструють принципово іншу електростатику. У таких приладах товщина кремнієвого шару або плавця `t_si` (зазвичай `5–8 нм`) є значно меншою за природну товщину збідненого шару `W_dep`, яка в об'ємному напівпровіднику сягає `50–100 нм`.

Оскільки геометричні межі кремнію обмежені ізолятором або протилежними гранями затвора, об'ємний заряд збіднення фіксується товщиною плівки й більше не може розростатися:

```
Q_B(max) = −q · N_A · t_si = const
```

Диференціюючи цей фіксований заряд за напругою зміщення витоку:

```
∂Q_B / ∂V_SB = 0
```

Оскільки похідна заряду збіднення за напругою витоку дорівнює нулю, ефективний класичний коефіцієнт ефекту підкладки зникає:

```
γ_eff = (1 / C_ox) · (∂Q_B / ∂V_SB) → 0
```

Відповідно, паразитна підкладкова крутість `g_mb` також прямує до нуля:

```
g_mb(FinFET) = g_m · (∂V_th / ∂V_SB) ≈ 0
```

Це математично підтверджує, чому перехід мікроелектроніки на тривимірні затвори та ультратонкі шари кремнію повністю ліквідував проблему деградації порогової напруги в цифрових і аналогових інтегральних схемах, забезпечивши максимальну швидкість перемикання та високу лінійність аналогової обробки сигналів.
