# 🧮 Частотна смуга та динамічні спотворення цифрового потенціометра

Цифровий потенціометр на низьких частотах поводиться як майже ідеальний дільник напруги. Проте щойно частота вхідного сигналу підіймається до сотень кілогерців або мегагерців, вихідна амплітуда починає несподівано падати, а форма гармонічного сигналу спотворюється. Причина полягає у взаємодії власного розподіленого опору резистивної матриці, кінцевого опору внутрішніх CMOS-ключів R_W та паразитної ємності вузла повзунка C_W.

Тут наведено строгий математичний вивід еквівалентного вихідного опору за Тевеніном, частоти зрізу фільтра низьких частот для довільного коду повзунка, а також розрахунок нелінійних спотворень (THD), спричинених модуляцією опору ключа амплітудою сигналу.

## 1. Еквівалентний опір виходу та передавальна функція

Розглянемо цифровий потенціометр із повним номінальним опором R_AB між кінцевими терміналами A і B. Положення повзунка задається цифровим кодом D, нормалізованим до діапазону від 0 до 1:

```text
D = code / (2^N - 1)
```

де N — розрядність потенціометра (для 8-бітного чипа code належить [0, 255], D належить [0, 1]).

Термінал B заземлений (V_B = 0 В), а на термінал A подано гармонічний сигнал V_A(t). Повний опір R_AB розділений повзунком на дві частини:

```text
R_BW = D · R_AB
R_AW = (1 - D) · R_AB
```

Між точкою з'єднання резисторів і зовнішнім виводом повзунка W увімкнений внутрішній CMOS-ключ із ненульовим опором увімкненого каналу R_W. Паразитна ємність вузла повзунка відносно землі позначається як C_W (сюди входить сумарна ємність стоків усіх закритих і одного відкритого ключа, ємність металевої шини та ємність виводу корпусу).

Знайдемо еквівалент Тевеніна для кола, що живить ємність C_W. Напруга холостого ходу у вузлі повзунка дорівнює напрузі ідеального дільника:

```text
V_th(s) = V_A(s) · (R_BW / (R_AW + R_BW))      [напруга холостого ходу дільника]
        = V_A(s) · (D · R_AB / R_AB)          [підстановка значень плечей R_BW та R_AW]
        = D · V_A(s)                          [скорочення R_AB]
```

Еквівалентний опір Тевеніна R_th(D) розраховується при закороченому джерелі вхідного сигналу V_A = 0. У цій схемі резистори R_AW та R_BW виявляються з'єднаними паралельно, а послідовно з їхньою паралеллю стоїть опір відкритого ключа R_W:

```text
R_th(D) = (R_AW || R_BW) + R_W                                                      [паралельне з'єднання плечей плюс опір ключа]
        = ( (1 - D) · R_AB · D · R_AB ) / ( (1 - D) · R_AB + D · R_AB ) + R_W       [розкриття формули паралельних опорів]
        = ( D · (1 - D) · R_AB² ) / R_AB + R_W                                       [спрощення знаменника: (1-D) + D = 1]
        = D · (1 - D) · R_AB + R_W                                                   [скорочення R_AB у чисельнику й знаменнику]
```

Еквівалентна схема зводиться до найпростішого RC-фільтра першого порядку, де джерело V_th(s) = D · V_A(s) навантажене на послідовний опір R_th(D) та паразитну ємність C_W. Передавальна функція по напрузі H(s) = V_W(s) / V_A(s) має вигляд:

```text
H(s) = D / (1 + s · R_th(D) · C_W)                      [передавальна функція RC-ланцюга першого порядку]
     = D / (1 + s · (D · (1 - D) · R_AB + R_W) · C_W)   [підстановка вихідного опору R_th(D)]
```

Частота зрізу за рівнем −3 дБ визначається положенням полюса передавальної функції:

```text
f_{-3dB}(D) = 1 / ( 2 · π · R_th(D) · C_W )                                [частота полюса передавальної функції]
            = 1 / ( 2 · π · [ D · (1 - D) · R_AB + R_W ] · C_W )           [підстановка значення R_th(D)]
```

## 2. Найгірший випадок смуги пропускання (Mid-Scale)

Дослідимо функцію R_th(D) на екстремум за параметром D на інтервалі від 0 до 1. Візьмемо першу похідну:

```text
d(R_th)/dD = (1 - 2·D) · R_AB = 0   =>   D = 0.5
```

Друга похідна:

```text
d²(R_th)/dD² = -2 · R_AB < 0
```

Оскільки друга похідна скрізь від'ємна, значення D = 0.5 (середина шкали, код 128 для 8-бітного чипа) відповідає абсолютному **максимуму вихідного опору Тевеніна** і, відповідно, **мінімальній смузі пропускання**:

```text
R_th_max = R_th(0.5) = 0.5 · 0.5 · R_AB + R_W = R_AB / 4 + R_W

f_{-3dB_min} = 1 / ( 2 · π · ( R_AB / 4 + R_W ) · C_W )
```

У крайніх положеннях (D = 0 або D = 1) паралельний опір плечей спадає до нуля, і вихідний опір визначається виключно опором ключа R_W:

```text
R_th(0) = R_th(1) = R_W

f_{-3dB_max} = 1 / ( 2 · π · R_W · C_W )
```

### Числовий розрахунок для типових номіналів

Нехай типові параметри цифрового потенціометра становлять: опір ключа R_W = 100 Ом, паразитна ємність повзунка C_W = 35 пФ. Порівняємо найгіршу смугу пропускання (у точці D = 0.5) для трьох поширених номіналів R_AB:

1. **Номінал R_AB = 10 кОм:**
```text
R_th_max = 10000 / 4 + 100 = 2500 + 100 = 2600 Ом

f_{-3dB} = 1 / ( 2 · π · 2600 · 35×10⁻¹² )   [підстановка R_th та C_W у формулу полюса]
         ≈ 1 / ( 5.7177×10⁻⁷ )                [розрахунок знаменника]
         ≈ 1.748 МГц                          [результуюча частота зрізу]
```

2. **Номінал R_AB = 50 кОм:**
```text
R_th_max = 50000 / 4 + 100 = 12500 + 100 = 12600 Ом

f_{-3dB} = 1 / ( 2 · π · 12600 · 35×10⁻¹² )  [підстановка R_th та C_W у формулу полюса]
         ≈ 1 / ( 2.7709×10⁻⁶ )                [розрахунок знаменника]
         ≈ 360.9 кГц                          [результуюча частота зрізу]
```

3. **Номінал R_AB = 100 кОм:**
```text
R_th_max = 100000 / 4 + 100 = 25000 + 100 = 25100 Ом

f_{-3dB} = 1 / ( 2 · π · 25100 · 35×10⁻¹² )  [підстановка R_th та C_W у формулу полюса]
         ≈ 1 / ( 5.5198×10⁻⁶ )                [розрахунок знаменника]
         ≈ 181.2 кГц                          [результуюча частота зрізу]
```

Звідси очевидний практичний висновок: цифровий потенціометр на 100 кОм у ролі регулятора гучності у високоякісному аудіотракті на частоті 20 кГц уже вносить фазовий зсув:

```text
φ = -arctan( f / f_{-3dB} )      [фазовий зсув RC-ланцюга першого порядку]
  = -arctan( 20000 / 181200 )    [підстановка частоти 20 кГц та f_{-3dB} = 181.2 кГц]
  ≈ -arctan( 0.1104 )            [обчислення відношення частот]
  ≈ -6.3°                        [результуючий фазовий зсув]
```

А спад амплітуди на 20 кГц становить:

```text
|H(jω)| / D = 1 / sqrt( 1 + (20 / 181.2)² )   [модуль коефіцієнта передачі фільтра]
            = 1 / sqrt( 1 + 0.01218 )         [обчислення квадратичного доданка]
            ≈ 0.9940  (-0.052 дБ)             [ослаблення сигналу в децибелах]
```

Для широкосмугових кіл або високочастотних фільтрів слід обирати найменший можливий номінал R_AB (1 кОм ... 10 кОм), або компенсувати спад активними каскадами.

## 3. Вплив зовнішнього навантаження (R_L, C_L)

Якщо до повзунка під'єднано реальне навантаження з опором R_L та вхідною ємністю наступного каскаду C_L (наприклад, ємність доріжки друкованої плати та входу ОП), загальна ємність вузла стає рівною:

```text
C_total = C_W + C_L
```

А передавальне відношення на постійному струмі H_0(D) просідає через резистивне навантаження:

```text
R_bottom_eff = ( D · R_AB ) || ( R_W + R_L )
```

Коли опір навантаження значно більший за повний опір потенціометра (R_L ≫ R_AB), результуючий вихідний опір із врахуванням R_L становить:

```text
R_out(D) = ( R_th(D) · R_L ) / ( R_th(D) + R_L )
```

І реальна смуга пропускання каскаду обчислюється як:

```text
f_{-3dB_real}(D) = 1 / ( 2 · π · R_out(D) · (C_W + C_L) )
```

Якщо ємність монтажу C_L додає ще 50 пФ (C_total = 85 пФ), смуга для чипа на 100 кОм у середній точці падає до критичних 74.5 кГц.

## 4. Нелінійні спотворення (THD) від модуляції опору ключа R_W(V)

CMOS-ключ усередині цифрового потенціометра є передавальним вентилем (Transmission Gate), що складається з паралельно з'єднаних польових транзисторів NMOS та PMOS. Опір відкритого каналу польового транзистора в тріодному (лінійному) режимі залежить від напруги затвор-витік:

```text
R_on_nmos ≈ 1 / [ μ_n · C_ox · (W/L)_n · (V_DD - V_in - V_th_n) ]
R_on_pmos ≈ 1 / [ μ_p · C_ox · (W/L)_p · (V_in - |V_th_p|) ]
```

Сумарний опір ключа R_W(V_in) = R_on_nmos || R_on_pmos не є сталою величиною. Він має куполоподібну залежність від миттєвого потенціалу сигналу V_in: мінімальний біля рейок живлення (0 В і V_DD) та максимальний у середині діапазону.

Нехай залежність R_W від напруги V наближається квадратичним поліномом:

```text
R_W(V) = R_{W0} · [ 1 + α · (V - V_DD / 2)² ]
```

Коли через повзунок протікає ненульовий струм I_W у навантаження R_L, падіння напруги на ключі становить:

```text
V_drop = I_W · R_W(V)                [падіння напруги на опорі ключа]
       = (V_W / R_L) · R_W(V)        [вираження струму повзунка через опір навантаження]
```

Підставивши гармонічний сигнал V(t) = V_0 · sin(ω · t), отримуємо появу вищих гармонік струму та напруги:

```text
V_drop(t) ≈ (V_0 / R_L) · R_{W0} · sin(ω·t) · [ 1 + α · (V_0 · sin(ω·t) - V_DD / 2)² ]
```

Розклад тригонометричного добутку sin³(ω · t) = (3/4) · sin(ω · t) - (1/4) · sin(3 · ω · t) генерує третю гармоніку сигналу з частотою 3ω. Коефіцієнт гармонійних спотворень (THD) у першому наближенні прямо пропорційний відношенню опору ключа до опору навантаження:

```text
THD ≈ ( α · V_0² · R_{W0} ) / ( 4 · R_L )
```

### Практичне усунення THD

1. **Мінімізація струму повзунка (I_W → 0):** Повзунок W підключається виключно до неінвертуючого входу операційного підсилювача з польовими транзисторами на вході (JFET або CMOS, струм витоку I_B < 10 пА). При I_W ≈ 0 падіння напруги на R_W(V) прямує до нуля, і нелінійність ключа перестає спотворювати вихідний сигнал.
2. **Ратіометричне увімкнення:** При роботі в режимі дільника напруги сигнал ділиться резисторами полікремнієвої матриці, температурний і потенціальний коефіцієнт яких у сотні разів нижчий за кремнієвий канал транзистора.
