- [RTC і точний відлік часу](root:hw-components/rtc-timekeeping) — структура лічильників, калібрування та регістри збереження часу.

- [Детектування просідання напруги](root:hw-arch/brownout) — пороги POR, PVD та поведінка мікроконтролера при аварії живлення.
</preknowlist>

Коли на шині основного живлення промислового контролера чи автономного реєстратора напруга 3.3 В падає до нуля, процесорне ядро, конвеєри інструкцій і швидкісна периферія зупиняються за мікросекунди, щойно розряджаються блокувальні конденсатори. Проте через тиждень, місяць або три роки після знеструмлення прилад під час першого запуску повинен мати абсолютно точний календарний час, збережені калібрувальні константи датчиків у незалежній пам'яті та точні мітки часу несанкціонованого відкриття корпусу приладу, зафіксовані в темряві. Для цього всередині мікроконтролера створюють фізично відокремлену область кремнію — домен резервного живлення, підключений до окремого виводу `VBAT`.

Головне схемотехнічне протиріччя вузла `VBAT` полягає в масштабах струмів: якщо активне ядро споживає десятки міліампер, то резервний домен зобов'язаний укладатися в сумарний струм менше ніж 1 мкА. Будь-який паразитно відкритий p-n перехід, витік через затвор або наскрізний струм комутатора здатні спустошити літієвий дисковий елемент за кілька діб замість десятиліття.

### Архітектура кремнієвого острова та міждоменна ізоляція

Домен резервного живлення (англ. *Backup Power Domain*) — це фізично відокремлений острів на напівпровідниковій підкладці мікроконтролера, розміщений у власній ізольованій кишені (технологія Triple-Well або Deep N-Well). Така топологічна ізоляція запобігає протіканню підкладкових струмів від знеструмлених або зашумлених вузлів цифрового ядра до надчутливих кіл генератора реального часу.

До складу резервного домену входять лише критично необхідні вузли, здатні функціонувати в умовах суворого ліміту споживання потужності:

1. **Генератор низької частоти LSE (32.768 кГц):** інвертор генератора П'єрса, оптимізований для збудження годинникового кварцу при транспровідності `g_m` у межах одиниць мікросименсів, що споживає всього 100–300 нА.
2. **Ядро годинника реального часу (RTC Core):** асинхронний 7-бітний подільник частоти, синхронний 15-бітний дільник і двійково-десяткові (BCD) лічильники секунд, хвилин, годин, днів і років.
3. **Резервні регістри (Backup Registers, BKP):** масив із 20–32 32-розрядних регістрів, побудованих на статичних тригерах наднизького витоку, що зберігають налаштування системи та криптографічні ключі.
4. **Резервне статичне ОЗП (Backup SRAM):** блок пам'яті обсягом 2–4 КБ, призначений для зберігання контексту операційної системи реального часу перед переходом у режим глибокого сну.
5. **Модуль детектування розкриття корпусу (Tamper & Timestamping):** швидкодіючий компаратор зовнішніх сигналів тривоги, здатний апаратно затерти вміст Backup SRAM за кілька наносекунд при спрацюванні кінцевого вимикача чи зламі пломби.
6. **Апаратний комутатор живлення (Power Switch):** аналоговий селектор, що підключає шину резервного домену до основного живлення `VDD` або до піна `VBAT`.

![Архітектура домену резервного живлення](/root/hw/hw-components/backup-power-domain/img/vbat-internal-architecture.svg)
*Кремнієва архітектура домену резервного живлення: ізольований острів із годинником RTC, генератором LSE 32.768 кГц, пам'яттю Backup SRAM та апаратним бар'єром міждоменної ізоляції.*

Найбільшу небезпеку для домену становить інтерфейсна межа з основним доменом `VDD`. Коли основне живлення вимикається, напруга на лініях системної шини (адреси, дані, сигнали вибірки) спадає до 0 В або «зависає» у високоімпедансному плаваючому стані. Якщо подати такий невизначений потенціал на затвори польових транзисторів резервного домену, виникне наскрізний струм провідності CMOS-інверторів (одночасне часткове відкриття N- і P-каналів), який миттєво підніме струм споживання з наноампер до сотень мікроампер.

Щоб цьому запобігти, на межі двох світів ставлять **ізоляційні комірки** (англ. *Isolation Cells*) та **перетворювачі рівнів** (англ. *Level Shifters*). Коли детектор напруги фіксує падіння `VDD` нижче порогу працездатності ядра, апаратний сигнал `PWR_ISO` примусово відсікає входи резервного домену, фіксуючи цифрові лінії на рівні внутрішньої землі або внутрішнього `V_BACKUP` за допомогою логічних елементів 2AND/2OR із прямим підтягуванням.

#### Кремнієва топологія Backup SRAM на транзисторах High-Vt

Комірки оперативної пам'яті основного процесорного ядра оптимізують для максимальної швидкодії: у них використовують транзистори з низькою пороговою напругою (Low-Vt або Standard-Vt) і надтонкими підзатворними оксидами (товщиною 1.2–1.8 нм). Такі транзистори перемикаються за пікосекунди, але мають значний квантово-механічний струм тунелювання електронів крізь оксид затвора та відчутний підпороговий струм витоку сток-витік.

Для резервної пам'яті Backup SRAM (2–4 КБ) швидкодія в сотні мегагерц не потрібна. Тому її 6-транзисторні комірки (6T SRAM) виготовляють за спеціальною технологією наднизького витоку:
- **Високий поріг відкриття (High-Vt):** Порогову напругу транзисторів штучно підвищують додатковим легуванням каналу, що пригнічує підпороговий струм витоку у вимкненому стані на три порядки.
- **Потовщений підзатворний діелектрик (Dual Gate Oxide):** Товщину оксиду кремнію збільшують до 3.5–5.0 нм, зводячи пряме тунелювання затвора практично до нуля.
- **Асиметричні розміри каналів:** Геометрію транзисторів зворотного зв'язку в тригерах розраховують так, щоб забезпечити статичний запас стійкості (Static Noise Margin, SNM) при напрузі живлення аж до 1.6 В, гарантуючи збереження бітів під час глибокого просідання батареї.

#### Збудження LSE: від'ємний опір та коефіцієнт запасу (Safety Factor)

Генератор низької частоти LSE базується на схемі інвертора П'єрса, що охоплений від'ємним зворотним зв'язком через високоомний резистор зміщення (10–20 МОм). Щоб коливання в контурі резонатора виникли самочинно після подачі живлення та не зривалися при перепадах температури, активна частина генератора повинна створювати **від'ємний динамічний опір** `R_neg`, модуль якого багаторазово перевищує еквівалентний послідовний опір кварцу (ESR або `R_m`).

Величина від'ємного опору інвертора визначається його крутизною (транспровідністю `g_m`), робочою кутовою частотою `ω = 2 · π · 32768 рад/с` та ємностями навантажувальних конденсаторів `CL1, CL2`:

```
R_neg = - g_m / (ω² · C_L1 · C_L2)
```

Для оцінки стійкості генератора використовують безрозмірний **коефіцієнт запасу збудження** (англ. *Oscillation Safety Factor, SF*):

```
SF = |R_neg| / ESR
```

Для надійного запуску в усьому діапазоні температур від -40 до +85 °C інженерний стандарт вимагає `SF ≥ 5`. Якщо коефіцієнт менший за 5, генератор може не запуститися на морозі або зупинитися від механічного струсу.

Розрахуємо коефіцієнт запасу для годинникового кварцу з `ESR = 60 кОм`, `C_L1 = C_L2 = 15 пФ` та налаштуванням крутизни інвертора `g_m = 25 мкСм` (Medium-Low Drive):

```
ω = 2 · π · 32768
≈ 205887 рад/с                          [кругова частота генерації]

ω² = (205887)² ≈ 4.239·10¹⁰ рад²/с²     [квадрат кругової частоти]

C_prod = C_L1 · C_L2
= (15·10⁻¹² Ф) · (15·10⁻¹² Ф) = 2.25·10⁻²² Ф² [добуток навантажувальних ємностей]

Denominator = ω² · C_prod
= 4.239·10¹⁰ · 2.25·10⁻²² ≈ 9.538·10⁻¹² [знаменник формули від'ємного опору]

|R_neg| = g_m / Denominator
= (25·10⁻⁶ См) / (9.538·10⁻¹²)
≈ 2621000 Ом ≈ 2.62 МОм                 [модуль створеного від'ємного опору]

SF = |R_neg| / ESR
= 2621000 Ом / 60000 Ом
≈ 43.7                                   [коефіцієнт запасу: 43.7 >> 5, відмінний запас]
```

Однак надмірне збільшення `g_m` (перехід у режим High Drive з `g_m = 50..80 мкСм`) небезпечне: воно збільшує потужність збудження кварцу (Drive Level). Якщо розсіювана на кварці потужність перевищить паспортний ліміт `P_drive_max = 0.5..1.0 мкВт`, тонкі камертонні зубці резонатора зазнають механічного перенапруження, що спричинить розтріскування п'єзокристала та незворотний дрейф частоти.

Крім електричної ізоляції, реалізовано апаратний захист від випадкового спотворення даних — прапорець заборони запису `DBP` (англ. *Disable Backup Domain Protection*). Після будь-якого перезавантаження мікроконтролера доступ на запис до регістрів RTC і Backup SRAM блокується апаратним замком. Прошивка повинна явно виконати послідовність запису в регістр керування підсистеми живлення `PWR->CR`, перш ніж зможе змінити хоча б один біт у резервній пам'яті. Це виключає псування калібрувань годинника перехідними процесами під час коливань живлення на старті процесора.

> 🔧 **Навіщо це.** Без ізоляційних комірок на кристалі занулення шини `VDD` під час вимкнення приладу перетворює захисні діоди шинних буферів на шляхи паразитних витоків. Струм батареї `VBAT` починає через внутрішні вузли стікати на шину `VDD`, намагаючись заживити знеструмлене процесорне ядро. Резервна батарейка в такому стані сідає за лічені години.

### Внутрішній апаратний комутатор живлення

Перемикання живлення між основною шиною `VDD` та резервною батареєю `VBAT` не можна виконати звичайною діодною схемою монтажного «АБО» (Diode-OR) на діодах Шотткі. Пряме падіння напруги на діоді Шотткі становить 0.3–0.5 В. Для літієвого елемента з початковою напругою 3.0 В втрата 0.4 В означає, що корисний робочий діапазон батареї скорочується майже наполовину, оскільки нижній поріг роботи генератора LSE та лічильників RTC становить близько 1.8–2.0 В. Крім того, зворотний струм витоку діодів Шотткі при підвищеній температурі (70–85 °C) сягає десятків мікроампер, що категорично неприпустимо для неперезаряджуваних літієвих елементів.

Тому всередині кремнію реалізують активний напівпровідниковий комутатор живлення (англ. *Power Switch*), побудований на низьковольтних P-канальних польових транзисторах із динамічним керуванням підкладкою.

![Топологія комутатора живлення](/root/hw/hw-components/backup-power-domain/img/power-switch-transistor-topology.svg)
*Топологія внутрішнього комутатора живлення: зустрічно-увімкнені пари P-MOSFET із перемиканням підкладки (Body Switching) для повного блокування зворотних паразитних діодів.*

Головний схемотехнічний виклик у MOSFET-комутаторі — це наявність внутрішнього паразитного діода підкладки (англ. *Body Diode*), утвореного p-n переходом між областю стоку та n-кишенею підкладки. Якщо використати одиночний P-MOSFET, то при напрузі `VDD = 3.3 В` та напрузі свіжої батареї `VBAT = 3.0 В` паразитний діод транзистора батарейної гілки зміститься у прямому напрямку, і струм від основного живлення потече всередину батарейки.

Для ліквідації цього шляху витоку в комутаторі застосовують зустрічно-послідовне увімкнення пар P-MOSFET (англ. *Back-to-Back topology*) або схему активного комутатора підкладки (англ. *Dynamic Body Biasing / Body Switch*). Логіка керування підкладкою підключає n-кишеню кристала до того з двох виводів (`VDD` чи `VBAT`), на якому в поточний момент діє найвищий потенціал. Завдяки цьому паразитні діоди завжди залишаються замкненими у зворотному напрямку, виключаючи будь-який зворотний перетік струму з шини `VDD` в батарею або навпаки.

Керування комутацією здійснює прецизійний компаратор напруги з вбудованим гістерезисом `ΔV_hyst ≈ 50..100 мВ`:

- **Режим роботи від VDD:** Коли напруга `VDD` перевищує поріг внутрішнього детектора живлення `V_POR` (Power-On Reset) або `V_PVD` (Power Voltage Detector), що зазвичай становить 1.8–2.1 В, комутатор замикає гілку `VDD` і повністю розмикає гілку `VBAT`. Резервний домен споживає струм від стабілізатора плати, а споживання від батареї падає до струму закритого каналу — менше ніж 10 нА.
- **Перехід на VBAT:** Коли напруга `VDD` спадає нижче порогового значення `V_SW_TH`, компаратор перемикає логічні стани. Щоб запобігти короткочасному паралельному замиканню обох джерел, блок керування затворами реалізує неперекривну часову паузу (англ. *Break-Before-Make*, `t_dead ≈ 15..30 нс`).
- **Безперервність напруги V_BACKUP:** Під час паузи перемикання `t_dead` внутрішня шина резервного домену живиться винятково енергією, накопиченою в розподіленій ємності затворів і внутрішніх блокувальних конденсаторів домену (близько 50–200 пФ). Оскільки струм домену не перевищує кількох сотень наноампер, напруга на шині за 30 наносекунд встигає просісти лише на мікровольти:

```
ΔV = (I_BACKUP · t_dead) / C_INT
= (500·10⁻⁹ А · 30·10⁻⁹ с) / (100·10⁻¹² Ф)   [закон розряду ємності постійним струмом]
= (1.5·10⁻¹⁴) / (10⁻¹⁰)
= 0.00015 В = 0.15 мВ                      [падіння напруги на внутрішній шині]
```

![Перехідний процес комутатора живлення](/root/hw/hw-components/backup-power-domain/img/vbat-switching-waveforms.svg)
*Осцилограми безрозривного перемикання: спад напруги VDD, спрацьовування порогу комутації, утримання напруги V_BACKUP на рівні батареї та неперервна генерація LSE без жодного пропущеного такту.*

Якщо основне живлення зникає плавно (наприклад, повільний саморозряд електролітичних конденсаторів мережевого джерела протягом кількох секунд), напруга `VDD` може тривалий час дрейфувати біля порогу спрацьовування. Наявність аналогового гістерезису запобігає «дребезгу» комутатора (безперервному хаотичному перемиканню туди-назад на частотах у сотні кілогерц), що могло б спричинити генерацію імпульсних завад і збій лічильників RTC.

### Порівняння джерел резервної енергії: CR2032 та суперконденсатори

Вибір джерела для виводу `VBAT` визначається балансом між планованим строком автономності пристрою в знеструмленому стані, діапазоном робочих температур, габаритами та необхідністю періодичного обслуговування.

```
+───────────────────────────+───────────────────────+───────────────────────────+
| Параметр                  | Батарея CR2032        | Іоністор (Supercap 0.47 Ф)|
+───────────────────────────+───────────────────────+───────────────────────────+
| Хімічна система           | Літій-діоксид марганцю| Електричний подвійний шар |
| Номінальна напруга        | 3.0 В                 | 2.7 В..5.5 В              |
| Робочий запас енергії     | ~220 мА·год (700 Дж)  | ~0.47 Ф (1.5 Дж при 3.0 В)|
| Власний струм саморозряду | < 1% на рік (при 25°C)| 0.5..3.0 мкА (постійно)   |
| Автономність RTC (<1 мкА) | 10..15 років          | 3..7 діб                  |
| Кількість циклів зарядки  | 1 (первинний елемент) | > 500 000 циклів          |
| Підзарядка на платі       | СУВОРО ЗАБОРОНЕНО     | Потребує Trickle Charge   |
| Діапазон температур       | -20..+70 °C           | -40..+85 °C               |
+───────────────────────────+───────────────────────+───────────────────────────+
```

#### Літієвий дисковий елемент CR2032

Елемент CR2032 базується на хімічній парі літій — діоксид марганцю (Li/MnO₂). Свіжа батарея має напругу розімкненого кола близько 3.2–3.3 В. Її ключова перевага — надзвичайно полога крива розряду: при мікроамперних струмах напруга тримається в діапазоні 2.9–2.8 В упродовж понад 90% часу життя, після чого починається лавинний спад до порогу відсічки 2.0 В.

Надзвичайно низький саморозряд (менше ніж 1% на рік за кімнатної температури) забезпечується утворенням мікроскопічної захисної плівки пасивації (Li₂O та органічні комплекси) на поверхні металевого літієвого анода. Ця плівка практично блокує паразитну взаємодію між літієм та рідким електролітом під час простою. Проте підвищення температури експлуатації до +60..+70 °C різко активує дифузійні процеси, збільшуючи темп саморозряду до 3–5% на рік згідно із законом Арреніуса.

**Вимога безпеки (UL 1642):** Первинні літієві елементи категорично заборонено піддавати будь-якому зарядному струму. Якщо напруга `VDD` просочиться у батарею через дефект плати чи пробій комутатора, це призведе до відновлення кристалічного металевого літію на катоді у вигляді мікронних голок — дендритів. Дендрити проростають крізь пористий поліпропіленовий сепаратор, створюючи внутрішнє коротке замикання з подальшим розігрівом, газовиділенням, розгерметизацією корпусу та займанням.

Стандарт безпеки UL 1642 вимагає, щоб струм зворотного заряджання в несправному стані не перевищував 1 мкА. Для виконання цієї норми виробники мікроконтролерів сертифікують надійність ізоляції внутрішнього Power Switch, а на платі послідовно з батареєю встановлюють додатковий обмежувальний резистор опором 1 кОм.

#### Іоністори (суперконденсатори) та крапельна підзарядка

Іоністор (англ. *Electric Double-Layer Capacitor, EDLC*) накопичує енергію за рахунок електростатичного розділення зарядів на межі між високопористим активованим вугіллям та іонним рідким електролітом. Завдяки площі поверхні до 2000 м²/г ємність мініатюрних монетних іоністорів діаметром 6–12 мм становить від 0.1 до 1.5 Ф.

Головна перевага іоністора — необмежений ресурс перезаряджання (> 500 000 циклів) та здатність працювати при температурах до -40 °C, де рідкий електроліт звичайних хімічних батарей замерзає. Проте енергоємність іоністора непорівнянно нижча за батарейну, а спад напруги відбувається за експонентою `V(t) = V_0 · e^(-t / RC)`.

![Порівняння профілів розряду](/root/hw/hw-components/backup-power-domain/img/supercap-vs-cr2032-discharge.svg)
*Порівняння кривих розряду: стійке хімічне плато CR2032, розраховане на 10–15 років, проти швидкого експоненційного спаду іоністора 0.47 Ф на часовому горизонті кількох діб.*

Щоб іоністор залишався зарядженим під час штатної роботи системи від `VDD`, сучасні мікроконтролери мають вбудований модуль **крапельної підзарядки** (англ. *Trickle Charger*). Цей вузол складається з внутрішнього комутаційного P-MOSFET, послідовного струмообмежувального резистора з вибором номіналу (1.5 кОм або 5 кОм) та послідовного захисного діода.

Підзарядка активується програмно встановленням спеціальної бітової комбінації у регістрі керування (наприклад, у STM32 записом біта `TCHEN` та маски `TCR[3:0] = 0b1010` у регістрі `PWR_CR3`). Захисний механізм захищений ключовим кодом: випадковий збійний запис одного біта не може ненароком увімкнути підзарядку, якщо замість іоністора встановлено батарейку CR2032.

Час заряду іоністора ємністю `C = 0.47 Ф` від 0 до 95% номінальної напруги `VDD = 3.3 В` через внутрішній резистор `R = 1.5 кОм` розраховується через сталу часу `τ`:

```
τ = R · C
= 1500 Ом · 0.47 Ф = 705 с ≈ 11.75 хв   [стала часу RC-ланцюга заряду]

t_95% = 3 · τ
= 3 · 705 с = 2115 с ≈ 35.25 хв         [час досягнення 95% заряду]

t_99% = 5 · τ
= 5 · 705 с = 3525 с ≈ 58.75 хв         [повний час завершення підзарядки]
```

### Бюджет струмів витоку та інженерний розрахунок автономності

Сумарний струм, що споживається від виводу `VBAT` у знеструмленому стані приладу, складається з кількох незалежних фізичних складових:

```
I_VBAT_TOTAL = I_LSE + I_RTC + I_BKP_SRAM + I_PCB_LEAK + I_SELF_DISCHARGE
```

Розглянемо внесок кожного компонента за нормальної (+25 °C) та підвищеної (+70 °C) температури:

1. **Струм генератора LSE (`I_LSE`):** Складається з постійного струму зміщення інвертора П'єрса та динамічного струму перезаряджання навантажувальних конденсаторів `CL1, CL2`. Залежить від налаштування параметра крутизни (Drive Capability):
   - Low Drive (для кварців з `C_L = 6 пФ`): `I_LSE ≈ 120..180 нА`.
   - High Drive (для кварців з `C_L = 12.5 пФ` або в умовах високих вібрацій): `I_LSE ≈ 350..500 нА`.
2. **Струм ядра RTC (`I_RTC`):** Динамічне перемикання 22 тригерів дільника частоти та BCD-регістрів на частоті 32.768 кГц. Становить 80–150 нА.
3. **Струм утримання Backup SRAM (`I_BKP_SRAM`):** Струм підпорогового витоку (Subthreshold Leakage) закритих транзисторів 6T SRAM-комірок. За температури +25 °C для блоку 4 КБ він не перевищує 150–250 нА. Однак підпороговий витік кремнієвих переходів зростає експоненційно з температурою, подвоюючись кожні 8–10 °C. За температури +70 °C витік Backup SRAM зростає до 2.5–4.5 мкА, стаючи домінуючою статтею витрат енергії.
4. **Струм поверхневого витоку по друкованій платі (`I_PCB_LEAK`):** Струми розтікання між контактними майданчиками піна `VBAT`, доріжками кварцу та сусідніми шинами через мікроскопічні залишки флюсу, конденсат та атмосферний пил. На неякісно відмитій платі в умовах вологості 80% витік легко сягає 1–5 мкА.

#### Розрахунок 1: Автономність від батареї CR2032

Візьмемо типову батарею CR2032 з номінальною ємністю `C_nom = 225 мА·год`. Припустимо, що система експлуатується при середній температурі +25 °C, використовує кварц із Low Drive (`I_LSE = 150 нА`), RTC увімкнено (`I_RTC = 100 нА`), Backup SRAM задіяна (`I_BKP = 200 нА`), плата ретельно відмита й покрита лаком (`I_PCB = 50 нА`).

```
I_TOTAL = I_LSE + I_RTC + I_BKP + I_PCB
= 150 нА + 100 нА + 200 нА + 50 нА
= 500 нА = 0.0005 мА                     [сумарний струм споживання від VBAT]

t_ideal = C_nom / I_TOTAL
= 225 мА·год / 0.0005 мА
= 450000 год                             [теоретичний час розряду]

t_years_ideal = 450000 / (24 · 365.25)
= 450000 / 8766 ≈ 51.3 року              [ідеальний термін без урахування саморозряду]
```

Зрозуміло, що 51 рік — це математична абстракція. Реальний термін служби батареї обмежений її власним хімічним саморозрядом (близько 1% на рік) та висиханням органічного електроліту крізь полімерний ущільнювальний ізолятор корпусу.

Врахуємо внутрішній річний саморозряд елемента:

```
C_self_year = C_nom · 0.01
= 225 мА·год · 0.01 = 2.25 мА·год/рік    [втрата ємності на саморозряд за рік]

I_self_equiv = 2.25 мА·год / 8766 год
= 0.000256 мА = 256 нА                  [еквівалентний постійний струм саморозряду]

I_REAL = I_TOTAL + I_self_equiv
= 500 нА + 256 нА = 756 нА = 0.000756 мА [реальне річне навантаження на елемент]

t_years_real = 225 мА·год / (0.000756 мА · 8766 год/рік)
= 225 / 6.627 ≈ 33.9 року               [розрахунковий час до хімічної деградації]
```

На практиці максимальний гарантований виробниками строк служби CR2032 становить **10–12 років**, оскільки за цей час відбувається незворотна деградація ущільнювача і втрата рідкої фази електроліту. Тим не менш, розрахунок показує: струм схеми 500 нА є настільки малим, що батарея встигає швидше зістаритися природним шляхом, ніж розрядитися від навантаження.

#### Розрахунок 2: Автономність від іоністора 0.47 Ф

Нехай замість батареї встановлено суперконденсатор ємністю `C = 0.47 Ф`, заряджений до робочої напруги `V_0 = 3.2 В` (напруга `VDD = 3.3 В` мінус пряме падіння на зарядному діоді 0.1 В). Нижня порогова напруга, за якої зупиняється генератор LSE або скидаються регістри, дорівнює `V_min = 2.0 В`.

Власний струм витоку якісного іоністора становить близько `I_leak_sc = 1.0 мкА`. Сумарний струм навантаження від мікроконтролера за температури 25 °C дорівнює `I_MCU = 0.5 мкА`.

```
I_DISCHARGE = I_leak_sc + I_MCU
= 1.0 мкА + 0.5 мкА = 1.5 мкА = 1.5·10⁻⁶ А [повний струм розряду ємності]

ΔV_usable = V_0 - V_min
= 3.2 В - 2.0 В = 1.2 В                  [корисний перепад напруги]

ΔQ_usable = C · ΔV_usable
= 0.47 Ф · 1.2 В = 0.564 Кл              [корисний електричний заряд]

t_seconds = ΔQ_usable / I_DISCHARGE
= 0.564 Кл / (1.5·10⁻⁶ А)
= 376000 с                               [час автономності в секундах]

t_hours = 376000 / 3600 ≈ 104.4 год      [автономність у годинах]
t_days = 104.4 / 24 ≈ 4.35 доби          [автономність у добах]
```

Іоністор ємністю 0.47 Ф забезпечує безперервний хід годинника протягом **4 діб і 8 годин**. Цього повністю вистачає для транспортування приладу між об'єктами, планового перепідключення мережі живлення або заміни основного акумулятора без втрати системного часу.

### Принципова схемотехніка та трасування PCB вузла VBAT

Надійна робота резервного домену на тривалих інтервалах часу вимагає жорсткого дотримання правил схемотехнічного обв'язування та топології друкованої плати.

![Принципова схема вузла VBAT](/root/hw/hw-components/backup-power-domain/img/vbat-complete-schematic.svg)
*Принципова електрична схема вузла VBAT: захисний резистор R1 (UL 1642), блокувальна кераміка C1, охоронне кільце GND навколо резонатора LSE та внутрішній дільник АЦП.*

#### Схемотехнічні вимоги

1. **Блокувальний конденсатор `C1`:** Безпосередньо біля виводу `VBAT` мікроконтролера обов'язково встановлюють високоякісний керамічний конденсатор ємністю 100 нФ (діелектрик X7R або X5R, типорозмір 0402 або 0603). Його призначення — замикати на землю високочастотні імпульсні наведення від сусідніх цифрових ліній та забезпечувати миттєву віддачу струму під час мікросекундного перемикання внутрішнього Power Switch.
2. **Захисний резистор `R1` (1 кОм):** Встановлюється послідовно між плюсовим контактом батарейного тримача CR2032 та конденсатором `C1`. При падінні на ньому струму навантаження 1 мкА падіння напруги становить лише `ΔV = 1 кОм · 1 мкА = 1 мВ`, що абсолютно непомітно для схеми. Але у випадку аварійного пробою кристала або замикання піна `VBAT` на шину 3.3 В резистор обмежить струм заряджання батареї безпечною величиною `I_charge_max = 3.3 В / 1000 Ом = 3.3 мА`, запобігши тепловому розгону літію.
3. **Навантажувальні конденсатори кварцу `CL1`, `CL2`:** Розраховуються за формулою еквівалентної ємності послідовного з'єднання з урахуванням паразитної ємності друкованих провідників та виводів корпусу MCU (`C_stray ≈ 2..4 пФ`):

```
C_L = (C_L1 · C_L2) / (C_L1 + C_L2) + C_stray

При виборі C_L1 = C_L2 = C_ext:
C_L = (C_ext / 2) + C_stray
C_ext = 2 · (C_L - C_stray)             [формула розрахунку зовнішніх конденсаторів]
```

Для кварцу з паспортною навантажувальною ємністю `C_L = 9 пФ` та паразитною ємністю плати `C_stray = 3 пФ`:

```
C_ext = 2 · (9 пФ - 3 пФ)
= 2 · 6 пФ = 12 пФ                       [номінал для конденсаторів CL1 та CL2]
```

Конденсатори повинні мати діелектрик класу NP0 (C0G) з допуском ±5%, що забезпечує стабільність ємності в усьому температурному діапазоні.

#### Топологічні вимоги трасування (PCB Layout)

- **Охоронне кільце (GND Guard Ring):** Виводи `OSC32_IN` та `OSC32_OUT` разом із корпусом кварцового резонатора та конденсаторами `CL1`, `CL2` обводять суцільною замкненою доріжкою землі на верхньому шарі плати. Це охоронне кільце з'єднується з внутрішнім полігоном цифрової землі тільки в **одній точці** біля земляного виводу мікроконтролера. Охоронне кільце екранує високоомний вхід підсилювача від паразитних ємнісних наведень (Cross-talk) із сусідніх швидкісних шин SPI/UART.
- **Заборона трасування під кварцом:** Під площею кварцового генератора та його конденсаторів на всіх проміжних шарах багатошарової друкованої плати суворо заборонено прокладати будь-які сигнальні та силові провідники (особливо імпульсні лінії DC-DC перетворювачів, тактові лінії ШІМ та шини даних). Під кварцом має бути суцільний екран заливки Ground Plane.
- **Довжина доріжок:** Відстань від виводів кварцу до пінів MCU має бути мінімальною (не більше 3–5 мм). Будь-яке подовження доріжок збільшує паразитну антену, що ловить радіозавади та призводить до зриву генерації чи спотворення ходу годинника.
- **Хімічна чистота та лакування:** Опір витоку між провідниками на платі при наявності мікроскопічних залишків активованого безвідмивного флюсу падає до одиниць мегомів. За напруги 3 В опір 3 МОм створює паразитний струм 1 мкА, подвоюючи навантаження на батарею. Плати з вузлами `VBAT` вимагають ультразвукового відмивання в деіонізованій воді зі спиртом та обов'язкового покриття вологозахисним поліуретановим або силіконовим лаком (Conformal Coating).

### Апаратний захист Tamper та фіксація міток подій

У критичних застосунках (банківські POS-термінали, тахографи, криптографічні модулі) домен `VBAT` виконує функцію апаратного сейфа безпеки. Оскільки криптографічні ключі AES та приватні сертифікати зберігаються в Backup SRAM, мікроконтролер повинен гарантувати їх миттєве фізичне знищення при спробі розкриття корпусу приладу, навіть якщо основне живлення `VDD` повністю вимкнене.

Модуль Tamper підтримує два режими захисту:

1. **Пасивний Tamper (Passive Edge/Level Detection):** Зовнішній контакт (мікроперемикач, оптичний датчик розтину або магнітний геркон) підключається до виводу `TAMP_IN`. Будь-яка зміна логічного рівня ініціює апаратну подію тривоги.
2. **Активний динамічний Tamper (Active Shield):** Запобігає обходу захисту шляхом примусового підтягування лінії до фіксованого потенціалу дротяною перемичкою. Мікроконтролер генерує на виводі `TAMP_OUT` псевдовипадкову послідовність імпульсів, тактовану від LSE, яка проходить крізь захисну змійку провідників на корпусі та повертається на вхід `TAMP_IN`. Якщо зловмисник закоротить лінію на землю або переріже шлейф, апаратний компаратор зафіксує невідповідність бітів протягом одного такту LSE (30.5 мкс).

При виникненні події тривоги домен `VBAT` виконує дві апаратні дії без участі ядра процесора:
- **Миттєве стирання (Zeroization):** Апаратний ключ скидання підключає всі комірки Backup SRAM та резервних регістрів BKP до землі, занулюючи всі дані за 15–20 нс.
- **Фіксація мітки часу (Timestamping):** Поточний стан двійково-десяткових лічильників RTC миттєво копіюється в тіньові регістри `RTC_TSTR` та `RTC_TSDR`, фіксуючи точну секунду, хвилину, годину та дату інциденту.

### Програмна діагностика та моніторинг напруги батареї

#### Алгоритм детектування «холодного старту» (Cold Boot)

Під час кожного запуску процесорного ядра прошивка повинна надійно розрізняти два принципово різні сценарії старту:
- **Теплий старт (Warm Boot):** Перезапуск ядра кнопкою Reset, вихід із глибокого сну Standby або відновлення після зникнення `VDD`, коли батарея `VBAT` успішно утримала живлення домену. У цьому випадку годинник RTC іде безперервно, його повторна ініціалізація суворо заборонена, а дані в Backup SRAM є дійсними.
- **Холодний старт (Cold Boot):** Перше ввімкнення новозібраної плати на виробництві або запуск після повної втрати живлення `VBAT` (глибокий розряд батареї). У цьому стані лічильники часу містять випадкове сміття, а дані пам'яті спотворені.

Для розрізнення цих станів у перший резервний регістр `BKP_DR0` записують фіксовану сигнатуру — «магічне число» (Magic Word, наприклад `0xA5A5C0DE`), а блок налаштувань у Backup SRAM захищають контрольною сумою CRC16. При старті прошивка перевіряє сигнатуру: якщо магічне число відсутнє, виконується початкове встановлення часу за замовчуванням, форматування Backup SRAM та запис нової сигнатури.

#### Вимірювання напруги батареї через керований міст

Для попередження оператора про необхідність заміни батарейки CR2032 мікроконтролер повинен періодично вимірювати напругу на піні `VBAT`.

Тут виникає інженерна пастка: якщо підключити пін `VBAT` до звичайного вхідного каналу аналого-цифрового перетворювача (АЦП) через резистивний дільник напруги з номіналами 2 × 500 кОм, то через цей дільник постійно тектиме струм:

```
I_divider = V_BAT / (R1 + R2)
= 3.0 В / (500000 Ом + 500000 Ом)
= 3.0 В / 1000000 Ом = 3.0 мкА          [постійне паразитне споживання]
```

Струм 3 мкА утричі перевищує споживання всього домену RTC і висадить батарейку CR2032 за 5–7 років замість 15.

Виробники мікроконтролерів вирішують цю проблему шляхом інтеграції **керованого внутрішнього моста вимірювання** (англ. *Switched VBAT ADC Bridge*). Вхід виводу `VBAT` підключається до внутрішнього резистивного дільника (із коефіцієнтом ділення 1/3 або 1/4) тільки через аналоговий ключ на базі польового транзистора. У вимкненому стані ключ повністю розімкнений, і струм витоку через міст становить менше 1 нА.

Програма вмикає аналоговий ключ (бітом `VBATEN` у конфігураційних регістрах АЦП чи блоку `PWR`) лише на кілька мікросекунд безпосередньо перед запуском перетворення АЦП, зчитує результат і негайно вимикає міст. Вимірювання достатньо виконувати раз на добу або під час старту пристрою.

Нижче наведено професійну реалізацію діагностики стану батареї `VBAT` та ініціалізації домену для сімейства STM32, виконану мовами C (HAL/LL) та сучасним ідіоматичним C++20.

```c
#include "stm32f4xx_hal.h"
#include <stdint.h>
#include <stdbool.h>

// Граничні пороги напруги елемента CR2032 (у мілівольтах)
#define VBAT_MV_GOOD         2800U   // Батарея повністю заряджена (> 2.8 В)
#define VBAT_MV_WARNING      2400U   // Попередження про знос (2.4..2.8 В)
#define VBAT_MV_CRITICAL     2100U   // Критичний розряд (< 2.4 В, необхідна заміна)
#define VBAT_DIVIDER_COEFF   4U      // Внутрішній апаратний подільник STM32F4 (1/4)

typedef enum {
    BATTERY_STATUS_OK = 0,
    BATTERY_STATUS_LOW,
    BATTERY_STATUS_CRITICAL,
    BATTERY_STATUS_ERROR
} battery_status_t;

typedef struct {
    uint32_t voltage_mv;
    battery_status_t status;
} vbat_report_t;

extern ADC_HandleTypeDef hadc1;

/**
 * @brief  Виконати безпечне вимірювання напруги на виводі VBAT.
 * @note   Аналоговий міст вмикається лише на час перетворення АЦП.
 */
vbat_report_t vbat_measure_voltage(void)
{
    vbat_report_t report = { .voltage_mv = 0, .status = BATTERY_STATUS_ERROR };
    ADC_ChannelConfTypeDef sConfig = {0};

    // 1. Увімкнення тактування модуля керування живленням та АЦП
    __HAL_RCC_PWR_CLK_ENABLE();
    
    // 2. Активація внутрішнього аналогового моста дільника VBAT
    // Встановлення біта VBATE у регістрі ADC->CCR
    ADC->CCR |= ADC_CCR_VBATE;

    // 3. Конфігурація каналу АЦП для вимірювання VBAT (ADC1_IN18 для STM32F4)
    sConfig.Channel      = ADC_CHANNEL_VBAT;
    sConfig.Rank         = 1;
    sConfig.SamplingTime = ADC_SAMPLETIME_480CYCLES; // Максимальний час вибірки для високоомного дільника

    if (HAL_ADC_ConfigChannel(&hadc1, &sConfig) != HAL_OK) {
        ADC->CCR &= ~ADC_CCR_VBATE; // Вимикаємо міст при помилці
        return report;
    }

    // 4. Запуск перетворення
    if (HAL_ADC_Start(&hadc1) == HAL_OK) {
        if (HAL_ADC_PollForConversion(&hadc1, 10) == HAL_OK) {
            uint32_t raw_adc = HAL_ADC_GetValue(&hadc1);
            
            // Розрахунок напруги: V_vbat = (raw / 4095) * Vdda * 4
            // Використовуємо цілочисельну арифметику у мілівольтах (припускаємо Vdda = 3300 мВ)
            uint32_t vdda_mv = 3300U;
            report.voltage_mv = (raw_adc * vdda_mv * VBAT_DIVIDER_COEFF) / 4095U;

            // 5. Класифікація стану батареї
            if (report.voltage_mv >= VBAT_MV_GOOD) {
                report.status = BATTERY_STATUS_OK;
            } else if (report.voltage_mv >= VBAT_MV_WARNING) {
                report.status = BATTERY_STATUS_LOW;
            } else {
                report.status = BATTERY_STATUS_CRITICAL;
            }
        }
        HAL_ADC_Stop(&hadc1);
    }

    // 6. ОБОВ'ЯЗКОВО: Вимикаємо вимірювальний міст для зупинки витоку струму!
    ADC->CCR &= ~ADC_CCR_VBATE;

    return report;
}
```

```cpp
#include <cstdint>
#include <expected>
#include <span>
#include <concepts>
#include "stm32f4xx_hal.h"

namespace vbat {

enum class BatteryState : uint8_t {
    Good,       // Напруга > 2.8 В, ресурс достатній
    Degraded,   // Напруга 2.4..2.8 В, планова заміна
    Critical,   // Напруга < 2.4 В, загроза втрати даних RTC
    Invalid     // Помилка апаратного вимірювання
};

enum class DriverError : uint8_t {
    AdcConfigFailed,
    ConversionTimeout,
    CalibrationFailed
};

struct DiagnosticReport {
    uint32_t voltage_mv;
    BatteryState state;

    [[nodiscard]] constexpr bool is_safe() const noexcept {
        return state == BatteryState::Good;
    }
};

/**
 * @brief RAII-обгортка для гарантованого відключення вимірювального моста VBAT.
 * Запобігає неперервному витоку струму через мікроконтролерний дільник АЦП.
 */
class VbatBridgeGuard {
public:
    explicit VbatBridgeGuard(ADC_Common_TypeDef* common_regs) noexcept 
        : common_(common_regs) 
    {
        __HAL_RCC_PWR_CLK_ENABLE();
        common_->CCR |= ADC_CCR_VBATE; // Замикаємо міст дільника
    }

    ~VbatBridgeGuard() noexcept {
        common_->CCR &= ~ADC_CCR_VBATE; // Гарантовано розмикаємо міст при виході з області видимості
    }

    VbatBridgeGuard(const VbatBridgeGuard&) = delete;
    VbatBridgeGuard& operator=(const VbatBridgeGuard&) = delete;
    VbatBridgeGuard(VbatBridgeGuard&&) = delete;
    VbatBridgeGuard& operator=(VbatBridgeGuard&&) = delete;

private:
    ADC_Common_TypeDef* common_;
};

class BatteryMonitor {
public:
    static constexpr uint32_t ThresholdGoodMv     = 2800;
    static constexpr uint32_t ThresholdWarningMv  = 2400;
    static constexpr uint32_t DividerRatio        = 4;     // Дільник 1/4
    static constexpr uint32_t AdcMaxCounts        = 4095;  // 12-бітний АЦП

    explicit BatteryMonitor(ADC_HandleTypeDef& adc_handle) noexcept 
        : adc_handle_(adc_handle) {}

    [[nodiscard]] std::expected<DiagnosticReport, DriverError> sample(uint32_t vdda_mv = 3300) noexcept {
        // Застосовуємо RAII guard: міст буде відключено автоматично при будь-якому поверненні
        VbatBridgeGuard bridge_guard(ADC);

        ADC_ChannelConfTypeDef config{};
        config.Channel      = ADC_CHANNEL_VBAT;
        config.Rank         = 1;
        config.SamplingTime = ADC_SAMPLETIME_480CYCLES;

        if (HAL_ADC_ConfigChannel(&adc_handle_, &config) != HAL_OK) {
            return std::unexpected(DriverError::AdcConfigFailed);
        }

        if (HAL_ADC_Start(&adc_handle_) != HAL_OK) {
            return std::unexpected(DriverError::AdcConfigFailed);
        }

        if (HAL_ADC_PollForConversion(&adc_handle_, 10) != HAL_OK) {
            HAL_ADC_Stop(&adc_handle_);
            return std::unexpected(DriverError::ConversionTimeout);
        }

        const uint32_t raw = HAL_ADC_GetValue(&adc_handle_);
        HAL_ADC_Stop(&adc_handle_);

        const uint32_t measured_mv = (raw * vdda_mv * DividerRatio) / AdcMaxCounts;
        const BatteryState state   = evaluate_state(measured_mv);

        return DiagnosticReport{ .voltage_mv = measured_mv, .state = state };
    }

private:
    ADC_HandleTypeDef& adc_handle_;

    [[nodiscard]] static constexpr BatteryState evaluate_state(uint32_t mv) noexcept {
        if (mv >= ThresholdGoodMv) {
            return BatteryState::Good;
        }
        if (mv >= ThresholdWarningMv) {
            return BatteryState::Degraded;
        }
        return BatteryState::Critical;
    }
};

} // namespace vbat
```

> 🔧 **Навіщо це.** Якщо під час написання драйвера забути скинути біт `ADC_CCR_VBATE` після завершення вимірювання, вимірювальний міст залишиться підключеним до піна `VBAT`. Батарейка почне безперервно розряджатися через резистори дільника струмом у кілька мікроампер. Застосування RAII-патерну `VbatBridgeGuard` у C++ гарантує відключення моста незалежно від помилок виконання або дострокового повернення з функції.
