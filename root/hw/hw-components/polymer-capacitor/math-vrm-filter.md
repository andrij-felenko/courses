# 🧮 Математичний розрахунок вихідного фільтра VRM та цільового імпедансу PDN

Математичний апарат розрахунку перехідних процесів у колах живлення процесорів та імпульсних стабілізаторах доводить, чому величина еквівалентного послідовного опору ESR та індуктивності ESL полімерних конденсаторів визначає стабільність вихідної напруги під час динамічних стрибків струму навантаження.

## Концепція цільового імпедансу шини живлення (Target Impedance)

У сучасних обчислювальних системах (центральні процесори, графічні прискорювачі, FPGA) струм споживання ядра змінюється стрибкоподібно між режимами сну (Idle) та максимального навантаження (Turbo Boost). Швидкість наростання струму `di/dt` сягає десятків амперів за наносекунду, тоді як відхилення напруги живлення ядра `V_core` не повинно виходити за межі вузького допуску (зазвичай ±3...5% від номіналу 0.8–1.2 В).

Для забезпечення цієї вимоги в усьому діапазоні робочих частот (від постійного струму до гігагерців) імпеданс мережі розподілу живлення PDN (*Power Distribution Network*) повинен бути меншим або дорівнювати **цільовому імпедансу** `Z_target`:

```
Z_target = ΔV_allowed / ΔI_step
```

де:
- `ΔV_allowed` — максимально допустиме відхилення напруги (розмах просідання або викиду, В);
- `ΔI_step` — максимальний стрибок струму споживання (А).

### Розрахунок Z_target для процесорної шини 1.0 В

Розглянемо типовий вузол живлення процесора з напругою `V_nom = 1.0 В`, де максимальний стрибок струму навантаження становить `ΔI_step = 50 А`, а допустиме динамічне просідання напруги обмежене величиною `±30 мВ` (`ΔV_allowed = 0.030 В`):

```
Z_target = 0.030 / 50
         = 0.0006 Ом
         = 0.6 мОм      [максимально допустимий імпеданс шини]
```

Це означає, що на будь-якій частоті в смузі комутації перетворювача та його вихідного фільтра сумарний імпеданс вихідних конденсаторів не повинен перевищувати 0.6 мОм.

## Частотна характеристика вихідного імпедансу та роль власного резонансу

Еквівалентна схема реального конденсатора складається з трьох послідовно з'єднаних елементів: ідеальної ємності `C`, еквівалентного послідовного опору `ESR` та еквівалентної послідовної індуктивності `ESL`.

Комплексний імпеданс конденсатора як функція циклічної частоти `ω = 2π f` має вигляд:

```
Z(f) = ESR + j · (2π · f · ESL − 1 / (2π · f · C))
```

Модуль повного імпедансу визначається формулою:

```
|Z(f)| = √(ESR² + (2π · f · ESL − 1 / (2π · f · C))²)
```

Аналіз цієї функції показує три чіткі частотні області:

1. **Низькочастотна (ємнісна) область (`f << f₀`):**
   Реактивний опір індуктивності мізерний, реактивний опір ємності домінує:
   ```
   |Z(f)| ≈ 1 / (2π · f · C)      [нахил −20 дБ/декаду]
   ```

2. **Область власного послідовного резонансу (`f = f₀`):**
   Ємнісний та індуктивний реактивні опори повністю компенсують один одного:
   ```
   2π · f₀ · ESL = 1 / (2π · f₀ · C)
   ```
   Звідси частота власного резонансу:
   ```
   f₀ = 1 / (2π · √(C · ESL))
   ```
   На цій частоті реактивна складова обнуляється, а модуль імпедансу досягає абсолютного мінімуму, який визначається виключно активним опором:
   ```
   |Z_min| = ESR
   ```

3. **Високочастотна (індуктивна) область (`f >> f₀`):**
   Реактивний опір індуктивності домінує над ємнісним:
   ```
   |Z(f)| ≈ 2π · f · ESL          [нахил +20 дБ/декаду]
   ```

## Нуль передавальної функції, породжений ESR, та фазовий запас петлі регулювання

У силових імпульсних перетворювачах вихідний `LC`-фільтр створює пару комплексно-спряжених полюсів на резонансній частоті:

```
f_LC = 1 / (2π · √(L_out · C_out))
```

Ці полюси спричиняють різкий спад коефіцієнта підсилення розімкненого контуру зі швидкістю −40 дБ/декаду та фазовий зсув на −180°, що загрожує втратою стійкості (самозбудженням перетворювача).

Реальний опір `ESR` вихідного конденсатора вносить у передавальну функцію перетворювача нуль лівої півплощини на частоті:

```
f_z_esr = 1 / (2π · C_out · ESR)
```

Цей нуль змінює нахил частотної характеристики з −40 дБ/декаду на −20 дБ/декаду та додає позитивний фазовий зсув (фазове випередження) до +90° у діапазоні частот вище `f_z_esr`.

### Порівняння частоти нуля для різних типів конденсаторів

Розглянемо вихідний конденсатор номіналом `C_out = 330 мкФ`:

1. **Звичайний алюмінієвий електролітичний (`ESR = 80 мОм`):**
   ```
   f_z_esr = 1 / (2π · 330·10⁻⁶ · 0.080)
           = 1 / (2π · 2.64·10⁻⁵)
           = 6.03 кГц      [нуль розташований надто низько, обмежує смугу регулювання]
   ```

2. **Полімерний алюмінієвий конденсатор SP-Cap (`ESR = 4.5 мОм`):**
   ```
   f_z_esr = 1 / (2π · 330·10⁻⁶ · 0.0045)
           = 1 / (2π · 1.485·10⁻⁶)
           = 107.2 кГц     [ідеальне розташування для розширення смуги до 50–100 кГц]
   ```

3. **Керамічний конденсатор MLCC (`ESR = 1.2 мОм`):**
   ```
   f_z_esr = 1 / (2π · 330·10⁻⁶ · 0.0012)
           = 1 / (2π · 3.96·10⁻⁷)
           = 401.9 кГц     [нуль виходить за смугу одиничного підсилення петлі]
   ```

Полімерний конденсатор завдяки помірному значенню ESR (3–10 мОм) створює нуль компенсації акурат у смузі 50–150 кГц, що дозволяє стабілізувати перетворювач за допомогою простої схеми компенсації Type-II (на 1 операційному підсилювачі з RC-ланкою) замість складної триполюсної Type-III.

### Синтез ланки компенсації Type-II з використанням нуля ESR

Розглянемо класичну схему стабілізатора з широтно-імпульсною модуляцією (ШІМ) на основі підсилювача похибки зі зворотним зв'язком (схема Type-II). Передавальна функція ланки компенсації має вигляд:

```
H_comp(s) = (1 + s · R_f · C_z) / (s · R_in · (C_z + C_p) · (1 + s · R_f · (C_z · C_p / (C_z + C_p))))
```

де `C_z >> C_p`. Ланка формує один інтегруючий полюс на нульовій частоті, один нуль `f_z1` та один високочастотний полюс `f_p2`:

```
f_z1 = 1 / (2π · R_f · C_z)
f_p2 = 1 / (2π · R_f · C_p)
```

Інженерна методика синтезу контуру стабілізації з полімерним конденсатором будується за чотирма строгими кроками:

1. **Вибір частоти зрізу петлі `f_c`:**
   Частоту перетину одиничного підсилення обирають у межах `f_c ≈ (1/10...1/5) · f_sw` (де `f_sw` — тактова частота комутації ключів, наприклад, `f_c = 100 кГц` при `f_sw = 600 кГц`).

2. **Компенсація полюса силового LC-фільтра:**
   Нуль компенсатора `f_z1` налаштовують на частоту подвійного полюса вихідного фільтра `f_LC`:
   ```
   f_z1 = f_LC = 1 / (2π · √(L_out · C_out))
   ```
   Це ліквідує один із двох спадів нахилу та зупиняє просідання фази на рівні −90° замість −180°.

3. **Скасування нуля ESR високочастотним полюсом компенсатора:**
   Нуль `f_z_esr`, породжений полімерним конденсатором, створює додатковий підйом фази +90°, розширюючи смугу пропускання. Щоб придушити комутаційні шуми ШІМ на високих частотах, другий полюс компенсатора `f_p2` налаштовують точно на частоту нуля ESR:
   ```
   f_p2 = f_z_esr = 1 / (2π · C_out · ESR_total)
   ```

4. **Розрахунок запасу фази (Phase Margin, PM):**
   На частоті зрізу `f_c` сумарний фазовий зсув розімкненого контуру становить:
   ```
   PM = 180° − 90° [інтегратор] − arctan(f_c / f_LC) + arctan(f_c / f_z1) + arctan(f_c / f_z_esr) − arctan(f_c / f_p2)
   ```
   Оскільки `f_z1 ≈ f_LC` та `f_p2 ≈ f_z_esr`, взаємна компенсація фазових вкладів дає на частоті зрізу ідеальний запас фази:
   ```
   PM ≈ 180° − 90° = 60°...75°      [гарантія аперіодичного перехідного процесу без перерегулювання]
   ```

Якщо замість полімерного конденсатора встановити кераміку MLCC з `ESR < 1 мОм`, частота `f_z_esr` зміститься вище 400 кГц. Фазове випередження в зоні 100 кГц зникне, запас фази впаде нижче 20–30°, і перетворювач почне генерувати незатухаючі автоколивання або вимагатиме переходу на громіздку схему Type-III з трьома конденсаторами та двома резисторами у зворотному зв'язку.

## Часовий розклад динамічного просідання напруги (Transient Droop)

Коли навантаження миттєво збільшує споживання на величину `ΔI_step` за час наростання `t_rise` зі швидкістю `di/dt = ΔI_step / t_rise`, вихідна напруга зазнає сумарного просідання, яке складається з трьох послідовних фізичних компонентів:

```
ΔV_total(t) = ΔV_esl(t) + ΔV_esr(t) + ΔV_cap(t)
```

1. **Індуктивний сплеск напруги (`ΔV_esl`):**
   Виникає миттєво під час зміни струму через паразитна індуктивність виводів та геометрії шарів:
   ```
   ΔV_esl = ESL_total · (di / dt)
   ```

2. **Омічне падіння напруги (`ΔV_esr`):**
   Виникає одразу після встановлення постійного значення нового струму навантаження:
   ```
   ΔV_esr = ΔI_step · ESR_total
   ```

3. **Ємнісне просідання заряду (`ΔV_cap`):**
   Триває впродовж часу реакції петлі зворотного зв'язку перетворювача `t_response ≈ 1 / (2π · f_c)` (де `f_c` — частота зрізу петлі стабілізації, типово 50–100 кГц), поки силова індуктивність `L_out` не збільшить струм від вхідного джерела:
   ```
   ΔV_cap = (ΔI_step · t_response) / (2 · C_total)
   ```

Сумарне пікове просідання напруги виражається рівнянням:

```
ΔV_peak = ESL_total · (di / dt) + ΔI_step · ESR_total + (ΔI_step · t_response) / (2 · C_total)
```

## Розрахунковий приклад: проектування вихідного фільтра VRM

**Умова задачі:**
Синхронний понижувальний стабілізатор живить процесор з параметрами:
- Вихідна напруга: `V_out = 1.0 В`;
- Стрибок струму навантаження: `ΔI_step = 40 А`;
- Швидкість наростання струму: `di/dt = 8 А/нс = 8·10⁹ А/с`;
- Допустиме відхилення напруги: `ΔV_max = 40 мВ` (0.040 В);
- Частота зрізу контуру регулювання: `f_c = 80 кГц` → час реакції:
  ```
  t_response = 1 / (2π · 80 000) ≈ 1.99·10⁻⁶ с ≈ 2.0 мкс
  ```

### Порівняння варіантів фільтрації

#### Варіант A: Рідкі електролітичні конденсатори (Low-ESR, 470 мкФ / 6.3 В)
- Параметри однієї банки: `C₁ = 470 мкФ`, `ESR₁ = 50 мОм`, `ESL₁ = 3.5 нГн`.
- Візьмемо 4 конденсатори в паралель:
  ```
  C_total   = 4 · 470 мкФ = 1880 мкФ
  ESR_total = 50 / 4 = 12.5 мОм
  ESL_total = 3.5 / 4 = 0.875 нГн
  ```

Розрахуємо компоненти просідання:
```
ΔV_esr = 40 · 0.0125
       = 0.500 В = 500 мВ      [обвал напруги в 12.5 раза перевищує норму 40 мВ!]
```
*Висновок:* Звичайні електроліти непридатні для VRM через завеликий ESR. Щоб отримати потрібні 40 мВ, знадобилося б понад 50 таких банок.

#### Варіант B: Керамічні конденсатори MLCC 100 мкФ / 6.3 В (X5R, типорозмір 1206)
- Номінал: `C_nom = 100 мкФ`, `ESR₁ = 2.5 мОм`, `ESL₁ = 0.6 нГн`.
- Врахування DC-bias ефекту: при `V_dc = 1.0 В` ємність падає на 30% → `C_eff = 70 мкФ`.
- Візьмемо 10 конденсаторів у паралель:
  ```
  C_total   = 10 · 70 мкФ = 700 мкФ
  ESR_total = 2.5 / 10 = 0.25 мОм
  ESL_total = 0.6 / 10 = 0.06 нГн
  ```

Розрахуємо компоненти просідання:
```
ΔV_esr = 40 · 0.00025 = 0.010 В = 10 мВ
ΔV_cap = (40 · 2.0·10⁻⁶) / (2 · 700·10⁻⁶)
       = 8.0·10⁻⁵ / 1.4·10⁻³
       = 0.0571 В = 57.1 мВ
ΔV_total = 10 + 57.1 = 67.1 мВ      [перевищує ліміт 40 мВ через малу ефективну ємність]
```
*Висновок:* Потрібно подвоїти кількість керамічних конденсаторів (до 20–25 шт), що створює ризик акустичного дзвону (п'єзоефект) та механічного розтріскування плати.

#### Варіант C: Полімерні алюмінієві конденсатори SP-Cap (330 мкФ / 2.0 В)
- Параметри одного SP-Cap: `C₁ = 330 мкФ`, `ESR₁ = 4.5 мОм`, `ESL₁ = 0.9 нГн`.
- Втрата ємності від DC-bias: 0% (постійна ємність `330 мкФ`).
- Візьмемо 4 конденсатори в паралель:
  ```
  C_total   = 4 · 330 мкФ = 1320 мкФ = 1.32·10⁻³ Ф
  ESR_total = 4.5 / 4 = 1.125 мОм = 1.125·10⁻³ Ом
  ESL_total = 0.9 / 4 = 0.225 нГн = 2.25·10⁻¹⁰ Гн
  ```

Розрахуємо всі складові перехідного процесу:

```
1. Омічне падіння на ESR:
   ΔV_esr = 40 · 0.001125
          = 0.0450 В = 45.0 мВ (до розрахунку розряду)

2. Ємнісне просідання заряду:
   ΔV_cap = (40 · 2.0·10⁻⁶) / (2 · 1.32·10⁻³)
          = 8.0·10⁻⁵ / 2.64·10⁻³
          = 0.0303 В = 30.3 мВ

3. Індуктивний пік (фільтрується локальною парою MLCC 0402 прямо біля кристала):
   ΔV_esl = 2.25·10⁻¹⁰ · 8·10⁹
          = 1.8 В      [поглинається внутрішньокристальними конденсаторами decouping]
```

При паралельному додаванні невеликого блоку кераміки (4 × 10 мкФ MLCC 0402, `C_mlcc = 40 мкФ`, `ESR ≈ 0.5 мОм`) сумарний опір `ESR_total` знижується до 0.85 мОм:
```
ΔV_esr = 40 · 0.00085 = 34.0 мВ      [вкладається у встановлений ліміт 40 мВ]
```

## Паралельне комбінування: полімерний конденсатор + кераміка MLCC та явище антирезонансу

На практиці вихідний фільтр силового перетворювача ніколи не будують лише на одному типі конденсаторів. Інженери об'єднують переваги двох світів: встановлюють масив великої ємності з полімерних конденсаторів (для накопичення заряду та забезпечення стабільності на середніх частотах 10–500 кГц) паралельно з масивом малогабаритних керамічних конденсаторів MLCC типорозмірів 0402/0603 (для шунтування струмів на високих частотах 1–50 МГц).

Проте паралельне з'єднання двох конденсаторів з різними резонансними частотами створює небезпечне явище — **паралельний антирезонанс** (англ. *anti-resonance*).

### Математичний механізм антирезонансного піку

Нехай паралельно увімкнено:
1. Полімерний конденсатор з параметрами `C_p`, `ESR_p`, `ESL_p`;
2. Керамічний конденсатор MLCC з параметрами `C_c`, `ESR_c`, `ESL_c`.

У частотній області між власною резонансною частотою полімерного конденсатора `f₀_p` (де він уже проявляє індуктивний характер `+jω ESL_p`) та резонансною частотою керамічного конденсатора `f₀_c` (де кераміка все ще є ємністю `-j / (ω C_c)`), еквівалентна схема перетворюється на паралельний коливальний контур, утворений індуктивністю `ESL_p` та ємністю `C_c`.

Частота антирезонансного піку імпедансу визначається формулою:

```
f_anti ≈ 1 / (2π · √(C_c · ESL_p))
```

На цій частоті паралельний реактивний опір різко зростає, утворюючи гострий пік імпедансу, амплітуда якого обмежена лише сумарним активним опором гілок:

```
|Z_anti_peak| ≈ √(ESL_p / C_c) / (ESR_p + ESR_c)
```

Якщо цей пік перевищить цільовий імпеданс `Z_target`, гармоніки комутації перетворювача або швидкі зміни струму процесора викличуть на шині незгасаючі коливання великої амплітуди (паразитний дзвін).

### Умова критичного демпфування антирезонансу: чому ESR полімеру рятує схему

Добротність паралельного антирезонансного контуру описується співвідношенням:

```
Q_anti = (1 / (ESR_p + ESR_c)) · √(ESL_p / C_c)
```

Щоб повністю придушити пік імпедансу та забезпечити пласку характеристику `|Z(f)| ≤ Z_target` без перевищення (аперіодичне затухання, `Q_anti ≤ 1`), сумарний опір втрат повинен задовольняти **критерію демпфування**:

```
ESR_p + ESR_c ≥ √(ESL_p / C_c)
```

Оскільки керамічний конденсатор має надзвичайно низький власний опір (`ESR_c ≈ 1...3 мОм`), усе навантаження з демпфування лягає на опір полімерного конденсатора `ESR_p`.

**Числовий приклад:**
Нехай `ESL_p = 1.0 нГн = 10⁻⁹ Гн`, а сумарна ємність керамічного масиву `C_c = 40 мкФ = 4·10⁻⁵ Ф`:

```
Z_char = √(ESL_p / C_c)
       = √(10⁻⁹ / (4·10⁻⁵))
       = √(2.5·10⁻⁵)
       = 0.005 Ом = 5.0 мОм      [характеристичний опір контуру]
```

Звідси випливає фундаментальний висновок: для повного придушення резонансного дзвону опір полімерного конденсатора повинен становити `ESR_p ≥ 5.0 мОм`. 

Якщо розробник замінить полімерний конденсатор на масив чистої кераміки з сумарним `ESR = 0.5 мОм`, добротність контуру підскочить до:

```
Q = 5.0 / 0.5 = 10
```

Імпеданс на антирезонансній частоті зросте в 10 разів (до 50 мОм), спричиняючи аварійні викиди напруги під час динамічного навантаження. Таким чином, помірний опір полімерного конденсатора (3–10 мОм) є не недоліком, а строго розрахованим інженерним інструментом демпфування всієї системи розподілу живлення.

## Замкнений імпеданс перетворювача зі зворотним зв'язком

На низьких частотах (від 0 Гц до частоти зрізу петлі зворотного зв'язку `f_c`) вихідний імпеданс перетворювача визначається не пасивними конденсаторами, а дією активної петлі регулювання.

Вихідний імпеданс замкненої системи `Z_cl(s)` пов'язаний з розімкненим імпедансом `Z_ol(s)` через передавальну функцію петлі регулювання `T(s)`:

```
Z_cl(s) = Z_ol(s) / (1 + T(s))
```

де `T(s) = G_pwm · G_filter(s) · H_comp(s)` — загальне петлеве підсилення стабілізатора.

На нульовій частоті (постійний струм) завдяки інтегральній складовій підсилювача похибки петлеве підсилення прагне до нескінченності (`T(0) → ∞`), тому вихідний опір стабілізатора наближається до нуля:

```
Z_cl(0) ≈ 0 Ом
```

Зі збільшенням частоти підсилення `T(f)` спадає зі швидкістю −20 дБ/декаду. На частоті зрізу контуру `f = f_c` модуль петлевого підсилення стає рівним одиниці (`|T(f_c)| = 1`), і активна система регулювання втрачає здатність компенсувати зміни навантаження:

```
|Z_cl(f_c)| ≈ |Z_ol(f_c)| / √2
```

На частотах вище `f_c` активний стабілізатор повністю вимикається з роботи, і весь тягар утримання напруги в межах цільового імпедансу `Z_target` лягає виключно на пасивний вихідний фільтр із полімерних та керамічних конденсаторів.

## Критерій оптимізації багатокаскадної PDN: зв'язок між VRM, полімером та керамікою

Повна мережа розподілу живлення формує ступінчасту піраміду імпедансів:
1. **Низькі частоти (0–100 кГц):** регулюються активним ШІМ-стабілізатором VRM;
2. **Середні частоти (100 кГц – 2 МГц):** підтримуються масивом полімерних конденсаторів великої ємності з низьким ESL;
3. **Високі частоти (2–50 МГц):** шунтуються керамічними конденсаторами MLCC на платі;
4. **Ультрависокі частоти (50 МГц – 1 ГГц):** фільтруються кремнієвими ємностями підкладки сокета та кристала CPU (BGA / on-die capacitance).

Щоб імпеданс не мав сплесків на стиках цих чотирьох діапазонів, ємності та індуктивності сусідніх каскадів мають задовольняти **умові геометричного узгодження**:

```
Z_char_stage = √(ESL_k / C_k+1) ≤ Z_target
```

Якщо значення характеристичного опору `√(ESL_k / C_k+1)` перевищує цільовий імпеданс `Z_target`, активний опір `ESR` проміжного полімерного конденсатора мусить бути підібраний точно рівним `Z_target`:

```
ESR_opt = Z_target = ΔV_allowed / ΔI_step
```

Ця фундаментальна формула доводить, що прагнення до нульового ESR у системному проектуванні є помилковим: оптимізований VRM вимагає точного збігу `ESR_total` з `Z_target`, що гарантує абсолютно пласку безрезонансну криву живильної напруги під будь-якими імпульсними навантаженнями.

## Тепловий розрахунок нагріву від пульсуючого струму (Ripple Current Heating)

Середньоквадратичний струм пульсацій `I_ripple_rms` вихідного каскаду синхронного перетворювача розсіюється на активному опорі `ESR_total` у вигляді тепла:

```
P_loss = I_ripple_rms² · ESR_total
```

Приймемо струм пульсацій індуктивності `I_ripple_rms = 8.5 А` (RMS):

```
P_loss = 8.5² · 0.001125
       = 72.25 · 0.001125
       = 0.0813 Вт = 81.3 мВт      [сумарні теплові втрати на 4 конденсатори]
```

На кожен із чотирьох конденсаторів припадає теплова потужність:
```
P_one = 81.3 / 4 ≈ 20.3 мВт
```

При тепловому опорі корпуса SP-Cap до навколишнього середовища `R_th_ja ≈ 60 °C/Вт` підвищення температури становить:
```
ΔT = P_one · R_th_ja
   = 0.0203 · 60
   = 1.22 °C      [перегрів повністю невідчутний для надійності]
```

Для порівняння, звичайний електролітичний конденсатор з `ESR = 50 мОм` при такому ж струмі пульсацій виділяв би:
```
P_loss_el = 72.25 · 0.050 = 3.61 Вт
```
що призвело б до миттєвого закипання електроліту, спрацьовування захисного клапана та виходу схеми з ладу впродовж кількох секунд.
