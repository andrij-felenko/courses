# 🧮 Математична теорія амбіполярного переносу та розрахунок падіння напруги

У силових напівпровідникових приладах (PIN-діодах, IGBT, тиристорах) товщина слабколегованої дрейфової бази сягає десятків і сотень мікрометрів, щоб утримувати блокуючу напругу до кількох кіловольт. За прямого зміщення концентрація введених електронів і дірок перевищує фонову концентрацію домішок на кілька порядків, що докорінно змінює фізику руху носіїв. Для розрахунку падіння напруги, просторового розподілу густини плазми, контактних бар'єрів, температурних коефіцієнтів та накопиченого заряду застосовують теорію амбіполярного переносу (лат. *ambi* — обидва, грец. *polos* — полюс), яка описує зв'язаний рух електронів і дірок у квазінейтральному середовищі.

## 1. Рівняння неперервності та густина струмів носіїв

Розглянемо одновимірну дрейфову базу довжиною `W_B = 2d` у системі координат від `-d` (анодна межа з сильнолегованим емітером `p⁺`) до `+d` (катодна межа з сильнолегованим емітером `n⁺`).

Повні густини електронного струму `J_n` та діркового струму `J_p` складаються з дрейфової та дифузійної складових:

```
J_n = q · μ_n · n · E + q · D_n · (dn/dx)
J_p = q · μ_p · p · E - q · D_p · (dp/dx)
```

де:
- `q = 1.602 · 10⁻¹⁹ Кл` — елементарний електричний заряд електрона;
- `μ_n`, `μ_p` — рухливості електронів і дірок у кристалічній ґратці кремнію (`см²/(В·с)`);
- `D_n`, `D_p` — коефіцієнти дифузії електронів і дірок (`см²/с`);
- `E` — локальна напруженість електричного поля (`В/см`);
- `n(x)`, `p(x)` — локальні концентрації електронів і дірок (`см⁻³`).

Зв'язок між рухливістю і коефіцієнтом дифузії для кожного типу носіїв задається фундаментальним співвідношенням Ейнштейна:

```
D_n / μ_n = D_p / μ_p = (k_B · T) / q = V_t
```

де `k_B = 1.381 · 10⁻²³ Дж/К` — стала Больцмана, `T` — абсолютна термодинамічна температура в кельвінах, а `V_t` — температурний потенціал, який за кімнатної температури `T = 300 К` дорівнює `V_t ≈ 0.0259 В` (25.9 мВ).

Повний струм через прилад `J` у стаціонарному одновимірному режимі є просторовою константою, що випливає із закону збереження електричного заряду:

```
J = J_n(x) + J_p(x) = const
```

## 2. Умова інжекції високого рівня та просторова квазінейтральність

У режимі інжекції високого рівня (High-Level Injection, HLI) концентрація інжектованих дірок `p(x)` та електронів `n(x)` набагато більша за фонову концентрацію донорів `N_D` у дрейфовій зоні:

```
p(x) >> N_D
n(x) >> N_D
```

Розподіл електричного поля в напівпровіднику підпорядковується одновимірному рівнянню Пуассона:

```
dE/dx = (q / ε_s) · (p(x) - n(x) + N_D)
```

де `ε_s = 11.7 · ε₀ ≈ 1.036 · 10⁻¹² Ф/см` — діелектрична проникність кремнію.

Якщо уявити, що концентрація одного типу носіїв перевищить концентрацію іншого хоча б на 0.1% при типовій густині плазми `10¹⁷ см⁻³`, різниця `|p - n| ≈ 10¹⁴ см⁻³` створить градієнт електричного поля величиною понад `15 кВ/см` на відстані всього в 1 мкм. Таке гігантське поле миттєво підтягує протилежні носії, відновлюючи баланс.

З цієї причини в усій товщі дрейфової бази з високою точністю виконується умова просторової **квазінейтральності**:

```
n(x) ≈ p(x)
dn/dx ≈ dp/dx
```

Електрони й дірки більше не рухаються незалежно — вони формують єдину зв'язану систему, яка поводиться як щільна двокомпонентна електронно-діркова плазма.

## 3. Виведення амбіполярного електричного поля

Щоб знайти внутрішнє електричне поле `E(x)`, додамо рівняння густин електронного та діркового струмів, підставивши умову квазінейтральності `n(x) = p(x)`:

```
J = J_n + J_p
= q · (μ_n + μ_p) · p(x) · E(x) + q · (D_n - D_p) · (dp/dx)
```

Виразимо з цієї рівності напруженість електричного поля `E(x)`:

```
E(x) = J / (q · (μ_n + μ_p) · p(x)) - ((D_n - D_p) / (μ_n + μ_p)) · (1 / p(x)) · (dp/dx)
```

Скориставшись співвідношенням Ейнштейна `D_n - D_p = V_t · (μ_n - μ_p)`, поле можна записати у вигляді суми двох чітких фізичних складових:

```
E(x) = E_ohm(x) + E_diff(x)
```

де:
- `E_ohm(x) = J / (q · (μ_n + μ_p) · p(x))` — омічне поле провідності, яке підтримує дрейфовий рух носіїв крізь середовище з локальною провідністю `σ(x) = q · (μ_n + μ_p) · p(x)`;
- `E_diff(x) = - V_t · ((μ_n - μ_p) / (μ_n + μ_p)) · (1 / p(x)) · (dp/dx)` — дифузійне поле поляризації (ефект Дембера). Оскільки рухливість електронів у кремнії приблизно втричі вища за рухливість дірок (`μ_n ≈ 3 · μ_p`), електрони намагаються дифундувати швидше, випереджаючи дірки. Це породжує мікроскопічне просторове зміщення зарядів, яке створює внутрішнє електричне поле, спрямоване на гальмування швидких електронів і прискорення повільних дірок.

## 4. Виведення амбіполярного рівняння дифузії (ADE)

Підставимо отримане електричне поле `E(x)` у вихідне рівняння для діркового струму `J_p`:

```
J_p(x) = q · μ_p · p · [ J / (q · (μ_n + μ_p) · p) - ((D_n - D_p) / (μ_n + μ_p)) · (1 / p) · (dp/dx) ] - q · D_p · (dp/dx)
```

Розкриваючи дужки та групуючи доданки:

```
J_p(x) = (μ_p / (μ_n + μ_p)) · J - q · [ (μ_p · (D_n - D_p) / (μ_n + μ_p)) + D_p ] · (dp/dx)
```

Перетворимо вираз у квадратних дужках:

```
(μ_p · (D_n - D_p) + D_p · (μ_n + μ_p)) / (μ_n + μ_p)
= (μ_p · D_n - μ_p · D_p + D_p · μ_n + D_p · μ_p) / (μ_n + μ_p)    [розкриття дужок у чисельнику]
= (2 · μ_p · D_n) / (μ_n + μ_p)                                     [взаємне скорочення членів μ_p · D_p]
= (2 · D_n · D_p) / (D_n + D_p)                                     [підстановка співвідношення Ейнштейна D = V_t · μ]
= D_a                                                               [означення амбіполярного коефіцієнта дифузії]
```

Величина `D_a` є фундаментальною кінетичною константою біполярного напівпровідника і називається **амбіполярним коефіцієнтом дифузії**:

```
D_a = (2 · D_n · D_p) / (D_n + D_p) = 2 · V_t · (μ_n · μ_p) / (μ_n + μ_p)
```

Дірковий струм набуває вигляду:

```
J_p(x) = (μ_p / (μ_n + μ_p)) · J - q · D_a · (dp/dx)
```

Перший доданок описує частку повного струму, яку дірки переносять під дією зовнішнього поля, а другий доданок описує зв'язану амбіполярну дифузію плазми.

Стаціонарне рівняння неперервності для дірок із урахуванням рекомбінації Шоклі-Ріда-Голла (SRH) зі сталим часом життя високого рівня `τ_HL`:

```
(1/q) · (dJ_p/dx) = - R = - p(x) / τ_HL
```

Продиференціюємо рівняння струму `J_p(x)` за координатою `x`. Оскільки повна густина струму `J` є сталою вздовж кристала (`dJ/dx = 0`):

```
dJ_p/dx = - q · D_a · (d²p/dx²)
```

Прирівнюючи похідну струму до швидкості рекомбінації:

```
- q · D_a · (d²p/dx²) = - q · (p(x) / τ_HL)
d²p/dx² = p(x) / (D_a · τ_HL)
```

Введемо **амбіполярну дифузійну довжину `L_a`**:

```
L_a = √(D_a · τ_HL)
```

Отримуємо класичне **амбіполярне рівняння дифузії (Ambipolar Diffusion Equation, ADE)**:

```
d²p/dx² = p(x) / L_a²
```

Це лінійне диференціальне рівняння другого порядку є основою всієї фізики силових біполярних напівпровідникових приладів.

## 5. Граничні умови та точний аналітичний розв'язок профілю плазми

Загальний розв'язок диференціального рівняння записується через базис гіперболічних функцій:

```
p(x) = A₁ · cosh(x / L_a) + A₂ · sinh(x / L_a)
```

Константи інтегрування `A₁` та `A₂` визначаються граничними умовами на інжектуючих контактах:
1. На анодній межі `x = -d` емітер `p⁺` має високу ефективність інжекції дірок, тому струм на переході є майже чисто дірковим: `J_p(-d) ≈ J`.
2. На катодній межі `x = +d` емітер `n⁺` інжектує електрони, тому дірковий струм спадає практично до нуля: `J_p(+d) ≈ 0`.

Підставимо граничні значення у вираз для діркового струму `J_p(x)`:

```
J_p(-d) = (μ_p / (μ_n + μ_p)) · J - q · D_a · (dp/dx)|_{x = -d} = J
- q · D_a · (dp/dx)|_{x = -d} = (μ_n / (μ_n + μ_p)) · J

J_p(+d) = (μ_p / (μ_n + μ_p)) · J - q · D_a · (dp/dx)|_{x = +d} = 0
- q · D_a · (dp/dx)|_{x = +d} = - (μ_p / (μ_n + μ_p)) · J
```

Обчислимо похідну `dp/dx = (A₁ / L_a) · sinh(x / L_a) + (A₂ / L_a) · cosh(x / L_a)` і підставимо координати границь:

```
(A₁ / L_a) · sinh(d / L_a) - (A₂ / L_a) · cosh(d / L_a) = (J · μ_n) / (q · D_a · (μ_n + μ_p))
- (A₁ / L_a) · sinh(d / L_a) - (A₂ / L_a) · cosh(d / L_a) = - (J · μ_p) / (q · D_a · (μ_n + μ_p))
```

Додаючи обидва рівняння, знаходимо коефіцієнт `A₂`:

```
- 2 · (A₂ / L_a) · cosh(d / L_a) = J · (μ_n - μ_p) / (q · D_a · (μ_n + μ_p))
A₂ = - (J · L_a) / (2 · q · D_a) · ((μ_n - μ_p) / (μ_n + μ_p)) · (1 / cosh(d / L_a))
```

Віднімаючи друге рівняння від першого, знаходимо коефіцієнт `A₁`:

```
2 · (A₁ / L_a) · sinh(d / L_a) = J · (μ_n + μ_p) / (q · D_a · (μ_n + μ_p)) = J / (q · D_a)
A₁ = (J · L_a) / (2 · q · D_a · sinh(d / L_a))
```

Остаточний просторовий профіль концентрації плазми вздовж бази:

```
p(x) = (J · L_a) / (2 · q · D_a) · [ (cosh(x / L_a) / sinh(d / L_a)) - ((μ_n - μ_p) / (μ_n + μ_p)) · (sinh(x / L_a) / cosh(d / L_a)) ]
```

Мінімальна концентрація носіїв досягається поблизу середини бази `x = 0`:

```
p_min ≈ p(0) = A₁ = (J · L_a) / (2 · q · D_a · sinh(d / L_a))
```

Цей вираз наочно демонструє вплив геометричного фактора `d / L_a`:
- Якщо `d / L_a ≤ 1`, то `sinh(d / L_a) ≈ d / L_a`, і концентрація в центрі `p(0) ≈ J / (2 · q · D_a · (d / L_a²)) = (J · τ_HL) / (2 · q · d)` є максимальною й рівномірною по всій базі.
- Якщо `d / L_a >> 2`, то `sinh(d / L_a) ≈ (1/2) · exp(d / L_a)`, і концентрація в центрі падає за експоненційним законом `p(0) ∝ exp(-d / L_a)`. Носії рекомбінують поблизу емітерів, не встигаючи за рахунок дифузії досягти центральних шарів бази.

## 6. Контактні різниці потенціалів та ідеальність ВАХ

Повне пряме падіння напруги на силовому приладі складається з контактних напруг на переходах та інтегрального падіння на товщі бази:

```
V_F = V_j1 + V_base + V_j2
```

За умов високого рівня інжекції контактні різниці потенціалів на переходах визначаються узагальненими граничними співвідношеннями Флетчера (Fletcher boundary conditions):

```
p(-d) · n(-d) = p(-d)² = n_i² · exp(q · V_j1 / (k_B · T))
p(+d) · n(+d) = p(+d)² = n_i² · exp(q · V_j2 / (k_B · T))
```

де `n_i` — власна концентрація носіїв у кремнії (`n_i ≈ 1.5 · 10¹⁰ см⁻³` при `300 К`).

Виражаючи напруги на переходах:

```
V_j1 = V_t · ln(p(-d)² / n_i²) = 2 · V_t · ln(p(-d) / n_i)
V_j2 = V_t · ln(p(+d)² / n_i²) = 2 · V_t · ln(p(+d) / n_i)
```

Сума падінь напруг на двох переходах:

```
V_j = V_j1 + V_j2 = 2 · V_t · ln( (p(-d) · p(+d)) / n_i² )
```

Оскільки `p(-d)` та `p(+d)` пропорційні густині струму `J`, вираз для суми контактних потенціалів набуває вигляду:

```
V_j = 2 · V_t · ln(J / J_s)
```

Звідси стає зрозумілим походження коефіцієнта неідеальності `n = 2` у класичному рівнянні вольт-амперної характеристики діода за високого рівня інжекції:

```
J ∝ exp(q · V_F / (2 · k_B · T))
```

Множник 2 у знаменнику показника експоненти свідчить про те, що струм лімітується бімолекулярною рекомбінацією інжектованої плазми.

## 7. Інтегрування падіння напруги на базі

Падіння напруги вздовж модульованої бази розраховується як інтеграл від напруженості електричного поля:

```
V_base = ∫_{-d}^{+d} E(x) dx = V_ohm + V_diff
```

Дифузійна складова інтегрується безпосередньо:

```
V_diff = - V_t · ((μ_n - μ_p) / (μ_n + μ_p)) · ∫_{-d}^{+d} (1 / p) · (dp/dx) dx
= - V_t · ((μ_n - μ_p) / (μ_n + μ_p)) · ln(p(+d) / p(-d))
```

Оскільки концентрації носіїв на обох межах близькі за величиною (`p(-d) / p(+d) ≈ μ_n / μ_p ≈ 3`), значення `V_diff` становить не більше `10 – 15 мВ` і майже не впливає на загальний баланс напруги.

Омічна складова падіння напруги обчислюється через інтеграл зворотної концентрації:

```
V_ohm = (J / (q · (μ_n + μ_p))) · ∫_{-d}^{+d} (1 / p(x)) dx
```

Підставивши розв'язок для `p(x)` та виконавши заміну змінної `u = tanh(x / L_a)`, інтеграл зводиться до замкненої аналітичної форми Голла:

```
V_ohm = (2 · k_B · T / q) · (sinh(d / L_a) / √(1 - B² · tanh²(d / L_a))) · arctan[ √(1 - B² · tanh²(d / L_a)) · sinh(d / L_a) ]
```

де `B = (μ_n - μ_p) / (μ_n + μ_p)`.

Для практичних інженерних оцінок використовують два наближення:
1. **Для тонкої бази (`d / L_a ≤ 1.5`):**
   ```
   V_ohm ≈ 3 · V_t · (d / L_a)²
   ```
   Омічне падіння напруги на базі становить лише кілька десятків мілівольтів (`0.03 – 0.15 В`).
2. **Для товстої бази (`d / L_a > 2.5`):**
   ```
   V_ohm ≈ (π · k_B · T / q) · exp(d / L_a)
   ```
   Падіння напруги наростає за експонентою, спричиняючи значні втрати потужності провідності.

## 8. Температурні коефіцієнти та точка термостабільності

Залежність прямого падіння напруги `V_F` від температури визначається конкуренцією двох протилежних фізичних ефектів:

```
dV_F / dT = dV_j / dT + dV_base / dT
```

1. **Температурна похідна переходів `dV_j / dT`:**
   Власна концентрація носіїв різко зростає з температурою за експоненційним законом:
   ```
   n_i²(T) ∝ T³ · exp(- E_g / (k_B · T))
   ```
   Через це висота контактних потенційних бар'єрів падає зі швидкістю приблизно `- 1.8 ... - 2.2 мВ/К`:
   ```
   dV_j / dT ≈ - 2.0 мВ/К < 0  (від'ємний температурний коефіцієнт)
   ```

2. **Температурна похідна омічного опору бази `dV_base / dT`:**
   Рухливість носіїв струму деградує при нагріванні через посилення розсіювання на теплових коливаннях кристалічної ґратки (фононах):
   ```
   μ_n(T) ∝ T^(-2.4)
   μ_p(T) ∝ T^(-2.2)
   ```
   Зниження рухливості зменшує коефіцієнт дифузії `D_a` та дифузійну довжину `L_a`, внаслідок чого опір модульованої бази зростає:
   ```
   dV_base / dT > 0  (додатний температурний коефіцієнт)
   ```

При малих густинах струму (`J < J_cross`) домінує спад контактної напруги переходів, тому `dV_F / dT < 0`. Якщо паралельно з'єднати кілька кристалів або транзисторів у цьому режимі, найгарячіший кристал матиме менше падіння напруги, перетягне на себе більшу частку струму, нагріється ще сильніше і зазнає теплового пробою (термонестійкість).

При номінальних робочих струмах (`J > J_cross ≈ 50 – 100 А/см²`) омічний опір бази переважає контактні напруги, внаслідок чого сумарний температурний коефіцієнт стає строго додатним: `dV_F / dT > 0`. Це забезпечує автоматичне самовирівнювання струмів між паралельно з'єднаними чіпами у складі силових модулів.

## 9. Вплив електрон-діркового розсіювання при високій густині струму

Коли густина прямого струму перевищує `200 – 500 А/см²`, концентрація плазми досягає `10¹⁷ – 10¹⁸ см⁻³`. За таких умов відстань між рухомими носіями стає порівнянною з міжатомною відстанню в кристалі, і визначальним механізмом опору стає взаємне кулонівське розсіювання електронів на дірках (Carrier-Carrier Scattering).

Ефективна сумарна рухливість носіїв знижується за емпіричною моделлю Флетчера-Чу (Choo model):

```
1 / (μ_n + μ_p)_eff = 1 / (μ_n0 + μ_p0) + p(x) / C_sc
```

де `C_sc ≈ 2 · 10¹⁹ см⁻¹·(В·с)⁻¹` — константа електрон-діркового розсіювання для кремнію.

Через деградацію рухливості опір плазми перестає зменшуватися пропорційно `1 / p(x)`. Це призводить до того, що на ділянці надвисоких струмів ВАХ приладу змінює характер з логарифмічного на суто лінійний (омічний) з залишковим диференційним опором, що захищає кристал від струмового шнурування.

## 10. Оже-рекомбінація за умов аварійних надструмів

Під час аварійних режимів (струми короткого замикання в інверторах або ударні імпульси струму I²t), коли густина струму сягає `1000 – 5000 А/см²`, концентрація плазми перевищує `10¹⁸ см⁻³`. За такої надвисокої густини носіїв домінуючим каналом рекомбінації стає тричастинковий безвипромінювальний процес **Оже-рекомбінації** (Auger recombination).

Під час рекомбінації електрон і дірка анігілюють, але замість передачі енергії фононам або фотонам надлишкова енергія забороненої зони передається третьому вільному носію (електрону або дірці), який переходить у високоенергетичний стан зони провідності або валентної зони.

Швидкість Оже-рекомбінації зростає пропорційно кубу концентрації плазми:

```
R_Auger = C_a · p(x)³
```

де `C_a = C_n + C_p ≈ 4 · 10⁻³¹ см⁶/с` — коефіцієнт Оже для кремнію.

Ефективний час життя носіїв різко скорочується за законом:

```
1 / τ_eff = 1 / τ_SRH + C_a · p(x)²
```

Коли концентрація плазми досягає `p ≈ 2 · 10¹⁸ см⁻³`, Оже-час життя падає до `τ_Auger = 1 / (C_a · p²) ≈ 60 нс`. Це явище самообмежує подальше зростання концентрації плазми: опір бази починає різко зростати, що призводить до десатурації силового ключа та дає змогу системам захисту вчасно вимкнути аварійне коротке замикання до руйнування кристала.

## 11. Динаміка розпаду заряду, метод OCVD та зворотне відновлення

Накопичений заряд плазми в базі під час стаціонарної провідності дорівнює:

```
Q_F = I_F · τ_HL
```

Якщо струм через прилад миттєво розірвати (режим розімкненого кола), носії заряду почнуть зникати виключно за рахунок об'ємної рекомбінації:

```
dQ/dt = - Q / τ_HL
Q(t) = Q_F · exp(-t / τ_HL)
```

Оскільки контактна напруга пов'язана з концентрацією носіїв як `V_F(t) ≈ 2 · V_t · ln(p(t) / n_i)`, швидкість спаду напруги на клемах приладу становить:

```
dV_F / dt = 2 · V_t · (1 / p) · (dp/dt) = - 2 · V_t · (1 / τ_HL) = - (2 · k_B · T / q) · (1 / τ_HL)
```

Це співвідношення лежить в основі стандартного вимірювального методу спаду напруги розімкненого кола (**Open Circuit Voltage Decay, OCVD**): інженер підключає осцилограф до вимиканого діода і безпосередньо вимірює нахил лінійної ділянки спаду напруги, розраховуючи час життя плазми:

```
τ_HL = (2 · k_B · T / q) / |dV_F / dt|
```

Під час примусового вимикання зворотним струмом зі сталою швидкістю комутації `di/dt` піковий зворотний струм `I_rr,peak` та час розсмоктування фази `t_a` розраховуються за формулою Брієра:

```
I_rr,peak = √( 2 · Q_stored · (di/dt) )
t_a = √( (2 · Q_stored) / (di/dt) )
```

Звідси видно, що чим більший час життя носіїв `τ_HL` (а отже, чим вищий `Q_stored`), тим більшим є піковий струм зворотного відновлення і тим вищі динамічні комутаційні втрати.

## 12. Числовий приклад розрахунку силової структури (1200 В, 100 А)

Розглянемо параметри дрейфової зони кремнієвого силового модуля на 1200 В:
- Площа активної структури: `A = 0.5 см²` (робочий струм `I_F = 100 А`, густина `J = 200 А/см²`);
- Товщина дрейфової n⁻ бази: `W_B = 120 мкм` (`d = 60 мкм = 6 · 10⁻³ см`);
- Фонова концентрація легування: `N_D = 1.5 · 10¹⁴ см⁻³`;
- Рухливості за `T = 300 К`: `μ_n = 1350 см²/(В·с)`, `μ_p = 450 см²/(В·с)`;
- Температурний потенціал: `V_t = 0.0259 В`;
- Час життя носіїв: `τ_HL = 5 мкс = 5 · 10⁻⁶ с`.

### Покроковий розрахунок:

1. **Амбіполярний коефіцієнт дифузії:**
   ```
   D_a = 2 · V_t · (μ_n · μ_p) / (μ_n + μ_p)
       = 2 · 0.0259 · (1350 · 450) / (1350 + 450)                      [підстановка V_t та рухливостей носіїв]
       = 0.0518 · 607500 / 1800 = 17.48 см²/с                          [арифметичне обчислення]
   ```

2. **Амбіполярна довжина дифузії:**
   ```
   L_a = √(D_a · τ_HL)
       = √(17.48 · 5 · 10⁻⁶) = √(8.74 · 10⁻⁵)                          [підстановка D_a та часу життя τ_HL]
       = 9.35 · 10⁻³ см = 93.5 мкм                                     [добування квадратного кореня]
   ```

3. **Ступінь затоплення бази:**
   ```
   d / L_a = (60 мкм) / (93.5 мкм) = 0.642
   W_B / L_a = 120 / 93.5 = 1.28
   ```
   Умова `d / L_a < 1` свідчить про глибоке й однорідне затоплення плазмою.

4. **Мінімальна густина плазми в центрі кристала:**
   ```
   p(0) = (J · L_a) / (2 · q · D_a · sinh(d / L_a))
        = (200 · 9.35 · 10⁻³) / (2 · 1.602 · 10⁻¹⁹ · 17.48 · 0.687)   [підстановка J, L_a, q, D_a та sinh(0.642)]
        = 1.87 / (3.847 · 10⁻¹⁸) = 4.86 · 10¹⁷ см⁻³                   [ділення чисельника на знаменник]
   ```
   Густина плазми перевищує легування `N_D` у `4.86 · 10¹⁷ / 1.5 · 10¹⁴ = 3240 разів`.

5. **Омічне падіння напруги на базі:**
   ```
   V_ohm ≈ 3 · V_t · (d / L_a)²
         = 3 · 0.0259 · (0.642)²                                       [підстановка V_t та d / L_a]
         = 0.0777 · 0.412 = 0.032 В                                    [обчислення омічного спаду напруги]
   ```

6. **Контактне падіння напруги на переходах:**
   ```
   V_j = 2 · V_t · ln(p(границя) / n_i)
       = 2 · 0.0259 · ln( (1.2 · 10¹⁸) / (1.5 · 10¹⁰) )                [підстановка p_edge = 1.2·10¹⁸ та n_i = 1.5·10¹⁰]
       = 0.0518 · ln(8 · 10⁷) = 0.0518 · 18.2 = 0.943 В               [обчислення контактних бар'єрів]
   ```

7. **Повне пряме падіння напруги та втрати потужності:**
   ```
   V_F = V_j + V_ohm = 0.943 В + 0.032 В ≈ 0.975 В
   P_cond = I_F · V_F = 100 А · 1.15 В = 115 Вт
   ```

8. **Порівняння з уніполярним кремнієвим резистором без інжекції:**
   ```
   ρ_unipolar = 1 / (q · μ_n · N_D)
              = 1 / (1.602 · 10⁻¹⁹ · 1350 · 1.5 · 10¹⁴) = 30.83 Ом·см  [питомий опір без плазми]
   R_drift = ρ_unipolar · W_B / A = 30.83 · 1.2 · 10⁻² / 0.5 = 0.74 Ом
   V_unipolar = 100 А · 0.74 Ом = 74 В
   P_unipolar = 100² · 0.74 = 7400 Вт = 7.4 кВт
   ```

9. **Накопичений заряд плазми:**
   ```
   Q_F = I_F · τ_HL = 100 А · 5 · 10⁻⁶ с = 500 мкКл
   ```

## 13. Вплив буферного шару Field Stop на граничні умови та накопичений заряд

У сучасних структурах польового обмеження (Field Stop IGBT або Buffer Layer діодах) між слабколегованою `n⁻` базою та сильнолегованим `p⁺` колектором вводиться тонкий (1–3 мкм) проміжний шар `n`-типу з концентрацією донорів `N_FS ≈ 10¹⁵ – 10¹⁶ см⁻³`. 

Цей шар виконує подвійну математичну роль:
1. Різко гасить електричне поле на зворотній гілці, що дозволяє зменшити загальну товщину дрейфової бази `W_B` на 30–40% при збереженні тієї ж блокуючої напруги.
2. Діє як рекомбінаційний бар'єр для інжекції дірок, зменшуючи граничну концентрацію `p(-d)`.

Зменшення товщини бази `W_B` з 120 мкм до 80 мкм зменшує інтегральний об'ємний накопичений заряд `Q_F` пропорційно товщині кристала. Завдяки цьому прилад досягає надшвидкого вимикання без потреби штучного радіаційного скорочення часу життя `τ_HL`, зберігаючи високу провідність увімкненого стану.
