# 🧮 Математичний аналіз температурних кривих та пружних констант

Ця вставка містить строгий аналітичний вивід температурно-частотної характеристики кварцових резонаторів, математичну модель тензорного повороту пружних констант кристалічної ґратки, розрахунок рівняння Крістоффеля для подвійних поворотів, виведення умови компенсації напружень третього порядку для SC-зрізу та математичну модель частотного підтягування.

### 1. Зв'язок частоти зі швидкістю звуку та геометрією

Для пластини, що коливається в режимі товщинного зсуву (товщина `t`, густина `ρ`, ефективний модуль пружного зсуву `c′₆₆`), частота основної моди резонансу визначається формулою стоячої акустичної хвилі:

```
f = v / (2·t)
= √(c′₆₆ / ρ) / (2·t)                                 [підстановка v = √(c′₆₆ / ρ)]
```

де `v` — швидкість зсувної хвилі в обраному кристалографічному напрямку.

Візьмемо натуральний логарифм від обох частин рівняння та знайдемо похідну за температурою `T`:

```
ln(f) = (1/2)·ln(c′₆₆) − (1/2)·ln(ρ) − ln(t)
```

Диференціюємо за `T`:

```
(1/f)·(df/dT)
= (1/2)·(1/c′₆₆)·(dc′₆₆/dT) − (1/2)·(1/ρ)·(dρ/dT) − (1/t)·(dt/dT)   [похідна логарифма]
= (1/2)·Tc′₆₆ − (1/2)·Tρ − α′₃₃                                    [введення коефіцієнтів]
```

Тут позначено:
* `Tc′₆₆ = (1/c′₆₆)·(dc′₆₆/dT)` — перший температурний коефіцієнт ефективного модуля пружності;
* `Tρ = (1/ρ)·(dρ/dT) = −(α′₁₁ + α′₂₂ + α′₃₃)` — температурний коефіцієнт густини, виражений через коефіцієнти лінійного теплового розширення `α′ᵢᵢ`;
* `α′₃₃ = (1/t)·(dt/dT)` — коефіцієнт лінійного теплового розширення вздовж товщини пластини.

Підставивши вираз для `Tρ`, отримуємо перший температурний коефіцієнт частоти `Tf⁽¹⁾`:

```
Tf⁽¹⁾ = (1/f₀)·(df/dT)
= (1/2)·Tc′₆₆ + (1/2)·(α′₁₁ + α′₂₂) − (1/2)·α′₃₃     [підстановка виразу Tρ]
```

Оскільки коефіцієнти теплового розширення кварцу мають порядок `10⁻⁵ ... 10⁻⁶ К⁻¹`, вирішальний внесок у стабільність частоти робить саме температурна залежність модуля пружності `Tc′₆₆`.

### 2. Тензорний поворот констант пружності для Y-зрізів

У вихідній кристалографічній системі координат `(X, Y, Z)` тригональний кварц (клас 32) має 6 незалежних пружних констант у матриці Фойгта: `c₁₁`, `c₁₂`, `c₁₃`, `c₁₄`, `c₃₃`, `c₄₄` (причому `c₆₆ = (c₁₁ − c₁₂)/2`).

При повороті системи навколо електричної осі `X` на кут `θ` (зрізи сімейства YXl, куди входять AT і BT) новий ефективний модуль зсуву `c′₆₆` розраховується через тензорне перетворення 4-го рангу:

```
c′₆₆(θ) = c₆₆·cos²(θ) + c₄₄·sin²(θ) + 2·c₁₄·sin(θ)·cos(θ)
```

Візьмемо температурну похідну від `c′₆₆(θ)`:

```
dc′₆₆(θ)/dT
= (dc₆₆/dT)·cos²(θ) + (dc₄₄/dT)·sin²(θ) + 2·(dc₁₄/dT)·sin(θ)·cos(θ)   [диференціювання за T]
```

Для кварцу кімнатної температури експериментальні температурні коефіцієнти вихідних констант мають такі значення:
* `Tc₆₆ = +178·10⁻⁶ К⁻¹` (позитивний!);
* `Tc₄₄ = −163·10⁻⁶ К⁻¹` (негативний!);
* `Tc₁₄ = −1010·10⁻⁶ К⁻¹`.

Оскільки `Tc₆₆` та `Tc₄₄` мають **протилежні знаки**, існує кут `θ`, при якому позитивний внесок `c₆₆` точно компенсує негативний внесок `c₄₄`.

Розв'яжемо рівняння нульового температурного коефіцієнта `Tf⁽¹⁾(θ) = 0` при `T = 25 °C`:

```
(1/2)·Tc′₆₆(θ) + (1/2)·(α′₁₁ + α′₂₂) − (1/2)·α′₃₃ = 0
```

Це тригонометричне рівняння має два корені в діапазоні `−90° ... +90°`:
1. `θ₁ = +35°15′` (35.25°) — відповідає **AT-зрізу**;
2. `θ₂ = −49°00′` (−49.0°) — відповідає **BT-зрізу**.

### 3. Рівняння Крістоффеля та подвійні повороти (SC-зріз)

Для подвійно повернутих пластин (кути `φ` навколо осі Z та `θ` навколо нової осі X′) поширення пружних хвиль описується тензорним рівнянням Крістоффеля:

```
(Γ_ik − ρ·v²·δ_ik) · u_k = 0
```

де `Γ_ik = c′_ijkl · n_j · n_l` — тензор Крістоффеля другого рангу, `n` — одиничний вектор нормалі до площини пластини, `u` — вектор поляризації зміщення, `δ_ik` — символ Кронекера.

У загальному випадку для заданого напрямку `n` характеристичне рівняння `det(Γ_ik − ρ·v²·δ_ik) = 0` має три дійсні додатні власні значення:

```
v_A² > v_B² > v_C²
```

Ці три швидкості відповідають трьом незалежним акустичним модам у товщині пластини:
1. **Квазіпоздовжня мода (A-мода):** найвища швидкість `v_A`, зміщення `u` переважно паралельне нормалі `n`.
2. **Швидка квазізсувна мода (B-мода):** проміжна швидкість `v_B`, зміщення перпендикулярне до нормалі.
3. **Повільна квазізсувна мода (C-мода):** найнижча швидкість `v_C`, робоча мода для SC-зрізу (`N_C ≈ 1.797 МГц·мм`).

Для SC-зрізу розрахунок кутів `φ ≈ 21.93°` та `θ ≈ 34.11°` здійснюється з умови одночасного виконання двох критеріїв:
1. Термокомпенсація першого порядку: `Tf⁽¹⁾(φ, θ) = 0` при `T = 92 °C`.
2. Рівність нулю чутливості швидкості `v_C` до планарного тензора напружень: `(∂v_C / ∂T_11) + (∂v_C / ∂T_22) = 0`.

### 4. Нелінійні пружні модулі третього порядку та компенсація напружень

Коли монокристал зазнає зовнішнього механічного навантаження (наприклад, стиск монтажними кліпсами чи деформація під дією сил тяжіння `g`), акустична швидкість змінюється через нелінійність міжатомних сил зв'язку.

У термодинамічній теорії пружності Е. ЕрНіссе зміщення акустичної швидкості від початкового напруженого стану `T_ij` описується через пружні константи третього порядку (Third-Order Elastic Constants, TOEC) `c_ijklmn`:

```
Δv / v₀ = (1 / (2 · ρ₀ · v₀²)) · (c′_ijklmn · n_j · n_l · n_m · n_n · S_mn + T_ik · u_i · u_k)
```

де `S_mn` — тензор статичної деформації.

Для тонкої дискової пластини, затиснутої по колу, основне навантаження є ізотропним планарним напруженням `T_11 = T_22 = σ_planar`, тоді як напруження по товщині відсутнє (`T_33 = 0`).

Відносний зсув частоти записується через сумарний коефіцієнт чутливості до планарних напружень `K_planar`:

```
Δf / f₀ = K_planar · σ_planar = (K_11 + K_22) · σ_planar
```

Значення коефіцієнта `K_planar` залежить від просторових кутів зрізу `(φ, θ)`:
* Для **AT-зрізу** (`φ = 0°`, `θ = +35°15′`):
  `K_planar = (K_11 + K_22) ≈ −2.45·10⁻¹¹ Па⁻¹`.
  Стиск пластини силою всього 1 МПа (10 атмосфер) зміщує частоту на `Δf/f₀ = −2.45·10⁻¹¹ · 10⁶ = −24.5 ppm`.
* Для **SC-зрізу** (`φ = 21.93°`, `θ = 34.11°`):
  Розрахунок згортки тензорів третього порядку дає строгу компенсацію:
  `K_11 ≈ +1.28·10⁻¹¹ Па⁻¹`
  `K_22 ≈ −1.28·10⁻¹¹ Па⁻¹`
  `K_planar = K_11 + K_22 = 0.00·10⁻¹¹ Па⁻¹`.

Завдяки тотожній рівності нулю суми діагональних коефіцієнтів планарне напруження не викликає зсуву частоти C-моди.

### 5. Динамічний тепловий градієнт та термопружна дифузія

Коли температура навколишнього середовища змінюється зі швидкістю `dT/dt`, тепловий потік проникає крізь пластину за тривимірним рівнянням теплопровідності Фур'є:

```
∂T / ∂t = D_th · ∇²T = D_th · (∂²T/∂x² + ∂²T/∂y² + ∂²T/∂z²)
```

де `D_th = κ / (ρ · c_p)` — коефіцієнт температуропровідності кварцу (`D_th ≈ 3.5·10⁻⁶ м²/с`).

Через скінченну швидкість теплопровідності зовнішні шари пластини нагріваються швидше за внутрішнє ядро. Різниця температур `ΔT_grad(r, z, t)` викликає неоднорідне теплове розширення, яке створює внутрішні механічні напруження `σ_th`:

```
σ_th(t) = [E / (1 − ν)] · α_th · (r² / (8 · D_th)) · (dT / dt)
```

У резонаторах **AT-зрізу** це напруження через ненульовий `K_planar` породжує динамічний зсув частоти:

```
(Δf / f₀)_dynamic = ã · (dT / dt)
```

де динамічний коефіцієнт `ã = K_planar · [E / (1 − ν)] · α_th · (r² / (8 · D_th)) ≈ (1.5 ... 2.0)·10⁻⁵ с/°C`.

Якщо нагрівач OCXO змінює температуру зі швидкістю `0.5 °C/с`, резонатор AT-зрізу дає динамічний викид частоти:

```
Δf/f₀ = 1.5·10⁻⁵ · 0.5 = 7.5·10⁻⁶ = +7.5 ppm
```

У **SC-зрізі**, оскільки `K_planar = 0`, внутрішні термічні напруження не транслюються в зміну швидкості зсувної хвилі: `ã_SC < 1·10⁻⁷ с/°C`, що забезпечує повну відсутність частотних сплесків при теплових ударах.

### 6. Розклад у ряд Тейлора: кубічна проти параболічної моделі

Відносна зміна частоти `Δf/f₀` у широкому діапазоні температур розкладається в ряд Тейлора за степенями відхилення температури `ΔT = T − T₀`:

```
Δf / f₀ = a₁·(T − T₀) + a₂·(T − T₀)² + a₃·(T − T₀)³ + a₄·(T − T₀)⁴ + ...
```

де `T₀` — температура перегину або вершини (зазвичай обирають `T₀ = 25 °C` для AT/BT або `T₀ = 92 °C` для SC).

#### Розрахунок коефіцієнтів для AT-зрізу (`θ = +35°15′`)

Для ідеально нарізаного AT-зрізу перший коефіцієнт обнуляється (`a₁ = 0`), а другий коефіцієнт біля точки перегину також близький до нуля (`a₂ ≈ 0`). Головну роль відіграє кубічний член:

```
a₁ = 0.0 ppm/°C
a₂ = −0.0004 ppm/°C²
a₃ = +0.000095 ppm/°C³  (або 9.5·10⁻¹¹ / °C³)
```

Підставимо граничні температури промислового діапазону:

```
Для T = −40 °C (ΔT = −65 °C):
Δf/f₀ = 0·(−65) − 0.0004·(−65)² + 0.000095·(−65)³    [підстановка ΔT = −65 °C]
= 0 − 0.0004·4225 + 0.000095·(−274625)               [піднесення до степеня]
= −1.69 ppm − 26.09 ppm                              [множення коефіцієнтів]
= −27.78 ppm                                         [підсумок для −40 °C]

Для T = +85 °C (ΔT = +60 °C):
Δf/f₀ = 0·(+60) − 0.0004·(+60)² + 0.000095·(+60)³    [підстановка ΔT = +60 °C]
= 0 − 0.0004·3600 + 0.000095·216000                 [піднесення до степеня]
= −1.44 ppm + 20.52 ppm                              [множення коефіцієнтів]
= +19.08 ppm                                         [підсумок для +85 °C]
```

Увесь діапазон від −40 °C до +85 °C вкладається у смугу **±28 ppm**.

#### Розрахунок для BT-зрізу (`θ = −49°00′`)

У BT-зрізі друга похідна модуля пружності за температурою є сильно негативною, що формує параболу:

```
a₁ = 0.0 ppm/°C  (при T₀ = 25 °C)
a₂ = −0.040 ppm/°C²
a₃ ≈ 0
```

Розрахунок відхилення:

```
Для T = −40 °C (ΔT = −65 °C):
Δf/f₀ = −0.040 · (−65)²                              [підстановка ΔT = −65 °C]
= −0.040 · 4225                                      [квадрат різниці]
= −169.0 ppm                                         [підсумок для BT при −40 °C]

Для T = +85 °C (ΔT = +60 °C):
Δf/f₀ = −0.040 · (+60)²                              [підстановка ΔT = +60 °C]
= −0.040 · 3600                                      [квадрат різниці]
= −144.0 ppm                                         [підсумок для BT при +85 °C]
```

Похибка BT-зрізу на краях температурного діапазону в 5–6 разів перевищує похибка AT-зрізу.

### 7. Чутливість першого коефіцієнта AT-зрізу до похибки кута нарізки

Якщо кут зрізу пили відхиляється від номіналу `θ₀ = +35°15′` на кутову величину `δθ = θ − θ₀` (вимірюється в кутових мінутах `′`), лінійний коефіцієнт `a₁` перестає дорівнювати нулю.

Чутливість `a₁` до кута описується похідною:

```
da₁ / dθ ≈ −5.08·10⁻⁶ 1/(°C · град)                  [похідна за градусом]
= −8.47·10⁻⁸ 1/(°C · мін)                            [поділ на 60 мінут]
= −0.0847 ppm/(°C · arcmin)                          [переведення в ppm]
```

Якщо кут зрізу зміщено всього на **+2 кутові мінути** (`δθ = +2′`):

```
a₁ = −0.0847 · (+2) = −0.1694 ppm/°C
```

Обчислимо похибку при `T = −40 °C` (`ΔT = −65 °C`) з урахуванням зміщеного кута:

```
Δf/f₀ = a₁·ΔT + a₃·(ΔT)³                             [поліном з кутовим зсувом]
= (−0.1694)·(−65) + 0.000095·(−274625)               [підстановка a₁ та ΔT]
= +11.01 ppm − 26.09 ppm                             [проміжний підсумок]
= −15.08 ppm                                         [результуючий дрейф]
```

А при `T = +85 °C` (`ΔT = +60 °C`):

```
Δf/f₀ = (−0.1694)·(+60) + 0.000095·216000            [підстановка значень]
= −10.16 ppm + 20.52 ppm                             [проміжний підсумок]
= +10.36 ppm                                         [результуючий дрейф]
```

Зсув кута на кілька кутових мінут нахиляє кубічну криву, зсуваючи екстремуми та точку перегину.

### 8. Математика добового відставання годинникових камертонів (32.768 кГц)

Для камертонного резонатора параболічна похибка частоти переводиться в похибку ходу часу за добу (`Δt_day`, секунди) або за рік (`Δt_year`, хвилини):

```
Δt_day = (Δf / f₀) · 86400 с                         [секунд у добі]
Δt_year = (Δf / f₀) · 31536000 с / 60                [хвилин у році]
```

При параболічному коефіцієнті `B = 0.035 ppm/°C²` та вершині `T₀ = 25 °C`:

```
Δf/f₀ = −0.035·10⁻⁶ · (T − 25)²
```

Зведемо залежність відставання годинника від температури експлуатації:

```
При T = 25 °C:
Δf/f₀ = 0 ppm  →  Δt_day = 0.00 с/добу  (0 хв/рік)

При T = 15 °C (ΔT = −10 °C):
Δf/f₀ = −0.035·100 = −3.5 ppm
Δt_day = −3.5·10⁻⁶ · 86400 = −0.302 с/добу  (−1.84 хв/рік)

При T = 0 °C (ΔT = −25 °C):
Δf/f₀ = −0.035·625 = −21.875 ppm
Δt_day = −21.875·10⁻⁶ · 86400 = −1.890 с/добу  (−11.50 хв/рік)

При T = −15 °C (ΔT = −40 °C):
Δf/f₀ = −0.035·1600 = −56.0 ppm
Δt_day = −56.0·10⁻⁶ · 86400 = −4.838 с/добу  (−29.43 хв/рік)
```

### 9. Математична модель частотного підтягування (Frequency Pulling)

Коли до резонатора підключають зовнішню навантажувальну ємність `C_L`, еквівалентна паралельна ємність контуру стає рівною `C₀ + C_L`. Робоча резонансна частота навантаженого кварцу `f_L` розраховується за формулою:

```
f_L = fs · √(1 + C₁ / (C₀ + C_L))
≈ fs · (1 + C₁ / (2·(C₀ + C_L)))                      [наближення першого порядку]
```

Відносне зміщення частоти відносно послідовного резонансу `fs`:

```
(f_L − fs) / fs ≈ C₁ / (2·(C₀ + C_L))
```

Чутливість частоти до зміни навантажувальної ємності (коефіцієнт підтягування `S_L`):

```
S_L = d(Δf/fs) / dC_L
= −C₁ / (2·(C₀ + C_L)²)                               [похідна за ємністю]
```

Для типового AT-кварцу на 16 МГц (`C₁ = 18 фФ`, `C₀ = 4.5 пФ`, `C_L = 18 пФ`):

```
C₀ + C_L = 4.5 + 18.0 = 22.5 пФ                       [сума статичної та навантажувальної ємностей]

(f_L − fs) / fs = 18·10⁻¹⁵ / (2 · 22.5·10⁻¹²)         [підстановка ємностей C1 та (C0+CL)]
= 18 / 45 · 10⁻³ = 0.4·10⁻³ = 400 ppm                [обчислення відносного зміщення]

S_L = −18·10⁻¹⁵ / (2 · (22.5·10⁻¹²)²)                 [підстановка у формулу чутливості]
= −18·10⁻¹⁵ / (2 · 506.25·10⁻²⁴)                      [піднесення знаменника до квадрата]
= −18 / 1012.5 · 10⁹ ≈ −17.78 ppm/пФ                 [кінцева чутливість до ємності]
```

Це означає, що зміна паразитної ємності друкованої плати всього на `0.1 пФ` зміщує робочу частоту генератора на `1.78 ppm`. У резонаторах SC-зрізу динамічна ємність `C₁` значно менша (відношення `r = C₀/C₁ ≈ 600`), що робить їх у 2.5 раза менш чутливими до паразитної нестабільності монтажних ємностей.
