# 🧮 Математична модель поляризації Дебая та комплексного імпедансу

Ця математична вставка містить строге аналітичне виведення частотної дисперсії комплексної діелектричної проникності, рівнянь релаксації Дебая, інтегральних співвідношень Крамерса-Кроніга, міжповерхневої релаксації Максвелла-Вагнера, моделі температурно-часової суперпозиції Вільямса-Ландела-Феррі (WLF), синтезу багатоланкових схем Фостера для SPICE-моделювання, інтеграла розсіяної енергії за один цикл змінного поля та формул точного перерахунку між паралельною та послідовною еквівалентними схемами заміщення конденсатора. Вона призначена для інженерів і дослідників, яким потрібен математичний апарат для моделювання високочастотних діелектричних втрат, розрахунку опору втрат `R_di(ω)` та обчислення теплового розсіювання потужності в колах силової та високочастотної комутації.

### Молекулярна механіка релаксації: співвідношення Стокса-Ейнштейна-Дебая

У діелектричних матеріалах, молекули яких мають несиметричну будову та власний постійний дипольний момент, орієнтація у зовнішньому електричному полі пов'язана з подоланням гідродинамічного або внутрішньокристалічного опору середовища. Кожен молекулярний диполь можна змоделювати як мікроскопічну сферу ефективного гідродинамічного радіуса `r`, яка здійснює обертальний рух у в'язкому оточенні з динамічною в'язкістю `η`.

Обертанню диполя під дією обертального моменту електричного поля протидіє момент сили молекулярного тертя. Згідно з гідродинамічною теорією Стокса та статистичною термодинамікою Ейнштейна, середній характерний час обертальної релаксації молекули визначається формулою Стокса-Ейнштейна-Дебая:

```
τ = (4 · π · η · r³) / (k_B · T)
```

де `k_B = 1.380649·10⁻²³` Дж/К — стала Больцмана, а `T` — абсолютна температура в кельвінах.

Цей вираз безпосередньо розкриває фізичну причину температурної залежності діелектричних втрат:
1. За низьких температур в'язкість середовища `η` зростає, а теплова енергія `k_B·T` зменшується, що призводить до різкого збільшення часу релаксації `τ`. Диполі «замерзають» і втрачають рухливість, через що пік діелектричних втрат зсувається у бік низьких частот;
2. При нагріванні в'язкість падає за експоненційним законом Арреніуса `η(T) = η_0 · exp(E_a / (k_B·T))`, де `E_a` — енергія активації переорієнтації диполя. Час релаксації стрімко зменшується, зміщуючи область інтенсивного поглинання у високочастотний діапазон.

Повна поляризованість діелектрика `P(t)` у будь-який момент часу складається з двох фізичних процесів:
* **Миттєва (пружна) поляризація** `P_∞(t) = ε_0 · (ε_∞ - 1) · E(t)`, зумовлена зсувом електронних хмар та оптичних фононів кристалічної ґратки. Вона встановлюється за час порядку `10⁻¹⁵…10⁻¹⁴` с і в усьому діапазоні радіочастот не створює фазового запізнення;
* **Релаксаційна (орієнтаційна) поляризація** `P_dip(t)`, яка описує поворот полярних молекул або перескоки іонів між локальними мінімумами потенціалу в неоднорідних кристалічних комірках.

Якщо діелектрик тривалий час перебуває в постійному полі `E_0`, у ньому встановлюється термодинамічно рівноважне статичне значення релаксаційної поляризації:

```
P_dip_stat = ε_0 · (ε_s - ε_∞) · E_0
```

де `ε_s` — статична діелектрична проникність на нульовій частоті (DC), а `ε_∞` — оптична діелектрична проникність на нескінченно високій частоті.

Петер Дебай у 1913 році запропонував фундаментальне кінетичне рівняння першого порядку, яке постулює, що швидкість повернення поляризованості до рівноваги пропорційна величині поточного відхилення:

```
dP_dip(t) / dt = ( P_dip_stat(t) - P_dip(t) ) / τ
```

Перепишемо його у формі лінійного диференціального рівняння:

```
τ · (dP_dip(t) / dt) + P_dip(t) = ε_0 · (ε_s - ε_∞) · E(t)
```

### Фур'є-образ та виведення частотної залежності проникності

Нехай прикладене електричне поле змінюється за гармонічним законом: `E(t) = E_0 · exp(j·ω·t)`. Шукаємо усталений розв'язок для релаксаційної поляризації у вигляді гармонічного коливання тієї ж частоти: `P_dip(t) = P_dip_0 · exp(j·ω·t)`.

Обчислимо часову похідну `dP_dip / dt = j·ω·P_dip(t)` і підставимо її в диференціальне рівняння:

```
τ · (j·ω·P_dip_0 · exp(j·ω·t)) + P_dip_0 · exp(j·ω·t)
= ε_0 · (ε_s - ε_∞) · E_0 · exp(j·ω·t)       [підстановка гармонічного сигналу]

P_dip_0 · (1 + j·ω·τ)
= ε_0 · (ε_s - ε_∞) · E_0                     [скорочення на exp(j·ω·t)]

P_dip_0
= ε_0 · (ε_s - ε_∞) · E_0 / (1 + j·ω·τ)        [вираз для комплексної амплітуди]
```

Вектор електричного зміщення `D(t)` у середовищі визначається сумою вакуумного зсуву та повної поляризації:

```
D(t) = ε_0 · E(t) + P(t) = ε_0 · E(t) + P_∞(t) + P_dip(t)
```

Підставимо отримані компоненти поляризації:

```
D(t)
= ε_0 · E(t) + ε_0 · (ε_∞ - 1) · E(t) + ε_0 · (ε_s - ε_∞) · E(t) / (1 + j·ω·τ)
= ε_0 · ε_∞ · E(t) + ε_0 · (ε_s - ε_∞) · E(t) / (1 + j·ω·τ)
= ε_0 · [ ε_∞ + (ε_s - ε_∞) / (1 + j·ω·τ) ] · E(t)    [винесення ε_0 · E(t)]
```

З матеріального рівняння електродинаміки `D(t) = ε_0 · ε*(ω) · E(t)` отримуємо класичну **функцію дисперсії Дебая**:

```
ε*(ω) = ε_∞ + (ε_s - ε_∞) / (1 + j·ω·τ)
```

### Розділення дійсної та уявної частин комплексної проникності

Комплексна діелектрична проникність записується через дійсну та уявну складові:

```
ε*(ω) = ε'(ω) - j·ε''(ω)
```

де `ε'(ω)` описує зворотне накопичення енергії електричного поля, а `ε''(ω)` — необоротну дисипацію енергії в тепло.

Домножимо дріб у виразі Дебая на комплексно-спряжений знаменник `(1 - j·ω·τ)`:

```
(ε_s - ε_∞) / (1 + j·ω·τ)
= (ε_s - ε_∞) · (1 - j·ω·τ) / [ (1 + j·ω·τ) · (1 - j·ω·τ) ]
= (ε_s - ε_∞) · (1 - j·ω·τ) / (1 + ω²·τ²)       [розкриття різниці квадратів j² = −1]
= (ε_s - ε_∞) / (1 + ω²·τ²) - j · [ (ε_s - ε_∞) · ω · τ / (1 + ω²·τ²) ]
```

Звідси випливають строгі формули Дебая для компонентів проникності:

```
ε'(ω) = ε_∞ + (ε_s - ε_∞) / (1 + ω²·τ²)          [дійсна частина проникності]
ε''(ω) = (ε_s - ε_∞) · ω · τ / (1 + ω²·τ²)      [коефіцієнт діелектричних втрат]
```

Тангенс кута діелектричних втрат `tan(δ)` розраховується як відношення розсіяної потужності до реактивної:

```
tan(δ) = ε''(ω) / ε'(ω)
       = [ (ε_s - ε_∞) · ω · τ / (1 + ω²·τ²) ] / [ ε_∞ + (ε_s - ε_∞) / (1 + ω²·τ²) ]
       = (ε_s - ε_∞) · ω · τ / [ ε_s + ε_∞ · ω² · τ² ]    [після домноження на (1 + ω²·τ²)]
```

### Співвідношення Крамерса-Кроніга та принцип причинності

Фундаментальний зв'язок між дійсною частиною діелектричної проникності `ε'(ω)` (накопичення енергії) та уявною частиною `ε''(ω)` (дисипація енергії) диктується принципом фізичної причинності. Відгук поляризації `P(t)` у середовищі не може випередити прикладене електричне поле `E(t)`:

```
P(t) = ε_0 · ∫[0..∞] χ_e(u) · E(t - u) du
```

де `χ_e(u)` — дійсна функція часового відгуку діелектрика, яка тотожно дорівнює нулю при `u < 0`.

Завдяки аналітичності комплексної сприйнятливості `χ*(ω)` у верхній півплощині комплексної частоти, дійсна та уявна частини комплексної діелектричної проникності пов'язані парою інтегральних перетворень Гільберта, які в електродинаміці називають **співвідношеннями Крамерса-Кроніга**:

```
ε'(ω) - ε_∞ = (2 / π) · P ∫[0..∞] ( s · ε''(s) ) / ( s² - ω² ) ds
ε''(ω) = -(2 · ω / π) · P ∫[0..∞] ( ε'(s) - ε_∞ ) / ( s² - ω² ) ds
```

де символ `P` позначає інтеграл у сенсі головного значення за Коші.

Зі співвідношень Крамерса-Кроніга випливають важливі фізичні наслідки:
1. **Неможливість безвтратної дисперсії**: Будь-яка зміна діелектричної проникності `ε'(ω)` за частотою неминуче супроводжується появою піка діелектричних втрат `ε''(ω)` у цій частотній області. Створити діелектрик зі стрибком ємності без супутніх втрат енергії фізично неможливо;
2. **Інтегральне правило сум**: Повна площа під кривою діелектричних втрат у логарифмічному масштабі частоти однозначно визначає повний стрибок статичної проникності:

```
∫[0..∞] ( ε''(ω) / ω ) dω = (π / 2) · (ε_s - ε_∞)
```

### Температурно-часова суперпозиція та модель Вільямса-Ландела-Феррі

У полімерних діелектриках (поліпропілен PP, поліетилентерефталат PET, полістирол) молекулярні ланцюги демонструють складний кооперативний рух сегментів. Поблизу температури склування `T_g` залежність часу релаксації від температури перестає описуватися простим законом Арреніуса і підпорядковується рівнянню Вільямса-Ландела-Феррі (WLF-модель):

```
log10( a_T ) = -C_1 · ( T - T_ref ) / ( C_2 + ( T - T_ref ) )
```

де:
* `a_T = τ(T) / τ(T_ref)` — коефіцієнт температурного зсуву частотної шкали;
* `T_ref` — опорна температура вимірювання (зазвичай береться близькою до `T_g`);
* `C_1, C_2` — універсальні константи матеріалу (для більшості аморфних полімерів `C_1 ≈ 17.4`, `C_2 ≈ 51.6` К).

Принцип температурно-часової суперпозиції дозволяє інженерам перераховувати вимірювання діелектричних втрат: підвищення температури еквівалентне зсуву частотної характеристики в область вищих частот. Це дає змогу будувати так звані узагальнені «майстер-криві» втрат діелектрика у діапазоні до 12 декад частоти на основі серії вимірювань за різних температур.

### Розділення провіднісних та релаксаційних втрат

У загальному випадку струм втрат у діелектрику містить не лише релаксаційне молекулярне тертя диполів `ε''_dip(ω)`, а й джоулеві втрати на наскрізну статичну електропровідність вільних носіїв заряду `σ_DC`:

```
ε''_total(ω) = ε''_dip(ω) + σ_DC / ( ε_0 · ω )
```

Звідси повний тангенс кута втрат конденсатора складається з двох доданків:

```
tan(δ_total) = tan(δ_dip) + σ_DC / ( ε_0 · ε'(ω) · ω )
```

На низьких частотах (менше 100 Гц) доданок наскрізної провідності `σ_DC / ω` може домінувати, тоді як на радіочастотах понад 100 кГц вирішальну роль відіграє релаксаційна складова `tan(δ_dip)`.

### Міжповерхнева поляризація Максвелла-Вагнера

У реальних гетерогенних діелектриках — багатошаровій кераміці з провідними межами зерен, пористих плівках та оксидних шарах електролітичних конденсаторів — виникає релаксація за рахунок накопичення вільних зарядів на межах розділу двох середовищ із різними питомими провідностями `σ_1, σ_2` та проникностями `ε_1, ε_2`.

Розглянемо двошаровий конденсатор товщинами шарів `d_1, d_2`. Комплексні питомі провідності кожного шару дорівнюють `σ_k* = σ_k + j·ω·ε_0·ε_k`. Повний імпеданс структури являє собою послідовне з'єднання двох паралельних RC-ланок:

```
Z_MW(ω) = ( d_1 / S ) / ( σ_1 + j·ω·ε_0·ε_1 ) + ( d_2 / S ) / ( σ_2 + j·ω·ε_0·ε_2 )
```

Звідси еквівалентна комплексна діелектрична проникність структури точно відповідає формулі Дебая:

```
ε_MW*(ω) = ε_∞_MW + (ε_s_MW - ε_∞_MW) / ( 1 + j·ω·τ_MW )
```

де ефективний час релаксації Максвелла-Вагнера визначається співвідношенням товщин та провідностей:

```
τ_MW = ε_0 · ( ε_1·d_2 + ε_2·d_1 ) / ( σ_1·d_2 + σ_2·d_1 )
```

Оскільки провідності шарів `σ_1, σ_2` порівняно малі, час релаксації `τ_MW` становить від мілісекунд до сотень секунд. Це породжує гігантське зростання діелектричних втрат та уявне збільшення ємності на низьких інфразвукових частотах (0.1–100 Гц).

### Синтез еквівалентних схем Фостера для SPICE-моделювання

Для точного моделювання діелектричних втрат у схемотехнічних симуляторах (LTspice, SPICE, ADS) частотно-залежну функцію Дебая апроксимують багатоланковою еквівалентною схемою Фостера.

Якщо матеріал описується сумою `N` незалежних релаксаційних мод із часами `τ_k` та кроками проникності `Δε_k = ε_s_k - ε_∞_k`, повна ємність конденсатора представляється як паралельне з'єднання високочастотної базової ємності `C_∞` та `N` послідовних `R_k - C_k` гілок:

```
C_∞ = ε_0 · ε_∞ · (S / d)
C_k = ε_0 · Δε_k · (S / d)                     [ємність релаксаційної гілки]
R_k = τ_k / C_k = τ_k / ( ε_0 · Δε_k · (S / d) ) [опір молекулярного тертя]
```

Повний адмітанс такої схеми заміщення у частотній області:

```
Y_Foster(ω) = j · ω · C_∞ + ∑ [ ( j · ω · C_k ) / ( 1 + j · ω · R_k · C_k ) ]
```

Кожна пара `R_k - C_k` створює один локальний пік діелектричних втрат на частоті `f_k = 1 / (2·π·R_k·C_k)`. Поєднуючи від 3 до 5 таких ланок із логарифмічно розподіленими часами `τ_k`, інженер отримує надзвичайно точну SPICE-модель, яка відтворює як частотну зміну ємності, так і плато ESR у діапазоні від 10 Гц до 1 ГГц.

### Аналіз екстремумів та точка максимального поглинання

Дослідимо функцію діелектричних втрат `ε''(ω)` на екстремум за частотою. Для цього візьмемо похідну за безрозмірним параметром `(ω·τ)` і прирівняємо її до нуля:

```
d(ε'') / d(ω·τ) = (ε_s - ε_∞) · [ (1 + (ω·τ)²) - (ω·τ) · 2·(ω·τ) ] / (1 + (ω·τ)²)²
                = (ε_s - ε_∞) · (1 - (ω·τ)²) / (1 + (ω·τ)²)² = 0
```

Екстремум досягається при виконанні умови:

```
1 - (ω·τ)² = 0
ω_max · τ = 1
ω_max = 1 / τ
f_max = 1 / (2 · π · τ)                         [частота максимуму діелектричних втрат]
```

Підставивши значення `ω_max = 1 / τ` у вирази для `ε'` та `ε''`, отримуємо координати точки релаксаційного максимуму:

```
ε'(ω_max) = ε_∞ + (ε_s - ε_∞) / 2 = (ε_s + ε_∞) / 2
ε''(ω_max) = (ε_s - ε_∞) / 2                    [максимальне значення коефіцієнта втрат]
```

Фізичний зміст цієї точки полягає в тому, що коли період коливань зовнішнього поля точно збігається з часом життя орієнтованого стану молекули `T_field = 2·π·τ`, диполі поглинають максимальну потужність від генератора, оскільки швидкість їхнього вимушеного обертання перебуває у фазовому резонансі з тертям середовища.

### Діаграма Коула-Коула та узагальнені моделі релаксації

Якщо побудувати залежність уявної частини проникності `ε''(ω)` від дійсної частини `ε'(ω)` на площині в параметричному вигляді за частотою `ω`, модель Дебая описує ідеальне півколо з центром на дійсній осі:

```
( ε' - (ε_s + ε_∞)/2 )² + ( ε'' )² = ( (ε_s - ε_∞)/2 )²
```

Центр півкола розташований у точці `((ε_s + ε_∞)/2, 0)`, а його радіус дорівнює `(ε_s - ε_∞)/2`.

У реальних конденсованих діелектриках локальне мікрооточення різних диполів відрізняється через аморфність матриці, дефекти ґратки та взаємодію між сусідніми молекулами. Це породжує неперервний спектр часів релаксації. Для точного моделювання реальних матеріалів використовують феноменологічні рівняння:

1. **Модель Коула-Коула (Cole-Cole, 1941)**:
   Описує симетричне розширення піку втрат у сегнетокераміці (X7R) та полімерах:
   ```
   ε*(ω) = ε_∞ + (ε_s - ε_∞) / ( 1 + (j · ω · τ_0)^(1 - α) )
   ```
   де `α ∈ [0, 1)` — параметр депресії; центр півкола на діаграмі опускається нижче дійсної осі на кут `α · π / 2`.

2. **Модель Коула-Девідсона (Cole-Davidson, 1951)**:
   Описує асиметричне розширення піку втрат у високомолекулярних рідинах та електролітах:
   ```
   ε*(ω) = ε_∞ + (ε_s - ε_∞) / ( 1 + j · ω · τ_0 )^β
   ```
   де `β ∈ (0, 1]` — коефіцієнт асиметрії, що відображає наявність повільних кооперативних процесів перебудови структури.

3. **Модель Гавріляка-Негамі (Havriliak-Negami, 1966)**:
   Поєднує обидва підходи в універсальний п'ятипараметричний закон:
   ```
   ε*(ω) = ε_∞ + (ε_s - ε_∞) / [ 1 + (j · ω · τ_0)^(1 - α) ]^β
   ```

### Розрахунок енергії розсіювання за період змінного поля

Обчислимо об'ємну густину енергії `w`, яка необоротно перетворюється на тепло всередині діелектрика за один повний період коливань електричного поля `T = 2·π / ω`.

Нехай дійсне електричне поле змінюється як `E(t) = E_0 · cos(ω·t)`. Вектор електричного зміщення відстає за фазою на кут `δ`:

```
D(t) = D_0 · cos(ω·t - δ)
```

де `D_0 = ε_0 · |ε*| · E_0 = ε_0 · √(ε'² + ε''²) · E_0`.

Елементарна робота поля над діелектриком за час `dt` дорівнює:

```
dw = E · dD = E(t) · (dD/dt) · dt
```

Обчислимо похідну від вектора зміщення:

```
dD/dt = -ω · D_0 · sin(ω·t - δ)
      = -ω · D_0 · [ sin(ω·t)·cos(δ) - cos(ω·t)·sin(δ) ]
```

Інтегруємо роботу за повний період `T = 2·π/ω`:

```
w = ∫[0..T] E(t) · (dD/dt) dt
  = -ω · E_0 · D_0 · ∫[0..T] cos(ω·t) · [ sin(ω·t)·cos(δ) - cos(ω·t)·sin(δ) ] dt
```

Розглянемо два інтеграли окремо:
1. `∫[0..T] cos(ω·t) · sin(ω·t) dt = (1/2) · ∫[0..T] sin(2·ω·t) dt = 0` (інтеграл від синуса подвійної частоти за цілий період дорівнює нулю — це реактивна складова енергії, яка повертається в джерело живлення).
2. `∫[0..T] cos²(ω·t) dt = T / 2 = π / ω`.

Підставивши значення другого інтеграла, маємо:

```
w = ω · E_0 · D_0 · sin(δ) · (π / ω)
  = π · E_0 · D_0 · sin(δ)                      [втрачена енергія за один цикл на одиницю об'єму]
```

Оскільки `D_0 · sin(δ) = ε_0 · ε'' · E_0`, підставимо його:

```
w = π · ε_0 · ε'' · E_0²
```

Середня питома потужність діелектричних втрат `p_v` (потужність на одиницю об'єму діелектрика в Вт/м³):

```
p_v = w / T = (w · ω) / (2 · π)                [потужність за період Т = 2·π/ω]
    = (π · ε_0 · ε'' · E_0² · ω) / (2 · π)     [підстановка розсіяної енергії w]
    = (1/2) · ω · ε_0 · ε'' · E_0²             [скорочення спільних множників]
```

Якщо виразити через діюче (RMS) значення напруженості поля `E_rms = E_0 / √2`:

```
p_v = ω · ε_0 · ε'' · E_rms² = ω · ε_0 · ε' · tan(δ) · E_rms²
```

Повна потужність діелектричних втрат у конденсаторі об'ємом `V = S · d`:

```
P_di = p_v · V = ω · ε_0 · ε' · tan(δ) · (U_rms / d)² · (S · d)
     = ω · [ ε_0 · ε' · (S / d) ] · tan(δ) · U_rms²
     = ω · C · tan(δ) · U_rms²                 [загальна формула діелектричних втрат]
```

### Точний перерахунок між паралельною та послідовною схемами заміщення

Неідеальний конденсатор на фіксованій частоті `ω` можна еквівалентно представити двома способами:
1. **Паралельна схема**: ідеальна ємність `C_p`, паралельно з якою увімкнено опір втрат `R_p`.
2. **Послідовна схема**: еквівалентна послідовна ємність `C_s`, послідовно з якою увімкнено опір `R_s` (який і є `ESR`).

```
Y = 1 / R_p + j · ω · C_p = G_p + j · B_p      [паралельний адмітанс]
Z = R_s + 1 / (j · ω · C_s) = R_s - j / (ω · C_s) [послідовний імпеданс]
```

Оскільки обидві моделі описують один і той самий фізичний двополюсник, має виконуватися тотожність `Z = 1 / Y`:

```
R_s - j / (ω · C_s)
= 1 / [ 1/R_p + j · ω · C_p ]
= [ 1/R_p - j · ω · C_p ] / [ (1/R_p)² + (ω · C_p)² ]    [домноження на спряжене]
```

Прирівняємо дійсні та уявні частини:

```
R_s = (1 / R_p) / [ 1/R_p² + ω² · C_p² ]
    = R_p / [ 1 + (ω · C_p · R_p)² ]           [домноження чисельника й знаменника на R_p²]

1 / (ω · C_s) = (ω · C_p) / [ 1/R_p² + ω² · C_p² ]
              = (ω · C_p · R_p²) / [ 1 + (ω · C_p · R_p)² ]
```

Визначимо добротність паралельного контуру `Q` та тангенс кута втрат `tan(δ)`:

```
Q = ω · C_p · R_p = 1 / tan(δ)
```

Підставимо `Q` у вирази для компонентів послідовної схеми:

```
R_s = R_p / (1 + Q²) = R_p · tan²(δ) / (1 + tan²(δ))
C_s = C_p · (1 + 1 / Q²) = C_p · (1 + tan²(δ))
```

Для високоякісних конденсаторів (плівкові, керамічні C0G/X7R), де `tan(δ) < 0.05` (а отже `Q > 20`), величина `tan²(δ) < 0.0025`. Тому з високою точністю (похибка менше 0.25%) справедливі наближення:

```
C_s ≈ C_p = C
R_s = R_p / Q² = R_p · tan²(δ) = (1 / (ω · C · Q)) · tan(δ)
    = tan(δ) / (ω · C)                          [еквівалентний послідовний опір діелектрика]
```

Звідси отримуємо строгий зв'язок:

```
R_di(ω) = tan(δ) / (ω · C)
```

### Універсальний динамічний відгук Йоншера (UDR)

У багатьох невпорядкованих діелектриках (аморфні оксиди, напівпровідникові кераміки та іонні провідники) міграція носіїв заряду відбувається шляхом стрибкової провідності між локалізованими станами (Hopping Conduction). Анджей Йоншер (Andrew Jonscher, 1977) експериментально встановив, що дійсна питома провідність змінного струму `σ_AC(ω) = ω · ε_0 · ε''(ω)` у надзвичайно широкому діапазоні частот підпорядковується універсальному степеневому закону:

```
σ_AC(ω) = σ_DC + A · ω^n
```

де:
* `σ_DC` — провідність на постійному струмі (наскрізний витік);
* `A` — температурно-залежний коефіцієнт поляризаційної взаємодії;
* `n ∈ (0, 1)` — дробовий степеневий показник (зазвичай `n ≈ 0.6…0.85`), що відображає ступінь просторової кореляції та енергетичного безладу в діелектричній матриці.

Зі співвідношень Крамерса-Кроніга для закону Йоншера безпосередньо випливає, що відношення уявної частини проникності до дійсної частини сприйнятливості стає частотно-незалежною константою:

```
ε''(ω) / ( ε'(ω) - ε_∞ ) = cot( n · π / 2 )
```

Це пояснює, чому в багатьох промислових сегнетокерамічних конденсаторах (X7R, Y5V) та електролітичних оксидних шарах тангенс кута втрат `tan(δ)` залишається майже сталим або змінюється дуже плавно протягом кількох декад частоти замість різкого вузького піку, передбачуваного простою однополюсною моделлю Дебая.

```c
#include <stdio.h>
#include <math.h>

#define EPS_0 8.8541878128e-12

typedef struct {
    double eps_s;      // Статична проникність
    double eps_inf;    // Оптична проникність
    double tau;        // Час релаксації (с)
    double c_nom;      // Номінальна ємність (Ф)
    double r_dc;       // Омічний опір металу на DC (Ом)
    double k_skin;     // Коефіцієнт скін-ефекту (Ом/sqrt(Гц))
} DielectricModel;

typedef struct {
    double f;          // Частота (Гц)
    double eps_real;   // Дійсна проникність eps'
    double eps_imag;   // Уявна проникність eps''
    double tan_delta;  // Тангенс кута втрат
    double r_di;       // Діелектричний опір втрат (Ом)
    double r_ohm;      // Омічний опір металу зі скін-ефектом (Ом)
    double esr;        // Сумарний ESR (Ом)
    double q_factor;   // Добротність Q
} CapacitorMetrics;

CapacitorMetrics compute_losses(const DielectricModel *m, double freq_hz) {
    CapacitorMetrics res;
    res.f = freq_hz;

    double omega = 2.0 * M_PI * freq_hz;
    double wt = omega * m->tau;
    double wt_sq = wt * wt;

    // Формули Дебая
    res.eps_real = m->eps_inf + (m->eps_s - m->eps_inf) / (1.0 + wt_sq);
    res.eps_imag = (m->eps_s - m->eps_inf) * wt / (1.0 + wt_sq);
    res.tan_delta = res.eps_imag / res.eps_real;

    // Розрахунок опорів
    res.r_di = res.tan_delta / (omega * m->c_nom);
    res.r_ohm = m->r_dc + m->k_skin * sqrt(freq_hz);
    res.esr = res.r_di + res.r_ohm;
    res.q_factor = 1.0 / res.tan_delta;

    return res;
}

int main(void) {
    DielectricModel x7r = {
        .eps_s = 2200.0,
        .eps_inf = 120.0,
        .tau = 1.5e-8,       // 15 нс (релаксація доменів)
        .c_nom = 100e-9,     // 100 нФ
        .r_dc = 0.012,       // 12 мОм
        .k_skin = 1.2e-6     // скін-ефект у тонких електродах
    };

    double test_freqs[] = {1e2, 1e3, 1e4, 1e5, 1e6, 1e7};
    printf("Частота (Гц) | eps'    | eps''   | tan(delta) | R_di (Ом)  | ESR (Ом)   | Q\n");
    printf("-------------+---------+---------+------------+------------+------------+-------\n");

    for (int i = 0; i < 6; ++i) {
        CapacitorMetrics met = compute_losses(&x7r, test_freqs[i]);
        printf("%12.0f | %7.1f | %7.2f | %10.5f | %10.5f | %10.5f | %7.1f\n",
               met.f, met.eps_real, met.eps_imag, met.tan_delta, met.r_di, met.esr, met.q_factor);
    }
    return 0;
}
```

```cpp
#include <iostream>
#include <iomanip>
#include <vector>
#include <numbers>
#include <cmath>

struct DielectricModel {
    double eps_s{2200.0};      // Статична проникність
    double eps_inf{120.0};     // Оптична проникність
    double tau{1.5e-8};        // Час релаксації (с)
    double c_nom{100e-9};      // Номінальна ємність (Ф)
    double r_dc{0.012};        // Омічний опір металу на DC (Ом)
    double k_skin{1.2e-6};     // Коефіцієнт скін-ефекту (Ом/sqrt(Гц))
};

struct CapacitorMetrics {
    double f{};
    double eps_real{};
    double eps_imag{};
    double tan_delta{};
    double r_di{};
    double r_ohm{};
    double esr{};
    double q_factor{};
};

class DebyeLossCalculator {
public:
    explicit DebyeLossCalculator(DielectricModel model) : model_{model} {}

    [[nodiscard]] CapacitorMetrics compute(double freq_hz) const noexcept {
        CapacitorMetrics res{};
        res.f = freq_hz;

        const double omega = 2.0 * std::numbers::pi * freq_hz;
        const double wt = omega * model_.tau;
        const double wt_sq = wt * wt;

        // Формули Дебая
        res.eps_real = model_.eps_inf + (model_.eps_s - model_.eps_inf) / (1.0 + wt_sq);
        res.eps_imag = (model_.eps_s - model_.eps_inf) * wt / (1.0 + wt_sq);
        res.tan_delta = res.eps_imag / res.eps_real;

        // Розрахунок опорів
        res.r_di = res.tan_delta / (omega * model_.c_nom);
        res.r_ohm = model_.r_dc + model_.k_skin * std::sqrt(freq_hz);
        res.esr = res.r_di + res.r_ohm;
        res.q_factor = 1.0 / res.tan_delta;

        return res;
    }

private:
    DielectricModel model_;
};

int main() {
    const DielectricModel x7r_model{
        .eps_s = 2200.0,
        .eps_inf = 120.0,
        .tau = 1.5e-8,
        .c_nom = 100e-9,
        .r_dc = 0.012,
        .k_skin = 1.2e-6
    };

    const DebyeLossCalculator calc{x7r_model};
    const std::vector<double> test_freqs{1e2, 1e3, 1e4, 1e5, 1e6, 1e7};

    std::cout << std::left
              << std::setw(14) << "Частота (Гц)"
              << std::setw(10) << "eps'"
              << std::setw(10) << "eps''"
              << std::setw(13) << "tan(delta)"
              << std::setw(13) << "R_di (Ом)"
              << std::setw(13) << "ESR (Ом)"
              << "Q\n";
    std::cout << std::string(80, '-') << "\n";

    for (const double f : test_freqs) {
        const auto m = calc.compute(f);
        std::cout << std::left << std::fixed
                  << std::setw(14) << std::setprecision(0) << m.f
                  << std::setw(10) << std::setprecision(1) << m.eps_real
                  << std::setw(10) << std::setprecision(2) << m.eps_imag
                  << std::setw(13) << std::setprecision(5) << m.tan_delta
                  << std::setw(13) << std::setprecision(5) << m.r_di
                  << std::setw(13) << std::setprecision(5) << m.esr
                  << std::setprecision(1) << m.q_factor << "\n";
    }

    return 0;
}
```

### Підсумкова таблиця фізико-математичних тотожностей

| Величина | Формула в моделі Дебая | Фізичний зміст |
| :--- | :--- | :--- |
| Комплексна проникність `ε*(ω)` | `ε_∞ + (ε_s - ε_∞) / (1 + j·ω·τ)` | Повний динамічний відгук поляризації |
| Дійсна проникність `ε'(ω)` | `ε_∞ + (ε_s - ε_∞) / (1 + ω²·τ²)` | Енергоємність (визначає ємність `C`) |
| Коефіцієнт втрат `ε''(ω)` | `(ε_s - ε_∞)·ω·τ / (1 + ω²·τ²)` | Інтенсивність дисипації енергії в тепло |
| Тангенс кута втрат `tan(δ)` | `ε''(ω) / ε'(ω)` | Співвідношення потужності втрат до реактивної |
| Опір діелектричних втрат `R_di` | `tan(δ) / (ω · C)` | Послідовний еквівалент діелектричного тертя |
| Об'ємні втрати потужності `p_v` | `ω · ε_0 · ε' · tan(δ) · E_rms²` | Густина тепловиділення в діелектрику (Вт/м³) |
