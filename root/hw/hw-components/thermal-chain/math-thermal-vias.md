# 🧮 Тепловий розрахунок масиву перехідних отворів і розтікання тепла в платі

Перехідні отвори під термопадами SMD-компонентів є єдиним каналом скидання тепла від гарячого напівпровідника до внутрішніх шарів заземлення та зворотного боку плати. Без точного розрахунку їхньої геометрії та розтікання тепла в тонкій мідній фользі інженер або закладає недостатню кількість отворів і отримує локальний перегрів кристала, або робить отвори надто великими, через що припій витікає всередину гільз під час паяння, утворюючи теплоізолювальні порожнечі під чипом.

Тут наведено строгий аналітичний розрахунок теплового опору окремої перехідної гільзи, еквівалентного опору масиву отворів, а також радіального розтікання теплового потоку в тонких мідних полігонах друкованої плати.

---

### 1. Геометрія та тепловий опір одиничного перехідного отвору

Перехідний отвір у друкованій платі являє собою циліндричний канал у діелектрику FR-4, внутрішня поверхня якого вкрита тонким шаром гальванічної міді товщиною `t_cu`.

Тепловий потік тече вздовж осі циліндра від верхнього мідного майданчика (top copper pad) до нижнього шару або внутрішнього полігону заземлення крізь діелектричну основу товщиною `h_pcb`.

Параметри одиничного перехідного отвору:
- `d_drill` — діаметр свердління (зовнішній діаметр мідної гільзи);
- `t_cu` — товщина осадженої гальванічної міді на стінках гільзи (стандарт IPC-6012 Class 2 задає мінімум 20 мкм, типово 25 мкм, для важкої міді — 35 мкм);
- `d_in = d_drill - 2 · t_cu` — внутрішній діаметр порожнини отвору;
- `h_pcb` — висота гільзи, що дорівнює товщині друкованої плати (типово 1.6 мм для стандартних 4-шарових плат, або 0.8–1.0 мм для компактних модулів);
- `k_cu` — коефіцієнт теплопровідності гальванічної міді (становить приблизно `385 Вт/(м·К)` при 25 °C і знижується до `375 Вт/(м·К)` при 100 °C).

Площа поперечного перерізу мідного кільця гільзи `A_cu` виводиться як різниця площ зовнішнього та внутрішнього циліндрів:

```
A_cu = π · (d_drill² - d_in²) / 4                               [площа кільцевого перерізу]
     = π · (d_drill² - (d_drill - 2·t_cu)²) / 4                 [підстановка внутрішнього діаметра]
     = π · (d_drill² - (d_drill² - 4·d_drill·t_cu + 4·t_cu²)) / 4 [розкриття квадрата різниці]
     = π · (4·d_drill·t_cu - 4·t_cu²) / 4                       [скорочення d_drill²]
     = π · t_cu · (d_drill - t_cu)                              [винесення спільного множника]
```

За законом Фур'є тепловий опір мідної гільзи `R_via_cu` [°C/Вт або K/Вт] обчислюється як опір одновимірного провідника постійного перерізу:

```
R_via_cu = h_pcb / (k_cu · A_cu)                                [закон Фур'є для циліндричної стінки]
         = h_pcb / (k_cu · π · t_cu · (d_drill - t_cu))         [підстановка площі перерізу міді]
```

#### Внесок заповнення отвору (припій проти повітря)

Якщо перехідний отвір не замасковано паяльною маскою, під час оплавлення паяльної пасти частина припою затягується в отвір за рахунок капілярних сил.

Коефіцієнт теплопровідності безсвинцевого припою SAC305 становить `k_solder ≈ 58 Вт/(м·К)`. Переріз серцевини припою `A_solder = π · d_in² / 4`.

Тепловий опір серцевини з припою `R_via_solder`:

```
R_via_solder = h_pcb / (k_solder · A_solder)                    [закон Фур'є для серцевини]
             = 4 · h_pcb / (k_solder · π · d_in²)               [вираз через внутрішній діаметр]
```

Оскільки мідна стінка та серцевина з припою з'єднані паралельно між тими самими температурними площинами, повний тепловий опір одиничного заповненого отвору `R_via_filled`:

```
1 / R_via_filled = (1 / R_via_cu) + (1 / R_via_solder)          [паралельне з'єднання провідностей]
R_via_filled     = (R_via_cu · R_via_solder) / (R_via_cu + R_via_solder) [еквівалентний тепловий опір]
```

#### Числовий розрахунок для типового отвору 0.3 мм

Візьмемо стандартні виробничі параметри:
- Товщина плати `h_pcb = 1.6 мм = 1.6 × 10⁻³ м`;
- Діаметр свердління `d_drill = 0.3 мм = 0.3 × 10⁻³ м`;
- Товщина міді `t_cu = 25 мкм = 25 × 10⁻⁶ м`;
- `k_cu = 385 Вт/(м·К)`;
- `k_solder = 58 Вт/(м·К)`.

Геометрія перерізу:
```
d_in = 0.30 - 2 · 0.025                                         [віднімання двох товщин стінки]
     = 0.25 мм                                                  [внутрішній просвіт отвору]

A_cu = π · 25×10⁻⁶ · (300×10⁻⁶ - 25×10⁻⁶)                       [підстановка чисел у формулу кільця]
     = π · 25×10⁻⁶ · 275×10⁻⁶                                   [множення різниці діаметрів]
     = 2.1598 × 10⁻⁸ м²                                         [площа мідної гільзи в м²]
     = 0.0216 мм²                                               [площа міді у квадратних міліметрах]

A_solder = π · (0.25×10⁻³)² / 4                                 [площа круга внутрішнього просвіту]
         = 4.9087 × 10⁻⁸ м²                                     [площа серцевини припою в м²]
         = 0.0491 мм²                                           [площа серцевини у мм²]
```

Тепловий опір мідної гільзи:
```
R_via_cu = 1.6 × 10⁻³ / (385 · 2.1598 × 10⁻⁸)                   [підстановка геометрії та теплопровідності]
         = 1.6 × 10⁻³ / 8.3152 × 10⁻⁶                           [обчислення знаменника провідності]
         = 192.4 °C/Вт                                          [опір лише порожньої мідної гільзи]
```

Тепловий опір припою всередині гільзи:
```
R_via_solder = 1.6 × 10⁻³ / (58 · 4.9087 × 10⁻⁸)                [підстановка параметрів припою SAC305]
             = 1.6 × 10⁻³ / 2.8470 × 10⁻⁶                       [обчислення теплової провідності припою]
             = 562.0 °C/Вт                                      [опір суцільного стовпчика припою]
```

Еквівалентний опір заповненого отвору:
```
R_via_filled = (192.4 · 562.0) / (192.4 + 562.0)                [формула паралельних опорів]
             = 108128.8 / 754.4                                 [ділення добутку на суму]
             = 143.3 °C/Вт                                      [зменшення опору на 25.5% завдяки припою]
```

Один перехідний отвір має тепловий опір порядку 140–190 °C/Вт. При розсіюванні потужності в 2–5 Вт один перехід створив би неприпустимий перегрів у сотні градусів, тому тепловідведення реалізують масивом паралельних отворів.

#### Залежність опору від товщини плати та типу матеріалу

Товщина діелектрика визначає довжину вертикального теплового каналу. Порівняємо тепловий опір одиничного заповненого отвору `d = 0.3 мм` для різних конфігурацій плат:

| Товщина плати `h_pcb` | Тип плати та застосування | Опір гільзи `R_via_cu` | Опір із припоєм `R_via_filled` |
|---|---|---|---|
| `0.8 мм` | 2-шарові або 4-шарові тонкі модулі | `96.2 °C/Вт` | `71.7 °C/Вт` |
| `1.0 мм` | Компактні високочастотні пристрої | `120.3 °C/Вт` | `89.6 °C/Вт` |
| `1.6 мм` | Стандартні промислові 4-шарові плати | `192.4 °C/Вт` | `143.3 °C/Вт` |
| `2.4 мм` | Багатошарові силові обчислювальні плати | `288.6 °C/Вт` | `215.0 °C/Вт` |

Зменшення товщини плати з 1.6 мм до 0.8 мм знижує опір перехідного отвору рівно вдвічі, що робить тонкі плати значно ефективнішими для SMD-компонентів із двостороннім охолодженням.

### 2. Еквівалентний опір масиву перехідних отворів

Коли під тепловідвідним майданчиком чипа розміщено регулярну матрицю з `N` перехідних отворів, з'єднаних паралельно спільними верхнім і нижнім мідними полігонами, сумарний опір масиву `R_vias_total` обчислюється як паралельне з'єднання:

```
R_vias_total = R_via / N                                        [ідеальний опір N паралельних отворів]
```

Залежність сумарного опору від кількості отворів `N` для `R_via = 143.3 °C/Вт`:
- Для `N = 4` (матриця 2 × 2): `R_vias = 143.3 / 4 = 35.8 °C/Вт`;
- Для `N = 9` (матриця 3 × 3): `R_vias = 143.3 / 9 = 15.9 °C/Вт`;
- Для `N = 16` (матриця 4 × 4): `R_vias = 143.3 / 16 = 8.96 °C/Вт`;
- Для `N = 25` (матриця 5 × 5): `R_vias = 143.3 / 25 = 5.73 °C/Вт`.

#### Коефіцієнт взаємної теплової взаємодії (Thermal Coupling Factor)

У реальній платі отвори не є повністю незалежними провідниками, оскільки вони відбирають тепло від обмеженої площі верхнього майданчика і скидають його на спільний нижній полігон. Через горизонтальний опір підвідних ділянок міді центральні отвори матриці нагріваються сильніше за периферійні.

Фактичний тепловий опір масиву коригується коефіцієнтом взаємодії `η_array`:

```
R_vias_actual = (R_via / N) · η_array                           [врахування взаємного нагріву отворів]
```

де `η_array ≈ 1.05–1.20` для щільних матриць із кроком `p < 1.0 мм`. При кроці `p = 1.0–1.2 мм` коефіцієнт `η_array` наближається до одиниці (`1.02–1.05`), і проста формула ділення на `N` дає точність у межах 5%.

#### Технологічні обмеження на розмір та крок отворів

Оптимізація масиву перехідних отворів вимагає дотримання таких інженерних меж:
1. **Мінімальна перемичка діелектрика:** Відстань між краями сусідніх отворів має становити щонайменше `0.25 мм` для запобігання мікротріщинам склотекстоліту під час механічного свердління.
2. **Крок сітки (Pitch):** При стандартному діаметрі свердління `d_drill = 0.3 мм` і діаметрі контактного кільця `0.6 мм` рекомендований крок становить `1.0–1.2 мм`.
3. **Запобігання витіканню припою:** Отвори діаметром понад `0.35 мм` створюють значне капілярне втягування паяльної пасти під час оплавлення в конвекційній печі. Це призводить до утворення порожнеч (voids) площею понад 25–35% під кристалом, що підіймає контактний опір `θ_CS` у кілька разів.

### 3. Теплове розтікання в площині мідного шару (Thermal Spreading Resistance)

Коли тепловий потік проходить крізь перехідні отвори й потрапляє на внутрішній або нижній мідний полігон, він не виходить у повітря в одній точці, а розтікається радіально від центру нагріву по тонкому мідному листу товщиною `t_foil`.

Мідна фольга має високу теплопровідність у своїй площині (`k_cu ≈ 385 Вт/(м·К)`), тоді як діелектрик FR-4 під нею та повітря над нею є теплоізоляторами (`k_fr4 ≈ 0.3 Вт/(м·К)`, `k_air ≈ 0.026 Вт/(м·К)`).

Розглянемо осесиметричне радіальне розтікання тепла від еквівалентного циліндричного джерела радіусом `r_in` (радіус зони розміщення отворів) до зовнішнього радіуса мідного полігону `r_out`.

Диференціал теплового опору циліндричного кільця радіусом `r` і шириною `dr`:

```
dA_cond = 2 · π · r · t_foil                                    [бічна площа циліндричного перерізу фольги]
dR_spread = dr / (k_cu · dA_cond)                               [закон Фур'є для елементарного кільця]
          = dr / (2 · π · k_cu · t_foil · r)                    [диференціал радіального опору]
```

Інтегруючи від внутрішнього радіуса джерела `r_in` до зовнішнього радіуса полігону `r_out`:

```
R_spread = ∫ [r_in .. r_out] dr / (2 · π · k_cu · t_foil · r)   [інтеграл радіального розтікання]
         = ln(r_out / r_in) / (2 · π · k_cu · t_foil)           [аналітичний опір розтікання у тонкому шарі]
```

#### Характерний масштаб теплової довжини та ефект насичення

Опір розтікання `R_spread` росте логарифмічно з віддаленням від джерела, тоді як площа віддачі тепла в повітря збільшується квадратично `A(r) = π · r²`.

Рівновага між радіальним перенесенням тепла вздовж мідного шару та його віддачею у повітря визначається характерною тепловою довжиною `L_th` (thermal characteristic length):

```
L_th = √( (k_cu · t_foil) / h_conv )                            [характерний масштаб теплового розсіювання]
```

де `h_conv` — сумарний коефіцієнт тепловіддачі конвекцією та випромінюванням (для природної конвекції на відкритому повітрі `h_conv ≈ 10–15 Вт/(м²·К)`).

Обчислення для стандартної фольги 1 oz (`t_foil = 35 мкм = 35 × 10⁻⁶ м`) при `h_conv = 12 Вт/(м²·К)`:

```
L_th = √( (385 · 35 × 10⁻⁶) / 12 )                              [підстановка параметрів фольги 1 oz]
     = √( 0.013475 / 12 )                                       [ділення теплопровідності на тепловіддачу]
     = √( 1.1229 × 10⁻³ )                                       [підкореневий вираз у м²]
     = 0.0335 м                                                 [характерна довжина в метрах]
     = 33.5 мм                                                  [ефективний тепловий радіус для фольги 1 oz]
```

Для потовщеної фольги 2 oz (`t_foil = 70 мкм`):

```
L_th = √( (385 · 70 × 10⁻⁶) / 12 )                              [підстановка параметрів фольги 2 oz]
     = √( 0.02695 / 12 )                                        [обчислення співвідношення провідностей]
     = √( 2.2458 × 10⁻³ )                                       [підкореневий вираз для 2 oz]
     = 0.0474 м                                                 [характерна довжина у метрах]
     = 47.4 мм                                                  [ефективний тепловий радіус для фольги 2 oz]
```

Звідси випливає фундаментальний інженерний висновок: ефективна зона тепловіддачі навколо SMD-компонента обмежена радіусом приблизно `r_eff ≈ 1.5 · L_th ≈ 50 мм` (для 1 oz) та `r_eff ≈ 70 мм` (для 2 oz).

Збільшення розмірів друкованої плати понад цей радіус не призводить до додаткового зниження температури компонента, оскільки температурний напір на периферії спадає до нуля через опір тонкої фольги.

### 4. Комплексний числовий розрахунок теплового тракту SMD-вузла

Розглянемо повний тепловий розрахунок для силового перетворювача напруги:
- Компонент у корпусі DFN 5×6 мм із розміром термопада `4.0 × 4.0 мм` (`A_pad = 16 мм²`);
- Під термопадом розміщено регулярну матрицю з `N = 12` отворів діаметром `d = 0.3 мм`, `t_cu = 25 мкм` на платі товщиною `1.6 мм`;
- Плата 4-шарова: верхній шар (1 oz), внутрішній суцільний шар GND (1 oz), нижній шар тепловідводу (1 oz);
- Сумарна товщина паралельних мідних шарів розтікання: `t_spread = 35 мкм + 35 мкм = 70 мкм`;
- Електрична потужність, що розсіюється: `P_d = 2.5 Вт`;
- Температура повітря всередині блоку: `T_a = 40 °C`.

Опір масиву перехідних отворів:
```
R_vias = 143.3 / 12                                             [опір одного отвору поділений на 12]
       = 11.94 °C/Вт                                            [сумарний тепловий опір перехідного масиву]
```

Опір розтікання у двох суцільних шарах міді (GND + Bottom):
Еквівалентний радіус джерела `r_in = √(16 / π) ≈ 2.26 мм`. Ефективний радіус розсіювача `r_out = 30 мм`.
```
R_spread = ln(30 / 2.26) / (2 · π · 385 · 70×10⁻⁶)               [підстановка логарифма радіусів та товщини міді]
         = ln(13.27) / 0.1693                                   [обчислення знаменника провідності двох шарів]
         = 2.585 / 0.1693                                       [ділення логарифма на провідність]
         = 15.27 °C/Вт                                          [опір розтікання в площині міді]
```

Опір конвекції та випромінювання з двох боків плати площею `60 × 60 мм` (`A_conv = 2 · 0.06 · 0.06 = 7.2 × 10⁻³ м²`):
```
R_conv = 1 / (h_conv · A_conv)                                  [закон тепловіддачі Ньютона]
       = 1 / (12 · 7.2 × 10⁻³)                                  [підстановка коефіцієнта 12 Вт/м²К та подвійної площі]
       = 1 / 0.0864                                             [обчислення повної конвективної провідності]
       = 11.57 °C/Вт                                            [тепловий опір тепловіддачі в повітря]
```

Сумарний тепловий опір друкованої плати `R_pcb`:
```
R_pcb = R_vias + R_spread + R_conv                              [послідовне додавання трьох теплових опорів]
      = 11.94 + 15.27 + 11.57                                   [підстановка значень окремих ланок]
      = 38.78 °C/Вт                                             [повний опір плати від термопада до повітря]
```

Перегрів термопада та температура напівпровідникового кристала:
```
ΔT_pad = P_d · R_pcb                                            [перегрів контактного майданчика за законом Ома]
       = 2.5 · 38.78                                            [множення потужності на опір плати]
       = 96.95 °C                                               [температурний перепад на платі]

T_pad = T_a + ΔT_pad                                            [абсолютна температура термопада]
      = 40 + 96.95                                              [додавання температури навколишнього середовища]
      = 136.95 °C                                               [температура металу під чипом]
```

Додаючи внутрішній опір кристала `θ_JC = 1.8 °C/Вт`:
```
ΔT_JC = 2.5 · 1.8                                               [перепад всередині корпусу чипа]
      = 4.5 °C                                                  [додатковий перегрів p-n переходу]

T_j = T_pad + ΔT_JC                                             [підсумок температури напівпровідника]
    = 136.95 + 4.5                                              [додавання внутрішнього перепаду]
    = 141.45 °C                                                 [підсумкова температура кристала кремнію]
```

За паспортної граничної температури кристала `150 °C` робоча точка 141.45 °C має неприпустимо малий запас надійності (лише 8.5 °C).

Щоб забезпечити довготривалу надійність (Tj ≤ 110 °C), вживають таких заходів:
1. Застосування фольги 2 oz (`70 мкм`) на зовнішніх шарах зменшує `R_spread` до `7.6 °C/Вт`.
2. Організація примусового обдуву `v = 1.5 м/с` збільшує `h_conv` до `25 Вт/(м²·К)`, знижуючи `R_conv` до `5.55 °C/Вт`.
3. У результаті повний опір плати знижується до `R_pcb = 11.94 + 7.6 + 5.55 = 25.09 °C/Вт`, а температура кристала становить безпечні `T_j = 40 + 2.5 · (25.09 + 1.8) = 107.2 °C`.

### 5. Практичні правила проєктування в САПР (CAD PCB Layout)

Щоб аналітичні розрахунки точно відповідали фізичній поведінці зібраної плати, під час трасування в середовищах Altium Designer, KiCad або Cadence Allegro дотримуються таких правил:

1. **Суцільне підключення (Solid Connection):** Теплові перехідні отвори та виводи термопада підключають до внутрішніх шарів заземлення виключно суцільною заливкою (Solid Connect), без термобар'єрів (Thermal Relief). Термобар'єри необхідні лише для ручного паяння вивідних компонентів; у силових SMD-вузлах вузькі спиці термобар'єра створюють паразитний тепловий опір у 5–15 °C/Вт.
2. **Шахове розташування (Staggered Pattern):** Для великих площ розміщення отворів зі зміщенням у шаховому порядку (staggered grid) покращує вирівнювання температурного поля порівняно з прямокутною сіткою завдяки рівномірнішому радіальному перекриттю зон розтікання.
3. **Шовковистість та маска (Solder Mask Dam):** Якщо отвори не заповнюються компаундом (non-plugged), вікна в паяльній масці відкривають індивідуально навколо кожного майданчика або розбивають на матрицю дрібних квадратів (паперів). Це утримує паяльну пасту на поверхні завдяки силам поверхневого натягу і не дає їй стікати в сусідні отвори.
