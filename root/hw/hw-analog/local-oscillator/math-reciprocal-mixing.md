# 🧮 Математика фазового шуму та взаємного змішування (Reciprocal Mixing)

У реальному гетеродині вихідне коливання не є ідеальною гармонічною синусоїдою вида A·cos(2π·f_LO·t). Реальний фізичний сигнал завжди містить випадкові флуктуації амплітуди α(t) та фази φ(t), які описуються випадковими процесами:

```
v_LO(t) = [A + α(t)] · cos( 2π · f_LO · t + φ(t) )
```

Оскільки амплітудні флуктуації α(t) ефективно обмежуються й придушуються нелінійним режимом роботи автогенератора та амплітудними обмежувачами (буферними каскадами), вирішальну роль у погіршенні характеристик радіотракту відіграє **фазовий шум** φ(t).

### 1. Спектральна щільність фазового шуму L(Δf)

Фазовий шум характеризують величиною L(Δf) — відношенням потужності шуму в однополосній смузі шириною 1 Гц на відбудові Δf від несучої до повної потужності сигналу несучої P_LO:

```
L(Δf) = P_noise(f_LO + Δf, 1 Гц) / P_LO
```

Одиниця вимірювання L(Δf) — **дБн/Гц** (децибели відносно несучої на герц, dBc/Hz).

За фундаментальною формулою Лісона (*Leeson's equation*), спектральна щільність фазового шуму автогенератора на відбудові Δf описується як:

```
L(Δf) = 10 · log₁₀ { 2·k·T·F / P_sig · [ 1 + (f_LO / (2 · Q_L · Δf))² ] · [ 1 + f_c / Δf ] }
```

Де:
- k = 1.38 × 10⁻²³ Дж/К — стала Больцмана;
- T — абсолютна температура в Кельвінах (290 K);
- F — коефіцієнт шуму активного підсилювального елемента генератора;
- P_sig — потужність коливань у резонаторі;
- Q_L — нагружена добротність коливального контуру чи резонатора;
- f_c — частота зрізу флікер-шуму (1/f шуму транзистора);
- Δf — відбудова (зсув частоти) від основного піку гетеродина f_LO.

Аналіз формули Лісона розкриває три спектральні області фазового шуму гетеродина:
1. **Область флікер-шуму (поблизу несучої, Δf < f_c):** Шум спадає зі швидкістю −30 дБ/декаду (або 1/f³). Визначається технологією транзистора (польові транзистори GaAs мають вищу f_c, ніж кремнієві біполярні SiGe).
2. **Область білого фазового шуму (проміжна відбудова):** Шум спадає зі швидкістю −20 дБ/декаду (або 1/f²). Визначається добротністю Q_L резонатора.
3. **Шумове підніжжя (далека відбудова):** Шум виходить на константне плато, яке визначається тепловим шумом буферних каскадів.

### 2. Математичний механізм взаємного змішування (Reciprocal Mixing)

Уявімо, що на вхід змішувача приймача надходять два сигнали:
1. Слабкий корисний сигнал на частоті f_RF з потужністю P_in (дБм).
2. Потужна завада (блокер) на сусідній частоті f_blocker = f_RF + Δf з потужністю P_blocker (дБм).

Змішувач здійснює математичну операцію множення вхідного спектра на спектр гетеродина. Ідеальний гетеродин без шуму переніс би заваду на частоту f_IF + Δf, де її повністю відфільтрував би смуговий фільтр ПЧ. 

Проте реальний гетеродин має «спідницю» фазового шуму з щільністю L(Δf). Множення сильної завади P_blocker на фазовий шум L(Δf) створює шумову смугу, яка падає **точно на проміжну частоту f_IF**:

```
P_noise_recip(дБм/Гц) = P_blocker(дБм) + L(Δf)(дБн/Гц)
```

### 3. Розрахунок підняття шумового порогу у смузі приймача

Для прийняття корисного сигналу приймач має смугу пропускання B (Гц). Загальна потужність шуму взаємного змішування P_N_recip у смузі B становить:

```
P_N_recip(дБм) = P_blocker(дБм) + L(Δf)(дБн/Гц) + 10 · log₁₀(B)
```

Перевіримо розмірності в лінійному масштабі:

```
P_N_recip_lin (Вт)
= P_blocker_lin · L_lin(Δf) · B
= [Вт] · [1/Гц] · [Гц]
= [Вт]      [відповідність розмірностей доведена]
```

### 4. Повний інтегральний шум та деградація SNR

Власний тепловий шум приймача у смузі B визначається як:

```
P_N_thermal(дБм) = −174 дБм/Гц + 10 · log₁₀(B) + NF
```

Де NF (*Noise Figure*) — коефіцієнт шуму приймального тракту (в дБ), а −174 дБм/Гц — спектральна щільність теплового шуму при 290 K.

Під час дії завади P_blocker сумарна потужність шуму на ПЧ P_N_total дорівнює сумі теплового шуму та шуму взаємного змішування:

```
P_N_total (Вт) = P_N_thermal (Вт) + P_N_recip (Вт)
```

Деградація чутливості ΔSensitivity (в дБ) обчислюється як відношення нового сумарного шуму до початкового теплового:

```
ΔSensitivity
= 10 · log₁₀( P_N_total / P_N_thermal )            [визначення деградації через відношення шумів]
= 10 · log₁₀( 1 + P_N_recip_lin / P_N_thermal_lin ) [підстановка суми теплового шуму та шуму завади]
```

### 5. Детальний числовий приклад розрахунку

Розглянемо випадок проектування радіоприймача цифрового зв'язку стандарту DMR/PMR зі смугою каналу 12.5 кГц.

Вихідні параметри системи:
- Смуга каналу: B = 12.5 кГц (12500 Гц → 10·log₁₀(12500) = 40.97 дБ·Гц);
- Коефіцієнт шуму приймача: NF = 5.0 дБ;
- Фазовий шум гетеродина на відбудові Δf = 25 кГц (сусідній канал): L(25 кГц) = −125 дБн/Гц;
- Потужність завади від сусідньої рації на відбудові 25 кГц: P_blocker = −20 дБм.

**Крок 1. Розрахуємо власний тепловий шум приймача у смузі каналу:**

```
P_N_thermal = −174 + 40.97 + 5.0
            = −128.03 дБм
```

**Крок 2. Розрахуємо шум взаємного змішування від завади:**

```
P_N_recip
= P_blocker + L(Δf) + 10 · log₁₀(B)   [формула взаємного змішування у смузі B]
= −20 + (−125) + 40.97                 [підстановка вихідних даних]
= −104.03 дБм                          [підсумок потужності шуму завади]
```

**Крок 3. Переведемо обидва шуми в лінійну форму (мілівати):**

```
P_N_thermal_lin = 10^(−128.03 / 10) = 1.574 × 10⁻¹³ мВт
P_N_recip_lin   = 10^(−104.03 / 10) = 3.954 × 10⁻¹¹ мВт
```

**Крок 4. Знайдемо сумарний шум на проміжній частоті та деградацію чутливості:**

```
P_N_total_lin
= 1.574 × 10⁻¹³ + 3.954 × 10⁻¹¹        [сумування лінійних потужностей]
= 3.9697 × 10⁻¹¹ мВт                   [значення сумарного шуму на ПЧ]

ΔSensitivity
= 10 · log₁₀( 3.9697 × 10⁻¹¹ / 1.574 × 10⁻¹³ ) [відношення нового шуму до початкового]
= 10 · log₁₀(252.2)                    [значення лінійного коефіцієнта збільшення шуму]
= 24.02 дБ                             [підсумкова катастрофічна втрата чутливості]
```

**Інженерний висновок розрахунку:** Потужна завада −20 дБм у сусідньому каналі через недостатню спектральну чистоту гетеродина L(25 кГц) = −125 дБн/Гц погіршила чутливість приймача на **24.02 дБ** (понад 250 разів по потужності!). Приймач повністю втратить здатність приймати тихі сигнали.

Щоб деградація чутливості не перевищувала допустимі 1.0 дБ, шум взаємного змішування P_N_recip повинен бути принаймні на 6 дБ нижчим за власний тепловий шум (−134 дБм), що вимагає від гетеродина фазового шуму L(25 кГц) ≤ −155 дБн/Гц.

### 6. Вплив фазового шуму на інтегральний джитер (RMS Phase Jitter)

У цифрових системах зв'язку з квадратурною модуляцією (QPSK, QAM-16, QAM-64, QAM-256) фазовий шум гетеродина інтегрують по смузі частот від f_start до f_stop для обчислення середньоквадратичного джитера фази σ_phi:

```
σ_phi² (рад²) = 2 · ∫ [ 10^(L(f)/10) ] df   (інтеграл від f_start до f_stop)
```

Переведення знайденого значення σ_phi в градуси:

```
σ_phi (град) = σ_phi (рад) · (180 / π)
```

Якщо інтегральний фазовий джитер гетеродина перевищує 1.0° RMS, сузір'я відліків для QAM-256 починає перекривати границі прийняття рішень, створюючи нездоланне шумове підніжжя векторної амплітуди помилки (EVM Floor), яке неможливо усунути підвищенням потужності передавача.
