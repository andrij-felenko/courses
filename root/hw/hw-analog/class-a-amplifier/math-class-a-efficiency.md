# 🧮 Звідки в класі A беруться 25 % і 50 %

Стеля ефективності класу A — не випадкове число й не вада конкретної схеми, а пряма арифметика двох потужностей: сталої «данини» від живлення й малого корисного гойдання поверх неї. Розрахуймо обидві стелі — для резистивного й для трансформаторного живлення — від першопричини.

## Дві потужності, які ми ділимо

Ефективність (ККД) — це відношення корисної потужності в навантаженні до повної потужності, яку каскад бере від джерела:

```
η = P_нав / P_жив
```

Уся хитрість — у тому, що чисельник і знаменник поводяться **зовсім по-різному**. Знаменник майже сталий: робоча точка задає постійний струм, що тече завжди. Чисельник же залежить від розмаху сигналу й максимальний лише на повному ході. Тому стеля ККД — це найбільший можливий чисельник, поділений на (майже незмінний) знаменник.

## Звідки множник ½ у потужності синуса

Перш ніж рахувати, варто прояснити одне місце, яке потім скрізь спливатиме: чому середня потужність синусоїди з **амплітудою** Vₚ дорівнює Vₚ²/(2R), а не Vₚ²/R. Річ у тім, що потужність — це **квадрат** миттєвої напруги, поділений на опір, а сигнал увесь час змінюється, тож треба брати **середнє** за період:

```
p(t) = v(t)² / R = (Vₚ·sin(ωt))² / R = (Vₚ²/R)·sin²(ωt)
```

Уся залежність від часу сидить у множнику sin²(ωt). А середнє значення квадрата синуса за повний період — рівно **½** (синус половину часу проводить «вище» свого середнього квадрата, половину — «нижче», і виходить точно половина від одиниці). Тому:

```
P_сер = (Vₚ²/R) · ⟨sin²⟩ = (Vₚ²/R) · ½ = Vₚ² / (2R)
```

Звідси, до речі, й увесь сенс **середньоквадратичного** (англ. *RMS* — root mean square) значення: Vₚ/√2. Підставивши його у звичну P = V²/R, отримаємо те саме Vₚ²/(2R). Цей множник ½ — одна з двох «половинок», що зрештою дадуть чверть.

## Резистивне (послідовне) живлення → 25 %

Розгляньмо найзвичайніший каскад: транзистор, у колекторі резистор навантаження R до живлення Vcc, робоча точка виставлена посередині. «Посередині» означає, що в спокої на транзисторі падає половина живлення, і стільки ж — на резисторі; постійний струм спокою позначмо I₀.

**Постійна потужність від живлення.** Джерело віддає Vcc, крізь нього тече I₀ — завжди, незалежно від сигналу:

```
P_жив = Vcc · I₀     (стала, тече і в тиші)
```

**Найбільший можливий розмах.** Напруга на транзисторі може гойдатися від майже нуля (насичення) до майже Vcc (відсічка), тобто навколо середини Vcc/2 — на амплітуду щонайбільше:

```
Vₚ(макс) ≈ Vcc / 2
```

Більше не вийде: угору впремося в живлення, униз — у насичення.

**Корисна потужність сигналу.** Навантаження — той самий резистор R. Середня потужність синусоїди з амплітудою Vₚ на опорі R дорівнює (множник ½ — бо середнє від квадрата синуса дорівнює половині):

```
P_нав = Vₚ² / (2R)
```

Щоб виразити все через одні величини, згадаймо, що робоча точка посередині: половина Vcc падає на R при струмі I₀, тобто Vcc/2 = I₀·R, звідки R = Vcc/(2·I₀). Підставмо максимальний розмах Vₚ = Vcc/2:

```
P_нав(макс) = (Vcc/2)² / (2R)
            = (Vcc²/4) / (2 · Vcc/(2·I₀))
            = (Vcc²/4) / (Vcc/I₀)
            = Vcc · I₀ / 4
```

**Ділимо.** Тепер стеля ККД виходить сама:

```
η_макс = P_нав(макс) / P_жив
       = (Vcc · I₀ / 4) / (Vcc · I₀)
       = 1/4 = 25 %
```

Ось і чверть. Причина прозора: знаменник — повна данина Vcc·I₀, а найбільший чисельник — лише її чверть, бо корисний розмах обмежений половиною живлення, а множник ½ від усереднення синуса ріже ще вдвічі. Половина × половина = чверть.

**Жирний приклад-умова: реальний каскад, Vcc = 12 В, I₀ = 100 мА.**

```c
// Резистивний каскад класу A, робоча точка посередині
float Vcc = 12.0f;     // живлення, В
float I0  = 0.100f;    // постійний струм спокою, А

float P_zhiv = Vcc * I0;          // = 1.20 Вт — тече ЗАВЖДИ
float P_nav  = Vcc * I0 / 4.0f;   // = 0.30 Вт — максимум корисного
float eta    = P_nav / P_zhiv;    // = 0.25 → 25 %

// Тепло в найгіршому випадку — ТИША: уся данина осідає в каскаді
float P_teplo_tisha = P_zhiv;     // = 1.20 Вт
// На повному сигналі трохи менше: P_zhiv - P_nav = 0.90 Вт
```

Висновок: каскад безперервно бере 1.2 Вт, а корисного віддає щонайбільше 0.3 Вт. Решта — тепло, і найбільше його (повні 1.2 Вт) припадає на спокій, а не на повний сигнал. Саме тому радіатор класу A рахують під тишу.

## Трансформаторне (індуктивне) живлення → 50 %

Чверть прикро мала. Звідки втрата? Половина живлення безповоротно «з'їдається» постійним падінням на резисторі R — на ньому в спокої сидить Vcc/2, і ця потужня просто гріє резистор. Що, якби живити навантаження так, щоб **на постійному струмі напруга не марнувалася**? Саме це дає трансформатор (чи дросель): його обмотка має майже нульовий опір **постійному** струму, тож постійна складова проходить крізь неї без падіння напруги.

Наслідок — два виграші воднораз. По-перше, у спокої на транзисторі сидить **усе** живлення Vcc (а не Vcc/2), бо на котушці постійному струму падати нічому. По-друге, завдяки магнітному «розгойдуванню» індуктивності напруга на колекторі може злітати **вище** за Vcc — аж до 2·Vcc у піку. Тому розмах подвоюється:

```
Vₚ(макс) ≈ Vcc        (а не Vcc/2)
```

**Постійна потужність від живлення** лишається тією самою формою — джерело й далі віддає Vcc при струмі спокою I₀:

```
P_жив = Vcc · I₀
```

**Корисна потужність.** Навантаження приведене до первинної обмотки, і транзистор бачить його як опір змінному струму R_ac; саме на цьому опорі гойдається сигнал з амплітудою Vₚ = Vcc. Середня потужність синусоїди — тієї самої форми, що й у резистивному випадку (той самий множник ½ від усереднення квадрата синуса):

```
P_нав = Vₚ² / (2·R_ac)
```

Лишилося виразити R_ac через наші величини — так само, як вище ми виразили R через Vcc та I₀. На повному ході напруга гойдається на всю амплітуду Vcc рівно тоді, коли струм гойдається на всю амплітуду струму спокою I₀ (від нуля до 2·I₀); ці дві амплітуди зв'язує саме опір змінному струму:

```
Vcc = I₀ · R_ac     звідки     R_ac = Vcc / I₀
```

Підставмо максимальний розмах Vₚ = Vcc і цей R_ac:

```
P_нав(макс) = Vcc² / (2 · Vcc/I₀)
            = Vcc² · I₀ / (2 · Vcc)
            = Vcc · I₀ / 2
```

**Ділимо:**

```
η_макс = P_нав(макс) / P_жив
       = (Vcc · I₀ / 2) / (Vcc · I₀)
       = 1/2 = 50 %
```

Рівно вдвічі краще за резистивні 25 %. Тут легко піддатися спокусі й вирішити, що коли розмах подвоївся, то потужність (а вона — квадрат напруги) мала б зрости **вчетверо**; та це не так. Разом із розмахом удвічі виріс і приведений опір: R_ac = Vcc/I₀ проти резистивного R = Vcc/(2·I₀), тобто R_ac = 2R. Квадрат подвоєної напруги множить потужність на чотири, а вдвічі більший опір у знаменнику ділить її навпіл — у підсумку рівно вдвічі, не вчетверо. А корінь самого виграшу — той, що й дав подвоєний розмах: трансформатор прибрав постійне падіння напруги, яке резистор марнував на нагрів, тож у спокої на транзисторі сидить усе Vcc, і гойдатися сигнал може на повне Vcc замість половини.

**Жирний приклад-умова: той самий Vcc = 12 В, I₀ = 100 мА, але трансформаторний зв'язок.**

```c
// Трансформаторний каскад класу A
float Vcc = 12.0f;
float I0  = 0.100f;

float P_zhiv = Vcc * I0;          // = 1.20 Вт — як і раніше, тече завжди
float P_nav  = Vcc * I0 / 2.0f;   // = 0.60 Вт — удвічі більше за резистивний
float eta    = P_nav / P_zhiv;    // = 0.50 → 50 %
```

Висновок: та сама постійна данина 1.2 Вт, але корисного тепер до 0.6 Вт — половина. Платимо за це габаритним, дорогим трансформатором і його власними недоліками (обмежена смуга, спотворення на краях). Тому в сучасній техніці трансформаторний клас A — рідкість; це спадок лампової доби.

## Дві стелі поруч

Зведімо обидва розрахунки в одну картину — видно, що різниця походить рівно з двох незалежних чинників:

```
                       резистивне        трансформаторне
──────────────────────────────────────────────────────────
постійне падіння на
  зв'язку (марнується)  Vcc/2  (на R)     ≈0   (котушка)
доступний розмах Vₚ      Vcc/2            Vcc        ← удвічі
P_нав(макс)             Vcc·I₀ / 4        Vcc·I₀ / 2
P_жив                   Vcc·I₀            Vcc·I₀
η_макс                  25 %              50 %
```

Перший чинник — куди дівається постійна напруга: резистор просто палить на собі половину живлення в спокої, а котушка віддає її всю транзистору. Другий — наскільки далеко може гойднутися вихід: пів живлення проти повного. Насправді це не два незалежні чинники, а один, побачений із двох боків: саме тому, що котушка не марнує постійної напруги, робоча точка стоїть на повному Vcc — тож і розмах сягає повного Vcc замість половини. Одне тягне за собою друге, і стелі різняться рівно вдвічі, не вчетверо.

> Зверніть увагу: у жодній формулі немає ні β, ні типу приладу. Стелі 25 % і 50 % — властивість **режиму** (безперервне протікання з робочою точкою посередині), а не транзистора чи лампи. Той самий результат вийшов би для польового транзистора чи вакуумної лампи: щойно прилад веде струм усі 360°, арифметика данини й розмаху та сама.

## Чому реальний ККД ще нижчий

Обидві цифри — **стелі**, досяжні лише в ідеалі й лише на **повному** розмаху. У житті виходить менше з кількох причин, що накладаються:

```
причина                       наслідок
─────────────────────────────────────────────
сигнал рідко на повну         η падає ~ квадратично з розмахом
запас від зламів (headroom)   повний хід неприпустимий — кліп
падіння на стабілізувальному
  емітерному резисторі Re     частина Vcc втрачена на нагрів
насичення ≠ рівно нуль        корисний розмах ще трохи менший
```

Найважливіша з них — перша: ефективність максимальна тільки на повному розмаху, а музика чи мова **переважно тиха**. На половині амплітуди корисна потужність учетверо менша, а данина від живлення — та сама; реальний середній ККД резистивного класу A на музиці легко падає до **одиниць відсотків**. Це не привід лякатися — це плата за лінійність, свідомо прийнята там, де вірність дорожча за ват.

## Чому навіть 50 % програють класу B

Корисно бачити межу зверху. Клас B, де кожен із двох приладів веде лише пів періоду, має теоретичну стелю **≈78.5 %** (π/4) — бо його прилади в тиші **закриті** й данини не платять зовсім: струм течуть лише тоді, коли є сигнал. Ось фундаментальна різниця: клас A платить за **готовність** підсилювати щомиті (струм тече завжди), клас B — лише за **роботу** (струм тече на вимогу). Перевага A — за цю безперервність нема ні зламу, ні перехідного спотворення; ціна — те саме безперервне тепло. Уся арифметика 25 % і 50 % — це, по суті, ціна одного-єдиного рішення: не давати приладові закриватися ніколи.
