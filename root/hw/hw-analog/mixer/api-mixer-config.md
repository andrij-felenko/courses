# 📋 Інтерфейс та конфігурація інтегрального ВЧ-змішувача

Цей документ є довідковою специфікацією апаратного та програмного інтерфейсу керування інтегральним ВЧ-змішувачем із вбудованими буферами гетеродина, регульованим підсиленням та SPI/I2C шиною конфігурації (на прикладі мікросхем класів Analog Devices AD831, Maxim Integrated MAX2680, Linear Technology LTC5510, Texas Instruments TRF3705).

Інтегральні ВЧ-змішувачі поєднують у єдиному кристалі аналоговий високочастотний тракт (комірку Гілберта, малошумний підсилювач, вихідний драйвер ПЧ) та цифрову систему конфігурації. Для забезпечення їхньої надійної роботи інженер повинен суворо дотримуватися вимог як до електричного з'єднання аналогових портів, так і до послідовності програмного програмування внутрішніх регістрів.

### Фізичні порти та специфікація виводів (Pinout)

ВЧ-змішувач інтегрується у друковану плату через високочастотні 50-омні лінії та цифрову шину керування.

| Назва виводу | Тип | Електричний рівень | Опис та функціональне призначення |
| :--- | :--- | :--- | :--- |
| **RF_IN+ / RF_IN−** | Вхід | АС-зв'язок, 50 Ом диф. | Диференційний вхід ВЧ-сигналу. Смуга: 400 МГц ... 6.0 ГГц. |
| **LO_IN+ / LO_IN−** | Вхід | АС-зв'язок, 50 Ом диф. | Вхід гетеродина. Рівень: `-10 ... +3` дБм. |
| **IF_OUT+ / IF_OUT−** | Вихід | Відкритий колектор / 50 Ом | Диференційний вихід проміжної частоти. |
| **VCC_RF / VCC_LO** | Живлення | `+3.3V` або `+5.0V` DC | Окремі шини живлення аналогової та цифрової секцій. |
| **BIAS_SET** | Вхід | Аналоговий струм | Резистор встановлення струму спокою для вибору IIP3. |
| **EN / SHDN** | Вхід | CMOS Logic (0 / 3.3V) | Вивід увімкнення мікросхеми (1 = Active, 0 = Power-down). |
| **SPI_CLK / SCN / SDI**| Вхід | SPI Mode 0 (up to 20 MHz)| Цифрова шина налаштування регістрів конфігурації. |

#### Електричні вимоги до аналогових портів
1. **Порт RF (Radio Frequency):** Вхідні виводи `RF_IN+` та `RF_IN−` внутрішньо підключені до баз диференційної транзисторної пари V-I перетворювача. Вони вимагають обов'язкової розв'язки по постійному струму за допомогою зовнішніх керамічних конденсаторів ємністю 10–100 пФ. Для забезпечення диференційного імпедансу 50 Ом перед входом встановлюють симетруючий трансформатор (балун) або LC-ланку узгодження.
2. **Порт LO (Local Oscillator):** Вхід гетеродина подається на перемикальну квадропу. Вбудований малопотужний буфер дозволяє подавати сигнал LO з низьким рівнем (від -10 дБм), що суттєво спрощує вимоги до зовнішнього синтезатора PLL.
3. **Порт IF (Intermediate Frequency):** Виходи відкритих колекторів `IF_OUT+ / IF_OUT−` вимагають зовнішнього подачі живлення `VCC` через високочастотні дроселі (Choke Inductors) або первинну обмотку вихідного ПЧ-трансформатора.

### Карта регістрів конфігурації змішувача

Керування режимами роботи змішувача здійснюється записом 16-бітних слів у внутрішні регістри конфігурації по шині SPI.

#### Таблиця регістрів (Register Map)

| Адреса | Назва регістра | Біти | Замовчування | Функціональне призначення |
| :--- | :--- | :--- | :--- | :--- |
| `0x00` | `REG_POWER` | `[15:0]` | `0x0001` | Керування живленням каскадів та режимом Power-down. |
| `0x01` | `REG_GAIN` | `[7:0]` | `0x000C` | Налаштування коефіцієнта підсилення ПЧ (`0...18` дБ з кроком 1 дБ). |
| `0x02` | `REG_BIAS` | `[3:0]` | `0x0002` | Триммер струму спокою комірки Гілберта (оптимізація IIP3 vs Icc). |
| `0x03` | `REG_LO_BUFF` | `[5:0]` | `0x0010` | Підсилення внутрішнього буфера гетеродина та дільник частоти. |
| `0x04` | `REG_STAT` | `[15:0]` | `RO` | Регістр стану: детектування перевантаження (Peak Detector Overload). |

### Детальний аналіз функцій та бітових полів регістрів

#### Регістр керування живленням `REG_POWER` (Адреса `0x00`)
- **Біт `[0]` — `PWR_UP`:** Головний перемикач живлення аналогового ядра. Значення `0` переводить мікросхему в режим глибокого сну (Power-down), при якому струм споживання падає до 1 мкА. Значення `1` вмикає внутрішній генератор опорного струму (Bandgap Reference) та аналогові каскади. Час виходу з режиму сну до повної стабілізації становить не більше 15 мікросекунд.
- **Біт `[1]` — `LO_BUF_EN`:** Окреме керування живленням буфера гетеродина. Дозволяє вимикати вход LO під час роботи в режимі напівдуплексу (T/R switching) для збереження енергії батареї.
- **Біт `[2]` — `IF_AMP_EN`:** Керування вихідним підсилювачем проміжної частоти.

#### Регістр конфігурації підсилення `REG_GAIN` (Адреса `0x01`)
- **Біти `[4:0]` — `IF_GAIN_ATTN`:** 5-бітне цифрове керування атенюатором ПЧ. Забезпечує регулювання коефіцієнта перетворення від 0 дБ до +18 дБ з дискретністю 1 дБ. Використання цифрового підсилення дозволяє системі автоматичного регулювання підсилення (АРП/AGC) утримувати постійний рівень сигналу на вході АЦП.
- **Біт `[5]` — `RF_ATTN_EN`:** Вмикає додатковий вхідний атенюатор RF величиною 10 дБ. Застосовується при виявленні надзвичайно потужних завад на вході для попередження насичення вхідного каскаду.
- **Біт `[6]` — `MIX_MUTE`:** Швидке програмне вимкнення виходу ПЧ (Mute).

#### Регістр оптимізації струму та лінійності `REG_BIAS` (Адреса `0x02`)
Ключова особливість сучасних активних змішувачів — можливість динамічної зміни струму спокою комірки Гілберта залежно від завадової обстановки в ефірі:
- **Режим Low-Power (`IIP3_TRIM = 000`):** Струм споживання `Icc = 12 мА`, `IIP3 = +2 дБм`. Призначений для роботи від батареї при відсутності потужних завад.
- **Режим Normal (`IIP3_TRIM = 011`):** Струм споживання `Icc = 28 мА`, `IIP3 = +10 дБм`. Стандартний робочий режим.
- **Режим High-Linearity (`IIP3_TRIM = 111`):** Струм споживання `Icc = 55 мА`, `IIP3 = +18 дБм`. Використовується при виявленні потужних завад на сусідніх каналах для збереження максимального динамічного діапазону.

### Послідовність програмного налаштування (C та C++ протіпи)

Алгоритм конфігурації мікросхеми передбачає дотримання часових затримок між увімкненням живлення та записами у регістри підсилення.

```c
#include <stdint.h>
#include <stdbool.h>

/* Адреси регістрів змішувача */
#define MIXER_REG_POWER   0x00
#define MIXER_REG_GAIN    0x01
#define MIXER_REG_BIAS    0x02
#define MIXER_REG_LO_BUFF 0x03

/* Прототип зовнішньої функції запису SPI */
extern void spi_write_register(uint8_t reg_addr, uint16_t reg_val);
extern void delay_us(uint32_t microseconds);

/* Структура конфігурації змішувача */
typedef struct {
    uint8_t  if_gain_db;    /* 0..18 dB */
    bool     rf_atten_en;   /* true = enable -10dB RF attenuation */
    uint8_t  iip3_mode;     /* 0 = Low Power, 1 = Normal, 2 = High Linearity */
    uint8_t  lo_divider;    /* 1, 2, 4, 8 */
} rf_mixer_config_t;

/* Процедура ініціалізації та конфігурації ВЧ-змішувача */
int rf_mixer_configure(const rf_mixer_config_t *cfg) {
    uint16_t reg_val = 0;

    /* 1. Подача живлення аналогового ядра та буфера LO */
    spi_write_register(MIXER_REG_POWER, 0x0003); // Power Up + LO Buffer EN
    delay_us(20); // Чекаємо стабілізації внутрішнього Bandgap (15 мкс)

    /* 2. Налаштування підсилення IF та атенюатора RF */
    reg_val = (cfg->if_gain_db & 0x1F);
    if (cfg->rf_atten_en) {
        reg_val |= (1 << 5);
    }
    spi_write_register(MIXER_REG_GAIN, reg_val);

    /* 3. Налаштування струму спокою для оптимізації IIP3 */
    switch (cfg->iip3_mode) {
        case 0: reg_val = 0x0000; break; // Low-power (+2 dBm)
        case 1: reg_val = 0x0003; break; // Normal (+10 dBm)
        case 2: reg_val = 0x0007; break; // High-Linearity (+18 dBm)
        default: return -1;
    }
    spi_write_register(MIXER_REG_BIAS, reg_val);

    /* 4. Налаштування дільника та підсилювача LO */
    reg_val = (cfg->lo_divider & 0x07);
    spi_write_register(MIXER_REG_LO_BUFF, reg_val);

    return 0; // Успішно
}
```

### Практичні застереження при монтажі та розведенні (PCB Layout)

1. **Ізоляція порту гетеродина (LO Shielding).** Доріжку сигналу гетеродина необхідно оточувати захисним бар'єром із перехідних отворів (Via Fencing) через кожні 1.5 мм. Витік гетеродина на друкованій платі через паразитну ємність доріжок псує розв'язку LO-to-RF на 15–20 дБ.
2. **Розв'язка за живленням.** Біля кожного виводу `VCC` мікросхеми змішувача обов'язково встановлюються блокирувальні керамічні конденсатори ємністю 10 пФ (для ВЧ) та 100 нФ (для НЧ) з мінімальною довжиною траси до шару GND.
3. **Симетрія диференційних ліній.** Диференційні пари `RF_IN+ / RF_IN−` та `IF_OUT+ / IF_OUT−` повинні розводитися симетрично з однаковою довжиною доріжок (skew < 0.2 мм), інакше втрачається придушення парних гармонік та падає коефіцієнт розв'язки.
