# ⚙️ Реалізація цифрового квадратурного змішувача (I/Q Mixer) для SDR

У сучасному цифровому радіозв’язку (Software-Defined Radio, SDR) завдання перенесення спектра частот вирішується програмно-апаратним шляхом після аналого-цифрового перетворення (АЦП). Ця вставка містить детальний опис математичного алгоритму, архітектури, методів компенсації дисбалансу та високопродуктивної програмної реалізації цифрового квадратурного змішувача, який здійснює переношення дискретизованого ВЧ-сигналу або проміжної частоти (IF) у нульову базову смугу (Baseband I/Q).

---

### Постановка задачі та математичний алгоритм

Нехай від АЦП із частотою дискретизації `f_s` (наприклад, 100 Мвибірок/сек) надходить послідовність дійсних відліків `x[n]`. Потрібно перенести корисний сигнал із центральної проміжної частоти `f_IF` на нульову частоту `0 Гц` та розкласти його на два комплексні квадратурні канали:
- **I (In-phase):** синфазна складова сигналу.
- **Q (Quadrature):** квадратурна (зсунута на 90°) складова сигналу.

Для цього вхідний потік `x[n]` перемножується з двома опорними синусоїдальними послідовностями цифрового гетеродина (NCO, *Numerically Controlled Oscillator*):

```
I_raw[n] = x[n] · cos(2π · f_IF · n / f_s)
Q_raw[n] = -x[n] · sin(2π · f_IF · n / f_s)
```

Внаслідок множення утворення спектра описується сумою та різницею частот. Різницева частота `f_IF − f_IF = 0 Гц` формує корисний базовий спектр, а сумарна частота `2·f_IF` є небажаною побічною компонентою, яка підлягає обов'язковій фільтрації цифровим фільтром низьких частот (ФНЧ).

---

### Принцип роботи фазового акумулятора NCO

Для генерування точних синусоїдальних відліків без обчислення витратних функцій `sin()` та `cos()` у реальному часі застосовують метод **цифрового фазового акумулятора** із табличним пошуком (Look-Up Table, LUT).

Фазовий акумулятор являє собою 32-бітне беззнакове ціле число `phase_accumulator`. На кожному кроці дискретизації `n` до акумулятора додається постійне число — приріст фази `phase_increment`:

```
phase_increment = (uint32_t)( (f_IF / f_s) · 2³² )
```

Природне беззнакове переповнення 32-бітного регістра при досягненні `2³²` точно відповідає математичному періоду тригонометричної функції `2π` без використання умовних операторів `if`.

Для вибірки з таблиці розміром `N = 1024` елементи (`2¹⁰`) беруться старші 10 бітів акумулятора:
```
index = phase_accumulator >> (32 - 10)
```

**Динамічний діапазон від квантування фази.** Відсікання молодших 22 бітів акумулятора створює паразитно-фазові побічні компоненти (Phase Truncation Spurs). Рівень придушення цих побічних частот обчислюється за формулою:
```
SFDR_trunc (дБc) ≈ 6.02 · B_table + 12 дБ = 6.02 · 10 + 12 ≈ 72 дБc
```
Такого рівня придушення достатньо для більшості систем зв'язку. Для підвищення SFDR до 100+ дБ застосовують лінійну тригонометричну інтерполяцію між сусідніми елементами таблиці.

### Обробка форматів даних: Фіксована проти Плаваної крапки (Q15 vs Float32)

На вибір архітектури обробки впливає тип обчислювального ядра:
1. **Вбудовані мікроконтролери та ПЛІС (FPGA / Cortex-M4):** Для запобігання втратам продуктивності використовують формат із фіксованою крапкою Q15 або Q31. Таблиця синусів пакується у масив 16-бітних цілих чисел `int16_t`, а множення виконується інструкцією `__SMUAD()` за один такт.
2. **Центральні процесори та DSP (x86_64 / ARM Cortex-A):** Використовують формат із плаваючою крапкою `float` (IEEE-754 single precision). Це повністю усуває загрозу числового переповнення при сумуванні та виключає потребу у розрахунку масштабних коефіцієнтів (scaling factors).

### Компенсація квадратурного дисбалансу (I/Q Imbalance Correction)

У реальних цифрових та змішаних аналогово-цифрових квадратурних змішувачах канали I та Q часто мають невеликий дисбаланс амплітуди `ε` та відхилення ортогональності фази `Δφ` (невідповідність 90°).

Математична модель неідеального квадратурного сигналу виглядає так:
```
I_real[n] = (1 + ε/2) · I_ideal[n]
Q_real[n] = (1 − ε/2) · [ Q_ideal[n] · cos(Δφ) − I_ideal[n] · sin(Δφ) ]
```

Це викликає появу паразитного дзеркального піку на спектрі (Image Spur). Для виправлення дисбалансу в цифровому тракті застосовують матричну компенсаційну корекцію Грама-Шмідта:
```
I_corr[n] = I_real[n]
Q_corr[n] = ( Q_real[n] + I_real[n] · sin(Δφ) ) / cos(Δφ)
```
Параметри `ε` та `Δφ` оцінюються в реальному часі шляхом усереднення квадратів та добутків вибірок `I` та `Q`.

### Реалізація цифрового змішувача мовами C та C++

Наведені нижче реалізації розроблені за принципом високої обчислювальної ефективності. Версія мовою C виконується з мінімальними накладними витратами через покажчики та структури. Версія мовою C++ використовує семантику RAII, стандартизовані контейнери `std::vector`, `std::complex` та `std::span` для гарантії безпеки пам'яті.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <stdint.h>

#define NCO_TABLE_SIZE 1024
#define PI 3.14159265358979323846

/* Структура цифрового квадратурного змішувача */
typedef struct {
    float sin_table[NCO_TABLE_SIZE];
    float cos_table[NCO_TABLE_SIZE];
    uint32_t phase_accumulator;
    uint32_t phase_increment;
} sdr_mixer_t;

/* Ініціалізація змішувача та генерація таблиць NCO */
void sdr_mixer_init(sdr_mixer_t *mixer, double sample_rate, double target_freq) {
    int i;
    for (i = 0; i < NCO_TABLE_SIZE; i++) {
        double angle = (2.0 * PI * i) / NCO_TABLE_SIZE;
        mixer->sin_table[i] = (float)sin(angle);
        mixer->cos_table[i] = (float)cos(angle);
    }
    
    mixer->phase_accumulator = 0;
    /* Крок фази у 32-бітному фіксованому форматі */
    double norm_freq = target_freq / sample_rate;
    mixer->phase_increment = (uint32_t)(norm_freq * 4294967296.0);
}

/* Обробка буфера вхідних відліків */
void sdr_mixer_process(sdr_mixer_t *mixer, const float *in_rf, 
                       float *out_i, float *out_q, size_t count) {
    size_t n;
    for (n = 0; n < count; n++) {
        /* Отримання 10-бітного індексу таблиці з старших бітів акумулятора */
        uint32_t index = mixer->phase_accumulator >> (32 - 10);
        
        float cos_val = mixer->cos_table[index];
        float sin_val = mixer->sin_table[index];
        
        float sample = in_rf[n];
        out_i[n] = sample * cos_val;
        out_q[n] = sample * (-sin_val);
        
        /* Оновлення фазового акумулятора */
        mixer->phase_accumulator += mixer->phase_increment;
    }
}
```
```cpp
#include <vector>
#include <complex>
#include <cmath>
#include <numbers>
#include <cstdint>
#include <span>
#include <algorithm>

class SDRQuadratureMixer {
public:
    static constexpr size_t NcoTableSize = 1024;

    SDRQuadratureMixer(double sampleRate, double targetFreq)
        : phaseAccumulator_{0} {
        sinTable_.resize(NcoTableSize);
        cosTable_.resize(NcoTableSize);

        for (size_t i = 0; i < NcoTableSize; ++i) {
            double angle = (2.0 * std::numbers::pi * i) / NcoTableSize;
            sinTable_[i] = static_cast<float>(std::sin(angle));
            cosTable_[i] = static_cast<float>(std::cos(angle));
        }

        double normFreq = targetFreq / sampleRate;
        phaseIncrement_ = static_cast<uint32_t>(normFreq * 4294967296.0);
    }

    // Обробка масиву відліків із поверненням комплексного вектора I/Q
    void process(std::span<const float> inRf, 
                 std::span<std::complex<float>> outIq) {
        const size_t count = std::min(inRf.size(), outIq.size());
        
        for (size_t n = 0; n < count; ++n) {
            uint32_t index = phaseAccumulator_ >> (32 - 10);
            
            float cosVal = cosTable_[index];
            float sinVal = sinTable_[index];
            
            float sample = inRf[n];
            // I = sample * cos, Q = -sample * sin
            outIq[n] = std::complex<float>(sample * cosVal, -sample * sinVal);
            
            phaseAccumulator_ += phaseIncrement_;
        }
    }

private:
    std::vector<float> sinTable_;
    std::vector<float> cosTable_;
    uint32_t phaseAccumulator_{0};
    uint32_t phaseIncrement_{0};
};
```

### Критичні інженерні пастки та SIMD-оптимізація

1. **Фільтрація сумарної частоти `2·f_IF`.** Цифрове перемноження утворює сумарну частоту, яка повинна бути видалена до процесу децимації (зменшення частоти дискретизації). На практиці одразу після змішувача ставлять каскад CIC-фільтра (Cascaded Integrator-Comb) та вирівнювальний FIR-фільтр низьких частот.
2. **Апаратно-векторизоване виконання (AVX2 / ARM NEON).** Цикл перемноження легко піддається векторизації. При використанні прапорів компілятора `-O3 -mavx2` або `-march=native` сучасний компілятор розгортає цикл і виконує обробку 8 елементів типів `float` за одну SIMD-інструкцію `_mm256_mul_ps()`.
3. **Вирівнювання буферів пам'яті (Memory Alignment).** Для забезпечення максимальної швидкості вибірки масиви даних `in_rf`, `out_i`, `out_q` слід вирівнювати в оперативній пам'яті за межею 32 або 64 байт (alignas(32)), що виключає штрафні такти за розщеплення кєш-рядків центрального процесора.
4. **Багатопотокова паралелізація (Multi-threading).** Для багатоканальних радіопприймачів (MIMO / Phase Array) обробка цифрових змішувачів розділяється між потоками CPU через робочу чергу (Thread Pool) або обробляється паралельними шейдерами на GPU (OpenCL / CUDA).
