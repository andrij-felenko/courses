# 🧮 Малосигнальний аналіз каскоду: вихідний опір та частотний відгук

Каскодна топологія розв'язує фундаментальний конфлікт між підсиленням за напругою та шириною смуги пропускання завдяки двом ключовим малосигнальним властивостям: надзвичайно високому вихідному динамічному опору `R_вих` та низькому вхідному опору другого транзистора `R_вх2`, що фіксує амплітуду змінної напруги у проміжному вузлі.

Нижче наведено строгий малосигнальний аналіз КМОН-каскоду (з урахуванням підкладкового ефекту), біполярного BJT-каскоду (з урахуванням скінченного опору бази `r_π`), а також точний розрахунок полюсів передавальної функції.

---

### 1. Вхідний опір каскаду зі спільним затвором і підсилення першого ступеня

Розглянемо польовий каскод, що складається з транзисторів `M1` (вхідний каскад зі спільним витоком) та `M2` (буфер струму зі спільним затвором). Змінний сигнал `v_вх` подається на затвор `M1`, витік `M1` заземлено, затвор `M2` підключено до джерела постійної напруги зміщення `V_BIAS` (малосигнальна земля). Стік `M1` з'єднаний із витоком `M2` у вузлі `X`.

Знайдемо малосигнальний вхідний опір транзистора `M2`, якщо дивитися у його витік, за наявності довільного навантаження `R_L` у стоці `M2`.

Подамо на витік `M2` тестову напругу `v_x` відносно малосигнальної землі. Тоді напруга затвор-витік дорівнює `v_gs2 = 0 − v_x = −v_x`, а напруга підкладка-витік — `v_bs2 = 0 − v_x = −v_x`.

Струм `i_x`, що втікає у витік `M2`, дорівнює сумі струмів керованих джерел та струму через вихідний опір каналу `r_o2`:

```
i_x = −g_m2 · v_gs2 − g_mb2 · v_bs2 + (v_x − v_вих) / r_o2   [рівняння струмів у витоковому вузлі M2]
v_gs2 = −v_x,  v_bs2 = −v_x                                    [затвор і підкладка заземлені за змінним струмом]
v_вих = −i_x · R_L                                             [падіння напруги на навантаженні R_L у стоці M2]
i_x = (g_m2 + g_mb2) · v_x + (v_x + i_x · R_L) / r_o2          [підстановка потенціалів у рівняння вузла]
i_x · (1 − R_L / r_o2) = v_x · [g_m2 + g_mb2 + 1/r_o2]         [зведення подібних доданків відносно струму i_x]
R_вх2 = v_x / i_x = (r_o2 + R_L) / [1 + (g_m2 + g_mb2) · r_o2] [точний вхідний опір каскаду зі спільним затвором]
```

Якщо опір навантаження `R_L` сумірний або менший за власний опір транзистора `r_o2` (`R_L << (g_m2 + g_mb2) · r_o2²`), формулу можна спростити:

```
R_вх2 ≈ 1 / (g_m2 + g_mb2) + R_L / [(g_m2 + g_mb2) · r_o2]     [апроксимація при (g_m2 + g_mb2)·r_o2 >> 1]
R_вх2 ≈ 1 / g_m2                                               [за нехтування підкладковим ефектом та малих R_L]
```

Повний опір у проміжному вузлі `X` визначається паралельним з'єднанням вихідного опору нижнього транзистора `r_o1` та вхідного опору верхнього транзистора `R_вх2`:

```
R_X = R_вх2 || r_o1 ≈ (1 / g_m2) || r_o1 ≈ 1 / g_m2
```

Знаючи опір вузла `X`, обчислимо коефіцієнт передачі за напругою нижнього транзистора `M1`:

```
A_v1 = v_X / v_вх = −g_m1 · R_X                                [коефіцієнт передачі напруги на вузол X]
A_v1 ≈ −g_m1 · (1 / g_m2) = −g_m1 / g_m2                       [підстановка опору R_X ≈ 1/g_m2]
A_v1 ≈ −1                                                      [за однакових струмів і розмірів транзисторів M1 та M2]
```

Завдяки тому, що коефіцієнт підсилення вхідного ступеня за модулем близький до одиниці (`|A_v1| ≈ 1`), вхідна динамічна ємність за теоремою Міллера становить:

```
C_вх,M = C_gd1 · (1 + |A_v1|) ≈ 2 · C_gd1                      [придушення міллерівського множення ємності]
```

### 2. Строге виведення вихідного опору польового каскоду

Для розрахунку вихідного динамічного опору `R_вих` подамо на вихідний вузол (стік `M2`) тестове джерело напруги `v_тест` при заземленому вході `v_вх = 0` і визначимо результуючий тестовий струм `i_тест`.

При `v_вх = 0` вхідний транзистор `M1` перебуває у стані спокою і представляє собою простий пасивний резистор `r_o1`, увімкнений між вузлом `X` та землею.

```
v_X = i_тест · r_o1                                            [напруга у вузлі X, створена тестовим струмом через r_o1]
v_gs2 = 0 − v_X = −i_тест · r_o1                               [напруга затвор-витік M2 при заземленому затворі]
v_bs2 = 0 − v_X = −i_тест · r_o1                               [напруга підкладка-витік M2 при заземленій підкладці]
i_джерела = (g_m2 + g_mb2) · v_gs2 = −(g_m2 + g_mb2) · i_тест · r_o1 [струм керованого генератора транзистора M2]
i_ro2 = i_тест − i_джерела = i_тест · [1 + (g_m2 + g_mb2) · r_o1]    [струм через диференційний опір r_o2]
v_тест = v_X + i_ro2 · r_o2                                    [сумарне падіння напруги від виходу до землі]
v_тест = i_тест · r_o1 + i_тест · [1 + (g_m2 + g_mb2) · r_o1] · r_o2 [підстановка виразів для v_X та i_ro2]
v_тест = i_тест · [r_o1 + r_o2 + (g_m2 + g_mb2) · r_o1 · r_o2]       [групування доданків за струмом i_тест]
R_вих = v_тест / i_тест = r_o1 + r_o2 + (g_m2 + g_mb2) · r_o1 · r_o2  [точна формула вихідного опору польового каскоду]
```

Оскільки добуток `(g_m2 + g_mb2) · r_o1 · r_o2` на два-три порядки перевищує суму `r_o1 + r_o2`, практична інженерна формула має вигляд:

```
R_вих ≈ (g_m2 + g_mb2) · r_o1 · r_o2 ≈ g_m2 · r_o2 · r_o1
```

### 3. Вихідний опір біполярного каскоду (BJT) з урахуванням r_π

У біполярному каскоді на транзисторах `Q1` та `Q2` (NPN) ситуація ускладнюється наявністю скінченного вхідного опору бази верхнього транзистора `r_π2 = β2 / g_m2`.

Коли тестовий струм `i_тест` входить у вихідний вузол колектора `Q2`, він стікає через емітер `Q2` у паралельне з'єднання опору `r_o1` та опору база-емітер `r_π2`:

```
R_екв,X = r_o1 || r_π2                                         [еквівалентний опір у вузлі X для транзистора Q2]
v_X = i_тест · (r_o1 || r_π2)                                  [падіння напруги у вузлі X]
v_be2 = −v_X = −i_тест · (r_o1 || r_π2)                        [малосигнальна напруга база-емітер транзистора Q2]
i_джерела = g_m2 · v_be2 = −g_m2 · i_тест · (r_o1 || r_π2)     [струм керованого генератора Q2]
i_ro2 = i_тест − i_джерела = i_тест · [1 + g_m2 · (r_o1 || r_π2)] [струм через власний вихідний опір r_o2]
v_тест = v_X + i_ro2 · r_o2                                    [сумарна напруга на колекторі Q2]
v_тест = i_тест · (r_o1 || r_π2) + i_тест · [1 + g_m2 · (r_o1 || r_π2)] · r_o2
R_вих,BJT = r_o2 + (r_o1 || r_π2) + g_m2 · r_o2 · (r_o1 || r_π2) [точний вихідний опір біполярного каскоду]
```

Оскільки зазвичай `r_o1 >> r_π2`, паралельне з'єднання `r_o1 || r_π2 ≈ r_π2`. Підставивши `r_π2 = β2 / g_m2`, отримуємо граничну величину вихідного опору біполярного каскоду:

```
R_вих,BJT ≈ g_m2 · r_o2 · r_π2 = g_m2 · r_o2 · (β2 / g_m2) = β2 · r_o2
```

Вихідний опір біполярного каскоду обмежений значенням `β2 · r_o2` (типово одиниці-десятки мегаомів), тоді як польовий каскод теоретично не має обмеження за базовим струмом і досягає сотень мегаомів.

### 4. Повний коефіцієнт підсилення та активне каскодне навантаження

Повний коефіцієнт підсилення каскодного каскаду за напругою дорівнює добутку ефективної крутості схеми `G_m` на повний імпеданс у вихідному вузлі:

```
G_m = g_m1 · [1 / (1 + 1 / ((g_m2 + g_mb2) · r_o1))] ≈ g_m1    [еквівалентна крутість каскоду практично тотожна g_m1]
R_вих,повне = R_вих,N || R_навантаження                       [сумарний опір на виході]
A_v = −G_m · R_вих,повне ≈ −g_m1 · (R_вих,N || R_навантаження) [загальний коефіцієнт підсилення каскаду]
```

Якщо підсилювач навантажений на пасивний резистор `R_L`, де `R_L << R_вих,N`, підсилення дорівнює звичайному `A_v ≈ −g_m1 · R_L`.

Якщо ж як навантаження використано активне каскодне дзеркало струму на PMOS-транзисторах `M3` та `M4` з власним вихідним опором `R_вих,P ≈ g_m3 · r_o3 · r_o4`, то повний вихідний опір становить `R_вих,повне = R_вих,N || R_вих,P ≈ (1/2) · g_m · r_o²`. У цьому разі підсилення за напругою досягає власного максимуму:

```
A_v,макс ≈ −g_m · [(1/2) · g_m · r_o²] = −(1/2) · (g_m · r_o)²
```

### 5. Частотний відгук і точний розрахунок полюсів

Динамічна поведінка каскоду на високих частотах описується трьома основними полюсами у вузлах схеми:

1. **Вхідний полюс `p_вх`** (формується опором джерела `R_дж` та вхідною ємністю):
```
C_вх,повна = C_gs1 + C_gd1 · (1 + |A_v1|) + C_монтаж ≈ C_gs1 + 2 · C_gd1 + C_монтаж
ω_p,вх = 1 / (R_дж · C_вх,повна)
f_p,вх = 1 / [2π · R_дж · (C_gs1 + 2 · C_gd1 + C_монтаж)]
```

2. **Полюс проміжного вузла `p_X`** (формується малим вхідним опором `M2`):
```
C_X = C_db1 + C_gd1 + C_gs2 + C_sb2                            [сумарна паразитна ємність вузла X]
R_X ≈ 1 / (g_m2 + g_mb2)                                       [низький опір вузла X]
ω_p,X = 1 / (R_X · C_X) ≈ (g_m2 + g_mb2) / C_X
f_p,X = (g_m2 + g_mb2) / [2π · (C_db1 + C_gd1 + C_gs2 + C_sb2)]
```
Оскільки `R_X` становить одиниці або десятки омів, цей полюс розташований на надвисоких частотах (сумірних із граничною частотою транзистора `f_T`), тому він майже не впливає на фазовий зсув у робочій смузі.

3. **Вихідний полюс `p_вих`** (домінантний полюс за високого вихідного опору):
```
C_вих = C_L + C_db2 + C_gd2 + C_навантаження                    [повна ємність навантаження вихідного вузла]
ω_p,вих = 1 / (R_вих,повне · C_вих)
f_p,вих = 1 / [2π · (R_вих,N || R_вих,P) · C_вих]
```

### 6. Числовий приклад розрахунку каскодного каскаду (65-нм КМОН)

Розглянемо практичний розрахунок аналогового КМОН-каскоду з такими параметрами робочої точки:
* Струм спокою: `I_D = 200 мкА`
* Параметри транзисторів `M1` та `M2`: `g_m1 = g_m2 = 2.5 мА/В`, `g_mb2 = 0.5 мА/В`, `r_o1 = r_o2 = 20 кОм`
* Паразитні ємності: `C_gs1 = C_gs2 = 25 фФ`, `C_gd1 = C_gd2 = 8 фФ`, `C_db1 = C_sb2 = 12 фФ`
* Опір джерела сигналу: `R_дж = 5 кОм`, ємність вихідного навантаження: `C_L = 100 фФ`

**Крок 1. Розрахунок опору у вузлі X та підсилення першого транзистора:**
```
R_X ≈ 1 / (g_m2 + g_mb2) = 1 / (2.5 + 0.5) мА/В = 1 / 0.0030 См ≈ 333 Ом
A_v1 = −g_m1 · R_X = −2.5 мА/В · 333 Ом ≈ −0.83
```

**Крок 2. Розрахунок вхідної ємності та вхідного полюса:**
```
C_вх = C_gs1 + C_gd1 · (1 + |A_v1|) = 25 фФ + 8 фФ · (1 + 0.83) = 25 + 14.6 = 39.6 фФ
f_p,вх = 1 / (2π · 5000 Ом · 39.6·10⁻¹⁵ Ф) ≈ 804 МГц
```
*(Для порівняння: в одиночному каскаді зі спільним витоком при підсиленні A_v = −50 вхідна ємність склала б C_вх = 25 + 8 · 51 = 433 фФ, а вхідний полюс упав би до f_p,вх ≈ 73 МГц).*

**Крок 3. Розрахунок вихідного опору та підсилення на постійному струмі:**
```
R_вих,N ≈ (g_m2 + g_mb2) · r_o1 · r_o2 = 0.0030 См · 20 000 Ом · 20 000 Ом = 1.2 МОм
```
При використанні симетричного активного каскодного навантаження `R_вих,P = 1.2 МОм`:
```
R_вих,повне = 1.2 МОм || 1.2 МОм = 600 кОм
A_v = −g_m1 · R_вих,повне = −2.5 мА/В · 600 кОм = −1500  (63.5 дБ)
```

**Крок 4. Полюс проміжного вузла X:**
```
C_X = C_db1 + C_gd1 + C_gs2 + C_sb2 = 12 + 8 + 25 + 12 = 57 фФ
f_p,X = 1 / (2π · 333 Ом · 57·10⁻¹⁵ Ф) ≈ 8.38 ГГц
```

Полюс проміжного вузла `f_p,X` лежить на частоті понад 8 ГГц і гарантовано не створює фазової загрози в робочому діапазоні, забезпечуючи високу стійкість підсилювача при замкненому негативному зворотному зв'язку.

### 7. Спектральна густина шумів та внесок другого транзистора

Для оцінки шумових властивостей каскоду знайдемо еквівалентну спектральну густину вхідної шумової напруги `S_v,вх`.

Тепловий шум каналу польового транзистора моделюється генератором шумового струму стоку зі спектральною густиною `S_i,d = 4kT · γ · g_m`, де `k` — стала Больцмана, `T` — абсолютна температура, а `γ ≈ 2/3` для довгоканальних приладів (`γ ≈ 1.0...2.0` для глибокого субмікрона).

Шумовий струм вхідного транзистора `M1` безпосередньо стікає у вихідне навантаження. Його внесок у вхідну напругу:

```
S_v,in1 = S_i,d1 / g_m1² = (4kT · γ · g_m1) / g_m1² = 4kT · γ / g_m1
```

Шумовий струм верхнього каскодного транзистора `M2` (`i_n,d2`) протікає через його стік і витік. Проте у витоку `M2` увімкнено вихідний опір `r_o1` нижнього транзистора. Для шумового генератора `M2` опір `r_o1` діє як глибокий витоковий зворотний зв'язок:

```
i_n,вих2 = i_n,d2 / [1 + (g_m2 + g_mb2) · r_o1]               [шумовий струм M2 на виході каскоду]
S_v,in2 = S_i,d2 / [g_m1² · (1 + (g_m2 + g_mb2) · r_o1)²]     [вхідний еквівалент шуму транзистора M2]
```

Оскільки знаменник містить множник `[(g_m2 + g_mb2) · r_o1]² >> 1000`, внесок другого транзистора в загальний низькочастотний шум каскаду придушується на 30–40 дБ і становить менше 1% від шуму вхідного транзистора `M1`.

### 8. Гранична умова високочастотної стійкості (від'ємний вхідний опір)

Присутність паразитної індуктивності `L_b` у колі бази (або затвора) верхнього транзистора `Q2` створює фазовий зсув струму бази, що відбивається у витоковий вузол `X`.

Якщо імпеданс затвора становить `Z_g = jωL_g`, то вхідний імпеданс у витік `M2` з урахуванням ємності `C_gs2` дорівнює:

```
Z_вх2(jω) ≈ (1 + jω · L_g · jω · C_gs2) / [g_m2 + jω · C_gs2]
Z_вх2(jω) ≈ (1 − ω² · L_g · C_gs2) / [g_m2 · (1 + j · ω / ω_T)]
Re{Z_вх2(ω)} ≈ 1 / g_m2 − (ω² · L_g · C_gs2) / g_m2            [дійсна частина імпедансу у вузлі X]
```

При виконанні умови `ω² · L_g · C_gs2 > 1` дійсна частина опору стає від'ємною `Re{Z_вх2} < 0`. Для гарантування безумовної стійкості паразитна індуктивність виводу затвора мусить задовольняти нерівність:

```
L_g < 1 / (ω_макс² · C_gs2)
```

Введення послідовного резистора `R_демпф` у затвор або базу зміщує дійсну частину імпедансу в додатну область, повністю ліквідуючи ризик автоколивань на НВЧ.
