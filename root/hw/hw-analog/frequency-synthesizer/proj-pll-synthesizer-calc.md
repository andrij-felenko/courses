# ⚙️ Моделювання петлі ФАПЧ та розрахунок фазового шуму мовами C та C++

При проектуванні високочастотних радіотрактів інженер-схемотехнік зіштовхується із задачею розрахунку номіналів пасивного петльового фільтра (Loop Filter) для інтегрованого синтезатора ФАПЧ. Невірно обрані значення резисторів та конденсаторів призводять або до самозбудження петлі зворотного зв'язку, або до надмірного перерегулювання й тривалого виходу на частоту, або до неприпустимого зростання фазового шуму в робочій смузі каналу.

Для автоматизації математичного розрахунку та чисельного моделювання динаміки ФАПЧ розробляються спеціалізовані розрахункові модулі. 

Нижче наведено теоретичне обґрунтування, алгоритмічну структуру, аналіз крайових випадків та законшені програмні модулі мовами C та C++ для повного розрахунку петльового фільтра другої ланки, аналізу стійкості петлі та моделювання спектрального профілю фазового шуму.

### Алгоритм математичного моделювання та фізичні формули

Математичне моделювання синтезатора частот складається з п'яти послідовних етапів:

1. **Розрахунок коефіцієнта ділення дільника зворотного зв'язку N:**
   Визначається відношенням бажаної вихідної частоти VCO `f_out` до опорної частоти порівняльного фазового детектора `f_PFD`:
   ```
   N = f_out / f_PFD
   ```

2. **Обчислення ємності головного конденсатора петльового фільтра C1:**
   Для забезпечення заданої смуги пропускання петлі `f_c` (або кутової частоти `ω_c = 2π · f_c`) та розрахованого запасу стійкості по фазі `PM` (Phase Margin) ємність `C1` обчислюється за формулою:
   ```
   C1 = [ I_cp · K_vco · cos(PM) ] / [ 2π · N · ω_c² ]
   ```
   де `I_cp` — струм помпи заряду (в амперах), а `K_vco` — крутизна характеристики генератора керованого напругою (в рад/(с·В)).

3. **Обчислення демпфувального опору R1:**
   Опір резистора `R1` визначає положення нуля передавальної функції `ω_z = 1 / (R1 · C1)` і виражається через коефіцієнт демпфування `ζ` (для критичного демпфування обирають `ζ ≈ 0.707`):
   ```
   R1 = ( 2 · ζ ) / ( ω_c · C1 )
   ```

4. **Обчислення паразитного згладжувального конденсатора C2:**
   Для придушення пульсацій опорної частоти паралельно до ланцюга `R1-C1` підключається конденсатор `C2`. Щоб зберегти запас стійкості по фазі `PM = 45°...50°`, співвідношення ємностей обирають як `C1 / C2 ≈ 10`:
   ```
   C2 = C1 / 10
   ```

5. **Оцінка часу встановлення частоти (Lock Time):**
   Час `t_lock`, за який вихідна частота входить у задану смугу допуску `Δf_tol` (наприклад, 1 кГц) після стрибка частоти `Δf_step` (наприклад, 50 МГц), обчислюється за апроксимаційною формулою 2-го порядку:
   ```
   t_lock ≈ [ -ln( Δf_tol / Δf_step ) ] / ( ζ · ω_n )
   ```
   де `ω_n = √[ (I_cp · K_vco) / (2π · N · C1) ]` — власна резонансна частота петлі.

6. **Моделювання профілю фазового шуму L(Δf):**
   Внутрішньосмуговий фазовий шум ФАПЧ `L_inband` (до частоти зрізу `f_c`) розраховується через показник якості фазового детектора `FOM` (Figure of Merit, типово -230 дБн/Гц):
   ```
   L_inband = FOM + 10·log₁₀(f_PFD) + 20·log₁₀(N)    [дБн/Гц]
   ```
   За межами смуги петлі (`Δf > f_c`) фазовий шум спадає зі швидкістю −20 дБ/декада і визначається власним шумом VCO `L_VCO(Δf)`. Загальний шум обчислюється як логарифмічна сума потужностей двох компонент:
   ```
   P_total = 10^(L_inband / 10) + 10^(L_VCO / 10)
   L_total = 10 · log₁₀( P_total )
   ```

### Аналіз крайових випадків та інженерних обмежень

При реалізації чисельного розрахунку в коді необхідно враховувати наступні крайові випадки та апаратні обмеження:

- **Перевірка від'ємних або нульових частот:** Якщо вхідна опорна частота `f_pfd` або вихідна частота `f_out` дорівнює нулю чи від'ємна, програма повинна негайно припинити обчислення й повернути помилку validation, оскільки ділення на нуль призведе до `NaN` або `Inf`.
- **Запас стійкості по фазі (Phase Margin Guard):** Якщо задати `PM ≥ 90°` або `PM ≤ 0°`, тригонометрична функція `cos(PM)` виродиться в 0 або від'ємне значення, що призведе до фізично неможливої від'ємної ємності `C1 < 0`. Безпечний інженерний діапазон вхідного `PM` становить `30°...70°`.
- **Вибір стандартних номіналів ряду E24/E96:** Обчислені значення `C1`, `R1`, `C2` є ідеальними математичними числами. На практиці розробник підбирає найближчі реальні пасивні компоненти із рядів допусків E24 (5%) або E96 (1%). Після заміни номіналів на стандартні необхідно переобчислити фактичний запас по фазі `actual_pm_deg` для гарантії стійкості.
- **Обмеження струму помпи заряду:** Струм `I_cp` у чипах регулюється дискретно (наприклад, від 0.31 мА до 5.0 мА з кроком 0.31 мА). Занадто малий струм робить конденсатор `C1` мікроскопічним (нестійким до паразитної ємності монтажу), а занадто великий струм вимагає конденсаторів великої ємності (> 100 нФ), які випускаються лише у кераміці з високим п'єзоефектом (X7R/Y5V), що спричиняє мікрофонний шум.

### Аналіз та інженерна інтерпретація результатів

Запуск розрахованого модуля для вхідних даних діапазону 2.4 ГГц (`f_out = 2.4 ГГц`, `f_PFD = 25 МГц`, `I_cp = 2.5 мА`, `K_vco = 30 МГц/В`, цільова смуга `f_c = 100 кГц`) демонструє наступний набір вихідних характеристик:

1. **Значення пасивних компонентів фільтра:** 
   Обчислене значення `C1 = 1.27 нФ` округлюється до найближчого номіналу E24 — `1.2 нФ`. Резистор `R1 = 1724 Ом` замінюється на `1.6 кОм`, а ємність `C2 = 120 пФ` обирається з кераміки типу NPO/COG (зокрема, кераміка C0G/NPO має нульовий температурний коефіцієнт ємності й не проявляє п'єзоефекту, на відміну від X7R).

2. **Запас стійкості по фазі (PM):** 
   Розраховане значення `PM = 50.1°` забезпечує стійкість системи у всьому діапазоні робочих температур від -40°C до +85°C. Навіть при відхиленні номіналів `R1` та `C1` на ±10% під дією технологічного розкину фактичний запас не опуститься нижче `42°`, що гарантує відсутність самозбудження петлі.

3. **Швидкість встановлення частоти (Lock Time):** 
   Розрахований час `t_lock = 21.5 мкс` відповідає жорстким вимогам протоколів із часовим поділом та частотним скапуванням (наприклад, системи радіокерування ExpressLRS, де інтервал між пакетами становить 1000 Гц або 1 мс). Петля ФАПЧ встигає повністю стабілізувати фазу за перші 20% тривалості тайм-слоту.

4. **Оцінка фазового шуму:** 
   Розрахований рівень внутрішньосмугового шуму `-116.4 дБн/Гц` та підсумкового шуму на відбудові 100 кГц `-114.2 дБн/Гц` дозволяє застосовувати даний синтезатор у радіоканалах із квадратурною модуляцією QAM-256 та OFDM, гарантуючи придушення фазового джитера й збереження високого відношення сигнал/шум (SNR).
