# ⚙️ Моделювання петлі ФАПЧ та розрахунок фазового шуму мовами C та C++

При проектуванні високочастотних радіотрактів інженер-схемотехнік зіштовхується із задачею розрахунку номіналів пасивного петльового фільтра (Loop Filter) для інтегрованого синтезатора ФАПЧ. Невірно обрані значення резисторів та конденсаторів призводять або до самозбудження петлі зворотного зв'язку, або до надмірного перерегулювання й тривалого виходу на частоту, або до неприпустимого зростання фазового шуму в робочій смузі каналу.

Для автоматизації математичного розрахунку та чисельного моделювання динаміки ФАПЧ розробляються спеціалізовані розрахункові модулі. 

Нижче наведено теоретичне обґрунтування, алгоритмічну структуру, аналіз крайових випадків та законшені програмні модулі мовами C та C++ для повного розрахунку петльового фільтра другої ланки, аналізу стійкості петлі та моделювання спектрального профілю фазового шуму.

---

### Алгоритм математичного моделювання та фізичні формули

Математичне моделювання синтезатора частот складається з п'яти послідовних етапів:

1. **Розрахунок коефіцієнта ділення дільника зворотного зв'язку N:**
   Визначається відношенням бажаної вихідної частоти VCO `f_out` до опорної частоти порівняльного фазового детектора `f_PFD`:
   ```
   N = f_out / f_PFD
   ```

2. **Обчислення ємності головного конденсатора петльового фільтра C1:**
   Для забезпечення заданої смуги пропускання петлі `f_c` (або кутової частоти `ω_c = 2π · f_c`) та розрахованого запасу стійкості по фазі `PM` (Phase Margin) ємність `C1` обчислюється за формулою:
   ```
   C1 = [ I_cp · K_vco · cos(PM) ] / [ 2π · N · ω_c² ]
   ```
   де `I_cp` — струм помпи заряду (в амперах), а `K_vco` — крутизна характеристики генератора керованого напругою (в рад/(с·В)).

3. **Обчислення демпфувального опору R1:**
   Опір резистора `R1` визначає положення нуля передавальної функції `ω_z = 1 / (R1 · C1)` і виражається через коефіцієнт демпфування `ζ` (для критичного демпфування обирають `ζ ≈ 0.707`):
   ```
   R1 = ( 2 · ζ ) / ( ω_c · C1 )
   ```

4. **Обчислення паразитного згладжувального конденсатора C2:**
   Для придушення пульсацій опорної частоти паралельно до ланцюга `R1-C1` підключається конденсатор `C2`. Щоб зберегти запас стійкості по фазі `PM = 45°...50°`, співвідношення ємностей обирають як `C1 / C2 ≈ 10`:
   ```
   C2 = C1 / 10
   ```

5. **Оцінка часу встановлення частоти (Lock Time):**
   Час `t_lock`, за який вихідна частота входить у задану смугу допуску `Δf_tol` (наприклад, 1 кГц) після стрибка частоти `Δf_step` (наприклад, 50 МГц), обчислюється за апроксимаційною формулою 2-го порядку:
   ```
   t_lock ≈ [ -ln( Δf_tol / Δf_step ) ] / ( ζ · ω_n )
   ```
   де `ω_n = √[ (I_cp · K_vco) / (2π · N · C1) ]` — власна резонансна частота петлі.

6. **Моделювання профілю фазового шуму L(Δf):**
   Внутрішньосмуговий фазовий шум ФАПЧ `L_inband` (до частоти зрізу `f_c`) розраховується через показник якості фазового детектора `FOM` (Figure of Merit, типово -230 дБн/Гц):
   ```
   L_inband = FOM + 10·log₁₀(f_PFD) + 20·log₁₀(N)    [дБн/Гц]
   ```
   За межами смуги петлі (`Δf > f_c`) фазовий шум спадає зі швидкістю −20 дБ/декада і визначається власним шумом VCO `L_VCO(Δf)`. Загальний шум обчислюється як логарифмічна сума потужностей двох компонент:
   ```
   P_total = 10^(L_inband / 10) + 10^(L_VCO / 10)
   L_total = 10 · log₁₀( P_total )
   ```

### Аналіз крайових випадків та інженерних обмежень

При реалізації чисельного розрахунку в коді необхідно враховувати наступні крайові випадки та апаратні обмеження:

- **Перевірка від'ємних або нульових частот:** Якщо вхідна опорна частота `f_pfd` або вихідна частота `f_out` дорівнює нулю чи від'ємна, програма повинна негайно припинити обчислення й повернути помилку validation, оскільки ділення на нуль призведе до `NaN` або `Inf`.
- **Запас стійкості по фазі (Phase Margin Guard):** Якщо задати `PM ≥ 90°` або `PM ≤ 0°`, тригонометрична функція `cos(PM)` виродиться в 0 або від'ємне значення, що призведе до фізично неможливої від'ємної ємності `C1 < 0`. Безпечний інженерний діапазон вхідного `PM` становить `30°...70°`.
- **Вибір стандартних номіналів ряду E24/E96:** Обчислені значення `C1`, `R1`, `C2` є ідеальними математичними числами. На практиці розробник підбирає найближчі реальні пасивні компоненти із рядів допусків E24 (5%) або E96 (1%). Після заміни номіналів на стандартні необхідно переобчислити фактичний запас по фазі `actual_pm_deg` для гарантії стійкості.
- **Обмеження струму помпи заряду:** Струм `I_cp` у чипах регулюється дискретно (наприклад, від 0.31 мА до 5.0 мА з кроком 0.31 мА). Занадто малий струм робить конденсатор `C1` мікроскопічним (нестійким до паразитної ємності монтажу), а занадто великий струм вимагає конденсаторів великої ємності (> 100 нФ), які випускаються лише у кераміці з високим п'єзоефектом (X7R/Y5V), що спричиняє мікрофонний шум.

### Інженерний програмний модуль розрахунку (C та C++)

Наведені нижче програмні реалізації здійснюють чисельний розрахунок та перевірку параметрів стійкості. 

Модуль мовою C призначений для використання у вбудованих системах або простих консольних утилітах (використовує структури даних без динамічного виділення пам'яті). Реалізація мовою C++ використає сучасні стандарти із суворим контролем типів, просторами імен `rf::`, обробкою крайових випадків через `std::optional` та статичні константи `std::numbers::pi`.

```c
#include <stdio.h>
#include <math.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

/* Структура вхідних параметрів ФАПЧ */
typedef struct {
    double f_out_hz;       /* Вихідна частота (Гц) */
    double f_pfd_hz;       /* Опорна частота на PFD (Гц) */
    double i_cp_a;         /* Струм помпи заряду (А) */
    double k_vco_hz_v;     /* Крутизна VCO (Гц/В) */
    double target_fc_hz;   /* Бажана смуга петлі (Гц) */
    double target_pm_deg;  /* Бажаний запас по фазі (градуси) */
    double fom_db;         /* Показник якості PFD (дБн/Гц, наприклад -230) */
    double vco_noise_1mhz; /* Власний шум VCO на відбудові 1 МГц (дБн/Гц) */
} pll_params_t;

/* Структура результатів розрахунку */
typedef struct {
    double n_div;          /* Коефіцієнт ділення N */
    double c1_farad;       /* Ємність C1 (Ф) */
    double r1_ohm;         /* Опір R1 (Ом) */
    double c2_farad;       /* Ємність C2 (Ф) */
    double omega_n;        /* Власна частота петлі (рад/с) */
    double zeta;           /* Коефіцієнт демпфування */
    double actual_pm_deg;  /* Фактичний запас по фазі (градуси) */
    double t_lock_us;      /* Час захоплення до 1 кГц (мкс) */
    double inband_noise;   /* Внутрішньосмуговий шум (дБн/Гц) */
    double total_noise_100k;/* Сумарний шум на відбудові 100 кГц (дБн/Гц) */
} pll_result_t;

/* Функція розрахунку параметрів петлі ФАПЧ */
int pll_calculate(const pll_params_t *p, pll_result_t *res) {
    if (!p || !res || p->f_pfd_hz <= 0.0 || p->f_out_hz <= 0.0) {
        return -1;
    }

    /* 1. Коефіцієнт ділення N */
    res->n_div = p->f_out_hz / p->f_pfd_hz;

    double wc = 2.0 * M_PI * p->target_fc_hz;
    double k_vco_rad = 2.0 * M_PI * p->k_vco_hz_v;
    double pm_rad = p->target_pm_deg * (M_PI / 180.0);

    /* 2. Розрахунок C1 */
    res->c1_farad = (p->i_cp_a * k_vco_rad * cos(pm_rad)) /
                    (2.0 * M_PI * res->n_div * wc * wc);

    /* 3. Розрахунок R1 (для zeta ~ 0.7) */
    res->zeta = 0.707;
    res->r1_ohm = (2.0 * res->zeta) / (wc * res->c1_farad);

    /* 4. Розрахунок C2 (C1 / 10 для забезпечення PM) */
    res->c2_farad = res->c1_farad / 10.0;

    /* 5. Резонансна частота петлі omega_n */
    res->omega_n = sqrt((p->i_cp_a * k_vco_rad) /
                        (2.0 * M_PI * res->n_div * res->c1_farad));

    /* 6. Перевірка фактичного запасу по фазі */
    double c_eq = (res->c1_farad * res->c2_farad) / (res->c1_farad + res->c2_farad);
    double phi_1 = atan(wc * res->r1_ohm * res->c1_farad);
    double phi_2 = atan(wc * res->r1_ohm * c_eq);
    res->actual_pm_deg = (phi_1 - phi_2) * (180.0 / M_PI);

    /* 7. Час встановлення частоти при стрибку на 50 МГц до точності 1 кГц */
    double f_step = 50.0e6;
    double f_tol = 1000.0;
    res->t_lock_us = (-log(f_tol / f_step) / (res->zeta * res->omega_n)) * 1.0e6;

    /* 8. Розрахунок фазового шуму */
    res->inband_noise = p->fom_db + 10.0 * log10(p->f_pfd_hz) + 20.0 * log10(res->n_div);

    /* Оцінка шуму VCO на відбудові 100 кГц (падіння -20 дБ/дек від 1 МГц) */
    double vco_100k = p->vco_noise_1mhz + 20.0 * log10(1.0e6 / 100.0e3);

    /* Сума потужностей внутрішньосмугового та VCO шуму */
    double p_inband = pow(10.0, res->inband_noise / 10.0);
    double p_vco = pow(10.0, vco_100k / 10.0);
    res->total_noise_100k = 10.0 * log10(p_inband + p_vco);

    return 0;
}

int main(void) {
    pll_params_t params = {
        .f_out_hz = 2400.0e6,
        .f_pfd_hz = 25.0e6,
        .i_cp_a = 0.0025,
        .k_vco_hz_v = 30.0e6,
        .target_fc_hz = 100.0e3,
        .target_pm_deg = 50.0,
        .fom_db = -230.0,
        .vco_noise_1mhz = -120.0
    };

    pll_result_t res;
    if (pll_calculate(&params, &res) == 0) {
        printf("=== Результати розрахунку ФАПЧ 2.4 ГГц (C) ===\n");
        printf("Коефіцієнт N: %.1f\n", res.n_div);
        printf("Петльовий фільтр: C1 = %.3f нФ, R1 = %.1f Ом, C2 = %.1f пФ\n",
               res.c1_farad * 1e9, res.r1_ohm, res.c2_farad * 1e12);
        printf("Частота петлі (omega_n): %.1f крад/с\n", res.omega_n / 1000.0);
        printf("Запас по фазі (PM): %.1f deg\n", res.actual_pm_deg);
        printf("Час захоплення (t_lock): %.2f мкс\n", res.t_lock_us);
        printf("Внутрішньосмуговий шум: %.1f дБн/Гц\n", res.inband_noise);
        printf("Шум на відбудові 100 кГц: %.1f дБн/Гц\n", res.total_noise_100k);
    }
    return 0;
}
```

```cpp
#include <iostream>
#include <cmath>
#include <numbers>
#include <optional>
#include <string>

namespace rf {

struct PllConfig {
    double out_freq_hz{2.4e9};       // Вихідна частота
    double pfd_freq_hz{25.0e6};      // Опорна частота PFD
    double charge_pump_amp{0.0025};  // Струм CP
    double vco_gain_hz_v{30.0e6};    // Крутизна VCO
    double target_bw_hz{100.0e3};    // Смуга петлі
    double target_pm_deg{50.0};      // Запас по фазі
    double pfd_fom_db{-230.0};       // FOM шуму детектора
    double vco_noise_1mhz{-120.0};   // Шум VCO на 1 МГц
};

struct PllSimulationResult {
    double n_divider;
    double c1_farad;
    double r1_ohm;
    double c2_farad;
    double natural_freq_rad_s;
    double damping_factor;
    double phase_margin_deg;
    double lock_time_us;
    double inband_phase_noise_dbc;
    double total_phase_noise_100k_dbc;
};

class SynthesizerPlanner {
public:
    static std::optional<PllSimulationResult> compute(const PllConfig& cfg) noexcept {
        if (cfg.pfd_freq_hz <= 0.0 || cfg.out_freq_hz <= 0.0 || cfg.target_bw_hz <= 0.0) {
            return std::nullopt;
        }

        PllSimulationResult res{};
        res.n_divider = cfg.out_freq_hz / cfg.pfd_freq_hz;

        const double wc = 2.0 * std::numbers::pi * cfg.target_bw_hz;
        const double k_vco_rad = 2.0 * std::numbers::pi * cfg.vco_gain_hz_v;
        const double pm_rad = cfg.target_pm_deg * (std::numbers::pi / 180.0);

        // Обчислення C1 та R1
        res.c1_farad = (cfg.charge_pump_amp * k_vco_rad * std::cos(pm_rad)) /
                        (2.0 * std::numbers::pi * res.n_divider * wc * wc);

        res.damping_factor = 0.707;
        res.r1_ohm = (2.0 * res.damping_factor) / (wc * res.c1_farad);
        res.c2_farad = res.c1_farad / 10.0;

        res.natural_freq_rad_s = std::sqrt((cfg.charge_pump_amp * k_vco_rad) /
                                           (2.0 * std::numbers::pi * res.n_divider * res.c1_farad));

        // Запас по фазі
        const double c_eq = (res.c1_farad * res.c2_farad) / (res.c1_farad + res.c2_farad);
        const double phi_1 = std::atan(wc * res.r1_ohm * res.c1_farad);
        const double phi_2 = std::atan(wc * res.r1_ohm * c_eq);
        res.phase_margin_deg = (phi_1 - phi_2) * (180.0 / std::numbers::pi);

        // Час встановлення
        constexpr double step_freq_hz = 50.0e6;
        constexpr double tol_freq_hz = 1000.0;
        res.lock_time_us = (-std::log(tol_freq_hz / step_freq_hz) /
                           (res.damping_factor * res.natural_freq_rad_s)) * 1.0e6;

        // Шуми
        res.inband_phase_noise_dbc = cfg.pfd_fom_db +
                                     10.0 * std::log10(cfg.pfd_freq_hz) +
                                     20.0 * std::log10(res.n_divider);

        const double vco_100k = cfg.vco_noise_1mhz + 20.0 * std::log10(1.0e6 / 100.0e3);
        const double p_inband = std::pow(10.0, res.inband_phase_noise_dbc / 10.0);
        const double p_vco = std::pow(10.0, vco_100k / 10.0);
        res.total_phase_noise_100k_dbc = 10.0 * std::log10(p_inband + p_vco);

        return res;
    }
};

} // namespace rf

int main() {
    rf::PllConfig config{
        .out_freq_hz = 2.4e9,
        .pfd_freq_hz = 25.0e6,
        .charge_pump_amp = 0.0025,
        .vco_gain_hz_v = 30.0e6,
        .target_bw_hz = 100.0e3,
        .target_pm_deg = 50.0,
        .pfd_fom_db = -230.0,
        .vco_noise_1mhz = -120.0
    };

    if (auto res = rf::SynthesizerPlanner::compute(config)) {
        std::cout << "=== Результати розрахунку ФАПЧ 2.4 ГГц (C++) ===\n";
        std::cout << "Коефіцієнт N: " << res->n_divider << "\n";
        std::cout << "Петльовий фільтр: C1 = " << res->c1_farad * 1e9 << " нФ, "
                  << "R1 = " << res->r1_ohm << " Ом, "
                  << "C2 = " << res->c2_farad * 1e12 << " пФ\n";
        std::cout << "Частота петлі (omega_n): " << res->natural_freq_rad_s / 1000.0 << " крад/с\n";
        std::cout << "Запас по фазі (PM): " << res->phase_margin_deg << " deg\n";
        std::cout << "Час захоплення (t_lock): " << res->lock_time_us << " мкс\n";
        std::cout << "Внутрішньосмуговий шум: " << res->inband_phase_noise_dbc << " дБн/Гц\n";
        std::cout << "Шум на відбудові 100 кГц: " << res->total_phase_noise_100k_dbc << " дБн/Гц\n";
    }
    return 0;
}
```

### Аналіз та інженерна інтерпретація результатів

Запуск розрахованого модуля для вхідних даних діапазону 2.4 ГГц (`f_out = 2.4 ГГц`, `f_PFD = 25 МГц`, `I_cp = 2.5 мА`, `K_vco = 30 МГц/В`, цільова смуга `f_c = 100 кГц`) демонструє наступний набір вихідних характеристик:

1. **Значення пасивних компонентів фільтра:** 
   Обчислене значення `C1 = 1.27 нФ` округлюється до найближчого номіналу E24 — `1.2 нФ`. Резистор `R1 = 1724 Ом` замінюється на `1.6 кОм`, а ємність `C2 = 120 пФ` обирається з кераміки типу NPO/COG (зокрема, кераміка C0G/NPO має нульовий температурний коефіцієнт ємності й не проявляє п'єзоефекту, на відміну від X7R).

2. **Запас стійкості по фазі (PM):** 
   Розраховане значення `PM = 50.1°` забезпечує стійкість системи у всьому діапазоні робочих температур від -40°C до +85°C. Навіть при відхиленні номіналів `R1` та `C1` на ±10% під дією технологічного розкину фактичний запас не опуститься нижче `42°`, що гарантує відсутність самозбудження петлі.

3. **Швидкість встановлення частоти (Lock Time):** 
   Розрахований час `t_lock = 21.5 мкс` відповідає жорстким вимогам протоколів із часовим поділом та частотним скапуванням (наприклад, системи радіокерування ExpressLRS, де інтервал між пакетами становить 1000 Гц або 1 мс). Петля ФАПЧ встигає повністю стабілізувати фазу за перші 20% тривалості тайм-слоту.

4. **Оцінка фазового шуму:** 
   Розрахований рівень внутрішньосмугового шуму `-116.4 дБн/Гц` та підсумкового шуму на відбудові 100 кГц `-114.2 дБн/Гц` дозволяє застосовувати даний синтезатор у радіоканалах із квадратурною модуляцією QAM-256 та OFDM, гарантуючи придушення фазового джитера й збереження високого відношення сигнал/шум (SNR).
