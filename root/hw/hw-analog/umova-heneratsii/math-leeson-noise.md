# 🧮 Математична модель фазового шуму Лісона

Будь-який реальний гармонійний автогенератор замість нескінченно тонкої спектральної лінії дельта-функції Дірака на частоті `f₀` випромінює розмитий спектр із шумовим «п'єдесталом». Ця спектральна розмитість називається **фазовим шумом** (англ. *phase noise*) і виникає через те, що власний тепловий та флікерний шум електронних компонентів безперервно модулює фазу та частоту коливань у замкненій петлі. 1966 року американський інженер Девід Лісон (*David B. Leeson*) опублікував у журналі *Proceedings of the IEEE* статтю «A Simple Model of Feedback Oscillator Noise Spectrum», де запропонував напівемпіричну аналітичну модель, що пов'язує спектральну густину фазового шуму автогенератора з добротністю коливальної системи, рівнем потужності та коефіцієнтом шуму підсилювача.

## Фізика перетворення амплітудного та фазового шуму в петлі

У замкненому автогенераторі діють два типи шумових збурень: випадкові коливання амплітуди (AM-шум) та випадкові коливання фази (PM-шум).

У стаціонарному режимі автоколивань нелінійний механізм стабілізації амплітуди (насичення транзистора або система АРП) неперервно придушує будь-які флуктуації розмаху сигналу: якщо амплітуда випадково підскочила, ефективне підсилення миттєво падає, повертаючи розмах до рівноважного значення. Тому амплітудний шум у вихідному спектрі сильно ослаблений.

Натомість для фази коливань у системі немає жодної абсолютної зовнішньої прив'язки в часі. Фазовий зсув, спричинений тепловим шумовим поштовхом, не зустрічає відновлювальної сили — він інтегрується й накопичується в часі. Це явище називають **дифузією фази**. Оскільки загальна потужність білого теплового шуму рівномірно ділиться між ортогональними амплітудною та фазовою складовими, рівно половина потужності теплового шуму (`1/2`) безпосередньо трансформується у фазовий шум.

## Передавальна функція резонатора в околі резонансу

Розглянемо автогенератор як лінійну систему зі зворотним зв'язком, де частотно-вибірковий елемент (LC-контур або кварцовий резонатор) має навантажену добротність `Q_L` та власну резонансну частоту `ω₀ = 2·π·f₀`.

Комплексний коефіцієнт передачі паралельного коливального контуру в околі резонансної частоти `ω = ω₀ + Δω` (де `Δω << ω₀` — відстрочка за частотою від носійної) описується виразом:

```
H_res(jω) = 1 / ( 1 + j · 2·Q_L · (Δω / ω₀) )
```

У стаціонарному режимі генерації за критерієм Баркгаузена петлеве підсилення на резонансній частоті дорівнює одиниці: `A(jω₀) · H_res(jω₀) = 1`.

При появі внутрішнього шумового струму або напруги відхилення сигналу на виході автогенератора визначається замкненою передавальною функцією системи:

```
H_cl(jω) = 1 / ( 1 - A · H_res(jω) )
```

Підставимо коефіцієнт передачі резонатора за умови `A = 1` на резонансі:

```
1 - H_res(jω)
= 1 - 1 / ( 1 + j · 2·Q_L · (Δω / ω₀) )                         [підстановка виразу H_res]
= ( 1 + j · 2·Q_L · (Δω / ω₀) - 1 ) / ( 1 + j · 2·Q_L · (Δω / ω₀) ) [зведення до спільного знаменника]
= ( j · 2·Q_L · (Δω / ω₀) ) / ( 1 + j · 2·Q_L · (Δω / ω₀) )     [спрощення чисельника]
```

Для малих відстрочок від носійної частоти в межах смуги резонатора (`Δω << ω₀ / (2·Q_L)`):

```
|1 - H_res(jω)| ≈ 2 · Q_L · |Δω| / ω₀
```

Звідси квадрат модуля замкненої передавальної функції підсилення шуму в петлі становить:

```
|H_cl(jω)|²
= 1 / |1 - H_res(jω)|²             [визначення квадрата модуля передачі]
= 1 / ( 2 · Q_L · |Δω| / ω₀ )²     [підстановка лінійного наближення]
= ( ω₀ / ( 2 · Q_L · Δω ) )²       [перевертання дробу]
= ( f₀ / ( 2 · Q_L · Δf ) )²       [перехід від кругової частоти до герців: ω = 2·π·f]
```

Цей множник описує ефект резонансного підсилення та інтегрування фазових флуктуацій: усередині смуги пропускання навантаженого контуру `Δf < f₀ / (2·Q_L)` спектральна густина фазового шуму спадає зі швидкістю `1 / Δf²` (тобто на 20 дБ на декаду збільшення відстрочки).

## Внесок теплового та низькочастотного флікер-шуму

Загальна спектральна густина теплового шуму, приведеного до входу активного елемента підсилювача, задається формулою Джонсона–Найквіста з урахуванням коефіцієнта шуму `F`:

```
S_in = F · k · T
```

де:
- `k = 1.380649·10⁻²³ Дж/К` — стала Больцмана;
- `T` — абсолютна температура в кельвінах (стандартна температура розрахунку `T = 290 К` або `300 К`);
- `F` — безрозмірний коефіцієнт шуму підсилювального каскаду (`F = 10^(NF/10)`).

Ураховуючи рівний розподіл потужності між амплітудною та фазовою компонентами (`1/2`), внесок білого шуму у фазові флуктуації становить:

```
S_φ,white = ( 1 / 2 ) · ( F · k · T / P_sig )
```

де `P_sig` — повна потужність вихідного гармонійного сигналу генератора на вході резонатора (у ватах).

Крім білого теплового шуму, реальні напівпровідникові прилади (біполярні та польові транзистори) мають власний низькочастотний флікер-шум зі спектральною густиною `1 / f`. Через нелінійну ємність p-n переходів транзистора (зокрема ємність колекторного чи стокового переходу) низькочастотні флуктуації напруги зміщують робочу точку та модулюють фазу високочастотного сигналу.

Цей процес описується множником флікерної модуляції:

```
M_flicker = 1 + f_c / |Δf|
```

де `f_c` — кутова частота флікер-шуму (англ. *flicker corner frequency*), на якій густина флікер-шуму зрівнюється з рівнем білого шуму.

## Повне аналітичне рівняння Лісона

Об'єднавши виведені складові, отримуємо остаточну напівемпіричну формулу Лісона для односмугової спектральної густини фазового шуму `L(Δf)` (виражається в децибелах відносно носійної на смугу 1 Гц — дБн/Гц):

```
L(Δf) = 10 · lg [ 1/2 · ( 1 + ( f₀ / (2 · Q_L · Δf) )² ) · ( F · k · T / P_sig ) · ( 1 + f_c / |Δf| ) ]
```

Спектр фазового шуму автогенератора згідно з моделлю Лісона чітко ділиться на три характерні частотні зони:

1. **Зона `1/Δf³` (спад 30 дБ/декада):**
   Діапазон найближчих відстрочок `Δf < f_c`. Тут домінує флікер-шум транзистора, перемножений на інтегруючу дію контуру `(1/Δf) · (1/Δf²) = 1/Δf³`.
2. **Зона `1/Δf²` (спад 20 дБ/декада):**
   Діапазон від `f_c` до половини смуги контуру `f₀ / (2·Q_L)`. Тут домінує білий тепловий шум, профільтрований резонатором.
3. **Широкосмуговий шумовий поріг (Noise Floor, плоска зона 0 дБ/декада):**
   Діапазон великих відстрочок `Δf > f₀ / (2·Q_L)`. Фільтрація контуру закінчується, і фазовий шум визначається суто тепловим порогом: `L_floor = 10 · lg [ ( F · k · T ) / ( 2 · P_sig ) ]`.

## Покроковий числовий розрахунок для генератора 100 МГц

**Вихідні інженерні параметри LC-генератора Колпітца:**
- Номінальна частота: `f₀ = 100 МГц = 10⁸ Гц`
- Навантажена добротність контуру: `Q_L = 50`
- Потужність сигналу в резонаторі: `P_sig = +10 дБм = 10 мВт = 10⁻² Вт`
- Коефіцієнт шуму транзистора: `NF = 6.0 дБ` (`F = 10^(6.0/10) ≈ 3.981`)
- Температура навколишнього середовища: `T = 300 К` (`k · T = 1.38065·10⁻²³ · 300 = 4.142·10⁻²¹ Дж`)
- Кутова частота флікер-шуму: `f_c = 10 кГц = 10⁴ Гц`

Обчислимо значення `L(Δf)` на двох характерних відстрочках: `Δf₁ = 10 кГц` та `Δf₂ = 1 МГц`.

### 1. Розрахунок широкосмугового теплового порогу

```
S_floor
= ( F · k · T ) / P_sig                    [формула теплового порогу]
= ( 3.981 · 4.142·10⁻²¹ ) / 10⁻²            [підстановка параметрів F, kT, P_sig]
= 1.6489·10⁻²⁰ / 10⁻²                       [обчислення чисельника]
= 1.6489·10⁻¹⁸ 1/Гц                         [кінцева густина ненормованого шуму]
```

Логарифмічний рівень порогу з урахуванням множника `1/2`:

```
L_floor
= 10 · lg( 0.5 · S_floor )                 [визначення вхідного порогу фазового шуму]
= 10 · lg( 0.5 · 1.6489·10⁻¹⁸ )             [підстановка S_floor]
= 10 · lg( 8.2445·10⁻¹⁹ )                  [множення на 0.5]
= 10 · ( -19 + lg( 8.2445·10¹ ) )          [виділення порядку]
= 10 · ( -19 + 0.91616 )                   [обчислення десяткового логарифма]
= -180.84 дБн/Гц                           [широкосмуговий шумовий поріг]
```

### 2. Смуга пропускання навантаженого контуру

```
f_bw
= f₀ / ( 2 · Q_L )                         [визначення напівширини смуги контуру]
= 10⁸ / ( 2 · 50 )                         [підстановка робочої частоти та добротності]
= 10⁸ / 100                                [множення в знаменнику]
= 10⁶ Гц = 1 МГц                           [гранична частота фільтрації резонатора]
```

### 3. Фазовий шум на відстрочці Δf = 10 кГц (зона 1/Δf³)

```
Множник фільтрації: ( f_bw / Δf )² = ( 10⁶ / 10⁴ )² = ( 100 )² = 10000
1 + ( f_bw / Δf )² = 1 + 10000 = 10001 ≈ 10⁴
Множник флікер-шуму: 1 + f_c / Δf = 1 + 10⁴ / 10⁴ = 1 + 1 = 2

L(10 кГц)
= L_floor + 10 · lg( 10001 ) + 10 · lg( 2 ) [логарифм повного добутку Лісона]
= -180.84 + 10 · 4.00004 + 10 · 0.30103     [обчислення окремих логарифмічних добавок]
= -180.84 + 40.00 + 3.01                   [проміжне сумування]
= -137.83 дБн/Гц                           [фазовий шум на відстрочці 10 кГц]
```

### 4. Фазовий шум на відстрочці Δf = 1 МГц (межа зони 1/Δf²)

```
Множник фільтрації: ( f_bw / Δf )² = ( 10⁶ / 10⁶ )² = 1² = 1
1 + ( f_bw / Δf )² = 1 + 1 = 2
Множник флікер-шуму: 1 + f_c / Δf = 1 + 10⁴ / 10⁶ = 1 + 0.01 = 1.01

L(1 МГц)
= L_floor + 10 · lg( 2 · 1.01 )            [логарифм добутку на відстрочці 1 МГц]
= -180.84 + 10 · lg( 2.02 )                [обчислення аргументу логарифма]
= -180.84 + 10 · 0.30535                   [обчислення десяткового логарифма]
= -177.79 дБн/Гц                           [фазовий шум на відстрочці 1 МГц]
```

Отримані значення наочно показують дію моделі: на відстрочці 1 МГц фазовий шум практично впритул опускається до абсолютного теплового порогу схеми (-178 дБн/Гц), тоді як поблизу носійної (на 10 кГц) шум піднятий резонансною петлею та флікер-ефектом до -138 дБн/Гц.
