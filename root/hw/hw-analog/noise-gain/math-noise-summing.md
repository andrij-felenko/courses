# 🧮 Виведення шумового підсилення та частотної компенсації ємнісного навантаження входу

Коли на вхід операційного підсилювача під'єднують ємнісне джерело — фотодіод, п'єзодатчик чи довгу коаксіальну лінію — або коли до інвертувального вузла сходяться десятки сигнальних резисторів суматора, схема часто починає шуміти в рази сильніше за розрахунки або взагалі зривається в високочастотну генерацію. Причина криється у частотній залежності коефіцієнта зворотного зв'язку `β(s)` та його оберненої величини `1/β(s)` — шумового підсилення. Нижче наведено строге математичне виведення передавальних функцій для багатоканального суматора, Т-подібного моста зворотного зв'язку, чотирирезисторного диференційного каскаду, активних фільтрів, інтеграторів і диференціаторів, трансімпедансного каскаду з ємністю на вхідному вузлі, знаходження оптимального коригувального конденсатора зворотного зв'язку `Cf` для баттервортівського відгуку другого порядку, аналітичний розрахунок коефіцієнта шуму (Noise Factor) та інтегрального шумового піка з урахуванням низькочастотного флікер-шуму `1/f`.

### Багатоканальний суматор: чому зростання кількості входів руйнує відношення сигнал/шум

Розглянемо інвертувальний суматор на `N` каналів. До інвертувального входу під'єднано `N` вхідних резисторів `R₁, R₂, ..., Rₙ`, а вихід з'єднано з інвертувальним входом через резистор `Rf`. Неінвертувальний вхід заземлено.

Знайдемо коефіцієнт передачі для `k`-го корисного сигналу `U_вх,k` (за умови нульових напруг на решті входів):

```
U_вих / U_вх,k
= −Rf / Rk                           [закон Ома для віртуального нуля на мінус-вході]
```

Для знаходження коефіцієнта зворотного зв'язку `β` обнулимо всі зовнішні джерела напруги (`U_вх,1 = ... = U_вх,n = 0`). Тоді всі `N` резисторів опиняються під'єднаними паралельно між інвертувальним входом і землею. Позначимо їхній еквівалентний паралельний опір `R_in,eq`:

```
1 / R_in,eq
= 1/R₁ + 1/R₂ + ... + 1/Rₙ           [формула паралельного з'єднання провідностей]
= ∑ (1/Rk)                           [сума за всіма каналами від k=1 до N]
```

Коефіцієнт зворотного зв'язку `β` — це частка напруги виходу, яка повертається на інвертувальний вхід через резистивний дільник, утворений `Rf` та `R_in,eq`:

```
β
= R_in,eq / (R_in,eq + Rf)            [дільник напруги на інвертувальному вході]
= 1 / (1 + Rf / R_in,eq)              [поділили чисельник і знаменник на R_in,eq]
= 1 / (1 + Rf · ∑(1/Rk))              [підставили суму провідностей для R_in,eq]
```

Шумове підсилення `NG` (англ. *Noise Gain*) є точним математичним оберненням величини `β`:

```
NG
= 1 / β                               [означення шумового підсилення через петлю]
= 1 + Rf · ∑(1/Rk)                    [підставили вираз для β]
= 1 + ∑ (Rf / Rk)                     [внесли Rf під знак суми]
= 1 + ∑ |G_сигн,k|                    [де |G_сигн,k| — модуль підсилення k-го сигналу]
```

Якщо маємо `N` однакових каналів, кожен із одиничним підсиленням сигналу (`R₁ = ... = Rₙ = Rf`, тобто `|G_сигн,k| = 1`):

```
NG
= 1 + N · 1                           [підставили N однакових одиничних каскадів]
= 1 + N                               [шумове підсилення для N однакових входів]
```

Звідси випливає фундаментальний наслідок для власної спектральної густини шуму напруги ОП `e_n`: на виході суматора шум масштабується у `(1 + N)` разів:

```
e_вих,ОП
= e_n · NG                            [власний шум ОП множиться на шумове підсилення]
= e_n · (1 + N)                       [для N однакових каналів із підсиленням 1]
```

Якщо сигнал одного каналу `U_вх` проходить на вихід із підсиленням 1 (`U_вих = U_вх`), то відношення напруги сигналу до напруги шуму ОП на виході становить:

```
SNR_вих
= U_вх / (e_n · (1 + N))              [відношення корисного сигналу до вихідного шуму]
= SNR_вх / (1 + N)                    [деградація пропорційна кількості входів суматора]
```

Смуга пропускання за частотою зрізу замкненого контуру `f_cl` для всіх каналів суматора одночасно звужується у `(1 + N)` разів порівняно з добутком підсилення на смугу `GBP`:

```
f_cl
= GBP / NG                            [частота перетину петльового підсилення з одиницею]
= GBP / (1 + N)                       [смуга суматора падає зі збільшенням кількості каналів]
```

### Т-подібний міст у зворотному зв'язку: ілюзія високого підсилення та шумовий колапс

Коли розробнику потрібен екстремально великий опір зворотного зв'язку (наприклад, `100 МОм` у фоточутливих каскадах чи електрометрах), використання одного високоомного резистора пов'язане з проблемами: висока ціна, нестабільність від вологи та паразитна ємність корпусу.
Поширеним «спрощенням» є використання Т-подібного моста з трьох помірних резисторів `R₁`, `R₂` та `R₃` (де `R₃` увімкнено між середньою точкою моста та землею).

Знайдемо еквівалентний трансімпеданс `Req` такого моста для корисного струму:

```
U_середнє = −I_вх · R₁                [спад напруги на першому плечі моста]
I_R3 = U_середнє / R₃ = −I_вх · (R₁ / R₃)  [струм шунтувального резистора R3]
I_R2 = I_вх + I_R3 = I_вх · (1 + R₁ / R₃)  [струм через друге плече моста]

Uвих
= U_середнє − I_R2 · R₂               [потенціал виходу ОП]
= −I_вх · R₁ − I_вх · R₂ · (1 + R₁ / R₃)  [підставили вирази для струмів]
= −I_вх · [ R₁ + R₂ + (R₁ · R₂) / R₃ ]    [винесли I_вх за дужки]
```

Еквівалентний опір передачі становить:

```
Req = R₁ + R₂ + (R₁ · R₂) / R₃
```

Якщо взяти `R₁ = R₂ = 100 кОм`, а `R₃ = 100 Ом`, отримаємо велетенський еквівалентний опір:

```
Req
= 100·10³ + 100·10³ + (100·10³ · 100·10³) / 100  [підставили номінали]
= 200·10³ + 100·10⁶
≈ 100.2 МОм                          [еквівалентний трансімпеданс досягнуто]
```

Але тепер знайдемо коефіцієнт зворотного зв'язку `β` та шумове підсилення `NG` для цього Т-моста!
Обчислимо дільник напруги від виходу `Uвих` до інвертувального входу за умови під'єднання вхідного джерела з внутрішнім опором `Rin`:

```
β
= [ R₃ / (R₂ + R₃) ] · [ Rin / (Rin + R₁ + (R₂ ∥ R₃)) ]  [добуток коефіцієнтів двох дільників]
≈ (R₃ / R₂) · [ Rin / (Rin + R₁) ]   [оскільки R3 ≪ R2]
```

Звідси шумове підсилення `NG = 1 / β`:

```
NG
= (R₂ / R₃) · [ (Rin + R₁) / Rin ]   [обернули дріб для коефіцієнта зв'язку]
= (R₂ / R₃) · [ 1 + R₁ / Rin ]       [почленно поділили чисельник на Rin]
```

Для наших значень (`R₂ / R₃ = 100 кОм / 100 Ом = 1000`) шумове підсилення становить щонайменше:

```
NG ≥ 1000
```

Це призводить до інженерної катастрофи:
1. **Напруга зміщення `Vos`** підсилюється на виході в 1000 разів! ОП зі зміщенням `1 мВ` видасть на виході постійну напругу `1 В`.
2. **Власний шум напруги `en`** (наприклад, 10 нВ/√Гц) виходить на вихід із густиною `10 мкВ/√Гц`!
3. **Смуга пропускання** падає у 1000 разів: підсилювач із `GBP = 10 МГц` матиме смугу лише `10 кГц`.

Математичний висновок однозначний: **Т-міст у зворотному зв'язку дає колосальне шумове підсилення і руйнує динамічний діапазон схеми. У прецизійних трактах завжди слід віддавати перевагу одиночному високоомному резистору.**

### Диференціатори та інтегратори: аналіз частотної стабільності

Розглянемо базові операційні схеми аналогової обробки сигналів: ідеальний диференціатор та інтегратор.

#### 1. Ідеальний аналоговий диференціатор
У диференціаторі на вході встановлено конденсатор `C`, а в колі зворотного зв'язку — резистор `R`.
Сигнальна передавальна функція:

```
G_сигн(s) = −s · R · C               [диференціювання в часовій області]
```

Знайдемо шумове підсилення схеми:

```
Zin(s) = 1 / (s · C)
Zf(s) = R
β(s) = Zin / (Zin + Zf) = 1 / (1 + s · R · C)
NG(s) = 1 / β(s) = 1 + s · R · C
```

Шумове підсилення `NG(s)` має нуль на частоті `fz = 1 / (2·π·R·C)` і далі **безперервно зростає з нахилом +20 дБ/декаду**.
У точці перетину з власною характеристикою ОП `A(f)` (−20 дБ/дек) швидкість зближення дорівнює `ROC = 40 дБ/дек`.
Ідеальний диференціатор на операційному підсилювачі є **принципово нестійким**: він або самозбуджується на високих частотах, або насичується власним високочастотним шумом.

Щоб стабілізувати диференціатор, послідовно з вхідним конденсатором `C` додають резистор `Rin`. Тоді на високих частотах (`s → ∞`) шумове підсилення обмежується значенням:

```
NG_max = 1 + R / Rin
```

Це формує полюс у передавальній функції `1/β(s)` і відновлює безпечну швидкість зближення `ROC = 20 дБ/дек`.

#### 2. Інтегратор Міллера
В інтеграторі на вході стоїть резистор `R`, а в колі зворотного зв'язку — конденсатор `C`.
Сигнальне підсилення: `G_сигн(s) = −1 / (s · R · C)`.
Шумове підсилення:

```
Zin(s) = R
Zf(s) = 1 / (s · C)
β(s) = Rin / (Rin + 1 / (s · C)) = (s · R · C) / (1 + s · R · C)
NG(s) = 1 / β(s) = 1 + 1 / (s · R · C) = (1 + s · R · C) / (s · R · C)
```

На низьких частотах (`s → 0`) шумове підсилення прямує до нескінченності (`NG → ∞`), оскільки конденсатор розімкнений і схема не має від'ємного зворотного зв'язку за постійним струмом. Напруга зміщення `Vos` та вхідний струм зсуву інтегруються в часі, викликаючи дрейф виходу до шини живлення. Паралельне шунтування конденсатора високоомним резистором `Rf` обмежує статичне шумове підсилення до `NG(0) = 1 + Rf / R`.

### Диференційний підсилювач на 4 резисторах: симетрія сигналів та шуму

Розглянемо класичний диференційний каскад (англ. *difference amplifier*) на одному операційному підсилювачі. До інвертувального входу під'єднано резистор `R₁` від джерела `V−` та резистор зворотного зв'язку `R₂` з виходу `Uвих`. До неінвертувального входу під'єднано дільник напруги: резистор `R₃` від джерела `V+` та резистор `R₄` на землю.

Для забезпечення високого коефіцієнта придушення синфазного сигналу (CMRR) номінали резисторів узгоджують у пропорції:

```
R₂ / R₁ = R₄ / R₃ = K                [умова симетрії моста для максимального CMRR]
```

Знайдемо диференційний коефіцієнт підсилення сигналу `U_diff = V+ − V−`:

```
V+_вхід = V+ · [ R₄ / (R₃ + R₄) ]    [напруга на неінвертувальному вході ОП]
        = V+ · [ K / (1 + K) ]       [поділили чисельник і знаменник на R₃]

Uвих
= V+_вхід · (1 + R₂ / R₁) − V− · (R₂ / R₁)  [суперпозиція за неінвертувальним та інвертувальним входами]
= V+ · [ K / (1 + K) ] · (1 + K) − V− · K   [підставили вираз для V+_вхід та R₂/R₁ = K]
= K · (V+ − V−)                             [скоротили множник (1 + K)]
= (R₂ / R₁) · U_diff                        [підсилення диференційного корисного сигналу]
```

Тепер знайдемо коефіцієнт зворотного зв'язку `β` та шумове підсилення `NG` для внутрішніх шумів і напруги зміщення `Vos`.

Обнулимо зовнішні джерела сигналів (`V+ = 0`, `V− = 0`). Тоді:
- Інвертувальний вхід бачить дільник із резисторів `R₂` (з виходу) та `R₁` (на землю).
- Неінвертувальний вхід з'єднаний із землею через паралельне з'єднання `R₃ ∥ R₄`.

Коефіцієнт зворотного зв'язку `β` визначається виключно петлею від виходу до інвертувального входу:

```
β
= R₁ / (R₁ + R₂)                     [дільник зворотного зв'язку на інвертувальному вході]
= 1 / (1 + R₂ / R₁)                  [поділили чисельник і знаменник на R₁]
= 1 / (1 + K)                        [де K = R₂/R₁ — сигнальне диференційне підсилення]
```

Звідси шумове підсилення диференційного підсилювача:

```
NG
= 1 / β                              [обернений коефіцієнт зворотного зв'язку]
= 1 + R₂ / R₁                        [шумове підсилення для внутрішніх шумів]
= 1 + K                              [на одиницю більше за диференційне підсилення!]
```

Цей результат пояснює важливу інженерну закономірність:
1. **Одиничний диференційний підсилювач (`K = 1`, `R₁ = R₂ = R₃ = R₄ = 10 кОм`)** має диференційне підсилення сигналу `G_diff = 1`, але його шумове підсилення дорівнює `NG = 1 + 1 = 2`.
2. Вхідна напруга зміщення `Vos` операційного підсилювача виходить на вихід подвоєною: `Vos,out = 2 · Vos`.
3. Власний шум напруги `en` масштабується у 2 рази: `en,out = 2 · en`.
4. Смуга пропускання диференційного каскаду становить `f_cl = GBP / 2`.

### Розрахунок коефіцієнта шуму (Noise Figure) інвертувального та неінвертувального каскадів

Коефіцієнт шуму `F` (англ. *Noise Factor*) та його децибельне вираження `NF` (англ. *Noise Figure*) кількісно визначають, на скільки погіршується відношення сигнал/шум при проходженні сигналу крізь підсилювальний каскад:

```
F = SNR_вхід / SNR_вихід = 1 + ( e_дод_вх² / (4 · k · T · Rs) )
NF = 10 · log₁₀(F)
```

де `Rs` — внутрішній опір джерела сигналу, а `e_дод_вх²` — спектральна густина потужності всіх додаткових шумів підсилювача, приведених до його входу.

#### 1. Неінвертувальний підсилювач із коефіцієнтом G = 1 + Rf/Rg
Приведений до входу сумарний шум підсилювача становить:

```
e_дод_вх²(неінв)
= en² + (in+ · Rs)² + (in− · (Rf ∥ Rg))² + 4 · k · T · (Rf ∥ Rg)
```

Коефіцієнт шуму неінвертувального каскаду:

```
F_неінв
= 1 + [ en² + (in+ · Rs)² + 4·k·T·(Rf ∥ Rg) ] / (4 · k · T · Rs)
```

#### 2. Інвертувальний підсилювач із підсиленням G = −Rf/Rin (де Rin = Rs)
В інвертувальному підсилювачі весь вхідний резистор `Rin` сам є джерелом теплового шуму `4·k·T·Rin`. Крім того, власний шум ОП `en` множиться на шумове підсилення `NG = 1 + Rf/Rin`, тоді як сигнал підсилюється лише в `Rf/Rin` разів.

Приведений до входу шум інвертувального каскаду:

```
e_дод_вх²(інв)
= en² · [ (1 + Rf / Rin) / (Rf / Rin) ]² + 4 · k · T · (Rf / (Rf / Rin)²) + (in− · Rin)²
= en² · (1 + Rin / Rf)² + 4 · k · T · (Rin² / Rf) + (in− · Rin)²
```

Поділивши на шум джерела `4·k·T·Rin`:

```
F_інв
= 1 + [ en² · (1 + Rin/Rf)² + 4·k·T·(Rin²/Rf) ] / (4 · k · T · Rin)
```

Оскільки множник `(1 + Rin/Rf)² > 1`, коефіцієнт шуму інвертувального каскаду **завжди вищий, ніж у неінвертувального**. При слабкому підсиленні (`Rf/Rin = 1` або `0.1`) інвертувальна схема додає в рази більше шуму через надлишок шумового підсилення `NG`.

### Активні фільтри: частотна поведінка шумового підсилення

У схемах активних фільтрів другого порядку топологія кола зворотного зв'язку містить реактивні елементи (конденсатори), через що коефіцієнт `β(s)` та шумове підсилення `NG(s)` суттєво змінюються від нульової частоти до нескінченності.

#### 1. Фільтр Саллена-Кея (Sallen-Key)

У низькочастотному фільтрі Саллена-Кея з одиничним коефіцієнтом підсилення ОП увімкнено за схемою повторювача (`Rf = 0`, `Rin → ∞`).

На постійному струмі (`s = 0`):
- Усі конденсатори розімкнені.
- Вихід з'єднаний безпосередньо з інвертувальним входом: `β(0) = 1`, отже `NG(0) = 1` (0 дБ).

На нескінченно високій частоті (`s → ∞`):
- Конденсатор зворотного зв'язку `C₁` між виходом і проміжним вузлом фільтра замикається накоротко.
- Вхідний конденсатор `C₂` на плюс-вході замикає неінвертувальний вхід на землю.
- Зворотний зв'язок з виходу на мінус-вхід залишається прямим з'єднанням: `β(∞) = 1`, отже `NG(∞) = 1`.

Шумове підсилення фільтра Саллена-Кея залишається близьким до одиниці на всіх частотах (із невеликим резонансним горбом біля частоти зрізу, пропорційним добротності фільтра `Q`). Тому фільтри Саллена-Кея є одними з найменш шумних активних фільтрів.

#### 2. Фільтр із багаторазовим зворотним зв'язком (MFB / Multiple Feedback)

У низькочастотному фільтрі MFB сигнал подається на інвертувальний вхід через резистивно-конденсаторний міст.

На постійному струмі (`s = 0`):
- Конденсатори розімкнені.
- Схема працює як звичайний інвертувальний підсилювач із резисторами `R₁` та `R₂`:

```
G_сигн(0) = −R₂ / R₁
NG(0) = 1 + R₂ / R₁
```

На високих частотах (`s → ∞`):
- Конденсатор зворотного зв'язку `C₁`, увімкнений паралельно до резистора `R₂`, замикає вихід ОП на інвертувальний вхід (`Zf → 0`).
- Водночас конденсатор `C₂` замикає вхідний резистивний дільник на землю.
- Передавальна функція зворотного зв'язку `β(s)` має високочастотний нуль, через що шумове підсилення `NG(s)` на високих частотах формує спад або підйом залежно від співвідношення ємностей.

Аналіз показує, що для фільтрів MFB з високою добротністю `Q > 2` характеристика `1/β(s)` формує виражений резонансний пік на частоті зрізу фільтра, що вимагає вибору операційного підсилювача з `GBP` щонайменше у `20–50` разів вищим за частоту зрізу фільтра для запобігання фазовому збудженню.

### Трансімпедансний підсилювач: зворотний зв'язок у комплексній площині Laplace

У трансімпедансному перетворювачі (TIA) фотодіод або ємнісний датчик під'єднано до інвертувального входу.
Повна паразитна ємність на інвертувальному вузлі `Cin` складається з трьох доданків:

```
Cin
= Cd + C_cm + C_diff + C_pcb          [ємність датчика Cd + синфазна, диференційна та монтажна ємності]
```

У колі зворотного зв'язку паралельно до резистора `Rf` встановлено конденсатор компенсації `Cf`.
Знайдемо комплексні імпеданси вхідного та зворотного кіл у формі оператора Лапласа `s = j·ω`:

```
Z_in(s)
= 1 / (s · Cin)                       [імпеданс повної вхідної ємності інвертувального вузла]

Z_f(s)
= Rf ∥ (1 / (s · Cf))                 [паралельне з'єднання резистора Rf та конденсатора Cf]
= Rf / (1 + s · Rf · Cf)              [еквівалентний імпеданс ланки зворотного зв'язку]
```

Коефіцієнт зворотного зв'язку `β(s)` як дільник напруги між виходом ОП та інвертувальним входом:

```
β(s)
= Z_in(s) / (Z_in(s) + Z_f(s))        [формула дільника напруги]
= 1 / (1 + Z_f(s) / Z_in(s))          [поділили на Z_in(s)]
= 1 / (1 + s · Cin · Z_f(s))          [підставили 1/Z_in(s) = s·Cin]
= 1 / (1 + (s · Cin · Rf) / (1 + s · Rf · Cf))  [підставили вираз для Z_f(s)]
= (1 + s · Rf · Cf) / (1 + s · Rf · Cf + s · Rf · Cin)  [звели до спільного знаменника]
= (1 + s · Rf · Cf) / (1 + s · Rf · (Cin + Cf))         [згрупували доданки з s]
```

Знайдемо комплексну функцію шумового підсилення `NG(s) = 1 / β(s)`:

```
NG(s)
= 1 / β(s)                            [шумове підсилення як обернений коефіцієнт зв'язку]
= (1 + s · Rf · (Cin + Cf)) / (1 + s · Rf · Cf)         [обернули дріб β(s)]
```

Аналізуючи нулі та полюси передавальної функції `NG(s)`:
1. Функція має **нуль** на частоті `ω_z` (де `NG(s)` починає зростати з нахилом +20 дБ/декада):

```
ω_z
= 1 / (Rf · (Cin + Cf))               [кругова частота нуля шумового підсилення]
f_z
= 1 / (2 · π · Rf · (Cin + Cf))       [частота нуля в герцах]
```

2. Функція має **полюс** на частоті `ω_p` (де зростання `NG(s)` припиняється і формується високочастотна поличка):

```
ω_p
= 1 / (Rf · Cf)                       [кругова частота полюса шумового підсилення]
f_p
= 1 / (2 · π · Rf · Cf)               [частота полюса в герцах]
```

На нульовій частоті (`s = 0`): `NG(0) = 1` (0 дБ).
На нескінченно високій частоті (`s → ∞`):

```
NG(∞)
= (Cin + Cf) / Cf                     [високочастотна границя шумового підсилення]
= 1 + Cin / Cf                        [визначається відношенням ємностей]
```

### Характеристичне рівняння та виведення оптимальної ємності Cf

Модель операційного підсилювача з інтегральною однополюсною корекцією та добутком підсилення на смугу `GBP = ω_t / (2·π)` має комплексний коефіцієнт підсилення без зворотного зв'язку:

```
A(s)
≈ ω_t / s                             [інтеграторна апроксимація у робочій смузі частот]
```

Замкнена передавальна функція для вхідного сигналу пропорційна коефіцієнту прямого перетворення, поділеному на характеристичний вираз замкненого контуру:

```
D(s)
= 1 + A(s) · β(s)                     [характеристичний поліном зворотного зв'язку]
= 1 + (ω_t / s) · ( (1 + s·Rf·Cf) / (1 + s·Rf·(Cin + Cf)) )  [підставили A(s) та β(s)]
```

Прирівняємо характеристичний вираз до нуля для пошуку полюсів замкненої системи:

```
s · (1 + s · Rf · (Cin + Cf)) + ω_t · (1 + s · Rf · Cf) = 0  [помножили на s·(1 + s·Rf·(Cin+Cf))]
s + s² · Rf · (Cin + Cf) + ω_t + s · ω_t · Rf · Cf = 0       [розкрили дужки]
s² · Rf · (Cin + Cf) + s · (1 + ω_t · Rf · Cf) + ω_t = 0     [згрупували за степенями s]
```

Поділимо все рівняння на коефіцієнт при `s²`, тобто на `Rf · (Cin + Cf)`:

```
s² + s · [ (1 + ω_t · Rf · Cf) / (Rf · (Cin + Cf)) ] + [ ω_t / (Rf · (Cin + Cf)) ] = 0
```

Порівняємо це з канонічним характеристичним рівнянням ланки 2-го порядку:

```
s² + 2 · ζ · ω₀ · s + ω₀² = 0         [де ω₀ — власна резонансна частота, ζ — коефіцієнт демпфування]
```

Зіставлення коефіцієнтів дає:

```
ω₀²
= ω_t / (Rf · (Cin + Cf))             [квадрат власної частоти замкненого кола]

ω₀
= √( ω_t / (Rf · (Cin + Cf)) )        [власна частота]

2 · ζ · ω₀
= (1 + ω_t · Rf · Cf) / (Rf · (Cin + Cf))  [коефіцієнт при першому степені s]
```

Для отримання максимально плоскої амплітудно-частотної характеристики Баттерворта без викидів і дзвону у перехідній характеристиці коефіцієнт демпфування вибирають рівним:

```
ζ
= 1 / √2 ≈ 0.707                      [умова максимально плоскої АЧХ Баттерворта, Q = 1/√2]
```

Підставимо `ζ = 1/√2` у вираз для лінійного коефіцієнта:

```
2 · (1 / √2) · ω₀
= √2 · ω₀                             [спрощення лівої частини]
= √2 · √( ω_t / (Rf · (Cin + Cf)) )   [підставили значення ω₀]
```

Прирівняємо до правої частини, нехтуючи одиницею порівняно з `ω_t · Rf · Cf` (оскільки `ω_t · Rf · Cf ≫ 1` для практичних ОП):

```
√2 · √( ω_t / (Rf · (Cin + Cf)) )
≈ (ω_t · Rf · Cf) / (Rf · (Cin + Cf)) [наближення для ω_t·Rf·Cf ≫ 1]
= (ω_t · Cf) / (Cin + Cf)             [скоротили Rf у чисельнику й знаменнику]
```

Піднесемо обидві частини рівності до квадрата:

```
2 · [ ω_t / (Rf · (Cin + Cf)) ]
= [ ω_t² · Cf² ] / (Cin + Cf)²        [піднесення до квадрата]
```

Помножимо обидві частини на `(Cin + Cf)²` та поділимо на `ω_t`:

```
2 · (Cin + Cf) / Rf
= ω_t · Cf²                           [спрощення після скорочення]
```

Оскільки в оптимально скомпемсованому каскаді `Cf ≪ Cin`, наближено `Cin + Cf ≈ Cin`:

```
2 · Cin / Rf
≈ ω_t · Cf²                           [наближення малої ємності зворотного зв'язку]

Cf²
= (2 · Cin) / (ω_t · Rf)              [виразили квадрат ємності]
= (2 · Cin) / (2 · π · GBP · Rf)      [підставили ω_t = 2·π·GBP]
= Cin / (π · GBP · Rf)                [скоротили двійку]
```

Добуваємо квадратний корінь і отримуємо класичну інженерну формулу оптимальної ємності компенсації:

```
Cf
= √( Cin / (2 · π · Rf · GBP) )       [для демпфування Баттерворта з запасом фази ≈ 65.5°]
```

### Аналітичний розрахунок шумового піка з урахуванням шуму 1/f

Вхідний шум напруги ОП має дві складові: білий широкосмуговий шум `e_nw` та низькочастотний флікер-шум `1/f` із частотою перегину `f_nc` (англ. *1/f noise corner frequency*):

```
e_n²(f)
= e_nw² · (1 + f_nc / f)              [модель спектральної густини з флікер-шумом]
```

Повна спектральна густина напруги шуму на виході TIA з урахуванням частотної характеристики шумового підсилення `NG(f)`:

```
e_вих²(f)
= e_n²(f) · |NG(f)|²
= e_nw² · (1 + f_nc / f) · [ (1 + (f / f_z)²) / (1 + (f / f_p)²) ]
```

Для знаходження середньоквадратичного значення напруги шуму `V_rms` проінтегруємо потужність шуму від нижньої межі вимірювання `f_low` (зазвичай 0.1 ГГц або 10 Гц) до верхньої частоти зрізу замкненого контуру `f_cl`:

```
V_noise,rms²
= ∫_{f_low}^{f_cl} e_вих²(f) df       [повний інтеграл потужності шуму за робочою смугою]
```

Розглянемо випадок некомпенсованого каскаду (`Cf = 0`, отже `f_p → ∞`), де домінує білий шум на ділянці зростання `f_z < f < f_cl`:

```
V_noise,rms²
≈ ∫_{f_low}^{f_z} e_nw² df + ∫_{f_z}^{f_cl} e_nw² · (f / f_z)² df  [розбиття на низькочастотну та високочастотну ділянки]
= e_nw² · (f_z − f_low) + (e_nw² / f_z²) · [ (f_cl³ − f_z³) / 3 ]   [інтегрування полінома другого степеня]
≈ (e_nw² / (3 · f_z²)) · f_cl³        [оскільки f_cl ≫ f_z, кубічний член визначає понад 95% шуму]
```

Добуваючи корінь:

```
V_noise,rms
≈ e_nw · √( f_cl³ / (3 · f_z²) )      [кубічна пропорційність від смуги спричиняє шумовий сплеск]
```

Коли встановлено розрахунковий конденсатор `Cf`, частота полюса `f_p` обмежує підйом кривої `1/β(f)` на рівні `1 + Cin/Cf`. Інтеграл шуму на ділянці `f_p < f < f_cl` стає лінійним замість кубічного:

```
V_noise,rms²(comp)
≈ e_nw² · f_z + (e_nw² / f_z²) · (f_p³ / 3) + e_nw² · (1 + Cin/Cf)² · (f_cl − f_p)
```

Завдяки цьому введення ємності `Cf = 0.8–1 пФ` знижує інтегральну напругу вихідного шуму у 10–50 разів, перетворюючи потенційно нестійкий каскад на прецизійний тракт реєстрації оптичного сигналу.
