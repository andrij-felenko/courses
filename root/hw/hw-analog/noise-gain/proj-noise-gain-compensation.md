# ⚙️ Розрахунок шумового бюджету та стабілізації декомпенсованих ОП

Коли високошвидкісний операційний підсилювач із малим власним шумом використовують у каскаді зі слабким підсиленням (наприклад, одиничний інвертор `G = −1` або атенюатор `G = −0.1`), розробник стикається з двома небезпеками: підсилювач із неповною внутрішньою корекцією (декомпенсований ОП) самозбуджується через брак шумового підсилення, а розрахунок шуму за коефіцієнтом сигналу дає занижену в рази похибку. Нижче наведено інженерну утиліту на C та C++, яка обчислює справжній коефіцієнт шумового підсилення, смугу пропускання, сумарний вихідний шум і напругу зміщення, а також розраховує параметри коригувального ланцюга штучного завищення шумового підсилення `Rш–Cш` для забезпечення абсолютної стійкості високошвидкісних аналогових трактів.

### Інженерний контекст: конфлікт швидкодії та малого підсилення

При проектуванні вхідних каскадів для широкосмугових АЦП, швидкісних фотоприймачів оптичного зв'язку чи вимірювальних трактів осцилографів інженеру потрібні операційні підсилювачі з екстремальними параметрами:
1. Дуже високий добуток підсилення на смугу (`GBP` від сотень мегагерців до кількох гігагерців);
2. Велика швидкість наростання вихідної напруги (`Slew Rate > 1000 В/мкс`) для передачі крутих фронтів без динамічних спотворень;
3. Наднизький рівень власного шуму напруги (`en < 1.5 нВ/√Гц`).

Універсальні підсилювачі з повною внутрішньою корекцією (англ. *unity-gain stable*) не можуть одночасно забезпечити такі показники при помірному струмі споживання. Щоб зробити підсилювач стійким при коефіцієнті підсилення `×1`, виробники змушені штучно збільшувати ємність внутрішнього коригувального конденсатора Міллера. Це гальмує вихідний каскад і звужує робочу смугу.

Тому провідні виробники напівпровідників (Texas Instruments, Analog Devices) випускають **декомпенсовані ОП** (наприклад, OPA657, OPA847, ADA4899, LMH6629). Внутрішню ємність корекції в них зменшено в рази. Підсилювач отримує гігагерцову смугу та колосальну швидкість наростання, але вимагає від схеми обов'язкового мінімального шумового підсилення: `NG ≥ 5` (14 дБ), `NG ≥ 7` (17 дБ) або `NG ≥ 10` (20 дБ).

Якщо такий підсилювач увімкнути за звичайною інвертувальною схемою з малим підсиленням корисного сигналу (наприклад, атенюатор `G_сигн = −0.2` або буфер `G_сигн = −1`), його шумове підсилення складе `NG = 1 + |G_сигн| = 1.2` або `2.0`. Це значно нижче порогу стійкості `NG_min = 5`. На виході негайно виникає паразитна генерація на частотах у сотні мегагерців.

Традиційні спроби виправити ситуацію зазвичай провалюються:
- Встановлення конденсатора паралельно резистору зворотного зв'язку `Rf` зменшує шумове підсилення на високих частотах до одиниці (`NG → 1`), що лише погіршує нестійкість декомпенсованого ОП;
- Збільшення резистора зворотного зв'язку `Rf` збільшує шум Джонсона і звужує смугу пропускання корисного сигналу;
- Встановлення фільтра низьких частот перед підсилювачем фільтрує корисний сигнал, але ніяк не впливає на внутрішній контур петлі зворотного зв'язку ОП.

### Фізичний принцип: штучне маніпулювання шумовим підсиленням

Єдиним коректним методом використання швидкісних декомпенсованих ОП у каскадах із низьким сигнальним підсиленням є **штучне завищення шумового підсилення** (англ. *Noise Gain Manipulation*) за допомогою фазовипереджально-запізнювального ланцюга (англ. *lead-lag network*).

Між інвертувальним (`V−`) та неінвертувальним (`V+`) входами операційного підсилювача під'єднують послідовний ланцюг із резистора `R_dummy` (шунтувальний резистор `Rш`) та конденсатора `C_dummy` (розділовий конденсатор `Cш`).

Розберемо поведінку цієї структури для двох різних процесів:

#### 1. Проходження корисного сигналу (DC та робочі частоти)
Корисний сигнал `Uвх` заходить через резистор `Rin` на інвертувальний вхід. Неінвертувальний вхід під'єднано до землі (`V+ = 0 В`). Завдяки велетенському підсиленню ОП зворотний зв'язок підтримує на інвертувальному вході потенціал віртуального нуля (`V− ≈ 0 В`).

Різниця потенціалів на виводах коригувального ланцюга `R_dummy–C_dummy` дорівнює:

```
ΔV = V+ − V− = 0 В − 0 В = 0 В
```

Оскільки напруга на ланцюгу дорівнює нулю, струм корисного сигналу крізь нього **не протікає взагалі**:

```
I_dummy = ΔV / Z_dummy = 0 / Z_dummy = 0 А
```

Весь струм вхідного сигналу `I_in = Uвх / Rin` без втрат проходить через резистор зворотного зв'язку `Rf`. Коефіцієнт підсилення сигналу залишається строго незмінним:

```
Uвих / Uвх = −Rf / Rin
```

#### 2. Зворотний зв'язок та стійкість на високих частотах
Коли розраховують коефіцієнт зворотного зв'язку `β`, зовнішнє джерело вхідного сигналу занулюють (`Uвх = 0 В`, що еквівалентно заземленню лівого виводу `Rin`).

На високих частотах біля частоти зрізу петлі `f_cross` конденсатор `C_dummy` замикається накоротко (`Z_C ≈ 0`). Тепер резистор `R_dummy` виявляється увімкненим паралельно до резистора `Rin` між інвертувальним входом і землею.

Еквівалентний опір нижнього плеча дільника зворотного зв'язку стає рівним:

```
Req = Rin ∥ R_dummy = (Rin · R_dummy) / (Rin + R_dummy)
```

Шумове підсилення на високих частотах стрибає вгору до розрахункового значення:

```
NG_hf = 1 + Rf / Req = 1 + Rf / Rin + Rf / R_dummy
```

Підбираючи номінал `R_dummy`, ми штучно виставляємо `NG_hf = NG_min` (наприклад, `NG_hf = 7.0`). У точці перетину амплітудної характеристики з графіком власного підсилення `A(f)` підсилювач «бачить» шумове підсилення `×7`, швидкість зближення становить безпечні `20 дБ/дек`, і схема зберігає повний запас стійкості.

Конденсатор `C_dummy` потрібен для того, щоб розімкнути коло постійного струму. Завдяки йому на нульовій і низьких частотах `NG_dc = 1 + Rf/Rin`, тому напруга зміщення `Vos` і дрейф не підсилюються. Частоту перегину `f_zero = 1 / (2·π·R_dummy·C_dummy)` обирають приблизно в 10 разів нижчою за очікувану частоту перетину `f_cross`.

### Оптичний вхід: фотодіодний трансімпедансний тракт (TIA)

У швидкісних фотоприймальних пристроях (лідари, оптоволоконні приймачі, спектрометри) фотодіод генерує струм, пропорційний оптичній потужності. Фотодіод можна підключати у двох режимах:

#### 1. Фотогальванічний режим (Photovoltaic mode, нульове зміщення Vbias = 0)
- Зворотна напруга на фотодіоді дорівнює нулю.
- Темновий струм відсутній, що усуває додатковий дробовий шум `√(2·q·Idark)`.
- Але бар'єрна ємність p-n переходу `Cd` є максимальною (наприклад, `80–120 пФ`).
- Велика ємність зсуває нуль шумового підсилення `fz` вниз за частотою, викликаючи потужний сплеск `1/β(f)` і звужуючи стабільну смугу сигналу.

#### 2. Фотопровідниковий режим (Photoconductive mode, зворотне зміщення Vbias = 3.3...15 В)
- Зворотна напруга розширює збіднену область p-n переходу, зменшуючи ємність `Cd` у 4–6 разів (наприклад, з `100 пФ` до `20 пФ`).
- Зменшення `Cin` зміщує нуль `fz` вгору за частотою, розширюючи смугу пропускання трансімпедансного каскаду у `√(100/20) ≈ 2.24` раза.
- Ціною є поява темнового струму витоку `Idark` (наприклад, `5 нА`), який генерує дробовий струм шуму `in,shot = √(2 · q · Idark) = √(2 · 1.6·10⁻¹⁹ · 5·10⁻⁹) ≈ 1.26 пА/√Гц`.

Інженерний компроміс: фотопровідниковий режим обирають для максимальної швидкодії (понад 10 МГц), а фотогальванічний — для наднизького шуму в діапазоні до 1 МГц.

### Динамічні характеристики: перехідний процес, викид та час встановлення

Шумове підсилення `NG` безпосередньо формує коефіцієнт демпфування `ζ` замкненого контуру. При подачі на вхід ідеального перепаду напруги (сходинки) вихідний сигнал другого порядку описується рівнянням:

```
Uвих(t) = U₀ · [ 1 − (1 / √(1 − ζ²)) · e^{−ζ·ω₀·t} · sin(ω₀·√(1 − ζ²)·t + arccos(ζ)) ]
```

Ключові показники якості перехідного процесу:
1. **Відносне перерегулювання (викид / overshoot)**:
   `Overshoot% = 100 · exp( −π · ζ / √(1 − ζ²) )`.
   - При `ζ = 0.707` (Баттерворт): викид становить лише `4.3%`.
   - При `ζ = 0.38` (запас фази 40°): викид зростає до `28%`.
   - При `ζ → 0` (запас фази 0°): виникають незатухаючі коливання (генерація).
2. **Час наростання фронту від 10% до 90%**:
   `t_r ≈ 0.35 / f_cl = 0.35 · (NG / GBP)`.
3. **Час встановлення (settling time)** до похибки 0.1%:
   `t_s ≈ 7 / (ζ · ω₀)`.

### Робота на ємнісне навантаження: подвійний зворотний зв'язок (Dual Feedback)

Коли підсилювач із малим шумовим підсиленням повинен працювати на кабель або фільтр з ємністю `Cload = 1–100 нФ`, вихідний опір ОП `Ro` створює додатковий полюс, що завалює фазу петлі на 90°.
Для усунення генерації застосовують ланцюг подвійного зворотного зв'язку:
1. Послідовно з виходом ОП встановлюють ізолюючий резистор `Riso` (зазвичай `20–50 Ом`), який відокремлює навантаження від вихідного каскаду.
2. Постійний струм і сигнал низьких частот знімають після `Riso` через основний резистор `Rf`, забезпечуючи точність передачі напруги під навантаженням.
3. Високочастотний зворотний зв'язок замикають безпосередньо з виходу ОП на інвертувальний вхід через конденсатор `Cf_hf = (Cload · Ro) / Rf`.

На високих частотах конденсатор `Cf_hf` шунтує навантаження, перетворюючи ОП на локальний повторювач із високим запасом фази.

### Вплив шумового підсилення на придушення пульсацій живлення (PSRR)

Пульсації напруги шин живлення `+Vcc` та `−Vee` (наприклад, залишковий високочастотний шум імпульсного перетворювача) проникають усередину операційного підсилювача. Коефіцієнт придушення пульсацій живлення `PSRR` (англ. *Power Supply Rejection Ratio*) визначає еквівалентну напругу помилки, приведеної до входу:

```
V_err,psrr = V_ripple / PSRR
```

Оскільки ця напруга діє як внутрішнє вхідне джерело помилки, на вихід каскаду вона передається не з сигнальним підсиленням, а **помноженою на шумове підсилення `NG`**:

```
V_out,ripple = V_err,psrr · NG = ( V_ripple / PSRR ) · ( 1 + Rf / Rin )
```

У багатоканальних суматорах із високим шумовим підсиленням (наприклад, `NG = 20`) навіть мізерні високочастотні пульсації живлення амплітудою `10 мВ`, послаблені підсилювачем на 60 дБ (у 1000 разів до `10 мкВ`), підсилюються на виході у 20 разів і створюють вихідну паразитну заваду розмахом `200 мкВ`. Тому високошвидкісні суматори та каскади з маніпулюванням шумового підсилення вимагають обов'язкового блокування шин живлення керамічними конденсаторами X7R безпосередньо біля виводів живлення мікросхеми.

### Температурний дрейф та стабільність зміщення

При зміні температури навколишнього середовища вхідна напруга зміщення ОП змінюється за лінійним законом:

```
Vos(T) = Vos(25°C) + (dVos / dT) · (T − 25°C)
```

де `dVos/dT` — температурний коефіцієнт дрейфу зміщення (зазвичай `0.5–5 мкВ/°C`).

Вихідний дрейф напруги підсилювача множиться на низькочастотне шумове підсилення:

```
ΔV_вих(T) = ΔVos(T) · NG_dc = [ (dVos / dT) · ΔT ] · [ 1 + Rf / Rin ]
```

Оскільки наш коригувальний ланцюг `R_dummy–C_dummy` містить розділовий конденсатор `C_dummy`, на постійному струмі `NG_dc` залишається низьким (`1 + Rf/Rin`). Завдяки цьому температурний дрейф вихідної напруги залишається мінімальним і не роздувається високим високочастотним підсиленням `NG_min`.

### Розрахунок паразитної ємності доріжок друкованої плати

Паразитна ємність монтажу на інвертувальному вході `C_pcb` визначається геометрією мікросмужкової лінії над земляним полігоном. Для стандартного склотекстоліту FR-4 (діелектрична проникність `εr = 4.3`, товщина діелектрика `h = 1.6 мм`, ширина доріжки `w = 0.3 мм`, товщина міді `t = 35 мкм`) погонна ємність розраховується за формулою:

```
C_per_cm = [ 0.264 · (εr + 1.41) ] / ln( (5.98 · h) / (0.8 · w + t) )  [пФ/см]
```

Підставивши типові значення геометрії плати:

```
C_per_cm
= [ 0.264 · (4.3 + 1.41) ] / ln( (5.98 · 1.6) / (0.8 · 0.3 + 0.035) )
= [ 0.264 · 5.71 ] / ln( 9.568 / 0.275 )
= 1.507 / ln( 34.79 )
= 1.507 / 3.55
≈ 0.42 пФ/см
```

Доріжка завдовжки лише 3 см плюс контактні площадки резисторів додають до інвертувального входу близько `2.0 пФ` паразитної ємності. Для високоомного резистора `Rf = 100 кОм` це створює паразитний нуль на частоті `fz = 1 / (2·π·100к·2пФ) ≈ 795 кГц`, що викликає відчутний підйом шумового підсилення та втрату запасу фази. Повне видалення шарів землі під інвертувальним вузлом знижує цю ємність до `< 0.2 пФ`.

### Покроковий алгоритм інженерного розрахунку

1. **Визначення сигнального та статичного шумового підсилення**:
   - Інвертувальна схема: `G_сигн = −Rf / Rin`, `NG_dc = 1 + Rf / Rin`.
   - Неінвертувальна схема: `G_сигн = 1 + Rf / Rin`, `NG_dc = 1 + Rf / Rin`.
2. **Перевірка критерію стійкості**:
   - Порівнюємо `NG_dc` із даташитним параметром `NG_min`.
   - Якщо `NG_dc ≥ NG_min` — схема стійка природним шляхом, додаткова корекція не потрібна (`R_dummy = ∞`).
   - Якщо `NG_dc < NG_min` — потрібен коригувальний ланцюг штучного завищення.
3. **Синтез шунтувального резистора `R_dummy`**:
   - Необхідний еквівалентний опір: `Req_target = Rf / (NG_min − 1)`.
   - Провідність шунта: `G_dummy = (1 / Req_target) − (1 / Rin)`.
   - Опір шунта: `R_dummy = 1 / G_dummy`.
4. **Синтез розділового конденсатора `C_dummy`**:
   - Розрахункова частота перетину: `f_cross = GBP / NG_min`.
   - Частота нуля випередження: `f_zero = f_cross / 10`.
   - Ємність конденсатора: `C_dummy = 1 / (2 · π · R_dummy · f_zero)`.
5. **Складання повного 5-компонентного шумового бюджету**:
   - Внесок напруги ОП: `e_out,en = en · NG_dc` (нВ/√Гц);
   - Внесок струму мінус-входу: `e_out,in− = in− · Rf` (нВ/√Гц);
   - Внесок струму плюс-входу: `e_out,in+ = in+ · R+ · NG_dc` (нВ/√Гц);
   - Тепловий шум резистора зворотного зв'язку: `e_out,Rf = √(4 · k · T · Rf)` (нВ/√Гц);
   - Тепловий шум вхідного резистора: `e_out,Rin = √(4 · k · T · Rin) · |G_сигн|` (нВ/√Гц);
   - Сумарна вихідна густина шуму: `e_out,total = √( ∑ e_out,i² )`.
6. **Інтегральний розрахунок середньоквадратичного шуму (RMS)**:
   - Еквівалентна шумова смуга: `ENBW = (π / 2) · (GBP / NG_dc)`.
   - Загальний шум виходу: `V_rms = e_out,total · √( ENBW )`.

### Практикум моделювання у SPICE: розрив петлі за методом Міддлбрука

Для точного підтвердження стійкості скоригованого каскаду в симуляторі (LTspice, ngspice або PSpice) петлю зворотного зв'язку розривають за допомогою віртуального LC-фільтра:
- Між виходом ОП та ланкою зворотного зв'язку встановлюють індуктивність `L_break = 1 ГГн` (на постійному струмі — нульовий опір для розрахунку робочої точки DC, на AC — повний розрив петлі).
- Послідовно зі зворотним зв'язком подають змінну напругу з джерела `Vac = 1 В` через конденсатор `C_break = 1 ГФ`.

Директива моделювання частотної характеристики:
```text
.ac dec 100 1k 10G
.meas AC PM_deg FIND 180+ph(V(loop_out)/V(loop_in)) WHEN mag(V(loop_out)/V(loop_in))=1
```
Симулятор автоматично знаходить частоту одиничного петльового підсилення та фіксує точний запас фази `PM_deg`. Для запропонованої схеми на базі OPA847 із ланцюгом корекції розрахунковий запас фази становить `62.4°`, що гарантує чистий перехідний процес без дзвону.

### Розбір інженерних підводних каменів

#### 1. Власний тепловий шум шунтувального резистора R_dummy
Резистор `R_dummy` під'єднано між інвертувальним і неінвертувальним входами ОП. На високих частотах, де конденсатор `C_dummy` має малий опір, тепловий шум Джонсона цього резистора `e_th = √(4·k·T·R_dummy)` діє безпосередньо як додаткове вхідне джерело шуму і множиться на повне шумове підсилення `NG_min`.

Якщо розрахунок дав `R_dummy = 47.6 Ом`, його власний шум становить `0.89 нВ/√Гц`. Доданий до власного шуму підсилювача `en = 0.85 нВ/√Гц`, він збільшує загальний шум каскаду на високих частотах у `√(0.85² + 0.89²) / 0.85 ≈ 1.45` раза. Це неминуча плата за стабілізацію декомпенсованого каскаду.

#### 2. Паразитна індуктивність доріжок друкованої плати
На частотах понад `500 МГц` навіть доріжка плати завдовжки `5 мм` має паразитну індуктивність близько `4–5 нГн`. На частоті 1 ГГц її реактивний опір становить `X_L = 2·π·f·L ≈ 30 Ом`.
Якщо ланцюг `R_dummy–C_dummy` розведено з довгими доріжками, паразитна індуктивність розриває коло шунта на надвисоких частотах, і підсилювач все одно самозбудиться на частоті вище 800 МГц. Резистор і конденсатор корекції обов'язково розміщують у корпусах SMD 0402 безпосередньо між виводами 2 і 3 мікросхеми.

#### 3. Верифікація за допомогою моделювання у SPICE
Перед виготовленням плати розраховану схему перевіряють двома типами аналізу в симуляторі:
1. **Аналіз петльового підсилення за методом Тіана або Міддлбрука (`.ac dec 100 1k 10G`)**: розривають петлю в точці виходу ОП і вимірюють точний запас фази `Phase Margin` у точці, де петльове підсилення `T(f) = 0 дБ`. Для стабільної роботи без дзвону запас фази має бути не менше `55°–60°`.
2. **Аналіз перехідного процесу (`.tran 0.05n 50n`)**: подають на вхід імпульс із фронтом `0.5 нс` і контролюють викид (англ. *overshoot*) на виході. Перевищення амплітуди не повинно бути більше `5–10%`.

#### 4. Монтажний аналіз Монте-Карло та допуски компонентів
У масовому виробництві номінали резисторів `Rin`, `Rf`, `R_dummy` мають технологічний розкид (зазвичай `±1%`), а паразитна вхідна ємність монтажу коливається в межах `±20%`. Крім того, діелектрична проникність матеріалу FR-4 має технологічний допуск `εr = 4.3 ± 0.3`, що змінює розподілену ємність доріжок на ±10% від партії до партії.
При найгіршому збігу допусків (значення `Rf` відхилилося вгору на +1%, а `R_dummy` — вгору на +1%) високочастотне шумове підсилення може опуститися нижче порогу `NG_min`. Тому при інженерному проектуванні цільове значення шумового підсилення для розрахунку `R_dummy` обирають із 15–20% запасом відносно даташитного мінімуму: `NG_target = 1.2 · NG_min`. У серійних виробах рекомендується використовувати тонкоплівкові резистори SMD 0402 з допуском 0.1% і ТКС ±10 ppm/°C та керамічні діелектрики NP0/C0G із низькою діелектричною абсорбцією для компенсаційних конденсаторів, уникаючи сегнетоелектричної кераміки X7R/Y5V у колах зворотного зв'язку.
