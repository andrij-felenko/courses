# 🧮 Аналітичний розрахунок динамічного опору Ron та інжекції заряду передавального вентиля

Щоб розрахувати точний час перемикання цифрових комірок або амплітудну похибку схем вибірки-зберігання (Sample-and-Hold), інженеру недостатньо якісного розуміння, що передавальний вентиль «проводить у всьому діапазоні». Потрібна точна математична модель його еквівалентної провідності `G_on(V_in)` та динамічного опору `R_on(V_in) = 1 / G_on(V_in)` як неперервної функції вхідної напруги `V_in ∈ [0, V_DD]`, з урахуванням зміни режимів роботи польових транзисторів (лінійний режим і насичення) та нелінійного зсуву порогових напруг через ефект підкладки (body effect).

Цей математичний апарат дає точні аналітичні вирази для опору кожного плеча, умови оптимального геометричного співвідношення ширин каналів `(W/L)_p / (W/L)_n` для вирівнювання провідності, розрахунок перехідного процесу заряду вихідної ємності, затримки Елмора для послідовних каскадів, інтегрального теплового шуму вибірки kT/C, частотної смуги пропускання та високочастотної ізоляції закритого ключа, придушення нелінійних гармонік у комутованому сигналі, диференціального коефіцієнта придушення синфазної завади (CMRR) та кількісну оцінку залишкового п'єдесталу напруги при інжекції заряду в момент розмикання ключа.

### Малосигнальна провідність каналів MOSFET при нульовому спаді напруги

Розглянемо передавальний вентиль, увімкнений між клемами `A` та `B`. Сигнал керування `EN = V_DD`, `EN̄ = 0`. На клему `A` подано потенціал `V_in`, а через ключ протікає нескінченно малий струм `I_DS → 0`, що створює між виводами спад `V_DS = V_B − V_A → 0`.

У цьому квазістатичному режимі обидва транзистори працюють на початку вихідної вольт-амперної характеристики (крута лінійна ділянка, де `V_DS ≪ 2·(V_GS − V_th)`).

Струм стоку NMOS-транзистора описується класичним рівнянням квадратичної моделі для лінійної області:

```
I_D,n(V_in)
= μ_n · C_ox · (W/L)_n · [ (V_GS,n − V_thn)·V_DS − ½·V_DS² ]   [квадратична модель у тріодній області]
≈ μ_n · C_ox · (W/L)_n · (V_GS,n − V_thn)·V_DS                 [нехтування малим доданком ½·V_DS² при V_DS → 0]
```

Для NMOS-транзистора затвор під'єднано до `V_DD`, а витік сидить на потенціалі сигналу `V_in` (при заряді виходу) або навпаки. Отже, напруга затвор–витік дорівнює `V_GS,n = V_DD − V_in`.

Диференціальна провідність відкритого каналу NMOS `G_n(V_in) = ∂I_D,n / ∂V_DS` набуває вигляду:

```
G_n(V_in)
= ∂/∂V_DS [ μ_n · C_ox · (W/L)_n · (V_DD − V_in − V_thn)·V_DS ] [диференціювання струму стоку за спадом напруги]
= μ_n · C_ox · (W/L)_n · (V_DD − V_in − V_thn)                  [лінійна питома провідність каналу]
= k_n · (V_DD − V_in − V_thn)                                   [де параметр крутизни k_n = μ_n·C_ox·(W/L)_n]
```

Цей вираз дійсний лише за умови, що затворний перехід інвертований, тобто `V_GS,n > V_thn`, звідки `V_in < V_DD − V_thn`. Коли `V_in ≥ V_DD − V_thn`, канал NMOS вироджується (транзистор закривається, струм переходить у мізерний підпороговий витік), тому:

```
G_n(V_in) = 0   [при V_in ≥ V_DD − V_thn]
```

Дзеркально розрахуємо провідність PMOS-транзистора. Його затвор під'єднано до `EN̄ = 0` (земля), а витік перебуває під потенціалом `V_in` (при `V_in > V_out`) або підтягнутий до `V_DD`. Напруга витік–затвор становить `V_SG,p = V_in − 0 = V_in`.

Струм стоку відкритого PMOS у лінійному режимі:

```
I_D,p(V_in)
= μ_p · C_ox · (W/L)_p · [ (V_SG,p − |V_thp|)·V_SD − ½·V_SD² ]   [рівняння PMOS у тріодній області]
≈ μ_p · C_ox · (W/L)_p · (V_in − |V_thp|)·V_SD                   [лінеаризація при малому спаді V_SD → 0]
```

Диференціальна провідність каналу PMOS:

```
G_p(V_in)
= ∂/∂V_SD [ μ_p · C_ox · (W/L)_p · (V_in − |V_thp|)·V_SD ] [диференціювання за спадом напруги на PMOS]
= μ_p · C_ox · (W/L)_p · (V_in − |V_thp|)                  [провідність каналу PMOS]
= k_p · (V_in − |V_thp|)                                   [де k_p = μ_p·C_ox·(W/L)_p]
```

PMOS залишається відкритим, поки `V_SG,p > |V_thp|`, тобто `V_in > |V_thp|`. При `V_in ≤ |V_thp|` канал PMOS повністю перекривається:

```
G_p(V_in) = 0   [при V_in ≤ |V_thp|]
```

### Сумарна паралельна провідність та еквівалентний опір ключа

Оскільки NMOS і PMOS увімкнені паралельно між спільними вузлами, їхні малосигнальні провідності безпосередньо сумуються:

```
G_TG(V_in) = G_n(V_in) + G_p(V_in)
```

Діапазон вхідних напруг `V_in ∈ [0, V_DD]` розпадається на три характерні інтервали провідності:

#### 1. Область низької напруги: `0 ≤ V_in < |V_thp|`
У цьому діапазоні PMOS закритий (`G_p = 0`), а NMOS сильно відкритий.

```
G_TG(V_in)
= G_n(V_in)                     [PMOS закритий]
= k_n · (V_DD − V_in − V_thn)   [провідність забезпечується виключно каналом NMOS]
```

Опір передавального вентиля:

```
R_on(V_in)
= 1 / G_TG(V_in)                        [обернена величина до провідності]
= 1 / [ k_n · (V_DD − V_in − V_thn) ]   [опір одиночного NMOS]
```

При `V_in = 0`:

```
R_on(0) = 1 / [ k_n · (V_DD − V_thn) ]   [мінімальний опір NMOS біля нульової шини]
```

#### 2. Проміжна область сумісної провідності: `|V_thp| ≤ V_in ≤ V_DD − V_thn`
У цьому діапазоні обидва транзистори одночасно перебувають у лінійному режимі, шунтуючи один одного.

```
G_TG(V_in)
= G_n(V_in) + G_p(V_in)                                                [сума провідностей обох відкритих каналів]
= k_n·(V_DD − V_in − V_thn) + k_p·(V_in − |V_thp|)                     [підстановка виразів для k_n та k_p]
= [ k_n·(V_DD − V_thn) − k_p·|V_thp| ] + (k_p − k_n)·V_in             [групування сталих та змінних членів від V_in]
```

Якщо параметри крутизни транзисторів підібрані ідеально симетричними, тобто `k_n = k_p = k`, змінний член `(k_p − k_n)·V_in` тотожно перетворюється на нуль:

```
G_TG(V_in)
= k·(V_DD − V_thn) − k·|V_thp| + 0·V_in   [при k_n = k_p = k]
= k · (V_DD − V_thn − |V_thp|)            [повна незалежність сумарної провідності від рівня сигналу Vin]
```

За цієї умови еквівалентний динамічний опір у середній зоні стає строго інваріантним до амплітуди напруги:

```
R_on(V_in) = 1 / [ k · (V_DD − V_thn − |V_thp|) ] = const
```

#### 3. Область високої напруги: `V_DD − V_thn < V_in ≤ V_DD`
У цій зоні закривається NMOS (`G_n = 0`), а всю провідність бере на себе повністю відкритий PMOS.

```
G_TG(V_in)
= G_p(V_in)                [NMOS закритий]
= k_p · (V_in − |V_thp|)   [провідність забезпечується виключно каналом PMOS]
```

Опір передавального вентиля:

```
R_on(V_in)
= 1 / G_TG(V_in)                   [обернена величина до провідності]
= 1 / [ k_p · (V_in − |V_thp|) ]   [опір одиночного PMOS]
```

При `V_in = V_DD`:

```
R_on(V_DD) = 1 / [ k_p · (V_DD − |V_thp|) ]   [мінімальний опір PMOS біля шини живлення]
```

### Умова балансування геометрії каналів (W/L)

Оскільки рухливість дірок у кремнії `μ_p` у 2–3 рази нижча за рухливість електронів `μ_n` через вищу ефективну масу дірок у валентній зоні, умова рівності крутизни `k_n = k_p` вимагає компенсаційного збільшення ширини каналу PMOS-транзистора:

```
k_n = k_p
⇒ μ_n · C_ox · (W/L)_n = μ_p · C_ox · (W/L)_p   [рівність параметрів провідності]
⇒ (W/L)_p / (W/L)_n = μ_n / μ_p                 [оптимальне відношення геометрій]
```

Для типового кремнієвого CMOS-процесу `μ_n ≈ 450 см²/(В·с)`, `μ_p ≈ 160 см²/(В·с)`:

```
(W/L)_p / (W/L)_n = 450 / 160 ≈ 2.81
```

Обрання `W_p ≈ 2.5–3.0 · W_n` гарантує, що крайові опори `R_on(0)` та `R_on(V_DD)` будуть практично однаковими, усуваючи асиметрію фронтів наростання та спаду імпульсів.

### Врахування ефекту підкладки: зсув порогів Vth(Vin)

У реальній інтегральній схемі підкладка NMOS (P-substrate) приєднана до найнижчого потенціалу `V_SS = 0 В`, а ізольований карман PMOS (N-well) — до найвищого потенціалу `V_DD`.

Коли сигнал `V_in` зростає від нуля до `V_DD`, виникає позитивна різниця потенціалів витік–підкладка NMOS `V_SB,n = V_in > 0`. Ця напруга розширює збіднений шар під інверсійним каналом, збільшуючи нескомпенсований просторовий заряд іонізованих акцепторів, що призводить до нелінійного зростання порогової напруги:

```
V_thn(V_in)
= V_thn0 + γ_n · [ √(2·|ϕ_F,n| + V_in) − √(2·|ϕ_F,n|) ]   [модель ефекту підкладки для NMOS]
```

де `V_thn0` — поріг при нульовому зсуві підкладки, `γ_n = √(2·q·ε_si·N_A) / C_ox` — коефіцієнт впливу підкладки (типово `0.3–0.6 В^(1/2)`), `2·|ϕ_F,n| ≈ 0.6–0.7 В` — поверхневий потенціал подвійної фермієвої інверсії.

Для PMOS-транзистора різниця потенціалів між підкладкою (N-well при `V_DD`) і витоком (при потенціалі `V_in`) становить `V_BS,p = V_DD − V_in > 0`. Це призводить до дзеркального зростання абсолютного значення порогу PMOS при зниженні вхідної напруги:

```
|V_thp(V_in)|
= |V_thp0| + γ_p · [ √(2·|ϕ_F,p| + (V_DD − V_in)) − √(2·|ϕ_F,p|) ]   [модель ефекту підкладки для PMOS]
```

#### Вплив на піковий опір у центрі діапазону
Підставимо залежні від напруги пороги у вираз для сумарної провідності при `V_in = V_DD / 2`:

```
V_thn(V_DD/2) = V_thn0 + γ_n · [ √(2·|ϕ_F| + V_DD/2) − √(2·|ϕ_F|) ]
|V_thp(V_DD/2)| = |V_thp0| + γ_p · [ √(2·|ϕ_F| + V_DD/2) − √(2·|ϕ_F|) ]
```

Обидва пороги суттєво зростають (наприклад, з 0.45 В до 0.72 В при `V_DD = 3.3 В`). Внаслідок цього ефективна надпорогова напруга керування `(V_GS − V_th)` у центрі шкали зменшується, формуючи локальний мінімум сумарної провідності `G_TG,min` та відповідний максимум динамічного опору:

```
R_on,max
= 1 / G_TG(V_DD / 2)
= 1 / [ k_n·(V_DD/2 − V_thn(V_DD/2)) + k_p·(V_DD/2 − |V_thp(V_DD/2)|) ]   [піковий опір ключа]
```

Якщо напруга живлення знижується до критичної межі:

```
V_DD ≤ V_thn(V_in) + |V_thp(V_in)|
```

виникає зона мертвої провідності, в якій обидва транзистори вимикаються в середині діапазону `V_in`, а опір передавального вентиля `R_on → ∞`. Це фундаментальне фізичне обмеження вимагає застосування схем генерації підвищеної напруги затвора (bootstrapping / charge pump) у низьковольтних вузлах (нижче 1.2 В).

### Динамічний перехідний процес заряду навантажувальної ємності

Розглянемо часову динаміку встановлення напруги на конденсаторі навантаження `C_L`, коли передавальний вентиль вмикається в момент часу `t = 0`, передаючи стрибок напруги від `0 В` до `V_DD`.

Диференціальне рівняння балансу струмів на вихідному вузлі:

```
C_L · (dV_out / dt) = I_D,n(V_out) + I_D,p(V_out)
```

Перехідний процес поділяється на два часові інтервали відповідно до режимів роботи польових приладів:

#### Інтервал 1: Початковий швидкий розгін (`0 ≤ V_out < V_DD − V_thn`)
У цьому інтервалі NMOS перебуває в насиченні (оскільки `V_DS,n = V_DD − V_out > V_GS,n − V_thn = V_DD − V_out − V_thn`), формуючи постійний струм насичення:

```
I_D,n,sat
= ½ · k_n · (V_DD − V_out − V_thn)²   [струм насичення NMOS]
```

Одночасно PMOS перебуває в лінійному режимі (`V_SD,p = V_DD − V_out ≪ 2·(V_SG,p − |V_thp|)`), забезпечуючи струм:

```
I_D,p,lin
= k_p · [ (V_DD − |V_thp|)·(V_DD − V_out) − ½·(V_DD − V_out)² ]   [струм тріодної області PMOS]
```

Сумарний струм заряду великий, завдяки чому крутизна наростання `dV_out / dt` максимальна на перших пікосекундах перехідного процесу.

#### Інтервал 2: Завершальне дотягування (`V_DD − V_thn ≤ V_out ≤ V_DD`)
Коли напруга `V_out` перетинає поріг `V_DD − V_thn`, транзистор NMOS повністю закривається (`I_D,n = 0`). Весь залишковий заряд вихідної ємності бере на себе PMOS-транзистор, який працює у глибокому лінійному режимі:

```
C_L · (dV_out / dt)
= k_p · (V_DD − |V_thp|) · (V_DD − V_out)   [експоненційне наближення до V_DD через опір PMOS]
```

Інтегруючи це диференціальне рівняння від `V_out(t_1) = V_DD − V_thn` до `V_out(t) = V_DD · (1 − ε)`:

```
∫ [ dV_out / (V_DD − V_out) ]
= (k_p / C_L) · (V_DD − |V_thp|) · ∫ dt   [розділення змінних для часу релаксації]
⇒ ln[ V_thn / (ε · V_DD) ]
= (t − t_1) / τ_p                        [де постійна часу τ_p = C_L / (k_p · (V_DD − |V_thp|))]
```

Звідси повний час встановлення вихідної напруги до рівня 90% (`V_out = 0.9·V_DD`):

```
t_rise,90% ≈ t_sat,n + 2.3 · τ_p
```

Завдяки PMOS-плечу вихід досягає повного розмаху живлення `V_DD` без застрягання на пороговому плато.

### Затримка Елмора для послідовного ланцюга передавальних вентилів

Коли `N` передавальних вентилів з'єднані послідовно (наприклад, у мультиплексорному дереві або матричному комутаторі), кожен вузол між ключами має власну паразитну ємність дифузії та розводки `C_node`, а кожен ключ має опір `R_on`.

За моделлю затримок Елмора (Elmore Delay) сумарний час розповсюдження фронту імпульсу від першого входу до кінцевого навантаження `C_L` обчислюється як сума добутків опорів на накопичену за ними ємність:

```
t_pd,Elmore
= R_on·(C_node + C_node + ... + C_L) + R_on·(C_node + ... + C_L) + ... + R_on·C_L   [сума за всіма RC-ланками]
= R_on · C_node · [ N·(N + 1) / 2 ] + N · R_on · C_L                               [аналітичне згортання суми]
≈ ½ · R_on · C_node · N² + N · R_on · C_L                                          [квадратична залежність при N >> 1]
```

Цей квадратичний ріст затримки `O(N²)` виникає через те, що перший ключ повинен заряджати ємності всіх наступних `N` вузлів через власний скінченний опір `R_on`. Щоб розірвати квадратичну залежність і звести її до лінійної `O(N)`, кожні 3–4 передавальні вентилі розділяють активним CMOS-інвертором, який відновлює крутизну фронту та забезпечує низький вихідний опір драйвера.

### Частотна характеристика та високочастотна ізоляція закритого ключа

У відкритому стані передавальний вентиль разом із паразитними ємностями дифузійних областей стоку `C_drain` та вхідною ємністю навантаження `C_L` утворює фільтр низьких частот із передатною функцією:

```
H_on(s)
= 1 / [ 1 + s · R_on · (C_drain + C_L) ]   [малосигнальна передатна функція відкритого ключа]
```

Гранична частота смуги пропускання за рівнем −3 дБ:

```
f_-3dB = 1 / [ 2 · π · R_on · (C_drain + C_L) ]
```

У вимкненому стані (`EN = 0`) між входом і виходом залишається паразитна прохідна ємність закритого ключа `C_off = ½ · (C_ov,n + C_ov,p)`. Якщо вихід навантажений на активний опір приймача `R_L` та ємність `C_L`, передатна функція проникнення паразитного сигналу (Feedthrough Transfer Function) становить:

```
H_off(s)
= (s · C_off · R_L) / [ 1 + s · (C_off + C_L) · R_L ]   [передатна функція диференціюючого RC-кола]
```

Модуль коефіцієнта передачі закритого ключа на високих частотах (де `ω · (C_off + C_L) · R_L ≪ 1`):

```
|H_off(jω)|
= (ω · C_off · R_L) / √[ 1 + (ω · (C_off + C_L) · R_L)² ]   [амплітудно-частотна характеристика]
≈ 2 · π · f · C_off · R_L                                  [лінійне зростання протікання сигналу з частотою]
```

Звідси величина високочастотного послаблення (Off-Isolation, дБ):

```
Isolation(f) = −20 · lg[ 2 · π · f · C_off · R_L ]
```

Для досягнення високої ізоляції на гігагерцових частотах (понад 60 дБ) застосовують Т-подібні комутаційні структури (T-switch), де два послідовні передавальні вентилі розділені третім шунтуючим ключем, що замикає середню точку на землю під час вимкнення тракту.

### Тепловий шум вибірки kT/C у схемах Sample-and-Hold

Опір відкритого каналу передавального вентиля `R_on` є джерелом теплового шуму Джонсона–Найквіста зі спектральною густиною потужності:

```
S_v(f) = 4 · k_B · T · R_on   [В²/Гц, де k_B — стала Больцмана, T — абсолютна температура]
```

Разом із конденсатором вибірки `C_H` ключ утворює фільтр низьких частот першого порядку з частотою зрізу:

```
f_c = 1 / (2 · π · R_on · C_H)
```

Інтегруючи шумовий спектр по всій смузі частот від 0 до нескінченності:

```
v_noise,rms²
= ∫ [ 4 · k_B · T · R_on / (1 + (2·π·f·R_on·C_H)²) ] df   [інтегрування шуму по нескінченній смузі]
= 4 · k_B · T · R_on · [ 1 / (4 · R_on · C_H) ]           [обчислення інтеграла арктангенса]
= (k_B · T) / C_H                                         [повне скорочення опору Ron]
```

Цей висновок є фундаментальним для мікроелектроніки: **величина інтегрального теплового шуму вибірки не залежить від величини опору ключа R_on, а визначається виключно ємністю конденсатора зберігання C_H**. Зменшення `R_on` розширює смугу пропускання фільтра рівно настільки, наскільки зменшується спектральна густина шуму, залишаючи сумарну енергію шумової напруги `k_B·T / C_H` незмінною.

### Придушення нелінійних спотворень (THD) та синфазних завад (CMRR)

При комутації гармонійних аналогових сигналів `V_in(t) = V_0 + V_m · sin(ω·t)` нелінійна залежність провідності каналу від миттєвої напруги спотворює форму хвилі, генеруючи вищі гармоніки.

Розкладемо малосигнальну провідність кожного транзистора в ряд Тейлора навколо середньої робочої точки `V_0 = V_DD / 2`:

```
G_n(V_in)
= G_n0 + g_1,n · (V_in − V_0) + g_2,n · (V_in − V_0)²   [розклад провідності NMOS у ряд Тейлора]

G_p(V_in)
= G_p0 + g_1,p · (V_in − V_0) + g_2,p · (V_in − V_0)²   [розклад провідності PMOS у ряд Тейлора]
```

Оскільки похідна провідності NMOS за напругою `∂G_n / ∂V_in = −k_n < 0`, а для PMOS `∂G_p / ∂V_in = +k_p > 0`, лінійні коефіцієнти розкладу мають строго протилежні знаки:

```
g_1,n = −k_n
g_1,p = +k_p
```

Сумарна динамічна провідність пари:

```
G_TG(V_in)
= (G_n0 + G_p0) + (k_p − k_n) · (V_in − V_0) + (g_2,n + g_2,p) · (V_in − V_0)²
```

При симетричному виборі геометрій `k_n = k_p`:
1. Перша похідна сумарної провідності обнуляється: `(k_p − k_n) = 0`.
2. Це призводить до повного придушення **другої гармоніки (HD2)** струму спотворення.
3. Коефіцієнт сумарних гармонійних спотворень (Total Harmonic Distortion, THD) зменшується на 25–35 дБ порівняно з комутатором на одиночному транзисторі, роблячи передавальний вентиль придатним для високоякісних аудіотрактів та прецизійних вимірювальних кіл.

У повністю диференціальних аналогових трактах два ідентичні передавальні вентилі комутують комплементарну пару сигналів `V_in+` та `V_in-`. Синфазні імпульсні завади від шин живлення та тактового сигналу потрапляють на обидва канали з однаковою амплітудою і синфазно віднімаються на диференціальному підсилювачі, підвищуючи коефіцієнт придушення синфазного сигналу (CMRR) схеми вибірки до понад 80–90 дБ.

### Кількісний приклад числового розрахунку

Нехай маємо передавальний вентиль із такими технологічними параметрами:
- Напруга живлення: `V_DD = 3.3 В`
- Параметри оксиду: `t_ox = 7 нм` ⇒ `C_ox = ε_ox / t_ox ≈ 4.93 фФ/мкм²`
- Рухливості: `μ_n = 400 см²/(В·с)`, `μ_p = 150 см²/(В·с)`
- Геометрія: `(W/L)_n = 10 мкм / 0.35 мкм ≈ 28.57`, `(W/L)_p = 27 мкм / 0.35 мкм ≈ 77.14`
- Параметри порогів: `V_thn0 = 0.55 В`, `|V_thp0| = 0.60 В`
- Коефіцієнти підкладки: `γ_n = γ_p = 0.4 В^(1/2)`, `2·ϕ_F = 0.65 В`

#### Крок 1. Розрахунок питомої крутизни k_n та k_p:
```
k_n
= μ_n · C_ox · (W/L)_n                                   [формула питомої крутизни NMOS]
= (400 · 10⁻⁴ м²/В·с) · (4.93 · 10⁻³ Ф/м²) · 28.57       [підстановка числових параметрів]
≈ 5.63 · 10⁻³ А/В² = 5.63 мА/В²                          [обчислення крутизни NMOS]

k_p
= μ_p · C_ox · (W/L)_p                                   [формула питомої крутизни PMOS]
= (150 · 10⁻⁴ м²/В·с) · (4.93 · 10⁻³ Ф/м²) · 77.14       [підстановка числових параметрів]
≈ 5.70 · 10⁻³ А/В² = 5.70 мА/В²                          [обчислення крутизни PMOS]
```
Параметри крутизни `k_n ≈ k_p` збалансовані з точністю до 1.2%.

#### Крок 2. Опір при нульовій напрузі (Vin = 0 В):
При `V_in = 0 В`: `V_SB,n = 0 ⇒ V_thn = 0.55 В`. PMOS закритий.
```
R_on(0)
= 1 / [ k_n · (V_DD − 0 − V_thn0) ]   [формула опору NMOS при Vin = 0]
= 1 / [ 5.63 · 10⁻³ · (3.3 − 0.55) ]  [підстановка напруги живлення та порогу]
= 1 / [ 5.63 · 10⁻³ · 2.75 ]          [обчислення знаменника]
= 1 / 0.01548 См                      [сумарна провідність]
≈ 64.6 Ом                             [підсумковий опір]
```

#### Крок 3. Опір при максимальній напрузі (Vin = 3.3 В):
При `V_in = 3.3 В`: `V_BS,p = 0 ⇒ |V_thp| = 0.60 В`. NMOS закритий.
```
R_on(3.3 В)
= 1 / [ k_p · (V_DD − |V_thp0|) ]    [формула опору PMOS при Vin = V_DD]
= 1 / [ 5.70 · 10⁻³ · (3.3 − 0.60) ] [підстановка напруги живлення та порогу]
= 1 / [ 5.70 · 10⁻³ · 2.70 ]         [обчислення знаменника]
= 1 / 0.01539 См                     [сумарна провідність]
≈ 65.0 Ом                            [підсумковий опір]
```

#### Крок 4. Опір у середині діапазону (Vin = 1.65 В) з урахуванням ефекту підкладки:
Розрахуємо зсув порогів:
```
ΔV_thn
= 0.4 · [ √(0.65 + 1.65) − √(0.65) ]   [формула зсуву порогу NMOS]
= 0.4 · [ √2.30 − √0.65 ]              [обчислення підкореневих виразів]
= 0.4 · [ 1.5166 − 0.8062 ]            [обчислення коренів]
= 0.4 · 0.7104                         [різниця коренів]
≈ 0.284 В                              [зсув порогу через ефект підкладки]
⇒ V_thn(1.65 В) = 0.55 + 0.284 = 0.834 В

Δ|V_thp|
= 0.4 · [ √(0.65 + (3.3 − 1.65)) − √(0.65) ]   [формула зсуву порогу PMOS]
= 0.284 В                                      [симетричний зсув при V_in = V_DD / 2]
⇒ |V_thp(1.65 В)| = 0.60 + 0.284 = 0.884 В
```

Розрахуємо провідності обох транзисторів:
```
G_n(1.65 В)
= 5.63 · 10⁻³ · (3.3 − 1.65 − 0.834)   [провідність NMOS при V_in = 1.65 В]
= 5.63 · 10⁻³ · 0.816                  [ефективна надпорогова напруга]
≈ 4.594 · 10⁻³ См                      [обчислення провідності NMOS]

G_p(1.65 В)
= 5.70 · 10⁻³ · (1.65 − 0.884)         [провідність PMOS при V_in = 1.65 В]
= 5.70 · 10⁻³ · 0.766                  [ефективна надпорогова напруга]
≈ 4.366 · 10⁻³ См                      [обчислення провідності PMOS]
```

Сумарна провідність та піковий динамічний опір:
```
G_TG(1.65 В)
= 4.594 · 10⁻³ + 4.366 · 10⁻³   [сума провідностей обох відкритих каналів]
= 8.960 · 10⁻³ См               [сумарна провідність пари]

R_on(1.65 В)
= 1 / (8.960 · 10⁻³ См)         [обернена величина до сумарної провідності]
≈ 111.6 Ом                      [піковий динамічний опір вентиля]
```

**Висновки з розрахунку:**
- Завдяки паралельній парі опір ключа в усьому діапазоні `0...3.3 В` коливається лише в межах від `64.6 Ом` до `111.6 Ом`.
- Якби використовувався лише одиночний NMOS, при `V_in = 1.65 В` його опір становив би `217.7 Ом`, а при `V_in ≥ 2.466 В` опір злетів би до нескінченності.
- Ефект підкладки підняв центральний горб опору з `75.2 Ом` (ідеальний випадок без підкладки) до `111.6 Ом`, що становить збільшення на 48.4%.

### Модель динамічної похибки: інжекція заряду та clock feedthrough

При вимиканні передавального вентиля (`EN: V_DD → 0`, `EN̄: 0 → V_DD`) на вихідний конденсатор зберігання `C_H` переносяться паразитичні заряди двох природи:

#### 1. Інжекція мобільного заряду інверсійного каналу (Channel Charge Injection)
Повний заряд електронів у каналі NMOS перед вимиканням становить:

```
Q_ch,n(V_in) = − W_n · L_n · C_ox · [ V_DD − V_in − V_thn(V_in) ]
```

Повний заряд дірок у каналі PMOS:

```
Q_ch,p(V_in) = + W_p · L_p · C_ox · [ V_in − |V_thp(V_in)| ]
```

При швидкому спаді керуючих напруг рухливі носії виштовхуються через стоки та витоки. При симетричному опорі джерела та навантаження рівно половина заряду кожного каналу потрапляє на вихідний вузол `C_H`:

```
ΔV_inj(V_in)
= ½ · [ Q_ch,n(V_in) + Q_ch,p(V_in) ] / C_H                                             [розподіл заряду на ємність C_H]
= ½ · C_ox / C_H · [ W_p·L_p·(V_in − |V_thp|) − W_n·L_n·(V_DD − V_in − V_thn) ]         [підстановка зарядів каналів]
```

#### 2. Перехідна ємнісна наводка перемикання (Clock Feedthrough)
Ємнісні дільники, утворені паразитними ємностями перекриття затвор–стік `C_ov,n = W_n · C_ov0` та `C_ov,p = W_p · C_ov0` разом із навантаженням `C_H`, наводять стрибки напруги протилежного знаку:

```
ΔV_clk
= [ −C_ov,n · V_DD + C_ov,p · V_DD ] / (C_H + C_ov,n + C_ov,p)   [суперпозиція ємнісних стрибків від парафазних сигналів]
= V_DD · C_ov0 · (W_p − W_n) / (C_H + C_ov,total)               [спрощення через питому ємність перекриття C_ov0]
```

#### 3. Сумарний залишковий зсув напруги вибірки:
```
ΔV_error(V_in) = ΔV_inj(V_in) + ΔV_clk
```

Якщо підібрати геометрію та робочу точку так, що `W_p·L_p·(V_in − |V_thp|) ≈ W_n·L_n·(V_DD − V_in − V_thn)`, інжектовані заряди електронів і дірок повністю рекомбінують на вузлі `C_H`, забезпечуючи придушення похибки вибірки на 20–30 дБ порівняно з однотранзисторним ключем.
