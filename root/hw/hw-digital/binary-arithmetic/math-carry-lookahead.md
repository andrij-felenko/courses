# 🧮 Алгебра паралельного переносу: генерація, розповсюдження та префіксні оператори

Послідовний суматор із наскрізним переносом (Ripple-Carry Adder) створює критичний шлях обчислень з лінійною часовою складністю `O(N)`, де кожен наступний розряд змушений очікувати на стабілізацію сигналу переносу від попередньої ланки. У 32- або 64-розрядних трактах сучасних процесорів така затримка становить десятки вентильних тактів і робить арифметичний блок головним вузьким місцем усього конвеєра інструкцій. Математичне розв'язання цієї проблеми полягає в перетворенні рекурентної залежності переносу на систему прямих булевих рівнянь та доведенні асоціативності префіксного оператора, що дозволяє паралелізувати обчислення до логарифмічної глибини `O(log₂ N)`.

### Булеві функції генерації та розповсюдження

У класичному повному суматорі біт суми `S_i` та вихідний перенос `C_{i+1}` для розряду `i` визначаються через вхідні операнди `A_i`, `B_i` та вхідний перенос `C_i`:

```
S_i = A_i ⊕ B_i ⊕ C_i                [сума i-го розряду: потрійний XOR]
C_{i+1} = A_i·B_i + C_i·(A_i ⊕ B_i)   [вихідний перенос: комбінація AND-OR]
```

Для розділення безпосередніх операндів від транзитного ланцюжка переносів уведемо дві допоміжні булеві функції, що обчислюються повністю паралельно й незалежно для кожного розряду:

```
G_i = A_i · B_i                       [функція генерації (Generate): перенос виникає незалежно від C_i]
P_i = A_i ⊕ B_i                       [функція розповсюдження (Propagate): вхідний перенос C_i транслюється далі]
```

Функція генерації `G_i` показує, що поточний розряд гарантовано створює вихідний перенос (`C_{i+1} = 1`), якщо обидва вхідні біти `A_i` та `B_i` дорівнюють одиниці. Цей процес не залежить від того, яке значення прийде по лінії `C_i` з молодших розрядів.

Функція розповсюдження `P_i` показує, що поточний розряд пропустить вхідний сигнал переносу далі (`C_{i+1} = C_i`), якщо рівно один із вхідних бітів дорівнює одиниці.

У цифровій схемотехніці замість `P_i = A_i ⊕ B_i` інколи застосовують простішу логічну диз'юнкцію `P_i = A_i + B_i`. Доведемо еквівалентність обох виразів при формуванні вихідного переносу `C_{i+1}`:

```
C_{i+1} = A_i·B_i + (A_i + B_i)·C_i   [підстановка диз'юнктивного P_i]
        = A_i·B_i + A_i·C_i + B_i·C_i [дистрибутивність кон'юнкції над диз'юнкцією]
        = A_i·B_i + C_i·(A_i ⊕ B_i)   [поглинання: терм A_i·B_i повністю покриває випадок A_i=B_i=1]
```

Коли `A_i = B_i = 1`, значення `G_i = 1`, тому диз'юнкція гарантовано повертає одиницю незалежно від стану другого доданка. Проте застосування суворого `P_i = A_i ⊕ B_i` є значно вигіднішим на кристалі, оскільки той самий проміжний сигнал `P_i` без змін подається на фінальний елемент XOR для обчислення біта суми `S_i = P_i ⊕ C_i`, усуваючи дублювання логічних вентилів.

### Рекурентне розгортання 4-бітного блоку CLA

Завдяки введеним функціям вираз для вихідного переносу набуває канонічного рекурентного вигляду:

```
C_{i+1} = G_i + P_i · C_i             [канонічне рекурентне рівняння переносу]
```

Розкриємо цю рекурентність для 4-бітного модуля (розряди від 0 до 3) шляхом послідовної аналітичної підстановки:

```
C_1 = G_0 + P_0 · C_0                 [перенос у розряд 1: вихідний розряд 0]

C_2 = G_1 + P_1 · C_1                 [вихідне рекурентне рівняння для C_2]
    = G_1 + P_1 · (G_0 + P_0 · C_0)   [підстановка C_1 у формулу C_2]
    = G_1 + P_1 · G_0 + P_1 · P_0 · C_0 [розкриття дужок: дворівнева ДНФ-форма]

C_3 = G_2 + P_2 · C_2                 [вихідне рекурентне рівняння для C_3]
    = G_2 + P_2 · (G_1 + P_1·G_0 + P_1·P_0·C_0) [підстановка C_2 у формулу C_3]
    = G_2 + P_2·G_1 + P_2·P_1·G_0 + P_2·P_1·P_0·C_0 [дистрибутивність кон'юнкції над диз'юнкцією]

C_4 = G_3 + P_3 · C_3                 [вихідне рекурентне рівняння для C_4]
    = G_3 + P_3 · (G_2 + P_2·G_1 + P_2·P_1·G_0 + P_2·P_1·P_0·C_0) [підстановка C_3 у формулу C_4]
    = G_3 + P_3·G_2 + P_3·P_2·G_1 + P_3·P_2·P_1·G_0 + P_3·P_2·P_1·P_0·C_0 [повне розгортання переносу C_4]
```

Усі отримані вирази мають строгу дворівневу структуру суми добутків (AND-OR). Це фундаментальний результат: за наявності попередньо обчислених сигналів `G_i` та `P_i` (що займає рівно 1 вентильну затримку) усі вихідні переноси `C_1, C_2, C_3, C_4` формуються абсолютно паралельно рівно за 2 вентильні затримки (один шар багаторозрядних вентилів AND плюс один шар вентилів OR).

### Фізичні обмеження та проблема коефіцієнта об'єднання (Fan-In)

Чому не можна розгорнути ці формули відразу на 32 або 64 біти? Погляньмо на формулу для переносу `C_4`: вона вимагає вентиля AND на 5 входів (`P_3 · P_2 · P_1 · P_0 · C_0`) та вентиля OR на 5 входів. Для 32-бітного суматора останній розряд потребував би вентиля на 33 входи.

У реальних CMOS-схемах послідовне з'єднання `K` транзисторів (NMOS у вентилі NAND або PMOS у вентилі NOR) призводить до квадратичного зростання опору каналу та паразитних ємностей. Затримка розповсюдження сигналу на такому вентилі деградує пропорційно `O(K²)`. Практичний ліміт завантаження по входу (Fan-In) у сучасних кремнієвих бібліотеках стандартних комірок становить не більше 4–5 входів на вентиль.

### Ієрархічні групові функції для багаторозрядних модулів

Для побудови широких трактів без перевантаження вентилів 4-бітні блоки об'єднують в ієрархічні структури. Для кожного 4-бітного блоку визначають групову генерацію `G_{group}` та групове розповсюдження `P_{group}`:

```
P_{0..3} = P_3 · P_2 · P_1 · P_0      [групове розповсюдження: блок пропускає C_0 лише тоді, коли всі 4 розряди транслюють перенос]
G_{0..3} = G_3 + P_3·G_2 + P_3·P_2·G_1 + P_3·P_2·P_1·G_0 [групова генерація: перенос народжується всередині 4-бітного блоку]
```

Тоді вихідний перенос із будь-якого 4-бітного блоку виражається компактно:

```
C_4 = G_{0..3} + P_{0..3} · C_0       [макрорівняння міжблочного переносу]
```

Блок другого рівня (Lookahead Carry Unit, LCU) приймає групові сигнали `(G_{0..3}, P_{0..3})`, `(G_{4..7}, P_{4..7})`, `(G_{8..11}, P_{8..11})`, `(G_{12..15}, P_{12..15})` і паралельно генерує міжблочні переноси `C_4, C_8, C_12, C_16` за ті самі 2 рівні логіки. Це забезпечує логарифмічне масштабування затримки.

### Асоціативний префіксний оператор

Розглянемо пару `(G, P)` як узагальнений алгебраїчний стан інтервалу і визначимо бінарний префіксний оператор `•` (оператор Ладнера–Фішера або Брента–Кунга), що об'єднує два суміжні інтервали: лівий `(G_L, P_L)` та правий `(G_R, P_R)`:

```
(G_L, P_L) • (G_R, P_R) = (G_L + P_L · G_R,   P_L · P_R) [композиція префіксних інтервалів]
```

Доведемо строгу асоціативність оператора `•`. Розглянемо три послідовні розрядні блоки `A = (g_3, p_3)`, `B = (g_2, p_2)`, `C = (g_1, p_1)`:

```
(A • B) • C
= (g_3 + p_3·g_2, p_3·p_2) • (g_1, p_1) [обчислення лівої композиції A • B]
= ( (g_3 + p_3·g_2) + (p_3·p_2)·g_1,   (p_3·p_2)·p_1 ) [обчислення результату з правою парою C]
= ( g_3 + p_3·g_2 + p_3·p_2·g_1,   p_3·p_2·p_1 ) [розкриття дужок]

A • (B • C)
= (g_3, p_3) • (g_2 + p_2·g_1, p_2·p_1) [обчислення правої композиції B • C]
= ( g_3 + p_3·(g_2 + p_2·g_1),   p_3·(p_2·p_1) ) [обчислення результату з лівою парою A]
= ( g_3 + p_3·g_2 + p_3·p_2·g_1,   p_3·p_2·p_1 ) [дистрибутивність кон'юнкції: повний збіг із лівим групуванням]
```

Оскільки `(A • B) • C = A • (B • C)`, порядок розстановки дужок не змінює результату. Асоціативність дозволяє будувати префіксні обчислювальні дерева будь-якої топології:

1. **Дерево Когге–Стоуна (Kogge-Stone Adder):** забезпечує мінімальну логічну глибину `log₂ N` та коефіцієнт розгалуження (Fan-Out) не більше 2 на кожному вузлі. Ця топологія є найшвидшою у високопродуктивних процесорах, проте вимагає максимальної кількості логічних елементів (`O(N · log₂ N)`) та щільного трасування шин.
2. **Дерево Брента–Кунга (Brent-Kung Adder):** мінімізує кількість логічних вузлів і площу трасування, маючи лінійну кількість операторів (`O(N)`), але подвоєну глибину дерева `2·log₂ N - 1`. Це ідеальний компроміс для енергоефективних мікроконтролерів.
3. **Дерево Хан–Карлсона (Han-Carlson Adder):** гібридна архітектура, що обчислює префікси лише для непарних бітів на проміжних рівнях, зменшуючи кількість міжз'єднань у півтора раза порівняно з Когге–Стоуном при збільшенні затримки лише на 1 вентильний рівень.

Асоціативна алгебра паралельного переносу перетворює задачу арифметичного додавання на топологічну оптимізацію спрямованого ациклічного графа, дозволяючи досягати затримок менше ніж 200 пікосекунд у 64-розрядних трактах сучасних мікропроцесорів.
