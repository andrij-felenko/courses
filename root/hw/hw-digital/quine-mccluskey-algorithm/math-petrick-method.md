# 🧮 Метод Патріка для розв'язання циклічних таблиць покриття

Коли друга фаза методу Квайна–Мак-Класкі вилучає всі істотні прості імпліканти та вичерпує правила домінування рядків і стовпців, таблиця покриття нерідко залишається непорожньою. У такій таблиці кожен стовпець містить щонайменше дві позначки, і жоден рядок не домінує над іншим. Така конфігурація зветься **циклічним ядром** (англ. *cyclic core*). Спроби жадібно обрати довільний імплікант можуть призвести до неоптимального виразу. Метод, запропонований Стенлі Патріком (англ. *Stanley R. Petrick*) 1956 року, перетворює комбінаторну вимогу покриття стовпців на точне булеве рівняння, алгебраїчне розкриття якого дає **всі** можливі мінімальні покриття без пропусків.

## Алгебраїчна постановка задачі покриття

Нехай після попередніх спрощень залишилося `m` непокритих мінтермів `C₁, C₂, …, Cₘ` та `k` кандидатів у прості імпліканти `P₁, P₂, …, Pₖ`.

Кожному простому імпліканту `Pᵢ` зіставимо булеву змінну, яка набуває значення `1`, якщо імплікант включено до фінального покриття, і `0`, якщо його відкинуто.

Щоб мінтерм `Cⱼ` був покритим, необхідно й достатньо обрати **хоча б один** із тих імплікантів, які його накривають. Якщо стовпець `Cⱼ` має позначки в рядках `P_{j₁}, P_{j₂}, …, P_{jᵣ}`, ця вимога записується диз'юнкцією:

```
(P_{j₁} + P_{j₂} + … + P_{jᵣ}) = 1
```

Щоб функція була реалізована повністю, необхідно задовольнити вимоги **кожного** стовпця одночасно. Об'єднання всіх окремих умов дає кон'юнкцію кон'юнктивних вимог (кон'юнктивну нормальну форму, КНФ):

```
P = ∏ (P_{j₁} + P_{j₂} + … + P_{jᵣ}) = 1    [j = 1 … m]
```

Вираз `P` є функцією істинності покриття. Будь-який двійковий набір змінних `(P₁, …, Pₖ)`, на якому `P = 1`, задає коректне покриття всіх стовпців. Завдання полягає в тому, щоб перетворити вираз `P` із добутку сум (КНФ) у суму добутків (ДНФ) і знайти кон'юнкції з найменшою кількістю змінних та найменшою сумарною вагою літер.

## Закони булевого спрощення

Пряме перемноження дужок за дистрибутивним законом породжує велику кількість кон'юнкцій. Однак більшість із них є надлишковими або повторюваними. Для їхнього спрощення застосовують три фундаментальні закони [булевої алгебри](topic:math-logic/boolean-algebra):

```
X·X = X                     [ідемпотентність множення: усунення повторних імплікантів]
X + X = X                   [ідемпотентність додавання: усунення однакових варіантів]
X + X·Y = X                 [закон поглинання: викреслення надлишкових розширень]
(X + Y)·(X + Z) = X + Y·Z   [дистрибутивність додавання щодо множення]
```

Особливо потужним є закон поглинання `X + X·Y = X`. Якщо варіант покриття `X` (наприклад, `P₁·P₃`) повністю міститься всередині іншого варіанта `X·Y` (наприклад, `P₁·P₃·P₄`), то другий варіант містить зайвий імплікант `P₄` і може бути відкинутий без втрати правильності.

## Повний розбір циклічного ядра

Розглянемо класичну циклічну таблицю 6×6, де шість імплікантів `P₁ … P₆` накривають шість мінтермів `m₀ … m₅` кільцем (кожен імплікант накриває рівно два суміжні мінтерми):

```
Імплікант    m₀    m₁    m₂    m₃    m₄    m₅
─────────────────────────────────────────────
P₁           ✕     ✕
P₂                 ✕     ✕
P₃                       ✕     ✕
P₄                             ✕     ✕
P₅                                   ✕     ✕
P₆           ✕                             ✕
```

У цій таблиці немає жодного стовпця з єдиним `✕` (у кожному стовпці рівно дві позначки), а всі рядки накривають рівно по два мінтерми (немає домінування рядків чи стовпців).

### Крок 1: Запис функції покриття у КНФ

Запишемо вимогу покриття для кожного з шести стовпців:

```
P = (P₁ + P₆) · (P₁ + P₂) · (P₂ + P₃) · (P₃ + P₄) · (P₄ + P₅) · (P₅ + P₆)
```

### Крок 2: Попарне перемноження суміжних дужок

Згрупуємо дужки по двоє та застосуємо дистрибутивний закон `(X + Y)·(X + Z) = X + Y·Z`:

```
(P₁ + P₆)·(P₁ + P₂)
= P₁ + P₂·P₆                [дистрибутивність за спільним термом P₁]

(P₂ + P₃)·(P₃ + P₄)
= P₃ + P₂·P₄                [дистрибутивність за спільним термом P₃]

(P₄ + P₅)·(P₅ + P₆)
= P₅ + P₄·P₆                [дистрибутивність за спільним термом P₅]
```

Отримуємо стислий вираз із трьох доданків:

```
P = (P₁ + P₂·P₆) · (P₃ + P₂·P₄) · (P₅ + P₄·P₆)
```

### Крок 3: Перемноження перших двох блоків

```
(P₁ + P₂·P₆) · (P₃ + P₂·P₄)
= P₁·P₃ + P₁·P₂·P₄ + P₂·P₃·P₆ + P₂·P₄·P₆·P₂   [розкриття дужок]
= P₁·P₃ + P₁·P₂·P₄ + P₂·P₃·P₆ + P₂·P₄·P₆      [ідемпотентність: P₂·P₂ = P₂]
```

### Крок 4: Фінальне перемноження та поглинання

Множимо отриманий проміжний результат на третій блок `(P₅ + P₄·P₆)`:

```
P = (P₁·P₃ + P₁·P₂·P₄ + P₂·P₃·P₆ + P₂·P₄·P₆) · (P₅ + P₄·P₆)

= P₁·P₃·P₅ + P₁·P₃·P₄·P₆
  + P₁·P₂·P₄·P₅ + P₁·P₂·P₄·P₆
  + P₂·P₃·P₅·P₆ + P₂·P₃·P₄·P₆
  + P₂·P₄·P₅·P₆ + P₂·P₄·P₆
```

Застосовуємо закон поглинання `X + X·Y = X`:
- Терм `P₂·P₄·P₆` поглинає довші терми, що його містять:
  * поглинає `P₁·P₂·P₄·P₆`
  * поглинає `P₂·P₃·P₄·P₆`
  * поглинає `P₂·P₄·P₅·P₆`

Отримуємо скорочену диз'юнктивну нормальну форму:

```
P = P₁·P₃·P₅ + P₂·P₄·P₆ + P₁·P₃·P₄·P₆ + P₁·P₂·P₄·P₅ + P₂·P₃·P₅·P₆
```

Кожен кон'юнктивний доданок у цьому виразі є валідним покриттям нашої початкової таблиці:
1. `P₁·P₃·P₅` — покриття з **3 імплікантів** (імпліканти 1, 3, 5).
2. `P₂·P₄·P₆` — покриття з **3 імплікантів** (імпліканти 2, 4, 6).
3. `P₁·P₃·P₄·P₆` — покриття з 4 імплікантів (надлишкове).
4. `P₁·P₂·P₄·P₅` — покриття з 4 імплікантів (надлишкове).
5. `P₂·P₃·P₅·P₆` — покриття з 4 імплікантів (надлишкове).

## Вибір глобального оптимуму

Серед знайдених мінімальних кон'юнкцій відбирають ті, що містять найменшу кількість простих імплікантів. Тут маємо два рівноцінні варіанти мінімального розміру 3:

```
Варіант A:  F = P₁ + P₃ + P₅
Варіант B:  F = P₂ + P₄ + P₆
```

Якщо всі прості імпліканти мають однакову довжину (кількість літер), обидва варіанти є абсолютно еквівалентними за ціною. Якщо ж окремі імпліканти мають різну кількість літер (наприклад, `P₁` — 2 літери, а `P₂` — 3 літери), підраховується сумарна ціна літер кожного варіанта, і обирається вираз із найменшою вартістю.

## Обчислювальна складність та оптимізація розгалуженням

Метод Патріка гарантує знаходження **всіх** мінімальних покриттів і є повністю точним. Проте його обчислювальна складність у найгіршому випадку зростає експоненційно: розкриття `m` дужок може згенерувати до `2ᵐ` проміжних термів перед поглинанням.

Коли розмір циклічного ядра перевищує кілька десятків стовпців, замість символьного перемноження застосовують алгоритм **гілок і меж** (англ. *branch and bound*, або правило розщеплення Квайна):
1. Обирають опорний стовпець `Cⱼ` із мінімальною кількістю позначок.
2. Створюють дві рекурсивні гілки для кандидата `Pᵢ`:
   - **Гілка 1 (взяти `Pᵢ`):** додаємо `Pᵢ` до поточного розв'язку, вилучаємо всі стовпці, які він накриває, і рекурсивно розв'язуємо меншу таблицю.
   - **Гілка 2 (відкинути `Pᵢ`):** вилучаємо рядок `Pᵢ` з таблиці та рекурсивно шукаємо розв'язок серед решти імплікантів.
3. Відсікають гілки, поточна вартість яких уже перевищує вартість найкращого знайденого розв'язку.

Метод Патріка залишається фундаментальним алгебраїчним еталоном: він показує прямий зв'язок між логічним висновком та оптимізацією дискретного покриття.
