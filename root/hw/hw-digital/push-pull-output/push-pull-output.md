# Двотактний вихід (Push-Pull Output): активне керування обома логічними рівнями

Більшість GPIO-виводів мікроконтролерів (STM32, ESP32, AVR, RP2040) за замовчуванням працюють у режимі **двотактного виходу** (англ. @@en|push-pull output@@). На відміну від виходу з відкритим стоком (@@en|open-drain output@@), який здатний лише притягувати лінію до землі, двотактна схема активна в обох станах: вона напряму «виштовхує» струм із джерела живлення в навантаження при логічній `1` та «всмоктує» струм із навантаження на землю при логічному `0`.

---

## 1. Схема та принцип дії комплементарної пару транзисторів

Основою двотактного виходу є комплементарна пара польових транзисторів (CMOS): верхній **P-канальний MOSFET** (англ. @@en|PMOS@@ — верхнє плече, @@en|high-side transistor@@) та нижній **N-канальний MOSFET** (англ. @@en|NMOS@@ — нижнє плече, @@en|low-side transistor@@), з'єднані послідовно між шиною живлення $V_{DD}$ та землею $GND$.

```
           V_DD
            │
        ┌───┴───┐
      ──┤ P-MOS │ (High-side)
        └───┬───┘
            ├─── Out (Вихід GPIO)
        ┌───┴───┐
      ──┤ N-MOS │ (Low-side)
        └───┬───┘
            │
           GND
```

### Режими роботи:

1. **Логічна одиниця (`1` / High)**:
   - Внутрішній драйвер подає низький рівень на затвори.
   - P-MOS транзистор **відкривається**, підключаючи вихід напряму до $V_{DD}$.
   - N-MOS транзистор **закривається**.
   - Струм витікає з виводу в навантаження (англ. @@en|source current@@).

2. **Логічний нуль (`0` / Low)**:
   - Внутрішній драйвер подає високий рівень на затвори.
   - P-MOS транзистор **закривається**.
   - N-MOS транзистор **відкривається**, притягуючи вихід до $GND$.
   - Струм втікає у вивід із навантаження на землю (англ. @@en|sink current@@).

---

## 2. Переваги та обмеження двотактного режиму

### Переваги:
- **Висока швидкість перемикання**: Завдяки низькому відкритому опору транзисторів ($R_{DS(on)}$ близько $20\dots 50 \text{ Ом}$) паразитна ємність лінії та затворів навантаження заряджається й розряджається активним струмом. Стрімкий фронт та спад імпульсу (понад $50\dots 100 \text{ МГц}$).
- **Вдсутність підтягувального резистора**: На відміну від Open-Drain, для стабільного формування логічної `1` не потрібен зовнішній @@en|pull-up@@ резистор, що економить компоненти та площу плати.
- **Повна амплітуда сигналу (Rail-to-Rail)**: Вихідна напруга досягає значень $V_{OH} \approx V_{DD}$ та $V_{OL} \approx GND$.

### Обмеження та застереження:
- ⛔ **Заборона об'єднання виходів (Bus Contention)**: Спроба з'єднати два двотактні виводи разом призведе до КЗ, якщо один вивод видасть `1`, а інший — `0`. Виникає високий струм короткого замикання (скрізний струм), який здатний випалити GPIO-порти мікроконтролера.
- **Шини з кількома майстрами**: Двотактний режим не підходить для шин I2C або One-Wire, де на одній лінії працюють кілька пристроїв. Для них використовують режим Open-Drain.

## 3. Практичне налаштування в мікроконтролерах

### STM32 (HAL / LL):
```c
GPIO_InitTypeDef GPIO_InitStruct = {0};
GPIO_InitStruct.Pin = GPIO_PIN_5;
GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP; // Push-Pull mode
GPIO_InitStruct.Pull = GPIO_NOPULL;
GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_HIGH;
HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);
```

### AVR / Arduino:
```cpp
pinMode(13, OUTPUT); // За замовчуванням конфігурується у Push-Pull
digitalWrite(13, HIGH);
```

## 4. Підсумкове порівняння: Push-Pull проти Open-Drain

| Параметр | Push-Pull (Двотактний) | Open-Drain (Відкритий сток) |
| :--- | :--- | :--- |
| **Активне плече `1`** | Так (PMOS підтягує до $V_{DD}$) | Ні (виможений зовнішній Pull-up) |
| **Активне плече `0`** | Так (NMOS притягує до $GND$) | Так (NMOS притягує до $GND$) |
| **Швидкість фронту `0 → 1`** | Дуже висока (активний заряд) | Обмежена опором резистора $R_{pullup}$ |
| **Об'єднання виходів** | ⛔ Заборонено (ризик КЗ) | ✅ Дозволено (Wired-AND) |
| **Сфера застосування** | SPI, UART, PWM, LED, реле | I2C, SMBus, 1-Wire, переривання |
