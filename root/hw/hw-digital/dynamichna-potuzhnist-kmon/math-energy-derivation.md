# 🧮 Виведення енергетичного балансу перезаряду КМОН та інтегралу наскрізного струму

Цей математичний аналіз виводить точний розподіл енергії під час перезаряджання паразитної ємності КМОН-вузла, доводить незалежність теплових втрат на каналі транзистора від його омічного опору (включно з довільною нелінійністю вольт-амперної характеристики), розраховує енергетику неповного розмаху напруг, а також виводить аналітичний інтеграл наскрізного струму короткого замикання за моделлю Веєстакера з урахуванням вихідного навантаження.

---

### 1. Аналітичне виведення балансу енергії під час заряду ємності (перехід 0 → 1)

Розгляньмо еквівалентну схему заряджання вихідного вузла інвертора. До шини живлення з постійною напругою `V_DD` через відкритий PMOS-транзистор із динамічним, нелінійним опором каналу `R_on,p(t)` під'єднано зосереджену навантажувальну ємність `C_L`. У початковий момент часу `t = 0` напруга на конденсаторі дорівнює нулю: `v_C(0) = 0`. До моменту завершення перехідного процесу `t → ∞` напруга на конденсаторі досягає напруги живлення: `v_C(∞) = V_DD`.

Миттєвий струм заряду `i(t)`, що витікає з шини живлення `V_DD` і втікає в конденсатор, визначається фундаментальним диференціальним співвідношенням для ємності:

```
i(t) = C_L · (dv_C / dt)
```

#### Загальна енергія, отримана від джерела живлення

Енергія `E_VDD`, яку джерело живлення віддає в схему протягом усього часу заряду від `t = 0` до `t = ∞`, дорівнює інтегралу миттєвої потужності джерела `p_VDD(t) = V_DD · i(t)`:

```
E_VDD
= ∫₀^∞ (V_DD · i(t)) dt              [означення повної електричної енергії]
= V_DD · ∫₀^∞ i(t) dt               [константа V_DD винесена за знак інтеграла]
= V_DD · ∫₀^V_DD (C_L · dv_C)       [заміна змінної інтегрування: i(t) dt = C_L dv_C]
= V_DD · C_L · ∫₀^V_DD dv_C         [константа C_L винесена за інтеграл]
= V_DD · C_L · [v_C]₀^V_DD          [обчислення первісної]
= C_L · V_DD²                       [підстановка меж: (V_DD - 0)]
```

Отже, повна енергія, передана джерелом живлення за один акт заряду, строго дорівнює добутку повного переданого заряду `Q = C_L · V_DD` на напругу живлення `V_DD`:

```
E_VDD = Q · V_DD = C_L · V_DD²
```

#### Енергія, накопичена в електричному полі конденсатора

Енергія `E_cap`, накопичена в електричному полі зарядженої ємності `C_L` при досягненні напруги `V_DD`, дорівнює інтегралу миттєвої потужності, що надходить безпосередньо в конденсатор:

```
E_cap
= ∫₀^∞ (v_C(t) · i(t)) dt           [миттєва потужність на обкладках ємності]
= ∫₀^V_DD (v_C · C_L) dv_C          [заміна змінної: i(t) dt = C_L dv_C]
= C_L · ∫₀^V_DD v_C dv_C            [винесення константи C_L]
= C_L · [½ · v_C²]₀^V_DD            [інтегрування степеневої функції]
= ½ · C_L · V_DD²                   [підстановка меж інтегрування]
```

#### Енергія, розсіяна у вигляді тепла на транзисторі PMOS

Згідно з другим законом Кірхгофа, миттєва напруга на каналі PMOS-транзистора дорівнює спаду напруги між шиною живлення та вихідним вузлом: `v_ds,p(t) = V_DD - v_C(t)`.

Миттєва теплова потужність, що розсіюється на опорі каналу транзистора `R_on,p`, визначається як `p_PMOS(t) = v_ds,p(t) · i(t) = (V_DD - v_C(t)) · i(t)`.

Інтегруємо цю потужність за часом перехідного процесу:

```
E_PMOS
= ∫₀^∞ ((V_DD - v_C(t)) · i(t)) dt  [інтеграл потужності втрат на каналі]
= ∫₀^∞ (V_DD · i(t)) dt - ∫₀^∞ (v_C(t) · i(t)) dt  [розбиття на два інтеграли]
= E_VDD - E_cap                     [підстановка знайдених вище енергій]
= C_L · V_DD² - ½ · C_L · V_DD²    [віднімання значень]
= ½ · C_L · V_DD²                   [остаточний баланс втрат]
```

Цей фундаментальний висновок доводить: **рівно 50% енергії, переданої джерелом живлення, неминуче розсіюється у вигляді тепла на активному опорі каналу заряджального транзистора, незалежно від величини та нелінійності його опору `R_on,p(t)`.**

Зміна ширини каналу чи матеріалу напівпровідника змінює лише час протікання процесу `τ = R_on · C_L` та амплітуду струму, але загальна кількість виділеного тепла лишається строго інваріантною: `½ · C_L · V_DD²`.

### 2. Енергетичний баланс за неповного розмаху напруг (Partial Voltage Swing)

У деяких спеціалізованих низькоспоживаючих інтерфейсах (наприклад, у шинах пам'яті SSTL або при диференційній передачі сигналів низької напруги LVDS) вихідний сигнал гойдається не від `0` до `V_DD`, а в обмеженому діапазоні від рівня `V_OL` до рівня `V_OH`, де `ΔV = V_OH - V_OL < V_DD`.

Обчислімо енергетику такого перехідного процесу. Під час переходу з рівня `V_OL` до `V_OH` джерело живлення постачає заряд `ΔQ = C_L · (V_OH - V_OL) = C_L · ΔV`.

Повна енергія, взята від джерела живлення:

```
E_VDD_partial
= V_DD · ΔQ                         [добуток напруги живлення на перенесений заряд]
= C_L · V_DD · (V_OH - V_OL)        [енергія живлення при неповному перепаді]
```

Зміна накопиченої в конденсаторі енергії становить:

```
ΔE_cap
= ½ · C_L · V_OH² - ½ · C_L · V_OL² [різниця кінцевої та початкової енергій поля]
= ½ · C_L · (V_OH² - V_OL²)         [винесення спільного множника]
= ½ · C_L · (V_OH - V_OL) · (V_OH + V_OL) [розклад різниці квадратів]
```

Теплові втрати на транзисторі PMOS під час часткового заряду:

```
E_PMOS_partial
= E_VDD_partial - ΔE_cap            [баланс енергії за першим законом термодинаміки]
= C_L · V_DD · (V_OH - V_OL) - ½ · C_L · (V_OH - V_OL) · (V_OH + V_OL)
= C_L · (V_OH - V_OL) · (V_DD - ½ · (V_OH + V_OL))
```

Якщо напруга живлення зменшена так, що рівні стають симетричними відносно половини живлення, або коли `V_OH = V_DD` та `V_OL = 0`, формула повертається до класичного значення `½ · C_L · V_DD²`. Зменшення амплітуди перепаду `ΔV` дає лінійне зниження енергії за один перехід, що лежить в основі всіх високошвидкісних інтерфейсів пам'яті.

### 3. Аналітичне виведення балансу енергії під час розряду ємності (перехід 1 → 0)

Під час перемикання виходу з одиниці в нуль PMOS-транзистор закривається, повністю відсікаючи джерело живлення `V_DD` (`E_VDD = 0`), а NMOS-транзистор відкривається, з'єднуючи заряджений конденсатор із землею.

Початкова напруга на ємності `v_C(0) = V_DD`, кінцева напруга `v_C(∞) = 0`. Струм розряду `i_dis(t) = -C_L · (dv_C / dt)`.

Миттєва напруга на каналі NMOS дорівнює напрузі на конденсаторі: `v_ds,n(t) = v_C(t)`.

Повна енергія, яка виділяється на опорі NMOS-транзистора у вигляді тепла:

```
E_NMOS
= ∫₀^∞ (v_C(t) · i_dis(t)) dt       [інтеграл потужності розряду]
= ∫_V_DD^0 (v_C · (-C_L)) dv_C      [заміна змінних з урахуванням напрямку струму]
= C_L · ∫₀^V_DD v_C dv_C            [зміна меж інтегрування за рахунок знака мінус]
= ½ · C_L · V_DD²                   [результат інтегрування]
```

Уся енергія, попередньо збережена в електричному полі конденсатора під час фази заряду, під час фази розряду повністю перетворюється на теплову енергію в каналі NMOS-транзистора.

#### Загальний енергетичний підсумок повного такту перемикання

За повний цикл (0 → 1 → 0) сумарна розсіяна теплова енергія становить:

```
E_cycle
= E_PMOS + E_NMOS                   [сума втрат за дві напівфази]
= ½ · C_L · V_DD² + ½ · C_L · V_DD² [додавання теплових втрат]
= C_L · V_DD²                       [повна енергія циклу]
```

Якщо вузол перемикається з тактовою частотою `f`, а ймовірність переходу 0 → 1 за один такт дорівнює коефіцієнту активності `α`, середня потужність ємнісного розсіювання визначається як:

```
P_cap = α · C_L · V_DD² · f
```

### 4. Математична модель наскрізного струму короткого замикання (модель Веєстакера)

Під час перемикання інвертора вхідна напруга `v_in(t)` змінюється за лінійним законом з крутизною фронту `t_rf`:

```
v_in(t) = (V_DD / t_rf) · t         [при переході 0 → V_DD]
```

Припустимо симетричний інвертор із рівними пороговими напругами NMOS та PMOS: `V_th,n = |V_th,p| = V_th` та однаковими питомими крутизнами транзисторів: `β_n = β_p = β = μ · C_ox · (W / L)`.

Обидва транзистори одночасно проводять струм у діапазоні вхідних напруг:

```
V_th < v_in(t) < V_DD - V_th
```

Цей інтервал часу триває:

```
Δt_sc = t_rf · (1 - 2 · (V_th / V_DD))
```

#### Розрахунок пікового струму короткого замикання

Максимальний наскрізний струм `I_peak` досягається в точці симетрії `v_in = V_DD / 2`, коли обидва транзистори перебувають у режимі насичення:

```
I_peak
= ½ · β · (v_in - V_th)²            [формула струму насичення MOSFET]
= ½ · β · (V_DD / 2 - V_th)²        [підстановка v_in = V_DD / 2]
= ⅛ · β · (V_DD - 2·V_th)²          [спрощення виразу]
```

#### Інтегрування наскрізного струму за фронт перемикання

Струм короткого замикання `i_sc(t)` як функція вхідної напруги має форму симетричної параболи від `v_in = V_th` до `v_in = V_DD - V_th`.

Інтеграл заряду `Q_sc`, що протікає крізь обидва транзистори за один фронт (наростання або спаду), обчислюється через заміну змінної `dt = (t_rf / V_DD) dv_in`:

```
Q_sc
= 2 · ∫_(t(V_th))^(t(V_DD/2)) i_sc(t) dt  [інтеграл струму двох симетричних половин]
= 2 · ∫_V_th^(V_DD/2) (½ · β · (v_in - V_th)²) · (t_rf / V_DD) dv_in
= (β · t_rf / V_DD) · ∫_V_th^(V_DD/2) (v_in - V_th)² dv_in
= (β · t_rf / V_DD) · [⅓ · (v_in - V_th)³]_V_th^(V_DD/2)
= (β · t_rf / (3 · V_DD)) · (V_DD / 2 - V_th)³
= (β · t_rf / (24 · V_DD)) · (V_DD - 2·V_th)³
```

#### Повна потужність наскрізного струму

Оскільки за один повний період сигналу відбуваються два перемикання (фронт наростання і фронт спаду), сумарний наскрізний заряд за період становить `2 · Q_sc`.

Повна середня потужність короткого замикання `P_sc` при робочій частоті `f` та напрузі живлення `V_DD`:

```
P_sc
= (2 · Q_sc) · V_DD · f             [середня потужність за період]
= 2 · ((β · t_rf / (24 · V_DD)) · (V_DD - 2·V_th)³) · V_DD · f
= (1 / 12) · β · (V_DD - 2·V_th)³ · t_rf · f
```

#### Врахування впливу ємності навантаження `C_L`

Класична формула Веєстакера отримана для ненавантаженого інвертора (`C_L → 0`), коли напруга на виході встигає миттєво відслідковувати вхідний стан. У реальній схемі присутня скінченна ємність навантаження `C_L`, яка уповільнює зміну вихідної напруги `v_out(t)`.

Позначмо сталу часу вихідного кола як `τ_out = R_on · C_L ≈ C_L / (β · (V_DD - V_th))`.

Якщо `t_rf ≤ τ_out` (швидкий вхідний фронт, відносно важке навантаження), вихідна напруга `v_out` під час проходження небезпечної зони залишається високою, що переводить нижній NMOS у лінійний режим з малим спадом напруги `v_ds,n`. За таких умов реальний струм короткого замикання зменшується в рази за рахунок поправочного коефіцієнта навантаження:

```
P_sc_loaded ≈ P_sc · (1 / (1 + (τ_out / t_rf)²))
```

Це математично підтверджує ключовий висновок схемотехніки КМОН: за правильного балансу затримок, коли тривалість фронту на вході вентиля не перевищує затримки розряду його вихідного вузла, втрати на наскрізний струм природно придушуються й не перевищують лічених відсотків від енергії ємнісного перезаряду.
