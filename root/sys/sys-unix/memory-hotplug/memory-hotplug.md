# Гаряче додавання й вилучення пам'яті (Memory Hotplug)

**Memory Hotplug** — це механізм у ядрі Linux, що дозволяє динамічно додавати та вилучати оперативну пам'ять під час роботи операційної системи, без її перезавантаження. 

Ця технологія є критично важливою для:
- **Хмарних середовищ та віртуалізації:** гіпервізори можуть динамічно виділяти або забирати RAM у віртуальних машин залежно від навантаження.
- **Enterprise-серверів:** дозволяє замінювати пошкоджені модулі пам'яті або збільшувати загальний обсяг RAM без зупинки критичних сервісів.

Керування блоками пам'яті здійснюється через віртуальну файлову систему `sysfs`, зазвичай у каталозі `/sys/devices/system/memory/`. Пам'ять ділиться на блоки (наприклад, `memory0`, `memory1`), які можна переводити у стан `online` (доступна для використання) або `offline` (вилучена з використання). Вилучення пам'яті є значно складнішим завданням, ніж додавання, оскільки ядру доводиться "на льоту" переміщувати (мігрувати) зайняті сторінки пам'яті в інші ділянки, оновлюючи таблиці сторінок процесів.
