# 📋 Довідник анотацій Sparse

Нижче наведено найпоширеніші анотації, що застосовуються в коді ядра Linux для роботи зі Sparse. Усі вони визначені в заголовку `include/linux/compiler_types.h`. Внутрішню форму наведено з номерами адресних просторів — так їх писали до ядра 5.4 включно; з 5.5 ті самі макроси вживають імена (`address_space(__user)` замість `address_space(1)`), а сенс анотацій не змінився.

| Анотація | Внутрішній макрос | Призначення |
|----------|-------------------|-------------|
| `__user` | `__attribute__((noderef, address_space(1)))` | Позначає вказівник на простір користувача. Забороняє пряме розіменування та змішування з вказівниками ядра. Вимагає використання `copy_from_user()` / `copy_to_user()`. |
| `__iomem` | `__attribute__((noderef, address_space(2)))` | Позначає вказівник на пам'ять пристроїв (I/O). Вимагає використання спеціальних функцій доступу на кшталт `readl()` / `writel()`. |
| `__rcu` | `__attribute__((noderef, address_space(4)))` | Позначає вказівник, який захищено механізмом RCU (Read-Copy-Update). Вимагає використання `rcu_dereference()` для безпечного доступу. |
| `__percpu` | `__attribute__((noderef, address_space(3)))` | Змінні, специфічні для конкретного процесорного ядра (CPU). Звернення можливе лише через макроси `this_cpu_read()`, `per_cpu()` тощо. |
| `__bitwise` | `__attribute__((bitwise))` | Створює новий, суворий тип, що унеможливлює неявне зведення. Використовується переважно для чисел з певним порядком байтів (`__le32`, `__be16`). |
| `__force` | `__attribute__((force))` | Дозволяє примусове зведення (cast) між різними просторами адрес, ігноруючи попередження Sparse. |
| `__acquires(x)` | `__attribute__((context(x, 0, 1)))` | Вказує, що функція захоплює блокування (наприклад, spinlock) і не звільняє його до повернення. |
| `__releases(x)` | `__attribute__((context(x, 1, 0)))` | Вказує, що функція звільняє блокування, яке було захоплено раніше. |
