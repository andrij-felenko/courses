# Блокування вимкнення: systemd Inhibit Locks

Уявіть ситуацію: ви оновлюєте прошивку BIOS або записуєте важливий образ диска (`dd`), і в цей момент інший користувач або скрипт ініціює вимкнення системи. Це може призвести до непоправних наслідків (отримання "цеглини" замість материнської плати).

Щоб запобігти цьому, systemd пропонує механізм **Inhibitor Locks** (блокувань). Програми можуть через D-Bus зробити запит до `systemd-logind` на тимчасове блокування операцій сну, вимкнення або перезавантаження.

Адміністратори можуть використовувати утиліту `systemd-inhibit` для запуску критичних скриптів:

```bash
systemd-inhibit --what=shutdown:sleep --who="Firmware Updater" \
                --why="Flashing BIOS, do not interrupt" \
                fwupdmgr update
```

Доки виконується ця команда, будь-який запит на вимкнення системи (навіть натискання кнопки живлення, якщо воно обробляється логічно) буде відкладено або відхилено, доки блокування не буде знято. Це важливий патерн для написання надійних системних утиліт.
