# 📋 Довідник інтерфейсу AWK: вбудовані змінні, системні функції та опції CLI

Мова AWK надає фіксований набір вбудованих спеціальних змінних для керування станом парсера, системні функції для обробки рядків і виконання чисельних обчислень, а також прапорці командного рядка для конфігурації середовища виконання. Цей довідник описує стандартний інтерфейс POSIX AWK із детальним описом семантики поведінки, крайових випадків та поширених розширень GNU AWK (`gawk`).

---

## 1. Спеціальні системні змінні

Вбудовані змінні автоматично ініціалізуються інтерпретатором під час запуску програми та оновлюються на кожному кроці циклу обробки записів. Будь-яку з цих змінних можна зчитувати у виразах та змінювати вручну для динамічного керування парсером.

| Змінна | Тип | За замовчуванням | Призначення та семантика |
|---|---|---|---|
| **`$0`** | Рядок | — | Повний вміст поточного вхідного запису (включно з внутрішніми роздільниками). |
| **`$1` .. `$NF`** | Рядок / Число | — | Позиційні поля поточного запису, виділені за правилами `FS`. Модифікація будь-якого `$i` призводить до автоматичної перебудови `$0` з використанням роздільника `OFS`. |
| **`FS`** | Рядок / Regex | `" "` (пробіл) | **Field Separator:** роздільник полів. Якщо `FS = " "`, роздільником вважається будь-яка послідовність пробілів та табуляцій (ведучі й кінцеві пробіли ігноруються). Якщо задано конкретний символ (наприклад, `":"`) або регулярний вираз (наприклад, `"[,\t]"`), поділ здійснюється строго за збігом. |
| **`RS`** | Рядок / Regex | `"\n"` (новий рядок) | **Record Separator:** роздільник записів. У стандарті POSIX — один символ. Якщо `RS = ""` (порожній рядок), вмикається режим абзаців (paragraph mode): записи розділяються одним або кількома порожніми рядками, а `FS` за замовчуванням сприймає новий рядок як роздільник полів. У `gawk` `RS` може бути довільним регулярним виразом. |
| **`OFS`** | Рядок | `" "` (пробіл) | **Output Field Separator:** роздільник полів під час виводу через інструкцію `print expr1, expr2` або під час автоматичної перебудови `$0`. |
| **`ORS`** | Рядок | `"\n"` (новий рядок) | **Output Record Separator:** роздільник записів під час виводу інструкцією `print`. Додається в кінець кожного друкованого рядка. |
| **`NF`** | Ціле число | — | **Number of Fields:** кількість полів у поточному записі `$0`. Може бути явно зменшено користувачем (наприклад, `NF = 2` обрізає всі поля після другого) або збільшено (створює порожні поля). |
| **`NR`** | Ціле число | `0` | **Number of Records:** глобальний порядковий номер поточного оброблюваного запису з моменту запуску програми через усі вхідні файли. |
| **`FNR`** | Ціле число | `0` | **File Number of Records:** порядковий номер поточного запису у поточному відкритому вхідному файлі. Скидається в `1` під час переходу до кожного наступного файлу зі списку аргументів. |
| **`FILENAME`** | Рядок | `""` | Ім'я поточного вхідного файлу, який зчитує інтерпретатор. У блоці `BEGIN` значення дорівнює порожньому рядку `""`. Під час читання зі стандартного вводу містить `"-"` або `""` залежно від реалізації. |
| **`ARGC`** | Ціле число | — | Кількість позиційних аргументів командного рядка, переданих інтерпретатору (включно з іменем самої утиліти `awk`). |
| **`ARGV`** | Масив | — | Асоціативний масив аргументів командного рядка з числовими індексами від `0` до `ARGC - 1`. Елементи масиву можна модифікувати або очищати (`ARGV[i] = ""`) у блоці `BEGIN` для динамічного керування списком оброблюваних файлів. |
| **`ENVIRON`** | Масив | — | Асоціативний масив змінних середовища поточного процесу. Ключами є імена змінних (наприклад, `ENVIRON["USER"]`, `ENVIRON["PATH"]`). |
| **`SUBSEP`** | Рядок | `"\034"` (ASCII 28) | **Subscript Separator:** невидимий роздільник, який використовується для конкатенації індексів у багатовимірних масивах виду `arr[i, j]`. |
| **`CONVFMT`** | Рядок | `"%.6g"` | Формат неявного перетворення числових значень у рядки під час конкатенації або запису в масив. |
| **`OFMT`** | Рядок | `"%.6g"` | Формат виводу чисел із плаваючою комою за допомогою простої інструкції `print`. |
| **`RSTART`** | Ціле число | `0` | Початкова позиція (індексація з 1) знайденого фрагмента після виклику функції `match()`. Якщо збігу немає — `0`. |
| **`RLENGTH`** | Ціле число | `-1` | Довжина у символах знайденого фрагмента після виклику функції `match()`. Якщо збігу немає — `-1`. |

### Тонкощі поведінки спеціальних змінних

1. **Особливий статус пробілу у `FS`:** Якщо змінній `FS` явно присвоєно рядок з одного пробілу (`FS = " "`), інтерпретатор застосовує спеціальний алгоритм розбиття. Пробіли та знаки табуляції на початку рядка відтинаються, будь-яка група послідовних пробілів вважається одним роздільником, а пробіли в кінці рядка ігноруються. Якщо потрібно розбивати рядок строго по одному пробілу (з утворенням порожніх полів), слід використовувати регулярний вираз `FS = "[ ]"`.
2. **Спеціальні розширення GNU AWK для розбиття полів:**
   - **`FPAT` (Field Pattern):** замість опису того, що стоїть між полями (роздільник), `FPAT` описує сам вміст полів через регулярний вираз. Наприклад, для парсингу файлів CSV із лапками використовується `FPAT = "([^,]+)|(\"[^\"]+\")"`.
   - **`FIELDWIDTHS`:** рядок із переліком фіксованих ширин колонок (наприклад, `FIELDWIDTHS = "4 2 2 10"`). Дозволяє миттєво парсити бінарно-текстові логи з фіксованою структурою без використання роздільників.
   - **`IGNORECASE = 1`:** вмикає регістронезалежний пошук для всіх регулярних виразів, операторів `~` та функцій `sub`/`gsub`.

## 2. Вбудовані рядкові функції

Усі рядкові функції в AWK базуються на **1-індексації**: перший символ будь-якого рядка має індекс `1`, а не `0`. Якщо функції передається позиція `0`, вона або автоматично коригується до `1`, або генерує помилку залежно від суворості стандарту.

### `length([target]) -> int`
Обчислює та повертає кількість символів у рядку `target`. Якщо аргумент не передано, функція повертає довжину поточного повного запису `length($0)`. У GNU AWK, якщо як `target` передати ім'я асоціативного масиву, функція повертає кількість елементів у ньому.

### `substr(s, start [, length]) -> string`
Вирізає та повертає підрядок із вихідного рядка `s`, починаючи з позиції `start`. Якщо аргумент `length` вказано, вибирається щонайбільше `length` символів. Якщо `length` опущено або вказана довжина перевищує залишок рядка, повертаються всі символи до кінця `s`. Якщо `start` перевищує довжину рядка `length(s)`, функція повертає порожній рядок `""`.

### `index(s, substr) -> int`
Виконує лінійний пошук першого входження підрядка `substr` усередині рядка `s`. Повертає 1-індексовану позицію першого символу збігу. Якщо підрядок `substr` відсутній у `s`, функція повертає `0`.

### `match(s, regex [, array]) -> int`
Перевіряє, чи містить рядок `s` хоча б один збіг із регулярним виразом `regex`. Під час виконання функція автоматично модифікує системні змінні:
- `RSTART` встановлюється в позицію початку знайденого збігу (або `0` у разі невдачі).
- `RLENGTH` встановлюється в довжину знайденого фрагмента (або `-1` у разі невдачі).

Функція повертає значення `RSTART`. У реалізаціях POSIX.1-2008 та GNU AWK, якщо передано третій аргумент `array`, цей масив заповнюється знайденими групами захоплення: `array[1]` містить першу круглу дужку `(...)`, `array[2]` — другу тощо.

### `split(s, array [, fieldsep]) -> int`
Розбиває вхідний рядок `s` на елементи та записує їх у масив `array` з послідовними числовими індексами `array[1]`, `array[2]`, ..., `array[N]`. Перед початком роботи попередній вміст масиву `array` повністю очищається. Якщо параметр `fieldsep` не вказано, як роздільник використовується поточне значення системної змінної `FS`. Функція повертає ціле число `N` — загальну кількість сформованих елементів.

### `sub(regex, replacement [, target]) -> int`
Знаходить **перше** входження регулярного виразу `regex` у цільовому рядку `target` і замінює його на текст `replacement`. Якщо символ `&` зустрічається у рядку `replacement`, він замінюється на повний знайдений текстовий фрагмент, що збігся з `regex`. Модифікація рядка відбувається за місцем (in-place). Якщо третій аргумент `target` опущено, заміна виконується безпосередньо у поточному записі `$0` (що викликає подальшу інвалідацію полів `$1..$NF`). Функція повертає `1`, якщо заміну було виконано, або `0`, якщо збігів не виявлено.

### `gsub(regex, replacement [, target]) -> int`
Виконує **глобальну заміну**: знаходить усі входження регулярного виразу `regex` у рядку `target` і замінює їх на `replacement`. Повертає ціле число — загальну кількість виконаних замін. Якщо збігів немає, повертає `0`.

### `sprintf(format, expr1, expr2, ...) -> string`
Форматує передані аргументи відповідно до специфікаторів рядка `format` за аналогією з однойменною функцією мови C. Повертає результуючий рядок без виводу у стандартний потік.

### `tolower(s) -> string` / `toupper(s) -> string`
Повертають новий рядок, у якому всі символи переведені відповідно у нижній або верхній регістр з урахуванням правил поточної системної локалі.

## 3. Вбудовані математичні функції

Математичне ядро AWK виконує всі чисельні операції у форматі чисел із плаваючою комою подвійної точності IEEE 754 (еквівалент 64-бітного типу `double` у мові C). Це забезпечує 53 біти точності мантиси (близько 15–17 десяткових знаків) та діапазон експоненти від 10^-308 до 10^+308.

| Функція | Призначення | Поведінка та крайові випадки |
|---|---|---|
| **`int(x)`** | Відтинання дробової частини | Округлює число `x` до нуля (наприклад, `int(4.8)` повертає `4`, `int(-4.8)` повертає `-4`). Не виконує математичного округлення до найближчого цілого. |
| **`sqrt(x)`** | Квадратний корінь | Обчислює квадратний корінь. Якщо `x < 0`, генерує помилку часу виконання або повертає значення `NaN` (Not a Number). |
| **`exp(x)`** | Експоненційна функція | Обчислює значення e^x. У разі надто великого `x` призводить до переповнення (`+Inf`). |
| **`log(x)`** | Натуральний логарифм | Обчислює логарифм за основою e для числа `x > 0`. Якщо `x <= 0`, генерує помилку або повертає `-Inf` / `NaN`. |
| **`sin(x)`** | Тригонометричний синус | Приймає кут `x` у радіанах. |
| **`cos(x)`** | Тригонометричний косинус | Приймає кут `x` у радіанах. |
| **`atan2(y, x)`** | Арктангенс відношення | Обчислює арктангенс `y / x` у діапазоні `[-π, π]` радіан, коректно враховуючи знаки обох координат для визначення квадранта. |
| **`rand()`** | Генератор випадкових чисел | Повертає псевдовипадкове число з плаваючою комою у напіввідкритому інтервалі `[0.0, 1.0)`. Без попереднього виклику `srand()` видає ідентичну послідовність при кожному запуску програми. |
| **`srand([seed])`** | Ініціалізація генератора | Встановлює початкове зерно для `rand()`. Якщо `seed` не вказано, використовує поточний системний час в епосі Unix (з точністю до секунд). Повертає попереднє значення зерна. |

## 4. Механізми введення-виведення та керування процесами

### Інструкції `print` та `printf`
- **`print expr1, expr2, ...`:** виводить значення виразів, розділяючи їх рядком `OFS` (за замовчуванням пробіл), та завершує вивід символом `ORS` (новий рядок). Якщо викликати `print` без аргументів, виводиться весь поточний запис `$0`.
- **`printf format, expr1, expr2, ...`:** забезпечує точне форматування згідно зі специфікаторами `%d`, `%s`, `%f`, `%e`, `%x`, `%c`. На відміну від `print`, не додає автоматичного роздільника рядків.

### Перенаправлення виводу у файли та канали
Вивід будь-якої інструкції `print` чи `printf` може бути скерований у файл або конвеєр безпосередньо з AWK:
- `print $0 > "filename"` — відкриває файл на запис (якщо файл ще не відкривався у цьому процесі, він перезаписується; наступні виклики дописують дані у відкритий дескриптор).
- `print $0 >> "filename"` — відкриває файл у режимі дописування (`O_APPEND`).
- `print $0 | "command"` — відкриває міжпроцесний канал через POSIX-виклик `popen()` і передає байти на стандартний вхід зовнішньої утиліти.

### Детальна семантика викликів `getline`

| Варіант виклику | Джерело даних | Куди потрапляє рядок | Зміна NR / FNR | Повертане значення |
|---|---|---|---|---|
| **`getline`** | Поточний вхідний потік | `$0`, поля `$1..$NF`, `NF` | Оновлюються (`NR++`, `FNR++`) | `1` — успіх; `0` — EOF; `-1` — системна помилка. |
| **`getline var`** | Поточний вхідний потік | Змінна `var` (`$0` не змінюється) | Оновлюються (`NR++`, `FNR++`) | `1` — успіх; `0` — EOF; `-1` — системна помилка. |
| **`getline < "file"`** | Зовнішній файл | `$0`, поля `$1..$NF`, `NF` | **Не** змінюються | `1` — успіх; `0` — EOF; `-1` — файл не відкрито. |
| **`getline var < "file"`** | Зовнішній файл | Змінна `var` | **Не** змінюються | `1` — успіх; `0` — EOF; `-1` — файл не відкрито. |
| **`"cmd" \| getline`** | Вивід команди `cmd` | `$0`, поля `$1..$NF`, `NF` | **Не** змінюються | `1` — успіх; `0` — EOF; `-1` — збій конвеєра. |
| **`"cmd" \| getline var`** | Вивід команди `cmd` | Змінна `var` | **Не** змінюються | `1` — успіх; `0` — EOF; `-1` — збій конвеєра. |

> ⚠️ **Обов'язкове закриття дескрипторів через `close()`:** AWK кешує всі відкриті файли та конвеєри у внутрішній таблиці дескрипторів. Якщо прочитати файл або команду через `getline` до кінця (`EOF`), дескриптор залишається у стані завершення. Наступний виклик `getline < "file"` миттєво поверне `0`, не читаючи файл з початку. Щоб перечитати файл або скинути буфери конвеєра, необхідно явно викликати `close("file")` або `close("cmd")`.

## 5. Прапорці командного рядка (CLI)

Інтерпретатор AWK підтримує стандартні параметри виклику POSIX та специфічні опції продуктивності:

```bash
awk [options] 'program_text' [file ...]
awk [options] -f program_file [file ...]
```

- **`-F fsvalue`**: Встановлює початкове значення системного роздільника полів `FS`. Еквівалентно виконанню інструкції `BEGIN { FS = "fsvalue" }`. Може приймати одиночний символ, спеціальну послідовність (наприклад `-F'\t'`) або регулярний вираз.
- **`-v var=value`**: Присвоює змінній `var` значення `value` **до** запуску блоку `BEGIN`. Це єдиний спосіб передати конфігураційні параметри, які мають бути доступні безпосередньо під час ініціалізації середовища. Кожна змінна вимагає окремого прапорця `-v`.
- **`-f scriptfile`**: Зчитує вихідний код програми з файлу `scriptfile`. Дозволяється вказувати кілька прапорців `-f` для розділення коду на модулі та бібліотеки функцій.
- **`-e 'program_text'`** *(GNU AWK / POSIX.1-2008)*: Дозволяє комбінувати фрагменти коду з командного рядка разом із файлами, підключеними через `-f`.
- **`-W options` / `--posix`** *(GNU AWK)*: Вмикає суворий режим сумісності зі стандартом POSIX, вимикаючи непереносні розширення (мережеві сокети, нерегулярні масиви, функцію `gensub` тощо).
- **`-W version` / `-V`**: Виводить версію інтерпретатора (`gawk`, `mawk`, `bwk`) та інформацію про ліцензію.
