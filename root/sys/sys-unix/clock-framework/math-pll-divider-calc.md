# Math Pll Divider Calc

### Математика тактування: PLL та дільники

Частота на виході PLL розраховується за такою базовою формулою (апаратні реалізації можуть відрізнятися):

```
f_out = f_in × M / (N × P)
```

Де:
*   `f_in` — опорна частота на вході (зазвичай від зовнішнього кварцового резонатора, наприклад, 24 МГц).
*   `M` — множник (Multiplier).
*   `N` — вхідний дільник (Pre-divider).
*   `P` — вихідний дільник (Post-divider).

**Приклад:**
Маємо кварц `f_in` = 24 МГц. Нам потрібно отримати `f_out` = 1008 МГц для ядра CPU.
Ми можемо налаштувати:
*   `N` = 1 (без попереднього ділення)
*   `M` = 42
*   `P` = 1

Тоді:

```
f_out = 24 МГц × 42 / (1 × 1) = 1008 МГц
```

Далі, щоб отримати частоту для шини пам'яті (наприклад, 504 МГц), сигнал від цього PLL може пройти через окремий дільник (Divider Clock) з коефіцієнтом ділення `D` = 2:

```
f_bus = f_pll / D = 1008 МГц / 2 = 504 МГц
```

У драйверах постачальників (clock providers) ці формули реалізовані у функціях зворотного виклику (callbacks), таких як `.recalc_rate`, `.set_rate` та `.round_rate`, щоб переводити запити CCF у конкретні значення регістрів `M`, `N`, `P` та `D`.
