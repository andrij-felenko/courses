# Геометричне виведення кінематичних рівнянь велосипедної моделі

Кінематична велосипедна модель описує рух чотириколісного або двоколісного транспортного засобу на площині без урахування маси, інерційних моментів та бічних сил деформації шин. Рух визначається виключно геометрією колісної бази та кінематичними в'язями абсолютно твердого тіла: колеса котяться без бічного ковзання.

Нижче наведено строге аналітичне виведення рівнянь руху для трьох характерних точок шасі: центру задньої осі, центру мас ($CG$) та центру переднього керованого колеса, зв'язок між кутами реального кермового механізму Аккермана та еквівалентним кутом вивороту віртуального колеса, а також аналіз якобіанів кінематичної системи для лінеаризації.

## 1. Геометрія Аккермана та зведення до віртуального колеса

У реальному автомобільному шасі передні керовані колеса рознесені на ширину колії `W`. Під час повороту по дузі радіуса `R` відносно центру задньої осі внутрішнє колесо рухається по меншому радіусу `R - W/2`, а зовнішнє — по більшому радіусу `R + W/2`.

Колісна база (відстань між передньою та задньою осями) позначається через `L`. З прямокутних трикутників для внутрішнього кута `δ_i` та зовнішнього кута `δ_o` маємо:

```
cot(δ_i) = (R − W / 2) / L
cot(δ_o) = (R + W / 2) / L
```

Знайдемо середнє арифметичне котангенсів кутів вивороту обох керованих коліс:

```
(cot(δ_i) + cot(δ_o)) / 2
= ((R − W / 2) / L + (R + W / 2) / L) / 2       [підстановка виразів котангенсів]
= (2 · R / L) / 2                               [зведення подібних доданків: −W/2 + W/2 = 0]
= R / L                                         [скорочення двійки в чисельнику і знаменнику]
= cot(δ)                                        [означення еквівалентного кута віртуального колеса на осі симетрії]
```

Таким чином, котангенс віртуального кута повороту `δ` є точним середнім арифметичним котангенсів реальних кутів коліс:

```
cot(δ) = (cot(δ_i) + cot(δ_o)) / 2
```

При малих кутах вивороту (`tan(δ) ≈ δ`) або при відношенні ширини колії до радіуса повороту `W / R ≪ 1`, чотириколісне шасі точно зводиться до велосипедної моделі з колісною базою `L` та кутом вивороту переднього колеса `δ`.

## 2. Миттєвий центр обертання та радіуси поворотів

Нехай початок локальної системи координат закріплено на задній осі. Вектор швидкості заднього колеса `v_r` спрямований строго вздовж поздовжньої осі корпусу, оскільки задня вісь не повертається. Вектор швидкості переднього колеса `v_f` спрямований під кутом `δ` до поздовжньої осі.

За теоремою Ейлера-Шаля, плоский рух твердого тіла в кожен момент часу є миттєвим обертанням навколо миттєвого центру обертання (МЦО, англ. *ICR — Instantaneous Center of Rotation*). МЦО лежить на перетині перпендикулярів до векторів швидкостей усіх точок тіла:

1. Перпендикуляр до вектора швидкості заднього колеса `v_r` збігається з лінією задньої осі.
2. Перпендикуляр до вектора швидкості переднього колеса `v_f` нахилений під кутом `δ` до лінії передньої осі.

Перетин цих двох ліній утворює прямокутний трикутник з вершинами в МЦО, центрі задньої осі та центрі передньої осі. Катети цього трикутника: колісна база `L` та радіус повороту задньої осі `R_r`:

```
tan(δ) = L / R_r
R_r = L / tan(δ)
```

Радіус обертання передньої осі `R_f` є гіпотенузою цього прямокутного трикутника:

```
R_f
= √(R_r² + L²)                                  [теорема Піфагора для трикутника ICR-Зад-Перед]
= √((L / tan(δ))² + L²)                         [підстановка R_r = L / tan(δ)]
= √(L² · (1 / tan²(δ) + 1))                     [винесення L² за дужки]
= √(L² · (cos²(δ) / sin²(δ) + 1))               [означення tan(δ) = sin(δ)/cos(δ)]
= √(L² · (cos²(δ) + sin²(δ)) / sin²(δ))         [зведення до спільного знаменника]
= √(L² / sin²(δ))                               [основна тригонометрична тотожність: cos²(δ) + sin²(δ) = 1]
= L / sin(δ)                                    [добування квадратного кореня]
```

Координати точки МЦО в системі координат, прив'язаній до центру задньої осі (де вісь `X_b` спрямована вперед вздовж кузова, а `Y_b` — ліворуч перпендикулярно до кузова), виражаються вектором:

```
x_icr = 0
y_icr = L / tan(δ)
```

Коли колесо повернуто вліво (`δ > 0`), МЦО лежить на додатній півосі `Y_b` (`y_icr > 0`). При вивороті керма вправо (`δ < 0`) МЦО зміщується на від'ємну піввісь `Y_b`. Коли кермо стоїть рівно (`δ → 0`), значення `y_icr → ±∞`, що відповідає прямолінійному поступальному руху.

## 3. Кут зсуву швидкості (side-slip angle) у центрі мас

Нехай центр мас ($CG$) розташований на поздовжній осі на відстані `l_r` від задньої осі та на відстані `l_f` від передньої осі, де загальна колісна база:

```
L = l_f + l_r
```

Вектор швидкості центру мас `v` утворює кут `β` з поздовжньою віссю автомобіля. Цей кут називають **кутом зсуву вектора швидкості** (англ. *side-slip angle*).

Оскільки вектор швидкості `v` перпендикулярний до радіуса обертання центру мас `R_cg` (відрізка від МЦО до точки $CG$), у прямокутному трикутнику з вершинами в МЦО, центрі задньої осі та точці $CG$:
- горизонтальний катет дорівнює `R_r = L / tan(δ)`;
- вертикальний катет дорівнює `l_r`.

Кут між радіусом `R_cg` та лінією задньої осі дорівнює куту `β` між вектором швидкості та поздовжньою віссю корпусу (кути з взаємно перпендикулярними сторонами). Знаходимо тангенс кута `β`:

```
tan(β)
= l_r / R_r                                     [відношення протилежного катета l_r до прилеглого R_r]
= l_r / (L / tan(δ))                            [підстановка R_r = L / tan(δ)]
= (l_r / L) · tan(δ)                            [ділення на дріб: множення на обернену величину]
= (l_r / (l_f + l_r)) · tan(δ)                  [підстановка повної бази L = l_f + l_r]
```

Звідси кут зсуву швидкості виражається явно:

```
β = arctan((l_r / (l_f + l_r)) · tan(δ))
```

Радіус обертання центру мас `R_cg` знаходиться за теоремою Піфагора або через косинус кута `β`:

```
R_cg
= √(R_r² + l_r²)                                [теорема Піфагора]
= R_r / cos(β)                                  [з прямокутного трикутника: cos(β) = R_r / R_cg]
= (L / tan(δ)) / cos(β)                         [підстановка R_r = L / tan(δ)]
= L / (tan(δ) · cos(β))                         [перетворення дробу]
```

## 4. Кутова швидкість повороту (yaw rate)

Усі точки твердого тіла обертаються навколо МЦО з однаковою кутовою швидкістю `ω = θ̇`. Лінійна швидкість будь-якої точки пов'язана з кутовою швидкістю через радіус обертання:

```
v = ω · R
ω = v / R
```

Виразимо кутову швидкість `θ̇` через лінійну швидкість центру мас `v`:

```
θ̇
= v / R_cg                                      [кутова швидкість тіла через радіус центру мас]
= v / (L / (tan(δ) · cos(β)))                   [підстановка виразу для R_cg]
= (v / L) · tan(δ) · cos(β)                     [множення на обернений дріб]
```

Альтернативно, виразимо кутову швидкість через швидкість задньої осі `v_r = v · cos(β)`:

```
θ̇
= v_r / R_r                                     [кутова швидкість через радіус задньої осі]
= v_r / (L / tan(δ))                            [підстановка R_r = L / tan(δ)]
= (v_r / L) · tan(δ)                            [підстановка відношення]
```

Також можна виразити `θ̇` через `sin(β)`:

```
sin(β)
= l_r / R_cg                                    [з прямокутного трикутника ICR-Задня вісь-CoM]
= l_r · (θ̇ / v)                                 [підстановка R_cg = v / θ̇]
```

Звідси:

```
θ̇ = (v / l_r) · sin(β)
```

## 5. Повна система нелінійних диференціальних рівнянь

Нехай `(x, y)` — глобальні декартові координати точки на площині, `θ` — кут курсу (орієнтація поздовжньої осі корпусу відносно осі `X`), `v` — модуль лінійної швидкості обраної точки, а `δ` — кут вивороту керованого колеса.

### Формулювання відносно центру задньої осі

У точці задньої осі вектор швидкості спрямований строго вздовж курсу (`β = 0`), тому рівняння мають найпростіший вигляд:

```
ẋ_r = v_r · cos(θ)
ẏ_r = v_r · sin(θ)
θ̇   = (v_r / L) · tan(δ)
```

### Формулювання відносно центру мас (CoM)

Вектор швидкості центру мас повернутий відносно осі `X` на кут `θ + β`:

```
ẋ = v · cos(θ + β)
ẏ = v · sin(θ + β)
θ̇ = (v / L) · tan(δ) · cos(β)
```

де кут `β` розраховується на кожному кроці як:

```
β = arctan((l_r / (l_f + l_r)) · tan(δ))
```

### Формулювання відносно передньої керованої осі

У точці переднього колеса вектор швидкості спрямований під кутом `θ + δ`:

```
ẋ_f = v_f · cos(θ + δ)
ẏ_f = v_f · sin(θ + δ)
θ̇   = (v_f / L) · sin(δ)
```

де швидкість переднього колеса пов'язана зі швидкістю задньої осі співвідношенням `v_f = v_r / cos(δ)`.

## 6. Чутливість та лінеаризація моделі для алгоритмів керування

Для побудови лінійних квадратичних регуляторів (LQR) або розширених фільтрів Калмана (EKF) необхідно знайти матриці Якобі нелінійної системи відносно вектора стану `q = [x, y, θ]ᵀ` та вектора керування `u = [v, δ]ᵀ`.

Для формулювання відносно задньої осі вектор-функція швидкостей має вигляд:

```
f(q, u) = [v · cos(θ),  v · sin(θ),  (v / L) · tan(δ)]ᵀ
```

Обчислимо частинні похідні за станом (матриця Якобі `A = ∂f / ∂q`):

```
∂ẋ / ∂x = 0,  ∂ẋ / ∂y = 0,  ∂ẋ / ∂θ = −v · sin(θ)
∂ẏ / ∂x = 0,  ∂ẏ / ∂y = 0,  ∂ẏ / ∂θ =  v · cos(θ)
∂θ̇ / ∂x = 0,  ∂θ̇ / ∂y = 0,  ∂θ̇ / ∂θ = 0
```

Обчислимо частинні похідні за вектором керування (матриця Якобі `B = ∂f / ∂u`):

```
∂ẋ / ∂v = cos(θ),            ∂ẋ / ∂δ = 0
∂ẏ / ∂v = sin(θ),            ∂ẏ / ∂δ = 0
∂θ̇ / ∂v = (1 / L) · tan(δ),  ∂θ̇ / ∂δ = (v / L) · (1 / cos²(δ))
```

Ці аналітичні матриці дозволяють здійснювати миттєву лінеаризацію вздовж довільної опорної траєкторії без застосування чисельного диференціювання, що критично для швидкодії алгоритмів Model Predictive Control на мікроконтролерах.
