Безпілотний літальний апарат зависає над пошкодженим технологічним вузлом, щоб перекрити аварійний вентиль за допомогою встановленого знизу триланкового маніпулятора. Енкодери в суглобах руки вимірюють лише кути повороту валів сервоприводів у радіанах, тоді як ціль — важіль крана — задана камерою технічного зору як точка в тривимірному декартовому просторі `(x, y, z)` з вектором просторової орієнтації фланця. Якщо польотний контролер чи бортовий комп'ютер передасть на приводи некоректні кути, губки захвату або пройдуть повз вентиль, або вдарять по трубопроводу, створивши реактивний крутний момент, здатний перекинути дрон у повітрі.

Математичний міст між внутрішніми координатами суглобів маніпулятора та зовнішнім тривимірним світом будує **кінематика** (від грец. *kínēma* — «рух»). Вона розпадається на дві фундаментальні взаємно обернені задачі: пряму кінематику (визначення декартової пози робочого органа за відомими кутами суглобів) та обернену кінематику (обчислення необхідних кутів суглобів для досягнення бажаної декартової пози у просторі).

## Просторові трансформації та однорідні матриці групи SE(3)

Маніпулятор являє собою відкритий кінематичний ланцюг, що складається з жорстких ланок (англ. *links*), з'єднаних між собою рухомими зчленуваннями або суглобами (англ. *joints*). Кожен суглоб має рівно один ступінь вільності (англ. *Degree of Freedom*, DOF) — обертальний (англ. *revolute*, обертання навколо осі на кут `θ`) або поступальний (англ. *prismatic*, лінійне зміщення вздовж осі на відстань `d`).

Щоб визначити положення кожної ланки відносно базової системи координат робота `O_0`, з кожною `i`-ю ланкою жорстко пов'язують власну систему координат `O_i`. Стан твердого тіла у тривимірному просторі визначається шістьма параметрами: трьома координатами позиції `p = [p_x, p_y, p_z]ᵀ` та трьома кутами орієнтації (від лат. *oriens* — «схід», наведення на орієнтир), які задаються ортогональною матрицею повороту `R ∈ SO(3)` (спеціальна ортогональна група розмірності 3).

Для компактного математичного опису одночасного повороту та лінійного зсуву використовують **однорідні координати** (від грец. *homogenēs* — «однорідний») та групу спеціальних евклідових перетворень `SE(3)`:

```
        [ R₃ₓ₃ | p₃ₓ₁ ]   [ r₁₁  r₁₂  r₁₃  |  p_x ]
T₄ₓ₄ = [ ─────┼────── ] = [ r₂₁  r₂₂  r₂₃  |  p_y ]
        [ 0₁ₓ₃ |   1   ]   [ r₃₁  r₃₂  r₃₃  |  p_z ]
                           [  0    0    0   |   1  ]
```

Тут:
- Блок `R₃ₓ₃` задає напрямки осей `X_i, Y_i, Z_i` нової системи відносно попередньої (напрямні косинуси базисних векторів);
- Блок `p₃ₓ₁` задає вектор зміщення початку координат `O_i` у системі `O_(i-1)`;
- Нижній рядок `[0, 0, 0, 1]` забезпечує збереження масштабу та дає змогу об'єднувати послідовні перетворення звичайним множенням матриць 4×4.

Будь-яка точка `p^i = [x^i, y^i, z^i, 1]ᵀ`, задана в локальних координатах `i`-ї ланки, перераховується в базову систему координат `O_0` за допомогою матричного множення:

```
p^0 = T_0^i · p^i
```

Якщо відомі відносні матриці трансформації між усіма сусідніми ланками `T_0^1, T_1^2, ..., T_(n-1)^n`, то результуюча поза кінцевого робочого органа (англ. *end-effector*, захвату чи інструмента) у базовій системі координат обчислюється через ланцюговий добуток:

```
T_0^n(q) = T_0^1(q_1) · T_1^2(q_2) · ... · T_(n-1)^n(q_n)
```

Цей добуток і є аналітичним розв'язком **прямої кінематики** (англ. *Forward Kinematics*, FK). Для будь-якого фіксованого вектора кутів суглобів `q = [q_1, q_2, ..., q_n]ᵀ` він однозначно та детерміновано обчислює просторову позу робочого органа.

## Параметри Денавіта-Гартенберга (DH-угода)

При довільному виборі систем координат на ланках для опису взаємного розташування двох тіл у просторі потрібно шість незалежних параметрів (три координати зсуву та три кути повороту). Для кінематичного ланцюга з `n` одноосьовими суглобами це давало б `6n` змінних, що перевантажує опис надлишковими ступенями вільності.

У 1955 році Жак Денавіт (Jacques Denavit) та Річард Гартенберг (Richard Hartenberg) запропонували строгу геометричну домовленість, яка скорочує кількість параметрів між сусідніми ланками з шести до **чотирьох**.

![Чотири параметри Денавіта-Гартенберга](/root/sys/sys-dron/kinematyka-manipuliatora/img/dh-parameters-frame.svg)
*Геометричне перетворення Денавіта-Гартенберга між системами координат ланок i-1 та i. Параметри θ_i та d_i відраховуються вздовж і навколо осі Z_(i-1), а параметри a_i та α_i — вздовж і навколо спільного перпендикуляра X_i.*

Правила призначення осей за класичною угодою Денавіта-Гартенберга:
1. Вісь `Z_(i-1)` спрямовується строго вздовж осі руху `i`-го суглоба (вісь обертання для револьверного або вісь висування для призматичного);
2. Вісь `X_i` спрямовується вздовж **спільного перпендикуляра** (відрізка найкоротшої відстані) між осями `Z_(i-1)` та `Z_i`, від `Z_(i-1)` до `Z_i`. Якщо осі перетинаються, `X_i` обирається перпендикулярно до площини, що містить обидві осі (`X_i = ±(Z_(i-1) × Z_i)`);
3. Вісь `Y_i` доповнює систему координат до правої трійки: `Y_i = Z_i × X_i`.

Завдяки перпендикулярності `X_i` до осі `Z_(i-1)` перетворення між системами координат `(i-1)` та `i` повністю описується чотирма параметрами:

| Параметр | Назва | Геометричний зміст | Змінна величина |
|---|---|---|---|
| `θ_i` | Кут зчленування (*joint angle*) | Кут повороту від осі `X_(i-1)` до `X_i` навколо осі `Z_(i-1)` | Змінна для обертального суглоба (`θ_i = θ_{i,0} + q_i`) |
| `d_i` | Зміщення ланки (*link offset*) | Відстань від початку `O_(i-1)` до точки перетину осей `Z_(i-1)` та `X_i` вздовж осі `Z_(i-1)` | Змінна для поступального суглоба (`d_i = d_{i,0} + q_i`) |
| `a_i` | Довжина ланки (*link length*) | Довжина спільного перпендикуляра між `Z_(i-1)` та `Z_i` вздовж осі `X_i` | Константа геометрії |
| `α_i` | Кут скручування (*link twist*) | Кут повороту від осі `Z_(i-1)` до `Z_i` навколо осі `X_i` | Константа геометрії |

Повна однорідна матриця переходу `T_i^(i-1)` розкладається у послідовність чотирьох елементарних просторових операцій:

```
T_i^(i-1) = Rot(Z, θ_i) · Trans(Z, d_i) · Trans(X, a_i) · Rot(X, α_i)
```

Перемножуючи ці чотири елементарні матриці 4×4:

```
[ cos θ_i  −sin θ_i   0   0 ]   [ 1  0  0   0  ]   [ 1  0  0  a_i ]   [ 1    0          0       0 ]
[ sin θ_i   cos θ_i   0   0 ] · [ 0  1  0   0  ] · [ 0  1  0   0  ] · [ 0  cos α_i  −sin α_i   0 ]
[    0         0      1   0 ]   [ 0  0  1  d_i ]   [ 0  0  1   0  ]   [ 0  sin α_i   cos α_i   0 ]
[    0         0      0   1 ]   [ 0  0  0   1  ]   [ 0  0  0   1  ]   [ 0    0          0       1 ]
```

Отримуємо канонічну матрицю трансформації ланки Денавіта-Гартенберга:

```
           [ cos θ_i   −sin θ_i · cos α_i    sin θ_i · sin α_i   a_i · cos θ_i ]
T_i^(i-1) = [ sin θ_i    cos θ_i · cos α_i   −cos θ_i · sin α_i   a_i · sin θ_i ]
           [    0            sin α_i              cos α_i             d_i      ]
           [    0               0                    0                 1       ]
```

### Стандартні проти модифікованих параметрів DH (Craig Notation)

У робототехніці існують дві школи представлення DH-параметрів:
1. **Стандартна схема (Standard DH, 1955):** Система координат `O_i` жорстко прив'язана до вихідного кінця ланки `i`. Перетворення йде від `(i-1)` до `i` вздовж `Z_(i-1)`, а потім вздовж `X_i`. Обертання суглоба `q_i` відбувається навколо осі `Z_(i-1)`.
2. **Модифікована схема (Modified DH, Craig 1986):** Система координат `O_i` прив'язана до вхідного шарніра ланки `i`. Перетворення записується у послідовності `Rot(X, α_(i-1)) · Trans(X, a_(i-1)) · Rot(Z, θ_i) · Trans(Z, d_i)`. Тут змінна `q_i` діє навколо осі `Z_i`.

Модифікована нотація Крейга широко використовується в пакетах симуляції (наприклад, деревоподібні описи URDF/SDF у ROS), оскільки вона спрощує розрахунок деревоподібних кінематичних ланцюгів із розгалуженнями. Для послідовних маніпуляторів обидві схеми повністю взаємозамінні за умови дотримання єдиної угоди.

> 🔧 **Навіщо це.** Складання таблиці DH-параметрів дає змогу описати маніпулятор будь-якої складності компактним масивом чисел. Пряма кінематика на мікроконтролері зводиться до послідовного заповнення 16 елементів матриці за формулою вище та матричного множення у циклі без потреби щоразу вручну виводити тригонометрію для кожної точки простору.

## Обернена кінематика: аналітичний геометричний розв'язок

Задача **оберненої кінематики** (англ. *Inverse Kinematics*, IK) є фундаментально складнішою за пряму. За заданою декартовою цільовою позою `T_target ∈ SE(3)` необхідно знайти вектор кутів суглобів `q = [q_1, q_2, ..., q_n]ᵀ`, такий що:

```
T_0^n(q) = T_target
```

На відміну від прямої кінематики, яка завжди має єдиний розв'язок, обернена кінематика володіє специфічними властивостями:
1. **Нелінійність:** зв'язок між кутами та положенням містить добутки синусів і косинусів;
2. **Неєдиність розв'язків:** одній і тій самій декартовій точці можуть відповідати декілька різних конфігурацій руки (наприклад, «лікоть угору» та «лікоть униз»);
3. **Відсутність розв'язку:** якщо цільова точка лежить за межами досяжності маніпулятора (англ. *workspace*);
4. **Нескінченна кількість розв'язків:** у надлишкових маніпуляторах (кількість суглобів `n > 6` для 3D простору) або в точках кінематичної сингулярності.

Для маніпуляторів з малою кількістю ланок (2-DOF або 3-DOF), що часто встановлюються на легкі розвідувальні БПЛА та колісні ровери, найшвидшим і найнадійнішим є **геометричний розв'язок**.

![Геометрична обернена кінематика](/root/sys/sys-dron/kinematyka-manipuliatora/img/geometric-ik-2dof-3dof.svg)
*Геометричне розщеплення задачі оберненої кінематики для просторового 3-DOF маніпулятора. Ліворуч: визначення азимутального кута основи θ_1 у площині X_0-Y_0. Праворуч: плоска задача 2-DOF для кутів плеча й ліктя θ_2 та θ_3 у площині r-Z із двома гілками розв'язку (лікоть угору / лікоть униз).*

Розглянемо просторовий 3-DOF маніпулятор:
- 1-й суглоб: вертикальна вісь обертання основи навколо `Z_0` (азимут);
- 2-й суглоб: плече довжиною `L_1`, вісь обертання горизонтальна;
- 3-й суглоб: лікоть із ланкою довжиною `L_2`, вісь обертання паралельна 2-й.

Нехай цільова точка задана декартовими координатами `P(x, y, z)`.

### Крок 1. Азимут основи θ_1

Оскільки суглоби плеча й ліктя рухаються виключно в площині, що обертається разом з основою, кут основи `θ_1` визначається проекцією точки `P` на горизонтальну площину `X_0−Y_0`:

```
θ_1 = atan2(y, x)
```

Функція `atan2(y, x)` (арктангенс двох аргументів) є критично важливою, оскільки вона враховує знаки обох координат і повертає кут у повному діапазоні `[-π, π]`, усуваючи неоднозначність квадрантів, притаманну звичайному `atan(y/x)`.

Радіальна відстань від осі обертання основи до цілі:

```
r = √(x² + y²)
```

### Крок 2. Зведення до плоскої задачі 2-DOF

Просторова задача звелася до знаходження конфігурації двох ланок `L_1` та `L_2` у вертикальній площині з координатами `(r, z)`.

Пряма відстань від шарніра плеча до цілі `s`:

```
s² = r² + z²
```

Застосовуємо теорему косинусів до трикутника, утвореного ланками `L_1, L_2` та відрізком `s`:

```
s² = L_1² + L_2² − 2 · L_1 · L_2 · cos(π − θ_3)   [теорема косинусів для трикутника плече-лікоть]
= L_1² + L_2² + 2 · L_1 · L_2 · cos(θ_3)          [спрощення: cos(π − θ_3) = −cos(θ_3)]
```

Звідси косинус кута ліктя `θ_3`:

```
cos(θ_3) = (r² + z² − L_1² − L_2²) / (2 · L_1 · L_2)
```

Якщо `|cos(θ_3)| > 1`, цільова точка недосяжна (лежить далі, ніж максимальний виліт `L_1 + L_2`, або ближче, ніж мінімальний вигин `|L_1 − L_2|`).

Якщо значення в межах `[-1, 1]`, кут `θ_3` має два симетричних розв'язки:

```
θ_3 = ± atan2(√(1 − cos²(θ_3)), cos(θ_3))
```

Знак `+` відповідає конфігурації **«лікоть униз»** (англ. *elbow down*), а знак `−` — конфігурації **«лікоть угору»** (англ. *elbow up*).

### Крок 3. Кут плеча θ_2

Кут підйому плеча `θ_2` обчислюється як різниця між кутом нахилу цільового вектора `s` та внутрішнім кутом трикутника плеча:

```
β = atan2(z, r)
γ = atan2(L_2 · sin(θ_3), L_1 + L_2 · cos(θ_3))
θ_2 = β − γ
```

Для повнорозмірних 6-осьових маніпуляторів аналітичний розв'язок у замкненій формі можливий лише за виконання **критерію П'єпера** (перетин осей трьох останніх зчленувань у центрі сферичного зап'ястя). Повне математичне виведення декупінгу орієнтації для 6-DOF ланцюга наведено у вставці [виведення розв'язку П'єпера](root:sys-dron/kinematyka-manipuliatora/math-pieper-solution.md).

## Матриця Якобі та диференціальна кінематика

Пряма та обернена кінематика положення пов'язують статичні координати `q` та `p`. Проте під час руху маніпулятора бортовий комп'ютер мусить керувати не лише статичними точками, а й **швидкостями** робочого органа: лінійною швидкістю `v = [v_x, v_y, v_z]ᵀ` та кутовою швидкістю `ω = [ω_x, ω_y, ω_z]ᵀ`.

Швидкість кінцевого органа у просторі утворює 6-вимірний вектор просторової швидкості (твіст, англ. *spatial velocity vector* або *twist*):

```
v_ee = [ v ] = [ ẋ, ẏ, ż, ω_x, ω_y, ω_z ]ᵀ ∈ ℝ⁶
       [ ω ]
```

Диференціюючи рівняння прямої кінематики за часом за правилом диференціювання складеної функції:

```
ẋ_i = ∑_{j=1}^n (∂f_i / ∂q_j) · q̇_j
```

Отримуємо фундаментальне матричне співвідношення **диференціальної кінематики**:

```
v_ee = J(q) · q̇
```

Тут `q̇ = [q̇_1, q̇_2, ..., q̇_n]ᵀ ∈ ℝⁿ` — вектор кутових швидкостей суглобів, а `J(q) ∈ ℝ⁶ˣⁿ` — **геометрична матриця Якобі маніпулятора** (на честь німецького математика Карла Густава Якоба Якобі, Carl Gustav Jacob Jacobi).

Матриця Якобі складається з `n` стовпців, де кожен `i`-й стовпець `J_i` показує просторовий внесок швидкості `i`-го суглоба в сумарний рух кінцевого органа:

```
J(q) = [ J_1  J_2  ...  J_n ] = [ J_v_1   J_v_2   ...   J_v_n ]
                                [ J_ω_1   J_ω_2   ...   J_ω_n ]
```

Для кожного суглоба стовпець обчислюється через пряму кінематику проміжних ланок:
- Якщо `i`-й суглоб **обертальний** (revolute):
  Лінійна швидкість кінця руки створюється обертанням радіус-вектора `(p_ee − p_(i-1))` навколо осі `z_(i-1)`:
  ```
  J_v_i = z_(i-1) × (p_ee − p_(i-1))
  J_ω_i = z_(i-1)
  ```
- Якщо `i`-й суглоб **поступальний** (prismatic):
  Суглоб створює виключно лінійне переміщення вздовж своєї осі без кутового обертання:
  ```
  J_v_i = z_(i-1)
  J_ω_i = [0, 0, 0]ᵀ
  ```

Тут `z_(i-1)` — одиничний вектор осі `Z` системи координат `(i-1)` у світовому базисі (третій стовпець матриці `R_0^(i-1)`), `p_(i-1)` — положення початку `(i-1)`-ї системи, а `p_ee` — поточне положення кінцевого органа.

### Геометричний проти Аналітичного Якобіана

Слід чітко розрізняти дві форми матриці Якобі:
1. **Геометричний Якобіан `J_G`:** пов'язує похідні суглобів `q̇` з фізичною кутовою швидкістю `ω ∈ ℝ³` твердого тіла. Він залежить виключно від геометрії маніпулятора і не має координатних артефактів;
2. **Аналітичний Якобіан `J_A`:** пов'язує `q̇` з похідними конкретної параметризації орієнтації (наприклад, кутів Ейлера `ṙ = [ẋ, ẏ, ż, φ̇, θ̇, ψ̇]ᵀ`).

Зв'язок між фізичною кутовою швидкістю `ω` та похідними кутів Ейлера `[φ̇, θ̇, ψ̇]ᵀ` задається матрицею перетворення `E(φ, θ)`:

```
ω = E(φ, θ) · [ φ̇, θ̇, ψ̇ ]ᵀ
```

Звідси зв'язок між Якобіанами:

```
J_G = [ I₃   0  ] · J_A
      [ 0   E(φ,θ) ]
```

Аналітичний Якобіан `J_A = diag(I₃, E⁻¹) · J_G` стає виродженим не лише у фізичних сингулярностях руки, а й у точках так званого шарнірного замка (англ. *Gimbal Lock*, наприклад при `θ = π/2`), коли матриця `E` втрачає ранг. З цієї причини в бортових системах керування БПЛА застосовують виключно **геометричний Якобіан**, а орієнтаційну похибку розраховують через кватерніони або вектор осі повороту.

![Відображення швидкостей через Якобіан та еліпсоїд маніпулятивності](/root/sys/sys-dron/kinematyka-manipuliatora/img/jacobian-mapping-velocities.svg)
*Диференціальне відображення швидкостей за допомогою матриці Якобі J(q). Одинична сфера кутових швидкостей суглобів відображається в еліпсоїд швидкостей робочого органа в декартовому просторі. У регулярній позі еліпсоїд об'ємний (рух можливий у всіх напрямках), у точці сингулярності — сплющується в площину (втрата ступеня вільності).*

### Еліпсоїд маніпулятивності Йошикави

Якщо обмежити кутові швидкості приводів одиничною сферою `||q̇||² = q̇ᵀ q̇ ≤ 1`, то в декартовому просторі можливі швидкості робочого органа утворюють гіпереліпсоїд:

```
v_eeᵀ · (J · Jᵀ)⁻¹ · v_ee ≤ 1
```

Півосі цього еліпсоїда збігаються з напрямками лівих сингулярних векторів `u_i` матриці Якобі, а їхні довжини дорівнюють сингулярним числам `σ_i` (`J = U Σ Vᵀ`).

Цунео Йошикава (Tsuneo Yoshikawa) у 1985 році запропонував кількісний скалярний критерій якості кінематичної конфігурації — **індекс маніпулятивності** (англ. *manipulability measure*):

```
w(q) = √(det(J(q) · J(q)ᵀ)) = σ_1 · σ_2 · ... · σ_m
```

Індекс `w(q)` пропорційний об'єму еліпсоїда швидкостей. Коли рука повністю випрямлена або складена, об'єм еліпсоїда прямує до нуля (`w(q) → 0`), що сигналізує про наближення до небезпечної зони.

## Сингулярності та затухаючий метод найменших квадратів (DLS)

Конфігурація маніпулятора `q`, у якій матриця Якобі втрачає повний ранг (`rank(J) < min(6, n)` або `det(J · Jᵀ) = 0`), називається **кінематичною сингулярністю** (від лат. *singularis* — «одиничний, винятковий»).

У точці сингулярності:
1. Робочий орган фізично втрачає можливість рухатися в одному або кількох просторових напрямках (відповідна піввісь еліпсоїда стискається в нуль: `σ_min = 0`);
2. Безпосереднє обернення матриці Якобі `q̇ = J⁻¹ · v_ee` стає неможливим через ділення на нуль;
3. При наближенні до сингулярності намагання рухатися у виродженому напрямку з кінцевою швидкістю `v_ee` вимагає від приводів **нескінченно великих кутових швидкостей** (`||q̇|| → ∞`).

Для квадратних матриць `6×6` пряме обернення `J⁻¹` застосовне лише далеко від сингулярностей. Для загального випадку (зокрема надлишкових маніпуляторів з `n > 6`) класичним розв'язком є **псевдообернення Мура-Пенроуза** (англ. *Moore-Penrose pseudoinverse*):

```
J⁺ = Jᵀ · (J · Jᵀ)⁻¹
```

Псевдоінверсія знаходить вектор кутових швидкостей `q̇ = J⁺ · v_ee`, який мінімізує норму енергії приводів `min ||q̇||²`. Проте вона не вирішує проблему сингулярності: при `σ_min → 0` норма матриці `||J⁺|| = 1 / σ_min` прямує до нескінченності.

![Поведінка швидкостей біля сингулярності: Мура-Пенроуз проти DLS](/root/sys/sys-dron/kinematyka-manipuliatora/img/dls-singularity-damping.svg)
*Порівняння швидкостей сервоприводів біля кінематичної сингулярності. Стандартна псевдоінверсія Мура-Пенроуза призводить до вибухового зростання швидкості q̇ → ∞ та аварійного зриву сервоприводів. Затухаючий метод DLS обмежує швидкість ланок ціною незначної тимчасової декартової похибки позиції.*

### Затухаючий метод найменших квадратів (DLS / Levenberg-Marquardt)

Щоб усунути катастрофічні стрибки швидкості біля сингулярностей, застосовують **затухаючий метод найменших квадратів** (англ. *Damped Least Squares*, DLS, також відомий у чисельній оптимізації як метод Левенберга-Марквардта).

Замість чистої мінімізації помилки швидкості DLS розв'язує задачу компромісної оптимізації з регуляризацією Тихонова:

```
min_q̇ ( ‖J(q) · q̇ − v_cmd‖² + λ² · ‖q̇‖² )
```

Тут `λ > 0` — **коефіцієнт демпфування** (від нім. *dämpfen* — «глушити, гасити»). Перший доданок вимагає точного відстеження траєкторії, а другий — штрафує за надмірну швидкість моторів.

Взяття похідної за `q̇` та прирівнювання її до нуля дає аналітичний вираз регуляризованого псевдообернення:

```
J_DLS⁺ = Jᵀ · (J · Jᵀ + λ² · I)⁻¹
```

Де `I` — одинична матриця розмірності `m×m` (зазвичай 6×6 або 3×3). Оскільки матриця `(J · Jᵀ + λ² · I)` має власні значення `(σ_i² + λ²) > 0`, вона є **строго додатно визначеною та завжди невиродженою**, що гарантує існування оберненої матриці за будь-якої конфігурації маніпулятора.

Сингулярний розклад (SVD) показує дію DLS на кожну моду руху:

```
q̇ = ∑_{i=1}^m ( σ_i / (σ_i² + λ²) ) · (u_iᵀ · v_cmd) · v_i
```

- Коли `σ_i ≫ λ` (далеко від сингулярності): множник `σ_i / (σ_i² + λ²) ≈ 1 / σ_i`, тобто алгоритм працює як точна псевдоінверсія Мура-Пенроуза;
- Коли `σ_i → 0` (вхід у сингулярність): множник `σ_i / (σ_i² + λ²) → 0`, тобто алгоритм плавно «вимикає» рух у заблокованому напрямку, не допускаючи зростання швидкості вище безпечної межі `1 / (2λ)`.

### Адаптивне демпфування

Постійне значення `λ` вносить паразитну похибку відстеження навіть у безпечних зонах. Тому на практиці застосовують **адаптивний коефіцієнт демпфування Накамури-Ханкафі** (Nakamura & Hanafusa):

```
λ² = 0,                                     якщо w(q) ≥ w_threshold
λ² = λ_max² · (1 − (w(q) / w_threshold))², якщо w(q) < w_threshold
```

Поки індекс маніпулятивності `w(q)` вищий за поріг `w_threshold`, демпфування вимкнене (`λ = 0`, нульова похибка відстеження). Як тільки маніпулятор заходить у небезпечну зону, `λ` плавно зростає до `λ_max`, зберігаючи керованість апарата.

## Чисельні алгоритми оберненої кінематики (Numerical IK)

Для кінематичних ланцюгів довільної структури (наприклад, 7-DOF маніпулятора з надлишковим зчленуванням для обходу перешкод або робота без сферичного зап'ястя) аналітичний розв'язок не існує. У таких системах обернену кінематику розв'язують чисельно в циклі реального часу через ітеративне оновлення за методом Ньютона-Рафсона з використанням DLS.

### Вектор просторової похибки

На кожній ітерації `k` обчислюється поточна поза `T(q_k)` через пряму кінематику та знаходиться вектор похибки `e(q_k) ∈ ℝ⁶`:

1. **Позиційна похибка:**
   ```
   e_pos = p_target − p(q_k)
   ```
2. **Орієнтаційна похибка:**
   Задається вектором осі-кута (або векторною частиною кватерніона помилки `Δq = q_target ⊗ q(q_k)⁻¹`):
   ```
   R_err = R_target · R(q_k)ᵀ
   e_rot = 0.5 · [ R_err(3,2) − R_err(2,3),  R_err(1,3) − R_err(3,1),  R_err(2,1) − R_err(1,2) ]ᵀ
   ```

Повний вектор похибки: `e = [ e_pos; e_rot ]`.

### Ітераційний крок Ньютона-DLS

```
q_(k+1) = q_k + α · J_DLS⁺(q_k) · e(q_k)
```

Тут `α ∈ (0, 1]` — крок інтегрування (learning rate), що запобігає перерегулюванню.

### Оптимізація в нуль-просторі для надлишкових маніпуляторів

Для систем із кількістю суглобів `n > 6` існує нескінченна кількість конфігурацій `q`, що реалізують ту саму цільову позу `T_target`. Матриця проєкції в нуль-простір (англ. *null-space projector*) `P_null = (I − J⁺ · J)` дає змогу виконувати додаткові завдання без порушення руху робочого органа:

```
q̇ = J⁺ · v_cmd + (I − J⁺ · J) · k_0 · ∇H(q)
```

Тут `H(q)` — скалярна функція додаткового критерію якості, а `k_0 > 0` — коефіцієнт підсилення вторинного завдання. Типові інженерні критерії:
1. **Уникнення апаратних упорів суглобів:**
   ```
   H_limits(q) = − 1 / (2n) · ∑_{i=1}^n ((q_i − q_{mid,i}) / (q_{max,i} − q_{min,i}))²
   ```
   Градієнт `∇H_limits` штовхає суглоби до центру їхнього безпечного робочого діапазону.
2. **Максимізація віддалення від сингулярностей:**
   ```
   H_manip(q) = w(q) = √(det(J · Jᵀ))
   ```
   Градієнт спрямовує ланки в конфігурацію з максимальним об'ємом еліпсоїда швидкостей.

Повна автономна реалізація прямої кінематики, обчислення Якобіана та чисельного розв'язувача DLS на мовах C та C++ без динамічного виділення пам'яті представлена у проєктній вставці [бібліотека кінематики маніпулятора](root:sys-dron/kinematyka-manipuliatora/proj-manipulator-kinematics.md).

## Динамічна взаємодія маніпулятора з літальним апаратом

Встановлення рухомого маніпулятора на дрон створює явище **динамічного зв'язку** (англ. *dynamic coupling*), де рух руки безпосередньо збурює політ носія:

1. **Зсув центру мас (Center of Mass, CoM):**
   При висуванні руки вперед центр мас усієї системи зміщується:
   ```
   p_CoM = (m_drone · p_drone + ∑_{i=1}^n m_i · p_i(q)) / (m_drone + ∑_{i=1}^n m_i)
   ```
   Зсув `p_CoM` відносно точки прикладання сумарної тяги пропелерів створює постійний гравітаційний перекидний момент `τ_gravity = (p_CoM − p_thrust) × (M_total · g)`, який змушує автопілот постійно перекошувати тягу моторів для збереження горизонту.
2. **Реактивні сили та моменти:**
   Під час швидкого розгону або гальмування ланок рука створює на рамі дрона динамічний реактивний момент:
   ```
   τ_reaction = − ∑_{i=1}^n ( I_i · ω̇_i + ω_i × (I_i · ω_i) + m_i · r_i × a_i )
   ```
   Якщо маніпулятор робить різкий мах, реактивний момент може перевищити максимальний керівний момент гвинтів, що призведе до зриву стабілізації та падіння апарата.

### Компенсація в польотному стеку (PX4 / ArduPilot)

Сучасні авіонічні системи використовують прямий зв'язок (англ. *feedforward compensation*): бортовий комп'ютер маніпулятора в реальному часі транслює розраховані значення реактивного моменту `τ_reaction` та зсуву `p_CoM` у польотний контролер через шину CAN або протокол MAVLink. Польотний контролер додає компенсаційний момент безпосередньо до виходів мікшера моторів, усуваючи крен і тангаж ще до того, як гіроскопи зафіксують відхилення корпусу.

## Інженерний компроміс: аналітичний проти чисельного розв'язувача

У бортових системах вибір методу кінематики диктується жорсткими обмеженнями процесорного часу та механічної компоновки:

| Критерій | Аналітичний розв'язок (Geometric / Pieper) | Чисельний розв'язок (DLS / Newton-Raphson) |
|---|---|---|
| **Час обчислення** | Детермінований (0.5–2 мкс на ARM Cortex-M7) | Змінний (20–200 мкс залежно від кількості ітерацій) |
| **Гарантія збіжності** | 100% (миттєвий точний результат) | Можливе застрягання в локальних мінімумах |
| **Вимоги до геометрії** | Суворе дотримання критерію П'єпера або плоска схема | Працює з довільною конфігурацією ланок |
| **Керування надлишковістю** | Не підтримує `n > 6` без евристик | Природна оптимізація через нуль-простір |
| **Поведінка біля сингулярностей** | Вимагає окремої логіки для вироджених випадків | Плавне демпфування через коефіцієнт `λ` |

На мобільних платформах та БПЛА пріоритет віддають маніпуляторам із геометрією П'єпера, оскільки аналітичний розрахунок гарантує миттєве оновлення керуючого сигналу з частотою 1 кГц без ризику пропуску кроку керування. Для нестандартних захватів та багатоланкових систем числові методи DLS залишаються універсальним стандартом індустрії.
