# 🧮 Аналітичний розв'язок П'єпера для 6-осьового маніпулятора

Аналітичний метод розв'язання оберненої кінематики дає точний результат за фіксований час без ітерацій і ризику розбіжності чисельного пошуку. Для загального просторового 6-ланкового маніпулятора система з шести нелінійних тригонометричних рівнянь у просторі `SE(3)` не має замкненого аналітичного розв'язку. Проте Дональд П'єпер (англ. *Donald L. Pieper*) у 1968 році сформулював і довів фундаментальний критерій: якщо осі трьох сусідніх обертальних зчленувань маніпулятора перетинаються в одній спільній точці, повна просторова задача оберненої кінематики розпадається на два незалежних послідовних підзавдання меншої розмірності.

Найпоширенішим втіленням критерію П'єпера в робототехніці є **сферичне зап'ястя** (англ. *spherical wrist*), де осі 4-го, 5-го та 6-го суглобів перетинаються в єдиній точці — центрі зап'ястя `p_w` (англ. *wrist center*). Це дає змогу відокремити задачу просторового позиціонування перших трьох ланок від задачі просторової орієнтації кінцевого фланця.

## Геометричне розщеплення: виділення центру зап'ястя

Нехай цільова поза робочого органа (захвату або інструмента) задана однорідною матрицею трансформації `T_target ∈ SE(3)`:

```
           [ r₁₁  r₁₂  r₁₃  |  p_x ]   [ R_target | p_target ]
T_target = [ r₂₁  r₂₂  r₂₃  |  p_y ] = [ ─────────┼────────── ]
           [ r₃₁  r₃₂  r₃₃  |  p_z ]   [ 0  0  0  |    1     ]
           [  0    0    0   |   1  ]
```

Тут `R_target = [n, s, a]` — ортогональна матриця орієнтації 3×3, де вектор `a = [r₁₃, r₂₃, r₃₃]ᵀ` задає напрямок осі `Z_6` кінцевого фланця (вектор підходу, англ. *approach vector*), а `p_target = [p_x, p_y, p_z]ᵀ` — декартові координати робочої точки інструмента.

Оскільки остання вісь `Z_6` виходить безпосередньо з центру зап'ястя `p_w` на фіксовану відстань `d_6` (виліт інструмента), просторове положення центру зап'ястя у світовій системі координат `O_0` не залежить від кутів орієнтації зап'ястя `θ_4, θ_5, θ_6` і визначається геометрією:

```
p_w = p_target − d_6 · a
```

Розкриваючи це співвідношення покомпонентно для кожної координатної осі:

```
p_wx = p_x − d_6 · r₁₃      [зсув уздовж осі X_0]
p_wy = p_y − d_6 · r₂₃      [зсув уздовж осі Y_0]
p_wz = p_z − d_6 · r₃₃      [зсув уздовж осі Z_0]
```

Значення `p_w` залежить виключно від геометрії перших трьох ланок маніпулятора `θ_1, θ_2, θ_3`. Задача розмірності 6 зводиться до розв'язання положення точки в просторі для 3 ступенів вільності, після чого кути зап'ястя знаходяться з різниці матриць орієнтації.

## Знаходження перших трьох кутів (позиціонування)

Для типового антропоморфного маніпулятора з вертикальною віссю обертання основи `Z_0` та паралельними плечовими осями `Z_1 ∥ Z_2` (наприклад, маніпулятор розвідника або інспекційного дрона):

### 1. Кут обертання основи θ_1

Позиція центру зап'ястя в горизонтальній площині `X_0−Y_0` однозначно задає азимутальний кут основи:

```
θ_1 = atan2(p_wy, p_wx)
```

Для маніпуляторів із ненульовим плечовим бічним зміщенням `d_2` (англ. *shoulder offset*), коли ланка зміщена перпендикулярно площині обертання, рівняння набуває форми:

```
r_xy = √(p_wx² + p_wy²)                               [радіальна відстань у площині XY]
θ_1 = atan2(p_wy, p_wx) − atan2(d_2, ±√(r_xy² − d_2²)) [урахування плечового зсуву d_2]
```

Знаки перед коренем відповідають двом конфігураціям: «плече ліворуч» та «плече праворуч».

### 2. Кути плеча й ліктя θ_2 та θ_3

Після обертання системи координат на кут `θ_1` центр зап'ястя проектується у вертикальну площину руки `r_planar−Z`:

```
r_planar = cos(θ_1) · p_wx + sin(θ_1) · p_wy          [поздовжня координата в площині руки]
z_planar = p_wz − d_1                                  [висота відносно центру плеча]
```

Пряма відстань від шарніра плеча до центру зап'ястя `s`:

```
s² = r_planar² + z_planar²                             [квадрат відстані до центру зап'ястя]
```

Трикутник, утворений плечем довжиною `a_2`, передпліччям довжиною `a_3` (або `√(a_3² + d_4²)`) та відрізком `s`, розв'язується через теорему косинусів.

Виведення кута ліктя `θ_3`:

```
s² = a_2² + a_3² − 2 · a_2 · a_3 · cos(π − θ_3)        [теорема косинусів для трикутника руки]
= a_2² + a_3² + 2 · a_2 · a_3 · cos(θ_3)               [тригонометрична тотожність: cos(π − x) = −cos(x)]
```

Звідси косинус кута `θ_3`:

```
cos(θ_3) = (s² − a_2² − a_3²) / (2 · a_2 · a_3)        [вираження невідомого косинуса]
```

Якщо `|cos(θ_3)| > 1`, цільова точка лежить поза межами досяжності маніпулятора (рука не дістає фізично або складена занадто близько до основи). Для значень у межах `[-1, 1]` кут `θ_3` має два аналітичних розв'язки («лікоть угору» та «лікоть униз»):

```
sin(θ_3) = ± √(1 − cos²(θ_3))                          [основна тригонометрична тотожність]
θ_3 = atan2(sin(θ_3), cos(θ_3))                        [точне обчислення кута через atan2]
```

Після знаходження `θ_3` кут плеча `θ_2` обчислюється через різницю кута нахилу прямої `s` та внутрішнього кута трикутника:

```
β = atan2(z_planar, r_planar)                          [кут нахилу цільового відрізка s]
γ = atan2(a_3 · sin(θ_3), a_2 + a_3 · cos(θ_3))        [внутрішній кут плечового шарніра]
θ_2 = β − γ                                            [підсумковий кут підйому плеча]
```

## Знаходження кутів орієнтації сферичного зап'ястя

Після того як перші три кути `q_pos = [θ_1, θ_2, θ_3]ᵀ` знайдені, орієнтація системи координат 3-ї ланки `R_0^3(θ_1, θ_2, θ_3)` стає повністю відомою через добуток матриць прямої кінематики:

```
R_0^3 = R_0^1(θ_1) · R_1^2(θ_2) · R_2^3(θ_3)
```

Загальна орієнтація кінцевого органа є добутком орієнтації позиціонуючої руки та орієнтації зап'ястя:

```
R_target = R_0^3 · R_3^6(θ_4, θ_5, θ_6)                [композиція орієнтацій руки та зап'ястя]
```

Оскільки матриці поворотів ортогональні (`R⁻¹ = Rᵀ`), множимо обидві частини рівності зліва на `(R_0^3)ᵀ`:

```
R_3^6 = (R_0^3)ᵀ · R_target                            [відокремлення відносної орієнтації зап'ястя]
```

Матриця `R_3^6` є відомою числовою матрицею 3×3:

```
        [ m₁₁  m₁₂  m₁₃ ]
R_3^6 = [ m₂₁  m₂₂  m₂₃ ]
        [ m₃₁  m₃₂  m₃₃ ]
```

З іншого боку, для стандартного сферичного зап'ястя зі структурою поворотів `Z−Y−Z` (або `X−Y−X` залежно від призначення DH-осей), матриця `R_3^6` аналітично виражається через кути Ейлера `θ_4, θ_5, θ_6`:

```
R_3^6 = Rot(Z, θ_4) · Rot(Y, θ_5) · Rot(Z, θ_6)
```

Розкриваючи матричний добуток:

```
        [ cos θ_4 cos θ_5 cos θ_6 − sin θ_4 sin θ_6   −cos θ_4 cos θ_5 sin θ_6 − sin θ_4 cos θ_6   cos θ_4 sin θ_5 ]
R_3^6 = [ sin θ_4 cos θ_5 cos θ_6 + cos θ_4 sin θ_6   −sin θ_4 cos θ_5 sin θ_6 + cos θ_4 cos θ_6   sin θ_4 sin θ_5 ]
        [ −sin θ_5 cos θ_6                             sin θ_5 sin θ_6                              cos θ_5         ]
```

### Виведення кутів зап'ястя θ_4, θ_5, θ_6

Порівнюючи елементи матриць:

1. **Кут згину зап'ястя θ_5:**
З елемента `m₃₃ = cos(θ_5)` та елементів `m₁₃, m₂₃`:

```
cos(θ_5) = m₃₃                                         [елемент третього рядка й стовпця]
sin(θ_5) = ± √(m₁₃² + m₂₃²)                            [норма проекції на площину XY]
θ_5 = atan2(sin(θ_5), cos(θ_5))                        [два розв'язки: прямий і вивернутий]
```

2. **Кут скручування передпліччя θ_4 (при sin(θ_5) ≠ 0):**

```
cos(θ_4) = m₁₃ / sin(θ_5)                              [з першого рядка третього стовпця]
sin(θ_4) = m₂₃ / sin(θ_5)                              [з другого рядка третього стовпця]
θ_4 = atan2(m₂₃, m₁₃)                                  [за умови додатного sin(θ_5)]
```

3. **Кут обертання інструмента θ_6 (при sin(θ_5) ≠ 0):**

```
cos(θ_6) = −m₃₁ / sin(θ_5)                             [з третього рядка першого стовпця]
sin(θ_6) = m₃₂ / sin(θ_5)                              [з третього рядка другого стовпця]
θ_6 = atan2(m₃₂, −m₃₁)                                 [за умови додатного sin(θ_5)]
```

### Сингулярність зап'ястя (Wrist Singularity)

Коли `sin(θ_5) = 0` (тобто `θ_5 = 0` або `θ_5 = π`), осі `Z_4` та `Z_6` стають колінеарними (спрямованими вздовж однієї прямої). Маніпулятор втрачає один ступінь вільності в орієнтації, а кути `θ_4` та `θ_6` перестають бути незалежними:

```
R_3^6 = Rot(Z, θ_4 ± θ_6)                              [злиття двох обертань навколо однієї осі Z]
```

У цій точці фізично має значення лише сума або різниця кутів `θ_4 ± θ_6 = atan2(m₂₁, m₁₁)`. На практиці алгоритм фіксує поточне або нульове значення для `θ_4` (`θ_4 = 0`), а всю решту обертання передає на суглоб інструмента `θ_6 = atan2(m₂₁, m₁₁)`.

## Підсумок простору розв'язків

Завдяки критерію П'єпера 6-осьовий маніпулятор зі сферичним зап'ястям має до **8 аналітичних розв'язків** для кожної досяжної декартової пози:

1. Дві конфігурації основи (`θ_1` вперед / назад із розворотом плеча);
2. Дві конфігурації ліктя (`θ_3` лікоть угору / униз);
3. Дві конфігурації зап'ястя (`θ_5 > 0` пряме / `θ_5 < 0` вивернуте).

Вибір конкретного розв'язку з восьми можливих здійснюється контролером траєкторії на основі мінімізації кутового переміщення від поточного стану приводів `min ||q - q_current||` та перевірки апаратних обмежень діапазону руху кожного шарніра.
