# 🧮 Математичне виведення суми Мінковського та властивостей C-перешкод

Сума Мінковського є базовою алгебро-геометричною операцією над множинами у векторному просторі, яка перетворює задачу планування траєкторії просторового тіла довільної форми на задачу пошуку шляху для матеріальної точки. У цьому математичному розборі виведено фундаментальну теорему еквівалентності колізій, доведено властивості опуклості результуючого многокутника, оцінено граничну кількість його вершин та обґрунтовано лінійний алгоритм згортки контурів `O(N + M)`.

## 1. Алгебраїчні означення: сума, відбиття та різниця

Нехай `W = ℝᵈ` — `d`-вимірний евклідовий простір (для плоского руху роботів `d = 2`, для просторового польоту `d = 3`). Розглянемо дві непорожні компактні підмножини `A, B ⊂ ℝᵈ`, де `A` задає геометрію робота в його локальній системі координат з початком у характерній точці (центрі мас чи центрі обертання), а `B` — геометричне тіло нерухомої перешкоди у світовій системі координат.

**Означення 1 (Сума Мінковського):** Сумою Мінковського (позначається оператором `⊕`) множин `A` та `B` називається множина всіх попарних векторних сум їхніх елементів:

```
A ⊕ B = { a + b : a ∈ A, b ∈ B }
```

**Означення 2 (Центральне відбиття множини):** Відбиттям множини `A` відносно початку координат називається множина `-A`:

```
-A = { -a : a ∈ A }
```

**Означення 3 (Різниця Мінковського):** Різницею Мінковського (або сумою з відбиттям) називається операція:

```
B ⊕ (-A) = { b - a : b ∈ B, a ∈ A }
```

**Означення 4 (Трансляція тіла):** Положення робота `A`, зміщеного на вектор трансляції `q ∈ ℝᵈ` без зміни орієнтації, позначається як `A(q)`:

```
A(q) = { a + q : a ∈ A }
```

## 2. Теорема еквівалентності колізії (The Collision Theorem)

Фундаментальне твердження, на якому тримається вся теорія конфігураційного простору: перевірка геометричного перетину тіла `A(q)` з перешкодою `B` тотожна перевірці належності точки `q` множині `B ⊕ (-A)`.

**Теорема:** Тіло робота `A`, розміщене у конфігурації трансляції `q`, перетинає перешкоду `B` тоді й лише тоді, коли вектор `q` належить різниці Мінковського `B ⊕ (-A)`:

```
A(q) ∩ B ≠ ∅  ⇔  q ∈ B ⊕ (-A)
```

**Доведення:**

1. **Необхідність (`⇒`):**
   Нехай робот перетинає перешкоду: `A(q) ∩ B ≠ ∅`.
   Це означає, що існує хоча б одна спільна просторова точка `p ∈ ℝᵈ`, яка належить обом множинам:
   `p ∈ A(q)` та `p ∈ B`.
   За означенням трансляції `A(q)`, точку `p` можна подати як:
   `p = a + q` для деякого елемента `a ∈ A`.
   Оскільки одночасно `p = b` для деякого `b ∈ B`, маємо рівність:

```
a + q = b
q = b - a                 [віднімання вектора a від обох частин]
q = b + (-a)              [подання різниці як суми з відбитим вектором]
```

   Оскільки `b ∈ B`, а `-a ∈ -A`, результуючий вектор `q` за означенням суми Мінковського належить множині `B ⊕ (-A)`. Необхідність доведено.

2. **Достатність (`⇐`):**
   Нехай вектор конфігурації `q ∈ B ⊕ (-A)`.
   За означенням множини `B ⊕ (-A)`, існують такі елементи `b ∈ B` та `a ∈ A`, для яких виконується:
   `q = b - a`.
   Додамо вектор `a` до обох частин рівності:

```
q + a = b                 [додавання вектора a до обох частин]
a + q = b                 [комутативність додавання векторів]
```

   Ліва частина `a + q` за означенням належить множині `A(q)`. Права частина `b` належить множині `B`.
   Отже, точка `b` одночасно належить множинам `A(q)` та `B`, звідки:
   `b ∈ A(q) ∩ B  ⇒  A(q) ∩ B ≠ ∅`.

Теорему повністю доведено. Звідси випливає аналітичне означення забороненої C-перешкоди для точки:

```
C_obs(B) = B ⊕ (-A)
```

## 3. Збереження опуклості та опорні гіперплощини

Важливою обчислювальною властивістю є поведінка опуклих множин під час операції додавання Мінковського.

**Лема 1 (Опуклість суми):** Якщо множини `A` та `B` є опуклими, то їхня сума Мінковського `A ⊕ B` також є строго опуклою множиною.

**Доведення:**
Нехай `p₁, p₂ ∈ A ⊕ B`. За означенням існують такі точки `a₁, a₂ ∈ A` та `b₁, b₂ ∈ B`, що:
`p₁ = a₁ + b₁`, `p₂ = a₂ + b₂`.
Розглянемо довільну точку `p(λ)` на відрізку між `p₁` та `p₂` для будь-якого `λ ∈ [0, 1]`:

```
p(λ) = (1 - λ)·p₁ + λ·p₂
= (1 - λ)·(a₁ + b₁) + λ·(a₂ + b₂)     [підстановка p₁ та p₂]
= ((1 - λ)·a₁ + λ·a₂) + ((1 - λ)·b₁ + λ·b₂)  [перегрупування доданків]
```

Оскільки множина `A` опукла, точка `a(λ) = (1 - λ)·a₁ + λ·a₂ ∈ A`.
Оскільки множина `B` опукла, точка `b(λ) = (1 - λ)·b₁ + λ·b₂ ∈ B`.
Отже, `p(λ) = a(λ) + b(λ) ∈ A ⊕ B`. Опуклість доведено.

**Опорна функція (Support Function):** Для опуклої множини `S ⊂ ℝᵈ` опорна функція `h_S: ℝᵈ → ℝ` у напрямку одиничного вектора `u` визначається як:

```
h_S(u) = sup { u · x : x ∈ S }
```

Опорна функція має властивість лінійності відносно суми Мінковського:

```
h_{A ⊕ B}(u) = sup { u · (a + b) : a ∈ A, b ∈ B }         [означення опорної функції для суми множин]
= sup { u · a + u · b : a ∈ A, b ∈ B }                    [дистрибутивність скалярного добутку: u · (a + b) = u · a + u · b]
= sup { u · a : a ∈ A } + sup { u · b : b ∈ B }           [незалежність вибору точок a та b: супремум суми дорівнює сумі супремумів]
= h_A(u) + h_B(u)                                         [згортка за означенням опорних функцій вихідних множин]
```

Це означає, що опорна гіперплощина до суми `A ⊕ B` у напрямку нормалі `u` розташована на відстані, що дорівнює сумі відстаней опорних гіперплощин вихідних тіл `A` та `B` з тим самим вектором нормалі `u`.

## 4. Оцінка складності: кількість вершин C-перешкоди

Нехай `A` — опуклий многокутник з `N` вершинами, а `B` — опуклий многокутник з `M` вершинами на площині `ℝ²`.

**Теорема про кількість граней:** Кількість вершин результуючого опуклого многокутника `C_obs = B ⊕ (-A)` не перевищує `N + M`.

**Доведення:**
Кожне ребро опуклого многокутника визначається унікальним напрямком зовнішньої нормалі `n_i`. На гауссовому колі напрямків `S¹` нормалі многокутника `A` розбивають коло на `N` дуг, а нормалі многокутника `B` — на `M` дуг.

Сума Мінковського відповідає накладанню цих двох розбиттів на колі одиничних нормалей. Оскільки кожна грань результуючого многокутника `A ⊕ B` породжується або ребром многокутника `A`, або ребром многокутника `B` (збіг нормалей зменшує загальну кількість сторін):

```
Кількість граней(A ⊕ B) ≤ N + M
```

Якщо жодна пара ребер многокутників `A` та `B` не є паралельною, кількість вершин суми строго дорівнює `N + M`. Якщо існують ребра з однаковими зовнішніми нормалями, вони зливаються в одне подовжене ребро, і кількість вершин зменшується.

## 5. Алгоритм циклічної згортки контурів за лінійний час O(N + M)

Завдяки впорядкованості нормалей опуклих многокутників обчислення суми Мінковського не потребує попарного перебору всіх `N · M` комбінацій вершин.

Нехай вершини многокутників `B` та `-A` задано у порядку обходу проти годинникової стрілки:
`B = (v₀, v₁, ..., v_{M-1})`, `-A = (w₀, w₁, ..., w_{N-1})`.

Сформуємо вектори спрямованих ребер:
`e_B,i = v_{i+1} - v_i` (індекси за модулем `M`),
`e_A,j = w_{j+1} - w_j` (індекси за модулем `N`).

Кути орієнтації векторів `θ(e) = atan2(e_y, e_x) ∈ [0, 2π)` утворюють монотонно зростаючі послідовності.

Алгоритм виконує двовказівникове злиття (merge), аналогічне фазі злиття у сортуванні MergeSort:

1. Знайти початкові вершини `v₀ ∈ B` та `w₀ ∈ -A` з найменшою координатою `y` (та найменшою `x` при однакових `y`).
2. Початкова вершина суми: `u₀ = v₀ + w₀`.
3. На кожному кроці порівнюються полярні кути поточних ребер `θ(e_B,i)` та `θ(e_A,j)`:
   - Якщо `θ(e_B,i) < θ(e_A,j)`: додаємо ребро `e_B,i`, переходимо до `i = i + 1`.
   - Якщо `θ(e_A,j) < θ(e_B,i)`: додаємо ребро `e_A,j`, переходимо до `j = j + 1`.
   - Якщо `θ(e_B,i) == θ(e_A,j)` (колінеарні ребра): додаємо сумарний вектор `e_B,i + e_A,j`, переходимо до `i = i + 1`, `j = j + 1`.
4. Наступна вершина многокутника обчислюється як `u_{k+1} = u_k + e_обране`.

Оскільки кожен індекс `i` та `j` збільшується рівно до одного повного обходу (`M` та `N` кроків відповідно), сумарна часова складність алгоритму становить строго `O(N + M)`.

## 6. Неопуклі многокутники та декомпозиція

Для неопуклих перешкод або складної форми робота властивість монотонності кутів нормалей втрачається. У цьому випадку застосовується дистрибутивність суми Мінковського відносно операції об'єднання.

Нехай неопуклий робот `A` розбито на `p` опуклих частин `A = ⋃ [i=1..p] A_i`, а неопуклу перешкоду `B` — на `q` опуклих частин `B = ⋃ [j=1..q] B_j`.

Тоді C-перешкода виражається як об'єднання попарних сум Мінковського опуклих компонент:

```
C_obs(B) = (⋃ [j=1..q] B_j) ⊕ (- ⋃ [i=1..p] A_i)          [підстановка розбиття на опуклі компоненти]
= ⋃ [j=1..q] ⋃ [i=1..p] (B_j ⊕ (-A_i))                   [дистрибутивність суми Мінковського відносно операції об'єднання множин]
```

Кожна пара `B_j ⊕ (-A_i)` є опуклим многокутником і обчислюється за час `O(N_i + M_j)`. Загальне об'єднання `p · q` опуклих полігонів утворює складний полігональний комплекс із можливими самоперетинами та внутрішніми дірками, який будується за допомогою алгоритмів плоскої декомпозиції (sweep-line arrangement) за час `O((K + I) log K)`, де `K = ∑ (N_i + M_j)`, а `I` — кількість точок перетину ребер.
