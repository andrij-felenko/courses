# 🧮 Топологічні основи клітинного розкладу Морса

Ця математична вставка formalize-ує топологію замітання вільного простору прямою та доводить повноту бустрофедонного клітинного розкладу. Вона потрібна для того, щоб показати суворе обґрунтування: чому розбиття на комірки відбувається саме в критичних точках проекції, чому кожна виділена комірка гарантовано покривається суцільним рухом без розривів і чому побудований граф суміжності зберігає зв'язність вихідного робочого середовища.

Без цього апарату евристичне планування натрапляє на небезпечну пастку: у складних середовищах із багатьма гострими кутами та внутрішніми островами незрозуміло, які саме вершини вимагають розрізу, а які можна ігнорувати. Топологічний аналіз функції Морса дає однозначний критерій: розріз потрібен тоді й тільки тоді, коли змінюється кількість зв'язних компонент одновимірного перетину вільного простору.

## Вільний простір, січна пряма та зрізи

Нехай робоче середовище робота задано як замкнений многокутник на площині з `k` багатокутними перешкодами (отворами). Позначимо відкритий вільний простір через `Q_free ⊂ ℝ²`. Межа цього простору `∂Q_free` складається зі скінченного набору орієнтованих відрізків — зовнішнього контуру та внутрішніх контурів перешкод.

Розглянемо гладку (або шматочно-лінійну) функцію висоти `h: Q_free → ℝ`, яка задає напрямок замітання простору. Без обмеження загальності оберемо ортогональну систему координат так, щоб функція `h` збігалася з координатою `x`:

```
h(x, y) = x
```

Для кожного значення координати `x ∈ ℝ` визначимо січну пряму `L(x) = { (x, y) ∈ ℝ² }`. Перетин січної прямої з вільним простором утворює одновимірний зріз:

```
Q(x) = Q_free ∩ L(x)
```

Оскільки `Q_free` є відкритим полігональним простором, одновимірний зріз `Q(x)` для майже всіх `x` є скінченним об'єднанням `m(x)` неперетинних відкритих інтервалів уздовж осі `y`:

```
Q(x) = ⋃ [j=1 .. m(x)] (y_нижнє_j(x), y_верхнє_j(x))
```

Число інтервалів `m(x)` дорівнює нульовому числу Бетті цього зрізу:

```
b₀(Q(x)) = m(x)
```

Це число показує, на скільки ізольованих робочих коридорів розпадається вільний простір для робота при фіксованому положенні лінії замітання `x`.

## Критичні точки в теорії Морса для полігональних просторів

У класичній диференціальній топології критичною точкою гладкої функції `h: M → ℝ` є точка, де градієнт обнуляється: `∇h(p) = 0`. Для многокутників межа `∂Q_free` не є всюди гладкою, тому критичні точки визначаються через локальну топологію перетину лінії рівня `L(x)` із замиканням вільного простору в околі кожної вершини `v = (x_v, y_v)`.

Нехай `v` — вершина многокутника на межі `∂Q_free`. Розглянемо два суміжні ребра `e₁` та `e₂`, що сходяться у вершині `v`. Позначимо одиничні вектори напрямку цих ребер, спрямовані від вершини `v` усередину відповідних відрізків, як `u₁ = (u₁_x, u₁_y)` та `u₂ = (u₂_x, u₂_y)`.

Знак проекції ребер на вісь замітання визначається горизонтальними компонентами `u₁_x` та `u₂_x`. Можливі три фундаментальні конфігурації:

1. **Регулярна точка (прохідна вершина):**
   Одне ребро спрямоване ліворуч, а друге — праворуч:
   ```
   u₁_x · u₂_x < 0
   ```
   При проходженні січної лінії через таку точку топологія зрізу `Q(x)` не змінюється. Кількість інтервалів лишається сталою: `m(x_v - ε) = m(x_v + ε)`. Змінюється лише функція координати кінця інтервалу `y(x)`. Розріз простору в цій точці не потрібен.

2. **Локальний мінімум (обидва ребра спрямовані вправо):**
   ```
   u₁_x > 0  та  u₂_x > 0
   ```
   При підході зліва (`x = x_v - ε`) у безпосередньому околі точки `v` не було перетину, а справа (`x = x_v + ε`) з'являється новий сегмент.

3. **Локальний максимум (обидва ребра спрямовані вліво):**
   ```
   u₁_x < 0  та  u₂_x < 0
   ```
   При підході зліва існував сегмент, який при переході через `x_v` замикається та зникає.

## Класифікація чотирьох подій: IN, OUT, SPLIT, MERGE

Щоб точно відрізнити події на зовнішній межі від подій на внутрішніх перешкодах, розглянемо внутрішній тілесний кут вільного простору при вершині `v`.

Нехай вектор нормалі `n_внутр` спрямований усередину `Q_free`. Класифікація критичних точок здійснюється за знаком горизонтальних компонент суміжних ребер та положенням вільного простору відносно вершини:

### 1. Подія IN (поява вільного простору)
Вершина належить зовнішній межі. Обидва ребра спрямовані праворуч (`u₁_x > 0, u₂_x > 0`), а сектор між ними належить вільному простору `Q_free`.
Зміна нульового числа Бетті зрізу:

```
Δb₀ = b₀(Q(x_v + ε)) − b₀(Q(x_v − ε))
    = (m + 1) − m
    = +1                  [народження нової зв'язної компоненти зрізу]
```

### 2. Подія OUT (зникнення вільного простору)
Вершина належить зовнішній межі. Обидва ребра спрямовані ліворуч (`u₁_x < 0, u₂_x < 0`), а сектор між ними належить вільному простору `Q_free`.
Зміна нульового числа Бетті зрізу:

```
Δb₀ = b₀(Q(x_v + ε)) − b₀(Q(x_v − ε))
    = (m − 1) − m
    = −1                  [знищення зв'язної компоненти зрізу]
```

### 3. Подія SPLIT (розщеплення інтервалу перешкодою)
Вершина належить контуру перешкоди (внутрішнього отвору). Обидва ребра перешкоди спрямовані праворуч (`u₁_x > 0, u₂_x > 0`), але сектор між ними є матеріалом перешкоди, тому вільний простір лежить зовні цього кута.
Січна пряма при `x = x_v - ε` перетинала вільний простір одним неперервним інтервалом. У точці `x = x_v + ε` перешкода розрізає цей інтервал на два незалежні інтервали: верхній і нижній.
Зміна нульового числа Бетті зрізу:

```
Δb₀ = b₀(Q(x_v + ε)) − b₀(Q(x_v − ε))
    = (m + 1) − m
    = +1                  [розпад одного інтервалу на два]
```

### 4. Подія MERGE (злиття інтервалів за перешкодою)
Вершина є заднім краєм перешкоди. Обидва ребра перешкоди спрямовані ліворуч (`u₁_x < 0, u₂_x < 0`), вільний простір лежить поза кутом перешкоди.
При `x = x_v - ε` вільний простір огинав перешкоду двома незалежними інтервалами. У точці `x = x_v + ε` перешкода закінчилася, і верхній та нижній інтервали об'єднуються в один спільний інтервал.
Зміна нульового числа Бетті зрізу:

```
Δb₀ = b₀(Q(x_v + ε)) − b₀(Q(x_v − ε))
    = (m − 1) − m
    = −1                  [злиття двох інтервалів в один]
```

## Зведене рівняння динаміки ейлерової характеристики

Для одновимірного многовиду (набору відрізків) ейлерова характеристика `χ(Q(x))` тотожно дорівнює кількості зв'язних компонент `b₀(Q(x))`:

```
χ(Q(x)) = b₀(Q(x)) − b₁(Q(x))      [за означенням ейлерової характеристики]
        = b₀(Q(x)) − 0             [одновимірний зріз не містить циклів: b₁ = 0]
        = m(x)                     [кількість зв'язних інтервалів зрізу]
```

При проходженні лінії замітання вздовж осі `x` зміна кількості активних комірок виражається сумою стрибків у критичних точках:

```
m(x) = ∑ [v_k: x_k ≤ x] Δb₀(v_k)
```

де для кожної критичної точки `v_k`:

```
Δb₀(v_k) = +1   [якщо тип події IN або SPLIT]
Δb₀(v_k) = −1   [якщо тип події OUT або MERGE]
Δb₀(v_k) =  0   [якщо точка регулярна]
```

Повний інтеграл за всім простором повертає ейлерову характеристику вихідного двовимірного простору `Q_free`:

```
χ(Q_free) = N_IN − N_SPLIT − N_MERGE + N_OUT
```

Це співвідношення гарантує топологічну замкненість алгоритму: кількість подій розщеплення та злиття строго узгоджена з кількістю перешкод у середовищі.

## Теорема монотонності комірки

Головна вимога до комірки бустрофедонного розкладу полягає в тому, щоб її можна було повністю покрити паралельними галсами без внутрішніх повернень і без розриву траєкторії.

**Визначення комірки:**
Нехай `x_1 < x_2 < ... < x_p` — упорядковані `x`-координати всіх критичних точок простору `Q_free`.
Коміркою `C` називається відкрита зв'язна підмножина `Q_free`, обмежена двома сусідніми критичними перетинами `x = x_i` та `x = x_{i+1}` і двома неперервними функціями верхньої та нижньої меж:

```
C = { (x, y) ∈ ℝ² : x ∈ (x_i, x_{i+1}),  y_нижнє(x) < y < y_верхнє(x) }
```

**Доведення монотонності комірки:**

1. Оскільки в інтервалі `(x_i, x_{i+1})` відсутні критичні точки функції `h(x, y) = x`, за теоремою про неявну функцію верхня межа `y_верхнє(x)` та нижня межа `y_нижнє(x)` є однозначними шматочно-гладкими неперервними функціями від `x`.

2. Для будь-якого `x₀ ∈ (x_i, x_{i+1})` перетин комірки з прямою `L(x₀)` складається рівно з одного зв'язного відрізка:
   ```
   C ∩ L(x₀) = { (x₀, y) : y ∈ (y_нижнє(x₀), y_верхнє(x₀)) }
   ```

3. Будь-який вертикальний галс, проведений від точки `(x₀, y_нижнє(x₀))` до точки `(x₀, y_верхнє(x₀))`, повністю лежить усередині комірки `C` і не перетинає жодних перешкод:
   ```
   ∀ y ∈ (y_нижнє(x₀), y_верхнє(x₀))  ⟹  (x₀, y) ∈ C ⊂ Q_free
   ```

4. Отже, довільна послідовність вертикальних проходів із кроком `d = w·(1 − перекриття)` повністю замітає комірку `C` без необхідності об'їзду будь-яких внутрішніх перешкод. Комірка є строго `x`-монотонною.

## Топологія графа Реба та збереження зв'язності

Бустрофедонний розклад породжує подвійний граф зв'язності `G = (V, E)` — так званий граф Реба (Reeb graph) для функції висоти `h(x, y) = x`.

- **Множина вершин `V`:** кожна вершина `v_C ∈ V` відповідає окремій монотонній комірці `C_i`.
- **Множина ребер `E`:** ребро `(v_A, v_B) ∈ E` існує тоді й тільки тоді, коли комірки `C_A` та `C_B` мають спільний відкритий вертикальний відрізок межі при критичній координаті `x_крит`.

**Доведення збереження зв'язності:**

1. Нехай вільний простір `Q_free` є лінійно зв'язним. Це означає, що для будь-яких двох точок `p, q ∈ Q_free` існує неперервний шлях `γ: [0, 1] → Q_free`, такий що `γ(0) = p` та `γ(1) = q`.

2. Шлях `γ` перетинає скінченну послідовність комірок `C_{i_1}, C_{i_2}, ..., C_{i_k}`.

3. Оскільки перехід шляху `γ` з комірки `C_{i_j}` у комірку `C_{i_{j+1}}` відбувається через їхню спільну критичну межу, у графі `G` існує ребро між вершинами `v_{i_j}` та `v_{i_{j+1}}`.

4. Отже, послідовність вершин `v_{i_1}, v_{i_2}, ..., v_{i_k}` утворює неперервний шлях у графі `G`.

5. Граф суміжності `G` є зв'язним.

Зі зв'язності графа `G` випливає фундаментальний наслідок для повноти покриття: будь-який алгоритм обходу зв'язного графа (наприклад, пошук у глибину DFS або пошук найкоротшого листового обходу) гарантовано відвідає кожну вершину `v_C ∈ V`, а отже, робот виконає покриття кожної комірки `C_i`, досягаючи 100% покриття всього простору `Q_free`.

## Оптимізація напрямку замітання: мінімізація сумарних поворотів

Напрямок замітання не обов'язково має збігатися з віссю абсцис вихідної системи координат. Позначимо кут напрямку замітання через `θ ∈ [0, π)`.

Поворот системи координат на кут `θ` задається матрицею повороту:

```
[ x' ]   [  cos θ   sin θ ] [ x ]
[ y' ] = [ −sin θ   cos θ ] [ y ]
```

Для фіксованого кута `θ` вільний простір розкладається на `K(θ)` комірок `{ C₁(θ), C₂(θ), ..., C_{K(θ)}(θ) }`.

Кількість поворотів робота всередині однієї комірки `C_i` пропорційна її ширині вздовж осі замітання `x'` та обернено пропорційна ефективній ширині захвату `d`:

```
N_розворотів(C_i, θ) = ⌈ (x'_макс(C_i) − x'_мін(C_i)) / d ⌉ − 1
```

Сумарна вартість покриття середовища при куті замітання `θ` складається з робочих проходів, внутрішньокоміркових розворотів та міжкоміркових переходів:

```
Cost(θ) = L_робоча + T_turn · ∑ [i=1 .. K(θ)] N_розворотів(C_i, θ) + L_транзит(θ)
```

Оскільки сумарна робоча довжина `L_робоча ≈ S(Q_free) / d` майже не залежить від кута `θ`, мінімізація функціоналу `Cost(θ)` зводиться до мінімізації суми ширин комірок уздовж напрямку замітання та мінімізації кількості критичних точок `K(θ)`.

Для опуклого многокутника мінімум досягається при замітанні вздовж найдовшого ребра (або перпендикулярно до мінімальної ширини за штангенциркулем Туссена). Для складного неопуклого простору з перешкодами оптимальний кут `θ*` знаходиться дискретним пошуком серед кутів, колінеарних ребрам найбільших перешкод середовища.
