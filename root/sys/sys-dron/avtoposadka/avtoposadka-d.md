Безпілотник масою чотири кілограми завершує автономну місію і спускається до посадкового майданчика з вертикальною швидкістю два метри на секунду. На висоті пів метра над бетоном повітряні струмені від пропелерів відбиваються від площини, створюючи під рамою зону підвищеного статичного тиску: барометр фіксує стрибок на два паскалі й помилково інтерпретує його як раптове просідання на двадцять сантиметрів. Висотний PID-регулятор миттєво зменшує оберти двигунів, апарат провалюється вниз, і одна стійка карбонового шасі торкається похилого каменя раніше за інші. Якщо контур стабілізації у цю частку секунди спробує вирівняти нахилений корпус до нульового горизонту, він додасть максимальний газ на нижні мотори: жорстка опора перетвориться на шарнір, рама перекинеться навколо точки торкання, а карбонові лопаті розлетяться на уламки об землю. Процедура **автоматичної посадки** (*Auto-Landing*) та **детектування контакту з ґрунтом** (*Ground Detection*) — це найбільш критичний етап польоту, де автопілот зобов'язаний узгодити суперечливі показання сенсорів, розпізнати фізичний контакт без кінцевих вимикачів на ніжках і вчасно роззброїти двигуни до виникнення динамічного перекидання.

Посадка єдиним чином поєднує три взаємопов'язані фази: кероване профільоване зниження, багатофакторне детектування контакту з твердою опорою та детерміноване розброєння із захистом від розгону інтеграторів.

### Фізика переходу з повітря на ґрунт і динамічні загрози

У вільному польоті мультиротор є вільним твердим тілом із шістьма ступенями вільності (6 DoF): трьома поступальними координатами (X, Y, Z) у локальній навігаційній системі координат та трьома кутами орієнтації (крен φ, тангаж θ, рискання ψ). Будь-який дисбаланс тяги між протилежними моторами створює чистий крутний момент, який викликає кутове прискорення навколо центру мас без виникнення зовнішніх реакцій опори. Положення центру мас лишається динамічним центром усієї системи сил.

У момент торкання поверхні механічна система зазнає миттєвого фазового переходу. Стійка шасі торкається ґрунту, внаслідок чого на конструкцію починають діяти зовнішня сила нормальної реакції поверхні N та сила тертя спокою або ковзання F_fr. Кількість ступенів вільності миттєво падає: вільне тверде тіло перетворюється на просторовий маятник із закріпленою точкою опори.

```
       У ПОВІТРІ (6 DoF)                    ПРИ КОНТАКТІ (Накладені в'язі)
          ▲ Z (Тяга T)                                 ▲ Z (Тяга T)
          │                                            │
     ┌────┴────┐                                  ┌────┴────┐
     │  ДРОН   │ ◄── Центр мас                    │  ДРОН   │ ◄── Центр мас (h_cg)
     └────┬────┘                                  └────┬────┘
         ╱ ╲                                          ╱ ╲
        ╱   ╲  (Вільний рух)                         ╱   ● ◄── Точка опори (Pivot point)
                                                   ▒▒▒▒▒▒▒▒▒▒▒▒ (Реакція N, тертя F_fr)
```

Цей перехід породжує дві головні загрози руйнування апарата:

#### 1. Механіка динамічного перекидання (Dynamic Rollover / Tip-Over)
Коли одна нога шасі зачіпляється за ґрунт, камінь або високу траву, вона стає нерухомою віссю обертання (*pivot point*). Припустимо, що внаслідок нерівності рельєфу або початкового нахилу рама нахилилася на кут φ. Кутовий PID-регулятор автопілота бачить відхилення від цільового горизонту `phi_cmd = 0°` і формує керівний момент стабілізації:

```
M_PID = K_p * (phi_cmd - phi) + K_i * int(e_phi dt) + K_d * (d e_phi / dt)   [керівний момент кутового PID]
```

Оскільки `phi_cmd - phi = -phi`, регулятор сприймає нахил як зовнішнє кутове збурення у повітрі та починає форсувати тягу двигунів на нижньому боці рами.

Складемо рівняння моментів відносно точки опори ноги шасі:

```
M_total  = T_lower * l_arm + T_total * h_cg * sin(phi) - m * g * d_stance * cos(phi) [баланс моментів навколо опори]
phi_crit = arctan(d_stance / h_cg)                                                   [критичний кут перекидання]
```

де `T_lower` — тяга моторів на боці нахилу, `l_arm` — плече мотора відносно центру, `h_cg` — висота центру мас над землею, `d_stance` — половина ширини колії шасі.

Якщо момент відновлення `m * g * d_stance * cos(phi)` виявляється меншим за момент перекидання, створюваний тягою моторів, виникає позитивний зворотний зв'язок: чим більше регулятор намагається вирівняти дрон, тим сильніше він притискає точку опори й перекидає апарат через шасі. Кут перекидання стрімко перевищує критичний поріг `phi_crit`, рама падає на бік, і лопаті, що обертаються зі швидкістю понад 6000 об/хв, зазнають катастрофічного руйнування від удару об ґрунт.

Ширина колії шасі та висота центру мас безпосередньо визначають геометричний запас стійкості. Для високих знімальних коптерів із підвішеною важкою камерою відношення `d_stance / h_cg` часто не перевищує одиниці, що дає критичний кут перекидання всього 45 градусів у статиці, а в динаміці з урахуванням розгону кутових регуляторів — менше 12 градусів.

#### 2. Інтегральне насичення висотного контуру (Throttle Integrator Windup)
Під час керованого зниження висотний PID-регулятор працює за похибкою вертикальної швидкості:

```
e_vz(t) = Vz_cmd(t) - Vz(t)   [похибка вертикальної швидкості регулятора]
```

де `Vz_cmd = -0.5 м/с` (уставка на спуск).

Коли апарат опиняється на землі, його реальна швидкість стає строго нульовою (`Vz = 0`). Похибка швидкості залишається постійно від'ємною (`e_vz = -0.5 - 0 = -0.5 м/с`).

Інтегральна складова регулятора починає безперервно інтегрувати цю похибку:

```
I_z(t) = I_z(t0) + K_i * int(e_vz(tau) dtau)   [накопичення інтегратора газу в мінус]
```

Значення `I_z` падає з кожною мілісекундою, зменшуючи загальну команду газу `u_throttle = P_z + I_z + D_z` до апаратного мінімуму `THR_MIN`. Якщо в цей момент набіжить порив вітру, або дрон підстрибне на пружинному шасі, або пілот вирішить перервати посадку (Go-Around), глибоко від'ємний інтегратор заблокує наростання тяги. Двигуни не зможуть підхопити апарат протягом 0.5–1.2 секунди, необхідних для розвантаження інтегратора, і безпілотник безконтрольно впаде з висоти кількох метрів.

#### 3. Динаміка удару та хвильові процеси в рамі
При торканні твердої поверхні кінетична енергія вертикального спуску переходить у деформацію конструкції. Механічний імпульс удару передається через карбонові промені на плату польотного контролера. Якщо демпфери польотного контролера мають власну резонансну частоту в діапазоні 20–50 Гц, удар збуджує високоамплітудні коливання чутливих елементів MEMS-акселерометрів.

Це явище викликає насичення чутливих каналів вимірювання (акселерометричний кліпінг). Інтегратор швидкості розширеного фільтра Калмана (EKF) отримує спотворений сигнал прискорення, що веде до миттєвої розбіжності оцінки швидкості (Velocity Innovation Spike). Якщо алгоритм детектора землі не має фільтрації шокових імпульсів, похибка оцінки швидкості збиває всю навігаційну систему.

#### 4. Адаптивне оцінювання тяги зависання (Hover Thrust Tracking)
Надійність детектування спаду тяги базується на знанні точного значення газу зависання `T_hover`. Проте під час тривалого польоту маса апарата може змінюватися (скидання корисного навантаження, витрата пального на гібридних установках), а напруга літій-полімерної батареї неминуче просідає від 4.2 В до 3.5 В на елемент. Через це газ зависання зростає на 20–35% протягом одного вильоту.

Сучасний автопілот безперервно оцінює поточну тягу зависання за допомогою рекурентного фільтра Калмана, що зіставляє вертикальне прискорення з виданою сумарною тягою. У момент початку зниження адаптивний оцінювач заморожує своє значення, щоб виключити помилкове коригування тяги під дією аеродинамічного гальмування та екранного ефекту.

### Багатофазний вертикальний профіль зниження

Процес автопосадки розбивається на чітко розмежовані висотні фази, кожна з яких розв'язує окрему аеродинамічну та кінематичну задачу.

![Вертикальний профіль автопосадки та фази детектування землі](/root/sys/sys-dron/avtoposadka/img/landing-phases-profile.svg)
*Чотири послідовні фази автопосадки: швидке зниження на крейсерській швидкості, плавне гальмування до посадкової швидкості 0.5 м/с при проходженні порога LAND_ALT_LOW, фіксація контакту з ґрунтом за комплексом фізичних ознак та лінійне зняття тяги з автоматичним розброєнням.*

#### Фаза 1: Швидкий спуск (Fast Descent)
Зниження від початкового ешелону (30–120 метрів) до точки зміни профілю `LAND_ALT_LOW` (зазвичай 3–8 метрів) виконується з підвищеною вертикальною швидкістю:

```
Vz_fast = 1.5 .. 2.5 м/с   [швидкість швидкого вертикального спуску]
```

Мета фази — мінімізувати час перебування у фазі зниження, заощадивши енергію акумулятора та знизивши експозицію дрона до атмосферної турбулентності. Проте швидкість `Vz_fast` не може призначатися довільно великою. Її верхня межа жорстко диктується аеродинамічним феноменом **режиму вихрового кільця** (*Vortex Ring State*, VRS).

У стаціонарному зависанні гвинти відкидають повітря вниз з індукованою швидкістю `v_i`, яка за імпульсною теорією ротора дорівнює:

```
v_i = sqrt( T / (2 * rho * A) )   [індукована швидкість струменя роторів]
```

де `T = m * g` — сумарна тяга апарата, `rho` — густина повітря (1.225 кг/м³), `A = n * pi * R^2` — сумарна ометена площа n пропелерів.

Якщо мультиротор знижується строго вертикально зі швидкістю спуску `Vz`, яка потрапляє в критичний інтервал:

```
0.5 * v_i <= Vz <= 1.25 * v_i   [небезпечна зона вихрового кільця VRS]
```

відкинутий униз повітряний струмінь не встигає розсіятися в атмосфері й під дією набігаючого знизу потоку загортається вгору повз кінці лопатей. Утворюється замкнений тороїдальний вихор навколо диска пропелера.

У режимі VRS виникає зрив потоку біля кореневих ділянок лопатей, ефективна тяга падає на 60–80%, а локальні флуктуації вихорів викликають хаотичне розгойдування по крену й тангажу з частотою 1–3 Гц. Додавання газу в режимі VRS лише збільшує енергію тороїдального вихору, посилюючи провалювання апарата. Тому максимальна вертикальна швидкість автопосадки `Vz_fast` програмно обмежується порогом, який не перевищує `0.7 * v_i` (для більшості мультироторів безпечна межа становить 2.0–2.5 м/с).

#### Фаза 2: Гальмування та посадкове підкрадання (Slow Touchdown Approach)
Під час перетину висоти `LAND_ALT_LOW` автопілот за допомогою лінійного або S-подібного рамп-генератора знижує швидкість спуску до постійної посадкової величини `LAND_SPEED`:

```
Vz_land = 0.5 .. 0.7 м/с   [посадкова швидкість підкрадання]
```

Цей діапазон вибрано з компромісу між двома критичними фізичними обмеженнями:
- **Чому не можна сідати швидше ніж 0.8 м/с:**
  Кінетична енергія вертикального руху в момент торкання становить:
```
E_k = 0.5 * m * Vz^2   [кінетична енергія вертикального удару]
```
  Під час удару об твердий ґрунт або бетон ця енергія має розсіятися пружною деформацією стійок шасі та гумових демпферів. При `Vz = 1.2 м/с` пікове ударне перевантаження на рамі перевищує 4.5g. Це призводить до мікротріщин у карбоні, зміщення оптичних осей гіростабілізованого підвісу та виходу показань акселерометрів за межі динамічного діапазону (clipping IMU), що збиває орієнтацію EKF.
- **Чому не можна сідати повільніше ніж 0.3 м/с:**
  При надмірно низькій швидкості апарат зависає у приземному шарі протягом тривалого часу. Це призводить до перегріву силових MOSFET-ключів у регуляторах швидкості (ESC) через роботу на малій шпаруватості ШІМ при високих фазних струмах. Крім того, тривале перебування на малій висоті робить дрон вкрай чутливим до бокових поривів приземного вітру: горизонтальний знос зміщує апарат убік, і замість вертикальної посадки відбувається посадка з боковим ударом і ковзанням.

#### Фаза 3: S-подібний профіль прискорення та ривка (Jerk-Limited Trajectory)
Для плавного переходу від швидкого спуску до посадкового підкрадання сучасні прошивки застосовують траєкторні генератори з обмеженням ривка (*jerk* — похідна від прискорення). Якщо змінити уставку швидкості стрибком, висотний регулятор видасть різкий ривок прискорення, що викличе закидання лопатей пропелерів і паразитний сплеск кутового крену.

Траєкторний генератор формує уставку прискорення `a_z(t)` з обмеженням максимального ривка `J_max = 3.0 м/с³` та максимального вертикального уповільнення `a_max = 1.5 м/с²`. Це гарантує безперервність другої похідної положення та повністю виключає коливальні перехідні процеси у висотному контурі.

#### Фаза 4: Злиття далекоміра та оптичного потоку (AGL Fusion)
При вході в зону висоти менше 4 метрів автопілот виконує плавний перехід із барометричної оцінки висоти на локальну висоту над рельєфом (AGL — *Above Ground Level*), яку надає оптичний далекомір або LiDAR.

Одночасно з далекоміром активується модуль оптичного потоку (*Optical Flow*). Камера, спрямована вниз, розраховує рух текстури підстильної поверхні й компенсує боковий дрейф із субсантиметровою точністю. Це критично для посадки на вузькі злітно-посадкові платформи та дахи автомобілів, де помилка GNSS може складати метр або більше.

### Фізичні критерії детектування контакту з землею

Чому бортовий комп'ютер не може визначити момент посадки за простим порогом абсолютного висотоміра?

У реальному польоті пряме вимірювання абсолютної висоти має принципові похибки:
1. **Барометричний висотомір** зазнає температурного дрейфу до 1.5 м за час польоту через прогрів плати польотного контролера та зміну атмосферного фронту. Крім того, при наближенні до землі барометр зазнає аеродинамічного спотворення від екранного ефекту.
2. **Супутникова навігація GNSS** має вертикальну похибку `sigma_z ≈ ±1.5..3.0 м` через геометрію супутникового сузір'я (VDOP) та багатопроменевість від землі.
3. **Оптичні та лазерні далекоміри (LiDAR / ToF)** можуть бути засліплені прямим сонячним світлом, давати хибні показання над водою, склом, високою травою або піднімати хмару пилу від пропелерів, яка відбиває лазерний промінь на висоті 20 см над реальним ґрунтом.

Тому сучасні автопілоти (PX4, ArduPilot) використовують **багатофакторний непрямий детектор контакту** (*Ground Detector*). Він розглядає дрон як замкнену динамічну систему й виявляє перехід стану за одночасним виконанням чотирьох фізичних інваріантів.

```
                     ┌────────────────────────────────────────┐
                     │         ДЖЕРЕЛА ДАНИХ ДЕТЕКТОРА        │
                     └───────────────────┬────────────────────┘
                                         │
     ┌───────────────────┬───────────────┴───────────────┬───────────────────┐
     ▼                   ▼                               ▼                   ▼
┌──────────────┐  ┌──────────────┐              ┌──────────────┐      ┌──────────────┐
│ Вихід газу   │  │ Оцінка EKF   │              │ Акселерометр │      │  Гіроскопи   │
│  (Throttle)  │  │ (Velocity Z) │              │ (IMU Accel)  │      │ (Gyro Rates) │
└──────┬───────┘  └──────┬───────┘              └──────┬───────┘      └──────┬───────┘
       │                 │                             │                     │
       ▼                 ▼                             ▼                     ▼
┌──────────────┐  ┌──────────────┐              ┌──────────────┐      ┌──────────────┐
│  Газ < 25%   │  │ |Vz| < 0.15  │              │ Сплеск |az|  │      │ |ω| < 10°/s  │
│  від висіння │  │     м/с      │              │ або спокій σ │      │  по 3 осях   │
└──────┬───────┘  └──────┬───────┘              └──────┬───────┘      └──────┬───────┘
       │                 │                             │                     │
       └─────────────────┴───────────────┬─────────────┴─────────────────────┘
                                         ▼
                     ┌────────────────────────────────────────┐
                     │      ІНТЕГРАТОР ДОВІРИ / ТАЙМЕР        │
                     │       t_persistence ≥ 1.0..1.5 с       │
                     └───────────────────┬────────────────────┘
                                         ▼
                     ┌────────────────────────────────────────┐
                     │    СТАН LANDED -> ДИСАРМ МОТОРІВ       │
                     └────────────────────────────────────────┘
```

Розглянемо кожен із чотирьох критеріїв детально:

#### 1. Спад потреби тяги та насичення газу (Throttle Drop & Saturation)
У польоті для підтримки стабільної швидкості спуску двигуни повинні створювати тягу, близьку до ваги апарата: `T ≈ m * g - c_d * Vz^2 ≈ 0.9 * T_hover`. Коли шасі впирається в ґрунт, сила нормальної реакції поверхні N бере на себе вагу дрона (`N -> m * g`). Висотний контур бачить, що апарат перестав знижуватися, і для досягнення уставки `Vz_cmd = -0.5 м/с` починає скидати оберти.

Рівень вихідної тяги `T_out` падає нижче каліброваного порога:

```
T_out <= T_hover * k_land_thr   [поріг детектування спаду тяги контакту]
```

де `T_hover` — адаптивно оцінена в польоті тяга зависання (зазвичай 0.35–0.55 від максимуму), а `k_land_thr = 0.25..0.30` (поріг 25–30% від газу висіння).

#### 2. Кінематична зупинка за EKF (Velocity Zero Lock)
Розширений фільтр Калмана безперервно зливає високочастотні дані акселерометрів (200–1000 Гц) з корекціями далекоміра та GNSS. Попри те, що висотний PID вимагає спуску `Vz_cmd = -0.5 м/с`, оцінена фільтром вертикальна швидкість падає до нуля:

```
|Vz| <= Vz_thresh   [поріг швидкості зупинки Vz_thresh = 0.12..0.18 м/с]
```

Невідповідність між уставкою швидкості та нульовим реальним рухом при мінімальній тязі є прямим доказом наявності твердої перешкоди під шасі.

#### 3. Ударний імпульс та вертикальне прискорення (Vertical Acceleration Spike)
У момент фізичного торкання шасі ґрунту вектор прискорення по осі Z зазнає короткочасного стрибка:

```
|az - g| >= a_shock_thresh   [поріг ударного прискорення a_shock = 3.0..6.0 м/с²]
```

Після згасання ударного імпульсу (через 100–150 мс) ковзна дисперсія вертикального прискорення `sigma^2(az)` падає до мінімального рівня, оскільки апарат переходить із вільного вібраційного стану в режим жорсткої опори.

#### 4. Кутовий спокій (Angular Rate Rest)
Бортові гіроскопи фіксують відсутність динамічного обертання навколо всіх трьох осей:

```
|omega_x| <= omega_max, |omega_y| <= omega_max, |omega_z| <= omega_max   [omega_max = 0.18..0.25 рад/с]
```

Це виключає помилкове спрацьовування детектора у випадках, коли апарат зазнає кутового збурення від турбулентності або перебуває в стані аварійного перекидання у повітрі.

### Скінченний автомат: від контакту до автоматичного розброєння

Для виключення хибних спрацьовувань від випадкових поривів вітру, просідання на гілках дерев або підстрибування на пружинному шасі алгоритм детектування організовано у вигляді детермінованого скінченного автомата з фільтрами стійкості (*Persistence Filters*).

![Граф станів автомата детектування землі (Ground Detector FSM)](/root/sys/sys-dron/avtoposadka/img/ground-detector-fsm.svg)
*Скінченний автомат детектора землі: послідовний перехід станів від IN_AIR до DISARMED із захисними гілками повернення при відриві від ґрунту або сплесках кутових швидкостей.*

Автомат підтримує п'ять станів:

#### 1. Стан `IN_AIR` (У повітрі)
Штатний режим польоту або керованого зниження. Мотори заармлені, навігаційні контури керують вектором тяги.
- *Умова переходу в `GROUND_CONTACT`:* одночасне виконання всіх чотирьох фізичних критеріїв контакту (`T_out < 0.3 * T_hover`, `|Vz| < 0.15 м/с`, `|omega| < 12°/s`).
- При вході в стан `GROUND_CONTACT` фіксується мітка часу `t_contact_start`.

#### 2. Стан `GROUND_CONTACT` (Первинний контакт)
Тимчасовий стан валідації першого торкання.
- *Захисна гілка:* якщо хоча б один із критеріїв порушується (наприклад, порив вітру відірвав дрон від землі або Vz зросла понад 0.25 м/с), автомат негайно повертається в стан `IN_AIR`.
- *Умова переходу в `MAYBE_LANDED`:* умови контакту безперервно утримуються протягом інтервалу `t_contact >= 0.5 с`.

#### 3. Стан `MAYBE_LANDED` (Підтвердження посадки)
Стан глибокої підготовки до зупинки двигунів.
- *Дії автопілота в стані `MAYBE_LANDED`:*
  1. **Заморожування та скидання інтеграторів (I-term Zeroing):** інтегральні складові кутових PID-регуляторів по крену, тангажу та курсу обнуляються (`I_phi = 0`, `I_theta = 0`, `I_psi = 0`). Це повністю усуває загрозу динамічного перекидання, якщо шасі стоїть на похилій поверхні.
  2. **Обмеження кутового моменту:** максимальні кути стабілізації обмежуються діапазоном ±2.5°.
  3. **Притискання до поверхні:** висотний контур подає мінімальну уставку від'ємної тяги (Spin Minimum) для запобігання підстрибуванню від екранного ефекту.
- *Умова переходу в `LANDED`:* контакт безперервно утримується понад повний тайм-аут `LAND_DETECTOR_TIMEOUT` (зазвичай 1.0–1.5 с).

#### 4. Стан `LANDED` (Посадку зафіксовано)
Факт приземлення остаточно верифіковано.
- *Дії автопілота в стані `LANDED`:*
  1. Бортовий прапорець стану переводиться в `vehicle_landed = true`.
  2. Запускається процедура лінійного зняття тяги (*Throttle Ramp-down*): ШІМ-команда моторів лінійно зменшується від поточного значення холостого ходу до нуля за час 0.3–0.5 с.
  3. Запускається таймер розброєння `AUTO_DISARM_TIMEOUT` (0.5–1.0 с).

#### 5. Стан `DISARMED` (Розброєно)
Фінал посадкової місії.
- Генератори сигналів керування ШІМ/DShot/CAN повністю вимикають передачу імпульсів на силові регулятори ESC.
- Мотори знеструмлюються і зупиняються.
- Автопілот блокує зміну станів до наступної ручної або програмної команди армінгу, запис польотного логу на SD-карту фіналізується.

Детальний математичний апарат фільтрації та архітектуру окремого компонента розібрано у вставці [автономного модуля детектування землі](root:sys-dron/avtoposadka/proj-ground-detector.md).

### Електромеханіка гальмування двигунів та DShot телеметрія

Після переходу в стан `LANDED` двигуни не повинні залишатися на холостому ходу, але й миттєво обривати керування небезпечно. Швидкість зупинки обертання роторів визначається типом силових регуляторів (ESC) та налаштуванням активного гальмування (*Active Braking / Damped Light*).

При пасивному вибігу (вільне обертання без замикання обмоток) великі пропелери діаметром 15–22 дюйми продовжують обертатися за інерцією протягом 1.5–2.5 секунд. Увесь цей час гвинти генерують залишкову підйомну силу, створюючи ризик здування апарата боковим вітром. При активному рекуперативному гальмуванні польотні ключі MOSFET почергово замикають фази двигуна, скидаючи кінетичну енергію ротора в силові конденсатори ESC. Оберти падають до нуля за 0.2–0.4 секунди.

Сучасні протоколи DShot (DShot300 / DShot600) з двонаправленою телеметрією (Bidirectional DShot) передають поточні оберти кожного мотора назад у польотний контролер із частотою до 1 кГц. Це дозволяє автопілоту верифікувати фізичну зупинку всіх роторів (`RPM == 0`) перед фінальною публікацією статусу `DISARMED`, виключаючи небезпеку травмування наземного персоналу.

### Крайові випадки та аеродинамічні пастки приземлення

Під час польотів у реальних атмосферних умовах автопілот стикається з низкою специфічних фізичних ефектів, які за відсутності належного захисту призводять до аварій.

#### 1. Екранний ефект (Ground Effect Cushion)
Коли відстань між пропелерами та підстильною поверхнею стає меншою за діаметр ротора (`h < D_prop`), вільне розсіювання індукованого струменя блокується твердою землею.

```
               ПОЛІТ У ВІЛЬНОМУ ПОВІТРІ                 ЕКРАННИЙ ЕФЕКТ (h < D)
                      ▲ Тяга T                                 ▲ Тяга T + ΔT
                   ┌──┴──┐                                  ┌──┴──┐
                ═══╡     ╞═══                            ═══╡     ╞═══
                  ╱       ╲                                ╱       ╲
                 ▼         ▼                              ▼         ▼
             (Вільний схід струменя)                   ═══════════════════ ◄── Стрибок тиску (+ΔP)
                                                       ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒ ◄── Тверда земля
```

За моделлю Чізмана-Беннетта (*Cheeseman-Bennett model*) відношення тяги поблизу землі T до тяги у вільному повітрі `T_inf` при незмінній споживаній потужності описується формулою:

```
T / T_inf = 1 / (1 - (R / (4 * h))^2)   [модель Чізмана-Беннетта екранного ефекту]
```

де R — радіус пропелера, h — висота осі ротора над землею.

При наближенні до поверхні (`h -> R`) ефективна підйомна сила ротора зростає на 15–25%. Індукований скіс потоку зменшується, лопаті працюють із вищим ефективним кутом атаки, і дрон починає «плавати» над землею на висоті 15–30 см. Якщо автопілот не має спеціального контуру посадкового притискання, висотний регулятор може зависнути в рівновазі, і дрон ніколи не опуститься на землю.

#### 2. Барометрична бульбашка надлишкового тиску (Positive Pressure Bubble)
Гальмування високошвидкісного низхідного струменя від пропелерів об землю створює під днищем фюзеляжу зону підвищеного статичного тиску. За рівнянням Бернуллі динамічний напір струменя переходить у надлишковий статичний тиск:

```
Delta_P = 0.5 * rho * v_downwash^2   [надлишковий тиск повітряної подушки Delta_P = 2..10 Па]
Delta_h = -Delta_P / (rho * g)       [уявне просідання за барометром Delta_h ≈ -0.084 м/Па]
```

Бортовий барометр всередині корпусу вимірює тиск, характерний для висоти, яка на 20–80 см **нижча** за реальну висоту апарата.

```
       БЕЗ ЗАХИСТУ ВІД GROUND EFFECT              З АДАПТИВНИМ EKF (EKF_GND_EFF_DZ)
┌─────────────────────────────────────────┐  ┌─────────────────────────────────────────┐
│ 1. Дрон входить у зону h < 1.0 м        │  │ 1. Дрон входить у зону h < 1.5 м        │
│ 2. Барометр фіксує +ΔP (ріст тиску)     │  │ 2. Далекомір (LiDAR) підтверджує h_terr │
│ 3. EKF думає: «Дрон раптово просів!»    │  │ 3. EKF обнуляє вагу барометра R_baro→∞  │
│ 4. PID дає різкий газ -> Дрон підскакує │  │ 4. Спуск триває стабільно за далекоміром│
└─────────────────────────────────────────┘  └─────────────────────────────────────────┘
```

*Механізм захисту:* введення параметра мертвої зони екранного ефекту `EKF_GND_EFF_DZ` (зазвичай 1.5–2.0 м). Коли далекомір фіксує висоту `h < EKF_GND_EFF_DZ`, фільтр Калмана штучно збільшує дисперсію шуму барометра `R_baro -> inf`, повністю виключаючи барометричні інновації з розрахунку вертикального стану й спираючись суто на далекомір та оптичний потік.

#### 3. Посадка на похилу поверхню (Sloped Terrain Landing)
При посадці на схил із кутом нахилу `alpha = 10..25°` першою ґрунту торкається нагірна нога шасі. Якщо в цей момент контур стабілізації залишається повністю активним, він намагається горизонтувати раму, що викликає збільшення газу на підвітряних моторах і провокує перекидання.

*Алгоритм захисту від перекидання на схилі:*
- Детектування несиметричного контакту: якщо після часткового падіння тяги (`T < 0.6 * T_hover`) виникає різкий кутовий стрибок `|omega_roll| > 8°/s` або `|omega_pitch| > 8°/s`, контролер перемикається в режим демпфування кутів (*Slope Damping*).
- Кутові моменти обмежуються на 80%, а висотний контур примусово скидає газ до рівня `0.2 * T_hover`, змушуючи дрон під дією гравітації плавно опуститися на всі точки опори за нормаллю до схилу.

#### 4. Пружне підстрибування шасі (Chassis Bouncing & Chatter)
Карбонові трубки шасі мають високий коефіцієнт пружності. При контакті на швидкості `Vz = 0.6 м/с` деформація шасі накопичує потенціальну енергію, яка через 80–120 мс викидає дрон назад у повітря з прискоренням `az > 1.8g`.

Якщо алгоритм детектора землі використовує простий таймер, який скидається від будь-якого одиничного сплеску `az`, дрон потрапляє в режим циклічного стрибання по землі. Для усунення цього дефекту в просунутих детекторах застосовують витікаючий інтегратор довіри (*Leaky Integrator*), який накопичує впевненість у контакті й плавно фільтрує короткочасні відскоки.

#### 5. Посадка у шквалистий вітер
При посадці за бокового вітру 10–14 м/с автопілот нахиляє раму проти вітру на кут `theta = 15..25°` для компенсації зносу. У момент торкання виникає комбінована загроза: підвітряна опора торкається першою, а бокова сила вітру створює перекидний момент.

*Інваріант безпеки:* горизонтальні контури позиціювання зобов'язані утримувати нульову шляхову швидкість відносно землі (`V_xy_ground = 0`) аж до моменту переходу в стан `LANDED`. Будь-яке передчасне вимикання горизонтальної стабілізації призводить до того, що вітер перекидає дрон по поверхні бетону ще до зупинки моторів.

#### 6. Процедура аварійного переривання посадки (Landing Abort / Go-Around)
Якщо під час посадкового підкрадання виникає непередбачена перешкода (поява людини в зоні посадки, перекриття далекоміра пилом або виявлення нахилу поверхні понад 30 градусів), автопілот повинен мати можливість безпечного переривання посадки.

При надходженні команди Go-Around автомат детектора землі миттєво скидає всі накопичені таймери контакту, розморожує інтегратори кутових PID-регуляторів і переводить висотний контур у режим максимального вертикального підйому (`Vz_cmd = +2.5 м/с`) до досягнення безпечного ешелону очікування над точкою старту.

```c
#include <stdint.h>
#include <stdbool.h>
#include <math.h>

typedef enum {
    GD_STATE_IN_AIR = 0,
    GD_STATE_GROUND_CONTACT,
    GD_STATE_MAYBE_LANDED,
    GD_STATE_LANDED,
    GD_STATE_DISARMED
} ground_detector_state_t;

typedef struct {
    float max_velocity_z;         // Поріг вертикальної швидкості (м/с, зазвичай 0.15)
    float max_angular_rate_rad;   // Поріг кутової швидкості (рад/с, ~0.25 рад/с ≈ 14 град/с)
    float throttle_hover_ratio;   // Частка газу від висіння для детекту (зазвичай 0.30)
    float ground_effect_alt_m;    // Зона екранного ефекту (м, зазвичай 1.5)
    uint32_t contact_time_ms;     // Час підтвердження первинного контакту (мс, 500)
    uint32_t landed_time_ms;      // Час фіксації повного приземлення (мс, 1000)
    uint32_t disarm_timeout_ms;   // Таймаут лінійного гасіння і розброєння (мс, 500)
} ground_detector_config_t;

typedef struct {
    ground_detector_state_t state;
    ground_detector_config_t cfg;
    uint32_t contact_start_ms;
    uint32_t maybe_landed_start_ms;
    uint32_t landed_start_ms;
    float    throttle_output;
    bool     i_terms_frozen;
    bool     disarm_commanded;
} ground_detector_t;

void ground_detector_init(ground_detector_t *gd, const ground_detector_config_t *cfg) {
    gd->state = GD_STATE_IN_AIR;
    gd->cfg = *cfg;
    gd->contact_start_ms = 0;
    gd->maybe_landed_start_ms = 0;
    gd->landed_start_ms = 0;
    gd->throttle_output = 1.0f;
    gd->i_terms_frozen = false;
    gd->disarm_commanded = false;
}

// Періодичний виклик у контурі навігації (50 Гц / кожні 20 мс)
void ground_detector_update(ground_detector_t *gd,
                            float vz_actual,
                            float gyro_norm_rad,
                            float current_throttle,
                            float hover_throttle,
                            float altitude_m,
                            uint32_t now_ms) {
    
    // Розрахунок порога тяги від поточного рівня зависання
    float throttle_threshold = hover_throttle * gd->cfg.throttle_hover_ratio;
    
    // Перевірка базових фізичних умов контакту
    bool low_thrust = (current_throttle <= throttle_threshold);
    bool near_zero_vz = (fabsf(vz_actual) <= gd->cfg.max_velocity_z);
    bool gyro_quiet = (gyro_norm_rad <= gd->cfg.max_angular_rate_rad);
    bool physical_contact = low_thrust && near_zero_vz && gyro_quiet;

    switch (gd->state) {
        case GD_STATE_IN_AIR: {
            gd->i_terms_frozen = false;
            gd->disarm_commanded = false;

            if (physical_contact) {
                gd->state = GD_STATE_GROUND_CONTACT;
                gd->contact_start_ms = now_ms;
            }
            break;
        }

        case GD_STATE_GROUND_CONTACT: {
            if (!physical_contact) {
                // Відрив або порив вітру — повернення в повітря
                gd->state = GD_STATE_IN_AIR;
                break;
            }

            if ((now_ms - gd->contact_start_ms) >= gd->cfg.contact_time_ms) {
                gd->state = GD_STATE_MAYBE_LANDED;
                gd->maybe_landed_start_ms = now_ms;
                gd->i_terms_frozen = true; // Блокування розгону I-термів
            }
            break;
        }

        case GD_STATE_MAYBE_LANDED: {
            if (!physical_contact) {
                // Дрон підстрибнув або перекинувся
                gd->state = GD_STATE_IN_AIR;
                gd->i_terms_frozen = false;
                break;
            }

            if ((now_ms - gd->maybe_landed_start_ms) >= gd->cfg.landed_time_ms) {
                gd->state = GD_STATE_LANDED;
                gd->landed_start_ms = now_ms;
            }
            break;
        }

        case GD_STATE_LANDED: {
            // Лінійне плавне зниження обертів (Ramp down)
            uint32_t elapsed = now_ms - gd->landed_start_ms;
            if (elapsed < gd->cfg.disarm_timeout_ms) {
                float ramp_factor = 1.0f - ((float)elapsed / (float)gd->cfg.disarm_timeout_ms);
                gd->throttle_output = current_throttle * ramp_factor;
            } else {
                gd->throttle_output = 0.0f;
                gd->disarm_commanded = true;
                gd->state = GD_STATE_DISARMED;
            }
            break;
        }

        case GD_STATE_DISARMED:
        default: {
            gd->throttle_output = 0.0f;
            gd->disarm_commanded = true;
            gd->i_terms_frozen = true;
            break;
        }
    }
}
```

```cpp
#include <cstdint>
#include <cmath>
#include <algorithm>
#include <chrono>

enum class GroundDetectorState : uint8_t {
    InAir = 0,
    GroundContact,
    MaybeLanded,
    Landed,
    Disarmed
};

struct GroundDetectorConfig {
    float maxVelocityZ{0.15f};          // Поріг вертикальної швидкості (м/с)
    float maxAngularRateRad{0.25f};     // Поріг кутової швидкості (~14 град/с)
    float throttleHoverRatio{0.30f};    // Поріг газу (30% від газу зависання)
    float groundEffectAltM{1.50f};      // Висота зони екранного ефекту (м)
    std::chrono::milliseconds contactDuration{500};
    std::chrono::milliseconds landedDuration{1000};
    std::chrono::milliseconds disarmTimeout{500};
};

class GroundDetector {
public:
    using Milliseconds = std::chrono::milliseconds;

    explicit GroundDetector(const GroundDetectorConfig& config) noexcept
        : config_(config) {}

    void update(float vzActual,
                float gyroNormRad,
                float currentThrottle,
                float hoverThrottle,
                float altitudeM,
                Milliseconds now) noexcept {
        
        const float throttleThreshold = hoverThrottle * config_.throttleHoverRatio;
        const bool lowThrust = (currentThrottle <= throttleThreshold);
        const bool nearZeroVz = (std::abs(vzActual) <= config_.maxVelocityZ);
        const bool gyroQuiet = (gyroNormRad <= config_.maxAngularRateRad);
        const bool physicalContact = lowThrust && nearZeroVz && gyroQuiet;

        switch (state_) {
            case GroundDetectorState::InAir: {
                iTermsFrozen_ = false;
                disarmCommanded_ = false;

                if (physicalContact) {
                    state_ = GroundDetectorState::GroundContact;
                    contactStart_ = now;
                }
                break;
            }

            case GroundDetectorState::GroundContact: {
                if (!physicalContact) {
                    state_ = GroundDetectorState::InAir;
                    break;
                }

                if ((now - contactStart_) >= config_.contactDuration) {
                    state_ = GroundDetectorState::MaybeLanded;
                    maybeLandedStart_ = now;
                    iTermsFrozen_ = true;
                }
                break;
            }

            case GroundDetectorState::MaybeLanded: {
                if (!physicalContact) {
                    state_ = GroundDetectorState::InAir;
                    iTermsFrozen_ = false;
                    break;
                }

                if ((now - maybeLandedStart_) >= config_.landedDuration) {
                    state_ = GroundDetectorState::Landed;
                    landedStart_ = now;
                }
                break;
            }

            case GroundDetectorState::Landed: {
                const auto elapsed = now - landedStart_;
                if (elapsed < config_.disarmTimeout) {
                    const float rampFactor = 1.0f - (static_cast<float>(elapsed.count()) /
                                                     static_cast<float>(config_.disarmTimeout.count()));
                    throttleOutput_ = currentThrottle * rampFactor;
                } else {
                    throttleOutput_ = 0.0f;
                    disarmCommanded_ = true;
                    state_ = GroundDetectorState::Disarmed;
                }
                break;
            }

            case GroundDetectorState::Disarmed:
            default: {
                throttleOutput_ = 0.0f;
                disarmCommanded_ = true;
                iTermsFrozen_ = true;
                break;
            }
        }
    }

    [[nodiscard]] GroundDetectorState state() const noexcept { return state_; }
    [[nodiscard]] bool areITermsFrozen() const noexcept { return iTermsFrozen_; }
    [[nodiscard]] bool isDisarmCommanded() const noexcept { return disarmCommanded_; }
    [[nodiscard]] float throttleOutput() const noexcept { return throttleOutput_; }

private:
    GroundDetectorConfig config_;
    GroundDetectorState state_{GroundDetectorState::InAir};
    Milliseconds contactStart_{0};
    Milliseconds maybeLandedStart_{0};
    Milliseconds landedStart_{0};
    float throttleOutput_{1.0f};
    bool iTermsFrozen_{false};
    bool disarmCommanded_{false};
};
```
