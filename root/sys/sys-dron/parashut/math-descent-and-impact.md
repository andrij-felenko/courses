# 🧮 Розрахунок площі купола, динамічного навантаження та енергії приземлення

Цей розрахунковий апарат дозволяє точно обчислити проєкційну й конструктивну площу парашута, оцінити пікове динамічне перевантаження під час розкриття (opening shock load) та визначити кінетичну енергію контакту з землею для сертифікації безпілотника за стандартами ASTM F3322 та нормами EASA/FAA.

---

### Розрахунок проєкційної та конструктивної площі купола

Для забезпечення безпечного спуску апарата з усталеною вертикальною швидкістю `V_term` аеродинамічний опір розкритого купола повинен точно врівноважувати вагу безпілотника в повітряному середовищі:

```
F_d = F_g      [умова рівноваги сил при усталеному спуску]
0.5 · ρ · V_term² · S_p · C_d = m · g      [розгортання формули швидкісного напору та ваги]
```

Звідси необхідна ефективна проєкційна площа купола `S_p` (площа поперечного перерізу наповненого повітрям купола) виводиться аналітично:

```
S_p = (2 · m · g) / (ρ · C_d · V_term²)      [розрахунок необхідної проєкційної площі]
```

Де:
- `m` — повна злітна маса безпілотника (MTOW), кг;
- `g = 9.80665 м/с²` — прискорення вільного падіння;
- `ρ` — густина повітря (для стандартної атмосфери на рівні моря при температурі +15 °C приймається `ρ = 1.225 кг/м³`; для розрахунків у гарячому розрідженому повітрі на висоті 2000 м закладається консервативне значення `ρ ≈ 1.006 кг/м³`);
- `C_d` — коефіцієнт лобового опору обраної форми купола (`C_d ≈ 0.80` для плоского круглого, `C_d ≈ 1.40` для конічного, `C_d ≈ 1.65` для хрестоподібного);
- `V_term` — цільова вертикальна швидкість спуску, м/с.

Конструктивна площа тканини `S_0` (площа викрійки матеріалу в плоскому розгорнутому стані) більша за проєкційну площу через кривизну та втягування купола стропами. Коефіцієнт проєкції `k_p = S_p / S_0` залежить від аеродинамічного профілю:
- Для плоского круглого купола: `k_p ≈ 0.65–0.70`, отже `S_0 = S_p / 0.68 ≈ 1.47 · S_p`;
- Для напівсферичного купола: `k_p ≈ 0.50`, отже `S_0 = 2.0 · S_p`;
- Для хрестоподібного (cruciform) купола: `k_p ≈ 0.72–0.78`, отже `S_0 = S_p / 0.75 ≈ 1.33 · S_p`.

**Практичний розрахунок площі для мультиротора масою 6.0 кг:**
Задано: `m = 6.0 кг`, цільова швидкість `V_term = 3.6 м/с`, форма — хрестоподібна (`C_d = 1.65`, `k_p = 0.75`), густина `ρ = 1.225 кг/м³`.

```
S_p = (2 · 6.0 · 9.81) / (1.225 · 1.65 · 3.6²)
= 117.72 / (2.02125 · 12.96)      [підстановка параметрів]
= 117.72 / 26.1954
≈ 4.494 м²      [необхідна проєкційна площа купола]
```

Конструктивна площа тканини викрійки:

```
S_0 = S_p / k_p
= 4.494 / 0.75      [врахування коефіцієнта форми]
≈ 5.992 м² ≈ 6.0 м²      [площа розкрою парашутної тканини]
```

### Динамічне навантаження під час розкриття (Opening Shock Load)

У момент наповнення купола на високій швидкості падіння `V_deploy` виникає пікова гальмівна сила (opening shock load / snatch force), яка значно перевищує статичну вагу безпілотника. Недооцінка цієї сили призводить до обриву вуздечки кріплення, виривання анкерних болтів з карбонової рами або руйнування строп.

Пікова динамічна сила розкриття описується співвідношенням Пфланца (Pflanz formula):

```
F_peak = C_x · q_deploy · S_p · X_1      [загальне рівняння сили розкриття]
= 0.5 · C_x · ρ · V_deploy² · S_p · X_1      [розгортання швидкісного напору]
```

Де:
- `C_x` — коефіцієнт опору купола в процесі роздування (`C_x ≈ C_d`);
- `q_deploy = 0.5 · ρ · V_deploy²` — швидкісний напір у момент спрацьовування викиду;
- `X_1` — динамічний коефіцієнт форми наповнення (opening shock factor): для парашутів без рифлення `X_1 ≈ 1.4–1.8`; для куполів з еластичними амортизаторами строп `X_1 ≈ 1.1–1.3`.

Через відношення швидкостей пікове перевантаження `n_peak` (у одиницях `g`) виражається спрощеною формулою:

```
n_peak = F_peak / (m · g)
= X_1 · (V_deploy / V_term)²      [вираз пікового перевантаження через відношення швидкостей]
```

**Розрахунок пікового зусилля при аварії на швидкості 25 м/с (дрон 6.0 кг):**
Якщо парашут розкривається в горизонтальному польоті на швидкості `V_deploy = 25 м/с` при `V_term = 3.6 м/с` та `X_1 = 1.4`:

```
n_peak = 1.4 · (25.0 / 3.6)²
= 1.4 · 6.944²      [відношення швидкостей]
= 1.4 · 48.225
≈ 67.5 g      [пікове розрахункове перевантаження без амортизації]
```

Теоретична пікова сила:

```
F_peak = m · g · n_peak
= 6.0 · 9.81 · 67.5      [розрахунок зусилля на вуздечку]
≈ 3973 Н ≈ 4.0 кН      [динамічний ривок близько 400 кгс]
```

> ⚠️ **Інженерний висновок:** Прямий жорсткий зв'язок купола з рамою при такому ривку вирве кріплення. Саме тому парашутні вуздечки обов'язково оснащують **розривними текстильними амортизаторами (tear-webbing / shock-cord)** або налаштовують сповільнене витягування строп зі слайдером. Амортизатор обмежує пікове перевантаження до безпечного рівня `n_peak ≤ 10–12 g` (`F_peak ≤ 600–700 Н`), поглинаючи надлишкову кінетичну енергію шляхом розриву каліброваних стібків.

### Час наповнення та мінімальна втрата висоти

Повний час від фіксації аварії до виходу на усталену швидкість `t_total` складається з чотирьох послідовних фаз:

```
t_total = t_detect + t_eject + t_stretch + t_inflate      [структура часу порятунку]
```

1. `t_detect = 0.08–0.12 с` — алгоритмічна верифікація вільного падіння / tumble в PTU;
2. `t_eject = 0.02–0.05 с` — спрацьовування піропатрона або розтискання пружини;
3. `t_stretch = 0.15–0.25 с` — вихід фала та повне натягування строп (Line Stretch);
4. `t_inflate` — аеродинамічне наповнення купола повітрям за емпіричною формулою О'Хари:

```
t_inflate = (n · D_0) / V_stretch      [формула часу наповнення О'Хари]
```

Де:
- `D_0 = √( (4 · S_0) / π )` — номінальний діаметр купола (`D_0 = √( (4 · 6.0) / 3.1416 ) ≈ 2.76 м`);
- `n` — коефіцієнт наповнення (`n ≈ 6.0` для круглого, `n ≈ 4.5` для хрестоподібного);
- `V_stretch` — швидкість апарата в момент натягування строп (при падінні з зависання `V_stretch ≈ g · (t_detect + t_eject + t_stretch) ≈ 9.81 · 0.35 ≈ 3.43 м/с`).

```
t_inflate = (4.5 · 2.76) / 3.43
= 12.42 / 3.43      [розрахунок часу наповнення]
≈ 3.62 с      [час наповнення при низькій швидкості скидання]
```

Під час наповнення купол створює наростаючий опір, тому середня швидкість зниження на фазі наповнення становить `V_avg ≈ 0.5 · (V_stretch + V_term)`.

Сумарна втрата висоти `h_loss` під час аварійного викиду з нульової початкової швидкості (зависання):

```
h_freefall = 0.5 · g · (t_detect + t_eject + t_stretch)²
= 0.5 · 9.81 · (0.10 + 0.03 + 0.20)²      [вільне падіння до натягу строп]
= 0.5 · 9.81 · 0.33²
= 4.905 · 0.1089
≈ 0.53 м      [втрата висоти до натягування строп]
```

Втрата висоти під час роздування купола:

```
h_inflate = V_avg · t_inflate
≈ 5.5 м / с · 1.8 с      [інтеграл швидкості під час гальмування]
≈ 9.9 м      [втрата висоти до повного розкриття]
```

Мінімальна безпечна висота спрацьовування з урахуванням запасу на маятникове заспокоєння (`h_margin ≈ 3–5 м`):

```
h_min = h_freefall + h_inflate + h_margin
= 0.53 + 9.9 + 4.0      [сумарна мінімальна висота]
≈ 14.43 м ≈ 15 м      [мінімальна сертифікаційна висота розкриття]
```

### Кінетична енергія удару та критерії травматизму

Кінетична енергія зіткнення безпілотника з перешкодою чи поверхнею землі під куполом визначається виключно масою апарата та вертикальною швидкістю спуску:

```
E_k = 0.5 · m · V_term²      [кінетична енергія приземлення]
```

У міжнародних авіаційних стандартах безпеки (ASTM F3322, FAA 14 CFR Part 107 Category 2/3, EASA SORA MoC 2511) встановлено чіткі пороги кінетичної енергії для оцінки ризику летальності при падінні апарата на людей:

1. **Критичний поріг важких травм (80 Дж):** Падіння твердого предмета з енергією `E_k ≥ 80 Дж` на незахищену людину призводить до пробиття черепа з імовірністю понад 50% (за критерієм Shelbourne / Head Injury Criterion). Парашутна система повинна гарантувати `E_k < 80 Дж` для польотів над скупченнями людей.
2. **Поріг малої травматичності (34 Дж / 25 ft-lbs):** Найсуворіший норматив FAA Part 107 (Category 2 OOP — Operations Over People без сертифікації конструкції). Гарантує відсутність серйозних травм при випадковому контакті.

#### Зведена таблиця характеристик для безпілотників різної маси

Нижче наведено параметри парашутних систем для типових вагових класів БПЛА за умови забезпечення швидкості спуску `V_term = 3.5 м/с` (хрестоподібний купол `C_d = 1.65`, `ρ = 1.225 кг/м³`):

| Маса БПЛА `m`, кг | Проєкційна площа `S_p`, м² | Конструктивна площа `S_0`, м² | Енергія удару `E_k`, Дж | Відповідність нормі ASTM / FAA |
|---|---|---|---|---|
| **1.5 кг** (DJI Mavic 3 Enterprise) | 1.19 м² | 1.58 м² | **9.2 Дж** | Повна безпека (`E_k < 34 Дж`) |
| **4.0 кг** (DJI Matrice 30) | 3.16 м² | 4.22 м² | **24.5 Дж** | Повна безпека (`E_k < 34 Дж`) |
| **9.5 кг** (DJI Matrice 350 RTK) | 7.51 м² | 10.01 м² | **58.2 Дж** | Дозволено над людьми (`E_k < 80 Дж`) |
| **15.0 кг** (Важкий розвідник / VTOL) | 11.86 м² | 15.82 м² | **91.9 Дж** | Потребує `V_term ≤ 3.2 м/с` для `E_k < 80 Дж` |
| **25.0 кг** (Максимум класу Part 107) | 19.77 м² | 26.36 м² | **153.1 Дж** | Потребує `V_term ≤ 2.5 м/с` або деформівних зон |

Для важких апаратів масою `m > 12–15 кг` досягнення порогу 80 Дж виключно за рахунок збільшення купола вимагає надмірно великої площі тканини (`S_0 > 25–30 м²`), що суттєво обтяжує безпілотник. У таких конструкціях застосовують комбінований захист: парашут гальмує апарат до швидкості `V_term ≈ 4.0–4.5 м/с`, а залишок кінетичної енергії гаситься деформівними посадковими опорами (crumple zones) або надувними балонетами (airbags).
