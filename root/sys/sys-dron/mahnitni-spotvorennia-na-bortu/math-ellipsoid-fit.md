# 🧮 Алгебраїчне вписування еліпсоїда та матричне відновлення сфери

Магнітометр, закріплений на рухомому апараті, під час обертання у довільних просторових орієнтаціях видає відліки вектора магнітної індукції. В ідеальному однорідному полі Землі напруженістю `B₀` множина кінців цих векторів утворює ідеальну сферу радіусом `B₀` із центром у початку координат `(0, 0, 0)`. Проте через наявність на борту постійних магнітних полів (тверде залізо) та феромагнітних матеріалів з анізотропною магнітною сприйнятливістю (м'яке залізо) виміряні точки лягають на поверхню тривісного еліпсоїда, центр якого зміщений на вектор `V_hard`, а головні осі деформовані та повернуті матрицею `W_soft`.

Завдання калібрування полягає у визначенні геометрії цього еліпсоїда за накопиченою хмарою експериментальних точок та знаходженні зворотного лінійного перетворення, яке переводить спотворений еліпсоїд назад у вихідну сферу.

## Алгебраїчна модель еліпсоїда у тривимірному просторі

Загальне рівняння поверхні другого порядку (тривимірної квадрики) у декартових координатах `x = (x, y, z)ᵀ` записується у вигляді:

```
F(x, y, z) = a·x² + b·y² + c·z² + 2·d·x·y + 2·e·x·z + 2·f·y·z + 2·g·x + 2·h·y + 2·k·z + j = 0
```

У матрично-векторній формі це рівняння набуває компактного вигляду:

```
xᵀ · A · x + 2 · b_vecᵀ · x + c_const = 0
```

де симетрична матриця форми `A` розміром 3×3, вектор лінійних членів `b_vec` розміром 3×1 та скаляр `c_const` мають структуру:

```
A = [ a  d  e ]
    [ d  b  f ]
    [ e  f  c ]

b_vec = [ g ]
        [ h ]
        [ k ]

c_const = j
```

Щоб поверхня другого порядку була дійсним еліпсоїдом, матриця `A` повинна бути додатно визначеною (усі її власні значення є строго додатними: `λ₁ > 0, λ₂ > 0, λ₃ > 0`), а детермінант повної розширеної матриці квадрики повинен задовольняти умову обмеженості об'єму. Якщо хоча б одне власне значення від'ємне або дорівнює нулю, поверхня вироджується в однопорожнинний чи двопорожнинний гіперболоїд, конус або еліптичний циліндр, що виникає при спробі калібрування за точками, зібраними лише в одній площині.

## Алгебраїчна та геометрична нев'язка: постановка оптимізації

Існує принципова відмінність між чистою геометричною відстанню від експериментальної точки до поверхні еліпсоїда та алгебраїчною нев'язкою:
- **Геометрична нев'язка:** ортогональна евклідова відстань `d_geom = ||x_i − x_closest||`, де `x_closest` — найближча точка на поверхні еліпсоїда. Мінімізація суми квадратів геометричних відстаней є нелінійною задачею числової оптимізації, яка вимагає ітераційного методу Гаусса-Ньютона або Левенберга-Марквардта і чутлива до початкового наближення.
- **Алгебраїчна нев'язка:** значення функції квадрики `F(x_i, y_i, z_i)`. Мінімізація алгебраїчної похибки зводиться до прямої задачі лінійного методу найменших квадратів, що розв'язується в один крок за фіксований час без ітерацій.

Для надійного вписування на борту безпілотника використовують алгебраїчний підхід. Нехай маємо вибірку з `N` тривимірних вимірювань `(x_i, y_i, z_i)`, де `i = 1, ..., N` (причому `N ≥ 9`). Для кожного відліку алгебраїчна похибка дорівнює значенню функції `F(x_i, y_i, z_i)`.

Введемо 10-вимірний вектор параметрів квадрики `v`:

```
v = [ a, b, c, 2·d, 2·e, 2·f, 2·g, 2·h, 2·k, j ]ᵀ
```

Та сформуємо для кожного вимірювання рядок матриці плану `D_i`:

```
D_i = [ x_i², y_i², z_i², x_i·y_i, x_i·z_i, y_i·z_i, x_i, y_i, z_i, 1 ]
```

Повна матриця плану `D` розміром `N × 10` складається з рядків `D_i`. Задача мінімізації суми квадратів алгебраїчних нев'язок має вигляд:

```
min_v || D · v ||²    за умови нормування вектора v
```

Оскільки рівняння квадрики є однорідним (множення всіх коефіцієнтів на ненульовий скаляр не змінює геометрію еліпсоїда), для усунення тривіального нульового розв'язку фіксують вільний член `j = -1`. Якщо початок координат знаходиться всередині еліпсоїда (що завжди виконується для реальних магнітометрів при помірних зсувах твердого заліза), вільний член строго від'ємний після вибору додатної визначеності матриці `A`.

Розділимо вектор параметрів `v` на 9-вимірний вектор форми й зсуву `p` та фіксований скаляр:

```
p = [ a, b, c, 2·d, 2·e, 2·f, 2·g, 2·h, 2·k ]ᵀ
j = -1
```

Матриця плану `D` відповідно розбивається на підматрицю `H` розміром `N × 9` та одиничний вектор:

```
H_i = [ x_i², y_i², z_i², x_i·y_i, x_i·z_i, y_i·z_i, x_i, y_i, z_i ]
```

Тоді система рівнянь зводиться до класичної лінійної задачі найменших квадратів:

```
H · p ≈ 1_vec
```

де `1_vec` — вектор-стовпчик з одиниць розміром `N × 1`. Розв'язок за нормальними рівняннями Гаусса записується через псевдообернення:

```
p = (Hᵀ · H)⁻¹ · Hᵀ · 1_vec   [розв'язок нормальних рівнянь МНК]
```

Матриця `Hᵀ · H` має фіксований розмір 9×9 і формується послідовним додаванням зовнішніх добутків `H_iᵀ · H_i` для кожного нового вимірювання, що усуває потребу зберігати вихідну вибірку точок у пам'яті.

## Виведення центру еліпсоїда та геометричних осей

Отримавши вектор оцінених коефіцієнтів `p`, відновлюємо матрицю `A`, вектор `b_vec` та вільний член `c_const = -1`.

Геометричний центр еліпсоїда `x₀ = V_hard` є точкою симетрії поверхні. Знайдемо градієнт функції квадрики `F(x)` за вектором координат `x`:

```
∇F(x) = 2 · A · x + 2 · b_vec
```

У центрі симетрії еліпсоїда градієнт дорівнює нулю, оскільки протилежні точки поверхні симетричні відносно центру:

```
2 · A · x₀ + 2 · b_vec = 0
A · x₀ = −b_vec              [умова екстремуму в центрі квадрики]
x₀ = −A⁻¹ · b_vec            [вектор центру твердого заліза V_hard]
```

Тепер перенесемо початок координат у знайдений центр еліпсоїда, зробивши заміну змінних `x' = x − x₀`. Тоді вихідне рівняння перетворюється у центровану форму:

```
(x' + x₀)ᵀ · A · (x' + x₀) + 2 · b_vecᵀ · (x' + x₀) + c_const = 0
x'ᵀ · A · x' + 2 · (A · x₀ + b_vec)ᵀ · x' + (x₀ᵀ · A · x₀ + 2 · b_vecᵀ · x₀ + c_const) = 0
```

Оскільки `A · x₀ + b_vec = 0`, лінійний член за `x'` тотожно зникає. Враховуючи, що `b_vec = −A · x₀`, вираз у дужках спрощується:

```
x₀ᵀ · A · x₀ + 2 · (−A · x₀)ᵀ · x₀ + c_const = −x₀ᵀ · A · x₀ + c_const
```

Підставляючи це значення назад у рівняння:

```
x'ᵀ · A · x' = x₀ᵀ · A · x₀ − c_const
(x − V_hard)ᵀ · A · (x − V_hard) = V_hardᵀ · A · V_hard − c_const
```

Позначимо скалярний масштабний множник як `scale`:

```
scale = V_hardᵀ · A · V_hard − c_const
```

Оскільки ми обрали `c_const = -1`, маємо розрахункову формулу:

```
scale = V_hardᵀ · A · V_hard + 1   [масштабний коефіцієнт рівняння форми]
```

Поділивши обидві частини рівняння на `scale`, отримуємо канонічну безрозмірну форму матриці еліпсоїда:

```
M = (1 / scale) · A
(x − V_hard)ᵀ · M · (x − V_hard) = 1   [канонічне центроване рівняння еліпсоїда]
```

Матриця `M` розміром 3×3 повністю визначає просторову форму, довжини півосей та орієнтацію головних осей еліпсоїда у зв'язаній системі координат апарата.

## Відновлення сфери через спектральний розклад та матричний корінь

Симетрична додатно визначена матриця `M` описує геометрію деформації. Оскільки `M` симетрична, вона допускає спектральний розклад:

```
M = R · Λ · Rᵀ
```

де `R` — ортогональна матриця власних векторів (матриця повороту головних осей еліпсоїда відносно осей давача), а `Λ = diag(λ₁, λ₂, λ₃)` — діагональна матриця власних значень. Довжини півосей еліпсоїда дорівнюють `r_k = 1 / √λ_k`.

Калібрувальна трансформація повинна перевести центрований вектор `(x − V_hard)` у вектор `x_sphere`, що лежить на сфері радіусом `B₀`:

```
x_sphereᵀ · x_sphere = B₀²
```

Підставимо лінійну заміну `x_sphere = T · (x − V_hard)` у рівняння сфери:

```
(T · (x − V_hard))ᵀ · (T · (x − V_hard)) = B₀²
(x − V_hard)ᵀ · (Tᵀ · T) · (x − V_hard) = B₀²
(x − V_hard)ᵀ · ((1 / B₀²) · Tᵀ · T) · (x − V_hard) = 1
```

Порівнюючи цей результат із центрованим рівнянням еліпсоїда `(x − V_hard)ᵀ · M · (x − V_hard) = 1`, отримуємо фундаментальне матричне співвідношення для калібрувальної матриці `T`:

```
(1 / B₀²) · Tᵀ · T = M
Tᵀ · T = B₀² · M
```

Один із точних симетричних розв'язків задається через матричний квадратний корінь:

```
T = B₀ · M^(1/2) = B₀ · R · diag(√λ₁, √λ₂, √λ₃) · Rᵀ
```

## Факторизація Холецького як обчислювально ефективна альтернатива

Обчислення спектрального розкладу (знаходження власних значень і власних векторів матриці 3×3 через коріння кубічного характеристичного многочлена за формулами Кардано або ітераціями Якобі) вимагає значної кількості тригонометричних функцій та ітерацій.

Для вбудованих мікроконтролерів без апаратного прискорювача лінійної алгебри застосовують факторизацію Холецького додатно визначеної матриці `M`:

```
M = L · Lᵀ                   [нижньотрикутний розклад Холецького]
```

де `L` — нижня трикутна матриця. Підставляючи цей розклад у матричне співвідношення:

```
Tᵀ · T = B₀² · (L · Lᵀ) = (B₀ · L) · (B₀ · Lᵀ) = (B₀ · Lᵀ)ᵀ · (B₀ · Lᵀ)
```

Звідси шукана матриця компенсації м'якого заліза набуває вигляду верхньої трикутної матриці:

```
T = B₀ · Lᵀ                  [компенсаційна матриця прямого ходу]
```

Оскільки матриця `T` є верхньотрикутною, застосування корекції до кожного виміряного вектора під час польоту потребує лише 6 операцій множення та 3 операцій додавання замість 9 множень у випадку загальної матриці:

```
B_cal_x = T₁₁ · (B_raw_x − V_x) + T₁₂ · (B_raw_y − V_y) + T₁₃ · (B_raw_z − V_z)
B_cal_y =                          T₂₂ · (B_raw_y − V_y) + T₂₃ · (B_raw_z − V_z)
B_cal_z =                                                   T₃₃ · (B_raw_z − V_z)
```

## Числова стійкість та обумовленість матриці накопичення

На практиці якість оцінки параметрів квадрики критично залежить від числа обумовленості матриці `Hᵀ · H`. Якщо просторові вимірювання охоплюють лише малу ділянку сфери (наприклад, сектор менше 90° за тілесним кутом), матриця `Hᵀ · H` стає майже виродженою (ill-conditioned), а число її обумовленості перевищує `10⁶`. У такому випадку дрібний шум датчика амплітудою в 0.2 мкТл призводить до похибки визначення центру `V_hard` у сотні мікротесла.

Для гарантії числової стійкості на борту застосовують попереднє масштабування координат: перед внесенням у матрицю плану всі компоненти ділять на характерний масштаб геомагнітного поля (наприклад, `s = 50.0 мкТл`). Це вирівнює порядки величин членів четвертого степеня `(x/s)⁴` та лінійних членів `(x/s)`, запобігаючи втраті значущих розрядів при додаванні чисел з рухомою комою одинарної точності (float32).
