# 🧮 Розрахунок тензора інерції борту та вплив компонування на контури стабілізації

Розподіл компонентів на рамі безпілотного апарата визначає не лише статичне положення центру мас, але й тензор моментів інерції твердого тіла, який безпосередньо входить у передатну функцію об'єкта керування та обмежує граничну смугу пропускання PID-регуляторів кутових швидкостей.

> 🔧 **Навіщо це.** Якщо розмістити важкі елементи (акумуляторну батарею, корисне навантаження, регулятори) на віддаленні від центру обертання, моменти інерції за осями крену, тангажу та рискання зростають пропорційно квадрату відстані. У результаті для отримання того самого кутового прискорення двигуни змушені розвивати значно більший диференційний момент тяги. Це призводить до передчасного насичення моторів, виникнення фазового запізнення в контурі керування кутовою швидкістю, перегріву обмоток через роботу D-компонента та зриву автопілота в автоколивання під час різких маневрів або поривів вітру.

### Тензор інерції твердого тіла в зв'язаній системі координат

У тривимірному просторі динаміка обертання жорсткого тіла апарата відносно зв'язаної системи координат `Oxyz` (де вісь `Ox` спрямована вперед по поздовжній осі фюзеляжу, `Oy` — праворуч по розмаху крила або поперечних променях, `Oz` — униз перпендикулярно площині апарата) описується симетричною матрицею тензора інерції розмірністю `3×3`:

```
    [  I_xx  -I_xy  -I_xz ]
I = [ -I_yx   I_yy  -I_yz ]
    [ -I_zx  -I_zy   I_zz ]
```

Головні діагональні елементи `I_xx`, `I_yy`, `I_zz` називаються осьовими моментами інерції відносно осей крену (англ. *roll*), тангажу (англ. *pitch*) та рискання (англ. *yaw*). Недіагональні елементи `I_xy = I_yx`, `I_xz = I_zx`, `I_yz = I_zy` називаються відцентровими моментами інерції (англ. *products of inertia*) і характеризують ступінь динамічної асиметрії розподілу мас.

Для дискретної системи, що складається з `N` точкових мас `m[k]` з координатами `(x[k], y[k], z[k])` відносно центру мас, кожен елемент тензора обчислюється як сума:

```
I_xx = ∑ m[k] · (y[k]² + z[k]²)      [момент інерції відносно осі крену Roll]
I_yy = ∑ m[k] · (x[k]² + z[k]²)      [момент інерції відносно осі тангажу Pitch]
I_zz = ∑ m[k] · (x[k]² + y[k]²)      [момент інерції відносно осі рискання Yaw]

I_xy = ∑ m[k] · x[k] · y[k]          [відцентровий момент у площині Oxy]
I_xz = ∑ m[k] · x[k] · z[k]          [відцентровий момент у площині Oxz]
I_yz = ∑ m[k] · y[k] · z[k]          [відцентровий момент у площині Oyz]
```

Якщо компонування апарата спроєктоване симетрично відносно поздовжньої площини `Oxz` (ліва та права половини дрона дзеркальні), відцентрові моменти `I_xy` та `I_yz` дорівнюють нулю. Якщо апарат також має симетрію за площиною `Oyz` (передня та задня частини), відцентровий момент `I_xz` також прямує до нуля, і зв'язані осі збігаються з головними осями інерції.

### Теорема Гюйгенса — Штейнера для складеного борту

Більшість вузлів безпілотника мають власні скінченні габарити (наприклад, акумуляторний блок прямокутної форми або циліндричний статор безколекторного двигуна). За теоремою Гюйгенса — Штейнера (теоремою про паралельне перенесення осей), сумарний момент інерції `i`-го компонента масою `m_i` відносно загального центру мас апарата складається з власного моменту інерції компонента відносно його власного центру мас `I_self` та додаткового доданка, пропорційного квадрату відстані `d_i` від його центру мас до головної осі обертання:

```
I_total = I_self + m_i · d_i²      [теорема Гюйгенса — Штейнера про паралельні осі]
```

Для прямокутного акумулятора масою `m_bat` з розмірами `a` (довжина вздовж `x`), `b` (ширина вздовж `y`) та `c` (висота вздовж `z`), зміщеного від центру мас апарата на вектор `(x_b, y_b, z_b)`, компоненти інерції мають вигляд:

```
I_xx_bat = (1/12) · m_bat · (b² + c²) + m_bat · (y_b² + z_b²)      [інерція батареї за віссю X]
I_yy_bat = (1/12) · m_bat · (a² + c²) + m_bat · (x_b² + z_b²)      [інерція батареї за віссю Y]
I_zz_bat = (1/12) · m_bat · (a² + b²) + m_bat · (x_b² + y_b²)      [інерція батареї за віссю Z]
```

### Розрахунковий приклад: 7-дюймовий квадрокоптер

Порівняємо два варіанти компонування для одного й того самого 7-дюймового квадрокоптера загальною злітною масою `M = 1.30 кг` (база моторів по діагоналі `D = 295 мм`, радіус винесення моторів `r_m = 0.1475 м`).

Склад компонентів:
1. Рама з карбону та кріплення: `m_frame = 0.20 кг`, радіус інерції `r_f ≈ 0.08 м`.
2. Чотири двигуни 2806.5 з пропелерами: `4 × 0.055 кг = 0.22 кг`, координати моторів: `(±0.104, ±0.104, 0.00) м`.
3. Політний контролер, 4-in-1 ESC, VTX, джгути: `m_elec = 0.13 кг`, розташовані в центрі `(0.0, 0.0, 0.0)`.
4. Акумуляторна батарея LiPo 6S 4000 mAh: `m_bat = 0.55 кг`, габарити `a = 0.14 м`, `b = 0.045 м`, `c = 0.045 м`.
5. Корисне навантаження (курсова камера високої роздільної здатності з передавачем): `m_cam = 0.20 кг`.

#### Варіант А: Концентроване компонування
Батарея закріплена строго по центру мас на нижній палубі (`x_b = 0.00 м`, `y_b = 0.00 м`, `z_b = 0.02 м`). Камера встановлена на мінімальному виносі в носовій частині (`x_c = 0.06 м`, `y_c = 0.00 м`, `z_c = 0.00 м`).

Обчислимо внесок кожного елемента в момент інерції за віссю тангажу `I_yy`:

```
I_yy_frame ≈ (1/2) · m_frame · r_f²
= 0.5 · 0.20 · (0.08)²                 [підстановка маси й радіуса інерції рами]
= 0.10 · 0.0064                        [множення на квадрат радіуса]
= 0.00064 кг·м²                        [інерція карбонової рами]

I_yy_motors = 4 · m_motor · x_m²
= 4 · 0.055 · (0.104)²                 [підстановка 4 моторів на плечі 104 мм]
= 0.22 · 0.010816                      [піднесення плеча до квадрата]
≈ 0.00238 кг·м²                        [сумарна інерція моторів за тангажем]

I_yy_bat = (1/12) · m_bat · (a² + c²) + m_bat · (x_b² + z_b²)
= (1/12) · 0.55 · ((0.14)² + (0.045)²) + 0.55 · ((0.00)² + (0.02)²)  [підстановка розмірів і зміщення]
= 0.04583 · (0.0196 + 0.002025) + 0.55 · 0.0004                      [власна геометрія + зміщення по Z]
= 0.04583 · 0.021625 + 0.000220                                       [розрахунок власної інерції блока]
= 0.000991 + 0.000220                                                 [додавання Штейнерівського доданка]
≈ 0.00121 кг·м²                                                       [інерція батареї в центрі]

I_yy_cam = m_cam · x_c²
= 0.20 · (0.06)²                       [камера масою 200 г на плечі 60 мм]
= 0.20 · 0.0036                        [множення на квадрат виносу]
= 0.00072 кг·м²                        [інерція камери]

I_yy_total_A = I_yy_frame + I_yy_motors + I_yy_bat + I_yy_cam
= 0.00064 + 0.00238 + 0.00121 + 0.00072  [підсумовування всіх часток]
= 0.00495 кг·м²                          [повний момент інерції за тангажем]
```

#### Варіант Б: Рознесене компонування
Батарея зміщена назад на консоль для вирівнювання важкої камери на довгому носовому підвісі: `x_b = -0.12 м`, `x_c = +0.16 м`.

Перерахуємо моменти інерції зміщених мас:

```
I_yy_bat_B = (1/12) · m_bat · (a² + c²) + m_bat · (x_b² + z_b²)
= 0.000991 + 0.55 · ((-0.12)² + (0.02)²)   [підстановка виносу батареї на 120 мм]
= 0.000991 + 0.55 · (0.0144 + 0.0004)      [обчислення квадрата відстані]
= 0.000991 + 0.55 · 0.0148                 [множення маси на квадрат плеча]
= 0.000991 + 0.008140                      [різке зростання Штейнерівського члена]
≈ 0.00913 кг·м²                            [інерція батареї на консолі]

I_yy_cam_B = m_cam · x_c²
= 0.20 · (0.16)²                           [камера на довгому виносі 160 мм]
= 0.20 · 0.0256                            [піднесення плеча до квадрата]
= 0.00512 кг·м²                            [інерція винесеної камери]

I_yy_total_B = I_yy_frame + I_yy_motors + I_yy_bat_B + I_yy_cam_B
= 0.00064 + 0.00238 + 0.00913 + 0.00512    [підсумовування компонентів рознесеного борту]
= 0.01727 кг·м²                            [сумарний момент інерції рознесеного варіанта]
```

Порівняння результатів:
```
I_yy_total_B / I_yy_total_A
= 0.01727 / 0.00495      [відношення моментів інерції]
≈ 3.49                   [зростання інерції у 3.49 раза]
```

Рознесення важких компонентів збільшило момент інерції за тангажем у `3.49 раза` при незмінній сумарній злітної масі апарата.

### Зв'язок моменту інерції з динамікою контуру PID

Кутове прискорення `α` твердого тіла під дією керуючого моменту `τ`, створюваного парою протилежних двигунів, описується другим законом Ньютона для обертального руху:

```
τ = I · α          [основне рівняння динаміки обертання]
α = τ / I          [кутове прискорення апарата]
```

Передатна функція об'єкта керування за кутовою швидкістю `ω(s)` від керуючого моменту `τ(s)` у частотній області Лапласа має вигляд інтегруючої ланки першого порядку:

```
G(s) = ω(s) / τ(s) = 1 / (I · s)      [передатна функція кутової швидкості]
```

При замкненні контуру пропорційно-диференційним регулятором з коефіцієнтом підсилення швидкості `K_p` характеристичне рівняння замкненої системи визначає смугу пропускання контуру `ω_c` (частоту зрізу одиничного підсилення):

```
ω_c = K_p / I      [частота зрізу контуру швидкості]
```

Для збереження стабільності та демпфування час реакції контуру `t_settle ≈ 3 / ω_c` повинен бути якомога меншим. У концентрованому компонуванні А (`I = 0.00495 кг·м²`) при базовому підсиленні `K_p = 0.18 Н·м / (рад/с)`:

```
ω_c_A = 0.18 / 0.00495
≈ 36.36 рад/с (5.78 Гц)      [смуга пропускання концентрованого варіанта]
```

Щоб досягти такої самої смуги пропускання у рознесеному компонуванні Б (`I = 0.01727 кг·м²`), автопілот змушений збільшити пропорційний коефіцієнт `K_p` у `3.49 раза` — до `K_p = 0.628 Н·м / (рад/с)`.

Однак диференційний коефіцієнт `K_d`, який компенсує інерційність і гасить коливання, також зростає пропорційно `I`. Високий `K_d` підсилює високочастотні шуми гіроскопа IMU:

```
τ_D(t) = K_d · (dω / dt)      [керуючий вплив диференційної ланки]
```

Шум датчика з амплітудою `δω` на частоті вібрацій моторів `f_vib = 200 Гц` (`ω_vib = 1256 рад/с`) породжує високочастотну пульсацію моменту:

```
δτ = K_d · ω_vib · δω      [амплітуда високочастотної пульсації моменту]
```

При `3.5-кратному` збільшенні `K_d` амплітуда високочастотного струму в обмотках двигунів зростає в `3.5 раза`, що спричиняє критичний тепловий перегрів ключів MOSFET у регуляторах ESC, передчасне насичення широтно-імпульсної модуляції (100% PWM) та повну втрату керованості на граничних кутах атаки.
