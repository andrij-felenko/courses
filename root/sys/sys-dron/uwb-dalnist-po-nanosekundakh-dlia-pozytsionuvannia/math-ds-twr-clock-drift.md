# 🧮 Компенсація частотного дрейфу кварцових генераторів у DS-TWR

Вимірювання відстані за часом прольоту електромагнітної хвилі (Time-of-Flight, ToF) вимагає субнаносекундної точності фіксації часових міток. Оскільки швидкість світла у вакуумі та повітрі становить приблизно `c ≈ 299 792 458 м/с` (близько `0.2998 мм/пс`), похибка вимірювання часу всього в `1 наносекунду` призводить до похибки оцінки дистанції у `30 сантиметрів`.

Реальні кварцові генератори, що тактують автономні безпілотники (Tag) та опорні навігаційні станції (Anchor), мають власну нестабільність резонансної частоти через технологічний розкид, температурні коливання та старіння кристала. Типовий дрейф недорогих кварців становить від `±10` до `±20 ppm` (parts per million, тобто `10⁻⁶`). Без спеціальної симетричної структури протоколу обміну пакетами ця різниця частот повністю руйнує точність позиціонування.

## Модель локальних часових шкал з відносним зсувом частоти

Нехай реальний фізичний час позначається через `t`. Локальний годинник ініціатора (пристрій A, дрон-тег) та локальний годинник відповідача (пристрій B, анкер) відраховують час за власними тактовими генераторами.

Позначимо відносні відхилення частот генераторів від номінальної еталонної частоти `f₀` як безрозмірні величини `e_A` та `e_B`:

```
f_A = f₀ · (1 + e_A)
f_B = f₀ · (1 + e_B)
```

Коли у фізичному часі минає інтервал тривалістю `Δt`, лічильник пристрою A фіксує часовий інтервал `ΔT_A`, а лічильник пристрою B — інтервал `ΔT_B`:

```
ΔT_A = Δt · (1 + e_A)
ΔT_B = Δt · (1 + e_B)
```

Відношення темпу ходу годинника A до темпу ходу годинника B описується коефіцієнтом частотного зсуву `k_AB`:

```
k_AB
= (1 + e_A) / (1 + e_B)                       [відношення частот генераторів]
= (1 + e_A) · (1 − e_B + e_B² − O(e_B³))     [розклад у ряд Тейлора для малих e_B]
= 1 + (e_A − e_B) + O(e²)                     [лінійне наближення відносного дрейфу]
```

Позначимо сумарну різницю частот як `e_drift = e_A − e_B`. Для двох генераторів з індивідуальними похибками `+10 ppm` та `−10 ppm` сумарний відносний дрейф становить `e_drift = 20 · 10⁻⁶ = 20 ppm`.

## Похибка одностороннього вимірювання дальності (SS-TWR)

У протоколі Single-Sided Two-Way Ranging (SS-TWR) ініціатор A відправляє пакет Poll у локальний момент часу `t₁`. Відповідач B приймає його у момент `t₂`, витримує фіксовану апаратну паузу обробки `T_reply` і відправляє кадр Response у момент `t₃`. Ініціатор A фіксує прийом відповіді у момент `t₄`.

Нехай істинний час поширення радіохвилі в один бік дорівнює `ToF`.

Ініціатор A вимірює загальний час кругового обігу `T_round` за власним годинником:

```
T_round = t₄ − t₁
```

Відповідач B вимірює час підготовки відповіді `T_reply` за своїм годинником:

```
T_reply = t₃ − t₂
```

У фізичному часі тривалість подій зв'язана точним співвідношенням:

```
Δt_round_true = 2 · ToF + Δt_reply_true
```

Переведемо виміряні інтервали у фізичний час, враховуючи темп генераторів:

```
T_round = (2 · ToF + Δt_reply_true) · (1 + e_A)
T_reply = Δt_reply_true · (1 + e_B)
```

Класична оцінка часу прольоту в алгоритмі SS-TWR розраховується ініціатором за формулою:

```
ToF_est_SS = ½ · (T_round − T_reply)
```

Підставимо фізичні інтервали у формулу оцінки:

```
ToF_est_SS
= ½ · [ (2 · ToF + Δt_reply_true) · (1 + e_A) − Δt_reply_true · (1 + e_B) ]   [підстановка виміряних інтервалів]
= ½ · [ 2 · ToF · (1 + e_A) + Δt_reply_true · (1 + e_A − 1 − e_B) ]           [групування за доданками ToF та reply]
= ToF · (1 + e_A) + ½ · Δt_reply_true · (e_A − e_B)                            [виділення похибки дрейфу]
```

Оскільки істинний час `ToF` у приміщенні становить десятки наносекунд (наприклад, для дистанції `15 м`: `ToF ≈ 50 нс`), доданок `ToF · e_A` дає похибку `50 нс · 10⁻⁵ = 0.5 пс` (менше `0.15 мм`), чим можна знехтувати.

Проте другий доданок містить час реакції відповідача `Δt_reply_true`. Навіть у найшвидших апаратних трансиверах час прийому пакета, перевірки CRC, формування кадру відповіді та виходу передавача на режим становить від `0.5 мс` до `2.0 мс` (`500–2000 мкс`).

Обчислимо абсолютну похибку часу `ΔToF_SS` для типових параметрів:
- Час відповіді: `T_reply = 1.0 мс = 10⁻³ с`;
- Різниця частот кварців: `e_drift = e_A − e_B = 20 ppm = 20 · 10⁻⁶`.

```
ΔToF_SS
= ½ · T_reply · (e_A − e_B)                 [формула часової похибки SS-TWR]
= ½ · (1.0 · 10⁻³ с) · (20 · 10⁻⁶)          [підстановка значень T_reply та дрейфу]
= 10 · 10⁻⁹ с = 10 наносекунд               [результат обчислення затримки]
```

Помноживши цю часову похибку на швидкість світла, отримуємо похибку визначення дистанції:

```
Δd_SS
= c · ΔToF_SS                               [зв'язок часу та дистанції через швидкість світла]
= (3 · 10⁸ м/с) · (10 · 10⁻⁹ с)             [множення швидкості світла на часову похибку]
= 3.0 метри                                 [просторова похибка одностороннього прольоту]
```

Похибка у три метри робить протокол SS-TWR абсолютно непридатним для навігації безпілотника в обмеженому просторі.

## Математичне виведення симетричного DS-TWR

Щоб усунути множник першого порядку `T_reply · e_drift`, протокол Double-Sided Two-Way Ranging (DS-TWR) вводить третій кадр (Final), формуючи два послідовні зустрічні вимірювання кругового обігу.

Процедура складається з трьох повідомлень:
1. Пристрій A відправляє Poll (`t₁`), пристрій B приймає (`t₂`);
2. Пристрій B відправляє Response (`t₃`), пристрій A приймає (`t₄`);
3. Пристрій A відправляє Final (`t₅`), пристрій B приймає (`t₆`).

Фіксуються чотири локальні інтервали:
- На пристрої A: перший раунд `T_round1 = t₄ − t₁` та час паузи перед фіналом `T_reply2 = t₅ − t₄`;
- На пристрої B: час підготовки відповіді `T_reply1 = t₃ − t₂` та другий раунд `T_round2 = t₆ − t₃`.

Зв'яжемо ці інтервали з істинним часом польоту `ToF` та істинними паузами обробки `T_p1` і `T_p2` у фізичному часі:

```
T_round1 = (2 · ToF + T_p1) · (1 + e_A)
T_reply2 = T_p2 · (1 + e_A)
T_round2 = (2 · ToF + T_p2) · (1 + e_B)
T_reply1 = T_p1 · (1 + e_B)
```

Симетрична формула оцінки часу польоту DS-TWR має вигляд:

```
ToF_est_DS = (T_round1 · T_round2 − T_reply1 · T_reply2) / (T_round1 + T_round2 + T_reply1 + T_reply2)
```

Доведемо, що ця формула повністю анулює похибки першого порядку. Розкриємо чисельник `N` та знаменник `D`.

### Розкриття чисельника

```
N = T_round1 · T_round2 − T_reply1 · T_reply2
```

Підставимо вирази для кожного виміряного інтервалу:

```
T_round1 · T_round2
= (2 · ToF + T_p1) · (1 + e_A) · (2 · ToF + T_p2) · (1 + e_B)
= (1 + e_A) · (1 + e_B) · [ 4 · ToF² + 2 · ToF · T_p1 + 2 · ToF · T_p2 + T_p1 · T_p2 ]   [розкриття дужок у першому добутку]

T_reply1 · T_reply2
= T_p1 · (1 + e_B) · T_p2 · (1 + e_A)
= (1 + e_A) · (1 + e_B) · [ T_p1 · T_p2 ]                                                [винесення спільних множників]
```

Віднімемо другий добуток від першого. Спільний множник `(1 + e_A) · (1 + e_B) · T_p1 · T_p2` взаємно знищується:

```
N
= (1 + e_A) · (1 + e_B) · [ 4 · ToF² + 2 · ToF · (T_p1 + T_p2) ]                        [віднімання добутків]
= 2 · ToF · (1 + e_A) · (1 + e_B) · [ 2 · ToF + T_p1 + T_p2 ]                            [факторизація множника 2·ToF]
```

### Розкриття знаменника

```
D = T_round1 + T_round2 + T_reply1 + T_reply2
```

Підставимо вирази:

```
D
= (2 · ToF + T_p1) · (1 + e_A) + (2 · ToF + T_p2) · (1 + e_B) + T_p1 · (1 + e_B) + T_p2 · (1 + e_A)   [підстановка 4 інтервалів]
= 2 · ToF · (1 + e_A) + 2 · ToF · (1 + e_B) + T_p1 · (1 + e_A + 1 + e_B) + T_p2 · (1 + e_B + 1 + e_A)   [групування за T_p1 та T_p2]
= 2 · ToF · (2 + e_A + e_B) + (T_p1 + T_p2) · (2 + e_A + e_B)                                           [винесення суми (2+e_A+e_B)]
= (2 + e_A + e_B) · [ 2 · ToF + T_p1 + T_p2 ]                                                           [факторизація знаменника]
```

### Знаходження оцінки ToF

Розділимо чисельник `N` на знаменник `D`. Спільний множник `[ 2 · ToF + T_p1 + T_p2 ]`, що містить великі інтервали пауз `T_p1` та `T_p2`, повністю скорочується:

```
ToF_est_DS
= N / D                                                                                                 [означення оцінки]
= { 2 · ToF · (1 + e_A) · (1 + e_B) · [ 2 · ToF + T_p1 + T_p2 ] } / { (2 + e_A + e_B) · [ 2 · ToF + T_p1 + T_p2 ] }  [підстановка N та D]
= 2 · ToF · (1 + e_A) · (1 + e_B) / (2 + e_A + e_B)                                                     [скорочення спільного множника]
```

Перетворимо дріб, що залишився:

```
(1 + e_A) · (1 + e_B) / (1 + ½ · (e_A + e_B))
= (1 + e_A + e_B + e_A · e_B) · [ 1 − ½ · (e_A + e_B) + ¼ · (e_A + e_B)² − O(e³) ]    [розклад знаменника в ряд Тейлора]
= 1 + (e_A + e_B) − ½ · (e_A + e_B) + e_A · e_B − ½ · (e_A + e_B)² + O(e³)            [перемноження членів розкладу]
= 1 + ½ · (e_A + e_B) − ½ · (e_A² + 2 · e_A · e_B + e_B²) + e_A · e_B + O(e³)         [розкриття квадрата суми]
= 1 + ½ · (e_A + e_B) − ½ · (e_A² + e_B²) + O(e³)                                      [спрощення перехресного члена]
```

Отже, остаточна залежність виміряного часу від істинного має вигляд:

```
ToF_est_DS = ToF · [ 1 + ½ · (e_A + e_B) − ½ · (e_A² + e_B²) + O(e³) ]
```

## Аналіз залишкової похибки DS-TWR

Головний висновок виведення: у формулі DS-TWR час паузи `T_reply` взагалі відсутній у виразі похибки. Похибка вимірювання масштабується **виключно самим часом прольоту `ToF`**, а не часом обробки пакета.

Обчислимо залишкову похибку для максимальної дистанції позиціонування дрона в приміщенні:
- Дистанція: `d = 30 метрів`;
- Істинний час прольоту: `ToF = 30 м / (3 · 10⁸ м/с) = 100 нс`;
- Відхилення частоти кварцу ініціатора: `e_A = +20 ppm = +2 · 10⁻⁵`;
- Відхилення частоти кварцу відповідача: `e_B = −20 ppm = −2 · 10⁻⁵`.

Лінійний член похибки:

```
ΔToF_lin
= ToF · ½ · (e_A + e_B)                             [лінійне наближення похибки DS-TWR]
= 100 нс · ½ · (20 · 10⁻⁶ − 20 · 10⁻⁶)              [підстановка протилежних знаків дрейфу]
= 0 пс                                              [повне взаємне скорочення похибки]
```

Якщо відхилення кварців мають однаковий знак (наприклад, обидва генератори поспішають на `+20 ppm`), лінійний член становить:

```
ΔToF_lin
= 100 нс · (20 · 10⁻⁶)                              [оцінка для синфазного зсуву частоти]
= 2.0 · 10⁻¹² с = 2.0 пікосекунди                   [абсолютна залишкова часова похибка]
```

Переведемо максимальну часову похибку у просторову дальність:

```
Δd_DS
= c · ΔToF_lin                                      [перерахунок часу в просторову метрику]
= (3 · 10⁸ м/с) · (2.0 · 10⁻¹² с)                   [множення швидкості світла на пікосекунди]
= 0.6 міліметра                                     [субміліметрова залишкова похибка]
```

| Параметр | Односторонній вимірювач (SS-TWR) | Симетричний подвійний вимірювач (DS-TWR) |
|---|---|---|
| Кількість пакетів в ефірі | 2 (Poll, Response) | 3 (Poll, Response, Final) |
| Залежність похибки від часу відповіді `T_reply` | Пряма лінійна: `½ · T_reply · e_drift` | Відсутня (скорочується повністю) |
| Залишкова похибка при дрейфі 20 ppm та `T_reply = 1 мс` | **6.0 метрів** (неприпустимо) | **< 0.6 міліметра** (ідеально) |
| Чутливість до затримок операційної системи | Критична (вимагає мікросекундного RTOS) | Низька (час відповіді може коливатися) |

Таким чином, перехід від SS-TWR до DS-TWR зменшує апаратну похибку несинхронізованих кварцових резонаторів на чотири порядки — від метрів до десятих часток міліметра. Це дозволяє використовувати дешеві стандартні кварцові резонатори замість дорогих і енергоємних термостатованих генераторів (OCXO).
