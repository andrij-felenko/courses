# 🧮 Математика перехідного режиму VTOL: аеродинамічний блендинг та динамічний розподіл

Під час переходу апарата вертикального зльоту та посадки (VTOL) від режиму зависання до крейсерського літакового польоту підйомна сила передається від підйомних повітряних гвинтів до нерухомого крила. Якщо це перемикання виконати ступінчасто або за лінійною функцією від швидкості, апарат неминуче втратить висоту або зірветься в аеродинамічний штопор. Причина полягає в принциповій нелінійності аеродинаміки: підйомна сила крила залежить від квадрата повітряної швидкості, тоді як ефективність аеродинамічних рулів при низькому швидкісному напорі є майже нульовою. Математичний апарат перехідного режиму забезпечує неперервну динамічну рівновагу сил і моментів уздовж усього швидкісного діапазону.

## 1. Рівновага сил та аеродинамічна підйомна сила крила

У зв'язаній системі координат апарата FRD (Forward-Right-Down) повне рівняння руху центра мас уздовж вертикальної осі Z під час прямолінійного горизонтованого переходу має вигляд:

```
m · a_z = m · g - L(V_ias, α) - T_hover,z(t) - T_tilt,z(θ, t)
```

де:
- `m` — повна злітна маса апарата (кг);
- `g = 9.80665 м/с²` — прискорення вільного падіння;
- `L(V_ias, α)` — повна аеродинамічна підйомна сила крила (Н);
- `T_hover,z(t)` — сумарна вертикальна складова тяги підйомних моторів для схеми з роздільною тягою (QuadPlane);
- `T_tilt,z(θ, t)` — вертикальна складова тяги поворотних рушіїв під кутом нахилу `θ` для схеми Tilt-Rotor;
- `a_z` — вертикальне прискорення центра мас (для стабільного горизонтованого переходу вимагається `a_z = 0`).

Аеродинамічна підйомна сила крила визначається класичним рівнянням аеродинаміки:

```
L(V_ias, α) = 0.5 · ρ · V_ias² · S · C_L(α)
```

де `ρ` — густина навколишнього повітря (для стандартної атмосфери ISA на рівні моря `ρ₀ = 1.225 кг/м³`), `V_ias` — індикаторна повітряна швидкість (м/с), `S` — площа несного крила (м²), `C_L(α)` — безрозмірний коефіцієнт підйомної сили при поточному куті атаки `α`.

У докритичному діапазоні кутів атаки (до настання зриву потоку) коефіцієнт описується лінійною залежністю:

```
C_L(α) = C_L0 + C_Lα · α
```

де `C_L0` — підйомна сила при нульовому куті атаки профілю, а `C_Lα = dC_L / dα` — похідна коефіцієнта підйомної сили за кутом атаки (типово `4.5 .. 5.8 рад⁻¹` для крила кінцевого подовження).

Критична швидкість звалювання `V_stall` відповідає режиму, коли за максимального допустимого коефіцієнта підйомної сили `C_L,max` крило здатне самостійно утримувати повну вагу без допомоги роторів:

```
V_stall = sqrt( (2 · m · g) / (ρ · S · C_L,max) )
```

## 2. Квадратичний закон блендингу за швидкісним напором

Динамічний швидкісний напір `q` масштабується пропорційно квадрату швидкості потоку:

```
q = 0.5 · ρ · V_ias²
```

Оскільки підйомна сила крила `L` та відновлювальні моменти аеродинамічних рулів `M_aero` залежать безпосередньо від `q`, застосування лінійного вагового коефіцієнта `w_lin = V_ias / V_trans` є грубою фізичною помилкою. Наприклад, на швидкості `V_ias = 0.5 · V_trans` лінійний блендинг примусово зменшить роторну тягу на 50%, тоді як крило при напорі `(0.5)² = 0.25` згенерує лише 25% потрібної підйомної сили. У результаті виникає сумарний провал вертикальної сили на 25% від ваги апарата (`ΔF_z = 0.25 · m · g`), що спричиняє раптове просідання висоти на десятки метрів у критичній фазі польоту.

Фізично узгоджена функція вагового коефіцієнта літакового режиму `w_fw(V_ias) ∈ [0.0, 1.0]` будується на основі нормованого швидкісного напору між порогом відчутності крила `V_min` та швидкістю гарантованого переходу `V_trans`:

```
w_fw(V_ias) = 0.0,                                               якщо V_ias < V_min
w_fw(V_ias) = (V_ias² - V_min²) / (V_trans² - V_min²),           якщо V_min ≤ V_ias ≤ V_trans
w_fw(V_ias) = 1.0,                                               якщо V_ias > V_trans
```

Швидкість завершення переходу `V_trans` розраховується з обов'язковим коефіцієнтом запасу відносно швидкості звалювання `V_stall`:

```
V_trans = k_margin · V_stall,    де k_margin ∈ [1.15, 1.30]
```

Звідси розрахункова компенсаційна тяга вертикальних роторів `T_hover,req` у процесі розгону апарата маршовим двигуном виражається формулою:

```
T_hover,req(V_ias) = m · g · (1.0 - w_fw(V_ias))
```

При такому квадратичному законі сумарна вертикальна сила `T_hover,req(V_ias) + L(V_ias)` залишається ідеально інваріантною і точно дорівнює `m · g` у будь-якій точці швидкісного діапазону незалежно від темпу прискорення чи наявності поздовжнього вітру.

## 3. Профілювання кута тангажу та керування кутом атаки

Під час розгону вектор набігаючого потоку змінює кут відносного обдування. Щоб крило створювало розрахункову підйомну силу без виходу на критичні кути атаки, автопілот реалізує програмне профілювання кута тангажу `θ_pitch(V_ias)`:

```
θ_pitch(V_ias) = θ_hover · (1.0 - w_fw(V_ias)) + θ_cruise · w_fw(V_ias) + Δθ_trim(q)
```

де `θ_hover` — кут тангажу на зависанні (зазвичай 0° або невеликий позитивний кут для компенсації зсуву акумулятора), `θ_cruise` — усталений кут тангажу літака в горизонтальному крейсерському польоті, а `Δθ_trim(q)` — динамічна поправка на аеродинамічний момент скосу потоку від крила та підйомних пропелерів.

Кут атаки `α` при цьому утримується у вузькому діапазоні лінійної стійкості:

```
α = θ_pitch - arctan( -v_z / v_x ) ∈ [α_opt - 2°, α_opt + 3°]
```

де `v_x, v_z` — поздовжня та вертикальна швидкості в системі координат планера. Утримання кута атаки поблизу оптимального значення `α_opt ≈ 4° .. 6°` мінімізує індуктивний опір крила `C_Di = C_L² / (π · e · AR)` (де `AR = b² / S` — подовження крила, `e` — коефіцієнт Освальда) та скорочує час перебування у перехідному режимі.

## 4. Перерозподіл кутових моментів та масштабування рульових поверхонь

Відновлювальні моменти сил, створювані аеродинамічними поверхнями (елеронами `δ_a`, кермом висоти `δ_e` та кермом напрямку `δ_r`), пропорційні динамічному напору повітряного потоку:

```
M_aero,x = q · S · b · C_l,δa · δ_a
M_aero,y = q · S · c_bar · C_m,δe · δ_e
M_aero,z = q · S · b · C_n,δr · δ_r
```

де `b` — розмах крила, `c_bar` — середня аеродинамічна хорда крила, а `C_l,δa, C_m,δe, C_n,δr` — безрозмірні похідні ефективності відповідних рульових поверхонь.

На низьких швидкостях `V_ias → 0` ефективність рулів наближається до нуля, тому відновлювальні моменти повністю покладаються на диференціальну тягу роторів. Підсистема розподілу керування формує команди віртуальних моментів для роторної та рульової груп за схемою комплементарного крос-фейдингу:

```
τ_rotors   = (1.0 - w_fw(V_ias)) · τ_sp
τ_surfaces = w_fw(V_ias) · K_scale(V_ias) · τ_sp
```

Масштабуючий коефіцієнт `K_scale(V_ias)` компенсує квадратичне зростання чутливості рулів на високих швидкостях, запобігаючи виникненню небезпечних високочастотних автоколивань у контурі кутової швидкості:

```
K_scale(V_ias) = (V_trans / max(V_ias, V_min))²
```

## 5. Динаміка поворотних рушіїв (Tilt-Rotor) та гіроскопічна прецесія

Для апаратів із поворотними механізмами мотогондол (Tilt-Rotor) кут нахилу `θ(t) ∈ [0, π/2]` змінюється в часі сервоприводом з кутовою швидкістю `ω_tilt = dθ/dt`:

```
θ = π/2  (90° — вертикальне положення, режим Hover)
θ = 0    (0° — горизонтальне положення, режим Fixed-Wing)
```

Сила тяги `i`-го поворотного мотора `T_i` породжує тривимірний вектор сили у зв'язаній системі координат:

```
F_i(θ) = [
    T_i · sin(θ),
    0,
   -T_i · cos(θ)
]ᵀ
```

Момент сили відносно центра мас `r_i = [x_i, y_i, z_i]ᵀ` формується векторним добутком плеча на вектор сили плюс реактивний крутний момент гвинта `Q_i = d_i · c_m · T_i`:

```
M_i(θ) = r_i × F_i(θ) + Q_i · [sin(θ), 0, -cos(θ)]ᵀ
```

Розкриваючи компоненти по осях:

```
M_i,x(θ) = -y_i · T_i · cos(θ) + d_i · c_m · T_i · sin(θ)
M_i,y(θ) =  z_i · T_i · sin(θ) + x_i · T_i · cos(θ)
M_i,z(θ) =  y_i · T_i · sin(θ) - d_i · c_m · T_i · cos(θ)
```

Під час швидкого повороту гондоли виникає потужний гіроскопічний момент прецесії гвинта `M_gyro`, спричинений одночасним обертанням пропелера з кутовою швидкістю `Ω` навколо власної осі та поворотом мотогондоли зі швидкістю `ω_tilt`:

```
M_gyro = I_prop · (ω_tilt × Ω)
```

де `I_prop` — осьовий момент інерції пропелера. Для важких гвинтів (діаметром понад 15 дюймів) цей момент досягає величин `1.5 .. 4.0 Н·м` і вноситься в матрицю керування як детерміноване перехресне збурення по осі рискання чи крену.

## 6. Зворотний перехід (Back-Transition) та баланс кінетичної енергії

Зворотний перехід від швидкісного літакового польоту до зависання вимагає швидкого розсіювання кінетичної енергії планера:

```
ΔE_k = 0.5 · m · (V_cruise² - V_hover²)
```

Рівняння поздовжнього гальмування при вимкненій маршовій тязі має вигляд:

```
m · (dV / dt) = -D_aero(V, α) - D_rotors_idle - m · g · sin(γ)
```

де `D_aero = 0.5 · ρ · V² · S · C_D` — аеродинамічний опір планера, `γ` — кут нахилу траєкторії до горизонту (кут глісади), а `D_rotors_idle` — паразитний аеродинамічний опір обертання розкручуваних підйомних гвинтів.

Критична умова безпеки зворотного переходу полягає в тому, що підйомні ротори повинні вийти на режим створення повної компенсаційної тяги `T_hover = m · g` за час `t_spinup` до моменту, коли швидкість повітряного потоку опуститься нижче порогу звалювання `V_stall`:

```
t_spinup = (I_rotor · (Ω_nom - Ω_idle)) / M_motor,max
```

Якщо `V(t_spinup) < V_stall`, виникає аварійна ситуація звалювання на крило до підхоплення висоти гвинтами. Щоб гарантувати безпечний запас, польотний контролер ініціює запуск і розкрутку підйомних моторів завчасно — при досягненні верхнього порогу `V_back = 1.2 · V_stall`, одночасно переводячи апарат у короткочасний режим аеродинамічного кабельрування (підйом носа на кут тангажу `θ_flare = +6° .. +12°`). Це забезпечує інтенсивне аеродинамічне гальмування за рахунок зростання опору `C_D(α)` та створює додатковий імпульс підйомної сили на час виходу роторів на робочі оберти.
