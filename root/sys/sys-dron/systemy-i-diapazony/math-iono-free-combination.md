# 🧮 Виведення безіоносферної лінійної комбінації для частот L1 та L5

У супутниковій навігації іоносферна затримка є найбільшим джерелом нестаціонарної похибки псевдодальності, яка під час сонячної активності здатна зміщувати просторові координати на десятки метрів. Оскільки іоносферна плазма є дисперсійним середовищем, величина затримки радіохвилі обернено пропорційна квадрату її несучої частоти. Це математичне виведення демонструє, як на основі одночасного вимірювання псевдодальностей на двох когерентних частотах `L1` (1575.42 МГц) та `L5` (1176.45 МГц) побудувати лінійну комбінацію, що повністю виключає іоносферний член першого порядку без використання наближених емпіричних моделей.

---

### Фізичні передумови: дисперсія в розрідженій плазмі

Верхній шар атмосфери на висотах від 60 до 1000 км містить вільні електрони та іони, утворені внаслідок фотоіонізації під дією сонячного випромінювання. Для високочастотних сигналів дециметрового діапазону (GNSS), частота яких суттєво перевищує власну плазмову частоту `f_p ≈ 9 √(N_e) кГц` (де `N_e` — об'ємна концентрація електронів у `ел/м³`), фазовий показник заломлення холодної плазми без зіткнень описується наближенням Апплтона-Гартрі:

```
n_ph = √(1 − f_p² / f²)
≈ 1 − f_p² / (2·f²)           [розклад у ряд Тейлора для f >> f_p]
= 1 − (e²·N_e) / (8·π²·ε₀·m_e·f²)
= 1 − 40.308 · N_e / f²       [підстановка констант: e, m_e, ε₀]
```

Оскільки фазова швидкість `v_ph = c / n_ph` перевищує швидкість світла у вакуумі (`n_ph < 1`), фаза несучої хвилі зазнає випередження. Натомість інформаційний код (далекомірна модуляція) поширюється з груповою швидкістю `v_gr`, показник заломлення якої визначається співвідношенням Релея:

```
n_gr = n_ph + f · (d n_ph / d f)
= (1 − 40.308 · N_e / f²) + f · (80.616 · N_e / f³)   [диференціювання за частотою]
= 1 + 40.308 · N_e / f²                               [зведення подібних членів]
```

Інтегруючи затримку вздовж траєкторії поширення променя `s` від супутника до антени приймача, отримуємо абсолютну кодову іоносферну затримку `I_iono` у метрах:

```
I_iono = ∫ (n_gr − 1) ds
= (40.308 / f²) · ∫ N_e ds    [винесення частоти за знак інтеграла]
= (40.308 / f²) · TEC         [де TEC = ∫ N_e ds — повний електронний вміст]
```

Одиницею вимірювання повного електронного вмісту є TECU (англ. *Total Electron Content Unit*), де `1 TECU = 10¹⁶ ел/м²`. У спокійній атмосфері значення TEC становить 10–30 TECU, а в періоди сонячних спалахів та магнітних бур у низьких широтах досягає 100–200 TECU.

Кодова затримка `I` є додатною (сигнал запізнюється), а її залежність від частоти має вигляд:

```
I(f) = K_iono / f²      [де константа K_iono = 40.308 · TEC]
```

### Система рівнянь спостережень на частотах L1 та L5

Нехай приймач одночасно вимірює дві кодові псевдодальності `ρ_1` та `ρ_5` до одного й того самого космічного апарата на частотах `f_1 = 1575.42 МГц` та `f_5 = 1176.45 МГц`:

```
ρ_1 = r_geom + c·δt_rcv − c·δt_sat + I_1 + T_trop + ε_1      [рівняння псевдодальності L1]
ρ_5 = r_geom + c·δt_rcv − c·δt_sat + I_5 + T_trop + ε_5      [рівняння псевдодальності L5]
```

Тут:
- `r_geom` — справжня геометрична відстань між фазовими центрами антен супутника та приймача;
- `c·δt_rcv − c·δt_sat` — сумарний далекомірний зсув через розсинхронізацію кварцового та атомного годинників;
- `T_trop` — тропосферна затримка (недисперсійна в L-діапазоні, однакова для L1 та L5);
- `I_1` та `I_5` — іоносферні затримки першого порядку;
- `ε_1` та `ε_5` — некорельовані шуми приймача та випадкові помилки багатопроменевості.

Виразимо затримку `I_5` через затримку `I_1`:

```
I_1 = K_iono / f_1²
I_5 = K_iono / f_5² = I_1 · (f_1² / f_5²) = γ · I_1      [де γ = (f_1 / f_5)²]
```

Обчислимо безрозмірне відношення квадратів частот `γ`:

```
γ = (1575.42 / 1176.45)²
= (1.33913043)²
= 1.79327032      [коефіцієнт зростання іоносферної затримки на L5]
```

Отже, на частоті `L5` затримка сигналу в плазмі є на 79.3% більшою, ніж на `L1`.

### Синтез коефіцієнтів безіоносферної комбінації

Шукаємо лінійну комбінацію псевдодальностей `ρ_IF` у вигляді:

```
ρ_IF = α · ρ_1 + β · ρ_5      [лінійна комбінація з ваговими коефіцієнтами]
```

Для того щоб комбінована величина `ρ_IF` зберігала незмінну геометричну дальність `r_geom` і повністю знищувала іоносферні члени `I_1` та `I_5`, коефіцієнти `α` та `β` повинні одночасно задовольняти два лінійні обмеження:

```
α + β = 1             [умова збереження масштабу геометричної дальності]
α·I_1 + β·I_5 = 0     [умова повного взаємного скорочення іоносфери]
```

Підставимо зв'язок `I_5 = I_1 · (f_1² / f_5²)` у друге рівняння:

```
α·I_1 + β·I_1·(f_1² / f_5²) = 0
α + β·(f_1² / f_5²) = 0      [скорочення ненульового множника I_1]
α = −β · (f_1² / f_5²)       [вираження α через β]
```

Підставимо знайдений вираз для `α` у перше рівняння:

```
−β · (f_1² / f_5²) + β = 1
β · (1 − f_1² / f_5²) = 1                     [винесення β за дужки]
β · ( (f_5² − f_1²) / f_5² ) = 1               [зведення до спільного знаменника]
β = f_5² / (f_5² − f_1²) = −f_5² / (f_1² − f_5²)   [знаходження коефіцієнта β]
```

Знаходимо коефіцієнт `α`:

```
α = 1 − β
= 1 − ( −f_5² / (f_1² − f_5²) )               [підстановка β]
= 1 + f_5² / (f_1² − f_5²)                    [розкриття мінуса]
= (f_1² − f_5² + f_5²) / (f_1² − f_5²)         [зведення до спільного знаменника]
= f_1² / (f_1² − f_5²)                         [знаходження коефіцієнта α]
```

Таким чином, канонічна безіоносферна комбінація псевдодальностей (англ. *Ionosphere-Free Linear Combination*) має точний аналітичний вигляд:

```
ρ_IF = (f_1² · ρ_1 − f_5² · ρ_5) / (f_1² − f_5²)      [універсальна формула комбінації]
```

### Точний числовий розрахунок для пари частот L1 та L5

Підставимо номінальні значення несучих частот `f_1 = 1575.42 МГц` та `f_5 = 1176.45 МГц`:

```
f_1² = 1575.42² = 2 481 948.1764 МГц²
f_5² = 1176.45² = 1 384 034.1025 МГц²
f_1² − f_5² = 2 481 948.1764 − 1 384 034.1025 = 1 097 914.0739 МГц²

α = 2 481 948.1764 / 1 097 914.0739 ≈ +2.2605996
β = −1 384 034.1025 / 1 097 914.0739 ≈ −1.2605996
```

Перевіримо виконання умов:
- Сума коефіцієнтів: `α + β = 2.2605996 − 1.2605996 = 1.0000000`;
- Іоносферний баланс: `α + β · γ = 2.2605996 − 1.2605996 · 1.79327032 = 2.2605996 − 2.2605996 = 0`.

Робоча формула приймача для обчислення очищеної псевдодальності:

```
ρ_IF = 2.2606 · ρ_1 − 1.2606 · ρ_5      [практична безіоносферна псевдодальність]
```

#### Числовий приклад компенсації реальної затримки

Розглянемо типову ситуацію середньої сонячної активності з рівнем іонізації `TEC = 50 TECU`:
- На частоті L1 затримка становить: `I_1 = (40.308 · 50 · 10¹⁶) / (1575.42 · 10⁶)² ≈ 8.120 метра`;
- На частоті L5 затримка становить: `I_5 = I_1 · 1.79327 ≈ 14.561 метра`.

Нехай істинна геометрична відстань з урахуванням зсуву годинників становить `r' = 22 000 000.000 метрів`. Виміряні псевдодальності приймача:
- `ρ_1 = 22 000 000.000 + 8.120 = 22 000 008.120 м`;
- `ρ_5 = 22 000 000.000 + 14.561 = 22 000 014.561 м`.

Застосовуємо безіоносферну формулу:

```
ρ_IF = 2.2605996 · 22 000 008.120 − 1.2605996 · 22 000 014.561
= 49 733 209.704 − 27 733 209.704
= 22 000 000.000 метра      [похибку 8.12 м та 14.56 м ліквідовано до 0.000 м]
```

### Аналіз шуму та поширення похибок вимірювань

Лінійна комбінація повністю усуває систематичну іоносферну затримку, але впливає на статистичний шум вимірювань. Якщо дисперсії некорельованого вимірювального шуму на частотах `L1` та `L5` позначити як `σ_1²` та `σ_5²`, дисперсія комбінованої псевдодальності `σ_IF²` визначається теоремою про дисперсію лінійної комбінації незалежних випадкових величин:

```
σ_IF² = Var(α·ρ_1 + β·ρ_5)
= α² · Var(ρ_1) + β² · Var(ρ_5)      [через некорельованість шуму каналів]
= α² · σ_1² + β² · σ_5²              [підстановка позначень]
```

У припущенні однакового рівня кодового шуму `σ_1 ≈ σ_5 = σ_code`, результуюче середньоквадратичне відхилення шуму зростає у `k_noise` разів:

```
k_noise = √(α² + β²)
= √( 2.2606² + (−1.2606)² )
= √( 5.1103 + 1.5891 )
= √6.6994
≈ 2.5883      [коефіцієнт посилення некорельованого шуму]
```

#### Порівняння комбінацій L1/L5 та L1/L2

Для класичної геодезичної комбінації `L1` (1575.42 МГц) та `L2` (1227.60 МГц):
- `f_2² = 1227.60² = 1 507 001.76 МГц²`;
- `f_1² − f_2² = 974 946.4164 МГц²`;
- `α_12 = f_1² / (f_1² − f_2²) ≈ 2.5457`;
- `β_12 = −f_2² / (f_1² − f_2²) ≈ −1.5457`;
- Коефіцієнт підсилення шуму: `k_noise_12 = √(2.5457² + 1.5457²) = √(6.4807 + 2.3892) = √8.8699 ≈ 2.9782`.

Пара `L1 + L5` має дві вирішальні переваги над `L1 + L2`:
1. Більший частотний рознос (`Δf = 398.97 МГц` проти `347.82 МГц`) забезпечує менший коефіцієнт підсилення шуму (`2.59` проти `2.98`).
2. Код `L5` має 10-кратну тактову частоту чипів (10.23 МГц проти 1.023 МГц), завдяки чому його первинний дисперсійний шум `σ_5` у 3–5 разів нижчий за шум `L1 C/A` або `L2C`. Це повністю нівелює теоретичне посилення шуму `k_noise`, роблячи підсумкову точність комбінації `L1/L5` вищою за одиночний розв'язок на `L1`.

### Фазова безіоносферна комбінація та вищі порядки дисперсії

Аналогічна комбінація застосовується для прецизійних фазових спостережень несучої хвилі `Φ` у міліметровому RTK-позиціонуванні:

```
Φ_IF = (f_1² · Φ_1 − f_5² · Φ_5) / (f_1² − f_5²)      [фазова безіоносферна комбінація]
```

Оскільки фазовий шум вимірювання несучої хвилі становить частки міліметра (близько 1–2 мм), посилення фазового шуму у 2.59 раза дає результуючий шум лише 3–5 мм, повністю усуваючи багатометрову іоносферну невизначеність.

#### Залишкові іоносферні ефекти вищих порядків

Перший порядок затримки (`∝ 1/f²`) становить 99.9% сумарного впливу плазми. Залишкові члени вищих порядків виникають через взаємодію радіохвилі з геомагнітним полем Землі та викривлення променя:
- **Другий порядок (вплив магнітного поля Землі `B_0`)**: залежить від кута між вектором магнітного поля та напрямком поширення хвилі, спадаючи за законом `1/f³`. У періоди екстремальних геомагнітних бур залишковий зсув другого порядку не перевищує 1–3 см на частоті L1;
- **Третій порядок (викривлення геометрії променя)**: зумовлений тим, що промені L1 та L5 проходять через злегка різні шари плазми через заломлення, спадаючи за законом `1/f⁴`. Його величина на практиці становить менше ніж 1–2 міліметри.

Для навігації БПЛА та більшості задач геодезичного позиціонування компенсація першого порядку є вичерпною, гарантуючи сантиметрову точність координат у будь-якій точці земної кулі.
