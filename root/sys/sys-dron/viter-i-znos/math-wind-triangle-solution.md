# Математичне виведення навігаційного трикутника швидкостей

У польоті літального апарата за наявності атмосферного руху виникає розбіжність між вектором орієнтації носа і фактичною траєкторією руху над землею. Для точного виходу на цільову точку маршруту автопілот повинен аналітично розрахувати кут упередження вітру (кут крабування) та результуючу шляхову швидкість. Нижче наведено повне строге виведення рівнянь векторного трикутника швидкостей, аналіз умов його розв'язності та критичних обмежень при сильному вітрі.

## Векторна модель у горизонтальній площині

Рух літального апарата розглядається у правій навігаційній системі координат NED (North-East-Down — Північ-Схід-Вниз). У горизонтальній площині `(N, E)` діють три вектори:

1. **Вектор дійсної повітряної швидкості `V_a` (True Airspeed, TAS):** швидкість руху апарата відносно повітряної маси. За відсутності аеродинамічного ковзання (кут ковзання `β = 0`) вектор `V_a` спрямований уздовж поздовжньої будівельної осі фюзеляжу під кутом курсу `ψ` (Heading), виміряним від півночі за годинниковою стрілкою:

```
V_a = [ V_a · cos(ψ),  V_a · sin(ψ) ]ᵀ         [вектор повітряної швидкості у фреймі NED]
```

2. **Вектор швидкості вітру `W` (Wind Velocity):** вектор переміщення повітряної маси відносно земної поверхні. Якщо вітер має абсолютну швидкість `W = ||W||` і дме **в напрямку** навігаційного азимута `ψ_w` (напрямок куди дме потік):

```
W = [ W · cos(ψ_w),  W · sin(ψ_w) ]ᵀ           [вектор швидкості вітру у фреймі NED]
```

> **Метеорологічний та навігаційний напрямок вітру:** У метеорології напрямок вітру `ψ_meteo` традиційно вказує, **звідки** дме вітер. У навігаційних векторних рівняннях використовується аеродинамічний напрямок `ψ_w` — **куди** дме потік. Зв'язок між ними визначається зсувом на 180 градусів:
> ```
> ψ_w = ψ_meteo + π                              [перехід від метеорологічного до навігаційного напрямку]
> ```

3. **Вектор шляхової швидкості `V_g` (Ground Speed):** фактична швидкість переміщення апарата відносно Землі. Вектор `V_g` спрямований під шляховим кутом `χ` (Ground Track / Course):

```
V_g = [ V_g · cos(χ),  V_g · sin(χ) ]ᵀ         [вектор шляхової швидкості у фреймі NED]
```

Згідно з класичним принципом відносності Галілея для нерелятивістських швидкостей, шляхова швидкість дорівнює векторній сумі повітряної швидкості та швидкості середовища:

```
V_g = V_a + W                                  [навігаційне векторне рівняння]
```

## Проєкції на осі NED та скалярна система рівнянь

Розпишемо векторне рівняння покомпонентно для північної осі `N` та східної осі `E`:

```
V_g · cos(χ) = V_a · cos(ψ) + W · cos(ψ_w)     [проєкція на вісь Північ (N)]
V_g · sin(χ) = V_a · sin(ψ) + W · sin(ψ_w)     [проєкція на вісь Схід (E)]
```

Перенесемо складові вітру в ліву частину:

```
V_a · cos(ψ) = V_g · cos(χ) − W · cos(ψ_w)     [рівняння (1)]
V_a · sin(ψ) = V_g · sin(χ) − W · sin(ψ_w)     [рівняння (2)]
```

Кут крабування `α_c` (Crab Angle) визначається як різниця між фактичним напрямком руху по землі `χ` та курсом орієнтації носа `ψ`:

```
α_c = χ − ψ                                    [визначення кута крабування]
ψ = χ − α_c                                    [вираз курсу через кут крабування]
```

## Виведення кута крабування через теорему синусів

Розглянемо трикутник, утворений векторами `V_a`, `W` та `V_g`. 

Кут між вектором шляхової швидкості `V_g` та вектором вітру `W` дорівнює `(χ − ψ_w)`. Кут між вектором `V_g` та вектором повітряної швидкості `V_a` дорівнює куту крабування `|α_c| = |χ − ψ|`.

Застосуємо теорему синусів до навігаційного трикутника:

```
W / sin(χ − ψ) = V_a / sin(π − (χ − ψ_w))      [теорема синусів для сторін W та V_a]
= V_a / sin(χ − ψ_w)                           [тотожність sin(π − θ) = sin(θ)]
```

Звідси виразимо синус кута крабування `α_c = χ − ψ`:

```
sin(α_c) = (W / V_a) · sin(χ − ψ_w)            [формула синуса кута крабування]
```

Величина `W · sin(χ − ψ_w)` являє собою поперечну складову швидкості вітру `W_cross` (боковий вітер відносно бажаної лінії шляху `χ`):

```
W_cross = W · sin(χ − ψ_w)                     [бокова складова вітру (Crosswind)]
sin(α_c) = W_cross / V_a                       [безрозмірний коефіцієнт бічного зносу]
```

Звідси аналітичний розв'язок для кута крабування `α_c`:

```
α_c = arcsin( W_cross / V_a )
    = arcsin( (W / V_a) · sin(χ − ψ_w) )       [аналітичний вираз кута крабування]
```

Необхідний курс орієнтації носа літального апарата `ψ` для точного слідування за лінією зі шляховим кутом `χ`:

```
ψ = χ − arcsin( (W / V_a) · sin(χ − ψ_w) )     [розрахунок заданого курсу Heading]
```

## Виведення шляхової швидкості через проєкції та теорему косинусів

Щоб знайти модуль шляхової швидкості `V_g`, піднесемо рівняння (1) та (2) до квадрата і додамо їх:

```
(V_a · cos(ψ))² + (V_a · sin(ψ))² = (V_g · cos(χ) − W · cos(ψ_w))² + (V_g · sin(χ) − W · sin(ψ_w))²
V_a² · (cos²(ψ) + sin²(ψ))
= V_g² · (cos²(χ) + sin²(χ)) + W² · (cos²(ψ_w) + sin²(ψ_w)) − 2 · V_g · W · (cos(χ) · cos(ψ_w) + sin(χ) · sin(ψ_w))
V_a² = V_g² + W² − 2 · V_g · W · cos(χ − ψ_w)  [тригонометрична тотожність додавання кутів]
```

Отримали квадратне рівняння відносно невідомої величини `V_g`:

```
V_g² − (2 · W · cos(χ − ψ_w)) · V_g + (W² − V_a²) = 0   [квадратне рівняння шляхової швидкості]
```

Позначимо поздовжню складову вітру вздовж лінії шляху як `W_along`:

```
W_along = W · cos(χ − ψ_w)                     [поздовжня складова вітру (Along-track wind)]
```

Розв'яжемо квадратне рівняння через дискримінант `D`:

```
D = (2 · W_along)² − 4 · 1 · (W² − V_a²)
  = 4 · W_along² − 4 · W² + 4 · V_a²           [розкриття дужок]
  = 4 · (V_a² − (W² − W_along²))               [групування доданків]
  = 4 · (V_a² − W_cross²)                      [оскільки W² = W_along² + W_cross²]
```

Оскільки шляхова швидкість у прямому польоті повинна бути додатним дійсним числом `V_g > 0`, обираємо додатний корінь:

```
V_g = (2 · W_along + √D) / 2
    = W_along + √(V_a² − W_cross²)             [аналітичний вираз шляхової швидкості]
```

Оскільки `sin(α_c) = W_cross / V_a`, то `√(V_a² − W_cross²) = V_a · √(1 − sin²(α_c)) = V_a · cos(α_c)`.

Підставляючи це у формулу, отримуємо компактний вираз:

```
V_g = V_a · cos(α_c) + W · cos(χ − ψ_w)        [шляхова швидкість через кут крабування]
```

Перший доданок `V_a · cos(α_c)` показує зменшення ефективної поздовжньої швидкості через розворот носа вбік, а другий доданок `W · cos(χ − ψ_w)` враховує попутне прискорення або зустрічне гальмування вітром.

## Аналіз розв'язності та критичні граничні режими

Формули кута крабування та шляхової швидкості мають чітко визначену область фізичного існування розв'язку.

### 1. Критична умова бокового зносу

Функція `arcsin(x)` визначена лише на відрізку `[-1, 1]`. Отже, умова існування стаціонарного польоту за заданим курсом `χ` має вигляд:

```
|W_cross / V_a| ≤ 1
|(W / V_a) · sin(χ − ψ_w)| ≤ 1                 [умова фізичної розв'язності]
```

Звідси випливають три випадки:

1. **`|W_cross| < V_a` (Штатний політ):** бокова складова вітру менша за повітряну швидкість літака. Існує єдиний стійкий кут крабування `α_c ∈ (−90°, +90°)`. Автопілот успішно утримує лінію шляху.
2. **`|W_cross| = V_a` (Граничний режим):** бокова складова вітру точно дорівнює повітряній швидкості. Кут крабування досягає `|α_c| = 90°`. Ніс літака розгортається строго перпендикулярно до лінії шляху назустріч вітру. Поздовжня складова повітряної швидкості `V_a · cos(90°) = 0`. Апарат рухається вздовж лінії виключно за рахунок попутного вітру `V_g = W_along`. Якщо попутного вітру немає (`W_along = 0`), апарат зависає на місці над землею (`V_g = 0`).
3. **`|W_cross| > V_a` (Зрив керування / неможливість утримання):** боковий вітер перевищує максимальну повітряну швидкість апарата. Підкореневий вираз у формулі швидкості стає від'ємним `(V_a² − W_cross² < 0)`, а аргумент арксинуса перевищує одиницю. Геометрично вектор `V_a` не здатний дотягнутися до лінії шляху. Апарат неминуче зноситься вітром убік, і жоден контур автопілота не здатний запобігти відхиленню від коридору.

### 2. Зустрічний ураганний вітер (Headwind Stall over Ground)

Розглянемо випадок строго зустрічного вітру `χ − ψ_w = 180°`:

```
W_cross = W · sin(180°) = 0                    [бокова складова відсутня]
α_c = arcsin(0) = 0°                           [кут крабування дорівнює нулю, ψ = χ]
W_along = W · cos(180°) = −W                   [вітер діє строго назустріч]
V_g = V_a · cos(0°) + (−W) = V_a − W           [шляхова швидкість при зустрічному вітрі]
```

- Якщо `W < V_a`: літак просувається вперед зі швидкістю `V_a − W > 0`.
- Якщо `W = V_a`: літак зависає відносно земної поверхні `V_g = 0`, зберігаючи повну аеродинамічну керованість (повітря обтікає крило зі швидкістю `V_a`).
- Якщо `W > V_a`: результуюча шляхова швидкість стає від'ємною `V_g < 0`. Літак летить носом уперед на повній тязі, але відносно землі рухається хвостом назад.

## Числовий приклад розрахунку

Нехай безпілотний літак виконує політ із параметрами:
- Дійсна повітряна швидкість: `V_a = 22.0` м/с;
- Бажаний шляховий кут маршруту: `χ = 060°` (`1.0472` рад);
- Швидкість вітру: `W = 8.5` м/с;
- Напрямок вітру (куди дме потік): `ψ_w = 140°` (`2.4435` рад).

1. Обчислюємо різницю кутів між шляхом і вітром:
```
χ − ψ_w = 60° − 140° = −80°                    [відносний кут вітру]
```

2. Обчислюємо поперечну та поздовжню складові вітру:
```
W_cross = 8.5 · sin(−80°) = 8.5 · (−0.9848) = −8.371 м/с   [боковий вітер з правого борту]
W_along = 8.5 · cos(−80°) = 8.5 · (0.1736)  = +1.476 м/с   [слабкий попутний вітер]
```

3. Перевіряємо умову розв'язності:
```
|W_cross / V_a| = |−8.371 / 22.0| = 0.3805 ≤ 1.0           [умова виконується]
```

4. Розраховуємо кут крабування:
```
α_c = arcsin(−0.3805) = −22.37°                            [кут крабування ліворуч]
```

5. Розраховуємо заданий курс орієнтації носа `ψ`:
```
ψ = χ − α_c = 60° − (−22.37°) = 82.37°                     [автопілот повинен тримати курс 082.4°]
```

6. Обчислюємо фактичну шляхову швидкість `V_g`:
```
V_g = V_a · cos(α_c) + W_along
    = 22.0 · cos(−22.37°) + 1.476
    = 22.0 · 0.9248 + 1.476
    = 20.345 + 1.476 = 21.821 м/с                          [шляхова швидкість над землею]
```

Незважаючи на наявність попутної складової вітру `+1.476` м/с, результуюча шляхова швидкість `21.82` м/с виявилася нижчою за повітряну швидкість `22.0` м/с, оскільки значна частина тяги витрачається на поворот носа під кутом `22.37°` для компенсації сильного бокового зносу.
