# Довідник команд польотних завдань MAVLink (MAV_CMD)

Цей довідник містить повну технічну специфікацію параметрів, систем координат, форматів даних та семантики виконання команд автопілота в польотних місіях MAVLink. Кожне польотне завдання передається у стандартизованій структурі повідомлення `MISSION_ITEM_INT` (ідентифікатор повідомлення `#73`). Універсальні числові поля `param1..param4` та тривимірні координати `x`, `y`, `z` набувають специфічного інженерного змісту залежно від коду команди `command` (перелік `MAV_CMD`).

## 1. Структурний контракт повідомлення MISSION_ITEM_INT

Повідомлення `MISSION_ITEM_INT` містить 38 байтів корисного навантаження. Завдяки правилу природного вирівнювання протоколу MAVLink v2 поля впорядковані за спаданням розміру типів: спершу чотирибайтові дійсні та цілі числа, потім двобайтові індекси, і наприкінці однобайтові прапорці та системні адреси.

```
Структура двійкового кадру MISSION_ITEM_INT (#73):
┌──────────┬──────────────────┬─────────┬────────────────────────────────────────────────────────┐
│ Зсув (б) │ Назва поля       │ Тип     │ Фізичний зміст та одиниці вимірювання                  │
├──────────┼──────────────────┼─────────┼────────────────────────────────────────────────────────┤
│ 0..3     │ param1           │ float32 │ Перший контекстний параметр (час, кут, номер каналу)   │
│ 4..7     │ param2           │ float32 │ Другий параметр (радіус прийому, швидкість, ШІМ)       │
│ 8..11    │ param3           │ float32 │ Третій параметр (радіус прольоту, лічильник, прапорець)│
│ 12..15   │ param4           │ float32 │ Четвертий параметр (бажаний курс Yaw, режим відліку)   │
│ 16..19   │ x (Latitude)     │ int32_t │ Географічна широта (градуси · 10⁷) або Local X (метри) │
│ 20..23   │ y (Longitude)    │ int32_t │ Географічна довгота (градуси · 10⁷) або Local Y (метри)│
│ 24..27   │ z (Altitude)     │ float32 │ Висота цілі в метрах (AMSL / Relative / Terrain / Z)   │
│ 28..29   │ seq              │ uint16  │ Порядковий індекс елемента в масиві місії (0..65535)   │
│ 30..31   │ command          │ uint16  │ Числовий код інструкції з переліку MAV_CMD             │
│ 32       │ target_system    │ uint8_t │ Системний ідентифікатор цільового апарата (sysid)      │
│ 33       │ target_component │ uint8_t │ Ідентифікатор вузла (compid, 1 = основний автопілот)   │
│ 34       │ frame            │ uint8_t │ Координатна рамка відліку (перелік MAV_FRAME)          │
│ 35       │ current          │ uint8_t │ 1 = активний виконуваний пункт, 0 = неактивний         │
│ 36       │ autocontinue     │ uint8_t │ 1 = автоматичний перехід до seq+1, 0 = зупинка/пауза   │
│ 37       │ mission_type     │ uint8_t │ 0 = Mission, 1 = GeoFence, 2 = Rally Points           │
└──────────┴──────────────────┴─────────┴────────────────────────────────────────────────────────┘
```

Поле `autocontinue` визначає поведінку планувальника після виконання критерію досягнення цілі:
- Значення `1`: автопілот негайно перемикає внутрішній покажчик активного пункту на `seq + 1` і продовжує безперервний автономний рух.
- Значення `0`: автопілот після досягнення цільової точки переводить контур навігації в режим очікування або кружляння (Loiter/Hold) і блокує виконання наступних пунктів місії до отримання явної команди від оператора (`MAV_CMD_DO_SET_MISSION_CURRENT` або перемикання польотного режиму).

## 2. Навігаційні команди (MAV_CMD_NAV_*)

Навігаційні команди формують тривимірну траєкторію польоту. У кожен момент часу контур наведення польотного контролера може виконувати тільки одну навігаційну команду. Черга завдань утримує керування на цьому пункті до повного виконання геометричних і часових умов переходу.

### MAV_CMD_NAV_WAYPOINT (код 16)
Основна команда перельоту в точку маршруту з можливістю зависання, контролю радіуса прийому та орієнтації курсу:
- `param1` (Hold Time): час зависання в точці в секундах. Якщо значення дорівнює нулю, апарат проходить точку в динаміці. Якщо значення більше нуля, апарат повністю гальмує до нульової шляхової швидкості й утримує позицію протягом заданого часу.
- `param2` (Acceptance Radius): горизонтальний радіус сфери або циліндра прийому точки в метрах. Точка вважається досягнутою, коли відстань від поточного положення апарата до цільових координат стає меншою або рівною цьому значенню.
- `param3` (Pass Radius): радіус прольоту по дотичній у метрах (Fly-through). Якщо значення більше нуля, навігатор перемикається на наступний відрізок траєкторії задовго до досягнення центру точки, забезпечуючи плавне зрізання кута без скидання швидкості. Якщо значення дорівнює нулю, траєкторія будується строго через центр точки.
- `param4` (Desired Yaw): бажаний кут курсу носа апарата в градусах (від 0° до 359° відносно географічної півночі). Спеціальне значення `NaN` (Not-a-Number) наказує автопілоту автоматично орієнтувати апарат уздовж вектора швидкості польоту.
- `x` (param5): географічна широта цілі у форматі цілого числа (`градуси · 10⁷`).
- `y` (param6): географічна довгота цілі у форматі цілого числа (`градуси · 10⁷`).
- `z` (param7): висота цільової точки в метрах відносно рамки `frame`.

### MAV_CMD_NAV_LOITER_UNLIM (код 17)
Нескінченне утримання позиції (кружляння для літака або зависання для мультиротора):
- `param1`..`param2`: не використовуються (встановлюються в 0).
- `param3` (Loiter Radius): радіус кружляння в метрах для апаратів літакового типу. Додатне значення означає кружляння за годинниковою стрілкою (CW), від'ємне — проти годинникової стрілки (CCW). Для коптерів ігнорується (зависання в точці).
- `param4` (Desired Yaw): бажаний кут курсу в точці зависання або `NaN`.
- `x`, `y`, `z`: координати центру зони утримання позиції.
- *Критерій завершення:* команда не завершується автоматично; вимагає зовнішньої зміни активного пункту або ручного перехоплення керування.

### MAV_CMD_NAV_LOITER_TURNS (код 18)
Кружляння навколо цільової точки із заданою кількістю повних обертів:
- `param1` (Turns): кількість повних витків (обертів на 360°), яку літак повинен виконати навколо центру.
- `param2`: не використовується (0).
- `param3` (Loiter Radius): радіус кружляння в метрах (знак визначає CW або CCW).
- `param4` (Exit Heading): кут курсу при виході з кола (градуси від півночі) або 0 для негайного виходу після завершення обертів.
- `x`, `y`, `z`: географічні координати центру кола.
- *Критерій завершення:* накопичений сумарний кут обертання апарата навколо центру перевищує `param1 · 360°`.

### MAV_CMD_NAV_LOITER_TIME (код 19)
Тимчасове утримання точки протягом фіксованого часового інтервалу:
- `param1` (Loiter Time): час утримання позиції в секундах.
- `param2`: не використовується (0).
- `param3` (Loiter Radius): радіус кружляння в метрах (для літаків).
- `param4` (Desired Yaw): бажаний курс для коптера під час зависання.
- `x`, `y`, `z`: просторові координати точки.
- *Критерій завершення:* відлік таймера починається лише після першого входу апарата в радіус прийому точки й завершується при досягненні `param1` секунд.

### MAV_CMD_NAV_RETURN_TO_LAUNCH (код 20)
Автоматичне повернення до вихідної точки старту (Home) або призначеної зони збору (Rally Point):
- `param1`..`param4`: не використовуються (0).
- `x`, `y`, `z`: ігноруються (використовуються збережені координати Home).
- *Поведінка:* апарат підіймається на попередньо налаштовану безпечну висоту повернення (параметри `RTL_ALT` або `RTL_RETURN_ALT`), летить по прямій лінії до точки зльоту й переходить у режим зависання або автоматичної посадки.

### MAV_CMD_NAV_LAND (код 21)
Автоматична вертикальна посадка в заданій точці:
- `param1` (Abort Altitude): висота переривання посадки в метрах (якщо посадка скасовується, апарат набирає цю висоту).
- `param2` (Precision Land Mode): режим точної посадки (0 = звичайна за барометром та GNSS, 1 = опортуністична за оптичним маркером або далекоміром, 2 = обов'язкова точна посадка).
- `param3`: не використовується (0).
- `param4` (Desired Yaw): бажаний курс орієнтації носа при зниженні (градуси) або `NaN`.
- `x`, `y`: координати посадкового майданчика.
- `z`: цільова висота вимкнення моторів (зазвичай 0).
- *Критерій завершення:* спрацьовування детектора контакту з землею (падіння струму двигунів, припинення вертикального руху, збіг барометричного тиску) та автоматичне зняття двигунів з охорони (Disarm).

### MAV_CMD_NAV_TAKEOFF (код 22)
Автоматичний зліт і набір висоти:
- `param1` (Minimum Pitch): мінімальний кут тангажу в градусах на етапі розгону (для літаків). Для коптерів — 0.
- `param2`..`param3`: не використовуються (0).
- `param4` (Desired Yaw): кут курсу при зльоті.
- `x`, `y`: координати точки зльоту (зазвичай збігаються з поточною позицією).
- `z`: цільова висота завершення зльоту в метрах.
- *Критерій завершення:* досягнення поточною висотою апарата значення `z`.

### MAV_CMD_NAV_SPLINE_WAYPOINT (код 82)
Проходження поворотних точок за неперервно гладкими кубічними сплайнами Ерміта (підтримується в ArduPilot):
- `param1` (Hold Time): час зависання в секундах (якщо > 0, сплайн переривається для повної зупинки).
- `param2`..`param4`: не використовуються (0).
- `x`, `y`, `z`: координати контрольного вузла сплайна.
- *Критерій завершення:* проходження точки з дотичним вектором швидкості, розрахованим за сусідніми пунктами `seq - 1` та `seq + 1`.

### MAV_CMD_NAV_VTOL_TAKEOFF (код 84) та MAV_CMD_NAV_VTOL_LAND (код 85)
Керування зльотом і посадкою для апаратів вертикального зльоту та посадки (VTOL):
- `NAV_VTOL_TAKEOFF`: вертикальний підйом у мультироторному режимі до висоти `z` із наступною активацією перехідного процесу (Transition) у літаковий режим польоту.
- `NAV_VTOL_LAND`: зворотний перехід літака у вертолітний режим на підльоті до майданчика `(x, y)` та плавне вертикальне зниження до торкання поверхні.

## 3. Команди дій та конфігурації (MAV_CMD_DO_*)

Команди дій призначені для миттєвої зміни стану виконавчих підсистем, конфігурації контурів швидкості, керування навантаженням та організації логіки переходів між пунктами місії. Вони не створюють просторових траєкторій.

### MAV_CMD_DO_SET_SERVO (код 183)
Пряме встановлення сигналу на вихідному сервоканалі мікроконтролера:
- `param1` (Servo Channel): номер вихідного каналу ШІМ (PWM) польотного контролера (від 1 до 16).
- `param2` (PWM Output): ширина імпульсу в мікросекундах (типовий діапазон від 1000 мкс до 2000 мкс; нейтральне положення 1500 мкс).
- `param3`..`param4`: не використовуються (0).
- `x`, `y`, `z`: не використовуються (0).

### MAV_CMD_DO_SET_RELAY (код 181)
Керування дискретним силовим реле або транзисторним ключем:
- `param1` (Relay Number): номер релейного виходу на платі (від 0 до 5).
- `param2` (State): цільовий стан виходу: `0` — розімкнути/вимкнути (рівень 0 В), `1` — замкнути/увімкнути (активний рівень 3.3 В або 5 В).
- `param3`..`param4`, `x`, `y`, `z`: 0.

### MAV_CMD_DO_REPEAT_SERVO (код 184) та MAV_CMD_DO_REPEAT_RELAY (код 182)
Циклічне коливання сервоприводу або перемикання реле (для скидання маркерів, аварійного скиду або стробоскопів):
- `param1`: номер каналу сервоприводу або реле.
- `param2`: значення ШІМ (мкс) для серво або стан для реле.
- `param3` (Cycle Count): кількість повних циклів спрацьовування.
- `param4` (Cycle Time): тривалість одного циклу в секундах.

### MAV_CMD_DO_CHANGE_SPEED (код 178)
Динамічна модифікація обмежень швидкості руху в контурі стабілізації:
- `param1` (Speed Type): тип регульованої швидкості:
  - `0`: повітряна швидкість (Airspeed) за датчиком трубки Піто.
  - `1`: шляхова швидкість відносно землі (Groundspeed) за GNSS.
  - `2`: швидкість вертикального підйому (Climb Speed).
  - `3`: швидкість вертикального зниження (Descent Speed).
- `param2` (Speed Value): цільове значення швидкості в метрах за секунду (значення `-1` означає збереження поточного параметра).
- `param3` (Throttle): рівень газу у відсотках від 0% до 100% (або `-1` для автоматичного розрахунку).
- `param4` (Relative Flag): `0` — абсолютне значення швидкості, `1` — відносна зміна (дельта до поточної швидкості).

### MAV_CMD_DO_SET_CAM_TRIGG_DIST (код 206)
Конфігурація автоматичного просторового інтервалометра камери для картографування:
- `param1` (Distance): відстань між послідовними знімками в метрах. Значення `0` повністю вимикає автоматичне спрацьовування затвора.
- `param2` (Shutter Time): тривалість імпульсу затвора в мілісекундах (0 = використовувати системне налаштування `CAM_DURATION`).
- `param3` (Trigger Immediate): якщо встановлено в `1`, автопілот робить один позачерговий знімок негайно в момент обробки команди.
- `param4`, `x`, `y`, `z`: 0.

### MAV_CMD_DO_DIGICAM_CONTROL (код 203)
Разове пряме керування цифровою камерою через протокол MAVLink Camera Protocol:
- `param1` (Session): номер сеансу або ID камери.
- `param2` (Zoom): керування оптичним зумом (крок або фокусна відстань).
- `param3` (Aperture): керування діафрагмою або експокорекцією.
- `param4` (Command ID): код наказу: `1` — зробити разове фото, `2` — розпочати відеозапис, `3` — зупинити відеозапис.

### MAV_CMD_DO_MOUNT_CONTROL (код 205)
Пряме кутове позиціонування 3-осьового гіростабілізованого підвісу:
- `param1` (Pitch): кут тангажу в сантиградусах (градуси · 100, наприклад, -9000 відповідає положенню камери вертикально вниз у надир).
- `param2` (Roll): кут крену в сантиградусах.
- `param3` (Yaw): кут курсу в сантиградусах (відносно корпусу або півночі залежно від режиму підвісу).
- `param4`..`z`: 0.

### MAV_CMD_DO_SET_ROI (код 195) / MAV_CMD_DO_SET_ROI_LOCATION (код 197)
Встановлення точки інтересу (ROI, від англ. *Region of Interest*), на яку автопілот автоматично наводить камеру або розвертає ніс апарата під час виконання всієї подальшої місії:
- `x`, `y`, `z`: просторові координати наземного об'єкта спостереження.

### MAV_CMD_DO_JUMP (код 177)
Керування циклами та переходами в польотному плані:
- `param1` (Target Seq): порядковий номер елемента місії (`seq`), до якого здійснюється стрибок.
- `param2` (Repeat Count): кількість повторень циклу (ціле число від 1 до 65535). Значення `-1` задає нескінченний цикл.
- `param3`..`z`: 0.

## 4. Умовні команди синхронізації (MAV_CMD_CONDITION_*)

Умовні команди запобігають виконанню наступних інструкцій дій `DO_*` до моменту настання певної просторової, часової або навігаційної події.

### MAV_CMD_CONDITION_DELAY (код 112)
Часовий бар'єр виконання дій:
- `param1` (Delay): час очікування в секундах.
- *Семантика:* таймер запускається в момент обробки пункту; виконання наступних команд у черзі заморожується на вказаний час, тоді як поточний навігаційний рух продовжується в штатному режимі.

### MAV_CMD_CONDITION_DISTANCE (код 114)
Просторовий бар'єр відстані:
- `param1` (Distance): гранична відстань у метрах до наступної навігаційної точки (`seq + 1`).
- *Семантика:* блокує чергу дій доти, доки літальний апарат не наблизиться до наступного поворотного пункту на відстань, меншу або рівну `param1`. Застосовується для завчасного відкриття стулок скидання вантажу або зміни кута камери за 50 метрів до повороту.

### MAV_CMD_CONDITION_YAW (код 115)
Орієнтаційний бар'єр курсу:
- `param1` (Target Angle): цільовий кут курсу в градусах (від 0° до 360°).
- `param2` (Angular Speed): кутова швидкість розвороту в градусах за секунду (0 = використовувати системне значення за замовчуванням).
- `param3` (Direction): напрямок обертання: `1` — за годинниковою стрілкою (CW), `-1` — проти годинникової стрілки (CCW).
- `param4` (Relative Flag): `0` — абсолютний кут відносно географічної півночі, `1` — відносний кут до поточного напрямку носа апарата.
- *Семантика:* блокує перехід до наступних пунктів доти, доки автопілот не доверне апарат на заданий кут із похибкою контуру курсу (типово < 2°).

### MAV_CMD_CONDITION_GATE (код 117)
Синхронізація проходження просторового створу (використовується в автономних гонках дронів):
- `x`, `y`, `z`: просторові координати центру воріт створу.
- *Семантика:* фіксує перетин віртуальної площини, перпендикулярної до траєкторії входу.

## 5. Довідник систем координат (MAV_FRAME)

Поле `frame` однозначно задає інтерпретацію координатних полів `x`, `y`, `z`:

```
Значення переліку MAV_FRAME у польотних завданнях:
• MAV_FRAME_GLOBAL (код 0) / MAV_FRAME_GLOBAL_INT (код 5):
  x: Широта (int32_t, degE7), y: Довгота (int32_t, degE7), z: Абсолютна висота над рівнем моря (AMSL, м, геоїд EGM96).
• MAV_FRAME_LOCAL_NED (код 1):
  x: Північ (м), y: Схід (м), z: Вниз (м; висота 50 м позначається як z = -50.0).
• MAV_FRAME_GLOBAL_RELATIVE_ALT (код 3) / MAV_FRAME_GLOBAL_RELATIVE_ALT_INT (код 6):
  x: Широта (int32_t, degE7), y: Довгота (int32_t, degE7), z: Висота відносно точки старту (Home Alt, м).
• MAV_FRAME_LOCAL_ENU (код 4):
  x: Схід (м), y: Північ (м), z: Вгору (м; висота 50 м позначається як z = +50.0).
• MAV_FRAME_GLOBAL_TERRAIN_ALT (код 10) / MAV_FRAME_GLOBAL_TERRAIN_ALT_INT (код 11):
  x: Широта (int32_t, degE7), y: Довгота (int32_t, degE7), z: Висота над поточною поверхнею рельєфу (AGL, м).
• MAV_FRAME_BODY_NED (код 8) / MAV_FRAME_BODY_FRD (код 12):
  Координати прив'язані до зв'язаної системи координат апарата: Forward-Right-Down (Вперед-Вправо-Вниз).
```

## 6. Результати виконання та коди помилок (MAV_RESULT)

При інтерактивній передачі команд через повідомлення `COMMAND_LONG` або `COMMAND_INT` автопілот зобов'язаний повернути повідомлення-підтвердження `COMMAND_ACK` із кодом результату з переліку `MAV_RESULT`:

```
Значення статусів підтвердження MAV_RESULT:
• MAV_RESULT_ACCEPTED (код 0):
  Команда повністю валідна, прийнята до виконання й успішно запущена в роботу.
• MAV_RESULT_TEMPORARILY_REJECTED (код 1):
  Команда підтримується, але наразі не може бути виконана через поточний стан апарата (наприклад, команда зльоту при заблокованих двигунах або відсутності фіксації GNSS).
• MAV_RESULT_DENIED (код 2):
  Команда категорично відхилена з міркувань безпеки (наприклад, команда калібрування гіроскопів під час польоту в повітрі).
• MAV_RESULT_UNSUPPORTED (код 3):
  Код команди MAV_CMD не реалізований у прошивці даного автопілота.
• MAV_RESULT_FAILED (код 4):
  Команда прийнята, але в процесі її виконання сталася апаратна або програмна помилка (наприклад, тайм-аут сервоприводу).
• MAV_RESULT_IN_PROGRESS (код 5):
  Команда тривалої дії прийнята й виконується; фінальне підтвердження надійде пізніше (підтримується в MAVLink v2).
• MAV_RESULT_CANCELLED (код 6):
  Виконання тривалої команди було перервано іншою пріоритетною командою або дією пілота.
```
