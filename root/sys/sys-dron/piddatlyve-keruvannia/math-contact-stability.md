# 🧮 Пасивність та стійкість взаємодії в контактних задачах

Математичний аналіз стійкості взаємодії виникає з фундаментальної проблеми: неперервний імпедансний контролер, який є абсолютно стійким на папері, у цифровому мікропроцесорному виконанні починає вібрувати, стукати по поверхні або переходить у розбіжний автоколивальний режим при зіткненні з твердим тілом. Розуміння меж дискретизації, фазового запізнення та умов пасивності дозволяє обчислити граничні значення віртуальної жорсткості `K_d` та віртуального демпфування `B_d` для стабільної роботи на реальному бортовому контролері.

### Критерій пасивності неперервного імпедансу

Механічний порт взаємодії маніпулятора з довкіллям визначається потоком миттєвої механічної потужності `P(t) = F_ext(t) · v(t)`, де `F_ext` — вектор зовнішньої сили, а `v` — вектор лінійної швидкості кінцевого органа.

За визначенням Колгейта і Хогана (Colgate & Hogan), багатовимірна динамічна система є пасивною (passive), якщо сумарна механічна енергія, передана нею в зовнішнє середовище за будь-який інтервал часу `t ≥ 0`, обмежена початковим запасом енергії `E(0)`:

```
∫₀ᵗ F_ext(τ) · v(τ) dτ ≥ -E(0)      [критерій пасивності за Колгейтом і Хоганом]
```

Для цільової динаміки віртуального імпедансу одиничної маси функція накопиченої енергії Ляпунова `V(e, v)` визначається сумою кінетичної та потенційної енергій віртуальної механічної системи:

```
V(e, v) = 0.5 · M_d · v² + 0.5 · K_d · e²
```

Похідна функції Ляпунова за часом:

```
V̇ = M_d · v · v̇ + K_d · e · v
  = v · (M_d · v̇ + K_d · e)                 [винесення швидкості v за дужки]
  = v · (F_ext − B_d · v)                   [підстановка рівняння цільового імпедансу M_d·v̇ + K_d·e = F_ext − B_d·v]
  = v · F_ext − B_d · v²                    [розкриття дужок]
```

Інтегруючи вираз для `V̇` від `0` до `t`, отримуємо баланс енергії:

```
V(t) − V(0) = ∫₀ᵗ F_ext(τ)·v(τ) dτ − ∫₀ᵗ B_d·v²(τ) dτ
∫₀ᵗ F_ext(τ)·v(τ) dτ = V(t) − V(0) + ∫₀ᵗ B_d·v²(τ) dτ
                     ≥ -V(0)               [оскільки V(t) ≥ 0 та B_d·v² ≥ 0 для будь-якого B_d > 0]
```

Оскільки розсіювання енергії через віртуальний демпфер `B_d · v²(t) ≥ 0` є строго додатним для будь-якої ненульової швидкості, неперервна система другого порядку ніколи не генерує власної механічної енергії та залишається пасивною при контакті з будь-яким пасивним середовищем (наприклад, пружною стінкою з довільною жорсткістю `K_env`).

### Частотна характеристика механічного імпедансу

У частотній області операторний механічний імпеданс `Z(s)` зв'язує силу `F(s)` та швидкість `V(s) = s · X(s)`:

```
F(s) = Z(s) · V(s)
Z(s) = M_d · s + B_d + K_d / s              [передавальна функція віртуального імпедансу]
```

Підставимо у передавальну функцію чисто уявну частоту `s = j·ω`:

```
Z(j·ω) = M_d · (j·ω) + B_d + K_d / (j·ω)
       = B_d + j · (M_d · ω − K_d / ω)      [розподіл на дійсну та уявну частини]
```

Дійсна частина імпедансу визначає активне розсіювання енергії:

```
Re{Z(j·ω)} = B_d                            [дійсна частина імпедансу]
```

Критерій строгої позитивної дійсності (Positive Realness): лінійна система є пасивною тоді й лише тоді, коли `Re{Z(j·ω)} ≥ 0` для всіх частот `ω ∈ (-∞, +∞)`. У неперервному часі умова виконується автоматично при `B_d > 0`.

### Руйнування пасивності через квантування часу (Zero-Order Hold)

У цифровому мікропроцесорному контурі з періодом квантування `T_s` вимірювання та обчислення виконуються дискретно. Елемент екстраполяції нульового порядку (Zero-Order Hold, ZOH) фіксує обчислене значення командної сили `F_cmd[k]` постійним протягом усього часового кроку `[k·T_s, (k+1)·T_s)`.

Ця затримка еквівалентна чистому фазовому запізненню на половину періоду дискретизації `T_delay ≈ T_s / 2`.

Розглянемо роботу віртуальної пружини за один крок інтегрування `Δt = T_s`. Нехай у момент `t_k` координата дорівнює `x[k]`, а швидкість `v[k]`. До кінця такту положення змінюється:

```
x[k+1] = x[k] + v[k] · T_s                  [зміщення за крок дискретизації]
F_spring[k] = K_d · x[k]                    [командна сила, зафіксована блоком ZOH на початку кроку]
```

Фактична механічна робота `ΔW`, виконана віртуальною пружиною над зовнішнім об'єктом за період `T_s`:

```
ΔW = F_spring[k] · (x[k+1] − x[k])
   = K_d · x[k] · (v[k] · T_s)              [підстановка кроку координати]
```

Істинна потенційна енергія `ΔE_pot`, накопичена ідеальною пружиною за цей самий інтервал:

```
ΔE_pot = 0.5 · K_d · x²[k+1] − 0.5 · K_d · x²[k]
       = 0.5 · K_d · (x[k] + v[k]·T_s)² − 0.5 · K_d · x²[k]
       = 0.5 · K_d · (x²[k] + 2·x[k]·v[k]·T_s + v²[k]·T_s²) − 0.5 · K_d · x²[k]
       = K_d · x[k] · v[k] · T_s + 0.5 · K_d · v²[k] · T_s²   [розкриття дужок]
```

Різниця між виконаною роботою та зміною накопиченої потенційної енергії є енергією `ΔE_gen`, яка паразитно генерується дискретним алгоритмом у кожному циклі:

```
ΔE_gen = ΔW − ΔE_pot
       = K_d·x[k]·v[k]·T_s − (K_d·x[k]·v[k]·T_s + 0.5·K_d·v²[k]·T_s²)
       = -0.5 · K_d · T_s² · v²[k]          [паразитна енергетична накачка]
```

Ділячи згенеровану енергію на тривалість кроку `T_s` і квадрат швидкості `v²`, знаходимо еквівалентне від'ємне демпфування `B_neg`, яке ZOH вносить у контур:

```
B_neg = -0.5 · K_d · T_s                    [еквівалентне від'ємне демпфування дискретизації]
```

### Дискретний аналіз на z-площині

Для точного дослідження стійкості замкненого контуру розглянемо дискретну передавальну функцію системи у z-просторі. Нехай маніпулятор масою `M` контактує з пружним довкіллям жорсткістю `K_env`. Неперервна передавальна функція об'єкта під дією сили:

```
G(s) = 1 / (M · s² + B_phys · s + K_env)
```

Дискретизація із фіксатором нульового порядку `ZOH(s) = (1 − e^(-s·T_s)) / s` дає імпульсну передавальну функцію `G(z) = 𝒵{ ZOH(s) · G(s) }`.

Якщо в контурі реалізовано пропорційно-диференціальне керування зусиллям `C(z) = K_p + K_v · (1 − z⁻¹) / T_s`, характеристичне рівняння замкненої системи на z-площині має вигляд:

```
1 + C(z) · G(z) = 0                         [характеристичне рівняння замкненого контуру]
```

При збільшенні жорсткості контакту `K_env` полюси замкненої системи зміщуються в напрямку межі одиничного кола `|z| = 1`. При перевищенні критичного коефіцієнта підсилення полюси виходять у ліву півплощину за межі одиничного кола (поблизу точки `z = -1`), що відповідає високочастотним розбіжним коливанням із частотою Найквіста `f_nyq = f_sample / 2`.

### Гранична умова контактної стійкості

Щоб замкнена система залишалася пасивною та не входила в режим самозбудження при контакті з абсолютно твердою перешкодою, сумарне демпфування в контурі зобов'язане компенсувати енергетичну накачку дискретизації:

```
B_total = B_d + B_neg ≥ 0                   [умова невід'ємного сумарного розсіювання]
B_d − 0.5 · K_d · T_s ≥ 0                   [підстановка від'ємного демпфування]
B_d ≥ 0.5 · K_d · T_s                       [базовий критерій пасивності Колгейта]
```

Якщо в контурі присутній додатковий фазовий зсув від фільтрації сенсора сили `T_filter` та затримки комунікаційної шини `T_comm`, сумарне запізнення зростає:

```
T_delay_total = 0.5 · T_s + T_filter + T_comm
```

При контакті з пружним середовищем жорсткістю `K_env` гранична умова стійкості адмітансного контуру набуває строгого вигляду:

```
B_d ≥ K_env · (0.5 · T_s + T_filter + T_comm) + 0.5 · K_d · T_s
```

### Числовий приклад розрахунку стабільного вікна

Розглянемо практичний приклад налаштування промислового маніпулятора, який виконує операцію шліфування твердої сталевої деталі (`K_env = 500 000 Н/м`).

Параметри керуючого контролера:
* Частота циклу: `f_loop = 1000 Гц` (`T_s = 0.001 с`);
* Затримка аналого-цифрового перетворювача та низькочастотного фільтра F/T-давача: `T_filter = 0.0015 с` (1.5 мс);
* Затримка пакетного обміну через EtherCAT: `T_comm = 0.0005 с` (0.5 мс);
* Бажана віртуальна жорсткість: `K_d = 500 Н/м`.

Обчислимо сумарне запізнення в контурі взаємодії:

```
T_delay_total = 0.5 · 0.001 + 0.0015 + 0.0005
              = 0.0025 с                    [сумарне фазове запізнення 2.5 мс]
```

Розрахуємо мінімально допустиме віртуальне демпфування `B_min`:

```
B_min = 500000 · 0.0025 + 0.5 · 500 · 0.001
      = 1250 + 0.25
      = 1250.25 Н·с/м                       [мінімальний демпфер для гарантії стійкості]
```

Якщо розробник встановить демпфування `B_d = 100 Н·с/м` для більш швидкого позиціонування, система гарантовано втратить стійкість і почне сильно бити по поверхні деталі. Для забезпечення стабільності при меншому демпфуванні необхідно або знизити затримку фільтрації давача, або перейти на вищу частоту циклу (наприклад, `4000 Гц`), що пропорційно зменшить критичну межу `B_min`.

### Захист через спостерігачі енергії (Energy Tanks)

У сучасних контролерах роботів для запобігання втраті стійкості без надмірного завищення постійного демпфування `B_d` застосовують архітектуру віртуальних енергетичних резервуарів (Energy Tanks або Passivity Observer / Passivity Controller, PO/PC за Ханнафордом і Рю).

Контролер підтримує стан накопиченої віртуальної енергії `E_tank(t)`. Коли віртуальний демпфер розсіює енергію (`B_d · v² > 0`), вона зараховується у резервуар:

```
Ė_tank = B_d · v² − P_active                [динаміка наповнення резервуара]
```

Якщо енергія резервуара падає до встановленого мінімального порогу `E_min` (ознака того, що дискретизація чи шум почали закачувати енергію в контактний інтерфейс), алгоритм PO/PC миттєво активує додаткове адаптивне демпфування `α(k) · v[k]`, примусово повертаючи систему в пасивний стан без зриву заданої траєкторії.
