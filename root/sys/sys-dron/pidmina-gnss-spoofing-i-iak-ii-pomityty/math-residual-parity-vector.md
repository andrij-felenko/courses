# 🧮 Математичний апарат RAIM: вектор несинхронності та статистика залишкових нев'язок

Автономний контроль цілісності у приймачі (Receiver Autonomous Integrity Monitoring, RAIM) — це статистичний метод виявлення та ізоляції аномальних або підроблених супутникових вимірювань без використання зовнішніх диференційних станцій чи корекцій. Ця вставка розгортає повне строге математичне виведення проекційної матриці простору несинхронності (Parity Space), квадратичної форми залишкових нев'язок, оцінки порогів за розподілом хі-квадрат та алгоритму локалізації несправного супутника (FDE).

## 1. Лінеаризована система навігаційних рівнянь

Нехай приймач спостерігає `N` супутників (`N ≥ 5` для виявлення похибки, `N ≥ 6` для її ізоляції). Вектор псевдодальностей `ρ = [ρ₁, ρ₂, ..., ρ_N]ᵀ` лінеаризується навколо поточної апріорної точки розгортання `x₀ = [p₀ᵀ, c·dt₀]ᵀ`.

Вектор вимірювальних нев'язок `y ∈ ℝᴺ` (різниця між виміряними псевдодальностями та розрахованими геометричними відстанями до супутників) пов'язаний із вектором просторово-часової поправки `x = [Δp_x, Δp_y, Δp_z, c·Δdt]ᵀ ∈ ℝ⁴` лінійним співвідношенням:

```
y = H·x + ε + b
```

де:
- `H ∈ ℝᴺˣ⁴` — геометро-матричний базис прямої видимості (матриця напрямних косинусів або матриця Якобі). Кожен `i`-й рядок матриці `H` має вигляд:

```
H[i, :] = [ -e_ix,  -e_iy,  -e_iz,  1 ]
```

де `e_i = [e_ix, e_iy, e_iz]ᵀ` — одиничний вектор прямої видимості (Line-of-Sight, LOS) від приймача до `i`-го супутника у геоцентричній системі координат ECEF;
- `x ∈ ℝ⁴` — чотиривимірний вектор коригування координат і зміщення годинника приймача;
- `ε ∈ ℝᴺ` — випадковий вектор некорельованого білого вимірювального шуму з нульовим математичним сподіванням і діагональною коваріаційною матрицею `R = σ² · I_N` (для простоти подальшого виведення приймаємо однакову дисперсію вимірювань `σ²`; при зваженому RAIM / WRAIM матриця нормується через зворотні вагові коефіцієнти синуса елевації);
- `b ∈ ℝᴺ` — вектор детермінованих похибок або штучного зміщення спуфінгу. Якщо всі супутники справжні та не скомпрометовані, `b = 0`. Якщо ж супутник `k` підроблено, `b_k ≠ 0`.

## 2. Оцінка найменших квадратів та проектор залишкових нев'язок

Оцінка вектора стану за методом найменших квадратів (Least Squares, LS) мінімізує норму похибки вимірювань:

```
x_hat = (Hᵀ·H)⁻¹ · Hᵀ · y      [псевдообернена матриця Мура-Пенроуза]
```

Підставляючи оцінку `x_hat` назад у модель вимірювань, отримуємо вектор оцінених спостережень `y_hat`:

```
y_hat = H · x_hat
      = H · (Hᵀ·H)⁻¹ · Hᵀ · y
```

Матриця `P_hat = H · (Hᵀ·H)⁻¹ · Hᵀ ∈ ℝᴺˣᴺ` називається матрицею ортогональної проекції на чотиривимірний підпростір стовпців матриці `H` (Image of H).

Вектор залишкових нев'язок (Residual Vector) `r ∈ ℝᴺ` визначається як різниця між спостереженнями `y` та їхньою оцінкою `y_hat`:

```
r = y − y_hat
  = y − H · (Hᵀ·H)⁻¹ · Hᵀ · y           [підстановка оцінки найменших квадратів y_hat]
  = (I_N − H · (Hᵀ·H)⁻¹ · Hᵀ) · y       [винесення вектора y за дужки]
```

Позначимо ортогональний проектор на підпростір залишкових нев'язок як `P`:

```
P = I_N − H · (Hᵀ·H)⁻¹ · Hᵀ
```

### Властивості проекційної матриці P:
1. **Симетричність:** `Pᵀ = (I_N − H · (Hᵀ·H)⁻¹ · Hᵀ)ᵀ = P`.
2. **Ідемпотентність (проектор другого ступеня):** `P² = P · P = P`.
   
Перевіримо це аналітично:
```
P · P = (I − H·(Hᵀ·H)⁻¹·Hᵀ) · (I − H·(Hᵀ·H)⁻¹·Hᵀ)
      = I − 2·H·(Hᵀ·H)⁻¹·Hᵀ + H·(Hᵀ·H)⁻¹·Hᵀ · H·(Hᵀ·H)⁻¹·Hᵀ    [розкриття дужок та зведення подібних доданків]
      = I − 2·H·(Hᵀ·H)⁻¹·Hᵀ + H·(Hᵀ·H)⁻¹ · (Hᵀ·H) · (Hᵀ·H)⁻¹·Hᵀ [об'єднання внутрішнього блоку (Hᵀ·H)]
      = I − 2·H·(Hᵀ·H)⁻¹·Hᵀ + H·(Hᵀ·H)⁻¹·Hᵀ                     [скорочення (Hᵀ·H)·(Hᵀ·H)⁻¹ = I]
      = I − H·(Hᵀ·H)⁻¹·Hᵀ                                      [спрощення коефіцієнтів: -2 + 1 = -1]
      = P                                                      [за визначенням проектора P]
```

3. **Ортогональність до геометрії `H`:** `P · H = 0`.
```
P · H = (I − H·(Hᵀ·H)⁻¹·Hᵀ) · H         [підстановка виразу проектора P]
      = H − H·(Hᵀ·H)⁻¹·(Hᵀ·H)           [розкриття дужок: I·H = H]
      = H − H·I                         [скорочення матричного добутку (Hᵀ·H)⁻¹·(Hᵀ·H) = I]
      = 0                               [віднімання тотожних матриць: H − H = 0]
```
Це означає, що матриця `P` повністю фільтрує будь-яку просторову зміну координат приймача `x` або зсув його годинника. Вектор `r = P · y = P · (H·x + ε + b) = P·ε + P·b` залежить виключно від шуму `ε` та похибок супутників `b`, і є абсолютно інваріантним до істинного руху апарата.

4. **Ранг і слід матриці `P`:**
```
rank(P) = trace(P)                                    [властивість симетричного ідемпотентного проектора]
        = trace(I_N) − trace(H · (Hᵀ·H)⁻¹ · Hᵀ)       [лінійність оператора сліду: trace(A − B) = trace(A) − trace(B)]
        = N − trace((Hᵀ·H)⁻¹ · (Hᵀ·H))                [циклічна перестановка співмножників trace(A·B) = trace(B·A)]
        = N − trace(I₄)                               [скорочення матриць до одиничної матриці розміру 4x4]
        = N − 4                                       [слід одиничної матриці I₄ дорівнює її розмірності 4]
```
Простір залишкових нев'язок має розмірність `(N − 4)`.

## 3. Вектор несинхронності (Parity Vector)

Оскільки ранг матриці `P` дорівнює `(N − 4)`, вектор `r ∈ ℝᴺ` лежить у підпросторі розмірності `(N − 4)`. Для переходу до ортонормованого базису простору несинхронності (Parity Space) використовують QR-розклад матриці `H`:

```
H = Q · R_qr = [ Q_A  Q_B ] · [ R_top ]
                              [   0   ]
```

де:
- `Q_A ∈ ℝᴺˣ⁴` — перші 4 стовпці матриці `Q`, що утворюють ортонормований базис підпростору стовпців `H`;
- `Q_B ∈ ℝᴺˣ⁽ᴺ⁻⁴⁾` — останні `(N − 4)` стовпців матриці `Q`, ортогональні до `H` (`Q_Bᵀ · H = 0` та `Q_Bᵀ · Q_B = I_(N-4)`);
- `R_top ∈ ℝ⁴ˣ⁴` — верхньотрикутна невироджена матриця.

Визначимо матрицю несинхронності `S = Q_Bᵀ ∈ ℝ⁽ᴺ⁻⁴⁾ˣᴺ`.

Вектор несинхронності (Parity Vector) `p ∈ ℝᴺ⁻⁴` визначається як лінійна трансформація вимірювань:

```
p = S · y = Q_Bᵀ · y
```

Підставляючи розклад вимірювань `y = H·x + ε + b`:
```
p = Q_Bᵀ · (H·x + ε + b)                      [підстановка моделі спостережень y = H·x + ε + b]
  = Q_Bᵀ·H·x + Q_Bᵀ·ε + Q_Bᵀ·b                [дистрибутивність множення матриць]
  = 0 + Q_Bᵀ·ε + Q_Bᵀ·b                       [ортогональність базису: Q_Bᵀ·H = 0]
  = S·ε + S·b                                 [визначення матриці S = Q_Bᵀ]
```

Математичне сподівання та коваріація вектора `p` за відсутності похибок (`b = 0`):
```
E[p] = E[S·ε] = S · E[ε] = 0                  [лінійність оператора математичного сподівання при E[ε] = 0]
Cov(p) = E[p · pᵀ]                            [означення коваріаційної матриці для центрованого вектора]
       = S · E[ε · εᵀ] · Sᵀ                   [підстановка p = S·ε та винесення детермінованої матриці S]
       = S · (σ² · I_N) · Sᵀ                  [коваріаційна матриця некорельованого шуму E[ε·εᵀ] = σ²·I_N]
       = σ² · (S · Sᵀ)                        [винесення дисперсійного скаляра σ²]
       = σ² · I_(N-4)                         [ортонормованість рядків S·Sᵀ = Q_Bᵀ·Q_B = I]
```
Компоненти вектора несинхронності `p` є взаємно незалежними стандартними гауссівськими величинами з дисперсією `σ²`.

## 4. Тестова статистика та зв'язок із сумою квадратів нев'язок

Квадрат евклідової норми вектора несинхронності дорівнює сумі квадратів залишкових нев'язок (Sum of Squared Errors, SSE):

```
pᵀ · p = (S · y)ᵀ · (S · y)                   [визначення норми вектора несинхронності p = S·y]
       = yᵀ · Sᵀ · S · y                      [транспонування добутку матриць (S·y)ᵀ = yᵀ·Sᵀ]
       = yᵀ · Q_B · Q_Bᵀ · y                  [підстановка ортогональної матриці S = Q_Bᵀ]
```

Оскільки повна ортогональна матриця `Q = [Q_A  Q_B]` задовольняє умову `Q · Qᵀ = Q_A · Q_Aᵀ + Q_B · Q_Bᵀ = I_N`, а `Q_A · Q_Aᵀ = H · (Hᵀ·H)⁻¹ · Hᵀ`, маємо тотожність:

```
Q_B · Q_Bᵀ = I_N − H · (Hᵀ·H)⁻¹ · Hᵀ = P
```

Отже:
```
pᵀ · p = yᵀ · P · y                           [підстановка тотожності Q_B·Q_Bᵀ = P]
       = yᵀ · Pᵀ · P · y                      [ідемпотентність і симетрія проектора: P = Pᵀ·P]
       = (P · y)ᵀ · (P · y)                   [групування співмножників за операцією транспонування]
       = rᵀ · r                               [підстановка вектора залишкових нев'язок r = P·y]
       = ∑ (r_i)²                             [скалярний добуток вектора r на самого себе]
```

Визначимо тестову статистику RAIM `SSE`:

```
SSE = rᵀ · r = pᵀ · p = ∑_{i=1}^N (r_i)²
```

Нормована тестова статистика `J = SSE / σ²`:

```
J = (pᵀ · p) / σ² = ∑_{j=1}^{N-4} (p_j / σ)²
```

## 5. Перевірка статистичних гіпотез за розподілом хі-квадрат

Для контролю цілісності формулюються дві альтернативні статистичні гіпотези:

1. **Нульова гіпотеза `H₀` (сигнал автентичний, відсутність спуфінгу/відмов):**
   Вектор похибок `b = 0`.
   Нормована статистика `J = SSE / σ²` підпорядковується центральному розподілу хі-квадрат із `(N − 4)` ступенями вільності:

```
J ~ χ²(N − 4)
```

2. **Альтернативна гіпотеза `H₁` (наявна підміна або груба похибка):**
   Принаймні один супутник має штучне зміщення `b ≠ 0`.
   У цьому випадку математичне сподівання вектора несинхронності ненульове: `E[p] = S · b`.
   Статистика `J` підпорядковується нецентральному розподілу хі-квадрат:

```
J ~ χ²(N − 4, λ)
```

де `λ` — параметр нецентральності (Non-centrality parameter):

```
λ = (E[p]ᵀ · E[p]) / σ² = (bᵀ · Sᵀ · S · b) / σ² = (bᵀ · P · b) / σ²
```

### Розрахунок порогу виявлення `T_raim`

Поріг виявлення `T_raim` обирається з умови забезпечення заданої ймовірності хибної тривоги `P_fa` (False Alarm Probability, за авіаційними стандартами ICAO/RTCA DO-229 `P_fa = 10⁻⁵`):

```
P_fa = P( J > T_raim | H₀ ) = 1 − F_χ²(T_raim; N − 4)
```

де `F_χ²(·; k)` — функція кумулятивного розподілу (CDF) центрального хі-квадрат з `k` ступенями вільності.
Поріг `T_raim` обчислюється через зворотну функцію квантилів (Inverse CDF):

```
T_raim = F_χ²⁻¹(1 − P_fa; N − 4)
```

Правило прийняття рішення:
- Якщо `SSE / σ² ≤ T_raim` — гіпотеза `H₀` приймається (навігаційне рішення вважається цілісним).
- Якщо `SSE / σ² > T_raim` — гіпотеза `H₀` відхиляється, фіксується порушення цілісності або атака підміни (тривога RAIM).

```
Таблиця критичних порогів T_raim для P_fa = 10⁻⁵:
------------------------------------------------------
Кількість супутників N   Ступені вільності (N-4)   Поріг T_raim
------------------------------------------------------
5 супутників             1                         19.51
6 супутників             2                         23.03
7 супутників             3                         25.90
8 супутників             4                         28.47
9 супутників             5                         30.86
10 супутників            6                         33.12
------------------------------------------------------
```

## 6. Алгоритм локалізації та ізоляції несправності (FDE)

Коли `N ≥ 6` і зафіксовано спрацювання тривоги `SSE / σ² > T_raim`, алгоритм FDE (Fault Detection and Exclusion) повинен однозначно визначити індекс `k` скомпрометованого супутника та вилучити його з навігаційного розв'язку.

### Метод нормованих залишкових нев'язок (w-тест):

Коваріаційна матриця вектора нев'язок `r` дорівнює:
```
Cov(r) = Cov(P · y) = P · Cov(y) · Pᵀ = σ² · P · Pᵀ = σ² · P
```

Дисперсія нев'язки `i`-го супутника є діагональним елементом матриці `P`:
```
Var(r_i) = σ² · P_ii
```

Нормована нев'язка `w_i` для кожного `i`-го каналу обчислюється як:

```
w_i = |r_i| / (σ · √(P_ii))
```

Супутник з максимальним значенням `w_i` є найбільш імовірним джерелом спотворення:

```
k_fault = argmax_{i = 1..N} ( w_i )
```

### Процедура вилучення (Exclusion):
1. Видалити `k_fault`-й рядок з вектора вимірювань `y` та матриці `H`.
2. Сформувати нову редуковану матрицю `H_sub ∈ ℝ⁽ᴺ⁻¹⁾ˣ⁴` та вектор `y_sub ∈ ℝᴺ⁻¹`.
3. Повторно перерахувати проектор `P_sub`, залишкові нев'язки `r_sub` та нову тестову статистику `SSE_sub`.
4. Якщо `SSE_sub / σ² ≤ T_raim(N − 5)`, скомпрометований супутник успішно ізольовано, а нове PVT-рішення вважається валідним.
5. Якщо після вилучення `SSE_sub / σ² > T_raim(N − 5)`, фіксується групова підміна декількох супутників (Multiple Satellite Spoofing), і прийом GNSS повністю блокується.

## 7. Числовий приклад обчислення FDE

Нехай приймач спостерігає `N = 6` супутників з номінальним шумом псевдодальності `σ = 2.0` м. На супутник №3 накладається фальшива псевдодальність зі зміщенням `b₃ = +35.0` м.

Матриця спрямованості `H` має вигляд:
```
H = [ -0.21,   0.65,   0.73,  1.0 ]
    [  0.54,   0.31,   0.78,  1.0 ]
    [ -0.72,  -0.41,   0.56,  1.0 ]  ← PRN 3 (атакований супутник)
    [  0.15,  -0.82,   0.55,  1.0 ]
    [  0.68,  -0.51,   0.53,  1.0 ]
    [ -0.35,   0.22,   0.91,  1.0 ]
```

1. Обчислюємо проекційну матрицю `P = I₆ − H · (Hᵀ · H)⁻¹ · Hᵀ`. Діагональні елементи `P_ii`:
```
diag(P) = [ 0.32,  0.28,  0.41,  0.35,  0.29,  0.35 ]
```

2. Вектор виміряних нев'язок `y` та результуючий вектор залишків `r = P · y`:
```
r = [ -4.12,  -3.25,  +14.35,  -3.88,  -2.95,  -0.15 ] м
```

3. Обчислюємо суму квадратів залишкових похибок `SSE`:
```
SSE = (-4.12)² + (-3.25)² + (14.35)² + (-3.88)² + (-2.95)² + (-0.15)² [сума квадратів нев'язок r_i]
    = 16.97 + 10.56 + 205.92 + 15.05 + 8.70 + 0.02                    [піднесення до квадрата]
    = 257.22 м²                                                        [арифметичне підсумовування]
```

4. Нормована тестова статистика `J`:
```
J = SSE / σ² = 257.22 / (2.0)² = 257.22 / 4.0 = 64.30
```

5. Для `N = 6` ступенів вільності `k = 6 − 4 = 2`. Критичний поріг при `P_fa = 10⁻⁵` дорівнює `T_raim = 23.03`.
Оскільки `J = 64.30 > 23.03`, алгоритм однозначно фіксує аварійний стан порушення цілісності.

6. Локалізація супутника через нормовані нев'язки `w_i = |r_i| / (σ · √(P_ii))`:
