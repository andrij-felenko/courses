# 🧮 Математичне виведення закону нелінійного наведення L1

Математичний апарат нелінійного наведення L1 (Nonlinear Guidance Law) розв'язує задачу точного слідування криволінійній або прямій просторовій траєкторії через побудову миттєвої дуги кола між поточною позицією рухомого об'єкта та точкою прицілювання на лінії. На відміну від евристичних регуляторів похибки зміщення, закон L1 синтезує бічне доцентрове прискорення як аналітичну функцію поточної швидкості та геометрії випередження, забезпечуючи інваріантний коефіцієнт демпфування другого порядку.

## Постановка задачі та геометрія наведення

Нехай точка `p = (x, y)` описує положення центру мас літального апарата на двовимірній навігаційній площині. Вектор шляхової швидкості об'єкта `V` має модуль `V = ||V||` та спрямований під шляховим кутом `χ` відносно осі `X`.

Задана траєкторія руху є нескінченною прямою лінією, напрям якої визначається одиничним вектором `t̂` під кутом `χ_path`. Перпендикулярно до лінії спрямовано одиничний вектор нормалі `n̂`. Відстань від точки `p` до прямої зі знаком позначається як бічне відхилення `d` (cross-track error):

```
d = (p − W_A) × t̂                             [векторний добуток у площині]
```

На прямій траєкторії обирається опорна точка прицілювання `p_ref` (lookahead reference point), яка віддалена від поточної позиції апарата `p` на фіксовану відстань `L_1`:

```
||p_ref − p|| = L_1                           [довжина вектора випередження]
```

Вектор випередження `L_1 = p_ref − p` утворює кут `η` (eta) з поточним вектором швидкості `V`. Кут `η` відраховується від вектора `V` до вектора `L_1` проти годинникової стрілки:

```
η = ∠(V, p_ref − p)                           [кут рознесення швидкості й цілі]
```

## Синтез команди бічного прискорення

Ідея алгоритму полягає у виборі такої миттєвої кругової траєкторії, яка одночасно є дотичною до поточного вектора швидкості `V` у точці `p` і проходить через точку прицілювання `p_ref`.

Розглянемо рівнобедрений трикутник, утворений центром кола повороту `C`, поточною позицією `p` та точкою `p_ref`. Обидва радіуси дорівнюють `R = ||p − C|| = ||p_ref − C||`.

Оскільки вектор швидкості `V` перпендикулярний до радіуса `p − C`, кут між хордою `p_ref − p` та дотичною `V` дорівнює точно половині центрального кута `∠p C p_ref`. Отже, центральний кут дорівнює `2·η`.

Із прямокутного трикутника, утвореного опусканням висоти з центра `C` на хорду довжиною `L_1`, маємо співвідношення для радіуса кривини `R`:

```
sin(η) = (L_1 / 2) / R                        [тригонометрія половинного кута]
R = L_1 / (2 · sin(η))                        [радіус кола наведення]
```

Кривина траєкторії `κ` (kappa) обернено пропорційна радіусу кола:

```
κ = 1 / R
= 2 · sin(η) / L_1                            [миттєва кривина траєкторії]
```

Для руху по колу радіуса `R` зі швидкістю `V` апарат повинен розвивати доцентрове (нормальне до вектора швидкості) прискорення `a_s_cmd`:

```
a_s_cmd = V² / R                              [формула доцентрового прискорення]
= V² · (2 · sin(η) / L_1)                     [підстановка радіуса R]
= 2 · (V² / L_1) · sin(η)                     [базовий закон наведення L1]
```

Знак прискорення `a_s_cmd` відповідає знаку `sin(η)`: додатне прискорення повертає вектор швидкості ліворуч, від'ємне — праворуч.

## Лінеаризація та передатна функція контуру

Для дослідження стійкості та динаміки збіжності розглянемо диференціальні рівняння похибок відносно лінії шляху `χ_path = 0`.

Похибка шляхового курсу визначається як `χ̃ = χ − χ_path`. Похідна бічного відхилення `d` за часом дорівнює проекції швидкості на нормаль до лінії:

```
ḋ = V · sin(χ̃)                                [кінематика бокового зміщення]
```

Похідна курсу за часом визначається нормальним прискоренням:

```
χ̃̇ = a_s_cmd / V
= 2 · (V / L_1) · sin(η)                      [кутова швидкість розвороту]
```

Знайдемо геометричний зв'язок між кутом `η`, курсовою похибкою `χ̃` та боковим відхиленням `d`. Нехай `η_ref` — кут нахилу вектора `L_1` до осі траєкторії. З прямокутного трикутника між проєкцією точки `p` на лінію та точкою `p_ref`:

```
sin(η_ref) = −d / L_1                         [проєкція відхилення на вектор L_1]
```

Кут між вектором швидкості та вектором випередження складається з різниці кутів нахилу:

```
η = η_ref − χ̃                                 [різниця кутів орієнтації]
```

При малих відхиленнях (`|χ̃| ≪ 1`, `|d| ≪ L_1`) застосовуємо лінійні наближення `sin(χ̃) ≈ χ̃`, `sin(η_ref) ≈ −d / L_1`, `sin(η) ≈ η`:

```
η ≈ −(χ̃ + d / L_1)                            [лінеаризований кут прицілювання]
```

Підставимо лінеаризований вираз у рівняння для похідної курсу:

```
χ̃̇ = −2 · (V / L_1) · (χ̃ + d / L_1)             [лінеаризована динаміка курсу]
```

Візьмемо похідну за часом від рівняння `ḋ ≈ V · χ̃`:

```
d̈ = V · χ̃̇                                     [друга похідна відхилення]
= V · [ −2 · (V / L_1) · (χ̃ + d / L_1) ]       [підстановка виразу для χ̃̇]
= −2 · (V / L_1) · (V · χ̃) − 2 · (V² / L_1²) · d   [розкриття дужок]
= −2 · (V / L_1) · ḋ − 2 · (V² / L_1²) · d     [підстановка ḋ = V · χ̃]
```

Перенесемо всі члени в ліву частину та отримаємо характеристичне диференціальне рівняння другого порядку для похибки повернення на лінію:

```
d̈ + 2 · (V / L_1) · ḋ + 2 · (V² / L_1²) · d = 0 [канонічне ОДР другого порядку]
```

## Власна частота та інваріантний коефіцієнт демпфування

Зіставимо отримане рівняння зі стандартною формою лінійної коливальної ланки другого порядку:

```
d̈ + 2 · ζ · ω₀ · ḋ + ω₀² · d = 0               [еталонна форма другого порядку]
```

Прирівняємо коефіцієнти при `d` та `ḋ`:

```
ω₀² = 2 · V² / L_1²                           [квадрат власної частоти]
ω₀ = √2 · (V / L_1)                           [незгасна власна частота контуру]
```

Знаючи `ω₀`, знайдемо коефіцієнт демпфування `ζ` (zeta):

```
2 · ζ · ω₀ = 2 · (V / L_1)                    [коефіцієнт при першій похідній]
2 · ζ · (√2 · V / L_1) = 2 · (V / L_1)        [підстановка ω₀]
ζ · √2 = 1                                    [скорочення однакових множників]
ζ = 1 / √2 ≈ 0.7071                           [теоретичний коефіцієнт демпфування]
```

Це ключова аналітична властивість алгоритму L1: **коефіцієнт демпфування контуру повернення на лінію завжди строго дорівнює `ζ = 1 / √2 ≈ 0.7071` незалежно від швидкості польоту `V` та вибору відстані `L_1`**.

Значення `ζ = 1/√2` відповідає характеристиці фільтра Баттерворта другого порядку та забезпечує оптимальний компроміс між швидкістю збіжності та перерегулюванням:
- Величина перерегулювання за положенням складає `M_p = exp( −π · ζ / √(1 − ζ²) ) = exp(−π) ≈ 4.32%`.
- Корені характеристичного полінома лежать під кутом 45° у лівій комплексній півплощині: `s₁,₂ = −ω₀/√2 ± j · ω₀/√2 = −(V/L_1) ± j · (V/L_1)`.

## Налаштування контуру через період коливань T_L1

На практиці пряме задання метричної відстані `L_1` незручне, оскільки при зміні швидкості польоту власна частота `ω₀` змінюється пропорційно `V`. Якщо задати постійну відстань `L_1 = 40` м, на швидкості 10 м/с частота буде `ω₀ = 0.35` рад/с, а на швидкості 30 м/с — `ω₀ = 1.06` рад/с, що призведе до надмірно різких маневрів на високих швидкостях.

Для забезпечення інваріантності перехідного процесу в часі параметр `L_1` адаптують до поточної швидкості `V` через бажаний період демпфованих коливань `T_L1`:

```
T_L1 = 2 · π / ω₀                             [бажаний період другого порядку]
= 2 · π / (√2 · V / L_1)                      [підстановка власної частоти]
= √2 · π · (L_1 / V)                          [зв'язок періоду, швидкості та L_1]
```

Звідси отримуємо інженерну формулу розрахунку динамічного випередження `L_1(V)`:

```
L_1 = (T_L1 · V) / (√2 · π)
≈ 0.225 · T_L1 · V                            [формула адаптації L_1 до швидкості]
```

Задаючи єдиний параметр налаштування — період `T_L1` (типово від 15 до 25 секунд для безпілотних літаків і від 3 до 8 секунд для маневрених роверів і коптерів), автопілот зберігає незмінну часову форму перехідного процесу повернення на лінію в усьому діапазоні експлуатаційних швидкостей.

Час встановлення перехідного процесу (входження в 2% зону відхилення) становить:

```
t_settle ≈ 4 / (ζ · ω₀)
= 4 / (V / L_1)                               [підстановка ζ·ω₀ = V/L_1]
= 4 · L_1 / V                                 [час встановлення через L_1 та V]
= 4 · (T_L1 / (√2 · π))                       [підстановка формули для L_1]
≈ 0.90 · T_L1                                 [час заспокоєння контуру]
```

## Нелінійний аналіз стійкості за Ляпуновим

У разі великих початкових відхилень (`|d| > L_1`) наближення малих кутів не працює. Доведемо асимптотичну стійкість нелінійної замкненої системи за допомогою прямого методу Ляпунова.

Розглянемо функцію-кандидат Ляпунова `W(d, χ̃)`, яка містить квадратичні міри просторового відхилення та курсової помилки:

```
W = (1/2) · d² + (L_1 / 2) · (1 − cos(χ̃))     [додатно визначена функція Ляпунова]
```

Обчислимо повну похідну функції `W` за часом вздовж траєкторій нелінійної системи:

```
Ẇ = d · ḋ + (L_1 / 2) · sin(χ̃) · χ̃̇             [диференціювання за часом]
= d · (V · sin(χ̃)) + (L_1 / 2) · sin(χ̃) · (2 · V / L_1 · sin(η))   [підстановка ḋ та χ̃̇]
= V · sin(χ̃) · [ d + sin(η) ]                 [винесення спільних множників]
```

Оскільки `sin(η) = sin(η_ref − χ̃) = sin(η_ref)·cos(χ̃) − cos(η_ref)·sin(χ̃)` та `sin(η_ref) = −d / L_1`, при помірних кутах розходження `Ẇ ≤ 0`. Рівність нулеві досягається виключно у точці рівноваги `d = 0, χ̃ = 0`. Відповідно до теореми Ла-Салля про інваріантні множини, стан `(d = 0, χ̃ = 0)` є глобально асимптотично стійким.
