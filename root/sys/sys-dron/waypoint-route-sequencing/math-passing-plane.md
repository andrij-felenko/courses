# 🧮 Геометрія площини прольоту та запобігання зацикленню

У системах автономної навігації проста перевірка входження апарата в кулю досягнення радіуса `R_acc` навколо шляхової точки стає джерелом критичних відмов: за високої швидкості чи сильного бічного вітру дрон проскакує сферу між дискретними тактами обчислень або виходить на нескінченне кружляння довкола точки. Математичне розв'язання цієї проблеми полягає у введенні ортогональної гіперплощини прольоту (Passing Plane) або бісекторної розділової площини на повороті, перетин якої однозначно фіксує проходження точки за скалярним добутком векторів.

## Векторна постановка задачі

Нехай у локальній системі координат NED (North-East-Down) задано послідовність шляхових точок місії:

```text
W[k-1] = [x[k-1], y[k-1], z[k-1]]ᵀ  — попередня точка (start waypoint)
W[k]   = [x[k],   y[k],   z[k]]ᵀ    — поточна цільова точка (current target)
W[k+1] = [x[k+1], y[k+1], z[k+1]]ᵀ  — наступна точка (next target)
```

Поточне оцінене положення апарата в момент часу `t` позначається вектором `P(t) = [x(t), y(t), z(t)]ᵀ`, а його вектор швидкості — `V(t) = [v_x(t), v_y(t), v_z(t)]ᵀ` із модулем `v = ||V(t)||`.

Вектор спрямованого відрізка траєкторії між попередньою та поточною точками дорівнює:

```text
S_in = W[k] − W[k-1]
L_in = ||S_in|| = √((x[k] − x[k-1])² + (y[k] − y[k-1])² + (z[k] − z[k-1])²)
```

Одиничний напрямний вектор сегмента наближення:

```text
u_in = S_in / L_in
```

Аналогічно, вихідний сегмент до наступної точки:

```text
S_out = W[k+1] − W[k]
L_out = ||S_out||
u_out = S_out / L_out
```

## Нормальна площина прольоту (Segment Passing Plane)

Найпростіша площина прольоту визначається як геометричне місце точок `P`, ортогональне до вхідного відрізка `W[k-1] → W[k]`, що проходить безпосередньо через цільову точку `W[k]`.

Вектор зміщення апарата відносно цілі:

```text
d_k(t) = P(t) − W[k]
```

Рівняння нормальної площини у векторній формі:

```text
(P(t) − W[k]) · u_in = 0
```

У координатній формі для тривимірного простору:

```text
(x(t) − x[k]) · u_in,x + (y(t) − y[k]) · u_in,y + (z(t) − z[k]) · u_in,z = 0
```

Скалярна проєкція зміщення `P(t) − W[k]` на вектор `u_in` визначає орієнтовану відстань прольоту `s_pass(t)`:

```text
s_pass(t) = (P(t) − W[k]) · u_in
```

Знак величини `s_pass(t)` однозначно розбиває тривимірний простір на два півпростори:

1. `s_pass(t) < 0` — апарат перебуває на підльоті до точки `W[k]` (у межах відрізка або збоку від нього, не дійшовши до нормальної площини).
2. `s_pass(t) = 0` — апарат перетинає площину прольоту.
3. `s_pass(t) > 0` — апарат перетнув площину прольоту й рухається за точку `W[k]`.

Отже, базовий критерій спрацьовування нормальної площини прольоту формулюється як нерівність:

```text
(P(t) − W[k]) · u_in ≥ 0
```

## Бісекторна площина повороту (Corner Bisector Plane)

Коли траєкторія місії змінює напрям у точці `W[k]` на просторовий кут `θ = arccos(u_in · u_out)`, нормальна площина до відрізка `u_in` може виявитися неоптимальною: якщо дрон починає плавний маневр заздалегідь, зрізаючи кут, він може опинитися в мертвій зоні між площинами вхідного та вихідного сегментів.

Для симетричного розділення областей наведення між двома непаралельними сегментами будують бісекторну нормаль `n_bis`. Вона спрямована вздовж бісектриси кута між напрямками `u_in` та `u_out`:

```text
n_bis = (u_in + u_out) / ||u_in + u_out||
```

Перевірка перетину бісекторної площини:

```text
s_bis(t)
= (P(t) − W[k]) · n_bis                                       [визначення скалярної проєкції на бісектрису]
= (P(t) − W[k]) · ((u_in + u_out) / ||u_in + u_out||)         [підстановка одиничного вектора бісектриси]
= ((P(t) − W[k]) · u_in + (P(t) − W[k]) · u_out) / ||u_in + u_out|| [дистрибутивність скалярного добутку]
```

Оскільки знаменник `||u_in + u_out|| > 0` для будь-якого кута повороту `θ < 180°`, умова перетину бісекторної площини обчислюється без квадратного кореня й ділення:

```text
(P(t) − W[k]) · u_in + (P(t) − W[k]) · u_out ≥ 0
```

Ця формула симетрично ділить простір повороту: будь-яка точка, що знаходиться ближче до продовження наступного відрізка `W[k] → W[k+1]`, ніж до попереднього `W[k-1] → W[k]`, автоматично переводить секвенсер на наступний відрізок.

## Чому критерію кулі `R_acc` недостатньо: аналіз відмов

Класична умова досягнення точки полягає в перевірці евклідової відстані:

```text
||P(t) − W[k]|| ≤ R_acc
```

Розгляньмо два фізичні сценарії, коли ця умова повністю руйнує виконання місії.

### Сценарій 1: Дискретний стрибок за високої швидкості

Нехай бортовий навігаційний цикл виконується з періодом `Δt` (наприклад, `50 Гц`, тобто `Δt = 0.02 с`), а апарат летить зі швидкістю `v = 25 м/с`.

Крок переміщення між двома послідовними тактами дискретизації:

```text
Δs = v · Δt = 25 · 0.02 = 0.50 м
```

Якщо радіус кулі задано малим (наприклад, `R_acc = 1.0 м` для точного картографування), а апарат рухається під невеликим кутом до осі точки з бічним зміщенням `e_ct = 0.90 м`, максимальна довжина хорди перетину сфери траєкторією польоту становить:

```text
L_chord
= 2 · √(R_acc² − e_ct²)           [теорема Піфагора для хорди перетину сфери]
= 2 · √(1.0² − 0.90²)             [підстановка R_acc = 1.0 м, e_ct = 0.90 м]
= 2 · √(1.0 − 0.81)               [обчислення квадратів величин]
= 2 · √0.19                       [віднімання під знаком кореня]
≈ 2 · 0.4359                      [добування квадратного кореня]
≈ 0.8718 м                        [довжина хорди перетину]
```

Час перебування всередині кулі досягнення:

```text
t_in = L_chord / v = 0.8718 / 25 ≈ 0.0348 с
```

Якщо перший такт перевірки відбувся за мить до входу в сферу (`t = 0.00 с`), наступний такт відбудеться в момент `t = 0.02 с` (всередині сфери). Проте за несприятливої фази дискретизації та зміщення `e_ct = 0.95 м`:

```text
L_chord
= 2 · √(1.0² − 0.95²)             [теорема Піфагора для хорди перетину]
= 2 · √(1.0 − 0.9025)             [обчислення квадратів]
= 2 · √0.0975                     [віднімання під знаком кореня]
≈ 2 · 0.3122                      [добування квадратного кореня]
≈ 0.6245 м                        [довжина хорди перетину]
```

Час прольоту хорди:

```text
t_in = 0.6245 / 25 ≈ 0.0249 с
```

Якщо такт опитування давачів випадково потрапляє на момент за межами кулі (`t = -0.005 с`), а наступний такт у повільнішому навігаційному контурі (`10 Гц`, `Δt = 0.1 с`) припадає на `t = +0.095 с`, крок інтегрування `Δs = 2.5 м > 2 · R_acc` призводить до того, що дрон перелітає всю кулю за один крок, жодного разу не опинившись усередині неї в момент перевірки умови.

### Сценарій 2: Пастка нескінченного кружляння (Loiter Trap)

Якщо точка не була зарахована під час прольоту, апарат за алгоритмом прямого наведення на `W[k]` намагається повернутися назад.

Мінімальний радіус розвороту літака або швидкісного крила обмежений максимально допустимим кутом крену `φ_max`:

```text
R_min = v² / (g · tan(φ_max))
```

Для швидкості `v = 20 м/с` та кута крену `φ_max = 30°` (`tan(30°) ≈ 0.5774`, `g = 9.81 м/с²`):

```text
R_min
= 20² / (9.81 · tan(30°))         [формула радіуса координованого розвороту]
= 400 / (9.81 · 0.5774)           [підстановка числових значень]
= 400 / 5.664                     [множення в знаменнику]
≈ 70.62 м                         [мінімальний радіус розвороту]
```

Якщо `R_acc = 15 м`, апарат виконує віраж із радіусом `70.62 м` навколо точки `W[k]`. Якщо центр кола розвороту зміщений відносно точки `W[k]` менше ніж на `R_min − R_acc = 55.62 м`, траєкторія кола взагалі ніколи не перетинає кулю радіуса `15 м`.

За наявності вітрового зносу `V_wind` центр кола дрейфує за вітром, перетворюючи траєкторію на циклоїду, яка циклічно обертається довкола цільової точки без жодного шансу увійти в сферу `R_acc`.

## Аналіз чутливості до затримок давачів (Latency Sensitivity)

Оцінка положення `P(t)`, яку видає розширений фільтр Калмана (EKF), запізнюється відносно реального положення апарата на час затримки вимірювань `τ_delay` (GNSS latency + EKF fusion buffer delay, типово `0.08–0.15 с`).

Зсув фіксованої площини прольоту внаслідок затримки:

```text
Δs_delay = v · τ_delay
```

Для швидкості `v = 20 м/с` та затримки `τ_delay = 0.12 с`:

```text
Δs_delay
= 20 · 0.12                       [підстановка швидкості та затримки EKF]
= 2.40 м                          [просторове запізнення спрацьовування площини]
```

Оскільки затримка постійна вздовж усього відрізка, перетин площини фіксується на `2.4 м` далі по траєкторії польоту. Для звичайної місії похибка у 2.4 м уздовж лінії шляху не порушує топологію маршруту і в рази безпечніша за ризик пропуску точки в алгоритмах зі сферою досягнення.

## Комплексний критерій спрацьовування

Поєднання кулі досягнення та площини прольоту усуває всі перелічені вразливості:

```text
is_reached = (||P(t) − W[k]|| ≤ R_acc)  OR  ((P(t) − W[k]) · u_in ≥ 0  AND  ||e_ct(t)|| ≤ R_max_cross)
```

де `e_ct(t)` — вектор бічного відхилення від лінії відрізка:

```text
e_ct(t) = (P(t) − W[k-1]) − ((P(t) − W[k-1]) · u_in) · u_in
```

Обмеження `||e_ct(t)|| ≤ R_max_cross` (де типово `R_max_cross = 3 · R_acc` або `R_max_cross = L1_distance`) гарантує, що площина прольоту не спрацює випадково, якщо апарат летить на великій паралельній відстані від маршруту або повертається з аварійного режиму.
