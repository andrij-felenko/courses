# 🧮 Обчислення найкоротшої кутової дуги на колі S¹

Утримання курсу літального апарата або поворотної платформи спирається на неперервне вимірювання кута нишпорення (англ. *yaw*). На відміну від лінійних координат (метрів по осі X чи Z), кут живе на одновимірному топологічному колі `S¹` — компактному многовиді з періодичністю `2π` (або `360°`). Наївне віднімання цільового кута від поточного біля межі розриву числової шкали породжує катастрофічну похибку керування: замість довороту на пару градусів регулятор спрямовує апарат на повний виснажливий розворот у протилежний бік.

## Природа розриву шкали та топологія кола S¹

Кут курсу `ψ` у навігаційних системах традиційно задають у діапазоні `[-π, +π]` (радіани) або `[-180°, +180°]` (градуси), де `0` позначає географічну північ, `+π/2` — схід, `-π/2` — захід, а `±π` — південь. Точки `+180°` та `-180°` позначають абсолютно однаковий фізичний вектор у тривимірному просторі, проте в числовому представленні з плаваючою комою між ними лежить штучний розрив величиною `360°`.

Нехай апарат спрямований на південь із невеликим відхиленням на схід: `ψ_meas = +175°` (`+3.0543` рад). Уставка від планувальника місії вимагає довернути трохи на захід: `ψ_target = -175°` (`-3.0543` рад). Фізична відстань між цими двома орієнтаціями становить лише `10°` праворуч.

Якщо обчислити похибку лінійним відніманням дійсних чисел:

```
e_naive = ψ_target − ψ_meas
        = −175° − (+175°)
        = −350°  (−6.1087 рад)
```

Регулятор бачить гігантську похибку `-350°`, впадає в глибоке насичення по інтегральній і пропорційній складових і розкручує мотори на розворот ліворуч на `350°` замість короткого руху на `10°`. Це явище в теорії автоматичного керування називають **розкручуванням** (англ. *unwinding*). У реальному польоті це призводить до зриву супроводу цілі камерою, закручування кабелів підвісу, дезорієнтації навігаційного фільтра та раптового падіння висоти через дефіцит тяги під час тривалого обертання.

## Математична постановка задачі

Нехай задано дві точки на колі `θ₁, θ₂ ∈ [-π, π]`. Метрика найкоротшої геодезичної відстані `d(θ₁, θ₂)` на колі `S¹` визначається як довжина найменшої дуги, що з'єднує ці точки:

```
d(θ₁, θ₂) = min(|θ₁ − θ₂|, 2π − |θ₁ − θ₂|)
```

Для задач керування нам потрібна не просто абсолютна відстань, а **знакова похибка** `e ∈ (-π, +π]`, яка вказує точний напрямок і кут найкоротшого повороту:
- Додатне значення `e > 0` означає необхідність повороту проти годинникової стрілки (праворуч у системі координат літака).
- Від'ємне значення `e < 0` означає поворот за годинниковою стрілкою (ліворуч).

Значення похибки має задовольняти модульну конгруенцію:

```
e ≡ (ψ_target − ψ_meas) (mod 2π),   причому −π < e ≤ +π
```

## Методи програмної реалізації

Розглянемо чотири алгоритмічні підходи до розв'язання цього рівняння, їхню обчислювальну складність та крайові випадки.

### 1. Тригонометричний інваріант через atan2

Найелегантніший аналітичний спосіб спирається на тригонометричну тотожність різниці кутів та функцію арктангенса двох аргументів `atan2(y, x)`:

```
sin(Δψ) = sin(ψ_target − ψ_meas) = sin(ψ_target)·cos(ψ_meas) − cos(ψ_target)·sin(ψ_meas)
cos(Δψ) = cos(ψ_target − ψ_meas) = cos(ψ_target)·cos(ψ_meas) + sin(ψ_target)·sin(ψ_meas)

e = atan2(sin(Δψ), cos(Δψ))
```

Функція `atan2(y, x)` за стандартом IEEE 754 повертає кут вектора `(x, y)` строго в інтервалі `(-π, +π]`. Головна перевага методу — абсолютна математична стійкість: вираз не містить умовних переходів `if/else`, не боїться накопичення кратних періодів (навіть якщо аргумент дорівнює `100π`) і коректно обробляє особливу точку `-π`.

Головний недолік — висока обчислювальна вартість: обчислення `sin`, `cos` та `atan2` на мікроконтролерах Cortex-M4F без розширених інструкцій CORDIC займає від 150 до 300 тактів процесора, що є надмірним для високочастотних циклів (1 кГц).

### 2. Модульна арифметика з fmod

Стандартна бібліотечна функція взяття залишку від ділення чисел із плаваючою комою `fmodf(x, y)` у мовах C/C++ повертає значення з тим самим знаком, що й ділене `x` (наприклад, `fmodf(-1.0f, 6.28f) == -1.0f`). Через це пряме використання `fmod` для кутів вимагає фазового зсуву шкали:

:::tabs
```c
#include <math.h>

float wrap_pi_fmod(float angle) {
    const float two_pi = 2.0f * (float)M_PI;
    // Зсуваємо діапазон [-π, π] у [0, 2π)
    float a = fmodf(angle + (float)M_PI, two_pi);
    if (a < 0.0f) {
        a += two_pi; // корекція від'ємного залишку
    }
    return a - (float)M_PI;
}
```
```cpp
#include <cmath>
#include <numbers>

[[nodiscard]] constexpr float wrap_pi_fmod(float angle) noexcept {
    constexpr float kTwoPi = 2.0f * std::numbers::pi_v<float>;
    float a = std::fmod(angle + std::numbers::pi_v<float>, kTwoPi);
    if (a < 0.0f) {
        a += kTwoPi;
    }
    return a - std::numbers::pi_v<float>;
}
```
:::

Алгоритм виконує зсув на `+π`, зводить значення за модулем `2π` у додатний напівінтервал `[0, 2π)`, після чого повертає нуль координат назад відніманням `π`. Метод працює в 5–8 разів швидше за тригонометричний і підходить для будь-яких вхідних кутів.

### 3. Ітеративна нормалізація для малих кроків інтегрування

У замкнених контурах автопілота похибка між двома сусідніми тактами дискретизації рідко перевищує кілька градусів, оскільки частота циклу висока (100–500 Гц). У таких умовах достатньо простого розгалуження:

:::tabs
```c
#include <math.h>

float wrap_pi_fast(float angle) {
    while (angle > (float)M_PI)  angle -= 2.0f * (float)M_PI;
    while (angle < -(float)M_PI) angle += 2.0f * (float)M_PI;
    return angle;
}
```
```cpp
#include <numbers>

[[nodiscard]] constexpr float wrap_pi_fast(float angle) noexcept {
    while (angle > std::numbers::pi_v<float>)  angle -= 2.0f * std::numbers::pi_v<float>;
    while (angle < -std::numbers::pi_v<float>) angle += 2.0f * std::numbers::pi_v<float>;
    return angle;
}
```
:::

У 99.9% випадків цикл не виконує жодної ітерації (якщо кут уже лежить у межах), або виконує рівно одне віднімання/додавання на межі розриву. Це найефективніший код для контурів реального часу (1–3 такти процесора).

### 4. Цілочисельна двійкова кутова міра (BAM)

У спеціалізованих вбудованих системах керування кути представляють у двійковій кутовій мірі (англ. *Binary Angular Measurement*, BAM). Уся шкала `[0, 360°)` відображається на повний діапазон цілого беззнакового числа фіксованої розрядності, наприклад `uint16_t` (`0 .. 65535` дискрет) або `uint32_t`:

```
1 коло (2π рад) = 65536 дискрет (для 16 біт)
1 дискрета       = 360° / 65536 ≈ 0.005493° ≈ 0.33 кутової мінути
```

У цій системі обчислення найкоротшої різниці не вимагає жодних математичних функцій, умов або констант:

:::tabs
```c
#include <stdint.h>
#include <math.h>

float calc_heading_error_bam(float target_rad, float meas_rad) {
    uint16_t target_bam = (uint16_t)(target_rad * (32768.0f / (float)M_PI));
    uint16_t meas_bam   = (uint16_t)(meas_rad   * (32768.0f / (float)M_PI));

    // Апаратне переповнення беззнакового регістра реалізує операцію за модулем 2¹⁶:
    int16_t diff_bam = (int16_t)(target_bam - meas_bam);

    // Перетворення назад у плаваючу кому:
    return (float)diff_bam * ((float)M_PI / 32768.0f);
}
```
```cpp
#include <cstdint>
#include <numbers>

[[nodiscard]] constexpr float calc_heading_error_bam(float target_rad, float meas_rad) noexcept {
    constexpr float kRadToBam = 32768.0f / std::numbers::pi_v<float>;
    constexpr float kBamToRad = std::numbers::pi_v<float> / 32768.0f;

    const auto target_bam = static_cast<uint16_t>(target_rad * kRadToBam);
    const auto meas_bam   = static_cast<uint16_t>(meas_rad * kRadToBam);

    const auto diff_bam = static_cast<int16_t>(target_bam - meas_bam);
    return static_cast<float>(diff_bam) * kBamToRad;
}
```
:::

Переповнення беззнакового регістра процесора природно замикає топологію кільця. Інтерпретація результату як знакового числа `int16_t` автоматично перетворює відрізок `[0 .. 65535]` у симетричний інтервал `[-32768 .. +32767]`, тобто в `[-180°, +180°]`. Це найшвидший із можливих методів: на рівні асемблера він компілюється в одну інструкцію віднімання `SUB`.

## Кватерніонний вимір найкоротшої дуги у тривимірному просторі

Коли орієнтація апарата представлена кватерніоном `q = (w, x, y, z)`, де `w = cos(θ/2)` — скалярна частина, а `(x, y, z) = ê · sin(θ/2)` — векторна частина повороту навколо осі `ê`, виникає багатовимірний аналог проблеми розриву кола.

Кватерніони `q` та `-q` відповідають одній і тій самій фізичній матриці повороту в просторі `SO(3)` (подвійне покриття групою `SU(2)`). Проте з погляду метрики чотиривимірного простору між ними лежить повна довжина сфери.

Похибка орієнтації між поточним станом `q_meas` та цільовим `q_target` обчислюється як:

```
q_err = q_target ⊗ q_meas⁻¹
```

Якщо скалярна частина добутку виявилася від'ємною (`q_err.w < 0`), це свідчить про те, що алгоритм обрав «довгий» шлях обертання (кутовий поворот `θ > 180°`). Для вибору найкоротшої геодезичної траєкторії на тривимірній сфері виконують інверсію знака всього кватерніона:

:::tabs
```c
typedef struct { float w, x, y, z; } Quaternion;

void quat_shortest_arc(Quaternion *q_err) {
    if (q_err->w < 0.0f) {
        q_err->w = -q_err->w;
        q_err->x = -q_err->x;
        q_err->y = -q_err->y;
        q_err->z = -q_err->z;
    }
}
```
```cpp
struct Quaternion {
    float w{1.0f}, x{0.0f}, y{0.0f}, z{0.0f};

    void ensure_shortest_arc() noexcept {
        if (w < 0.0f) {
            w = -w;
            x = -x;
            y = -y;
            z = -z;
        }
    }
};
```
:::

Ця операція гарантує, що кут просторового довороту `θ = 2 · arccos(q_err.w)` не перевищує `180°`, повністю усуваючи просторове розкручування апарата по всіх трьох осях одночасно.
