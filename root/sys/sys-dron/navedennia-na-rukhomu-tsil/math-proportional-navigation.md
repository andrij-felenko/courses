# 🧮 Математика пропорційної навігації: кінематика зближення, оптимум коефіцієнта N та Zero Effort Miss

Математичний апарат пропорційного наведення розв'язує задачу зведення промаху до нуля за мінімальних енергетичних витрат рушійної установки. Якщо спрямовувати вектор швидкості переслідувача безпосередньо на рухомий об'єкт, виникає нелінійна крива погоні, де кутова швидкість обертання лінії візування стрімко зростає при зменшенні дальності. Пропорційна навігація (англ. *Proportional Navigation*, PN) змінює кінематичний зв'язок: поперечне командне прискорення формується пропорційно до кутової швидкості лінії візування, що утримує кут візування постійним та переводить зближення на траєкторію випередження.

---

### Диференціальні рівняння відносного руху в полярних координатах

Розглянемо плоский рух переслідувача (дрона `D`) та цілі (`T`) в інерційній системі координат `(X_I, Y_I)`. Положення цілі відносно дрона визначається вектором дальності `R = r_t - r_d` довжиною `R = ||R||` та кутом нахилу лінії візування (англ. *Line-of-Sight*, LOS) `λ` відносно осі `X_I`.

Введемо рухомий полярний базис `(e_r, e_λ)`, де одиничний вектор `e_r` спрямований вздовж вектора дальності від дрона до цілі, а орт `e_λ` перпендикулярний до нього в бік зростання кута `λ`:

```
e_r = [cos(λ), sin(λ)]ᵀ
e_λ = [-sin(λ), cos(λ)]ᵀ
```

Похідні ортів за часом визначаються кутовою швидкістю лінії візування `Ω = dλ/dt`:

```
d(e_r)/dt
= [-sin(λ)·(dλ/dt), cos(λ)·(dλ/dt)]ᵀ   [диференціювання за часом]
= Ω · e_λ                             [підстановка орта e_λ]
```

```
d(e_λ)/dt
= [-cos(λ)·(dλ/dt), -sin(λ)·(dλ/dt)]ᵀ  [диференціювання за часом]
= -Ω · e_r                            [підстановка орта e_r]
```

Вектор відносного положення цілі записується як `R = R · e_r`. Знайдемо першу похідну вектора дальності за часом, тобто вектор відносної швидкості `V_r`:

```
V_r = dR/dt
= (dR/dt)·e_r + R·(d(e_r)/dt)         [правило диференціювання добутку]
= Ṙ·e_r + R·Ω·e_λ                     [підстановка похідної орта d(e_r)/dt]
```

Радіальна складова `Ṙ = dR/dt` пов'язана зі швидкістю зближення `V_c` співвідношенням `V_c = -Ṙ`. Поперечна складова відносної швидкості дорівнює `V_λ = R · Ω`.

Знайдемо вектор відносного прискорення `a_rel = a_t - a_d` через другу похідну:

```
a_rel = d(V_r)/dt
= d(Ṙ·e_r + R·Ω·e_λ)/dt               [похідна вектора відносної швидкості]
= R̈·e_r + Ṙ·(d(e_r)/dt) + (Ṙ·Ω + R·Ω̇)·e_λ + R·Ω·(d(e_λ)/dt) [диференціювання суми]
= R̈·e_r + Ṙ·Ω·e_λ + Ṙ·Ω·e_λ + R·Ω̇·e_λ - R·Ω²·e_r [підстановка похідних ортів]
= (R̈ - R·Ω²)·e_r + (R·Ω̇ + 2·Ṙ·Ω)·e_λ   [групування за ортами e_r та e_λ]
```

Проєктуючи векторне рівняння на осі `e_r` та `e_λ`, отримуємо фундаментальну систему диференціальних рівнянь кінематики зближення:

```
R̈ - R·Ω² = a_t_r - a_d_r              [радіальне рівняння руху]
R·Ω̇ + 2·Ṙ·Ω = a_t_λ - a_d_λ          [трансверсальне рівняння руху]
```

У трансверсальному рівнянні член `2·Ṙ·Ω = -2·V_c·Ω` являє собою поворотне прискорення Коріоліса, зумовлене обертанням системи координат лінії візування.

### Лінеаризація та точний розв'язок рівняння пропорційної навігації

Закон істинного пропорційного наведення (англ. *True Proportional Navigation*, TPN) вимагає прикладання нормального прискорення переслідувача перпендикулярно до лінії візування:

```
a_d_λ = a_cmd = N · V_c · Ω
```

де `N` — безрозмірний навігаційний коефіцієнт (англ. *navigation ratio*).

Припустимо, що ціль рухається без прискорення (`a_t_λ = 0`), а швидкість зближення `V_c = -Ṙ` залишається практично постійною протягом перехоплення. Тоді час до зустрічі (англ. *time-to-go*) дорівнює `t_go = t_f - t = R / V_c`, де `t_f` — кінцевий момент зустрічі.

Підставимо закон керування `a_d_λ = N · V_c · Ω` у трансверсальне рівняння кінематики:

```
R·(dΩ/dt) + 2·Ṙ·Ω = -N·V_c·Ω          [підстановка a_cmd у трансверсальне рівняння]
R·(dΩ/dt) - 2·V_c·Ω = -N·V_c·Ω         [заміна Ṙ на -V_c]
R·(dΩ/dt) = (2 - N)·V_c·Ω              [перенесення членів з Ω вправо]
```

Розділимо змінні, враховуючи, що `R = V_c · (t_f - t)` та `dR = -V_c · dt`:

```
(1/Ω) · dΩ
= ((2 - N)·V_c / R) · dt               [розділення змінних]
= ((2 - N)·V_c / (V_c·(t_f - t))) · dt [підстановка R = V_c·(t_f - t)]
= ((N - 2) / (t_f - t)) · dt           [скорочення V_c та зміна знаку]
```

Інтегруємо обидві частини від початкового моменту `t = 0` (де `Ω = Ω_0`) до довільного часу `t`:

```
ln(Ω(t) / Ω_0)
= ∫₀ᵗ ((N - 2) / (t_f - τ)) dτ         [інтегрування за часом]
= -(N - 2) · ln((t_f - t) / t_f)       [первісна від 1/(t_f - τ)]
= (N - 2) · ln(t_f / (t_f - t))        [властивість логарифма]
= ln((1 - t/t_f)^(2 - N))              [внесення степеня під логарифм]
```

Потенціюючи отриманий вираз, маємо аналітичну залежність кутової швидкості лінії візування від часу:

```
Ω(t) = Ω_0 · (1 - t/t_f)^(N - 2)
```

Підставивши вираз для `Ω(t)` у закон пропорційного наведення, отримуємо замкнений вираз для командного прискорення дрона:

```
a_cmd(t) = N · V_c · Ω_0 · (1 - t/t_f)^(N - 2)
```

### Аналіз поведінки траєкторії та прискорення залежно від коефіцієнта N

Отримана формула `a_cmd(t) = N · V_c · Ω_0 · (1 - t/t_f)^(N - 2)` розкриває фундаментальні властивості пропорційного наведення при наближенні до цілі (`t → t_f`, тобто `(1 - t/t_f) → 0`):

1. **Випадок `N < 2` (зокрема чиста погоня `N = 1`):**
   Показник степеня `N - 2 < 0`. При `t → t_f` величина `(1 - t/t_f)^(N-2) → ∞`.
   Потрібне командне прискорення необмежено зростає на фінальній ділянці траєкторії:
   ```
   lim_{t → t_f} a_cmd(t) = ∞         [при N < 2]
   ```
   Будь-який реальний дрон має обмеження тяги мотора та нормального прискорення `|a_cmd| ≤ a_max`. При досягненні насичення контур втрачає здатність компенсувати обертання лінії візування, що призводить до динамічного зриву та промаху.

2. **Випадок `N = 2`:**
   Показник степеня `N - 2 = 0`. Командне прискорення залишається постійним протягом усього часу зближення:
   ```
   a_cmd(t) = 2 · V_c · Ω_0 = const   [при N = 2]
   ```
   Прискорення не розходиться, проте початкова помилка курсу не зменшується за амплітудою керування.

3. **Випадок `N > 2` (стандартні значення `N ∈ [3, 5]`):**
   Показник степеня `N - 2 > 0`. При наближенні до цілі (`t → t_f`) величина `(1 - t/t_f)^(N-2) → 0`:
   ```
   lim_{t → t_f} a_cmd(t) = 0         [при N > 2]
   ```
   Дрон активно маневрує на початку зближення, виправляючи початковий кутовий неузгоджений пеленг, після чого виходить на прямолінійний курс зустрічі. Біля цілі лінія візування перестає обертатися (`Ω → 0`), а необхідне прискорення спадає до нуля.

### Оптимальність коефіцієнта N = 3 через принцип мінімуму Понтрягіна та ZEM

Розглянемо задачу синтезу оптимального керування, яка мінімізує інтегральні енергетичні витрати перехоплювача при гарантії нульового кінцевого промаху.

Визначимо поняття неухильного промаху (англ. *Zero Effort Miss*, ZEM) — відстані, на яку дрон розминеться з ціллю у момент `t_f`, якщо починаючи з поточного часу `t` обидва об'єкти рухатимуться прямолінійно без прискорень (`a_d = 0`, `a_t = 0`).

Для лінеаризованої геометрії вздовж осі, перпендикулярної до початкової лінії візування, поточне відносне поперечне зміщення позначимо `y(t)`, а відносну швидкість `v_y(t) = ẏ(t)`. Тоді ZEM обчислюється як:

```
ZEM(t) = y(t) + v_y(t) · t_go
```

де `t_go = t_f - t`.

Диференціал ZEM за часом дорівнює:

```
d(ZEM)/dt
= ẏ + v̇_y·t_go + v_y·(d(t_go)/dt)     [диференціювання добутку]
= v_y + (a_t_y - a_cmd)·t_go - v_y    [підстановка v̇_y = a_t_y - a_cmd та d(t_go)/dt = -1]
= (a_t_y - a_cmd) · t_go              [скорочення швидкості v_y]
```

Для неманевруючої цілі (`a_t_y = 0`) маємо просте диференціальне рівняння еволюції промаху:

```
d(ZEM)/dt = -a_cmd(t) · t_go
```

Сформулюємо варіаційну задачу оптимального керування. Необхідно знайти закон `a_cmd(t)`, що мінімізує функціонал витрат енергії:

```
J = (1/2) · ∫₀ᵗᶠ (a_cmd(t))² dt
```

за термінальної крайової умови нульового промаху:

```
ZEM(t_f) = 0
```

Складемо функцію Гамільтона-Понтрягіна `H` з спряженою змінною (множником Лагранжа) `p(t)`:

```
H(ZEM, a_cmd, p, t) = (1/2)·(a_cmd)² + p·(-a_cmd · t_go)
```

З умови стаціонарності Гамільтоніана за керуванням `∂H/∂a_cmd = 0`:

```
a_cmd - p · t_go = 0
a_cmd*(t) = p(t) · t_go               [оптимальне командне прискорення]
```

Рівняння для спряженої змінної `p(t)`:

```
dp/dt = -∂H/∂ZEM = 0  ⇒  p(t) = p₀ = const [спряжена змінна є константою]
```

Звідси optimal acceleration набуває вигляду:

```
a_cmd*(t) = p₀ · (t_f - t)
```

Підставимо оптимальне керування в диференціальне рівняння для ZEM та проінтегруємо від `t` до `t_f`:

```
ZEM(t_f) - ZEM(t)
= -∫ₜᵗᶠ a_cmd*(τ) · (t_f - τ) dτ      [інтегрування від t до t_f]
= -∫ₜᵗᶠ p₀ · (t_f - τ)² dτ             [підстановка a_cmd*(τ) = p₀·(t_f - τ)]
= -p₀ · [-(t_f - τ)³ / 3]ₜᵗᶠ           [обчислення визначеного інтеграла]
= -p₀ · (t_f - t)³ / 3                [підстановка верхньої та нижньої меж]
= -p₀ · t_go³ / 3                     [заміна (t_f - t) на t_go]
```

Оскільки термінальна умова вимагає `ZEM(t_f) = 0`, маємо:

```
0 - ZEM(t) = -p₀ · (t_go³ / 3)
p₀ = (3 · ZEM(t)) / t_go³             [вираження константи Лагранжа через поточний ZEM]
```

Підставляючи отримане значення `p₀` у вираз для `a_cmd*(t)`:

```
a_cmd*(t)
= p₀ · t_go                           [закон оптимального прискорення]
= (3 · ZEM(t) / t_go³) · t_go         [підстановка p₀]
= (3 / t_go²) · ZEM(t)                [оптимальне прискорення через ZEM]
```

Зв'яжемо ZEM з кутовою швидкістю лінії візування `Ω`. За геометричним визначенням:

```
ZEM(t) = R(t) · (λ_collision - λ(t)) ≈ R(t) · Ω(t) · t_go
```

Підставляючи цей зв'язок у закон оптимального керування:

```
a_cmd*(t)
= (3 / t_go²) · (R · Ω · t_go)        [підстановка ZEM = R·Ω·t_go]
= 3 · (R / t_go) · Ω                  [скорочення t_go]
= 3 · V_c · Ω                         [підстановка V_c = R / t_go]
```

Ми отримали класичний закон пропорційної навігації з коефіцієнтом `N = 3`. Це доводить, що **навігаційний коефіцієнт `N = 3` є строго оптимальним за критерієм мінімуму інтеграла квадрата прискорення** для неманевруючої цілі.

### Розширена пропорційна навігація (Augmented PN, APN) для маневруючих цілей

Якщо ціль маневрує з постійним поперечним прискоренням `a_t_y = const`, невгамовний промах `ZEM` набуває додаткового квадратичного члена за часом:

```
ZEM_aug(t) = y(t) + v_y(t)·t_go + (1/2)·a_t_y·t_go²
```

Повторюючи варіаційне виведення за критерієм мінімуму енергії для модифікованого стану, отримуємо закон розширеної пропорційної навігації (англ. *Augmented Proportional Navigation*, APN):

```
a_cmd_APN(t)
= (3 / t_go²) · ZEM_aug(t)            [оптимальне керування через повний ZEM]
= (3 / t_go²) · (R·Ω·t_go + (1/2)·a_t_y·t_go²) [розкриття складових ZEM]
= 3·(R/t_go)·Ω + (3/2)·a_t_y          [ділення на t_go²]
= 3 · V_c · Ω + (N / 2) · a_t_perp    [канонічна форма закону APN для N = 3]
```

Для довільного навігаційного коефіцієнта `N` узагальнений закон APN записується у векторній формі:

```
a_cmd_APN = N · V_c · (Ω × e_los) + (N / 2) · a_t_perp
```

Член `(N / 2) · a_t_perp` забезпечує пряму компенсацію прискорення цілі (англ. *feedforward acceleration compensation*). Завдяки цьому дрон не відстає від маневруючої цілі у фазовому запізненні, а кутова швидкість лінії візування `Ω` асимптотично прямує до нуля навіть за наявності постійного поперечного перевантаження цілі.
