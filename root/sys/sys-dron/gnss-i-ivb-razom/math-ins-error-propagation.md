# 🧮 Математика простору похибок навігаційного фільтра (ES-EKF)

У розширеному фільтрі Калмана для комплексування супутникових та інерціальних вимірювань (GNSS/INS) пряме оцінювання повного вектора стану (True-State EKF) призводить до значних обчислювальних ускладнень і ризику втрати стійкості. Повна орієнтація апарата здійснюється у тривимірному просторі через нелінійні кінематичні залежності, а кути Ейлера мають геометричні сингулярності (блокування рамок). 

Замість прямої лінеаризації великих поворотів сучасні польотні контролери (зокрема архітектури EKF2 та EKF3 в PX4 та ArduPilot) використовують **фільтр стану похибок** (Error-State Extended Kalman Filter, ES-EKF). У цій архітектурі повний стан розділяється на дві незалежні складові:
1. **Номінальний стан** `x` — великомасштабні змінні (координати, швидкість, кватерніон орієнтації), які інтегруються на високій частоті (250–1000 Гц) за допомогою точних нелінійних кінематичних рівнянь без жодної лінеаризації.
2. **Стан похибок** `δx` — маломасштабні відхилення істинного стану від номінального, які описуються строго лінійними диференціальними рівняннями.

Оскільки стан похибок завжди залишається малим поблизу нуля (завдяки постійній інжекції поправок у номінальний стан), лінеаризація першого порядку є математично точною, коваріаційна матриця не містить сингулярностей, а тривимірна похибка орієнтації описується звичайним вектором кутових нев'язок `δθ` у дотичному просторі Лі до групи обертань SO(3).

## Вектор стану похибок

Повний вектор стану похибок `δx` має розмірність 15×1:

```
δx = [ δpᵀ,  δvᵀ,  δθᵀ,  δb_aᵀ,  δb_gᵀ ]ᵀ
```

де складові вектора визначаються як:
- `δp = [δp_N, δp_E, δp_D]ᵀ` — вектор похибки координат у локальній навігаційній системі NED (North, East, Down), метри;
- `δv = [δv_N, δv_E, δv_D]ᵀ` — вектор похибки лінійної швидкості у системі NED, м/с;
- `δθ = [δθ_x, δθ_y, δθ_z]ᵀ` — вектор кутової похибки просторової орієнтації у зв'язаній системі координат Body, радіани;
- `δb_a = [δb_ax, δb_ay, δb_az]ᵀ` — похибка оцінки зміщення нуля (bias) тривісного акселерометра, м/с²;
- `δb_g = [δb_gx, δb_gy, δb_gz]ᵀ` — похибка оцінки зміщення нуля тривісного гіроскопа, рад/с.

Зв'язок між істинним станом `(p_true, v_true, R_true)`, номінальним станом `(p, v, R)` та похибками `(δp, δv, δθ)` задається співвідношеннями:

```
p_true = p + δp
v_true = v + δv
R_true = R · Exp([δθ]×) ≈ R · (I + [δθ]×)
```

де `R` — матриця повороту зі зв'язаної системи координат Body в навігаційну систему NED, побудована з номінального кватерніона `q`, а оператор `[v]×` позначає кососиметричну матрицю векторного добутку:

```
[v]× = [  0   -v_z   v_y ]
       [  v_z   0   -v_x ]
       [ -v_y  v_x    0  ]
```

## Неперервні диференціальні рівняння похибок

Істинні вимірювання інерціального блока (IMU) містять шум та невідомі зміщення:

```
ω_meas = ω_true + b_g + w_g
f_meas = f_true + b_a + w_a
```

де `f_true = Rᵀ · (a_true − g)` — питома сила, що діє на чутливі елементи акселерометра, `g = [0, 0, g₀]ᵀ` — вектор гравітаційного прискорення в системі NED, а `w_g ~ N(0, σ_g² I)` та `w_a ~ N(0, σ_a² I)` — високочастотні білі шуми вимірювань (кутковий та швидкісний випадковий блукання).

Динаміка зміни номінального стану описується класичними рівняннями інерціальної навігації (Strapdown INS Mechanization):

```
ṗ = v
v̇ = R · (f_meas − b_a) + g
Ṙ = R · [ω_meas − b_g]×
```

Знайдемо похідні похибок за часом, віднімаючи номінальну динаміку від істинної.

### 1. Похибка положення

```
δṗ = ṗ_true − ṗ
   = v_true − v          [підстановка визначення похідної координат]
   = δv                  [за визначенням вектора похибки швидкості]
```

### 2. Похибка орієнтації

Диференціюючи вираз `R_true = R · (I + [δθ]×)` та підставляючи рівняння кінематики кутової швидкості:

```
Ṙ_true = Ṙ · (I + [δθ]×) + R · [δθ̇]×
R_true · [ω_true]× = R · [ω_meas − b_g]× · (I + [δθ]×) + R · [δθ̇]×
```

Після перенесення доданків, використання наближення першого порядку та врахування `ω_true = ω_meas − b_g − δb_g − w_g`:

```
[δθ̇]× = −[ω_meas − b_g]× · [δθ]× + [δθ]× · [ω_meas − b_g]× − [δb_g + w_g]×
δθ̇ = −[ω_meas − b_g]× · δθ − δb_g − w_g
```

У компактному вигляді для кутової швидкості оцінки `ω̂ = ω_meas − b_g`:

```
δθ̇ = −[ω̂]× · δθ − δb_g − w_g
```

### 3. Похибка швидкості

Диференціюємо похибку швидкості:

```
δv̇ = v̇_true − v̇
   = (R_true · f_true + g) − (R · (f_meas − b_a) + g)
   = R · (I + [δθ]×) · (f_meas − b_a − δb_a − w_a) − R · (f_meas − b_a)
```

Розкриваючи дужки та нехтуючи добутками малих величин другого порядку `[δθ]× · δb_a` та `[δθ]× · w_a`:

```
δv̇ = R · [δθ]× · (f_meas − b_a) − R · δb_a − R · w_a
```

Використовуючи тотожність векторного добутку `[a]× · b = −[b]× · a` та позначаючи оцінену питому силу як `f̂ = f_meas − b_a`:

```
δv̇ = −R · [f̂]× · δθ − R · δb_a − R · w_a
```

### 4. Динаміка зміщень давачів (Bias Random Walk)

Зміщення нуля акселерометрів та гіроскопів моделюються як випадкові блукання (вінеровські процеси), похідні яких є білим шумом:

```
δḃ_a = w_ba,    w_ba ~ N(0, σ_ba² I)
δḃ_g = w_bg,    w_bg ~ N(0, σ_bg² I)
```

## Матрична форма системи неперервного часу

Об'єднуючи виведені рівняння, отримуємо лінійну систему стохастичних диференціальних рівнянь:

```
δẋ(t) = F_c(t) · δx(t) + G_c(t) · w(t)
```

де матриця динаміки системи `F_c` розміром 15×15 має блочну структуру:

```
F_c = [  0₃   I₃        0₃          0₃       0₃   ]
      [  0₃   0₃   -R·[f̂]×        -R       0₃   ]
      [  0₃   0₃    -[ω̂]×         0₃       -I₃  ]
      [  0₃   0₃        0₃          0₃       0₃   ]
      [  0₃   0₃        0₃          0₃       0₃   ]
```

Тут `0₃` та `I₃` — нульова та одинична матриці 3×3 відповідно.

Вектор шумів процесу `w = [w_aᵀ, w_gᵀ, w_baᵀ, w_bgᵀ]ᵀ` розмірністю 12×1 має спектральну густину потужності `Q_c`:

```
Q_c = diag( σ_a² I₃,  σ_g² I₃,  σ_ba² I₃,  σ_bg² I₃ )
```

Матриця впливу шумів `G_c` розміром 15×12 визначається як:

```
G_c = [  0₃    0₃    0₃    0₃  ]
      [ -R     0₃    0₃    0₃  ]
      [  0₃   -I₃    0₃    0₃  ]
      [  0₃    0₃    I₃    0₃  ]
      [  0₃    0₃    0₃    I₃  ]
```

## Дискретизація рівнянь для реалізації в EKF

Польотний контролер виконує обчислення дискретно з інтервалом інтегрування `Δt` (наприклад, `Δt = 0.004` с для 250 Гц).

### 1. Матриця переходу стану (State Transition Matrix)

Для інтервалу `Δt` матриця переходу `Φ` обчислюється через матричну експоненту:

```
Φ = exp(F_c · Δt)
```

Для вбудованих мікроконтролерів обчислення повної матричної експоненти 15×15 є надто ресурсомістким, тому використовують аналітичне розкладання ряду Тейлора другого порядку:

```
Φ ≈ I₁₅ + F_c · Δt + 0.5 · (F_c · Δt)²
```

З урахуванням розрідженої блочної структури `F_c`, ненульові блоки матриці `Φ` обчислюються безпосередньо:

```
Φ[0..2, 0..2] = I₃
Φ[0..2, 3..5] = I₃ · Δt
Φ[0..2, 6..8] = -0.5 · R · [f̂]× · Δt²
Φ[0..2, 9..11] = -0.5 · R · Δt²
Φ[3..5, 3..5] = I₃
Φ[3..5, 6..8] = -R · [f̂]× · Δt
Φ[3..5, 9..11] = -R · Δt
Φ[6..8, 6..8] = I₃ - [ω̂]× · Δt
Φ[6..8, 12..14] = -I₃ · Δt
Φ[9..11, 9..11] = I₃
Φ[12..14, 12..14] = I₃
```

### 2. Дискретна матриця коваріації шуму процесу

Дискретна коваріація шуму процесу `Q_d` розраховується через числове або аналітичне інтегрування інтеграла Ван Лоана:

```
Q_d = ∫₀^{Δt} Φ(τ) · G_c · Q_c · G_cᵀ · Φᵀ(τ) dτ
```

У наближенні першого порядку з точністю `O(Δt)`:

```
Q_d ≈ G_c · Q_c · G_cᵀ · Δt
```

Діагональні блоки матриці `Q_d`:
- Для позиції: `Q_p = 0.5 · σ_a² · Δt³ · I₃` (або `0₃` для першого порядку);
- Для швидкості: `Q_v = σ_a² · Δt · I₃`;
- Для орієнтації: `Q_θ = σ_g² · Δt · I₃`;
- Для зміщення акселерометра: `Q_ba = σ_ba² · Δt · I₃`;
- Для зміщення гіроскопа: `Q_bg = σ_bg² · Δt · I₃`.

## Крок передбачення коваріації похибок

На кожному такті надходження даних від IMU коваріаційна матриця стану похибок `P` (розміром 15×15) поширюється вперед у часі за класичним рівнянням Калмана:

```
P_{k|k-1} = Φ_k · P_{k-1|k-1} · Φ_kᵀ + Q_d
```

Для збереження числової стійкості та симетрії матриці `P` після множення виконують примусову симетризацію:

```
P = 0.5 · (P + Pᵀ)
```

## Лінеаризація вимірювань GNSS

У слабкозв'язаній схемі комплексування (Loosely Coupled) вектор вимірювань GNSS складається з координат і швидкостей у системі NED:

```
z_gnss = [ p_gnssᵀ,  v_gnssᵀ ]ᵀ   (розмірність 6×1)
```

Рівняння спостереження для номінального стану:

```
h(x) = [ p,  v ]ᵀ
```

Матриця чутливості вимірювань `H = ∂h/∂(δx)` має розмірність 6×15:

```
H = [ I₃   0₃   0₃   0₃   0₃ ]
    [ 0₃   I₃   0₃   0₃   0₃ ]
```

Нев'язка вимірювання (інновація):

```
y = z_gnss − h(x_nom) = [ p_gnss − p,  v_gnss − v ]ᵀ
```

Коваріація інновації `S` розміром 6×6:

```
S = H · P · Hᵀ + R_gnss
```

де `R_gnss = diag(σ_p_hor², σ_p_hor², σ_p_vert², σ_v_hor², σ_v_hor², σ_v_vert²)` — коваріаційна матриця похибок вимірювань GNSS-приймача.

Оптимальний коефіцієнт підсилення Калмана `K` розміром 15×6:

```
K = P · Hᵀ · S⁻¹
```

Оцінка стану похибок:

```
δx̂ = K · y
```

## Інжекція стану похибок та скидання (Error-State Feedback & Reset)

Після обчислення `δx̂ = [δp̂ᵀ, δv̂ᵀ, δθ̂ᵀ, δb̂_aᵀ, δb̂_gᵀ]ᵀ` накопичені похибки застосовуються для корекції номінального стану:

```
p_new = p + δp̂
v_new = v + δv̂
q_new = q ⊗ [ 1,  0.5 · δθ̂ᵀ ]ᵀ    [нормалізація: q_new = q_new / ||q_new||]
b_a_new = b_a + δb̂_a
b_g_new = b_g + δb̂_g
```

Оновлення коваріаційної матриці за числово-стійкою формою Джозефа:

```
P_new = (I₁₅ − K · H) · P · (I₁₅ − K · H)ᵀ + K · R_gnss · Kᵀ
```

Оскільки похибка була повністю передана в номінальний стан, математичне сподівання стану похибок знову стає строго рівним нулю `δx̂ = 0`, що гарантує збереження лінійності для всіх наступних кроків інтегрування.
