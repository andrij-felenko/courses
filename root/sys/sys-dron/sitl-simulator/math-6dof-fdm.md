# 🧮 Математична модель динаміки польоту 6 DOF та інтегрування стану

Усі безпілотні літальні апарати в симуляторі підкоряються єдиній системі нелінійних диференціальних рівнянь руху твердого тіла з шістьма ступенями вільності (англ. *six degrees of freedom* — 6 DOF). Без точного розрахунку цих рівнянь симуляція перетворюється на візуальну анімацію: автопілот не зможе налаштувати коефіцієнти [PID-регуляторів](root:com-signal/discrete-pid), перевірити збіжність [фільтра Калмана EKF](root:com-signal/kalman-ekf) чи виявити нестійкість контурів керування на високих кутових швидкостях.

Тут наведено повне математичне виведення поступального й обертального руху, кінематики кватерніонів, аеродинамічних сил, моментів роторів та чисельного методу інтегрування Рунге-Кутти 4-го порядку (RK4).

## 1. Системи координат та параметризація вектора стану

Динаміка польоту описується у двох базових тривимірних правосторонніх декартових системах координат:

1. **Навігаційна система NED (North-East-Down):** нерухома відносно поверхні Землі точка старту. Вісь `X_n` спрямована строго на північ, `Y_n` — на схід, `Z_n` — вертикально вниз за місцевим вектором гравітації Землі. Ця система відліку вважається локально інерційною для польотів малого радіуса.
2. **Зв'язана система координат Body Frame:** жорстко зафіксована на конструкції літального апарата з початком у центрі мас. Вісь `X_b` спрямована вперед уздовж поздовжньої осі (ніс апарата), `Y_b` — у бік правого крила або правого променя, `Z_b` — крізь днище апарата вертикально вниз.

Повний вектор стану літального апарата `x` розмірністю 13×1 однозначно визначає кінематичний і динамічний стан системи в кожен момент часу:

```
x = [ r_n,  v_n,  q_nb,  ω_b ]ᵀ

r_n = [x, y, z]ᵀ             — положення в системі NED (метри)
v_n = [v_x, v_y, v_z]ᵀ       — лінійна швидкість у системі NED (м/с)
q_nb = [q₀, q₁, q₂, q₃]ᵀ     — кватерніон орієнтації (поворот Body відносно NED)
ω_b = [p, q, r]ᵀ             — кутова швидкість у системі Body (рад/с)
```

## 2. Матриця напрямних косинусів та кінематика кватерніонів

Для переходу між системою координат NED та зв'язаною системою Body застосовується нормований [кватерніон орієнтації](root:math-geometry/quaternions) `q_nb = [q₀, q₁, q₂, q₃]ᵀ`, де `q₀` — скалярна частина, а `[q₁, q₂, q₃]ᵀ` — векторна частина. Кватерніон усуває математичну сингулярність шарнірного замка (Gimbal Lock), яка виникає в кутах Ейлера при вертикальному тангажі `θ = ±90°`.

Матриця повороту `R_nb` (переведення координат вектора зі зв'язаної системи Body в навігаційну систему NED) виражається через елементи кватерніона:

```
R_nb = 
[ q₀² + q₁² - q₂² - q₃²,   2·(q₁·q₂ - q₀·q₃),     2·(q₁·q₃ + q₀·q₂)     ]
[ 2·(q₁·q₂ + q₀·q₃),     q₀² - q₁² + q₂² - q₃²,   2·(q₂·q₃ - q₀·q₁)     ]
[ 2·(q₁·q₃ - q₀·q₂),     2·(q₂·q₃ + q₀·q₁),     q₀² - q₁² - q₂² + q₃² ]
```

Зворотне перетворення здійснюється транспонованою ортогональною матрицею `R_bn = R_nbᵀ`.

Диференціальне рівняння кінематики кватерніона визначає швидкість зміни орієнтації під впливом поточної кутової швидкості апарата `ω_b = [p, q, r]ᵀ`:

```
q̇_nb = 0.5 · q_nb ⊗ [0, ω_b]ᵀ = 0.5 · Ω(ω_b) · q_nb

де кососиметрична матриця кутових швидкостей має вигляд:
Ω(ω_b) = 
[  0   -p   -q   -r  ]
[  p    0    r   -q  ]
[  q   -r    0    p  ]
[  r    q   -p    0  ]
```

## 3. Динаміка поступального руху за Ньютоном

Зміна лінійної швидкості в навігаційній системі відліку визначається другим законом Ньютона. Сумарне прискорення утворюється результуючою силою тяги рушіїв `F_thrust_b`, аеродинамічним опором `F_aero_b`, зовнішніми збуреннями `F_ext_n` та гравітаційним прискоренням:

```
m · v̇_n = R_nb · ( F_thrust_b + F_aero_b ) + F_ext_n + m · g_n

v̇_n = (1 / m) · R_nb · F_total_b + g_n
```

Де:
- `m` — повна злітна маса літального апарата (кг);
- `g_n = [0, 0, +9.80665]ᵀ` м/с² — вектор прискорення вільного падіння у системі координат NED;
- `F_total_b = [F_x, F_y, F_z]ᵀ` — вектор сумарних сил, прикладених до центру мас у системі Body.

Швидкість зміни просторових координат положення апарата:

```
ṙ_n = v_n
```

## 4. Динаміка обертального руху твердого тіла за Ейлером

Рівняння динаміки обертання твердого тіла навколо центру мас у зв'язаній системі координат Body враховують тензор моментів інерції `J` та перехресні гіроскопічні моменти:

```
J · ω̇_b + ω_b × (J · ω_b) + M_gyro = M_total_b

ω̇_b = J⁻¹ · ( M_total_b - ω_b × (J · ω_b) - M_gyro )
```

Тензор інерції апарата `J` є симетричною додатно визначеною матрицею 3×3:

```
J = 
[  I_xx   -I_xy   -I_xz ]
[ -I_xy    I_yy   -I_yz ]
[ -I_xz   -I_yz    I_zz ]
```

Для мультироторних платформ із симетричною геометрією променів відносно площин симетрії відцентрові моменти інерції прямують до нуля (`I_xy ≈ I_xz ≈ I_yz ≈ 0`). У цьому випадку рівняння Ейлера спрощуються до трьох скалярних диференціальних рівнянь для кутових прискорень по осях крену (`p`), тангажу (`q`) та рискання (`r`):

```
ṗ = ( (I_yy - I_zz) · q · r + M_x - M_gyro_x ) / I_xx
q̇ = ( (I_zz - I_xx) · p · r + M_y - M_gyro_y ) / I_yy
ṙ = ( (I_xx - I_yy) · p · q + M_z ) / I_zz
```

Гіроскопічний момент від обертання гвинтів із власним моментом інерції ротора `J_prop` та кутовою швидкістю `Ω_i`:

```
M_gyro = ∑ [ J_prop · (ω_b × [0, 0, 1]ᵀ) · d_i · Ω_i ]
```

де `d_i = +1` для гвинтів правого обертання (CW) та `d_i = -1` для гвинтів лівого обертання (CCW).

## 5. Модель сил і керуючих моментів безколекторних моторів

Для типового квадрокоптера схеми `Quad-X` тяга `T_i` та аеродинамічний реактивний крутний момент `Q_i` кожного окремого ротора пропорційні квадрату кутової швидкості обертання `Ω_i` (рад/с):

```
T_i = C_T · ρ · D⁴ · (Ω_i / (2·π))² = k_t · Ω_i²
Q_i = C_Q · ρ · D⁵ · (Ω_i / (2·π))² = k_q · Ω_i²
```

Де:
- `C_T, C_Q` — безрозмірні аеродинамічні коефіцієнти тяги та моменту лопаті гвинта;
- `ρ` — густина повітря на поточній висоті польоту (кг/м³);
- `D` — геометричний діаметр пропелера (метри);
- `k_t, k_q` — коефіцієнти тяги та аеродинамічного опору обертанню.

Сумарна сила тяги чотирьох двигунів діє вздовж від'ємного напрямку осі `Z_b` (спрямована вгору відносно корпусу):

```
F_thrust_b = [ 0, 0, -(T₁ + T₂ + T₃ + T₄) ]ᵀ
```

Керуючі моменти крену `M_x`, тангажу `M_y` та рискання `M_z` при відстані від центру мас до осі двигуна `L` розраховуються за геометрією розташування променів:

```
d = L / √2

M_x = d · (-T₁ + T₂ + T₃ - T₄)      [момент крену: різниця тяг правого й лівого бортів]
M_y = d · ( T₁ - T₂ + T₃ - T₄)      [момент тангажу: різниця тяг передніх і задніх двигунів]
M_z = k_q · (Ω₁² - Ω₂² + Ω₃² - Ω₄²)  [момент рискання: дисбаланс реактивних моментів гвинтів]
```

## 6. Аеродинамічний опір та спектральна модель поривів вітру

Рух апарата крізь повітряне середовище створює зустрічний швидкісний напір. Швидкість польоту відносно набігаючого повітряного потоку (Airspeed) розраховується з урахуванням вектора локального вітру:

```
v_air_n = v_n - v_wind_n
v_air_b = R_bn · v_air_n
```

Сила лобового аеродинамічного опору корпусу діє проти напрямку руху в системі Body:

```
F_drag_b = -0.5 · ρ · C_d · A_ref · ||v_air_b|| · v_air_b
```

Крім того, при кутовому обертанні виникають аеродинамічні демпфуючі моменти, які пропорційні кутовим швидкостям і стабілізують планер у повітрі:

```
M_aero_damp = [ -c_p · p,  -c_q · q,  -c_r · r ]ᵀ
```

Модель вітру в симуляторах високої точності поєднує постійний профіль середнього вітру за висотою (логарифмічний закон приземного шару) та динамічні пориви за спектральною моделлю турбулентності Драйдена. Пориви вітру формуються шляхом пропускання некорельованого білого гаусового шуму через формуючі аналогові фільтри першого та другого порядків із просторовими масштабами турбулентності `L_u, L_v, L_w`.

## 7. Чисельне інтегрування методом Рунге-Кутти 4-го порядку (RK4)

Пряме інтегрування системи диференціальних рівнянь методом Ейлера (`x_{k+1} = x_k + dt · f(x_k, u_k)`) має перший порядок точності `O(dt)` і швидко накопичує фазову похибку. При кроках інтегрування `dt > 2` мс метод Ейлера призводить до штучного розгойдування контурів кутового положення.

Тому симулятори фізики використовують класичний чотирикроковий метод Рунге-Кутти (RK4), який має четвертий порядок точності `O(dt⁴)` і забезпечує високу стійкість інтегрування.

Для загальної системи диференціальних рівнянь `dx/dt = f(t, x, u)` інтегрування на часовий інтервал `dt` виконується у чотири етапи:

```
k₁ = f( t,          x,                  u )
k₂ = f( t + 0.5·dt, x + 0.5·dt · k₁,    u )
k₃ = f( t + 0.5·dt, x + 0.5·dt · k₂,    u )
k₄ = f( t + dt,     x + dt · k₃,        u )

x(t + dt) = x(t) + (dt / 6) · ( k₁ + 2·k₂ + 2·k₃ + k₄ )
```

### Покроковий приклад розрахунку одного такту інтегрування

Розглянемо чисельний розрахунок динаміки розгону апарата за швидкістю:

```
Початкові умови на момент часу t₀ = 0.000 с:
  Крок інтегрування: dt = 0.004 с (частота 250 Гц)
  Маса апарата: m = 1.500 кг
  Початкова швидкість: v(t₀) = 12.000 м/с
  Тяга двигунів: F_thrust = 22.000 Н
  Коефіцієнт лобового опору: c_drag = 0.5 · ρ · C_d · A = 0.040 кг/м

Рівняння динаміки поступального руху:
  dv/dt = f(v) = (F_thrust - c_drag · v²) / m

1. Розрахунок коефіцієнта k₁ на початку інтервалу:
   a₁ = (22.000 - 0.040 · 12.000²) / 1.500
      = (22.000 - 5.760) / 1.500
      = 10.8267 м/с²
   k₁ = 10.8267

2. Пробний крок на половину інтервалу v₂ = v + 0.5 · dt · k₁:
   v₂ = 12.000 + 0.5 · 0.004 · 10.8267 = 12.0217 м/с
   a₂ = (22.000 - 0.040 · 12.0217²) / 1.500
      = (22.000 - 5.7809) / 1.500
      = 10.8127 м/с²
   k₂ = 10.8127

3. Другий пробний крок на половину інтервалу v₃ = v + 0.5 · dt · k₂:
   v₃ = 12.000 + 0.5 · 0.004 · 10.8127 = 12.0216 м/с
   a₃ = (22.000 - 0.040 · 12.0216²) / 1.500
      = (22.000 - 5.7808) / 1.500
      = 10.8128 м/с²
   k₃ = 10.8128

4. Пробний крок на повний інтервал v₄ = v + dt · k₃:
   v₄ = 12.000 + 0.004 · 10.8128 = 12.0433 м/с
   a₄ = (22.000 - 0.040 · 12.0433²) / 1.500
      = (22.000 - 5.8016) / 1.500
      = 10.7989 м/с²
   k₄ = 10.7989

5. Зважена інтеграція за формулою Сімпсона:
   v(t₀ + dt) = 12.000 + (0.004 / 6) · (10.8267 + 2·10.8127 + 2·10.8128 + 10.7989)
              = 12.000 + 0.0006667 · (64.8766)
              = 12.000 + 0.04325 = 12.04325 м/с
```

Після завершення кожного кроку інтегрування кватерніон орієнтації `q_nb` обов'язково підлягає процедурі примусової нормалізації для усунення чисельної похибки неортогональності:

```
q_norm = √(q₀² + q₁² + q₂² + q₃²)
q_nb = q_nb / q_norm
```

Отримана система рівнянь гарантує точне моделювання динаміки в [SITL-симуляторі](root:sys-dron/sitl-simulator), дозволяючи автопілоту стабілізувати апарат за будь-яких просторових маневрів.
