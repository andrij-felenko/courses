# 🧮 Виведення матриці DOP та розклад коваріацій у системі ENU

Цей математичний аналіз встановлює точний аналітичний зв'язок між просторовою конфігурацією супутників на небосхилі та роздуванням дисперсії навігаційних помилок у локальній системі координат дрона Схід-Північ-Вгору (англ. *East-North-Up*, ENU). Без виведення матриці геометричного фактора неможливо строго довести, чому вертикальна похибка супутникового позиціонування фундаментально перевищує горизонтальну та як саме обчислюються метрики GDOP, PDOP, HDOP, VDOP і TDOP у навігаційному процесорі.

---

### 1. Лінеаризована модель вимірів і матриця геометрії G

Нехай у системі координат ECEF (WGS-84) положення антени приймача задано вектором `x = [X, Y, Z]ᵀ`, а координати `i`-го супутника (`i = 1, …, N`, де `N ≥ 4`) — вектором `x_i = [X_i, Y_i, Z_i]ᵀ`.

Геометрична відстань `r_i` та виміряна псевдодальність `ρ_i` описуються нелінійним рівнянням:

```
ρ_i = √[(X_i − X)² + (Y_i − Y)² + (Z_i − Z)²] + c · δt_rcv + ε_i
```

Розкладаючи функцію відстані в ряд Тейлора в околиці точки початкового наближення `x₀ = [X₀, Y₀, Z₀]ᵀ` з часовим зсувом `c·δt₀`:

```
r_i(x) ≈ r_i(x₀) + (∂r_i / ∂X)·ΔX + (∂r_i / ∂Y)·ΔY + (∂r_i / ∂Z)·ΔZ
```

Обчислюємо частинні похідні (напрямні косинуси одиничного вектора візування `u_i` від приймача до `i`-го супутника):

```
∂r_i / ∂X = −(X_i − X₀) / r_i(x₀) = −u_xi
∂r_i / ∂Y = −(Y_i − Y₀) / r_i(x₀) = −u_yi
∂r_i / ∂Z = −(Z_i − Z₀) / r_i(x₀) = −u_zi
```

Позначаючи вектор приросту навігаційного стану `Δx = [ΔX, ΔY, ΔZ, c·Δδt]ᵀ` та вектор нев'язок псевдодальностей `Δρ = [Δρ₁, Δρ₂, …, Δρ_N]ᵀ`, де `Δρ_i = ρ_i − r_i(x₀) − c·δt₀`, отримуємо лінійну матричну систему:

```
Δρ = G · Δx + ε
```

де `G` — матриця геометрії (розмірності `N × 4`):

```
G = [ −u_x1   −u_y1   −u_z1   1 ]
    [ −u_x2   −u_y2   −u_z2   1 ]
    [   ⋮       ⋮       ⋮     ⋮ ]
    [ −u_xN   −u_yN   −u_zN   1 ]
```

### 2. Оцінка МНК та коваріаційна матриця помилок стану

Припускаючи, що похибки вимірювань псевдодальностей `ε_i` є незалежними однаково розподіленими випадковими величинами з нульовим математичним сподіванням `E[ε] = 0` та дисперсією `σ₀²` (User Equivalent Range Error, `Cov(ε) = σ₀² · I_N`), оцінка вектора приросту стану за методом найменших квадратів має вигляд:

```
Δx̂ = (Gᵀ · G)⁻¹ · Gᵀ · Δρ
```

Коваріаційна матриця вектора помилок оцінки `Cov(Δx̂) = E[(Δx̂ − Δx)(Δx̂ − Δx)ᵀ]` виводиться безпосередньо через властивості матричного множення:

```
Cov(Δx̂)
= E[( (Gᵀ·G)⁻¹·Gᵀ·ε ) · ( (Gᵀ·G)⁻¹·Gᵀ·ε )ᵀ]        [підстановка помилки оцінки]
= (Gᵀ·G)⁻¹·Gᵀ · E[ε · εᵀ] · G·((Gᵀ·G)⁻¹)ᵀ           [винесення детермінованих матриць]
= (Gᵀ·G)⁻¹·Gᵀ · (σ₀² · I_N) · G·(Gᵀ·G)⁻¹            [підстановка Cov(ε) = σ₀²·I]
= σ₀² · (Gᵀ·G)⁻¹ · (Gᵀ · G) · (Gᵀ·G)⁻¹              [асоціативність та симетрія GᵀG]
= σ₀² · (Gᵀ · G)⁻¹                                  [спрощення: A · A⁻¹ = I]
```

Матриця `H = (Gᵀ · G)⁻¹` розмірності `4 × 4` називається **матрицею коваріації геометрії**. Вона повністю визначається взаємним розташуванням супутників відносно приймача і не залежить від фізичної якості радіосигналу `σ₀`.

### 3. Перехід від геоцентричної системи ECEF до топоцентричної ENU

Помилки в декартових осях ECEF `(X, Y, Z)` не мають прямої фізичної інтерпретації для керування безпілотником. Для аналізу горизонтального дрейфу та висоти виконується поворот коваріаційної матриці в локальну топоцентричну систему координат ENU (East — Схід, North — Північ, Up — Вгору / Зеніт).

Для точки з геодезичною широтою `φ` та довготою `λ` ортогональна матриця повороту `R` розмірності `3 × 3` визначається одиничними базисними векторами:

```
R = [ −sin(λ)              cos(λ)              0       ]   ← East (Схід)
    [ −sin(φ)·cos(λ)      −sin(φ)·sin(λ)      cos(φ)   ]   ← North (Північ)
    [  cos(φ)·cos(λ)       cos(φ)·sin(λ)      sin(φ)   ]   ← Up (Вгору)
```

Розширимо матрицю перетворення до розмірності `4 × 4` для збереження часового компонента:

```
T = [    R      0₁ₓ₃ᵀ ]
    [  0₁ₓ₃       1   ]
```

Коваріаційна матриця навігаційних помилок у системі ENU обчислюється як:

```
Cov_ENU(Δx̂) = T · Cov_ECEF(Δx̂) · Tᵀ = σ₀² · Q_ENU
```

де безрозмірна матриця геометричних вагових коефіцієнтів `Q_ENU` дорівнює:

```
Q_ENU = T · (Gᵀ · G)⁻¹ · Tᵀ = [ q_EE   q_EN   q_EU   q_Et ]
                              [ q_NE   q_NN   q_NU   q_Nt ]
                              [ q_UE   q_UN   q_UU   q_Ut ]
                              [ q_tE   q_tN   q_tU   q_tt ]
```

Оскільки перетворення `T` є ортогональним обертанням просторового блоку, слід матриці (англ. *trace*) є інваріантом повороту:

```
Tr(Q_ENU) = Tr((Gᵀ · G)⁻¹) = q_EE + q_NN + q_UU + q_tt
```

### 4. Визначення та формули метрик DOP

Метрики зниження точності (DOP) визначаються як квадратні корені з відповідних діагональних елементів матриці `Q_ENU`:

1. **GDOP (Geometric Dilution of Precision — геометричний фактор):**
   Характеризує сукупну похибку 3D-позиції та часу годинника приймача:
   ```
   GDOP = √Tr(Q_ENU) = √(q_EE + q_NN + q_UU + q_tt) = √(PDOP² + TDOP²)
   ```

2. **PDOP (Position Dilution of Precision — просторовий фактор 3D):**
   Характеризує тривимірну просторову похибку положення:
   ```
   PDOP = √(q_EE + q_NN + q_UU)
   ```
   Зв'язок із просторовою дисперсією:
   ```
   σ_3D = σ₀ · PDOP = √(σ_E² + σ_N² + σ_U²)
   ```

3. **HDOP (Horizontal Dilution of Precision — горизонтальний фактор):**
   Характеризує точність позиціонування у горизонтальній площині (Схід-Північ):
   ```
   HDOP = √(q_EE + q_NN)
   ```
   Зв'язок із горизонтальною круговою похибкою:
   ```
   σ_horiz = σ₀ · HDOP = √(σ_E² + σ_N²)
   ```

4. **VDOP (Vertical Dilution of Precision — вертикальний фактор):**
   Характеризує похибку визначення висоти:
   ```
   VDOP = √q_UU
   ```
   Зв'язок із вертикальною дисперсією:
   ```
   σ_vert = σ₀ · VDOP = σ_U
   ```

5. **TDOP (Time Dilution of Precision — часовий фактор):**
   Характеризує похибку оцінки часового зсуву годинника приймача:
   ```
   TDOP = √q_tt
   ```
   Зв'язок із похибкою часу:
   ```
   σ_time = (σ₀ / c) · TDOP
   ```

Фундаментальне співвідношення між усіма факторами записується через піфагорове додавання:

```
PDOP² = HDOP² + VDOP²
GDOP² = PDOP² + TDOP² = HDOP² + VDOP² + TDOP²
```

### 5. Теоретичне доведення нерівності VDOP > HDOP

У супутниковій навігації спостерігається незмінна закономірність: вертикальна точність визначення висоти `VDOP` завжди у 1.5–2.5 раза гірша за горизонтальну точність `HDOP`.

**Доведення через геометрію півсфери:**

Розглянемо одиничний вектор напрямку на `i`-й супутник у топоцентричній системі координат ENU:

```
u_i_ENU = [ cos(el_i)·sin(az_i), cos(el_i)·cos(az_i), sin(el_i) ]ᵀ
```

де `el_i ∈ [0°, 90°]` — кут місця (висота над горизонтом), `az_i ∈ [0°, 360°]` — азимут.

Для горизонтальних компонентів Схід і Північ супутники розподілені рівномірно по всьому колу азимутів `az_i ∈ [0, 2π]`. Отже:

```
∑ sin(az_i) ≈ 0,    ∑ cos(az_i) ≈ 0
```

Оскільки супутники знаходяться з протилежних сторін від антени (наприклад, схід і захід, північ і південь), вектори візування компенсують один одного, створюючи симетричну базу вимірювань у площині горизонту з кутовим розкриттям до `180°`.

Для вертикального компонента Вгору (Up) існує фізичне обмеження: Земля є непрозорим тілом для радіохвиль гігагерцового діапазону. Приймач може спостерігати лише супутники з кутом місця `el_i > 0°` (на практиці застосовується маска кута місця `el_i ≥ 10°`…`15°`). Жоден супутник не може знаходитися «знизу», тобто під горизонтом `el_i < 0°`.

Через це всі вертикальні проєкції векторів візування мають один і той самий знак:

```
u_z_i = sin(el_i) > 0    для всіх i = 1, …, N
```

Вектори спостереження вздовж осі Up утворюють однобічний конус над антеною. Односторонній базис призводить до того, що матриця нормальних рівнянь `Gᵀ·G` має суттєво менше власне значення вздовж вертикальної осі порівняно з горизонтальними осями.

Оскільки елементи коваріаційної матриці `(Gᵀ·G)⁻¹` обернено пропорційні власним значенням `Gᵀ·G`:

```
λ_Up(Gᵀ·G) < λ_Horiz(Gᵀ·G)  ⇒  q_UU > (q_EE + q_NN) / 2
```

Звідси випливає фундаментальна нерівність:

```
VDOP = √q_UU > HDOP / √2
```

На практиці для рівномірно розподіленого сузір'я відношення `VDOP / HDOP` становить приблизно `√2`…`2.0`, що робить вертикальну координату GNSS найбільш чутливою до шумів і вимагає обов'язкового комплексування з барометричним висотоміром у польотному контролері.
