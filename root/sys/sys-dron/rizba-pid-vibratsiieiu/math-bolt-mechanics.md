# 🧮 Механіка напружень і розрахунок моменту затягування: формула Келлермана-Кляйна

Коли динамометричний ключ обертає головку болта, лише 10–15% прикладеного моменту йде на корисне розтягнення його стрижня, тоді як решта 85–90% витрачається на подолання тертя у витках різьби та під торцем головки. Математичний розклад цих зусиль визначає, який саме осьовий натяг виникне в з'єднанні, чи витримають поверхні карбону й витки алюмінію задане навантаження, і яке критичне зсувне зусилля призведе до мікропроковзування в стику.

## Розклад крутного моменту: формула VDI 2230

Повний момент затягування `T_total`, що прикладається інструментом, складається з трьох незалежних фізичних компонентів:
1. `T_pitch` — корисний момент підйому по гвинтовій лінії (розтягнення стрижня болта);
2. `T_thread` — момент тертя на робочих похилих гранях витків різьби;
3. `T_bearing` — момент тертя на торцевій опорній поверхні головки болта або гайки.

```
T_total = T_pitch + T_thread + T_bearing
```

### Корисний момент підйому різьби

Розглядаючи один крок метричної різьби `p` як розгортку похилої площини на циліндрі середнього діаметра `d_2`, робота осьової сили `F_p` на переміщенні `p` дорівнює роботі окружного зусилля на довжині кола `π · d_2`:

```
W_axial = F_p · p                         [робота осьового розтягу на один оберт]
W_rot   = F_tangential · (π · d_2)        [робота тангенціального зусилля на оберт]
F_tangential = F_p · p / (π · d_2)        [з умови рівності робіт без тертя]
T_pitch = F_tangential · (d_2 / 2)        [момент як добуток сили на плече]
        = F_p · p / (2 · π)               [фінальний корисний момент розтягу]
```

### Момент тертя у витках метричної різьби

Метрична різьба ISO має трикутний профіль із кутом при вершині `α = 60°` (напівкут `α/2 = 30°`). Нормальна сила реакції на грані витка `N` більша за осьову силу `F_p` через клиновий ефект бокового скосу грані:

```
N = F_p / cos(α/2)                        [нормальна сила реакції на скошеній грані]
F_f_thread = μ_th · N                     [сила тертя ковзання на грані витка]
           = μ_th · F_p / cos(α/2)        [тертя з урахуванням кута профілю різьби]
T_thread   = F_f_thread · (d_2 / 2)       [плече дії тертя — середній радіус різьби]
           = F_p · μ_th · d_2 / (2 · cos(α/2))  [момент тертя у витках різьби]
```

Для стандартного профілю `cos(30°) = √3 / 2 ≈ 0.8660`, тому ефективний коефіцієнт тертя в різьбі збільшується у `1 / 0.866 ≈ 1.155` раза.

### Момент торцевого тертя під головкою

Опорний торець головки болта чи шайби контактує з поверхнею деталі по кільцевій площі з внутрішнім діаметром отвору `d_h` та зовнішнім діаметром опорного буртика `d_w`. За умови рівномірного контактного тиску ефективний радіус тертя `r_b` становить:

```
r_b = (d_w + d_h) / 4                     [середній радіус кільцевої опорної зони]
T_bearing = F_p · μ_b · r_b               [момент тертя на торці]
          = F_p · μ_b · (d_w + d_h) / 4   [розгорнутий вираз торцевого тертя]
```

### Зведена формула Келлермана-Кляйна

Об'єднуючи всі три доданки та виносячи цільову силу попереднього затягування `F_p` за дужки:

```
T = F_p · [ (p / (2 · π)) + (μ_th · d_2 / (2 · cos(α/2))) + (μ_b · (d_w + d_h) / 4) ]
```

Часто в інженерній практиці використовують спрощений «коефіцієнт затягування» `K` (nut factor), де `T = K · F_p · d`. Для сухої сталі `K ≈ 0.20`, для сталі з анаеробним фіксатором різьби `K ≈ 0.15...0.16`, а для змащеної різьби `K ≈ 0.10...0.12`.

## Пружна податливість системи та діаграма стику

З'єднання складається з двох зустрічно деформованих пружин: стрижня болта, який розтягується, та пакету деталей, який стискається. Їхні коефіцієнти жорсткості визначаються геометрією та модулями пружності:

```
k_bolt  = (E_bolt · A_nominal) / L_grip   [жорсткість стрижня болта на розтяг]
k_parts = (E_parts · A_eff_cone) / L_grip [жорсткість пакету деталей на стиск]
```

Ефективна площа стиснутого матеріалу `A_eff_cone` розраховується за моделлю конуса тиску під кутом розсіювання напружень `φ ≈ 30°`.

Коли до з'єднання прикладається зовнішнє осьове динамічне навантаження `F_ext`, воно перерозподіляється між болтом та деталями через **коефіцієнт навантаження стику** `Φ`:

```
Φ = k_bolt / (k_bolt + k_parts)           [частка зовнішнього зусилля, що йде на болт]
ΔF_bolt  = Φ · F_ext                      [додаткове розтягнення болта]
ΔF_parts = (1 - Φ) · F_ext                [розвантаження стику деталей]
```

Оскільки жорсткість пакету алюмінієвих та карбонових деталей зазвичай у 3–5 разів перевищує жорсткість тонкого довгого стрижня болта (`k_parts >> k_bolt`), коефіцієнт `Φ` становить лише `0.15...0.25`. Це означає, що 75–85% зовнішнього пульсуючого навантаження компенсується зміною тиску в стику, захищаючи болт від високих амплітуд знакозмінних напружень до моменту розкриття стику.

## Розрахунок площі напружень та граничної сили затягування

Номінальний діаметр стрижня `d` не відображає реальної міцності через проточку канавок різьби. Розрахункова площа розтягу стрижня `A_s` (tensile stress area) за стандартом ISO 898-1 обчислюється через середнє між внутрішнім `d_3` та середнім `d_2` діаметрами:

```
d_3 = d_1 - H/6 = d - 1.22687 · p         [внутрішній діаметр западини різьби]
d_2 = d - 0.64952 · p                     [середній діаметр різьби]
d_s = (d_2 + d_3) / 2 = d - 0.9382 · p    [еквівалентний діаметр розтягу]
A_s = (π / 4) · d_s²                      [розрахункова площа напруженого перерізу]
    = (π / 4) · (d - 0.9382 · p)²         [робоча формула площі перерізу]
```

Гранична пружна сила болта визначається границею текучості матеріалу `R_p0.2`. Для запобігання пластичній деформації при затягуванні беруть коефіцієнт використання границі текучості `ν = 0.85...0.90`:

```
F_preload_max = ν · A_s · R_p0.2          [максимальний рекомендований натяг]
```

Для гвинта М3 класу міцності 10.9 (`R_p0.2 = 940 МПа`, крок `p = 0.5 мм`):

```
d_s = 3.0 - 0.9382 · 0.5 = 2.5309 мм      [еквівалентний діаметр М3]
A_s = (π / 4) · (2.5309)² = 5.031 мм²     [площа розтягу для М3]
F_preload_max = 0.85 · 5.031 · 940 = 4019 Н  [максимальний натяг ≈ 4.02 кН]
```

## Контактний тиск під головкою та критерій карбону

При затягуванні гвинта зусилля `F_p` передається на матеріал через опорну кільцеву площу `A_bearing`. Контактний тиск `σ_b` не повинен перевищувати допустиму міцність матеріалу на стиск:

```
A_bearing = (π / 4) · (d_w² - d_h²)       [площа контакту під фланцем або шайбою]
σ_b = F_p / A_bearing                     [середній контактний тиск]
```

### Порівняння вузької головки DIN 912 та фланця ISO 7380-2 для болта M3

1. **Вузька циліндрична головка DIN 912** (`d_w = 5.5 мм`, отвір `d_h = 3.4 мм`):
```
A_bearing_narrow = (π / 4) · (5.5² - 3.4²) = 14.68 мм²
σ_b_narrow = 4019 Н / 14.68 мм² = 273.8 МПа
```
*Висновок:* Тиск `273.8 МПа` значно перевищує границю міцності епоксидної матриці карбону поперек шарів (`σ_comp_matrix ≈ 120–150 МПа`), що призводить до негайного роздавлювання смоли та релаксації натягу.

2. **Гвинт із фланцем ISO 7380-2 або широка шайба** (`d_w = 9.0 мм`, отвір `d_h = 3.4 мм`):
```
A_bearing_wide = (π / 4) · (9.0² - 3.4²) = 54.54 мм²
σ_b_wide = 4019 Н / 54.54 мм² = 73.7 МПа
```
*Висновок:* Тиск `73.7 МПа` знаходиться в безпечній зоні (`< 120 МПа`), деформування є суто пружним, а повзучість полімеру не розвивається.

## Розрахунок довжини зачеплення різьби в алюмінії проти зрізу витків

При закручуванні сталевого болта (клас 10.9) у м'який алюмінієвий сплав (наприклад, 6061-T6 із границею зрізу `τ_al ≈ 150 МПа`) найслабшою ланкою стають внутрішні алюмінієві витки.

Площа зрізу циліндра внутрішньої різьби по вершинах витків болта становить:

```
A_shear_internal = π · d · (0.75 · L_eff)   [коефіцієнт перекриття профілю 0.75]
```

Умова рівноміцності різьби та стрижня болта:

```
F_strip = A_shear_internal · τ_al ≥ F_break_bolt
π · d · 0.75 · L_eff · τ_al ≥ A_s · R_m_bolt
L_eff ≥ (A_s · R_m_bolt) / (π · d · 0.75 · τ_al)
```

Для болта М3 класу 10.9 (`A_s = 5.031 мм²`, `R_m = 1040 МПа`) у різьбу зі сплаву 6061-T6 (`τ_al = 150 МПа`):

```
L_eff_min = (5.031 · 1040) / (π · 3.0 · 0.75 · 150)
          = 5232.2 / 1060.3
          = 4.93 мм                         [довжина зачеплення ≈ 1.65 · d]
```

З урахуванням коефіцієнта запасу 1.25 на нерівномірність навантаження по витках мінімальна безпечна довжина різьби в сплаві 6061-T6 становить `L_safe ≥ 2.0 · d` (для М3 — не менше 6.0 мм). Якщо глибина корпусу менша за 6 мм, повний момент затягування неминуче призведе до зриву різьби, що вимагає застосування сталевих різьбових вставок Helicoil.

## Граничне зсувне навантаження стику та поріг ковзання Юнкера

Згідно з теорією Юнкера, самовідкручування починається, коли поперечна динамічна сила зрізу `F_transverse` перевищує силу тертя спокою між скріплюваними пластинами:

```
F_transverse_crit = μ_joint · F_preload   [поріг початку поперечного мікрозсуву]
```

Для моторного вузла з чотирма гвинтами М3 класу 10.9, затягнутими з натягом `F_p = 3.5 кН` кожен (сумарний натяг `14.0 кН`), при коефіцієнті тертя сухого стику карбон-алюміній `μ_joint ≈ 0.25`:

```
F_transverse_max = 0.25 · 14000 = 3500 Н  [критична зсувна сила вузла ≈ 3.5 кН]
```

Якщо динамічні сили від вібрацій та ударних маневрів не перевищують `3.5 кН`, відносний зсув у стику відсутній, і нарізне з'єднання зберігає 100% натягу навіть без додаткових фіксаторів. Проте при зниженні натягу внаслідок релаксації чи перегріву критичний поріг падає, відкриваючи шлях до циклічного проковзування та самовідкручування.
