# 🧮 Математика 7-фазного профілю швидкості з обмеженим ривком

У класичній теорії автоматичного керування зміна швидкості матеріальної точки найчастіше моделюється трапецоїдним профілем: миттєве ввімкнення постійного прискорення `+a_max`, рівномірний рух зі сталою швидкістю `v_max` та миттєве ввімкнення гальмівного прискорення `−a_max`.

У моменти перемикання фаз похідна прискорення за часом — ривок (англ. *jerk*) — прямує до нескінченності. Для фізичного безпілотника нескінченний ривок є неприпустимим. Миттєва зміна прискорення `Δa` вимагає стрибкоподібного збільшення сили тяги `F = m·a`. Електродвигуни безколекторного типу (BLDC) та регулятори швидкості (ESC) мають власну індуктивність обмоток та обмежену швидкість наростання струму `dI / dt`. Спроба стрибком наростити тягу викликає просідання напруги на силовій шині акумулятора, потужні електромагнітні завади (EMI) на навігаційному компасі, ударні механічні навантаження на лопаті пропелерів та зрив стабілізації оптичного гіропідвісу камери.

7-фазний S-кривий профіль швидкості (Jerk-Limited S-Curve) обмежує абсолютну величину ривка фіксованим значенням `j_max`. Завдяки цьому прискорення стає неперервною кусочно-лінійною функцією, швидкість — гладкою кривою класу `C¹`, а просторове положення — кривою класу `C²`.

Нижче наведено строге математичне виведення рівнянь руху для всіх семи фаз одновимірного профілю, методику розрахунку тривалостей фаз, обробку асиметричних лімітів розгону й гальмування, вироджених коротких сегментів та покроковий числовий приклад розрахунку.

## Фізичні величини та визначення фаз руху

Позначимо положення точки вздовж траєкторії через координату `s(t)`, лінійну швидкість через `v(t) = ṡ(t)`, прискорення через `a(t) = v̇(t) = s̈(t)` та ривок через `j(t) = ȧ(t) = s⃛(t)`.

Повний цикл руху від початкової швидкості `v₀` до кінцевої швидкості `v_target` через максимальну крейсерську швидкість `v_max` складається з семи послідовних часових фаз:

| Фаза | Ривок `j(t)` | Прискорення `a(t)` | Характер зміни швидкості `v(t)` | Фізичний опис етапу |
|---|---|---|---|---|
| **1** | `+j_max` | зростає від `0` до `+a_max` | увігнута парабола | Наростання тяги (вхід у розгін) |
| **2** | `0` | стале `+a_max` | пряма лінія | Рух із постійним максимальним прискоренням |
| **3** | `−j_max` | спадає від `+a_max` до `0` | опукла парабола | Зменшення прискорення (вихід на `v_max`) |
| **4** | `0` | стале `0` | стала горизонталь | Рух із постійною швидкістю `v_max` |
| **5** | `−j_max` | спадає від `0` до `−a_max` | опукла парабола | Наростання гальмування (вхід у сповільнення) |
| **6** | `0` | стале `−a_max` | пряма лінія | Рух із постійним максимальним сповільненням |
| **7** | `+j_max` | зростає від `−a_max` до `0` | увігнута парабола | Зменшення гальмування (вихід на `v_target`) |

## Покрокове інтегрування рівнянь руху для кожної фази

Позначимо тривалості окремих фаз через `T₁, T₂, T₃, T₄, T₅, T₆, T₇`. З властивостей симетрії наростання та спадання прискорення отримуємо:

```
T₁ = T₃ = T_j_acc                                 [тривалість фаз зміни прискорення під час розгону]
T₅ = T₇ = T_j_dec                                 [тривалість фаз зміни прискорення під час гальмування]
T₂ = T_a                                          [тривалість фази постійного максимального розгону]
T₄ = T_v                                          [тривалість фази крейсерського руху зі швидкістю v_max]
T₆ = T_d                                          [тривалість фази постійного максимального гальмування]
```

### Фаза 1: Лінійне наростання прискорення `[0 ≤ t < T₁]`

Початкові умови на початку руху: `s(0) = 0`, `v(0) = v₀`, `a(0) = 0`. Ривок є строго додатним і сталим: `j(t) = +j_max`.

Послідовне інтегрування диференціальних рівнянь руху дає:

```
a(t) = j_max · t                                  [інтегрування ривка за часом]
v(t) = v₀ + 0.5 · j_max · t²                      [інтегрування прискорення]
s(t) = v₀ · t + (1/6) · j_max · t³                [інтегрування швидкості]
```

Стан системи наприкінці першої фази в момент часу `t = T₁ = T_j_acc`:

```
a₁ = j_max · T_j_acc                              [досягнуте значення прискорення]
v₁ = v₀ + 0.5 · j_max · T_j_acc²                  [набрана швидкість наприкінці фази 1]
s₁ = v₀ · T_j_acc + (1/6) · j_max · T_j_acc³      [пройдена дистанція у фазі 1]
```

### Фаза 2: Рух із постійним прискоренням `[0 ≤ τ < T₂]`, де `τ = t − T₁`

Початковий стан: `s = s₁`, `v = v₁`, `a = a_max`. Ривок дорівнює нулю: `j(τ) = 0`.

```
a(τ) = a_max                                      [постійне максимальне прискорення]
v(τ) = v₁ + a_max · τ                             [лінійне зростання швидкості]
s(τ) = s₁ + v₁ · τ + 0.5 · a_max · τ²             [квадратичне наростання пройденого шляху]
```

Стан наприкінці другої фази при `τ = T₂ = T_a`:

```
a₂ = a_max
v₂ = v₁ + a_max · T_a
s₂ = s₁ + v₁ · T_a + 0.5 · a_max · T_a²
```

### Фаза 3: Лінійне спадання прискорення до нуля `[0 ≤ τ < T₃]`, де `τ = t − (T₁ + T₂)`

Початковий стан: `s = s₂`, `v = v₂`, `a = a_max`. Ривок від'ємний: `j(τ) = −j_max`.

```
a(τ) = a_max − j_max · τ                          [прискорення лінійно зменшується до нуля]
v(τ) = v₂ + a_max · τ − 0.5 · j_max · τ²          [швидкість плавно наближається до v_max]
s(τ) = s₂ + v₂ · τ + 0.5 · a_max · τ² − (1/6) · j_max · τ³
```

Наприкінці фази 3 при `τ = T₃ = T_j_acc` система виходить на крейсерську швидкість `v_max` з нульовим прискоренням:

```
a₃ = 0
v₃ = v_max = v₂ + a_max · T_j_acc − 0.5 · j_max · T_j_acc²
s₃ = s₂ + v₂ · T_j_acc + 0.5 · a_max · T_j_acc² − (1/6) · j_max · T_j_acc³
```

Повний приріст швидкості за період розгону (фази 1, 2, 3) становить:

```
Δv_acc = v_max − v₀
       = a_max · T_j_acc + a_max · T_a            [сумарний набір швидкості]
```

Повна довжина ділянки розгону дорівнює:

```
S_acc = s₃ = 0.5 · (v₀ + v_max) · (2·T_j_acc + T_a) [площа під графіком швидкості на розгоні]
```

### Фаза 4: Крейсерський політ зі сталою швидкістю `[0 ≤ τ < T₄]`, де `τ = t − (T₁ + T₂ + T₃)`

Під час крейсерської фази прискорення та ривок дорівнюють нулю, а швидкість залишається строго постійною:

```
a(τ) = 0
v(τ) = v_max
s(τ) = s₃ + v_max · τ
```

Тривалість цієї фази визначається залишковою довжиною прямолінійного сегмента після віднімання шляхів розгону й гальмування:

```
S_cruise = L − S_acc − S_dec
T_v = S_cruise / v_max                            [час руху з постійною швидкістю]
```

### Фази 5, 6, 7: Гальмування до кінцевої швидкості `v_target`

Фази сповільнення розраховуються за аналогічними диференціальними рівняннями з від'ємним знаком прискорення та зміною швидкості `Δv_dec = v_max − v_target`.

Загальна дистанція повного гальмування `S_dec` визначається формулою:

```
S_dec = 0.5 · (v_max + v_target) · (2·T_j_dec + T_d) [дистанція повного сповільнення]
```

## Розрахунок тривалостей фаз і критерій досяжності максимального прискорення

Для заданих фізичних лімітів приводу `v_max`, `a_max`, `j_max` та перепаду швидкості `Δv = v_max − v₀` необхідно аналітично визначити, чи встигає прискорення взагалі вийти на своє пікове значення `a_max`.

Мінімальний перепад швидкості, який необхідний для повного наростання і спадання прискорення без фази постійного розгону (`T_a = 0`):

```
Δv_threshold = a_max² / j_max                     [пороговий перепад швидкості]
```

Залежно від співвідношення між фактичним перепадом швидкості `Δv` та пороговим значенням `Δv_threshold` виникає два характерні режими роботи профілювальника:

### Режим 1: Повний S-профіль `Δv ≥ Δv_threshold`

Прискорення гарантовано досягає встановленого ліміту `a_max`, а фаза 2 постійного прискорення має додатну тривалість (`T_a > 0`):

```
T_j_acc = a_max / j_max                           [час наростання та спадання прискорення]
T_a     = (Δv − Δv_threshold) / a_max             [тривалість руху зі сталою тягою a_max]
```

### Режим 2: Скорочений S-профіль `Δv < Δv_threshold` (трикутне прискорення)

Перепад швидкості є занадто малим, тому прискорення не встигає досягти максимального значення `a_max` і відразу після наростання починає спадати (`T_a = 0`).

У цьому разі пікове прискорення `a_peak < a_max` та скоригована тривалість фаз обчислюються за формулами:

```
a_peak  = √(Δv · j_max)                           [максимальне фактично досягнуте прискорення]
T_j_acc = √(Δv / j_max)                           [скорочений час наростання прискорення]
T_a     = 0                                       [фаза постійного прискорення вироджується]
```

## Асиметрія розгону та гальмування у безпілотниках

У реальних польотних контролерах параметри розгону та гальмування часто налаштовуються асиметрично:
- При розгоні дрон нахиляється вперед, збільшуючи газ для компенсації втрати вертикальної тяги: максимальне прискорення обмежене запасом тяги гвинтів `a_accel`.
- При гальмуванні дрон нахиляється назад: набігаючий потік повітря створює додатковий аеродинамічний опір корпусу, тому ефективне гальмівне прискорення `a_brake` може бути на 30–50% вищим за `a_accel`.

Аналітичний апарат 7-фазного профілю дозволяє незалежно розраховувати трійку `(a_accel, j_accel)` для фаз 1–3 та трійку `(a_brake, j_brake)` для фаз 5–7, повністю зберігаючи математичну гладкість сполучення у фазі 4.

## Обробка коротких сегментів: баланс шляху без виходу на `v_max`

Якщо загальна довжина відрізка `L` між двома точками менша за мінімальну суму шляхів розгону та гальмування `S_acc + S_dec`, максимальна крейсерська швидкість `v_max` не може бути досягнута фізично. Спроба розігнатися до `v_max` призведе до того, що дрон пролетить точку початку обов'язкового гальмування та вріжеться у поворот на небезпечній швидкості.

У такій ситуації планувальник розв'язує задачу знаходження нової пікової швидкості `v_peak < v_max`, для якої виконується умова рівності сумарного шляху довжині сегмента:

```
S_acc(v_peak) + S_dec(v_peak) = L                 [рівняння балансу шляху на короткому сегменті]
```

Для повного S-профілю рівняння балансу шляху має вигляд:

```
(v_peak² − v₀²) / (2 · a_accel) + (v_peak² − v_target²) / (2 · a_brake) +
+ v_peak · (T_j_acc + T_j_dec) = L
```

Розв'язуючи це квадратне рівняння відносно `v_peak`, отримуємо точне значення максимальної безпечної швидкості, яку дозволено набрати на цьому відрізку. Тривалість крейсерської фази 4 при цьому встановлюється рівною нулю (`T_v = 0`), а розгін відразу переходить у фазу гальмування через спільну вершину `v_peak`.

## Покроковий числовий приклад розрахунку

Розглянемо практичний розрахунок руху для середнього квадрокоптера:
- Початкова швидкість на точці: `v₀ = 0 м/с`;
- Бажана крейсерська швидкість місії: `v_max = 12 м/с`;
- Гранична швидкість проходження наступного кута: `v_target = 4 м/с`;
- Максимальне прискорення розгону: `a_accel = 3 м/с²`;
- Максимальне прискорення гальмування: `a_brake = 4 м/с²`;
- Максимальний допустимий ривок: `j_max = 15 м/с³`.

**Крок 1. Перевірка порогового перепаду швидкості на розгоні:**

```
Δv_threshold_acc = a_accel² / j_max
                 = 3² / 15
                 = 9 / 15
                 = 0.6 м/с                        [поріг досягнення a_accel]
```

Оскільки `Δv_acc = 12 − 0 = 12 м/с > 0.6 м/с`, прискорення гарантовано виходить на поличку `a_accel`.

**Крок 2. Розрахунок тривалостей фаз розгону:**

```
T_j_acc = a_accel / j_max = 3 / 15 = 0.20 с       [час наростання і спадання прискорення]
T_a     = (12.0 − 0.6) / 3.0 = 11.4 / 3.0 = 3.80 с [час фази постійного розгону]
T_acc_total = 2 · 0.20 + 3.80 = 4.20 с            [повний час розгону до 12 м/с]
```

**Крок 3. Розрахунок дистанції розгону:**

```
S_acc = 0.5 · (0 + 12) · 4.20
      = 6 · 4.20
      = 25.20 м                                   [шлях, необхідний для повного розгону]
```

**Крок 4. Розрахунок параметрів гальмування до `v_target = 4 м/с`:**

```
Δv_dec = 12 − 4 = 8 м/с
Δv_threshold_dec = a_brake² / j_max = 4² / 15 = 16 / 15 ≈ 1.07 м/с
T_j_dec = a_brake / j_max = 4 / 15 ≈ 0.267 с
T_d     = (8.0 − 1.067) / 4.0 = 6.933 / 4.0 ≈ 1.733 с
T_dec_total = 2 · 0.267 + 1.733 = 2.267 с         [повний час гальмування]
S_dec   = 0.5 · (12 + 4) · 2.267 = 8 · 2.267 = 18.14 м [шлях повного гальмування]
```

**Крок 5. Підсумок та аналіз результатів:**

Для виконання цього сегмента польоту без зниження крейсерської швидкості пряма дистанція між точками має бути не меншою за `S_acc + S_dec = 25.20 + 18.14 = 43.34 м`. Якщо фактична довжина відрізка становить, наприклад, 100 м, дрон проведе у фазі 4 крейсерського польоту дистанцію `100 − 43.34 = 56.66 м`, що займе додатково `56.66 / 12 = 4.72 с`.

Порівняно з простим трапецоїдним профілем різниця у сумарному часі польоту становить менше 0.3 секунди, але виграш у надійності безпілотника колосальний:
1. Силові транзистори регуляторів ESC не зазнають імпульсних перевантажень.
2. Немає різкого просідання напруги батареї на старті розгону.
3. IMU автопілота отримує чистий сигнал без високочастотних вібрацій, що забезпечує бездоганну точність оцінки орієнтації у фільтрі Калмана.
