# 🧮 Геометрія зрізання кутів і криві Безьє

Коли безпілотний апарат рухається за планом місії, координати точок маршруту утворюють ламану лінію з гострими просторовими зламами. Спроба фізичного апарата пролетіти крізь таку вершину без зміни напрямку наперед вимагає нескінченного бічного прискорення. Оскільки сила тяги двигунів і допустимий кут нахилу корпуса безпілотника завжди обмежені, прямолінійні відрізки сполучають плавними перехідними кривими.

Нижче наведено строге математичне виведення просторової геометрії кругового скруглення (fillet arc), кінематичного зв'язку між швидкістю, радіусом і бічним прискоренням, алгоритму динамічного масштабування радіуса на коротких сегментах, а також параметричної побудови кривих Безьє 5-го порядку для забезпечення неперервності кривини класу `C²`.

## Векторна геометрія кругового скруглення між двома відрізками

Розглянемо три послідовні тривимірні точки маршруту `W[i-1]`, `W[i]`, `W[i+1]`. Точка `W[i]` є вершиною просторового кута зламу, на якій сходяться вхідний та вихідний прямолінійні сегменти.

Для аналітичного опису руху введемо одиничні напрямні вектори вхідного та вихідного відрізків:

```
u_in  = (W[i] − W[i-1]) / ||W[i] − W[i-1]||      [одиничний напрямний вектор входу]
u_out = (W[i+1] − W[i]) / ||W[i+1] − W[i]||      [одиничний напрямний вектор виходу]
```

Кут зламу траєкторії `θ` (повний кут зміни напрямку руху в просторі) визначається через скалярний добуток цих одиничних векторів:

```
cos(θ) = u_in · u_out                             [скалярний добуток напрямків]
θ      = arccos(clamp(u_in · u_out, −1.0, 1.0))   [кут відхилення траєкторії від прямої]
```

Якщо `θ = 0`, відрізки є строго колінеарними й утворюють єдину пряму лінію — скруглення в цій точці вимикається. Якщо `θ = π` (180°), має місце повний розворот у зворотному напрямку, який вимагає окремої обробки.

Задача вписування кругового скруглення полягає у знаходженні дуги кола радіуса `R`, яка лежить у площині маневру та є дотичною до обох прямолінійних відрізків.

Площина повороту задається двома напрямними векторами `u_in` та `u_out`. Одиничний вектор бінормалі `b`, що є перпендикуляром до цієї площини, визначається через векторний добуток:

```
b = (u_in × u_out) / ||u_in × u_out||             [одиничний вектор бінормалі площини маневру]
```

З прямокутного трикутника, утвореного вершиною `W[i]`, точкою дотику `T₁` та центром кола `O`, знаходимо довжину перехідного відрізка відступу `d` (дистанцію випередження початку маневру):

```
d = R · tan(θ / 2)                                [відстань від вершини кута до точок початку скруглення]
```

Точки входу `T₁` на вхідному відрізку та виходу `T₂` на вихідному відрізку обчислюються векторним зміщенням від вершини:

```
T₁ = W[i] − d · u_in                              [точка дотику на вхідному прямому відрізку]
T₂ = W[i] + d · u_out                             [точка дотику на вихідному прямому відрізку]
```

Щоб знайти центр дуги `O`, визначимо одиничний вектор головної normal `n_in`, спрямований від точки `T₁` перпендикулярно до вхідного відрізка всередину площини повороту:

```
n_in = b × u_in                                   [головна нормаль у точці дотику T₁]
```

Центр кола `O` розташований на відстані радіуса `R` уздовж знайденої нормалі:

```
O = T₁ + R · n_in                                 [тривимірні координати центра дуги скруглення]
```

Важливим практичним показником є максимальне просторове відхилення траєкторії від початкової вершини ламаної (кліренс зрізу вершини, англ. *apex clearance*) `h`. Це найкоротша відстань від точки `W[i]` до найближчої точки вписаної дуги по бісектрисі кута:

```
h = R · (1 / cos(θ / 2) − 1)                      [максимальна глибина зрізання кута]
```

Довжина самої дуги скруглення `S_arc` обчислюється як добуток радіуса на кут зламу в радіанах:

```
S_arc = R · θ                                     [довжина криволінійної траєкторії повороту]
```

Оскільки замість двох прямолінійних ділянок відступу загальною довжиною `2·d` апарат проходить дугу `S_arc`, сумарне скорочення довжини маршруту становить:

```
ΔS = 2·d − S_arc
   = 2·R·tan(θ / 2) − R·θ                         [чиста геометрична економія шляху]
```

## Кінематичний розрахунок: зв'язок швидкості, радіуса та кута крену

Під час проходження кругової дуги радіуса `R` зі швидкістю `v` на апарат діє доцентрове (бічне) прискорення `a_lat`:

```
a_lat = v² / R                                    [доцентрове прискорення матеріальної точки]
```

У квадрокоптерах та інших мультироторних системах горизонтальне прискорення створюється виключно шляхом нахилу сумарного вектора тяги двигунів на кут крену `ϕ`. Вертикальна складова тяги врівноважує силу тяжіння `m·g`, а горизонтальна складова забезпечує необхідне доцентрове зусилля `m·a_lat`.

З балансу сил випливає прямий зв'язок кута крену `ϕ` з бічним прискоренням:

```
tan(ϕ) = a_lat / g                                [зв'язок кута нахилу корпуса з бічним прискоренням]
a_lat  = g · tan(ϕ)                               [бічне прискорення через кут нахилу дрона]
```

Для гарантування стабільності контурів орієнтації, запобігання втраті висоти та зриву потоку на пропелерах польотний контролер обмежує максимальний кут нахилу значенням `ϕ_max` (зазвичай у межах 30°–45°).

Знаючи граничний кут нахилу `ϕ_max` та прискорення вільного падіння `g = 9.81 м/с²`, визначаємо максимально допустиме бічне прискорення `a_lat_max`:

```
a_lat_max = g · tan(ϕ_max)                        [гранично допустиме бічне прискорення апарата]
```

Наприклад, якщо для місії встановлено обмеження крену `ϕ_max = 35°`:

```
a_lat_max = 9.81 · tan(35°·π / 180°)
          = 9.81 · 0.7002
          = 6.87 м/с²                             [числове значення ліміту прискорення]
```

Це обмеження накладає дві фундаментальні умови на планувальник польоту:

1. **Мінімальний радіус скруглення** для безперешкодного прольоту кута на крейсерській швидкості `v_cruise`:

```
R_min = v_cruise² / a_lat_max                     [радіус, що дозволяє не скидати швидкість]
```

2. **Гранична швидкість проходження повороту** для фіксованого геометрією радіуса `R`:

```
v_corner_max = √(a_lat_max · R)                   [максимально безпечна швидкість на куті]
```

## Алгоритм динамічного масштабування радіуса на коротких сегментах

У реальних місіях відстань між послідовними точками маршруту може бути невеликою. Якщо довжина відрізка `L = ||W[i] − W[i-1]||` є меншою за суму відступів двох сусідніх поворотів `d[i-1] + d[i]`, дуги скруглення почнуть геометрично перетинатися, що призведе до руйнування розрахунку траєкторії.

Щоб уникнути взаємного накладання, планувальник динамічно обмежує максимальний відступ `d` на кожній вершині половиною довжини найкоротшого з прилеглих відрізків.

Розрахунок масштабованого радіуса виконується за таким алгоритмом:

```
L_in      = ||W[i] − W[i-1]||                     [довжина вхідного сегмента]
L_out     = ||W[i+1] − W[i]||                     [довжина вихідного сегмента]
d_max     = 0.48 · min(L_in, L_out)               [гранично допустимий геометричний відступ]
d_nominal = R_desired · tan(θ / 2)                [номінальний відступ для бажаного радіуса]

α         = min(1.0, d_max / d_nominal)          [коефіцієнт стиснення геометрії]
R_eff     = α · R_desired                         [фактичний ефективний радіус дуги]
d_eff     = R_eff · tan(θ / 2)                    [фактичний відступ точок початку скруглення]
```

Після зменшення радіуса до `R_eff` алгоритм обов'язково перераховує граничну швидкість повороту:

```
v_corner = √(a_lat_max · R_eff)                   [скоригована безпечна швидкість проходження]
```

## Неперервність кривини C²: скруглення поліномами Безьє 5-го порядку

Хоча кругове скруглення забезпечує геометричну неперервність напрямку дотичної `C¹`, воно страждає на розрив кривини `κ(s)` у точках сполучення `T₁` і `T₂`. На прямому відрізку кривина дорівнює нулю (`κ = 0`), а в точці дотику миттєво стрибає до величини `κ = 1 / R`.

При русі зі швидкістю `v` стрибок кривини породжує миттєвий стрибок прискорення `Δa = v² / R`. За нульовий час зміни прискорення ривок прямує до нескінченності:

```
jerk = da / dt → ∞                                [нескінченний ривок на межі кругової дуги]
```

Для створення ідеально гладкого переходу класу `C²` (де функція кривини `κ(s)` є неперервною і плавно зростає від нуля та повертається до нуля) застосовують параметричні поліноми Безьє 5-го порядку (квінтичні криві).

Крива Безьє 5-го порядку задається вектором параметра `u ∈ [0, 1]` та шістьма контрольними точками `P₀, P₁, P₂, P₃, P₄, P₅`:

```
P(u) = ∑ [k = 0..5] (5! / (k! · (5−k)!)) · (1−u)⁵⁻ᵏ · uᵏ · P_k
```

Розкриваючи біноміальні коефіцієнти, отримуємо поліноміальний вираз:

```
P(u) = (1−u)⁵·P₀ + 5·(1−u)⁴·u·P₁ + 10·(1−u)³·u²·P₂ + 10·(1−u)²·u³·P₃ + 5·(1−u)·u⁴·P₄ + u⁵·P₅
```

Похідні кривої за параметром `u` на межах відрізка `u = 0` та `u = 1` визначаються виключно сусідніми контрольними точками:

```
P(0)   = P₀
P(1)   = P₅
P'(0)  = 5 · (P₁ − P₀)                            [перша похідна на початку кривої]
P'(1)  = 5 · (P₅ − P₄)                            [перша похідна в кінці кривої]
P''(0) = 20 · (P₂ − 2·P₁ + P₀)                    [друга похідна на початку кривої]
P''(1) = 20 · (P₅ − 2·P₄ + P₃)                    [друга похідна в кінці кривої]
```

Кривина тривимірної параметричної кривої в довільній точці `u` визначається класичною формулою диференціальної геометрії:

```
κ(u) = ||P'(u) × P''(u)|| / ||P'(u)||³            [кривина параметричної просторової лінії]
```

Для забезпечення нульової кривини на стиках із прямолінійними ділянками (`κ(0) = 0` та `κ(1) = 0`), вектори другої похідної на кінцях мають дорівнювати нулю: `P''(0) = 0` та `P''(1) = 0`.

Прирівнюючи вирази других похідних до нуля, знаходимо точне геометричне положення внутрішніх контрольних точок Безьє:

```
P₀ = T₁                                           [початкова точка на вхідному відрізку]
P₅ = T₂                                           [кінцева точка на вихідному відрізку]

P₁ = P₀ + (d / 5) · u_in                          [перша внутрішня точка вздовж вектора входу]
P₂ = 2·P₁ − P₀ = P₀ + (2·d / 5) · u_in            [забезпечує P''(0) = 0 і нульову кривину на вході]

P₄ = P₅ − (d / 5) · u_out                         [четверта внутрішня точка вздовж вектора виходу]
P₃ = 2·P₄ − P₅ = P₅ − (2·d / 5) · u_out           [забезпечує P''(1) = 0 і нульову кривину на виході]
```

За такого вибору контрольних точок перші три точки `P₀, P₁, P₂` лежать строго на одній лінії вздовж вхідного прямолінійного відрізка, а останні три `P₃, P₄, P₅` — на лінії вихідного відрізка.

Кривина починається з нуля, гладко наростає до максимуму у вершині повороту та плавно повертається до нуля на виході. Завдяки цьому прискорення змінюється без сходинок, а похідна прискорення — ривок `jerk` — залишається строго скінченною величиною, що усуває будь-які паразитні механічні резонанси в конструкції дрона.
