# Математика векторного керування підвісом: перетворення координат та SVPWM

Векторне керування (англ. *Field-Oriented Control*, FOC) безколекторним двигуном прямого приводу вимагає математичного перенесення фізичних трифазних струмів та напруг статора в обертову систему координат, жорстко прив'язану до магнітного потоку ротора. У звичайному скалярному керуванні (трапецеподібній або синусоїдальній ШІМ) магнітне поле статора крокує або обертається з фіксованою дискретністю, через що кут між вектором магнітного поля статора й магнітним полем постійних магнітів ротора коливається навколо оптимальних 90°. Це викликає пульсації крутного моменту, які в безредукторному приводі передаються безпосередньо на оптичну вісь камери.

Векторне перетворення координат усуває цю проблему: воно дозволяє керувати трифазним двигуном змінного струму так само просто й точно, як колекторним двигуном постійного струму, де струм збудження магнітного поля та струм створення механічного моменту розділені фізично в просторі.

## Перетворення Кларк: перехід від трифазної системи до нерухомої ортогональної

Статор трифазного BLDC-двигуна містить три обмотки `a`, `b`, `c`, просторові осі яких зсунуті одна відносно одної на 120° (2π/3 радіан). Миттєві фазні струми `i_a`, `i_b`, `i_c` утворюють сумарний вектор струму статора. Оскільки обмотки зазвичай з'єднані за схемою «зірка» без нульового проводу (ізольована нейтраль), за першим законом Кірхгофа сума фазних струмів завжди дорівнює нулю:

```
i_a + i_b + i_c = 0
```

Це означає, що система має лише два незалежні ступені вільності. Перетворення Кларк (назване на честь інженерки Едіт Кларк, англ. *Edith Clarke*, яка запропонувала цей матричний метод у 1938 році) трансформує трифазну систему координат `a-b-c` у двовісну стаціонарну декартову систему координат `α-β`, де вісь `α` спрямована вздовж осі фази `a`, а вісь `β` повернута ортогонально на +90°.

У варіанті перетворення зі збереженням амплітуди (англ. *amplitude-invariant Clarke transform*), проекції вектора на осі `α` та `β` визначаються як:

```
i_α = i_a
i_β = (i_a + 2·i_b) / √3 = (i_b − i_c) / √3
```

Повне матричне виведення прямого перетворення Кларк:

```
[ i_α ]       [  1      −1/2      −1/2   ]   [ i_a ]
[ i_β ] = 2/3 [  0     √3/2      −√3/2   ] · [ i_b ]
[ i_0 ]       [ 1/2     1/2       1/2    ]   [ i_c ]
```

Підставивши умову відсутності струму нульової послідовності `i_c = −i_a − i_b` у рядок для `i_β`:

```
i_β = (2/3) · ( (√3/2)·i_b − (√3/2)·i_c )      [другий рядок матриці Кларк]
    = (1/√3) · ( i_b − (−i_a − i_b) )           [підстановка i_c = −i_a − i_b]
    = (1/√3) · ( i_a + 2·i_b )                  [спрощення: зведення подібних]
```

Звідси отримуємо спрощену обчислювальну формулу для мікроконтролера, яка вимагає вимірювання лише двох фазних струмів `i_a` та `i_b`:

```
i_α = i_a                                    [проекція на вісь фази A]
i_β = 0.577350269 · (i_a + 2.0 · i_b)        [де 1/√3 ≈ 0.577350269]
```

## Перетворення Парка: перехід в обертову систему координат ротора

Система `α-β` нерухома відносно статора, тому для створення постійного за величиною моменту при обертанні ротора струми `i_α` та `i_β` повинні змінюватися синусоїдально в часі з електричною частотою обертання двигуна `ω_e`. На високих швидкостях або під час швидкого відпрацювання різких вібрацій класичний лінійний регулятор не встигає підтримувати нульову фазову похибку за синусоїдальним опорним сигналом через обмеження смуги пропускання.

Перетворення Парка (запропоноване Робертом Парком, англ. *Robert H. Park*, у 1929 році) переносить змінні з нерухомої системи `α-β` в обертову систему координат `d-q` (англ. *direct-quadrature*), яка жорстко обертається разом із магнітним вектором ротора з електричним кутом `θ_e`.

* Вісь `d` (пряма вісь, *direct*) спрямована вздовж вектора магнітного поля постійних магнітів ротора;
* Вісь `q` (поперечна або квадратурна вісь, *quadrature*) випереджає вісь `d` на 90° електричних за напрямком обертання.

Матриця прямого перетворення Парка:

```
[ i_d ]   [  cos(θ_e)   sin(θ_e) ]   [ i_α ]
[ i_q ] = [ −sin(θ_e)   cos(θ_e) ] · [ i_β ]
```

Покомпонентне обчислення проекцій:

```
i_d =  i_α · cos(θ_e) + i_β · sin(θ_e)       [поздовжня складова, потік]
i_q = −i_α · sin(θ_e) + i_β · cos(θ_e)       [поперечна складова, момент]
```

Електромагнітний крутний момент неявнополюсного двигуна з постійними магнітами (англ. *Surface Permanent Magnet*, де індуктивності `L_d = L_q`) виражається рівнянням:

```
τ_e = (3/2) · p · Ψ_m · i_q
```

де `p` — кількість пар магнітних полюсів ротора, `Ψ_m` — зчеплений магнітний потік постійних магнітів (Вб), `i_q` — квадратурний струм (А).

З цього рівняння випливає ключовий принцип FOC для стабілізованого підвісу:
1. Струм прямої осі `i_d` задається рівним нулю (`i_d_des = 0`). Будь-який струм `i_d ≠ 0` не створює корисного обертового моменту, а лише марно нагріває обмотки двигуна та створює непотрібне радіальне навантаження на підшипники (демагнетизацію або підмагнічування).
2. Струм квадратурної осі `i_q` прямо пропорційний бажаному крутному моменту стабілізації: `i_q_des = τ_des / K_t`.

## Зворотне перетворення Парка

Після того, як регулятори струму (або контур напруги в системах з прямим заданням поля) обчислили необхідні керівні напруги `u_d` та `u_q` в обертовій системі координат ротора, їх необхідно повернути назад у нерухому систему `α-β` статора для фізичного формування напруг напівмостами інвертора:

```
[ u_α ]   [ cos(θ_e)  −sin(θ_e) ]   [ u_d ]
[ u_β ] = [ sin(θ_e)   cos(θ_e) ] · [ u_q ]
```

Покомпонентний розрахунок зворотного перетворення:

```
u_α = u_d · cos(θ_e) − u_q · sin(θ_e)
u_β = u_d · sin(θ_e) + u_q · cos(θ_e)
```

При роботі підвісу в режимі задання напруги без вимірювання фазних струмів (voltage-mode FOC, типовий для моторів з високим опором обмоток), ми задаємо `u_d = 0`, а `u_q` беремо прямо з виходу регулятора швидкості. Тоді формули спрощуються до:

```
u_α = −u_q · sin(θ_e)
u_β =  u_q · cos(θ_e)
```

## Широтно-імпульсна модуляція просторового вектора (SVPWM)

Отриманий двовимірний вектор бажаної напруги статора `U_out = (u_α, u_β)` з модулем `U_mag = √(u_α² + u_β²)` та кутом `θ_v = atan2(u_β, u_α)` потрібно синтезувати за допомогою трифазного інвертора.

Три напівмости інвертора можуть перебувати у двох дискретних станах кожен: верхній ключ відкритий (стан `1`) або нижній ключ відкритий (стан `0`). Це дає `2³ = 8` можливих комбінацій перемикання ключів:
* 6 активних базових векторів напруги `V_1...V_6` з однаковою амплітудою `(2/3) · V_dc`, розташованих по вершинах правильного шестикутника зі зсувом 60°;
* 2 нульові вектори `V_0 (000)` та `V_7 (111)`, при яких усі фази двигуна закорочені на мінусову або плюсову шину живлення, а вихідна напруга на фазах дорівнює нулю.

### Визначення номера сектора

Простір напруг ділиться на 6 секторів по 60° кожен:

```
Сектор 1:    0° ≤ θ_v < 60°   (між V1(100) та V2(110))
Сектор 2:   60° ≤ θ_v < 120°  (між V2(110) та V3(010))
Сектор 3:  120° ≤ θ_v < 180°  (між V3(010) та V4(011))
Сектор 4:  180° ≤ θ_v < 240°  (між V4(011) та V5(001))
Сектор 5:  240° ≤ θ_v < 300°  (між V5(001) та V6(101))
Сектор 6:  300° ≤ θ_v < 360°  (між V6(101) та V1(100))
```

Швидке визначення сектора без обчислення трансцендентної функції `atan2()` виконується за трьома проекціями Кларк:

```
v_ref1 = u_β
v_ref2 = (√3 · u_α − u_β) / 2
v_ref3 = (−√3 · u_α − u_β) / 2
```

Формується бітова маска сектора:

```
a = (v_ref1 > 0) ? 1 : 0
b = (v_ref2 > 0) ? 1 : 0
c = (v_ref3 > 0) ? 1 : 0
sector_code = a + 2·b + 4·c
```

За таблицею відповідності коду визначається індекс сектора: `[0, 2, 6, 1, 4, 3, 5]`.

### Розрахунок часу увімкнення базових векторів (Dwell Times)

Усередині довільного сектора вектор напруги `U_out` синтезується за період ШІМ `T_s` як середньозважена комбінація двох сусідніх активних векторів `V_a`, `V_b` та нульових векторів:

```
U_out · T_s = V_a · T_1 + V_b · T_2 + V_0 · (T_0 / 2) + V_7 · (T_0 / 2)
```

Для сектора 1 (де `V_a = V_1`, `V_b = V_2`, кут всередині сектора `θ' = θ_v`):

```
T_1 = T_s · (√3 · U_out / V_dc) · sin(60° − θ')                 [геометрична проекція на вісь V1]
    = (√3 · T_s / V_dc) · (u_α · sin(60°) − u_β · cos(60°))     [тригонометрична тотожність різниці кутів]
    = (T_s / V_dc) · ( (3/2)·u_α − (√3/2)·u_β )                [підстановка sin(60°)=√3/2 та cos(60°)=1/2]

T_2 = T_s · (√3 · U_out / V_dc) · sin(θ')                       [геометрична проекція на вісь V2]
    = (√3 · T_s / V_dc) · u_β                                   [підстановка u_β = U_out · sin(θ')]

T_0 = T_s − T_1 − T_2                                           [залишковий час для нульових станів V0, V7]
```

Якщо вектор виходить за межі лінійної модуляції (`T_1 + T_2 > T_s`), проводиться нормалізація (масштабування):

```
T_1_sat = T_1 · T_s / (T_1 + T_2)
T_2_sat = T_2 · T_s / (T_1 + T_2)
T_0_sat = 0
```

### Симетрична 7-сегментна комутація ШІМ

Для мінімізації високочастотних пульсацій струму та гармонійних втрат у залізі двигуна імпульси ШІМ центрують симетрично відносно середини періоду таймера (режим Center-Aligned PWM з лічильником Up-Down).

Послідовність перемикання станів у секторі 1 протягом періоду:
`V_0 (000) → V_1 (100) → V_2 (110) → V_7 (111) → V_2 (110) → V_1 (100) → V_0 (000)`

Тривалості високого рівня коефіцієнтів заповнення для таймерів фаз `A`, `B`, `C`:

```
T_a = T_1 + T_2 + T_0 / 2
T_b = T_2 + T_0 / 2
T_c = T_0 / 2
```

Коефіцієнти шпаруватості ШІМ для апаратних регістрів порівняння таймера:

```
Duty_A = T_a / T_s
Duty_B = T_b / T_s
Duty_C = T_c / T_s
```

## Перевага SVPWM над стандартною синусоїдальною модуляцією (SPWM)

У класичній синусоїдальній модуляції максимальна міжфазна напруга без спотворення форми синусоїди обмежена величиною:

```
V_phase_max_SPWM = V_dc / 2 = 0.500 · V_dc
```

У векторній модуляції SVPWM додавання синфазної нульової послідовності (яка еквівалентна третій гармоніці синусоїди) ефективно ущільнює напругу без її проникнення у міжфазну різницю потенціалів. Максимальний радіус неспотвореного вектора відповідає радіусу кола, вписаного в шестикутник:

```
V_phase_max_SVPWM = V_dc / √3 ≈ 0.57735 · V_dc
```

Приріст ефективності використання напруги шини постійного струму становить:

```
ΔV = (1/√3 − 1/2) / (1/2) = 2/√3 − 1 ≈ 15.47%
```

Для акумуляторного підвісу дрона з напругою батареї 12 В (3S LiPo) це дає змогу отримати додатковий запас динамічної напруги для компенсації швидких кутових прискорень без необхідності підвищення напруги живлення всієї плати.
