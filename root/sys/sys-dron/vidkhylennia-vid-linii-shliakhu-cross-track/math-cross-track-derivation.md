# 🧮 Геометричне виведення похибки відхилення та стійкості LOS

Без точного математичного виведення неможливо зрозуміти, чому звичайний векторний добуток дає відстань зі знаком і за яких саме умов кут наведення гарантує експоненційне повернення без розгойдування. Тут наведено строгий геометричний вивід похибки відхилення від прямої (cross-track error), поздовжньої відстані (along-track distance), а також аналіз стійкості за Ляпуновим для закону наведення прямої видимості (Line-of-Sight, LOS) та інтегральної компенсації зносу вітром.

## Векторне представлення відрізка та позиції

Нехай у двовимірній декартовій системі координат задано відрізок маршруту двома точками: початковою `W_A = (x_A, y_A)` та кінцевою `W_B = (x_B, y_B)`. Поточне положення безпілотного апарата описується точкою `p = (p_x, p_y)`.

Введемо вектор переміщення відрізка `b` та вектор зміщення апарата від початку відрізка `a`:

```
b = W_B − W_A = (x_B − x_A,  y_B − y_A)       [вектор відрізка шляху]
a = p − W_A   = (p_x − x_A,  p_y − y_A)       [вектор від початку до дрона]
```

Довжина заданого сегмента маршруту `L_AB` дорівнює евклідовій нормі вектора `b`:

```
L_AB = ||b|| = √( (x_B − x_A)² + (y_B − y_A)² )   [евклідова довжина відрізка]
```

Одиничний дотичний вектор `t̂`, що вказує напрямок руху вздовж лінії від `W_A` до `W_B`, має вигляд:

```
t̂ = b / ||b|| = ( (x_B − x_A) / L_AB,  (y_B − y_A) / L_AB ) = (t_x, t_y)   [дотичний орт]
```

Одиничний нормальний вектор `n̂`, повернутий на 90° за годинниковою стрілкою (праворуч по ходу руху):

```
n̂ = (−t_y,  t_x) = ( −(y_B − y_A) / L_AB,  (x_B − x_A) / L_AB )            [нормальний орт]
```

Оскільки вектори `t̂` та `n̂` ортогональні й мають одиничну довжину, вони утворюють ортонормований базис рухомого фрейму шляху (Frenet frame). Будь-який двовимірний вектор положення можна однозначно розкласти за цим базисом.

## Виведення поздовжньої пройденої відстані (along-track)

Поздовжня відстань `s` є ортогональною проєкцією вектора положення `a` на дотичний вектор `t̂`. За означенням скалярного добутку:

```
s = a · t̂
  = a_x · t_x + a_y · t_y                     [розклад за координатами]
  = ( (p_x − x_A)(x_B − x_A) + (p_y − y_A)(y_B − y_A) ) / L_AB   [підстановка складових]
```

Нормалізований прогрес проходження відрізка `u` обчислюється як частка від повної довжини:

```
u = s / L_AB
  = ( (p_x − x_A)(x_B − x_A) + (p_y − y_A)(y_B − y_A) ) / (L_AB)²   [параметр відрізка]
```

Значення параметра `u` однозначно визначає просторове положення проєкції відносно меж відрізка:
- `u < 0`: проєкція лежить позаду початкової точки `W_A` (дрон ще не увійшов у робочу зону сегмента);
- `0 ≤ u ≤ 1`: проєкція лежить безпосередньо на відрізку між `W_A` та `W_B`;
- `u > 1`: проєкція вийшла за межі точки `W_B` (сегмент пройдено, потрібне негайне перемикання на наступну точку місії).

Координати точки ортогональної проєкції `p_proj` на пряму маршруту визначаються векторним рівнянням прямої:

```
p_proj = W_A + s · t̂ = W_A + u · b            [координати точки проєкції]
```

Вектор відхилення точки `p` від її проєкції `p_proj` лежить строго на нормалі `n̂`:

```
p − p_proj = a − (a · t̂) · t̂                  [ортогональна складова положення]
```

## Виведення поперечного відхилення (cross-track error)

Поперечне відхилення `e_ct` є знаковою відстанню від точки `p` до прямої, що проходить через `W_A` та `W_B`. У двовимірному просторі косий (псевдоскалярний) добуток векторів `a` та `b` чисельно дорівнює орієнтованій площі паралелограма, натягнутого на ці вектори.

З іншого боку, площа цього ж паралелограма дорівнює добутку довжини основи `||b||` на висоту `e_ct`:

```
Площа = a_x · b_y − a_y · b_x                 [псевдоскалярний 2D-добуток a × b]
Площа = ||b|| · e_ct                          [геометрична площа через основу і висоту]
```

Прирівнюючи обидва вирази для площі, отримуємо формулу поперечного відхилення:

```
e_ct = (a_x · b_y − a_y · b_x) / ||b||
     = ( (p_x − x_A)(y_B − y_A) − (p_y − y_A)(x_B − x_A) ) / L_AB   [формула cross-track]
```

Через одиничний дотичний вектор `t̂ = (t_x, t_y)` вираз записується у формі проєкції на нормальний орт:

```
e_ct = a · n̂ = a_x · (−t_y) + a_y · (t_x) = a_x · t_y − a_y · t_x   [скалярний добуток з нормаллю n̂]
```

Правило знаків відхилення:
- Якщо вектор `a` відхилений праворуч від напрямку `t̂`, визначник є додатним: `e_ct > 0` (дрон знаходиться праворуч від лінії, потрібен поворот ліворуч);
- Якщо вектор `a` відхилений ліворуч від напрямку `t̂`, визначник є від'ємним: `e_ct < 0` (дрон знаходиться ліворуч від лінії, потрібен поворот праворуч);
- Якщо дрон знаходиться точно на лінії шляху, вектори `a` та `b` колінеарні, `e_ct = 0`.

## Матрична форма та обертання системи координат

Альтернативним способом обчислення є прямий перенос початку координат у точку `W_A` з подальшим обертанням системи на кут орієнтації лінії шляху `χ_F = atan2(y_B − y_A, x_B − x_A)`.

Матриця повороту для переходу у фрейм шляху має вигляд:

```
[ s    ]   [  cos(χ_F)   sin(χ_F) ] [ p_x − x_A ]
[ e_ct ] = [ −sin(χ_F)   cos(χ_F) ] [ p_y − y_A ]     [матричне перетворення координат]
```

Розкриваючи матричний добуток:

```
s    =  (p_x − x_A) · cos(χ_F) + (p_y − y_A) · sin(χ_F)   [поздовжня координата]
e_ct = −(p_x − x_A) · sin(χ_F) + (p_y − y_A) · cos(χ_F)   [поперечна координата]
```

Оскільки `cos(χ_F) = t_x` та `sin(χ_F) = t_y`, цей результат повністю тотожний формулам через скалярний та косий добутки.

## Динаміка похибки та закон наведення прямої видимості (LOS)

Розглянемо кінематику руху безпілотного апарата у горизонтальній площині. Нехай апарат рухається зі шляховою швидкістю `v` під шляховим кутом `χ`. Кут орієнтації відрізка шляху позначимо через `χ_F`.

Швидкість зміни поперечного відхилення `ė_ct` визначається проєкцією вектора швидкості `v` на нормаль до лінії шляху:

```
ė_ct = v · sin(χ − χ_F)                       [диференціальне рівняння бокового зміщення]
```

Класичний закон наведення Line-of-Sight (LOS) формує командний кут шляху `χ_cmd` як суму базового кута сегмента `χ_F` та кута корекції `χ_cross`:

```
χ_cross = atan( −e_ct / Δ_los )               [кут входу на лінію]
χ_cmd   = χ_F + χ_cross
        = χ_F − atan( e_ct / Δ_los )          [командний курс LOS]
```

де `Δ_los > 0` — дистанція випередження прямої видимості (lookahead distance).

Підставляючи командний курс `χ = χ_cmd` у диференціальне рівняння швидкості відхилення:

```
ė_ct = v · sin( −atan( e_ct / Δ_los ) )
     = −v · sin( atan( e_ct / Δ_los ) )       [непарність функції синуса]
```

Скористаємося тригонометричною тотожністю `sin(atan(z)) = z / √(1 + z²)`:

```
sin( atan( e_ct / Δ_los ) )
= (e_ct / Δ_los) / √( 1 + (e_ct / Δ_los)² )   [тригонометрична тотожність]
= e_ct / √( Δ_los² + e_ct² )                  [зведення до спільного знаменника]
```

Отримуємо замкнене диференціальне рівняння еволюції cross-track похибки:

```
ė_ct = −v · e_ct / √( Δ_los² + e_ct² )        [точне нелінійне рівняння замкненого контуру]
```

## Доведення стійкості за Ляпуновим

Для доведення глобальної асимптотичної стійкості оберемо квадратичну функцію Ляпунова `V(e_ct)`:

```
V(e_ct) = (1/2) · e_ct²                       [радіально необмежена, V(0) = 0, V > 0 при e_ct ≠ 0]
```

Обчислимо повну похідну функції Ляпунова за часом уздовж траєкторії системи:

```
V̇(e_ct) = e_ct · ė_ct
        = e_ct · ( −v · e_ct / √( Δ_los² + e_ct² ) )   [підстановка диференціального рівняння]
        = −v · e_ct² / √( Δ_los² + e_ct² )             [похідна Ляпунова]
```

Аналіз знаку похідної `V̇(e_ct)`:
1. Оскільки швидкість `v > 0` і `Δ_los > 0`, знаменник `√(Δ_los² + e_ct²) > 0` для будь-яких `e_ct`;
2. Чисельник `e_ct² > 0` для будь-якого `e_ct ≠ 0`;
3. Отже, `V̇(e_ct) < 0` строго від'ємна для всіх `e_ct ≠ 0`, і `V̇(0) = 0`.

За теоремою Барбашина–Красовського рівноважний стан `e_ct = 0` є глобально асимптотично стійким. Похибка гарантовано прямує до нуля з будь-якого початкового відхилення без ризику нестійкості чи необмеженого розбігання.

## Лінеаризація та оцінка сталої часу контуру

Коли апарат знаходиться поблизу лінії шляху (`|e_ct| ≪ Δ_los`), знаменник `√(Δ_los² + e_ct²) ≈ Δ_los`. Нелінійне диференціальне рівняння переходить у лінійне диференціальне рівняння першого порядку:

```
ė_ct ≈ −(v / Δ_los) · e_ct                    [лінеаризована динаміка першого порядку]
```

Розв'язок цього рівняння є класичною експонентою:

```
e_ct(t) = e_ct(0) · exp( −t / τ )             [експоненційне затухання]
τ = Δ_los / v                                 [стала часу перехідного процесу]
```

Стала часу `τ` показує, за який час бокове відхилення зменшиться в `e ≈ 2.718` разів:
- При збільшенні швидкості `v` процес повернення прискорюється (менше `τ`);
- При збільшенні дистанції випередження `Δ_los` рух стає плавнішим, але час збіжності зростає;
- Час практичного усунення похибки (до рівня 5% від початкового) становить `t_settle ≈ 3 · τ = 3 · Δ_los / v`.

## Врахування запізнення внутрішнього контуру курсу

У реальному літаку курс `χ` не змінюється миттєво до `χ_cmd`. Внутрішній контур автопілота (рулі, елерони, гіроскопи) має власну динаміку, яку можна апроксимувати аперіодичною ланкою першого порядку зі сталою часу `T_ψ`:

```
χ̇ = (1 / T_ψ) · (χ_cmd − χ)                   [динаміка відстеження курсу літаком]
```

Об'єднуючи лінеаризовані рівняння для `e_ct` та `χ`, отримуємо систему другого порядку:

```
d² e_ct / dt² + (1 / T_ψ) · (d e_ct / dt) + (v / (T_ψ · Δ_los)) · e_ct = 0   [рівняння коливальної ланки]
```

Характеристичне рівняння цієї замкненої системи:

```
p² + (1 / T_ψ) · p + (v / (T_ψ · Δ_los)) = 0  [характеристичний поліном]
```

Стандартна форма характеристичного рівняння коливальної ланки:

```
p² + 2 · ζ · ω_n · p + ω_n² = 0               [канонічна форма другого порядку]
```

Прирівнюючи коефіцієнти, визначаємо власну частоту `ω_n` та коефіцієнт демпфування `ζ`:

```
ω_n = √( v / (T_ψ · Δ_los) )                  [власна частота контуру навігації]
ζ   = (1 / (2 · T_ψ · ω_n)) = (1 / 2) · √( Δ_los / (v · T_ψ) )   [коефіцієнт демпфування]
```

Умова відсутності коливань та перерегулювання (аперіодичний або критично демпфований процес `ζ ≥ 1.0`):

```
(1 / 2) · √( Δ_los / (v · T_ψ) ) ≥ 1.0        [умова демпфування без коливань]
Δ_los ≥ 4 · v · T_ψ                           [мінімально допустима дистанція випередження]
```

Ця формула дає фундаментальне інженерне правило налаштування: **дистанція випередження `Δ_los` повинна перевищувати щонайменше чотири шляхи, які літак пролітає за час реакції свого контуру курсу `v · T_ψ`**. Якщо обрати `Δ_los` меншим за цей поріг, виникнуть незгасаючі бічні автоколивання літака навколо лінії маршруту.

## Вплив бокового вітру та інтегральна корекція (ILOS)

Нехай на дрон діє постійний боковий вітер зі швидкістю `v_w` перпендикулярно до лінії шляху. Якщо автопілот орієнтує ніс літака за курсом `χ_cmd`, дійсний вектор швидкості відносно землі відхиляється на кут зносу (drift angle) `β_w ≈ v_w / v`.

У сталому режимі (`ė_ct = 0`) стандартний закон LOS створює постійне статичне зміщення:

```
0 = v · sin( χ_cross + β_w )                  [умова стаціонарності з вітром]
χ_cross = −β_w                                [необхідний кут парирування]
−atan( e_ct_ss / Δ_los ) = −β_w               [підстановка закону LOS]
e_ct_ss = Δ_los · tan(β_w) ≈ Δ_los · (v_w / v) [статична похибка без інтегратора]
```

Для повного усунення цієї статичної похибки вводиться інтеграл похибки відхилення:

```
y_int(t) = ∫₀ᵗ e_ct(t') dt'                   [накопичена поперечна похибка]
e_ct_eff = e_ct + k_i · y_int                 [ефективна похибка з інтегратором]
χ_cmd    = χ_F − atan( (e_ct + k_i · y_int) / Δ_los )   [закон інтегрального наведення ILOS]
```

У сталому режимі інтеграл `y_int` накопичує значення `y_int_ss = (Δ_los / k_i) · tan(β_w)`, що повністю компенсує кут зносу, зводячи дійсну похибку положення точно до нуля: `e_ct_ss = 0`.
