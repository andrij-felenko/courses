# 🧮 Аеродинамічна модель екранного ефекту землі та динаміка відриву

Екранний ефект землі (англ. *In Ground Effect*, IGE) докорінно змінює структуру повітряного потоку під ротором безпілотного апарата на малій висоті. Коли лопаті обертаються поблизу непроникної твердої поверхні, вільний схід індуктивного струменя гальмується, під пропелером утворюється зона підвищеного статичного тиску, а кінцеві вихори деформуються й рециркулюють. Це явище дає приріст підйомної сили при тій самій потужності, але водночас породжує аеродинамічну нестабільність і створює локальні барометричні аномалії.

## Класична імпульсна теорія та метод гідродинамічних відображень

Для кількісного опису зміни тяги ротора на малій висоті застосовують класичну імпульсну теорію та метод гідродинамічних відображень. Тверда поверхня землі розглядається як непроникна межа розділу, на якій нормальна складова швидкості повітряного потоку тотожно дорівнює нулю:

```
v_z(x, y, 0) = 0
```

Цю крайову умову моделюють розміщенням фіктивного дзеркального ротора на відстані `h` під поверхнею землі з протилежно спрямованим потоком.

Нехай:
- `R` — радіус гвинта (у метрах);
- `D = 2 · R` — діаметр гвинта (у метрах);
- `A = π · R²` — площа ометання ротора (у квадратних метрах);
- `h` — висота площини обертання гвинта над твердою поверхнею (у метрах);
- `T_OGE` — тяга ротора у вільному повітрі (Out of Ground Effect, у ньютонах);
- `T_IGE` — тяга ротора в зоні екранного ефекту (In Ground Effect, у ньютонах);
- `v_i,inf` — індуктивна швидкість у вільному повітрі на режимі висіння (у метрах за секунду);
- `ρ` — густина повітря (приблизно 1.225 кг/м³ за стандартних атмосферних умов).

За теоремою про зміну кількості руху індуктивна швидкість у вільному повітрі пов'язана з тягою та геометрією ротора:

```
v_i,inf = sqrt( T_OGE / (2 · ρ · A) )
```

Поле швидкостей дзеркального ротора створює додаткову висхідну складову швидкості в площині реального гвинта, що зменшує результуючу індуктивну швидкість струменя `v_i(h)`:

```
v_i(h) = v_i,inf · [ 1 - (R / (4 · h))² ]
```

Оскільки тяга ротора за незмінної механічної потужності на валу двигуна `P` обернено пропорційна середній швидкості протоку повітря крізь диск, відношення тяги в екрані до тяги у вільному повітрі за моделлю Чізмена–Беннета (Cheeseman & Bennett) набуває аналітичного вигляду:

```
T_IGE / T_OGE = 1 / [ 1 - (R / (4 · h))² ]
```

Розрахуємо коефіцієнт підсилення тяги `k_IGE = T_IGE / T_OGE` для характерних відносних висот `z = h / D = h / (2 · R)`:

```
h / D = 0.25  =>  h = 0.5 · R  =>  k_IGE = 1 / [ 1 - (1/2)² ] = 1 / (1 - 0.25) = 1.333   [приріст тяги +33.3%]
h / D = 0.50  =>  h = 1.0 · R  =>  k_IGE = 1 / [ 1 - (1/4)² ] = 1 / (1 - 0.0625) = 1.067 [приріст тяги +6.7%]
h / D = 0.75  =>  h = 1.5 · R  =>  k_IGE = 1 / [ 1 - (1/6)² ] = 1 / (1 - 0.0278) = 1.029 [приріст тяги +2.9%]
h / D = 1.00  =>  h = 2.0 · R  =>  k_IGE = 1 / [ 1 - (1/8)² ] = 1 / (1 - 0.0156) = 1.016 [приріст тяги +1.6%]
h / D = 1.50  =>  h = 3.0 · R  =>  k_IGE = 1 / [ 1 - (1/12)² ] = 1.007                    [екранний ефект зникає]
```

## Уточнена емпірична модель Хейдена для надмалих висот

Класична формула Чізмена–Беннета має математичну сингулярність при наближенні висоти до `h = R / 4` (знаменник перетворюється на нуль). У реальному середовищі потік має в'язкість і впирається у пограничний шар на поверхні, через що повітря розтікається радіально. Для точного моделювання діапазону надмалих висот (`h / D < 0.5`) використовують емпіричну модель Хейдена (Hayden), верифіковану в експериментах для безпілотних мультироторів:

```
T_IGE / T_OGE = 1 / [ A_h - B_h · (h / D)^1.5 ]
```

де для типових дволопатевих і трилопатевих карбонових гвинтів емпіричні коефіцієнти становлять `A_h = 0.95` та `B_h = 0.35`.

Модель показує, що на рівні посадкових опор дрона (`h / D ≈ 0.15–0.20`) максимальний приріст тяги досягає `20–25%`. При підйомі апарата на висоту одного діаметра (`h ≥ 1.0 · D`) вплив екрана падає нижче 2%, а на висоті `h ≥ 1.5 · D` повністю нівелюється.

## Енергетика та баланс потужності в екранному ефекті

Повна аеродинамічна потужність, споживана гвинтом `P_aero`, складається з індуктивної потужності `P_i` (витрати енергії на відкидання маси повітря вниз) та профільної потужності `P_0` (витрати на подолання в'язкого тертя лопатей):

```
P_aero = P_i + P_0 = T · v_i + 1/8 · ρ · C_d0 · σ · A · (ω · R)³
```

де:
- `C_d0` — середній коефіцієнт профільного опору лопаті (зазвичай 0.012–0.018);
- `σ = (N_blades · c_chord) / (π · R)` — коефіцієнт заповнення ротора;
- `ω` — кутова швидкість обертання ротора (в радіанах за секунду).

В екранному ефекті профільна потужність `P_0` залишається незмінною, тоді як індуктивна потужність суттєво зменшується через зниження індуктивної швидкості `v_i(h)`:

```
P_i,IGE = T · v_i(h) = T · v_i,inf · [ 1 - (R / (4 · h))² ]
```

Економія електричної потужності `ΔP_elec`, що споживається від силового акумулятора через регулятор ESC (з ККД `η_esc ≈ 0.95` та ККД мотора `η_mot ≈ 0.85`), становить:

```
ΔP_elec = (P_i,inf - P_i,IGE) / (η_esc · η_mot) = [ T · v_i,inf · (R / (4 · h))² ] / (η_esc · η_mot)
```

Для 4-моторного дрона масою `m = 2.0 кг` на висоті `h = 0.15 м` сумарна економія потужності сягає `18–25 Вт`. Проте ця вигода є оманливою: перехідний характер зони екрана змушує регулятор витрачати додаткову енергію на динамічне парирування вихрових збурень.

## Дестабілізуючий перекидальний момент на похилій поверхні

Якщо дрон розташований над похилою площиною (кут нахилу рельєфу `α`) або здійснює зліт за наявності бічного вітру, відстань від кожного ротора до землі виявляється різною.

```
                  Мотор 1 (вище)                   Мотор 2 (нижче)
                     h₁ > h₂                           h₂ < h₁
                    ┌───────┐                         ┌───────┐
                    │  M₁   │                         │  M₂   │
                    └───┬───┘                         └───┬───┘
                        │                                 │
     Повітряний         │   Тяга T₁ (менша)               │   Тяга T₂ (більша: екран!)
     зазор              │                                 │
                        │                                 ▼
   ─────────────────────┴───────────────────────────────────────   Поверхня землі
                                                            Похилий майданчик (кут α)
```

Нехай відстань між протилежними моторами дорівнює базі рами `L`. При нахилі корпусу на кут `θ` ротори опиняються на висотах:

```
h_1 = h_0 + (L / 2) · sin(θ)
h_2 = h_0 - (L / 2) · sin(θ)
```

Оскільки ротор 2 знаходиться ближче до землі (`h_2 < h_1`), його коефіцієнт підсилення тяги `k_IGE,2` більший за коефіцієнт ротора 1 (`k_IGE,1`). Виникає нескомпенсована різниця тяг:

```
ΔT_IGE = T_2 - T_1 = T_hover · [ k_IGE(h_2) - k_IGE(h_1) ]
```

Ця різниця тяг породжує аеродинамічний момент перекидання навколо центру мас:

```
M_destab = ΔT_IGE · (L / 2) = T_hover · [ k_IGE(h_2) - k_IGE(h_1) ] · (L / 2)
```

Для апарата масою `m = 2.5 кг` (`T_hover = 24.5 Н`), базою `L = 0.45 м` на висоті `h_0 = 0.12 м` при випадковому куті нахилу `θ = 4°`:

```
h_1 = 0.12 + 0.225 · sin(4°) = 0.12 + 0.0157 = 0.1357 м
h_2 = 0.12 - 0.225 · sin(4°) = 0.12 - 0.0157 = 0.1043 м
k_IGE,1 = 1.072,   k_IGE,2 = 1.135
ΔT_IGE = 12.25 · (1.135 - 1.072) = 0.772 Н
M_destab = 0.772 · 0.225 = 0.174 Н·м
```

Момент `0.174 Н·м` на плечі 22.5 см є достатнім, щоб розгорнути дрон на опорах за час менше `0.25 с`, якщо контур стабілізації не парирує це збурення швидким диференціальним відгуком.

## Аеродинамічний тиск повітряної подушки та вплив на барометр

Гальмування вертикального потоку об землю трансформує динамічний тиск індуктивного струменя в надлишковий статичний тиск `ΔP_cushion` під корпусом дрона:

```
ΔP_cushion = 1/2 · ρ · [ v_i,inf² - v_i(h)² ]
```

Підставляючи вираз для `v_i(h)`:

```
ΔP_cushion = 1/2 · ρ · v_i,inf² · [ 1 - ( 1 - (R / (4 · h))² )² ]
```

Для квадрокоптера масою 2.0 кг із 10-дюймовими гвинтами (`R = 0.127 м`, сумарна тяга висіння `T = 19.62 Н`, `T_per_rotor = 4.905 Н`):

```
A = π · 0.127² = 0.05067 м²
v_i,inf = sqrt( 4.905 / (2 · 1.225 · 0.05067) ) = 6.28 м/с
```

На висоті `h = 0.10 м` (`h / D ≈ 0.39`):

```
R / (4 · h) = 0.127 / 0.40 = 0.3175
(R / (4 · h))² = 0.1008
v_i(h) = 6.28 · (1 - 0.1008) = 5.65 м/с
ΔP_cushion = 0.5 · 1.225 · ( 6.28² - 5.65² ) = 0.6125 · ( 39.44 - 31.92 ) = 4.61 Па
```

Барометрична формула зв'язку тиску з висотою біля поверхні землі:

```
Δh_baro = - ΔP / (ρ · g)
```

де `g = 9.81 м/с²`.

При надлишковому тиску `ΔP = +4.61 Па`:

```
Δh_baro = - 4.61 / (1.225 · 9.81) = - 0.383 м  [-38.3 см]
```

Цей результат пояснює природу злітної барометричної аномалії: підвищений статичний тиск під гвинтами сприймається неізольованим датчиком як «занурення» апарата під землю на 30–40 сантиметрів.

## Динаміка розгону під час подолання екрана

Диференціальне рівняння вертикального руху центру мас дрона вздовж вертикальної осі Z (спрямованої вгору) має вигляд:

```
m · (d²h / dt²) = T_total(u, h) - m · g - F_drag(dh/dt)
```

де:
- `m` — маса дрона (кг);
- `T_total(u, h) = 4 · T_per_rotor(u) · k_IGE(h)` — сумарна тяга роторів;
- `F_drag = 1/2 · ρ · C_d,z · S_z · (dh/dt)²` — аеродинамічний опір корпусу при вертикальному русі.

Щоб мінімізувати час перебування в зоні вихрової нестабільності та барометричного шуму (`0 < h < h_clear`, де `h_clear ≈ 1.2 · D`), автомат зльоту задає підвищену тягу відриву `u_takeoff ≈ 1.30 · u_hover`.

Для маси `m = 2.0 кг` тяга висіння становить `T_hover = 19.62 Н`. При форсованій тязі `T_takeoff = 1.30 · 19.62 = 25.51 Н` та середньому коефіцієнті екрана `k_IGE_avg ≈ 1.15` на перших 0.5 м підйому:

```
T_eff = 25.51 · 1.15 = 29.34 Н
a_z = (T_eff - m · g) / m = (29.34 - 19.62) / 2.0 = 4.86 м/с²
```

Час проходження приземного шару товщиною `h_clear = 1.2 м`:

```
t_clear = sqrt( 2 · h_clear / a_z ) = sqrt( 2 · 1.2 / 4.86 ) = sqrt( 0.494 ) = 0.703 с
```

Досягнута вертикальна швидкість у момент виходу з екрана:

```
V_z,clear = a_z · t_clear = 4.86 · 0.703 = 3.42 м/с
```

Імпульсний зліт із підвищеним темпом набору висоти долає небезпечну зону екрана менш ніж за одну секунду, унеможливлюючи розгойдування апарата та захищаючи його від перекидання.
