# 🧮 Геометрія та кінематика плавного повернення на лінію шляху

Коли літальний апарат виходить із режиму утримання позиції (Loiter/Hold) і повертається до виконання перерваного маршруту, пряме наведення на активну точку створює дві проблеми: вихід за межі узгодженого польотного коридору та різкий стрибок кутового прискорення. Для плавного повернення автопілот розраховує траєкторію перехоплення вихідної прямої між точками `W[k-1]` та `W[k]`, обмежуючи кут зустрічі з лінією, бічне перевантаження та швидкість наростання ривка (jerk).

## 1. Локальна система координат відрізка та бокове зміщення

Нехай попередній пройдений пункт маршруту має локальні декартові координати в системі NED (North-East-Down) `W_prev = [x_prev, y_prev, z_prev]`, а активна цільова точка — `W_curr = [x_curr, y_curr, z_curr]`.

Горизонтальний вектор напрямку польотного сегмента у площині North-East позначаємо як `Δr`, а його евклідову довжину — як `L_seg`:

```text
Δx = x_curr − x_prev                                    [приріст по осі North]
Δy = y_curr − y_prev                                    [приріст по осі East]
L_seg = sqrt(Δx² + Δy²)                                 [горизонтальна довжина сегмента]
```

Одиничний напрямний вектор відрізка `u`:

```text
u_x = Δx / L_seg                                        [напрямний косинус осі North]
u_y = Δy / L_seg                                        [напрямний косинус осі East]
```

Одиничний вектор правої нормалі `n`, отриманий поворотом вектора `u` на 90° за годинниковою стрілкою:

```text
n_x =  u_y                                              [компонента нормалі North]
n_y = −u_x                                              [компонента нормалі East]
```

Поточне положення безпілотника у просторі позначаємо вектором `P = [x, y, z]`. Вектор відносної позиції від початку поточного відрізка:

```text
Δp_x = x − x_prev                                       [зсув від початкової точки North]
Δp_y = y − y_prev                                       [зсув від початкової точки East]
```

Скалярна проекція положення дрона на вісь маршруту (поздовжній прогрес `s`) та бокове відхилення від лінії шляху (Cross-Track Error `e_xt`):

```text
s    = Δp_x · u_x + Δp_y · u_y                          [пройдена дистанція вздовж осі]
e_xt = Δp_x · n_x + Δp_y · n_y                          [відхилення від осі: >0 праворуч, <0 ліворуч]
```

Координати точки ортогональної проекції `P_proj` на вісь треку:

```text
x_proj = x_prev + s · u_x                               [координата North проекції]
y_proj = y_prev + s · u_y                               [координата East проекції]
```

Залишкова відстань уздовж прямої до кінцевого пункту `d_rem`:

```text
d_rem = L_seg − s                                       [дистанція від проекції до W_curr]
```

Якщо значення `s < 0`, дрон перебуває позаду початкової точки `W_prev`; якщо `s > L_seg`, апарат проскочив точку `W_curr` за інерцією або через дію попутного вітру.

## 2. Розрахунок точки перехоплення та кута зближення

Якщо спрямувати вектор тяги безпосередньо в точку проекції `P_proj`, кут перетину лінії становитиме 90°. При досягненні осі регулятор буде змушений за нульовий час розвернути вектор швидкості на 90°, що фізично неможливо і призводить до значного перерегулювання (overshoot) із вильотом на протилежний бік коридору та незатухаючими коливаннями.

Для забезпечення асимптотичної збіжності алгоритм обирає рухому точку перехоплення (Intercept Point) `P_int`, розташовану попереду проекції `P_proj` на дистанцію випередження `L_lead`:

```text
L_lead = max(L_min, τ_lookahead · v_ground)             [динамічна дистанція випередження]
```

Параметр `τ_lookahead` задає часовий горизонт перехоплення (типово 2.5–4.0 секунди для мультироторів та 4.0–8.0 секунд для літаків), `L_min` — гарантований базовий відступ (наприклад, 10 метрів), що унеможливлює ділення на нуль під час старту із нульовою швидкістю, а `v_ground` — поточна шляхова швидкість апарата.

Координати точки перехоплення `P_int`:

```text
s_int = min(s + L_lead, L_seg)                          [обмеження точкою W_curr]
x_int = x_prev + s_int · u_x                            [координата North точки зустрічі]
y_int = y_prev + s_int · u_y                            [координата East точки зустрічі]
```

Кут перехоплення `χ_int` між вектором бажаного відрізка `u` та прямою на точку `P_int`:

```text
χ_int = atan2(−e_xt, L_lead)                            [геометричний кут сходження]
```

Знак мінус забезпечує повернення до нуля: при `e_xt > 0` (дрон праворуч від лінії) кут `χ_int < 0` спрямовує апарат ліворуч.

При великих бокових зсувах (`|e_xt| >> L_lead`) значення `atan2` прямує до ±90°. Для збереження курсової стійкості застосовується функція насичення з кутовим порогом `χ_max`:

```text
χ_cmd = clamp(χ_int, −χ_max, +χ_max)                    [насичення кута, χ_max = 30°..45°]
```

Повний командний шляховий кут польоту (Target Course) `ψ_cmd`:

```text
ψ_track = atan2(u_y, u_x)                               [азимут основного відрізка]
ψ_cmd   = ψ_track + χ_cmd                               [командний курс відновлення місії]
```

## 3. Доведення стійкості сходження за функцією Ляпунова

Розглянемо кінематику бокового зміщення у часі. Швидкість зміни бокової помилки описується рівнянням:

```text
ė_xt = v_ground · sin(ψ − ψ_track)                      [швидкість ліквідації зміщення]
```

Позначимо курсову помилку як `χ = ψ − ψ_track`. Якщо внутрішній контур стабілізації курсу відпрацьовує команду `χ → χ_cmd` із малою затримкою, отримуємо:

```text
ė_xt = v_ground · sin(χ_cmd)                            [динаміка бокового зближення]
```

Підставимо розрахунок кута через функцію арктангенса без насичення:

```text
sin(χ_cmd) = sin(atan2(−e_xt, L_lead)) = −e_xt / sqrt(L_lead² + e_xt²) [тригонометрична підстановка]
ė_xt = −(v_ground / sqrt(L_lead² + e_xt²)) · e_xt       [нелінійне диференціальне рівняння]
```

Виберемо додатньо визначену функцію Ляпунова `V(e_xt)`:

```text
V(e_xt) = 0.5 · e_xt²                                   [квадратична функція енергії помилки]
```

Її похідна за часом `V̇(e_xt)`:

```text
V̇(e_xt) = e_xt · ė_xt = −(v_ground / sqrt(L_lead² + e_xt²)) · e_xt² [похідна функції Ляпунова]
```

Оскільки `v_ground > 0` та `sqrt(L_lead² + e_xt²) > 0`, для всіх `e_xt ≠ 0` похідна `V̇(e_xt) < 0` є строго від'ємною. Це доводить асимптотичну стійкість: бокове відхилення монотонно прямує до нуля без перерегулювання та автоколивань.

## 4. Компенсація вітрового зносу та розрахунок кута упередження

У реальних польотних умовах на літальний апарат діє постійний вітровий вектор `w = [w_x, w_y]`. Якщо просто орієнтувати ніс апарата за курсом `ψ_cmd`, повітряний потік знесе дрон із розрахункової дуги перехоплення.

Позначимо повітряну швидкість апарата як `v_air`, а шляхову швидкість як `v_ground`. Трикутник швидкостей визначає кут зносу вітром (Wind Correction Angle або Crab Angle) `β_wind`:

```text
w_cross = −w_x · sin(ψ_cmd) + w_y · cos(ψ_cmd)          [бокова проекція швидкості вітру]
sin(β_wind) = w_cross / v_air                           [рівноважний синус кута зносу]
β_wind = asin(clamp(w_cross / v_air, −1.0, 1.0))        [розрахунковий кут упередження]
```

Командний кут рискання (Target Heading) `ψ_heading_cmd`, який подається на автопілот:

```text
ψ_heading_cmd = ψ_cmd + β_wind                          [корекція орієнтації носа на вітер]
```

Завдяки введенню `β_wind` вектор дійсної шляхової швидкості `v_ground` точно збігається з бажаним напрямком перехоплення `ψ_cmd`, навіть за наявності сильного бокового вітру, що досягає 40–50% від повітряної швидкості дрона.

## 5. Кінематичні обмеження: бічне прискорення та радіус розвороту

Рух по дузі виходу на лінію генерує доцентрове прискорення `a_lat`. Для запобігання зриву потоку на крилі літака або надмірного крену мультиротора величина `a_lat` обмежується порогом `a_lat_max` (типово 2.0–4.0 м/с²):

```text
a_lat = v_ground² / R_turn                              [доцентрове прискорення]
R_min = v_ground² / a_lat_max                           [мінімальний допустимий радіус кривини]
```

Для літака кут крену `φ` пов'язаний із доцентровим прискоренням співвідношенням:

```text
tan(φ) = a_lat / g = v_ground² / (g · R_turn)           [рівноважний кут крену]
φ_max  = atan(a_lat_max / g)                            [максимальний комфортний крен]
```

Якщо розрахункова дистанція випередження `L_lead` породжує траєкторію з кривизною, що перевищує `1 / R_min`, значення `L_lead` автоматично коригується для задоволення геометричного обмеження:

```text
L_lead_corr = sqrt(max(L_lead², 2 · R_min · |e_xt| − e_xt²)) [динамічне розширення дистанції]
```

## 6. Профіль розгону з обмеженням ривка (7-фазна S-крива)

Після виходу з паузи апарат повинен набрати швидкість від `0` до `v_cruise`. Використання кусково-постійного прискорення створює безкінечний ривок (jerk `j = da/dt = ∞`), що збуджує пружні коливання рами дрона та підвісу камери.

Траєкторний генератор формує 7-фазний симетричний S-профіль із фіксацією граничного ривка `j_max` (наприклад, 5.0 м/с³) та максимального прискорення `a_max` (2.0 м/с²):

Фаза 1: Лінійне наростання прискорення (`0 ≤ t < t_1`, де `t_1 = a_max / j_max`):

```text
j(t) = +j_max                                           [сталий позитивний ривок]
a(t) = j_max · t                                        [прискорення зростає від 0 до a_max]
v(t) = v_0 + 0.5 · j_max · t²                           [квадратичний набір швидкості]
```

Фаза 2: Постійне прискорення (`t_1 ≤ t < t_2`):

```text
j(t) = 0                                                [ривок відсутній]
a(t) = a_max                                            [стале граничне прискорення]
v(t) = v(t_1) + a_max · (t − t_1)                       [лінійне наростання швидкості]
```

Фаза 3: Плавне гасіння прискорення перед полицею швидкості (`t_2 ≤ t < t_3`, де `t_3 − t_2 = t_1`):

```text
j(t) = −j_max                                           [від'ємний ривок гасіння]
a(t) = a_max − j_max · (t − t_2)                        [прискорення падає від a_max до 0]
v(t) = v(t_2) + a_max · Δt − 0.5 · j_max · Δt²          [плавний вихід на сталу швидкість v_cruise]
```

Фаза 4: Рух із постійною круїзною швидкістю:

```text
j(t) = 0                                                [ривок нульовий]
a(t) = 0                                                [прискорення нульове]
v(t) = v_cruise                                         [стабільний маршовий режим]
```

Узгодження S-подібного набору швидкості `v(t)` з адаптивним вектором перехоплення `χ_cmd(t)` та вітровою поправкою `β_wind` гарантує, що апарат повертається на лінію маршруту без коливань, зберігаючи високу точність просторового слідування.
