# Робочий простір і сингулярності

<preknowlist>
- [Кінематика маніпулятора](root:sys-dron/kinematyka-manipuliatora) — пряма та обернена задачі кінематики, простір конфігурацій шарнірів.
- [Матриця Якобі](root:math-analysis/jacobian-matrix) — лінеаризація вектор-функції багатьох змінних, відображення дотичних просторів.
- [Група обертань SO(3)](root:math-algebra/lie-group-so3) — матриці повороту, простір просторових орієнтацій твердого тіла.
- [Сингулярність шарнірного підвісу (Gimbal Lock)](root:math-geometry/gimbal-lock) — виродження кутів Ейлера при збігу осей обертання.
</preknowlist>

Бортовий шестиланковий маніпулятор розвідувального дрона підлітає до технологічного вузла для захоплення рухомого карабіна або заміни датчика. Планувальник траєкторії бортового комп'ютера надсилає сервоприводам команду плавного декартового зміщення інструмента вперед зі швидкістю п'ять сантиметрів на секунду. Коли кінцевий ефектор проходить повз центральну вісь маніпулятора, четвертий і шостий приводи зап'ястка раптово намагаються розвинути кутову швидкість понад чотириста радіанів на секунду, споживаний струм сягає сорока амперів, польотний контролер реєструє аварійне перевантаження за струмом, і маніпулятор зазнає різкого динамічного удару, розхитуючи весь літальний апарат у повітрі. Рука натрапила на кінематичну сингулярність — точку простору конфігурацій, де геометрія зчленувань втрачає можливість створювати незалежні просторові рухи.

Безперешкодне просторове керування робочим органом можливе лише всередині чітко окресленого робочого простору та поза зонами сингулярностей. Геометрія робочого простору задає межі, де ефектор узагалі може опинитися і які просторові кути він здатен прийняти. Сингулярності ж визначають вироджені конфігурації, де зв'язок між швидкостями зчленувань і декартовим рухом втрачає повний ранг, перетворюючи звичайні алгоритми оберненої кінематики на джерело безконтрольних розбіжностей.

## Простір конфігурацій та декартів простір: межі фізичного руху

Математичний опис маніпулятора (від лат. *manipulus* — «жменя, ручна рукоять») будується на переході між двома принципово різними просторами координат:

1. **Простір конфігурацій шарнірів** (англ. *Joint Space*, або *Configuration Space*) `Q ⊆ ℝⁿ`: векторний простір внутрішніх змінних маніпулятора `q = [q₁, q₂, ..., qₙ]ᵀ`, де кожна координата `qᵢ` відповідає куту повороту обертального зчленування (англ. *revolute joint*) або лінійному висуванню призматичного зчленування (англ. *prismatic joint*). Оскільки для обертальних шарнірів кут визначається на колі `S¹`, топологічно простір конфігурацій шестиланкової руки є n-вимірним тором `Tⁿ = S¹ × S¹ × ... × S¹`.
2. **Декартів простір завдання** (англ. *Task Space*, або *Operational Space*) `SE(3) = ℝ³ × SO(3)`: простір положень і орієнтацій кінцевого ефектора (англ. *end-effector*) у тривимірному базисі відліку, що описується вектором координат `p = [x, y, z]ᵀ` та матрицею орієнтації `R ∈ SO(3)`.

Фізичні розміри ланок, взаємне розташування осей обертання та конструктивні обмеження приводів накладають на простір конфігурацій жорсткі нерівності. Жоден реальний шарнір не може обертатися на довільний кут без упирання в механічні упори або закручування кабельного джгута:

```
q_min,i ≤ qᵢ ≤ q_max,i      [діапазон допустимих кутів i-го шарніра]
```

Сукупність усіх можливих положень кінцевого ефектора у світових координатах, досяжних за умови виконання шарнірних обмежень `q ∈ Q`, утворює **робочий простір маніпулятора** (англ. *manipulator workspace*). Пряма кінематична функція `f_kin: Q → SE(3)` є нелінійною, неін'єктивною (багато конфігурацій `q` можуть відповідати одній точці в просторі) та несюр'єктивною (маніпулятор не може вийти за межі власного вильоту). Проте здатність маніпулятора лише торкнутися певної просторової точки ще не означає здатність виконати в ній технологічну операцію під потрібним кутом. Через це робочий простір поділяють на фундаментальні топологічні підмножини.

## Зона досяжності проти простору маневреності

Повна характеристика робочого простору вимагає роздільного аналізу позиційної досяжності та орієнтаційної свободи робочого органа.

![Структура робочого простору маніпулятора](/root/sys/sys-dron/robochyi-prostir-i-synhuliarnosti/img/reachability-vs-dexterity.svg)
*Геометричне співвідношення зони досяжності W_R та простору маневреності W_D. На зовнішній межі досяжності доступна лише одна фіксована орієнтація ефектора; у внутрішньому ядрі W_D можливе повне обертання SO(3).*

### Зона досяжності (Reachable Workspace)

**Зона досяжності** `W_R` (англ. *Reachable Workspace*, або *Maximal Workspace*) — це геометрична множина всіх точок декартового простору `p ∈ ℝ³`, яких точка кріплення інструмента може досягти **бодай в одній** орієнтації:

```
W_R = { p ∈ ℝ³ | ∃ q ∈ Q, ∃ R ∈ SO(3) : f_kin(q) = (p, R) }
```

Для простого плоского дволанкового маніпулятора з довжинами ланок `L₁` та `L₂` і повними кутами обертання шарнірів `[-π, π]` зона досяжності являє собою кругове кільце на площині. Зовнішній радіус кільця визначається повним випрямленням руки, а внутрішній — відстанню найближчого наближення:

```
R_max = L₁ + L₂             [максимальний виліт маніпулятора]
R_min = |L₁ − L₂|           [радіус внутрішньої мертвої зони]
```

Якщо довжини ланок рівні (`L₁ = L₂`), внутрішня порожнина стягується в точку, і маніпулятор може торкнутися власної основи. Проте на зовнішній межі `r = R_max` ланки вишиковуються в одну пряму лінію: ефектор може дивитися виключно радіально назовні. Спроба розвернути захоплювач перпендикулярно до лінії вильоту на самій межі вимагає складання ланок, що миттєво зменшує відстань від основи `r < R_max`.

### Простір маневреності (Dextrous Workspace)

**Простір маневреності** `W_D` (англ. *Dextrous Workspace*, від лат. *dexter* — «вправний, праворучний») — це множина точок простору `p ∈ ℝ³`, у яких кінцевий ефектор здатний зайняти **будь-яку довільну орієнтацію** з групи поворотів `SO(3)`:

```
W_D = { p ∈ ℝ³ | ∀ R ∈ SO(3), ∃ q ∈ Q : f_kin(q) = (p, R) }
```

Простір маневреності завжди є строгою внутрішньою підмножиною зони досяжності:

```
W_D ⊆ W_R                   [маневреність є підмножиною досяжності]
```

Для плоского маніпулятора довільна орієнтація означає здатність підійти до точки під будь-яким кутом підходу в межах трьохсот шістдесяти градусів. Щоб триланковий плоский маніпулятор з довжинами ланок `L₁`, `L₂`, `L₃` мав непорожній простір маневреності `W_D ≠ ∅`, довжини його ланок повинні задовольняти строгу геометричну нерівність трикутника:

```
L₁ + L₂ > L₃                [необхідна умова існування простору маневреності]
|L₁ − L₂| < L₃              [умова відсутності розриву внутрішнього кільця]
```

Радіус простору маневреності для такого маніпулятора обмежується значно вужчими межами, ніж зона максимального вильоту:

```
R_dextrous,max = L₁ + L₂ − L₃       [зовнішня межа маневреності]
R_dextrous,min = |L₁ − L₂| + L₃     [внутрішня межа маневреності]
```

Точки, розташовані між `R_dextrous,max` та `R_max`, утворюють **вторинний робочий простір** (англ. *Sub-dextrous Workspace*, або *Secondary Workspace*). У цих точках маніпулятор може функціонувати, але діапазон доступних орієнтацій кінцевого ефектора обмежений конусом із тілесним кутом `Ω < 4π sr`.

Міру орієнтаційної доступності в точці `p` кількісно виражають через інтегральний індекс маневреності:

```
D(p) = (1 / (8π²)) · ∫_{SO(3)} I_reach(p, R) dR
```

де `I_reach(p, R) = 1`, якщо орієнтація `R` досяжна в точці `p`, і `0` в іншому разі. Для точок всередині `W_D` індекс `D(p) = 1`, на межі робочого простору він падає до нуля.

> 🔧 **Навіщо це.** Під час планування польотних операцій дрона з маніпулятором координати цільового об'єкта під час зависання апарата завжди намагаються розмістити всередині простору маневреності `W_D`. Якщо об'єкт опиниться у вторинному робочому просторі біля самої межі `∂W_R`, захоплювач не зможе підлаштуватися під кут нахилу деталі без додаткового переміщення всього літального апарата в повітрі, що створює зайві аеродинамічні збурення.

## Диференціальна кінематика та природа сингулярностей

Зв'язок між просторовим положенням ефектора `x ∈ ℝ⁶` та суглобовими координатами `q ∈ ℝⁿ` описується нелінійною функцією прямої кінематики:

```
x = f_kin(q)                [пряма кінематична задача]
```

Диференціювання цього рівняння за часом встановлює лінійний зв'язок між миттєвими швидкостями в просторі зчленувань `q̇ ∈ ℝⁿ` та декартовим вектором просторової швидкості інструмента `v_e = [vᵀ, ωᵀ]ᵀ ∈ ℝ⁶` (де `v` — лінійна швидкість, а `ω` — кутова швидкість):

```
ẋ = (∂f_kin / ∂q) · q̇ = J(q) · q̇
```

Матриця часткових похідних `J(q) ∈ ℝ⁶ˣⁿ` називається **геометричним якобіаном** маніпулятора (на честь німецького математика Карла Густава Якобі, *Carl Gustav Jacobi*). Її `i`-й стовпчик `J_i(q)` показує внесок швидкості `q̇ᵢ` окремого `i`-го шарніра в сумарний поступальний та обертальний рух ефектора.

```
J(q) = [ J₁(q)   J₂(q)   ...   Jₙ(q) ]
```

Для обертального зчленування з одиничним вектором осі обертання `z_{i-1}` та радіус-вектором від початку шарніра до кінцевого ефектора `p_e - p_{i-1}` стовпчик Якобіана має вигляд:

```
J_i(q) = [ z_{i-1} × (p_e − p_{i-1}) ]    [лінійна швидкість від обертання]
         [          z_{i-1}          ]    [кутова швидкість навколо осі]
```

### Умова сингулярності

Конфігурація маніпулятора `q` називається **кінематичною сингулярністю** (від лат. *singularis* — «одиничний, особливий, відокремлений»), якщо матриця Якобі `J(q)` втрачає свій максимальний ранг:

```
rank(J(q)) < min(6, n)      [загальна умова кінематичної сингулярності]
```

Для маніпулятора без надлишкових ступенів вільності з шістьма шарнірами (`n = 6`) матриця Якобі є квадратною розміром `6 × 6`. У цьому випадку умова сингулярності еквівалентна перетворенню визначника матриці на нуль:

```
det(J(q)) = 0               [виродження квадратного Якобіана]
```

Геометрично втрата рангу означає, що лінійна оболонка стовпчиків Якобіана `Im(J(q))` (образ оператора) більше не покриває весь шестивимірний простір швидкостей `ℝ⁶`. Стовпчики Якобіана стають лінійно залежними.

Це породжує три фундаментальні наслідки для керування роботом:

1. **Втрата ступенів вільності руху:** У декартовому просторі виникає принаймні один напрямок `v_sing ∉ Im(J(q))`, вздовж якого кінцевий ефектор не може зміститися або розвернутися з ненульовою швидкістю за жодних, навіть як завгодно великих швидкостей приводів `q̇`.
2. **Розбіжність оберненої швидкості:** Класичний закон керування в швидкостях вимагає знаходження швидкостей шарнірів через обернену матрицю Якобі:
   ```
   q̇ = J⁻¹(q) · v_des
   ```
   За формулою крамерівського обернення `J⁻¹ = (1 / det(J)) · adj(J)`. Коли маніпулятор наближається до сингулярної конфігурації, визначник прямує до нуля `det(J(q)) → 0`. Якщо задана траєкторія має хоча б малу складову вздовж втраченого напрямку, елементи `J⁻¹` прямують до нескінченності:
   ```
   ||q̇|| → ∞   при   det(J) → 0
   ```
   Контролер формує колосальні завдання швидкості на сервоприводи, що спричиняє насичення двигунів за напругою, спрацьовування апаратних захистів за струмом і зрив стеження за траєкторією.
3. **Дуальність сил та нескінченна механічна жорсткість:** За принципом віртуальних робіт зв'язок між декартовою силою/моментом на ефекторі `F_ext ∈ ℝ⁶` та крутними моментами на валах шарнірів `τ ∈ ℝⁿ` визначається транспонованим Якобіаном. Елементарна робота сил у декартових координатах `δW = F_extᵀ · δx` дорівнює віртуальній роботі в суглобах `δW = τᵀ · δq`. Оскільки `δx = J · δq`, маємо:
   ```
   F_extᵀ · J · δq = τᵀ · δq
   (Jᵀ · F_ext − τ)ᵀ · δq = 0
   τ = Jᵀ(q) · F_ext         [статичний зв'язок зусиль і моментів]
   ```
   Якщо зовнішня сила прикладена вздовж напрямку сингулярності `v_sing` (який належить ядру транспонованого оператора `Ker(Jᵀ)`), результуючий вектор моментів дорівнює нулю `τ = 0`. Маніпулятор витримує нескінченно велике зовнішнє навантаження суто за рахунок жорсткості своєї механічної структури (ефект клина чи колони), не навантажуючи електродвигуни. Проте зворотно: щоб створити власну рушійну силу вздовж цього напрямку за допомогою приводів, знадобився б нескінченний крутний момент.

## Граничні та внутрішні сингулярності

Усі кінематичні сингулярності просторових маніпуляторів поділяються на два класи за місцем їх виникнення в робочому просторі: **граничні** та **внутрішні**.

![Типи кінематичних сингулярностей маніпулятора](/root/sys/sys-dron/robochyi-prostir-i-synhuliarnosti/img/singularity-types.svg)
*Геометрія виродження Якобіана. 1 — Гранична сингулярність (повне розгинання руки, втрата радіального руху). 2 — Сингулярність зап'ястка (вирівнювання осей z₄ та z₆). 3 — Плечова сингулярність (перетин зап'ястком осі обертання основи z₁).*

### Граничні сингулярності (Boundary Singularities)

**Граничні сингулярності** виникають на фізичних межах зони досяжності `∂W_R`:

* **Повне розгинання руки (максимальний виліт):** ліктьовий суглоб повністю випрямлений (`q_elbow = 0`), усі ланки вишикувані вздовж радіального променя від основи. Усі миттєві лінійні швидкості шарнірів `z_{i-1} × (p_e - p_{i-1})` виявляються перпендикулярними до лінії ланок. Радіальна складова швидкості тотожно дорівнює нулю `v_r = 0`. Рух назовні геометрично неможливий, а спроба відійти назад вимагає координованого згинання суглобів.
* **Повне складання маніпулятора (внутрішня межа):** ланки складаються впритул одна до одної (`q_elbow = 180°`), ефектор досягає межі внутрішньої мертвої порожнини `R_min = |L₁ - L₂|`.

Граничні сингулярності легко діагностуються та уникаються геометричним обмеженням робочої зони в планувальнику шляху (встановленням програмного ліміту вильоту `R_safe ≤ 0.95 · R_max`).

### Внутрішні сингулярності (Internal Singularities)

Набагато небезпечнішими є **внутрішні сингулярності**. Вони виникають усередині робочого простору далеко від його зовнішніх меж через специфічне взаємне розташування проміжних осей обертання. Для класичних антропоморфних шестиланкових маніпуляторів зі сферичним зап'ястком (де осі останніх трьох шарнірів 4, 5 і 6 перетинаються в одній точці — центрі зап'ястка `P_w`) виділяють три головні внутрішні сингулярності.

Завдяки розділенню кінематики маніпулятора зі сферичним зап'ястком на позиційну частину `J_pos` (перші три шарніри, що задають координати точки `P_w`) та орієнтаційну частину `J_ori` (зап'ясток), загальний визначник Якобіана факторизується на добуток аналітичних доданків:

```
det(J(q)) = a₂ · a₃ · sin(q₃) · sin(q₅) · (a₂ · cos(q₂) + a₃ · cos(q₂ + q₃))
```

де `a₂` та `a₃` — довжини плечової та ліктьової ланок. Кожен множник у цьому виразі породжує окремий геометричний тип сингулярності:

#### 1. Сингулярність зап'ястка (Wrist Singularity)

Виникає при перетворенні множника `sin(q₅) = 0` на нуль:

```
q₅ = 0°   або   q₅ = 180°   [умова сингулярності зап'ястка]
```

Коли кут п'ятого шарніра дорівнює нулю, вісь четвертого шарніра `z₄` (скручування передпліччя) та вісь шостого шарніра `z₆` (обертання фланця інструмента) вишиковуються вздовж однієї прямої лінії `z₄ || z₆`. Обидва шарніри здійснюють обертання навколо однієї й тієї самої просторової осі. Маніпулятор втрачає один ступінь свободи просторової орієнтації: миттєве обертання навколо осі, перпендикулярної до площини зап'ястка, стає неможливим.

Якщо керуюча програма вимагає плавного розвороту робочого органа навколо перпендикулярної осі під час проходження точки `q₅ = 0`, четвертий і шостий шарніри намагаються миттєво розвернутися на сто вісімдесят градусів у протилежних напрямках із нескінченною кутовою швидкістю `q̇₄ = -q̇₆ → ∞`. Це явище є точним кінематичним еквівалентом сингулярності карданового підвісу (англ. *Gimbal Lock*).

#### 2. Плечова / Колонна сингулярність (Shoulder / Column Singularity)

Виникає, коли множник вильоту зап'ястка в горизонтальній площині дорівнює нулю:

```
r_xy = a₂ · cos(q₂) + a₃ · cos(q₂ + q₃) = 0   [центр зап'ястка на осі z₁]
```

Це означає, що центр сферичного зап'ястка `P_w` потрапляє строго на вертикальну вісь обертання першого шарніра основи `z₁` (тобто координати на площині бази `x_w = 0, y_w = 0`).

У цій точці поворот першого шарніра `q₁` лише повертає зап'ясток навколо власної осі, не створюючи жодного лінійного зміщення в просторі. Якщо планувальник вимагає переміщення інструмента вбік по прямій лінії поперек поточної площини маніпулятора, перший шарнір основи повинен миттєво здійснити оберт на значний кут, щоб змінити площину руки:

```
q̇₁ → ∞   при   r_xy → 0
```

#### 3. Ліктьова сингулярність (Elbow Singularity)

Виникає при перетворенні на нуль множника ліктя `sin(q₃) = 0`:

```
q₃ = 0°   або   q₃ = 180°   [випрямлений або складений лікоть]
```

Центр зап'ястка `P_w` опиняється в одній лінії з плечовим і ліктьовим шарнірами. Уся рука втрачає можливість створювати лінійну швидкість вздовж напрямку плечової ланки, навіть якщо сам кінцевий ефектор перебуває всередині робочого об'єму завдяки нахилу зап'ястка.

Для безпілотного літального апарата виникнення внутрішніх сингулярностей несе подвійну небезпеку: розбіжність кутових швидкостей `q̇ᵢ → ∞` створює колосальний реактивний гіроскопічний і динамічний момент на корпус дрона `τ_react = d(I_arm · q̇)/dt`, який миттєво збиває кутову стабілізацію безпілотника за креном і тангажем.

## Еліпсоїд маніпулятивності та показник Йошікави

Для кількісної оцінки віддаленості поточної позиції маніпулятора від сингулярностей та вимірювання його маневреності в різних просторових напрямках японський робототехнік Цунео Йошікава (*Tsuneo Yoshikawa*) у 1985 році запропонував геометричну концепцію **еліпсоїда маніпулятивності** (англ. *Manipulability Ellipsoid*).

![Еліпсоїд маніпулятивності Йошікави](/root/sys/sys-dron/robochyi-prostir-i-synhuliarnosti/img/manipulability-ellipsoid.svg)
*Трансформація одиничної сфери шарнірних швидкостей в еліпсоїд декартових швидкостей та сил. У міру наближення до сингулярності мала піввісь σ₂ стягується до нуля, а дуальна вісь сили 1/σ₂ прямує до нескінченності.*

Розглянемо множину всіх допустимих суглобових швидкостей, обмежених одиничною гіперсферою у просторі конфігурацій:

```
||q̇||² = q̇ᵀ · q̇ ≤ 1         [одинична сфера швидкостей у просторі шарнірів]
```

Оскільки декартова швидкість пов'язана з шарнірною через Якобіан `v = J(q) · q̇`, для невиродженого випадку `q̇ = J⁺ · v` (де `J⁺` — псевдообернена матриця). Підстановка цього виразу в нерівність одиничної сфери дає рівняння гіпереліпсоїда в декартовому просторі швидкостей:

```
(J⁺ · v)ᵀ · (J⁺ · v) ≤ 1
vᵀ · (J⁺)ᵀ · J⁺ · v ≤ 1
vᵀ · (J · Jᵀ)⁻¹ · v ≤ 1     [рівняння еліпсоїда маніпулятивності швидкостей]
```

### Сингулярний розклад (SVD) Якобіана

Геометрія еліпсоїда розкривається через **сингулярний розклад** (англ. *Singular Value Decomposition*, *SVD*) матриці Якобі:

```
J(q) = U · Σ · Vᵀ
```

де:
* `U = [u₁, u₂, ..., u_m] ∈ ℝᵐˣᵐ` — ортогональна матриця лівих сингулярних векторів (задають просторову орієнтацію головних півосей еліпсоїда);
* `Σ = diag(σ₁, σ₂, ..., σ_m) ∈ ℝᵐˣⁿ` — діагональна матриця сингулярних чисел, упорядкованих за спаданням: `σ₁ ≥ σ₂ ≥ ... ≥ σ_m ≥ 0`;
* `V = [v₁, v₂, ..., v_n] ∈ ℝⁿˣⁿ` — ортогональна матриця правих сингулярних векторів у просторі шарнірів.

Головні півосі еліпсоїда маніпулятивності спрямовані вздовж векторів `uᵢ`, а довжина кожної півосі строго дорівнює відповідному сингулярному числу `σᵢ`:

```
довжина i-ї півосі = σᵢ = √(λᵢ(J · Jᵀ))
```

* Якщо всі сингулярні числа рівні між собою `σ₁ = σ₂ = ... = σ_m`, еліпсоїд перетворюється на ідеальну сферу. Маніпулятор має однакову здатність рухатися в усіх просторових напрямках — така конфігурація називається **ізотропною** (англ. *isotropic configuration*).
* Якщо маніпулятор наближається до сингулярності, найменше сингулярне число стягується до нуля `σ_min = σ_m → 0`. Еліпсоїд сплющується, перетворюючись на плоский диск або відрізок. Рух вздовж осі `u_m` стає неможливим.

### Кількісна міра маніпулятивності Йошікави

**Міра маніпулятивності Йошікави** (англ. *Yoshikawa Manipulability Measure*) `w(q)` визначається як корінь квадратний з визначника матриці Грама `J · Jᵀ`:

```
w(q) = √(det(J(q) · Jᵀ(q))) = σ₁ · σ₂ · ... · σ_m
```

Геометричний зміст показника `w(q)`: він прямо пропорційний гіпероб'єму еліпсоїда маніпулятивності.
* У сингулярній конфігурації об'єм еліпсоїда дорівнює нулю `w(q) = 0`.
* У центрі робочого простору при зручних кутах згину суглобів показник `w(q)` досягає максимуму.

Градієнт показника маніпулятивності за кутами шарнірів обчислюється через формулу Якобі для диференціювання визначника:

```
∂w / ∂qᵢ = (w / 2) · tr((J · Jᵀ)⁻¹ · (∂(J · Jᵀ) / ∂qᵢ))
```

Цей аналітичний градієнт використовується в алгоритмах локальної оптимізації пози маніпулятора в реальному часі.

### Число обумовленості (Condition Number)

Хоча міра Йошікави `w(q)` показує загальний запас швидкості, вона не відображає ступінь деформації еліпсоїда. Для оцінки спрямованої рівномірності використовують **число обумовленості** Якобіана:

```
κ(J) = ||J|| · ||J⁺|| = σ_max / σ_min ≥ 1
```

* `κ(J) = 1`: ідеальна ізотропія (сферичний еліпсоїд).
* `κ(J) → ∞`: гранична сингулярність (нескінченна анізотропія руху).

### Дуальний еліпсоїд зусиль (Force Ellipsoid)

Якщо розглянути одиничну сферу доступних моментів двигунів `||τ||² = τᵀ · τ ≤ 1`, то за статичним рівнянням `τ = Jᵀ · F` допустимі декартові сили на ефекторі описуються **еліпсоїдом зусиль**:

```
(Jᵀ · F)ᵀ · (Jᵀ · F) ≤ 1
Fᵀ · (J · Jᵀ) · F ≤ 1       [рівняння еліпсоїда зусиль]
```

Півосі еліпсоїда зусиль спрямовані вздовж тих самих сингулярних векторів `uᵢ`, проте їхні довжини обернено пропорційні сингулярним числам:

```
довжина сили i-ї осі = 1 / σᵢ
```

Це доводить фундаментальну дуальність швидкостей і сил: напрямок, у якому маніпулятор найменш маневрений за швидкістю (`σ_min → 0`), є напрямком, де він здатен розвивати або витримувати колосальні механічні сили без навантаження на електродвигуни.

## Алгоритми обходу та демпфування сингулярностей

Пряме застосування класичної псевдоінверсії Мура-Пенроуза (англ. *Moore-Penrose Pseudoinverse*) `J⁺ = Jᵀ (J Jᵀ)⁻¹` у контурі числової оберненої кінематики біля сингулярності призводить до чисельної катастрофи.

У сингулярному базисі SVD розв'язок швидкостей розкладається на ряд:

```
q̇ = ∑_{i=1}^m ( (uᵢᵀ · v_des) / σᵢ ) · vᵢ
```

Коли `σ_m → 0`, дріб `1 / σ_m` прямує до нескінченності. Навіть мікроскопічна похибка дискретизації або шуми датчиків генерують нескінченні швидкості шарнірів.

![Порівняння псевдоінверсії та методу DLS біля сингулярності](/root/sys/sys-dron/robochyi-prostir-i-synhuliarnosti/img/damped-least-squares.svg)
*Поведінка швидкості шарнірів q̇ під час проходження сингулярності. Стандартна псевдоінверсія призводить до гіперболічного стрибка швидкості (аварія приводів), тоді як DLS обмежує швидкість за рахунок контрольованого короткочасного відхилення траєкторії.*

### Метод демпфованих найменших квадратів (DLS)

Щоб усунути розбіжність, застосовують **метод демпфованих найменших квадратів** (англ. *Damped Least Squares*, *DLS*, також відомий як регуляризація Левенберга-Марквардта). Замість строгого розв'язання рівняння `J q̇ = v_des` алгоритм мінімізує зважений квадратичний функціонал втрат, який одночасно карає як похибку відстеження траєкторії, так і надмірну величину швидкості шарнірів:

```
min_{q̇} ( ||J(q) · q̇ − v_des||² + λ² · ||q̇||² )
```

де `λ > 0` — коефіцієнт демпфування (регуляризації).

Диференціювання функціоналу за вектором `q̇` та прирівнювання градієнта до нуля дає аналітичний розв'язок:

```
q̇ = Jᵀ · (J · Jᵀ + λ² · I)⁻¹ · v_des = J_DLS⁺ · v_des
```

У сингулярному базисі SVD кожний гармонійний коефіцієнт швидкості набуває регуляризованого вигляду:

```
коефіцієнт_i = σᵢ / (σᵢ² + λ²)
```

* Коли `σᵢ ≫ λ` (далеко від сингулярності), дріб `σᵢ / (σᵢ² + λ²) ≈ 1 / σᵢ` — алгоритм працює як точна псевдоінверсія без спотворення траєкторії.
* Коли `σᵢ → 0` (всередині сингулярності), дріб `σᵢ / (σᵢ² + λ²) → 0 / λ² = 0` — замість розбіжності до нескінченності швидкість шарнірів плавно зануляється вздовж сингулярного напрямку!

Максимальне можливе значення коефіцієнта досягається при `σᵢ = λ` і дорівнює `1 / (2λ)`. Це гарантує строгу верхню межу швидкості будь-якого суглоба маніпулятора:

```
||q̇||_max ≤ ||v_des|| / (2λ)
```

Похибка відстеження швидкості ефектора при застосуванні DLS має точний вираз:

```
e_v = v_des − J · q̇ = λ² · (J · Jᵀ + λ² · I)⁻¹ · v_des
```

Ця похибка виникає строго вздовж сингулярної осі `u_m`, дозволяючи роботові плавно прослизнути повз сингулярну точку з мінімальним зсувом без перевищення допустимого струму приводів.

### Адаптивний коефіцієнт демпфування Накамури-Ханафуси

Постійний коефіцієнт `λ` викликає паразитне відхилення від траєкторії навіть тоді, коли маніпулятор перебуває далеко від сингулярностей. Тому застосовують адаптивне демпфування (схема Накамури-Ханафуси та Вамплера), де величина `λ` автоматично регулюється за поточною мірою маніпулятивності Йошікави `w(q)`:

```
λ²(w) = 0                                   [якщо w(q) ≥ w₀ — далеко від сингулярності]
λ²(w) = λ_max² · (1 − (w(q) / w₀))²          [якщо w(q) < w₀ — зона згладжування]
```

де `w₀` — граничний поріг активації захисту, а `λ_max` — максимальний коефіцієнт демпфування.

### Проекція в нуль-простір для надлишкових маніпуляторів

Якщо маніпулятор має більше шести ступенів вільності (`n > 6`, наприклад, семиланкова антропоморфна рука), він володіє кінематичною надлишковістю (англ. *kinematic redundancy*). Розмірність ядра оператора Якобі `Ker(J)` становить `n - 6 > 0`.

Усі рухи в просторі шарнірів, що проектуються оператором `(I - J⁺ J)` у нуль-простір (англ. *null-space*), змінюють конфігурацію ліктя чи плеча, але не створюють жодного руху кінцевого ефектора. Це дає змогу додати вторинне завдання — автоматичну максимізацію міри маніпулятивності `w(q)`:

```
q̇ = J_DLS⁺ · v_des + (I − J⁺ · J) · (k_w · ∇_q w(q))
```

де `∇_q w(q)` — градієнт міри Йошікави за кутами суглобів, а `k_w > 0` — коефіцієнт підтягування. Під час руху вздовж основної декартової траєкторії маніпулятор самостійно відводить внутрішні зчленування геть від сингулярних орієнтацій.

## Програмна реалізація: виявлення та регуляризація на C та C++

Наведена нижче бібліотека реалізує швидкий та стійкий до сингулярностей розв'язувач оберненої швидкості маніпулятора методом демпфованих найменших квадратів (DLS) з адаптивним підбором коефіцієнта регуляризації та захистом від перевантаження за кутовою швидкістю.

:::tabs
```c
#include <math.h>
#include <stdbool.h>
#include <stddef.h>

#define DOF 6
#define CARTESIAN_DIM 6

typedef struct {
    double q[DOF];             /* Кути шарнірів (рад) */
} JointState;

typedef struct {
    double v[3];               /* Лінійна швидкість (м/с) */
    double omega[3];           /* Кутова швидкість (рад/с) */
} Twist;

typedef struct {
    double lambda_max;         /* Максимальний коефіцієнт демпфування */
    double w_threshold;        /* Поріг маніпулятивності активації DLS */
    double max_joint_vel;      /* Гранична швидкість приводу (рад/с) */
} DlsConfig;

/* Обчислення добутку A * B для квадратних матриць 6x6 */
static void mat_mul6(const double a[6][6], const double b[6][6], double out[6][6]) {
    for (int r = 0; r < 6; ++r) {
        for (int c = 0; c < 6; ++c) {
            double sum = 0.0;
            for (int k = 0; k < 6; ++k) {
                sum += a[r][k] * b[k][c];
            }
            out[r][c] = sum;
        }
    }
}

/* Обчислення матриці Грама G = J * J^T (розмір 6x6) */
static void compute_gram_matrix(const double J[6][6], double G[6][6]) {
    for (int r = 0; r < 6; ++r) {
        for (int c = 0; c < 6; ++c) {
            double sum = 0.0;
            for (int k = 0; k < 6; ++k) {
                sum += J[r][k] * J[c][k];
            }
            G[r][c] = sum;
        }
    }
}

/* Обернення матриці 6x6 методом Гауса-Жордана з частковим вибором головного елемента */
static bool invert_matrix6(const double in[6][6], double inv[6][6], double *det_out) {
    double aug[6][12];
    for (int r = 0; r < 6; ++r) {
        for (int c = 0; c < 6; ++c) {
            aug[r][c] = in[r][c];
            aug[r][c + 6] = (r == c) ? 1.0 : 0.0;
        }
    }

    double det = 1.0;

    for (int i = 0; i < 6; ++i) {
        int pivot = i;
        double max_val = fabs(aug[i][i]);
        for (int r = i + 1; r < 6; ++r) {
            double val = fabs(aug[r][i]);
            if (val > max_val) {
                max_val = val;
                pivot = r;
            }
        }

        if (max_val < 1e-12) {
            if (det_out) *det_out = 0.0;
            return false; /* Матриця вироджена */
        }

        if (pivot != i) {
            for (int c = 0; c < 12; ++c) {
                double tmp = aug[i][c];
                aug[i][c] = aug[pivot][c];
                aug[pivot][c] = tmp;
            }
            det = -det;
        }

        double diag = aug[i][i];
        det *= diag;

        for (int c = 0; c < 12; ++c) {
            aug[i][c] /= diag;
        }

        for (int r = 0; r < 6; ++r) {
            if (r != i) {
                double factor = aug[r][i];
                for (int c = 0; c < 12; ++c) {
                    aug[r][c] -= factor * aug[i][c];
                }
            }
        }
    }

    if (det_out) *det_out = det;

    for (int r = 0; r < 6; ++r) {
        for (int c = 0; c < 6; ++c) {
            inv[r][c] = aug[r][c + 6];
        }
    }
    return true;
}

/* Оцінка показника маніпулятивності Йошікави w = sqrt(det(J * J^T)) */
double compute_yoshikawa_manipulability(const double J[6][6]) {
    double G[6][6];
    compute_gram_matrix(J, G);

    double invG[6][6];
    double det_G = 0.0;
    if (!invert_matrix6(G, invG, &det_G) || det_G <= 0.0) {
        return 0.0;
    }
    return sqrt(det_G);
}

/* Розв'язання оберненої швидкості методом адаптивного DLS */
bool solve_ik_dls(const double J[6][6], const Twist *twist,
                  const DlsConfig *cfg, double qdot_out[DOF], double *manipulability) {
    if (!twist || !cfg || !qdot_out) return false;

    double G[6][6];
    compute_gram_matrix(J, G);

    /* Обчислення маніпулятивності */
    double invG_dummy[6][6];
    double det_G = 0.0;
    invert_matrix6(G, invG_dummy, &det_G);
    double w = (det_G > 0.0) ? sqrt(det_G) : 0.0;
    if (manipulability) *manipulability = w;

    /* Розрахунок адаптивного демпфування lambda^2 */
    double lambda_sq = 0.0;
    if (w < cfg->w_threshold) {
        double ratio = 1.0 - (w / cfg->w_threshold);
        lambda_sq = cfg->lambda_max * cfg->lambda_max * ratio * ratio;
    }

    /* Додавання регуляризації: G_damped = J * J^T + lambda^2 * I */
    for (int i = 0; i < 6; ++i) {
        G[i][i] += lambda_sq;
    }

    /* Обернення регуляризованої матриці */
    double G_inv[6][6];
    double det_damped = 0.0;
    if (!invert_matrix6(G, G_inv, &det_damped)) {
        return false;
    }

    /* Вектор декартової швидкості x_dot */
    double x_dot[6] = {
        twist->v[0], twist->v[1], twist->v[2],
        twist->omega[0], twist->omega[1], twist->omega[2]
    };

    /* v_temp = G_inv * x_dot */
    double v_temp[6];
    for (int r = 0; r < 6; ++r) {
        double sum = 0.0;
        for (int c = 0; c < 6; ++c) {
            sum += G_inv[r][c] * x_dot[c];
        }
        v_temp[r] = sum;
    }

    /* q_dot = J^T * v_temp */
    double max_qdot = 0.0;
    for (int j = 0; j < DOF; ++j) {
        double sum = 0.0;
        for (int r = 0; r < 6; ++r) {
            sum += J[r][j] * v_temp[r];
        }
        qdot_out[j] = sum;
        if (fabs(sum) > max_qdot) {
            max_qdot = fabs(sum);
        }
    }

    /* Масштабування швидкостей у разі перевищення ліміту приводів */
    if (max_qdot > cfg->max_joint_vel && max_qdot > 1e-6) {
        double scale = cfg->max_joint_vel / max_qdot;
        for (int j = 0; j < DOF; ++j) {
            qdot_out[j] *= scale;
        }
    }

    return true;
}
```

```cpp
#include <array>
#include <cmath>
#include <optional>
#include <span>
#include <algorithm>

namespace drone::robotics {

constexpr std::size_t kDof = 6;
constexpr std::size_t kCartesianDim = 6;

using Matrix6d = std::array<std::array<double, kDof>, kCartesianDim>;
using Vector6d = std::array<double, kDof>;

struct Twist {
    std::array<double, 3> linear{};   // Швидкість поступального руху (м/с)
    std::array<double, 3> angular{};  // Кутова швидкість (рад/с)
};

struct DlsSettings {
    double lambda_max{0.3};           // Максимальний коефіцієнт демпфування
    double w_threshold{0.05};         // Поріг маніпулятивності Йошікави
    double max_joint_vel{5.0};        // Максимальна кутова швидкість суглоба (рад/с)
};

class SingularityRobustSolver {
public:
    explicit constexpr SingularityRobustSolver(DlsSettings settings = {})
        : settings_{settings} {}

    [[nodiscard]] static double computeManipulability(const Matrix6d& jacobian) noexcept {
        const auto gram = computeGram(jacobian);
        const auto det = computeDeterminant6x6(gram);
        return (det > 0.0) ? std::sqrt(det) : 0.0;
    }

    [[nodiscard]] std::optional<Vector6d> solveVelocityIk(
        const Matrix6d& jacobian,
        const Twist& target_twist) const noexcept {

        auto gram = computeGram(jacobian);
        const double w = computeManipulability(jacobian);

        // Адаптивне квадратичне демпфування
        double lambda_sq = 0.0;
        if (w < settings_.w_threshold) {
            const double ratio = 1.0 - (w / settings_.w_threshold);
            lambda_sq = settings_.lambda_max * settings_.lambda_max * ratio * ratio;
        }

        // Регуляризація діагоналі G + lambda^2 * I
        for (std::size_t i = 0; i < kCartesianDim; ++i) {
            gram[i][i] += lambda_sq;
        }

        const auto gram_inv = invertMatrix6x6(gram);
        if (!gram_inv) {
            return std::nullopt;
        }

        const std::array<double, kCartesianDim> x_dot{
            target_twist.linear[0],  target_twist.linear[1],  target_twist.linear[2],
            target_twist.angular[0], target_twist.angular[1], target_twist.angular[2]
        };

        // v_temp = (J * J^T + lambda^2 * I)^(-1) * x_dot
        std::array<double, kCartesianDim> v_temp{};
        for (std::size_t r = 0; r < kCartesianDim; ++r) {
            for (std::size_t c = 0; c < kCartesianDim; ++c) {
                v_temp[r] += (*gram_inv)[r][c] * x_dot[c];
            }
        }

        // q_dot = J^T * v_temp
        Vector6d q_dot{};
        double max_vel = 0.0;
        for (std::size_t j = 0; j < kDof; ++j) {
            for (std::size_t r = 0; r < kCartesianDim; ++r) {
                q_dot[j] += jacobian[r][j] * v_temp[r];
            }
            max_vel = std::max(max_vel, std::abs(q_dot[j]));
        }

        // Пропорційне насичення швидкостей суглобів
        if (max_vel > settings_.max_joint_vel && max_vel > 1e-6) {
            const double scale = settings_.max_joint_vel / max_vel;
            for (auto& vel : q_dot) {
                vel *= scale;
            }
        }

        return q_dot;
    }

private:
    DlsSettings settings_;

    [[nodiscard]] static Matrix6d computeGram(const Matrix6d& j) noexcept {
        Matrix6d g{};
        for (std::size_t r = 0; r < kCartesianDim; ++r) {
            for (std::size_t c = 0; c < kCartesianDim; ++c) {
                double sum = 0.0;
                for (std::size_t k = 0; k < kDof; ++k) {
                    sum += j[r][k] * j[c][k];
                }
                g[r][c] = sum;
            }
        }
        return g;
    }

    [[nodiscard]] static double computeDeterminant6x6(Matrix6d mat) noexcept {
        double det = 1.0;
        for (std::size_t i = 0; i < kCartesianDim; ++i) {
            std::size_t pivot = i;
            double max_val = std::abs(mat[i][i]);
            for (std::size_t r = i + 1; r < kCartesianDim; ++r) {
                if (const double val = std::abs(mat[r][i]); val > max_val) {
                    max_val = val;
                    pivot = r;
                }
            }

            if (max_val < 1e-12) return 0.0;

            if (pivot != i) {
                std::swap(mat[i], mat[pivot]);
                det = -det;
            }

            const double diag = mat[i][i];
            det *= diag;

            for (std::size_t r = i + 1; r < kCartesianDim; ++r) {
                const double factor = mat[r][i] / diag;
                for (std::size_t c = i; c < kCartesianDim; ++c) {
                    mat[r][c] -= factor * mat[i][c];
                }
            }
        }
        return det;
    }

    [[nodiscard]] static std::optional<Matrix6d> invertMatrix6x6(const Matrix6d& in) noexcept {
        std::array<std::array<double, 12>, 6> aug{};
        for (std::size_t r = 0; r < 6; ++r) {
            for (std::size_t c = 0; c < 6; ++c) {
                aug[r][c] = in[r][c];
                aug[r][c + 6] = (r == c) ? 1.0 : 0.0;
            }
        }

        for (std::size_t i = 0; i < 6; ++i) {
            std::size_t pivot = i;
            double max_val = std::abs(aug[i][i]);
            for (std::size_t r = i + 1; r < 6; ++r) {
                if (const double val = std::abs(aug[r][i]); val > max_val) {
                    max_val = val;
                    pivot = r;
                }
            }

            if (max_val < 1e-12) return std::nullopt;

            if (pivot != i) {
                std::swap(aug[i], aug[pivot]);
            }

            const double diag = aug[i][i];
            for (std::size_t c = 0; c < 12; ++c) {
                aug[i][c] /= diag;
            }

            for (std::size_t r = 0; r < 6; ++r) {
                if (r != i) {
                    const double factor = aug[r][i];
                    for (std::size_t c = 0; c < 12; ++c) {
                        aug[r][c] -= factor * aug[i][c];
                    }
                }
            }
        }

        Matrix6d inv{};
        for (std::size_t r = 0; r < 6; ++r) {
            for (std::size_t c = 0; c < 6; ++c) {
                inv[r][c] = aug[r][c + 6];
            }
        }
        return inv;
    }
};

} // namespace drone::robotics
```
