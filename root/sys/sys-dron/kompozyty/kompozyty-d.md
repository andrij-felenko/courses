> 🔧 **Навіщо це.** Силовий каркас безпілотного апарата — від швидкісного FPV-дрона до дальнього розвідувального літака з розмахом крила 4 метри — проектується в умовах суперечливих вимог: максимальна жорсткість на вигин і кручення для стабільності контурів регулювання кутових швидкостей (PID), мінімальна польотна маса, радіопрозорість для антен зв'язку і телеметрії, електроізоляція силових кіл з напругою до 50 В та здатність поглинати енергію ударів без вибухового руйнування конструкції. Розуміння мікромеханіки передачі напружень між волокном і полімерною матрицею, законів анізотропії шаруватих ламінатів, електрофізичних властивостей вуглепластику та деформаційної поведінки склопластику дозволяє обрати оптимальну схему армування, запобігти прихованому розшаруванню рами та розрахувати коефіцієнт запасу міцності балки під екстремальними навантаженнями.

### Мікромеханіка композитів: взаємодія волокна і матриці

Композиційним матеріалом *(лат. compositus — складений)* називають штучно створену неоднорідну суцільну систему, що складається з двох або більше фаз із чіткою міжфазною межею розділу: високоміцного армувального наповнювача (волокон) та зв'язувальної основи (матриці).

Жоден із компонентів окремо не володіє необхідним комплексом експлуатаційних властивостей. Тонкі вуглецеві або скляні волокна діаметром 5–15 мкм мають колосальну міцність на одновісний розтяг (від 3000 до 5500 МПа), однак не здатні сприймати згинальні зусилля, стиск чи зсув: без бічної підтримки гнучка нитка миттєво втрачає стійкість за механізмом ейлерового поздовжнього згину при мізерних стискальних напруженнях у кілька мегапаскалів. Навпаки, полімерна термореактивна матриця (епоксидна смола на основі дигліцидилового етеру бісфенолу A) має низьку міцність на розтяг (50–90 МПа) та скромний модуль пружності (3.0–4.5 ГПа), але володіє ізотропною просторовою формостійкістю, захищає волокна від абразивного стирання і проникнення вологи та фіксує їхнє положення у просторі.

![Мікроструктура волокно–матриця та розподіл напружень](/root/sys/sys-dron/kompozyty/img/composite-load-transfer.svg)
*Мікроструктура композиту: навантаження передається від полімерної матриці до волокна через дотичні напруження зсуву τ_i на міжфазній межі. Напруження у волокні досягає максимуму на критичній довжині l_c.*

#### Механізм передачі напружень (модель Кокса)

Коли до композитного зразка прикладається зовнішнє розтягувальне зусилля, деформація матриці передається волокнам через дотичні напруження зсуву `τ_i` *(грец. tau)*, що виникають на контактній поверхні «волокно–епоксид». Цей процес описується моделлю зсувного запізнення (англ. *shear-lag model* Кокса).

Нехай волокно круглого перерізу діаметром `d` та довжиною `l` оточене пружною матрицею. Рівновага елемента волокна довжиною `dx` записується через баланс нормальної сили розтягу `dF = (π · d² / 4) · dσ_f` та сили тертя зсуву на бічній поверхні `dF_s = π · d · τ_i · dx`:

```
dσ_f / dx
= (4 · τ_i) / d      [баланс диференціальних сил на елементі волокна]
```

На торці обірваного або дискретного волокна (`x = 0`) нормальне напруження дорівнює нулю (`σ_f(0) = 0`), тоді як дотичні напруження зсуву в смолі `τ_i` набувають максимального значення. У міру віддалення від кінця волокна дотичні напруження спадають, а розтягувальне напруження `σ_f(x)` монотонно зростає. 

Відстань від торця, на якій розтягувальне напруження у волокні досягає своєї теоретичної межі міцності `σ_f^*`, визначає **критичну довжину передачі напружень** `l_c`:

```
l_c
= (σ_f^* · d) / (2 · τ_c)      [критична довжина волокна за межею міцності зсуву матриці τ_c]
```

Якщо довжина волокна `l < l_c`, волокно не встигає повністю навантажитися до своєї несучої здатності: при досягненні граничного зсуву матриці або межі адгезії волокно просто висмикується з полімеру (англ. *fiber pull-out*). Якщо ж `l >> l_c` (що характерно для неперервних волокон у препрегах, де `l / d > 10000`), переважна частина довжини нитки працює при максимальних напруженнях `σ_f^*`, забезпечуючи граничну реалізацію міцності армувального каркаса.

#### Об'ємна частка та правило сумішей Фойгта–Ройсса

Механічні константи композитного моношару визначаються відносним вмістом компонентів. Головним параметром виступає об'ємна частка волокон `V_f` *(лат. volumen — об'єм)*:

```
V_f = Vol_fiber / (Vol_fiber + Vol_matrix)
```

У виробах, виготовлених методом ручного формування (англ. *hand lay-up*), об'ємна частка волокон зазвичай не перевищує `V_f ≈ 0.35–0.45` через високий вміст залишкової смоли та мікропор. Вакуумна інфузія (англ. *vacuum-assisted resin infusion*) дозволяє підняти `V_f` до `0.50–0.58`. Автоклавне формування препрегів під тиском 6–8 бар при підвищеній температурі забезпечує `V_f ≈ 0.60–0.68` при мінімальній пористості (менше 0.5%).

Для односпрямованого моношару поздовжній модуль пружності `E_1` (вздовж осі волокон) розраховується за ізодеформаційною гіпотезою Фойгта (однакова поздовжня деформація волокна й матриці `ε_1 = ε_f = ε_m`):

```
E_1
= V_f · E_f + (1 - V_f) · E_m      [поздовжній модуль пружності за правилом Фойгта]
```

Оскільки модуль пружності вуглецевого волокна `E_f ≈ 230–400 ГПа` на два порядки перевищує модуль епоксидної смоли `E_m ≈ 3.5 ГПа`, поздовжня жорсткість на 98% визначається волокнами: при `V_f = 0.6` поздовжній модуль становить `E_1 = 0.6 · 230 + 0.4 · 3.5 = 138.0 + 1.4 = 139.4 ГПа`.

У поперечному напрямку (перпендикулярно до волокон) діє ізостресова гіпотеза Ройсса (волокно і матриця зазнають однакового нормального напруження `σ_2 = σ_f = σ_m`):

```
1 / E_2
= V_f / E_f + (1 - V_f) / E_m      [поперечна податливість за правилом Ройсса]
```

Перетворюючи вираз відносно поперечного модуля Юнга `E_2`:

```
E_2
= (E_f · E_m) / (V_f · E_m + (1 - V_f) · E_f)      [поперечний модуль пружності]
```

Підставляючи ті самі значення:

```
E_2
= (230 · 3.5) / (0.6 · 3.5 + 0.4 · 230)      [підстановка параметрів волокна та смоли]
= 805 / (2.1 + 92.0)                          [обчислення добутків у знаменнику]
= 805 / 94.1                                  [додавання членів знаменника]
≈ 8.55 ГПа                                    [ділення: поперечний модуль пружності]
```

Співвідношення поздовжнього та поперечного модулів `E_1 / E_2 = 139.4 / 8.55 ≈ 16.3` наочно демонструє крайній ступінь природної механічної анізотропії односпрямованого моношару.

Аналогічно, модуль зсуву в площині шару `G_12` та головний коефіцієнт Пуассона `ν_12` обчислюються як:

```
G_12
= (G_f · G_m) / (V_f · G_m + (1 - V_f) · G_f)      [модуль зсуву в площині моношару]
```

```
ν_12
= V_f · ν_f + (1 - V_f) · ν_m                      [поздовжній коефіцієнт Пуассона]
```

### Вуглепластик (CFRP): анізотропія, структура плетіння та квазіізотропні шари

Вуглепластик (англ. *Carbon Fiber Reinforced Polymer*, CFRP) базується на волокнах, сформованих із піролізованого поліакрилонітрилу (ПАН) або нафтових пеків. При термічній обробці за температур 1500–2800 °C атоми вуглецю утворюють витягнуті вздовж осі нитки гексагональні графітоподібні площини з міцними ковалентними зв'язками `sp²`-гібридизації (міжатомна відстань 0.142 нм). Між паралельними площинами діють слабкі сили Ван-дер-Ваальса (відстань 0.335 нм).

Завдяки орієнтації міцних ковалентних зв'язків строго вздовж осі волокна вуглепластик має унікальне поєднання високого модуля Юнга (`230–600 ГПа`) та низької густини (`ρ ≈ 1.50–1.80 г/см³`).

![Форми армування та квазіізотропний ламінат](/root/sys/sys-dron/kompozyty/img/carbon-fiber-layup.svg)

#### Питома жорсткість і питома міцність

В авіаційних конструкціях визначальними критеріями є питома міцність `σ_u / ρ` *(відношення міцності до густини)* та питома жорсткість `E / ρ`.

|---|---|---|---|---|---|
| Конструкційна сталь 40Х | 7.85 | 210 | 980 | 26.7 | 125 |
| Дюралюміній Д16Т (2024-T4) | 2.78 | 72 | 450 | 25.9 | 162 |
| Алюмінієвий сплав 7075-T6 | 2.81 | 71 | 570 | 25.3 | 203 |
| Титановий сплав ВТ6 (Ti-6Al-4V) | 4.43 | 114 | 950 | 25.7 | 214 |
| Вуглепластик UD CFRP (Toray T700) | 1.55 | 135 | 2100 | **87.1** | **1355** |
| Високомодульний CFRP (Toray M40J) | 1.60 | 230 | 2400 | **143.8** | **1500** |

З таблиці чітко видно фундаментальний закон вагового проектування: всі метали (сталь, алюміній, титан) мають практично однакову питому жорсткість `E / ρ ≈ 25–27 МДж/кг`. Заміна алюмінієвої балки на титанову не дає виграшу в масі при збереженні однакової жорсткості на вигин. Вуглепластик стандартного модуля перевершує будь-який метал за питомою жорсткістю у 3.3–3.5 раза, а за питомою міцністю — у 6–8 разів.

#### Текстильні форми: філаменти, плетіння 3K та тканини

Вуглецеві волокна випускаються у вигляді джгутів (ровингів), маркування яких позначає кількість елементарних ниток у тисячах:
- **1K** — 1 000 філаментів (надтонкі легкі тканини з поверхневою густиною 50–100 г/м²);
- **3K** — 3 000 філаментів (основний стандарт для рам дронів, поверхнева густина тканини 160–240 г/м²);
- **6K / 12K** — 6 000 / 12 000 філаментів (товсті джгути для силових лонжеронів великих БПЛА та автоклавних препрегів).

Джгути переплітають у тканини трьох основних типів:
1. **Полотняне плетіння (Plain weave 1x1):** нитки основи та піткання перетинаються через одну. Тканина має максимальну формостійкість і стабільність кромок при різанні, але високий вигин волокон на перетинах (англ. *crimp*) знижує граничну міцність ламінату на розтяг на 10–15% порівняно з прямим волокном.
2. **Саржеве плетіння (Twill weave 2x2):** нитка основи проходить над двома нитками піткання, а потім під двома зі зсувом на один крок, формуючи характерний діагональний малюнок. Менший вигин волокон знижує концентрацію напружень, а тканина має високу драпованість (здатність без зморшок облягати криволінійні форми обтічників і крил).
3. **Атласне / сатинове плетіння (Satin 4H / 8H):** джгут перекриває від 3 до 7 зустрічних ниток, забезпечуючи мінімальний crimp і максимальні механічні характеристики наближені до односпрямованих стрічок.

#### Ламінати та квазіізотропний пакет укладки

Оскільки односпрямований моношар має мізерну міцність у поперечному напрямку (`E_2 ≈ 8–9 ГПа`, `Y_t ≈ 40–60 МПа`), монолітні деталі формують із шаруватого пакета (ламінату), чергуючи шари під різними кутами `θ` *(грец. theta)*.

У класичній теорії ламінатів (CLT) зв'язок між узагальненими силами (нормальними зусиллями `N` та згинальними моментами `M`) та деформаціями серединної площини `ε⁰` і кривизнами `κ` описується матрицею `ABD`:

```
[ N ]   [ A   B ]   [ ε⁰ ]
[   ] = [       ] · [    ]      [матричне рівняння ламінату CLT]
[ M ]   [ B   D ]   [ κ  ]
```

де:
- `A` — матриця мембранної жорсткості на розтяг/стиск та зсув;
- `B` — матриця пружного зв'язку розтягу–вигину;
- `D` — матриця згинальної жорсткості.

Якщо пакет укладки є **несиметричним** відносно серединної площини пластини (наприклад, `[0° / 90°]`), компоненти матриці `B` стають ненульовими (`B_ij ≠ 0`). При охолодженні деталі після полімеризації в печі різниця коефіцієнтів термічного розширення шарів вздовж і поперек волокон генерує внутрішні згинальні моменти, внаслідок чого деталь неконтрольовано вигинається (коробиться) гвинтом або сферою.

Щоб гарантувати `B_ij = 0`, ламінат проектують строго **симетричним** відносно серединної площини (позначається індексом `s`).

Для деталей, що сприймають навантаження з довільних напрямків (наприклад, центральні пластини рами коптера, вузли кріплення підвісу камери), застосовують **квазіізотропну укладку** *(грец. isos — однаковий, tropos — напрямок)*:

```
[ 0° / +45° / -45° / 90° ]_s
```

Такий 8-шаровий симетричний пакет володіє однаковим ефективним модулем пружності `E_x = E_y ≈ 50–55 ГПа` та модулем зсуву `G_xy ≈ 20 ГПа` в будь-якому напрямку в площині пластини.

Для круглих трубчастих променів квадрокоптерів, де головними факторами є вигин від тяги мотора та кручення від реактивного моменту пропелера, використовують спеціалізовані пакети: 50–60% шарів укладають під кутом `0°` (поздовжній вигин), а 40–50% — під кутами `±45°` (жорсткість на кручення та запобігання крутильному флатеру).

### Електрофізика та радіовластивості вуглепластику

Вуглецеві волокна є напівпровідниками з вираженою електричною провідністю. Питомий об'ємний електричний опір вуглепластику вздовж осі волокна становить `ρ_e ≈ 1.5·10⁻⁵...5.0·10⁻⁵ Ом·м`, а в поперечному напрямку (через випадкові контакти між сусідніми філаментами в матриці) — `10⁻²...10⁻¹ Ом·м`.

Ця особливість докорінно відрізняє карбон від склопластику та створює три критичні інженерні проблеми при компонуванні борту безпілотника.

![Взаємодія радіохвиль з вуглепластиком та склопластиком](/root/sys/sys-dron/kompozyty/img/rf-behavior-carbon-vs-fiberglass.svg)
*Електродинамічна поведінка: вуглепластик утворює замкнений екран Фарадея, блокуючи радіохвилі, тоді як склопластик є прозорим діелектриком для НВЧ сигналів.*

#### 1. Електромагнітне екранування (клітка Фарадея)

При взаємодії високочастотної радіохвилі з провідною вуглепластиковою поверхнею вільні носії заряду у вуглецевих волокнах збуджують вихрові струми, які перевипромінюють відбиту хвилю у зворотному напрямку. Глибина проникнення електромагнітного поля (товщина скін-шару `δ`) описується формулою:

```
δ
= √( 1 / (π · f · μ · σ_e) )      [глибина скін-шару для провідного середовища]
```

де:
- `f` — частота радіосигналу (Гц);
- `μ = μ₀ · μ_r ≈ 4π·10⁻⁷ Гн/м` — магнітна проникність вуглепластику (немагнітний матеріал, `μ_r ≈ 1`);
- `σ_e = 1 / ρ_e ≈ 2·10⁴ См/м` — питома електропровідність.

Для діапазону GPS L1 (`f = 1.575 ГГц`):

```
δ_GPS
= √( 1 / (3.1416 · 1.575·10⁹ · 4·3.1416·10⁻⁷ · 2·10⁴) )      [підстановка частоти L1, проникності та провідності]
= √( 1 / (4.948·10⁹ · 2.513·10⁻² ) )                         [перемноження частотного та електродинамічного множників]
= √( 1 / 1.243·10⁸ )                                         [добуток у знаменнику під коренем]
= √( 8.045·10⁻⁹ )                                            [обернене значення дробу]
≈ 8.97·10⁻⁵ м                                                [вилучення квадратного кореня: товщина скін-шару 0.09 мм]
```

Оскільки стандартна товщина карбонової пластини або фюзеляжу становить 1.5–3.0 мм, що у 15–30 разів перевищує глибину скін-шару, вуглепластикова оболонка працює як суцільний металевий екран. Рівень затухання радіочастотного сигналу всередині закритого карбонового корпусу становить від `-40 дБ` до `-70 дБ` (послаблення потужності в 10 000 — 10 000 000 разів). 

**Практичний наслідок:** будь-яка антена (GNSS, приймач керування ELRS/CRSF на 868/915/2400 МГц, відеопередавач VTX на 5.8 ГГц), розташована всередині карбонового фюзеляжу або безпосередньо під карбоновою пластиною, втрачає зв'язок або зазнає глибоких тіньових провалів діаграми спрямованості під час маневрування. Антени вимагають виносу на діелектричні щогли або розміщення під радіопрозорими ковпаками.

#### 2. Ризик коротких замикань бортової електроніки

Оскільки епоксидна смола на зовнішній поверхні карбонової пластини має товщину всього кілька мікрометрів, вона легко стирається або прорізається гострими кромками електронних компонентів, гайками, стійками та виводами силових транзисторів регуляторів швидкості (ESC).

Якщо оголений плюсовий провід або полігон силової плати торкається карбонової рами, весь каркас дрона опиняється під електричним потенціалом батареї. При випадковому торканні іншим силовим елементом або металевим гвинтом кріплення виникає міжфазне коротке замикання акумулятора LiPo (зі струмами до 500–1000 А), що призводить до миттєвого випаровування мідних доріжок, займання літієвої батареї та руйнування полімерної матриці від термічного шоку.

**Заходи захисту:**
- Встановлення плат живлення (PDB) та 4-in-1 ESC виключно через ізоляційні стійки з поліаміду (нейлону) або поліацеталю (POM);
- Наклеювання на карбонову поверхню під платами шару діелектричного склотекстоліту FR-4 (товщиною 0.5 мм) або термостійкої каптонової плівки (поліімід);
- Обов'язкова перевірка омметром опору між плюсовим/мінусовим виводами роз'єму живлення (XT60/XT90) та всіма точками карбонової рами перед першим поданням живлення (опір має бути нескінченним).

#### 3. Гальванічна корозія при контакті з металами

Вуглець має високий позитивний стандартний електродний потенціал (`E° ≈ +0.2 В` відносно стандартного водневого електрода), виступаючи ефективним благородним катодом. 

Алюмінієві сплави (Д16Т, 6061, 7075), з яких виготовляють монтажні стійки, затискачі моторів та гвинти, мають від'ємний потенціал (`E° ≈ -0.7...-0.9 В`). Різниця потенціалів у контактній парі «вуглепластик–алюміній» досягає `ΔE ≈ 1.0 В`. 

У присутності вологи або сольового туману утворюється активний мікрогальванічний елемент, в якому алюміній інтенсивно анодно розчиняється, перетворюючись на пухкий оксид і гідроксид алюмінію `Al(OH)₃`. Це призводить до послаблення затяжки різьбових з'єднань, корозійного розтріскування кріплень та руйнування конструкції в польоті.

**Заходи захисту:** застосування кріплення з нержавіючої сталі (A2/A4), титанових гвинтів, анодованого алюмінію з непошкодженим оксидним шаром або розділових склопластикових шайб.

### Склопластик (GFRP) та кевлар (AFRP): радіопрозорість і демпфування

Склопластик (англ. *Glass Fiber Reinforced Polymer*, GFRP) виготовляють на основі неорганічних скляних волокон з аморфного діоксиду кремнію `SiO₂` з добавками оксидів алюмінію, кальцію, бору та магнію. 

Основні типи промислового скловолокна:
- **E-glass (електричне скло):** алюмоборосилікатний склад, найпоширеніше волокно з низькою собівартістю, високим електричним опором (`ρ_e > 10¹² Ом·м`), модулем пружності `E_f ≈ 72–76 ГПа` та міцністю на розрив `σ_u ≈ 3.4 ГПа`.
- **S-glass / R-glass (високоміцне скло):** магнієво-алюмосилікатний склад із підвищеним вмістом `SiO₂` та `Al₂O₃`, оптимізований для авіації. Модуль Юнга `E_f ≈ 86–90 ГПа`, міцність `σ_u ≈ 4.6–4.8 ГПа`.

#### Радіопрозорість та діелектричні характеристики

Склопластик є класичним діелектриком із низькою відносною діелектричною проникністю (`ε_r ≈ 4.2–5.2`) та малим тангенсом кута діелектричних втрат (`tan δ ≈ 0.004–0.015` на частотах 1–10 ГГц). 

Електромагнітна хвиля проходить крізь склопластикову стінку практично без відбиття та затухання (втрати потужності складають менше 0.2–0.5 дБ).

```
P_loss
= 1 - exp( - (2π · f · d_wall · √ε_r · tan δ) / c )      [втрати потужності НВЧ хвилі в діелектрику]
```

Завдяки цьому склопластик є безальтернативним матеріалом для:
- Антенних обтічників (англ. *radomes*) курсових радарів, супутникових антен GNSS та радіоліній;
- Трубчастих променів безпілотників, всередину яких монтуються коаксіальні дипольні антени телеметрії;
- Друкованих плат електроніки у вигляді листового склотекстоліту FR-4 (англ. *Flame Retardant 4* — склотканина E-glass, просочена бромованою епоксидною смолою).

#### Деформаційна здатність та енергоємність руйнування

Порівняно з вуглепластиком скловолокно має менший модуль пружності (у 3 рази нижчий за стандартний карбон), однак вирізняється високим граничним пружним подовженням до руйнування: `ε_max ≈ 3.5–4.8%` (проти `1.0–1.8%` у вуглепластику).

Питома енергія пружної деформації (площа під кривою деформування `U_def = (σ · ε) / 2`) у високоміцного склопластику значно вища, ніж у карбону. Конструкція зі склопластику здатна витримувати великі пружні вигини без появи тріщин, ефективно демпфуючи низькочастотні коливання та поглинаючи енергію жорстких посадок.

#### Арамід (Кевлар / AFRP)

Арамідні волокна (поліпарафенілен-терефталамід, торгові марки *Kevlar 29 / 49*, *Twaron*) складаються з жорстких витягнутих полімерних ланцюгів, з'єднаних міжмолекулярними водневими зв'язками.

Ключові переваги араміду:
- Виняткова питома ударна в'язкість і стійкість до розриву (балістичний захист);
- Відсутність крихкого руйнування: при перевищенні межі міцності волокна не ламаються на гострі осколки, а фібрилюють (розпадаються на мікроволокна), поглинаючи кінетичну енергію;
- Низька густина (`ρ ≈ 1.44 г/см³`).

**Недоліки араміду:** дуже низька міцність на стиск (всього 200–250 МПа через легке зминання полімерних ланцюгів), високе водопоглинання (до 4–6% вологи руйнує міжмолекулярні зв'язки) та екстремальна складність механічної обробки (волокна ворсяться і вимагають спеціальних ножів та алмазних фрез).

В авіаційних безпілотниках широке застосування знаходять **гібридні тканини** (Carbon–Kevlar twill weave), де чергуються джгути вуглецю та кевлару: карбон забезпечує високу жорсткість на вигин, а кевлар запобігає розльоту уламків рами при ударі та захищає акумуляторний відсік від пробиття.

### Механіка руйнування: дефекти, BVID та правила механічної обробки

Шаруваті композити докорінно відрізняються за характером руйнування від ізотропних пластичних металів. Метали перед руйнуванням демонструють виражену пластичну текучість, перерозподіляючи локальні піки напружень. Композити є пружно-крихкими матеріалами, в яких накопичення пошкоджень відбувається дискретно через декілька взаємопов'язаних мікроструктурних механізмів.

![Механізми руйнування композитів](/root/sys/sys-dron/kompozyty/img/composite-failure-modes.svg)
*Чотири базові моди руйнування: 1 — міжшарове розшарування (деламінація), 2 — матричне розтріскування, 3 — мікрозминання волокон при стиску, 4 — висмикування волокон при розтязі.*

#### Механізми деградації та руйнування

1. **Матричне мікророзтріскування (Matrix cracking):** виникає в шарах, орієнтованих поперек напрямку головного навантаження (наприклад, у шарах `90°`), коли поперечна деформація досягає граничного подовження епоксидної смоли (`ε_m ≈ 0.8–1.2%`). Тріщини зупиняються на межі сусіднього шару `0°`, знижуючи поперечну жорсткість та відкриваючи доступ волозі.
2. **Втрата стійкості волокон при стиску (Microbuckling / Kinking):** при дії стискальних напружень тонкі волокна втрачають стійкість у пружній матриці, утворюючи смуги пластичного злому (англ. *kink-bands*). Через це міцність вуглепластику на стиск `X_c` завжди на 35–50% нижча за міцність на розтяг `X_t` (`1200 МПа` проти `2100 МПа`).
3. **Міжшарове розшарування (Interlaminar Delamination):** розділення сусідніх шарів під дією міжшарових дотичних напружень `τ_xz, τ_yz` або нормальних напружень відриву `σ_z`. Оскільки між шарами немає армувальних волокон, міцність визначається виключно чистим епоксидним прошарком (`G_Ic ≈ 200–400 Дж/м²`).
4. **Приховані ударні пошкодження (BVID — Barely Visible Impact Damage):** при падінні інструмента або зіткненні дрона з гілкою дерева на лицьовій стороні карбонової пластини залишається ледь помітна мікроподряпина глибиною менше 0.1 мм. Однак всередині пакета утворюється конічна зона масивного розшарування та розтріскування смоли. Залишкова міцність пластини на стиск після удару (англ. *Compression After Impact*, CAI) падає на **40–60%**, що призводить до раптового перелому променя при звичайному польотному маневрі.

#### Механічна обробка та охорона праці

Обробка вуглепластику та склопластику на фрезерних верстатах із ЧПУ або ручним інструментом пов'язана з двома фундаментальними проблемами: високою абразивністю волокна та токсичністю дрібнодисперсного пилу.

##### 1. Знос інструменту та геометрія різання
Вуглецеві волокна мають твердість за Моосом близько 7–8 (твердіші за загартовану сталь), а скловолокно складається з абразивного кварцового скла.
- Звичайні свердла та фрези зі швидкорізальної сталі (HSS) затуплюються і згорають після виконання 3–5 отворів;
- Для чистової обробки застосовують монолітний твердий сплав із карбіду вольфраму (ВК6 / ВК8 / Tungsten Carbide) з алмазоподібним покриттям DLC (Diamond-Like Carbon) або полікристалічним алмазом (PCD);
- Фрезерування пазів і кромок виконують спеціальними багатозахідними фрезами сітчастого типу («кукурудза», англ. *diamond-cut router*), які подрібнюють волокно без створення спрямованих сколювальних зусиль;
- Швидкість різання встановлюють високою (18 000 — 24 000 об/хв), а швидкість подачі — помірною, щоб температура в зоні різання не перевищувала температуру склування смоли `T_g ≈ 120–150 °C` (перегрів призводить до випаровування смоли та розпушення волокон).

##### 2. Запобігання розшаруванню на вході та виході
При свердлінні осьова сила подачі свердла підриває верхній шар ламінату на вході (англ. *peel-up delamination*) і виштовхує нижній шар на виході (англ. *push-out delamination*).
- Обов'язкове використання щільної жертвенної підкладки (дерево твердих порід, текстоліт) під деталлю, затиснутої струбцинами;
- Зменшення швидкості подачі на 50–70% у момент входу та виходу інструменту;
- Застосування спеціальних свердел зі зворотною підрізною геометрією кромок (англ. *brad-point drill* або корончасті свердла).

##### 3. Небезпека карбонового пилу
Пил, що утворюється при сухому різанні вуглепластику, складається з мікроскопічних голчастих електропровідних фрагментів волокон розміром 1–20 мкм.
- **Для апаратури:** карбоновий пил зависає в повітрі, затягується кулерами в блоки живлення, польотні контролери та комп'ютери. Осідаючи між виводами планарних мікросхем (STM32, MOSFET, IMU), струмопровідні голки викликають непередбачувані мікрозамикання та спалювання плат;
- **Для здоров'я людини:** голчасті частки вуглецю та скла не розчиняються в організмі, глибоко проникають в альвеоли легень і викликають хронічний фіброз та подразнення слизових оболонок (аналогічно азбестовому пилу);
- **Обов'язкові заходи безпеки:** фрезерування у водяній ванні (мокре різання повністю зв'язує пил у шлам), застосування промислових стружковідсмоктувачів із HEPA-фільтрами класу H14 та використання засобів індивідуального захисту (респіратор класу FFP3 / P3, захисні герметичні окуляри та рукавички).

### Модель розрахунку міцності композитного променя

Для верифікації силової конструкції променя дрона розроблено алгоритмічну модель на основі класичної теорії ламінатів (CLT). Програма визначає ефективні пружні характеристики пакета шарів, розраховує напруження в кожному моношарі під дією згинального моменту від тяги мотора та перевіряє тензорний критерій руйнування Цая–Ву:

```
F₁·σ₁ + F₂·σ₂ + F₁₁·σ₁² + F₂₂·σ₂² + F₆₆·τ₁₂² + 2·F₁₂·σ₁·σ₂ ≤ 1.0
```

Повний бібліотечний модуль із підтримкою довільної кількості шарів, автоматичного формування матриць `ABD` та інтеграції в CAD/CAM системи наведено у вставці [модель розрахунку міцності та деформації композитного променя на C та C++](root:sys-dron/kompozyty/proj-composite-beam-calc.md).

Нижче наведено базовий алгоритм обчислення жорсткості та деформації композитної консольної балки:

:::tabs
```c
#include <stdio.h>
#include <stdbool.h>
#include <math.h>

#define PI 3.14159265358979323846
#define DEG2RAD (PI / 180.0)

/* Характеристики односпрямованого моношару */
typedef struct {
    double E1;      /* Па: поздовжній модуль пружності */
    double E2;      /* Па: поперечний модуль пружності */
    double G12;     /* Па: модуль зсуву */
    double nu12;    /* Коефіцієнт Пуассона */
    double Xt;      /* Па: міцність на розтяг вздовж волокна */
    double Xc;      /* Па: міцність на стиск вздовж волокна */
    double Yt;      /* Па: міцність на поперечний розтяг */
    double Yc;      /* Па: міцність на поперечний стиск */
    double S;       /* Па: міцність на зсув */
    double t;       /* м: товщина моношару */
} CompositePly;

/* Обчислення плоских напружень та коефіцієнта запасу за Цаєм-Ву */
double calculate_tsai_wu_margin(const CompositePly* ply, double sigma1, double sigma2, double tau12) {
    double F1 = (1.0 / ply->Xt) - (1.0 / ply->Xc);
    double F2 = (1.0 / ply->Yt) - (1.0 / ply->Yc);
    double F11 = 1.0 / (ply->Xt * ply->Xc);
    double F22 = 1.0 / (ply->Yt * ply->Yc);
    double F66 = 1.0 / (ply->S * ply->S);
    double F12 = -0.5 * sqrt(F11 * F22);

    /* Квадратне рівняння для коефіцієнта навантаження SF: A*SF^2 + B*SF - 1 = 0 */
    double A = F11 * sigma1 * sigma1 + F22 * sigma2 * sigma2 +
               F66 * tau12 * tau12 + 2.0 * F12 * sigma1 * sigma2;
    double B = F1 * sigma1 + F2 * sigma2;

    if (A <= 1e-20) return 100.0;
    double discr = B * B + 4.0 * A;
    if (discr < 0.0) return 0.0;

    return (-B + sqrt(discr)) / (2.0 * A);
}

/* Розрахунок ефективного модуля та прогину трубчастого променя */
bool evaluate_composite_tube(
    const CompositePly* mat,
    const double* angles_deg,
    int num_layers,
    double length_m,
    double outer_rad_m,
    double thrust_force_n,
    double* out_Ex_eff,
    double* out_deflection_mm,
    double* out_min_sf
) {
    if (!mat || !angles_deg || num_layers <= 0) return false;

    double nu21 = (mat->nu12 * mat->E2) / mat->E1;
    double denom = 1.0 - mat->nu12 * nu21;

    double Q11 = mat->E1 / denom;
    double Q12 = (mat->nu12 * mat->E2) / denom;
    double Q22 = mat->E2 / denom;
    double Q66 = mat->G12;

    double A11 = 0.0, A12 = 0.0, A22 = 0.0;
    double total_h = num_layers * mat->t;

    for (int k = 0; k < num_layers; ++k) {
        double rad = angles_deg[k] * DEG2RAD;
        double m = cos(rad), n = sin(rad);
        double m2 = m * m, n2 = n * n;
        double m4 = m2 * m2, n4 = n2 * n2, m2n2 = m2 * n2;

        double Qbar11 = Q11 * m4 + 2.0 * (Q12 + 2.0 * Q66) * m2n2 + Q22 * n4;
        double Qbar12 = (Q11 + Q22 - 4.0 * Q66) * m2n2 + Q12 * (m4 + n4);
        double Qbar22 = Q11 * n4 + 2.0 * (Q12 + 2.0 * Q66) * m2n2 + Q22 * m4;

        A11 += Qbar11 * mat->t;
        A12 += Qbar12 * mat->t;
        A22 += Qbar22 * mat->t;
    }

    double Ex_eff = (A11 * A22 - A12 * A12) / (total_h * A22);
    double inner_rad_m = outer_rad_m - total_h;
    double I_xx = (PI / 4.0) * (pow(outer_rad_m, 4.0) - pow(inner_rad_m, 4.0));

    /* Максимальний прогин консолі w = F * L^3 / (3 * E * I) */
    double w_max = (thrust_force_n * pow(length_m, 3.0)) / (3.0 * Ex_eff * I_xx);

    /* Максимальна поздовжня деформація від вигину */
    double M_bend = thrust_force_n * length_m;
    double eps_x_max = (M_bend * outer_rad_m) / (Ex_eff * I_xx);

    double min_sf = 1e9;
    for (int k = 0; k < num_layers; ++k) {
        double rad = angles_deg[k] * DEG2RAD;
        double m = cos(rad), n = sin(rad);

        double eps1 = eps_x_max * m * m;
        double eps2 = eps_x_max * n * n;
        double gamma12 = -2.0 * eps_x_max * m * n;

        double sigma1 = Q11 * eps1 + Q12 * eps2;
        double sigma2 = Q12 * eps1 + Q22 * eps2;
        double tau12  = Q66 * gamma12;

        double sf = calculate_tsai_wu_margin(mat, sigma1, sigma2, tau12);
        if (sf < min_sf) min_sf = sf;
    }

    *out_Ex_eff = Ex_eff;
    *out_deflection_mm = w_max * 1e3;
    *out_min_sf = min_sf;
    return true;
}

int main(void) {
    CompositePly t700 = {
        .E1 = 135.0e9, .E2 = 9.0e9, .G12 = 4.8e9, .nu12 = 0.30,
        .Xt = 2100.0e6, .Xc = 1200.0e6, .Yt = 50.0e6, .Yc = 180.0e6, .S = 75.0e6,
        .t = 0.125e-3
    };

    double layup[8] = {0.0, 45.0, -45.0, 90.0, 90.0, -45.0, 45.0, 0.0};
    double Ex, deflection, sf;

    if (evaluate_composite_tube(&t700, layup, 8, 0.35, 0.0125, 45.0, &Ex, &deflection, &sf)) {
        printf("Модуль Ex: %.2f ГПа, Прогин: %.3f мм, Запас міцності: %.2f\n",
               Ex / 1e9, deflection, sf);
    }
    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <numbers>
#include <optional>
#include <iomanip>

namespace drone_mechanics {

struct CompositeMaterial {
    double E1{135.0e9};      // Па: поздовжній модуль Юнга
    double E2{9.0e9};        // Па: поперечний модуль Юнга
    double G12{4.8e9};       // Па: модуль зсуву
    double nu12{0.30};       // Коефіцієнт Пуассона
    double Xt{2100.0e6};     // Па: міцність на поздовжній розтяг
    double Xc{1200.0e6};     // Па: міцність на поздовжній стиск
    double Yt{50.0e6};       // Па: міцність на поперечний розтяг
    double Yc{180.0e6};      // Па: міцність на поперечний стиск
    double S{75.0e6};        // Па: міцність на зсув
    double ply_thickness{0.125e-3}; // м: товщина одного шару
};

struct BeamResult {
    double Ex_eff_gpa{0.0};
    double deflection_mm{0.0};
    double min_safety_factor{0.0};
};

class CompositeTubeCalculator {
public:
    explicit CompositeTubeCalculator(CompositeMaterial mat, std::vector<double> layup_deg)
        : mat_(mat), layup_(std::move(layup_deg)) {}

    [[nodiscard]] std::optional<BeamResult> evaluate(
        double length_m,
        double outer_radius_m,
        double thrust_force_n
    ) const {
        if (layup_.empty() || length_m <= 0.0 || outer_radius_m <= 0.0) {
            return std::nullopt;
        }

        const double nu21 = (mat_.nu12 * mat_.E2) / mat_.E1;
        const double denom = 1.0 - mat_.nu12 * nu21;

        const double Q11 = mat_.E1 / denom;
        const double Q12 = (mat_.nu12 * mat_.E2) / denom;
        const double Q22 = mat_.E2 / denom;
        const double Q66 = mat_.G12;

        double A11 = 0.0, A12 = 0.0, A22 = 0.0;
        const double total_thickness = layup_.size() * mat_.ply_thickness;

        for (double angle_deg : layup_) {
            const double rad = angle_deg * (std::numbers::pi / 180.0);
            const double m = std::cos(rad);
            const double n = std::sin(rad);
            const double m2 = m * m, n2 = n * n;
            const double m4 = m2 * m2, n4 = n2 * n2, m2n2 = m2 * n2;

            const double Qbar11 = Q11 * m4 + 2.0 * (Q12 + 2.0 * Q66) * m2n2 + Q22 * n4;
            const double Qbar12 = (Q11 + Q22 - 4.0 * Q66) * m2n2 + Q12 * (m4 + n4);
            const double Qbar22 = Q11 * n4 + 2.0 * (Q12 + 2.0 * Q66) * m2n2 + Q22 * m4;

            A11 += Qbar11 * mat_.ply_thickness;
            A12 += Qbar12 * mat_.ply_thickness;
            A22 += Qbar22 * mat_.ply_thickness;
        }

        const double Ex_eff = (A11 * A22 - A12 * A12) / (total_thickness * A22);
        const double inner_radius_m = outer_radius_m - total_thickness;
        const double I_xx = (std::numbers::pi / 4.0) * (std::pow(outer_radius_m, 4.0) - std::pow(inner_radius_m, 4.0));

        const double w_max = (thrust_force_n * std::pow(length_m, 3.0)) / (3.0 * Ex_eff * I_xx);
        const double M_bend = thrust_force_n * length_m;
        const double eps_x_max = (M_bend * outer_radius_m) / (Ex_eff * I_xx);

        double min_sf = 1e9;
        for (double angle_deg : layup_) {
            const double rad = angle_deg * (std::numbers::pi / 180.0);
            const double m = std::cos(rad);
            const double n = std::sin(rad);

            const double eps1 = eps_x_max * m * m;
            const double eps2 = eps_x_max * n * n;
            const double gamma12 = -2.0 * eps_x_max * m * n;

            const double sigma1 = Q11 * eps1 + Q12 * eps2;
            const double sigma2 = Q12 * eps1 + Q22 * eps2;
            const double tau12  = Q66 * gamma12;

            const double sf = compute_tsai_wu_sf(sigma1, sigma2, tau12);
            if (sf < min_sf) min_sf = sf;
        }

        return BeamResult{
            .Ex_eff_gpa = Ex_eff / 1e9,
            .deflection_mm = w_max * 1e3,
            .min_safety_factor = min_sf
        };
    }

private:
    [[nodiscard]] double compute_tsai_wu_sf(double s1, double s2, double t12) const noexcept {
        const double F1 = (1.0 / mat_.Xt) - (1.0 / mat_.Xc);
        const double F2 = (1.0 / mat_.Yt) - (1.0 / mat_.Yc);
        const double F11 = 1.0 / (mat_.Xt * mat_.Xc);
        const double F22 = 1.0 / (mat_.Yt * mat_.Yc);
        const double F66 = 1.0 / (mat_.S * mat_.S);
        const double F12 = -0.5 * std::sqrt(F11 * F22);

        const double A = F11 * s1 * s1 + F22 * s2 * s2 + F66 * t12 * t12 + 2.0 * F12 * s1 * s2;
        const double B = F1 * s1 + F2 * s2;

        if (A <= 1e-20) return 100.0;
        const double discr = B * B + 4.0 * A;
        return (discr < 0.0) ? 0.0 : (-B + std::sqrt(discr)) / (2.0 * A);
    }

    CompositeMaterial mat_;
    std::vector<double> layup_;
};

} // namespace drone_mechanics

int main() {
    using namespace drone_mechanics;

    CompositeMaterial carbon_t700{};
    std::vector<double> quasi_layup{0.0, 45.0, -45.0, 90.0, 90.0, -45.0, 45.0, 0.0};

    CompositeTubeCalculator calculator(carbon_t700, quasi_layup);
    if (const auto res = calculator.evaluate(0.35, 0.0125, 45.0)) {
        std::cout << std::fixed << std::setprecision(2);
        std::cout << "Ефективний модуль Ex: " << res->Ex_eff_gpa << " ГПа\n";
        std::cout << "Прогин на кінці: " << res->deflection_mm << " мм\n";
        std::cout << "Мінімальний запас міцності: " << res->min_safety_factor << "\n";
    }
    return 0;
}
```

### Підсумкові інженерні рекомендації

1. **Вибір матеріалу:** для силових балок, лонжеронів крила та опорних пластин фюзеляжу, де критична жорсткість на вигин при мінімальній масі, застосовують вуглепластик (CFRP). Для захисних ковпаків, обтічників антен (radomes) та променів із внутрішнім розміщенням антен зв'язку застосовують склопластик (GFRP). Для відсіків акумуляторних батарей та зон підвищеного ударного ризику — гібридний вуглець–кевлар (Carbon–Kevlar).
2. **Схема армування:** уникайте чисто односпрямованих шарів `[0°]` для деталей складної форми. Для корпусних пластин використовуйте квазіізотропний симетричний пакет `[0° / ±45° / 90°]_s`, а для трубчастих променів — комбінацію шарів `0°` (вигин) та `±45°` (кручення та зсув).
3. **Електроізоляція та радіорозв'язка:** ізолюйте всі силові плати (PDB, ESC) діелектричними прокладками з FR-4 або каптону, перевіряйте відсутність контакту силових шин із карбоновою рамою та виносьте антени за межі затінення струмопровідного каркаса.
4. **Технологія обробки:** фрезеруйте деталі твердосплавними алмазними фрезами на високих обертах із жертвенними підкладками та водяним зв'язуванням карбонового пилу, використовуючи засоби індивідуального захисту класу FFP3.
