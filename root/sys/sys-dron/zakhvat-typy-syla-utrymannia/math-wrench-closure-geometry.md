# 📐 Геометрія замикання: чому нуль мусить лежати всередині оболонки

Це виведення умов силового та геометричного замикання в шестивимірному просторі силових гвинтів — тієї самої умови «опукла оболонка охоплює нуль», яку основна стаття подає готовою. Тут показано, звідки вона береться, чому «охоплює» означає саме *строго всередині*, чому два точкові пальці з тертям принципово не тримають скручування навколо власної осі, і як із цієї геометрії народжується ефективний радіус тертя `r_eff = (2/3) · R`, що в розрахунку сили стискання виявився вирішальним.

## Простір, у якому живе задача

Тверде тіло в просторі має шість ступенів вільності, тож і будь-яка дія на нього — шестивимірна. Пара «сила плюс момент», зведена до центру мас, називається силовим гвинтом:

```
w = [ f_x, f_y, f_z, m_x, m_y, m_z ]ᵀ ∈ ℝ⁶      [силовий гвинт]
```

Перші три координати — Ньютони, останні три — Ньютон-метри. Це різні фізичні величини в одному векторі, і саме тут ховається перша пастка всієї теорії: «довжина» такого вектора не має фізичного змісту, доки не обрано масштаб довжини. Тому моментні координати ділять на характерний радіус тіла `ρ` — найбільшу відстань від центру мас до точки поверхні:

```
ŵ = [ f_x, f_y, f_z, m_x/ρ, m_y/ρ, m_z/ρ ]ᵀ      [нормований гвинт]
```

Після такого нормування всі шість координат вимірюються в Ньютонах, і геометричні поняття — відстань, куля, кут — знову щось означають. Усі числові оцінки запасу далі стосуються саме нормованих гвинтів; забути про `ρ` означає порівнювати захвати різного розміру за шкалою, яка тихо змінюється разом із деталлю.

## Що вміє один контакт

Точковий контакт із тертям у точці `r_i` (радіус-вектор від центру мас) із зовнішньою нормаллю `n_i` здатен передати тілу лише ті сили, що лежать усередині конуса тертя: нормальну складову — тільки на стиск, тангенціальну — обмежену законом Кулона. Множина допустимих сил у цій точці:

```
C_i = { c : c · n_i ≥ 0,  ‖c − (c · n_i) n_i‖ ≤ μ · (c · n_i) }      [конус тертя контакту]
```

Конус круглий, а працювати зручніше з многогранником, тому його замінюють вписаною пірамідою з `k` бічними ребрами (типово `k = 4...8`). Кожне ребро — це гранична сила, спрямована рівно по твірній конуса:

```
c_ij = n_i + μ · ( t_i1 · cos(2πj/k) + t_i2 · sin(2πj/k) ),   j = 0…k−1      [ребра піраміди тертя]
```

де `t_i1`, `t_i2` — два ортогональні дотичні орти в площині контакту. Заміна конуса на вписану піраміду **занижує** можливості захвату: всі оцінки запасу, отримані далі, консервативні, і це саме та похибка, знак якої нас влаштовує.

Кожне ребро, перенесене на центр мас, дає один базисний гвинт:

```
w_ij = [        c_ij        ]
       [   r_i × c_ij       ]      [примітивний гвинт ребра піраміди]
```

Верхній блок — сила, нижній — момент, який ця сила створює плечем `r_i`. Для `m` контактів отримуємо `m · k` примітивних гвинтів. Усе, що захват узагалі здатен прикласти до вантажу, — це їхні невід'ємні комбінації:

```
W = { Σ λ_ij · w_ij : λ_ij ≥ 0 }      [конічна оболонка досяжних гвинтів]
```

Невід'ємність тут не формальність: палець уміє тиснути, але не тягнути. Саме однобічність контакту робить множину `W` конусом, а не лінійним підпростором, і саме через неї задача не зводиться до звичайного рангу матриці.

## Умова силового замикання і чому нуль має бути *строго* всередині

Захват тримає вантаж, якщо на будь-яке зовнішнє навантаження `W_ext` знайдуться такі невід'ємні натиски, що `Σ λ_ij w_ij = −W_ext`. Оскільки `W_ext` довільний, вимога звучить так: конічна оболонка примітивних гвинтів має накривати весь простір `ℝ⁶`.

Тепер — переклад цієї вимоги мовою опуклої оболонки, бо саме в такому вигляді її подають у практиці. Обмежимо сумарний натиск: `Σ λ_ij ≤ 1`. Тоді досяжна множина стає опуклою оболонкою `H = conv{ w_ij }` разом із нулем. Твердження: **конічна оболонка накриває `ℝ⁶` тоді й лише тоді, коли нуль лежить у внутрішності `H`.**

Обидва боки видно без важкої техніки.

Якщо нуль **не** внутрішній, то через нього проходить опорна гіперплощина: існує ненульовий напрямок `u`, для якого `u · w_ij ≥ 0` одразу для всіх примітивних гвинтів. Будь-яка невід'ємна комбінація успадковує цю нерівність, тож гвинт `−u` захват не згенерує ніколи. А отже, зовнішнє навантаження `W_ext = u` не буде скомпенсоване жодним зусиллям пальців — хоч мотор спали. Одного «сліпого» напрямку досить, щоб захоплення не було замкненим.

Якщо нуль **внутрішній**, то навколо нього є куля радіуса `ε > 0`, що цілком лежить в `H`. Візьмімо будь-який напрямок `u` одиничної довжини: точка `ε·u` належить `H`, тобто є опуклою комбінацією примітивних гвинтів. Домноживши коефіцієнти на `‖W_ext‖/ε`, дістаємо потрібний гвинт будь-якої величини. Замикання є, і водночас ми щойно знайшли ціну питання: щоб протидіяти навантаженню `W_ext`, сумарний натиск пальців мусить бути не менший за `‖W_ext‖/ε`.

Звідси й метрика якості захоплення — радіус найбільшої кулі, вписаної в оболонку з центром у нулі. Для многогранника він рахується тривіально, бо найближча точка межі завжди лежить на грані:

```
ε_grasp = min over граней ( d_facet ),   d_facet = |b| / ‖n_facet‖      [запас утримання]
```

де `n_facet` — нормаль опорної гіперплощини грані, `b` — її вільний член. Практичний зміст `ε_grasp` тепер цілком прозорий: це **найгірший напрямок навантаження**, і саме він, а не середній, визначає потрібну силу мотора. Захват із `ε = 0.05` вимагає натиску, у двадцять разів більшого за зовнішнє збурення; захват із `ε = 0.5` — лише вдвічі.

## Два плоскі пальці: де саме оболонка торкається нуля

Тепер прикладімо цю машинерію до конфігурації з основної статті — паралельний двопальцевий захват. Контакти лежать на спільній осі `x` симетрично щодо центру мас:

```
r_1 = (−L, 0, 0),  n_1 = (+1, 0, 0)
r_2 = (+L, 0, 0),  n_2 = (−1, 0, 0)      [геометрія двопальцевого хвату]
```

Порахуймо, який момент навколо осі `x` — тієї самої, що з'єднує пальці, — здатні створити контактні сили. Тангенціальна складова лежить у площині `yz`: `c = (c_x, c_y, c_z)`. Момент першого контакту:

```
r_1 × c = (−L, 0, 0) × (c_x, c_y, c_z)
        = ( 0·c_z − 0·c_y,  0·c_x − (−L)·c_z,  (−L)·c_y − 0·c_x )
        = ( 0,  L·c_z,  −L·c_y )      [момент сили першого пальця]
```

Перша координата — нуль. Те саме для другого контакту, бо його радіус-вектор теж колінеарний осі `x`. Висновок жорсткий: **при ідеальному точковому контакті двопальцевий захват створює рівно нульовий момент навколо осі власного стискання.** У просторі гвинтів це означає, що вся оболонка `H` лежить у гіперплощині `m_x = 0`, нуль опиняється на її межі, і `ε_grasp = 0`. Формально такий хват не має силового замикання взагалі — жодна сила стискання, хоч мільйон Ньютонів, не втримає вантаж від провертання навколо лінії між губками.

Це не абстракція, а найчастіший спосіб загубити вантаж: деталь не вислизає вбік, вона *обертається* між губками й випадає з-під них. Формула основної статті `F_grip = (k_safe · M_rot) / (n · μ · r_eff)` при `r_eff → 0` дає нескінченність — і це та сама нуль-грань, лише записана арифметикою замість геометрії.

## Звідки береться `r_eff = (2/3) · R` — м'який палець рятує вироджену грань

Порятунок у тому, що реальна накладка не точка, а пляма. Контакт із площею передає ще й **момент кручення навколо нормалі**, і саме він виводить оболонку з виродженої гіперплощини.

Візьмімо круглу накладку радіуса `R`, притиснуту силою `F_grip`, і припустімо рівномірний тиск:

```
p = F_grip / (π · R²)      [середній контактний тиск]
```

Кожне елементарне кільце радіуса `r` завтовшки `dr` має площу `dA = 2πr·dr` і несе граничну силу тертя `μ · p · dA`, спрямовану по дотичній до кола. Її плече відносно центру плями дорівнює `r`, тож внесок у момент кручення:

```
dM = r · μ · p · 2πr · dr = 2π μ p r² dr      [внесок кільця в момент кручення]
```

Інтегруємо по всій плямі:

```
M_torsion = ∫₀ᴿ 2π μ p r² dr
          = 2π μ p · R³/3
          = 2π μ · [ F_grip / (π R²) ] · R³/3      [підстановка тиску]
          = (2/3) · μ · F_grip · R
```

Порівнявши з канонічною формою `M_torsion = μ · F_grip · r_eff`, читаємо відповідь просто з рівності:

```
r_eff = (2/3) · R      [ефективний радіус тертя круглої плями]
```

Ось і все походження коефіцієнта, який основна стаття бере як даність. Дві третини, а не половина, — бо зовнішні кільця плями мають і більше плече, і більшу площу водночас: вага `r²` під інтегралом підтягує центр ваги тертя до краю.

Фізичний сенс для конструктора значно ширший за один множник. Оболонка `H` тепер має ненульову товщину вздовж координати `m_x` — рівно `μ · F_grip · r_eff` після нормування на `ρ`. Це **найтонший вимір оболонки**, тож саме він і задає `ε_grasp` двопальцевого захвату. Звідси й правило, яке інакше виглядало б суто емпіричним: збільшення діаметра накладки допомагає лінійно, тоді як збільшення сили мотора допомагає лише в тій самій пропорції — але коштує струму, маси й перегріву. V-подібний виріз, згаданий у статті, працює ще різкіше: він розносить контакт у дві рознесені смуги, плече яких визначається вже не радіусом накладки, а шириною призми, і `r_eff` зростає стрибком.

Строго кажучи, рівномірний тиск — це припущення. Для пружного стиску за Герцем тиск падає до краю плями як `√(1 − r²/R²)`, і той самий інтеграл дає `r_eff ≈ 0.59·R` замість `0.667·R`. Різниця в 12% сидить усередині коефіцієнта запасу `k_safe`, тож для розрахунку захвату беруть простішу формулу — але знати, у який бік вона помиляється, корисно: у бік оптимізму.

## Геометричне замикання: та сама геометрія без тертя

Геометричне замикання — це та сама умова, поставлена жорсткіше: конічна оболонка має накривати `ℝ⁶`, коли з кожного контакту дозволено брати **лише нормаль**, `μ = 0`:

```
{ Σ λ_i · [ n_i ; r_i × n_i ] : λ_i ≥ 0 } = ℝ⁶      [умова геометричного замикання]
```

Тепер кожен контакт дає рівно один гвинт замість `k`, і питання переходить у комбінаторику: скільки променів потрібно, щоб їхня конічна оболонка накрила шестивимірний простір? Загальна теорема опуклої геометрії дає нижню межу `n + 1` для простору `ℝⁿ`, тобто сім. Для механіки цей результат довів 1900 року Павло Сомов, професор механіки Варшавського політехнічного інституту; в площині відповідне число дорівнює чотирьом, і його ще 1875-го отримав із кінематичних міркувань Франц Рело. Що сім контактів не лише необхідні, а й достатні для практично всіх тіл — крім поверхонь обертання, які принципово не знерухомити жодною їх кількістю, — показали значно пізніше, наприкінці 1980-х, у роботах з обчислювальної геометрії захоплення.

Звідси випливає ієрархія, яку легко переплутати:

- геометричне замикання завжди тягне за собою силове, бо піраміда тертя містить нормаль як своє осердя;
- зворотне невірно: три пальці з тертям дають силове замикання майже будь-якої опуклої деталі, але геометричного не дають — прибери тертя, і деталь поїде;
- «п'ять пальців тримають краще за три» стосується запасу `ε`, а не типу замикання: додаткові контакти не змінюють природу умови, вони роздувають оболонку й відсувають найближчу грань від нуля.

## Що з цього лишається в голові інженера

Уся теорія зводиться до трьох робочих тверджень. Перше: захват описується не «силою в Ньютонах», а шестивимірною оболонкою досяжних гвинтів, і надійність — це відстань від нуля до найближчої її грані. Друге: запас визначає найгірший напрямок навантаження, а для плоских двопальцевих захватів цей напрямок майже завжди — кручення навколо осі губок, бо саме там оболонка вироджується в нуль при точковому контакті. Третє: площа накладки — не косметика, а єдине, що взагалі створює цей вимір оболонки, і `(2/3)·R` — точна ціна кожного міліметра її радіуса.

Практичне рішення, яке звідси випливає, просте до банальності й водночас систематично ігнорується: перш ніж підіймати силу стискання, збільште плече. Ширша накладка, V-подібний виріз, два рознесені п'ятачки замість одного круглого — усе це рухає найтоншу грань оболонки, тоді як струм мотора лише розтягує ту саму фігуру, залишаючи її форму незмінною.
