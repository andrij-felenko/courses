# 📋 Структура Декларації відповідності (EU DoC) та схема маніфесту відповідності

Декларація відповідності ЄС (*EU Declaration of Conformity*, DoC) — це офіційний юридичний документ, за допомогою якого виробник прямо бере на себе повну цивільну та кримінальну відповідальність за безпеку приладу. Формат і склад обов'язкових полів Декларації суворо регламентовані: для радіообладнання базовою є структура з Додатка VI Директиви RED 2014/53/EU, для загального електротехнічного обладнання — Додаток III Рішення № 768/2008/EC.

Будь-який пропуск обов'язкового розділу, розмите формулювання назви моделі або посилання на нечинну редакцію гармонізованого стандарту позбавляє декларацію юридичної сили та розцінюється наглядовими органами як порушення умов допуску на ринок.

### Обов'язкова 9-пунктова структура EU DoC за Директивою RED

Згідно з Додатком VI Директиви 2014/53/EU, текст Декларації відповідності повинен містити дев'ять нумерованих розділів у фіксованому порядку:

1. **Унікальний ідентифікатор документа (No. XXXX):** унікальний номер декларації в системі документообігу виробника (наприклад, `DoC-2026-GW100-v2`). Необхідний для однозначного посилання в контрактах, митних деклараціях і каталогах.
2. **Виробник або уповноважений представник:** повне юридичне найменування підприємства та його офіційна зареєстрована поштова адреса (включно з країною та індексом). Якщо виробник зареєстрований за межами ЄС, зазначаються також реквізити призначеного Уповноваженого представника в ЄС (*Authorised Representative*) згідно зі Статтею 4 Регламенту (ЄС) 2019/1020 про нагляд за ринком.
3. **Заява про одноосібну відповідальність:** стандартне юридичне формулювання: *«This declaration of conformity is issued under the sole responsibility of the manufacturer»* («Ця декларація відповідності видається під виключну відповідальність виробника»). Будь-які застереження або спроби розділити відповідальність із субпідрядниками роблять DoC недійсною.
4. **Об'єкт декларації (Ідентифікація виробу):**
   - Комерційна назва продукту та маркетингове найменування;
   - Номер моделі, артикул (SKU), тип обладнання;
   - Діапазон серійних номерів або позначення виробничої партії;
   - Чітка кольорова фотографія продукту або його креслення з габаритами для візуальної верифікації митними інспекторами;
   - Стислий опис функціонального призначення (наприклад: «Промисловий бездротовий шлюз телеметрії з інтерфейсами Wi-Fi 2.4 ГГц та Bluetooth Low Energy»).
5. **Гармонізаційне законодавство ЄС:** вичерпний перелік усіх чинних директив і регламентів Європейського Союзу, під дію яких підпадає виріб:
   - *Directive 2014/53/EU (Radio Equipment Directive — RED);*
   - *Directive 2011/65/EU and delegated directive (EU) 2015/863 (RoHS 3 — обмеження небезпечних речовин);*
   - *Regulation (EU) 2023/1230 (Machinery Regulation — якщо у виробі є рухомі виконавчі механізми);*
   - *Regulation (EU) 2024/2847 (Cyber Resilience Act — CRA).*
6. **Посилання на застосовані гармонізовані стандарти та технічні специфікації:** найважливіший інженерний розділ. Кожен стандарт має бути вказаний із **точним суфіксом версії, роком видання та змінами** (A1, A11 тощо). Вказувати «голі» назви на кшталт «EN 300 328» без зазначення версії суворо заборонено:
   - *Стаття 3.1a (Безпека):* `EN IEC 62368-1:2020 + A11:2020`, `EN 50663:2017`, `EN 62311:2020`;
   - *Стаття 3.1b (ЕМС):* `EN 301 489-1 V2.2.3`, `EN 301 489-17 V3.2.4`, `EN 55032:2015 + A11:2020`, `EN 55035:2017 + A11:2020`;
   - *Стаття 3.2 (Спектр):* `ETSI EN 300 328 V2.2.2`, `ETSI EN 301 893 V2.1.1`;
   - *Стаття 3.3 (Кібербезпека):* `ETSI EN 303 645 V2.1.1`;
   - *RoHS:* `EN IEC 63000:2018`.
7. **Комплектуючі, аксесуари та версії програмного забезпечення:** опис додаткових елементів (антени з конкретним коефіцієнтом підсилення, зовнішні блоки живлення, кабелі), які дозволяють радіообладнанню працювати за призначенням. **Обов'язкова фіксація версії прошивки (Firmware Release)**, на якій проводилися сертифікаційні випробування і яка гарантує збереження радіочастотних меж.
8. **Залучення нотифікованого органу (якщо застосовувався Модуль B):**
   - Назва та 4-значний номер нотифікованого органу (наприклад: *Notified Body 0700, PHOENIX TESTLAB GmbH*);
   - Опис виконаної процедури: *«performed EU-Type Examination in accordance with Module B of Directive 2014/53/EU»*;
   - Номер виданого сертифіката: *«and issued the EU-Type Examination Certificate: No. 26-104892»*.
   - Якщо оцінка здійснювалася за Модулем A (чиста самодекларація), у цьому пункті пишеться: *«Not Applicable (Conformity assessment module A applied)»*.
9. **Додаткова інформація та підпис посадової особи:**
   - Місце підписання (місто, країна);
   - Дата видання декларації (дата підписання має передувати або збігатися з датою першого відвантаження товару);
   - Прізвище, ім'я та офіційна посада підписанта (генеральний директор, віце-президент із якості або уповноважений технічний директор, який має право підпису юридичних зобов'язань від імені юридичної особи);
   - Власноручний або кваліфікований електронний цифровий підпис (QES).

### Мовні вимоги до Декларації

Згідно зі Статтею 10(4) Директиви RED, Декларація відповідності має бути перекладена **мовою або мовами, які вимагає держава-член ЄС**, де виріб розміщується або надається на ринку.

Кожен прилад, що постачається кінцевому споживачеві чи дистриб'ютору, повинен супроводжуватися або повною копією DoC національною мовою країни продажу, або її спрощеним варіантом (*Simplified EU Declaration of Conformity*) із прямим інтернет-посиланням (URL/QR-код) на повний текст:

> *«Hereby, [Manufacturer Name] declares that the radio equipment type [Model] is in compliance with Directive 2014/53/EU. The full text of the EU declaration of conformity is available at the following internet address: https://example.com/doc/gw100»*

### Машиночитна схема маніфесту відповідності (JSON Schema)

Для автоматизації перевірки сертифікаційних параметрів у конвеєрах CI/CD та цифрових паспортах продукції (*Digital Product Passport*, DPP) використовується структурований маніфест відповідності:

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "EUProductComplianceManifest",
  "type": "object",
  "required": [
    "doc_identifier",
    "manufacturer",
    "product",
    "directives",
    "standards",
    "firmware",
    "signatory"
  ],
  "properties": {
    "doc_identifier": {
      "type": "string",
      "pattern": "^DoC-[0-9]{4}-[A-Z0-9_-]+$"
    },
    "manufacturer": {
      "type": "object",
      "required": ["legal_name", "country", "eu_representative_address"],
      "properties": {
        "legal_name": { "type": "string" },
        "tax_id": { "type": "string" },
        "headquarters_address": { "type": "string" },
        "eu_representative_address": { "type": "string" }
      }
    },
    "product": {
      "type": "object",
      "required": ["commercial_name", "model_number", "hw_revision"],
      "properties": {
        "commercial_name": { "type": "string" },
        "model_number": { "type": "string" },
        "hw_revision": { "type": "string" },
        "intended_use": { "type": "string" }
      }
    },
    "directives": {
      "type": "array",
      "items": { "type": "string" },
      "minItems": 1
    },
    "standards": {
      "type": "array",
      "items": {
        "type": "object",
        "required": ["directive_article", "standard_code", "version_year"],
        "properties": {
          "directive_article": { "type": "string" },
          "standard_code": { "type": "string" },
          "version_year": { "type": "string" },
          "test_report_id": { "type": "string" }
        }
      }
    },
    "firmware": {
      "type": "object",
      "required": ["certified_version", "sha256_hash", "rf_power_table_crc"],
      "properties": {
        "certified_version": { "type": "string" },
        "sha256_hash": { "type": "string", "pattern": "^[a-f0-9]{64}$" },
        "rf_power_table_crc": { "type": "string" }
      }
    },
    "notified_body": {
      "type": "object",
      "properties": {
        "name": { "type": "string" },
        "number_4digit": { "type": "string", "pattern": "^[0-9]{4}$" },
        "certificate_id": { "type": "string" }
      }
    },
    "signatory": {
      "type": "object",
      "required": ["full_name", "role", "issue_date", "issue_place"],
      "properties": {
        "full_name": { "type": "string" },
        "role": { "type": "string" },
        "issue_date": { "type": "string", "format": "date" },
        "issue_place": { "type": "string" }
      }
    }
  }
}
```

Такий маніфест запікається в захищену область пам'яті контролера під час фінального заводського калібрування. Пристрій може транслювати свій сертифікаційний профіль через діагностичний порт або BLE-маяк, що дозволяє митним терміналам та органам ринкового нагляду проводити миттєву бездротову верифікацію автентичності сертифікаційних параметрів.
