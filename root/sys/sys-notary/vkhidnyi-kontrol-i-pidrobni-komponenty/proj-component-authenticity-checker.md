# ⚙️ Програмно-апаратний аналізатор вольт-амперних сигнатур напівпровідникових переходів

</preknowlist>

Коли партія з кількох тисяч мікроконтролерів, операційних підсилювачів або силових драйверів надходить на виробничий майданчик від незалежного дистриб'ютора чи брокера відкритого ринку, руйнівна хімічна декапсуляція кислотами дає стовідсоткову впевненість у топології кристала, але безповоротно знищує перевірений зразок. Звичайне функціональне тестування на програматорі чи тестовій платі здатне підтвердити лише те, що чіп відгукується на базові команди за кімнатної температури. Воно не виявляє прихованого перемаркування чіпа на вищий температурний діапазон, використання кристала іншої ревізії з меншою площею кремнію, деградації захисних ESD-структур після випаювання з відходів або монтажу кристала з дешевим бракованим кремнієм від неавторизованої фабрики.

Для швидкого, повністю неруйнівного та високочутливого вхідного контролю компонентів застосовують метод аналогового сигнатурного аналізу (Analog Signature Analysis, ASA), відомий також як метод зняття вольт-амперних сигнатур (Curve Tracer). Цей інженерний проект розглядає фізичні принципи формування сигнатур напівпровідникових переходів, схемотехніку вимірювального тракту, алгоритми цифрового аналізу геометрії кривих Ліссажу, компенсацію паразитних параметрів вимірювальної системи та завершену програмну реалізацію сигнатурного аналізатора на C99 і C++20.

## Фізичні основи аналогового сигнатурного аналізу

Метод аналогового сигнатурного аналізу ґрунтується на фундаментальній властивості будь-якої мікроелектронної схеми: кожен зовнішній вивід інтегральної схеми (ІС) фізично з'єднаний із внутрішньою напівпровідниковою структурою кристала через вбудовані елементи електростатичного захисту (Electrostatic Discharge, ESD), підкладкові діоди, захисні супресори або паразитні p-n переходи комплементарних транзисторів.

При цьому мікросхема під час вимірювання залишається повністю знеструмленою — напруга живлення на вивід `VDD` не подається. Тестування виконується шляхом прикладання до обраного вивода компонента змінного випробувального синусоїдального або трикутного сигналу низької амплітуди через послідовний прецизійний опір обмеження струму (випробувальний баласт):

```
+───────────────────────────────────────────────────────────────────────────+
| ПРИНЦИПОВА СХЕМА СИГНАТУРНОГО АНАЛІЗАТОРА (CURVE TRACER)                  |
|                                                                           |
|   Генератор тестового сигналу          DUT (Device Under Test)            |
|       V_gen(t) = V_pk · sin(ωt)             (Вивід чіпа)                 |
|            ○───────[ R_source ]──────┬──────────○ Pin_X                   |
|                                      │                                    |
|                                    [ADC_V]   ┌─────────────────┐          |
|                                      │       │ Внутрішні ESD   │          |
|                                      │       │ діоди кристала  │          |
|                                      │       │  ▲ D_up         │          |
|                                      │       │  │ (до VDD)     │          |
|                                      │       │  ▼ D_down       │          |
|                                      │       │    (до GND)     │          |
|                                      │       └─────────────────┘          |
|                                      │                  │                 |
|            ○─────────────────────────┴──────────────────○ Pin_GND        |
|           GND_ref                                                         |
+───────────────────────────────────────────────────────────────────────────+
```

Генератор формує періодичну напругу:

```
V_gen(t) = V_pk · sin(ω · t)      [тестова змінна напруга генератора]
```

де `V_pk` — пікова амплітуда тестової напруги (зазвичай обирається в діапазоні від 200 мВ до 10 В залежно від типу перевірки), а `ω = 2·π·f` — циклічна частота (типово від 10 Гц до 10 кГц).

Напруга безпосередньо на виводі тестованого компонента `V_dut(t)` вимірюється першим каналом аналого-цифрового перетворювача (АЦП). Струм `I_dut(t)`, що протікає через напівпровідниковий перехід вивода, розраховується за законом Ома через падіння напруги на відомому джерельному резисторі `R_source`:

```
I_dut(t) = (V_gen(t) - V_dut(t)) / R_source      [закон Ома для вимірювального кола]
```

Якщо відкласти миттєві значення напруги `V_dut(t)` по горизонтальній осі абсцис `X`, а миттєві значення струму `I_dut(t)` по вертикальній осі ординат `Y`, на екрані формується замкнена або розімкнена вольт-амперна траєкторія — сигнатура вивода:

1. **Ідеальний резистивний контакт (лінійна характеристика):** пряма лінія, нахил якої визначається опором каналу або навантаження `R = ΔV / ΔI`. Горизонтальна лінія відповідає повному обриву кола (`R = ∞`), вертикальна лінія — чистому короткому замиканню (`R = 0`).
2. **Напівпровідниковий p-n перехід (ESD-діод на землю або шину живлення):** за прямого зміщення струм експоненційно зростає при перевищенні порогової напруги відмикання діода `V_F` (близько 0.6–0.7 В для стандартного кремнію, 0.2–0.3 В для діодів Шотткі). За зворотного зміщення струм залишається близьким до нуля аж до напруги лавинного чи зенерівського пробою `V_BR`.
3. **Ємнісний перехід (паразитна ємність виводу, шини живлення або затвора MOSFET):** струм випереджає напругу на фазовий кут `φ = π / 2`. Траєкторія перетворюється на еліпс, площа якого пропорційна ємності `C` та частоті сигналу `ω`.
4. **Комбінована структура (реальний вивід ІС):** нелінійна крива, що складається з експоненційного коліна прямого діодного струму, вертикального коліна зворотного пробою супресора та розширення петлі внаслідок бар'єрної ємності p-n переходу `C_j`.

```
+───────────────────────────────────────────────────────────────────────────+
| ФОРМА ВОЛЬТ-АМПЕРНИХ СИГНАТУР РІЗНИХ ТИПІВ НАПІВПРОВІДНИКОВИХ СТРУКТУР    |
|                                                                           |
|   1. Обрив (Open)         2. КЗ (Short)           3. p-n перехід (Diode)  |
|         I                       I                       I                 |
|         │                       │  ▲                    │      ▲          |
|         │                       │  │                    │     ╱           |
|   ──────┼────── V         ──────┼──┼── V          ──────┼────╱─ V         |
|         │                       │  │                    │   V_F           |
|         │                       │  ▼                    │                 |
|                                                                           |
|   4. Ємність (Capacitor)  5. Резистор (Resistor)  6. ESD-кліп виводу ІС   |
|         I                       I                       I                 |
|       ╭─┴─╮                     │  ╱                    │    ▲ /          |
|      │  │  │                    │ ╱                     │   ( (           |
|   ───┼──┼──┼─── V         ──────┼╱───── V         ──────┼───) )── V       |
|      │  │  │                   ╱│                   ▲   │  V_F            |
|       ╰─┬─╯                   ╱ │                 ──┴───┘                 |
+───────────────────────────────────────────────────────────────────────────+
```

## Фізико-хімічні першопричини відмінності сигнатур у напівпровідниках

Пряма гілка вольт-амперної характеристики будь-якого p-n переходу підпорядковується фундаментальному рівнянню Шокла для ідеального напівпровідникового діода:

```
I(V) = I_s · (exp(q · V / (n · k · T)) - 1)      [рівняння Шокла]
```

де `I_s` — теоретичний струм насичення неосновних носіїв заряду, `q = 1.602 · 10⁻¹⁹ Кл` — елементарний електричний заряд електрона, `k = 1.380 · 10⁻²³ Дж/К` — стала Больцмана, `T` — абсолютна термодинамічна температура кристала в Кельвінах, а `n` — коефіцієнт неідеальності переходу (емісійний коефіцієнт, який для монокристалічного кремнію коливається в межах від 1.02 до 1.15 за домінування дифузійного струму і зростає до 1.8–2.0 при домінуванні струмів генерації-рекомбінації в збідненому шарі).

Струм теплового насичення `I_s` пропорційний фізичній площі металургійного переходу `A_junction` та концентрації легуючих домішок:

```
I_s = q · A_junction · ( (D_n · n_p0 / L_n) + (D_p · p_n0 / L_p) )      [струм насичення через площу кристала]
```

де `D_n, D_p` — коефіцієнти дифузії електронів та дірок, `L_n, L_p` — дифузійні довжини носіїв, а `n_p0, p_n0` — рівноважні концентрації неосновних носіїв.

Саме цей зв'язок пояснює колосальну чутливість аналогового сигнатурного аналізу до підробок:

1. **Площа кристала та кремнієвий масштаб (Die Area):** Якщо контрафактний виробник скопіював мікроконтролер чи підсилювач, використавши дешевший технологічний процес із меншою площею кремнію або спрощеними ESD-клітинами, площа переходу `A_junction` зменшується в 2–5 разів. Відповідно зменшується струм `I_s`. Згідно з рівнянням Шокла, для досягнення того самого струму в 1 мА напруга відмикання `V_F` у такого чіпа повинна зміститися вправо на величину:

```
ΔV_F = (n · k · T / q) · ln(A_orig / A_clone)      [зсув напруги через зміну площі кристала]
```

При зміні площі кристала вдвічі зсув прямої напруги становить від 18 до 25 мВ. Сучасний 16-бітний АЦП сигнатурного аналізатора має роздільну здатність за напругою близько 0.15 мВ, що робить виявлення зменшеного кристала гарантованим і миттєвим.

2. **Диференційний послідовний опір `r_d`:** Окрім власне p-n переходу, струм проходить через опір нейтральних областей кремнієвої підкладки (bulk resistance), опір перехідних контактних вікон металізації (vias contact resistance) та опір тонких золотих або мідних розварювальних дротів:

```
V_meas = V_junction(I) + I · (R_bulk + R_contact + R_wire)      [повна напруга на виводі]
```

У відновлених (recycled) чіпах, які зазнали термічного удару при випаюванні, або в кустарно розварених чіпах із тонкими алюмінієвими дротами замість золотих, паразитичний опір `R_series` зростає від типових 2–5 Ом до 25–80 Ом. На вольт-амперній сигнатурі це викликає помітний нахил верхньої вертикальної гілки діода праворуч.

3. **Фізика зворотного пробою та супресорів:** Захисні структури сучасних КМОН ІС містять спеціальні лавинні діоди (TVS) або біполярні n-p-n транзистори з плаваючою базою (Open-Base BJT), які працюють у режимі зворотного лавинного пробою або керованого відмикання (Snapback SCR). Зворотний пробій кремнію буває двох фізичних типів:
   - **Зенерівський тунельний пробій:** домінує при низьких напругах (`V_BR < 5.2 В`) у сильно легованих переходах, де квантово-механічне тунелювання електронів крізь вузький потенціальний бар'єр має негативний температурний коефіцієнт напруги (`dV_BR / dT < 0`).
   - **Лавинний пробій:** домінує при напругах `V_BR > 6.0 В`, де носії розганяються електричним полем і викликають ударну іонізацію атомів ґратки. Лавинний пробій має позитивний температурний коефіцієнт (`dV_BR / dT > 0`), оскільки амплітуда теплових коливань кристалічної ґратки зростає і скорочує довжину вільного пробігу електронів.
   Якщо дешевий клон замість прецизійного зенерівського діода з напругою 5.1 В містить звичайний слаболегований p-n перехід із лавинним пробоєм при 12 В, сигнатура чіпа в 3-му квадранті розкривається зовсім інакше.

4. **Бар'єрна та дифузійна ємність:** За зворотного зміщення p-n перехід поводиться як плоский конденсатор зі збідненим діелектричним шаром:

```
C_j(V) = C_j0 / (1 - V_rev / V_bi)^m      [бар'єрна ємність збідненого шару]
```

де `C_j0` — ємність при нульовому зміщенні, `V_bi` — контактна різниця потенціалів (близько 0.8–0.9 В для Si), а `m` — коефіцієнт градієнта легування (`m = 0.5` для різкого переходу, `m = 0.33` для плавного дифузійного переходу). Зняття сигнатури на змінному струмі частотою 1–10 кГц збуджує цю ємність, утворюючи еліптичну розбіжність фази, площа якої прямо пропорційна внутрішній ємності піна. У підроблених компонентах іншого технологічного покоління ємність відрізняється на 30–200%.

## Нелінійний гармонійний аналіз струму переходів

При збудженні чистою гармонійною синусоїдальною напругою `V_gen(t) = V_pk · sin(ωt)` струм через напівпровідниковий перехід спотворюється внаслідок сильної нелінійності вольт-амперної характеристики. Розклад струму в тригонометричний ряд Фур'є дає нескінченний спектр гармонік:

```
I_dut(t) = I_0 + I_1 · sin(ωt + φ_1) + I_2 · sin(2ωt + φ_2) + I_3 · sin(3ωt + φ_3) + ...      [ряд Фур'є нелінійного струму]
```

Амплітуди вищих гармонік `I_2, I_3, I_4` та їхні фазові кути `φ_k` є унікальними відбитками фізичної природи переходу:
- **Парні гармоніки (`I_2, I_4`):** виникають виключно через асиметрію провідності переходу в прямому та зворотному напрямках (однопівперіодне випрямлення). Що сильніша асиметрія, то вища амплітуда другої гармоніки.
- **Непарні гармоніки (`I_3, I_5`):** відображають ступінь насичення та крутизну коліна характеристики.

Сумарний коефіцієнт гармонійних спотворень (Total Harmonic Distortion, THD) струму:

```
THD_I = √( I_2² + I_3² + I_4² + ... ) / I_1      [коефіцієнт гармонік струму]
```

Для оригінальних субмікронних чіпів із різким градієнтним переходом `THD_I` при тестовій напрузі 2.0 В становить близько `0.65–0.78`. Для застарілих клонів або повільних технологічних процесів із дифузійно-розмитими переходами `THD_I` знижується до `0.40–0.52`. Програмний розрахунок швидкого перетворення Фур'є (FFT) над масивом точок струму дозволяє додати спектральний векторний індикатор до паспорта автентичності кожного піна.

## Теплова безпека та динамічне нагрівання напівпровідника

Критичною вимогою до методології вхідного контролю є абсолютна неруйнівність випробувального процесу. Прикладання тестового сигналу не повинно викликати локального теплового пробою, електроміграції металізації кристала або лавинної деградації тонких затворних діелектриків.

Миттєва електрична потужність, що виділяється в структурі напівпровідникового переходу:

```
P_inst(t) = V_dut(t) · I_dut(t)      [миттєва теплова потужність]
```

Оскільки максимальна потужність генератора досягається при узгодженні навантаження `R_dut = R_source`, теоретичний піковий максимум потужності обмежений схемотехнічно:

```
P_max = V_pk² / (4 · R_source)      [максимальна потужність у колі]
```

При стандартних параметрах тестування (`V_pk = 5.0 В`, `R_source = 1000 Ом`) максимальна потужність становить лише:

```
P_max = 25.0 / 4000.0 = 6.25 мВт      [безпечний ліміт розсіювання]
```

Середня інтегральна потужність за один період синусоїди для діодної структури не перевищує `1.2–1.8 мВт`. Динамічне підвищення температури мікропереходу площею 100 мкм² у кремнієвій підкладці за час одного циклу вимірювання (10 мс) розраховується через тепловий імпеданс:

```
ΔT_junction = P_avg · Z_th(t) < 0.05 °C      [термічний перегрів переходу]
```

Такий мізерний перегрів повністю виключає термодеструкцію напівпровідникових структур, роблячи аналоговий сигнатурний аналіз цілком безпечним навіть для надчутливих напівпровідникових структур із проектними нормами менше 16 нм.

## Сигнатури спеціалізованих функціональних вузлів

Кожен тип функціонального піна мікросхеми формує унікальний геометричний патерн:

1. **Входи з внутрішньою підтяжкою (Internal Pull-up / Pull-down):** Вбудований полікремнієвий або канальний резистор опором 30–50 кОм підключений паралельно до захисного діода. На сигнатурі горизонтальна ділянка закритого діода отримує чіткий лінійний нахил, відповідний опору `R_pull`. Якщо в підробленому чіпі підтяжка реалізована слабким струмовим джерелом на польовому транзисторі, сигнатура показує характерне горизонтальне насичення струму замість лінійного нахилу.
2. **Входи підвищеної напруги (5V-tolerant inputs у чіпах 3.3 В):** У звичайних КМОН входах верхній захисний діод `D_up` анодом з'єднаний із виводом, а катодом — із шиною `VDD = 3.3 В`. У 5V-tolerant виводах цей діод відсутній (інакше подача 5 В викликала б прямий струм у шину 3.3 В). Замість нього встановлюється спеціальний зворотно-зміщений n-p-n біполярний транзистор або послідовний стек діодів. На сигнатурі верхнє діодне коліно при напрузі вище +0.7 В повністю відсутнє аж до напруги пробою +8.5 В. Якщо шахраї замість 5V-tolerant чіпа встановили дешевий кристал без підтримки 5 В, сигнатура миттєво показує наявність діода до 3.3 В.
3. **Виходи LDO та внутрішні фільтри ядра (VCAP / VDD_CORE):** Ці виводи з'єднані з внутрішньою шиною живлення процесорного ядра через потужні інтегровані конденсатори розв'язки на кристалі (Decoupling on-chip capacitors) ємністю сотні пікофарад. На частотах 1–5 кГц сигнатура утворює широкий еліпс із помітним асиметричним викривленням за рахунок паразитних діодів n-well кишень.

## Схемотехнічна архітектура сигнатурного аналізатора

Щоб забезпечити метрологічну достовірність та повторюваність вимірювань, апаратна частина аналізатора будується за прецизійною триканальною схемою:

```
+───────────────────────────────────────────────────────────────────────────+
| СХЕМОТЕХНІКА АНАЛОГОВОГО ВИМІРЮВАЛЬНОГО ТРАКТУ СИГНАТУРНОГО АНАЛІЗАТОРА   |

|   │ 10-10000 Гц│          │ [R1] 100 Ом   │     │ X0 ──○─── Pin 1 (DUT) │ |
|   │ 0.2 - 10 В ├─────────►│ [R2] 1 кОм    ├───► │ X1 ──○─── Pin 2 (DUT) │ |
|   │ Синус/Пила │          │ [R3] 10 кОм   │     │ X2 ──○─── Pin 3 (DUT) │ |
|   └────────────┘          │ [R4] 100 кОм  │     │ ...  ...  ...         │ |
|                           └───────┬───────┘     │ Xn ──○─── Pin n (DUT) │ |
|                                   │             └───┬───────────────────┘ |
|                                   ▼                 │                     |
|                           [Sense Amplifier]         │ (Kelvin Sensing)    |

|                                   │             ADS8354 (16 біт, 1 MSPS)  |

+───────────────────────────────────────────────────────────────────────────+
```

1. **Генератор тестового сигналу:** Реалізується на базі цифрового синтезатора прямого синтезу (Direct Digital Synthesis, DDS) або швидкісного 12-бітного ЦАП мікроконтролера з частотою дискретизації не менше 100 квиб/с. Вихідний сигнал пропускається крізь активний низькочастотний фільтр Баттерворта 4-го порядку для повного придушення вищих гармонік дискретизації, які можуть викликати паразитний резонанс індуктивності виводів чіпа.
2. **Прецизійний комутатор діапазонів струму:** Блок джерельних баластних резисторів містить чотири калібровані прецизійні резистори (100 Ом, 1 кОм, 10 кОм, 100 кОм) із класом точності 0.05% та температурним коефіцієнтом опору (ТКС) не гірше 5 ppm/°C. Перемикання діапазонів виконується малосигнальними твердотільними реле PhotoMOS або ключами з ультранизьким опором у відкритому стані:
   - **Діапазон 100 Ом (Low-Z):** використовується для силових виводів, стабілізаторів напруги, ключів MOSFET, обмоток індуктивностей та перевірки низькоомних захисних шин.
   - **Діапазон 1 кОм (Medium-Z):** базовий діапазон для більшості стандартних цифрових ліній вводу-виводу (GPIO), шин SPI, I2C, UART, ліній скидання та тактування.
   - **Діапазон 10 кОм (High-Z):** оптимізований для аналогових входів АЦП/ЦАП, високоомних входів ОУ та виводів із низькими струмами витоку.
   - **Діапазон 100 кОм (Ultra-Z):** призначений для виявлення деградації затворних оксидів MOSFET (Gate Oxide Breakdown) та витоків ізоляції між сусідніми виводами понад 10 МОм.
3. **Чотирипровідна схема вимірювання Кельвіна (Kelvin Sensing):** На відміну від простих лабораторних випробувачів, промисловий сигнатурний аналізатор використовує роздільні силові (Force) та потенційні (Sense) лінії комутації безпосередньо до контактних пружин ZIF-панелі (Zero Insertion Force socket). Це повністю виключає опір комутаційних ключів матриці та дротів шлейфу з вимірюваного значення напруги на напівпровіднику.
4. **Синхронний двоканальний АЦП:** Для запобігання фазового спотворення сигнатури канали вимірювання напруги `V` та струму `I` оцифровуються одночасно за допомогою синхронного SAR-АЦП (наприклад, ADS8354 або вбудованого здвоєного АЦП STM32H7 у режимі Dual Simultaneous Sampling).

## Трасування друкованої плати та захист від струмів витоку

При вимірюванні струмів витоку на рівні одиниць наноампер звичайна друкована плата з діелектриком FR-4 стає джерелом критичних похибок через поверхневі струми витоку (Surface Leakage Currents). При відносній вологості повітря 60–70% на поверхні маски плати утворюється мономолекулярна плівка вологи, опір якої між сусідніми доріжками може впасти до `10¹⁰–10¹¹ Ом`. При тестовій напрузі 10 В це створює паразитний струм до 100 нА, що на два порядки перевищує струм витоку якісного КМОН-входу.

Для нейтралізації цього ефекту в схемотехніці аналізатора застосовують охоронні кільця (Guard Rings):

```
+───────────────────────────────────────────────────────────────────────────+
| ПРИНЦИП РОБОТИ ОХОРОННОГО КІЛЬЦЯ (GUARD RING) НА ДРУКОВАНІЙ ПЛАТІ         |
|                                                                           |
|   Високоомна лінія Sense          Охоронне кільце Guard                   |
|   (Напруга V_in = 5.000 В)        (Буфер з напругою V_guard = 5.000 В)    |
|        ┌──────────┐                     ┌──────────┐                      |
|        │  Trace   │ ◄── ΔV = 0.000 В ──►│  Guard   │                      |
|        │  Sense   │   I_leak = 0.0 пА   │  Ring    │                      |
|        └──────────┘                     └────┬─────┘                      |
|                                              │                            |
|                                         [Буфер ОУ]                        |
|                                         (Unity Gain)                      |
+───────────────────────────────────────────────────────────────────────────+
```

Навколо всіх вимірювальних трас розводиться мідний провідник, на який за допомогою прецизійного повторювача напруги на операційному підсилювачі подається точно той самий потенціал, що й на вимірювальній лінії (`V_guard = V_sense`). Оскільки різниця потенціалів між вимірювальним провідником та охоронним кільцем становить `ΔV = 0.0 В`, паразитний струм витоку між ними строго дорівнює нулю за законом Ома:

```
I_leak = ΔV / R_surface = 0.0 В / R_surface = 0.0 пА      [повна нейтралізація поверхневого витоку]
```

## Протоколи калібрування вимірювальних щупів та компенсація паразитної реактивності (OSL De-embedding)

При аналізі напівпровідникових переходів на високих частотах (понад 1 кГц) або при вимірюванні струмів витоку менше 10 нА паразитна ємність з'єднувальних коаксіальних кабелів (типово 70–100 пФ/м), індуктивність вимірювальних щупів (10–25 нГн/см) та перехідний опір контактних гострих голок ZIF-панелі (15–50 мОм) суттєво спотворюють форму вольт-амперної кривої. Без апаратно-програмної компенсації паразитна ємність створює штучне фазове розширення петлі Ліссажу, маскуючи справжні бар'єрні параметри кристала.

Для виключення впливу вимірювальної оснастки застосовується триточковий протокол калібрування OSL (Open-Short-Load Calibration за стандартом IEEE 370):

1. **Калібрування холостого ходу (Open Standard):** Вимірювальні щупи розімкнені у повітрі. Вимірюється комплексна паразитна провідність кабелів, комутатора та контактної панелі:
```
Y_open(ω) = G_open + j · ω · C_open      [паразитна провідність холостого ходу]
```
де `C_open` — сумарна міжелектродна та монтажна ємність вимірювального тракту (типово 12–28 пФ).

2. **Калібрування короткого замикання (Short Standard):** Кінчики щупів замикаються на поліровану позолочену мідну калібрувальну пластину. Вимірюється залишковий послідовний імпеданс:
```
Z_short(ω) = R_short + j · ω · L_short      [залишковий імпеданс короткого замикання]
```
де `R_short` — опір комутаційних реле та дротів, а `L_short` — паразитна петльова індуктивність.

3. **Калібрування узгодженого навантаження (Load Standard):** До щупів підключається прецизійний безіндуктивний тонкоплівковий SMD-резистор `R_cal = 1000.00 ± 0.05 Ом` з ТКС не гірше 2 ppm/°C. Програмне ядро верифікує точність фазового зсуву та масштабних коефіцієнтів підсилювачів струму та напруги.

Математичне деімбедингування (De-embedding) істинного імпедансу тестованого напівпровідника `Z_dut` із виміряного загального імпедансу `Z_meas`:

```
Y_dut(ω) = (Y_meas(ω) - Y_open(ω)) / (1 - Z_short(ω) · (Y_meas(ω) - Y_open(ω)))      [формула повного деімбедингування]
```

Істинний струм напівпровідникового переходу в часовій області обчислюється векторним відніманням струму зміщення ємності оснастки:

```
I_dut_true(t) = I_meas(t) - C_open · (dV_meas(t) / dt)      [компенсація ємнісного струму зміщення]
```

Завдяки цьому алгоритму чутливість аналізатора до внутрішньої бар'єрної ємності p-n переходу зростає до 0.2 пФ, дозволяючи надійно розрізняти субмікронні технологічні норми напівпровідникових фабрик.

## Математичний апарат фільтрації та розпізнавання патернів

Отриманий із АЦП масив дискретних вибірок піддається багаторівневій математичній обробці перед класифікацією:

### 1. Цифрове згладжування фільтром Савіцького-Голея

Класичне ковзне середнє згладжує високочастотний шум АЦП, проте неминуче «заокруглює» гострий кут відмикання діода, спотворюючи виміряну порогову напругу `V_F`. Щоб зберегти вищі похідні сигналу без спотворення форми коліна, застосовується поліноміальний фільтр Савіцького-Голея:

```
V_filt[k] = (1 / 35) · ( -3·V[k-2] + 12·V[k-1] + 17·V[k] + 12·V[k+1] - 3·V[k+2] )      [фільтр Савіцького-Голея 2-го порядку]
```

Цей фільтр мінімізує середньоквадратичну похибку апроксимації локального відрізка кривої параболою, повністю зберігаючи точні координати точки перегину експоненти.

### 2. Нормалізація координат та фазове вирівнювання

Для усунення масштабності напруга та струм приводяться до безрозмірних координат у просторі `[-1.0 .. +1.0]`:

```
x[k] = V[k] / V_scale      [нормалізація напруги]
y[k] = I[k] / I_scale      [нормалізація струму]
```

### 3. Алгоритм динамічного трансформування шкали (DTW)

Для компенсації температурного дрейфу та незначної асинхронності вибірок будується матриця локальних відстаней `D` розмірністю `N × M`:

```
D[i, j] = √( (x_uut[j] - x_gold[i])² + (y_uut[j] - y_gold[i])² )      [локальна метрика відхилення точок]
```

Кумулятивна матриця трансформації `γ[i, j]` обчислюється динамічним програмуванням:

```
γ[i, j] = D[i, j] + min( γ[i-1, j], γ[i, j-1], γ[i-1, j-1] )      [кумулятивна функція вартості шляху DTW]
```

Нормована відстань DTW:

```
DTW_score = γ[N-1, M-1] / (N + M)      [інтегральний показник подібності сигнатур]
```

Якщо `DTW_score < 0.05`, сигнатура вважається автентичною. Якщо `DTW_score > 0.08`, кристал чіпа гарантовано має відмінну напівпровідникову топологію.

## Багатовимірна статистика та відстань Махаланобіса

При масовому вхідному контролі компонентів виникає природний технологічний розкид параметрів кремнієвих пластин від партії до партії (Fab Lot-to-Lot Variations). У межах однієї оригінальної серії чіпів напруга `V_F` може коливатися на ±15 мВ, а динамічний опір `r_d` — на ±5%.

Просте обмеження допуску жорсткими евклідовими рамками призводить або до хибного бракування оригінальних партій з іншої кремнієвої пластини, або до пропуску якісних клонів. Для подолання цього обмеження застосовується багатовимірна відстань Махаланобіса (Mahalanobis Distance):

```
D_M(x) = √( (x - μ)ᵀ · Σ⁻¹ · (x - μ) )      [відстань Махаланобіса]
```

де `x = [V_F, r_d, I_leak, C_j, THD]ᵀ` — 5-вимірний вектор параметрів виводу тестованого компонента, `μ` — вектор середніх значень параметрів еталонної вибірки оригінальних чіпів, а `Σ` — коваріаційна матриця розмірністю `5 × 5`, що враховує взаємну кореляцію параметрів технологічного процесу:

```
+───────────────────────────────────────────────────────────────────────────+
| ПОРІВНЯННЯ ЄВКЛІДОВОГО ДОПУСКУ ТА КОВАРІАЦІЙНОГО ЕЛІПСОЇДА МАХАЛАНОБІСА   |
|                                                                           |
|   Диференційний опір r_d                                                  |
|         ▲                                                                 |
|         │              ╭──────────────╮ ◄── Коваріаційний еліпсоїд        |
|         │             ╱   ●    ●     ╱      Махаланобіса (D_M ≤ 3σ)       |
|         │            ╱  ●   ●   ●   ╱                                     |
|         │    ┌──────╱──────────────╱──────┐ ◄── Жорсткий прямокутний      |
|         │    │     ╱  ●   ●   ●   ╱   ●   │     евклідовий допуск         |
|         │    │    ╱      ●   ●   ╱        │     (дає хибний PASS)         |
|         │    │   ╰──────────────╯         │                               |
|         │    │   ▲ Підробка з порушеною   │                               |
|         │    │     кореляцією V_F та r_d  │                               |
|         │    └────────────────────────────┘                               |
|         └──────────────────────────────────────► Напруга відмикання V_F  |
+───────────────────────────────────────────────────────────────────────────+
```

Якщо підробний кристал має зсув параметрів уздовж головної осі еліпсоїда (природний температурний або легуючий зсув), відстань Махаланобіса залишається низькою (`D_M < 3.0`). Якщо ж у кристала-клона порушена кореляція між товщиною оксиду та питомим опором бази (точка виходить за межі вузького еліпсоїда), відстань Махаланобіса стрімко зростає (`D_M > 6.0`), надійно детектуючи фальсифікат навіть у тому випадку, коли окремі параметри формально вкладаються в табличні межі даташиту.

## Інтеграція з базою Golden Signatures та векторне кластеризування профілів

Для промислового вхідного контролю за стандартом AS6081 критично мати централізовану та захищену базу еталонних сигнатур (Golden Signatures Database). Кожен запис профілю компонента в системі містить багаторівневий набір даних:

1. **Ієрархічні метадані походження:** Номер кремнієвої пластини (Wafer Lot ID), сертифікат походження заводу (OCM CoC), тип корпусу та ревізія топології кристала (Mask Stepping).
2. **Багаточастотний масив вольт-амперних характеристик:** Сигнатури знімаються на наборі стандартизованих тестових частот (10 Гц, 100 Гц, 1 кГц, 10 кГц) та з трьома значеннями джерельного баласту (100 Ом, 1 кОм, 10 кОм). Це дозволяє одночасно зафіксувати як низькоомну резистивну гілку, так і високочастотну бар'єрну ємність.
3. **Трисигмовий динамічний коридор допуску (3σ Boundary Envelopes):** Для кожної дискретної точки кривої `k` зберігаються середнє значення струму `μ_I[k]` та дисперсія `σ_I²[k]`, розраховані за репрезентативною вибіркою з щонайменше 20 сертифікованих оригінальних чіпів із трьох різних виробничих партій.
4. **Криптографічний хеш-підпис (Ed25519 / SHA-256):** Кожен еталонний файл підписується закритим ключем лабораторії надійності, що унеможливлює несанкціоноване підкручування допусків операторами або постачальниками.

Вектор ознак виводу формується у 6-вимірному просторі параметрів:

```
F_pin = [ V_F, r_d, I_leak, C_j, THD_I, DTW_score ]ᵀ      [вектор ознак напівпровідникового переходу]
```

Для детекції змішаних партій (Mixed Lots), коли брокер досипає у котушку 10–15% дешевих клонів серед оригінальних чіпів, модуль аналітики застосовує алгоритм просторової кластеризації DBSCAN (Density-Based Spatial Clustering of Applications with Noise). Якщо множина векторів вибірки замість одного компактного кластера розділяється на дві ізольовані групи центроїдів або містить викиди з відстанню Махаланобіса `D_M > 4.5`, партія миттєво маркується як сфальсифікована без потреби руйнування компонентів.

## Інженерні пастки, крайові випадки та метрологія

Під час проектування та експлуатації програмно-апаратних комплексів сигнатурного аналізу виникає низка специфічних апаратних і метрологічних факторів, нехтування якими призводить до хибних спрацьовувань або пропуску витонченого контрафакту:

### 1. Температурний дрейф напівпровідникового переходу

Пряма напруга відмикання кремнієвого p-n переходу `V_F` має виражений негативний температурний коефіцієнт:

```
dV_F / dT ≈ -2.0 мВ / °C      [температурний коефіцієнт напруги діода]
```

Якщо еталонна база знімалася в кондиційованій лабораторії за температури +20 °C, а партія тестується на складі за температури +30 °C, зміщення напруги становить близько `-20 мВ` (-3% від `V_F`). Без температурної компенсації це зміщення може перевищити поріг допуску й спричинити хибне відбракування партії. Програмний комплекс повинен вимірювати температуру корпусу мікросхеми за допомогою пірометра або вбудованого термодатчика та виконувати компенсаційне масштабування кривої:

```
V_corr = V_meas + 0.002 · (T_meas - 20.0)      [температурна корекція сигнатури]
```

### 2. Паразитна ємність вимірювальних трас та індуктивність щупів

Використання довгих коаксіальних кабелів між комутатором і тестовою контактною колодкою вносить власну ємність монтажу (близько 50–100 пФ/м). На частотах випробувального сигналу понад 1 кГц ця паразитна ємність створює штучне розширення фазової петлі Ліссажу, маскуючи справжню ємність ESD-структури чіпа.

Для усунення цього ефекту обов'язково реалізується процедура двоточкового калібрування перед кожною вимірювальною сесією (Open/Short Calibration):
- **Калібрування холостого ходу (Open Cal):** зняття сигнатури з порожньої колодки без мікросхеми та збереження масиву паразитної ємнісної провідності `Y_open(ω)`.
- **Калібрування короткого замикання (Short Cal):** замикання контактів колодки еталонною пластиною та збереження опору контактних переходів `Z_short`.

Під час тестування програмне ядро виконує векторне віднімання паразитної провідності:

```
I_dut_true(t) = I_meas(t) - I_open(t)      [компенсація ємності кабелів]
```

### 3. Рекомбінаційна релаксація та перемикання високошвидкісних інтерфейсів

У сучасних високошвидкісних трансиверах (наприклад, диференційні лінії PCIe 4.0/5.0, USB 3.2, 10GbE) вхідні ESD-структури побудовані на базі тиристорних діодних мостів із наднизькою ємністю (Ultra-low capacitance ESD, `C_esd < 0.15 пФ`) та зворотною динамічною релаксацією.

При випробуванні таких ліній на частотах понад 5 кГц час відновлення зворотного опору (Reverse Recovery Time, `t_rr`) призводить до виникнення характерних динамічних «викидів» струму на вершині синусоїди. Сигнатурний аналізатор повинен адаптувати частоту розгортки: для швидкісних інтерфейсів частота знижується до 50–100 Гц для вимірювання квазістатичної характеристики, а для силових ключів та підтягувальних резисторів підвищується до 1–2 кГц для збільшення роздільної здатності за ємністю.

### 4. Диференційні пари та плаваючі вузли (Floating Substrate)

Особливу увагу слід звертати на ізольовані або симетричні диференційні входи (наприклад, лінії LVDS або входи прецизійних інструментальних підсилювачів), де захисні діоди включені зустрічно-паралельно між лініями `IN+` та `IN-` без прямого прив'язування до шини GND. Тестування таких пінів у стандартному режимі `Pin-to-GND` показує лише високий опір ізоляції підкладки.

Програмно-апаратний комплекс повинен підтримувати диференційне сканування, коли тестовий сигнал подається безпосередньо між парою `IN+` та `IN-`, формуючи класичну двонаправлену симетричну сигнатуру зустрічних діодів.

## Детальний розбір реальних промислових кейсів виявлення контрафакту

Розглянемо чотири характерні кейси виявлення підробок із практики лабораторій вхідного контролю, де стандартний функціональний контроль пропустив брак, а сигнатурний аналізатор зафіксував контрафакт на перших секундах тестування:

### Кейс 1: Підробка популярних 32-бітних мікроконтролерів STM32F103C8T6

Мікроконтролери STM32F103C8T6 на ядрі ARM Cortex-M3 є однією з найчастіших мішеней для клонування. На відкритому ринку зустрічаються десятки клонів від неавторизованих виробників (CS32F103, APM32, HK32, GD32), які шахраї шліфують, наносять шар Blacktop та лазером гравіюють оригінальний логотип STMicroelectronics та маркування `STM32F103C8T6`.

Більшість таких клонів успішно проходять базовий тест програматором ST-Link: читають Device ID `0x410`, дозволяють прошити тестову програму та миготять світлодіодом. Проте в реальному виробі вони виходять з ладу через іншу напругу живлення флеш-пам'яті, підвищений струм споживання в режимі Stop/Standby та зрив генерації високочастотного кварцового генератора HSE.

**Результати сигнатурного аналізу пінів OSC_IN та OSC_OUT:**
1. Оригінальний STM32F103 містить на виводах резонатора інтегровані резистивні структури зворотного зв'язку інвертора Пірса та симетричні діоди з бар'єрною ємністю `C_j ≈ 4.5 пФ` при `V_F = 0.68 В`.
2. Клон HK32/CS32 містить спрощену схему без вбудованого резистора з ємністю `C_j ≈ 1.2 пФ` та напругою діода `V_F = 0.54 В`.
3. Сигнатура виводів OSC_IN/OSC_OUT у клона виглядає як суттєво вужча петля з іншим кутом нахилу діодного коліна. Метрика розбіжності евклідової площі становить `D_area = 0.28` (28% відхилення при допустимих 3%), що однозначно ідентифікує чужорідний кристал.

### Кейс 2: Фальсифікація прецизійних малошумних ОУ OPA2134 (перемаркування NE5532)

Аудіофільські та прецизійні операційні підсилювачі OPA2134 з польовими транзисторами на вході (FET Input) коштують у 5–8 разів дорожче за дешеві біполярні підсилювачі NE5532 або LM358. Шахраї беруть старі запаси NE5532, спилюють верхній шар компаунду та гравіюють маркування OPA2134.

Якщо такий підсилювач перевірити простим генератором синусоїди на частоті 1 кГц, він посилює сигнал і виглядає робочим. Але при встановленні у високоомний тракт вимірювального датчика схема перестає працювати через вхідний струм зсуву: в OPA2134 струм становить `I_bias = 5 пА`, а у підробленого NE5532 — `I_bias = 200 нА` (різниця у 40 000 разів).

**Результати сигнатурного аналізу входів `IN+` та `IN-`:**
1. В оригінального OPA2134 польові транзистори затвора JFET мають захисні діоди наднизького витоку. На діапазоні 100 кОм сигнатура входу являє собою чисту горизонтальну лінію з крихітною ємнісною петлею (`C_j ≈ 2 пФ`, `I_leak < 10 нА` при 5 В).
2. У фальсифікованого біполярного NE5532 на вході стоять відкриті p-n переходи емітерів BJT-транзисторів із зустрічно-паралельними захисними діодами між базами. Сигнатура на діапазоні 1 кОм демонструє два зустрічних діодних коліна при напругах `+0.7 В` та `-0.7 В`, а струм витоку на 5 В перевищує 500 мкА.
3. Сигнатурний аналізатор відкидає таку партію за 100 мілісекунд, класифікуючи виводи як `VERDICT_SUSPECT_REMARK`.

### Кейс 3: Відновлені силові MOSFET (E-waste pull IRFP460)

Силові високовольтні транзистори IRFP460 (500 В, 20 А) часто збираються з відпрацьованих промислових блоків живлення та інверторів на звалищах електроніки в Китаї та Індії. Транзистори випаюють газовими пальниками, шліфують фланці ТО-247 на абразивних кругах для видалення слідів пайки та перелуджують виводи свинцевим припоєм.

Термічний удар при полум'яному демонтажі руйнує крихкий оксид кремнію `SiO2` під затвором транзистора, викликаючи появу локальних тунельних мікродефектів.

**Результати сигнатурного аналізу виводів Gate-Source та Drain-Source:**
1. Оригінальний IRFP460 має вхідну ємність затвора `C_iss ≈ 4200 пФ`. На частоті 1 кГц при амплітуді 5 В сигнатура пари Gate-Source утворює ідеальний симетричний широко відкритий еліпс без резистивного нахилу (`R_leak > 100 МОм`). Вбудований боді-діод Drain-Source має пряме падіння `V_F = 0.85 В` при 10 мА та нульовий витік у закритому стані.
2. Відновлений транзистор після перегріву показує деградацію затвора: еліпс сильно нахилений праворуч через паразитний струм витоку через мікротріщини оксиду (`R_leak ≈ 80 кОм`, `I_leak = 60 мкА`). Боді-діод має закруглене, нечітке коліно з підвищеним диференційним опором `r_d = 45 Ом` замість 8 Ом через деградацію омичних контактів кристала до мідної підкладки.
3. Аналізатор миттєво відхиляє партію з вердиктом `VERDICT_DAMAGED_ESD` / `VERDICT_SUSPECT_REMARK`, рятуючи виробництво від масового вибуху силових ключів під час першого ж увімкнення блоків під навантаженням.

### Кейс 4: Фальсифікація супервізорів живлення та джерел опорної напруги TL431

Регульовані стабілізатори напруги TL431 є наймасовішими компонентами систем живлення. Підробні варіанти виготовляються на застарілих пластинах із сильним технологічним розкидом напруги внутрішнього забороненого шару (Bandgap Reference).

Оригінальний TL431 містить прецизійну схему забороненої зони Брокау (Brokaw Bandgap Cell) з номінальною напругою `Vref = 2.495 В` та дрейфом не більше 50 ppm/°C. Дешеві підробки використовують простий стабілітрон із діодним компенсатором, напруга якого дрейфує на сотні мілівольт при зміні температури.

**Результати сигнатурного аналізу виводів Ref-Anode та Cathode-Anode:**
1. Сигнатура пари Ref-Anode оригінального чіпа на частоті 500 Гц демонструє різкий пробій при напрузі строго `2.495 ± 0.010 В` із майже вертикальним диференційним опором `r_d < 0.2 Ом`.
2. Підроблений чіп показує розмите коліно при напрузі від 2.2 В до 2.8 В із високим динамічним опором `r_d ≈ 12–25 Ом` та сильним гістерезисом фази через повільні поверхневі пастки діелектрика.
3. Евклідове відхилення між еталоном та UUT перевищує 35%, що автоматично маркує партію як непридатну до встановлення у високонадійні джерела живлення.

## Статистичні плани вибіркового контролю за ANSI/ASQ Z1.4

Для великих виробничих партій компонентів (наприклад, 10 000 — 50 000 штук у стрічках на котушках) тестування 100% виробів може вимагати значного часу. У таких випадках сигнатурний контроль інтегрується у статистичну схему приймального контролю за стандартом ANSI/ASQ Z1.4 (еквівалент ISO 2859-1 та MIL-STD-105E):

1. **Визначення обсягу вибірки:** Залежно від розміру лоту та обраного рівня контролю (типово General Inspection Level II) обирається літерний код вибірки (Sample Size Code Letter). Наприклад, для партії 10 000 мікросхем літерний код `L` встановлює обсяг вибірки `n = 200` штук.
2. **Рівень прийнятної якості (AQL):** Для критичних аерокосмічних, автомобільних та оборонних систем встановлюється рівень дефектності `AQL = 0.65%` або план із нульовим допустимим браком (Zero Acceptance Number, `C = 0` за стандартом Squeglia). Якщо хоча б один компонент із 200 вибіркових зразків демонструє невідповідність сигнатури кремнієвого кристала (`Failed = 1`), вся партія з 10 000 штук негайно бракується, маркується червоними ярликами та направляється на обов'язкову руйнівну кислотну декапсуляцію для юридичного оформлення претензії.
3. **Кластеризація змішаних партій (Mixed Lot Detection):** Шахраї часто змішують усередині однієї заводської котушки 85% оригінальних компонентів і 15% дешевих клонів. Простий вибірковий тест 5–10 штук може випадково потрапити на оригінальні зразки й пропустити підробку. Статистичний модуль аналізатора будує двовимірну карту кластерів методом DBSCAN: якщо вибірка розпадається на два ізольовані центроїди, партія однозначно класифікується як змішаний фальсифікат.
4. **Автоматична паспортизація в MES/PLM:** Програмне ядро сигнатурного аналізатора автоматично генерує цифровий криптографічно підписаний XML/JSON протокол контролю з повним масивом сирих кривих, прив'язаним до серійного номера котушки та номера лоту. Це формує юридично неспростовний доказ якості вхідної сировини для сертифікаційного технічного файлу виробу.

## Протокол створення та валідації еталонної бази (Golden Database Protocol)

Надійність сигнатурного аналізатора безпосередньо залежить від чистоти та достовірності бази еталонних профілів (Golden Signatures Database). Помилка у збереженні еталона призведе до систематичного пропуску браку або хибного відбракування якісних партій.

Стандартний інженерний протокол створення еталонного профілю включає такі етапи:
1. **Верифікація походження еталонних зразків:** Еталонні чіпи замовляються виключно через офіційні франчайзингові канали виробника (наприклад, Arrow, Avnet, DigiKey, Mouser) із прямим сертифікатом відповідності від заводу-виготовлювача (Factory Original Certificate of Conformance, CoC) та повною простежуваністю ланцюга постачання до номеру кремнієвої пластини (Wafer Lot ID).
2. **Статистичне усереднення вибірки з 10–20 зразків:** Знімаються сигнатури всіх виводів для щонайменше 10 оригінальних мікросхем із двох різних заводських лотів. Для кожної точки `k` обчислюється середнє арифметичне значення напруги `μ_V[k]` та струму `μ_I[k]`, а також середньоквадратичне відхилення `σ_V[k]` та `σ_I[k]`.
3. **Побудова трисигмового коридору допуску (3σ Envelope):** Верхня та нижня межі допустимих відхилень розраховуються за правилом трьох сигм:

```
V_max[k] = μ_V[k] + 3 · σ_V[k]      [верхня межа 3-сигма коридору]
V_min[k] = μ_V[k] - 3 · σ_V[k]      [нижня межа 3-сигма коридору]
```

Це гарантує, що 99.73% оригінальних компонентів із наступних заводських партій успішно пройдуть автоматичний контроль без хибних відмов.

4. **Криптографічне підписання бази:** Файл профілю компонента містить повні метадані (партномер, тип корпусу, призначення пінів, діапазони баластних резисторів, амплітуди, частоти) та підписується асиметричним ключем RSA-4096 / Ed25519 сертифікаційної лабораторії підприємства для запобігання несанкціонованій модифікації параметрів операторами на лінії.

## Щоденний регламент калібрування та самодіагностики стенду

Перед початком кожної робочої зміни або після заміни випробувальної ZIF-панелі оператор лабораторії вхідного контролю зобов'язаний виконати регламент апаратної самодіагностики сигнатурного аналізатора:
1. **Тест нульового зміщення підсилювачів (Zero Offset Verification):** Вимірювальні щупи відключаються від контактної колодки. Перевіряється залишковий струм зміщення нульової лінії на всіх чотирьох діапазонах джерельного опору (100 Ом, 1 кОм, 10 кОм, 100 кОм). Залишковий струм на діапазоні 100 кОм не повинен перевищувати `± 200 пА`. У разі перевищення автоматично запускається калібрувальний ЦАП цифрового зміщення нуля (Auto-Zero Calibration Routine).
2. **Перевірка каліброваної матриці навантажень (Calibration Verification Standard):** У роз'єм встановлюється еталонний сертифікований калібратор, що містить прецизійний резистор `1000.0 ± 0.1 Ом`, діод Шотткі 1N5819, кремнієвий діод 1N4148, стабілітрон BZX84C5V1 та керамічний конденсатор `1000 ± 5 пФ` з діелектриком NP0/C0G.
3. **Розрахунок метрологічного дрейфу:** Програмне ядро виконує вимірювання сигнатур еталонних навантажень та обчислює похибку амплітуди напруги `ΔV` та струму `ΔI`. Якщо сумарне середньоквадратичне відхилення калібратора перевищує 0.25%, генерація звітів блокується до завершення повторного метрологічного юстування стенду.

## Аналіз похибок першого та другого роду в сигнатурному контролі

У метрологічній практиці автоматизованого контролю напівпровідників критично важливо розрізняти два типи статистичних помилок класифікації:

1. **Похибка першого роду `α` (Ризик виробника / False Alarm / Type I Error):** Випадок, коли абсолютно автентичний, якісний оригінальний чіп помилково класифікується аналізатором як брак (`Failed`). Найчастішими причинами є окиснення контактних пружин ZIF-панелі, мікропил на виводах, наявність статичного заряду на корпусі або підвищена температура в цеху. Усувається алгоритмом автоматичного триразового перетестування з механічним мікропротиранням контактів (Micro-Wipe Cycle): якщо при повторному притисканні опір контакту нормалізується, вердикт переглядається на `PASS`.
2. **Похибка другого роду `β` (Ризик споживача / False Acceptance / Type II Error):** Найнебезпечніша ситуація, коли підроблений компонент помилково визнається придатним (`Passed`) і потрапляє на автоматичну лінію монтажу. У сигнатурному аналізаторі ймовірність `β` зведена до величини менше `10⁻⁶` завдяки комбінації трьох незалежних критеріїв: одночасної перевірки евклідової розбіжності площі `D_area`, динамічного трансформування шкали часу DTW та спектрального коефіцієнта гармонік THD.

## Інтеграція в автоматизовані лінії поверхневого монтажу (SMD / ATE)

Сучасні високопродуктивні виробничі лінії інтегрують модуль сигнатурного тестування безпосередньо у живильники автоматичних установників компонентів (Pick & Place Feeders) або роботизовані станції розвантаження стрічок (Tape & Reel De-taping Stations). Роботизований маніпулятор вакуумним соплом захоплює мікросхему зі стрічки, притискає її виводи до підпружиненої матриці щупів Кельвіна, і за 15–50 мілісекунд апаратний сигнатурний блок проводить повне багатопінове сканування.

Якщо хоча б один вивід демонструє невідповідність еталону, сопло автомата не встановлює чіп на друковану плату, а скидає його у спеціальний закритий лоток відбракування (Reject Bin) із внесенням серійного номера у звіт інцидентів. Це повністю унеможливлює потрапляння контрафактних мікросхем на плати ще до початку процесу пайки оплавленням, заощаджуючи сотні годин на наступній діагностиці, ремонті та рекламаціях.

Сигнатурний аналіз є найбільш економічним, швидким та високопродуктивним неруйнівним інструментом верифікації компонентів, що дозволяє за лічені секунди перевірити повну напівпровідникову відповідність багатовивідного чіпа перед його встановленням на автоматичну лінію SMD-монтажу.
