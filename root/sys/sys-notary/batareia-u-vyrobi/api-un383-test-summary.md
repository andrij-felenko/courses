# 📋 Структура й верифікація звіту UN 38.3 Test Summary Report

Звіт про короткий зміст випробувань літієвих елементів та батарей (англ. *UN 38.3 Test Summary Report*, TSR) є стандартизованим юридичним і технічним документом, який виробники й наступні дистриб'ютори зобов'язані надавати на кожній ланці ланцюга постачання на вимогу перевізників, митних органів або системних інтеграторів. Вимога щодо наявності стандартизованого TSR набула чинності 1 січня 2020 року згідно з Типовими правилами ООН (*UN Model Regulations*, перегляд 20 і 21) та регламентом IATA DGR (пункт 3.9.2.6.1). Документ замінює необхідність передавати конфіденційний повний протокол випробувань лабораторії обсягом у 50–100 сторінок, концентруючи критичні інженерні дані та підтвердження безпеки у форматі стислої публічної декларації.

## 1. Юридичний статус та обов'язки суб'єктів ланцюга постачання

Традиційно виробники акумуляторів надавали замовникам повні лабораторні звіти (*UN 38.3 Test Reports*). Проте такі звіти містять конфіденційну інтелектуальну власність: пошарову рецептуру електроліту, конструкцію електродних рулонів, хімічний склад катодних домішок та детальні креслення внутрішніх клапанів скидання тиску. Як наслідок, виробники часто відмовлялися надавати повні звіти стороннім експедиторам, що створювало сліпу зону для авіаційної безпеки.

Регламент TSR вирішив цю проблему, створивши стандартизовану тристоронню модель відповідальності:
1. **Виробник комірки або батареї:** Зобов'язаний самостійно або через акредитовану лабораторію ISO/IEC 17025 провести повний цикл випробувань T.1–T.8, скласти TSR англійською мовою (як мовою міжнародного транспортного спілкування) та забезпечити його доступність усім контрагентам без укладання угод про нерозголошення (NDA).
2. **Виробник кінцевого обладнання (OEM / Інтегратор):** Якщо пристрій містить знімну або впаяну батарею, інтегратор зобов'язаний отримати TSR від постачальника акумулятора, верифікувати його дійсність та включити до загального технічного файлу приладу.
3. **Дистриб'ютори та логістичні провайдери:** Зобов'язані перевіряти наявність чинного TSR для кожного артикула продукції перед прийняттям вантажу до міжнародного перевезення.

Відсутність або неповне заповнення хоча б одного пункту робить документ юридично недійсним і дає авіакомпаніям та логістичним хабам безумовне право затримати партію.

## 3. Правила сертифікації батарейних збірок (пункти 38.3.3 f та 38.3.3 g)

Коли інженерна компанія збирає власний акумуляторний блок із сертифікованих покупних комірок 18650 або 21700, виникає питання необхідності проведення повторного тестування:

1. **Батареї з сумарною енергією понад 6200 Вт·год (пункт 38.3.3 g):** Якщо велика модульна батарея створюється шляхом паралельно-послідовного об'єднання менших батарейних модулів, які вже успішно пройшли всі тести UN 38.3, і така батарея обладнана загальною системою моніторингу напруги та струму, проведення повторних тестів T.1–T.5 не вимагається.
2. **Батареї з енергією до 6200 Вт·год (пункт 38.3.3 f):** Якщо акумуляторна збірка складається з попередньо сертифікованих комірок, готова батарея все одно **зобов'язана пройти випробування T.1–T.5 (кліматика та механіка) та T.7 (перезаряд)**. Випробування T.6 (роздавлювання) та T.8 (форсований розряд) у цьому разі позначаються в TSR як `N/A`, оскільки вони вже закриті протоколами випробувань вихідних комірок.

## 4. Специфікація перевірки таблиці тестів (T.1–T.8)

Статус кожного тесту в полі № 7 має жорстко відповідати типу джерела живлення. Неправильне маркування `N/A` у тесті, який є обов'язковим для конкретного формфактора, свідчить про технічну некомпетентність або фальсифікацію звіту:

1. **Одиночна комірка (Li-ion або Li-metal):**
   - T.1 (Висота), T.2 (Термоцикли), T.3 (Вібрація), T.4 (Удар), T.5 (Зовнішнє КЗ) — обов'язково `Passed`.
   - T.6 (Роздавлювання / Удар) — обов'язково `Passed`.
   - T.7 (Перезаряд) — статус `N/A` (тест перезаряду застосовується виключно до акумуляторних батарей/пакетів з електронним захистом або зарядним інтерфейсом).
   - T.8 (Форсований розряд) — обов'язково `Passed` (для комірок, призначених для використання в послідовних збірках).

2. **Батарейний блок / Пакет (Li-ion Battery Pack із BMS):**
   - T.1–T.5 — обов'язково `Passed` на рівні готової батареї.
   - T.6 — статус `N/A` (проводиться на рівні окремих компонентних комірок перед збиранням).
   - T.7 (Перезаряд) — обов'язково `Passed`.
   - T.8 — статус `N/A` (проводиться на рівні базових комірок).

## 6. Контрольний алгоритм автоматичної перевірки (Audit Rules)

Під час імпорту TSR-файлу від постачальника акумуляторів система приймання продукції виконує набір обов'язкових предикативних перевірок:

1. **Правило збереження енергетичної узгодженості:**
   Енергія у ват-годинах `energyWh` повинна дорівнювати добутку номінальної напруги та ємності з точністю до похибки заокруглення:
   `| energyWh - (voltageNominalV × capacityAh) | ≤ 0.05 × energyWh`

2. **Правило літієвого еквівалента для Li-metal:**
   Для первинних літієвих джерел маса металічного літію оцінюється за теоретичною ємністю (0.3 г на 1 А·год):
   `lithiumContentGrams ≈ capacityAh × 0.3`

3. **Правило консистентності статусу батареї:**
   Якщо `productDescription.type == "battery"`, то `testResults.t7_overcharge` не може дорівнювати `N/A` і має бути виключно `Pass`. Якщо ж це `cell`, то `t6_crush_impact` та `t8_forced_discharge` повинні бути `Pass`.

4. **Правило актуальності редакції стандарту:**
   Поле `unManualEdition` повинно посилатися на чинну редакцію стандарту (наприклад, Rev.6 Amend.1, Rev.7 або Rev.8). Посилання на застарілі редакції (Rev.4 чи Rev.5) відхиляються міжнародними авіаперевізниками як недійсні.
