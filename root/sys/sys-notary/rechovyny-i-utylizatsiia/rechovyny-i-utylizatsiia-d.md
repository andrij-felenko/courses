- [Евтектика](root:hw-pcb/eutectic-alloys) — термодинаміка сплавів олово-свинець та безсвинцевих припоїв.
- [Декларація відповідності й технічний файл](root:sys-notary/deklaratsiia-vidpovidnosti-i-tekhnichnyi-fail) — юридичне оформлення допуску продукції на ринок ЄС.
</preknowlist>

Партія з п'яти тисяч промислових шлюзів збору телеметрії вартістю понад 400 000 євро прибуває до митного термінала порту Гамбург. Інспектори державного агентства ринкового нагляду відбирають два серійні зразки для лабораторного аудиту. Рентгенофлуоресцентний спектрометр фіксує, що в латунних різьбових стійках кріплення плати вміст свинцю становить 2.8% за масою — це легально за тимчасовим винятком RoHS, проте імпортер не вказав номер винятку в декларації відповідності. Газова хромато-мас-спектрометрія показує, що в чорній еластомерній муфті герметизації кабельного вводу міститься 1600 ppm (0.16% за масою) пластифікатора DEHP, що перевищує граничний ліміт 1000 ppm. Одночасно автоматизована перевірка реєстру виявляє, що бренд не зареєстрований у німецькій системі обліку відходів електроніки `stiftung ear`, а на пластиковому корпусі приладу відсутнє маркування перекресленого смітника. Митниця накладає повну заборону на випуск партії, призначає компанії штраф у 85 000 євро та зобов'язує імпортера реекспортувати або утилізувати всю продукцію за власний рахунок.

Цей прецедент доводить непохитне інженерне правило сучасного ринку: пристрій не є готовим до комерційного випуску, якщо його схемотехніка бездоганна, але хімічний склад матеріалів або життєвий цикл утилізації порушують екологічне законодавство. Допуск на глобальний ринок вимагає суворого дотримання трьох регуляторних стовпів Європейського Союзу: директиви **RoHS** (обмеження небезпечних речовин у конструкції), регламенту **REACH** (контроль і нотифікація хімічних сполук) та директиви **WEEE** (розширена відповідальність виробника за збирання й переробку відходів).

Хронологію виникнення цих правил — від екологічних трагедій у Мінаматі та отруєння кадмієм у Японії до глобальної кризи переробки електронного сміття у країнах третього світу — викладено в [історії екологічних директив у галузі електроніки](root:sys-notary/rechovyny-i-utylizatsiia/hist-environmental-directives.md).

### Філософія трьох екологічних стовпів ЄС: RoHS, REACH та WEEE

Усі три законодавчі акти спрямовані на захист довкілля та здоров'я людини, проте вони діють на принципово різних етапах життєвого циклу продукту й використовують різні правові механізми.

```
Співвідношення екологічних рамок Європейського Союзу:
+-------------------+---------------------------+---------------------------+---------------------------+
| Параметр          | RoHS (Директива           | REACH (Регламент          | WEEE (Директива           |
|                   | 2011/65/EU + 2015/863)    | (ЄС) № 1907/2006)         | 2012/19/EU)               |
+-------------------+---------------------------+---------------------------+---------------------------+
| Юридичний статус  | Секторальна директива     | Горизонтальний регламент  | Секторальна директива     |
|                   | для електроніки (EEE)     | прямої дії для всіх галузей| для відходів EEE          |
+-------------------+---------------------------+---------------------------+---------------------------+
| Фокус регулювання | Вхідні матеріали          | Усі хімічні речовини      | Кінець життя продукту     |
|                   | (заборона 10 токсинів)    | (список кандидатів SVHC)  | (збирання, переробка, EPR)|
+-------------------+---------------------------+---------------------------+---------------------------+
| Базовий рівень    | Гомогенний матеріал       | Окремий виріб (Article)   | Готовий прилад            |
| оцінки маси       | (шар, покриття, сплав)    | за правилом OAOA          | (маса виробу в зборі)     |
+-------------------+---------------------------+---------------------------+---------------------------+
| Зв'язок із знаком | Обов'язкова вимога        | Незалежно від CE          | Окреме маркування         |
| маркування CE     | для нанесення знака CE    | (нотифікація в базі SCIP) | перекресленого смітника   |
+-------------------+---------------------------+---------------------------+---------------------------+
```

1. **RoHS (Restriction of Hazardous Substances):** Працює як «вхідний фільтр» для електронної промисловості. Директива встановлює пряму заборону на застосування 10 конкретних високотоксичних речовин (важких металів, бромованих антипіренів та фталатів) у будь-якому однорідному матеріалі виробу. Без виконання вимог RoHS заборонено наносити маркування `CE`.
2. **REACH (Registration, Evaluation, Authorisation and Restriction of Chemicals):** Горизонтальний закон Європейського Союзу, що охоплює абсолютно всі хімічні речовини в усіх галузях — від фарб і текстилю до інтегральних мікросхем. Він не забороняє компоненти автоматично, але вимагає обов'язкової реєстрації речовин, детального інформування споживачів за статтею 33 та внесення даних про речовини високого занепокоєння (SVHC) до центральної бази даних ECHA SCIP.
3. **WEEE (Waste Electrical and Electronic Equipment):** Регулює «вихідний потік» апаратури після завершення терміну експлуатації. Директива втілює принцип розширеної відповідальності виробника (*Extended Producer Responsibility*, EPR), змушуючи розробників та імпортерів реєструватися в національних реєстрах, сплачувати збори за переробку та проектувати вироби з можливістю легкого демонтажу й сортування вторинної сировини.

### RoHS (Директива 2011/65/EU та 2015/863): обмеження небезпечних речовин

Серцевиною вимог директиви RoHS є поняття **гомогенного матеріалу** (від грец. *homogenes* — однорідний за складом).

![Концепція гомогенного матеріалу в електронному вузлі за RoHS](/root/sys/sys-notary/rechovyny-i-utylizatsiia/img/rohs-homogeneous-materials.svg)
*Концепція «гомогенного матеріалу» в електронному вузлі. Концентрація десяти лімітованих речовин вимірюється окремо для кожного шару (корпус мікросхеми, покриття ніжки, припій, мідна доріжка, маска плати), а не для друкованого вузла загалом.*

**Гомогенний матеріал** визначається як матеріал рівномірного хімічного складу по всьому об'єму, який неможливо механічно розділити на різні матеріали шляхом відкручування, розрізання, роздавлювання, шліфування чи абразивних дій.

Розглянемо звичайний поверхнево-монтований чіп (наприклад, мікроконтролер у корпусі QFP). З точки зору RoHS це не один компонент, а сукупність щонайменше шести незалежних гомогенних матеріалів:
1. Епоксидний компаунд корпусу (Molding Compound);
2. Кремнієвий напівпровідниковий кристал (Silicon Die);
3. Струмопровідний клей монтажу кристала (Die Attach Adhesive);
4. Золоті або мідні дротяні розварки (Bonding Wires);
5. Мідний вивідний каркас (Leadframe);
6. Гальванічне фінішне покриття виводів (Lead Finish).

Якщо хоча б в одному з цих шести шарів (наприклад, у гальванічному покритті виводів) концентрація свинцю перевищить допустимий норматив, уся мікросхема, вся друкована плата і весь кінцевий прилад визнаються такими, що порушують директиву RoHS.

#### Список 10 заборонених речовин та граничні ліміти (RoHS 3)

Директива 2011/65/EU зі змінами згідно з Делегованою директивою (EU) 2015/863 встановлює вичерпний перелік із 10 обмежених субстанцій:

```
Гранично допустимі концентрації речовин за RoHS 3:
+------------------------------------+---------------+-----------------------+-----------------------+
| Назва хімічної речовини            | Хімічний      | Граничний ліміт (%    | Граничний ліміт (ppm  |
|                                    | символ / код  | за масою, w/w)        | або мг/кг)            |
+------------------------------------+---------------+-----------------------+-----------------------+
| Кадмій та його сполуки             | Cd            | 0.01%                 | 100 ppm               |
| Свинець та його сполуки            | Pb            | 0.1%                  | 1000 ppm              |
| Ртуть та її сполуки                | Hg            | 0.1%                  | 1000 ppm              |
| Шестивалентний хром                | Cr(VI)        | 0.1%                  | 1000 ppm              |
| Полібромовані дифеніли             | PBB           | 0.1%                  | 1000 ppm              |
| Полібромовані дифенілові ефіри     | PBDE          | 0.1%                  | 1000 ppm              |
| Біс(2-етилгексил)фталат            | DEHP          | 0.1%                  | 1000 ppm              |
| Бутилбензилфталат                  | BBP           | 0.1%                  | 1000 ppm              |
| Дибутилфталат                      | DBP           | 0.1%                  | 1000 ppm              |
| Диізобутилфталат                   | DIBP          | 0.1%                  | 1000 ppm              |
+------------------------------------+---------------+-----------------------+-----------------------+
```

Зверніть увагу на особливий статус кадмію: його ліміт становить `0.01% (100 ppm)`, що у десять разів суворіше за інші метали. Це зумовлено надзвичайно високою біоакумулятивною здатністю кадмію в нирках людини та його екстремальною токсичністю для водних екосистем.

Чотири складні ефіри фталевої кислоти (DEHP, BBP, DBP, DIBP) набули чинності в рамках оновлення RoHS 3 у липні 2019 року. Вони використовуються як пластифікатори для надання гнучкості ПВХ-ізоляції кабелів, термозбіжним трубкам, ущільнювальним гумовим кільцям та еластичним ніжкам корпусів. Фталати є ендокринними руйнівниками, що блокують гормональні рецептори людини.

Детальний хімічний і фізичний опис припоїв, металевих покриттів та полімерних сполук наведено в [огляді матеріалів і хімічного складу компонентів](root:sys-notary/rechovyny-i-utylizatsiia/comp-rohs-reach-materials.md).

#### Фізика безсвинцевого переходу: SAC305 та ниткоподібні кристали

Перехід від свинцевого припою Sn63Pb37 до безсвинцевих сплавів став наймасштабнішою зміною у виробничих процесах електроніки за пів століття. Основним промисловим стандартом став трикомпонентний сплав **SAC305** (96.5% олова Sn, 3.0% срібла Ag, 0.5% міді Cu).

Фізичні наслідки заміни припою безпосередньо впливають на схемотехніку й розведення друкованих плат:
1. **Підвищення температурного профілю:** Температура плавлення Sn63Pb37 становить 183 °C, а пікова температура оплавлення складала 215–225 °C. Для SAC305 точка плавлення зросла до 217 °C, а пікова температура паяння в печі сягає 245–260 °C. Це створює жорсткі термічні напруження: склотекстоліт FR4 повинен мати вищу температуру склування (`Tg ≥ 150–170 °C`), а всі компоненти повинні відповідати рівням вологочутливості MSL 3 або MSL 2 за стандартом IPC/JEDEC J-STD-020.
2. **Ниткоподібні кристали олова (Tin Whiskers):** Чисте матове або блискуче олов'яне покриття контактів схильне до спонтанного росту монокристалічних вусів під дією внутрішніх напружень стиснення. Довжина такого кристала може досягати 1–2 мм, що викликає коротке замикання між виводами з дрібним кроком. Свинець повністю блокував цей процес. У безсвинцевій технології захист забезпечується обов'язковим нанесенням підшару нікелю товщиною 2–4 мкм та термічним відпалом після нанесення олова.

#### Легальні винятки з директиви RoHS (Annex III та IV)

Оскільки для деяких фізичних процесів повноцінна хімічна заміна свинцю наразі неможлива без втрати функціональності чи безпеки, директива містить систему офіційних винятків (*Exemptions*), викладених у Додатках III та IV:

```

+---------------+-----------------------------------------------+---------------------------------------+
| Номер винятку | Опис сфери застосування                       | Допустима концентрація / особливості  |
+---------------+-----------------------------------------------+---------------------------------------+
| 6(a) / 6(a)-I | Свинець як легувальний елемент у сталі        | До 0.35% свинцю за масою              |
|               | для механічної обробки                        |                                       |
+---------------+-----------------------------------------------+---------------------------------------+
| 6(b) / 6(b)-I | Свинець як легувальний елемент в алюмінії     | До 0.4% свинцю за масою               |
+---------------+-----------------------------------------------+---------------------------------------+
| 6(c)          | Свинець у мідних сплавах (латунь, бронза)     | До 4.0% свинцю за масою               |
+---------------+-----------------------------------------------+---------------------------------------+
| 7(a)          | Свинець у високотемпературних припоях         | Вміст свинцю 85% або більше за масою  |
|               | (наприклад, внутрішнє з'єднання кристала)     |                                       |
+---------------+-----------------------------------------------+---------------------------------------+
| 7(c)-I        | Електричні та електронні компоненти, що       | Без обмеження концентрації всередині  |
|               | містять свинець у склі або кераміці (крім     | керамічної/скляної фази (товстоплівкові|
|               | діелектричної кераміки конденсаторів)         | чіп-резистори, п'єзоелементи)         |
+---------------+-----------------------------------------------+---------------------------------------+
```

Використання винятку не означає звільнення від документального контролю. Виробник зобов'язаний зафіксувати точний пункт винятку в Декларації відповідності (EU DoC) та відстежувати термін його дії: Єврокомісія періодично переглядає Додатки III/IV і скасовує застарілі винятки в міру розвитку технологій заміщення.

> 🔧 **Навіщо це.** Практичний висновок: типовий SMD-резистор типорозміру 0805 містить свинець у скляній матриці резистивного шару, а кріпильна латунна стійка містить 3% свинцю для полегшення токарної обробки. Обидва елементи законні в ЄС, але виключно за умови посилання на винятки 7(c)-I та 6(c) у технічному файлі. Якщо аудит виявить свинець без зазначення винятку в документації, пристрій визнають контрафактним.

### REACH (Регламент ЄС № 1907/2006): Реєстрація, оцінка та обмеження хімікатів

Регламент REACH є фундаментальним нормативним актом Європейського Союзу, який регулює виробництво, імпорт та обіг усіх хімічних субстанцій. Для інженерів електроніки ключове значення має поділ об'єктів регулювання на три правові категорії:

1. **Речовина (Substance):** Хімічний елемент та його сполуки у природному стані або отримані шляхом виробничого процесу (наприклад, ізопропіловий спирт, ацетон, чиста мідь).
2. **Суміш (Mixture):** Розчин або суміш двох чи більше речовин (наприклад, паяльна паста, епоксидний двокомпонентний компаунд, лак захисного покриття друкованих плат).
3. **Виріб (Article, від лат. *articulus* — окрема частина):** Об'єкт, якому під час виробництва надається спеціальна форма, поверхня або конструкція, що визначають його кінцеву функцію більшою мірою, ніж його хімічний склад (наприклад, резистор, мікросхема, друкована плата, гвинт, пластиковий корпус, кабель).

#### Список кандидатів SVHC (Substances of Very High Concern)

Європейське хімічне агентство (ECHA, Гельсінкі) двічі на рік публікує та розширює **Список кандидатів речовин дуже високого занепокоєння (Candidate List of SVHC)**.

Речовина вноситься до списку SVHC, якщо вона відповідає критеріям небезпеки згідно зі статтею 57 регламенту REACH:
- **CMR:** Канцерогенні, мутагенні або токсичні для репродуктивної системи сполуки (категорії 1A або 1B);
- **PBT:** Стійкі, біоакумулятивні та токсичні речовини;
- **vPvB:** Дуже стійкі та дуже біоакумулятивні речовини;
- **Ендокринні дизраптори:** Сполуки з доведеним руйнівним впливом на гормональну систему ссавців.

Станом на сьогодні список SVHC містить понад 240 хімічних речовин, включаючи сполуки свинцю, кадмію, триоксид миш'яку, антипірен тетрабромбісфенол А (TBBA), фталати та перфторалкільні речовини (PFAS).

#### Принцип OAOA та рішення Суду ЄС (C-106/14)

Головна судова та інженерна колізія довкола регламенту REACH полягала у способі розрахунку концентрації речовин SVHC у складних електронних приладах.

Закон встановлює: якщо концентрація речовини зі списку кандидатів SVHC у виробі перевищує **0.1% за масою (1000 мг/кг, w/w)**, виробник зобов'язаний виконувати обов'язки інформування та нотифікації.

Раніше частина виробників застосовувала метод «розмивання маси»: маса невеликої токсичної деталі ділилася на загальну масу всього приладу.

![Принцип Once An Article Always An Article у регламенті REACH](/root/sys/sys-notary/rechovyny-i-utylizatsiia/img/reach-oaoa-principle.svg)
*Принцип Once An Article, Always An Article (OAOA) у регламенті REACH. Рішення Суду ЄС (справа C-106/14) забороняє розчиняти масу токсичної речовини в загальній вазі пристрою: ліміт 0.1% w/w розраховується для кожної складової деталі окремо.*

10 вересня 2015 року Суд Справедливості Європейського Союзу ухвалив історичне рішення у справі **C-106/14**, закріпивши принцип: **«Once An Article, Always An Article» (ОАОА — одного разу виріб, завжди виріб)**.

**Суть принципу OAOA:** Якщо деталь відповідала визначенню «виробу» (Article) до того, як її було змонтовано у складений пристрій (Complex Object), вона **зберігає статус окремого виробу** і всередині готового продукту. Пороговий ліміт 0.1% w/w повинен розраховуватися щодо **власної маси цієї конкретної деталі**, а не щодо маси всього фінального обладнання.

**Приклад розрахунку:**
Уявімо промисловий роутер вагою 1000 грамів. Усередині встановлено гумове ущільнювальне кільце кнопки вагою 0.5 грама. Кільце містить 10 мг пластифікатора DEHP:
- За некоректною схемою (на весь прилад): `10 мг / 1000 г = 0.001%` (виробник помилково вважає, що нічого декларувати не треба, оскільки `0.001% < 0.1%`).
- За законним принципом OAOA: `10 мг / 0.5 г = 2.0% w/w`.
- Оскільки `2.0% > 0.1%`, виникає пряме юридичне зобов'язання негайного розкриття інформації!

#### Юридичні зобов'язання за регламентом REACH: Стаття 33 та база даних SCIP

Перевищення порогу 0.1% w/w для будь-якого компонента активує два незалежні правові механізми:

1. **Обов'язок інформування (Стаття 33 REACH):**
   - **B2B (Стаття 33.1):** Постачальник зобов'язаний автоматично й безкоштовно надати професійному покупцю інформацію щодо безпечного використання виробу та назву наявної речовини SVHC.
   - **B2C (Стаття 33.2):** На запит кінцевого споживача виробник або продавець зобов'язаний надати аналогічну інформацію протягом **45 календарних днів** на безоплатній основі.
2. **Нотифікація до бази даних SCIP (Waste Framework Directive):**
   З 5 січня 2021 року набули чинності зміни до Директиви про відходи (WFD 2008/98/EC). Будь-яка компанія, що постачає виріб на ринок ЄС із вмістом речовини SVHC понад 0.1% w/w у будь-якому його компоненті, зобов'язана передати структуроване електронне досьє до бази даних **SCIP** (*Substances of Concern In articles as such or in complex objects / Products*) Європейського хімічного агентства (ECHA).

Досьє SCIP містить артикул деталі, назву й концентраційний діапазон речовини SVHC, класифікатор матеріалу та інструкції з безпечного розбирання й утилізації для операторів переробки відходів.

Програмну реалізацію алгоритму перевірки BOM та генерації нотифікацій SCIP продемонстровано в [проєкті аналізатора BOM для оцінки SVHC та генерації SCIP-досьє](root:sys-notary/rechovyny-i-utylizatsiia/proj-scip-bom-analyzer.md).

#### Додатки XVII (Обмеження) та XIV (Авторизація)

Крім списку кандидатів SVHC, у регламенті REACH діють два суворіші інструменти:
- **Додаток XVII (Restrictions):** Встановлює повну або часткову заборону на виробництво, використання та продаж певних речовин у специфічних сферах (наприклад, заборона використання нікелю в предметах, що контактують зі шкірою, заборона фталатів в іграшках, обмеження азбесту).
- **Додаток XIV (Authorisation List):** Перелік речовин, які повністю заборонено застосовувати на території ЄС після певної дати («Sunset Date»), якщо підприємство не отримало персонального тимчасового дозволу від Єврокомісії за відсутності технічно доступних альтернатив.

### WEEE (Директива 2012/19/EU) та розширена відповідальність виробника (EPR)

Якщо директиви RoHS та REACH контролюють пристрій під час розробки та виготовлення, то Директива **WEEE 2012/19/EU** регулює фінал його життєвого циклу — перетворення на відходи.

![Маркування WEEE та замкнений цикл розширеної відповідальності виробника EPR](/root/sys/sys-notary/rechovyny-i-utylizatsiia/img/weee-mark-and-epr-loop.svg)
*Маркування WEEE та замкнений цикл розширеної відповідальності виробника (EPR). Виробник фінансово забезпечує інфраструктуру роздільного збирання, демонтажу та вторинної переробки електроніки.*

#### Знак перекресленого смітника та стандарт EN 50419

Будь-який електричний або електронний прилад, призначений для ринку Європейського Союзу, повинен мати чітке, незмивне та видиме маркування у вигляді перекресленого смітника на колесах згідно зі стандартом **EN 50419**.

Вимоги до нанесення знака WEEE:
- **Символ:** Перекреслений хрестом сміттєвий бак на колесах, що вказує на заборону викидання приладу разом із несортованими побутовими відходами.
- **Суцільна смуга (Black Bar):** Горизонтальна суцільна чорна лінія під смітником висотою `h > 0.3a` (де `a` — ширина смітника). Вона засвідчує, що пристрій виведено на ринок **після 13 серпня 2005 року** (коли набули чинності обов'язки EPR). Як альтернатива смузі дозволяється зазначати точну дату виробництва.
- **Розміри та стійкість:** Мінімальна висота символу становить **7 мм** (якщо розміри самого пристрою замалі, дозволяється наносити знак на пакування, інструкцію користувача та гарантійний талон). Маркування перевіряється на стійкість до стирання: поверхню труть шматком тканини, змоченим водою (15 секунд), а потім спиртом (15 секунд) — напис повинен залишатися повністю читабельним.

#### Механізм розширеної відповідальності виробника (EPR)

Принцип **EPR (Extended Producer Responsibility)** юридично покладає фінансову, організаційну та екологічну відповідальність за утилізацію обладнання на «виробника».

**Хто вважається «виробником» (Producer) за директивою WEEE:**
1. Компанія, яка виготовляє електроніку під власною торговою маркою в межах країни ЄС;
2. Компанія, яка перепродає під власною маркою обладнання інших виробників;
3. **Імпортер**, який професійно ввозить продукцію з третіх країн (наприклад, з України, Китаю чи США) на територію будь-якої держави-члена ЄС;
4. Суб'єкт дистанційної торгівлі (e-commerce), який продає обладнання кінцевим користувачам у країнах ЄС через інтернет-магазини та транскордонні маркетплейси (Amazon, eBay тощо).

**Як працює контур EPR на практиці:**
- **Національні реєстри:** У Європейському Союзі немає єдиного центрального реєстру WEEE. Виробник зобов'язаний окремо зареєструватися в національному органі **кожної країни**, де продається його продукція (наприклад, `stiftung ear` у Німеччині, `ADEME` у Франції, `WEEE Ireland` в Ірландії) та отримати унікальний реєстраційний номер WEEE-Reg.-Nr.
- **Організації колективної відповідальності (PRO — Producer Responsibility Organizations):** Оскільки жодна приватна компанія не може самостійно побудувати пункти збирання брухту по всій Європі, виробники укладають договори з акредитованими операторами PRO. Виробник сплачує **еко-внесок (Eco-fee)** за кожен кілограм обладнання, виведеного на ринок.
- **Щорічна звітність та квоти:** Щомісяця або щороку компанія звітує про точну масу проданої техніки за категоріями. Оператори PRO організовують роздільне збирання, вилучення небезпечних елементів (конденсаторів, ртутних ламп, літієвих батарей) та афінаж цінних металів, забезпечуючи виконання нормативів рециклінгу (залежно від категорії — від 55% до 80% вторинної переробки маси приладу).
- **Блокування за відсутність EPR:** З 2022–2023 років маркетплейси (Amazon, AliExpress) зобов'язані за законом перевіряти номери WEEE/EPR продавців. Якщо виробник не надав чинний реєстраційний номер у країні покупця, його лістинги автоматично блокуються на рівні платформи.

#### Дизайн для переробки (Design for Recycling) та інтеграція з Battery Regulation

Директива WEEE встановлює прямі вимоги до конструктивного проектування виробів:
- **Розбірність:** Забороняється використовувати нерозбірні клейові з'єднання, які заважають швидкому демонтажу друкованих плат, металевих шасі та літієвих батарей на лініях сортування.
- **Синергія з Новим регламентом про батареї (Regulation (EU) 2023/1542):** З 2027 року всі портативні пристрої на ринку ЄС повинні проектуватися так, щоб кінцевий користувач міг самостійно та безпечно вилучити й замінити акумуляторну батарею за допомогою стандартних інструментів без застосування нагріву чи спеціальних розчинників. Батареї мають власний окремий контур реєстрації EPR та сплати еко-внесків.

### Практична стратегія комплаєнсу для інженерних команд

Побудова системи управління екологічною відповідністю у команді розробників вимагає чіткого алгоритму дій за гармонізованим європейським стандартом **EN IEC 63000:2018** (*Technical documentation for the assessment of electrical and electronic products with respect to the restriction of hazardous substances*).

![Конвеєр оцінки відповідності матеріалів за стандартом EN IEC 63000:2018](/root/sys/sys-notary/rechovyny-i-utylizatsiia/img/compliance-verification-flow.svg)
*Конвеєр оцінки відповідності матеріалів за стандартом EN IEC 63000:2018. Чотирирівнева модель перевірки: оцінка ризиків, збір декларацій постачальників, аналітичний лабораторний контроль та формування Технічного файлу.*

#### Чотири етапи конвеєра комплаєнсу:

1. **Етап 1: Оцінка ризиків матеріалів (BOM Risk Assessment):**
   Інженерна команда аналізує перелік компонентів (BOM) і класифікує деталі за категоріями ризику:
   - *Низький ризик:* Пасивні кремнієві компоненти, стандартні керамічні конденсатори MLCC від провідних виробників (Murata, TDK), де ризик токсинів мінімальний.
   - *Середній ризик:* Друковані плати, паяльні маски, роз'єми з термопластику.
   - *Високий ризик:* Металовироби з латуні та сталі (ризик свинцю > 0.1%), кабелі з ПВХ-ізоляцією (ризик фталатів DEHP/DBP), деталі з антикорозійним покриттям (ризик `Cr VI`), компоненти від неперевірених локальних постачальників без міжнародної сертифікації.
2. **Етап 2: Збір та верифікація декларацій постачальників:**
   Для компонентів збираються офіційні доказові документи:
   - *Сертифікати відповідності (CoC — Certificate of Compliance);*
   - *Декларації матеріалів за стандартом IPC-1752A або IEC 62474 (рівень Class D — Full Material Disclosure).*
   Формати обміну даними та структуру XML/JSON схем детально описано у [довіднику форматів декларацій IPC-1752A та IEC 62474](root:sys-notary/rechovyny-i-utylizatsiia/api-compliance-declarations.md).
3. **Етап 3: Інструментальний аналітичний контроль (Лабораторні випробування):**
   Для компонентів високого ризику та при вхідному контролі партій застосовується двоступеневий аудит за стандартом IEC 62321:
   - *Ступінь A (Неруйнівний XRF-скринінг):* Рентгенофлуоресцентний спектрометр за 30–60 секунд визначає наявність важких металів (Pb, Hg, Cd, Cr, Br) у гомогенній точці. Якщо концентрація перебуває у зоні невизначеності (наприклад, бром `500–1200 ppm`), зразок передають на хімічний аналіз.
   - *Ступінь B (Мокра хімія):* Руйнівний аналіз методом оптико-емісійної спектрометрії з індуктивно-зв'язаною плазмою (ICP-OES) для точного кількісного визначення свинцю й кадмію, колориметрія UV-Vis для шестивалентного хрому та газова хромато-мас-спектрометрія (GC-MS) для фталатів і бромованих антипіренів.
4. **Етап 4: Формування Технічного файлу та підписання EU DoC:**
   Усі звіти, декларації та протоколи випробувань зшиваються в єдиний Technical File згідно з EN IEC 63000:2018. Виробник складає та підписує офіційну **Декларацію про відповідність (EU DoC)** із зазначенням директив 2011/65/EU (RoHS), 2014/53/EU (RED) тощо, після чого має законне право нанести маркування `CE` та знак WEEE на корпус виробу. Технічний файл зберігається компанією протягом **10 років** з моменту випуску останнього екземпляра серії.

Розглянемо практичний алгоритм оцінки концентрацій речовин для типового вузла комутації, що містить латунний болт кріплення, діелектричну прокладку та сигнальний роз'єм.

```c
#include <stdio.h>
#include <stdbool.h>

typedef struct {
    const char *part_name;
    double total_mass_mg;
    const char *substance_name;
    double substance_mass_mg;
    double rohs_limit_percent;
    bool has_exemption;
    const char *exemption_clause;
} PartAnalysis;

void run_validation(const PartAnalysis *parts, size_t count) {
    for (size_t i = 0; i < count; ++i) {
        const PartAnalysis *p = &parts[i];
        double concentration_percent = (p->substance_mass_mg / p->total_mass_mg) * 100.0;
        double concentration_ppm = concentration_percent * 10000.0;

        printf("Деталь: %s | Речовина: %s\n", p->part_name, p->substance_name);
        printf("  Концентрація: %.4f%% (%.1f ppm) | Ліміт: %.4f%%\n",
               concentration_percent, concentration_ppm, p->rohs_limit_percent);

        if (concentration_percent > p->rohs_limit_percent) {
            if (p->has_exemption) {
                printf("  -> СТАТУС: ВІДПОВІДАЄ ЗА ВИНИТКОМ %s\n", p->exemption_clause);
            } else {
                printf("  -> СТАТУС: КРИТИЧНЕ ПОРУШЕННЯ (FAIL)!\n");
            }
        } else {
            printf("  -> СТАТУС: ВІДПОВІДАЄ НОРМІ (PASS)\n");
        }

        /* Перевірка порогу SVHC для бази SCIP (> 0.1% w/w) */
        if (concentration_percent > 0.1) {
            printf("  -> SCIP: Обов'язкова нотифікація в ECHA (SVHC > 0.1%% w/w)\n");
        }
        printf("\n");
    }
}

int main(void) {
    PartAnalysis sample_parts[] = {
        {"Bolt-M4", 1200.0, "Свинець (Pb)", 33.6, 0.1, true, "6(c)"},
        {"Gasket-EPDM", 400.0, "Фталат DEHP", 0.8, 0.1, false, ""},
        {"Connector-SMA", 2500.0, "Кадмій (Cd)", 0.15, 0.01, false, ""}
    };

    run_validation(sample_parts, 3);
    return 0;
}
```

```cpp
};

class ComplianceValidator {
public:
    static void evaluate(const std::vector<MaterialSample>& samples) {
        std::cout << std::fixed << std::setprecision(4);

        for (const auto& item : samples) {
            if (item.total_mass_mg <= 0.0) continue;

            const double concentration_percent = (item.substance_mass_mg / item.total_mass_mg) * 100.0;
            const double concentration_ppm = concentration_percent * 10'000.0;

            std::cout << "Деталь: " << item.part_name << " | Речовина: " << item.substance_name << "\n";
            std::cout << "  Концентрація: " << concentration_percent << "% ("
                      << std::setprecision(1) << concentration_ppm << " ppm) | Ліміт: "
                      << std::setprecision(4) << item.rohs_limit_percent << "%\n";

            if (concentration_percent > item.rohs_limit_percent) {
                if (item.has_exemption) {
                    std::cout << "  -> СТАТУС: ВІДПОВІДАЄ ЗА ВИНИТКОМ " << item.exemption_clause << "\n";
                } else {
                    std::cout << "  -> СТАТУС: КРИТИЧНЕ ПОРУШЕННЯ (FAIL)!\n";
                }
            } else {
                std::cout << "  -> СТАТУС: ВІДПОВІДАЄ НОРМІ (PASS)\n";
            }

            if (concentration_percent > 0.1) {
                std::cout << "  -> SCIP: Обов'язкова нотифікація в ECHA (SVHC > 0.1% w/w)\n";
            }
            std::cout << "\n";
        }
    }
};

int main() {
    const std::vector<MaterialSample> test_items = {
        {"Bolt-M4", 1200.0, "Свинець (Pb)", 33.6, 0.1, true, "6(c)"},
        {"Gasket-EPDM", 400.0, "Фталат DEHP", 0.8, 0.1, false, ""},
        {"Connector-SMA", 2500.0, "Кадмій (Cd)", 0.15, 0.01, false, ""}
    };

    ComplianceValidator::evaluate(test_items);
    return 0;
}
```

1. **Болт `Bolt-M4`:** Концентрація свинцю 2.8% перевищує 0.1%, але вкладається у 4.0% винятку 6(c). Виріб легальний, але через концентрацію `2.8% > 0.1%` SVHC вимагає подання досьє SCIP.
2. **Прокладка `Gasket-EPDM`:** Вміст пластифікатора DEHP становить 0.2% (2000 ppm), що у два рази перевищує ліміт RoHS 0.1%. 3. **Роз'єм `Connector-SMA`:** Концентрація кадмію 60 ppm є нижчою за жорсткий ліміт 100 ppm (0.01%). Компонент повністю відповідає нормам.
