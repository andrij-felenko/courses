# 📋 Формати декларацій матеріалів: IPC-1752A, IEC 62474 та структура технічного файлу EN IEC 63000

Обмін даними про хімічний склад компонентів між виробниками напівпровідників, дистриб'юторами та виробниками кінцевого обладнання (OEM) вимагає суворої стандартизації. Паперові листи та неструктуровані PDF-сертифікати неможливо автоматизовано валідувати в сучасних PLM-системах (Product Lifecycle Management) та інженерних базах даних.

Для цифрового обміну даними про комплаєнс індустрія використовує міжнародні машиночитані формати декларацій та структуру технічної документації за гармонізованим стандартом EN IEC 63000:2018.

---

### Стандарт IPC-1752A: класи розкриття інформації про матеріали

Стандарт **IPC-1752A** (*Materials Declaration Management*) базується на форматі обміну даними XML/PDF і визначає чотири стандартизовані класи декларацій залежно від глибини розкриття інформації:

```
Класифікація декларацій стандарту IPC-1752A:
+---------+----------------------------------+-----------------------------------------------+
| Клас    | Назва рівня                      | Зміст і призначення декларації                |
+---------+----------------------------------+-----------------------------------------------+
| Class A | Reporting Query / DoC            | Базовий сертифікат відповідності (так/ні) для |
|         |                                  | списків директив RoHS та REACH                |
+---------+----------------------------------+-----------------------------------------------+
| Class B | Manufacturing Information        | Додаються технологічні параметри паяння (MSL, |
|         |                                  | максимальна температура оплавлення, винятки) |
+---------+----------------------------------+-----------------------------------------------+
| Class C | Material Group Declaration       | Декларація маси гомогенних матеріалів         |
|         |                                  | без повного переліку хімічних речовин         |
+---------+----------------------------------+-----------------------------------------------+
| Class D | Full Material Disclosure (FMD)   | Повне 100% розкриття хімічного складу        |
|         |                                  | кожного гомогенного шару до номерів CAS       |
+---------+----------------------------------+-----------------------------------------------+
```

Для довгострокового управління ризиками найкращим інженерним вибором є **Class D (Full Material Disclosure)**. Якщо виробник чіпа надав FMD-файл, інженерній команді не потрібно щороку запитувати новий сертифікат, коли ECHA додає нові речовини до списку кандидатів REACH SVHC: достатньо запустити автоматичний скрипт перевірки бази CAS-номерів за наявним FMD-досьє.

#### Структура даних IPC-1752A Class D у форматі XML
Файл FMD-декларації містить сувору трирівневу ієрархію: виріб (Product) → гомогенний матеріал (Homogeneous Material) → хімічна речовина (Substance). Нижче наведено типовий фрагмент XML-схеми:

```xml
<Product name="STM32F401RET6" mass="0.135" massUnit="g">
  <HomogeneousMaterial name="Leadframe Base Metal" mass="0.045" massUnit="g">
    <Substance name="Copper" casNumber="7440-50-8" mass="0.04365" massPercent="97.0"/>
    <Substance name="Iron" casNumber="7439-89-6" mass="0.00108" massPercent="2.4"/>
    <Substance name="Phosphorus" casNumber="7723-14-0" mass="0.00027" massPercent="0.6"/>
  </HomogeneousMaterial>
  <HomogeneousMaterial name="Die Attach Adhesive" mass="0.002" massUnit="g">
    <Substance name="Silver" casNumber="7440-22-4" mass="0.0016" massPercent="80.0"/>
    <Substance name="Epoxy Resin" casNumber="25068-38-6" mass="0.0004" massPercent="20.0"/>
  </HomogeneousMaterial>
</Product>
```

#### Порівняння з новим стандартом IPC-1754
Для складніших виробів авіакосмічної, оборонної та автомобільної промисловості розроблено стандарт **IPC-1754** (*Materials and Substances Declaration for Aerospace and Defense and Other Industries*). На відміну від IPC-1752A, який орієнтований переважно на плоскі списки компонентів друкованих плат, IPC-1754 підтримує необмежену глибину ієрархічного дерева вузлів (Sub-assemblies) та повністю адаптований під вимоги рішення Суду ЄС C-106/14 (принцип OAOA).

### База даних декларованих речовин IEC 62474

Міжнародний стандарт **IEC 62474** (*Material Declaration for Products of and for the Electrotechnical Industry*) підтримує глобальну онлайн-базу даних декларованих речовин (DSL — *Declarable Substance List*), яку веде спільний технічний комітет IEC.

Кожен запис у базі IEC 62474 містить стандартизовані поля, що використовуються автоматизованими парсерами:

```json
{
  "IEC62474_Entry": {
    "SubstanceGroupID": "0001",
    "SubstanceGroupName": "Lead and its compounds",
    "ReportingThreshold": "0.1% by weight (1000 ppm) of homogeneous material",
    "LegalReference": "EU RoHS Directive 2011/65/EU",
    "TypicalApplications": [
      "Solder alloys",
      "Leadframe finishes",
      "Piezoelectric ceramics",
      "High melting temp solders"
    ],
    "ThresholdEvaluationMethod": "HomogeneousMaterialLevel"
  }
}
```

База даних IEC 62474 щоквартально оновлюється через веб-сервіси, що дозволяє корпоративним ERP-системам автоматично синхронізувати нові регуляторні пороги без зміни вихідного коду програмного забезпечення.

### Специфікація корисного навантаження нотифікації ECHA SCIP

Нотифікація до бази даних SCIP (*Substances of Concern In articles as such or in complex objects / Products*) виконується через REST API Європейського хімічного агентства (ECHA Submission Portal) у форматі JSON/IUCLID:

```json
{
  "scipDossier": {
    "header": {
      "dossierType": "SCIP_NOTIFICATION",
      "submissionVersion": "2.0",
      "submitterLegalEntity": "EUID-UA-10048291"
    },
    "articleDescription": {
      "primaryArticleIdentifierType": "PART_NUMBER",
      "primaryArticleIdentifierValue": "GW-IOT-IND-4G",
      "articleName": "Промисловий IoT-шлюз передавання даних",
      "articleCategory": "85176200",
      "productionInEU": false,
      "safeUseInstructions": "Використовувати згідно з інструкцією; не розкривати корпус; передавати на переробку авторизованому оператору WEEE."
    },
    "complexObjectComponents": [
      {
        "subArticleIdentifier": "BRASS-SPACER-M3",
        "subArticleName": "Стійка кріплення плати латунна M3",
        "subArticleCategory": "74153300",
        "candidateListSubstance": {
          "substanceName": "Lead",
          "ecNumber": "231-100-4",
          "casNumber": "7439-92-1",
          "concentrationRange": "≥ 1.0% w/w and ≤ 4.0% w/w",
          "materialCategory": "Metal -> Copper alloy -> Brass",
          "rohsExemptionApplicable": "Annex III, 6(c)"
        }
      }
    ]
  }
}
```

#### Допустимі діапазони концентрацій ECHA (Concentration Ranges):
Замість передачі точного значення маси, яке постачальники часто вважають комерційною таємницею, схема SCIP API вимагає зазначення одного зі стандартизованих діапазонів:
- `≥ 0.1% w/w and < 0.3% w/w`
- `≥ 0.3% w/w and < 1.0% w/w`
- `≥ 1.0% w/w and < 10.0% w/w`
- `≥ 10.0% w/w and ≤ 100.0% w/w`

#### Коди категорій товарів TARIC / CN Code:
Поле `articleCategory` повинно містити валідний 8-значний цифровий код Комбінованої номенклатури ЄС (Combined Nomenclature, CN code). Для електронного обладнання це зазвичай коди товарної групи 85 (наприклад, `8517 62 00` для апаратури передавання даних або `8504 40 30` для імпульсних перетворювачів напруги).

#### Автоматизація через System-to-System (S2S) API
Для компаній із широкою номенклатурою виробів агентство ECHA надає інтерфейс System-to-System (S2S). Програма-аналізатор BOM генерує архівний пакет у форматі `.i6z` (формат системи IUCLID 6) та завантажує його через захищений шлюз HTTPS з використанням сертифікатів авторизації ECHA API Key. У відповідь сервер повертає унікальний номер SCIP Number (наприклад, `a1b2c3d4-5678-90ef-...`), який заноситься до бази даних технічної документації виробу.

### Структура технічного файлу за стандартом EN IEC 63000:2018

Для нанесення маркування `CE` за директивою RoHS 2011/65/EU виробник зобов'язаний зібрати та зберігати протягом **10 років** Технічний файл (Technical File). Стандарт **EN IEC 63000:2018** визначає обов'язкові розділи цього досьє:

```
Складові частини технічного файлу комплаєнсу EN IEC 63000:
1. Загальний опис продукту (General Product Description):
   ├── Призначення, структурні схеми, складальні креслення
   └── Фотографії виробу зі знятими кришками корпусу
2. Матеріальна специфікація та оцінка ризиків (Risk Assessment):
   ├── Повний ієрархічний перелік матеріалів і компонентів (BOM)
   └── Матриця ризиків матеріалів (High / Medium / Low Risk за категоріями)
3. Доказова документація щодо матеріалів (Material Evidence):
   ├── Декларації постачальників (Supplier Declarations CoC / IPC-1752A)
   ├── Договірні гарантії якості ланцюга постачання
   └── Протоколи лабораторних випробувань (XRF, ICP-OES, GC-MS за IEC 62321)
4. Перелік застосованих гармонізованих стандартів (Applied Standards):
   ├── Посилання на гармонізований стандарт EN IEC 63000:2018
   └── Посилання на інші стандарти безпеки (EN 62368-1, EN 301 489 тощо)
5. Декларація про відповідність ЄС (EU Declaration of Conformity):
   ├── Офіційно підписаний документ EU DoC
   └── Юридична адреса виробника та уповноваженого представника в ЄС
```

#### Матриця оцінки надійності постачальника за EN IEC 63000:
Стандарт визначає процедуру категоризації доказів комплаєнсу на основі надійності джерела:
1. **Високий ступінь довіри:** Постачальник має сертифіковану систему менеджменту якості (ISO 9001, IATF 16949, ISO 14001), регулярно оновлює публічні бази даних FMD на власному сайті та надає повні протоколи випробувань сторонніх акредитованих лабораторій (ISO/IEC 17025). Додаткові лабораторні тести не потрібні.
2. **Середній ступінь довіри:** Постачальник надає типовий сертифікат відповідності (CoC) без детального розкриття складу хімічних речовин. Вимагається проведення періодичного вибіркового експрес-контролю методом рентгенофлуоресцентного аналізу (XRF).
3. **Низький ступінь довіри / Невідомий постачальник:** Деталі придбані через брокерів або неперевірених локальних посередників, відсутні прямі контакти з виробником кристала чи корпусу. Усі партії підлягають обов'язковим руйнівним хімічним випробуванням методом ICP-OES та GC-MS у сертифікованій лабораторії.

### Управління змінами (ECO) та процедура аудиту ринкового нагляду

Екологічна сертифікація не закінчується після підписання первинної декларації відповідності. Протягом усього 10-річного життєвого циклу продукту діють обов'язкові інженерні регламенти контролю:

#### Процедура сповіщення про зміни (PCN / ECN)
Коли виробник чіпів змінює завод виготовлення або корпус мікросхеми, він публікує сповіщення про зміни продукту (Product Change Notification, PCN). Інженерна команда OEM-виробника зобов'язана пропустити новий FMD-файл компонента через автоматичний валідатор. Якщо заміна мікроконтролера чи драйвера призвела до появи нової речовини SVHC або зміни застосованого винятку RoHS (наприклад, перехід зі свинцевмісного паяного з'єднання на безсвинцеве), технічний файл оновлюється з фіксацією дати та номера ревізії виробу.

#### Регламент перевірки ринковим наглядом (Market Surveillance Audit)
У разі вибіркової перевірки наглядовими органами країн ЄС (наприклад, німецьким Федеральним мережевим агентством Bundesnetzagentur або французьким DGCCRF) виробнику надсилається офіційний запит за Статтею 18 Регламенту (ЄС) 2019/1020. Виробник зобов'язаний надати повний Технічний файл EN IEC 63000:2018 протягом **10 робочих днів**. Якщо файли відсутні або декларації постачальників є недійсними, регулятор має право негайно ініціювати відкликання продукції з усього ринку Європейського Союзу через загальноєвропейську систему швидкого сповіщення Safety Gate (RAPEX).
