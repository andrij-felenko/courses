# 🧮 Математичний аналіз нелінійності та інтермодуляції 3-го порядку (IMD3)

У багатокористувацьких системах радіозв'язку та при групових польотах БПЛА головним джерелом незрозумілих взаємних завад є нелінійні спотворення у високочастотних трактах приймачів і передавачів. Математичний апарат теорії нелінійних кіл дозволяє строго вивести спектральний склад продуктів взаємної модуляції (інтермодуляції), розрахувати точки перетину 3-го порядку (IP3), каскадну лінійність приймального тракту, динамічний діапазон без інтермодуляції (SFDR), перехресну модуляцію (Cross-Modulation), зворотне змішування фазового шуму (Reciprocal Mixing) та довести геометричні умови побудови безконфліктних частотних сіток.

---

## Степеневий ряд нелінійної передатної характеристики

Реальні напівпровідникові підсилювачі (LNA на вході приймача, PA на виході передавача) та аналогові змішувачі мають передатну характеристику, лінійну лише для нескінченно малих сигналів. При зростанні амплітуди вхідної напруги `v_in(t)` вихідна напруга `v_out(t)` описується рядом Тейлора (від англ. *Taylor series*):

```
v_out(t) = a₁·v_in(t) + a₂·v_in²(t) + a₃·v_in³(t) + a₄·v_in⁴(t) + a₅·v_in⁵(t) + ...
```

Де:
- `a₁` — коефіцієнт лінійного підсилення за напругою (малосигнальний коефіцієнт передачі);
- `a₂` — коефіцієнт квадратичної нелінійності (відповідає за випрямлення та гармоніки парного порядку);
- `a₃` — коефіцієнт кубічної нелінійності (визначає компресію коефіцієнта підсилення та інтермодуляцію 3-го порядку);
- `a₄, a₅, ...` — вищі члени ряду (у більшості практичних розрахунків ВЧ-трактів домінуючим є член 3-го порядку `a₃`).

Для симетричних диференціальних схем парні коефіцієнти `a₂, a₄, ...` взаємно компенсуються (`a₂ ≈ 0`), тому саме кубічний член `a₃` повністю визначає нелінійну поведінку тракту при помірних рівнях потужності.

## Двотоновий аналіз: виведення продуктів інтермодуляції 3-го порядку

Нехай на вхід нелінійного каскаду надходить сума двох синусоїдальних сигналів однакової або близької амплітуди від двох різних передавачів на несучих частотах `ω₁` та `ω₂` (де `ω = 2·π·f`):

```
v_in(t) = V₁·cos(ω₁·t) + V₂·cos(ω₂·t)
```

Підставимо вхідний сигнал `v_in(t)` у кубічну складову передатної характеристики `v_out,3(t) = a₃·v_in³(t)`:

```
v_in³(t) = (V₁·cos(ω₁·t) + V₂·cos(ω₂·t))³
         = V₁³·cos³(ω₁·t) 
           + 3·V₁²·V₂·cos²(ω₁·t)·cos(ω₂·t) 
           + 3·V₁·V₂²·cos(ω₁·t)·cos²(ω₂·t) 
           + V₂³·cos³(ω₂·t)
```

Розгорнемо кожен доданок за допомогою тригонометричних тотожностей.

### 1. Куби окремих коливань: `cos³(α) = (3/4)·cos(α) + (1/4)·cos(3·α)`

```
V₁³·cos³(ω₁·t) = (3/4)·V₁³·cos(ω₁·t) + (1/4)·V₁³·cos(3·ω₁·t)
V₂³·cos³(ω₂·t) = (3/4)·V₂³·cos(ω₂·t) + (1/4)·V₂³·cos(3·ω₂·t)
```

- Члени на частотах `ω₁` та `ω₂` створюють ефект **десенсибілізації (компресії)** основного сигналу;
- Члени на частотах `3·ω₁` та `3·ω₂` є **третіми гармоніками** (для 5.8 ГГц вони потрапляють у діапазон 17.4 ГГц і легко відфільтровуються смуговими фільтрами).

### 2. Перехресні добутки: `cos²(α)·cos(β) = (1/2)·[1 + cos(2·α)]·cos(β)`

Розкриємо перехресний член `3·V₁²·V₂·cos²(ω₁·t)·cos(ω₂·t)`:

```
3·V₁²·V₂·cos²(ω₁·t)·cos(ω₂·t)
= 3·V₁²·V₂·(1/2)·[1 + cos(2·ω₁·t)]·cos(ω₂·t)
= (3/2)·V₁²·V₂·cos(ω₂·t) + (3/2)·V₁²·V₂·cos(2·ω₁·t)·cos(ω₂·t)
```

Застосуємо тотожність добутку косинусів `cos(2·α)·cos(β) = (1/2)·[cos(2·α − β) + cos(2·α + β)]`:

```
(3/2)·V₁²·V₂·cos(2·ω₁·t)·cos(ω₂·t)
= (3/4)·V₁²·V₂·cos((2·ω₁ − ω₂)·t) + (3/4)·V₁²·V₂·cos((2·ω₁ + ω₂)·t)
```

Аналогічно для симетричного члена `3·V₁·V₂²·cos(ω₁·t)·cos²(ω₂·t)`:

```
3·V₁·V₂²·cos(ω₁·t)·cos²(ω₂·t)
= (3/2)·V₁·V₂²·cos(ω₁·t) 
  + (3/4)·V₁·V₂²·cos((2·ω₂ − ω₁)·t) 
  + (3/4)·V₁·V₂²·cos((2·ω₂ + ω₁)·t)
```

### 3. Повний спектральний склад кубічного відгуку

Збираючи всі складові, отримуємо спектральні компоненти вихідного сигналу:

```
Частота              Амплітуда коливання
──────────────────────────────────────────────────────────────────
ω₁                   a₁·V₁ + (3/4)·a₃·V₁³ + (3/2)·a₃·V₁·V₂²
ω₂                   a₁·V₂ + (3/4)·a₃·V₂³ + (3/2)·a₃·V₁²·V₂
2·ω₁ − ω₂            (3/4)·a₃·V₁²·V₂           ← IMD3 (нижній бічний)
2·ω₂ − ω₁            (3/4)·a₃·V₁·V₂²           ← IMD3 (верхній бічний)
2·ω₁ + ω₂            (3/4)·a₃·V₁²·V₂           ← позасмуговий продукт (~17.4 ГГц)
2·ω₂ + ω₁            (3/4)·a₃·V₁·V₂²           ← позасмуговий продукт (~17.4 ГГц)
3·ω₁                 (1/4)·a₃·V₁³              ← 3-тя гармоніка (~17.4 ГГц)
3·ω₂                 (1/4)·a₃·V₂³              ← 3-тя гармоніка (~17.4 ГГц)
```

### Фізичний висновок із двотонового виведення

Продукти на частотах `f_IMD3,low = 2·f₁ − f₂` та `f_IMD3,high = 2·f₂ − f₁` мають ключову небезпечну особливість: **вони розташовані безпосередньо у робочій смузі частот** на тій самій відстані `Δf = |f₂ − f₁|` від основних сигналів:

```
f_IMD3,low  = f₁ − (f₂ − f₁) = f₁ − Δf
f_IMD3,high = f₂ + (f₂ − f₁) = f₂ + Δf
```

Жоден вхідний смуговий фільтр (Bandpass Filter) приймача 5.8 ГГц не здатен відфільтрувати ці паразитні частоти, оскільки вони лежать усередині загальної смуги пропускання 5650–5950 МГц. Якщо на частоті `2·f₂ − f₁` працює третій пілот `f₃`, інтермодуляційний продукт накладається прямо на його канал.

## Трисигнальний аналіз: потрійні биття (Triple-Beat IMD3)

Коли в повітрі одночасно перебувають три або більше дронів із частотами `f₁`, `f₂`, `f₃`, кубічна нелінійність породжує значно більшу кількість комбінаційних коливань виду `f_i ± f_j ± f_k`.

Розглянемо вхідний сигнал із трьох тонів:

```
v_in(t) = V₁·cos(ω₁·t) + V₂·cos(ω₂·t) + V₃·cos(ω₃·t)
```

У кубічному розкладі `(v_in)³` з'являється перехресний потрійний член:

```
6·V₁·V₂·V₃·cos(ω₁·t)·cos(ω₂·t)·cos(ω₃·t)
```

Застосовуючи тригонометричне перетворення добутку трьох косинусів:

```
cos(α)·cos(β)·cos(γ) = (1/4)·[cos(α + β − γ) + cos(α − β + γ) + cos(−α + β + γ) + cos(α + β + γ)]
```

Отримуємо комбінаційні складові виду `ω₁ + ω₂ − ω₃`, `ω₁ + ω₃ − ω₂`, `ω₂ + ω₃ − ω₁`.

Амплітуда кожного такого потрійного продукту (Triple-Beat Product) дорівнює:

```
V_triple = 6 · a₃ · (1/4) · V₁·V₂·V₃ = (3/2) · a₃ · V₁·V₂·V₃
```

### Порівняння потужності двотонового та тритонового IMD3

Порівняємо амплітуду двотонового продукту `(3/4)·a₃·V₁²·V₂` (при рівних амплітудах `V₁ = V₂ = V₃ = V`) та тритонового продукту `(3/2)·a₃·V³`:

```
V_triple ÷ V_two-tone = [(3/2)·a₃·V³] ÷ [(3/4)·a₃·V³] = 2
```

Оскільки потужність пропорційна квадрату напруги `P ∝ V²`:

```
P_triple ÷ P_two-tone = 2² = 4  (+6.02 дБ)
```

**Висновок:** у групових польотах за участю 3–8 пілотів потрійні інтермодуляційні продукти `f_i + f_j − f_k` за потужністю **вчетверо (+6 дБ) перевищують** класичні двотонові продукти `2·f_i − f_j` і створюють набагато щільнішу сітку паразитних завад у всьому діапазоні 5.8 ГГц.

## Точки нелінійного перетину: IP3, IIP3, OIP3 та компресія 1 дБ

Для кількісної оцінки стійкості приймача та лінійності передавача в радіотехніці використовують дві ключові точки: точку компресії на 1 дБ (`P1dB`) та віртуальну точку перетину 3-го порядку (`IP3`).

### 1. Точка компресії на 1 дБ (1-dB Compression Point, P1dB)

При збільшенні вхідної напруги амплітуда основного сигналу на частоті `ω₁` під дією від'ємного коефіцієнта `a₃` (для підсилювачів у режимі насичення `a₃ < 0`) зменшується відносно ідеальної лінійної характеристики:

```
V_out(ω₁) = a₁·V_in + (3/4)·a₃·V_in³ = a₁·V_in · [1 + (3/4)·(a₃/a₁)·V_in²]
```

Точка `P1dB` відповідає рівню вхідного сигналу, при якому реальний коефіцієнт підсилення зменшується на 1 дБ (множник `10^(-1/20) ≈ 0.891`):

```
1 + (3/4)·(a₃/a₁)·V_in,1dB² = 0.891
(3/4)·|a₃/a₁|·V_in,1dB² = 0.109
V_in,1dB = √( 0.145 · |a₁ / a₃| )
```

У логарифмічній шкалі потужності:

```
P1dB,out (дБм) = P1dB,in (дБм) + G (дБ) − 1 дБ
```

### 2. Точка перетину третього порядку (Third-Order Intercept Point, IP3)

Якщо зобразити графік вихідної потужності основного сигналу `P_fund` та потужності інтермодуляції `P_IMD3` у логарифмічному масштабі (дБм) як функцію від вхідної потужності `P_in`:

- Лінійний сигнал зростає з нахилом **1 дБ/дБ** (підсилення `G`): `P_out,fund (дБм) = P_in (дБм) + G (дБ)`;
- Інтермодуляційний продукт 3-го порядку зростає з нахилом **3 дБ/дБ** (оскільки `V_IMD3 ∝ V_in³`): `P_out,IMD3 (дБм) = 3·P_in (дБм) + K`.

Точка, в якій екстрапольовані лінійні прямі перетинаються, називається **точкою перетину 3-го порядку (IP3)**:
- **IIP3 (Input IP3):** проєкція точки перетину на вісь вхідної потужності;
- **OIP3 (Output IP3):** проєкція точки перетину на вісь вихідної потужності.

Знайдемо математичний вираз для напруги `V_IIP3`:

```
a₁·V_IIP3 = (3/4)·|a₃|·V_IIP3³
1 = (3/4)·|a₃/a₁|·V_IIP3²
V_IIP3 = √( (4/3) · |a₁ / a₃| )
```

Порівняємо `V_IIP3` та `V_in,1dB`:

```
V_IIP3 ÷ V_in,1dB = √( (4/3) ÷ 0.145 ) = √( 9.195 ) ≈ 3.032
```

Переведемо співвідношення напруг у децибели потужності:

```
IIP3 (дБм) − P1dB,in (дБм) = 20 · log₁₀(3.032) ≈ 9.63 дБ
```

**Теоретичне правило:** для довільного безінерційного кубічного нелінійного елемента точка `IIP3` завжди розташована приблизно на **9.6 дБ вище** за точку компресії `P1dB,in`.

### Формула розрахунку рівня завади IMD3 на практиці

Якщо відомі рівні вхідних сигналів двох передавачів `P_in,1` та `P_in,2` (у дБм) і значення `IIP3` приймача:

```
P_IMD3,in (дБм) = 2·P_in,1 (дБм) + P_in,2 (дБм) − 2·IIP3 (дБм)
```

При рівних рівнях сигналів `P_in,1 = P_in,2 = P_in`:

```
P_IMD3,in (дБм) = 3·P_in (дБм) − 2·IIP3 (дБм)
```

**Приклад розрахунку:**
- Два близькі передавачі створюють на вході LNA приймача рівень `P_in = −20 дБм`;
- Вхідний підсилювач RX5808 має `IIP3 = −10 дБм`;
- Рівень паразитного продукту IMD3 на вході становитиме:
  `P_IMD3 = 3·(−20) − 2·(−10) = −60 + 20 = −40 дБм`.

Якщо корисний сигнал від власного далекого дрона надходить на рівні `−85 дБм`, паразитний сигнал інтермодуляції (`−40 дБм`) перевищує його на **45 дБ**, що повністю знищує прийом відео.

## Каскадний розрахунок нелінійності: формула Фрііса для IIP3

Реальний супергетеродинний або прямого перетворення приймач FPV складається з послідовності функціональних вузлів: вхідного фільтра, малошумного підсилювача (LNA), радіочастотного смугового фільтра, змішувача (Mixer) та підсилювача проміжної частоти (IF Amplifier).

Кожен каскад `k` характеризується власним коефіцієнтом підсилення за потужністю `G_k` (у разах) та власною точкою перетину `IIP3,k` (у лінійних міліватах).

Загальний каскадний коефіцієнт `IIP3_total` усієї приймальної системи визначається формулою нелінійного накопичення спотворень:

```
1 / (IIP3_total) = 1 / (IIP3_1) + G₁ / (IIP3_2) + (G₁·G₂) / (IIP3_3) + (G₁·G₂·G₃) / (IIP3_4) + ...
```

Де:
- `IIP3_1` — точка перетину першого каскаду (LNA);
- `IIP3_2` — точка перетину другого каскаду (Mixer);
- `G₁` — коефіцієнт підсилення LNA;
- `G₂` — коефіцієнт передачі фільтра або змішувача.

### Парадокс високого підсилення вхідного LNA

Із формули каскадного IIP3 безпосередньо випливає критичний інженерний компроміс:
- Для зменшення загального коефіцієнта шуму приймача (Noise Figure, `NF`) згідно з класичною формулою Фрііса для шумів, підсилення першого каскаду `G₁` слід робити якомога більшим;
- Проте у формулі для нелінійності член `G₁ / IIP3_2` прямо пропорційний до `G₁`. Якщо LNA має надмірне підсилення (наприклад, +25–30 дБ), він багаторазово підсилює сигнали завад від сусідніх дронів і заганяє змішувач у глибоку нелінійну компресію.

Саме тому високоякісні FPV-приймачі (RapidFIRE, TBS Fusion, True-D) використовують LNA з помірним підсиленням (+12–15 дБ) і високим власним значенням `IIP3 > +5 дБм`, а також керовані цифрові атенюатори для захисту змішувача від перевантаження.

## Динамічний діапазон, вільний від інтермодуляції (SFDR)

Динамічний діапазон без паразитної інтермодуляції (SFDR, від англ. *Spurious-Free Dynamic Range*) визначає робочий проміжок між мінімальним рівнем сигналу, обмеженим тепловим шумом, та максимальним рівнем сигналів завад, при якому продукти IMD3 ще не перевищують рівень власних шумів приймача.

Рівень теплового шуму приймача на вході дорівнює:

```
P_noise (дБм) = −174 дБм/Гц + 10·log₁₀(B) + NF
```

Де:
- `−174 дБм/Гц` — спектральна густина теплового шуму Джонсона-Найквіста при кімнатній температурі (290 К);
- `B` — смуга пропускання каналу в герцах (для аналогового відео `B ≈ 20 МГц`, тобто `10·log₁₀(2·10⁷) ≈ 73 дБ·Гц`);
- `NF` — коефіцієнт шуму приймача (для типових модулів RX5808 `NF ≈ 4–6 дБ`).

Шумовий поріг приймача:

```
P_noise = −174 + 73 + 5 = −96 дБм
```

Значення SFDR третього порядку розраховується за формулою:

```
SFDR₃ (дБ) = (2/3) · (IIP3 (дБм) − P_noise (дБм))
```

Якщо приймач має `IIP3 = −10 дБм` та рівень шуму `P_noise = −96 дБм`:

```
SFDR₃ = (2/3) · (−10 − (−96)) = (2/3) · 86 = 57.3 дБ
```

Це означає, що різниця потужностей між найсильнішим сигналом близького передавача та найслабшим прийнятним сигналом далекого дрона не повинна перевищувати 57 дБ. Якщо один дрон стоїть на старті за 5 метрів від окулярів із потужністю 1 Вт (+30 дБм), а другий летить на відстані 1.5 км (втрати на трасі ~115 дБ), динамічний діапазон приймача буде перевищено, і слабкий сигнал буде безповоротно втрачено.

## Перехресна модуляція та зворотне змішування фазового шуму

Крім прямого утворення дискретних продуктів IMD3 на комбінаційних частотах, кубічна нелінійність та фазова нестабільність гетеродинів спричиняють ще два важливих ефекти деградації зв'язку:

### 1. Перехресна модуляція (Cross-Modulation, XMOD)

Якщо на вхід приймача разом із слабким немодульованим сигналом корисної несучої `V₁·cos(ω₁·t)` надходить потужний амплітудно-модульований або відеомодульований сигнал завади `V₂(t)·cos(ω₂·t) = V₂₀·[1 + m₂·s(t)]·cos(ω₂·t)`, кубічний член `(3/2)·a₃·v_in³` переносить модуляцію завади `s(t)` безпосередньо на амплітуду корисної несучої `ω₁`:

```
v_out,ω₁(t) = [a₁·V₁ + (3/2)·a₃·V₁·V₂²(t)] · cos(ω₁·t)
            = a₁·V₁ · [1 + m_cross · s(t)] · cos(ω₁·t)
```

Коефіцієнт перехресної модуляції дорівнює:

```
m_cross = 3 · |a₃ / a₁| · V₂₀² · m₂
```

Це пояснює, чому при польоті поруч із потужним дроном на екрані власного відеоприймача з'являються напівпрозорі контури чужого кадру, біжучі рядки або паразитна телеметрія OSD навіть тоді, коли несучі частоти формально рознесені на десятки мегагерців.

### 2. Зворотне змішування фазового шуму (Reciprocal Mixing)

Гетеродин приймача (Local Oscillator, LO) не є ідеальним джерелом монохроматичного коливання: його спектр має бічні шумові спідниці фазового шуму `L(Δf)` (вимірюється в дБн/Гц на відстані `Δf` від несучої).

Коли на змішувач приймача надходить потужний позасмуговий сигнал завади `P_adj` на відстані `Δf` від частоти налаштування, він перемножується з шумовою спідницею гетеродина і переноситься прямо в смугу проміжної частоти (IF). Додаткова густина шуму на вході детектора дорівнює:

```
P_noise,recip (дБм) = P_adj (дБм) + L(Δf) (дБн/Гц) + 10·log₁₀(B)
```

Якщо передавач сусіднього дрона на відстані `Δf = 37 МГц` створює на вході змішувача рівень `P_adj = −15 дБм`, а фазовий шум гетеродина на цій розстройці становить `L(37 МГц) = −120 дБн/Гц`, то в смузі `B = 20 МГц` (`73 дБ·Гц`) підняття шумового порогу складе:

```
P_noise,recip = −15 − 120 + 73 = −62 дБм
```

Шумовий поріг приймача зростає з −96 дБм до −62 дБм (на **34 дБ!**), що повністю позбавляє приймач здатності приймати далекі слабкі сигнали.

## Теорія безконфліктних частотних сіток: різницеві трикутники та лінійки Голомба

Математична проблема вибору робочих частот для `N` пілотів полягає в пошуку множини цілих або дробових чисел `{f₁, f₂, ..., f_N}`, для якої не виконується жодна з умов колізії:

1. **Колізія прямого збігу (Co-channel):** `f_i = f_j` (при `i ≠ j`);
2. **Колізія 2-тонового IMD3:** `2·f_i − f_j = f_k` (при `i ≠ j`);
3. **Колізія 3-тонового IMD3:** `f_i + f_j − f_k = f_m` (при `i, j, k, m` різних).

### Доведення неминучості колізій у рівномірних сітках

Нехай частоти задано рівномірною сіткою `f_k = f₀ + k·Δf`, де `k ∈ {1, 2, ..., M}` — цілочисельний індекс каналу.

Розглянемо вираз для 2-тонового IMD3 між довільними двома каналами `a` та `b`:

```
f_IMD3 = 2·f_b − f_a                   [означення частоти 2-тонового IMD3]
       = 2·(f₀ + b·Δf) − (f₀ + a·Δf)  [підстановка виразу рівномірної сітки]
       = 2·f₀ − f₀ + (2·b − a)·Δf     [розкриття дужок і групування]
       = f₀ + (2·b − a)·Δf            [зведення подібних доданків]
```

Оскільки індекси `a` та `b` є цілими числами, величина `c = 2·b − a` **завжди є цілим числом**. Якщо обчислене значення `c` лежить у діапазоні робочих каналів `1 ≤ c ≤ M`, продукт IMD3 **ідеально точно збігається** з несучою частотою каналу `f_c`.

**Приклад для Band F (крок 20 МГц, F1 = 5740 МГц, F2 = 5760 МГц, F3 = 5780 МГц):**
- Пілот 1 на каналі F1 (`a = 1`);
- Пілот 2 на каналі F2 (`b = 2`);
- Продукт інтермодуляції: `c = 2·(2) − 1 = 3` → канал F3 (5780 МГц).
- **Результат:** канал F3 виявляється заблокованим безпосередньо за рахунок випромінювання F1 та F2.

### Математичний критерій лінійки Голомба (Golomb Ruler) та множин Сідона

Щоб усунути інтермодуляційні колізії 3-го порядку, частотні інтервали між усіма парами каналів повинні бути взаємно унікальними.

Перепишемо умову колізії 3-тонового IMD3 `f_i + f_j − f_k = f_m` у вигляді різниць:

```
f_i − f_k = f_m − f_j   (або Δf_{i,k} = Δf_{m,j})
```

Множина частот `{f₁, f₂, ..., f_N}` є повністю вільною від продуктів IMD3 тоді й лише тоді, коли **всі попарні різниці `|f_i − f_j|` для всіх `i < j` є строго різними**. Така множина в математиці називається **множиною Сідона (Sidon Set)** або **лінійкою Голомба (Golomb Ruler)**.

### Оптимальні розкладки каналів на базі лінійок Голомба

1. **4-канальна оптимальна сітка (лінійка Голомба {0, 1, 4, 6}):**
   - Базовий крок `Δ = 38 МГц`, початкова частота `5650 МГц`;
   - **Канал 1:** 5650 МГц (`0 · 38`);
   - **Канал 2:** 5688 МГц (`1 · 38`);
   - **Канал 3:** 5802 МГц (`4 · 38`);
   - **Канал 4:** 5878 МГц (`6 · 38`).
   - Усі попарні різниці частот: `{38, 152, 228, 114, 190, 76}` МГц — кожне число строго унікальне! Жоден продукт IMD3 не потрапляє на жоден робочий канал.

2. **5-канальна сітка (лінійка Голомба {0, 1, 4, 9, 11}):**
   - Базовий крок `Δ = 25 МГц`, початкова частота `5650 МГц`;
   - Канал 1: 5650 МГц (`0 · 25`);
   - Канал 2: 5675 МГц (`1 · 25`);
   - Канал 3: 5750 МГц (`4 · 25`);
   - Канал 4: 5875 МГц (`9 · 25`);
   - Канал 5: 5925 МГц (`11 · 25`).
   - Попарні різниці: `{25, 100, 225, 275, 75, 200, 250, 125, 175, 50}` МГц. Жодних повторень різниць.
