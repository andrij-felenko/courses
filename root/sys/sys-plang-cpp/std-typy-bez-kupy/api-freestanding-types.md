# 📋 Довідник інтерфейсу: типи без купи у freestanding C++

В автономному середовищі (англ. *freestanding implementation*) стандарт C++ гарантує доступність набору типів і утиліт, які не вимагають підтримки операційної системи, системного завантажувача динамічних бібліотек, винятків (`-fno-exceptions`) або системної купи (`malloc`/`free`).

Цей довідник містить систематизований опис інтерфейсів, внутрішнього розміщення в пам'яті, угод про виклики (ABI), часової складності та правил безпеки для типів `std::array`, `std::span`, `std::string_view`, `std::optional` та `std::variant`.

## Статус типів у стандартах ISO C++ Freestanding

Згідно зі стандартом ISO/IEC 14882 (пункт 4.1), реалізація C++ може бути повною (англ. *hosted*) або автономною (англ. *freestanding*). Автономна реалізація призначена для систем без операційної системи, завантажувачів ядер ОС та вбудованих мікроконтролерів.

Починаючи зі стандарту C++20 і завдяки роботі групи стандартизації ISO WG21 (зокрема пропозиціям P0829 «Freestanding Proposal», P1642 «Freestanding Library: Easy Utilities», P2264 «Make std::optional Freestanding» та P2833 «Freestanding Library: in-place abstractions»), перелік обов'язкових заголовків для автономного режиму було суттєво розширено.

1. `<array>` — повністю автономний починаючи з C++11, забезпечує нульові накладні витрати над фіксованими блоками пам'яті.
2. `<span>` — повністю автономний починаючи з C++20, надає безпечні неволодіючі проєкції над довільними неперервними діапазонами.
3. `<string_view>` — повністю автономний починаючи з C++20 (формально стандартизований у C++17, оновлений у C++20 для підтримки `constexpr` та методів `starts_with`/`ends_with`).
4. `<optional>` — повністю автономний у C++23, усуває використання динамічної пам'яті для опціональних результатів.
5. `<variant>` — повністю автономний у C++23, надає типобезпечний розмічений союз без віртуальних таблиць та викликів алокатора.

## std::array<T, N>

Фіксований послідовний контейнер зі значеннєвою семантикою та нульовими накладними витратами.

### Структура пам'яті та особливості ABI

Об'єкт `std::array<T, N>` розташовується в пам'яті як суцільний масив `T[N]`. Якщо тип `T` є тривіально копійованим (англ. *trivially copyable*), `std::array` зберігає всі властивості тривіального типу.
- **Розмір:** `sizeof(std::array<T, N>) = sizeof(T) * N`. Для `N = 0` розмір дорівнює 1 байту за вимогами мови щодо унікальності адрес об'єктів.
- **Вирівнювання:** `alignof(std::array<T, N>) = alignof(T)`.
- **Розміщення:** Залежно від контексту оголошення потрапляє у стек процесу (локальна змінна), сегмент `.bss` (статичний неініціалізований масив), сегмент `.data` (статичний ініціалізований масив) або Flash-пам'ять `.rodata` (`constexpr`).

### Сигнатури методів та часова складність

- `constexpr T* data() noexcept` — повертає прямий покажчик на перший елемент масиву. Складність `O(1)`.
- `constexpr const T* data() const noexcept` — константна версія доступу до пам'яті. Складність `O(1)`.
- `constexpr size_type size() const noexcept` — повертає константу `N`. Складність `O(1)`.
- `constexpr reference operator[](size_type pos)` — прямий доступ до елемента без перевірки меж. Складність `O(1)`.
- `constexpr reference at(size_type pos)` — доступ із перевіркою меж. За умов `-fno-exceptions` вихід за межі викликає аварійний зупин `std::terminate()`.
- `constexpr reference front() noexcept` — посилання на перший елемент. Складність `O(1)`.
- `constexpr reference back() noexcept` — посилання на останній елемент. Складність `O(1)`.
- `constexpr void fill(const T& value)` — присвоює значення `value` усім елементам. Складність `O(N)`.
- `constexpr bool empty() const noexcept` — повертає `N == 0`. Складність `O(1)`.

## std::span<T, Extent>

Неволодіюча типізована проєкція над неперервним діапазоном пам'яті.

### Механізм екстентів та передача у регістри процесора

Параметр шаблону `Extent` визначає поведінку структури:
1. **Динамічний екстент (`std::dynamic_extent`):** Складається з двох полів — вказівника на дані `T* ptr_` та довжини `std::size_t size_`. Займає 8 байтів на 32-бітних архітектурах ARM Cortex-M і передається у регістрах `r0` та `r1` згідно з угодою AAPCS.
2. **Статичний екстент (`std::span<T, N>`):** Складається виключно з вказівника `T* ptr_`. Займає 4 байти на 32-бітних архітектурах і передається в одному регістрі `r0`. Довжина `N` зберігається у типі та повертається методом `size()` як константа часу компіляції.

### Операції поділу та доступу до пам'яті

- `constexpr pointer data() const noexcept` — вказівник на початок послідовності. Складність `O(1)`.
- `constexpr size_type size() const noexcept` — кількість елементів у спані. Складність `O(1)`.
- `constexpr size_type size_bytes() const noexcept` — загальний розмір діапазону в байтах (`size() * sizeof(T)`). Складність `O(1)`.
- `constexpr span<T, Count> first<Count>() const` — виділяє перші `Count` елементів зі статичним розміром. Складність `O(1)`.
- `constexpr span<T, dynamic_extent> first(size_type count) const` — виділяє перші `count` елементів із динамічним розміром. Складність `O(1)`.
- `constexpr span<T, Count> last<Count>() const` — виділяє останні `Count` елементів. Складність `O(1)`.
- `constexpr auto subspan(size_type offset, size_type count = dynamic_extent) const` — формує зріз починаючи зі зміщення `offset`. Складність `O(1)`.

### Байтові трансформації

- `std::as_bytes(span<T, N>)` — перетворює спан на `std::span<const std::byte, ...>` для безпечного читання сирої пам'яті.
- `std::as_writable_bytes(span<T, N>)` — перетворює неконстантний спан на `std::span<std::byte, ...>` для запису байтів без порушення правил сумісності типів.

## std::string_view

Неволодіюча проєкція над послідовністю символів без обов'язкового завершального нуля `\0`.

### Структура та контракт використання

`std::string_view` зберігає покажчик `const char* str_` та кількість символів `std::size_t len_`.
- **Розмір:** 8 байтів на 32-бітних процесорах (2 машинних слова).
- **Відсутність нуль-термінатора:** Рядок не зобов'язаний закінчуватися байтом `0x00`. Передача `sv.data()` у функції C-бібліотеки на зразок `printf("%s", sv.data())` чи `strlen(sv.data())` є грубою помилкою, що призводить до невизначеної поведінки (UB).
- **Безпечний парсинг чисел:** Для перетворення текстових чисел у цілі або дробові значення використовується заголовок `<charconv>` та функція `std::from_chars(sv.data(), sv.data() + sv.size(), value)`.

### Основні методи маніпуляції вікном спостереження

- `constexpr void remove_prefix(size_type n) noexcept` — переміщує початок вікна вперед на `n` символів. Складність `O(1)`.
- `constexpr void remove_suffix(size_type n) noexcept` — переміщує кінець вікна назад на `n` символів. Складність `O(1)`.
- `constexpr string_view substr(size_type pos = 0, size_type count = npos) const` — вирізає підрядок за постійний час `O(1)` без виклику `malloc`.
- `constexpr bool starts_with(string_view sv) const noexcept` — перевіряє наявність префікса. Складність `O(M)`.
- `constexpr bool ends_with(string_view sv) const noexcept` — перевіряє наявність суфікса. Складність `O(M)`.
- `constexpr size_type find(string_view sv, size_type pos = 0) const noexcept` — пошук підрядка. Складність `O(N * M)`.

## std::optional<T>

Контейнер значеннєвої семантики для збереження значення або стану порожнечі `std::nullopt` без використання динамічної купи.

### Внутрішня будова та розмір

- **Буфер зберігання:** `alignas(T) std::byte storage_[sizeof(T)]`.
- **Прапорець стану:** `bool has_value_`.
- **Формула розміру:** `sizeof(std::optional<T>) = sizeof(T) + alignof(T)` (з урахуванням padding). Наприклад, `sizeof(std::optional<uint8_t>) = 2`, `sizeof(std::optional<uint32_t>) = 8`.
- **Життєвий цикл:** Пам'ять резервується заздалегідь. Конструктор `T` викликається через placement new лише при ініціалізації значенням. При виклику `reset()` або знищенні `optional` явно викликається деструктор `~T()`.

### Методи доступу та монадичні операції C++23

- `constexpr bool has_value() const noexcept` — повертає `true`, якщо об'єкт містить ініціалізоване значення.
- `constexpr explicit operator bool() const noexcept` — аналог `has_value()`.
- `constexpr T& operator*() & noexcept` — прямий доступ до розіменованого значення. Розіменування порожнього `optional` є невизначеною поведінкою.
- `constexpr T value_or(U&& default_value) const&` — повертає значення об'єкта або значення за замовчуванням `default_value`.
- `constexpr T& emplace(Args&&... args)` — конструює об'єкт `T` на місці через аргументи конструктора.
- `constexpr void reset() noexcept` — знищує активний об'єкт і скидає стан у `std::nullopt`.
- `opt.and_then(F)` — монадичне зв'язування: викликає функцію `F(*opt)`, яка повертає новий `std::optional`.
- `opt.transform(F)` — застосовує функцію `F(*opt)` і автоматично огортає результат у `std::optional`.
- `opt.or_else(F)` — викликає відновлювальну функцію `F()`, якщо `opt` є порожнім.

## std::variant<Ts...>

Типобезпечний розмічений союз із гарантією захисту від неініціалізованого читання на етапі компіляції.

### Структура пам'яті та керування типами

- **Буфер зберігання:** `alignas(max(alignof(Ts)...)) std::byte storage_[max(sizeof(Ts)...)]`.
- **Дискримінант:** `std::size_t index_` — цілочисельний індекс активного типу (від `0` до `sizeof...(Ts) - 1`).
- **Розмір:** `sizeof(std::variant<Ts...>) = max(sizeof(Ts)...) + sizeof(size_t) + padding`.
- **Обробка винятків у freestanding:** Функція `std::get<T>(v)` у разі невідповідності активного типу за наявності прапорця `-fno-exceptions` викликає `std::terminate()`. Для безпечного вилучення значення рекомендовано використовувати `std::get_if<T>(&v)`, який повертає вказівник або `nullptr`.
- **Патерн Overload:** Використання варіативних шаблонів для побудови вичерпного набору лямбда-обробників під час виклику `std::visit`.
