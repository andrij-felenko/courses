# 📋 Довідник інтерфейсу бібліотеки <random>

Заголовочний файл `<random>` надає повний спектр об'єктів для роботи з псевдовипадковими числами: від низькорівневих апаратних та алгоритмічних рушіїв генерації випадкових бітів (URBG) до високорівневих математичних розподілів. Інтерфейс бібліотеки побудовано на засадах жорсткого розділення джерела випадковості та математичного закону його трансформації, що виключає бокові ефекти та гарантує повну потокобезпеку екземплярів.

---

## 1. Концепт URBG (Uniform Random Bit Generator)

Усі генератори випадкових бітів у стандартній бібліотеці C++ повинні відповідати вимогам формального концепту `std::uniform_random_bit_generator` (впровадженого у C++20):

```cpp
template<typename G>
concept uniform_random_bit_generator =
    std::invocable<G&> &&
    std::unsigned_integral<invoke_result_t<G&>> &&
    requires {
        { G::min() } -> std::same_as<invoke_result_t<G&>>;
        { G::max() } -> std::same_as<invoke_result_t<G&>>;
    };
```

### Детальні вимоги та гарантії концепту URBG:
- **Тип вихідного результату `result_type`**: Повинен бути беззнаковим цілочисельним типом (`unsigned int`, `unsigned long`, `unsigned long long` або `uint32_t`, `uint64_t`). Використання значних типів або типів із плаваючою крапкою заборонено на рівні концепту.
- **Оператор виклику `operator()()`**: Повертає наступне беззнакове ціле число у скінченному закритому діапазоні `[G::min(), G::max()]`. Виклик оператора змінює внутрішній стан генератора за сталий час O(1) і не повинен викидати винятки (`noexcept` гарантія для всіх стандартних псевдовипадкових рушіїв).
- **Статичний метод `G::min()`**: Повертає найменше можливе значення, яке здатний згенерувати даний рушій. Для більшості генераторів це значення дорівнює нулю, але для деяких специфічних LCG воно може бути більшим за нуль.
- **Статичний метод `G::max()`**: Повертає найбільше можливе значення генератора. Для 32-бітних генераторів воно дорівнює `4294967295`, а для 64-бітних — `18446744073709551615`.

## 2. Генератори псевдовипадкових чисел (Random Engines)

Стандартна бібліотека містить три фундаментальні класи-шаблони псевдовипадкових генераторів, а також їхні стандартизовані псевдоніми типів.

### 2.1. Лінійний конгруентний генератор `std::linear_congruential_engine`
Обчислює послідовність випадкових чисел за класичною формулою `X[n+1] = (a * X[n] + c) mod m`.

```cpp
template<typename UIntType, UIntType a, UIntType c, UIntType m>
class linear_congruential_engine;
```

#### Параметри шаблону:
- `UIntType`: Беззнаковий цілочисельний тип для збереження внутрішнього стану.
- `a`: Множник (Multiplier). Повинен бути меншим за модуль `m`.
- `c`: Приріст (Increment). Якщо `c = 0`, генератор називається чистим конгруентним генератором Лемера.
- `m`: Модуль (Modulus). Визначає верхню межу періоду. Якщо `m = 0`, модуль приймається рівним `std::numeric_limits<UIntType>::max() + 1`.

#### Стандартизовані псевдоніми типів:
- `std::minstd_rand0`: Використовує константи `a = 16807`, `c = 0`, `m = 2147483647`. Це класичний генератор Лемера, запропонований у 1969 році.
- `std::minstd_rand`: Використовує покращені константи `a = 48271`, `c = 0`, `m = 2147483647`, які забезпечують кращі спектральні характеристики.

---

### 2.2. Генератор Вихору Мерсенна `std::mersenne_twister_engine`
Базується на матричній рекурентній послідовності над скінченним полем Galois Field GF(2) і забезпечує рівномірний розподіл у багатовимірних просторах.

```cpp
template<
    typename UIntType, size_t w, size_t n, size_t m, size_t r,
    UIntType a, size_t u, UIntType d, size_t s,
    UIntType b, size_t t, UIntType c, size_t l, UIntType f
> class mersenne_twister_engine;
```

#### Повний аналіз параметрів шаблону:
- `w`: Розрядність генерованого числа у бітах (32 або 64 біти).
- `n`: Кількість елементів у векторі внутрішнього стану (розмір масиву).
- `m`: Зсув середньої ланки у рекурентному рівнянні (`1 <= m <= n`).
- `r`: Кількість бітів молодшої маски при конкатенації двох сусідніх слів.
- `a`: Матрична векторна константа для побітового множення.
- `u, s, t, l`: Числові величини бітових зсувів у фазі загартування (Tempering Phase).
- `d, b, c`: Бітові маски маскування у фазі загартування.
- `f`: Множник початкового розгортання стану при одночисельному посіві.

#### Стандартизовані псевдоніми типів:
- `std::mt19937`: 32-бітний Mersenne Twister. Розмір стану дорівнює `624` елементи типу `uint32_t` (загалом `2496` байтів). Довжина періоду повторення становить `2^19937 - 1`.
- `std::mt19937_64`: 64-бітний Mersenne Twister. Розмір стану дорівнює `312` елементів типу `uint64_t` (загалом `2496` байтів). Довжина періоду становить `2^19937 - 1`.

---

### 2.3. Генератор із відніманням і переносом `std::subtract_with_carry_engine`
Реалізує алгоритм віднімання з позиченням (Subtract with Carry), який є узагальненням рекурентних генераторів Фібоначчі.

```cpp
template<typename UIntType, size_t w, size_t s, size_t r>
class subtract_with_carry_engine;
```

#### Стандартизовані псевдоніми типів:
- `std::ranlux24_base`, `std::ranlux48_base`: Базові генератори без відкидання елементів.
- `std::ranlux24`, `std::ranlux48`: Оптимізовані адаптери, які відкидають блоки значень за допомогою `std::discard_block_engine` для зниження кореляції між сусідніми числами.

---

### 2.4. Недетерміноване апаратне джерело ентропії `std::random_device`
Забезпечує доступ до справді випадкових чисел, отриманих від апаратних систем або ядра операційної системи.

```cpp
class random_device {
public:
    using result_type = unsigned int;

    explicit random_device(const std::string& token = /* implementation-defined */);
    static constexpr result_type min() { return 0; }
    static constexpr result_type max() { return std::numeric_limits<result_type>::max(); }
    double entropy() const noexcept;
    result_type operator()();

    // Заборона копіювання через системний ресурс
    random_device(const random_device&) = delete;
    random_device& operator=(const random_device&) = delete;
};
```

#### Особливості поведінки та системні інваріанти:
- **Параметр `token`**: Дозволяє вибрати конкретне системне джерело (наприклад, `"/dev/urandom"`, `"/dev/random"` у Linux). За замовчуванням вибирається найкращий системний провайдер.
- **Метод `entropy()`**: Повертає числову оцінку апаратної ентропії. Якщо системний пристрій використовує справжню фізичну ентропію (RDRAND/RDSEED), метод повертає `32.0`. Якщо ж операційна система застосовує псевдовипадковий алгоритм-фолбек, повертається `0.0`.
- **Обробка помилок**: Якщо системний пристрій не вдається відкрити або прочитати, конструктор або `operator()()` викидають виняток `std::system_error`.

## 3. Клас ініціалізації та розсіювання посіву `std::seed_seq`

Клас `std::seed_seq` призначений для якісної ініціалізації генераторів із великим внутрішнім станом (таких як `std::mt19937`), коли початкова ентропія складається з кількох слів.

```cpp
class seed_seq {
public:
    using result_type = uint_least32_t;

    seed_seq() noexcept;
    template<typename InputIt> seed_seq(InputIt first, InputIt last);
    seed_seq(std::initializer_list<result_type> il);

    template<typename RandomIt> void generate(RandomIt begin, RandomIt end);
    size_t size() const noexcept;
    template<typename OutputIt> void param(OutputIt dest) const;

    seed_seq(const seed_seq&) = delete;
    seed_seq& operator=(const seed_seq&) = delete;
};
```

### Механіка двофазного алгоритму `generate(begin, end)`:
Метод приймає діапазон ітераторів для заповнення буфера довжиною `N` слів. Обчислення виконуються у дві послідовні фази:
1. **Пряма фаза (Forward Pass)**: Буфер ініціалізується константою `0x8b8b8b8b`. Кожен елемент змішується з попереднім за допомогою нелінійних бітових зсувів, побітового `XOR` та множення на коефіцієнт `1664525`.
2. **Зворотна фаза (Backward Pass)**: Елементи перемішуються від кінця до початку із використанням коефіцієнта `1566083941`.

Завдяки цьому гарантується лавинний ефект: навіть якщо два вхідних вектори посіву відрізняються лише одним бітом, вихідні масиви значень будуть абсолютно статистично незалежними.

Метод `param(dest)` дозволяє витягнути вихідну послідовність початкових зерен і зберегти її у зовнішньому контейнері для подальшого аналізу.

## 4. Допоміжні адаптери рушіїв (Engine Adaptors)

Адаптери обгортають базовий псевдовипадковий рушій і модифікують його вихідну послідовність для підвищення якості.

- **`std::discard_block_engine<Engine, p, r>`**: З кожної групи у `p` послідовно згенерованих чисел залишає лише перші `r` значень, відкидаючи решту `p - r` елементів. Це руйнує міжциклічні кореляції.
- **`std::independent_bits_engine<Engine, w, UIntType>`**: Пакує біти, отримані від базового генератора, у нові цілі числа точно заданої розрядності `w` бітів.
- **`std::shuffle_order_engine<Engine, k>`**: Зберігає внутрішній буфер із `k` елементів і видає їх у перемішаному порядку за алгоритмом Кнута — Баєса — Дурхема. Стандартний псевдонім: `std::knuth_b`.

Конструктори адаптерів приймають базовий рушій як за значенням (через rvalue переміщення), так і за допомогою створення нового екземпляра з початковим посівом.

## 5. Допоміжні алгоритми нормалізації та вибірки

### 5.1. Канонічна нормалізація `std::generate_canonical`
Генерує дійснозначне число типу `RealType` у напіввідкритому інтервалі `[0.0, 1.0)` із заданою кількістю бітів мантиси `Bits`.

```cpp
template<typename RealType, size_t Bits, typename URBG>
RealType generate_canonical(URBG& g);
```

Функція автоматично розраховує необхідну кількість викликів генератора `g()` для повного заповнення `Bits` бітів мантиси числа плаваючої крапки без утворення прогалин у сітці розподілу.

---

### 5.2. Випадкове перемішування `std::shuffle` та `std::ranges::shuffle`
Перемішує елементи у діапазоні `[first, last)` за допомогою заданого генератора бітів `g` за сталий амортизований час O(N).

```cpp
template<typename RandomIt, typename URBG>
void shuffle(RandomIt first, RandomIt last, URBG&& g);
```

У C++20 алгоритм `std::ranges::shuffle` дозволяє передавати контейнери напряму без явного вказання ітераторів `begin()` та `end()`. Алгоритм реалізує беззсувну перестановку Фішера — Єйтса. Старий алгоритм `std::random_shuffle` вилучено у C++17 через використання глобального `std::rand()`.

---

### 5.3. Випадкова вибірка `std::sample`
Вибирає `n` випадкових елементів із популяції `[first, last)` без повторень і копіює їх у вихідний ітератор `out`.

```cpp
template<typename PopulationIt, typename SampleIt, typename Distance, typename URBG>
SampleIt sample(PopulationIt first, PopulationIt last, SampleIt out, Distance n, URBG&& g);
```

Якщо ітератори популяції належать до категорії `std::random_access_iterator`, алгоритм застосовує швидку вибірку за індексами за час O(N). Для однонаправлених ітераторів застосовується резервуарна вибірка (Reservoir Sampling).

---

## 6. Вичерпний перелік математичних розподілів

Усі розподіли є легковагими об'єктами, які зберігають параметри закону ймовірностей і перетворюють бітовий потік генератора `g`.

### 6.1. Рівномірні розподіли (Uniform Distributions)
- **`std::uniform_int_distribution<IntType>`**: 
  - Повертає цілі числа у закритому інтервалі `[a, b]`.
  - Використовує алгоритм Rejection Sampling або безділильний метод Леміра для усунення бітового зміщення Modulo Bias.
- **`std::uniform_real_distribution<RealType>`**:
  - Повертає дійснозначні числа у напіввідкритому інтервалі `[a, b)`.
  - Забезпечує точне мапування бітів мантиси IEEE 754.

---

### 6.2. Бернулліївські розподіли (Bernoulli Distributions)
- **`std::bernoulli_distribution`**:
  - Видає булеве значення `true` із ймовірністю `p` та `false` із ймовірністю `1 - p`.
- **`std::binomial_distribution<IntType>`**:
  - Моделює кількість успішних випробувань Бернуллі у серії з `t` спроб із ймовірністю успіху `p`.
- **`std::geometric_distribution<IntType>`**:
  - Моделює кількість невдач до настання першого успіху.
- **`std::negative_binomial_distribution<IntType>`**:
  - Моделює кількість невдач до настання `k`-го успіху.

---

### 6.3. Пуассонівські та безперервні розподіли часу
- **`std::poisson_distribution<IntType>`**:
  - Моделює кількість подій за фіксований інтервал при інтенсивності `lambda > 0`.
  - Для малих `lambda < 10` застосовує метод Кнута, для великих `lambda >= 10` — відсікальну вибірку з лоренцівською огинаючою.
- **`std::exponential_distribution<RealType>`**:
  - Моделює час між незалежними подіями пуассонівського потоку за формулою `X = -ln(U) / lambda`.
- **`std::gamma_distribution<RealType>`**:
  - Моделює суму декількох експоненційно розподілених величин з параметрами `alpha` та `beta`.
- **`std::weibull_distribution<RealType>`**:
  - Застосовується у теорії надійності для аналізу часу до відмови обладнання.
- **`std::extreme_value_distribution<RealType>`**:
  - Моделює розподіл максимальних значень Гумбеля.

---

### 6.4. Нормальні розподіли (Normal Distributions)
- **`std::normal_distribution<RealType>`**:
  - Моделює класичний гаусівський розподіл із параметрами середнього значення `m` та стандартного відхилення `s > 0`.
  - Застосовує алгоритм Ціккурат або трансформацію Бокса — Мюллера.
- **`std::lognormal_distribution<RealType>`**:
  - Моделює логнормальний розподіл величини `X = exp(Y)`, де `Y` належить normal_distribution.
- **`std::chi_squared_distribution<RealType>`**:
  - Моделює хі-квадрат розподіл із `n` ступенями свободи для перевірки статистичних гіпотез.
- **`std::cauchy_distribution<RealType>`**:
  - Моделює розподіл Коші з параметрами розташування `a` та масштабу `b`.
- **`std::fisher_f_distribution<RealType>`**, **`std::student_t_distribution<RealType>`**:
  - Спеціалізовані статистичні розподіли Фішера та Стьюдента для оцінки довірчих інтервалів.

---

### 6.5. Вибіркові та інтервальні розподіли (Sampling Distributions)
- **`std::discrete_distribution<IntType>`**:
  - Дискретний розподіл за довільним списком вагових коефіцієнтів `{w[0], w[1], ..., w[n-1]}`.
  - Операція вибірки виконується за сталий час O(1) завдяки попередній побудові таблиці псевдонімів Волкера (Alias Table).
- **`std::piecewise_constant_distribution<RealType>`**:
  - Кусочно-постійна щільність ймовірностей на прямокутних підінтервалах `[b[0], b[1]), [b[1], b[2]), ..., [b[n-1], b[n])`.
- **`std::piecewise_linear_distribution<RealType>`**:
  - Кусочно-лінійна щільність ймовірностей із лінійною інтерполяцією між заданими граничними точками.

---

## 7. Параметри розподілів та структура `param_type`

Кожен клас розподілу `D` містить вкладений тип `D::param_type`, який дозволяє зберігати, передавати та змінювати параметри розподілу без перестворення самого об'єкта.

```cpp
#include <iostream>
#include <random>

int main() {
    std::mt19937 rng(42);
    std::uniform_int_distribution<int> dist(1, 10);

    // Отримання поточних параметрів
    auto p1 = dist.param();
    std::cout << "Початковий діапазон: [" << p1.a() << ", " << p1.b() << "]\n";

    // Зміна параметрів через param_type без створення нового розподілу
    using param_t = std::uniform_int_distribution<int>::param_type;
    dist.param(param_t(50, 100));

    std::cout << "Нове значення у діапазоні [50, 100]: " << dist(rng) << "\n";
    return 0;
}
```

Конструкція `dist(rng, param)` дозволяє одноразово перевизначити параметри вибірки для конкретного виклику без зміни внутрішнього стану об'єкта `dist`. Це корисно у ситуаціях, коли функція повинна генерувати випадкові величини з параметрами, що варіюються від виклику до виклику, уникнувши повторної алокації внутрішніх таблиць розподілу.

Крім того, кожна структура `param_type` підтримує оператори порівняння `operator==` та `operator!=`, що дозволяє перевіряти еквівалентність двох налаштувань розподілів.

## 8. Потокова серіалізація стану (Stream I/O)

Усі генератори псевдовипадкових чисел та розподіли підтримують повне збереження та відновлення внутрішнього стану через текстові потоки `std::ostream` та `std::istream`:

```cpp
#include <iostream>
#include <sstream>
#include <random>
#include <cassert>

void test_stream_serialization() {
    std::mt19937 rng1(12345);
    for (int i = 0; i < 100; ++i) rng1(); // Зміщуємо стан

    // Збереження стану генератора у текстовий потік
    std::stringstream ss;
    ss << rng1;

    // Відновлення стану у новому об'єкті
    std::mt19937 rng2;
    ss >> rng2;

    // Обидва генератори видають тотожні числа
    assert(rng1() == rng2());
    std::cout << "✔ Потокова серіалізація стану виконана успішно!\n";
}
```

Текстовий формат потокового збереження стандартизовано для кожного типу генератора. Для `std::mt19937` стан серіалізується у вигляді 624 десяткових цілих чисел, відокремлених пробілами, плюс поточний індекс зміщення в масиві.

## 9. Нововведення C++20: Можливість обчислення під час компіляції (`constexpr`)

Починаючи з C++20, операції генерування чисел для класів-шаблонів генераторів (зокрема `std::linear_congruential_engine` та `std::mersenne_twister_engine`) отримали специфікатор `constexpr`. Це дозволяє виконувати ініціалізацію таблиць та створення псевдовипадкових масивів безпосередньо під час компіляції програми:

```cpp
#include <random>
#include <array>

constexpr auto generate_compile_time_table() {
    std::array<uint32_t, 10> table{};
    std::minstd_rand rng(42);
    for (auto& val : table) {
        val = rng();
    }
    return table;
}

// Таблиця обчислюється під час компіляції і розміщується у секції констант .rodata
constexpr auto random_table = generate_compile_time_table();
```

Компілятор гарантує, що `random_table` буде вичислено на етапі збірки, усуваючи накладні витрати на генерацію під час виконання програми.

## 10. Гарантії потокобезпеки та відсутність винятків

1. **Гарантія потокобезпеки**: Самі по собі об'єкти генераторів та розподілів не є атомарними чи потокобезпечними. Одночасний виклик `operator()()` над одним екземпляром з кількох потоків виконання викликає стан гонитви (Data Race). Для багатопотокового використання рекомендовано застосовувати специфікатор `thread_local`.
2. **Гарантія винятків**: Метод `operator()()` усіх псевдовипадкових рушіїв (`std::mt19937`, `std::minstd_rand`) володіє гарантією `noexcept`. Викидання винятків `std::system_error` можливе лише при роботі з `std::random_device`, якщо операційна система відмовляє у відкритті системного файлу ентропії.

## 11. Розширене проектування власних розподілів

Розробники мають можливість створювати власні класи розподілів, які інтегруються у стандартну екосистему `<random>`. Для цього власний клас розподілу повинен надавати вкладений тип `param_type`, статичні методи `min()` та `max()`, метод `reset()` для скидання внутрішнього кешу (наприклад, збереженого гаусового значення) та двохверсійний оператор виклику `operator()(g)` і `operator()(g, param)`.

Ця гнучкість дозволяє адаптувати стандартну бібліотеку для вирішення вузькоспеціалізованих задач моделювання фізичних процесів, штучного інтелекту та економічних агентів у симуляціях будь-якого рівня складності.

## 12. Порівняльний аналіз розподілів та сумісність з іншими бібліотеками

Усі математичні розподіли з `<random>` є повністю сумісними з паралельними алгоритмами C++17 (`std::execution::par`) та діапазонами C++20 (`std::ranges`). Вони надають стандартизований та переносний інтерфейс, який забезпечує повну відтворюваність статистичних результатів між різними компіляторами (GCC, Clang, MSVC) при використанні однакового рушія та початкового посіву.

Використання стандартизованого інтерфейсу гарантує чистоту, переносність та підтримуваність коду у промислових високопродуктивних проектах будь-якої складності.

Завдяки цьому розробники отримують потужний та гнучкий інструментарій для побудови надійного програмного забезпечення у сферах ігрового розроблення, моделювання та фінансової аналітики. Повний огляд усіх компонентів підтверджує зрілість та універсальність архітектури бібліотеки random. Огляд усіх API надає повне уявлення про доступні інструменти та правила їхньої побудови у modern C++. Системний підхід дозволяє створювати високонадійне програмне забезпечення без зайвих витрат ресурсів пам'яті.
