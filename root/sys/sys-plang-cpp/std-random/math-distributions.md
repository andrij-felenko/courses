# 🧮 Математична механіка трансформації розподілів

Будь-який псевдовипадковий генератор випадкових бітів (URBG) у заголовочному файлі `<random>` повертає рівномірно розподілені беззнакові цілі числа у фіксованому скінченному діапазоні `[g.min(), g.max()]`. Для отримання випадкових величин, які підпорядковуються іншим математичним законам ймовірностей (нормальному, експоненційному, пуассонівському чи дискретному категоріальному), стандартна бібліотека C++ застосовує аналітичні та числові ймовірнісні трансформації.

Вся система розділена на два класи алгоритмів: безперервні трансформації (базовані на обчисленні обернених функцій та гелікоїдальних полярних проекціях) та дискретні табульовані вибірки (базовані на заповненні огинаючих кошиків).

---

## 1. Метод оберненої функції розподілу (Inverse Transform Sampling)

Метод оберненої функції розподілу є фундаментальним і найбільш універсальним способом отримання безперервних випадкових величин із заданою кумулятивною функцією розподілу `F(x)`.

### 1.1. Математичне доведення теореми обернення
Нехай `U` — випадкова величина, рівномірно розподілена на відкритому інтервалі `(0, 1)`. Нехай `F(x)` — строго зростаюча непреривна кумулятивна функція розподілу із строго визначеною оберненою функцією `F^-1(u)`.

Тоді випадкова величина `X = F^-1(U)` має функцію розподілу, яка є тотожно рівною цільовій функції `F(x)`.

```math
P(X <= x) = P(F^-1(U) <= x)       [Застосовуємо монотонну функцію F до обох частин]
         = P(U <= F(x))          [Враховуємо рівномірність U на інтервалі (0, 1)]
         = F(x)                  [Отримано цільову функцію розподілу]
```

Це математичне доведення показує, що для отримання вибірки будь-якого безперервного розподілу достатньо взяти рівномірну вибірку `U` та обчислити значення оберненої функції `F^-1(U)`.

---

### 1.2. Математичне виведення для Експоненційного розподілу
Експоненційний розподіл моделює тривалість часу між двома послідовними незалежними подіями у найпростішому пуассонівському потоці з інтенсивністю `lambda > 0`.

Щільність ймовірності даного розподілу має вигляд:

```
f(x) = lambda * e^(-lambda * x),  при x >= 0
```

Для знаходження кумулятивної функції розподілу `F(x)` обчислюємо визначений інтеграл від щільності на інтервалі від 0 до `x`:

```math
F(x) = integral_0^x (lambda * e^(-lambda * t)) dt    [Первісна функція дорівнює -e^(-lambda * t)]
     = 1 - e^(-lambda * x)                          [Визначений інтеграл на інтервалі [0, x]]
```

Тепер прирівнюємо отриману кумулятивну функцію `F(x)` до рівномірної випадкової змінної `u` на інтервалі `(0, 1)` і виражаємо шукану величину `x`:

```math
u = 1 - e^(-lambda * x)          [Переносимо експоненту в ліву частину]
e^(-lambda * x) = 1 - u          [Логарифмуємо обидві частини рівняння]
-lambda * x = ln(1 - u)          [Ділимо обидві частини на -lambda]
x = -ln(1 - u) / lambda          [Остаточна аналітична формула трансформації]
```

Оскільки випадкова величина `1 - u` на відкритому інтервалі `(0, 1)` розподілена абсолютно тотожно до `u`, аналітична формула у реалізації класу `std::exponential_distribution` спрощується до вигляду `X = -ln(U) / lambda`.

---

### 1.3. Виведення для Рівномірного дійснозначного розподілу `std::uniform_real_distribution`
Для отримання дійснозначного числа плаваючої крапки типу `double` у напіввідкритому інтервалі `[a, b)` спочатку генерується 53 випадкових біти для заповнення мантиси у форматі IEEE 754:

```math
u = bits53 / 2^53                [Отримуємо значення u на інтервалі [0, 1)]
```

Після отримання нормованого числа `u` застосовується масштабувальна лінійна трансформація:

```
X = a + u * (b - a)
```

Ця формула забезпечує абсолютну рівномірність щільності ймовірностей на всьому інтервалі `[a, b)` без виникнення модульного зміщення чи втрати розрядності.

---

### 1.4. Аналітичне виведення для розподілу Вейбулла
Розподіл Вейбулла моделює час до відмови складних технічних систем та деталей з урахуванням ефекту зносу. Його щільність ймовірності визначається двома параметрами: формою `a > 0` та масштабом `b > 0`.

Кумулятивна функція розподілу має аналітичний вигляд:

```
F(x) = 1 - exp(-(x / b)^a),  при x >= 0
```

Прирівнюючи `F(x)` до рівномірної змінної `u` на інтервалі `(0, 1)`, виражаємо цільове значення `x`:

```math
u = 1 - exp(-(x / b)^a)            [Переносимо експоненту]
exp(-(x / b)^a) = 1 - u            [Логарифмуємо обидві частини]
-(x / b)^a = ln(1 - u)             [Змінюємо знак і беремо корінь степеня a]
x = b * (-ln(1 - u))^(1 / a)       [Остаточна формула вибірки Вейбулла]
```

Завдяки симетрії рівномірного розподілу вираз `1 - u` замінюється на `u`, що дозволяє обчислювати вибірку Вейбулла за один виклик натурального логарифма та піднесення до дробового степеня.

---

### 1.5. Аналітичне виведення для розподілу Коші `std::cauchy_distribution`
Розподіл Коші описує фізичні процеси з вкрай довгими хвостами (наприклад, розподіл точок влучання повертаного променя на екран). Щільність ймовірності має вигляд:

```
f(x) = 1 / (pi * b * (1 + ((x - a) / b)^2))
```

Кумулятивна функція розподілу обчислюється через арктангенс:

```math
F(x) = (1 / pi) * arctan((x - a) / b) + 1/2   [Інтеграл від раціонального дробу]
```

Прирівнюючи `F(x)` до рівномірної вибірки `u`, отримуємо аналітичну обернену функцію:

```math
u - 1/2 = (1 / pi) * arctan((x - a) / b)       [Множимо на pi]
tan(pi * (u - 1/2)) = (x - a) / b             [Домножуємо на b і додаємо a]
x = a + b * tan(pi * (u - 1/2))               [Формула генерації розподілу Коші]
```

Клас `std::cauchy_distribution` реалізує саме цю формулу через виклик стандартної функції `std::tan`.

## 2. Гаусів розподіл: Трансформація Бокса — Мюллера та Метод Ціккурат

Стандартний нормальний (Гаусів) розподіл із середнім значенням `m` та дисперсією `s^2` володіє наступною симетричною щільністю ймовірності:

```
f(x) = (1 / (s * sqrt(2 * pi))) * exp(-(x - m)^2 / (2 * s^2))
```

Кумулятивна функція даного розподілу `F(x)` виражається через спецфункцію помилок `erf(x)`, що унеможливлює знаходження прямої аналітичної оберненої функції `F^-1(u)`.

---

### 2.1. Алгебраїчне виведення трансформації Бокса — Мюллера
У 1958 році Джордж Бокс та Мервін Мюллер запропонували точний метод генерації двох незалежних стандартних нормальних величин `Z0` та `Z1` з двох незалежних рівномірних величин `U1, U2` на інтервалі `(0, 1)`:

```math
Z0 = sqrt(-2 * ln(U1)) * cos(2 * pi * U2)    [Перша незалежна гаусова величина]
Z1 = sqrt(-2 * ln(U1)) * sin(2 * pi * U2)    [Друга незалежна гаусова величина]
```

#### Доведення через Двовимірний Якобіан переходу:
Спільна щільність ймовірностей для двох незалежних стандартних нормальних величин `(Z0, Z1)` дорівнює добутку їхніх поодиноких щільностей:

```math
f(z0, z1) = (1 / (2 * pi)) * exp(-(z0^2 + z1^2) / 2)   [Двовимірний гаусів дзвін]
```

Переходимо до полярної системи координат `z0 = R * cos(Theta)`, `z1 = R * sin(Theta)`, де `R^2 = z0^2 + z1^2`.

Обчислюємо детермінант матриці Якобі (Якобіан) переходу від полярних координат `(R, Theta)` до декартових `(z0, z1)`:

```math
J = R                            [Матриця Якобі має детермінант R]
f(R, Theta) dR dTheta = (1 / (2 * pi)) * exp(-R^2 / 2) * R dR dTheta   [Розділяємо змінні]
```

Інтегруючи за кутом `Theta` від `0` до `2 * pi`, отримуємо рівномірний розподіл кута `Theta = 2 * pi * U2`.

Для радіуса `R` кумулятивна функція розподілу дорівнює:

```math
F(R) = 1 - exp(-R^2 / 2)         [Інтегруємо вираз R * exp(-R^2 / 2)]
```

Прирівнюючи `F(R)` до рівномірної змінної `1 - U1`, отримуємо величину радіуса `R = sqrt(-2 * ln(U1))`.

---

### 2.2. Полярна модифікація Марсальї
Для уникнення важких тригонометричних обчислень функцій `cos` та `sin` застосовують Полярну модифікацію Марсальї:
1. Генеруються дві рівномірні вибірки `V1, V2` у квадраті `[-1, 1]`.
2. Обчислюється квадрат відстані до центру `S = V1^2 + V2^2`.
3. Якщо `S >= 1` або `S == 0`, точка відкидається (Rejection Sampling).
4. Якщо `S < 1`, заставляємо полярний кут відповідати співвідношенням:

```math
cos(Theta) = V1 / sqrt(S)        [Заміна тригонометричного косинуса]
sin(Theta) = V2 / sqrt(S)        [Заміна тригонометричного синуса]
```

Остаточні формули вибірки набувають вигляду:

```math
Z0 = V1 * sqrt(-2 * ln(S) / S)   [Обчислення першої гаусової величини]
Z1 = V2 * sqrt(-2 * ln(S) / S)   [Обчислення другої гаусової величини]
```

---

### 2.3. Алгоритм Ціккурат (Ziggurat Algorithm)
У сучасних високоефективних бібліотеках (зокрема GCC `libstdc++`) замість методу Бокса — Мюллера використовується Алгоритм Ціккурат, який розділяє гаусів дзвін на 128 або 256 прямокутних шарів одинакової площі.

```
       |--|         <- Шар 127 (Хвіст / Tail)
     |------|       <- Шар 126
   |----------|     <- Шар 125
 |--------------|   <- Шар 0 (Основа)
------------------
```

Для 98% вибірок випадкова точка потрапляє всередину прямокутної частини шару і повертається за 1 такт CPU без будь-яких обчислень плаваючої крапки. Якщо точка потрапляє у крайній підзону або хвіст, виконується точне обчислення через експоненціальне відсікання.

## 3. Дискретні розподіли: Алгоритм Волкера (Alias Method)

Для дискретного розподілу `std::discrete_distribution` із ваговими коефіцієнтами `{w[0], w[1], ..., w[n-1]}` побудова кумулятивного масиву дає складність пошуку `O(log N)`. Метод псевдонімів Волкера дозволяє звести генерацію до сталого часу `O(1)`.

```
Кошик 0: [Основна категорія 0: 70%] [Псевдонім 2: 30%]
Кошик 1: [Основна категорія 1: 40%] [Псевдонім 0: 60%]
Кошик 2: [Основна категорія 2: 100%]
```

### 3.1. Фаза попередньої побудови таблиці Alias Table за O(N)
1. Обчислюється середня висота кошика `mean = sum(w) / N`.
2. Всі категоріальні ймовірності нормалізуються відносно `mean`.
3. Категорії розділяються на два робочі стеки: `Small` (елементи з ймовірністю менше 1.0) та `Large` (елементи з ймовірністю більше або рівно 1.0).
4. У циклі з елемента `Small` заповнюється основа кошика, а недостатній обсяг доповнюється верхівкою з елемента `Large`. За залишковою ймовірністю елемент `Large` повертається у стек `Small` або `Large`.

---

### 3.2. Алгоритм вибірки за час O(1):
1. Генерується випадковий цілочисельний індекс кошика `i` у діапазоні `[0, N-1]`.
2. Генерується дійснозначна монета `U` у діапазоні `[0.0, 1.0)`.
3. Якщо `U < Prob[i]`, повертається значення `i`.
4. Якщо `U >= Prob[i]`, повертається псевдонім `Alias[i]`.

## 4. Пуассонівський розподіл `std::poisson_distribution`

Дискретний розподіл Пуассона виражає ймовірність отримання `k` подій за інтервал часу при середній інтенсивності `lambda`:

```
P(K = k) = (lambda^k * e^-lambda) / k!
```

### 4.1. Алгоритм Кнута для малих `lambda < 10`:
Оскільки інтервали між подіями мають експоненціальний розподіл з параметром `lambda`, кількість подій `k` дорівнює найбільшому цілому числу, для якого сума інтервалів не перевищує 1:

```math
prod_{i=1}^{k+1} U_i < e^-lambda   [Умова зупинки алгоритму Кнута]
```

Генератор послідовно перемножує рівномірні вибірки `U_i` доти, доки їхній добуток не стане меншим за заздалегідь обчислену константу `e^-lambda`. Кількість виконаних множень мінус 1 є цільовим значенням `k`.

---

### 4.2. Метод лоренцівської огинаючої для великих `lambda >= 10`:
При великих значеннях `lambda` обчислення Кнута вимагають занадто багатьох множень. Алгоритм переключається на відсікальну вибірку (Rejection Method), де функція щільності Пуассона наближається неперервною лоренцівською кривою (Cauchy Envelope). Це забезпечує середню кількість викликів генератора на рівні 1.4 вибірок незалежно від величини `lambda`.

---

## 5. Гамма-розподіл `std::gamma_distribution`

Гамма-розподіл з параметром форми `alpha` та масштабу `beta` є узагальненням суми `alpha` експоненціальних величин.

Для `alpha >= 1` клас `std::gamma_distribution` використовує метод Марсальї та Цана (2000):
1. Генерується стандартна нормальна величина `Z`.
2. Обчислюється кубічна трансформація `V = (1 + c * Z)^3`, де `c = 1 / sqrt(9 * alpha - 3)`.
3. Генерується рівномірна вибірка `U`.
4. Якщо `U < 1 - 0.0331 * Z^4` або `ln(U) < 0.5 * Z^2 + d * (1 - V + ln(V))`, вибірка приймається і повертається значення `d * V * beta`, де `d = alpha - 1/3`.

Завдяки цьому високоефективному числовому алгоритму Гамма-розподіл обчислюється практично з такою ж швидкістю, як і нормальний розподіл.

## 6. Логнормальний розподіл `std::lognormal_distribution`

Логнормальний розподіл моделює величину `X`, логарифм якої `Y = ln(X)` має нормальний розподіл `N(m, s^2)`.

Алгоритм генерації у класу `std::lognormal_distribution`:
1. Генерується гаусова вибірка `Y` за допомогою `std::normal_distribution<RealType>(m, s)`.
2. Повертається значення `X = exp(Y)`.

Цей розподіл застосовується у фінансовій математиці для моделювання цін акцій та у біології для опису розмірів живих організмів.

---

## 7. Біноміальний розподіл `std::binomial_distribution`

Біноміальний розподіл моделює кількість успіхів у `t` незалежних випробуваннях Бернуллі з ймовірністю успіху `p`.

Для малих значеннях `t < 30` реалізація прямим чином моделює `t` монетних кидків. Для великих значеннях `t >= 30` застосовується вибірка BTRD (Binomial Transformation Rejection Method), яка базується на кусковій апроксимації нормальним розподілом, забезпечуючи константний час генерації незалежно від кількості спроб `t`.

---

## 8. Кусочно-постійний та кусочно-лінійний розподіли

Клас `std::piecewise_constant_distribution` дозволяє задавати щільність ймовірностей у вигляді східчастої функції на підінтервалах `[b_k, b_{k+1}]`. Вибірка виконується у дві фази: спочатку за методом Волкера вибирається один із підінтервалів відповідно до його площі, після чого у вибраному підінтервалі генерується рівномірне дійснозначне число.

Клас `std::piecewise_linear_distribution` приймає значення щільностей у граничних точках і виконує лінійну інтерполяцію між ними. Вибір підінтервалу виконується за площею трапеції, а всередині підінтервалу рішення квадратичного рівняння перетворює рівномірну змінну у цільове значення.

---

## 9. Розподіли Фішера (F-distribution) та Стьюдента (t-distribution)

Розподіл Стьюдента `std::student_t_distribution` з `n` ступенями свободи моделюється як відношення стандартної нормальної величини `Z` до квадратного кореня незалежної хі-квадрат величини, поділеної на `n`:

```
T = Z / sqrt(Y / n)
```

де `Z` належить `std::normal_distribution`, а `Y` належить `std::chi_squared_distribution(n)`.

Розподіл Фішера `std::fisher_f_distribution` з `m` та `n` ступенями свободи моделюється як відношення двох незалежних нормованих хі-квадрат величин:

```
F = (Y1 / m) / (Y2 / n)
```

Ці спеціалізовані розподіли активно використовуються у математичній статистиці для перевірки нульових гіпотез та побудови довірчих інтервалів.

---

## 10. Геометричний та від'ємний біноміальний розподіли

Геометричний розподіл `std::geometric_distribution` моделює кількість невдач `k` до першого успіху у випробуваннях Бернуллі з ймовірністю `p`. Його обернена кумулятивна функція обчислюється аналітично через логарифм:

```math
k = floor(ln(U) / ln(1 - p))
```

Від'ємний біноміальний розподіл `std::negative_binomial_distribution` є узагальненням геометричного розподілу для `k` успіхів. Завдяки представленню як суміш пуассонівського та гамма-розподілів (Poisson-Gamma Mixture), генерація вибірки здійснюється через спочатку згенеровану гамма-змінну `Y`, яка потім передається у якості параметра `lambda` у пуассонівський розподіл.

---

## 11. Розподіл Гумбеля (Extreme Value Distribution)

Розподіл Гумбеля `std::extreme_value_distribution` моделює граничний розподіл максимальних або мінімальних значень у великих вибірках незалежних випадкових величин. Щільність ймовірності описується формулою:

```
f(x) = (1 / b) * exp(-((x - a) / b + exp(-(x - a) / b)))
```

Застосовуючи метод оберненої функції до кумулятивного виразу, отримуємо подвійно-логарифмічну аналітична формулу вибірки:

```math
X = a - b * ln(-ln(U))
```

Ця формула реалізується всього за два виклики натурального логарифма від рівномірної змінної `U`, забезпечуючи високу швидкість обчислення.

---

## 12. Генерація Багатовимірного Гаусового вектору (Multivariate Normal)

Для моделювання коррельованих випадкових векторів `X ~ N(Mu, Sigma)` з вектором середніх `Mu` та коваріаційною матрицею `Sigma` застосовується розклад Чолеського (Cholesky Decomposition).

Коваріаційна матриця `Sigma` розкладається на добуток нижньотрикутної матриці `L` та її транспонованої `L^T`:

```math
Sigma = L * L^T
```

Спочатку генерується вектор `Z` з `N` незалежних стандартних нормальних величин за допомогою `std::normal_distribution`.

Остаточний корельований вектор `X` обчислюється шляхом матричного множення:

```math
X = Mu + L * Z
```

Цей математичний підхід є основним інструментом у квантовій фінансовій математиці для вимірювання ризиків (Value-at-Risk) та у тривимірній комп'ютерній графіці для генерації корельованого шуму.

---

## 13. Числова стійкість та обробка субнормальних чисел у IEEE 754

Під час обчислення обернених трансцендентних функцій (наприклад, `std::log(U)` при Inverse Transform Sampling) виникає математична небезпека, коли значення рівномірної вибірки `U` прямує до нуля. 

Якщо псевдовипадковий генератор повертає точне значення нуль `U = 0.0`, обчислення натурального логарифма `std::log(0.0)` повертає від'ємну безкінечність `-HUGE_VAL` (`-inf`), що призводить до руйнування подальших фізичних розрахунків та виникнення помилок `NaN` у розрахункових ядрах.

Для запобігання цьому крайовому випадку реалізації математичних розподілів у заголовочному файлі `<random>` застосовують затискання (Clamping) вхідного діапазону. Замість чистого відкритому інтервалу `(0, 1)` рівномірна вибірка масштабується у напіввідкритий інтервал `[std::numeric_limits<RealType>::denorm_min(), 1.0)`.

Крім того, при роботі з денормалізованими (субнормальними) числами плаваючої крапки процесорний блок обчислень FPU/AVX може знижувати пропускну здатність у 10–50 разів через виклик мікрокоду ядра для обробки втрати розрядності. Ввімкнення режимів прапорців компілятора `-ffast-math` або прапорців обнулення субденоміналів `FTZ` (Flush-to-Zero) та `DAZ` (Denormals-are-Zero) на рівнях керуючих регістрів `MXCSR` гарантує збереження пікової продуктивності при обчисленні математичних трансформацій без втрати точності в межах робочих допусків.

## 14. Зведена аналітична таблиця алгоритмів перетворення

| Розподіл | Основний алгоритм | Аналітична формула / Числовий метод | Залежності |
| :--- | :--- | :--- | :--- |
| `exponential_distribution` | Inverse Transform | `X = -ln(U) / lambda` | `std::log` |
| `uniform_real_distribution` | IEEE 754 bit-pack | `X = a + (bits53 / 2^53) * (b - a)` | Pobyte Shift |
| `normal_distribution` | Ziggurat / Box-Muller | 256 прямоугольників або `sqrt(-2ln U1)cos(2piU2)` | Lookup Table / `std::cos` |
| `cauchy_distribution` | Inverse Transform | `X = a + b * tan(pi * (U - 0.5))` | `std::tan` |
| `weibull_distribution` | Inverse Transform | `X = b * (-ln(U))^(1/a)` | `std::log`, `std::pow` |
| `poisson_distribution` | Knuth / Lorentzian | Multiplicative loop або Cauchy envelope | Rejection Sampling |
| `discrete_distribution` | Walker Alias Method | Alias Table O(1) | O(N) prep table |
| `extreme_value_distribution` | Inverse Transform | `X = a - b * ln(-ln(U))` | Dual `std::log` |

Розуміння математичної механіки трансформацій дозволяє розробникам обирати найбільш ефективні класи розподілів для складних фізичних та статистичних симуляцій будь-якого масштабного рівня.
