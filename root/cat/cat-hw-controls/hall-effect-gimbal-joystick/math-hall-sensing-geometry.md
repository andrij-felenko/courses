# Математика магнітного кутового зчитування та корекція нелінійності

## Фізико-математична модель датчика Холла

У механічних аналогових органах керування, таких як класичний [джойстик-модуль](root:cat-hw-controls/ky-023-joystick) чи [поворотний потенціометр](root:cat-hw-controls/rotary-potentiometer), кут відхилення вала зчитується через фрикційний механічний контакт, який з часом зношується. Магнітні джойстики на ефекті Холла (@@en|Hall Effect@@, від прізвища фізика Едвіна Холла) позбавлені цього недоліку, оскільки вимірюють кут безконтактно за допомогою зміни вектора магнітної індукції. Докладніше фізику виникнення поперечної різниці потенціалів пояснює стаття про [датчики Холла](root:ph-condensed/hall-effect).

Пластина напівпровідника, через яку тече струм керування `I`, реагує лише на нормальну (перпендикулярну) складову вектора магнітної індукції `B_perp`. Коли постійний магніт закріплено на валу підвісу (англ. @@en|gimbal@@ — підвіс), його повертання на кут `θ` відносно нормалі змінює проєкцію магнітного поля:

```
V_H
= K_H · I · B_perp                      [закон Холла для перпендикулярного поля]
= K_H · I · B_0 · sin(θ)                [тригонометрична проєкція вектора індукції]
= V_max · sin(θ)                        [згортання сталих параметрів у вихідну амплітуду]
```

Тут `K_H` — коефіцієнт чутливості елемента Холла, `I` — постійний струм живлення, `B_0` — модуль індукції магніту, а `V_max` — максимальна вихідна напруга при перпендикулярному магнітному потоці (`θ = 90°`). Для малих кутів нахилу вихідний потенціал змінюється практично пропорційно куту відхилення.

Проте амплітудне значення `V_max = K_H · I · B_0` не залишається абсолютно сталим під час роботи через фізичний @@en|temperature drift@@ (англ. *temperature drift* — температурний дрейф) його компонентів. Напівпровідниковий кристал реагує на зміну температури навколишнього середовища зміною рухливості носіїв заряду, що спричиняє температурний зсув коефіцієнта чутливості `K_H`. Водночас постійний магніт підвісу при нагріванні втрачає магнітну індукцію `B_0` (зокрема, неодимові магніти втрачають близько `0.12%` індукції на кожні `1 °C`). Сумарний температурний зсув `V_max` призводить до масштабної похибки виміряного кута, що вимагає застосування вбудованих схем термокомпенсації струму живлення `I` або програмного коригування.

## Геометричні причини виникнення синусоїдальної нелінійності

У спрощених розрахунках кут відхилення вала часто вважають пропорційним вихідній напрузі, спираючись на наближення малого кута `sin(θ) ≈ θ` (де кут `θ` виражено у радіанах). Проте функція синуса є нелінійною, і з ростом кута відхилення відносна похибка обчислень швидко зростає.

Оцінимо відносну похибку лінійного припущення для кутів 10°, 20° та 30°:

```
ε_10
= (10° · π / 180° - sin(10°)) / sin(10°) [відносна похибка при куті 10°]
= (0.1745 - 0.1736) / 0.1736            [обчислення значень радіан та синуса]
≈ 0.5%                                  [незначна похибка для малих кутів]

ε_30
= (30° · π / 180° - sin(30°)) / sin(30°) [відносна похибка при куті 30°]
= (0.5236 - 0.5000) / 0.5000            [обчислення значень радіан та синуса]
≈ 4.7%                                  [похибка перевищує припустиму межу]
```

При кутах відхилення важеля понад 15° синусоїдальна крива починає «виполажуватися», через що вихідна напруга зростає повільніше, ніж реальний кут нахилу вала. На краях ходу джойстика це спричиняє стиснення відгуку: однакове фізичне зміщення важеля дає менший приріст електричного сигналу. Якщо не компенсувати цю геометричну нелінійність, точність позиціонування на краях діапазону катастрофічно падає.

## Поліноміальна лінеаризація сигналу в мікроконтролері

Для точного визначення кута `θ` за виміряною напругою `V_H` необхідно обчислити обернену тригонометричну функцію: `θ = arcsin(V_H / V_max)`. Пряме обчислення арксинуса в реальному часі вимагає значних ресурсів процесора, тому у програмному забезпеченні використовують поліноміальну апроксимацію (від грец. *polys* — багатий та *onoma* — ім'я).

Розклад функції арксинуса у ряд Тейлора (названий на честь математика Брука Тейлора, @@en|Taylor Series@@) для нормованої напруги `v = V_H / V_max` має вигляд:

```
θ
= arcsin(v)                             [знаходження точного кута в радіанах]
= v + v³ / 6 + 3·v⁵ / 40 + ...          [розклад у ряд Тейлора навколо нуля]
≈ v + 0.1667 · v³                       [кубічне поліноміальне наближення]
```

Для більшої точності коефіцієнти полінома непарного ступеня `P(v) = a₁ · v + a₃ · v³` знаходять методом найменших квадратів (англ. @@en|Least Squares@@) за реальними калібрувальними точками датчика. Для обчислення в мікроконтролері формулу згортають за схемою Горнера (метод Вільяма Горнера):

```
θ_calc
= v · (a₁ + a₃ · v²)                    [схема Горнера для мінімізації множень]
```

Такий розрахунок вимагає лише двох операцій множення та одного додавання, забезпечуючи відновлення лінійного кута з похибкою менше 0.1% без виклику важкої функції `arcsin()`.

## Таблична корекція та лінійна інтерполяція

На простих 8-бітних мікроконтролерах навіть поліноміальні обчислення з плаваючою комою можуть сповільнювати цикл опитування. У таких системах або при складній нелінійній формі магнітного поля застосовують табличний метод корекції (англ. @@en|Lookup Table@@, LUT).

Калібрувальна крива зберігається в пам'яті у вигляді масиву контрольних точок `LUT[N]` із рівним кроком за напругою. Для довільного проміжного значення виміряної напруги `v` мікроконтролер визначає номер базового інтервалу `i` та виконує лінійну інтерполяцію (від лат. *inter* — між та *polire* — згладжувати):

```
θ_interp
= LUT[i] + (v - v_i) · (LUT[i+1] - LUT[i]) / (v_i+1 - v_i) [лінійна інтерполяція]
```

Оскільки крок між вузлами `Δv = v_i+1 - v_i` обирають як степінь двійки (наприклад, `64` або `128` відліків АЦП), ділення замінюється швидкою операцією побітового зсуву вправо. Таблична корекція з 16-ма вузлами забезпечує високу точність відновлення кута, потребуючи лише кількох цілочисельних операцій процесорного часу.
