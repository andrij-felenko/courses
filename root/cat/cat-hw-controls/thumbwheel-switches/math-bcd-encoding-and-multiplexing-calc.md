## Проблема ліній GPIO та декадне кодування

Пряме підключення роторного перемикача до мікроконтролера у наївній схемі вимагає окремого провідника на кожне положення. Якщо застосувати прямий десятковий код (від англ. @@en|direct 1-of-10 code@@ — прямий код 1-з-10; @@en|1-of-10 code@@), одна 10-позиційна декада займає 10 ліній порту вводу-виводу. Для чотирьохдекадного щитового блоку уставки знадобиться `N_lines = 4 × 10 = 40` ліній `GPIO`, що перевищує наявний ресурс більшості мікроконтролерів.

Вирішенням є двійково-десяткове BCD-кодування (від англ. @@en|binary-coded decimal@@ — двійково-кодоване десяткове число; @@en|BCD@@). Оскільки `2³ < 10 ≤ 2⁴`, будь-яке десяткове число від `0` до `9` описується комбінацією з чотирьох двійкових бітів. Барабанний перемикач BCD містить роторний диск із чотирма концентричними планарними доріжками кодування `8421` (ваги `2⁰=1`, `2¹=2`, `2²=4`, `2³=8`) та спільною шиною `C`. Під час повороту ручки на цифру `D` рухомі контактні щітки замикають шину `C` строго з тими доріжками, біти яких у двійковому розкладі числа `D` дорівнюють одиниці. Для захисту контактного вузла від тривалого механічного зношування планарні мідні доріжки покривають зносостійким гальванічним твердим золотом по нікелевому підшару (англ. @@en|hard gold plating@@), що у поєднанні з консистентним синтетичним мастилом виключає окислення та витирання металу. Такий роторний механізм надійно конвертує положення ручки у чотирибітовий цифровий сигнал. Для аналізу ефективності скорочення апаратури виведемо математичну залежність коефіцієнта економії ліній `K_save` та кількості заощаджених виводів `ΔL` від числа десяткових розрядів `N`. При прямому кодуванні 1-з-10 кількість потрібних ліній порту становить `L_direct = 10 · N`, а при паралельному BCD-кодуванні — `L_bcd = 4 · N`. Обчислимо відносне значення коефіцієнта економії `K_save`:

```
K_save = L_direct ÷ L_bcd
= (10 · N) ÷ (4 · N)                     [підстановка виразів прямого та BCD-коду]
= 10 ÷ 4                                  [скорочення змінного числа розрядів N]
= 2.5                                     [підсумковий сталий коефіцієнт скорочення]
```

Отриманий результат доводить, що BCD-структура дає стале 2.5-кратне зменшення потреби в лініях незалежно від масштабу системи. Абсолютна ж кількість звільнених виходів мікроконтролера `ΔL` лінійно зростає зі збільшенням числа розрядів `N`:

```
ΔL = L_direct - L_bcd
= 10 · N - 4 · N                          [різниця ліній двох систем кодування]
= 6 · N                                   [винесення за дужки кількості розрядів N]
```

Завдяки цьому для блоку з `N = 4` розрядів вивільняється `ΔL = 6 · 4 = 24` виводи `GPIO`, що виключає потребу у використанні додаткових зовнішніх розширювачів порту.

Завдяки цьому замість 10 ліній одна декада вимагає лише 4 сигнальні провідники, скорочуючи кількість ліній `GPIO` в `2.5` рази:

N_lines = N_decades × 4    [розрахунок кількості ліній при паралельному BCD-підключенні]
= 4 × 4 = 16              [підстановка N = 4 декади]

Подальша оптимізація паралельного опитування BCD-шин спирається на принципи, аналогічні підключенню [DIP-перемикачів та джамперних блоків конфігурації](root:cat-hw-controls/dip-switches-and-configuration-blocks).

## Позиційні значення та BCD-код 8421

Кожна декада `k` (від `0` для одиниць до `N - 1` для найстаршого розряду) видає чотирибітовий вектор `Bₖ = (b₃, b₂, b₁, b₀)ₖ`. Десяткова цифра декади `Dₖ` обчислюється скалярним добутком бітів на вагові коефіцієнти `(8, 4, 2, 1)`:

Dₖ = b₃ × 8 + b₂ × 4 + b₁ × 2 + b₀ × 1 [обчислення цифри розряду]

Обчислення підсумкового багатозначного числа `V` здійснюється через поліноміальне згортання (від грец. @@el|polys@@ — численний та лат. @@la|nomen@@ — ім'я; @@en|polynomial convolution@@) розрядів зі зсувом на степені десятки:

```
V = ∑ (Dₖ · 10ᵏ)          [сумування по розрядах k від 0 до N - 1]
= D₀ · 10⁰ + D₁ · 10¹ + D₂ · 10² + ... + Dₙ₋₁ · 10ⁿ⁻¹ [розгортання суми]
```

Розглянемо покроковий алгебраїчний розрахунок для відновлення п'ятизначного числа `V` (`N = 5`) з вектора чотирибітових BCD-сигналів розрядів `B₀`–`B₄`. Задано вхідні вектори декад: одиниці `B₀ = (0, 1, 0, 1)₂`, десятки `B₁ = (0, 0, 0, 0)₂`, сотні `B₂ = (1, 0, 0, 1)₂`, тисячі `B₃ = (0, 0, 1, 1)₂` та десятки тисяч `B₄ = (0, 1, 1, 1)₂`. Обчислено десяткові значення цифр розрядів: `D₀ = 5`, `D₁ = 0`, `D₂ = 9`, `D₃ = 3` та `D₄ = 7`. Виконаємо покрокове поліноміальне згортання підсумкової величини `V`:

**Обчислення п'ятизначного числа з розрядних цифр D₀ = 5, D₁ = 0, D₂ = 9, D₃ = 3, D₄ = 7:**

```
V = D₀ · 10⁰ + D₁ · 10¹ + D₂ · 10² + D₃ · 10³ + D₄ · 10⁴
= 5 · 1 + 0 · 10 + 9 · 100 + 3 · 1000 + 7 · 10000      [підстановка розрядних вагових значень]
= 5 + 0 + 900 + 3000 + 70000                          [обчислення добутків декадних компонентів]
= 73905                                                [підсумкове сумування всіх розрядів]
```

Отриманий результат `V = 73905` демонструє, що скалярне згортання чотирибітових векторів повертає точне значення п'ятизначної уставки без похибок перетворення.

V = ∑ (Dₖ × 10ᵏ)          [сумування по розрядах k від 0 до N - 1]
= D₀ × 10⁰ + D₁ × 10¹ + D₂ × 10² + ... + Dₙ₋₁ × 10ⁿ⁻¹ [розгортання суми]

У чотирьох бітах можна зашифрувати `2⁴ = 16` станів. Значення від `10` до `15` (`1010₂`–`1111₂`) є невалідними псевдодекадами (від грецького @@el|pseudos@@ — несправжній та @@el|dekas@@ — десяток; англійською @@en|pseudo-decimals@@). Для аналізу відповідності вихідних комбінацій складемо таблицю істинності (від англійського @@en|truth table@@) булевої функції верифікації `M_valid`. Умова `Dₖ > 9` виконується тоді й лише тоді, коли старший біт `b₃ = 1` супроводжується активним станом біта `b₂ = 1` (значення 12–15) або біта `b₁ = 1` (значення 10–11). Звідси булевий вираз маскування невалідного стану описується як заперечення логічної кон'юнкції:

```
M_valid = ¬(b₃ ∧ (b₂ ∨ b₁))               [умова валідності комбінації Dₖ ≤ 9]
```

Для апаратного схемного обнулення невалідних комбінацій застосовують комбінаційну логіку (на елементах І, АБО-НЕ) або апаратний строб-блокатор шини, який при виникненні кодового збою під час механічного прокручування барабана примусово скидає шину даних у нуль. У програмних алгоритмах мікроконтролера обнулення виконують шляхом множення розрядної цифри `Dₖ` на селекторну маску: `D_valid = Dₖ · M_valid`. Якщо `M_valid = 0` або `Dₖ > 9`, зчитана комбінація відхиляється як кодовий збій чи аномалія перехідного стану, що виключає появу помилкових значень у поліноміальному згортанні підсумкового числа `V`.

M_valid = ¬(b₃ ∧ (b₂ ∨ b₁)) [перевірка умови Dₖ ≤ 9]

Якщо `M_valid = 0` або `Dₖ > 9`, зчитана комбінація відхиляється як кодовий збій чи аномалія перехідного стану.

## Матричне мультиплексування та розрахунок ліній

Щоб додатково зменшити кількість ніжок мікроконтролера при підключенні `N` декад, застосовують матричне мультиплексування (від лат. @@la|matrix@@ — джерело та @@la|multiplex@@ — багаторазовий; @@en|matrix multiplexing@@). Спільні виходи BCD-шин `1`, `2`, `4`, `8` усіх перемикачів об'єднують паралельно у 4 стовпчики даних, а спільні контакти кожної декади підключають до `N` окремих скануючих рядків. При поданні активного низького рівня напруги `V_OL` на скануючий рядок струм прямого зміщення `I_D` тече від лінії живлення `V_CC` через підтягувальний резистор `R_pull` (від англ. @@en|pull-up resistor@@), замкнену контактну групу та розв'язувальний діод (від англ. @@en|decoupling diode@@). Математично прямовий спад напруги `V_f` на розв'язувальному діоді описується вольт-амперною характеристикою за рівнянням Шоклі (від прізвища фізика Вільяма Шоклі; від англ. @@en|Shockley diode equation@@) як `V_f = n × V_T × ln(I_D / I_S + 1)`, де `V_T = k × T / q ≈ 25.85 мВ` при кімнатній температурі `300 К` є термічним потенціалом, `n` — коефіцієнтом неідеальності p-n переходу, `I_S` — тепловим струмом насичення, а робочий струм становить `I_D = (V_CC - V_f - V_OL) / R_pull`. Результуючий рівень логічного нуля на вході мікроконтролера зростає до значення `V_in_LOW = V_OL + V_f`, що зменшує запас завадостійкості (від англ. @@en|noise margin@@). Для дотримання умови надійного зчитування `V_in_LOW ≤ V_IL_max` (де `V_IL_max` — гранична напруга логічного нуля порту, що зазвичай становить `0.3 × V_CC` або `0.8 В`) застосовують діоди Шотткі (від прізвища фізика Вальтера Шотткі; від англ. @@en|Schottky diode@@), які за рахунок бар'єру металонапівпровідника забезпечують низьке падіння напруги `V_f ≈ 0.2...0.3 В` при робочому струмі `I_D`.

*Принципова схема матричної адресації BCD-перемикачів із діодною розв'язкою для усунення паразитних зрівняльних струмів.*

Загальна кількість потрібних ліній порту `N_gpio` для опитування `N` декад у матричній схемі обчислюється як сума рядків і стовпчиків:

N_gpio = N_rows + N_cols  [загальна кількість ліній GPIO]
= N + 4                   [де N — кількість декад, 4 — лінії BCD]

Для `N = 4` декад замість `16` ліній потрібно лише `4 + 4 = 8` ніжок. Щоб запобігти зрівняльним струмам через паралельно замкнені ротори суміжних декад, послідовно з кожним перемикачем умикають діодна розв'язка (від англ. @@en|diode decoupling@@ — діодне розв'язування; @@en|diode decoupling@@). Діоди блокують зворотні струми при виборчому поданні низького рівня на скануючий рядок, що аналогічно опитуванню у [матричній клавіатурі 4×4 (мембранній)](root:cat-hw-controls/keypad-4x4-membrane).

## Часові інтервали сканування та демпінг брязкоту

Динамічне опитування матриці барабанних перемикачів вимагає розрахунку часового графіка сканування. Нехай матриця опитується з частотою оновлення `f_scan`. Тривалість активного імпульсу сканування одного рядка `t_row` дорівнює:

t_row = 1 / (N_rows × f_scan) [часовий слот сканування одного рядка]

При механічному прокручуванні барабана виникає контактний брязкіт (від англ. @@en|contact bounce@@ — брязкіт контактів; @@en|contact bounce@@), тривалість якого `t_bounce` становить від `2` до `10` мілісекунд. Для поглинання брязкоту вікно цифрової фільтрації `t_filter` має перевищувати максимальну тривалість механічних коливань:

t_filter ≥ 1.5 × t_bounce_max [критерій антибрязкового часового вікна]

Для `t_bounce_max = 10 мс` обирають `t_filter = 15 мс`. Верхня межа частоти сканування обмежується постійною часу `τ = R_pullup × C_bus`, де `R_pullup` — опір підтягувальних резисторів, а `C_bus` — паразитна ємність шини (від англ. @@en|bus capacitance@@). Оскільки паразитна ємність та опір утворюють інтегруючий RC-ланцюг (від англ. @@en|RC circuit@@), перехідна характеристика напруги описується експоненційним законом `v(t) = V_CC × (1 - e⁻ᵗ/ᵀ)`, що викликає закруглення та викривлення прямокутного імпульсу сканування. Для досягнення повного часу встановлення (від англ. @@en|settling time@@) напруги до рівня `99.3%` від `V_CC` тривалість скануючого слота одного рядка повинна задовольняти критерію `t_row ≥ t_row_min = 5τ = 5 × R_pullup × C_bus`. Оскільки повний цикл опитування `N_rows` рядків становить `T_scan = N_rows × t_row`, максимальна допустима частота сканування матриці `f_scan_max` обчислюється як `f_scan_max = 1 / (N_rows × t_row_min) = 1 / (5 × N_rows × R_pullup × C_bus)`. Перевищення `f_scan_max` призводить до амплітудного зрізання імпульсів та збоїв декодування BCD-коду на входах мікроконтролера. Придушення брязкоту контактними пружинами детально розкрито у статті про [тактильні кнопки з ковпачками](root:cat-hw-controls/tactile-buttons).
