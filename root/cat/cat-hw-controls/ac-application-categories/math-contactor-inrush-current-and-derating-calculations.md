# Розрахунок пускових струмів, електродинамічних зусиль та коефіцієнтів зниження потужності

## Обчислення кратників пускового струму та енергії пуску

Під час прямого пуску асинхронного двигуна з короткозамкненим ротором пусковий струм I_inrush обчислюється за кратністю пускового струму k_start: I_inrush = k_start · I_nom, де k_start ≈ 5 ... 8. Постійна часу статорного кола T_a = L / R суттєво залежить від потужності двигуна: для низьковольтних двигунів до 5 кВт T_a становить 10–20 мс, тоді як для потужних двигунів понад 100 кВт вона сягає 50–100 мс через превалювання індуктивного опору обмоток.

```
I_inrush = k_start · I_nom
```

де k_start ≈ 5 ... 8. Аналітичний вираз для перехідного пускового струму містить періодичну та аперіодичну складові:

```
i(t) = I_max · (sin(ωt + α - φ) - sin(α - φ) · e^{-t / T_a})
```

де T_a = L / R — постійна часу статорного кола, а α — фазовий кут напруги в момент увімкнення. Постійна часу T_a суттєво залежить від потужності двигуна: для низьковольтних двигунів малої потужності (до 5 кВт) співвідношення L/R невелике, і T_a становить 10–20 мс, тоді як для потужних двигунів (понад 100 кВт) індуктивний опір обмоток превалює над активним, внаслідок чого T_a зростає до 50–100 мс, подовжуючи тривалість аперіодичного кидка струму. Наприклад, для двигуна з I_nom = 32 A пусковий струм сягає I_inrush = 7 · 32 = 224 A. При тривалості пуску t_start = 2.5 с та експоненційному затуханні пускового кидка тепловий інтеграл Джоуля обчислюється як I²t ≈ (1/3) · I_inrush² · t_start = (1/3) · (224)² · 2.5 ≈ 41813 A²·s. Виділена енергія спричиняє швидкий адіабатичний розігрів тонкого приконтактного шару, викликаючи лінійне теплове розширення накладок ΔL = α_th · L_0 · ΔT, що локально змінює контактний тиск і вимагає термічного резерву механіки контактора. Оцінка сумарного комутаційного зносу контактної групи за період експлуатації описується формулою накопичувальної ерозійної маси Δm_total = N_cycles · K_wear · ∫₀^{t_arc} U_arc(t) · i(t) dt, де K_wear — емпіричний коефіцієнт матеріалоперенесення срібного сплаву, а t_arc — час горіння комутаційної дуги.

```
I²t = ∫₀^{t_start} i(t)² dt
```

## Розрахунок електродинамічного відштовхування контактів

При проходженні високого пускового струму між паралельними контактними накладками виникає електродинамічна сила відштовхування (@@en|electrodynamic repulsion force@@) F_rep: F_rep = C_geo · I_inrush², де C_geo — геометричний коефіцієнт контактного вузла. Наприклад, для пускового струму I_inrush = 250 A та коефіцієнта C_geo = 1.2·10^{-4} N/A² сила відштовхування сягає F_rep = 1.2·10^{-4} · 62500 = 7.5 N. Для виключення мікророзмикання та дугового зварювання контактна притискна пружина розраховується на мінімальне зусилля F_spring ≥ 1.5 · F_rep = 11.25 N. Сила F_rep створює згинальний момент M_bend = F_rep · L_arm на рухомому контактотримачі, тому пружний деформаційний зсув консолі обчислюється як δ = (F_rep · L_arm³) / (3 · E · I_z), що вимагає вибору підвищеної жорсткості мідних або латунних траверс. При пульсаціях пускового струму з подвоєною частотою мережі (100 Гц) моделюють резонансні коливання контактотримача, перевіряючи, щоб власна частота конструкції f_0 = (1 / 2π) · √(k / m) не збігалася з частотою електродинамічних імпульсів. Якщо притискна сила пружини тимчасово поступається зусиллю F_rep, математичний розрахунок зазору мікророзмикання контактних накладок описується виразом x_gap = (F_rep - F_spring) / k_spring: утворення зазору навіть на величину x_gap ≈ 0.05 мм викликає мікродуговий спалах, оскільки напруга мікродугового пробою розраховується за законом Пашена U_breakdown = (B · p · x_gap) / (ln(A · p · x_gap) - ln(ln(1 + 1/γ))) ≈ 300 В, що за робочої напруги мережі миттєво іонізує повітряний проміжок та викликає ерозію срібла.

```
F_rep = C_geo · I_inrush²
```

де C_geo — геометричний коефіцієнт контактного вузла. Наприклад, для пускового струму I_inrush = 250 A та коефіцієнта C_geo = 1.2·10^{-4} N/A² сила відштовхування сягає F_rep = 1.2·10^{-4} · 62500 = 7.5 N. Для виключення мікророзмикання та дугового зварювання контактна притискна пружина розраховується на мінімальне зусилля F_spring ≥ 1.5 · F_rep = 11.25 N. Сила F_rep створює згинальний момент M_bend = F_rep · L_arm на рухомому контактотримачі, тому пружний деформаційний зсув консолі обчислюється як δ = (F_rep · L_arm³) / (3 · E · I_z), що вимагає вибору підвищеної жорсткості мідних або латунних траверс. При пульсаціях пускового струму з подвоєною частотою мережі (100 Гц) моделюють резонансні коливання контактотримача, перевіряючи, щоб власна частота конструкції f_0 = (1 / 2π) · √(k / m) не збігалася з частотою електродинамічних імпульсів. Якщо притискна сила пружини тимчасово поступається зусиллю F_rep, математичний розрахунок зазору мікророзмикання контактних накладок описується виразом x_gap = (F_rep - F_spring) / k_spring: утворення зазору навіть на величину x_gap ≈ 0.05 мм викликає мікродуговий спалах, оскільки напруга мікродугового пробою розраховується за законом Пашена U_breakdown = (B · p · x_gap) / (ln(A · p · x_gap) - ln(ln(1 + 1/γ))) ≈ 300 В, що за робочої напруги мережі миттєво іонізує повітряний проміжок та викликає ерозію срібла.

## Математична модель температурного та висотного дерейтингу

Підсумковий допустимий струм контактора I_op у реальних умовах експлуатації обчислюється як добуток номінального струму та коефіцієнтів зниження: I_op = I_nom · K_temp · K_density · K_alt. При тривалому ввімкненні котушки живлення (режим ПВ 100%) її активний опір зростає відповідно до температурного коефіцієнта міді R_coil(T) = R_20 · (1 + α_Cu · (T - 20)), де α_Cu = 0.00393 1/°C, що при робочій температурі T = 70 °C знижує струм утримування котушки на 19.6% та вимагає витримування мінімального коефіцієнта запасу напруги U_hold ≥ 0.85 · U_rated для запобігання відпаданню якоря.

```
I_op = I_nom · K_temp · K_density · K_alt
```

При експлуатації контактора в високогірних умовах на висоті понад 2000 м над рівнем моря розріджене повітря погіршує умови охолодження та знижує електрична міцність ізоляції, тому висотний коефіцієнт обчислюється як K_alt = 1 - 0.05 · ((H - 2000) / 1000); наприклад, на висоті H = 3000 м коефіцієнт становить K_alt = 0.95, що вимагає додаткового зниження навантаження на 5%. У комбінованому режимі експлуатації при I_nom = 40 A, температурі 55 °C (K_temp = 0.85), щільному ряду з 4 контакторів (K_density = 0.80) та висоті 3000 м (K_alt = 0.95), підсумковий робочий струм розраховується як I_op = 40 · 0.85 · 0.80 · 0.95 ≈ 25.84 A. Для забезпечення робочого струму навантаження 30 А за результатами розрахунку вибирають контактор наступного типорозміру з номіналом I_nom = 50 A, що гарантує запас міцності та виключає термічний перегрів. Температурний дерейтинг котушки живлення при тривалому ввімкненні (ПВ 100%) враховує зростання її активного опору R_coil(T) = R_20 · (1 + α_Cu · (T - 20)), що при T = 70 °C знижує утримуючий струм котушки на 19.6% та вимагає дотримання мінімального коефіцієнта запасу напруги утримання U_hold ≥ 0.85 · U_rated. При імпульсно-переривчастому режимі роботи з тривалістю увімкнення ПВ = (t_on / (t_on + t_off)) · 100% коефіцієнт навантаження коригується відношенням K_duty = 1 / √(ПВ / 100): для повторно-короткочасного режиму з ПВ = 40% еквівалентний допустимий струм зростає в 1.58 рази за рахунок охолодження контактів під час паузи.
