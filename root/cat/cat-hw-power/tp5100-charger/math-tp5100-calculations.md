## Чому довільна обв'язка TP5100 перегріває модуль

При практичній розробці імпульсних зарядних пристроїв інженери часто стикаються із ситуацією, коли під час заряду одноелементних (1S, 4.2 В) або двоелементних (2S, 8.4 В) літієвих акумуляторів струмом до 2 А плата на базі [імпульсного контролера TP5100](root:cat-hw-power/tp5100-charger) починає критично перегріватися, а силовий дросель видає акустичний шум і входить у глибоке насичення. Головна причина цього явища полягає у хибному припущенні, ніби пасивні компоненти силової обв'язки, зазначені у типових тестових схемах з технічної документації, залишаються однаково ефективними для будь-яких комбінацій вхідної напруги живлення від 5 В до 18 В та довільних струмів заряду.

На відміну від лінійних регуляторів, функціонування даної мікросхеми спирається на фіксовану частоту перемикання ШІМ (англ. @@en|PWM switching frequency@@) 400 кГц. Це означає, що процес накопичення енергії в магнітному полі та її передачі у навантаження повторюється 400 000 разів на секунду. Зміна режиму роботи з 1S на 2S або коливання вхідної напруги безпосередньо змінюють коефіцієнт заповнення ШІМ-імпульсів та амплітуду напруги, прикладеної до індуктивного елемента під час відкритого стану силового ключа.

Якщо при проектуванні вузла вимірювальний шунт струму (англ. @@en|current sense resistor@@) або силовий дросель (англ. @@en|power inductor@@) підібрані без урахування цих динамічних факторів, амплітуда пульсацій струму виходить за допустимі межі. Дросель втрачає індуктивність через насичення сердечника, що призводить до стрибкоподібного зростання пікового струму через внутрішній MOSFET-ключ, різкого падіння коефіцієнта корисної дії та виділення надлишкового тепла. Щоб запобігти виходу компонента з ладу та забезпечити температурну стабільність, необхідно вивести чіткі математичні залежності для кожного елемента, який утворює обв'язку [понижувального імпульсного перетворювача](root:cat-hw-power/tp5100-charger/tp5100-buck-topology-power-path).

## Розрахунок вимірювального шунта та його потужності

Задавання амплітуди струму заряду акумулятора `I_charge` здійснюється шляхом вимірювання спаду напруги на зовнішньому низькоомному резисторі, який виконує роль вимірювального шунта струму (англ. @@en|current sense resistor@@) `R_S`. Внутрішня схема порівняння контролера постійно зіставляє цей спад із фіксованою опорною напругою зворотного зв'язку `V_sense = 100 мВ` (0.1 В).

Для точного обчислення необхідного номіналу опору `R_S` під заданий струм заряду застосовується математичний вираз, виведений із закону Ома для ділянки кола:

```
R_S = V_sense / I_charge
= 0.1 / I_charge               [фіксована опорна напруга V_sense = 0.1 В]
```

У цій формулі значення опору `R_S` отримують у Омах (Ом), якщо опорну напругу `V_sense` підставлено у Вольтах (В), а бажаний струм заряду `I_charge` — у Амперах (А). Для практичних розрахунків типових режимів роботи використовуються такі співвідношення:

```
[Крок 1: Обчислення R_S для максимального струму заряду 2 А]
R_S = 0.1 / 2.0 = 0.05 Ом       [50 мОм]

[Крок 2: Обчислення R_S для струму заряду 1.5 А]
R_S = 0.1 / 1.5 = 0.0667 Ом     [66.7 мОм]

[Крок 3: Обчислення R_S для помірного струму заряду 1 А]
R_S = 0.1 / 1.0 = 0.1 Ом        [100 мОм]
```

Окрім вибору опору, критично важливим є обчислення питомої потужності розсіювання `P_RS` на шунті для запобігання його перегріву та деградації параметрів. Оскільки струм через шунт у фазі провідності дорівнює струму заряду, розсіювана потужність визначається виразом:

```
P_RS = V_sense * I_charge
= 0.1 * I_charge                [потужність розсіювання вимірювального шунта]
```

При проведення заряду максимальним струмом `I_charge = 2 А` виділення потужності на шунті становить `P_RS = 0.1 * 2.0 = 0.2 Вт` (200 мВт). Вибір типорозміру SMD-резистора мусить здійснюватися з урахуванням інженерного запасу за температурою (англ. @@en|thermal derating@@):

- Типорозмір 0805 із номінальною потужністю 125 мВт є неприпустимим, оскільки працюватиме у режимі постійного перевантаження. - Типорозмір 1206 із номінальною потужністю 250 мВт (0.25 Вт) забезпечує мінімальний робочий допуск, однак викликає помірне самонагрівання резистора, що призводить до температурного дрейфу опору (TCR). - Типорозміри 1210, 2010 (0.5–0.75 Вт) або 2512 (1 Вт) є оптимальними для тривалої експлуатації на струмах 2 А, оскільки мають низький термічний опір між виводами та друкованою платою.

## Обчислення силового дроселя та пульсацій струму

Розрахунок силового індуктивного елемента визначає стабільність роботи всієї імпульсної системи. Силовий дросель (англ. @@en|power inductor@@) `L` накопичує енергію під час відкритого стану внутрішнього ключа і віддає її в акумулятор у фазі розрядження. Фіксована частота перемикання ШІМ (англ. @@en|PWM switching frequency@@) `f_sw = 400 кГц` (400 000 Гц) вимагає суворого узгодження індуктивності із допустимим рівнем пульсацій струму (англ. @@en|current ripple@@) `Delta I_L`.

Математичне рівняння для обчислення індуктивності понижувального перетворювача виводиться з закону електромагнітної індукції Фарадея на інтервалі часу відкритого стану ключа `t_on = V_bat / (V_in * f_sw)`:

```
L = (V_in - V_bat) * t_on / Delta I_L
= (V_in - V_bat) * V_bat / (V_in * f_sw * Delta I_L)  [формула індуктивності силового дроселя]
```

Де `V_in` — вхідна напруга живлення (В), `V_bat` — напруга на батареї (4.2 В для 1S або 8.4 В для 2S), `f_sw` — частота перемикання (400 000 Гц), а `Delta I_L` — розмах пульсацій струму в дроселі (А). Для забезпечення високого ККД та низьких втрат у магнітопроводі розмах пульсацій `Delta I_L` обирають у межах від 20% до 40% від номінального струму заряду `I_charge`. При `I_charge = 2 А` оптимальне значення пульсацій становить `Delta I_L = 0.3 * 2.0 = 0.6 А`.

Розглянемо покрокове обчислення номіналу індуктивності для вхідної напруги живлення `V_in = 12 В`:

```
[Крок 1: Обчислення L для конфігурації 1S (V_bat = 4.2 В, V_in = 12 В, Delta I_L = 0.6 А)]
L_1S = (12 - 4.2) * 4.2 / (12 * 400000 * 0.6)
= 7.8 * 4.2 / 2880000
= 32.76 / 2880000
= 0.000011375 Гн                 [11.38 мкГн -> найближчий стандартний номінал 10 мкГн або 15 мкГн]

[Крок 2: Обчислення L для конфігурації 2S (V_bat = 8.4 В, V_in = 12 В, Delta I_L = 0.6 А)]
L_2S = (12 - 8.4) * 8.4 / (12 * 400000 * 0.6)
= 3.6 * 8.4 / 2880000
= 30.24 / 2880000
= 0.0000105 Гн                   [10.5 мкГн -> найближчий стандартний номінал 10 мкГн]
```

Окрім величини індуктивності, дросель повинен задовольняти вимогам щодо пікового струму та струму насичення `I_sat`. Піковий струм через дросель дорівнює сумі середнього струму заряду та половини амплітуди пульсацій:

```
I_peak = I_charge + (Delta I_L / 2)
= 2.0 + (0.6 / 2) = 2.3 А        [піковий струм у силовому контурі]
```

Параметр струму насичення дроселя `I_sat` (струм, при якому індуктивність падає на 30% від номіналу) повинен перевищувати `I_peak` щонайменше на 25–30%: `I_sat ≥ 3.0 А`.

Поширене міфотворення стверджує, що для зменшення габаритів плати можна довільно вибирати дроселі меншого номіналу (наприклад, 2.2 мкГн замість 10 мкГн) без негативних наслідків. Математичний аналіз спростовує цю думку: зменшення індуктивності у 4.5 раза призведе до пропорційного зростання пульсацій `Delta I_L` до 2.7 А. Це змістить піковий струм `I_peak` до 3.35 А, заганяючи магнітний сердечник у глибоке насичення (англ. @@en|core saturation@@). При насиченні індуктивність дроселя падає до нуля, викликаючи надвисокі імпульсні струми через виводи [апаратного інтерфейсу контролера](root:cat-hw-power/tp5100-charger/api-tp5100-hardware), що призводить до негайного перегріву та руйнування кристала.

## Тепловий баланс та порівняння з TP4056

Оцінка загального теплового режиму зарядного вузла базується на обчисленні коефіцієнта корисної дії (англ. @@en|buck converter efficiency@@) `eta` та аналізі сумарних втрат потужності `P_loss`. Корисна потужність `P_out`, яка передається в акумулятор, становить:

```
P_out = V_bat * I_charge
```

Споживана від джерела живлення потужність `P_in` та загальні теплові втрати `P_loss` визначаються виразами:

```
P_in = P_out / eta = (V_bat * I_charge) / eta

P_loss = P_in - P_out
= P_out * ((1 - eta) / eta)      [формула загальних теплових втрат]
```

Щоб оцінити переваги імпульсної топології TP5100, виконаємо порівняльний кількісний аналіз із тепловиділенням, яке демонструє [класичного лінійного контролера](root:cat-hw-power/tp4056). У лінійному регуляторі вхідний струм дорівнює струму заряду `I_in = I_charge`, а вся різниця напруг між джерелом та акумулятором перетворюється на чисте тепло:

```
P_loss_linear = (V_in - V_bat) * I_charge
```

Проведемо розрахунок для трьох характерних сценаріїв експлуатації:

```
[Сценарій 1: Заряд 1S акумулятора V_bat = 3.7 В струмом I_charge = 1 А при вхідній напрузі V_in = 5 В]
P_loss_TP4056 = (5.0 - 3.7) * 1.0 = 1.3 Вт
P_loss_TP5100 = (3.7 * 1.0) * ((1 - 0.90) / 0.90) = 3.7 * 0.111 = 0.41 Вт

[Сценарій 2: Заряд 1S акумулятора V_bat = 3.7 В струмом I_charge = 1 А при підвищеній напрузі V_in = 12 В]
P_loss_TP4056 = (12.0 - 3.7) * 1.0 = 8.3 Вт   [неможливо розсіяти в корпусі SOP-8, спрацьовує термозахист]
P_loss_TP5100 = (3.7 * 1.0) * ((1 - 0.88) / 0.88) = 3.7 * 0.136 = 0.50 Вт

[Сценарій 3: Заряд 2S акумулятора V_bat = 8.4 В струмом I_charge = 2 А при вхідній напрузі V_in = 12 В]
P_loss_TP4056 = не підтримує режим 2S
P_loss_TP5100 = (8.4 * 2.0) * ((1 - 0.90) / 0.90) = 16.8 * 0.111 = 1.87 Вт
```

З кількісного аналізу видно, що при напрузі живлення 12 В лінійний контролер виділяє 8.3 Вт тепла, що робить його використання фізично неможливим без гігантських радіаторів. Натомість TP5100 розсіює лише 0.5 Вт в аналогічному режимі. При заряді 2S батареї потужністю 16.8 Вт імпульсний контролер втрачає менше 1.87 Вт, розподілених між кристалом мікросхеми, силовим дроселем, випрямним діодом Шотткі та вимірювальним шунтом. Це дозволяє проектувати компактні зарядні пристрої, які легко інтегруються в модулі [зарядного модуля MH-CD42](root:cat-hw-power/mh-cd42-charger) або плати розширення [автономного живлення Raspberry Pi](root:cat-hw-power/liion-hat-rpi), за умови використання зовнішньої [системи балансування BMS](root:cat-hw-power/bms-multicell) та належного [модуля захисту акумуляторів](root:cat-hw-power/pcb-1s-protection).

## Залежність тепловиділення від вхідної напруги

Поширеною помилкою серед розробників є перенесення властивостей лінійних стабілізаторів на імпульсні перетворювачі, що формує хибну думку про лінійне зростання тепловиділення TP5100 при підвищенні вхідної напруги живлення `V_in` від 5 В до 18 В.

У понижувальному перетворювачі коефіцієнт заповнення ШІМ (англ. @@en|duty cycle@@) `D` перебуває у зворотній залежності від вхідної напруги:

```
D = V_bat / V_in
```

При фіксованій напрузі акумулятора `V_bat = 4.2 В` зростання вхідної напруги спричиняє пропорційне зменшення часу відкритого стану силового ключа:

```
[Крок 1: Коефіцієнт заповнення при V_in = 5 В]
D_5V = 4.2 / 5.0 = 0.84         [84% часу ключ відкритий]

[Крок 2: Коефіцієнт заповнення при V_in = 12 В]
D_12V = 4.2 / 12.0 = 0.35       [35% часу ключ відкритий]

[Крок 3: Коефіцієнт заповнення при V_in = 18 В]
D_18V = 4.2 / 18.0 = 0.233      [23.3% часу ключ відкритий]
```

Завдяки зменшенню `D` середній вхідний струм, що споживається від джерела живлення, зменшується відповідно до рівняння `I_in ≈ (V_bat * I_charge) / (V_in * eta)`. Загальні теплові втрати складаються з двох основних компонентів:

1. Втрати провідності (англ. @@en|conduction loss@@) `P_cond`, які виділяються на опорі відкритого каналу MOSFET `R_ds(on)` та падінні напруги на діоді Шотткі. Вони залежать від струму заряду `I_charge`, а не від вхідної напруги. 2. Динамічні втрати перемикання (англ. @@en|switching loss@@) `P_sw`, які виникають під час фронтів наростання та спаду напруги на частоті 400 кГц:

```
P_sw = 0.5 * V_in * I_charge * (t_rise + t_fall) * f_sw   [динамічні втрати перемикання]
```

Зі зростанням `V_in` від 5 В до 18 В втрати провідності залишаються практично незмінними (або навіть трохи знижуються за рахунок зменшення часу провідності верхнього ключа), тоді як динамічні втрати перемикання `P_sw` зростають лінійно від вхідної напруги. Проте, оскільки `P_sw` складає лише незначну частку від загального балансу втрат, підсумкове тепловиділення мікросхеми збільшується дуже помірно (наприклад, з 0.8 Вт при 5 В до 1.2 Вт при 18 В для режиму 1S 2А). Це повністю спростовує міф про теплову непридатність високих вхідних напруг та підтверджує гнучкість розрахунку параметрів, які описує [апаратного інтерфейсу контролера](root:cat-hw-power/tp5100-charger/api-tp5100-hardware).
