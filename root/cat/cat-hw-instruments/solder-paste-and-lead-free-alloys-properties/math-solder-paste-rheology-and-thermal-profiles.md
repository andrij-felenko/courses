## Дефекти друку та термообробки пасти

У серійному поверхневому монтажі вихід придатних друкованих плат визначається точністю дозування матеріалів та суворим дотриманням теплових режимів. Вибір режимів на основі емпіричних спроб призводить до трьох критичних дефектів: запливання пасти під трафарет з утворенням коротких замикань між виводами, розтріскування керамічних конденсаторів та формування кульок припою біля чип-компонентів. Для обґрунтованого вибору рецептури [паяльних флюсів та паст](root:cat-hw-instruments/smd-soldering-fluxes-and-pastes) необхідно розуміти фізику процесів деформації матеріалу та теплопередачі.

Дефект запливання виникає через падіння в'язкості матеріалу під впливом зсувного зусилля, яке створює ракель (від нім. @@de|Rakel@@ — шкребок). Якщо динамічна в'язкість падає нижче допустимого рівня або не відновлюється після зняття трафарету, припайна паста витікає в зазор між підкладкою та маскою. Під час зорового [контролю точності нанесеного припою](root:cat-hw-instruments/optical-microscope-soldering) виявляють розмиті дози, що при оплавленні формують стібкові мостики між контактами microBGA або QFN.

Термічні дефекти виникають при недотриманні профілю нагрівання в конвекційній печі. Багатошарові керамічні конденсатори (від англ. @@en|multilayer ceramic capacitor@@, @@en|MLCC@@) складаються з шарів титанату барію та внутрішніх електродів з різними коефіцієнтами теплового розширення. Якщо градієнт температури `dT/dt` перевищує граничні `2–3 °C/s`, у кераміці виникають розтягувальні напруження, що створюють мікротріщини і призводять до електричного пробою при експлуатації.

Утворення кульок припою (від англ. @@en|solder beading@@) спричиняється вибуховим випаровуванням летких розчинників флюсу в зоні попереднього нагріву. Надлишковий тиск газу виштовхує частки припою під корпус чип-компонента, де при досягненні температури ліквідусу вони оплавляються в ізольовані сферичні кульки, здатні спричинити коротке замикання.

Для уникнення цих дефектів розробляють суворий температурний профіль оплавлення, який враховує тепловий бюджет друкованої плати (від англ. @@en|printed circuit board@@, @@en|PCB@@).

![Графік температурного профілю оплавлення SAC305 із зонами нагріву та витримування](img/sac305-reflow-thermal-profile-zones.svg)
*Термограма профілю паяння розплавленням для безсвинцевого сплаву SAC305 із позначенням температурних зон.*

Аналіз термограми вимагає кількісного опису процесів. Для [вибору термомеханічних режимів сплаву](root:cat-hw-instruments/soldering-fluxes-and-solders) недоцільно спиратися на усереднені графіки. Вимоги до якості вимагають побудови математичних моделей реології припайної пасти на етапі друку та розрахунку диференціальних рівнянь теплопровідності під час термообробки.

## Математика реології Гіршеля-Балклі та в'язкості

Трафаретний друк (від англ. @@en|stencil printing@@) вимагає від припайної пасти подвійної реологічної поведінки. Під час руху ракеля (від англ. @@en|squeegee@@) матеріал має легко текти, заповнюючи апертури трафарету, а після зняття трафарету — миттєво зберігати форму дози. Звичайні ньютонівські рідини зі сталою в'язкістю не здатні забезпечити таких протилежних станів.

Припайна паста належить до неньютонівських рідин (від англ. @@en|non-Newtonian fluid@@) і є концентрованою суспензією частинок припою у високов'язкому флюсі. Її опис здійснюється за допомогою реологічної моделі Гіршеля-Балклі (від прізвищ науковців Вінслоу Гіршеля та Рональда Балклі — @@en|Herschel-Bulkley model@@), яка поєднує концепцію границі плинності та степеневий закон зсувного розрідження.

Основними параметрами є зсувне напруження `τ` (від англ. @@en|shear stress@@, вимірюється в Паскалях, Па), градієнт швидкості зсуву `γ̇` (від англ. @@en|shear rate@@, вимірюється в обернених секундах, с⁻¹) та динамічна в'язкість `η` (від англ. @@en|dynamic viscosity@@, Па·с). Рівняння Гіршеля-Балклі описує залежність зсувного напруження від швидкості зсуву при перевищенні границі плинності `τ₀`:

```
τ = τ₀ + K · γ̇ⁿ
```

Тут `τ₀` означає границю плинності (від англ. @@en|yield stress@@), тобто мінімальне напруження для початку течії. Символ `K` описує індекс консистентності (Па·сⁿ), а `n` — індекс течії. Для припайних паст `n < 1`, що свідчить про наявність ефектів псевдопластичності (від англ. @@en|pseudoplasticity@@) та зсувного розрідження (від англ. @@en|shear thinning@@). Для [хімічної класифікації флюсу](root:cat-hw-instruments/no-clean-fluxes-chemistry-and-classification) у складі пасти значення `n` становить 0.3–0.6.

Ефективна динамічна в'язкість `η_eff` визначається як відношення зсувного напруження до швидкості зсуву:

```
η_eff = τ / γ̇
= (τ₀ + K · γ̇ⁿ) / γ̇      [підстановка рівняння Гіршеля-Балклі]
= τ₀ · γ̇⁻¹ + K · γ̇ⁿ⁻¹   [розділення на окремі доданки]
```

Оскільки `n < 1`, показник `n - 1` є від'ємним. При зростанні швидкості зсуву `γ̇` обидва доданки `τ₀ · γ̇⁻¹` та `K · γ̇ⁿ⁻¹` зменшуються, тому ефективна в'язкість пасти стрімко падає при підвищенні швидкості руху ракеля.

Швидкість зсуву `γ̇` у зазорі між лезом ракеля та трафаретом математично виражається через лінійну швидкість руху ракеля `v_sq` та товщину зсувного шару `h_g`:

```
γ̇ = v_sq / h_g
```

![Залежність динамічної в'язкості та зсувного напруження від швидкості зсуву за рівнянням Гіршеля-Балклі](img/solder-paste-herschel-bulkley-viscosity-curve.svg)
*Графік залежності динамічної в'язкості та зсувного напруження від швидкості зсуву за рівнянням Гіршеля-Балклі.*

На графіку видно дві області: при `τ < τ₀` матеріал поводиться як пружне тверде тіло і не тече. Коли тиск ракеля створює `τ > τ₀`, паста переходить у рідкий стан, а її в'язкість знижується на кілька порядків. Застосування [безвідмивного паяльного флюсу](root:cat-hw-instruments/flux-fvs7) дає змогу точно керувати значеннями `K` та `n`.

**Розрахунок ефективної в'язкості припайної пасти під ракелем**
Обчислимо ефективну в'язкість пасти при швидкості друку `v_sq = 60 мм/с = 0.06 м/с` та товщині зсувного шару `h_g = 0.12 мм = 0.00012 м`. Параметри пасти: границя плинності `τ₀ = 180 Па`, індекс консистентності `K = 75 Па·сⁿ`, індекс течії `n = 0.42`.

Спочатку обчислюємо швидкість зсуву `γ̇`:

```
γ̇ = 0.06 / 0.00012
= 500 с⁻¹                [ділення швидкості ракеля на товщину шару]
```

Тепер обчислюємо зсувне напруження `τ` та ефективну в'язкість `η_eff`:

```
τ = 180 + 75 · (500)⁰·⁴²
= 180 + 75 · 13.62       [обчислення степеня 500⁰·⁴²]
= 180 + 1021.5           [множення на індекс консистентності K]
= 1201.5 Па              [додавання границі плинності τ₀]

η_eff = 1201.5 / 500
= 2.403 Па·с             [ділення зсувного напруження на швидкість зсуву]
```

У стаціонарному стані без зсуву (при `γ̇ → 0`) в'язкість цієї пасти перевищує `100 Па·с`. Під лезом ракеля при `γ̇ = 500 с⁻¹` в'язкість знижується до `2.403 Па·с`, що забезпечує заповнення апертур трафарету.

## Розрахунок тиксотропії та границі плинності

Після зняття трафарету розріджена під ракелем припайна паста залишається на контактних площадках. Повільне відновлення в'язкості призводить до осідання дози під дією сили тяжіння та поверхневого натягу, викликаючи дефект бічного розтікання (від англ. @@en|slump@@). Часова залежність відновлення внутрішньої коагуляційної структури матеріалу описується явищем тиксотропії (від грец. @@grc|θίξις@@ — дотик та @@grc|троπή@@ — зміна; @@en|thixotropy@@).

Динаміку внутрішньої структури матеріалу описують безрозмірним параметром структури `λ` (у межах від 0 для повністю зруйнованої сітки до 1 для відновленої). Швидкість зміни `λ` у часі `t` залежить від константи механічного руйнування `k_d`, швидкості зсуву `γ̇` та константи тиксотропного відновлення в стані спокою `k_r` (с⁻¹). Кінетичне диференціальне рівняння руйнування та відновлення має вигляд:

```
dλ/dt = -k_d · γ̇ · λ + k_r · (1 - λ)
```

Під час руху ракеля при високій швидкості зсуву `γ̇` переважає доданок руйнування `-k_d · γ̇ · λ`, і параметр `λ` прямує до мінімуму. У стані спокою після зняття трафарету (`γ̇ = 0`) рівняння спрощується до кінетики відновлення:

```
dλ/dt = k_r · (1 - λ)
```

Інтегрування цього рівняння визначає зростання границі плинності `τ₀(t)` від початкового значення `τ₀_min` до стаціонарного максимуму `τ₀_max`:

```
τ₀(t) = τ₀_max - (τ₀_max - τ₀_min) · e⁻ᵏʳᵗ
```

Для запобігання розтіканню `slump` дози пасти висотою `h_deposit` границя плинності `τ₀` повинна перевищувати сумарне напруження від власної ваги та капілярного тиску. Умова стійкості дози виражається через густину пасти `ρ` (для матеріалів на основі [чистого припою та олова](root:cat-hw-instruments/solder-tin) вона становить 7300–7500 кг/м³), прискорення вільного падіння `g` (9.81 м/с²), поверхневий натяг флюсової фази `γ_surf` (Н/м) та радіус кривизни бічної поверхні `R_curv` (м):

```
τ₀ > ρ · g · h_deposit + (2 · γ_surf / R_curv)
```

**Розрахунок мінімальної границі плинності для запобігання розтіканню дози**
Обчислимо мінімальну границю плинності `τ₀`, необхідну для утримання дози пасти висотою `h_deposit = 150 мкм = 0.00015 м` з густиною `ρ = 7400 кг/м³` та капілярним напруженням `P_cap = 15 Па`.

Гідростатичне напруження від власної ваги `P_hydro` обчислюємо як добуток густини, прискорення вільного падіння та висоти дози:

```
P_hydro = 7400 · 9.81 · 0.00015
= 72594 · 0.00015         [множення густини на прискорення вільного падіння]
= 10.889 Па               [обчислення гідростатичного напруження від ваги пасти]
```

Сумарне критичне напруження деформації `τ_crit` дорівнює сумі гідростатичного та капілярного напружень:

```
τ_crit = 10.889 + 15
= 25.889 Па               [додавання капілярного напруження P_cap]
```

Для компенсації вібрацій транспортера та динамічного удару під час монтажу компонентів автоматичним установником (від англ. @@en|pick-and-place@@) вводять коефіцієнт запасу міцності `S_f = 4`. Мінімальна границя плинності `τ₀_min` в момент зняття трафарету становить:

```
τ₀_min = 25.889 · 4
= 103.556 Па              [множення критичного напруження на коефіцієнт запасу]
```

Якщо за час між друком та встановленням компонентів значення `τ₀(t)` не досягає `104 Па` через мале значення `k_r`, доза пасти розтікається з утворенням перемичок між суміжними відбитками.

## Рівняння теплопровідності та температурні градієнти

При проходженні вузла через піч пади 0201 прогріваються за секунди, а масивні корпуси @@en|BGA@@ (англ. *BGA*, скорочення від *Ball Grid Array* — масив кулькових виводів) мають теплову інерцію з градієнтом до 20–25 °C. Фізичним описом явища є диференціальне @@en|heat conduction equation@@ (англ. *heat conduction equation*, від дав.-гр. *θερμή* — тепло + лат. *conductio* — перенесення + лат. *aequatio* — зрівняння) у тривимірній формі Фур'є.

Температуру `T(x, y, z)` у часі `t` під дією конвекції визначає рівняння:

    ∂T / ∂t = α · (∂²T / ∂x² + ∂²T / ∂y² + ∂²T / ∂z²)
            = α · ∇²T                           [тривимірне нестаціонарне рівняння Фур'є]

Тут `α = k / (ρ · c_p)` — температуропровідність, де `k` — теплопровідність @@en|thermal conductivity@@ (англ. *thermal conductivity*, від лат. *thermalis* — тепловий + *conductivus* — провідний), `ρ` — густина, `c_p` — питома теплоємність @@en|thermal capacity@@ (англ. *thermal capacity*, від лат. *capacitas* — місткість).

Структура @@en|PCB@@ (англ. *PCB*, скорочення від *Printed Circuit Board* — друкована плата) анізотропна: склотекстоліт має `k_FR4 ≈ 0.28 Вт/(м·К)`, мідь — `k_Cu ≈ 390 Вт/(м·К)`. Поздовжню `k_xy` та поперечну `k_z` теплопровідність для товщини `D_total` визначають формули:

    k_xy = ∑ (d_i · k_i) / D_total                              [поздовжня теплопровідність]
    k_z = D_total / ∑ (d_i / k_i)                              [поперечна теплопровідність]

Для 4-шарової плати `D_total = 1.6 мм` із екранами міді `0.07 мм` та текстолітом `1.53 мм`:

    k_xy = (0.07 · 390 + 1.53 · 0.28) / 1.6
         = (27.3 + 0.4284) / 1.6                              [сумування поздовжніх теплових потоків]
         ≈ 17.33 Вт/(м·К)                                     [поздовжня теплопровідність]

    k_z = 1.6 / ((0.07 / 390) + (1.53 / 0.28))
        = 1.6 / (0.000179 + 5.464)                            [сумування поперечних теплових опорів]
        ≈ 0.293 Вт/(м·К)                                      [поперечна теплопровідність]

Перевищення `k_xy` над `k_z` у 59 разів створює інтенсивний питомий тепловідвід — @@en|specific heat dissipation@@ (англ. *specific heat dissipation*, від лат. *specificus* — питомий + *dissipatio* — розсіювання) — вздовж площини плати.

Швидкість нагріву `dT/dt` залежить від площі `A` та маси `m`:

    dT / dt = h · A · (T_gas - T_comp) / (m · c_p)            [швидкість нагріву компонента]

Для пада 0402 (`m_pad ≈ 0.005 г`, `τ_pad ≈ 4 c`) й корпусу @@en|BGA@@ (`m_bga ≈ 8 г`, `τ_bga ≈ 40 c`) обчислимо градієнт `ΔT` через `t = 30 c` в середовищі `T_gas = 175 °C` (`T_0 = 25 °C`):

    T_pad(30) = 175 - 150 · exp(-30 / 4) ≈ 174.9 °C
    T_bga(30) = 175 - 150 · exp(-30 / 40) = 175 - 150 · 0.4724 ≈ 104.1 °C
    ΔT = 174.9 °C - 104.1 °C = 70.8 °C                         [градієнт без стабілізації]

Градієнт 70.8 °C спричиняє деактивацію флюсу з [компонентів припайних паст](root:cat-hw-instruments/smd-soldering-fluxes-and-pastes) на дрібних падах до прогріву @@en|BGA@@. Обстеження зон [оптичним мікроскопом паяння](root:cat-hw-instruments/optical-microscope-soldering) доводить потребу у фазі стабілізації.

## Математика теплового бюджету та стабілізації

Вирівнювання температурного поля по площі плати до рівності `ΔT ≤ 2–5 °C` відбувається у зоні витримування — @@en|soak time@@ (англ. *soak time*). Тут випаровуються розчинники флюсу й активуються органічні кислоти.

Методика [обчислення теплового бюджету](#thermal-budget-evaluation) `Q_budget` (Дж) описується сумою конвективного та радіаційного теплових потоків у часі `t`:

    Q_budget = ∫ [h · A · (T_oven(t) - T_pcb(t)) + ε · σ_SB · A · (T_rad⁴(t) - T_pcb⁴(t))] dt    [інтеграл теплового бюджету]

Тут `h` — коефіцієнт конвективної тепловіддачі, `A` — площа поверхні, `T_oven` і `T_pcb` — температури печі та плати, `ε` — ступінь чорноти, `σ_SB` — стала Стефана-Больцмана, `T_rad` — температура випромінювачів.

Зменшення температурного градієнта `ΔT(t)` визначає закон експоненційного згладжування з часовою константою релаксації `τ_eq`:

    ΔT(t) = ΔT_0 · exp(-t / τ_eq)                              [релаксація температурного градієнта]

Розрахуємо мінімальний час витримування `t_soak_min` для вирівнювання градієнта від початкового `ΔT_0 = 25 °C` до цільового `ΔT_target = 3 °C` при `τ_eq = 35 с`:

    t_soak_min = -35 · ln(3 / 25)
               = -35 · (-2.1203)                               [обчислення натурального логарифма]
               ≈ 74.2 с                                        [мінімальний час зони soak time]

Верхню межу часу обмежено термодеструкцією флюсу за кінетичним рівнянням Арреніуса:

    k_deg(T) = A_deg · exp(-E_a / (R_gas · T))                 [швидкість термодеструкції флюсу]

Де `A_deg` — передекспоненційний множник, `E_a` — енергія активації розкладу, `R_gas` — універсальна газова стала, `T` — абсолютна температура. При `t_soak > 120 с` у діапазоні 170–190 °C флюсуюча здатність падає нижче 15%, спричиняючи окислення контактів.

Перевищення швидкості нагріву спричиняє @@en|thermal shock@@ та розшарування @@en|delamination@@ підкладки. Для [запобігання термічному шоку](#thermal-shock-prevention) компонентоємних керамічних конденсаторів @@en|MLCC@@ (англ. *MLCC*) враховують внутрішнє термонапруження `σ_therm`:

    σ_therm = E_ceramic · α_ceramic · ΔT_internal / (1 - ν)   [термонапруження в MLCC]

Тут `E_ceramic` — модуль Юнга кераміки, `α_ceramic` — коефіцієнт теплового розширення (КТР), `ΔT_internal` — перепад температур у корпусі, `ν` — коефіцієнт Пуассона. При `σ_therm > 80 МПа` кераміка тріскається. Для плати вище температури склування `T_g = 150 °C` КТР вздовж осі `z` зростає з 35 до 250 ppm/°C.

Розрахуємо граничну швидкість нагріву `(dT/dt)_max` для різниці КТР `Δα_z = 233 · 10⁻⁶ K⁻¹` та припустимого зсувного напруження FR-4 `τ_shear = 25 МПа`:

    (dT / dt)_max = 25 · 10⁶ / (22 · 10⁹ · 233 · 10⁻⁶ · 2.5)
                  = 25 · 10⁶ / 128150                          [обчислення знаменника]
                  ≈ 1.95 °C/s                                  [гранична швидкість нагріву]

Тому швидкість нагріву обмежують у межах 1.5–2.0 °C/s. Застосування [безпечних безвідмивних флюсів](root:cat-hw-instruments/no-clean-fluxes-chemistry-and-classification) і налаштування [паяльних термоповітряних станцій](root:cat-hw-instruments/baku-hot-air-stations-family) виключають руйнування вузла.

## Моделювання профілю оплавлення сплаву SAC305

Розрахований [профіль паяння розплавленням](#reflow-soldering-profile) — @@en|reflow soldering profile@@ (англ. *reflow soldering profile*, від англ. *reflow* — повторне оплавлення + *soldering* — паяння + італ. *profilo* — обрис) — описує режими для безсвинцевого сплаву @@en|SAC305@@ (англ. *SAC305*, скорочення від *Sn-Ag-Cu 96.5/3.0/0.5* — сплав олова, срібла та міді) з температурою плавлення `T_eutectic = 217 °C`. Ключовим параметром є час перебування вище лінії ліквідусу — @@en|time above liquidus@@ (англ. *time above liquidus*, від лат. *liquidus* — рідкий), який позначають як @@en|TAL@@ (англ. *TAL*, скорочення від *Time Above Liquidus* — час перебування вище лінії ліквідусу).

![Термопрофіль оплавлення безсвинцевого сплаву SAC305 із позначенням зон нагріву, витримування soak time, часу TAL та охолодження. З нього читач бачить часово-температурні межі кожної фази та критичні пороги dT/dt.](img/sac305-reflow-thermal-profile.svg)
*Термопрофіль оплавлення безсвинцевого сплаву SAC305 із позначенням зон нагріву, витримування soak time, часу TAL та охолодження: часово-температурні межі кожної фази та критичні пороги dT/dt.*

Протягом @@en|TAL@@ утворюється міжметалева сполука — @@en|intermetallic compound@@ (англ. *intermetallic compound*, від лат. *inter* — між + *metallum* — метал + *componere* — складати) — `Cu₆Sn₅`. Товщина шару `d_IMC` зростає за законом:

    d_IMC = d_0 + K_0 · exp(-Q_IMC / (R_gas · T_peak)) · √(t_TAL)   [ріст міжметалевого шару]

При `t_TAL > 90 с` або `T_peak > 250 °C` шар `d_IMC` перевищує `4 мкм`, викликаючи окрихчування паяного з'єднання. Норма для @@en|SAC305@@: `T_peak = 238–245 °C`, `t_TAL = 60–70 с`, охолодження `-(dT/dt)_cool = 2.5–4.0 °C/s`.

Асиметрія плавлення `ΔT_melt > 3 °C` створює перекидальний момент, що спричиняє дефект «надгробного камена» — @@en|tombstoning@@ (англ. *tombstoning*, від англ. *tombstone* — надгробний камінь), а швидке газоутворення при початковому нагріві викликає утворення кульок припою — @@en|solder beading@@ (англ. *solder beading*, від англ. *solder* — припій + *bead* — бусина). Рівняння Холомона визначає розмір дендритів `Ag₃Sn` при охолодженні:

    d_dendrite = C_cool / (-(dT / dt)_cool)⁰·⁵                [дисперсність Ag3Sn]

При `-(dT/dt)_cool = 3.5 °C/s` утворюються дрібні комірки `d_dendrite < 1.5 мкм` для максимальної міцності.

**Розрахунок тривалостей зон профілю**
Для заданих параметрів нагріву й охолодження обчислимо тривалість кожної зони та загальний час циклу `t_total`:

    t_1 = (150 - 25) / 1.5
        ≈ 83.3 с                                               [тривалість фази Preheat]

    t_soak = 90.0 с                                           [тривалість фази Soak]

    t_3 = (240 - 200) / 1.6
        = 25.0 с                                               [тривалість підйому Ramp-to-peak]

    t_TAL = 65.0 с                                             [час вище ліквідусу Reflow]

    t_5 = (240 - 100) / 3.0
        ≈ 46.7 с                                               [тривалість охолодження Cooling]

    t_total = 83.3 + 90.0 + 25.0 + 46.7
            = 245.0 с
            ≈ 4.08 хв                                          [загальний час термоциклу]

Математична модель оптимізує застосування [безсвинцевих сплавів припою](root:cat-hw-instruments/soldering-fluxes-and-solders). При ремонтних роботах із використанням [видалення залишків припою](root:cat-hw-instruments/solder-wick) профіль виключає перегрів сусідніх компонентів.
