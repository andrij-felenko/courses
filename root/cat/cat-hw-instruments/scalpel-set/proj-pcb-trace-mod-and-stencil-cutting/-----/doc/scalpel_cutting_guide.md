# Технологічна карта та інструкція з прецизійної обробки скальпелем

## 1. Огляд геометрії та вибір змінних лез

Для досягнення чистого зрізу без деформації країв оброблюваного матеріалу (пластикових корпусів, ізоляційних плівок, друкованих плат) вибирають відповідний профіль змінних лез:

| Позначення | Профіль кромки | Основне призначення | Особливості застосування |
| :--- | :--- | :--- | :--- |
| **Лезо №10** | Довге опукле вигнуте полотно | Лінійні розрізи та підрізання широких площин | Забезпечує велику площу контакту під малим кутом атаки |
| **Лезо №11** | Гострокутне пряме з гострим кінчиком | Проколювання, вибірка прямих кутів, підрізка доріжок | Вимагає обережності: кінчик чутливий до згинальних моментів |
| **Лезо №15** | Мале закруглене полотно | Зачищення фасок, підрізка радіусних заокруглень | Дозволяє виконувати точні маніпуляції у обмежених пазах |
| **Лезо №12** | Серпоподібне з угнутою кромкою | Знімання заудирок у важкодоступних заглибленнях | Працює на тяговий рух «на себе» |

## 2. Фіксація леза в рукоятці та безпечна заміна

Утримування леза в рукоятці здійснюється цанговим затискачем або замковим пазом стандарту №3 (для малих лез №10–15) чи №4 (для великих лез).

### Покроковий алгоритм безпечної заміни:
1. **Категорично заборонено** брати лезо незахищеними пальцями за різальну кромку.
2. Для встановлення затисніть обух леза (неробочу частину) вузькогубцями або пінцетом.
3. Сумістіть отвір замкового паза леза з направляючими пазами рукоятки.
4. Просуньте лезо назад до характерного клацання фіксатора.
5. Для знімання підніміть задню кромку леза пінцетом і зсуньте його вперед у напрямку «від себе».
6. Відпрацьовані леза утилізуйте у жорсткий контейнер для гострих відходів.

## 3. Підготовка робочого місця та вибір оснащення

* **Макетовальний килимок (Self-Healing Mat):** Багатошаровий PVC-килимок із властивістю самовідновлення поверхового шару. Вловлює вістря леза, запобігаючи тупінню кромки та сованню деталі.
* **Металева лінійка:** Використовується сталева лінійка з гумовою протиковзною накладкою на зворотному боці. Пластикові чи дерев'яні лінійки не застосовуються через ризик зрізання стружки у тіло лінійки.

## 4. Практична техніка різання та розклад сил

### Контроль кута атаки (α) та притиску (F_N):
* **Принцип багатьох проходів:** Товсті листові матеріали (акрил, ABS, PETG) не зрізають за один силовий прохід. Виконують 3–5 послідовних проходів із помірним притискним зусиллям F_N. Перший прохід створює направляючий рівчак, наступні — заглиблюють його.
* **Кут атаки (α):**
  * Для тонких плівок та паперу: α = 45°–60° (збільшує стійкість полотна).
  * Для товстого пластику та м'яких еластомерів: α = 15°–30° (зменшує силу тертя F_fr на бічних фасках).
* **Техніка хвату:** Рукоятку утримують як пиловий олівець (триточковий хват) з опорою мізинця або безіменного пальця на макетовальний килимок для стабілізації глибини.

---

## 5. Типові дефекти та їх усунення

* **Злам кінчика леза №11:** Виникає при прикладанні бічного зусилля під час повороту. Лезо №11 призначене виключно для прямолінійного руху або проколювання.
* **Утворення заудирок на пластику:** Свідчить про затуплення мікрорадіуса кромки або надмірну швидкість протягування. Замініть лезо та зменшіть зусилля.
* **Совання матеріалу:** Відбувається при різанні без опертя на самовідновлюваний килимок або при недостатньому фіксуванні деталі.
