# Поглиблений аналіз динаміки VCM, математики PDAF/CDAF та драйверів

Автофокусування у прецизійних оптичних приладах — це мультидисциплінарна задача на стику мікроелектромеханічних систем (MEMS/VCM), хвильової оптики та швидкісних алгоритмів цифрової обробки зображень (DSP/ISP). У цьому розділі наведено суворий математичний опис перехідних процесів звукової котушки, алгоритмів формування імпульсів безколивального руху (Input Shaping), математики операторів контрасту Тенеграда та фазової кореляції, а також виробничий драйвер на мові C для інтегрального контролера DW9714.

---

## 1. Математична модель динаміки звукової котушки VCM

Механічна частина VCM представляє собою класичний осцилятор другого порядку: маса оптичного тубуса з лінзами `m` утримується двома планарними пружинами з жорсткістю `K_s` у в'язкому середовищі з коефіцієнтом демпфування `b`.

### Диференційне рівняння другого порядку

Рух лінзи вздовж оптичної осі Z описується рівнянням:

```text
m * (d^2 z / dt^2) + b * (d z / dt) + K_s * z = F_lorentz(t)
де:
  m — маса рухомого оптичного блока (типово 150 .. 280 мг = 1.5e-4 .. 2.8e-4 кг),
  b — коефіцієнт в'язкого демпфування повітря та матеріалу пружин,
  K_s — сумарна жорсткість двох пружин (типово 12 .. 25 Н/м),
  F_lorentz(t) = K_f * I(t) — сила Лоренца,
  K_f — електромагнітний силовий фактор приводу (типово 0.08 .. 0.15 Н/А).
```

### Передавальна функція в операторній формі Лапласа

Застосувавши перетворення Лапласа, отримуємо передавальну функцію від струму котушки `I(s)` до механічного зміщення `Z(s)`:

```text
G(s) = Z(s) / I(s) = (K_f / m) / (s^2 + 2 * zeta * omega_0 * s + omega_0^2)
де:
  omega_0 = sqrt(K_s / m) — власна кутова резонансна частота (рад/с),
  f_0 = omega_0 / (2 * pi) — резонансна частота в герцах (типово 75 .. 110 Гц),
  zeta = b / (2 * sqrt(m * K_s)) — коефіцієнт демпфування системи.
```

Для реальних пружинних VCM коефіцієнт демпфування вкрай малий: `zeta ≈ 0.05 .. 0.12` (дуже слабке затухання). Внаслідок цього амплітудно-частотна характеристика має гострий резонансний пік добротності `Q = 1 / (2 * zeta) ≈ 4 .. 10` (+12 .. +20 дБ), що робить систему вкрай схильною до тривалого «дзвону» (Ringing).

## 2. Математика придушення коливань: метод шейпування імпульсів (Zero Vibration Shaping)

Щоб перемістити лінзу в нову точку за мінімальний час без виникнення резонансних коливань, застосовується алгоритм **шейпування вхідного сигналу (Input Shaping)**, зокрема метод нульової вібрації (ZV Shaper).

Замість одного прямокутного стрибка струму амплітудою `I_target` на котушку подається послідовність із двох зсунутих у часі імпульсів:
- Перший імпульс амплітудою `A1` у момент часу `t1 = 0`.
- Другий імпульс амплітудою `A2` у момент часу `t2 = T_d / 2`.

```text
Розрахунок параметрів ZV-шейпера:
  K = exp( - (zeta * pi) / sqrt(1 - zeta^2) )
  A1 = 1 / (1 + K)
  A2 = K / (1 + K)
  t2 = pi / omega_d = 1 / (2 * f_d)
де:
  omega_d = omega_0 * sqrt(1 - zeta^2) — демпфована частота коливань,
  f_d — частота дзвону VCM (вимірюється під час калібрування).
```

Приклад для `zeta = 0.08` та `f_0 = 85 Гц`:
```text
K = exp( - (0.08 * 3.1416) / sqrt(1 - 0.0064) ) = exp(-0.252) ≈ 0.777
A1 = 1 / (1 + 0.777) ≈ 0.563 (56.3% від повного стрибка струму)
A2 = 0.777 / (1 + 0.777) ≈ 0.437 (43.7% від повного стрибка струму)
t2 = 1 / (2 * 85) = 0.00588 с = 5.88 мс.
```

Через 5.88 мс після подачі першого імпульсу лінза досягає амплітудного максимуму коливання. Подача другого імпульсу в цей самий момент збуджує коливання в точній протифазі, що призводить до повної деструктивної інтерференції механічних хвиль. Коливання взаємно знищуються, і лінза миттєво зупиняється в заданій точці.

## 3. Математичні оператори контрастного фокусування (CDAF)

В алгоритмах CDAF процесор сигналу зображення аналізує різкість виділеного вікна інтересу (Region of Interest, ROI) розміром, наприклад, 256x256 пікселів.

### Оператор Тенеграда (Tenengrad Focus Measure)

Найстійкішим до цифрового шуму є інтегральний оператор Тенеграда, що базується на згортці зображення з ядрами Собеля розміром 3x3:

```text
G_x = [ -1  0 +1 ]          G_y = [ -1 -2 -1 ]
      [ -2  0 +2 ]                [  0  0  0 ]
      [ -1  0 +1 ]                [ +1 +2 +1 ]

S_x(x,y) = Image * G_x,     S_y(x,y) = Image * G_y
```

Сумарна функція різкості Тенеграда обчислюється як сума квадратів градієнтів, що перевищують поріг чутності шумів матриці `Threshold`:

```text
FV_Tenengrad = SUM_{x,y} [ (S_x(x,y)^2 + S_y(x,y)^2) ],  за умови (S_x^2 + S_y^2) > Threshold
```

### Модифікований Лапласіан (Sum of Modified Laplacian, SML)

Для сцен із тонкою текстурою (дрібний текст або мікродеталі) кращу чутливість забезпечує оператор SML, який уникає взаємного гасіння других похідних вздовж осей X та Y:

```text
ML(x,y) = | 2*I(x,y) - I(x - step, y) - I(x + step, y) | +
          | 2*I(x,y) - I(x, y - step) - I(x, y + step) |

FV_SML = SUM_{x,y} ML(x,y),  де step — крок дискретизації (зазвичай 1 або 2 пікселі).
```

## 4. Математика фазової детекції (PDAF): кореляція та дефокус

У сенсорах із підтримкою PDAF (Dual Pixel 2PD або масковані пікселі) мікролінза формує два суб-зображення одного фрагмента сцени: ліве `I_L(x)` та праве `I_R(x)`.

Величина та знак фазового зсуву `Delta_x` визначаються максимумом функції взаємної крос-кореляції:

```text
R_LR(d) = SUM_{x} [ I_L(x) * I_R(x + d) ]
```

Позиція максимуму з субпіксельною точністю `d*` визначається за трьома точками через параболічну інтерполяцію вершини:
```text
d* = d_max + (R(d_max - 1) - R(d_max + 1)) / (2 * (R(d_max - 1) - 2 * R(d_max) + R(d_max + 1)))
```

Зв'язок між оптичним зсувом `d*` та фізичним дефокусом лінзи `Delta_z` описується калібрувальним коефіцієнтом оптичного розділення зіниці `K_pdaf` (DCC — Defocus Conversion Coefficient):

```text
Delta_z = K_pdaf * d*
```

Знаючи `Delta_z`, контролер безпосередньо обчислює необхідну зміну коду ЦАП драйвера VCM за один такт опитування:
```text
Delta_DAC = Delta_z / S_vcm
де S_vcm — чутливість приводу VCM (типово 0.3 .. 0.45 мкм / крок ЦАП).
```

## 5. Виробнича реалізація драйвера VCM на мові C (DW9714)

Нижче наведено виробничий драйвер для популярного 10-бітного контролера звукової котушки **DW9714**, який реалізує апаратне налаштування фільтра Anti-Ringing (DLC/S-Curve) через послідовну шину I2C.

```c
#include <stdint.h>
#include <stdbool.h>

/* I2C адреса мікросхеми DW9714 (7-бітна: 0x0C, 8-бітна запис: 0x18) */
#define DW9714_I2C_ADDR_7BIT      0x0C
#define DW9714_I2C_ADDR_WRITE     0x18

/* Максимальне значення 10-бітного ЦАП */
#define DW9714_DAC_MAX            1023

/* Режими роботи вихідного каскаду */
typedef enum {
    DW9714_MODE_DIRECT      = 0x00, /* Прямий крок без фільтрації */
    DW9714_MODE_RINGING_DLC = 0x01, /* Прямий ZV-компенсатор дзвону (DLC) */
    DW9714_MODE_S_CURVE     = 0x02  /* Плавний S-подібний профіль струму */
} dw9714_mode_t;

/* Прототипи функцій апаратного рівня (HAL) мікроконтролера */
extern bool hal_i2c_write_bytes(uint8_t dev_addr, const uint8_t *data, uint16_t length);
extern void hal_delay_us(uint32_t us);

/* Структура дескриптора приводу VCM */
typedef struct {
    uint16_t current_code;
    uint8_t  step_period_code; /* Параметр Ts резонансної затримки */
    dw9714_mode_t mode;
} dw9714_driver_t;

static dw9714_driver_t g_vcm;

/**
 * @brief Ініціалізація мікросхеми драйвера VCM DW9714
 * @param res_freq_hz Резонансна частота VCM (наприклад, 85 Гц)
 * @param mode Режим формування фронту струму
 * @return true у разі успішного конфігурування
 */
bool dw9714_init(uint16_t res_freq_hz, dw9714_mode_t mode) {
    uint8_t init_packet[2];

    g_vcm.current_code = 0;
    g_vcm.mode = mode;

    /* Розрахунок періоду резонансу для апаратного таймера драйвера:
     * DW9714 використовує 4-бітний код вибору часу T_step:
     * Коди 0x0..0xF задають інтервал затримки від 50 мкс до 12.8 мс */
    if (res_freq_hz >= 120) {
        g_vcm.step_period_code = 0x04; /* ~4.2 мс */
    } else if (res_freq_hz >= 80) {
        g_vcm.step_period_code = 0x06; /* ~5.9 мс */
    } else {
        g_vcm.step_period_code = 0x08; /* ~8.0 мс */
    }

    /* Формування командного байта конфігурації фільтра Anti-Ringing:
     * Байт 1: [0 1 1 0] | [Режим 2 біти] | [T_step старші біти]
     * Байт 2: [T_step молодші біти] | [0 0 0 0] */
    init_packet[0] = 0xEC; /* Спеціальна команда Power-On / Setup */
    init_packet[1] = 0xA3;

    if (!hal_i2c_write_bytes(DW9714_I2C_ADDR_WRITE, init_packet, 2)) {
        return false;
    }

    /* Початкове встановлення струму в 0 (фокус на нескінченність) */
    return dw9714_set_focus_code(0);
}

/**
 * @brief Встановлення значення ЦАП приводу VCM (0..1023)
 * @param dac_code Значення струму (0 = Infinity, 1023 = Macro)
 */
bool dw9714_set_focus_code(uint16_t dac_code) {
    uint8_t packet[2];

    if (dac_code > DW9714_DAC_MAX) {
        dac_code = DW9714_DAC_MAX;
    }

    /* Формат передачі даних DW9714 (16-бітний фрейм):
     * Байт 0: [Режим 2 біти] [T_step 2 біти] [DAC_Code біти 9:6]
     * Байт 1: [DAC_Code біти 5:0] [PD біт (0=Normal, 1=PowerDown)] [Reserved 0] */
    if (g_vcm.mode == DW9714_MODE_RINGING_DLC) {
        packet[0] = (uint8_t)(((g_vcm.step_period_code & 0x0F) << 4) | ((dac_code >> 6) & 0x0F));
    } else if (g_vcm.mode == DW9714_MODE_S_CURVE) {
        packet[0] = (uint8_t)(0x80 | ((g_vcm.step_period_code & 0x07) << 4) | ((dac_code >> 6) & 0x0F));
    } else {
        packet[0] = (uint8_t)((dac_code >> 6) & 0x0F); /* Прямий режим */
    }

    packet[1] = (uint8_t)((dac_code & 0x3F) << 2); /* Біт 1 = 0 (Power On) */

    if (!hal_i2c_write_bytes(DW9714_I2C_ADDR_WRITE, packet, 2)) {
        return false;
    }

    g_vcm.current_code = dac_code;
    return true;
}

/**
 * @brief Переведення драйвера VCM у режим ультра-низького споживання (Power Down)
 */
bool dw9714_power_down(void) {
    uint8_t packet[2];
    packet[0] = 0x00;
    packet[1] = 0x02; /* Біт PD (Power Down) = 1 */
    return hal_i2c_write_bytes(DW9714_I2C_ADDR_WRITE, packet, 2);
}
```

## 6. Діагностика несправностей актуатора VCM

1. **Гравітаційне розкалібрування фокусу (Orientation Tilt Error):**
   - *Симптом:* Камера чудово фокусується у горизонтальному положенні, але втрачає різкість або вимагає зовсім інших значень ЦАП при нахилі об'єктива строго вгору або вниз.
   - *Фізика:* Сила тяжіння `m * g` додається або віднімається від сили Лоренца, зміщуючи початкову точку пружини на 20–40 мкм.
   - *Вирішення:* Використання приводів Closed-Loop VCM із датчиком Холла, або програмна корекція таблиці фокусу за даними вбудованого 6-осьового акселерометра/гіроскопа (IMU).
2. **Теплове дрейфування фокусу (Thermal Drift):**
   - При тривалій роботі лінійного матричного сенсора нагріваються оптичні пластикові лінзи та корпус, змінюючи коефіцієнт теплового розширення та радіус заломлення світла.
   - *Вирішення:* Періодична фонова перевірка піку чіткості CDAF раз на 10–30 секунд при зміні показників внутрішнього термодатчика камери.
