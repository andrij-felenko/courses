# Поглиблений інженерний аналіз та схемотехніка датчиків серії AHT20

Датчики відносної вологості й температури AHT20 поєднують передові досягнення кремнієвої мікромеханіки (MEMS) та низькоспоживаючих змішаних аналого-цифрових інтегральних схем (ASIC). На відміну від застарілих датчиків із дискретними сенсорними пластинами, компонування AHT20 використовує мікролітографічні ємнісні структури та прецизійний сигма-дельта тракт перетворення ємності в код безпосередньо всередині мініатюрного корпусу.

У цьому детальному посібнику розглядаються технологічні етапи виготовлення MEMS-сенсора, архітектура комутованого аналогового фронтенду CDC, математичні моделі калібрування DSP, проектування неблокуючого виробничого драйвера на C з контролем CRC-8, а також протоколи дегазації та забезпечення надійності в промислових умовах.

---

## 1. Мікромеханічна технологія MEMS: фотолітографія, плазмове травлення та формування полімерного діелектрика

MEMS-кристал AHT20 виготовляється за груповою планарною технологією на монокристалічних кремнієвих пластинах діаметром 200 мм (p-тип провідності, орієнтація кристалічної решітки <100>).

### Технологічний маршрут виготовлення осередку

1. **Термічне оксидування:** Формування ізолюючого шару діоксиду кремнію (SiO2) товщиною 800–1200 нм у печі за температури 1050 °C у середовищі сухого та вологого кисню для електричної ізоляції від кремнієвої підкладки.
2. **Осадження електродної металізації:** Нанесення адгезійного підшару титану або хрому (Ti/Cr товщиною 20 нм) та основного провідного шару золота чи платини (Au/Pt товщиною 200–300 нм) методом магнетронного розпилення.
3. **Фотолітографія та сухе травлення гребінців:** Формування топології зустрічно-штирьових електродів за допомогою ультрафіолетової літографії та реактивного іонного травлення (RIE). Зазор між сусідніми мікросмужками становить s = 2.0–2.5 мкм при ширині пальця w = 2.5 мкм.
4. **Центрифугування та полімеризація чутливого шару (Spin Coating):** Нанесення рідкого розчину гідрофільного термореактивного полііміду (або ефірів целюлози) на центрифузі зі швидкістю 3000–5000 об/хв для досягнення суворо рівномірної товщини плівки d = 1.2–1.8 мкм. Потім пластина проходить ступінчастий термопрогрів (Soft Bake 120 °C, Hard Cure 350 °C в інертній атмосфері азоту).
5. **Напилення пористого верхнього електрода:** Магнетронне напилення перколяційної плівки чистого золота товщиною лише 20–30 нм. Плівка утворює відкриту лабіринтну нанопористу мережу з розміром пор 10–50 нм, що забезпечує електричну провідність для екранування від статичних зарядів і водночас відкриває вільний доступ молекулам газу до полімеру.

### Модель нестаціонарної дифузії вологи (Закони Фіка)

Час відгуку сенсора визначається швидкістю дифузії водяної пари крізь товщу полімерної плівки. Дифузійний процес описується другим законом Фіка для одновимірного випадку:

```
dC_w / dt = D_eff * (d^2 C_w / dx^2)
```

де `C_w(x, t)` — концентрація молекул води на глибині x у момент часу t, а `D_eff` — ефективний коефіцієнт дифузії вологи в полімері (для поліімідів при 25 °C становить близько `1.5e-9 см^2/с`).

Характерний час виходу на 63.2% рівноважної ємності (постійна часу t_63%) визначається товщиною шару d:

```
t_63% ≈ (4 * d^2) / (pi^2 * D_eff)
```

При товщині плівки d = 1.5 мкм (1.5e-4 см):

```
t_63% ≈ (4 * (1.5e-4)^2) / (3.14159^2 * 1.5e-9) = (4 * 2.25e-8) / (9.8696 * 1.5e-9) ≈ 9.0e-8 / 1.48e-8 ≈ 6.08 секунди
```

Теоретичний розрахунок ідеально збігається з експериментальними даними даташиту (постійна часу AHT20 становить 5–8 с).

## 2. Схемотехніка аналогового інтерфейсу ASIC: Switched-Capacitor CDC та сигма-дельта модуляція

Аналоговий фронтенд ASIC реалізує прецизійне вимірювання ємності безперервним балансуванням заряду.

### Диференційний інтегратор заряду на комутованих конденсаторах

Осередок CDC містить прецизійний операційний підсилювач із комутованими МОН-ключами, що працюють у двотактному режимі (фази Phi_1 та Phi_2 неперекривного тактування):

```
Фаза Phi_1 (Скидання): Сенсорний конденсатор C_sens заряджається до V_ref, інтегруючий конденсатор C_int розряджається.
Фаза Phi_2 (Перенесення): Заряд Q_sens переноситься у віртуальну землю ОП на інтегруючу ємність C_int.
```

Вихідна напруга за один цикл комутації становить:

```
V_out = V_ref * ( (C_sens - C_ref) / C_int )
```

де `C_ref` — внутрішній інтегрований опорний кремнієвий конденсатор високої стабільності (ТКО < 5 ppm/°C).

### Придушення низькочастотного флікер-шуму 1/f

Для виключення дрейфу напруги зміщення ОП (Offset Drift) та придушення низькочастотного шуму типу 1/f (рожевий шум МОН-транзисторів) застосовується метод корельованої подвійної вибірки (Correlated Double Sampling, CDS):
- На фазі скидання фіксується власна напруга зміщення підсилювача V_os.
- На фазі інтегрування напруга V_os віднімається від результуючого сигналу.
- Це дозволяє знизити еквівалентний шум вимірювання ємності до рівня одиниць атоофарад (1 аФ = 10^-18 Ф).

### Сигма-дельта модулятор 2-го порядку та децимуючий фільтр

Вихідна напруга CDC перетворюється в однобітний цифровий потік сигма-дельта модулятором 2-го порядку з частотою тактування f_mod = 1.024 МГц. 

Коефіцієнт передискретизації становить:

```
OSR = f_mod / (2 * f_Nyquist) = 1024000 / (2 * 50) = 10240
```

Цифровий децимуючий sinc^3-фільтр перетворює потік модульованих бітів у 20-бітне паралельне двійкове слово з частотою видачі 12.5 Гц (час перетворення одного вимірювання становить 80 мс). 

Завдяки високому коефіцієнту OSR шум квантування витісняється у високочастотну область спектра (Noise Shaping), забезпечуючи ефективне співвідношення сигнал/шум (SNR) понад 92 дБ.

## 3. Алгоритми поліноміальної калібровки DSP та енергонезалежна OTP ROM

Фізична залежність ємності полімеру від відносної вологості має нелінійний S-подібний характер через перехід від мономолекулярної адсорбції до капілярної конденсації, а чутливість залежить від поточної температури кристала.

### Математична двовимірна поліноміальна модель

Для відновлення лінійної метрологічної шкали вбудований апаратний математичний співпроцесор DSP виконує розрахунок за двовимірною корекційною матрицею:

```
RH_true = A0 + A1 * (C_raw) + A2 * (C_raw)^2 + T_comp * (T_raw - T_ref)
```

Коефіцієнти індивідуального калібрування розраховуються на заводському автоматичному калібрувальному стенді за трьох опорних умов (наприклад: 25 °C / 20% RH, 25 °C / 60% RH, 40 °C / 80% RH) і записуються в енергонезалежну матрицю OTP ROM (One-Time Programmable Memory).

### Структура та контроль цілісності OTP ROM

Пам'ять OTP ROM містить 64 байти даних:
- Байти 0x00–0x0F: Унікальний серійний номер датчика (UID).
- Байти 0x10–0x2F: Калібрувальні коефіцієнти крутизни та зміщення для каналів RH і T.
- Байти 0x30–0x3B: Регістри конфігурації АЦП та порогові константи.
- Байт 0x3F: Контрольна сума CRC-8 калібрувального блоку.

Під час подачі живлення або при виконанні команди ініціалізації (0xBE) внутрішній контролер зчитує всю матрицю OTP, перевіряє її цілісність за контрольною сумою і, якщо помилок немає, виставляє прапорець `CAL_EN = 1` (біт 3 статусного регістра). Якщо пам'ять пошкоджено або не ініціалізовано, біт залишається рівним 0, а результати вимірювань вважаються недостовірними.

## 4. Промисловий низькорівневий I2C-драйвер на C з підтримкою DMA, CRC-8 та неблокуючої машини станів

У промислових системах керування неприпустимо використовувати затримки `HAL_Delay(80)` для очікування завершення оцифрування AHT20. Нижче наведено високонадійний неблокуючий драйвер на мові C, спроектований для роботи під керуванням FreeRTOS або у суперциклі з неблокуючими таймерами.

```c
#include <stdint.h>
#include <stdbool.h>
#include <string.h>

#define AHT20_I2C_ADDR_7BIT       0x38
#define AHT20_CMD_INIT            0xBE
#define AHT20_CMD_TRIGGER         0xAC
#define AHT20_STATUS_BUSY_BIT     (1 << 7)
#define AHT20_STATUS_CAL_BIT      (1 << 3)
#define AHT20_CONVERSION_TIME_MS  85

typedef enum {
    AHT20_STATE_UNINITIALIZED = 0,
    AHT20_STATE_IDLE,
    AHT20_STATE_MEASURING,
    AHT20_STATE_DATA_READY,
    AHT20_STATE_ERROR
} aht20_fsm_state_t;

typedef struct {
    float humidity_rh;
    float temperature_c;
    bool is_valid;
} aht20_result_t;

typedef struct {
    aht20_fsm_state_t state;
    uint32_t timestamp_start_ms;
    uint8_t rx_buffer[7];
    aht20_result_t latest_data;
} aht20_driver_t;

/**
 * @brief Розрахунок CRC-8 за поліномом x^8 + x^5 + x^4 + 1 (0x31), ініціалізація 0xFF
 */
uint8_t aht20_calc_crc8(const uint8_t *data, size_t length) {
    uint8_t crc = 0xFF;
    for (size_t i = 0; i < length; ++i) {
        crc ^= data[i];
        for (uint8_t bit = 8; bit > 0; --bit) {
            if (crc & 0x80) {
                crc = (crc << 1) ^ 0x31;
            } else {
                crc = (crc << 1);
            }
        }
    }
    return crc;
}

/* Зовнішні абстрактні функції I2C платформи (HAL / CMSIS) */
extern bool platform_i2c_write(uint8_t addr_7bit, const uint8_t *buf, uint16_t len);
extern bool platform_i2c_read(uint8_t addr_7bit, uint8_t *buf, uint16_t len);
extern uint32_t platform_get_tick_ms(void);

/**
 * @brief Неблокуючий запуск перетворення
 */
bool aht20_start_measurement(aht20_driver_t *dev) {
    if (dev->state == AHT20_STATE_MEASURING) {
        return false; /* Вже виконується вимірювання */
    }

    uint8_t cmd[3] = {AHT20_CMD_TRIGGER, 0x33, 0x00};
    if (!platform_i2c_write(AHT20_I2C_ADDR_7BIT, cmd, 3)) {
        dev->state = AHT20_STATE_ERROR;
        return false;
    }

    dev->timestamp_start_ms = platform_get_tick_ms();
    dev->state = AHT20_STATE_MEASURING;
    return true;
}

/**
 * @brief Опитування кінцевого автомата станів AHT20 (викликається в циклі/задачі)
 */
void aht20_poll_process(aht20_driver_t *dev) {
    if (dev->state != AHT20_STATE_MEASURING) {
        return;
    }

    /* Перевіряємо, чи минув необхідний час оцифрування (85 мс) */
    uint32_t current_time = platform_get_tick_ms();
    if ((current_time - dev->timestamp_start_ms) < AHT20_CONVERSION_TIME_MS) {
        return; /* Очікуємо завершення без блокування потоку */
    }

    /* Зчитуємо 7 байтів фрейму даних */
    if (!platform_i2c_read(AHT20_I2C_ADDR_7BIT, dev->rx_buffer, 7)) {
        dev->state = AHT20_STATE_ERROR;
        return;
    }

    /* Перевірка прапорця зайнятості BUSY (біт 7) */
    if (dev->rx_buffer[0] & AHT20_STATUS_BUSY_BIT) {
        /* Якщо сенсор все ще зайнятий, даємо додаткові 5 мс */
        return;
    }

    /* Валідація контрольної суми CRC-8 (перші 6 байтів порівнюються з 7-м) */
    uint8_t expected_crc = aht20_calc_crc8(dev->rx_buffer, 6);
    if (expected_crc != dev->rx_buffer[6]) {
        dev->latest_data.is_valid = false;
        dev->state = AHT20_STATE_ERROR;
        return;
    }

    /* Розпакування 20-бітних слів вологості та температури */
    uint32_t raw_humidity = ((uint32_t)dev->rx_buffer[1] << 12) |
                            ((uint32_t)dev->rx_buffer[2] << 4)  |
                            ((uint32_t)dev->rx_buffer[3] >> 4);

    uint32_t raw_temperature = (((uint32_t)dev->rx_buffer[3] & 0x0F) << 16) |
                               ((uint32_t)dev->rx_buffer[4] << 8)  |
                               ((uint32_t)dev->rx_buffer[5]);

    /* Обчислення фізичних значень */
    dev->latest_data.humidity_rh = ((float)raw_humidity / 1048576.0f) * 100.0f;
    dev->latest_data.temperature_c = (((float)raw_temperature / 1048576.0f) * 200.0f) - 50.0f;
    dev->latest_data.is_valid = true;

    dev->state = AHT20_STATE_DATA_READY;
}
```

## 5. Надійність, старіння датчика, аналіз умов конденсації та технологічні протоколи дегазації

В умовах промислової експлуатації та автоматизації мікроклімату датчик AHT20 зазнає деградаційних впливів навколишнього середовища.

### Протокол дегазації після монтажу оплавленням (Reflow De-gassing)

Під час проходження через паяльну піч за температури +240...+260 °C термостійкий полімерний діелектрик сенсора зазнає теплового стресу, а пари летких речовин паяльного флюсу (каніфольні кислоти, активовані галогеніди) адсорбуються на поверхні нанопор золотого електрода. Це призводить до тимчасового зміщення калібрувальної кривої на +3..+6% RH.

Для повного відновлення точності датчика після пайки виробник ASAIR вимагає проведення технологічної процедури дегазації та нормалізації:
1. **Витримка в сухому теплі (Baking):** Плати поміщають у сушильну термошафу з температурою **+50...+60 °C** та низькою вологістю (< 20% RH) на час **6–12 годин**. Це видаляє залишки розчинників та флюсу.
2. **Природна регідратація:** Витримка плат при кімнатній температурі (+20...+30 °C) та вологості 50–70% RH протягом 24 годин перед фінальним вихідним калібруванням або пакуванням виробу.

### Метрологічний дрейф у хімічно агресивних середовищах

| Агресивний фактор | Механізм деградації | Швидкість дрейфу | Спосіб захисту |
| :--- | :--- | :--- | :--- |
| **Пари діоксиду сірки (SO2) та оксидів азоту (NOx)** | Кислотне травлення пористого золотого електрода | До 2–3% RH / місяць | Захисний ковпачок з пористого фторопласту ePTFE |
| **Пари аміаку (NH3, тваринницькі ферми)** | Лужна взаємодія з поліімідним діелектриком | До 5% RH / місяць | Періодичний термічний відпал (Baking при 80 °C) |
| **Конденсація вологи з солями** | Замикання мікроштирьових електродів сольовим електролітом | Миттєве блокування на 100% RH | Монтаж датчика отвором донизу, підігрів зони плати |

### Розрахунок точки роси (Dew Point)

Для запобігання конденсації на чутливому елементі мікроконтролер повинен розраховувати температуру точки роси за наближенням Магнуса:

```
gamma(T, RH) = (17.27 * T) / (237.7 + T) + ln(RH / 100.0)
T_dew = (237.7 * gamma(T, RH)) / (17.27 - gamma(T, RH))
```

Якщо різниця між поточною температурою сенсора та розрахованою точкою роси стає меншою за 1.5–2.0 °C (`T - T_dew < 2.0 °C`), система автоматики повинна завчасно активувати локальний підігрів вентиляційного каналу або тимчасово знизити подачу пари зволожувача для захисту MEMS-елемента від небезпечної плівкової конденсації.
