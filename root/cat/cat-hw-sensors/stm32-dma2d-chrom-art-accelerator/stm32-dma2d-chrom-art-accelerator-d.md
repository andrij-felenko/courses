# Поглиблений аналіз регістрової моделі DMA2D, альфа-композиції та драйвера

Графічний 2D-прискорювач DMA2D Chrom-ART є ключовим інструментом побудови швидкісного інтерфейсу у вбудованих системах. Завдяки наявності апаратних блоків перетворення форматів (PFC) та попіксельних обчислень альфа-змішування він здатен на льоту комбінувати потік живого відео з камери DCMI, фоновий інтерфейс користувача та напівпрозорі елементи телеметрії без жодного такту затримки процесорного ядра.

У цьому розділі наведено поглиблений розбір регістрової структури DMA2D, математику альфа-режимів конвеєрів та виробничий асинхронний драйвер на мові C для FreeRTOS.

---

## 1. Регістрова модель контролера DMA2D Chrom-ART

Керування прискорювачем здійснюється через регістровий блок `DMA2D_TypeDef`:

```text
+-------------------+--------------------------------------------------------------------------+
| Регістр           | Призначення та ключові бітові поля                                       |
+-------------------+--------------------------------------------------------------------------+
| DMA2D_CR          | Control Register:                                                        |
|                   | - [17:16] MODE[1:0]: 00 = M2M, 01 = M2M+PFC, 10 = M2M+Blend, 11 = R2M   |
|                   | - [9] TCIE: Дозвіл переривання завершення передачі Transfer Complete     |
|                   | - [8] TEIE: Дозвіл переривання помилки передачі Transfer Error           |
|                   | - [1] SUSP: Призупинення передачі (Suspend)                              |
|                   | - [0] START: Запуск графічної операції (1 = Start, автоскид в 0)         |
+-------------------+--------------------------------------------------------------------------+
| DMA2D_ISR / IFCR  | Interrupt Status & Flag Clear Registers (Статус та скидання прапорців):  |
|                   | - [1] TCIF: Прапорець завершення перенесення прямокутника (Transfer Done)|
|                   | - [0] TEIF: Прапорець помилки доступу до шини                            |
+-------------------+--------------------------------------------------------------------------+
| DMA2D_FGMAR /     | Foreground & Background Memory Address Registers:                        |
| DMA2D_BGMAR       | 32-бітні фізичні адреси початкових точок шарів у пам'яті SRAM/SDRAM      |
+-------------------+--------------------------------------------------------------------------+
| DMA2D_FGOR /      | Foreground & Background Line Offset Registers:                           |
| DMA2D_BGOR        | [13:0] Кількість пікселів для пропуску в кінці рядка: W_canvas - W_rect  |
+-------------------+--------------------------------------------------------------------------+
| DMA2D_FGPFCR /    | Foreground & Background Pixel Format Configuration:                      |
| DMA2D_BGPFCR      | - [23:16] ALPHA[7:0]: Константне значення альфа (0..255)                 |
|                   | - [17:16] AM[1:0]: Режим альфа: 00 = Pixel, 01 = Replace, 10 = Combine   |
|                   | - [3:0] CM[3:0]: Формат пікселя: 0000 = ARGB8888, 0001 = RGB888,         |
|                   |                  0010 = RGB565, 0101 = L8, 1000 = A8, 1010 = AL88        |
+-------------------+--------------------------------------------------------------------------+
| DMA2D_OMAR        | Output Memory Address Register: фізична адреса буфера призначення        |
+-------------------+--------------------------------------------------------------------------+
| DMA2D_OOR         | Output Offset Register: [13:0] зміщення рядка приймача: W_canvas - W_rect|
+-------------------+--------------------------------------------------------------------------+
| DMA2D_OPFCR       | Output Pixel Format Configuration: [2:0] вихідний формат пікселів        |
+-------------------+--------------------------------------------------------------------------+
| DMA2D_OCOLR       | Output Color Register: 32-бітний колір для режиму заливки R2M            |
+-------------------+--------------------------------------------------------------------------+
| DMA2D_NLR         | Number of Line Register:                                                 |
|                   | - [31:16] PL[15:0]: Ширина прямокутника (кількість пікселів у рядку)     |
|                   | - [15:0]  NL[15:0]: Висота прямокутника (кількість рядків)               |
+-------------------+--------------------------------------------------------------------------+
```

## 2. Математика апаратного альфа-змішування та режими AM[1:0]

Блок альфа-змішування виконує апаратну нормалізацію кольорів відповідно до режиму поля `AM[1:0]` у регістрі `FGPFCR`:

1. **Режим `AM = 00` (Pixel Alpha):**
   - Використовується власний альфа-канал кожного пікселя вхідного зображення (наприклад, старші 8 біт у форматі ARGB8888).
   - Ефективне значення: `Alpha_eff = Alpha_pixel`.
2. **Режим `AM = 01` (Replace Alpha):**
   - Власний альфа-канал пікселя повністю ігнорується і замінюється значенням константи `ALPHA[7:0]` із регістра.
   - Ефективне значення: `Alpha_eff = ALPHA_const`. Дозволяє зробити будь-яку глуху картинку RGB565 напівпрозорою за один запис регістра.
3. **Режим `AM = 10` (Combinatorial Alpha):**
   - Власний альфа-канал пікселя перемножується з константою:
   ```text
   Alpha_eff = (Alpha_pixel * ALPHA_const) / 255
   ```
   Дозволяє створити ефект поступового згасання (Fade-Out) для вже напівпрозорого інтерфейсу.

### Формула попіксельного обчислення результуючого кольору:

Для кожного з колірних каналів (Червоний R, Зелений G, Синій B):
```text
C_out = (C_fg * Alpha_eff + C_bg * (255 - Alpha_eff)) / 255
```

Апаратний конвеєр виконує це цілочисельне множення та поділ на 255 паралельно для всіх трьох каналів усього за **1 машинний такт**.

## 3. Виробничий асинхронний драйвер DMA2D для FreeRTOS на мові C

Нижче наведено виробничу реалізацію модуля неблокуючого копіювання кадру камери з вхідного буфера в активний буфер відображення з використанням бінарного семафора FreeRTOS:

```c
#include "stm32f4xx.h"
#include <stdint.h>
#include <stdbool.h>

/* Інтеграція з операційною системою реального часу FreeRTOS */
#include "FreeRTOS.h"
#include "semphr.h"

static SemaphoreHandle_t g_dma2d_sem = NULL;

/**
 * @brief Ініціалізація апаратного модуля DMA2D та семафора синхронізації
 */
void dma2d_init(void) {
    /* 1. Увімкнення тактування DMA2D */
    RCC->AHB1ENR |= RCC_AHB1ENR_DMA2DEN;

    /* 2. Створення бінарного семафора */
    if (g_dma2d_sem == NULL) {
        g_dma2d_sem = xSemaphoreCreateBinary();
    }

    /* 3. Налаштування пріоритету та увімкнення переривання в NVIC */
    NVIC_SetPriority(DMA2D_IRQn, 5);
    NVIC_EnableIRQ(DMA2D_IRQn);
}

/**
 * @brief Асинхронне копіювання кадру камери у вікно дисплея з конвертацією формату
 * @param src_addr Адреса вхідного кадру камери (наприклад, SRAM1)
 * @param dst_addr Базова адреса фреймбуфера екрана в SDRAM
 * @param x, y Координати розміщення вікна камери на екрані
 * @param width, height Розміри кадру камери (наприклад, 320x240)
 * @param canvas_width Повна ширина дисплея (наприклад, 800)
 * @return true у разі успішного завершення
 */
bool dma2d_blit_camera_frame_async(uint32_t src_addr, uint32_t dst_addr,
                                   uint16_t x, uint16_t y,
                                   uint16_t width, uint16_t height,
                                   uint16_t canvas_width) {
    /* Розрахунок початкової точки у фреймбуфері призначення (RGB565 = 2 байти) */
    uint32_t dst_start = dst_addr + ((y * canvas_width + x) * 2);

    /* Очікування завершення попередньої передачі, якщо модуль зайнятий */
    while (DMA2D->CR & DMA2D_CR_START);

    /* 1. Режим Memory-to-Memory (M2M: 00) */
    DMA2D->CR = (0 << DMA2D_CR_MODE_Pos) | DMA2D_CR_TCIE;

    /* 2. Конфігурація переднього плану (Foreground):
     * CM = 0010 (RGB565) */
    DMA2D->FGMAR = src_addr;
    DMA2D->FGOR  = 0; /* Неперервний буфер камери не має зміщення рядка */
    DMA2D->FGPFCR = 0x02;

    /* 3. Конфігурація вихідного буфера (Output):
     * Вихідний зсув OOR = W_canvas - W_rect (800 - 320 = 480) */
    DMA2D->OMAR  = dst_start;
    DMA2D->OOR   = canvas_width - width;
    DMA2D->OPFCR = 0x02; /* RGB565 */

    /* 4. Розміри області копіювання: пікселі та лінії */
    DMA2D->NLR = (width << DMA2D_NLR_PL_Pos) | (height << DMA2D_NLR_NL_Pos);

    /* 5. Запуск апаратного трансферу */
    DMA2D->CR |= DMA2D_CR_START;

    /* 6. Блокування поточної задачі FreeRTOS в очікуванні семафора від переривання
     * (Процесор повністю вільний для виконання інших системних задач!) */
    if (xSemaphoreTake(g_dma2d_sem, pdMS_TO_TICKS(50)) == pdTRUE) {
        return true;
    } else {
        /* Таймаут передачі (аварія шини або зависання SDRAM) */
        DMA2D->CR |= DMA2D_CR_ABORT;
        return false;
    }
}

/**
 * @brief Апаратний обробник переривання завершення передачі DMA2D
 */
void DMA2D_IRQHandler(void) {
    BaseType_t xHigherPriorityTaskWoken = pdFALSE;

    /* Перевірка прапорця Transfer Complete (TCIF) */
    if (DMA2D->ISR & DMA2D_ISR_TCIF) {
        /* Апаратне очищення прапорця */
        DMA2D->IFCR = DMA_IFCR_CTCIF;

        /* Розблокування задачі FreeRTOS */
        if (g_dma2d_sem != NULL) {
            xSemaphoreGiveFromISR(g_dma2d_sem, &xHigherPriorityTaskWoken);
            portYIELD_FROM_ISR(xHigherPriorityTaskWoken);
        }
    }

    /* Обробка апаратних помилок доступу до шини (TEIF) */
    if (DMA2D->ISR & DMA2D_ISR_TEIF) {
        DMA2D->IFCR = DMA_IFCR_CTEIF;
    }
}
```

## 4. Контрольний чек-лист діагностики помилок DMA2D

1. **Помилка конфігурації (Прапорець CEIF — Configuration Error Interrupt Flag):**
   - *Причина:* Спроба запуску передачі в режимі альфа-змішування (`MODE = 10`), коли один із шарів налаштований у несумісний формат (наприклад, прямий вивід у формат YUV або відсутність палітри для CLUT).
   - *Виправлення:* Перевірте відповідність форматів у регістрах `FGPFCR`, `BGPFCR` та `OPFCR`.
2. **Артефакт накладання: зміщення рядків по діагоналі (Skewing):**
   - *Причина:* Неправильний розрахунок вихідного зміщення `DMA2D_OOR`. Пам'ятайте, що `OOR` вимірюється в **кількості пікселів, а не байтів**!
3. **Зависання шини на прапорці START:**
   - *Причина:* Адреса `OMAR` вказує на неініціалізований банк зовнішньої пам'яті SDRAM (`0xC0000000`), тактування якого ще не активовано в контролері FMC.
