# Поглиблений аналіз та математичне моделювання приводів Auto-Iris

Електромеханічний вузол діафрагми об'єктива є динамічною коливальною системою другого порядку з нелінійним оптичним коефіцієнтом передачі. Для створення стійкого та швидкодіючого контуру керування в промислових камерах машинного зору інженер повинен володіти математичним описом електромеханіки гальванометра, оптичними обмеженнями роздільної здатності та алгоритмами цифрового координування тріади експозиції: діафрагми, електронного затвора та підсилення сенсора.

---

## 1. Електромеханічна модель гальванометричного приводу DC-Iris

Механізм DC-Iris складається з легкого постійного магніту на осі обертання та двох нерухомих обмоток: обмотки збудження (Drive Coil) та обмотки демпфування (Damping Coil).

### Диференційні рівняння механічного руху

Обертальний рух ротора описується рівнянням Ньютона для кутових переміщень:

```text
J * (d^2 theta / dt^2) + B * (d theta / dt) + K_s * theta = T_m(t)
де:
  J — момент інерції рухомого ротора та пелюсток діафрагми (типово 1.2e-7 .. 3.5e-7 кг*м^2),
  B — коефіцієнт в'язкого механічного тертя повітря та шарнірів,
  K_s — коефіцієнт жорсткості поворотної пружини (Н*м/рад),
  theta(t) — кут повороту ротора діафрагми (рад),
  T_m(t) — електромагнітний обертовий момент (Н*м).
```

Електромагнітний момент формується струмом обмотки приводу:
```text
T_m(t) = K_t * I_drive(t)
де K_t — коефіцієнт електромеханічного перетворення моменту (Н*м/А).
```

### Електричні кола обмоток

Електричний контур обмотки приводу описується рівнянням Кірхгофа:
```text
V_in(t) = L_drive * (d I_drive / dt) + R_drive * I_drive(t) + V_back_emf(t)
де:
  V_back_emf(t) = K_e * (d theta / dt) — проти-ЕРС індукції обмотки приводу,
  R_drive ≈ 190 Ом, L_drive ≈ 10..25 мГн.
```

В обмотці демпфування (Damp Coil) стороннє джерело струму відсутнє; напруга на її клемах виникає виключно завдяки зміні магнітного потоку під час руху ротора:
```text
V_damp(t) = K_damp * (d theta / dt)
де K_damp — коефіцієнт демпфуючої ЕРС (В*с/рад), R_damp ≈ 1150 Ом.
```

### Передавальна функція системи без демпфування

Якщо знехтувати малою індуктивністю `L_drive` на низьких частотах механічного руху (< 30 Гц), струм прямо пропорційний напрузі: `I_drive ≈ V_in / R_drive`. Підставивши це в механічне рівняння, отримуємо передавальну функцію:

```text
G(s) = Theta(s) / V_in(s) = (K_t / R_drive) / (J * s^2 + (B + K_t * K_e / R_drive) * s + K_s)
```

Власна частота механічного резонансу системи:
```text
omega_0 = sqrt(K_s / J)  ≈  2 * pi * (8 .. 15) рад/с  (тобто 8..15 Гц)
```

Коефіцієнт демпфування без увімкнення котушки гальмування складає `zeta < 0.2`, що зумовлює сильний резонансний сплеск (+14 дБ) та тривалі автоколивання пелюсток (ringing) у відповідь на будь-яку сходинку напруги керування.

### Вплив замкненого кола котушки демпфування

Коли клеми `Damp +` та `Damp -` замикаються через зовнішній резистор або навантажуються на диференційний підсилювач, струм демпфування створює додатковий момент опору:
```text
T_damp = - (K_damp^2 / (R_damp + R_ext)) * (d theta / dt)
```

Це штучно збільшує ефективний коефіцієнт в'язкого тертя `B_eff = B + B_magnetic`, піднімаючи коефіцієнт демпфування до оптимального значення `zeta = 0.707 .. 0.85`, завдяки чому перехідний процес стає аперіодичним, а час встановлення скорочується до 180 мс.

## 2. Критерії дифракційного ліміту та криві різкості MTF

Функція передачі модуляції (Modulation Transfer Function, MTF) описує контрастність передачі просторових гармонік лінзою об'єктива залежно від просторової частоти (лінійних пар на міліметр, lp/mm).

При зміні діафрагмового числа F-number два фізичні явища конкурують між собою:
1. **Геометричні аберації (сферична аберація, кома, астигматизм):** домінують на широких отворах (F/1.4 .. F/2.0). Промені світла, що проходять крізь крайні ділянки лінзи, фокусуються не в одній точці площини сенсора. Зі зменшенням отвору аберації різко спадають пропорційно `1 / F_number^2`.
2. **Хвильова дифракція на круглому краї діафрагми:** домінує на малих отворах (F/8 .. F/22). Відповідно до дифракційного критерію Релея, зображення нескінченно віддаленої точки перетворюється на центральний диск Ейрі, радіус якого до першого дифракційного мінімуму дорівнює:

```text
r_airy = 1.22 * lambda * F_number
де lambda — довжина хвилі світла (550 нм = 0.55 мкм для зеленого каналу).
```

```text
F-number  |  Радіус диска Ейрі (r_airy)  |  Діаметр плями Ейрі  |  Ліміт дифракції сенсора
----------+------------------------------+----------------------+---------------------------
F/1.4     |  0.93 мкм                    |  1.87 мкм            |  Вище більшості пікселів
F/2.8     |  1.88 мкм                    |  3.75 мкм            |  Ідеально для пікселів 2.5 мкм
F/4.0     |  2.68 мкм                    |  5.37 мкм            |  Оптимальний баланс MTF
F/5.6     |  3.76 мкм                    |  7.52 мкм            |  Пік різкості на краях
F/8.0     |  5.37 мкм                    |  10.74 мкм           |  Початок втрати мікроконтрасту
F/16.0    |  10.74 мкм                   |  21.47 мкм           |  Критичне падіння різкості (мило)
```

> **Правило дифракційного ліміту (Diffraction Limit):** Якщо діаметр плями Ейрі `2 * r_airy` перевищує подвоєний розмір пікселя сенсора `2 * Pitch_pixel`, роздільна здатність оптичної системи більше не обмежується мегапіксельністю камери, а повністю диктується хвильовою дифракцією діафрагми. Для сучасних сенсорів із пікселем 1.85–2.9 мкм будь-яке закриття діафрагми понад F/5.6 є критично шкідливим для чіткості.

## 3. Таблиці калібрування крокового приводу P-Iris

На відміну від DC-Iris, прецизійний об'єктив P-Iris керується мініатюрним кроковим біполярним двигуном через черв'ячну передачу або важільний механізм. Повний хід пелюсток від положення «повністю закрито» до «максимально відкрито» розділений на N кроків (зазвичай 80..120 кроків).

Зв'язок між номером кроку та еквівалентним F-числом має виражений нелінійний характер через геометрію перекриття серповидних пелюсток. Тому виробник об'єктива (наприклад, Kowa, Theia, Computar) постачає фабричну таблицю калібрування, яка прошивається у пам'ять камери:

```text
Крок (Step)  |  Діафрагма (F-stop)  |  Площа отвору (мм^2)  |  Відносний потік світла
-------------+----------------------+-----------------------+------------------------
0 (Home)     |  Закрито (Closed)    |  0.0                  |  0.00 %
15           |  F/16.0              |  0.8                  |  0.78 %
32           |  F/8.0               |  3.1                  |  3.12 %
48           |  F/5.6 (Sweet Spot)  |  6.3                  |  6.25 %
65           |  F/4.0 (Sweet Spot)  |  12.5                 |  12.50 %
82           |  F/2.8 (Sweet Spot)  |  25.0                 |  25.00 %
100          |  F/2.0               |  50.0                 |  50.00 %
118 (Max)    |  F/1.4               |  100.0                |  100.00 %
```

Під час старту камери виконується обов'язкова ініціалізація (Homing): кроковий двигун крокує у бік закриття на 130 кроків (з гарантованим упором у механічний демпфер), після чого лічильник позиції обнуляється (`Step = 0`).

## 4. Архітектура комбінованого регулятора експозиції на C++

Нижче наведено промисловий модуль керування експозицією машинного зору, який оптимізує різкість зображення шляхом утримання P-Iris у зоні F/2.8 .. F/5.6, керуючи в першу чергу витримкою електронного затвора.

```cpp
#include <cstdint>
#include <algorithm>

/**
 * @brief Дескриптор калібрувальної точки F-числа P-Iris
 */
struct PIrisStep {
    uint8_t step_index;
    float f_number;
    float relative_light;
};

/* Таблиця калібрування об'єктива P-Iris (приклад 8-крокової інтерполяції) */
static const PIrisStep P_IRIS_CALIBRATION_TABLE[] = {
    {  0, 16.0f, 0.008f },
    { 18, 11.0f, 0.016f },
    { 36,  8.0f, 0.031f },
    { 54,  5.6f, 0.063f }, /* Верхня межа Sweet Spot */
    { 72,  4.0f, 0.125f }, /* Центр Sweet Spot */
    { 90,  2.8f, 0.250f }, /* Нижня межа Sweet Spot */
    { 105, 2.0f, 0.500f },
    { 120, 1.4f, 1.000f }
};
static constexpr size_t CALIB_TABLE_SIZE = sizeof(P_IRIS_CALIBRATION_TABLE) / sizeof(PIrisStep);

class ExposureController {
public:
    struct HardwareLimits {
        float min_exposure_us;
        float max_exposure_us;
        float min_gain_db;
        float max_gain_db;
        uint8_t min_iris_step;
        uint8_t max_iris_step;
        uint8_t sweet_spot_min_step; /* крок F/5.6 */
        uint8_t sweet_spot_max_step; /* крок F/2.8 */
    };

    struct CameraState {
        float current_exposure_us;
        float current_gain_db;
        uint8_t current_iris_step;
    };

    ExposureController(const HardwareLimits& limits) 
        : limits_(limits), state_{10000.0f, 0.0f, 72} {}

    /**
     * @brief Оновлення контуру автоекспозиції на основі поточної яскравості сцени
     * @param luma_error Помилка яскравості: Target_Luma - Current_Luma (-128.0 .. +128.0)
     */
    void update(float luma_error) {
        if (std::abs(luma_error) < 2.0f) {
            return; /* Зона нечутливості (Deadband) для запобігання дрижанню */
        }

        /* 1. Сцена надто темна (luma_error > 0): потрібно додати світла */
        if (luma_error > 0.0f) {
            // Спочатку відкриваємо діафрагму до центру Sweet Spot (F/4.0 -> F/2.8)
            if (state_.current_iris_step < limits_.sweet_spot_max_step) {
                state_.current_iris_step = std::min(static_cast<uint8_t>(state_.current_iris_step + 2),
                                                    limits_.sweet_spot_max_step);
                return;
            }

            // Далі нарощуємо час експозиції (Shutter)
            if (state_.current_exposure_us < limits_.max_exposure_us) {
                state_.current_exposure_us = std::min(state_.current_exposure_us * 1.15f,
                                                      limits_.max_exposure_us);
                return;
            }

            // Якщо витримка досягла ліміту частоти кадрів (наприклад, 33 мс для 30 fps), відкриваємо діафрагму на максимум
            if (state_.current_iris_step < limits_.max_iris_step) {
                state_.current_iris_step = std::min(static_cast<uint8_t>(state_.current_iris_step + 4),
                                                    limits_.max_iris_step);
                return;
            }

            // В останню чергу піднімаємо аналогове підсилення матриці (AGC Gain)
            if (state_.current_gain_db < limits_.max_gain_db) {
                state_.current_gain_db = std::min(state_.current_gain_db + 0.5f,
                                                  limits_.max_gain_db);
            }
        } 
        /* 2. Сцена надто яскрава (luma_error < 0): потрібно зменшити потік світла */
        else {
            // В першу чергу скидаємо шумне підсилення Gain до 0 дБ
            if (state_.current_gain_db > limits_.min_gain_db) {
                state_.current_gain_db = std::max(state_.current_gain_db - 1.0f,
                                                  limits_.min_gain_db);
                return;
            }

            // Якщо діафрагма ширша за Sweet Spot, прикриваємо її до F/4.0 .. F/5.6
            if (state_.current_iris_step > limits_.sweet_spot_min_step) {
                state_.current_iris_step = std::max(static_cast<uint8_t>(state_.current_iris_step - 2),
                                                    limits_.sweet_spot_min_step);
                return;
            }

            // Скорочуємо час витримки затвора (до 1/10000 с або 100 мкс)
            if (state_.current_exposure_us > limits_.min_exposure_us) {
                state_.current_exposure_us = std::max(state_.current_exposure_us * 0.85f,
                                                      limits_.min_exposure_us);
                return;
            }

            // Лише якщо експозиція вже мінімальна, закриваємо P-Iris у зону дифракції (F/8..F/16)
            if (state_.current_iris_step > limits_.min_iris_step) {
                state_.current_iris_step = std::max(static_cast<uint8_t>(state_.current_iris_step - 2),
                                                    limits_.min_iris_step);
            }
        }
    }

    const CameraState& getState() const { return state_; }

private:
    HardwareLimits limits_;
    CameraState state_;
};
```

## 5. Діагностика несправностей та польовий чек-лист

1. **Ефект «полювання» діафрагми (Hunting / Pumping):**
   - Пелюстки безперервно відкриваються і закриваються з періодом 0.5–2 секунди.
   - *Причина:* Занадто високий коефіцієнт пропорційного підсилення Kp у цифровому ПІД-регуляторі або обрив котушки демпфування Damping Coil (перевірити мультиметром опір 1150 Ом на контактах 1-2 роз'єму EIAJ).
2. **Акустичний писк об'єктива DC-Iris:**
   - *Причина:* Низька частота ШІМ приводу Drive Coil (< 16 кГц).
   - *Вирішення:* Підвищити частоту таймера ШІМ мікроконтролера до 24–40 кГц та додати низькочастотний RC-фільтр (100 Ом + 10 мкФ) перед котушкою.
3. **Заклинювання пелюсток на морозі:**
   - *Причина:* Загусання змазки механізму пелюсток або ослаблення пружини за від'ємних температур (-20 °C і нижче).
   - *Діагностика:* Перевірка струму споживання котушки приводу під час повної подачі напруги (повинен складати `4 В / 190 Ом ≈ 21 мА`).
