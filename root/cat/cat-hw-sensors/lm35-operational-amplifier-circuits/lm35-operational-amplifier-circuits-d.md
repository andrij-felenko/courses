# Поглиблений інженерний аналіз та розрахунок схем на операційних підсилювачах для LM35

Використання операційних підсилювачів у прецизійних вимірювальних трактах з датчиком температури LM35 вимагає ретельного аналізу теорії зворотного зв'язку, стабільності контурів, частотних властивостей і бюджету похибок. У реальних умовах неідеальність компонентів (напруга зміщення, струми витоку, температурний дрейф, кінцевий коефіцієнт підсилення з відкритим контуром) може звести нанівець заводську точність сенсора (+/-0.5 °C).

У цьому детальному посібнику розглядаються розрахунки неінвертуючих та диференційних каскадів, параметричний синтез активних фільтрів Баттерворта, проектування передавачів 4–20 мА з діагностикою аварій, а також схемотехніка прецизійних компараторів для промислових систем термостатування.

## 1. Математичний аналіз та розрахунок неінвертуючого підсилювача: похибки зміщення та аналіз стабільності

Неінвертуючий підсилювач є базовим каскадом для узгодження шкали LM35 (10 мВ/°C) з динамічним діапазоном АЦП. Для забезпечення точності тракту краще 0.1 °C необхідно враховувати неідеальності операційного підсилювача.

### Передатна функція та вплив кінцевого коефіцієнта підсилення A_ol

Ідеальний коефіцієнт підсилення із закритим контуром визначається як:

```
G_ideal = 1 + (R2 / R1)
```

З урахуванням кінцевого коефіцієнта підсилення ОП з відкритим контуром A_ol та коефіцієнта зворотного зв'язку beta = R1 / (R1 + R2) = 1 / G_ideal реальний коефіцієнт передачі становить:

```
G_real = G_ideal / (1 + 1 / (A_ol * beta)) = G_ideal / (1 + G_ideal / A_ol)
```

Відносна похибка коефіцієнта підсилення через кінцеве значення A_ol виражається формулою:

```
epsilon_gain = -G_ideal / (A_ol + G_ideal) ≈ -G_ideal / A_ol
```

Для типового ОП загального призначення (наприклад, LM358 з A_ol ≈ 100 дБ = 100 000) при G = 3.3 відносна похибка становить лише 0.0033%, що є допустимим. Проте на частотах завад коефіцієнт A_ol падає з частотою зрізу 10–100 Гц зі швидкістю -20 дБ/декаду, тому для збереження точності слід обирати ОП зі смугою пропускання GBP (Gain Bandwidth Product) не менше 1 МГц.

### Бюджет статичних похибок (Error Budget)

Загальна вихідна напруга підсилювача з урахуванням напруги зміщення V_os, вхідних струмів зміщення I_b+, I_b- та температурного дрейфу описується виразом:

```
V_out = (V_lm35 + V_os + I_b+ * R_source) * (1 + R2 / R1) - I_b- * R2
```

Для мінімізації похибки від вхідних струмів вибирають еквівалентні опори входів:

```
R_eq = R_source = (R1 * R2) / (R1 + R2)
```

Тоді вплив струмів зміщення зводиться до різницевого струму I_os = |I_b+ - I_b-|:

```
Delta_V_out_Ios = I_os * R2
```

Аналіз внеску компонентів у похибку вимірювання (при R1 = 10 кОм, R2 = 23 кОм, G = 3.3):

| Параметр неідеальності | Значення для LM358 | Значення для MCP6001 | Значення для OPA333 (Zero-Drift) | Еквівалентна похибка T (MCP6001) |
| :--- | :--- | :--- | :--- | :--- |
| **Вхідна напруга зміщення (V_os)** | 3.0 мВ | 1.0 мВ | 10 мкВ | 0.10 °C |
| **Температурний дрейф V_os** | 7.0 мкВ/°C | 2.0 мкВ/°C | 0.05 мкВ/°C | 0.002 °C/°C |
| **Вхідний струм зміщення (I_b)** | 50 нА | 1 пА | 70 пА | Нехтовно мало (< 0.0001 °C) |
| **Допуск резисторів R1, R2** | 1.0% | 0.1% | 0.05% | 0.07 °C |
| **CMRR (придушення синфазного)** | 65 дБ | 75 дБ | 130 дБ | 0.015 °C |

### Аналіз стійкості контуру та компенсація фазового запасу

Вихідний каскад LM35 побудований на емітерному повторювачі NPN-транзистора класу A з малим внутрішнім струмом спокою (близько 50 мкА). При прямому підключенні кабелю чи ємнісного навантаження C_load > 50 пФ вихідний опір сенсора утворює додатковий полюс у петлі зворотного зв'язку, що спричиняє зменшення фазового запасу (Phase Margin) нижче 45° та високочастотну генерацію (100–500 кГц).

Для запобігання автоколиванням застосовують комплексну компенсацію:
1. **Ізолюючий послідовний резистор R_iso:** Встановлюється безпосередньо біля виводу V_out мікросхеми LM35. При R_iso = 1.0 кОм і C1 = 10 нФ створюється локальний фільтр низьких частот:
   ```
   f_iso = 1 / (2 * pi * R_iso * C1) = 1 / (2 * 3.14159 * 1000 Ом * 10e-9 Ф) ≈ 15.9 кГц
   ```
2. **Конденсатор зворотного зв'язку Cf:** Підключається паралельно до резистора зворотного зв'язку R2. Він створює випереджаючий нуль у петлевому підсиленні, додаючи додатковий фазовий зсув +90° на високих частотах:
   ```
   f_zero = 1 / (2 * pi * R2 * Cf)
   ```
   Для R2 = 23 кОм і Cf = 100 пФ:
   ```
   f_zero = 1 / (2 * 3.14159 * 23000 Ом * 100e-12 Ф) ≈ 69.2 кГц
   ```
   Це гарантує фазовий запас контуру підсилювача понад 65°, що повністю виключає перельоти й дзвін на виході при переході вхідного сигналу АЦП.

## 2. Прецизійні топології зсуву рівня для повного біполярного діапазону: інструментальні та сумуючі схеми

При вимірюванні температур від -55 °C до +150 °C розмах вихідної напруги LM35 становить 2.05 В (від -0.55 В до +1.50 В). Завдання аналогового інтерфейсу — перенести цей діапазон у межі 0.0...+3.0 В, сумісні з вхідною напругою однополярного АЦП мікроконтролера.

### Математична модель диференційного суматора

Розглянемо класичний чотирирезисторний диференційний каскад зі зсувом рівня від джерела опорної напруги V_ref. 

Вихідна напруга описується рівнянням суперпозиції:

```
V_adc = V_lm35 * [ (R4 / R3) * ((R1 + R2) / (R3 + R4)) * (R3 / R1) ] + V_ref * [ R2 / (R1 + R2) * (1 + R4 / R3) ]
```

При симетричному виборі плечей R3 = R1 та R4 = R2 формула значно спрощується:

```
V_adc = (R2 / R1) * (V_lm35_plus - V_lm35_minus) + V_ref * (R2 / (R1 + R2)) * (1 + R2 / R1)
```

Якщо неінвертуючий вхід отримує суміш сигналу та опорної напруги зсуву V_shift, рівняння набуває канонічного вигляду масштабування зі зміщенням:

```
V_adc = G * V_lm35 + V_zero
```

Для маппінгу діапазону:
- При T = -55 °C: V_lm35 = -0.55 В -> V_adc = 0.00 В
- При T = +150 °C: V_lm35 = +1.50 В -> V_adc = 3.00 В

Звідси розраховуємо необхідний коефіцієнт підсилення G:

```
Delta_V_adc = 3.00 В - 0.00 В = 3.00 В
Delta_V_lm35 = +1.50 В - (-0.55 В) = 2.05 В
G = Delta_V_adc / Delta_V_lm35 = 3.00 В / 2.05 В ≈ 1.4634
```

Напруга нульового зсуву V_zero (при T = 0 °C, V_lm35 = 0.00 В):

```
V_zero = 0.00 В + G * 0.55 В = 1.4634 * 0.55 В ≈ 0.8049 В
```

### Вплив допуску резисторів на коефіцієнт CMRR

У диференційних схемах зсуву рівня здатність схеми ігнорувати синфазні шуми живлення та заземлення виражається коефіцієнтом CMRR. За найгіршого розкиду резисторів delta_R / R теоретичний коефіцієнт придушення синфазного сигналу становить:

```
CMRR_worst ≈ (1 + G) / (4 * (delta_R / R))
```

Для резисторів з різними класами точності:
- **Звичайні резистори 1.0% (delta = 0.01):** CMRR ≈ 2.46 / 0.04 ≈ 61.5 (лише 35.8 дБ). Похибка перенесення синфазної завади сягає до 1.6%.
- **Прецизійні резистори 0.1% (delta = 0.001):** CMRR ≈ 2.46 / 0.004 ≈ 615 (55.8 дБ). Похибка знижується до 0.16%.
- **Ультрапрецизійні узгоджені матриці 0.01% (наприклад, LT5400):** CMRR > 86 дБ.

Для високоточних систем рекомендовано використовувати спеціалізовані інструментальні підсилювачі з інтегрованими лазерно-підігнаними резисторами (INA333, AD623), у яких CMRR гарантовано перевищує 100 дБ без індивідуального підбору дискретних компонентів.

## 3. Синтез активних фільтрів Саллена-Кея та Баттерворта: частотна характеристика, фазові затримки та придушення шуму

Теплові вимірювання часто стикаються з проблемою електромагнітної сумісності (ЕМС): дроти сенсора сприймають синфазні та диференційні завади від мережі 50 Гц, частотних перетворювачів електроприводів (ШІМ 4–16 кГц) та іскрових розрядів контакторів.

### Передатна функція топології Саллена-Кея

Передатна функція низькочастотної ланки Саллена-Кея з одиничним коефіцієнтом підсилення у комплексній формі Лапласа описується виразом другого порядку:

```
H(s) = 1 / ( s^2 * (R1 * R2 * C1 * C2) + s * (C2 * (R1 + R2)) + 1 )
```

Порівнюючи з канонічною формою ланки другого порядку:

```
H(s) = omega_0^2 / ( s^2 + s * (omega_0 / Q) + omega_0^2 )
```

Отримуємо співвідношення для характеристичної кутової частоти omega_0 та добротності Q:

```
omega_0 = 1 / sqrt(R1 * R2 * C1 * C2)
Q = sqrt(R1 * R2 * C1 * C2) / (C2 * (R1 + R2))
```

Якщо R1 = R2 = R, формула добротності спрощується до:

```
Q = 0.5 * sqrt(C1 / C2)
```

Для фільтра Баттерворта другого порядку вимагається значення добротності Q = 1 / sqrt(2) ≈ 0.7071 (максимально гладка АЧХ без викидів у смузі пропускання). Звідси випливає фундаментальна умова на співвідношення ємностей:

```
0.5 * sqrt(C1 / C2) = 1 / sqrt(2)  =>  sqrt(C1 / C2) = sqrt(2)  =>  C1 = 2 * C2
```

### Розрахунок придушення завади 50 Гц та групового часу затримки

За частоти зрізу фільтра fc = 10.0 Гц коефіцієнт передачі на довільній частоті f розраховується за формулою модуля АЧХ:

```
|H(f)| = 1 / sqrt( 1 + (f / fc)^4 )
```

Розрахунок для ключових гармонік:
- **Мережева частота f = 50 Гц:**
  ```
  |H(50)| = 1 / sqrt( 1 + (50 / 10)^4 ) = 1 / sqrt( 1 + 625 ) = 1 / sqrt(626) ≈ 0.03997 (-27.96 дБ)
  ```
  Амплітуда мережевої завади послаблюється в 25.0 разів.
- **Друга гармоніка випрямляча f = 100 Гц:**
  ```
  |H(100)| = 1 / sqrt( 1 + (100 / 10)^4 ) = 1 / sqrt( 1 + 10000 ) ≈ 0.009999 (-40.0 дБ)
  ```
  Завада послаблюється в 100.0 разів.

Фазовий зсув фільтра phi(f) визначається як:

```
phi(f) = -arctan( (sqrt(2) * (f / fc)) / (1 - (f / fc)^2) )
```

Груповий час затримки (Group Delay) у смузі низьких частот:

```
t_gd(0) = sqrt(2) / (2 * pi * fc) = 1.4142 / (2 * 3.14159 * 10) ≈ 22.5 мс
```

Затримка 22.5 мс є абсолютно невідчутною для теплових систем (де теплова інерція становить секунди), але забезпечує бездоганне аналогове згладжування сигналу перед оцифруванням.

## 4. Проектування промислового перетворювача 4–20 мА: термостабільність, калібрування нуля та шкали

Струмова петля 4–20 мА є промисловим стандартом передачі даних на довгі відстані, де сигнал передається величиною струму, що протікає по лінії.

### 2-провідні та 3-провідні конфігурації

1. **3-провідна схема (підключення з окремим живленням):** Сенсор і перетворювач мають спільний провід заземлення (GND), лінію живлення (+24 В) та лінію сигнального струму. Це найбільш проста й надійна топологія для LM35, оскільки сенсор живиться незалежно від вихідного струму.
2. **2-провідна схема (Loop-Powered):** Вся вимірювальна схема (сенсор, ОП, джерело опорної напруги) живиться безпосередньо від струму петлі. Головне обмеження 2-провідних систем: загальний струм споживання всіх мікросхем вузла у стані спокою повинен бути строго меншим за мінімальний вихідний струм:
   ```
   I_quiescent_total < 3.60 мА (з урахуванням стандарту аварійних станів NAMUR NE 43)
   ```
   Оскільки LM35DZ споживає струм спокою лише 60–130 мкА, а сучасні мікропотужні ОП (наприклад, OPA317 або MAX40007) споживають менше 20–50 мкА, побудова 2-провідного датчика на базі LM35 є повністю реалізованою.

### Розрахунок вимірювального резистора R_sense та транзисторного ключа

Струм у петлі I_loop формується через падіння напруги на прецизійному резисторі R_sense:

```
I_loop = V_in_plus / R_sense
```

При виборі R_sense = 25.0 Ом:
- Для формування струму 4.00 мА керуюча напруга повинна дорівнювати:
  ```
  V_sense(4мА) = 4.00 мА * 25.0 Ом = 100.0 мВ
  ```
- Для формування струму 20.00 мА керуюча напруга повинна дорівнювати:
  ```
  V_sense(20мА) = 20.00 мА * 25.0 Ом = 500.0 мВ
  ```

Розмах напруги керування становить Delta_V = 500 мВ - 100 мВ = 400 мВ на повний діапазон температури 0...+100 °C (розмах виходу LM35 становить 1000 мВ). Отже, вхідний дільник повинен мати коефіцієнт передачі:

```
K_span = 400 мВ / 1000 мВ = 0.400
```

А напруга нульового зміщення (Offset) становить фіксовані 100.0 мВ, які подаються від джерела опорної напруги через масштабуючий дільник.

### Розрахунок максимального опору кабельної лінії

Максимальний опір петлі R_loop_max визначається мінімальною напругою джерела живлення петлі V_supply_min, мінімальним падінням напруги на регулюючому транзисторі V_drop_tx (зазвичай 8.0 В) та опором шунта приймача R_load (250 Ом):

```
R_line_max = [ (V_supply_min - V_drop_tx) / I_max ] - R_load
```

Для стандартного промислового джерела живлення 24 В (-10% допуск -> V_supply_min = 21.6 В):

```
R_line_max = [ (21.6 В - 8.0 В) / 0.020 А ] - 250 Ом = (13.6 В / 0.02 А) - 250 Ом = 680 Ом - 250 Ом = 430 Ом
```

При питомому опорі мідного кабелю перерізом 0.5 мм² близько 36 Ом/км (петля з двох жил дає 72 Ом/км):

```
L_max = 430 Ом / 72 Ом/км ≈ 5.97 км
```

Це демонструє колосальну перевагу струмової петлі: температурний сигнал можна транслювати на відстань до 6 кілометрів без найменшої втрати метрологічної точності.

## 5. Проектування високоточного віконного термостата з незалежним регулюванням порогів та гістерезису

Для систем апаратного захисту промислового обладнання використовують схеми на подвійних компараторах (LM393, TLV3702), які забезпечують незалежні уставки увімкнення та вимкнення нагрівача чи охолоджувача.

### Розрахунок передатної характеристики компаратора з позитивним зворотним зв'язком

Неінвертуючий тригер Шмітта з відкритим колектором (LM393) має два рівні порогів перемикання залежно від поточного стану виходу:

1. **Верхній поріг увімкнення (V_high):** Коли вихід компаратора знаходиться у стані логічного нуля (транзистор відкрито, вихід замкнено на GND через R_ds_on ≈ 0 Ом). Резистор R_hys підключено паралельно нижньому плечу вхідного ланцюга:
   ```
   V_high = V_ref * (1 + R_in / R_hys)
   ```
2. **Нижній поріг вимкнення (V_low):** Коли вихід знаходиться у стані логічної одиниці (вихідний транзистор закрито, резистор R_hys підтягнуто через R_pull до шини V_cc):
   ```
   V_low = V_ref - (V_cc - V_ref) * (R_in / (R_hys + R_pull))
   ```

Ширина вікна гістерезису становить:

```
Delta_V_hys = V_high - V_low ≈ V_cc * (R_in / R_hys)  (за умови R_hys >> R_in, R_pull << R_hys)
```

### Промисловий модуль обробки та калібрування на C

Нижче наведено виробничий код драйвера аналогового тракту LM35 на мікроконтролері STM32 (ARM Cortex-M), який реалізує математичну модель корекції апаратного зміщення та масштабування, обчислення температури у форматі чисел з фіксованою комою та діагностику виходу за межі:

```c
#include <stdint.h>
#include <stdbool.h>

/**
 * @brief Структура конфігурації аналогового каскаду на ОП
 */
typedef struct {
    float gain;             /* Коефіцієнт підсилення схеми ОП (наприклад, 3.30f) */
    float offset_mv;        /* Апаратний зсув нуля в мілівольтах (для схем зсуву рівня) */
    float vref_mv;          /* Опорна напруга АЦП (наприклад, 3300.0f мВ) */
    uint32_t adc_max_code;  /* Максимальний код АЦП (4095 для 12-біт) */
    float sensitivity_mv;   /* Чутливість LM35 (10.0f мВ/°C) */
} lm35_opamp_config_t;

/**
 * @brief Результат вимірювання температури з діагностичним статусом
 */
typedef enum {
    LM35_STATUS_OK = 0,
    LM35_STATUS_UNDERFLOW = 1,  /* Обрив сенсора або температура нижче допустимої */
    LM35_STATUS_OVERFLOW = 2,   /* Коротке замикання або перегрів понад ліміт */
    LM35_STATUS_INVALID = 3
} lm35_status_t;

typedef struct {
    float temperature_c;
    int32_t temp_millicelsius;
    lm35_status_t status;
} lm35_measurement_t;

/**
 * @brief Обчислення фізичної температури з урахуванням каскаду на ОП
 * @param raw_adc Сире значення 12-бітного коду АЦП
 * @param cfg Вказівник на калібрувальні параметри апаратного тракту
 * @param out_result Вказівник на структуру результату
 */
void lm35_process_opamp_adc(uint16_t raw_adc, 
                            const lm35_opamp_config_t *cfg, 
                            lm35_measurement_t *out_result) 
{
    if (cfg == NULL || out_result == NULL) {
        return;
    }

    /* Діагностика апаратних меж АЦП */
    if (raw_adc == 0) {
        out_result->status = LM35_STATUS_UNDERFLOW;
    } else if (raw_adc >= cfg->adc_max_code) {
        out_result->status = LM35_STATUS_OVERFLOW;
    } else {
        out_result->status = LM35_STATUS_OK;
    }

    /* Перетворення сирого коду в напругу на вході АЦП (мВ) */
    float v_adc_mv = ((float)raw_adc / (float)cfg->adc_max_code) * cfg->vref_mv;

    /* Реверс аналогової трансформації ОП:
     * V_adc = G * V_lm35 + V_offset  =>  V_lm35 = (V_adc - V_offset) / G
     */
    float v_lm35_mv = (v_adc_mv - cfg->offset_mv) / cfg->gain;

    /* Обчислення температури: T = V_lm35 / S (де S = 10 мВ/°C) */
    float temp_c = v_lm35_mv / cfg->sensitivity_mv;

    out_result->temperature_c = temp_c;
    out_result->temp_millicelsius = (int32_t)(temp_c * 1000.0f);
}
```

### Комплексний метрологічний підсумок

1. **Неінвертуючий масштабуючий каскад** забезпечує підвищення відношення сигнал/шум квантування (SQNR) на 10.4 дБ при узгодженні з 3.3 В опорною напругою, підвищуючи роздільну здатність системи до 0.024 °C/код.
2. **Диференційний зсув рівня** є безальтернативним схемотехнічним рішенням для контролю від'ємних температур до -55 °C у приладах із виключно однополярним живленням.
3. **Фільтр Саллена-Кея з характеристикою Баттерворта 2-го порядку** гарантує високу селективність до наведених мережевих завад 50/100 Гц (-28 дБ на 50 Гц), повністю усуваючи необхідність трудомісткої програмної цифрової фільтрації в ядрі мікроконтролера.
4. **Струмова петля 4–20 мА** трансформує сигнал LM35 у промисловий стандарт передачі даних, захищений від перешкод та падінь напруги в кабельних лініях протяжністю до декількох кілометрів.
