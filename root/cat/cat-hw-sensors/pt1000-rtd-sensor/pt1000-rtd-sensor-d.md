# Поглиблений інженерний аналіз та розрахунок вимірювальних систем на базі PT1000

Платинові термометри опору PT1000 є ключовими метрологічними сенсорами в сучасній автоматиці будівель, енергетиці, системах ОВіК (HVAC) та автомобілебудуванні. Високий базовий опір (R0 = 1000 Ом при 0 °C) забезпечує чутливість 3.85 Ом/°C, що дозволяє спростити схемотехніку кабельних ліній за рахунок переходу на двопровідне підключення, але накладає жорсткі вимоги на струми збудження через небезпеку саморозігріву.

У цьому детальному посібнику розглядаються аналіз стандартів допусків IEC 60751, термодинаміка розсіювання тепла, схемотехнічний розрахунок логометричних трактів на базі 24-бітних сигма-дельта АЦП, аналітичні методи обернення рівняння Календара-Ван Дюзена за алгоритмом Ньютона-Рафсона та промислові аспекти застосування в теплолічильниках EN 1434.

## 1. Метрологічний аналіз та класи допусків IEC 60751: температурні залежності та довготривала стабільність

Метрологічна поведінка платинових тонкоплівкових терморезисторів регламентується стандартом **IEC 60751:2008**. Стандарт встановлює функціональну залежність номінального опору та математичні моделі допустимих відхилень.

### Класифікація допусків тонкоплівкових датчиків

Тонкоплівкові резистори маркуються категоріями відповідно до стандарту IEC 60751:

| Клас допуску | Формула допуску похибки | Допуск при 0 °C | Допуск при 100 °C | Допустимий діапазон |
| :--- | :--- | :--- | :--- | :--- |
| **Клас AA** | Delta_T = +/- (0.10 + 0.0017 * |t|) | +/- 0.10 °C (+/- 0.39 Ом) | +/- 0.27 °C (+/- 1.01 Ом) | 0 °C .. +150 °C |
| **Клас A** | Delta_T = +/- (0.15 + 0.0020 * |t|) | +/- 0.15 °C (+/- 0.58 Ом) | +/- 0.35 °C (+/- 1.33 Ом) | -30 °C .. +300 °C |
| **Клас B** | Delta_T = +/- (0.30 + 0.0050 * |t|) | +/- 0.30 °C (+/- 1.15 Ом) | +/- 0.80 °C (+/- 3.03 Ом) | -50 °C .. +500 °C |
| **Клас C** | Delta_T = +/- (0.60 + 0.0100 * |t|) | +/- 0.60 °C (+/- 2.30 Ом) | +/- 1.60 °C (+/- 6.04 Ом) | -50 °C .. +600 °C |
| **1/3 DIN** | Delta_T = +/- (1/3) * (0.30 + 0.0050 * |t|) | +/- 0.10 °C (+/- 0.38 Ом) | +/- 0.27 °C (+/- 1.01 Ом) | 0 °C .. +100 °C |

### Довготривалий дрейф та термомеханічні напруження

Тонкоплівковий шар платини (товщиною 0.8–1.2 мкм) напилюється на підкладку з діелектричної кераміки оксиду алюмінію (Al2O3). Коефіцієнт лінійного теплового розширення (КЛТР) чистої платини становить `alpha_Pt ≈ 9.0e-6 K^-1`, тоді як для оксиду алюмінію `alpha_Al2O3 ≈ 8.0e-6 K^-1`.

Через невелику різницю КЛТР при різких температурних змінах у кристалі виникають механічні напруження стиснення-розтягу. Вони змінюють мікроструктуру кристалічної решітки платини (п'єзорезистивний ефект), що створює незначний гістерезис при циклічному нагріві та охолодженні. 

Для якісних промислових тонкоплівкових елементів (JUMO, Heraeus, Yageo) довготривалий дрейф базового опору становить:

```
Delta_R0_drift < 0.04% (менше 0.4 Ом, еквівалентно 0.1 °C) після 1000 годин роботи при 400 °C
```

Це на порядок перевершує будь-які типи термісторів (NTC/PTC), опір яких може дрейфувати на 1–5% на рік.

## 2. Термодинамічний аналіз саморозігріву: тепловий опір, середовища вимірювання та імпульсне збудження

Похибка від саморозігріву виникає внаслідок теплового опору між чутливим платиновим шаром і середовищем, що вимірюється:

```
Delta_T_sh = T_die - T_medium = P_dissipated * Theta_th = (I_exc^2 * R_pt1000) / G_dissipation
```

де `Theta_th` — тепловий опір конструкції датчика (K/мВт або °C/мВт), а `G_dissipation = 1 / Theta_th` — коефіцієнт розсіювання потужності (мВт/°C).

### Коефіцієнти розсіювання в різних технологічних середовищах

Для стандартного тонкоплівкового датчика розміром 2.0 × 2.3 × 0.9 мм:

| Середовище | Швидкість руху потоку | Коефіцієнт розсіювання G | Похибка при I = 100 мкА | Похибка при I = 1.0 мА |
| :--- | :--- | :--- | :--- | :--- |
| **Стояче повітря** | 0 м/с (нерухоме) | **1.2 .. 1.8 мВт/°C** | **0.007 °C** | **0.71 °C (Неприпустимо!)** |
| **Повітряний потік** | 1.0 м/с | **3.0 .. 4.5 мВт/°C** | **0.003 °C** | **0.28 °C** |
| **Стояча вода** | 0 м/с | **12 .. 18 мВт/°C** | **< 0.001 °C** | **0.07 °C** |
| **Проточна рідина** | > 0.5 м/с | **30 .. 50 мВт/°C** | **< 0.0005 °C** | **0.02 °C** |

### Метод імпульсного збудження (Pulsed Excitation)

Для повної ліквідації проблеми саморозігріву в прецизійних мікроспоживаючих вузлах застосовують імпульсне збудження:
- Джерело струму 200–500 мкА вмикається аналоговим ключем лише на час вибірки АЦП (t_active = 2–5 мс).
- Решту часу (t_idle = 995 мс) струм через датчик не протікає.
- Коефіцієнт заповнення становить Duty_Cycle = 0.5%. Середня виділена теплова потужність падає у 200 разів, що гарантує абсолютно нульовий саморозігрів при підвищеній амплітуді сигналу на вході АЦП.

## 3. Схемотехніка аналогового тракту: вимірювальні мости, джерела струму на ОП та 24-бітні АЦП

Для зняття сигналу з PT1000 використовують різні схемотехнічні топології.

### Порівняння апаратних топологій кондиціювання сигналу

1. **Міст Вітстона з диференційним підсилювачем:** Класична топологія. Міст живиться від стабілізованої напруги, у нижнє плече встановлено PT1000, в інші плечі — прецизійні резистори 1000.0 Ом. 
   - *Недолік:* Нелінійність самого моста додається до нелінійності платини, потрібен інструментальний ОП з високим CMRR.
2. **Джерело стабільного струму на ОП (Howland Current Pump):** ОП формує фіксований струм I = 100 мкА через датчик на землю. Падіння напруги подається на АЦП.
   - *Недолік:* Дрейф опорного стабілізатора напруги та точність підгонки резисторів генератора струму безпосередньо впливають на точність.
3. **Логометрична схема з послідовним шунтом R_ref (Ratiometric Architecture):** Датчик PT1000 та опорний резистор R_ref включені послідовно в струмову петлю. Опорна напруга АЦП знімається безпосередньо з R_ref.
   - *Перевага:* Абсолютне пригнічення дрейфу струму. Це де-факто промисловий еталон для мікросхем класу ADS1220 (Texas Instruments), MAX31865 (Analog Devices) та MCP3561 (Microchip).

### Розрахунок синфазного діапазону та захисних фільтрів (RFI/EMI)

Для забезпечення коректної роботи вбудованого буфера PGA АЦП напруга на аналогових входах AINP та AINN повинна залишатися всередині лінійного діапазону живлення (зазвичай від GND + 0.2 В до AVDD - 0.2 В).

При послідовному з'єднанні `I_exc = 100 мкА`, `R_rtd = 1000..1800 Ом` та `R_ref = 4000 Ом`:
- Падіння напруги на R_ref: `V_ref = 100 мкА * 4000 Ом = 0.400 В`.
- Падіння напруги на PT1000: `V_rtd = 100 мкА * 1000 Ом = 0.100 В` (при 0 °C) та `0.180 В` (при +200 °C).
- Потенціал на AINP: `V_ref + V_rtd = 0.400 + 0.180 = 0.580 В`.
- Потенціал на AINN: `V_ref = 0.400 В`.
Обидва рівні ідеально вписуються в середину динамічного діапазону однополярного живлення +3.3 В.

Для захисту від синфазних та диференційних радіочастотних перешкод на входах встановлюють симетричний RC-фільтр низьких частот: два резистори по 1.0 кОм, два конденсатори синфазної фільтрації C_cm = 10 нФ на землю та міжканальний диференційний конденсатор C_diff = 100 нФ (його ємність вибирають у 10 разів більшою за C_cm для збереження балансу плечей).

## 4. Промисловий C/C++ драйвер з оберненням рівняння Календара-Ван Дюзена та підтримкою 2/3/4-провідних схем

Нижче наведено модульний виробничий код драйвера PT1000 на мові C, що містить аналітичне розв'язання для позитивного діапазону та ітераційний алгоритм Ньютона-Рафсона для повного охоплення від'ємного кріогенного діапазону (від -200 °C до 0 °C).

```c
#include <stdint.h>
#include <stdbool.h>
#include <math.h>

/**
 * @brief Константи Callendar-Van Dusen за стандартом IEC 60751
 */
#define PT1000_R0         1000.0f
#define PT1000_CVD_A      3.9083e-3f
#define PT1000_CVD_B     -5.7750e-7f
#define PT1000_CVD_C     -4.1830e-12f

typedef enum {
    PT1000_WIRING_2WIRE = 2,
    PT1000_WIRING_3WIRE = 3,
    PT1000_WIRING_4WIRE = 4
} pt1000_wiring_t;

typedef struct {
    float r_ref_ohm;            /* Номінал опорного резистора (наприклад, 4000.0f Ом) */
    float lead_resistance_ohm;  /* Сумарний опір кабелю для 2-провідної схеми */
    pt1000_wiring_t wiring;     /* Схема підключення */
    uint32_t adc_max_code;      /* Максимальний код АЦП (8388608 для 24-біт логометрії) */
} pt1000_config_t;

/**
 * @brief Прямий розрахунок R(T) за рівнянням Callendar-Van Dusen
 */
float pt1000_temperature_to_resistance(float temp_c) {
    if (temp_c >= 0.0f) {
        return PT1000_R0 * (1.0f + (PT1000_CVD_A * temp_c) + (PT1000_CVD_B * temp_c * temp_c));
    } else {
        float t2 = temp_c * temp_c;
        float t3 = t2 * temp_c;
        float t4 = t3 * temp_c;
        return PT1000_R0 * (1.0f + (PT1000_CVD_A * temp_c) + (PT1000_CVD_B * t2) + 
                            (PT1000_CVD_C * (temp_c - 100.0f) * t3));
    }
}

/**
 * @brief Похідна dR/dT для методу Ньютона-Рафсона (для T < 0 °C)
 */
static float pt1000_cvd_derivative_negative(float temp_c) {
    float t2 = temp_c * temp_c;
    float t3 = t2 * temp_c;
    /* d/dT [ 1 + A*T + B*T^2 - 100*C*T^3 + C*T^4 ] */
    return PT1000_R0 * (PT1000_CVD_A + (2.0f * PT1000_CVD_B * temp_c) - 
                        (300.0f * PT1000_CVD_C * t2) + (4.0f * PT1000_CVD_C * t3));
}

/**
 * @brief Високоточне обернення T(R) методом Ньютона-Рафсона для T < 0 °C
 */
static float pt1000_invert_cvd_newton(float r_target) {
    /* Початкове лінійне наближення */
    float temp = (r_target - PT1000_R0) / (PT1000_R0 * PT1000_CVD_A);

    /* 3-4 ітерації гарантують похибку < 0.001 °C */
    for (int i = 0; i < 4; ++i) {
        float r_current = pt1000_temperature_to_resistance(temp);
        float d_r = pt1000_cvd_derivative_negative(temp);
        float delta = (r_current - r_target) / d_r;
        temp -= delta;
        if (fabsf(delta) < 1.0e-4f) {
            break;
        }
    }
    return temp;
}

/**
 * @brief Перетворення виміряного коду АЦП у фізичну температуру
 */
bool pt1000_process_measurement(int32_t raw_adc_code, 
                                const pt1000_config_t *cfg, 
                                float *out_temperature_c) 
{
    if (cfg == NULL || out_temperature_c == NULL || raw_adc_code <= 0) {
        return false;
    }

    /* 1. Розрахунок фізичного опору сенсора за логометричним відношенням */
    float r_measured = cfg->r_ref_ohm * ((float)raw_adc_code / (float)cfg->adc_max_code);

    /* 2. Компенсація опору кабелю при 2-провідному підключенні */
    float r_sensor = r_measured;
    if (cfg->wiring == PT1000_WIRING_2WIRE) {
        r_sensor -= cfg->lead_resistance_ohm;
    }

    /* Діагностика меж фізичного діапазону (-200 °C = 185 Ом, +600 °C = 3137 Ом) */
    if (r_sensor < 180.0f || r_sensor > 3200.0f) {
        return false; /* Обрив або коротке замикання датчика */
    }

    /* 3. Обернення CVD рівняння */
    if (r_sensor >= PT1000_R0) {
        /* Точне квадратичне аналітичне обернення для T >= 0 °C */
        float discriminant = (PT1000_CVD_A * PT1000_CVD_A) - 
                             (4.0f * PT1000_CVD_B * (1.0f - (r_sensor / PT1000_R0)));
        if (discriminant < 0.0f) discriminant = 0.0f;
        *out_temperature_c = (-PT1000_CVD_A + sqrtf(discriminant)) / (2.0f * PT1000_CVD_B);
    } else {
        /* Метод Ньютона для T < 0 °C */
        *out_temperature_c = pt1000_invert_cvd_newton(r_sensor);
    }

    return true;
}
```

## 5. Промислове застосування: автоматика HVAC, теплові лічильники та сонячні геліоколектори

Специфіка застосування PT1000 зумовлена його балансом між точністю, низькою споживаною потужністю та технологічністю монтажу.

### Вузли комерційного обліку тепла (EN 1434 Heat Meters)

У лічильниках теплової енергії теплова потужність обчислюється як:

```
Q_dot = m_dot * c_p * (T_flow - T_return) = m_dot * c_p * Delta_T
```

При малих витратах теплоносія різниця температур подачі та звороту `Delta_T` може становити всього 3.0–5.0 °C. Будь-яка абсолютна похибка вимірювання різниці температур на рівні 0.1 °C дає відносну похибку обліку тепла до 2–3%, що веде до значних фінансових втрат.

Для теплолічильників застосовують парні узгоджені термометри (Matched Pairs) PT1000 класу за стандартом EN 1434:
- Датчики проходять груповий заводський відбір за різницею опорів `Delta_R0 < 0.02 Ом` (розходження менше 0.005 °C при 0 °C).
- Використання PT1000 є обов'язковим для автономних лічильників тепла з 10-річним строком служби від вбудованої батареї.

### Сонячні термальні колектори та захист від перегріву

У геліотермальних установках датчик на сонячному колекторі працює в екстремальних режимах:
- У зимовий період при нічному морозі температура падає до -30...-40 °C.
- У літній день при зупинці циркуляційного насоса настає режим стагнації (Stagnation), коли температура теплоносія досягає **+200...+250 °C**.
Напівпровідникові датчики (DS18B20, терморезистори NTC) руйнуються або виходять за межі вимірювання вже при +125...+150 °C. Датчики PT1000 у герметичних гільзах із силіконовим або тефлоновим кабелем безперервно витримують температури до +300...+400 °C, гарантуючи надійне аварійне скидання тиску та безпеку геліосистеми.
