# Поглиблений аналіз регістрової карти LTDC, тіньового перезавантаження та драйвера

Конфігурація контролера LTDC містить унікальну особливість архітектури STM32: усі часові координати розгортки задаються не відносними тривалостями інтервалів, а **акумульованими абсолютними значеннями (Accumulated Timings)**, починаючи від лівого верхнього кута кадру. Будь-яка неточність у налаштуванні регістрів `SSCR`, `BPCR`, `AWCR` або `TWCR` спричиняє зрив рядкової чи кадрової синхронізації та повну відсутність зображення на екрані.

У цьому розділі наведено поглиблений розбір регістрової структури LTDC, механізму безпечного перезавантаження тіньових регістрів (Shadow Registers) та виробничий драйвер на мові C для панелі 800x480.

---

## 1. Регістрова модель формування часових стробів розгортки

Для налаштування таймінгів РК-панелі контролер LTDC використовує чотири обов'язкові конфігураційні регістри, значення в яких записуються строго кумулятивно (накопичувальним підсумком мінус 1 такт):

```text
+--------------+---------------------------------------------------------------------------------+
| Регістр      | Формула та бітова структура акумульованих таймінгів                            |
+--------------+---------------------------------------------------------------------------------+
| LTDC_SSCR    | Synchronization Size Configuration Register (Ширина синхроімпульсів):           |
|              | - [27:16] HSW[11:0] = Hsync_Width - 1                                           |
|              | - [10:0]  VSH[10:0] = Vsync_Height - 1                                          |
+--------------+---------------------------------------------------------------------------------+
| LTDC_BPCR    | Back Porch Configuration Register (Акумульоване заднє гасіння):                 |
|              | - [27:16] AHBP[11:0] = Hsync_Width + Horizontal_Back_Porch - 1                  |
|              | - [10:0]  AVBP[10:0] = Vsync_Height + Vertical_Back_Porch - 1                  |
+--------------+---------------------------------------------------------------------------------+
| LTDC_AWCR    | Active Width Configuration Register (Акумульований активний екран):            |
|              | - [27:16] AAW[11:0] = Hsync_Width + Horizontal_Back_Porch + Active_Width - 1    |
|              | - [10:0]  AAH[10:0] = Vsync_Height + Vertical_Back_Porch + Active_Height - 1   |
+--------------+---------------------------------------------------------------------------------+
| LTDC_TWCR    | Total Width Configuration Register (Акумульований повний період):              |
|              | - [27:16] TOTALW[11:0] = AAW + Horizontal_Front_Porch                            |
|              | - [10:0]  TOTALH[10:0] = AAH + Vertical_Front_Porch                            |
+--------------+---------------------------------------------------------------------------------+
```

### Практичний розрахунок для панелі WVGA 800x480:

Вихідні параметри з даташиту дисплея:
- HSW = 1 такт, HBP = 46 тактів, HACT = 800 пікселів, HFP = 210 тактів.
- VSW = 1 рядок, VBP = 23 рядки, VACT = 480 рядків, VFP = 22 рядки.

Розрахунок значень для запису в регістри:
1. `LTDC_SSCR`:
   - `HSW = 1 - 1 = 0`
   - `VSH = 1 - 1 = 0`
   - Значення: `0x00000000`
2. `LTDC_BPCR`:
   - `AHBP = 1 + 46 - 1 = 46 (0x2E)`
   - `AVBP = 1 + 23 - 1 = 23 (0x17)`
   - Значення: `(46 << 16) | 23 = 0x002E0017`
3. `LTDC_AWCR`:
   - `AAW = 1 + 46 + 800 - 1 = 846 (0x34E)`
   - `AAH = 1 + 23 + 480 - 1 = 503 (0x1F7)`
   - Значення: `(846 << 16) | 503 = 0x034E01F7`
4. `LTDC_TWCR`:
   - `TOTALW = 846 + 210 = 1056 (0x420)`
   - `TOTALH = 503 + 22 = 525 (0x20D)`
   - Значення: `(1056 << 16) | 525 = 0x0420020D`

## 2. Полярності сигналів та глобальний регістр керування (LTDC_GCR)

Регістр `LTDC_GCR` налаштовує активні рівні сигналів керування дисплеєм:
- **Біт [31] — `HSPOL` (Horizontal Synchronization Polarity):** 0 = активний низький рівень (типово), 1 = активний високий.
- **Біт [30] — `VSPOL` (Vertical Synchronization Polarity):** 0 = активний низький рівень, 1 = активний високий.
- **Біт [29] — `DEPOL` (Data Enable Polarity):** 0 = активний низький, 1 = активний високий (для 95% матриць використовується 1).
- **Біт [28] — `PCPOL` (Pixel Clock Polarity):** 0 = засувка пікселя по наростаючому фронту, 1 = по спадному.
- **Біт [16] — `DEN` (Dither Enable):** 1 = увімкнення апаратного дизерингу.
- **Біт [0] — `LTDCEN` (LTDC Enable):** 1 = увімкнення генератора розгортки.

## 3. Регістри конфігурації графічного шару (Layer Registers)

Кожен шар має префікс `LTDC_L1` або `LTDC_L2`:

```text
+-------------------+--------------------------------------------------------------------------+
| Регістр шару      | Призначення та налаштування                                              |
+-------------------+--------------------------------------------------------------------------+
| LTDC_LxWHPCR      | Window Horizontal Position: координати початку та кінця вікна:           |
|                   | - [27:16] WHSPPOS = AHBP + X_Stop                                        |
|                   | - [11:0]  WHSTPOS = AHBP + X_Start + 1                                   |
+-------------------+--------------------------------------------------------------------------+
| LTDC_LxWVPCR      | Window Vertical Position: вертикальні межі вікна:                        |
|                   | - [26:16] WVSPPOS = AVBP + Y_Stop                                        |
|                   | - [10:0]  WVSTPOS = AVBP + Y_Start + 1                                   |
+-------------------+--------------------------------------------------------------------------+
| LTDC_LxPFCR       | Pixel Format Configuration (Кодування кольору):                          |
|                   | 000: ARGB8888 (32 біти) | 001: RGB888 (24 біти)                           |
|                   | 010: RGB565 (16 бітів)  | 011: ARGB1555 (16 бітів)                        |
|                   | 101: L8 (8 біт індекс CLUT) | 111: AL88 (8 біт альфа + 8 біт палітра)   |
+-------------------+--------------------------------------------------------------------------+
| LTDC_LxCFBAR      | Color Frame Buffer Address: 32-бітна фізична адреса буфера в SDRAM       |
+-------------------+--------------------------------------------------------------------------+
| LTDC_LxCFBLR      | Color Frame Buffer Length:                                               |
|                   | - [28:16] CFBP[12:0]: Крок рядка в байтах (Pitch = Width * Bpp)          |
|                   | - [12:0]  CFBLL[12:0]: Довжина активного рядка (Width * Bpp + 3 або + 7) |
+-------------------+--------------------------------------------------------------------------+
| LTDC_LxCFBLNR     | Color Frame Buffer Line Number: кількість рядків кадру (480)             |
+-------------------+--------------------------------------------------------------------------+
| LTDC_LxBFCR       | Blending Factors: вибір коефіцієнтів змішування:                         |
|                   | - [10:8] BF1 = 100: Constant Alpha * Pixel Alpha                         |
|                   | - [2:0]  BF2 = 101: 1 - (Constant Alpha * Pixel Alpha)                   |
+-------------------+--------------------------------------------------------------------------+
```

## 4. Механізм тіньового перезавантаження регістрів (Shadow Reloading)

Щоб запобігти графічним артефактам та розривам кадрів (Tearing), будь-які зміни координат шарів, зміни адрес фреймбуферів або коефіцієнтів прозорості записуються спочатку в **тіньові регістри (Shadow Registers)**.

Для застосування змін на екрані використовується регістр перезавантаження `LTDC_SRCR`:
- **Vertical Blanking Reload (`VBR = 1`):** нові параметри копіюються з тіньових регістрів в активні strictly під час кадрового імпульсу гасіння VBLANK. Це гарантує 100% плавність анімації без розривів рядків.
- **Immediate Reload (`IMR = 1`):** негайне застосування параметрів прямо посеред кадру (використовується виключно під час початкової ініціалізації при зупиненому дисплеї).

```c
/* Безпечне перемикання фреймбуфера у VBLANK */
void ltdc_switch_framebuffer(uint32_t layer_idx, uint32_t new_buffer_address) {
    if (layer_idx == 0) {
        LTDC_Layer1->CFBAR = new_buffer_address;
    } else {
        LTDC_Layer2->CFBAR = new_buffer_address;
    }
    /* Запит перезавантаження під час наступного VBLANK */
    LTDC->SRCR = LTDC_SRCR_VBR;
}
```

## 5. Виробничий низькорівневий драйвер ініціалізації LTDC на мові C

Нижче наведено виробничу реалізацію драйвера прямого запуску панелі 800x480 у форматі RGB565:

```c
#include "stm32f4xx.h"
#include <stdint.h>
#include <stdbool.h>

#define LCD_WIDTH               800
#define LCD_HEIGHT              480

/* Таймінги панелі WVGA */
#define HSW                     1
#define HBP                     46
#define HFP                     210
#define VSW                     1
#define VBP                     23
#define VFP                     22

#define LAYER1_FRAMEBUFFER_ADDR 0xC0000000 /* SDRAM Bank 1 */

/**
 * @brief Пряма регістрова ініціалізація контролера LTDC
 */
void ltdc_init_wvga_panel(void) {
    /* 1. Увімкнення тактування LTDC */
    RCC->APB2ENR |= RCC_APB2ENR_LTDCEN;

    /* (Примітка: налаштування пінів GPIO портів I, J, K в режим AF14 виконується на рівні BSP) */

    /* 2. Конфігурація акумульованих таймінгів розгортки */
    LTDC->SSCR = ((HSW - 1) << LTDC_SSCR_HSW_Pos) | 
                 ((VSW - 1) << LTDC_SSCR_VSH_Pos);

    LTDC->BPCR = ((HSW + HBP - 1) << LTDC_BPCR_AHBP_Pos) | 
                 ((VSW + VBP - 1) << LTDC_BPCR_AVBP_Pos);

    LTDC->AWCR = ((HSW + HBP + LCD_WIDTH - 1) << LTDC_AWCR_AAW_Pos) | 
                 ((VSW + VBP + LCD_HEIGHT - 1) << LTDC_AWCR_AAH_Pos);

    LTDC->TWCR = ((HSW + HBP + LCD_WIDTH + HFP - 1) << LTDC_TWCR_TOTALW_Pos) | 
                 ((VSW + VBP + LCD_HEIGHT + VFP - 1) << LTDC_TWCR_TOTALH_Pos);

    /* 3. Налаштування полярностей та апаратного дизерингу (LTDC_GCR)
     * DEPOL = 1 (Active High), PCPOL = 0 (Rising edge), DEN = 1 (Dither Enable) */
    LTDC->GCR = LTDC_GCR_DEPOL | LTDC_GCR_DEN;

    /* 4. Колір фону екрана за межами активного вікна (Чорний) */
    LTDC->BCCR = 0x00000000;

    /* =================== КОНФІГУРАЦІЯ ШАРУ 1 (LAYER 1) =================== */

    /* Вікно на повний екран */
    uint32_t h_start = HSW + HBP + 1;
    uint32_t h_stop  = HSW + HBP + LCD_WIDTH;
    uint32_t v_start = VSW + VBP + 1;
    uint32_t v_stop  = VSW + VBP + LCD_HEIGHT;

    LTDC_Layer1->WHPCR = (h_stop << LTDC_LxWHPCR_WHSPPOS_Pos) | (h_start << LTDC_LxWHPCR_WHSTPOS_Pos);
    LTDC_Layer1->WVPCR = (v_stop << LTDC_LxWVPCR_WVSPPOS_Pos) | (v_start << LTDC_LxWVPCR_WVSTPOS_Pos);

    /* Формат пікселів: RGB565 (код 010) */
    LTDC_Layer1->PFCR = 0x02;

    /* Константна альфа (255 = 100% непрозорий) */
    LTDC_Layer1->CACR = 255;

    /* Фактори змішування Blending Factors */
    LTDC_Layer1->BFCR = (4 << LTDC_LxBFCR_BF1_Pos) | (5 << LTDC_LxBFCR_BF2_Pos);

    /* Фізична адреса кадрового буфера в SDRAM */
    LTDC_Layer1->CFBAR = LAYER1_FRAMEBUFFER_ADDR;

    /* Довжина рядка: Pitch = 800 * 2 = 1600 байтів, LineLength = 1600 + 3 */
    LTDC_Layer1->CFBLR = ((LCD_WIDTH * 2) << LTDC_LxCFBLR_CFBP_Pos) | 
                         ((LCD_WIDTH * 2 + 3) << LTDC_LxCFBLR_CFBLL_Pos);

    /* Кількість рядків у буфері */
    LTDC_Layer1->CFBLNR = LCD_HEIGHT;

    /* Увімкнення Layer 1 */
    LTDC_Layer1->CR |= LTDC_LxCR_LEN;

    /* 5. Застосування налаштувань через Immediate Reload */
    LTDC->SRCR = LTDC_SRCR_IMR;

    /* 6. Глобальний запуск контролера LTDC */
    LTDC->GCR |= LTDC_GCR_LTDCEN;
}
```

## 6. Діагностика несправностей відеотракту LTDC

1. **Зсув зображення по горизонталі або вертикалі:**
   - *Причина:* Помилка в розрахунку акумульованих регістрів `BPCR` або `AWCR`. Перевірте, чи враховано додавання попередніх інтервалів HSW/VSW.
2. **Тремтіння окремих пікселів або муар:**
   - *Причина:* Неправильна полярність тактування `PCPOL`. Змініть стробування з наростаючого фронту на спадний у регістрі `LTDC_GCR`.
3. **Виникнення чорних горизонтальних смуг:**
   - *Причина:* Аварія FIFO Underrun. Збільште пріоритет арбітражу AXI QoS або переведіть інші потік DMA на режим пакетної передачі Burst INC4.
