# Поглиблений метрологічний аналіз та математичний апарат шкали ITS-90

Міжнародна температурна шкала 1990 року (ITS-90) є вичерпною метрологічною системою, розробленою Консультативним комітетом з термометрії (CCT) та ухваленою CIPM. Вона встановлює точні процедури калібрування, фізичні константи реперних ампул та офіційні поліноми високого ступеня, що пов'язують відносний електричний опір платини з термодинамічною температурою.

У цьому посібнику розглядаються аналітичний апарат опорних функцій BIPM, розрахунок функцій відхилення для 11 калібрувальних піддіапазонів SPRT, термодинамічний бюджет невизначеності фіксованих точок, алгоритми програмної реалізації на C/C++ та перерахунок різниць між шкалами ITS-90, IPTS-68 і промисловим стандартом IEC 60751.

---

## 1. Повний математичний апарат опорних функцій BIPM Wr(T90) та їх обернення

Діапазон еталонних платинових термометрів SPRT (від 13.8033 K до 1234.93 K) розбито на два основні температурні інтервали, для кожного з яких Міжнародне бюро мір і ваг (BIPM) визначило безперервні опорні функції `W_r(T_90)`.

### 1. Високотемпературний діапазон: від 0 °C до 961.78 °C (273.15 K .. 1234.93 K)

Офіційне рівняння опорної функції `W_r(T_90)` являє собою степеневий поліном 9-го порядку:

```
W_r(T_90) = C_0 + Sum [ C_i * ( (T_90 - 273.15 K) / 754 K )^i ]   (i = 1 .. 9)
```

Нормувальний коефіцієнт 754 K обрано для того, щоб аргумент поліному змінювався в межах від 0.0 до 1.0 (оскільки 1234.93 K - 273.15 K = 961.78 K ≈ 754 K у зміщеній нормалізації).

Таблиця нормативних коефіцієнтів C_i (BIPM):

| Індекс i | Коефіцієнт C_i |
| :--- | :--- |
| **0** | **+0.183324722** |
| **1** | **+0.240975303** |
| **2** | **+0.209108771** |
| **3** | **+0.190439972** |
| **4** | **+0.142648498** |
| **5** | **+0.077993465** |
| **6** | **+0.012475611** |
| **7** | **-0.032267127** |
| **8** | **-0.075293522** |
| **9** | **-0.056470860** |

### Обернена опорна функція T_90(W_r)

Для швидкого обчислення температури `T_90` безпосередньо за розрахованим відношенням `W_r` стандарт ITS-90 надає обернений поліном:

```
(T_90 - 273.15 K) / 754 K = D_0 + Sum [ D_i * ( (W_r - 2.64) / 1.64 )^i ]   (i = 1 .. 9)
```

Похибка математичної неузгодженості між прямим поліномом `W_r(T_90)` та оберненим виразом становить менше **0.1 мК (0.0001 °C)** у всій області від 0 °C до 961.78 °C.

### 2. Кріогенний діапазон: від 13.8033 K до 273.16 K

Для низьких температур опір платини має різку логарифмічну залежність. Опорна функція описується поліномом 12-го ступеня від натурального логарифма:

```
ln(W_r(T_90)) = A_0 + Sum [ A_i * ( (ln(T_90 / 273.15 K) + 1.5) / 1.5 )^i ]   (i = 1 .. 12)
```

## 2. Функції відхилення Delta_W для піддіапазонів калібрування SPRT та матричний розрахунок

Шкала ITS-90 дозволяє калібрувати SPRT не на весь максимальний діапазон одразу, а в окремих практичних піддіапазонах (Subranges), залежно від завдань лабораторії.

### Структура функцій відхилення для ключових піддіапазонів

Індивідуальна функція відхилення екземпляра термометра описується виразом:

```
Delta_W = W(T_90) - W_r(T_90)
```

1. **Піддіапазон 0 °C .. +29.7646 °C (Калібрування по точці плавлення галію Ga):**
   Використовується одна реперна точка крім TPW:
   ```
   Delta_W = a * (W - 1)
   ```
   Коефіцієнт `a` обчислюється тривіально: `a = (W_Ga - W_r_Ga) / (W_Ga - 1)`.

2. **Піддіапазон 0 °C .. +156.5985 °C (Точки Ga та затвердіння індію In):**
   ```
   Delta_W = a * (W - 1) + b * (W - 1)^2
   ```

3. **Піддіапазон 0 °C .. +419.527 °C (Точки олова Sn та цинку Zn):**
   Найпоширеніший промисловий діапазон повірки:
   ```
   Delta_W = a * (W - 1) + b * (W - 1)^2
   ```

4. **Піддіапазон 0 °C .. +660.323 °C (Точки Sn, Zn та алюмінію Al):**
   ```
   Delta_W = a * (W - 1) + b * (W - 1)^2 + c * (W - 1)^3
   ```

### Матричний метод розрахунку коефіцієнтів a, b, c

Для піддіапазону 0..660 °C результати вимірювань у трьох реперних ампулах (Sn, Zn, Al) дають систему трьох лінійних рівнянь відносно невідомих коефіцієнтів `[a, b, c]^T`:

```
[ (W_Sn - 1)   (W_Sn - 1)^2   (W_Sn - 1)^3 ]   [ a ]     [ W_Sn - W_r_Sn ]
[ (W_Zn - 1)   (W_Zn - 1)^2   (W_Zn - 1)^3 ] * [ b ]  =  [ W_Zn - W_r_Zn ]
[ (W_Al - 1)   (W_Al - 1)^2   (W_Al - 1)^3 ]   [ c ]     [ W_Al - W_r_Al ]
```

Матриця системи є матрицею Вандермонда, визначник якої завжди строго відмінний від нуля за умови різних температур реперів. Розв'язок системи методом Крамера або розкладанням LU дає унікальний калібрувальний вектор коефіцієнтів термометра.

## 3. Фізико-хімічні особливості реалізації реперних точок та бюджет невизначеності

Реалізація фіксованих точок шкали ITS-90 вимагає суворого врахування термодинамічних поправок.

### Бюджет невизначеності реперної ампули затвердіння цинку (Zn FP, 419.527 °C)

| Джерело невизначеності | Механізм виникнення | Типове значення | Внесок у невизначеність |
| :--- | :--- | :--- | :--- |
| **Хімічні домішки металу** | Зниження температури плавлення за законом Рауля | Чистота 99.9999% (6N) | 0.25 мК |
| **Гідростатичний ефект стовпа рідини** | Тиск розплаву на глибині h занурення датчика | `dT/dh = +2.7e-8 K/Па` (~18 см стовпа) | 0.48 мК (поправка) |
| **Тиск буферного газу аргону** | Відхилення зовнішнього тиску від 101 325 Па | `dT/dp = +4.3e-8 K/Па` | 0.05 мК |
| **Паразитний витік тепла по гільзі** | Теплопровідність уздовж трубки датчика назовні | Глибина занурення > 180 мм | 0.15 мК |
| **Саморозігрів вимірювальним струмом** | Вимірювання при I = 1 мА та I = sqrt(2) мА | Екстраполяція до I = 0 мА | 0.10 мК |

Сумарна стандартна невизначеність реалізації плато кристалізації цинку в національних інститутах метрології не перевищує **u_c = 0.6–0.8 мК**.

## 4. Програмний алгоритм на C/C++ для обчислення температури за шкалою ITS-90

Нижче наведено промисловий код модуля на C, що реалізує розрахунок міжнародної температури `T_90` та `t_90` для діапазону від 0 °C до 961.78 °C за офіційними формулами BIPM:

```c
#include <stdint.h>
#include <stdbool.h>
#include <math.h>

/**
 * @brief Офіційні коефіцієнти опорної функції BIPM Wr(T90) від 0 °C до 961.78 °C
 */
static const double C_COEFF[10] = {
    +0.183324722,
    +0.240975303,
    +0.209108771,
    +0.190439972,
    +0.142648498,
    +0.077993465,
    +0.012475611,
    -0.032267127,
    -0.075293522,
    -0.056470860
};

/**
 * @brief Калібрувальний паспорт еталонного термометра SPRT
 */
typedef struct {
    double r_tpw_ohm;   /* Опір термометра в потрійній точці води R(273.16 K) */
    double a_coeff;     /* Індивідуальний коефіцієнт відхилення 'a' */
    double b_coeff;     /* Індивідуальний коефіцієнт відхилення 'b' */
    double c_coeff;     /* Індивідуальний коефіцієнт відхилення 'c' */
} its90_sprt_calibration_t;

/**
 * @brief Обчислення ідеальної опорної функції Wr за заданою температурою T90 (Кельвіни)
 */
double its90_calc_wr(double t90_kelvin) {
    double tau = (t90_kelvin - 273.15) / 754.0;
    double wr = C_COEFF[0];
    double tau_pow = tau;

    for (int i = 1; i <= 9; ++i) {
        wr += C_COEFF[i] * tau_pow;
        tau_pow *= tau;
    }
    return wr;
}

/**
 * @brief Похідна dWr / dT90 для ітераційного наближення Ньютона
 */
static double its90_calc_dwr_dt(double t90_kelvin) {
    double tau = (t90_kelvin - 273.15) / 754.0;
    double dwr_dtau = 0.0;
    double tau_pow = 1.0;

    for (int i = 1; i <= 9; ++i) {
        dwr_dtau += (double)i * C_COEFF[i] * tau_pow;
        tau_pow *= tau;
    }
    return dwr_dtau / 754.0;
}

/**
 * @brief Точне обчислення T90 за виміряним опором SPRT
 * @param r_measured_ohm Виміряний опір SPRT (Ом)
 * @param cal Вказівник на калібрувальні константи термометра
 * @param out_t90_celsius Вказівник на результат у градусах Цельсія
 * @return true у разі успішного збігу
 */
bool its90_calculate_temperature(double r_measured_ohm, 
                                 const its90_sprt_calibration_t *cal, 
                                 double *out_t90_celsius) 
{
    if (cal == NULL || out_t90_celsius == NULL || cal->r_tpw_ohm <= 0.0) {
        return false;
    }

    /* 1. Обчислення безрозмірного відношення W */
    double w = r_measured_ohm / cal->r_tpw_ohm;

    /* 2. Обчислення індивідуального відхилення Delta_W */
    double w_minus_1 = w - 1.0;
    double delta_w = (cal->a_coeff * w_minus_1) + 
                     (cal->b_coeff * w_minus_1 * w_minus_1) + 
                     (cal->c_coeff * w_minus_1 * w_minus_1 * w_minus_1);

    /* 3. Отримання опорного значення Wr */
    double wr_target = w - delta_w;

    /* 4. Метод Ньютона-Рафсона для точного розв'язання рівняння Wr(T90) = wr_target */
    double t_est = 273.15 + (wr_target - 1.0) / 0.00398; /* Початкове лінійне наближення */

    for (int iter = 0; iter < 6; ++iter) {
        double wr_current = its90_calc_wr(t_est);
        double dwr_dt = its90_calc_dwr_dt(t_est);
        double diff = wr_current - wr_target;

        t_est -= diff / dwr_dt;

        if (fabs(diff) < 1.0e-8) {
            break; /* Збіжність до похибки < 0.00001 мК */
        }
    }

    *out_t90_celsius = t_est - 273.15;
    return true;
}
```

## 5. Взаємозв'язок ITS-90, IPTS-68 та промислового стандарту IEC 60751

У промисловості та інженерних розрахунках часто виникає потреба порівняння результатів за шкалою ITS-90 з історичними даними шкали IPTS-68 або з робочими датчиками IEC 60751.

### Різниця між шкалами T_90 та T_68

При переході від старої шкали IPTS-68 до ITS-90 у 1990 році відбулося уточнення температур реперних точок, що спричинило стрибкоподібне зміщення чисельних значень:

```
Delta_T = T_90 - T_68
```

- При 0 °C: `Delta_T = 0.000 °C` (збігається за визначенням потрійної точки води).
- При +40 °C: `T_90` нижча за `T_68` на **-0.038 °C**.
- При +100 °C (точка кипіння води за старою шкалою): `T_90 = 99.974 °C` (зсув становить **-0.026 °C**).
- При +600 °C: `T_90` нижча на **-0.210 °C**.
- При +1000 °C: різниця сягає **-0.450 °C**.

Усі сучасні термопарні градуювальні таблиці (ДСТУ/IEC 60584-1) та стандарти термометрів опору (IEC 60751) були повністю перераховані під шкалу ITS-90.

### Співвідношення між ITS-90 та промисловим стандартом IEC 60751

Промислові датчики PT100/PT1000 описуються квадратичним рівнянням Календара-Ван Дюзена:

```
R(T) = R_0 * (1 + A * T + B * T^2)
```

Хоча параметри A і B в стандарті IEC 60751 були підігнані до шкали ITS-90, різниця у формі математичних функцій (квадратична парабола IEC проти поліному 9-го ступеня ITS-90) створює залишкову нелінійну розбіжність:
- У діапазоні 0..100 °C відхилення між моделлю IEC 60751 та первинною шкалою ITS-90 становить не більше **0.015 °C**.
- У діапазоні 200..500 °C розбіжність досягає **0.05–0.08 °C**.

Для стандартних промислових процесів ця різниця є незначною, проте в калібрувальних лабораторіях вищої точності цифрові вимірювальні трансмітери програмують на пряму роботу з опорними поліномами ITS-90.
