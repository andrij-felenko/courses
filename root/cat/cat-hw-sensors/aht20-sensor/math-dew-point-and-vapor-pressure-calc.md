# Математичні формули розрахунку точки роси та насиченої пари

## Перетворення сирих 20-бітних відліків AHT20

Обробка даних цифрового давача влаштована так, що пристрій видає не готові фізичні величини, а двійкові коди внутрішнього аналого-цифрового перетворювача. Цифровий давач @@en|AHT20@@ передає показання по шині @@en|I2C@@ (англ. @@en|Inter-Integrated Circuit@@, міжмікросхемне з'єднання) у вигляді кадру з шести байтів. Для мікроконтролера ці байти є необробленими відліками (англ. @@en|raw data@@, сирі дані), які потребують математичного розпакування та масштабування. На відміну від застарілих 8-бітних давачів вологості, які ділять весь вимірювальний діапазон лише на 256 дискретних рівнів (що забезпечує роздільну здатність лише 1% вологості та 1 °C), 20-бітний @@en|АЦП@@ (від українського *аналого-цифровий перетворювач*) давача @@en|AHT20@@ забезпечує більше мільйона дискретних кроків, що дозволяє фіксувати найменші коливання мікроклімату з роздільною здатністю до 0.024% відносної вологості та 0.0002 °C.

Внутрішня схема @@en|AHT20@@ квантує виміряні параметри з роздільною здатністю 20 бітів. Повний діапазон 20-бітного числа становить `2²⁰ = 1048576` дискретних рівнів (від 0 до 1048575). У кадровому пакеті ці 20-бітні поля розділені між байтами: третій байт містить старші 4 біти вологості та молодші 4 біти температури.

![Розрозподіл 20-бітних полів вологості та температури в байтовому кадрі AHT20](img/aht20-bit-unpacking.svg)
*Структура кадру показує зсув бітів та розподіл третього байта між вологістю й температурою.*

Бінарні значення вологості `S_RH` та температури `S_T` відновлюються з масиву `data` за допомогою побітових зсувів:

```
S_RH = (data[1] << 12) | (data[2] << 4) | (data[3] >> 4)
S_T  = ((data[3] & 0x0F) << 16) | (data[4] << 8) | data[5]
```

Отримані значення перетворюються у відносну вологість `RH` (англ. @@en|relative humidity@@, відносна вологість у відсотках) та температуру `T` у градусах Цельсія. Подібно до давачів серії [AHT20 та BMP280](root:cat-hw-sensors/aht20-bmp280), лінійне масштабування охоплює повну шкалу АЦП:

```
RH = (S_RH / 1048576) × 100      [масштабування вологості від 0 до 100%]
T  = (S_T / 1048576) × 200 - 50  [масштабування температури від -50 до +150 °C]
```

**Обчислення для сирих відліків `S_RH = 576716` та `S_T = 393216`:**
```
RH = (576716 / 1048576) × 100
   = 0.550003 × 100              [ділення на 2²⁰]
   = 55.0 %                      [відносна вологість]

T  = (393216 / 1048576) × 200 - 50
   = 0.375 × 200 - 50            [ділення на 2²⁰]
   = 75.0 - 50                   [множення на діапазон 200 °C]
   = 25.0 °C                     [зсув шкали на -50 °C]
```

## Обчислення тиску насиченої та актуальної водяної пари

Показник відносної вологості `RH = 55%` сам по собі не визначає фізичну кількість вологи в повітрі, оскільки здатність повітря утримувати водяну пару нелінійно зростає з підвищенням температури. На відміну від первинних вимірювань [давача DHT11](root:cat-hw-sensors/dht11), де відображаються лише відсотки насичення, для автоматики вентиляції необхідно знати парціальний тиск водяної пари. У разі застосування формули за від'ємних температур (нижче 0 °C) стандартні коефіцієнти Магнуса `b = 17.67` та `c = 243.5 °C` втрачають точність, оскільки над льодом тиск насиченої пари є нижчим, ніж над переохолодженою водою, тому за умов замерзання використовують скориговані емпіричні коефіцієнти `b = 22.46` та `c = 272.62 °C`. Для вирахування точного тиску насиченої пари застосовується [формула Магнуса-Тетенса](root:cat-hw-sensors/magnus-formula).

Максимально можливий тиск водяної пари за даної температури називається тиском насиченої пари `P_s` (латин. @@en|vapor pressure@@, тиск випарів). Для його обчислення в діапазоні від 0 до 50 °C застосовують наближену формулу @@en|Magnus-Tetens@@:

```
P_s(T) = a × exp((b × T) / (c + T))
P_a    = P_s(T) × (RH / 100)

де:
a = 6.112 hPa (тиск насиченої пари при 0 °C)
b = 17.67     (безрозмірний емпіричний коефіцієнт)
c = 243.5 °C  (температурна константа зсуву)
```

Тиск насиченої пари `P_s` вимірюється в гектопаскалях (гПа, або `hPa`). Актуальний парціальний тиск `P_a` дорівнює частці від тиску насичення відповідно до поточного значення `RH`.

**Обчислення тиску пари при `T = 25.0 °C` та `RH = 55.0 %`:**
```
b × T             = 17.67 × 25.0 = 441.75
c + T             = 243.5 + 25.0 = 268.5
(b × T) / (c + T) = 441.75 / 268.5 = 1.645251

P_s(25.0)         = 6.112 × exp(1.645251)
                  = 6.112 × 5.18231               [значення експоненти]
                  = 31.674 hPa                    [тиск насиченої пари при 25 °C]

P_a               = 31.674 × (55.0 / 100)
                  = 31.674 × 0.55                 [частка відносної вологості]
                  = 17.421 hPa                    [парціальний тиск пари]
```

## Розрахунок точки роси та абсолютної вологості

Коли вологе повітря охолоджується при постійному тиску, його відносна вологість зростає до межі 100%. Температура, за якої парціальний тиск водяної пари `P_a` стає рівним тиску насичення `P_s`, називається температурою точки роси `T_d` (англ. @@en|dew point@@, точка випадання роси). Якщо поверхня холодніша за `T_d`, на ній випадає конденсат. За умов значних змін атмосферного тиску (наприклад, у високогірних районах чи барокамерах) розраховану точку роси додатково коригують за формулою залежності від барометричного тиску, оскільки зниження зовнішнього тиску прискорює випаровування та знижує парціальний тиск водяної пари при сталій відносній вологості.

Для обчислення `T_d` рівняння @@en|Magnus-Tetens@@ перетворюють відносно температури, вводячи проміжний логарифмічний коефіцієнт `γ(T, RH)`:

```
γ(T, RH) = ln(RH / 100) + (b × T) / (c + T)
T_d      = (c × γ(T, RH)) / (b - γ(T, RH))
```

Абсолютна вологість `AH` (латин. @@en|absolutus@@, безумовна вологість) визначає масу водяної пари в одному кубічному метрі повітря (г/м³). На відміну від непрямих вимірювань, для порівняння з поверхневою температурою через [давач DS18B20](root:cat-hw-sensors/ds18b20) розрахунок `AH` виконують через рівняння стану ідеального газу:

```
AH = (216.7 × P_a) / (273.15 + T)

де:
216.7 — абсолютний газовий коефіцієнт для водяної пари (г·К/гПа·м³)
273.15 + T — абсолютна температура повітря в кельвінах (K)
```

**Обчислення точки роси та абсолютної вологості при `T = 25.0 °C`, `RH = 55.0 %` і `P_a = 17.421 hPa`:**
```
ln(55.0 / 100) = ln(0.55) = -0.597837
(b × T) / (c + T) = 1.645251

γ(25.0, 55.0)  = -0.597837 + 1.645251
               = 1.047414                     [значення проміжної змінної γ]

T_d            = (243.5 × 1.047414) / (17.67 - 1.047414)
               = 255.045 / 16.622586          [ділення за оберненою формулою]
               = 15.34 °C                     [температура точки роси]

AH             = (216.7 × 17.421) / (273.15 + 25.0)
               = 3776.1307 / 298.15           [розрахунок маси пари в 1 м³]
               = 12.675 g/m³                  [абсолютна вологість]
```
