## Неперервне вимірювання проти порогової комутації

Дискретні цифрові давачі Холла (такі як A3144 чи SS41F) чудово підходять для бінарних задач: фіксації крайнього положення штока, відкриття дверей або підрахунку кількості обертів вала. Проте вони мають принципове обмеження: цифрові ключі не несуть інформації про точну відстань до об'єкта, швидкість його переміщення чи амплітуду магнітного поля у проміжних точках.

Для задач плавного пропорційного керування — електронних педалей газу, промислових джойстиків, давачів кута повороту дросельної заслінки, безконтактних потенціометрів та вимірювачів струму — необхідний неперервний аналоговий сигнал. Цю задачу вирішують лінійні давачі Холла (наприклад, поширені мікросхеми SS49E, A1302, A1324).

На відміну від цифрових ключів, лінійний давач не має внутрішнього тригера Шмітта. Його вихідний каскад генерує неперервну аналогову напругу, суворо пропорційну векторній величині та напрямку перпендикулярної магнітної індукції `B`.

## Внутрішня архітектура та напруга спокою

Монолітна структура лінійного давача Холла містить повний аналоговий тракт:

1. **Напівпровідникова пластина Холла:** тонка кремнієва або арсенід-галієва пластина, крізь яку стабілізатор пропускає постійний струм зміщення. Сила Лоренца відхиляє носії заряду до граней, утворюючи первинну ЕРС Холла `V_H` порядку кількох мікровольтів на Гаус.
2. **Диференційний підсилювач:** масштабує мікровольтовий потенціал із коефіцієнтом підсилення у кілька сотень разів.
3. **Схема формування зсуву спокою (Quiescent Voltage):** задає рівноважну напругу за відсутності зовнішнього магнітного поля (`B = 0` Гаус) рівно на рівні половини живлення:
```
V_0 = VCC / 2
```
Це дозволяє давачу реєструвати магнітні поля обох полярностей при однополярному живленні:
- **Південний полюс (B > 0):** вихідна напруга плавно зростає від `VCC / 2` до верхньої шини насичення (до `VCC - 0.2 В`).
- **Північний полюс (B < 0):** вихідна напруга плавно спадає від `VCC / 2` до нижньої шини насичення (до `0.2 В`).

## Раціометричний вихід та захист від нестабільності живлення

Критичною схемотехнічною властивістю більшості лінійних сенсорів є раціометричність вихідного сигналу (ratiometric output). Це означає, що як напруга спокою `V_0`, так і чутливість `S` (у мВ/Гс або мВ/мТл) лінійно масштабуються пропорційно фактичній напрузі живлення `VCC`:

```
V_out = (VCC / 2) + S_nom * (VCC / VCC_nom) * B
```

**Чому це важливо на практиці?**
У типових схемах на мікроконтролерах опорною напругою вбудованого АЦП (`V_REF`) слугує та сама шина живлення `VCC`. Якщо напруга живлення нестабільна або просідає на кілька відсотків під навантаженням, вихідна напруга давача `V_out` пропорційно зменшиться на такий самий відсоток. Внаслідок цього цифровий код АЦП, який обчислюється як відношення:

```
ADC_Code = (V_out / V_REF) * (2^N - 1)
```

залишається абсолютно стабільним та незмінним. Раціометрична взаємодія повністю компенсує дрейф і пульсації живлення без необхідності застосування дорогих зовнішніх джерел опорної напруги.

## Чопперна стабілізація та її компроміси

Власна напруга зсуву кремнієвої пластини, викликана механічними напруженнями у кристалі та температурними коливаннями, може перевищувати корисний сигнал у слабких магнітних полях. Для її пригнічення в сучасних сенсорах використовують чопперну стабілізацію (динамічне обнулення зсуву):
- Мостовий комутатор періодично повертає напрямок струму живлення крізь пластину Холла на 90° з тактовою частотою `f_clk` (100–400 кГц).
- Корисний сигнал переноситься на частоту тактування, підсилюється AC-підсилювачем без температурного дрейфу нуля, випрямляється синхронним демодулятором назад у постійну напругу, а залишковий високочастотний офсет зрізається внутрішнім фільтром низьких частот (ФНЧ).

**Інженерні компроміси чоппування:**
1. **Обмеження смуги пропускання:** вбудований ФНЧ обмежує максимальну смугу вимірюваного магнітного поля діапазоном 10–80 кГц.
2. **Часова затримка відгуку:** фільтрація вносить затримку сигналу 10–50 мкс, що слід враховувати у швидкодіючих системах керування приводами.
3. **Тактовий шум:** на виході присутні незначні мікровольтові пульсації тактової частоти чоппера, які усувають зовнішнім RC-фільтром.

## Схемотехніка узгодження з АЦП мікроконтролера

Для якісного оцифрування аналогового сигналу давача Холла (наприклад, SS49E) мікроконтролером (STM32, ESP32, AVR) застосовують типову апаратну обв'язку:

1. **Блокувальний конденсатор:** керамічний конденсатор ємністю 100 нФ встановлюють безпосередньо біля виводів живлення VCC та GND сенсора для придушення високочастотних імпульсних наводок.
2. **Протиаліасинговий RC-фільтр:** між аналоговим виходом давача та входом АЦП монтують резистор `R = 1 кОм` та конденсатор `C = 10..100 нФ` на землю:
```
f_c = 1 / (2 * pi * R * C) ≈ 1.59 кГц (при C = 100 нФ)
```
Цей фільтр ефективно гасить залишкові пульсації чоппування та одночасно створює резервуар заряду для внутрішнього конденсатора вибірки-зберігання (S&H) АЦП мікроконтролера.

## Нелінійність магнітного поля та програмна лініаризація

При вимірюванні лінійного переміщення виникає фізична нелінійність: індукція постійного магніту спадає з відстанню не за лінійним законом, а пропорційно `1 / d³` у дальній зоні та за складною експоненційною функцією у ближній зоні.

Для перетворення виміряної напруги в реальну відстань у міліметрах застосовують два програмні підходи:
- **Look-Up Table (LUT):** заздалегідь знята калібрувальна таблиця контрольних точок із лінійною інтерполяцією між сусідніми вузлами. Забезпечує високу точність при мінімальних витратах процесорного часу.
- **Поліноміальна апроксимація:** опис залежності відстані від напруги поліномом 3-го степеня `d(V) = c0 + c1*V + c2*V² + c3*V³`. Економить оперативну пам'ять і дає гладку аналітичну криву.

Повний математичний аналіз раціометричності, розрахунок шумів, фільтрів та програмні драйвери оцифрування наведено в матеріалі [Аналогові та лінійні давачі Холла (поглиблено)](root:cat-hw-sensors/linear-hall-effect-sensors/linear-hall-effect-sensors-d).
