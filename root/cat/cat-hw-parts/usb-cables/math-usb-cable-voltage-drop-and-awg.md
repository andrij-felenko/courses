# Падіння напруги в кабелях USB та вибір калібру провідників AWG

## Електрична структура USB-кабелю та фізична модель замкненого кола (VBUS + GND)

У практичній схемотехніці та системній інженерії USB-кабель помилково розглядають як ідеальний провідник із нульовим опором. Проте з математичної та фізичної точок зору кабель живлення являє собою розподілене двопровідне електричне коло з послідовно ввімкненими паразитними опорами провідників та контактних переходів роз'ємів.

Головним принципом розрахунку постійного струму в кабельних лініях є концепція замкненого кола: електричний струм `I`, що витікає з джерела живлення (англ. @@en|Downstream Facing Port@@, @@en|DFP@@) по силовій жилі `VBUS`, проходить через навантаження споживача (англ. @@en|Upstream Facing Port@@, @@en|UFP@@) і обов'язково повертається назад до джерела по зворотній жилі спільної землі (`GND`, від англ. @@en|Ground@@). 

![Еквівалентна електрична схема двопровідного лінійного кола USB-кабелю з урахуванням опору жил VBUS, GND та чотирьох контактних переходів роз'ємів](img/usb-cable-equivalent-circuit.svg)
*Еквівалентна електрична схема двопровідного лінійного кола USB-кабелю з урахуванням опору жил VBUS, GND та чотирьох контактних переходів роз'ємів.*

Еквівалентна електрична схема кола містить чотири основні компоненти опору, з'єднані послідовно:
1. Активний опір прямої мідної жили `VBUS` довжиною `L`: `R_wire_vbus`.
2. Активний опір зворотної мідної жили `GND` довжиною `L`: `R_wire_gnd`.
3. Сумарний контактний опір переходів штекер–гніздо лінії `VBUS` на обох кінцях кабелю: `R_contact_vbus`.
4. Сумарний контактний опір переходів штекер–гніздо лінії `GND` на обох кінцях кабелю: `R_contact_gnd`.

Повний еквівалентний опір кабельної петлі `R_loop` розраховується як сума всіх послідовних елементів:

```
R_loop = R_wire_vbus + R_wire_gnd + R_contact_vbus + R_contact_gnd
```

У більшості симетричних кабелів провідники `VBUS` та `GND` виконано з дроту однакового калібру (`R_wire_vbus = R_wire_gnd = R_wire`), а контактні групи роз'ємів джерела та споживача мають ідентичну конструкцію (`R_contact_src = R_contact_snk = R_contact`). За таких умов математична модель розрахунку повного опору петлі спрощується до вигляду:

```
R_loop = 2 · R_wire + 2 · R_contact
```

Множник `2` при опорі жили `R_wire` відображає той фізичний факт, що струм долає подвійну геометричну довжину траси `2 · L` (туди й назад). Ігнорування опору зворотної жили `GND` або контактного опору роз'ємів у розрахунках призводить до систематичної помилки під час оцінки падіння напруги, що може викликати збої в роботі чутливих мікроконтролерів та периферійних пристроїв.

Для визначення підсумкових електричних характеристик кабелю необхідно послідовно розрахувати складові `R_wire` та `R_contact` на основі геометричних параметрів провідників та специфікацій з'єднувачів.

## Математичний апарат розрахунку опору жил (стандарт AWG)

Опір суцільного металевого провідника з постійним поперечним перерізом описується класичним законом Ома:

```
R_wire = ρ · L ÷ S
```

де `ρ` — питомий електричний опір матеріалу провідника (для електротехнічної відпаленої міді при температурі `T = 20 °C` приймається значення `ρ_Cu = 0.01724 Ом·мм²/м` або `1.724 · 10⁻⁸ Ом·м`), `L` — фізична довжина кабелю в метрах, а `S` — площа поперечного перерізу струмопровідної жили в квадратних міліметрах.

У кабельній індустрії геометричні розміри жил стандартизовано за американською системою калібрів дротів (англ. @@en|American Wire Gauge@@, @@en|AWG@@). Система @@en|AWG@@ є геометричною прогресією, у якій номер калібру `n` обернено пропорційний діаметру провідника: чим більший номер калібру, тим тонший дріт.

Математична залежність діаметра суцільної мідної жили `d_n` (в міліметрах) від номера калібру `n` виражається експоненційною формулою:

```
d_n = 0.127 · 92^((36 - n) ÷ 39)
```

Відповідно, площа поперечного перерізу жили `S_n` (в мм²) розраховується як площа круга:

```
S_n = (π ÷ 4) · d_n²
= (π ÷ 4) · [0.127 · 92^((36 - n) ÷ 39)]²
```

З математичних властивостей цієї геометричної прогресії випливають три важливі інженерні правила:
1. Зміна калібру на 3 кроки (`Δn = 3`) змінює площу перерізу `S` та активний опір `R_wire` приблизно вдвічі. Зменшення калібру на 3 одиниці (наприклад, з AWG 24 до AWG 21) подвоює площу міді й зменшує опір удвічі.
2. Зміна калібру на 6 кроків (`Δn = 6`) змінює діаметр жили `d` вдвічі, а площу перерізу `S` — у 4 рази.
3. Зміна калібру на 10 кроків (`Δn = 10`) змінює площу перерізу та опір приблизно в 10 разів.

У табл. 1 зведено математичні та електричні параметри мідних провідників стандартних калібрів @@en|AWG@@, які застосовуються в силових та сигнальних лініях [USB-кабелів](root:cat-hw-parts/usb-cables) та [монтажних дротів](root:cat-hw-parts/hookup-wire).

Під час проходження електричного струму провідники кабелю нагріваються. Питомий опір міді має додатний температурний коефіцієнт (англ. @@en|temperature coefficient of resistance@@) `α_Cu ≈ 0.00393 K⁻¹`. Зміна опору жили при розігріві від початкової температури `T₀ = 20 °C` до робочої температури `T` описується лінійною моделью:

```
R_wire(T) = R_wire(20) · [1 + α_Cu · (T - 20)]
```

Якщо внаслідок тривалого проходження високого струму кабель розігрівається до `T = 70 °C` (`ΔT = 50 °C`), його опір зростає на:

```
ΔR_rel = 0.00393 · 50
= 0.1965                         [зростання опору на 19.65%]
```

**Розрахунок опору жил кабелю завдовжки 1.5 м для AWG 28 та AWG 20**

Порівняємо активний опір однієї мідної жили `R_wire` для кабелю довжиною `L = 1.5 м`, виконаного тонким сигнальним дротом AWG 28 та силовим дротом AWG 20 при `T = 20 °C`:

```
R_wire_AWG28 = ρ_Cu · L ÷ S_AWG28
= 0.01724 · 1.5 ÷ 0.0810         [підстановка питомого опору міді, довжини та площі AWG 28]
= 0.02586 ÷ 0.0810               [обчислення чисельника]
≈ 0.3193 Ом                      [опір однієї жили AWG 28]

R_wire_AWG20 = ρ_Cu · L ÷ S_AWG20
= 0.01724 · 1.5 ÷ 0.518          [підстановка параметрів для AWG 20]
= 0.02586 ÷ 0.518                [обчислення чисельника]
≈ 0.0499 Ом                      [опір однієї жили AWG 20]
```

Збільшення калібру з AWG 28 до AWG 20 зменшує опір провідника в 6.4 раза при тій самій довжині кабелю.

## Аналіз контактного опору роз'ємів (R_contact) та паралельних ліній USB Type-C

Контактний опір роз'єму `R_contact` (англ. @@en|contact resistance@@) виникає на межі зіткнення штирового й гніздового металевих контактів. Він не є суто омічним опором суцільного металу, а складається з двох фізичних величин:

```
R_contact = R_struction + R_film
```

де `R_struction` — опір звуження (стягування ліній струму у мікроскопічних точках фактичного механічного контакту плями підтиску), а `R_film` — опір поверхневих оксидних, сульфідних та оливних плівок (ефект фретинг-корозії, англ. @@en|fretting corrosion@@).

Для стандартних роз'ємів USB Type-A, Micro-USB та Mini-USB опір однієї контактної пари в новому стані становить від `30 мОм` до `50 мОм` (`0.030–0.050 Ом`). У процесі експлуатації (після 500–1000 циклів з'єднання) внаслідок зносу золочення та окиснення контактний опір зростає до `80–150 мОм`.

Конструкція сучасного стандарту USB Type-C має принципову математичну та електричну перевагу. Роз'єм Type-C містить 24 контакти, серед яких під силі лінії живлення виділено по 4 паралельні піни для `VBUS` (контакти A4, A9, B4, B9) та по 4 паралельні піни для `GND` (контакти A1, A12, B1, B12).

![Схема паралельного з'єднання чотирьох контактних груп VBUS і GND у роз'ємі USB Type-C](img/usb-type-c-parallel-contacts.svg)
*Схема паралельного з'єднання чотирьох контактних груп VBUS і GND у роз'ємі USB Type-C для зниження еквівалентного контактного опору.*

Коли до кабелю підключено повнофункціональний роз'єм Type-C, струм `I` рівномірно розподіляється між `N_pins = 4` паралельно з'єднаними контактами. Еквівалентний контактний опір одного з'єднання `R_contact_eff` розраховується за формулою паралельних опорів:

```
R_contact_eff = R_pin ÷ N_pins
```

Якщо опір поодинокого контакту становить `R_pin = 40 мОм`, то для роз'єму Type-C з чотирма паралельними пінами отримаємо:

```
R_contact_eff = 40 ÷ 4
= 10 мОм                         [0.010 Ом на один кінець кабелю]
```

Завдяки мультиконтактному паралельному з'єднанню сумарний контактний опір роз'ємів USB Type-C у 4 рази менший за показники застарілих роз'ємів Micro-USB або [сигнальних з'єднувачів JST](root:cat-hw-parts/jst-sm-connectors).

**Порівняльний розрахунок опору петлі R_loop для Micro-USB та USB Type-C кабелів**

Обчислимо повний опір петлі `R_loop` для двох кабелів однакової довжини `L = 1.0 м`:
1. Кабель Micro-USB: жила AWG 28 (`S = 0.0810 мм²`), `R_contact` одного з'єднання `40 мОм` (по 1 контакту на VBUS і GND).
2. Кабель USB Type-C: жила AWG 22 (`S = 0.326 мм²`), `R_contact_eff` одного з'єднання `10 мОм` (по 4 паралельні контакти).

```
[Кабель 1: Micro-USB, AWG 28, L = 1.0 м]
R_wire = 0.01724 · 1.0 ÷ 0.0810
≈ 0.2128 Ом                      [опір однієї жили]

R_loop_micro = 2 · R_wire + 2 · (R_contact_vbus + R_contact_gnd)
= 2 · 0.2128 + 2 · (0.040 + 0.040) [врахування двох жил та контактів на обох кінцях]
= 0.4256 + 0.1600                [сумування опору жил та контактів]
= 0.5856 Ом                      [повний опір петлі Micro-USB кабелю]

[Кабель 2: USB Type-C, AWG 22, L = 1.0 м]
R_wire = 0.01724 · 1.0 ÷ 0.326
≈ 0.0529 Ом                      [опір однієї жили]

R_loop_typec = 2 · R_wire + 2 · (R_contact_eff_vbus + R_contact_eff_gnd)
= 2 · 0.0529 + 2 · (0.010 + 0.010) [врахування жил AWG 22 та паралельних контактів]
= 0.1058 + 0.0400                [сумування опору жил та контактів]
= 0.1458 Ом                      [повний опір петлі Type-C кабелю]
```

Підсумковий опір петлі якісного Type-C кабелю виявився в 4 рази меншим за опір стандартного Micro-USB кабелю, що принципово змінює умови передачі високих струмів живлення.

## Математика падіння напруги (ΔV) та явище просідання напруги на навантаженні (UFP Brownout)

Згідно із законом Ома для ділянки кола, проходження струму живлення `I` через опір кабельної петлі `R_loop` спричиняє падіння напруги `ΔV`:

```
ΔV = I · R_loop
= I · (2 · R_wire + 2 · R_contact)
```

Напруга, яка реально доходить до роз'єму споживача `U_load` (UFP), дорівнює вихідній напрузі джерела живлення `U_source` мінус падіння напруги в кабелі:

```
U_load = U_source - ΔV
= U_source - I · R_loop
```

Специфікація USB 2.0 та стандарт заряджання @@en|USB BC 1.2@@ (англ. @@en|Battery Charging Specification v1.2@@) встановлюють номінальну напругу джерела `U_source = 5.00 В` з допустимим технологічним розкидом `4.75–5.25 В`. При цьому для надійного функціонування контролерів заряду та мікроконтролерних систем мінімально припустима напруга на вході споживача `U_load_min` при максимальному струмі `I = 1.5 А` не повинна опускатися нижче `4.40 В`.

Це визначає максимально припустиме падіння напруги в кабелі `ΔV_max`:

```
ΔV_max = U_source_min - U_load_min
= 4.75 - 4.40
= 0.35 В                         [гранично припустиме падіння напруги]
```

Якщо еквівалентний опір кабелю `R_loop` перевищує критичне значення `R_loop_crit = ΔV_max ÷ I = 0.35 ÷ 1.5 ≈ 0.233 Ом`, напруга на споживачі просідає нижче `4.40 В`.

**Механізм скидання струму (Charger Throttling / VINDPM)**

Сучасні інтелектуальні контролери заряду акумуляторів (наприклад, мікросхеми PMIC у смартфонах та повербанках) оснащено функцією динамічного керування вхідним струмом за напругою (англ. @@en|Input Voltage Dynamic Power Management@@, @@en|VINDPM@@). 

Коли контролер намагається збільшити струм споживання `I`, а високий опір кабелю `R_loop` викликає просідання вхідної напруги `U_load` нижче безпечного порогу `U_th ≈ 4.50 В`, спрацьовує захисний алгоритм обмеження струму (англ. @@en|Brownout prevention@@). Контролер припиняє подальше нарощування струму й примусово фіксує його на нижчому рівні `I_reduced` (наприклад, `0.5 А` замість `2.0 А`), щоби втримати напругу `U_load` на рівні `4.50 В`.

Вираз для відновленого струму в режимі обмеження `VINDPM` виводиться з рівняння напруги:

```
I_reduced = (U_source - U_th) ÷ R_loop
```

> 🔧 **Навіщо це.**
> Математична модель просідання напруги пояснює явище «повільного заряджання»: коли пристрій підключено через торокуватий кабель із високим `R_loop`, контролер заряду не «згорає» і не вимикається, а автоматично скидає струм у 2–4 рази. Зовні кабель здається робочим, але час заряджання батареї зростає з 1.5 години до 5–6 годин.

**Обчислення просідання напруги та режиму VINDPM для двох 2-метрових кабелів під навантаженням 2.0 А**

Розглянемо джерело живлення з виходом `U_source = 5.00 В` та порівняємо два кабелі довжиною `L = 2.0 м` при спробі споживача відібрати струм `I = 2.0 А`:
- Кабель A (бюджетний): жила AWG 28 (`R_1m = 0.2128 Ом/м`), роз'єми Micro-USB (`R_contact_total = 0.160 Ом`).
- Кабель B (високоякісний): жила AWG 20 (`R_1m = 0.0333 Ом/м`), роз'єми Type-C (`R_contact_total = 0.040 Ом`).

```
[Кабель A: Бюджетний 2.0 м, AWG 28, Micro-USB]
R_wire = 0.2128 · 2.0 = 0.4256 Ом
R_loop_A = 2 · 0.4256 + 0.1600 = 1.0112 Ом

ΔV_ideal = I · R_loop_A
= 2.0 · 1.0112 = 2.0224 В        [теоретичне падіння напруги]

U_load_theoretical = 5.00 - 2.0224
= 2.9776 В                       [критичне просідання нижче порогу 4.50 В]

I_actual_VINDPM = (U_source - U_th) ÷ R_loop_A
= (5.00 - 4.50) ÷ 1.0112
= 0.50 ÷ 1.0112
≈ 0.494 А                        [автоматично обмежений струм заряджання]

[Кабель B: Силовой 2.0 м, AWG 20, Type-C]
R_wire = 0.0333 · 2.0 = 0.0666 Ом
R_loop_B = 2 · 0.0666 + 0.0400 = 0.1732 Ом

ΔV_B = I · R_loop_B
= 2.0 · 0.1732 = 0.3464 В        [фактичне падіння напруги]

U_load_B = 5.00 - 0.3464
= 4.6536 В                       [напруга вище порогу 4.50 В, струм 2.0 А зберігається]
```

Кабель A викликає просідання напруги до критичних `2.98 В`, через що контролер пристрою скидає струм з 2.0 А до 0.49 А. Кабель B утримує напругу на рівні `4.65 В`, забезпечуючи повноцінний режим швидкого заряджання.

## Теплові втрати потужності (P_loss) та математичне обґрунтування високовольтних режимів (USB PD)

Електрична енергія, яка втрачається в кабелі під час передачі живлення, перетворюється на тепло відповідно до закону Джоуля-Ленца. Теплова потужність втрат `P_loss` розраховується через квадрат струму та повний опір петлі:

```
P_loss = I² · R_loop
```

Коефіцієнт корисної дії (ККД, `η`) передачі електричної потужності від джерела до споживача визначається як відношення корисної потужності на навантаженні `P_load = U_load · I` до повної потужності джерела `P_source = U_source · I`:

```
η = P_load ÷ P_source
= (U_load · I) ÷ (U_source · I)
= U_load ÷ U_source
= (U_source - I · R_loop) ÷ U_source
= 1 - (I · R_loop ÷ U_source)
```

Аналіз цієї формули показує: при сталій переданій потужності `P_target = U_source · I` збільшення струму `I` призводить до квадратичного зростання втрат `P_loss ~ I²`.

**Математичний доказ переваги підвищення напруги (стандарти Quick Charge та USB Power Delivery)**

Виразимо струм живлення `I` через цільову потужність `P_target` та напругу джерела `U_source`:

```
I = P_target ÷ U_source
```

Підставимо отриманий вираз у формулу втрат потужності `P_loss`:

```
P_loss = (P_target ÷ U_source)² · R_loop
= (P_target² · R_loop) ÷ U_source²
```

Звідси випливає фундаментальний математичний закон високовольтних протоколів заряджання (англ. @@en|USB Power Delivery@@, @@en|USB PD@@; @@en|Quick Charge@@, @@en|QC@@): **при незмінній переданій потужності `P_target` теплові втрати в кабелі `P_loss` обернено пропорційні квадрату напруги джерела `U_source²`**.

Якщо збільшити напругу живлення у `k` разів при незмінній потужності `P_target`:
- Струм `I` зменшується у `k` разів.
- Падіння напруги у відносних відсотках `ΔV / U_source` зменшується у `k²` разів.
- Теплові втрати в кабелі `P_loss` зменшуються у `k²` разів.

**Розрахунок втрат потужності при передачі 15 Вт для режимів 5 В / 3 А та 9 В / 1.67 А**

Порівняємо передачу потужності `P_target = 15 Вт` через кабель з опором петлі `R_loop = 0.20 Ом`:
1. Режим USB Type-C Standard: `U_source = 5.0 В`, `I = 3.0 А`.
2. Режим USB PD / QC: `U_source = 9.0 В`, `I = 1.67 А`.

```
[Режим 1: 5.0 В / 3.0 А (15 Вт)]
P_loss_5V = I² · R_loop
= (3.0)² · 0.20 = 9.0 · 0.20
= 1.80 Вт                        [теплові втрати в кабелі]

η_5V = 1 - (I · R_loop ÷ U_source)
= 1 - (3.0 · 0.20 ÷ 5.0)
= 1 - (0.60 ÷ 5.0) = 1 - 0.12
= 0.88                           [ККД = 88.0%]

[Режим 2: 9.0 В / 1.67 А (15 Вт)]
P_loss_9V = I² · R_loop
= (1.67)² · 0.20 = 2.7889 · 0.20
≈ 0.5578 Вт                      [теплові втрати в кабелі]

η_9V = 1 - (I · R_loop ÷ U_source)
= 1 - (1.67 · 0.20 ÷ 9.0)
= 1 - (0.334 ÷ 9.0) = 1 - 0.0371
≈ 0.9629                         [ККД = 96.3%]
```

Перехід з напруги 5 В на 9 В зменшив теплові втрати на нагрів кабелю з 1.80 Вт до 0.56 Вт (у 3.2 раза), підвищивши ККД системи з 88% до 96.3%.

## Математична модель граничного струму та розрахунок режимів USB PD EPR (48 V / 5 A)

Передача високої потужності в сучасній екосистемі USB Type-C нормується специфікаціями @@en|USB Power Delivery 3.1@@. Специфікація ділить кабелі на дві категорії за максимальним струмовим навантаженням:
1. Стандартні кабелі без електронного маркування (англ. @@en|non-e-Marked cables@@): обмежені граничним струмом `I_max = 3.0 А`.
2. Сертифіковані силові кабелі з електронною маркувальною мікросхемою (англ. @@en|Electronically Marked Cable Assembly@@, @@en|e-Marker IC@@): розраховані на струм `I_max = 5.0 А`.

Мікросхема @@en|e-Marker@@ вбудовується безпосередньо у штекер Type-C і передає контролерам джерела та споживача по сигнальній лінії `CC` (англ. @@en|Configuration Channel@@) цифровий протокол із параметрами допустимої напруги, струму та опору провідників. Якщо джерело живлення не виявляє чипа @@en|e-Marker@@, воно математично заблокує вихідні профілі зі струмом понад 3.0 А.

З виходом стандарту USB PD 3.1 впроваджено режим розширеного діапазону потужності (англ. @@en|Extended Power Range@@, @@en|EPR@@), який піднімає напругу живлення до `28 В`, `36 В` та `48 В` при граничному струмі `I = 5.0 А`. Це дозволяє передавати по USB-кабелю максимальну потужність:

```
P_max_EPR = U_max · I_max
= 48 · 5.0
= 240 Вт                         [гранична потужність стандарту USB PD 3.1 EPR]
```

**Теплова модель розігріву кабелю при струмі 5.0 А**

Проходження струму `I = 5.0 А` створює високі вимоги до перерізу жил `VBUS` та `GND`. Виділення теплової потужності в кабелі обчислюється як:

```
P_loss_5A = (5.0)² · R_loop
= 25 · R_loop
```

Якщо кабель має опір петлі `R_loop = 0.12 Ом`, то виділення тепла на довжині кабелю становитиме `P_loss = 25 · 0.12 = 3.0 Вт`.

Розрахунок перегріву зовнішньої силіконової або ПВХ-оболонки кабелю над температурою навколишнього середовища `T_amb` описується формулою теплового опору «кабель–повітря» `R_th_ca` (вимірюється в °C/Вт):

```
ΔT_cable = P_loss · R_th_ca
T_cable = T_amb + ΔT_cable
```

Для стандартного гнучкого кабелю діаметром 4.5 мм у стаціонарному повітряному середовищі тепловий опір становить `R_th_ca ≈ 18–22 °C/Вт` на 1 метр довжини. При `P_loss = 3.0 Вт` перегрів оболонки сягне `ΔT = 3.0 · 20 = 60 °C`. За температури навколишнього середовища `T_amb = 25 °C` температура кабелю підніметься до `85 °C`, що наближається до межі термостійкості звичайного ізоляційного пластику (90 °C).

Щоб обмежити теплові втрати значенням `P_loss ≤ 1.5 Вт` при струмі 5.0 А, опір петлі 1-метрового кабелю не повинен перевищувати:

```
R_loop_max_5A = P_loss_max ÷ I²
= 1.5 ÷ 25
= 0.060 Ом                       [60 мОм на весь кабель]
```

Це вимагає обов'язкового використання жил `VBUS` та `GND` калібру не менше **AWG 20–21** або застосування дубльованих мультижильних скруток.

**Підсумковий розрахунок режиму USB PD 3.1 EPR (48 В / 5 А, 240 Вт) для 2-метрового кабелю AWG 20 з e-Marker**

Проведемо повний розрахунок електричних та теплових параметрів для якісного 2-метрового силового кабелю USB PD 3.1 EPR (`L = 2.0 м`, жила AWG 20, `S = 0.518 мм²`, `R_contact_eff = 0.010 Ом` на з'єднання, наявний чип e-Marker):

```
R_wire = ρ_Cu · L ÷ S_AWG20
= 0.01724 · 2.0 ÷ 0.518
≈ 0.0666 Ом                      [опір однієї жили довжиною 2 м]

R_loop = 2 · R_wire + 2 · (R_contact_vbus + R_contact_gnd)
= 2 · 0.0666 + 2 · (0.010 + 0.010)
= 0.1332 + 0.0400
= 0.1732 Ом                      [повний опір петлі 2-метрового кабелю]

[Розрахунок режимів при струмі I = 5.0 А]

ΔV = I · R_loop
= 5.0 · 0.1732
= 0.866 В                        [абсолютне падіння напруги в кабелі]

U_load = U_source - ΔV
= 48.0 - 0.866
= 47.134 В                       [напруга на роз'ємі споживача UFP]

P_loss = I² · R_loop
= (5.0)² · 0.1732 = 25 · 0.1732
= 4.33 Вт                        [сумарне тепловиділення на всій довжині 2 м]

P_load = U_load · I
= 47.134 · 5.0
= 235.67 Вт                      [корисна потужність, передана споживачу]

η = P_load ÷ P_source
= 235.67 ÷ 240.0
≈ 0.9820                         [ККД передачі високої потужності = 98.2%]
```

Математичний розрахунок доводить: завдяки високій напрузі `48 В` навіть при значному падінні напруги `0.866 В` та тепловиділенні `4.33 Вт` на 2-метровій трасі ККД системи становить високі **98.2%**, що підтверджує енергетичну ефективність стандарту USB PD EPR для живлення потужних ноутбуків, зарядних станцій та промислової автоматики.
