## Проблеми живлення та висячих рівнів

При самостійній збірці схем на базі модулів ESP8266 розробники часто стикаються зі спонтанними перезавантаженнями пристрою, цикличною панікою ядра або висінням системи під час спроби встановити бездротове з'єднання. Причиною цієї поведінки є нерозраховане джерело живлення та відсутність схемотехнічної фіксації системних керуючих ліній.

Ключовим апаратним чинником фільтрації перехідних процесів у колі живлення є еквівалентний послідовний опір @@en|ESR@@ (від англ. @@en|Equivalent Series Resistance@@ — еквівалентний послідовний опір) вихідних конденсаторів. Під час активації випромінювача бездротового зв'язку в [архітектурі SoC ESP8266](root:cat-hw-boards/esp8266-soc-architecture-overview) споживання струму зростає стрибкоподібно за декілька наносекунд. За наявності розв'язувального конденсатора з високим значенням @@en|ESR@@ (наприклад, звичайного алюмінієвого електролітичного конденсатора з опором 1–2 Ом) імпульсний струм створює на його внутрішньому опорі миттєве спадання напруги `ΔV = I_burst × ESR`. При імпульсі струму `I_burst = 0.35 А` та `ESR = 2 Ом` динамічне просідання на шині досягає `ΔV = 0.7 В`, знижуючи системний рівень 3.3 В до критичної позначки 2.6 В і провокуючи скид чипа ще до того, як накопичений у ємності електричний заряд встигне розрядитися. Для ефективного придушення високочастотних сплесків паралельно до електролітичного буфера обов'язково додають керамічні SMD-конденсатори ємністю 100 нФ типу X7R або X5R із малим значенням @@en|ESR@@ на рівні декількох міліом.

Використання слабких лінійних регуляторів з малим падінням напруги @@en|LDO@@ (від англ. @@en|Low Dropout Regulator@@ — стабілізатор напруги з малим падінням) або підключення живлення через вбудований перетворювач USB-UART адаптера не забезпечує потрібного струмового запасу та призводить до критичного перегріву компонента. В момент ініціалізації та калібрування високочастотного передавача @@en|Wi-Fi@@ споживання струму мікроконтролером імпульсно зростає до 300–400 мА. При зниженні напруги з первинної шини 5 В до системного рівня 3.3 В розсіювана теплова потужність стабілізатора обчислюється як добуток спаду напруги та струму навантаження: `P_dis = (5 В - 3.3 В) × 0.4 А = 0.68 Вт`. У компактних корпусах SOT-23 з високим тепловим опором кристал-довкілля (близько 230 °C/Вт) така теплова потужність спричиняє розігрів напівпровідникового кристала більш ніж на 150 °C вище температури середовища, що активує внутрішній термозахист і спричиняє раптове вимкнення виходу. Якщо джерело живлення не здатно видати такий імпульс або на лінії відсутні розв'язувальні конденсатори, напруга 3.3 В короткочасно просідає нижче критичного порогу 2.8 В, викликаючи спрацьовування апаратного скидання @@en|Power-On Reset@@ (англ. *power-on reset*, від англ. *power* — живлення + *reset* — скидання; @@en|POR@@). Для запобігання просіданням живлення безпосередньо біля виводів модуля [ESP-01 (Wi-Fi, ESP8266)](root:cat-hw-boards/esp-01) або [ESP-01S (Wi-Fi, ESP8266)](root:cat-hw-boards/esp-01s) необхідно встановлювати паралельну пару конденсаторів: електролітичний або танталовий ємністю 10–100 мкФ для компенсації низькочастотних кидків та керамічний 100 нФ для фільтрації високочастотних перешкод.

Іншою поширеною причиною нестабільності є незафіксовані вхідні рівні на керуючих контактах `CH_PD` (англ. *chip power down*; увімкнення кристала) та `REST` (англ. *reset*; апаратне скидання). Якщо контакт `CH_PD` залишити у «висячому» стані без підключення, наведені напруги та наводки від наводячих електромагнітних полів довільно переводять чип у режим зниженого енергоспоживання. Обидві лінії вимагають обов'язкової апаратної підтяжки до шини 3.3 В через зовнішні резистори опором 10 кОм.

## Електричні параметри та призначення GPIO

Кристал ESP8266 містить 17 цифрових виводів загального призначення @@en|GPIO@@ (англ. *general-purpose input/output*, від лат. *generalis* — загальний + *propositum* — мета; `GPIO0`–`GPIO16`), які працюють виключно з логічними рівнями 3.3 В. Пряма подача 5-вольтових сигналів від стандартних плати розробки без використання схем узгодження рівнів призводить до пробою захисних діодів і незворотного пошкодження вхідних буферів.

Гранично припустимий струм навантаження на один контакт @@en|GPIO@@ (англ. *general-purpose input/output*; контакт загального призначення) становить 12 мА, проте для тривалої та надійної експлуатації рекомендовано не перевищувати 6–8 мА. Окрім подекадного обмеження окремих виводів, існує сумарний струмовий ліміт спільного внутрішнього домену живлення `VDD3P3` (англ. *power domain*, домен живлення периферії), який обмежує загальний струм усіх шин GPIO значенням 120 мА. Одночасне навантаження кількох виводів граничними струмами спричиняє локальне просідання напруги на внутрішніх провідниках кристала та критичний розігрів вихідних буферів, що прискорює деградацію напівпровідника та викликає спонтанні перезавантаження. Пряме підключення світлодіода вимагає розрахунку струмообмежувального резистора за законом Ома: `R_LED = (U_CC - U_LED) ÷ I_LED`. При вихідній напрузі `U_CC = 3.3 В`, прямому падінні на індикаторному світлодіоді `U_LED = 1.8 В` та безпечному робочому струмі `I_LED = 6 мА = 0.006 А` необхідний опір становить `R_LED = (3.3 В - 1.8 В) ÷ 0.006 А = 250 Ом` (найближчий стандартний номінал E24 — 270 Ом). Для керування потужнішими силовими навантаженнями (наприклад, котушкою електромагнітного реле зі струмом споживання `I_relay = 70 мА`) застосовують транзисторний ключ на @@en|NPN@@-транзисторі. Опір базового резистора обчислюється з урахуванням коефіцієнта підсилення транзистора `h_FE = 100` та необхідного коефіцієнта насичення `k_sat = 2` для гарантованого відмикання ключа: базовий струм насичення становить `I_B = (I_relay ÷ h_FE) × k_sat = (70 мА ÷ 100) × 2 = 1.4 мА`. З огляду на падіння напруги на переході база-емітер `U_BE = 0.7 В`, величина базового резистора обчислюється за формулою `R_B = (U_CC - U_BE) ÷ I_B = (3.3 В - 0.7 В) ÷ 0.0014 А ≈ 1857 Ом` (обирають стандартне значення 1.8 кОм чи 2.2 кОм), що повністю захищає контакт від струмового перевантаження.

Шість виводів мікроконтролера (`GPIO6`–`GPIO11`) зарезервовані для обміну даними з внутрішньою або зовнішньою мікросхемою пам'яті @@en|SPI Flash@@ (англ. *serial peripheral interface flash*). Будь-яка спроба підключити зовнішню периферію до цих контактів припиняє зчитування інструкцій прошивки й викликає фатальний збій процесора.

Окреме функціональне призначення має вивід `GPIO16`, який належить до домену таймера реального часу @@en|RTC@@ (англ. *real-time clock*, від лат. *realis* — дійсний + *tempus* — час). На відміну від інших ліній, `GPIO16` має вбудований підтягувальний резистор до землі @@en|Pull-Down@@ (англ. *pull-down* — підтяжка до землі) і підключається до контакту `REST` для апаратного виводу мікроконтролера з режиму глибокого сну @@en|Deep Sleep@@. Інші лінії `GPIO0`–`GPIO15` мають програмно керовані внутрішні підтяжки до живлення @@en|Pull-Up@@ опором 30–50 кОм, проте їхньої сили недостатньо для фіксації завантажувальних режимів.

## Схемотехніка конфігураційних виводів та завантаження

Під час подачі живлення або зняття сигналу скидання з лінії `REST` первинний завантажувач у постійній пам'яті кристала зчитує стан трьох конфігураційних виводів — @@en|strapping pins@@ (англ. *strap* — ремінь, фіксатор). Логічні рівні на контактах `GPIO0`, `GPIO2` та `GPIO15` визначають, з якого джерела мікроконтролер почне виконання коду.

Для вибору режиму роботи використовуються такі поєднання напруг:
- Режим виконання з флешпам'яті (англ. *Flash Boot*): `GPIO15` повинен мати низький рівень (підтяжка до землі через 10 кОм), `GPIO0` — високий рівень (підтяжка до 3.3 В через 10 кОм), `GPIO2` — високий рівень (підтяжка до 3.3 В через 10 кОм);
- Режим прошивання через послідовний порт (англ. *UART Download*): `GPIO15` — низький рівень, `GPIO0` — низький рівень (замикання на землю під час скидання), `GPIO2` — високий рівень.

![Схемотехнічна діаграма підключення підтягувальних резисторів на виводах GPIO0, GPIO2, GPIO15, CH_PD та REST для режимів завантаження ESP8266.](img/esp8266-boot-strapping-schematic.svg)
*_Схемотехніка фіксації завантажувальних рівнів strapping-виводів та кнопок скидання й прошивання для мікроконтролера ESP8266._*

Помилка в розрахунку підтяжок, наприклад залишене у повітрі плече `GPIO15`, призводить до вибору неіснуючого режиму завантаження з @@en|SD-Card@@ та повної втрати працездатності плати. Окрім статичних логічних рівнів, критичне значення має динаміка наростання напруги: надмірна довжина друкованої траси лінії `CH_PD` вносить паразитну ємність (@@en|parasitic capacitance@@, паразитна ємність), яка разом із високоомним резистором підтяжки утворює RC-ланцюжок і затягує фронт сигналу ввімкнення. Повільний підйом рівня на `CH_PD` спричиняє неузгодженість за часом між активацією внутрішніх системних вузлів та зняттям сигналу скидання на лінії `REST`, через що засувки завантажувача зчитують нестабільні перехідні стани на strapping-виводах і блокують старт мікроконтролера. Детальний розбір алгоритмів і засувок наведено у матеріалах [Режими завантаження мікроконтролера ESP8266](root:cat-hw-boards/esp8266-boot-modes) та [Конфігураційні виводи завантаження ESP8266](root:cat-hw-boards/esp8266-boot-strapping-pins).

## Робота з аналогово-цифровим входом TOUT

Мікроконтролер ESP8266 оснащений одним 10-бітним аналогово-цифровим перетворювачем АЦП — @@en|ADC@@ (англ. *analog-to-digital converter*, від лат. *analogus* — відповідний + *digitus* — цифра; контакт `TOUT`). АЦП виконує перетворення вхідної напруги на ціле число від 0 до 1023 за схемою послідовного наближення.

При проєктуванні схем вимірювання важливо розрізняти тип використовуваного модуля. На голом кристалі ESP8266 та компактних модулях вхідний діапазон контакту `TOUT` обмежений строго від 0 до 1.0 В. Подача напруги 3.3 В безпосередньо на вхід `TOUT` викликає насичення АЦП та створює ризик пошкодження аналогового тракту. Натомість на розробницьких платах розібраних у матеріалі [Огляд сімейства Wi-Fi модулів ESP-01 та ESP-01S](root:cat-hw-boards/esp-01-module-family-overview), вивід `TOUT` вже підключений через внутрішній резистивний дільник напруги з верхнім плечем `R₁` 220 кОм та нижнім плечем `R₂` 100 кОм, що розширює зовнішній вимірювальний діапазон до 0–3.3 В. Коефіцієнт послаблення сигналу `K_div` визначається відношенням опорів ланцюжка:

```
K_div = R₂ ÷ (R₁ + R₂)
= 100 ÷ (220 + 100)      [підстановка значень опорів у кОм]
= 100 ÷ 320              [обчислення суми опорів знаменника]
= 0.3125                 [підсумковий коефіцієнт ділення]
```

Знаючи `K_div`, максимальну зовнішню вимірювану напругу `V_in` при граничному значенні аналогового входу `V_ADC` 1.0 В розраховують через зворотне співвідношення:

```
V_in = V_ADC ÷ K_div
= 1.0 ÷ 0.3125           [підстановка граничного рівня АЦП 1.0 В]
= 3.2 В                  [значення верхньої межі вимірювання]
```

Повний вхідний імпеданс схемотехнічного вузла `Z_in` обчислюється як послідовне сумування опорів резисторів дільника:

```
Z_in = R₁ + R₂
= 220 + 100              [сумування верхнього та нижнього плечей]
= 320 кОм                [еквівалентний вхідний опір АЦП]
```

Такий вхідний опір 320 кОм мінімізує струмове навантаження на підключені аналогові датчики, проте для джерел із високим внутрішнім опором вимагає буферизації операційним підсилювачем.

![Схема підключення аналогового входу TOUT із зовнішнім резистивним дільником напруги для узгодження сигналів у діапазоні від 0 до 3.3 В.](img/esp8266-adc-divider-circuit.svg)
*_Схемотехнічне розведення резистивного дільника напруги для безпечного вимірювання аналогових сигналів на вході TOUT._*

Якщо апаратний контакт `TOUT` залишено непідключеним, АЦП можна програмно перемикнути на внутрішнє вимірювання напруги живлення мікроконтролера `VDD33` у діапазоні від 1.8 до 3.6 В, що дозволяє відстежувати розряд акумуляторних батарей без додаткових зовнішніх компонентів.
