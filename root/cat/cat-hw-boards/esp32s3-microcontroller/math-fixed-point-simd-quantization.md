## Виклики FP32-обчислень та концепція квантування

Мікроконтролери без спеціалізованих матричних нейроприскорювачів, такі як пристрої [родини плат на ESP32-S3](root:cat-hw-boards/esp32-s3-boards-family-overview), стикаються з апаратними обмеженнями при виконанні глибоких нейронних мереж. Виконання обчислень у форматі з плаваючою комою @@en|FP32@@ (з @@en|Single-Precision Floating-Point@@ — 32-бітне число з плаваючою комою) вимагає значних ресурсів пам'яті: кожен ваговий коефіцієнт та активація займають 4 байти. При виконанні згорткових шарів пропускна здатність шини оперативної пам'яті стає «вузьким місцем», а математичний співпроцесор @@en|FPU@@ (з @@en|Floating-Point Unit@@ — блок обчислень з плаваючою комою) обробляє значення послідовно за кілька тактів процесора. Невеликий обсяг кєш-пам'яті L1 (зазвичай 32 КБ для інструкцій та даних) і висока латентність звернення до системної шини SRAM спричиняють систематичні простої обчислювального конвеєра при промахах кєшу. Кожен некєшований вибірка 32-бітного операнда з вихідного масиву змушує процесор чекати від 3 до 8 додаткових тактів шини, уповільнюючи виконання матричного множення в кілька разів.

Прямолінійне округлення або відсікання дробової частини дійсних чисел спричиняє спотворення розподілу даних і накопичення помилки в глибоких шарах мережі. Для розв'язання цієї проблеми застосовують @@en|квантування@@ (з @@en|quantization@@ — від латинського @@la|quantus@@, скільки) — математичне відображення безперервної множини дійсних чисел `x_real ∈ [x_min, x_max]` у дискретну цілочисельну множину обмеженої розрядності, наприклад `INT8 ∈ [-128, 127]`.

Перехід від 32-бітних чисел до 8-бітних цілих значень скорочує обсяг використовуваної пам'яті в 4 рази. Це дозволяє розміщувати вагові коефіцієнти компактних моделей у швидкій внутрішній пам'яті SRAM таких плат, як [ESP32-S3-Zero](root:cat-hw-boards/esp32-s3-zero) або [Waveshare ESP32-S3R2](root:cat-hw-boards/esp32-s3r2-waveshare), замість звернення до повільнішої зовнішньої PSRAM.

## Математика афінного квантування та масштабування

Афінне (несиметричне) квантування забезпечує точне відображення дійсного діапазону значень у цілочисельний простір за допомогою двох параметрів: масштабу `S` та нульової точки `Z`. Масштаб @@en|Scale@@ `S` виступає позитивним дійсним числом, що задає крок між сусідніми дискретними рівнями, а нульова точка @@en|Zero-Point@@ `Z` є цілим числом, яке відповідає дійсному нулю `x = 0`. Для визначення підсумкових меж `x_min` та `x_max` будують гістограму розподілу активацій на калібрувальній вибірці даних. Замість прямолінійного вибору абсолютного мінімуму й максимуму застосовують відсікання аномальних викидів (перцентилі 99.99%) або мінімізацію дивергенції Кульбака — Лейблера, що запобігає розтягуванню крок квантування `S` через поодинокі екстремальні значення й зберігає максимальну роздільну здатність для основної маси активацій. Особливий математичний нюанс обчислення виникає при наявності від'ємних активацій (`x_min < 0`) або коли весь розрахований діапазон лежить у від'ємній області (`x_max ≤ 0`). Щоб апаратні операції згортки з нульовим доповненням (англ. @@en|zero-padding@@ — нульове доповнення) та функції активацій не накопичували похибку зсуву, дійсний нуль `x = 0` мусить тотожно відповідати точній цілочисельній точці `Z`. Для цього вхідний інтервал примусово розширюють умовою `x_min' = min(x_min, 0)` та `x_max' = max(x_max, 0)`, після чого від'ємне значення `x_min'` робить додатком величину `- (x_min' / S)`, зсуваючи дробове значення `Z_real = q_min - (x_min' / S)` углиб цілочисельного діапазону `[q_min, q_max]`. Округлення `Z = round(clamp(Z_real, q_min, q_max))` остаточно зафіксовує нульову точку, трохи коригуючи ефективні межі сітки квантування та зберігаючи тотожність точного нуля `x = 0` із цілим значенням `Z`.

Формула квантування довільного дійсного значення `x` у цілочисельне значення `q` має вигляд:

```
q = clamp(round(x / S) + Z, q_min, q_max)
```

Масштабний коефіцієнт `S` обчислюється через граничні значення вибірки:

```
S = (x_max - x_min) / (q_max - q_min)
```

Нульова точка `Z` розраховується з умови збереження точного значення нуля:

```
Z_real = q_min - (x_min / S)
Z = round(clamp(Z_real, q_min, q_max))            [округлення до найближчого цілого]
```

Зворотне перетворення (деквантування) здійснюється за формулою:

```
x_approx = S × (q - Z)
```

При обчисленні скалярного добутку двох квантованих векторів — активацій `a` та вагових коефіцієнтів `w` — деквантована сума розкладається на цілочисельні компоненти:

```
sum(x_a × x_w) = S_a × S_w × sum( (a_i - Z_a) × (w_i - Z_w) )
= S_a × S_w × ( sum(a_i × w_i) - Z_w × sum(a_i) - Z_a × sum(w_i) + N × Z_a × Z_w )
```

У разі симетричного квантування вагових коефіцієнтів нульова точка `Z_w = 0`, що спрощує підсумковий вираз і усуває додаткові перехресні доданки під час інференсу:

```
sum(x_a × x_w) = S_a × S_w × ( sum(a_i × w_i) - Z_a × sum(w_i) )
```

## Векторні SIMD-інструкції Xtensa PIE

Процесорне ядро Xtensa LX7 у мікроконтролері ESP32-S3 містить векторне розширення @@en|PIE@@ (з @@en|Processor Instruction Extensions@@ — інструкції розширення процесора). Воно додає 128-бітні векторні регістри `q0`–`q7` та спеціалізований копроцесор @@en|SIMD@@ (з @@en|Single Instruction, Multiple Data@@ — одна інструкція, множинні дані). Для забезпечення виконання векторної інструкції за один такт вхідні масиви мають бути строго вирівняні в пам'яті SRAM по 16-байтній (128-бітній) межі. Спроба невирівняного зчитування операндів призводить до апаратного розщеплення транзакції шини на два окремі звернення й виконання додаткових зміщень у регістровому файлі. Це створює тактову затримку від 2 до 4 додаткових тактів процесора на кожну векторну інструкцію завантаження, що знижує загальну ефективність SIMD-конвеєра майже вдвічі. При виконанні векторної операції множення з накопиченням @@en|MAC@@ (з @@en|Multiply-Accumulate@@ — множення з додаванням) для 16-елементних векторів розрядності `INT8` попарні добутки елементів спочатку розширюються до 16-бітних знакових чисел, після чого апаратний суматор PIE здійснює їхнє попарне підсумовування у 32-бітні акумулятори. Оскільки максимальне значення добутку двох 8-бітних чисел становить 16 384, розширення проміжних 16-бітних значень до 32-бітної розрядної сітки акумулятора дає змогу безперервно підсумовувати понад 130 000 елементів вектора без ризику арифметичного переповнення чи втрати значущих розрядів.

Один 128-бітний регістр уміщує 16 упакованих 8-бітних цілих чисел `INT8` або 8 упакованих 16-бітних чисел `INT16`. Завдяки цьому одна інструкція множення з накопиченням @@en|MAC@@ (з @@en|Multiply-Accumulate@@ — множення з додаванням) виконує паралельне обчислення одразу для 16 елементів векторів за один такт центрального процесора.

Оптимізована бібліотека @@en|ESP-NN@@ використовує апаратні векторні інструкції PIE для прискорення базових операцій тензорної арифметики. При виконанні паралельного множення двох векторів розрядності `INT8` добутки проміжних пар розширюються до `INT16` або `INT32` перед додаванням до 32-бітного акумулятора. Це запобігає апаратному арифметичному переповненню під час підсумовування довгих послідовностей.

Для досягнення пікової швидкодії SIMD-інструкцій масиви даних у пам'яті повинні бути вирівняні по 16-байтній межі (128 біт). Невирівняний доступ до пам'яті спричиняє додаткові штрафні такти на зчитування та вирівнювання операндів перед завантаженням у регістри `q0`–`q7`.

## Оцінка складності, точності та прискорення

Обчислювальна складність скалярного добутку двох векторів довжиною `N` у форматі FP32 становить `N` операцій множення та `N - 1` операцій додавання, що вимагає передачі `4 × N` байтів через шину пам'яті. Використання 8-бітного SIMD-квантування знижує обсяг зчитуваних даних до `1 × N` байтів і зменшує кількість процесорних інструкцій до `N / 16` векторних команд. Накопичення середньоквадратичної помилки @@en|MSE@@ (з @@en|Mean Squared Error@@ — середня квадратна помилка) лінійно зростає зі збільшенням глибини каналів `N`: для мілинних шарів (`N ≤ 64`) сумарна дисперсія шумів квантування не перевищує допустимий поріг, але у глибоких шарах із високою канальністю (`N ≥ 512`) покрокове підсумовування малих округлень викликає помітне зсунення математичного сподівання суми, що вимагає застосування поштучного квантування за каналами (per-channel quantization).

Теоретичне прискорення математичного ядра `T_speedup` оцінюється як відношення кількості тактів скалярного виконанні FP32 до векторного INT8:

```
T_speedup = Cycles_FP32 / Cycles_INT8_SIMD
```

На ESP32-S3 скалярне виконанні FP32 MAC займає 4–5 тактів процесора на одну операцію, тоді як векторна інструкція PIE виконує 16 операцій `INT8 MAC` за 1 такт. Реальний коефіцієнт прискорення алгоритмів у бібліотеці ESP-NN становить від `4×` до `8×`, оскільки підсумкова швидкодія обмежена латентністю шини оперативної пам'яті.

Вплив квантування на точність моделі вимірюється середньоквадратичною помилкою @@en|MSE@@ (з @@en|Mean Squared Error@@ — середня квадратна помилка) між оригінальним дійсним вектором `x_real` та його деквантованим наближенням `x_approx`:

```
MSE = (1 / N) × ∑ (x_real_i - x_approx_i)²
```

Формат `INT8` забезпечує 4-кратну екологію пам'яті та 16-елементний паралелізм з мінімальним зростанням MSE для класифікаційних мереж. У шарах з високою чутливістю до динамічного діапазону (наприклад, у глибинно-сепарабельних згортках) застосовують формат `INT16`. Він надає 8-елементний SIMD-паралелізм та зменшує середньоквадратичну помилку квантування приблизно в 256 разів порівняно з `INT8`.
