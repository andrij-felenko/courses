## Чому ESP-01 збоїть під час Wi-Fi

Підключення плати [модуль ESP-01](root:cat-hw-boards/esp-01) до саморобного USB-адаптера чи схеми на безпаєчній макетній платі часто супроводжується хаотичними перезавантаженнями. У стані очікування або при виконанні простих інструкцій мікроконтролер споживає незначний струм 15–20 мА. Проте під час передачі мережевих пакетів, ініціалізації радіомодуля чи випромінювання сигналу підсилювачем потужності Wi-Fi струмоспоживання стрибкоподібно зростає до пікових значень `I_peak = 300..500 мА`.

Якщо лінійний стабілізатор напруги @@en|LDO@@ (англ. *Low-Dropout Regulator* — регулятор зі зниженим падінням напруги, від латинського *regulare* — впорядковувати) чи джерело живлення 5 В не розраховані на такі імпульсні навантаження, виникають дві критичні проблеми: невиправдане тепловиділення та динамічне просідання напруги. У момент швидкого наростання струму випромінювання Wi-Fi внутрішнє коло зворотного зв'язку стабілізатора має скінченну швидкість реакції, через що його регулювальний транзистор протягом перших мікросекунд діє як еквівалентний перехідний опір каналу `r_LDO`. Під час кидка струму `ΔI = I_peak - I_idle = 500 - 20 = 480 мА` цей опір викликає падіння напруги `ΔV_drop = ΔI · r_LDO`. Граничне значення припустимого опору визначається різницею між номіналом 3.3 В та межею спрацьовування детектора просідання живлення @@en|brownout detector@@ (`V_BOR = 2.7 В`):

r_LDO_max = ΔV_max ÷ ΔI
          = (V_out - V_BOR) ÷ (I_peak - I_idle)  [умова збереження напруги живлення]
          = (3.3 - 2.7) ÷ (0.50 - 0.02)         [підстановка параметрів живлення та струму]
          = 0.60 ÷ 0.48                          [обчислення різниць напруги та струму]
          = 1.25 Ом                              [граничний перехідний опір каналу LDO]

Якщо еквівалентний опір `r_LDO` перевищує `1.25 Ом`, миттєве просідання напруги перетинає поріг `V_BOR = 2.7 В`, викликаючи спрацьовування внутрішнього детектора @@en|brownout detector@@ та апаратне перезавантаження модуля.

1. На регуляторі @@en|LDO@@ виникає високе падіння напруги `ΔV = V_in - V_out`, що призводить до швидкого нагріву корпусу мікросхеми.
2. Недостатня швидкість реакції регулятора та паразитна індуктивність провідників викликають швидке просідання напруги живлення на шині 3,3 В.

Якщо напруга живлення мікроконтролера просідає нижче критичного порогу 2,7 В, спрацьовує внутрішня схема скидання при просіданні живлення @@en|brownout@@ (англ. *brownout* — просідання напруги, аварійне зниження). Мікроконтролер миттєво перезавантажується, перериваючи зв'язок.

Щоб забезпечити надійну роботу пристрою, необхідний точний математичний розрахунок пасивних компонентів обв'язки: потужності стабілізатора, ємності фільтрувальних конденсаторів, дільника ліній зв'язку та підтягувальних резисторів.

## Розрахунок потужності LDO та теплового режиму

Лінійний стабілізатор напруги @@en|LDO@@ працює за принципом керованого опору, перетворюючи надлишок напруги на теплову енергію. Для адаптера ESP-01 вхідна напруга шини USB становить `V_in = 5.0 V`, а вихідна напруга живлення модуля дорівнює `V_out = 3.3 V`.

Обчислимо падіння напруги `ΔV_LDO` на регуляторі:

```
ΔV_LDO = V_in - V_out
       = 5.0 - 3.3            [падіння напруги на регуляторі]
       = 1.7 V
```

При піковому струмі випромінювання Wi-Fi `I_peak = 400 мА` (`0.4 А`) миттєва розсіювана потужність `P_peak` дорівнює:

```
P_peak = ΔV_LDO × I_peak
       = 1.7 × 0.400          [підстановка падіння напруги та струму]
       = 0.68 W               [пікова потужність у ватах]
```

Оскільки Wi-Fi передавач працює короткими імпульсами, розрахуємо середній струм споживання `I_avg` при робочому циклі передачі `D = 0.3` (30% часу активного випромінювання):

```
I_avg = I_idle × (1 - D) + I_peak × D
      = 0.020 × 0.7 + 0.400 × 0.3      [обчислення середнього струму]
      = 0.014 + 0.120
      = 0.134 A                        [середній струм 134 мА]
```

Середня розсіювана потужність `P_avg` становить:

```
P_avg = ΔV_LDO × I_avg
      = 1.7 × 0.134           [множення падіння напруги на середній струм]
      ≈ 0.228 W
```

Для стабілізатора AMS1117-3.3 у корпусі @@en|SOT-223@@ тепловий опір кристал-довкілля `R_θJA` суттєво залежить від площі мідного полігону тепловідводу `A_cop` на друкованій платі, оскільки металева площадка корпусу скидає основне тепло через шари міді. За мінімальної площі контактних площадок опір становить `R_θJA = 90 °C/W`, але при створенні суцільного полігону товщиною 35 мкм він знижується за сумарною залежністю `R_θJA(A_cop) = R_θJC + R_θCA(A_cop)`, досягаючи `50 °C/W` при `A_cop = 500 mm²`. Оскільки допустима потужність обмежена максимальною температурою кристала `T_j_max = 125 °C`, граничний тривалий струм `I_max` виводиться як `I_max = (T_j_max - T_ambient) / (ΔV_LDO × R_θJA(A_cop))`, де збільшення площі полігону пропорційно розширює межу струму. Оцінимо температуру кристала `T_j` при стандартному опорі `R_θJA = 90 °C/W` та температурі довкілля `T_ambient = 25 °C`:

```
T_j = T_ambient + P_avg × R_θJA
    = 25 + 0.228 × 90         [розрахунок температури кристала]
    = 25 + 20.52
    ≈ 45.5 °C
```

При звичайному обміні по шині USB температура корпусу не перевищує безпечні 46 °C. Проте під час безперервного передавання даних великого обсягу через [сокети TCP/UDP](root:cat-hw-boards/esp01-tcp-udp-sockets) або під час виконання [оновлення прошивки по повітрю (FOTA)](root:cat-hw-boards/esp8266-fota-update) середній струм зростає до 300 мА. У цьому разі потужність досягає `P_avg = 1.7 × 0.3 = 0.51 W`, а температура кристала зростає до 71 °C. При живленні від джерел з напругою понад 7 В без додаткового радіатора стабілізатор перегрівається та входить у режим теплового захисту.

## Обчислення ємності згладжувальних конденсаторів живлення

Лінійні стабілізатори мають скінченний час реакції `t_resp` (зазвичай 5–10 мкс) на швидку зміну струму навантаження. Протягом цього інтервалу регулятор не встигає підняти вихідний струм, і єдиним джерелом енергії для ESP8266 стає локальний згладжувальний конденсатор `C_smooth`.

Розрахуємо мінімальну ємність `C_min`, необхідну для утримання напруги в межах допустимого просідання `ΔV_dip = 0.2 V` (від 3,3 В до 3,1 В) під час імпульсу струму тривалістю `Δt_pulse = 50 мкс` із амплітудою `I_cap = I_peak - I_idle = 380 мА` (`0.38 А`):

```
C_min = I_cap × Δt_pulse / ΔV_dip
      = (0.380 × 50 × 10⁻⁶) / 0.2      [підстановка параметрів імпульсу]
      = 19 × 10⁻⁶ / 0.2
      = 95 × 10⁻⁶ F                    [мінімальна ємність 95 мкФ]
```

Окрім ємності, вирішальну роль відіграє еквівалентний послідовний опір конденсатора @@en|ESR@@ (англ. *Equivalent Series Resistance* — еквівалентний послідовний опір). На опір `ESR` падає додаткова напруга `ΔV_ESR = I_cap × ESR`. Якщо застосувати звичайний електролітичний конденсатор із `ESR = 1.0 Ом`, сумарне просідання становитиме `0.2 + 0.38 = 0.58 V`, що призведе до зниження напруги до 2,72 В і викличе @@en|brownout@@-перезавантаження. Крім активного опору `ESR`, на крутих високочастотних фронтах імпульсів споживання (з часом наростання `t_r ≈ 1` нс та еквівалентною частотою гармонік `f = 1 / (π × t_r) ≈ 300` МГц) критичним є реактивний опір еквівалентної послідовної індуктивності виводів та корпусу @@en|ESL@@ (англ. *Equivalent Series Inductance* — еквівалентна послідовна індуктивність). Підсумковий імпеданс конденсатора `Z` визначається виразом `Z = √(ESR² + (X_L - X_C)²)`, де індуктивний опір складає `X_L = 2 × π × f × ESL`, а ємнісний `X_C = 1 / (2 × π × f × C)`. Для вивідного конденсатора з `ESL = 5` нГн індуктивний опір на частоті `300` МГц сягає `X_L = 2 × π × 300 × 10⁶ × 5 × 10⁻⁹ ≈ 9.42` Ом, через що вивідний елемент блокує високочастотний струм і втрачає здатність стабілізувати напругу під час сплесків випромінювання @@en|Wi-Fi@@.

Тому паралельно з основним керамічним або танталовим конденсатором ємністю 100–220 мкФ обов'язково встановлюють високочастотний керамічний конденсатор ємністю 100 нФ з `ESR < 0.05 Ом` безпосередньо біля виводів живлення модуля.

## Розрахунок дільника UART та підтяжуючих резисторів

Для стабільного функціонування адаптера необхідно узгодити рівні сигналів лінії передачі даних та зафіксувати стани конфігураційних виводів.

### Узгодження рівнів лінії RXD

Сигнал передавача `TXD` USB-перетворювача оперує 5-вольтними логічними рівнями @@en|TTL@@ (англ. *Transistor-Transistor Logic* — транзисторно-транзисторна логіка). Для захисту входу `RXD` модуля ESP-01 із робочою напругою 3,3 В застосовують резистивний дільник напруги з верхнього резистора `R1` та нижнього `R2`. Проте паралельне з'єднання плечей дільника створює еквівалентний опір `R_eq = (R1 × R2) / (R1 + R2)`, який разом із паразитною ємністю входу та провідників `C_eq` (близько 15 пФ) утворює @@en|RC@@-фільтр низьких частот із сталою часу `τ = R_eq × C_eq`. Тривалість фронту наростання сигналу `t_r ≈ 2.2 × τ` обмежує максимальну швидкість обміну @@en|baud rate@@, оскільки при надто великих номіналах резисторів (наприклад, десятки кілоом) завали фронтів викривляють тривалість імпульсу `T_bit` і призводять до помилок зчитування бітів на швидкостях понад 115200 бод.

Формула вихідної напруги дільника `V_out`:

```
V_out = V_in × (R2 / (R1 + R2))
```

При вхідній напрузі `V_in = 5.0 V` та необхідній вихідній напрузі `V_out = 3.3 V` співвідношення опорів дорівнює `R2 / (R1 + R2) = 0.66`. Обираємо стандартний номінал верхнього резистора `R1 = 1.0 кОм`:

```
0.66 × (1000 + R2) = R2
660 + 0.66 × R2 = R2          [розкриття дужок]
0.34 × R2 = 660               [перенесення змінних]
R2 = 660 / 0.34
   ≈ 1941 Ом                  [розрахований опір]
```

Обираємо найближчий стандартний номінал `R2 = 2.0 кОм`. Перевіримо фактичну напругу `V_out`:

```
V_out = 5.0 × (2000 / (1000 + 2000))
      = 5.0 × 0.666
      ≈ 3.33 V                [безпечна напруга логічної 1]
```

### Розрахунок підтягувальних резисторів GPIO0, GPIO2 та RST

Згідно з описом, який наводять [конфігураційні виводи завантаження ESP8266](root:cat-hw-boards/esp8266-boot-strapping-pins), а також [режими завантаження ESP8266](root:cat-hw-boards/esp8266-boot-modes), для старту з SPI-флеш-пам'яті виводи `GPIO0`, `GPIO2`, `RST` та `EN` повинні перебувати у високому логічному стані 1.

Визначимо верхню межу опору підтягувального резистора `R_pull_max` з урахуванням максимального струму витоку входу `I_leak_max = 10 мкА` та мінімальної напруги високого рівня `V_IH_min = 0.75 × V_DD = 0.75 × 3.3 = 2.475 V`:

```
ΔV_R_max = V_DD - V_IH_min
         = 3.3 - 2.475        [падіння напруги на резисторі]
         = 0.825 V

R_pull_max = ΔV_R_max / I_leak_max
           = 0.825 / (10 × 10⁻⁶)    [розрахунок максимального опору]
           = 82.5 kОм
```

Нижня межа опору `R_pull_min` визначається максимально допустимим струмом виводу `I_out_max = 12 мА` під час замикання виводу `GPIO0` на землю для переходу в режим [прошивання ESP-01](root:cat-hw-boards/esp01-firmware-flashing):

```
R_pull_min = V_DD / I_out_max
           = 3.3 / 0.012      [розрахунок мінімального опору]
           = 275 Ом
```

Оптимальним вибором підтягувальних резисторів є @@en|pull-up@@ (англ. *pull-up* — підтяжка вгору) номіналом `R_pull = 10 кОм`. При такому опорі падіння напруги від витоку становить лише `ΔV = 10 мкА × 10 кОм = 0.1 V`, забезпечуючи стабільні 3,2 В на виводах при мінімальному статичному споживанні струму.
