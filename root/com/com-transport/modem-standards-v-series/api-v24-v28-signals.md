# 📋 Специфікація кіл V.24 та електричні рівні V.28

Рекомендація **ITU-T V.24** визначає функціональне призначення та логічну семантику сигнальних кіл обміну між кінцевим обладнанням даних (DTE — *Data Terminal Equipment*, наприклад персональним комп'ютером, роутером або промисловим контролером) та обладнанням закінчення каналу даних (DCE — *Data Circuit-terminating Equipment*, наприклад аналоговим модемом, оптичним медіаконвертером або приймачем).

Рекомендація **ITU-T V.28** встановлює електричні характеристики цих кіл: напруги пасивного та активного станів, допустимі навантаження, крутизну фронтів та межі струмів короткого замикання. Разом V.24 та V.28 складають міжнародний системний відповідник американського стандарту **EIA/TIA RS-232-C**.

## 1. Функціональна класифікація кіл V.24 (Серія 100)

Усі кола стику V.24 розділені на три технологічні категорії: кола передачі даних, кола керування та кола синхронізації.

```
+----------+---------------------------------+-----------+-------------------------+
| Номер    | Назва англійською (EIA RS-232)  | Напрямок  | Функціональне призначення |
| кола V.24|                                 |           |                         |
+----------+---------------------------------+-----------+-------------------------+
| 102      | Signal Ground (GND / SG)        | -         | Загальний сигнальний дріт|
| 103      | Transmitted Data (TXD / TD)     | DTE -> DCE| Передача вихідних даних |
| 104      | Received Data (RXD / RD)        | DCE -> DTE| Прийом вхідних даних    |
| 105      | Request to Send (RTS)           | DTE -> DCE| Запит на передачу       |
| 106      | Clear to Send (CTS)             | DCE -> DTE| Готовність до приймання |
| 107      | Data Set Ready (DSR)            | DCE -> DTE| Модем увімкнений і готовий|
| 108/2    | Data Terminal Ready (DTR)       | DTE -> DCE| Термінал увімкнений     |
| 109      | Data Carrier Detect (DCD / RLSD)| DCE -> DTE| Виявлено несучу частоту |
| 125      | Ring Indicator (RI)             | DCE -> DTE| Сигнал виклику (дзвінок)|
| 114      | Transmitter Signal Element (TCE)| DCE -> DTE| Синхронізація передачі  |
| 115      | Receiver Signal Element (RCE)   | DCE -> DTE| Синхронізація прийому   |
+----------+---------------------------------+-----------+-------------------------+
```

### Детальний аналіз функціонування кіл керування

Кожне сигнальне коло серії 100 виконує строго визначену роль у підтримці апаратного зв'язку між контролером та модемом.

- **Коло 102 (Signal Ground — GND):** Забезпечує спільний опорний потенціал 0 В для вимірювання двополярних напруг усіх інших сигналів. Без надійного низькоомного з'єднання кола 102 різниця потенціалів між заземленнями пристроїв викликає спотворення сигналів та вихід з ладу приймачів.
- **Коло 103 (Transmitted Data — TXD):** Несе послідовний двійковий потік бітів від DTE до DCE. У стані спокою (коли дані не передаються) лінія утримується в пасивному стані MARK (від'ємна напруга).
- **Коло 104 (Received Data — RXD):** Несе відновлений двійковий потік бітів від модема до комп'ютера. У стані спокою лінія також тримається в стані MARK.
- **Коло 105 (Request to Send — RTS):** Переводиться комп'ютером в активний стан SPACE (додатна напруга), коли прикладне програмне забезпечення має дані для надсилання. У напівдуплексних модемах RTS перемикає напрямок аналогового тракту з прийому на передачу.
- **Коло 106 (Clear to Send — CTS):** Відповідь модема на коло RTS. Модем активує CTS лише після того, як сформує стабільну аналогову несучу частоту в лінії та підготує внутрішні буфери DSP. Комп'ютер має право передавати біти по колу TXD виключно тоді, коли RTS та CTS одночасно перебувають в активному стані.
- **Коло 107 (Data Set Ready — DSR):** Сигналізує комп'ютеру про те, що модем підключений до мережі живлення, успішно пройшов внутрішній самотест і переведений у робочий режим (а не в режим самодіагностичної петлі).
- **Коло 108/2 (Data Terminal Ready — DTR):** Сигнал готовності від комп'ютера. Переведення DTR у пасивний стан MARK слугує для модема командами розриву поточного телефонного з'єднання («покласти слухавку») та скидання в початковий стан.
- **Коло 109 (Data Carrier Detect — DCD):** Інформує комп'ютер про те, що приймач модема виявив у телефонній лінії стабільний тональний сигнал несучої частоти віддаленого модема та захопив фазову синхронізацію.
- **Коло 125 (Ring Indicator — RI):** Передає імпульси в ритмі високовольтного синусоїдального сигналу виклику (дзвінка амплітудою 60–90 В з частотою 25 Гц), який надходить від АТС при вхідному дзвінку.

## 2. Електричні параметри та фізичні рівні V.28

Стандарт **ITU-T V.28** визначає електричні граничні значення напруг, струмів та опір навантаження. V.28 є несиметричним двополярним інтерфейсом із загальним земльованим провідником.

### Логічні рівні та діапазони напруг

Сигнали V.28 інвертовані відносно стандартної TTL-логіки: активний стан («0») кодується додатною напругою, а пасивний стан («1») — від'ємною.

```
+---------------------+-------------------+-------------------+-------------------+
| Логічний стан       | Двійкове значення | Стан колу V.24    | Діапазон напруги  |
+---------------------+-------------------+-------------------+-------------------+
| MARK (Маркер)       | 1                 | OFF (Вимкнено)    | -3 В ... -15 В    |
| SPACE (Пробіл)      | 0                 | ON (Увімкнено)    | +3 В ... +15 В    |
| Невизначена зона    | -                 | -                 | -3 В ... +3 В     |
+---------------------+-------------------+-------------------+-------------------+
```

Зона напруг від `-3 В` до `+3 В` є зазором гістерезису (невизначеною зоною). Приймач V.28 зберігає попередній логічний стан при попаданні напруги в цей діапазон, що захищає системні входи від флуктуацій шуму та наводок.

### Фізичні граничні параметри за стандартом V.28

1. **Напруга холостого ходу передавача (U0):** Абсолютна величина напруги на відкритих вихідних клемах передавача не повинна перевищувати `±15 В` (типові значення інтегральних мікросхем становлять `±9 В` або `±12 В`).
2. **Напруга передавача під навантаженням (UL):** При підключенні стандартного навантаження опором від 3000 до 7000 Ом вихідна напруга передавача повинна залишатися в межах від `±5 В` до `±15 В`.
3. **Вхідний опір приймача (Ri):** Вхідний опір приймального каскаду повинен становити від `3 кОм` до `7 кОм` за будь-яких напруг у діапазоні від `-15 В` до `+15 В`.
4. **Максимальна ємність навантаження (CL):** Сумарна ємність з'єднувального кабелю та входів приймача не повинна перевищувати `2500 пФ`. Оскільки стандартний екранований кабель має ємність близько `150 пФ/м`, це фіксує максимальну довжину фізичного кабелю на рівні `15 метрів` для швидкостей до 20 кбіт/с.
5. **Обмеження крутизни фронту (Slew Rate):** Швидкість зміни напруги на виході передавача обмежена верхньою межею `30 В/мкс`. Це обмеження усуває високочастотні гармоніки, що запобігає випромінюванню радіозавад та зменшує ємнісні перехресні наводки між сусідніми жилами у багатожильному джгуті.
6. **Захист від короткого замикання (Isc):** Передавач V.28 зобов'язаний безперервно витримувати коротке замикання вихідного сигналу на коло Signal Ground (102) або на будь-яке інше коло V.24 без термічного руйнування. Струм короткого замикання обмежений величиною не більше `500 мА`.

## 3. Перетворення рівнів та мікросхеми драйверів (MAX232)

Оскільки мікроконтролери та цифрові процесори оперують однополярними TTL/CMOS-рівнями напруги (0 В та +3.3 В або +5 В), для зв'язку за стандартом V.28/RS-232 потрібні спеціалізовані мікросхеми рівневих конвертерів.

Класичним рішенням стала мікросхема **MAX232** (та її сучасні 3.3-вольтні аналоги MAX3232). Вона містить внутрішній двокаскадний емкостісний інвертор і подвоювач напруги (Charge Pump), який генерує двополярні напруги `+8.5 В` та `-8.5 В` з однополярного джерела живлення `+5 В` за допомогою чотирьох зовнішніх керамічних конденсаторів ємністю `0.1 мкФ`.

```
+------------------+------------------+------------------+
| Логічний вхід    | Передавач MAX232 | Вихід V.28 / RS-232|
| (TTL / CMOS)     |                  | (Двополярна)     |
+------------------+------------------+------------------+
| 0 В (Логічна 0)  | -> Інверсія ->   | +8.5 В (SPACE)   |
| +5 В (Логічна 1) | -> Інверсія ->   | -8.5 В (MARK)    |
+------------------+------------------+------------------+
```

Приймальний каскад мікросхеми MAX232 виконує зворотне перетворення: двополярний сигнал V.28 (наприклад, `-12 В` або `+12 В`) трансформується у стандартний TTL-рівень `+5 В` або `0 В` із додаванням апаратного гістерезису для підвищення шумностійкості.

## 4. Схема роз'ємів DB-25 та DE-9 (ISO 2110 / EIA-574)

Стандарт V.24 початково описував лише функціональні кола, тоді як механічні конструкції роз'ємів регламентувалися окремими стандартами: 25-контактним DB-25 (ISO 2110) та більш компактним 9-контактним DE-9 (EIA/TIA-574, що став стандартом де-факто в персональних комп'ютерах IBM PC AT).

```
+----------+------------+------------+-------------------------------------+
| Сигнал   | Коло V.24  | Контакт    | Контакт DE-9 (Стандарт IBM PC AT)   |
| V.24     |            | DB-25      |                                     |
+----------+------------+------------+-------------------------------------+
| Shield   | 101        | 1          | Корпус (Shield)                     |
| TXD      | 103        | 2          | 3                                   |
| RXD      | 104        | 3          | 2                                   |
| RTS      | 105        | 4          | 7                                   |
| CTS      | 106        | 5          | 8                                   |
| DSR      | 107        | 6          | 6                                   |
| GND      | 102        | 7          | 5                                   |
| DCD      | 109        | 8          | 1                                   |
| DTR      | 108/2      | 20         | 4                                   |
| RI       | 125        | 22         | 9                                   |
+----------+------------+------------+-------------------------------------+
```

## 5. Алгоритм часового узгодження рукостискання (Handshake)

Часова послідовність активації кіл V.24 під час здійснення апаратного з'єднання та керування потоком даних:

```
DTE (Термінал / ПК)                                   DCE (Модем)
      |                                                    |
      |<---------- Коло 125 (RI) [УВІМКНЕНО] ---------------| (Надійшов виклик з АТС)
      |                                                    |
      |---------- Коло 108/2 (DTR) [УВІМКНЕНО] ----------->| (Команда зняти слухавку)
      |                                                    |
      |<---------- Коло 107 (DSR) [УВІМКНЕНО] --------------| (Модем захопив лінію)
      |                                                    | (Обмін тон-сигналами V.8)
      |<---------- Коло 109 (DCD) [УВІМКНЕНО] --------------| (Несучу захоплено)
      |                                                    |
      |---------- Коло 105 (RTS) [УВІМКНЕНО] ----------->| (Запит на передачу даних)
      |                                                    |
      |<---------- Коло 106 (CTS) [УВІМКНЕНО] --------------| (Готовність приймати TXD)
      |                                                    |
      |========== Коло 103 (TXD) [ДАНІ] ==================>| (Передача потоку бітів)
```

### Режими тестового петлевого випробування (Loopback)

Стандарт V.24 передбачає діагностичні режими перевірки працездатності кіл та аналогового тракту:
- **Локальна аналогова петля (Loop 3):** Передавач модема підключається безпосередньо до власного приймача всередині пристрою, відключаючи телефонну лінію. Це дозволяє перевірити спроможність DTE надсилати й приймати дані через кола 103/104 та трансивер V.28.
- **Віддалена цифрова петля (Loop 2):** Віддалений модем приймає аналоговий сигнал з лінії, демодулює його у двійкові біти й одразу надсилає їх назад у передавач без участі віддаленого комп'ютера. Це дає змогу виміряти коефіцієнт помилок (BER) усього скрізного каналу зв'язку.

Правильне застосування специфікацій V.24 та V.28 гарантує повну апаратну та електричну сумісність комунікаційних пристроїв незалежно від їхнього виробника.
