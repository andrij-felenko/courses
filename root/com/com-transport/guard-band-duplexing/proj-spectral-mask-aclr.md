# ⚙️ Розрахунок ACLR та перевірка спектральної маски випромінювання

У цифрових системах бездротового зв'язку (LTE, 5G NR, Wi-Fi) вихідний радіосигнал передавача ніколи не є ідеально обмеженим за частотою. Нелінійність підсилювача потужності (Power Amplifier, PA), фазові шуми гетеродина, фазові дрижання тактового генератора та перехідні процеси цифро-аналогового перетворення викликають небажане розширення спектра — позасмугові випромінювання (Out-Of-Band Emissions, OOBE). Для захисту сусідніх частотних каналів, де можуть працювати інші оператори або критичні служби, регулятори (3GPP, ITU-R, FCC, ETSI) вимагають обов'язкового дотримання спектральної маски випромінювання (Spectral Emission Mask, SEM) та мінімального коефіцієнта витоку потужності в сусідній канал (Adjacent Channel Leakage Ratio, ACLR).

Нижче наведено теоретичні засади, алгоритм оцінки спектральної щільності потужності методом Велча (Welch PSD), математичні правила інтегрування смуг, порівняння віконних функцій, еволюцію фільтрації від LTE до 5G NR, практичний числовий розрахунок для базової станції LTE, а також повноцінну реалізацію розрахунку ACLR і верифікації маски випромінювання на основі масиву комплексних I/Q-відліків мовами C та сучасним C++.

### Математична модель ACLR та спектральної маски

#### 1. Коефіцієнт витоку потужності в сусідній канал (ACLR)
Показник ACLR кількісно виражає, наскільки чисто передавач утримує власну енергію всередині виділеного каналу порівняно з енергією, що паразитно випромінюється у сусідні смуги. Він визначається як відношення інтегральної потужності корисного сигналу, випроміненої в призначеному каналі передавача (Carrier Bandwidth), до потужності завади, яка просочується в сусідній канал (Adjacent Channel):

```
ACLR = P_корисний / P_сусідній
```

У логарифмічному масштабі (децибелах):

```
ACLR(дБ) = 10 · log₁₀ ( ∫[f_c - B_ch/2 .. f_c + B_ch/2] S(f) df / ∫[f_adj - B_ch/2 .. f_adj + B_ch/2] S(f) df )
```

де:
- `S(f)` — оцінка спектральної щільності потужності сигналу (Power Spectral Density, PSD) у Вт/Гц;
- `f_c` — центральна несуча частота корисного каналу;
- `f_adj = f_c ± ΔF` — центральна частота сусіднього каналу (для каналу шириною 20 МГц міжцентровий рознос зазвичай становить `ΔF = 20 МГц`);
- `B_ch` — смуга інтегрування (для каналу LTE 20 МГц номінальна зайнята смуга становить `18.0 МГц`, яка містить 100 активних ресурсних блоків, а по 1 МГц з обох боків відведено під захисні смуги).

За вимогами стандартів 3GPP TS 36.104 (LTE) та 3GPP TS 38.104 (5G NR) мінімально допустиме значення ACLR для базових станцій становить:
- `ACLR1 ≥ 45 дБ` для першого сусіднього каналу (зміщення на `±20 МГц`);
- `ACLR2 ≥ 50 дБ` для другого сусіднього каналу (зміщення на `±40 МГц`).

Рівень у `45 дБ` означає, що паразитна потужність, яка витікає в сусідній частотний блок іншого оператора, повинна бути щонайменше в `31 622 рази` меншою за потужність власної корисної передачі.

#### 2. Спектральна маска випромінювання (SEM)
Якщо ACLR дає єдине інтегральне число для всього сусіднього каналу, то спектральна маска випромінювання (SEM) контролює форму спаду спектра безпосередньо біля межі каналу — у перехідній смузі та зоні захисного інтервалу. Вона являє собою неперервну або східчасту граничну криву максимальної допустимої потужності залежно від частотного відступу `Δf` від краю номінального каналу.

Потужність вимірюється за допомогою нормативного смугового фільтра зі стандартизованою вимірювальною смугою `B_meas` (зазвичай `100 кГц` поблизу краю каналу та `1 МГц` на більшому віддаленні):

```
P_meas(f) = ∫[f - B_meas/2 .. f + B_meas/2] S(ν) dν ≤ Mask(f - f_c)
```

Типова маска 3GPP для базової станції середньої потужності (Category B) вимагає:
- на відступі `Δf = 0..0.5 МГц` від краю каналу: спад до `-14 дБм / 100 кГц`;
- на відступі `Δf = 0.5..5.0 МГц`: лінійний спад від `-14 дБм` до `-26 дБм / 100 кГц`;
- на відступі `Δf = 5.0..10.0 МГц`: пригнічення до `-15 дБм / 1 МГц`.

### Детальний аналіз алгоритму розрахунку

Для точної цифрової оцінки ACLR та SEM за масивом комплексних цифрових відліків базової смуги (Baseband I/Q Samples) програмний конвеєр виконує кілька послідовних кроків:

#### 1. Порівняння віконних функцій для спектрального аналізу
Дискретне перетворення Фур'є (ДПФ/FFT), застосоване до кінцевого відрізка сигналу довжиною `N`, неявно множить нескінченний у часі процес на прямокутне вікно. Оскільки перетворення Фур'є прямокутника є функцією `sinc(f) = sin(πf) / (πf)`, кожна спектральна лінія отримує бічні пелюстки, перша з яких затухає лише на `-13.3 дБ`. Цей паразитичний ефект називається розтіканням спектра (англ. *Spectral Leakage*). Він штучно завищує оцінку потужності в сусідніх каналах, роблячи коректний вимір `ACLR > 30 дБ` неможливим.

Вибір віконної функції визначає компроміс між шириною головної пелюстки (роздільною здатністю за частотою) та рівнем пригнічення бічних пелюсток (динамічним діапазоном):

| Віконна функція | Рівень 1-ї бічної пелюстки | Швидкість спаду | Сфера застосування |
| :--- | :--- | :--- | :--- |
| **Прямокутне (Rectangular)** | `-13.3 дБ` | `-6 дБ / октаву` | Непридатне для вимірювання ACLR (фальшивий витік) |
| **Ханна (Hann)** | `-31.5 дБ` | `-18 дБ / октаву` | Оптимальний баланс для стандартизованого аналізу ACLR |
| **Хеммінга (Hamming)** | `-42.7 дБ` | `-6 дБ / октаву` | Гарне початкове пригнічення, але повільний спад у далекій зоні |
| **Блекмана-Харріса (4-term)**| `-92.0 дБ` | `-6 дБ / октаву` | Прецизійні вимірювання глибокого позасмугового шуму (>80 дБ) |

Для типових задач верифікації передавачів мобільних мереж вікно Ханна є базовим стандартом, оскільки його кубічний асимптотичний спад швидко зводить спектральні хвости до нуля на відстані кількох мегагерц від несучої:

```
w[n] = 0.5 · (1 - cos(2π · n / (N - 1))),   n = 0, 1, ..., N - 1
```

#### 2. Оцінка спектральної щільності потужності методом Велча
Одинична періодограма на основі одного блоку FFT має високу випадкову дисперсію. Метод Велча розбиває загальний масив відліків довжиною `L` на серію блоків розміром `N_fft` із перекриттям у 50% (Hop Size = `N_fft / 2`). Для кожного блоку обчислюється модуль спектра, після чого всі періодограми усереднюються:

```
S_welch[k] = (1 / (M · P_win)) · ∑[m=0..M-1] |FFT{x_m · w}[k]|²
```

де `P_win = ∑ w²[n]` — енергія вікна, яка компенсує втрату потужності через зважування, а `M` — кількість накопичених блоків.

#### 3. Центрування нульової частоти (FFT-Shift)
Стандартний алгоритм FFT повертає спектральні біни в діапазоні від `0` до `f_s`. Для розрахунку ACLR необхідно центрувати постійну складову (DC, нульову частоту) посередині масиву, зсуваючи індекси так, щоб індекс `k = N_fft / 2` відповідав центральній несучій частоті `f_c = 0`, ліва половина — від'ємним частотам `-f_s/2 .. 0`, а права — додатним `0 .. +f_s/2`.

#### 4. Чисельне інтегрування за дискретними бінами
Частотна роздільна здатність одного біна становить:

```
Δf_bin = f_s / N_fft
```

Потужність у будь-якій заданій смузі частот `[f_start, f_end]` обчислюється шляхом простого чисельного підсумовування значень спектральної щільності бінів, що потрапляють у цей інтервал:

```
P_band = Δf_bin · ∑[k: f_start ≤ f_k ≤ f_end] S_welch[k]
```

Оскільки при розрахунку відношення `ACLR = P_carrier / P_adj` множник `Δf_bin` скорочується в чисельнику та знаменнику, обчислення можна виконувати безпосередньо над сумою відліків PSD.

### Еволюція цифрової фільтрації: від LTE до 5G NR

Різниця в ширині захисних смуг між стандартами поколінь 4G та 5G безпосередньо зумовлена розвитком цифрових методів формування форми імпульсу:

1. **Класичний CP-OFDM у 4G LTE:**
   У стандарті LTE кожен OFDM-символ обмежується в часі прямокутним вікном із додаванням циклічного префікса (CP). Прямокутний імпульс у часі породжує нескінченні бічні пелюстки `sinc(f)` для кожної піднесучої. Щоб сумарні хвости всіх 1200 піднесучих не порушували маску SEM та вимогу `ACLR ≥ 45 дБ`, стандарт LTE виділяє під захисні смуги рівно `10%` спектра (у каналі 20 МГц зайнято лише 18 МГц, а 2 МГц витрачаються на захисні поля).
2. **Віконне та субсмугове фільтрування у 5G NR (W-OFDM / Filtered-OFDM):**
   У 5G NR базова станція застосовує або плавне згладжування фронтів символів у часовій області (Windowed-OFDM), або пропускає групи піднесучих крізь поліфазні цифрові смугові фільтри (Filtered-OFDM). Цифровий спад передавальної функції на краях смуги досягає крутизни понад `60 дБ на мегагерц`. Це дозволило скоротити захисні смуги до менш ніж `2%`: у каналі 5G NR 100 МГц (Band n78, `μ = 1`, `Δf = 30 кГц`) активно використовуються 273 ресурсні блоки (3276 піднесучих), що становить `98.28 МГц` корисної зайнятої смуги із загальних 100 МГц.

### Роль цифрового передіспотворення (DPD) та формування смуги

Позасмугові випромінювання на практиці є наслідком компромісу між енергоефективністю та лінійністю радіотракту:

1. **Енергоефективність (PA Efficiency):** Щоб підсилювач потужності (наприклад, на транзисторах LDMOS або GaN HEMT) мав високий коефіцієнт корисної дії (PAE > 40–50%), його робочу точку зміщують близько до зони насичення (P1dB / Psat).
2. **Нелінійність і генерація інтермодуляцій (IMD):** Сигнали OFDM мають випадковий характер амплітуди з високим відношенням пікової потужності до середньої (PAPR ≈ 8..11 дБ). Коли амплітудні піки потрапляють у нелінійну зону насичення підсилювача, виникає інтермодуляційне розширення спектра 3-го і 5-го порядків (`IMD3`, `IMD5`). Замість крутого спаду за межами каналу спектр отримує характерні широкі «плечі» (англ. *Spectral Regrowth*), які заливають захисні смуги та сусідній канал з рівнем `ACLR ≈ 25..30 дБ`.
3. **Цифрова лінеаризація (Digital Pre-Distortion, DPD):** Щоб відновити чистоту спектра без відкочування робочої точки в неефективний лінійний клас A, у сигнальному процесорі (DSP/FPGA) застосовують адаптивний блок DPD. Алгоритм пропускає вхідний цифровий сигнал через нелінійну модель із пам'яттю (поліноми Вольтерри або Memory Polynomial), яка вносить спотворення, точно дзеркальні до передавальної характеристики PA. Проходячи через реальний підсилювач, попередньо викривлений сигнал лінеаризується, пригнічуючи спектральні плечі в сусідніх смугах на `20..25 дБ` і забезпечуючи результуючий `ACLR > 50 дБ`.

### Практичний числовий розрахунок для базової станції LTE

Розглянемо реальний випадок верифікації базової станції LTE Band 7 (несуча частота `f_c = 2650 МГц`, номінальна смуга 20 МГц, вихідна потужність передавача `+43 дБм` або 20 Вт).

Вимірювання спектра за допомогою каліброваного приймача SDR показало такі інтегральні значення потужностей:
- Потужність у смузі корисного каналу `[2641..2659 МГц]` (18 МГц): `P_carrier = +42.8 дБм` (19.05 Вт);
- Потужність, що витікає в перший нижній сусідній канал `[2621..2639 МГц]`: `P_lower = -4.7 дБм` (0.339 мВт);
- Потужність, що витікає в перший верхній сусідній канал `[2661..2679 МГц]`: `P_upper = -5.2 дБм` (0.302 мВт).

Обчислення ACLR:

```
ACLR_нижній = +42.8 - (-4.7) = 47.5 дБ
ACLR_верхній = +42.8 - (-5.2) = 48.0 дБ
```

Обидва значення перевищують нормативний поріг `45.0 дБ`. Передавач успішно проходить сертифікаційне випробування 3GPP.

Якщо вимкнути блок цифрового передіспотворення (DPD Off), рівень інтермодуляційних продуктів у сусідній смузі підскакує до `P_lower = +13.5 дБм` (22.4 мВт). У цьому випадку:

```
ACLR_без_DPD = +42.8 - (+13.5) = 29.3 дБ  [НЕ ПРОЙДЕНО: дефіцит 15.7 дБ]
```

При такому рівні витоку базова станція створює непереборну заваду для абонентів сусіднього оператора на відстані до кількох кілометрів, викликаючи масові обриви сесій зв'язку.

### Робота з SDR та автоматизованими вимірювальними стендами

Для автоматизації сертифікаційних випробувань передавачів у лабораторіях застосовують або програмно-визначені радіосистеми (SDR: USRP X310, Ettus N320), або прецизійні лабораторні спектроаналізатори (Rohde & Schwarz FSW, Keysight N9020B).

#### 1. Калібрування шкали АЦП у фізичні одиниці (дБм)
Комплексні відліки від АЦП надходять як 16-бітні цілі числа `int16_t` у діапазоні `[-32768..+32767]`. Для переведення цифрової потужності в абсолютну шкалу `дБм` на стандартному навантаженні `R_load = 50 Ом` використовують формулу калібрування:

```
V_in[n] = (I[n] / 32768.0) · V_ref
P_inst[n] = (V_in[n]² + Q_in[n]²) / R_load
P_dbm = 10 · log₁₀(P_inst / 1·10⁻³) + G_cal
```

де `V_ref` — повна шкала вхідної напруги АЦП (Full-Scale Voltage, зазвичай 1.0 В пік-пік), а `G_cal` — коефіцієнт апаратного калібрування з урахуванням згасання вхідного кабелю та посилення LNA приймача.

#### 2. Керування через SCPI у вимірювальних приладах
Промислові спектроаналізатори виконують цей самий розрахунок автоматично за протоколом SCPI (Standard Commands for Programmable Instruments) через інтерфейси LAN/GPIB:

```
:CONFigure:ACPower                          [вмикання режиму вимірювання ACLR]
:SENSe:POWer:ACHannel:BANDwidth:INTegration 18.0MHz   [корисна смуга каналу]
:SENSe:POWer:ACHannel:SPACing 20.0MHz       [рознос між сусідніми каналами]
:READ:ACPower?                              [зчитування масиву значень ACLR у дБ]
```

Прилад повертає рядок із трьома значеннями: абсолютна потужність головного каналу у дБм, відносне пригнічення нижнього каналу у дБ та відносне пригнічення верхнього каналу у дБ.

### Типові підводні камені та інженерні пастки

#### 1. Розтікання спектра через прямокутне вікно (Spectral Leakage)
Якщо обчислювати БПФ сирого масиву відліків без віконного зважування, прямокутний обрив послідовності породжує бічні пелюстки виду `sinc(f)`. Спад першої бічної пелюстки прямокутного вікна становить лише `-13.3 дБ`. Це штучне математичне розширення спектра створить фальшивий витік у сусідні біни з рівнем `ACLR ≈ 20..25 дБ`, навіть якщо вхідний сигнал є ідеальною чистою синусоїдою. Застосування вікна Ханна гарантує спад бічних пелюсток зі швидкістю `-18 дБ/октаву`, забезпечуючи динамічний діапазон вимірювань понад `80 дБ`.

#### 2. Невідповідність смуги інтегрування та захисних смуг
Поширеною помилкою є інтегрування потужності корисного каналу по всій номінальній смузі (наприклад, по всіх 20 МГц каналу LTE замість 18 МГц зайнятої смуги). Захисні смуги по краях каналу (по 1 МГц зліва і справа) не містять активних піднесучих OFDM. Включення захисних смуг у межі інтегрування корисного сигналу занижує розрахункову потужність на межі та спотворює значення спектральної щільності.

#### 3. Вплив постійної складової (DC Offset) та IQ-дисбалансу в SDR
При практичних вимірюваннях за допомогою квадратурних радіоприймачів прямого перетворення (Zero-IF SDR, таких як AD9361 або LMS7002M) у центрі спектра неминуче виникає паразитна постійна складова (DC Offset), викликана прямим просочуванням сигналу гетеродина (LO Leakage). Якщо пік DC потрапляє в центральний бін, він може додати до інтегралу потужності кілька децибелів фіктивної енергії. У професійних спектроаналізаторах перед розрахунком ACLR центральний бін `k = N_fft / 2` або апаратно режекторно фільтрується (Notch Filter), або інтерполюється за двома сусідніми бінами.

#### 4. Вибір частоти дискретизації для захоплення інтермодуляцій
Щоб коректно виміряти ACLR першого та другого сусідніх каналів для сигналу шириною 20 МГц, спектроаналізатор або АЦП приймача повинен мати смугу оцифрування, яка охоплює як мінімум три повні канали (головний та два сусідніх, тобто `3 × 20 МГц = 60 МГц`). Якщо частота дискретизації `f_s` менша за подвоєну граничну частоту (наприклад, менша за 61.44 МГц), виникає явище накладання спектрів (Aliasing), при якому продукти інтермодуляції 3-го порядку загортаються назад у корисний канал, спотворюючи результати вимірювання EVM та маскуючи реальний рівень OOBE.

#### 5. Нелінійне спотворення у вимірювальному тракті
Якщо вхідний сигнал, що подається на АЦП вимірювального приймача, має занадто високий рівень, змішувач та малошумний підсилювач самого вимірювача переходять у нелінійний режим. У результаті вимірювач сам генерує інтермодуляційні складові, показуючи незадовільний ACLR навіть для ідеально лінійного передавача. Щоб уникнути цієї пастки, на вході вимірювача встановлюють регульований атенюатор (Step Attenuator) і проводять перевірку: при введенні додаткового згасання на 10 дБ виміряне значення ACLR не повинно змінюватися. Якщо ACLR зростає — вимірювальний прилад був перевантажений.

#### 6. Обчислювальна складність та оптимізація SIMD
При обробці неперервного I/Q-потоку в реальному часі на швидкості 61.44 MSPS (що генерує близько 490 МБ/с даних) обчислювальна складність FFT алгоритмом Кулі-Тьюкі становить `O(M · N_fft · log₂ N_fft)` комплексних множень за секунду. Для забезпечення роботи без втрати відліків у сучасних SDR-системах алгоритм FFT оптимізують за допомогою SIMD-інструкцій (AVX-512 / NEON) або виносять у логіку FPGA (де застосовують конвеєрні метеликові структури Pipelined Radix-2/4), що дозволяє обчислювати спектральну маску в реальному часі паралельно з передачею даних.
