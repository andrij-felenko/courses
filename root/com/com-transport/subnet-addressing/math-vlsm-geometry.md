# 🧮 Математика бітових масок та двійкового розбиття простору

Простір адрес IPv4 є скінченним абелевим кільцем цілих чисел за модулем `2³²` (`Z_(2³²)`) та водночас 32-вимірним векторним простором над скінченним полем Галуа `GF(2)`. Будь-яка IP-адреса `A` строго формалізується або як двійковий вектор розрядності 32 (`A ∈ {0, 1}³²`), або як ціле невід'ємне число в замкненому діапазоні `0 ≤ A ≤ 2³² − 1`. Математична теорія підмережевої адресації є строгим апаратом факторизації цього простору на неперетинні підмножини (інтервали та афінні підпростори) за допомогою лінійних бітових проєкторів — масок підмереж.

---

### Алгебра бітових масок та лінійні проєктори префіксів

Маскою підмережі довжини `n` (де параметр довжини префікса задовольняє умову `0 ≤ n ≤ 32`) називається 32-бітний бінарний вектор `M(n)`, у якого рівно `n` старших розрядів встановлено в логічну одиницю `1`, а решта `32 − n` молодших розрядів встановлено в логічний нуль `0`.

Число молодших нульових розрядів позначається як `h = 32 − n` і визначає кількість бітів, виділених під адресацію локальних вузлів (хостів).

Аналітичне значення маски `M(n)` виводиться як сума розрядів відповідної двійкової геометричної прогресії:

```
M(n) = ∑ (i = 32 − n .. 31) 2ⁱ                           [сума старших n розрядів]
     = 2³²⁻ⁿ · ∑ (j = 0 .. n − 1) 2ʲ                      [винесення множника 2^(32-n)]
     = 2³²⁻ⁿ · (2ⁿ − 1)                                   [формула суми геометричної прогресії]
     = 2³² − 2³²⁻ⁿ                                        [розкриття дужок]
     = 2³² − 2ʰ                                           [заміна h = 32 - n]
```

Розмір повного блоку адрес, що охоплюється маскою `M(n)`, називається кроком або ємністю підмережі `S(n)`:

```
S(n) = 2³²⁻ⁿ = 2ʰ
```

Інверсною маскою (англ. *wildcard mask*, або шаблонною маскою хоста) називається побітове заперечення маски `M(n)`, яке позначається як `W(n)`:

```
W(n) = ¬M(n)                                              [порозрядне логічне заперечення НЕ]
     = (2³² − 1) − M(n)                                   [арифметичне доповнення до одиниць]
     = (2³² − 1) − (2³² − 2ʰ)                             [підстановка виразу для M(n)]
     = 2ʰ − 1                                             [скорочення доданків 2^32]
```

Для довільної IP-адреси `A ∈ Z_(2³²)` та маски `M(n)` визначаються два головні проєкційні оператори:

1. **Оператор мережевої адреси (Network ID Projector):**
   `Net(A, n) = A ∧ M(n)`, де `∧` — порозрядне логічне множення (AND).
2. **Оператор широкомовної адреси (Directed Broadcast Projector):**
   `Brd(A, n) = A ∨ W(n)`, де `∨` — порозрядне логічне додавання (OR).

#### Алгебраїчні властивості оператора Net

Оператор `Net(·, n)` є ортогональним проєктором на підпростір старших `n` бітів і має такі фундаментальні властивості:

1. **Ідемпотентність:** повторне застосування маски не змінює результат:
   `Net(Net(A, n), n) = (A ∧ M(n)) ∧ M(n) = A ∧ (M(n) ∧ M(n)) = A ∧ M(n) = Net(A, n)`.
2. **Дистрибутивність відносно двійкового додавання:** якщо `X` та `Y` не мають спільних одиничних розрядів (`X ∧ Y = 0`), то `Net(X ⊕ Y, n) = Net(X, n) ⊕ Net(Y, n)`.
3. **Ієрархічне вкладення (звуження префікса):** для будь-яких довжин префіксів `n₁ ≤ n₂` виконується рівність:
   `M(n₁) ∧ M(n₂) = M(n₁)`.
   Звідси випливає композиція операторів:
   `Net(Net(A, n₂), n₁) = (A ∧ M(n₂)) ∧ M(n₁) = A ∧ (M(n₂) ∧ M(n₁)) = A ∧ M(n₁) = Net(A, n₁)`.

Підмережа, породжена адресою `A` та довжиною префікса `n`, строго задається як дискретний числовий інтервал:

```
Subnet(A, n) = [ Net(A, n), Brd(A, n) ] = [ Net(A, n), Net(A, n) + 2³²⁻ⁿ − 1 ]
```

### Декомпозиція за октетами та магічне число

Оскільки IPv4-адреса традиційно записується у вигляді чотирьох 8-бітних десяткових чисел (октетів) `A = (A₁, A₂, A₃, A₄)`, оператор `Net(A, n)` розпадається на прямий добуток чотирьох незалежних 8-бітних проєкцій:

```
Net(A, n) = ( A₁ ∧ M₁(n), A₂ ∧ M₂(n), A₃ ∧ M₃(n), A₄ ∧ M₄(n) )
```

Усі чотири октети маски діляться на три типи:

1. **Повні мережеві октети (`M_k = 255`):** відповідний октет адреси переноситься в результат без змін (`A_k ∧ 255 = A_k`).
2. **Повні хостові октети (`M_k = 0`):** відповідний октет адреси повністю обнуляється (`A_k ∧ 0 = 0`).
3. **Граничний октет (англ. *interesting octet*):** єдиний октет `k = ⌊n / 8⌋ + 1`, у якому маска містить дробову кількість одиниць `r = n mod 8` (де `1 ≤ r ≤ 7`).

Значення маски в граничному октеті аналітично дорівнює:

```
M_boundary = ∑ (i = 8 − r .. 7) 2ⁱ = 256 − 2⁸⁻ʳ
```

Числове значення `Δ = 2⁸⁻ʳ = 256 − M_boundary` у мережевій інженерії називається **магічним числом** або кроком підмережі в граничному октеті. Воно показує дискретний крок додавання між сусідніми підмережами: кожна наступна підмережа починається рівно на `Δ` вище за попередню.

### Лінійна алгебра векторного простору над GF(2)

Якщо розглядати 32-бітну адресу як вектор-стовпчик `v ∈ (GF(2))³²`:

```
v = [ v₃₁, v₃₀, ..., v₁, v₀ ]ᵀ
```

тоді операція накладання маски довжини `n` еквівалентна множенню вектора `v` на діагональну проєкційну матрицю `Pₙ` розмірності `32 × 32`:

```
Pₙ = diag( 1, ..., 1 [n разів], 0, ..., 0 [32-n разів] )
```

Ранг матриці `rank(Pₙ) = n`. Ядро лінійного відображення `Ker(Pₙ)` має розмірність `dim(Ker(Pₙ)) = 32 − n = h` і являє собою векторний підпростір усіх можливих комбінацій номерів хостів:

```
Ker(Pₙ) = { v ∈ (GF(2))³² : v₃₁ = v₃₀ = ... = v₃₂₋ₙ = 0 }
```

Образ матриці `Im(Pₙ)` має розмірність `dim(Im(Pₙ)) = n` і визначає множину всіх допустимих адрес підмереж.

Будь-яка підмережа `Subnet(A, n)` у термінах лінійної алгебри є **афінним підпростором** (суміжним класом або шаром фактор-простору `(GF(2))³² / Ker(Pₙ)`):

```
Subnet(A, n) = Net(A, n) + Ker(Pₙ) = { Net(A, n) ⊕ h : h ∈ Ker(Pₙ) }
```

Кількість неперетинних підмереж даної фіксованої довжини `n` точно дорівнює потужності фактор-простору:

```
| (GF(2))³² / Ker(Pₙ) | = 2³² / 2ʰ = 2ⁿ
```

### Ультраметричний простір підмереж та ієрархія префіксів

Множина всіх двійкових префіксів утворює метричний простір особливого типу — **ультраметричний простір** (англ. *ultrametric space*).

Для двох адрес `X, Y ∈ {0, 1}³²` визначимо функцію спільного префікса `lcp(X, Y)` (найдовший спільний префікс, англ. *longest common prefix*):

```
lcp(X, Y) = max { k ∈ [0, 32] : Net(X, k) = Net(Y, k) }
```

Відстань між двома адресами визначається експоненційною метрикою:

```
d_ultra(X, Y) = 2^(-lcp(X, Y))   якщо X ≠ Y, та d_ultra(X, X) = 0
```

Ця метрика задовольняє сильну нерівність трикутника (аксіому ультраметрики):

```
d_ultra(X, Z) ≤ max( d_ultra(X, Y), d_ultra(Y, Z) )
```

З властивостей ультраметричних просторів випливають дві фундаментальні топологічні властивості підмереж:

1. **Принцип «куля в кулі»:** будь-які дві підмережі (відкриті кулі в ультраметриці) або повністю не перетинаються, або одна підмережа цілком міститься всередині іншої. Не існує часткового перекриття з непустим власним перетином.
2. **Кожна точка є центром:** будь-яка довільна IP-адреса всередині підмережі `A ∈ Subnet(N, n)` може слугувати еквівалентним представником цього класу при накладанні проєктора `Net(·, n)`.

### Теорема про кратне вирівнювання меж (Power-of-Two Boundary)

У практичній адресації виникає запитання: чи можна обрати довільний діапазон із `2ʰ` послідовних адрес і призначити йому маску `/n`? Алгебраїчна відповідь є категорично негативною.

#### Формулювання теореми

Неперервний інтервал адрес `[B, B + 2ʰ − 1]` потужністю `2ʰ` утворює валідну підмережу з маскою `M(32 − h)` тоді і тільки тоді, коли початкове числове значення адреси `B` ділиться націло на розмір блоку `2ʰ`:

```
B mod 2ʰ = 0
```

#### Доведення

Запишемо довільну 32-бітну адресу `B` у позиційному двійковому базисі:

```
B = ∑ (i = 0 .. 31) bᵢ · 2ⁱ = ∑ (i = h .. 31) bᵢ · 2ⁱ + ∑ (i = 0 .. h − 1) bᵢ · 2ⁱ
```

**1. Доведення необхідності (якщо інтервал є підмережею, то `B mod 2ʰ = 0`):**

За означенням мережевої адреси, початкова точка інтервалу `B` мусить бути фіксованою точкою оператора `Net(·, 32 − h)`:

```
B = Net(B, 32 − h) = B ∧ M(32 − h)
```

Маска `M(32 − h)` має точний вигляд:

```
M(32 − h) = ∑ (i = h .. 31) 1 · 2ⁱ + ∑ (i = 0 .. h − 1) 0 · 2ⁱ
```

Обчислюючи порозрядний добуток `B ∧ M(32 − h)` для кожного розряду `i ∈ [0, h − 1]`, маємо:

```
bᵢ = bᵢ ∧ 0 = 0   для всіх i ∈ [0, h − 1]
```

Це означає, що у двійковому записі числа `B` молодша група з `h` бітів складається виключно з нулів.
Тоді молодша сума розкладу обнуляється:

```
∑ (i = 0 .. h − 1) bᵢ · 2ⁱ = 0
```

Підставляючи це значення у повний розклад числа `B`:

```
B = ∑ (i = h .. 31) bᵢ · 2ⁱ                               [обнулення молодших h бітів]
  = 2ʰ · ∑ (j = 0 .. 31 − h) b_(j+h) · 2ʲ                 [винесення множника 2^h]
  = 2ʰ · K                                                [де K — ціле невід'ємне число]
```

Оскільки `B = K · 2ʰ`, залишок від ділення `B mod 2ʰ` дорівнює нулю. Необхідність доведено.

**2. Доведення достатності (якщо `B mod 2ʰ = 0`, то інтервал є підмережею):**

Нехай числове значення `B` кратне `2ʰ`, тобто `B = K · 2ʰ`.
Тоді двійковий запис числа `B` містить нулі в усіх розрядах від `0` до `h − 1`.
Застосуємо оператор мережевої адреси:

```
B ∧ M(32 − h) = (K · 2ʰ) ∧ (2³² − 2ʰ)                      [підстановка аналітичного виразу маски]
              = K · 2ʰ                                    [оскільки молодші h бітів уже є нулями]
              = B                                         [вихідне значення відновлено]
```

Оскільки `B ∧ M(32 − h) = B`, адреса `B` є валідною мережевою адресою, а додавання вектора хоста `H ∈ [0, 2ʰ − 1]` породжує взаємно однозначне відображення на повний інтервал `[B, B + 2ʰ − 1]`. Достатність доведено. ∎

#### Геометричний приклад

Для префікса `/27` маємо `h = 32 − 27 = 5`, отже розмір блоку `S = 2⁵ = 32`.
Усі коректні мережеві адреси в межах будь-якого октету мусять бути кратними 32: `0, 32, 64, 96, 128, 160, 192, 224`. Діапазон адрес від `192.168.1.16` до `192.168.1.47` має розмір 32 адреси, але **не є валідною підмережею**, оскільки `16 mod 32 = 16 ≠ 0`.

### Теорема про неперетинання інтервалів VLSM (Prefix Disjointness)

Під час ієрархічного розбиття адресного простору змінними масками критично важливо гарантувати, що жодні два призначені префікси не мають спільних адрес.

#### Формулювання теореми

Нехай задано дві довільні підмережі `P₁ = (N₁, n₁)` та `P₂ = (N₂, n₂)` з довжинами префіксів `n₁ ≤ n₂`.

Інтервали підмереж або взаємно не перетинаються (`P₁ ∩ P₂ = ∅`), або підмережа `P₂` повністю вкладена в підмережу `P₁` (`P₂ ⊆ P₁`).

При цьому умова строгого неперетинання виконується тоді і тільки тоді, коли результат застосування коротшої маски `M(n₁)` до мережевої адреси `N₂` не збігається з мережевою адресою `N₁`:

```
P₁ ∩ P₂ = ∅   ⟺   (N₂ ∧ M(n₁)) ≠ N₁
```

#### Доведення

Запишемо інтервали підмереж у явному вигляді:

```
P₁ = [ N₁, N₁ + 2³²⁻ⁿ¹ − 1 ]
P₂ = [ N₂, N₂ + 2³²⁻ⁿ² − 1 ]
```

Оскільки `n₁ ≤ n₂`, показник степеня `32 − n₁ ≥ 32 − n₂`, звідки випливає, що ємність `S(n₁)` ділиться націло на ємність `S(n₂)`:

```
2³²⁻ⁿ¹ = 2ⁿ²⁻ⁿ¹ · 2³²⁻ⁿ² = q · 2³²⁻ⁿ²   (де q = 2ⁿ²⁻ⁿ¹ ∈ N)
```

Припустимо від супротивного, що підмережі мають бодай одну спільну адресу `X ∈ P₁ ∩ P₂`.
За означенням належності до інтервалів маємо:

```
X ∧ M(n₂) = N₂                                            [належність X до підмережі P2]
X ∧ M(n₁) = N₁                                            [належність X до підмережі P1]
```

Застосуємо проєктор коротшої маски `M(n₁)` до першої рівності:

```
(X ∧ M(n₂)) ∧ M(n₁) = N₂ ∧ M(n₁)                          [накладення маски M(n1) на обидві частини]
X ∧ (M(n₂) ∧ M(n₁)) = N₂ ∧ M(n₁)                          [асоціативність побітового множення]
X ∧ M(n₁)           = N₂ ∧ M(n₁)                          [оскільки n1 <= n2, M(n2) ∧ M(n1) = M(n1)]
N₁                  = N₂ ∧ M(n₁)                          [підстановка рівності X ∧ M(n1) = N1]
```

Отримана рівність `N₂ ∧ M(n₁) = N₁` свідчить про те, що вся підмережа `P₂` є підмножиною підмережі `P₁`:

```
P₂ ⊆ P₁
```

Це доводить, що часткове (транзитивне) перекриття меж підмереж для двійкових префіксів є математично неможливим: один префікс або повністю поглинає інший, або вони є повністю диз'юнктними (`P₁ ∩ P₂ = ∅`).

Отже, критерієм повної незалежності двох підмереж є невиконання умови поглинання, тобто `(N₂ ∧ M(n₁)) ≠ N₁`. Теорему доведено. ∎

### Аналіз фрагментації та ефективності розподілу адрес

Під час виділення адресного блоку розміром `S = 2ʰ` для обслуговування потреби в `R` корисних хостах виникає два типи втрат адресного простору: внутрішня та зовнішня фрагментація.

#### 1. Внутрішня фрагментація (Internal Fragmentation)

Внутрішня фрагментація виникає внаслідок дискретності степенів двійки: якщо мережі потрібно `R` адрес, виділяється блок `S = 2^⌈log₂(R + 2)⌫`. Коефіцієнт внутрішньої фрагментації `Φ_int` визначається як частка невикористаних адрес усередині виділеного блоку:

```
Φ_int(R) = ( S − (R + 2) ) / S = 1 − (R + 2) / 2^⌈log₂(R + 2)⌫
```

Найгірший випадок внутрішньої фрагментації настає, коли число необхідних адрес на одиницю перевищує степінь двійки: `R + 2 = 2ᵏ + 1`. Тоді виділяється блок розміром `S = 2ᵏ⁺¹`, і коефіцієнт фрагментації наближається до 50%:

```
Φ_int_max = ( 2ᵏ⁺¹ − (2ᵏ + 1) ) / 2ᵏ⁺¹ = ( 2ᵏ − 1 ) / 2ᵏ⁺¹ = 1/2 − 1/2ᵏ⁺¹ ≈ 50%
```

Найкращий випадок настає при точній рівності `R + 2 = 2ᵏ`, коли `Φ_int = 0%`.

#### 2. Зовнішня фрагментація (External Fragmentation)

Зовнішня фрагментація виникає, коли сумарний обсяг вільного адресного простору достатній для задоволення запиту, але він розбитий на ізольовані несуміжні інтервали, жоден із яких не задовольняє умову кратності `B mod S = 0`.

Коефіцієнт зовнішньої фрагментації `Φ_ext` визначається як частка вільного адресного простору `V_free`, яку неможливо виділити під запит розміру `S_target`:

```
Φ_ext = 1 − ( ∑ (інтервали Iⱼ: |Iⱼ| ≥ S_target ∧ Bⱼ mod S_target = 0) |Iⱼ| ) / V_free
```

### Теорема про агрегацію префіксів (Supernetting Condition)

Зворотна задача до підмережевої адресації — згортання двох суміжних маршрутів у єдиний узагальнений префікс (агрегація маршрутів).

#### Формулювання теореми

Дві рівновеликі підмережі `P_left = (N₁, n)` та `P_right = (N₂, n)` з однаковою довжиною префікса `n` можуть бути коректно об'єднані в одну сумарну підмережу `P_parent = (N_parent, n − 1)` ємністю `2³²⁻ⁿ⁺¹` тоді і тільки тоді, коли одночасно виконано дві умови:

1. **Кратність базової адреси:** мережева адреса `N₁` вирівняна за маскою `M(n − 1)`:
   `N₁ ∧ M(n − 1) = N₁`.
2. **Бінарна суміжність:** адреса другої підмережі `N₂` відрізняється від `N₁` рівно в одному `(32 − n)`-му біті:
   `N₂ = N₁ + 2³²⁻ⁿ`.

#### Доведення

Об'єднаний інтервал мусить дорівнювати об'єднанню інтервалів двох вихідних підмереж:

```
Subnet(N_parent, n − 1) = Subnet(N₁, n) ∪ Subnet(N₂, n)
```

Нижня межа об'єднаного інтервалу дорівнює `N₁`, а верхня межа:

```
Brd(N₂, n) = N₂ + 2³²⁻ⁿ − 1
           = (N₁ + 2³²⁻ⁿ) + 2³²⁻ⁿ − 1                     [підстановка умови суміжності N2 = N1 + 2^(32-n)]
           = N₁ + 2 · 2³²⁻ⁿ − 1                           [групування доданків]
           = N₁ + 2³²⁻⁽ⁿ⁻¹⁾ − 1                           [властивість степеня двійки]
```

Отриманий інтервал `[N₁, N₁ + 2³²⁻⁽ⁿ⁻¹⁾ − 1]` строго збігається з інтервалом підмережі з префіксом `n − 1` та початком `N₁`. Доведено. ∎

Якщо дві підмережі `/24` мають адреси `192.168.1.0/24` та `192.168.2.0/24`, вони **не можуть бути агреговані** в єдиний блок `/23`, оскільки `192.168.1.0` не вирівняна за межею `/23` (`1 mod 2 = 1 ≠ 0`). Натомість підмережі `192.168.2.0/24` та `192.168.3.0/24` утворюють валідний супернет `192.168.2.0/23`.

### Топологія двійкового дерева (Prefix Trie) та оптимальне пакування

Адресний простір `Z_(2³²)` ізоморфний повному двійковому дереву глибини 32, де корінь відповідає префіксу `0.0.0.0/0`, ліве ребро додає двійковий розряд `0`, а праве ребро — двійковий розряд `1`.

```
                    0.0.0.0/0 (2³²)
                   /               \
            0 (ліворуч)          1 (праворуч)
                 /                   \
        0.0.0.0/1 (2³¹)         128.0.0.0/1 (2³¹)
           /        \               /         \
    0.0.0.0/2    64.0.0.0/2   128.0.0.0/2  192.0.0.0/2
```

Виділення підмережі з префіксом `/n` відповідає видаленню (маркуванню зайнятим) повного піддерева з коренем у вузлі глибини `n`.

#### Теорема про жадібне пакування без фрагментації

Нехай маємо вихідний пул адрес розміром `2ᴸ` та набір запитів на створення підмереж із вимогами до кількості корисних хостів `R₁, R₂, ..., Rₘ`.

Для кожного запиту розраховується мінімально необхідна ємність підмережі `Sᵢ = 2ʰⁱ`, де `hᵢ = ⌈log₂(Rᵢ + 2)⌫` та `nᵢ = 32 − hᵢ`.

Якщо впорядкувати всі запити за незростанням необхідного розміру:

```
S₁ ≥ S₂ ≥ S₃ ≥ ... ≥ Sₘ   (відповідно n₁ ≤ n₂ ≤ n₃ ≤ ... ≤ nₘ)
```

і послідовно призначати кожній підмережі найменшу доступну вільну адресу `Bᵢ`, що задовольняє умову вирівнювання `Bᵢ mod Sᵢ = 0`, то:

1. Отримане розбиття повністю виключає зовнішню фрагментацію адресного пулу (між сусідніми виділеними блоками ніколи не виникає неможливих до використання вільних інтервалів).
2. Сумарний зайнятий адресний простір є строго компактним і мінімальним.

#### Доведення індукцією

Нехай після виділення перших `k − 1` підмереж сумарний виділений обсяг адрес становить:

```
V_(k−1) = ∑ (j = 1 .. k − 1) Sⱼ
```

Оскільки за правилом сортування кожен попередній блок `Sⱼ` (для `j < k`) задовольняє умову `Sⱼ ≥ Sₖ`, а всі `Sⱼ` та `Sₖ` є степенями двійки, то кожен розмір `Sⱼ` ділиться на `Sₖ` націло:

```
Sⱼ mod Sₖ = 0   для всіх j < k
```

Отже, вся накопичена сума виділених адрес `V_(k−1)` також ділиться націло на `Sₖ`:

```
V_(k−1) mod Sₖ = ( ∑ (j = 1 .. k − 1) Sⱼ ) mod Sₖ = 0
```

Це означає, що початкова адреса наступного доступного простору `Bₖ = B_start + V_(k−1)` **вже ідеально вирівняна** за необхідною межею `Sₖ` (`Bₖ mod Sₖ = 0`). Немає потреби пропускати жодної адреси для досягнення кратності: новий блок розміщується впритул до попереднього.

Якщо ж порядок сортування порушено (наприклад, спочатку виділено малий блок `S₁ = 4`, а потім великий `S₂ = 64`), наступна вільна адреса `B_start + 4` не ділиться на 64 (`4 mod 64 = 4 ≠ 0`). Алгоритм змушений пропустити 60 адрес до найближчої адреси `B_start + 64`. Утворений проміжок із 60 адрес стає «діркою» зовнішньої фрагментації, куди неможливо вкласти блок на 64 адреси.

Отже, монотонне спадання розмірів підмереж є математично доведеною умовою оптимального безвідходного розміщення префіксів у дереві VLSM.

### Граничні топологічні випадки: префікси /31 та /32

У загальній теорії підмереж існують два особливі граничні випадки:

#### 1. Префікс /31 (RFC 3021)

Для префікса `n = 31` маємо `h = 32 − 31 = 1`, отже `S = 2¹ = 2`.
У класичній моделі число корисних хостів дорівнювало б `2¹ − 2 = 0`. Проте для двоточкового лінійного графу зв'язку `K₂` (канал точка-точка) маршрутизатор завжди має рівно одного сусіда на інтерфейсі.

Алгебраїчно відпадає потреба в широкомовленні (будь-який пакет, відправлений в інтерфейс, фізично може дійти лише до єдиного парного вузла) та в окремому ідентифікаторі мережі в таблицях безпосередньо підключених інтерфейсів.
Адреси `B` та `B + 1` утворюють бієктивну пару для кінцевих інтерфейсів каналу:

```
Interface_A = B + 0
Interface_B = B + 1
```

#### 2. Префікс /32 (Host Route)

Для префікса `n = 32` маємо `h = 32 − 32 = 0`, отже `S = 2⁰ = 1`.
Ядро лінійного відображення вироджується в нуль-простір: `dim(Ker(P₃₂)) = 0`.
Кожен вектор є власним одноелементним афінним простором `Subnet(A, 32) = { A }`. Застосовується для віртуальних Loopback-інтерфейсів та точкових хостових маршрутів.

### Покроковий числовий приклад адресної декомпозиції

Розглянемо числовий приклад розрахунку характеристик підмережі для адреси `A = 172.24.139.73` з довжиною префікса `n = 19`.

**Крок 1. Переведення октетів у двійкове представлення:**

```
Октет 1: 172 = 128 + 32 + 8 + 4        ->  10101100
Октет 2:  24 = 16 + 8                  ->  00011000
Октет 3: 139 = 128 + 8 + 2 + 1         ->  10001011
Октет 4:  73 = 64 + 8 + 1              ->  01001001
---------------------------------------------------
A = 10101100 . 00011000 . 10001011 . 01001001  (2 887 289 673 у десятковій формі)
```

**Крок 2. Побудова маски `M(19)` та інверсної маски `W(19)`:**

Маска містить 19 одиниць та `32 − 19 = 13` нулів:

```
M(19) = 11111111 . 11111111 . 11100000 . 00000000  (255.255.224.0)
W(19) = 00000000 . 00000000 . 00011111 . 11111111  (0.0.31.255)
```

**Крок 3. Обчислення мережевої адреси `Net(A, 19)`:**

```
  10101100 . 00011000 . 10001011 . 01001001  (172.24.139.73)
∧ 11111111 . 11111111 . 11100000 . 00000000  (255.255.224.0)
-------------------------------------------------------------
= 10101100 . 00011000 . 10000000 . 00000000  (172.24.128.0)
```

**Крок 4. Обчислення широкомовної адреси `Brd(A, 19)`:**

```
  10101100 . 00011000 . 10001011 . 01001001  (172.24.139.73)
∨ 00000000 . 00000000 . 00011111 . 11111111  (0.0.31.255)
-------------------------------------------------------------
= 10101100 . 00011000 . 10011111 . 11111111  (172.24.159.255)
```

**Крок 5. Розрахунок діапазону та ємності:**

- Повна ємність блоку: `S = 2¹³ = 8192` адрес.
- Перший корисний хост: `Net(A, 19) + 1 = 172.24.128.1`.
- Останній корисний хост: `Brd(A, 19) − 1 = 172.24.159.254`.
- Число корисних хостів: `2¹³ − 2 = 8190` адрес.
