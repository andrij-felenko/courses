# 🧮 Розрахунок бюджету радіолінії та доплерівського зсуву для LEO/GEO IoT

Енергетичний розрахунок супутникової лінії зв'язку (Link Budget) визначає, чи зможе сигнал від малопотужного автономного передавача подолати відстань у сотні або тисячі кілометрів космічного простору та бути коректно демодульованим приймачем супутника при заданому рівні шумів та завад.

## 1. Втрати поширення у вільному просторі (FSPL)

Електромагнітна хвиля, випромінена ізотропною антеною з потужністю `P_t`, рівномірно розсіюється по сфері радіуса `d`. Густина потоку потужності на відстані `d` дорівнює:

```
S = P_t / (4 · π · d²)    [густина потоку потужності на сфері площею 4πd²]
```

Приймальна антена з ефективною апертурою `A_eff = λ² / (4 · π)` вловлює потужність `P_r = S · A_eff`:

```
P_r = (P_t / (4 · π · d²)) · (λ² / (4 · π))    [множення густини потоку на апертуру]
    = P_t · (λ / (4 · π · d))²                [формула передачі Фрііса для ізотропних антен]
```

Відношення потужності випромінювання до потужності прийому визначає коефіцієнт втрат вільного простору (FSPL — *Free-Space Path Loss*):

```
FSPL_linear = P_t / P_r                       [відношення переданої до прийнятої потужності]
            = (4 · π · d / λ)²                [підстановка довжини хвилі]
            = (4 · π · d · f / c)²            [підстановка зв'язку довжини хвилі та частоти λ = c / f]
```

У логарифмічній шкалі (децибелах) рівняння набуває канонічного інженерного вигляду:

```
FSPL [дБ] = 10 · log10((4 · π · d · f / c)²)                      [перехід до десяткових логарифмів]
          = 20 · log10(d) + 20 · log10(f) + 20 · log10(4 · π / c)  [розкладання добутку на суму логарифмів]
```

Підставивши швидкість світла у вакуумі `c ≈ 2.99792458 × 10⁸ м/с`, відстань `d` у кілометрах та частоту `f` у мегагерцах, отримуємо розрахункову формулу:

```
20 · log10(4 · π · 10³ · 10⁶ / 2.99792458 × 10⁸)    [зведення числових констант]
= 20 · log10(41.9169)                                [обчислення аргументу логарифма]
≈ 32.44 дБ                                           [числова константа рівняння]

FSPL [дБ] = 32.44 + 20 · log10(d_км) + 20 · log10(f_МГц)
```

## 2. Порівняльний розрахунок втрат: LEO (Iridium) проти GEO (Inmarsat)

Розрахуємо втрати у вільному просторі для двох типових сценаріїв супутникового зв'язку IoT на куті підвищення антени 30° над горизонтом (нахилена траєкторія крізь атмосферу).

### Сценарій А: Низька навколоземна орбіта (LEO — Iridium, f = 1621.25 МГц)

При висоті орбіти `h = 780 км` та куті місця `elevation = 30°`, похила дальність `d_slant` до супутника обчислюється через радіус Землі `R_E = 6371 км`:

```
d_slant = √(R_E² · sin²(elev) + 2 · R_E · h + h²) - R_E · sin(elev)          [геометрична формула похилої дальності]
        = √((6371 · sin(30°))² + 2 · 6371 · 780 + 780²) - 6371 · sin(30°)    [підстановка радіуса Землі та висоти]
        = √(3185.5² + 9938760 + 608400) - 3185.5                             [обчислення тригонометрії кута 30°]
        = √(10147410 + 9938760 + 608400) - 3185.5                            [піднесення до квадрата]
        = √(20694570) - 3185.5                                               [сумування компонентів під коренем]
        = 4549.1 - 3185.5                                                    [добування квадратного кореня]
        = 1363.6 км                                                          [похила відстань до супутника LEO]
```

Обчислюємо втрати FSPL для Iridium:

```
FSPL_LEO = 32.44 + 20 · log10(1363.6) + 20 · log10(1621.25)    [підстановка d = 1363.6 км та f = 1621.25 МГц]
         = 32.44 + 20 · 3.1347 + 20 · 3.2098                    [обчислення десяткових логарифмів]
         = 32.44 + 62.69 + 64.20                                [множення на коефіцієнт 20]
         = 159.33 дБ                                            [підсумкові втрати поширення]
```

### Сценарій Б: Геостаціонарна орбіта (GEO — Inmarsat, f = 1540 МГц)

Геостаціонарний супутник розташований на висоті `h = 35 786 км`. Для помірних широт похила відстань становить приблизно `d ≈ 38 500 км`:

```
FSPL_GEO = 32.44 + 20 · log10(38500) + 20 · log10(1540.0)      [підстановка d = 38500 км та f = 1540 МГц]
         = 32.44 + 20 · 4.5855 + 20 · 3.1875                    [обчислення десяткових логарифмів]
         = 32.44 + 91.71 + 63.75                                [множення на коефіцієнт 20]
         = 187.90 дБ                                            [підсумкові втрати поширення]
```

Різниця у втратах між LEO та GEO становить:

```
ΔFSPL = FSPL_GEO - FSPL_LEO                             [різниця втрат вільного простору]
      = 187.90 - 159.33                                 [віднімання значень у дБ]
      = 28.57 дБ                                        [сигнал GEO слабший у 719 разів за потужністю]
```

Саме ці додаткові `~28.6 дБ` змушують термінали геостаціонарного зв'язку використовувати або параболічні дзеркала з високим підсиленням, або передавачі потужністю понад 10–20 Вт, що унеможливлює створення ультракомпактних кишенькових IoT-маяків.

## 3. Еквівалентна шумова температура та чутливість системи

Загальна шумова потужність на вході радіоприймального тракту супутника залежить не лише від власного коефіцієнта шуму приймача, а й від радіояскравісної температури Землі та космічного простору, яку бачить антена.

### Шумова температура приймальної системи

Еквівалентна шумова температура приймальної системи `T_sys`, приведена до входу антени, визначається формулою каскадного шуму:

```
T_sys = T_ant + T_feed · (L_feed - 1) + T_rx · L_feed    [шум антени, фідера та приймача]
```

Де:
- `T_ant` — шумова температура антени, що визначається випромінюванням поверхні Землі (`T_earth ≈ 290 К`) та атмосфери;
- `L_feed` — лінійний коефіцієнт втрат у фідерному тракті (`L_feed = 10^(0.5 / 10) ≈ 1.122`);
- `T_feed` — фізична температура фідера (`290 К`);
- `T_rx` — еквівалентна шумова температура приймача, яка визначається його коефіцієнтом шуму `NF` (Noise Figure):

```
T_rx = T_0 · (10^(NF / 10) - 1)    [де T_0 = 290 К — стандартна температура]
```

Для супутникового малошумного підсилювача (LNA) з коефіцієнтом шуму `NF = 2.5 дБ`:

```
T_rx = 290 · (10^(2.5 / 10) - 1)    [підстановка NF = 2.5 дБ]
     = 290 · (1.7783 - 1)           [переведення дБ у лінійний масштаб]
     = 290 · 0.7783                 [обчислення надлишкового множника]
     ≈ 225.7 К                      [шумова температура приймача]
```

Обчислюємо загальну шумову температуру системи `T_sys` при шумовій температурі антени `T_ant = 290 К`:

```
T_sys = 290 + 290 · (1.122 - 1) + 225.7 · 1.122    [сумування шумових внесків]
      = 290 + 35.38 + 253.24                       [обчислення складових]
      ≈ 578.6 К                                    [підсумкова шумова температура системи]
```

Спектральна густина теплового шуму `N_0` визначається сталою Больцмана `k = 1.380649 × 10⁻²³ Дж/К`:

```
N_0 = k · T_sys                                         [формула Найквіста для густини шуму]
N_0 [дБм/Гц] = -174.0 + 10 · log10(T_sys / 290)         [логарифмічна форма]
             = -174.0 + 10 · log10(578.6 / 290)         [підстановка T_sys = 578.6 К]
             = -174.0 + 10 · log10(1.995)               [обчислення відношення температур]
             = -174.0 + 3.00                            [додавання теплової поправки]
             = -171.00 дБм/Гц                           [спектральна густина шуму системи]
```

## 4. Повний каскадний баланс Uplink (Бюджет радіолінії)

Для надійного прийому відношення потужності сигналу до густини шуму на вході демодулятора супутника `(C / N_0)` повинно перевищувати мінімальний поріг демодуляції з урахуванням запасу на загасання (Link Margin `M ≥ 3…6 дБ`).

Рівняння потужності сигналу на вході приймача `P_rx`:

```
P_rx [дБм] = P_tx + G_tx - L_tx_feed - FSPL - L_atm - L_pol + G_rx - L_rx_feed
```

Розрахунок для передавача Iridium 9603N (`P_tx = +32 дБм` / 1.58 Вт):

```
P_tx       = +32.0 дБм     [вихід підсилювача потужності трансивера]
G_tx       = +2.5 дБі      [підсилення керамічної патч-антени IoT]
L_tx_feed  = -0.5 дБ       [втрати у кабелі U.FL та мікросмужковій лінії]
EIRP       = +34.0 дБм     [еквівалентна ізотропно-випромінювана потужність]

FSPL       = -159.3 дБ     [втрати вільного простору на трасі 1363 км]
L_atm      = -0.8 дБ       [поглинання киснем, вологою повітря та хмарами]
L_pol      = -1.2 дБ       [неідеальність кругової поляризації антени (Axial Ratio)]
G_rx       = +6.0 дБі      [підсилення фазованої антенної решітки супутника]
L_rx_feed  = -1.0 дБ       [втрати у вхідному тракті супутника]

P_rx = 34.0 - 159.3 - 0.8 - 1.2 + 6.0 - 1.0    [сума підсилень та втрат тракту]
     = -122.3 дБм                              [потужність на вході МШУ супутника]
```

### Відношення сигнал/шум та енергія біта

Відношення потужності несучої до густини шуму `C / N_0`:

```
C / N_0 = P_rx - N_0                         [різниця потужності сигналу та густини шуму]
        = -122.3 дБм - (-171.00 дБм/Гц)      [віднімання значень у дБм]
        = 48.70 дБ·Гц                        [відношення несуча/шум]
```

Для передачі даних зі швидкістю `R = 2400 біт/с` енергія на один інформаційний біт до густини шуму `E_b / N_0` становить:

```
E_b / N_0 = C / N_0 - 10 · log10(R)         [віднімання швидкості передачі даних R]
          = 48.70 - 10 · log10(2400)         [підстановка швидкості 2400 біт/с]
          = 48.70 - 33.80                    [обчислення логарифма швидкості]
          = 14.90 дБ                         [енергія біта до густини шуму]
```

Для когерентної демодуляції QPSK із прямим виправленням помилок (FEC rate 1/2) для досягнення ймовірності бітової помилки `BER = 10⁻⁵` необхідний поріг `(E_b / N_0)_req = 6.5 дБ`.

Обчислюємо підсумковий енергетичний запас каналу (Link Margin):

```
Margin = E_b / N_0 - (E_b / N_0)_req           [різниця між наявним та пороговим Eb/N0]
       = 14.90 - 6.50                          [віднімання значень у дБ]
       = +8.40 дБ                              [достатній запас для компенсації неглибоких завмирань]
```

## 5. Математика доплерівського зсуву частоти на низьких орбітах (LEO)

Орбітальна швидкість супутника на круговій орбіті висотою `h` обчислюється із закону всесвітнього тяжіння:

```
v_orb = √(G · M_E / (R_E + h))
```

де гравітаційний параметр Землі `μ = G · M_E = 3.986004418 × 10¹⁴ м³/с²`, `R_E = 6 371 000 м`, `h = 780 000 м` (орбіта Iridium):

```
v_orb = √(3.986004418 × 10¹⁴ / (6371000 + 780000))    [підстановка радіуса Землі та висоти]
      = √(3.986004418 × 10¹⁴ / 7151000)                [радіус орбіти r = 7151 км]
      = √(55740517.6)                                  [ділення під коренем]
      ≈ 7466 м/с = 7.466 км/с                          [лінійна орбітальна швидкість]
```

Доплерівський зсув частоти несучої `f_0` при відносному русі з радіальною швидкістю `v_rel(t)` визначається формулою:

```
Δf(t) = f_0 · (v_rel(t) / c)
```

Радіальна швидкість `v_rel(t)` є проекцією вектора швидкості супутника на лінію візування між терміналом і космічним апаратом:

```
v_rel = v_orb · cos(θ)
```

де `θ` — кут між вектором швидкості супутника та напрямком на наземний пристрій. При наближенні супутника до горизонту (AOS — *Acquisition of Signal*) кут `θ` мінімальний:

```
cos(θ_max) ≈ (R_E / (R_E + h)) · cos(elev_min)          [тригонометричне співвідношення]
            = (6371 / 7151) · cos(0°)                   [підстановка нульового кута місця]
            ≈ 0.8909                                    [максимальний косинус кута]
```

Максимальна радіальна швидкість:

```
v_rel_max = 7466 м/с · 0.8909 ≈ 6651.5 м/с
```

Максимальний доплерівський зсув для частоти `f_0 = 1621.25 МГц`:

```
Δf_max = ± 1621.25 × 10⁶ · (6651.5 / 2.99792458 × 10⁸)    [підстановка f_0, v_rel_max та c]
       = ± 1621.25 × 10⁶ · 2.2187 × 10⁻⁵                  [обчислення коефіцієнта зсуву]
       = ± 35970 Гц ≈ ± 36.0 кГц                          [максимальний частотний зсув]
```

### Швидкість дрейфу частоти (Doppler Rate)

Найкритичнішим параметром для контуру автопідстроювання частоти (AFC/PLL) приймача є максимальна похідна зміни частоти за часом `d(Δf) / dt`, яка досягається в момент кульмінації (найближчого прольоту супутника над головою в зеніті при `elevation = 90°`):

```
(d(Δf) / dt)_zenith = - f_0 · (v_orb² / (c · h))                                     [формула дрейфу в зеніті]
                    = - 1621.25 × 10⁶ · (7466² / (2.99792458 × 10⁸ · 780000))       [підстановка параметрів]
                    = - 1621.25 × 10⁶ · (55741156 / (2.33838 × 10¹⁴))               [обчислення знаменника]
                    = - 1621.25 × 10⁶ · 2.38375 × 10⁻⁷                              [множення частоти]
                    ≈ - 386.5 Гц/с                                                   [максимальна швидкість дрейфу]
```

## 6. Тривалість вікна видимості супутника LEO (Contact Pass Time)

Для автономного термінала важливо знати тривалість сеансу радіозв'язку (вікна видимості). Центральний кут видимості `γ_max` для мінімального кута місця антени `elev_min = 10°` визначається теоремою синусів для трикутника Земля–термінал–супутник:

```
sin(α) = (R_E / (R_E + h)) · cos(elev_min)            [кут між супутником та центром Землі]
       = (6371 / 7151) · cos(10°)                     [підстановка радіусів та кута 10°]
       = 0.8909 · 0.9848                              [обчислення добутку]
       ≈ 0.8773                                       [значення синуса]
α = arcsin(0.8773) ≈ 61.32°                           [кут при супутнику]

γ_max = 90° - elev_min - α                            [центральний кутовий радіус соти]
      = 90° - 10° - 61.32°                            [віднімання кутів трикутника]
      = 18.68° ≈ 0.3260 рад                           [максимальний центральний кут]
```

Орбітальний період супутника `P_orb`:

```
P_orb = 2 · π · √((R_E + h)³ / μ)                     [третій закон Кеплера для кругової орбіти]
      = 2 · π · √(7151000³ / (3.986004418 × 10¹⁴))    [підстановка гравітаційного параметра]
      = 2 · π · √(3.6568 × 10²⁰ / (3.9860 × 10¹⁴))   [ділення під коренем]
      = 2 · π · √(9.1741 × 10⁵)                       [обчислення кореня]
      = 2 · π · 957.8                                 [множення на 2π]
      ≈ 6018 с ≈ 100.3 хв                             [повний період одного оберту довкола Землі]
```

Максимальна тривалість прольоту супутника через зеніт `T_pass_max`:

```
T_pass_max = P_orb · (2 · γ_max / 360°)               [пропорція кута до повного оберту 360°]
           = 6018 · (2 · 18.68° / 360°)               [підстановка параметрів орбіти Iridium]
           = 6018 · (37.36 / 360)                     [обчислення кутової частки]
           = 6018 · 0.10378                           [множення на період]
           ≈ 624.5 с ≈ 10.4 хв                        [максимальне вікно зв'язку за один проліт]
```

Для бокових непрохідних траєкторій (проліт супутника збоку від зеніту) тривалість вікна скорочується до `3–6 хвилин`. За цей час мікроконтролер повинен встигнути пробудитися, виконати синхронізацію, завантажити пакет та гарантовано завершити транзакцію в ефірі.

## 7. Вплив низьких кутів місця та замирання сигналу (Low Elevation Fading)

Коли супутник перебуває на кутах підвищення менше `10°–15°` над горизонтом, радіопромінь проходить значно довший шлях крізь тропосферу та іоносферу. Оптична товщина атмосфери (повітряна маса `M_air`) масштабується пропорційно секансу зенітного кута `z = 90° - elev`:

```
M_air ≈ 1 / sin(elev + 0.0548 · (elev + 2.65)⁻¹·²)    [наближення Кастена–Янга]
```

Для кута `elev = 10°` повітряна маса становить `M_air ≈ 5.6`, що збільшує поглинання газами в 5.6 раза порівняно з зенітом.

Окрім атмосферного поглинання, на низьких кутах місця до прямого променя додаються відбиття від поверхні землі або води (багатопроменевість / Multipath):

```
P_fade_margin = 10 · log10(1 + |Γ|² + 2 · |Γ| · cos(Δφ))    [інтерференція прямого та відбитого променів]
```

де `|Γ|` — модуль коефіцієнта відбиття поверхні (для сухого ґрунту `|Γ| ≈ 0.3…0.5`, для морської води `|Γ| ≈ 0.8…0.9`), `Δφ` — різниця фаз між променями. Деструктивна інтерференція може призводити до раптових провалів рівня сигналу глибиною до `8–14 дБ`, що вимагає закладання додаткового запасу (Fading Margin) у загальний баланс радіолінії термінала.
