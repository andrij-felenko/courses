# 🧮 Розрахунок порогів роумінгу, фільтрації RSSI та затримок хендоверу

У бездротових мережах рівень прийнятого сигналу RSSI (англ. *Received Signal Strength Indicator*) не є детермінованою величиною. Навіть коли мобільна станція залишається абсолютно нерухомою, миттєві покази потужності на антені коливаються з амплітудою до 10–15 dBm через багатопроменеве поширення радіохвиль (англ. *multipath fading*), релеївські завмирання та випадкове затінення рухомими перешкодами. Якщо керівний алгоритм клієнта реагує на сирі значення RSSI, виникає небезпечний ефект «пінг-понгу» — неперервне хаотичне перепідключення між двома сусідніми точками доступу. Математичний розрахунок параметрів цифрової фільтрації, порогів гістерезису, часових затримок та ймовірностей хибного спрацьовування дозволяє усунути нестабільність і мінімізувати час розриву зв'язку.

### 1. Модель радіозатухання та динаміка сигналу під час руху

Потужність сигналу `P_rx(d)` (у dBm) на відстані `d` від передавача точки доступу описується логарифмічною моделлю затухання на трасі з логнормальним затіненням (англ. *Log-Distance Path Loss with Shadowing*):

```
P_rx(d) = P_tx + G_tx + G_rx - PL(d₀) - 10 · n · log₁₀(d / d₀) + X_σ
```

де:
* `P_tx` — потужність передавача AP (зазвичай 15..20 dBm);
* `G_tx`, `G_rx` — коефіцієнти підсилення антен передавача й приймача (типово 2..3 dBi);
* `PL(d₀)` — базові втрати на опорній відстані `d₀ = 1 м` (для 2.4 ГГц `PL(1м) ≈ 40 dB`, для 5 ГГц `PL(1м) ≈ 47 dB`);
* `n` — показник згасання середовища (`n = 2` у вільному просторі, `n = 3.0 .. 4.5` усередині офісних будівель зі стінами);
* `X_σ` — випадкова величина з нульовим середнім і нормальним розподілом `N(0, σ²)`, що описує затінення перешкодами (дисперсія шуму `σ` становить від 3 до 6 dB).

Коли клієнт рухається зі швидкістю `v = 1.4 м/с` (середній темп пішохода) у напрямку від `AP₁` до `AP₂`, середня швидкість падіння сигналу `d(P_rx)/dt` становить:

```
d(P_rx) / dt = -(10 · n / ln(10)) · (v / d) ≈ -4.34 · n · (v / d)  [dB/с]
```

На відстані `d = 10 м` при `n = 3.5` градієнт спаду потужності сягає `2.1 dB/с`. Звідси випливає фундаментальне обмеження: період оновлення вимірювань і час реакції алгоритму роумінгу не повинні перевищувати 1–2 секунди, інакше сигнал впаде нижче межі чутливості приймача (-85 dBm) до моменту завершення хендоверу.

### 2. Цифрова фільтрація шумів сигналу (EWMA проти ковзної медіани)

Для видалення релеївських шумів `X_σ` використовують рекурсивне експоненційне зважене ковзне середнє (англ. *Exponentially Weighted Moving Average*, EWMA). Кожен новий вимір RSSI оновлює внутрішній стан фільтра:

```
RSSI_filtered[k] = α · RSSI_raw[k] + (1 - α) · RSSI_filtered[k - 1]
```

де `α ∈ (0, 1]` — коефіцієнт згладжування, а `k` — індекс вибірки. При періоді надходження маякових кадрів `T_beacon = 102.4 мс` постійна часу еквівалентного аперіодичного фільтра `τ` дорівнює:

```
τ = -T_beacon / ln(1 - α)

Для α ≤ 0.2:
τ ≈ T_beacon / α
```

Залишкове стандартне відхилення шуму після фільтрації `σ_filtered` пов'язане з дисперсією вхідного шуму `σ_raw` співвідношенням:

```
σ_filtered² = σ_raw² · (α / (2 - α))

σ_filtered = σ_raw · √(α / (2 - α))
```

**Порівняльний розрахунок фільтра для різних значень α:**
При типовому розкиді сирого шуму `σ_raw = 4.5 dBm`:

```
1) α = 0.5 (слабке згладжування):
   σ_filtered = 4.5 · √(0.5 / 1.5) = 4.5 · 0.577 ≈ 2.60 dBm
   τ ≈ 100 / 0.5 = 200 мс

2) α = 0.2 (оптимальне згладжування):
   σ_filtered = 4.5 · √(0.2 / 1.8) = 4.5 · 0.333 ≈ 1.50 dBm
   τ ≈ 100 / 0.2 = 500 мс

3) α = 0.05 (надмірне згладжування):
   σ_filtered = 4.5 · √(0.05 / 1.95) = 4.5 · 0.160 ≈ 0.72 dBm
   τ ≈ 100 / 0.05 = 2000 мс
```

Значення `α = 0.2` є інженерним оптимумом: воно зменшує розкид шуму втричі (з 4.5 до 1.5 dBm), а часова затримка реакції у 500 мс дозволяє відстежувати рух пішохода зі швидкістю до 2 м/с без втрати чутливості.

Альтернативою є медіанний фільтр ковзного вікна (англ. *Sliding Median Filter*) розміром `M = 5`. На відміну від лінійного середнього, медіанний фільтр повністю відсікає поодинокі екстремальні викиди (англ. *outliers*), спричинені перешкодами від мікрохвильових печей чи імпульсних передавачів Bluetooth, але потребує буферизації `M` вибірок та операції сортування `O(M · log M)` на кожен прийнятий beacon-кадр.

### 3. Математичний розрахунок запасу гістерезису та ймовірності пінг-понгу

Розглянемо дві сусідні точки доступу `AP₁` та `AP₂`. Клієнт перебуває в зоні перекриття, де математичні сподівання сигналів рівні: `μ₁ = μ₂`. Різниця згладжених вимірювань `D = RSSI_filtered(AP₂) - RSSI_filtered(AP₁)` є випадковою величиною з нормальним розподілом:

```
D ~ N(0, 2 · σ_filtered²)
```

Якщо правило перемикання вимагає простої переваги `RSSI₂ > RSSI₁`, станція буде перемикатися між точками на кожному кроці з ймовірністю `P = 0.5`. Для стабілізації вводиться поріг гістерезису `Δ_hysteresis > 0`, за якого перехід дозволяється лише за умови:

```
RSSI_filtered(AP₂) - RSSI_filtered(AP₁) > Δ_hysteresis
```

Ймовірність хибного зворотного переходу `P_pingpong` виражається через стандартизовану функцію Лапласа `Φ(z)`:

```
P_pingpong = 1 - Φ(Δ_hysteresis / (√2 · σ_filtered))

де Φ(z) = (1 / √(2π)) · ∫_{-∞}^{z} exp(-t² / 2) dt
```

Розрахуймо величину `Δ_hysteresis` для гарантування ймовірності хибного перемикання `P_pingpong ≤ 0.001` (одне хибне спрацьовування на 1000 вимірювань):

```
Квантиль нормального розподілу для P = 0.001:
z = 3.09

Δ_hysteresis
= z · √2 · σ_filtered           [формула порогу гістерезису]
= 3.09 · 1.4142 · 1.50          [підстановка значень для α = 0.2]
= 3.09 · 2.121
≈ 6.55 dBm                      [практичний поріг: 6..7 dB]
```

Встановлення порогу гістерезису `Δ_hysteresis = 6 dBm` у поєднанні з таймером затримки між повторними переходами (Holdoff Timer `T_holdoff ≥ 3..5 с`) гарантує математичну відсутність циклічних коливань.

### 4. Марковська модель станів роумінгу під час руху

Поведінку станції в зоні між двома точками можна промоделювати як дискретний ланцюг Маркова з двома основними станами `S₁` (асоційовано з AP₁) та `S₂` (асоційовано з AP₂).

Імовірність переходу `P₁₂` на кроці вимірювання `k` залежить від просторової координати `x(t)`:

```
P₁₂(x) = P(RSSI₂(x) - RSSI₁(x) > Δ_hysteresis) = 1 - Φ((Δ_hysteresis - (μ₂(x) - μ₁(x))) / (√2 · σ_filtered))
P₂₁(x) = P(RSSI₁(x) - RSSI₂(x) > Δ_hysteresis) = 1 - Φ((Δ_hysteresis - (μ₁(x) - μ₂(x))) / (√2 · σ_filtered))
```

З аналізу матриці ймовірностей видно, що ширина зони невизначеності (де жодна точка не може ініціювати перехід) розширюється пропорційно величині `Δ_hysteresis`. Якщо задати `Δ_hysteresis` занадто великим (наприклад, 15 dBm), станція почне страждати від деградації швидкості на старій точці доступу, перш ніж наважиться перемкнутися на нову.

### 5. Розрахунок часу перебування на каналі (Dwell Time)

Під час активного сканування тривалість перебування станції на кожному частотному каналі `T_dwell` розраховується за часовими інтервалами протоколу CSMA/CA:

```
T_dwell = T_pll_tune + DIFS + CW_min · T_slot + T_probe_req + SIFS + T_probe_resp + T_extra_wait
```

Для стандарту 802.11ax/ac у смузі 5 ГГц параметри фізичного рівня становлять:
* `T_pll_tune` (перемикання синтезатора частоти RF PLL) = `0.2 мс`;
* `DIFS` (Distributed Inter-Frame Space) = `34 мкс`;
* `T_slot` (тривалість тайм-слота) = `9 мкс`;
* `CW_min` (розмір вікна конкуренції) = `15`;
* `SIFS` (Short Inter-Frame Space) = `16 мкс`;
* `T_probe_req` (кадр 120 байтів на швидкості 6 Мбіт/с) ≈ `0.20 мс`;
* `T_probe_resp` (кадр 350 байтів на швидкості 6 Мбіт/с) ≈ `0.52 мс`.

Якщо на каналі немає активних точок доступу, станція чекає мінімальний інтервал `T_min_channel = 10 мс` і перемикається далі. Якщо надійде відповідь, таймер подовжується до `T_max_channel = 25..35 мс` для збору відповідей від усіх сусідніх точок на цій частоті.

### 6. Повний часовий баланс затримки хендоверу (Latency Budget)

Загальний час переривання зв'язку `T_blackout` визначається сумою послідовних фаз:

```
T_blackout = T_scan + T_tune + T_auth + T_reassoc + T_crypto + T_bridge
```

Зведемо результати розрахунку для чотирьох архітектурних конфігурацій:

```
1. Класичний WPA2-PSK (36 каналів без 802.11k/v/r):
   T_scan   = 36 каналів × 12 мс (середнє)    = 432 мс
   T_tune   = перемикання на цільовий канал   = 1 мс
   T_auth   = 802.11 Open Auth (2 кадри)      = 6 мс
   T_reassoc= 802.11 Reassociation (2 кадри)  = 14 мс
   T_crypto = WPA2 4-Way Handshake            = 85 мс
   T_bridge = Gratuitous ARP + оновлення CAM  = 2 мс
   ───────────────────────────────────────────────────
   T_total  = 540 мс  [глибокий обрив передачі, втрата аудіопотоку]

2. Оптимізований 802.11k + WPA2-PSK (скан 3 сусідів за Neighbor Report):
   T_scan   = 3 канали × 12 мс                = 36 мс
   T_tune   = перемикання на цільовий канал   = 1 мс
   T_auth   = 802.11 Open Auth                = 6 мс
   T_reassoc= 802.11 Reassociation            = 14 мс
   T_crypto = WPA2 4-Way Handshake            = 85 мс
   T_bridge = Gratuitous ARP                  = 2 мс
   ───────────────────────────────────────────────────
   T_total  = 144 мс  [помітне заїкання у голосовому зв'язку]

3. Швидкий перехід 802.11r FT Over-the-Air:
   T_scan   = 0 мс (канал відомий із 802.11k/v)
   T_tune   = перемикання синтезатора         = 1 мс
   T_auth   = FT Authentication (2 кадри)     = 8 мс
   T_reassoc= FT Reassociation (2 кадри)      = 12 мс
   T_crypto = 0 мс (ключ PTK виведено локально з PMK-R1)
   T_bridge = Gratuitous ARP                  = 2 мс
   ───────────────────────────────────────────────────
   T_total  = 23 мс   [непомітно для слуху, поріг відчутності ITU-T G.114 < 50 мс]

4. Швидкий перехід 802.11r FT Over-the-DS:
   T_scan   = 0 мс
   T_prep   = FT Action через дріт (фоново)   = 0 мс (без зупинки радіо)
   T_tune   = перемикання на цільову AP       = 1 мс
   T_reassoc= FT Reassociation (2 кадри)      = 10 мс
   T_crypto = 0 мс
   T_bridge = Gratuitous ARP                  = 2 мс
   ───────────────────────────────────────────────────
   T_total  = 13 мс   [абсолютно безшовний перехід без втрати пакетів]
```

Математичний аналіз доводить, що 802.11k скорочує часову затримку фази виявлення на 91%, а 802.11r виключає криптографічну затримку на 100%, забезпечуючи теоретичний мінімум перемикання каналу на фізичному рівні.
