# 🧮 Аналітичне виведення меж підтяжки та коефіцієнта наростання фронту

У цьому математичному виведенні розв'язано диференціальне рівняння перехідного процесу в лінії I²C, аналітично доведено виникнення константи `0.8473`, виведено передатну функцію шини в частотній області, розраховано динамічні та статичні втрати потужності, проаналізовано модель активного розряду через нелінійний MOSFET і встановлено строгі аналітичні межі опору підтяжки `R_p,min` і `R_p,max` з урахуванням технологічних допусків компонентів. Без цього математичного апарату неможливо обґрунтувати, чому напруга живлення та вхідні логічні пороги жорстко обмежують максимальну фізичну ємність шини.

### Еквівалентна схема та диференціальне рівняння заряду

Фізична лінія шини I²C (SDA або SCL) у стані пасивного переходу з низького рівня у високий моделюється класичним послідовним RC-колом. Джерело живлення з постійною напругою `V_DD` підключене через зосереджений резистор підтяжки `R_p` до розподіленої паразитної ємності шини `C_b`, другий вивід якої з'єднаний зі спільною шиною нульового потенціалу (GND).

Коли всі вихідні транзистори мікросхем на шині закриваються (переходять у стан високого імпедансу *Hi-Z*), струм заряду `i(t)` тече від шини живлення крізь резистор `R_p`, накопичуючи електричний заряд на сумарній ємності `C_b`. За другим законом Кірхгофа сума спадів напруг у цьому контурі в будь-який момент часу `t` дорівнює напрузі джерела живлення:

```
V_DD = V_R(t) + V_C(t)
V_DD = R_p · i(t) + V(t)
```

Струм, що протікає крізь ємність `C_b`, визначається фундаментальним співвідношенням між струмом і швидкістю зміни напруги на обкладках конденсатора:

```
i(t) = C_b · (d V(t) / dt)
```

Підставивши вираз для струму в рівняння контуру, отримуємо лінійне неоднорідне звичайне диференціальне рівняння першого порядку відносно миттєвої напруги на шині `V(t)`:

```
R_p · C_b · (d V(t) / dt) + V(t) = V_DD
d V(t) / dt + V(t) / (R_p · C_b) = V_DD / (R_p · C_b)
```

Введемо фундаментальну характеристику інерційності кола — сталу часу `τ` (грецька літера «тау», одиниця вимірювання — секунда):

```
τ = R_p · C_b
```

Рівняння набуває канонічного вигляду:

```
d V(t) / dt + V(t) / τ = V_DD / τ
```

Розв'яжемо це диференціальне рівняння методом розділення змінних:

```
d V(t) / dt = (V_DD - V(t)) / τ
d V(t) / (V_DD - V(t)) = dt / τ
-d(V_DD - V(t)) / (V_DD - V(t)) = dt / τ
```

Інтегруємо обидві частини рівності:

```
∫ -d(V_DD - V(t)) / (V_DD - V(t)) = ∫ dt / τ
-ln|V_DD - V(t)| = t / τ + C_0
ln|V_DD - V(t)| = -t / τ - C_0
V_DD - V(t) = A · e^(-t / τ)
V(t) = V_DD - A · e^(-t / τ)
```

де `A` — стала інтегрування, що визначається з початкових умов. Нехай у початковий момент часу `t = 0`, коли ключ розімкнувся, залишковий потенціал на лінії дорівнював `V(0) = V_0` (у граничному випадку `V_0 = 0` або `V_0 = V_OL`):

```
V(0) = V_DD - A · e^0 = V_DD - A = V_0
A = V_DD - V_0
```

Остаточний аналітичний вираз для перехідної напруги заряду лінії I²C має вигляд:

```
V(t) = V_DD - (V_DD - V_0) · e^(-t / τ)
V(t) = V_DD · (1 - e^(-t / τ)) + V_0 · e^(-t / τ)
```

Якщо припустити, що перед початком підйому конденсатор був повністю розряджений до нуля (`V_0 = 0`), закон зміни напруги спрощується до класичної формули:

```
V(t) = V_DD · (1 - e^(-t / (R_p · C_b)))
```

### Аналітичне виведення коефіцієнта часу наростання 0.8473

Специфікація I²C (NXP UM10204) стандартизує час наростання фронту `t_r` (*rise time*) не від `0 В` до `V_DD`, а в межах між двома фіксованими відносними порогами вхідних каскадів логіки КМОН (*CMOS*):

1. Нижній контрольний рівень: `V_1 = V_IL = 0.3 · V_DD` — максимальна напруга, яку приймач гарантовано трактує як логічний нуль.
2. Верхній контрольний рівень: `V_2 = V_IH = 0.7 · V_DD` — мінімальна напруга, яку приймач гарантовано трактує як логічну одиницю.

Час наростання `t_r` за визначенням є тривалістю інтервалу, протягом якого напруга зростає від `V_1` до `V_2`:

```
t_r = t_2 - t_1
```

де `t_1` — момент досягнення рівня `0.3 · V_DD`, а `t_2` — момент досягнення рівня `0.7 · V_DD`.

Знайдемо момент часу `t_1`, підставивши `V(t_1) = 0.3 · V_DD` у рівняння перехідного процесу при `V_0 = 0`:

```
0.3 · V_DD = V_DD · (1 - e^(-t_1 / τ))
0.3 = 1 - e^(-t_1 / τ)       [скоротили на V_DD]
e^(-t_1 / τ) = 1 - 0.3
e^(-t_1 / τ) = 0.7
-t_1 / τ = ln(0.7)
t_1 = -τ · ln(0.7)
t_1 = τ · ln(1 / 0.7)
t_1 = τ · ln(10 / 7)
```

Обчислимо точне чисельне значення натурального логарифма:

```
ln(10 / 7) = ln(1.42857142857...) ≈ 0.3566749439387324
t_1 ≈ 0.356675 · τ
```

Знайдемо момент часу `t_2`, підставивши `V(t_2) = 0.7 · V_DD`:

```
0.7 · V_DD = V_DD · (1 - e^(-t_2 / τ))
0.7 = 1 - e^(-t_2 / τ)       [скоротили на V_DD]
e^(-t_2 / τ) = 1 - 0.7
e^(-t_2 / τ) = 0.3
-t_2 / τ = ln(0.3)
t_2 = -τ · ln(0.3)
t_2 = τ · ln(1 / 0.3)
t_2 = τ · ln(10 / 3)
```

Чисельне значення логарифма:

```
ln(10 / 3) = ln(3.33333333333...) ≈ 1.203972804325936
t_2 ≈ 1.203973 · τ
```

Тепер обчислимо різницю часових відліків `t_r = t_2 - t_1`:

```
t_r = t_2 - t_1
t_r = τ · ln(10 / 3) - τ · ln(10 / 7)
t_r = τ · (ln(10 / 3) - ln(10 / 7))
t_r = τ · ln((10 / 3) / (10 / 7))     [властивість логарифма: ln(a) - ln(b) = ln(a / b)]
t_r = τ · ln(7 / 3)
t_r = τ · ln(2.33333333333...)
```

Обчислимо константу `ln(7 / 3)` з високою точністю:

```
k_r = ln(7 / 3) = 0.8472978603872037... ≈ 0.8473
```

Отримуємо фундаментальне співвідношення для часу наростання фронту I²C:

```
t_r = 0.847298 · R_p · C_b
```

Зверніть увагу на математичну елегантність цього результату: абсолютна величина напруги живлення `V_DD` повністю скоротилася під час логарифмування. Оскільки обидва пороги стандартизовані як сталі частки від живлення (`0.3 · V_DD` та `0.7 · V_DD`), час перетину забороненої зони залежить виключно від добутку `R_p · C_b` та константи `ln(7/3)`.

### Узагальнення для довільних відносних порогів перемикання

Нехай початковий і кінцевий пороги вимірювання часу переходу задані як довільні безрозмірні коефіцієнти від напруги живлення: `v_1 = V_1 / V_DD` та `v_2 = V_2 / V_DD` (де `0 < v_1 < v_2 < 1`).

Моменти досягнення цих порогів виражаються загальною формулою:

```
t(v) = τ · ln(1 / (1 - v))
```

Тривалість переходу між довільними порогами `v_1` та `v_2` дорівнює:

```
Δt(v_1 → v_2) = t(v_2) - t(v_1)
Δt(v_1 → v_2) = τ · ln(1 / (1 - v_2)) - τ · ln(1 / (1 - v_1))
Δt(v_1 → v_2) = τ · ln( (1 - v_1) / (1 - v_2) )
```

Обчислимо коефіцієнти для поширених інженерних стандартів:

1. **Стандарт I²C (30% → 70%):**
   ```
   k_I2C = ln((1 - 0.3) / (1 - 0.7)) = ln(0.7 / 0.3) = ln(7 / 3) ≈ 0.847298
   ```
2. **Загальноприйнятий стандарт цифрової електроніки (10% → 90%):**
   ```
   k_10_90 = ln((1 - 0.1) / (1 - 0.9)) = ln(0.9 / 0.1) = ln(9) = 2 · ln(3) ≈ 2.197225
   ```
3. **Стандарт високошвидкісних інтерфейсів (20% → 80%):**
   ```
   k_20_80 = ln((1 - 0.2) / (1 - 0.8)) = ln(0.8 / 0.2) = ln(4) = 2 · ln(2) ≈ 1.386294
   ```

Формули взаємного перерахунку між метриками:

```
t_r(I2C) = (ln(7/3) / ln(9)) · t_r(10%→90%) = (0.847298 / 2.197225) · t_r(10%→90%) ≈ 0.38562 · t_r(10%→90%)
t_r(I2C) = (ln(7/3) / ln(4)) · t_r(20%→80%) = (0.847298 / 1.386294) · t_r(20%→80%) ≈ 0.61120 · t_r(20%→80%)
```

### Частотна характеристика та передатна функція шини в S-області

Розгляньмо лінію I²C у частотній області операторного числення Лапласа. Вхідним сигналом є еквівалентний струм або напруга джерела живлення, а вихідним — напруга на ємності `C_b`.

Комплексний опір кола:

```
Z_C(s) = 1 / (s · C_b)
H(s) = V_out(s) / V_in(s) = Z_C(s) / (R_p + Z_C(s)) = (1 / (s · C_b)) / (R_p + 1 / (s · C_b))
H(s) = 1 / (1 + s · R_p · C_b) = 1 / (1 + s · τ)
```

Передатна функція `H(s)` являє собою класичний фільтр низьких частот першого порядку з одиничним коефіцієнтом передачі на постійному струмі.

Підставивши `s = j · ω` (де `ω = 2 · π · f` — кутова частота), отримуємо комплексну амплітудно-фазову частотну характеристику:

```
H(jω) = 1 / (1 + j · ω · R_p · C_b)
|H(jω)| = 1 / √(1 + (ω · R_p · C_b)²)
φ(ω) = -arctan(ω · R_p · C_b)
```

Частота зрізу фільтра по рівню `-3 дБ` (`|H(jω_c)| = 1 / √2 ≈ 0.707`):

```
ω_c · R_p · C_b = 1
ω_c = 1 / (R_p · C_b)
f_c = 1 / (2 · π · R_p · C_b)
```

Зв'язок між смугою пропускання лінії `f_c` та часом наростання `t_r`:

```
f_c = 0.847298 / (2 · π · t_r) ≈ 0.13485 / t_r
```

Для режиму Fast-mode (`t_r = 300 нс`):

```
f_c = 0.13485 / (300 · 10⁻⁹) ≈ 449.5 кГц
```

Це доводить, що при гранично допустимому опорі підтяжки смуга пропускання фізичної лінії I²C майже точно збігається з основною тактовою частотою шини (400 кГц). Усі вищі гармоніки прямокутного сигналу (3-тя гармоніка 1.2 МГц, 5-та гармоніка 2.0 МГц) сильно придушуються RC-фільтрацією, перетворюючи імпульси на шині на майже чисті синусоїди біля верхньої межі `R_p,max`.

### Інваріантність часу наростання до залишкової напруги нуля V_OL

У реальних схемах напруга на шині перед відпусканням ключа не дорівнює ідеальному нулю, а становить деякий залишковий спад `V_OL` (зазвичай `0.1–0.4 В`), обумовлений внутрішнім опором відкритого транзистора. Перевіримо, чи впливає початкове значення `V_0 = V_OL` на розрахований коефіцієнт `0.8473`.

Нехай `V_0 = V_OL < 0.3 · V_DD`. Загальний розв'язок має вигляд:

```
V(t) = V_DD - (V_DD - V_OL) · e^(-t / τ)
```

Знайдемо момент `t_1`, коли `V(t_1) = 0.3 · V_DD`:

```
0.3 · V_DD = V_DD - (V_DD - V_OL) · e^(-t_1 / τ)
(V_DD - V_OL) · e^(-t_1 / τ) = V_DD - 0.3 · V_DD = 0.7 · V_DD
e^(-t_1 / τ) = (0.7 · V_DD) / (V_DD - V_OL)
t_1 = τ · ln((V_DD - V_OL) / (0.7 · V_DD))
```

Знайдемо момент `t_2`, коли `V(t_2) = 0.7 · V_DD`:

```
0.7 · V_DD = V_DD - (V_DD - V_OL) · e^(-t_2 / τ)
(V_DD - V_OL) · e^(-t_2 / τ) = V_DD - 0.7 · V_DD = 0.3 · V_DD
e^(-t_2 / τ) = (0.3 · V_DD) / (V_DD - V_OL)
t_2 = τ · ln((V_DD - V_OL) / (0.3 · V_DD))
```

Обчислимо час наростання `t_r = t_2 - t_1`:

```
t_r = t_2 - t_1
t_r = τ · [ ln((V_DD - V_OL) / (0.3 · V_DD)) - ln((V_DD - V_OL) / (0.7 · V_DD)) ]
t_r = τ · ln( [ (V_DD - V_OL) / (0.3 · V_DD) ] / [ (V_DD - V_OL) / (0.7 · V_DD) ] )
t_r = τ · ln( (0.7 · V_DD) / (0.3 · V_DD) )
t_r = τ · ln(0.7 / 0.3)
t_r = τ · ln(7 / 3) = 0.8473 · τ
```

Член `(V_DD - V_OL)` повністю скорочується під час ділення під знаком логарифма. Це означає, що **час наростання між фіксованими порогами 0.3·V_DD та 0.7·V_DD абсолютно не залежить від глибини початкового нуля V_OL**, за умови, що сам нуль знаходиться нижче `0.3 · V_DD`. Будь-яка зміна `V_OL` лише зсуває момент початку інтегрування `t_1`, але тривалість польоту через зону невизначеності `t_r` залишається строго інваріантною.

### Математична модель активного спаду фронту (t_f)

На відміну від пасивного підйому, спад напруги при відкриванні N-канального MOSFET транзистора відбувається активно. Розгляньмо нелінійну модель розряду ємності `C_b` через транзистор з крутизною `K = 1/2 · μ_n · C_ox · (W/L)` та пороговою напругою `V_th`.

Розряд проходить через дві послідовні фази:

1. **Фаза насичення (`V_DS > V_GS - V_th`):**
   Поки напруга на стоці висока (`V(t) > V_DD - V_th`), транзистор працює як генератор майже постійного струму розряду `I_sat = K · (V_DD - V_th)²`.
   Швидкість спаду є постійною:
   ```
   d V(t) / dt = -I_sat / C_b
   Δt_sat = C_b · (V_DD - (V_DD - V_th)) / I_sat = C_b · V_th / I_sat
   ```
2. **Лінійна омічна фаза (`V_DS < V_GS - V_th`):**
   Коли напруга падає нижче `V_DD - V_th`, транзистор переходить у лінійний режим і поводиться як еквівалентний резистор відкритого каналу `R_DS(on)`.
   Залишковий розряд описується експонентою з постійною часу `τ_f = R_DS(on) · C_b`:
   ```
   V(t) = (V_DD - V_th) · e^(-t / τ_f)
   ```

Час спаду між контрольними рівнями `0.7 · V_DD` та `0.3 · V_DD` за стандартом обчислюється як:

```
t_f ≈ 0.8473 · R_DS(on) · C_b
```

Оскільки опір відкритого каналу сучасних транзисторів становить лише `R_DS(on) ≈ 5–20 Ом` (проти `R_p ≈ 1–10 кОм`), час спаду виявляється у сотні разів меншим за час наростання:

```
t_f / t_r ≈ R_DS(on) / R_p ≈ 10 Ом / 2200 Ом ≈ 0.0045 (менше 0.5%)
```

### Розрахунок статичної та динамічної потужності розсіювання

Енергетичний баланс шини I²C складається з двох компонентів: динамічних втрат на циклічне перезаряджання ємності `C_b` та статичних втрат під час утримання лінії в низькому логічному стані.

#### 1. Динамічна потужність (P_dynamic)

При кожному переході лінії з нуля в одиницю джерело живлення віддає енергію:

```
E_source = ∫ [0 до ∞] V_DD · i(t) dt = V_DD · ∫ i(t) dt = V_DD · Q = V_DD · (C_b · V_DD) = C_b · V_DD²
```

Половина цієї енергії `E_cap = 1/2 · C_b · V_DD²` накопичується в електричному полі конденсатора, а друга половина `E_R = 1/2 · C_b · V_DD²` розсіюється у вигляді тепла на резисторі підтяжки `R_p`. Під час наступного спадного переходу накопичена в конденсаторі енергія розсіюється на опорі каналу транзистора `R_DS(on)`.

При безперервному перемиканні лінії з частотою `f_sw` (для тактової лінії `f_sw = f_SCL`):

```
P_dynamic = C_b · V_DD² · f_SCL
```

*Приклад:* При `C_b = 400 пФ`, `V_DD = 3.3 В` та `f_SCL = 400 кГц`:

```
P_dynamic = 400 · 10⁻¹² · 3.3² · 400 · 10³ = 400 · 10⁻¹² · 10.89 · 400 · 10³ = 1.742 · 10⁻³ Вт = 1.74 мВт
```

#### 2. Статична потужність (P_static)

Коли лінія утримується в нулі (наприклад, під час передачі нульових бітів, байтів підтвердження ACK або розтягування такту *Clock Stretching*), крізь резистор підтяжки постійно тече струм `I_OL = (V_DD - V_OL) / R_p`.

Миттєва потужність, що виділяється на резисторі підтяжки:

```
P_static = (V_DD - V_OL)² / R_p
```

Якщо частка часу, протягом якого лінія знаходиться в низькому стані, становить `D_low` (коефіцієнт заповнення нуля, типово `D_low ≈ 0.5`):

```
P_static,avg = D_low · [ (V_DD - V_OL)² / R_p ]
```

*Приклад:* Для `V_DD = 5.0 В`, `V_OL = 0.4 В`, `R_p = 1.5 кОм` та `D_low = 0.5`:

```
P_static,avg = 0.5 · (5.0 - 0.4)² / 1500 = 0.5 · 21.16 / 1500 = 0.5 · 0.0141 Вт = 7.05 мВт
```

### Точка замикання робочого вікна C_b,crit та аналіз чутливості

Допустимий номінал резистора підтяжки існує лише за виконання умови несуперечливості меж:

```
R_p,min ≤ R_p,max
(V_DD - V_OL,max) / I_OL,max ≤ t_r,max / (0.847298 · C_b)
```

Звідси виводиться аналітичний вираз для абсолютної критичної ємності лінії `C_b,crit`:

```
C_b,crit = (t_r,max · I_OL,max) / [ 0.847298 · (V_DD - V_OL,max) ]
```

Проаналізуємо чутливість критичної ємності до варіацій напруги живлення `V_DD` за допомогою часткової похідної:

```
∂ C_b,crit / ∂ V_DD = - (t_r,max · I_OL,max) / [ 0.847298 · (V_DD - V_OL,max)² ] < 0
```

Від'ємний знак похідної показує, що **зі збільшенням напруги живлення критична ємність шини невпинно зменшується**. Чим вища напруга живлення, тим швидше зачиняється робоче вікно опорів підтяжки при фіксованому струмі драйвера `I_OL = 3 мА`.

Чисельні значення `C_b,crit` для режиму Fast-mode (400 кГц, `t_r,max = 300 нс`, `I_OL,max = 3 мА`):
- При `V_DD = 1.8 В` (`V_OL = 0.36 В`): `C_b,crit = (300·10⁻⁹ · 0.003) / (0.8473 · 1.44) = 9·10⁻¹⁰ / 1.2201 ≈ 737.6 пФ`
- При `V_DD = 3.3 В` (`V_OL = 0.40 В`): `C_b,crit = (300·10⁻⁹ · 0.003) / (0.8473 · 2.90) = 9·10⁻¹⁰ / 2.4572 ≈ 366.3 пФ`
- При `V_DD = 5.0 В` (`V_OL = 0.40 В`): `C_b,crit = (300·10⁻⁹ · 0.003) / (0.8473 · 4.60) = 9·10⁻¹⁰ / 3.8976 ≈ 230.9 пФ`

### Оцінка гіршого випадку з урахуванням інженерних допусків (Worst-Case Analysis)

У реальному серійному виробництві всі фізичні параметри мають розкид:
- Допуск опору резисторів: `δR = ±5%` (або `±1%`);
- Нестабільність напруги живлення: `δV = ±5%` (наприклад, `3.3 В ± 0.165 В`);
- Температурний дрейф опору транзистора `R_DS(on)`: до `+50%` при максимальній робочій температурі +105 °C.

Для гарантованого проходження тестів в усьому діапазоні температур і напруг межі `R_p` розраховують за критерієм найгіршого випадку (*Worst-Case Scenario*):

```
R_p,min,wc = (V_DD,max - V_OL,max) / (I_OL,max · (1 - δR))
R_p,max,wc = t_r,max / (0.847298 · C_b,max · (1 + δR))
```

*Приклад розрахунку найгіршого випадку:*
Для системи `3.3 В ± 5%` (`V_DD,max = 3.465 В`), Fast-mode (`300 нс`), `C_b = 200 пФ`, резистори `±5%`:

```
R_p,min,wc = (3.465 - 0.40) / (0.003 · 0.95) = 3.065 / 0.00285 ≈ 1075 Ом (1.08 кОм)
R_p,max,wc = (300 · 10⁻⁹) / (0.847298 · 200 · 10⁻¹² · 1.05) = 300 · 10⁻⁹ / 1.7793 · 10⁻¹⁰ ≈ 1686 Ом (1.69 кОм)
```

Гарантоване вікно значень звужується від `[967 Ом ... 1770 Ом]` до `[1075 Ом ... 1686 Ом]`. Єдиним стандартним номіналом ряду E24, який надійно вкладається в цей звужений діапазон, є резистор **`1.2 кОм`** або **`1.5 кОм`**.

Цей строгий математичний апарат є теоретичним базисом, на якому будуються всі практичні інженерні розрахунки шини I²C.
