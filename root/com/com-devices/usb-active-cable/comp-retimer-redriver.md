# 🔌 Редрайвери та ретаймери сигнальних ліній

Високошвидкісні кондиціонери сигналу — редрайвери та ретаймери — це спеціалізовані інтегральні мікросхеми, які вбудовують безпосередньо в штекери кабелю або розміщують на друкованій платі біля роз'ємів для подолання частотного згасання сигналів у трактах USB 3.2, USB4, Thunderbolt, PCIe та DisplayPort. Коли швидкість передачі даних сягає 10, 20 чи 40 Гбіт/с на диференційну пару, звичайні провідники перетворюються на смугові фільтри низьких частот, які критично спотворюють амплітуду та часові параметри імпульсів. Без активного вирівнювання сигналу всередині кабелю надійний зв'язок на таких швидкостях стає неможливим уже на відстані понад 0.8 метра.

### Внутрішня архітектура аналогового редрайвера

Редрайвер є суто аналоговим підсилювачем із вибірковою частотною корекцією. Його внутрішній тракт складається з кількох послідовних функціональних блоків:

1. **Вхідний каскад узгодження:** термінаційні резистори 50 Ом на землю (або 100 Ом диференційно) з прецизійним лазерним підганянням опору для мінімізації зворотних відбиттів (коефіцієнт відбиття S11 менше -12 дБ у смузі до 15 ГГц).
2. **Лінійний еквалайзер неперервного часу (CTLE):** диференційний підсилювальний каскад із паралельним RC-колом у витоках (емітерах) вхідної транзисторної пари. На низьких частотах конденсатор розімкнений, і глибокий зворотний зв'язок за витоком знижує підсилення до одиничного рівня (0 дБ). Зі зростанням частоти імпеданс конденсатора спадає, шунтуючи резистор зворотного зв'язку, що створює плавний підйом коефіцієнта підсилення до +6..+15 дБ на частоті Найквіста. Частота нуля `f_z` та частота полюса `f_p` визначаються номіналами елементів:
```
f_z = 1 / (2 · π · R_s · C_s)                      [частота появи підйому АЧХ]
f_p = (1 + g_m · R_s / 2) / (2 · π · R_s · C_s)     [частота виходу на плато підсилення]
```
3. **Підсилювач із регульованим коефіцієнтом передачі (VGA):** дозволяє встановити загальний розмах сигналу для узгодження з динамічним діапазоном наступних каскадів.
4. **Вихідний драйвер із формуванням деакцентуації (De-emphasis):** формує вихідний диференційний перепад напруги. У моменти перемикання логічного стану драйвер видає повний розмах напруги (boost), а якщо стан біта повторюється кілька тактів поспіль, рівень вихідної напруги автоматично знижується на 3–6 дБ, що запобігає надмірному накопиченню заряду в паразитних ємностях лінії.
5. **Детектор втрати сигналу (Loss of Signal, LOS):** швидкий аналоговий компаратор пікового рівня, який переводить мікросхему в режим наднизького споживання (Squelch / Standby), коли амплітуда диференційного сигналу на вході опускається нижче 50 мВ пік-пік.

Оскільки редрайвер не виконує квантування за часом, його власна затримка проходження (propagation delay) є мінімальною (типово 70–120 пікосекунд), а споживання не перевищує 40–80 мВт на канал. Проте аналоговий підсилювач не здатний відокремити корисний сигнал від паразитного фазового двитеру та теплового шуму, підсилюючи їх разом із фронтами. Тому редрайвери придатні лише для помірного подовження ліній до 2.0–2.5 метрів на швидкостях до 10 Гбіт/с.

### Внутрішня архітектура цифрового ретаймера

Ретаймер є повноцінним регенератором фізичного рівня (PHY Slice), який повністю відновлює як амплітуду, так і часову сітку сигналу:

1. **Аналоговий приймальний каскад:** поєднує вхідний еквалайзер CTLE та багатокаскадний адаптивний фільтр зі зворотним зв'язком за рішенням (Decision Feedback Equalizer, DFE на 3–5 тактів). Фільтр DFE використовує попередньо розпізнані біти `d[n-1], d[n-2], ...` для віднімання залишкових «хвостів» міжсимвольної завади (ISI) безпосередньо перед стробуванням:
```
V_вхід_компаратора[n] = V_аналог[n] - ∑ (w_k · d[n-k])    [віднімання інтерференції від k-х бітів]
```
Вагові коефіцієнти `w_k` адаптуються в реальному часі за градієнтним алгоритмом найменших середніх квадратів (LMS).
2. **Вузол відновлення такту й даних (CDR):** містить фазовий детектор типу Александера (Bang-Bang Phase Detector), цифровий петлевий фільтр та керований генератор PLL. Схема виділяє фазу переходів у вхідному потоці й формує новий локальний тактовий сигнал, практично вільний від вхідного двитеру.
3. **Пружний буфер пам'яті (Elastic Buffer FIFO):** компенсує похибку опорних генераторів між передавачем хоста та локальним приймачем (стандарт USB4 допускає розбіжність тактових частот до ±300 ppm). Буфер періодично вставляє або вилучає службові символи вирівнювання (Skip Ordered Sets) у моменти між корисними пакетами даних, запобігаючи переповненню чи спустошенню черги.
4. **Формувач вихідного тактового домену та драйвер FFE:** повністю незалежний передавач генерує нові імпульси за допомогою синтезованого внутрішнього такту. Вихідний драйвер реалізує трьохточковий трансверсальний фільтр передіскажень (Feed-Forward Equalization, FFE: pre-cursor, main cursor, post-cursor).
5. **Логічний контролер протоколу:** розпізнає службові команди USB4, PCIe та DisplayPort, бере участь у процедурах навчання ліній (Link Training TS1/TS2), вимірює коефіцієнт помилок BER за вбудованими псевдовипадковими послідовностями (PRBS) та динамічно керує станами живлення кристала.

Ретаймер повністю розриває зв'язок за накопиченням фазового джитеру: на його виході залишковий джитер визначається лише фазовим шумом власного генератора PLL (менше 0.04 UI).

```
Аналоговий редрайвер:
Вхід ──► [ Вхідне узгодження 50 Ом ] ──► [ CTLE Еквалайзер ] ──► [ VGA ] ──► [ Драйвер Tx ] ──► Вихід
(шум, перехресні завади та фазовий джитер проходять наскрізь)

Цифровий ретаймер:
Вхід ──► [ CTLE + DFE ] ──► [ Фазовий детектор CDR ] ──► [ Буфер FIFO ] ──► [ FFE Драйвер Tx ] ──► Вихід
                                    ▲                          ▲
                              [ Вузол PLL ] ───────────── [ Локальний такт ]
(новий тактовий домен: фазовий джитер вхідного каналу знищено)
```

### Електрична інтеграція на мікроплатах роз'ємів

Монтаж редрайверів та ретаймерів усередині металевого корпусу кабельного штекера USB Type-C висуває жорсткі вимоги до схемотехніки друкованої плати (типово 4- або 6-шарова гнучко-жорстка плата товщиною 0.4–0.6 мм):

1. **Цілісність живлення (Power Integrity):** генератор PLL ретаймера вкрай чутливий до пульсацій живлення: високочастотний шум на шині живлення аналогового ядра перетворюється на фазовий шум та періодичний джитер вихідного сигналу. Тому розраховується цільовий імпеданс системи розподілу живлення (PDN):
```
Z_цільовий = ΔV_пульсацій / ΔI_стрибка
= 15 мВ / 300 мА                             [допустима пульсація 15 мВ при стрибку струму 300 мА]
= 50 мОм                                     [максимальний імпеданс шини живлення в смузі до 200 МГц]
```
Лінія живлення ядра (типово 0.9 В або 1.1 В) відділяється від загального входу VCONN феритовими фільтрами з імпедансом не менше 120 Ом на частоті 100 МГц та керамічними конденсаторами типорозміру 0201/01005 із низьким еквівалентним послідовним опором (ESR < 10 мОм).

2. **Послідовність подачі напруг (Power Sequencing):** сучасні мікросхеми ретаймерів виготовляються за субмікронними техпроцесами FinFET (12 нм або 7 нм) і вимагають суворого дотримання часових інтервалів під час запуску. Напруга живлення цифрового ядра (Core 0.9 В) повинна підніматися раніше або одночасно з напругою блоків введення-виведення (I/O 1.8 В). Порушення черговості подачі напруг може викликати ефект паразитного тиристорного замикання (latch-up), що призводить до катастрофічного вигорання кристала від струму шини VCONN.

3. **Контроль хвильового опору та ефект плетіння скловолокна:** диференційні пари швидкісних ліній SSTX/SSRX розводяться копланарними хвилеводами або мікросмужками з диференційним хвильовим опором рівно 85 або 90 Ом (залежно від версії специфікації USB4/Thunderbolt). На частотах 10–20 ГГц критичним стає ефект неоднорідності діелектрика через плетіння склотканини (fiber weave effect): якщо один провідник диференційної пари лягає вздовж пучка скляних ниток (діелектрична проникність `ε_r ≈ 6.0`), а сусідній — над зоною епоксидної смоли (`ε_r ≈ 3.2`), виникає значна фазова розбіжність фронтів (skew). Для запобігання перекосу фаз доріжки розводять під кутом 10–15 градусів до структури полотна склотекстоліту, а перехідні отвори (vias) виконуються з видаленням невикористаних залишків металізації (backdrilling).

4. **Тепловідведення:** виділення 0.8–1.5 Вт тепла у герметичному об'ємі менше ніж один кубічний сантиметр створює високу питому густину теплового потоку. Для запобігання перегріву кристала понад допустимі 85–105 °C під мікросхемою формується масив теплопровідних перехідних отворів (thermal vias) діаметром 0.2 мм із кроком 0.4 мм, з'єднаних із суцільними мідними полігонами внутрішніх шарів і зовнішнім латунним або сталевим екраном штекера за допомогою компаунда з високою теплопровідністю (> 2.0 Вт/(м·К)).

### Програмне керування та конфігурація параметрів

Ретаймери підтримують як автономний запуск (зчитування заводських налаштувань із мікросхеми EEPROM або за допомогою підтягуючих резисторів на контактах strapping), так і динамічне конфігурування керівним мікроконтролером кабелю (E-Marker) через інтерфейс I2C або I3C.

Нижче наведено модуль налаштування еквалайзера та вихідного каскаду ретаймера під конкретну довжину й характеристики мідного каналу.

```c
#include <stdint.h>
#include <stdbool.h>

/* Регістри та бітові маски сигнального кондиціонера */
#define REG_CH_CTRL_BASE    0x10
#define REG_CTLE_CONFIG     0x14
#define REG_TX_DEEMPHASIS   0x18
#define REG_CDR_STATUS      0x20

#define CTLE_BOOST_MASK     0x0F
#define TX_SWING_MASK       0x07
#define CDR_LOCK_BIT        (1 << 7)

typedef struct {
    uint8_t i2c_addr;
    uint8_t channel_count;
    bool (*i2c_write)(uint8_t addr, uint8_t reg, uint8_t val);
    bool (*i2c_read)(uint8_t addr, uint8_t reg, uint8_t *val);
} retimer_dev_t;

/* Налаштування посилення CTLE (0..15 дБ) та деакцентуації Tx для обраного каналу */
bool retimer_configure_channel(const retimer_dev_t *dev, uint8_t ch, 
                               uint8_t ctle_boost_db, uint8_t deemph_db) {
    if (!dev || ch >= dev->channel_count) {
        return false;
    }
    if (ctle_boost_db > 15 || deemph_db > 7) {
        return false;
    }

    uint8_t ch_offset = ch * 0x10;
    uint8_t ctle_reg = REG_CTLE_CONFIG + ch_offset;
    uint8_t tx_reg = REG_TX_DEEMPHASIS + ch_offset;

    /* Запис коефіцієнта аналогового підсилення високих частот */
    if (!dev->i2c_write(dev->i2c_addr, ctle_reg, ctle_boost_db & CTLE_BOOST_MASK)) {
        return false;
    }

    /* Запис глибини деакцентуації вихідного каскаду для компенсації втрат */
    if (!dev->i2c_write(dev->i2c_addr, tx_reg, deemph_db & TX_SWING_MASK)) {
        return false;
    }

    return true;
}

/* Перевірка захоплення тактової частоти фазовим детектором CDR */
bool retimer_is_locked(const retimer_dev_t *dev, uint8_t ch) {
    if (!dev || ch >= dev->channel_count) {
        return false;
    }
    uint8_t status = 0;
    uint8_t reg = REG_CDR_STATUS + (ch * 0x10);
    if (!dev->i2c_read(dev->i2c_addr, reg, &status)) {
        return false;
    }
    return (status & CDR_LOCK_BIT) != 0;
}
```
```cpp
#include <cstdint>
#include <concepts>
#include <optional>
#include <span>

template <typename I2cBus>
concept I2cMaster = requires(I2cBus bus, uint8_t addr, uint8_t reg, uint8_t val, uint8_t& out_val) {
    { bus.write_reg(addr, reg, val) } -> std::same_as<bool>;
    { bus.read_reg(addr, reg, out_val) } -> std::same_as<bool>;
};

template <I2cMaster Bus>
class RetimerController {
public:
    static constexpr uint8_t RegChCtrlBase  = 0x10;
    static constexpr uint8_t RegCtleConfig  = 0x14;
    static constexpr uint8_t RegTxDeemph    = 0x18;
    static constexpr uint8_t RegCdrStatus   = 0x20;
    static constexpr uint8_t CdrLockBit     = 1 << 7;

    constexpr RetimerController(Bus& bus, uint8_t i2c_addr, uint8_t channels) noexcept
        : bus_(bus), addr_(i2c_addr), channel_count_(channels) {}

    [[nodiscard]] bool configure_channel(uint8_t ch, uint8_t ctle_boost_db, uint8_t deemph_db) noexcept {
        if (ch >= channel_count_ || ctle_boost_db > 15 || deemph_db > 7) {
            return false;
        }

        const uint8_t offset = ch * 0x10;
        const uint8_t ctle_reg = RegCtleConfig + offset;
        const uint8_t tx_reg = RegTxDeemph + offset;

        if (!bus_.write_reg(addr_, ctle_reg, ctle_boost_db & 0x0F)) {
            return false;
        }
        return bus_.write_reg(addr_, tx_reg, deemph_db & 0x07);
    }

    [[nodiscard]] std::optional<bool> is_channel_locked(uint8_t ch) const noexcept {
        if (ch >= channel_count_) {
            return std::nullopt;
        }
        uint8_t status = 0;
        const uint8_t reg = RegCdrStatus + (ch * 0x10);
        if (!bus_.read_reg(addr_, reg, status)) {
            return std::nullopt;
        }
        return (status & CdrLockBit) != 0;
    }

private:
    Bus& bus_;
    uint8_t addr_;
    uint8_t channel_count_;
};
```

### Типові несправності та обмеження компонентів

* **Перекомпенсація (over-equalization):** надмірне підсилення CTLE (наприклад, виставлення 12 дБ бусту на короткому кабелі з втратами лише 3 дБ) призводить до штучного загострення фронтів, виникнення перерегулювання (overshoot) і високочастотного дзвону, що звужує око діаграми за напругою точно так само, як і недокомпенсація.
* **Втрата блокування CDR під час зміни швидкостей:** перехід інтерфейсу між поколіннями (наприклад, перемикання з USB 3.2 Gen1 на Gen2 або USB4) вимагає динамічного перемикання коефіцієнтів ділення дільників PLL. Якщо мікропрограма контролера кабелю не підтримує протокольне узгодження швидкості (Ordered Sets Link Training), ретаймер залишається розсинхронізованим, блокуючи проходження даних.
* **Термічний дрейф частоти:** тривала робота ретаймера при високих температурах (> 80 °C) викликає зміщення робочої точки LC-генератора VCO. Без якісного тепловідведення на металевий корпус штекера фазовий шум PLL зростає, призводячи до спонтанних бітових помилок при тривалому копіюванні великих масивів даних.
