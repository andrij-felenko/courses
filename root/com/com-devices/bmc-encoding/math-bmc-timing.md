# Розрахунок часових вікон та RC-затримок сигналу BMC

Передача цифрових пакетів USB Power Delivery на фізичному рівні Configuration Channel (CC) відбувається по одному несиметричному провіднику з розподіленою ємністю кабелю та друкованої плати. Щоб приймач безпомилково декодував біти за методом Biphase Mark Code (BMC) на номінальній швидкості 300 кбіт/с, фронти напруги мають наростати достатньо швидко, а таймер вхідного захоплення повинен мати чіткі математичні межі для розрізнення половинного та повного бітового інтервалів.

```
                  tBit = 3.333 мкс
       |<─────────────────────────────────>|
       |                 |                 |
───────┐                 ┌─────────────────┐
       │                 │                 │       Логічна '1' (два переходи)
       └─────────────────┘                 └───────
       |<─── t_half ────>|<─── t_half ────>|
          1.667 мкс         1.667 мкс

───────┐
       │                                           Логічна '0' (один перехід)
       └───────────────────────────────────────────
       |<────────────── t_full ───────────────────>|
                          3.333 мкс
```

Розрахунок фізичних параметрів каналу спирається на аналіз перехідних процесів у еквівалентному RC-колі, міжсимвольну інтерференцію, розрахунок очної діаграми з урахуванням гістерезису компаратора, хвильові характеристики довгої лінії, спектральне обґрунтування DC-балансу, оцінку ймовірності бітових помилок (BER), вплив квантування таймера та визначення похибок стробування через фазовий джиттер.

---

### 1. Перехідний процес та час наростання фронту на лінії CC

Фізичний канал зв'язку утворений вихідним опором передавача `R_tx`, опором провідника кабелю, паразитною ємністю друкованих плат обох вузлів та власною ємністю витої пари або коаксіальної жили лінії CC у кабелі Type-C. Згідно зі стандартом USB Type-C та USB PD, сумарна ємність лінії `C_line` у найгіршому випадку досягає 1000 пФ (1 нФ), а вихідний динамічний опір драйвера передавача `R_tx` перебуває в межах від 30 до 50 Ом.

Еквівалентна стала часу кола `τ` (tau) під час перемикання push-pull виходу визначається добутком еквівалентного опору та сумарної ємності навантаження:

```
τ = R_tx · C_line
= 50 Ом · 1000·10⁻¹² Ф    [підстановка максимальних значень опору драйвера та ємності лінії]
= 50·10⁻⁹ с                [виконання множення]
= 50 нс                    [переведення в наносекунди]
```

Перехідна характеристика напруги `v(t)` на ємності лінії під час стрибка напруги від нуля до максимального розмаху `V_swing = 1.12 В` описується експоненційним рівнянням:

```
v(t) = V_swing · (1 - e^(-t / τ))
```

Стандарт визначає час наростання `t_rise` (і час спаду `t_fall`) як інтервал, за який напруга змінюється від рівня 10% до рівня 90% від повної амплітуди `V_swing`. Обчислимо моменти досягнення цих рівнів `t₁₀` та `t₉₀`:

```
v(t₁₀) = 0.10 · V_swing
0.10 · V_swing = V_swing · (1 - e^(-t₁₀ / τ))   [прирівнювання до виразу перехідного процесу]
1 - e^(-t₁₀ / τ) = 0.10                          [скорочення на V_swing]
e^(-t₁₀ / τ) = 0.90                              [перенесення доданків]
-t₁₀ / τ = ln(0.90)                              [логарифмування обох частин]
t₁₀ = -τ · ln(0.90)                              [вираження t₁₀]
= -50 нс · (-0.10536)                            [підстановка значення сталої часу та логарифма]
= 5.27 нс                                        [значення часу досягнення рівня 10%]
```

Для рівня 90%:

```
v(t₉₀) = 0.90 · V_swing
0.90 · V_swing = V_swing · (1 - e^(-t₉₀ / τ))   [прирівнювання до рівняння перехідного процесу]
1 - e^(-t₉₀ / τ) = 0.90                          [скорочення на V_swing]
e^(-t₉₀ / τ) = 0.10                              [перенесення доданків]
-t₉₀ / τ = ln(0.10)                              [логарифмування обох частин]
t₉₀ = -τ · ln(0.10)                              [вираження t₉₀]
= -50 нс · (-2.30258)                            [підстановка сталої часу та натурального логарифма]
= 115.13 нс                                      [значення часу досягнення рівня 90%]
```

Час наростання фронту `t_rise`:

```
t_rise = t₉₀ - t₁₀
= 115.13 нс - 5.27 нс                            [різниця моментів часу]
= 109.86 нс                                      [результат віднімання]
≈ 2.197 · τ                                      [аналітичний зв'язок зі сталою часу]
```

Отримане значення `t_rise ≈ 110 нс` повністю вкладається у нормативний коридор стандарту USB PD (від 100 нс до 300 нс). Обмеження швидкості наростання зверху (не швидше 100 нс) реалізується навмисним уповільненням драйвера за допомогою послідовного резистора або керованого джерела струму для зниження електромагнітної емісії (EMI) у радіочастотному спектрі.

### 2. Номінальні параметри та часові інтервали BMC

Номінальна швидкість передачі бітів `f_bit` у протоколі USB PD дорівнює 300 кбіт/с з допустимим технологічним відхиленням ±10% (діапазон частот від 270 кГц до 330 кГц). Номінальний період одного інформаційного біта `tBit`:

```
tBit_nom = 1 / f_bit
= 1 / (300·10³ с⁻¹)                               [підстановка номінальної частоти]
= 3.3333·10⁻⁶ с                                  [виконання ділення]
= 3.333 мкс                                      [переведення в мікросекунди]
```

Діапазон тривалості бітового інтервалу з урахуванням граничних відхилень тактових генераторів передавача:

```
tBit_min = 1 / 330 кГц = 3.030 мкс                [мінімальний період при максимальній частоті]
tBit_max = 1 / 270 кГц = 3.704 мкс                [максимальний період при мінімальній частоті]
```

У кодуванні BMC кожен бітовий інтервал починається з обов'язкового переходу рівня напруги. Для передачі логічної одиниці в середині інтервалу формується додатковий перехід. Таким чином, у послідовності з'являються два базові часові інтервали між сусідніми фронтами:
1. `t_half` — інтервал між фронтами для логічної одиниці (половина біта);
2. `t_full` — інтервал між фронтами для логічного нуля (повний біт).

Номінальні значення цих інтервалів:

```
t_half_nom = tBit_nom / 2
= 3.3333 мкс / 2                                 [ділення номінального періоду навпіл]
= 1.6667 мкс                                     [номінальний напівперіод]

t_full_nom = tBit_nom
= 3.3333 мкс                                     [номінальний повний період]
```

### 3. Міжсимвольна інтерференція (ISI) та залишковий заряд ємності

Коли передавач переходить від тривалого інтервалу повного біта `t_full = 3.33 мкс` до короткого половинного біта `t_half = 1.67 мкс`, напруга на ємності лінії встигає досягти різних рівнів перед наступним перемиканням. Це явище формує міжсимвольну інтерференцію (Inter-Symbol Interference, ISI).

Розрахуємо залишковий дефіцит заряду `ΔV_isi` на ємності лінії після інтервалу `t_half = 1.67 мкс`:

```
v(t_half) = V_swing · (1 - e^(-t_half / τ))
= 1.12 В · (1 - e^(-1667 нс / 50 нс))             [підстановка тривалості півбіта та сталої часу]
= 1.12 В · (1 - e^(-33.34))                       [обчислення степеня експоненти]
= 1.12 В · (1 - 3.32·10⁻¹⁵)                       [експонента практично дорівнює нулю]
≈ 1.12 В                                         [напруга досягає повного розмаху задовго до кінця півбіта]
```

Оскільки тривалість найкоротшого інтервалу `t_half = 1.667 мкс` перевищує сталу часу кола `τ = 50 нс` у `1667 / 50 ≈ 33.3` раза, перехідний процес встигає завершитися на `99.999%` вже за `5 · τ = 250 нс`. Це математично означає, що лінія CC повністю вільна від міжсимвольної пам'яті (ISI), а амплітуда кожного імпульсу досягає стабільної полички задовго до наступного фронту.

### 4. Бюджет фазового джиттеру та динамічна похибка порогу компаратора

Під час руху сигналу кабельною лінією моменти перетину порогової напруги компаратора `V_th` зміщуються відносно ідеальних тактових засічок через три незалежні фізичні фактори:
- Дрейф опорного генератора передавача `Δt_gen`;
- Зміщення порогу компаратора через шум та несиметрію фронтів `Δt_th`;
- Власні фазові шуми вхідного каскаду приймача `Δt_rx`.

```
                  Напруга V_cc
                      ▲
            V_swing ──┼───────────────┐
                      │              /│
                      │             / │
               V_th ──┼────────────X──┼────────────── (поріг компаратора)
                      │           /│  │
                      │          / │  │
                  0 ──┴─────────┴──┴──┴────────► Час t
                                   |  |
                                   └──┘
                                  Δt_th (фазовий зсув моменту спрацьовування)
```

Похибка моменту спрацьовування `Δt_th` виникає через те, що реальний фронт має скінченну крутизну (швидкість наростання `SR = dV/dt`). При розмаху сигналу `V_swing = 1.12 В` та часі наростання `t_rise = 120 нс` середня крутизна фронту становить:

```
SR = (0.90 · V_swing - 0.10 · V_swing) / t_rise
= (0.80 · 1.12 В) / (120·10⁻⁹ с)                 [підстановка робочих параметрів]
= 0.896 В / 120 нс                                [обчислення перепаду напруги]
= 7.467·10⁶ В/с                                   [виконання ділення]
= 7.47 В/мкс                                      [переведення у вольти на мікросекунду]
```

Якщо нестабільність опорної напруги компаратора або шум на лінії становить `ΔV_noise = ±50 мВ` (0.05 В), максимальний часовий зсув точки перетину порогу становить:

```
Δt_th = ΔV_noise / SR
= 0.05 В / (7.467·10⁶ В/с)                       [ділення амплітуди шуму на крутизну]
= 6.70·10⁻⁹ с                                    [результат у секундах]
= 6.7 нс                                         [результат у наносекундах]
```

Сумарний часовий джиттер `J_total` враховує всі складові похибок і в найгірших умовах кабельного каналу довжиною 2 метри не перевищує `J_total = ±0.20 · t_half_nom ≈ ±333 нс`.

### 5. Хвильова модель лінії передачі та обмеження довжини кабелю

Для повного опису лінії CC за умов високих швидкостей або довгих кабельних трас розглядається модель довгої лінії з розподіленими параметрами. Погонна індуктивність провідника `L_0` та погонна ємність `C_0` стандартного кабелю USB Type-C становлять орієнтовно `L_0 ≈ 250 нГн/м` та `C_0 ≈ 80 пФ/м`.

Хвильовий опір лінії `Z_0`:

```
Z_0 = √(L_0 / C_0)
= √( (250·10⁻⁹ Гн/м) / (80·10⁻¹² Ф/м) )          [підстановка погонних параметрів]
= √( 3125 Ом² )                                  [ділення під коренем]
= 55.90 Ом                                       [обчислення квадратного кореня]
≈ 56 Ом                                          [хвильовий опір лінії CC]
```

Швидкість поширення електромагнітної хвилі в кабелі `v_prop`:

```
v_prop = 1 / √(L_0 · C_0)
= 1 / √( 250·10⁻⁹ · 80·10⁻¹² )                   [добуток погонних величин]
= 1 / √( 20·10⁻¹⁸ с²/м² )                        [обчислення підкореневого виразу]
= 1 / (4.472·10⁻⁹ с/м)                           [вилучення кореня]
= 2.236·10⁸ м/с                                  [швидкість сигналу]
≈ 0.745 · c                                      [швидкість становить ~75% від швидкості світла]
```

Час затримки поширення сигналу `t_prop` для стандартного 2-метрового кабелю USB-C (`l = 2.0 м`):

```
t_prop = l / v_prop
= 2.0 м / (2.236·10⁸ м/с)                        [ділення довжини на швидкість]
= 8.94·10⁻⁹ с                                    [час пробігу лінії]
≈ 8.94 нс                                        [затримка менше 9 наносекунд]
```

Порівняємо час затримки поширення `t_prop` із часом наростання фронту `t_rise = 110 нс`:

```
t_prop / t_rise
= 8.94 нс / 110 нс                               [відношення затримки до тривалості фронту]
= 0.081                                          [значення відношення]
= 8.1%                                           [затримка значно менша за чверть фронту]
```

Оскільки затримка поширення становить менше 10% від часу наростання фронту (`t_prop << t_rise / 4`), відбиття від кінців лінії згасають задовго до завершення перехідного процесу. Це математично доводить, що лінія CC довжиною до 2 метрів на частоті 300 кбіт/с поводиться як коло із зосередженими параметрами, і узгодження хвильового опору резисторами-термінаторами 50 Ом не потрібне: достатньо розглядати навантаження як сумарну ємність `C_line`.

### 6. Розрахунок меж вікон дискримінації приймача

Щоб надійно розділяти інтервали половинного біта `t_half` та повного біта `t_full`, цифровий декодер вимірює тривалість між сусідніми фронтами за допомогою апаратного таймера та класифікує отримане значення `Δt` за чотирма зонами.

Поділ здійснюється за трьома критичними граничними порогами:
- `T_noise` — нижня межа шуму (усе, що коротше, вважається брязкотом або завадою);
- `T_split` — розділовий поріг між одиничним напівперіодом та нульовим повним періодом;
- `T_timeout` — верхня межа очікування (перевищення означає закінчення пакета або обрив зв'язку).

Розрахунок розділового порогу `T_split`:

```
T_split = (t_half_nom + t_full_nom) / 2
= (1.6667 мкс + 3.3333 мкс) / 2                  [знаходження середнього арифметичного двох інтервалів]
= 5.0000 мкс / 2                                 [сума напівперіоду та періоду]
= 2.500 мкс                                      [розділовий поріг у мікросекундах]
```

У відносних одиницях від номінального бітового інтервалу `tBit`:

```
T_split / tBit_nom
= 2.500 мкс / 3.3333 мкс                         [відношення порогу до періоду]
= 0.750                                          [коефіцієнт відношення]
= 3/4 · tBit_nom                                 [поріг становить рівно три чверті біта]
```

Нижня межа валідного сигналу `T_noise` обирається посередині між нульовою тривалістю та напівперіодом:

```
T_noise = t_half_nom / 2
= 1.6667 мкс / 2                                 [половина напівперіоду]
= 0.833 мкс                                      [поріг відсікання шумів]
= 0.250 · tBit_nom                               [одна чверть бітового інтервалу]
```

Верхня межа валідного біта `T_timeout`:

```
T_timeout = t_full_nom + (t_full_nom - t_half_nom) / 2
= 3.3333 мкс + (3.3333 мкс - 1.6667 мкс) / 2    [симетричне розширення зони повного біта]
= 3.3333 мкс + 0.8333 мкс                        [додавання чверті бітового періоду]
= 4.167 мкс                                      [верхній часовий ліміт]
= 1.250 · tBit_nom                               [п'ять чвертей бітового інтервалу]
```

### 7. Очна діаграма та розрахунок запасу завадостійкості з гістерезисом

На боці приймача вхідний сигнал подається на аналоговий компаратор із порогом спрацьовування `V_ref ≈ 0.55 В` та вбудованим гістерезисом `V_hys = 50 мВ`. Верхній поріг перемикання становить `V_th_high = 0.575 В`, а нижній — `V_th_low = 0.525 В`.

Розрахуємо мінімальну вертикальну апертуру очної діаграми `V_eye` (висоту розкриття ока). Для сигналу з розмахом `V_swing = 1.12 В` та максимальним спадом через залишкову напругу розряду ємності лінії:

```
V_eye = V_swing - 2 · ΔV_noise - V_hys
= 1.12 В - 2 · 0.05 В - 0.05 В                   [віднімання шумових коридорів та ширини гістерезису]
= 1.12 В - 0.10 В - 0.05 В                       [обчислення втрат амплітуди]
= 0.97 В                                         [залишкова вертикальна апертура ока]
```

Відносна висота відкриття ока:

```
V_eye / V_swing
= 0.97 В / 1.12 В                                [відношення відкритої зони до повної амплітуди]
= 0.866                                          [коефіцієнт розкриття]
= 86.6%                                          [вертикальний запас становить понад 86%]
```

Горизонтальне розкриття очної діаграми `T_eye` (часове вікно, вільне від невизначеності) для найкоротшого інтервалу `t_half = 1.667 мкс` з урахуванням сумарного джиттеру `J_total = ±333 нс` та часу наростання `t_rise = 110 нс`:

```
T_eye = t_half_nom - 2 · |J_total| - t_rise
= 1667 нс - 2 · 333 нс - 110 нс                  [віднімання подвійного пікового джиттеру та часу наростання]
= 1667 нс - 666 нс - 110 нс                      [обчислення часових втрат]
= 891 нс                                         [корисна тривалість стабільної полички сигналу]
```

Відносне горизонтальне розкриття:

```
T_eye / t_half_nom
= 891 нс / 1667 нс                               [відношення корисного інтервалу до тривалості півбіта]
= 0.534                                          [коефіцієнт часової апертури]
= 53.4%                                          [горизонтальне розкриття перевищує 50%]
```

Отриманий запас доводить, що навіть у найгірших експлуатаційних умовах (довгий кабель, максимальна ємність, завади від сусідніх силових шин VBUS) середина бітового інтервалу залишається повністю вільною від перехідних процесів протягом майже 900 нс.

### 8. Спектральна щільність потужності та баланс постійної складової

Однією з ключових вимог до протоколу зв'язку на лінії CC є збереження статичного зміщення DC, яке задається резистивним дільником Rp/Rd для відстеження підключення кабелю. Якщо інформаційний потік міститиме довготривалу постійну складову (як це відбувається у простому кодуванні NRZ при передачі довгих послідовностей одиниць або нулів), середня напруга на лінії почне плавати, що викличе хибне спрацьовування аналогових компараторів виявлення роз'єднання порту.

Спектральна густина потужності `S_BMC(f)` сигналу BMC описується аналітичним виразом:

```
S_BMC(f) = V_swing² · tBit · (sin⁴(π · f · tBit / 2)) / (π · f · tBit / 2)²
```

Дослідимо поведінку спектра на нульовій частоті `f → 0` (постійна складова):

```
lim [f → 0] S_BMC(f)
= lim [f → 0] V_swing² · tBit · ( (π · f · tBit / 2)⁴ ) / ( (π · f · tBit / 2)² )   [розклад синуса в ряд Тейлора sin(x) ≈ x]
= lim [f → 0] V_swing² · tBit · (π · f · tBit / 2)²                                  [скорочення степенів]
= 0                                                                                   [спектральна щільність на нульовій частоті тотожно рівна нулю]
```

Нульова спектральна щільність на постійному струмі гарантує, що передача довільного пакета даних у кодуванні BMC не змінює середнього потенціалу лінії за інтервал передачі, якщо сигнал модулюється симетрично відносно поточного рівня зміщення або передається через активний драйвер, який після завершення кадру плавно повертає лінію у високоімпедансний стан.

### 9. Фазова стійкість при відхиленні частоти тактового генератора

Розглянемо накопичення часової похибки при максимальному технологічному відхиленні частоти внутрішнього RC-генератора мікроконтролера `Δf / f_nom = ±10%`.

У класичному асинхронному протоколі без проміжних переходів (наприклад, UART на 10 бітів) фазова похибка накопичується від стартового біта до стопового:

```
Δt_uart_accum = 9.5 · tBit_nom · (Δf / f_nom)
= 9.5 · 3.333 мкс · 0.10                         [накопичення похибки за 9.5 бітових інтервалів]
= 3.166 мкс                                      [сумарне зміщення стробуючого імпульсу]
```

Для UART таке зміщення становить `3.166 / 3.333 = 95%` бітового інтервалу, що призводить до повного зриву прийому (зміщення стробу за межі комірки).

На противагу цьому, у кодуванні BMC кожен біт обов'язково починається з переходу рівня. Це означає, що таймер або контур ФАПЧ приймача скидає накопичену фазову похибку на межі кожної комірки. Максимальна фазова похибка `Δt_bmc_max` обмежується тривалістю лише одного напівперіоду:

```
Δt_bmc_max = t_half_nom · (Δf / f_nom)
= 1.667 мкс · 0.10                               [максимальний дрейф за один напівперіод]
= 0.1667 мкс                                     [зміщення всього 167 наносекунд]
= 167 нс                                         [абсолютна похибка]
```

Порівняємо це зміщення з мінімальним запасом вікна дискримінації `M_half = 833 нс`:

```
Δt_bmc_max / M_half
= 167 нс / 833 нс                                [відношення похибки до запасу вікна]
= 0.200                                          [коефіцієнт використання запасу]
= 20.0%                                          [похибка використовує лише п'яту частину допустимого вікна]
```

Математичний висновок однозначний: навіть при значному дрейфі тактової частоти ±10% похибка стробування BMC становить лише 20% від критичного запасу, що гарантує 100% збереження синхронізації без застосування прецизійних кварцових резонаторів.

### 10. Квантування таймера мікроконтролера та вибір тактової частоти

Коли декодування BMC виконується за допомогою таймера захоплення мікроконтролера (input capture timer), виміряний інтервал дискретизується з кроком періоду таймера `T_clk = 1 / f_timer`. Похибка дискретизації вимірювання інтервалу становить `±1 · T_clk`.

Розрахуємо мінімальну допустиму тактову частоту таймера `f_timer_min`, щоб похибка квантування не перевищувала 5% від мінімального запасу вікна `M_half = 833 нс`:

```
Δt_quant_max = 0.05 · M_half
= 0.05 · 833 нс                                  [обчислення 5% від запасу вікна]
= 41.65 нс                                       [максимально допустимий крок таймера]

f_timer_min = 1 / Δt_quant_max
= 1 / (41.65·10⁻⁹ с)                             [обернена величина до кроку]
= 24.01·10⁶ Гц                                   [мінімальна тактова частота таймера]
≈ 24 МГц                                         [потрібна частота ядра/таймера]
```

При стандартній тактовій частоті таймера сучасних мікроконтролерів `f_timer = 48 МГц` (`T_clk ≈ 20.83 нс`) кількість відліків таймера для ключових порогів становить:

```
N_half = t_half_nom / T_clk
= 1.6667 мкс / 20.833 нс                         [кількість тактів на півбіт]
= 80 відліків                                    [номинал для півбіта]

N_full = t_full_nom / T_clk
= 3.3333 мкс / 20.833 нс                         [кількість тактів на повний біт]
= 160 відліків                                   [номинал для повного біта]

N_split = T_split / T_clk
= 2.500 мкс / 20.833 нс                          [кількість тактів для порогу поділу]
= 120 відліків                                   [поріг у коді таймера]
```

Ці цілочисельні константи (`80`, `120`, `160` тактів) закладаються безпосередньо в регістри порівняння та логіку обробника переривань вхідного захоплення, забезпечуючи практично нульові обчислювальні витрати процесора під час потокового декодування.

### 11. Імовірність бітової помилки (BER) та стійкість до гаусового шуму

Оцінимо ймовірність бітової помилки (Bit Error Rate, `BER`) декодера в умовах випадкового адитивного білого гаусового шуму (AWGN) з дисперсією `σ²` (середньоквадратичне відхилення напруги шуму `σ_noise`).

Помилка виникає тоді, коли миттєва напруга шуму `v_n` перевищує половину вертикального розкриття ока `V_eye / 2`:

```
P_bit_error = Q( (V_eye / 2) / σ_noise )
```

де `Q(x)` — інтегральна хвостова функція стандартного нормального розподілу.

Для реального робочого оточення з типовим рівнем шуму `σ_noise = 30 мВ` (0.030 В) та `V_eye = 0.97 В`:

```
x_arg = (V_eye / 2) / σ_noise
= (0.97 В / 2) / 0.030 В                         [ділення напіввисоти ока на СКВ шуму]
= 0.485 В / 0.030 В                              [обчислення відношення]
= 16.17                                          [аргумент Q-функції]
```

Для аргументу `x = 16.17` значення Q-функції прямує до астрономічно малих величин:

```
Q(16.17) ≈ (1 / (16.17 · √(2π))) · e^(-16.17² / 2)
≈ 0.02465 · e^(-130.74)                          [обчислення експоненти]
≈ 10⁻⁵⁸                                          [теоретична ймовірність бітової помилки]
```

Для повного пакета повідомлення USB PD довжиною `N_bits = 240 біт` (30 байтів разом із заголовком, об'єктами PDO та CRC-32) імовірність успішного прийому пакета без спотворень `P_packet_success`:

```
P_packet_success = (1 - P_bit_error)^N_bits
≈ (1 - 10⁻⁵⁸)²⁴⁰                                 [піднесення до степеня 240]
≈ 1 - 240·10⁻⁵⁸                                  [лінійна апроксимація для малих P]
≈ 1.0                                            [абсолютна надійність прийому]
```

Навіть за екстремальних умов завад від сусідніх імпульсних перетворювачів із розмахом шуму `σ_noise = 80 мВ` аргумент становить `x = 0.485 / 0.08 = 6.06`, що дає `BER ≈ Q(6.06) ≈ 6.8·10⁻¹⁰`. Для такого зашумленого каналу 32-розрядний циклічний код CRC-32 виявляє 100% одиночних, подвійних, потрійних та будь-яких непарних пакетних помилок довжиною до 32 біт, гарантуючи ймовірність пропуску дефектного пакета менше `2⁻³² ≈ 2.33·10⁻¹⁰`.

### 12. Енергетичні втрати на перезаряджання ємності кабелю

Під час генерації послідовності BMC драйвер передавача на кожному фронті здійснює заряд або розряд сумарної ємності лінії `C_line`. Енергія `E_trans`, що розсіюється на вихідному опорі драйвера та провідниках за один перехід напруги з розмахом `V_swing`:

```
E_trans = 1/2 · C_line · V_swing²
= 0.5 · 1000·10⁻¹² Ф · (1.12 В)²                 [підстановка максимальної ємності лінії та амплітуди]
= 0.5 · 10⁻⁹ Ф · 1.2544 В²                       [піднесення до квадрата]
= 0.6272·10⁻⁹ Дж                                 [обчислення енергії одного переходу]
= 0.627 нДж                                      [енергія у наноджоулях]
```

Для послідовності бітів '1' частота перемикання становить два переходи на біт, тобто `f_trans = 2 · f_bit = 600·10³` переходів за секунду (600 кГц). Середня динамічна потужність розсіювання `P_dyn`:

```
P_dyn = f_trans · E_trans
= 600·10³ с⁻¹ · 0.6272·10⁻⁹ Дж                   [множення частоти переходів на енергію одиничного переходу]
= 376.32·10⁻⁶ Вт                                 [обчислення потужності у ватах]
= 376.3 мкВт                                     [переведення у мікровати]
= 0.376 мВт                                      [потужність менше половини мілівата]
```

Мізерне значення динамічної потужності (менше 0.4 мВт) дозволяє інтегрувати BMC-трансивери безпосередньо у кристали малопотужних контролерів живлення без додаткових тепловідводів та без значного навантаження на акумулятор портативного пристрою.

### 13. Підсумкова таблиця рішень кінцевого автомата приймача

На основі розрахованих порогів формується таблиця рішень кінцевого автомата приймача, де виміряний інтервал між фронтами `Δt` однозначно визначає тип прийнятого символу:

```
[0.000 мкс .. 0.833 мкс)  →  Шум / апаратний брязкіт: таймер ігнорує подію
[0.833 мкс .. 2.500 мкс)  →  Півбіт (t_half): перша чи друга половина біта '1'
[2.500 мкс .. 4.167 мкс)  →  Повний біт (t_full): завершений біт '0'
[4.167 мкс .. +∞)         →  Таймаут: лінія вільна (Line Idle) / завершення кадру
```

Запас завадостійкості для половинного біта `M_half` та повного біта `M_full`:

```
M_half = T_split - t_half_nom
= 2.500 мкс - 1.667 мкс                          [відстань від центру вікна до границі]
= 0.833 мкс                                      [абсолютний запас]
= 0.833 мкс / 1.667 мкс                          [відносний запас]
= 50.0%                                          [допустиме відхилення півбіта]

M_full = T_timeout - t_full_nom
= 4.167 мкс - 3.333 мкс                          [відстань від номіналу до таймауту]
= 0.834 мкс                                      [абсолютний запас]
= 0.834 мкс / 3.333 мкс                          [відносний запас]
= 25.0%                                          [допустиме відхилення повного біта]
```

Наявність симетричного запасу завадостійкості не менше 25% дозволяє системі стабільно приймати пакети USB PD навіть за умов значного дрейфу тактової частоти дешевих RC-генераторів мікроконтролерів (до ±10%) та сильного спотворення фронтів через паразитну ємність довгих кабелів.
