# 🧮 Математична модель виявлення приймача SuperSpeed

Фізичний рівень SuperSpeed USB повинен визначати наявність підключеного приймача на протилежному кінці кабелю без використання виділених механічних чи логічних контактів виявлення. Через наявність розв'язувальних AC-конденсаторів ємністю `C_ac` у діапазоні 75–200 нФ постійний струм через лінію не проходить, що унеможливлює пряме вимірювання статичного опору дільника. Рішення базується на вимірюванні перехідного процесу заряду еквівалентного RC-ланцюжка при подачі східчастого сигналу напруги `V_step`.

Нижче наведено строгий математичний аналіз перехідних характеристик для випадків підключеного та відімкненого приймача, виведення передатної функції в операторній формі Лапласа, аналітичний розрахунок часових констант, диференційний та синфазний аналіз, нелінійну модель ESD-структур, оцінку впливу паразитарної індуктивності (RLC-модель другого порядку), розрахунок затримок поширення у довгому кабелі, вплив проміжних комутаторів Type-C MUX та редрейверів, пікові струми гарячого підключення, енергетичний баланс вимірювального циклу, метрологічну сертифікацію USB-IF та обґрунтування вибору порогу спрацьовування стробувального компаратора в умовах технологічного розкиду й температурного дрейфу.

### 1. Фізична постановка задачі та еквівалентна схема

У класичному стандарті USB 2.0 виявлення пристрою здійснювалося шляхом вимірювання постійної напруги на лініях D+ або D−, яку створював резистор підтяжки 1,5 кОм до джерела 3,3 В. У шині SuperSpeed лінії постійного струму розірвані послідовними конденсаторами `C_ac`, встановленими безпосередньо біля вихідних буферів передавача. Постійний струм через відкритий порт не протікає ніколи, незалежно від наявності чи відсутності кабелю.

Щоб виявити наявність приймача, апаратний блок передавача (TX PHY) періодично переходить у спеціальний діагностичний стан `Rx.Detect`. У цьому стані вихідні драйвери передавача SSTX+ та SSTX− генерують одночасний синфазний стрибок напруги `V_step = V₀ · u(t)`, де `u(t)` — функція одиничного стрибка Хевісайда:

```
u(t) = 0   при t < 0
u(t) = 1   при t ≥ 0
```

Розглянемо зосереджені параметри одного сигнального плеча тракту:
- `V₀` — амплітуда вихідного імпульсу передавача (за стандартом `V₀ = 0.50 В`);
- `R_tx` — внутрішній вихідний імпеданс драйвера передавача (`R_tx = 45 Ом`);
- `C_ac` — послідовна розв'язувальна ємність передавача (`C_ac = 100 нФ`, допуск 75–200 нФ);
- `C_pad` — паразитарна ємність вихідних контактних площадок кремнієвого кристала, корпусу мікросхеми та друкованого роз'єма (`C_pad ≈ 1.5–2.0 пФ`);
- `L_trace` — паразитарна індуктивність вивідної рамки та роз'єма (`L_trace ≈ 1.0–2.5 нГн`);
- `R_rx` — вхідний термінаційний опір приймача відносно високочастотної сигнальної землі.

Стандарт USB 3.x чітко розрізняє два фізичні стани термінації `R_rx`:
1. **Приймач підключено (Terminated Receiver):** вхідний опір термінатора приймача активовано і він становить `R_rx = R_term = 45 Ом` (що формує диференційний опір пари 90 Ом).
2. **Приймач відсутній (Open Circuit / Unattached):** навантаження розімкнене, внутрішні термінатори вимкнені, опір лінії визначається виключно опором витоку діелектрика `R_rx = R_open → ∞` (типово `R_leak > 25 кОм`).

### 2. Операторний аналіз у просторі Лапласа

Для отримання повного аналітичного розв'язку незалежно від форми вхідного сигналу побудуємо операторну модель кола за допомогою перетворення Лапласа.

Вхідний ступінчастий сигнал у просторі Лапласа подається як `V_in(s) = V₀ / s`.

Повний комплексний імпеданс послідовного кола `Z_total(s)` містить опір джерела `R_tx`, імпеданс розв'язувального конденсатора `1 / (s · C_ac)` та активний опір приймача `R_rx`:

```
Z_total(s) = R_tx + 1 / (s · C_ac) + R_rx
= (R_total · s · C_ac + 1) / (s · C_ac)   [зведення до спільного знаменника]
```

де `R_total = R_tx + R_rx` — сумарний активний опір петлі заряду.

Струм заряду в операторному вигляді визначається за законом Ома:

```
I(s) = V_in(s) / Z_total(s)
= (V₀ / s) · (s · C_ac / (R_total · s · C_ac + 1))   [ділення напруги на імпеданс]
= (V₀ · C_ac) / (R_total · C_ac · s + 1)             [скорочення оператора s]
= (V₀ / R_total) / (s + 1 / τ_term)                  [канонічна форма першого порядку]
```

де `τ_term = R_total · C_ac` — часова константа навантаженого кола.

Вимірювальний компаратор передавача фізично підключений до внутрішнього сигнального вузла мікросхеми перед розв'язувальним конденсатором `C_ac`. Напруга у цій точці `V_sense(s)` формується як падіння напруги на послідовній ланці «конденсатор `C_ac` + термінатор `R_rx`»:

```
V_sense(s) = I(s) · (1 / (s · C_ac) + R_rx)
= I(s) · ((1 + s · R_rx · C_ac) / (s · C_ac))       [імпеданс навантажувальної гілки]
```

Підставивши вираз для струму `I(s)` та ввівши позначення локальної константи приймача `τ_rx = R_rx · C_ac`:

```
V_sense(s) = (V₀ / s) · ((1 + s · τ_rx) / (1 + s · τ_term))   [операторна напруга сенсорного вузла]
```

Передатна характеристика ланки `H(s) = V_sense(s) / V_in(s)` має вигляд:

```
H(s) = (1 + s · τ_rx) / (1 + s · τ_term)
```

Аналіз полюсів та нулів передатної функції показує:
- Нуль передатної функції: `z₁ = -1 / τ_rx = -1 / (R_rx · C_ac)`;
- Полюс передатної функції: `p₁ = -1 / τ_term = -1 / ((R_tx + R_rx) · C_ac)`.

Оскільки сумарний опір `R_total = R_tx + R_rx` завжди строго більший за `R_rx`, полюс лежить ближче до початку координат, ніж нуль (`|p₁| < |z₁|`). Це означає, що система демонструє поведінку інтегрувальної ланки з початковим східчастим п'єдесталом напруги, обумовленим резистивним дільником.

### 3. Часовий розв'язок для підключеного приймача

Виконаємо зворотне перетворення Лапласа для виразу `V_sense(s)` методом розкладання на прості дроби:

```
V_sense(s) / V₀ = A / s + B / (s + 1 / τ_term)
```

Обчислимо залишки у полюсах:

```
A = lim_{s→0} [s · V_sense(s) / V₀]
= 1                                          [значення стаціонарного коефіцієнта]

B = lim_{s→-1/τ_term} [(s + 1/τ_term) · V_sense(s) / V₀]
= -R_tx / R_total                            [значення динамічного коефіцієнта]
```

Переходячи в часову область за таблицею оригіналів:

```
V_sense(t) = V₀ · (1 - (R_tx / R_total) · e^(-t / τ_term))
```

Враховуючи, що номінальні опори стандарту симетричні (`R_tx = R_rx = 45 Ом`), коефіцієнт дільника дорівнює:

```
R_tx / R_total = 45 / (45 + 45) = 0.5
```

Тоді аналітичний вираз напруги для підключеного приймача набуває остаточного вигляду:

```
V_sense(t) = V₀ · (1 - 0.5 · e^(-t / τ_term))
```

Розрахуємо параметри для номінальних компонентів стандарту:

```
R_total = R_tx + R_rx
= 45 Ом + 45 Ом                              [сумарний активний опір кола]
= 90 Ом                                      [хвильовий опір узгодженої пари]

τ_term = R_total · C_ac
= 90 Ом · 100 · 10⁻⁹ Ф                       [добуток опору та номінальної ємності]
= 9.0 · 10⁻⁶ с                               [обчислення експоненційної константи]
= 9.0 мкс                                    [номінальна часова константа заряду]
```

У початковий момент комутації `t = 0+` розв'язувальний конденсатор повністю розряджений і еквівалентний короткому замиканню. Струм визначається суто резистивним дільником:

```
V_sense(0+) = V₀ · (1 - 0.5 · 1)
= 0.5 · V₀                                   [половинна амплітуда через дільник 45/45 Ом]
= 0.250 В                                    [початкова напруга для V₀ = 0.5 В]
```

Миттєва швидкість зміни напруги у початковий момент:

```
d V_sense / dt |_{t=0+} = (0.5 · V₀) / τ_term
= 0.250 В / 9.0 · 10⁻⁶ с                     [початкова похідна експоненти]
= 27 778 В/с                                 [швидкість зростання сигналу]
= 0.0278 В/мкс                               [швидкість у практичних одиницях]
```

### 4. Часовий розв'язок для відімкненого приймача

Якщо кабель відімкнено або вхідні транзистори протилежного боку перебувають у високоомному стані (`R_rx → ∞`), струм через розв'язувальний конденсатор `C_ac` не має шляху стікання на землю.

Єдиним шляхом протікання струму стає крихітна паразитарна ємність вихідної контактної площадки та роз'єма `C_pad ≈ 2.0 пФ`.

Еквівалентна часова константа вільного порту:

```
τ_open = R_tx · C_pad
= 45 Ом · 2.0 · 10⁻¹² Ф                      [паразитарне навантаження драйвера]
= 90 · 10⁻¹² с                               [обчислення константи заряду]
= 90 пс                                      [часова константа вільної лінії]
```

Динаміка зміни напруги на розімкненому контакті:

```
V_sense_open(t) = V₀ · (1 - e^(-t / τ_open))
```

Початкова швидкість наростання напруги на вільному виводі:

```
d V_sense_open / dt |_{t=0+} = V₀ / τ_open
= 0.500 В / 90 · 10⁻¹² с                     [похідна напруги паразитарної ємності]
= 5.556 · 10⁹ В/с                            [початкова крутизна фронту]
= 5556 В/мкс                                 [швидкість наростання вільного виводу]
```

Порівняємо ключові часові характеристики двох станів:

```
τ_term / τ_open
= 9.0 · 10⁻⁶ с / 90 · 10⁻¹² с                [відношення часових констант]
= 100 000                                    [розрив у часових масштабах у 100 тисяч разів]

(d V_open / dt) / (d V_term / dt)
= 5556 В/мкс / 0.0278 В/мкс                  [відношення початкових швидкостей наростання]
= 200 000                                    [крутизна наростання різниться у 200 000 разів]
```

Цей гігантський розрив у п'ять порядків робить метод динамічного виявлення приймача надзвичайно стійким до будь-яких зовнішніх завад.

### 5. Затримка поширення хвилі в довгому кабелі (Transmission Line Delay)

Оцінимо вплив просторової затримки сигналу при використанні гранично допустимої довжини кабелю USB 3.0 `l_cable = 3.0 м`.

Швидкість поширення сигналу в кабелі з діелектричною проникністю ізоляції з поліетилену (`ε_r ≈ 2.25`):

```
v_cable = c / √ε_r
= 300 000 км/с / √2.25                       [швидкість світла в діелектрику кабелю]
= 300 000 / 1.5                              [обчислення кореня]
= 200 000 км/с = 200 мм/нс                   [швидкість поширення хвилі в ізоляції]
```

Час подвійного пробігу хвилі в кабелі (Round-Trip Time, RTT) до приймача і назад:

```
t_rtt = (2 · l_cable) / v_cable
= (2 · 3000 мм) / 200 мм/нс                  [подвоєна довжина кабелю на швидкість]
= 6000 / 200                                 [ділення величин]
= 30 нс                                      [час подвійного пробігу імпульсу]
```

Порівняємо час пробігу хвилі `t_rtt = 30 нс` із часом стробування компаратора `t_strobe = 1500 нс`:

```
t_rtt / t_strobe = 30 нс / 1500 нс = 0.02 = 2.0%
```

Оскільки час поширення сигналу становить лише 2% від моменту вимірювання, будь-які хвильові відбиття в кабелі встигають повністю затухнути задовго до стробування, і лінія поводиться строго як зосереджений RC-ланцюг.

### 6. Вплив комутаторів Type-C MUX та активних редрейверів

У сучасних комп'ютерах з портами USB Type-C між кристалом хост-контролера та фізичним роз'ємом часто встановлюються мікросхеми комутації орієнтації кабелю (Type-C Crossbar Multiplexer, MUX) або активні повторювачі (Redriver / Retimer).

Комутатор MUX додає в коло власний активний опір відкритих польових транзисторів `R_on ≈ 3–5 Ом` та паразитну ємність виводів `C_mux ≈ 0.5–1.0 пФ`:
- Сумарний опір кола незначно зростає: `R_total_mux = R_total + R_on = 90 + 5 = 95 Ом`;
- Часова константа змінюється до: `τ_term_mux = 95 Ом · 100 нФ = 9.5 мкс` (зсув становить лише +5,5%).

Сучасні редрейвери підтримують спеціальний апаратний режим трансляції виявлення (`Rx Detect Pass-Through`): коли мікросхема редрейвера помічає стрибок напруги на своєму вході від хоста, вона дублює аналогічний тестовий імпульс на свій вихідний порт до периферійного пристрою, транслюючи стан лінії приймача назад до хоста без порушення часових інтервалів.

### 7. Синфазний характер збудження та несприйнятливість до завад

Важливою перевагою алгоритму є те, що стрибок напруги `V_step` прикладається одночасно до обох ліній диференційної пари: SSTX+ та SSTX−.

Оскільки обидва провідники отримують однакову напругу:

```
V_diff(t) = V_TX+(t) - V_TX-(t)
= V_sense(t) - V_sense(t)                    [віднімання синфазних компонент]
= 0 В                                        [диференційна складова строго нульова]
```

Нульова диференційна напруга гарантує:
1. **Відсутність хибного спрацьовування високошвидкісного приймача:** диференційний вхідний підсилювач приймача реагує виключно на різницю напруг `V_diff`. Оскільки синфазна напруга придушується вхідним каскадом (коефіцієнт придушення синфазного сигналу CMRR > 30 дБ), тестовий імпульс виявлення не сприймається логікою приймача як початок передачі даних і не викликає спонтанних бітових помилок.
2. **Мінімальне випромінювання радіозавад:** синфазний стрибок напруги з амплітудою 0,5 В і частотою повторення 10–100 Гц генерує спектр випромінювання у низькочастотній області, яка повністю безпечна для радіочастотних трактів Wi-Fi та Bluetooth.

### 8. Нелінійність захисних ESD-діодів кристала

На кожному виводі інтегральної схеми фізичного рівня встановлено захисні діоди від електростатичного розряду (ESD, Electrostatic Discharge), з'єднані з шиною живлення та землею.

Зворотна ємність p-n переходу закритого ESD-діода залежить від миттєвої напруги на виводі `V` за нелінійним законом:

```
C_esd(V) = C₀ / √(1 + V / V_bi)
```

де:
- `C₀ ≈ 0.8–1.2 пФ` — бар'єрна ємність діода при нульовій напрузі зміщення;
- `V_bi ≈ 0.7 В` — вбудований контактний потенціал кремнієвого переходу.

Під час наростання напруги `V(t)` від 0 до 0,5 В ємність `C_esd` зменшується від `C₀` до `0.76 · C₀`. Оскільки ця ємність входить до складу малої паразитарної величини `C_pad` (порядку 2 пФ), її нелінійне зменшення лише прискорює наростання напруги на вільному виводі, ще більше збільшуючи розрив між вільною лінією та підключеним навантаженням `C_ac = 100 нФ`.

### 9. Аналіз впливу паразитарної індуктивності (Модель другого порядку RLC)

На реальній друкованій платі провідники роз'єма та бонди кристала мають паразитну індуктивність `L_trace ≈ 2.0 нГн`. Перевіримо, чи не виникає в колі коливального перехідного процесу (ringing), який міг би спотворити вимірювання напруги компаратором.

Характеристичне рівняння другого порядку для RLC-контуру:

```
s² + (R_total / L_trace) · s + 1 / (L_trace · C_ac) = 0
```

Коефіцієнт загасання контуру `ζ` (коефіцієнт демпфування):

```
ζ = (R_total / 2) · √(C_ac / L_trace)
= (90 / 2) · √(100 · 10⁻⁹ / 2.0 · 10⁻⁹)      [підстановка параметрів RLC контуру]
= 45 · √50                                   [обчислення підкореневого виразу]
= 45 · 7.071                                 [числовий розрахунок]
≈ 318
```

Оскільки коефіцієнт демпфування `ζ = 318 >> 1`, коло перебуває в стані глибокого аперіодичного загасання (overdamped response). Паразитна індуктивність роз'єма абсолютно не впливає на мікросекундний процес заряду і не створює жодних резонансних коливань.

---

### 10. Піковий струм та динаміка гарячого підключення (Hot-Plug Surge Current)

При раптовому вставлянні кабелю в порт напруга на виході драйвера піддається навантаженню незарядженої ємності лінії. Оцінимо максимальний піковий струм `I_peak`, що протікає крізь вихідні транзистори передавача:

```
I_peak = V₀ / R_tx
= 0.500 В / 45 Ом                            [максимальний струм короткого замикання]
= 11.1 · 10⁻³ А
= 11.1 мА                                    [безпечний рівень струму драйвера]
```

Величина 11,1 мА є абсолютно безпечною для транзисторів вихідного каскаду SerDes і не викликає теплової деградації чи ефекту защіпання (latch-up) у субмікронних КМОН-структурах.

### 11. Вибір часового стробування та розрахунок порогу компаратора

Компаратор передавача опитує рівень напруги на сигнальному виводі через суворо фіксований час стробування `t_strobe` після початку подачі імпульсу `V_step`.

Специфікація USB 3.x регламентує діапазон часу стробування в межах `t_strobe = 1.0 ... 3.0 мкс`. Оберемо центральну робочу точку `t_strobe = 1.5 мкс` і обчислимо миттєві напруги.

#### Стан 1: Приймач відсутній

```
t_strobe / τ_open
= 1.5 · 10⁻⁶ с / 90 · 10⁻¹² с                [відношення часу стробування до константи]
= 16 667                                     [число констант часу вільної лінії]

V_sense_open(1.5 мкс)
= V₀ · (1 - e^(-16 667))                     [розрахунок за експонентою розряду]
= V₀ · (1 - 0)                               [нескінченно мале значення залишкового члена]
= 0.500 В                                    [напруга досягає повної амплітуди джерела]
```

#### Стан 2: Приймач підключено

```
t_strobe / τ_term
= 1.5 мкс / 9.0 мкс                          [відношення часу вибірки до константи]
= 1 / 6 ≈ 0.1667                             [частка періоду заряду]

V_sense_term(1.5 мкс)
= V₀ · (1 - 0.5 · e^(-0.1667))               [підстановка показника експоненти]
= V₀ · (1 - 0.5 · 0.8465)                    [числове значення експоненти]
= V₀ · (1 - 0.4232)                          [множення коефіцієнтів]
= 0.5768 · V₀                                [відносна амплітуда сигналу на вузлі]
= 0.5768 · 0.500 В                           [підстановка напруги V₀]
= 0.288 В                                    [напруга за наявності підключеного приймача]
```

Абсолютний динамічний запас дискримінації між двома станами:

```
ΔV = V_sense_open - V_sense_term
= 0.500 В - 0.288 В                          [різниця виміряних рівнів]
= 0.212 В                                    [запас завадостійкості компаратора]
```

Ця різниця складає 42,4% від повної напруги живлення кроку `V₀`.

Оптимальний поріг спрацьовування стробувального компаратора `V_th` встановлюється точно посередині між двома рівнями:

```
V_th = (V_sense_open + V_sense_term) / 2
= (0.500 + 0.288) / 2                        [середнє арифметичне граничних рівнів]
= 0.394 В ≈ 0.400 В                          [поріг спрацьовування компаратора]
```

### 12. Аналіз граничних відхилень компонентів (Worst-Case Analysis)

Специфікація SuperSpeed допускає значний технологічний розкид характеристик дискретних та інтегральних компонентів:
- Ємність розв'язувального конденсатора `C_ac`: від 75 нФ (−25%) до 200 нФ (+100%);
- Вихідний опір передавача `R_tx`: допуск ±10% (від 40.5 Ом до 49.5 Ом);
- Вхідний опір приймача `R_rx`: допуск ±10% (від 40.5 Ом до 49.5 Ом);
- Температурний коефіцієнт опору (ТКО) напівпровідникових резисторів `α = +0.15% / °C`.

В діапазоні робочих температур від −40 °C до +85 °C максимальний опір резисторів кристала може зростати:

```
R_max = 49.5 Ом · (1 + 0.0015 · (85 - 25))
= 49.5 Ом · 1.09                             [врахування температурного нагріву]
= 53.95 Ом                                   [максимальний опір при +85 °C]
```

#### Найгірший випадок 1: Найшвидший заряд підключеного приймача
Цей випадок реалізується при мінімальній ємності `C_ac = 75 нФ` та мінімальних опорах `R_tx = R_rx = 40.5 Ом`:

```
R_total_min = 40.5 + 40.5 = 81.0 Ом
τ_min = 81.0 Ом · 75 · 10⁻⁹ Ф
= 6.075 мкс                                  [мінімальна можлива часова константа]

V_sense_worst(1.5 мкс)
= V₀ · (1 - 0.5 · e^(-1.5 / 6.075))          [найгірший випадок раннього стробу]
= V₀ · (1 - 0.5 · 0.7812)                    [значення показникової функції]
= 0.6094 · V₀                                [граничний відносний рівень напруги]
= 0.305 В                                    [максимальна напруга підключеного стану]
```

#### Найгірший випадок 2: Найповільніший заряд вільного порту
Цей випадок виникає при підвищеній паразитарній ємності `C_pad = 5.0 пФ` та максимальному опорі драйвера при нагріві `R_tx = 53.95 Ом`:

```
τ_open_max = 53.95 Ом · 5.0 · 10⁻¹² Ф
= 270 пс                                     [максимальна паразитарна затримка]

V_sense_open_worst(1.5 мкс)
= V₀ · (1 - e^(-1.5 · 10⁻⁶ / 270 · 10⁻¹²))
= V₀ · (1 - e^(-5555))
= V₀ = 0.500 В                               [повне досягнення амплітуди V₀]
```

Оцінка запасів стійкості порогу компаратора:

```
Запас_знизу = V_th - V_sense_worst
= 0.400 В - 0.305 В                          [відстань від найвищого сигналу підключення]
= 0.095 В                                    [запас 95 мВ]

Запас_зверху = V_sense_open_worst - V_th
= 0.500 В - 0.400 В                          [відстань від найнижчого сигналу відсутності]
= 0.100 В                                    [запас 100 мВ]
```

Запас завадостійкості складає не менше ніж 95–100 мВ в обидва боки, що повністю виключає помилкові спрацьовування в усьому діапазоні температур і технологічних допусків.

### 13. Метрологічна сертифікація та вимірювання за стандартами USB-IF

Під час проходження офіційної сертифікації USB-IF лабораторії відповідності перевіряють роботу вузла Receiver Detection за допомогою тестових стендів із прецизійними вимірювальними оснастками (USB 3.0 Electrical Compliance Test Fixture).

Осцилограф реального часу зі смугою пропускання понад 12 ГГц та активними диференційними пробниками реєструє фронт наростання напруги `V(t)` при підключенні каліброваного навантаження 90 Ом та розімкненої лінії. Специфікація вимагає, щоб час реакції схеми виявлення знаходився строго у вікні між 1,0 мкс та 3,0 мкс, а контролер не переходив у стан `Polling.LFPS` при підключенні паразитних ємностей до 10 пФ.

### 14. Енергетичний баланс та енергозбереження під час опитування

Визначимо кількість електричної енергії, яка розсіюється у вигляді тепла на активних опорах за один цикл генерації імпульсу виявлення:

```
E_pulse = ∫₀^∞ i²(t) · R_total dt
= (1 / 2) · C_ac · V₀²                       [інтегральна енергія заряду конденсатора]
= 0.5 · 100 · 10⁻⁹ Ф · (0.50 В)²             [підстановка параметрів вимірювального імпульсу]
= 12.5 · 10⁻⁹ Дж
= 12.5 нДж                                   [енергія одного циклу виявлення]
```

При стандартному періоді між опитуваннями в режимі очікування `T_poll = 100 мс` (частота повторення 10 Гц) середня електрична потужність становить:

```
P_avg = E_pulse / T_poll
= 12.5 · 10⁻⁹ Дж / 0.100 с                   [розрахунок середньої потужності]
= 125 · 10⁻⁹ Вт
= 125 нВт                                    [споживання у режимі очікування]
```

Величина 125 нВт у десятки тисяч разів менша за струм власного саморозряду типового акумулятора смартфона чи ноутбука. Це дозволяє контролерам SuperSpeed постійно тримати активним механізм `Rx.Detect` без помітного впливу на автономність пристрою.
