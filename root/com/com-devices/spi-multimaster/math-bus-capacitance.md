# 🧮 Розрахунок паразитної ємності, струмів витоку та граничної частоти шини SPI

Коли на спільну шину SPI підключають понад три-чотири ведені мікросхеми, цифрові сигнали стикаються з аналоговими законами фізики. Кожен додатковий корпус додає власну вхідну ємність виводів, ділянку друкованого провідника та струм витоку закритого вихідного каскаду. Якщо при двох датчиках шина бездоганно передає байти на частоті 40 МГц, то при підключенні десяти пристроїв прямокутні імпульси тактового сигналу SCK та даних MISO перетворюються на згладжені експоненційні криві. Це призводить до порушення часу встановлення (*setup time*) та фазового зсуву даних.

Нижче наведено повний математичний апарат розрахунку електричного навантаження багатоточкової шини SPI, формули динаміки перезаряду фронтів, критерій розподілених ліній з хвильовим опором, аналіз теплових струмів витоку, ємнісні перехресні наведення (*crosstalk*), паразитний підйом потенціалу землі (*Ground Bounce*), температурний дрейф параметрів та розрахунок граничної тактової частоти.

---

### 1. Модель сумарної паразитної ємності лінії

Будь-яка лінія зв'язку на друкованій платі (SCK, MOSI, MISO) має розподілену паразитну ємність відносно внутрішніх екранних шарів землі (*GND*) та живлення (*VCC*), а також зосереджені ємності кожного підключеного кристала.

Сумарна ємність лінії `C_total` для системи з одного ведучого (*Master*) та `N` ведених пристроїв (*Slaves*) виражається сумою трьох складових:

```
C_total = C_master + N · C_pin + C_trace      [сумарна ємність шини: буфери + піни + доріжки]
```

де:
- `C_master` — вихідна ємність виводу ведучого мікроконтролера (для ліній SCK та MOSI) або вхідна ємність буфера прийому (для лінії MISO). Типове значення для сучасних мікроконтролерів (STM32, ESP32, NXP i.MX RT) становить `3...6 пФ`.
- `C_pin` — власна ємність виводу кожного веденого пристрою (вхідний буфер плюс захисні діоди ESD). Для мікросхем у корпусах SOIC-8, QFN-16, LGA-24 вона лежить у межах `5...12 пФ`.
- `C_trace` — паразитна ємність друкованої доріжки плати.

#### Розрахунок погонної ємності: мікросмужка проти симетричної смужки

Геометрія трасування сигнального провідника на друкованій платі визначає його погонну ємність відносно екранних полігонів:

1. **Зовнішній шар (Мікросмужкова лінія / Microstrip):**
Сигнальний провідник розташовано на верхньому або нижньому шарі над суцільним полігоном землі. Для стандартного діелектрика FR-4 (`ε_r ≈ 4.3...4.5`, товщина шару препрегу `h = 0.2 мм`, ширина доріжки `w = 0.25 мм`, товщина мідної фольги `t = 0.035 мм`):

```
C_distr_micro = (0.264 · (ε_r + 1.41)) / (ln( (5.98 · h) / (0.8 · w + t) ))   [погонна ємність мікросмужки, пФ/см]
```

При підстановці параметрів:
- Чисельник формули: `0.264 · (4.4 + 1.41) = 0.264 · 5.81 ≈ 1.534`
- Знаменник формули: `ln( (5.98 · 0.2) / (0.8 · 0.25 + 0.035) ) = ln( 1.196 / 0.235 ) = ln(5.089) ≈ 1.627`
- Погонна ємність: `C_distr_micro = 1.534 / 1.627 ≈ 0.94 пФ / см`

2. **Внутрішній шар (Симетрична смужкова лінія / Stripline):**
Провідник затиснутий між двома суцільними екранними шарами землі або живлення (типово для 4-шарових та 6-шарових плат). Відстань між екранами `b = 0.5 мм`:

```
C_distr_strip = (0.555 · ε_r) / (ln( (3.8 · b + t) / (0.8 · w + t) ))          [погонна ємність смужки, пФ/см]
```

- Чисельник формули: `0.555 · 4.4 ≈ 2.442`
- Знаменник формули: `ln( (3.8 · 0.5 + 0.035) / (0.8 · 0.25 + 0.035) ) = ln( 1.935 / 0.235 ) = ln(8.234) ≈ 2.108`
- Погонна ємність: `C_distr_strip = 2.442 / 2.108 ≈ 1.16 пФ / см`

У реальній топології кожен перехідний отвір (*via*) між шарами плати має ємність `C_via ≈ 0.3...0.6 пФ`, а контактні площадки SMD-компонентів (*pads*) додають ще `0.2...0.4 пФ`. Тому інженерна оцінка розводки на платі приймається як `C_distr ≈ 1.2...1.5 пФ / см`.

Якщо загальна довжина топологічної магістралі шини становить `L = 25 см`, то ємність доріжки обчислюється як:

```
C_trace = L · C_distr                          [ємність доріжки від довжини]
= 25 см · 1.3 пФ/см                            [підстановка довжини 25 см та погонної ємності]
= 32.5 пФ                                      [результат ємності траси]
```

### 2. Динаміка перезаряду та тривалість фронтів

Вихідні каскади передавачів SPI працюють у комплементарному двотактному режимі (*push-pull*). При переході сигналу з логічного нуля в логічну одиницю верхній польовий транзистор (P-MOSFET) відкривається і заряджає ємність лінії від джерела живлення `VCC` через власний внутрішній опір каналу `R_on`.

Еквівалентна схема перезаряду описується класичним диференціальним рівнянням першого порядку, розв'язок якого дає експоненційну функцію напруги від часу:

```
U(t) = VCC · (1 - e^(-t / τ))                  [напруга заряду RC-кола від часу]
```

де стала часу кола:

```
τ = R_total · C_total                          [стала часу перехідного процесу]
```

Сумарний активний опір кола заряду `R_total` складається з внутрішнього опору відкритого транзистора `R_on`, зовнішнього послідовного резистора `R_series` (типово `22...33 Ом`) та опору мідного провідника:

```
R_total = R_on + R_series                      [сумарний активний опір кола передавача]
```

Для цифрових мікросхем стандарту LVCMOS 3.3V стандартний час наростання фронту `t_rise` вимірюється між рівнями 10% та 90% від напруги живлення `VCC`:

```
t_10 = -τ · ln(1 - 0.1) = -τ · ln(0.9) ≈ 0.1054 · τ   [час досягнення рівня 10% напруги]
t_90 = -τ · ln(1 - 0.9) = -τ · ln(0.1) ≈ 2.3026 · τ   [час досягнення рівня 90% напруги]
t_rise = t_90 - t_10                           [тривалість фронту наростання 10%-90%]
= 2.3026 · τ - 0.1054 · τ                      [різниця моментів часу]
= 2.1972 · τ                                   [точний коефіцієнт експоненти]
≈ 2.2 · R_total · C_total                      [інженерна формула тривалості фронту]
```

Аналогічно, тривалість спадання фронту `t_fall` при розряді через нижній N-канальний транзистор становить:

```
t_fall ≈ 2.2 · R_total_N · C_total             [тривалість фронту спадання сигналу]
```

Оскільки рухливість електронів у кремнії приблизно у 2–2.5 раза перевищує рухливість дірок, опір `R_on_N` N-канального транзистора зазвичай на 20–30% менший за опір `R_on_P` P-канального транзистора тієї ж площі. Через це час спадання фронту `t_fall` завжди дещо менший за час наростання `t_rise`.

### 3. Хвильові процеси: межа зосереджених та розподілених параметрів

При високих частотах комутації та довгих провідниках лінія перестає бути зосередженою ємністю і перетворюється на довгу лінію з хвильовими відбиттями (*transmission line*).

Швидкість поширення електромагнітної хвилі у діелектрику FR-4:

```
v = c / √(ε_eff)                               [швидкість поширення хвилі в діелектрику]
```

де `c = 300 000 км/с` — швидкість світла у вакуумі, а ефективна діелектрична проникність для мікросмужки `ε_eff ≈ 0.64 · ε_r + 0.36 ≈ 3.18`.

```
v = 30 / √(3.18) ≈ 30 / 1.783 ≈ 16.8 см / нс   [швидкість сигналу на платі]
```

Час подвійного пробігу сигналу вздовж доріжки довжиною `L` становить `t_prop = 2 · L / v`. За класичним правилом високочастотної схемотехніки, провідник вважається довгою лінією з необхідністю узгодження хвильового опору, якщо час наростання фронту менший за потрійний час пробігу:

```
t_rise ≤ 3 · t_prop = (6 · L) / v              [критерій розподіленої довгої лінії]
```

Звідси критична довжина провідника `L_crit`, вище якої виникають паразитні дзвін (*ringing*) та відбиття сигналу:

```
L_crit = (t_rise · v) / 6                      [критична довжина неузгодженої доріжки]
```

Якщо `t_rise = 3 нс` (швидкий вихід мікроконтролера STM32 у режимі Very High Speed), то:

```
L_crit = (3 нс · 16.8 см/нс) / 6 = 8.4 см      [максимальна довжина без узгодження]
```

Якщо довжина магістралі перевищує 8.4 см, на виході передавача обов'язково встановлюють послідовний демпферний резистор `R_series`, номінал якого вибирають з умови рівності сумарного опору хвильовому опору лінії `Z_0 ≈ 50...65 Ом`:

```
R_series = Z_0 - R_on                          [номінал послідовного узгоджувального резистора]
```

При `Z_0 = 50 Ом` та `R_on = 25 Ом` оптимальний номінал становить `R_series = 25 Ом` (стандартний ряд 22 або 27 Ом).

### 4. Ємнісне та індуктивне перехресне наведення (Crosstalk Modeling)

Коли високошвидкісна лінія тактування SCK проходить паралельно до лінії даних MISO або MOSI протягом значної відстані, між ними виникає паразитна взаємна ємність `C_mutual` та взаємна індуктивність `L_mutual`.

Під час кожного перепаду тактового сигналу SCK через взаємну ємність у лінію MISO інжектується струм завади:

```
I_crosstalk = C_mutual_total · (dV_sck / dt)    [ємнісний струм перехресного наведення]
```

Для крутого фронту мікроконтролера `dV_sck / dt = 3.3 В / 1.5 нс = 2.2 · 10⁹ В/с`. При взаємній ємності паралельних провідників `C_mutual = 0.3 пФ / см` на ділянці довжиною `L = 10 см` сумарна ємність зв'язку становить `C_mutual_total = 3.0 пФ`:

```
I_crosstalk = 3.0 · 10⁻¹² Ф · 2.2 · 10⁹ В/с     [обчислення струму завади]
= 6.6 · 10⁻³ А = 6.6 мА                         [амплітуда імпульсу струму наведення]
```

Цей струм завади створює сплеск напруги на вихідному опорі активного передавача `R_on = 35 Ом`:

```
V_noise = I_crosstalk · R_on                   [амплітуда пікової наведеної напруги]
= 6.6 · 10⁻³ А · 35 Ом                          [множення струму на опір каналу]
≈ 231 мВ                                       [сплеск напруги на лінії даних]
```

Якщо ж лінія MISO перебуває у стані High-Z з підтягуючим резистором `R_pull = 47 кОм`, амплітуда завади без обмеження захисними діодами могла б сягнути напруги живлення, генеруючи хибні біти.

**Схемотехнічне правило 3W:** Щоб зменшити взаємну ємність на 70%, відстань між центрами сигнальних провідників `S` повинна бути не меншою за потрійну ширину провідника: `S ≥ 3 · w`. Для критичних ліній SCK та MISO між ними додатково прокладають захисний екранний провідник землі (*Shield Trace*), підключений до полігону GND перехідними отворами через кожні 5–10 мм.

### 5. Температурний дрейф параметрів та аналіз найгіршого випадку (Worst-Case)

У реальних умовах експлуатації температура кристалів мікроконтролерів та ведених датчиків може змінюватися від -40 °C до +105 °C. Цей нагрів істотно змінює фізичні параметри напівпровідникових структур:

1. **Температурне зростання опору каналів польових транзисторів `R_on`:**
Через посилення розсіювання носіїв заряду на теплових коливаннях кристалічної ґратки (фононах) рухливість електронів і дірок у кремнії падає пропорційно `T^(-1.5)`. Опір відкритого каналу польового транзистора при температурі `T` зростає за законом:

```
R_on(T) = R_on(25°C) · (T_kelvin / 298.15)^1.5 [температурна залежність опору транзистора]
```

При температурі навколишнього середовища +105 °C (`T = 378.15 К`):

```
R_on(105°C) = 35 Ом · (378.15 / 298.15)^1.5    [підстановка температурного відношення]
= 35 Ом · (1.2683)^1.5                         [обчислення степеня]
= 35 Ом · 1.428 ≈ 50.0 Ом                      [гарячий опір відкритого каналу]
```

2. **Дрейф діелектричної проникності плати FR-4:**
Зі зростанням температури до +105 °C діелектрична проникність епоксидного компаунда зростає з 4.4 до 4.58, додаючи ще близько 4% до ємності друкованих провідників.

3. **Перерахунок тривалості фронту для гарячої плати:**
```
R_total_hot = R_on_hot + R_series              [сумарний опір при 105°C]
= 50.0 Ом + 22 Ом = 72.0 Ом                    [додавання опорів]

C_total_hot ≈ 150 пФ                           [гаряча ємність з урахуванням діелектрика]

τ_hot = 72.0 Ом · 150 · 10⁻¹² Ф                [гаряча стала часу]
= 10.8 нс                                      [стала часу перехідного процесу]

t_rise_hot = 2.197 · 10.8 нс ≈ 23.73 нс        [гаряча тривалість фронту наростання]
```

Якщо при кімнатній температурі фронт наростання становив 18.28 нс, то при максимальному нагріванні він розтягується до 23.73 нс (збільшення на 30%). Якщо додати час встановлення `t_su = 5 нс`, мінімальний напівперіод сигналу SCK зростає до `28.73 нс`, а гранична надійна тактова частота знижується з 21.5 МГц до `f_max_hot = 1 / (2 · 28.73 нс) ≈ 17.4 МГц`.

### 6. Розрахунок граничної тактової частоти шини

Період тактового сигналу SCK складається з тривалості високого напівперіоду `t_high`, низького напівперіоду `t_low` та двох перехідних фронтів `t_rise` і `t_fall`:

```
T_sck = t_high + t_low                         [повний період тактового сигналу SCK]
```

Для стабільного захоплення даних тригером веденого сигнал на лініях MOSI та MISO повинен зафіксуватися на стабільному рівні щонайменше за час встановлення `t_su` (*setup time*) до активного фронту SCK і зберігатися незмінним протягом часу утримання `t_hold` (*hold time*) після нього.

Мінімально допустима тривалість напівперіодів такту обмежується сумою тривалості фронту та часових вимог кремнію:

```
t_high_min = t_rise + t_su                     [мінімальний високий напівперіод SCK]
t_low_min  = t_fall + t_hold                   [мінімальний низький напівперіод SCK]
```

Для симетричного меандру зі шпаруватістю 50% (`t_high = t_low = T_sck / 2`) мінімальний період тактування визначається найгіршим із двох напівперіодів:

```
T_sck_min = 2 · max(t_rise + t_su, t_fall + t_hold)  [мінімальний період такту шини]
```

Звідси гранична теоретична частота тактування шини `f_max`:

```
f_max = 1 / T_sck_min                          [гранична частота шини SPI]
= 1 / (2 · (2.2 · R_total · C_total + t_su))   [розгорнута формула через фізичні параметри кола]
```

### 7. Повний інженерний розрахунок системи з 12 веденими

Розглянемо практичний приклад розрахунку магістральної шини SPI на платі промислового контролера.

**Вихідні дані:**
- Кількість підключених ведених пристроїв: `N = 12`.
- Середня вхідна ємність виводу одного веденого: `C_pin = 8.5 пФ`.
- Ємність приймально-передавального буфера ведучого MCU: `C_master = 5.0 пФ`.
- Загальна довжина магістралі шини на платі: `L = 30 см` при погонній ємності `1.3 пФ/см`.
- Вихідний опір транзистора передавача MCU: `R_on = 35 Ом`.
- Встановлено узгоджувальний демпферний резистор: `R_series = 22 Ом`.
- Паспортний час встановлення найповільнішого веденого (з даташита): `t_su = 5.0 нс`.
- Струм витоку одного веденого в стані Hi-Z: `I_OZ = 0.8 мкА` (при 25 °C).

#### Крок 1. Розрахунок сумарної паразитної ємності шини
```
C_trace = L · C_distr                          [ємність друкованого провідника]
= 30 см · 1.3 пФ/см                            [множення довжини на погонну ємність]
= 39.0 пФ                                      [результат ємності траси]

C_pins_total = N · C_pin                       [сумарна ємність виводів усіх ведених]
= 12 · 8.5 пФ                                  [множення кількості чіпів на ємність виводу]
= 102.0 пФ                                     [результат ємності мікросхем]

C_total = C_master + C_pins_total + C_trace    [сума всіх ємностей на лінії]
= 5.0 пФ + 102.0 пФ + 39.0 пФ                  [додавання складових]
= 146.0 пФ                                     [сумарне ємнісне навантаження шини]
```

#### Крок 2. Розрахунок активного опору та сталої часу
```
R_total = R_on + R_series                      [сумарний опір кола передавача]
= 35 Ом + 22 Ом                                [додавання вихідного опору та резистора]
= 57 Ом                                        [активний опір заряду]

τ = R_total · C_total                          [стала часу заряду кола]
= 57 Ом · 146.0 · 10⁻¹² Ф                      [підстановка опору та ємності]
= 8.322 · 10⁻⁹ с                               [обчислення експоненти]
= 8.322 нс                                     [стала часу в наносекундах]
```

#### Крок 3. Розрахунок тривалості фронту наростання
```
t_rise = 2.197 · τ                             [формула фронту наростання 10%-90%]
= 2.197 · 8.322 нс                             [множення коефіцієнта на сталу часу]
= 18.28 нс                                     [тривалість фронту наростання напруги]
```

#### Крок 4. Розрахунок мінімального періоду та граничної частоти
```
t_high_min = t_rise + t_su                     [мінімальний напівперіод такту]
= 18.28 нс + 5.0 нс                            [додавання тривалості фронту та часу встановлення]
= 23.28 нс                                     [тривалість високого стану SCK]

T_sck_min = 2 · t_high_min                     [мінімальний період сигналу SCK]
= 2 · 23.28 нс                                 [подвоєння для шпаруватості 50%]
= 46.56 нс                                     [мінімальний період такту]

f_max = 1 / T_sck_min                          [максимальна теоретична частота]
= 1 / (46.56 · 10⁻⁹ с)                         [обчислення зворотної величини]
≈ 21.48 МГц                                    [гранична тактова частота шини]
```

**Висновки розрахунку:**
Спроба тактувати дану магістраль на паспортній частоті швидкої Flash-пам'яті `40 МГц` (`T_sck = 25 нс`, напівперіод `12.5 нс`) гарантовано призведе до збою: тривалість фронту `18.28 нс` більша за весь напівперіод такту, сигнал не досягне рівня логічної одиниці `V_IH`. З урахуванням 25% запасу на температурний дрейф максимальна робоча частота даної шини становить `f_work = 16 МГц`.

### 8. Струми витоку на лінії MISO та вибір резистора підтяжки

Коли активний ведений завершує транзакцію і піднімає свій вивід CS у високий стан `1`, його вихід MISO переходить у стан високого імпедансу (*High-Z*).

У цей момент всі `N` мікросхем генерують струми витоку `I_OZ` через закриті захисні ESD-діоди та закриті канали вихідних польових транзисторів:

```
I_leak_total = ∑ I_OZ_i ≈ N · I_OZ             [сумарний струм витоку на спільній лінії MISO]
```

При кімнатній температурі (+25 °C):

```
I_leak_total = 12 · 0.8 мкА = 9.6 мкА          [струм витоку при 25°C]
```

При роботі приладу в промисловому діапазоні температур (+85 °C) зворотні струми витоку p-n переходів подвоюються на кожні 10 °C підвищення температури:

```
k_temp = 2^((85 - 25) / 10) = 2^6 = 64         [коефіцієнт температурного зростання витоку]
I_leak_total_85C = 9.6 мкА · 64 ≈ 614 мкА      [максимальний гарячий струм витоку шини]
```

#### Розрахунок підтягуючого резистора (Pull-Down / Pull-Up)

Щоб уникнути плаваючого потенціалу MISO, лінію фіксують резистором `R_pull` до землі або живлення.

1. **Верхня межа опору (гарантія логічного нуля під дією витоку):**
Падіння напруги від максимального струму витоку на резисторі підтяжки до землі не повинно перевищувати граничний рівень логічного нуля `V_IL_max = 0.3 · VCC = 0.99 В`:

```
R_pull_max ≤ V_IL_max / I_leak_total_85C       [максимальний опір підтяжки з умови порогу нуля]
= 0.99 В / (614 · 10⁻⁶ А)                      [підстановка порогу та гарячого струму витоку]
≈ 1.61 кОм                                     [стеля опору для екстремальних температур]
```

2. **Нижня межа опору (обмеження навантаження на активний передавач):**
Активний ведений із вихідним опором `R_on = 35 Ом` при підтяжці до землі повинен забезпечити напругу одиниці `V_OH ≥ 0.8 · VCC = 2.64 В`:

```
R_pull_min ≥ R_on · (V_OH / (VCC - V_OH))      [мінімальний опір підтяжки з умови порогу одиниці]
= 35 Ом · (2.64 / 0.66)                        [підстановка параметрів дільника напруги]
= 35 Ом · 4                                    [множення коефіцієнта дільника]
= 140 Ом                                       [абсолютний нижній поріг опору]
```

**Практичне правило:** Для стандартних комерційних плат (+10...+50 °C) оптимальний номінал підтяжки становить `47...100 кОм`. Для важких промислових та автомобільних умов (+85...+125 °C) номінал підтяжки вибирають у межах `4.7...10 кОм`, або застосовують активні шинні буфери з функцією Bus-Hold.

### 9. Ефект підйому потенціалу землі (Ground Bounce) та завади живлення

При одночасному перемиканні вихідних ключів передавача SPI у процесі перезаряду високої ємності лінії `C_total` протікає значний імпульсний струм:

```
I_peak ≈ VCC / R_total                         [піковий струм перезаряду ємності шини]
= 3.3 В / 57 Ом ≈ 58 мА                        [обчислення пікового струму]
```

Швидкість наростання струму `di / dt` при тривалості фронту `t_rise = 18 нс`:

```
di / dt ≈ I_peak / (t_rise / 2)                [швидкість зміни струму в колі]
= 58 · 10⁻³ А / (9 · 10⁻⁹ с)                   [підстановка параметрів імпульсу]
≈ 6.44 · 10⁶ А / с = 6.44 А / мкс              [екстремальна крутість перепаду струму]
```

Паразитна індуктивність виводів корпусу мікроконтролера та провідників друкованої плати `L_ground ≈ 3...8 нГн` під дією цього перепаду струму генерує сплеск напруги на внутрішній земляній шині кристала — ефект **Ground Bounce**:

```
V_bounce = L_ground · (di / dt)                [амплітуда паразитного підскоку землі]
= 5 · 10⁻⁹ Гн · 6.44 · 10⁶ А/с                 [множення індуктивності на швидкість струму]
≈ 32.2 мВ                                      [сплеск напруги на виводі GND]
```

При одночасній роботі 32-розрядних паралельних шин або кількох каналів SPI цей сплеск може сягати `0.3...0.6 В`, що викликає помилкове спрацьовування вхідних тригерів Шмітта мікроконтролера. Для придушення Ground Bounce кожен вивід живлення `VCC` мікросхем обов'язково блокують керамічним конденсатором номіналом 100 нФ (типорозмір 0402 або 0603) з мінімальною довжиною підвідних доріжок безпосередньо біля виводу корпусу.

### 10. Динамічна потужність комутації шини

Перезаряд сумарної ємності шини на високих частотах генерує динамічну втрату потужності передавача, яка розсіюється у вигляді тепла на вихідних ключах:

```
P_dyn = C_total · VCC² · f_sck                 [динамічна потужність перезаряду ємності шини]
```

Для нашої системи з `C_total = 146 пФ` при `VCC = 3.3 В` та тактовій частоті `f_sck = 16 МГц`:

```
P_dyn = 146 · 10⁻¹² Ф · (3.3 В)² · 16 · 10⁶ Гц [підстановка ємності, напруги та частоти]
= 146 · 10⁻¹² · 10.89 · 16 · 10⁶               [обчислення квадратів та коефіцієнтів]
= 25.44 · 10⁻³ Вт = 25.44 мВт                  [динамічні втрати на кожній лінії SCK/MOSI]
```

Сумарні втрати на трьох активних лініях шини (SCK, MOSI, MISO) перевищують 75 мВт, що слід враховувати в енергоефективних автономних приладах із живленням від акумулятора.
