# 🧮 Розрахунок часового бюджету CS та асиметрії затримок

Коли тактова частота шини SPI перевищує 10–20 МГц або коли між ведучим мікроконтролером і веденим пристроєм встановлено гальванічну розв'язку (оптопари чи цифрові ізолятори), сигнал вибору кристала CS зазнає нерівномірних затримок відносно тактового сигналу SCLK. Якщо час поширення спадного фронту CS перевищить затримку сигналу SCLK, ведений пристрій отримає перший тактовий імпульс раніше, ніж його внутрішній автомат станів вийде зі стану очікування. У цьому розрахунку виведено повну систему рівнянь часового бюджету шини SPI: формули ефективного часу встановлення `t[CSS_eff]`, часу утримання `t[CSH_eff]`, мінімально допустимої паузи між транзакціями `t[CS_HIGH_eff]`, розрахунок максимальної безпечної тактової частоти `f[SCK_max]`, а також враховано вплив паразитної ємності друкованих провідників, хвильового опору мікросмужкових ліній, навантаження багатьох ведених (Multi-Drop Loading), фазового джиттера тактового генератора та температурного дрейфу компонентів.

---

### Фізична та еквівалентна схема каналу зв'язку

Розглянемо тракт поширення сигналів від вихідних каскадів мікроконтролера (Master) до вхідних тригерів веденої мікросхеми (Slave). Повний шлях сигналу проходить крізь чотири послідовні ланки:

```
Ведучий (Master)                      Ведений (Slave)
┌──────────────┐   Ізолятор / Драйвер ┌──────────────┐
│ GPIO (CS)    ├───[ t[PHL_CS]  ]────►│ CS_in        │
│ SPI (SCLK)   ├───[ t[PLH_CLK] ]────►│ SCLK_in      │
│ SPI (MOSI)   ├───[ t[prop_MOSI] ]──►│ MOSI_in      │
│ SPI (MISO)   ◄───[ t[prop_MISO] ]───┤ MISO_out     │
└──────────────┘                      └──────────────┘
```

1. **Вихідні цифрові драйвери ведучого**:
   Вихідний порт GPIO (для CS) та апаратний передавач SPI (для SCLK) мають внутрішній опір відкритого каналу польових транзисторів `R[on_P]` (для верхнього плеча) та `R[on_N]` (для нижнього плеча), а також внутрішню затримку перемикання логіки `t[d_gpio]` та `t[d_spi]`.
2. **Гальванічний ізолятор або буферний формувач**:
   Будь-який активний елемент розв'язки (оптичний, магнітний чи ємнісний) характеризується затримкою поширення сигналу при перемиканні з низького рівня у високий `t[PLH]` (від англ. *Propagation Delay Low-to-High*) та з високого в низький `t[PHL]` (від англ. *Propagation Delay High-to-Low*).
3. **Розподілена RC-лінія друкованого монтажу**:
   Друкований провідник має погонну індуктивність `L[trace]`, активний опір `R[trace]` та погонну ємність `C[trace]`. Якщо довжина лінії `l` менша за критичну довжину узгодження `l[crit] = t[r] / (2 · t[pd])`, лінію можна моделювати зосередженою ємністю навантаження `C[L]`, що складається з ємності доріжки `C[trace]`, вхідної ємності веденого `C[in]` та ємності монтажних майданчиків:
   ```
   C[L] = C[trace] · l + C[in_slave] + C[pad]
   ```
4. **Вхідний каскад веденого**:
   Вхід веденого пристрою являє собою комплементарну пару польових транзисторів із порогом перемикання `V[th] ≈ 0.5 · V[DD]` та гістерезисом тригера Шмітта `V[hyst] ≈ 0.2 · V[DD]`. Для гарантованого розпізнавання логічного нуля напруга на вході повинна впасти нижче `V[IL_max] = 0.3 · V[DD]`, а для логічної одиниці — піднятися вище `V[IH_min] = 0.7 · V[DD]`.

### Хвильові затримки мікросмужкових ліній друкованої плати

При передачі високочастотних сигналів по друкованій платі швидкість поширення електромагнітної хвилі вздовж поверхневого мікросмужкового провідника (*Microstrip Line*) над суцільним шаром землі обмежується ефективною діелектричною проникністю середовища `ε[r_eff]`:

```
ε[r_eff]
= 0.475 · ε[r] + 0.67                                 [емпірична формула Шнейдера для мікросмужки]
```

Для стандартного склотекстоліту марки FR-4 з відносною діелектричною проникністю `ε[r] ≈ 4.3`:

```
ε[r_eff]
= 0.475 · 4.3 + 0.67                                  [підстановка ε_r = 4.3]
= 2.0425 + 0.67                                       [множення]
= 2.7125                                              [ефективна проникність діелектрика]
```

Швидкість поширення сигналу в мідному провіднику:

```
v[prop]
= c / sqrt(ε[r_eff])                                  [швидкість світла у вакуумі поділена на корінь діелектрика]
= (3.0 · 10⁸) / sqrt(2.7125)                          [підстановка швидкості c = 3·10^8 м/с]
= (3.0 · 10⁸) / 1.647                                 [обчислення кореня]
≈ 1.82 · 10⁸ м/с                                      [реальна швидкість сигналу на платі]
```

Погонна затримка поширення на одиницю довжини провідника:

```
t[pd]
= 1 / v[prop]                                         [затримка на метр лінії]
= 1 / (1.82 · 10⁸)                                    [ділення]
≈ 5.49 · 10⁻⁹ с/м                                     [переведення у наносекунди]
= 5.49 пс/мм                                          [приблизно 5.5 пікосекунд на кожен міліметр доріжки]
```

Для плати з довжиною лінії `l = 150 мм` час прольоту хвилі становить:

```
t[flight]
= t[pd] · l                                           [добуток погонної затримки на довжину]
= 5.49 · 150                                          [множення значень]
= 823.5 пс                                            [результат у пікосекундах]
≈ 0.82 нс                                             [час прольоту лінії]
```

### Ємнісне навантаження при зірковій топології та багатьох ведених

Коли до однієї шини SPI підключено `N` ведених пристроїв, лінії SCLK та MOSI є спільними для всіх ведених, тоді як лінія CS розгалужується окремо на кожен кристал.

Нехай погонна ємність друкованої доріжки становить `C[0] = 1.0 пФ/см`, вхідна ємність кожного веденого кристала `C[in] = 7.0 пФ`, а ємність контактного майданчика `C[pad] = 1.5 пФ`.
Для шини довжиною `l = 20 см` з `N = 6` веденими пристроями сумарна ємність спільних ліній та індивідуальних ліній CS відрізняється кардинально:

```
C[L_CS]
= C[0] · l + 1 · (C[in] + C[pad])                     [ємність однієї лінії CS для одного веденого]
= 1.0 · 20 + 1 · (7.0 + 1.5)                          [підстановка значень]
= 20.0 + 8.5                                          [додавання складових]
= 28.5 пФ                                             [сумарна ємність лінії CS]

C[L_SCLK]
= C[0] · l + N · (C[in] + C[pad])                     [ємність спільної тактової лінії для N ведених]
= 1.0 · 20 + 6 · (7.0 + 1.5)                          [підстановка N = 6 пристроїв]
= 20.0 + 6 · 8.5                                      [множення на кількість ведених]
= 20.0 + 51.0                                         [підсумок ємності входів]
= 71.0 пФ                                             [сумарна ємність лінії SCLK]
```

Через значну різницю ємностей (`71.0 пФ` проти `28.5 пФ`) час наростання тактового сигналу SCLK стає більш ніж у 2.5 раза довшим, ніж час перемикання сигналу CS.

Зміна хвильового опору навантаженої тактової лінії:

```
Z[0_loaded]
= Z[0] / sqrt(1 + C[distributed] / C[line])           [формула деградації імпедансу при зосередженому навантаженні]
= 50.0 / sqrt(1 + 51.0 / 20.0)                        [підстановка номіналу Z_0 = 50 Ом]
= 50.0 / sqrt(1 + 2.55)                               [ділення ємностей]
= 50.0 / sqrt(3.55)                                   [обчислення виразу під коренем]
= 50.0 / 1.884                                        [добування квадратного кореня]
≈ 26.5 Ом                                             [зниження хвильового опору навантаженої шини]
```

Це падіння хвильового опору викликає значні відбиття сигналу на кінцях лінії. Якщо вихідний опір драйвера мікроконтролера становить `R[drv] ≈ 25 Ом`, а лінія не узгоджена послідовним резистором, коефіцієнт відбиття на вході веденого:

```
Γ[load]
= (R[in] - Z[0_loaded]) / (R[in] + Z[0_loaded])       [коефіцієнт відбиття від високомного входу CMOS]
≈ (10⁶ - 26.5) / (10⁶ + 26.5)                         [підстановка R_in = 1 МОм]
≈ +1.0                                                [повне відбиття хвилі без зміни фази]
```

Відбита хвиля викликає коливальний дзвін (*Ringing*), через що напруга на лінії CS після спаду може повторно перетнути поріг `V[IL] = 0.3 · V[DD]`, викликаючи помилкове подвійне детектування початку кадру. Для демпфування дзвону безпосередньо біля виводу ведучого встановлюють демпферний резистор номіналом `R[series] = Z[0_loaded] - R[drv] ≈ 20–33 Ом`.

### Розрахунок граничної тактової частоти шини SPI

Максимальна тактова частота шини SPI `f[SCK_max]` обмежується повним часом кругової затримки сигналу в тракті зчитування даних (*Round-Trip Propagation Delay*).

Під час читання даних ведучий генерує перепад SCLK, який поширюється до веденого. Ведений пристрій видає біт даних на лінію MISO із внутрішньою затримкою `t[CLQV]` (або `t[V]`). Після цього сигнал MISO поширюється назад до ведучого і повинен надійти на вхідний тригер ведучого раніше, ніж завершиться півперіоду такту, із запасом на час встановлення ведучого `t[setup_master]`.

Рівняння кругового часового балансу для режиму SPI Mode 0:

```
T[SCK] / 2
≥ t[prop_CLK_forward] + t[CLQV_slave] + t[prop_MISO_return] + t[setup_master] [умова успішного зчитування за півперіоду]
```

Повний період тактового сигналу:

```
T[SCK_min]
= 2 · (t[prop_CLK_forward] + t[CLQV_slave] + t[prop_MISO_return] + t[setup_master]) [мінімальний період такту SCLK]
```

Розрахуємо граничну частоту для прямого підключення Flash-пам'яті Winbond W25Q128JV (`t[CLQV] = 6.0 нс`) до мікроконтролера STM32H7 (`t[setup_master] = 2.0 нс`) при затримці друкованих ліній `t[flight] = 0.8 нс` та тривалості фронтів `t[r] = 1.2 нс`:

```
t[prop_CLK]
= 0.8 + 1.2                                           [сума часу прольоту та наростання такту]
= 2.0 нс                                              [затримка такту до веденого]

t[prop_MISO]
= 0.8 + 1.2                                           [сума часу прольоту та спаду MISO]
= 2.0 нс                                              [затримка повернення даних до ведучого]

T[SCK_min]
= 2 · (2.0 + 6.0 + 2.0 + 2.0)                         [підстановка значень у формулу періоду]
= 2 · 12.0                                            [додавання складових затримок]
= 24.0 нс                                             [мінімальний період тактового сигналу]
```

Максимальна теоретична частота прямого SPI читання:

```
f[SCK_max]
= 1 / T[SCK_min]                                      [обернена величина періоду]
= 1 / (24.0 · 10⁻⁹)                                   [ділення одиниці на наносекунди]
≈ 41.67 · 10⁶ Гц                                      [результат у герцах]
≈ 41.6 МГц                                            [максимальна робоча частота шини без зсуву фази]
```

Якщо на шину додано гальванічний ізолятор із затримкою `t[prop_iso] = 40.0 нс` у кожному напрямку, мінімальний період такту різко зростає:

```
T[SCK_isolated]
= 2 · (40.0 + 2.0 + 6.0 + 40.0 + 2.0 + 2.0)           [підстановка затримок з урахуванням ізолятора]
= 2 · 92.0                                            [сума затримок кругового тракту]
= 184.0 нс                                            [мінімальний період такту в ізольованому каналі]

f[SCK_isolated_max]
= 1 / (184.0 · 10⁻⁹)                                  [ділення]
≈ 5.43 МГц                                            [падіння граничної частоти майже у 8 разів]
```

### Рівняння затримок поширення фронтів

Активним станом сигналу CS у переважній більшості мікросхем є логічний нуль (активний спадний фронт `1 → 0`). Повний час поширення спадного фронту від моменту зміни біта в регістрі ведучого до фіксації низького рівня на вході веденого:

```
t[prop_CS_fall]
= t[d_gpio] + t[PHL_CS] + t[f_RC_CS] + t[flight]      [сума затримок драйвера, ізолятора, спаду RC та поширення хвилі]
```
де:
* `t[d_gpio]` — апаратна затримка порту вводу-виводу мікроконтролера;
* `t[PHL_CS]` — затримка перемикання ізолятора при перепаді `1 → 0`;
* `t[f_RC_CS]` — час спаду напруги від `0.9 · V[DD]` до `0.3 · V[DD]`, який визначається розрядом ємності лінії через нижній транзистор драйвера:
  ```
  t[f_RC_CS] ≈ 1.2 · R[on_N] · C[L_CS]
  ```
* `t[flight]` — час поширення електромагнітної хвилі по мідному провіднику друкованої плати.

Тактовий сигнал SCLK у режимі SPI Mode 0 (CPOL = 0) у стані спокою має рівень логічного нуля, а його перший активний перепад є наростаючим (`0 → 1`). Повний час поширення наростаючого фронту такту:

```
t[prop_CLK_rise]
= t[d_spi] + t[PLH_CLK] + t[r_RC_CLK] + t[flight]     [сума затримок блоку SPI, ізолятора, наростання RC та хвилі]
```
де:
* `t[d_spi]` — затримка внутрішньої логіки блоку SPI мікроконтролера;
* `t[PLH_CLK]` — затримка ізолятора при перепаді `0 → 1`;
* `t[r_RC_CLK]` — час наростання напруги від `0.1 · V[DD]` до `0.7 · V[DD]` через верхній транзистор драйвера `R[on_P]`:
  ```
  t[r_RC_CLK] ≈ 1.2 · R[on_P] · C[L_CLK]
  ```

### Виведення формули ефективного часу встановлення (t_CSS_eff)

Нехай у початковий момент часу `T = 0` ведучий мікроконтролер переводить лінію CS у низький рівень. За внутрішнім алгоритмом або завдяки апаратній паузі ведучий подає перший активний фронт такту SCLK через інтервал `t[CSS_master]`.

Момент приходу спадного фронту CS на вхід веденого:
```
T[CS_slave_active]
= 0 + t[prop_CS_fall]                                 [момент досягнення порогу V[IL] на вході CS веденого]
```

Момент приходу першого наростаючого фронту SCLK на вхід веденого:
```
T[CLK_slave_first]
= t[CSS_master] + t[prop_CLK_rise]                    [момент досягнення порогу V[IH] на вході SCLK веденого]
```

Ефективний час встановлення `t[CSS_eff]`, який фізично спостерігає вхідна логіка веденого пристрою:

```
t[CSS_eff]
= T[CLK_slave_first] - T[CS_slave_active]             [різниця моментів приходу такту та вибору]
= (t[CSS_master] + t[prop_CLK_rise]) - t[prop_CS_fall][розкриття часових виразів]
= t[CSS_master] + (t[prop_CLK_rise] - t[prop_CS_fall] [групування затримок каналів]
```

Підставимо детальні вирази затримок ліній:

```
t[CSS_eff]
= t[CSS_master] + (t[d_spi] - t[d_gpio]) + (t[PLH_CLK] - t[PHL_CS]) + (t[r_RC_CLK] - t[f_RC_CS]) [повна формула ефективного t_CSS]
```

Для гарантованого прийому першого біта обов'язково повинна виконуватися нерівність:

```
t[CSS_eff] ≥ t[CSS_min_datasheet]                     [умова надійної фіксації за паспортом веденого]
```

Звідси мінімальний інтервал випередження `t[CSS_master]`, який повинен забезпечити ведучий у коді:

```
t[CSS_master_min]
= t[CSS_min_datasheet] + (t[prop_CS_fall] - t[prop_CLK_rise]) [необхідний інтервал випередження на боці ведучого]
```

Визначимо диференційний часовий перекіс каналів ізоляції:

```
Δt[skew_iso]
= t[PHL_CS] - t[PLH_CLK]                              [асиметрія затримок ізолятора для спаду CS та наростання такту]
```

Якщо `Δt[skew_iso] > 0` (тобто спадний фронт CS поширюється повільніше, ніж наростаючий фронт такту), ефективний час встановлення зменшується на величину `Δt[skew_iso]`.

### Виведення формули ефективного часу утримання (t_CSH_eff)

Після формування останнього `N`-го тактового імпульсу ведучий утримує сигнал CS на низькому рівні протягом інтервалу `t[CSH_master]`, після чого переводить CS у високий стан (перепад `0 → 1`, деактивація).

Момент завершення останнього такту SCLK на веденому (повернення у стан спокою, спад `1 → 0`):
```
T[CLK_slave_last]
= T[last_edge] + t[prop_CLK_fall]                     [момент спаду останнього такту на вході веденого]
```
де `t[prop_CLK_fall] = t[d_spi] + t[PHL_CLK] + t[f_RC_CLK] + t[flight]`.

Момент підйому CS на веденому:
```
T[CS_slave_deactive]
= T[last_edge] + t[CSH_master] + t[prop_CS_rise]      [момент підйому CS на вході веденого]
```
де `t[prop_CS_rise] = t[d_gpio] + t[PLH_CS] + t[r_RC_CS] + t[flight]`.

Ефективний час утримання на веденому:

```
t[CSH_eff]
= T[CS_slave_deactive] - T[CLK_slave_last]            [інтервал від кінця такту до підйому CS]
= t[CSH_master] + (t[prop_CS_rise] - t[prop_CLK_fall])[групування складових затримок]
= t[CSH_master] + (t[PLH_CS] - t[PHL_CLK]) + (t[r_RC_CS] - t[f_RC_CLK]) [розгорнутий вираз ефективного часу утримання]
```

Критерій коректності:
```
t[CSH_eff] ≥ t[CSH_min_datasheet]                     [паспортна вимога веденого]
```

### Виведення формули відновлення між транзакціями (t_CS_HIGH_eff)

Нехай ведучий завершив першу транзакцію у момент `T[1]`, піднявши CS, і почав наступну транзакцію у момент `T[2]`, опустивши CS. Інтервал паузи на виході ведучого становить `t[CS_HIGH_master] = T[2] - T[1]`.

Момент деактивації (підйому напруги вище `0.7 · V[DD]`) на веденому:
```
T[slave_idle_start]
= T[1] + t[prop_CS_rise]                              [початок неактивного стану на веденому]
```

Момент повторної активації (спаду напруги нижче `0.3 · V[DD]`) на веденому:
```
T[slave_idle_end]
= T[2] + t[prop_CS_fall]                              [кінець неактивного стану на веденому]
```

Ефективний час паузи, протягом якого лінія CS на веденому безперервно утримується у високому рівні:

```
t[CS_HIGH_eff]
= T[slave_idle_end] - T[slave_idle_start]             [тривалість високого рівня на веденому]
= (T[2] + t[prop_CS_fall]) - (T[1] + t[prop_CS_rise]) [підстановка абсолютних моментів]
= (T[2] - T[1]) + (t[prop_CS_fall] - t[prop_CS_rise]) [групування інтервалу ведучого та затримок]
= t[CS_HIGH_master] - (t[prop_CS_rise] - t[prop_CS_fall]) [ефективна пауза CS High]
```

### Температурний дрейф та фазовий джиттер тактового генератора

Часові параметри напівпровідникових оптопар та цифрових буферів мають виражену залежність від температури кристала. При зростанні температури від кімнатної (+25 °C) до максимальної робочої (+85 °C):
* Рухливість носіїв заряду в кремнії падає, що збільшує опір каналів польових транзисторів `R[on]`.
* Час вимкнення світлодіода та фототранзистора оптопари зростає з температурним коефіцієнтом `α[T] ≈ +0.7% / °C`.

Затримка перемикання оптопари при температурі `T = 85 °C`:

```
t[PHL](85°C)
= t[PHL](25°C) · (1 + α[T] · (85 - 25))               [формула лінійного температурного дрейфу]
= 75.0 · (1 + 0.007 · 60)                             [підстановка номіналу 75 нс та різниці 60 градусів]
= 75.0 · (1 + 0.42)                                   [множення коефіцієнта]
= 75.0 · 1.42                                         [підсумок у дужках]
= 106.5 нс                                            [зростання затримки на 42%]
```

Крім того, на високих частотах передачі (понад 25–50 МГц) тактовий сигнал SCLK формується внутрішніми помножувачами частоти PLL (Phase-Locked Loop). Вихідний сигнал PLL характеризується фазовим джиттером `t[jitter_pk_pk]` та відхиленням коефіцієнта заповнення (Duty Cycle Distortion, DCD) від ідеальних 50%:

```
D = t[high] / T[SCK] = 0.50 ± ΔD
```

де `ΔD` становить зазвичай від 3% до 7% залежно від дільника шини APB.

Тривалість першого півперіоду такту SCLK при найгіршому стисненні:
```
t[high_min]
= (0.50 - ΔD) · T[SCK] - t[jitter_pk_pk] / 2          [мінімальна тривалість активної фази такту]
```

Якщо в режимах CPHA = 0 ведучий прив'язує момент генерації першого такту до таймера шини, джиттер PLL може змістити перший активний перепад SCLK вліво на величину `t[jitter_pk_pk] / 2`.
Повний часовий бюджет із запасом на джиттер та температуру набуває вигляду:

```
t[CSS_master_guaranteed]
= t[CSS_min_datasheet] + Δt[skew_iso] + t[jitter_pk_pk] / 2 + t[margin_temp] [бюджет встановлення з урахуванням джиттера]
```

### Практичний наскрізний розрахунок для ізольованого вузла Flash-пам'яті

Розглянемо реальну схему промислового вимірювача:
* **Ведучий**: STM32F407 (тактова частота шини SPI `f[SCK] = 10 МГц`, період `T[SCK] = 100 нс`, тривалість півперіоду `t[half] = 50 нс`).
* **Гальванічна розв'язка**: швидкодіючі оптопари 6N137 з відкритим колектором та резисторами підтяжки `R[pullup] = 1 кОм` до `V[DD] = 3.3 В`.
* **Ведений пристрій**: Flash-пам'ять Winbond W25Q128JV (`V[DD] = 3.3 В`).
* **Параметри монтажу**: довжина доріжок `l = 150 мм`, ємність лінії з урахуванням виводів `C[L] = 45 пФ`.

#### 1. Паспортні часові обмеження компонентів

Параметри оптопари 6N137 при `R[pullup] = 1 кОм`, `T = 25 °C`:
* Час перемикання у низький рівень (LED увімкнено, транзистор відкрився): `t[PHL_min] = 25 нс`, `t[PHL_typ] = 45 нс`, `t[PHL_max] = 75 нс`.
* Час перемикання у високий рівень (LED вимкнено, розряд через підтяжку): `t[PLH_min] = 35 нс`, `t[PLH_typ] = 65 нс`, `t[PLH_max] = 100 нс`.
* Опір відкритого транзистора оптопари: `R[on] ≈ 15 Ом`.

Параметри пам'яті W25Q128JV:
* `t[CSS_min] = 5.0 нс`.
* `t[CSH_min] = 5.0 нс`.
* `t[CS_HIGH_min] = 10.0 нс` (для читання) та `50.0 нс` (для команд запису).

#### 2. Покроковий розрахунок перехідних процесів RC

Розрахуємо час спаду напруги на лінії при відкриванні транзистора оптопари:

```
t[f_RC]
= 1.2 · R[on] · C[L]                                  [час розряду ємності через відкритий канал]
= 1.2 · 15 · 45 · 10⁻¹²                               [підстановка значень R=15 Ом, C=45 пФ]
= 8.1 · 10⁻¹⁰ с                                       [обчислення добутку]
≈ 0.81 нс                                             [переведення у наносекунди]
```

Розрахуємо час наростання напруги на лінії при закриванні транзистора (заряд через підтяжку 1 кОм до рівня `0.7 · V[DD]`):

```
ln(1 / (1 - 0.7))
= ln(1 / 0.3)                                         [підстановка V[IH_min] = 0.7 · V[DD]]
= ln(3.333)                                           [ділення: 1 / 0.3 = 3.333]
≈ 1.204                                               [обчислення натурального логарифма]

t[r_RC]
= 1.204 · R[pullup] · C[L]                            [формула експоненціального заряду до 0.7 V_DD]
= 1.204 · 1000 · 45 · 10⁻¹²                           [підстановка R=1000 Ом, C=45 пФ]
= 5.418 · 10⁻⁸ с                                      [обчислення добутку]
≈ 54.2 нс                                             [переведення у наносекунди]
```

#### 3. Розрахунок найгіршого випадку для часу встановлення t_CSS

Для аналізу надійності беремо найгіршу комбінацію затримок: спад CS поширюється найповільніше (`t[PHL_max]`), а наростання SCLK — найшвидше (`t[PLH_min]`):

```
t[prop_CS_fall_max]
= t[PHL_max] + t[f_RC] + t[flight]                    [максимальна затримка спадного фронту CS]
= 75.0 + 0.81 + 0.82                                  [підстановка значень оптопари, RC та прольоту хвилі]
= 76.63 нс                                            [результат максимальної затримки CS]

t[prop_CLK_rise_min]
= t[PLH_min] + t[r_RC] + t[flight]                    [мінімальна затримка наростаючого фронту SCLK]
= 35.0 + 54.2 + 0.82                                  [підстановка значень оптопари, RC та прольоту]
= 90.02 нс                                            [результат мінімальної затримки SCLK]
```

Різниця затримок між каналами:

```
Δt[margin_setup]
= t[prop_CLK_rise_min] - t[prop_CS_fall_max]          [запас затримки завдяки повільному такту]
= 90.02 - 76.63                                       [віднімання затримок]
= 13.39 нс                                            [позитивний часовий зсув каналів]
```

Якщо ведучий стартує SCLK безпосередньо після опускання CS (`t[CSS_master] = 0`), ефективний час встановлення на вході Flash-пам'яті:

```
t[CSS_eff]
= 0 + 13.39                                           [підстановка у формулу ефективного t_CSS]
= 13.39 нс                                            [ефективний інтервал встановлення]
```

Оскільки `13.39 нс ≥ 5.0 нс` (`t[CSS_min]`), умова виконується. Проте запас складає лише `13.39 - 5.0 = 8.39 нс`. Якщо при підвищенні температури час перемикання оптопари CS збільшиться ще на 10 нс, виникне збій прийому першого біта.

#### 4. Розрахунок найгіршого випадку для часу відновлення t_CS_HIGH

Розрахуємо затримку наростання CS при деактивації (`t[prop_CS_rise_max]`) та затримку спаду CS при наступній активації (`t[prop_CS_fall_min]`):

```
t[prop_CS_rise_max]
= t[PLH_max] + t[r_RC] + t[flight]                    [максимальна затримка наростаючого фронту CS]
= 100.0 + 54.2 + 0.82                                 [підстановка максимальних паспортних значень]
= 155.02 нс                                           [підсумок затримки підйому CS]

t[prop_CS_fall_min]
= t[PHL_min] + t[f_RC] + t[flight]                    [мінімальна затримка спадного фронту CS]
= 25.0 + 0.81 + 0.82                                  [підстановка мінімальних паспортних значень]
= 26.63 нс                                            [підсумок затримки спаду CS]
```

Знайдемо часове стиснення паузи між транзакціями:

```
Δt[loss_high]
= t[prop_CS_rise_max] - t[prop_CS_fall_min]           [величина скорочення паузи CS High на веденому]
= 155.02 - 26.63                                      [віднімання значень]
= 128.39 нс                                           [втрата тривалості високого стану]
```

Якщо програма мікроконтролера зробить паузу між транзакціями `t[CS_HIGH_master] = 50.0 нс`, реальний час високого стану на вході Flash-пам'яті становитиме:

```
t[CS_HIGH_eff]
= 50.0 - 128.39                                       [розрахунок ефективної паузи на веденому]
= -78.39 нс                                           [від'ємне значення: лінія не досягає порогу 0.7 V_DD]
```

Від'ємне значення означає катастрофічну помилку: лінія CS на вході пам'яті взагалі не встигає піднятися вище порогу `V[IH_min] = 2.31 В`! Мікросхема Flash сприймає дві послідовні транзакції як одну нерозривну команду, що призводить до повного зависання інтерфейсу обміну.

#### 5. Розрахунок необхідної програмної затримки для мікроконтролера

Щоб гарантувати паспортний час відновлення `t[CS_HIGH_min] = 50.0 нс` для операцій запису Flash-пам'яті, ведучий повинен витримувати програмну паузу:

```
t[CS_HIGH_master_min]
= t[CS_HIGH_min] + Δt[loss_high] + t[margin_safety]   [формула розрахунку безпечної програмної паузи]
= 50.0 + 128.39 + 30.0                                [підстановка з урахуванням запасу безпеки 30 нс]
= 208.39 нс                                           [мінімальний інтервал CS High на боці ведучого]
```

Для мікроконтролера STM32F4 з тактовою частотою ядра `f[CPU] = 168 МГц` (період такту інструкції `t[cyc] = 1 / 168 · 10⁶ ≈ 5.95 нс`):

```
N[nop]
= 208.39 / 5.95                                       [кількість тактів процесора]
≈ 35.02                                               [ділення]
= 36 тактів NOP                                       [округлення вгору до цілого числа]
```

### Вплив перехідних отворів (Vias) та розривів опорного шару

При переході сигнальних ліній CS та SCLK між шарами багатошарової друкованої плати кожен перехідний отвір додає паразитну індуктивність `L[via] ≈ 0.8–1.2 нГн` та паразитну ємність `C[via] ≈ 0.3–0.5 пФ`:
* Якщо лінія CS змінює шар, а земляний шар розривається без встановлення поруч заземлювального перехідного отвору (*Ground Return Via*), зворотний струм високої частоти змушений обтікати розрив по довгому контуру.
* Це створює спільну індуктивність зворотного зв'язку (*Ground Bounce*), що генерує паразитний імпульс амплітудою до 0.5–0.8 В на сусідніх лініях вибору кристала в момент перемикання такту SCLK.
* Для запобігання хибному спрацьовуванню ведених усі лінії CS слід розводити над єдиним суцільним полігоном землі, розміщуючи зшивальні перехідні отвори на відстані не більше 1 мм від кожного сигнального переходу.

### Підсумкова таблиця правил проєктування швидкісних ліній CS

| Вузол схеми | Потенційний дефект | Інженерний розрахунок і спосіб захисту |
| :--- | :--- | :--- |
| **Оптоізолятор з відкритим колектором** | Повільне наростання `t[r]`, зрізання `t[CS_HIGH]` | Зменшити `R[pullup]` до 470–1000 Ом або замінити на цифровий ізолятор (Si864x, ISO774x). |
| **Довгий плоский шлейф (>20 см)** | Висока ємність `C[L] > 100 пФ`, дзвін ліній | Додати послідовні демпферні резистори 22–33 Ом біля виходів ведучого. |
| **Високочастотне ядро (>200 МГц)** | Занадто швидкий старт SCLK (`t[CSS] < 5 нс`) | Вставити від 4 до 10 інструкцій `__NOP()` між опусканням CS та увімкненням такту SPI. |
| **Потоковий запис у Flash/EEPROM** | Ігнорування внутрішнього циклу програмування | Витримувати `t[CS_HIGH] ≥ 50–100 нс` перед кожною новою командою запису. |
| **Мультиплексована шина (N > 4)** | Ємнісне завалювання фронтів SCLK відносно CS | Використовувати буферні повторювачі такту (Clock Drivers) або зіркові сплітери. |
| **Широкий температурний діапазон (−40...+85 °C)**| Зростання затримок оптопар на 40% при нагріванні | Закладати подвійний запас випередження `t[CSS_master] ≥ 2 · t[CSS_datasheet]`. |
