# ⚙️ Обчислення коефіцієнта укорочення, TDR-рефлектометрії та вирівнювання затримок трас

Ця вставка містить практичну програмну реалізацію алгоритму імпульсної рефлектометрії (Time-Domain Reflectometry, TDR) для локалізації пошкоджень кабелю за коефіцієнтом укорочення, а також розрахунок міжпровідникового часового зсуву (skew) та компенсаційного меандрування для високошвидкісних цифрових шин.

## 1. Фізичні принципи імпульсної рефлектометрії (TDR)

Метод імпульсної рефлектометрії у часовій області є основним високоточним інструментом діагностики кабельних ліній передачі та друкованих плат. Генератор рефлектометра подає в тестовану лінію надкороткий прямокутний або ґауссів перепад напруги з крутим фронтом.

Електромагнітна хвиля поширюється вздовж лінії з фазовою швидкістю, яка повністю визначається діелектричними властивостями ізоляційного матеріалу. Коли хвиля натрапляє на локальну неоднорідність хвильового імпедансу, у точці неоднорідності виникає відбита хвиля. Коефіцієнт відбиття за напругою визначається співвідношенням між хвильовим опором лінії та опором навантаження.

Форма та амплітуда відбитого імпульсу на екрані осцилографа точно вказують на фізичний характер пошкодження. При повному обриві кабелю коефіцієнт відбиття дорівнює плюс одиниці, тому відбита хвиля повертається з тією самою полярністю та амплітудою, подвоюючи рівень напруги на вихідних клемах. При короткому замиканні коефіцієнт відбиття дорівнює мінус одиниці, тому відбита хвиля повертається в протифазі й повністю обнуляє підсумкову напругу. У випадку паразитної ємності перехідного отвору формується від'ємний сплеск напруги з наступним експоненційним відновленням. При наявності паразитної індуктивності зрізу екрана формується позитивний вузький пік. Якщо лінія ідеально узгоджена, відбита хвиля повністю відсутня.

Відстань від джерела сигналу до точної локації пошкодження прямо пропорційна часовому інтервалу затримки між виходом первинного фронту та реєстрацією відбитого імпульсу. Дільник два у цій формулі відображає двосторонній шлях хвилі — від рефлектометра до пошкодження та назад. Помилка у значенні коефіцієнта укорочення призводить до пропорційної системної помилки обчислення відстані. Наприклад, помилка в заданні коефіцієнта укорочення всього на п'ять відсотків при довжині кабелю двісті метрів призведе до промаху локалізації пошкодження на десять метрів.

## 2. Математичне забезпечення вирівнювання затримок у друкованих платах

У сучасних високошвидкісних цифрових шинах параметри затримки сигналів вимірюються в пікосекундах. Наприклад, у паралельній шині пам'яті максимальний припустимий часовий розсинхронізм між стробувальним сигналом та паралельними лініями даних не повинен перевищувати п'ятнадцяти пікосекунд.

Оскільки погонна затримка поширення сигналу на одиницю довжини траси обчислюється як величина, обернена до швидкості хвилі, будь-яка геометрія різниці довжин двох паралельних трас неминуче викликає часовий розсинхронізм фронтів. Для повного усунення розсинхронізму коротку трасу штучно подовжують шляхом додавання компенсаційних меандрів. Фізична довжина додаткового меандру обчислюється як точна різниця геометричних довжин трас.

## 3. Зв'язок TDR з вимірюваннями у частотній області (S-параметри)

У сучасній вимірювальній техніці рефлектометрія у часовій області є дуальною до вимірювань вектора коефіцієнта відбиття у частотній області за допомогою векторного аналізатора кіл. Параметр матриці розсіювання S11 описує комплексний коефіцієнт відбиття, де фазовий зсув прямо пов'язаний з електричною довжиною лінії та фазовою швидкістю хвилі.

Шляхом застосування оберненого швидкого перетворення Фур'є до частотної залежності вимірювальний прилад відновлює часову рефлектограму. Це дозволяє розділити диференційну та спільну моди поширення хвилі в зв'язаних лініях, визначивши окремі коефіцієнти укорочення для диференційного сигналу та сигналу спільної моди.

Оскільки для диференційного сигналу силові лінії електричного поля концентруються між двома провідниками в товщі діелектрика, а для спільної моди частина поля виходить до зовнішнього заземленого шару, їх ефективні діелектричні проникності відрізняються. В результаті коефіцієнт укорочення для спільної моди виявляється вищим, що створює явище перетворення мод на неоднорідностях лінії.

```c
#include <stdio.h>
#include <stdbool.h>
#include <math.h>

#define C_VACUUM_MM_PS 0.299792458  /* швидкість світла в мм/пс */

typedef struct {
    double velocity_factor;  /* коефіцієнт укорочення (0.0..1.0) */
    double delta_t_ps;        /* час двостороннього пробігу імпульсу в пс */
} TdrInput;

typedef struct {
    double distance_mm;      /* обчислена відстань до пошкодження в мм */
    double propagation_delay;/* погонна затримка в пс/мм */
    bool is_valid;           /* прапорець коректності вхідних даних */
} TdrResult;

typedef struct {
    double length_diff_mm;   /* необхідна компенсаційна довжина меандру в мм */
    double time_skew_ps;     /* часовий зсув сигналів у пс */
} SkewResult;

/* Обчислення відстані до пошкодження методом TDR */
TdrResult calculate_tdr_fault(TdrInput input) {
    TdrResult res = {0.0, 0.0, false};
    if (input.velocity_factor <= 0.0 || input.velocity_factor > 1.0 || input.delta_t_ps < 0.0) {
        return res;
    }

    double v_signal = C_VACUUM_MM_PS * input.velocity_factor; /* швидкість у мм/пс */
    res.distance_mm = (v_signal * input.delta_t_ps) / 2.0;    /* двосторонній шлях */
    res.propagation_delay = 1.0 / v_signal;                   /* пс/мм */
    res.is_valid = true;
    return res;
}

/* Обчислення довжини компенсаційного меандру для вирівнювання трас */
SkewResult calculate_trace_skew(double len1_mm, double len2_mm, double vf) {
    SkewResult res = {0.0, 0.0};
    if (vf <= 0.0 || vf > 1.0) return res;

    double v_signal = C_VACUUM_MM_PS * vf;
    double t_pd = 1.0 / v_signal; /* пс/мм */

    double t1 = len1_mm * t_pd;
    double t2 = len2_mm * t_pd;

    res.time_skew_ps = fabs(t1 - t2);
    res.length_diff_mm = fabs(len1_mm - len2_mm);
    return res;
}

int main(void) {
    /* Приклад 1: Вимірювання кабелю RG-58 (VF = 0.66) за допомогою TDR */
    TdrInput cable_test = { .velocity_factor = 0.66, .delta_t_ps = 101010.0 }; /* 101.01 нс */
    TdrResult tdr_res = calculate_tdr_fault(cable_test);

    if (tdr_res.is_valid) {
        printf("--- TDR Рефлектометрія (C) ---\n");
        printf("Відстань до обриву: %.2f мм (%.3f м)\n", tdr_res.distance_mm, tdr_res.distance_mm / 1000.0);
        printf("Погонна затримка:   %.3f пс/мм (%.2f нс/м)\n", tdr_res.propagation_delay, tdr_res.propagation_delay);
    }

    /* Приклад 2: Вирівнювання трас шини DDR4 на платі FR-4 (VF = 0.55) */
    SkewResult skew = calculate_trace_skew(120.0, 135.0, 0.55);
    printf("\n--- Вирівнювання трас PCB (C) ---\n");
    printf("Часовий зсув сигналів: %.2f пс\n", skew.time_skew_ps);
    printf("Додати меандр довжиною:  %.2f мм\n", skew.length_diff_mm);

    return 0;
}
```

```cpp
#include <iostream>
#include <cmath>
#include <optional>
#include <format>

namespace rf_physics {

constexpr double C_VACUUM_MM_PS = 0.299792458; // Швидкість світла у мм/пс

struct TdrParams {
    double velocity_factor; // Коефіцієнт укорочення
    double delta_t_ps;      // Затримка відбитого імпульсу (пс)
};

struct TdrMeasurement {
    double distance_mm;       // Відстань до пошкодження
    double propagation_delay; // Погонна затримка (пс/мм)
};

struct TraceSkew {
    double time_skew_ps;    // Часовий розсинхронізм
    double meander_len_mm;  // Необхідна довжина меандру
};

class SignalVelocityCalculator {
public:
    // Обчислення параметрів TDR із використанням std::optional для обробки помилок
    [[nodiscard]] static std::optional<TdrMeasurement> compute_tdr(const TdrParams& params) noexcept {
        if (params.velocity_factor <= 0.0 || params.velocity_factor > 1.0 || params.delta_t_ps < 0.0) {
            return std::nullopt;
        }

        const double v_signal = C_VACUUM_MM_PS * params.velocity_factor;
        const double distance = (v_signal * params.delta_t_ps) / 2.0;
        const double t_pd = 1.0 / v_signal;

        return TdrMeasurement{ .distance_mm = distance, .propagation_delay = t_pd };
    }

    // Обчислення міжканального розсинхронізму трас
    [[nodiscard]] static std::optional<TraceSkew> compute_skew(double len1_mm, double len2_mm, double vf) noexcept {
        if (vf <= 0.0 || vf > 1.0 || len1_mm < 0.0 || len2_mm < 0.0) {
            return std::nullopt;
        }

        const double v_signal = C_VACUUM_MM_PS * vf;
        const double t_pd = 1.0 / v_signal;
        const double skew = std::abs(len1_mm - len2_mm) * t_pd;
        const double diff_len = std::abs(len1_mm - len2_mm);

        return TraceSkew{ .time_skew_ps = skew, .meander_len_mm = diff_len };
    }
};

} // namespace rf_physics

int main() {
    using namespace rf_physics;

    // Приклад TDR-вимірювання коаксіального кабелю RG-58 (VF = 0.66)
    constexpr TdrParams cable_params{ .velocity_factor = 0.66, .delta_t_ps = 101010.0 };
    if (const auto res = SignalVelocityCalculator::compute_tdr(cable_params)) {
        std::cout << "--- TDR Рефлектометрія (C++) ---\n";
        std::cout << "Відстань до обриву: " << res->distance_mm / 1000.0 << " м\n";
        std::cout << "Погонна затримка:   " << res->propagation_delay << " пс/мм\n";
    }

    // Приклад вирівнювання трас на платі FR-4 (VF = 0.55)
    if (const auto skew = SignalVelocityCalculator::compute_skew(120.0, 135.0, 0.55)) {
        std::cout << "\n--- Вирівнювання трас (C++) ---\n";
        std::cout << "Часовий зсув:       " << skew->time_skew_ps << " пс\n";
        std::cout << "Довжина меандру:    " << skew->meander_len_mm << " мм\n";
    }

    return 0;
}
```

```py
from dataclasses import dataclass
from typing import Optional
import math

C_VACUUM_MM_PS: float = 0.299792458  # швидкість світла у мм/пс


@dataclass(frozen=True)
class TdrMeasurement:
    distance_mm: float
    propagation_delay_ps_mm: float


@dataclass(frozen=True)
class TraceSkew:
    time_skew_ps: float
    meander_length_mm: float


def calculate_tdr(velocity_factor: float, delta_t_ps: float) -> Optional[TdrMeasurement]:
    """Обчислює відстань до місця обриву кабелю методом TDR."""
    if not (0.0 < velocity_factor <= 1.0) or delta_t_ps < 0:
        return None

    v_signal = C_VACUUM_MM_PS * velocity_factor
    distance = (v_signal * delta_t_ps) / 2.0
    t_pd = 1.0 / v_signal

    return TdrMeasurement(distance_mm=distance, propagation_delay_ps_mm=t_pd)


def calculate_skew(len1_mm: float, len2_mm: float, velocity_factor: float) -> Optional[TraceSkew]:
    """Обчислює розсинхронізм між двома трасами та довжину компенсаційного меандру."""
    if not (0.0 < velocity_factor <= 1.0) or len1_mm < 0 or len2_mm < 0:
        return None

    v_signal = C_VACUUM_MM_PS * velocity_factor
    t_pd = 1.0 / v_signal
    diff_len = abs(len1_mm - len2_mm)
    skew = diff_len * t_pd

    return TraceSkew(time_skew_ps=skew, meander_length_mm=diff_len)


if __name__ == "__main__":
    # Тест TDR для кабелю з VF = 0.66
    tdr_res = calculate_tdr(velocity_factor=0.66, delta_t_ps=101010.0)
    if tdr_res:
        print(f"--- TDR Рефлектометрія (Python) ---")
        print(f"Відстань до пошкодження: {tdr_res.distance_mm / 1000.0:.3f} м")
        print(f"Погонна затримка:        {tdr_res.propagation_delay_ps_mm:.3f} пс/мм")

    # Тест вирівнювання трас на FR-4 (VF = 0.55)
    skew_res = calculate_skew(len1_mm=120.0, len2_mm=135.0, velocity_factor=0.55)
    if skew_res:
        print(f"\n--- Вирівнювання трас PCB ---")
        print(f"Часовий зсув:            {skew_res.time_skew_ps:.2f} пс")
        print(f"Компенсаційний меандр:   {skew_res.meander_length_mm:.2f} мм")
```

## 6. Детальний аналіз інженерних пасток та практичних edge cases

Під час практичної розробки надвисокочастотних пристроїв, вимірювань TDR та трасування високошвидкісних друкованих плат інженери зіштовхуються з п'ятьма типовими проблемами, пов'язаними з коефіцієнтом укорочення.

У реальних діелектриках із втратами діелектрична проникність не є ідеальною константою, а падає зі зростанням частоти. В результаті високоелементні спектральні компоненти фронту імпульсу рухаються з трохи більшою фазовою швидкістю, але зазнають набагато сильнішого згасання. При поширенні вздовж довгого кабелю крутий фронт нарастання імпульсу поступово розмивається, перетворюючись на похилу криву. Це ускладнює точну фіксацію моменту приходу відбитого сигналу. Для усунення помилки сучасні цифрові рефлектометри застосовують вимірювання за точкою п'ятдесяти відсотків амплітуди фронту або математичне відновлення сигналу за допомогою оберненого перетворення Фур'є.

Діелектрична проникність більшості полімерних ізоляторів залежить від температури через зміну густини матеріалу та тепловий рух молекул. Для суцільного поліетилену температурний коефіцієнт є суттєво від'ємним. Якщо коаксіальний фідер антени або підземний кабель зв'язку зазнає сезонних коливань температури від мінус тридцяти до плюс п'ятдесяти градусів, діелектрична проникність змінюється більш ніж на два відсотки. Це викликає зміщення фазового коефіцієнта укорочення та зміну затримки сигналу. У прецизійних системах фазованих антенних решіток така дефазировка розфокусує промінь антени, тому там використовують спеціальні кабелі з діелектриком із мікропористого фторопласту зі збалансованим температурним коефіцієнтом.

При розрахунку мікросмужкових ліній на зовнішніх шарах друкованої плати розробники часто використовують базову формулу Шнайдера для межі між діелектриком та повітрям. Проте після виготовлення плата покривається шаром захисної паяльної маски з високою діелектричною проникністю. Оскільки маска покриває провідник у зоні найбільшої концентрації крайового електричного поля, вона додатково витісняє повітря, піднімаючи ефективну діелектричну проникність. В результаті реальна затримка сигналу виявляється більшою, а коефіцієнт укорочення — нижчим за розрахований. На високочастотних платах траси розраховують із обов'язковим урахуванням товщини та проникності маски або видаляють маску над лініями.

Матеріал склотекстоліту є композитом, що складається зі сплетеного скловолокна та заповнювача з епоксидної смоли. На мікроскопічному рівні діелектрик є глибоко неоднорідним. Якщо провідники диференційної пари розраховані паралельно ниткам плетіння, одна траса може повністю проходити над скляною ниткою, а друга — над кишенею з епоксидної смоли. Це створює постійний міжканальний розсинхронізм, що призводить до руйнування диференційного сигналу на частотах понад десять гігагерц. Для вирішення проблеми траси розводять під кутом до сітки плати або застосовують матеріали з розплавленим складовим плетінням.

При використанні додаткових вигинів меандрів для вирівнювання довжин трас слід пам'ятати: якщо відстань між сусідніми паралельними сегментами меандру менша за потрійну ширину траси, між ними виникає сильний зв'язок через паразитивну ємність і взаємну індуктивність. Високочастотні компоненти сигналу частково проскочують через паразитивну ємність між вигинами, не проходячи повну геометричну довжину меандру. В результаті реальна затримка меандрованої траси виявляється меншою за розраховану за геометричною довжиною. Щоб меандр давав повну затримку, крок вигинів роблять розрядженим, а висоту меандру обмежують.

## 7. Методологія калібрування VF за допомогою еталонного відрізка

Коли реальне значення коефіцієнта укорочення матеріалу або кабелю невідоме (наприклад, для нової партії сурогатного діелектрика чи складного гнучко-жорсткого стека друкованої плати), використовують метод експериментального калібрування за еталонним відрізком.

Процедура складається з чотирьох послідовних кроків. Спочатку відрізають зразок кабелю або виготовляють тестову трасу точно виміряної геометричної довжини. Далі підключають один кінець зразка до рефлектометра TDR, залишаючи протилежний кінець повністю відкритим для одержання стовідсоткового відбиття позитивної полярності. Після цього вимірюють часовий інтервал двостороннього пробігу імпульсу між зондувальним та відбитим фронтами. На завершення обчислюють точний практичний коефіцієнт укорочення для даного матеріалу. Одержане калібрувальне значення вводять у рефлектометр або програмний модуль аналізу перед виконанням робочих вимірювань всієї протяжної лінії.

## 8. Інтеграція алгоритму з сучасними САПР друкованих плат

Сучасні системи автоматизованого проектування друкованих плат використовують поданий алгоритм вирівнювання затримок у реальному часі під час інтерактивного трасування шин.

Користувач визначає в правилах проектування групу сигналів та задає максимальний припустимий часовий розсинхронізм у пікосекундах. САПР автоматично опитує діелектричний стек плати, розраховує ефективну діелектричну проникність для кожного шару та обчислює точний коефіцієнт укорочення. Під час руху миші трасувальника САПР динамічно підраховує поточну затримку та автоматично генерує згладжені меандри потрібної амплітуди та кроку, підсвічуючи зеленим кольором момент досягнення точного балансу затримок між усіма лініями шини.

## 9. Застосування в оптичних лінійних рефлектометрах (OTDR)

Описані алгоритми обчислення затримки та калібрування коефіцієнта укорочення повністю застосовні також в оптичних імпульсних рефлектометрах, які використовують світлові імпульси замість електричних.

В оптичних волокнах роль коефіцієнта укорочення виконує величина, обернена до ефективного показника заломлення серцевини волокна. Оптичний рефлектометр посилає лазерний імпульс тривалістю в кілька наносекунд та реєструє бреґґівське зворотне релейовське розсіяння світла на неоднорідностях скла. Обчислення відстані до обриву або зварного з'єднання волокна виконується за аналогічною математичною формулою двостороннього пробігу.

## 10. Практична оптимізація обчислень для вбудованих DSP та FPGA

При реалізації рефлектометрії у високошвидкісних приладах на базі цифрових сигнальних процесорів або ПЛІС математичне ділення замінюють множенням на заздалегідь обчислену обернену константу.

Замість виконання операцій ділення з плаваючою комою у кожному циклі збору даних, процесор заздалегідь обчислює інваріантний масштабний коефіцієнт швидкості у формі числового множника з фіксованою комою. Це дозволяє обробляти мільйони відліків рефлектограми за секунду, забезпечуючи миттєве оновлення графіка на екрані портативного приладу без затримок.
