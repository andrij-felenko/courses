# 📋 Довідник діелектричних матеріалів, коефіцієнтів укорочення та ліній передачі

Цей довідник містить комплексний систематизований масив інженерних даних, необхідних для розрахунку фазової швидкості, затримок сигналів, геометричного укорочення антен та хвильового імпедансу ліній передачі. Документ об'єднує фізичні характеристики класичних діелектриків, електродинамічні параметри радіочастотних коаксіальних кабелів, властивості НВЧ-субстратів друкованих плат, а також канонічні розрахункові формули та лабораторні методики вимірювання.

## 1. Класифікація та фундаментальні характеристики діелектричних середовищ

Електродинамічна поведінка будь-якого діелектрика у високочастотному електромагнітному полі визначається трьома основними параметрами: відносною діелектричною проникністю, тангенсом кута діелектричних втрат та температурним коефіцієнтом проникності.

Діелектрична проникність описує ступінь поляризації речовини під дією зовнішнього електричного поля і прямо визначає коефіцієнт укорочення. Чим вища проникність матеріалу, тим сильніше орієнтуються диполі середовища, створюючи протидіючу вторинну хвилю, і тим повільніше поширюється електромагнітне збурення. Тангенс кута втрат характеризує частку електромагнітної енергії, яка неповоротно перетворюється на джоулеве тепло через в'язке гальмування диполів та струми витоку. Температурний коефіцієнт відображає зміну проникності при нагріванні матеріалу внаслідок розширення матриці та посилення теплового хаотичного руху атомів.

## 2. Параметри та специфікації промислових коаксіальних кабелів

Коаксіальний кабель є найбільш розповсюдженим різновидом замкненої лінії передачі з суцільним поперечним електромагнітним режимом. Хвильовий опір кабелю визначається геометрією провідників та діелектричною проникністю ізолятора, а фазова швидкість залежить виключно від діелектрика.

У радіочастотній інженерії виділяють два стандартні номінали хвильового опору. П'ятдесятиомні кабелі застосовуються в системних трансиверах, радіолокації, вимірювальних приладах та антенних фідерах передавачів, оскільки опір п'ятдесят Ом забезпечує оптимальний компроміс між максимальною електричною міцністю на пробій та мінімальним згасанням. Сімдесятип'ятиомні кабелі є стандартом для кабельного телебачення, супутникових приймачів та відеосистем, оскільки опір сімдесят п'ять Ом гарантує абсолютний мінімум високочастотного згасання у коаксіалі з повітряним чи спіненим діелектриком.

## 3. Матеріали та субстрати друкованих плат (PCB Laminates)

У конструкції сучасних високошвидкісних цифрових систем та надвисокочастотних модулів діелектричний ламінат друкованої плати є повноцінним компонентом схеми. Нестабільність діелектричної проникності ламінату призводить до розбалансування хвильового опору, виникнення паразитного міжпровідникового розсинхронізму та викривлення прямокутних імпульсів.

Стандартний склотекстоліт марки FR-4, що складається зі склотканини та епоксидної смоли, є чудовим дешевим матеріалом для низькочастотної електроніки, але має високий тангенс втрат та нестабільну діелектричну проникність на частотах понад один гігагерц. Для високошвидкісних ліній даних застосовують спеціалізовані НВЧ-ламінати на основі термореактивних смол або фторопласту.

## 4. Зведена шпаргалка розрахункових формул

Нижче систематизовано ключові математичні співвідношення, що використовуються при проектному розрахунку ліній передачі, антенних елементів та імпульсних затримувачів.

### 4.1. Основні співвідношення швидкості та затримки

```
1. Фазова швидкість у діелектрику:
   v = c / √(ε[r] · μ[r])              [м/с]

2. Коефіцієнт укорочення (Velocity Factor):
   VF = v / c = 1 / √(ε[r] · μ[r])     [безрозмірний, 0.0..1.0]

3. Довжина хвилі в діелектрику:
   λ = λ₀ · VF = (c · VF) / f         [м]

4. Погонна часова затримка (Propagation Delay):
   t[pd] = 1 / v = 1 / (c · VF)       [нс/м або пс/мм]
   t[pd] = 3.3356 · √(ε[eff])          [пс/мм]

5. Час проходження лінії довжиною L:
   T[delay] = L · t[pd] = L / (c · VF) [с або пс]
```

### 4.2. Розрахунок геометрії ліній передачі

```
1. Коаксіальний кабель (суцільний діелектрик ε[r]):
   ε[eff] = ε[r]
   VF = 1 / √(ε[r])
   Z₀ = (60 / √(ε[r])) · ln(b / a)     [Ом]

2. Замкнена смужкова лінія (Stripline):
   ε[eff] = ε[r]
   VF = 1 / √(ε[r])
   Z₀ = (60 / √(ε[r])) · ln((4 · h) / (π · w[eff]))  [Ом]

3. Відкрита мікросмужкова лінія (Microstrip, w/h ≥ 1):
   ε[eff] = ((ε[r] + 1) / 2) + ((ε[r] − 1) / 2) · (1 / √(1 + 12 · (h / w)))
   VF = 1 / √(ε[eff])
   Z₀ = (87 / √(ε[eff] + 1.41)) · ln((5.98 · h) / (0.8 · w + t))  [Ом]

4. Двопровідна повітряна лінія (Twin-Lead):
   ε[eff] ≈ 1.0...1.1
   VF ≈ 0.95...0.98
   Z₀ = 276 · lg(2 · D / d)            [Ом]
```

### 4.3. Прикладні інженерні формули

```
1. Фізична довжина чвертьхвильового резонатора (λ/4-шлейф):
   L[λ/4] = (c · VF) / (4 · f)         [м]

2. Відстань до пошкодження в рефлектометрії TDR:
   d = (c · VF · ΔT) / 2               [м]

3. Міжканальний розсинхронізм (Skew) між двома трасами L₁ та L₂:
   ΔT[skew] = |L₁ − L₂| · t[pd] = |L₁ − L₂| · (√(ε[eff]) / c)  [пс]

4. Відносна помилка вимірювання TDR при хибному VF:
   Error(%) = ((VF[set] − VF[actual]) / VF[actual]) · 100%
```

## 5. Практична методологія вимірювання VF у лабораторних умовах

Для експериментального визначення невідомого коефіцієнта укорочення кабелю або сурогатного діелектрика в лабораторній практиці застосовують три класичні методики.

Перша методика базується на імпульсній рефлектометрії у часовій області. Підключають один кінець відрізка кабелю точно виміряної фізичної довжини до рефлектометра, залишаючи другий кінець відкритим. Вимірюють часовий інтервал між зондувальним та відбитим імпульсом, після чого обчислюють коефіцієнт укорочення за формулою подвійного пробігу.

Друга методика спирається на вимірювання четвертьхвильового резонансу за допомогою векторного аналізатора кіл. Підключають відрізок кабелю як замкнений шлейф і знаходять першу частоту мінімуму коефіцієнта відбиття, що відповідає чверті довжини хвилі у діелектрику.

Третя методика використовує вимірювання фазового зсуву трансівера. За допомогою двоканального осцилографа порівнюють фази синусоїдального сигналу на вході та виході кабелю відомої довжини, обчислюючи точну фазову швидкість.

Ці довідкові дані та математичний апарат забезпечують повний інженерний розрахунок НВЧ-пристроїв, високих частот зв'язку та прецизійних цифрових інтерфейсів.
