# 🧮 Математичний апарат розрахунку бюджету радіолінії

Бюджет радіолінії (*Link Budget*) є математичним виразом закону збереження енергії для радіохвилі, яка поширюється від генератора передавача до демодулятора приймача. 

Усі рівняння балансу розраховуються у **логарифмічній формі (децибелах, дБ)**, що дозволяє замінити множення та ділення фізичних потужностей на просте додавання підсилень та віднімання втрат.

---

## 1. Рівняння балансу прийнятої потужності

Основне рівняння радіолінії визначає рівень потужності високочастотного сигналу `P_RX` (у dBm або dBW) безпосередньо на вхідному роз'ємі приймача:

```
P_RX = P_TX - L_tx + G_TX - FSPL - L_atm - L_rain - L_fade - L_misc + G_RX - L_rx
```

Де використано наступні фізичні величини:

- `P_TX` — вихідна потужність передавача (dBm). `P(dBm) = 10 · log10( P(mW) / 1 mW )`.
- `L_tx` — втрати в кабелі, фідері та з'єднувачах передавача (dB, додатня величина).
- `G_TX` — коефіцієнт підсилення передавальної антени відносно ізотропного випромінювача (dBi).
- `FSPL` — втрати поширення у вільному просторі (Free Space Path Loss, dB).
- `L_atm` — згасання сигналу в атмосферних газах (кисень, водяна пара, dB).
- `L_rain` — додаткове згасання в опадах (дощ, туман, сніг, dB).
- `L_fade` — запас на дрібномасштабні інтерференційні завмирання (Fading Margin, dB).
- `L_misc` — додаткові технічні втрати (разом: розузгодження поляризації, розстроювання частоти, втрати в радомі, dB).
- `G_RX` — коефіцієнт підсилення приймальної антени (dBi).
- `L_rx` — втрати у фідерному тракті приймача (dB).

## 2. Еквівалентна ізотропно-випромінювана потужність (EIRP) та апертура антени

Комбінація вихідної потужності передавача, фідерних втрат та підсилення антени формує **EIRP** (*Equivalent Isotropically Radiated Power*) — ефективну потужність, яку мав би випромінювати ідеальний ізотропний випромінювач для створення такої ж густини потоку потужності в напрямку головного пелюстка:

```
EIRP = P_TX - L_tx + G_TX   [dBm]
```

Зв'язок між коефіцієнтом підсилення антени `G` та її ефективною площею апертури `A_e` виражається математичною формулою:

```
A_e = ( λ² · G ) / ( 4 · π )   [м²]
```

Де `λ = c / f` — довжина хвилі. У логарифмічній формі ефективна апертура дозволяє обчислити потужність сигналу `P_RX`, перехоплену приймальною антеною від густини потоку потужності `S` (Вт/м²):

```
P_RX(Вт) = S · A_e
```

Якщо підсилення антени вказано відносно півхвильового диполя (dBd), перерахунок у dBi здійснюється додаванням constant-зсуву:

```
G(dBi) = G(dBd) + 2.15 dB
```

Загальна сума втрат у трасі між випромінювальною та приймальною антенами позначається як `L_path`:

```
L_path = FSPL + L_atm + L_rain + L_fade + L_misc   [dB]
```

Тоді рівняння прийнятої потужності спрощується до вигляду:

```
P_RX = EIRP - L_path + G_RX - L_rx   [dBm]
```

## 3. Математика втрат у вільному просторі (FSPL)

Згідно з формулою Фрііса, у вільному просторі щільність енергії спадає обернено пропорційно квадрату відстані `d²` через сферичне розходження хвильового фронту. Втрати `FSPL` у лінійних величинах виражаються як:

```
FSPL_linear = ( (4 · π · d) / λ )² = ( (4 · π · f · d) / c )²
```

Де `c ≈ 3·10⁸ м/с` — швидкість світла у вакуумі, `f` — частота сигналу в герцах, `d` — відстань у метрах, `λ = c / f` — довжина хвилі.

Переходячи до логарифмічного масштабу та підставляючи фізичні константи, отримуємо практичні формули для обчислень:

### Варіант 1: Відстань у кілометрах (км), частота у мегагерцах (МГц)
```
FSPL = 20·log10(d_km) + 20·log10(f_MHz) + 20·log10( (4·π·10³·10⁶) / (3·10⁸) )
FSPL = 20·log10(d_km) + 20·log10(f_MHz) + 32.44 dB
```

### Варіант 2: Відстань у кілометрах (км), частота у гігагерцах (ГГц)
```
FSPL = 20·log10(d_km) + 20·log10(f_GHz) + 92.45 dB
```

### Варіант 3: Відстань у метрах (м), частота у мегагерцах (МГц)
```
FSPL = 20·log10(d_m) + 20·log10(f_MHz) - 27.55 dB
```

## 4. Математика атмосферного поглинання та згасання в опадах

Окрім вільного простору, на високочастотний сигнал впливають молекулярні резонанси газів тропосфери та розсіювання на краплях води.

### 4.1. Згасання в атмосферних газах (ITU-R P.676)
Поглинання атмосферою `L_atm` обчислюється як інтеграл від питомого згасання `γ_a` (дБ/км) вздовж довжини траси `d`:

```
L_atm = ( γ_o + γ_w ) · d   [dB]
```

Де `γ_o` — питоме згасання в кисні, а `γ_w` — питоме згасання у водяній парі. 
На частоті **60 ГГц** спостерігається потужний резонанс молекули кисню `O₂`, де питоме згасання сягає `γ_o ≈ 15 dB/km`. Це робить діапазон 60 ГГц ідеальним для закритих кімнатних мереж (WiGig), оскільки сигнал не виходить за межі стін приміщення.

### 4.2. Згасання в дощі (ITU-R P.838)
Питоме згасання в опадах `γ_R` (дБ/км) описується степеневою залежністю від інтенсивності дощу `R` (мм/год):

```
γ_R = k · R ^ α   [dB/km]
```

Коефіцієнти `k` та `α` залежать від частоти сигналу, температури крапель та поляризації (вертикальна чи горизонтальна). Для частоти 15 ГГц при зливі з інтенсивністю `R = 50 мм/год` питоме згасання становить близько `γ_R ≈ 3.5 dB/km`, що додає `42 dB` втрат на 12-кілометровій трасі.

## 5. Фізика шуму та каскадна шумова температура

Щоб передача даних була можливою, прийнята потужність `P_RX` повинна перевищувати поріг чутливості приймача `P_sens`. 

Поріг чутливості визначається фундаментальним тепловим шумом середовища, смугою пропускання приймача, власними шумами електронних компонентів та вимогами конкретної схеми модуляції.

### 5.1. Спектральна щільність теплового шуму
Тепловий шум (шум Джонсона-Найквіста) створюється хаотичним рухом електронів у провідниках при температурі, відмінній від абсолютного нуля. Спектральна щільність потужності теплового шуму `N_0` виражається формулою:

```
N_0 = k_B · T   [Вт/Гц]
```

Де `k_B = 1.380649 · 10⁻²³ Дж/К` — стала Больцмана, `T` — абсолютна температура в кельвінах (стандартна еталонна температура кімнати `T_0 = 290 K`).

У логарифмічному вигляді для еталонної температури `290 K`:

```
N_0(dBm/Hz) = 10 · log10( (1.380649·10⁻²³ · 290) / 10⁻³ )
N_0(dBm/Hz) = -173.98 dBm/Hz  ≈  -174 dBm/Hz
```

### 5.2. Повна потужність теплового шуму приймача
Загальна потужність теплового шуму `N_th` в еквівалентній шумовій смузі приймача `B` (в Гц) дорівнює:

```
N_th = N_0 · B   [Вт]
N_th(dBm) = -174 dBm/Hz + 10 · log10( B_Hz )
```

Наприклад, для смуги `B = 1 МГц = 10⁶ Гц`:
```
N_th = -174 + 10·log10(10⁶) = -174 + 60 = -114 dBm
```

### 5.3. Каскадна формула шуму Фрііса для багатокаскадних приймачів
Приймальний тракт складається з декількох послідовних підсилювальних та змішувальних каскадів (LNA, бандпас-фільтр, змішувач, підсилювач ПЧ). Загальний коефіцієнт шуму `F_total` у лінійному масштабі обчислюється за каскадною формулою Фрііса:

```
F_total = F_1 + (F_2 - 1) / G_1 + (F_3 - 1) / (G_1 · G_2) + ...
```

Де `F_1, F_2, F_3` — лінійні коефіцієнти шуму каскадів, а `G_1, G_2` — лінійні коефіцієнти підсилення каскадів.

З цієї математичної залежності випливає фундаментальне правило радіоприймачів: **перший каскад (LNA) визначає 90% шумових характеристик всієї системи**. Якщо перший підсилювач має високе підсилення `G_1 >> 1` (наприклад, 20 дБ = 100 разів), то шуми наступних каскадів `(F_2 - 1) / 100` стають мізерно малими.

Коефіцієнт шуму в децибелах виражається через лінійний фактор як `N_F = 10 · log10(F_total)`.

## 6. Співвідношення E_b/N_0, SNR та гранична ємність Шеннона

Для декодування сигналу із заданою імовірністю бітової помилки (BER, *Bit Error Rate*) демодулятор вимагає мінімального відношення потужності сигналу до потужності шуму `SNR_min` (у dB).

Зв'язок між `SNR` та нормованим показником `E_b / N_0` визначається спектральною ефективністю модуляції (відношенням швидкості передачі даних `R` в біт/с до смуги частот `B` в Гц):

```
SNR = (E_b / N_0) · (R / B)
SNR(dB) = (E_b / N_0)(dB) + 10 · log10( R / B )
```

### Зв'язок із граничною ємністю Шеннона
Згідно з теоремою Шеннона-Хартлі, максимально можлива пропускна здатність каналу зв'язку `C` (у біт/с) обмежена шириною смуги `B` та співвідношенням сигнал/шум `SNR`:

```
C = B · log2( 1 + SNR_linear )
```

При гранично низьких рівнях `SNR << 1` (наприклад, у LoRa або супутниковому зв'язку) застосовується логарифмічне наближення `ln(1 + x) ≈ x`. Це дає абсолютну фундаментальну межу Шеннона для `E_b / N_0`:

```
(E_b / N_0)_min = ln(2) ≈ 0.693  =  -1.59 dB
```

Нічна система зв'язку у світі не може декодувати дані без помилок, якщо `E_b / N_0 < -1.59 dB`. Сучасні системи з кодами LDPC та Turbo наближаються до цієї межі на відстань `0.2–0.5 dB`.

## 7. Запас радіолінії (Link Margin, M) та логарифмічно-нормальне затінення

Запас лінії `M` (Link Margin) є різницею між реально прийнятою потужністю сигналу `P_RX` та порогом чутливості приймача `P_sens`:

```
M = P_RX - P_sens   [dB]
```

При розрахунку запасу у великомасштабному середовищі (Large-Scale Fading) середня потужність сигналу зазнає флуктуацій через затінення пагорбами та будівлями. Ці флуктуації підпорядковуються **логарифмічно-нормальному розподілу** (Log-Normal Distribution) із середньоквадратичним відхиленням `σ_dB` (типово від `4 dB` у передмісті до `10 dB` у щільній міській забудові).

Ймовірність того, що зв'язок буде збережено (`P_success`), виражається через стандартну функцію помилок `q_func`:

```
P_success = 1 - Q( M / σ_dB )
```

Для забезпечення доступності покриття на рівні 95% території потрібен запас `M = 1.64 · σ_dB` (наприклад, при `σ_dB = 8 dB` запас `M = 13.1 dB`). Для покриття 99% території потрібен запас `M = 2.33 · σ_dB` (при `σ_dB = 8 dB` запас `M = 18.6 dB`).

## 8. Математика розузгодження поляризації (L_pol)

Якщо вектор електричного поля хвилі передавальної антени відхилений на кут `θ` відносно орієнтації приймальної антени, втрати розузгодження поляризації `L_pol` виражаються математично як:

```
L_pol_linear = cos²(θ)
L_pol(dB) = -20 · log10( cos(θ) )
```

- При `θ = 0°` (повний збіг поляризації): `cos(0°) = 1` → `L_pol = 0 dB`.
- При `θ = 45°`: `cos(45°) = 0.707` → `L_pol = -20·log10(0.707) = +3.01 dB`.
- При `θ = 85°`: `cos(85°) = 0.087` → `L_pol = -20·log10(0.087) = +21.2 dB`.
- При `θ = 90°` (ортогональна поляризація): `cos(90°) = 0` → `L_pol → ∞` (втрата сигналу понад `30–40 dB` через недосконалість реальних антен).

## 9. Математична модель дифракційних втрат зони Френеля (ITU-R P.526)

Якщо на трасі між антенами присутня поодинока клиноподібна перешкода (будівля, гребінь пагорба), що перекриває першу зону Френеля на висоту `h`, виникають дифракційні втрати `L_diff`.

Радіус першої зони Френеля `r_1` у точці розташування перешкоди обчислюється як:

```
r_1 = 17.32 · √( (d_1 · d_2) / (f_GHz · D) )   [м]
```

Де `d_1` та `d_2` — відстані від перешкоди до передавача та приймача (в км), `D = d_1 + d_2` — загальна довжина траси (в км), а `f_GHz` — частота (в ГГц).

Безрозмірний геометрічний параметр дифракції `v` обчислюється як:

```
v = h · √( (2 · (d_1 + d_2)) / (λ · d_1 · d_2) )
```

Згасання сигналу через дифракцію на гострому клині `J(v)` в дБ апроксимується емпіричною формулою Рекомендації ITU-R P.526:

```
J(v) = 6.9 + 20 · log10( √( (v - 0.1)² + 1 ) + v - 0.1 ),   при v > -0.7
```

- Якщо `h = 0` (перешкода торкається прямої лінії): `v = 0` → `J(0) = 6.0 dB` додаткових втрат.
- Якщо `h = r_1` (перешкода перекриває 100% радіуса зони Френеля): `v = 1.41` → `J(v) ≈ 16 dB` втрат.
- Для відсутності дифракційних втрат (`J(v) ≈ 0 dB`) необхідно забезпечити просвіт не менше `0.6 · r_1` (60% радіуса першої зони Френеля).

## 10. Математика згасання в рослинних масивах та лісах (ITU-R P.833)

При поширенні радіохвиль через лісові масиви чи міські парки виникають додаткові втрати у кронах дерев `L_veg` (у дБ). Математична модель Рекомендації ITU-R P.833 визначає питоме згасання у лісі залежно від частоти `f` (у МГц) та довжини ділянки лісу `d_veg` (у метрах):

```
L_veg = A · f ^ B · (d_veg) ^ C   [dB]
```

Де для листяного лісу у літній період емпіричні коефіцієнти становлять: `A ≈ 0.2`, `B ≈ 0.3`, `C ≈ 0.6`.

На частоті 915 МГц при проходженні сигналу через ділянку густого лісу завдовжки `d_veg = 100 м` додаткове згасання обчислюється як:

```
L_veg = 0.2 · (915 ^ 0.3) · (100 ^ 0.6) ≈ 0.2 · 7.74 · 15.85 = 24.5 dB
```

Це пояснює, чому поява лісової смуги на трасі радіолінії вимагає закладання у лінк-бюджет додаткового 25-децибельного запасу потужності.

## 11. Розрахунок граничної дальності зв'язку (d_max)

Прирівнюючи запас лінії до нуля (`M = 0 dB`), тобто `P_RX = P_sens`, ми можемо виразити максимально припустимі втрати у вільному просторі `FSPL_max`:

```
FSPL_max = P_TX - L_tx + G_TX - L_atm - L_rain - L_fade - L_misc + G_RX - L_rx - P_sens
```

Підставивши формулу `FSPL = 20·log10(d_km) + 20·log10(f_MHz) + 32.44`, знаходимо граничну відстань `d_max` у кілометрах:

```
20·log10(d_max_km) = FSPL_max - 20·log10(f_MHz) - 32.44

d_max_km = 10 ^ ( (FSPL_max - 20·log10(f_MHz) - 32.44) / 20 )
```

Ця формула лежить в основі всіх алгоритмів розрахунку покриття радіомереж та оцінки геометрії радіоліній.
