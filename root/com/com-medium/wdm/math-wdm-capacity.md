# 🧮 Фізичні межі та розрахунок спектральної ефективності WDM

Ця вставка містить математичне виведення співвідношення між частотним кроком і рознесенням довжин хвиль, прораховує частотну сітку ITU-T, накопичення оптичного шуму (OSNR) у ланцюгу підсилювачів та оцінює граничну спектральну ефективність за Шенноном з урахуванням чотирихвильового змішування.

### 1. Перерахунок частотного кроку в інтервал довжин хвиль

У телекомунікаціях спектральна сітка DWDM стандартизована в одиницях частоти (герцах), оскільки інтервали між лазерними модами та параметри оптичних комутаторів не залежать від середовища поширення та фазової швидкості хвилі у конкретному склі. Зв'язок між оптичною частотою `f`, довжиною хвилі у вакуумі `λ` та швидкістю світла `c = 299792458 м/с` виражається базовим співвідношенням:

```text
f = c / λ
```

Для знаходження зміни довжини хвилі `Δλ`, яка відповідає частотному кроку `Δf`, беремо похідну від функції `λ(f) = c / f`:

```text
dλ / df = d(c · f⁻¹) / df
        = -c · f⁻²           [правило диференціювання степеневої функції]
        = -c / f²            [перенесення від'ємного степеня у знаменник]
        = -λ² / c            [підстановка f = c / λ]
```

Знак мінус у цій формулі має чіткий фізичний зміст: вищим оптичним частотам відповідають коротші довжини хвиль. Для малих приростів частоти переходять від нескінченно малих диференціалів до скінченної різниці `Δλ`:

```text
|Δλ| = (λ² / c) · Δf
```

Звернувши увагу на цю формулу, можна помітити важливу фізичну особливість: той самий частотний крок `Δf` у різних спектральних діапазонах відповідає різним інтервалам довжин хвиль `Δλ`. Чим більша довжина хвилі `λ`, тим ширший нанометровий інтервал відповідає одному й тому самому частотному проміжку в `100 ГГц`.

Обчислимо інтервал довжин хвиль `Δλ` для стандартного частотного кроку DWDM `Δf = 100 ГГц = 10¹¹ Гц` на опорній довжині хвилі C-діапазону `λ = 1550 нм = 1.55 × 10⁻⁶ м`:

```text
|Δλ| = ( (1.55 × 10⁻⁶)² / 299792458 ) · 10¹¹
     = ( 2.4025 × 10⁻¹² / 2.9979 × 10⁸ ) · 10¹¹   [обчислення квадрата чисельника та розпис c]
     = ( 8.0139 × 10⁻²¹ ) · 10¹¹                 [ділення коефіцієнтів]
     = 8.0139 × 10⁻¹⁰ м                          [множення на частотний крок]
     = 0.8014 нм                                 [переведення в нанометри]
```

Для кроку `Δf = 50 ГГц` інтервал зменшується вдвічі:

```text
|Δλ| = 0.8014 / 2      [лінійна пропорційність від Δf]
     = 0.4007 нм       [обчислення для 50 ГГц сітки]
```

Для кроку `Δf = 25 ГГц` інтервал складає біля `0.2 нм`. Отже, крок `100 ГГц` у діапазоні `1550 нм` відповідає спектральному інтервалу близько `0.8 нм`, а крок `50 ГГц` — близько `0.4 нм`.

### 2. Математична модель частотної сітки ITU-T G.694.1

Стандарт ITU-T G.694.1 визначає центральні частоти оптичних каналів DWDM за лінійною формулою:

```text
f_m = 193.10 ТГц + m · Δf
```

де `193.10 ТГц` (`1552.52 нм`) — абсолютна опорна частота ITU, `Δf` — вибраний сітковий крок (`100 ГГц = 0.1 ТГц`, `50 ГГц = 0.05 ТГц` або `12.5 ГГц = 0.0125 ТГц`), `m` — ціле число (додатне для вищих частот / коротших хвиль, від'ємне для нижчих частот / довших хвиль).

Обчислимо центральну частоту та довжину хвилі для каналу з номером `m = +2` при кроці `Δf = 100 ГГц = 0.1 ТГц`:

```text
f₂ = 193.10 + 2 · 0.1
   = 193.10 + 0.20     [множення номера каналу на крок]
   = 193.30 ТГц        [додавання до опорної частоти]
```

Визначимо відповідну довжину хвилі у вакуумі `λ₂`:

```text
λ₂ = c / f₂
   = 299792458 / (193.30 × 10¹²)   [підстановка швидкості світла та частоти в Гц]
   = 1.550918 × 10⁻⁶ м             [ділення чисел]
   = 1550.92 нм                    [переведення в нанометри]
```

У системах з гнучкою сіткою **Flex-Grid** центральна частота оптичного слота описується більш загальним виразом:

```text
f_slot = 193.10 ТГц + n · 0.00625 ТГц
```

де `n` — ціле число, що задає зсув центральної частоти з кроком `6.25 ГГц`. Спектральна ширина слота задається співвідношенням `S = m · 12.5 ГГц`, де `m` — кількість атомарних спектральних гранул шириною `12.5 ГГц`.

### 3. Накопичення оптичного шуму (OSNR) у каскаді підсилювачів

Будь-який оптичний підсилювач EDFA додає до корисного сигналу шум спонтанного випромінювання (ASE, *Amplified Spontaneous Emission*). Фізична причина виникнення шуму ASE полягає в тім, що збуджені іони ербію `Er³⁺` у волокні можуть самочинно скидати енергію, випромінюючи спонтанні фотони довільної фази й поляризації. Ці спонтанні фотони подальшим проходженням підсилюються разом із корисним сигналом.

Потужність шуму ASE в одному поляризаційному стані на один підсилювальний проліт дорівнює:

```text
P_ase_span = 2 · n_sp · (G - 1) · h · f · B_ref
```

де `n_sp` — коефіцієнт спонтанної емісії (фактор шуму підсилювача `NF = 2 · n_sp`), `G` — коефіцієнт підсилення (що компенсує загасання прольоту `G = 10^(α·L / 10)`), `h = 6.626 × 10⁻³⁴ Дж·с` — стала Планка, `f` — оптична частота, `B_ref = 12.5 ГГц` (`0.1 нм` на довжині хвилі `1550 нм`) — опорна спектральна смуга вимірювання OSNR.

Відношення оптичного сигналу до шуму (OSNR) виражається співвідношенням потужності сигналу `P_in` на вході підсилювача до потужності шуму:

```text
OSNR_linear = P_in / P_ase
```

При послідовному проходженні `N` однакових прольотів із підсилювачами шуми ASE кожного підсилювача додаються інкогерентно (по потужності). Лінійне відношення OSNR на виході ланцюга обчислюється як сума обернених величин:

```text
1 / OSNR_total_linear = ∑ [i=1..N] (1 / OSNR_span_i)
                      = N / OSNR_span_linear             [для N однакових прольотів]
```

Переводячи у логарифмічну шкалу (децибели):

```text
OSNR_total_dB = OSNR_span_dB - 10 · log₁₀(N)
```

Приклад розрахунку: нехай один проліт має `OSNR_span = 38 дБ`. Обчислимо підсумковий OSNR після `N = 16` каскадних прольотів (близько `1280 км` траси при довжині прольоту `80 км`):

```text
OSNR_total_dB = 38 - 10 · log₁₀(16)
              = 38 - 10 · 1.20412    [обчислення десяткового логарифма від 16]
              = 38 - 12.04           [множення на 10]
              = 25.96 дБ             [підсумкове віднімання]
```

Отже, каскад із 16 підсилювачів погіршує OSNR лінії на `12.04 дБ`.

### 4. Гранична спектральна ефективність за Шенноном

Спектральна ефективність (SE, *Spectral Efficiency*) вимірюється в `(біт/с) / Гц` і показує, скільки біт за секунду передається в одному герці оптичного спектра:

```text
SE = C / B
```

де `C` — загальна швидкість каналу (біт/с), `B` — зайнята спектральна смуга (Гц).

За теоремою Шеннона-Гартлі, гранична пропускна здатність оптичного каналу з доданим білим гаусовим шумом (AWGN) для двох станів поляризації світла обчислюється як:

```text
C_shannon = 2 · B · log₂ ( 1 + OSNR_linear )
```

Множник 2 на початку формули враховує існування двох ортогональних станів поляризації світла (горизонтальної та вертикальної), кожна з яких є незалежнім носієм інформації в одномодовому волокні.

Звідси гранична спектральна ефективність дорівнює:

```text
SE_shannon = C_shannon / B
           = 2 · log₂ ( 1 + OSNR_linear )
```

Обчислимо граничну спектральну ефективність для отриманого вище відношення `OSNR = 25.96 дБ`. Спочатку переведемо `25.96 дБ` у лінійну величину:

```text
OSNR_linear = 10^(25.96 / 10)
            = 10^2.596          [ділення децибелів на 10]
            = 394.46            [піднесення 10 до степеня]
```

Тепер обчислимо граничну спектральну ефективність `SE`:

```text
SE_shannon = 2 · log₂ ( 1 + 394.46 )
           = 2 · log₂ ( 395.46 )              [додавання одиниці]
           = 2 · ( ln(395.46) / ln(2) )        [перехід до натурального логарифма]
           = 2 · ( 5.98006 / 0.69315 )         [обчислення логарифмів]
           = 2 · 8.6274                        [ділення логарифмів]
           = 17.255 (біт/с) / Гц               [підсумкове множення на 2 поляризації]
```

У реальних когерентних DWDM-системах (наприклад, 16-QAM з коефіцієнтом надлишковості FEC 20%) досягається спектральна ефективність близько `4–6 (біт/с)/Гц`, оскільки реальний лінійний тракт обмежений нелінійним ефектом Керра.

### 5. Комбінаційні частоти чотирихвильового змішування (FWM)

При високій щільності каналів у DWDM виникає нелінійний ефект Керра — чотирихвильове змішування (FWM, *Four-Wave Mixing*). Три оптичні частоти `f_i`, `f_j`, `f_k` внаслідок нелінійної сприйнятливості третього порядку `χ⁽³⁾` скляної серцевини генерують нові паразитичні частоти `f_ijk`:

```text
f_ijk = f_i + f_j - f_k
```

Загальна кількість неколінеарних комбінаційних продуктів FWM, що виникають у системі з `N` каналів, описується комбінаторною формулою:

```text
M_fwm = (N² · (N - 1)) / 2
```

Для системи з `N = 40` каналів кількість паразитичних комбінаційних хвиль досягає `(1600 · 39) / 2 = 31200` побічних частот.

Якщо частотна сітка є строго рівновіддаленою (`f_n = f_0 + n · Δf`), то паразитична частота `f_ijk` точно збігається з одним із діючих інформаційних каналів `f_m`. Наприклад, для каналів `i = 1`, `j = 3`, `k = 2`:

```text
f_132 = f₁ + f₃ - f₂
      = (f₀ + 1·Δf) + (f₀ + 3·Δf) - (f₀ + 2·Δf)   [підстановка рівновіддаленої сітки]
      = f₀ + (1 + 3 - 2) · Δf                    [групування доданків]
      = f₀ + 2 · Δf                              [обчислення індексу]
      = f₂                                       [збіг із частотою другого каналу]
```

Паразитичний сигнал `f_132` накладається безпосередньо на канал `f₂`, викликаючи непереборні міжканальні перехресні завади (*crosstalk*).

Ефективність генерації паразитичної хвилі FWM залежить від умови фазового розсинхронізму `Δk`:

```text
Δk = (2π · λ² / c) · |f_i - f_k| · |f_j - f_k| · D
```

де `D` — хроматична дисперсія волокна.

Якщо хроматична дисперсія строго дорівнює нулю (`D = 0`, як у волокнах DSF / G.653), то `Δk = 0`. Світлові хвилі рухаються з однаковою фазовою швидкістю, FWM досягає 100% ККД і руйнує весь DWDM-сигнал.

Для пригнічення FWM у DWDM-системах застосовують оптичні волокна з ненульовою хроматичною дисперсією (NZ-DSF, ITU-T G.655). Значення дисперсії `D ≈ 2...6 пс/(нм·км)` створює великий фазовий розсинхронізм `Δk >> 0`, що знижує потужність паразитичних частот FWM на кілька порядків.
