# 🧮 Виведення полів випромінювання синфазного та протифазного струмів

Електромагнітне поле, що випромінюється провідниками кабелю на великій відстані (у дальній хвильовій зоні, де дистанція спостереження `r` значно перевищує як довжину хвилі `λ`, так і лінійні габарити кабельної траси `L`), визначається просторовим розподілом струмів через запізнілий векторний потенціал електромагнітного поля. Суворе математичне виведення на основі рівнянь Максвелла дозволяє кількісно обґрунтувати, чому тонкий дріт або джгут провідників перетворюється на електричний диполь чи магнітну рамкову антену, і чому випромінювальна спроможність синфазного струму на багато порядків перевершує протифазну за однакової амплітуди.

## 1. Векторний потенціал та польові рівняння в дальній зоні

У середовищі без просторових зарядів із магнітною проникністю `μ₀` та діелектричною проникністю `ε₀` розподілений уздовж координатної осі `z` гармонічний струм `I(z') = I₀ · e^(j·ω·t)` створює в довільній точці простору запізнілий магнітний векторний потенціал `A(r)`:

```
A(r)
= (μ₀ / (4·π)) · ∫ [I(z') · e^(-j·k·R) / R] dz'    [інтеграл векторного потенціалу за довжиною]
≈ (μ₀ · e^(-j·k·r) / (4·π·r)) · ∫ I(z') · e^(j·k·z'·cos θ) dz'  [наближення далекої зони: R ≈ r - z'·cos θ]
```

У цих співвідношеннях `k = ω / c = 2·π / λ` — просторове хвильове число, `c = 1 / √(μ₀·ε₀)` — швидкість поширення світла у вакуумі (`≈ 3·10⁸` м/с), а `θ` — кут між віссю провідника і вектором напрямку на точку спостереження `r`.

Межа між реактивною ближньою зоною та дальньою зоною випромінювання визначається радіусом Фраунгофера:

```
r_far ≥ 2 · L² / λ   та   r_far >> λ / (2·π)
```

Напруженість електричного поля `E` у дальній зоні зв'язана з магнітним векторним потенціалом через характеристичний імпеданс вільного простору `η₀ = √(μ₀ / ε₀) ≈ 120·π ≈ 377` Ом:

```
E_θ
= -j·ω·A_θ                                         [зв'язок напруженості поля з векторним потенціалом]
= -j·ω·A · sin θ                                   [проєкція на полярну координату сферичної системи]
```

## 2. Синфазне випромінювання (модель короткого електричного диполя)

У синфазному режимі струм `I_CM` рухається в одному напрямку вздовж усіх внутрішніх жил кабелю довжиною `L` і замикається через розподілену паразитну ємність на опорну площину шасі. Для кабелю, довжина якого менша за чверть довжини хвилі (`L < λ / 4`), розподіл струму вздовж провідника спадає від джерела до відкритого кінця.

Для отримання консервативної верхньої оцінки випромінювання приймається модель елементарного диполя Герца з еквівалентним рівномірним струмом по всій довжині `L`. Тоді фазовий інтеграл за відрізком кабелю від `-L/2` до `+L/2` набуває вигляду:

```
∫ I_CM · e^(j·k·z'·cos θ) dz'
= I_CM · ∫ 1 dz'                                   [наближення e^(j·k·z'·cos θ) ≈ 1 при k·L << 1]
= I_CM · L                                         [інтегрування константи по відрізку довжини L]
```

Підставляючи отримане значення в загальне рівняння для векторного потенціалу, визначаємо просторовий розподіл напруженості електричного поля:

```
E_CM(r, θ)
= -j·ω · (μ₀ · e^(-j·k·r) / (4·π·r)) · I_CM · L · sin θ   [підстановка векторного потенціалу]
= -j · (2·π·f) · μ₀ · I_CM · L · sin θ / (4·π·r)          [підстановка кругової частоти ω = 2·π·f]
= -j · (μ₀ · f · I_CM · L · sin θ) / (2·r)                 [скорочення спільних множників]
```

Максимальна напруженість поля виникає в площині, строго перпендикулярній до осі кабелю (`sin θ = 1` при `θ = 90°`). Модуль напруженості поля у вільному просторі становить:

```
|E_CM|
= (μ₀ · f · L · I_CM) / (2·r)                      [амплітуда поля короткого синфазного диполя]
= (1.2566·10⁻⁶ · f · L · I_CM) / (2·r)             [підстановка магнітної сталої μ₀ ≈ 4·π·10⁻⁷ Гн/м]
= (6.283·10⁻⁷ · f · L · I_CM) / r                  [максимальне поле у вільному просторі]
```

Під час сертифікаційних випробувань на електромагнітну сумісність прилад встановлюється над металевою площиною заземлення. Відбита від землі хвиля додається у фазі з прямою хвилею на висоті вимірювальної антени, що збільшує максимальну напруженість поля вдвічі (коефіцієнт конструктивної інтерференції дорівнює `2`):

```
|E_CM, max|
= 2 · |E_CM|                                       [урахування дзеркального відбиття від землі]
= (μ₀ · f · L · I_CM) / r                          [розрахункова формула стандарту CISPR/FCC]
= (1.257·10⁻⁶ · f · L · I_CM) / r                  [фінальний вираз напруженості поля, В/м]
```

З формули видно, що напруженість синфазного поля `|E_CM|` зростає строго **лінійно з частотою** (`~ f`), а також прямо пропорційно повній довжині кабелю `L` і величині синфазного струму `I_CM`.

## 3. Протифазне випромінювання (модель малої магнітної рамки)

У протифазному режимі струм сигналу `I_DM` протікає в прямому напрямку по одній жилі і повертається у зворотному напрямку по сусідній жилі, розташованій на міжосьовій відстані `s`. Разом вони формують замкнений витягнутий прямокутний контур площею `A = s · L`.

Сумарний векторний потенціал двох паралельних провідників зі струмами `+I_DM` при координаті `x = +s/2` та `-I_DM` при `x = -s/2` утворюється різницею фаз сигналів через малий просторовий зсув `s · sin θ`:

```
A_DM(r)
= (μ₀ · e^(-j·k·r) / (4·π·r)) · I_DM · L · [e^(j·k·(s/2)·sin θ) - e^(-j·k·(s/2)·sin θ)]  [сума потенціалів двох жил]
= (μ₀ · e^(-j·k·r) / (4·π·r)) · I_DM · L · [2·j · sin((k·s / 2) · sin θ)]               [перетворення за формулою Ейлера]
≈ (μ₀ · e^(-j·k·r) / (4·π·r)) · I_DM · L · [2·j · (k·s / 2) · sin θ]                    [наближення sin(x) ≈ x при k·s << 1]
= j · (μ₀ · k · I_DM · (s · L) · sin θ) / (4·π·r)                                         [введення геометричної площі петлі A]
= j · (μ₀ · k · A · I_DM · sin θ) / (4·π·r)                                              [потенціал еквівалентної магнітної рамки]
```

Напруженість електричного поля випромінювання в дальній зоні визначається через векторний потенціал рамки:

```
|E_DM|
= ω · |A_DM|                                       [зв'язок напруженості електричного поля з потенціалом]
= ω · (μ₀ · k · A · I_DM · sin θ) / (4·π·r)         [підстановка виразу векторного потенціалу]
= (2·π·f) · μ₀ · (2·π·f / c) · A · I_DM / (4·π·r)   [підстановка кругової частоти та хвильового числа]
= (μ₀ · π · f² · A · I_DM) / (c · r)               [групування сталих величин]
```

З урахуванням подвоєння напруженості поля внаслідок відбиття від опорної площини вимірювального майданчика:

```
|E_DM, max|
= 2 · |E_DM|                                       [урахування відбиття від провідної поверхні]
= (2·π · μ₀ · f² · A · I_DM) / (c · r)             [спрощення числових множників]
= (2·π · 4·π·10⁻⁷ · f² · A · I_DM) / (3·10⁸ · r)   [підстановка фундаментальних сталих μ₀ та c]
= (2.632·10⁻¹⁴ · f² · A · I_DM) / r                [фінальний розрахунковий вираз поля, В/м]
```

На відміну від синфазного режиму, напруженість протифазного поля `|E_DM|` зростає **пропорційно квадрату частоти** (`~ f²`) та площі струмової петлі `A = s · L`.

## 4. Опір випромінювання та повна випромінювана потужність

Фундаментальна причина колосальної різниці між синфазним та протифазним випромінюванням стає очевидною при розрахунку опору випромінювання `R_rad` — еквівалентного активного опору, на якому виділяється повна потужність електромагнітного випромінювання `P_rad = I² · R_rad`.

Для короткого електричного диполя (синфазний кабель над землею) інтегрування вектора Пойнтінга по охоплюючій сфері дає опір випромінювання:

```
R_rad, CM
= 80 · π² · (L / λ)²                               [опір випромінювання електричного диполя]
= 80 · π² · (f · L / c)²                           [підстановка довжини хвилі λ = c / f]
```

Для малої магнітної рамки (протифазна петля площею `A = s · L`):

```
R_rad, DM
= 320 · π⁴ · (A / λ²)²                             [опір випромінювання магнітної рамки]
= 320 · π⁴ · (f² · s · L / c²)²                    [підстановка площі A = s · L та λ = c / f]
```

Обчислимо співвідношення опорів випромінювання двох мод:

```
R_rad, CM / R_rad, DM
= [80 · π² · (L / λ)²] / [320 · π⁴ · (s · L / λ²)²] [ділення формул опорів випромінювання]
= (1 / (4 · π²)) · (λ / s)²                        [скорочення довжини кабелю L]
= (1 / (4 · π²)) · (c / (f · s))²                  [вираження через частоту та міжосьову відстань]
```

Для типових параметрів кабелю (`s = 2` мм, `f = 100` МГц, `λ = 3` м):

```
R_rad, CM / R_rad, DM
= (1 / (4 · 9.8696)) · (3.0 / 0.002)²              [числові значення для 100 МГц та s = 2 мм]
= (1 / 39.478) · (1500)²                           [обчислення знаменника та просторового відношення]
= 0.02533 · 2.25·10⁶
≈ 57000                                            [перевага синфазного опору випромінювання]
```

Синфазний контур випромінює у **57 000 разів більше електромагнітної енергії**, ніж протифазна пара з тим самим струмом. Цей математичний результат доводить, що захист кабелю від EMI вимагає першочергового придушення синфазних струмів.

## 5. Порівняння випромінюваних полів та чутливості до струмів

Знайдемо відношення напруженостей електричних полів у дальній зоні:

```
|E_CM| / |E_DM|
= [(μ₀ · f · L · I_CM) / r] / [(2·π · μ₀ · f² · (s · L) · I_DM) / (c · r)]  [ділення формул напруженостей полів]
= (f · L · I_CM · c) / (2·π · f² · s · L · I_DM)                           [скорочення спільних множників]
= (c · I_CM) / (2·π · f · s · I_DM)                                        [скорочення частоти f та довжини L]
= (λ / (2·π · s)) · (I_CM / I_DM)                                          [підстановка довжини хвилі λ = c / f]
= (1 / (k · s)) · (I_CM / I_DM)                                            [вираження через хвильове число k = 2·π / λ]
```

Оскільки геометрична відстань між провідниками `s` у кабелях становить від 0.5 мм до 3 мм, параметр `k · s = 2·π·s / λ << 1` є надзвичайно малим числом, що зумовлює колосальну просторову перевагу дипольного синфазного випромінювача.

Для однакової напруженості випромінюваного поля необхідне співвідношення струмів становить:

```
I_DM / I_CM
= λ / (2·π · s)                                    [умова еквівалентної напруженості поля]
```

На частоті 100 МГц (`λ = 3` м, `s = 2` мм) це відношення становить `239`. На частоті 30 МГц (`λ = 10` м, `s = 2` мм) відношення сягає `796`.

## 6. Числовий приклад розрахунку нормативів CISPR 32 Class B

Міжнародний стандарт CISPR 32 (EN 55032) для мультимедійного обладнання побутового класу (Class B) встановлює граничну напруженість випромінюваного квазіпікового поля на вимірювальній дистанції `r = 10` м:

- У діапазоні від 30 до 230 МГц: `30` дБ(мкВ/м) (`31.62` мкВ/м = `3.162·10⁻⁵` В/м).
- У діапазоні від 230 до 1000 МГц: `37` дБ(мкВ/м) (`70.79` мкВ/м = `7.079·10⁻⁵` В/м).

Обчислимо гранично допустимий синфазний струм `I_CM` для кабелю довжиною `L = 1.0` м на частоті `f = 100` МГц:

```
I_CM, limit
= (E_limit · r) / (μ₀ · f · L)                     [вираження струму з формули поля CM]
= (3.162·10⁻⁵ · 10) / (1.257·10⁻⁶ · 100·10⁶ · 1.0) [підстановка числових параметрів]
= 3.162·10⁻⁴ / 125.7                               [обчислення знаменника]
≈ 2.516·10⁻⁶ А = 2.52 мкА                          [граничний струм за стандартом]
```

Тепер розрахуємо граничний протифазний струм `I_DM` для того ж кабелю з відстанню між жилами `s = 2.0` мм (`A = s · L = 2.0·10⁻³` м²):

```
I_DM, limit
= (E_limit · r) / (2.632·10⁻¹⁴ · f² · A)           [вираження струму з формули поля DM]
= (3.162·10⁻⁵ · 10) / (2.632·10⁻¹⁴ · (100·10⁶)² · 2·10⁻³) [підстановка параметрів]
= 3.162·10⁻⁴ / (2.632·10⁻¹⁴ · 10¹⁶ · 2·10⁻³)       [обчислення квадрата частоти]
= 3.162·10⁻⁴ / 5.264·10⁻¹                          [обчислення знаменника]
≈ 6.007·10⁻⁴ А = 601 мкА                           [граничний протифазний струм]
```

Якщо ж застосувати виту пару з кроком скрутки `20` мм, еквівалентна площа незкомпенсованої петлі зменшується до площі одного піввитка (`A_eff ≈ 2·10⁻⁵` м²), що піднімає допустимий протифазний струм сигналу до `60` мА.

Цей розрахунок наочно демонструє, чому цифрові інтерфейси з диференційними струмами в десятки міліампер вільно вкладаються в норми стандартів, тоді як витік навіть кількох мікроамперів синфазного струму на кабель гарантовано призводить до непроходження сертифікації.
