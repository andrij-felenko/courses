# ⚙️ Програмне розділення мод та цифрове придушення синфазних завад

При обробці сигналів із високошвидкісних диференційних ліній зв'язку, датчикових вимірювальних каналів та промислових шин польового рівня постає практичне інженерне завдання: виділити синфазну (Common Mode) та протифазну (Differential Mode) складові з двох фізичних ліній зв'язку, оцінити ступінь спотворення корисного сигналу через паразитне перетворення мод та застосувати цифровий адаптивний компенсатор для придушення високочастотної завади.

Синфазна завада, наведена зовнішнім електромагнітним полем на довгий кабель, проникає в диференційний сигнальний тракт через асиметрію друкованих провідників, технологічний розкид вхідних ємностей мікросхем або нерівномірність контактних опорів роз'ємів. Якщо аналоговий каскад підсилювача на високих частотах має обмежений коефіцієнт придушення синфазного сигналу (CMRR), залишкова завада потрапляє на вхід аналогово-цифрового перетворювача (АЦП), де її можна придушити програмними методами цифрової обробки сигналів.

## 1. Математична модель розділення мод та перетворення завад

Нехай на приймальному кінці диференційної пари виконується синхронне дискретне вимірювання напруг двох провідників `v_a[k]` та `v_b[k]` відносно локальної землі схеми з періодом дискретизації `T_s = 1 / f_s`.

Матричне перетворення фізичних напруг у модальний базис визначається лінійними співвідношеннями:

```
v_dm[k] = v_a[k] - v_b[k]
v_cm[k] = (v_a[k] + v_b[k]) / 2
```

де `v_dm[k]` — виміряна диференційна напруга корисного сигналу, а `v_cm[k]` — виміряна синфазна напруга завади.

У реальній фізичній системі через паразитну асиметрію плечей лінії (перекіс довжин трас `ΔL`, нерівність ємностей `ΔC` та опорів `ΔR`) виникає взаємний зв'язок між модами. Повна виміряна диференційна напруга містить як чистий корисний сигнал `s_dm[k]`, так і просочену частку синфазної завади:

```
v_dm[k] = s_dm[k] + α · v_cm[k]
```

Тут `α` — невідомий заздалегідь коефіцієнт перетворення мод (Mode Conversion Factor), величина якого зазвичай коливається в межах від 0.01 до 0.10 (від 1% до 10% проникнення синфазної завади в корисний канал).

Для відновлення первинного сигналу `s_dm[k]` застосовується алгоритм адаптивної фільтрації Відроу-Гоффа за критерієм найменших середніх квадратів (Least Mean Squares, LMS). Оскільки корисний інформаційний сигнал `s_dm[k]` та зовнішня синфазна завада `v_cm[k]` є статистично незалежними (їхня взаємна кореляція прямує до нуля), адаптивний фільтр здатний точно оцінити параметр проникнення `α` шляхом мінімізації повної енергії вихідного сигналу помилки `e[k]`:

```
y[k] = w[k] · v_cm[k]                             [оцінка прониклої синфазної завади]
e[k] = v_dm[k] - y[k]                             [очищений корисний сигнал на виході]
w[k+1] = w[k] + μ · e[k] · v_cm[k]                 [адаптація вагового коефіцієнта за LMS]
```

Параметр швидкості адаптації `μ` (step size) обирається з умови стійкості алгоритму:

```
0 < μ < 2 / (P_cm · N)
```

де `P_cm = E{v_cm²}` — середня потужність синфазного сигналу завади.

Для запобігання розбіжності фільтра при різких сплесках амплітуди завади використовується нормалізований алгоритм (Normalized LMS, NLMS):

```
w[k+1] = w[k] + [μ / (ε + v_cm²[k])] · e[k] · v_cm[k]
```

де `ε` — мале додатне число (коефіцієнт регуляризації), яке унеможливлює ділення на нуль під час пауз у сигналі завади.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

typedef struct {
    double* v_dm;
    double* v_cm;
    size_t length;
} ModeDecomposition;

/* Розділення сигналів двох ліній на DM та CM складові */
ModeDecomposition decompose_modes(const double* va, const double* vb, size_t n) {
    ModeDecomposition res;
    res.length = n;
    res.v_dm = (double*)malloc(n * sizeof(double));
    res.v_cm = (double*)malloc(n * sizeof(double));
    if (!res.v_dm || !res.v_cm) {
        free(res.v_dm);
        free(res.v_cm);
        res.v_dm = NULL;
        res.v_cm = NULL;
        res.length = 0;
        return res;
    }

    for (size_t i = 0; i < n; ++i) {
        res.v_dm[i] = va[i] - vb[i];
        res.v_cm[i] = 0.5 * (va[i] + vb[i]);
    }
    return res;
}

void free_decomposition(ModeDecomposition* d) {
    if (d) {
        free(d->v_dm);
        free(d->v_cm);
        d->v_dm = NULL;
        d->v_cm = NULL;
        d->length = 0;
    }
}

/* Адаптивний LMS-фільтр придушення синфазної завади */
void lms_cancel_cm_interference(const double* v_dm_noisy, const double* v_cm,
                                double* v_dm_clean, size_t n, double mu) {
    double w = 0.0; /* поточна оцінка коефіцієнта проникнення CM -> DM */
    for (size_t i = 0; i < n; ++i) {
        double estimated_cm_leak = w * v_cm[i];
        double error = v_dm_noisy[i] - estimated_cm_leak;
        v_dm_clean[i] = error;
        /* Оновлення ваги за стохастичним градієнтом найменших квадратів */
        w += mu * error * v_cm[i];
    }
}

/* Розрахунок наведеної напруги за передавальним імпедансом екрана Z_T */
double calc_induced_shield_voltage(double i_shield_rms, double z_transfer, double length_m) {
    return i_shield_rms * z_transfer * length_m;
}

int main(void) {
    const size_t N = 1000;
    double* va = (double*)malloc(N * sizeof(double));
    double* vb = (double*)malloc(N * sizeof(double));
    double* clean_dm = (double*)malloc(N * sizeof(double));

    if (!va || !vb || !clean_dm) {
        free(va);
        free(vb);
        free(clean_dm);
        return 1;
    }

    const double f_sig = 1000.0;    /* 1 кГц корисний сигнал інформаційного каналу */
    const double f_emi = 50000.0;   /* 50 кГц синфазна завада від силового ШІМ-інвертора */
    const double fs = 500000.0;     /* 500 кГц частота дискретизації АЦП */
    const double alpha_leak = 0.05; /* 5% асиметрія провідників (коефіцієнт перетворення) */

    for (size_t i = 0; i < N; ++i) {
        double t = (double)i / fs;
        double sig_dm = 1.0 * sin(2.0 * M_PI * f_sig * t);
        double emi_cm = 3.0 * sin(2.0 * M_PI * f_emi * t);

        /* Моделювання напруг ліній із перекосом */
        va[i] = (0.5 * sig_dm) + emi_cm;
        vb[i] = (-0.5 * sig_dm) + emi_cm * (1.0 - alpha_leak);
    }

    ModeDecomposition decomp = decompose_modes(va, vb, N);
    if (decomp.v_dm && decomp.v_cm) {
        lms_cancel_cm_interference(decomp.v_dm, decomp.v_cm, clean_dm, N, 0.01);

        printf("Індекс | V_a (В)  | V_b (В)  | V_DM вихідна | V_CM завада | V_DM очищена\n");
        printf("--------------------------------------------------------------------\n");
        for (size_t i = 0; i < 5; ++i) {
            printf("%6zu | %8.4f | %8.4f | %12.4f | %11.4f | %12.4f\n",
                   i, va[i], vb[i], decomp.v_dm[i], decomp.v_cm[i], clean_dm[i]);
        }
    }

    free_decomposition(&decomp);
    free(va);
    free(vb);
    free(clean_dm);
    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <span>
#include <cmath>
#include <numbers>
#include <iomanip>

struct ModeSignals {
    std::vector<double> dm;
    std::vector<double> cm;
};

/* Клас аналізатора модального розкладу та цифрової фільтрації */
class DifferentialLineProcessor {
public:
    /* Розділення виміряних сигналів на протифазну та синфазну компоненти */
    static ModeSignals decompose(std::span<const double> va, std::span<const double> vb) {
        const size_t n = std::min(va.size(), vb.size());
        ModeSignals result;
        result.dm.reserve(n);
        result.cm.reserve(n);

        for (size_t i = 0; i < n; ++i) {
            result.dm.push_back(va[i] - vb[i]);
            result.cm.push_back(0.5 * (va[i] + vb[i]));
        }
        return result;
    }

    /* Адаптивне придушення синфазної завади методом LMS (Widrow-Hoff) */
    static std::vector<double> cancelInterference(
        std::span<const double> v_dm,
        std::span<const double> v_cm,
        double mu = 0.01)
    {
        const size_t n = std::min(v_dm.size(), v_cm.size());
        std::vector<double> clean_dm;
        clean_dm.reserve(n);

        double w = 0.0; /* ваговий коефіцієнт проникнення завади CM -> DM */
        for (size_t i = 0; i < n; ++i) {
            double estimated_leak = w * v_cm[i];
            double error = v_dm[i] - estimated_leak;
            clean_dm.push_back(error);
            w += mu * error * v_cm[i];
        }
        return clean_dm;
    }

    /* Обчислення наведеної напруги за передавальним імпедансом екрана Z_T */
    static constexpr double transferImpedanceVoltage(
        double shield_current_rms,
        double z_transfer_ohm_per_m,
        double cable_length_m) noexcept
    {
        return shield_current_rms * z_transfer_ohm_per_m * cable_length_m;
    }
};

int main() {
    constexpr size_t sampleCount = 1000;
    constexpr double f_sig = 1000.0;    // 1 кГц корисний сигнал
    constexpr double f_emi = 50000.0;   // 50 кГц синфазна завада від ШІМ
    constexpr double fs = 500000.0;     // 500 кГц частота квантування АЦП
    constexpr double alpha_leak = 0.05; // 5% асиметрія провідників лінії

    std::vector<double> va(sampleCount);
    std::vector<double> vb(sampleCount);

    for (size_t i = 0; i < sampleCount; ++i) {
        double t = static_cast<double>(i) / fs;
        double sig_dm = 1.0 * std::sin(2.0 * std::numbers::pi * f_sig * t);
        double emi_cm = 3.0 * std::sin(2.0 * std::numbers::pi * f_emi * t);

        va[i] = (0.5 * sig_dm) + emi_cm;
        vb[i] = (-0.5 * sig_dm) + emi_cm * (1.0 - alpha_leak);
    }

    auto modes = DifferentialLineProcessor::decompose(va, vb);
    auto clean_dm = DifferentialLineProcessor::cancelInterference(modes.dm, modes.cm, 0.01);

    std::cout << std::fixed << std::setprecision(4);
    std::cout << "Індекс | V_a (В)  | V_b (В)  | V_DM вихідна | V_CM завада | V_DM очищена\n";
    std::cout << "--------------------------------------------------------------------\n";
    for (size_t i = 0; i < 5; ++i) {
        std::cout << std::setw(6) << i << " | "
                  << std::setw(8) << va[i] << " | "
                  << std::setw(8) << vb[i] << " | "
                  << std::setw(12) << modes.dm[i] << " | "
                  << std::setw(11) << modes.cm[i] << " | "
                  << std::setw(12) << clean_dm[i] << "\n";
    }

    return 0;
}
```

## 3. Особливості вбудованої реалізації та апаратні обмеження

При перенесенні алгоритму на мікроконтролери сімейств STM32, ESP32 або спеціалізовані сигнальні процесори (DSP) необхідно враховувати низку практичних інженерних факторів:

1. **Фазовий перекіс семплування АЦП:** якщо два вхідні канали `V_a` та `V_b` вимірюються одним мультиплексованим АЦП почергово з часовим зсувом `Δt_adc`, цей зсув штучно генерує фазову асиметрію. Для високошвидкісних ліній обов'язково використовують АЦП із синхронним одночасним вибірково-зберігальним каскадом (Dual Simultaneous Sampling ADC).
2. **Арифметика з фіксованою комою:** на ядрах ARM Cortex-M0/M3 без апаратного блоку FPU обчислення переводяться у формат фіксованої коми `Q15` або `Q31`. Множення на крок адаптації `μ` замінюється бітовим зсувом вправо на `k` позицій (`μ = 2^(-k)`), що зводить кожну ітерацію адаптації до кількох базових машинних циклів складання та зсуву.
3. **Граничний діапазон вхідних синфазних напруг (Input Common Mode Range):** цифровий компенсатор здатний видалити заваду лише тоді, коли сумарна напруга `V_cm + V_dm/2` не виходить за межі лінійного діапазону вхідного підсилювача та опорної напруги АЦП (Rail-to-Rail Range). Якщо амплітуда синфазної завади викликає обмеження чи насичення вхідного каскаду, інформація про сигнал втрачається безповоротно, тому цифрова фільтрація завжди повинна доповнюватися апаратними синфазними дроселями та феритовими муфтами.

## 4. Порівняння апаратної та цифрової фільтрації синфазних завад

В інженерній практиці програмна компенсація завад не замінює апаратні заходи, а ефективно доповнює їх:

- **Апаратні синфазні дроселі та ферити:** забезпечують широкосмугове придушення на частотах від 1 МГц до 1 ГГц ще до потрапляння сигналу в мікросхеми, запобігаючи нелінійній детекції та перевантаженню каскадів.
- **Цифрові адаптивні алгоритми (LMS):** демонструють максимальну ефективність у діапазоні від одиниць герц до кількох сотень кілогерців (низькочастотні гармоніки мережі 50 Гц, комутаційні завади ШІМ-перетворювачів частоти), де фізичні габарити аналогових дроселів стали б неприпустимо великими.

## 5. Обробка крайових випадків та стійкість до імпульсних сплесків

У реальних промислових середовищах кабель періодично піддається впливу потужних імпульсних завад мікросекундної тривалості (наприклад, комутація індуктивних контакторів, електростатичні розряди ESD або грозові наведення). Такі сплески викликають миттєвий стрибок сигналу помилки `e[k]`, що може призвести до розбіжності (дрейфу в нескінченність) адаптивного вагового коефіцієнта `w[k]`.

Для гарантування абсолютної числової стійкості алгоритму в прошивку додають два механізми захисту:

1. **Обмеження градієнта (Gradient / Error Clipping):** якщо модуль помилки перевищує заданий поріг максимального фізичного діапазону сигналу `E_max`, значення помилки обмежується на цьому рівні, запобігаючи надмірному коригуванню ваги за один крок.
2. **Фільтрація з витоком (Leaky LMS):** до рівняння оновлення ваги вводиться малий коефіцієнт забування `γ` (`10⁻⁴ – 10⁻³`):
   ```
   w[k+1] = (1 - γ) · w[k] + μ · e[k] · v_cm[k]
   ```
   Це змушує вагу плавно повертатися до нуля під час тривалих пауз у сигналі або при зникненні зовнішньої синфазної завади, запобігаючи накопиченню похибок округлення в регістрах процесора.
