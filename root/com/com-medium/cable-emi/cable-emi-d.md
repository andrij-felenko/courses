- [Диференційна пара](root:com-medium/differential-pair) — симетричне передавання сигналу двома лініями протифазними напругами.

- [Зони випромінювання](root:com-medium/radiation-zones) — ближня зона індукції та реактивного поля й далека хвильова зона.

</preknowlist>

Коли довжина провідника `L` стає порівнянною з часткою довжини хвилі найвищої спектральної складової струму (`L ≥ λ / 10`), будь-який сигнальний або живильний кабель перестає діяти як зосереджене електричне з'єднання з нульовим опором і перетворюється на просторову випромінювальну та приймальну структуру — електромагнітну антену. Змінний електричний струм, протікаючи вздовж провідника, збуджує змінне магнітне поле, а змінна різниця потенціалів між жилами або відносно навколишнього металевого оточення збуджує змінне електричне поле. Згідно з рівняннями Максвелла, у зоні просторового відриву ці поля взаємно підтримують одне одного у вигляді поперечної електромагнітної хвилі, що безповоротно забирає енергію від передавача у відкритий простір.

Зворотний процес відбувається з тією ж фізичною ефективністю: будь-яке зовнішнє електромагнітне поле — від радіостанцій, мобільних веж, інверторів або сусідніх силових шин — наводить у розподіленій ємності та індуктивності кабелю струми й напруги завад. Це явище неконтрольованої електромагнітної взаємодії зветься електромагнітною завадою (англ. *electromagnetic interference, EMI*, від грец. *ēlektron* — бурштин, *magnētis* — магніт та лат. *inter* — між, *ferire* — вдаряти). Завади проникають у чутливі вхідні каскади мікроконтролерів, аналогово-цифрових перетворювачів та мережевих трансиверів, викликаючи спотворення даних, аварійні скидання процесора та хибні спрацьовування компараторів.

## Фізика випромінювання: від замкненої лінії до відкритого простору

В ідеальній лінії передачі електромагнітне поле повністю локалізоване в діелектрику між прямим та зворотним провідниками. Якщо два нескінченно довгі провідники розташовані впритул один до одного і несуть суворо рівні за величиною, але протилежні за напрямком струми, магнітні поля від обох провідників у кожній зовнішній точці простору мають протилежний знак і взаємно компенсуються. Електричне поле замкнене безпосередньо між поверхнями жил, тому зовнішнє випромінювання дорівнює нулю.

У реальному кабелі ця ідеальна компенсація порушується з трьох причин: скінченна відстань між жилами `s`, просторова асиметрія провідників відносно навколишніх металевих конструкцій (шасі, захисного заземлення, опорних площин) та наявність високих частот у спектрі сигналів.

Спектральний склад цифрового сигналу визначається не стільки його тактовою частотою `f_clk`, скільки тривалістю фронту наростання та спаду імпульсу `t_r` (rise time). Гранична частота спектра імпульсу `f_max`, до якої амплітуда гармонік залишається значною, оцінюється класичним співвідношенням:

```
f_max ≈ 0.35 / t_r
```

Для сучасного мікроконтролера або цифрового інтерфейсу з фронтом перемикання `t_r = 1.0` нс гранична частота сягає:

```
f_max ≈ 0.35 / (1.0·10⁻⁹) = 350·10⁶ Гц = 350 МГц
```

Довжина хвилі `λ` у повітрі для цієї частоти становить:

```
λ = c / f_max = (3·10⁸ м/с) / (350·10⁶ Гц) ≈ 0.857 м = 85.7 см
```

Якщо до цифрової плати підключено звичайний кабель датчика або лінію передачі даних довжиною `L = 1.0` м, умова зосередженого кола (`L << λ / 10`, тобто `L << 8.5` см) грубо порушується: довжина кабелю перевищує повну довжину хвилі. Струм уздовж кабелю змінює не лише фазу, але й напрямок у різних точках лінії, перетворюючи провідник на розподілену резонансну антену.

## Два режими струмів: протифазний (DM) та синфазний (CM)

Струми, що протікають у будь-якому кабелі з двома або більше провідниками, завжди можна розкласти на дві незалежні ортогональні складові: протифазну (диференційну) та синфазну.

![Протифазний та синфазний режими випромінювання кабелю](/root/com/com-medium/cable-emi/img/fig-cm-dm-radiation.svg)
*Порівняння протифазного контуру (мала площа петлі, взаємне скасування полів) та синфазного електричного диполя (струм в один бік, замикання через паразитну ємність і шасі).*

### 1. Протифазний струм (Differential Mode, DM)

Протифазний струм (від лат. *differentia* — різниця) — це функціональний, корисний струм сигналу. Він виходить із джерела через сигнальний провідник `+`, проходить крізь навантаження на приймальному кінці та повертається до джерела через зворотний провідник `-`.

Математично протифазний струм `I_DM` визначається як половина різниці струмів у двох жилах:

```
I_DM = (I₁ - I₂) / 2
```

Два провідники зі струмами протилежного напрямку утворюють плоску струмову петлю з площею `A = s · L`, де `s` — відстань між центрами жил, `L` — довжина лінії. Така петля діє як елементарний магнітний диполь (мала рамкова антена).

Напруженість електричного поля випромінювання протифазного струму `E_DM` у дальній хвильовій зоні на відстані `r` від кабелю описується формулою:

```
|E_DM| = (μ₀ · π · f² · A · I_DM) / (c · r)
```

З урахуванням конструктивного відбиття від провідної поверхні землі під час вимірювань за стандартами EMC, максимальне поле на відстані `r` дорівнює:

```
|E_DM, max| = (2.632·10⁻¹⁴ · f² · A · I_DM) / r   [В/м]
```

Головна характеристика протифазного випромінювання — його пропорційність **квадрату частоти** `f²` та **площі контуру** `A = s · L`. Оскільки в якісно виготовленому кабелі відстань між жилами `s` мінімізована (до частки міліметра у витих парах), площа петлі `A` надзвичайно мала, а випромінюване поле лишається слабким навіть при значних робочих струмах сигналу (`I_DM ~ 10–100` мА).

### 2. Синфазний струм (Common Mode, CM)

Синфазний струм (англ. *common mode*, від лат. *communis* — спільний і *modus* — міра, спосіб) — це паразитарний струм, який протікає в **одному напрямку** одночасно по всіх жилах кабелю (включаючи сигнальні дроти, землю та металевий екран).

Математично синфазний струм `I_CM` є середнім арифметичним струмів обох жил:

```
I_CM = (I₁ + I₂) / 2
```

Оскільки весь струм тече в один бік, він не може замкнутися всередині самого кабелю. За першим законом Кірхгофа замкненість кола забезпечується через розподілену паразитну ємність кабелю відносно навколишнього середовища (металевих конструкцій шасі, опорної землі, корпусу приладу).

Уся конструкція кабелю разом із шасі перетворюється на відкритий асиметричний електричний диполь довжиною `L`.

Напруженість електричного поля випромінювання синфазного струму `E_CM` у дальній зоні на відстані `r` визначається рівнянням:

```
|E_CM| = (μ₀ · f · L · I_CM) / (2 · r)
```

А з урахуванням максимального підсилення через відбиття від землі:

```
|E_CM, max| = (1.257·10⁻⁶ · f · L · I_CM) / r   [В/м]
```

Синфазне випромінювання пропорційне **першому степеню частоти** `f` та повній **довжині кабелю** `L`. Докладне покрокове виведення обох формул із рівнянь Максвелла та векторного потенціалу наведено у вставці [математичне виведення полів випромінювання](root:com-medium/cable-emi/math-radiated-fields.md).

### Драматична різниця випромінювальної ефективності: чутливість до мікроамперів

Порівняємо відношення випромінюваних полів, створених синфазним та протифазним струмами однакової величини в кабелі довжиною `L = 1.0` м із відстанню між жилами `s = 2.0` мм на частоті `f = 100` МГц (`λ = 3.0` м):

```
|E_CM| / |E_DM|
= (c) / (2·π · f · s)                              [спрощення відношення формул полів]
= λ / (2·π · s)                                    [підстановка довжини хвилі λ = c / f]
= 3.0 / (2 · 3.14159 · 0.002)                      [числові значення для f = 100 МГц, s = 2 мм]
= 3.0 / 0.012566
≈ 238.7                                            [перевага синфазного випромінювання]
```

Синфазний струм створює у **238 разів потужніше** електричне поле, ніж такий самий протифазний струм.

Якщо звернутися до міжнародного стандарту електромагнітної сумісності CISPR 32 Class B (побутова апаратура), на частоті 100 МГц на вимірювальній дистанції `r = 10` м допустима напруженість поля становить `30` дБ(мкВ/м), або `31.6` мкВ/м (`3.16·10⁻⁵` В/м).

Обчислимо граничні струми:

```
I_CM, limit
= (E_limit · r) / (1.257·10⁻⁶ · f · L)             [граничний синфазний струм]
= (3.162·10⁻⁵ · 10) / (1.257·10⁻⁶ · 100·10⁶ · 1.0)
≈ 2.52·10⁻⁶ А = 2.52 мкА                           [всього 2.5 мікроампера!]
```

Для протифазного струму:

```
I_DM, limit
= (E_limit · r) / (2.632·10⁻¹⁴ · f² · A)           [граничний протифазний струм]
= (3.162·10⁻⁵ · 10) / (2.632·10⁻¹⁴ · (100·10⁶)² · 0.002)
≈ 6.01·10⁻⁴ А = 601 мкА                            [у 238 разів більше]
```

А для якісної крученої пари, де відстань між центрами жил зменшена до `s = 0.5` мм з чергуванням фаз витків, протифазний струм може перевищувати `20–50` мА без виходу за межі дозволеного стандартом поля.

> 🔧 **Навіщо це.** В інженерній практиці майже 95% усіх проблем із непроходженням сертифікації EMC (випромінювання кабелів на стенді з антеною) спричинені виключно **синфазними струмами**. Достатньо крихітного паразитного витоку всього у **2.5–5 мікроамперів**, щоб 1-метровий кабель завалив тест на випромінювання.

## Механізми виникнення синфазного струму: перетворення мод

Чому в кабелі взагалі з'являється синфазний струм, якщо передавач генерує виключно протифазний сигнал? Процес переходу енергії з корисної диференційної моди в паразитну синфазну зветься перетворенням мод (англ. *mode conversion*).

![Механізми виникнення синфазного струму](/root/com/com-medium/cable-emi/img/fig-mode-conversion.svg)
*Перетворення протифазного сигналу на синфазну заваду через фазовий перекіс довжин ліній, незбалансованість ємностей та скінченний імпеданс землі.*

Існує три основні фізичні причини перетворення мод у реальних пристроях:

### 1. Фазовий перекіс та асиметрія затримок (Phase Skew)

Якщо провідники диференційної пари на друкованій платі або всередині кабелю мають різну фізичну довжину (`ΔL`), сигнал на одному провіднику запізнюється відносно іншого на час:

```
Δt = ΔL / v
```

де `v = c / √(ε_r)` — швидкість поширення хвилі в діелектрику (`≈ 15` см/нс для склотекстоліту FR-4).

Під час зміни логічного рівня напруги `V_A(t)` та `V_B(t)` не компенсують одна одну впродовж інтервалу `Δt`. У цій часовій щілині виникає короткий синфазний імпульс амплітудою:

```
V_CM(t) = (V_A(t) + V_B(t)) / 2
```

Якщо сигнал має перепад `3.3` В з тривалістю фронту `t_r = 1.0` нс, а різниця довжин доріжок становить лише `ΔL = 3` мм (`Δt ≈ 20` пс), амплітуда синфазного сплеску сягає:

```
V_CM, peak ≈ (Δt / t_r) · V_sig = (0.02 / 1.0) · 3.3 В ≈ 66 мВ
```

При типовому синфазному хвильовому опорі кабелю `Z_CM ≈ 150` Ом цей сплеск збуджує синфазний струм:

```
I_CM = V_CM / Z_CM = 0.066 В / 150 Ом = 440 мкА
```

Це значення у **175 разів перевищує** допустиму межу стандарту CISPR 32!

### 2. Незбалансовані паразитні ємності та імпеданси

Якщо провідник `A` розташований ближче до металевого корпусу або має ширшу контактну площадку, ніж провідник `B`, їхні ємності на землю різняться: `C₁ ≠ C₂`. Змінний протифазний сигнал `dV/dt` створює нерівні струми зміщення на шасі:

```
i₁ = C₁ · (dV_A / dt)
i₂ = C₂ · (dV_B / dt)
```

Оскільки `V_A = -V_B`, сумарний струм, що стікає на шасі, не дорівнює нулю:

```
i_CM = i₁ + i₂ = (C₁ - C₂) · (dV_A / dt) = ΔC · (dV_A / dt)
```

Різниця ємностей всього у `ΔC = 0.5` пФ при швидкості наростання фронту `dV/dt = 3.3 В / 1 нс = 3.3·10⁹ В/с` генерує синфазний струм:

```
i_CM = 0.5·10⁻¹² Ф · 3.3·10⁹ В/с = 1.65·10⁻³ А = 1.65 мА = 1650 мкА
```

### 3. Підстрибування потенціалу землі (Ground Bounce)

Коли вихідні транзистори мікросхеми перемикають струм у навантаженні, струм повернення протікає крізь паразитну індуктивність виводів корпусу мікросхеми та перехідних отворів плати `L_gnd` (`≈ 2–10` нГн). Це створює динамічний перепад напруги на внутрішній землі кристала:

```
V_bounce = L_gnd · (d I_total / dt)
```

Ця напруга зсуває потенціал усіх вихідних сигналів одночасно відносно зовнішнього шасі, напряму прикладаючись до кабелю як джерело синфазної ЕРС `V_CM = V_bounce`.

Програмну симуляцію розділення мод, оцінку витоку через асиметрію та цифровий алгоритм компенсації завади наведено у вставці [програмне розділення мод та цифрове придушення синфазних завад](root:com-medium/cable-emi/proj-cm-dm-filter.md).

## Кабель як приймальна антена: вловлювання зовнішніх полів

За фундаментальною теоремою взаємності Лоренца (англ. *reciprocity theorem*, від лат. *reciprocus* — взаємний) просторова діаграма спрямованості, коефіцієнт підсилення та ефективна площа антени в режимі передавання та в режимі приймання є тотожними. Кабель, який ефективно випромінює синфазні завади, настільки ж ефективно вловлює зовнішні електромагнітні поля.

Зовнішнє електромагнітне поле взаємодіє з кабелем двома шляхами:

1. **Магнітне (індуктивне) наведення:** зовнішній змінний магнітний потік `B(t)`, що перетинає петлю між провідниками або між кабелем і заземленим шасі, за законом індукції Фарадея наводить ЕРС:
   ```
   e_ind = - dΦ / dt = - A_loop · (dB / dt)
   ```
   Чим більша площа контуру `A_loop`, утвореного кабелем і землею, тим вища наведена завада.

2. **Електричне (ємнісне) наведення:** зовнішнє змінне електричне поле `E(t)` індукує заряди на поверхні кабелю, збуджуючи синфазний струм зміщення, що протікає крізь ємнісний зв'язок на вхідні опори схеми.

Наведений синфазний струм `I_CM_induced`, доходячи до приймального вузла, прикладається до вхідних імпедансів `Z₁` та `Z₂`. Якщо вхідні каскади мають навіть мінімальний розкид параметрів (`ΔZ = Z₁ - Z₂`), на вході диференційного підсилювача виникає паразитна диференційна напруга завади:

```
V_noise_DM = I_CM_induced · ΔZ
```

Здатність схеми протистояти такому наведенню вимірюється коефіцієнтом придушення синфазного сигналу (англ. *Common Mode Rejection Ratio, CMRR*):

```
CMRR = 20 · log₁₀(A_DM / A_CM)   [дБ]
```

Якщо на низьких частотах операційні підсилювачі та приймачі RS-485 мають CMRR порядку `70–90` дБ, то на частотах понад 10 МГц CMRR стрімко падає до `20–30` дБ через паразитарні ємності кристала й розводки, роблячи приймач беззахисним перед високочастотними завадами.

## Екранування кабелів та передавальний імпеданс

Найпоширенішим методом захисту від випромінювання та наведення завад є екранування кабелю — оточення внутрішніх провідників суцільною металевою трубкою або плетеною сіткою з мідних чи алюмінієвих дротиків.

Екран діє як бар'єр: він перехоплює струми зміщення електричного поля (відбиваючи та відводячи їх на шасі) та створює вихрові струми, магнітне поле яких протидіє зовнішньому магнітному полю за правилом Ленца.

### Передавальний імпеданс екрана (Transfer Impedance)

Кількісною характеристикою якості кабельного екрана є його передавальний імпеданс `Z_T` (англ. *surface transfer impedance*, від лат. *impedire* — перешкоджати). Він визначається як відношення падіння поздовжньої напруги на внутрішній поверхні екрана `dV_inner / dx` до повного струму завади `I_shield`, що протікає по зовнішній поверхні екрана:

```
Z_T = (1 / I_shield) · (dV_inner / dx)   [Ом/м або мОм/м]
```

Фізичний зміст `Z_T`: чим менший передавальний імпеданс, тим менша напруга завади наводиться на внутрішніх сигнальних жилах при протіканні струму по екрану, і тим менше поле випромінюється назовні.

Частотна залежність `Z_T(f)` має три характерні зони:

1. **Низькі частоти (DC — 100 кГц):** струм рівномірно розподілений по всій товщині стінки екрана. Передавальний імпеданс дорівнює активному омічному опору екрана постійному струму:
   ```
   Z_T ≈ R_dc
   ```
2. **Середні частоти (100 кГц — 10 МГц):** вмикається скин-ефект. Струм витісняється на зовнішню поверхню екрана. На внутрішній поверхні напруженість поля спадає експоненційно з товщиною стінки `t`:
   ```
   Z_T(f) = R_dc · (t / δ) / sinh(t / δ)
   ```
   де `δ = √(ρ / (π · f · μ))` — глибина скин-шару. Для суцільної металевої трубки `Z_T` на високих частотах прямує до нуля!
3. **Високі частоти (понад 10–30 МГц для плетених екранів):** у плетеному обплетенні між схрещеними дротиками існують мікроскопічні ромбічні отвори (оптичні апертури). Зовнішній магнітний потік просочується крізь ці отвори, створюючи взаємну індуктивність зв'язку `M_12`. Передавальний імпеданс починає зростати лінійно з частотою:
   ```
   Z_T(f) ≈ R_dc + j · ω · M_12
   ```

Детальні числові таблиці передавального імпедансу для різних конструкцій кабелів (RG-58, RG-214, Cat.6A S/FTP, Semi-Rigid) наведено у вставці [довідник передавального імпедансу екранів та норм випромінювання](root:com-medium/cable-emi/api-shield-transfer-impedance.md).

### Катастрофа «поросячого хвостика» (Pigtail Effect)

Найдорожчий екран із подвійним срібним обплетенням стає абсолютно марним, якщо його неправильно підключено до корпусу приладу.

![Порівняння кругового 360-градусного заземлення екрана та заземлення через «поросячий хвостик»](/root/com/com-medium/cable-emi/img/fig-shield-pigtail.svg)
*360-градусний металевий контакт забезпечує рівномірне стікання струму без витоку в сигнальний контур, тоді як паразитна індуктивність хвостика руйнує екранування на ВЧ.*

Поширена монтажна помилка — розплітання екрана біля роз'єму, скручування його в тонкий дріт («поросячий хвостик», англ. *pigtail*) довжиною `2–5` см і прикручування гвинтом до клеми заземлення.

Провідник довжиною `l = 25` мм і діаметром `1` мм має власну індуктивність приблизно `L_pigtail ≈ 25` нГн (емпіричне правило: близько `1` нГн на кожен міліметр довжини).

На частоті `f = 100` МГц реактивний імпеданс такого хвостика становить:

```
X_pigtail
= 2·π · f · L_pigtail                              [реактивний індуктивний опір провідника]
= 2 · 3.14159 · 100·10⁶ Гц · 25·10⁻⁹ Гн            [підстановка частоти 100 МГц та індуктивності 25 нГн]
≈ 15.7 Ом                                          [розрахунковий опір заземлення екрана]
```

Якщо по екрану протікає високочастотний струм завади всього `I_shield = 10` мА, на індуктивності хвостика виникає напруга:

```
V_drop = I_shield · X_pigtail = 0.01 А · 15.7 Ом = 0.157 В = 157 мВ
```

Ця напруга прикладається безпосередньо між екраном кабелю та корпусом пристрою. Увесь екран кабелю відносно шасі перетворюється на відкриту передавальну штирову антену, яка випромінює заваду з потужністю, що перевищує випромінювання неекранованого дроту. Крім того, магнітне поле струму хвостика пронизує оголені сигнальні жили, наводячи в них диференційні завади.

**Єдине правильне рішення:** круговий 360-градусний контакт екрана з металевим корпусом роз'єму (Backshell) за допомогою цангового затискача, обтискної мідної гільзи або пружинної контактної муфти. У такій конструкції паразитна індуктивність менша за `0.2` нГн, а струм стікає симетрично по периметру без проникнення полів у внутрішній об'єм роз'єму.

## Комплексні методи пригнічення випромінювання кабелів

Забезпечення електромагнітної сумісності вимагає узгодженого застосування схемотехнічних, конструктивних та компонентних заходів на всіх етапах проєктування.

```
       Джерело завади (TX)               Кабельна траса               Приймач (RX)
┌───────────────────────────────┐     ┌──────────────────┐     ┌───────────────────────┐
│ • Диференційний драйвер       │     │ • Вита пара      │     │ • Синфазний дросель   │
│ • Фільтрація фронтів (RC/фер.)│ ──► │ • Екран 360°     │ ──► │ • Симетричне навант.  │
│ • Контроль довжин ΔL < 0.5 мм │     │ • Траса вздовж   │     │ • Високий CMRR на ВЧ  │
│ • Суцільна площина GND        │     │   металоконструкц│     │ • Захисні діоди (TVS) │
└───────────────────────────────┘     └──────────────────┘     └───────────────────────┘
```

### 1. Симетрія та звивання провідників (Twisted Pair)

Звивання провідників з постійним кроком скрутки (наприклад, 50–70 витків на метр у кабелях Cat.6) забезпечує чергування просторової орієнтації кожної сусідньої напівпетлі. Зовнішнє однорідне магнітне поле наводить у сусідніх напівпетлях протилежні за знаком ЕРС, які взаємно компенсуються:

```
e_total = e₁ - e₂ + e₃ - e₄ ≈ 0
```

Для ефективної компенсації крок скрутки `p` повинен бути значно меншим за довжину хвилі завади (`p << λ / 20`).

### 2. Синфазні дроселі та феритові муфти

Синфазний дросель (Common Mode Choke) містить дві обмотки, намотані на спільному магнітному осерді з високою проникністю.

- Для протифазного корисного струму магнітні потоки двох обмоток спрямовані зустрічно і повністю компенсуються (`Φ_total = Φ₁ - Φ₂ = 0`). Індуктивність для корисного сигналу дорівнює нулю (за винятком мізерної індуктивності розсіювання `L_leak`), тому сигнал проходить без спотворень.
- Для синфазного струму завади магнітні потоки складаються (`Φ_total = Φ₁ + Φ₂ = 2·Φ`). Дросель створює великий послідовний індуктивний опір:
  ```
  Z_CM = j · ω · L_CM + R_loss(ω)
  ```

Феромагнітна муфта (феритова защіпка на кабелі) діє аналогічно: проходячи крізь отвір феритового циліндра, кабель утворює одновитковий синфазний трансформатор. На високих частотах (30–500 МГц) ферит із матеріалу NiZn (нікель-цинк) вносить значні магнітні втрати, перетворюючи енергію синфазного струму на тепло і додаючи `100–300` Ом активного опору в синфазний контур.

### 3. Правило просторового трасування (Image Plane Effect)

Прокладання кабелю у повітрі на великій відстані від металевих поверхонь створює величезну площу петлі між кабелем і землею повернення струму `A_CM`.

Якщо кабель прокладено впритул до заземленого металевого лотка, шасі приладу або корпусної металоконструкції, у металі наводиться дзеркальний струм протилежного напрямку. Цей дзеркальний струм компенсує поле кабелю на відстані, зменшуючи еквівалентну площу антени в десятки разів і знижуючи випромінювання на `20–35` дБ без жодних додаткових витрат.

## Інженерний приклад: аналіз та розрахунок придушення завад лінії

Розглянемо практичну задачу: промисловий інтерфейс передає дані по неекранованому кабелю довжиною `L = 2.0` м зі швидкістю фронту `t_r = 2.0` нс. Напруга живлення `V_cc = 3.3` В. Через асиметрію вихідного каскаду драйвера на кабелі виникає синфазна напруга `V_CM = 80` мВ на частоті гармоніки `f = 125` МГц. Хвильовий опір синфазної антени кабелю `Z_ant ≈ 180` Ом.

### Розрахунок 1. Випромінюване поле без захисту

Обчислимо синфазний струм у кабелі:

```
I_CM
= V_CM / Z_ant                                     [закон Ома для синфазного кола]
= 0.080 В / 180 Ом
≈ 4.444·10⁻⁴ А = 444.4 мкА                         [початковий синфазний струм]
```

Розрахуємо максимальне випромінюване поле на відстані `r = 10` м:

```
E_measured
= (1.257·10⁻⁶ · f · L · I_CM) / r                  [напруженість поля синфазного випромінювання]
= (1.257·10⁻⁶ · 125·10⁶ · 2.0 · 4.444·10⁻⁴) / 10  [підстановка параметрів системи]
= (1.257·10⁻⁶ · 2.5·10⁸ · 4.444·10⁻⁴) / 10        [множення частоти та довжини]
= (0.31425 · 4.444·10⁻⁴) / 10                      [проміжний добуток коефіцієнтів]
= 1.396·10⁻⁴ / 10                                  [обчислення чисельника]
= 1.396·10⁻⁵ В/м = 13.96 мкВ/м                     [абсолютна напруженість поля]
```

Переведемо напруженість поля в логарифмічні одиниці дБ(мкВ/м):

```
E_dB
= 20 · log₁₀(E_measured / 1 мкВ/м)                 [розрахунок у дБ щодо 1 мкВ/м]
= 20 · log₁₀(13.96)
= 20 · 1.1449
≈ 22.9 дБ(мкВ/м)                                   [рівень випромінювання]
```

Якщо лінія має додатковий перекіс затримок `Δt = 0.5` нс на роз'ємі, амплітуда синфазної завади зростає до `V_CM = 400` мВ, що дає:

```
I_CM_skew = 0.4 В / 180 Ом ≈ 2.22 мА
E_dB_skew = 22.9 + 20 · log₁₀(2.22 / 0.444) = 22.9 + 14.0 = 36.9 дБ(мкВ/м)
```

Норматив CISPR 32 Class B на частоті 125 МГц становить `30.0` дБ(мкВ/м). Рівень випромінювання перевищує допустимий на **`6.9 дБ`** — пристрій не проходить сертифікацію.

### Розрахунок 2. Встановлення феритового фільтра

Для усунення перевищення на кабель біля роз'єму встановлюється феритова муфта з NiZn, що має резистивний імпеданс `Z_ferrite = 220` Ом на частоті 125 МГц.

Новий синфазний струм становить:

```
I_CM_filtered
= V_CM / (Z_ant + Z_ferrite)                       [струм з урахуванням імпедансу фериту]
= 0.400 В / (180 Ом + 220 Ом)                      [додавання послідовного опору]
= 0.400 В / 400 Ом
= 1.00·10⁻³ А = 1.00 мА                            [знижений синфазний струм]
```

Зниження струму в децибелах (вносиме згасання, Insertion Loss):

```
IL_dB = 20 · log₁₀((180 + 220) / 180) = 20 · log₁₀(400 / 180) = 20 · 0.3468 ≈ 6.94 дБ
```

Новий рівень випромінюваного поля:

```
E_dB_final = 36.9 дБ(мкВ/м) - 6.94 дБ = 29.96 дБ(мкВ/м)
```

Додаткове переведення неекранованого кабелю на екранований із круговим закладенням 360° (передавальний імпеданс `Z_T = 0.05` Ом/м) зменшує випромінюване поле ще на `45–60` дБ, гарантуючи стійкий запас надійності понад `35` дБ до норм стандарту.

## Зведена таблиця правил боротьби з кабельними завадами

| Джерело / Механізм завади | Первинна фізична причина | Інженерне рішення першої лінії | Неприпустимі дії |
|---|---|---|---|
| **Синфазне випромінювання (CM)** | Підстрибування потенціалу землі драйвера (Ground Bounce), струм на шасі | Синфазний дросель біля роз'єму, феритова муфта NiZn, суцільна площина GND | Трасування ліній над розривами земляного полігону |
| **Перетворення мод (DM → CM)** | Фазовий перекіс довжин ліній (`ΔL`), нерівні паразитні ємності `ΔC` | Вирівнювання довжин трас із точністю < 0.2 мм, симетричний монтаж компонентів | Одностороннє розташування конденсаторів захисту TVS |
| **Протифазне випромінювання (DM)** | Велика площа сигнальної петлі `A = s · L` | Звивання провідників (Twisted Pair), мінімізація відстані `s`, розв'язувальні ємності | Прокладання прямого та зворотного проводів різними трасами |
| **Проникнення завад крізь екран** | Високий передавальний імпеданс `Z_T`, оптичні щілини обплетення | Кабель із подвійним екраном (фольга + плетінка з покриттям > 85%) | Використання дешевого аудіокабелю з рідким спіральним екраном |
| **Втрата екранування на роз'ємі** | Паразитна індуктивність кінцевого закладення `L_pigtail` | 360-градусний металевий Backshell або цангова затискна муфта на шасі | Заземлення екрана скрученим дротиком («поросячим хвостиком») на пін |
| **Наведення від сусідніх ліній (Crosstalk)** | Велика площа петлі відносно шасі | Трасування кабелів упритул до металевого шасі або в заземлених лотках | Підвішування кабельних джгутів у повітрі паралельно до силових шин |
