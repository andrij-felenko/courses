# 🧮 Геометрія параболи, фазова когерентність та діаграма випромінювання

Цей математичний аналіз виводить фундаментальні геометричні та електродинамічні властивості параболічного рефлектора. Ми доведемо строгу рівність оптичних шляхів від фокуса до апертурної площини, виведемо векторні закони відбиття хвилі, обчислимо апертурний інтеграл Фраунгофера для кругової апертури з спаданням поля та статистично обґрунтуємо формулу Рузе для втрат підсилення через дефекти поверхні.

---

### 1. Строгий вивід сталості оптичного шляху

Розглянемо канонічне рівняння параболи у меридіональному перерізі `(r, z)`, де `z` — оптична вісь рефлектора, а `r = √(x² + y²)` — радіальна відстань від осі обертання.

Вершина параболоїда розташована в початку координат `(0, 0)`, а фокус `F` має координати `(0, f)`, де `f` — фокусна відстань.

Рівняння поверхні параболоїда має вигляд:
```
z = r² / (4·f)
```

Нехай точкове джерело (опромінювач) розташоване у фокусі `F(0, f)`. Довільний промінь випромінюється з фокуса під кутом `θ` до осі `z`, падає на поверхню рефлектора в точці `P(r, z)` і відбивається у напрямку, паралельному осі `z`, перетинаючи апертурну площину `z = z₀` (де `z₀ > z_max`) у точці `P'(r, z₀)`.

Обчислимо повну довжину оптичного шляху `L(r)` від фокуса `F` через точку відбиття `P` до апертурного екрана `P'`:

```
L(r) = |FP| + |PP'|
```

1. Обчислимо евклідову відстань від фокуса `F(0, f)` до точки на рефлекторі `P(r, z)`:

```
|FP|² = r² + (z - f)²
```

Підставимо вираз для `r² = 4·f·z` з рівняння параболи:

```
|FP|² = 4·f·z + (z² - 2·f·z + f²)   [підстановка r² = 4·f·z]
      = z² + 2·f·z + f²             [зведення подібних доданків]
      = (z + f)²                    [квадрат суми: (a + b)²]
```

Отже, відстань від фокуса до будь-якої точки параболоїда дорівнює:

```
|FP| = z + f
```

2. Обчислимо відстань від точки відбиття `P(r, z)` до площини апертури `z = z₀`:

```
|PP'| = z₀ - z
```

3. Знайдемо сумарну довжину оптичного шляху `L(r)`:

```
L(r) = |FP| + |PP'|                [сума відрізків оптичного шляху]
     = (z + f) + (z₀ - z)          [підстановка |FP| = z + f та |PP'| = z₀ - z]
     = f + z₀                      [скорочення z та -z]
```

**Висновок**: Повна довжина оптичного шляху `L(r) = f + z₀` **є строго константою** і не залежить від радіальної координати `r` точки відбиття!

Оскільки фазовий набіг електромагнітної хвилі дорівнює `φ = k·L = (2·π / λ)·L`, однаковий оптичний шлях гарантує, що всі промені приходять на площину апертури `z = z₀` з **абсолютно однаковою фазою**. Сферичний хвильовий фронт, що виходить з фокуса, після відбиття перетворюється на строго плоский синфазний фронт.

### 2. Векторний закону відбиття та кут охоплення розкриву

Перевіримо векторну форму закону відбиття Снелліуса для параболічної поверхні. 

Поверхня параболоїда задається неявною функцією `S(x, y, z) = x² + y² - 4·f·z = 0`. Вектор нормалі `n` до поверхні у точці `P(x, y, z)` пропорційний градієнту `∇S`:

```
n = (x / (2·f),  y / (2·f),  -1)
```

Нормалізований одиничний вектор нормалі має вигляд:

```
n_hat = n / |n| = (x, y, -2·f) / √(r² + 4·f²)
```

Одиничний вектор падаючого променю з фокуса `F(0,0,f)` до точки `P(x,y,z)` дорівнює:

```
v_i = (P - F) / |PF| = (x, y, z - f) / (z + f)
```

Згідно з векторним законом відбиття `v_r = v_i - 2·(v_i · n_hat)·n_hat`. Обчисливши скалярний добуток `v_i · n_hat`, отримуємо:

```
v_i · n_hat = - √(z / (z + f))
```

Підставивши це у формулу для відбитого вектора `v_r`, маємо:

```
v_r = (0, 0, 1)
```

**Висновок**: Відбитий вектор `v_r` строго паралельний оптичній осі `Z` для будь-якої точки поверхні `(x, y, z)`.

#### Кут охоплення країв рефлектора (Subtense Angle)
Максимальний кут `ψ_e`, під яким край тарілки видно з фокуса `F`, визначається через відношення фокусної відстані до діаметра `f / D`:

```
tan(ψ_e / 2) = D / (4·f)  →  ψ_e = 2 · arctan [ 1 / (4 · f/D) ]
```

Для глибоких тарілок (`f/D = 0.25`) край видно під кутом `ψ_e = 180°` (півсфера). Для дрібних офсетних тарілок (`f/D = 0.6`) кут охоплення становить `ψ_e ≈ 90°`.

### 3. Діаграма випромінювання кругової апертури (Дифракційне наближення)

Згідно з принципом Гюйгенса-Френеля та інтегралом дифракції Фраунгофера, дальнє поле випромінювання кругової апертури радіуса `R = D / 2` з розподілом амплітуди по апертурі `E_a(r)` описується двовимірним перетворенням Фур’є.

Для симетричного розподілу поля `E_a(r)` комплексний амплітудний розподіл у далекому полі під кутом `θ` від осі дорівнює:

```
E(θ) = 2·π · ∫₀ʳ E_a(r) · J₀(k·r·sin θ) · r dr
```

де `J₀` — функція Бесселя першого роду нульового порядку, `k = 2·π / λ`.

#### Випадок 1: Рівномірне опромінення (E_a(r) = E₀ = const)

Ввівши безрозмірну кутову змінну:

```
u = k·R·sin θ = (π·D / λ)·sin θ
```

Інтеграл зводиться до відомого співвідношення для бесселевих функцій `∫ x·J₀(x) dx = x·J₁(x)`:

```
E(u) = E₀ · (π·R²) · [ 2·J₁(u) / u ]
```

Нормована діаграма спрямованості за напругою має вигляд:

```
F(u) = 2·J₁(u) / u
```

Нормована діаграма за потужністю (в лінійному масштабі):

```
P(u) = | 2·J₁(u) / u |²
```

#### Характеристики нормованої діаграми `F(u)`:
1. **Перший нуль діаграми**: відповідає першому кореню функції Бесселя `J₁(u₁) = 0`, де `u₁ ≈ 3.8317`.
   
```
sin θ_null = u₁ / (π·D / λ) 
           ≈ 3.8317 / (π·D / λ) 
           ≈ 1.22 · (λ / D)
```

Для малих кутів `θ_null ≈ 1.22 · (λ / D)` рад (це класична межа дифракції Релея).

2. **Ширина променя за рівнем половини потужності (HPBW, -3 dB)**:
   Рівняння `| 2·J₁(u_3dB) / u_3dB |² = 0.5` має корінь `u_3dB ≈ 1.616`.

```
θ_3dB = 2 · arcsin( u_3dB / (π·D / λ) )
      ≈ 2 · (1.616 / π) · (λ / D)
      ≈ 1.029 · (λ / D)  рад
      ≈ 58.9° · (λ / D)
```

3. **Рівень першої бічної пелюстки**:
   Перший максимум функції `J₁(u) / u` за межами головного нуля лежить при `u ≈ 5.1356`, де `|F(u)| ≈ 0.1323`.
   У децибелах відносно головного максимуму:

```
SLL = 20 · log₁₀(0.1323) ≈ -13.26 dB
```

#### Випадок 2: Параболічно-квадратичне спадання опромінення

Для опису реального спадання поля від центру апертури до країв використовують функцію:

```
E_a(r) = E₀ · [ 1 - τ · (r / R)² ]ⁿ
```

де `τ` — коефіцієнт спадання амплітуди на краю (наприклад, `τ = 0.7`), `n` — степеневий показник плавності.

Застосовуючи теорему про дифракцію для спадаючого поля, нормована діаграма спрямованості бере вигляд узагальнених бесселевих функцій:

```
F(u, n) = 2ⁿ⁺¹ · n! · [ Jₙ₊₁(u) / uⁿ⁺¹ ]
```

При збільшенні спадання `τ`:
- Рівень бічних пелюсток пригнічується з `-13.2 dB` до **-24.7 dB** (при `n = 1`, `τ = 0.75`).
- Ширина головної пелюстки розширюється від `58.9° · (λ/D)` до **70° · (λ/D)**.
- Коефіцієнт апертурної ефективності `η_i` досягає оптимального компромісного значення.

### 4. Статистичний вивід формули Рузе (Ruze's Law)

Реальне дзеркало параболічної антени має відхилення від ідеальної параболічної форми `ε(x, y)` внаслідок погрешностей виготовлення, температурного розширення та вітрового навантаження.

Припустимо, що відхилення поверхні `ε(x, y)` є випадковим гауссовим полем із нульовим середнім `⟨ε⟩ = 0` та дисперсією `σ_ε² = ε_rms²`.

При відбитті від поверхні з локальною помилкою висоти `ε` промінь проходиться додатковий шлях `2·ε·cos θ_i` (для параболоїдів із великим `f/D` кут падіння `θ_i ≈ 0`, тому додатковий шлях `ΔL ≈ 2·ε`).

Локальна фазова помилка відбитої хвилі на апертурі дорівнює:

```
Δφ(x, y) = k · ΔL = (2·π / λ) · (2·ε) = (4·π·ε / λ)
```

Дисперсія фазової помилки дорівнює:

```
σ_φ² = ⟨Δφ²⟩ = (4·π · ε_rms / λ)²
```

Когерентне поле у центрі головної пелюстки є сумою випадкових фазових векторів по всій площі апертури `A`:

```
E_max = (1 / A) · ∬_A E₀ · exp(j·Δφ(x, y)) dx dy
```

Математичне сподівання комплексного поля для Гауссового розподілу фази `Δφ` визначається характеристичною функцією:

```
⟨exp(j·Δφ)⟩ = exp( -σ_φ² / 2 )
```

Отже, середнє когерентне поле зменшується у множник `exp(-σ_φ² / 2)`:

```
⟨E_max⟩ = E₀ · exp[ -1/2 · (4·π·ε_rms / λ)² ]
```

Оскільки коефіцієнт підсилення пропорційний квадрат модуля поля `G ∝ |E_max|²`, ефективність Рузе `η_r = G_real / G_ideal` становить:

```
η_r = | ⟨E_max⟩ / E₀ |²                      [визначення ефективності як відношення квадратів амплітуд]
    = { exp[ -1/2 · (4·π·ε_rms / λ)² ] }²     [підстановка виразу для ⟨E_max⟩]
    = exp[ - (4·π·ε_rms / λ)² ]              [піднесення експоненти до квадрата]
```

Це і є класична **формула Рузе** (John Ruze, 1966).

#### Розрахунок граничної частоти:
Зі збільшенням частоти `f` довжина хвилі `λ = c / f` зменшується, і відносне значення `ε_rms / λ` зростає. 

Повний коефіцієнт підсилення з урахуванням формули Рузе дорівнює:

```
G(f) = η_a0 · (π · D · f / c)² · exp[ - (4·π · ε_rms · f / c)² ]
```

Візьмемо похідну за частотою `dG/df = 0` та знайдемо частоту `f_max`, при якій підсилення досягає абсолютного максимуму:

```
f_max = c / (4·π · ε_rms)
```

На цій частоті `λ_min = 4·π · ε_rms ≈ 12.57 · ε_rms`, а спад підсилення внаслідок шорсткості становить `exp(-1) ≈ 0.368` (тобто втрата `-4.34 dB`). Подальше підвищення частоти призводить не до зростання підсилення, а до його стрімкого падіння до нуля через фазову декогерентність.
