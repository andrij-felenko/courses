# 🧮 Математичне виведення полів диполя та вектора Пойнтінга у зонах

Математичний аналіз просторової структури електромагнітного поля, яке випромінюється змінними струмами та зарядами, базується на розв'язку неоднорідного хвильового рівняння для електромагнітних потенціалів. У цьому матеріалі наведено детальне виведення полів гармонічного електричного диполя, дослідження асимптотики полів у реактивній ближній та хвильовій далекій зонах, обчислення комплексного вектора Пойнтінга, розрахунок випроміненої потужності за формулою Лармора, аналіз закону збереження енергії, розклад по сферичних гармоніках, математичну теорію NFTFF, а також порівняльний математичний аналіз дуальної магнітної рамки.

---

### 1. Потенціали Герца та виведення точних полів елементарного диполя

Розглянемо точковий елементарний електричний диполь довжиною `L` (значно меншою за довжину хвилі `λ`), розташований у початку координат і орієнтований вздовж осі `z`. Електричний дипольний момент змінюється за гармонічним законом:

```
p(t) = p₀ · e⁻ⁱʷᵗ
```

де `p₀ = q₀ · L` — амплітуда дипольного моменту, `q₀` — амплітуда перенесеного електричного заряду на кінцях диполя, а `ω` — колова частота коливань джерела.

У канонічному калібруванні Лоренца (`div A + (1/c²) ∂φ/∂t = 0`) хвильові рівняння для скалярного потенціалу `φ` та векторного потенціалу `A` у вільному просторі мають відомий неоднорідний вигляд:

```
∇² φ - (1/c²) · (∂²φ / ∂t²) = - ρ / ε₀                             [хвильове рівняння скалярного потенціалу]
∇² A - (1/c²) · (∂²A / ∂t²) = - μ₀ · J                              [хвильове рівняння векторного потенціалу]
```

Для математичного аналізу випромінювання дипольних систем надзвичайно зручно ввести єдиний електричний векторний потенціал Герца `П_z(r, t)`. Скалярний та векторний потенціали електромагнітного поля виражаються через вектор Герца за допомогою двох базових співвідношень:

```
A = (1/c²) · (∂П / ∂t)                                             [визначення A через потенціал Герца]
φ = - div П                                                       [визначення φ через потенціал Герца]
```

Завдяки цьому введенню рівняння Лоренца автоматично задовольняються, а вектор Герца відповідає точечному хвильовому рівнянню. Для точкового диполя розв'язок має вигляд сферичної хвилі із запізнюванням:

```
П_z(r, t) = (p₀ / (4π · ε₀ · r)) · eⁱ⁽ᵏʳ ⁻ ʷᵗ⁾                       [розв'язок хвильового рівняння із запізнюванням]
```

де `k = ω/c = 2π/λ` означає хвильове число у вільному просторі, а `r` — геометричну відстань від диполя до спостерігача. Фізичний зміст експоненціального множника `eⁱᵏʳ` полягає у врахуванні скінченної швидкості поширення взаємодії: стан поля у точці `r` у момент часу `t` визначається станом джерела у запізнений момент часу `t' = t - r/c`.

Напруженість магнітного поля `H` обчислюється як ротор похідної потенціалу Герца `H = ε₀ · rot (∂П / ∂t)`, а напруженість електричного поля `E` — через подвійний ротор `E = rot (rot П)` за тотожністю векторного аналізу:

```
E = ∇(∇ · П) - ∇² П = ∇(∇ · П) + k² П                             [подвійний ротор векторного потенціалу]
```

Використовуючи сферичну систему координат `(r, θ, φ)`, у якій полярний кут `θ` відраховується від осі диполя `z`, та зважаючи на осесиметрію відносно `z` (`∂/∂φ = 0`), ми бачимо, що складові `E_φ = 0`, `H_r = 0` та `H_θ = 0`. 

Виконання диференціальних операцій векторного аналізу у сферичних координатах дає такі точні вирази для трьох відмінних від нуля складових електромагнітного поля:

```
E_r = (p₀ · cos θ / (2π · ε₀)) · eⁱ⁽ᵏʳ ⁻ ʷᵗ⁾ · ( 1/r³ - i·k/r² )

E_θ = (p₀ · sin θ / (4π · ε₀)) · eⁱ⁽ᵏʳ ⁻ ʷᵗ⁾ · ( 1/r³ - i·k/r² - k²/r )

H_φ = (ω · p₀ · sin θ / (4π)) · eⁱ⁽ᵏʳ ⁻ ʷᵗ⁾ · ( k/r + i/r² )
```

Аналізуючи математичну структуру отриманих виразів, зверніть увагу на відмінність доданків у дужках:
* Радіальне електричне поле `E_r` містить доданки зі спаданням `1/r³` та `1/r²`. Воно прямо пов'язане з розділенням зарядів на кінцях випромінювача.
* Меридіональне електричне поле `E_θ` містить три доданки: `1/r³`, `1/r²` та `1/r`.
* Азимутальне магнітне поле `H_φ` містить два доданки: `1/r²` та `1/r`.

Перший член `1/r³` відповідає квазістатичному кулонівському полю зарядів, другий член `1/r²` — індукційному полю змінних струмів, а третій член `1/r` описує випромінену електромагнітну хвилю, яка здатна поширюватися на нескінченність.

### 2. Асимптотичний розклад у реактивній ближній зоні (k·r ≪ 1)

Розглянемо асимптотичну поведінку полів у безпосередній близькості від випромінювача. Коли відстань `r` значно менша за радіанну довжину хвилі (`r ≪ λ / (2π)`), це відповідає безрозмірній математичній умові `k·r ≪ 1`.

У цьому випадку степені `1/r³` та `1/r²` у знаменниках виразів переважають над хвильовим членом `1/r`. Зберігаючи у математичних виразах тільки основні за величиною доданки з найвищими степенями `1/r`, ми отримуємо границеві формули реактивної ближньої зони:

```
E_r  ≈ (2 · p₀ · cos θ / (4π · ε₀ · r³)) · e⁻ⁱʷᵗ                      [наближення k·r ≪ 1: домінує член 1/r³]
E_θ  ≈ (p₀ · sin θ / (4π · ε₀ · r³)) · e⁻ⁱʷᵗ                          [наближення k·r ≪ 1: домінує член 1/r³]
H_φ  ≈ i · (ω · p₀ · sin θ / (4π · r²)) · e⁻ⁱʷᵗ                       [наближення k·r ≪ 1: домінує член i/r²]
```

#### Фазовий зсув на 90° та відсутність незворотного випромінювання
Зверніть увагу на множник `i = eⁱᵖⁱ/²` у виразі для азимутального магнітного поля `H_φ`. У комплексному математичному аналізі гармонічних коливань множення на уявну одиницю `i` відповідає зсуву фази коливань у часі на `90°` (`π/2` радіан). 

Це означає фундаментальну фізичну властивість: у будь-який момент часу, коли електричне поле `E` досягає свого максимуму, магнітне поле `H` у ближній зоні точно прямує до нуля, і навпаки.

Обчислимо комплексний вектор Пойнтінга `S = (1/2) · (E × H*)`, який визначає напрямок та густину потоку електромагнітної енергії:

```
S_r = (1/2) · E_θ · H_φ*                                              [визначення радіального потоку енергії]
    = (1/2) · [ p₀ sin θ / (4π ε₀ r³) ] · [ -i ω p₀ sin θ / (4π r²) ]    [підстановка полів ближньої зони]
    = -i · (ω · p₀² · sin² θ / (32 · π² · ε₀ · r⁵))                      [перемноження та виділення уявного множника]
```

Оскільки радіальна складова вектора Пойнтінга `S_r` виявилася чисто уявною величиною (`Re(S_r) = 0`), середній за періодом дійсний потік енергії через будь-яку сферичну поверхню у ближній зоні дорівнює нулю:

```
⟨ P_дійсне ⟩ = Re ∮ S_r · dA = 0                                       [середній потік енергії дорівнює нулю]
```

Математичний висновок `Re(S_r) = 0` означає, що у реактивній ближній зоні енергія не випромінюється незворотно у простір. Натомість енергія циркулює назад і вперед між електричним та магнітним полями диполя.

#### Реактивне накопичення енергії та фундаментальна межа Чу-Харрінгтона
Енергія у ближній зоні накопичується у просторі довкола антени. Усереднена за часом густина електричної та магнітної енергій дорівнює:

```
w_e = (1/4) · ε₀ · |E|²                                               [густина електричної енергії]
w_m = (1/4) · μ₀ · |H|²                                               [густина магнітної енергії]
```

Повна реактивна енергія `W_R = ∫ (w_e + w_m) dV`, накопичена у ближній зоні, виступає як навантаження для випромінювача. Відношення цієї реактивної енергії до випроміненої потужності визначає добротність антени `Q`. 

З математичного розкладу випливає фундаментальна межа Чу-Харрінгтона (Chu-Harrington limit) для мінімально можливої добротності `Q_min` будь-якої електрично малої антени з габаритним радіусом `a` (`k·a < 1`):

```
Q_min = 1 / (k·a)³ + 1 / (k·a)                                         [найнижча фізично можлива добротність]
```

Зменшення фізичних розмірів антени `a` призводить до того, що накопичена реактивна енергія зростає як `1/(k·a)³`. Це математично доводить, що електрично малі антени неминуче мають вузьку смугу робочих частот та високі реактивні втрати.

### 3. Асимптотичний розклад у хвильовій далекій зоні (k·r ≫ 1)

Розглянемо протилежний випадок — поведінку полів на великих відстанях від випромінювача, коли `r ≫ λ / (2π)`, що відповідає безрозмірній математичній умові `k·r ≫ 1`.

У далекій зоні доданки зі згасанням `1/r³` та `1/r²` у знаменниках прямують до нуля набагато швидше, ніж радіаційний член `1/r`. Наприклад, при збільшенні відстані `r` у `1000` разів член `1/r³` зменшується в `1 000 000 000` разів, член `1/r²` — у `1 000 000` разів, а радіаційний член `1/r` — лише у `1000` разів.

Тому у підсумкових виразах далекого поля залишаються виключно радіаційні члени, пропорційні `1/r`:

```
E_r  → 0                                                              [гранична умова k·r ≫ 1: член 1/r² згасає]
E_θ  ≈ - (p₀ · k² · sin θ / (4π · ε₀ · r)) · eⁱ⁽ᵏʳ ⁻ ʷᵗ⁾             [гранична умова k·r ≫ 1: домінує член k²/r]
H_φ  ≈ (ω · p₀ · k · sin θ / (4π · r)) · eⁱ⁽ᵏʳ ⁻ ʷᵗ⁾                  [гранична умова k·r ≫ 1: домінує член k/r]
```

#### Математичні властивості далекої електромагнітної хвилі
1. **Поперечна структура хвилі (TEM):** Радіальне електричне поле `E_r` згасає пропорційно `1/r²` і у далекій зоні прямує до нуля. Вектори `E_θ`, `H_φ` та напрямок поширення хвилі `r` утворюють праву трійку взаємно перпендикулярних векторів.
2. **Сінфазність коливань:** Вирази для `E_θ` та `H_φ` містять однакову часову експоненту `eⁱ⁽ᵏʳ ⁻ ʷᵗ⁾` без додаткових уявних одиниць. Це доводить, що у далекій зоні вектори `E` та `H` коливаються строго в однаковій фазі, одночасно проходячи через нулі та максимуми.

Знайдемо хвильовий імпеданс середовища як відношення амплітуд полів у далекій зоні:

```
Z = |E_θ| / |H_φ|                                                     [визначення хвильового опору]
  = [ (p₀ k² sin θ) / (4π ε₀ r) ] / [ (ω p₀ k sin θ) / (4π r) ]       [підстановка амплітуд полів]
  = k / (ω · ε₀)                                                      [скорочення спільних множників]
  = (ω / c) / (ω · ε₀)                                                [заміна хвильового числа k = ω/c]
  = 1 / (c · ε₀)                                                      [скорочення колової частоти ω]
  = √(μ₀ / ε₀)                                                        [підстановка швидкості світла c = 1/√(ε₀ μ₀)]
  ≈ 376.73 Ом ≈ 120π Ом                                               [обчислення хвильового опору вакууму]
```

Обчислимо дійсний потік енергії далекого поля. Дійсна частина вектора Пойнтінга є строго додатною величиною:

```
S_r = (1/2) · Re(E_θ · H_φ*)                                           [обчислення дійсного потоку енергії]
    = (1/2) · |E_θ|² / Z₀                                             [заміна H_φ = E_θ / Z₀]
    = (c · k⁴ · p₀² · sin² θ / (32 · π² · ε₀ · r²))                    [підстановка амплітуди E_θ]
```

Результат показує, що густина потоку випроміненої енергії спадає обернено пропорційно квадрату відстані `1/r²`. Це є прямим математичним наслідком збереження енергії для сферичної хвилі у тривимірному евклідовому просторі.

### 4. Повний розрахунок випроміненої потужності та опору випромінювання

Щоб обчислити повну електромагнітну потужність `P`, випромінену диполем у навколишній простір, зінтегруємо дійсний вектор Пойнтінга `S_r` по всій поверхні замкненої сфери радіуса `r`:

```
P = ∮ S_r · dA                                                        [потік вектора Пойнтінга через сферу]
  = ∫₀²ᵖⁱ dφ ∫₀ᵖⁱ S_r · r² · sin θ dθ                                  [перехід до сферичних координат]
  = (c · k⁴ · p₀² / (32 · π² · ε₀)) · 2π · ∫₀ᵖⁱ sin³ θ dθ              [винесення констант та інтегрування за φ]
```

Для обчислення кутового інтеграла `∫₀ᵖⁱ sin³ θ dθ` застосуємо тригонометричну заміну:

```
∫₀ᵖⁱ sin³ θ dθ = ∫₀ᵖⁱ (1 - cos² θ) d(-cos θ)                          [заміна змінної u = cos θ]
               = [ -cos θ + (cos³ θ)/3 ]₀ᵖⁱ                           [обчислення первісної]
               = (1 - 1/3) - (-1 + 1/3) = 4/3                          [взяття граничних значень]
```

Підставляємо розраховане значення кутового інтеграла `4/3` у формулу повної потужності:

```
P = (c · k⁴ · p₀² / (32 · π² · ε₀)) · 2π · (4/3)                      [підстановка результату кутового інтеграла]
  = k⁴ · p₀² · c / (12 · π · ε₀)                                       [скорочення чисельника і знаменника]
  = μ₀ · ω⁴ · p₀² / (12 · π · c)                                       [заміна k = ω/c та c² = 1/(ε₀ μ₀)]
```

Отриманий підсумковий вираз `P = (μ₀ · ω⁴ · p₀²) / (12 · π · c)` являє собою класичну **формулу Лармора** для випромінювання електричного диполя. 

Зауважте важливу математичну деталь: радіус сфери `r` повністю скоротився під час інтегрування. Це строго доводить, що повний потік випроміненої енергії через будь-яку концентричну сферу у далекій зоні є величиною постійною (`P = const`), що повністю узгоджується із диференціальним законом збереження електромагнітної енергії (теоремою Пойнтінга):

```
div S + ∂w/∂t = - J · E                                               [диференціальна форма закону збереження енергії]
```

Запишемо потужність через діюче значення струму `I_rms = I₀ / √2` в антені, враховуючи співвідношення між зарядом і струмом `p₀ = (I₀ / ω) · L`:

```
P = I_rms² · R_випр                                                   [визначення еквівалентного опору випромінювання]
```

Звідси обчислюємо **опір випромінювання** `R_випр` елементарного диполя:

```
R_випр = (2 · P) / I₀²                                                [визначення опору випромінювання]
       = (2 / I₀²) · [ μ₀ · ω⁴ · (I₀ · L / ω)² / (12 · π · c) ]        [підстановка p₀ = I₀ L / ω]
       = μ₀ · ω² · L² / (6 · π · c)                                   [скорочення I₀² та частоти ω²]
       = (2π / 3) · Z₀ · (L / λ)²                                     [заміна ω/c = 2π/λ та μ₀ c = Z₀]
       ≈ 80 · π² · (L / λ)² Ом                                        [підстановка хвильового опору вакууму Z₀ = 120π]
```

Для елементарного диполя довжиною `L = 0.1 · λ` опір випромінювання становить `R_випр ≈ 80 · π² · (0.1)² ≈ 7.9 Ом`. Цей опір виступає як еквівалентний активний опір, що визначає ефективність перетворення електричної енергії струму у випромінену хвилю.

### 5. Повний розклад по сферичних гармоніках для довільних джерел

Для випромінювачів складної геометричної форми (наприклад, апертурних антен чи антенних решіток) точний розклад полів у ближній та далекій зонах виконують за допомогою розкладу по сферичних хвильових функціях (сферичних гармоніках `Y_lm(θ, φ)` та сферичних функціях Бесселя й Ханкеля `h_l⁽¹⁾(kr)`):

```
E(r, θ, φ) = ∑ₗ ∑ₘ [ aₗₘ · Mₗₘ⁽¹⁾(kr, θ, φ) + bₗₘ · Nₗₘ⁽¹⁾(kr, θ, φ) ]   [розклад полю за сферичними векторами-гармоніками]
```

У цьому математичному розкладі векторні гармонічні функції `M_lm` описують поперечно-електричні (TE) моменти випромінювання, а векторні функції `N_lm` — поперечно-магнітні (TM) моменти випромінювання.

Сферичні функції Ханкеля першого роду `h_l⁽¹⁾(kr)` описують вихідні сферичні хвилі, що поширюються від джерела до нескінченності. Асимптотична поведінка функцій Ханкеля при різних значеннях аргументу `kr` чітко розкриває математичну природу зон поля:

* **Ближня реактивна зона (`kr ≪ 1`):** Сферичні функції Ханкеля прямують до асимптотики степеня `(kr)⁻⁽ˡ⁺¹⁾`. Для дипольного випромінювання (`l=1`) це дає кулонівське згасання полів `1/r³`. Для квадрупольного випромінювання (`l=2`) поле у ближній зоні згасає ще стрімкіше — пропорційно `1/r⁴`. Для октупольного моменту (`l=3`) поле ближньої зони спадає як `1/r⁵`.
* **Далека хвильова зона (`kr ≫ 1`):** Незалежно от порядку мультиполя `l`, усі сферичні функції Ханкеля прямують до універсальної асимптотики хвилі:
  ```
  h_l⁽¹⁾(kr) → (-i)ˡ⁺¹ · (eⁱᵏʳ / (k·r))                               [універсальна асимптотика хвилі далекого поля]
  ```
Це математично доводить, що у далекій зоні випромінювання будь-яких складно впорядкованих джерел та мультиполів вищого порядку (диполів, квадруполів, октуполів) завжди прямує до єдиного співвідношення згасання `1/r`.

### 6. Перетворення полів з ближньої зони у далеку (NFTFF)

Математичний алгоритм Near-Field to Far-Field Transformation спирається на еквівалентну теорему екстраполяції Пойнтінга-Гюйгенса. Якщо виміряти поверхневі розподіли електричного та магнітного полів `E_s` та `H_s` на замкненій поверхні `S`, що охоплює антену у ближній зоні, еквівалентні поверхневі електричні та магнітні струми дорівнюють:

```
J_s = n × H_s                                                         [еквівалентний електричний поверхневий струм]
M_s = - n × E_s                                                       [еквівалентний магнітний поверхневий струм]
```

де `n` — зовнішній вектор нормалі до поверхні вимірювання `S`.

Потім шляхом обчислення векторних потенціалів випромінювання `N` та `L` через поверхневі інтеграли Дюамеля:

```
N = ∬_S J_s · eⁱᵏ⁽ʳ'·r̂⁾ dS
L = ∬_S M_s · eⁱᵏ⁽ʳ'·r̂⁾ dS
```

комп'ютер здійснює точний аналітичний перерахунок амплітуд та фаз у далеке поле, обчислюючи діаграму напрямленості `E_far(θ, φ)` без проведення вимірювань на гігантських відстанях межі Фраунгофера.

### 7. Математичний аналіз фазових інтегралів Френеля

У проміжній зоні для прямокутних чи круглих апертур обчислення напруженості поля уздовж осі поширення вимагає розрахунку інтегралів Френеля `C(w)` та `S(w)`:

```
C(w) = ∫₀ʷ cos(π t² / 2) dt
S(w) = ∫₀ʷ sin(π t² / 2) dt
```

Амплітуда поля уздовж осі апертури розраховується як спіраль Клотоети (спіраль Ейлера-Френеля). Осциляції поля у проміжній зоні відповідають виткам спіралі, а перехід у далеку зону Фраунгофера прямує до асимптотичної точки сходу спіралі на нескінченності, де фазова похибка `Δφ` спадає нижче `π/8`.

### 8. Порівняльна математична таблиця характеристик полів у зонах

Для підсумкового систематичного порівняння математичних властивостей полів у різних зонах простору зведемо ключові співвідношення для електричного диполя та магнітної рамки у таблицю:

| Фізичний параметр / Зона | Ближня реактивна зона (`kr ≪ 1`) | Проміжня зона Френеля (`kr ≈ 1`) | Далека хвильова зона (`kr ≫ 1`) |
| :--- | :--- | :--- | :--- |
| **Домінуюча складова полів** | `E ~ 1/r³`, `H ~ 1/r²` | `E, H ~ 1/r²` та `1/r` | `E, H ~ 1/r` |
| **Фазовий зсув між E та H** | `90°` (квадратура в часі) | Змінюється від `90°` до `0°` | `0°` (строга синфазність) |
| **Вектор Пойнтінга S** | Чисто уявний (`Re(S) = 0`) | Комплексний (`Re(S) > 0`, `Im(S) ≠ 0`) | Чисто дійсний (`S > 0`, спадає `1/r²`) |
| **Хвильовий опір Z = E/H (диполь)**| `Z ≫ Z₀` (High Impedance) | `Z` залежить від відстані | `Z = Z₀ = 377 Ом` |
| **Хвильовий опір Z = E/H (рамка)** | `Z ≪ Z₀` (Low Impedance) | `Z` залежить від відстані | `Z = Z₀ = 377 Ом` |
| **Структура хвильового фронту** | Пов'язане квазістатичне поле | Формування хвильового фронту | Поперечна `TEM` хвиля (`E ⊥ H ⊥ k`) |

Математичний закон збереження імпульсу та тензор напружень Максвелла `T_ij` доводять, що у реактивній ближній зоні механічний тиск електромагнітного поля на сторонній заряд є зв'язаним квазістатичним, тоді як у далекій зоні тиск випромінювання прямо дорівнює `P_rad = S / c`.

### 9. Дуальне виведення для малої магнітної рамки

Для порівняння математичної структури полів розглянемо дуальне випромінювальне джерело — малу круглу магнітну рамку радіуса `a` та площі `A = π a²`, по якій протікає гармонічний струм `I(t) = I₀ · e⁻ⁱʷᵗ`. Магнітний дипольний момент дорівнює `m₀ = I₀ · A`.

Використовуючи магнітний векторний потенціал Герца `П_m`, ми отримуємо точні математичні вирази для полів рамки у сферичних координатах:

```
H_r = (m₀ · cos θ / (2π)) · eⁱ⁽ᵏʳ ⁻ ʷᵗ⁾ · ( 1/r³ - i·k/r² )

H_θ = (m₀ · sin θ / (4π)) · eⁱ⁽ᵏʳ ⁻ ʷᵗ⁾ · ( 1/r³ - i·k/r² - k²/r )

E_φ = - (Z₀ · k · m₀ · sin θ / (4π)) · eⁱ⁽ᵏʳ ⁻ ʷᵗ⁾ · ( k/r + i/r² )
```

Порівняльний аналіз виразів для електричного та магнітного диполів наочно демонструє дуальну симетрію рівнянь Максвелла (принцип дуальності):

1. **У ближній зоні (`k·r ≪ 1`):** Для магнітної рамки домінує магнітне поле `H_r, H_θ ~ 1/r³`, тоді як вихрове електричне поле `E_φ ~ 1/r²` є значно слабшим. Хвильовий опір полів у ближній зоні дорівнює `Z_рамка = |E_φ| / |H_θ| ≈ Z₀ · (k·r) ≪ Z₀`. 
2. **У далекій зоні (`k·r ≫ 1`):** Хвильовий опір магнітної рамки також прямує до асимптоти внутрішнього опору середовища `Z₀ = 377 Ом`, а випромінена потужність дорівнює `P = (Z₀ · k⁴ · m₀²) / (12 · π)`. Опір випромінювання малої рамки обчислюється як `R_випр ≈ 31171 · (A / λ²)² Ом`.

### 10. Підсумкові висновки математичного виведення

Проведений математичний розклад строго показує, що просторовий розподіл полів будь-якої випромінювальної системи є цілісним аналітичним розв'язком неоднорідних хвильових рівнянь Лоренца у тривимірному просторі. Чіткий розподіл на ближню, проміжну та далеку зони відображає фундаментальну асимптотику сферичних функцій Ханкеля та забезпечує неперервний фізичний перехід від накопиченої реактивної енергії зв'язаного квазістатичного поля до вільного випромінювання електромагнітних хвиль у навколишній простір.
