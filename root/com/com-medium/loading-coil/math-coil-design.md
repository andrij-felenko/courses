# 🧮 Математика індуктивного завантаження: імпеданс, ККД та висока напруга

Ця вставка містить точний математичний вивід вхідного імпедансу укороченої антени, аналітичний розрахунок необхідної індуктивності завантажувальної котушки, формулу Нагаока для геометричного проєктування витків, обчислення омічних втрат ВЧ-струму, підсумковий ККД, добротність, смугу пропускання, теплове розсіювання та високовольтні напруги, що виникають на витках котушки при передачі.

---

### 1. Теоретичний вивід ємності укороченого штиря

Вертикальний штир (монополь) висотою `h` та радіусом провідника `a` над ідеальною провідною землею при фізичній довжині `h < λ / 4` поводиться як розімкнений на кінці еквівалентний конденсатор. 

Для виводу ємності використаємо метод дзеркальних зображень. Включимо дзеркальне відображення штиря у землі, отримавши симетричний диполь довжиною `2h`. Потенціал `V` на поверхні тонкого циліндричного провідника з лінійною густиною заряду `q` визначається інтегруванням потенціалу точкових зарядів:

```
V = (q / (4π · ε₀)) · ∫₋ₕ⁺ʰ (dz' / √(z'² + a²))
```

Оскільки радіус провідника значно менший за його довжину (`a ≪ h`), інтеграл обчислюється аналітично:

```
∫₋ₕ⁺ʰ (dz' / √(z'² + a²)) = 2 · ln(2h / a)
```

З урахуванням нерівномірного спадання заряду до нуля на розімкненому кінці штиря та дзеркальної поверхні землі, середня ємність укороченого монополя `C_ant` описується точною аналітичною формулою Шелкунова:

```
C_ant = (2π · ε₀ · h) / (ln(h / a) - 1)
```

де `ε₀ ≈ 8.854 × 10⁻¹² Ф/м` — електрична стала вакууму, `ln` — натуральний логарифм відношення висоти штиря до його радіуса.

Реактивний опір антени має чисто ємнісний характер (`-j X_C`), де модуль реактивності `X_C` на круговій частоті `ω = 2πf` дорівнює:

```
X_C = 1 / (ω · C_ant) = 1 / (2π · f · C_ant)
```

**Крок 1. Розрахунок ємності автомобільної антени.**  
Розглянемо практичний приклад автомобільного штиря з фізичною висотою `h = 1.8 м`, радіусом дроту `a = 2 мм = 0.002 м` на робочій частоті `f = 7.1 МГц` (довжина хвилі у вільному просторі `λ = c / f = 299.79 / 7.1 ≈ 42.25 м`). 

Фізичне укорочення антени становить `h / λ = 1.8 / 42.25 ≈ 0.0426` (тобто штир становить лише `4.26%` довжини хвилі замість резонансних `25%`).

Обчислимо геометричний логарифмічний фактор:

```
ln(h / a) - 1
= ln(1.8 / 0.002) - 1     [підстановка геометричних параметрів: h = 1.8 м, a = 0.002 м]
= ln(900) - 1             [обчислення відношення висоти штиря до радіуса]
= 6.802 - 1               [значення натурального логарифма ln(900)]
= 5.802                   [підсумковий геометричний фактор]
```

Тепер обчислимо власну ємність штиря `C_ant`:

```
C_ant
= (2π · 8.854×10⁻¹² · 1.8) / 5.802   [підстановка ε₀, h = 1.8 м та розрахованого логарифмічного фактора]
= (1.0013 × 10⁻¹⁰) / 5.802           [обчислення чисельника]
≈ 17.26 × 10⁻¹² Ф                    [значення ємності в фарадах]
= 17.26 пФ                           [переведення в пікофаради]
```

Обчислимо ємнісний реактивний опір `X_C` на частоті `f = 7.1 МГц`:

```
ω = 2π · 7.1 × 10⁶ ≈ 44.61 × 10⁶ рад/с   [кругова частота на f = 7.1 МГц]

X_C 
= 1 / (44.61×10⁶ · 17.26×10⁻¹²)          [підстановка ω та C_ant]
= 1 / 0.000770                           [обчислення знаменника]
≈ 1298.7 Ом                              [підсумковий ємнісний реактивний опір]
```

Отже, вхідний реактивний опір короткого штиря становить `-j 1298.7 Ом`.

### 2. Необхідна індуктивність завантажувальної котушки

Для досягнення електричного резонансу вхідна реактивність системи повинна обнулитися (`X_вх = X_L - X_C = 0`). Це означає, що завантажувальна котушка повинна внести індуктивний опір, який точно дорівнює за модулем ємнісному опору штиря:

```
X_L = X_C = 1298.7 Ом
```

Розрахуємо необхідну індуктивність котушки `L_coil`:

```
L_coil 
= X_L / (2π · f)                         [умова компенсації: X_L = X_C = 1298.7 Ом]
= 1298.7 / (44.61 × 10⁶)                 [ділення реактивності на кругову частоту]
≈ 29.11 × 10⁻⁶ Гн                        [індуктивність у генрі]
= 29.11 мкГн                             [переведення в мікрогенрі]
```

### 3. Формула Нагаока для геометричного розрахунку котушки

Для практичного виготовлення одношарової циліндричної завантажувальної котушки застосовують **формулу Нагаока** (*Nagaoka formula*). Для котушки з індуктивністю `L_coil` (у мкГн), діаметром каркаса `D` (у см) та довжиною намотки `l` (у см) необхідна кількість витків `N` обчислюється так:

```
N = √[ L_coil · (45 · D + 100 · l) / (2.54 · D²) ]
```

**Приклад розрахунку геометричних витків.**  
Нехай ми мотаємо котушку `L_coil = 29.11 мкГн` на фторопластовому каркасі діаметром `D = 5.0 см` з довжиною намотки `l = 8.0 см`:

```
45 · D + 100 · l
= 45 · (5.0) + 100 · (8.0)                [підстановка геометричних розмірів каркаса]
= 225 + 800                              [обчислення лінійних чисельників]
= 1025                                   [підсумковий чисельник геометричного фактора]

2.54 · D²
= 2.54 · (5.0)²                          [підстановка діаметра D = 5.0 см]
= 2.54 · 25.0                            [піднесення діаметра до квадрата]
= 63.5                                   [підсумковий знаменник]

N²
= (29.11 · 1025) / 63.5                  [підстановка індуктивності та геометричних чинників]
= 29837.75 / 63.5                        [обчислення чисельника]
≈ 469.88                                 [квадрат кількості витків]

N = √469.88 ≈ 21.68 витків               [найближче ціле — 22 витки]
```

### 4. Ефективна висота, опір випромінювання та опір втрат

Опір випромінювання укороченого штиря залежить від його ефективної висоти `h_eff`. Для незавантаженого штиря із трикутним розподілом струму `h_eff = h / 2`. 

Загальна формула опору випромінювання описується виразом:

```
R_рад = 160 · π² · (h / λ)²    [Ом]
```

Виведемо значення `R_рад` для нашого штиря `h / λ = 0.0426`:

```
(h / λ)² = (0.0426)² ≈ 0.001815          [квадрат відносної висоти h/λ = 1.8/42.25]

R_рад 
= 160 · (9.8696) · 0.001815              [підстановка π² ≈ 9.8696 та (h/λ)²]
= 1579.1 · 0.001815                      [множення 160 · π²]
≈ 2.86 Ом                                [підсумковий опір випромінювання короткого штиря]
```

Повний активний опір системи `R_повн` складається з трьох елементів:

```
R_повн = R_рад + R_землі + R_котушки
```

1. `R_землі` — опір втрат у поверхні автомобіля або заземленні (типово `R_землі ≈ 4.0 Ом`).
2. `R_котушки` — активний опір витків котушки з урахуванням скін-ефекту та ефекту близькості витків (*proximity effect*). Якщо якісна котушка має власну добротність `Q_coil = 200`, її опір втрат становить:

```
R_котушки 
= X_L / Q_coil                           [формула втрат котушки через добротність]
= 1298.7 / 200                           [підстановка X_L = 1298.7 Ом та Q_coil = 200]
≈ 6.49 Ом                                [опір втрат ВЧ-струму в витках]
```

Складемо всі трійки активних опорів:

```
R_повн 
= 2.86 + 4.0 + 6.49                      [сума опорів R_рад, R_землі та R_котушки]
= 13.35 Ом                               [підсумковий активний вхідний опір]
```

### 5. ККД випромінювання та смуга пропускання

Корисна потужність випромінюється лише на опорі `R_рад`. Відповідно, ККД антени `η` визначається як співвідношення корисного опору випромінювання до повного активного опору:

```
η = (R_рад / R_повн) × 100%
```

Підставимо значення:

```
η 
= (2.86 / 13.35) × 100%                  [відношення опору випромінювання до повного опору]
= 0.2142 × 100%                          [обчислення частки корисної потужності]
≈ 21.4%                                  [підсумковий ККД антени у відсотках]
```

Майже **78.6%** потужності передавача безповоротно втрачається у вигляді тепла на нагрівання котушки (`6.49 Ом`) та заземлення (`4.0 Ом`)!

Тепер обчислимо еквівалентну добротність усієї антени `Q_ант` та її смугу пропускання по рівню −3 дБ (`BW`):

```
Q_ант = X_C / R_повн = 1298.7 / 13.35 ≈ 97.3
```

Смуга пропускання антени `BW` на частоті `f₀ = 7100 кГц`:

```
BW 
= f₀ / Q_ант                             [формула смуги пропускання по рівню -3 дБ]
= 7100 кГц / 97.3                        [підстановка частоти f₀ = 7100 кГц та Q_ант = 97.3]
≈ 72.9 кГц                               [ширина смуги пропускання антени]
```

### 6. Високовольтний розрахунок напруги на котушці

Подамо на вхід цієї антени стандартну потужність радіоаматорського передавача `P = 100 Вт`.

Обчислимо діючий струм у котушці та основі антени `I_ант`:

```
I_ант 
= √(100 / 13.35)                         [підстановка потужності P = 100 Вт та R_повн = 13.35 Ом]
= √7.49                                  [ділення потужності на опір]
≈ 2.737 А                                [діючий ВЧ-струм антени (RMS)]
```

Тепер обчислимо діючу напругу високої частоти на клемах котушки `V_rms`:

```
V_rms 
= I_ант · X_L                            [закон Ома для реактивного опору котушки]
= 2.737 А × 1298.7 Ом                    [підстановка діючого струму та реактивності]
≈ 3554.5 В                               [діюча напруга ВЧ на клемах котушки]
```

Амплітудне (пікове) значення напруги `V_peak`:

```
V_peak 
= V_rms · √2                             [перехід від діючого значення до амплітудного]
= 3554.5 × 1.4142                        [множення на коефіцієнт амплітуди √2]
≈ 5027 В = 5.03 кВ                       [пікова амплітуда напруги 5.03 кВ]
```

Напруга понад **5 кіловольт** на котушці довжиною всього 10–15 см створює напруженість електричного поля порядку `500 кВ/м`, що перевищує поріг електричного пробою повітря у сиру погоду (`E_пробою ≈ 300 кВ/м`). Це пояснює необхідність збільшеного кроку між витками та високоякісної фторопластової або повітряної ізоляції.

### 7. Теплове розсіювання та зсув резонансу від вологи

Обчислимо теплове розсіювання потужності на котушці `P_котушки`:

```
P_котушки 
= I_ант² · R_котушки                     [закон Джоуля-Ленца для ВЧ-опору котушки]
= (2.737)² × 6.49                        [підстановка ВЧ-струму та опору втрат]
= 7.491 × 6.49                           [піднесення струму до квадрата]
≈ 48.6 Вт                                [теплова потужність, що нагріває котушку]
```

Майже **половина всієї потужності 100-ватного передавача** виділяється у вигляді тепла всередині невеликої котушки! При тривалій передачі це спричиняє нагрівання провідників та діелектричного каркасу.

Зміна ємності антени від дощу чи вологи на `ΔC = 1.5 пФ` спричиняє зсув резонансної частоти `Δf`:

```
Δf / f₀ ≈ -0.5 · (ΔC / C_ant)

Δf 
= -0.5 · (1.5 / 17.26) · 7100 кГц       [підстановка зміни ємності та робочої частоти]
= -0.5 · 0.0869 · 7100                   [обчислення відносного зміщення]
≈ -308.5 кГц                             [зсув резонансу вниз]
```

Зсув резонансу на **308 кГц** при смугі пропускання антени всього **73 кГц** означає, що при попаданні перших крапель дощу КСХ антени негайно підстрибне від 1.1 до понад 8.0, роблячи передачу неможливою без підлаштування індуктивності.

### 8. Граничні математичні випадки моделі

Для оцінки меж застосовності індуктивного завантаження проаналізуємо два крайніх граничних випадки:

1. **Граничний випадок наближення до резонансної довжини (`h → λ / 4`):**
   - Відношення `h / λ → 0.25`.
   - Власна ємність штиря `C_ant` зростає, а її ємнісний опір прямує до нуля (`X_C → 0`).
   - Необхідна індуктивність котушки прямує до нуля (`L_coil → 0`).
   - Опір випромінювання наближається до теорії резонансного монополя: `R_рад = 160 · π² · (0.25)² ≈ 39.5 Ом`.
   - Опір котушки зникає (`R_котушки → 0`), а ККД системи наближається до максимуму: `η → R_рад / (R_рад + R_землі) ≈ 39.5 / (39.5 + 4.0) ≈ 90.8%`.

2. **Граничний випадок надкороткого штиря (`h → 0.001 · λ`):**
   - На частоті 7.1 МГц це відповідає штиреві довжиною всього `4.2 см`.
   - Опір випромінювання прямує до нульового значення: `R_рад = 160 · π² · (0.001)² ≈ 0.00158 Ом`.
   - Ємність штиря зменшується до `C_ant ≈ 0.3 пФ`, а її опір зростає до `X_C ≈ 75 000 Ом`.
   - Необхідна індуктивність котушки досягає `L_coil ≈ 1680 мкГн`. При `Q_coil = 200` опір втрат котушки досягає `R_котушки ≈ 375 Ом`.
   - Повний опір системи становить `R_повн ≈ 379 Ом`.
   - ККД випромінювання просідає до мізерного значення: `η = 0.00158 / 379 × 100% ≈ 0.00041%`!
   - З 100 ватів потужності передавача у радіохвилю перетворюється лише **0.41 мілівата**! Вся решта потужності іде на тепловий нагрів котушки.
   - Добротність антени зростає до `Q_ант = 75000 / 379 ≈ 198`, а смуга пропускання звужується до катастрофічних **35 Гц**.

Ці математичні межі чітко показують фізичний бар'єр укорочення: індуктивна котушка здатна забезпечити електричний резонанс для будь-якого штиря, але вона не здатна обійти закон квадратичного спадання опору випромінювання `R_рад`.
