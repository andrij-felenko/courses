# ⚙️ Алгоритм Клобучара: реалізація обчислення іоносферної затримки

У цій практичній вставці подано покроковий аналіз, алгоритмічну специфікацію та повну реалізацію алгоритму Клобучара (Klobuchar model, IS-GPS-200) для обчислення одночастотної іоносферної затримки супутникового сигналу мовами C та C++.

Модель Клобучара призначена для розрахунку іоносферної затримки кодових вимірювань супутникових приймачів, що працюють на одній частоті (наприклад, GPS L1 C/A 1575.42 МГц або Galileo E1 1575.42 МГц). Модель оперує 8 параметрами, які транслюються в підкадрі 4 навігаційного кадру GPS, і дозволяє компенсувати близько 50% середньоквадратичного значення іоносферної затримки в будь-якій точці Землі.

### Фізична та геометрична основа алгоритму

Алгоритм Клобучара базується на двох фундаментальних спрощеннях:
1. **Тонкошарова модель іоносфери:** передбачається, що вся електронна маса атмосфери зосереджена у тонкій сферичній оболонці на фіксованій висоті `h_m = 350 км` над поверхнею Землі. Точка перетину радіопроменя між приймачем і супутником із цією оболонкою називається **пробійною точкою іоносфери (Ionospheric Pierce Point, IPP)**.
2. **Добовий апроксимаційний профіль:** вважається, що в нічний час затримка є сталою й дорівнює 5 наносекундам (приблизно 1.5 м), а в денний час змінюється за законом додатного зрізу косинусоїди з максимумом о 14:00 місцевого сонячного часу в точці IPP. Амплітуда та період цієї косинусоїди є функціями геомагнітної широти IPP й обчислюються за допомогою поліномів 3-го порядку від коефіцієнтів `α₀..α₃` та `β₀..β₃`.

### Покроковий алгоритм розрахунку

#### Крок 1. Переведення кутових величин у напівкола (Semi-circles)
Усі кутові координати в алгоритмі Клобучара подаються не в градусах і не в радіанах, а у спеціальних одиницях — **напівколах** (1 напівколо = `180° = π` радіан).
- Широта приймача: `φ_u = lat_deg / 180.0`
- Довгота приймача: `λ_u = lon_deg / 180.0`
- Кут елевації супутника: `e = elev_deg / 180.0`
- Азимут супутника переводиться в радіани: `A = azim_deg · (π / 180.0)`

#### Крок 2. Обчислення центрального кута Землі `ψ`
Центральний кут Землі `ψ` між вектором положення приймача та вектором пробійної точки IPP визначається спрощеною геометричною формулою:

```
ψ = (0.0137 / (e + 0.11)) - 0.022  [напівкіл]
```

Ця формула апроксимує точне точне тригонометричне співвідношення для оболонки висотою 350 км із похибкою не більше кількох тисячних напівкола.

#### Крок 3. Визначення географічних координат пробійної точки IPP
Широта пробійної точки `φ_i` обчислюється як:

```
φ_i = φ_u + ψ · cos(A)  [напівкіл]
```

Оскільки широта не може перевищувати полюсів, її значення суворо обмежують діапазоном `[-0.416, +0.416]` напівкіл (що відповідає `±74.88°`). Якщо широта перевищує ці межі, вона примусово прирівнюється до граничного значення.

Довгота пробійної точки `λ_i` обчислюється за формулою:

```
λ_i = λ_u + (ψ · sin(A)) / cos(φ_i · π)  [напівкіл]
```

#### Крок 4. Розрахунок геомагнітної широти `φ_m`
Оскільки стан іоносферної плазми суттєво залежить від дипольного магнітного поля Землі, амплітуда й період моделі розраховуються не від географічної, а від **геомагнітної широти** `φ_m`. Вони зв'язані співвідношенням:

```
φ_m = φ_i + 0.064 · cos((λ_i - 1.617) · π)  [напівкіл]
```

де `1.617` напівкола (`291.06°` сх. д.) відповідають довготі геомагнітного полюса.

#### Крок 5. Обчислення місцевого сонячного часу `t` в точці IPP
Місцевий сонячний час `t` (у секундах від початку доби) обчислюється шляхом додавання довготного зсуву IPP до системного часу GPS `t_GPS` (Time of Week):

```
t = 43200 · λ_i + t_GPS  [секунд]
```

Оскільки отримане значення може виходити за межі 24 годин (86400 с), його приводять до діапазону `[0, 86400)` за допомогою операції взяття за модулем 86400.

#### Крок 6. Розрахунок похилого картографічного фактора `F(e)`
Вертикальна затримка в точці IPP перераховується у похилу затримку вздовж променя за допомогою похилого картографічного фактора `F(e)`:

```
F(e) = 1.0 + 16.0 · (0.53 - e)³
```

При елевації супутника `e = 90°` (`0.5` напівкола) фактор `F(e) ≈ 1.0` (зенитний промінь). При елевації `e = 5°` (`0.0278` напівкола) фактор `F(e) ≈ 3.0` (похилий промінь біля горизонту).

#### Крок 7. Обчислення амплітуди `A` та періоду `P`
Амплітуда денного піку `A` (у секундах) та період косинусоїди `P` (у секундах) розраховуються як кубічні поліноми від геомагнітної широти `φ_m` за коефіцієнтами `α₀..α₃` та `β₀..β₃`:

```
A = α₀ + α₁ · φ_m + α₂ · φ_m² + α₃ · φ_m³  [секунд]
P = β₀ + β₁ · φ_m + β₂ · φ_m² + β₃ · φ_m³  [секунд]
```

Якщо обчислена амплітуда `A < 0`, її значення відсікається до `0.0`. Якщо обчислений період `P < 72000` секунд (20 годин), він відсікається до мінімального порогу `72000.0` с.

#### Крок 8. Обчислення підсумкової часової та часо-частотної затримки
Обчислюється фаза добового косинусоїдного профілю `x` відносно піку о 14:00 (50400 секунд):

```
x = (2 · π · (t - 50400)) / P  [радіан]
```

Підсумкова часова затримка `I` (у секундах) визначається умовами:
- Якщо `|x| < 1.57` радіан (денний час між 08:00 та 20:00):
  ```
  I = F(e) · (5 · 10⁻⁹ + A · (1 - x² / 2 + x⁴ / 24))
  ```
  де косинус апроксимується 4-м членом ряду Тейлора для прискорення обчислень.
- Якщо `|x| ≥ 1.57` радіан (нічний час):
  ```
  I = F(e) · (5 · 10⁻⁹)
  ```

Далі часова затримка `I` перераховується у відстаневу затримку в метрах для довільної частоти `f`:

```
ΔR = I · c · (f_L1 / f)²  [метрів]
```

де `c = 299 792 458 м/с`, а `f_L1 = 1575.42 МГц`.

### Потенційні пастки та крайові випадки при програмуванні

1. **Граничні географічні широти:** При обчисленні широти пробійної точки `lat_i` значення обмежується граничним діапазоном `±0.416` напівкіл (що відповідає `±74.88°`). Нехтування цим обмеженням призводить до математичного розриву у знаменнику `cos(lat_i * π)` при розрахунку довготи IPP `lon_i` біля приполярних областей.
2. **Перехід через північ (24:00):** Сонячний час `t_local` може виходити за межі доби (ставати від'ємним або перевищувати 86400 с) через додавання довготного зсуву точки IPP. Використання оператора дробового залишку `fmod` та перевірка від'ємного знаку є обов'язковими для збереження правильності розрахунку фази `x`.
3. **Обмеження амплітуди та періоду:** Поліном амплітуди `amp` при високих геомагнітних широтах може набувати від'ємних значень. Його слід примусово обмежувати ніжнім порогом `0.0`. Поліном періоду `period` не повинен бути меншим за `72000` секунд (20 годин).
4. **Апроксимація косинуса:** В алгоритмі IS-GPS-200 косинус розкладається рядом Тейлора до 4-го степеня `1 - x²/2 + x⁴/24`. Це зроблено для запобігання втраті продуктивності на бортових навігаційних мікроконтролерах без апаратного блоку FPU, де обчислення трансендентних функцій `cos()` вимагає багато циклів.
