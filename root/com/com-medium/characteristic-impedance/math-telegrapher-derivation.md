# 🧮 Математичний вивід рівнянь ліній передачі

Ця математична вставка містить суворий вивід диференціальних телеграфних рівнянь, вирази для комплексної константи поширення хвилі, аналітичний розрахунок згасання та фазового зсуву, вивід характеристичного імпедансу `Z_0` та математичну формулу вхідного імпедансу лінії скінченної довжини з навантаженням `Z_L`.

## Вивід телеграфних рівнянь у часовій області

Розглянемо нескінченно малий елемент лінії передачі довжиною `dx`, розташований між координатами `x` та `x + dx`. Елемент описується чотирма погонними параметрами: `R_0` (Ом/м), `L_0` (Гн/м), `G_0` (См/м) та `C_0` (Ф/м).

Застосуємо другий закон Кірхгофа (закон напруг) для контуру, утвореного сигнальним та зворотним провідниками на відрізку `dx`:

```
V(x, t) - R_0 · dx · I(x, t) - L_0 · dx · (∂I(x, t) / ∂t) - V(x + dx, t) = 0
```

Перенесемо `V(x + dx, t)` у праву частину та поділимо обидві частини рівняння на `dx`:

```
-(V(x + dx, t) - V(x, t)) / dx = R_0 · I(x, t) + L_0 · (∂I(x, t) / ∂t)
```

Переходячи до границі при `dx → 0`, за визначенням часткової похідної отримуємо перше диференціальне телеграфне рівняння:

```
-∂V(x, t) / ∂x = R_0 · I(x, t) + L_0 · (∂I(x, t) / ∂t)    [перше телеграфне рівняння]
```

Тепер застосуємо перший закон Кірхгофа (закон струмів) для вузла у точці `x + dx`:

```
I(x, t) - G_0 · dx · V(x + dx, t) - C_0 · dx · (∂V(x + dx, t) / ∂t) - I(x + dx, t) = 0
```

Поділивши на `dx` та спрямувавши `dx → 0`, отримуємо друге диференціальне телеграфне рівняння:

```
-∂I(x, t) / ∂x = G_0 · V(x, t) + C_0 · (∂V(x, t) / ∂t)    [друге телеграфне рівняння]
```

## Перехід до гармонічного режиму (комплексні амплітуди)

У гармонічному режимі на колова частоті `ω` напруга та струм виражаються через комплексні амплітуди (комплексні вектори):

```
V(x, t) = Re{ V(x) · e^(j·ω·t) }
I(x, t) = Re{ I(x) · e^(j·ω·t) }
```

Операція часткової похідної за часом `∂ / ∂t` замінюється множенням на `j·ω`. Тоді система двох часткових диференціальних рівнянь перетворюється на систему звичайних комплексних диференціальних рівнянь за координатою `x`:

```
-dV(x) / dx = (R_0 + j·ω·L_0) · I(x)    [рівняння 1 в комплексній формі]
-dI(x) / dx = (G_0 + j·ω·C_0) · V(x)    [рівняння 2 в комплексній формі]
```

Позначимо комплексний послідовний імпеданс лінії на один метр як `Z_s = R_0 + j·ω·L_0`, а комплексне паралельне провідність на один метр як `Y_p = G_0 + j·ω·C_0`.

Щоб роз'єднати змінні, продиференціюємо перше рівняння за `x`:

```
d²V(x) / dx² = -Z_s · (dI(x) / dx)
```

Підставивши вираз для `dI(x) / dx` з другого рівняння, отримуємо одновимірне комплексне хвильове рівняння (рівняння Гельмгольца) для напруги:

```
d²V(x) / dx² = Z_s · Y_p · V(x)
```

Аналогічно, дифференціюючи друге рівняння, отримуємо таке ж хвильове рівняння для струму:

```
d²I(x) / dx² = Z_s · Y_p · I(x)
```

Введемо комплексний коефіцієнт поширення (константу поширення) `γ` (грецька літера гамма):

```
γ = √(Z_s · Y_p) = √((R_0 + j·ω·L_0) · (G_0 + j·ω·C_0)) = α + j·β
```

де:
- `α` (альфа) — коефіцієнт згасання (вимірюється в неперах на метр, Нп/м, або дБ/м);
- `β` (бета) — фазова константа або хвильове число (вимірюється в радіанах на метр, рад/м).

Рівняння Гельмгольца набуває стандартного вигляду:

```
d²V(x) / dx² - γ² · V(x) = 0
```

## Вивід складових константи поширення α та β

Піднесемо вираз `γ = α + j·β` до квадрата та прирівняємо до добутку `Z_s · Y_p`:

```
γ² = (α + j·β)² = (α² - β²) + j · (2·α·β)
Z_s · Y_p = (R_0 · G_0 - ω² · L_0 · C_0) + j · ω · (R_0 · C_0 + G_0 · L_0)
```

Прирівнюючи дійсні та уявні частини, отримуємо систему двох алгебраїчних рівнянь:

```
α² - β² = R_0 · G_0 - ω² · L_0 · C_0                     [рівняння 1 для дійсних частин]
2 · α · β = ω · (R_0 · C_0 + G_0 · L_0)                  [рівняння 2 для уявних частин]
```

Знайдемо модуль числа `γ²`:

```
|γ²| = α² + β² = √((R_0² + ω²·L_0²) · (G_0² + ω²·C_0²))  [модуль комплексного числа γ²]
```

Додаючи та віднімаючи вирази для `(α² + β²)` та `(α² - β²)`, розв'язуємо систему відносно `α` та `β`:

```
α = (1 / √2) · √[ √((R_0² + ω²·L_0²) · (G_0² + ω²·C_0²)) + (R_0·G_0 - ω²·L_0·C_0) ]
β = (1 / √2) · √[ √((R_0² + ω²·L_0²) · (G_0² + ω²·C_0²)) - (R_0·G_0 - ω²·L_0·C_0) ]
```

### Малозгасаюче наближення (Low-Loss Approximation)

У високочастотному діапазоні, коли омічні втрати малі в порівнянні з реактивними опорами (`R_0 << ω·L_0` та `G_0 << ω·C_0`), вирази для `α` та `β` можна розкласти в ряд Тейлора:

```
α ≈ (R_0 / 2) · √(C_0 / L_0) + (G_0 / 2) · √(L_0 / C_0)
= (R_0 / (2 · Z_0)) + ((G_0 · Z_0) / 2)                     [коефіцієнт згасання лінії]
```

де перша складова `R_0 / (2 · Z_0)` відповідає за омічні втрати в міді, а друга `(G_0 · Z_0) / 2` — за діелектричні втрати в ізоляторі.

Фазова константа `β` у цьому наближенні дорівнює:

```
β ≈ ω · √(L_0 · C_0)                                       [лінійна залежність від частоти]
```

Фазова швидкість поширення сигналу `v_p = ω / β = 1 / √(L_0 · C_0)` є постійною величиною, що гарантує відсутність фазової дисперсії.

## Математичне доведення умови Гевісайда

Згасання `α` та фазова швидкість `v_p` не залежать від частоти `ω` тоді й лише тоді, коли підкореневі вирази в повних формулах дають лінійне співвідношення.

Розглянемо умову `R_0 / L_0 = G_0 / C_0 = k` (де `k` — константа):

```
Z_s = L_0 · (k + j·ω)
Y_p = C_0 · (k + j·ω)
```

Тоді добуток `Z_s · Y_p` спрощується:

```
γ² = Z_s · Y_p = L_0 · C_0 · (k + j·ω)²
γ = √(L_0 · C_0) · (k + j·ω) = k · √(L_0 · C_0) + j · ω · √(L_0 · C_0)
```

Порівнюючи з `γ = α + j·β`, отримуємо:

```
α = (R_0 / L_0) · √(L_0 · C_0) = R_0 · √(C_0 / L_0) = R_0 / Z_0  [згасання стале на всіх частотах]
β = ω · √(L_0 · C_0)                                             [фазова швидкість v = 1/√(L_0 C_0)]
```

Отже, при дотриманні умови `R_0 / L_0 = G_0 / C_0` лінія передає будь-яку складну хвильову форму (у тому числі прямокутні цифровий імпульси) без найменших частотних спотворень та дисперсії.

## Загальний розв'язок хвильових рівнянь та вивід Z_0

Загальний розв'язок лінійного диференціального рівняння другого порядку є сумою двох експоненціальних функцій:

```
V(x) = V^+ · e^(-γ·x) + V^- · e^(+γ·x)
```

де `V^+ · e^(-γ·x)` описує падаючу хвилю, що рухається у додатному напрямку осі `x`, а `V^- · e^(+γ·x)` описує відбиту хвилю, що рухається у від'ємному напрямку.

Для знаходження відповідного виразу для струму `I(x)` підставимо розв'язок для напруги у перше телеграфне рівняння `-dV / dx = Z_s · I`:

```
I(x) = -(1 / Z_s) · dV(x) / dx
= -(1 / Z_s) · (-γ · V^+ · e^(-γ·x) + γ · V^- · e^(+γ·x))    [підстановка часткової похідної dV/dx]
= (γ / Z_s) · (V^+ · e^(-γ·x) - V^- · e^(+γ·x))                [раціоналізація знаків та множників]
```

Розглянемо коефіцієнт пропорційності `γ / Z_s`:

```
γ / Z_s = √((R_0 + j·ω·L_0) · (G_0 + j·ω·C_0)) / (R_0 + j·ω·L_0)
= √((G_0 + j·ω·C_0) / (R_0 + j·ω·L_0))                       [ділення чисельника на підкореневий вираз]
= 1 / Z_0                                                   [заміна відношення за визначенням Z_0]
```

Обернена величина за визначенням є **характеристичним імпедансом лінії** `Z_0`:

```
Z_0 = Z_s / γ = √((R_0 + j·ω·L_0) / (G_0 + j·ω·C_0))
```

Отже, вираз для струму через характеристичний імпеданс набуває вигляду:

```
I(x) = (V^+ / Z_0) · e^(-γ·x) - (V^- / Z_0) · e^(+γ·x) = I^+(x) + I^-(x)
```

У лінії без втрат (`R_0 = 0`, `G_0 = 0`):

```
γ = √((j·ω·L_0) · (j·ω·C_0)) = j · ω · √(L_0 · C_0)
α = 0                        [згасання відсутнє]
β = ω · √(L_0 · C_0)         [фазова константа]
Z_0 = √((j·ω·L_0) / (j·ω·C_0)) = √(L_0 / C_0)
```

## Доведення збереження активної потужності у лінії без втрат

У лінії без втрат середній за часом потік активної електромагнітної потужності `P(x)` у довільному перерізі `x` визначається виразом:

```
P(x) = (1 / 2) · Re{ V(x) · I*(x) }
```

де `I*(x)` — комплексно-спряжений струм.

Підставивши розв'язки для `V(x)` та `I(x)` при `Z_0 = Re{Z_0}` та `γ = j·β`:

```
P(x) = (1 / 2) · Re{ (V^+ · e^(-j·β·x) + V^- · e^(j·β·x)) · ((V^+)* / Z_0 · e^(j·β·x) - (V^-)* / Z_0 · e^(-j·β·x)) }
= (1 / (2 · Z_0)) · ( |V^+|² - |V^-|² )
```

Усі перехресні доданки `e^(j·2·β·x)` мають чисто уявні коефіцієнти і після взяття дійсної частини `Re{...}` звертаються на нуль.

Це доводить, що активна потужність у лінії без втрат дорівнює різниці потужності падаючої хвилі `P^+ = |V^+|² / (2 · Z_0)` та потужності відбитої хвилі `P^- = |V^-|² / (2 · Z_0)` і не залежить від координати `x`.

## Вхідний імпеданс лінії скінченної довжини

Розглянемо лінію передачі довжиною `l`, до виходу якої (`x = l`) підключено навантаження `Z_L`.

Знайдемо відношення комплексної напруги `V(x)` до струму `I(x)` на відстані `d' = l - x` від навантаження. Застосувавши граничну умову `V(l) = I(l) · Z_L`, отримуємо коефіцієнт відбиття на навантаженні `Γ_L = (Z_L - Z_0) / (Z_L + Z_0)`.

Тоді напруга та струм у будь-якій точці лінії на відстані `d'` від навантаження дорівнюють:

```
V(d') = V^+ · (e^(γ·d') + Γ_L · e^(-γ·d'))
I(d') = (V^+ / Z_0) · (e^(γ·d') - Γ_L · e^(-γ·d'))
```

Поділивши напругу на струм, отримуємо вхідний імпеданс відрізка лінії довжиною `d'`:

```
Z_in(d') = Z_0 · ((e^(γ·d') + Γ_L · e^(-γ·d')) / (e^(γ·d') - Γ_L · e^(-γ·d')))
```

Підставивши вираз для `Γ_L` та перейшовши до гіперболічних функцій, отримуємо загальну формулу вхідного імпедансу для лінії з втратами:

```
Z_in(d') = Z_0 · ((Z_L + Z_0 · tanh(γ·d')) / (Z_0 + Z_L · tanh(γ·d')))
```

Для лінії без втрат (`γ = j·β`, звідки `tanh(j·β·d') = j · tan(β·d')`) отримуємо класичне рівняння вхідного імпедансу:

```
Z_in(d') = Z_0 · ((Z_L + j · Z_0 · tan(β·d')) / (Z_0 + j · Z_L · tan(β·d')))
```

### Наслідки та часткові випадки

1. **Узгоджена лінія (`Z_L = Z_0`)**:
   Для будь-якої довжини `d'` маємо `tan(β·d')` у чисельнику й знаменнику однаково, звідки `Z_in(d') = Z_0`. Вхідний імпеданс не залежить від довжини лінії.

2. **Замкнена на коротко лінія (`Z_L = 0`)**:
   ```
   Z_in(d') = j · Z_0 · tan(β·d')
   ```
   При `d' < λ / 4` лінія поводиться як індуктивність `L_eq = (Z_0 / ω) · tan(β·d')`, а при `λ / 4 < d' < λ / 2` — як ємність.

3. **Разомкнута лінія (`Z_L = ∞`)**:
   ```
   Z_in(d') = -j · Z_0 · cot(β·d')
   ```
   При `d' < λ / 4` лінія виступає чистою ємністю.

4. **Чвертьхвильовий трансформатор (`d' = λ / 4`, де `β·d' = (2·π / λ) · (λ / 4) = π / 2`)**:
   Оскільки `tan(π / 2) → ∞`, ділимо чисельник і знаменник на `tan(β·d')`:
   ```
   Z_in(λ / 4) = (Z_0)² / Z_L
   ```
   Чвертьхвильовий відрізок інвертує імпеданс: високий імпеданс перетворюється на низький і навпаки.
