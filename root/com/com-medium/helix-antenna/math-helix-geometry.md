# 🧮 Математична теорія та фазове узгодження спіральної антени

Аналітичний опис випромінювання спіральної антени базується на теорії хвильоводів біжучої хвилі та теорії антенних решіток. На відміну від резонаторних систем зі стоячими хвилями (наприклад, диполів), осьовий режим спіралі описується як лінійна решітка з `N` дискретних випромінювачів (витків), збуджених біжучою хвилею струму з постійним зсувом фази.

---

### 1. Геометрія витка та векторні співвідношення

Спіраль утворюється намотуванням провідника навколо уявного циліндра радіуса `a` (діаметра `D = 2·a`) з постійним кроком `S`. У циліндричній системі координат `(r, φ, z)` параметричне рівняння траєкторії провідника має вигляд:

```
r(t) = D / 2
φ(t) = 2·π·t
z(t) = S·t
```

де `t` — число витків (`0 ≤ t ≤ N`).

Якщо розгорнути бічну поверхню одного витка циліндра на площину, отримаємо прямокутний трикутник із катетами `C = π·D` (довжина кола) та `S` (крок витка). Гіпотенуза `L₀` відповідає повній довжині провідника в одному витку:

```
L₀ = √(C² + S²) = √((π·D)² + S²)
```

Кут нахилу витка `α` (*pitch angle*) визначається співвідношеннями:

```
tan(α) = S / C = S / (π·D)
sin(α) = S / L₀
cos(α) = C / L₀
```

Для канонічного осьового режиму оптимальне значення кута нахилу становить `α ≈ 12.5° ... 14°`. При цьому виникає стійке співвідношення `S ≈ 0.23·C`.

---

### 2. Умова фазового узгодження та умова Хансена — Вудьярда

Розглянемо випромінювання хвилі вздовж осі спіралі `z`. Нехай хвиля струму поширюється вздовж провідника спіралі зі фазовою швидкістю `v = p·c`, де `p = v/c` — відносна фазова швидкість (`0.7 < p < 1.0`), а `c` — швидкість світла у вакуумі.

Час `t₁`, за який струм долає один виток провідника довжиною `L₀`, дорівнює:

```
t₁ = L₀ / (p·c)
```

За цей самий час `t₁` електромагнітна хвиля, випромінена у простір уздовж осі `z`, долає відстань `S` зі швидкістю світла `c` за час `t₂ = S/c`.

Різниця фаз `Δφ` між хвилею струму в наступному витку та хвилею у просторі, що прийшла від попереднього витка, становить:

```
Δφ = k₀ · (L₀ / p) - k₀ · S · cos(θ)
```

де `k₀ = 2·π / λ` — хвильове число у вакуумі, а `θ` — кут відносно осі `z`.

Для напрямку уздовж осі (`θ = 0°`, `cos(0°) = 1`) вираз спрощується до:

```
Δφ = k₀ · (L₀ / p - S) = (2·π / λ) · (L₀ / p - S)
```

#### А. Звичайна умова ендфаєр-випромінювання (Ordinary End-fire Condition)
Для того щоб випромінювання всіх витків додавалося строго синфазно у напрямку осі `z`, різниця фаз `Δφ` повинна бути кратною `2·π`:

```
(2·π / λ) · (L₀ / p - S) = 2·π · m      [де m = 1, 2, 3...]
```

Для першої (основної) осьової моди `m = 1`:

```
L₀ / (p·λ) - S / λ = 1
```

Виражаємо відносну фазову швидкість `p`:

```
p_ordinary = (L₀ / λ) / (S / λ + 1)
```

#### Б. Умова підвищеної спрямованості Хансена — Вудьярда (Hansen-Woodyard Condition)
Як довели Хансен і Вудьярд, для лінійних антен біжучої хвилі кінцевої довжини максимальний коефіцієнт підсилення досягається не при точній синфазності, а при наявності додаткового фазового зсуву `π / N` на всій довжині антени:

```
Δφ = 2·π + π / N
```

Підставляємо цю умову у рівняння різниці фаз:

```
(2·π / λ) · (L₀ / p - S) = 2·π + π / N
```

Поділивши обидві частини на `2·π`:

```
L₀ / (p·λ) - S / λ = 1 + 1 / (2·N)

L₀ / (p·λ) = S / λ + 1 + 1 / (2·N)

p_HW = (L₀ / λ) / (S / λ + 1 + 1 / (2·N))
```

Для антени з `N = 10` витків при `C = λ` та `α = 12.8°` (`S = 0.227·λ`, `L₀ = √(1 + 0.227²) = 1.025·λ`):

```
p_HW = 1.025 / (0.227 + 1 + 1/20) = 1.025 / 1.277 ≈ 0.802
```

Фазова швидкість струму у спіралі становить близько **80% від швидкості світла**. Завдяки ефекту сповільнення хвиля струму узгоджується з фазовим фронтом у просторі.

### 3. Множник антенної решітки та діаграма спрямованості

Спіральну антену з `N` витків можна представити як послідовність `N` однакових точкових випромінювачів із відстанню `S` між ними та фазовим зсувом `Ψ = Δφ`.

Нормований множник решітки (*Array Factor*, **AF**) для такої системи дорівнює:

```
AF(θ) = [ sin(N · Ψ / 2) ] / [ N · sin(Ψ / 2) ]
```

де фазова функція `Ψ(θ)` має вигляд:

```
Ψ(θ) = k₀ · (L₀ / p - S · cos θ)
```

Загальна діаграма спрямованості антени `E_total(θ)` є добутком діаграми спрямованості одного витка `E_turn(θ)` на множник решітки `AF(θ)`:

```
E_total(θ) = E_turn(θ) · AF(θ)
```

Діаграма спрямованості одного витка при `C ≈ λ` описується косинусною функцією `E_turn(θ) ≈ cos(θ)`. Отже, головна пелюстка стає тим вужчою, чим більша кількість витків `N`.

### 4. Розрахункові формули Крауса для характеристики випромінювання

На основі узагальнення великого масиву експериментальних даних Джон Краус вивів емпіричні формули, які дають точність у межах `±10%` для спіралей із параметрами `12° ≤ α ≤ 15°`, `0.8 · λ ≤ C ≤ 1.2 · λ` та `3 ≤ N ≤ 25`:

#### 1. Вхідний хвильовий опір (Input Impedance)
```
R_in ≈ 140 · (C / λ)   [Ом]
```
При `C = λ` вхідний опір становить `140 Ом` і носить чисто резистивний характер (`X_in ≈ 0`).

#### 2. Абсолютна спрямованість та коефіцієнт підсилення (Directivity & Gain)
Абсолютна спрямованість `D₀` (відносно ізотропного випромінювача):
```
D₀ ≈ 15 · N · (C / λ)² · (S / λ)
```
З урахуванням коефіцієнта корисної дії антени (`η ≈ 0.8...0.85`) коефіцієнт підсилення `G` в дБі:
```
G_dBi = 10 · log₁₀ [ 12 · N · (C / λ)² · (S / λ) ]
```

#### 3. Ширина діаграми спрямованості за половинною потужністю (HPBW)
Ширина головної пелюстки на рівні `-3 дБ` (у градусах):
```
HPBW ≈ 52° / [ (C / λ) · √( N · S / λ ) ]
```

#### 4. Ширина діаграми між нулями (FNBW)
Кутова відстань між першими нулями випромінювання:
```
FNBW ≈ 115° / [ (C / λ) · √( N · S / λ ) ]
```

#### 5. Коефіцієнт еліптичності (Axial Ratio)
Якість кругової поляризації визначається відношенням компонентів поля:
```
AR = (2·N + 1) / (2·N)
```
При збільшенні кількості витків `N` коефіцієнт еліптичності `AR` прямує до ідеального значення `1.0` (`0 дБ`).

### 5. Аналіз вищих мод випромінювання та межі прозорості

При зміні робочої частоти змінюється відносний периметр витка `C / λ`. Це викликає трансформацію внутрішньої структури хвиль струму:

1. **Нормальна мода (`C < 0.2 · λ`):** фазовий зсув струму вздовж витка `Δφ ≈ 0`. Хвиля струму квазістатична, випромінювання максимальне перпендикулярно до осі спіралі.
2. **Перша осьова мода (`0.75 · λ < C < 1.33 · λ`):** основним є режим `m = 1`. Забезпечує стабільний ендфаєр-промінь із круговою поляризацією.
3. **Конічна мода (`1.33 · λ < C < 1.8 · λ`):** виникає вища мода `m = 2`. Умова синфазності на осі порушується, і максимуми випромінювання відхиляються від осі `z` на кут `θ_cone ≈ 30° ... 50°`, утворюючи воронкоподібну (конічну) діаграму спрямованості з нулем випромінювання строго по осі.
4. **Багатопелюсткові вищі моди (`C > 2.0 · λ`):** діаграма спрямованості розпадається на велику кількість вузьких паразитно орієнтованих пелюсток, а поляризація втрачає круговий характер.

### 6. Вплив скінченності кількості витків та загасання хвиль

У реальній антені біжуча хвиля струму згасає під час поширення від входу до кінця за рахунок випромінювання енергії у простір. Вираз для розподілу амплітуди струму `I(z)` вздовж спіралі має вигляд:

```
I(z) = I₀ · exp(-α_att · z) · exp(-j · β · z)
```

де `α_att` — коефіцієнт загасання випромінювання, а `β = k₀ / p` — фазова константа.

Для перших 2–3 витків амплітуда струму залишається високою, а починаючи з 4-го витка випромінюється понад 70% енергії. Відбита від вільного кінця спіралі хвиля струму має амплітуду менше `5%` від початкової, що й пояснює відсутність стоячих хвиль та резистивний вхідний опір антени.

### 7. Покроковий чисельний приклад розрахунку

**Вихідні дані:**
- Робоча частота: `f = 2.45 ГГц` (`2450 МГц`, діапазон Wi-Fi / Bluetooth).
- Кількість витків: `N = 10`.

**Покрокове обчислення:**
1. Довжина хвилі у вакуумі:
   ```
   λ = 299 792.458 / 2450 = 122.36 мм
   ```
2. Геометрія витка для `C = λ = 122.36 мм`:
   ```
   D = C / π = 122.36 / 3.14159 = 38.95 мм
   ```
3. Крок спіралі для кута `α = 12.8°` (`tan(12.8°) = 0.2272`):
   ```
   S = C · tan(12.8°) = 122.36 · 0.2272 = 27.80 мм
   ```
4. Довжина провідника витка:
   ```
   L₀ = √(122.36² + 27.80²) = √(14972 + 772.8) = 125.48 мм
   ```
5. Загальна осьова довжина антени:
   ```
   L = N · S = 10 · 27.80 = 278.0 мм
   ```
6. Вхідний опір антени:
   ```
   R_in = 140 · (122.36 / 122.36) = 140 Ом
   ```
7. Коефіцієнт підсилення:
   ```
   G_dBi = 10 · log₁₀ [ 12 · 10 · (1.0)² · (27.80 / 122.36) ] 
         = 10 · log₁₀ [ 120 · 0.2272 ] = 10 · log₁₀ [ 27.26 ] ≈ 14.36 дБі
   ```
8. Ширина діаграми спрямованості (HPBW):
   ```
   HPBW = 52° / [ 1.0 · √( 10 · 0.2272 ) ] = 52° / √2.272 = 52° / 1.507 ≈ 34.5°
   ```
