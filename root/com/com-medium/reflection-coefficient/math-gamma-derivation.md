# 🧮 Вивід формули комплексного коефіцієнта відбиття та хвильових трансформацій

Ця математична вставка містить суворий аналітичний вивід формули комплексного коефіцієнта відбиття з дифференціальних рівнянь лінії передачі, доведення його трансформації вздовж довжини з урахуванням згасання, зв'язок із матрицею розсіяння (`S`-параметрами) та розрахунок розподілу активної та реактивної потужностей у неузгодженому ВЧ-тракті.

### 1. Фізичні засади та вивід формули коефіцієнта відбиття з граничних умов

Розглянемо однорідну лінію передачі з хвильовим опором `Z₀`, яка в точці `z = 0` підключена до комплексного навантаження `Z_L = R_L + j X_L`.

Згідно з розв'язком телеграфних рівнянь у сталому гармонійному режимі, повна напруга `V(z)` та повний струм `I(z)` у довільній точці лінії являють собою суму падаючої (біжучої вправо) та відбитої (біжучої вліво) хвиль:

```
V(z) = V⁺ · e⁻ᵍᶻ + V⁻ · e⁺ᵍᶻ
I(z) = (1 / Z₀) · (V⁺ · e⁻ᵍᶻ − V⁻ · e⁺ᵍᶻ)
```

де `V⁺` — комплексна амплітуда падаючої хвилі напруги, що біжить у додатному напрямку осі `z` (від генератора до навантаження); `V⁻` — комплексна амплітуда відбитої хвилі напруги, що біжить у зворотному напрямку; `Z₀` — хвильовий опір лінії передачі, визначений її погонними параметрами `Z₀ = √((R + jωL) / (G + jωC))`; `γ = α + j β` — комплексний коефіцієнт поширення, де `α` — коефіцієнт згасання (Нп/м), а `β = 2π / λ` — фазова стала (рад/м).

Розмістимо початок координат `z = 0` у точці підключення навантаження з комплексним імпедансом `Z_L = R_L + j X_L`. 

У цій точці експоненційні множники `e⁻ᵍᶻ` та `e⁺ᵍᶻ` перетворюються на одиницю (`e⁰ = 1`). Оскільки лінія передачі безпосередньо з'єднана з навантаженням, за законом Ома для ділянки кола відношення сумарної напруги `V(0)` до сумарного струму `I(0)` має дорівнювати імпедансу `Z_L`:

```
Z_L = V(0) / I(0)
= (V⁺ + V⁻) / [ (1 / Z₀) · (V⁺ − V⁻) ]       [підставили вирази для V(0) та I(0)]
= Z₀ · (V⁺ + V⁻) / (V⁺ − V⁻)                 [перенесли Z₀ у чисельник]
```

Цей вираз описує фундаментальне балансове співвідношення між хвильовими амплітудами та імпедансом межі розділу. Щоб виділити відношення хвиль, поділимо чисельник і знаменник дробу на величину падаючої напруги `V⁺`:

```
Z_L = Z₀ · (1 + V⁻ / V⁺) / (1 − V⁻ / V⁺)     [поділили чисельник і знаменник на V⁺]
```

За математичним означенням, **комплексний коефіцієнт відбиття навантаження** `Γ_L` являє собою відношення комплексної амплітуди відбитої хвилі напруги до комплексної амплітуди падаючої хвилі в точці `z = 0`:

```
Γ_L = V⁻ / V⁺
```

Підставимо `Γ_L` у вираз для імпедансу `Z_L` та виконаємо послідовні алгебраїчні перетворення для знаходження зворотної залежності:

```
Z_L / Z₀ = (1 + Γ_L) / (1 − Γ_L)             [поділили обидві частини на Z₀]
z_L = (1 + Γ_L) / (1 − Γ_L)                  [увели нормований імпеданс z_L = Z_L / Z₀]
z_L · (1 − Γ_L) = 1 + Γ_L                    [помножили обидві частини на (1 − Γ_L)]
z_L − z_L · Γ_L = 1 + Γ_L                    [розкрили дужки у лівій частині]
z_L − 1 = Γ_L + z_L · Γ_L                    [перенесли додатки з Γ_L у праву частину]
z_L − 1 = Γ_L · (1 + z_L)                    [винесли Γ_L за дужки]
Γ_L = (z_L − 1) / (z_L + 1)                  [виразили Γ_L через нормований імпеданс]
```

Підставляючи нормований імпеданс `z_L = Z_L / Z₀` назад у дріб, отримуємо канонічну формулу коефіцієнта відбиття:

```
Γ_L = ((Z_L / Z₀) − 1) / ((Z_L / Z₀) + 1)
= (Z_L − Z₀) / (Z_L + Z₀)                    [домножили чисельник і знаменник на Z₀]
```

Аналогічно виводиться коефіцієнт відбиття для струму `Γ_I`. Оскільки струм відбитої хвилі протікає у зворотному напрямку, напрямок вектора `I⁻` протилежний до `V⁻`. Звідси випливає, що коефіцієнт відбиття для струму точно дорівнює коефіцієнту відбиття для напруги з протилежним знаком: `Γ_I = I⁻ / I⁺ = −Γ_L`.

### 2. Алгебраїчний розклад на дійсну та уявну частини

Представимо комплексні величини в алгебраїчній формі: `Z_L = R_L + j X_L` та `Γ_L = Γ_r + j Γ_i`. Підставимо їх у базову формулу та позбудемося уявного числа `j` у знаменнику:

```
Γ_L = ((R_L + j X_L) − Z₀) / ((R_L + j X_L) + Z₀)
= ((R_L − Z₀) + j X_L) / ((R_L + Z₀) + j X_L) [згрупували дійсну та уявну частини]
```

Для вивільнення знаменника від комплексності помножимо чисельник та знаменник на комплексно-сопряжений вираз знаменника `((R_L + Z₀) − j X_L)`:

```
Знаменник = (R_L + Z₀)² + X_L²               [квадрат модуля знаменника]

Чисельник = [ (R_L − Z₀) + j X_L ] · [ (R_L + Z₀) − j X_L ]
= (R_L − Z₀)(R_L + Z₀) − j X_L(R_L − Z₀) + j X_L(R_L + Z₀) − j² X_L²
= (R_L² − Z₀²) + j X_L (R_L + Z₀ − R_L + Z₀) + X_L²  [врахували j² = −1]
= (R_L² + X_L² − Z₀²) + j (2 X_L Z₀)         [звели подібні додатки]
```

Розділивши чисельник на знаменник, отримуємо явні вирази для дійсної `Γ_r` та уявної `Γ_i` компонент коефіцієнта відбиття:

```
Γ_r = (R_L² + X_L² − Z₀²) / ( (R_L + Z₀)² + X_L² )
Γ_i = (2 X_L Z₀) / ( (R_L + Z₀)² + X_L² )
```

З аналізу цих рівностей випливають важливі властивості:
1. Якщо навантаження чисто активне (`X_L = 0`), то уявна частина дорівнює нулю (`Γ_i = 0`), а коефіцієнт відбиття є суто дійсним числом `Γ_r = (R_L − Z₀) / (R_L + Z₀)`;
2. Якщо `R_L > Z₀`, то `Γ_r > 0` (відбита хвиля збігається за фазою з падаючою);
3. Якщо `R_L < Z₀`, то `Γ_r < 0` (відбита хвиля інвертована за фазою);
4. Знак уявної частини `Γ_i` повністю збігається зі знаком реактивності `X_L`: для індуктивного навантаження (`X_L > 0`) уявна частина додатна (`Γ_i > 0`), а для ємнісного (`X_L < 0`) — від'ємна (`Γ_i < 0`).

### 3. Математичний аналіз кол конформного відображення Сміта

Рівняння `z_L = (1 + Γ) / (1 − Γ)` здійснює конформне відображення правій півплощини `z_L = r + j x` (де `r ≥ 0`) всередину одиничного кола `|Γ| ≤ 1`.

Розділимо дійсну та уявну частини нормованого імпедансу:

```
r + j x = ( (1 + Γ_r) + j Γ_i ) / ( (1 − Γ_r) − j Γ_i )
```

Домноживши на сопряжений знаменник `((1 − Γ_r) + j Γ_i)`, отримуємо системи рівнянь:

```
r = (1 − Γ_r² − Γ_i²) / ( (1 − Γ_r)² + Γ_i² )
x = (2 Γ_i) / ( (1 − Γ_r)² + Γ_i² )
```

Шляхом алгебраїчного виділення повного квадрата ці рівняння зводяться до канонічних рівнянь кіл у координатах `(Γ_r, Γ_i)`:

#### Кола постійного активного опору (r = const):

```
(Γ_r − r / (r + 1))² + Γ_i² = (1 / (r + 1))²
```

Це сім'я кіл із центрами в точках `(r / (r + 1), 0)` та радіусами `R_r = 1 / (r + 1)`. Усі кола проходять через точку розриву `(1, 0)`.

#### Кола постійного реактивного опору (x = const):

```
(Γ_r − 1)² + (Γ_i − 1 / x)² = (1 / x)²
```

Це сім'я кіл із центрами в точках `(1, 1/x)` та радіусами `R_x = 1 / |x|`. Центри цих кіл лежать на вертикальній лінії `Γ_r = 1`.

### 4. Вивід трансформації Г(l) уздовж лінії з урахуванням згасання

У реальних лініях передачі згасання `α > 0` призводить до експоненційного зменшення амплітуди хвиль. 

Комплексна напруга в точці на відстані `l` від навантаження (точка `z = −l`) записується як:

```
V⁺(⁻l) = V⁺(0) · e⁺ᵍˡ = V⁺(0) · e⁺ᵃˡ · e⁺ʲᵇˡ
V⁻(⁻l) = V⁻(0) · e⁻ᵍˡ = V⁻(0) · e⁻ᵃˡ · e⁻ʲᵇˡ
```

Складемо відношення відбитої хвилі до падаючої в точці `z = −l`:

```
Γ(l) = V⁻(⁻l) / V⁺(⁻l)
= [ V⁻(0) · e⁻ᵃˡ · e⁻ʲᵇˡ ] / [ V⁺(0) · e⁺ᵃˡ · e⁺ʲᵇˡ ]
= (V⁻(0) / V⁺(0)) · (e⁻ᵃˡ / e⁺ᵃˡ) · (e⁻ʲᵇˡ / e⁺ʲᵇˡ)  [розділили співмножники]
= Γ_L · e⁻²ᵃˡ · e⁻²ʲᵇˡ                        [врахували Γ_L = V⁻(0)/V⁺(0) та 1/eˣ = e⁻ˣ]
```

Перейдемо до полярної форми запису `Γ(l) = |Γ(l)| · e⁺ʲ ᶲ⁽ˡ⁾`:

```
|Γ(l)| = |Γ_L| · e⁻²ᵃˡ                       [модуль згасає за експонентою]
φ(l) = φ_L − 2 β l                           [фаза зменшується лінійно]
```

**Аналітичний висновок:** 
1. При наявності втрат (`α > 0`) модуль коефіцієнта відбиття зменшується при віддаленні від навантаження до джерела. Подвійний коефіцієнт `2α` у показнику експоненти з'являється тому, що сигнал долає довжину лінії `l` двічі (туди й назад).
2. Згасання лінії покращує вхідний КСХ: якщо на кінці кабелю з загальним згасанням `A_db = α · l · 8.686` дБ лежить повне відбиття (`|Γ_L| = 1`), то на вході кабелю модуль відбиття дорівнюватиме `|Γ_in| = 10⁻⁽² ᴬᵈᵇ ⁾²⁰⁾`. Для кабелю з втратами 10 дБ відбита хвиля ослабне на 20 дБ, і на вході прилад зафіксує чудове узгодження `|Γ_in| = 0.1` (КСХ = 1.22), хоча сама антена може бути зламана.

### 5. Зв'язок із хвильовими змінними a, b та S-параметрами

У теорії мікрохвильових кіл замість абсолютних напруг та струмів використовують нормовані хвильові змінні падаючої `a` та відбитої `b` хвиль:

```
a = V⁺ / √Z₀ = (V + Z₀ · I) / (2 · √Z₀)
b = V⁻ / √Z₀ = (V − Z₀ · I) / (2 · √Z₀)
```

Модуль квадрата хвильової змінної дорівнює переносимій активній потужності:

```
|a|² = P_inc = |V⁺|² / Z₀                    [потужність падаючої хвилі]
|b|² = P_ref = |V⁻|² / Z₀                    [потужність відбитої хвилі]
```

У цих термінах коефіцієнт відбиття однопортового пристрою визначається як елемент матриці розсіяння `S₁₁`:

```
S₁₁ = b₁ / a₁ = (V⁻ / √Z₀) / (V⁺ / √Z₀) = V⁻ / V⁺ = Γ
```

Передана в навантаження потужність дорівнює різниці квадратів модулів хвильових змінних:

```
P_load = |a|² − |b|² = |a|² · (1 − |b / a|²) = P_inc · (1 − |S₁₁|²) = P_inc · (1 − |Γ|²)
```

### 6. Детальний числовий розрахунковий приклад

**Початкові дані:**
До лінії з хвильовим опором `Z₀ = 50 Ом`, довжиною `l = 0.2 м`, фазовою сталістю `β = 10 рад/м` та згасанням `α = 0.5 Нп/м` підключено комплексне навантаження `Z_L = 75 + j 25 Ом`.

**Крок 1: Обчислення коефіцієнта відбиття на навантаженні `Γ_L`.**

```
Z_L − Z₀ = (75 + j 25) − 50 = 25 + j 25 Ом
Z_L + Z₀ = (75 + j 25) + 50 = 125 + j 25 Ом
```

Домножимо на комплексно-сопряжене значення знаменника `(125 − j 25)`:

```
Знаменник = 125² + 25² = 15625 + 625 = 16250 [обчислили квадрат модуля знаменника]
Чисельник = (25 + j 25) · (125 − j 25)       [записали множення на сопряжене]
= 3125 − j 625 + j 3125 + 625                 [розкрили дужки та врахували j² = −1]
= 3750 + j 2500                              [звели подібні доданки]

Γ_L = (3750 + j 2500) / 16250                [підставили чисельник і знаменник]
= (3750 / 16250) + j (2500 / 16250)          [порозділяли дійсну та уявну частини]
≈ 0.2308 + j 0.1538                          [виконали ділення]
```

Обчислимо модуль та фазу `Γ_L`:

```
|Γ_L| = √(0.2308² + 0.1538²)                  [формула модуля комплексного числа]
= √(0.05327 + 0.02365)                       [піднесення до квадрата доданків]
= √0.07692                                    [додавання підкореневих виразів]
≈ 0.2773                                      [добування квадратного кореня]

φ_L = arctan(0.1538 / 0.2308)                [формула арктангенса для фази]
= arctan(0.6663)                             [ділення уявної частини на дійсну]
≈ 33.68° = 0.5879 рад                         [обчислення кута в градусах та радіанах]
```

**Крок 2: Трансформація `Γ` на початок лінії (`l = 0.2 м`).**

Обчислимо згасання модуля:

```
|Γ(l)| = |Γ_L| · e⁻²ᵃˡ                      [формула згасання модуля]
= 0.2773 · e⁻² ⁽⁰ˑ⁵⁾ ⁽⁰ˑ²⁾                    [підставили α = 0.5 та l = 0.2]
= 0.2773 · e⁻⁰ˑ²                             [перемножили показник]
= 0.2773 · 0.8187 ≈ 0.2270                    [обчислили згашений модуль]
```

Обчислимо нову фазу:

```
φ(l) = φ_L − 2 β l                           [формула повороту фази]
= 0.5879 − 2 · 10 · 0.2                      [підставили β = 10 та l = 0.2]
= 0.5879 − 4.0 = −3.4121 рад                 [обчислили фазу в радіанах]
```

Приведемо кут до стандартного діапазону `[−π, +π]`:

```
φ_norm = −3.4121 + 2π = −3.4121 + 6.2832 = +2.8711 рад [додали 2π для приведення]
φ_deg = 2.8711 · (180 / π) ≈ +164.50°         [перевели в градуси]
```

Переведемо `Γ_in` назад у комплексні координати:

```
Γ_r(l) = 0.2270 · cos(164.50°) = 0.2270 · (−0.9636) ≈ −0.2187 [обчислили дійсну частину]
Γ_i(l) = 0.2270 · sin(164.50°) = 0.2270 · (0.2672) ≈ +0.0607   [обчислили уявну частину]

Γ_in = −0.2187 + j 0.0607
```

**Крок 3: Обчислення вхідного імпедансу `Z_in`.**

```
Z_in = Z₀ · (1 + Γ_in) / (1 − Γ_in)          [формула трансформації імпедансу]
= 50 · [ (1 − 0.2187 + j 0.0607) / (1 + 0.2187 − j 0.0607) ] [підставили Γ_in]
= 50 · [ (0.7813 + j 0.0607) / (1.2187 − j 0.0607) ] [звели доданки]
```

Помножимо на сопряжений знаменник `(1.2187 + j 0.0607)`:

```
Знаменник = 1.2187² + 0.0607² = 1.4852 + 0.0037 = 1.4889 [обчислили модуль знаменника]
Чисельник = (0.7813 + j 0.0607) · (1.2187 + j 0.0607) [множення чисельника]
= 0.9522 + j 0.0474 + j 0.0740 − 0.0037      [розкрили дужки]
= 0.9485 + j 0.1214                          [звели подібні]

Z_in = 50 · [ (0.9485 + j 0.1214) / 1.4889 ]  [підставили чисельник і знаменник]
= 50 · (0.6370 + j 0.0815)                   [виконали ділення]
≈ 31.85 + j 4.08 Ом                           [помножили на 50 Ом]
```

**Підсумок розрахунку:** Через згасання та затримку в лінії довжиною 20 см початковий імпеданс `Z_L = 75 + j 25 Ом` трансформувався на вході лінії в `Z_in = 31.85 + j 4.08 Ом`, а модуль коефіцієнта відбиття зменшився з 0.2773 (КСХ = 1.77) до 0.2270 (КСХ = 1.59).
