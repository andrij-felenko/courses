# 🧮 Перерахунок зворотних втрат, КСХ та коефіцієнта відбиття

Вставка надає розширене й строге математичне виведення взаємозв'язків між зворотними втратами (Return Loss), коефіцієнтом відбиття напруги та потужності, коефіцієнтом стоячої хвилі (КСХ/VSWR), втратами на неузгодження (Mismatch Loss), параметрами матриці розсіювання (S-параметрами) та комплексним імпедансом навантаження. Також виведено математичні моделі загасання сигналу у коаксіальному кабелі та трансформації імпедансу вздовж лінії передачі. Вона створена для швидкого й точного розрахунку параметрів радіочастотного тракту без спрощень і наближених здогадок.

### 1. Фізико-математична модель хвилі у лінії передачі

У однорідній лінії передачі без втрат із хвильовим опором `Z₀` (типово 50 Ом у радіотехніці або 75 Ом у телебаченні) розподіл напруги `V(z)` та струму `I(z)` вздовж поздовжньої осі `z` описується сумою двох падаючої та відбитої хвиль, що рухаються у протилежних напрямках:

```
V(z) = V_pos · e^(−j·β·z) + V_neg · e^(+j·β·z)

I(z) = (V_pos / Z₀) · e^(−j·β·z) − (V_neg / Z₀) · e^(+j·β·z)
```

де `V_pos` — амплітуда прямої (падаючої) хвилі напруги, `V_neg` — амплітуда зворотної (відбитої) хвилі напруги, `β = 2·π / λ` — фазова константа поширення хвилі у діелектрику лінії, `j = √(−1)` — уявна одиниця.

На межі з’єднання лінії та навантаження з комплексним імпедансом `Z_L = R_L + j·X_L` (де `R_L` — активний опір у омах, `X_L` — реактивний опір) має виконуватися закон Ома для повного напруги та струму: `V(0) / I(0) = Z_L`.

Підставляючи вирази для напруги та струму в точці `z = 0`, отримуємо фундаментальне відношення для комплексного коефіцієнта відбиття напруги `Γ`:

```
Γ = V_neg / V_pos = (Z_L − Z₀) / (Z_L + Z₀)
```

Оскільки імпеданс навантаження загалом є комплексним числом `Z_L = R_L + j·X_L`, коефіцієнт відбиття також є комплексним числом з модулем `|Γ|` та фазовим зсувом `θ`:

```
Γ = |Γ| · e^(j·θ) = |Γ| · (cos(θ) + j·sin(θ))
```

Розкриваємо чисельник та знаменник для комплексного імпедансу:

```
Γ = ((R_L − Z₀) + j·X_L) / ((R_L + Z₀) + j·X_L)   [підстановка Z_L = R_L + j·X_L]
```

Для розрахунку зворотних втрат необхідний квадрат модуля комплексного числа `|Γ|²`, який дорівнює відношенню квадратів модулів чисельника й знаменника:

```
|Γ|² = ((R_L − Z₀)² + X_L²) / ((R_L + Z₀)² + X_L²) [квадрат модуля комплексного дробу]

|Γ|  = √[ ((R_L − Z₀)² + X_L²) / ((R_L + Z₀)² + X_L²) ] [добування квадратного кореня]
```

Якщо навантаження містить лише активний опір (`X_L = 0`), формула спрощується до дійсного числа:

```
|Γ| = |R_L − Z₀| / (R_L + Z₀)
```

### 2. Строге означення та виведення зворотних втрат (Return Loss)

У радіочастотній інженерії вимірювання напруги на високих частотах є ускладненим через виникнення стоячих хвиль. Тому основним об'єктом вимірювань є потужність електромагнітної хвилі. Падаюча потужність `P_inc` та відбита потужність `P_ref` виражаються через напругу та дійсний хвильовий опір лінії `Z₀`:

```
P_inc = |V_pos|² / (2 · Z₀)

P_ref = |V_neg|² / (2 · Z₀)
```

Відношення відбитої потужності до падаючої дорівнює квадрату модуля коефіцієнта відбиття:

```
P_ref / P_inc = |V_neg|² / |V_pos|² = |Γ|²
```

Зворотні втрати (**Return Loss, RL**) за стандартом IEEE визначаються як логарифмічне відношення падаючої потужності до відбитої, виражене у децибелах (дБ):

```
RL = 10 · log₁₀(P_inc / P_ref)             [означення через відношення потужностей]
   = 10 · log₁₀(1 / |Γ|²)                   [підстановка P_ref / P_inc = |Γ|²]
   = −10 · log₁₀(|Γ|²)                      [властивість логарифма: log(1/x) = −log(x)]
   = −20 · log₁₀|Γ|                         [властивість логарифма: log(x²) = 2·log(x)]
```

Звідси отримуємо обернену формулу для розрахунку модуля коефіцієнта відбиття `|Γ|` з відомого значення зворотних втрат `RL` у децибелах:

```
|Γ| = 10^(−RL / 20)
```

Частка відбитої потужності у відсотках `P_ref %`:

```
P_ref / P_inc = |Γ|² = 10^(−RL / 10)
P_ref % = 100% · 10^(−RL / 10)
```

Частка переданої у навантаження потужності `P_load %`:

```
P_load / P_inc = 1 − |Γ|² = 1 − 10^(−RL / 10)
P_load % = 100% · (1 − 10^(−RL / 10))
```

### 3. Математичний зв’язок із коефіцієнтом стоячої хвилі (КСХ / VSWR)

Інтерференція падаючої та відбитої хвиль утворює у лінії стоячу хвилю з амплітудними пучностями (максимумами напруги `V_max`) та вузлами (мінімумами напруги `V_min`):

```
V_max = |V_pos| + |V_neg| = |V_pos| · (1 + |Γ|)

V_min = |V_pos| − |V_neg| = |V_pos| · (1 − |Γ|)
```

Коефіцієнт стоячої хвилі за напругою (**VSWR**, Voltage Standing Wave Ratio) визначається як відношення максимуму напруги до її мінімуму:

```
VSWR = V_max / V_min = (1 + |Γ|) / (1 − |Γ|)
```

Для виведення оберненої залежності `|Γ|` від `VSWR` виконуємо такі алгебраїчні перетворення:

```
VSWR · (1 − |Γ|) = 1 + |Γ|                 [домноження обох частин на (1 − |Γ|)]
VSWR − VSWR · |Γ| = 1 + |Γ|                 [розкриття дужок]
VSWR − 1 = |Γ| · (VSWR + 1)                 [згрупування доданків з |Γ|]
|Γ| = (VSWR − 1) / (VSWR + 1)              [вираження модуля |Γ|]
```

Підставляючи значення `|Γ|` у формулу зворотних втрат `RL`, маємо прямий математичний перерахунок між `VSWR` та `RL`:

```
RL = −20 · log₁₀( (VSWR − 1) / (VSWR + 1) )  [підстановка |Γ| через VSWR]
   = 20 · log₁₀( (VSWR + 1) / (VSWR − 1) )   [перевертання аргументу: −log(a/b) = log(b/a)]
```

Для зворотного перерахунку `RL → VSWR`:

```
1. |Γ|   = 10^(−RL / 20)
2. VSWR  = (1 + 10^(−RL / 20)) / (1 − 10^(−RL / 20))
```

### 4. Втрати на неузгодження (Mismatch Loss) та Mismatch Efficiency

Втрати на неузгодження (**Mismatch Loss, ML**) описують послаблення потужності, переданої у навантаження, внаслідок того, що частина енергії відбилася назад до джерела:

```
P_load = P_inc − P_ref = P_inc · (1 − |Γ|²)
```

Втрати на неузгодження в децибелах виражаються відношенням падаючої потужності до фактично поглинутої навантаженням:

```
ML = 10 · log₁₀(P_inc / P_load)             [означення втрат на неузгодження]
   = 10 · log₁₀(1 / (1 − |Γ|²))              [підстановка P_load / P_inc = 1 − |Γ|²]
   = −10 · log₁₀(1 − |Γ|²)                 [властивість логарифма: log(1/x) = −log(x)]
```

Виражаючи `ML` безпосередньо через зворотні втрати `RL`:

```
ML = −10 · log₁₀(1 − 10^(−RL / 10))        [формула через зворотні втрати RL]
```

Ефективність узгодження за потужністю (**Mismatch Efficiency, η_m**):

```
η_m = P_load / P_inc = 1 − |Γ|² = 1 − 10^(−RL / 10)
```

### 5. Трансформація імпедансу та вплив загасання кабелю

#### Трансформація імпедансу уздовж лінії передачі

Коли хвиля поширюється уздовж лінії з хвильовим опором `Z₀` на відстань `d` від навантаження `Z_L`, вхідний імпеданс `Z_in(d)` змінюється за формулою Телеграфних рівнянь:

```
Z_in(d) = Z₀ · (Z_L + j·Z₀·tan(β·d)) / (Z₀ + j·Z_L·tan(β·d))
```

При цьому фаза коефіцієнта відбиття змінюється на `2·β·d`, але його **модуль залишається незмінним** (у лінії без втрат):

```
Γ(d) = Γ_L · e^(−j·2·β·d)
|Γ(d)| = |Γ_L|
```

Це означає, що у лінії без втрат зворотні втрати `RL` є однаковими у будь-якій точці фідера.

#### Вплив згасання реального кабелю на виміряні зворотні втрати

У реальному коаксіальному кабелі з коефіцієнтом загасання `α` (непер/м або дБ/м) і довжиною `L` амплітуда хвилі зменшується за експоненційним законом `e^(−α·L)`.

Падаюча хвиля при проходженні від джерела до антени послаблюється у `10^(A_cable / 20)` разів (де `A_cable` — загасання кабелю у дБ). Відбита від антени хвиля повертається назад і долає таку саму відстань, послаблюючись ще раз на ті самі `A_cable` дБ.

Внаслідок подвійного проходу кабелю виміряні на початку кабелю зворотні втрати `RL_measured` виявляються **більшими (кращими)**, ніж реальні зворотні втрати антени `RL_antenna`:

```
RL_measured = RL_antenna + 2 · A_cable [дБ]
```

Модуль коефіцієнта відбиття на вході кабелю:

```
|Γ_in| = |Γ_antenna| · 10^(−2·A_cable / 20) = |Γ_antenna| · 10^(−A_cable / 10)
```

Це критичний практичний момент: якщо з'єднувальний кабель має власні втрати 3 дБ, а аналізатор кіл показує `RL = 16` дБ на вході кабелю, то реальні зворотні втрати антени становлять лише `RL_antenna = 16 − 2·3 = 10` дБ! Високе загасання кабелю «приховує» неузгодження антени.

### 6. Матриця розсіювання (S-параметри) двопортових кіл

Для каскаду радіочастотних пристроїв (наприклад атенюатор + фільтр + LNA) зв'язок між падаючими хвильними амплітудами `a₁, a₂` та відбитими `b₁, b₂` виражається матрицею S-параметрів:

```
b₁ = S₁₁ · a₁ + S₁₂ · a₂

b₂ = S₂₁ · a₁ + S₂₂ · a₂
```

де:
- `S₁₁` — коефіцієнт відбиття від входу 1 при узгодженому виході 2 (`a₂ = 0`). Зворотні втрати входу `RL₁ = −20·log₁₀|S₁₁|`.
- `S₂₂` — коефіцієнт відбиття від виходу 2 при узгодженому вході 1 (`a₁ = 0`). Зворотні втрати виходу `RL₂ = −20·log₁₀|S₂₂|`.
- `S₂₁` — коефіцієнт прямої передачі (підсилення або загасання).
- `S₁₂` — коефіцієнт зворотної передачі (ізоляція).

Якщо до виходу 2 приєднати навантаження з коефіцієнтом відбиття `Γ_L`, то ефективний вхідний коефіцієнт відбиття `Γ_in` з урахуванням повторних відбиттів дорівнює:

```
a₂ = Γ_L · b₂
b₂ = S₂₁ · a₁ + S₂₂ · Γ_L · b₂  ⇒  b₂ = (S₂₁ · a₁) / (1 − S₂₂ · Γ_L)

b₁ = S₁₁ · a₁ + S₁₂ · Γ_L · b₂
   = S₁₁ · a₁ + (S₁₂ · S₂₁ · Γ_L · a₁) / (1 − S₂₂ · Γ_L)

Γ_in = b₁ / a₁ = S₁₁ + (S₁₂ · S₂₁ · Γ_L) / (1 − S₂₂ · Γ_L)
```

Ця формула математично описує, як зворотні втрати навантаження `Γ_L` трансформуються через двопортник на його вхід.

### 8. Покроковий числовий приклад розрахунку для комплексного навантаження

**Умова задачі:**
Антена на частоті `f = 2.45` ГГц підключена до передавача з хвильовим опором `Z₀ = 50` Ом. Виміряний комплексний імпеданс антени становить `Z_L = 30 + j·20` Ом. Довжина з'єднувального коаксіального кабелю `L = 5` метрів, загасання кабелю на частоті 2.45 ГГц становить `A_unit = 0.4` дБ/м.

Необхідно розрахувати:
1. Комплексний коефіцієнт відбиття антени `Γ_antenna` та його модуль `|Γ_antenna|`.
2. Зворотні втрати безпосередньо на клемах антени `RL_antenna`.
3. КСХ на клемах антени `VSWR_antenna` та втрати на неузгодження `ML_antenna`.
4. Зворотні втрати `RL_measured` та `VSWR_measured`, які виміряє аналізатор кіл на початку 5-метрового кабелю.

#### Крок 1. Розрахунок комплексного коефіцієнта відбиття антени Γ_antenna

```
Z_L − Z₀ = (30 − 50) + j·20 = −20 + j·20      [різниця імпедансів]
Z_L + Z₀ = (30 + 50) + j·20 =  80 + j·20      [сума імпедансів]

Γ_antenna = (−20 + j·20) / (80 + j·20)         [відношення різниці до суми]
```

Множимо чисельник і знаменник на спряжене значення знаменника `(80 − j·20)`:

```
Знаменник: 80² + 20² = 6400 + 400 = 6800       [модуль знаменника у квадраті]

Чисельник: (−20 + j·20) · (80 − j·20)
         = −1600 + j·400 + j·1600 − j²·400     [перемноження дужок]
         = −1600 + 400 + j·2000                [враховано j² = −1]
         = −1200 + j·2000                      [додавання дійсних частин]

Γ_antenna = (−1200 / 6800) + j·(2000 / 6800)   [ділення частин на знаменник]
          = −0.1765 + j·0.2941                 [комплексна форма Γ]
```

#### Крок 2. Розрахунок модуля |Γ_antenna|

```
|Γ_antenna|² = (−0.1765)² + (0.2941)²          [сума квадратів дійсної та уявної частин]
             = 0.03115 + 0.08650 = 0.11765     [додавання квадратів]

|Γ_antenna|  = √0.11765 = 0.3430               [добування квадратного кореня]
```

#### Крок 3. Розрахунок зворотних втрат RL_antenna

```
RL_antenna = −20 · log₁₀(0.3430)              [формула зворотних втрат: RL = −20·log₁₀|Γ|]
           = −20 · (−0.4647)                  [обчислення логарифма: log₁₀(0.3430) = −0.4647]
           = 9.29 дБ                          [результат множення: −20 · (−0.4647) = 9.29]
```

#### Крок 4. Розрахунок КСХ (VSWR_antenna) та Mismatch Loss (ML_antenna)

```
VSWR_antenna = (1 + 0.3430) / (1 − 0.3430)     [підстановка |Γ| = 0.3430]
             = 1.3430 / 0.6570                [обчислення чисельника та знаменника]
             = 2.044                          [ділення: 1.3430 / 0.6570 = 2.044]

ML_antenna   = −10 · log₁₀(1 − |Γ|²)            [формула втрат на неузгодження]
             = −10 · log₁₀(1 − 0.11765)         [підстановка |Γ|² = 0.11765]
             = −10 · log₁₀(0.88235)             [віднімання в аргументі: 1 − 0.11765 = 0.88235]
             = −10 · (−0.05436)                 [обчислення логарифма: log₁₀(0.88235) = −0.05436]
             = 0.54 дБ                          [результат множення: −10 · (−0.05436) = 0.54]
```

#### Крок 5. Урахування загасання 5-метрового кабелю

Сумарне загасання кабелю у прямому напрямку `A_cable`:

```
A_cable = 5 м · 0.4 дБ/м = 2.0 дБ              [перемноження довжини на питоме загасання]
```

Виміряні на початку кабелю зворотні втрати `RL_measured` з урахуванням подвійного проходу:

```
RL_measured = RL_antenna + 2 · A_cable         [формула подвійного проходу загасання]
            = 9.29 дБ + 2 · 2.0 дБ
            = 9.29 + 4.0 = 13.29 дБ            [додавання загасання кабелю]
```

Обчислення коефіцієнта відбиття `|Γ_measured|` та `VSWR_measured` на початку кабелю:

```
|Γ_measured| = 10^(−13.29 / 20) = 0.2165       [перерахунок з RL у модуль Γ]

VSWR_measured = (1 + 0.2165) / (1 − 0.2165)
              = 1.2165 / 0.7835 = 1.55         [ділення чисельника на знаменник]
```

**Аналіз результатів:**
Безпосередньо на антені зворотні втрати становлять `9.29` дБ (КСХ = 2.04). Проте при вимірюванні через 5-метровий кабель із загасанням 2 дБ прилад покаже `RL = 13.29` дБ (КСХ = 1.55). Загасання кабелю штучно покращило виміряний КСХ від 2.04 до 1.55. Цей приклад показує важливість калібрування VNA безпосередньо на кінці кабелю в точці підключення антени.
