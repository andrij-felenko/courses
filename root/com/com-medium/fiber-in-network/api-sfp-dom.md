# 📋 Інтерфейс цифрового моніторингу SFF-8472 (SFP DOM/DDM)

Ця специфікація описує апаратно-програмний інтерфейс цифрової діагностики та моніторингу (**DOM** — *Digital Optical Monitoring* / **DDM** — *Digital Diagnostic Monitoring*) оптичних приймально-передавальних модулів форм-факторів SFP, SFP+ та SFP28 згідно з промисловим стандартом **SFF-8472**.

### Фізичний рівень, розпіновка роз'єму та шина I2C

Інтерфейс моніторингу спирається на послідовну двопровідну шину **I2C** (*Inter-Integrated Circuit*), заведену на крайні контакти 20-пінового роз'єму SFP. Сигнали шини мають відкритий колектор і потребують зовнішніх підтягувальних резисторів (*pull-up*) номіналом 4.7–10 кОм до лінії живлення +3.3 В на материнській платі комутатора чи маршрутизатора.

```text
               СХЕМА ПІДКТЮЧЕННЯ ШИНИ I2C ТА СИГНАЛІВ КЕРУВАННЯ SFP
 ┌───────────────────────────────┐               ┌───────────────────────────────┐
 │   МАПЕР / КОМУТАТОР (HOST)    │               │    ОПТИЧНИЙ МОДУЛЬ (SFP)      │
 │                               │               │                               │
 │  +3.3V ──[R_pu]─── SCL (Pin 5)├───────────────┤SCL ──► Контроллер DOM (MCU)   │
 │  +3.3V ──[R_pu]─── SDA (Pin 4)├───────────────┼SDA ◄─► EEPROM 0xA0 / 0xA2      │
 │                               │               │                               │
 │  +3.3V ──[R_pu]─ Mod_ABS(Pin 6)├──────────────┤GND (Низький рівень присадки)  │
 │                   TX_Disable (2)├────────────►│Вимкнення лазера (High = Off)  │
 │  +3.3V ──[R_pu]─── TX_Fault (3)├──────────────┼Аварія лазера (Open Drain)     │
 │  +3.3V ──[R_pu]─── RX_LOS (15) ├──────────────┼Втрата сигналу (Open Drain)    │
 └───────────────────────────────┘               └───────────────────────────────┘
```

Розподіл критичних контактів 20-пінового роз'єму SFP, що відповідають за діагностику та життєвий цикл оптичного модуля:
- **Pin 2 (TX Disable):** Вхідний цифровий сигнал вимкнення передавача. Високий рівень (2.0…3.3 В) миттєво знеструмлює лазерний діод.
- **Pin 3 (TX Fault):** Вихідний сигнал апаратного збою лазера з відкритим колектором. Високий рівень свідчить про вихід струму зміщення лазера за безпечні межі або пробій драйвера.
- **Pin 4 (SDA):** Послідовна лінія даних шини I2C.
- **Pin 5 (SCL):** Послідовна лінія тактування шини I2C (тактова частота до 100 кГц, стандартний режим).
- **Pin 6 (Mod_ABS / MOD-DEF0):** Сигнал присутності модуля у слоті. На платі трансивера цей контакт жорстко заземлений на GND. Хост підтягує його до +3.3 В; коли модуль вставляють у порт, напруга падає до 0 В, сповіщаючи процесор комутатора про факт підключення обладнання (Hot-Plug Event).
- **Pin 15 (VCCR):** Живлення приймальної частини (+3.3 В ± 5%).
- **Pin 16 (VCCT):** Живлення передавальної частини (+3.3 В ± 5%).
- **Pin 15 (RX LOS):** Сигнал втрати оптичного сигналу на приймачі (*Loss of Signal*). Високий рівень свідчить про те, що оптична потужність на фотодіоді впала нижче порогу чутливості.

### Адресація пам'яті I2C та структура сторінок SFF-8472

Контролер трансивера відповідає на дві 7-бітні I2C-адреси. З точки зору процесора хоста пам'ять модуля представлена у вигляді двох логічних мікросхем EEPROM обсягом по 256 байтів кожна:

1. **Адреса `0xA0` (7-бітна адреса `0x50`):**
   Містить статичну інформацію про специфікацію оптичного трансивера: форм-фактор (SFP/SFP+), тип оптичного роз'єму (LC/SC), тип кабелю (SMF/MMF), довжину хвилі випромінювання (наприклад, 1310 нм), підтримувану швидкість (1.25G, 10G, 25G), назву виробника, артикул (Part Number), серійний номер та дату виготовлення.
2. **Адреса `0xA2` (7-бітна адреса `0x51`):**
   Описує таблицю цифрового моніторингу DOM/DDM реального часу.

```text
               КАРТА ПАМ'ЯТІ ІНТЕРФЕЙСУ SFF-8472 (АДРЕСА 0xA2 / 0x51)
 ┌───────────┬───────────────────────────────────────────────────────────┐
 │ Байт      │ Призначення та вміст                                      │
 ├───────────┼───────────────────────────────────────────────────────────┤
 │ 00 – 39   │ Порогові значення тривог і застережень (Alarm & Warning)  │
 │ 40 – 55   │ Зарезервовано для розширення специфікації                 │
 │ 56 – 91   │ Константи калібрування зовнішніх датчиків (Calibration)   │
 │ 92 – 94   │ Константа контрольної суми калібрувальних полів           │
 │ 95        │ Контрольна сума рядків 0..94 (CC_DMI)                     │
 │ 96 – 105  │ ДАТЧИКИ РЕАЛЬНОГО ЧАСУ (Real-Time Diagnostic Values)      │
 │ 106 – 109 │ Зарезервовано                                             │
 │ 110       │ Статусні прапорці стану (Data Ready, LOS, Soft TX Disable) │
 │ 111       │ Зарезервовано                                             │
 │ 112 – 117 │ Апаратні прапорці тривог (Alarm & Warning Flags)          │
 │ 118 – 119 │ Зарезервовано                                             │
 │ 120 – 127 │ Таблиця паролів та вибору сторінок (Page Select 127)      │
 │ 128 – 247 │ Паролезахищена користувацька таблиця EEPROM               │
 │ 248 – 255 │ Таблиця вендорських даних                                 │
 └───────────┴───────────────────────────────────────────────────────────┘
```

### Таблиця порогів тривог і застережень (Байти 00–39)

Перед початком експлуатації керувальне програмне забезпечення зчитує з байтів `00…39` таблиці `0xA2` фабричні межі безпечної роботи даної конкретної оптики:

- **Temp High/Low Alarm (Байти 00–03):** Абсолютні граничні температури кристала (наприклад, +85°C та -5°C). При виході за ці межі модуль може незворотно вийти з ладу.
- **Temp High/Low Warning (Байти 04–07):** Попереджувальні пороги температури (наприклад, +75°C та 0°C), що свідчать про проблеми з вентиляцією шафи.
- **Voltage High/Low Alarm (Байти 08–11):** Граничні напруги живлення (наприклад, 3.63 В та 2.97 В).
- **Bias High/Low Alarm (Байти 16–19):** Граничні струми зміщення лазера (наприклад, 80 мА та 2 мА).
- **TX Power High/Low Alarm (Байти 24–27):** Гранична вихідна оптична потужність (наприклад, +5.0 дБм та -4.0 дБм).
- **RX Power High/Low Alarm (Байти 32–35):** Гранична приймана потужність (наприклад, -2.0 дБм перевантаження та -24.0 дБм чутливість).

### Реєстри телеметрії реального часу (Байти 96–105)

Показники датчиків телеметрії оновлюються внутрішнім мікроконтролером оптичного модуля кожні 10–100 мс. Усі значення записані у формі 16-бітних цілих чисел у форматі Big-Endian (старший байт MSB передує молодшому LSB):

| Реєстри (MSB, LSB) | Назва параметра | Формат даних | Одиниця вимірювання | Формула перетворення |
|---|---|---|---|---|
| **96, 97** | Температура модуля (`Temp`) | 16-біт зі знаком (int16_t) | °C | `Temp_C = Value / 256.0` |
| **98, 99** | Напруга живлення (`VCC`) | 16-біт без знаку (uint16_t)| Вольт | `VCC_V = Value / 10000.0` |
| **100, 101**| Струм зміщення лазера (`TX Bias`)| 16-біт без знаку (uint16_t)| мА (міліампери) | `I_bias_mA = Value / 500.0` |
| **102, 103**| Вихідна потужність TX (`TX Power`)| 16-біт без знаку (uint16_t)| мВт / дБм | `P_tx_mW = Value / 10000.0` |
| **104, 105**| Вхідна потужність RX (`RX Power`)| 16-біт без знаку (uint16_t)| мВт / дБм | `P_rx_mW = Value / 10000.0` |

### Математика внутрішнього та зовнішнього калібрування

Стандарт SFF-8472 визначає два методи інтерпретації сирих чисел із байтів `96…105`. Спосіб калібрування вказується в прапорці **Bit 4 Byte 92** сторінки `0xA0`:

1. **Внутрішнє калібрування (*Internal Calibration*):**
   Мікроконтролер трансивера самостійно перераховує нелінійність своїх АЦП і записує в байти `96…105` вже остаточно відкалібровані двійкові значення. У 99% сучасних SFP+ модулів застосовується саме це калібрування. Формули лінійної конвертації:
   ```text
   T [°C]      = raw_int16(Byte 96, 97) / 256.0
   VCC [В]     = raw_uint16(Byte 98, 99) / 10000.0
   I_bias [мА] = raw_uint16(Byte 100, 101) / 500.0
   P_TX [мВт]  = raw_uint16(Byte 102, 103) / 10000.0
   P_RX [мВт]  = raw_uint16(Byte 104, 105) / 10000.0
   ```

   Логарифмічний перерахунок оптичної потужності з міліват у децибел-мілівати (дБм):
   ```text
   P [дБм] = 10 · log₁₀( P [мВт] )
   ```
   Якщо `raw_uint16 == 0`, виміряна потужність дорівнює нулю (світло відсутнє). У цьому разі логарифм прямує до мінус нескінченності, тому програма виставляє фіксований поріг відсутності сигналу `−40.0 дБм`.

2. **Зовнішнє калібрування (*External Calibration*):**
   У застарілих або спеціалізованих модулях байти `96…105` містять сирі значення АЦП. Хост-процесор зобов'язаний зчитати поліноміальні коефіцієнти калібрування з байтів `56…91` сторінки `0xA2` та застосувати їх за формулою:
   ```text
   P_real = Slope · Value_raw + Offset
   ```
   Для фотодіода RX використовується квадратний поліном четвертого порядку для компенсації нелінійності p-i-n кристала на малих рівнях потужності.
