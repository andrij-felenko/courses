# 🧮 Виведення співвідношення між ефективною апертурою та підсиленням

Фундаментальна формула `A_e = (λ² / 4π) · G` пов'язує просторову площу прийому антени з її коефіцієнтом спрямованої дії. Цей документ містить повний термодинамічний доказ цього співвідношення через рівноважне випромінювання Чорного тіла (метод Найквіста — Планка), пряме електричне виведення для герцевого диполя та аналіз впливу омічних втрат антени.

## 1. Термодинамічне виведення (метод термодинамічної рівноваги)

Уявимо ізольовану замкнену порожнину з ідеально відбиваючими стінками, що перебуває у стані термодинамічної рівноваги за температури `T`. Усередині порожнини існує однорідне, ізотропне шумове електромагнітне випромінювання (випромінювання чорного тіла).

Помістимо в цю порожнину дві антени, кожна з яких підключена до власного узгодженого опору `R` (навантаження) тієї ж температури `T`:

- **Антена 1:** Уявна ізотропна антена без втрат з апертурою `A_e1 = A_e,iso` та коефіцієнтом спрямованої дії `G₁ = 1`.
- **Антена 2:** Довільна напрямлена антена з апертурою `A_e2(θ, φ)` та підсиленням `G₂(θ, φ)`.

За Другим законом термодинаміки, чистий потік енергії між будь-якими двома тілами з однаковою температурою в замкненій системі дорівнює нулю. Це означає, що потужність, яку антена приймає з навколишнього простору й віддає у свій опір `R`, мусить **точно дорівнювати** тепловій шумової потужності, яку цей опір `R` перевипромінює через антену назад у простір.

### Крок 1: Шумова потужність опору (формула Найквіста)

За формулою Найквіста, тепловий шум напруги на клемах опору `R` у вузькій смузі частот `Δf` віддає в узгоджене навантаження потужність:

```
P_R = k_B · T · Δf           [тепловий шум Найквіста у смузі Δf]
```

де `k_B` — стала Больцмана (`1.380649 × 10⁻²³ Дж/К`). Антена без втрат випромінює цю потужність у простір відповідно до своєї діаграми спрямованості.

### Крок 2: Густина спектральної енергії в порожнині

У термодинамічній рівновазі густина спектральної енергії чорного випромінювання на одиницю об'єму та на одиницю смуги частот виражається формулою Релея — Джинса (яка є високочастотним наближенням формули Планка для радіочастотного діапазону `h f « k_B T`):

```
u_f = (8π · f² / c³) · k_B · T      [густина енергії Релея — Джинса на м³·Гц]
u_f = (8π / (λ² · c)) · k_B · T     [підстановка c = f · λ]
```

Оскільки випромінювання в порожнині ізотропне (поширюється рівномірно за всіма напрямками зі швидкістю світла `c`), повна густина потоку потужності на одиницю тілесного кута `dΩ` дорівнює:

```
S_Ω = u_f · c / (4π)                [інтегрування по повній сфері 4π стер]
S_Ω = (2 / λ²) · k_B · T            [спектральна густина потоку на стер]
```

Враховуючи, що будь-яка невипадково поляризована антена приймає лише **одну поляризацію** із двох неполяризованих ортогональних компонент ізотропного шуму, ефективна густина потоку потужності на одиницю тілесного кута ділиться навпіл:

```
S_Ω,pol = (1 / λ²) · k_B · T        [потік енергії для однієї поляризації]
```

### Крок 3: Баланс потужності для ізотропної антени

Ізотропна антена ловить енергію з усіх напрямків однаково. Прийнята нею потужність у смузі `Δf` обчислюється інтегруванням густини потоку по всій сфері `4π` стеррадіан:

```
P_rec = ∬ S_Ω,pol · A_e,iso · dΩ · Δf    [інтеграл потоку по сфері]
P_rec = S_Ω,pol · A_e,iso · Δf · ∬ dΩ    [винесення сталих величин]
P_rec = S_Ω,pol · A_e,iso · Δf · (4π)    [повний тілесний кут сфери дорівнює 4π]
P_rec = ((1 / λ²) · k_B · T) · A_e,iso · Δf · (4π) [підстановка S_Ω,pol]
```

Прирівнюємо прийняту з простору потужність `P_rec` до теплового шуму Найквіста `P_R = k_B · T · Δf`, який опір подає на антену:

```
((4π / λ²) · A_e,iso) · k_B · T · Δf = k_B · T · Δf [рівновага прийому й випромінювання]
(4π / λ²) · A_e,iso = 1              [скорочення k_B · T · Δf з обох боків]
A_e,iso = λ² / (4π)                  [визначення апертури ізотропної антени]
```

Це фундаментальний результат: **ізотропна антена перехоплює електромагнітну енергію з ефективної площі `λ² / (4π)`**.

### Крок 4: Узагальнення для довільної напрямленої антени

Для антени з коефіцієнтом спрямованої дії `G(θ, φ)`, що концентрує випромінювання у `G` разів сильніше за ізотропну у своєму головному напрямку, її ефективна апертура в цьому напрямку зростає пропорційно `G`:

```
A_e = A_e,iso · G                   [визначення за відносною спрямованістю]
A_e = (λ² / 4π) · G                 [основне фундаментальне співвідношення]
```

## 2. Пряме електричне виведення для елементарного герцевого диполя

Перевіримо той самий результат принципово іншим шляхом — через прямий розрахунок наведеної ЕРС та опору випромінювання для елементарного диполя довжиною `dl « λ`.

1. Напруга холостого ходу, наведена електричним полем `E` в герцевому диполі:

```
V_oc = E · dl                        [проекція поля E на довжину провідника dl]
```

2. Опір випромінювання герцевого диполя розраховується через інтегрування вектора Пойнтінга у далекому полі:

```
R_r = 80π² · (dl / λ)²              [теоретичний опір випромінювання герцевого диполя]
```

3. За умови сопряженого узгодження навантаження (`R_L = R_r`), максимальна корисна потужність у навантаженні:

```
P_r = |V_oc|² / (4 · R_r)           [формула максимальної потужності Тевеніна]
P_r = (E² · dl²) / (4 · 80π² · (dl / λ)²) [підстановка V_oc та R_r]
P_r = (E² · λ²) / (320π²)           [скорочення довжини диполя dl]
```

4. Густина потоку потужності падаючої плоскої хвилі у вакуумі виражається через амплітуду електричного поля `E`:

```
S = E² / (2 · Z₀)                   [де Z₀ = 120π ≈ 377 Ом — хвильовий опір вакууму]
S = E² / (240π)                     [підстановка Z₀ = 120π]
```

5. Знаходимо ефективну апертуру як відношення прийнятої потужності `P_r` до густини потоку `S`:

```
A_e = P_r / S                       [визначення ефективної апертури]
A_e = [(E² · λ²) / (320π²)] / [E² / (240π)] [підстановка P_r та S]
A_e = (240π / 320π²) · λ²           [скорочення амплітуди поля E]
A_e = (3 / (4π)) · λ²               [алгебраїчне спрощення дробу]
A_e ≈ 0.2387 · λ²                   [числове значення для герцевого диполя]
```

6. Напрямленість герцевого диполя відома з його тороїдальної діаграми спрямованості `D(θ) = 1.5 · sin²θ` і дорівнює `G = 1.5` (або `1.76 дБ`). Підставимо значення `G = 1.5` у загальну формулу `A_e = (λ² / 4π) · G`:

```
A_e = (λ² / 4π) · 1.5               [підстановка G = 1.5 у загальну формулу]
A_e = (1.5 / 4π) · λ²               [перегрупування множників]
A_e = (3 / (4π)) · λ²               [абсолютний збіг із прямим електричним виведенням!]
```

Прямий електричний розрахунок диполя дав точно такий самий результат, як і термодинамічний аналіз за методом Найквіста — Планка.

## 3. Виведення для півхвильового диполя

Для реального півхвильового диполя довжиною `L = λ / 2` розподіл струму є синусоїдальним `I(z) = I_0 · cos(2π z / λ)`.

1. Ефективна висота півхвильового диполя дорівнює:

```
h_eff = λ / π                       [інтеграл синусоїдального струму вздовж плечей]
```

2. Напруга холостого ходу:

```
V_oc = E · h_eff = E · λ / π
```

3. Опір випромінювання півхвильового диполя у вільному просторі дорівнює `R_r ≈ 73.13 Ом`.
4. Максимальна прийнята потужність у сопряженому навантаженні:

```
P_r = |V_oc|² / (4 · R_r)
P_r = (E² · λ² / π²) / (4 · 73.13)
P_r = (E² · λ²) / (2886.7)
```

5. Ділимо на густину потоку потужності `S = E² / (240π)`:

```
A_e = P_r / S
A_e = [(E² · λ²) / (2886.7)] / [E² / (240π)]
A_e = (240π / 2886.7) · λ²
A_e ≈ 0.2616 · (λ² / 2) ≈ 0.1308 · λ²
```

Оскільки коефіцієнт підсилення півхвильового диполя дорівнює `G = 1.643` (2.15 дБі), підставимо його у формулу `A_e = (λ² / 4π) · G`:

```
A_e = (λ² / 4π) · 1.643 ≈ 0.13075 · λ²
```

Результати знову збігаються з високою точністю.

## 4. Вплив омічних втрат та ефективність випромінювання

Якщо антена має омічні втрати у провідниках чи діелектриках (`R_L > 0`), її **ефективність випромінювання** (*radiation efficiency*) визначається як:

```
e_r = R_r / (R_r + R_L)             [частка потужності, що випромінюється / приймається]
```

У цьому випадку реальне підсилення антени `G` пов'язане з коефіцієнтом спрямованої дії `D` співвідношенням `G = e_r · D`.

Фактична ефективна апертура з урахуванням втрат дорівнює:

```
A_e = e_r · A_em = e_r · (λ² / 4π) · D = (λ² / 4π) · G
```

Це доводить, що формула `A_e = (λ² / 4π) · G` враховує омічні втрати антени автоматично, якщо під `G` розуміють **реальне підсилення антени** (*realized gain*), а не лише її геометричну спрямованість `D`.
