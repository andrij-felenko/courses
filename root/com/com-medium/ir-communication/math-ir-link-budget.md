# 🧮 Розрахунок оптичного бюджету та дальності ІЧ-лінії зв'язку

Дальність та надійність бездротового інфрачервоного каналу визначаються геометричним розходженням оптичного пучка, кутовою діаграмою випромінювача, шумами фотоприймального тракту, спектральним узгодженням компонентів, френелівськими втратами на захисному склі та інтегральним поглинанням у повітряному середовищі.

### 1. Просторова діаграма випромінювача та показник Ламберта

Сила випромінювання напівпровідникового світлодіода (англ. *Radiant Intensity*) `I_e` вимірюється в міліватах на стерадіан (`мВт/ср`). Просторова густина випромінювання під кутом `θ` відносно головної оптичної осі описується узагальненим законом Ламберта:

```
I_e(θ) = I_e(0) · cosᵐ(θ)
```

Показник степеня `m` визначає спрямованість оптичного променя (вузькість лінзи діода) і обчислюється через кут половинної потужності `θ₁/₂` (кут, за якого інтенсивність спадає вдвічі, тобто `I_e(θ₁/₂) / I_e(0) = 0.5`):

```
cosᵐ(θ₁/₂) = 0.5
m · ln(cos θ₁/₂) = ln(0.5)
m = -ln(2) / ln(cos θ₁/₂)
```

**Приклад розрахунку показника Ламберта для лінзованого світлодіода:**

Для світлодіода з кутом половинної інтенсивності `θ₁/₂ = 20°`:

```
m = -ln(2) / ln(cos 20°)
  = -0.69315 / ln(0.93969)      [підстановка косинуса кута 20°]
  = -0.69315 / (-0.06220)       [обчислення натурального логарифма]
  = 11.14                       [розрахунковий показник спрямованості]
```

Для широкого безлінзового випромінювача з `θ₁/₂ = 60°`:
`cos(60°) = 0.5`, отже `m = -ln(2) / ln(0.5) = 1.0` (класичне дифузне джерело).

### 2. Інтегральний оптичний потік випромінювача

Повна потужність випромінювання світлодіода `Φ_total` (у міліватах) пов'язана з осьовою силою світла `I_e(0)` через інтеграл по півсфері тілесного кута:

```
Φ_total = ∫ I_e(θ) dΩ
        = ∫₀²ᵖⁱ dφ ∫₀ᵖⁱ/² I_e(0) · cosᵐ(θ) · sin(θ) dθ     [інтегрування за сферичними координатами]
        = 2·π · I_e(0) · [ -cosᵐ⁺¹(θ) / (m + 1) ]₀ᵖⁱ/²    [первісна від тригонометричного добутку]
        = 2·π · I_e(0) / (m + 1)                           [значення на межах 0 та π/2]
```

Звідси осьова сила світла випромінювача з оптичною потужністю `Φ_total = 50 мВт` та кутом `θ₁/₂ = 20°` (`m = 11.14`):

```
I_e(0) = Φ_total · (m + 1) / (2·π)
       = 50 · (11.14 + 1) / (2 · 3.14159)               [підстановка потужності та числа пі]
       = 50 · 12.14 / 6.28318                           [перемноження в чисельнику]
       = 607.0 / 6.28318                                [ділення на подвоєне число пі]
       = 96.61 мВт/ср                                   [розрахункова осьова сила випромінювання]
```

### 3. Освітленість на приймачі та закон обернених квадратів

Густина оптичного потоку або опроміненість (англ. *Irradiance*) `E_e` на площині фотоприймача, розташованого на відстані `d` під кутом приходу `φ` до нормалі детектора, зменшується пропорційно квадрату відстані:

```
E_e = I_e(θ) · cos(φ) / d²
```

Якщо передавач і приймач орієнтовані совісно вздовж головних оптичних осей (`θ = 0°`, `φ = 0°`, отже `cos(θ) = 1` та `cos(φ) = 1`), формула спрощується:

```
E_e = I_e(0) / d²
```

Гранична дальність зв'язку `d_max` досягається тоді, коли освітленість на приймачі дорівнює мінімальному порогу спрацьовування компаратора `E_e_min`:

```
d_max = √( I_e(0) · cosᵐ(θ) · cos(φ) / E_e_min )
```

**Покроковий розрахунок граничної дальності прямого зв'язку:**

Вихідні параметри:
- Імпульсна сила випромінювання діода по осі при струмі `I_peak = 400 мА`: `I_e(0) = 250 мВт/ср` (типове значення для діода TSAL6100);
- Чутливість інтегрованого приймача TSOP4838: `E_e_min = 0.12 мВт/м²` (`0.00012 мВт/см²`);
- Кут відхилення передавача від осі `θ = 15°` (`m = 11.14`);
- Кут прийому `φ = 0°`.

```
d_max = √( I_e(0) · cosᵐ(15°) · cos(0°) / E_e_min )
      = √( 250 · (cos 15°)¹¹·¹⁴ · 1.0 / 0.12 )     [підстановка параметрів системи]
      = √( 250 · (0.96593)¹¹·¹⁴ / 0.12 )          [обчислення косинуса кута 15°]
      = √( 250 · 0.6725 / 0.12 )                  [піднесення до степеня m=11.14]
      = √( 168.125 / 0.12 )                       [розрахунок ефективної сили світла]
      = √( 1401.04 )                              [ділення на поріг чутливості]
      = 37.43 м                                   [гранична теоретична дальність]
```

У реальних умовах через пил у повітрі, відхилення тримальної частоти та оптичні втрати на захисному склі практична дальність становить `15..20 м`.

### 4. Спектральне узгодження та температурний дрейф

Реальний фотострум приймача визначається інтегралом спектрального перекриття між нормованим спектром випромінювання світлодіода `S(λ)`, спектральною чутливістю фотодіода `R_λ(λ)` та кривою пропускання оптичного фільтра корпусу `T_filter(λ)`:

```
I_sig = A_det · E_e · ∫ S(λ) · R_λ(λ) · T_filter(λ) dλ
```

Якщо передавач використовує світлодіод на `880 нм` замість номінальних `940 нм`, спектральний коефіцієнт перекриття падає з `0.95` до `0.65`, що еквівалентно додатковому згасанню сигналу на `1.65 дБ`.

Крім того, при нагріванні p-n переходу світлодіода внаслідок протікання великого імпульсного струму ширина забороненої зони арсеніду галію звужується за емпіричним законом Варшні:

```
E_g(T) = E_g(0) - (α · T²) / (T + β)
```

де `α = 5.4 · 10⁻⁴ еВ/К`, а `β = 204 К`.

Це призводить до червоного зміщення довжини хвилі випромінювання зі швидкістю `Δλ / ΔT ≈ +0.25 нм/К` та падіння квантового виходу випромінювальної рекомбінації за експоненційним законом:

```
P_opt(T) = P_opt(25°C) · exp( -(T - 25°C) / T₀ )
```

де `T₀ ≈ 100 К` — характеристична температура прямозонного напівпровідника. При нагріванні кристала до 75°C оптична потужність спадає приблизно на 40% (`-2.2 дБ`).

### 5. Оптичні втрати на межах середовищ (формули Френеля)

Оптичний промінь, що проходить крізь захисне пластикове або скляне віконце корпусу приладу, зазнає втрат на відбиття на двох поверхнях (повітря-пластик та пластик-повітря). За нормального падіння променя коефіцієнт відбиття Френеля на одній межі з показником заломлення `n = 1.5` (полікарбонат або оргскло) дорівнює:

```
R_fresnel = ( (n - 1) / (n + 1) )²
          = ( (1.5 - 1.0) / (1.5 + 1.0) )²          [підстановка показника заломлення]
          = ( 0.5 / 2.5 )²                          [обчислення різниці та суми]
          = ( 0.2 )²                                [ділення дробів]
          = 0.04 = 4.0%                             [втрати на одній оптичній поверхні]
```

Сумарний коефіцієнт пропускання двох поверхонь захисного вікна без просвітлювального покриття становить `T_window = (1 - R_fresnel)² = (0.96)² = 0.9216` (втрата близько `0.35 дБ` оптичної потужності).

### 6. Джерела шумів приймального тракту: квантовий та тепловий шум

Повний еквівалентний шумовий струм на вході підсилювача складається з двох незалежних фізичних складових: дробового шуму та теплового шуму Джонсона-Найквіста.

1. **Квантовий дробовий шум фотоструму (Shot Noise)**.
Під дією постійної сонячної засвітки `E_bg ≈ 100 Вт/м²` фотодіод генерує постійний струм:

```
I_bg = R_λ · E_bg · A_det
     = 0.6 · 100 · (4.5 · 10⁻⁶)       [підстановка параметрів фону]
     = 2.7 · 10⁻⁴ А = 270 мкА         [постійний струм засвітки]
```

де `R_λ = 0.6 А/Вт` — спектральна чутливість кремнію, `A_det = 4.5 мм²` — площа фотодіода.

Середньоквадратичний квантовий струм шуму в смузі фільтра `B = f₀ / Q ≈ 38000 / 15 ≈ 2533 Гц`:

```
i_shot = √( 2 · q · I_bg · B )
       = √( 2 · (1.602 · 10⁻¹⁹) · (2.7 · 10⁻⁴) · 2533 )   [підстановка заряду, струму фону та смуги]
       = √( 2.191 · 10⁻¹⁹ )                                [перемноження підкореневого виразу]
       = 4.68 · 10⁻¹⁰ А = 0.468 нА                         [добування квадратного кореня]
```

де `q = 1.602 · 10⁻¹⁹ Кл` — елементарний заряд електрона.

2. **Тепловий шум резистора зворотного зв'язку TIA (Thermal Noise)**.
Трансімпедансний підсилювач містить резистор зворотного зв'язку `R_f ≈ 1.0 МОм` (`10⁶ Ом`), що перетворює струм у напругу. За абсолютної температури `T = 300 К` (27°C) струм теплового шуму Джонсона-Найквіста дорівнює:

```
i_thermal = √( 4 · k_B · T · B / R_f )
          = √( 4 · (1.3806 · 10⁻²³) · 300 · 2533 / 10⁶ )   [підстановка сталої Больцмана і температури]
          = √( 4.197 · 10⁻²³ )                             [обчислення підкореневого добутку]
          = 2.05 · 10⁻¹² А = 0.00205 нА                    [добування квадратного кореня]
```

де `k_B = 1.3806 · 10⁻²³ Дж/К` — стала Больцмана.

Порівняння показує: квантовий дробовий шум сонячної засвітки (`0.468 нА`) перевищує власний тепловий шум підсилювача (`0.002 нА`) більш ніж у 200 разів. Таким чином, дальність оптичного зв'язку на відкритому просторі лімітується виключно флуктуаціями фонового сонячного світла (режим *Background Limited Infrared Performance*, BLIP).

### 7. Розрахунок енергетичного запасу лінії (Link Margin)

Енергетичний запас лінії зв'язку (англ. *Link Margin*) `M_link` на робочій відстані `d = 10 м` показує перевищення реальної освітленості над порогом чутливості:

```
E_e(10м) = I_e(0) / d²
         = 250 / 10²                    [ділення на квадрат відстані 10 метрів]
         = 250 / 100                    [піднесення 10 до квадрата]
         = 2.50 мВт/м²                  [освітленість на приймачі на 10 м]
```

Енергетичний запас у децибелах:

```
M_link = 10 · log₁₀( E_e / E_e_min )
       = 10 · log₁₀( 2.50 / 0.12 )      [ділення на поріг чутливості TSOP4838]
       = 10 · log₁₀( 20.833 )           [обчислення відношення рівнів]
       = 10 · 1.3187                    [обчислення десяткового логарифма]
       = 13.19 дБ                       [запас затухання лінії на відстані 10 м]
```

Запас `13.19 дБ` гарантує надійний прийом навіть при запиленні захисного скла та значних кутових відхиленнях пульта від оптичної осі.

### 8. Модель дифузного відбиття від стін (NLOS)

Якщо прямий оптичний промінь перекритий перешкодою, зв'язок підтримується за рахунок розсіяного відбиття від стелі або стін. Опроміненість відбитим променем від ділянки стіни площею `A_wall` з коефіцієнтом відбиття `ρ` на відстанях `d_1` (передавач-стіна) та `d_2` (стіна-приймач) розраховується за формулою:

```
E_e_refl = (I_e(θ₁) · ρ · A_wall · cos(α₁) · cos(α₂)) / (π · d₁² · d₂²)
```

де `α₁` — кут падіння променя на поверхню, а `α₂` — кут спостереження відбитої площадки приймачем. Для білої матової фарби (`ρ ≈ 0.7..0.8`) втрати потужності при розсіянні становлять `25..35 дБ`, що обмежує практичну дальність непрямого керування межами `3..5 метрів`.
