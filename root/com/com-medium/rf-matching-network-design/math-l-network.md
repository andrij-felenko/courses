# 🧮 Математика узгоджувальних кіл та L-ланок

Математична задача узгодження імпедансів зводиться до перетворення заданого комплексного опору навантаження `Z_L = R_L + jX_L` у комплексно-спряжений опір джерела `Z_S* = R_S - jX_S` на робочій частоті `f₀`. При такому співвідношенні реактивні складові повністю взаємно компенсуються, утворюючи резонанс, а активні опори стають рівними. Це забезпечує передачу максимальної активної потужності від джерела до навантаження без шкідливого відбиття електромагнітної хвилі назад у передавач.

У цьому розділі наведено строге математичне виведення теореми про максимальну передачу потужності, розрахунок еквівалентних перетворень послідовних і паралельних LC-ланцюгів, алгоритм розрахунку L-подібних і П-подібних узгоджувальних кіл, а також виведення формул для прямого узгодження складних реактивних імпедансів.

### 1. Теорема про максимальну передачу потужності (Теорема Якобі)

Розглянемо еквівалентну схему генератора (джерела сигналу) з внутрішнім комплексним імпедансом `Z_S = R_S + jX_S` та ЕРС `V_S`, підключеного до пасивного навантаження з імпедансом `Z_L = R_L + jX_L`.

Повний опір замкненого електричного кола обчислюється як сума комплексних імпедансів джерела та навантаження:

```
Z_total = Z_S + Z_L
        = (R_S + R_L) + j(X_S + X_L)     [групування активної та реактивної частин]
```

Дійсне значення (модуль) струму `I`, що протікає крізь коло, виражається через модуль повного імпедансу за законом Ома для змінного струму:

```
I = |V_S| / |Z_total|
  = |V_S| / √((R_S + R_L)² + (X_S + X_L)²)     [модуль комплексного числа: |a+jb| = √(a²+b²)]
```

Корисна активна потужність `P_L`, яка виділяється на активному опорі навантаження `R_L` і перетворюється на корисну роботу (або випромінюється антеною), визначається виразом:

```
P_L = I² · R_L                            [закон Джоуля-Ленца для активної потужності]
    = (|V_S|² · R_L) / ((R_S + R_L)² + (X_S + X_L)²)  [підстановка модуля струму I]
```

Аналіз цього виразу показує, що потужність `P_L` залежить від двох незалежних змінних навантаження: реактивності `X_L` та активного опору `R_L`. Знайдемо умови, за яких ця потужність набуває абсолютного математичного максимуму.

#### Перший крок: оптимізація за реактивністю `X_L`

Знаменник виразу для `P_L` містить квадратичний член `(X_S + X_L)²`. Оскільки квадрат будь-якого дійсного числа завжди невід'ємний, знаменник досягає свого найменшого можливого значення тоді і тільки тоді, коли цей член дорівнює нулю:

```
(X_S + X_L)² = 0       [найменше значення квадратичного члена]
X_L = -X_S             [умова компенсації реактивності та резонансу]
```

Це означає, що реактивна складова навантаження мусить мати такий самий за модулем, але протилежний за знаком реактивний опір. Якщо джерело має індуктивний опір (`X_S > 0`), навантаження мусить мати ємнісний опір (`X_L < 0`) такої ж величини. За цієї умови реактивні енергії накопичення в індуктивності та ємності періодично обмінюються між собою, не перешкоджаючи проходженню активного струму від генератора.

#### Другий крок: оптимізація за активним опором `R_L`

Підставивши умову компенсації реактивності `X_L = -X_S` у вираз потужності, отримуємо спрощену функцію потужності від однієї змінної `R_L`:

```
P_L(R_L) = (|V_S|² · R_L) / (R_S + R_L)²   [підстановка X_L = -X_S]
```

Щоб знайти екстремум (максимум) цієї функції, обчислимо першу похідну від `P_L` по змінній `R_L`, застосовуючи правило диференціювання частки двох функцій `(u/v)' = (u'v - uv') / v²`:

```
dP_L / dR_L = |V_S|² · [ 1 · (R_S + R_L)² - R_L · 2(R_S + R_L) ] / (R_S + R_L)⁴  [диференціювання за R_L]
            = |V_S|² · [ (R_S + R_L) - 2·R_L ] / (R_S + R_L)³                    [скорочення на (R_S + R_L)]
            = |V_S|² · [ R_S - R_L ] / (R_S + R_L)³                              [спрощення чисельника]
```

Прирівнюючи першу похідну до нуля `dP_L / dR_L = 0` для знаходження критичної точки:

```
|V_S|² · [ R_S - R_L ] / (R_S + R_L)³ = 0   [умова екстремуму гладкої функції]
R_S - R_L = 0                               [чисельник дорівнює нулю]
R_L = R_S                                   [умова рівності активних опорів]
```

Таким чином, для досягнення максимальної передачі активної потужності імпеданс навантаження мусить бути точно комплексно-спряженим до внутрішнього імпедансу джерела:

```
Z_L = Z_S* = R_S - jX_S                      [умова комплексно-спряженого узгодження]
```

При цьому максимальна потужність, яку джерело здатне віддати у навантаження, дорівнює:

```
P_max = |V_S|² / (4 · R_S)                   [підстановка R_L = R_S у вираз для P_L]
```

Важливо розуміти енергетичний баланс цього стану: у режимі комплексно-спряженого узгодження на внутрішньому опорі джерела `R_S` виділяється точно така ж потужність, як і в навантаженні `R_L`. Отже, коефіцієнт корисної дії (ККД) джерела становить рівно 50%. Для малосигнальних трактів (наприклад, у приймачах та LNA) максимізація передачі сигналу є головним пріоритетом, тому 50% ККД є цілком прийнятною платою. Проте для потужних передавачів (PA) режим максимальної потужності може призводити до перевитрати енергії та перегріву, тому підсилювачі потужності часто узгоджують не на комплексно-спряжений імпеданс, а на так зване оптимальне навантаження за вихідною потужністю та ККД (Load-Pull matching).

### 2. Еквівалентне перетворення «Послідовне ↔ Паралельне»

При розрахунку пасивних узгоджувальних кіл постійно виникає потреба перераховувати послідовне з'єднання резистора й реактивного елемента у паралельне з'єднання, і навпаки. Це перетворення базується на рівності комплексних провідностей обох схем на конкретній робочій частоті `ω = 2πf₀`.

Розглянемо послідовне коло, що складається з активного опору `R_s` та реактивного опору `X_s`. Введемо важливу характеристику кола — нагружену добротність `Q`:

```
Q = |X_s| / R_s      [визначення Q для послідовного кола]
```

Записавши комплексний імпеданс послідовного кола `Z_s = R_s + jX_s`, знайдемо його еквівалентну комплексну провідність (адмітанс) `Y_s = 1 / Z_s`:

```
Y_s = 1 / (R_s + jX_s)                                            [визначення провідності Y = 1/Z]
    = (R_s - jX_s) / ((R_s + jX_s)(R_s - jX_s))                  [домножили на комплексно-спряжене]
    = (R_s - jX_s) / (R_s² + X_s²)                                [виконано множення знаменника]
    = [ R_s / (R_s² + X_s²) ] - j [ X_s / (R_s² + X_s²) ]        [розділено на дісну та уявну частини]
```

Тепер розглянемо паралельне з'єднання резистора `R_p` та реактивного елемента `X_p`. Його комплексна провідність `Y_p` є простою сумою двох паралельних провідностей:

```
Y_p = (1 / R_p) - j(1 / X_p)                                      [сума паралельних провідностей]
```

Для повної електричної еквівалентності обох кіл на частоті `ω` їхні комплексні провідності мусять бути тотожно рівними `Y_s = Y_p`. Прирівнюючи окремо дійсні (активні) та уявні (реактивні) частини:

1. **Дійсна частина (активна провідність G):**
   ```
   1 / R_p = R_s / (R_s² + X_s²)                                 [прирівнювання дійсних частин]
   R_p = (R_s² + X_s²) / R_s                                     [обернення виразу]
       = R_s · (1 + (X_s / R_s)²)                                 [винесення R_s за дужки]
       = R_s · (1 + Q²)                                           [підстановка визначення Q = X_s/R_s]
   ```

2. **Уявна частина (реактивна провідність B):**
   ```
   1 / X_p = X_s / (R_s² + X_s²)                                 [прирівнювання уявних частин]
   X_p = (R_s² + X_s²) / X_s                                     [обернення виразу]
       = X_s · (1 + (R_s / X_s)²)                                 [винесення X_s за дужки]
       = X_s · (1 + 1/Q²)                                         [підстановка 1/Q = R_s/X_s]
       = X_s · (1 + Q²) / Q²                                      [зведення до спільного знаменника]
   ```

Звідси випливає фундаментальна властивість еквівалентного перетворення: **добротність `Q` залишається незмінною при переході від послідовної до паралельної схеми**:

```
Q = |X_s| / R_s = R_p / |X_p|                                     [інваріантність Q при перетворенні]
```

Фізичний зміст трансформації опору полягає в тому, що додавання паралельного реактивного елемента з добротністю `Q` візуально «збільшує» активний опір у `(1 + Q²)` разів: `R_p = R_s · (1 + Q²)`. Саме ця властивість дозволяє перетворювати низькі опори у високі та навпаки за допомогою комбінацій реактивних елементів.

### 3. Математичний розрахунок L-подібної ланки

L-ланка є найпростішим пасивним узгоджувальним чотириполюсником і складається з двох реактивних елементів: одного послідовного та одного паралельного. Головне правило узгодження L-ланкою звучить так: **паралельний реактивний елемент завжди підключається паралельно до більшого з двох активних опорів**.

Позначимо більший за величиною опір як `R_high`, а менший як `R_low`.

#### Крок 1: Визначення добротності L-ланки `Q`

Оскільки паралельний елемент мусить трансформувати `R_high` у `R_low` за формулою `R_high = R_low · (1 + Q²)`, виразимо необхідну добротність `Q` безпосередньо через відношення двох опорів:

```
1 + Q² = R_high / R_low                                           [формула трансформації активного опору]
Q² = (R_high / R_low) - 1                                         [перенесення одиниці]
Q = √((R_high / R_low) - 1)                                       [добування квадратного кореня]
```

Це рівняння показує ключове обмеження L-ланок: **нагружена добротність `Q` та смуга пропускання L-ланки повністю жорстко визначені співвідношенням опорів `R_high / R_low`**. Їх неможливо вибирати довільно. Якщо співвідношення опорів велике (наприклад, 500 Ом і 50 Ом), добротність буде високою (`Q = 3`), а смуга частот — вузькою.

#### Крок 2: Обчислення реактивних опорів елементів `X_L` та `X_C`

Залежно від того, де стоять індуктивність та ємність, L-ланка має чотири фундаментальні конфігурації:

1. **ФНЧ знижувальний (`R_S > R_L`):**
   Послідовна індуктивність `L` з боку `R_L`, паралельна ємність `C` з боку `R_S`.
   ```
   X_L_series = Q · R_low                                         [реактивність послідовної індуктивності]
   X_C_parallel = R_high / Q                                      [реактивність паралельної ємності]
   ```

2. **ФНЧ підвищувальний (`R_S < R_L`):**
   Паралельна ємність `C` з боку `R_L`, послідовна індуктивність `L` з боку `R_S`.
   ```
   X_L_series = Q · R_low                                         [реактивність послідовної індуктивності]
   X_C_parallel = R_high / Q                                      [реактивність паралельної ємності]
   ```

3. **ФВЧ знижувальний (`R_S > R_L`):**
   Послідовна ємність `C` з боку `R_L`, паралельна індуктивність `L` з боку `R_S`.
   ```
   X_C_series = Q · R_low                                         [реактивність послідовної ємності]
   X_L_parallel = R_high / Q                                      [реактивність паралельної індуктивності]
   ```

4. **ФВЧ підвищувальний (`R_S < R_L`):**
   Паралельна індуктивність `L` з боку `R_L`, послідовна ємність `C` з боку `R_S`.
   ```
   X_C_series = Q · R_low                                         [реактивність послідовної ємності]
   X_L_parallel = R_high / Q                                      [реактивність паралельної індуктивності]
   ```

Перехід від реактивних опорів `X_L` та `X_C` до фізичних номіналів на робочій частоті `f₀` виконується за стандартними формулами:

```
L = X_L / (2π · f₀)                                               [номінал індуктивності L = X_L / ω]
C = 1 / (2π · f₀ · X_C)                                           [номінал ємності C = 1 / (ω · X_C)]
```

### 4. Повний числово розрахований приклад L-ланки

**Постановка задачі:** Інженер розробляє малопотужний передавач для діапазону ISM 433.92 МГц. Вихідний транзистор підсилювача потужності в обраному режимі має вихідний опір `Z_S = 10 + j0 Ом`. Його необхідно узгодити зі стандартною антенною фідерною лінією `Z_L = 50 + j0 Ом`. Потрібно розрахувати номінали ФНЧ L-ланки для придушення гармонік.

**Розв'язання покроково:**

1. **Аналіз опорів:**
   - `R_S = 10 Ом`, `R_L = 50 Ом`.
   - `R_high = 50 Ом` (сторона антени), `R_low = 10 Ом` (сторона транзистора).
   - Оскільки `R_S < R_L`, паралельний елемент (ємність `C`) мусить стояти паралельно до антени `R_L`, а послідовний елемент (індуктивність `L`) — між транзистором та вузлом ємності.

2. **Обчислення добротності `Q`:**
   ```
   Q = √((R_high / R_low) - 1)                                    [формула добротності L-ланки]
     = √((50 / 10) - 1)                                           [підстановка R_high = 50, R_low = 10]
     = √(5 - 1)                                                  [ділення 50 / 10 = 5]
     = √4 = 2.0                                                  [віднімання та добування кореня]
   ```

3. **Обчислення кругової частоти `ω₀`:**
   ```
   ω₀ = 2π · f₀                                                   [визначення кругової частоти]
      = 2 · 3.14159265 · 433.92 · 10⁶ Гц                           [підстановка f0 = 433.92 МГц]
      ≈ 2.72641 · 10⁹ рад/с                                       [обчислення значення ω0]
   ```

4. **Обчислення послідовної індуктивності `L`:**
   Реактивний опір послідовної котушки:
   ```
   X_L = Q · R_low                                                [формула послідовної реактивності]
       = 2.0 · 10 Ом = 20 Ом                                      [підстановка Q = 2.0, R_low = 10]
   ```
   Номінал індуктивності:
   ```
   L = X_L / ω₀                                                   [перехід до генрі]
     = 20 / (2.72641 · 10⁹)                                       [підстановка X_L = 20, ω0]
     ≈ 7.3356 · 10⁻⁹ Гн = 7.34 нГн                                [обчислення номіналу L]
   ```

5. **Обчислення паралельної ємності `C`:**
   Реактивний опір паралельного конденсатора:
   ```
   X_C = R_high / Q                                               [формула паралельної реактивності]
       = 50 / 2.0 = 25 Ом                                         [підстановка R_high = 50, Q = 2.0]
   ```
   Номінал ємності:
   ```
   C = 1 / (ω₀ · X_C)                                             [перехід до фарад]
     = 1 / (2.72641 · 10⁹ · 25)                                   [підстановка ω0, X_C = 25]
     ≈ 14.671 · 10⁻¹² Ф = 14.67 пФ                                [обчислення номіналу C]
   ```

**Перевірка результату аналітичним перетворенням:**
Згорнемо паралельне з'єднання антени `R_L = 50 Ом` та конденсатора `X_C = 25 Ом` у послідовний еквівалент:
```
R_eq_series = R_high / (1 + Q²) = 50 / (1 + 4) = 10 Ом            [перерахований активний опір]
X_eq_series = -X_C / (1 + 1/Q²) = -25 / (1 + 0.25) = -20 Ом       [перерахований ємнісний опір]
```
Підставивши послідовну індуктивність `X_L = +20 Ом`, знаходимо повний вхідний імпеданс схеми з боку транзистора:
```
Z_in = R_eq_series + j(X_eq_series + X_L)                        [сума послідовних імпедансів]
     = 10 + j(-20 + 20)                                           [підстановка еквівалентних значень]
     = 10 + j0 Ом                                                 [компенсація реактивностей -20 + 20 = 0]
```
Вхідний імпеданс точно дорівнює 10 Ом. Коефіцієнт відбиття `Γ = 0`, КСХ дорівнює 1.0. Розрахунок абсолютно точний.

### 5. П-подібні (Pi) та Т-подібні ланки: довільний вибір Q

Коли співвідношення опорів `R_high / R_low` мале, добротність L-ланки стає занадто низькою, що позбавляє коло фільтрувальних властивостей. Для того щоб розробник мав можливість самостійно задавати добротність `Q` (а отже, і смугу частот та фільтрацію гармонік), застосовують триелементні топології: **П-подібну (Pi)** та **Т-подібну (T)** ланки.

#### П-подібна ланка (Pi-Network)

П-подібна ланка складається з двох паралельних ємностей `C1`, `C2` та однієї послідовної індуктивності `L`. Вона розглядається як послідовне з'єднання двох L-ланок через уявний внутрішній проміжний опір `R_v`, який є **меншим** за обидва крайові опори:

```
R_v < R_S  та  R_v < R_L
```

Алгоритм розрахунку Pi-ланки:
1. Задається бажана добротність першого вузла `Q_node` (наприклад, `Q = 10` для ефективної фільтрації гармонік у підсилювачі класу C).
2. Обчислюється віртуальний опір `R_v`:
   ```
   R_v = R_S / (1 + Q_node²)                                      [віртуальний опір вузла 1]
   ```
3. Обчислюється добротність другого вузла `Q_node2`:
   ```
   Q_node2 = √((R_L / R_v) - 1)                                   [добротність вузла 2]
   ```
4. Обчислюються реактивні опори трьох елементів:
   ```
   X_C1 = R_S / Q_node                                           [реактивність першої ємності]
   X_C2 = R_L / Q_node2                                          [реактивність другої ємності]
   X_L = (Q_node · R_v) + (Q_node2 · R_v) = R_v · (Q_node + Q_node2) [сума послідовних індуктивностей]
   ```

Завдяки тому що `R_v` можна зробити скільки завгодно малим за рахунок збільшення `Q_node`, Pi-ланка дозволяє забезпечувати високу селективність та чудове придушення вищих гармонік.

#### Т-подібна ланка (T-Network)

Т-подібна ланка складається з двох послідовних ємностей `C1`, `C2` та однієї паралельної індуктивності `L`. Вона розглядається як з'єднання двох L-ланок через віртуальний опір `R_v`, який є **більшим** за обидва крайові опори:

```
R_v > R_S  та  R_v > R_L
```

Формули розрахунку T-ланки:
```
R_v = R_low · (1 + Q_node²)                                       [віртуальний опір вузла T-ланки]
X_L_parallel = R_v / (Q_node1 + Q_node2)                          [реактивність паралельної котушки]
X_C1_series = Q_node1 · R_S                                       [реактивність першої ємності]
X_C2_series = Q_node2 · R_L                                       [реактивність другої ємності]
```

T-ланка широко застосовується в транзисторних підсилювачах надвисоких частот та в антенах з низьким імпедансом, а також там, де послідовні ємності одночасно виконують роль розв'язувальних конденсаторів для постійного струму (DC-block).
