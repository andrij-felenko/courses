# 🧮 Математичний вивід залежності BER від SNR та розрахунок PER

Оцінка якості бездротового каналу спирається на строгий математичний апарат теорії ймовірностей, математичної статистики та цифрового оброблення сигналів. Ця вставка містить покроковий математичний вивід зв'язку між ймовірністю бітової помилки (BER), знормованим співвідношенням сигнал/шум `E_b / N_0`, ймовірністю втрати кадру (PER), математичним усередненням у каналах із завмираннями та підсиленням завадостійкого кодування (FEC).

## 1. Зв'язок між SNR та знормованим показником Eb/N0

Виміряне у приймачі співвідношення потужності сигналу до шуму (SNR) залежить від ширини смуги частот приймача `B`. Для зіставлення та порівняння систем із різними видами модуляції (BPSK, QPSK, QAM) та різними бітовими швидкостями використовують знормовану міру `E_b / N_0` — відношення енергії одного біта `E_b` до спектральної щільності потужності шуму `N_0`.

Енергія одного переданого біта `E_b` пов'язана з потужністю корисного сигналу `P_s` та бітовою швидкістю передачі `R_b` (біт/с) співвідношенням:

```
E_b = P_s / R_b
```

Спектральна щільність шуму `N_0` пов'язана з загальною потужністю шуму `P_n` у смузі `B`:

```
N_0 = P_n / B
```

Підставляючи ці вирази у співвідношення `E_b / N_0`, отримуємо:

```
E_b / N_0 
= (P_s / R_b) / (P_n / B)    [підстановка виразів E_b = P_s / R_b та N_0 = P_n / B]
= (P_s / P_n) · (B / R_b)    [перегрупування множників]
= SNR · (B / R_b)            [означення SNR = P_s / P_n]
```

У логарифмічній формі (у децибелах):

```
(E_b / N_0)_dB = SNR_dB + 10 · log10(B / R_b)
```

Якщо спектральна ефективність модуляції становить `η = R_b / B` (біт/с/Гц), то:

```
(E_b / N_0)_dB = SNR_dB - 10 · log10(η)
```

Для двопозиційної фазової модуляції BPSK без надлишкового кодування `η = 1`, тому значення `E_b / N_0` у децибелах чисельно дорівнює `SNR_dB` у смузі сигналу.

## 2. Покроковий вивід ймовірності помилки для BPSK в каналі AWGN

Розглянемо канал із адитивним білим гаусовим шумом (AWGN). При прийманні BPSK сигналу з амплітудою `A` переданий біт `1` відповідає рівню `+A`, а біт `0` — рівню `-A`. На приймачі формується вирішальна статистика `y = s + n`, де `n` — гаусова випадкова величина з нульовим середнім значенням та дисперсією `σ² = N_0 / 2`.

Помилка виникає тоді, коли передано біт `0` (сигнал `-A`), але через шум `n > A`, або коли передано біт `1` (сигнал `+A`), але шум `n < -A`.

Завдяки симетрії завад ймовірність помилки `P_e` (або BER) дорівнює ймовірності того, що шум перевищить поріг `A`:

```
BER = P(n > A) = ∫[A..∞] (1 / √(2π · σ²)) · exp(-x² / (2σ²)) dx
```

Виконуючи заміну змінної `u = x / σ`, отримуємо вираз через функцію Q-гауса `Q(z)`:

```
BER = Q(A / σ)
```

Оскільки енергія біта для BPSK становить `E_b = A²`, а дисперсія шуму `σ² = N_0 / 2`, відношення `A / σ` виражається через `E_b / N_0`:

```
A / σ = √A² / σ² = √(E_b / (N_0 / 2)) = √(2 · E_b / N_0)
```

Таким чином, підсумкова формула ймовірності бітової помилки для BPSK має вигляд:

```
BER_BPSK = Q(√(2 · E_b / N_0))
```

Функція `Q(z)` пов'язана з додатковою функцією помилок `erfc(z)` співвідношенням `Q(z) = 0.5 · erfc(z / √2)`. Отже:

```
BER_BPSK = 0.5 · erfc(√(E_b / N_0))
```

Для обчислень зручно використовувати числове наближення функції `Q(z)` при `z > 3`:

```
Q(z) ≈ (1 / (z · √(2π))) · exp(-z² / 2)
```

### Числовий приклад розрахунку BER для BPSK

Нехай у каналі зв'язку з BPSK співвідношення `(E_b / N_0)_dB = 9.6 дБ`.

**Крок 1.** Переводимо `E_b / N_0` з дБ у лінійну величину:

```
(E_b / N_0)_lin = 10^(9.6 / 10) = 10^0.96 ≈ 9.12
```

**Крок 2.** Обчислюємо аргумент функції `Q(z)`:

```
z = √(2 · 9.12) = √18.24 ≈ 4.27
```

**Крок 3.** Застосовуємо числове наближення для `Q(4.27)`:

```
Q(4.27) 
≈ (1 / (4.27 · √(2 · 3.14159))) · exp(-4.27² / 2)   [підстановка z = 4.27 у наближену формулу Q(z)]
= (1 / (4.27 · 2.5066)) · exp(-18.2329 / 2)          [обчислення квадратного кореня √(2π) ≈ 2.5066]
= (1 / 10.703) · exp(-9.1164)                         [перемноження у знаменнику та піднесення до квадрата]
= 0.09343 · 0.0001098                                [ділення одиниці та обчислення експоненти e^(-9.1164)]
≈ 1.026 · 10⁻⁵                                        [підсумковий результат множення]
```

Отже, при `E_b / N_0 = 9.6 дБ` на кожні 100 000 переданих бітів припадає пересічно 1 бітова помилка (`BER ≈ 10⁻⁵`).

## 3. Ймовірність бітової помилки для квадратних модуляцій M-QAM

Для вищих видів модуляції (QPSK, 16-QAM, 64-QAM) сигнальні точки розташовані у два виміри на квадратурній площині I/Q.

Для QPSK кожні 2 біти кодуються одним символом. Оскільки квадратурні складові I та Q є ортогональними і незалежними, ймовірність бітової помилки для QPSK повністю збігається з BPSK:

```
BER_QPSK = Q(√(2 · E_b / N_0))
```

Для квадратних модуляцій `M-QAM` (де `M = 16, 64, 256`) з кодуванням Ґрея ймовірність бітової помилки при високих значеннях `E_b / N_0` наближено виражається формулою:

```
BER_MQAM ≈ (4 / log2(M)) · (1 - 1 / √M) · Q(√( (3 · log2(M) / (M - 1)) · (E_b / N_0) ))
```

Обчислимо граничні вимоги `E_b / N_0` для досягнення цільового рівня `BER = 10⁻⁵` для різних типів модуляції:

1. **BPSK / QPSK (`M = 4`):** Потрібно `(E_b / N_0) = 9.6 дБ`.
2. **16-QAM (`M = 16`):** `log2(16) = 4`, аргумент Q-функції зменшується внаслідок зближення точок сітки. Потрібно `(E_b / N_0) = 13.4 дБ`.
3. **64-QAM (`M = 64`):** `log2(64) = 6`. Для збереження `BER = 10⁻⁵` потрібно `(E_b / N_0) = 18.5 дБ`.

Висновок: перехід від QPSK до 64-QAM збільшує швидкість передачі даних у 3 рази, проте вимагає підвищення `E_b / N_0` майже на 9 дБ (у 8 разів за потужністю).

## 4. Математичний вивід PER через BER для кадру довжиною N біт

Розглянемо кадр довжиною `N` бітів. Припустимо, що помилки в окремих бітах є статистично незалежними подіями (канал без пакетування помилок, тобто без завад з пам'яттю).

Ймовірність того, що конкретний біт буде прийнято без помилки, дорівнює `1 - BER`.

Кадр вважається прийнятим успішно (без жодної помилки), якщо **всі `N` бітів** прийнято правильно. Оскільки біти незалежні, ймовірність успішного прийому кадру `P_success` дорівнює добутку ймовірностей:

```
P_success = (1 - BER)ⁿ
```

Ймовірність помилки кадру (Packet Error Rate, PER) є протилежною подією:

```
PER = 1 - P_success = 1 - (1 - BER)ⁿ
```

При малих значеннях `BER` (коли `N · BER << 1`) можна застосувати перші два члени розкладу Тейлора для степені `(1 - x)ⁿ ≈ 1 - n·x`:

```
PER ≈ 1 - (1 - N · BER) = N · BER
```

### Вплив довжини кадру на PER

Проілюструємо математичну залежність PER від довжини кадру `N` при фіксованому `BER = 10⁻⁴`:

1. Для короткого пакета `N = 64` біти (8 байт):

```
PER = 1 - (1 - 10⁻⁴)⁶⁴ = 1 - (0.9999)⁶⁴ ≈ 1 - 0.9936 = 0.0064 (0.64%)
```

2. Для стандартного кадру `N = 1024` біти (128 байт):

```
PER = 1 - (1 - 10⁻⁴)¹⁰²⁴ ≈ 1 - 0.9026 = 0.0974 (9.74%)
```

3. Для великого кадру Ethernet `N = 12 000` біт (1500 байт):

```
PER = 1 - (1 - 10⁻⁴)¹²⁰⁰⁰ ≈ 1 - 0.3011 = 0.6989 (69.89%)
```

Висновок: при одному й тому самому рівні `BER` великі кадри втрачаються у 100 разів частіше, ніж короткі пакети. Це пояснює необхідність фрагментації пакетів у зашумленому радіоефірі.

## 5. Математичне усереднення BER у каналах із завмираннями Релея

У реальному радіоефірі через багатопроменевість амплітуда сигналу зазнає швидких завмирань. У каналі з відсутністю прямого променю (NLOS) огинаюча амплітуди підпорядковується розподілу Релея, а миттєве значення `γ = E_b / N_0` має експоненціальний розподіл ймовірностей:

```
p(γ) = (1 / γ_avg) · exp(-γ / γ_avg)
```

де `γ_avg` — середнє значення `E_b / N_0` по ансамблю завмирань.

Середня ймовірність бітової помилки `BER_rayleigh` обчислюється шляхом інтегрування миттєвого значення `BER(γ)` по всьому діапазону значений `γ`:

```
BER_rayleigh = ∫[0..∞] BER_BPSK(γ) · p(γ) dγ
             = ∫[0..∞] 0.5 · erfc(√γ) · (1 / γ_avg) · exp(-γ / γ_avg) dγ
```

Взявши цей визначений інтеграл, отримуємо точну аналітичну формулу:

```
BER_rayleigh = 0.5 · (1 - √(γ_avg / (1 + γ_avg)))
```

При високих значеннях `γ_avg >> 1` наближення показує фундаментальну зміну характеру залежності:

```
BER_rayleigh ≈ 1 / (4 · γ_avg)
```

У стаціонарному каналі AWGN ймовірність помилки падає експоненціально `BER ∝ exp(-SNR)`, тоді як у каналі з Релеївськими завмираннями вона падає лише степенним чином `BER ∝ 1 / SNR`. 

Це означає, що для досягнення `BER = 10⁻⁵` у каналі із завмираннями потрібне середнє значення `SNR ≈ 40 дБ` замість `9.6 дБ` у стаціонарному каналі. 

Для компенсації цього падіння у бездротових системах обов'язково застосовують рознесення антен (*Diversity*) та завадостійке кодування із перемежуванням (*Interleaving*).

## 6. Математична модель FEC (блокове кодування Хеммінга та Ріда-Соломона)

Завадостійке кодування (Forward Error Correction, FEC) додає надлишкові перевірочні біти, що дозволяє приймачу виправляти `t` помилок у блоці з `n` бітів (де `k` — кількість інформаційних бітів).

Для блокового коду `(n, k)`, здатного виправляти `t = 1` помилку (наприклад, код Хеммінга), блок вважається зіпсованим лише тоді, коли в ньому виникає **2 або більше помилок**.

Ймовірність виникнення точно `i` помилок у блоці з `n` бітів описується біноміальним розподілом:

```
P(i) = C(n, i) · BERⁱ · (1 - BER)ⁿ⁻ⁱ
```

Де `C(n, i) = n! / (i! · (n - i)!)` — біноміальний коефіцієнт.

Ймовірність невиправної помилки блоку після застосування декодера `PER_fec` дорівнює сумі ймовірностей виникнення більше ніж `t` помилок:

```
PER_fec = ∑[i = t+1 .. n] C(n, i) · BERⁱ · (1 - BER)ⁿ⁻ⁱ
```

Для коду Хеммінга з `t = 1`:

```
PER_fec = 1 - P(0) - P(1)
        = 1 - (1 - BER)ⁿ - n · BER · (1 - BER)ⁿ⁻¹
```

При малих `BER` розклад дає наближення:

```
PER_fec ≈ C(n, 2) · BER² = (n · (n - 1) / 2) · BER²
```

### Кодування Ріда-Соломона RS(255, 223) у супутникових каналах

У супутникових та оптоволоконних лініях зв'язку застосовують байтово-орієнтоване кодування Ріда-Соломона `RS(255, 223)`. Код працює над полями Галуа `GF(28)`, де кожен символ містить 8 бітів (1 байт). Блок довжиною `n = 255` байтів містить `k = 223` інформаційні байти та `2t = 32` перевірочні байти, що дозволяє виправляти до `t = 16` байтових помилок у будь-якій позиції блоку.

Ймовірність невиправної помилки блоку `PER_RS` обчислюється через байтову ймовірність помилки `SER_byte = 1 - (1 - BER)⁸`:

```
PER_RS = ∑[i = 17 .. 255] C(255, i) · (SER_byte)ⁱ · (1 - SER_byte)²⁵⁵⁻ⁱ
```

При сирому `BER = 10⁻³` підсумковий рівень після декодера Ріда-Соломона падає нижче `BER_post_FEC < 10⁻¹²`, що гарантує абсолютно чистий канал зв'язку.

### Згорткове кодування та декодер Вітербі

У згорткових кодах із м'яким рішенням (Soft-Decision Viterbi Decoding) з відносній швидкістю `R = 1/2` та довжиною кодового обмеження `K = 7` (стандарт NASA та IEEE 802.11a/g) ймовірність бітової помилки на виході декодера обмежена зверху виразом:

```
BER_viterbi < ∑[d = d_free .. ∞] a_d · Q(√(2 · d · R · E_b / N_0))
```

де `d_free = 10` — мінімальна вільна відстань коду, а `a_d` — вагові коефіцієнти розкладу спектра відстаней.

Завдяки збереженню аналогової інформації про рівень напруги на вході демодулятора м'яке декодування Вітербі забезпечує додатковий кодувальний виграш `2 дБ` порівняно з жорстким рішенням (*Hard Decision*). Це математично пояснює, чому всі сучасні бездротові модеми передають на декодер `FEC` не просто біти 0 або 1, а квантовані значення ймовірностей (Log-Likelihood Ratios, LLR).
