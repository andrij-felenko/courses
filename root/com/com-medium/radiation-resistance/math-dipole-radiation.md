# 🧮 Виведення опору випромінювання диполя Герца та півхвильового диполя

Ця вставка містить суворий і послідовний математичний вивід опору випромінювання для двох фундаментальних еталонів антенної техніки: елементарного диполя Герца (`dl << λ`) з постійним струмом та тонкого симетричного півхвильового диполя (`l = λ/2`) з синусоїдальним розподілом струму. 

Розрахунок базується на інтегруванні усередненого за часом вектора Пойнтинга по замкненій сферичній поверхні великого радіуса у далекій зоні (зоні Фраунгофера). Такий підхід дає змогу пов'язати абсолютні значення напруженостей електричного та магнітного полів у довкіллі з амплітудою струму в точці живлення антени.

---

### Електродинамічний фундамент: Запізнілий векторний потенціал

Для обчислення полів випромінювання ниткового струму `i(t) = I₀ · cos(ω·t)` скористаємося методом векторного потенціалу `A`. У тривимірному просторі запізнілий векторний потенціал електричного струму густиною `J` визначається розв'язком неоднорідного хвильового рівняння Д'Аламбера:

```
A(r, t) = (μ₀ / (4·π)) · ∭ [ J(r', t - R/c) / R ] dV'
```

де `R = |r - r'|` — відстань від елемента джерела `dV'` у точці `r'` до точки спостереження `r`.

Для елементарного диполя довжиною `dl`, розташованого на осі `Z` у початку координат (`r' = 0`), векторний потенціал має лише `Z`-складову:

```
A_z(r, t) = (μ₀ · I₀ · dl) / (4·π·r) · cos(ω·t - k·r)
```

Переходячи до сферичних компонент `(A_r, A_θ, A_φ)` за формулами перетворення координат:

```
A_r = A_z · cos(θ) = (μ₀ · I₀ · dl) / (4·π·r) · cos(θ) · cos(ω·t - k·r)
A_θ = -A_z · sin(θ) = -(μ₀ · I₀ · dl) / (4·π·r) · sin(θ) · cos(ω·t - k·r)
A_φ = 0
```

Напруженість магнітного поля знаходиться з ротора векторного потенціалу `H = (1 / μ₀) · ∇ × A`, а напруженість електричного поля — з другого рівняння Максвелла у часовій формі `E = (1 / (j·ω·ε₀)) · ∇ × H`.

Після обчислення диференціальних операторів у сферичних координатах отримуємо точний розподіл полів на довільній відстані `r`:

```
H_φ = (I₀ · dl / (4·π)) · k² · [ 1 / (k·r) + 1 / (j·k²·r²) ] · sin(θ) · e⁻ʲᵏʳ
E_θ = (η₀ · I₀ · dl / (4·π)) · k² · [ 1 / (k·r) + 1 / (j·k²·r²) - 1 / (k³·r³) ] · sin(θ) · e⁻ʲᵏʳ
E_r = (η₀ · I₀ · dl / (2·π)) · k² · [ 1 / (j·k²·r²) - 1 / (k³·r³) ] · cos(θ) · e⁻ʲᵏʳ
```

#### Поділ простору на фізичні зони
Аналіз членів залежності від відстані `r` виявляє три характерні просторові області:

1. **Реактивна ближня зона (`k·r << 1` або `r << λ / 2π`):** Панують члени `1/r³` та `1/r²`. Електричне та магнітне поля перебувають у квадратурі (зсунуті за фазою на 90°), а усереднений потік енергії дорівнює нулю. Енергія почергово запасається у ємності та індуктивності оточуючого середовища.
2. **Проміжна зона Френеля (`k·r ≈ 1`):** Складові полів порівнянні за величиною, відбувається формування фронту вільної хвилі.
3. **Далека хвильова зона Фраунгофера (`k·r >> 1` або `r >> λ`):** Члени вищих степенів `1/r²` та `1/r³` стають нехтовно малими порівняно з хвильовим членом `1/r`. Поле стає чисто поперечним (`E_r → 0`), а амплітуди `E_θ` та `H_φ` перебувають у точній синфазності.

### 1. Виведення для диполя Герца (короткого диполя)

У далекій зоні (`r >> λ`) комплексно-амплітудні складові спрощуються до вигляду біжучої сферичної хвилі:

```
E_θ(r, θ) = j · (η₀ · I₀ · k · dl) / (4·π·r) · sin(θ) · e⁻ʲᵏʳ
H_φ(r, θ) = j · (I₀ · k · dl) / (4·π·r) · sin(θ) · e⁻ʲᵏʳ
```

де `η₀ = √(μ₀ / ε₀) ≈ 120·π ≈ 376.73 Ом` — хвильовий опір вакууму, а `k = 2·π / λ` — волнове число.

#### Усереднений за часом вектор Пойнтинга
Модуль радіальної складової усередненого за період вектора Пойнтинга `S_avg` визначається як півдобуток комплексної амплітуди електричного поля на комплексно-спряжену амплітуду магнітного поля:

```
S_avg = (1/2) · Re( E_θ · H_φ* )
= (1/2) · (η₀ · I₀² · k² · dl²) / (16·π²·r²) · sin²(θ)   [підстановка E_θ та H_φ*]
= (η₀ · π · I₀² · dl²) / (8·r² · λ²) · sin²(θ)            [заміна k = 2·π/λ]
```

Зауважимо, що щільність потоку потужності спадає з відстанню за законом оберненого квадрата `1/r²`, що відображає збереження енергії при розширенні сферичної хвильової поверхні.

#### Інтегрування випромінюваної потужності
Повна потужність випромінювання `P_рад` знаходиться шляхом інтегрування вектора Пойнтинга `S_avg` по всій сферичній поверхні радіуса `r`:

```
P_рад = ∬ S_avg · dA                                      [поверхневий інтеграл Пойнтинга]
= ∫₀²ᵖⁱ dφ · ∫₀ᵖⁱ S_avg(r, θ) · r² · sin(θ) dθ           [елемент площі сфери dA = r²·sin(θ)dθ dφ]
= 2·π · r² · ∫₀ᵖⁱ S_avg(r, θ) dθ                          [інтегрування по φ від 0 до 2π]
= 2·π · r² · [ (η₀ · π · I₀² · dl²) / (8·r² · λ²) ] · ∫₀ᵖⁱ sin³(θ) dθ   [підстановка S_avg]
= [ (η₀ · π² · I₀² · dl²) / (4 · λ²) ] · ∫₀ᵖⁱ sin³(θ) dθ  [скорочення r² та множника 2π/8]
```

Обчислимо визначений інтеграл від кутової діаграми спрямованості `sin³(θ)`:

```
∫₀ᵖⁱ sin³(θ) dθ
= ∫₀ᵖⁱ (1 - cos²(θ)) d(-cos(θ))                          [тотожність sin²θ = 1 - cos²θ]
= [ -cos(θ) + (1/3)·cos³(θ) ]₀ᵖⁱ                         [первісна функція]
= (1 - 1/3) - (-1 + 1/3)                                 [підстановка меж інтегрування]
= 4/3                                                     [результат інтегрування]
```

Підставивши значення інтеграла `4/3` у формулу повної потужності:

```
P_рад = [ (η₀ · π² · I₀² · dl²) / (4 · λ²) ] · (4/3)    [підстановка значення інтеграла]
= (η₀ · π² · I₀² · dl²) / (3 · λ²)                        [скорочення 4 у чисельнику і знаменнику]
```

#### Визначення опору випромінювання R_рад
За фундаментальним визначенням, опір випромінювання `R_рад` за піковою амплітудою струму `I₀` у точці живлення зв'язаний з випромінюваною потужністю формулою активних втрат `P_рад = (1/2) · I₀² · R_рад`:

```
(1/2) · I₀² · R_рад = (η₀ · π² · I₀² · dl²) / (3 · λ²)   [прирівняння P_рад до активних втрат]
R_рад = (2 · η₀ · π² / 3) · (dl / λ)²                    [скорочення I₀² та множення на 2]
= (2 · (120·π) · π² / 3) · (dl / λ)²                      [підстановка η₀ = 120·π Ом]
= (80 · π²) · (dl / λ)²                                  [спрощення коефіцієнта 240/3 = 80]
≈ 789.57 · (dl / λ)² Ом                                   [обчислення 80·π²]
```

#### Урахування реального лінійного струму короткого диполя
У реальному симетричному короткому диполі з відкритими кінцями струм не може бути постійним вздовж довжини, оскільки на кінцях дротів немає накопичувачів заряду. Струм спадає від максимуму `I₀` у центрі до нуля на кінцях за лінійним законом.

Середньоквадратичне значення струму вздовж антени для лінійного трикутного розподілу становить `I_avg = I₀ / 2`. Оскільки випромінювана потужність пропорційна квадрату струму, реальний опір випромінювання короткого диполя є у 4 рази меншим за диполь Герца:

```
R_рад_короткий = (1/4) · (80 · π²) · (l / λ)²           [множник (1/2)² для лінійного струму]
= (20 · π²) · (l / λ)²                                   [ділення 80/4 = 20]
≈ 197.39 · (l / λ)² Ом                                    [обчислення 20·π²]
```

### 2. Виведення для півхвильового диполя (l = λ/2)

Для тонкого півхвильового диполя загальною довжиною `l = λ/2`, розташованого уздовж осі `Z` від `z = -λ/4` до `z = +λ/4`, струм має синусоїдальний розподіл із пучністю у центрі:

```
I(z) = I₀ · cos(k·z) = I₀ · cos( (2·π/λ) · z )
```

#### Поле у далекій зоні
Напруженість електричного поля у далекій зоні знаходять як фазовану інтегральну суму полів від усіх елементарних струмових елементів `dz`:

```
E_θ(r, θ) = j · (η₀ · I₀) / (2·π·r) · [ cos((π/2) · cos(θ)) / sin(θ) ] · e⁻ʲᵏʳ
```

Модуль вектора Пойнтинга `S_avg`:

```
S_avg = (η₀ · I₀²) / (8·π²·r²) · [ cos²((π/2) · cos(θ)) / sin²(θ) ]
```

#### Інтегрування випромінюваної потужності
Повна потужність випромінювання знаходять інтегруванням по куту `θ`:

```
P_рад = ∬ S_avg · dA                                      [інтеграл Пойнтинга]
= 2·π · r² · ∫₀ᵖⁱ S_avg dθ                                [інтегрування по φ]
= (η₀ · I₀²) / (4·π) · ∫₀ᵖⁱ [ cos²((π/2) · cos(θ)) / sin(θ) ] dθ   [підстановка S_avg]
```

Для обчислення безрозмірного інтеграла зробимо заміну змінної `u = cos(θ)`, `du = -sin(θ) dθ`:

```
J = ∫₀ᵖⁱ [ cos²((π/2) · cos(θ)) / sin(θ) ] dθ
= ∫₋₁⁺¹ [ cos²((π/2) · u) / (1 - u²) ] du                 [заміна u = cos(θ)]
= (1/2) · Cin(2·π)                                        [інтегральний косинус Cin]
```

де значення спеціальної функції `Cin(2·π)` визначається як розклад у статевий ряд:

```
Cin(2·π) = ∫₀²ᵖⁱ [ (1 - cos(x)) / x ] dx
= γ + ln(2·π) - Ci(2·π) ≈ 2.4376488
```

тут `γ ≈ 0.577215` — константа Ейлера-Маскероні, а `Ci(2·π)` — косинусний інтеграл.

#### Розрахунок підсумкового значення R_рад
Підставивши значення інтеграла `J` у формулу потужності:

```
P_рад = (η₀ · I₀²) / (4·π) · [ (1/2) · Cin(2·π) ]        [підстановка інтеграла J]
= (η₀ · I₀² · Cin(2·π)) / (8·π)                           [перемноження знаменників 4π·2]
```

Прирівнюємо виражену потужність до виразу через опір випромінювання `(1/2) · I₀² · R_рад`:

```
(1/2) · I₀² · R_рад = (η₀ · I₀² · Cin(2·π)) / (8·π)       [прирівняння P_рад]
R_рад = (η₀ · Cin(2·π)) / (4·π)                           [скорочення I₀² та множення на 2]
= 30 · Cin(2·π)                                           [підстановка η₀ = 120·π Ом]
= 30 · 2.4376488...                                       [підстановка Cin(2π)]
≈ 73.1295 Ом                                              [підсумковий опір випромінювання]
```

Таким чином, суворо доведено, що опір випромінювання тонкого ідеального півхвильового диполя в ізольованому безмежному просторі становить **73.13 Ом**.

### 3. Виведення для малої рамкової (петльової) антени

Розглянемо круглу рамку радіуса `a << λ` із кількістю витків `N`, орієнтовану у площині `XY`. По рамці протікає рівномірний струм `I(t) = I₀ · cos(ω·t)`.

Магнітний момент такої рамки дорівнює:

```
m₀ = N · I₀ · A = N · I₀ · (π · a²)
```

У далекій зоні (`r >> λ`) магнітний диполь створює сферичні компоненти полів, які виражаються дуально до електричного диполя:

```
E_φ(r, θ) = (η₀ · k² · m₀) / (4·π·r) · sin(θ) · e⁻ʲᵏʳ
H_θ(r, θ) = -(k² · m₀) / (4·π·r) · sin(θ) · e⁻ʲᵏʳ
```

Усереднений вектор Пойнтинга має лише радіальну складову:

```
S_avg = (1/2) · Re( E_φ · (-H_θ*) )
= (η₀ · k⁴ · m₀²) / (32·π²·r²) · sin²(θ)   [підстановка E_φ та H_θ*]
```

Інтегруючи по всій сфері площею `4·π·r²` із врахуванням фактора `∫₀ᵖⁱ sin³(θ) dθ = 4/3`:

```
P_рад = ∬ S_avg · dA                                      [інтеграл Пойнтинга по сфері]
= (η₀ · k⁴ · m₀²) / (32·π²·r²) · (2·π·r²) · (4/3)        [інтегрування по φ та θ]
= (η₀ · k⁴ · m₀²) / (12·π)                                [скорочення r² та множників]
```

Замінивши волнове число `k = 2·π / λ` та магнітний момент `m₀ = N · I₀ · A`:

```
P_рад = [ η₀ · (2·π / λ)⁴ · (N · I₀ · A)² ] / (12·π)    [підстановка k та m₀]
= [ 16 · π⁴ · η₀ · N² · I₀² · A² ] / (12 · π · λ⁴)       [піднесення до 4 степеня]
= (4 · π³ · η₀ / 3) · N² · I₀² · (A / λ²)²                [скорочення 16/12 = 4/3]
```

Прирівнявши `P_рад` до виразу `(1/2) · I₀² · R_рад` та підставивши `η₀ = 120·π Ом`:

```
(1/2) · I₀² · R_рад = (4 · π³ · (120·π) / 3) · N² · I₀² · (A / λ²)²  [прирівняння P_рад]
R_рад = (2 · 160 · π⁴) · N² · (A / λ²)²                              [множення на 2 і спрощення 40·4]
= (320 · π⁴) · N² · (A / λ²)²                                         [коефіцієнт 320·π⁴]
≈ 31171.8 · N² · (A / λ²)² Ом                                         [обчислення 320·π⁴]
```

Отриманий закон `R_рад ∝ (A / λ²)²` підтверджує, що для малих рамкових антен опір випромінювання падає пропорційно **четвертому степеню** зменшення лінійного розміру рамки, що пояснює їхній украй низький ККД у порівнянні з лінійними диполями.
