# 🔌 Еквівалентна схема антени та механізми втрат

Будь-яка випромінювальна структура (антена) з точки зору електричного кола є двополюсником із комплексним вхідним імпедансом `Z_A`. На відміну від звичайного резистора чи конденсатора, активний складник імпедансу антени складається з двох фундаментально різних частин: опору випромінювання `R_рад` (корисно випромінена енергія у дальню зону) та сумарного опору втрат `R_втрат` (енергія, що перетворюється на тепловий нагрів матеріалу та оточуючого середовища).

Повна вхідна потужність `P_вх = 1/2 · I_0^2 · R_вх`, що підводиться від фідерної лінії до клем випромінювача, апаратно розділяється на два шляхи: корисну потужність випромінювання `P_рад = 1/2 · I_0^2 · R_рад` у дальню зону та потужність теплових втрат `P_втрат = 1/2 · I_0^2 · R_втрат`. Фізичний дисипативний механізм втрат складається з трьох апаратних складників: омічного нагріву провідників у високочастотному скін-шарі з урахуванням мікрошорсткості поверхні, діелектричного поглинання у підкладці та ізоляторах, а також опору витоку струмів у радіалах та заземленні.

---

### Еквівалентна схема антени поблизу резонансу

Поблизу першого (основного) резонансу тонкопровідникову антену (наприклад, симетричний диполь чи чвертьхвильовий штир) можна подати еквівалентною послідовною RLC-ланцюгом:

```
          ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
 ───o─────┤  R_рад  ├───┤ R_втрат ├───┤   L_A   ├───┤   C_A   ├─────o───
   (In+)  └─────────┘   └─────────┘   └─────────┘   └─────────┘    (In-)
```

Де:
- `R_рад` — опір випромінювання (моделює незворотний вихід електромагнітної енергії у дальню зону);
- `R_втрат` — опір втрат (еквівалентний омічний, діелектричний та ґрунтовий нагрів);
- `L_A` — еквівалентна індуктивність ближнього магнітного поля антени;
- `C_A` — еквівалентна ємність ближнього електричного поля антени.

Повний вхідний імпеданс:

```
Z_A = (R_рад + R_втрат) + j · (ω·L_A - 1 / (ω·C_A))
```

На точній резонансній частоті `ω₀ = 1 / √(L_A · C_A)` реактивний складник обнуляється (`X_A = 0`), і коло стає чисто активним `Z_A = R_рад + R_втрат`.

### Анатомія опору втрат R_втрат

Сумарний опір втрат антени `R_втрат` додається послідовно до опору випромінювання і складається з трьох ключових фізичних джерел:

```
R_втрат = R_провід + R_земля + R_діелектрик
```

#### 1. Втрати у провідниках (R_провід), скін-ефект та шорсткість поверхні
На високочастотному змінному струмі змінне магнітне поле всередині провідника витісняє струм до його зовнішньої поверхні. Глибина проникнення струму (скін-шар `δ`) становить:

```
δ = 1 / √(π · f · μ · σ)
```

Де:
- `f` — робоча частота (Гц);
- `μ` — абсолютна магнітна проникність матеріалу (Гн/м);
- `σ` — питома електропровідність провідника (См/м).

Наприклад, для міді (`σ = 5.8×10⁷ См/м`) на частоті 100 МГц глибина скін-шару становить всього **6.6 мкм**, а на частоті 2.4 ГГц — лише **1.35 мкм**.

Для провідника круглого перерізу радіуса `a` і довжини `l` (при `a >> δ`) ефективна площа перерізу струму дорівнює `2·π·a·δ`. Високочастотний омічний опір провідника:

```
R_провід = l / (2·π·a·σ·δ) = (l / (2·π·a)) · √( (π·f·μ) / σ )
```

З формули видно, що опір втрат провідника зростає пропорційно квадратному кореню з частоти `√f`.

> ⚠️ **Шорсткість поверхні (Surface Roughness):** На мікрохвильових частотах (понад 1 ГГц) висота мікронерівностей металевої поверхні `Δ` стає порівнянною з товщиною скін-шару `δ`. Струм змушений огинати виступи й западини профілю металу, що подовжує його реальний шлях і підвищує `R_провід` у 1.5–2.2 рази відповідно до формули Морґанталера-Хамерґрена:
> `K_s = 1 + (2/π) · arctan( 1.9 · (Δ / δ)² )`.

> ⚠️ **Ефект близькості (Proximity Effect):** У багатовиткових рамкових антенах (Loop Antennas) або згорнутих диполях струми сусідніх витків взаємно витісняють один одного, що додатково підвищує `R_провід` у 2–4 рази порівняно зі звичайним скін-ефектом.

#### 2. Втрати у заземленні та противагах (R_земля)
У монопольних (нештірових) антенах струм високочастотного фідеру повертається до генератора через поверхню землі або систему радіальних провідників (противаг). 

Реальний ґрунт має низьку електропровідність (`σ_землі ≈ 1...10 мСм/м`) та діелектричну проникність `ε_r ≈ 5...15`, що викликає значне теплопоглинання струмів зміщення та провідності. Для укороченого штиря на низьких частотах опір втрат у землі `R_земля` обчислюється за емпіричною формулою Брауна залежно від кількості радіальних провідників `N_rad` та їхньої довжини `L_rad`:

```
R_земля ≈ R_ґрунту / ( 1 + 0.05 · N_rad · (L_rad / λ) )
```

Без радіальної сітки опір заземлення `R_земля` становить від 20 Ом до 60 Ом, що переважає опір випромінювання короткого штиря `R_рад ≈ 1...5 Ом`.

#### 3. Діелектричні втрати (R_діелектрик)
Електричне поле у ближній зоні антени пронизує конструктивні ізоляторах, підкладки друкованих плат (PCB substrate), обтічники (радоми) та корпуса пристроїв. Втрати у діелектриках описуються тангенсом кута діелектричних втрат `tan(δ)`:

```
R_діелектрик = (tan(δ) / (ω · C_A)) · (W_діелектрик / W_повної)
```

де `W_діелектрик / W_повної` — частка енергії електричного поля, що локалізована всередині діелектричного матеріалу.

Використання дешевих матеріалів на зразок стеклотекстоліту FR-4 (`tan(δ) ≈ 0.02`) на частотах понад 1 ГГц викликає значний омічний нагрів підкладки у порівнянні з високочастотними матеріалами на основі фторопласту (Rogers, PTFE з `tan(δ) ≈ 0.0009`).

### Коефіцієнт корисної дії (ККД) антени

Радіаційна ефективність (ККД) антени `η` визначається як відношення корисно випроміненої потужності `P_рад` до всієї підведеної активної потужності `P_вх`:

```
η = P_рад / P_вх = R_рад / (R_рад + R_втрат)
```

У децибелах радіаційна ефективність виражається як:

```
η_дБ = 10 · lg(η) = 10 · lg( R_рад / (R_рад + R_втрат) )
```

#### Типові співвідношення для різних типів антен:

| Тип антени | Типовий R_рад | Типовий R_втрат | ККД (η) | Причина зниження ККД |
| :--- | :--- | :--- | :--- | :--- |
| Півхвильовий диполь (мідь) | 73.1 Ом | 0.2...0.5 Ом | **99.3% ... 99.7%** | Мінімальні омічні втрати |
| Чвертьхвильовий штир (над ідеальним екраном) | 36.5 Ом | 0.3...1.0 Ом | **97% ... 99%** | Незначні втрати у металі |
| Чвертьхвильовий штир (на реальному ґрунті) | 36.5 Ом | 15...30 Ом | **55% ... 70%** | Втрати у ґрунті (R_земля) |
| Укорочена штирова антена (0.05λ) | 0.8 Ом | 5...10 Ом | **7% ... 14%** | R_рад << R_втрат |
| Друкована чип-антена смартфона (2.4 ГГц) | 2.5 Ом | 4.5 Ом | **35% ... 40%** | Втрати у FR-4 та металізації |

### Експериментальне виділення R_рад: Метод ковпака Вілера (Wheeler Cap)

Оскільки звичайний омметр вимірює лишь постійний струм (DC), а ВЧ-вимірювач імпедансу (VNA) дає загальну суму `R_вх = R_рад + R_втрат`, безпосереднє розділення `R_рад` та `R_втрат` в лабораторії є непростою задачею.

У 1959 році американський інженер **Гарольд Вілер** (*Harold Wheeler*) запропонував елегантний метод вимірювання ККД малих антен:

1. **Крок 1 (Вільне середовище):** Антена підключається до векторного аналізатора ланцюгів (VNA) безпосередньо у вільному просторі (або у безвідбивної камері). На резонансній частоті вимірюється сумарний опір `R_вільне = R_рад + R_втрат`.
2. **Крок 2 (Провідний ковпак):** Антена накривається замкненим провідним металевим ковпаком (сферою або циліндром) із радіусом `r ≈ λ / (2·π)`. Ковпак створює реактивне коротке замикання для хвиль дальньої зони, повністю блокуючи випромінювання (`R_рад → 0`), але практично не змінює струми у самій антені та її омічні втрати.
3. **Обчислення:** Опір, виміряний під ковпаком, дорівнює чистому опору втрат: `R_ковпак = R_втрат`.

Звідси опір випромінювання та ККД знаходяться за простими різницевими формулами:

```
R_рад = R_вільне - R_ковпак
η = (R_вільне - R_ковпак) / R_вільне
```

Конструктивні вимоги до ковпака Вілера вимагають відсутності власних об'ємних резонансів порожнини на робочій частоті антени, для чого радіус ковпака вибирають суворо у межах `λ / (2·π) < r < 0.61 · λ`.
