# 🧮 Математичний аналіз пасивних елементів та множника решітки Яґі-Уда

Електродинамічна поведінка решітки Яґі-Уда описується системою зв'язаних інтегральних рівнянь для тонких провідних випромінювачів у середовищі з діелектричною проникністю `ε` та магнітною проникністю `μ`. Оскільки пасивні елементи збуджуються не прямокутними джерелами напруги, а перевипроміненим полем сусідніх провідників, для повного розрахунку розподілу струмів застосовують метод наведених ЕРС або метод моментів (*Method of Moments*, MoM).

---

### 1. Інтегральне рівняння Поклінгтона для тонких провідників

Розглянемо випромінювач довжиною `L` та радіусом `a` (`a « λ`), розташований уздовж осі `z`. Згідно з рівняннями Максвелла, зв'язок між поздовжньою складовою напруженості падаючого електричного поля `E_z^inc(z)` та розподілом високочастотного струму `I(z')` уздовж провідника описується інтегральним рівнянням Поклінгтона:

```
∫ [-L/2 to L/2] I(z') · [ d²/dz² + k² ] G(z, z') dz' = -j · ω · ε · E_z^inc(z)
```

де:
- `k = ω·√(μ·ε) = 2·π / λ` — хвильове число у вільному просторі;
- `G(z, z') = e^(-j·k·R) / (4·π·R)` — тривимірна функція Гріна для вільного простору;
- `R = √[ (z - z')² + a² ]` — евклідова відстань між точкою джерела `z'` на осі та точкою спостереження `z` на поверхні провідника радіуса `a`.

Для решітки із `N` паралельних металевих стрижнів, розташованих на відстанях `d_mn` один від одного, падаюче поле `E_z^inc(z)` на `m`-му провіднику є сумою первинного поля (якщо це активний елемент) та вторинних полів, згенерованих струмами всіх інших `N - 1` провідників:

```
E_z,m^inc(z) = E_z,m^ext(z) - ∑ [n ≠ m] ∫ [-L_n/2 to L_n/2] I_n(z') · K_mn(z, z') dz'
```

де `K_mn(z, z')` — ядро взаємної індукції між `m`-им та `n`-им провідниками.

### 2. Система рівнянь взаємних опорів (Метод моментів)

Дискретизувавши розподіл струму `I_n(z')` за допомогою базисних функцій (наприклад, синусоїдальних модифікованих базисів), інтегральне рівняння Поклінгтона зводиться до алгебраїчної системи лінійних рівнянь матричного типу:

```
[ V ] = [ Z ] · [ I ]
```

У розгорнутому вигляді для решітки з `N` елементів (де елемент 1 — активний диполь, а елементи `2, 3, ..., N` — рефлектор та директори):

```
[ V₁ ]   [ Z₁₁  Z₁₂  Z₁₃  ...  Z₁N ]   [ I₁ ]
[ 0  ] = [ Z₂₁  Z₂₂  Z₂₃  ...  Z₂N ] · [ I₂ ]
[ 0  ]   [ Z₃₁  Z₃₂  Z₃₃  ...  Z₃N ]   [ I₃ ]
[ :  ]   [  :    :    :    ⋱    :  ]   [ :  ]
[ 0  ]   [ Z_N1 Z_N2 Z_N3 ... Z_NN ]   [ I_N ]
```

Тут:
- `V₁` — амплітуда комплексного напруги джерела живлення, підключеного до центральних клем активного диполя;
- `V₂ = V₃ = ... = V_N = 0` — нульові напруги на замкнених (незапитаних) пасивних елементах;
- `Z_mm = R_mm + j·X_mm` — власні комплексні опори елементів (залежать від їхніх фізичних довжин `L_m` та радіуса `a`);
- `Z_mn = R_mn + j·X_mn` — взаємні опори між `m`-им та `n`-им елементами.

Обчислення взаємного опору `Z_mn` між двома паралельними диполями довжиною `L` на відстані `d` виконується методом наведених ЕРС через синусоїдальний розподіл струму:

```
R_mn = (30 / sin²(k·L/2)) · ∫ [0 to L] sin(k·z) · [ C_i(y₁) + C_i(y₂) - 2·C_i(y₀) ] dz
```

де `C_i(y)` — функція інтегрального косинуса, а `y₀, y₁, y₂` — геометрія відстаней між крайніми точками провідників.

### 3. Двоелементна решітка: аналітичне розв'язання для струму та фази

Розглянемо окремий випадок решітки з двох елементів: активного диполя (індекс 1) та пасивного елемента (індекс 2).

Система рівнянь має вигляд:

```
V₁ = I₁·Z₁₁ + I₂·Z₁₂
0  = I₁·Z₂₁ + I₂·Z₂₂
```

Виразимо струм пасивного елемента `I₂` через струм активного диполя `I₁`:

```
I₂ = - I₁ · (Z₂₁ / Z₂₂)
```

Переведемо комплексні опори `Z₂₁` та `Z₂₂` у полярну форму:

```
Z₂₁ = |Z₂₁| · e^(j·ψ₂₁)
Z₂₂ = |Z₂₂| · e^(j·α₂₂)
```

де `α₂₂ = arctan(X₂₂ / R₂₂)` — фазовий кут власного опору пасивного стрижня.

Тоді вираз для комплексного струму `I₂` перетворюється на:

```
I₂ = - I₁ · (|Z₂₁| / |Z₂₂|) · e^(j·[ψ₂₁ - α₂₂])
   = I₁ · (|Z₂₁| / |Z₂₂|) · e^(j·[π + ψ₂₁ - α₂₂])
```

Повний зсув фази `Δφ` наведеного струму `I₂` відносно струму живлення `I₁` дорівнює:

```
Δφ = π + ψ₂₁ - α₂₂
```

Три складові фазового зсуву мають чіткий фізичний зміст:
1. `π` (180°) — протифазність індукції за законом Ленца;
2. `ψ₂₁` — кут взаємного опору (для близьких паралельних провідників `ψ₂₁ ≈ 0`);
3. `-α₂₂ = -arctan(X₂₂ / R₂₂)` — керована реактивна складова фази.

### 4. Вивід умови компенсації заднього поля (Рефлектор)

Результуюче електричне поле `E(θ)` у напрямку кута `θ` (відрахованого від осі антени `z`) дорівнює суперпозиції полів двох випромінювачів, рознесених на відстань `d`:

```
E(θ) = E₀ · [ 1 + (I₂ / I₁) · e^(j·k·d·cos θ) ]
     = E₀ · [ 1 + (|Z₂₁| / |Z₂₂|) · e^(j·[π + ψ₂₁ - α₂₂ + k·d·cos θ]) ]
```

Для повного придушення випромінювання у зворотному напрямку (`θ = 180°`, `cos θ = -1`) показник експоненти мусить дорівнювати нулю або парному числу `2·π`:

```
(π + ψ₂₁ - α₂₂ - k·d) - π = 0   =>   α₂₂ = ψ₂₁ - k·d
```

Оскільки для близьких елементів `ψ₂₁ ≈ 0`, маємо:

```
α₂₂ = - k·d < 0
```

Оскільки `α₂₂ = arctan(X₂₂ / R₂₂) < 0`, реактивний опір пасивного елемента **обов'язково має бути індуктивним**:

```
X₂₂ > 0   =>   L_R > λ/2   (Рефлектор)
```

Це є строгим математичним доказом: рефлектор мусить бути довшим за резонансне значення `λ/2`, щоб його індуктивна реактивність разом із просторовою затримкою `k·d` створила точну протифазу ззаду і синфазність вперед.

### 5. Множник багатоелементної решітки (Array Factor)

Для загального випадку решітки з `N` елементів, розташованих уздовж осі `z` у точках `z₁, z₂, ..., z_N`, результуючий множник решітки `AF(θ)` у далекій зоні описується формулою:

```
AF(θ) = ∑ [m=1 to N] I_m · e^(j·k·z_m·cos θ)
```

де комплексні амплітуди струмів `I_m` знаходяться з матричного рівняння шляхом обернення матриці взаємних опорів:

```
[ I ] = [ Z ]⁻¹ · [ V ]
```

Вхідний опір активного диполя `Z_in` у складі багатоелементної антени обчислюється як:

```
Z_in = V₁ / I₁ = Z₁₁ + ∑ [n=2 to N] (I_n / I₁) · Z₁_n
```

Оскільки комплексні співвідношення `I_n / I₁` мають значні від'ємні дійсні частини, сумарний активний опір випромінювання `R_in = Re(Z_in)` різко знижується зі збільшенням кількості директорів, що підтверджує необхідність використання петльових диполів та трансформуючих узгоджувальних кіл.

### 6. Розрахунок коефіцієнта спрямованості та вектор Пойнтінга

Коефіцієнт спрямованості `D` антени Яґі-Уда визначається як відношення максимальної інтенсивності випромінювання у напрямку головного променя `U_max` до середньої інтенсивності випромінювання по всій сфері:

```
D = 4·π · U_max / P_rad
```

Повна випромінювана потужність `P_rad` обчислюється шляхом інтегрування модуля вектора Пойнтінга `S(θ, ϕ)` по замкненій сфері радіуса `r` у далекій зоні:

```
P_rad = ∫ [0 to 2π] dϕ ∫ [0 to π] ( |E_total(θ, ϕ)|² / (2·η₀) ) · r² · sin θ dθ
```

де `η₀ = √(μ₀ / ε₀) ≈ 377 Ом` — імпеданс вільного простору.

Підставивши вираз для `E_total(θ, ϕ) = E_dipole(θ) · AF(θ)` у формулу спрямованості, отримуємо підсумковий вираз для спрямованості решітки Яґі-Уда:

```
D = 4·π · |AF(0°)|² / ∫ [0 to 2π] dϕ ∫ [0 to π] |f_dipole(θ) · AF(θ)|² · sin θ dθ
```

Чисельне варіювання довжин директорів `L_Di` та відстаней між ними `S_Di` дозволяє розв'язувати задачу оптимізації: знаходити глобальний максимум спрямованості `D_max` або максимум відношення вперед/назад `(F/B)_max`. Важливо зазначити, що максимуми `D` та `F/B` досягаються при трохи відмінних геометріях, тому в реальному проектуванні обирають компромісну геометричну конфігурацію.
