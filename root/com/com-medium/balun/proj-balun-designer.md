# ⚙️ Розрахунок параметрів балуна та феритового осердя

Під час проектування високочастотного радіотракту або розрахунку симетруючого пристрою для антени перед інженером постає завдання точного математичного вибору параметрів феритового осердя та конфігурації обмотки. Вибір «на око» або використання випадкових феритових кілець часто призводить до двох крайніх дефектів: або балун не забезпечує необхідного пригнічення спільної моди (через недостатній опір `Z_cm`), або феритове осердя перегрівається і входить у режим магнітного насичення при подачі робочої ВЧ-потужності.

У цій вставці наведено розрахунковий алгоритм, математичний розбір та повну практичну програму мовами C та C++, яка виконує комплексно-інженерний обчислювальний цикл для струмового балуна Гуанелла.

## 1. Фізична та математична модель розрахунку

Для забезпечення ефективної ізоляції несиметричного кабелю від симетричної антени індуктивний опір спільної моди `Z_cm` на найнижчій робочій частоті `f_min` має перевищувати хвильовий опір кабелю `Z_0` принаймні в 10–20 разів (для ліній 50 Ом це становить `Z_cm ≥ 500…1000 Ом`).

Обчислювальний алгоритм складається з п'яти послідовних етапів:

### Етап 1: Визначення мінімальної необхідної індуктивності `L_cm`
Зв'язок між індуктивним опором `Z_cm` та індуктивністю `L_cm` на частоті `f` задається формулою:

```
Z_cm = 2π · f · L_cm
L_cm = Z_cm / (2π · f)
```

де `Z_cm` вимірюється в Омах, `f` — у Герцах, а `L_cm` — у Генрі. При розрахунку на низьких частотах (наприклад, 1.8 МГц чи 3.5 МГц) необхідна індуктивність виходить значно більшою, ніж для діапазонів 28 МГц чи 144 МГц, що вимагає вибору фериту з вищою початковою магнітною проникністю `μ_i`.

### Етап 2: Розрахунок кількості витків `N`
Індуктивність котушки на тороїдальному феритовому осерді визначається коефіцієнтом індуктивності `A_L` (задається в нГн на один виток у квадраті, `нГн / N²`):

```
L_nH = A_L · N²
N = ceil( √( L_nH / A_L ) )
```

Оскільки кількість витків може бути лише цілим числом, результат округлюється в більшу сторону (`ceil`). Коефіцієнт `A_L` залежить від геометричних розмірів тороїда (зовнішнього діаметра `D`, внутрішнього діаметра `d` та висоти `h`) і комплексної проникності `μ`:

```
A_L = (4π · 10⁻⁷ · A_e · μ_i / l_m) · 10⁹    [нГн / виток²]
```

де `A_e = h · (D - d) / 2` — ефективна площа перерізу осердя, а `l_m = π · (D + d) / 2` — середня довжина магнітної лінії.

### Етап 3: Обчислення фактичного імпедансу та CMRR
Після округлення кількості витків до найближчого цілого `N` перераховується фактична індуктивність та підсумковий опір спільної моди `Z_actual`:

```
L_actual_nH = N² · A_L
Z_actual = 2π · f · L_actual_H
CMRR = 20 · log10( 1 + Z_actual / (2 · Z_0) )    [в децибелах, дБ]
```

Значення CMRR показує відносне послаблення струмів затікання на оплітку кабелю порівняно з диференційним сигналом. При `CMRR = 20 дБ` струм затікання становить менше 10% від диференційного струму, а при `CMRR = 30 дБ` — менше 3.16%.

### Етап 4: Розрахунок пікової ВЧ-напруги
При подачі на кабель з хвильовим опором `Z_0` синусоїдальної ВЧ-потужності `P` амплітудне (пікове) значення напруги обчислюється як:

```
V_peak = √( 2 · P · Z_0 )
```

Для потужності `100 Вт` у 50-омній лінії пікова напруга становить `V_peak = √(2 · 100 · 50) = 100 В`. Для потужності `1500 Вт` пікова напруга зростає до `V_peak = √(2 · 1500 · 50) = 387.3 В`. При високому КСХ напруга у вузлах стоячої хвилі може подвоюватися, сягаючи `770 В`.

### Етап 5: Перевірка магнітної індукції `B_peak` та ризику насичення
Амплітуда магнітної індукції в осерді з ефективною площею перерізу `A_e` (у см²) на частоті `f` (у Гц) розраховується за формулою Фарадея:

```
B_peak = ( V_peak · 10⁸ ) / ( 4.44 · f · A_e · N )    [в Гауссах]
```

Якщо `B_peak` перевищує допустиму межу для обраної феритової суміші (для Mix 31/43 безпечна межа становить `2500 Гаусс` або `0.25 Тл`), програма сигналізує про ризик магнітного насичення та перегріву. При насиченні фериту його проникність `μ` різко падає до одиниці, балун втрачає опір спільної моди, а вихідний ВЧ-сигнал збагачується високими гармоніками.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

/* Структура вхідних даних для розрахунку балуна */
typedef struct {
    double freq_mhz;         /* Робоча частота (МГц) */
    double z0_ohm;           /* Хвильовий опір фідерної лінії (Ом) */
    double target_zcm_ohm;   /* Бажаний опір спільної моди Z_cm (Ом) */
    double power_watts;      /* ВЧ потужність передавача (Вт) */
    double core_al_nh;       /* Коефіцієнт індуктивності осердя A_L (нГн/виток^2) */
    double core_ae_cm2;      /* Ефективна площа перерізу осердя A_e (см^2) */
} balun_input_t;

/* Структура результатів обчислення */
typedef struct {
    double min_l_uh;         /* Необхідна мін. індуктивність L_cm (мкГн) */
    int turns_count;         /* Розрахункова кількість витків N */
    double actual_zcm_ohm;   /* Фактичний опір Z_cm на робочій частоті (Ом) */
    double cmrr_db;          /* Пригнічення спільної моди (дБ) */
    double v_peak;           /* Пікова ВЧ напруга (В) */
    double b_peak_gauss;     /* Пікова магнітна індукція у фериті (Гаусс) */
    int is_saturated;        /* Прапорець ризику насичення (1 - так, 0 - ні) */
} balun_output_t;

/* Функція розрахунку параметрів балуна */
int calculate_balun_params(const balun_input_t *in, balun_output_t *out) {
    if (!in || !out || in->freq_mhz <= 0.0 || in->z0_ohm <= 0.0) {
        return -1;
    }

    double omega = 2.0 * M_PI * (in->freq_mhz * 1e6);
    
    /* 1. Розрахунок мінімально необхідної індуктивності */
    double req_l_h = in->target_zcm_ohm / omega;
    out->min_l_uh = req_l_h * 1e6;

    /* 2. Обчислення кількості витків: N = sqrt( L_nH / A_L ) */
    double req_l_nh = req_l_h * 1e9;
    if (in->core_al_nh > 0.0) {
        out->turns_count = (int)ceil(sqrt(req_l_nh / in->core_al_nh));
        if (out->turns_count < 1) out->turns_count = 1;
    } else {
        out->turns_count = 0;
    }

    /* 3. Фактичний опір та CMRR */
    double actual_l_nh = (double)(out->turns_count * out->turns_count) * in->core_al_nh;
    double actual_l_h = actual_l_nh * 1e-9;
    out->actual_zcm_ohm = omega * actual_l_h;
    
    out->cmrr_db = 20.0 * log10(1.0 + (out->actual_zcm_ohm / (2.0 * in->z0_ohm)));

    /* 4. Розрахунок пікової напруги та магнітної індукції */
    out->v_peak = sqrt(2.0 * in->power_watts * in->z0_ohm);
    
    /* B_peak (Gauss) = (V_peak * 10^8) / (4.44 * f_Hz * A_e_cm2 * N) */
    if (in->core_ae_cm2 > 0.0 && out->turns_count > 0) {
        double f_hz = in->freq_mhz * 1e6;
        out->b_peak_gauss = (out->v_peak * 1e8) / (4.44 * f_hz * in->core_ae_cm2 * (double)out->turns_count);
    } else {
        out->b_peak_gauss = 0.0;
    }

    /* Межа насичення для типових феритів Mix 31/43 становить ~2500 Гаусс (0.25 Тл) */
    out->is_saturated = (out->b_peak_gauss > 2500.0) ? 1 : 0;

    return 0;
}

int main(void) {
    balun_input_t input = {
        .freq_mhz = 14.150,      /* Діапазон 20 метрів (14.15 МГц) */
        .z0_ohm = 50.0,          /* Коаксіал 50 Ом */
        .target_zcm_ohm = 1000.0,/* Цільовий опір Z_cm = 1000 Ом */
        .power_watts = 500.0,    /* Потужність 500 Вт */
        .core_al_nh = 240.0,     /* Осердя FT-240-31 (A_L ≈ 240 нГн/виток^2) */
        .core_ae_cm2 = 1.58      /* Площа перерізу FT-240 A_e = 1.58 см^2 */
    };

    balun_output_t output;
    if (calculate_balun_params(&input, &output) != 0) {
        fprintf(stderr, "Помилка розрахунку параметрів балуна.\n");
        return EXIT_FAILURE;
    }

    printf("=== РОЗРАХУНОК СТРУМОВОГО БАЛУНА ГУАНЕЛЛА (C) ===\n");
    printf("Частота            : %.3f МГц\n", input.freq_mhz);
    printf("Потужність         : %.1f Вт\n", input.power_watts);
    printf("Мін. індуктивність : %.2f мкГн\n", output.min_l_uh);
    printf("Кількість витків N : %d витків\n", output.turns_count);
    printf("Фактичний Z_cm     : %.1f Ом\n", output.actual_zcm_ohm);
    printf("Пригнічення CMRR   : %.2f дБ\n", output.cmrr_db);
    printf("Пікова ВЧ напруга  : %.1f В\n", output.v_peak);
    printf("Магнітна індукція  : %.1f Гаусс\n", output.b_peak_gauss);
    printf("Статус осердя      : %s\n", output.is_saturated ? "УВАГА: Ризик насичення!" : "ОК (Безпечний режим)");

    return EXIT_SUCCESS;
}
```

```cpp
#include <iostream>
#include <cmath>
#include <numbers>
#include <format>
#include <expected>
#include <string_view>

struct BalunInput {
    double freq_mhz{14.150};
    double z0_ohm{50.0};
    double target_zcm_ohm{1000.0};
    double power_watts{500.0};
    double core_al_nh{240.0};
    double core_ae_cm2{1.58};
};

struct BalunOutput {
    double min_l_uh{0.0};
    int turns_count{0};
    double actual_zcm_ohm{0.0};
    double cmrr_db{0.0};
    double v_peak{0.0};
    double b_peak_gauss{0.0};
    bool is_saturated{false};
};

enum class BalunCalcError {
    InvalidFrequency,
    InvalidImpedance,
    InvalidCoreData
};

[[nodiscard]] std::expected<BalunOutput, BalunCalcError> calculate_balun(const BalunInput& in) noexcept {
    if (in.freq_mhz <= 0.0) return std::unexpected(BalunCalcError::InvalidFrequency);
    if (in.z0_ohm <= 0.0 || in.target_zcm_ohm <= 0.0) return std::unexpected(BalunCalcError::InvalidImpedance);

    BalunOutput out;
    const double omega = 2.0 * std::numbers::pi * (in.freq_mhz * 1e6);

    // 1. Необхідна індуктивність L_cm
    const double req_l_h = in.target_zcm_ohm / omega;
    out.min_l_uh = req_l_h * 1e6;

    // 2. Кількість витків N
    const double req_l_nh = req_l_h * 1e9;
    if (in.core_al_nh > 0.0) {
        out.turns_count = static_cast<int>(std::ceil(std::sqrt(req_l_nh / in.core_al_nh)));
        out.turns_count = std::max(1, out.turns_count);
    }

    // 3. Фактичний опір та CMRR
    const double actual_l_nh = static_cast<double>(out.turns_count * out.turns_count) * in.core_al_nh;
    const double actual_l_h = actual_l_nh * 1e-9;
    out.actual_zcm_ohm = omega * actual_l_h;

    out.cmrr_db = 20.0 * std::log10(1.0 + (out.actual_zcm_ohm / (2.0 * in.z0_ohm)));

    // 4. Напруга та магнітна індукція
    out.v_peak = std::sqrt(2.0 * in.power_watts * in.z0_ohm);

    if (in.core_ae_cm2 > 0.0 && out.turns_count > 0) {
        const double f_hz = in.freq_mhz * 1e6;
        out.b_peak_gauss = (out.v_peak * 1e8) / (4.44 * f_hz * in.core_ae_cm2 * static_cast<double>(out.turns_count));
    }

    out.is_saturated = (out.b_peak_gauss > 2500.0);

    return out;
}

int main() {
    constexpr BalunInput input{
        .freq_mhz = 14.150,
        .z0_ohm = 50.0,
        .target_zcm_ohm = 1000.0,
        .power_watts = 500.0,
        .core_al_nh = 240.0,
        .core_ae_cm2 = 1.58
    };

    const auto result = calculate_balun(input);

    if (!result) {
        std::cerr << "Помилка обчислення параметрів балуна!\n";
        return 1;
    }

    const auto& out = *result;

    std::cout << std::format("=== РОЗРАХУНОК СТРУМОВОГО БАЛУНА ГУАНЕЛЛА (C++) ===\n");
    std::cout << std::format("Частота            : {:.3f} МГц\n", input.freq_mhz);
    std::cout << std::format("Потужність         : {:.1f} Вт\n", input.power_watts);
    std::cout << std::format("Мін. індуктивність : {:.2f} мкГн\n", out.min_l_uh);
    std::cout << std::format("Кількість витків N : {} витків\n", out.turns_count);
    std::cout << std::format("Фактичний Z_cm     : {:.1f} Ом\n", out.actual_zcm_ohm);
    std::cout << std::format("Пригнічення CMRR   : {:.2f} дБ\n", out.cmrr_db);
    std::cout << std::format("Пікова ВЧ напруга  : {:.1f} В\n", out.v_peak);
    std::cout << std::format("Магнітна індукція  : {:.1f} Гаусс\n", out.b_peak_gauss);
    std::cout << std::format("Статус осердя      : {}\n", 
        out.is_saturated ? "УВАГА: Ризик насичення!" : "ОК (Безпечний режим)");

    return 0;
}
```

## 3. Розбір синтаксису та ідіоматичних відмінностей між C та C++

Версія програми мовою C спирається на стандартні структури `balun_input_t` та `balun_output_t` з явним передаванням вказувачів та перевіркою коректності параметрів у кодах повернення. Використовуються стандартні математичні функції з бібіліотеки `<math.h>` (`ceil`, `sqrt`, `log10`) та класичний вивід через `printf`.

Версія мовою C++ виправляє недоліки сишного дизайну за допомогою сучасних стандартів C++20 та C++23:
- **Типобезпечна обробка помилок `std::expected<BalunOutput, BalunCalcError>`:** Замість повернення числових кодів помилок або сирих вказувачів функція повертає об'єкт `std::expected`. Якщо вхідні дані некоректні, повертається строго типізований enum класу `BalunCalcError` (`InvalidFrequency`, `InvalidImpedance`). Це повністю виключає можливість випадкового використання непоініціалізованого результату.
- **Стандартні математичні константи `std::numbers::pi`:** Використання точної математичної константи `π` зі стандарту C++20 замість застарілих препроцесорних макросів `#define M_PI`, що запобігає забрудненню глобального простору імен.
- **Безпечне форматування `std::format`:** Сучасний безнадійний форматичний вивід спирається на тип безпечний `std::format` із C++20. Він гарантує відсутність помилок приведення типів у специфікаторах (на кшталт невідповідності `%f` та `%d` у `printf`).
- **Конструкції `constexpr` та `noexcept`:** Оголошення структур та обчислювальної функції як `noexcept` та підготовка вхідних даних як `constexpr` дозволяють компілятору виконувати обчислення параметрів балуна безпосередньо під час компіляції для стаціонарних конфігурацій антен.

## 4. Покроковий розбір обчислення та інженерні висновки

Для тестового прикладу передавача потужністю `500 Вт` на частоті `14.15 МГц` із популярним тороїдом FT-240-31 програма видає такі розрахункові величини:

1. **Індуктивність `L_cm`:** Для досягнення `Z_cm = 1000 Ом` на частоті 14.15 МГц необхідна індуктивність `L_cm = 11.24 мкГн`.
2. **Кількість витків `N`:** З урахуванням `A_L = 240 нГн/виток²` розрахунок дає `N = √(11240 / 240) = 6.84`, що округлюється до `7 витків`.
3. **Фактичне пригнічення:** 7 витків дають `L_actual = 11.76 мкГн`, що забезпечує `Z_actual = 1046 Ом` та коефіцієнт пригнічення `CMRR = 21.2 дБ`.
4. **Магнітна індукція:** При потужності 500 Вт напруга становить `V_peak = 223.6 В`, а магнітна індукція `B_peak = 32.2 Гаусс`. Це значно нижче критичної межі `2500 Гаусс`, що гарантує відсутність насичення фериту та стабільну роботу балуна без перегріву.

## 5. Крайові випадки та інженерні пастки

Під час використання калькулятора слід зважати на кілька практичних крайових випадків:

- **Занадто мала кількість витків (`N < 3`):** Якщо розрахунок дає `N = 1` або `N = 2`, опір `Z_cm` вийде недостатнім на нижньому краю діапазону. Рекомендується обрати осердя з більшим коефіцієнтом `A_L` (наприклад, суміш Mix 31 замість Mix 61).
- **Перевищення магнітної індукції (`B_peak > 2500 Гаусс`):** Якщо прапорець `is_saturated` стає активним (наприклад, при роботі з потужністю 1500 Вт на частоті 1.8 МГц), необхідно збільшити кількість витків `N`, скласти разом два осердя FT-240 (що подвоїть площу `A_e` до `3.16 см²`) або обрати тороїд більшого діаметра FT-290.
- **Врахування міжвиткової ємності `C_p`:** Додавання кожного нового витка збільшує паразитну ємність обмотки. На частотах понад 21 МГц занадто велика кількість витків (`N > 12`) знижує власну резонансну частоту дроселя `f_SRF`, переводячи його в ємнісний режим із втратою ефективності пригнічення.
