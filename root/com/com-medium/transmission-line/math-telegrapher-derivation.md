# 🧮 Вивід телеграфних рівнянь з рівнянь Максвелла

Теорія ліній передачі поєднує польову електродинаміку Максвелла із практичною теорією електричних кіл. Модель Телеграфіста не є довільним гіпотетичним припущенням: вона прямо виводиться з фундаментальних рівнянь Максвелла у диференціальній та інтегральній формах для поперечної електромагнітної хвилі (ТЕМ-хвилі), що поширюється у системі з двох паралельних провідників.Цей математичний вивід показує точний фізичний зміст погонних параметрів `L_0`, `C_0`, `R_0`, `G_0` та пояснює, як хвильова константа поширення задає затухання й фазову швидкість сигналу.

## Поперечна електромагнітна хвиля (ТЕМ) та поле у перерізі

Розглянемо двопровідну лінію передачі довільного поперечного перерізу, напрямок поширення хвилі у якій збігається з віссю `z`. Матеріал провідників вважається ідеальним провідником із нескінченною електропровідністю `σ → ∞`, а міжпровідний простір заповнений однорідним діелектриком із проникностями `ε` та `μ`.

У ТЕМ-хвилі поздовжні складові векторів електричного та магнітного полів дорівнюють нулю:

```
E_z(x, y, z, t) = 0
H_z(x, y, z, t) = 0
```

Це означає, що вектори `E` та `H` лежать строго у поперечній площині `xy`. Розпишемо систему диференціальних рівнянь Максвелла у частинних похідних для гармонічного режиму `e^(j·ω·t)`.

Рівняння ротора електричного поля `∇ × E = - j·ω·μ·H` у декартових координатах розпадається на складові. З урахуванням того, що `E_z = 0`, поздовжня складова ротора дає:

```
∂E_y / ∂x - ∂E_x / ∂y = - j · ω · μ · H_z = 0
```

Ця рівність означає, що у кожному поперечному перерізі лінії (при фіксованій координаті `z`) ротор поперечного електричного поля дорівнює нулю: `∇_t × E_t = 0`. Отже, у межах одного перерізу електричне поле є потенціальним і може бути виражене через скалярний електричний потенціал `Φ(x,y)`:

```
E_t(x, y, z) = - ∇_t Φ(x, y, z)
```

Застосовуючи перше рівняння Максвелла `∇ · D = 0` для діелектрика без вільних об'ємних зарядів, отримуємо, що потенціал `Φ(x,y)` у поперечному перерізі задовольняє двовимірне рівняння Лапласа:

```
∇_t² Φ = ∂²Φ / ∂x² + ∂²Φ / ∂y² = 0
```

Це надзвичайно важливий математичний результат: конфігурація електричного та магнітного полів у поперечному перерізі ТЕМ-лінії на будь-якій частоті є повністю тотожною конфігурації статичних електростатичного та магнітостатичного полів для даної геометрії провідників.

## Строгий польовий вивід телеграфних рівнянь

Для зв'язку польових змінних із напругою та струмом виділимо у лінії передачі елементарний об'єм довжиною `dz` між координатами `z` та `z + dz`.

Напруга `V(z)` у перерізі `z` задається різницею потенціалів між першим і другим провідниками:

```
V(z) = Φ_1(z) - Φ_2(z) = - ∫[від 1 до 2] E_t · dl
```

Струм `I(z)`, що протікає по першому провіднику, за законом Ампера визначається циркуляцією магнітного поля по контуру `C_1`, який охоплює цей провідник у площині перерізу:

```
I(z) = ∮[навколо 1] H_t · dl
```

Застосуємо закон індукції Фарадея в інтегральній формі до прямокутного контуру `K` довжиною `dz`, одна сторона якого лежить на поверхні першого провідника, а протилежна — на поверхні другого:

```
∮[по контуру K] E · dl = - j · ω · ∬[через контур K] B · dA
```

Обчислимо циркуляцію поля `E` по контуру `K`:
- На сегменті довжиною `dz` уздовж ідеального провідника 1 поздовжнє поле дорівнює нулю `E_z = 0` (або `R_0 · I` при врахуванні омічного опору втрат).
- На поперечному відрізку в точці `z` інтеграл дає напругу `V(z)`.
- На поперечному відрізку в точці `z + dz` інтеграл дає `- V(z + dz)`.

Отже, ліва частина закону Фарадея дорівнює `V(z) - V(z + dz) = - dV`.

Права частина дорівнює часовій похідній магнітного потоку `dΦ_m`, що пронизує прямокутник шириною між провідниками та довжиною `dz`:

```
dΦ_m = (∫[між провідниками] B_t · dl) · dz = (L_0 · I(z)) · dz
```

де погонна індуктивність `L_0` визначається як відношення магнітного потоку на один метр до струму:

```
L_0 = (μ / I) · ∫[між провідниками] H_t · dl
```

Прирівнюючи ліву та праву частини і додаючи активний опір втрат у металі `R_0` на одиницю довжини, отримуємо перше телеграфне рівняння Хевісайда:

```
dV / dz = - R_0 · I - j · ω · L_0 · I = - (R_0 + j·ω·L_0) · I      [перше телеграфне рівняння]
```

Аналогічно, застосуємо закон Ампера — Максвелла `∇ × H = J + j·ω·ε·E` до об'єму довжиною `dz`, що охоплює перший провідник. Зміна струму `dI` вздовж провідника зумовлена витоком струму провідності крізь діелектрик `G_0 · V · dz` та струмом зсуву крізь ємність `j·ω·C_0 · V · dz`:

```
dI / dz = - G_0 · V - j · ω · C_0 · V = - (G_0 + j·ω·C_0) · V      [друге телеграфне рівняння]
```

де погонна ємність `C_0` задається відношенням електричного заряду провідника на один метр до напруги:

```
C_0 = (ε / V) · ∮[навколо 1] E_t · dn
```

а погонна провідність витоку ізоляції `G_0` дорівнює:

```
G_0 = (σ_d / V) · ∮[навколо 1] E_t · dn
```

де `σ_d` — питома провідність діелектрика.

## Фундаментальна теорема про добуток погонних параметрів

Перемножимо вирази для погонної індуктивності `L_0` та погонної ємності `C_0` для довільної геометричної форми провідників у однорідному діелектрику:

```
L_0 · C_0
= ((μ / I) · ∫[між 1 і 2] H_t · dl) · ((ε / V) · ∮[навколо 1] E_t · dn)
```

Зі співвідношень ортогональності полів у ТЕМ-хвилі випливає, що модуль магнітного поля у кожній точці зв'язаний із модулем електричного поля співвідношенням `H_t = √(ε / μ) · E_t`. Підставивши це співвідношення у подвійний інтеграл, геометричні інтеграли по контурах повністю скорочуються із величинами `V` та `I`.

У результаті отримуємо фундаментальну теорему електродинаміки ТЕМ-ліній:

```
L_0 · C_0 = μ · ε      [теорема про добуток погонних параметрів]
```

Цей математичний доказ показує: для будь-якої ТЕМ-лінії передачі з двох провідників (коаксіал, вита пара, двообкладний хвилевід, смугова лінія) добуток погонної індуктивності на погонну ємність залежить виключно від матеріалу діелектрика і не залежить від форми чи розмірів провідників.

Звідси негайно випливає, що фазова швидкість хвилі у лінії без втрат завжди дорівнює швидкості світла у даному середовищі:

```
v = 1 / √(L_0 · C_0) = 1 / √(μ · ε)
```

## Гармонічний режим та комплексні хвильові рівняння

У синусоїдальному усталеному режимі з коловою частотою `ω` система телеграфних рівнянь записується у матричній формі:

```
dV / dz = - Z_series · I
dI / dz = - Y_shunt · V
```

де `Z_series = R_0 + j·ω·L_0` — комплексний поздовжній імпеданс елементарної ланки, а `Y_shunt = G_0 + j·ω·C_0` — комплексний поперечний адмітанс.

Продиференціюємо перше рівняння по `z` і підставимо вираз для `dI / dz`:

```
d²V / dz²
= - Z_series · (dI / dz)                    [диференціювання по z]
= - Z_series · (- Y_shunt · V)              [підстановка dI/dz = -Y_shunt · V]
= Z_series · Y_shunt · V                     [зведення знаків]
= γ² · V                                     [визначення константи γ]
```

Аналогічна процедура для струму дає повністю симетричне хвильове рівняння:

```
d²I / dz² = γ² · I
```

Комплексна константа поширення `γ` виражається через погонні параметри лінії:

```
γ = √(Z_series · Y_shunt)                   [за визначенням хвильової константи]
= √((R_0 + j·ω·L_0) · (G_0 + j·ω·C_0))      [підстановка виразів для Z_series та Y_shunt]
= α + j·β                                   [розділення на дійсну та уявну частини]
```

де:
- `α` — коефіцієнт затухання (вимірюється в неперах на метр, Нп/м, або децибелах на метр, дБ/м);
- `β` — коефіцієнт фази (вимірюється в радіанах на метр, рад/м).

Розв'язок хвильового рівняння для напруги має вигляд суми двох біжучих хвиль:

```
V(z) = V⁺ · e^(-γ·z) + V⁻ · e^(+γ·z)
```

де `V⁺ · e^(-γ·z)` описує хвилю, що рухається в напрямку зростання `z` (падаюча хвиля), а `V⁻ · e^(+γ·z)` — хвилю, що рухається в протилежному напрямку (відбита хвиля).

## Аналіз лінії з малими втратами (High-Frequency Limit)

У високочастотному діапазоні (для швидкісних цифрових сигналів та РЧ-трактів) реактивні опори суттєво перевищують активні втрати: `ω·L_0 >> R_0` та `ω·C_0 >> G_0`. Розкладемо квадратний корінь константи поширення `γ` у біноміальний ряд по малому параметру.

Винесемо `j·ω·√(L_0·C_0)` за дужки у виразі для `γ`:

```
γ = j·ω·√(L_0·C_0) · √((1 + R_0 / (j·ω·L_0)) · (1 + G_0 / (j·ω·C_0)))
```

Використовуючи наближення Тейлора `√(1 + x) ≈ 1 + x / 2` для `x << 1`:

```
γ ≈ j·ω·√(L_0·C_0) · (1 + R_0 / (2·j·ω·L_0) + G_0 / (2·j·ω·C_0))
= j·ω·√(L_0·C_0) + (R_0 / 2) · √(C_0 / L_0) + (G_0 / 2) · √(L_0 / C_0)
```

Розділивши дійсну та уявну частини `γ = α + j·β`, отримуємо наближені формули для лінії з малими втратами:

```
α ≈ (R_0 / (2 · Z_0)) + ((G_0 · Z_0) / 2)    [коефіцієнт затухання]
β ≈ ω · √(L_0 · C_0)                        [коефіцієнт фази]
```

де `Z_0 = √(L_0 / C_0)` — характеристичний імпеданс лінії без втрат.

З отриманого виразу видно:
1. Затухання складається з двох доданків: омічних втрат у металі `R_0 / (2·Z_0)` та діелектричних втрат `(G_0·Z_0) / 2`.
2. Фазовий коефіцієнт `β` є лінійним по частоті, тому фазова швидкість `v = ω / β = 1 / √(L_0·C_0)` у лінії з малими втратами залишається майже сталою, мінімізуючи дисперсію.

## Математичний вивід умови Хевісайда

Знайдемо суворі математичні умови, за яких коефіцієнт затухання `α` є абсолютно сталим на всіх частотах, а фазова швидкість `v = ω / β` не залежить від частоти.

Розкриємо квадрат константи поширення `γ²`:

```
γ² = (R_0 + j·ω·L_0) · (G_0 + j·ω·C_0)
= R_0·G_0 - ω²·L_0·C_0 + j·ω·(R_0·C_0 + L_0·G_0)
```

Підставимо умову Олівера Хевісайда `R_0 / L_0 = G_0 / C_0 = k` (де `k` — стала величина). Звідси `R_0·C_0 = k·L_0·C_0` та `L_0·G_0 = k·L_0·C_0`.

Тоді уявна частина підкореневого виразу спрощується:

```
R_0·C_0 + L_0·G_0 = 2 · √(R_0 · G_0 · L_0 · C_0)
```

Підставляючи це у вираз для `γ²`:

```
γ² = (√(R_0·G_0) + j·ω·√(L_0·C_0))²
```

Беручи квадратний корінь з обох частин, отримуємо точне значення для `γ`:

```
γ = α + j·β
= √(R_0·G_0) + j·ω·√(L_0·C_0)
```

Звідси випливають два фундаментальні висновки:

1. Коефіцієнт затухання `α = √(R_0 · G_0)` є повністю сталим і не залежить від частоти `ω`. Усі спектральні компоненти затухають з однаковою швидкістю.
2. Коефіцієнт фази `β = ω · √(L_0 · C_0)` строго лінійно залежить від частоти. Фазова швидкість хвилі `v = ω / β = 1 / √(L_0 · C_0)` є однаковою для всіх частот. Дисперсія сигналу повністю відсутня.

## Вплив поверхневого ефекту (Скін-ефекту) на погонні параметри

На високих частотах припущення про сталість погонного опору `R_0` та індуктивності `L_0` стає неточнішим через поверхневий ефект у металевих провідниках.

Змінне магнітне поле всередині провідника створює вихрові струми, які виштовхують основний струм до поверхні. Глибина проникнення струму `δ` зменшується обернено пропорційно квадратному кореню з частоти:

```
δ = √(2 / (ω · μ_m · σ))
```

де `σ` — питома провідність металу, а `μ_m` — магнітна проникність провідника.

Унаслідок цього ефективний переріз струму стає прямо пропорційним `δ`, а погонний опір `R_0` зростає пропорційно `√ω`:

```
R_0(ω) = R_dc · (d / (4 · δ)) ∝ √ω
```

Одночасно внутрішня магнітна енергія всередині металу прямує до нуля, внаслідок чого внутрішня індуктивність провідника `L_int` зменшується пропорційно `1 / √ω` до нуля. На високих частотах у лінії залишається лише зовнішня індуктивність `L_ext`, яка визначається конфігурацією полів у діелектрику.

Комплексний поверхневий імпеданс провідника `Z_s` на високих частотах володіє однаковою дійсною та уявною частинами:

```
Z_s = R_s + j · X_s = (1 + j) / (σ · δ) = (1 + j) · √(ω · μ_m / (2 · σ))
```

Рівність дійсної та уявної частин поверхневого опору призводить до того, що активний опір металу `R_0(ω)` на високих частотах робить однаковий внесок як у затухання `α`, так і в додатковий фазовий зсув сигналу, спричиняючи слабку залишкову дисперсію навіть у добре узгоджених лініях.
