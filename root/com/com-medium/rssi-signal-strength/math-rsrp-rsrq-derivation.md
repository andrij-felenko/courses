# 🧮 Математична модель вимірювання RSRP, RSRQ та логарифмічного затухання

Оцінка якості бездротового каналу зв'язку у мультиносійних системах OFDM спирається на точний математичний апарат усереднення потужності дискретних відліків у частотній та часовій областях, моделювання завад і розрахунок емпіричних моделей загасання електромагнітних хвиль у середовищі.

## Дискретне усереднення потужності та розрахунок RSRP

У системах OFDM спектральна смуга розбита на `N_sub` піднесних із частотним інтервалом `Δf` (наприклад, `Δf = 15 кГц` у стандарту LTE або `30 кГц` у 5G NR). Комплексний відлік сигналу на `k`-й піднесній після виконання швидкого перетворення Фур’є (FFT) у цифровому процесорі приймача позначається як:

```
X[k] = I[k] + j · Q[k]
```

Де `I[k]` — синфазна складова, а `Q[k]` — квадратурна складова сигналу. Миттєва лінійна потужність `P[k]` на `k`-й піднесній (у ватах) обчислюється як квадрат модуля комплексного числа:

```
P[k] = |X[k]|² = I[k]² + Q[k]²
```

Позначимо через `S_RS` множину індексів ресурсних елементів (Resource Elements, RE), які містять еталонний пилотний/опорний сигнал (Cell-specific Reference Signal, CRS у LTE або Synchronization Signal Block, SSB у 5G NR). Кількість таких елементів у вимірювальному інтервалі часу дорівнює `N_RE`.

Метрика **RSRP (Reference Signal Received Power)** обчислюється як математичне середнє лінійної потужності на опорних піднесних:

```
RSRP_mW = (1 / N_RE) · ∑ P[k]     [k ∈ S_RS]
```

Переведення RSRP у логарифмічну шкалу децибел-міліватів (дБм) виконується за формулою:

```
RSRP_dBm = 10 · log10( RSRP_mW )
```

Якщо передавач випромінює опорний сигнал із потужністю `P_tx_RE` (наприклад, `10 мВт` або `+10 дБм` на один ресурсний елемент), а загальне згасання в каналі між антенами дорівнює `L_path` (у разах), то вхідний RSRP прямо вимірює втрати в середовищі:

```
RSRP_mW = P_tx_RE / L_path                                           [загасання сигналу в середовищі]
RSRP_dBm = P_tx_RE_dBm - L_path_dB                                    [переведення в децибельний вигляд]
```

У системах з багатьма антенами (MIMO 2x2 або 4x4) вимірювання RSRP проводиться окремо для кожного антенного порту (Antenna Port 0, 1, 2, 3). Підсумкове значення RSRP обчислюється як лінійне середнє по всіх доступних вимірювальних портах антени.

## Математичний зв’язок між RSSI, RSRP та RSRQ у LTE та 5G

RSSI вимірює **сумарну широкосмугову потужність** OFDM-символу по всіх піднесних вимірювальної смуги, що складається з `N_RB` ресурсних блоків. Оскільки один ресурсний блок стандарту LTE містить `12` піднесних у частотній області, загальна кількість піднесних у смузі вимірювання дорівнює `12 · N_RB`.

Нехай `P_data` — середня потужність піднесних даних, `P_int` — потужність зовнішніх завад (Interference), а `P_noise` — потужність внутрішнього теплового шуму приймача. Повний лінійний RSSI дорівнює алгебраїчній сумі всіх джерел випромінювання:

```
RSSI_mW = 12 · N_RB · RSRP_mW + P_data_total + P_int_total + P_noise_total
```

У разі, коли базова станція повністю завантажена (усі піднесні передають дані з тією ж потужністю, що й пилоти: `P_data = RSRP_mW`), за відсутності зовнішніх завад та шуму сумарний RSSI спрощується до:

```
RSSI_mW = 12 · N_RB · RSRP_mW
```

**RSRQ (Reference Signal Received Quality)** визначається як безрозмірне відношення нормованого RSRP до сумарного RSSI:

```
RSRQ = (N_RB · RSRP_mW) / RSSI_mW
```

Переведемо формулу RSRQ у логарифмічний вигляд (у децибелах):

```
RSRQ_dB = 10 · log10( (N_RB · RSRP_mW) / RSSI_mW )
        = 10 · log10(N_RB · RSRP_mW) - 10 · log10(RSSI_mW)          [властивість логарифма частки: log(A/B) = log A - log B]
        = 10 · log10(RSRP_mW) + 10 · log10(N_RB) - 10 · log10(RSSI_mW) [властивість логарифма добутку: log(A·B) = log A + log B]
        = RSRP_dBm + 10 · log10(N_RB) - RSSI_dBm                       [означення дБм: 10·log10(P_mW) = P_dBm]
```

### Математичний аналіз граничних значень RSRQ:

1. **Ідеальний порожній канал (тільки пилоти БС, без даних і завад):**
   У ресурсному блоці з 12 піднесних випромінюються тільки 2 пилотні елементи. Сумарний `RSSI_mW = 2 · N_RB · RSRP_mW`.
   Тоді `RSRQ = N_RB · RSRP / (2 · N_RB · RSRP) = 1/2 = 0.5`, що в децибелах відповідає:
   `RSRQ_max = 10 · log10(0.5) = -3.01 дБ`.
2. **Повністю завантажений канал без завад:**
   Усі 12 піднесних активні й передають дані. `RSSI_mW = 12 · N_RB · RSRP_mW`.
   `RSRQ = N_RB · RSRP / (12 · N_RB · RSRP) = 1/12 ≈ 0.0833`, що відповідає:
   `RSRQ_loaded = 10 · log10(1/12) ≈ -10.79 дБ`.
3. **Канал із сильними завадами або на межі соти:**
   Коли `RSSI_mW` визначається потужними завадами сусідніх веж, RSRQ падає до `-15 дБ … -20 дБ`.

## Оцінка відношення сигнал/завада+шум (SINR)

SINR (Signal-to-Interference-plus-Noise Ratio) описує чистоту сигналу на рівні окремого ресурсного елемента:

```
SINR_linear = RSRP_mW / (I_RE_mW + N_RE_mW)
SINR_dB = 10 · log10( SINR_linear )
```

Де `I_RE_mW` — середня потужність інтерференції від сусідніх стільниць у даному ресурсному елементі, а `N_RE_mW` — потужність внутрішнього теплового шуму.

Тепловий шум приймача у смузі піднесного `Δf` розраховується за формулою Найквіста:

```
N_RE_mW = k · T · Δf · NF
```

Де:
- `k = 1.380649 · 10⁻²³ Дж/К` — константа Больцмана;
- `T = 290 К` — абсолютна температура (стандартна кімнатна);
- `Δf = 15000 Гц` — смуга піднесного;
- `NF` — коефіцієнт шуму малошумного підсилювача LNA (Noise Figure, у разах, наприклад `NF = 2.0` / `3 дБ`).

При `Δf = 15 кГц` шумова підкладка одного ресурсного елемента становить:

```
N_RE_mW = 1.380649 · 10⁻²³ · 290 · 15000 · 2.0 ≈ 1.201 · 10⁻¹⁶ Вт = -129.2 дБм
```

У практичних алгоритмах 3GPP SINR виводять із виміряних значень RSRQ за наближеною співвідносиною в умовах повного завантаження соти:

```
RSRQ_linear ≈ (1 / 12) · ( SINR_linear / (SINR_linear + 1) )
```

При високому SINR (`SINR >> 1`), `RSRQ_linear → 1/12` (`-10.8 дБ`). При низькому SINR (`SINR << 1`), `RSRQ_linear ≈ SINR / 12`, тобто `RSRQ_dB ≈ SINR_dB - 10.8 дБ`.

## Логарифмічна модель загасання сигналу з відстанню (Log-Distance Path Loss)

Для вирішення задач оцінки відстані за рівнем сигналу (RSSI/RSRP trilateration) застосовують емпіричну модель Log-Distance Path Loss:

```
PL(d)_dB = PL(d0)_dB + 10 · n · log10( d / d0 ) + X_sigma
```

Де:
- `d` — відстань між передавачем і приймачем (в метрах);
- `d0` — опорна відстань ближнього поля (зазвичай `d0 = 1 м`);
- `PL(d0)` — втрати на опорній відстані `1 м` (обчислюються за формулою Фріїса `PL(d0) = 20·log10(4·π·d0 / λ)`);
- `n` — показник загасання середовища (Path Loss Exponent): `n = 2.0` у вільному просторі, `n = 1.6…1.8` у хвилеводах коридорів, `n = 2.7…4.5` у міській забудові чи всередині приміщень;
- `X_sigma` — випадкова величина з нормальним розподілом `N(0, σ²)`, що описує повільні затінення (Shadow Fading, `σ = 4…12 дБ`).

Рівень виміряного RSSI на відстані `d` виражається через випромінювану потужність `P_tx_dBm`:

```
RSSI(d)_dBm = P_tx_dBm + G_tx_dBi + G_rx_dBi - PL(d)_dB
RSSI(d)_dBm = RSSI(1m)_dBm - 10 · n · log10( d )
```

Визначення відстані `d` за виміряним значенням RSSI:

```
10 · n · log10( d ) = RSSI(1m)_dBm - RSSI(d)_dBm                     [підстановка моделі затухання]
log10( d ) = ( RSSI(1m)_dBm - RSSI(d)_dBm ) / ( 10 · n )             [ділення обох частин на 10·n]
d = 10 ^ [ ( RSSI(1m)_dBm - RSSI(d)_dBm ) / ( 10 · n ) ]             [потенціювання: 10 в степені обох частин]
```

### Числовий приклад обчислення відстані:
Нехай виміряний рівень сигналу на відстані `1 м` дорівнює `RSSI(1m) = -40 дБм`. Поточний виміряний RSSI становить `RSSI(d) = -70 дБм`. Показник загасання в офісному приміщенні `n = 3.0`.

```
d = 10 ^ [ ( -40 - (-70) ) / ( 10 · 3.0 ) ]                          [підстановка значень RSSI та n]
  = 10 ^ [ 30 / 30 ]                                                 [обчислення різниці -40 - (-70) = 30]
  = 10 ^ 1                                                           [ділення 30/30 = 1]
  = 10 метрів                                                         [значення 10¹ = 10]
```

Якщо ж через тінь від стіни RSSI впаде до `-85 дБм`:

```
d = 10 ^ [ ( -40 - (-85) ) / 30 ]                                    [підстановка нового значення RSSI = -85 дБм]
  = 10 ^ [ 45 / 30 ]                                                 [обчислення різниці -40 - (-85) = 45]
  = 10 ^ 1.5                                                         [ділення 45/30 = 1.5]
  ≈ 31.62 метра                                                      [обчислення 10¹·⁵ ≈ 31.62]
```

Отже, помилка вимірювання RSSI на `15 дБ` через затінення призводить до триразової помилки в оцінці відстані, що ілюструє необхідність математичної фільтрації часових рядів RSSI/RSRP.

## Математична модель Layer 3 Filtering у 3GPP (TS 36.331)

У специфікації 3GPP TS 36.331 реалізовано цифрову фільтрацію RSRP та RSRQ для прийняття рішень про хендовер за рекурентною формулою:

```
F[n] = (1 - a) · F[n-1] + a · M[n]
```

Де:
- `M[n]` — останнє виміряне значення RSRP від фізичного рівня (Layer 1);
- `F[n]` — профільтроване значення RSRP для прийняття рішень на рівні RRC (Layer 3);
- `F[n-1]` — попередній стан фільтра (`F[0] = M[0]`);
- `a = 1 / 2^(k / 4)` — параметр коефіцієнта згладжування, де `k` задається базовою станцією в системній інформації (System Information Block, SIB).

Якщо `k = 4`, то `a = 1 / 2¹ = 0.5`. Якщо `k = 8`, то `a = 1 / 2² = 0.25`. Завдяки логарифмічній шкалі параметра `k`, оператор може гнучко налаштовувати постійну часу фільтра залежно від швидкості руху абонентів у даній соті.
