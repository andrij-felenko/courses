# ⚙️ Обчислення параметрів іоносферної траси: критична частота, MUF та мертва зона

Цей проєктний файл присвячено розробці практичного інженерного інструменту для автоматизованого розрахунку параметрів іоносферного радіозв'язку. Програма приймає на вхід виміряну або спрогнозовану електронну густину шару іоносфери `N_e`, його діючу висоту `h`, бажану відстань траси `D` та обрану частоту передавача `f_op`. На основі цих даних обчислюються критична частота зенітного зондування `f_c`, Максимум придатної частоти (`MUF`), Оптимальна робоча частота (`OWF`), а також відстань стрибка (`D_skip`) та наявність мертвої зони.

---

### Принцип роботи та математична модель

При розрахунку трас короткохвильового зв'язку обчислювальний модуль послідовно виконує чотири етапи розрахунку:

1. **Критична частота зенітного відбиття (`f_c`):**
   Критична частота визначається плазмовою частотою у точці максимуму електронної густини `N_e` (вираженої в електронах на кубічний метр):
   ```
   f_c_Hz = 8.98 · √(N_e)
   f_c_MHz = f_c_Hz / 10⁶
   ```

2. **Геометрія похилого променя та сферична корекція (`MUF`):**
   Для траси довжиною `D` на плоскій Землі кут падіння променя на шар висотою `h` становить `θ_flat = arctan(D / (2·h))`. Проте для реальної Землі радіуса `R_E = 6371 км` кривизна поверхні зменшує ефективний кут підйому променя. Сферичний кут падіння `θ_sph` визначається за формулою:
   ```
   sin(θ_sph) = sin(θ_flat) · (R_E / (R_E + h))
   cos(θ_sph) = √(1 - sin²(θ_sph))
   ```
   Коефіцієнт підйому частоти (`MUF-фактор`) дорівнює `k_sph = 1 / cos(θ_sph)`. Максимально придатна частота становить:
   ```
   MUF = f_c · k_sph
   ```

3. **Запас надійності та Оптимальна робоча частота (`OWF`):**
   Робота на граничній частоті `MUF` є ризикованою через постійні дрібномасштабні флуктуації електронної густини. Тому програма обчислює Оптимальну робочу частоту (`OWF / FOT`), яка забезпечує 85% від `MUF`:
   ```
   OWF = 0.85 · MUF
   ```

4. **Відстань стрибка (`D_skip`) та мертва зона:**
   Якщо обрана робоча частота передавача `f_op` лежить у межах `f_c < f_op ≤ MUF`, промені під крутими кутами пробивають іоносферу, а промені під пологішими кутами відбиваються. Найкоротша відстань, на яку повертається відбитий промінь, виражається через необхідний секанс `sec(θ_req) = f_op / f_c`:
   ```
   cos(θ_req) = f_c / f_op
   sin(θ_req) = √(1 - cos²(θ_req))
   tan(θ_req) = sin(θ_req) / cos(θ_req)
   D_skip = 2 · h · tan(θ_req)
   ```
   Якщо `f_op ≤ f_c`, відбиття відбувається під будь-яким кутом, і мертва зона відсутня (`D_skip = 0`). Якщо ж `f_op > MUF`, промінь вилітає у космос, і відбиття не відбувається взагалі.

### Детальний розбір реалізації мовами C та C++

Наведені реалізації демонструють ідіоматичний підхід до розробки обчислювальних модулів у сисадмінських та вбудованих системах:

#### Особливості реалізації мовою C

1. **Конструювання результату у стек-структурі `iono_path_result_t`:**
   Функція `calculate_iono_path` не використовує динамічного виділення пам'яті (`malloc`), що гарантує відсутність витоків пам'яті та критично важливо для вбудованих систем реального часу (RTOS). Результат повертається за значенням через регістри або стек.
2. **Безпека тригонометричних викликів:**
   При розрахунку `sin_theta_sph` введено явну перевірку `if (sin_theta_sph > 1.0) sin_theta_sph = 1.0;`. Це запобігає виклику `sqrt()` від від'ємного аргументу при крайніх значеннях кутів (захист від помилок обчислення з плаваючою крапкою `NaN`).
3. **Числовий прапор `is_reflected`:**
   У мові C стан відбиття кодується за допомогою цілочисельного прапора (1 або 0), що є стандартною практикою для C89/C99 кодів.

#### Особливості реалізації мовою C++

1. **Використання семантики `std::optional`:**
   Відстань стрибка `skip_distance_km` представлена типом `std::optional<double>`. Якщо частота вища за `MUF`, промінь физично не повертається на Землю, і концепція відстані стрибка втрачає сенс. Повернення `std::nullopt` явно кодує відсутність значення на рівні типів, виключаючи використання «магічних чисел» на зразок `-1.0`.
2. **Агрегатна ініціалізація C++20:**
   Структура `PathParams` ініціалізується за допомогою метаімен аргументів (`.electron_density_m3 = ...`), що робить виклик функції прозорим і самодокументованим.
3. **Обчислювальний клас без стану з гарантією `noexcept`:**
   Метод `IonosphereCalculator::compute` є статичним та позначений атрибутом `[[nodiscard]]` й гарантією `noexcept`. Це спонукає компілятор до виклику найефективніших інструкцій SIMD/FPU без генерації таблиць обробки винятків.

### Практичне використання для прогнозування проходження

Припустимо, аналітик радіолінії повинен оцінити придатність короткохвильових аматорських діапазонів для траси довжиною `D = 2000 км` при висоті шару F2 `h = 300 км`. 

За даними зондування вдень електронна густина становить `N_e = 1.2 · 10¹² ел/м³`. Розрахунок дає:
- Критична частота `f_c = 9.84 МГц`.
- `MUF-фактор` для траси 2000 км становить `3.48`.
- Максимальна придатна частота `MUF = 9.84 · 3.48 = 34.24 МГц`.
- Оптимальна робоча частота `OWF = 0.85 · 34.24 = 29.10 МГц`.

**Аналіз діапазонів:**
- **Діапазон 20 метрів (14.15 МГц):** Менше за `MUF` та вище за `f_c`. Відстань стрибка для цієї частоти становить `D_skip ≈ 820 км`. Сигнал упевнено накриває приймач на відстані 2000 км.
- **Діапазон 10 метрів (28.5 МГц):** Нижче за `MUF`, але вище за `OWF`. Проходження можливе, але відстань стрибка зростає до `D_skip ≈ 1750 км`.
- **Діапазон 6 метрів (50.1 МГц):** Перевищує `MUF` (50.1 > 34.24 МГц). Сигнал пробиває іоносферу й іде у космос — зв'язок відсутній.

### Оцінка зв'язку NVIS (Near Vertical Incidence Skywave)

Режим NVIS (близьковезинітне поширення просторової хвилі) є ключовою тактикою зв'язку у гірській місцевості або при відсутності супутникової інфраструктури (наприклад, під час ліквідації наслідків стихійних лих чи військових операцій).

При NVIS антена випромінює під кутами `θ_i = 0°..30°` вертикально вгору. Основна математична умова успішного NVIS-зв'язку полягає в тому, що робоча частота передавача повинна бути strictly нижчою за критичну частоту зеніту:

```
f_op < f_c(F2)
```

Завдяки цьому промінь відбивається прямо над передавачем і розсіюється куполом вниз, покриваючи «сліпу зону» радіусом від 0 до 500 км без жодної мертвої зони (`D_skip = 0`). Якщо вдень `f_c = 7.2 МГц`, то кращим діапазоном для NVIS є 5.3 МГц (60 метрів) або 7.0 МГц (40 метрів). Якщо уночі `f_c` падає до 3.8 МГц, необхідно перемикатися на 3.5 МГц (80 метрів) або 1.8 МГц (160 метрів).

### Багатострибкові траси (Multi-hop propagation)

Коли необхідна відстань зв'язку перевищує максимальну довжину одного стрибка через шар F2 (`D > 4000 км`), сигнал поширюється кількома послідовними стрибками за схемою «передавач → іоносфера → поверхня Землі/океану → іоносфера → приймач».

Для розрахунку `N`-стрибкової траси загальна відстань ділиться на кількість стрибків `D_hop = D / N`. Обчислювальний алгоритм перевіряє умову `f_op ≤ MUF(D_hop)` для кожного з відбиткових пунктів уздовж Великого кола Землі. При кожному проміжному відбитті від поверхні Землі додаються додаткові втрати на відбиття від ґрунту чи води (поблизу `3–6 дБ` на один відбивальний пункт), які повинні враховуватися у загальному бюджеті радіолінії.

### Інтеграція з рекомендаціями ITU-R P.533 та VOACAP

Промислові обчислювальні комплекси прогнозування короткохвильових трас (такі як VOACAP або стандарт ITU-R P.533) доповнюють наведену математичну модель кліматологічними картами іоносфери та розрахунком сумарних втрат:

1. **Розрахунок поглинання у шарі D:** Втрати поглинання визначаються за інтегралом напруженості сонячного випромінювання вздовж траєкторії і падають як `1 / (f + f_H)²`.
2. **Втрати на фокусування та геометрію:** Ураховують розмазування енергії по сфері та сферичне фокусування променів у відбивальних точках.
3. **Множник проходження (Reliability):** Обчислюється як ймовірність того, що відношення сигнал/шум (SNR) на приймальному кінці перевищить порогове значення для обраної модифікації (наприклад, SSB голосовий зв'язок або цифрова магістраль FT8).

### Інтеграція з потоками даних космічної погоди (NOAA SWPC)

Автоматизований сервер розрахунку MUF може отримувати геофізичні дані реального часу у форматі JSON із центрів моніторингу космічної погоди (наприклад, NOAA SWPC):

- `SFI` (Solar Flux Index — індекс сонячного випромінювання на довжині хвилі 10.7 см): вимірює рівень ультрафіолетової іонізації Сонця (діапазон 70–250). Вищий SFI означає вищу електронну густину `N_e` та зростання `f_c`.
- `Kp-індекс` (Планетарний індекс геомагнітної активності): оцінює збурення геомагнітного поля від 0 до 9. При `Kp ≥ 5` починається геомагнітна буря, яка розмиває шар F2 та викликає деградацію короткохвильового проходження.

Алгоритм використовує значення SFI для динамічного масштабування базисної електронної густини: `N_e(SFI) = N_e_base · (1 + 0.008 · (SFI - 70))`.

### Обчислення доплерівського зсуву та динаміки шару

Під час світанку та заходу Сонця висота відбивального шару F2 вертикально зміщується зі швидкістю `v_h = dh'/dt` (до `20–50 м/с`). 

Це викликає доплерівський зсув частоти прийнятого сигналу `Δf_Doppler`:

```
Δf_Doppler = -2 · (f_op / c) · (dh'/dt)
```

Для робочої частоти 14 МГц при швидкості опускання шару 30 м/с доплерівський зсув становить `Δf = -2 · (14·10⁶ / 3·10⁸) · 30 ≈ -2.8 Гц`. Обчислювальний калькулятор розширюється методом оцінки узгодженості фази для вузькосмугових цифрових мод зв'язку.

### Модульне юніт-тестування алгоритму

### Оцінка енергетичного бюджету траси з урахуванням іоносфери

Повний підрахунок втрат потужності на іоносферній трасі визначається підсумовуванням геометричного згасання та атмосферних факторів у децибелах:

```
L_total_dB = FSPL_dB + L_absorption_D + L_ground_reflection + L_polarization
```

1. **Геометричні втрати вільного простору (`FSPL`):** Обчислюються для повної довжини променя `S = 2 · √(h² + (D/2)²)`.
2. **Поглинання у шарі D (`L_absorption_D`):** Удень становить від `10` до `40 дБ` на частотах `3.5–7 МГц`, але падає до `1–3 дБ` на частотах `21–28 МГц`.
3. **Втрати відбиття від Землі (`L_ground_reflection`):** Для морської води становлять близько `0.5–1 дБ`, а для сухого ґрунту — від `3` до `6 дБ` за кожен проміжний стрибок.
4. **Поляризаційні втрати (`L_polarization`):** Унаслідок обертання Фарадея при невизначеній орієнтації приймальної антени середні втрати приймають на рівні `3 дБ`.

### Адаптивна зміна частот у системах радіозв'язку (ALE)

Сучасні цифрові короткохвильові системи зв'язку військового та спеціального призначення використовують технологію **ALE** (Automatic Link Establishment — автоматичне встановлення зв'язку, стандарти MIL-STD-188-141B та STANAG 4538). 

Пристрої ALE постійно сканують групу запрограмованих частотних каналів у діапазоні від 2 до 30 МГц, надсилаючи короткі зондувальні зонди-сигнали. Приймальні станції аналізують відношення сигнал/шум (SNR) та рівень багатопроменевих спотворень для кожного каналу, автоматично обираючи поточну частоту `OWF` для передачі даних без участі оператора.

### Сучасне застосування у розробці загоризонтних радарів (OTH Radar)

Обчислювальний алгоритм розрахунку `MUF` та траєкторії променя знаходить пряме застосування при розробці загоризонтних радіолокаційних станцій (Over-The-Horizon Radar, OTHR). 

Загоризонтні радари випромінюють потужні короткохвильові імпульси в напрямку іоносфери під малими кутами до горизонту. Промінь відбивається від шару F2, опромінює морські чи повітряні цілі на відстанях 1000–3500 км та повертається зворотним іоносферним шляхом до приймача. Алгоритм безперервно перераховує робочу частоту радара відповідно до поточних змін `foF2`, підтримуючи фокусировку променя на цільовому районі спостереження.

### Крайові випадки та обробка виняткових ситуацій

При обчисленні реальних трас виникають додаткові крайні фізичні ситуації, які обчислювальний модуль повинен обробляти без збоїв:

1. **Нічний режим (Низька електронна густина `N_e < 10¹¹ ел/м³`):**
   У нічний час при відсутності сонячної іонізації критична частота падає до `f_c ≈ 2–3 МГц`. У цьому випадку для високих короткохвильових діапазонів (14–28 МГц) умова `f_op ≤ MUF` не виконується, і калькулятор правильно повертає статус пробивання іоносфери (`std::nullopt`). Розрахунок показує необхідність переходу на нижчі діапазони (3.5–7 МГц).
2. **Граничні кути випромінювання та геометричний горизонт:**
   На великих відстанях (`D > 3000 км`) кут падіння променя на іоносферу прямує до горизонту (`θ_sph → 73°`). Програма затискає значення `sin_theta_sph` на рівні 1.0, що відсікає нефізичні розв'язки з від'ємними значеннями підкореневого виразу і забезпечує стійку роботу алгоритму при моделюванні гранично довгих однострибкових трас (до 4000 км).
