# 🧮 Аналітична кінематика 7-сегментного профілю S-кривої

У системах точного позиціювання неможливо обмежитися евристичним згладжуванням швидкості: системі потрібні точні аналітичні вирази для координати `s(t)`, швидкості `v(t)` та прискорення `a(t)` у будь-який момент часу. Без точного розв'язку диференціальних рівнянь руху з кусково-постійним ривком привід або перелітає цільову точку, або втрачає синхронізацію в багатоосьових верстатах. Нижче наведено виведення кінематичних рівнянь для всіх семи фаз траєкторії, критерії виродження профілю за обмеженого переміщення та розв'язання граничних задач для досяжних пікових швидкостей.

### Диференціальний базис кусково-постійного ривка

Рух матеріальної точки вздовж однієї осі описується ланцюгом інтегрування від ривка (англ. *jerk*) до координати положення:

```
da(t)/dt = j(t)
dv(t)/dt = a(t)
ds(t)/dt = v(t)
```

Коли на часовому відрізку `t ∈ [tₖ, tₖ + Δt]` ривок залишається незмінним (`j(t) = jₖ = const`), послідовне інтегрування за початкових умов фази `(sₖ, vₖ, aₖ)` на початку інтервалу дає аналітичні поліноми:

```
a(t) = aₖ + ∫ jₖ dt
     = aₖ + jₖ·Δt                                         [інтегрування ривка]

v(t) = vₖ + ∫ a(t) dt
     = vₖ + ∫ (aₖ + jₖ·t) dt
     = vₖ + aₖ·Δt + (1/2)·jₖ·Δt²                          [інтегрування прискорення]

s(t) = sₖ + ∫ v(t) dt
     = sₖ + ∫ (vₖ + aₖ·t + (1/2)·jₖ·t²) dt
     = sₖ + vₖ·Δt + (1/2)·aₖ·Δt² + (1/6)·jₖ·Δt³           [інтегрування швидкості]
```

Ці три рівняння становлять замкнений розв'язок для кожного окремого інтервалу. Завдання планувальника — розбити весь інтервал переміщення від початкового стану `(s₀, v₀)` до цільового `(s₁, v₁)` на сім послідовних сегментів і визначити точну тривалість кожного з них: `T₁` … `T₇`.

### Сім фаз класичної S-кривої

Повний симетричний профіль руху складається з ділянки розгону (фази I–III), ділянки рівномірного руху з крейсерською швидкістю (фаза IV) та ділянки гальмування (фази V–VII):

1. **Фаза I (наростання прискорення):** `j(t) = +j_max`, прискорення зростає від `0` до `+a_max`.
2. **Фаза II (постійне максимальне прискорення):** `j(t) = 0`, прискорення постійне `a(t) = +a_max`.
3. **Фаза III (спадання прискорення):** `j(t) = −j_max`, прискорення спадає від `+a_max` до `0`, швидкість досягає `v_max`.
4. **Фаза IV (крейсерський рух / cruise):** `j(t) = 0, a(t) = 0`, рух із постійною швидкістю `v(t) = v_max`.
5. **Фаза V (наростання гальмування):** `j(t) = −j_max`, прискорення спадає від `0` до `−a_max`.
6. **Фаза VI (постійне максимальне гальмування):** `j(t) = 0`, прискорення постійне `a(t) = −a_max`.
7. **Фаза VII (вихід на нульову швидкість у цілі):** `j(t) = +j_max`, прискорення зростає від `−a_max` до `0`.

Позначимо тривалості фаз розгону як `T_j1` (тривалість фаз I та III) і `T_a` (тривалість фази II). Для симетричного гальмування тривалості фаз V та VII позначимо як `T_j2`, а фази VI — як `T_d`. Тривалість крейсерської фази IV позначимо як `T_v`.

### Виведення тривалостей інтервалів для повного профілю

Розглянемо випадок розгону від початкової швидкості `v₀ = 0` до максимальної `v_max` з обмеженнями за прискоренням `a_max` та ривком `j_max`.

Час, необхідний для лінійного наростання прискорення від `0` до `a_max` у фазі I:

```
T_j1 = a_max / j_max                                      [час наростання прискорення]
```

Приріст швидкості за час фази I (`Δt = T_j1`, `a₀ = 0`):

```
Δv_I = (1/2)·j_max·T_j1²
     = (1/2)·j_max·(a_max / j_max)²
     = a_max² / (2·j_max)                                 [приріст швидкості у фазі I]
```

Оскільки фаза III симетрична за зміною швидкості (`j = −j_max`, спадання від `a_max` до `0`), приріст швидкості у фазі III дорівнює приросту у фазі I:

```
Δv_III = Δv_I = a_max² / (2·j_max)
```

Сумарна зміна швидкості за обидві фази зміни ривка (фази I та III):

```
Δv_jerk = Δv_I + Δv_III
        = a_max² / j_max                                  [зміна швидкості на ривках]
```

Решта приросту швидкості до `v_max` має бути набрана у фазі II з постійним максимальним прискоренням `a_max`:

```
Δv_II = (v_max − v₀) − Δv_jerk
      = (v_max − v₀) − a_max² / j_max
```

Звідси тривалість фази II постійного прискорення:

```
T_a = Δv_II / a_max
    = (v_max − v₀)/a_max − a_max / j_max                  [тривалість постійного прискорення]
```

Аналогічно для ділянки гальмування від `v_max` до кінцевої швидкості `v₁`:

```
T_j2 = a_max / j_max
T_d  = (v_max − v₁)/a_max − a_max / j_max                 [тривалість постійного гальмування]
```

### Обчислення переміщення на ділянках розгону та гальмування

Для визначення довжини крейсерської фази необхідно точно проінтегрувати шлях, пройдений на ділянках розгону (`S_acc`) та гальмування (`S_dec`).

Для ділянки розгону проінтегруємо зміну положення по фазах I, II, III:

```
s_I(T_j1)   = s₀ + v₀·T_j1 + (1/6)·j_max·T_j1³
v_I(T_j1)   = v₀ + (1/2)·j_max·T_j1²
a_I(T_j1)   = a_max

s_II(T_a)   = s_I(T_j1) + v_I(T_j1)·T_a + (1/2)·a_max·T_a²
v_II(T_a)   = v_I(T_j1) + a_max·T_a
a_II(T_a)   = a_max

s_III(T_j1) = s_II(T_a) + v_II(T_a)·T_j1 + (1/2)·a_max·T_j1² − (1/6)·j_max·T_j1³
```

Підставляючи вирази та враховуючи `j_max·T_j1 = a_max`, отримуємо компактну формулу для повного переміщення під час розгону:

```
S_acc = (v₀ + v_max)·T_acc / 2
      = (v₀ + v_max)·(2·T_j1 + T_a) / 2                   [шлях розгону через середню швидкість]
```

Завдяки симетрії параболічних ділянок середня швидкість на інтервалі розгону строго дорівнює `(v₀ + v_max) / 2`, що дає змогу виразити переміщення розгону й гальмування без громіздких кубічних многочленів:

```
S_acc = (1/2)·(v₀ + v_max)·(2·T_j1 + T_a)
S_dec = (1/2)·(v_max + v₁)·(2·T_j2 + T_d)
```

Загальне необхідне переміщення розгону та гальмування: `S_trans = S_acc + S_dec`.

Якщо повне задане переміщення `S = s₁ − s₀` перевищує `S_trans`, привід досягає повної швидкості `v_max`, і тривалість крейсерської фази IV становить:

```
T_v = (S − S_trans) / v_max                               [тривалість крейсерської фази]
```

### Виродження профілю: трикутні за прискоренням профілі (`T_a = 0`)

Якщо задана різниця швидкостей `(v_max − v₀)` замала, привід не встигає вийти на максимальне прискорення `a_max`. Умова існування фази постійного прискорення:

```
T_a > 0  ⟺  (v_max − v₀) > a_max² / j_max
```

Якщо `(v_max − v₀) ≤ a_max² / j_max`, прискорення сягає лише деякого пікового значення `a_peak < a_max`, після чого одразу починає спадати. Фаза II зникає (`T_a = 0`).

У цьому разі пікове прискорення `a_peak` та новий час фази ривка `T_j1` визначаються з рівняння набору швидкості:

```
Δv = 2·Δv_I
   = 2·[(1/2)·j_max·T_j1²]
   = j_max·T_j1²

T_j1 = √((v_max − v₀) / j_max)                             [скорочений час ривка]
a_peak = j_max·T_j1 = √((v_max − v₀)·j_max)                [досягнуте пікове прискорення]
```

Аналогічна перевірка виконується для фази гальмування: якщо `(v_max − v₁) ≤ a_max² / j_max`, то `T_d = 0`, `T_j2 = √((v_max − v₁) / j_max)`.

### Виродження профілю: короткі переміщення (`T_v = 0`)

Найскладніший випадок у плануванні траєкторії виникає тоді, коли загальна дистанція `S` менша за шлях, необхідний для виходу на бажану швидкість `v_max` (`S < S_trans`). Крейсерська фаза відсутня (`T_v = 0`), а профіль стає «трикутним» за швидкістю з невідомою піковою швидкістю `v_peak < v_max`.

Розглянемо випадок симетричних обмежень (`v₀ = 0, v₁ = 0, a_max, j_max`). Задача зводиться до пошуку `v_peak`, за якого сума шляхів розгону й гальмування в точності дорівнює заданій відстані `S`:

```
S = 2·S_acc(v_peak)
```

Тут можливі два підрежими:

#### 1. Пікове прискорення досягається (`a_peak = a_max`)

Якщо за шуканої `v_peak` умова `v_peak > a_max² / j_max` виконується, то `T_j = a_max / j_max`, а час розгону `T_acc = T_j + v_peak / a_max`. Підставляючи у вираз переміщення:

```
S = v_peak·(T_j + v_peak / a_max)
  = v_peak·(a_max / j_max) + v_peak² / a_max
```

Множимо обидві частини на `a_max` і отримуємо класичне квадратне рівняння відносно `v_peak`:

```
v_peak² + (a_max² / j_max)·v_peak − a_max·S = 0
```

Оскільки швидкість має бути додатного знаку, беремо єдиний фізичний додатний корінь:

```
D = (a_max² / j_max)² + 4·a_max·S
v_peak = [−(a_max² / j_max) + √(D)] / 2                     [пікова швидкість з виходом на a_max]
```

#### 2. Пікове прискорення НЕ досягається (`a_peak < a_max`)

Якщо переміщення `S` надзвичайно мале, привід не встигає розвинути навіть `a_max` (`T_a = 0, T_d = 0, T_v = 0`). Тоді профіль складається лише з чотирьох фаз зміни ривка: I, III, V, VII.

У цьому випадку:

```
T_j = ∛(S / (2·j_max))                                     [час чверть-фази ривка для мікропереміщення]
v_peak = j_max·T_j² = j_max·[S / (2·j_max)]^(2/3)
a_peak = j_max·T_j = j_max·∛(S / (2·j_max))
```

Перевірка межі між випадком 1 та 2 здійснюється через граничну відстань `S_limit`, за якої прискорення якраз досягає `a_max`:

```
S_limit = 2·a_max³ / j_max²                                [критична відстань виходу на a_max]
```

Якщо `S < S_limit`, застосовують формулу кубічного кореня з випадку 2. Якщо `S ≥ S_limit`, розв'язують квадратне рівняння випадку 1.

### Зведені формули для обчислення в реальному часі

Повний алгоритм аналітичного розрахунку інтервалів узагальнено в блок-схемі прийняття рішень:

```
1. Обчислити граничні перевірочні величини:
   T_j = a_max / j_max
   S_limit = 2·a_max³ / j_max²

2. Якщо S < S_limit (надкороткий рух):
   T_j1 = T_j2 = ∛(S / (2·j_max))
   T_a  = T_d = 0
   T_v  = 0

3. Інакше (S ≥ S_limit):
   Знайти v_peak з квадратного рівняння:
   v_peak = [−(a_max² / j_max) + √((a_max² / j_max)² + 4·a_max·S)] / 2
   
   Якщо v_peak < v_max:
      # Крейсерська фаза відсутня
      T_j1 = T_j2 = a_max / j_max
      T_a  = T_d = (v_peak − a_max² / j_max) / a_max
      T_v  = 0
   Інакше:
      # Повний 7-сегментний рух
      v_peak = v_max
      T_j1 = T_j2 = a_max / j_max
      T_a  = T_d = (v_max − a_max² / j_max) / a_max
      S_trans = v_max·(2·T_j1 + T_a)
      T_v  = (S − S_trans) / v_max
```

Ці формули гарантують аналітичну неперервність `s(t)`, `v(t)` та `a(t)` на всіх інтервалах, виключаючи появу нескінченного ривка та накопичення числової похибки позиціювання.
