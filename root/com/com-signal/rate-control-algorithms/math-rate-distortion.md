# 🧮 Теорія швидкості-спотворення та лагранжів множник

Теорія швидкості-спотворення (англ. *Rate-Distortion Theory*, започаткована Клодом Шенноном у 1948–1959 роках) дає фундаментальну математичну межу: яку мінімальну кількість бітів `R` необхідно витратити, щоб передати джерело сигналу із середнім спотворенням, що не перевищує заданого порогу `D`. У практичному відеокодуванні ця неперервна теорія перетворюється на дискретну задачу оптимізації: вибір режимів передбачення, векторів руху, структури розбиття блоків та кроків квантування так, щоб мінімізувати сумарну похибку за жорстко обмеженого бюджету каналу зв'язку.

### Функція швидкості-спотворення Шеннона

Для неперервного випадкового джерела `X` із густиною розподілу `p(x)` та відновленого сигналу `X̂` спотворення вимірюється функцією втрат `d(x, x̂)`. У цифровому відео стандартом є середньоквадратична похибка (MSE, англ. *Mean Squared Error*):

```
d(x, x̂) = (x − x̂)²
```

Функція швидкості-спотворення `R(D)` визначається як інфімум взаємної інформації `I(X; X̂)` за всіма можливими умовними розподілами відновлення `q(x̂|x)`, які задовольняють обмеження середнього спотворення:

```
R(D) = inf I(X; X̂)  за умови  E[d(X, X̂)] ≤ D
```

Для гаусового джерела з нульовим середнім і дисперсією `σ²` функція `R(D)` має точний аналітичний вигляд:

```
R(D) = 0.5 · log₂(σ² / D),   якщо 0 < D ≤ σ²
R(D) = 0,                    якщо D > σ²
```

Обернена функція спотворення-швидкості `D(R)` показує експоненційний спад похибки зі зростанням бітрейту:

```
D(R) = σ² · 2^(−2R)
```

Для залишків просторового та міжкадрового передбачення розподіл значень коефіцієнтів DCT значно точніше описується розподілом Лапласа (експоненційним розподілом із гострим піком у нулі та важкими хвостами) з густиною `p(x) = (1 / (√2 · σ)) · exp(−√2 · |x| / σ)`. Для лапласового джерела апроксимація Шеннона на середніх і високих бітрейтах набуває вигляду:

```
R(D) = 0.5 · log₂(e / (2 · π) · σ² / D) + 0.5 · log₂(2 · e)
D(R) = (e / π) · σ² · 2^(−2R)
```

Крива `R(D)` для будь-якого фізичного джерела є строго опуклою вниз монотонно спадною функцією. Це означає, що кожне наступне покращення якості (зменшення спотворення `D`) вимагає все більшої кількості бітів `R`.

### Лагранжева оптимізація компромісу

Кодування кадру складається з `N` макроблоків. Для кожного блоку `i` кодер має дискретну множину можливих режимів кодування `M[i]` (вибір інтра-напрямку, вектори руху, розбиття на підблоки 16×16, 8×8 чи 4×4, рівень квантування). Кожен режим `m ∈ M[i]` призводить до спотворення `D[i](m)` та вимагає кількості бітів `R[i](m)`.

Глобальна задача оптимізації формулюється як умовна мінімізація сумарного спотворення за обмеженого бюджету бітів `R_budget`:

```
min ∑ D[i](m[i])   за умови   ∑ R[i](m[i]) ≤ R_budget
```

Пряме розв'язання цієї комбінаторної задачі вимагало б повного перебору всіх комбінацій режимів для всіх блоків кадру, що обчислювально неможливо через експоненційну складність простору пошуку. За методом невизначених множників Лагранжа (англ. *Lagrangian Multiplier Method*) умовна оптимізація зводиться до безумовної мінімізації функції вартості `J`:

```
J(m, λ) = ∑ ( D[i](m[i]) + λ · R[i](m[i]) )
```

Оскільки блоки вважаються локально незалежними, глобальна сума розпадається на незалежні задачі оптимізації для кожного окремого блоку:

```
min J[i](m[i], λ) = min ( D[i](m[i]) + λ · R[i](m[i]) )   для кожного i ∈ [1..N]
```

Параметр `λ` (множник Лагранжа) відіграє роль обмінного курсу між бітами та якістю: він задає ціну одного витраченого біта в одиницях спотворення.

### Геометричний зміст та умова однакового нахилу

У точці оптимуму Лагранжа частинна похідна функції вартості за бітрейтом дорівнює нулю:

```
∂J / ∂R = 0
∂D / ∂R + λ = 0      [прирівнюємо похідну до нуля]
λ = − ∂D / ∂R        [множник Лагранжа є від'ємним нахилом дотичної до кривої R(D)]
```

Звідси випливає фундаментальна теорема оптимального розподілу бітів між блоками кадру: **у глобально оптимальному стані всі блоки повинні мати однаковий локальний нахил кривої спотворення-швидкості**:

```
λ₁ = λ₂ = ... = λ_N = − ∂D[i] / ∂R[i]
```

Якщо для одного блоку `A` нахил `|∂D_A / ∂R_A|` був би більшим, ніж для блоку `B`, ми могли б забрати `ΔR` бітів у блоку `B` (збільшивши його спотворення на незначну величину `λ_B · ΔR`) і віддати їх блоку `A` (зменшивши його спотворення на значно більшу величину `λ_A · ΔR`). Сумарне спотворення зменшилося б за незмінного загального бітрейту. Перерозподіл бітів досягає стійкої рівноваги, коли локальні нахили скрізь зрівнюються — це математичний принцип водяного рівня (англ. *water-filling*).

### Зв'язок множника λ з кроком квантування QP

У сучасних відеокодеках (H.264, H.265/HEVC, AV1) основним інструментом регулювання швидкості є параметр квантування `QP` (англ. *Quantization Parameter*), який визначає крок скалярного квантування `Qstep`. У стандарті H.264 крок квантування подвоюється на кожні 6 одиниць `QP`:

```
Qstep(QP) = 0.625 · 2^(QP / 6)
```

Для рівномірного квантувальника з кроком `Qstep` та рівномірним розподілом похибки в інтервалі `[−Qstep/2, +Qstep/2]` спотворення на один коефіцієнт описується дисперсією шуму квантування:

```
D = (Qstep)² / 12
```

Бітрейт `R` зв'язаний зі спотворенням логарифмічною залежністю високої швидкості (апроксимація Шеннона):

```
R ≈ 0.5 · log₂(σ² / D) = 0.5 · log₂(12 · σ² / (Qstep)²)
```

Знайдемо аналітичну похідну `∂D/∂R`:

```
D(R) = σ² · e^(−2 · ln(2) · R)
∂D / ∂R = −2 · ln(2) · D
```

Підставивши вираз для спотворення `D = (Qstep)² / 12`, отримуємо теоретичний зв'язок між множником Лагранжа та кроком квантування:

```
λ = − ∂D / ∂R = 2 · ln(2) · (Qstep)² / 12 ≈ 0.1155 · (Qstep)²
```

В емпіричних дослідженнях стандартизації H.264/AVC (роботи Томаса Віганда та Гісберта Блейтемана) з урахуванням ентропійного кодування CABAC та психовізуальних властивостей зору коефіцієнт був уточнений до практичних формул:

```
λ_MODE = 0.85 · 2^((QP − 12) / 3) = 0.85 · (Qstep)²
λ_MOTION = √λ_MODE = 0.92 · 2^((QP − 12) / 6)
```

Для оцінки векторів руху використовується `λ_MOTION`, оскільки при оцінці руху замість квадратичного MSE застосовують швидшу лінійну метрику SAD (суму абсолютних різниць, англ. *Sum of Absolute Differences*), яка масштабується лінійно від амплітуди сигналу.

### Оптимізоване квантування коефіцієнтів (RDOQ)

У класичному кодуванні квантування коефіцієнта DCT `c` є звичайною детермінованою операцією заокруглення: `k = round(c / Qstep)`. Проте з точки зору лагранжевої вартості коефіцієнт `k` не завжди є оптимальним.

Алгоритм RDOQ (англ. *Rate-Distortion Optimized Quantization*) для кожного коефіцієнта розглядає три кандидати: заокруглення вниз `k_down = floor(|c| / Qstep)`, заокруглення вгору `k_up = k_down + 1` та обнулення `k_zero = 0`. Для кожного варіанта обчислюється зміна вартості Лагранжа:

```
ΔJ = ΔD + λ · ΔR
```

де `ΔD = (c − k · Qstep)²` — квадратична похибка реконструкції конкретного коефіцієнта, а `ΔR` — точна кількість бітів, яку арифметичний кодер CABAC витратить на кодування цього рівня у структурі карти значущості (англ. *significance map*) та останнього ненульового коефіцієнта (англ. *last coefficient position*). Якщо обнулення коефіцієнта економить передачу цілого блоку синтаксису CABAC (прапорець `coded_block_flag = 0`), зменшення `λ · ΔR` часто значно переважає невелике зростання спотворення `ΔD`, що дає від 5% до 15% виграшу в бітрейті за тієї самої об'єктивної якості PSNR.

### Модель складності та розподілу бітів

Для узгодження між цільовим бітрейтом кадру `T_frame`, складністю зображення `X` та параметром `QP` у практичних регуляторах швидкості використовується гіперболічна модель:

```
R = X / Qstep
```

Тут `X` — внутрішня складність кадру, яка обчислюється як добуток фактично витрачених бітів на застосований крок квантування: `X = S_actual · Qstep`. Перед кодуванням майбутнього кадру його складність прогнозується на основі метрики просторово-часового руху SATD (сума абсолютних трансформованих за Адамаром різниць). Якщо рух у кадрі зростає, параметр `X` збільшується, сигналізуючи алгоритму про необхідність підвищити `QP` або виділити більшу частку з віртуального буфера VBV.
