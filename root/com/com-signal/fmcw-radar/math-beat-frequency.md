# 🧮 Виведення рівняння сигналу биття та фазового зсуву FMCW

Математичний апарат радіолокації неперервного випромінювання з лінійною частотною модуляцією (Linear Frequency Modulated Continuous Wave, FMCW) описує точний взаємозв'язок між параметрами випроміненого радіочастотного сигналу, геометричною затримкою відбиття та характеристиками низькочастотного сигналу на виході квадратурного змішувача. Це виведення встановлює аналітичні вирази для миттєвої частоти й фази коливань, розкриває механізм утворення сигналу биття, доводить формули роздільної здатності за відстанню, швидкістю та кутом, порівнює методи усунення зв'язку дальності й швидкості в пилкоподібній та трикутній модуляціях, аналізує просторову згортку у віртуальних антенних решітках MIMO та визначає фундаментальні межі однозначності вимірювань.

---

### 1. Аналітична модель випроміненого LFM-сигналу

Частотно-модульоване коливання задається функцією часу з миттєвою амплітудою `A_tx` та повною фазою `φ_tx(t)`:

```
s_tx(t) = A_tx · cos(φ_tx(t))
```

Миттєва частота сигналу `f(t)` за фізичним означенням є швидкістю зміни повної фази коливання, поділеною на `2·π`:

```
f(t) = (1 / (2·π)) · (dφ_tx(t) / dt)
```

У радіолокаторі з лінійною частотною модуляцією частота випромінювання змінюється від початкового значення `f₀` до максимального `f₀ + B` за час одного періоду модуляції (тривалість чірпа) `T_c`. Параметр `B` позначає смугу девіації частоти, а швидкість наростання частоти (крутизна частотного нахилу) `S` визначається відношенням:

```
S = B / T_c
```

Миттєва частота сигналу передавача на інтервалі `t ∈ [0, T_c]` змінюється за лінійним законом:

```
f_tx(t) = f₀ + S·t
```

Повна фаза коливання знаходиться інтегруванням миттєвої кутової швидкості `ω(t) = 2·π·f_tx(t)` за часом:

```
φ_tx(t)
= 2·π · ∫ (f₀ + S·u) du                     [інтегрування лінійної функції за часом від 0 до t]
= 2·π · (f₀·t + 0.5·S·t²) + φ₀              [первісна суми: інтеграл від сталої та лінійного доданка]
```

Тут `φ₀` — початкова фаза коливань генератора в момент `t = 0`. Доданок `π·S·t²` являє собою квадратичний фазовий набіг, характерний для лінійно-частотної модуляції.

---

### 2. Затримка поширення та рівняння відбитого сигналу

Електромагнітна хвиля поширюється у просторі зі швидкістю світла `c`. Якщо радіолокаційна ціль перебуває на радіальній відстані `R(t)` від трансивера і рухається з радіальною швидкістю `v`, її координата змінюється за законом:

```
R(t) = R₀ + v·t
```

Час подвійного проходження дистанції «радар — ціль — радар» позначається через `τ(t)`. З урахуванням руху цілі під час поширення сигналу затримка зв'язана з відстанню рівнянням:

```
τ(t) = 2 · R(t - τ(t)/2) / c ≈ 2 · (R₀ + v·t) / c
```

Оскільки радіальна швидкість цілей у практичних застосуваннях на багато порядків менша за швидкість світла (`v ≪ c`), затримка `τ` подається у вигляді суми постійної часової затримки `τ₀` та лінійної часової деформації:

```
τ(t) = τ₀ + (2·v / c)·t
де τ₀ = 2·R₀ / c
```

Відбитий сигнал `s_rx(t)` на вході приймальної антени є ослабленою та затриманою в часі копією випроміненого коливання:

```
s_rx(t) = A_rx · cos(φ_rx(t)) = A_rx · cos(φ_tx(t - τ(t)))
```

Повна фаза відбитого коливання записується підстановкою аргументу `(t - τ)` у вираз повної фази передавача:

```
φ_rx(t)
= φ_tx(t - τ)                               [підстановка затриманого часу у вираз повної фази]
= 2·π · (f₀·(t - τ) + 0.5·S·(t - τ)²) + φ₀  [розкриття квадратичного фазового виразу передавача]
```

### 3. Квадратурне гетеродинне перетворення та сигнал биття

У гомодинному FMCW-приймачі випромінений сигнал від генератора чірпів подається на опорний вхід квадратурного I/Q-змішувача, виконуючи роль сигналу гетеродина (Local Oscillator, LO). Відбитий сигнал з антени після малошумного підсилювача подається на радіочастотний вхід змішувача.

Комплексне подання сигналів на інтервалі сумісного існування:

```
s_lo(t) = exp(j · φ_tx(t))
s_rf(t) = exp(j · φ_rx(t))
```

Результат множення в змішувачі розкладається на низькочастотну різницеву та високочастотну сумарну складові:

```
s_lo(t) · s_rf*(t) = exp(j · (φ_tx(t) - φ_rx(t)))
```

Аналоговий фільтр проміжної частоти (ФНЧ) повністю пригнічує коливання з частотами порядку `2·f₀` (у міліметровому діапазоні це понад 150 ГГц). На виході тракту утворюється аналітичний комплексний сигнал биття (Beat Signal) `s_b(t)` з амплітудою `A_b`:

```
s_b(t) = A_b · exp(j · φ_b(t))
де φ_b(t) = φ_tx(t) - φ_rx(t)
```

Розгорнемо різницю фаз `φ_b(t)` за кроками:

```
φ_b(t)
= φ_tx(t) - φ_tx(t - τ)                      [різниця повної фази передавача та затриманого сигналу]
= 2·π·(f₀·t + 0.5·S·t²) - 2·π·(f₀·(t - τ) + 0.5·S·(t - τ)²)  [підстановка аналітичних виразів фази]
= 2·π·(f₀·τ + 0.5·S·(t² - (t - τ)²))        [групування доданків зі сталими f₀ та нахилом S]
= 2·π·(f₀·τ + 0.5·S·(2·t·τ - τ²))           [розкриття різниці квадратів: t² - (t² - 2tτ + τ²)]
= 2·π·(S·τ·t + f₀·τ - 0.5·S·τ²)             [зведення до канонічного вигляду лінійної фази]
```

Підставимо у фазовий вираз явну залежність затримки від часу для рухомої цілі `τ(t) = τ₀ + (2·v/c)·t`:

```
φ_b(t)
= 2·π · (S·(τ₀ + 2·v·t/c)·t + f₀·(τ₀ + 2·v·t/c) - 0.5·S·(τ₀ + 2·v·t/c)²)   [підстановка затримки рухомої цілі]
= 2·π · (S·τ₀·t + f₀·τ₀ + (2·v·f₀/c)·t + (2·v·S/c)·t² - 0.5·S·τ₀² - S·τ₀·(2·v/c)·t)  [розкриття добутків і квадратів]
```

Згрупуємо отримані доданки за степенями часу `t`:

1. Коефіцієнт при першому степені `t` визначає миттєву частоту сигналу биття `f_b`:
```
f_b
= S·τ₀ + (2·v·f₀ / c)                       [сума частоти дальності та доплерівського зсуву]
= (S · 2·R₀ / c) + (2·v / λ)                [перехід через довжину несучої хвилі λ = c / f₀]
```

Перший доданок `f_R = S · (2·R₀ / c) = (2·B·R₀) / (c·T_c)` обумовлений виключно відстанню до цілі. Другий доданок `f_d = 2·v / λ` є доплерівським зсувом частоти.

2. Вільний член фази (початковий зсув на початку чірпа при `t = 0`):
```
φ_const
= 2·π·f₀·τ₀ - π·S·τ₀²                       [початкова фаза сигналу биття]
= (4·π·R₀ / λ) - π·S·(2·R₀ / c)²            [підстановка τ₀ = 2R₀/c]
```

Оцінимо величину залишкового квадратичного члена `π·S·(2·R₀/c)²`. Для смуги `B = 4` ГГц, тривалості чірпа `T_c = 40` мкс (крутизна `S = 10¹⁴` Гц/с) та відстані `R₀ = 150` м затримка становить `τ₀ = 1` мкс. Тоді:

```
π · S · τ₀² = π · 10¹⁴ · (10⁻⁶)² = 0.0001 · π рад ≈ 0.018°
```

Ця величина є незначною і нею нехтують. Водночас перший член `4·π·R₀ / λ` є надзвичайно чутливим. Для довжини хвилі `λ = 3.9` мм (діапазон 77 ГГц) зміна відстані `R₀` всього на 1 мм спричиняє зміну фази на `4·π·10⁻³ / (3.9·10⁻³) ≈ 3.22` радіана (понад 184°).

3. Квадратичний член `(2·v·S/c)·t²` описує зміну частоти биття всередині одного чірпа через рух цілі. При швидкості автомобіля `v = 50` м/с (180 км/год) та `T_c = 40` мкс повний набіг частоти за час чірпа становить:

```
Δf_intra = 2 · v · S · T_c / c = 2 · 50 · 10¹⁴ · (40·10⁻⁶) / (3·10⁸) ≈ 1.33 Гц
```

Оскільки роздільна здатність за частотою за час одного чірпа становить `1 / T_c = 25` кГц, зміщенням на 1.33 Гц повністю нехтують, вважаючи сигнал биття гармонічним коливанням зі строго постійною частотою протягом одного чірпа:

```
s_b(t) ≈ A_b · exp(j · (2·π · (f_R + f_d)·t + (4·π·R₀ / λ)))
```

### 4. Зв'язок дальності й швидкості: трикутна модуляція проти пилкоподібної

В класичних повільних FMCW-радарах для розділення дальності `R` та швидкості `v` використовували симетричну трикутну модуляцію (Triangular FMCW), що складається з напівперіоду наростання частоти (Up-Chirp зі схилом `+S`) та напівперіоду спадання частоти (Down-Chirp зі схилом `-S`).

Для зростаючого схилу частота биття формується як різниця частоти дальності та доплерівського зсуву:

```
f_b_up = |f_R - f_d| = ((2·B·R) / (c·T_c)) - ((2·v) / λ)
```

Для спадного схилу знаки доданків однакові:

```
f_b_down = |f_R + f_d| = ((2·B·R) / (c·T_c)) + ((2·v) / λ)
```

Розв'язок системи двох лінійних рівнянь дозволяє знайти дальність та швидкість:

```
f_R
= 0.5 · (f_b_down + f_b_up)                 [півсума частот виділяє складову дальності]
= (2·B·R) / (c·T_c)                         [рівність частоті дальності за означенням]
```

```
f_d
= 0.5 · (f_b_down - f_b_up)                 [піврізниця частот виділяє доплерівську складову]
= 2·v / λ                                   [рівність доплерівському зсуву за означенням]
```

Звідки шукані параметри:

```
R = (c · T_c · (f_b_down + f_b_up)) / (4 · B)
v = (λ · (f_b_down - f_b_up)) / 4
```

#### Проблема хибних цілей (Ghost Targets)
Трикутна схема ідеально працює для однієї цілі. Якщо в зоні видимості присутні `K` цілей, на висхідному схилі з'являється `K` піків, і на низхідному — `K` піків. Оскільки відсутня інформація про те, який висхідний пік відповідає якому низхідному, кількість можливих пар становить `K²`. Це породжує `K·(K - 1)` хибних цілей-привидів (Ghost Targets), для усунення яких доводиться додавати третій напівперіод без модуляції (CW-сегмент) або змінювати крутизну нахилу в наступному циклі.

Саме через комбінаторну проблему привидів сучасні високопродуктивні радари повністю відмовилися від трикутної модуляції на користь послідовностей надшвидких пилкоподібних чірпів (Fast-Chirp FMCW) із двовимірним перетворенням Фур'є (2D-FFT).

### 5. Фазова еволюція в пачці чірпів (кадрі) та вимірювання швидкості

У парадигмі Fast-Chirp FMCW передається пачка з `N_chirp` однакових швидких чірпів з інтервалом повторення `T_r` (Chirp Repetition Interval, де `T_r ≥ T_c`).

Нехай індекс чірпа у кадрі позначається через `m ∈ [0, N_chirp - 1]`. Час початку `m`-го чірпа відлічується як `t_m = m · T_r`. Відстань до цілі на початку `m`-го чірпа становить:

```
R_m = R₀ + v · m · T_r
```

Сигнал биття на інтервалі `m`-го чірпа описується формулою, де внутрішньочірповий швидкий час позначено через `t_fast ∈ [0, T_c]`:

```
s_b(t_fast, m) = A_b · exp(j · (2·π·f_R·t_fast + φ_m))
```

Початкова фаза `φ_m` для `m`-го чірпа визначається відстанню `R_m`:

```
φ_m
= 4·π·R_m / λ                               [фазовий набіг сигналу на відстані R_m]
= 4·π·(R₀ + v·m·T_r) / λ                    [підстановка закону прямолінійного руху цілі]
= (4·π·R₀ / λ) + (4·π·v·T_r / λ) · m        [виділення постійної та лінійно залежної від m фази]
```

Зміна фази сигналу биття між двома сусідніми чірпами (`m` та `m + 1`):

```
Δφ_slow = φ_(m+1) - φ_m = (4·π · v · T_r) / λ
```

Знаючи різницю фаз `Δφ_slow`, радіальна швидкість обчислюється аналітично:

```
v = (λ · Δφ_slow) / (4·π · T_r)
```

#### Межа однозначності швидкості
Дискретне перетворення Фур'є за повільним часом (по індексу `m`) може однозначно визначити фазовий зсув лише в межах головного інтервалу без фазового переповнення (aliasing):

```
|Δφ_slow| < π
```

Підставивши вираз для `Δφ_slow`, отримуємо максимальну швидкість без однозначного перекриття:

```
(4·π · |v_max| · T_r) / λ = π
⇒ |v_max| = λ / (4 · T_r)
```

#### Роздільна здатність за швидкістю
Мінімальна помітна різниця доплерівських частот у спектрі за повільним часом обмежена загальною тривалістю спостереження кадру `T_frame = N_chirp · T_r`:

```
Δf_d = 1 / T_frame = 1 / (N_chirp · T_r)
```

Оскільки `f_d = 2·v / λ`, диференціювання дає роздільну здатність за радіальною швидкістю:

```
Δv = (λ / 2) · Δf_d = λ / (2 · N_chirp · T_r) = λ / (2 · T_frame)
```

### 6. Роздільність за відстанню та граничні параметри оцифрування

Дві точкові цілі з відстанями `R₁` та `R₂` створюють у сигналі биття дві спектральні складові з частотами `f_b1` та `f_b2`:

```
f_b1 = (2·B·R₁) / (c·T_c)
f_b2 = (2·B·R₂) / (c·T_c)
```

Різниця частот биття між цілями:

```
Δf_b = f_b2 - f_b1 = (2·B · (R₂ - R₁)) / (c · T_c) = (2·B · ΔR) / (c · T_c)
```

За критерієм Релея для дискретного перетворення Фур'є на часовому вікні спостереження тривалістю `T_c` два гармонічні піки є роздільними, якщо різниця їхніх частот перевищує ширину головної пелюстки спектра:

```
Δf_b ≥ 1 / T_c
```

Підставивши вираз для `Δf_b`:

```
(2·B · ΔR) / (c · T_c) ≥ 1 / T_c
⇒ ΔR = c / (2 · B)
```

Роздільна здатність за відстанню фундаментально визначається виключно смугою частотної модуляції `B` і не залежить від тривалості чірпа `T_c` чи несучої частоти `f₀`.

#### Вплив віконних функцій на реальну роздільність
У реальному спектральному аналізі для пригнічення бічних пелюсток (Spectral Leakage) сигнал множиться на вагове вікно `w(n)` (Ганнінга, Геммінга чи Блекмана). Зважування зменшує рівень бічних пелюсток від -13 дБ (прямокутне вікно) до -31 дБ (Ганнінг) або -58 дБ (Блекман), проте розширює головну пелюстку спектра на коефіцієнт еквівалентної шумової смуги `k_w`:

```
ΔR_real = k_w · (c / (2 · B))
```

Для прямокутного вікна `k_w = 1.0`, для вікна Ганнінга `k_w ≈ 1.44`, для вікна Блекмана `k_w ≈ 1.73`. Тобто придушення бічних пелюсток для виявлення слабких цілей поруч із потужними відбивачами оплачується розширенням смуги роздільності на 44–73%.

#### Максимальна вимірювана дальність
Максимальна частота биття `f_b_max`, яку може зареєструвати приймач, обмежена частотою зрізу аналогового ФНЧ та частотою дискретизації АЦП `f_s`. За теоремою Найквіста-Котельникова:

Для комплексного I/Q дискретизування: `f_b_max ≤ f_s`.
Для дійсного дискретизування (Real ADC): `f_b_max ≤ f_s / 2`.

Зв'язок максимальної дальності `R_max` із параметрами оцифрування:

```
f_b_max = (2·B·R_max) / (c·T_c) ≤ f_s / 2
⇒ R_max = (c · T_c · f_s) / (4 · B)          [для дійсного АЦП]
```

Для комплексного тракту I/Q:

```
R_max = (c · T_c · f_s) / (2 · B)          [для комплексного АЦП]
```

### 7. Просторова фаза, кутова пеленгація та віртуальні решітки MIMO

Розглянемо лінійну фазовану антенну решітку з `N_rx` приймальних елементів, розташованих уздовж однієї осі з кроком `d`. На решітку під кутом `θ` (відрахованим від нормалі до площини решітки) падає плоска електромагнітна хвиля від віддаленої цілі.

Різниця геометричного ходу хвилі до сусідніх приймальних антен становить:

```
Δl = d · sin(θ)
```

Додатковий час поширення сигналу між антенами:

```
Δτ_spatial = Δl / c = (d · sin(θ)) / c
```

Різниця фаз між сигналами, прийнятими двома сусідніми антенами:

```
Δφ_spatial
= 2·π · f₀ · Δτ_spatial                     [фазовий зсув на несучій частоті f₀]
= 2·π · f₀ · (d · sin(θ)) / c               [підстановка геометричної часової затримки]
= (2·π / λ) · d · sin(θ)                    [вираження через довжину хвилі λ = c / f₀]
```

Вимірявши просторовий фазовий зсув `Δφ_spatial`, кут приходу хвилі `θ` розраховується через обернену тригонометричну функцію:

```
θ = arcsin((λ · Δφ_spatial) / (2·π · d))
```

#### Просторовий аліасинг та вибір кроку решітки
Щоб уникнути неоднозначності кутового вимірювання (виникнення бічних дифракційних пелюсток у секторі `θ ∈ [-π/2, π/2]`), просторовий фазовий зсув повинен однозначно вкладатися в межі `[-π, π]`:

```
|Δφ_spatial| ≤ π
⇒ (2·π / λ) · d · |sin(θ)| ≤ π
```

Оскільки максимальне значення `|sin(θ)| = 1`, отримуємо класичну умову просторової теореми відліків:

```
d ≤ λ / 2
```

Якщо крок антен обрано рівним `d = λ / 2`, просторовий фазовий зсув спрощується до:

```
Δφ_spatial = π · sin(θ)
```

#### Кутова роздільна здатність
Дискретне просторове перетворення Фур'є по антенній решітці з `N_rx` елементів (Angle-FFT) має роздільну здатність за просторовою частотою `Δ(sin(θ)) = 1 / N_rx` (для `d = λ/2`). Кутова роздільна здатність `Δθ` поблизу нормалі (`θ ≈ 0`, де `cos(θ) ≈ 1`):

```
Δθ ≈ λ / (N_rx · d · cos(θ)) = 2 / (N_rx · cos(θ)) рад
```

#### Просторове згортання у MIMO-радарах (Virtual Array Synthesis)
Нехай передавальна решітка складається з `N_tx` антен із просторовими координатами `x_tx(i)`, а приймальна — з `N_rx` антен із координатами `x_rx(j)`. При одночасному або почерговому ортогональному випромінюванні сумарний фазовий набіг сигналу, випроміненого `i`-ю антеною і прийнятого `j`-ю антеною:

```
φ_mimo(i, j) = (2·π / λ) · (x_tx(i) + x_rx(j)) · sin(θ)
```

Координати елементів еквівалентної віртуальної решітки задаються просторовою згорткою (векторною сумою Мінковського) положень фізичних антен:

```
x_virt(i, j) = x_tx(i) + x_rx(j)
```

Якщо `N_rx` приймальних антен розміщені щільно з кроком `d = λ/2` (`x_rx = [0, d, 2d, ..., (N_rx - 1)·d]`), а `N_tx` передавальних антен рознесені на відстань `d_tx = N_rx · d`, то віртуальні приймачі утворюють суцільну рівновіддалену лінійну решітку (Uniform Linear Array, ULA) із `N_virt = N_tx · N_rx` елементів із загальною апертурою:

```
D_virt = (N_tx · N_rx - 1) · (λ / 2)
```

Це дозволяє досягти кутової роздільності великої фазованої решітки з мінімальною кількістю фізичних радіочастотних каналів на кристалі.

### 8. Числовий розрахунок параметрів автомобільного 77 ГГц радара

Розглянемо практичний приклад розрахунку мікрохвильового радара міліметрового діапазону з наступними параметрами:
* Несуча частота: `f₀ = 77` ГГц (довжина хвилі `λ = 3.896` мм).
* Смуга модуляції: `B = 1.5` ГГц (діапазон 77.0–78.5 ГГц).
* Тривалість активного чірпа: `T_c = 40` мкс (`40 · 10⁻⁶` с).
* Період повторення чірпів: `T_r = 50` мкс.
* Кількість чірпів у кадрі: `N_chirp = 128`.
* Частота дискретизації комплексного АЦП: `f_s = 12.5` МГц.
* Конфігурація антен: 3 передавачі (TX) та 4 приймачі (RX), `N_virt = 12`.

**1. Крутизна частотного нахилу:**
```
S = B / T_c = (1.5 · 10⁹) / (40 · 10⁻⁶) = 3.75 · 10¹³ Гц/с = 37.5 МГц/мкс
```

**2. Роздільна здатність за відстанню:**
```
ΔR = c / (2 · B) = (3 · 10⁸) / (2 · 1.5 · 10⁹) = 0.10 м = 10 см
```

**3. Максимальна вимірювана дальність (комплексний тракт):**
```
R_max = (c · T_c · f_s) / (2 · B) = (3 · 10⁸ · 40 · 10⁻⁶ · 12.5 · 10⁶) / (2 · 1.5 · 10⁹) = 50 м
```

**4. Максимальна однозначна радіальна швидкість:**
```
v_max = λ / (4 · T_r) = (3.896 · 10⁻³) / (4 · 50 · 10⁻⁶) = 19.48 м/с ≈ 70.1 км/год
```

**5. Роздільна здатність за радіальною швидкістю:**
```
T_frame = N_chirp · T_r = 128 · 50 · 10⁻⁶ = 6.4 мс
Δv = λ / (2 · T_frame) = (3.896 · 10⁻³) / (2 · 6.4 · 10⁻³) = 0.304 м/с ≈ 1.1 км/год
```

**6. Кутова роздільна здатність віртуальної решітки:**
```
Δθ ≈ 2 / N_virt = 2 / 12 = 0.167 рад ≈ 9.55°
```

**7. Частота биття та фазовий набіг для цілі на відстані `R = 30` м зі швидкістю `v = 15` м/с:**
```
f_R = S · (2·R / c) = 3.75 · 10¹³ · (60 / (3 · 10⁸)) = 7.5 МГц
f_d = 2 · v / λ = (2 · 15) / (3.896 · 10⁻³) = 7700 Гц = 7.7 кГц
f_b = f_R + f_d = 7.5077 МГц
Δφ_slow = (4·π · v · T_r) / λ = (4·π · 15 · 50 · 10⁻⁶) / (3.896 · 10⁻³) = 2.419 рад ≈ 138.6°
```

### 9. Нелінійність частотного нахилу та фазовий шум

У реальних генераторах, керованих напругою (VCO), характеристика перестроювання частоти має нелінійну залежність від напруги. Якщо нахил частоти змінюється в часі `f_tx(t) = f₀ + S·t + α·t²`, де `α` — квадратичний коефіцієнт нелінійності, фаза передавача містить кубічний доданок `φ_tx(t) = 2·π·(f₀·t + 0.5·S·t² + (α/3)·t³)`.

При відніманні затриманої фази сигнал биття отримує залежність частоти від швидкого часу всередині чірпа:

```
f_b(t) = S·τ₀ + 2·α·τ₀·t
```

Зміна частоти биття `Δf_chirp = 2·α·τ₀·T_c` призводить до розмиття спектрального піка після Range-FFT (дефокусування цілі), що погіршує еквівалентну роздільність за відстанню та знижує пікову амплітуду сигналу (SNR loss).

Для забезпечення ідеальної лінійності нахилу в сучасних мікросхемах радарів застосовують цифрові синтезатори із дробовими фазовими автопідстроюваннями частоти (Fractional-N PLL) або схеми прямого цифрового синтезу (DDS) із замкненим контуром корекції нахилу.

Фазовий шум гетеродина `S_φ(f)` у гомодинній схемі FMCW частково компенсується завдяки ефекту когерентного віднімання (Range Correlation Effect). Оскільки той самий генератор живить і передавач, і змішувач, фазові флуктуації з інтервалом кореляції, більшим за час затримки `τ₀`, взаємно знищуються в змішувачі. Фактор пригнічення фазового шуму описується передавальною функцією:

```
H_corr(f) = 4 · sin²(π · f · τ₀)
```

Для близьких цілей (`τ₀ ≪ 1` мкс) низькочастотний фазовий шум (1/f шум і шум флікера поблизу несучої) послаблюється пропорційно `(2·π·f·τ₀)²`, що дозволяє виявляти відбивачі з високою чутливістю навіть на недорогих інтегральних кремнієвих генераторах.
