# 🧮 Математика CIC-фільтра: передавальна характеристика та розростання бітів

Ця вставка містить строге аналітичне виведення передавальної функції та амплітудно-частотного відгуку каскаду інтеграторів-гребінок (*Cascaded Integrator-Comb*, CIC), математичне обґрунтування розташування нулів заглушення на кратних частотах децимації, формулу апроксимації спаду в смузі пропускання, розрахунок граничного підсилення на постійному струмі, а також алгебраїчне доведення теореми Гогенауера про збереження точності в кільці лишків `ℤ / 2^B ℤ` та правила усічення розрядності проміжних регістрів.

---

### 1. Передавальна функція каскаду ковзного середнього

Базовим елементом структури є незважений усереднювач прямокутного вікна довжиною `D = R · M`, де `R` — коефіцієнт децимації (*decimation factor*), а `M` — диференційна затримка гребінки (*differential delay*, найчастіше `M = 1` або `M = 2`).

Імпульсна характеристика одного такого блоку складається з `D` одиничних відліків: `h[n] = 1` для `0 ≤ n ≤ D - 1` та `h[n] = 0` для решти `n`.

Обчислимо Z-перетворення цієї послідовності як суму скінченної геометричної прогресії:

```
H_box(z) = ∑_{k=0}^{D-1} z^(-k)
         = 1 + z^(-1) + z^(-2) + ... + z^(-(D-1))      [розгортання скінченної суми]
         = (1 - z^(-D)) / (1 - z^(-1))                  [формула суми геометричної прогресії]
```

Для каскаду з `N` однакових послідовно з'єднаних ланок загальна передавальна функція дорівнює добутку передавальних функцій кожної окремої ланки:

```
H(z) = [H_box(z)]^N
     = [ (1 - z^(-D)) / (1 - z^(-1)) ]^N              [підстановка довжини D = R·M]
     = [ (1 - z^(-R·M)) / (1 - z^(-1)) ]^N            [канонічний вигляд передавальної функції]
```

Отримана функція розпадається на дві частини:
1. Знаменник `1 / (1 - z^(-1))^N` відповідає `N` каскадам рекурсивних цифрових інтеграторів.
2. Чисельник `(1 - z^(-R·M))^N` відповідає `N` каскадам диференціаторів (гребінкових фільтрів).

Полюс інтегратора `z = 1` точно скорочується з нулем гребінки в точці `z = 1`. Завдяки цьому система залишається фільтром зі скінченною імпульсною характеристикою (КІХ), хоча всередині містить рекурсивні накопичувачі.

### 2. Амплітудно-частотна характеристика та нулі Діріхле

Для переходу в частотну область підставимо комплексну змінну `z = e^(j·ω) = e^(j·2π·f / f_s)`, де `f_s` — висока вхідна частота дискретизації, а `ω = 2π·f / f_s` — нормована кругова частота:

```
H(e^(j·ω)) = [ (1 - e^(-j·ω·R·M)) / (1 - e^(-j·ω)) ]^N
```

Перетворимо чисельник і знаменник, винісши половинні фазові множники:

```
1 - e^(-j·θ) = e^(-j·θ/2) · (e^(j·θ/2) - e^(-j·θ/2))     [винесення спільного фазового зсуву]
             = e^(-j·θ/2) · 2j · sin(θ / 2)             [формула Ейлера для синуса]
```

Підставимо цей вираз окремо для чисельника з `θ = ω·R·M` та знаменника з `θ = ω`:

```
1 - e^(-j·ω·R·M) = e^(-j·ω·R·M / 2) · 2j · sin(ω·R·M / 2)   [перетворення чисельника]
1 - e^(-j·ω)     = e^(-j·ω / 2)     · 2j · sin(ω / 2)       [перетворення знаменника]
```

Ділимо чисельник на знаменник:

```
H(e^(j·ω)) = [ (e^(-j·ω·R·M / 2) · 2j · sin(ω·R·M / 2)) / (e^(-j·ω / 2) · 2j · sin(ω / 2)) ]^N
           = e^(-j·ω·N·(R·M - 1) / 2) · [ sin(ω·R·M / 2) / sin(ω / 2) ]^N   [скорочення 2j та групування фази]
```

Амплітудно-частотна характеристика (модуль передавальної функції) визначається ядром Діріхле в степені `N`:

```
|H(f)| = | sin(π · R · M · f / f_s) / sin(π · f / f_s) |^N
```

Фазочастотна характеристика є строго лінійною, з постійною груповою затримкою:

```
τ_g = N · (R · M - 1) / 2   [відліків високої частоти f_s]
```

#### Розташування нулів заглушення

Чисельник АЧХ перетворюється на нуль, коли аргумент синуса кратний `π`:

```
π · R · M · f_null / f_s = k · π,   де k ∈ ℤ
f_null = k · f_s / (R · M) = k · f_out / M
```

Якщо `k` не ділиться націло на `R·M`, знаменник `sin(π·f / f_s)` не дорівнює нулю. Отже, АЧХ має нулі кратності `N` на всіх частотах `f = k · f_s / (R·M)`.

Оскільки дециматор `↓R` складає всі частотні смуги довкола кратних `k · f_s / R` прямо в нульову корисну смугу, нулі `N`-го порядку CIC-фільтра розташовані саме там, де загроза аліасингу максимальна.

### 3. Тейлорівське наближення спаду в смузі пропускання

У корисній низькочастотній смузі (де `f ≪ f_s / (R·M)`) аргументи обох синусів є малими величинами. Скористаємося розкладом синуса в ряд Тейлора: `sin(x) = x - x³ / 6 + O(x⁵)`.

Розкладемо чисельник і знаменник амплітудної характеристики:

```
sin(π·R·M·f / f_s) ≈ (π·R·M·f / f_s) · [ 1 - (π·R·M·f / f_s)² / 6 ]
sin(π·f / f_s)     ≈ (π·f / f_s)     · [ 1 - (π·f / f_s)² / 6 ]
```

Поділивши один вираз на інший та скориставшись наближенням `1 / (1 - ε) ≈ 1 + ε`, отримуємо нормовану амплітуду однієї ланки:

```
|H_1(f)| / (R·M) ≈ [ 1 - (π·R·M·f / f_s)² / 6 ] · [ 1 + (π·f / f_s)² / 6 ]
                 ≈ 1 - (π² · f² / (6 · f_s²)) · [ (R·M)² - 1 ]
```

Для повного каскаду з `N` ланок, підносячи до степеня `N` за наближенням `(1 - δ)^N ≈ 1 - N·δ`:

```
|H(f)|_norm ≈ 1 - (N · π² / 6) · [ (R·M)² - 1 ] · (f / f_s)²
```

Оскільки вихідна частота дискретизації становить `f_out = f_s / R`, а `(R·M)² - 1 ≈ (R·M)²` для великих `R`, вираз набуває компактного практичного вигляду через відношення до вихідної частоти:

```
|H(f)|_norm ≈ 1 - (N · π² · M² / 6) · (f / f_out)²
```

Ця квадратична залежність показує, що спад у смузі пропускання залежить виключно від порядку `N`, затримки `M` та відносної частоти `f / f_out`, і абсолютно не залежить від коефіцієнта децимації `R`.

Переведемо спад у децибели (`20 · log₁₀(1 - x) ≈ -8.686 · x`):

```
ΔA(f) ≈ -8.686 · (N · π² · M² / 6) · (f / f_out)²
      ≈ -14.29 · N · M² · (f / f_out)²   [дБ]
```

Для `N = 4`, `M = 1` на частоті `f = 0.2 · f_out` (що відповідає приблизно 19.2 кГц при `f_out = 96 кГц`):

```
ΔA ≈ -14.29 · 4 · 1 · (0.2)² = -57.16 · 0.04 ≈ -2.28 дБ
```

Саме цей плавний спад у `-2.28 дБ` компенсує КІХ-фільтр другого ступеня децимації, піднімаючи край звукового діапазону інверсною передавальною характеристикою `1 / |H(f)|_norm`.

### 4. Підсилення на постійному струмі (DC Gain)

На частоті постійного струму `f = 0` (або `ω = 0`) маємо невизначеність типу `0 / 0`. Знайдемо границю за правилом Лопіталя:

```
lim_{f → 0} [ sin(π·R·M·f / f_s) / sin(π·f / f_s) ]
= lim_{f → 0} [ (π·R·M / f_s) · cos(π·R·M·f / f_s) ] / [ (π / f_s) · cos(π·f / f_s) ]   [диференціювання]
= (π·R·M / f_s) / (π / f_s)                                                              [підстановка f = 0]
= R · M                                                                                  [статичний коефіцієнт однієї ланки]
```

Для повного каскаду порядку `N` максимальний коефіцієнт підсилення становить:

```
G_max = (R · M)^N
```

Якщо на вхід подати постійний сигнал одиничної амплітуди `x[n] = 1`, вихідне значення після `N` каскадів у стаціонарному режимі досягне величини `(R · M)^N`.

### 5. Теорема Гогенауера про розростання розрядності (Bit Growth)

Якщо вхідний сигнал має розрядність `B_in` бітів (включаючи знаковий біт), то максимальний динамічний діапазон входу становить `2^(B_in)`.

З урахуванням максимального підсилення `G_max`, максимальний динамічний діапазон вихідного сигналу `D_out` не перевищує:

```
D_out = 2^(B_in - 1) · G_max
      = 2^(B_in - 1) · (R · M)^N
```

Кількість бітів `B_max`, необхідна для представлення вихідного сигналу без втрати точності й без спотворення динамічного діапазону, визначається логарифмом за основою 2:

```
B_max = ⌈ log₂(D_out / 2^(B_in - 1)) + B_in ⌉   [загальне правило розширення розрядності]
      = ⌈ B_in + log₂((R · M)^N) ⌉               [властивість логарифма добутку]
      = ⌈ B_in + N · log₂(R · M) ⌉               [теорема Гогенауера про розрядність]
```

### 6. Доведення коректності обчислень у кільці лишків ℤ / 2^B ℤ

Розглянемо, чому нескінченне накопичення в інтеграторах не призводить до спотворення результату на виході гребінок при використанні додаткового коду (*two's complement*).

Нехай усі змінні інтеграторів і диференціаторів мають фіксовану розрядність `B ≥ B_max` і арифметика виконується за модулем `2^B`.

Позначимо оператор накопичення інтегратора як `I(z) = 1 / (1 - z^(-1))`, а оператор гребінки як `C(z) = 1 - z^(-D)`.

У часовій області вихід одного інтегратора на кроці `n`:

```
s[n] = ( s[n-1] + x[n] ) mod 2^B = ( ∑_{i=0}^n x[i] ) mod 2^B
```

Вихід гребінки з затримкою `D = R·M` на кроці `n`:

```
y[n] = ( s[n] - s[n - D] ) mod 2^B
```

Підставимо вираз для `s[n]` та `s[n - D]`:

```
y[n] = [ ( ∑_{i=0}^n x[i] ) mod 2^B - ( ∑_{i=0}^{n - D} x[i] ) mod 2^B ] mod 2^B
     = [ ∑_{i=0}^n x[i] - ∑_{i=0}^{n - D} x[i] ] mod 2^B      [гомоморфізм кільця ℤ → ℤ/2^B ℤ]
     = ( ∑_{i=n - D + 1}^n x[i] ) mod 2^B                      [взаємне знищення спільних доданків]
```

Оскільки розрядність `B` обрано за теоремою Гогенауера такою, що максимальна можлива сума `|∑_{i=n - D + 1}^n x[i]| < 2^(B - 1)`, значення суми гарантовано не виходить за межі діапазону представлення чисел зі знаком у розрядності `B`.

Отже, взяття за модулем `2^B` є тотожним відображенням:

```
y[n] = ∑_{i=n - D + 1}^n x[i]   [строга рівність у звичайній цілочисельній арифметиці]
```

#### Числовий приклад самознищення переповнення в 8-бітному регістрі:

Розглянемо знаковий 8-бітний регістр (`B = 8`, діапазон `[-128, +127]`, модуль `2^8 = 256`), фільтр з `D = 4`. Нехай накопичувач через довгий потік одиниць переповнився:

```
Стан інтегратора 4 такти тому:   s[n-4] = 120
Поточний стан інтегратора:       s[n]   = (120 + 3 + 2 + 1 + 2) = 128 ≡ -128 (сталося переповнення)
Обчислення різниці в гребінці:   y[n]   = (s[n] - s[n-4]) mod 256
                                        = (-128 - 120) mod 256
                                        = -248 mod 256
                                        = +8
```

Справжня сума чотирьох нових відліків: `3 + 2 + 1 + 2 = 8`. Результат збігся абсолютно точно, попри те, що проміжне число перейшло через край розрядної сітки й змінило знак з плюса на мінус.

### 7. Правило оптимізації розрядності регістрів (Hogenauer Pruning)

В апаратних реалізаціях на FPGA або ASIC немає необхідності зберігати повну ширину `B_max` у всіх проміжних каскадах.

Гогенауер довів, що похибка відкидання молодших розрядів (*truncation/pruning*) у проміжних інтеграторах і гребінках не поширюється катастрофічно, а додає шум квантування, сумарна потужність якого може бути обмежена нижче рівня шуму квантування вихідного сигналу.

Якщо допустима загальна дисперсія похибки на виході становить `σ²_total = 2^(2·B_out) / 12`, то кількість молодших бітів `F_j`, які можна безпечно відкинути на `j`-му каскаді фільтра (`j = 1, ..., 2N`), визначається формулою:

```
B_j = ⌈ B_max - F_j ⌉
```

де `F_j` розраховується через імпульсну характеристику від `j`-го каскаду до виходу фільтра:

```
h_j[n] — імпульсний відгук від точки відкидання бітів до виходу системи
E_j = ∑_n (h_j[n])²   [підсилення дисперсії шуму від j-го каскаду]
```

Для перших каскадів інтеграторів підсилення шуму `E_j` є максимальним, тому перші каскади вимагають майже повної розрядності `B_max`. Натомість останні каскади гребінок мають малий коефіцієнт передачі шуму на вихід, що дозволяє зменшувати ширину їхніх регістрів на 2–6 бітів. У програмних реалізаціях на 32-розрядних мікроконтролерах усі регістри зазвичай залишають 32-бітними заради швидкодії, оскільки команди роботи з 32-бітними регістрами виконуються за один такт.
