# 🧮 Математична модель накопичення похибки при копіюванні

Ця вставка містить точний математичний вивід накопичення аддитивного шуму в лінійних аналогових каскадах, аналіз спектрального розширення детонацією, теорію 2D-перетворень та квантування у частотній області, доведення існування стабільного атрактора (ідемпотентності) для повторного стиснення, а також розрахунок метрик SSIM, маскування в аудіокодеках і нескінченного дрейфу похибки при зсуві сітки.

---

### 1. Аналоговий лінійний каскад: аналіз аддитивного шуму та формули Фрііса

Розглянемо послідовність із `N` ідентичних аналогових перетворювачів або каналів запису та відтворення (наприклад, каскад стрічкових магнітофонів, аналогових відеомагнітофонів чи радіорелейних підсилювальних станцій).

#### 1.1. Сумування потужності незалежних шумів

Позначимо вхідний корисний сигнал як `s₀(t)` з амплітудним значенням і середньоквадратичною потужністю `P_s = E[s₀²(t)]`.

Припустимо, що кожен `k`-й каскад додає власний незалежний аддитивний шум `n_k(t)` з однаковим середнім значенням `E[n_k(t)] = 0` та однаковою дисперсією (потужністю шуму) `P_n1 = σ_e²`. Коефіцієнт підсилення сигналу в кожному каскаді нормовано до одиниці (`A = 1`).

Сигнал на виході `N`-го покоління є випадковим процесом:

```
s_N(t) = s₀(t) + n₁(t) + n₂(t) + ... + n_N(t)
```

Обчислимо повну математичну потужність шуму `P_N` після `N` поколінь:

```
P_N = E[( ∑_{k=1}^N n_k(t) )²]
    = E[ ∑_{k=1}^N n_k²(t) + 2 · ∑_{1 ≤ i < j ≤ N} n_i(t) · n_j(t) ]
    = ∑_{k=1}^N E[n_k²(t)] + 2 · ∑_{1 ≤ i < j ≤ N} E[n_i(t) · n_j(t)]
```

Оскільки шумові процеси у різних носіях і підсилювачах є статистично незалежними, взаємна кореляція між ними дорівнює нулю: `E[n_i(t) · n_j(t)] = E[n_i(t)] · E[n_j(t)] = 0` при `i ≠ j`.

Тому сумарна потужність шуму лінійно зростає з числом поколінь:

```
P_N = ∑_{k=1}^N P_n1 = N · P_n1
```

#### 1.2. Розрахунок відношення сигнал/шум (SNR) у децибелах

Відношення сигнал/шум (`SNR`, *Signal-to-Noise Ratio*) після `N` поколінь у децибелах визначається як логарифм відношення потужності сигналу до сумарної потужності шуму:

```
SNR_N = 10 · log10( P_s / P_N )
      = 10 · log10( P_s / (N · P_n1) )
```

Застосуємо властивість логарифма частки `log10(A / B) = log10(A) - log10(B)`:

```
SNR_N = 10 · log10( P_s / P_n1 ) - 10 · log10( N )
      = SNR₁ - 10 · log10( N )
```

де `SNR₁ = 10 · log10(P_s / P_n1)` — це відношення сигнал/шум після першого копіювання.

З отриманої формули випливають важливі практичні закономірності:
- При першому подвоєнні поколінь (`N = 2`) `SNR₂ = SNR₁ - 10 · log10(2) ≈ SNR₁ - 3.01` дБ.
- При проведенні 4 поколінь (`N = 4`) втрата становить `10 · log10(4) ≈ 6.02` дБ (потужність шуму зростає вчетверо, амплітуда шуму подвоюється).
- При 10 поколіннях (`N = 10`) `SNR₁₀ = SNR₁ - 10` дБ (потужність шуму зростає ровно в 10 разів).

#### 1.3. Спектральне розширення від фазового тремтіння (Wow and Flutter)

Крім аддитивного шуму, механічний носій створює паразитна частотну модуляцію сигналу через детонацію швидкості обертання двигуна.

Нехай фазове тремтіння описується гармонійною детонацією з частотою `ω_m` та індексом модуляції `β`:

```
ϕ(t) = β · sin( ω_m · t )
```

Тоді однотоновий сигнал `s(t) = A · cos( ω₀ · t + ϕ(t) )` розкладається у ряд через функції Бесселя першого роду `J_k(β)`:

```
s(t) = A · ∑_{k=-∞}^{∞} J_k(β) · cos( (ω₀ + k · ω_m) · t )
```

На кожному поколінні аналогового перезапису індекс модуляції зростає `β_N = β · √N`, викликаючи швидке розростання бічних спектральних смуг `ω₀ ± k · ω_m` та розмиття чистого гармонічного піку в суцільну спектральну пляму.

### 2. Спектральна щільність потужності (PSD) каскадного шуму

Для глибшого аналізу розглянемо спектральну щільність потужності (`PSD`, *Power Spectral Density*) випадкового шуму `S_n(f)`.

У реальному аналоговому тракті шум не є чисто білим (із постійною `S_n(f) = N₀ / 2`). Через частотну характеристику підсилювача й намагніченості стрічки спектральна щільність має підйом на низьких і високих частотах (флікер-шум `1/f` та шум форми зазору голівки):

```
S_n(f) = N₀ / 2 + K_f / |f| + K_h · f²
```

Після `N` каскадів перезапису підсумкова спектральна щільність дорівнює:

```
S_N(f) = N · S_n(f) = N · ( N₀ / 2 + K_f / |f| + K_h · f² )
```

Інтегруючи `S_N(f)` по робочій смузі частот `[f_min, f_max]`, ми отримуємо повну потужність шуму `P_N`:

```
P_N = ∫_{f_min}^{f_max} S_N(f) df = N · ∫_{f_min}^{f_max} S_n(f) df
```

Це математично пояснює, чому при аналоговому копіюванні найшвидше піднімається саме високочастотна шумова полиця: доданок `K_h · f²` зростає пропорційно квадрату частоти `f²`, створюючи характерний високочастотний студійний свист (*tape hiss*).

### 3. Математична модель джиттеру клоку в ланцюгах ЦАП ↔ АЦП

При передачі сигналу крізь повторні аналогово-цифрові петлі (*Digital-to-Analog-to-Digital loops*) додатковим джерелом втрати якості є апаратний джиттер клоку генератора дискретизації `τ_n`.

Нехай момент вибірки `n`-го відліку дорівнює `t_n = n · T_s + τ_n`, де `τ_n` — випадкове значення з нормальним розподілом `N(0, σ_τ²)`.

Розкладемо значення дискретизованого сигналу `x(t_n)` у ряд Тейлора довкола ідеального моменту `n · T_s`:

```
x(t_n) = x(n · T_s + τ_n) ≈ x(n · T_s) + τ_n · x'(n · T_s)
```

Похибка джиттеру для одного відліку становить `e_j(n) = τ_n · x'(n · T_s)`.

Обчислимо дисперсію похибки джиттеру `σ_j²`:

```
σ_j² = E[e_j²] = E[τ_n²] · E[(x'(t))²] = σ_τ² · P_{x'}
```

Для гармонійного сигналу `x(t) = A · sin(2π · f₀ · t)` похідна дорівнює `x'(t) = 2π · f₀ · A · cos(2π · f₀ · t)`, а її потужність становить `P_{x'} = (2π · f₀)² · (A² / 2) = (2π · f₀)² · P_s`.

Звідси отримуємо відому формулу гранічного `SNR`, викликаного джиттером:

```
SNR_jitter = 10 · log10( P_s / σ_j² ) = 10 · log10( 1 / ( (2π · f₀)² · σ_τ² ) ) = -20 · log10( 2π · f₀ · σ_τ )
```

У ланцюгу з `N` послідовних ЦАП ↔ АЦП перетворень дисперсії джиттеру сумуються `σ_{τ,N}² = N · σ_τ²`. Внаслідок цього відношення сигнал/шум опускається за законом:

```
SNR_{jitter,N} = -20 · log10( 2π · f₀ · σ_τ · √N ) = SNR_{jitter,1} - 10 · log10( N )
```

Ця формула підтверджує, що для високочастотних сигналів (наприклад, `f₀ = 20` кГц) джиттер генератора в 1 наносекунду створює жорстку стелю якості `SNR ≤ 78` дБ, яка деградує з кожним повторним аналогово-цифровим перетворенням.

### 4. Дискретне двовимірне перетворення та похибка квантування

У цифрових графічних та відеокодеках (JPEG, MPEG, H.264) вхідний блок зображення `p[x,y]` розміром `8x8` пікселів піддається двовимірному дискретному косинусному перетворенню (2D-ДКТ):

```
X[u,v] = ( C(u) · C(v) / 4 ) · ∑_{x=0}^7 ∑_{y=0}^7 p[x,y] · cos( (2x + 1) · u · π / 16 ) · cos( (2y + 1) · v · π / 16 )
```

де `C(0) = 1 / √2`, а `C(w) = 1` для `w > 0`.

Матриця перетворення `T` є строго ортогональною, тобто зберігає векторну норму й енергію сигналу у відповідності до теореми Парсеваля.

#### 4.1. Рівномірний скалярний квантувач

Основне стиснення й основного джерела втрат інформації завдає оператор квантування `Q_q`. Для кожного частотного коефіцієнта `X[u,v]` із відповідним елементом матриці квантування `Q[u,v]` квантований індекс `k[u,v]` та відновлений коефіцієнт `X̂[u,v]` обчислюються як:

```
k[u,v] = round( X[u,v] / Q[u,v] )
X̂[u,v] = k[u,v] · Q[u,v] = round( X[u,v] / Q[u,v] ) · Q[u,v]
```

Похибка квантування для одного коефіцієнта визначається як різниця між відновленим та вхідним значенням:

```
e[u,v] = X̂[u,v] - X[u,v] = round( X[u,v] / Q[u,v] ) · Q[u,v] - X[u,v]
```

#### 4.2. Дисперсія похибки рівномірного квантувача

Припускаючи, що крок квантування `Q[u,v]` є малим порівняно з динамічним діапазоном сигналу, похибка `e` підпорядковується рівномірному розподілу ймовірностей на інтервалі `[-Q[u,v] / 2,  Q[u,v] / 2]`:

```
p(e) = 1 / Q[u,v]   при e ∈ [-Q/2, Q/2],  і  p(e) = 0 в інших точках.
```

Обчислимо математичне сподівання `E[e]` та дисперсію `σ_e²` похибки квантування:

```
E[e] = ∫_{-Q/2}^{Q/2} e · (1 / Q) de = 0      [симетрія інтервалу]

σ_e² = E[e²] = ∫_{-Q/2}^{Q/2} e² · (1 / Q) de
     = (1 / Q) · [ e³ / 3 ]_{-Q/2}^{Q/2}
     = (1 / Q) · ( (Q / 2)³ / 3 - (-Q / 2)³ / 3 )
     = (1 / Q) · ( Q³ / 24 + Q³ / 24 )
     = (1 / Q) · ( Q³ / 12 )
     = Q² / 12
```

Дисперсія похибки квантування одного коефіцієнта прямо пропорційна квадрату кроку квантування: `σ_e² = Q² / 12`.

### 5. Теорема про ідемпотентність і стабільний атрактор

Розглянемо повний оператор одного циклу стиснення й декодування `f(x) = D(E(x))`, де:
- `E(x) = round( (T · x) / Q )` — оператор кодування (перетворення у частотну область і квантування).
- `D(k) = T⁻¹ · (k · Q)` — оператор декодування (зворотне множення на крок `Q` та обернене перетворення `T⁻¹`).

Отже, вихідний відновлений вектор `x₁` після першого збереження дорівнює:

```
x₁ = f(x₀) = T⁻¹ · ( round( (T · x₀) / Q ) · Q )
```

#### 5.1. Доведення ідемпотентності для другого покоління

Підставимо відновлений вектор `x₁` у якості вхідного сигналу для другого циклу кодування й декодування `x₂ = f(x₁)`:

```
x₂ = f(x₁) = T⁻¹ · ( round( (T · x₁) / Q ) · Q )
```

Обчислимо частотний вектор `T · x₁` перед другим квантуванням:

```
T · x₁ = T · ( T⁻¹ · ( round( (T · x₀) / Q ) · Q ) )   [підстановка x₁ у формулу перетворення T · x]
       = (T · T⁻¹) · ( round( (T · x₀) / Q ) · Q )     [сполучна властивість множення матриць]
       = I · ( round( (T · x₀) / Q ) · Q )             [ортогональність ДКТ-матриці T · T⁻¹ = I]
       = round( (T · x₀) / Q ) · Q                     [властивість тотожної матриці I · A = A]
```

Тепер обчислимо нові квантовані коефіцієнти `k₂`:

```
k₂ = round( (T · x₁) / Q )                            [визначення квантованих індексів]
   = round( ( round( (T · x₀) / Q ) · Q ) / Q )        [підстановка розрахованого вектора T · x₁]
   = round( round( (T · x₀) / Q ) )                    [скорочення однакового множника й дільності Q / Q = 1]
```

Позначимо цілочисловий вектор індексів після першого збереження як `k₁ = round((T · x₀) / Q)`. Оскільки елементи вектора `k₁` за визначенням є цілими числами (`k₁ ∈ ℤ`), операція округлення цілого числа не змінює його значення: `round(k₁) = k₁`.

Звідси випливає:

```
k₂ = k₁
x₂ = T⁻¹ · ( k₂ · Q ) = T⁻¹ · ( k₁ · Q ) = x₁
```

#### 5.2. Наслідки існування атрактора

Ми довели, що для оператора `f` виконується рівність:

```
f(f(x₀)) = f(x₀)   або   fⁿ(x₀) = f(x₀)   для всіх n ≥ 1.
```

Властивість `f(f(x)) = f(x)` називається **ідемпотентністю оператора обробки**. Множина фіксованих точок `A = { x ∈ ℝᴹ | f(x) = x }` утворює **підпростір атрактора кодека**. 

Якщо структура сітки (розмір блоків), колірний простір, обчислювальна точність ДКТ та матриця квантування `Q` лишаються **абсолютно однаковими**, то перше кодування відображає довільний вектор `x₀` на дискретний атрактор `A`. Усі наступні `N` збережень дають **нульову додаткову похибку**:

```
e_N = x_N - x₁ = 0   при N ≥ 1.
```

### 6. Математична модель колірного дрейфу YUV ↔ RGB

При перетворенні колірних компонентів між простором `RGB` та `YUV` за стандартом ITU-R BT.601 застосовується пряма матриця перетворення `M`:

```
Y =  0.299 · R + 0.587 · G + 0.114 · B
U = -0.1687 · R - 0.3313 · G + 0.500 · B + 128
V =  0.500 · R - 0.4187 · G - 0.0813 · B + 128
```

Обернене перетворення здійснюється матрицею `M⁻¹`:

```
R = Y + 1.402 · (V - 128)
G = Y - 0.34414 · (U - 128) - 0.71414 · (V - 128)
B = Y + 1.772 · (U - 128)
```

Оскільки елементи матриць `M` та `M⁻¹` є дробовими числами, а координати пікселів у пам'яті мають 8-бітну цілочислову дискретність `[0...255]`, операція квантування `clamp(round(M⁻¹ · clamp(round(M · C))))` не є тотожним відображенням.

Дисперсія похибки округлення колірної матриці на кожен піксель становить `σ_color² ≈ 0.33` рівнів яскравості. Після `N` послідовних циклів `RGB ↔ YUV` сумарне відхилення кольору розширюється за законом:

```
ΔE_N = √ ( (R_N - R₀)² + (G_N - G₀)² + (B_N - B₀)² ) ≈ √ ( N · σ_color² )
```

Це доказує, що навіть без квантування ДКТ, саме лише повторне перетворення колірних просторів `RGB ↔ YUV420` на кожному збереженні викликає монотонне згасання насиченості кольорів зі швидкістю пропорційною `√N`.

### 7. Математична специфіка аудіокодеків (MDCT та Психоакустика)

В аудіокодеках MP3, AAC та Opus використовується модифіковане дискретне косинусне перетворення (MDCT), яке володіє властивістю скасування часового аліасингу (TDAC, *Time-Domain Aliasing Cancellation*).

Оператор перетворення MDCT розгортає вікно довжиною `2N` у `N` спектральних коефіцієнтів:

```
X[k] = ∑_{n=0}^{2N-1} x[n] · h[n] · cos( (π / N) · (n + 1/2 + N/2) · (k + 1/2) )
```

Квантування в аудіокодеках є нелінійним і спирається на степеневу функцію 3/4 для стиснення динамічного діапазону:

```
k[i] = sign(X[i]) · floor( ( |X[i]| / A[i] )^(3/4) + 0.4054 )
```

де `A[i]` — коефіцієнт маскування психоакустичної смуги.

Оскільки нелінійна функція `x^(3/4)` не є сумісною з цілочисловими матрицями ДКТ, повторне кодування аудіофайлу на кожній ітерації перераховує психоакустичні пороги маскування `A[i]`. Це створює нелінійну фазову неідемпотентність: фазовий кут `θ_k = arctan(Im / Re)` частотних банків зсувається, викликаючи дисперсійне «розмиття» фази та артефакти фленджера.

### 8. Аналіз згасання контрасту через просторову передавальну функцію (MTF)

Для опису просторового розмиття контрастних меж у Сценарії Б застосуємо передавальну функцію модуляції (`MTF`, *Modulation Transfer Function*).

Моделюватимемо зсув сітки квантування та міжблокову інтерполяцію як згортку двовимірного кадру `I(x,y)` із двовимірним гаусовим ядром розмиття `h(x,y)`:

```
h(x,y) = ( 1 / (2π · σ_b²) ) · exp( -(x² + y²) / (2 · σ_b²) )
```

Функція `MTF(f_x, f_y)` є двовимірним перетворенням Фур'є від імпульсної характеристики `h(x,y)`:

```
MTF(f_x, f_y) = | F{ h(x,y) } | = exp( -2π² · σ_b² · (f_x² + f_y²) )
```

Після `N` послідовних збережень із незбігом сітки передавальна функція каскаду `MTF_N` описується як добуток окремих передавальних функцій:

```
MTF_N(f_x, f_y) = ∏_{k=1}^N MTF_k(f_x, f_y) = [ MTF₁(f_x, f_y) ]^N = exp( -2π² · (N · σ_b²) · (f_x² + f_y²) )
```

Отриманий результат підтверджує, що ефективний радіус розмиття контрастних меж зростає пропорційно `σ_N = σ_b · √N`. Високі просторові частоти `f_x, f_y > 1 / (2π · σ_b · √N)` експоненційно згасають до нуля, перетворюючи різкий чорно-білий текст чи дрібну текстуру на суцільне сіре поле.

### 9. Порушення ідемпотентності та метрики SSIM і PSNR

Якщо між декодуванням `D` і наступним кодуванням `E` виконується операція зсуву сітки `S_Δ` (зсув кадру на `Δx` пікселів), матриці перетворення не комутують: `T · S_Δ · T⁻¹ ≠ I`.

Внаслідок міжблокового перекресного змішування `α ∈ (0, 1]`, на кожному `N`-му збереженні додається нова дисперсія похибки `σ_e² = Q² / 12`:

```
σ_N² = σ₁² + (N - 1) · α · (Q² / 12)
```

#### 9.1. Метрика структурної подібності (SSIM)

Індекс структурної подібності (`SSIM`, *Structural Similarity Index*) між вихідним блоком `x` та копією `y` обчислюється через математичне сподівання `μ`, дисперсію `σ²` та коваріацію `σ_xy`:

```
SSIM(x,y) = [ (2 · μ_x · μ_y + C₁) · (2 · σ_xy + C₂) ] / [ (μ_x² + μ_y² + C₁) · (σ_x² + σ_y² + C₂) ]
```

При каскадному накопиченні похибки квантування `σ_y² = σ_x² + (N-1) · α · σ_e²`, а коваріація спадає за законом `σ_xy = σ_x² · exp( -(N-1) · γ )`. 

Підстановка цих виразів доказує, що `SSIM_N` монотонно прямує до нуля при `N → ∞`, що описує повну втрату впізнаваності геометричних структур зображення при тривалому перекодуванні зі зсувом.

#### 9.2. Непорушність нерівності обробки даних (Data Processing Inequality)

Застосуємо теорему теорії інформації про нерівність обробки даних для марковського ланцюга `X₀ → X₁ → X₂ → ... → X_N`.

Взаємна інформація `I(X₀; X_N)` між оригіналом `X₀` та копією `N`-го покоління `X_N` описується суворою монотонною нерівністю:

```
I(X₀; X₀) ≥ I(X₀; X₁) ≥ I(X₀; X₂) ≥ ... ≥ I(X₀; X_N)
```

Для детермінованих безвтратних перетворень `I(X₀; X_k) = H(X₀)`. Проте для будь-якого квантувача або аддитивного шуму утворюється сувора нерівність `I(X₀; X_k) < I(X₀; X_{k-1})`. 

Це фундаментально доказує, що жоден подальший алгоритм обробки, підсилення чи фільтрації не спроможний відновити втрачені біти взаємної інформації `I(X₀; X_N)` після `N` поколінь, підтверджуючи непорушність другого закону термодинаміки для інформаційних потоків.
