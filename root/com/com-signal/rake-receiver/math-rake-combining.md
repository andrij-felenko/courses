# 🧮 Математика оптимального додавання пальців RAKE: MRC, EGC та SC

Ця вставка містить точний математичний вивід оптимальних вагових коефіцієнтів для об'єднання сигналів у пальцях RAKE-приймача. Вона пояснює, чому метод додавання з максимальним відношенням (Maximum Ratio Combining, MRC) є строго оптимальним з точки зору максимізації вихідного співвідношення сигнал/шум (SNR), та порівнює його з простішими альтернативами — додаванням з однаковим підсиленням (EGC) та селективним вибором (SC).

---

### 1. Модель багатопроменевого каналу та дерозширення

Розглянемо комплексний аналітичний сигнал на вході RAKE-приймача, який пройшов крізь багатопроменевий канал із `L` вимірними шляхами (променями). Кожен `k`-й промінь характеризується загасанням `a_k`, фазовим зсувом `θ_k` та часовою затримкою `τ_k`.

Імпульсна характеристика такого каналу записується сумою зсунутих дельта-функцій з комплексними коефіцієнтами передачі:

```
h(t) = ∑_{k=0}^{L-1} a_k · e^(j·θ_k) · δ(t - τ_k)
```

Вхідний комплексний сигнал приймача `r(t)` є згорткою переданого широкосмугового сигналу `s(t)` із каналом `h(t)` плюс адитивний білий гаусів шум `n(t)` з двосторонньою спектральною щільністю потужності `N_0 / 2`:

```
r(t) = s(t) ⁕ h(t) + n(t)
     = ∑_{k=0}^{L-1} a_k · e^(j·θ_k) · s(t - τ_k) + n(t)
```

Переданий сигнал `s(t)` у системі з прямим розширенням спектра (DSSS) має вигляд:

```
s(t) = A · d_0 · c(t)
```

де `A` — амплітуда сигналу, `d_0 ∈ {+1, -1}` — переданий інформаційний біт тривалістю `T_s` та енергією `E_b = A² · T_s`, а `c(t)` — псевдовипадкова послідовність (ПСП) із частотою чипів `f_c = 1 / T_c`.

Кожен `m`-й палець RAKE-приймача налаштований на затримку `τ_m` і виконує дерозширення — множить вхідний сигнал на зсунуту спряжену послідовність `c*(t - τ_m)` та інтегрує за інтервал символу `T_s`:

```
y_m = (1 / T_s) · ∫₀^{T_s} r(t) · c*(t - τ_m) dt
```

Підставивши вираз для `r(t)` у вирази інтеграла та скориставшись нормувальною властивістю автокореляції ПСП `R_c(Δτ) = 1` при `Δτ = 0` та `R_c(Δτ) ≈ 0` при `|Δτ| ≥ T_c`, отримуємо вихідний відлік `m`-го пальця:

```
y_m = a_m · e^(j·θ_m) · d_0 + n_m'
```

де `n_m'` — опрацьований шумовий відлік на виході `m`-го корелятора з нульовим математичним сподіванням та дисперсією `σ_n² = N_0 / (2 · T_s)`.

Оскільки затримки різних пальців задовольняють умову `|τ_m - τ_k| ≥ T_c`, шумові складові `n_m'` та `n_k'` на виходах різних пальців є некорельованими гаусовими випадковими величинами.

### 2. Максимізація SNR та строгий вивід MRC (Maximum Ratio Combining)

Сумарний вихідний сигнал RAKE-приймача `Y` утворюється як зважена лінійна комбінація виходів усіх `L` пальців з комплексними ваговими коефіцієнтами `w_m`:

```
Y = ∑_{m=0}^{L-1} w_m · y_m
  = d_0 · (∑_{m=0}^{L-1} w_m · a_m · e^(j·θ_m)) + ∑_{m=0}^{L-1} w_m · n_m'
```

Позначимо вектор комплексних амплітуд каналу як `h = [a_0·e^(j·θ_0), a_1·e^(j·θ_1), ..., a_{L-1}·e^(j·θ_{L-1})]^T`, а вектор вагових коефіцієнтів як `w = [w_0, w_1, ..., w_{L-1}]^T`.

Потужність корисної сигнальної складової на виході суматора дорівнює квадрирату модуля скалярного добутку:

```
P_signal = |w^T · h|² · E_b
```

Потужність шумів на виході суматора (за умови некорельованості шуму в пальцях):

```
P_noise = ||w||² · N_0 = (∑_{m=0}^{L-1} |w_m|²) · N_0
```

Миттєве співвідношення сигнал/шум (SNR) на виході суматора має вигляд:

```
γ_out = P_signal / P_noise
      = (|∑_{m=0}^{L-1} w_m · h_m|²) · E_b / ((∑_{m=0}^{L-1} |w_m|²) · N_0)
```

Щоб знайти вектор ваг `w`, який максимізує `γ_out`, застосуємо **нерівність Коші–Буняковського–Шварца** для векторів `w` та `h` у комплексному Гільбертовому просторі:

```
|w^T · h|² ≤ ||w||² · ||h||²
```

де `||h||² = ∑_{m=0}^{L-1} |h_m|² = ∑_{m=0}^{L-1} a_m²`.

Рівність досягається тоді й лише тоді, коли вектор ваг `w` є строго пропорційним комплексно-спряженому вектору каналу `h*`:

```
w_m = C · h_m* = C · a_m · e^(-j·θ_m)      [умова оптимальності MRC]
```

де `C` — довільна позитивна масштабувальна константа (без втрати загальності можна покласти `C = 1`).

Підставивши оптимальні ваги `w_m = a_m · e^(-j·θ_m)` у формулу вихідного SNR, отримуємо покроковий вивід:

```
γ_MRC
= ((∑_{m=0}^{L-1} a_m²)²) · E_b / ((∑_{m=0}^{L-1} a_m²) · N_0)   [підстановка оптимальних ваг w_m = h_m*]
= (∑_{m=0}^{L-1} a_m²) · (E_b / N_0)                           [скорочення сумарної амплітуди ∑ a_m²]
= ∑_{m=0}^{L-1} γ_m                                             [підстановка визначення SNR m-го пальця]
```

де `γ_m = a_m² · (E_b / N_0)` — миттєве співвідношення сигнал/шум у `m`-му пальці.

**Головний математичний висновок MRC:** Результуюче співвідношення сигнал/шум при MRC-об'єднанні дорівнює **прямій арифметичній сумі SNR усіх окремих пальців**. Це гарантує нульову втрату енергії та абсолютну оптимізацію якості прийому.

### 3. Додавання з однаковим підсиленням (Equal Gain Combining, EGC)

У ситуаціях, коли вимірювання амплітуд каналу `a_m` є неточим або апаратно занадто дорогим, застосовують простіший метод вирівнювання лише фаз — EGC. Ваговий коефіцієнт у цьому випадку має одиничну амплітуду:

```
w_m = e^(-j·θ_m)
```

Сумарний вихідний сигнал EGC-суматора дорівнює:

```
Y_EGC = d_0 · (∑_{m=0}^{L-1} a_m) + ∑_{m=0}^{L-1} e^(-j·θ_m) · n_m'
```

Вихідне співвідношення сигнал/шум для EGC обчислюється як:

```
γ_EGC = (∑_{m=0}^{L-1} a_m)² · E_b / (L · N_0)
```

**Аналітичне порівняння MRC та EGC:** 
Оскільки за нерівністю про середнє квадратичне та середнє арифметичне:

```
(∑_{m=0}^{L-1} a_m)² ≤ L · (∑_{m=0}^{L-1} a_m²)
```

то `γ_EGC ≤ γ_MRC`. Рівність досягається лише в ідеальному випадку, коли всі промені мають строго однакові амплітуди `a_0 = a_1 = ... = a_{L-1}`. У реальному каналі з флуктуаціями амплітуд EGC втрачає від 0.5 до 1.5 дБ порівняно з MRC, оскільки надає однакову вагу як сильним, так і дуже слабким зашумленим променям.

---

### 4. Селективне додавання (Selection Combining, SC)

Найпростіший підхід полягає у виборі лише одного пальця з найбільшим рівнем сигналу та відключенні всіх інших:

```
m* = argmax_{m} (a_m)

w_m = e^(-j·θ_m)  при m = m*
w_m = 0           при m ≠ m*
```

Вихідне SNR для SC дорівнює максимальному значення серед усіх пальців:

```
γ_SC = max_{m} (γ_m) = (a_{m*}²) · (E_b / N_0)
```

---

### 5. Аналіз чутливості MRC до похибок оцінювання каналу

На практиці оцінка каналу `h_hat_m` відрізняється від істинного значення `h_m` через наявність шуму в пілотних символах. Припустимо, що оцінювач фази має похибку `Δθ_m = θ_hat_m - θ_m`.

Тоді вихідний сигнал MRC-суматора набуває вигляду:

```
Y_imperfect = d_0 · ∑_{m=0}^{L-1} a_m² · cos(Δθ_m) + n_eff
```

Якщо фазова похибка розподілена за нормальним законом `N(0, σ_θ²)`, середнє зменшення корисної потужності сигналу виражається множником:

```
Loss_dB = -10 · log10( E[cos(Δθ)]² ) ≈ 4.34 · σ_θ²  [дБ]
```

Це означає, що для збереження переваг MRC похибка фазової синхронізації у пальцях не повинна перевищувати `σ_θ < 15°` (0.26 радіан), інакше втрати перевищать 0.3 дБ.

### 6. Ймовірність помилки (BER) у каналі з Релеєвськими завмираннями

У каналах із незалежними Релеєвськими завмираннями амплітуди `a_m` є випадковими величинами з Релеєвським розподілом. Ймовірність бітової помилки для BPSK із `L` променями при MRC-об'єднанні виражається точною інтегральною формулою:

```
P_b(L) = [ (1 - μ) / 2 ]^L · ∑_{k=0}^{L-1} (L - 1 + k choose k) · [ (1 + μ) / 2 ]^k
```

де параметр `μ` визначається середнім SNR на один промінь `γ_avg`:

```
μ = √( γ_avg / (1 + γ_avg) )
```

При великому SNR (`γ_avg >> 1`) ймовірність помилки спадає як зворотно пропорційна `L`-му степеню SNR:

```
P_b(L) ≈ ( (2L - 1 choose L) / (4 · γ_avg)^L )
```

Це показує фундаментальну перевагу RAKE-приймача: замість повільного лінійного спадання помилки у звичайному Релеєвському каналі `P_b ∝ 1 / γ_avg`, RAKE із `L` пальцями забезпечує **поліноміальний порядок рознесення `L`**, наближаючи надійність мобільного зв'язку до надійності проводового каналу AWGN.

---

### 7. Підсумкова порівняльна таблиця методів

| Метод об'єднання | Формула ваги `w_m` | Результуюче SNR `γ_out` | Необхідна інформація | Програш відносно MRC | Порядок рознесення |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **MRC** (Maximum Ratio) | `a_m · e^(-j·θ_m)` | `∑ γ_m` | Амплітуда `a_m` та фаза `θ_m` | **0 дБ (Строгий оптимум)** | Повний `L` |
| **EGC** (Equal Gain) | `e^(-j·θ_m)` | `(∑ a_m)² · E_b / (L·N_0)` | Лише фаза `θ_m` | ~0.5 – 1.2 дБ | Повний `L` |
| **SC** (Selection) | `1` для max `a_m`, `0` для інших | `max(γ_m)` | Лише амплітуда `a_m` | ~2.0 – 4.5 дБ | Залежить від порівняння |

Завдяки максимізації SNR метод **MRC** є математичним стандартом для RAKE-приймачів у системах 3G WCDMA та CDMA2000.
