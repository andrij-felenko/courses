# 🧮 Математичний аналіз розповсюдження похибок в інерціальній навігації

Цей аналітичний розбір містить суворе математичне виведення лінеаризованої системи диференціальних рівнянь похибок безплатформної інерціальної навігаційної системи (БІНС), аналітичні розв'язки для детермінованих зміщень давачів, стохастичний аналіз накопичення дисперсії випадкових блукань та дослідження стійкості навігаційних каналів на сферичній Землі.

## 1. Повна лінеаризована модель збурень БІНС

Розглянемо навігацію в локальній географічній системі координат NED (North-East-Down — Північ-Схід-Вниз). Вектор стану істинної системи описується положенням `pⁿ`, лінійною швидкістю `vⁿ` та матрицею орієнтації `C_bⁿ` (перехід із системи корпусу `b` у навігаційну `n`).

Нелінійні диференціальні рівняння ідеальної БІНС у локальній площині мають вигляд:

```
ṗⁿ = vⁿ                                     [кінематичне визначення швидкості]
v̇ⁿ = C_bⁿ · fᵇ + gⁿ − (2·ω_ieⁿ + ω_enⁿ) × vⁿ [питома сила, гравітація та сила Коріоліса]
Ċ_bⁿ = C_bⁿ · [ω_ibᵇ ×] − [ω_inⁿ ×] · C_bⁿ  [матричне кінематичне рівняння Пуассона]
```

Тут:
- `fᵇ` — вектор істинної питомої сили в системі корпусу;
- `gⁿ = [0, 0, g]ᵀ` — вектор гравітаційного прискорення в системі NED;
- `ω_ibᵇ` — абсолютна кутова швидкість обертання корпусу відносно інерціального простору;
- `ω_ieⁿ` — кутова швидкість обертання Землі (`≈ 7.292115 · 10⁻⁵ рад/с`), спроектована на навігаційну систему;
- `ω_enⁿ` — кутова швидкість перенесення навігаційної системи відносно Землі через кривизну поверхні (`ω_enⁿ = [v_E / R_E, −v_N / R_E, −v_E · tg(lat) / R_E]ᵀ`);
- `ω_inⁿ = ω_ieⁿ + ω_enⁿ` — сумарна кутова швидкість навігаційної системи.

Для компактних роботів, дронів та керованих апаратів на коротких інтервалах часу кутові швидкості `ω_ieⁿ` та `ω_enⁿ` набагато менші за власні кутові швидкості маневрування апарата (`||ω_ibᵇ|| ≫ ||ω_inⁿ||`), тому в локальній навігації застосовують спрощену модель плоскої Землі:

```
ṗⁿ = vⁿ
v̇ⁿ = C_bⁿ · fᵇ + gⁿ
Ċ_bⁿ = C_bⁿ · [ω_ibᵇ ×]
```

### Модель похибок первинних давачів

Реальні вимірювання акселерометра `f̃ᵇ` та гіроскопа `ω̃ᵇ` спотворені систематичними зміщеннями нуля (bias) `b_a`, `b_g` та широкосмуговим білим гаусовим шумом `w_a`, `w_g`:

```
f̃ᵇ = fᵇ + b_a + w_a                         [вимірювання акселерометра]
ω̃ᵇ = ωᵇ + b_g + w_g                         [вимірювання гіроскопа]
```

Визначимо вектор помилок оцінки навігаційного стану як різницю між обчисленими `(^) ` та істинними величинами:

```
δpⁿ = p̂ⁿ − pⁿ                               [похибка координат]
δvⁿ = v̂ⁿ − vⁿ                               [похибка швидкості]
```

Кутову помилку просторової орієнтації задамо через малий вектор повороту `ψⁿ = [ψ_N, ψ_E, ψ_D]ᵀ`, який зв'язує розрахункову навігаційну систему координат з істинною:

```
Ĉ_bⁿ ≈ (I − [ψⁿ ×]) · C_bⁿ                  [лінеаризована матриця орієнтації]
```

де `[ψⁿ ×]` — кососиметрична матриця вектору кутових помилок:

```
          [   0   -ψ_D   ψ_E ]
[ψⁿ ×] =  [  ψ_D    0   -ψ_N ]
          [ -ψ_E   ψ_N    0  ]
```

### Виведення диференціального рівняння кутової помилки

Продиференціюємо співвідношення для `Ĉ_bⁿ` за часом:

```
Ċ̂_bⁿ = Ĉ_bⁿ · [ω̃ᵇ ×]
     = (I − [ψⁿ ×]) · C_bⁿ · [(ωᵇ + b_g + w_g) ×]
```

З іншого боку, пряме диференціювання лінеаризованого виразу дає:

```
Ċ̂_bⁿ = d/dt [(I − [ψⁿ ×]) · C_bⁿ]
     = −[ψ̇ⁿ ×] · C_bⁿ + (I − [ψⁿ ×]) · Ċ_bⁿ
     = −[ψ̇ⁿ ×] · C_bⁿ + (I − [ψⁿ ×]) · C_bⁿ · [ωᵇ ×]
```

Прирівнюючи обидва вирази та відкидаючи доданки другого порядку малості, отримуємо:

```
−[ψ̇ⁿ ×] · C_bⁿ = (I − [ψⁿ ×]) · C_bⁿ · [(b_g + w_g) ×]
−[ψ̇ⁿ ×] = C_bⁿ · [(b_g + w_g) ×] · (C_bⁿ)ᵀ
```

Скориставшись властивістю подібності кососиметричних матриць `C · [v ×] · Cᵀ = [(C · v) ×]`, переходимо до чистого векторного диференціального рівняння:

```
ψ̇ⁿ = −C_bⁿ · (b_g + w_g)                    [динаміка кутової похибки орієнтації]
```

### Виведення диференціального рівняння похибки швидкості

Обчислене прискорення в навігаційній системі за показами давачів:

```
v̂̇ⁿ = Ĉ_bⁿ · f̃ᵇ + gⁿ
   = (I − [ψⁿ ×]) · C_bⁿ · (fᵇ + b_a + w_a) + gⁿ
   = C_bⁿ · fᵇ + C_bⁿ · (b_a + w_a) − [ψⁿ ×] · C_bⁿ · fᵇ + gⁿ
   = v̇ⁿ + C_bⁿ · (b_a + w_a) − [ψⁿ ×] · fⁿ
```

Оскільки `−[ψⁿ ×] · fⁿ = [fⁿ ×] · ψⁿ`, швидкість зміни похибки швидкості дорівнює:

```
δv̇ⁿ = v̂̇ⁿ − v̇ⁿ
    = [fⁿ ×] · ψⁿ + C_bⁿ · b_a + C_bⁿ · w_a [витік гравітації + похибка акселерометра]
```

Об'єднуючи виведені рівняння, записуємо повну лінеаризовану систему динаміки помилок БІНС у векторно-матричній формі `δẋ = F · δx + G · w`:

```
[ δṗⁿ ]   [  0    I      0       0      0   ]   [ δpⁿ ]   [  0    0   ]
[ δv̇ⁿ ] = [  0    0   [fⁿ ×]   C_bⁿ     0   ] · [ δvⁿ ] + [ C_bⁿ  0   ] · [ w_a ]
[  ψ̇ⁿ  ]   [  0    0      0       0   −C_bⁿ  ]   [  ψⁿ ]   [  0  −C_bⁿ ]   [ w_g ]
[ ḃ_a ]   [  0    0      0       0      0   ]   [ b_a ]   [  0    0   ]
[ ḃ_g ]   [  0    0      0       0      0   ]   [ b_g ]   [  0    0   ]
```

## 2. Аналітичне інтегрування детермінованих похибок

Розглянемо випадок квазістатичного або горизонтального прямолінійного руху, коли апарат не відчуває великих корисних прискорень, і вектор питомої сили врівноважує силу тяжіння: `fⁿ ≈ −gⁿ = [0, 0, −g]ᵀ`.

Кососиметрична матриця вектору питомої сили в системі NED:

```
         [  0   g   0 ]
[fⁿ ×] = [ −g   0   0 ]
         [  0   0   0 ]
```

Проаналізуємо вплив кожного ізольованого джерела похибки за допомогою послідовного інтегрування.

### 1. Початкова похибка швидкості `δv₀`

При відсутності дрейфів давачів (`b_a = 0, b_g = 0, ψ₀ = 0`):

```
δv̇(t) = 0
δv(t) = δv₀                                 [похибка швидкості стала]

δp(t) = ∫₀ᵗ δv(τ) dτ
      = δv₀ · t                             [лінійний ріст похибки координат]
```

### 2. Систематичне зміщення нуля акселерометра `b_a`

Нехай акселерометр має постійне зміщення `b_a` вздовж осі руху, а орієнтація визначена ідеально (`ψ = 0`):

```
δv̇(t) = b_a
δv(t) = ∫₀ᵗ b_a dτ
      = b_a · t                             [лінійне зростання похибки швидкості]

δp(t) = ∫₀ᵗ δv(τ) dτ
      = ∫₀ᵗ (b_a · τ) dτ
      = 1/2 · b_a · t²                      [квадратичне зростання похибки координат]
```

### 3. Дрейф гіроскопа `b_g` та витік гравітації (Кубічний дрейф)

Нехай гіроскоп має постійний дрейф нуля `b_g` навколо осі сходу (канал тангажу). Рівняння кутової помилки:

```
ψ̇_E(t) = −b_g
ψ_E(t) = ∫₀ᵗ (−b_g) dτ
       = −b_g · t                           [лінійний ріст кутової невідповідності]
```

Кутова помилка `ψ_E` повертає уявну вертикаль, внаслідок чого вектор гравітації проектується на вісь півночі через матрицю `[fⁿ ×]`:

```
δv̇_N(t) = g · ψ_E(t)
        = −g · b_g · t                      [лінійний ріст хибного прискорення]

δv_N(t) = ∫₀ᵗ (−g · b_g · τ) dτ
        = −1/2 · g · b_g · t²               [квадратичний ріст швидкості]

δp_N(t) = ∫₀ᵗ δv_N(τ) dτ
        = ∫₀ᵗ (−1/2 · g · b_g · τ²) dτ
        = −1/6 · g · b_g · t³               [КУБІЧНИЙ РІСТ ПОЗИЦІЇ]
```

Загальна сума детермінованих похибок позиції в горизонтальній площині:

```
δp(t) = δp₀ + δv₀ · t + 1/2 · b_a · t² + 1/6 · g · b_g · t³
```

Множник `g ≈ 9.81` діє як гігантський підсилювач кутової похибки. Саме тому для інерціальної системи точність гіроскопа на кілька порядків важливіша за точність акселерометра.

## 3. Стохастичний аналіз та випадкові блукання

Розглянемо вплив неперервного білого шуму давачів на дисперсію помилок навігаційного стану.

### Випадкове блукання швидкості (Velocity Random Walk, VRW)

Білий шум акселерометра `w_a(t)` задається спектральною густиною потужності `S_a` з автокореляційною функцією `E[w_a(t₁) · w_a(t₂)] = S_a · δ_dirac(t₁ − t₂)`.

Похибка швидкості від шуму акселерометра:

```
δv(t) = ∫₀ᵗ w_a(τ) dτ

Var(δv(t)) = E[(∫₀ᵗ w_a(τ) dτ)²]
           = ∫₀ᵗ ∫₀ᵗ E[w_a(τ₁) · w_a(τ₂)] dτ₁ dτ₂
           = ∫₀ᵗ S_a dτ
           = S_a · t                        [дисперсія швидкості росте лінійно]
```

Похибка позиції від шуму акселерометра:

```
δp(t) = ∫₀ᵗ δv(τ) dτ
      = ∫₀ᵗ (t − τ) · w_a(τ) dτ             [інтегрування за частинами]

Var(δp(t)) = E[(∫₀ᵗ (t − τ) · w_a(τ) dτ)²]
           = ∫₀ᵗ (t − τ)² · S_a dτ
           = S_a · [−(t − τ)³ / 3]₀ᵗ
           = 1/3 · S_a · t³                 [дисперсія позиції росте як t³]
```

Середньоквадратичне відхилення (СКВ, `σ_p = √Var`) зростає як `t^(3/2) = t^1.5`.

### Випадкове блукання кута (Angular Random Walk, ARW)

Білий шум гіроскопа `w_g(t)` зі спектральною густиною `S_g` породжує випадкове блукання кутової помилки з дисперсією `Var(ψ(t)) = S_g · t`.

Хибне прискорення від проекції гравітації: `δv̇(t) = g · ψ(t) = g · ∫₀ᵗ w_g(τ) dτ`.

Дисперсія швидкості:

```
δv(t) = g · ∫₀ᵗ (t − τ) · w_g(τ) dτ

Var(δv(t)) = g² · ∫₀ᵗ (t − τ)² · S_g dτ
           = 1/3 · g² · S_g · t³            [дисперсія швидкості росте як t³]
```

Дисперсія позиції:

```
δp(t) = g · ∫₀ᵗ 1/2 · (t − τ)² · w_g(τ) dτ

Var(δp(t)) = g² · S_g · ∫₀ᵗ 1/4 · (t − τ)⁴ dτ
           = 1/20 · g² · S_g · t⁵           [ДИСПЕРСІЯ ПОЗИЦІЇ РОСТЕ ЯК t⁵]
```

Середньоквадратичне відхилення позиції через випадковий шум гіроскопа зростає як `σ_p(t) = √(g² S_g / 20) · t^(2.5)`. Степень `2.5` означає, що навіть за нульового середнього зміщення нуля шум гіроскопа незворотно руйнує оцінку положення за лічені секунди.

## 4. Сферична Земля, період Шулера та нестійкість вертикального каналу

На великих відстанях вектор гравітації не є паралельним сам собі: він завжди спрямований до центру Землі. При зміщенні положення на величину `δp_N` локальна нормаль до сфери Землі радіуса `R_E ≈ 6371 км` повертається на кут `δθ_E = δp_N / R_E`.

Це змінює напрямок сили тяжіння, створюючи негативний зворотний зв'язок у горизонтальному каналі:

```
δg_N = −(g / R_E) · δp_N
```

Підставивши це в рівняння для прискорення `δp̈_N = δv̇_N`:

```
δp̈_N + (g / R_E) · δp_N = b_a               [рівняння гармонічного осцилятора Шулера]
```

Частота та період коливань Шулера дорівнюють:

```
ω_s = √(g / R_E)
    = √(9.80665 / 6371000)
    ≈ 1.24 · 10⁻³ рад/с

T_s = 2·π / ω_s
    = 2·π · √(R_E / g)
    ≈ 5066 с ≈ 84.4 хвилини
```

### Горизонтальний канал проти вертикального

1. **Горизонтальні канали (North, East):**
   Кривизна Землі створює відновлювальну силу, яка перетворює необмежене квадратичне накопичення похибки від акселерометра на обмежені гармонічні коливання з періодом 84.4 хвилини та амплітудою `A = b_a · R_E / g`.
2. **Вертикальний канал (Down):**
   Сила тяжіння зменшується з висотою згідно із законом всесвітнього тяжіння: `g(z) = g₀ · (R_E / (R_E + h))²`.
   Похідна тяжіння по вертикальній координаті має додатний знак у системі NED:

```
∂g_D / ∂p_D = +2·g / R_E = +2·ω_s²
```

Диференціальне рівняння вертикальної похибки набуває вигляду:

```
δp̈_D − 2·ω_s² · δp_D = b_az                  [НЕСТІЙКИЙ ОСЦИЛЯТОР З ВІД'ЄМНОЮ ЖОРСТКІСТЮ]
```

Власні числа цього рівняння дійсні та мають протилежні знаки: `λ = ±√(2) · ω_s`.
Розв'язок містить експоненційно зростаючу моду `e^(+√(2) · ω_s · t)`.

Це фундаментальна теорема інерціальної навігації: **вертикальний канал БІНС є фізично нестійким за своєю природою**. Навіть ідеальна навігаційна система високого класу не здатна утримувати висоту чисто інерціально без зовнішнього висотоміра (барометричного датчика, радіовисотоміра чи GNSS).
