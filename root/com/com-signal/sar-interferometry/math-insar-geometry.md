# 🧮 Математична геометрія інтерферометрії та фазова чутливість

У радарній інтерферометрії вимірювання рельєфу та міліметрових зміщень земної поверхні спирається на тригонометричну різницю двох оптичних шляхів між парою просторово рознесених радарних антен і спостережуваною точкою. Ця вставка розгортає повний математичний апарат InSAR: точний аналітичний розв'язок трикутника бази спостереження, розкладання фазової різниці на топографічну складову та деформацію, геометричні спотворення радарного зображення (стиснення схилів, перекриття, радіотінь), виведення висоти невизначеності, границю критичної просторової бази, фільтрацію спільних смуг просторових частот, метод розщеплення спектра для іоносферної корекції, адаптивну фільтрацію Гольдштейна — Вернера, розв'язання задачі томографічної роздільності по висоті (TomoSAR), варіацію бази вздовж орбітального треку, коваріаційну матрицю часових рядів інтерферометрії, статистичну модель спекл-шуму та теоретичну межу дисперсії фазової похибки Крамера — Рао.

## 1. Геометрія бази спостереження та різниця похилих дальностей

Розглянемо дві радарні антени `S₁` (головна, *master*) та `S₂` (ведена, *slave*), розташовані у просторі на відстані векторної просторової бази `B`. Вектор `B` має модуль `B = |B|` і нахилений до місцевої горизонталі під кутом `α`.

Обидві антени спостерігають точкову ціль `P` на земній поверхні. Відстань від `S₁` до `P` дорівнює похилій дальності `R₁`, а від `S₂` до `P` — дальності `R₂`. Кут між вертикаллю до еліпсоїда (надиром) і лінією візування `S₁P` позначається як кут візування `θ`. Кут між вектором бази `B` та напрямком лінії візування на ціль становить `θ - α`.

За теоремою косинусів у трикутнику `S₁ S₂ P` квадрат відстані `R₂` виражається через `R₁`, модуль просторової бази `B` та внутрішній кут `θ - α`:

```
R₂²
= R₁² + B² - 2·R₁·B·cos(90° - (θ - α))   [теорема косинусів для трикутника S₁ S₂ P]
= R₁² + B² - 2·R₁·B·sin(θ - α)           [тригонометрична тотожність: cos(90° - x) = sin(x)]
```

Винесемо `R₁²` за дужки та візьмемо квадратний корінь для знаходження точного виразу похилої дальності `R₂`:

```
R₂
= √(R₁² · (1 - 2·(B / R₁)·sin(θ - α) + (B / R₁)²))  [винесення R₁² як спільного множника]
= R₁ · √(1 - 2·(B / R₁)·sin(θ - α) + (B / R₁)²)     [винесення R₁ з-під кореня]
```

Оскільки в космічних та авіаційних системах дальність `R₁` (сотні кілометрів) на багато порядків перевищує довжину просторової бази `B` (десятки або сотні метрів), відношення `B / R₁ << 1` є малим параметром (типово `10⁻⁴` ... `10⁻³`). Застосуємо біноміальний розклад Тейлора другого порядку `√(1 + x) = 1 + x/2 - x²/8 + O(x³)` для малого аргументу `x = -2·(B / R₁)·sin(θ - α) + (B / R₁)²`:

```
R₂
≈ R₁ · (1 + (1/2)·(-2·(B/R₁)·sin(θ - α) + (B/R₁)²) - (1/8)·(-2·(B/R₁)·sin(θ - α))²)  [розклад кореня у ряд Тейлора]
= R₁ · (1 - (B/R₁)·sin(θ - α) + (1/2)·(B²/R₁²) - (1/2)·(B²/R₁²)·sin²(θ - α))          [розкриття дужок і зведення степенів]
= R₁ - B·sin(θ - α) + (B² / (2·R₁))·(1 - sin²(θ - α))                                [групування членів другого порядку]
= R₁ - B·sin(θ - α) + (B² / (2·R₁))·cos²(θ - α)                                      [тригонометрична тотожність: 1 - sin²(x) = cos²(x)]
```

Різниця ходу променів `ΔR = R₁ - R₂` між двома антенами з точністю до членів першого та другого порядків становить:

```
ΔR
= R₁ - R₂                                         [означення різниці похилих дальностей]
≈ B·sin(θ - α) - (B² / (2·R₁))·cos²(θ - α)         [підстановка розкладу Тейлора для R₂]
```

Для космічної радарної інтерферометрії членом другого порядку `B² / (2·R₁)` зазвичай нехтують (при `B = 150` м і `R₁ = 800` км він складає лише `0.014` мм), отримуючи наближення паралельних ліній візування:

```
ΔR ≈ B·sin(θ - α) = B_par                          [наближення паралельних променів]
```

де `B_par = B·sin(θ - α)` — паралельна проекція вектора бази на лінію візування. Ортогональна складова бази, відома як **перпендикулярна просторова база** `B_perp`, визначається як:

```
B_perp = B·cos(θ - α)                              [означення перпендикулярної бази]
```

## 2. Фаза інтерферограми та її зв'язок із різницею ходу

Радарний сигнал проходить подвійний шлях від антени до спостережуваної ділянки поверхні й повертається назад. Повна фаза відбитого когерентного сигналу визначається оптичною довжиною шляху та фазою розсіювання:

```
φ₁ = -(4π / λ) · R₁ + φ_scat,1                     [фаза першого відбитого сигналу]
φ₂ = -(4π / λ) · R₂ + φ_scat,2                     [фаза другого відбитого сигналу]
```

де `λ` — довжина хвилі зондувального радіовипромінювання, а `φ_scat` — фазовий зсув, внесений мікроструктурою розсіювачів на поверхні.

При формуванні комплексної інтерферограми шляхом попіксельного комплексного множення першого зображення `S₁` на комплексно-спряжене друге `S₂*`, інтерферометрична фазова різниця `Δφ = arg(S₁ · S₂*)` набуває вигляду:

```
Δφ
= φ₁ - φ₂                                         [визначення фазової різниці інтерферограми]
= -(4π / λ) · (R₁ - R₂) + (φ_scat,1 - φ_scat,2)   [підстановка виразів фаз окремих проходів]
= -(4π / λ) · ΔR                                  [умова ідентичності розсіювачів: φ_scat,1 = φ_scat,2]
```

Для однопрохідної інтерферометрії з одним спільним передавачем і двома приймальними антенами (бістатична схема місії SRTM або TanDEM-X) фазовий набіг подвоюється лише на відрізку повернення хвилі, тому в чисельнику використовується множник `2π / λ` замість `4π / λ`. У повторно-прохідній інтерферометрії (монорадарний двопрохідний супутниковий режим) діє повний коефіцієнт `4π / λ`.

## 3. Топографічна фаза та висота рельєфу

Нехай земна поверхня має локальну висоту `h` над опорним геодезичним еліпсоїдом. Зміна висоти рельєфу `dh` при фіксованій геометрії орбіти супутника викликає зміну локального кута візування `θ`. Зв'язок між диференціалом висоти `dh` та кутом `θ` визначається через висоту польоту носія `H_sat`:

```
h = H_sat - R₁·cos θ                              [зв'язок висоти точки з кутом візування]
dh = R₁·sin θ · dθ                                [диференціювання висоти по куту θ]
dθ = dh / (R₁·sin θ)                              [вираження диференціала кута через приріст висоти]
```

Знайдемо похідну різниці ходу `ΔR = B·sin(θ - α)` за кутом візування `θ`:

```
d(ΔR) / dθ
= d(B·sin(θ - α)) / dθ                            [похідна тригонометричного виразу різниці ходу]
= B·cos(θ - α)                                    [диференціювання синуса: d(sin u)/du = cos u]
= B_perp                                         [підстановка означення перпендикулярної бази]
```

Підставивши вираз для `dθ` через диференціал висоти `dh`, отримуємо зміну різниці ходу під впливом зміни рельєфу:

```
d(ΔR)
= B_perp · dθ                                    [використання похідної d(ΔR)/dθ = B_perp]
= (B_perp / (R₁·sin θ)) · dh                     [підстановка dθ = dh / (R₁·sin θ)]
```

Диференціал інтерферометричної фази за висотою рельєфу становить:

```
d(Δφ) / dh
= -(4π / λ) · (d(ΔR) / dh)                       [зв'язок диференціала фази з різницею ходу]
= -(4π / λ) · (B_perp / (R₁·sin θ))              [підстановка похідної d(ΔR)/dh]
```

Інтегруючи від нульового рівня еліпсоїда до висоти точки `h`, отримуємо базове рівняння топографічної інтерферометричної фази:

```
Δφ_topo = -(4π · B_perp) / (λ · R₁ · sin θ) · h   [інтеграл від d(Δφ)/dh по висоті h]
```

## 4. Висота невизначеності

Висотою невизначеності (*height of ambiguity*, `z_2π` або `h_2π`) називають величину зміни топографічної висоти рельєфу, яка спричиняє повний фазовий зсув на один інтерференційний цикл `|Δφ| = 2π`:

```
|Δφ_topo| = 2π                                   [умова одного повного інтерференційного циклу]
(4π · B_perp) / (λ · R₁ · sin θ) · z_2π = 2π     [підстановка формули топографічної фази]
z_2π = (2π · λ · R₁ · sin θ) / (4π · B_perp)      [вираження z_2π шляхом ділення на коефіцієнт]
z_2π = (λ · R₁ · sin θ) / (2 · B_perp)           [скорочення множника 2π в чисельнику і знаменнику]
```

**Числовий розрахунок для супутника Sentinel-1 (C-діапазон):**
Нехай довжина хвилі `λ = 0.05546` м (частота 5.405 ГГц), дальність `R₁ = 850` км, кут візування `θ = 37°` (`sin 37° ≈ 0.6018`), а перпендикулярна просторова база `B_perp = 120` м:

```
z_2π
= (0.05546 · 850 000 · 0.6018) / (2 · 120)       [підстановка параметрів орбіти й довжини хвилі]
= 28369.8 / 240                                  [обчислення добутків у чисельнику та знаменнику]
≈ 118.2 м                                        [результат розрахунку висоти невизначеності]
```

Кожні 118.2 метра зміни висоти рельєфу утворюють одну інтерференційну смугу на інтерферограмі. Збільшення перпендикулярної бази `B_perp` зменшує `z_2π`, що підвищує чутливість до дрібних деталей рельєфу, але одночасно наближає систему до межі просторової декореляції.

## 5. Геометричні спотворення радарного рельєфу

Оскільки радар вимірює відстань вздовж похилого променя лінії візування, проекція тривимірного рельєфу на площину дальності створює специфічні геометричні спотворення залежно від локального кута нахилу земного схилу `α_slope`:

1. **Стиснення схилу (*Foreshortening*):**
   Виникає на схилах, звернених у бік радара, коли кут нахилу менший за кут візування (`0 < α_slope < θ`). Довжина схилу на радарному знімку стискається у `sin(θ - α_slope) / sin θ` разів. Стиснута ділянка виглядає аномально яскравою через концентрацію енергії розсіювання на малій кількості радарних пікселів.
2. **Перекриття схилів (*Layover*):**
   Виникає на крутих схилах, коли кут нахилу перевищує кут візування (`α_slope ≥ θ`). Вершина гори розташована ближче до антени, ніж її підніжжя. Відлуння від вершини приходить раніше за відлуння від підніжжя, у результаті чого вершина на радарному зображенні «падає» в бік сенсора, накладаючись на рівнинні ділянки. Фазова інформація в зоні перекриття є сумішшю сигналів і не піддається розгортанню.
3. **Радіотінь (*Shadow*):**
   Виникає на зворотних схилах, якщо кут спаду поверхні перевищує доповнення кута візування (`α_slope < -(90° - θ)`). Прямий радарний промінь не досягає поверхні; у зоні тіні приймається виключно фоновий тепловий шум, а інтерферометрична когерентність дорівнює нулю.

## 6. Фазова чутливість до деформацій поверхні

Якщо за інтервал часу між двома прольотами супутника ділянка земної кори зазнала тектонічного, вулканічного чи антропогенного зміщення на вектор `d`, його проекція на одиничний вектор лінії візування `e_LOS` задає радіальне зміщення `Δr = d · e_LOS`. Зміна подвійного оптичного шляху сигналу становить `2 · Δr`.

Фазовий зсув, викликаний переміщенням ґрунту, визначається формулою:

```
Δφ_disp = -(4π / λ) · Δr                         [зв'язок деформаційної фази зі зміщенням вздовж LOS]
```

Звідси коефіцієнт чутливості фазової різниці до зміщення поверхні дорівнює:

```
|d(Δφ_disp) / d(Δr)| = 4π / λ                    [похідна деформаційної фази за зміщенням]
```

Один повний цикл зміни фази `2π` відповідає переміщенню на половину довжини хвилі:

```
Δr_2π = λ / 2                                    [величина зміщення для одного повного фазового циклу]
```

Для радара C-діапазону (`λ = 5.55` см) повний фазовий цикл фіксує переміщення всього на `2.77` см. При типовій точності вимірювання інтерферометричної фази близько `5°` (`0.087` рад), досягається субміліметрова точність детектування деформацій:

```
δ(Δr)
= (λ / (4π)) · δ(Δφ)                             [визначення абсолютної похибки зміщення через фазовий шум]
= (0.05546 / 12.566) · 0.087                     [підстановка числових значень для C-діапазону]
≈ 0.00038 м = 0.38 мм                            [оцінка межі виявлення зміщень поверхні]
```

## 7. Критична просторова база та фільтрація спектральних зсувів

Зміна кута спостереження між двома орбітальними проходами на кут `Δθ = B_perp / R₁` спричиняє спектральний зсув радіальних просторових частот відбитого радіосигналу:

```
Δf_r
= -(f₀ · B_perp) / (R₁ · tan θ)                  [спектральний зсув радіальної частоти через зміну кута]
= -(c · B_perp) / (λ · R₁ · tan θ)               [підстановка зв'язку несучої частоти f₀ = c / λ]
```

де `f₀` — несуча частота радара, `c` — швидкість світла.

Спектральне перекриття між двома когерентними відгуками лінійно зменшується зі зростанням величини зсуву `|Δf_r|`. Коли зсув частоти дорівнює повній спектральній смузі зондувального імпульсу `B_chirp`, спільна частина спектра повністю зникає, а інтерферометрична когерентність падає до нуля:

```
|Δf_r| = B_chirp                                 [критерій повної просторової декореляції]
(c · B_crit) / (λ · R₁ · tan θ) = B_chirp        [підстановка формули зсуву частоти при B_perp = B_crit]
B_crit = (B_chirp · λ · R₁ · tan θ) / c          [вираження критичної бази B_crit]
```

Враховуючи, що роздільна здатність за похилою дальністю становить `δ_r = c / (2 · B_chirp)`, формулу критичної бази записують у класичному геометричному вигляді:

```
B_crit = (λ · R₁ · tan θ) / (2 · δ_r)            [геометричний вираз критичної перпендикулярної бази]
```

**Приклад розрахунку критичної просторової бази:**
Для `λ = 0.0555` м, `R₁ = 850` км, `θ = 37°` (`tan 37° ≈ 0.7536`) та роздільності за дальністю `δ_r = 2.5` м:

```
B_crit
= (0.0555 · 850 000 · 0.7536) / (2 · 2.5)       [підстановка параметрів супутникової системи]
= 35551 / 5.0                                    [обчислення проміжних значень чисельника і знаменника]
≈ 7110 м = 7.11 км                               [підсумкове значення критичної просторової бази]
```

Якщо фізична перпендикулярна база `B_perp` менша за `B_crit`, просторову когерентність відновлюють шляхом **фільтрації спільних смуг** (*Common-Band Filtering* або *Wavenumber Shift Filtering*): спектр першого знімка фільтрують у смузі `[f_min + Δf_r, f_max]`, а другого — у смузі `[f_min, f_max - Δf_r]`. Відкидання неперекритих спектральних компонент усуває геометричний шум декореляції ціною незначного загрублення роздільності.

## 8. Адаптивна просторова фільтрація Гольдштейна — Вернера

Для придушення фазового шуму на згорнутій інтерферограмі без розмиття чітких інтерференційних смуг Річард Гольдштейн та Чарльз Вернер (*Goldstein & Werner*, 1998) запропонували нелінійний адаптивний частотний фільтр.

Інтерферограма розбивається на перекривні просторові блоки розміром `32×32` або `64×64` пікселів. Для кожного блока обчислюється 2D-спектр Фур'є `Z(u, v) = FFT2D{I(x, y)}`. Передавальна функція фільтра формується на основі згладженого енергетичного спектра `|Z(u, v)|`:

```
H(u, v) = |Z(u, v)|^α                            [передавальна функція фільтра Гольдштейна]
```

де `α ∈ [0, 1]` — параметр фільтрації (типово `α = 0.5 ... 0.8`), який часто пов'язують із локальною когерентністю: `α = 1 - γ`.

Відфільтрований спектр `Z_filt(u, v) = Z(u, v) · H(u, v)` повертається у просторову область через обернене 2D БПФ. У зонах із високою просторовою когерентністю (чіткий спектральний пік) фільтр підсилює домінуючу просторову частоту смуг; у зашумлених некогерентних зонах (рівномірний спектр) фільтрація працює як м'який низькочастотний фільтр, зменшуючи щільність сингулярних залишків у десятки разів.

## 9. Метод розщеплення спектра для іоносферної корекції

При зйомці в низькочастотних діапазонах (L-діапазон, 1.2 ГГц; P-діапазон, 435 МГц) затримка сигналу в іоносфері носить виражений дисперсійний характер і залежить від повного електронного вмісту (*Total Electron Content*, TEC):

```
Δφ_iono = (4π · K_iono · ΔTEC) / (c · f)         [дисперсійний фазовий зсув в іоносфері]
```

де `K_iono = 40.31` м³/с², а `f` — миттєва частота зондування. На відміну від іоносфери, топографічний набіг і деформація ґрунту є недесперсійними та лінійно пропорційними до частоти: `Δφ_nondisp = -(4π · f / c) · ΔR`.

**Метод розщеплення спектра (*Split-Spectrum Method*):**
Спектр зондувального ЛЧМ-імпульсу шириною `B` ділять на дві субсмуги: нижню з центральною частотою `f_L = f₀ - B/4` та верхню з частотою `f_H = f₀ + B/4`. Формуючи дві окремі інтерферограми `Δφ_L` та `Δφ_H`, отримують систему лінійних рівнянь:

```
Δφ_L = (f_L / f₀) · Δφ_nondisp + (f₀ / f_L) · Δφ_iono
Δφ_H = (f_H / f₀) · Δφ_nondisp + (f₀ / f_H) · Δφ_iono
```

Розв'язуючи цю систему, іоносферний фазовий екран `Δφ_iono` аналітично вилучають із вимірювань:

```
Δφ_iono = (f_L · f_H) / (f₀ · (f_H² - f_L²)) · (f_H · Δφ_L - f_L · Δφ_H)
```

Це дозволяє усувати смугасті іоносферні аномалії на знімках L-діапазону над полярними та екваторіальними широтами.

## 10. Роздільна здатність радарної томографії за висотою

У радарній томографії (TomoSAR) стек із `M` проходів із різними просторовими базами `B_{perp,m}` утворює синтезовану апертуру вздовж осі висоти (нормалі до похилої площини візування). 

Якщо повний розмах перпендикулярних баз становить `B_span = max(B_{perp,m}) - min(B_{perp,m})`, синтезована томографічна роздільна здатність за висотою `δ_z` визначається як:

```
δ_z = (λ · R₁ · sin θ) / (2 · B_span)             [формула роздільної здатності TomoSAR по висоті]
```

Для супутника TerraSAR-X (`λ = 0.031` м, `R₁ = 600` км, `θ = 35°`) при розмаху бази `B_span = 300` м томографічна роздільність становить `δ_z ≈ (0.031 · 600000 · 0.5736) / 600 ≈ 17.8` метрів, що дозволяє розділяти поверхи багатоповерхових будівель або шари лісового пологу.

## 11. Збіжність орбіт та лінійна варіація бази вздовж азимута

У реальних повторних прольотах супутника орбіти не є строго паралельними через різницю нахилу та прецесію площини орбіти. Вектор бази плавно змінюється вздовж азимутального повільного часу `η`:

```
B_perp(η) = B_perp,0 + (dB_perp / dη) · η         [лінійна апроксимація перпендикулярної бази]
```

де `dB_perp / dη` — швидкість зміни просторової бази. Ця варіація створює додатковий азимутальний фазовий градієнт (орбітальний рампа-тренд, *orbital ramp*), який описується білінійною функцією координат кадру `φ_ramp(x, r) = a·x + b·r + c·x·r + d` і підлягає видаленню на етапі плаского вирівнювання за допомогою точних ефемерид GNSS/DORIS.

## 12. Коваріаційна матриця та часові ряди інтерферометрії

У методах часових рядів (PSI / SBAS / SqueeSAR) аналізується стек із `M` радарних знімків, отриманих в моменти часу `t₁, t₂, ..., t_M`. Вектор спостережень для одного пікселя записується у вигляді комплексного вектора `y = [s₁, s₂, ..., s_M]^T`.

Статистична поведінка комплексного вектора `y` описується багатовимірним нормальним розподілом із нульовим середнім та ермітовою коваріаційною матрицею `C = E[y · y^H]`:

```
C_jk = E[s_j · s_k*] = σ_j · σ_k · γ_jk · exp(j · (φ_j - φ_k))
```

де `γ_jk` — модуль комплексної когерентності між знімками `j` та `k`, а `φ_j` — істинна фаза в момент `t_j`.

Оцінка максимальної правдоподібності вектора фаз `Φ = [φ₁, φ₂, ..., φ_M]^T` зводиться до максимізації квадратичної форми:

```
Φ_hat = argmax_Φ { exp(-j · Φ)^T · (|C|⁻¹ ⊙ C_sample) · exp(j · Φ) }
```

де `⊙` позначає поелементний добуток Адамара матриць, а `C_sample` — вибіркова коваріаційна матриця, оцінена за просторовим вікном із `N` однорідних пікселів. Алгоритми оптимізації (фазове зв'язування, *Phase Linking*) знаходять оптимальний вектор фазових відліків, що мінімізує залишковий шум і забезпечує лінійну швидкість деформації з субміліметровою точністю.

## 13. Статистична модель спекл-шуму та розподіл Гудмана

Розподіл комплексного сигналу від ділянки з багатьма випадковими розсіювачами всередині одного пікселя підпорядковується циркулярному гаусовому закону Гудмана (*Goodman distribution*). Густина ймовірності інтерферометричної фазової різниці `Δφ` при заданій когерентності `γ` та числі луків `N = 1` описується точним виразом:

```
pdf(Δφ) = (1 - |γ|²) / (2π · (1 - |γ|² · cos²(Δφ - Δφ₀))) · ( 1 + (|γ|·cos(Δφ - Δφ₀) · (π - arccos(|γ|·cos(Δφ - Δφ₀)))) / √(1 - |γ|²·cos²(Δφ - Δφ₀)) )
```

При високій когерентності (`|γ| → 1`) розподіл фази наближається до нормального з нульовим зміщенням та мінімальною дисперсією.

## 14. Теоретична межа дисперсії фази Крамера — Рао

Якість інтерферометричної фази кількісно описується комплексною когерентністю `γ`. Для оцінки фази методом максимальної правдоподібності за ансамблем `N` незалежних просторових відліків (кількість луків, *number of looks*), нижня межа дисперсії оцінки фази задається нерівністю Крамера — Рао:

```
σ_φ² ≥ (1 - |γ|²) / (2 · N · |γ|²)               [нерівність Крамера — Рао для дисперсії фази InSAR]
```

Стандартне відхилення фазового шуму становить:

```
σ_φ = (1 / √(2·N)) · (√(1 - |γ|²) / |γ|)          [теоретичне середньоквадратичне відхилення фази]
```

Пов'язуючи фазовий шум із похибкою вимірювання топографічної висоти рельєфу `σ_h` та радіального зміщення `σ_r`:

```
σ_h = (λ · R₁ · sin θ) / (4π · B_perp) · σ_φ      [трансляція фазового шуму в похибку висоти рельєфу]
σ_r = (λ / (4π)) · σ_φ                           [трансляція фазового шуму в похибку зміщення поверхні]
```

При когерентності `|γ| = 0.85` та мультилукінгу на `N = 16` незалежних просторових комірок:

```
σ_φ
= (1 / √(32)) · (√(1 - 0.7225) / 0.85)           [підстановка N = 16 та модуля когерентності 0.85]
= (1 / 5.657) · (0.5268 / 0.85)                  [обчислення коренів та відношень]
≈ 0.1096 рад (6.28°)                             [оцінка СКО інтерферометричної фази]
```

Для довжини хвилі супутника Sentinel-1 (`λ = 5.55` см) теоретична похибка вимірювання деформації становить:

```
σ_r
= (0.05546 / 12.566) · 0.1096                    [підстановка СКО фази та довжини хвилі]
≈ 0.00048 м = 0.48 мм                            [підсумкова точність вимірювання деформації]
```

Ці аналітичні залежності доводять, що точність радарної інтерферометрії фундаментально обмежена не розміром пікселя зображення (який може становити метри), а довжиною хвилі випромінювання, рівнем когерентності та просторовою базою інтерферометра.
