# 🧮 Унімодулярне Z-перетворення та факторизація LDLᵀ у методі LAMBDA

Цілочислові найменші квадрати в задачі RTK шукають вектор цілих чисел `a ∈ ℤⁿ`, який мінімізує зважену квадратичну відстань до дійсного вектора оцінок `â ∈ ℝⁿ` із коваріаційною матрицею `Q_â`:

```
F(a) = (â − a)ᵀ · Q_â⁻¹ · (â − a)  →  min,   де a ∈ ℤⁿ
```

Прямий перебір у просторі `a` паралізований високою кореляцією: недіагональні елементи `Q_â` близькі до діагональних, власні числа різняться на 4–8 порядків, а еліпсоїд пошуку витягнутий у голку. Метод LAMBDA (*Least-squares AMBiguity Decorrelation Adjustment* — «декореляційне узгодження неоднозначностей за найменшими квадратами») розв'язує цю проблему за допомогою лінійної заміни змінних:

```
ẑ = Zᵀ · â
z = Zᵀ · a
Q_ẑ = Zᵀ · Q_â · Z
```

Ця вставка містить строге математичне виведення вимог до матриці `Z`, геометричних властивостей ґраток, алгоритму факторизації `L·D·Lᵀ`, дискретних зсувів Гаусса та умов перестановок, що гарантують стиснення еліпсоїда до форми, близької до сферичної.

## Геометрія цілочислової ґратки та унімодулярність

Цілочислова ґратка (англ. *integer lattice*) `ℤⁿ` являє собою дискретну підгрупу евклідового простору `ℝⁿ`, утворену всіма можливими лінійними комбінаціями стандартного ортонормованого базису з цілими коефіцієнтами. Кожен вузол ґратки відповідає одній гіпотезі про комбінацію цілих довжин хвиль несучої частоти між супутниками та приймачами.

Навколо кожного вузла ґратки існує область тяжіння — комірка Вороного (англ. *Voronoi cell*), яка містить усі точки неперервного простору `ℝⁿ`, розташовані ближче до цього вузла, ніж до будь-якого іншого. У звичайній евклідовій метриці комірка Вороного є стандартним одиничним `n`-вимірним кубом із центром у вузлі ґратки, а її об'єм дорівнює одиниці:

```
Vol(Комірка) = 1
```

Проте в задачі цілочислових найменших квадратів відстань вимірюється не в евклідовій метриці, а в метриці Махаланобіса, яка зважує відхилення за допомогою оберненої коваріаційної матриці `Q_â⁻¹`. У цій метриці комірки Вороного перетворюються на сплюснуті, витягнуті багатогранники, орієнтовані вздовж головних осей кореляції. Якщо кут між осями еліпсоїда та осями координат гострий, стандартне покомпонентне округлення потрапляє в сусідні неефективні комірки.

Щоб дискретна оптимізаційна задача в новому просторі `z` була строго еквівалентна вихідній задачі в просторі `a`, матриця перетворення `Z` зобов'язана задовольняти чотири фундаментальні умови:

1. **Цілочисловість елементів:** усі компоненти `Z_{i,j}` мусять належати множині цілих чисел `ℤ`. Якщо вектор `a ∈ ℤⁿ`, то трансформований вектор `z = Zᵀ·a` автоматично належить `ℤⁿ`.
2. **Унімодулярність (збереження об'єму комірки):** абсолютна величина визначника матриці дорівнює плюс або мінус одиниці:
   ```
   |det(Z)| = 1
   ```
   З теореми про визначник оберненої матриці `det(Z⁻¹) = 1 / det(Z)` випливає, що обернена матриця `Z⁻¹` також має виключно цілі елементи:
   ```
   Z⁻¹ = adj(Z) / det(Z)  ∈  ℤⁿˣⁿ
   ```
   Це забезпечує взаємно однозначне відображення (бієкцію) цілої ґратки на саму себе: `ℤⁿ ↔ ℤⁿ`. Жоден цілий вузол не зникає, жоден сторонній дробовий вузол не стає цілим, а щільність вузлів у просторі залишається абсолютно незмінною. Фундаментальний об'єм елементарної комірки ґратки зберігається:
   ```
   Vol(Zᵀ · ℤⁿ) = |det(Zᵀ)| · Vol(ℤⁿ) = 1 · 1 = 1
   ```
3. **Декореляція коваріаційної матриці:** матриця `Q_ẑ = Zᵀ · Q_â · Z` має стати максимально діагональною. Недіагональні коефіцієнти кореляції `r_{ij} = (Q_ẑ)_{ij} / √((Q_ẑ)_{ii} · (Q_ẑ)_{jj})` мають прямувати до нуля.
4. **Упорядкування умовних дисперсій:** діагональні елементи редукованої матриці вибудовуються так, щоб умовні дисперсії під час послідовного перебору давали найвужчі інтервали на кожному кроці, мінімізуючи розгалуження дерева пошуку.

## Факторизація коваріаційної матриці LDLᵀ

Оскільки коваріаційна матриця `Q_â` є симетричною і строго додатно визначеною (`xᵀ · Q_â · x > 0` для будь-якого ненульового вектора `x`), її можна однозначно розкласти на добуток унітрикутної та діагональної матриць:

```
Q_â = L · D · Lᵀ
```

де `L` — нижньотрикутна матриця з одиницями на головній діагоналі (`L_{ii} = 1`, `L_{ij} = 0` для `j > i`), а `D = diag(d₁, d₂, ..., dₙ)` — діагональна матриця з додатними умовними дисперсіями `d_i > 0`.

На відміну від класичного розкладу Холецького `Q_â = G · Gᵀ`, де трикутна матриця `G` містить квадратні корені на діагоналі, розклад `L·D·Lᵀ` розділяє геометричний зсув (коефіцієнти `L`) та масштаб невизначеності (діагональні дисперсії `D`). Це виключає операції добування коренів під час ітерацій декореляції та підвищує чисельну стійкість.

Елементи матриць `L` і `D` обчислюються за рекурсивним алгоритмом Холецького:

```
d_j = (Q_â)_{jj} − ∑_{k=1}^{j-1} L_{jk}² · d_k
L_{ij} = ( (Q_â)_{ij} − ∑_{k=1}^{j-1} L_{ik} · L_{jk} · d_k ) / d_j   [для i > j]
```

Обернена до `Q_â` матриця виражається через обернені трикутні співмножники:

```
Q_â⁻¹ = (L · D · Lᵀ)⁻¹ = L⁻ᵀ · D⁻¹ · L⁻¹
```

Підставивши цей розклад у квадратичну форму відстані Махаланобіса, ми отримуємо тотожне перетворення до канонічної суми незалежних зважених квадратів:

```
(â − a)ᵀ · Q_â⁻¹ · (â − a)
= (â − a)ᵀ · (L⁻ᵀ · D⁻¹ · L⁻¹) · (â − a)     [підстановка розкладу LDLᵀ]
= (L⁻¹ · (â − a))ᵀ · D⁻¹ · (L⁻¹ · (â − a))    [властивість транспонування добутку матриць]
= ∑_{i=1}ⁿ ( (â − a)_i + ∑_{j=1}^{i-1} L⁻¹_{ij} (â − a)_j )² / d_i
```

Кожен доданок у цій сумі відповідає відхиленню вздовж однієї осі, масштабованому на відповідну умовну дисперсію `d_i`.

## Елементарні цілочислові перетворення Гаусса (Size Reduction)

Недіагональні елементи матриці `L` відповідають за ступінь взаємного скосу координатних осей. Якщо елемент `|L_{ij}| > 0.5`, це свідчить про те, що осі `i` та `j` утворюють гострий або тупий кут, а проекція однієї осі на іншу перевищує половину кроку ґратки.

Щоб зменшити цей скіс, застосовують дискретне зсувне перетворення Гаусса, віднімаючи від `i`-ї координати ціле кратне `j`-ї координати.

Визначимо елементарну цілочислову матрицю Гаусса:

```
Z_{ij} = I − μ · e_i · e_jᵀ,   де μ = round(L_{ij}) ∈ ℤ
```

Тут `e_i` — одиничний вектор-стовпець із одиницею на `i`-й позиції, `e_jᵀ` — одиничний вектор-рядок, а `round()` — функція округлення до найближчого цілого числа.

Матриця `Z_{ij}` є унімодулярною, оскільки вона є трикутною з одиницями на головній діагоналі:
```
det(Z_{ij}) = 1
```

Оновлення матриці факторизації `L` при застосуванні `Z_{ij}` відбувається за правилом:

```
Q_нове = Z_{ij}ᵀ · Q_â · Z_{ij}
L_нове = Z_{ij}ᵀ · L
```

Зокрема, цільовий елемент `L_{ij}` оновлюється безпосереднім відніманням цілого числа `μ`:

```
L_{ij}' = L_{ij} − round(L_{ij})
```

Оскільки для будь-якого дійсного числа відхилення від найближчого цілого не перевищує половини одиниці (`|x − round(x)| ≤ 0.5`), після застосування перетворення гарантовано виконується умова:

```
|L_{ij}'| ≤ 0.5   [для всіх i > j]
```

Геометрично це перетворення являє собою дискретний паралельний зсув (англ. *shear mapping*) ґратки вздовж координатного напрямку. Цей зсув не змінює об'єму елементарної комірки, проте суттєво випрямляє похилий паралелепіпед, наближаючи його грані до ортогональних площин.

## Перестановка сусідніх координат (Permutation & Swapping)

Самих зсувів Гаусса недостатньо, якщо сусідні умовні дисперсії сильно розбалансовані. Якщо умовна дисперсія наступної координати `d_{i+1}` виявляється значно більшою за поточну `d_i`, форма перерізу еліпсоїда залишається сильно витягнутою вздовж певної осі. У такому разі вигідно поміняти місцями осі `i` та `i+1`.

Розглянемо 2×2 блок на головній діагоналі для пари сусідніх координат `(i, i+1)`:

```
[ L_{i,i}     0      ] · [ d_i    0    ] · [ L_{i,i}    L_{i+1,i} ]
[ L_{i+1,i}  L_{i+1,i+1} ]   [  0    d_{i+1} ]   [    0       L_{i+1,i+1} ]
= [   d_i           d_i · L_{i+1,i}                 ]
  [ d_i · L_{i+1,i}   d_i · L_{i+1,i}² + d_{i+1}    ]
```

Якщо поміняти місцями осі `i` та `i+1` за допомогою матриці перестановки `P`, нова факторизація `L' · D' · L'ᵀ` дасть оновлені значення умовних дисперсій `d_i'` та `d_{i+1}'`:

```
d_i' = d_i · L_{i+1,i}² + d_{i+1}
d_{i+1}' = (d_i · d_{i+1}) / d_i'
L_{i+1,i}' = (d_i · L_{i+1,i}) / d_i'
```

Зверніть увагу на фундаментальну інваріантність: добуток дисперсій залишається абсолютно сталим, що гарантує збереження визначника 2×2 блоку:

```
d_i' · d_{i+1}' = d_i · d_{i+1} = det(Блок 2×2)
```

**Критерій перестановки Тойніссена:** перестановка координат виконується тоді і тільки тоді, коли нова перша дисперсія стає строго меншою за попередню:

```
d_i' < d_i   ⇔   d_i · L_{i+1,i}² + d_{i+1} < d_i
```

Ця умова є прямим аналогом умови Ловаса (англ. *Lovász condition*) у знаменитому алгоритмі редукції базисів ґраток LLL (Ленстра — Ленстра — Ловас, 1982). Вона забезпечує, щоб менші дисперсії концентрувалися на вищих індексах, вибудовуючи природну ієрархію стиснення простору.

Оскільки кожна успішна перестановка строго зменшує потенційну функцію добутку проміжних головних мінорів:

```
Π(L, D) = ∏_{k=1}^{n-1} det(Q_k)
```

алгоритм не може зациклитися і гарантовано завершується за скінченне, поліноміально обмежене число кроків.

## Зв'язок з алгоритмом редукції ґраток LLL

Метод LAMBDA можна розглядати як спеціалізовану адаптацію алгоритму LLL для просторів із метрикою, заданою коваріаційною матрицею `Q_â`.

У класичному алгоритмі LLL вхідними даними є набір векторів базису `b₁, ..., bₙ`, а ортогоналізація виконується за схемою Грама — Шмідта. У методі LAMBDA вихідним об'єктом є симетрична коваріаційна матриця `Q_â`, яка неявно задає взаємні скалярні добутки векторів базису:

```
(Q_â)_{ij} = ⟨ b_i, b_j ⟩
```

Факторизація `L·D·Lᵀ` є точним алгебраїчним еквівалентом процесу Грама — Шмідта над коваріаційними моментами. Зсуви Гаусса забезпечують слабку ортогональність базисних векторів, а умова перестановки гарантує впорядкованість їхніх довжин. У результаті Z-перетворення знаходить майже ортогональний базис ґратки, в якому відношення максимальної півосі еліпсоїда до мінімальної зменшується в десятки або сотні разів.

## Числовий приклад декореляції розмірності 2×2

Розглянемо числовий розрахунок для сильно корельованої системи з двох неоднозначностей із коефіцієнтом взаємного зв'язку `r = 497.0 / √(500.0 · 495.0) ≈ 0.999`:

```
Q_â = [ 500.0   497.0 ]
      [ 497.0   495.0 ]
```

Число обумовленості вихідної матриці становить:
```
cond(Q_â) ≈ 994.0 / 0.998 ≈ 996
```

### Крок 1. Факторизація LDLᵀ

Обчислюємо початкові компоненти розкладу:

```
d₁ = 500.0
L₂₁ = 497.0 / 500.0 = 0.994
d₂ = 495.0 − 0.994² · 500.0 = 495.0 − 494.018 = 0.982

L = [ 1.0     0.0 ]
    [ 0.994   1.0 ]

D = [ 500.0    0.0  ]
    [   0.0    0.982 ]
```

### Крок 2. Гауссова цілочислова редукція

Оскільки недіагональний коефіцієнт `|L₂₁| = 0.994 > 0.5`, обчислюємо величину цілого зсуву:

```
μ = round(0.994) = 1
```

Формуємо елементарну унімодулярну матрицю `Z₁`:

```
Z₁ = [  1   −1 ]
     [  0    1 ]
det(Z₁) = 1 · 1 − 0 = 1
```

Обчислюємо редуковану коваріаційну матрицю `Q₁ = Z₁ᵀ · Q_â · Z₁`:

```
Q₁ = [ 1   0 ] · [ 500   497 ] · [  1  −1 ]
     [ −1  1 ]   [ 497   495 ]   [  0   1 ]

   = [ 1   0 ] · [ 500   −3  ]
     [ −1  1 ]   [ 497   −2  ]

   = [ 500    −3 ]
     [  −3     1 ]
```

### Крок 3. Перестановка координат (Swap)

Дисперсії в матриці `Q₁` становлять `500` та `1`. Перша координата має колосальну невизначеність, тоді як друга майже точно визначена. Застосовуємо матрицю перестановки `P`:

```
P = [ 0   1 ]
    [ 1   0 ]
```

Повна накопичена матриця перетворення `Z = Z₁ · P`:

```
Z = [  1  −1 ] · [ 0  1 ] = [ −1   1 ]
    [  0   1 ]   [ 1  0 ]   [  1   0 ]
det(Z) = −1 · 0 − 1 · 1 = −1
```

Нова коваріаційна матриця `Q_ẑ = Zᵀ · Q_â · Z`:

```
Q_ẑ = [ −1   1 ] · [ 500   497 ] · [ −1   1 ]
      [  1   0 ]   [ 497   495 ]   [  1   0 ]

    = [ 1   −3 ]
      [ −3  500 ]
```

Новий розклад цієї матриці `Q_ẑ = L_z · D_z · L_zᵀ`:

```
d_z1 = 1.0
L_z21 = −3.0 / 1.0 = −3.0
```

Оскільки коефіцієнт зв'язку знову більший за половину (`|−3.0| > 0.5`), виконуємо фінальний гауссів зсув із `μ = round(−3.0) = −3`. Після нього коефіцієнт зв'язку стає строго нульовим:

```
L_z21' = −3.0 − (−3) = 0.0
d_z2 = 500.0 − (−3)² · 1.0 = 491.0
```

Остаточна трансформована коваріаційна матриця:

```
Q_фінал = [ 1.0     0.0   ]
          [ 0.0   491.0   ]
```

### Підсумок перетворення

У вихідному просторі кореляція між неоднозначностями становила `0.999`, а перебір вимагав сканування відрізка вздовж головної осі довжиною `2 · √(500 · χ²) ≈ 44.7 · √χ²`.

У декорельованому просторі недіагональний коефіцієнт став рівним нулю, а перша змінна `z₁` перебирається в діапазоні шириною всього `2 · √(1.0 · χ²) = 2 · √χ²`. Пошук звузився більш ніж у 22 рази, усунувши необхідність перевірки тисяч хибних вузлів.
