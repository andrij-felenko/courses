# 🧮 Математичні засади кореляційного узгодження та фазової неперервності у WSOLA

Масштабування часової осі дискретного сигналу без зміни його спектрального складу вимагає розв'язання фундаментальної оптимізаційної задачі: як розбити сигнал на блоки та перевпорядкувати їх на новій часовій сітці так, щоб мінімізувати фазову неузгодженість на межах склеювання. Якщо блоки накладати без точного узгодження фази, гармонічні складові зазнають деструктивної інтерференції, що спричиняє гребінчасту фільтрацію (*comb filtering*), металевий призвук (*flanging*) та амплітудну модуляцію. Алгоритм WSOLA (*Waveform Similarity Overlap-Add*) формулює вибір кожного наступного кадру як задачу пошуку максимуму міри взаємної подібності форми хвилі у строго обмеженій часовій області.

### Постановка оптимізаційної задачі та геометрична розмітка

Нехай `x[n]` — дискретний вхідний сигнал, визначений для цілих відліків `n ∈ ℤ`. Потрібно побудувати вихідний сигнал `y[m]`, тривалість якого змінена у `1 / α` разів порівняно з оригіналом, де `α` — безрозмірний коефіцієнт темпу (*time-scaling factor*):

```
α > 1.0    [прискорення відтворення: тривалість зменшується]
α < 1.0    [сповільнення відтворення: тривалість збільшується]
α = 1.0    [тотожне відтворення без часових спотворень]
```

Процес синтезу вихідного сигналу відбувається на строго регулярній часовій сітці з постійним кроком синтезу `Hₛ` (*synthesis hop*). Центр кожного `k`-го синтезованого кадру розміщується в точці `k · Hₛ`. Відповідна номінальна координата аналізу на осі вхідного сигналу визначається співвідношенням:

```
t_nom[k] = k · Hₐ = k · (α · Hₛ)    [номінальна позиція аналізу для кадру k]
```

Оскільки крок аналізу `Hₐ = α · Hₛ` зазвичай є нецілим числом, розміщення кадрів строго в точках `k · Hₐ` без фазового підлаштування спричиняє розрив фазової траєкторії між суміжними сегментами. Справжня позиція взяття `k`-го кадру у вхідному сигналі позначається через `τ[k]` і формується як сума номінальної координати та зміщення `δ[k]`:

```
τ[k] = k · Hₐ + δ[k]    [фактична позиція зсуву кадру k]
```

де `δ[k]` — часове зміщення, що обирається з допустимого інтервалу допуску `[-Δ, +Δ]`:

```
δ[k] ∈ [-Δ, +Δ]    [обмеження області локального пошуку]
```

### Принцип збереження стаціонарної фази

Ключова математична інновація WSOLA полягає у виборі опорного сигналу (*reference template*). На відміну від алгоритму SOLA, де шаблон вилучається з уже накопиченого вихідного буфера `y[m]`, у WSOLA еталон формується безпосередньо з непорушеного вхідного сигналу `x[n]`.

Якщо `(k-1)`-й кадр було вирізано з позиції `τ[k-1]`, то природне, непорушне продовження хвильового процесу на крок синтезу `Hₛ` уперед розташоване у вхідному сигналі в точці:

```
τ_ref[k] = τ[k-1] + Hₛ    [ідеальна фазова координата продовження]
```

Сегмент сигналу `x[τ[k-1] + Hₛ + m]` для `m ∈ [0, L-1]` є точним фізичним еталоном форми хвилі. Задача полягає в тому, щоб знайти такий зсув `δ ∈ [-Δ, +Δ]`, за якого кандидатський блок `x[k · Hₐ + δ + m]` має найвищу ступінь подібності до еталону:

```
δ[k] = argmax_{δ ∈ [-Δ, +Δ]} S(x[τ[k-1] + Hₛ + ·],  x[k · Hₐ + δ + ·])
```

де `S(u, v)` — функціонал подібності векторів довжини `L`.

### Критерії оцінки подібності форми хвилі

Для практичного знаходження зміщення `δ[k]` застосовують кілька математичних метрик, кожна з яких забезпечує компроміс між стійкістю до зміни амплітуди та обчислювальною складністю.

#### 1. Ненормована взаємна кореляція (Cross-Correlation)

Найпростіший функціонал базується на скалярному добутку сигналів:

```
R(δ) = ∑_{m=0}^{L-1} x[τ[k-1] + Hₛ + m] · x[k · Hₐ + δ + m]
```

Оптимальне зміщення визначається глобальним максимумом кореляційної суми:

```
δ_opt = argmax_{δ ∈ [-Δ, +Δ]} R(δ)    [максимум взаємної кореляції]
```

Цей критерій є обчислювально найдешевшим при реалізації в часовій області, проте чутливий до локальних перепадів енергії: відрізок із більшою енергією може дати вище значення `R(δ)` навіть за гіршого збігу фази.

#### 2. Нормований коефіцієнт крос-кореляції (Normalized Cross-Correlation)

Для усунення впливу зміни амплітуди використовують нормований коефіцієнт кореляції Пірсона:

```
                     ∑_{m=0}^{L-1} x_ref[m] · x_cand[δ, m]
ρ(δ) = ─────────────────────────────────────────────────────────────
       √[ ∑_{m=0}^{L-1} (x_ref[m])² ] · √[ ∑_{m=0}^{L-1} (x_cand[δ, m])² ]
```

де:
- `x_ref[m] = x[τ[k-1] + Hₛ + m]` — еталонний відрізок;
- `x_cand[δ, m] = x[k · Hₐ + δ + m]` — кандидатський відрізок для заданого `δ`.

Коефіцієнт `ρ(δ)` набуває значень у діапазоні `[-1.0, +1.0]`, де `+1.0` відповідає абсолютному збігу форми з точністю до додатного масштабного множника. За нерівністю Коші-Буняковського максимум `ρ(δ) = 1.0` досягається тоді й лише тоді, коли вектори колінеарні: `x_cand[δ, m] = c · x_ref[m]` для деякої константи `c > 0`.

#### 3. Різницеві метрики: SAD та AMDF

Для апаратних платформ без швидкого апаратного множника задачу максимізації скалярного добутку замінюють еквівалентною задачею мінімізації норми різниці в просторі L1:

```
SAD(δ) = ∑_{m=0}^{L-1} | x[τ[k-1] + Hₛ + m] − x[k · Hₐ + δ + m] |    [Sum of Absolute Differences]
```

Середня функція абсолютної різниці (*Average Magnitude Difference Function*, AMDF) обчислюється як:

```
AMDF(δ) = (1 / L) · SAD(δ)
```

Оптимальний зсув відповідає глобальному мінімуму різницевої функції:

```
δ_opt = argmin_{δ ∈ [-Δ, +Δ]} SAD(δ)    [мінімум похибки узгодження]
```

Мінімізація `SAD(δ)` є прямим наближенням мінімізації квадратичної похибки в просторі L2, оскільки:

```
∑ (x_ref − x_cand)² = ∑ x_ref² + ∑ x_cand² − 2 ∑ (x_ref · x_cand)
```

Якщо локальна енергія сусідніх відрізків приблизно постійна, мінімум квадратичної похибки строго збігається з максимумом взаємної кореляції.

### Умова постійності перекриття (COLA)

Після знаходження оптимального зсуву `τ[k] = k · Hₐ + δ[k]`, відрізок сигналу довжиною `N` множиться на віконну функцію `w[n]` і накопичується у вихідному буфері:

```
y[m] = ∑_{k} w[m − k · Hₛ] · x[τ[k] + (m − k · Hₛ)]
```

Щоб реконструкція не спотворювала амплітудну обгортку вихідного сигналу, віконна функція `w[n]` та крок синтезу `Hₛ` повинні задовольняти умову постійності додавання перекриттів (*Constant Overlap-Add*, COLA):

```
∑_{k = -∞}^{+∞} w[m − k · Hₛ] ≡ 1.0    [умова лінійної реконструкції COLA]
```

Для класичного вікна Ганна (*Hann window*) довжиною `N`:

```
w[n] = 0.5 · (1 − cos(2π · n / N)),    n ∈ [0, N-1]
```

умова COLA строго виконується за умови вибору кроку синтезу `Hₛ = N / 2` або `Hₛ = N / 4`:

```
w[n] + w[n + N/2]
= 0.5 · (1 − cos(2πn/N)) + 0.5 · (1 − cos(2π(n + N/2)/N))  [підстановка вікна Ганна]
= 1.0 − 0.5 · [cos(2πn/N) + cos(2πn/N + π)]                [групування сталих]
= 1.0 − 0.5 · [cos(2πn/N) − cos(2πn/N)]                    [властивість: cos(θ + π) = −cos(θ)]
= 1.0                                                      [строга тотожність одиниці]
```

При довільних коефіцієнтах перекриття застосовують енергетичну нормалізацію через поділ накопиченого сигналу на суму квадратів вікон:

```
y_norm[m] = y[m] / ( ∑_{k} w²[m − k · Hₛ] )
```

### Стійкість та обмеженість накопиченої часової похибки

Важливою математичною властивістю WSOLA є відсутність необмеженого часового дрейфу. Оскільки кожен крок пошуку `δ[k]` локалізовано в інтервалі `[-Δ, +Δ]` навколо номінальної точки `k · Hₐ`, відхилення фактичної позиції від ідеальної не накопичується в часі:

```
| τ[k] − k · Hₐ | = | δ[k] | ≤ Δ    [рівномірна обмеженість часової похибки]
```

Середній темп перетворення сигналу на великому проміжку з `K` кадрів прямує до теоретичного значення:

```
lim_{K → ∞} (τ[K] − τ[0]) / (K · Hₛ)
= lim_{K → ∞} (K · Hₐ + δ[K] − δ[0]) / (K · Hₛ)   [розкриття τ[K]]
= lim_{K → ∞} (Hₐ / Hₛ) + (δ[K] − δ[0]) / (K · Hₛ)  [розбиття на доданки]
= α + 0                                            [оскільки |δ[K] − δ[0]| ≤ 2Δ]
= α                                                [строга збіжність до цільового темпу]
```

Це доводить, що локальні зсуви `δ[k]`, необхідні для бездоганного фазового зшивання, не порушують глобального масштабу часу: результуючий коефіцієнт зміни тривалості точно дорівнює заданому значенню `α`.

### Обчислення кореляції у частотній області через ШПФ

Коли радіус пошуку `Δ` великий (наприклад, для низькочастотних басових сигналів або симфонічної музики `Δ > 1024`), пряме обчислення скалярних добутків у часовій області вимагає `O(Δ · L)` операцій. Застосування дискретної теореми про згортку та перетворення Фур'є дозволяє знизити складність до `O(M · log M)`.

Нехай `x_cand[n]` — фрагмент вхідного сигналу довжиною `2Δ + L`, а `x_ref[n]` — еталонний шаблон довжиною `L`. Доповнимо обидва вектори нулями до найближчого степеня двійки `M ≥ 2Δ + 2L`:

```
1. Пряме ШПФ вхідного сегмента:
   X_cand = FFT(x_cand, M)

2. Пряме ШПФ реверсованого еталонного шаблону:
   X_ref = FFT(x_ref_reversed, M)

3. Поелементне множення спектрів:
   S_corr[k] = X_cand[k] · conj(X_ref[k])

4. Зворотне перетворення Фур'є:
   R_xy = IFFT(S_corr, M)
```

Масив `R_xy` містить точні значення ненормованої кореляції для всіх можливих зсувів `δ ∈ [-Δ, +Δ]`. Для знаходження максимуму достатньо одного лінійного проходу масиву `R_xy` довжиною `2Δ + 1`.
