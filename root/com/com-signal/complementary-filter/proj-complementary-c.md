# ⚙️ Комплементарний фільтр на C: крен, тангаж і вимикач довіри

## Задача

Формула фільтра — один рядок, але між «формулою на папері» й «апарат тримає рівновагу» лежить вузька смуга коду, де кожна дрібниця колись комусь коштувала годин відлагодження. Потрібен самодостатній модуль на C, який можна викликати з таймерного переривання на 100–500 Гц і бути певним, що: оцінка стартує одразу правильною (а не доганяє правду перші секунди), крен і тангаж рахуються кожен своєю віссю з правильним знаком, `dt` береться **справжній** (а не з даташита), а під час тривалого розгону фільтр **не повірить** збреханому акселерометру. Усе на `float`, без матриць і без тригонометрії в гарячому циклі, крім двох `atan2f` на такт.

## Ідея

Фільтр має **пам'ять** — поточна оцінка кута живе від такту до такту, тож тримати її в локальній змінній не можна. Складемо весь стан і налаштування у структуру `Comp`, а роботу одного такту — у `comp_step()`. Два кути (крен `roll`, тангаж `pitch`) ведемо в одній структурі: вони незалежні, але мають спільне `alpha` й однакову логіку, тож дублювати код ні до чого.

Опорні кути беремо з акселерометра через `atan2f` — функцію, що, на відміну від `asinf`, правильно працює в усіх чотирьох чвертях і не вибухає біля ±90°. Крен — це нахил навколо поздовжньої осі: його видно з `a_y` та `a_z`, бо саме між цими двома осями «перетікає» проєкція тяжіння, коли апарат хилиться вбік. Тангаж — навколо поперечної: його дає `a_x` проти проєкції решти, `sqrtf(a_y²+a_z²)`, — тобто нахил уперед-назад вимірюється відносно горизонтальної площини, а не однієї осі, і тому не плутається з креном. Ця проєкція в знаменнику й розв'язує два кути: кожен лишається чесним, навіть коли діють обидва нахили водночас. Знаки осей залежать від того, як IMU припаяний на платі, тож їх **перевіряють на столі**, а не вгадують.

Точності `float` тут вистачає з головою: кути — це частки радіана, а не астрономічні числа, тож 24 біти мантиси дають похибку, мізерну проти шуму самого давача. Перехід на `double` лише з'їв би такти на МК без апаратного подвійного формату й нічого не виграв — тому весь модуль свідомо на `float` і на `atan2f`/`sqrtf` (одинарні версії), а не на `atan2`/`sqrt`.

Головна хитрість — **вимикач довіри** до акселерометра. Уся довіра до нього тримається на тому, що він міряє чисте тяжіння; щойно `|a|` помітно відходить від g, до тяжіння домішалося власне прискорення, і вірити опорному куту не можна. Тоді на час маневру тимчасово піднімаємо `alpha` майже до 1 (спираємось майже лише на гіроскоп), а коли `|a|` повертається до g — відновлюємо звичну вагу. Це той самий «вимикач», що наближає комплементарний фільтр до фільтра Калмана, який зважує довіру **сам**, на кожному кроці, зі статистики шумів.

## Код

Спершу структура — стан і налаштування в одному місці:

:::tabs
```cpp
#include <math.h>

typedef struct {
    /* параметри */
    float alpha;        /* базовий коеф. довіри гіроскопу (напр. 0.98f)   */
    float g;            /* очікувана норма прискорення спокою, м/с² (9.81)*/
    float acc_band;     /* допуск |a|−g, за яким акселерометру не вірити  */
    /* стан (живе між тактами) */
    float roll, pitch;  /* поточні оцінки кутів, рад                      */
    int   seeded;       /* чи засіяно стартову оцінку                     */
} Comp;

void comp_init(Comp *c, float alpha, float g, float acc_band)
{
    c->alpha = alpha;  c->g = g;  c->acc_band = acc_band;
    c->roll = 0.0f;  c->pitch = 0.0f;  c->seeded = 0;
}
```
```python
from dataclasses import dataclass


@dataclass
class Comp:
    # параметри
    alpha: float          # базовий коеф. довіри гіроскопу (напр. 0.98)
    g: float              # очікувана норма прискорення спокою, м/с² (9.81)
    acc_band: float       # допуск |a|−g, за яким акселерометру не вірити
    # стан (живе між тактами)
    roll: float = 0.0     # поточна оцінка крену, рад
    pitch: float = 0.0    # поточна оцінка тангажа, рад
    seeded: bool = False  # чи засіяно стартову оцінку
```
:::

Тепер крок. Аргументи: три осі гіроскопа `gx,gy,gz` (рад/с), три осі акселерометра `ax,ay,az` (будь-які однакові одиниці — масштаб скоротиться в `atan2f`, але норму рахуємо для вимикача, тож тут зручно тримати м/с²), і **виміряний** період `dt` (с):

:::tabs
```cpp
void comp_step(Comp *c, float gx, float gy,
               float ax, float ay, float az, float dt)
{
    /* 1. опорні кути з акселерометра (atan2f — стійкий у всіх чвертях) */
    float roll_acc  = atan2f(ay, az);
    float pitch_acc = atan2f(-ax, sqrtf(ay*ay + az*az));

    /* 2. засіяти стартову оцінку показом акселерометра, не нулем */
    if (!c->seeded) {
        c->roll  = roll_acc;
        c->pitch = pitch_acc;
        c->seeded = 1;
        return;                 /* перший такт лише сіє, не інтегрує */
    }

    /* 3. вимикач довіри: якщо |a| далеко від g — підняти alpha майже до 1 */
    float amag = sqrtf(ax*ax + ay*ay + az*az);
    float a = c->alpha;
    if (fabsf(amag - c->g) > c->acc_band)
        a = 0.999f;             /* маневр: майже самий гіроскоп */

    /* 4. зважена сума окремо по кожній осі, кожна — своя вісь гіроскопа */
    c->roll  = a * (c->roll  + gx * dt) + (1.0f - a) * roll_acc;
    c->pitch = a * (c->pitch + gy * dt) + (1.0f - a) * pitch_acc;
}
```
```python
import math


def comp_step(c, gx, gy, ax, ay, az, dt):
    # 1. опорні кути з акселерометра (atan2 — стійкий у всіх чвертях)
    roll_acc  = math.atan2(ay, az)
    pitch_acc = math.atan2(-ax, math.sqrt(ay*ay + az*az))

    # 2. засіяти стартову оцінку показом акселерометра, не нулем
    if not c.seeded:
        c.roll  = roll_acc
        c.pitch = pitch_acc
        c.seeded = True
        return                  # перший такт лише сіє, не інтегрує

    # 3. вимикач довіри: якщо |a| далеко від g — підняти alpha майже до 1
    amag = math.sqrt(ax*ax + ay*ay + az*az)
    a = c.alpha
    if abs(amag - c.g) > c.acc_band:
        a = 0.999               # маневр: майже самий гіроскоп

    # 4. зважена сума окремо по кожній осі, кожна — своя вісь гіроскопа
    c.roll  = a * (c.roll  + gx * dt) + (1.0 - a) * roll_acc
    c.pitch = a * (c.pitch + gy * dt) + (1.0 - a) * pitch_acc
```
:::

Виклик із переривання таймера виглядає так — увесь сенс у тому, що `dt` **міряний**, а не константа:

:::tabs

static Comp filt;
/* при старті: */
comp_init(&filt, 0.98f, 9.81f, 0.6f);   /* допуск ±0.6 м/с² навколо g */

/* кожен такт (напр. з лічильника, що дає реальний інтервал): */
float dt = ticks_to_seconds(now - prev);   /* справжній період! */
prev = now;

/* filt.roll, filt.pitch — рад; для керування за потреби × 180/π */

## Числовий прогон одного такту

100 Гц (`dt = 0.01f`), `alpha = 0.98f`, спокій (`|a| ≈ g`, вимикач не спрацював). Кути для наочності в градусах; `gx` уже переведено в °/с:

```c
roll      = 10.0°      // попередня оцінка
gx        = 50.0°/с    // швидкість крену
roll_acc  = 12.0°      // опорний з акселерометра

c->roll = 0.98f * (10.0f + 50.0f*0.01f) + 0.02f * 12.0f
        = 0.98f * 10.5f                  + 0.24f
        = 10.29f                         + 0.24f      ==  10.53°
```

Оцінка пішла переважно за гіроскопом (до 10.5°) і лише на чверть градуса підтяглася до акселерометра. Тепер той самий такт **під час розгону**: `|a|` підскочила до 11.2 м/с², `fabsf(11.2 − 9.81) = 1.39 > 0.6`, вимикач підняв `a` до 0.999:

```c
c->roll = 0.999f * 10.5f + 0.001f * 12.0f
        = 10.4895f + 0.012f                          ==  10.50°
```

Тепер акселерометр майже не впливає (його вага 0.001) — фільтр свідомо ігнорує збрехану опору й тримається гіроскопа, доки прискорення не вщухне. Саме це й рятує оцінку від «втечі» за хибним «низом» у тривалому віражі.

## Пастки

- **Переплутані осі чи знак.** Найчастіша й найпідступніша помилка: фільтр виглядає робочим, але крен підмішується в тангаж, або знак гіроскопа перевернутий — і фільтр діє **за** помилкою, розгойдуючи апарат. Лікується тридцятисекундним тестом на столі: нахили по крену — `roll` має рости в правильний бік, `pitch` стояти; потім навпаки.
- **`dt` із даташита.** На `dt` множиться швидкість гіроскопа; «номінальний» період замість виміряного тихо псує масштаб інтегрування й дає повільний хибний дрейф. Завжди міряйте реальний інтервал між викликами.
- **Старт із нуля.** Якщо не засіяти оцінку показом акселерометра (`seeded`), фільтр перші τ секунд повзе від 0° до правди — апарат стартує з хибним кутом. Один `if` на старті це знімає.
- **Завузький `acc_band`.** Якщо допуск надто малий, вимикач спрацьовуватиме від кожної вібрації мотора й фільтр майже завжди сидітиме на самому гіроскопі — повернеться дрейф. Беріть смугу з запасом (десяті долі g), бо коротку вібрацію й так давить мала вага `(1−α)`.
- **Рискання (yaw).** Цей модуль веде лише крен і тангаж: акселерометр не бачить повороту навколо вертикалі. Для курсу потрібен [магнітометр](topic:hw-sensing/magnetometer) окремим комплементарним каналом — у цю структуру він не лягає.
