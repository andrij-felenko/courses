# 🧮 Спектральне переплетення та квадратурна модуляція піднесучої

Спільне передавання сигналу яскравості `Y(t)` та колірної піднесучої `C(t)` в єдиній неперервній смузі частот без взаємного руйнування інформації спирається на дискретну гармонійну структуру спектра двовимірного растра та точну квадратурну модуляцію. 

Математичний апарат спектрального переплетення пояснює, чому неперервна в часі напруга на виході відеокамери складається з дискретних спектральних піків, як напіврядковий або чвертьрядковий зсув піднесучої розміщує колір у міжгармонійних інтервалах, і як гребінчасті фільтри на лініях затримки розділяють суміш компонентів без перехресних спотворень.

### Дискретний спектр двовимірного растрового сканування

Розглянемо двовимірне світлове поле зображення на мішені передавальної камери `L(x, y, t)`, де `x` — горизонтальна координата, `y` — вертикальна координата, а `t` — час.

Під час електронного растрового сканування координати розгортки зв'язані з часом лінійними пилкоподібними функціями:

```
x(t) = v[x] · (t mod T[H])       [рух променя вздовж рядка з періодом T_H]
y(t) = v[y] · (t mod T[V])       [рух променя зверху донизу з періодом кадру T_V]
```

Для нерухомого або статичного зображення світловий розподіл є періодичною функцією як по горизонталі (з періодом рядка `T[H] = 1 / f[H]`), так і по вертикалі (з періодом поля `T[V] = 1 / f[V]`). Тому одновимірний електричний сигнал напруги на виході датчика `y(t) = L(x(t), y(t))` можна розкласти в подвійний комплексний ряд Фур'є:

```
y(t) = ∑[m=-∞..∞] ∑[n=-∞..∞] Y[m,n] · exp(j·2π·(m·f[H] + n·f[V])·t)
```

Застосовуючи пряме перетворення Фур'є до цього виразу, отримуємо спектральну густину сигналу яскравості `S[Y](f)`:

```
S[Y](f) = ∑[m=-∞..∞] ∑[n=-∞..∞] Y[m,n] · δ(f - (m·f[H] + n·f[V]))
```

де `δ(f)` — одинична дельта-функція Дірака.

Спектр яскравості являє собою не суцільну смугу, а дискретний гребінь дельта-імпульсів. Оскільки частота кадрової розгортки `f[V]` (25 Гц або 29.97 Гц) у сотні разів менша за частоту рядків `f[H]` (15625 Гц або 15734.26 Гц), спектральні лінії утворюють компактні кластери навколо основних гармонік рядкової частоти `m · f[H]`. 

Ширина кожного такого кластера рідко перевищує `±1 – 2 кГц`. Між сусідніми кластерами залишаються незайняті інтервали завширшки понад `13 – 14 кГц`, у яких спектральна густина енергії яскравості практично дорівнює нулю.

### Умова напіврядкового зсуву піднесучої (система NTSC)

Щоб гармоніки модульованого сигналу колірності `C(t)` потрапили точно в центри порожніх інтервалів між лініями яскравості, частота колірної піднесучої `f[sc]` повинна відстояти від початку координат на непарне число половин рядкової частоти:

```
f[sc] = (2k + 1) / 2 · f[H] = (k + 1/2) · f[H]
```

Для американської системи NTSC було обрано коефіцієнт `k = 227`. Розрахунок точного значення частоти піднесучої за рядкової частоти `f[H] = 15734.264 Гц`:

```
f[sc]
= (227 + 1/2) · 15734.264 Гц    [підстановка параметрів NTSC]
= 227.5 · 15734.264 Гц          [множення на напіврядковий коефіцієнт]
= 3579545.06 Гц ≈ 3.579545 МГц  [нормативна частота колірної піднесучої NTSC]
```

При такому виборі частоти спектр модульованого колірного сигналу `S[C](f)` концентрується навколо частот:

```
f[C,p,q] = f[sc] + p·f[H] + q·f[V] = (k + p + 1/2)·f[H] + q·f[V]
```

Кожна лінія спектра кольору лежить строго посередині між двома лініями яскравості. На екрані телевізора це створює просторово-часову протифазність: у будь-якій фіксованій точці растра колірна піднесуча змінює свій знак на протилежний у кожному наступному кадрі:

```
exp(j·2π·f[sc]·(t + T[frame]))
= exp(j·2π·(k + 0.5)·f[H]·(N_lines / f[H]))    [підстановка тривалості кадру]
= exp(j·2π·(k + 0.5)·525)                      [для NTSC N_lines = 525]
= exp(j·2π·(525·k + 262.5))                    [розкриття дужок]
= exp(j·(2π·M + π))                            [де M — ціле число]
= -1                                           [інверсія знака напруги]
```

Око глядача інтегрує світловий потік за два сусідні кадри, і паразитні точки від піднесучої оптично компенсуються до середнього рівня яскравості.

### Чвертьрядковий зсув та кадрова поправка (система PAL)

У європейській системі PAL фаза колірно-різницевого сигналу `V` інвертується на 180° у кожному наступному рядку: `V(t) = ±V_0 · cos(2π·f[sc]·t)`. Це еквівалентно додатковій фазовій модуляції меандром із частотою `f[H] / 2 = 7812.5 Гц`.

Внаслідок цього бічні смуги спектра сигналу `V` розщеплюються і зміщуються від піднесучої на `±f[H] / 2`. Якби в системі PAL застосували простий напіврядковий зсув `(k + 0.5)·f[H]`, спектральні лінії `V` зсунулися б на `(k + 0.5 ± 0.5)·f[H]`, тобто потрапили б точно на цілі гармоніки яскравості `m · f[H]`, викликавши сильні перехресні завади.

Щоб уникнути цього збігу, автори системи PAL застосували **чвертьрядковий зсув** (`283.75 · f[H]`) з додаванням невеликої кадрової поправки `f[V] / 2 = 25 Гц / 2 = 12.5 Гц / 625 = 1/625 · f[H]`:

```
f[sc]
= (283 + 3/4 + 1/625) · f[H]              [чвертьрядковий зсув з кадровою поправкою]
= (283.75 + 0.0016) · 15625.0 Гц          [підстановка f_H = 15625 Гц]
= 283.7516 · 15625.0 Гц                   [сумарний частотний множник]
= 4433618.75 Гц ≈ 4.433619 МГц            [нормативна частота піднесучої PAL]
```

Завдяки цьому складному зсуву гармоніки яскравості `Y`, піднесучої `U` та комутованої піднесучої `V` рівномірно розподіляються за частотною віссю з кроком `f[H] / 4`, досягаючи максимального взаємного розв'язання.

### Квадратурна модуляція та когерентне детектування

Колірний сигнал формується підсумовуванням двох квадратурних амплітудно-модульованих коливань із придушеною несучою (DSB-SC):

```
C(t) = U(t) · sin(ω[sc]·t) + V(t) · cos(ω[sc]·t)
```

де `ω[sc] = 2π·f[sc]`.

У приймачі для розділення сигналів `U(t)` та `V(t)` вхідний сигнал множиться на когерентні опорні коливання `2·sin(ω[sc]·t)` та `2·cos(ω[sc]·t)`, відновлені за допомогою фазового автопідстроювання частоти (PLL) за колірним спалахом Colorburst.

#### Математичне виділення каналу U(t)

Множення на синфазне опорне коливання:

```
C(t) · 2·sin(ω[sc]·t)
= (U(t)·sin(ω[sc]·t) + V(t)·cos(ω[sc]·t)) · 2·sin(ω[sc]·t)     [підстановка повного колірного сигналу]
= 2·U(t)·sin²(ω[sc]·t) + 2·V(t)·sin(ω[sc]·t)·cos(ω[sc]·t)       [розкриття дужок]
= U(t)·(1 - cos(2ω[sc]·t)) + V(t)·sin(2ω[sc]·t)                 [застосування тригонометричних тотожностей]
= U(t) - U(t)·cos(2ω[sc]·t) + V(t)·sin(2ω[sc]·t)                [виділення низькочастотної складової]
```

Отриманий вираз містить три складові:
1. `U(t)` — шуканий низькочастотний сигнал колірності (смуга `0 – 1.3 МГц`).
2. `-U(t)·cos(2ω[sc]·t)` — високочастотна складова на подвійній частоті піднесучої (близько `8.86 МГц`).
3. `V(t)·sin(2ω[sc]·t)` — перехресна квадратурна складова на подвійній частоті піднесучої.

Після пропускання сигналу через фільтр низьких частот (ФНЧ) із частотою зрізу `1.3 МГц` усі високочастотні компоненти з частотою `2ω[sc]` повністю придушуються, залишаючи чистий компонент `U(t)`:

```
LPF{ C(t) · 2·sin(ω[sc]·t) } = U(t)
```

#### Математичне виділення каналу V(t)

Аналогічно, множення на квадратурне опорне коливання дає:

```
C(t) · 2·cos(ω[sc]·t)
= (U(t)·sin(ω[sc]·t) + V(t)·cos(ω[sc]·t)) · 2·cos(ω[sc]·t)     [підстановка повного сигналу]
= 2·U(t)·sin(ω[sc]·t)·cos(ω[sc]·t) + 2·V(t)·cos²(ω[sc]·t)       [розкриття дужок]
= U(t)·sin(2ω[sc]·t) + V(t)·(1 + cos(2ω[sc]·t))                 [тригонометричні формули]
= V(t) + U(t)·sin(2ω[sc]·t) + V(t)·cos(2ω[sc]·t)                [виділення низькочастотного доданку]
```

Фільтрація низьких частот повністю усуває складові подвійної частоти, відновлюючи сигнал `V(t)`:

```
LPF{ C(t) · 2·cos(ω[sc]·t) } = V(t)
```

### Передавальні функції та нулі 1H гребінчастого фільтра

Розглянемо аналоговий гребінчастий фільтр на базі лінії затримки на один рядок `T[H] = 64.0 мкс`.

Вхідний композитний сигнал є сумою: `s(t) = y(t) + c(t)`.

Оскільки за напіврядкового зсуву колірний сигнал на сусідніх рядках інвертований `c(t) ≈ -c(t - T[H])`, а сигнал яскравості корелює вздовж вертикалі `y(t) ≈ y(t - T[H])`, розділення здійснюється сумою та різницею:

```
s[Y](t) = 0.5 · (s(t) + s(t - T[H]))    [канал виділення яскравості]
s[C](t) = 0.5 · (s(t) - s(t - T[H]))    [канал виділення колірності]
```

Обчислимо комплексну передавальну характеристику фільтра яскравості `H[Y](f)` через перетворення Фур'є:

```
H[Y](f)
= 0.5 · (1 + exp(-j·2π·f·T[H]))                                 [за визначенням затримки на T_H]
= 0.5 · exp(-j·π·f·T[H]) · (exp(j·π·f·T[H]) + exp(-j·π·f·T[H]))   [винесення середньої фази]
= cos(π·f·T[H]) · exp(-j·π·f·T[H])                              [застосування формули Ейлера]
```

Модуль коефіцієнта передачі фільтра яскравості:

```
|H[Y](f)| = |cos(π·f·T[H])|
```

1. **На гармоніках розгортки `f = m · f[H]`:**
   ```
   |H[Y](m·f[H])| = |cos(π · m · f[H] · (1 / f[H]))| = |cos(m·π)| = 1.0
   ```
   Сигнал яскравості проходить без найменшого послаблення.
2. **На частотах колірної піднесучої `f = (m + 0.5) · f[H]`:**
   ```
   |H[Y]((m + 0.5)·f[H])| = |cos(π · (m + 0.5))| = 0.0
   ```
   Колірна піднесуча повністю придушується в каналі яскравості, усуваючи ефект біжучих точок (Dot Crawl).

Аналогічно виводиться передавальна функція фільтра колірності `H[C](f)`:

```
H[C](f)
= 0.5 · (1 - exp(-j·2π·f·T[H]))                                 [фільтр різниці сигналів]
= 0.5 · exp(-j·π·f·T[H]) · (exp(j·π·f·T[H]) - exp(-j·π·f·T[H]))   [винесення експоненти]
= j · sin(π·f·T[H]) · exp(-j·π·f·T[H])                          [формула Ейлера для синуса]
```

Модуль передачі фільтра колірності:

```
|H[C](f)| = |sin(π·f·T[H])|
```

Фільтр має точні нулі передачі на частотах `m · f[H]` (`|H[C]| = 0`), повністю блокуючи високочастотні деталі яскравості від проникнення в колірний декодер, що запобігає виникненню фальшивого колірного муару (Cross-Color).
