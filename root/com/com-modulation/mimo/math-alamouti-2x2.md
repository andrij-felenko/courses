# 🧮 Алгебра просторово-часового кодування Аламоуті (2×1 та 2×2)

<preknowlist>
- [Канал AWGN](root:math-information/awgn-channel) — модель шуму та розрахунок відношення сигнал/шум.
- [Статистика завмирань](root:com-medium/fading-statistics) — комплексні коефіцієнти передачі радіоканалу.
</preknowlist>

Просторово-часовий блоковий код Аламоуті (Space-Time Block Code, STBC) є фундаментальним інженерним рішенням у галузі багатоантенного радіозв'язку. Це єдина математична конструкція для двох передавальних антен, яка одночасно забезпечує повну символьну швидкість передачі комплексних сигналів (`R = 1` символ за такт), максимальний теоретичний порядок просторового рознесення та допускає точне розв'язання міжпотокових завад на приймачі за допомогою простих лінійних операцій без передачі інформації про стан каналу назад на передавач.

Нижче наведено строге математичне виведення алгебраїчної структури коду, доведення його ортогональності, розрахунок результуючого відношення сигнал/шум (SNR) для конфігурацій 2×1 (MISO) та 2×2 (MIMO), аналіз теореми Гурвіца–Радона, інтегрування за допомогою функції генерації моментів (MGF), а також розрахунок деградації через часову селективність каналу та диференціальне розширення коду.

---

### 1. Модель передачі для конфігурації 2×1 (MISO)

Розглядаємо передавач із двома випромінювальними антенами `Tx₁`, `Tx₂` та приймач із однією антеною `Rx₁`. Радіоканал між антенами описується парою комплексних коефіцієнтів передачі:

```
h₁ = |h₁| · e^(jθ₁)     [коефіцієнт передачі з Tx₁ на Rx₁]
h₂ = |h₂| · e^(jθ₂)     [коефіцієнт передачі з Tx₂ на Rx₁]
```

Канал вважається квазістатичним (блоковим): амплітуди `|h_i|` та фази `θ_i` залишаються постійними впродовж щонайменше двох послідовних символьних тактів `t₁` та `t₂`, що відповідає умові, за якої час когерентності каналу суттєво перевищує тривалість просторово-часового блоку (`T_coh ≫ 2·T_sym`).

Інформаційний потік модулюється у вектор комплексних символів `s = [s₁, s₂]ᵀ` із сузір'я з середньою енергією `E[|s_i|²] = E_s`. Передавач кодує пару символів у просторово-часову матрицю `S` розмірності `2 × 2`, де рядки відповідають дискретним часовим інтервалам (`t₁`, `t₂`), а стовпці — передавальним антенам (`Tx₁`, `Tx₂`):

```
S = [  s₁    s₂ ]     [рядок 1: такт t₁, Tx₁=s₁, Tx₂=s₂]
    [ −s₂*   s₁*]     [рядок 2: такт t₂, Tx₁=−s₂*, Tx₂=s₁*]
```

У перший такт часу `t₁` антена `Tx₁` випромінює символ `s₁`, а антена `Tx₂` — символ `s₂`. У другий такт часу `t₂` антена `Tx₁` випромінює змінений за знаком і комплексно спряжений символ `−s₂*`, а антена `Tx₂` — комплексно спряжений символ `s₁*`.

Прийняті на приймальній антені сигнали за два такти формують систему рівнянь спостереження:

```
y₁ = h₁·s₁ + h₂·s₂ + n₁           [прийнятий сигнал у такт t₁]
y₂ = −h₁·s₂* + h₂·s₁* + n₂        [прийнятий сигнал у такт t₂]
```

де `n₁`, `n₂ ~ CN(0, N₀)` — некорельовані відліки комплексного білого гаусового шуму з нульовим математичним сподіванням і дисперсією `E[|n_i|²] = N₀`.

### 2. Еквівалентна матриця каналу та доведення ортогональності

Для лінійного розділення змінних візьмемо комплексне спряження другого рівняння спостереження:

```
y₂* = h₂*·s₁ − h₁*·s₂ + n₂*       [комплексне спряження другого такту]
```

Тепер вектор прийнятих сигналів `ỹ = [y₁, y₂*]ᵀ` можна подати як лінійне матричне перетворення над невідомим вектором вихідних символів `s = [s₁, s₂]ᵀ`:

```
[ y₁  ] = [ h₁    h₂  ] · [ s₁ ] + [ n₁  ]
[ y₂* ]   [ h₂*  −h₁* ]   [ s₂ ]   [ n₂* ]
```

Позначимо еквівалентну матрицю каналу розмірності `2 × 2` як `H_eff`:

```
H_eff = [ h₁    h₂  ]
        [ h₂*  −h₁* ]
```

Обчислимо ермітів добуток матриці `H_eff` на власну ермітово-спряжену матрицю `H_effᴴ`:

```
H_effᴴ · H_eff
= [ h₁*    h₂  ] · [ h₁    h₂  ]                       [ермітове спряження та матричний добуток]
  [ h₂*   −h₁  ]   [ h₂*  −h₁* ]
= [ h₁*·h₁ + h₂·h₂*         h₁*·h₂ + h₂·(−h₁*)   ]      [поелементне множення рядків на стовпці]
  [ h₂*·h₁ + (−h₁)·h₂*      h₂*·h₂ + (−h₁)·(−h₁*)]
= [ |h₁|² + |h₂|²           h₁*·h₂ − h₁*·h₂      ]      [використання властивості |z|² = z · z*]
  [ h₁·h₂* − h₁·h₂*         |h₁|² + |h₂|²        ]
= [ |h₁|² + |h₂|²           0                    ]      [взаємне знищення недіагональних членів]
  [ 0                       |h₁|² + |h₂|²        ]
= ( |h₁|² + |h₂|² ) · I₂                                [факторизація скалярної норми та одиничної матриці]
```

Отриманий результат демонструє ключову алгебраїчну властивість: стовпці матриці `H_eff` є строго ортогональними векторами в двовимірному комплексному просторі `ℂ²` для будь-яких комплексних чисел `h₁` та `h₂`. Скалярний коефіцієнт дорівнює квадрату норми Фробеніуса вихідного канального вектора `||h||² = |h₁|² + |h₂|²`.

### 3. Лінійне детектування та повна просторова розв'язка

Приймач фільтрує вектор вимірювань `ỹ` шляхом множення зліва на ермітово-спряжену матрицю `H_effᴴ`:

```
z = [ z₁ ] = H_effᴴ · [ y₁  ]
    [ z₂ ]            [ y₂* ]
```

Розкриємо матричне множення для кожного інформаційного символу окремо:

```
z₁
= h₁*·y₁ + h₂·y₂*                                               [перший рядок матричного фільтра]
= h₁*·(h₁·s₁ + h₂·s₂ + n₁) + h₂·(h₂*·s₁ − h₁*·s₂ + n₂*)        [підстановка рівнянь спостереження]
= (|h₁|² + |h₂|²)·s₁ + (h₁*·h₂ − h₁*·h₂)·s₂ + (h₁*·n₁ + h₂·n₂*) [групування за символами та шумом]
= (|h₁|² + |h₂|²)·s₁ + 0·s₂ + ñ₁                                [повне зникнення завади від символу s₂]
= (|h₁|² + |h₂|²)·s₁ + ñ₁

z₂
= h₂*·y₁ − h₁·y₂*                                               [другий рядок матричного фільтра]
= h₂*·(h₁·s₁ + h₂·s₂ + n₁) − h₁·(h₂*·s₁ − h₁*·s₂ + n₂*)        [підстановка рівнянь спостереження]
= (|h₁|² + |h₂|²)·s₂ + (h₁·h₂* − h₁·h₂*)·s₁ + (h₂*·n₁ − h₁·n₂*) [групування за символами та шумом]
= (|h₁|² + |h₂|²)·s₂ + 0·s₁ + ñ₂                                [повне зникнення завади від символу s₁]
= (|h₁|² + |h₂|²)·s₂ + ñ₂
```

Обидва символи `s₁` та `s₂` повністю відокремлені один від одного: матрична задача детектування розпалася на два паралельні скалярні рівняння без жодних залишкових перехресних завад.

### 4. Статистичні властивості шуму та порядок рознесення

Дослідимо кореляційні властивості результуючого шуму `ñ = [ñ₁, ñ₂]ᵀ = H_effᴴ · [n₁, n₂*]ᵀ`. Оскільки вектор вхідного шуму `n = [n₁, n₂*]ᵀ` має діагональну коваріаційну матрицю `R_nn = N₀ · I₂`, коваріація трансформованого шуму становить:

```
R_{ññ}
= E[ñ · ñᴴ]                                           [означення коваріаційної матриці]
= E[H_effᴴ · n · nᴴ · H_eff]                           [підстановка лінійного перетворення шуму]
= H_effᴴ · E[n · nᴴ] · H_eff                           [винесення детермінованої матриці каналу]
= H_effᴴ · (N₀ · I₂) · H_eff                           [властивість просторово-білого шуму]
= N₀ · (H_effᴴ · H_eff)                                [винесення скалярної спектральної густини]
= N₀ · (|h₁|² + |h₂|²) · I₂                            [підстановка ортогонального добутку]
```

Оскільки недіагональні елементи матриці `R_{ññ}` тотожно дорівнюють нулю, шумові складові `ñ₁` та `ñ₂` залишаються статистично незалежними гаусовими величинами з однаковою дисперсією `σ_ñ² = (|h₁|² + |h₂|²) · N₀`.

Обчислимо миттєве відношення сигнал/шум (SNR) для відновленого символу `s₁`:

```
SNR_out
= (|h₁|² + |h₂|²)² · E_s / ((|h₁|² + |h₂|²) · N₀)    [відношення потужності сигналу до дисперсії шуму]
= (|h₁|² + |h₂|²) · (E_s / N₀)                        [скорочення спільного множника (|h₁|² + |h₂|²)]
```

Якщо сумарна випромінювана потужність передавача обмежена величиною `P_total`, і кожна антена випромінює половину енергії `E_s = P_total / 2`:

```
SNR_out = ((|h₁|² + |h₂|²) / 2) · (P_total / N₀)
```

Величина `γ = |h₁|² + |h₂|²` є сумою квадратів чотирьох незалежних дійсних гаусових випадкових величин (дійсна та уявна частини двох комплексних коефіцієнтів Релея). Отже, випадкова величина `γ` підпорядковується розподілу хі-квадрат із чотирма ступенями вільності (`χ²(4)`):

```
p(γ) = γ · e^(−γ / σ_h²) / σ_h⁴,      γ ≥ 0
```

Усереднення ймовірності помилки за цим розподілом показує, що при високому SNR ймовірність бітової помилки (Bit Error Rate, BER) для модуляції BPSK/QPSK спадає за законом:

```
P_b ≈ 3 / (16 · SNR_avg²) ∝ SNR⁻²
```

Порядок рознесення схеми Аламоуті 2×1 дорівнює `d = 2`. Система забезпечує такий самий нахил кривої завадостійкості, як і схема максимального комбінування коефіцієнтів MRC з двома приймальними антенами (SIMO 1×2), проте всі апаратні витрати зосереджені на базовій станції, залишаючи абонентський термінал простим і компактним.

### 5. Узагальнення на схему Аламоуті 2×2 (MIMO)

У системі з двома передавальними (`Tx₁, Tx₂`) та двома приймальними (`Rx₁, Rx₂`) антенами матриця радіоканалу має розмірність `2 × 2`:

```
H = [ h₁₁  h₁₂ ]
    [ h₂₁  h₂₂ ]
```

де `h_ij` описує комплексний коефіцієнт передачі з `j`-ї передавальної на `i`-ю приймальну антену.

Приймач формує 4 відліки за два символьні такти: `y₁₁`, `y₁₂` на першій приймальній антені та `y₂₁`, `y₂₂` на другій приймальній антені:

```
y₁₁ = h₁₁·s₁ + h₁₂·s₂ + n₁₁
y₁₂ = −h₁₁·s₂* + h₁₂·s₁* + n₁₂
y₂₁ = h₂₁·s₁ + h₂₂·s₂ + n₂₁
y₂₂ = −h₂₁·s₂* + h₂₂·s₁* + n₂₂
```

Об'єднавши відліки в розширений вектор `ỹ = [y₁₁, y₁₂*, y₂₁, y₂₂*]ᵀ`, отримуємо систему рівнянь із розширеною еквівалентною матрицею каналу `H_eff,2x2` розмірності `4 × 2`:

```
[ y₁₁  ]   [ h₁₁   h₁₂  ]
[ y₁₂* ] = [ h₁₂* −h₁₁* ] · [ s₁ ] + [ n₁₁  ]
[ y₂₁  ]   [ h₂₁   h₂₂  ]   [ s₂ ]   [ n₁₂* ]
[ y₂₂* ]   [ h₂₂* −h₂₁* ]           [ n₂₁  ]
                                     [ n₂₂* ]
```

Обчислимо ермітів добуток `H_eff,2x2ᴴ · H_eff,2x2`:

```
H_eff,2x2ᴴ · H_eff,2x2
= [ h₁₁*  h₁₂  h₂₁*  h₂₂  ] · [ h₁₁   h₁₂  ]
  [ h₁₂* −h₁₁  h₂₂* −h₂₁  ]   [ h₁₂* −h₁₁* ]
                              [ h₂₁   h₂₂  ]
                              [ h₂₂* −h₂₁* ]
= ( |h₁₁|² + |h₁₂|² + |h₂₁|² + |h₂₂|² ) · I₂
= ||H||_F² · I₂
```

де `||H||_F` — норма Фробеніуса повної матриці каналу.

Лінійне комбінування відліків дає повністю розв'язані скалярні оцінки:

```
ŝ₁ = ||H||_F² · s₁ + ñ₁
ŝ₂ = ||H||_F² · s₂ + ñ₂
```

Сумарна потужність сигналу масштабується сумою квадратів усіх чотирьох просторових коефіцієнтів. Оскільки випадкова величина `||H||_F²` є сумою 8 незалежних дійсних гаусових компонентів, вона підпорядковується розподілу хі-квадрат із 8 ступенями вільності (`χ²(8)`).

Порядок просторового рознесення конфігурації 2×2 дорівнює:

```
d = N_t · N_r = 2 · 2 = 4
```

Крива ймовірності бітової помилки спадає як `P_b ∝ SNR⁻⁴`, забезпечуючи безпрецедентну стійкість радіолінії в умовах важких міських завмирань.

### 6. Розрахунок імовірності помилки через функцію генерації моментів (MGF)

Для строгого розрахунку ймовірності символьної помилки (Symbol Error Rate, SER) для довільного сигнального сузір'я M-PSK використовують інтегральний метод MGF:

```
P_s = (1 / π) · ∫_0^{(M−1)π/M} M_γ( −g_PSK / sin²(θ) ) dθ
```

де `g_PSK = sin²(π / M)`, а `M_γ(s) = E[e^(s·γ)]` — функція генерації моментів розподілу хі-квадрат `χ²(2d)`.

Для порядку рознесення `d` функція `M_γ(s)` виражається у замкненій формі:

```
M_γ(s) = ( 1 − s · (SNR_avg / N_t) )^(−d)
```

Підставляючи `d = 2` для конфігурації 2×1 та `d = 4` для 2×2, отримуємо точні інтегральні формули для розрахунку завадостійкості без потреби проведення тривалих симуляцій Монте-Карло.

### 7. Теоретичні обмеження: теорема Гурвіца–Радона

Виникає природне запитання: чи можна побудувати аналогічні ортогональні просторово-часові коди зі швидкістю `R = 1` для систем із трьома, чотирма чи більше передавальними антенами (`N_t > 2`)?

У 1999 році Вахід Тарох (Vahid Tarokh), Хамід Джафархані (Hamid Jafarkhani) та Роберт Калдербанк (Robert Calderbank) дослідили це питання за допомогою класичної алгебраїчної теорії дійсних і комплексних ортогональних дизайнів (Hurwitz-Radon Theorem). Вони довели фундаментальну теорему:

1. Для комплексних сигнальних сузір'їв (QPSK, QAM) **схема Аламоуті для N_t = 2 є єдиним у природі ортогональним блоковим кодом, який досягає повної швидкості R = 1**.
2. Для систем із `N_t = 3` та `N_t = 4` передавальними антенами ортогональні просторово-часові коди існують, проте їхня символьна швидкість не перевищує `R = 3/4` або `R = 1/2` (наприклад, код Тароха передає 3 комплексні символи за 4 часові такти).
3. Для досягнення швидкості `R = 1` при `N_t > 2` доводиться жертвувати строгою ортогональністю, переходячи до квазіортогональних кодів (Quasi-Orthogonal STBC, QSTBC), які залишають невелику парну інтерференцію між символами й вимагають попарного декодування.

### 8. Вплив часової селективності каналу та похибок оцінки

Фундаментальне припущення схеми Аламоуті полягає в тому, що коефіцієнти каналу не змінюються впродовж двох тактів: `h_i(t₁) = h_i(t₂)`.

Якщо термінал рухається зі значною швидкістю `v`, доплерівський зсув частоти `f_d = (v / c) · f_c` спричиняє часову деваріацію коефіцієнтів каналу:

```
h₁(t₂) = h₁(t₁) + δ₁
h₂(t₂) = h₂(t₁) + δ₂
```

Підставимо ці змінні у формулу фільтрації прийнятого сигналу на приймачі:

```
z₁ = ( |h₁|² + |h₂|² ) · s₁ + ( h₁* · δ₂ − h₂ · δ₁* ) · s₂* + ñ₁
```

Член `( h₁* · δ₂ − h₂ · δ₁* ) · s₂*` являє собою нескомпенсовану залишкову перехресну інтерференцію від другого символу. Навіть якщо відношення сигнал/шум прямує до нескінченності (`SNR → ∞`), ця завада не зникає, створюючи насичення кривої завадостійкості (Error Floor):

```
BER_floor ≈ (π · f_d · T_sym)² / 2
```

При високих швидкостях руху (наприклад, швидкісні поїзди `v > 300` км/год на частоті 3.5 ГГц) тривалість просторово-часового блоку повинна мінімізуватися шляхом скорочення символьного інтервалу OFDM.

### 9. Диференціальне просторово-часове кодування (Differential STBC)

Якщо приймач не може виконати оцінку каналу за пілотними сигналами (наприклад, через надто швидкі завмирання або обмеження енергії), застосовують диференціальне кодування Аламоуті (Differential STBC):

Передавач формує матрицю передачі `S_k` для `k`-го блоку шляхом унітарного матричного множення:

```
S_k = S_{k−1} · V_k
```

де `V_k` — унітарна матриця, що несе інформаційні біти сузір'я.

Приймач декодує дані за двома послідовними прийнятими блоками `Y_{k−1}` та `Y_k`:

```
V̂_k = arg max_{V}  Re{ Tr( Vᴴ · Y_{k−1}ᴴ · Y_k ) }
```

Диференціальна схема не вимагає жодного знання каналу (`h₁`, `h₂` взагалі не вимірюються), проте ціною за це є енергетичний програш у 3 дБ порівняно з когерентною схемою Аламоуті (через подвоєння дисперсії некогерентного шуму).
