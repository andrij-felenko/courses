# 🧮 Виведення ємності Шеннона–Телатара для каналу MIMO та алгоритм Water-filling

<preknowlist>
- [Смуга і межа Шеннона](root:math-information/bandwidth-capacity) — ємність одноантенного каналу AWGN.
- [Сингулярний розклад (SVD)](root:math-algebra/svd) — розклад матриці на ортогональні базиси.
- [Власні значення та вектори](root:math-algebra/eigenvalues) — спектральний розклад ермітових матриць.
</preknowlist>

Пропускна здатність багатоантенної радіолінії (Multiple-Input Multiple-Output, MIMO) є теоретико-інформаційною межею максимальної швидкості безпомилкової передачі інформації у смузі частот `W` (Гц) між передавачем із `N_t` антенами та приймачем із `N_r` антенами.

Матрична модель радіоканалу описується рівнянням спостереження:

```
y = H·x + n
```

де `H` — комплексна канальна матриця розмірності `N_r × N_t`, `x` — вектор переданих символів із коваріаційною матрицею `R_xx = E[x · xᴴ]`, а `n ~ CN(0, N₀·I_{N_r})` — вектор адитивного білого просторово-некорельованого гаусового шуму з нульовим середнім і спектральною густиною потужності `N₀`.

Нижче наведено строге виведення формули взаємної інформації, ємності Шеннона–Телатара для детермінованого та ергодичного каналів, сингулярного розкладу (SVD), оптимізації потужності методом заповнення водою (Water-filling), аналізу матриць Вішарта та закону Марченка–Пастура, а також впливу просторової кореляції.

---

### 1. Виведення взаємної інформації багатовимірного каналу

Взаємна інформація між вектором переданих сигналів `x` та вектором прийнятих сигналів `y` визначається через різницю повної та умовної диференціальної ентропії:

```
I(x; y) = h(y) − h(y | x) = h(y) − h(n)
```

Відомо, що для фіксованої коваріаційної матриці диференціальна ентропія максимізується комплексним кругово-симетричним гаусовим розподілом. Оскільки шум `n` є гаусовим, максимальна ентропія `h(y)` досягається тоді, коли вхідний вектор `x` також є комплексним гаусовим вектором: `x ~ CN(0, R_xx)`.

Коваріаційна матриця прийнятого вектора `y` дорівнює:

```
R_yy = E[y · yᴴ] = E[(H·x + n)·(H·x + n)ᴴ] = H·R_xx·Hᴴ + N₀·I_{N_r}
```

Диференціальні ентропії комплексних гаусових векторів `y` та `n` розмірності `N_r` обчислюються за формулами:

```
h(y) = log₂ det( π·e · R_yy ) = log₂ det( π·e · (H·R_xx·Hᴴ + N₀·I_{N_r}) )
h(n) = log₂ det( π·e · R_nn ) = log₂ det( π·e · N₀·I_{N_r} )
```

Підставимо ці вирази у формулу взаємної інформації:

```
I(x; y)
= log₂ det(π·e · (H·R_xx·Hᴴ + N₀·I_{N_r})) − log₂ det(π·e · N₀·I_{N_r})    [підстановка ентропій виходу та шуму]
= log₂ det((H·R_xx·Hᴴ + N₀·I_{N_r}) · (N₀·I_{N_r})⁻¹)                       [властивість log(det A) − log(det B) = log(det(A·B⁻¹))]
= log₂ det(I_{N_r} + (1 / N₀) · H·R_xx·Hᴴ)                                  [спрощення матричного добутку]
```

Пропускна здатність каналу `C` є максимумом взаємної інформації за всіма можливими коваріаційними матрицями вхідного сигналу `R_xx` за умови обмеження на повну середню випромінювану потужність `Tr(R_xx) ≤ P_total`:

```
C = max_{R_xx ≥ 0, Tr(R_xx) ≤ P_total}  log₂ det(I_{N_r} + (1 / N₀) · H·R_xx·Hᴴ)
```

де `R_xx ≥ 0` позначає, що матриця `R_xx` є ермітовою та невід'ємно визначеною.

### 2. Ємність без інформації про стан каналу на передавачі (Open-Loop)

Якщо передавач не володіє інформацією про стан каналу (CSIT відсутня), а приймач знає канал точно (ідеальний CSIR), передавач не може віддати перевагу жодному з просторових напрямків. Оптимальною стратегією за принципом максимуму ентропії є рівномірний та некорельований розподіл потужності між усіма `N_t` антенами:

```
R_xx = (P_total / N_t) · I_{N_t}
```

Підставивши цей вираз у формулу взаємної інформації, отримуємо класичну формулу Телатара (1999 рік) для детермінованої матриці каналу:

```
C_OL = log₂ det( I_{N_r} + (P_total / (N_t · N₀)) · H · Hᴴ )   [біт/с/Гц]
```

Використовуючи тотожність Сільвестра для детермінантів `det(I_m + A·B) = det(I_n + B·A)`, формулу можна еквівалентно записати через матрицю розмірності `N_t × N_t`:

```
C_OL = log₂ det( I_{N_t} + (SNR / N_t) · Hᴴ · H )
```

де `SNR = P_total / N₀` — повне відношення сигнал/шум системи.

### 3. SVD-декомпозиція та перехід до ортогональних підканалів

Якщо передавач володіє повною інформацією про стан каналу (ідеальний CSIT), матрицю `H` розмірності `N_r × N_t` можна факторизувати за допомогою сингулярного розкладу (Singular Value Decomposition, SVD):

```
H = U · Σ · Vᴴ
```

де:
- `U` — унітарна матриця розмірності `N_r × N_r` (`Uᴴ·U = I_{N_r}`);
- `V` — унітарна матриця розмірності `N_t × N_t` (`Vᴴ·V = I_{N_t}`);
- `Σ` — прямокутна діагональна матриця розмірності `N_r × N_t`, на головній діагоналі якої стоять строго додатні сингулярні числа `σ₁ ≥ σ₂ ≥ … ≥ σ_r > 0`, де `r = rank(H) ≤ min(N_t, N_r)`.

Передавач виконує просторове прекодування, множачи вектор інформаційних символів `s = [s₁, s₂, …, s_r]ᵀ` на матрицю `V`: `x = V · s`. Потужність кожного `i`-го символу становить `E[|s_i|²] = P_i`. Завдяки унітарності матриці `V` сумарна випромінювана потужність зберігається:

```
Tr(R_xx) = Tr(V · R_ss · Vᴴ) = Tr(R_ss · Vᴴ·V) = Tr(R_ss) = ∑_{i=1}^r P_i ≤ P_total
```

Приймач фільтрує прийнятий вектор посткодером `Uᴴ`:

```
ỹ
= Uᴴ · y                                      [фільтрація прийнятого вектора посткодером Uᴴ]
= Uᴴ · (H·x + n)                              [підстановка рівняння спостереження y = Hx + n]
= Uᴴ · (U·Σ·Vᴴ · V·s + n)                     [підстановка SVD-розкладу каналу та прекодера x = Vs]
= (Uᴴ·U) · Σ · (Vᴴ·V) · s + Uᴴ·n              [групування унітарних добутків UᴴU = I та VᴴV = I]
= Σ · s + ñ                                   [отримання діагональної матричної моделі]
```

Оскільки матриця `U` унітарна, шум `ñ = Uᴴ·n` залишається білим гаусовим шумом з незмінною коваріаційною матрицею `E[ñ·ñᴴ] = Uᴴ·(N₀·I)·U = N₀·I`.

Матрична система з перехресними завадами повністю розпалася на `r` незалежних паралельних каналів Гауса:

```
ỹ_i = σ_i · s_i + ñ_i,      i = 1, 2, …, r
```

Відношення сигнал/шум у кожному `i`-му підканалі становить `SNR_i = (P_i · σ_i²) / N₀`. Сумарна пропускна здатність є сумою ємностей незалежних підканалів:

```
C = ∑_{i=1}^r log₂(1 + (P_i · σ_i²) / N₀)
```

### 4. Виведення розподілу потужності Water-filling (заповнення водою)

Задача максимізації пропускної здатності зводиться до оптимального розподілу сумарної потужності `P_total` між `r` власними підканалами:

```
max_{P₁, …, P_r}  ∑_{i=1}^r ln(1 + (P_i · σ_i²) / N₀)    при умовах  ∑_{i=1}^r P_i = P_total,  P_i ≥ 0
```

Складаємо функцію Лагранжа:

```
L(P₁, …, P_r, μ, λ) = ∑_{i=1}^r ln(1 + (P_i · σ_i²) / N₀) − μ · (∑_{i=1}^r P_i − P_total) + ∑_{i=1}^r λ_i · P_i
```

де `μ` — скалярний множник Лагранжа для обмеження сумарної потужності, а `λ_i ≥ 0` — множники для нерівностей `P_i ≥ 0`.

Застосуємо необхідні та достатні умови Каруша–Куна–Такера (KKT):

```
∂L / ∂P_i = (σ_i² / N₀) / (1 + (P_i · σ_i²) / N₀) − μ + λ_i = 0
λ_i · P_i = 0                                                 [умова доповняльної нежорсткості]
λ_i ≥ 0,  P_i ≥ 0,  μ > 0
```

Перепишемо перший дріб:

```
1 / (P_i + N₀ / σ_i²) = μ − λ_i
```

Розглянемо два випадки для кожного підканалу `i`:
1. **Підканал активний (`P_i > 0`):** за умовою доповняльної нежорсткості `λ_i = 0`. Тоді:
```
1 / (P_i + N₀ / σ_i²) = μ   ⇒   P_i + N₀ / σ_i² = 1 / μ ≡ μ_level
P_i = μ_level − N₀ / σ_i²
```
2. **Підканал неактивний (`P_i = 0`):** тоді `λ_i ≥ 0`, що означає:
```
1 / (N₀ / σ_i²) = μ − λ_i ≤ μ   ⇒   N₀ / σ_i² ≥ μ_level
```

Об'єднавши обидва результати, отримуємо аналітичний розв'язок Water-filling:

```
P_i = max(0,  μ_level − N₀ / σ_i²)
```

Значення рівня води `μ_level` знаходиться з рівняння нормування потужності:

```
∑_{i=1}^r max(0, μ_level − N₀ / σ_i²) = P_total
```

#### Ітеративний чисельний алгоритм Water-filling:
1. Впорядкувати підканали за спаданням якості: `σ₁² ≥ σ₂² ≥ … ≥ σ_r²` (відповідно, рівні дна `N₀/σ₁² ≤ N₀/σ₂² ≤ … ≤ N₀/σ_r²`).
2. Покласти кількість активних підканалів `k = r`.
3. Обчислити пробний рівень води:
```
μ_level = (1 / k) · ( P_total + ∑_{i=1}^k (N₀ / σ_i²) )
```
4. Якщо для найгіршого з поточних підканалів `N₀ / σ_k² > μ_level`, відкинути його (встановити `P_k = 0`), зменшити `k = k − 1` і повторити крок 3.
5. Зафіксувати фінальні потужності `P_i = μ_level − N₀ / σ_i²` для `i = 1, …, k`.

### 5. Ергодична ємність та комплексні матриці Вішарта

У каналах зі швидкими завмираннями коефіцієнти матриці `H` є випадковими величинами. Ергодична пропускна здатність `C_erg` визначається як математичне сподівання миттєвої ємності за всіма реалізаціями каналу:

```
C_erg = E_H[ log₂ det( I_{N_r} + (SNR / N_t) · H · Hᴴ ) ]
```

Матриця Грама `W = H · Hᴴ` (розмірності `m × m`, де `m = min(N_t, N_r)`, `n = max(N_t, N_r)`) є комплексною центральною матрицею Вішарта `CW_m(n, I)`. Її власні значення `λ_i = σ_i²` мають спільну густину ймовірності (Joint PDF):

```
p(λ₁, …, λ_m) = K_{m,n} · ∏_{i < j} (λ_i − λ_j)² · ∏_{i=1}^m λ_i^{n−m} · e^{−∑ λ_i}
```

Інтегруючи за цією густиною за допомогою ортогональних поліномів Лагерра, отримують замкнені аналітичні вирази для ергодичної ємності без потреби чисельного моделювання.

### 6. Ємність із перериваннями (Outage Capacity)

У квазістатичних каналах із повільними завмираннями (де час когерентності великий) ергодична ємність втрачає фізичний зміст, оскільки вся передача блоку даних відбувається за однієї фіксованої випадкової реалізації `H`.

Якщо миттєва ємність реалізації `C(H)` виявляється меншою за задану швидкість передачі `R`, декодер зазнає невідновної помилки (Outage Event). Пропускна здатність із перериваннями `C_out(p_out)` визначається як максимальна швидкість передачі, за якої ймовірність помилки не перевищує заданого порогу `p_out`:

```
P( C(H) < C_out(p_out) ) = p_out
```

При великій кількості антен розподіл випадкової величини `C(H)` наближається до нормального з математичним сподіванням `μ_C` та дисперсією `σ_C²`. Тоді ємність із перериваннями обчислюється через обернену функцію помилок:

```
C_out(p_out) ≈ μ_C − √2 · σ_C · erf⁻¹(1 − 2·p_out)
```

### 7. Асимптотичний закон Марченка–Пастура (Massive MIMO Limit)

Коли кількість антен на передавачі та приймачі прямує до нескінченності зі збереженням їхнього фіксованого співвідношення `β = N_t / N_r` (`N_t, N_r → ∞`), емпіричний спектральний розподіл власних значень матриці `(1 / N_t) · H · Hᴴ` за законом Марченка–Пастура сходиться до детермінованої густини:

```
f(λ) = (1 / (2π · β · λ)) · √( (λ_+ − λ) · (λ − λ_−) ),      λ_− ≤ λ ≤ λ_+
```

де границі спектра визначаються виразами `λ_± = (1 ± √β)²`.

Асимптотична ємність на одну приймальну антену прямує до строгого інтегралу:

```
lim_{N_r → ∞} ( C_erg / N_r ) = ∫_{λ_−}^{λ_+} log₂(1 + SNR · λ) · f(λ) dλ
```

Цей результат підтверджує, що в масивних системах MIMO ємність зростає строго детерміновано та лінійно з кількістю антен без жодних залишкових флуктуацій.

### 8. Вплив просторової кореляції та модель Кронекера

У реальних умовах обмеженого кутового розкиду променів просторові коефіцієнти каналу виявляються корельованими:

```
H = R_rx^(1/2) · H_w · (R_tx^(1/2))ᵀ
```

Просторова кореляція стягує спектр сингулярних чисел до нуля, різко зменшуючи ємність у режимі просторового мультиплексування за високих SNR.

#### Парадокс «замкової щілини» (Keyhole Effect)
Якщо між передавачем і приймачем існує єдине вузьке хвилевідне пляшкове горло, кореляційні матриці можуть бути одиничними (`R_tx = I`, `R_rx = I`), проте ранг каналу падає до одиниці (`rank(H) = 1`). Пропускна здатність деградує до рівня одноантенної системи, попри наявність багатьох просторових випромінювачів з обох боків.
