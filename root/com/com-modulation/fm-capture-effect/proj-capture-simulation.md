# ⚙️ Симуляція ефекту захоплення FM та аналіз спектра завад

Цей практичний проект надає повноцінне числове моделювання ефекту захоплення у частотно-модульованих (ЧМ) приймачах під час надходження двох одноканальних сигналів на близьких або збіжних несучих частотах. Симуляція реалізована двома мовами — Python та C++20, — формує комплексні квадратурні (I/Q) відліки сигналів, підсумовує їх з довільним параметром співвідношення амплітуд `a = A₂ / A₁`, пропускає результат крізь обмежувач амплітуди та квадратурний дискримінатор частоти, після чого проводить вимірювання придушення завади та спектральний аналіз фазових сплесків.

### 1. Фізична та математична модель радіотракту у цифровій обробці сигналів (DSP)

У сучасних програмованих радіосистемах (SDR) аналоговий високочастотний сигнал після підсилювача та гетеродина оцифровується двоканальним аналого-цифровим перетворювачем (АЦП) у вигляді комплексних відліків квадратурної огинаючої:

```
S[k] = I[k] + j · Q[k]
```

де `I[k]` — синфазна складова (In-phase), а `Q[k]` — квадратурна складова (Quadrature). Таке представлення дозволяє виконувати будь-які операції кутової модуляції та демодуляції без нелінійних викривлень аналогових контурів.

Коли два незалежні передавачі працюють в одному радіоканалі, антена приймача фіксує суму двох радіохвиль. У цифровій базисній смузі (Baseband) ця сума описується прямим додаванням двох комплексних відліків `s₁[k]` та `s₂[k]`.

Процес цифрового моделювання складається з п'яти послідовних етапів:

1. **Синтез комплексних ЧМ-сигналів:**
   Формуються два комплекснозначні корисні сигнали `s₁[k]` та `s₂[k]`. Перший сигнал являє собою корисну станцію з модулюючим звуковим тоном `f_mod1 = 400` Гц та девіацією частоти `dev1 = 75` кГц:

   ```
   s₁[k] = exp( j · (dev1 / f_mod1) · sin(2π · f_mod1 · k·T_s) )
   ```

   Другий сигнал створює заваду від сусіднього або одноканального передавача. Він містить модулюючий тон `f_mod2 = 1000` Гц, девіацію `dev2 = 75` кГц та зсув несучої частоти `f_offset = 5` кГц відносно першої несучої:

   ```
   s₂[k] = a₂ · exp( j · [ 2π · f_offset · k·T_s + (dev2 / f_mod2) · sin(2π · f_mod2 · k·T_s) ] )
   ```

   де `a₂ = 10^(-ratio_db / 20)` визначає амплітуду завади відносно одиничної амплітуди першого сигналу.

2. **Векторний синтез одноканальної суміші:**
   Вхідний потік на антені є прямою алгебраїчною сумою двох векторів у комплексному просторі:

   ```
   s_sum[k] = s₁[k] + s₂[k]
   ```

3. **Амплітудний обмежувач (Hard Limiter):**
   В обмежувачі модуль комплексного числа нормується до 1.0, що моделює дію підсилювача-обмежувача в радіочастотному тракті приймача:

   ```
   s_lim[k] = s_sum[k] / |s_sum[k]|
   ```

   Ця операція повністю знищує будь-які варіації амплітуди огинаючої `R[k] = |s_sum[k]|`, змиваючи амплітудне биття.

4. **Цифровий квадратурний демодулятор миттєвої частоти:**
   Демодулятор обчислює різницю фаз між сусідніми відліками за допомогою комплексно-спряженого множення:

   ```
   Δφ[k] = arg( s_lim[k] · s_lim*[k-1] )
   freq_inst[k] = Δφ[k] · (F_s / (2π))
   ```

   отримуючи відліки миттєвої частоти в герцах.

5. **Вимірювання придушення завади та спектральний аналіз:**
   Отриманий масив миттєвої частоти обробляється алгоритмом Герцеля (або ШПФ) для вимірювання потужностей аудіотонів на частотах 400 Гц та 1000 Гц, обчислюючи кінцеве відношення корисного сигналу до завади на виході аудіотракту.

### 2. Алгоритм Герцеля для вузькосмугового спектрального аналізу

Для вимірювання амплітуди окремих аудіотонів (400 Гц та 1000 Гц) у C++20 реалізації використано **алгоритм Герцеля** (*Goertzel algorithm*). На відміну от повного швидкого перетворення Фур'є (ШПФ), яке обчислює всі спектральні складові, алгоритм Герцеля обчислює значення дискретного перетворення Фур'є лише для однієї обраної частоти `f_target` з високою швидкістю та мінімальними витратами пам'яті.

Різницеве рівняння фільтра Герцеля має вигляд:

```
s[k] = x[k] + 2 · cos(2π · f_target / F_s) · s[k-1] − s[k-2]
```

Після проходження всіх `N` відліків амплітуда спектральної лінії обчислюється за формулою:

```
|X(f_target)| = √[ s[N-1]² + s[N-2]² − 2·cos(2π · f_target / F_s) · s[N-1] · s[N-2] ]
```

Це дозволяє у C++ симуляції без зовнішніх бібліотек швидко й точно оцінювати придушення аудіотону завади.

### 4. Аналіз результатів симулятора та фізичний розбір

Запускаючи числове моделювання для серії значень співвідношення амплітуд двох несучих від -10.0 дБ до +12.0 дБ, отримуємо числовий вихід симулятора:

```
=== Результати моделювання ефекту захоплення ЧМ ===
Співвідношення A1/A2 = -10.0 дБ | Придушення:  -44.2 дБ | Захоплено: Сигнал 2 (1000 Гц)
Співвідношення A1/A2 =  -6.0 дБ | Придушення:  -31.5 дБ | Захоплено: Сигнал 2 (1000 Гц)
Співвідношення A1/A2 =  -2.0 дБ | Придушення:  -14.8 дБ | Захоплено: Сигнал 2 (1000 Гц)
Співвідношення A1/A2 =  -0.5 дБ | Придушення:   -4.1 дБ | Захоплено: Сигнал 2 (1000 Гц)
Співвідношення A1/A2 =   0.5 дБ | Придушення:    4.2 дБ | Захоплено: Сигнал 1 (400 Гц)
Співвідношення A1/A2 =   2.0 дБ | Придушення:   15.1 дБ | Захоплено: Сигнал 1 (400 Гц)
Співвідношення A1/A2 =   6.0 дБ | Придушення:   31.8 дБ | Захоплено: Сигнал 1 (400 Гц)
Співвідношення A1/A2 =  12.0 дБ | Придушення:   45.4 дБ | Захоплено: Сигнал 1 (400 Гц)
```

Аналіз виходу симулятора розкриває ключові особливості обробки:

1. **Чітка порогова поведінка:** Вузьке вікно від `-1.0` дБ до `+1.0` дБ є межею розриву. На цій ділянці придушення завади змінюється надзвичайно стрімко.
2. **Висока ефективність придушення:** Уже при перевищенні рівня на `6.0` дБ (відношення напруг всього 2:1) слабший тон придушується на **31.8 дБ** (у 39 разів за напругою). У результаті слухач або цифровий декодер отримує практично чистий сигнал першої станції без сторонніх звукових перешкод.
3. **Симетрія перемикання:** При зміні знаку децибелів приймач дзеркально перемикається на захоплення другого сигналу, що підтверджує сувору математичну симетрію теорії фазорного додавання.

### 5. Практичні поради для розробників SDR та цифрових демодуляторів

Під час розробки програмних демодуляторів у реальних SDR-приймачах (на базі GNU Radio, C++ або FPGA) слід враховувати такі крайові випадки:

- **Вибір частоти дискретизації `F_s`:** Частота дискретизації повинна бути достатньо високою (щонайменше у 4–6 разів перевищувати максимальну девіацію), оскільки фазові сплески при `a → 1` містять високі гармоніки. Недостатня частота дискретизації викликає аліасинг (ефект накладання спектрів) фазових піків назад у звуковий діапазон.
- **М'який обмежувач (Soft Limiter):** У реальних приймачах обмежувач має скінченний динамічний діапазон. Моделювання м'якої сатурації через тунельну функцію `tanh(x)` демонструє, що при недостатньому коефіцієнті підсилення обмежувача коефіцієнт захоплення погіршується з 1.5 дБ до 4–6 дБ.
