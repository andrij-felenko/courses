# 🧮 Математичний аналіз і виведення миттєвої частоти при накладанні двох ЧМ-несучих

Коли у радіоприймач частотної модуляції одночасно потрапляють два когерентні або близькі за частотою гармонічні сигнали, їхній сумарний вплив на вході амплітудного обмежувача описується векторною сумою двох фазорів. Це виведення розгортає повну математичну теорію взаємодії двох несучих, показує виведення миттєвої частоти, її розкладання у ряд Фур'є, строгий доказ нульового середнього значення завади за умови `A₁ > A₂`, а також аналізує спектральний склад фазових сплесків та коефіцієнт гармонійних спотворень.

### 1. Постановка задачі та векторний синтез у комплексному базисі

Розглянемо два модульовані за частотою сигнали `s₁(t)` та `s₂(t)`, які надходять на вхідну антену приймача від двох різних передавачів на близьких несучих частотах `ω₁` та `ω₂`:

```
s₁(t) = A₁ · cos(ω₁·t + φ₁(t))
s₂(t) = A₂ · cos(ω₂·t + φ₂(t))
```

де `A₁` та `A₂` — константні або повільно змінювані амплітуди сигналів (`A₁ > 0`, `A₂ > 0`), `ω₁` та `ω₂` — несучі частоти, а `φ₁(t)` та `φ₂(t)` — корисні кутові модуляції (повідомлення). Припустимо без втрати загальності, що перший сигнал є сильнішим за другий: `A₁ > A₂`. Введемо безрозмірне відношення амплітуд:

```
a = A₂ / A₁ < 1
```

Представимо сумарне коливання `s(t) = s₁(t) + s₂(t)` у комплексному вигляді, винісши за дужки фазор першого (сильнішого) сигналу:

```
s(t) = Re{ A₁ · e^(j·[ω₁·t + φ₁(t)]) + A₂ · e^(j·[ω₂·t + φ₂(t)]) }
     = Re{ A₁ · e^(j·Φ₁(t)) · [ 1 + a · e^(j·θ(t)) ] }
```

де позначено:
- `Φ₁(t) = ω₁·t + φ₁(t)` — повна фаза сильного сигналу;
- `Φ₂(t) = ω₂·t + φ₂(t)` — повна фаза слабкого сигналу;
- `θ(t) = Φ₂(t) − Φ₁(t) = (ω₂ − ω₁)·t + (φ₂(t) − φ₁(t))` — мгновенна фазова розбудова (різниця повних фаз).

Позначимо різницю несучих частот як `Δω = ω₂ − ω₁`.

### 2. Розділення огинаючої та фазового зсуву завади

Розкладемо комплексний множник у дужках `1 + a · e^(j·θ)` на дійсну та уявну частини:

```
1 + a · e^(j·θ) = (1 + a·cos θ) + j · (a·sin θ)
```

Перейдемо до полярної форми `R_rel(θ) · e^(j·ψ(θ))`, де:

```
R_rel(θ) = √[ (1 + a·cos θ)² + (a·sin θ)² ]
         = √[ 1 + a² + 2a·cos θ ]

tan ψ(θ) = (a · sin θ) / (1 + a · cos θ)
```

Тут `R_rel(θ)` — відносна амплітудна огинаюча сумарного коливання, а `ψ(θ)` — додатковий фазовий зсув (фазова завада), накинутий слабким сигналом на фазу сильного сигналу.

Отже, сумарний сигнал на вході приймача записується у вигляді:

```
s(t) = A₁ · R_rel(θ(t)) · cos( Φ₁(t) + ψ(θ(t)) )
```

### 3. Механізм дії ідеального амплітудного обмежувача

Всі високоякісні ЧМ-приймачі містять після підсилювача проміжної частоти (ПЧ) каскад **амплітудного обмежувача** (*amplitude limiter*). Функціональне завдання обмежувача — зрізати будь-які зміни амплітуди `R_rel(θ(t))`, перетворюючи вхідне коливання на синусоїду зі сталою амплітудою `E₀`:

```
u_lim(t) = E₀ · cos( Φ₁(t) + ψ(θ(t)) )
         = E₀ · cos( ω₁·t + φ₁(t) + ψ(θ(t)) )
```

Після обмежувача вся амплітудна модуляція, викликана биттям двох сигналів, повністю змивається. Завада залишається виключно у фазовій правці `ψ(θ(t))`.

### 4. Диференціювання фази: миттєва частота на виході ЧМ-дискримінатора

Частотний дискримінатор або цифровий IQ-демодулятор обчислює миттєву частоту як похідну повної фази вихідного сигналу по часу:

```
ω_inst(t) = d/dt [ Φ₁(t) + ψ(θ(t)) ]
          = dΦ₁/dt + (dψ/dθ) · (dθ/dt)
          = ω₁ + dφ₁/dt + (dψ/dθ) · [ Δω + dφ₂/dt − dφ₁/dt ]
```

Знайдемо точний алгебраїчний вираз для похідної `dψ/dθ`. Використовуючи формулу похідної арктангенса `d/dx arctan(u(x)) = (1 / (1 + u²)) · du/dx`:

```
u(θ) = (a · sin θ) / (1 + a · cos θ)

du/dθ = [ (a·cos θ)·(1 + a·cos θ) − (a·sin θ)·(−a·sin θ) ] / (1 + a·cos θ)²
      = [ a·cos θ + a²·cos²θ + a²·sin²θ ] / (1 + a·cos θ)²
      = [ a² + a·cos θ ] / (1 + a·cos θ)²      [тригонометрична тотожність sin²θ + cos²θ = 1]

1 + u²(θ) = 1 + (a²·sin²θ) / (1 + a·cos θ)²
          = [ (1 + a·cos θ)² + a²·sin²θ ] / (1 + a·cos θ)²
          = [ 1 + a² + 2a·cos θ ] / (1 + a·cos θ)²

dψ/dθ = (du/dθ) / (1 + u²)
      = [ a² + a·cos θ ] / [ 1 + a² + 2a·cos θ ]
```

Підставляючи отриману похідну, отримуємо точну формулу для відхилення миттєвої частоти на виході дискримінатора:

```
ω_inst(t) = ω₁ + dφ₁/dt + (Δω + dφ₂/dt − dφ₁/dt) · [ (a² + a·cos θ) / (1 + a² + 2a·cos θ) ]
```

### 5. Теорема про нульове середнє значення завади за період биття

Обчислимо середнє значення коефіцієнта завади `f(θ) = dψ/dθ` на періоді биття `θ ∈ [−π, π]`:

```
⟨ dψ/dθ ⟩ = (1 / 2π) · ∫ [−π..π] [ (a² + a·cos θ) / (1 + a² + 2a·cos θ) ] dθ
```

Для обчислення цього інтеграла застосуємо метод контурного інтегрування у комплексній площині. Здійснимо заміну `z = e^(j·θ)`, де `cos θ = (z + z⁻¹) / 2` та `dθ = dz / (j·z)`. Інтегрування по `θ` від `-π` до `π` перетворюється на інтегрування по замкненому одиничному колу `|z| = 1`:

```
1 + a² + 2a·cos θ = 1 + a² + a·z + a·z⁻¹ = [ (1 + a·z)·(z + a) ] / z
a² + a·cos θ = a² + (a/2)·z + (a/2)·z⁻¹ = [ a·z² + 2a²·z + a ] / (2z)

(a² + a·cos θ) / (1 + a² + 2a·cos θ) = [ a·z² + 2a²·z + a ] / [ 2 · (1 + a·z)·(z + a) ]
```

Тоді інтеграл набуває вигляду:

```
I(a) = (1 / 2πj) · ∮ [|z|=1] [ a·z² + 2a²·z + a ] / [ 2·z · (1 + a·z)·(z + a) ] dz
```

Аналізуємо особливі точки (полюси) підінтегральної функції всередині контуру `|z| = 1`:

1. **Полюс у точці z₀ = 0:** Завжди лежить всередині контуру. Обчислюємо лишок у точці `z = 0`:

   ```
   Res(0) = lim [z→0] [ (a·z² + 2a²·z + a) / (2 · (1 + a·z)·(z + a)) ]
          = a / (2·a) = 1/2      [лишок у точці z = 0]
   ```

2. **Полюс у точці z₁ = −a:** Оскільки за умовою `a < 1`, цей полюс лежить **всередині** одиничного кола `|z| = 1`. Обчислюємо лишок у точці `z = −a`:

   ```
   Res(−a) = [ a·(−a)² + 2a²·(−a) + a ] / [ 2·(−a) · (1 − a²) ]
           = [ a³ − 2a³ + a ] / [ −2a · (1 − a²) ]
           = [ a · (1 − a²) ] / [ −2a · (1 − a²) ]
           = −1/2                 [лишок у точці z = −a]
   ```

3. **Полюс у точці z₂ = −1/a:** Оскільки `a < 1`, маємо `|z₂| = 1/a > 1`, тому цей полюс знаходиться **поза** одиничним колом і не враховується.

Сумуємо лишки всередині контуру:

```
I(a) = Res(0) + Res(−a) = (1/2) + (−1/2) = 0
```

Якщо ж навпаки, слабший сигнал стає сильнішим (`a > 1`), то полюс `z₁ = −a` виходить за межі одиничного кола, а полюс `z₂ = −1/a` входить всередину. Тоді лишок у точці `z₂` дорівнює `+1/2`, і сума лишків стає `Res(0) + Res(−1/a) = 1/2 + 1/2 = 1`.

Таким чином, маємо суворий математичний доказ порогового ефекту захоплення:

```
             ┌ 0 ,  якщо a < 1  (A₁ > A₂)
⟨ dψ/dθ ⟩ = ┤
             └ 1 ,  якщо a > 1  (A₂ > A₁)
```

### 6. Спектральний розклад фазової завади у ряд Фур'є

Оскільки функція `f(θ) = dψ/dθ` є парною та періодичною відносно `θ`, розкладемо її у ряд Фур'є по косинусах:

```
dψ/dθ = ∑ [k=1..∞] (-1)^(k+1) · a^k · cos(k·θ)
```

Інтегруючи по `θ`, отримуємо розклад фазової завади `ψ(θ)`:

```
ψ(θ) = ∑ [k=1..∞] (-1)^(k+1) · (a^k / k) · sin(k·θ)
```

Звідси видно, що фазова завада складається з вищих гармонік розбудови `θ(t) = Δω·t`. Для малих `a ≪ 1` панує перша гармоніка з амплітудою `a`. Але при наближенні `a → 1` косинусна сума перетворюється на послідовність дуже вузьких від'ємних імпульсів.

### 7. Екстремальні значення та амплітуда фазових сплесків

Знайдемо екстремуми миттєвої частоти завади `dψ/dθ`:

1. **Сінфазність (θ = 0, вектори додаються):**

   ```
   (dψ/dθ)|_(θ=0) = (a² + a) / (1 + a² + 2a)
                  = [ a · (a + 1) ] / (a + 1)²
                  = a / (1 + a)      [значення при сінфазності]
   ```

   Для `a = 0.9` це значення дорівнює `0.9 / 1.9 ≈ +0.473`.

2. **Протифазність (θ = ±π, вектори віднімаються):**

   ```
   (dψ/dθ)|_(θ=π) = (a² − a) / (1 + a² − 2a)
                  = [ −a · (1 − a) ] / (1 − a)²
                  = −a / (1 − a)     [значення при протифазності]
   ```

   Для `a = 0.9` це значення дорівнює `−0.9 / 0.1 = −9.0`.

При `a → 1` пікове від'ємне значення прямує до мінус безкінечності `-∞`. При протифазі вектори майже повністю гасять один одного, сумарний вектор `R(t) → 0`, і фаза сумарного сигналу повертається майже миттєво на 180°.

Оскільки площа цього від'ємного піку за період точно компенсується позитивною пологою ділянкою протягом решти періоду, аудіофільтр низьких частот (ФНЧ) зрізає всі високі гармоніки `k · Δω`, залишаючи на виході приймача чисто корисне повідомлення `dφ₁/dt` без зміщення постійної складової.

### 8. Розрахунок коефіцієнта нелінійних спотворень (THD)

Якщо різниця частот двох сигналів `Δω` потрапляє у звуковий діапазон (наприклад, `Δf = 3` кГц), гармоніки сплесків `k · Δf` не повністю відсікаються ФНЧ і викликають нелінійні спотворення (THD).

Загальна потужність фазового шуму обчислюється як сума квадратів амплітуд гармонік Фур'є:

```
P_noise = (1 / 2) · ∑ [k=1..∞] (a^k)² = (1 / 2) · [ a² / (1 − a²) ]
```

Відношення сигналу до шуму (SNR) на виході частотного демодулятора для девіації корисного сигналу `ΔF_dev` становить:

```
SNR_out = 20 · log10( ΔF_dev / (Δf · √[ a² / (2 · (1 − a²)) ]) )
```

Наприклад, при девіації широкосмугової ЧМ `ΔF_dev = 75` кГц, розбудові `Δf = 5` кГц та відношенні амплітуд `a = 0.5` (різниця рівнів 6 дБ):

```
SNR_out ≈ 20 · log10( 75000 / (5000 · √[ 0.25 / 1.5 ]) )
        ≈ 20 · log10( 75000 / 2041 ) ≈ 31.3 дБ
```

Це пояснює, чому навіть при відношенні амплітуд 6 дБ у частотній модуляції отримують високу якість звучання з придушенням завади понад 30 дБ, тоді як в AM це відношення дало б мізерні 6 дБ SNR.
