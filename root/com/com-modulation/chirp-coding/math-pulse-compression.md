# 🧮 Математика стиснення імпульсів і виграшу обробки

Ця вставка розв'язує фундаментальну математичну задачу теорії сигналів: доведення того, як стиснення імпульсу узгодженим фільтром перетворює тривалий ЛЧМ-сигнал тривалістю `T` та девіацією частоти `B` у вузький пік форми `sinc(π B t)` з тривалістю `τ ≈ 1/B`. Математичний вивід показує, чому саме узгоджений фільтр із комплексно-спряженою частотною характеристикою `H(f) = S*(f) · exp(-j 2 π f t_0)` є оптимальним оператором для максимізації відношення сигнал/шум (SNR) на тлі аддитивного білого гаусового шуму (AWGN).

Аналіз розкриває аналітичний механізм формування виграшу обробки (Processing Gain): завдяки когерентному накопиченню фази амплітуда стисненого відгуку зростає в `√(B · T)` разів, а вихідне відношення сигнал/шум збільшується в `D = B · T` разів порівняно з вхідним `SNR`. У цьому документі послідовно виведено сигнальну модель ЛЧМ, аналітичний спектр методом стаціонарної фази, автокореляційну функцію, структуру бічних пелюсток `sinc`-піку, функцію невизначеності та квантифіковано виграш обробки.

## 1. Фізична та аналітична модель ЛЧМ-сигналу

Розглянемо комплексний аналітичний сигнал ЛЧМ-імпульсу прямокутної огинаючої з амплітудою `A = 1`, тривалістю `T` та спектральною смугою `B`. Часовий інтервал сигналу симетризовано відносно нуля: `t ∈ [-T/2, T/2]`.

```
s(t) = rect(t / T) · exp(j · φ(t))
```

де віконна функція прямокутної форми визначена як:

```
rect(t / T) = 1  при |t| ≤ T / 2
rect(t / T) = 0  при |t| > T / 2
```

Закон зміни миттєвої фази `φ(t)` є квадратичною функцією часу:

```
φ(t) = 2 · π · f_0 · t + π · μ · t²
```

де `f_0` — початкова несуча частота у центрі імпульсу, а `μ` — швидкість кутового розгортання частоти (чирп-рейт), яка дорівнює відношенню смуги частот `B` до тривалості імпульсу `T`:

```
μ = B / T   [Гц/с]
```

Миттєва колова частота `ω(t)` обчислюється як перша похідна від фази за часом:

```
ω(t) = dφ(t) / dt = 2 · π · f_0 + 2 · π · μ · t
```

Відповідно, миттєва частота сигналу в герцах `f(t)` змінюється за лінійним законом:

```
f(t) = ω(t) / (2 · π) = f_0 + μ · t
```

У крайніх точках часового інтервалу `t = -T/2` та `t = +T/2` миттєва частота набуває значень:

```
f(-T/2) = f_0 - (B / 2)
f(+T/2) = f_0 + (B / 2)
```

Отже, повна девіація частоти протягом імпульсу дорівнює `f(+T/2) - f(-T/2) = B`.

Дійсна частина комплексного сигналу описує реальне радіочастотне коливання, яке випромінюється антеною передавача:

```
s_rf(t) = rect(t / T) · cos(2 · π · f_0 · t + π · μ · t²)
```

## 2. Спектр ЛЧМ-сигналу та метод стаціонарної фази

Пряме перетворення Фур'є для комплексного ЛЧМ-сигналу визначено інтегралом:

```
S(f) = ∫ s(t) · exp(-j · 2 · π · f · t) dt  [інтегрування від -T/2 до +T/2]
= ∫ exp(j · (2 · π · (f_0 - f) · t + π · μ · t²)) dt  [підстановка фази φ(t)]
```

Оскільки показник експоненти містить квадратичний член `t²`, інтеграл зводиться до інтегралів Френеля:

```
C(x) = ∫_0^x cos(π · u² / 2) du
S_fren(x) = ∫_0^x sin(π · u² / 2) du
```

Для великих значень часово-частотного добутку `D = B · T >> 1` (зазвичай `D > 10`) точне аналітичне значення спектра знаходять за допомогою **методу стаціонарної фази**.

Позначимо повну фазу підінтегрального виразу як `Ψ(t)`:

```
Ψ(t) = 2 · π · (f_0 - f) · t + π · μ · t²
```

Точка стаціонарної фази `t_s` визначається з умови нульової похідної `dΨ/dt = 0`:

```
dΨ/dt = 2 · π · (f_0 - f) + 2 · π · μ · t_s = 0  [умова стаціонарності]
⇒ t_s = (f - f_0) / μ                           [вираження точки стаціонарності]
```

Розкладемо фазу `Ψ(t)` у ряд Тейлора в околі точки стаціонарності `t_s`:

```
Ψ(t) ≈ Ψ(t_s) + 0.5 · Ψ''(t_s) · (t - t_s)²
```

Друга похідна дорівнює `Ψ''(t_s) = 2 · π · μ`. Значення фази у точці стаціонарності:

```
Ψ(t_s) = 2 · π · (f_0 - f) · ((f - f_0) / μ) + π · μ · ((f - f_0) / μ)²   [підстановка t_s в фазу]
= -2 · π · (f - f_0)² / μ + π · (f - f_0)² / μ                             [винесення мінуса з різниці]
= -π · (f - f_0)² / μ                                                      [зведення подібних доданків]
```

Тоді інтеграл методом стаціонарної фази спрощується до ґаусового інтеграла Френеля:

```
S(f) ≈ exp(j · Ψ(t_s)) · ∫ exp(j · π · μ · (t - t_s)²) dt
= exp(-j · π · (f - f_0)² / μ) · √(1 / μ) · exp(j · π / 4)
```

Метод стаціонарної фази стверджує, що для частот у межах смуги `f ∈ [f_0 - B/2, f_0 + B/2]` точка `t_s` лежить усередині інтервалу `[-T/2, T/2]`, і основний внесок в інтеграл дає окіл точки `t_s`. За межами смуги стаціонарна точка виходить за межі імпульсу, тому амплітуда спектра стрімко спадає до нуля.

Результат обчислення амплітудно-частотного `|S(f)|` та фазово-частотного `Arg(S(f))` спектра має вигляд:

```
|S(f)| ≈ 1 / √(μ) = √(T / B)    при |f - f_0| ≤ B / 2
|S(f)| ≈ 0                      при |f - f_0| > B / 2
```

```
Arg(S(f)) ≈ -π · (f - f_0)² / μ + π / 4
```

Таким чином, амплітудний спектр ЛЧМ-сигналу великої тривалості має практично прямокутну форму шириною `B` з плоскою вершиною, а фазовий спектр має квадратичну залежність від частоти `(f - f_0)²`.

Згідно з теоремою Парсеваля, спектральна щільність енергії `G(f) = |S(f)|²` дорівнює:

```
G(f) = T / B    при |f - f_0| ≤ B / 2
```

Інтегрування спектральної щільності за смугою `B` підтверджує збереження енергії сигналу: `∫ G(f) df = (T / B) · B = T`.

## 3. Теоретична оптимальність узгодженого фільтра

Приймання сигналу в умовах аддитивного білого гаусового шуму (AWGN) вимагає максимізації відношення сигнал/шум (SNR) у момент прийняття рішення. Згідно з нерівністю Коші-Буняковського, максимуму SNR на виході лінійного фільтра з імпульсною характеристикою `h(t)` досягається тоді й лише тоді, коли частотна характеристика фільтра `H(f)` є комплексно-спряженою до спектра вхідного корисного сигналу `S(f)` із довільною часовою затримкою `t_0`:

```
H(f) = K · S*(f) · exp(-j · 2 · π · f · t_0)
```

Застосовуючи обернене перетворення Фур'є, отримуємо часову імпульсну характеристику узгодженого фільтра `h(t)`:

```
h(t) = K · s*(t_0 - t)
```

Приймаючи нормувальний коефіцієнт `K = 1` та часовий зсув `t_0 = 0` для аналізу автокореляційної функції:

```
h(t) = rect(t / T) · exp(-j · π · μ · t²)
```

Імпульсна характеристика узгодженого фільтра є часовим дзеркальним відображенням вхідного чирпа. У частотній області фазова характеристика фільтра дорівнює `+π · (f - f_0)² / μ`. Вона повністю компенсує квадратичну фазу вхідного сигналу `-π · (f - f_0)² / μ`, роблячи фази всіх частотних компонентів однаковими в момент часу `t = 0`.

## 4. Строгий вивід згортки та формули стисненого сигналу

Вихідний сигнал узгодженого фільтра `y(t)` обчислюється як згортка вхідного комплексного сигналу `s(t)` з імпульсною характеристикою `h(t)`:

```
y(t) = ∫ s(τ) · h(t - τ) dτ
```

Підставимо математичні вирази для `s(τ)` та `h(t - τ)`:

```
s(τ) = rect(τ / T) · exp(j · π · μ · τ²)
h(t - τ) = rect((t - τ) / T) · exp(-j · π · μ · (t - τ)²)
```

Разом інтеграл згортки набуває вигляду:

```
y(t) = ∫ rect(τ / T) · rect((t - τ) / T) · exp(j · π · μ · τ²) · exp(-j · π · μ · (t - τ)²) dτ
```

Розкриємо квадрат у показнику другої експоненти:

```
(t - τ)² = t² - 2 · t · τ + τ²
```

Тоді підінтегральний показник експоненти перетворюється:

```
j · π · μ · τ² - j · π · μ · (t² - 2 · t · τ + τ²)
= j · π · μ · τ² - j · π · μ · t² + j · 2 · π · μ · t · τ - j · π · μ · τ²  [розкриття дужок]
= -j · π · μ · t² + j · 2 · π · μ · t · τ                                  [взаємне скорочення τ²]
```

Квадратичний член `τ²` повністю взаємно знищується. Член `-j · π · μ · t²` не залежить від змінної інтегрування `τ`, тому його можна винести за знак інтеграла:

```
y(t) = exp(-j · π · μ · t²) · ∫ rect(τ / T) · rect((t - τ) / T) · exp(j · 2 · π · μ · t · τ) dτ
```

Для малих часових зсувів `|t| << T` перекриття двох прямокутних вікон `rect(τ / T)` та `rect((t - τ) / T)` відбувається на інтервалі `τ ∈ [-T/2 + |t|/2, T/2 - |t|/2]`. Знехтувавши малим крайнім зрізом для `|t| << T`, межі інтегрування приймаємо як `[-T/2, T/2]`:

```
y(t) ≈ exp(-j · π · μ · t²) · ∫ exp(j · 2 · π · μ · t · τ) dτ   [інтегрування від -T/2 до +T/2]
```

Інтеграл від комплексної експоненти обчислюється за стандартною формулою:

```
∫ exp(j · a · τ) dτ = (1 / (j · a)) · [exp(j · a · T / 2) - exp(-j · a · T / 2)]  [первісна експоненти]
= (2 / a) · sin(a · T / 2)                                                      [формула Ейлера для синуса]
```

Поклавши `a = 2 · π · μ · t`:

```
∫ exp(j · 2 · π · μ · t · τ) dτ
= (2 / (2 · π · μ · t)) · sin(π · μ · t · T)    [підстановка параметра a]
= (1 / (π · μ · t)) · sin(π · (B / T) · t · T)  [спрощення дробу 2/2 та підстановка μ = B/T]
= T · [sin(π · B · t) / (π · B · t)]            [множення й ділення знаменника на T]
= T · sinc(π · B · t)                           [заміна на нормовану функцію sinc]
```

Отже, остаточний математичний вираз для вихідного сигналу узгодженого фільтра дорівнює:

```
y(t) = T · sinc(π · B · t) · exp(-j · π · (B / T) · t²)
```

де нормована функція `sinc` визначена як `sinc(x) = sin(x) / x`.

## 5. Аналіз характеристик стисненого імпульсу та бічних пелюсток

Амплітудна огинаюча вихідного сигналу дорівнює модулю від виразу `y(t)`:

```
|y(t)| = T · |sinc(π · B · t)| = T · |sin(π · B · t) / (π · B · t)|
```

З цієї аналітичної формули випливають ключові геометричні й фізичні параметри стисненого імпульсу:

1. **Максимальна пікова амплітуда:**
   У момент часу `t = 0` за границею `lim_{x→0} sinc(x) = 1` отримуємо:
```
|y(0)| = T
```
   Амплітуда вихідного піку дорівнює тривалості вхідного імпульсу `T`. Порівняно з вхідною амплітудою `A = 1` приріст амплітуди становить `T` разів.

2. **Положення нулів та ширина головного піку:**
   Функція `sinc(π · B · t)` дорівнює нулю при `π · B · t = ±k · π` для цілих `k = 1, 2, 3...`.
   Перші нулі з обох боків від центрального піку виникають у моментах часу:
```
t_zero = ± 1 / B
```
   Повна ширина головної пелюстки стисненого імпульсу між першими нуля становить:
```
Δt_zero = 2 / B
```
   Ширина піку за рівнем половинної потужності (-3 dB, де `sinc(x) = 1 / √2 ≈ 0.707`) дорівнює:
```
τ_3dB ≈ 0.886 / B ≈ 1 / B
```

3. **Коефіцієнт стиснення імпульсу (Compression Ratio):**
   Відношення початкової тривалості прямокутного імпульсу `T` до ширини стисненого піку `τ_3dB`:
```
K_comp = T / τ_3dB = T / (1 / B) = B · T = D
```
   Коефіцієнт стиснення імпульсу строго дорівнює часово-частотному добутку `D = B · T`.

4. **Рівень бічних пелюсток та віконна обробка:**
   Найближчі бічні максимуми функції `sinc(x)` виникають при `x ≈ ±1.43 · π` і мають амплітуду:
```
|sinc(1.43 · π)| ≈ 1 / (1.43 · π) ≈ 0.217
```
   У логарифмічному масштабі відношення першої бічної пелюстки до головного піку становить:
```
SLL = 20 · lg(0.217) ≈ -13.26 dB
```
   У радіолокації та зв'язку рівень бічних пелюсток `-13.26 dB` часто є недостатнім, оскільки сильний стиснений пік від близької цілі або потужного некооперативного символу може замаскувати слабкий суміжний пік.
   Для придушення бічних пелюсток застосовують **зважувальні віконні функції** (Хеммінга, Ганна або Тейлора) у частотній області узгодженого фільтра. Наприклад, використання вікна Хеммінга знижує рівень бічних пелюсток до `-43 dB`, однак платою за це є розширення головного піку приблизно на 40% (до `τ_3dB ≈ 1.4 / B`) та втрата відношення сигнал/шум близько `1.34 dB`.

## 6. Функція невизначеності ЛЧМ-сигналу та часово-доплерівське зв'язування

Двовимірна функція невизначеності `χ(τ, ν)` (Ambiguity Function) описує відгук узгодженого фільтра на імпульс із часовим зсувом `τ` та доплерівським зсувом частоти `ν`:

```
χ(τ, ν) = ∫ s(t) · s*(t - τ) · exp(j · 2 · π · ν · t) dt
```

Для прямокутного ЛЧМ-сигналу модуль функції невизначеності має вигляд:

```
|χ(τ, ν)| = (T - |τ|) · |sinc(π · (ν + μ · τ) · (T - |τ|))|   при |τ| ≤ T
```

Графічно поверхня `|χ(τ, ν)|` являє собою вузький косий гребінь, витягнутий вздовж лінії `ν + μ · τ = 0` у площині «часова затримка — доплерівська частота».

Це явище називають **часово-доплерівським зв'язуванням** (Time-Doppler Coupling):
- Якщо вхідний сигнал зазнає доплерівського зміщення частоти `ν = Δf_Dop`, то лінія гребеня зміщує точку максимуму узгодженого фільтра за часом на величину:
```
Δτ = -ν / μ = -Δf_Dop / (B / T) = -Δf_Dop · (T / B)
```
- Зміщення частоти на `Δf_Dop` не зруйнує стиснення імпульсу й не зменшить його амплітуду, а лише зсуне момент появи стисненого піку на `Δτ`.
- У симетричних системах зв'язку (таких як LoRa) для розділення затримки та доплерівського зсуву передають послідовність висхідних чирпів (Up-Chirps), за якими йдуть два низхідні чирпи (Down-Chirps). Зсув Up-чирпа за часом дорівнює `τ_up = τ_delay - Δf_Dop / μ`, а Down-чирпа — `τ_down = τ_delay + Δf_Dop / μ`. Додавання та віднімання виміряних часових позначок дає змогу точно й незалежно знайти як точну затримку `τ_delay`, так и доплерівську частоту `Δf_Dop`.

## 7. Взаємно-кореляційні властивості чирпів із різними чирп-рейтами

У багаторадіоканальних системах зв'язку важливо аналізувати взаємну заваду між чирп-сигналами `s_1(t)` та `s_2(t)`, які мають різні чирп-рейти `μ_1 ≠ μ_2` (наприклад, символи з SF7 та SF12).

Взаємно-кореляційний інтеграл двох чирпів описується виразом:

```
R_12(τ) = ∫ s_1(t) · s_2*(t - τ) dt
= ∫ exp(j · π · μ_1 · t²) · exp(-j · π · μ_2 · (t - τ)²) dt
```

При множенні сигналів квадратичні фази з різними коефіцієнтами `μ_1` та `μ_2` не скасовуються повністю, а формують новий чирп із різницевою фазовою прискореністю `Δμ = μ_1 - μ_2`:

```
φ_cross(t) = π · (μ_1 - μ_2) · t² + 2 · π · μ_2 · τ · t - π · μ_2 · τ²
```

Оскільки різницевий сигнал залишається чирпом із широким спектром, його амплітуда при проходженні узгодженого фільтра не формує високого стисненого піку, а розмазується по часовому інтервалу. Максимальне значення взаємно-кореляційного огибання при `μ_1 ≠ μ_2` не перевищує:

```
max |R_12(τ)| ≈ 1 / √(|μ_1 - μ_2|)
```

У логарифмічних децибелах це забезпечує міжсимвольну ізоляцію від 16 dB до 22 dB між сигналами з різними Spreading Factors (SF), дозволяючи їм співіснувати на однаковій центральній частоті.

## 8. Дискретна математична модель для FFT-дечирпінгу

У цифрових модемах дискретизація комплексного сигналу виконується із частотою `F_s = B`. Інтервал дискретизації становить `T_s = 1 / F_s = 1 / B`.

Кількість дискретних відліків `N` в одному чирп-символі дорівнює:

```
N = T / T_s = T · B = 2^SF
```

Дискретний аналітичний висхідний чирп для відліків `n ∈ [0, N - 1]` описується формулою:

```
s[n] = exp(j · π · (n² / N))
```

Дискретний циклічно зсунутий чирп для символу `k ∈ [0, N - 1]` визначається як:

```
s_k[n] = exp(j · π · (((n + k) mod N)² / N))
```

Локальний опорний Down-Chirp приймача в дискретному часі дорівнює:

```
h_down[n] = exp(-j · π · (n² / N))
```

Множення прийнятого вектора `s_k[n]` на опорний `h_down[n]` у дискретному часі дає:

```
v_mix[n] = s_k[n] · h_down[n] = exp(j · 2 · π · (k · n / N) + j · ϕ_const)
```

де `ϕ_const = π · k² / N` — постійна фазовий зсув для даного символу `k`.

Дискретне перетворення Фур'є (DFT) від вектора `v_mix[n]` обчислюється як:

```
V[m] = ∑_{n=0}^{N-1} v_mix[n] · exp(-j · 2 · π · m · n / N)
= exp(j · ϕ_const) · ∑_{n=0}^{N-1} exp(j · 2 · π · ((k - m) · n / N))
```

Оскільки сума комплексно-ортогональних гармонік ортогональна:

```
V[m] = N · exp(j · ϕ_const)  при m = k
V[m] = 0                    при m ≠ k
```

Модуль відліків спектра дорівнює `|V[m]| = N` при `m = k` та `0` при всіх інших `m ≠ k`.

## 9. Аналіз витоку спектральної енергії (Spectral Leakage)

Коли дробова частина циклічного зсуву частоти не відповідає точно цілому біну DFT, виникає явище витоку спектральної енергії в сусідні біни `k ± 1` та `k ± 2`.

Оцінка частки енергії в центральному біні визначається відношенням:

```
η_leak = |V[k]|² / ∑_{m=0}^{N-1} |V[m]|²
```

Для прямокутного вікна без інтерполяції при дробовому частотному зсуві `δ ∈ (-0.5, 0.5)` величина `η_leak` знижується до `(sin(π · δ) / (π · δ))² ≈ 0.405` (-3.92 dB), що вимагає застосування додаткової 3-точкової параболічної або ґаусової інтерполяції спектральних піків у цифрових приймачах LoRa.

## 10. Обчислювальна складність FFT-дечирпінгу

Застосування алгоритму дечирпінгу з наступним швидким перетворенням Фур'є (FFT) принципово знижує обчислювальні витрати цифрового процесора обробки сигналів (DSP).

Пряме обчислення кореляції прийнятого чирп-сигналу з `N` можливими еталонними циклічними чирпами у часовій області вимагає `N²` комплексних множень та додавань. При `SF = 12` (`N = 4096`) це потребує понад 16.7 мільйона операцій на кожен переданий символ.

Схема дечирпінгу виконує:
1. `N` комплексних множень вектора сигналу на один опорний Down-Chirp: `O(N)`.
2. Одне Швидке Перетворення Фур'є (Кулі-Тьюкі FFT): `O(N · log2(N))`.

Загальне число операцій для `SF = 12` становить лише `4096 + 4096 · 12 = 53248` операцій, що в 315 разів менше за пряму кореляцію. Вона дає змогу реалізовувати декодування циклічних чирпів у реальному часі на мікроконтролерах з ARM Cortex-M4 із плаваючою крапкою або дешевих FPGA.

## 11. Строгий вивід виграшу обробки (Processing Gain)

Виграш обробки (Processing Gain, PG) характеризує підвищення відношення сигнал/шум (SNR) завдяки узгодженій фільтрації або дечирпінгу.

### Потужність сигналу на виході

Вхідний сигнал має амплітуду `A = 1` та тривалість `T`. Повна енергія сигналу дорівнює:

```
E_s = ∫ |s(t)|² dt = 1² · T = T
```

Пікова амплітуда стисненого піку на виході узгодженого фільтра дорівнює `y(0) = T`. Відповідно, пікова потужність вихідного корисного сигналу дорівнює квадрату амплітуди:

```
P_signal_out = |y(0)|² = T²
```

### Потужність шуму на виході

Нехай на вхід узгодженого фільтра надходить аддитивний білий гаусів шум `n(t)` із двосторонньою спектральною щільністю потужності `N_0 / 2` [Вт/Гц].

Дисперсія (потужність) шуму на виході узгодженого фільтра з імпульсною характеристикою `h(t)` обчислюється як:

```
P_noise_out = (N_0 / 2) · ∫ |h(t)|² dt
```

Оскільки `|h(t)| = rect(t / T) · |exp(-j · π · μ · t²)| = 1` на інтервалі тривалості `T`:

```
∫ |h(t)|² dt = T
```

Отже, потужність вихідного шуму дорівнює:

```
P_noise_out = (N_0 / 2) · T
```

### Обчислення вихідного та вхідного SNR

Вихідне відношення сигнал/шум у момент появи максимального піку `t = 0` становить:

```
SNR_out = P_signal_out / P_noise_out = T² / ((N_0 / 2) · T) = 2 · T / N_0 = 2 · E_s / N_0
```

На входом радіоприймача зі смугою пропускання `B` вхідна потужність шуму дорівнює `P_noise_in = N_0 · B`. Вхідна середня потужність сигналу дорівнює `P_signal_in = E_s / T = 1`.

Отже, вхідне відношення сигнал/шум у смузі `B` дорівнює:

```
SNR_in = P_signal_in / P_noise_in = 1 / (N_0 · B)
```

Знайдемо відношення `SNR_out` до `SNR_in`:

```
SNR_out / SNR_in = (2 · E_s / N_0) / (1 / (N_0 · B)) = 2 · E_s · B = 2 · (T) · B = 2 · (B · T)
```

Переходячи до логарифмічних децибельних одиниць (приймаючи нормування потужності за двостороннім спектром):

```
PG = 10 · lg(SNR_out / SNR_in) = 10 · lg(B · T)  [dB]
```

Виграш обробки в децибелах строго дорівнює десяти логарифмам від часово-частотного добутку `B · T`.

### Чисельний розрахунок для LoRa CSS

У системах циклічного чирп-кодування LoRa ширина смуги `B` пов'язана з тривалістю чирпа `T` через коефіцієнт розширення `SF ∈ [6, 12]`:

```
T = 2^SF / B  ⇒  B · T = 2^SF
```

Тоді виграш обробки дорівнює:

```
PG = 10 · lg(2^SF) = SF · 10 · lg(2) ≈ 3.0103 · SF  [dB]
```

Для різних значень `SF`:
- При `SF = 7`: `PG = 10 · lg(128) ≈ 21.07 dB`
- При `SF = 10`: `PG = 10 · lg(1024) ≈ 30.10 dB`
- При `SF = 12`: `PG = 10 · lg(4096) ≈ 36.12 dB`

Саме цей математичний виграш у `36.12 dB` дозволяє декодеру LoRa впевнено виділяти сигнальний пік із бінів FFT навіть при вхідному SNR рівному `-20 dB`.
