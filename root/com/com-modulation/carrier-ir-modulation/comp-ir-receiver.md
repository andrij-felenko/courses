# 🔌 Інтегровані ІЧ-приймачі: устрій, АРУ та підключення

Інтегровані інфрачервоні приймачі (серій TSOP38238, TSOP4838, HS0038, CRM38) являють собою завершені аналогово-цифрові системи на одному кремнієвому кристалі. Вони призначені для прийому інфрачервоних світлових сигналів, модульованих високочастотною піднесною (30, 33, 36, 38, 40 або 56 кГц), відсівання фонових завад і формування прямокутного цифрового сигналу з активним низьким рівнем (Active LOW) для подальшої обробки мікроконтролером.

### Структурна схема та внутрішні блоки TSOP

Усередині компактного триконтактного пластикового корпусу інтегровано два основні компоненти: кремнієвий PIN-фотодіод з великою площею фоточутливої поверхні та спеціалізована мікросхема обробки сигналу (ASIC).

```
 ┌─────────────────────────────────────────────────────────────────────────┐
 │                            ІНТЕГРОВАНИЙ ПРИЙМАЧ                         │
 │                                                                         │
 │  ┌───────────┐    ┌───────┐    ┌───────┐    ┌─────────┐    ┌─────────┐  │
 │  │ PIN-фото- │───>│  TIA  │───>│  AGC  │───>│ Смуговий│───>│ Демоду- │  │
 │  │  діод     │    │підсил.│    │ підси-│    │ фільтр  │    │ лятор + │  │
 │  └───────────┘    └───────┘    │ лювач │    │ 38 кГц  │    │ компара-│  │
 │                                └───────┘    └─────────┘    │ тор     │  │
 │                                    ▲             │         └────┬────┘  │
 │                                    └─────────────┴──────────────┘       │
 │                                          Петля зворотного зв'язку       │
 └───────────────────────────────────────────────────────────────────┬─────┘
                                                                     │
                                                                 OUT (Active LOW)
```

Внутрішній тракт мікросхеми містить шість функціональних вузлів:

1. **PIN-фотодіод:** Має високошвидкісну p-i-n структуру з товстим неекранованим i-шаром. Спектральна чутливість `S(λ)` має чіткий максимум на довжині хвилі 940 нм, що ідеально збігається з довжиною хвилі випромінювання ІЧ-світлодіодів на основі GaAs. Власна бар'єрна ємність становить `C_j ≈ 40..80 пФ`.
2. **Трансімпедансний підсилювач (TIA):** Перетворює змінний фотострум фотодіода у напругу. Оскільки вхідний струм від сонячного світла може досягати кількох міліампер, TIA має нелінійну (логарифмічну) характеристику для запобігання передчасному насиченню.
3. **Підсилювач із автоматичним регулюванням підсилення (АРУ / AGC):** Оцінює амплітуду вихідного сигналу та регулює коефіцієнт підсилення в діапазоні до 80 дБ. АРУ працює з двома постійними часу: швидкою атакою (`τ_attack ≈ 200 мкс`) для придушення раптових світлових сплесків та повільним спадом (`τ_decay ≈ 20 мс`) для підтримки стабільної чутливості під час прийому кадру.
4. **Активний смуговий фільтр (Bandpass Filter):** Реалізований за технологією перемикальних конденсаторів (Switched-Capacitor Filter). Фільтр має 4-й порядок та добротність `Q ≈ 9.5`, що забезпечує вузьку смугу пропускання `38 ± 2 кГц` та загасання не менше 60 дБ для завад на частотах нижче 1 кГц.
5. **Демодулятор та інтегратор:** Випрямляє високочастотні коливання 38 кГц та накопичує заряд на внутрішній ємності. Для підтвердження наявності пачки лічильник повинен зафіксувати від 6 до 10 послідовних циклів несучої.
6. **Вихідний тригер Шмітта та NPN-транзистор:** Формує логічний вихід з відкритим колектором (Open-Collector) та внутрішньою підтяжкою `R_pullup ≈ 30 кОм`.

### Призначення контактив та пастки розпіновки

Модуль приймача виготовляється в 3-вивідному пластиковому корпусі. Передня опукла частина корпусу працює як лінза Френеля, що збільшує кут огляду до ±45°.

Таблиця стандартного призначення контактів (серії TSOP382xx / TSOP483xx):

| № контакту | Назва | Тип | Опис та функціональне призначення |
| :--- | :--- | :--- | :--- |
| **1** | **OUT** | Цифровий вихід | Вихід з відкритим колектором (Active LOW). За відсутності сигналу рівень `VCC` (HIGH). При виявленні пачки 38 кГц падає в 0 В (LOW). |
| **2** | **GND** | Живлення | Спільний провід системи. |
| **3** | **VCC** | Живлення | Напруга живлення від 2.7 В до 5.5 В. Струм споживання у режимі очікування становить 0.35–0.9 мА. |

> ⚠️ **Пастка призначення виводів:** Різні конструктивні серії приймачів мають **різну розпіновку** при абсолютно однаковому вигляді корпусу! Наприклад, у серії TSOP1738 контакт 1 — це GND, 2 — VCC, 3 — OUT. У серії TSOP4838 контакт 1 — OUT, 2 — GND, 3 — VCC. Переплутування `VCC` та `GND` призводить до миттєвого теплового пробою аналогового підсилювача. Обов'язково звіряйте маркування з технічним описом (datasheet).

### Класифікація приймачів за типами АРУ (AGC2, AGC4, AGC5)

Виробники (зокрема Vishay Semiconductors) випускають приймачі з різними модифікаціями схеми АРУ, оптимізованими під конкретні умови завад:

- **AGC2 / AGC8 (Стандартні):** Призначені для традиційних протоколів (NEC, RC-5, Toshiba). Забезпечують максимальну чутливість у тихих приміщеннях.
- **AGC4 / AGC3 (Для складних умов):** Мають прискорену реакцію АРУ. Оптимізовані для прийому коротких пачок та придушення завад від люмінесцентних ламп із димерами.
- **AGC5 / AGC7 (Надвисока завадостійкість):** Застосовуються в умовах екстремального оптичного шуму (наприклад, поряд із плазмовими панелями або потужними світлодіодними прожекторами).

### Схема обв'язки живлення та EMC-рекомендації

Високий коефіцієнт підсилення аналогового тракту (понад 100 000) робить приймач вразливим до пульсацій по лінії живлення `VCC`. Блимання світлодіодів індикації, робота ШІМ-контролерів або імпульсних перетворювачів на тій самій шині живлення можуть викликати хибні спрацьовування.

Для надійної роботи в реальних пристроях обов'язково застосовують зовнішній RC-фільтр:

```
  VCC (3.3V / 5V) ───[ R1: 100 Ом ]───┬─── VCC приймача (pin 3)
                                       │
                                   [ C1: 0.1 мкФ ] (кераміка X7R)
                                       │
  GND ─────────────────────────────────┴─── GND приймача (pin 2)
```

1. Резистор `R1 = 100 Ом` обмежує високочастотні струми пульсацій.
2. Керамічний конденсатор `C1 = 0.1 мкФ` (100 нФ) розміщують на друкованій платі **безпосередньо біля виводів** приймача (на відстані не більше 5 мм).
3. Під корпусом приймача на друкованій платі рекомендується заливати суцільний шар землі (GND plane) для екранування від електромагнітних наводок.
