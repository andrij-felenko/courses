# 🧮 Енергетичний штраф PAM4: чому подвоєння бітів коштує 9.54 дБ

Коли лінійний передавач переходить від двійкового кодування NRZ до чотирирівневого PAM4, він пакує два біти в один часовий такт (символ). Здавалося б, пропускна здатність подвоюється задарма. Проте закони електродинаміки та теорії інформації вимагають плати: якщо зберегти незмінним повний розмах напруги передавача, відстань між сусідніми рівнями неминуче зменшується втричі. Менша відстань означає, що значно слабший шум здатен збити приймач з пантелику.

Нижче наведено строге математичне виведення енергетичного штрафу (англ. *SNR penalty*), обчислення ймовірності символьної помилки (SER), доведення ролі коду Грея у зниженні бітової помилки (BER) та розрахунок середньої потужності сигнального сузір'я.

---

### Геометрія рівнів: поділ амплітудного розмаху

Розгляньмо лінійний драйвер із симетричним діапазоном напруги від `−V₀` до `+V₀`. Повний розмах сигналу від піку до піку (англ. *peak-to-peak voltage*, `V_pp`) становить:

```
V_pp
= (+V₀) − (−V₀)          [визначення розмаху напруги між крайніми станами]
= 2·V₀                   [повний амплітудний інтервал передавача]
```

У двійковій модуляції NRZ (M = 2) використовуються лише два крайні рівні: `−V₀` (логічний нуль) та `+V₀` (логічна одиниця). Відстань між рівнями `d_NRZ` дорівнює всьому розмаху:

```
d_NRZ
= V_pp / (2 − 1)         [відстань між рівнями для двійкового сигналу]
= 2·V₀                   [відстань між нулем та одиницею в NRZ]
```

Поріг розпізнавання в ідеальному симетричному приймачі NRZ встановлюється рівно посередині — на рівні `0 В`. Щоб шум спричинив помилку, його миттєва амплітуда мусить перевищити половину відстані між рівнями, тобто запас завадостійкості (англ. *noise margin*) становить:

```
Margin_NRZ
= d_NRZ / 2              [половина відстані між сусідніми рівнями]
= (2·V₀) / 2             [підстановка d_NRZ]
= V₀                     [максимально допустима амплітуда шуму без помилки]
```

У чотирирівневій модуляції PAM4 (M = 4) той самий розмах `V_pp = 2·V₀` рівномірно ділиться на чотири рівні: `L0`, `L1`, `L2`, `L3`. Кількість проміжків між чотирма рівнями дорівнює `M − 1 = 3`. Відповідно, відстань між сусідніми рівнями `d_PAM4` становить:

```
d_PAM4
= V_pp / (M − 1)         [загальна формула відстані між M рівновіддаленими рівнями]
= 2·V₀ / (4 − 1)         [підстановка M = 4 для PAM4]
= (2/3)·V₀               [відстань між сусідніми рівнями PAM4]
= d_NRZ / 3              [відстань рівно втричі менша за відстань у NRZ]
```

Нормовані рівні напруги PAM4 набувають фіксованих значень:

```
L3 = +V₀                 [найвищий рівень, символ «10»]
L2 = +V₀ / 3             [верхній внутрішній рівень, символ «11»]
L1 = −V₀ / 3             [нижній внутрішній рівень, символ «01»]
L0 = −V₀                 [найнижчий рівень, символ «00»]
```

Запас завадостійкості для кожного з трьох очей PAM4 дорівнює половині відстані між рівнями:

```
Margin_PAM4
= d_PAM4 / 2             [половина мікрозвалу між сусідніми станами]
= ((2/3)·V₀) / 2         [підстановка d_PAM4]
= V₀ / 3                 [запас стійкості до шуму для PAM4]
= Margin_NRZ / 3         [запас зменшився рівно втричі порівняно з NRZ]
```

### Розрахунок амплітудного штрафу SNR у децибелах

Оскільки висота розкриття очка приймача зменшилася втричі, амплітуда сигналу, доступна для подолання теплового шуму, скоротилася в 3 рази. Відношення сигнал/шум за напругою зменшується у 3 рази, що у логарифмічній шкалі децибелів становить:

```
SNR_penalty_voltage
= 20 · log₁₀(Margin_PAM4 / Margin_NRZ)    [визначення втрати відношення амплітуд у дБ]
= 20 · log₁₀((V₀ / 3) / V₀)              [підстановка значень запасу завадостійкості]
= 20 · log₁₀(1 / 3)                      [спрощення дробу]
= −20 · log₁₀(3)                         [властивість логарифма: log(1/x) = -log(x)]
≈ −20 · 0.4771212547                     [десятковий логарифм трійки]
≈ −9.5424 дБ                             [точний енергетичний штраф PAM4 за амплітудою]
```

Цей результат означає: щоб отримати таку саму висоту розкриття кожного з трьох очей PAM4, як в одного очка NRZ, передавач мусив би збільшити напругу утричі, що збільшило б споживану електричну потужність у `3² = 9` разів (на `9.54 дБ`).

### Середня потужність сузір'я PAM4 проти NRZ

Перевіримо середню потужність сигналу при передачі випадкових рівноймовірних даних. Нехай навантаження каналу становить нормований опір `R = 1 Ом`.

Для NRZ з рівнями `+V₀` та `−V₀` миттєва потужність на кожному такті однакова:

```
P_NRZ
= (1/2) · (+V₀)² + (1/2) · (−V₀)²        [математичне сподівання потужності двох рівнів]
= (1/2) · V₀² + (1/2) · V₀²              [піднесення до квадрата]
= V₀²                                    [середня потужність NRZ сигналу]
```

Для PAM4 з рівнями `−V₀, −V₀/3, +V₀/3, +V₀` середня потужність становить середнє арифметичне квадратів усіх чотирьох станів:

```
P_PAM4
= (1/4) · [ (−V₀)² + (−V₀/3)² + (+V₀/3)² + (+V₀)² ]   [середнє за 4 рівноймовірними рівнями]
= (1/4) · [ V₀² + V₀²/9 + V₀²/9 + V₀² ]               [розкриття квадратів]
= (1/4) · [ 2·V₀² + (2/9)·V₀² ]                       [групування доданків]
= (1/4) · [ (18/9)·V₀² + (2/9)·V₀² ]                  [зведення до спільного знаменника]
= (1/4) · (20/9)·V₀²                                  [додавання дробів]
= (5/9) · V₀²                                         [середня потужність сигналу PAM4]
≈ 0.5556 · V₀²                                        [PAM4 має на 44.4% меншу середню потужність за фіксованого піку]
```

Якщо зафіксувати не пікову напругу `V_pp`, а однакову середню потужність `P_avg` для обох модуляторів, відстань між рівнями PAM4 дещо скоригується, проте сумарний програш за енергією на один переданий біт (`E_b / N₀`) для досягнення однакового BER усе одно становить близько `9.5 дБ`.

### Ймовірність символьної помилки (SER)

Нехай канал містить адитивний білий гаусів шум (AWGN) із нульовим середнім та дисперсією `σ²`. Густина ймовірності шуму описується функцією Гауса. Ймовірність того, що шум перевищить поріг `Margin = d / 2`, задається стандартною `Q`-функцією:

```
Q(x) = (1 / √(2·π)) · ∫[x..∞] exp(−t² / 2) dt
```

Розгляньмо поведінку чотирьох символів PAM4 під дією шуму:
1. **Внутрішні рівні (`L1 = −V₀/3` та `L2 = +V₀/3`)**: мають сусідів з обох боків (зверху і знизу). Помилка виникає, якщо шум вийде за межі `[−d/2, +d/2]`. Ймовірність помилки для внутрішнього рівня:
   ```
   P_err_inner = 2 · Q( d_PAM4 / (2·σ) )
   ```
2. **Зовнішні рівні (`L0 = −V₀` та `L3 = +V₀`)**: мають сусіда лише з одного боку. Шум у бік зовнішньої межі не призводить до перетину порогу рішення. Ймовірність помилки для крайнього рівня:
   ```
   P_err_outer = 1 · Q( d_PAM4 / (2·σ) )
   ```

Оскільки всі чотири символи передаються з однаковою ймовірністю `1/4`, середня ймовірність символьної помилки (англ. *Symbol Error Rate*, `SER`) дорівнює:

```
SER_PAM4
= (1/4) · [ P_err_outer + P_err_inner + P_err_inner + P_err_outer ]   [зважена сума за всіма рівнями]
= (1/4) · [ 1·Q + 2·Q + 2·Q + 1·Q ]                                  [підстановка складових з Q(d/2σ)]
= (1/4) · 6 · Q( d_PAM4 / (2·σ) )                                    [підсумовування доданків]
= (3/2) · Q( d_PAM4 / (2·σ) )                                        [теоретична формула SER для PAM4]
```

Для порівняння, у двійковому сигналі NRZ обидва рівні є крайніми (мають лише один поріг `0 В`), тому ймовірність бітової помилки NRZ становить:

```
BER_NRZ = Q( d_NRZ / (2·σ) ) = Q( V₀ / σ )
```

Підставивши `d_PAM4 = d_NRZ / 3 = (2/3)·V₀`, отримуємо точне співвідношення для PAM4:

```
SER_PAM4
= (3/2) · Q( ((2/3)·V₀) / (2·σ) )        [підстановка d_PAM4 через V₀]
= (3/2) · Q( V₀ / (3·σ) )                [аргумент Q-функції зменшився рівно втричі]
```

Оскільки `Q(x)` спадає експоненційно зі зростанням аргументу (як `exp(−x²/2)`), зменшення аргументу втричі спричиняє колосальний стрибок ймовірності помилки за однакового рівня шуму `σ`.

### Зв'язок SER та BER: чому код Грея ділить помилки навпіл

Кожен символ PAM4 несе `k = log₂(4) = 2` біти інформації. Зв'язок між символьною помилкою (SER) та бітовою помилкою (BER) критично залежить від таблиці відображення бітів у рівні напруги.

За помірного та високого відношення сигнал/шум переважна більшість помилок (понад 99%) спричинена переходом шуму в **найближчий сусідній рівень** (наприклад, `L1 → L2` або `L2 → L3`). Переходи через один чи два рівні вимагають викиду шуму з амплітудою `> 3·d/2` чи `> 5·d/2`, що через крутий спад гаусового розподілу трапляється на багато порядків рідше.

#### Варіант 1: Прямий натуральний двійковий код (Binary Mapping)

Розгляньмо пряме двійкове кодування: `L0=00, L1=01, L2=10, L3=11`.

Підрахуємо кількість бітових помилок при переходах між сусідніми станами:
- Перехід `L0 (00) ↔ L1 (01)`: змінюється 1 біт (відстань Геммінга `d_H = 1`).
- Перехід `L1 (01) ↔ L2 (10)`: змінюються **обидва біти** (`d_H = 2`).
- Перехід `L2 (10) ↔ L3 (11)`: змінюється 1 біт (`d_H = 1`).

Середня кількість бітових помилок на одну символьну помилку становить:

```
Bits_per_SymErr_binary
= (1/3) · (1 + 2 + 1)                    [середня відстань Геммінга для 3 можливих сусідніх переходів]
= 4 / 3 ≈ 1.333                          [на кожну помилку символу припадає 1.33 бітових збої]
```

Відповідно, бітова помилка становить:

```
BER_binary
= SER · (Bits_per_SymErr_binary / 2)     [ділення на кількість бітів у символі k=2]
= SER · ((4/3) / 2)                      [підстановка середнього числа помилок]
= (2/3) · SER                            [бітова помилка становить 66.7% від символьної]
```

#### Варіант 2: Кодування Грея (Gray Mapping)

У коді Грея таблиця будується так, щоб будь-які два сусідні рівні напруги відрізнялися **рівно в одному бітовому розряді**:
- `L3 (+V₀)   = 10`
- `L2 (+V₀/3) = 11`  (відрізняється від L3 лише молодшим бітом)
- `L1 (−V₀/3) = 01`  (відрізняється від L2 лише старшим бітом)
- `L0 (−V₀)   = 00`  (відрізняється від L1 лише молодшим бітом)

Перевіримо всі три сусідні переходи:
- `L0 (00) ↔ L1 (01)`: `d_H = 1` (помилка в молодшому біті).
- `L1 (01) ↔ L2 (11)`: `d_H = 1` (помилка в старшому біті).
- `L2 (11) ↔ L3 (10)`: `d_H = 1` (помилка в молодшому біті).

У **100% випадків** одиночного помилкового переходу в сусідній рівень страждає рівно один біт з двох. Оскільки символ містить 2 біти, ймовірність бітової помилки дорівнює:

```
BER_Gray
= SER_PAM4 · (1 / log₂(M))               [перехід від SER до BER за одиничної відстані Геммінга]
= SER_PAM4 / 2                           [кожна символьна помилка дає рівно одну бітову з двох]
= ((3/2) · Q( V₀ / (3·σ) )) / 2          [підстановка формули SER_PAM4]
= (3/4) · Q( V₀ / (3·σ) )                [підсумкова аналітична формула BER для Gray PAM4]
```

Застосування коду Грея зменшує результуючий бітовий потік помилок на чверть порівняно з натуральним двійковим кодом (`BER_Gray = 0.50·SER` проти `BER_binary = 0.67·SER`), що суттєво полегшує роботу блоку виправлення помилок FEC.

### Підсумкова порівняльна таблиця характеристик

| Параметр | Двійковий NRZ | Модуляція PAM4 | Фізичний наслідок для каналу |
|---|---|---|---|
| **Бітів на символ (`k`)** | 1 біт | 2 біти | Подвоєння швидкості даних за тієї самої символьної частоти |
| **Частота Найквіста (`f_N`)** | `f_bit / 2` | `f_bit / 4` | Зменшення робочої частоти в 2 рази скорочує згасання в міді на 12–18 дБ |
| **Кількість порогів рішення** | 1 поріг (`0 В`) | 3 пороги (`−2V₀/3, 0, +2V₀/3`) | Потрібно 3 компаратори (слайсери) замість одного |
| **Висота очка (`H_eye`)** | `2·V₀` | `(2/3)·V₀` | Звуження апертури відкриття рівно втричі |
| **Запас завадостійкості** | `V₀` | `V₀ / 3` | Зниження допустимої амплітуди шуму в 3 рази |

| **Формула BER (Gray)** | `Q(V₀ / σ)` | `(3/4)·Q(V₀ / (3·σ))` | Експоненційний зсув кривої BER вправо на 9.54 дБ |
