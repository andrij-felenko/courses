# 𧰨 Математика та фізика модуляції навантаженням і магнітного зв'язку

Математичний апарат аналізу Near Field Communication (NFC) спирається на теорію зв'язаних контурів у ближній зоні електромагнітного поля. На відміну від системи дальнього поля, де випромінювання описується хвильовим рівнянням з характерним хвильовим опором вільного простору `377 Ом`, у радіусі `r < λ / (2·π)` (для частоти `13.56 МГц` довжина хвилі `λ ≈ 22.1 м`, тому межа становить близько `3.5 м`) домінує магнітна складова індукції.

Взаємодія пристрою зчитування та безконтактної мітки описується моделями нелінійних зв'язаних електричних кіл, де передача енергії й зворотна передача даних відбуваються через спільний магнітний потік.

## 1. Модель взаємної індуктивності та наведена ЕРС

Розглянемо дві коаксіально розташовані котушки: первинну котушку зчитувача (PCD) з індуктивністю `L1` та числом витків `N1` і вторинну котушку пасивної мітки (PICC) з індуктивністю `L2` та числом витків `N2`.

При проходженні через котушку зчитувача змінного струму `I1(t) = I1 · sin(ω·t)` з коловою частотою `ω = 2·π·f_c` (де `f_c = 13.56 МГц`), у центрі антени створюється магнітне поле з напруженістю `H1`. Напруженість поля залежить від струму, кількості витків та геометричного радіуса котушки.

Взаємна індуктивність `M` між двома котушками визначається геометричними параметрами контурів, числом витків та безрозмірним коефіцієнтом зв'язку `k`:

```
M = k · √(L1 · L2)
```

Коефіцієнт зв'язку `k` для коротких відстаней залежить від радіуса антени зчитувача `R1`, радіуса антени мітки `R2` та осьової відстані між ними `x`:

```
k(x) ≈ (R1² · R2²) / (√(R1 · R2) · (R1² + x²)^(3/2))
```

Зниження коефіцієнта зв'язку `k` з відстанню описується кубічною залежністю `1 / x³`. Це означає, що при збільшенні відстані між зчитувачем та міткою у два рази наведена напруга зменшується у вісім разів. Для типових друкованих антен зчитувача радіусом `R1 = 35 мм` та мітки `R2 = 15 мм` на відстані `x = 20 мм` коефіцієнт зв'язку становить близько `k ≈ 0.03 – 0.05`.

Магнітний потік `Φ21`, що пронизує витки котушки мітки, лінійно залежить від струму зчитувача `I1` та взаємної індуктивності `M`:

```
Φ21 = M · I1
```

За законом електромагнітної індукції Фарадея ЕРС `V2`, наведена у котушці мітки, дорівнює швидкості зміни магнітного потоку, взятій зі зворотним знаком. Оскільки струм змінюється за гармонічним законом, похідна струму по часу вносить фазовий зсув на `90°` (косинусоїдальна залежність):

```
V2 = - dΦ21 / dt
= - M · (dI1 / dt)           [підстановка струму I1(t) = I1·sin(ω·t)]
= - ω · M · I1 · cos(ω·t)    [похідна sin(ω·t) по t дорівнює ω·cos(ω·t)]
```

Амплітудне значення наведеної напруги на відкритому контурі мітки `V2_open` становить:

```
V2_open = ω · M · I1
```

Оскільки напруга `V2_open` має бути достатньою для відкриття випрямляльних діодів та живлення мікросхеми мітки (мінімальна робоча напруга живлення `V_min ≈ 1.8 – 3.0 В`), існує критична межа мінімальної напруженості магнітного поля `H_min ≈ 1.5 А/м`. Якщо напруженість випромінюваного поля падає нижче цієї межі, мікросхема мітки вимикається через недостатність енергії.

## 2. Резонанс вторинного контуру та випрямлення

Для максимального збільшення наведеної напруги котушка антени мітки `L2` паралельно з'єднується з внутрішньою ємністю мікросхеми `C2`, утворюючи паралельний резонансний контур, настроєний на частоту несучої `f_c = 13.56 МГц`. Резонансне посилення дозволяє компенсувати мале значення коефіцієнта зв'язку `k` на межі радіуса дії.

Колова резонансна частота `ω0` та добротність контуру `Q2` задаються виразами:

```
ω0 = 1 / √(L2 · C2)          [умова резонансу: ω0 = 2·π·13.56 МГц]

Q2 = R_load / (ω0 · L2)      [де R_load — еквівалентний опір навантаження]
```

При точній настройці контуру на частоту несучої напруга на вході випрямляча мітки `V_in` зростає пропорційно добротності `Q2`:

```
V_in = Q2 · V2_open
= Q2 · ω0 · M · I1
```

Типові значення добротності для пасивних NFC-міток лежать у межах `Q2 ≈ 20 – 35`. Занадто висока добротність (`Q2 > 50`) звужує смугу пропускання контуру `Δf = f_c / Q2`. Це призводить до спотворення коротких імпульсів амплітудної модуляції (ASK 100%), викликаючи зрізання часових пауз Modified Miller та помилки виявлення фронтів сигналу зчитувачем.

Динаміка затухання та наростання коливань у резонансному контурі мітки під час 100% амплітудної паузи описується диференціальним рівнянням другого порядку з постійною часу затухання `τ`:

```
τ = (2 · L2) / R_loss = (2 · Q2) / ω0
```

Для частоти `13.56 МГц` та добротності `Q2 = 30` постійна часу становить `τ ≈ 0.7 мкс`. Це гарантує, що за час паузи Modified Miller (`2.3 – 3.0 мкс`) амплітуда коливань в контурі встигає впасти практично до нуля, забезпечуючи чітке розпізнавання паузи детектором мітки.

Випрямляч мітки на базі діодного моста Шотткі перетворює високочастотне коливання `13.56 МГц` на постійну напругу `V_DC`. Для стабілізації напруги при зміні відстані до зчитувача у мікросхему вбудовують обмежувальний шунтувальний регулятор (Limiter/Shunt Regulator), який скидає надлишок напруги при наближенні мітки до антени PCD на відстань менше 1 см, запобігаючи електричному пробою тонких діелектричних шарів CMOS-транзисторів.

При розрахунку випрямляча враховується пряме падіння напруги на діодах `V_d ≈ 0.3 В`. Ефективна постійна напруга живлення кристала визначається з урахуванням пікового значення резонансного коливання:

```
V_DC = (2 / π) · V_in - 2 · V_d
```

При вихідній напрузі на котушці `V_in = 5.0 В` випрямлена постійна напруга становить `V_DC ≈ 2.58 В`, що повністю достатньо для стійкого функціонування внутрішнього мікроконтролера та блоків пам'яті EEPROM.

## 3. Відбитий імпеданс та виведення модуляції навантаженням

Під час передачі даних від мітки до зчитувача мітка не генерує власний радіосигнал, а змінює свій внутрішній опір `Z2`. Зміна опору мітки за законом електромагнітної індукції трансформується у зміну імпедансу котушки зчитувача.

Запишемо систему рівнянь для двох зв'язаних контурів у комплексній формі, де `j` — уявна одиниця:

```
V1 = I1 · Z1 + j·ω·M · I2    [рівняння первинного контуру зчитувача]

0 = j·ω·M · I1 + I2 · Z2     [рівняння вторинного контуру мітки]
```

З другого рівняння виразимо комплексний струм у котушці мітки `I2`:

```
I2 = - (j·ω·M · I1) / Z2
```

Підставимо отримане значення струму `I2` у перше рівняння для контуру зчитувача:

```
V1 = I1 · Z1 + j·ω·M · (- (j·ω·M · I1) / Z2)
= I1 · Z1 + (ω² · M² · I1) / Z2       [враховано тотожність j² = -1]
= I1 · (Z1 + (ω² · M² / Z2))          [винесення струму I1 за дужки]
```

Величина `Z_ref`, на яку змінюється опір антени зчитувача внаслідок присутності мітки, називається **відбитим імпедансом** (Reflected Impedance):

```
Z_ref = (ω² · M²) / Z2
```

Фізичний зміст відбитого імпедансу полягає у тому, що будь-яка зміна навантаження у вторинній котушці мітки миттєво відображається на первинному контурі зчитувача. Коли мітка здійснює модуляцію навантаженням, вона підключає паралельно до контуру додатковий шунтуючий опір `R_mod` за допомогою ключового польового транзистора. Це змінює повний імпеданс мітки від стану `Z2_unmod` до стану `Z2_mod`:

```
Z2_mod = (Z2_unmod · R_mod) / (Z2_unmod + R_mod)
```

Зміна відбитого імпедансу на антені зчитувача `ΔZ_ref` визначає амплітуду сигналу відгуку, який детектується амплітудним або фазовим демодулятором зчитувача:

```
ΔZ_ref = Z_ref(mod) - Z_ref(unmod)
= ω² · M² · (1 / Z2_mod - 1 / Z2_unmod)
```

Оскільки коефіцієнт зв'язку `k` малий, величина відносної зміни напруги на антені зчитувача `ΔV1 / V1` становить частки відсотка (від `0.1%` до `2%`). Детектування такого малого сигналу вимагає застосування високочутливих синхронних або квадратурних (I/Q) демодуляторів у складі аналогового фронтенду зчитувача.

## 4. Спектральний аналіз піднесучої 848 кГц та фазова модуляція BPSK

Щоб надійно виділити сигнал `ΔZ_ref` на тлі потужного власного коливання зчитувача `13.56 МГц`, шунтуючий транзистор мітки перемикається не постійним рівнем біта, а з допоміжною піднесучою частотою `f_s = 848 кГц` (`13.56 МГц / 16`).

Математично процесор модуляції мітки перемножує інформаційний сигнал даних `d(t)` (де `d(t) ∈ {-1, 1}`) на прямокутне коливання піднесучої `s(t)` з частотою `f_s`.

Розкладемо прямокутне коливання піднесучої `s(t)` у ряд Фур'є:

```
s(t) = (4 / π) · ∑ [ (1 / (2·n - 1)) · sin((2·n - 1) · ω_s · t) ]
```

Підставивши першу гармоніку рядка Фур'є (`n = 1`) у вираз для результуючого відбитого сигналу на антені зчитувача `v_rx(t)`, отримуємо добуток трьох сигнальних складових:

```
v_rx(t) = V1 · sin(ω_c · t) + A_mod · d(t) · sin(ω_s · t) · sin(ω_c · t)
```

Застосуємо тригонометричну тотожність для розкладання добутку двох синусів у суму косинусів:

```
sin(α) · sin(β) = (1/2) · [cos(α - β) - cos(α + β)]
```

Підставивши `α = ω_c · t` та `β = ω_s · t`, отримуємо підсумкове спектральне розкладання відбитого сигналу:

```
v_rx(t) = V1 · sin(ω_c · t)
        + (A_mod / 2) · d(t) · cos((ω_c - ω_s) · t)
        - (A_mod / 2) · d(t) · cos((ω_c + ω_s) · t)
```

Аналіз отриманого виразу показує, що модуляція навантаженням на піднесучій частоті переносить інформаційний спектр у дві бічні бічні смуги:
- Нижня бічна смуга (LSB): `f_LSB = f_c - f_s = 13.56 МГц - 0.848 МГц = 12.712 МГц`.
- Верхня бічна смуга (USB): `f_USB = f_c + f_s = 13.56 МГц + 0.848 МГц = 14.408 МГц`.

У протоколі ISO 14443 Type B піднесуча додатково модулюється за фазою (BPSK). Зсув фази піднесучої на `180°` супроводжується інверсією знаку фазового кута `φ(t)`:

```
s_bpsk(t) = sin(ω_s · t + φ(t))    [де φ(t) = 0 для '1' та φ(t) = π для '0']
```

При демодуляції у зчитувачі квадратурний змішувач множить прийнятий сигнал на відновлені опорні синусоїдальне `cos(ω_c · t)` та косинусоїдальне `sin(ω_c · t)` коливання. Після фільтрації низьких частот виділяються I- та Q-складові піднесучої, що дозволяє декодувати фазовий зсув BPSK незалежно від амплітудних завад у каналі.

Формування фазового зсуву BPSK забезпечує вищу завадостійкість порівняно з амплітудною модуляцією Type A, оскільки фазові переходи краще розрізняються при малому рівні відбитого сигналу від далеких міток.

Отримані I- та Q-компоненти після цифрового полосового фільтра перетворюються аналого-цифровим перетворювачем (АЦП) зчитувача. Амплітуда виділеного вектора `A_demod = √(I² + Q²)` інформує про рівень сигналу мітки, а кут `θ = arctan(Q / I)` відновлює інформаційну фазу піднесучої BPSK.

Розрахунок допустимої фазової помилки `Δθ_max` при квадратурній демодуляції обмежується сектором `±45°`. Якщо кутове відхилення перевищує цей поріг через фазовий шум гетеродина або нелінійність підсилювача, виникають помилки бітових символів (Bit Error Rate, BER).

## 5. Розрахунок енергетичного балансу та ККД

Ефективність передачі енергії `η` від зчитувача до мітки в умовах слабозв'язаних контурів визначається добротностями обох антен `Q1`, `Q2` та коефіцієнтом зв'язку `k`:

```
η = (k² · Q1 · Q2) / (1 + √(1 + k² · Q1 · Q2)²)
```

Для виникнення стійкого зв'язку необхідно виконати умову критичного зв'язку. Умова означає, що добуток добротностей та квадрата коефіцієнта зв'язку повинен перевищувати одиницю:

```
k² · Q1 · Q2 ≥ 1
```

Якщо `k² · Q1 · Q2 < 1` (система в недозв'язаному стані), наведена напруга падає нижче порогу живлення мікросхеми мітки, і обмін даними стає неможливим.

Розрахунок споживаної потужності зчитувача `P1` для забезпечення необхідної напруженості поля `H` на відстані `x` виконується за формулою:

```
P1 = (H² · (R1² + x²)³) / (Q1 · R1⁴)
```

Отже, збільшення дальності читання `x` вимагає кубічного зростання потужності передавача зчитувача або оптимізації геометрії антени `R1` та підвищення добротності `Q1`. Врахування теплових втрат в антенному контурі задається активним опором витків котушки, який зростає на частоті `13.56 МГц` через скін-ефект у мідних провідниках плати. Глибина скін-шару міді `δ` на цій частоті становить близько `17.8 мкм`.

Розрахунок товщини провідника антени вибирається з умови `w_copper ≥ 2·δ ≈ 36 мкм`, що відповідає стандартній фольгованій міді друкованих плат вагою 1 унція на квадратний фут (1 oz copper).

Використання феритових підкладок для захисту антени від наближених металевих поверхонь змінює еквівалентну індуктивність `L1` за рахунок комплексної магнітної проникності матеріалу `μ = μ' - j·μ''`. Дійсна частина `μ'` збільшує індуктивність котушки, компенсуючи розстроювання, а уявна частина `μ''` визначає магнітні втрати на гістерезис та вихрові струми у фериті, знижуючи добротність `Q1`.

## 6. Вплив паразитних параметрів та узгодження антен

У реальних конструкціях антена зчитувача являє собою друковану котушку на платі, що має власну паразитною ємність `C_par` та послідовний опір втрат `R_loss`. Для передачі максимальної потужності від вихідного каскаду підсилювача зчитувача (з вихідним опором `50 Ом`) до антени застосовують симетричний L- або C-подібний узгоджувальний контур (Matching Network).

Еквівалентний опір антени на частоті `13.56 МГц` перераховується з урахуванням добротності:

```
Z_ant = R_loss + j · ω_c · L1
```

Узгоджувальний контур трансформує комплексний опір `Z_ant` у чистий активний опір `50 Ом` та зрізає вищі гармоніки несучої за допомогою фільтра низьких частот (EMC Filter), запобігаючи випромінюванню завад на частотах другої (`27.12 МГц`) та третьої (`40.68 МГц`) гармонік.

Розрахунок ємностей узгоджувального C-контуру `C1` (послідовна ємність) та `C2` (паралельна ємність) здійснюється за формулами:

```
C1 = 1 / (ω_c · √(R_out · R_loss - R_loss²))

C2 = (1 / (ω_c² · L1)) · (1 - √(R_loss / R_out))
```

Для типової планарної котушки індуктивністю `L1 = 1.0 мкГн` та опором втрат `R_loss = 1.5 Ом` при вихідному опорі передавача `R_out = 50 Ом` розраховані значення ємностей узгодження становлять `C1 ≈ 27 пФ` та `C2 ≈ 110 пФ`.

Співвідношення трансформації імпедансів `Z_in / Z_ant` змінюється у динаміці при наближенні мітки через внесення відбитого опору `Z_ref`. Для запобігання перевантаженню вихідного каскаду передавача зчитувача (PCD) вихідний опір підсилювача розраховують із запасом по струму натягу.

Паразитний ємнісний зв'язок між антеною та руками користувача або акумулятором смартфона зсуває резонансну частоту антени з `13.56 МГц` вниз до `12.8 – 13.1 МГц`. Для розширення робочої смуги та зменшення чутливості до розстроювання опір втрат антени навмисно збільшують шунтувальними резисторами, знижуючи добротність антени зчитувача до робочого значення `Q1 ≈ 10 – 15`. Це забезпечує стабільну передачу сигналів амплітудної модуляції з короткими фронтами наростання та спаду без розриву зв'язку.
