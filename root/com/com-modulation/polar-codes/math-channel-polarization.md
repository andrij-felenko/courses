# 🧮 Математика поляризації каналів

Поляризація каналу — це твердження про **границю**. Беремо N однакових посередніх каналів, застосовуємо оборотне перетворення й отримуємо N синтетичних; за великого N кожен із них виявляється або майже досконалим, або майже глухим, а посередині майже нічого не лишається. Слово «майже» тут не риторика, а збіжність, яку треба довести. А щоб її довести, потрібне число, яке робить три речі одразу: міряє непридатність каналу, підкоряється чіткій рекурсії при перетворенні й напряму обмежує ймовірність помилки. Пропускна здатність для цього не найзручніша — вона усереднює й ховає саме те, за чим ми женемося. Найгостріше знаряддя тут — параметр Бгаттачар'ї.

## Ще одне число, коли вже є пропускна здатність

[Взаємна інформація I(W)](root:math-information/mutual-information) каже, скільки бітів у середньому проходить каналом за одне використання: 1 — канал ідеальний, 0 — глухий. Це правильна відповідь на питання «скільки», але для доказу поляризації її замало. Нам треба стежити не за середнім по всіх каналах, а за **кожним** синтетичним каналом окремо й показати, що він неминуче тікає до краю. Отже, число має бути чутливим саме до країв — близьким до 0, коли канал майже досконалий, і близьким до 1, коли майже глухий, — і, головне, мати таку рекурсію, у якій **видно**, чому середина нестійка, а полюси притягують. Пропускна здатність цього не показує: I⁻ і I⁺ пов'язані з I лише балансом сум, а не наочним «квадратом». Тим числом, що показує розкол просто в очі, є параметр Бгаттачар'ї Z.

## Параметр Бгаттачар'ї: міра сплутаності входів

Візьмімо двійковий канал W: на вхід — 0 або 1, на виході — якесь y з імовірностями W(y|0) і W(y|1). Параметр Бгаттачар'ї (назва — від індійського статистика Аніла Кумара Бгаттачар'ї, який 1943 року ввів міру відстані між розподілами) означують так:

```
Z(W) =  Σ  √( W(y|0) · W(y|1) )        (сума по всіх виходах y)
        y
```

Сума по всіх виходах y береться від **геометричного середнього** двох імовірностей: побачити цей вихід, коли слали 0, і коли слали 1. Щоб відчути, що це міряє, уявіть два «димові хмаринки» виходів — одна від входу 0, друга від входу 1. Кожен доданок √(W(y|0)·W(y|1)) відмінний від нуля лише там, де хмаринки **перекриваються**: де обидва входи можуть дати той самий вихід. Z — це сумарне перекриття, тобто міра того, наскільки приймачеві важко розрізнити, що ж послали.

Крайні випадки роблять це точним:

```
хмаринки не перетинаються (для кожного y живе лише один вхід):
   у кожному доданку один множник = 0  →  Z = 0   (канал ідеальний: 0 від 1 видно завжди)

хмаринки збігаються (W(y|0) = W(y|1) для всіх y):
   доданок = √(W(y|0)²) = W(y|0),  сума = Σ W(y|0) = 1   →   Z = 1   (канал глухий)
```

Отже Z ∈ [0, 1], і — це головне — Z прямо обмежує помилку. Якщо приймач вирішує за максимумом правдоподібності, який біт послано, то ймовірність його помилки на одному використанні каналу не більша за Z:

```
P_помилки(W)  ≤  Z(W)
```

Доведення в один рядок: помилка можлива тільки там, де хмаринки накладаються, а Z якраз сумує це накладання (з правильними вагами) — тож воно ловить помилку зверху. Мале Z — мала помилка. Тому Z і є природною валютою: не абстрактне «скільки інформації», а безпосередньо «наскільки ризиковано».

> 🔧 **Навіщо це.** Коли інженер будує полярний код, він не ворожить, які позиції надійні, — він **рахує Z для кожного з N синтетичних каналів** і сортує їх за цим числом. На канали з найменшим Z (майже нульова помилка) кладе дані, решту заморожує. Тобто вся «конструкторська» робота над полярним кодом зводиться до обчислення Z за рекурсією, яку ми зараз і виведемо. Z — не теоретична абстракція, а те, що реально стоїть у таблиці проєктувальника.

Один окремий канал, у якому Z завжди рахується точно й просто, — це [двійковий канал зі стиранням](root:math-information/binary-erasure-channel) (BEC): біт або доходить цілим, або з імовірністю ε перетворюється на явну «дірку» (приймач знає, що на цьому місці стерто, але не знає, що там було). Порахуймо для нього Z. Виходи — це 0, 1 та «стерто». Коли слали 0, вихід 1 неможливий; коли слали 1, неможливий вихід 0. Перетинаються хмаринки лише на «стерто», де обидва входи дають його з імовірністю ε:

```
Z(BEC) = √(W(0|0)·W(0|1)) + √(W(e|0)·W(e|1)) + √(W(1|0)·W(1|1))
       = √((1−ε)·0)       + √(ε·ε)           + √(0·(1−ε))
       = 0 + ε + 0  =  ε
```

Для каналу зі стиранням Z дорівнює просто ймовірності стирання. Це той рідкісний випадок, де все рахується руками до кінця, і саме тому він буде наскрізним прикладом.

Нарешті, зв'язок Z із пропускною здатністю. Вони затиснуті одне одним із двох боків:

```
log₂( 2 / (1 + Z) )  ≤  I(W)  ≤  √( 1 − Z² )
```

Підставте краї й побачите, що Z і I — це два кінці однієї палиці. При Z → 0: ліва межа → log₂2 = 1, права → 1, отже I → 1 (канал стає ідеальним). При Z → 1: ліва → log₂1 = 0, права → 0, отже I → 0 (канал глухне). Для BEC зв'язок навіть точний: I = 1 − ε = 1 − Z. Тож **довести, що Z тікає до 0 або 1, — те саме, що довести, що I тікає до 1 або 0**, тобто що канали поляризуються. Далі ми доводимо саме про Z, бо в нього чиста рекурсія.

## Дві бухгалтерії: I зберігається, Z зсувається

Перетворення бере **два** незалежні використання каналу W (з бітами u₁, u₂, де x₁ = u₁⊕u₂, x₂ = u₂) і породжує два синтетичні канали: гірший W⁻ (для u₁, який декодують першим, наосліп) і кращий W⁺ (для u₂, який декодують, уже знаючи u₁). Про них ведуть дві різні бухгалтерії, і в цьому вся сіль.

Перша бухгалтерія — пропускна здатність, і вона **точно зберігається** для будь-якого каналу:

```
I(W⁻) + I(W⁺) = 2·I(W)
```

Це не випадковість, а ланцюгове правило для взаємної інформації: два біти, пропущені через два канали, несуть рівно стільки ж інформації, скільки й до перетворення, — оборотне змішування нічого не створює й не нищить. Скільки в одного синтетичного каналу відібрали, стільки другому додали. Пропускна здатність — незнищенна: перетворення її лише **перерозподіляє**.

Друга бухгалтерія — параметр Z, і вона поводиться інакше: Z не зберігається, а **в середньому зсувається вниз**. Саме цей зсув і є поляризацією, видимою через призму помилки. Але щоб побачити його, треба спершу виписати рекурсію Z.

## Рекурсія Z: чому кращий канал підносить непридатність до квадрата

Почнімо з кращого каналу W⁺ — того, що для u₂. Його декодують, уже знаючи u₁, тож у приймача є **дві** незалежні можливості дістати u₂: з другого виходу напряму, або з першого виходу, скориставшись відомим u₁. Помилка стається, лише коли **обидві** можливості підводять. Дві незалежні невдачі — імовірності перемножуються, і саме тому непридатність підноситься до квадрата:

```
Z(W⁺) = Z(W)²          — точно, для будь-якого каналу
```

Ця рівність — точна для всіх каналів, не лише для BEC. Оскільки Z ≤ 1, квадрат завжди менший за саме число, і що ближче Z до 0, то стрімкіше Z² пірнає ще нижче: 0.5 → 0.25, 0.25 → 0.0625, 0.0625 → 0.0039. Кращий канал не просто кращий — він **прискорено** мчить до досконалості.

Тепер гірший канал W⁻ — той, що для u₁, декодованого наосліп. Тут навпаки: u₁ = x₁⊕x₂ вимагає **обох** переданих символів, і помилка стається, коли підводить **хоч один**. Для каналу зі стиранням це рахується точно: стирання W⁻ настає, якщо стерто перший або другий вихід, тобто з імовірністю 1 − (1−Z)² = 2Z − Z². У загальному ж випадку тут не рівність, а межа зверху:

```
Z(W) ≤ Z(W⁻) ≤ 2Z(W) − Z(W)²      — рівність Z⁻ = 2Z−Z² саме для BEC
```

Гірший канал завжди гіршає (Z⁻ ≥ Z), але не більше, ніж до 2Z − Z²; на каналі зі стиранням він гіршає рівно до цієї стелі. Порахуймо обидва кроки на наскрізному прикладі.

**Приклад: один крок на BEC зі стиранням 0.5.** Тут Z = ε = 0.5, і обидві формули точні.

```
вихідний канал:   Z = 0.5

кращий  W⁺:  Z⁺ = Z²        = 0.25      ← пірнув до 0
гірший  W⁻:  Z⁻ = 2Z − Z²   = 0.75      ← поповз до 1

середнє Z: (0.25 + 0.75) / 2 = 0.5      ← тут ще зберіглося
```

Пара 0.5 і 0.5 роз'їхалася на 0.25 і 0.75 — розсунулась від середини до країв. Для BEC середнє Z навіть зберіглося (0.5), бо BEC сидить рівно на межі 2Z−Z². Для будь-якого іншого каналу нерівність Z⁻ ≤ 2Z−Z² строга, і тоді середнє Z **строго спадає**: (Z⁻ + Z⁺)/2 ≤ (2Z − Z² + Z²)/2 = Z. Ось перший натяк на дрейф униз, який усе й вирішить.

Зелена крива Z⁺ = Z² лежить під діагоналлю (тягне до 0), червона крива Z⁻ = 2Z − Z² лежить над діагоналлю (тягне до 1); сіра діагональ — «без змін». ## Мапа, з якої середина не має виходу

Ця мапа — уся динаміка поляризації в одній картинці. Зелена крива Z² завжди нижча за діагональ, червона 2Z−Z² завжди вища; збігаються вони з діагоналлю лише у двох точках — 0 і 1. Це **нерухомі точки**: якщо Z уже дорівнює 0 чи 1, перетворення його не рушить (0² = 0, 1² = 1). А от будь-яке проміжне Z перетворення розсуває: одна дитина стрибає ближче до 0, друга — ближче до 1, і обидві **далі** від 0.5, ніж вихідне значення. Повторюйте — і кожне покоління тікає від середини ще далі. Середина, 0.5, — точка максимального розколу, з якої годі втриматись: вона відштовхує в обидва боки. Полюси притягують, середина відштовхує. Лишається довести, що з нескінченним повторенням у середині **не лишається нічого**.

## Чому Z неминуче доходить до 0 або 1

Тепер строго. Оберімо один синтетичний канал навмання: підкиньмо n разів чесну монету, і на кожному кроці підемо або в гілку «−» (беремо W⁻), або в гілку «+» (беремо W⁺). Вийде випадковий шлях по дереву перетворень; позначмо канал у його кінці Wₙ, а два наші числа — Iₙ = I(Wₙ) та Zₙ = Z(Wₙ). Це випадкові величини, і за ними ми стежитимемо як за випадковим процесом.

Спершу пропускна здатність. Оскільки I(W⁻) + I(W⁺) = 2·I(W), середнє наступного значення точно дорівнює поточному:

```
E[ Iₙ₊₁ | Iₙ ] = ½·I(Wₙ⁻) + ½·I(Wₙ⁺) = I(Wₙ) = Iₙ
```

Процес, чиє умовне середнє наступного кроку дорівнює поточному значенню, зветься [мартингалом](root:math-probability/martingale) — це гра без дрейфу, як капітал у чесній ставці: у середньому ні виграшу, ні програшу. Ключова властивість: **обмежений мартингал майже напевно збігається**. Наш Iₙ замкнений у [0, 1], тож він майже напевно прямує до якоїсь границі I∞.

> Мартингал — випадковий процес Xₙ, у якому E[Xₙ₊₁ | X₁,…,Xₙ] = Xₙ: наступне значення в середньому дорівнює теперішньому, без систематичного дрейфу. Теорема про збіжність каже: якщо такий процес обмежений (тут — між 0 і 1), він майже напевно збігається до якоїсь випадкової границі. Саме це перетворює «канали кудись рухаються» на «канали кудись **прийдуть**».

Тепер Zₙ. Він не мартингал, а **супермартингал** — у середньому не зростає (E[Zₙ₊₁|Zₙ] ≤ Zₙ, ми це щойно бачили: середнє Z спадає або в найкращому разі зберігається). Обмежений супермартингал теж майже напевно збігається — назвімо границю Z∞. І ось у чому вся вправність доказу. Розгляньмо тільки «+»-кроки (їх на нескінченному шляху безліч). На такому кроці Zₙ₊₁ = Zₙ², тобто крок змінює Z на величину

```
| Zₙ₊₁ − Zₙ | = | Zₙ² − Zₙ | = Zₙ·(1 − Zₙ)
```

Але послідовність, яка збігається, врешті мусить робити **все менші** кроки — інакше вона нікуди не прийде. Отже вздовж нескінченної низки «+»-кроків величина Zₙ·(1 − Zₙ) мусить прямувати до нуля. А добуток Z·(1 − Z) дорівнює нулю лише на двох значеннях:

```
Z·(1 − Z) = 0   ⟺   Z = 0   або   Z = 1
```

Виходить, границя Z∞ майже напевно дорівнює 0 або 1. Проміжного значення бути не може: якби Z∞ застрягло десь усередині, «+»-кроки й далі стрибали б на Z∞·(1−Z∞) > 0, і жодної збіжності не було б. Ось чому поляризація неминуча — не «зазвичай», а **майже напевно**: сама вимога, щоб процес кудись прийшов, виштовхує його на полюси.

![Розліт значень Z до полюсів для BEC зі стиранням 0.5. Кожен стовпчик — рівень N = 2, 4, 8, 16, 32, 64; кожна точка — Z одного синтетичного каналу на висоті свого значення (0 внизу, 1 вгорі). Зелені точки (Z < 0.5) — майбутні канали даних, червоні (Z > 0.5) — майбутні заморожені. З кожним рівнем точки залишають середину й скупчуються біля 0 та 1](img/zflee.svg)
*Що більший блок, то менше точок лишається в мутній середині: вони стікають до 0 (досконалі) і до 1 (глухі). Частка тих, що осідають унизу, прямує до пропускної здатності.*

## Чому частка добрих каналів дорівнює саме C

Ми знаємо: Z∞ ∈ {0, 1}, отже й I∞ ∈ {1, 0} — кожен канал у границі або досконалий (I∞ = 1, Z∞ = 0), або глухий (I∞ = 0, Z∞ = 1). Лишилося порахувати, **яка частка** стала досконалою. І тут удруге спрацьовує мартингал. Для мартингала середнє зберігається на всій довжині, тож середнє границі дорівнює середньому старту:

```
E[I∞] = E[I₀] = I(W) = C
```

(На початку канал один, тож I₀ = I(W) = C без жодної випадковості.) Але I∞ набуває лише двох значень — 0 або 1. Середнє величини, що дорівнює 1 з імовірністю p і 0 з імовірністю 1−p, — це просто p. Отже:

```
E[I∞] = 1·P(I∞ = 1) + 0·P(I∞ = 0) = P(I∞ = 1)
```

Порівнявши два вирази, дістаємо напрочуд чисту рівність:

```
P(I∞ = 1) = C
```

Частка синтетичних каналів, що поляризуються до досконалих, дорівнює **точно** пропускній здатності вихідного каналу. Не «приблизно», не «в границі з поправкою» — рівно C. Ось звідки береться те, що дані кладуть на добрі канали й тим самим підходять до межі Шеннона: добрих каналів рівно стільки, скільки дозволяє C. Дві прості властивості — мартингал зберігає середнє, а границя двійкова — разом дали головний факт усієї теорії.

Перевірмо це на числах наскрізного прикладу — просто ітеруючи рекурсію Z для BEC(0.5) і рахуючи частку каналів, які стали майже досконалими (Z < 0.001):

```python
def bec_polarize(eps, n):
    """Z-значення 2**n синтетичних каналів для BEC(eps). Точна рекурсія."""
    zs = [eps]
    for _ in range(n):
        zs = [f(z) for z in zs for f in (lambda z: z*z,          # кращий W⁺
                                         lambda z: 2*z - z*z)]   # гірший W⁻
    return zs

for n in (2, 6, 10, 14, 18):
    zs = bec_polarize(0.5, n)
    good = sum(z < 1e-3 for z in zs) / len(zs)   # частка «майже досконалих»
    print(f"N={2**n:7d}   частка Z<0.001: {good:.3f}")
```

```
N=      4   частка Z<0.001: 0.000
N=     64   частка Z<0.001: 0.188
N=   1024   частка Z<0.001: 0.336
N=  16384   частка Z<0.001: 0.421
N= 262144   частка Z<0.001: 0.463
```

Частка добрих каналів повзе 0.188 → 0.336 → 0.421 → 0.463 — прямісінько до C = 0.5. За малого N вона ще далеко від межі: поляризація ще не завершилась, багато каналів висить у середині. Це підводить до останнього питання — **як швидко** приходить границя.

## Швидкість поляризації і чому важлива довжина блоку

Усе доведене вище — асимптотика: воно каже, куди канали прийдуть за N → ∞, але не як хутко. А для інженера це головне: скінченний блок мусить бути достатньо довгим, щоб канали встигли розшаруватися. Наскільки довгим?

Груба інтуїція виводиться з рекурсії. Кожен «+»-крок підносить Z до квадрата; k «+»-кроків поспіль дають Z у степені 2ᵏ — тобто дуже мале число. На типовому шляху до доброго каналу приблизно половина з n кроків — «+» (закон великих чисел: чесна монета дає ≈ n/2 гербів). Отже добрий канал набирає близько 2^(n/2) підведень до квадрата, а що 2^(n/2) = √(2ⁿ) = √N, то його Z спадає приблизно як

```
Z_доброго  ≈  (щось менше за 1) ^ √N   =   2^(−c·√N)
```

Показник √N = N^(1/2) і є **швидкість поляризації**. Строго її встановили Ердал Арікан і Емре Телатар (2008): для будь-якого β < 1/2 за досить великого N частка каналів із Z ≤ 2^(−N^β) прямує до C. Число 1/2 тут — «показник помилки» базового перетворення 2×2, і перевищити його не можна (β > 1/2 уже не працює). Наслідок для коду прямий: блокова помилка при послідовному скасуванні обмежена сумою Z по каналах даних,

```
P_блоку  ≤  Σ  Z(W_N^(i))   ≈   2^(−√N)
           i∈дані
```

тобто спадає майже експоненційно від **кореня** довжини блоку. Подвоїли N — і показник √N зріс у √2 разів; помилка падає стрімко, але саме з довжиною.

І ось де все сходиться на практиці. Швидкість √N добра **асимптотично**, але кволо приходить на коротких блоках: при малому N поляризація ще не завершена, і — як показали числа вище — чимало каналів застрягло в мутній середині, де Z ані близько до 0, ані до 1. Кожен такий недополяризований канал під даними псує надійність, а простий послідовний декодер ще й розносить його помилку по всьому блоку. Саме тому короткі полярні коди самотужки програють, і їх рятують списковим декодуванням із контрольною сумою: список тримає кілька гіпотез там, де поляризація не дала чіткої відповіді, а [CRC](root:com-modulation/crc) вибирає з них правильну. Довжина блоку — не деталь реалізації, а те, наскільки далеко зайшла сама поляризація.

---

Одне число несе всю теорію. Параметр Бгаттачар'ї Z міряє непридатність каналу (0 — ідеальний, 1 — глухий) і зверху обмежує помилку. При перетворенні кращий канал підносить своє Z до квадрата (Z⁺ = Z², прискорено до 0), гірший гіршає (Z⁻ ≤ 2Z − Z², до 1), а пропускна здатність при цьому точно зберігається — I⁻ + I⁺ = 2I. Ця збереженість робить Iₙ мартингалом, який майже напевно збігається; рекурсія Z⁺ = Z² робить із «+»-кроків стрибки завбільшки Z(1−Z), і вимога збіжності виштовхує границю Z∞ рівно на 0 або 1. А оскільки мартингал зберігає середнє, частка каналів, що дійшли до досконалості, дорівнює точно C. Швидкість цього — 2^(−√N): корінь довжини блоку в показнику й пояснює, чому полярним кодам потрібна довжина, а на коротких повідомленнях — ще й список із CRC.
