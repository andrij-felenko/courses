# 🧮 Математика порогів SNR, спектральної ефективності та ймовірності помилки

Математичний розрахунок адаптивної модуляції та кодування (AMC) полягає у виборі такої пари з порядку модуляції `M` і швидкості завадостійкого коду `R = k/n`, яка забезпечує максимум спектральної ефективності `η` при збереженні ймовірності помилки блоку `BLER ≤ BLER_target` (зазвичай `BLER_target = 0.1` або 10%).

Аналіз тримається на трьох математичних фундаментах: межі ємності каналу Шеннона, геометрії квадратних сузір'їв M-QAM у гаусовому шумі та статистичній умові стабільності вимірювального автомата.

## 1. Спектральна ефективність та межа Шеннона

Спектральна ефективність `η` (ета) визначається як кількість корисних інформаційних бітів, що передаються за один секундний інтервал у смузі 1 Гц:

```
η = R · log₂(M)    [біт/с/Гц]
```

де `M` — кількість точок у векторному сузір'ї модуляції (`M = 4` для QPSK, `M = 16` для 16-QAM, `M = 64` для 64-QAM, `M = 256` для 256-QAM), а `R = k / n` — швидкість завадостійкого коду FEC (відношення інформаційних бітів до загальної довжини блоку).

Згідно з теоремою Шеннона-Хартлі, теоретична границя пропускної здатності каналу з аддитивним білим гаусовим шумом (AWGN) для неперервного сигналу дорівнює:

```
C / B = log₂(1 + SNR)    [біт/с/Гц]
```

де `SNR = P_signal / P_noise` — відношення потужності корисної хвилі до потужності шуму в лінійному масштабі.

Проте для дискретних схем модуляції спектральна ефективність не може зростати нескінченно зі збільшенням SNR — вона обмежена стелею сузір'я `log₂(M)` біт/символ. Відстань між теоретичною межею Шеннона та практичною кривою дискретної спектральної ефективності описують коефіцієнтом реалізації (англ. *implementation gap*) `Γ ≥ 1` (гамма):

```
η_real = log₂(1 + SNR / Γ)    (при η_real ≤ log₂(M))
```

У реальних сучасних трансіверах 4G/5G (із кодуванням LDPC або турбокодами) значення `Γ` становить від 1.5 до 3.0 дБ (лінійно від 1.41 до 2.00).

## 2. Співвідношення між SNR, Eb/N0 та Es/N0

Для математичної строгості в теорії зв'язку розрізняють три варіанти відношення сигналу до шуму:
1. `SNR` — відношення середньої потужності сигналу до потужності шуму в смузі каналу `B`.
2. `E_s / N_0` — відношення енергії одного модульованого символу до спектральної щільності шуму.
3. `E_b / N_0` — відношення енергії одного корисного інформаційного біта до спектральної щільності шуму.

Ці величини пов'язані між собою через спектральну ефективність `η`:

```
E_s / N_0 = SNR · (B / f_symbol)
E_b / N_0 = (E_s / N_0) / η = SNR / η
```

У логарифмічному масштабі (в децибелах):

```
SNR_dB = Eb/N0_dB + 10 · log₁₀(η)
```

Це співвідношення показує: чим вища спектральна ефективність `η` обраної MCS, тим більша енергія `SNR` потрібна на символ для підтримки тієї самої питомої енергії біта `E_b / N_0`.

## 3. Геометрія сузір'я M-QAM та ймовірність бітової помилки (BER)

Для прямокутного сузір'я `M-QAM` із кодуванням Ґрея ймовірність бітової помилки (BER) незакодованого сигналу в каналі AWGN обчислюється через Q-функцію (інтеграл хвоста стандартного нормального розподілу):

```
BER_unCoded ≈ (4 / log₂(M)) · (1 − 1/√M) · Q( √( (3 · log₂(M) · E_b/N_0) / (M − 1) ) )
```

де Q-функція визначається як:

```
Q(x) = (1 / √(2π)) ∫_x^∞ e^{−u²/2} du
```

Зменшення евклідової відстані `d_min` між точками сузір'я зі зростанням `M` при сталій середній потужності сигналу описується формулою:

```
d_min = √( (6 · E_s) / (M − 1) )
```

Збільшення порядків модуляції від QPSK (`M = 4`) до 256-QAM (`M = 256`) зменшує мінімальну відстань `d_min` у 9.2 раза. Щоб компенсувати це стиснення й зберегти ту саму ймовірність виявлення точки, енергетику сигналу `E_s` доводиться піднімати майже на 19.3 дБ.

## 4. Зв'язок SNR із векторною величиною помилки (EVM)

У практичних вимірювальних системах приймач розраховує якість демодульованого сузір'я за показником **векторної величини помилки** (англ. *Error Vector Magnitude*, EVM). 

EVM вимірює середньоквадратичну відстань між прийнятим комплексним відліком `Z_k` та ідеальною точкою сузір'я `S_k`:

```
EVM = √( (Σ |Z_k − S_k|²) / (Σ |S_k|²) )
```

У каналі AWGN із нульовим частотним зсувом показник EVM прямо пов'язаний із рівнем `SNR`:

```
SNR ≈ 1 / (EVM²)
SNR_dB ≈ −20 · log₁₀(EVM)
```

Таблиця нижче показує граничні вимоги до EVM та SNR для забезпечення надійного прийому різних модуляцій згідно зі специфікацією 3GPP 5G NR:

```
Модуляція    Граничне EVM    Необхідне SNR
QPSK         17.5%           15.1 дБ
16-QAM       12.5%           18.1 дБ
64-QAM        8.0%           21.9 дБ
256-QAM       3.5%           29.1 дБ
1024-QAM      1.1%           39.2 дБ
```

## 5. Виведення порогів SNR для завадостійких кодів та BLER

При використанні завадостійкого кодування (LDPC або турбокодів) залежність ймовірності помилки блоку кадру `BLER` від `SNR` має характер «скали» (англ. *waterfall curve*). При перевищенні критичного порогу `SNR_th` ймовірність помилки кадру моментально падає від 1 до 10⁻⁴.

Залежність порогу декодування `SNR_th` для досягнення цільового `BLER = 10%` виводиться з розширеної моделі Шеннона з урахуванням гапу `Γ`:

```
SNR_th = Γ · (2^{R · log₂(M)} − 1) = Γ · (2^{η} − 1)
```

Переводячи вираз у децибели, отримуємо прямо формулу розрахунку порогових таблиць MCS:

```
SNR_th_dB = 10 · log₁₀( Γ · (2^{η} − 1) )
```

**Крок 1. Обчислення для MCS 0 (QPSK 1/2, η = 1.0 біт/с/Гц, Γ = 1.78):**
```
SNR_th = 1.78 · (2¹ − 1) = 1.78 · 1 = 1.78
SNR_th_dB = 10 · log₁₀(1.78) = 2.50 дБ
```

**Крок 2. Обчислення для MCS 2 (16-QAM 1/2, η = 2.0 біт/с/Гц, Γ = 1.78):**
```
SNR_th = 1.78 · (2² − 1) = 1.78 · 3 = 5.34
SNR_th_dB = 10 · log₁₀(5.34) = 7.27 дБ
```

**Крок 3. Обчислення для MCS 4 (64-QAM 2/3, η = 4.0 біт/с/Гц, Γ = 1.78):**
```
SNR_th = 1.78 · (2⁴ − 1) = 1.78 · 15 = 26.70
SNR_th_dB = 10 · log₁₀(26.70) = 14.26 дБ
```

**Крок 4. Обчислення для MCS 7 (256-QAM 5/6, η = 6.67 біт/с/Гц, Γ = 1.78):**
```
SNR_th = 1.78 · (2^{6.67} − 1) = 1.78 · 100.83 = 179.48
SNR_th_dB = 10 · log₁₀(179.48) = 22.54 дБ
```

## 6. Математична умова відсутності нехибного перемикання (Гістерезис)

Заміри `SNR`, виконувані приймачем по `N_pilot` пилотних символах, є випадковою величиною із середньоквадратичним відхиленням `σ_SNR` (сигма):

```
σ_SNR ≈ 1 / √(2 · N_pilot · SNR)
```

У децибельному масштабі для `N_pilot = 64` дисперсія вимірювання становить близько `σ_SNR_dB ≈ 0.3...0.5 дБ`.

Щоб випадковий шум вимірювань не викликав осциляцій вибору MCS, інтервал гістерезису `Δ_hyst` має задовольняти правило трьох сигм (імовірність хибного спрацювання `< 0.27%`):

```
Δ_hyst > 3 · σ_SNR_dB
```

Підставляючи `σ_SNR_dB ≈ 0.4 дБ`, отримуємо мінімальний розмір гістерезисної петлі:

```
Δ_hyst > 3 · 0.4 дБ = 1.2 дБ
```

Саме величина `Δ_hyst = 1.2 дБ` є стандартною константою в більшості алгоритмів адаптації лінку сучасних мобільних чипсетів.
