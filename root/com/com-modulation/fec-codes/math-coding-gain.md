# 🧮 Математика енергетичного виграшу та меж надлишковості

У реальному каналі зв'язку передача кожного біта вимагає витрати енергії. Зниження потужності передавача веде до експоненційного зростання ймовірності помилки, якщо передавати дані без захисту. Коди прямої корекції помилок дають змогу отримати ту саму якість зв'язку при значно меншому рівні сигналу. Цей виграш має точний кількісний вираз у децибелах, а максимальна ефективність будь-якого коду обмежена фундаментальними геометричними та ентропійними нерівностями.

## Енергетичні параметри: зв'язок між бітовою та канальною енергією

У системах цифрового зв'язку якість сигналу вимірюється не загальною напругою в лінії, а відношенням енергії на один інформаційний біт `E_b` до спектральної густини потужності білого шуму `N_0`. 

Коли кодер додає надлишкові перевірочні біти, інформаційна швидкість зменшується. Кодова швидкість `R` визначається як відношення кількості корисних бітів `k` до повної довжини кодового блоку `n`:

```
R = k / n
```

Оскільки за той самий час передачі одного інформаційного біта передавач тепер надсилає `1/R` канальних символів, енергія, яка припадає на один канальний символ `E_s` (або `E_c`), менша за енергію інформаційного біта:

```
E_s = R · E_b      [енергія канального символу зі швидкістю R]
```

Якщо використовується двійкова фазова маніпуляція (BPSK) у каналі з адитивним білим гаусовим шумом (АБГШ), імовірність бітової помилки для некодованого сигналу визначається інтегралом хвоста гаусового розподілу — Q-функцією:

```
P_b_uncoded = Q(√(2 · E_b / N_0))
```

де інтеграл Q-функції виражає ймовірність того, що нормальна випадкова величина з нульовим середнім та одиничною дисперсією перевищить значення `x`:

```
Q(x) = (1 / √(2 · π)) · ∫_x^∞ e^(-u² / 2) du
```

Верхня межа Чернова для Q-функції забезпечує зручну аналітичну експоненційну оцінку при `x ≥ 0`:

```
Q(x) ≤ (1 / 2) · e^(-x² / 2)
```

## Виведення ймовірності помилки блокового коду при жорсткому декодуванні

Розглянемо лінійний блоковий код `(n, k, d_min)`, де `d_min` — мінімальна кодова відстань Хеммінга між будь-якими двома дозволеними кодовими словами.

Код гарантовано виправляє будь-яку конфігурацію з `t` або менше помилок у блоці з `n` бітів, де параметр `t` дорівнює:

```
t = ⌊(d_min - 1) / 2⌋
```

При жорсткому квантуванні (Hard Decision) демодулятор ухвалює остаточне рішення щодо кожного символу окремо, перетворюючи аналоговий канал із шумом на двійковий симетричний канал (ДЗК) з імовірністю перехідної бітової помилки `p`:

```
p = Q(√(2 · E_s / N_0)) = Q(√(2 · R · E_b / N_0))
```

Зверніть увагу: оскільки `E_s = R · E_b < E_b`, канальна ймовірність помилки `p` на окремому символі кодованого сигналу завжди *вища*, ніж у некодованого біта за того самого `E_b / N_0`. Виграш виникає лише завдяки тому, що декодер виправляє комбінації помилок.

Імовірність помилки декодування всього кодового слова `P_cw` виникає тоді, коли шум спотворює `t + 1` або більше бітів у блоці з `n` переданих символів. За біноміальним законом розподілу для некорельованих помилок отримуємо точний вираз:

```
P_cw = ∑_{i = t + 1}^{n} (n! / (i! · (n - i)!)) · p^i · (1 - p)^(n - i)
```

За низької канальної ймовірності помилки `p ≪ 1` перший член суми при `i = t + 1` багаторазово переважає всі наступні доданки:

```
P_cw ≈ (n! / ((t + 1)! · (n - t - 1)!)) · p^(t + 1)
```

Щоб знайти результуючу ймовірність інформаційної бітової помилки після декодування `P_b_coded`, враховують середню частку інформаційних бітів, які спотворюються при виникненні непереборної помилки в кодовому слові. Для систематичних блокових кодів справедлива апроксимація:

```
P_b_coded ≈ ((d_min) / n) · (n! / ((t + 1)! · (n - t - 1)!)) · p^(t + 1)
```

## Союзна межа (Union Bound) та ваговий спектр коду

Для точного аналітичного оцінювання ймовірності блокової помилки лінійного коду при декодуванні за критерієм максимальної правдоподібності (MLD) використовують ваговий розподіл кодових слів `A_w` (кількість кодових слів, що мають вагу Хеммінга `w`):

```
A(X) = 1 + ∑_{w = d_min}^{n} A_w · X^w
```

Союзна межа Буля (Union Bound) обмежує повну ймовірність помилки сумою парних імовірностей помилкового переходу між нульовим словом та кожним дозволеним словом ваги `w`:

```
P_word ≤ ∑_{w = d_min}^{n} A_w · Q(√(2 · w · R · E_b / N_0))
```

При високих значеннях `E_b / N_0` експоненційний спад Q-функції призводить до того, що домінуючий внесок робить виключно перший ненульовий член суми з мінімальною вагою `w = d_min`:

```
P_word ≈ A_{d_min} · Q(√(2 · d_min · R · E_b / N_0))
```

Цей вираз математично демонструє, що нахил кривої `BER` на логарифмічному графі повністю задається добутком `d_min · R`, а коефіцієнт `A_{d_min}` визначає висоту зсуву кривої.

## Асимптотичний енергетичний виграш кодування (Coding Gain)

Енергетичний виграш від кодування `G_c` визначається як різниця рівнів `E_b / N_0` (у логарифмічному масштабі, децибелах), необхідних для досягнення однакового цільового рівня ймовірності помилки (наприклад, `BER = 10⁻⁵`):

```
G_c [дБ] = (E_b / N_0)_uncoded [дБ] - (E_b / N_0)_coded [дБ]
```

Для аналітичної оцінки при високих відношеннях сигнал/шум (`E_b / N_0 → ∞`) використовують експоненційну апроксимацію Q-функції: `Q(x) ≈ (1/2) · e^(-x² / 2)`. Підставляючи `p` у вираз для ймовірності помилки, отримуємо асимптотичну залежність:

```
P_b_coded ~ exp(- (t + 1) · R · (E_b / N_0))
```

Оскільки `t + 1 = (d_min + 1) / 2` для непарних `d_min`, ефективна швидкість спаду кривої помилок визначається добутком `R · d_min`. Асимптотичний енергетичний виграш для жорсткого декодування набуває вигляду:

```
G_c_asymptotic [дБ] = 10 · log10(R · (d_min / 2))
```

Звідси чітко видно дві протилежні сили:
1. Збільшення надлишковості зменшує `R`, що зсуває криву праворуч (енергетичний штраф за передачу додаткових бітів).
2. Збільшення мінімальної відстані `d_min` збільшує нахил кривої `BER`, що стрімко зсуває криву ліворуч при високих `E_b / N_0`.

Кодування стає вигідним лише тоді, коли виграш від збільшення `d_min` перекриває втрати від зменшення кодової швидкості `R`.

## Математична природа виграшу м'якого декодування (Soft Decision)

При м'якому квантуванні демодулятор не відсікає аналоговий рівень напруги до `0` або `1`, а передає декодеру безперервне значення або багаторозрядне квантування (наприклад, 4–8 бітів на символ) у формі логарифмічного відношення правдоподібностей (LLR):

```
LLR(y) = ln( P(y | x = +1) / P(y | x = -1) ) = (2 / σ²) · y
```

де `y` — прийнятий відлік напруги, `σ² = N_0 / (2 · E_s)` — дисперсія гаусового шуму.

Замість мінімізації відстані Хеммінга декодер м'яких рішень шукає кодове слово `c`, яке мінімізує евклідову відстань у `n`-вимірному просторі сигналів:

```
D_Euclidean²(y, c) = ∑_{j = 1}^{n} (y_j - c_j)²
```

Мінімальна квадратна евклідова відстань між дозволеними послідовностями становить:

```
d_E_min² = 4 · E_s · d_min = 4 · R · E_b · d_min
```

Імовірність помилкового переходу між двома найближчими кодовими словами в багатовимірному просторі дорівнює:

```
P_pair = Q( d_E_min / (2 · σ) ) = Q( √( 2 · R · d_min · (E_b / N_0) ) )
```

Порівняємо аргументи під коренем для некодованого сигналу, кодованого з жорстким декодуванням та кодованого з м'яким декодуванням:

```
Некодований BPSK:         x_unc = 2 · (E_b / N_0)
Жорстке декодування:     x_hard ≈ 2 · R · (d_min / 2) · (E_b / N_0) = R · d_min · (E_b / N_0)
М'яке декодування:       x_soft = 2 · R · d_min · (E_b / N_0)
```

Зіставляючи `x_soft` та `x_hard`, бачимо точний коефіцієнт переваги:

```
x_soft / x_hard = (2 · R · d_min) / (R · d_min) = 2
```

У логарифмічній шкалі коефіцієнт 2 перетворюється на точне значення:

```
10 · log10(2) ≈ 3.01 дБ
```

Це доводить фундаментальний факт теорії зв'язку: **перехід від жорстких бітових рішень до неперервних м'яких метрик забезпечує додатковий виграш близько 2–3 дБ за будь-якої структури коду в гаусовому каналі**. Жорстке рішення безповоротно знищує інформацію про ступінь впевненості демодулятора, що еквівалентно втраті половини потужності корисного сигналу.

## Параметр Баттачарія та оцінка надійності підканалів

У сучасній теорії полярних кодів для кількісної оцінки надійності дискретних каналів без пам'яті використовується параметр Баттачарія `Z(W)`:

```
Z(W) = ∑_{y ∈ Y} √( W(y | 0) · W(y | 1) )
```

Властивості параметра Баттачарія:
- `Z(W)` завжди лежить у діапазоні `[0, 1]`.
- Значення `Z(W) ≈ 0` відповідає ідеальному безшумному каналу (ймовірність помилки прямує до нуля).
- Значення `Z(W) ≈ 1` відповідає абсолютно зашумленому каналу (повна ентропійна невизначеність).
- Для двійкового симетричного каналу з імовірністю помилки `p`: `Z(W) = 2 · √(p · (1 - p))`.
- Для двійкового каналу зі стиранням з імовірністю стирання `ε`: `Z(W) = ε`.
- Для каналу з АБГШ та модуляцією BPSK: `Z(W) = e^(-E_s / N_0) = e^(-R · E_b / N_0)`.
- Верхня межа ймовірності помилки декодування блоку за алгоритмом послідовного скасування обмежується сумою параметрів Баттачарія обраних інформаційних підканалів: `P_block ≤ ∑_{i ∈ InfoSet} Z(W_N^{(i)})`.

## Спектральна ефективність та модуляційні компроміси

Кодова швидкість `R` безпосередньо взаємодіє з порядком модуляції. Якщо канальний модулятор використовує сузір'я розмірності `M = 2^m` (наприклад, 4-QAM з `m=2`, 16-QAM з `m=4`, 64-QAM з `m=6`, 256-QAM з `m=8`), кожен модульований символ несе `m · R` інформаційних бітів.

Чиста спектральна ефективність `η` системи зв'язку (біт/с на герц смуги пропускання) з урахуванням коефіцієнта скруглення спектрального фільтра Найквіста `α` (Roll-off factor, зазвичай `α = 0.1 ... 0.35`) визначається формулою:

```
η = (m · R) / (1 + α)     [біт/с/Гц]
```

Це співвідношення формує фундаментальний компроміс між енергетичною ефективністю (Power Efficiency) та спектральною ефективністю (Bandwidth Efficiency):
- При переході до вищих порядків модуляції (256-QAM) спектральна ефективність `η` зростає до 6–7 біт/с/Гц, але мінімальна евклідова відстань між точками сузір'я зменшується, вимагаючи вищого відношення `E_b / N_0` для збереження того самого рівня `BER`.
- Потужні коди FEC з низькою швидкістю `R = 1/3` або `1/2` розширюють смугу каналу, але дозволяють системі надійно працювати за критично низьких рівнів сигналу, недосяжних для незахищених передач.

## Фундаментальні межі надлишковості та пропускної здатності

Структура будь-якого лінійного блокового коду обмежена законами геометрії багатовимірних дискретних просторів.

### 1. Межа упаковки сфер Хеммінга (Hamming Bound)

Кожне з `2^k` дозволених кодових слів довжиною `n` оточене сферою радіуса `t = ⌊(d_min - 1) / 2⌋` у метриці Хеммінга. Щоб код міг однозначно виправляти до `t` помилок, ці сфери не повинні перетинатися.

Об'єм однієї сфери радіуса `t` у просторі розмірності `n` дорівнює кількості векторів на відстані від `0` до `t`:

```
V(n, t) = ∑_{i = 0}^{t} (n! / (i! · (n - i)!))
```

Сумарний об'єм усіх `2^k` неперетинних сфер не може перевищувати повного об'єму двійкового векторного простору `2^n`:

```
2^k · ∑_{i = 0}^{t} (n! / (i! · (n - i)!)) ≤ 2^n
```

Логарифмуючи нерівність, отримуємо нижню межу кількості перевірочних бітів `r = n - k`:

```
n - k ≥ log2( ∑_{i = 0}^{t} (n! / (i! · (n - i)!)) )
```

Коди, для яких ця нерівність перетворюється на строгу рівність, називаються *досконалими кодами* (Perfect Codes). Усі вектори простору належать сферам навколо кодових слів без жодного проміжку. Досконалими є лише коди Хеммінга (`t = 1`) та бінарний код Голея `(23, 12, 7)` з `t = 3`.

### 2. Межа Гілберта–Варшамова (існування лінійних кодів)

Межа Гілберта–Варшамова стверджує, що завжди існує лінійний двійковий код `(n, k)` з мінімальною відстанню не менше `d`, якщо виконується нерівність:

```
2^(n - k) > ∑_{i = 0}^{d - 2} ((n - 1)! / (i! · (n - 1 - i)!))
```

В асимптотичній формі при великих довжинах блоку `n → ∞` для відносної відстані `δ = d / n` та кодової швидкості `R = k / n` межа записується через бінарну функцію ентропії `H_2(δ)`:

```
R ≥ 1 - H_2(δ)
```

де `H_2(p) = -p · log2(p) - (1 - p) · log2(1 - p)`. Це доводить, що навіть при збереженні високої швидкості `R` існують коди з лінійно зростаючою кодовою відстанню.

### 3. Межа Сінглтона (Singleton Bound) та коди MDS

Якщо з кожного кодового слова довжиною `n` відкинути перші `d_min - 1` символів, усі решта `2^k` утворених векторів довжиною `n - (d_min - 1)` зобов'язані залишатися унікальними, інакше вихідна мінімальна відстань була б меншою за `d_min`.

Оскільки кількість унікальних векторів довжиною `n - d_min + 1` над алфавітом розміру `q` дорівнює `q^(n - d_min + 1)`, отримуємо нерівність:

```
q^k ≤ q^(n - d_min + 1)
```

Звідси випливає фундаментальна межа Сінглтона:

```
d_min ≤ n - k + 1
```

Коди, які досягають цієї теоретичної межі рівності `d_min = n - k + 1`, називаються *кодами з максимальною відстанню* (Maximum Distance Separable, MDS). Коди Ріда–Соломона є MDS-кодами, завдяки чому вони забезпечують математично граничну виправну здатність для заданого числа надлишкових символів.

### 4. Абсолютна границя Шеннона для каналу з АБГШ

Гранична пропускна здатність неперервного каналу зв'язку зі смугою `W` (Гц) за формулою Шеннона дорівнює:

```
C = W · log2(1 + P_signal / P_noise) = W · log2(1 + (R_b · E_b) / (W · N_0))
```

де `R_b` — швидкість передачі інформації (біт/с). Для можливості безпомилкової передачі швидкість `R_b` не повинна перевищувати ємність `C`. Позначаючи спектральну ефективність як `η = R_b / W` (біт/с/Гц), запишемо:

```
η ≤ log2(1 + η · (E_b / N_0))
```

Розв'язуючи нерівність відносно `E_b / N_0`, отримуємо нижню межу:

```
E_b / N_0 ≥ (2^η - 1) / η
```

Якщо спектральна смуга прямує до нескінченності `W → ∞` (спектральна ефективність `η → 0`), границя досягає свого абсолютного теоретичного мінімуму:

```
lim_{η → 0} ((2^η - 1) / η) = ln(2) ≈ 0.693
```

У логарифмічній шкалі децибелів це дає абсолютну межу Шеннона для будь-яких систем зв'язку:

```
(E_b / N_0)_min = 10 · log10(ln(2)) ≈ -1.59 дБ
```

Жодна система зв'язку у Всесвіті не здатна забезпечити надійну передачу даних у каналі з адитивним гаусовим шумом, якщо відношення енергії на інформаційний біт до шуму нижче за `-1.59 дБ`.

## Розрахунковий приклад: порівняння параметрів кодів

Розглянемо практичний розрахунок для двох типових систем захисту при цільовому рівні `BER = 10⁻⁵`.

| Параметр | Некодований BPSK | Код Хеммінга (7, 4) | Код Ріда–Соломона RS(255, 223) |
| :--- | :--- | :--- | :--- |
| Довжина блоку `n` | 1 | 7 | 255 байтів (2040 бітів) |
| Інформаційні символи `k` | 1 | 4 | 223 байти (1784 біти) |
| Кодова швидкість `R` | 1.000 | 0.571 (4/7) | 0.875 (223/255) |
| Мінімальна відстань `d_min` | 1 | 3 | 33 байти (MDS: `n - k + 1`) |
| Число виправних помилок `t` | 0 | 1 біт | 16 байтів (128 бітів у пачці) |
| Необхідний `E_b / N_0` при `BER = 10⁻⁵` | 9.6 дБ | 8.4 дБ (Hard) | 5.8 дБ (Hard) |
| Реальний енергетичний виграш `G_c` | 0.0 дБ | +1.2 дБ | +3.8 дБ |

Для простого коду Хеммінга `(7, 4)` виграш становить лише 1.2 дБ через високі накладні витрати (`R = 0.571`) та малу відстань `d_min = 3`.

Потужний блоковий код Ріда–Соломона `RS(255, 223)` при високій швидкості `R = 0.875` забезпечує мінімальну відстань `d_min = 33`, що дає солідний виграш 3.8 дБ при жорсткому декодуванні, а в поєднанні з м'яким внутрішнім кодом у каскадних схемах — понад 6.5 дБ.
