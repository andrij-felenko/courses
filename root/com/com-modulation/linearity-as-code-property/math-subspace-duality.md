# 🧮 Алгебра підпростору: дуальне дзеркало коду й межа його сили

Сказати «лінійний код — це підпростір, замкнений щодо XOR» — досить, щоб відчути, чому такі коди практичні. Але слово **підпростір** — не образ, а точний алгебраїчний об'єкт зі скінченного набору аксіом. Варто взяти його буквально — і з нього випадають три речі, на які інтуїція лише натякала: **чому дозволених слів рівно qᵏ** і що строго означає їхня «розмірність»; **другий код — дзеркальний**, який весь час ховається в перевірній матриці; і **тверда стеля** — наскільки сильним лінійний код взагалі має право стати. Ця вставка бере підпростір усерйоз і доводить кожну з трьох ниток до кінця.

## Код — це рівно k-вимірний підпростір над GF(q)

Візьмімо означення дослівно. Код C — це підмножина простору [GF(q)ⁿ](topic:math-algebra/finite-fields) усіх слів завдовжки n над скінченним полем із q елементів, і ця підмножина замкнена щодо [лінійних комбінацій](topic:math-algebra/linear-combination): для будь-яких двох кодових слів c₁, c₂ і будь-яких коефіцієнтів λ₁, λ₂ із поля слово λ₁·c₁ + λ₂·c₂ теж належить C. (Над GF(2) коефіцієнти — лише 0 і 1, тож комбінація вироджується у XOR підмножини слів; над більшим полем λ пробігає всі q значень.) Будь-яка множина з такою властивістю — [векторний підпростір](topic:math-algebra/vector-space), а кожен підпростір має **базис**: найменший набір слів g₁, …, gₖ, які лінійно незалежні (жодне не збирається з решти) і породжують усе C.

Тепер порахуймо, скільки в коді слів, — і побачмо, що відповідь не наближена, а **вимушена**. Кожне кодове слово — це якась комбінація базисних:

```
c = λ₁·g₁ + λ₂·g₂ + … + λₖ·gₖ ,   кожне λᵢ ∈ GF(q)
```

Побудуймо відображення φ, що бере набір коефіцієнтів (λ₁, …, λₖ) і повертає це слово. Воно **накриває** весь код — бо базис породжує C, тож кожне слово так виражається. І воно **не склеює** різних наборів у одне слово: якби два різні набори коефіцієнтів дали те саме c, їхня різниця була б нетривіальною комбінацією базисних слів, що дорівнює нулю, — а це пряма лінійна залежність, якої в базисі за означенням немає. Отже, φ — взаємно однозначна відповідність між наборами коефіцієнтів і кодовими словами. Наборів рівно стільки, скільки способів обрати k коефіцієнтів по q значень кожен:

```
|C| = q · q · … · q  (k разів)  =  qᵏ
```

Це не оцінка «десь близько qᵏ», а точна рівність, і тримається вона на одному — на **незалежності базису**. Приберіть незалежність — φ почне склеювати набори, і рівність розсиплеться. Число дозволених слів у лінійному коді зашите просто в розмір базису.

А **розмірність** k тут — не довільна назва. Фундаментальна теорема лінійної алгебри (однаково правдива над будь-яким полем, чи то ℝ, чи GF(q)) каже: усі базиси одного підпростору мають **однакову кількість** векторів. Тож k — це інваріант коду, «число незалежних напрямів», яке не залежить від того, який саме базис ви обрали. Звідси і швидкість коду читається як частка інформації на символ:

```
R = k / n = (log_q |C|) / n
```

логарифм за основою q від числа слів, поділений на довжину, — скільки символів даних припадає на кожен переданий символ.

> 🔧 **Навіщо це.** Розмірність — це чесна валюта коду. k незалежних напрямів — це рівно k символів даних, не більше й не менше, а qᵏ — точна, а не приблизна кількість дозволених слів. Саме тому весь код, хай хоч 2¹⁰⁰ слів, вміщується у k збережених базисних векторів: розмірність вимірює не «скільки слів», а «скільки незалежної свободи», і саме ця свобода, а не астрономічний перелік, і є тим, що зберігають та обробляють. Над GF(2) базис — це k бітових слів; над GF(256) у [Ріда — Соломона](topic:com-modulation/reed-solomon) — k байтових, по 256 значень на коефіцієнт; кістяк той самий, лише поле більше.

## Дуальний код: у перевірній матриці ховається другий код

Тепер найкрасивіше. Введімо на словах поняття **ортогональності**. Скалярний добуток двох слів над полем — це сума добутків їхніх координат:

```
x · y = x₁y₁ + x₂y₂ + … + xₙyₙ    (уся арифметика в полі GF(q))
```

Над GF(2) це просто парність позицій, де в обох словах стоять одиниці. Два слова звуть **ортогональними**, коли їхній добуток дорівнює нулю. І ось означення: **дуальний код** C⊥ — це множина **всіх** слів простору, ортогональних до кожного слова коду C:

```
C⊥ = { x ∈ GF(q)ⁿ :  x · c = 0  для всіх c ∈ C }
```

Це знову підпростір (перетин розв'язків лінійних рівнянь завжди підпростір), тобто **теж лінійний код**. Кожному лінійному коду природа безкоштовно додає його дзеркало.

І тут перевірна матриця H показує своє друге обличчя. Її означальна властивість — H·cᵀ = 0 для кожного дозволеного c — читається так: **кожен рядок H ортогональний до всього коду C**, тобто кожен рядок H сам лежить у C⊥. А рядків цих n − k, і вони незалежні (інакше H не ловила б усіх помилок). Отже, рядки перевірної матриці C — це базис дуального коду:

```
перевірна матриця коду C  =  твірна матриця коду C⊥
```

Те, що для C було «переліком контрольних рівнянь», для C⊥ виявляється «списком базисних слів». Кодер одного коду — це буквально перевіряч другого. (Механіка самого множення на G та H — як із базису зібрати кодування добутком і порахувати синдром — розгорнута в [лінійних блокових кодах](topic:com-modulation/generator-and-parity-check-matrices); тут важить не як множити, а що H і G — два обличчя однієї пари кодів.)

Скільки ж вимірів у дзеркала? Відповідь елегантно строга. Дуальний код — це множина розв'язків системи G·xᵀ = 0, де G (твірна матриця C) має розмір k × n і [ранг](topic:math-algebra/matrix-rank) k. За теоремою про ранг і дефект розмірність простору розв'язків дорівнює n мінус ранг:

```
dim C⊥ = n − rank(G) = n − k

звідси:   dim C + dim C⊥ = k + (n − k) = n
```

Розмірності коду й дуального завжди складаються рівно в довжину слова. Це не збіг конкретного коду, а пряма арифметика рангу.

**Наскрізний приклад: код повторення й код парності — дуальні.** Візьмімо найкоротші нетривіальні коди довжини 3.

```
код ПОВТОРЕННЯ [3,1]:   C_rep = { 000, 111 }        dim = 1
   твірна:   G_rep = [ 1 1 1 ]

його дуал — усі x, ортогональні до 111, тобто x·111 = x₁+x₂+x₃ = 0:
   це рівно слова ПАРНОЇ ваги
код ПАРНОСТІ [3,2]:     C_par = { 000, 110, 101, 011 }   dim = 2
   твірна:   G_par = [ 1 0 1 ]
                     [ 0 1 1 ]
```

А тепер погляньмо на перевірні матриці — і побачмо дзеркало наживо:

```
H коду повторення   =   [ 1 0 1 ]   =   G коду парності
                        [ 0 1 1 ]

H коду парності     =   [ 1 1 1 ]   =   G коду повторення
```

Твірна кожного з них — це перевірна другого; вони переставлені ролями. І розмірності сходяться: dim 1 + dim 2 = 3 = n. Код повторення й код парності — не просто «прості коди», а **точна дуальна пара**: найтупіший спосіб додати надлишок (повтори все) і найощадливіший ([один біт парності](topic:com-modulation/parity-bit)) виявляються двома боками однієї монети.

![Дуальна пара: код повторення [3,1] і код парності [3,2] як дзеркала — твірна матриця кожного дорівнює перевірній матриці другого, а їхні розмірності 1 і 2 складаються точно в довжину слова 3](img/dual-pair.svg)
*Код повторення [3,1] і код парності [3,2] — дуальні: G одного дорівнює H другого, і навпаки. Розмірності 1 + 2 = 3 = n. Кожен лінійний код має таке дзеркало, і виміри двох завжди складаються в довжину.*

**Де аналогія з ℝⁿ ламається.** Спокусливо думати про C⊥ як про звичне «ортогональне доповнення» з геометрії дійсного простору. Формула розмірностей і справді переноситься дослівно — бо вона суто про ранг, а ранг байдужий до поля. Але друга половина шкільної інтуїції над скінченним полем **гине**. У ℝⁿ доповнення не тільки додає розмірності до n, а й перетинається з простором лише в нулі (C ∩ C⊥ = {0}) і разом із ним заповнює весь простір без накладок. Причина — додатна визначеність: у ℝ добуток x·x = x₁² + … + xₙ² додатний для будь-якого ненульового x, тож ненульове слово **не може** бути ортогональним саме собі. Над GF(q) цього щита немає. Над GF(2):

```
11 · 11 = 1·1 + 1·1 = 1 + 1 = 0     ← слово ортогональне саме собі!
```

Слово може лежати у власному дуалі. Тому код повторення довжини **2** — C = {00, 11} — має C⊥ = {x : x₁+x₂ = 0} = {00, 11} = C: він **самодуальний**, дорівнює власному дзеркалу. Розмірності все ще сходяться (1 + 1 = 2), але перетин C ∩ C⊥ — це весь C, а не нуль. Тож правильне слово для C⊥ над скінченним полем — не «доповнення», а **анулятор**: те, що обертає код на нуль. І самодуальні коди — не курйоз, а еліта: розширений код Геммінга [8, 4, 4] і код Голея [24, 12, 8] самодуальні — половина символів дані, половина перевірки, а код збігається зі своїм перевірячем.

> 🔧 **Навіщо це.** Дуальність — не прикраса. По-перше, вона пояснює, звідки береться перевірна матриця: H коду — це G його дуала, тобто набір перевірок дається задарма разом із самим кодом. По-друге, найсильніші відомі коди тримаються саме на дуальній симетрії: самодуальний код сам собі перевіряч, і ця жорстка рівновага (як у Голея) дає рекордні відстані. Хто розуміє дуальний код, той бачить перевірку не як окрему машинерію, а як тінь самого коду.

## Межа Синглтона: скільки сили взагалі можна купити

Конструктор коду хоче двох речей одразу: великої **мінімальної відстані** d (щоб код виправляв багато помилок) і великої розмірності k (щоб не марнувати канал на надлишок), — і все це при фіксованій довжині n. Ці бажання тягнуть у різні боки: кожен символ, віддданий заради відстані, — це символ, забраний у даних. Постає чесне питання: чи є **тверда стеля**? Чи можна, доплачуючи надлишком, купувати відстань без кінця?

Ні. Стеля є, і вона проста — це **межа Синглтона**:

```
d ≤ n − k + 1
```

Мінімальна відстань лінійного [n, k]-коду не може перевищити число надлишкових символів плюс один. Найкраще, що дає кожен доданий контрольний символ, — рівно одна одиниця відстані.

Доведімо це **від першопричини**, без формул, самим лише рахуванням. Візьмімо код і **викиньмо** з кожного слова якісь d − 1 координат — залишмо тільки перші n − (d − 1) = n − d + 1 позицій (це називають *проколюванням*, puncturing). Тепер ключове спостереження: **скорочені слова досі всі різні**. Чому? Будь-які два повні кодові слова різняться щонайменше в d позиціях — це і є означення мінімальної відстані. Викидаючи d − 1 координат, ми стираємо щонайбільше d − 1 із цих розбіжностей, тож принаймні одна **лишається**: тіні двох слів усе одно десь відрізняються. Отже, з qᵏ повних слів вийшло qᵏ **різних** скорочених. Але скорочені слова живуть у просторі завдовжки n − d + 1, а в ньому всього qⁿ⁻ᵈ⁺¹ точок. Не можна розсадити qᵏ різних речей по меншій кількості місць:

```
qᵏ ≤ qⁿ⁻ᵈ⁺¹   ⟹   k ≤ n − d + 1   ⟹   d ≤ n − k + 1
```

Чистий принцип Діріхле — стільки голубів, стільки й комірок. Зверніть увагу: у доведенні **не використано жодної властивості поля**, окрім уміння рахувати точки, — тому межа Синглтона стоїть над будь-яким GF(q), двійковим і ні. Це не інженерна оцінка, а логічна неможливість: жоден [n, k]-код фізично не втисне відстань більшу за n − k + 1.

Історична примітка, чесно про ім'я. Цю нерівність зазвичай звуть межею Синглтона — за працею Річарда К. Синглтона «Maximum distance q-nary codes» (IEEE Transactions on Information Theory, 1964). Та сам результат **старший** за назву: його довів раніше С. Н. Джоші (1958), а ще раніше — Й. Комамія (1953), лише складнішим міркуванням. Тож ім'я в назві фіксує не першовідкривача, а того, чия праця закріпилася в каноні теорії кодування, — звичний візерунок, коли результат носить ім'я найвідомішого, а не найпершого автора. Статус доказовості: сама нерівність — усталений математичний факт; авторство назви — питання історіографії, не математики.

## MDS-коди: коли межа торкнута — і чому тоді треба велике поле

Що, як код **дотягується** до стелі — досягає рівності d = n − k + 1? Такі коди звуть **MDS** (від англ. Maximum Distance Separable — код найбільшої можливої відстані за даних n і k). У MDS-коді кожен із n − k надлишкових символів витискає свою повну одиницю відстані, без жодної втрати — це найсильніший [n, k]-код, який узагалі дозволений законами лічби.

Що ця гранична сила дає на практиці, найкраще видно через **стирання**. MDS-код [n, k] відновлює всі k символів даних із **будь-яких** k отриманих символів із n: втратьте які завгодно n − k символів — решти рівно вистачить, щоб точно відбудувати повідомлення. Це ідеальний (n, k)-код для стирань — та сама властивість, на якій тримаються RAID-масиви, QR-коди й зв'язок із далеким космосом.

Для контрасту — код, що межі **не** торкається. [Код Геммінга](topic:com-modulation/hamming-code) [7, 4, 3]: тут n − k + 1 = 4, а d = 3, на одиницю нижче стелі. Чудовий код, але **не MDS** — на карті сили він сидить рядком під межею Синглтона.

![Межа Синглтона як стеля сили: у площині «розмірність k — відстань d» пряма d = n−k+1 (для n=7) відсікає заборонену зону згори; MDS-коди лежать точно на прямій (повторення [7,1,7], Рід–Соломон [7,3,5] над GF(8), парність [7,6,2]), а код Геммінга [7,4,3] сидить на одиницю нижче — не MDS; над GF(2) досяжні лише кутові тривіальні MDS, а внутрішні точки прямої бере лише велике поле](img/singleton.svg)
*Межа Синглтона d = n − k + 1 (тут n = 7) — стеля сили лінійного коду; усе над прямою неможливе. MDS-коди сидять точно на ній. Над GF(2) досяжні лише кути (повторення й парність); щоб сісти на пряму всередині — як Рід–Соломон [7,3,5] — потрібне велике поле GF(8). Геммінг [7,4,3] лежить на одиницю нижче: не MDS.*

І ось де всі три нитки — розмірність, поле, межа — сходяться в одну. Над двійковим полем **сильних MDS-кодів просто немає**. Єдині двійкові MDS-коди — три тривіальні: увесь простір [n, n, 1], код парності [n, n−1, 2] і код повторення [n, 1, n]; будь-який інший двійковий код відстані стелі не торкається (усталений факт: «у двійковому випадку існують лише тривіальні MDS-коди»). Не можна водночас виправляти багато помилок **і** сидіти на межі Синглтона, лишаючись у світі бітів. Щоб дістати справжній MDS-код — такий, що виправляє відчутну частку помилок, — доводиться **покинути GF(2) заради більшого поля**. І там на межі вже чекає [Рід — Соломон](topic:com-modulation/reed-solomon): над GF(q) він MDS для будь-якого k, тобто [n, k, n − k + 1], а довжина його сягає порядку розміру поля q. Рід — Соломон — це межа Синглтона, втілена в код. Ось глибинна причина, чому теорія кодування тягнеться до полів GF(2ᵐ) і символів-байтів замість окремих бітів: не зручність, а єдиний спосіб узагалі збудувати сильний код, що торкається стелі. Більше поле — це буквально «купити місце на межі Синглтона».

## Де це працює в темі

Три алгебраїчні факти, витягнуті з одного слова «підпростір», — це не орнамент навколо коду, а його кістяк і його межі. Рівність |C| = qᵏ — причина, чому весь код, хоч який астрономічний, вміщується в k збережених базисних векторів: уся практичність тримається на ній. Дуальний код — причина, чому кожен лінійний код дарує перевірну матрицю задарма (це твірна дзеркала) і чому найсильніші коди самодуальні. А межа Синглтона з MDS-кодами окреслює зовнішню стіну — карту того, яку силу взагалі можна купити, і пояснення, чому найпотужніші коди живуть над великими полями. Підпростір, узятий буквально, каже не лише **як** лінійний код працює, а й **наскільки добрим** йому дозволено стати.
