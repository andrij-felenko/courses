# 🧮 Математичний вивід BER для частково-смугової завади

Ця вставка містить строгий математичний вивід ймовірності бітової помилки (англ. *Bit Error Rate*, BER) для радіолінії зі стрибками частоти (FHSS) та некогерентною частотною маніпуляцією (BFSK) в умовах частково-смугової завади (англ. *Partial-Band Jamming*, PBJ). Вивід розкриває фундаментальний інженерно-математичний ефект: як оптимізована частково-смугова завада перетворює експоненційну завадостійкість некодерованої системи на обернено-лінійну, і як завадостійке кодування зі стиранням відновлює експоненційний захист.

---

### 1. Фізична та спектральна модель системи

Розглядається передавач FHSS, який використовує некогерентну двопозиційну частотну маніпуляцію (BFSK). Корисний інформаційний сигнал має середню потужність `P_s` та тривалість передачі одного біта `T_b = 1 / R_b`, де `R_b` — швидкість передачі даних. Відповідно, енергія, яка припадає на один біт інформації, становить:

```
E_b = P_s · T_b = P_s / R_b
```

Передавач і приймач синхронно виконують стрибки частоти по `N` ортогональних частотних каналах у межах загальної смуги розширення спектра `W_ss`. Тривалість перебування на одній частоті (один хоп) дорівнює `T_h`.

Постановник завад володіє фіксованою сумарною потужністю випромінювання `J`. 

#### Сценарій А: Суцільна загороджувальна завада (Barrage Jamming)
Якщо глушильник рівномірно розподіляє свою потужність `J` по всій доступній смузі `W_ss`, еквівалентна спектральна густина потужності завадового шуму `N_J` виражається як:

```
N_J = J / W_ss
```

У каналі з аддитивним білим гаусовим шумом (AWGN) ймовірність бітової помилки `P_e` для некогерентного приймача BFSK описується формулою:

```
P_e = (1 / 2) · exp(-E_b / (2 · N_J))
```

Цей вираз показує **експоненційну завадостійкість**: при збільшенні енергії біта `E_b` або зменшенні спектральної густини завади `N_J` ймовірність помилки падає катастрофічно швидко для завади.

#### Сценарій Б: Частково-смугова завада (Partial-Band Jamming)
Постановник завад фокусує усю свою сумарну потужність `J` лише у частці смуги `ρ` (де `0 < ρ ≤ 1`). Ширина глушеного інтервалу становить `W_j = ρ · W_ss`. 

Усередині глушеної частки спектра спектральна густина потужності завади зростає у `1 / ρ` разів:

```
N_J' = N_J / ρ = J / (ρ · W_ss)
```

У решті смуги `(1 - ρ)` потужність завади дорівнює нулю. Власним тепловим шумом приймача `N_0` у даному аналізі нехтуємо, оскільки потужність завади зазвичай перевищує тепловий шум на кілька порядків (`N_J >> N_0`).

---

### 2. Ймовірність помилки у частково-смуговому каналі

Оскільки послідовність частотних хопів FHSS є псевдовипадковою та рівномірно розподіленою по `N` каналах, імовірність того, що довільний хоп потрапить у глушену частку смуги `ρ`, дорівнює `ρ`. Відповідно, з ймовірністю `(1 - ρ)` хоп потрапляє у чисту від завад смугу.

За формулою повної ймовірності загальна бітова ймовірність помилки `P_e(ρ)` дорівнює:

```
P_e(ρ) = P(помилка | уражений) · P(уражений) + P(помилка | чистий) · P(чистий)
```

1. **У чистій смузі `(1 - ρ)`:** Шумовий вплив відсутній (`N_0 → 0`), тому ймовірність помилки дорівнює нулю:
   
```
P(помилка | чистий) = 0
```

2. **У глушеній смузі `ρ`:** Спектральна густина шуму становить `N_J' = N_J / ρ`. Підставивши `N_J'` у формулу некогерентного BFSK, отримуємо:
   
```
P(помилка | уражений) = (1 / 2) · exp(-E_b / (2 · N_J'))
                      = (1 / 2) · exp(-ρ · E_b / (2 · N_J))
```

Підставляємо обидва компоненти у формулу повної ймовірності:

```
P_e(ρ) = ρ · (1 / 2) · exp(-ρ · E_b / (2 · N_J)) + (1 - ρ) · 0
       = (ρ / 2) · exp(-ρ · E_b / (2 · N_J))
```

### 3. Математична оптимізація стратегії завади (Найгірший випадок)

Постановник завад прагне обрати таке значення частки смуги `ρ`, яке **максимізує** підсумковий рівень помилок `P_e(ρ)` при фіксованій сумарній потужності `J`.

Знайдемо критичні точки функції `P_e(ρ)` за допомогою першої похідної по зміній `ρ`:

```
d P_e(ρ) / d ρ
= d / d ρ [ (ρ / 2) · exp(-ρ · E_b / (2 · N_J)) ]
= (1 / 2) · exp(-ρ · E_b / (2 · N_J)) + (ρ / 2) · [ -E_b / (2 · N_J) ] · exp(-ρ · E_b / (2 · N_J))    [правило похідної добутку]
= (1 / 2) · [ 1 - ρ · E_b / (2 · N_J) ] · exp(-ρ · E_b / (2 · N_J))                                 [винесення експоненти]
```

Прирівнюємо першу похідну до нуля для знаходження екстремуму:

```
(1 / 2) · [ 1 - ρ · E_b / (2 · N_J) ] · exp(-ρ · E_b / (2 · N_J)) = 0
```

Оскільки експоненційний множник `exp(...)` ніколи не дорівнює нулю для скінченних значень, нулем має бути вираз у квадратних дужках:

```
1 - ρ_opt · E_b / (2 · N_J) = 0
= ρ_opt · E_b / (2 · N_J) = 1
= ρ_opt = 2 / (E_b / N_J)      [значення найгіршої частки смуги]
```

#### Перевірка другої похідної на максимум
Обчислимо другу похідну `d² P_e / d ρ²` у точці `ρ_opt`:

```
d² P_e / d ρ² = (1 / 2) · [ -E_b / (2 · N_J) ] · exp(-ρ · E_b / (2 · N_J)) + (1 / 2) · [ 1 - ρ · E_b / (2 · N_J) ] · [ -E_b / (2 · N_J) ] · exp(...)
```

У точці `ρ = ρ_opt` другий доданок обертається в нуль, а перший доданок є строгим від'ємним числом:

```
d² P_e / d ρ² |_(ρ_opt) = - (E_b / (4 · N_J)) · exp(-1) < 0
```

Отже, точка `ρ_opt = 2 / (E_b / N_J)` дійсно є **глобальним максимумом** ймовірності помилки.

#### Фізичне обмеження на `ρ`
Оскільки частка смуги за визначенням обмежена інтервалом `0 < ρ ≤ 1`, знайдений оптимум `ρ_opt` є досяжним лише тоді, коли:

```
ρ_opt ≤ 1  ⇒  2 / (E_b / N_J) ≤ 1  ⇒  E_b / N_J ≥ 2  (тобто ≥ 3.01 дБ)
```

Якщо відношення енергії біта до завади є занадто малим (`E_b / N_J < 2`), глушильник не має достатньої потужності для звуження смуги, і його оптимальною тактикою стає суцільна загороджувальна завада (`ρ_opt = 1`).

---

### 4. Вивід найгіршої ймовірності помилки (P_e_max)

Підставимо знайдений оптимум `ρ_opt = 2 / (E_b / N_J)` у вираз для ймовірності бітової помилки `P_e(ρ)`:

```
P_e_max = P_e(ρ_opt)
        = (1 / 2) · [ 2 / (E_b / N_J) ] · exp(- [ 2 / (E_b / N_J) ] · E_b / (2 · N_J) )   [підстановка ρ_opt]
        = [ 1 / (E_b / N_J) ] · exp(-1)                                                   [скорочення 2 та E_b/N_J у показнику]
        = 1 / (e · (E_b / N_J))                                                           [число Ейлера e ≈ 2.71828]
        ≈ 0.367879 / (E_b / N_J)                                                          [підсумкова обернено-лінійна залежність]
```

### 5. Порівняльний аналіз завадостійкості

Отриманий результат демонструє радикальну зміну фізики ураження радіолінії:

1. **Суцільна загороджувальна завада (`ρ = 1`):**
   
```
P_e = (1 / 2) · exp(-0.5 · E_b / N_J)      [експоненційний спад помилок]
```

2. **Оптимізована частково-смугова завада (`ρ = ρ_opt`):**
   
```
P_e_max ≈ 0.3679 / (E_b / N_J)             [обернено-лінійний спад помилок]
```

| E_b / N_J (дБ) | E_b / N_J (лінійне) | ρ_opt (оптимум завади) | BER Barrage (ρ = 1) | BER Partial-Band (ρ_opt) | Погіршення BER у разі PBJ |

При відношенні сигнал/завада 20 дБ (що є відмінним рівнем для звичайного радіоканалу) загороджувальна завада дає практично нуль помилок (`10⁻²²`). Однак частково-смугова завада, концентруючи потужність лише у 2% каналів, забезпечує стабільні `0.37%` помилок. Для некодованого текстового чи командного потоку 0.37% бітових помилок означає руйнування майже кожного третього мережевого пакета.

### 6. Математична теорія відновлення завадостійкості через FEC та стирання

Щоб здолати лінійну характеристику ураження, у систему вводять кодер завадостійкого кодування (FEC) із кодовою відстанню `d_min` та блоковий перемішувач бітів (англ. *interleaver*).

#### Модель некогерентного детектора з вимірюванням метрики стирання (Erasure Metric)
Приймач вимірює сумарну енергію `E_sum = E₀ + E₁` у кожному хопі. Якщо `E_sum > γ_th` (де `γ_th` — поріг виявлення завади), приймач вважає цей хоп ураженим завадою і позначає всі його біти як **стирання** (англ. *erasure*).

Розглянемо блоковий код Ріда-Соломона `RS(n, k)` над галуаївським полем `GF(2ᵐ)`, який має довжину кодового блоку `n` символів та містить `k` інформаційних символів. Мінімальна кодова відстань становить:

```
d_min = n - k + 1
```

Код `RS(n, k)` здатний виправити `t` помилок та `e` стирань за умови дотримання фундаментальної нерівності:

```
2 · t + e ≤ n - k
```

Якщо приймач ідеально ідентифікує всі глушені хопи за допомогою енергетичного детектора (`t = 0`), виправна здатність по стираннях сягає граничних:

```
e_max = n - k
```

#### Ймовірність помилки кодового блоку під PBJ
Кожен символ кодового блоку після деперемішувача потрапляє у глушену смугу з незалежною ймовірністю `ρ`. Кількість стирань `e` у блоці з `n` символів підпорядковується біноміальному розподілу:

```
P(e стирань у блоці) = C(n, e) · ρᵉ · (1 - ρ)ⁿ⁻ᵉ
```

Помилка декодування кодового блоку виникає тоді і тільки тоді, коли кількість стирань `e` перевищує виправну здатність `n - k`:

```
P_block = ∑ [e = n - k + 1 ... n] C(n, e) · ρᵉ · (1 - ρ)ⁿ⁻ᵉ
```

При малих значеннях `ρ` головний внесок у суму дає перший член при `e = n - k + 1`:

```
P_block ≈ C(n, n - k + 1) · ρⁿ⁻ᵏ⁺¹
```

Підставивши у цей вираз найгіршу частку смуги `ρ_opt = 2 / (E_b / N_J)`, отримуємо підсумкову залежність помилки блоку від відношення сигнал/завада:

```
P_block ≈ C(n, n - k + 1) · [ 2 / (E_b / N_J) ]ⁿ⁻ᵏ⁺¹
```

### Висновок математичного аналізу

Завдяки застосуванню кодування зі стиранням підсумкова ймовірність помилки системи стає **степеневою функцією** від `E_b / N_J` з показником степеня `N_eff = n - k + 1`.

При виборі коду з виправною здатністю `n - k ≥ 3` кут нахилу кривої BER стає настільки крутим, що лінійна перевага частково-смугової завади повністю нівелюється, а підсумкова завадостійкість радіолінії знову демонструє високу експоненційну надійність.
