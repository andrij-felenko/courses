# 🧮 Математичний апарат IQ-перетворення та комплексного спектра

Ця вставка містить суворе математичне виведення зв'язку між аналітичним сигналом, перетворенням Гільберта, комплексним огинаючим, ортогональним розкладанням I/Q, переносом спектра між базовою смугою та радіочастотою, а також матричним описом апаратурних спотворень.

### 1. Тригонометричне розкладання та поляризаційні сили

Будь-який вузькосмуговий реальний радіосигнал `s(t)`, який коливається навколо несучої частоти `f_c = ω_c / 2π`, описується миттєвою амплітудою `A(t) ≥ 0` та миттєвою фазою `φ(t)`:

```
s(t) = A(t) · cos(ω_c t + φ(t))
```

Скориставшись тригонометричною тотожністю для косинуса суми двох аргументів `cos(α + β) = cos α cos β - sin α sin β`, розкриємо внутрішню фазову залежність сигналу:

```
s(t) = A(t) · (cos(φ(t)) · cos(ω_c t) - sin(φ(t)) · sin(ω_c t))
     = (A(t) · cos(φ(t))) · cos(ω_c t) - (A(t) · sin(φ(t))) · sin(ω_c t)
```

Введемо дві незалежні функції часу базової смуги (низькочастотні модулювальні сигнали):
- **Синфазна складова I(t)** (In-phase component):
```
I(t) = A(t) · cos(φ(t))
```
- **Квадратурна складова Q(t)** (Quadrature component):
```
Q(t) = A(t) · sin(φ(t))
```

Підставивши вирази для `I(t)` та `Q(t)` назад у рівняння сигналу, отримуємо канонічну квадратурну форму дійснозначного радіоколивання:

```
s(t) = I(t) · cos(ω_c t) - Q(t) · sin(ω_c t)
```

Звороне перетворення від прямокутних декартових компонент `I(t)` та `Q(t)` до полярних координат миттєвої амплітуди `A(t)` та фази `φ(t)` виконується за рівняннями:

```
A(t) = √(I²(t) + Q²(t))      [миттєва амплітуда / огинаюче]
φ(t) = atan2(Q(t), I(t))      [миттєва фаза]
```

Функція `atan2(Q, I)` враховує алгебраїчні знаки обох компонент і обчислює кут у повному діапазоні від `-π` до `+π` радіан, усуваючи неоднозначність прямого арктангенса `Q/I`.

### 2. Аналітичний сигнал, інтеграл Гільберта та теорема Бедрозіана

Для суворого опису фазових співвідношень у теорії сигналів використовують концепцію **аналітичного сигналу**. Нехай `s(t)` — дійсний фізичний сигнал. Його перетворення Гільберта `ŝ(t) = H{s(t)}` визначається як згортка сигналу з невласним ядром `1/(π t)` у сенсі головного значення за Коші (p.v. — principal value):

```
ŝ(t) = H{s(t)} = (1 / π) · p.v. ∫_{-∞}^{+∞} (s(τ) / (t - τ)) dτ
```

У частотній області перетворення Гільберта еквівалентне проходженню сигналу через ідеальний квадратурний фазообертач, який повертає фазу всіх додатних частотних компонент на `-90°` (`-π/2` радіан), а всіх від'ємних частотних компонент — на `+90°` (`+π/2` радіан). Передавальна функція такого фазообертача має вигляд:

```
F{ H{s(t)} } = -j · sgn(f) · S(f)
```

Аналітичний сигнал `s_a(t)` — це комплексний сигнал, у якого дійсною частиною є вихідний Signal `s(t)`, а уявною частиною — його перетворення Гільберта `ŝ(t)`:

```
s_a(t) = s(t) + j · ŝ(t)
```

Обчислимо перетворення Гільберта для гармонічного сигналу `s(t) = A(t) cos(ω_c t + φ(t))`. За теоремою Бедрозіана, якщо спектр низькочастотного огинаючого `A(t)` обмежений частотою `B`, а несуча частота `ω_c > 2π B` (спектри не перекриваються), то перетворення Гільберта від добутку низькочастотного сигналу на високочастотну гармоніку дорівнює добутку низькочастотного сигналу на перетворення Гільберта від високочастотної гармоніки:

```
ŝ(t) = H{ A(t) · cos(ω_c t + φ(t)) } = A(t) · H{ cos(ω_c t + φ(t)) } = A(t) · sin(ω_c t + φ(t))
```

Підставивши `ŝ(t)` в аналітичний сигнал, за формулою Ейлера `e^(j θ) = cos θ + j sin θ` отримуємо:

```
s_a(t)
= A(t) · cos(ω_c t + φ(t)) + j · A(t) · sin(ω_c t + φ(t))   [підстановка s(t) та ŝ(t)]
= A(t) · e^(j (ω_c t + φ(t)))                                [формула Ейлера]
= (A(t) · e^(j φ(t))) · e^(j ω_c t)                           [властивість показника степеня]
```

Множник `z(t) = A(t) e^(j φ(t))` називають **комплексним огинаючим** (*complex envelope*) або комплексним сигналом базової смуги. Розкриємо `z(t)` через формулу Ейлера:

```
z(t) = A(t) · (cos(φ(t)) + j · sin(φ(t)))
     = I(t) + j · Q(t)
```

Отже, аналітичний сигнал `s_a(t)` та фізичний дійсний сигнал `s(t)` виражаються через комплексне огинаюче `z(t)` наступними співвідношеннями:

```
s_a(t) = z(t) · e^(j ω_c t)
s(t)   = Re{ s_a(t) } = Re{ z(t) · e^(j ω_c t) }
```

Перевіримо дійсне значення добутку:

```
s(t)
= Re{ z(t) · e^(j ω_c t) }                                    [визначення через комплексне огинаюче]
= Re{ (I(t) + j·Q(t)) · (cos(ω_c t) + j·sin(ω_c t)) }         [підстановка z(t) та e^(j ω_c t)]
= Re{ I(t)·cos(ω_c t) - Q(t)·sin(ω_c t) + j·(...) }            [множення комплексних чисел]
= I(t)·cos(ω_c t) - Q(t)·sin(ω_c t)                           [виділення дійсної частини]
```

### 3. Комплексний спектр і частотний зсув

Знайдемо спектральне співвідношення між сигналом базової смуги та радіочастотним сигналом. Нехай `Z(f) = F{z(t)}` — перетворення Фурьє комплексного огинаючого `z(t) = I(t) + j Q(t)`.

Оскільки `z(t)` є комплекснозначним сигналом, його спектр `Z(f)` **не володіє** власністю ермітової симетрії. Загалом:

```
Z(f) = I(f) + j · Q(f)
Z(-f) ≠ Z*(f)      [спектр несиметричний відносно нуля]
```

Знайдемо перетворення Фурьє аналітичного сигналу `s_a(t) = z(t) · e^(j 2π f_c t)`. За теоремою про зсув у частотній області:

```
S_a(f) = F{ z(t) · e^(j 2π f_c t) } = Z(f - f_c)
```

Спектр аналітичного сигналу є точною зсунутою копією комплексного спектра базової смуги `Z(f)`, центрованою відносно несучої частоти `f_c`. При цьому:
- Спектральні складові базової смуги при `f > 0` (додатні частоти) переходять у частотну область `f_c + f > f_c`, утворюючи **верхню бічну смугу** (USB).
- Спектральні складові базової смуги при `f < 0` (від'ємні частоти) переходять у частотну область `f_c - |f| < f_c`, утворюючи **нижню бічну смугу** (LSB).

Оскільки дійсний сигнал `s(t) = (1/2) (s_a(t) + s_a*(t))`, його повний радіочастотний спектр `S(f)` складається з двох симетричних частин:

```
S(f) = (1/2) · Z(f - f_c) + (1/2) · Z*(-(f + f_c))
```

Це доводить, що за допомогою комплексної базової смуги `z(t)` можна довільно керувати асиметрією радіочастотного спектра навколо `f_c`.

### 4. Доведення математики квадратурного демодулятора

Розглянемо процес виділення компонент `I(t)` та `Q(t)` у демодуляторі приймача. Прийнятий сигнал `s(t) = I(t) cos(ω_c t) - Q(t) sin(ω_c t)` подається на два ортогональні змішувачі.

#### Канал I (перемноження на `cos(ω_c t)`):

```
x_I(t)
= s(t) · cos(ω_c t)                                           [сигнал після змішувача I]
= (I(t)·cos(ω_c t) - Q(t)·sin(ω_c t)) · cos(ω_c t)            [підстановка квадратурного s(t)]
= I(t)·cos²(ω_c t) - Q(t)·sin(ω_c t)·cos(ω_c t)                [розкриття дужок]
= (1/2)·I(t) + (1/2)·I(t)·cos(2ω_c t) - (1/2)·Q(t)·sin(2ω_c t) [тотожності подвійного кута]
```

Після пропускання сигналу через фільтр низьких частот (ФНЧ) з частотою зрізу `B < f_c`, високочастотні компоненти на подвоєній несучій `2ω_c` повністю пригнічуються:

```
I'(t) = LPF{ x_I(t) } = (1/2) · I(t)
```

#### Канал Q (перемноження на `-sin(ω_c t)`):

```
x_Q(t)
= s(t) · (-sin(ω_c t))                                        [сигнал після змішувача Q]
= -(I(t)·cos(ω_c t) - Q(t)·sin(ω_c t)) · sin(ω_c t)           [підстановка квадратурного s(t)]
= -I(t)·cos(ω_c t)·sin(ω_c t) + Q(t)·sin²(ω_c t)               [розкриття дужок]
= (1/2)·Q(t) - (1/2)·I(t)·sin(2ω_c t) - (1/2)·Q(t)·cos(2ω_c t) [тотожності подвійного кута]
```

Після низькочастотної фільтрації ФНЧ складові `2ω_c` зникають:

```
Q'(t) = LPF{ x_Q(t) } = (1/2) · Q(t)
```

Отриманий результат доводить, що ортогональне демодулювання виділяє первинні сигнали `I(t)` та `Q(t)` з однаковим коефіцієнтом передачі `1/2` без взаємного просочування компонент (перехресні завади дорівнюють нулю).

### 5. Матрична модель апаратурних спотворень та ортогоналізація

У реальному аналоговому змішувачі наявні апаратурні недосконалості:
- **DC offset:** постійні зсуви `I_0` та `Q_0`.
- **Gain imbalance:** відношення коефіцієнтів підсилення `g = g_Q / g_I`.
- **Phase imbalance:** фазове відхилення від 90°, рівне `Δφ`.

Спотворений виміряний вектор `[I_m, Q_m]^T` пов'язаний з ідеальним вектором `[I, Q]^T` матричним перетворенням:

```
[ I_m ]   [ 1            0               ]   [ I ]   [ I_0 ]
[     ] = [                              ] * [   ] + [     ]
[ Q_m ]   [ g·sin(Δφ)    g·cos(Δφ)       ]   [ Q ]   [ Q_0 ]
```

Для відновлення ідеального сигналу `[I, Q]^T` виконують зворотну матричну операцію (цифрова ортогоналізація Грама-Шмідта):

```
I_corr = I_m - I_0
Q_corr = ((Q_m - Q_0) - I_corr · g · sin(Δφ)) / (g · cos(Δφ))
```

Рівень пригнічення дзеркального каналу (Image Rejection Ratio, IRR) за наявності малих фазових `Δφ` та амплітудних `Δg` відхилень обчислюється як:

```
IRR ≈ 20 · log10( 4 / √( (Δg)² + (Δφ)² ) )
```

Ця операція повністю усуває перехресні зв'язки між каналами і відновлює вихідну прямокутну геометрію сузір'я точок у цифровому процесорі.
